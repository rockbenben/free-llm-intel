# 将 Amazon Bedrock 工具链用于 Amazon SageMaker JumpStart 模型

今天，我们很高兴宣布一项新能力：你可以从 [Amazon SageMaker JumpStart](https://aws.amazon.com/sagemaker/jumpstart/) 部署 100 多个开放权重和专有模型，并将它们注册到 [Amazon Bedrock](https://aws.amazon.com/bedrock/)，从而通过强大的 Amazon Bedrock API 无缝访问这些模型。现在，你可以把 [Amazon Bedrock Knowledge Bases](https://aws.amazon.com/bedrock/knowledge-bases/) 和 [Amazon Bedrock Guardrails](https://aws.amazon.com/bedrock/guardrails/) 等 Amazon Bedrock 功能用于通过 SageMaker JumpStart 部署的模型。

SageMaker JumpStart 通过提供完全可定制的解决方案，以及 400 多个热门开放权重和专有生成式 AI 模型的一键部署与微调，帮助你上手机器学习（ML）。Amazon Bedrock 是一项完全托管的服务，提供单一 API 来访问和使用多种高性能基础模型（FM），同时还提供一整套构建生成式 AI 应用的能力。[Amazon Bedrock Converse API](https://docs.aws.amazon.com/bedrock/latest/APIReference/API_runtime_Converse.html) 是一个运行时 API，提供可与不同模型配合使用的一致接口。它让你能够使用 Amazon Bedrock 中的高级功能，例如 playground、guardrails 和 tool use（函数调用）。

长期以来，SageMaker JumpStart 一直是开发者和数据科学家部署最先进生成式 AI 模型的首选服务。通过这次集成，你现在可以把在 SageMaker JumpStart 上托管模型的灵活性，与 Amazon Bedrock 的完全托管体验结合起来，包括高级安全控制、可扩展的基础设施和全面的监控能力。

本文介绍如何通过 SageMaker JumpStart 部署 FM、将它们注册到 Amazon Bedrock，并使用 Amazon Bedrock API 调用它们。

## 解决方案概览

Converse API 标准化了与 Amazon Bedrock FM 的交互方式，让开发者只写一次代码就能跨多种模型使用，而无需针对模型的差异做调整。它通过在 API 请求中携带对话历史来支持多轮对话，开发者还可以借助 [tools ](https://docs.aws.amazon.com/bedrock/latest/userguide/tool-use-inference-call.html)（函数调用）完成需要访问外部 API 的任务。此外，Converse API 允许你通过在 API 调用中[加入 guardrail ](https://docs.aws.amazon.com/bedrock/latest/userguide/guardrails-use-converse-api.html)来拦截不当输入或生成内容。完整的受支持模型与模型功能清单，请参阅[受支持的模型与模型功能](https://docs.aws.amazon.com/bedrock/latest/userguide/conversation-inference-supported-models-features.html)。

这项新功能把 Converse API 的能力扩展为单一接口，开发者可以用它调用部署在 SageMaker JumpStart 中的 FM。这样开发者就能用同一个 API 调用来自 Amazon Bedrock 和 SageMaker JumpStart 的模型，简化了把模型集成到生成式 AI 应用中的过程。现在，你可以通过单一 API，在更大的世界级开源与专有模型库之上进行构建。要查看 SageMaker JumpStart 提供的 Bedrock Ready 模型完整列表，请参阅 [Bedrock Marketplace](https://docs.aws.amazon.com/bedrock/latest/userguide/amazon-bedrock-marketplace.html) 文档。你也可以使用 [Amazon Bedrock Marketplace](https://docs.aws.amazon.com/bedrock/latest/userguide/amazon-bedrock-marketplace.html) 来发现这些模型并将它们部署到 SageMaker 端点。

本文将带你完成以下步骤：

- 使用 SageMaker JumpStart 部署 Gemma 2 9B Instruct 模型。
- 将该模型注册到 Amazon Bedrock。
- 使用 Amazon Bedrock playground 以示例 prompt 测试该模型。
- 使用 Amazon Bedrock `RetrieveAndGenerate` API 查询 Amazon Bedrock 知识库。
- 设置 Amazon Bedrock Guardrails，帮助拦截有害内容和个人可识别信息（PII）数据。
- 使用 Converse API 调用模型，展示端到端的检索增强生成（RAG）流水线。

## 先决条件

你可以在 [Amazon SageMaker Studio](https://aws.amazon.com/sagemaker/studio/) 界面中访问并部署 SageMaker JumpStart 中的预训练模型。要在 [AWS 管理控制台](https://aws.amazon.com/console)中访问 SageMaker Studio，你需要设置一个 [Amazon SageMaker](https://aws.amazon.com/sagemaker/) 域。SageMaker 使用域来组织用户配置文件、应用程序及其关联资源。要创建域并设置用户配置文件，请参阅[Amazon SageMaker 设置指南](https://docs.aws.amazon.com/sagemaker/latest/dg/gs.html)。

## 对已部署模型使用 Amazon Bedrock API

本节演示如何使用 [AWS SDK for Python（Boto3）](https://aws.amazon.com/sdk-for-python/) 和 Converse API，调用你此前通过 SageMaker 部署并注册到 Amazon Bedrock 的 Gemma 2 9B Instruct 模型。本文相关的完整源代码见配套的 [GitHub repo](https://github.com/aws-samples/sagemaker-genai-hosting-examples/blob/main/jumpstart-bedrock/amazon-bedrock-with-amazon-sageMaker-jumpstart.ipynb)。更多 Converse API 示例请参阅 [Converse API 示例](https://docs.aws.amazon.com/bedrock/latest/userguide/conversation-inference-examples.html)。

在这个代码示例中，我们还结合已部署的模型实现了 RAG 架构。RAG 是对大语言模型（LLM）的输出进行优化的过程，让它在生成回答之前先引用训练数据源之外的权威知识库。

将部署好的 SageMaker 模型与 Amazon Bedrock 提供的 `RetrieveAndGenerate` API 配合使用，查询知识库并基于检索结果生成回答。回答只会引用与查询相关的来源。有关创建知识库的信息，请参阅[创建知识库](https://docs.aws.amazon.com/bedrock/latest/userguide/knowledge-base-create.html)。更多代码示例请参阅 [RetrieveAndGenerate](https://docs.aws.amazon.com/bedrock/latest/APIReference/API_agent-runtime_RetrieveAndGenerate.html)。

下图展示了 RAG 工作流。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/12/03/ML-17932-UIMGRag.jpg)

请完成以下步骤：

- 要调用已部署的模型，你需要在 Converse API 的 `modelId` 参数中传入已部署模型的端点 ARN。

要获取已部署模型的 ARN，请前往 Amazon Bedrock 控制台。在导航窗格中，选择 **Foundation models** 下的 **Marketplace deployments **。从托管部署列表中选择你注册的模型以查看更多详情。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/12/03/ML-17932-UIMG12-CodeSample.png)

你会被带到 **Foundation models** 下 **Model catalog ** 页面的模型摘要。在这里可以找到与你已部署模型相关的详细信息。复制模型 ARN，以便在下面的代码示例中使用。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/12/03/ML-17932-UIMG13-CodeSample.png)

```
import boto3

bedrock_runtime = boto3.client("bedrock-runtime")

# Add your bedrock endpoint arn here.
endpoint_arn = "arn:aws:sagemaker:<AWS::REGION>:<AWS::AccountId>:endpoint/<Endpoint_Name>"

# Base inference parameters to use.
inference_config = {
        "maxTokens": 256,
        "temperature": 0.1,
        "topP": 0.999,
}

# Additional inference parameters to use.
additional_model_fields = {"parameters": {"repetition_penalty": 0.9, "top_k": 250, "do_sample": True}}


response = bedrock_runtime.converse(
    modelId=endpoint_arn,
    messages=[
        {
            "role": "user",
            "content": [
                {
                    "text": "What is Amazon doing in the field of generative AI?",
                },
            ]
        },
    ],
    inferenceConfig=inference_config,
    additionalModelRequestFields=additional_model_fields,
)
```

- 使用 `RetrieveAndGenerate` API 调用 SageMaker JumpStart 模型。`generation_template` API 中的 `orchestration_template` 和 `retrieve_and_generate` 参数是与模型相关的。这些模板定义了给语言模型的 prompt 和指令，指导生成过程以及与知识检索组件的集成。

```
import boto3

bedrock_agent_runtime_client = boto3.client("bedrock-agent-runtime")

# Provide your Knowledge Base Id 
kb_id = "" 

response = bedrock_agent_runtime_client.retrieve_and_generate(
    input={
        "text": "What is Amazon doing in the field of generative AI?"
    },
    retrieveAndGenerateConfiguration={
        "type": "KNOWLEDGE_BASE",
        "knowledgeBaseConfiguration": {
            "generationConfiguration": {
                "inferenceConfig": {
                    "textInferenceConfig": {
                        "maxTokens": 512,
                        "temperature": 0.1,
                        "topP": 0.9
                    }
                },
                "promptTemplate": {
                    "textPromptTemplate": generation_template
                }
            },
            "knowledgeBaseId": kb_id,
            "orchestrationConfiguration": {
                "inferenceConfig": {
                    "textInferenceConfig": {
                        "maxTokens": 512,
                        "temperature": 0.1,
                        "topP": 0.9
                    }
                },
                "promptTemplate": {
                    "textPromptTemplate": orchestration_template
                },
            },
            "modelArn": endpoint_arn,
            "retrievalConfiguration": {
                "vectorSearchConfiguration": {
                    "numberOfResults":5
                } 
            }
        }
    }
)
```

现在你可以为 SageMaker JumpStart 模型通过 Converse API 实施 guardrails。Amazon Bedrock Guardrails 让你可以基于自己的用例和负责任 AI 政策，为生成式 AI 应用实施防护措施。有关创建 guardrails 的信息，请参阅[创建 Guardrail](https://docs.aws.amazon.com/bedrock/latest/userguide/guardrails-create.html)。更多实施 guardrails 的代码示例请参阅[在 Converse API 中加入 guardrail](https://docs.aws.amazon.com/bedrock/latest/userguide/guardrails-use-converse-api.html)。

- 在下面的代码示例中，你在调用 SageMaker JumpStart 模型的 Converse API 请求中加入 guardrail：

```
import boto3

bedrock_agent_runtime_client = boto3.client("bedrock-agent-runtime")

# Provide your Knowledge Base Id
kb_id = "" 

relevant_documents = bedrock_agent_runtime_client.retrieve(
    retrievalQuery= {
        "text": "What is Amazon doing in the field of generative AI?"
    },
    knowledgeBaseId=kb_id,
    retrievalConfiguration= {
        "vectorSearchConfiguration": {
            "numberOfResults": 1
        }
    }
)

def invoke_model(prompt, source, inference_config=None, additional_model_field=None):
    messages = [
        {
            "role": "user",
            "content": [
                {
                    "guardContent": {
                        "text": {
                            "text": source,
                            "qualifiers": ["grounding_source"],
                        }
                    }
                },
                {
                    "guardContent": {
                        "text": {
                            "text": prompt,
                            "qualifiers": ["query"],
                        }
                    }
                },
            ],
        }
    ]
    if not inference_config:
        # Base inference parameters to use.
        inference_config = {
                "maxTokens": 256,
                "temperature": 0.1,
                "topP": 0.999,
        }
    
    if not additional_model_field:
        # Additional inference parameters to use.
        additional_model_fields = {"parameters": {"repetition_penalty": 0.9, "top_k": 250, "do_sample": True}}


    response = bedrock_runtime.converse(
        modelId=endpoint_arn,
        messages=messages,
        inferenceConfig=inference_config,
        additionalModelRequestFields=additional_model_fields,
        guardrailConfig={
            'guardrailIdentifier': guardrail_identifier,
            'guardrailVersion': guardrail_version
        },
    )
```
