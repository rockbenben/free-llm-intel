# Handmade.com 如何借助 Amazon Bedrock 和 Amazon OpenSearch Service 实现产品图像与描述处理的现代化

[Handmade.com](https://handmade.com/) 是一个领先的手工艺品市场，为全球客户提供独特的、由卖家贡献的商品。其目录中有超过 60,000 件商品，而部分商品列表的描述较为基础，若能改进可提升搜索和搜索引擎优化（SEO）表现，因此自动化的需求变得显而易见。人工处理平均每周消耗 10 小时，需要数人的团队来维持基线质量。随着其市场规模扩大，对以规模化方式自动生成并提升产品描述与元数据质量的需求也随之增长。

Handmade.com 支持范围广泛的手工艺品，每一件都有独特的属性和呈现需求，因此必须超越千篇一律的描述。产品类型的多样性——从纺织品到雕塑——要求内容能够反映每件物品的独特特征。此外，最大限度缩短从卖家提交到产品发布的时间至关重要，尤其是卖家期望获得实时反馈并在一小时内上线。为支持国际化增长，Handmade.com 还需要生成跨多种语言和地区的高质量内容，帮助全球受众发现并获得相关性。

本文聚焦为分布式卖家群体上传的手工艺品生成丰富、可扩展的产品描述这一挑战。我们探讨 Handmade.com 如何设计并实现一个混合 AI 与向量搜索的解决方案，使用 [Amazon Bedrock](https://aws.amazon.com/bedrock/) 和 [Amazon OpenSearch Service](https://aws.amazon.com/opensearch-service/) 进行语义内容检索。

## **解决方案概述**

Handmade.com 实现了一个端到端、由 AI 驱动的 pipeline，以自动化并丰富产品描述。流程从图像和元数据摄取开始，随后使用 Anthropic 的 Claude 3.7 Sonnet 大语言模型（LLM）生成初始描述。这些描述使用 Amazon Titan Text Embeddings V2 模型进行嵌入，并存储在 Amazon OpenSearch Service 中，从而支持基于向量的语义搜索。检索增强生成（RAG）随后为结果提供上下文，以生成针对每件产品量身定制的、精炼且经过 SEO 优化的输出。

下图展示了高层架构。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/07/08/Screenshot-2025-07-08-at-2.33.29 PM.png)

该解决方案包含以下组件：

**产品图像上传与初始处理：**

- 产品图像和元数据从 Handmade.com 的产品数据仓库和 Elasticsearch 索引中获取
- 使用 Amazon Bedrock 中的 Anthropic Claude 为每张上传的图像生成初始描述

**向量嵌入与存储：**

- 生成的描述使用 Amazon Titan Text Embeddings V2 进行嵌入
- 嵌入向量存储在 OpenSearch Service 向量索引中，从而支持语义搜索能力

**用户上传产品的丰富化：**

- 当用户上传产品图像时，Anthropic Claude 会生成一份描述草稿
- 描述草稿使用 Amazon Titan 进行嵌入，并与 OpenSearch Service 向量存储中的现有条目进行比较

**检索增强生成：**

- 从 OpenSearch Service 检索到的上下文与新图像一起发送给 Amazon Bedrock 中的 Anthropic Claude
- 使用 RAG 模式生成精炼且丰富的产品描述

**搜索引擎优化：**

- 使用 Anthropic Claude 3.7 Sonnet 生成 SEO 元数据，包括关键词和增强的产品叙述
- 发送给模型的 prompt 遵循以下模式：“分析这张产品图像，并提供包含 seoTerms、product-description 等内容的详细 SEO 响应。”

**用户交互与 API 处理：**

- 卖家通过 Handmade.com 界面进行交互
- 一个 Node.js API 使用 AWS SDK 和 OpenSearch 包来处理图像摄取、模型调用和搜索工作流

**数据处理与系统集成：**

- 产品和图像数据从 Handmade.com 索引持续摄取
- Amazon Bedrock、OpenSearch Service 和自定义 API 协同完成嵌入、向量搜索和上下文推理

该解决方案还纳入客户交互数据，以持续改进描述生成和产品发现。系统分析用户参与度指标，包括点击率、页面停留时间和转化事件。这些行为信号被用于改进针对 Anthropic Claude 的 prompt engineering，优化描述生成以提升客户参与度。

此外，系统还将客户评论数据作为 RAG pipeline 的有价值输入。自然语言处理从评论文本中提取特定的产品属性和工艺细节（例如“独特的施釉技法”或“颜色变化特征”）。这些洞见与产品描述一起嵌入 OpenSearch Service 向量存储，从而实现更细致的语义搜索能力。通过将评论衍生的上下文与行为数据相结合，系统能够基于视觉和定性属性，更有效地为客户匹配相关的手工艺产品。

### **描述与元数据示例 prompt**

为生成一致且高质量的输出，Handmade.com 为 Anthropic Claude 精心设计了结构化 prompt，以处理图像和元数据。这些 prompt 引导模型生成产品描述、上下文增强内容和元数据。以下是为让 Anthropic Claude 生成多种输出文本而设定的角色示例：

```
[
  { "role": "Material Enthusiast" },
  { "role": "Sustainability Advocate" },
  { "role": "Heritage Historian" },
  { "role": "Functionality Reviewer" },
  { "role": "Maker Advocate" },
  { "role": "Visual Poet" }
]
```

随后，该流程使用 AI 和向量存储来提升产品描述，以改善 SEO 和用户参与度。我们将在下一节讨论关键步骤。

## **图像分析**

图像分析工作流包含以下步骤：

- 用户上传一张产品图像。
- Anthropic Claude 处理该图像并生成结构化描述，识别细节和潜在用途：

```
"AI Request": [
    {
        "type": "image",
        "source": {
            "type": "uploaded_file",
            "data": "user_image"
        }
    },
    {
        "type": "text",
        "text": "Create a simple title and description for this product."
    }
]
```

## **相似产品的向量搜索**

向量搜索过程包含以下步骤：

- 上传的图像会与一个精心整理的数据集进行比较，该数据集包含约 100 万件手工产品的描述，这些产品是在 20 多年间收集而来的。
- 该数据集存储在 OpenSearch Service 索引中，结构为存储向量——一种数字系统，其中产品描述被编码为文本及其关系的数值表示，而非纯文本。
- 来自 Anthropic Claude 的图像描述使用 Amazon Titan Text Embeddings V2 转换为向量，从而在索引中实现高效的相似性搜索：

```
const aiResponse = "AI-generated text from Claude"; // The product description generated by Claude AI
const requestParams = {   modelId: "amazon.titan-embed-text-v2:0",    // AI model used to process the text    body: {{aiResponse }}    // Formatting Claude's response for Amazon Titan};
```

## **上下文增强的描述生成**

描述生成过程包含以下步骤：

- 系统检索描述与上传图像高度相似的产品。这些由专家撰写的描述作为上下文参考。
- Anthropic Claude 纳入这些上下文数据——例如风格、材质洞察和历史关联——生成经过增强和优化的产品描述，以提升用户参与度和可发现性。

以下代码是发送给 AI 的最终 RAG 请求示例，其中我们将 `contextDocs` 作为来自现有产品的 prompt 中的产品记录传入：

```
const productAnalysisRequest = `                 Analyze the uploaded product image.Use the provided context below to improve your response:${contextDocs}
Generate a clear and structured response in JSON format:{  "title": "A short product title",  "productDescription": "Describe the product, including details about materials used and unique features."}`;
```

这种结构化的方法确保 AI 生成的产品描述不仅准确且具备上下文感知，还针对搜索可见性进行了优化，从而改善用户体验和转化率。

## **结论**

Handmade.com 通过使用 AI 驱动的组件来自动化产品描述并优化搜索，成功实现了其内容生成工作流的现代化。他们之所以选择 Amazon Bedrock，是因为它可以快速、直接地与其现有架构集成，并为后台使用的模型和嵌入提供了多种选择，且价格合理。该架构整合了来自 Amazon Bedrock 的基础模型、Amazon OpenSearch Service 的语义检索，以及使用 [Amazon API Gateway](https://aws.amazon.com/api-gateway/) 的轻量 API 层，实现无缝编排。这些创新简化了卖家交互，并在庞大且不断增长的目录中实现了稳定的内容质量：

- 模块化编排 – Handmade.com 的设计集成了用于生成的 Anthropic Claude 和用于嵌入的 Amazon Titan，从而实现灵活的丰富化和实时上下文搜索
- 可扩展推理 – Amazon Bedrock 处理并发的多模态 prompt 和 SEO 请求，且无需承担基础设施开销
- 搜索优化 – 基于向量的搜索提升产品可发现性，并减少卖家内容工作流中的摩擦

该系统为未来能力奠定了基础，例如多语言 SEO、基于反馈的 prompt 调整，以及纳入新的内容类型。作为下一步，Handmade.com 计划扩展对 [Amazon Bedrock Agents](https://aws.amazon.com/bedrock/agents/) 的使用，以支持结构化 prompt 工作流，并进一步简化卖家的入驻流程。团队还在探索如何纳入用户参与信号和评论数据，以持续改进生成的内容并提升推荐质量。

准备好用 AI 改造你自己的内容管理工作流了吗？Handmade.com 为实现产品描述现代化所走过的历程，展示了将 Amazon Bedrock 的基础模型与 Amazon OpenSearch Service 的语义搜索能力相结合时的强大可能性。无论你是在管理电商平台、内容仓库还是数字市场，这些工具都能帮助你在自动化、可扩展性和增强用户体验方面取得类似成果。今天就开始探索 Amazon Bedrock 和 Amazon OpenSearch Service，构建你自己的 AI 驱动内容解决方案。访问 AWS 文档以进一步了解如何开始使用这些服务，或联系 AWS 解决方案架构师讨论你的具体需求。
