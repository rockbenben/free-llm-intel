# CLICKFORCE 如何借助 Amazon Bedrock Agents 加速数据驱动的广告业务

[CLICKFORCE](https://www.clickforce.com.tw/index.php) 是台湾数字广告服务领域的领军者之一，专精于数据驱动的广告与转化（D4A – Data for Advertising & Action）。CLICKFORCE 以交付行业领先、顺应趋势且富有创新的营销解决方案为使命，帮助品牌、代理商和媒体伙伴做出更明智的广告决策。

然而，随着广告行业快速演进，传统的分析方法和通用的 AI 输出已不足以提供可执行的洞察。为保持竞争力，CLICKFORCE 转向 AWS 构建了 Lumos——一个由 [Amazon Bedrock](https://aws.amazon.com/bedrock/)、[Amazon SageMaker AI](https://aws.amazon.com/sagemaker/ai/)、[Amazon OpenSearch](https://aws.amazon.com/opensearch-service/) 和 [AWS Glue](https://aws.amazon.com/glue/) 驱动的新一代 AI 营销分析解决方案。

本文演示 CLICKFORCE 如何使用 AWS 服务构建 Lumos，并把广告行业分析从数周的人工工作转变为自动化的一小时流程。

## 数字广告的挑战

在采用 Amazon Bedrock 之前，CLICKFORCE 在为数字广告构建可执行智能时面临若干障碍。大语言模型（LLM）往往产出通用建议，而非可执行、针对行业的智能。由于不理解广告环境，这些模型缺乏使建议贴合真实行业现实所需的行业上下文。

另一个重大挑战是缺乏整合的内部数据集，这削弱了输出的可靠性，并提高了出现幻觉或不准确洞察的风险。与此同时，营销团队依赖彼此割裂的工具和技术（例如 vibe coding），没有标准化的架构或工作流，使这些流程难以维护和扩展。

准备一份全面的行业分析报告同样耗时，通常需要两到六周。这一时间跨度源于多个劳动密集型阶段：一到三天用于界定目标并制定研究计划，一到四周用于从不同来源收集和验证数据，一到两周用于进行统计分析和制作图表，一到两天用于提取战略洞察，最后三到七天用于起草并定稿报告。每个阶段往往都需要跨团队反复协调，这进一步拉长了时间。结果，营销策略常常被延误，并且更多基于直觉而非及时、有数据支撑的洞察。

## 方案概览

为应对这些挑战，CLICKFORCE 使用 AWS 服务构建了 **Lumos**，一项集成式的 AI 驱动行业分析服务。

该方案的设计围绕 [Amazon Bedrock Agents](https://aws.amazon.com/bedrock/agents/) 实现上下文推理、围绕 [Amazon SageMaker AI](https://aws.amazon.com/sagemaker/ai/) 提升 Text-to-SQL 准确率。CLICKFORCE 之所以选择 Amazon Bedrock，是因为它提供了对基础模型的托管访问，无需自行构建或维护基础设施，同时提供能够编排多步骤任务并通过 Knowledge Bases 与企业数据源集成的 agent。这使团队能够把洞察建立在真实、可验证的数据之上，最小化幻觉，并快速试验不同的模型，同时还降低了运维开销并加快了上市速度。

![Lumos 架构](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/01/22/Lumos-Architecture.png)

第一步是使用 Amazon Bedrock 构建一个统一的 AI agent。最终用户与一个运行在 [Amazon ECS](https://aws.amazon.com/ecs/) 上的聊天机器人界面交互，该界面用 [Streamlit](https://streamlit.io/) 开发，并由 Application Load Balancer 前置。当用户提交查询时，查询会被路由到一个 [AWS Lambda](https://aws.amazon.com/lambda/) 函数，由它调用 [Amazon Bedrock Agent](https://aws.amazon.com/bedrock/agents/)。该 agent 从 [Amazon Bedrock Knowledge Bases](https://aws.amazon.com/bedrock/knowledge-bases/) 中检索相关信息，而该 Knowledge Base 由托管在 Amazon S3 中的源文档（例如广告活动报告、产品描述和行业分析文件）构建而成。这些文档会被自动转换为向量 embedding 并在 Amazon OpenSearch Service 中建立索引。通过把模型响应建立在这一精选文档集之上，CLICKFORCE 确保输出具备上下文、减少幻觉，并与真实世界的广告数据保持一致。

接下来，CLICKFORCE 通过使用 Text-to-SQL 请求，让工作流更具行动导向。当查询需要检索数据时，Bedrock Agent 通过 Agent Actions API Schema 生成 JSON schema。这些 schema 被传递给 Lambda Executor 函数，由它们把请求转换为 Text-to-SQL 查询。借助 AWS Glue crawler 持续从 Amazon S3 中的 CSV 文件更新 SQL 数据库，分析师能够对广告活动效果、受众行为和竞争基准运行精确查询。

最后，公司通过把 Amazon SageMaker 和 [MLflow](https://mlflow.org/) 纳入开发工作流来提升准确率。起初，CLICKFORCE 依赖基础模型进行 Text-to-SQL 转换，但发现它们不够灵活且常常不准确。通过使用 SageMaker，团队处理数据、评估不同方法，并调优整个 Text-to-SQL pipeline。验证完成后，优化后的 pipeline 通过 AWS Lambda 函数部署，并集成回该 agent，确保改进直接流入 Lumos 应用。由 MLflow 提供实验跟踪和评估，数据处理、pipeline 调优和部署的循环变得精简顺畅，使 Lumos 在查询生成上达到更高精度，并交付自动化、数据驱动的营销报告。

## 结果

对 CLICKFORCE 而言，采用 Amazon Bedrock Agents 和 SageMaker AI 带来的影响是变革性的。过去需要两到六周的行业分析，现在可以在一小时内完成，大幅加快了决策速度。公司还减少了对第三方行业研究报告的依赖，从而使运营成本降低了 47%。

除了节省时间和成本，Lumos 系统还把可扩展性延伸到营销环境中的各类角色。品牌主、代理商、分析师、营销人员和媒体伙伴现在都能独立生成洞察，无需等待集中的分析师团队。这种自主性使各项广告活动更具敏捷性。此外，通过把输出建立在内部数据集和行业专属上下文之上，Lumos 显著降低了幻觉风险，并确保洞察与行业现实更紧密地契合。

## 结论

CLICKFORCE 的 Lumos 系统代表了数字营销决策方式上的一次突破。通过结合 Amazon Bedrock Agents、Amazon SageMaker AI、Amazon OpenSearch Service 和 AWS Glue，CLICKFORCE 把其行业分析工作流从缓慢的人工流程转变为快速、自动化且可靠的系统。本文演示了 CLICKFORCE 如何使用这些 AWS 服务构建 Lumos，并把广告行业分析从数周的人工工作转变为自动化的一小时流程。
