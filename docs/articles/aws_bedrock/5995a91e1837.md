# 用 Amazon SageMaker JumpStart 部署并评估模型

为某个具体应用选对模型，需要一种务实的办法，用有代表性的输入去测试它。Amazon SageMaker JumpStart 提供了一个庞大目录的访问能力，其中的模型都已完成预训练。在本文里，我们演示如何部署一个 SageMaker JumpStart 中可用的模型，如何用 SageMaker Python SDK 跑一次轻量且可重复的性能测试，以及测试结束后如何删除 endpoint。就受支持的模型与可用容量而言，这个工作流提供了一条可重复的评估路径，尽管部署耗时会随模型、实例类型、配额和 AWS Region 而变化。

2026 年，SageMaker JumpStart 引入了两项简化模型发现与部署的改进。在 Amazon SageMaker AI 控制台的 Model Hub 区块，你可以浏览 SageMaker JumpStart 目录、查看示例 notebook，并直接在 SageMaker Studio 中打开它们。预先配置好的 endpoint 部署选项提供了一批具名配置，针对低成本、低延迟或通用工作负载这类优先级做过优化，覆盖多种生成式 AI 模型，其中也包括 Neuron 优化配置。此外，借助新的 deep link 集成，你现在可以一键从 Hugging Face 的模型发现走到 SageMaker AI 的部署。

## 方案概览

我们的做法使用一个可复用的 Python 脚本，它执行三个步骤：

- 从 SageMaker JumpStart 发现并部署一个模型。
- 运行模型专属的示例 prompt，并测量延迟、近似输出长度与单请求生成速率。
- 清理 endpoint。

这个模式适用于许多兼容的 SageMaker JumpStart 模型，不过 payload 格式、所需实例类型、最终用户许可协议（EULA）要求以及响应 schema 可能需要按具体模型做调整。

## 前置条件

- 一个具备 SageMaker AI 权限的 AWS 账户。
- Python 3+，并且安装了 SageMaker Python SDK v3（`pip install "sagemaker>=3,<4"`）。
- 为你想要测试的模型预留足够的 GPU 实例配额，或者[申请提高配额](https://docs.aws.amazon.com/sagemaker/latest/dg/studio-updated-launch.html#studio-updated-launch-quotas)。

使用 SageMaker Python SDK 的代码路径：

```
from sagemaker.core.jumpstart.notebook_utils import (
    list_jumpstart_models,
)

REGION = "us-east-1"

models = list_jumpstart_models(
    filter="task == textgeneration",
    region=REGION,
    list_versions=True,
)

print(f"Found {len(models)} text generation models")

for model_id, model_version in models[:10]:
    print(
        f" - {model_id} "
        f"(version {model_version})"
    )
```

或者按模型名称搜索：

## 步骤 1.b：部署模型

从 SageMaker JumpStart 部署模型的 UI 路径：

![Qwen3.8 27B 的 JumpStart 模型详情页，高亮显示 Deploy 按钮并列出模型能力](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/10/12/ML-22153-2.png)

图 2：在 SageMaker Studio 中从模型的 SageMaker JumpStart 详情页部署模型

使用 SageMaker Python SDK 的代码路径：

```
import time

from sagemaker.core.jumpstart.accessors import JumpStartModelsAccessor
from sagemaker.core.jumpstart.configs import JumpStartConfig
from sagemaker.core.training.configs import Compute
from sagemaker.serve import ModelBuilder

MODEL_ID = "huggingface-vlm-qwen3-5-27b"
MODEL_VERSION = "1.13.0"
REGION = "us-east-1"
ACCEPT_EULA = False  # Set True only after reviewing the model terms

def get_field(value, name, default=None):
    if isinstance(value, dict):
        return value.get(name, default)
    return getattr(value, name, default)

# Resolve the JumpStart-recommended deployment configuration.
specs = JumpStartModelsAccessor().get_model_specs(
    region=REGION,
    model_id=MODEL_ID,
    version=MODEL_VERSION,
)

if isinstance(specs, list):
    if not specs:
        raise ValueError(
            f"No JumpStart specification found for {MODEL_ID}"
        )
    specs = specs[0]

recommended_instance_type = get_field(
    specs,
    "default_inference_instance_type",
)

if not recommended_instance_type:
    raise ValueError(
        f"No recommended instance type found for {MODEL_ID}"
    )

print(f"Model: {MODEL_ID}")
print(f"Region: {REGION}")
print(f"Recommended instance: {recommended_instance_type}")

start = time.time()

jumpstart_config = JumpStartConfig(
    model_id=MODEL_ID,
    model_version=MODEL_VERSION,
    accept_eula=ACCEPT_EULA,
)

model_builder = ModelBuilder.from_jumpstart_config(
    jumpstart_config=jumpstart_config,
    compute=Compute(
        instance_type=recommended_instance_type,
        instance_count=1,
    ),
)

model = model_builder.build()
endpoint = model_builder.deploy()
deploy_time = time.time() - start

print(f"Deployed in {deploy_time:.1f} seconds")
print(f"Endpoint: {endpoint.endpoint_name}")
```

## 步骤 2：运行示例 prompt 并测量性能

```
from sagemaker.core.payloads import retrieve_all_examples
import json
import time

MODEL_ID = "huggingface-vlm-qwen3-5-27b"
MODEL_VERSION = "1.13.0"
REGION = "us-east-1"

example_payloads = retrieve_all_examples(
    region=REGION,
    model_id=MODEL_ID,
    model_version=MODEL_VERSION,
    serialize=True,
)

#you can re-create the endpoint pointer using the endpoint name:
#from sagemaker.core.resources import Endpoint
#endpoint = Endpoint.get(endpoint_name="<your_endpoint_name>",region=REGION)

def read_response_body(result):
    body = result.body
    if hasattr(body, "read"):
        body = body.read()
    if isinstance(body, bytes):
        body = body.decode("utf-8")
    if isinstance(body, str):
        try:
            return json.loads(body)
        except json.JSONDecodeError:
            return body
    return body

def extract_output(response):
    """Handle common JumpStart text-generation response formats."""
    if isinstance(response, list):
        response = response[0] if response else ""
    if isinstance(response, dict):
        choices = response.get("choices")
        if choices:
            choice = choices[0]
            message = choice.get("message")
            if isinstance(message, dict):
                return message.get("content", "")
            return choice.get("text", "")
        for field in (
            "generated_text",
            "output_text",
            "text",
        ):
            if field in response:
                return response[field]
    return response

results = []

for payload in example_payloads or []:
    start = time.perf_counter()
    result = endpoint.invoke(
        body=payload.body,
        content_type=payload.content_type,
        accept=payload.accept,
    )
    latency = time.perf_counter() - start
    response = read_response_body(result)
    output = extract_output(response)
    if not isinstance(output, str):
        output = json.dumps(output, indent=2)
    # This is an estimate based on whitespace-separated words.
    output_words = len(output.split())
    results.append(
        {
            "request_preview": payload.body[:50],
            "latency_s": round(latency, 2),
            "estimated_output_words": output_words,
            "words_per_second": round(
                output_words / latency,
                1,
            ) if latency > 0 else 0,
        }
    )
    print("Input:\n", payload.body, end="\n\n")
    print("Output:\n", output, end="\n\n")
    print(
        f"Latency: {latency:.2f} seconds\n"
        f"Estimated output words: {output_words}\n"
        f"Estimated single-request output generation rate: "
        f"{output_words / latency:.1f} words/second\n"
    )
    print("-" * 80)

print("\nSummary:")
for result in results:
    print(result)
```

## 结论

这个模式适用于许多可用的 SageMaker JumpStart 模型，但 payload 格式、所需实例类型、EULA 以及响应解析可能需要按具体模型做调整。通过使用一致的测试 prompt，并在各模型之间测量延迟、吞吐量与输出质量，你可以比较各个选项，为你的工作负载选出合适的方案。

拿 Amazon SageMaker JumpStart 里的不同模型试试这个方法，为你的应用找到质量、速度与成本之间的合适平衡。
