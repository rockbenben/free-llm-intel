# AWS Quick 新功能：更强大的 flow、焕新的网页体验，以及能协同工作的 agent

把一个人的流程变成整个团队的流程，在 Quick 网页应用里完成更多工作，并让协同工作的 agent 给出更完整的答案。

AWS Quick 是专为工作打造的 AI 工作空间。今天我们发布一系列更新，帮助你的团队把日常工作中的更多事情做完：

- **通过对话构建、查看并改进业务流程。** 在聊天中描述一个流程，Quick 就会构建一条 flow，用来编排 agent、skills 和工具，并让它们访问结构化数据、知识和应用。新增的确定性步骤让这些 flow 保持一致、可验证，如今还能运行更久，并支持更大的数据量。
- **在 Quick 网页应用中梳理每天的工作，并让 agent 持续运转。** 更新后的网页应用把需要你关注的事项和每日简报放到首页，把你在桌面端使用的 agent 和 skills 也带了进来，并且在你关闭标签页后仍让工作继续运行。
- **一条 prompt 就能完成跨多个 agent 的工作。** 借助多 agent 编排，多个专业 agent 同时处理你的请求，Quick 再把它们的发现汇总成一个回答。
- **把更多数据接入 Quick。** 连接 Meta 广告和 Amplitude，然后用自然语言提问，并把答案与你的其他数据源结合起来。
- **网页端 skill、安全与治理改进，以及更多语言：** 把你做某项任务的方式变成 Quick 可复用的 skill，现在在 Quick 网页应用里也能这么做。可为用户的 prompt 设置可配置的内容安全和敏感信息管控。新增日语、德语、中文（简体和繁体）和越南语支持。

AI 助手能让个人变得更快，但这份收益往往只留在一个人身上：某位分析师搭出月度报告的方式，很少会变成整个团队沿用的做法；而且只要没人在工位上，工作就只能等着。本次发布帮助你的团队把一个人掌握的东西沉淀为所有人都能依赖的流程，并在你离开时让工作继续推进。

## 把一个人的流程变成整个团队的流程

AWS Quick Flows 已经在帮助团队自动化和标准化业务流程，让人们能专注于最重要的工作。现在，你完全可以在聊天中构建、运行和改进 flow。而且无论从网页、桌面端还是移动应用发起，你的 flow 都能承担更多棘手的工作。

例如，flow 可以这样帮到一个财务团队。Maya 是一家零售企业的财务规划与分析经理。每个月，她都要为财务副总裁准备一份报告，说明成本和利润率的变化。她会按区域调取上个月的结果，与电子表格中的计划做对比，就变化最大的部分撰写评述，然后发送报告。这套流程存在于她的记忆和一份个人清单里。她不在时，同事只能从头重建报告，而且每次的样子都不一样。

借助 Quick，Maya 可以把这套流程标准化、自动化，并开放给团队使用。她在聊天中描述自己的流程，就像向新员工解释一样。Quick 根据她的描述构建 flow，她在同一个对话里测试和改进。聊天旁边的图示会显示每一步，方便她确认 flow 与自己实际的工作方式一致。

图 1：Maya 在聊天中描述她的月度报告，Quick 在旁边构建出 flow，并配上图示。两个视图（此处已放大以便看清）在同一个 Quick 窗口中并排显示

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/11/20/Screenshot-2026-11-20-at-4.58.51%E2%80%AFPM.png)

现在，一条 flow 可以汇聚 agent、skills、工具和数据，并用更多数据支撑更长的流程。固定的计算和校验确保结果一致，agent 负责起草和分析，Maya 决定最终报告里写什么。每次运行时，她的 flow 都会：

- 从 Quick 中团队的月度结果仪表板调取上个月的结果，这样她就从团队已经汇报的数字开始。
- 同时处理多个区域，让报告更快就绪，即使公司不断增加新区域。
- 用设定的公式把每个区域与团队预算电子表格中的年度计划做对比，确保每个月的数字都按同样的方式计算。
- 根据 Maya 设定的阈值，标记出偏离计划较大的区域，并用团队的评述 skill 为每个区域起草说明。
- 起草一份 Microsoft Excel 摘要，发到团队的共享 Space 和报告邮件，供 Maya 审核，并在 Slack 上通知团队草稿已就绪。

Maya 把这条 flow 发布给团队。到了下个月月末，她正在参加一场规划会，于是她团队里的分析师 Jordan 在 Quick 桌面应用的聊天中运行了它。在那里，flow 可以使用他电脑上保存的区域调整电子表格。报告发出前，Jordan 会审阅草稿，包括每个区域被标记的原因，在聊天中提出几处修改，然后批准发给财务副总裁。Priya 加入团队后，在第一个月末运行了同一条 flow，报告也以同样的方式生成。

这虽然是虚构的例子，但真实客户告诉我们，他们正在把复杂的业务流程自动化，让它更一致、更可重复。这让员工重新拿回宝贵的时间，可以专注于更具战略性的工作。以 Pomelo 为例，这是一家拉丁美洲的金融科技提供商，为客户提供发卡、处理和支付运营：

> “在 Pomelo，AWS Quick 改变了谁有资格构建解决方案。以前，每一项分析或自动化都依赖数据团队。如今，各个领域的人都能在一个统一、受治理的环境中探索信息、做出决策，并构建自己的 agent 和 flow。团队规模没有扩大，每月与数据打交道的人数却接近原来的四倍，我们的数据团队因此可以专注于最复杂、影响最大的工作。仅一个用例每月就为我们节省 80 小时的工作量。但真正的变革不在于省下的时间。Quick 正在改变我们的数据与创新文化：我们从少数人为多数人构建解决方案，转变为人人都能创造、试验并改变工作方式的组织。而这仅仅是开始。”

— Rodrigo Marini，数据负责人，Pomelo Fintech Services S.A.S.

## 在更新后的 Quick 网页应用中完成更多工作

如果你已经在浏览器里用 Quick，更新后的网页应用会在你登录后立刻把需要关注的事项放到首页。重新组织的左侧导航把 agent、flow、skills、知识和 connector 收进 Customize 之下，其中包括你在桌面端构建的 agent 和 skills，以及别人分享给你的那些。你现有的仪表板、主题和空间照常使用，不需要打开任何开关。

- **看到需要你处理的事项，然后动手处理。** 你的 feed 和新的每日简报会按优先级，把需要你处理的邮件和消息汇总到一起。就任何事项向 Quick 提问，或让它起草回复供你审阅后发送。
- **你离开时，agent 继续工作。** 安排一项任务，或在开会前发起一个耗时较长的请求，Quick 会在你关闭浏览器后继续运行。回来时查看结果，并在 Mission Control 中回复正在等你的 agent。
- **在一处找到你的工作。** Library 汇集你最近的工作、收藏、置顶项，以及你在 Quick 中创建的文档和文件。对话、agent 和文件会在网页、桌面端和移动端之间同步，因此你可以从浏览器开始，在手机或桌面应用里接着做——在桌面端，Quick 还能处理你电脑上的文件。

## 从协同工作的 agent 那里获得更完整的答案

有些请求需要不止一个专业 agent 的知识。借助多 agent 编排，你询问的 agent 可以同时引入多个专业 agent，各自处理自己最擅长的部分，再由它把各方的成果合成一个回答。每个 agent 都保有自己的指令、知识和 context，因此最了解这项工作的人可以自行构建和维护它。

例如，你可能想问某个区域的运费为什么涨了。你的 agent 可以引入一个基于团队规划数据构建的预测 agent，以及一个基于采购团队供应商合同构建的采购 agent。你会得到一个回答，其中显示每个 agent 各自贡献了什么，再自己决定怎么用。

## 把 Quick 接入团队已经在用的更多工具

工作分散在许多系统里。本次发布新增了 connector，让 Quick 能够取用你团队每天使用的分析数据和工具。连接一次，之后用自然语言提问即可。

**Meta 广告。** 通过连接到 Meta 广告的 Model Context Protocol（MCP）服务器的 connector，用自然语言创建、管理并分析 Meta 广告活动。Quick 会把 Meta 广告数据与你的一方和第三方来源结合起来，并在创建广告活动、调整预算或在广告账户中执行任何其他写入操作前征求你的许可。[免费试用 Quick 3 个月](https://quick.aws.com/sn?offer_type=meta-ads-quick-promo)，并可免费邀请最多 10 位同事。

**Amplitude。** 用自然语言询问产品使用情况、客户行为和转化情况。Quick 通过 Amplitude 的 MCP 服务器连接 Amplitude，产品和市场团队因此可以把行为洞察引入他们在 Quick 中构建的仪表板、文档和 flow。

connector 会遵循你现有的权限设置。Quick 只会展示每个人原本就有权访问的内容。在执行任何写入操作之前，Quick 都会先征求你的同意。管理员可以决定团队能够添加哪些 connector。

## 本次发布的其他内容

- **Quick 网页应用中的 skill。** skill 是可复用的指令，教 Quick 按你的方式完成某项任务，比如按团队清单审核合同，或按公司格式撰写项目更新。现在你可以在网页应用里浏览、安装、创建和管理 skill，与桌面端一致。
- **prompt 护栏（预览）。** 管理员可以设置策略，过滤内容、拦截被禁止的主题和词语、检测 prompt 攻击，并保护人们发送给 Quick 的 prompt 中特定类型的个人信息。策略可以先在仅检测模式下试运行，再正式执行，并可应用到单个用户、身份提供商用户组或整个账户。此功能面向所有订阅 Professional 和 Enterprise 套餐的 AWS Quick 客户提供。
- **按组设置权限和限额。** 管理员现在除了可以针对单个用户、角色和整个账户设置之外，还可以为来自身份提供商的用户组分配自定义权限和限制配置（limit profiles）。例如，你可以禁止财务组创建 agent，或设定组内每位成员可用的 agent 时长（agent hours），而无需逐人管理。此功能面向所有订阅 Professional 和 Enterprise 套餐的 AWS Quick 客户提供。
- **选择人们可以添加哪些数据源。** 管理员现在可以控制人们可以创建、更新或分享哪些类型的数据源。例如，你可以允许人们连接 Amazon Redshift 而禁止文件上传，或禁止人们分享来自某个特定 connector 的数据源。此功能面向所有订阅 Professional 和 Enterprise 套餐的 AWS Quick 客户提供。
- **更多语言。** Quick 支持日语、德语、中文（简体和繁体）和越南语。
