# 用 Amazon Nova 探索 Real-Time Race Track

*本文由 Wildlife 总裁兼联合创始人 Jake Friedman 共同撰写。*

[Amazon Nova](https://aws.amazon.com/ai/generative-ai/nova/) 正通过一种受一级方程式（F1）启发的沉浸式体验提升体育粉丝的参与度，把传统的旁观者转变为主动参与者。本文探讨 Real-Time Race Track（RTRT）——一个使用 [Amazon Bedrock](https://aws.amazon.com/bedrock/) 中的 Amazon Nova 构建的交互式体验，让粉丝设计、定制并分享自己的赛道。我们重点展示生成式 AI 的各项能力如何协同，交付进站时机与轮胎选择等策略性赛车洞察，以及 AI 语音助手、复古风格赛车海报等交互特性。

## 粉丝期待的变化与实时多模态参与的技术门槛

如今的体育观众期待的已不只是被动观看——他们想要参与、定制和分享。随着粉丝期待演变，交付有吸引力、可交互的体验已成为让受众持续投入的关键。静态数字内容不再能抓住注意力；粉丝被那些让他们能够影响或共同创造赛事某些方面的沉浸式形式所吸引。对品牌与版权方而言，这一转变既是机会也是挑战：如何大规模交付动态、有意义的参与。交付这种程度的交互性伴随一系列独特的技术挑战。它需要支持多种模态——文本、语音、图像与数据——实时协同工作，以创造无缝、沉浸的体验。由于面向粉丝的体验常常免费提供，成本效率对于在规模化下持续维持参与至关重要。而用户期待即时响应，因此在各类交互中保持低延迟性能对于避免破坏体验至关重要。

## 用 Amazon Nova 打造 RTRT 的沉浸式粉丝参与

为营造引人投入的沉浸式体验，我们开发了 Real-Time Race Track，让 F1 粉丝使用 Amazon Nova 设计自己的定制赛道。你可以绘制不同长度与形状的赛道，同时获得实时 AI 建议来调整你的比赛条件。你可以为赛道选择世界上任何地点，Amazon Nova Pro 会用该地区的天气与气候数据生成赛道名称，并模拟真实的赛道条件。赛道绘制完成后，Amazon Nova Pro 会分析赛道，产出最高速度与预计单圈时间等指标，并提供两套聚焦轮胎管理的可行比赛策略。你还可以咨询语音到语音模型 [Amazon Nova Sonic](https://aws.amazon.com/ai/generative-ai/nova/speech/)，获取赛道设计的策略性建议。整个体验的高潮是 [Amazon Nova Canvas](https://aws.amazon.com/ai/generative-ai/nova/creative/) 为你的定制赛道设计生成一张复古风格的赛车海报，你可以分享或下载。以下截图展示了 RTRT 界面的一些示例。

Amazon Nova 模型具备成本效益，在其各自级别中提供最优的性价比之一，帮助企业打造可扩展的粉丝体验，同时有效管理成本。凭借快速的语音处理与高效率，Amazon Nova 提供无缝的实时多模态交互，满足互动式粉丝参与的需求。此外，Amazon Nova 内置控制措施，以保障 AI 的安全与负责任使用。综合全面的能力、成本效益、低延迟与值得信赖的可靠性，Amazon Nova 是需要实时、动态参与的应用的理想选择。

## RTRT 体验背后的 prompt、输入与系统设计

RTRT 利用 Amazon Nova Pro 的多模态能力，有效地引导用户从一条线条路径的绘制，走到完全可行的赛道设计，包括策略性赛车建议，以及以复古赛车海报风格对赛道所做的醒目视觉呈现。

下图概述了系统架构。

![赛道设计、赛道位置、比赛策略与赛道图像生成的工作流](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/09/02/RTRT-3.png)

prompt 工程在交付可无缝流入 UI 的结构化输出方面起着关键作用；该 UI 经过优化，便于一眼抓住要点，借助 Amazon Nova Pro 快速分析多种数据输入，加速用户的决策。在 RTRT 中，这一点也延伸到提供给 Amazon Nova Pro 用于视觉分析的输入图像。每当用户为赛道添加新的路段，路径的一个版本会连同可见的坐标标记一起传给 Amazon Nova Pro，从而产出准确的路径分析（见下图）及相应的输出数据，再以按颜色区分的赛道扇区可视化地反馈给用户。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/09/02/RTRT-4.png)

这与多个 system prompt 配合使用，用于定义 Amazon Nova Pro 在应用各阶段的角色，并返回可直接供前端消费的响应。

以下是一个 prompt 示例：

```
The system is designed to analyze the input image of a completed racetrack path outline.
You must always return valid JSON.
```

这些 prompt 还使用成组的示例，以在多样化的可能赛道设计与位置之间产出稳定的结果：

```
Using the input data craft a track title for a fictional Formula 1 track. 
    Use the names of existing tracks from <example/> as a framework of how to format the
      title.
  The title must not infringe on any existing track names or copyrighted material.
    The title should take into account the location of the track when choosing what
      language certain components of the track title are in.
```

这也是落实 AI 负责任使用的关键阶段：指示模型不要生成可能侵犯现有赛道或其他版权材料的内容。

在使用 Amazon Nova Canvas 这类创意模型时，这些考量至关重要。赛车涂装通常包含十几个甚至更多赞助商标志。为避免引发顾虑，并提供最干净、最具美感的复古赛车海报设计，我们向 Amazon Nova Canvas 提供了一系列条件图像，以提升车辆的准确性与一致性。这些图像与我们关于醒目插画风格、带电影感视角的 prompt 协同工作。

以下是一个 prompt 示例：

```
Use a bold vector-style illustration approach with flat color fills, bold outlines,
    stylized gradients. Maintain a vintage racing poster aesthetic with minimal texture.
    Position the viewer to emphasize motion and speed.
```

## 结论

Real-Time Race Track 展示了生成式 AI 如何交付能与现代体育受众产生共鸣的个性化、交互式时刻。Amazon Nova 模型驱动着体验的每一层，从语音与图像生成到策略与分析，规模化地交付丰富、低延迟的交互。这次合作凸显了品牌如何使用 Amazon Nova 打造贴合需求且引人投入的体验。
