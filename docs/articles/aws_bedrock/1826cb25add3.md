# Amazon Nova Canvas 与 Amazon Nova Reel 的图像及视频 prompt 工程

Amazon 在 [Amazon Bedrock](https://aws.amazon.com/bedrock/) 上推出了两款新的创意内容生成模型：[用于图像生成的 Amazon Nova Canvas 和用于视频创作的 Amazon Nova Reel](https://aws.amazon.com/ai/generative-ai/nova/creative/)。这些模型把文本和图像输入转化为定制视觉内容，为专业项目和个人项目都开启了创作机会。Nova Canvas 是一流的图像生成模型，能从文本和图像输入生成专业级图像，非常适合广告、营销和娱乐应用。同样，Nova Reel 是先进的视频生成模型，支持从文本和图像输入创作短视频，并可用自然语言控制镜头运动。尽管这些模型是创意表达的强大工具，其效果在很大程度上取决于用户能否通过 prompt 清楚传达自己的构想。

本文深入探讨 Nova Canvas 和 Nova Reel 的 prompt 工程。我们分享经过验证的技巧，教你如何以模型能理解的方式描述主体、环境、光线和艺术风格。对于 Nova Reel，我们探讨如何用自然语言有效传达镜头运动和转场。无论你是在创作营销内容、做设计原型，还是探索创意想法，这些 prompt 策略都能帮助你释放 [Amazon Nova](https://aws.amazon.com/ai/generative-ai/nova/?gclid=Cj0KCQiAqL28BhCrARIsACYJvkcg3P4LrEY-S5uN51-PVVt1iBkZ_C4MMaYeBQbq3HFj_sA2VGlNn6saAl8yEALw_wcB&trk=0eaabb80-ee46-4e73-94ae-368ffb759b62&sc_channel=ps&ef_id=Cj0KCQiAqL28BhCrARIsACYJvkcg3P4LrEY-S5uN51-PVVt1iBkZ_C4MMaYeBQbq3HFj_sA2VGlNn6saAl8yEALw_wcB:G:s&s_kwcid=AL!4422!3!692006004685!e!!g!!amazon%20nova!21048268554!159639952775) 视觉生成能力的全部潜力。

## 方案概览

要开始使用 Nova Canvas 和 Nova Reel，你可以在 Amazon Bedrock 控制台上使用 Image/Video Playground，也可以通过 API 访问这些模型。有关详细设置说明，包括账户要求、模型访问和所需权限，请参阅 [Creative content generation with Amazon Nova](https://docs.aws.amazon.com/nova/latest/userguide/content-generation.html)。

## 用 Nova Canvas 生成图像

为 Amazon Nova Canvas 这类图像生成模型写 prompt，既是一门艺术也是一门科学。与[大型语言模型](https://aws.amazon.com/what-is/large-language-model/) (LLMs) 不同，Nova Canvas 不会显式推理或解读命令式指令。相反，它会根据 prompt 对目标图像本质的捕捉程度，把 prompt 转化为图像。写出有效的 prompt 是在各种用例中释放模型全部潜力的关键。本文探讨如何打造有效 prompt，剖析优秀 prompt 的关键要素，并深入典型用例，每个用例都配有精彩的示例 prompt。

### 优秀 prompt 的关键要素

一个好的 prompt 相当于一段描述性的图片说明，而不是命令式指令。它应提供足够的细节来清晰描述期望的结果，同时保持简洁（限 1,024 个字符）。与其给出"创作一片美丽的日落"这样的命令式指令，不如像亲眼所见那样描述场景，效果会更好："群山之上绚烂的日落，金色光芒穿透粉色云层，以低角度拍摄。"把它想象成用文字描绘一幅生动的画面，以此有效引导模型。

有效的 prompt 首先要清楚定义主体和动作：

- **主体** – 清楚定义图像的主体。示例："一辆蓝色跑车停在一座宏伟别墅前。"
- **动作或姿态 **– 说明主体在做什么或如何摆放。示例："车身略微朝向镜头倾斜，车门敞开，展现出流畅的内饰。"

补充更多背景：

- **环境 **– 描述场景或背景。示例："一座俯瞰科莫湖的宏伟别墅，四周是修剪整齐的花园和波光粼粼的湖水。"

确定图像的主要焦点后，你可以通过指定视觉风格、取景、光线和技术参数等额外属性，进一步细化 prompt。例如：

- **光线** – 加入光线细节以营造氛围。示例："多云天空下的柔和漫射光，凸显车身光亮表面和别墅的石材外墙。"
- **镜头位置与取景** – 提供视角和构图信息。示例："广角镜头，前景是汽车，背景是别墅的宏伟身姿，远处可见科莫湖。"
- **风格** – 提及视觉风格或媒介。示例："以电影风格呈现，细节鲜明、高对比度。"

最后，你可以用 negative prompt 从构图中排除特定元素或瑕疵，使其更贴近你的构想：

- **Negative prompt** – 使用 `negativeText` 参数排除主 prompt 中不想要的元素。例如，要从图像中去掉鸟或人，不要在 prompt 里加"no birds or people"，而应在 negative prompt 里加"birds, people"。避免在 prompt 和 negative prompt 中使用"no"、"not"或"without"这类否定词，因为它们可能导致意外结果。

## 用 Nova Reel 生成视频

视频生成模型最适合使用描述性 prompt，而不是命令式指令。编写 prompt 时，专注于你想看到什么，而不是告诉模型该做什么。把它想象成写一段详细的说明或场景描述，就像你在讲解一段已经存在的视频。例如，描述主体、它们在做什么、周围环境、场景如何打光、整体艺术风格以及任何镜头运动，都有助于生成更准确的结果。关键在于通过描述描绘出一幅完整的画面，而不是给出分步指令。这意味着与其说"创作一个戏剧性场景"，不如描述"日落时分的暴风雨海滩，浪涛拍岸、乌云密布，用缓慢的航拍镜头掠过海岸线拍摄"。你对想要的视觉元素描述得越具体、越细致，输出效果就越好。你不妨把主体、动作、环境、光线、风格和镜头运动等细节都包含进去。

为 Nova Reel 编写视频生成 prompt 时，请注意以下要求和最佳实践：

- prompt 不得超过 512 个字符。
- 为获得最佳效果，把镜头运动描述放在 prompt 的开头或结尾。
- 说明你想要包含什么，而不是排除什么。例如，不要写"fruit basket with no bananas"，而是写"fruit basket with apples, oranges, and pears"。

在视频 prompt 中描述镜头运动时，要明确说明想要的运动类型——是平滑的 dolly 推轨镜头（向前/向后移动）、pan 摇摄（左右扫过），还是 tilt 俯仰（上下移动）。想要更有动感的效果，可以要求航拍镜头、orbit 环绕运动，或 dolly zoom 这类专门技巧。你还可以指定运动速度；更多思路请参阅 [camera controls](https://docs.aws.amazon.com/nova/latest/userguide/prompting-video-camera-control.html)。

## 用 Nova Reel 生成基于图像的视频

除基础的 text-to-video 之外，Amazon Nova Reel 还支持 image-to-video 功能，允许你用输入的参考图像来引导视频生成。使用基于图像的 prompt 生成视频有显著优势：加快创意迭代过程，并能精确控制最终输出。你不必只依赖文字描述，而是可以直接在视觉上定义视频的起始画面。这些图像可以来自 Nova Canvas，也可以来自你拥有合法使用权的其他来源。这种方法有两种主要策略：

- **简单镜头运动 **– 先以参考图像确定视觉元素和风格，再添加极简的 prompt，只关注镜头运动，例如"dolly forward"。这种方法让场景基本保持静态，通过镜头调度营造动态感。
- **动态变换 **– 这一策略需要描述场景中的具体动作和时间变化。详细说明各种元素如何随时间演变，把描述设定为对目标变换的概括，而不是逐步指令。这样能实现更复杂的场景演进，同时保持参考图像确立的视觉基础。

这种方法以你的图像作为视觉基础，简化创作流程。你不必花时间打磨文字 prompt 来获得理想外观，而可以在 Nova Canvas 中快速生成一张图像（或从别处获取），把它作为 Nova Reel 的起点。相比纯 text-to-video 生成，这种方式迭代更快，结果也更可预测。

### 把它们整合起来

你可以把多个生成的视频片段组合成引人入胜的叙事，从而改变讲故事的方式。虽然视频生成由 Nova Reel 完成，但你也可以用自己喜欢的视频编辑软件进一步增强内容，加入精心设计的转场、背景音乐和旁白。这种组合营造出沉浸式的体验，把观众带入动人的故事。下面的例子展示了 Nova Reel 创作吸引人的视觉叙事的能力。每个片段都采用专业打光和电影级质感。

## 最佳实践

请参考以下最佳实践：

- **迭代优化** – 从简单开始，根据输出不断打磨 prompt。
- **具体明确** – 提供详细描述以获得更好结果。
- **丰富形容词** – 避免滥用"beautiful"或"amazing"这类笼统描述，改用"serene"或"ornate"等具体词语。
- **用 AI 优化 prompt** – 使用 Amazon Nova（Pro、Lite 或 Micro）等多模态理解模型，帮助你把高层次想法转化为符合最佳实践的精细 prompt。生成式 AI 还能帮你快速生成 prompt 的不同变体，尝试风格、取景等多种组合以及其他创意探索。试试社区工具，例如 [Amazon Nova Canvas Prompt Refiner in PartyRock](https://partyrock.aws/u/r3al1ty/40htNf4iH/Amazon-Nova-Canvas-Prompt-Refiner)、[Amazon Nova Canvas Prompting Assistant](https://github.com/garystafford/amazon-nova-canvas-prompting-assistant) 和 [Nova Reel Prompt Optimizer](https://github.com/xiehust/reel_optimizer)。
- **维护模板化 prompt 库** – 建立有效 prompt 及其结果的目录，随时间推移不断优化和调整。为常见场景创建可复用模板，节省时间并保持一致性。
- **向他人学习** – 探索社区资源和工具，了解有效的 prompt 并加以改造。
- **跟进趋势** – 关注更新或新模型功能，因为 prompt 的行为可能随新能力而变化。

## Amazon Nova 的 prompt 工程基础

针对 Amazon Nova Canvas 和 Nova Reel 的有效 prompt 工程遵循一个迭代过程，旨在优化输入并获得期望的输出。这一过程可以可视化为逻辑流程图，如下图所示。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/01/24/ML-18012-image1.png)

该过程包括以下步骤：

- 首先编写初始 prompt，重点关注主体、动作、环境、光线、风格以及镜头位置或运动等描述性要素。
- 生成首个输出后，评估它是否符合你的构想。如果结果接近预期，进入下一步；否则回到第 1 步，优化 prompt。
- 找到有希望的方向后，保持相同的 seed 值。这样在你做小幅调整时，后续生成能保持一致性。
- 对 prompt 做小而针对性的改动。可以是调整描述词、增删元素等。
- 用优化后的 prompt 生成新输出，保持 seed 值不变。
- 评估新输出。若满意，进入下一步；否则回到第 4 步继续优化。
- 获得满意结果后，尝试不同的 seed 值，为成功的 prompt 创造变体。这样你能探索细微差异，同时保持期望输出的核心要素。
- 从生成的选项中挑选最佳变体作为最终输出。

这种迭代方法让你能系统性地改进 prompt，从 Nova Canvas 和 Nova Reel 模型获得更准确、更具视觉吸引力的结果。记住，成功的关键在于渐进式调整、在需要时保持一致性，以及在找到成功配方后乐于探索各种变体。

## 结论

掌握 Nova Canvas 和 Nova Reel 的有效 prompt 工程，将开启创作惊艳图像与动人视频的激动人心的可能性。遵循本指南列出的最佳实践——从编写描述性 prompt 到迭代优化——你就能把想法转化为可用于生产的视觉素材。
