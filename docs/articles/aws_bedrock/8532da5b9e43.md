# 借助 LLM 与 Amazon Bedrock agent 集成增强诊断流程

[Noodoe](https://www.noodoe.com/) 是电动汽车充电创新领域的全球领导者，提供先进解决方案，帮助运营商优化充电站运营并提供卓越的用户体验。其通用充电站兼容所有电动汽车品牌，并提供直观的支付方式，包括信用卡和 Apple Pay。借助 Noodoe EV OS 云管理系统，公司提供全天候的自动化监控、诊断和维护，实现了 99.83% 的行业领先正常运行时间。Noodoe 的业务遍及 15 个以上国家，并坚定致力于可持续发展，正通过前沿技术和以用户为先的方式改变电动汽车充电行业。

尽管具备技术优势，Noodoe 在帮助充电站运营商优化性能、在多样化市场中选择最具成本效益的电价策略方面，仍遇到关键挑战。传统系统缺乏高效处理海量实时与历史数据的能力，也无法提供个性化、站点级的建议。这限制了运营商及时做出明智决策的能力——导致电费更高、资产利用不足，以及欠佳的客户体验。这些低效不仅降低盈利能力，也妨碍在竞争激烈、快速演变的电动汽车充电格局中扩展。

为解决这一问题，Noodoe 通过 [Amazon Bedrock](https://aws.amazon.com/bedrock/) 和 [Amazon Bedrock Agents](https://aws.amazon.com/bedrock/agents/) 集成大语言模型（LLMs），提供智能自动化、实时数据访问和多语言支持。这些 AI 驱动的工具会分析使用模式、充电站诊断以及天气或电网状况等外部变量，生成高度量身定制的定价建议。借助 Amazon Bedrock 的结构化编排和基于 prompt 的推理，Noodoe 为运营商提供可执行的洞见，帮助他们提升利润率、提高充电站利用率，并能够为用户提供更具竞争力的价格——最终提升客户满意度。该服务通过订阅模式交付，为 Noodoe 创造了新的、可扩展的收入来源，同时巩固其在电动汽车基础设施领域的领导地位与创新形象。

本文探讨 Noodoe 如何利用 AI 和 Amazon Bedrock 优化电动汽车充电运营。通过集成 LLM，Noodoe 增强了充电站诊断、实现了动态定价，并提供多语言支持。这些创新减少了停机时间、最大化了效率并改善了可持续性。继续阅读，了解 AI 如何改变电动汽车充电管理。

为满足功能需求，系统运行流程包含以下步骤：

- 充电数据先由 EV 服务处理，再进入数据库。
- 充电历史数据和定价数据存储在 EV 数据库中。
- [Amazon EventBridge Scheduler](https://docs.aws.amazon.com/scheduler/latest/UserGuide/what-is-scheduler.html) 定期触发 EV 服务执行分析。
- EV 服务调用 AI 服务来分析历史数据并提供定价建议。
- AI 服务收集整理好的历史数据以准备 prompt 模板。
- 这些信息与合适的 prompt 结合后，配合 [Amazon Bedrock Agents](https://aws.amazon.com/bedrock/agents/) 作为 AI 定价 agent 来提取相关信息。AI 定价 agent 分析这些组合数据，以识别每日高峰与非高峰时段，并为用户定价方案提供建议。
- 可选地，如果非英语用户需要翻译，来自 AI 定价 agent 的这些结果会经由另一个 Amazon Bedrock agent 进一步处理以完成翻译。
- 可选地，翻译 agent 使用 Amazon Bedrock 上的 [Anthropic Claude Sonnet 3.5](https://aws.amazon.com/bedrock/anthropic/) 获得对应语言的结果。
- 最后，AI 服务收集用户语言版本的结果进行格式化等处理，然后将其插入模板，生成一份全面的报告并推送到用户端。

下一节我们将深入介绍这些步骤以及所用的 AWS 服务。

## Noodoe AI 增强诊断的架构

Noodoe 在构建全球可扩展、可靠且具成本效益的架构时面临关键挑战。他们需要一个能够支持快速扩张、处理高数据量并在各 AWS 区域保持一致性能的解决方案。满足这些要求需要细致的架构规划，以提供灵活性与韧性。

![Noodoe AI 增强诊断的架构](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/05/20/Noodoe-GenAI-Architecture.drawio-1024x922.png)下图展示了 Noodoe 为克服这些挑战、支持全球增长而构建的解决方案架构。

电动汽车充电优化平台在多个 AWS 服务之间组织数据流，提供高效的数据摄取、处理和 AI 驱动的决策。[Amazon Elastic Kubernetes Service](https://aws.amazon.com/eks/)（Amazon EKS）从 [Amazon DocumentDB](https://aws.amazon.com/documentdb/) 检索数据、进行处理，并调用 Amazon Bedrock Agents 进行推理与分析。这一结构化的数据 pipeline 支持优化定价策略和多语言客户交互。通过使用容器化应用、事件驱动工作流和 AI 能力，系统为电动汽车充电站运营商提供可扩展且灵活的洞见。

### 数据摄取与处理

电动汽车充电站把实时充电数据发送到 [AWS IoT Core](https://aws.amazon.com/iot-core/)，后者作为数据处理的初始入口。数据随后传输到 [Amazon Managed Streaming for Apache Kafka](https://aws.amazon.com/msk/)（Amazon MSK），以实现高吞吐、可靠的流式处理。数据从 Amazon MSK 流入 Amazon EKS，EV 服务在此处理数据，然后把充电历史与趋势记录存入 DocumentDB。这种结构化存储为分析和预测提供了高效的检索能力。

### AI 驱动的定价分析

为优化定价策略，[Amazon EventBridge](https://aws.amazon.com/eventbridge/) 定期触发定价预测函数。该函数从 DocumentDB 检索历史充电数据，并将其连同预定义的 prompt 发送给 Amazon Bedrock 的 AI 定价 agent。这个由 Amazon Bedrock 上的 Anthropic Claude 驱动的 AI agent 会评估充电站使用趋势、高峰与非高峰时段以及定价低效之处，以生成最优定价建议。尽管定价 agent 不访问 Amazon Bedrock 知识库，也不触发 action group，但它使用预处理和后处理功能来改进预测并优化决策。

### 多语言支持与报告生成

如果需要翻译，定价分析结果会转发给 Amazon Bedrock 翻译 agent，由它把洞见转换为运营商偏好的语言。翻译并结构化后的数据随后被格式化为预定义的报告模板，并存储在指定的数据库中以便后续检索。这样就能跨多样市场无缝获取可执行的洞见。

### UI、监控与性能优化

运营商通过基于 Web 的 UI 访问系统，[Amazon Route 53](https://aws.amazon.com/route53/) 和 [Amazon CloudFront](https://aws.amazon.com/cloudfront/) 提供快速高效的内容分发。[Application Load Balancer](https://docs.aws.amazon.com/elasticloadbalancing/latest/application/introduction.html) 把传入请求分发到多个 EKS 实例，提供高可用性。为优化性能，[Amazon ElastiCache](https://aws.amazon.com/elasticache/) 加速数据检索，同时降低数据库负载。在系统监控与可观测性方面，[Amazon CloudWatch](https://aws.amazon.com/cloudwatch/) 提供额外的监控和可观测能力。Noodoe 的管理员使用 [Amazon Managed Service for Prometheus](https://aws.amazon.com/prometheus/) 和 [Amazon Managed Grafana](https://aws.amazon.com/grafana/) 进行系统监控与可视化。

这一架构为 Noodoe 提供了 AI 驱动、可扩展且智能的电动汽车充电管理解决方案，在全球范围内提升充电站利用率、优化收入并改善客户体验。

Noodoe 的 AI 增强诊断流程通过集成 Amazon Bedrock Agents 改变了电动汽车充电运营，把基于规则的自动化、实时用户输入和 LLM 驱动的洞见融合在一起，实现更明智的决策。在有完善知识库和精简 API 支持的前提下，该解决方案让运营商能够大规模自动化工作流、优化定价并提升充电站性能。知识库的持续扩展、工作流的不断改进和真实环境中的测试进一步提升效率与可靠性。这种方法带来了 15% 的收入增长，并把实施时间缩短了 10%。持续的反馈和清晰的文档让用户能够有效使用 AI 驱动的诊断，实现更智能的充电管理。

Noodoe 产品副总裁 Roman Kleinerman 分享道：“随着客户使用我们的 AI 解决方案来优化定价策略，我们看到收入增长了 10–25%，具体幅度取决于站点位置和数量。”

Noodoe 致力于提供更智能、更智慧的电动汽车充电服务，让最终用户和运营商都受益。目前，Noodoe 在 20 多个国家运营 1,000 多个充电站点，并计划在 2025 年底前再扩展 50 多个站点。展望未来，系统正在增强，以纳入需求、电网状况、时段和天气等因素，支持近实时的动态定价优化。Amazon Bedrock Agents 帮助实现这些智能能力，驱动动态定价、负载均衡和电网感知路由，以优化能源分配并引导用户前往最高效的充电站。未来的增强功能将基于用户偏好提供个性化充电建议和激励措施，为客户和运营商最大化价值。现在就用 [Amazon Bedrock](https://aws.amazon.com/bedrock/) 开始构建智能的、AI 驱动的电动汽车充电解决方案。
