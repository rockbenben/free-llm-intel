# 探索创作可能性：Amazon Nova Canvas 视觉指南

引人入胜的 AI 生成图像始于精心打磨的 prompt。作为我们 [Amazon Nova Canvas Prompt Engineering Guide](https://aws.amazon.com/blogs/machine-learning/image-and-video-prompt-engineering-for-amazon-nova-canvas-and-amazon-nova-reel/) 的续篇，我们在此展示一组由 Nova Canvas 生成的精选视觉画廊——按真实使用场景分类——涵盖从营销与产品可视化到概念艺术与设计探索。

每张图像都配有其生成时所用的 prompt 与参数，为你的 AI 驱动创作提供一个实用的起点。无论你是在打造特定类型的图像、优化工作流，还是仅仅寻找灵感，本指南都能帮你释放 [Amazon Nova](https://aws.amazon.com/ai/generative-ai/nova) Canvas 的全部潜力。

## 解决方案概述

上手 Nova Canvas 很简单。你可以通过 Amazon Bedrock 的 AWS Management Console 上的 Image Playground 访问该模型，也可以通过 API 访问。有关详细的设置说明（包括账户要求与所需权限），请参阅我们关于 [Creative content generation with Amazon Nova](https://docs.aws.amazon.com/nova/latest/userguide/content-generation.html) 的文档。我们此前关于 [prompt engineering 最佳实践](https://aws.amazon.com/blogs/machine-learning/image-and-video-prompt-engineering-for-amazon-nova-canvas-and-amazon-nova-reel/) 的文章，则为编写有效的 prompt 提供了全面指导。

## Amazon Nova Canvas 视觉指南

在这个画廊中，我们展示了一系列多样的图像及其生成所用的 prompt，突显 Amazon Nova Canvas 如何适配各种使用场景——从营销与产品设计到叙事与概念艺术。

下文所有图像均使用 Nova Canvas 生成，分辨率为 1280x720px，CFG scale 为 6.5，seed 为 0，图像质量设置为 Premium。该分辨率也与 Nova Reel 所要求的图像尺寸一致，因此你可以把这些图像带入 Amazon Nova Reel 试验视频生成。
