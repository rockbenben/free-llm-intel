# 使用 Amazon Bedrock 中的多模态提示读取图表、示意图、表格和扫描页面

大语言模型（LLM）已经走过了漫长的道路，从最初只能读取文本，到如今能够读取和理解图表、示意图、表格和图像。在本文中，我们将讨论如何使用 [Amazon Bedrock](https://aws.amazon.com/bedrock/) 上的 LLM，不仅可以提取文本，还能理解图像中呈现的信息。

Amazon Bedrock 是一项完全托管的服务，通过单一 API 提供来自 AI21 Labs、Anthropic、Cohere、Meta、Mistral AI、Stability AI 和 Amazon 等领先 AI 公司的多种高性能基础模型（FM）供选择。它还提供了广泛的能力，可用于构建具备安全性、隐私和负责任 AI 特性的生成式 AI 应用。

## 解决方案概览

在本文中，我们演示如何使用 Amazon Bedrock 上的模型从图像、表格和扫描文档中提取信息。我们提供以下示例：

- 执行目标分类和目标检测任务
- 读取和查询图表
- 读取流程图和架构图（例如 AWS 架构图）并将其转换为文本

我们还探索了一些具体用例，展示 Amazon Bedrock 如何帮你从图像中生成信息：

- 识别图像中的动作
- 为产品命名并提取元数据，以生成广告语和描述
- 为房产生成房地产挂牌信息
- 根据菜品图像生成食谱

## 使用 LLM 执行目标分类和目标检测任务

在撰写本文时，用于目标分类和检测的最佳算法都基于卷积神经网络。不过，Amazon Bedrock 上的 Anthropic Claude 3 Sonnet 等 LLM 也能通过 zero-shot prompting（零样本提示）完成这些任务——这是一种提示技术，即在不提供具体示例或针对该特定任务进行训练的情况下，直接把任务交给模型。在以下示例中，我们展示如何根据提示中传入的类别对图像进行分类。下图是一张[样本](https://www.servicesaustralia.gov.au/medicare-card)澳大利亚 Medicare 卡。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/11/14/ml-17086-image001.jpg)

我们使用以下prompt让 Anthropic 的 Claude 3 Sonnet 对该图像进行分类：

这是一位申请贷款的客户上传的文件之一。该图像可能属于以下四个类别之一：ID、银行对账单、申请表或公用事业账单。请判断这份文件属于哪个类别，只告诉我类别名称。目前我不需要任何其他信息。

我们得到 LLM 的以下响应：

> 根据所提供的图像，这份文件的类别似乎是身份证或身份证明文件。图像显示的内容看起来像是一张 Medicare 卡或类似的政府签发的身份证件，上面显示有姓名和一个身份识别号。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/11/14/ml-17086-image002.png)

它正确地识别出了类别；不过，用 JSON 格式响应会让后续处理更直接。我们在prompt末尾添加以下内容：

> 请以 json 格式提供响应，键为“class”，值为该文件的类别

我们得到以下响应：

`{`
`"class": "ID"`
`}`

现在你可以使用自己选择的库来读取 JSON 响应，例如 Python 的 [JSON](https://docs.python.org/3/library/json.html) 库。

在下一个示例中，我们使用 Meta 的 Llama 3.2 90B Vision 模型来识别图像中的物体。下图是一个变速箱。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/11/14/ml-17086-image003.png)

我们使用以下prompt从图像中识别变速箱：

> 识别这张图像中的整个机械部件。只以 JSON 格式给出该机械部件的名称，键为“name”，值为该机械部件的名称

下图截图展示了prompt以及模型给出的答案。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/11/14/ml-17086-image004.png)

## 读取和查询图表

在下一个示例中，我们展示如何读取图表，然后对图中的数值进行插值和外推。下图显示了几个国家的人口增长情况（[来源](https://ourworldindata.org/population-growth)）。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/11/14/ml-17086-image005.jpg)

我们将这张图像连同以下prompt一起传给 Anthropic 的 Claude 3 Sonnet：

> 根据这张图表，为印度人口创建一张表格，第一列为年份，第二列为以百万计的人口数。从 1950 年到 2025 年，每 5 年创建一行。

我们要求它每 5 年创建一行，因此模型必须对数值进行插值。我们还要求它把表格延长到 2025 年，由于数据只到 2021 年，模型不得不对数值进行外推。我们得到以下响应：

> 以下是印度人口表格，第一列为年份，第二列为以百万计的人口数，从 1950 年到 2025 年每 5 年一行：

`| Year | Population (in millions) |`

`|------|--------------------------|`

`| 1950 | 357.6 |`

`| 1955 | 390.5 |`

`| 1960 | 427.8 |`

`| 1965 | 468.0 |`

`| 1970 | 510.9 |`

`| 1975 | 556.9 |`

`| 1980 | 605.7 |`

`| 1985 | 658.0 |`

`| 1990 | 713.8 |`

`| 1995 | 773.0 |`

`| 2000 | 835.6 |`

`| 2005 | 901.7 |`

`| 2010 | 971.5 |`

`| 2015 | 1045.0 |`

`| 2020 | 1122.0 |`

`| 2025 | 1202.4 |`

外推结果可能并不准确，这时更传统的机器学习（ML）方法就会派上用场。

你还可以要求模型把它自身的知识与图表中的知识结合起来。下面的prompt要求给出图中各国 2021 年的人口，以及该国的首都：

> 你能创建一张 2021 年的表格吗？第一列是国家名称，第二列是以百万计的人口，第三列是该国的首都。

下图截图展示了响应。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/11/14/ml-17086-image006.jpg)

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/11/14/ml-17086-image007.jpg)

LLM 根据图表以及它自身关于各国首都的知识填写了这张表格。

你也可以尝试更难一些的任务。下图是一张天气图，来自

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/11/14/ml-17086-image008.jpg)

你可以向 LLM 提出一个具体问题，例如：

> 这是一张澳大利亚的降水图。悉尼现在下雨吗？

你不必告诉 LLM 悉尼在哪里，也不必告诉它这张图显示的是降雨量。

我们得到以下响应：

> 根据所显示的降水图，悉尼地区（位于澳大利亚大陆东海岸）上空似乎没有出现明显降雨。这张图使用等高线和颜色来表示降水量，但在该图所示的这一特定时间段，悉尼周边区域没有任何阴影区域或等高线表明有降雨。因此，现有数据表明，在这张降水图所代表的时刻，悉尼很可能没有下雨。

从这个用例中可以得出几点有趣的观察：

- Anthropic 的 Claude 3 Sonnet 能够读取地图
- 该模型能够读取地图上的叠加层
- 诸如“悉尼周边区域”这样的表述表明，模型并不需要精确信息，而是可以像人类一样使用近似值

## 结论

Amazon Bedrock 上提供的 Anthropic Claude 3 Sonnet 和 Meta Llama 3.2 90B Vision 模型等 FM，已经展现出令人瞩目的图像处理能力。这些 FM 带来了一系列强大的功能，包括图像分类、光学字符识别（OCR），以及解读图表和建筑蓝图等复杂视觉内容的能力。这些创新为各种棘手问题提供了新颖的解决方案，从检索扫描文档档案，到生成由图像启发的文本内容，再到把视觉信息转换为结构化数据。

要开始针对你的具体需求使用这些能力，我们建议探索 Amazon Bedrock 上的 [chat playground](https://docs.aws.amazon.com/bedrock/latest/userguide/playgrounds.html#chat-playground) 功能，它让你可以与图像交互并从中提取信息。
