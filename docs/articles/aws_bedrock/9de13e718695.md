# TUI 如何借助 Amazon Bedrock 在 10 秒内规模化内容创作并提升酒店描述质量

[TUI Group](https://www.tuigroup.com/en-en) 是全球领先的旅游服务企业之一，为 180 个地区的 2,100 万名客户提供无与伦比的度假体验。TUI Group 覆盖端到端的旅游产业链，拥有 400 多家自有酒店、16 艘邮轮、1,200 家旅行社和 5 家航空公司，覆盖全球所有主要度假目的地。在 TUI，打造高质量内容是推广策略的关键组成部分。

TUI 的内容团队负责为其网站产出高质量内容，包括产品详情、酒店信息和旅行指南，这些内容常常基于酒店和第三方合作伙伴撰写的描述。这些内容需要符合 TUI 的语气风格（tone of voice），而这对传达品牌独特的个性至关重要。但随着产品组合不断扩展、酒店与产品越来越多，规模化内容创作变得颇具挑战。这为利用[生成式 AI](https://aws.amazon.com/generative-ai/) 增强并自动化现有的内容创作流程提供了机会。

本文讨论我们如何使用 [Amazon SageMaker](https://aws.amazon.com/sagemaker/) 和 [Amazon Bedrock](https://aws.amazon.com/bedrock/) 构建一个内容生成器，按特定的品牌与风格准则改写营销内容。Amazon Bedrock 是一项全托管服务，通过单一 API 提供来自 AI21 Labs、Anthropic、Cohere、Meta、Mistral AI、Stability AI 和 Amazon 等领先 AI 公司的高性能基础模型（FM）选择，并提供构建生成式 AI 应用所需的一整套能力，涵盖安全、隐私和负责任 AI。Amazon SageMaker 帮助数据科学家和机器学习（ML）工程师从零构建 FM、用先进技术评估和定制 FM，并以细粒度控制部署 FM，满足对准确性、延迟和成本有严格要求的生成式 AI 用例。

通过实验，我们发现采用两阶段方法最能确保输出符合 TUI 的语气要求。第一阶段是用一个较小的大语言模型（LLM）在大量语料上做微调。第二阶段使用另一个 LLM 模型做后处理。通过微调，我们使用静态数据生成模仿 TUI 品牌语气的内容，这是 prompt 工程无法捕捉到的。采用带 few-shot 示例的第二个模型，有助于验证输出是否符合特定的格式和语法规则。后者使用更动态的数据集，我们未来可以用它针对不同的品牌要求快速调整输出。总体而言，这种方法产出了更高质量的内容，并使 TUI 能以更高的速度提升内容质量。

## 解决方案概览

该架构由几个关键组件构成：

- **LLM 模型** —— 我们评估了不同方案，发现双模型解决方案效果最好。其中包括一个微调过的 [Meta Llama](https://llama.meta.com/) 模型，为给定酒店生成描述，以及一个 [Anthropic 的 Claude](https://www.anthropic.com/) 模型，对其输出重新排版。Meta Llama 2 模型的微调与托管在 Amazon SageMaker 上完成，Anthropic 的 Claude 2 则通过 API 调用从 Amazon Bedrock 使用。
- **编排** —— 我们使用 [AWS Step Functions](https://aws.amazon.com/step-functions/) 创建了一个状态机，以批处理方式调用这两个 LLM，并从第三方 API 获取所生成内容的搜索引擎优化（SEO）评分。如果 SEO 内容评分高于既定阈值（80%），生成的内容就会存入 [Amazon DynamoDB](https://aws.amazon.com/dynamodb/) 表，之后内容团队可以直接在前端 UI 中审阅。通过这一流程，我们能够大规模地维护和监控内容质量。
- **人在环路反馈** —— 我们开发了一个自定义的 [React](https://react.dev/) 前端应用，用于收集内容团队的反馈，以促进持续改进和后续的模型微调。你可以利用这些反馈，在 SageMaker 上通过[基于人类反馈的强化学习（RLHF）](https://aws.amazon.com/what-is/reinforcement-learning-from-human-feedback/) 对基础模型进行微调，以提升性能。

## Prompt 工程

我们首先设计 prompt，把 TUI 内容团队识别出的最常见问题纳入其中，包括语气风格、准确性、长度和语法。我们在上下文窗口中向 LLM 提供了几个精选内容示例。尽管生成的输出遵循了指引，但写作风格并不符合 TUI 的语气要求。

**示例 prompt：**

```
You are an experienced British copywriter for TUI. TUI is a world-leading travel company. You are an expert in generating hotel descriptions, based on TUI’s tone of voice. TUI's tone of voice can be described as upbeat, enthusiastic, and promotional. Avoid all the words in the following list: {banned words}
Write at most 100 words.
Your hotel descriptions must follow TUI's tone of voice and apply SEO guidelines.
These are some good examples. You should mimic below.
{examples}.
Human: {input}
Assistant:
```

## 在 Amazon SageMaker JumpStart 上使用 PEFT 微调 Llama 2

这些问题和糟糕的反馈让我们得出结论：仅靠 prompt 工程不足以解决这个问题。因此，我们决定采取另一种方法：微调一个较小的大语言模型，使其按照 TUI 的语气风格改写文本。我们使用由 TUI 文案撰写人员编写的精选酒店描述，使模型更好地与我们的准则对齐。

我们通过 [Amazon SageMaker JumpStart](https://aws.amazon.com/sagemaker/jumpstart/) 选择了 Meta Llama 2 模型（当时可用的顶级开源 LLM 之一），并选择 13B 参数版本进行参数高效微调（PEFT），具体使用量化低秩适配（QLoRA）。该技术把预训练模型量化为 4 位，并添加小型低秩适配器用于微调。我们使用约 4,500 家酒店的相对较小数据集，在单个 ml.g5.4xlarge 实例上花了约 20 小时完成微调。我们还测试了 Llama 2 7B 和 70B 模型。结果发现 7B 模型表现不够好，而 70B 模型成本高得多，却没有带来显著提升。

我们在训练期间使用困惑度（perplexity）等常见的自然语言处理（NLP）评估指标进行评测和监控，并与内容团队建立每日反馈循环来完善测试集。微调后的 Meta Llama 2 13B 模型的输出有效模仿了 TUI 的语气风格，并遵循了大多数 SEO 准则，甚至包括 prompt 中未指定的准则。

## 集成 Anthropic 的 Claude 2 以进一步改进

为进一步改善输出，我们引入了使用 Amazon Bedrock 的 Anthropic 的 Claude 2 作为最终精修步骤。这包括把美式拼写转换为英式拼写、把一到九的数字写成单词而更大的数字使用阿拉伯数字、修正拼写错误和大小写错误、尽量减少禁用词、加入必要的 TUI 品牌词，以及补充缺失的酒店信息。我们还在 UI 中实现了反馈机制，把数据用于生产中的持续微调。通过使用 Anthropic Claude 2，我们确保最终输出应用了其余的格式规则。

## 关键成果

最终架构由一个微调过的 Meta Llama 2 13B 模型和 Anthropic Claude 2 组成，发挥各自的优势。在一次盲测中，在 50 家酒店的样本里有 75% 的情况下，这些动态生成的酒店描述评分高于人类撰写的描述。我们还集成了第三方 API 来计算所生成内容的 SEO 评分，结果观察到所生成内容的 SEO 评分相比人类撰写的描述最高提升了 4%。最重要的是，内容生成流程现在快了五倍，在不牺牲质量或一致性的前提下提升了我们团队的生产力。我们可以在短短几小时内生成大量酒店描述——而这项工作此前需要数月。

## 经验总结

展望未来，我们计划探索这项技术如何解决当前的效率低下与质量缺口，尤其是对于我们团队尚无余力精心打磨的酒店。我们计划把该解决方案扩展到 TUI 产品组合中的更多品牌和地区，包括以多种语言产出内容，并针对不同受众的具体需求进行定制。

在整个项目中，我们总结出几点宝贵的经验：

- 当示例有限、响应准则明确时，few-shot prompting 成本高效且足够。当你需要定制内容以匹配品牌的语气风格时，微调可以显著提升模型性能，但它可能资源开销大，而且基于可能过时的静态数据源。
- 微调 Llama 70B 模型的成本远高于 Llama 13B，且没有带来显著提升。
- 纳入人类反馈并保持人在环路的方式，对于保护品牌完整性和持续改进解决方案至关重要。TUI 工程、内容和 SEO 团队之间的协作是该项目成功的关键。

尽管 Meta Llama 2 和 Anthropic 的 Claude 2 是我们实验时最新的先进模型，但此后我们看到了 Meta Llama 3 和 Anthropic 的 Claude 3.5 的发布，我们预期它们能显著提升我们输出的质量。Amazon Bedrock 现在也支持对 Meta Llama 2、Cohere Command Light 和 [Amazon Titan](https://aws.amazon.com/bedrock/titan/) 模型进行微调，使测试模型更简单、更快速，且无需管理基础设施。
