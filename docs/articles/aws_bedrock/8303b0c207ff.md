# 在 AWS 上介绍 Claude Haiku 5.5

今天，我们很高兴地宣布 Claude Haiku 5.5 在 [Amazon Bedrock](https://aws.amazon.com/bedrock/) 和 [AWS 上的 Claude Platform](https://aws.amazon.com/blogs/machine-learning/introducing-claude-platform-on-aws-anthropics-native-platform-through-your-aws-account/) 上可用。据 Anthropic 称，Claude Haiku 5.5 是 Claude 5.5 系列中最快、最高效的型号，专为子代理和大批量、成本敏感的工作而构建。对于大多数任务来说，它的成本也比 Claude Haiku 4.5 低 75% 左右。

Amazon Bedrock 为您提供 Haiku 5.5 功能，同时通过区域数据驻留将您的数据保留在 AWS 基础设施中。它可与您的团队已使用的 AWS 控件配合使用，包括用于访问的 AWS Identity and Access Management (IAM)、用于审计的 AWS CloudTrail、用于监控的 Amazon CloudWatch 和 Amazon Bedrock Guardrails。使用情况会显示在您的 AWS 账单上。

AWS 上的 Claude Platform 让您可以通过 AWS 管理控制台直接访问 Anthropic 的本机平台体验和功能。使用与直接使用 Anthropic 相同的 API、功能和控制台体验进行构建、测试和部署，并与 AWS 计费和身份验证相统一。

这篇文章介绍了 Claude Haiku 5.5 的改进、何时选择 Haiku 5.5 的实用指南以及如何开始使用 Amazon Bedrock。

## 克劳德俳句 5.5 有何不同

Claude Haiku 5.5 是 Anthropic 最强大的俳句模型，涵盖编码、工具使用、计算机使用和代理任务。这也是第一个具有工作量控制的 Haiku 模型，因此您可以根据每个任务的智能调整成本，而不是为整个工作负载选择一个设置。

这些改进在快速且可重复的大规模工作方面表现突出。对于编码任务，它充当子代理路由请求、审查代码并对长文档进行分类。对于知识工作，Haiku 5.5 从小到中型文档中提取关键信息，进行初始扫描，并通过知识库回答快速问题。对于交互式应用程序，它的响应速度足够快，可以为简单的对话提供快速且有用的答案。它还可以按照生产功能所需的数量和成本处理传统的自然语言处理 (NLP) 任务，例如分类、摘要和文本生成。

Haiku 5.5 处理代理编码和多步骤工具的使用，并支持高分辨率图像。 Haiku 5.5 可以用作强大的计算机使用子代理，用于重复的浏览器和桌面任务，且成本可以承受规模。在开发工作流程中，它非常适合快速迭代 UI 和 UX 更改以及跨多个文件进行小型特定代码库更改。

## 将 Claude Haiku 5.5 与 Opus 5.5 配对

Haiku 5.5 与最近发布的 Claude Opus 5.5 配对。他们共同组成了一个强大的团队：Opus 5.5 进行计划并做出判断，Haiku 5.5 快速且大规模地执行明确定义的任务。您可以在重要的地方进行仔细的推理，并在任何地方降低成本和延迟。

- **Claude Opus 5.5 规划工作并做出判断。** 它分解复杂的问题，决定方法，并进行最困难的推理，例如发布调试、大型拉取请求的安全审查以及最终形成完整报告的长时间分析。
- **Claude Haiku 5.5 采用快速子代理层。** 它可以处理快速、大容量的任务，例如路由请求、分类和总结、重写长文档以及在许多文件中应用小的具体更改。作为审查子代理，它可以快速检查操作顺序和高层方向，因此 Opus 5.5 可以将其代币花在最难的推理上。由于它快速且经济高效，因此您可以并行运行多个 Haiku 子代理。

## 在 Amazon Bedrock 上开始使用 Claude Haiku 5.5

要尝试 Haiku 5.5，请打开 [Amazon Bedrock 控制台](https://console.aws.amazon.com/bedrock/)，选择 **Test**，然后选择 **Playground**，然后选择 Haiku 5.5 作为模型。从那里，您可以直接针对它运行提示。

图 1：在 Amazon Bedrock 控制台 Playground 中选择 Anthropic Claude 模型

您可以通过 Anthropic SDK 以编程方式针对“bedrock-runtime”使用 [Anthropic Messages API](https://docs.aws.amazon.com/bedrock/latest/userguide/model-parameters-anthropic-claude-messages.html) 调用模型。您还可以通过 [AWS 命令行界面 (AWS CLI)](https://aws.amazon.com/cli/) 和 [AWS] 在 `bedrock-runtime` 上使用 [Invoke](https://docs.aws.amazon.com/bedrock/latest/userguide/inference-api.html) 和 [Converse](https://docs.aws.amazon.com/bedrock/latest/userguide/conversation-inference.html) API SDK](https://aws.amazon.com/developer/tools/)。

### 先决条件

您必须具备以下先决条件：

- 具有 Amazon Bedrock 访问权限的活跃 AWS 账户。
- 安装并配置了 AWS 命令​​行界面 (AWS CLI)。
-Python 3.10+。
- Boto3 安装：`pip install boto3`。
- Anthropic SDK 安装：`pip install anthropic`。
- 安装了用于 Amazon Bedrock 身份验证的 Amazon Bedrock 令牌生成器：“pip install aws_bedrock_token_generator”。
- AWS Identity and Access Management (IAM) 权限：`bedrock:InvokeModel`、`bedrock:InvokeModelWithResponseStream`。

以下是使用适用于 Python 的 AWS 开发工具包 (Boto3) 和 InvokeModel API 的简单示例：
```
import boto3
import json

# Create a Bedrock Runtime client
bedrock_runtime = boto3.client(
    service_name="bedrock-runtime",
    region_name="us-east-1"
)

# Invoke Claude Haiku 5.5
response = bedrock_runtime.invoke_model(
    modelId="global.anthropic.claude-haiku-5-5",
    contentType="application/json",
    accept="application/json",
    body=json.dumps({
        "anthropic_version": "bedrock-2023-05-31",
        "max_tokens": 4096,
        "messages": [
            {
                "role": "user",
                "content": "Can you explain the features of Amazon Bedrock?"
            }
        ]
    })
)

result = json.loads(response["body"].read())
# Haiku 5.5 may return a thinking block before the text block,
# so select the text block rather than a fixed index.
print(next(b["text"] for b in result["content"] if b["type"] == "text"))
```
您还可以使用 Amazon Bedrock Converse API 获得统一的多模型体验：
```
import boto3

# Create a Bedrock Runtime client
bedrock_runtime = boto3.client(
    service_name="bedrock-runtime",
    region_name="us-east-1"
)

# Invoke Claude Haiku 5.5
response = bedrock_runtime.converse(
    modelId="global.anthropic.claude-haiku-5-5",
    messages=[
        {
            "role": "user",
            "content": [
                {
                    "text": "Can you explain the features of Amazon Bedrock?"
                }
            ]
        }
    ],
    inferenceConfig={
        "maxTokens": 4096
    }
)

if 'output' in response:
    blocks = response['output']['message']['content']
    print('\n'.join(b.get('text', '') for b in blocks if 'text' in b))
```
您还可以通过 anthropic SDK 包使用 Anthropic Messages API 以获得简化的体验：
```
from anthropic import Anthropic
from aws_bedrock_token_generator import provide_token

token = provide_token(region="us-east-1")

client = Anthropic(
    base_url="https://bedrock-runtime.us-east-1.amazonaws.com/anthropic",
    api_key=token,
)

# Invoke Claude Haiku 5.5
response = client.messages.create(
    model="global.anthropic.claude-haiku-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Can you explain the features of Amazon Bedrock?"}],
)
print(response)
```

Claude Haiku 5.5 现已在 Amazon Bedrock 上通过“bedrock-runtime”上的 US Geo CRIS (us.)、EU Geo CRIS (eu.)、AU Geo CRIS (au.)、JP Geo CRIS (jp.) 和 Global CRIS (global.) 推理配置文件在 Amazon Bedrock 上提供。在 AWS GovCloud（美国）中，它可在“bedrock-runtime”和“bedrock-mantle”端点上使用。

请参阅 [Amazon Bedrock 文档](https://docs.aws.amazon.com/bedrock/latest/userguide/model-cards-anthropic.html)，了解受支持的 AWS 区域的完整列表。有关定价信息，请参阅 [Amazon Bedrock 定价](https://aws.amazon.com/blogs/machine-learning/introducing-claude-haiku-5-5-on-aws/)。在北美，也可通过 [AWS 上的 Claude Platform](https://aws.amazon.com/blogs/machine-learning/introducing-claude-platform-on-aws-anthropics-native-platform-through-your-aws-account/) 获取该服务
