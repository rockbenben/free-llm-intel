# Claude Haiku 5.5 登陆 AWS

今天，我们很高兴地宣布 Claude Haiku 5.5 现已在 [Amazon Bedrock](https://aws.amazon.com/bedrock/) 和 [Claude Platform on AWS](https://aws.amazon.com/blogs/machine-learning/introducing-claude-platform-on-aws-anthropics-native-platform-through-your-aws-account/) 上开放使用。按 Anthropic 的说法，Claude Haiku 5.5 是 Claude 5.5 系列中速度最快、效率最高的模型，为子智能体以及高吞吐、成本敏感的工作而构建。在多数任务上，它的成本还比 Claude Haiku 4.5 低约 75%。

Amazon Bedrock 让你用上 Haiku 5.5 的能力，同时把数据留在 AWS 基础设施之内，并按 Region 实现数据驻留。它可以配合团队已经在使用的 AWS 管控能力，包括用于访问控制的 AWS Identity and Access Management (IAM)、用于审计的 AWS CloudTrail、用于监控的 Amazon CloudWatch，以及 Amazon Bedrock Guardrails。用量会出现在你的 AWS 账单上。

Claude Platform on AWS 让你通过 AWS Management Console 直接获得 Anthropic 原生平台的体验与能力。构建、测试和部署所用的 API、功能和控制台体验，与你直接对接 Anthropic 时完全一致，同时统一到 AWS 的账单和认证之下。

本文介绍 Claude Haiku 5.5 的改进之处、什么时候该选 Haiku 5.5 的实操建议，以及在 Amazon Bedrock 上的上手方式。

## Claude Haiku 5.5 有何不同

Claude Haiku 5.5 是 Anthropic 迄今能力最强的 Haiku 模型，覆盖编码、工具使用、computer use 和 agentic 任务。它也是首个带 effort 控制的 Haiku 模型，因此你可以针对每个任务去调校成本与智能之间的平衡，而不是给整个工作负载固定一个档位。

这些改进在快速、可重复、且要规模化执行的工作上最为明显。编码任务中，它可以作为子智能体来路由请求、审阅代码、给长文档分类。知识工作中，Haiku 5.5 能从小到中等篇幅的文档里提取关键信息、做初步扫描，并回答关于知识库的即时问题。在交互式应用里，它的响应速度足以让简单对话快速拿到有用的答案。它也能以生产功能所要求的吞吐量和成本，处理分类、摘要、文本生成这类传统的自然语言处理（NLP）任务。

Haiku 5.5 能处理 agentic coding 和多步工具使用，并支持高分辨率图像。作为 computer use 的子智能体，它可以胜任重复性的浏览器和桌面任务，同时在规模化时保持成本可控。在开发工作流里，它很适合用来快速迭代 UI 和 UX 改动，以及跨多个文件做小范围、目标明确的代码库修改。

## Claude Haiku 5.5 与 Opus 5.5 的搭配

Haiku 5.5 与最近发布的 Claude Opus 5.5 是配套的。两者搭在一起是一支很强的组合：Opus 5.5 负责规划并做出判断，Haiku 5.5 负责把定义清楚的任务快速、规模化地执行掉。该认真推理的地方有认真推理，其余所有地方都是更低的成本和延迟。

- **Claude Opus 5.5 规划工作并做出判断。** 它拆解复杂问题、决定方案，并承担最难的推理，例如发布调试、大型 pull request 的安全审查，以及最终以一份成稿报告收尾的长分析。
- **Claude Haiku 5.5 承担子智能体中快速的那一层。** 它处理快速、大量的任务，比如路由请求、分类与摘要、重写长文档，以及在大量文件里做小范围、明确的改动。作为审阅子智能体，它能快速检查操作顺序和高层方向，从而让 Opus 5.5 把 token 花在最难的推理上。由于又快又省，你可以并行运行许多个 Haiku 子智能体。

## 在 Amazon Bedrock 上开始使用 Claude Haiku 5.5

要试用 Haiku 5.5，打开 [Amazon Bedrock console](https://console.aws.amazon.com/bedrock/)，选择 **Test**，再选择 **Playground**，并把模型选为 Haiku 5.5，然后你就可以直接对它发送 prompt。

图 1：在 Amazon Bedrock 控制台的 Playground 中选择一个 Anthropic Claude 模型

以编程方式，你可以通过 Anthropic SDK，用 [Anthropic Messages API](https://docs.aws.amazon.com/bedrock/latest/userguide/model-parameters-anthropic-claude-messages.html) 调用 `bedrock-runtime` 上的模型。你也可以使用 `bedrock-runtime` 上的 [Invoke](https://docs.aws.amazon.com/bedrock/latest/userguide/inference-api.html) 与 [Converse](https://docs.aws.amazon.com/bedrock/latest/userguide/conversation-inference.html) API，通过 [AWS Command Line Interface (AWS CLI)](https://aws.amazon.com/cli/) 和 [AWS SDK](https://aws.amazon.com/developer/tools/) 来调用模型。

### 前置条件

你需要满足以下前置条件：

- 已启用并可访问 Amazon Bedrock 的 AWS 账号。
- 已安装并配置好 AWS Command Line Interface (AWS CLI)。
- Python 3.10+。
- 已安装 Boto3：`pip install boto3`。
- 已安装 Anthropic SDK：`pip install anthropic`。
- 已安装用于 Amazon Bedrock 认证的 The Amazon Bedrock Token Generator for Amazon Bedrock：`pip install aws_bedrock_token_generator`。
- AWS Identity and Access Management (IAM) 权限：`bedrock:InvokeModel`、`bedrock:InvokeModelWithResponseStream`。

下面是一个用 AWS SDK for Python (Boto3) 配合 InvokeModel API 的简短示例：

```
import boto3
import json

# Create a Bedrock Runtime client
bedrock_runtime = boto3.client(
    service_name="bedrock-runtime",
    region_name="us-east-1"
)

# Invoke Claude Haiku 5.5
response = bedrock_runtime.invoke_model(
    modelId="global.anthropic.claude-haiku-5-5",
    contentType="application/json",
    accept="application/json",
    body=json.dumps({
        "anthropic_version": "bedrock-2023-05-31",
        "max_tokens": 4096,
        "messages": [
            {
                "role": "user",
                "content": "Can you explain the features of Amazon Bedrock?"
            }
        ]
    })
)

result = json.loads(response["body"].read())
# Haiku 5.5 may return a thinking block before the text block,
# so select the text block rather than a fixed index.
print(next(b["text"] for b in result["content"] if b["type"] == "text"))
```

也可以用 Amazon Bedrock 的 Converse API 获得统一的多模型体验：

```
import boto3

# Create a Bedrock Runtime client
bedrock_runtime = boto3.client(
    service_name="bedrock-runtime",
    region_name="us-east-1"
)

# Invoke Claude Haiku 5.5
response = bedrock_runtime.converse(
    modelId="global.anthropic.claude-haiku-5-5",
    messages=[
        {
            "role": "user",
            "content": [
                {
                    "text": "Can you explain the features of Amazon Bedrock?"
                }
            ]
        }
    ],
    inferenceConfig={
        "maxTokens": 4096
    }
)

if 'output' in response:
    blocks = response['output']['message']['content']
    print('\n'.join(b.get('text', '') for b in blocks if 'text' in b))
```

也可以通过 anthropic SDK 包使用 Anthropic Messages API，流程更简洁：

```
from anthropic import Anthropic
from aws_bedrock_token_generator import provide_token

token = provide_token(region="us-east-1")

client = Anthropic(
    base_url="https://bedrock-runtime.us-east-1.amazonaws.com/anthropic",
    api_key=token,
)

# Invoke Claude Haiku 5.5
response = client.messages.create(
    model="global.anthropic.claude-haiku-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Can you explain the features of Amazon Bedrock?"}],
)
print(response)
```

更多示例可以查看 [Getting Started notebook](https://github.com/aws-samples/anthropic-on-aws/blob/main/notebooks/claude_haiku_5_5_getting_started/claude-haiku-5-5-getting-started.ipynb)。随着需求增长去扩展应用时，可以通过 [Amazon CloudWatch](https://docs.aws.amazon.com/bedrock/latest/userguide/monitoring.html) 和 [AWS Cost Explorer](https://aws.amazon.com/aws-cost-management/aws-cost-explorer/) 监控用量、性能和成本。

## 可用性

Claude Haiku 5.5 现已在 Amazon Bedrock 上提供，通过 `bedrock-runtime` 上的 US Geo CRIS (us.)、EU Geo CRIS (eu.)、AU Geo CRIS (au.)、JP Geo CRIS (jp.) 以及 Global CRIS (global.) inference profile 访问。在 AWS GovCloud (US) 中，`bedrock-runtime` 和 `bedrock-mantle` 两个端点都可用。

支持的 AWS Region 完整列表见 [Amazon Bedrock 文档](https://docs.aws.amazon.com/bedrock/latest/userguide/model-cards-anthropic.html)。定价信息见 [Amazon Bedrock pricing](https://aws.amazon.com/blogs/machine-learning/introducing-claude-haiku-5-5-on-aws/)。在北美，它也可以通过 [Claude Platform on AWS](https://aws.amazon.com/blogs/machine-learning/introducing-claude-platform-on-aws-anthropics-native-platform-through-your-aws-account/) 使用

可以在 [Amazon Bedrock console](https://console.aws.amazon.com/bedrock) 或 [Claude Platform on AWS](https://aws.amazon.com/blogs/machine-learning/introducing-claude-platform-on-aws-anthropics-native-platform-through-your-aws-account/) 上试试 Claude Haiku 5.5，也可以去看看 GitHub 上的 [Getting Started notebooks](https://github.com/aws-samples/anthropic-on-aws/tree/main/notebooks)。
