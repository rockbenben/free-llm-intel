组织每天都要处理数百万份文档，包括发票、合同、保险理赔单、病历和财务报表。尽管这些文档至关重要，但其中[估计有 80%–90%](https://mitsloan.mit.edu/ideas-made-to-matter/tapping-power-unstructured-data)的数据是非结构化的，且基本未被利用，其中蕴藏着可能改变业务成果的宝贵洞察。尽管技术不断进步，许多组织仍依赖人工录入数据，耗费大量时间从 PDF、扫描图像和表单中提取信息。这种人工方式耗时且容易出错，使组织难以扩大运营规模，也无法快速响应业务需求。

尽管生成式 AI 让构建文档处理概念验证方案变得更容易，但从概念验证走向生产的过程依然充满挑战。当组织发现原型无法应对生产规模、缺乏完善的错误处理、无法以符合成本效益的方式扩展，或无法满足企业安全与合规要求时，往往只能从头再来。在只有少量文档的演示中可行的方案，在生产环境中每天处理数千份文档时常常会崩溃。

## 理解智能文档处理

智能文档处理（intelligent document processing，IDP）涵盖用于从各类文档中提取并处理数据的技术与方法。常见的 IDP 任务包括：

- **OCR（光学字符识别）**——将扫描文档和图像转换为机器可读文本
- **文档分类**——自动识别文档类型（例如发票、合同或表单）
- **数据提取**——从非结构化文档中提取结构化信息
- **评估**——评价所提取数据的质量和置信度
- **摘要**——生成文档内容的简明摘要
- **评测**——对照预期结果衡量准确性和性能

这些能力在各行各业都至关重要。在金融服务领域，组织使用 IDP 处理贷款申请、从银行对账单中提取数据以及核验保险理赔。医疗机构依靠 IDP 从病历中提取患者信息、处理保险表单并高效管理化验结果。制造与物流公司使用 IDP 处理发票和采购订单、提取货运信息以及管理质量证书。政府机构使用 IDP 处理公民申请、从税务表单中提取数据、管理许可与执照，并确保监管合规。

## IDP 中的生成式 AI 革命

传统的 IDP 方案依赖基于模板的提取、正则表达式和经典机器学习（ML）模型。这些方法虽然可用，但需要大量前期配置，难以应对文档格式变化，而且在处理复杂文档时准确率有限。

大型语言模型（LLM）和生成式 AI 的出现，从根本上改变了 IDP 的能力。现代 AI 模型能够理解文档上下文、无需模板即可处理格式变化、在复杂提取任务上达到接近人类的准确率，并且只需少量样本就能适应新的文档类型。这种从基于规则到基于智能的处理方式的转变，意味着组织现在可以高准确率地处理不同类型的文档，大幅缩短实施时间并降低成本。

## 解决方案概览

GenAI IDP Accelerator 是一个模块化的无服务器解决方案，能自动将非结构化文档转换为结构化、可操作的数据。它完全基于 AWS 服务构建，提供企业级的可扩展性、安全性和成本效益，同时只需极少的配置和维护。其配置驱动的设计让团队能够快速调整 prompt、提取模板和校验规则以适配特定的文档类型，而无需改动底层基础设施。

该解决方案采用模块化流水线，在每个阶段不断丰富文档处理结果：从 OCR 到分类，再到提取、评估、摘要，最后以评测收尾。

你可以独立部署和定制每个步骤，从而针对自己的具体用例进行优化，同时保留集成工作流带来的优势。

该解决方案的一些关键特性包括：

- **无服务器架构**——基于 [AWS Lambda](https://aws.amazon.com/lambda/)、[AWS Step Functions](https://aws.amazon.com/step-functions/) 及其他无服务器技术构建，支持队列、并发管理和重试，可为各种规模的生产工作负载提供自动扩展和按使用量付费的定价
- **由生成式 AI 驱动的文档包拆分与分类**——使用 Amazon Bedrock Data Automation 或 Amazon Bedrock 多模态 FM 进行智能文档[分类](https://github.com/aws-solutions-library-samples/accelerated-intelligent-document-processing-on-aws/blob/main/docs/classification.md)，支持多文档包和文档包拆分
- **先进的 AI 关键信息提取**——使用 Amazon Bedrock Data Automation 或 Amazon Bedrock 多模态 FM 进行关键信息[提取](https://github.com/aws-solutions-library-samples/accelerated-intelligent-document-processing-on-aws/blob/main/docs/extraction.md)，并可选配 [agentic 提取](https://github.com/aws-solutions-library-samples/accelerated-intelligent-document-processing-on-aws/blob/main/lib/idp_common_pkg/idp_common/extraction/agentic_idp.py)，以生成能够自我纠正、符合 schema 的输出
- **统一处理架构**（v0.5.0 引入）——单次部署支持两种处理模式，可通过 `use_bda` 配置开关在运行时切换，无需重新部署。使用 [Test Studio](https://github.com/aws-solutions-library-samples/accelerated-intelligent-document-processing-on-aws/blob/main/docs/test-studio.md) 对比两种模式的准确率与成本，为你的文档找到最优方案： BDA 模式——使用 [Amazon Bedrock Data Automation](https://aws.amazon.com/bedrock/bda/)，这是一项全托管服务，提供丰富的开箱即用功能、易用性以及简单的按页定价，推荐用于大多数用例 Bedrock Pipeline 模式——使用 [Amazon Textract](https://aws.amazon.com/textract/) 和 [Amazon Bedrock](https://aws.amazon.com/bedrock/)，搭配 Amazon Nova、Anthropic 的 Claude 或自定义 fine-tune 模型，可完全掌控每个处理步骤，适合需要自定义逻辑、agentic 提取或自定义模型集成的复杂文档
- **Few-shot learning**——通过提供 [few-shot 示例](https://github.com/aws-solutions-library-samples/accelerated-intelligent-document-processing-on-aws/blob/main/docs/few-shot-examples.md)来引导 AI 模型，提升分类和提取的准确率
- **置信度评估**——由 AI 驱动的质量保证机制，可[评估各提取字段的置信度](https://github.com/aws-solutions-library-samples/accelerated-intelligent-document-processing-on-aws/blob/main/docs/assessment.md)，用于标记需要人工审核的文档，并通过边界框可视化对提取数据进行目视核验
- **Human-in-the-loop（HITL）审核**——内置的[人工审核](https://github.com/aws-solutions-library-samples/accelerated-intelligent-document-processing-on-aws/blob/main/docs/human-review.md)系统，直接集成在 Web UI 中，具备基于角色的访问控制（Admin 和 Reviewer 角色）、审核所有权机制以防止并发编辑，以及章节级审核工作流
- **Web 用户界面**——[响应式 Web UI](https://github.com/aws-solutions-library-samples/accelerated-intelligent-document-processing-on-aws/blob/main/docs/web-ui.md) 用于监控文档处理、查看结果和管理配置
- **知识库集成**——通过 [Amazon Bedrock Knowledge Bases](https://aws.amazon.com/bedrock/knowledge-bases/) 使用自然语言[查询已处理的文档](https://github.com/aws-solutions-library-samples/accelerated-intelligent-document-processing-on-aws/blob/main/docs/knowledge-base.md)
- **内置评测**——用于对照基线数据[评测](https://github.com/aws-solutions-library-samples/accelerated-intelligent-document-processing-on-aws/blob/main/docs/evaluation.md)并提升准确率的框架
- **Test Studio**——统一的 Web 界面，支持[管理测试集、运行测试和分析结果](https://github.com/aws-solutions-library-samples/accelerated-intelligent-document-processing-on-aws/blob/main/docs/test-studio.md)，提供并排对比、交互式图表和自动部署的基准数据集，可立即开始测试
- **AI Agent Companion**——交互式 [AI 助手](https://github.com/aws-solutions-library-samples/accelerated-intelligent-document-processing-on-aws/blob/main/docs/agent-companion-chat.md)，配备用于文档分析（自然语言转 SQL 并生成可视化）、错误分析与故障排查以及代码智能的专用 agent，并支持实时流式响应
- **规则校验**——依据可配置的业务规则和合规标准，对[提取的数据进行自动校验](https://github.com/aws-solutions-library-samples/accelerated-intelligent-document-processing-on-aws/blob/main/docs/rule-validation.md)，支持医疗预授权、贷款合规和合同核验等用例
- **智能文档发现**——自动[分析文档样本](https://github.com/aws-solutions-library-samples/accelerated-intelligent-document-processing-on-aws/blob/main/docs/discovery.md)，识别结构、字段类型和组织模式，然后生成配置，加快新文档类型的接入
- **分析与报表数据库**——集中式[分析数据库](https://github.com/aws-solutions-library-samples/accelerated-intelligent-document-processing-on-aws/blob/main/docs/reporting-database.md)，用于跟踪各文档工作流中的处理指标、准确率趋势和成本优化，并支持使用 [Amazon Athena](https://aws.amazon.com/athena) 分析提取出的文档内容
- **对开发者友好的 Python 包**——对于希望试验、优化或将 IDP 能力直接集成到自身工作流的数据科学与工程团队，可通过 [idp_common Python 包](https://github.com/aws-solutions-library-samples/accelerated-intelligent-document-processing-on-aws/blob/main/lib/idp_common_pkg/README.md)使用该解决方案的核心逻辑
- **IDP CLI 与 Python SDK**——提供[命令行界面](https://github.com/aws-solutions-library-samples/accelerated-intelligent-document-processing-on-aws/blob/main/docs/idp-cli.md)和 [Python SDK](https://github.com/aws-solutions-library-samples/accelerated-intelligent-document-processing-on-aws/blob/main/docs/idp-sdk.md)，支持批量文档处理、技术栈管理和负载测试，可通过编程方式集成到 CI/CD 流水线、Lambda 函数和自定义工作流中
- **自定义模型集成**——[Lambda Hook Inference](https://github.com/aws-solutions-library-samples/accelerated-intelligent-document-processing-on-aws/blob/main/docs/lambda-hook-inference.md) 支持在流水线的任意步骤中集成任何 LLM，包括托管在 [Amazon SageMaker](https://aws.amazon.com/sagemaker/)、Amazon ECS、Amazon EC2 上的模型或外部 API
- **MCP 集成**——支持[Model Context Protocol](https://github.com/aws-solutions-library-samples/accelerated-intelligent-document-processing-on-aws/blob/main/docs/mcp-integration.md))，使外部应用能够通过经过 OAuth 2.0 身份验证的安全 endpoint 访问 IDP 能力
- **无代码配置**——通过[配置](https://github.com/aws-solutions-library-samples/accelerated-intelligent-document-processing-on-aws/blob/main/docs/configuration.md)定制文档类型、提取字段和处理逻辑，并可在 Web UI 中编辑。可将多个命名的[配置版本](https://github.com/aws-solutions-library-samples/accelerated-intelligent-document-processing-on-aws/blob/main/docs/configuration-versions.md)作为完整快照管理，支持比较、激活和回滚，从而实现安全的试验和受控的发布
