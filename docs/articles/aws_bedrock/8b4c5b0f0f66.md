# Accenture 借助 Amazon Nova 与 Amazon Bedrock Agents 扩展视频分析规模

*本文与 Accenture 的 Ilan Geller、Kamal Mannar、Debasmita Ghosh 和 Nakul Aggarwal 共同撰写。*

视频集锦为内容发布者提供了一种强有力的方式，既能提升受众参与度，也能延伸内容价值。这些短小、冲击力强的片段捕捉关键时刻，能够提高观众留存、放大社交媒体上的触达、强化品牌形象，并开辟新的变现途径。然而，传统的集锦制作流程缓慢且属于劳动密集型工作。编辑必须人工审看素材、找出重要时刻、剪辑片段，并添加转场或旁白，之后还要做人工质量检查以及面向分发的格式化处理。这虽然保证了编辑控制权，却也制造了无法高效扩展的瓶颈。

本文展示 [Accenture Spotlight](https://aws.amazon.com/marketplace/pp/prodview-6b26i5zq6ko3e?sr=0-16&ref_=beagle&applicationId=AWSMPContessa) 如何借助 [Amazon Nova](https://aws.amazon.com/ai/generative-ai/nova/) 与 [Amazon Bedrock Agents](https://aws.amazon.com/bedrock/agents/) 交付一套可扩展、高性价比的视频集锦生成方案。Amazon Nova 基础模型（foundation model，FM）提供前沿智能与业界领先的性价比。借助 Spotlight，内容所有者可以配置 AI 模型与 agent，以支撑媒体行业中的多样化用例，同时提供 human-in-the-loop 选项，用于质量保证与协作式打磨。这样既保持了准确性、编辑监督与品牌规范的一致性，又不必在速度或可扩展性上做出妥协。

## 真实场景中的用例

Spotlight 已被应用于一系列行业场景，包括：

- **个性化短视频生成** – Spotlight 的专用 agent 分析热门短视频内容（例如短视频流媒体与其他社交媒体内容），以识别高表现内容的模式。随后 agent 把这种理解应用到长视频上，生成个性化的短片段，并内置对品牌一致性与内容标准的检查。
- **体育剪辑与集锦** – Spotlight 为足球、Formula 1、橄榄球等体育项目自动生成视频集锦，并按具体的用户偏好与兴趣进行定制。它还会校验每条集锦的质量与准确性，从而简化编辑工作流。
- **为利益相关方做内容匹配** – 借助丰富的元数据，Spotlight 把归档或直播的视频内容与受众人口统计特征相匹配，优化分发策略，并通过精准定向最大化广告主价值。
- **实时零售优惠生成** – 在加油站等零售环境中，Spotlight 处理实时 CCTV 画面，利用数据（例如车型或交易历史）推断顾客画像，然后动态生成个性化的商品优惠。这些优惠会考虑时段、天气等情境因素，并以定制化的视觉内容在近实时内交付。

## Spotlight 的架构

Spotlight 的架构应对可扩展视频处理的挑战，在保持速度与质量的同时高效地分析并生成内容。它同时纳入了任务专用模型与 Amazon Nova 基础模型，由专用的 Amazon Bedrock agent 进行编排。架构上的关键亮点包括：

- **任务驱动的模型选择** – Spotlight 根据给定任务的复杂度与延迟要求，在传统 AI 模型与 Amazon Nova 基础模型之间动态选择。这种智能编排让时间敏感型操作获得快速推理，同时在需要精细分析的地方部署更深层的多模态推理，从而在从实时零售优惠到复杂视频处理的各类应用中平衡速度与智能。
- **agent 编排** – 各专用 agent 分别为特定分析任务定制，在中心 orchestrator agent 的指挥下贯穿端到端工作流运作。orchestrator agent 负责任务拆解、数据流转以及 agent 之间的通信。
- **可扩展且可适配** – 借助 AWS 的能力，Spotlight 的架构可通过配置支撑不同负载，从高吞吐的视频集锦生成，到边缘侧低延迟的优惠个性化。

Spotlight 使用多层 agent 工作流来自动化视频处理与生成，同时保持质量控制。例如，为了生成动态视频集锦，Spotlight 使用三个专用的"超级 agent"，它们在中心 orchestrator agent 的监督下协同工作。每个超级 agent 都由 Amazon Nova 模型驱动，并有一组工具 agent 提供支持（见下图）。这些 agent 协同理解视频内容、生成高质量集锦，并保持与用户需求和品牌标准的一致。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/07/16/ML-18781-image-1.png)

该工作流由以下超级 agent 与工具 agent 组成：

- **视频处理 agent** – 该 agent 分析长视频并生成详细元数据，以指导短视频的创作。它使用以下工具 agent：  *研究 agent* – 分析热门短视频，找出造就视频传播力的关键要素，并为成功的短视频内容制定配方（recipe）。例如在音乐视频中，它可以标出以主表演者为核心的编舞舞蹈段落作为必要片段，并给出基于该洞察的配方。  *视觉分析 agent* – 把研究 agent 的发现应用到新的长视频内容上。它识别匹配的片段、标记关键人物，并为相关时刻打上时间戳。它使用传统 AI 模型（例如人物识别与跟踪）捕捉细粒度细节，用于片段识别。  *音频分析 agent* – 执行语音说话人分离（diarization）与转写，从视频音轨中提供更深的上下文，以支持研究 agent 与视觉分析 agent。
- **短视频生成 agent** – 该 agent 编排短视频的实际创作，整合相关片段并优化顺序。它的工具 agent 包括：  *兴趣片段（Section of interest，SOI）agent* – 基于视频类型、目标时长、出镜表演者以及来自视觉分析 agent 的 JSON 元数据，识别潜在片段。该 agent 优先考虑逻辑流畅性与观众参与度。  *视频生成 agent* – 使用视频处理 agent 给出的片段建议与组件模式来构建视频。例如，网红视频可能遵循吸引注意力的钩子、关键信息、行动号召的结构。该过程会根据审查 agent 的反馈迭代改进。  *视频后处理 agent* – 通过裁剪为适配移动端的宽高比，或添加字幕、背景音乐与品牌叠层等任务，为发布精修最终输出。
- **审查 agent** – 该 agent 与生成 agent 迭代协作，以维持视频质量与相关性。它的工具 agent 包括：  *相关性检查 agent* – 评估与用户定义的内容准则、受众预期以及期望主题的一致性。  *突兀度检查 agent* – 在片段之间提供平滑过渡，避免生硬的切换，从而提升观看体验与专业感。

## 方案概览

要与 Spotlight 交互，用户访问一个前端 UI，用自然语言输入说明自己的目标。随后 Spotlight 运用由 Amazon Nova 驱动的 agentic 工作流来完成给定任务。下图展示了视频集锦生成的方案架构。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/07/16/ML-18781-image-3.png)

该工作流由以下关键组件构成（编号与上图中的序号对应）：

- 用于用户交互的前端 UI：  用户通过一个由 [Amazon Cognito](https://aws.amazon.com/Users/karamide/Downloads/Amazon%20Cognito) 身份验证保护、并借助 [Amazon CloudFront](https://aws.amazon.com/cloudfront/) 交付的 Web 门户进行交互。[Amazon API Gateway](https://aws.amazon.com/api-gateway) 为视频处理与集锦生成服务提供 RESTful 端点。
- 直播视频流处理：  [AWS Elemental MediaLive](https://aws.amazon.com/medialive/) 处理传入的视频流，并触发 [AWS Lambda](https://aws.amazon.com/lambda) 启动工作流。（Spotlight 也接受以媒体文件形式提供的视频归档内容，用于处理与集锦生成。）
- 由 [AWS Step Functions](https://aws.amazon.com/step-functions/) 编排的视频处理工作流：  托管在 [Amazon SageMaker](https://aws.amazon.com/sagemaker/) 上的开源模型提供语音分析与计算机视觉能力，用于人物和物体检测。由 Amazon Nova Pro 驱动的视频处理 agent 分析视频并生成细粒度元数据（例如识别爆款视频中的模式）。由 Amazon Nova Premier 驱动的审查 agent 维持与品牌标准的一致。预分析任务使用开源工具链完成。
- 由 Step Functions 编排的集锦生成工作流：  Amazon Nova Pro 分析用户关于感兴趣片段的查询以理解意图，并为下游处理重写该查询。由 Amazon Nova Pro 驱动的短视频生成 agent 使用片段建议构建视频集锦。由 Amazon Nova Premier 驱动的审查 agent 确保构建出的集锦符合质量、品牌与上下文预期。[AWS Elemental Media Convert](https://aws.amazon.com/mediaconvert/) 与开源工具链支撑视频集锦的构建与后处理（例如字幕叠加、宽高比变更与转场）。
- 存储与监控：  [Amazon Simple Storage Service](https://aws.amazon.com/pm/serv-s3/)（Amazon S3）存储从处理工作流中提取的元数据、参考内容（例如脚本与品牌规范）以及生成的输出。[Amazon CloudWatch](https://aws.amazon.com/cloudwatch/) 维护端到端的系统健康度并监控性能。

## 主要收益

Spotlight 在视频处理与生成上的做法创造了动态价值。此外，它使用 Amazon Nova 与一体化 agentic 工作流的技术设计，帮助内容所有者在视频处理与编辑运营中获得收益。Spotlight 的主要收益包括：

- **跨行业适用** – Spotlight 的模块化设计使其能够无缝应用于各行业，从媒体娱乐到零售
- **实时处理** – 它同时支持直播流与预录视频，定制集锦的生成可在数分钟内完成，相比过去的数小时甚至数天大幅缩短
- **高性价比部署** – 它完全采用无服务器与按需模式，最大限度降低闲置基础设施成本并提高利用率
- **效率** – Accenture 对使用 Amazon Nova 模型的成本评估显示，由 Amazon Nova 驱动的 agent 相比传统集锦制作方式带来 10 倍以上的成本节省

下表对 Spotlight 的视频处理方式与传统的视频集锦制作方式做了对比分析。

| **指标** | **Spotlight 表现** | **传统方式** |
| --- | --- | --- |
| 视频处理延迟 | 2–3 小时的素材只需数分钟 | 数小时到数天 |
| 集锦审查成本（3–5 分钟） | 使用 Amazon Nova 降低 10 倍 | 传统方式成本高昂 |
| 集锦生成总体成本 | 采用无服务器与按需 LLM 部署，降低 10 倍 | 人工工作流，运营开销高 |
| 部署架构 | 完全无服务器，LLM 调用可弹性伸缩 | 通常资源沉重且静态预置 |
| 用例灵活性 | 体育、媒体剪辑、零售个性化等 | 往往只针对单一用例定制 |

## 结语

Spotlight 代表了前沿的 agentic 方案，旨在利用生成式 AI 应对复杂的媒体处理与客户个性化挑战。凭借构建在 Amazon Nova 之上的模块化多 agent 工作流，Spotlight 无缝实现了动态短视频生成。该方案的核心框架还可扩展到需要在规模上做多模态内容分析的各种行业用例。
