# Introducing Claude Fable 5.2 on AWS

Today, we are announcing the availability of Claude Fable 5.2 and Claude Mythos 5.2 on Amazon Bedrock and Claude Platform on AWS. Claude Fable 5.2 is Anthropic’s most capable generally available model for technical work that raises the bar in coding and the sciences. Claude Mythos 5.2 is available through Anthropic’s verification programs for advanced work in cyber security and life sciences.

In this post, we cover what’s new in both models, why Fable 5.2 matters for your technical workloads, and how to get started building with the model on Amazon Bedrock.

## Why Claude Fable 5.2

Fable 5.2 raises the bar on the hardest problems in coding, math, and science. It takes on ambiguous, multi-step work, verifies its own output, and can run unattended for hours to days. It interprets prompts, iterates, catches its own errors, and optimizes as it goes.

In Anthropic’s alignment testing, Mythos 5.2 hallucinates less, completes tasks more reliably, surfaces important information more consistently, and self-reports issues more honestly than Opus 5.5, Sonnet 5.5, and Mythos 5.1. Anthropic expects Fable 5.2 to behave similarly.

If a cyber security query is declined, you can retry it on Opus 4.8, and if a biology query is declined, you can retry it on Opus 5. On Amazon Bedrock, the retry is your code’s job, not an automatic switch. If the declined request hit the prompt cache, the refusal also includes a fallback credit token. Send that token with the retry and it’s billed as cache reads, so you don’t pay to write the same cache twice. Check the [documentation](https://docs.aws.amazon.com/bedrock/latest/userguide/claude-messages-fallback-credit.html) for more information on fallback credit.

For authorized work in cyber security and life sciences, Claude Mythos 5.2 is available through [Anthropic’s verification programs](https://www.anthropic.com/news/cyber-verification-program).

## Claude Fable 5.2 and Mythos 5.2 use cases

Where Fable 5.2 fits:

- **Agentic coding** across large, multi-repository codebases.
- **Long-running agents** for coordinating many subagents on multi-day work.
- **Scientific research** from new analytical methods to formal mathematical proofs.
- **Financial analysis** for quantitative research and forecasting.
- **Design for 3D, hardware, and motion** for generating environments, components, and simulations in code.

Mythos 5.2 covers two high-risk domains, available only through the verification programs noted earlier:

- **Cyber security**, for security engineering, red teaming, and penetration testing.
- **Life sciences research**, especially biomolecular design and research synthesis.

## Data retention and Enterprise Frontier Safeguards

Anthropic designates Claude Fable 5.2 as a [Covered Model](https://support.claude.com/en/articles/15425695-covered-models). By default, its use requires retention for up to 30 days and human safety review. On Amazon Bedrock, Amazon personnel perform the review within the AWS boundary. Set the `aws_review` data retention mode on your account or project before you invoke the model. See [Amazon Bedrock data retention](https://docs.aws.amazon.com/bedrock/latest/userguide/data-retention.html) for more details.

[Enterprise Frontier Safeguards](https://www.anthropic.com/news/enterprise-frontier-safeguards) (EFS), built in collaboration with AWS, combines the privacy of zero data retention (ZDR) with the latest safeguards for detecting misuse. EFS is available now. A version that keeps your data in a bucket and under keys you control is expected to follow, and it has not launched yet. Until it does, eligible customers can use Fable 5.2 with zero data retention through June 30, 2027.

## Getting started with Claude Fable 5.2 on Amazon Bedrock

To try Fable 5.2, open the [Amazon Bedrock console](https://console.aws.amazon.com/bedrock/), choose **Test**, **Playground**, and select **Fable 5.2** as the model. From there, you can run a prompt directly against it.

Programmatically, you can call the model with the [Anthropic Messages API](https://docs.aws.amazon.com/bedrock/latest/userguide/model-parameters-anthropic-claude-messages.html) against `bedrock-runtime` (through the Anthropic SDK). You can also stay on the [Invoke](https://docs.aws.amazon.com/bedrock/latest/userguide/inference-api.html) and [Converse](https://docs.aws.amazon.com/bedrock/latest/userguide/conversation-inference.html) APIs on `bedrock-runtime` through the [AWS Command Line Interface (AWS CLI)](https://aws.amazon.com/cli/) and [AWS SDK](https://aws.amazon.com/developer/tools/).

### Prerequisites

To follow along with the code examples in this post, you need the following:

- An active [AWS account](https://portal.aws.amazon.com/gp/aws/developer/registration/index.html) with Amazon Bedrock access.
- [AWS CLI](https://aws.amazon.com/cli/) installed and configured with appropriate credentials.
- Python 3.9 or later.
- [Boto3](https://boto3.amazonaws.com/v1/documentation/api/latest/index.html) (AWS SDK for Python) installed: `pip install boto3`.
- AWS Identity and Access Management (IAM) permissions: `bedrock:InvokeModel` and `bedrock:InvokeModelWithResponseStream`.

Here’s a quick example using the AWS SDK for Python (Boto3):

```
import boto3
import json

# Create a Bedrock Runtime client
bedrock_runtime = boto3.client(
    service_name="bedrock-runtime",
    region_name="us-east-1"
)

# Invoke Claude Fable 5.2
response = bedrock_runtime.invoke_model(
    modelId="global.anthropic.claude-fable-5-2",
    contentType="application/json",
    accept="application/json",
    body=json.dumps({
        "anthropic_version": "bedrock-2023-05-31",
        "max_tokens": 4096,
        "messages": [
            {
                "role": "user",
                "content": "An S3 bucket serves 40 TB/month egress. Estimate the monthly egress cost at $0.09/GB, and state one architecture change, using AWS services, to cut it. Show the calculation, keep it under 120 words."
            }
        ]
    })
)

result = json.loads(response["body"].read())

# Fable 5.2 is a reasoning model: the response may include a thinking block
# before the text block, so select the text block rather than a fixed index.
print(next(b["text"] for b in result["content"] if b["type"] == "text"))
```

## Migrating to Claude Fable 5.2 with the claude-api skill in Claude Code

For teams already running Claude models on Amazon Bedrock, the claude-api skill in Claude Code helps you upgrade to Fable 5.2.

The claude-api skill is an open-source skill built into [Claude Code](https://code.claude.com/docs) that captures the details that make Claude API code work well. It covers which agent patterns fit a given job, what parameters change between model generations, and when to apply prompt caching. It stays current as Anthropic’s SDKs evolve: when a new model is released or the API gains a feature, the skill already knows.

### What the skill does for Fable 5.2 migrations

When you ask Claude Code to upgrade your codebase to Fable 5.2, the skill reviews your code and walks you through:

- **Updating model references** swapping model IDs to the Fable 5.2 ID across your application code.
- **Adjusting thinking settings** moving manual thinking configurations to adaptive thinking where appropriate for the new model.
- **Cleaning up outdated parameters** removing deprecated beta headers, parameters, and settings that no longer apply.
- **Suggesting effort levels** recommending the right `output_config.effort` settings inline based on your use case.

The skill also detects your deployment platform including Amazon Bedrock, Claude Platform on AWS, and other environments and adjusts model ID formats and feature configurations accordingly. For example, it uses the Amazon Bedrock structured model ID format (`global.anthropic.claude-fable-5-2`).

### How to use it

In Claude Code, run the migration directly:

`/claude-api migrate`

This scans your working directory (or a subdirectory or specific file list you confirm) and applies the migration changes in a single guided pass. You can also invoke it conversationally by telling Claude Code:

- *“Upgrade me to Claude Fable 5.2”* Claude reviews your code and walks through the necessary changes.
- *“Improve my cache hit rate”* the skill applies prompt caching rules that many developers miss, helping reduce costs on Bedrock.
- *“Add context compaction to my agent”* it walks you through compaction primitives and agent patterns for long-running Fable 5.2 sessions.

The claude-api skill is available in Claude Code and is also bundled into CodeRabbit, JetBrains IDEs (including Junie), Resolve AI, and Warp. It is open source at [anthropics/skills](https://github.com/anthropics/skills/tree/main/skills/claude-api) on GitHub, so any coding agent can integrate it.
