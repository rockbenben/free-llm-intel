## [人工智能](https://aws.amazon.com/blogs/machine-learning/)

# 专业的工作需要专业的工具。认识 AWS Quick。

我们的第一个品牌活动旨在表彰那些保持业务发展的团队以及专为他们构建的人工智能工作空间。每天，领先企业的团队都使用 AWS Quick 对他们已经依赖的数据和应用程序进行研究、分析和采取行动。今天，我们推出第一个品牌活动，为全球数百万知识工作者带来同样的体验。该活动在美国和英国的流媒体电视、在线视频、社交媒体和领先的商业出版物上开展。 AWS Quick 是专为工作而构建的 AI 工作区，团队使用 AI 代理对他们已经依赖的数据和应用程序进行研究、分析和操作。几乎在每个行业，3M、宝马、亿滋、纽约人寿和西南航空等领先企业都在使用 Quick 来改变其工作方式。该活动旨在表彰那些知道自己每天所做的工作值得为其构建工具的团队。

## 你所知道的工作

客户告诉我们，他们的人工智能助手让个人变得更快，但收益仍然是个人的。销售代表仍然通过 CRM、仪表板、通话记录和电子邮件来制定区域计划。由于上下文始终锁定在单个项目或一个供应商的套件中，因此整个团队或公司的生产力永远不会复合。这些工具大多数都是从消费者应用程序开始的，并且仍然通过同一产品为个人和专业用途提供服务。 AWS Quick 采取了相反的道路：它从第一天起就为工作而构建，数百万客户使用相同的 AWS 基础设施来运行其任务关键型应用程序。其中包括许多世界上最复杂和安全敏感的工作负载。

## 从第一天起就为您的业务而打造

AWS Quick 没有消费者版本。我们发布的每一项路线图决策和每一项功能都始于一个问题：它是否可以帮助个人、团队和整个企业完成最重要的工作？ Quick 了解您的角色、您的团队以及您的项目、人员和数据如何连接，因为它适用于您的团队已经使用的应用程序和工作流程。快速观察变化，找出重要的事情，并代表您采取行动，这使您的团队可以自由地专注于推动业务发展的事情。任何人都可以通过用简单的语言描述他们的需求来构建代理、应用程序和自动化，而无需提交 IT 票证。共享空间中构建的所有东西都成为整个团队可以使用的资产。

## 内置信任

Quick 与您已使用的安全性和合规性工具集成，包括用于数据保护的 Microsoft Purview、AWS Identity and Access Management (IAM) 以及用于基于权限的控制的 Microsoft Active Directory。快速读取文件上已有的敏感度标签，强制执行现有权限，并向管理员标记潜在的敏感数据。包括代理、知识库和技能在内的资产只有通过批准的共享才能到达新团队，并且每次批准和拒绝都会记录谁决定、他们共享的内容以及原因。 Quick 还拥有大多数组织所需的合规性认证，包括 HIPAA、FedRAMP、SOC 2 和 ISO 27001。您的数据是您的，您的对话是私密的。其他人无法浏览您的对话，IT 管理员也无法访问您的聊天记录。内置 Amazon CloudWatch 和 AWS CloudTrail，为您的组织提供有关所发生事件、执行者和时间的完整审计跟踪。您的数据永远不会离开您的环境，也永远不会训练其他人的模型。

这一承诺也是我们现在称为 AWS Quick 的原因，这个名称标志着企业安全和治理从一开始就是 Quick 的一部分。

## 每一个决定都是你的

IT 主管、客户主管、项目经理和财务主管的工作方式各不相同，而 Quick 的工作方式与他们每个人的工作方式都不同，可以在任何设备上按照他们的日程安排进行工作。您做出判断，Quick 使您的团队有能力实现其目标。

准备好利用专为业务构建的 AI 来改变用户、团队和整个企业的最佳工作方式了吗？您可以[立即下载 Quick 并在几分钟内开始使用](https://aws.amazon.com/quick/download/)，或者与您的 AWS 客户团队讨论企业定价计划的选项。
