# 专业的工作值得专业的工具。认识一下 AWS Quick。

我们的首个品牌宣传活动，致敬那些让业务持续运转的团队，以及专为他们打造的 AI 工作空间。每天，领先企业的团队都在使用 AWS Quick，在他们已经依赖的数据和应用程序之间进行研究、分析和行动。今天，我们推出首个品牌宣传活动，把同样的体验带给全球数以百万计的知识工作者。该活动在美国和英国投放，覆盖流媒体电视、在线视频、社交媒体和主流商业刊物。AWS Quick 是专为工作打造的 AI 工作空间，团队在这里使用 AI agents，在他们已经依赖的数据和应用程序之间进行研究、分析和行动。几乎在每一个行业，包括 3M、BMW、Mondelez、New York Life 和 Southwest Airlines 在内的领先企业都在使用 Quick 变革他们的工作方式。该活动致敬那些深知自己每天所做的工作值得拥有为之打造的工具的团队。

## 你熟悉的工作

客户告诉我们，他们的 AI 助手让个人更快了，但收益停留在个人层面。销售代表仍然要从 CRM、仪表板、通话记录和电子邮件中拼凑信息来制定区域计划。由于上下文被锁在单个项目或某一家供应商的套件里，生产力无法在整个团队或公司范围内复利式累积。这些工具大多起家于消费级应用，至今仍用同一个产品服务个人和专业用途。AWS Quick 走了相反的路：它从第一天起就为工作而构建，运行在数百万客户用来承载其关键任务应用程序的同一套 AWS 基础设施之上。其中包括许多世界上最复杂、对安全最敏感的工作负载。

## 从第一天起就为你的业务而构建

AWS Quick 没有消费者版本。每一个路线图决策、我们发布的每一个功能，都始于同一个问题：它是否帮助个人、团队和整个企业完成他们最重要的工作？Quick 了解你的角色、你的团队，以及你的项目、人员和数据如何相互连接，因为它跨越你的团队已经在使用的各种应用程序和工作流开展工作。Quick 留意变化，浮现重要事项，并代表你采取行动，让你的团队得以专注于推动业务前进的事情。任何人都可以用平实的语言描述自己的需求来构建 agents、应用程序和自动化，无需提交 IT 工单。在共享空间中构建的一切，都会成为整个团队都能使用的资产。

## 内置的信任

Quick 与你已经在使用的安全和合规工具集成，包括用于数据保护的 Microsoft Purview、AWS Identity and Access Management (IAM)，以及用于基于权限的控制的 Microsoft Active Directory。Quick 读取你文件上已有的敏感度标签，强制执行现有权限，并向管理员标记潜在敏感数据。包括 agents、知识库和 skills 在内的资产，只有通过经批准的共享才能到达新团队，每一次批准和拒绝都会记录在案：谁做的决定、共享了什么、为什么。Quick 还具备大多数组织要求的合规认证，包括 HIPAA、FedRAMP、SOC 2 和 ISO 27001。你的数据属于你，你的对话是私密的。其他任何人都无法浏览你的对话，IT 管理员也无法访问你的聊天记录。Amazon CloudWatch 和 AWS CloudTrail 内置其中，为你的组织提供完整的审计跟踪：发生了什么、谁做的、何时发生。你的数据永远不会离开你的环境，也永远不会用于训练别人的模型。

这份承诺也是我们现在成为 AWS Quick 的原因，这个名字彰显了从 Quick 诞生之初就不可或缺的企业级安全与治理。

## 每个决策仍由你做主

IT 负责人、客户经理、项目经理和财务主管的工作方式各不相同，而 Quick 按他们各自的方式工作，在任何设备上、按他们自己的时间安排。你带来判断力，Quick 赋予你的团队与其目标相匹配的能力。

准备好用专为商业打造的 AI，变革你的用户、团队乃至整个企业完成最佳工作的方式了吗？你可以[立即下载 Quick，几分钟内即可上手](https://aws.amazon.com/quick/download/)，或与你的 AWS 客户团队洽谈企业定价方案的选项。
