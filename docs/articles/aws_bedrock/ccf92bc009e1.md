# 塑造未来：OMRON 与 AWS 同行的数据驱动之旅

*本文与 Omron Europe 的 Emrah Kaya 和 Xinyi Zhou 合写。*

数据是许多组织最重要的资产之一。它们不断寻找方法，想用手中海量的信息获取竞争优势。

[OMRON Corporation](https://www.omron.com/global/en/) 是工业自动化、医疗健康和电子元器件领域的领先技术供应商。在其“塑造未来 2030”（Shaping the Future 2030，SF2030）战略计划中，OMRON 致力于应对多样的社会议题、推动可持续的业务增长、变革业务模式与能力，并加速数字化转型。这场转型的核心是 OMRON 数据与分析平台（ODAP），一项旨在彻底改变公司利用其数据资产方式的创新举措。

本文探讨 OMRON Europe 如何利用 [Amazon Web Services（AWS）](https://aws.amazon.com/)构建其进阶的 ODAP，以及它在发挥[生成式 AI](https://aws.amazon.com/generative-ai/) 力量方面取得的进展。

## 挑战

借助进阶的数据与分析能力，组织可以深入了解自身运营、行业趋势和客户行为，从而制定更有依据的战略并提升洞察力。当应用于企业资源规划（ERP）和客户关系管理（CRM）系统等关键业务数据时，这种方法尤为有力，因为这些系统包含关于内部流程、供应链管理和客户交互的信息。通过分析数据，组织可以识别销售周期中的规律、优化库存管理，或帮助量身定制产品与服务以更有效地满足客户需求。然而，组织在实现这些收益时常常面临重大挑战，原因包括：

- 数据孤岛 – 组织常常在不同区域或部门使用多个系统。要整合这些多样的来源以形成单一可信来源（single source of truth）相当复杂，从而使生成统一报表或分析跨职能趋势变得困难。
- 数据治理挑战 – 在不同系统之间维持一致的数据治理至关重要，但也相当复杂。跨不同系统和部门实施统一策略会遇到重大障碍。
- 格式与标准各异 – 各系统通常使用不同的数据格式和结构。这种差异使数据集成和跨系统分析变得复杂，需要付出大量努力来对账和协调数据，才能获得全面的洞察。

## OMRON 数据与分析平台

为应对这些挑战，OMRON Europe（以下简称“OMRON”）决定实施一套进阶的数据与分析平台 ODAP。这项创新方案被设计为特定数据资产的集中枢纽，打破各种数据源和系统之间的壁垒。

下图展示了简化后的架构，以及 ODAP 所用的部分服务和架构模式。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/03/28/ml-17958-odap0new.png)

ODAP 的目标是把来自多个 ERP 和 CRM 系统以及组织内其他相关数据源的数据无缝整合起来。[Amazon AppFlow](https://aws.amazon.com/appflow) 被用来把各种来源的数据顺畅、安全地传输到 ODAP。此外，[Amazon Simple Storage Service（Amazon S3）](https://aws.amazon.com/s3) 作为中央数据湖，为从不同系统收集的多样数据类型提供可扩展且成本高效的存储方案。Amazon S3 提供的稳健安全特性（包括加密和持久性）被用来实现数据保护。最后，ODAP 在设计上还纳入了前沿的分析工具和面向未来的 AI 驱动洞察。

其中一些工具包括基于云的 AWS 解决方案，例如 [AWS Lambda](https://aws.amazon.com/lambda) 和 [AWS Step Functions](https://aws.amazon.com/step-functions)。Lambda 支持无服务器、事件驱动的数据处理任务，可以在数据到达时进行实时转换和计算。Step Functions 则通过编排复杂工作流、协调多个 Lambda 函数并为精密的数据处理流水线管理错误处理来与之配合。这让 OMRON 能从其庞大的数据仓库中提炼出有意义的模式与趋势，支持组织各层级做出更有依据的决策。

OMRON 的数据战略——体现在 ODAP 上——也让组织得以开启聚焦于切实业务成果和生产力提升的生成式 AI 用例。在使用人工智能和机器学习（AI/ML）与生成式 AI 的全面方法中，强大数据战略是其中一部分，它有助于提供高质量、可靠的数据。

## 借助 Amazon Bedrock 拥抱生成式 AI

公司已经识别出若干生成式 AI 能显著影响运营的用例，尤其是在分析和商业智能（BI）方面。

其中一项关键举措是 ODAPChat，一个由 AI 驱动的对话式助手，员工可以用自然语言查询与数据交互。这一工具让整个组织的数据访问更加民主化，即使非技术用户也能获得有价值的洞察。

一个突出的应用是 SQL 与自然语言互转能力，它把复杂的 SQL 查询翻译成通俗的自然语言，反之亦然，从而弥合技术与业务团队之间的鸿沟。为支撑这些进阶的 AI 特性，OMRON 选择了 [Amazon Bedrock](https://aws.amazon.com/bedrock)。这项全托管服务提供一系列[基础模型（FM）](https://aws.amazon.com/what-is/foundation-models/)，让你可以灵活地为每个用例选择最合适的模型。Amazon Bedrock 实现起来直接明了，再加上它能扩展以应对不断增长的数据量和用户请求，使其成为 OMRON 的理想选择。Amazon Bedrock 支持来自不同厂商的各种模型，这有助于确保 OMRON 始终能在最先进的 AI 能力演进时用上它们。

至关重要的是，Amazon Bedrock 提供的稳健安全特性与 OMRON 严格的数据保护要求完全契合。一些亮点包括：

- 细粒度的访问控制
- 网络安全特性，例如传输中和静态数据的加密，或使用私有虚拟私有云（VPC）的能力，帮助确保敏感业务数据即使在由 AI 模型处理时也保持安全
- [Amazon Bedrock Guardrails](https://aws.amazon.com/bedrock/guardrails/)

这些严格的安全控制提供了一套全面的安全方法，让 OMRON 既能用 AI 创新，又能维持最高标准的数据治理与保护。

下图展示了该方案运作方式的基本布局。它有助于说明主要组成部分，以及它们如何协同让 AI 助手完成工作。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/03/28/ml-17958-architecture-new.png)

该系统有三个主要部分：

- **用户界面** – 用户与托管在 AWS 上的对话界面交互。[Amazon Cognito](https://aws.amazon.com/cognito) 处理用户认证流程，为应用提供安全访问。
- **输入处理后端** – [Amazon API Gateway](https://aws.amazon.com/gateway) 接收传入的消息，这些消息随后由运行在 [Amazon Elastic Container Service](https://aws.amazon.com/ecs)（Amazon ECS）上的容器处理。对话内容保存在 [Amazon DynamoDB](https://aws.amazon.com/dynamodb) 中，供后续对话使用。Amazon Bedrock 负责生成 AI 响应，工具则通过 LangChain 配置，它有助于决定如何处理不同类型的查询。在需要时，系统可以访问 ODAP 数据仓库以获取额外信息。
- **文档管理** – 文档被安全地存储在 Amazon S3 中，当有新文档加入时，由 Lambda 函数把它们处理成 chunk。这些 chunk 使用 Amazon Bedrock 转换为嵌入向量，嵌入向量则存储在 [Amazon OpenSearch Service](https://aws.amazon.com/opensearch-service/) 的向量存储中，用于语义搜索。

## 成果与未来计划

在 AWS 上实施 ODAP 和 ODAPChat，已经为 OMRON 带来了显著收益：

- 报表得到优化，带来更高效、更有洞察力的分析
- 由生成式 AI 驱动的 SQL 与自然语言互转能力，让非技术用户也能更容易地使用数据
- 基础设施全面部署在云上，提升了业务敏捷性
- 数据民主化，让更多员工能够使用数据驱动的洞察

展望未来，OMRON 计划大幅扩展其对 AWS 服务的使用，并进一步利用生成式 AI 能力。公司打算把更多数据源（包括其他关键业务系统）集成到 ODAP 中。这一扩展将配合更强的数据治理措施，以帮助在这个不断壮大的数据方案中提升数据质量与合规性。

OMRON 也在探索更进阶的生成式 AI 用例。这些举措将利用 Amazon Bedrock 提供并不断演进的能力，有可能纳入更先进的 AI 模型和安全特性。

## 结论

OMRON 与 AWS 同行的历程，展示了基于云的数据解决方案和生成式 AI 在克服数据孤岛、推动业务创新方面的变革力量。通过使用 Amazon AppFlow、Amazon S3 和 Amazon Bedrock 等 AWS 服务，OMRON 打造了一个全面、安全且可适配的数据与分析平台，不仅满足当下需求，也为公司未来的成长与创新奠定了基础。

当各行各业的组织都在应对类似的数据挑战时，OMRON 的故事是一个鼓舞人心的范例，说明拥抱云技术和 AI 如何能带来显著的业务转型与竞争优势。
