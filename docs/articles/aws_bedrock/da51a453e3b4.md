# Amazon Bedrock Marketplace 现已收录 NVIDIA 模型：推出 NVIDIA Nemotron-4 NIM 微服务

*本文由 NVIDIA 的 Abhishek Sawarkar、Eliuth Triana、Jiahong Liu 和 Kshitiz Gupta 共同撰写。*

在 AWS re:Invent 2024 上，我们很高兴推出 Amazon Bedrock Marketplace。这是 [Amazon Bedrock](https://aws.amazon.com/bedrock/) 中一项革命性的新能力，充当发现、测试和落地基础模型（FM）的集中式枢纽。它为开发者和组织提供了访问 100 多个热门、新兴和专用 FM 的丰富目录，对 Amazon Bedrock 中已有的行业领先模型选型形成补充。Bedrock Marketplace 支持通过托管端点完成模型订阅与部署，同时保持 Amazon Bedrock 统一 API 的简洁性。

NVIDIA Nemotron 家族以 [NVIDIA NIM](https://www.nvidia.com/en-us/ai/) 微服务的形式提供，带来一套前沿的语言模型，现已在 Amazon Bedrock Marketplace 上可用，这标志着 AI 模型可获取性与部署方面的一个重要里程碑。

本文介绍 Bedrock Marketplace 与 Nemotron 模型的优势与能力，以及如何上手使用。

## 关于 Amazon Bedrock Marketplace

Bedrock Marketplace 通过若干关键优势，在普及先进 AI 能力方面发挥着关键作用：

- **全面的模型选择** – Bedrock Marketplace 提供范围异常广泛的模型，涵盖专有和公开可用的选项，让组织为其特定用例找到最合适的方案。

- **统一且安全的体验** – 通过 Amazon Bedrock API 为所有模型提供单一访问入口，Bedrock Marketplace 大幅简化了集成过程。组织可以安全地使用这些模型；对于兼容 Amazon Bedrock Converse API 的模型，你还可以使用 Amazon Bedrock 的强大工具集，包括 [Amazon Bedrock Agents](https://aws.amazon.com/bedrock/agents/)、[Amazon Bedrock Knowledge Bases](https://aws.amazon.com/bedrock/knowledge-bases/)、[Amazon Bedrock Guardrails](https://aws.amazon.com/bedrock/guardrails/) 和 [Amazon Bedrock Flows](mailto:https://aws.amazon.com/bedrock/flows/)。

- **可扩展的基础设施** – Bedrock Marketplace 通过托管端点提供可配置的伸缩能力，让组织选择所需的实例数量、选择合适的实例类型、定义可随工作负载需求动态调整的自定义自动扩缩策略，并在保持性能的同时优化成本。

## 关于 NVIDIA Nemotron 模型家族

NVIDIA Nemotron 模型家族的前沿是 Nemotron-4。如 NVIDIA 所述，这是一个强大的多语言大语言模型（LLM），在高达 8 万亿文本 token 上完成训练，并专门针对英语、多语言和编码任务做了优化。其核心能力包括：

- **合成数据生成** – 能够大规模创建高质量、特定领域的训练数据

- **多语言支持** – 在广泛的文本语料上训练，支持多种语言与任务

- **高性能推理** – 针对 GPU 加速基础设施上的高效部署进行了优化

- **多样的模型规模** – 包含 Nemotron-4 15B 等拥有 150 亿参数的变体

- **开放许可证** – 提供独特宽松的开放模型许可证，让企业能以可扩展的方式生成并拥有合成数据，从而帮助构建强大的 LLM

Nemotron 模型通过应对 AI 开发中的关键挑战，为 AI 开发者带来变革性的潜力：

- **数据增强 **– 通过生成合成的、高质量的训练数据集来解决数据稀缺问题

- **成本效率** – 降低人工数据标注成本，并缩短耗时的数据收集流程

- **模型训练增强** – 通过高质量的合成数据生成提升 AI 模型的表现

- **灵活集成** – 支持与现有 AWS 服务和工作流无缝集成，让开发者能更迅速地构建复杂的 AI 解决方案

这些能力使 Nemotron 模型特别适合那些希望在保持高性能与安全标准的同时加速 AI 举措的组织。

## 开始使用 Bedrock Marketplace 与 Nemotron

要开始使用 Amazon Bedrock Marketplace，请打开 Amazon Bedrock 控制台。在那里，你可以浏览 Bedrock Marketplace 界面，它提供来自不同提供商的全面 FM 目录。你可以浏览可用的选项，发现不同的 AI 能力与专长方向。这样的探索会引导你找到 NVIDIA 的模型产品，包括 Nemotron-4。

我们将在以下小节中带你走完这些步骤。

## 打开 Amazon Bedrock Marketplace

导航到 Amazon Bedrock Marketplace 十分简单：

- 在 Amazon Bedrock 控制台的导航窗格中，选择 **Model catalog**。

- 在 **Filters** 下，选择 **Bedrock Marketplace**。

进入 Bedrock Marketplace 后，你会看到一个组织良好的界面，带有多种分类和筛选器，帮助你找到符合需求的模型。你可以按提供商和模态浏览。

- 使用搜索功能快速定位特定的提供商，并浏览收录在 Bedrock Marketplace 中的模型。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/12/02/ML-17896-image001.png)

## 部署 NVIDIA Nemotron 模型

在 Bedrock Marketplace 中找到 NVIDIA 的模型产品后，你可以进一步缩小到 Nemotron 模型。要订阅并部署 Nemotron-4，请完成以下步骤：

- 在 **Providers** 下按 **Nemotron** 筛选，或按模型名称搜索。

- 从可用模型中选择一个，例如 `Nemotron-4 15B`。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/12/02/ML-17896-image003.png)

在模型详情页上，你可以查看其规格、能力和定价详情。Nemotron-4 模型具备出色的多语言与编码能力。

- 选择 **View subscription options ** 来订阅该模型。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/12/02/ML-17896-image005.png)

- 查看可用的选项并选择 **Subscribe**。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/12/02/ML-17896-image008.png)

- 选择 **Deploy ** 并按提示配置你的部署选项，包括实例类型和扩缩策略。

整个过程对用户友好，让你能够使用 Amazon Bedrock API 快速将这些强大的 AI 能力集成到你的项目中。

## 结语

NVIDIA Nemotron 模型在 Amazon Bedrock Marketplace 上的发布，标志着在让开发者与组织更容易获得先进 AI 能力方面的一个重要里程碑。Nemotron-4 15B 拥有令人印象深刻的 150 亿参数架构，并在 8 万亿文本 token 上完成训练，为 Amazon Bedrock 带来强大的多语言与编码能力。

通过 Bedrock Marketplace，组织可以使用 Nemotron 的先进能力，同时受益于 AWS 的可扩展基础设施和 NVIDIA 的强大技术。我们鼓励你今天就通过 Amazon Bedrock Marketplace 开始探索 NVIDIA Nemotron 模型的能力，亲身感受这个强大的语言模型如何改变你的 AI 应用。
