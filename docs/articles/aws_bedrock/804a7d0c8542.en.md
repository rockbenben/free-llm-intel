You can now distribute a private offer for a third-party model in Amazon Bedrock from the agreement in AWS Marketplace. A new

Distribution status

column on the

Manage subscriptions

page shows which agreements you haven't distributed. For more information, see

Distribute through AWS Marketplace

.
