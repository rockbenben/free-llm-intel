# 用生成式 AI 重塑 Volkswagen Group 的营销

*本文由 Volkswagen Group 的 Sebastian Angersbach、Philip Trempler 和 Weiran Zhang 共同撰写。*

[Volkswagen Group](https://www.volkswagen-group.com/en) 是全球最大的汽车制造商之一，2025 年前九个月交付了 660 万辆汽车。集团由来自五个欧洲国家的十个品牌组成：Volkswagen、Volkswagen Commercial Vehicles、ŠKODA、SEAT、CUPRA、Audi、Lamborghini、Bentley、Porsche 和 Ducati。2025 年，AWS Generative AI Innovation Center 与 Volkswagen Group 的营销和技术团队合作，构建了一套方案：既能利用生成式 AI 的速度与规模，又能保持定义 Volkswagen Group 的品牌精度。成果是一条端到端的营销图像生成与评估 pipeline，其中图像生成模型托管在 Amazon SageMaker AI 端点上，图像评估由 Amazon Bedrock 提供支持。下图展示了这条端到端的营销图像生成与评估 pipeline。

![架构图：端到端的营销图像生成与评估 pipeline，从在 Amazon SageMaker AI 上生成图像到在 Amazon Bedrock 上评估](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/03/23/ML-18778-vw-1.png)

在本文中，我们探讨 Volkswagen Group 在规模化生产符合品牌规范的营销素材时面临的挑战。我们也会讲解如何构建一套生成式 AI 方案：生成照片级真实的车辆图像，在部件层面验证技术准确性，并帮助十个品牌对齐品牌指南的合规要求。

## 挑战：全球规模遇上品牌精度

对 Volkswagen Group 的营销团队来说，这样的规模带来一个非同寻常的挑战：每年产出数千份营销素材，同时还要确保每一张图像都体现客户已经习以为常的精确品牌标准。一次车型发布可能需要数百个变体——不同角度、环境、光线条件以及区域化改编——而按传统方式，每一个变体都需要数月的制作工作。

仅为一个车型进行外景拍摄，成本就可能高达六位数。拍摄需要实体原型车、配备精确灯光的专业影棚，以及把车辆在不同地点之间转运以拍摄不同环境镜头的复杂物流。除制作成本之外，真正的瓶颈出现在验证环节：要在素材上市之前，确保每一份素材都符合其品牌独特的声音与视觉指南。

如果 Volkswagen 能在几分钟而不是几周内生成照片级真实的车辆图像呢？潜在收益很明确——更快的上市时间、大幅的成本削减，以及规模化创建个性化内容的能力。但对一个高端汽车品牌来说，有一条不可谈判的约束：每一张生成的图像都必须与专业摄影无法区分，并且完全符合品牌指南。

挑战不止于技术准确性。集团十个品牌各有自己的视觉语言：Bentley 含蓄的优雅所需的布景方式，与 Porsche 以性能为导向的美学或 ŠKODA 平易近人的现代感截然不同。方案不仅要生成高质量图像，还要系统地验证每一份素材都尊重了其品牌独特的身份。

## 规模化生成符合品牌调性的车辆图像

Volkswagen 生成式 AI 之旅的第一步看似简单：基础模型（FM）能否生成其车辆的照片级真实图像？用基础扩散模型做的初步实验暴露出两个关键缺口。第一，这些模型虽然能产出令人印象深刻的汽车图像，却缺少 Volkswagen 数十年的设计语言。最细微的特征都很重要：格栅网格的精确质感、大灯外壳的精确几何形状、每条车型专属的轮辐图案。模型可以生成一辆 Volkswagen，但配的是与实际年款不符的通用轮毂和格栅图案。第二，基础模型对尚未发布的车辆一无所知。它们无法生成仍在开发中的明年车型的图像，这严重限制了它们对前瞻性营销活动的用处。

方案需要在 Volkswagen 专有的视觉资产上微调基础模型。团队与 [SolidMeta](https://solidmeta.io/) 合作，使用 DreamBooth 微调技术，训练数据采集自 NVIDIA Omniverse 中的数字孪生。下图展示了针对 Volkswagen Tiguan 的这一过程。DreamBooth 训练分两部分：第一，模型从与唯一标识符 token *[VW Tiguan] *配对的 VW Tiguan 图像中学习，从而认识这款特定车型。第二，模型在通用汽车图像上训练，以保留其通用能力并帮助避免对训练集过拟合。

![示意图：针对 Volkswagen Tiguan 的 DreamBooth 微调过程，展示模型如何从与唯一标识符 token 配对的 VW Tiguan 图像以及通用汽车图像中学习](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/03/23/ML-18778-vw-2.png)

借助这种方法，我们可以生成高质量的训练数据，并精确控制车辆规格与环境条件。团队在 Amazon SageMaker AI 端点上部署了增强过的 Flux.1-Dev 扩散模型，并加挂 LoRA（Low-Rank Adaptation）适配器。这种做法让他们能把模型对 VW 设计语言的理解专精到格栅质感乃至具体配置选项的层级，同时保留基础模型的通用图像生成能力。

架构使用 Amazon SageMaker AI 的托管基础设施同时完成训练和推理。定制后的模型部署到 Amazon SageMaker AI 端点，配置为在 ml.g5.2xlarge GPU 实例上做异步推理，以承载计算密集的扩散过程。团队把 pipeline 配置为带自动扩缩的异步推理，从而能高效处理波动的工作负载。

但生成图像所需的不仅是一个微调过的模型，还需要正确的 prompt。团队很快发现，汽车营销图像的有效 prompt 需要专业词汇和风格修饰词，而大多数用户并不具备。营销团队成员可能输入“森林里一辆银色 VW”，但要生成符合品牌规范的图像，需要远为具体的描述：光线条件、拍摄角度、环境细节，以及对车辆特征的精确描述。

为弥补这一差距，Volkswagen 实现了一套基于 Amazon Nova Lite 的自动 prompt 优化系统。在每次图像生成请求之前，Nova Lite 会帮助增强用户的输入 prompt，用符合品牌调性的细节、技术规格和取自 VW 营销指南的风格元素来扩展它。一个简单的 prompt 于是变成全面的描述，引导扩散模型产出符合品牌规范的结果。

微调后的模型生成的图像具有准确的格栅质感、每个配置级别专属的正确轮毂设计，以及每个 VW 品牌特有的车身比例。prompt 优化则促成了不同用户、不同使用场景之间风格与基调的一致性。营销团队现在能更快地产出高质量的车辆渲染图——包括那些用传统方法根本无法可视化的未发布车型。

![并排对比：基础模型输出与微调后模型输出，显示车辆细节（如格栅质感和轮毂设计）准确性的提升](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/03/24/ML-18778-comparison.png)

但新的挑战出现了：在规模化场景下，你如何验证每一张生成的图像都达到 Volkswagen 严苛的标准？当要生成数百或数千个变体时，逐张人工检查并不可行。团队需要一套自动化的质量控制体系，能以与人类品牌专家相同的精度评估图像——而且要以机器的速度完成。

## 自动化质量控制：部件级评估

团队的第一直觉是利用既有的图像质量指标，例如 PSNR（Peak Signal-to-Noise Ratio）和 SSIM（Structural Similarity Index）。这些指标很快被证明不够用。它们评估的是整张图像（包括背景），因此无法把车辆本身单独隔离出来。更关键的是，它们无法指出具体哪个部件出了问题。一张生成的图像可能得分尚可，却有错误的格栅图案或错误的轮毂设计——而这恰恰是最重要的细节。这些数值分数往往与人类感知不一致：在专家看来明显错误的图像，可能在传统指标上得分很高。

团队需要另一种思路：像人类专家那样评估车辆，即用针对汽车设计的详细标准逐个检查部件。

方案把计算机视觉分割与作为自动评判者的视觉语言模型（VLM）结合起来。流程首先把参考照片和生成图像都拆解成单个部件：车轮、格栅、大灯、挡风玻璃、后视镜、车门、保险杠和标识。下面这些 Volkswagen Tiguan 的真实照片展示了从四个标准角度进行的这种分割，用零样本图像分割模型以边界框标出每个部件。

![Volkswagen Tiguan 从四个标准角度拍摄的参考照片，用边界框标出车轮、格栅、大灯和后视镜等单个部件](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/03/23/ML-18778-vw-4.png)

下图展示了把同样的流程应用于一张生成图像：

![Volkswagen Tiguan 的生成图像，用边界框标出为与参考图像比对而分割出的各个部件](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/03/23/ML-18778-vw-5.png)

这种分割使用开源的 Florence-2 模型，托管在 Amazon SageMaker AI 端点上。借助它，团队可以精确指定要检测哪些部件，而不必依赖通用的目标检测。为应对偶发错误，pipeline 中加入了一步由大语言模型（LLM）辅助的校验，使用 Nova Lite 确认每个抽出的片段与其预期标签相符。部件分割并配对完成后，会被并排呈现以供评估，如下图所示。

![并排对比：参考图像与生成图像中分割出的车辆部件，配对以便评估](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/03/23/ML-18778-vw-6.png)

团队为各部件制定了专属标准：对车轮，包括轮辐设计、中心盖细节和轮辋轮廓；对格栅，涵盖形状、质感和标识位置；对大灯，则评估外壳、饰条和内部结构。Amazon Bedrock 上的 Claude 4.5 Sonnet 担任 VLM 评判者，把这些标准应用到每一对部件上。模型会收到一份校准指南，定义从 1 分（普通观众也能看出明显缺陷）到 5 分（即使专家也察觉不到差异）的评分尺度。Claude 会对每条标准逐一评估并给出详细推理。下图展示了对一个大灯的评估。
![大灯评估示例：Claude 对外壳、饰条和内部结构三项标准打分并给出详细推理](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/03/23/ML-18778-vw-7.png)
外壳和饰条得到满分 5/5，但内部结构只得到 4/5，解释是：“AI 生成的图像在内部结构上显示了更多细节，而根据提供的参考图像，这可能并不准确。”这种细粒度反馈正是 Volkswagen 需要的——关于生成图像在何处偏离参考规格的具体、可执行的洞察。

pipeline 由 AWS Step Functions 编排，Amazon S3 为参考图像、生成输出和评估结果提供存储。系统可以跨多张图像聚合分数，以识别系统性问题——例如发现某些角度持续得分偏低，说明需要补充训练数据。

这种基于部件的方法解决了技术准确性的挑战。但促成产品正确性只是战役的一半。Volkswagen 还需要验证生成的图像尊重每个品牌独特的身份与营销指南。

## 促成品牌指南的合规对齐

部件级准确性解决了“生成的格栅或轮毂是否符合规格”这一技术挑战。但 Volkswagen 的品牌标准远不止技术正确性。集团十个品牌各自都有精心制定的指南，既管色板与光线条件，也管环境语境与情感基调。一张技术上完美的 Porsche 图像，如果布景错误或光线不当，仍可能违反品牌指南。

Volkswagen 的品牌身份强调真实、可企及的场景，配以更柔和的傍晚黄金时刻色调。图像应展示车辆在城市街道、乡间道路、家庭车道上——而不是奇幻或过度风格化的环境。布景必须显得真实：车辆合法停放、位置自然，并以符合品牌对质量、可靠与用心工程之价值观的方式呈现。

![Volkswagen 品牌身份指南示例：日常生活场景中黄金时刻光线下的真实车辆布景](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/03/23/ML-18778-vw-8.png)

考虑区域差异之后，复杂性成倍增加。在某个市场合规的内容，在另一个市场可能违反法规或文化规范。以 Volkswagen Touareg 后备箱功能的营销为例。在瑞典，当地法律要求用安全束带或运输箱运送犬只。如果德国营销团队使用一张狗在后备箱里自由活动的图像，该内容在瑞典就是法律上不合规的。把这乘以数十个市场上的数千条细微法规，人工审核就变得无法扩展。

团队构建了一套基于 LLM 的品牌指南评估系统，来系统地评估这些主观要素。该做法使用 Amazon Bedrock 上的 Claude 4.5 Sonnet，把生成的图像和 Volkswagen 全面的品牌指南一并作为上下文提供给它。模型评估多个维度：品牌身份与设计语言、色彩表现、图像风格与基调、车辆呈现、布景与环境、视角与焦距，以及是否符合区域法规。下图展示了一个品牌合规分析的示例。

![品牌合规分析示例：在品牌身份、色彩表现和布景等多个维度上的评估分数](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/03/23/ML-18778-vw-9.png)

与对照参考图像做比较的部件评估系统不同，这项评估是基于标准的。模型评估图像是否尊重品牌专属元素，例如 Volkswagen 标志性的色彩搭配；对故事驱动的图像，情感基调是否为“令人卸下防备的坦诚、真切的人性、出人意料的共情”；以及布景是否显得真实，而不是过度加工。

这套系统在捕捉区域合规问题上尤其有价值，而这些问题几乎不可能靠人工发现。举一个例子：系统评估了一张面向英国行业本地化的图像。尽管图像成功展示了英国城市环境中的右舵车辆，品牌指南评估却标出了一个关键问题。下面的图片展示了区域合规评估的一个示例。

![区域合规评估示例：一张面向英国本地化的图像因使用欧洲大陆车牌而非英国车牌被标记](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/03/23/ML-18778-vw-10.png)

模型给“标识与车牌”打了 2/5 分，解释说该车牌采用了欧洲大陆风格，并识别出这是一块以“WOI”开头的德国车牌。这个细节会立刻让英国客户意识到图像没有恰当地本地化。这类细微的不一致可能削弱 Volkswagen 竭力维护的真实感，却可能在数百张图像的人工审核中被忽略。

通过把部件级技术评估与品牌指南合规检查结合起来，Volkswagen 构建了一套全面的质量控制体系。生成的图像在到达营销团队之前，会按准确性和品牌对齐两方面自动过滤。系统对两个维度都给出详细反馈，让团队能快速识别哪些图像达标，并准确理解其他图像为何不达标。

团队意识到还有更进一步的机会。能否微调评估模型本身，使其更好地对齐 Volkswagen 特定的品牌专长？能否教会 AI 评判者更像 Volkswagen 自己的营销专家那样思考？

## 持续改进：为品牌评估定制 Nova Pro

使用 Claude 4.5 Sonnet 的品牌指南评估系统给出了很强的结果，但团队看到了更进一步的机会。能否专门针对 Volkswagen 的品牌标准定制一个基础模型，教会它以公司自己的营销专家的方式评估图像？

一种方法是监督式微调（SFT），但这通常需要数千个带标注的样本。让 Volkswagen Group 的营销分析师手工标注数千张图像既不现实也很昂贵。团队需要更高效的方案。

他们的洞见是用品牌指南本身来生成合成训练数据。借助一个 LLM，他们生成了 1,000 条旨在产出符合品牌规范图像的 prompt，以及 1,000 条刻意违反特定品牌指南的 prompt。下图展示了合成训练数据生成过程中一条合规 prompt 与一条不合规 prompt 的示例。

![示意图：合成训练数据生成过程中一条合规 prompt 与一条不合规 prompt 的示例](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/03/23/ML-18778-vw-11.png)

因为团队根据构造方式就知道哪些 prompt 合规、哪些不合规，所以他们可以自动为每张图像生成相应的评估文本，如下图所示。这样就得到了完整的 SFT 训练对：图像输入与正确的品牌评估输出配对。![示意图：合规与不合规 prompt 如何与相应的评估文本配对，从而构成 SFT 训练数据](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/03/23/ML-18778-vw-12.png)

有了这份合成数据集，团队使用在 Amazon SageMaker Training Jobs 上运行的 Amazon Nova Model Customization SFT recipe 来定制 Nova Pro。下图端到端地展示了这一过程。
