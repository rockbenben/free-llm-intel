# 在 Amazon Bedrock 上使用 AI agent 构建实时旅行推荐

生成式 AI 正在改变各行业企业交付个性化体验的方式，旅游与酒店业也不例外。旅行社正在通过提供个性化度假套餐来提升服务，这些套餐针对客户的独特偏好精心策划，包括无障碍需求、饮食限制与活动兴趣。要满足这些期望，需要一个把全面的旅行知识与实时价格、库存信息结合起来的解决方案。

本文中，我们展示如何使用 [Amazon Bedrock](https://aws.amazon.com/bedrock/?trk=42edd3ad-f9d1-4bec-98be-19a453395a44&sc_channel=ps&ef_id=EAIaIQobChMIor7b993BjQMVEdBEBx0oawBzEAAYASAAEgL39PD_BwE:G:s&s_kwcid=AL!4422!3!691967596761!e!!g!!amazon%20bedrock!21048269259!166106444144&gad_campaignid=21048269259&gbraid=0AAAAADjHtp_SC22M_TwQ4dP8rmx0DsdUo&gclid=EAIaIQobChMIor7b993BjQMVEdBEBx0oawBzEAAYASAAEgL39PD_BwE) 构建一个生成式 AI 解决方案，它通过把客户画像与偏好同实时价格数据结合，生成量身定制的度假套餐。我们演示如何使用 [Amazon Bedrock Knowledge Bases](https://aws.amazon.com/bedrock/knowledge-bases/) 承载旅行信息、使用 [Amazon Bedrock Agents](https://aws.amazon.com/bedrock/agents/) 获取实时航班详情，以及使用 [Amazon OpenSearch Serverless](https://aws.amazon.com/opensearch-service/features/serverless/) 实现高效的套餐搜索与检索。

## 解决方案概述

旅行社面临着对个性化推荐日益增长的需求，同时又难以兼顾实时数据的准确性与可扩展性。设想一家需要提供无障碍度假套餐的旅行社：它必须把特定的无障碍要求与实时的航班和住宿可用性相匹配，却受制于人工处理耗时以及传统系统中过时的信息。这一由 AI 驱动的解决方案把个性化与实时数据集成结合起来，使旅行社能够自动将无障碍要求与当前的旅行选项相匹配，在数分钟内而非数小时内交付准确的推荐。该方案采用三层架构，帮助旅行社生成个性化的度假推荐：

- **前端层 ——** 提供界面，供旅行社录入客户需求与偏好
- **编排层 ——** 处理请求，并用客户数据对其加以丰富
- **推荐层 ——** 组合两个关键组件：**旅行数据存储 ——** 维护可搜索的旅行套餐仓库；**实时信息检索 ——** 通过 API 集成获取当前航班详情

下图展示了这一架构。

[![AWS 旅行推荐架构图，展示客户请求流经多个服务层的过程](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/07/10/ML-18056-com-arch.jpeg)](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/07/10/ML-18056-com-arch.jpeg)

借助这种分层方式，旅行社可以捕获客户需求、用已存储的偏好对其加以丰富、集成实时数据，并交付契合客户需求的个性化推荐。下图展示了这些组件如何使用 AWS 服务实现。

[![度假推荐系统的架构图](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/07/10/ML-18056-aws-arch.png)](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/07/10/ML-18056-aws-arch.png)

AWS 端的实现包括：

- [Amazon API Gateway](https://aws.amazon.com/api-gateway/) **——** 接收请求并路由到 AWS Lambda 函数，便于发起安全 API 调用以检索推荐
- [AWS Lambda](https://aws.amazon.com/lambda/) **——** 处理输入数据、创建丰富后的 prompt，并执行推荐 workflow
- [Amazon DynamoDB](https://aws.amazon.com/dynamodb/) **——** 存储客户偏好与旅行历史
- [Amazon Bedrock Knowledge Bases](https://aws.amazon.com/bedrock/knowledge-bases/) **——** 帮助旅行社构建经过精选的目的地、旅行套餐与优惠数据库，确保推荐基于可靠且最新的信息
- [Amazon OpenSearch Serverless](https://aws.amazon.com/opensearch-service/features/serverless/) **——** 实现简单、可扩展且高性能的向量搜索
- [Amazon Simple Storage Service（Amazon S3）](https://aws.amazon.com/s3/) **——** 存储航班时刻表与推广物料等大型数据集
- [Amazon Bedrock Agents](https://aws.amazon.com/bedrock/agents/) **——** 集成实时信息检索，确保推荐行程通过外部 API 集成反映当前的可用性、价格与班期

该方案使用一个 [AWS CloudFormation](https://aws.amazon.com/cloudformation) 模板自动预置并配置所需资源。该模板处理完整的设置过程，包括服务配置与必要权限。

有关可能影响你部署的服务配额的最新信息，请参阅 [AWS 服务配额](https://docs.aws.amazon.com/general/latest/gr/aws_service_limits.html)。

当旅行社提交请求时，系统通过 `PersonalisedHolidayFunction` Lambda 函数编排一系列动作：查询知识库、使用模拟 API 检查实时航班信息，并返回契合客户具体需求与偏好的个性化推荐。推荐层使用以下 prompt 模板：

```
Based on the profile and requirements:

User Preferences:
- Travel Preferences: {travelStyle}
- Interests: {interests}
- Dietary Restrictions: {dietaryRestrictions}
- Accessibility Needs: {accessibility}

Current Request:
- Budget: {budget}
- Duration: {duration}
- Travel Date: {travelDate}
- Number of Travelers: {numberOfTravelers}

Previous Destinations: {previousDestinations}

Instructions:
1. Match the user's budget, travel style and interests
2. Consider dietary restrictions and accessibility needs
3. Avoid previously visited destinations
4. Include:
   - Recommended destinations
   - Suitable accommodations
   - Relevant activities and experiences
   - Transportation options
   - Estimated cost breakdown
   - Travel tips

Please follow the <Instructions> and provide a personalized holiday recommendation in the below format:
Destination: [Primary recommended destination]

[Detailed recommendation]
```

系统从用户画像中检索 Joe 的偏好，包括：

```
{
    "userPreferences": {
        "preferences": "Prefer warm climate and cultural experiences",
        "budget": 3000,
        "duration": "5 days",
        "travelDate": "2025-03-04",
        "interests": [
            "photography",
            "food",
            "beach"
        ],
        "travelStyle": "Luxury",
        "numberOfTravelers": 2,
        "dietaryRestrictions": [
            "plant based",
            "vegetarian"
        ],
        "accessibility": [
            "wheelchair-accessible"
        ],
        "previousDestinations": [
            "Maldives",
            "Bali"
        ]
    }
}
```

系统随后生成个性化推荐，其中考虑以下方面：

- 已验证具备轮椅无障碍条件的目的地
- 可用的奢华住宿
- 推荐目的地的航班详情

每条推荐包含以下细节：

- 详细的无障碍信息
- 实时航班价格与可用性
- 含无障碍设施的住宿详情
- 可参与的活动与体验
- 套餐总成本明细
