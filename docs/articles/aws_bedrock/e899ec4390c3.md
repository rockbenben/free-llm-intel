# 变革企业运营：Amazon Nova 的四个高影响力用例

自 [Amazon Nova](https://aws.amazon.com/ai/generative-ai/nova/) 在 AWS re:Invent 2024 发布以来，我们观察到各行业的采用趋势，在运营效率、合规性和客户满意度方面都有显著提升。凭借在安全的多模态 AI 和领域定制方面的能力，Nova 正在改进工作流，并在核心用例中实现成本效益。

在本文中，我们分享四个基于 Nova、在 [Amazon Bedrock](https://aws.amazon.com/bedrock/) 上构建的高影响力且被广泛采用的用例，它们有真实客户部署、AWS 合作伙伴提供的方案以及实践经验的支撑。对于正在研究自身 AI 采用策略和行业用例的组织来说，这些示例非常合适。

## 客户服务

传统聊天机器人常用脚本化、不灵活的回复让用户感到沮丧，这些回复无法理解上下文或意图。对企业而言，这错失了快速解决问题、降低支持成本和培养客户忠诚度的机会。AI 驱动的应用能够理解自然语言、适应个别客户需求并与后端系统实时集成。各类组织正在把支持工作从成本中心转变为提升满意度与留存的战略驱动力。这些场景往往流量大且交互性强，因此成本、速度与智能之间的平衡至关重要。

用 Amazon Bedrock 中的 Nova 构建的客户服务应用，可以与存储在 AWS 上的业务数据无缝集成，并提供企业环境生产使用所需的安全性、隐私性和可靠性。

- [Infosys](https://aws.amazon.com/blogs/machine-learning/how-infosys-improved-accessibility-for-event-knowledge-using-amazon-nova-pro-amazon-bedrock-and-amazon-elemental-media-services/)，一家全球领先的 IT 服务与咨询机构，开发了 Infosys Event AI，用于实时转写、多语言翻译和现场活动内容的智能摘要。Infosys Event AI 基于 Amazon Bedrock 中的 Amazon Nova Pro 构建。在班加罗尔最近的一场活动中，该 AI 助手每分钟处理约 230 名用户，平均每分钟被查询 57 次，生成了 9,000 多份会话摘要。该解决方案让活动洞察以多种语言和格式即时可访问，服务听障人士和远程参会者，从而提升了知识留存、参与度和包容性。通过把活动内容转化为持久、可搜索的多语言知识资产，Infosys Event AI 加速了学习与协作。
- [Fortinet](https://aws.amazon.com/solutions/case-studies/fortinet-nova-case-study/)，一家 AWS 合作伙伴和网络安全公司，使用 Amazon Nova Micro 为其 AI 支持助手提供支持，以极低的成本实现了显著的性能提升。通过改用 Amazon Bedrock 中的 Nova Micro，Fortinet 的推理成本降低了 85 倍，在保持快速响应时间的同时大幅降低了 TCO。该助手现在帮助用户快速浏览 60 多种产品的复杂文档，提升了支持效率并提高了客户满意度。
- AWS Summit New York City 2025 有 18,000 名参会者，其中包含用 Nova Sonic 开发的客户服务 AI 助手 Diana。拨打一个电话号码，这个由 Sonic 驱动的语音助手就回答了数百个关于活动的问题，包括分会场详情、位置和常见问题。

## 搜索

大型企业面对海量结构化和非结构化数据时，搜索往往缓慢、孤立且低效，耗费时间、生产力和客户响应速度。通过采用能够理解自然语言并强制执行安全访问控制的 AI 驱动多模态搜索，组织可以从文档、图像和技术文件中提供即时、相关的答案。这能加快决策、缩短交易周期、提升客户满意度，并降低大规模知识发现的成本。搜索应用越来越依赖跨模态的信息组合，包括文本、文档、图像和视频。

Nova 是最快、最具成本效益的多模态模型之一，并提供视觉微调能力。Nova 还能与更广泛的 Amazon 模型（包括 [Amazon Titan Multimodal Embeddings](https://docs.aws.amazon.com/bedrock/latest/userguide/titan-multiemb-models.html)）以及数据服务（包括 [Amazon OpenSearch Service](https://aws.amazon.com/opensearch-service/)）集成，以获得更强大的搜索能力和性能。

- [Siemens](https://www.youtube.com/watch?v=ULuiRddnJLE) 曾因庞大的数据集给传统搜索系统带来压力而面临日益严重的性能瓶颈，检索速度变慢，影响了其全球运营的生产力。为解决这一问题，Siemens 集成了 Amazon Nova，实现搜索性能三倍提升，大幅加快了数据检索并改善了工作流效率。Amazon Nova 提供高速、可扩展的搜索能力，Siemens 的实施也便于与现有系统无缝集成，以最小的中断保持业务连续性。这提升了用户体验，并使 Siemens 能够从容应对未来的数据增长，背后是持续的性能监控和紧密的基础设施协同。

## 视频理解与分析

各类组织正在采用视频理解应用，在多个方面创造业务价值，包括客户行为分析、交通模式和制造质量控制。通过实时威胁检测和工作场所安全监控实现安全与安保收益，并通过个性化内容推荐和更好的内容可搜索性改善客户体验。组织通过数据驱动的决策和服务交付创新获得竞争优势，同时通过减少人工复核流程和减少安全事件来削减成本。这种全面的视频分析方法帮助企业从视频数据中提取洞察，最终带来更好的运营、更优的决策和更出色的客户体验。随着开发者构建、迭代和演进这些应用，对原生理解视频的需求日益增长，而不是去处理帧、时间戳和同步带来的开销。

Amazon Nova 模型可以根据提供的指令分析、分类和总结视频中的信息。用 Amazon Bedrock 中的 Nova 理解模型构建的应用，通过灵活的输入方式对多种视频格式提供全面分析，能够分析、分类和总结视频内容，并通过 [Amazon Simple Storage Service](https://aws.amazon.com/s3)（Amazon S3）集成处理最大 1 GB 的文件。

- [Bitcentral](https://www.amazonnovapartnershowcase.com/partner-stories/caylent) 与 Caylent 合作，改变归档内容的发现、访问和再利用方式。使用 Amazon Bedrock 中的 Nova Pro，Caylent 部署了一套契合 1,600 多个客户站点记者、制作人和广播机构需求的解决方案。通过将语义视频搜索、上下文元数据生成和 AI 驱动的内容分析嵌入其工作流，Bitcentral 重新定义了归档素材的索引、发现和再利用方式。记者和制作人现在可以实时调出高价值内容，并开辟新的收入来源。
- [Loka](https://www.amazonnovapartnershowcase.com/partner-stories/loka)，一家 AWS Premier 合作伙伴，构建了一套视频监控方案，用于自动识别和分类视频素材中数以百万计的视觉事件。该系统能有效区分常规事件和关键事件，帮助过滤掉非必要的活动和告警。该方案非常成功，将无关告警减少了 55%，同时保持威胁检测率高于 97%。通过实施这套自动过滤系统，Loka 为其客户的视频监控效率提升了一倍。该工具基于 Amazon Bedrock、使用 Amazon Nova Pro 构建，在提升整体威胁检测能力的同时，显著减轻了人工操作员的工作量。
- [Accenture](https://aws.amazon.com/blogs/machine-learning/accenture-scales-video-analysis-with-amazon-nova-and-amazon-bedrock-agents/) Spotlight 可以分析长视频并自动生成个性化的短视频片段和集锦，对足球、一级方程式和橄榄球等体育内容尤其有用。Spotlight 能将内容匹配到特定的受众群体，并可处理零售场景中的实时 CCTV 素材以生成个性化优惠。该系统基于 Amazon Bedrock 中的 Amazon Nova 构建，通过一个中央编排器下辖三个专门化的 super agent 运作。Spotlight 能在几分钟内处理完原本需要数小时甚至数天的视频，同时实现比传统方法好 10 倍的成本节约。该解决方案足够通用，可跨媒体娱乐到零售等不同行业使用，并通过其人工介入（human-in-the-loop）的质量保证选项保持高质量标准和品牌一致性。

## 创意内容生成

各类组织正在寻求彻底改变创意内容生成的方式，包括图库影像、营销活动素材和产品可视化。这一过程往往因工作流割裂、制作成本高昂，以及需要持续在规模与个性化之间取得平衡而变慢。营销团队难以跟上多渠道对新鲜、高质量素材的需求，而创意疲劳和漫长的交付周期限制了他们的敏捷性。

Amazon Nova 通过 Nova Canvas 和 Nova Reel 应对这些挑战：这两个高质量创意模型可将文本和图像输入转化为专业级的图像和视频。Nova 创意模型旨在以可控特性交付可自定义的视觉内容，让媒体、娱乐、零售、营销和广告行业的创意内容生成变得可及且高效。

- [Dentsu](https://aws.amazon.com/pt/solutions/case-studies/dentsu-digital-case-study/) 正在借助 Amazon Nova 创意生成模型重新构想广告的诞生方式。过去需要数周头脑风暴、拍摄和剪辑的工作，现在几天内即可完成。其创意团队可以用自然语言勾勒一个想法，看着它变成精修的视频和定制图像，并以 200 多种语言为全球市场做好准备。审核、水印和 IP 赔偿等内置防护措施确保每一份素材都品牌安全。在 Co-op 项目中，Dentsu 更进一步——将 Nova 与 Amazon Ads 结合，设计定制受众画像，在 25–34 岁人群中带来品牌偏好 +4 个百分点的提升，在富裕消费者中带来好感度 +5 个百分点的提升。
- [Quantiphi](https://www.amazonnovapartnershowcase.com/partner-stories/quantiphi)，一家 AWS Premier 全球咨询合作伙伴，开发了 Qreator，这是一项构建在 AWS 之上、由生成式 AI 驱动的营销内容创作服务。其服务帮助营销人员通过自然语言 prompt 创作内容，同时保持品牌一致性和跨渠道适应性。借助 Qreator，企业可以将内容创作时间缩短约 30%，上市速度加快约 40%，把原本手工的流程自动化，并提升跨格式和跨渠道的一致性。
- [The Fragrance Lab](https://aws.amazon.com/blogs/machine-learning/create-personalized-products-and-marketing-campaigns-using-amazon-nova-in-amazon-bedrock/) 是一项独特的 AWS 活动，曾在戛纳国际创意节（Cannes Lions International Festival of Creativity）上展出。它演示了如何使用 Amazon Bedrock 中的 Amazon Nova 基础模型构建个性化产品和营销活动素材。虽然我们在戛纳国际创意节的活动聚焦于个性化香氛开发和广告活动创作，但其底层架构和方法论可以适配时尚、食品和饮料等多元品类，为定制化客户体验开辟无限可能。The Fragrance Lab 活动荣获两项[国际商业大奖（International Business Awards）](https://stevieawards.com/iba/2025-stevie-award-winners)：展览活动体验类金奖和体验式活动类银奖。

## 结论

本文介绍的四个用例展示了 Amazon Nova 跨行业、跨应用的实用性。从 Infosys 的 Event AI 提升可访问性和参与度，到 Loka 的智能视频监控，再到 Dentsu 的创意内容生成，每一个实施都展现了在效率、成本降低和客户满意度方面显著且可衡量的改进。

使用 Amazon Nova 的组织正通过基于实证的采用策略获得切实的业务成果。通过与 Amazon 和 AWS 合作伙伴携手，各类组织在加快 AI 转型的同时，保持在安全性、合规性和隐私设计原则方面的坚实基础。
