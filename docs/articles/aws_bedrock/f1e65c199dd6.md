# 使用 Amazon Bedrock 和 ConstitutionalChain 生成合规内容

[生成式 AI](https://aws.amazon.com/generative-ai/) 已成为内容创作的强大工具，带来若干关键优势，可以显著提升内容生产流程的效率和效果，例如制作营销素材、图像生成、内容审核等。[Constitutional AI](https://www.anthropic.com/research/constitutional-ai-harmlessness-from-ai-feedback) 和 [LangGraph](https://www.langchain.com/langgraph) 的反思机制代表了确保 AI 系统行为合乎伦理的两种互补方法——Anthropic 在训练期间嵌入原则，而 LangGraph 则通过反思与自我纠正机制在推理/运行时实施这些原则。通过使用 LanGraph 的 Constitutional AI，内容创作者可以精简工作流，同时维持用户定义的高标准合规性与伦理操守。这种方法不仅减少了对大量人工监督的需求，还提升了 AI 内容生成过程的透明度和可问责性。

在本文中，我们探讨使用 Constitutional AI 高效且有效地产出合规内容的实用策略：借助 [Amazon Bedrock](https://aws.amazon.com/bedrock/?gclid=Cj0KCQiA0MG5BhD1ARIsAEcZtwQKTF2XajiMI01XQdaYxrazrkiahrOlBCzmCS5Zdwa4X3426oOmQaIaAiN6EALw_wcB&trk=0eaabb80-ee46-4e73-94ae-368ffb759b62&sc_channel=ps&ef_id=Cj0KCQiA0MG5BhD1ARIsAEcZtwQKTF2XajiMI01XQdaYxrazrkiahrOlBCzmCS5Zdwa4X3426oOmQaIaAiN6EALw_wcB:G:s&s_kwcid=AL!4422!3!692006004688!p!!g!!amazon%20bedrock!21048268554!159639952935) 和 [LangGraph](https://www.langchain.com/langgraph) 构建 [ConstitutionalChain](https://python.langchain.com/docs/versions/migrating_chains/constitutional_chain/)，在金融和医疗等强监管行业实现快速内容创作。尽管 AI 带来显著的生产力收益，但保持对严格法规的合规至关重要。为符合监管要求而对 AI 生成内容进行人工验证可能既耗时又困难。我们还会概述 Publicis Groupe 旗下公司 Insagic 如何使用 Amazon Bedrock 把这一概念整合进其现有的医疗营销工作流。Insagic 是一家新一代洞察与咨询企业，把数据、设计和对话结合起来，为医疗营销人员交付可操作的洞察和变革性的智能。它汇集数据科学家、行为科学家和战略专家的专业能力，在医疗行业推动更好的成果。

## 理解 Constitutional AI

Constitutional AI 旨在使 large language model（LLM）与人类价值观和伦理考量保持一致。它的工作方式是把一组预定义的规则、原则和约束整合进 LLM 的核心架构和训练过程。这种方法确保 LLM 在指定的伦理和法律参数内运行，很像宪法治理一个国家的法律与行动那样。

Constitutional AI 用于内容创作的关键优势包括：

- **伦理一致性**——使用 Constitutional AI 生成的内容本身就与预定义的伦理标准保持一致
- **法律合规性**——LLM 被设计为在法律框架内运行，降低产出不合规内容的风险
- **透明度**——指导 LLM 决策过程的原则被清晰定义，且可以被检视
- **减少人工监督**——通过把伦理准则嵌入 LLM，对大量人工复审的需求显著降低

让我们探讨如何借助 Constitutional AI 的力量为你的组织生成合规内容。

## 解决方案概述

在本解决方案中，我们使用 [Amazon Bedrock Knowledge Bases](https://aws.amazon.com/bedrock/knowledge-bases/) 存储一个医疗文档库。我们采用[检索增强生成（RAG）](https://aws.amazon.com/what-is/retrieval-augmented-generation/)方法，先检索相关上下文，再基于检索到的上下文综合出答案，从而基于该文档库生成文章。随后，我们使用开源编排框架 [LangGraph](https://github.com/langchain-ai/langgraph) 和 `ConstitutionalChain` 在 [Amazon SageMaker](https://aws.amazon.com/sagemaker/?gclid=Cj0KCQiAqL28BhCrARIsACYJvkdPHesrBiOisT6BBceqYfKXcHU5ThawqO2pbk8--KqQORuGMN9ANEgaAtD8EALw_wcB&trk=8987dd52-6f33-407a-b89b-a7ba025c913c&sc_channel=ps&ef_id=Cj0KCQiAqL28BhCrARIsACYJvkdPHesrBiOisT6BBceqYfKXcHU5ThawqO2pbk8--KqQORuGMN9ANEgaAtD8EALw_wcB:G:s&s_kwcid=AL!4422!3!532502995192!e!!g!!amazon%20sagemaker!11206038603!113600690367) notebook 中生成、评析和复审 prompt，并开发一个 agentic 工作流来生成合规内容。下图展示了这一架构。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/03/18/ML-16141-1.png)

这一实现演示了一个精密的 agentic 工作流，它不仅基于 knowledge base 生成响应，还采用反思技术，通过伦理原则检视自己的输出，从而能够改进和完善其输出。我们把一组样例[心理健康文档](https://www.cdc.gov/children-mental-health/data-research/index.html)上传到 Amazon Bedrock Knowledge Bases，并使用这些文档以基于 RAG 的方式撰写一篇关于心理健康的文章。之后，我们定义一个 constitutional principle，其中包含自定义的多元、公平与包容（DEI）原则，指明如何为增强包容性而评析和修订响应。

## 定义 Constitutional AI 组件

接下来，我们定义一个 `Critique` 类来组织评析过程的输出。然后我们为评析和修订创建 prompt 模板。最后，我们使用 LangChain 搭建用于生成响应、评析和修订的 chain。

```
# LangChain Constitutional chain migration to LangGraph

class Critique(TypedDict):
    """Generate a critique, if needed."""

    critique: Annotated[str, ..., "If needed, the critique."]

critique_prompt = ChatPromptTemplate.from_template(
    "Critique this response according to the critique request. "
…
)

revision_prompt = ChatPromptTemplate.from_template(
    "Revise this response according to the critique and reivsion request.\n\n"
    ….
)
chain = llm | StrOutputParser()
critique_chain = critique_prompt | llm.with_structured_output(Critique)
revision_chain = revision_prompt | llm | StrOutputParser()
```
