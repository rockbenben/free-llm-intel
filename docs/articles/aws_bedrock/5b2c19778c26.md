# Pixtral-12B-2409 现已在 Amazon Bedrock Marketplace 上可用

今天，我们很高兴地宣布，Pixtral 12B（pixtral-12b-2409）现已通过 [Amazon Bedrock Marketplace](https://aws.amazon.com/bedrock/marketplace/) 向客户提供。这是来自 [Mistral AI](https://mistral.ai/) 的一款先进的 120 亿参数视觉语言模型（VLM），在纯文本任务和多模态任务上都有出色表现。Amazon Bedrock Marketplace 是 [Amazon Bedrock](https://aws.amazon.com/bedrock/) 中的一项新能力，让开发者能够在 Amazon Bedrock 现有的一系列行业领先模型之外，发现、测试并使用 100 多个热门、新兴和专用基础模型（FM）。你也可以[在 Amazon SageMaker JumpStart 上使用该模型](https://aws.amazon.com/blogs/machine-learning/pixtral-12b-is-now-available-on-amazon-sagemaker-jumpstart/)，后者是一个机器学习（ML）中心，提供可一键部署的算法与模型，用于运行推理。

本文将带你走一遍如何发现、部署并使用 Pixtral 12B 模型，以应对多种真实世界的视觉用例。

## Pixtral 12B 概览

Pixtral 12B 是 Mistral 的首款 VLM。根据 Mistral 的评估，它在一系列基准测试中表现出稳健的性能，超越其他开放模型，并可与更大的同类模型抗衡。Pixtral 兼顾图像与文档理解，在图表解读、文档问答、多模态推理和指令遵循等视觉相关任务上展现出高级能力——本文后文将用示例说明其中若干项。该模型按图像的原始分辨率和宽高比进行处理，提供高保真的输入处理能力。与许多开源替代方案不同，Pixtral 12B 在指令遵循、编码和数学推理等基于文本的基准测试中取得强劲结果，同时并未牺牲其在多模态任务上的能力。

Mistral 为 Pixtral 12B 开发了一种新颖的架构，同时针对计算效率与性能做了优化。该模型由两个主要部分组成：一个 4 亿参数的视觉编码器，负责对图像进行 token 化；以及一个 120 亿参数的多模态 transformer 解码器，根据文本与图像的序列预测下一个文本 token。视觉编码器经过专门训练，能够原生处理可变尺寸的图像，使 Pixtral 既能准确解读高分辨率的示意图、图表和文档，又能对图标、剪贴画和公式等较小图像保持快速推理。这一架构支持在 128k token 的大上下文窗口内处理任意数量、不同尺寸的图像。

使用开放权重模型时，许可协议是一个关键的决策因素。与其他 Mistral 模型（如 Mistral 7B、Mixtral 8x7B、Mixtral 8x22B 和 Mistral Nemo 12B）类似，Pixtral 12B 以[商业友好的 Apache 2.0](https://huggingface.co/mistralai/Pixtral-12B-2409) 许可发布，为企业与初创客户提供了一个高性能的 VLM 选择，用于构建复杂的多模态应用。

## 性能指标与基准测试

Pixtral 12B 经过训练，能够理解自然图像和文档，在大规模多任务语言理解（MMLU）推理基准上取得 52.5% 的成绩；据 Mistral 称，这超过了许多更大的模型。MMLU 基准是一项测试，用于评估语言模型在多种学科中理解和使用语言的能力。MMLU 由超过 10,000 道选择题组成，涵盖数学、哲学、法律和医学等多个学科。该模型在图表理解、文档问答、多模态推理和指令遵循等任务上展现出强大能力。Pixtral 能够按图像的原始分辨率和宽高比摄取图像，让用户在处理一张图像所用的 token 数量上拥有灵活性。Pixtral 还能在其 128,000 token 的长上下文窗口中处理多张图像。据 Mistral 称，与以往的开源模型不同，Pixtral 并没有为了在多模态任务上表现出色而牺牲文本基准测试的表现。

你可以查看 [Mistral 公布的基准测试结果](https://mistral.ai/en/news/pixtral-12b)

## Pixtral 12B 用例

本节我们使用示例 prompt 给出 Pixtral 12B 的用例示例。我们定义了一些辅助函数，用于通过 Amazon Bedrock Converse API 调用 Pixtral 12B 模型：

```
def get_image_format(image_path):
    with Image.open(image_path) as img:
        # Normalize the format to a known valid one
        fmt = img.format.lower() if img.format else 'jpeg'
        # Convert 'jpg' to 'jpeg'
        if fmt == 'jpg':
            fmt = 'jpeg'
    return fmt

def call_bedrock_model(model_id=None, prompt="", image_paths=None, system_prompt="", temperature=0.6, top_p=0.9, max_tokens=3000):
    
    if isinstance(image_paths, str):
        image_paths = [image_paths]
    if image_paths is None:
        image_paths = []
    
    # Start building the content array for the user message
    content_blocks = []

    # Include a text block if prompt is provided
    if prompt.strip():
        content_blocks.append({"text": prompt})

    # Add images as raw bytes
    for img_path in image_paths:
        fmt = get_image_format(img_path)
        # Read the raw bytes of the image (no base64 encoding!)
        with open(img_path, 'rb') as f:
            image_raw_bytes = f.read()

        content_blocks.append({
            "image": {
                "format": fmt,
                "source": {
                    "bytes": image_raw_bytes
                }
            }
        })

    # Construct the messages structure
    messages = [
        {
            "role": "user",
            "content": content_blocks
        }
    ]

    # Prepare additional kwargs if system prompts are provided
    kwargs = {}
    
    kwargs["system"] = [{"text": system_prompt}]

    # Build the arguments for the `converse` call
    converse_kwargs = {
        "messages": messages,
        "inferenceConfig": {
            "maxTokens": 4000,
            "temperature": temperature,
            "topP": top_p
        },
        **kwargs
    }

    
    converse_kwargs["modelId"] = model_id

    # Call the converse API
    try:
        response = bedrock_runtime.converse(**converse_kwargs)
    
        # Parse the assistant response
        assistant_message = response.get('output', {}).get('message', {})
        assistant_content = assistant_message.get('content', [])
        result_text = "".join(block.get('text', '') for block in assistant_content)
    except Exception as e:
        result_text = f"Error message: {e}"
    return result_text
```

如需更多 AWS 上的 Mistral 资源，请查看 [GitHub 仓库](https://github.com/aws-samples/mistral-on-aws)。本文所展示示例的完整代码可在 GitHub 上获取。Pixtral 12B 也可在 [Amazon SageMaker JumpStart](https://aws.amazon.com/sagemaker/jumpstart/) 中使用；详情请参阅 [Pixtral 12B 现已在 Amazon SageMaker JumpStart 上可用](https://aws.amazon.com/blogs/machine-learning/pixtral-12b-is-now-available-on-amazon-sagemaker-jumpstart/)。
