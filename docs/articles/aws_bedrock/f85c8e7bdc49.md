# 在 AWS 上推出 Claude Fable 5.1

今天，我们很高兴地宣布 Claude Fable 5.1 已在 Amazon Bedrock 和 Claude Platform on AWS 上可用。Claude Fable 5.1 为编码、科学研究和企业工作流等雄心勃勃的任务带来前沿智能。

鉴于其能力，Anthropic 已将 Fable 5.1 指定为 *Covered Model*（受覆盖模型），这一类 Claude 模型无论在哪里提供，都会附带额外的数据保留、安全审查和访问策略。更多信息请参阅 Amazon Bedrock 的[滥用检测](https://docs.aws.amazon.com/bedrock/latest/userguide/abuse-detection.html)和 Anthropic 的 [Covered Models](https://support.claude.com/en/articles/15425695-covered-models) 页面。Anthropic 还发布了 [Enterprise Frontier Safeguards](https://www.anthropic.com/news/enterprise-frontier-safeguards)，这一方案将让客户可以选择安全地部署 Anthropic 能力最强的模型，同时把数据保留在自己掌控的云基础设施中。下文「Enterprise Frontier Safeguards」一节将说明这在 Amazon Bedrock 上意味着什么。

本文介绍 Claude Fable 5.1 的改进、Enterprise Frontier Safeguards，以及如何在 Amazon Bedrock 上开始使用该模型构建应用。

## Claude Fable 5.1 有何不同

Anthropic 报告称，在 Anthropic 运行的最难推理测试中，Fable 5.1 相比 Fable 5 有明确提升。这些测试包括竞赛数学、工程与科学领域的研究生水平问题，以及可靠性至关重要的长链条多步骤问题。在日常使用中，这体现为在模糊任务上判断更好、自信却错误的回答更少：

- **Agentic coding（agentic 编码）。** 它能独自承担项目中更多的部分，从横跨整个代码库的功能开发，到代码审查与性能优化，并且能持续多个小时的工作会话。它也更为诚实：卡住时会直接说明，也更不容易为了让测试通过而禁用失败的测试。
- **Autonomous operation（自主运行）。** 为跨多个应用、持续数小时的任务而构建。它会制定计划、调用所需的工具、在某个步骤失败时恢复，并主动向你同步进展，无需你追问。
- **End-to-end knowledge work（端到端知识工作）。** 能把一项分析从最初的提问推进到成稿文档，自己完成调研、搭建电子表格、撰写备忘录或演示文稿，并在过程中核对数字。它面向日常的财务、会计和医疗健康工作而构建。
- **Scientific research（科学研究）。** 支持从文献梳理与假设提出，到建模、实验与形式化验证的完整研究活动。
- **Improved usability（可用性改进）。** 会在长时间任务中同步进展，文字表达更清晰，并且更严格地遵循指令。

## 数据保留

由于 Claude Fable 5.1 是 [Covered Model](https://support.claude.com/en/articles/15425695-covered-models)，其使用需遵守最长 30 天的数据保留，以及由 Amazon 人员执行的人工审查。使用 Amazon Bedrock 时，你可以通过账户或 Amazon Bedrock 项目上的模式控制数据保留，具体通过[数据保留 API](https://docs.aws.amazon.com/bedrock/latest/userguide/data-retention.html#data-retention-configuration) 配置。使用 Claude Fable 5.1 需要 `aws_review` 模式，你需要在调用模型之前设置该模式。在该模式下，AWS 会在 AWS 边界内保留你的 prompt 和输出，以便进行人工安全审查。Claude Fable 5.1 不要求与模型提供方共享数据。更多细节请参阅 [Amazon Bedrock 数据保留](https://docs.aws.amazon.com/bedrock/latest/userguide/data-retention.html)。

## Enterprise Frontier Safeguards（企业前沿保障）

[Enterprise Frontier Safeguards](https://www.anthropic.com/news/enterprise-frontier-safeguards)（EFS）由 AWS 与 Anthropic 合作构建，将帮助符合条件的客户使用 Claude Fable 5 和 Claude Fable 5.1 模型，同时把数据保留在自己掌控的云环境中。

如果你是符合 EFS 条件的客户，就可以在 Amazon Bedrock 和 Claude Platform on AWS 上以零数据保留（ZDR）方式使用 Claude Fable 5 和 Claude Fable 5.1。该能力至少到 2027 年 6 月 30 日都可用于内部用途。今年晚些时候还将提供更多 Enterprise Frontier Safeguards 能力，届时你可以把 prompt 和输出保存在自己的 AWS 账户中，由你自己的加密密钥、访问策略和审计日志来管理。安全监控将通过自动审查完成，无需人工审查。

## 在 Amazon Bedrock 上开始使用 Claude Fable 5.1

要试用 Fable 5.1，请打开 [Amazon Bedrock 控制台](https://console.aws.amazon.com/bedrock/)，进入 **Test > Playground**，并选择 Fable 5.1 作为模型。随后你就可以直接对它运行 prompt。

以编程方式调用时，你可以通过 Anthropic SDK 使用 [Anthropic Messages API](https://docs.aws.amazon.com/bedrock/latest/userguide/model-parameters-anthropic-claude-messages.html) 对 `bedrock-runtime` 发起调用。你也可以通过 [AWS Command Line Interface（AWS CLI）](https://aws.amazon.com/cli/)和 [AWS SDK](https://aws.amazon.com/developer/tools/)，继续使用 `bedrock-runtime` 上的 [Invoke](https://docs.aws.amazon.com/bedrock/latest/userguide/inference-api.html) 和 [Converse](https://docs.aws.amazon.com/bedrock/latest/userguide/conversation-inference.html) API。

### 前提条件

- 已启用 Amazon Bedrock 访问权限的可用 AWS 账户。
- 已安装并配置好的 AWS Command Line Interface（AWS CLI）。
- Python 3.10+。
- 已安装 Boto3：`pip install boto3`。
- AWS Identity and Access Management（IAM）权限：`bedrock:InvokeModel` 和 `bedrock:InvokeModelWithResponseStream`。

下面是一个使用 AWS SDK for Python（Boto3）的简单示例：

```
import boto3
import json

# Create a Bedrock Runtime client
bedrock_runtime = boto3.client(
    service_name="bedrock-runtime",
    region_name="us-east-1"
)

# Invoke Claude Fable 5.1
response = bedrock_runtime.invoke_model(
    modelId="global.anthropic.claude-fable-5-1",
    contentType="application/json",
    accept="application/json",
    body=json.dumps({
        "anthropic_version": "bedrock-2023-05-31",
        "max_tokens": 4096,
        "messages": [
            {
                "role": "user",
                "content": "An S3 bucket serves 40 TB/month egress. Estimate the monthly egress cost at $0.09/GB, and state one architecture change to cut it. Show the calculation, keep it under 120 words."
            }
        ]
    })
)

result = json.loads(response["body"].read())
# Fable 5.1 is a reasoning model: the response may include a thinking block
# before the text block, so select the text block rather than a fixed index.
print(next(b["text"] for b in result["content"] if b["type"] == "text"))
```

## 可用性

Claude Fable 5.1 今天已在 Amazon Bedrock 上通过 US Geo CRIS（us.）和 Global CRIS（global.）推理配置文件提供。在 AWS GovCloud (US) 中，它在 bedrock-runtime 和 bedrock-mantle 两个端点上均可用。完整支持区域列表请参阅 [Bedrock 文档](https://docs.aws.amazon.com/bedrock/latest/userguide/model-cards-anthropic.html)。定价信息请参阅 [Amazon Bedrock 定价](https://aws.amazon.com/bedrock/pricing/)。它也可在北美地区通过 Claude Platform on AWS 使用。

欢迎在 [Amazon Bedrock 控制台](https://console.aws.amazon.com/bedrock)、[Claude Platform on AWS](https://console.aws.amazon.com/claude-platform/) 中试用 Claude Fable 5.1，或在 GitHub 上浏览 [Getting Started notebooks](https://github.com/aws-samples/anthropic-on-aws/tree/main/notebooks)。
