# OpenAI 模型与 Codex 现已在 Amazon Bedrock 正式可用

GPT-5.5、GPT-5.4 和 Codex 现已在 Amazon Bedrock 正式可用。即日起，你可以在 Bedrock 的高性能推理引擎上，把它们部署到生产应用和 agent 中。

## 关键要点

- OpenAI 最先进的前沿模型 GPT-5.5 已在 Amazon Bedrock 正式可用，定价与 OpenAI 第一方价格一致。

- Amazon Bedrock 上的 Codex 已正式可用，采用按 token 付费的定价方式。推理通过 Bedrock 运行，用量计入你现有的 AWS 承诺额度。

在[扩大合作关系的公告](https://www.aboutamazon.com/news/aws/bedrock-openai-models)发布一个月后，GPT-5.5、GPT-5.4 和 Codex 现已在 [Amazon Bedrock](https://aws.amazon.com/bedrock/) 正式可用，让你能够获得前沿模型，以及用于软件开发的 OpenAI 编码 agent。

Amazon Bedrock 是用于在生产规模上构建和运行 AI 应用与 agent 的平台。[Bedrock 上的 OpenAI 模型](https://aws.amazon.com/bedrock/openai/)运行在 Amazon Bedrock 的下一代推理引擎上，该引擎专为高性能、可靠性和安全性而打造。

**Amazon Bedrock 上能力最强的 OpenAI 模型**

GPT-5.5 能更快把握你的意图，自主处理多步骤任务，在跨大型代码库编写与调试代码、分析数据、生成文档和电子表格，以及跨多个工具操作软件直至任务完成等方面表现突出。这些改进在 agentic 编码和知识工作中最为显著——在这些场景里，真正的进展取决于能否持续保持上下文并在较长时间内采取行动。

GPT-5.5 和 GPT-5.4 都专为复杂的多步骤任务而构建，如今已在 Amazon Bedrock 模型目录中提供。你可以通过 Amazon Bedrock 上的 Responses API 调用它们，并按与直接从 OpenAI 获取相同的每 token 费率付费，没有额外费用。

[Bedrock 的推理引擎](https://aws.amazon.com/blogs/machine-learning/exploring-the-zero-operator-access-design-of-mantle/)为你提供专属的隔离队列和自动化的容量管理，因此即使在重负载下，你的性能也能保持可预测。每个请求运行时，其完整状态都会被持久且持续地记录，因此如果硬件发生故障，或节点在调用中途重启，你的请求会从上次中断处继续，而不是从头开始。每次调用都继承你在 AWS 上已在使用的治理控制：IAM 权限、VPC 与 PrivateLink 隔离、KMS 加密和 AWS CloudTrail 审计日志。你的 prompt 和响应不会被用于训练模型，也不会与模型提供商共享。这些保护同样覆盖 Amazon Bedrock 上的 GPT-5.5 和 GPT-5.4。

> “在 Amgen，我们专注于以可能有助于加速潜在新疗法交付的方式应用先进 AI，同时为我们的团队配备先进的工具。OpenAI 的 GPT-5.5 和前沿模型在能力、质量和一致性方面带来了令人信服的进步，而在这个领域，问题复杂，对科学准确性和决策质量的标准异常之高。在 AWS 上提供这些模型，为我们提供了一条重要的新路径，可以在负责任的 AI 框架内探索并扩展这些能力，包括企业范围内的安全、治理和运营框架。”
>         – Sean Bruich，Amgen 高级副总裁兼首席技术官

**借助 Amazon Bedrock 上的 Codex 加速软件开发**

Codex 是 OpenAI 用于 AI 驱动软件开发的编码 agent。每周有超过 500 万人使用 Codex，在大型代码库中编写、重构、调试、测试和验证代码。Codex 能在整个仓库范围内保持上下文，对含糊的故障进行推理，使用工具核验假设，并在了解系统如何连接的前提下，把改动贯穿到周边代码中。在由 GPT-5.5 驱动推理的情况下，与之前的模型版本相比，Codex 完成同样的工作更高效，质量也更高。

[Amazon Bedrock 上的 Codex](https://developers.openai.com/api/docs/guides/amazon-bedrock)可通过 Codex App、Codex CLI，以及与 Visual Studio Code、JetBrains 和 Xcode 的 IDE 集成使用，所有模型推理都经由 Amazon Bedrock 路由。推理留在你所选的区域内，以满足数据驻留要求。你按 token 付费，没有席位许可，也没有按开发者的承诺用量，因此可以快速上手，并随需扩展访问量。

> “Autodesk 是为设计和建造我们周围世界的人们提供技术的平台。像建筑设计这样的工作流高度依赖迭代，需要团队之间保持精确、协同和持续优化。随着 OpenAI 模型和 Codex 现在在 Amazon Bedrock 上正式可用，我们的团队正在评估：可扩展、安全的 AWS 基础设施上的前沿 AI 能力和 AI 驱动的开发工具，如何帮助加速开发工作流，并为我们的客户支持更明智的决策。”
>         – Ritesh Bansal，Autodesk 分析数据、Agentic AI 与 AI/ML 平台副总裁。

## **后续计划**

在扩大合作关系的公告发布期间，我们推出了由 OpenAI 提供支持的 Amazon Bedrock Managed Agents。它即将推出，让你可以部署基于 OpenAI agent harness 构建的生产级 agent，带来更快的执行、更敏锐的推理，以及对长时间运行任务的可靠引导。每个 agent 都将以自己的身份运行，记录每一个操作以便审计，并且所有模型推理都在 Amazon Bedrock 上运行。如需了解最新进展，请通过[意向表](https://pages.awscloud.com/GLOBAL-ln-GC-openai-bedrock-interest.html)注册。

随着新的进展到来，我们将继续扩展 Amazon Bedrock 上可用的 OpenAI 能力。这包括 Daybreak——OpenAI 关于改变软件构建与防御方式的愿景。Daybreak 包含网络（cyber）模型和 Codex Security，旨在帮助网络防御者识别漏洞、审查代码风险，并在整个开发生命周期中指导修复。当 Daybreak 在 Bedrock 上可用时，安全团队将能够通过他们已在 AWS 上使用的治理和运营框架来采用它。

## **开始使用**

GPT-5.5 和 GPT-5.4 今天即可通过 Responses API 在 Amazon Bedrock 上使用。请查看 [AWS 区域页面](https://docs.aws.amazon.com/bedrock/latest/userguide/models-region-compatibility.html)了解可用性。有关文档和分步操作指南，请参阅 [Amazon Bedrock 文档](https://docs.aws.amazon.com/bedrock/latest/userguide/model-cards-openai.html)和[入门博文](https://aws.amazon.com/blogs/aws/get-started-with-openai-gpt-5-5-gpt-5-4-models-and-codex-on-amazon-bedrock)。
