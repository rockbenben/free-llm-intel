# Rox 借助由 Amazon Bedrock 驱动的 AI agent 提升销售生产力

*本文由 Rox 的 Shriram Sridharan、Taeuk Kang 和 Santhosh Kumar Manavasi Lakshminarayanan 共同撰写。*

[Rox](https://www.rox.com/) 正在为应用 AI 时代构建一套新的收入操作系统。

现代收入团队依赖比以往任何时候都更多的数据，例如客户关系管理（CRM）系统、营销自动化、财务系统、支持工单以及实时的产品使用数据。虽然每一类数据都有其作用，但它们叠加在一起就形成了数据孤岛，拖慢销售人员的节奏，也让洞察无从发掘。

Rox 通过提供一套收入操作系统来解决这一问题：这是一个统一层，把这些信号汇聚在一起，并让 AI agent 能够执行 go-to-market（GTM）工作流。销售人员无需再核对报表或更新字段，而是在日常工作流中获得实时智能与自动化。

今天，我们很高兴地宣布 Rox 已正式可用（generally available），其基础设施构建在 AWS 上，并通过 Web、Slack、macOS 和 iOS 交付。在本文中，我们分享 Rox 如何借助由 [Amazon Bedrock](https://aws.amazon.com/bedrock/) 驱动的 AI agent 提升销售生产力。

## 解决方案概览

正如 [Rox is transforming revenue teams with AI-driven integration powered by AWS](https://aws.amazon.com/startups/learn/how-rox-is-transforming-revenue-teams-with-ai-driven-integration-powered-by-aws) 一文所述，现代 GTM 团队需要的不是一个静态数据库。收入数据分布在数十个系统中，例如产品使用情况、财务和支持，团队需要一个能够统一上下文并实时对其采取行动的系统。

Rox 通过 AWS 上的分层架构实现这一点：

- **记录系统（system of record）** – 一个统一、受治理的知识图谱，汇聚 CRM、财务、支持、产品遥测和 Web 数据
- **Agent 集群（agent swarms）** – 智能且具有客户账户感知能力的 agent 在该图谱之上进行推理，并编排研究、外联、商机管理和提案生成等多步工作流
- **跨终端的界面** – 销售人员在自己工作所在的界面中即可参与这些工作流，例如 Web 应用、Slack、iOS 和 macOS

这把 CRM 从一个被动的记录系统转变为主动的行动系统，使团队能够立即且智能地基于数据采取行动。

## ROX 的收益与功能

Rox 现已正式可用，并通过 Command 把能力从智能延伸至完整执行——Command 是一个新的对话式界面，用于编排多 agent 工作流。Command 会与多个并行运行的专用 agent 协调。单个请求（例如“帮我为 ACME 续约做准备并起草跟进邮件”）会展开为一份计划：研究使用情况与支持信号、识别缺失的干系人、刷新信息补全、提出下一步最佳行动、起草外联内容、更新商机并组装提案。每个步骤都通过向你的系统发起工具调用完成，并受 guardrail 审批约束。我们全面的安全架构采用一套精密的多层 guardrail 系统，作为抵御不当、有害或恶意请求的第一道防线。传入的请求在到达推理层之前，会经由我们先进的过滤机制进行严格分析。这一预处理阶段会评估安全性与适当性的多个维度，例如法律合规评估和业务相关性评估，以确保只有合法、安全且在上下文中适当的请求才会进入模型执行。

Command 会拆解请求、把各步骤路由到合适的 agent、编排外部工具调用（CRM、日历、信息补全、邮件）的顺序、把结果归并到上下文系统中，并返回一条连贯的对话线程，可在 Web、Slack、iOS 或 macOS 上直接消费。每条建议都是可解释的（来源与追踪）、可回滚的（审计日志），并且具备策略感知能力（基于角色的访问控制、速率限制、必要审批）。

## Amazon Bedrock 如何支撑 Rox

Command 需要一个能够在多个步骤之间推理、编排工具并动态调整的模型。

为满足这些需求，Rox 选择了 Amazon Bedrock 上的 Anthropic Claude Sonnet 4。Anthropic 的 Claude Sonnet 4 持续展现出无可匹敌的工具调用与推理性能，使 Rox 的 agent 能够可靠地编排客户账户研究、信息补全、外联、商机管理和提案生成等工作流。

Amazon Bedrock 为企业级规模交付 Rox 提供了基础，带来安全性、与最新模型集成的灵活性，以及可靠处理数千个并发 agent 的可扩展性。

除 Command 之外，Rox 还包含以下功能：

- **Research** – 提供深入的账户与市场研究，以统一上下文为基础（延续自内测阶段）
- **Meet** – 支持录制、转写、总结会议，并把会议转化为行动（延续自内测阶段）
- **Outreach** – 提供个性化的潜在客户互动，由统一数据提供上下文（新增）
- **Revenue** – 帮助你在工作流中跟踪、更新和推进销售管道（新增）
- **Auto-fill proposals** – 帮助你在几秒钟内基于账户上下文组装量身定制的提案（新增）
- **Rox apps** – 提供模块化扩展，把专用工作流（看板、跟踪器）直接加入系统（新增）
- **iOS app** – 随时随地提供通知和会议准备（新增）
- **Mac app** – 带来转写通话并加入上下文系统的能力（新增）
- **Regional expansion** – 现已在 AWS 中东（巴林）AWS Region 上线，契合数据驻留与主权需求（新增）

- 销售代表生产力提升 50%
- 销售速度加快 20%
