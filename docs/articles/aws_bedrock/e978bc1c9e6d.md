# 从开发者桌面走向整个组织：在 Amazon Bedrock 上运行 Claude Desktop

***2026 年 6 月：本文已更新，以反映 Claude Desktop——包含 Claude Cowork、Claude Code 和 Chat——现已通过 Amazon Bedrock 提供***

今天，我们很高兴宣布 Amazon Bedrock 上完整的 Claude Desktop 体验。你现在可以通过 Amazon Bedrock 运行 Chat、Claude Cowork 和 Claude Code，既可以直连，也可以通过 LLM gateway 使用。

借助 Amazon Bedrock，你可以在现有的 AWS 环境中构建，保持企业级安全与区域数据驻留，并扩展推理规模。推理在你配置的 AWS 区域中运行，对话历史则存储在设备本地。

每个入口——Chat、Claude Cowork 和 Claude Code——都有各自的 policy key，因此管理员可以决定谁在什么时候获得什么。可以先让非技术团队使用 Chat 和 Claude Cowork，把 Claude Code 交给工程团队，并随着采用范围的扩大逐步放开访问。

在 Amazon Bedrock 上使用 Claude Desktop，你可以把 AI 的采用扩展到组织中的每一位知识工作者：Chat 用于快速答疑和梳理问题，Claude Cowork 用于跨已批准来源进行多步研究、处理文件并交付成型成果，Claude Code 则面向希望进行 agentic coding 而不必一直待在终端里的工程师。

在本文中，我们将介绍 Claude Desktop 如何与 Amazon Bedrock 集成，并展示一个知识工作者在实际工作中使用它的示例。

## 什么是 Claude Desktop

在 Amazon Bedrock 上使用 Claude Desktop，你的用户可以在桌面应用中把研究、文档分析、数据处理和报告生成委托给 Claude。他们可以获得完整的 [Claude Desktop](https://claude.com/resources/tutorials/navigating-the-claude-desktop-app) 体验，包括 [Chat](https://claude.com/resources/tutorials/navigating-the-claude-desktop-app#chat)、Claude Cowork 和 Claude Code。需要 Anthropic 托管推理的功能不在其列，包括 [Claude Design](https://support.claude.com/en/articles/14604416-get-started-with-claude-design)、Computer Use 和 Skills Marketplace，因为在这种配置下，Claude Desktop 的模型推理完全通过你 AWS 账户中的 Amazon Bedrock 路由。与 Claude Enterprise 的完整功能对比，请参阅 [Features on 3P](https://claude.com/docs/cowork/3p/feature-matrix)。

定价基于用量，通过你现有的 AWS 协议与账单结算，无需向 Anthropic 支付席位许可费用。

## Claude Desktop 如何与 Amazon Bedrock 集成

Amazon Bedrock 在你 AWS 账户内充当推理后端，可在[受支持的 AWS 区域](https://docs.aws.amazon.com/bedrock/latest/userguide/model-cards-anthropic.html)中使用。

在 Amazon Bedrock 上配置 Claude Desktop 分两步。第一步，用户在自己的机器上下载 [Claude Desktop](https://claude.ai/downloads) 应用。第二步，由你的设备管理系统（例如 Jamf、Microsoft Intune 或 Group Policy）向 Claude Desktop 推送一份配置，用来激活推理模式，并指定[模型 ID 和 Amazon Bedrock Inference Profile](https://docs.aws.amazon.com/bedrock/latest/userguide/model-cards-anthropic.html)、身份验证方式以及组织策略。如果你的组织通过 LLM gateway 集中管理模型访问，你可以用同一份受管配置把 Claude Desktop 指向该 gateway 的 URL。

如果你的组织已经在 Amazon Bedrock 中使用 Claude Code 进行构建，Claude Desktop 可以复用这套推理配置。

*图 1：下图展示了端到端流程*

该应用有三条出站路径，全部处于你的掌控之下。模型推理发往你配置的 AWS 区域中的 Amazon Bedrock。MCP 服务器连接（如果配置了）发往你批准的端点。Anthropic 只会收到聚合遥测数据（token 数、模型 ID、错误码、匿名设备标识符），这些数据可以通过配置选项关闭。

Amazon Bedrock 提供区域内、地理跨区域和全球跨区域的[推理配置文件](https://docs.aws.amazon.com/bedrock/latest/userguide/cross-region-inference.html#cross-region-inference-comparison)，你可以据此为组织选择合适的数据驻留级别。

Claude Desktop 可与你已经在使用的 AWS 服务配合工作：

- 通过 AWS IAM 或 [Amazon Bedrock API keys](https://aws.amazon.com/blogs/machine-learning/accelerate-ai-development-with-amazon-bedrock-api-keys/) 进行身份验证
- 通过 VPC endpoints 实现网络隔离
- 可观测性，可选通过[将 OpenTelemetry 导出到 Amazon CloudWatch](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/CloudWatch-OpenTelemetry-Sections.html)
- 通过 AWS CloudTrail 进行审计
- 统一的 AWS 账单结算，[并可实现细粒度的成本归因](https://aws.amazon.com/blogs/machine-learning/introducing-granular-cost-attribution-for-amazon-bedrock/)

有关 MDM 配置、凭证、MCP 服务器、插件以及激活 Chat 的详细信息，请参阅 [Claude Desktop 配置参考](https://claude.com/docs/third-party/claude-desktop/configuration)。

## Claude Desktop 的实际应用

完成集成配置后，用户打开 Claude Desktop 就可以开始委派工作。Claude Desktop 可以通过 MCP 服务器连接外部数据源，让 Claude 在工作过程中访问实时文档、web search 和其他工具。

例如，一位产品经理正在为一个托管在 AWS 上的高校体育应用规划新的通知功能。手头有指向各不相同的客户会议纪要、一套项目需求，以及用来调和这些材料的有限时间。他们把这些材料上传到 Cowork。

Claude 会对比这些差异颇大的输入，并把它们综合成一份产品简报。它会评估提议的方案、研究备选方案、指出技术挑战，并用证据支撑建议。在连接到 [AWS Documentation MCP server](https://github.com/awslabs/mcp/tree/main/src/aws-documentation-mcp-server) 和一个 web search MCP 服务器后，Claude 能让这份简报立足于当前的服务文档、市场背景和竞品定位。

*图 2：产品经理借助 Claude Cowork 把会议纪要变成产品简报*

几分钟后，这位产品经理就得到了一份结构清晰、基于最新来源、可供评审的简报。同样的模式也适用于其他知识工作者。运营经理可以把零散的文档整合成一份 SOP。财务分析师可以把原始数据变成格式规范的月度回顾。研究团队可以把多个来源的发现汇编成一份报告。

## 结论

借助 Amazon Bedrock 上的 Claude Desktop，你可以把 AI 的采用扩展到组织中的每一位知识工作者，同时让数据始终留在你的 AWS 环境中。在 [Amazon Bedrock 提供 Claude 模型](https://docs.aws.amazon.com/bedrock/latest/userguide/model-cards-anthropic.html)的 AWS 区域，Claude Desktop 可在 macOS 和 Windows 上使用。要开始使用，请从 [claude.com/download](http://claude.com/download) 下载 Claude Desktop，并参阅 [Claude Desktop 安装指南](https://claude.com/docs/cowork/3p/overview)。
