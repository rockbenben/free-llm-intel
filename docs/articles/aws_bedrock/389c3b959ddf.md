# 用 agentic AI 驱动的咨询加速企业方案：推出 AWS Professional Service Agents

AWS Professional Services 致力于通过专家指导与经过验证的方法论，帮助组织加速上云。今天，我们正处在咨询业的关键时刻。正如云计算改变了企业构建技术的方式，agentic AI 正在改变咨询服务创造价值的方式。我们相信这样一个未来：智能 agent 与专家顾问并肩工作，压缩开发周期、提升方案质量，并让组织更快实现数字化转型目标。要让这一愿景成为现实，需要对传统咨询模式做根本性的重新构想。基于我们大规模交付企业方案的经验，我很高兴宣布 AWS Professional Services 现已提供专门的 AI agent，包括 [AWS Professional Services Delivery Agent](https://aws.amazon.com/professional-services/)。这代表着咨询体验的一次转变：在整个咨询生命周期中内嵌智能 agent，为客户交付更大的价值。

## agent 优先的咨询方式

AWS Professional Services（AWS ProServe）在 agentic AI 上的新做法，从根本上改变了咨询业能做什么。通过把我们深厚的专业能力与专门的 AI agent 结合起来，我们交付企业方案的速度更快，同时保持客户所期待的严苛质量与安全标准。agent 让我们的顾问可以专注于最重要的事——理解客户独特的业务挑战、提供战略指导、推动有意义的成果——而实现细节则由 agent 以一致的方式和更快的速度处理。

我们已经开始通过 agent 改造客户项目，并在多个行业展现出可量化的影响。无论你是在构建下一代 AI 应用、把关键工作负载迁移上云，还是对现有系统做现代化改造，这些 agent 都能在保证质量的前提下，把时间线从数月压缩到数周——甚至从数周压缩到数天。

## 贯穿咨询周期的完整 agent 体系

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/11/14/ML-19984-1.png)

传统咨询模式很难在速度、质量与成本之间取得平衡。由专门 agent 组成的体系承载着 AWS 的机构知识与经过验证的方法论，有助于解决这一挑战。

**加速每个阶段的 AI agent**：该 agent 体系的核心是 AWS Professional Services Delivery Agent，一位由 AI 驱动的技术专家，作为技术项目的主要接口。Delivery Agent 会分析你的需求、直接构建 AI 应用，并通过把迁移与现代化任务委派给专用 agent 来编排专门工作，例如基于 [AWS Transform](https://aws.amazon.com/transform/) 构建的自定义 agent——AWS Transform 是面向企业迁移与现代化工作负载的 AWS agentic AI 服务。甚至在交付开始之前，一个销售 agent 就会简化提案生成与工作说明书（SOW）的创建，把传统上需要数周的工作压缩到数小时。在整个项目过程中，内嵌的能力确保方案符合企业级安全与合规标准。

**从需求到部署，创纪录的速度**：以一个典型的生成式 AI 应用开发项目为例。传统上，构建一个帮助客服代表快速获取政策信息的客服 agent，需要一个完整的咨询团队花 6-8 周收集需求、设计架构、开发代码并部署方案。Delivery Agent 会摄取你的需求——无论是详细文档、架构图，还是会议记录——并在数小时内产出与 AWS 最佳实践对齐的完整设计规范与实施计划。随后 agent 会生成代码、自动化测试并准备部署包，同时你的 AWS ProServe 顾问提供战略监督，确保与你的业务背景保持一致。

**大规模的迁移与现代化**：对迁移项目而言，引入 agent 带来的加速更为显著。设想一家医疗健康服务商要把 500 多个应用迁移到 AWS——传统上这是一项需要 12 个月以上、涉及大量调研与规划的工作。我们在 5 月推出 AWS Transform，帮助客户加速云转型之旅。在 AWS Transform 的基础上，并利用其可组合能力，我们构建了一个贴合 AWS ProServe 交付项目方式的自定义 agent。该 agent 融合了从 AWS ProServe 完成的数千次迁移中积累的知识库，以及加速项目交付的自动化能力。Delivery Agent 会分析工作说明书与项目产物，并为迁移调用该自定义 agent，由它自动处理波次规划、依赖关系映射、工作负载排期与 runbook 生成。你的 AWS ProServe 顾问保持战略监督，而 agent 把时间线压缩到仅几个月，同时始终保持严苛的安全与合规标准。

**构建在企业级 AI 基础设施之上**：该 agent 体系采用我们向客户提供的同样技术，包括 [Amazon Bedrock AgentCore](https://aws.amazon.com/bedrock/agentcore/)、AWS Transform，以及 [Kiro](https://kiro.dev/) 与 [Amazon Q Developer CLI](https://aws.amazon.com/q/developer/) 等先进开发工具。这有助于确保每个项目都能受益于行业领先的安全性（通过隔离的计算环境）、完整的可观测性（实现完全透明），以及可应对任意规模项目的可扩展性。

## 人类专业能力与 AI 加速相结合

AWS ProServe 的 agent 真正与众不同之处，在于它把人类专业能力的价值与 AI agent 的速度和一致性结合了起来。AWS ProServe 顾问仍然深度参与每个项目，包括理解你的业务背景、提供战略指导、做出关键决策，以及建立持久的合作关系。agent 通过处理实现细节、代码生成、测试与部署来放大他们的影响力，并把经过验证的 AWS 方法论直接内嵌到自身运作之中。

这种人机协作通过以下方式为客户创造价值：

- **前所未有的速度**：缩短项目时间线，用几天完成传统上需要数月的工作
- **一致的高水准**：每个方案都融入 AWS 最佳实践、架构模式与 Well-Architected Framework
- **更低的总成本**：精简的交付与更快的价值实现时间直接转化为更好的 ROI

与通用 AI 工具不同，这些 agent 承载着 AWS 的专门知识，包括由数千个过往项目沉淀出的数十年经验，以及经过验证的方法论。它从 AWS 庞大的机构知识库中汲取内容，并专门为企业级方案交付而设计。此外还有 AWS ProServe 的咨询专业能力作为支撑，确保每个方案都满足你独特的业务需求。

## 借助 agent 让业务转型落地

各行各业的组织已经通过与 AWS ProServe 的 agent 合作而看到成效，从快速开发 AI 应用到加速云迁移。美国国家橄榄球联盟（NFL）遇到了许多组织都熟悉的挑战：为服务数百万梦幻橄榄球（fantasy football）球迷构建 agent，同时兼顾速度与可靠性。他们与 AWS Professional Services 团队合作，使用 delivery agent，在短短几天内就部署出一个生产级原型，无缝整合 NextGen Stats、Player News、天气数据以及 NFL 的专有与公开信息，生成个性化的梦幻橄榄球推荐。

“构建一个服务数千名梦幻橄榄球球迷的 AI agent，既需要速度也需要可靠性。AWS Professional Services Delivery Agent 帮助我们两者兼得——我们在 8 周内从零走到生产，同时保持了 NFL 球迷所期待的质量标准。该框架自动化了日常开发任务，让我们的团队可以专注于性能优化，并交付由 NFL 专有数据驱动的独特洞察，”NFL Next Gen Stats 研究与分析高级经理 Mike Band 表示。

这种转变不仅体现在客户成果上，也改变了 AWS ProServe 交付咨询服务的方式。“我们在 AWS Transform 上的目标，一直是借助变革性的迁移新方法为客户带来更好的成果，”AWS Transform 副总裁 Asa Kalavade 表示。“AWS Professional Services 基于 AWS Transform 可组合基础构建的自定义 agent，完美体现了这一愿景。它针对 AWS ProServe 在客户账户中的工作方式交付定制化工作流，并通过基于目标、可交互的 agent 为每次迁移做个性化适配。无论是编排大型 VMware 迁移，还是为迁移数千台虚拟机的企业处理动态波次规划，这些 agent 都能适应每个客户独特的背景。这就是迁移的未来——更快、更个性化，并交付传统方法根本无法实现的成果。”

这代表着专业服务的未来：AI 增强的咨询，既能交付成果，又不牺牲复杂企业举措所需的战略指导与伙伴关系。

## 用 agentic AI 重新构想咨询的未来

这种新的 agent 驱动咨询方式，展示了把前沿 AI 技术用于改造自身运营时所能实现的可能性。当许多组织还在谈论 AI 未来可能做什么时，AWS ProServe 已经展示了 AI 今天能为企业带来什么。客户现在就可以通过与 AWS ProServe 及 AWS Professional Services 合作伙伴合作，体验新的 agent 驱动咨询模式。请联系你的 AWS 客户团队，或访问 [AWS Professional Services](https://aws.amazon.com/professional-services/) 网页，了解 AWS 如何加速你的数字化转型。
