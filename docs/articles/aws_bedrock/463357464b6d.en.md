# Amazon Polly delivers a major upgrade to its Generative engine

Amazon Polly Generative engine now offers more natural and accurate speech output. We’re introducing an upgrade to the [Amazon Polly Generative engine](https://docs.aws.amazon.com/polly/latest/dg/generative-voices.html) that delivers more expressive, more accurate speech output with low latency. The upgrade adds 14 new voices across 9 locales, including general availability of Generative voices in Hindi and Finnish for the first time. The upgrade is now generally available in production.

Importantly, this is a drop-in upgrade for existing generative voices. Voice names and API calls are unchanged, so your existing applications continue to work as they do today.

- **A larger catalog overall for Amazon Polly Generative engine** – Totaling 57 generative voices across 11 languages and 25 locales.
- **14 new voices** across 9 locales – US English (Kenneth, Nate), Australian English (Russell, Curtis), Indian English (Kiara, Arjun), German (Tina), US Spanish (Carlos), Brazilian Portuguese (Leo, Carolina), Korean (Hyunduk), Hindi (Kiara, Arjun) and Finnish (Suvi).
- **Net new languages generally available in Generative engine –** Hindi and Finnish.
- **Region expansion** to AWS GovCloud (US-West) – Totaling 11 AWS Regions.

## Built for production-ready speech workflows for enterprise

The upgraded Amazon Polly Generative engine uses a standard Amazon Polly API call to build your speech applications. With Amazon Polly, you can continue to build with familiar AWS patterns: call the same Amazon Polly API, manage access with AWS Identity and Access Management (IAM), use the output in your existing applications and contact-center flows, and monitor the workloads that synthesize speech for your customers.

This launch is designed to elevate the speech output quality that you can hear with your existing Amazon Polly implementation. No changes to your code are required to get the upgraded voices. For applications that already use Amazon Polly Generative voices, the upgrade happens in place. For new applications, the same `SynthesizeSpeech` API gives you access to a larger set of generative voice catalogs. With the Bi-Di Streaming API `StartSpeechSynthesisStream`, you can stream text to Amazon Polly and receive synthesized audio back simultaneously. This is well-suited for real-time applications like voice agents and bespoke characters in games.

## What you can build

**Contact centers.** Accuracy matters most in customer service conversations. When a caller checks an order, a voice that reads back the tracking number, address, and confirmation code correctly helps resolve the call in self-service rather than escalating to a human agent. Amazon Polly Generative voice’s accurate entity pronunciation and low-latency generation make automated interactive voice response (IVR) interactions sound more conversational.

**Cascaded voice agents.** Using Amazon Polly in a voice agent framework, you can convert LLM response text into clear, natural-sounding speech and stream it back to users in near real time over WebSockets or telephony channels. This makes live conversational voice possible. The primary benefits are low-latency playback, high scalability, and cost efficiency.

**Media, localization, and dubbing.** Convert scripts into finished audio for video, advertising, podcasts, product overviews, and audiobooks. You can use one voice or many, without a studio session. More natural intonation reduces post-production. The expanded locale coverage, including first-time generative Hindi and Finnish, means you can localize a single piece of content into more markets from the same pipeline.

**E-learning and training.** Narrate courseware, onboarding, and knowledge-based articles at scale, and update them as soon as the source text changes. No re-recording is required. More expressive delivery supports engagement through long-form material.

**Accessibility.** Provide a clear, natural spoken version of articles, documents, and applications so more people can consume your content by listening: read aloud, on the go, or with a screen reader.

**Interactive and transactional experiences.** Voice-enable games, kiosks, IVR menus, and IoT devices with responses generated on demand. Use Amazon Polly when the voice needs to sound natural and read names, numbers, product details, addresses, and confirmations reliably.

## Getting started

You can access the new voices using the [AWS Management Console](https://console.aws.amazon.com/), [AWS Command Line Interface (AWS CLI)](https://aws.amazon.com/cli), or the AWS SDKs.

Prerequisites:

- Active AWS account with Amazon Polly access.
- AWS Command Line Interface (AWS CLI) installed and configured.
- Python 3.10+.
- Boto3 installed: `pip install boto3`.
- AWS Identity and Access Management (IAM) permissions: `polly:SynthesizeSpeech`.

Here’s a quick example using the AWS SDK for Python (Boto3) with the `SynthesizeSpeech` API and a generative voice:

```
import boto3

polly = boto3.client("polly", region_name="us-east-1")

response = polly.synthesize_speech(
    Text="Hello! This is Amazon Polly's next-generation generative voice.",
    VoiceId="Kenneth",  # any generative voice in the catalogue
    Engine="generative",
    OutputFormat="mp3",
)

with open("speech.mp3", "wb") as f:
    f.write(response["AudioStream"].read())
```

You can also make the same request with the AWS CLI:

```
aws polly synthesize-speech \
  --region us-east-1 \
  --voice-id Kenneth \
  --engine generative \
  --output-format mp3 \
  --text "Hello! This is Amazon Polly's next-generation generative voice." \
  speech.mp3
```

To retrieve the full, current voice list programmatically, call `DescribeVoices`. You can use this in deployment checks to confirm that a selected generative voice is available in the Region where your application runs.

## Availability

The next-generation Generative engine and the new voices are now generally available. The 14 new Generative voices are available in the following AWS Regions: US East (N. Virginia), US West (Oregon), Europe (Frankfurt), Europe (Zurich), Europe (London), Asia Pacific (Sydney), Asia Pacific (Seoul), Asia Pacific (Singapore), Asia Pacific (Tokyo), Canada (Central), and AWS GovCloud (US-West). Getting started, by audience:

- **Developers** – Call `synthesize_speech` with `Engine="generative"` in your existing application. No other changes are required.
- **Contact-center teams** – The improvements reach **Amazon Connect** and **Genesys** flows automatically.
- **Everyone** – Access any voice in the [Amazon Polly console](https://console.aws.amazon.com/polly/).

A few things to know:

- **Standard and neural voices are unaffected.**
- **Speech marks are not available on generative voices** (unchanged from today). If your application requires them, standard and neural voices continue to support them.
- **Generative engine continues to support SSML tags.** See [supported SSML tags](https://docs.aws.amazon.com/polly/latest/dg/supportedtags.html) for more details.
- **Use current voice availability at runtime.** Call `DescribeVoices` or check the console when deploying across Regions.
