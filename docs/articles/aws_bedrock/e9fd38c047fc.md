# 来自 Inception Labs 的 Mercury 基础模型现已在 Amazon Bedrock Marketplace 和 Amazon SageMaker JumpStart 中可用

今天，我们欣然宣布，来自 Inception Labs 的 Mercury 和 Mercury Coder 基础模型（FM）现已通过 [Amazon Bedrock Marketplace](https://aws.amazon.com/bedrock/marketplace/) 和 [Amazon SageMaker JumpStart](https://aws.amazon.com/sagemaker/jumpstart/) 提供。借助本次发布，你可以部署 Mercury FM，在 AWS 上构建、试验并负责任地扩展你的生成式 AI 应用。

在本文中，我们将演示如何在 Amazon Bedrock Marketplace 和 SageMaker JumpStart 上开始使用 Mercury 模型。

## Mercury 基础模型简介

Mercury 是首个商业规模的基于扩散的语言模型系列，在保持高质量输出的同时，在生成速度上带来了突破性进展。与每次只生成一个 token 的传统自回归模型不同，Mercury 模型采用扩散方式，通过由粗到细的方法并行生成多个 token，从而实现大幅提升的推理速度。Mercury Coder 模型具备以下关键特性：

- 在 NVIDIA H100 GPU 上提供高达每秒 1,100 个 token 的超快生成速度，比同类模型快最多 10 倍
- 在多种编程语言中生成高质量代码，包括 Python、Java、JavaScript、C++、PHP、Bash 和 TypeScript
- 在中间填充（fill-in-the-middle）任务上表现强劲，非常适合代码补全与编辑工作流
- 基于 Transformer 的架构，可与现有优化技术和基础设施兼容
- 开箱即支持最长 128,000 个 token 的上下文长度

## 将 Mercury 用于工具使用和函数调用

Mercury 模型支持高级工具使用能力，能够根据用户查询智能地判断何时以及如何调用外部函数。这使它们非常适合构建可与外部系统、API 和数据库交互的 AI agent 和助手。
