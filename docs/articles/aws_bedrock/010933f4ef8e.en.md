Corrected the Reasoning entry on the

Claude Sonnet 5

model card, which incorrectly stated that adaptive thinking is always on and cannot be disabled. On Claude Sonnet 5, adaptive thinking is on by default — including for requests that omit the

thinking

field — and can be turned off by passing

"thinking": {"type": "disabled"}

. Added Claude Sonnet 5 to the supported models table on the

Adaptive thinking

topic, and added guidance covering the default-on behavior change from Claude Sonnet 4.6, the fact that only the explicit

disabled

thinking type turns thinking off (omitting the

thinking

field selects adaptive thinking, and

budget_tokens

is not supported on this model), that thinking tokens are billed as output tokens, and the need to revisit

max_tokens

for workloads migrated from Claude Sonnet 4.6.
