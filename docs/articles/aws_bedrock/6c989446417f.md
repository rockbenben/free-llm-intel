# Mistral-Small-3.2-24B-Instruct-2506 现已在 Amazon Bedrock Marketplace 和 Amazon SageMaker JumpStart 上可用

今天，我们很高兴地宣布，Mistral-Small-3.2-24B-Instruct-2506——一款来自 [Mistral AI](https://mistral.ai/)、拥有 240 亿参数、针对更强的指令遵循能力和更少的重复错误进行了优化的大语言模型（LLM）——现已通过 [Amazon SageMaker JumpStart](https://aws.amazon.com/sagemaker/jumpstart/) 和 [Amazon Bedrock Marketplace](https://aws.amazon.com/bedrock/marketplace/) 向客户提供。Amazon Bedrock Marketplace 是 [Amazon Bedrock](https://aws.amazon.com/bedrock) 中的一项能力，开发者可以用它来发现、测试并使用 100 多个热门、新兴和专用的基础模型（FM），与 Amazon Bedrock 中现有的行业领先模型一并使用。

本文介绍如何通过 Amazon Bedrock Marketplace 以及使用 SageMaker JumpStart 来发现、部署和使用 Mistral-Small-3.2-24B-Instruct-2506。

## Mistral Small 3.2（2506）概览

[Mistral Small 3.2（2506）](https://huggingface.co/mistralai/Mistral-Small-3.2-24B-Instruct-2506) 是 [Mistral-Small-3.1-24B-Instruct-2503](https://huggingface.co/mistralai/Mistral-Small-3.1-24B-Instruct-2503) 的更新版本，保持相同的 240 亿参数架构，同时在关键领域带来改进。该模型以 Apache 2.0 许可证发布，在性能与计算效率之间保持平衡。Mistral 以 Apache 2.0 提供该模型的预训练（Mistral-Small-3.1-24B-Base-2503）和指令微调（Mistral-Small-3.2-24B-Instruct-2506）两个 checkpoint。

Mistral Small 3.2（2506）的主要改进包括：

- 根据 Mistral 的基准测试，遵循精确指令的准确率提升至 84.78%，而 3.1 版本为 82.75%
- 无限生成或重复答案减少了一半，据 Mistral 称从 2.11% 降至 1.29%
- 为结构化 API 交互提供更健壮、更可靠的函数调用模板
- 现在包含图文到文本（image-text-to-text）能力，使模型能够同时处理并推理文本输入和视觉输入。这使它非常适合文档理解、视觉问答和以图像为依据的内容生成等任务。

这些改进使该模型特别适合 AWS 上对可靠性和精确度要求极高的企业应用。凭借 128,000 个 token 的上下文窗口，该模型可以处理大量文档，并在更长的对话中保持上下文。

我们定义了辅助函数，以使用 Amazon Bedrock Converse API 调用该模型：

```
def get_image_format(image_path):
    with Image.open(image_path) as img:
        # Normalize the format to a known valid one
        fmt = img.format.lower() if img.format else 'jpeg'
        # Convert 'jpg' to 'jpeg'
        if fmt == 'jpg':
            fmt = 'jpeg'
    return fmt

def call_bedrock_model(model_id=None, prompt="", image_paths=None, system_prompt="", temperature=0.6, top_p=0.9, max_tokens=3000):
    
    if isinstance(image_paths, str):
        image_paths = [image_paths]
    if image_paths is None:
        image_paths = []
    
    # Start building the content array for the user message
    content_blocks = []

    # Include a text block if prompt is provided
    if prompt.strip():
        content_blocks.append({"text": prompt})

    # Add images as raw bytes
    for img_path in image_paths:
        fmt = get_image_format(img_path)
        # Read the raw bytes of the image (no base64 encoding!)
        with open(img_path, 'rb') as f:
            image_raw_bytes = f.read()

        content_blocks.append({
            "image": {
                "format": fmt,
                "source": {
                    "bytes": image_raw_bytes
                }
            }
        })

    # Construct the messages structure
    messages = [
        {
            "role": "user",
            "content": content_blocks
        }
    ]

    # Prepare additional kwargs if system prompts are provided
    kwargs = {}
    
    kwargs["system"] = [{"text": system_prompt}]

    # Build the arguments for the `converse` call
    converse_kwargs = {
        "messages": messages,
        "inferenceConfig": {
            "maxTokens": 4000,
            "temperature": temperature,
            "topP": top_p
        },
        **kwargs
    }

    
    converse_kwargs["modelId"] = model_id

    # Call the converse API
    try:
        response = client.converse(**converse_kwargs)
    
        # Parse the assistant response
        assistant_message = response.get('output', {}).get('message', {})
        assistant_content = assistant_message.get('content', [])
        result_text = "".join(block.get('text', '') for block in assistant_content)
    except Exception as e:
        result_text = f"Error message: {e}"
    return result_text
```

## 函数调用示例

以下示例展示了 Mistral Small 3.2 的函数调用能力：它演示了模型如何识别用户问题何时需要外部数据，并以正确的参数调用正确的函数。我们的 prompt 和输入 payload 如下：

}
