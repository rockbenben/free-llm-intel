# Amazon Polly 推出语音克隆：为品牌打造独一无二的声音

Amazon Polly 的语音克隆现已作为受限发布正式可用。只需向 Amazon Polly 提供一位已同意被克隆语音的说话者几分钟的录音，它就能用这个人的声音构建出属于你的克隆语音。克隆语音运行在 Amazon Polly 生成式引擎上，自然度与准确性和其余生成式语音相当。Amazon Polly 语音克隆首发支持七种语言：英语、西班牙语、德语、法语、意大利语、葡萄牙语和印地语。每条克隆语音只说录制时所使用的语言。克隆语音自动加密并受访问控制：只有你能访问自己的克隆语音。

Amazon Polly 语音克隆在 Amazon Polly 生成式引擎支持的所有 AWS 区域可用，包括 AWS GovCloud（美国）区域。部分 Amazon Polly 客户已获开通访问权限。其他客户可以联系其 AWS 账户团队，或[申请访问权限](https://pages.awscloud.com/amazon-polly-voice-cloning-20261119.html)以获取访问权限。

有了这项新功能，你可以把克隆生命周期纳入 AWS 应用。对 Amazon Polly 客户而言，构建一条克隆语音是免费的；克隆语音的使用则按用量计费，详见 [Amazon Polly 定价页面](https://aws.amazon.com/polly/pricing/)。

## 亲耳听听

## 你可以构建什么

**跨渠道一致的品牌语音**

确立一条辨识度高的语音，用在交互式语音应答（IVR）系统、级联语音 agent、移动应用、店内广播、广告和联网设备上。不必依赖通用的现成语音，也不必每次改脚本就重约一次录音，你可以按需生成符合品牌的音频，在每个渠道都保持一致的听感。

**联络中心**

在自助服务 flow 中提供独特、贴合品牌的语音，并在优惠和政策变化时更新 prompt，无需再进录音棚。你可以从源文本创建 prompt，上线前先测试，并让问候、路由和通知环节共用同一条语音。

**大规模媒体与内容**

创作者、出版方和工作室可以用多条自定义语音制作有声书、课程、播客、游戏角色和视频，提升收听体验，并快速产出后续章节或更新。

**保持人设一致的本地化**

在内容库中维持可辨识的语音身份，让旁白在不同作品和更新之间保持连贯。每条克隆语音只说自己录制时使用的语言。要做多语言体验，请按支持的每种语言分别创建并审核已获批准的语音。

**无障碍与个性化**

为阅读体验、辅助工具和个性化交互提供自然、接近人声的语音。每次创建语音时，你都要确认说话者的同意。

## 语音克隆如何运作

借助语音克隆，你可以用单个说话者的录音构建自定义 Amazon Polly 语音，再通过 Amazon Polly 生成式引擎用这条语音合成语音。从录制说话者到使用成品语音，一共四步：

![语音克隆生命周期：录制、创建、等待、使用](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/11/19/ML-22432-1.png)

图 1：语音克隆生命周期，从录制说话者到使用成品语音

一条克隆语音要经过四个步骤：

- **录制。** 录制一位说话者（见下文录制建议）。录音可以直接放在 `CreateVoice` 请求里发送，也可以在控制台上传，或存到目标语音所在 AWS 区域的 Amazon Simple Storage Service（Amazon S3）存储桶中，再让 Amazon Polly 指向它。
- **创建。** 调用 `CreateVoice`，带上 1-10 段录音、录音所用语言和 `TermsAccepted=True`——后者是你对已取得说话者同意的确认。Amazon Polly 会立即返回语音 ID（`vc-…`），并在后台构建语音。
- **等待。** 创建是异步的，通常要 5-10 分钟。这段时间里，Amazon Polly 还会检查文本转语音（TTS）语音与说话者的相似度。你要反复调用 `GetVoice`，直到状态从 `pending` 变为 `active` 或 `failed`。
- **使用。** 把语音 ID 传给 `SynthesizeSpeech` 生成实时音频，或传给 `StartSpeechSynthesisTask` 把长音频写入 S3，并指定 `Engine="generative"`，调用方式与 Amazon Polly 其他生成式语音相同。不再需要这条语音时，调用 `DeleteVoice`。

## 同意与控制

克隆语音由一个人的录音制成。你要确认已取得说话者对全部录音的同意，并确认由你掌控谁可以使用该语音、何时删除。

- 每创建一条语音，你都要确认同意。在控制台创建，或在 API 中传 `TermsAccepted=True`，即表示你确认已取得创建和使用该克隆语音所需的全部权利与同意。你对语音克隆的使用受 [AWS 服务条款](https://aws.amazon.com/service-terms/)、[生物识别通知与同意条款](https://aws.amazon.com/legal/biometric-notice-and-consent-terms)、[AWS 负责任 AI 政策](https://aws.amazon.com/ai/responsible-ai/policy/)和 [AWS 可接受使用政策](https://aws.amazon.com/aup/)约束。
- 生成的语音带水印。Amazon Polly 会为用克隆语音生成的文本转语音音频添加水印。
- 只有你的账户能用。克隆语音限定在创建它的 AWS 账户内，访问权限由 AWS Identity and Access Management（IAM）控制。你可以用自己的 AWS Key Management Service（AWS KMS）密钥加密语音，并为其打标签。
- 何时删除由你决定。语音处于活动状态或创建失败后，一次 `DeleteVoice` 调用或在控制台上操作即可删除。
- 语音创建完成后，Amazon Polly 不再保留你的录音副本，也不会用它们训练 Amazon Polly 模型。它只保留合成语音所需的语音数据，并加密存储。你可以用自己的 AWS KMS 密钥做这层加密，`DeleteVoice` 会立即删除数据。

我们建议你：

- 保存每位说话者的同意记录。
- 说话者撤回同意时删除该语音。
- 在合适的场合告知听众他们听到的是合成语音。
- 只把语音权限授予真正需要的人和系统。

关于预期用途与限制，请参阅 [Amazon Polly AI 服务卡](https://docs.aws.amazon.com/ai/responsible-ai/amazon-polly/overview.html)与 [AWS 负责任地使用 AI](https://aws.amazon.com/ai/responsible-ai/) 指引。

## 录音最佳实践

你的克隆语音会从录音里学东西，包括你并不想让它学的部分：笔记本风扇声、房间回声、会议应用的降噪。

- 录 2 到 10 分钟自然说话，切成每段不超过 1 分钟的片段。每条语音最多提交 10 段录音，音频总时长不超过 15 分钟。质量比长度重要：音频更多，未必会改变语音的听感。
- 一位说话者、安静的房间、与麦克风保持同一距离。用 USB 麦克风，或用能录 WAV 的手机应用。从一开始就录单声道 WAV、16 位、24 kHz，省得之后再转换。Amazon Polly 也接受其他音频格式，但我们推荐 WAV。支持的格式与限制见 [Amazon Polly 开发人员指南](https://docs.aws.amazon.com/polly/latest/dg/what-is.html)。
- 避免用会议应用和浏览器录音器。它们的回声消除和噪声抑制会改变声音，克隆也会把这些改变学进去。
- 每一段都用你希望语音具备的风格录制。克隆语音的风格取自录音，无法把几种风格混合起来，所以欢快、悲伤、愤怒混着录，得不到一条三种都会的语音。
- 用语音应该说的语言录制。语音克隆已用美式英语、德语、美式西班牙语、法语、意大利语、巴西葡萄牙语和印地语的录音测试过。这些语言的其他口音（如英式英语、加拿大法语）也能用，但测试较少，请用你自己的内容验证。

## 开始使用

**在控制台上：** 账户开通语音克隆后（见「可用性」），展开左侧面板选择 **Voice cloning**，上传最多 10 段录音，或从 Amazon S3 中选择，确认条款后选择 **Create**。每次上传最大 5 MB。语音就绪后，可在其详情页试听。

**在代码中**，你需要：

- 最新版本的 boto3（`pip install --upgrade boto3`）。
- `polly:CreateVoice`、`polly:GetVoice`、`polly:DescribeVoices`、`polly:SynthesizeSpeech` 和 `polly:DeleteVoice` 的 IAM 权限。处理长音频时，还需要 `polly:StartSpeechSynthesisTask`、`polly:GetSpeechSynthesisTask`，以及对输出存储桶的 `s3:PutObject` 权限。
- 对于下面的 Amazon S3 示例：录音要放在创建语音所在区域的存储桶中，且调用 `CreateVoice` 的 IAM 角色或用户具备 `s3:GetObject` 权限。

```
import time

import boto3

# Use the Region of your S3 recordings.
polly = boto3.client("polly", region_name="us-east-1")

# 1. Create a voice from recordings of a speaker who has given consent.
#    Use 1-10 clean WAV takes of up to a minute each.
takes = [
    "s3://amzn-s3-demo-bucket/brand-voice/take-1.wav",
    "s3://amzn-s3-demo-bucket/brand-voice/take-2.wav",
    "s3://amzn-s3-demo-bucket/brand-voice/take-3.wav",
]
voice = polly.create_voice(
    Name="MyBrandVoice",    # letters, digits, - and _, up to 64 characters
    LanguageCode="en-US",   # the language spoken in the recordings
    TermsAccepted=True,     # you confirm the speaker's consent and the terms of use
    VoiceCreationData={
        "Recordings": [{"Format": "wav", "Data": {"S3Url": url}} for url in takes],
    },
    Tags={"consent-record": "speaker-0042"},  # optional: the ID of your own consent record, e.g. a signed release
    # Optional: encrypt the voice with your own KMS key (symmetric, same Region).
    # Callers who create or use the voice need kms:DescribeKey,
    # kms:GenerateDataKey and kms:Decrypt on the key.
    # CustomerManagedEncryption={
    #     "KmsKeyArn": "arn:aws:kms:us-east-1:111122223333:key/EXAMPLE"
    # },
)["Voice"]
voice_id = voice["Id"]      # for example "vc-0123456789"

# 2. Check the status every 30 seconds until the voice is active or failed
#    (usually a few minutes). Stop with an error after 20 minutes.
deadline = time.monotonic() + 20 * 60
while voice["Status"] not in ("active", "failed"):
    if time.monotonic() > deadline:
        raise TimeoutError(f"{voice_id} is still {voice['Status']}")
    time.sleep(30)
    voice = polly.get_voice(VoiceId=voice_id)["Voice"]
if voice["Status"] == "failed":
    # Check the recordings, delete this voice and create a new one.
    raise RuntimeError(f"{voice_id}: {voice.get('StatusReason', 'creation failed')}")

# 3. Synthesize speech with your new voice.
speech = polly.synthesize_speech(
    VoiceId=voice_id,
    Engine="generative",
    LanguageCode="en-US",
    OutputFormat="mp3",
    Text="Hello! This is my very own Amazon Polly voice.",
)
with open("my-voice.mp3", "wb") as f:
    f.write(speech["AudioStream"].read())

# When you no longer need the voice:
# polly.delete_voice(VoiceId=voice_id)
```

如果 Python 报 `Polly` 对象没有 `create_voice` 属性，请升级 boto3。

有声书章节、课程模块这类长文本，请用异步合成任务把音频写入 S3：

```
from pathlib import Path

task = polly.start_speech_synthesis_task(
    VoiceId=voice_id,
    Engine="generative",
    LanguageCode="en-US",
    OutputFormat="mp3",
    OutputS3BucketName="amzn-s3-demo-bucket",
    OutputS3KeyPrefix="narration/chapter-01",
    Text=Path("chapter-01.txt").read_text(encoding="utf-8"),
    # SnsTopicArn="arn:aws:sns:us-east-1:111122223333:polly-tasks",  # notify instead of polling
)["SynthesisTask"]
print(task["TaskId"], task["OutputUri"])  # poll get_speech_synthesis_task until "completed" or "failed"
```

## 生产环境注意事项

**提前创建语音**

语音创建要花几分钟，应把它当作预置步骤，而不是用户请求的一部分。一个小工作流（例如 AWS Step Functions 或作业队列）可以调用 `CreateVoice`，每 30 秒查一次 `GetVoice` 直到语音处于活动状态，再把语音 ID 写入你的配置。`CreateVoice` 和 `DeleteVoice` 共享每秒 1 个请求的限制，因此批量创建和删除要排队。

**维护清单**

`DescribeVoices` 会把你的克隆语音与 Amazon Polly 内置语音一并列出，克隆语音的 `Origin` 为 `customer`。为每条语音记录语音 ID、区域、语言、同意凭据和所有者，并给每条语音起唯一的 `Name`。如果 `CreateVoice` 调用超时或返回服务器错误，语音可能已经存在，而 SDK 的自动重试还可能再建一条。重试之前，先用 `DescribeVoices` 查一下这个名字。

**为错误做准备**

超过与 `DeleteVoice` 共享的每秒 1 个请求限制时，`CreateVoice` 返回 `ThrottlingException`；账户在该区域的克隆语音配额用尽时，返回 `ServiceQuotaExceededException`。对仍在创建中的语音做合成或删除，会返回 `ConflictException`。如果语音使用你自己的 KMS 密钥，无法访问该密钥的调用方会得到访问被拒绝的错误。创建失败时，`StatusReason` 只给一句笼统的说明，请按前面的录音最佳实践检查录音，然后删除失败的语音并重新创建。

**把权限限定到语音**

克隆语音是 IAM 资源，因此可以只授给服务流量的角色「用某一条语音合成」的权限。如果该语音使用你自己的 KMS 密钥，这个角色还需要访问该密钥。`polly:CreateVoice` 和 `polly:DeleteVoice` 留给单独的预置角色。下面是服务角色的示例策略：

```
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": "polly:SynthesizeSpeech",
      "Resource": "arn:aws:polly:us-east-1:111122223333:voice/vc-0123456789"
    }
  ]
}
```

借助标签，你可以用 `aws:ResourceTag` 条件为一整组语音只写一条规则。也请检查现有策略：一条允许对全部资源（`"Resource": "*"`）执行 `polly:SynthesizeSpeech` 的语句，同样覆盖账户里的每一条克隆语音。

**规划配额与区域**

每个账户在每个区域初始有 10 条克隆语音的配额。要申请提升，请联系你的账户团队或 [AWS Support](https://aws.amazon.com/contact-us/)。语音只存在于创建它的账户和区域内。要为另一个区域或账户提供服务，请用同一批录音在那个区域重新创建语音，并确保说话者的同意覆盖每一份副本。

**用真实脚本测试**

语音上线之前，先听它读你自己的内容：产品名、数字、地址，以及你手里最长的句子。同一段文本在不同请求之间可能略有出入。对于电话问候语这类固定 prompt，建议生成一次音频，由说话者和品牌团队确认后直接提供存储好的文件。如果某个名字或术语读错，可以换个拼法，或使用语音合成标记语言（SSML）的 `<phoneme>` 标签。音素标签可用于英语、法语、意大利语、德语和西班牙语的克隆语音。参见[支持的 SSML 标签](https://docs.aws.amazon.com/polly/latest/dg/supportedtags.html)。

| **语言** | 英语、德语、西班牙语、法语、意大利语、葡萄牙语和印地语。已测试的录音区域设置：美式英语（`en-US`）、德语（`de-DE`）、美式西班牙语（`es-US`）、法语（`fr-FR`）、意大利语（`it-IT`）、巴西葡萄牙语（`pt-BR`）和印地语（`hi-IN`）。这些语言的其他口音也可用，但测试较少。每条语音只说自己录制时使用的语言。 |
| **录音** | 每条语音 1-10 段录音，总时长不超过 15 分钟。推荐 WAV：单声道、16 位、24 kHz 或 44.1/48 kHz。Amazon Polly 也接受其他音频格式。控制台上传每个文件限 5 MB，更大的文件请用 Amazon S3。 |
| **数据处理** | 语音创建完成后，Amazon Polly 会删除你的录音副本，也不会用它们训练 Amazon Polly 模型。它只保留合成所需的语音数据，加密存储（可用你自己的 AWS KMS 密钥），直到你调用 `DeleteVoice`。 |
| **创建时间** | 构建 TTS 语音通常需要 5-10 分钟，异步进行。 |
| **合成延迟** | 与 Amazon Polly 的生成式语音相同。 |
| **配额** | 每个账户在每个 AWS 区域初始为 10 条克隆语音。要申请提升，请联系 AWS Support。`CreateVoice` 与 `DeleteVoice` 共享每秒 1 个请求的限制。 |
| **合成** | 克隆语音遵循 Amazon Polly 对生成式语音的配额，包括每次请求和每个合成任务的文本上限。参见 [Amazon Polly 配额](https://docs.aws.amazon.com/polly/latest/dg/limits.html)。 |
| **定价** | 创建克隆语音免费。克隆语音的使用由 Amazon Polly 按用量计费。参见 [Amazon Polly 定价](https://aws.amazon.com/polly/pricing/)。 |
| **API** | 用 `CreateVoice`、`GetVoice`、`DeleteVoice` 和 `DescribeVoices` 管理语音；用 `SynthesizeSpeech` 和 `StartSpeechSynthesisTask` 并指定 `Engine="generative"` 使用语音。参见 [Amazon Polly API 参考](https://docs.aws.amazon.com/polly/latest/dg/API_Reference.html)。 |

## 结论

Amazon Polly 的语音克隆让你的应用拥有一条人们认得出的语音：录制一次，取得说话者同意，就能通过 Amazon Polly API 使用。要在控制台上开始，请确认账户已开通 Voice cloning，准备好录音和所需的同意，打开 [Amazon Polly 控制台](https://console.aws.amazon.com/polly/)，创建第一条克隆语音。如果你是新客户并希望开通语音克隆，请联系你的 AWS 账户团队，或[申请访问权限](https://pages.awscloud.com/amazon-polly-voice-cloning-20261119.html)以获取访问权限。

开发人员指南见 [Amazon Polly 文档](https://docs.aws.amazon.com/polly/)。定价请见 [Amazon Polly 定价页面](https://aws.amazon.com/polly/pricing/)。想了解用 Amazon Polly（含语音克隆）还能做哪些语音 AI 用例，请查看 [GitHub 仓库](https://github.com/aws-samples/amazon-ai-samples/tree/main/text-to-speech)。
