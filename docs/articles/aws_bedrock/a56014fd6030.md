# Amazon Polly 推出声音克隆：为您的品牌打造独一无二的声音

Amazon Polly 中的声音克隆现已作为受限发布正式可用。向 Amazon Polly 提供一位已同意克隆其声音的说话者几分钟的音频录音，Amazon Polly 就会构建出以该说话者声音为基础的您自己的克隆声音。克隆声音运行在 Amazon Polly 生成式引擎上，其自然度和准确性与其他生成式声音相似。Amazon Polly 声音克隆发布时支持七种语言：英语、西班牙语、德语、法语、意大利语、葡萄牙语和印地语。每个克隆声音只说其录制时使用的语言。克隆声音会自动加密并受访问控制：只有您能访问您的克隆声音。

Amazon Polly 声音克隆在 Amazon Polly 生成式引擎支持的所有 AWS 区域均可用，包括 AWS GovCloud（美国）区域。部分 Amazon Polly 客户已启用访问权限。其他客户可以联系其 AWS 账户团队或[申请访问权限](https://pages.awscloud.com/amazon-polly-voice-cloning-20261119.html)以获取访问权限。

借助这一新增功能，您可以将克隆生命周期构建到 AWS 应用程序中。对 Amazon Polly 客户而言，构建克隆声音是免费的；Amazon Polly 按使用量对克隆声音的使用收费，详情请参阅 [Amazon Polly 定价页面](https://aws.amazon.com/polly/pricing/)。

## 你可以构建什么

**跨渠道一致的品牌声音**

建立一个可识别的声音，并将其用于您的交互式语音应答（IVR）系统、级联语音代理、移动应用、店内公告、广告和联网设备。无需依赖通用的现成声音，也无需在每次脚本变化时重新预约录音，您可以按需生成符合品牌调性的音频，并在每个渠道中保持一致的听感。

**联络中心**

在自助服务流程中提供独特的、符合品牌调性的声音，并在优惠和政策变化时更新提示语，而无需新的录音棚录制。您可以从源文本创建提示语，在推出前测试它们，并在问候、路由和通知体验中使用同一个声音。

**大规模媒体与内容**

创作者、出版商和工作室可以使用多个自定义声音创建有声书、课程、播客、游戏角色和视频，以增强聆听体验，并快速制作后续章节或更新。

**以一致人设进行本地化**

在内容库中保持可识别的声音身份，使旁白在不同标题和更新之间保持连贯。每个克隆声音只说其录制时使用的语言。对于多语言体验，请按支持的语言分别创建并审核已批准的声音。

**无障碍与个性化**

为阅读体验、辅助工具和个性化交互提供自然、类人的声音。每次创建声音时，您都要确认说话者的同意。

## 声音克隆如何工作

借助声音克隆，您可以从单个说话者的录音构建自定义 Amazon Polly 声音，然后通过 Amazon Polly 生成式引擎以该声音合成语音。该声音从录制说话者到使用成品声音，需经历四个步骤：

![声音克隆生命周期：录制、创建、等待、使用](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/11/19/ML-22432-1.png)

图 1：从录制说话者到使用成品声音的声音克隆生命周期

克隆声音需经历四个步骤：

- **录制。** 您录制一位说话者的音频（参见下面的录制提示）。您可以在 `CreateVoice` 请求中直接发送录音，或在控制台上传。也可以将录音存储在您希望声音所在的 AWS 区域的 Amazon Simple Storage Service（Amazon S3）存储桶中，并让 Amazon Polly 指向它们。
- **创建。** 您调用 `CreateVoice`，提供 1-10 段录音、录音所用语言以及 `TermsAccepted=True`（您确认已获得说话者同意）。Amazon Polly 会立即返回一个声音 ID（`vc-…`），并在后台构建声音。
- **等待。** 创建是异步的，通常需要 5-10 分钟。在此期间，Amazon Polly 还会检查文本转语音（TTS）声音在说话者相似度方面的质量。您调用 `GetVoice`，直到状态从 `pending` 变为 `active` 或 `failed`。
- **使用。** 您将声音 ID 传给 `SynthesizeSpeech` 以生成实时音频，或传给 `StartSpeechSynthesisTask` 以生成写入 S3 的长音频，并使用 `Engine="generative"`，与调用 Amazon Polly 中其他生成式声音的方式相同。当您不再需要该声音时，调用 `DeleteVoice`。

## 同意与控制

克隆声音由一个人的录音制作而成。您确认已获得说话者对全部录音的同意，并确认您控制谁可以使用该声音以及何时删除它。

- 您为自己创建的每个声音确认同意。当您在控制台上或通过 API 中的 `TermsAccepted=True` 创建声音时，您确认已获得创建和使用该克隆声音所需的所有权利和同意。您对声音克隆的使用受 [AWS 服务条款](https://aws.amazon.com/service-terms/)、[生物识别通知与同意条款](https://aws.amazon.com/legal/biometric-notice-and-consent-terms)、[AWS 负责任 AI 政策](https://aws.amazon.com/ai/responsible-ai/policy/)和 [AWS 可接受使用政策](https://aws.amazon.com/aup/)约束。
- 生成的语音带有水印。Amazon Polly 会为使用克隆声音生成的文本转语音音频添加水印。
- 只有您的账户可以使用它。克隆声音限定在创建它的 AWS 账户内，您可以通过 AWS Identity and Access Management（IAM）控制访问。您可以使用自己的 AWS Key Management Service（AWS KMS）密钥加密声音并为其添加标签。
- 您决定何时删除它。声音处于活动状态或创建失败后，您可以通过一次 `DeleteVoice` 调用或在控制台上删除声音。
- 声音创建完成后，Amazon Polly 不会保留您录音的副本，也不会将其用于训练 Amazon Polly 模型。它只保留合成语音所需的声音数据，并以加密方式存储。您可以使用自己的 AWS KMS 密钥进行该加密，`DeleteVoice` 会立即删除数据。

我们建议您：

- 保留每位说话者同意的记录。
- 如果说话者撤回同意，请删除该声音。
- 在适当场合告知听众他们听到的是合成声音。
- 仅向需要的人员和系统授予声音权限。

有关预期用途和限制的详细信息，请参阅 [Amazon Polly AI 服务卡](https://docs.aws.amazon.com/ai/responsible-ai/amazon-polly/overview.html)和 [AWS 负责任地使用 AI](https://aws.amazon.com/ai/responsible-ai/) 指南。

## 录音最佳实践

您的克隆声音会从录音中学习，包括您希望它不要学习的部分：笔记本电脑风扇声、房间回声、会议应用的噪声滤波器。

- 录制 2 到 10 分钟的自然语音，分成每段最长 1 分钟的片段。每个声音最多可发送 10 段录音，音频总时长最多 15 分钟。质量比长度更重要：更多音频未必会改变声音的听感。
- 一位说话者、安静的房间、与麦克风保持相同距离。使用 USB 麦克风，或能录制 WAV 的手机应用。从一开始就以单声道 WAV、16 位、24 kHz 录制，这样之后无需转换。Amazon Polly 接受其他音频格式，但我们推荐 WAV。支持的格式和限制请参阅 [Amazon Polly 开发人员指南](https://docs.aws.amazon.com/polly/latest/dg/what-is.html)。
- 避免使用会议应用和浏览器录音器。它们的回声消除和噪声抑制会改变声音，而克隆也会学习这些改变。
- 以您希望声音具有的风格录制每一段。克隆声音会从录音中获取风格，无法混合多种风格，因此欢快、悲伤和愤怒的片段不会给您一个能同时表现这三种风格的声音。
- 用声音应说的语言录制。声音克隆已使用美式英语、德语、美式西班牙语、法语、意大利语、巴西葡萄牙语和印地语录音进行测试。这些语言的其他口音（如英式英语或加拿大法语）录音也可使用，但测试较少，因此请用您自己的内容检查该声音。

## 开始使用

**在控制台上：** 为您的账户启用声音克隆后（参见“可用性”），展开左侧面板并选择 **Voice cloning**，上传最多 10 段录音或从 Amazon S3 中选择它们，确认条款，然后选择 **Create**。每次上传最大可达 5 MB。声音准备好后，可在其详情页试用。

**在代码中**，您需要：

- 最新版本的 boto3（`pip install --upgrade boto3`）。
- `polly:CreateVoice`、`polly:GetVoice`、`polly:DescribeVoices`、`polly:SynthesizeSpeech` 和 `polly:DeleteVoice` 的 IAM 权限。对于长音频，还需要对输出存储桶具有 `polly:StartSpeechSynthesisTask`、`polly:GetSpeechSynthesisTask` 和 `s3:PutObject` 权限。
- 对于以下 Amazon S3 示例：您的录音位于创建声音所在区域的存储桶中，并且调用 `CreateVoice` 的 IAM 角色或用户具有 `s3:GetObject` 权限。

```
import time

import boto3

# Use the Region of your S3 recordings.
polly = boto3.client("polly", region_name="us-east-1")

# 1. Create a voice from recordings of a speaker who has given consent.
#    Use 1-10 clean WAV takes of up to a minute each.
takes = [
    "s3://amzn-s3-demo-bucket/brand-voice/take-1.wav",
    "s3://amzn-s3-demo-bucket/brand-voice/take-2.wav",
    "s3://amzn-s3-demo-bucket/brand-voice/take-3.wav",
]
voice = polly.create_voice(
    Name="MyBrandVoice",    # letters, digits, - and _, up to 64 characters
    LanguageCode="en-US",   # the language spoken in the recordings
    TermsAccepted=True,     # you confirm the speaker's consent and the terms of use
    VoiceCreationData={
        "Recordings": [{"Format": "wav", "Data": {"S3Url": url}} for url in takes],
    },
    Tags={"consent-record": "speaker-0042"},  # optional: the ID of your own consent record, e.g. a signed release
    # Optional: encrypt the voice with your own KMS key (symmetric, same Region).
    # Callers who create or use the voice need kms:DescribeKey,
    # kms:GenerateDataKey and kms:Decrypt on the key.
    # CustomerManagedEncryption={
    #     "KmsKeyArn": "arn:aws:kms:us-east-1:111122223333:key/EXAMPLE"
    # },
)["Voice"]
voice_id = voice["Id"]      # for example "vc-0123456789"

# 2. Check the status every 30 seconds until the voice is active or failed
#    (usually a few minutes). Stop with an error after 20 minutes.
deadline = time.monotonic() + 20 * 60
while voice["Status"] not in ("active", "failed"):
    if time.monotonic() > deadline:
        raise TimeoutError(f"{voice_id} is still {voice['Status']}")
    time.sleep(30)
    voice = polly.get_voice(VoiceId=voice_id)["Voice"]
if voice["Status"] == "failed":
    # Check the recordings, delete this voice and create a new one.
    raise RuntimeError(f"{voice_id}: {voice.get('StatusReason', 'creation failed')}")

# 3. Synthesize speech with your new voice.
speech = polly.synthesize_speech(
    VoiceId=voice_id,
    Engine="generative",
    LanguageCode="en-US",
    OutputFormat="mp3",
    Text="Hello! This is my very own Amazon Polly voice.",
)
with open("my-voice.mp3", "wb") as f:
    f.write(speech["AudioStream"].read())

# When you no longer need the voice:
# polly.delete_voice(VoiceId=voice_id)
```

如果 Python 报告 `Polly` 对象没有 `create_voice` 属性，请升级 boto3。

对于有声书章节或课程模块等长文本，请使用将音频写入 S3 的异步合成任务：

```
from pathlib import Path

task = polly.start_speech_synthesis_task(
    VoiceId=voice_id,
    Engine="generative",
    LanguageCode="en-US",
    OutputFormat="mp3",
    OutputS3BucketName="amzn-s3-demo-bucket",
    OutputS3KeyPrefix="narration/chapter-01",
    Text=Path("chapter-01.txt").read_text(encoding="utf-8"),
    # SnsTopicArn="arn:aws:sns:us-east-1:111122223333:polly-tasks",  # notify instead of polling
)["SynthesisTask"]
print(task["TaskId"], task["OutputUri"])  # poll get_speech_synthesis_task until "completed" or "failed"
```

## 生产环境注意事项

**提前创建声音**

声音创建需要几分钟，因此请将其视为预置步骤，而不是用户请求的一部分。一个小型工作流（例如 AWS Step Functions 或作业队列）可以调用 `CreateVoice`，每 30 秒检查一次 `GetVoice`，直到声音处于活动状态，然后将声音 ID 存储到配置中。`CreateVoice` 和 `DeleteVoice` 共享每秒 1 个请求的限制，因此请将批量创建和删除排队。

**维护清单**

`DescribeVoices` 会列出您的克隆声音以及 Amazon Polly 内置声音。克隆声音的 `Origin` 设置为 `customer`。为每个声音存储声音 ID、区域、语言、同意参考信息和所有者，并为每个声音提供唯一的 `Name`。如果 `CreateVoice` 调用超时或返回服务器错误，该声音可能已经存在，而 SDK 的自动重试可能会创建第二个声音。重试前，请检查 `DescribeVoices` 中是否有该名称。

**为错误做好规划**

当您超过与 `DeleteVoice` 共享的每秒 1 个请求限制时，`CreateVoice` 会返回 `ThrottlingException`；当账户在该区域达到克隆声音配额时，会返回 `ServiceQuotaExceededException`。对仍在创建中的声音进行合成或删除会返回 `ConflictException`。如果声音使用您自己的 KMS 密钥，无法访问该密钥的调用方会收到访问被拒绝错误。创建失败时，`StatusReason` 只给出一条通用消息，因此请根据前面的录音最佳实践检查录音，然后删除失败的声音并创建新声音。

**将权限限定到声音**

克隆声音是 IAM 资源，因此您可以授予提供流量的角色仅使用某个选定声音进行合成的权限。如果该声音使用您自己的 KMS 密钥，该角色还需要访问该密钥。将 `polly:CreateVoice` 和 `polly:DeleteVoice` 保留给单独的预置角色。以下是服务角色的示例策略：

```
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": "polly:SynthesizeSpeech",
      "Resource": "arn:aws:polly:us-east-1:111122223333:voice/vc-0123456789"
    }
  ]
}
```

使用标签，您可以通过 `aws:ResourceTag` 条件为一整组声音只编写一次相同规则。还要检查您现有的策略：允许对所有资源（`"Resource": "*"`）执行 `polly:SynthesizeSpeech` 的语句也会覆盖账户中的每个克隆声音。

**规划配额和区域**

每个账户在每个区域初始有 10 个克隆声音的配额。要申请增加配额，请联系您的账户团队或 [AWS Support](https://aws.amazon.com/contact-us/)。声音只存在于您创建它时所用的账户和区域中。要为另一个区域或账户提供服务，请使用相同的录音在该区域重新创建声音，并确保说话者的同意涵盖每一份副本。

**用真实脚本测试**

在声音上线之前，听它朗读您自己的内容：产品名称、数字、地址以及您拥有的最长句子。同一段文本在不同请求之间可能略有不同。对于固定提示语（如电话问候语），请生成一次音频，由说话者和您的品牌团队批准，然后提供存储的文件。如果某个名称或术语读错，请在文本中以不同方式拼写，或使用语音合成标记语言（SSML）`<phoneme>` 标签。音素标签适用于英语、法语、意大利语、德语和西班牙语的克隆声音。请参阅[支持的 SSML 标签](https://docs.aws.amazon.com/polly/latest/dg/supportedtags.html)。

## 须知

| **可用性** | 访问权限按 AWS 账户启用。如果您在 Amazon Polly 控制台中看到 Voice cloning（展开左侧面板，查看是否列出 Voice cloning），则表示您的账户已启用该功能。如果没有，您可以联系您的 AWS 账户团队或[申请访问权限](https://pages.awscloud.com/amazon-polly-voice-cloning-20261119.html)来请求访问。支持的 AWS 区域与生成式引擎相同：美国东部（弗吉尼亚北部）、美国西部（俄勒冈）、欧洲（法兰克福）、欧洲（苏黎世）、欧洲（伦敦）、亚太地区（悉尼）、亚太地区（首尔）、亚太地区（新加坡）、亚太地区（东京）、加拿大（中部）以及 AWS GovCloud（美国西部）。克隆声音位于您创建它时所在的 AWS 区域。 |
| --- | --- |
| **语言** | 英语、德语、西班牙语、法语、意大利语、葡萄牙语和印地语。已测试的录音区域设置：美式英语（`en-US`）、德语（`de-DE`）、美式西班牙语（`es-US`）、法语（`fr-FR`）、意大利语（`it-IT`）、巴西葡萄牙语（`pt-BR`）和印地语（`hi-IN`）。这些语言的其他口音也可使用，但测试较少。每个声音只说其录制时使用的语言。 |
| **录音** | 每个声音 1-10 段录音，总时长最多 15 分钟。推荐 WAV：单声道、16 位、24 kHz 或 44.1/48 kHz。Amazon Polly 也接受其他音频格式。控制台上传每个文件限制为 5 MB。对于更大的文件，请使用 Amazon S3。 |
| **数据处理** | 声音创建完成后，Amazon Polly 会删除其录音副本，并且不会将其用于训练 Amazon Polly 模型。它只保留合成所需的声音数据，以加密方式存储（您可以使用自己的 AWS KMS 密钥），直到您调用 `DeleteVoice`。 |
| **创建时间** | 构建 TTS 声音通常需要 5-10 分钟，异步进行。 |
| **合成延迟** | 与 Amazon Polly 中的生成式声音相同。 |
| **配额** | 每个账户在每个 AWS 区域初始为 10 个克隆声音。要申请增加配额，请联系 AWS Support。`CreateVoice` 和 `DeleteVoice` 共享每秒 1 个请求的限制。 |
| **合成** | 克隆声音遵循 Amazon Polly 对生成式声音的配额，包括每个请求和每个合成任务的文本限制。请参阅 [Amazon Polly 配额](https://docs.aws.amazon.com/polly/latest/dg/limits.html)。 |
| **定价** | 创建克隆声音免费。Amazon Polly 按使用量对克隆声音的使用收费。请参阅 [Amazon Polly 定价](https://aws.amazon.com/polly/pricing/)。 |
| **API** | 使用 `CreateVoice`、`GetVoice`、`DeleteVoice` 和 `DescribeVoices` 管理声音。使用 `SynthesizeSpeech` 和 `StartSpeechSynthesisTask` 并设置 `Engine="generative"` 来使用它们。请参阅 [Amazon Polly API 参考](https://docs.aws.amazon.com/polly/latest/dg/API_Reference.html)。 |

## 结论

Amazon Polly 中的声音克隆为您的应用提供人们能识别的声音：录制一次，获得说话者同意，并可通过 Amazon Polly API 随时使用。要在控制台上开始使用，请确保您的账户已启用 Voice cloning，准备一段录音和所需的同意，打开 [Amazon Polly 控制台](https://console.aws.amazon.com/polly/)，并创建您的第一个克隆声音。如果您是新客户并希望启用声音克隆，请联系您的 AWS 账户团队或[申请访问权限](https://pages.awscloud.com/amazon-polly-voice-cloning-20261119.html)以获取访问权限。
