# 全新的 Amazon Bedrock Data Automation 能力简化视频与音频分析

各行各业的组织都在努力处理海量的非结构化视频与音频内容，以支撑其核心业务应用与组织优先事项。[Amazon Bedrock Data Automation](https://aws.amazon.com/bedrock/bda/) 通过简化应用开发并自动化使用文档、图像、音频和视频内容的工作流，帮助他们应对这一挑战。近期，我们发布了两项新能力，可用于从视频和音频中获取定制洞察。借助一致的多模态分析（并可无缝定制以满足其特定业务需求），你可以简化开发并提升效率。

Amazon Bedrock Data Automation 通过预打包的[基础模型](https://aws.amazon.com/what-is/foundation-models/)（FM）把开发时间从数天缩短到数分钟，无需再准备多个任务专用模型，也无需编写复杂的处理逻辑。现在，开发者可以摆脱大规模处理非结构化多模态内容这一耗时繁重的环节，无论是分析 PB 级的视频，还是处理数百万条客户对话。开发者可以使用自然语言指令生成洞察，以满足其下游系统与应用的需要。媒体与娱乐行业的用户可以从电影、电视节目、广告和用户生成的视频内容中挖掘定制洞察。面向客户的团队可以从音频中生成新的洞察——分析客户咨询以识别最佳实践、对对话主题进行分类，并提取有价值的客户问题用于培训。

## 使用 Amazon Bedrock Data Automation 为视频定制洞察

Amazon Bedrock Data Automation 让你可以轻松定制由[生成式 AI](https://aws.amazon.com/generative-ai/) 从视频生成的洞察。你可以指定希望从视频中生成哪些字段（例如场景上下文或摘要）、数据格式，以及每个字段的自然语言指令。你可以为 AI 驱动的多媒体分析应用以一致的格式生成特定洞察，从而定制 Amazon Bedrock Data Automation 的输出。例如，你可以使用 Amazon Bedrock Data Automation 在电影、电视节目和社交媒体内容中提取场景摘要、识别视觉上显著的物体，并检测 logo。借助 Amazon Bedrock Data Automation，你可以在数分钟内创建新的定制视频输出。你也可以从预构建解决方案目录中选择——包括广告分析、媒体搜索等。请阅读以下示例，了解一位客户如何将 Amazon Bedrock Data Automation 用于视频分析。

Air 是一款基于 AI 的软件产品，帮助企业将内容的收集、审批和共享流程自动化。创意团队青睐 Air，因为他们可以用 Air 的创意运营系统替换其数字资产管理（DAM）、云存储方案和工作流工具。如今，Air 为 Google、P&G 和 Sweetgreen 等全球品牌管理超过 250M 个图像和视频。Air 的产品于 2021 年 3 月发布，并已从世界级风险投资机构获得 $70M 融资。Air 使用 Amazon Bedrock Data Automation 帮助创意团队快速整理其内容。

> “在 Air，我们使用 Amazon Bedrock Data Automation 处理数千万计的图像和视频。Amazon Bedrock Data Automation 让我们能在数秒内从内容中提取具体的、定制化的洞察（例如视频章节、转录、光学字符识别）。这在过去对我们来说几乎是不可能完成的任务。Air 上由 Amazon Bedrock Data Automation 驱动的新功能为创意和营销团队提供了关键的业务洞察。借助 Amazon Bedrock Data Automation，Air 将其用户的搜索与整理时间减少了 90%。如今，每家公司都需要像媒体公司一样运作。企业正在优先建设生成原创且独特创意作品的能力：这一目标通过定制化即可实现。像 Amazon Bedrock Data Automation 这样的能力，让 Air 能够根据每位客户的具体目标与需求，为其定制提取流程。”
> ——Air 联合创始人兼 CEO Shane Hegde

## 使用 Amazon Bedrock Data Automation 从音频中提取聚焦洞察

全新的 Amazon Bedrock Data Automation 能力让你能更快速、更简洁地从音频中提取由生成式 AI 驱动的定制洞察。你可以用自然语言指定所需的输出配置。你还可以从客户来电、临床讨论、会议等音频中提取定制洞察——例如摘要、关键主题和意图。你可以利用 Amazon Bedrock Data Automation 中的音频洞察来提高生产力、提升客户体验、确保监管合规等。例如，销售代表可以从与客户的对话中提取摘要、关键行动项和后续步骤等洞察，从而提升自身生产力。

## 开始使用全新的 Amazon Bedrock Data Automation 视频与音频能力

要分析你的视频和音频资产，请按以下步骤操作：

- 在 [Amazon Bedrock 控制台](https://console.aws.amazon.com/bedrock)的导航窗格中选择 **Data Automation**。以下截图展示了 Data Automation 页面。
![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/05/23/ml-18853-image-1.png)
- 在 **Create a new BDA Project** 屏幕的 **BDA Project name** 下输入名称。选择 **Create project**，如下方截图所示。
![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/05/23/ml-18853-image-2.png)
- **Choose a Sample Blueprint or create a Blueprint**

要使用 blueprint，请按以下步骤操作：

- 你可以选择一个示例 blueprint，也可以新建一个。
- 要创建 blueprint，请在 Amazon Bedrock Data Automation 控制台的导航窗格中，于 **Data Automation** 下选择 **custom output**。
- 选择 **Create blueprint**，并为你想要为其创建 blueprint 的视频或音频文件选择对应图块，如下方截图所示。

为视频模态选择示例 blueprint

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/05/23/ml-18853-image-3.png)

为音频模态创建新的 blueprint

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/05/23/ml-18853-image-4.png)

- **Generate results for custom output **  在 blueprint 内的视频资产上，你可以选择 **Generate results** 查看详细分析。  ![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/05/23/ml-18853-image-5.png)
- 选择 **Edit field **——在 **Edit fields** 窗格中输入字段名称。在 **Instructions** 下，提供清晰、分步骤的说明，讲清在提取过程中如何识别并分类该字段的数据。
![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/05/23/ml-18853-image-6.png)
- 选择 **Save blueprint**。
