# 借助经 Amazon SageMaker 训练的模型，用 Amazon Bedrock 无服务器能力解锁高性价比的 AI 推理

在本文中，我将向你展示如何把 [Amazon Bedrock](https://aws.amazon.com/bedrock/)——凭借其全托管、按需调用的 API——与你在 [Amazon SageMaker](https://aws.amazon.com/sagemaker/) 中训练或微调过的模型结合使用。

Amazon Bedrock 是一项全托管服务，通过单一 API 提供来自 AI21 Labs、Anthropic、Cohere、Meta、Mistral AI、Stability AI 和 Amazon 等领先 AI 公司的一系列高性能基础模型（FM），并提供广泛的能力，帮助你以安全、隐私和负责任 AI 的方式构建生成式 AI 应用。

此前，如果你想在 Amazon Bedrock 中使用自己定制的微调模型，要么必须在 SageMaker 中自行管理推理基础设施，要么直接在 Amazon Bedrock 内训练模型，而这需要费用高昂的预置吞吐量。

借助 [Amazon Bedrock Custom Model Import](https://docs.aws.amazon.com/bedrock/latest/userguide/model-customization-import-model.html)，你可以使用在 SageMaker 中通过 [Amazon SageMaker JumpStart](https://aws.amazon.com/sagemaker-ai/jumpstart/getting-started/?sagemaker-jumpstart-cards.sort-by=item.additionalFields.priority&sagemaker-jumpstart-cards.sort-order=asc&awsf.sagemaker-jumpstart-filter-product-type=*all&awsf.sagemaker-jumpstart-filter-text=*all&awsf.sagemaker-jumpstart-filter-vision=*all&awsf.sagemaker-jumpstart-filter-tabular=*all&awsf.sagemaker-jumpstart-filter-audio-tasks=*all&awsf.sagemaker-jumpstart-filter-multimodal=*all&awsf.sagemaker-jumpstart-filter-RL=*all) 训练或微调的新模型或现有模型。你可以将受支持的架构导入 Amazon Bedrock，从而通过 Amazon Bedrock 的全托管调用模型 API 按需访问它们。

## 解决方案概览

在撰写本文时，Amazon Bedrock 支持从以下架构[导入自定义模型](https://docs.aws.amazon.com/bedrock/latest/userguide/model-customization-import-model.html)：

- Mistral
- Flan
- Meta Llama 2 和 Llama 3

在本文中，我们使用一个 [Hugging Face Flan-T5 Base](https://docs.aws.amazon.com/sagemaker/latest/dg/hugging-face.html) 模型。

在接下来的章节中，我将带你逐步完成在 SageMaker JumpStart 中训练模型并将其导入 Amazon Bedrock 的步骤。之后，你就可以通过 Amazon Bedrock playground 与你的自定义模型交互。

## 先决条件

在开始之前，请确认你拥有一个可以访问 [Amazon SageMaker Studio](https://aws.amazon.com/sagemaker/studio/) 和 Amazon Bedrock 的 AWS 账户。

如果你还没有 SageMaker Studio 实例，请参阅[启动 Amazon SageMaker Studio](https://docs.aws.amazon.com/sagemaker/latest/dg/studio-updated-launch.html) 了解创建实例的说明。

## 在 SageMaker JumpStart 中训练模型

请在 SageMaker JumpStart 中完成以下步骤来训练 Flan 模型：

- 打开 AWS Management Console，进入 SageMaker Studio。

![Amazon SageMaker Console](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/12/31/ML-17293-1.png)

- 在 SageMaker Studio 中，从导航窗格选择 **JumpStart**。

借助 SageMaker JumpStart，机器学习（ML）从业者可以从大量公开可用的 FM 中进行选择，使用预置的机器学习解决方案，只需点击几下即可完成部署。

- 搜索并选择 **Hugging Face Flan-T5 Base**

![Amazon SageMaker JumpStart Page](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/12/31/ML-17293-2.png)

在模型详情页面上，你可以查看模型的简短说明、如何部署、如何微调，以及自定义模型时训练数据需要采用什么格式。

- 选择 **Train** 开始在你的训练数据上微调模型。

![Flan-T5 Base Model Card](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/12/31/ML-17293-3.png)

使用默认设置创建训练作业。这些默认值会为训练作业填入推荐的设置。

- 本文中的示例使用一个预置的示例数据集。使用你自己的数据时，请在 **Data** 部分输入其位置，并确保它满足[格式要求。](https://docs.aws.amazon.com/sagemaker/latest/dg/jumpstart-foundation-models-fine-tuning-instruction-based.html)

![Fine-tune model page](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/12/31/ML-17293-4.png)

- 配置安全设置，例如 [AWS Identity and Access Management (IAM)](https://aws.amazon.com/iam/) 角色、虚拟私有云（VPC）和加密。
- 记下 **Output artifact location (S3 URI)** 的值，以备后续使用。
- 提交作业以开始训练。

你可以通过 **Jobs** 下拉菜单中的 **Training** 来监控作业。当训练作业状态显示为 **Completed** 时，说明作业已经完成。使用默认设置时，训练大约需要 10 分钟。

![Training Jobs](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/12/31/ML-17293-5.png)

## 将模型导入 Amazon Bedrock

模型训练完成后，你可以将其导入 Amazon Bedrock。请完成以下步骤：

- 在 Amazon Bedrock 控制台的导航窗格中，选择 **Foundation models** 下的 **Imported models**。
- 选择 **Import model**。

![Amazon Bedrock - Custom Model Import](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/12/31/ML-17293-6.png)

- 在 **Model name** 中，为你的模型输入一个易于识别的名称。
- 在 **Model import settings** 下，选择 **Amazon SageMaker model**，并选中你模型旁边的单选按钮。

![Importing a model from Amazon SageMaker](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/12/31/ML-17293-7.png)

- 在 **Service access** 下，选择 **Create and use a new service role**，并为该角色输入一个名称。
- 选择 **Import model**。

![Creating a new service role](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/12/31/ML-17293-8.png)

- 模型导入大约会在 15 分钟内完成。

![Successful model import](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/12/31/ML-17293-9.png)

- 在导航窗格的 **Playgrounds** 下，选择 **Text**。
- 选择 **Select model**。

![Using the model in Amazon Bedrock text playground](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/12/31/ML-17293-10.png)

- 在 **Category** 中，选择 **Imported models**。
- 在 **Model** 中，选择 **flan-t5-fine-tuned**。
- 在 **Throughput** 中，选择 **On-demand**。
- 选择 **Apply**。

![Selecting the fine-tuned model for use](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/12/31/ML-17293-11.png)

现在你就可以与自己的自定义模型交互了。在下面的截图中，我们使用示例自定义模型来概括一段关于 Amazon Bedrock 的描述。

![Using the fine-tuned model](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/12/31/ML-17293-12.png)

## 清理资源

请完成以下步骤来清理你的资源：

- 如果你不打算继续使用 SageMaker，请[删除你的 SageMaker 域](https://docs.aws.amazon.com/sagemaker/latest/dg/gs-studio-delete-domain.html)。
- 如果你不再想维护模型工件，请删除存储模型工件的 [Amazon Simple Storage Service (Amazon S3) 存储桶](https://docs.aws.amazon.com/AmazonS3/latest/userguide/delete-bucket.html)。
- 要从 Amazon Bedrock 中删除已导入的模型，请在 Amazon Bedrock 控制台的 **Imported models** 页面上选择你的模型，然后选择选项菜单（三个点）并选择 **Delete**。

![Clean-Up](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/12/31/ML-17293-13.png)

## 结论

在本文中，我们探讨了 Amazon Bedrock 中的 Custom Model Import 功能如何让你使用自己定制训练或微调过的模型，实现按需、高性价比的推理。通过将 SageMaker 的模型训练能力与 Amazon Bedrock 全托管、可扩展的基础设施相结合，你现在有了一种无缝的方式来部署专用模型，并通过简单的 API 访问它们。

无论你更偏好易用的 SageMaker Studio 控制台，还是 SageMaker notebook 的灵活性，都可以把模型训练好并导入 Amazon Bedrock。这让你能够专注于开发创新的应用与解决方案，而无需承担管理复杂 ML 基础设施的负担。

随着大型语言模型的能力不断演进，把自定义模型集成到应用中的价值也日益凸显。借助 Amazon Bedrock Custom Model Import 功能，你现在可以充分释放专用模型的潜力，为客户交付量身定制的体验，同时享受全托管服务带来的可扩展性与成本效益。

想进一步了解在 SageMaker 上进行微调，请参阅 [Instruction fine-tuning for FLAN T5 XL with Amazon SageMaker Jumpstart](https://aws.amazon.com/blogs/machine-learning/instruction-fine-tuning-for-flan-t5-xl-with-amazon-sagemaker-jumpstart/)。想获得更多 Amazon Bedrock 的实践体验，请查看我们的 [Building with Amazon Bedrock](https://catalog.workshops.aws/building-with-amazon-bedrock/en-US) 工作坊。
