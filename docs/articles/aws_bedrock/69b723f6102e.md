# 一家创新的金融服务领军者找到了合适的 AI 方案：Robinhood 与 Amazon Nova

*本文与来自 Robinhood 的 Renyu Chen 和 Dev Tagare 合写。*

在曾经保守的在线券商世界里，[Robinhood](https://robinhood.com/us/en/) 一直是先驱与颠覆者。公司成立于 2013 年，把一个以守门著称的行业变成了人人可及的开放平台。Robinhood 开创了零佣金交易，并借助技术力量与直觉式设计，为现代投资者打造无缝且富有吸引力的体验。时至今日，公司仍通过在 AWS 上推出突破性的产品创新，持续颠覆金融服务行业。

这些创新让 Robinhood 成为历史上增长最快的券商之一，全球客户超过 2,500 万，并以创新者和技术领导者的形象享誉全球。在“democratizing finance for all”（让金融民主化）使命的驱动下，公司对可及性的专注——尤其是对首次投资者——使 Robinhood 十多年来一直位居 Apple App Store 财经类应用前列，并为其赢得诸多荣誉，例如 Fast Company 杂志将其评为全球[50 家最具创新力公司](https://www.fastcompany.com/91270856/robinhood-most-innovative-companies-2025)之一。这一年度榜单聚焦通过创新重塑行业与文化的企业。

Robinhood 首席执行官 Vlad Tenev [解释了](https://www.cnbc.com/2021/05/25/robinhoods-disruptive-trade-the-good-the-bad-and-the-controversy.html)这一专注为何对 Robinhood 如此重要：

> “我们的信念是：我们越降低准入门槛，越能拉平竞争场地，让人们更年轻时就得以投资自己的资金，我们的经济就越好，社会也越好。”

Robinhood 生而为云，使用 AWS 支撑其在线业务、交付并更新移动交易应用、安全存储信息与数据，并开展业务分析。Robinhood 最近使用 AI 改善客户体验并扩大可及性。例如，公司将在 2025 年推出 Robinhood Cortex，这是一款 AI 投资工具，旨在提供实时洞察，帮助用户更好地把握市场、识别潜在机会，并及时了解最新的市场动向新闻。Cortex 是令人振奋的一步，它提供过去只面向机构投资者和富裕人群的优质投资与市场摘要。

随着 Robinhood 客户能在平台上做更多事情，公司正与 AWS 合作探索新的生成式 AI 方案，例如 [Amazon Nova](https://aws.amazon.com/ai/generative-ai/nova/)，这是一系列 foundation model（FM），让生成式 AI 开发更快、更高效，并具备出色的性价比。这些新方案将帮助公司应对客户需求的高速增长。

在本文中，我们分享 Robinhood 如何借助生成式 AI 与 Amazon Nova，实现金融民主化并提供实时市场洞察。

## 一段以客户痴迷为基石的 AI/ML 之旅

与所有金融服务公司一样，Robinhood 在高度监管的环境中运营。历史上，这个行业被视为行动迟缓、对新技术的态度谨慎。Robinhood 的创始人把技术放在首位，最初打造了一款不加修饰、零费用的应用，其设计初衷就是让投资对所有人可及，而不只是极富人群。随着 Robinhood 成长，它吸引了更多样化的客户：他们需要平台提供的速度、可靠性、安全性和低成本，但也希望针对不同且新颖的用例获得更丰富的服务。

Robinhood 会认真倾听这些活跃交易者的声音。正如 Robinhood 的资深机器学习（ML）工程师 Renyu Chen 所说，

> “我们希望为 AI/ML 应用打造一条从实验走向 Robinhood 规模的无缝旅程。我们指望 AWS 团队帮助满足开发者对 AI/ML 的需求，同时提供先进的 ML 工具，服务我们最精明的‘活跃交易者’客户。这还需要一种即插即用的方式，能够采纳来自开源、模型提供方和自研平台工具的最新生成式 AI 技术。”

Robinhood 在 2023 年探索了多种生成式 AI 方案，最终得出结论：要达到 Robinhood 规模，最好的方式是采用 [Amazon Bedrock](https://aws.amazon.com/bedrock/)，这是一项完全托管的服务，帮助用户构建生成式 AI 模型。Amazon Bedrock 提供来自多家提供方的丰富 FM 选择，并通过单一 API 实现高度定制与安全。

据 Robinhood 的 Renyu Chen 所说，

> “对我们而言，客户数据的安全是第一位的。没有什么比这更重要。使用 Amazon Bedrock，数据始终在我们的掌控之中。当我们查询模型时，输入和输出都不会离开我们的虚拟私有云。当我们微调 foundation model 时，微调基于该模型的一个私有副本。这意味着我们的客户数据不会与模型提供方共享，也不会被用于改进基础模型。”

为满足 Robinhood 不断壮大的高级用户群体的需求，Robinhood 正在探索 Amazon Nova，并估算使用 Amazon Nova 的每 token 价格可比他们测试过的其他模型低最多 80%，这将使驱动欺诈调查助手、增强文档处理、AI 生成内容创作等新的高需求用例变得成本高效。

此外，通过 Amazon Nova 运行的 AWS 生成式 AI 方案可以为 Robinhood 驱动新的 agentic 工作流，在其中自主 AI agent 能够独立做出决策、适应变化的情境并执行动作。

> “Robinhood 为客户提供简洁、快速、安全和成本节省。与 Robinhood 团队以开发者对开发者的方式合作、共同构建，我们可以设计出契合 Robinhood 优先事项与以客户为中心目标的生成式 AI 方案。例如，Amazon Nova 模型可以通过 Amazon Bedrock Model Distillation 轻松定制，该功能把知识从更大、更强的‘teacher’模型‘蒸馏’到更小、更快、更成本高效的‘student’模型。”
>         – Dushan Tharmal，Amazon Artificial General Intelligence（AGI）首席产品经理。

## Amazon Nova：为 Robinhood 及其客户带来更多服务与更大价值

在 AWS 的支持下推进其雄心勃勃的 AI 之旅，Robinhood 能够快速为客户扩展新服务，而无需传统券商那种昂贵的基础结构、人员和基础设施。借助 AWS 的支持，Robinhood 能够提供更丰富的客户体验，同时忠于其简洁、清晰、低成本、快速、安全与可靠的使命。

> “我们看到 Amazon Nova 与我们的使命高度契合。Amazon Nova 以极低的成本提供最低延迟的响应，并在 Robinhood 广泛的交互式与高并发应用中保持准确与极速。而且，与 Robinhood 对简洁和低成本服务客户的承诺一致，通过 Amazon Bedrock 使用 Amazon Nova 模型，让这些大规模任务显著更简单、更便宜、更具成本效益。”
>         – Dev Tagare，Robinhood AI 负责人。
