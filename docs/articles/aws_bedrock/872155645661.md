# 让客户能够大规模交付生产就绪的 AI agent

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/07/16/2025-0716_middle-grey-studios_aws-amers_preview-001_websize.jpg)

AI agent 将改变我们所有人的工作与生活方式。我们的 AWS CEO Matt Garman 分享了一个愿景：这是一场与互联网诞生同等量级的技术变革。这一愿景让我倍感振奋，因为我亲眼见证了这些智能 agent 系统如何开始解决复杂问题、自动化工作流，并在各个行业创造新的可能。借助 agentic AI，AstraZeneca 加速了医疗健康洞察的发现，Yahoo Finance 为数百万投资者重塑了金融研究，Syngenta 则以 AI 驱动的精准农业革新了农业。

要把这些早期成功扩展为广泛采用，组织需要一套务实的方法来应对 agentic 系统固有的复杂性。在 AWS，我们致力于成为构建世界上最实用 AI agent 的最佳场所，让组织能够大规模部署可靠且安全的 agent。

我们的重点是让每个组织都能触及我们的 agentic AI 愿景：把快速创新与安全、可靠性和卓越运营的坚实基础结合起来。我们的做法在既有验证过的原则之上拥抱新的可能，从而加速进展——构建能够随模型演进、新能力涌现以及用例在业务中扩展而适应的系统。

今天，我很高兴分享我们如何通过新能力把这一愿景变为现实，这些能力针对的是大规模构建和部署 agent 的根本性问题。这些创新将帮助你走出实验阶段，走向生产就绪的 agent 系统，并足以托付你最关键的业务流程。

一个用于大规模构建和部署生产就绪的 Agentic AI 系统的全面基础。

## 为 agent 演进的指导原则

在 AWS，我们的 agentic AI 方法源自我们在内部构建 agent 系统的经验，以及帮助数十万客户加速其 AI 之旅的经验。**四项核心原则**指导我们在这个领域所做的一切：

### **原则 1：把敏捷性当作竞争优势**

脱颖而出的组织不会是那些完美预测未来的组织，而是那些在变化展开时快速适应的组织。保持敏捷需要一种拥抱灵活性与开放性的 agentic 架构，而不是僵化的框架或单一模型。这意味着构建的系统能够在新模型出现时纳入新模型、连接到你的专有数据源，并与你现有的工具无缝集成。

对稳定性与适应性的双重需求，促使我们打造了 [Amazon Bedrock AgentCore](https://aws.amazon.com/blogs/aws/introducing-amazon-bedrock-agentcore-securely-deploy-and-operate-ai-agents-at-any-scale/)——一套用于在企业规模上安全地部署和运营高能力 agent 的完整服务。**AgentCore** 提供带完整会话隔离和当前最长运行时长工作负载的安全无服务器运行时，提供帮助 agent 以正确的权限和上下文执行工作流的工具与能力，以及用于运营可信 agent 的管控手段。它的各项能力可以组合使用，也可以独立使用，并且可与 CrewAI、LangGraph、LlamaIndex 和 [Strands Agents](https://strandsagents.com/) 等流行的开源框架配合，也可与包括 **Amazon Bedrock** 内外任何模型配合，因此开发者可以在技术变迁中保持敏捷。通过减少无差别的繁重工作，AgentCore 帮助组织走出实验阶段，走向生产就绪的 agent 系统，并足以托付你最关键的业务流程。

**Itaú Unibanco**、**Innovaccer**、**Boomi**、**Box** 和 **Epsilon** 等客户已经在试用 AgentCore，并对其加速 agent 投产的能力感到兴奋。这些早期采用者认识到，AgentCore 帮助消除了开源灵活性与企业级安全可靠性之间的取舍，使他们能够专注于创造业务价值，而不必从零开始搭建安全和运营基础。

### **原则 2：为 agentic 时代演进基础能力**

企业技术的核心原则并未改变，但我们的实现方式必须为 agentic 时代而演进。这些演进后的基础能力构筑了让生产级 agent 成为可能的地基：

- **安全与信任**。当 agent 跨越系统边界、代表用户执行操作，或在获得用户预先授权后自行行动时，会引入新的安全考量。信任需要透明度、护栏和验证。**AgentCore Runtime** 通过为每个会话提供专用计算环境和内存隔离来帮助应对这些问题，防止不同 agent 之间的数据泄露，这建立在 **AWS Lambda** 十年来在安全与可扩展性上的无服务器创新之上。
- **可靠性与可扩展性**。传统的软件扩展方法在 agentic 系统上并不够用，因为它们遵循不可预测的执行路径，且各次交互之间的资源需求也不固定。**AgentCore Runtime** 高度可靠，具备检查点和恢复能力，可在出现意外中断和失败时帮助实现平滑恢复，并能自动处理从零到数千个并发会话的扩展，免去容量规划和基础设施维护。
- **身份**。当 agent 代表用户和系统行动时，传统身份模型必须演进。当 agent 在跨多个系统的工作流中穿行时，同时管理 agent 和用户的权限对于保护你的数据变得至关重要。**AgentCore Identity** 借助临时、细粒度的权限和基于标准的身份验证，为 agent 提供跨 AWS 服务以及第三方应用和工具的安全访问。它可与 Amazon Cognito、Microsoft Entra ID 和 Okta 等领先身份提供商，以及 GitHub、Google、Salesforce 和 Slack 等主流 OAuth 提供商配合使用。
- **可观测性**。理解 agent 的决策需要新的监控方法。可观测性不仅对排障至关重要，对合规和持续改进也同样重要，它代表着从周期性审计到持续监督的转变。**AgentCore Observability** 通过内置仪表盘和可与你的监控栈集成的标准化遥测，提供实时可见性。
- **数据**。你的专有数据比以往任何时候都更有价值，它让 agent 能够理解你的特定上下文。安全地访问、处理这些数据并从中学习，已成为决定 agent 性能与相关性的关键差异化因素。例如，借助 **AgentCore Gateway**，你可以把包括 Amazon Bedrock Knowledge Bases 在内的数据源转换为与 agent 兼容的工具，让 agent 能够访问最新且相关的信息。
- **无缝集成**。Agent 必须与你环境中的一切协作：你的系统、其他云、SaaS 应用以及其他 agent。**AgentCore Gateway** 通过以极少的代码把 API 和服务转换为与 agent 兼容的工具来实现这一点，免去数月的集成工作，同时让 agent 能够发现你的系统并与之交互。我们的开源 **Strands Agents** SDK 则通过灵活的编排模式，以及对 MCP 和 A2A 的支持来补充这一点，从而实现跨不同环境的多个 agent 与工具之间的无缝协调。[AWS API MCP Server](https://github.com/awslabs/mcp/tree/main/src/aws-api-mcp-server) 为 agent 提供了调用 AWS 服务的接口，使基础模型能够发现可用的操作、推理输入与输出要求，并生成调用 AWS API 的计划，从而以超出模型训练截止时间的实时 AWS 能力去探索、配置或管理资源。
- **工具与能力**。Agent 需要专门的工具来执行复杂任务并在各次交互之间保持上下文。**AgentCore Memory** 消除了复杂的内存基础设施管理，同时让开发者对 AI agent 记住什么拥有完全控制，从而轻松构建上下文感知的 agent。它提供业界领先的准确性，并同时支持用于多轮对话的短期记忆和跨会话持久的长期记忆，还能在协作的 agent 之间共享记忆存储。内置工具包括用于 Web 交互的 **AgentCore Browser**，让 agent 能够浏览网站并代表你执行操作；以及用于安全执行代码的 **AgentCore** **Code Interpreter**，让 agent 能够以编程方式处理数据、生成可视化并解决复杂问题。这些能力扩展了 agent 能做的事情，同时保持了安全性与可靠性。

这些演进后的基础能力共同帮助组织构建安全、可靠且可扩展的 agent 架构，在生产环境中交付稳定的结果。借助 AgentCore，我们帮助客户专注于创造价值，而不是重新发明基础设施。

### **原则 3：以模型选择和数据交付卓越成果**

每个高效 agent 系统的核心都是其基础模型，它支撑着 agent 理解、推理和行动的能力。要让 agent 交付变革性的体验，经过精心选择、甚至可能经过定制调优的模型，需要与丰富的、特定于上下文的知识相结合，这决定了模型能以多高的效率代表你做出决策。这一现实适用于所有 AI 应用，因此 AWS 既给客户为每个用例选择最优模型的自由，也提供用其独有数据增强这些模型的工具。这种做法能为所有 AI 实现交付卓越成果和最佳性价比。

模型需求差异极大——有些应用需要复杂的推理，有些要求快速响应，还有许多在大规模场景下优先考虑成本效率。没有哪个单一模型在各个方面都表现出色，这正是我们在 2023 年通过 Amazon Bedrock 开创模型选择的原因。但真正的差异化因素在于你如何把模型与组织的专有数据结合起来，把通用 AI 转化为具备深厚领域专业能力的系统。

为了帮助你打造具备如此高水平专业能力的模型，今天我们通过推出 [Amazon SageMaker AI 中的 Amazon Nova 定制能力](https://aws.amazon.com/blogs/aws/announcing-amazon-nova-customization-in-amazon-sagemaker-ai/)来扩展模型定制能力。Nova 模型现在让客户能够在整个模型开发生命周期中灵活地定制模型。这包括预训练和后训练，涵盖微调与对齐，并支持参数高效微调（PEFT）和全量微调。凭借这些能力，Nova 现在为任何专有模型系列中提供了最全面的模型定制能力套件。利用监督式微调（SFT）、直接偏好优化（DPO）、基于近端策略优化（PPO）的人类反馈强化学习、持续预训练（CPT）和知识蒸馏等技术，客户可以创建针对其用例优化的 Nova 模型。定制完成后，这些模型可以直接部署到 Amazon Bedrock，让你把自定义模型无缝集成到 agent 系统和其他 AI 应用中。

我们也在训练针对特定 agent 用例优化的自有模型。[Nova Act](https://nova.amazon.com/act) 是一个被训练为在 Web 浏览器中执行操作的 AI 模型。客户可以使用 **Nova Act SDK** 开始构建自己的浏览器自动化 agent，该 SDK 专为构建由 Nova Act 模型驱动的可靠浏览器 agent 而打造。Nova Act SDK 目前已提供研究预览版，它使用 AgentCore Browser 实现可扩展的云端浏览器执行。

有了合适的模型之后，你还需要确保它能够与组织专有且最新的数据交互。向量已成为 AI 模型访问你的数据最主要、最快速的方式。到目前为止，存储向量嵌入（实现这种智能的关键）的成本一直迫使组织把 AI 系统限制在近期数据上，从而制约了它们的潜力。今天发布的 [Amazon S3 Vectors](https://aws.amazon.com/s3/features/vectors/) 是首个原生支持向量的云对象存储，它标志着一次根本性变化。S3 Vectors 在把向量存储成本降低 90% 的同时保持亚秒级查询性能，使 agent 能够记住更多、推理更深，并从每一次客户交互、文档和业务洞察中保持全面的上下文。S3 Vectors 可直接与用于高性价比 RAG 应用的 Amazon Bedrock Knowledge Bases 集成，也可与用于分层向量策略的 Amazon OpenSearch Service 集成。

### **原则 4：部署能够改变体验的解决方案**

模型和基础设施改变的是组织的构建方式，而 agentic 解决方案改变的是企业的运营方式。Agentic AI 的真正力量在于它能够重塑整个行业的工作流程与人的生产力。这些解决方案把人从例行任务中解放出来，处理复杂的信息流，让团队得以专注于创造性思考和战略决策。我们正通过预构建的 agentic 解决方案，让更多组织能够获得这种转变。把基础构件与预构建解决方案结合起来，你就能走出实验阶段，走向能够带来切实业务影响的全面 AI 战略。

今天，我们宣布你可以在 [AWS Marketplace 中购买 AI Agents and Tools](https://aws.amazon.com/marketplace/solutions/ai-agents-and-tools?trk=70405219-a2f8-4816-a915-9932f523f1bd&sc_channel=el&ams%23interactive-card-vertical%23pattern-data.filter=%257B%2522filters%2522%253A%255B%255D%257D)，享受简化的采购流程和多种部署选项。在当今碎片化的 AI 格局中，AWS Marketplace 提供集中化的目录，收录来自 AWS 合作伙伴的精选 agent、工具和解决方案。借助 AWS 合作伙伴的预构建 agent 快速实现自动化。我们基于 API 的新部署方式帮助你简化与支持 MCP 和 A2A 的其他 agent 和工具的集成。这些 agent 可以运行在受信任的 AWS 服务上，或运行在你的 AWS 环境中，由你保持对安全和访问的控制。你可以在 AgentCore 上部署部分预构建的 agent 和工具。

我们也在持续为客户提供可立即部署的 agent 解决方案，以实现这种转变。[Kiro](https://kiro.dev/) 是一个 AI IDE，通过规格驱动的开发帮助开发者从概念走向生产。从简单到复杂的任务，**Kiro** 都会与你并肩工作，把 prompt 变成详细的规格，再变成可运行的代码、文档和测试。这样，你构建的东西恰好就是你想要的，并且可以直接与团队分享。**Kiro** 的 agent 帮助你解决棘手问题，并自动化生成文档和单元测试之类的任务。借助 **Kiro**，你可以构建超越原型的产品，同时在每一步都握有主导权。[AWS Transform](https://aws.amazon.com/transform/) 部署专门的 AI agent 来自动化代码分析、重构和依赖关系梳理等复杂的现代化改造任务，极大缩短企业工作负载迁移的项目周期。每个解决方案都体现了我们对灵活性和选择权的承诺，帮助你更快创新、更早实现业务成果。而 [Amazon Connect](https://aws.amazon.com/connect/) 这一全面的客户体验解决方案，让组织能够通过所有渠道，在每一次客户交互中提供不受限制的 AI，从而取悦客户。

这四项原则指导着我们的产品战略，并融入我们今天宣布的每一项创新之中：拥抱敏捷、演进基础能力、把模型选择与专有数据结合、部署变革性的解决方案。它们共同提供了一个全面框架，帮助你在组织中成功落地 agentic AI。

## **前路**

对我们的客户以及我们自己多元业务所蕴含的巨大潜力，激励我们专注于打造地球上最值得信赖的 agentic AI 能力。但我能给出的最重要的建议很简单：**现在就开始**。

不要陷入试图一口吃成胖子的困境，也不要等到所有答案齐备才开始。选一个真正重要的具体业务问题，然后动手去构建。取得最大成功的组织并不是那些计划最宏大的组织，而是那些已经启动学习循环、收集真实反馈来指导每一次迭代的组织。为了在客户的 AI 之旅上提供帮助，我们将向 [AWS Generative AI Innovation Center](https://aws.amazon.com/blogs/machine-learning/aws-doubles-investment-in-aws-generative-ai-innovation-center-marking-two-years-of-customer-success/?trk=952ca252-c2d2-4ac3-ba62-585ee50ef0f4) 再投入 1 亿美元，把投资翻倍；该中心已经帮助包括 NFL、Yahoo Finance、BMW 和 AstraZeneca 在内的各行业数千家客户实现了数百万美元的生产力提升，并改变了客户体验。

AWS 为云计算树立了安全、可靠性和数据隐私的标准，我们正在把这些同样的原则带到 agentic AI 中。无论你的用例或要求是什么，AWS 都能提供合适的基础助你成功。携手共进，我们可以借助 agentic AI 的力量，为你的业务重新定义可能性。
