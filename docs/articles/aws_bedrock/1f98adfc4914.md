# 使用 Amazon Nova Canvas 的文本生成图像基础

AI 图像生成已成为近年来最具变革性的技术之一，彻底改变了你创建视觉内容、与视觉内容交互的方式。Amazon Nova Canvas 是 [Amazon Nova 创意模型](https://aws.amazon.com/ai/generative-ai/nova/creative/)套件中的一款生成式模型，让你能够根据纯文本描述生成逼真且富有创意的图像。

本文是使用 Amazon Nova Canvas 的入门指南。我们先介绍在 [Amazon Bedrock](https://aws.amazon.com/bedrock/) 上完成设置所需的步骤。Amazon Bedrock 是一项完全托管的服务，托管面向文本、代码和图像生成、摘要、问答，以及涉及微调与检索增强生成（RAG）的自定义用例等各种场景的领先基础模型（FM）。在本文中，我们聚焦于美国各 AWS 区域中可用的 [Amazon Nova](https://aws.amazon.com/ai/generative-ai/nova/) 图像生成模型，尤其是 Amazon Nova Canvas 模型。随后我们概述图像生成过程（扩散），并深入探讨使用 Amazon Nova Canvas 进行文本生成图像的各项输入参数。

## 理解生成过程

Amazon Nova Canvas 使用[基于扩散](https://docs.aws.amazon.com/ai/responsible-ai/nova-canvas/overview.html#design)的方法生成图像：

- **起点** – 该过程从随机噪声（一张纯粹的雪花噪点图）开始。
- **迭代去噪 **– 模型在你的 prompt 引导下分步逐渐去除噪声。每一步要移除多少噪声是在训练中学到的。例如，模型要生成一张猫的图像，就必须在多张猫的图像上训练，并迭代地向图像中注入噪声，直到它变成完全的噪声。在学习每一步添加多少噪声的过程中，模型实际上学到了反向过程：从一张噪声图像出发，迭代地减去噪声，最终得到猫的图像。
- **文本条件 **– 文本 prompt 作为条件，引导图像生成过程。prompt 被编码为一个数值向量，并与文本-图像[嵌入空间](https://aws.amazon.com/what-is/embeddings-in-machine-learning/)中对应图像的相似向量进行比对，然后利用这些向量把一张噪声图像转变为捕捉到输入 prompt 的图像。
- **图像条件 **– 除文本 prompt 外，Amazon Nova Canvas 也接受图像作为输入。
- **安全与公平 **– 为符合安全与公平目标，prompt 和生成的输出图像都会经过过滤器。如果没有触发任何过滤器，就返回最终图像。

## prompt 编写基础

图像生成始于有效的 prompt 编写——也就是构思文本描述、引导模型产出你期望结果的艺术。构造良好的 prompt 会包含关于主体、风格、光照、视角、氛围和构图的细节，并且当它以图像说明文字而非命令或对话的形式组织时效果更好。例如，不要说“generate an image of a mountain”，更有效的 prompt 可能是“a majestic snow-capped mountain peak at sunset with dramatic lighting and wispy clouds, photorealistic style.”。有关 prompt 编写的更多信息，请参阅 [Amazon Nova Canvas prompting best practices](https://docs.aws.amazon.com/nova/latest/userguide/prompting-image-generation.html)。

## 正向与负向 prompt

正向 prompt 告诉模型要包含什么，也就是你希望在最终图像中看到的要素、风格和特征。避免在 prompt 中使用“no”“not”或“without”这类否定词。Amazon Nova Canvas 是在图像-说明文字对上训练的，而说明文字很少描述图像中不存在的东西。因此，模型从未学过否定的概念。相反，应使用负向 prompt 来指定要从输出中排除的要素。

负向 prompt 指定要避免的内容。常见的负向 prompt 包括“blurry”“distorted”“low quality”“poor anatomy”“bad proportions”“disfigured hands”或“extra limbs”，它们帮助模型避免典型的生成瑕疵。

## 图像尺寸与宽高比

Amazon Nova Canvas 在 1:1、竖幅和横幅分辨率上训练，生成任务的最大输出分辨率为 419 万像素（即 2048×2048、2816×1536）。对于编辑任务，图像最长边应为 4,096 像素，宽高比在 1:4 到 4:1 之间，总像素数不超过 419 万。理解尺寸限制有助于避免拉伸或失真的结果，对特殊的构图需求尤其如此。

## Classifier-free guidance 缩放

Classifier-free guidance（CFG）缩放控制模型遵循你的 prompt 的严格程度：

- **低值（1.1–3）** – 给 AI 更多创作自由，可能更具美感，但对比度低、对 prompt 的遵循度较差
- **中值（4–7）** – 平衡的做法，通常推荐用于大多数生成任务
- **高值（8–10）** – 严格遵循 prompt，可产生更精确的结果，但有时会牺牲自然的美感并增加色彩饱和度

## 种子值与可复现性

每次图像生成都始于一个随机化种子——本质上是一个决定初始条件的起始数字：

- 种子通常表示为长整数（例如 `1234567890`）
- 使用相同的种子、prompt 和参数，每次都会复现完全相同的图像
- 保存种子可以让你重新回到成功的生成结果，或对有潜力的结果做变体
- 种子值本身没有优劣之分，它们只是不同的起点

通过种子值实现可复现性对专业工作流至关重要：它允许对 prompt 或其他输入参数做精细迭代，从而清楚地看到这些改动的影响，而不是面对完全随机的生成结果。下面的图像使用两个略有不同的 prompt（“A portrait of a girl smiling”与“A portrait of a girl laughing”）生成，同时保持种子值和所有其他参数不变。

本文前面所有图像都是使用 Amazon Nova Canvas 的文本生成图像（`TEXT_IMAGE`）任务类型生成的，该任务类型可通过 Amazon Bedrock [InvokeModel API](https://docs.aws.amazon.com/bedrock/latest/APIReference/API_runtime_InvokeModel.html) 使用。以下是图像生成的 API 请求与响应结构：

```
#Request Structure
{
    "taskType": "TEXT_IMAGE",
    "textToImageParams": {
        "text": string,         #Positive Prompt
        "negativeText": string  #Negative Prompt
    },
    "imageGenerationConfig": {
        "width": int,           #Image Resolution Width
        "height": int,          #Image Resolution Width
        "quality": "standard" | "premium",   #Image Quality
        "cfgScale": float,      #Classifer Free Guidance Scale
        "seed": int,            #Seed value
        "numberOfImages": int   #Number of images to be generated (max 5)
    }
}
#Response Structure
{
    "images": "images": string[], #list of Base64 encoded images
    "error": string
}
```

## 代码示例

该方案也可以在本地用 Python 脚本或 Jupyter notebook 测试。在本文中，我们使用 Python（v3.12）的 [Amazon SageMaker](https://aws.amazon.com/sagemaker-ai) AI notebook。更多信息请参见[使用 Amazon SageMaker AI notebook 运行示例 Amazon Bedrock API 请求](https://docs.aws.amazon.com/bedrock/latest/userguide/getting-started-api-ex-sm.html)。要了解如何设置 SageMaker notebook 实例，请参阅[创建 Amazon SageMaker notebook 实例](https://docs.aws.amazon.com/sagemaker/latest/dg/howitworks-create-ws.html)。请确保实例创建在已启用 Amazon Nova Canvas 访问权限的同一区域。在本文中，我们创建一个区域变量，使其与启用 Amazon Nova Canvas 的区域一致（`us-east-1`）。如果你在其他区域启用了该模型，则必须修改此变量。以下代码演示通过 Amazon Bedrock 调用 Amazon Nova Canvas v1.0 模型来生成文本到图像。要了解不同类型生成的 API 请求与响应结构、参数以及更多代码示例，请参阅[使用 Amazon Nova 生成图像](https://docs.aws.amazon.com/nova/latest/userguide/image-generation.html)。

```
import base64  #For encoding/decoding base64 data
import io  #For handling byte streams
import json  #For JSON processing
import boto3  #AWS SDK for Python
from PIL import Image  #Python Imaging Library for image processing
from botocore.config import Config  #For AWS client configuration

#Create a variable to fix the region to where Nova Canvas is enabled
region = "us-east-1"

#Setup an Amazon Bedrock runtime client
client = boto3.client(service_name='bedrock-runtime', region_name=region, config=Config(read_timeout=300))

#Set the content type and accept headers for the API call
accept = "application/json"
content_type = "application/json"

#Define the prompt for image generation
prompt = """A cat sitting on a chair, mountains in the background, low angle shot."""

#Create the request body with generation parameters
api_request= json.dumps({
        "taskType": "TEXT_IMAGE",  #Specify text-to-image generation
        "textToImageParams": {
            "text": prompt  
        },
        "imageGenerationConfig": {
            "numberOfImages": 1,   #Generate one image
            "height": 720,        #Image height in pixels
            "width": 1280,         #Image width in pixels
            "cfgScale": 7.0,       #CFG Scale
            "seed": 0              #Seed number for generation
        }
})
#Call the Bedrock model to generate the image
response = client.invoke_model(body=api_request, modelId='amazon.nova-canvas-v1:0', accept=accept, 
contentType=content_type)
        
#Parse the JSON response
response_json = json.loads(response.get("body").read())

#Extract the base64-encoded image from the response
base64_image = response_json.get("images")[0]
#Convert the base64 string to ASCII bytes
base64_bytes = base64_image.encode('ascii')
#Decode the base64 bytes to get the actual image bytes
image_data = base64.b64decode(base64_bytes)

#Convert bytes to an image object
output_image = Image.open(io.BytesIO(image_data))
#Display the image
output_image.show()
#Save the image to current working directory
output_image.save('output_image.png')
```
