# GuardianGamer 借助 AWS 扩展家庭安全型云游戏

*本文由 GuardianGamer 的 Heidi Vogel Brockmann 与 Ronald Brockmann 共同撰写。*

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/05/23/guard-gamer2.png)

数以百万计的家庭面临一个共同挑战：如何在不牺牲这些游戏所带来的乐趣与社交联结的前提下，保障孩子在网络游戏中的安全。

本文分享 [GuardianGamer](https://www.guardiangamer.ai/)——[AWS Activate](https://aws.amazon.com/activate/activate-landing/) 初创社区成员——如何利用 AWS 服务构建一个云游戏平台，帮助家长更好地理解并参与孩子的游戏体验。GuardianGamer 专为有 13 岁以下儿童的家庭打造，使用 [Amazon Nova](https://aws.amazon.com/ai/generative-ai/nova/) 与 [Amazon Bedrock](https://aws.amazon.com/bedrock/) 等 AWS 服务，提供可扩展且高效的监护平台。团队使用 Amazon Nova 进行智能叙事生成，为家长提供关于孩子游戏活动与社交互动的有意义洞察，同时保持非侵入式的监控方式。

## 挑战：监控孩子的网络游戏体验

监控孩子在网络游戏中的活动一直让家长不堪重负，可见性很低、控制能力有限。GuardianGamer 填补了市场上的一个重要空白，使家长能够在不打扰孩子的前提下有效监控其游戏活动。

传统的家长控制主要着眼于屏蔽内容，而非提供有关孩子游戏体验与社交互动的有价值数据。这促使 GuardianGamer 的创始人开发更好的方案——利用 AI 对游戏过程与聊天互动进行摘要，帮助家长以非侵入的方式（借助短视频集锦）更好地理解并参与孩子的游戏活动，同时帮助识别潜在的安全隐患。

## 为家长与孩子打造彼此联结的体验

GuardianGamer 是一个专为有 13 岁以下青春前期儿童的家庭构建的云游戏平台，把顺畅的游戏体验与全面的家长洞察结合起来。该平台基于 AWS 构建，并使用 Amazon Nova 进行智能叙事生成；它在串流热门游戏的同时，为家长提供他们迫切需要的、关于孩子游戏活动与社交互动的可见性。该服务通过集成的私密语音聊天同时兼顾安全与社交联结，营造积极的游戏环境，并以非侵入的方式让家长保持知情。

该平台提供两种彼此联结的体验：一种让家长保持知情，另一种让孩子在高度可信且安全的 GuardianGamer 空间中游玩。

对家长而言，GuardianGamer 提供一整套完整的家长参与工具与洞察，使他们能够保持知情并参与到孩子的在线活动中。洞察由游戏与视频理解生成，并通过短信发送给家长，以促成亲子之间的积极对话。借助这些工具，家长可以主动管理孩子的游戏体验，享受安全而均衡的在线娱乐方式。

对孩子而言，GuardianGamer 提供低延迟、不被打断的游戏体验，同时还能进行社交互动。该平台让孩子能够只在一个由家长逐一审核并批准的、可信的朋友圈内联络与游玩，为孩子现实世界中的关系打造安全的数字延伸。这将游戏时光转变为由学校、运动与社区活动建立的友谊的自然延伸，而这些体验又因先进的家长端 AI 洞察而进一步增强。

通过将技术、社区与家庭无缝融合，GuardianGamer 打造了一个更安全、更充实的数字空间，名为“[The Trusted Way for Kids to Play](https://youtu.be/Pr8Z1JVvoKg)”。

## 方案概览

当 GuardianGamer 团队着手构建一个帮助家长监护孩子在 Minecraft、Roblox 及其他游戏中游戏体验的平台时，他们知道自己需要一个具备全球覆盖能力与经过验证的可扩展性的云基础设施合作伙伴。由于此前项目已与 AWS 合作，团队认为 AWS 是他们这一宏大愿景的自然之选。

> “我们的目标是构建一个能从零扩展到全球数百万用户、同时保持低延迟与高可靠性的方案——而且要依靠一支小而精悍的工程团队。AWS 的无服务器架构恰好给了我们所需的一切，而无需投入庞大的 DevOps 资源。”
>         – Heidi Vogel Brockmann，GuardianGamer 创始人兼 CEO。

下图展示了后端的 AWS 架构。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/05/23/blog_gaming_ai_highlights.png)

GuardianGamer 的后端使用基于 [AWS Lambda](https://aws.amazon.com/lambda/)、[Amazon DynamoDB](https://aws.amazon.com/dynamodb/)、[Amazon Cognito](https://aws.amazon.com/cognito/)、[Amazon Simple Storage Service](https://aws.amazon.com/s3/)（Amazon S3）与 [Amazon Simple Notification Service](https://aws.amazon.com/sns/)（Amazon SNS）构建的完全无服务器技术栈，使平台能够随着用户采用度增长而轻松扩展，同时把运维开销保持在最低水平。该架构使团队得以专注于其核心创新：面向家长的 AI 驱动游戏监护，而不是基础设施管理。

云游戏组件带来了独特的挑战，需要靠近全球各地用户的低延迟 GPU 资源。

> “游戏本身就是一项全球性活动，延迟可能成就也可能毁掉用户体验。广泛的 Region 覆盖与多样的 Amazon Elastic Compute Cloud（Amazon EC2）实例类型，使我们能够灵活地把游戏服务器部署在用户所在之处。”
>         – Heidi Vogel Brockmann。

团队使用 [Amazon Elastic File System](https://aws.amazon.com/efs/)（Amazon EFS）在每个 AWS Region 内高效存储游戏状态，并使用 [Amazon Elastic Container Service](https://aws.amazon.com/ecs/)（Amazon ECS）简化集群管理。

对于构成 GuardianGamer 家长监护功能核心的 AI 分析能力，团队依靠 [AWS Batch](https://aws.amazon.com/batch/) 协调分析作业，并由 Amazon Bedrock 提供对强大大语言模型（LLM）的访问。

> “我们目前使用 Amazon Nova Lite 生成摘要并挑选精彩视频，帮助家长快速了解孩子游戏过程中发生了什么，而无需观看数小时内容，每天只需几分钟就能了解近况，并开启与孩子的知情对话。”
>         – Heidi Vogel Brockmann。

## 成果

AWS 与 GuardianGamer 携手，成功将 GuardianGamer 的云游戏平台扩展到可在多个游戏环境中承载数千名并发用户。该公司近期在既有 Minecraft 能力之外新增了对 Roblox 的支持，将其可服务市场扩大到 1.6 亿儿童及其家庭。

> “我们这套实现特别之处在于，我们使用 Amazon Nova 持续记录每个孩子跨会话的游戏活动。当家长打开我们的应用时，他们看到的是一份关于孩子数字旅程的完整视图，而不只是孤立的片段。”
>         – Ronald Brockmann，GuardianGamer CTO。

## 结论

GuardianGamer 展示了小规模敏捷团队如何利用 AWS 服务构建复杂的 AI 驱动游戏平台，同时兼顾儿童安全与家长参与。通过将跨多个 Region 的云游戏基础设施与 Amazon Bedrock、Amazon Nova 的能力相结合，GuardianGamer 正在开创家庭友好型游戏的新方式。借助持续的家长反馈与负责任的 AI 实践，该平台在保持快速创新的同时，交付更安全、更透明的游戏体验。

> “AWS 在汇聚公司内部不同团队与技术以支持我们愿景方面表现出色。我们先进的架构利用了多个专门的 AI 组件，包括语音分析、视频处理与游戏元数据采集。我们尤其期待引入 Amazon Nova，它帮助我们把复杂的游戏数据转化为面向家长的连贯叙事。有 AWS 作为我们的扩展伙伴，我们相信能够把服务交付给全球数以百万计的家庭。”
>         –  Heidi Vogel Brockmann。
