## 理解 Model Context Protocol

[Model Context Protocol](https://www.anthropic.com/news/model-context-protocol)（MCP）是由 Anthropic 开发的开放标准，用于在 AI 模型与多种数据源（包括内容存储库、业务工具和开发环境）之间建立安全、双向的连接。通过标准化这些交互，MCP 使 AI 系统能够获取所需的数据，从而给出更相关、更准确的响应。

MCP 采用客户端-服务器架构运行，开发者既可以通过 MCP server 暴露自己的数据，也可以构建连接到这些 server 的 AI 应用（MCP 客户端）。这种设置让集成过程更精简、更具可扩展性，取代了为每个数据源单独编写自定义连接器的做法。

## 用 Amazon Bedrock Data Automation 和 MCP server 增强 Amazon Q

Bedrock Data Automation 通过提供一整套强大的工具来补充 MCP，这些工具能够以最少的人工干预、大规模地自动化企业数据向 AI 工作流的抽取、转换和加载（ETL）。借助 Bedrock Data Automation，客户可以：

- 从文档、图像、音频和视频文件等多种来源中抽取非结构化数据。
- 借助 [Blueprints](https://docs.aws.amazon.com/bedrock/latest/userguide/bda-blueprint-info.html)、置信度评分和负责任 AI 实践，通过由 schema 驱动的抽取来转换并校验数据，以保持准确性、完整性和一致性。
- 将可直接使用的数据加载到 AI 模型中，从而跨业务实现实时、具备上下文感知的推理。

这种深度集成确保 AI 模型不只是与数据相连，而是建立在干净、经过校验且上下文丰富的信息之上。因此，智能 agent 能够交付更准确、更相关、更可靠的输出，帮助整个企业更快地做出决策、获得更丰富的洞察。Amazon Q Developer 是 AWS 推出的、由生成式 AI 驱动的对话式助手，旨在帮助软件开发人员和 IT 专业人员以更快的速度、更高的安全性和效率构建、运营和改造软件。它相当于一个智能编码伙伴和生产力工具，与 AWS 环境集成，可在流行的代码编辑器、AWS 管理控制台以及 Microsoft Teams 和 Slack 等协作工具中使用。如下图所示，Bedrock Data Automation MCP server 的工作方式如下：

- 用户向 MCP Host 发送“Request action”。
- MCP Host 用 LLM 处理该请求。
- 随后 MCP Host 向 MCP Client 请求执行工具。
- MCP Client 向 MCP Server 发起工具调用请求。
- MCP Server 向 Bedrock Data Automation 发起 API 请求。
- Bedrock Data Automation 向 MCP Server 返回 API 响应。
- MCP Server 把工具结果返回给 MCP Client。
- MCP Client 把结果回传给 MCP Host。
- MCP Host 再次用 LLM 进行处理。
- MCP Host 向用户发送最终响应。

## 分步指南

如果你是第一次使用 AWS MCP server，请访问 [AWS Labs GitHub 仓库中的安装与设置指南](https://github.com/awslabs/mcp?tab=readme-ov-file#installation-and-setup) 获取安装说明。安装完成后，将下面的 MCP server 配置添加到你的本地环境：

### 前置条件

- 你需要一个 AWS 账户，以及一个具有创建和管理此应用所需资源与组件权限的 [AWS Identity and Access Management (IAM)](https://aws.amazon.com/iam/) 角色和用户。如果你没有 AWS 账户，请参阅[如何创建并激活新的 Amazon Web Services 账户？](https://aws.amazon.com/premiumsupport/knowledge-center/create-and-activate-aws-account/)
- Bedrock Data Automation MCP 需要一个 [Amazon Simple Storage Service (Amazon S3)](https://aws.amazon.com/s3) 存储桶才能正常工作。如果你需要新建 S3 存储桶，请遵循 AWS 关于存储桶配置的[安全最佳实践](https://docs.aws.amazon.com/AmazonS3/latest/userguide/security-best-practices.html)。
- [NodeJS 和 NPM](https://nodejs.org/en/download)
- 按照这些[说明](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/command-line-installing.html)设置 Amazon Q

### 设置 MCP

安装 [Amazon Q for command line](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/command-line-installing.html) 并把配置添加到 `~/.aws/amazonq/mcp.json`。如果你已经是 Amazon Q CLI 用户，只需添加该配置即可。

```
{
  "mcpServers": {
    "bedrock-data-automation-mcp-server": {
      "command": "uvx",
      "args": [
        "awslabs.aws-bedrock-data-automation-mcp-server@latest"
      ],
      "env": {
        "AWS_PROFILE": "your-aws-profile",
        "AWS_REGION": "your-aws-region",
        "AWS_BUCKET_NAME": "amzn-s3-demo-bucket"
      }
    }
  }
}
```

要确认设置是否成功，打开终端并输入 `q chat`，进入与 Amazon Q 的聊天会话。

想知道有哪些工具可用？输入：`"Tell me the tools I have access to"`

## 清理

完成 Amazon Bedrock Data Automation MCP server 的使用后，请按照以下步骤执行清理：

- 清空并删除用于 Bedrock Data Automation 的 S3 存储桶。

```
   aws s3 rm s3://amzn-s3-demo-bucket --recursive
    aws s3 rb s3://amzn-s3-demo-bucket
```

- 从 `~/.aws/amazonq/mcp.json` 中移除为 `bedrock-data-automation-mcp-server` 添加的配置。
