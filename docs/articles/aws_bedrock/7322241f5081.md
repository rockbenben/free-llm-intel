今天，我们很高兴地宣布 Claude Opus 5.5 在 [Amazon Bedrock](https://aws.amazon.com/bedrock/) 和 [Claude Platform on AWS](https://aws.amazon.com/blogs/machine-learning/introducing-claude-platform-on-aws-anthropics-native-platform-through-your-aws-account/) 上可用，它是 Claude 5.5 模型家族的首个成员。Claude Opus 5.5 是 Anthropic 最强大的、适用于智能体式编码、知识工作和长时间运行任务的 Opus 模型。

本文涵盖 Claude Opus 5.5 的改进、实用指导，以及如何在 Amazon Bedrock 上开始用该模型构建。

## 是什么让 Claude Opus 5.5 与众不同

据 Anthropic 称，Claude Opus 5.5 用比 Claude Opus 5 更少的 token 做更多的事，而新的定价把这些收益直接让利给客户。更低的每-token 价格和便宜得多的缓存读取叠加在效率收益之上。结果是平均每个任务的成本比 Claude Opus 5 更低，于是团队能够以规模化运行更有雄心的智能体式工作。

Claude Opus 5.5 经过训练以更清晰地沟通。在它工作时，它会呈现它做了什么、发现了什么、需要什么，使长时间任务更易跟进。自适应思考（adaptive thinking）始终开启，Opus 5.5 自行决定每个任务需要多少推理。你可以用 effort（努力程度）作为你的控制手段，而非手动的思考预算。

Claude Opus 5.5 是首个自带类似 Claude Fable 5.1 在生物学、网络安全和 AI 开发方面安全分类器的 Opus 模型。与之前的 Opus 版本相比，请求被拒绝的频率会更高。

## 用例

Claude Opus 5.5 的能力很适合那些一致性和深度最重要的行业。在软件开发中，对于带清晰沟通和可解释性的、运行更长的会话，Opus 5.5 相比 Opus 5 有所改进，使其更易用、易审阅、可信。对于知识工作，它在处理和创建长文档与报告时，比 Opus 5 需要更少的纠正。

## 在 Amazon Bedrock 上开始使用 Claude Opus 5.5

要试用 Claude Opus 5.5，打开 [Amazon Bedrock 控制台](https://console.aws.amazon.com/bedrock/)，选择 **Test**，然后 **Playground**，并把 **Claude Opus 5.5** 选为模型。从这里，你可以直接对它运行一个 prompt。

图 1：在 Amazon Bedrock 控制台 Playground 中选择一个 Anthropic Claude 模型

图 2：在 Amazon Bedrock 控制台 Playground 中对一个 Claude 模型运行 prompt

以编程方式，你可以通过 Anthropic SDK 针对 `bedrock-runtime` 和 `bedrock-mantle` 用 [Anthropic Messages API](https://docs.aws.amazon.com/bedrock/latest/userguide/model-parameters-anthropic-claude-messages.html) 调用该模型。你也可以通过 [AWS Command Line Interface (AWS CLI)](https://aws.amazon.com/cli/) 和 [AWS SDK](https://aws.amazon.com/developer/tools/)，留在 `bedrock-runtime` 上使用 [Invoke](https://docs.aws.amazon.com/bedrock/latest/userguide/inference-api.html) 和 [Converse](https://docs.aws.amazon.com/bedrock/latest/userguide/conversation-inference.html) API。

### 前提条件

- 拥有 Amazon Bedrock 访问权限的有效 AWS 账户。
- 已安装并配置 AWS Command Line Interface (AWS CLI)。
- Python 3.10+。
- 已安装 Boto3：`pip install boto3`。
- 已安装 Anthropic SDK：`pip install anthropic`。
- 已安装用于 Amazon Bedrock 认证的 Amazon Bedrock Token Generator：`pip install aws_bedrock_token_generator`。
- AWS Identity and Access Management (IAM) 权限：`bedrock:InvokeModel` 和 `bedrock:InvokeModelWithResponseStream`。

下面是使用 AWS SDK for Python (Boto3) 的一个简短示例：

```
import boto3
import json

# Create a Bedrock Runtime client
bedrock_runtime = boto3.client(
    service_name="bedrock-runtime",
    region_name="us-east-1"
)

# Invoke Claude Opus 5.5
response = bedrock_runtime.invoke_model(
    modelId="global.anthropic.claude-opus-5-5",
    contentType="application/json",
    accept="application/json",
    body=json.dumps({
        "anthropic_version": "bedrock-2023-05-31",
        "max_tokens": 4096,
        "messages": [
            {
                "role": "user",
                "content": "An S3 bucket serves 40 TB/month egress. Estimate the monthly egress cost at $0.09/GB, and state one architecture change to cut it. Show the calculation, keep it under 120 words."
            }
        ]
    })
)

result = json.loads(response["body"].read())
# Opus 5.5 is a reasoning model: the response may include a thinking block
# before the text block, so select the text block rather than a fixed index.
print(next(b["text"] for b in result["content"] if b["type"] == "text"))
```

你也可以使用 Amazon Bedrock Converse API 获得统一的多模型体验：

```
import boto3

# Create a Bedrock Runtime client
bedrock_runtime = boto3.client(
    service_name="bedrock-runtime",
    region_name="us-east-1"
)

# Invoke Claude Opus 5.5
response = bedrock_runtime.converse(
    modelId="global.anthropic.claude-opus-5-5",
    messages=[
        {
            "role": "user",
            "content": [
                {
                    "text": "Can you explain the features of Amazon Bedrock?"
                }
            ]
        }
    ],
    inferenceConfig={
        "maxTokens": 4096
    }
)

if 'output' in response:
    blocks = response['output']['message']['content']
    print('\n'.join(b.get('text', '') for b in blocks if 'text' in b))
```

你也可以通过 `anthropic` SDK 包使用 Anthropic Messages API 获得更简洁的体验：

```
from anthropic import Anthropic
from aws_bedrock_token_generator import provide_token

token = provide_token(region="us-east-1")

client = Anthropic(
    base_url="https://bedrock-runtime.us-east-1.amazonaws.com/anthropic",
    api_key=token,
)

# Invoke Claude Opus 5.5
response = client.messages.create(
    model="global.anthropic.claude-opus-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Can you explain the features of Amazon Bedrock?"}],
)
print(response)
```

## 可用性

Claude Opus 5.5 今天可通过 `bedrock-runtime` 上的美国地理 CRIS（`us.`）、欧盟地理 CRIS（`eu.`）、澳大利亚地理 CRIS（`au.`）、日本地理 CRIS（`jp.`）和全球 CRIS（`global.`）推理配置，在 Amazon Bedrock 上获取。该模型还在 bedrock-mantle 上的美国东部（弗吉尼亚北部）区域（`us-east-1`）和亚太东南（墨尔本）区域（`ap-southeast-4`）运行。

受支持区域的完整列表见 [Amazon Bedrock 文档](https://docs.aws.amazon.com/bedrock/latest/userguide/model-cards-anthropic.html)。定价信息见 [Amazon Bedrock 定价](https://aws.amazon.com/bedrock/pricing/)。它在北美也可通过 Claude Platform on AWS 获取。

在 [Amazon Bedrock 控制台](https://console.aws.amazon.com/bedrock)、[Claude Platform on AWS](https://console.aws.amazon.com/claude-platform) 中试用 Claude Opus 5.5，或在 GitHub 上探索 [Getting Started notebooks](https://github.com/aws-samples/anthropic-on-aws/tree/main/notebooks)。
