# 借助 Amazon Bedrock Data Automation 与开放集目标检测增强视频理解

在现实世界的视频和图像分析中，企业常常面临这样的挑战：检测那些不属于模型原始训练集的目标。在动态环境中，当新的、未知的或用户自定义的目标频繁出现时，这尤其困难。例如，媒体发行方可能想跟踪用户生成内容中新兴的品牌或产品；广告主需要分析网红视频中的产品出现情况，即便存在视觉差异；零售服务商希望支持灵活的、描述性的搜索；自动驾驶汽车必须识别出意料之外的路面障碍物；制造系统需要在没有事先标注的情况下发现新颖或细微的缺陷。在所有这些场景中，传统的闭集目标检测（CSOD）模型——只识别一组固定预定义类别——都无法胜任。它们要么把未知目标分错类，要么完全忽略它们，从而限制了其在现实应用中的价值。开放集目标检测（OSOD）是一种让模型既能检测已知目标、也能检测此前未见过的目标（包括训练中未遇到的目标）的方法。它支持灵活的输入 prompt，从具体的物体名称到开放式的描述，并且可以在无需重新训练的情况下实时适应用户自定义的目标。通过把视觉识别与语义理解结合（通常借助视觉语言模型），OSOD 帮助用户对系统进行宽泛的查询，即便目标是不熟悉的、含糊的或全新的。

本文探讨 [Amazon Bedrock Data Automation](https://aws.amazon.com/bedrock/bda/) 如何利用 OSOD 增强视频理解。

## Amazon Bedrock Data Automation 与支持 OSOD 的视频 blueprint

Amazon Bedrock Data Automation 是一项基于云的服务，可从文档、图像、视频和音频等非结构化内容中提取洞见。具体到视频内容，Amazon Bedrock Data Automation 支持章节切分、帧级文本检测、基于 Interactive Advertising Bureau（IAB）分类法的章节级分类，以及帧级 OSOD。有关 Amazon Bedrock Data Automation 的更多信息，请参阅[使用 Amazon Bedrock Data Automation 为情境广告自动化提取视频洞见](https://aws.amazon.com/blogs/machine-learning/automate-video-insights-for-contextual-advertising-using-amazon-bedrock-data-automation/)。

Amazon Bedrock Data Automation 视频 blueprint 支持帧级 OSOD。你可以输入一段视频，同时给出文本 prompt 指定要检测的目标。对于每一帧，模型会输出一个字典，包含以 XYWH 格式表示的边界框（左上角的 x、y 坐标，随后是框的宽度和高度），以及相应的标签和置信度分数。你还可以根据需求进一步定制输出——例如，在优先考虑精确度时按高置信度检测结果过滤。

输入文本高度灵活，因此你可以在由 OSOD 驱动的 Amazon Bedrock Data Automation 视频 blueprint 中定义动态字段。

## 视频 blueprint 的示例输入与输出

以下示例演示如何定义一个 Amazon Bedrock Data Automation 视频 blueprint，以在章节级别检测视觉上显著的目标，并给出包含目标及其边界框的示例输出。

以下代码是我们的示例 blueprint schema：

```
blueprint = {
  "$schema": "http://json-schema.org/draft-07/schema#",
  "description": "This blueprint enhances the searchability and discoverability of video content by providing comprehensive object detection and scene analysis.",
  "class": "media_search_video_analysis",
  "type": "object",
  "properties": {
    # Targeted Object Detection: Identifies visually prominent objects in the video
    # Set granularity to chapter level for more precise object detection
    "targeted-object-detection": {
      "type": "array",
      "instruction": "Please detect all the visually prominent objects in the video",
      "items": {
        "$ref": "bedrock-data-automation#/definitions/Entity"
      },
      "granularity": ["chapter"]  # Chapter-level granularity provides per-scene object detection
    },  
  }
}
```

## 结论

Amazon Bedrock Data Automation 中的 OSOD 能力显著增强了从视频内容中提取可执行洞见的能力。通过把灵活的文本驱动查询与帧级目标定位结合，OSOD 帮助各行业的用户实施智能视频分析工作流——从有针对性的广告评估、安防监控，到自定义目标跟踪。OSOD 无缝集成到 Amazon Bedrock Data Automation 中更广泛的视频分析工具套件里，不仅简化了内容理解，还有助于减少人工干预和对僵化预定义 schema 的需求，使其成为面向可扩展的现实应用的有力工具。
