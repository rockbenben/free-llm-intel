# 使用生成式 AI 与 Amazon Bedrock 对特权访问管理进行视频安全分析

金融服务等受到高度监管的行业中的安全团队，常常采用特权访问管理（PAM）系统来保护、管理和监控其关键 IT 基础设施上特权访问的使用。安全与合规法规要求安全团队审计系统管理员使用特权凭证所执行的操作。击键记录（把键盘上敲击的按键记录到日志中的行为）与服务器控制台会话的录像，是 PAM 系统的一项功能，可让安全团队满足这些安全与合规义务。

击键记录会产生一个可以程序化解析的数据集，从而能够快速、大规模地审查这些会话中的活动是否存在异常。然而，把击键捕获到日志中并不总是可行。Windows 等操作系统主要通过图形用户界面进行交互，这使 PAM 系统只能把这些特权访问会话中的活动捕获为服务器控制台的视频录像。

视频录像无法像日志文件那样被轻易解析，需要安全团队成员回放录像，以审查其中执行的操作。一家金融服务机构的典型 PAM 系统每月可产生超过 100,000 小时的视频录像。如果这些录像中只有 30% 来自 Windows Server，那就需要 1,000 名员工全天候工作才能全部审查完。因此，安全团队只能进行随机抽查，这影响了他们发现恶意行为者造成的安全异常的能力。

下图是一个简单的 Windows Server 控制台活动示例，这类活动可以被捕获为视频录像。

![hello-world 的视频录像 :)](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/01/08/ml-17204-hello-world-1.gif)

AI 服务已经彻底改变了我们处理、分析视频内容并从中提取洞见的方式。这些服务使用先进的机器学习（ML）算法和计算机视觉技术来执行目标检测与跟踪、活动识别以及文本和音频识别等功能。然而，要从视觉上可观察到的内容来描述视频中正在发生什么，我们可以借助[生成式 AI](https://aws.amazon.com/generative-ai/) 的图像分析能力。

多模态大语言模型（MLLM）的进展，例如 Anthropic 最先进的 [Claude 3](https://www.anthropic.com/news/claude-3-family)，带来了前沿的计算机视觉技术，使 Anthropic 的 Claude 能够解读视觉信息，理解图像中所描绘的关系、活动与更广泛的上下文。借助这一能力，安全团队可以把所有视频录像处理成文字记录。随后便可以针对这些文字记录进行安全分析，使组织能够提升发现恶意行为者造成的安全异常的能力，从而改善其安全态势。

本文介绍如何使用 [Amazon Bedrock](https://aws.amazon.com/bedrock/?nc2=h_ql_prod_ml_br) 和 [Anthropic 的 Claude 3 ](https://aws.amazon.com/bedrock/claude/)来解决这个问题。我们将说明端到端的解决方案工作流、生成文字记录和执行安全分析所需的 prompt，并提供一个可部署的解决方案架构。

Amazon Bedrock 是一项全托管服务，它通过 API 提供来自领先 AI 初创公司和 Amazon 的基础模型（FM），因此你可以从广泛的 FM 中选择最适合自己用例的模型。借助 Amazon Bedrock 的无服务器体验，你可以快速上手，用你自己的数据私密地定制 FM，并使用 AWS 工具把它们集成和部署到你的应用中，而无需管理任何基础设施。

## 解决方案工作流

我们的解决方案需要一个两阶段的工作流：视频转写和安全分析。第一阶段使用 Anthropic 的 Claude 生成视频录像的文字记录。第二阶段使用 Anthropic 的 Claude 分析文字记录，找出安全异常。

### 第一阶段：视频转写

撰写本文时，许多可用的 MLLM（包括 Anthropic 的 Claude）无法直接处理 MPEG 和 AVI 这类顺序视觉数据格式；即使有些模型可以，其性能和准确性也低于分析静态图像时所能达到的水平。正因为如此，我们需要把视频录像拆分成一系列静态图像，供 Anthropic 的 Claude 分析。

下图展示了我们将用于执行视频转写的工作流。

![第一阶段高层工作流](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/01/08/ml-17204-high-level-workflow-stage1.png)

我们工作流的第一步是从视频录像中每秒提取一帧静止图像。然后我们把图像编排进 prompt，指示 Anthropic 的 Claude Haiku 3 分析这些图像并生成视觉文字记录。撰写本文时，Amazon Bedrock 上的 Anthropic 的 Claude 一次最多只能接受 20 张图像；因此，要转写长于 20 秒的视频，我们需要分批提交图像，为每个 20 秒的片段生成文字记录。在所有片段都分别转写完成后，我们再把它们编排进另一个 prompt，指示 Anthropic 的 Claude Sonnet 3 把这些片段汇总成完整的文字记录。

### 第二阶段：安全分析

第二阶段可以执行多次，针对合并后的文字记录运行不同的查询以进行安全分析。

下图展示了我们将用于对汇总后的视频文字记录执行安全分析的工作流。

![第二阶段高层工作流](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/01/08/ml-17204-high-level-workflow-stage2.png)

针对文字记录执行的安全分析类型会因多种因素而异，例如录像所在服务器的数据分类或重要性级别。以下是可执行的一些常见安全分析示例：

- **变更请求运行手册一致性** —— 把文字记录中描述的操作与相关变更请求的运行手册中定义的步骤进行比较。突出显示任何看起来不属于该运行手册的操作。
- **敏感数据访问与外泄风险** —— 分析文字记录中描述的操作，判断是否有任何敏感数据可能已被访问、更改或复制到外部位置。
- **权限提升风险** —— 分析文字记录中描述的操作，判断是否有任何试图提升权限或未经授权访问系统的行为。

这个工作流提供了通过 Anthropic 的 Claude 把视频录像处理成文字记录并执行安全分析的机械性功能。该解决方案能力的关键，在于我们精心设计、用于指示 Anthropic 的 Claude 该做什么的 prompt。

## Prompt 工程

Prompt 工程是精心设计交给 LLM 和其他生成式 AI 系统的输入 prompt 或指令的过程。这些 prompt 对于决定 AI 所生成输出的质量、相关性和连贯性至关重要。

关于 prompt 工程的全面指南，请参阅 [Prompt 工程技巧与最佳实践：在 Amazon Bedrock 上动手实践 Anthropic 的 Claude 3](https://aws.amazon.com/blogs/machine-learning/prompt-engineering-techniques-and-best-practices-learn-by-doing-with-anthropics-claude-3-on-amazon-bedrock/)。

### 视频转写 prompt（第一阶段）

我们解决方案的实用性取决于 Anthropic 的 Claude 在收到待分析图像后返回的文字记录的准确性。我们还必须考虑到我们所要求 Anthropic 的 Claude 分析的数据本身的局限。我们传给 Anthropic 的 Claude 的图像序列，往往缺少足以确凿判断正在执行什么操作所需的视觉线索。例如，使用 **Ctrl + S** 这样的快捷键保存文档，无法从控制台的一张图像中检测出来。按钮或菜单项的点击也可能发生在两帧静止图像之间 1 fps 的时间间隔内。这些局限可能导致 Anthropic 的 Claude 对正在执行的操作做出不准确的假设。为应对这一点，我们在 prompt 中加入指令：不要做假设，并在无法明确判断某个操作是否执行时打上标记。

生成式 AI 模型的输出永远不可能 100% 准确，但我们可以设计一个复杂的 prompt，让产出的文字记录达到足以支持我们安全分析目的的准确度。我们随解决方案一起提供了一个示例 prompt，后文会进一步详述，你可以随意改编和修改。通过在 prompt 中使用任务上下文、详细的任务描述与规则、即时任务，以及逐步思考的指令，我们通过描述 Anthropic 的 Claude 要扮演的角色和要执行的任务来影响图像分析的准确性。借助示例和输出格式元素，我们可以控制作为输出收到的文字记录的一致性。

要了解更多关于创建复杂 prompt 的内容并获得实践经验，请参阅我们的 [Prompt Engineering with Anthropic’s Claude 3](https://catalog.workshops.aws/prompt-eng-claude3/en-US) 工作坊中的 [Complex Prompts from Scratch](https://catalog.workshops.aws/prompt-eng-claude3/en-US/lessons/lab-9-complex-prompts-from-scratch) 实验。

以下是我们的任务上下文示例：

```
You are a Video Transcriptionist who specializes in watching recordings from Windows 
Server Consoles, providing a summary description of what tasks you visually observe 
taking place in videos.  You will carefully watch through the video and document the 
various tasks, configurations, and processes that you see being performed by the IT 
Systems Administrator. Your goal is to create a comprehensive, step-by-step transcript 
that captures all the relevant details.
```

以下是对任务的详细描述与规则：

```
Here is a description of how you will function:
- You receive an ordered sequence of still frame images taken from a sample of a video 
recording.
- You will analyze each of the still frame images in the video sequence, comparing the 
previous image to the current image, and determine a list of actions being performed by 
the IT Systems Administrator.
- You will capture detail about the applications being launched, websites accessed, 
files accessed or updated.
- Where you identify a Command Line Interface in use by the IT Systems Administrator, 
you will capture the commands being executed.
- If there are many small actions such as typing text letter by letter then you can 
summarize them as one step.
- If there is a big change between frames and the individual actions have not been 
captured then you should describe what you think has happened. Precede that description 
with the word ASSUMPTION to clearly mark that you are making an assumption.
```

以下是一些示例：

```
Here is an example.
<example>
1. The Windows Server desktop is displayed.
2. The administrator opens the Start menu.
3. The administrator uses the search bar to search for and launch the Paint application.
4. The Paint application window opens, displaying a blank canvas.
5. The administrator selects the Text tool from the toolbar in Paint.
6. The administrator types the text "Hello" using the keyboard.
7. The administrator types the text "World!" using the keyboard, completing the phrase 
"Hello World!".
8. The administrator adds a smiley face emoticon ":" and ")" to the end of the text.
9. ASSUMPTION: The administrator saves the Paint file.
10. ASSUMPTION: The administrator closes the Paint application.
</example>
```

下面概述即时任务：

```
Analyze the actions the administrator performs.
```

以下是指示逐步思考的内容：

```
Think step-by-step before you narrate what action the administrator took in 
<thinking></thinking> tags.
First, observe the images thoroughly and write down the key UI elements that are 
relevant to administrator input, for example text input, mouse clicks, and buttons.
Then identify which UI elements changed from the previous frame to the current frame. 
Then think about all the potential administrator actions that resulted in the change.
Finally, write down the most likely action that the user took in 
<narration></narration> tags.
```

最后，以下是输出格式的示例：

```
Detail each of the actions in a numbered list.
Do not provide any preamble, only output the list of actions and start with 1.
Put your response in <narration></narration> tags.
```

### 汇总文字记录 prompt（第一阶段）

为了生成汇总的文字记录，我们把所有片段的文字记录连同如何合并它们、如何格式化输出的说明，放在单个 prompt 中传给 Anthropic 的 Claude：

```
Combine the lists of actions in the provided messages.
List all the steps as a numbered list and start with 1.
You must keep the ASSUMPTION: where it is used.
Keep the style of the list of actions.
Do not provide any preamble, and only output the list of actions.
```

### 安全分析 prompt（第二阶段）

我们用于安全分析的 prompt 需要把汇总后的文字记录连同要执行的安全分析说明一起放在 prompt 中提供给 Anthropic 的 Claude。

以下 prompt 用于检查是否符合变更请求运行手册：

```
You are an IT Security Auditor. You will be given two documents to compare.
The first document is a runbook for an IT Change Management Ticket that describes the 
steps an IT Administrator is going to perform.
The second document is a transcript of a video recording taken in the Windows Server 
Console that the IT Administrator used to complete the steps described in the runbook. 
Your task is to compare the transcript with the runbook and assess whether there are 
any anomalies that could be a security concern.

You carefully review the two documents provided - the runbook for an IT Change 
Management Ticket and the transcript of the video recording from the Windows Server 
Console - to identify any anomalies that could be a security concern.

As the IT Security Auditor, you will provide your assessment as follows:
1. Comparison of the Runbook and Transcript:
- You will closely examine each step in the runbook and compare it to the actions 
taken by the IT Administrator in the transcript.
- You will look for any deviations or additional steps that were not outlined in the 
runbook, which could indicate unauthorized or potentially malicious activities.
- You will also check if the sequence of actions in the transcript matches the steps 
described in the runbook.
2. Identification of Anomalies:
- You will carefully analyze the transcript for any unusual commands, script executions,
 or access to sensitive systems or data that were not mentioned in the runbook.
- You will look for any indications of privilege escalation, unauthorized access 
attempts, or the use of tools or techniques that could be used for malicious purposes.
- You will also check for any discrepancies between the reported actions in the runbook 
and the actual actions taken, as recorded in the transcript.

Here are the two documents.  The runbook for the IT Change Management ticket is provided 
in <runbook> tags.  The transcript is provided in <transcript> tags.
```

以下 prompt 用于敏感数据访问与外泄风险：

```
You are an IT Security Auditor. You will be given a transcript that describes the actions 
performed by an IT Administrator on a Window Server.  Your task is to assess whether there 
are any actions taken, such as accessing, changing or copying of sensitive data, that could 
be a breach of data privacy, data security or a data exfiltration risk.

The transcript is provided in <transcript> tags.
```

以下 prompt 用于权限提升风险：

```
You are an IT Security Auditor. You will be given a transcript that describes the actions 
performed by an IT Administrator on a Window Server. Your task is to assess whether there 
are any actions taken that could represent an attempt to elevate privileges or gain 
unauthorized access to a system.

The transcript is provided in <transcript> tags.
```

## 解决方案概览

该无服务器架构提供了一个视频处理 pipeline 来运行工作流的第一阶段，并为第二阶段对汇总文字记录的安全分析提供了一个简单的 UI。该架构可用于演示，以及用你自己的视频录像和 prompt 进行测试；不过，它不适合生产使用。

下图展示了解决方案架构。

![解决方案架构](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/01/08/ml-17204-solution-architecture.png)

在第一阶段，视频录像被上传到 [Amazon Simple Storage Service](https://aws.amazon.com/s3/?nc2=h_ql_prod_st_s3)（Amazon S3）存储桶，该存储桶会把对象创建通知发送给 [Amazon EventBridge](https://aws.amazon.com/eventbridge)。随后 EventBridge 规则触发 [AWS Step Functions](https://aws.amazon.com/step-functions/?nc2=h_ql_prod_ap_stf) 工作流，开始把视频录像处理成文字记录。Step Functions 工作流从视频录像生成静止图像帧，并上传到另一个 S3 存储桶。然后该工作流并行运行任务，把每个 20 秒片段的图像提交给 Amazon Bedrock 进行转写，再把输出写入 [Amazon DynamoDB](https://aws.amazon.com/dynamodb/?nc2=h_ql_prod_db_ddb) 表。各片段的文字记录会传给工作流中的最后一个任务，该任务把它们连同合并成汇总文字记录的指令一起提交给 Amazon Bedrock，汇总结果写入 DynamoDB。

UI 由一个简单的 [Streamlit](https://docs.streamlit.io/get-started) 应用提供，该应用可访问 DynamoDB 和 Amazon Bedrock API。通过 Streamlit 应用，用户可以从 DynamoDB 读取文字记录，并提交给 Amazon Bedrock 进行安全分析。

## 结论

本文展示了一个创新解决方案，用于应对受高度监管行业的安全团队所面临的一项挑战：对特权访问管理（PAM）系统产生的大量视频录像进行高效的安全分析。我们演示了如何使用 Anthropic 的 Claude 3 系列模型和 Amazon Bedrock 来完成分析服务器控制台会话视频录像这一复杂任务，并执行查询以突出显示任何潜在的安全异常。

我们还提供了一个模板，说明如何分析从视频录像中提取的静止图像序列，该模板可应用于不同类型的视频内容。你可以使用本文描述的技术开发自己的视频转写解决方案。通过针对你的视频内容类型调整 prompt 工程，你可以让解决方案适配你的用例。此外，通过使用 Amazon Bedrock 中的[模型评估](https://aws.amazon.com/blogs/aws/amazon-bedrock-model-evaluation-is-now-generally-available/)，你可以提高从 prompt 获得的结果的准确性。
