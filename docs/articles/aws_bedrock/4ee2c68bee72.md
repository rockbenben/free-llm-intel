# 借助 Amazon Bedrock 跨区域推理加速加拿大的生成式 AI 创新

*本文由来自 Anthropic 的 Gareth Jones 共同撰写。*

[生成式 AI](https://aws.amazon.com/generative-ai/) 为加拿大各类组织带来了前所未有的机遇，可以变革其运营与客户体验。我们很高兴地宣布，加拿大的客户现在可以通过跨区域推理（CRIS）访问先进的 foundation model，包括 Anthropic 的 [Claude Sonnet 4.5](https://www.anthropic.com/claude/sonnet) 与 [Claude Haiku 4.5](https://www.anthropic.com/claude/haiku)，这些模型已在 [Amazon Bedrock](https://aws.amazon.com/bedrock/) 上提供。

本文将探讨加拿大各类组织如何从加拿大（中部）区域使用[跨区域推理配置文件](https://docs.aws.amazon.com/bedrock/latest/userguide/inference-profiles-use.html)访问最新的 foundation model，以加速 AI 举措。我们将演示如何开始使用这些新能力，提供从旧模型迁移的指导，并分享配额管理方面的推荐实践。

## 加拿大跨区域推理：通往全球 AI 创新的门户

为帮助客户实现其生成式 AI 应用的规模，Amazon Bedrock 提供[跨区域推理（CRIS）配置文件](https://docs.aws.amazon.com/bedrock/latest/userguide/cross-region-inference.html)，这是一项强大的功能，使组织能够把推理处理无缝分布到多个 AWS 区域。该能力帮助你在规模化构建时获得更高吞吐量，并有助于确保生成式 AI 应用即使在重负载下也保持响应性与可靠性。

Amazon Bedrock 提供两类跨区域推理配置文件：

- **地理 CRIS：** Amazon Bedrock 会在该地理范围内的商业区域中自动选择最优区域来处理你的推理请求。
- **全球 CRIS：** 全球 CRIS 进一步增强了跨区域推理，可以把推理请求路由到全球受支持的商业区域，从而优化可用资源并实现更高的模型吞吐量。

跨区域推理通过安全的 AWS 网络运行，对传输中的数据与静态数据均采用端到端加密。当客户从加拿大（中部）区域提交推理请求时，CRIS 会智能地把请求路由到为该推理配置文件配置的目标区域之一（US 或 Global 配置文件）。

关键区别在于：虽然推理处理（瞬时的计算）可能发生在其他区域，但所有静态数据——包括日志、knowledge base 以及任何已存储的配置——都完全保留在加拿大（中部）区域。推理请求经由 [AWS Global Network](https://aws.amazon.com/about-aws/global-infrastructure/global-network/) 传输，绝不经过公共互联网，响应会加密返回给你在加拿大的应用。

## 加拿大的跨区域推理配置

借助 CRIS，加拿大各类组织可以更早获得 foundation model，包括具备增强推理能力的 Claude Sonnet 4.5 等前沿模型，从而更快走向创新。CRIS 还通过提供跨多个区域的容量来提升容量与性能。这使其在报税季、Black Friday 与假日购物等高峰时段也能获得更高的吞吐量，无需人工干预即可自动处理突发流量，并通过从更大的资源池中处理请求来提高韧性。

加拿大客户可以依据自身需求，在两种推理配置文件类型之间选择：

| **CRIS 配置文件** | **源区域** | **目标区域** | **说明** |
| --- | --- | --- | --- |
| US 跨区域推理 | `ca-central-1` | [多个美国区域](https://docs.aws.amazon.com/bedrock/latest/userguide/inference-profiles-support.html) | 来自加拿大（中部）的请求可以被路由到有容量的受支持美国区域。 |
| 全球推理 | `ca-central-1` | [全球 AWS 区域](https://docs.aws.amazon.com/bedrock/latest/userguide/inference-profiles-support.html) | 来自加拿大（中部）的请求可以被路由到 AWS 全球 CRIS 配置文件中的某个区域。 |

## 在加拿大开始使用 CRIS

要开始在加拿大使用跨区域推理，请按以下步骤操作：

### 配置 AWS Identity and Access Management（IAM）权限

首先，确认你的 IAM 角色或用户拥有使用跨区域推理配置文件调用 Amazon Bedrock 模型所需的权限。

以下是用于 US 跨区域推理的一个 policy 示例：

```
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Action": [
                "bedrock:InvokeModel*"
            ],
            "Resource": [
                "arn:aws:bedrock:ca-central-1::inference-profile/us.anthropic.claude-sonnet-4-5-20250929-v1:0"
            ]
        },
        {
            "Effect": "Allow",
            "Action": [
                "bedrock:InvokeModel*"
            ],
            "Resource": [
                "arn:aws:bedrock:*::foundation-model/anthropic.claude-sonnet-4-5-20250929-v1:0"
            ],
            "Condition": {
                "StringLike": {
                    "bedrock:InferenceProfileArn": "arn:aws:bedrock:ca-central-1::inference-profile/us.anthropic.claude-sonnet-4-5-20250929-v1:0"
                }
            }
        }
    ]
}
```

关于全球 CRIS，请参阅博文[使用 Amazon Bedrock 上新的全球跨区域推理与 Anthropic 的 Claude Sonnet 4.5 解锁全球 AI 推理的可扩展性](https://aws.amazon.com/blogs/machine-learning/unlock-global-ai-inference-scalability-using-new-global-cross-region-inference-on-amazon-bedrock-with-anthropics-claude-sonnet-4-5/)。

### 使用跨区域推理配置文件

配置你的应用使用相应的推理配置文件 ID。这些配置文件使用前缀来表示其路由范围：

| **模型** | **路由范围** | **推理配置文件 ID** |
| --- | --- | --- |
| **Claude Sonnet 4.5** | 美国区域 | us.anthropic.claude-sonnet-4-5-20250929-v1:0 |
| **Claude Sonnet 4.5** | 全球 | global.anthropic.claude-sonnet-4-5-20250929-v1:0 |
| **Claude Haiku 4.5** | 美国区域 | us.anthropic.claude-haiku-4-5-20251001-v1:0 |
| **Claude Haiku 4.5** | 全球 | global.anthropic.claude-haiku-4-5-20251001-v1:0 |

### 示例代码

下面演示如何从加拿大使用带 US CRIS 推理配置文件的 Amazon Bedrock [Converse API](https://docs.aws.amazon.com/bedrock/latest/APIReference/API_runtime_Converse.html)：

```
import boto3

# Initialize Bedrock Runtime client
bedrock_runtime = boto3.client(
    service_name="bedrock-runtime",
    region_name="ca-central-1"  # Canada (Central) Region
)

# Define the inference profile ID
inference_profile_id = "us.anthropic.claude-sonnet-4-5-20250929-v1:0"

# Prepare the conversation
response = bedrock_runtime.converse(
    modelId=inference_profile_id,
    messages=[
        {
            "role": "user",
            "content": [
                {
                    "text": "What are the benefits of using Amazon Bedrock for Canadian organizations?"
                }
            ]
        }
    ],
    inferenceConfig={
        "maxTokens": 512,
        "temperature": 0.7
    }
)

# Print the response
print(f"Response: {response['output']['message']['content'][0]['text']}")
```

## 加拿大工作负载的配额管理

从加拿大使用 CRIS 时，配额管理在源区域层面进行（`ca-central-1`）。这意味着为加拿大（中部）区域申请的配额提升，适用于所有源自加拿大的推理请求，无论它们最终在何处处理。

### 理解配额计算

**重要：** 在计算所需的配额提升时，你需要考虑 [burndown rate](https://docs.aws.amazon.com/bedrock/latest/userguide/quotas-token-burndown.html)——它定义为输入与输出 token 折算为限流系统 token 配额用量的速率。以下模型的输出 token 具有 5 倍 burndown rate（1 个输出 token 消耗你配额中的 5 个 token）：

- Anthropic Claude Opus 4
- Anthropic Claude Sonnet 4.5
- Anthropic Claude Sonnet 4
- Anthropic Claude 3.7 Sonnet

对于其他模型，burndown rate 为 1:1（1 个输出 token 消耗你配额中的 1 个 token）。对于输入 token，token 与配额的比例为 1:1。每次请求的总 token 数计算方式如下：

`Input token count + Cache write input tokens + (Output token count x Burndown rate)`

### 申请配额提升

要为加拿大的 CRIS 申请配额提升：

- 在加拿大（中部）区域打开 [AWS Service Quotas 控制台](https://ca-central-1.console.aws.amazon.com/servicequotas/home?region=ca-central-1)
- 搜索特定的模型配额（例如 “Claude Sonnet 4.5 tokens per minute”）
- 根据你预计的用量提交提升申请

### 从旧版 Claude 模型迁移到 Claude 4.5

目前仍在使用旧版 Claude 模型的各类组织应规划迁移到 Claude 4.5，以利用[最新的模型能力。](https://docs.claude.com/en/docs/about-claude/models/whats-new-claude-4-5)

规划[迁移策略](https://aws.amazon.com/blogs/machine-learning/migrate-from-anthropics-claude-3-5-sonnet-to-claude-4-sonnet-on-amazon-bedrock/)时，请纳入以下要素：

- **对当前性能做基准测试**：为你现有的模型建立基线指标。
- **用有代表性的工作负载测试并优化 prompt**：用你的具体用例验证 Claude 4.5 的性能，并[调整 prompt](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)，以利用 Claude 4.5 增强后的能力，同时使用 [Bedrock prompt optimizer 工具](https://aws.amazon.com/blogs/machine-learning/improve-the-performance-of-your-generative-ai-applications-with-prompt-optimization-on-amazon-bedrock/)。
- **实施渐进式上线**：逐步切换流量。
- **监控与调整**：追踪性能指标，并按需调整配额。

## 在 US 与全球推理配置文件之间选择

在加拿大实施 CRIS 时，组织可以依据自身具体需求，在 US 与 Global 推理配置文件之间选择。

对于已有美国数据处理协议、具有高吞吐量与高韧性要求，以及设有开发与测试环境的组织，推荐使用 US 跨区域推理。

## 结论

Amazon Bedrock 的跨区域推理为希望在保持数据治理的同时使用 AI 的加拿大组织带来了机遇。通过区分瞬时的推理处理与持久的数据存储，CRIS 在不牺牲合规要求的前提下提供对最新 foundation model 的更快访问。

借助 CRIS，加拿大各类组织可以在几天内而非几个月内获得新模型。系统在业务高峰期自动扩缩容，同时在加拿大境内保持完整的审计轨迹。这有助于你满足合规要求，并使用与全球各地组织相同的先进 AI 能力。要开始使用，请先审视你的数据治理要求并配置 IAM 权限，然后用符合你需求的推理配置文件进行测试——需要到美国区域更低延迟就选 US，需要最大容量就选 Global。
