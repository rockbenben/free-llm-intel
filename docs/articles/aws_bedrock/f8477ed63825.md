# 在 Amazon Bedrock 上使用 GPT-6 Astra 承担你最雄心勃勃的工作

*来自 OpenAI 的 GPT-6 Astra 为你最严苛的任务带来更深的深度与判断力，并运行在为高性能、安全与规模而构建的 Amazon Bedrock 推理引擎之上。*

各类组织已经在 Amazon Bedrock 上以生产规模运行能够编写代码、分析数据并自动化复杂工作流的 AI agent。GPT-6 Astra 提升了这些 agent 所能交付的上限。它为复杂的业务决策带来更深入的推理和更敏锐的判断，能够跨软件与文件工作，并产出符合组织语气、模板与标准的专业级成果。

今天，OpenAI 最新、能力最强的模型 GPT-6 Astra 已在 [Amazon Bedrock](https://aws.amazon.com/bedrock/) 上正式可用。你可以通过 Amazon Bedrock API [直接调用该模型](https://aws.amazon.com/bedrock/openai/)，也可以配置 ChatGPT Work 和 Codex 使用 Amazon Bedrock 上的 GPT-6 Astra。作为本次发布的一部分，OpenAI 还为 ChatGPT Work 推出了新的企业插件，将 Astra 的浏览器使用能力扩展到常见的业务应用中。Amazon Bedrock 推理引擎提供生产环境所需的可扩展性与可靠性。成熟的 AWS 管控能力可帮助你保护工作负载、治理访问权限，并审计模型调用活动。

## 为复杂决策带来更深的深度

GPT-6 Astra 为那些需要你协调相互冲突的输入、追踪依赖关系并确定优先级的工作带来了更深的深度。在执行财务分析时，它可以帮助你协调相互矛盾的数据源，并识别可能改变建议结论的差异。在合同审查中，它可以在最多 100 万输入 token 的上下文窗口内审查数百页内容，并找出风险最高的条款。在代码库方面，它能够调查大型代码库中的问题、梳理依赖关系，并把修复从诊断一路推进到测试。GPT-6 Astra 还提升了计算机与浏览器的使用能力，使其能够跨应用工作，并在没有可用 API 或连接器时，直接通过软件界面延续工作流。

对于在多次请求之间复用同一上下文的 workflow，例如周期性文档审查、代码库分析，或基于公司标准构建的 agent，GPT-6 Astra 同时支持隐式和显式的 prompt caching。使用显式缓存时，你可以设置缓存断点来控制缓存哪些上下文。在后续请求中复用该上下文有助于减少重复处理、成本与延迟。

## 面向生产级 AI 的分层安全与治理

模型层面的防护措施与 Amazon Bedrock 的安全和治理控制共同发挥作用。OpenAI 通过其 [Preparedness Framework](https://cdn.openai.com/pdf/18a02b5d-6b67-4cec-ab64-68cdfbddebcd/preparedness-framework-v2.pdf) 对 GPT-6 Astra 进行了评估，该框架评估模型在各类安全相关领域的能力，并随着这些能力的提升逐步施加更强的防护。它是首个在网络安全能力上达到 Critical 分级的 OpenAI 模型。在该级别下，自动化防护措施会实时监控滥用行为，并可暂停或阻止超出既定边界的活动，且这些机制运行在 Amazon Bedrock 的服务边界之内。当 GPT-6 Astra 跨代码、软件和工具工作时，这些防护措施与 AWS 安全控制形成互补。

Amazon Bedrock 在每次模型调用时都会保护你的推理数据并治理访问。零操作员访问在芯片层面强制执行，因此即使在推理过程中，AWS 的操作人员也无法访问你的 prompt 和补全结果。数据在传输中和静态存储时均已加密。访问由你的 AWS Identity and Access Management（IAM）策略治理，每次调用都会记录在 AWS CloudTrail 中。你可以使用 AWS PrivateLink 通过虚拟私有云（VPC）端点路由流量，并在组织级别建立数据边界策略，帮助防止数据跨账户和网络边界外泄。

你的推理数据不会用于模型训练，使用 GPT-6 Astra 也不要求你选择与 OpenAI 共享数据。对于[自动化滥用检测](https://docs.aws.amazon.com/bedrock/latest/userguide/abuse-detection.html)，被分类器标记的流量会由 AWS 保留最多 30 天并以程序化方式处理。你可以通过 AWS 客户团队申请零数据保留。详情请参阅[数据保留](https://docs.aws.amazon.com/bedrock/latest/userguide/data-retention.html#data-retention-zdr)。

## 使用 Astra 构建、编码和工作

你可以将 GPT-6 Astra 用于推理、知识工作和软件开发。

### 将 Astra 集成到你的应用中

你可以使用受支持的 Amazon Bedrock API 将 GPT-6 Astra 直接集成到你的应用中。用它来驱动处理复杂多步工作流的自主 agent，构建大规模分析和综合文档的内部工具，或创建需要在相互竞争的输入之间做出判断的面向客户的应用。

### 把复杂任务变成可交付成果

ChatGPT Work 是一个生产力 agent，用于把复杂的业务任务转化为可交付的成果。借助 GPT-6 Astra，它可以跨应用和文件收集信息、使用 Web，并产出电子表格、幻灯片、文档和站点。你可以控制该 agent 能够访问哪些应用和网站、管理文件上传与下载，并要求在执行特定操作前获得确认。你还可以跟踪其进度、调整方向并批准关键步骤，从而在整个工作流中让人保持掌控。

ChatGPT Work 可通过 Mac 和 Windows 版 ChatGPT 桌面应用使用。随本次发布推出的新企业插件将浏览器使用能力扩展到商业智能工具、Workday、Navan 和 Avalara，覆盖数据分析、运营和财务等任务。这些插件通过你现有的用户账户并在管理员设定的权限范围内工作，因此不会为 Astra 授予额外访问权限。

### 更快地构建、测试和交付代码

Codex 是一个软件工程 agent，它可以与本地文件、代码仓库、终端、开发工具和开发环境协作，编写功能、修复 bug、运行测试并创建 pull request。当你配置 Codex 使用 Amazon Bedrock 上的 GPT-6 Astra 时，它会将 Astra 的推理和计算机使用能力应用到涵盖调查、实现和测试的任务中。

你可以通过 ChatGPT 桌面应用、CLI、VS Code、JetBrains IDE 和 Xcode 使用 Codex。对于 AWS 开发，[Agent Toolkit for AWS](https://docs.aws.amazon.com/agent-toolkit/latest/userguide/quick-start.html) 只需一条终端命令即可将 Codex 连接到 AWS 文档、API 和服务能力，让你的 agent 更高效地帮助你开发、部署和管理应用。

## 开始使用

你可以从 [Amazon Bedrock 控制台](https://us-east-1.console.aws.amazon.com/bedrock/home?region=us-east-1#/) 开始，或通过受支持的 Amazon Bedrock API 以编程方式开始。有关受支持的 [AWS 区域](https://docs.aws.amazon.com/bedrock/latest/userguide/models-region-compatibility.html)、端点、API、功能、推理配置文件和定价的信息，请参阅 [Amazon Bedrock 文档](https://docs.aws.amazon.com/bedrock/latest/userguide/model-cards-openai.html)。
