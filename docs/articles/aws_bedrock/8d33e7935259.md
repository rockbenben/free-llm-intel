# Amazon Bedrock AgentCore Browser Tool 简介

在 2025 年纽约 AWS Summit 上，[Amazon Web Services](https://aws.amazon.com/)（AWS）宣布预览 [Amazon Bedrock AgentCore](https://aws.amazon.com/bedrock/agentcore/?trk=e61dee65-4ce8-4738-84db-75305c9cd4fe&sc_channel=el) browser tool——一个完全托管、预构建的云端浏览器。该工具使[生成式 AI](https://aws.amazon.com/generative-ai/) agent 能够与网站无缝交互。它解决了两个根本性局限：第一，[基础模型](https://aws.amazon.com/what-is/foundation-models/)（FM）是在规模庞大但静态的数据集上训练的，当 API 访问不易获得时，需要动态获取当前信息；第二，组织在尝试为企业用例用 AI 扩展 Web 自动化时面临重大挑战。

agentic AI 系统的发展正朝着能够执行复杂、多步任务的应用方向演进。要让这些 agent 真正有效，它们需要访问动态的实时数据，尤其是那些不提供 API、或 API 集成过于复杂的网站和 Web 应用。此外，随着企业希望在各项业务中部署 AI 驱动的自动化，他们需要能够可靠扩展的解决方案，而不必承担管理浏览器集群或解决复杂并发问题的运维开销。AgentCore Browser Tool 提供了这些能力，使 agent 能够执行自动化研究、简化运营、与基于 Web 的应用交互等任务——同时享有 AWS 云基础设施的可扩展性、可靠性和安全性。通过提供完全托管的云端浏览器，AWS 回应了企业在大规模部署 AI 自动化时的关键需求：支持数千个并发会话，覆盖从客户服务自动化到大规模数据收集与分析的各种用例，同时摆脱自管理浏览器自动化框架的传统复杂性与资源限制。

本文将介绍新发布的 Amazon Bedrock AgentCore Browser Tool。我们探讨组织为何需要基于云的浏览器自动化，以及它解决了需要实时数据访问的 FM 所面临的哪些局限。我们讨论关键用例和 AgentCore Browser Tool 的核心能力。我们还将逐步说明如何开始使用该工具。

## 为什么需要基于云的 AgentCore Browser Tool？

传统的浏览器自动化方法通常需要大量的基础设施管理、安全考量和开发专业知识。完全托管的云端浏览器自动化解决方案的引入，回应了多项关键需求，包括简化基础设施管理、企业级安全、全球可用性与扩展能力，以及成本优化。组织不再需要为支持其自动化需求而预置、维护和扩展浏览器实例。AWS 现在负责处理复杂的基础设施需求，因此开发者可以专注于构建智能 agent 能力，而不是管理浏览器集群。基于云的浏览器自动化提供带有 AWS 安全控制的隔离执行环境，降低在管控较弱的环境中可能发生的数据外泄或未授权访问风险。借助云端浏览器，您可以瞬时在 AWS 的全球基础设施中部署浏览器实例，使浏览器自动化得以扩展。通过将浏览器自动化作为托管服务提供，组织可以采用按用量计费的定价模式，而不必维护常开的基础设施，这对于间歇性工作负载可以大幅降低成本。

## 基于云的浏览器自动化的用例

**处理重复性 Web 任务**：随着 Amazon Bedrock AgentCore Browser Tool 的推出，组织现在可以规模化实施复杂的浏览器自动化。云端浏览器自动化非常擅长将跨 Web 界面执行重复任务的人工操作降至最低。AI agent 可以跨多个系统填写复杂的 Web 表单、校验条目，并保持符合业务规则。agent 可以导航到内部仪表板、提取关键指标并编制报告，无需人工介入。对于管理大规模用户生成内容域的组织，agent 可以通过跨多个 Web 界面预筛内容来协助人工审核员。

**AI 驱动的研究与情报收集**：借助云端浏览器自动化，AI agent 成为强大的研究助手。它们可以定期监测相关网站的价格变动、新产品发布或内容更新。您可以使用 AI agent 在各类 Web 论坛、评测网站和社交域上收集并分析消费者情绪，为产品开发提供依据。借助 AgentCore Browser Tool，您可以创建自动扫描可信信息源的系统，使内部知识库保持最新。

**跨系统的复杂工作流自动化**：许多组织的运营涉及众多缺乏集成工作流的 Web 应用。当 API 不可用时，可使用 AgentCore Browser Tool 在多个软件即服务（SaaS）系统中自动化客户开通流程。这有助于保持一致性并降低错误率。您可以监测供应商门户、库存系统和物流服务，以维持对复杂供应链的可见性。通过自动化众多内部 Web 应用中的账号创建和权限设置，员工入职流程变得更加顺畅。

**测试与质量保证**：云端浏览器自动化支持规模化的稳健测试。您可以使用 AgentCore Browser Tool 在不同场景、设备和浏览器上并行验证用户体验和功能。部署 agent 持续与关键业务应用交互，并设置告警，在客户遇到问题之前通知您的团队。借助 AgentCore Browser Tool，您可以定期测试 Web 应用的无障碍合规性、安全漏洞或监管要求。

**遗留系统集成**：许多组织维护着缺乏现代 API 的遗留系统。让现代 AI 能力与那些替换或现代化改造代价高昂的遗留 Web 应用交互。将智能自动化应用于那些从未为程序化访问而设计的系统。因此，您可以通过定期、自动化的采集，把困在陈旧 Web 应用中的宝贵组织数据提取出来。

## 核心能力

Amazon Bedrock AgentCore Browser Tool 让 AI agent 能够以与人类相同的方式与 Web 内容交互，其背后是完全托管的远程浏览器基础设施，在最大限度减少传统复杂性的同时提供企业级安全性和可扩展性。

### Web 交互能力

- 跨网站和多页工作流的完整导航控制
- 与 JavaScript 密集型应用和动态内容交互
- 表单操作，包括文本字段、下拉菜单和文件上传
- 滚动、悬停和点击等类人交互模式

### 无服务器浏览器基础设施

- 零管理浏览器集群，自动打补丁
- 按需从单个会话无缝扩展到数千个会话
- 基于用量的定价与全球部署选项
- 在无基础设施开销的情况下获得优化性能

### 视觉理解

- 全页截图，使 AI 能够理解布局和内容
- 按外观和位置识别视觉元素
- 从图形元素中提取内容
- 分辨率和设备模拟能力

### 人在回路集成

- 面向人工操作员的实时交互式查看与控制
- 会话录制，用于审查、训练和合规

### 企业级安全

- 每个浏览器实例都具备完整的会话隔离
- 用于访问管理的 [AWS Identity and Access Management](https://aws.amazon.com/iam/)（IAM）控制
- 每次使用后重置的临时浏览器会话

### 复杂 Web 应用支持

- 与现代 JavaScript 框架完全兼容
- 认证处理和会话保持
- 处理异步内容和实时更新
- 与复杂 UI 模式的智能交互

### 审计与合规

- 详细的交互日志和会话录制
- 与 [AWS CloudTrail](https://aws.amazon.com/cloudtrail/) 集成，实现全面追踪

### 可观测性

- 延迟和资源使用方面的性能指标
- 与 [Amazon CloudWatch](https://aws.amazon.com/cloudwatch/) 集成，实现统一监控
- 会话录制与回放，用于可观测性

这一全面的能力集合弥合了 AI agent 与面向人类的 Web 之间的根本差距，使组织能够构建理解并与为人类设计的内容交互的智能 agent，而不局限于基于 API 的集成。

## AI agent 如何使用 AgentCore Browser Tool

Amazon Bedrock AgentCore Browser 运行在 AgentCore 内部安全、隔离的容器化环境中，将 Web 活动与您的本地系统隔离开来。您可以使用 Playwright 等浏览器驱动库，或使用 [Amazon Nova Act](https://nova.amazon.com/act) 和 Browser Use 等专为浏览器自动化打造的 AI agent 框架，与 AgentCore Browser Tool 交互。您还可以将浏览器自动化作为一个工具集成到多 agent 工作流中。

Amazon Nova Act 或 Browser Use 与 AgentCore Browser Tool 配合，接收用户的自然语言指令，并按以下工作流将其转换为浏览器上的操作：

- 用户发送查询，例如“在 Amazon 上搜索鞋子”
- Amazon Nova Act 或 Browser Use 等 agent 框架将查询传递给[大语言模型](https://aws.amazon.com/what-is/large-language-model/)（LLM）
- LLM 进行推理，并以结构化输出格式（例如 JSON 编码）生成指令
- agent 框架将这些指令映射为浏览器操作命令（如 Playwright、Puppeteer 或 Selenium）
- 浏览器操作命令通过安全的 WebSocket 连接在 AgentCore Browser 上执行
- 浏览器的响应和一张截图被发送回 agent，以便进一步推理

要使用 Amazon Bedrock AgentCore Browser Tool，您需要完成以下先决条件：

- Python 3.10+
- 验证您的 IAM 用户或角色具有使用 AgentCore Browser 的[权限](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/browser-resource-session-management.html)：

```
git clone https://github.com/awslabs/amazon-bedrock-agentcore-samples.git
pip install bedrock-agentcore 
```

要在本地机器上可视化浏览器，您需要克隆的仓库中位于以下路径的 `BrowserViewerServer` 组件：`01-tutorials/05-AgentCore-tools/02-Agent-Core-browser-tool/interactive_tools`

您还可以在 Amazon Bedrock AgentCore 控制台的 [https://us-east-1.console.aws.amazon.com/bedrock-agentcore/builtInTools](https://us-east-1.console.aws.amazon.com/bedrock-agentcore/builtInTools) 实时查看浏览器

以下 Python 代码演示如何使用 Playwright 库和 Amazon Bedrock AgentCore SDK 直接使用 AgentCore Browser Tool。此示例会发起一个安全的浏览器会话、连接到该会话，并自动化一个直接的工作流：导航到 [https://www.amazon.com](https://www.amazon.com) 并搜索商品。

- 开始使用 playwright：

```
cd 01-tutorials/05-AgentCore-tools/02-Agent-Core-browser-tool
```

- 安装依赖：

```
pip install playwright
```

- 编写基于 playwright 的脚本：

```
from playwright.sync_api import sync_playwright, Playwright, BrowserType
from bedrock_agentcore.tools.browser_client import browser_session
from browser_viewer import BrowserViewerServer
import time
from rich.console import Console
console = Console()
def run(playwright: Playwright):
    # Create the browser session and keep it alive
    with browser_session('us-west-2') as client:
        ws_url, headers = client.generate_ws_headers()
        # Start viewer server
        viewer = BrowserViewerServer(client, port=8005)
        viewer_url = viewer.start(open_browser=True)
        # Connect using headers
        chromium: BrowserType = playwright.chromium
        browser = chromium.connect_over_cdp(
            ws_url,
            headers=headers
        )
        context = browser.contexts[0]
        page = context.pages[0]
        try:
            page.goto("https://amazon.com/")
            console.print(page.title())
            # Keep running
            while True:
                time.sleep(120)
        except KeyboardInterrupt:
            console.print("\n\n[yellow]Shutting down...[/yellow]")
            if 'client' in locals():
                client.stop()
                console.print("✅ Browser session terminated")
        except Exception as e:
            console.print(f"\n[red]Error: {e}[/red]")
            import traceback
            traceback.print_exc()
with sync_playwright() as playwright:
    run(playwright)
```

另一种方式是，您可以使用 Amazon Nova Act 构建浏览器 agent 来自动化 Web 交互：

- 在 [https://nova.amazon.com/act](https://nova.amazon.com/act) 注册 Nova Act 并生成 API key。
- 在同一个 Python 虚拟环境中：

```
pip install nova-act
```

- 编写基于 Nova Act 的脚本：

```
import time
from bedrock_agentcore.tools.browser_client import browser_session
from nova_act import NovaAct
from rich.console import Console
from browser_viewer import BrowserViewerServer
 
NOVA_ACT_API_KEY = "YOUR_NOVA_ACT_API_KEY"
console = Console() 
 
def main():
    try:
        # Step 1: Create browser session
        with browser_session('us-west-2') as client:
            print("\r   ✅ Browser ready!                    ")
            ws_url, headers = client.generate_ws_headers()
 
            # Step 2: Start viewer server
            console.print("\n[cyan]Step 3: Starting viewer server...[/cyan]")
            viewer = BrowserViewerServer(client, port=8005)
            viewer_url = viewer.start(open_browser=True)
 
            # Step 3: Use Nova Act to interact with the browser with NovaAct
            with NovaAct(
                    cdp_endpoint_url=ws_url,
                    cdp_headers=headers,
                    preview={"playwright_actuation": True},
                    nova_act_api_key=NOVA_ACT_API_KEY,
                    starting_page="https://www.amazon.com",
                ) as nova_act:
                    result = nova_act.act("Search for coffee maker and get the details of the lowest priced one on the first page")
                    console.print(f"\n[bold green]Nova Act Result:[/bold green] {result}")
            
            # Keep running
            while True:
                time.sleep(1)
             
    except KeyboardInterrupt:
        console.print("\n\n[yellow]Shutting down...[/yellow]")
        if 'client' in locals():
            client.stop()
            print("✅ Browser session terminated")
    except Exception as e:
        print(f"\n[red]Error: {e}[/red]")
        import traceback
        traceback.print_exc()
 
if __name__ == "__main__":
    main()
```

**定价与可用性**

Amazon Bedrock AgentCore 提供灵活的按用量计费定价，无需前期承诺或最低费用。AgentCore Browser 可以独立于其他服务使用。在 2025 年 9 月 16 日之前，您可以免费试用 AgentCore 服务，不收取额外费用。此后，AgentCore Browser Tool 将按用量收费。计费按秒计算，采用该秒内 CPU 和内存使用量的最高水位，最小计费单位为 1 秒。适用 128 MB 最低内存计费。通过客户弹性网络接口进行的网络数据传输按标准 [Amazon Elastic Compute Cloud](https://aws.amazon.com/ec2/)（Amazon EC2）费率计费

Amazon Bedrock AgentCore Browser Tool 标志着 AI 驱动 Web 自动化的一次变革性进步，为组织提供完全托管的云端浏览器解决方案。AgentCore Browser Tool 解决了需要实时数据访问的生成式 AI 系统所面临的关键局限，使 AI agent 能够通过完整的导航控制、视觉理解以及与 Playwright 和 Amazon Nova Act 等框架的无缝集成等能力，自然地与网站交互。通过使用该工具，企业现在可以在各种用例中规模化实施复杂的自动化——从简化重复的 Web 任务、开展 AI 增强的研究，到自动化复杂工作流并与遗留系统集成——同时受益于 AWS 可靠的云基础设施，它能够适应组织需求，而无需承担管理浏览器集群的运维开销。
