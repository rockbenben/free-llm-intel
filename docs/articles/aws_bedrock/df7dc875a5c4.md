# 与 AWS 携手，Cara 如何为大型保险经纪机构开创领域专属 AI

保险是一个规模达 8 万亿美元的全球性行业，饱受手工工作流与日益加剧的人才短缺之累。[Cara](https://www.getcara.ai/) 在 AWS 上交付了一套 AI 原生的解决方案，为保险经纪机构自动化后台流程。

保险代理人常常要把数小时花在重复性任务上。这些任务包括填写申请表、分析保单保障范围、在各系统之间重复录入数据，以及在客户与承保机构之间传递信息。随着行业面临持续的人才短缺，经纪机构需要在员工人数不同比例增长的前提下扩大营收。

在本文中，我们探讨与 AWS 合作构建的 Cara 如何应对这些挑战。我们逐一介绍技术设计决策以及支撑该方案的 AWS 服务。我们还分享 Cara 为大型保险经纪机构带来的可量化成果。

## 挑战所在：为什么通用 AI 在保险业力有不逮

保险经纪机构在高监管环境中运营。每一笔交易都要求精确、可审计与合规。涉及的数据包括敏感的个人可识别信息（PII）、财务记录和承保细节。

通用 AI 工具并非为这种复杂性而设计。面向保险的有效 AI 必须理解领域专属的数据模型和经纪工作流。它还必须在满足企业安全标准的同时，处理承保机构特有的要求与监管约束。

Cara 的创始团队亲眼看到了这些缺口。Vic Yeh、Nikhil Kansal 和 Jon Patel 此前创办了一家数字保险经纪公司。他们将其发展壮大，并出售给了 The McGowan Companies——美国最大的私有保险机构之一。

在那段经历中，团队构建了一个由大语言模型（LLM）驱动的内部 AI copilot。这个 copilot 缩短了周转时间、提升了数据准确性，并简化了代理人的工作流。受到高采用率的鼓舞，他们把这个概念扩展为一款独立产品：Cara。

### 计算与编排

Cara 运行在 Amazon Elastic Kubernetes Service（Amazon EKS）上，以跨多个可用区进行容器编排。EKS 管理 Cara 的微服务，包括摄取 pipeline、工作流引擎和推理层。

该架构支持弹性伸缩，以应对续保与服务高峰期的需求。它在每家经纪机构中支持数千名并发用户和并发工作流。每个组织的工作负载都运行在隔离的 namespace 中，以实现租户隔离。

### AI 与推理

Cara 的 AI 能力由托管在 Amazon Bedrock 上的 LLM 驱动。Amazon Bedrock 通过全托管的 API 提供对基础模型的访问。这使 Cara 无需管理 GPU 基础设施即可运行推理。Cara 将 Amazon Bedrock 用于以下几项核心能力：

- **保障范围与报价智能** – 比较承保机构的报价、概括保障差异，并突出除外责任或缺口。
- **申请与表单自动化** – 使用源文件、以往提交材料和代理机构指南，交叉填写 ACORD 及补充表单。
- **提案与续保生成** – 生成带有品牌标识、可直接交付客户的提案和续保电子表格。
- **知识驱动的工作流** – 参考代理机构特有的指南、承保机构的承保偏好以及历史承保记录来指导决策。

### 安全与数据隔离

数据保护是保险机构的基础性要求。Cara 的架构在 AWS 上采用按账户隔离的部署。每家经纪机构的数据和工作流都被隔离在专用的安全工作区内。这一设计支持符合行业法规，并在组织层面提供可审计性。

### 集成

Cara 与领先的代理机构管理系统（AMS）和客户关系管理（CRM）工具集成。它同步账户、保单和文档，以减少重复的数据录入。AI 驱动的工作流直接在现有的经纪技术栈内运行。这一设计有助于最大限度减少对其代理人已在使用的系统的改动。

## 部署与运行特征

Cara 的设计目标之一是快速实现价值。大型保险经纪机构可以在数小时内完成入驻，并在数天内上线定制工作流。Cara 在 EKS 上的部署为每个新租户使用参数化模板。它无需手动设置即可预置隔离的 namespace、存储和推理端点。

在生产环境中，Cara 在 AWS 上的基础设施提供：

- **高可用性** – 在 EKS 上进行多可用区部署，并具备自动故障转移。
- **弹性伸缩** – Kubernetes Horizontal Pod Autoscaler 根据实时需求调整容量。这在高峰期可支持数千名并发用户。
- **企业级安全** – 按租户隔离数据、静态与传输中加密，并与 AWS Identity and Access Management（AWS IAM）集成。

## 展望未来

保险行业仍处在 AI 采用的早期阶段。随着企业需求增长，Cara 持续将 AI 驱动的工作流扩展到销售、服务和运营等领域。

> “能与 AWS 一起在真实的保险用例中推进领域专属 AI 的边界，我们感到非常振奋，”Cara 首席执行官 Vic Yeh 说道。“我们的目标是帮助保险专业人士回归这个行业的核心：人与人之间的关系。”
