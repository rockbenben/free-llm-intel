# 在 AWS 上推出 Claude Platform：通过 AWS 账户使用 Anthropic 原生平台

今天，我们很高兴地宣布 Claude Platform on AWS 正式可用。Claude Platform on AWS 是一项新服务，让客户可以通过自己的 AWS 账户直接访问 Anthropic 原生的 Claude Platform 体验，无需单独的凭证、合同或计费关系。AWS 是首家提供原生 Claude Platform 体验访问权限的云服务商。

在这篇博文中，我们探讨 Claude Platform on AWS 的工作原理，以及你如何立即开始使用它。

## 通过 AWS 获得 Claude Platform 体验

使用 Claude Platform on AWS，你可以使用与直接通过 Anthropic 相同的 API、功能和控制台体验。这包括 [Messages API](https://platform.claude.com/docs/en/build-with-claude/working-with-messages)、[Claude Managed Agents](https://platform.claude.com/docs/en/managed-agents/overview)（beta）、[advisor tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/advisor-tool)（beta）、[web search](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool) 和 [web fetch](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-fetch-tool)、[MCP connector](https://platform.claude.com/docs/en/agents-and-tools/mcp-connector)（beta）、[Agent Skills](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview)（beta）、[code execution](https://platform.claude.com/docs/en/agents-and-tools/tool-use/code-execution-tool)、[files API](https://platform.claude.com/docs/en/build-with-claude/files)（beta）。有关完整的功能列表，请参阅 [Claude Platform 文档](https://platform.claude.com/docs/en/home)。

你可以通过熟悉的 AWS 功能来访问 Claude Platform on AWS：

- **身份验证：**你使用现有的 [AWS IAM 凭证](https://docs.aws.amazon.com/claude-platform/latest/userguide/authentication.html) 来访问 Claude Platform，无需管理单独的账户或 API key。
- **计费**：用量通过 AWS Marketplace 按[消费量](https://platform.claude.com/docs/en/about-claude/pricing)计费，因此你可以将 AI 支出与其他 AWS 服务一起跟踪和管理。
- **审计**：活动会[记录在 AWS CloudTrail 中](https://docs.aws.amazon.com/claude-platform/latest/userguide/monitoring.html)，因此你可以像监控、审计和调查任何其他 AWS 服务一样，对 AI 用量做同样的事。

Claude Platform on AWS 由 Anthropic 运营，底层请求和数据在 AWS 安全边界之外处理。这使其非常适合没有特定区域数据驻留要求的团队，并与 Amazon Bedrock 上的 Claude 模型形成互补，因此你可以通过适合自己需求的方式访问 Claude。

## 开始使用 Claude Platform on AWS

你可以通过 AWS Marketplace 激活 Claude Platform on AWS。有关分步说明，请参阅[设置账户](https://docs.aws.amazon.com/claude-platform/latest/userguide/setup.html)。账户激活后，完成首次 API 调用需要三个步骤：创建 workspace、进行身份验证，以及调用 API。

### 步骤 1：创建 workspace

借助 [workspace](https://platform.claude.com/docs/en/manage-claude/workspaces)，你可以将项目、环境或团队分隔开来，同时保持集中计费和管理。它也是 Claude Platform on AWS 的主要 AWS Identity and Access Management（IAM）资源。你可以通过 IAM policy 使用 workspace ARN 授予或拒绝对特定 workspace 的访问。有关策略示例，请参阅 [IAM policy](https://docs.aws.amazon.com/claude-platform/latest/userguide/iam-policies.html#_example_per_customer_workspace_isolation)。

从 [Claude Platform on AWS Console](https://console.aws.amazon.com/claude-platform/) 中打开 Claude Console 并创建 workspace。

*图 2：你可以在 *Claude Platform on* AWS Console 中找到 workspace ID。*

### 步骤 2：身份验证

Claude Platform on AWS 支持两种身份验证方法：使用 [AWS Signature Version 4,](https://docs.aws.amazon.com/IAM/latest/UserGuide/reference_sigv.html) 的 IAM，以及 API key。对于需要更高安全级别的配置，我们建议使用[临时 IAM 凭证](https://docs.aws.amazon.com/IAM/latest/UserGuide/best-practices.html#bp-workloads-use-roles)；而在探索 Claude Platform on AWS 时，可使用 API key。

要快速测试你的配置，可以在 Claude Platform on AWS Console 中生成 API key：

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/05/11/ml-20969-image-2.png)

*图 3：你可以在 Claude Platform on AWS Console 中生成 API key*

将 API key、base URL 和 Workspace ID 设置为环境变量：

```
# Your API key  
export ANTHROPIC_API_KEY=<YOUR API KEY HERE> 

# Your regional endpoint for Claude Platform on AWS 
export ANTHROPIC_BASE_URL=https://aws-external-anthropic.<YOUR REGION HERE>.api.aws 

# Your workspace ID (find in Claude Platform on AWS Console → Workspaces) 
export ANTHROPIC_WORKSPACE_ID=<YOUR WORKSPACE ID HERE> 
```

### 步骤 3：发起首次 API 调用

现在你可以安装 [Anthropic Client SDK](https://platform.claude.com/docs/en/api/client-sdks#quick-installation) 并发起 API 调用：

```
from anthropic import Anthropic 
import os 
 
client = Anthropic( 
   default_headers={"anthropic-workspace-id": os.environ["ANTHROPIC_WORKSPACE_ID"]}, 
) 
 
message = client.messages.create( 
   model="claude-sonnet-4-6", 
   max_tokens=1024, 
   messages=[{"role": "user", "content": "Hello!"}], 
) 
 
print(message) 
```

有关更多代码示例，请参阅[入门 notebook](https://github.com/aws-samples/anthropic-on-aws/blob/main/claude-platform-on-aws/notebooks/)。

## Claude Platform on AWS 实践

配置完成后，你可以使用以下环境变量或配置，将 Claude Code、Claude Cowork 或任何其他 API 客户端指向你的 workspace：

```
export ANTHROPIC_API_KEY=<YOUR API KEY HERE> 

export ANTHROPIC_BASE_URL=https://aws-external-anthropic.<YOUR REGION HERE>.api.aws 

 # For Claude Cowork, set the “anthropic-workspace-id" in your inference configuration. For Claude Code use the following:  
export ANTHROPIC_CUSTOM_HEADERS='{"anthropic-workspace-id":"<YOUR WORKSPACE ID HERE>"}' 

 # For the Anthropic SDK 
export ANTHROPIC_WORKSPACE_ID=<YOUR WORKSPACE ID HERE> 
```

连接后，你的客户端可以通过 Claude Platform on AWS 使用 web search、MCP connector、agent skills、code execution 和文件上传等功能。

## 结语

借助 Claude Platform on AWS，你的团队可以通过现有的同一个 AWS 账户获得 Anthropic 完整的原生 API 和功能。Claude Platform on AWS 已在以下区域可用：美国东部（弗吉尼亚北部）、美国东部（俄亥俄）、美国西部（俄勒冈）、加拿大（中部）、南美洲（圣保罗）、欧洲（都柏林）、欧洲（伦敦）、欧洲（法兰克福）、欧洲（米兰）、欧洲（苏黎世）、欧洲（巴黎）、欧洲（斯德哥尔摩）、亚太地区（东京）、亚太地区（首尔）、亚太地区（墨尔本）、亚太地区（雅加达）和亚太地区（悉尼）。要开始使用，请打开 [Claude Platform on AWS Console](https://console.aws.amazon.com/claude-platform/) 或[浏览文档](https://platform.claude.com/docs/en/build-with-claude/claude-platform-on-aws)。

立即试用 Claude Platform on AWS，并通过 AWS re:Post 或你惯用的 AWS Support 联系人发送反馈。
