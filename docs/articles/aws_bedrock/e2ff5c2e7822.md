我们很高兴地宣布，Anthropic 的 [Claude Opus 5](https://aws.amazon.com/blogs/machine-learning/introducing-claude-opus-5-on-aws-anthropics-most-capable-opus-model/)、[Claude Sonnet 5](https://aws.amazon.com/blogs/machine-learning/introducing-claude-sonnet-5-on-aws-anthropics-most-capable-sonnet-model/) 和 [Claude Haiku 4.5](https://aws.amazon.com/about-aws/whats-new/2025/10/claude-4-5-haiku-anthropic-amazon-bedrock/) 已在印度可用。印度的区域端点通过[地理跨区域推理](https://docs.aws.amazon.com/bedrock/latest/userguide/geographic-cross-region-inference.html)提供服务。印度的客户现在可以在 Amazon Bedrock 上访问这些模型，并在已有的[全球跨区域推理](https://docs.aws.amazon.com/bedrock/latest/userguide/global-cross-region-inference.html)之外，在印度区域内处理数据。当客户需要满足在期望地理区域内本地处理数据的要求时，这会很有用。

在本文中，我们讨论印度地理跨区域推理如何从 Amazon Bedrock 的孟买和海得拉巴区域为 Anthropic Claude 模型工作。我们还演示如何从 Amazon Bedrock 控制台以及用代码上手——分别使用 Anthropic 的 Messages API、Amazon Bedrock InvokeModel API 和 Converse API。

## 印度推理

为了帮助你实现 AI 应用所需的规模，Amazon Bedrock 提供跨区域推理配置（cross-Region inference profiles），你可以用它把推理分布到多个 AWS 区域，而无需在每个区域管理容量。请求从你发起 API 调用的源区域出发，并被自动路由到推理配置中定义的某一个目标区域。印度的地理配置把推理保持在印度境内。请求只在 ap-south-1 和 ap-south-2 之间路由。你的输入 prompt 和输出结果可能在这两个区域之间移动。你的请求不再受限于单个区域的容量，而是从一个更广泛的算力池中获取。这有助于你在负载下维持吞吐和稳定的性能——这在流量高峰时最为重要。跨区域推理通过安全的 AWS 网络运行，对传输中的数据端到端加密。使用跨区域推理时，客户数据不会存储在目标区域，而是完全保留在源区域内。Amazon Bedrock 采用零数据保留（ZDR）的数据安全模型，意味着 Amazon Bedrock 默认不存储模型输入或输出。不过，某些模型要求：若内容被自动安全分类器标记，需由 AWS 进行人工审核作为前提条件。更多细节参见 Amazon Bedrock 用户指南中的[数据保留](https://docs.aws.amazon.com/bedrock/latest/userguide/data-retention.html)。无论由哪个后端区域处理请求，计费和配额消费都在源区域记在你的账户上。Amazon CloudWatch 和 AWS CloudTrail 只在源区域记录日志条目，因此你的监控集中在一处。地理跨区域推理在 `bedrock-runtime` 端点上可用。它支持 Anthropic 的 [Messages](https://docs.aws.amazon.com/bedrock/latest/userguide/inference-messages-api.html) API，以及 Amazon Bedrock 原生的 [InvokeModel](https://docs.aws.amazon.com/bedrock/latest/userguide/inference-api.html) 和 [Converse](https://docs.aws.amazon.com/bedrock/latest/userguide/conversation-inference.html) API，并支持诸如 [Amazon Bedrock Guardrails](https://docs.aws.amazon.com/bedrock/latest/userguide/guardrails.html) 和[智能 prompt 路由](https://docs.aws.amazon.com/bedrock/latest/userguide/prompt-routing.html)等 Amazon Bedrock 特性。

## 从 Amazon Bedrock 控制台访问 Claude 模型

你可以在 Amazon Bedrock 控制台的文本 playground 中访问 Claude 模型，无需编码或 SDK 设置。你可以发送 prompt、调整推理参数并在变体之间切换，以便在集成 API 之前先感受每个模型。

- 在你希望作为源的区域打开 [Amazon Bedrock 控制台](https://console.aws.amazon.com/bedrock/)。
- 在导航窗格的 **Test** 下，选择 **Playground**。
- 选择页面中间的 **Select model**。
- 搜索 Anthropic Claude Opus 5，在 **Inference** 下选择 **IN Anthropic Claude Opus 5** 作为推理配置，然后选择 **Apply**。
- 输入一个 prompt 并选择 **Run** 以生成响应。

## 用 Anthropic Messages API 及 Amazon Bedrock InvokeModel 和 Converse API 调用 Claude 模型

你可以使用印度地理推理配置 ID，通过 Anthropic SDK 在 `bedrock-runtime` 上用 [Anthropic Messages API](https://docs.aws.amazon.com/bedrock/latest/userguide/model-parameters-anthropic-claude-messages.html)以编程方式访问 Anthropic 的 Claude Opus 5、Claude Sonnet 5 或 Claude Haiku 4.5；也可以在 `bedrock-runtime` 上继续使用 [InvokeModel](https://docs.aws.amazon.com/bedrock/latest/userguide/inference-api.html) 和 [Converse](https://docs.aws.amazon.com/bedrock/latest/userguide/conversation-inference.html) API，通过 [AWS Command Line Interface (AWS CLI)](https://aws.amazon.com/cli/) 和 [AWS SDK](https://aws.amazon.com/developer/tools/) 访问。

### 前提条件

- 拥有 Amazon Bedrock 访问权限的有效 AWS 账户。
- 已安装并配置 AWS CLI。
- Python 3.8+。
- 已安装 Boto3：`pip install boto3`。
- 已安装 Anthropic SDK：`pip install anthropic`。
- 已安装用于 Amazon Bedrock 模型推理认证的 Bedrock Token Generator：`pip install aws_bedrock_token_generator`。
- [AWS Identity and Access Management](https://aws.amazon.com/iam/) (IAM) 角色或用户具备使用地理跨区域推理配置调用 Amazon Bedrock 模型的[必要权限](https://docs.aws.amazon.com/bedrock/latest/userguide/geographic-cross-region-inference.html#geographic-cris-iam-setup)。

下面是使用 AWS SDK for Python (Boto3) 配合 InvokeModel API 的一个简短示例：

```
import boto3
import json

# Create a Bedrock Runtime client
bedrock_runtime = boto3.client(
    service_name="bedrock-runtime",
    region_name="ap-south-1"
)

# Invoke Claude Sonnet 5
response = bedrock_runtime.invoke_model(
    modelId="in.anthropic.claude-sonnet-5",
    contentType="application/json",
    accept="application/json",
    body=json.dumps({
        "anthropic_version": "bedrock-2023-05-31",
        "max_tokens": 4096,
        "messages": [
            {
                "role": "user",
                "content": " Can you explain the features of Amazon Bedrock? "
            }
        ]
    })
)

result = json.loads(response["body"].read())
print(result["content"][0]["text"])
```

你也可以使用 Amazon Bedrock Converse API 获得统一的多模型体验：

```
import boto3

# Create a Bedrock Runtime client
bedrock_runtime = boto3.client(
    service_name="bedrock-runtime",
    region_name="ap-south-1"
)

# Invoke Claude Opus 5
response = bedrock_runtime.converse(
    modelId="in.anthropic.claude-opus-5",
    messages=[
        {
            "role": "user",
            "content": [
                {
                    "text": " Can you explain the features of Amazon Bedrock?"
                }
            ]
        }
    ],
    inferenceConfig={
        "maxTokens": 4096
    }
)

if 'output' in response:
    blocks = response['output']['message']['content']
    print('\n'.join(b.get('text', '') for b in blocks if 'text' in b))
```

你也可以使用 `anthropic` SDK 包，通过 Anthropic Messages API 获得更简洁的体验：

```
from anthropic import Anthropic
from aws_bedrock_token_generator import provide_token

token = provide_token(region="ap-south-1")

client = Anthropic(
    base_url="https://bedrock-runtime.ap-south-1.amazonaws.com/anthropic",
    api_key=token,
)

response = client.messages.create(
    model="in. anthropic.claude-haiku-4-5-20251001-v1:0",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Can you explain the features of Amazon Bedrock?"}],
)

print(response)
```

你可以通过 [CloudWatch](https://docs.aws.amazon.com/bedrock/latest/userguide/monitoring.html) 和 [AWS Cost Explorer](https://aws.amazon.com/aws-cost-management/aws-cost-explorer/) 监控用量、性能和成本，随需求增长扩展你的应用。

## 结论

随着 Anthropic 的 Claude Opus 5、Claude Sonnet 5 和 Claude Haiku 4.5 在 Amazon Bedrock 上借助印度地理跨区域推理上线，你现在可以构建高度可扩展、富有弹性的生成式 AI 应用，同时把推理保持在境内。要开始上手，可以在 [Amazon Bedrock 控制台](https://console.aws.amazon.com/bedrock/)访问 Anthropic 的 Claude 模型，或使用印度地理推理配置 ID 通过 API 调用它们。要获取每个区域模型可用性的最新信息，参见 Amazon Bedrock 用户指南中的[按模型的区域可用性](https://docs.aws.amazon.com/bedrock/latest/userguide/models-region-compatibility.html#model-regions-anthropic)。
