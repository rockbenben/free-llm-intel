Agentic retrieval on fully managed Amazon Bedrock knowledge bases now supports retrieval instructions. A retrieval instruction steers how the agent searches your knowledge bases and how it answers. Amazon Bedrock reviews each instruction before it takes effect, and you can pin an immutable version. Use the

retrievalInstructionConfiguration

field on

AgenticRetrieveStream

to apply one. For more information, see

Create and manage retrieval instructions

.
