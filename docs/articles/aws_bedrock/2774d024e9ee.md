# 为代码助手推出 AWS MCP Servers（第 1 部分）

我们很高兴宣布 [AWS MCP Servers for code assistants](https://github.com/awslabs/mcp/) 开源发布——这是一套专门的 Model Context Protocol（MCP）服务器，把 [Amazon Web Services](https://aws.amazon.com/)（AWS）最佳实践直接带入您的开发工作流。我们专门的 AWS MCP 服务器把深厚的 AWS 知识与 agentic AI 能力结合起来，加速关键领域的开发。每个 AWS MCP Server 聚焦 AWS 最佳实践的一个特定领域，它们协同工作，在您的整个开发旅程中提供全面的指引。

本文是介绍 AWS MCP Servers 系列的第一篇。在本文中，我们演示这些专门的 MCP 服务器如何大幅减少开发时间，同时把安全控制、成本优化和 [AWS Well-Architected](https://aws.amazon.com/architecture/well-architected/) 最佳实践融入您的代码。无论您是经验丰富的 AWS 开发者，还是刚刚开始云开发，您都会发现如何用 AI 驱动的编码助手应对常见挑战，例如复杂的服务配置、基础设施即代码（IaC）实现以及知识库集成。读完本文，您将了解如何开始使用 AWS MCP Servers 来改造开发工作流，并更快交付更好的解决方案。

如果您想立刻上手，请跳到“从概念到几分钟内跑通代码”一节。

AI 正在改变我们构建软件的方式，创造了在提升代码质量与一致性的同时大幅加速开发的机会。如今的 AI 助手能够理解复杂需求、生成可用于生产环境的代码，并帮助开发者实时应对技术挑战。这种 AI 驱动的方法在云开发中尤其有价值，因为开发者需要在保证安全、可扩展性和成本效益的同时编排多个服务。

开发者需要能够理解 AWS 服务细微差别与最佳实践的代码助手。专门的 AI agent 可以通过以下方式满足这些需求：

- 就 AWS 服务选型与配置提供结合上下文的指引
- 优化对安全最佳实践与监管要求的遵循
- 推广最高效的资源利用与最具成本效益的解决方案
- 用 AWS 特有的模式自动完成重复性实现任务

这种做法意味着开发者可以专注于创新，而由 AI 助手处理编码中那些非差异化的重体力活。无论您在工作流中使用 [Amazon Q](https://aws.amazon.com/q/)、[Amazon Bedrock](https://aws.amazon.com/bedrock/) 还是其他 AI 工具，AWS MCP Servers 都能以深厚的 AWS 专属知识补充并增强这些能力，帮助您更快构建更好的解决方案。

Model Context Protocol（MCP）是一个标准化的开放协议，使[大语言模型](https://aws.amazon.com/what-is/large-language-model/)（LLM）、数据源与工具之间能够无缝交互。该协议让 AI 助手可以使用专门的工具，并借助扩展模型内置知识之外的能力来访问领域专属知识——同时把敏感数据保留在本地。通过 MCP，通用 LLM 现在可以无缝访问初始训练数据之外的相关知识，并通过引入特定上下文与最佳实践被有效引导至期望的输出。

## 加速在 AWS 上构建

如果您的 AI 助手能够即时访问深厚的 AWS 知识，理解每一项 AWS 服务、最佳实践和架构模式，会怎样？借助 MCP，我们可以把通用 LLM 连接到专门的知识服务器，从而将它们转变为 AWS 专家。这为在保持安全并遵循最佳实践的同时加速云开发带来了令人兴奋的新可能。

用一小部分时间在 AWS 上构建，从第一行代码起就自动应用最佳实践。跳过数小时的文档研究，直接获取 [Amazon Bedrock Knowledge Bases](https://aws.amazon.com/bedrock/knowledge-bases/) 等复杂服务的即用型模式。我们的 MCP Servers 将帮助您从一开始就写出架构良好的代码、第一次就把 AWS 服务实现正确，并部署在设计上就安全、可观测且成本优化的解决方案。今天就改变您在 AWS 上构建的方式。

- **自动强制实施 AWS 最佳实践** – 从一开就写出架构良好的代码，内置安全控制、恰当的可观测性和优化的资源配置
- **大幅削减研究时间** – 不必再花数小时阅读文档。我们的 MCP Servers 提供结合上下文的指引，帮助您正确实现 AWS 服务，并自动规避常见陷阱
- **即刻获得即用型模式** – 使用从一开始就遵循 AWS 最佳实践的预构建 AWS CDK construct、[Amazon Bedrock Agents](https://aws.amazon.com/bedrock/agents/) schema 生成器以及 Amazon Bedrock Knowledge Bases 集成模板
- **主动优化成本** – 在设计解决方案时就获取成本优化建议并生成全面的成本报告，在部署前分析您的 AWS 支出，从而防止过度配置

为了把这一愿景变为现实，让 AWS 开发更快、更安全、更高效，我们创建了 AWS MCP Servers——一套专门的 AWS MCP 服务器，把 AWS 最佳实践直接带入您的开发工作流。我们专门的 AWS MCP 服务器把深厚的 AWS 知识与 AI 能力结合起来，加速关键领域的开发。每个 AWS MCP Server 聚焦 AWS 最佳实践的一个特定领域，它们协同工作，在您的整个开发旅程中提供全面的指引。

## 面向 AWS 开发的领域专属 MCP Servers 概览

我们专门的 MCP Servers 旨在覆盖 AWS 开发的不同方面，每一个都为特定领域带来深厚的知识，同时协同交付全面的解决方案：

- **Core** – 基础服务器，提供 AI 处理 pipeline 能力并充当中央协调者。它有助于为构建 AWS 解决方案提供清晰的规划，并可按需联邦到其他 MCP 服务器。
- [**AWS Cloud Development Kit**](https://aws.amazon.com/cdk/)** (AWS CDK)** – 交付 AWS CDK 知识，并提供用于落实最佳实践、使用 [cdk-nag](https://github.com/cdklabs/cdk-nag) 配置安全、集成 [Powertools for AWS Lambda](https://docs.powertools.aws.dev/lambda/python/latest/) 以及面向 [生成式 AI](https://aws.amazon.com/generative-ai/) 服务的专用 construct 的工具。它确保基础设施即代码（IaC）从一开始就遵循 AWS Well-Architected 原则。
- **Amazon Bedrock Knowledge Bases** – 实现对 Amazon Bedrock Knowledge Bases 的无缝访问，让开发者可以用自然语言查询企业知识、按数据源过滤结果，并使用重排序来提升相关性。
- **Amazon Nova Canvas** – 通过 Amazon Bedrock 使用 [Amazon Nova Canvas](https://aws.amazon.com/ai/generative-ai/nova/creative/) 提供图像生成能力，可根据文本 prompt 和色板创建视觉素材——非常适合 mockup、示意图和 UI 设计概念。
- **Cost** – 分析 AWS 服务成本并生成全面的成本报告，帮助开发者理解其架构决策的财务影响并针对成本效益进行优化。

## AWS MCP Servers 实战

以下展示 AWS MCP 服务器如何改造开发体验：

**开发者：**“我需要用 Amazon Bedrock 构建一个 AI 驱动的聊天机器人，能够回答来自公司知识库的问题。”

**Core：**“我来帮你构建一个 Amazon Bedrock Knowledge Bases 聊天机器人。我们创建一个架构，使用带自定义 action group 的 Amazon Bedrock Agents 来调用你的内部 API。”

Core 会生成一张全面的架构图，展示知识库集成、带 action group 的 Amazon Bedrock Agents 配置、API 连接以及组件之间的数据流。

**AWS CDK：**“这是你的聊天机器人配合 Amazon Bedrock Agents action group 所需的基础设施代码。我已经加入了合适的 IAM 角色、安全控制以及用于可观测性的 [Powertools for AWS Lambda](https://docs.powertools.aws.dev/lambda/python/latest/)。”

```
// CDK code
    const kb = new bedrock.VectorKnowledgeBase(this, 'KB', {
      embeddingsModel: bedrock.BedrockFoundationModel.TITAN_EMBED_TEXT_V2_1024,
      instruction: 'Use this knowledge base to answer questions about books. ' +
        'It contains the full text of novels. Please quote the books to explain your answers.',
    });

    const dataSource = new bedrock.S3DataSource(this, 'DataSource', {
      bucket: docBucket,
      knowledgeBase: kb,
      dataSourceName: 'books',
      chunkingStrategy: bedrock.ChunkingStrategy.fixedSize({
        maxTokens: 500,
        overlapPercentage: 20
      }),
    });

    const agent = new bedrock.Agent(this, 'Agent', {
      foundationModel: bedrock.BedrockFoundationModel.ANTHROPIC_CLAUDE_3_5_SONNET_V2_0,
      instruction: 'You are a helpful and friendly agent that answers questions about literature.',
      knowledgeBases: [kb],
      userInputEnabled: true,
      shouldPrepareAgent:true
    });

    const actionGroupFunction = new lambda_python.PythonFunction(this, 'ActionGroupFunction', {
      runtime: lambda.Runtime.PYTHON_3_12,
      entry: path.join(__dirname, '../lambda/action-group'),
      layers: [lambda.LayerVersion.fromLayerVersionArn(this, 'PowerToolsLayer', `arn:aws:lambda:${this.region}:017000801446:layer:AWSLambdaPowertoolsPythonV2:60`)],
      timeout:cdk.Duration.minutes(2)
    });

    const actionGroup = new AgentActionGroup({
      name: 'query-library',
      description: 'Use these functions to get information about the books in the library.',
      executor: bedrock.ActionGroupExecutor.fromlambdaFunction(actionGroupFunction),
      enabled: true,
      apiSchema: bedrock.ApiSchema.fromLocalAsset(path.join(__dirname, 'action-group.yaml')),
    });

    agent.addActionGroup(actionGroup);
// the rest of the code
```

CDK MCP Server 会生成完整的 AWS CDK 代码来部署整个解决方案。它会自动运行 [cdk-nag](https://github.com/cdklabs/cdk-nag) 以识别潜在安全问题，并针对每项发现提供修复步骤，确保基础设施遵循 AWS Well-Architected 最佳实践。

**Amazon Bedrock Knowledge Bases 检索：**“我将使用 Amazon Bedrock Knowledge Base MCP Server，从你的内部开发平台和文档中获取相关信息。”

Amazon Bedrock Knowledge Bases MCP Server 让您可以直接在 MCP 客户端中访问 AWS 上已有的知识库。例如，您可以使用该服务器把内部数据的上下文直接提供给代码助手。该服务器可以跨多个知识库搜索，并针对特定数据源使用过滤器。

**Amazon Nova Canvas：**“为增强你的登录页，我将使用 Amazon Nova Canvas MCP Server 生成一张与你的应用和行业相配的图片。”

Amazon Nova Canvas MCP 服务器使用您 AWS 账户中的 Amazon Nova Canvas 生成图片。该服务器还包含图像生成的 prompt 指引，让 MCP 客户端中的 LLM 可以帮助您写出更好的图像生成 prompt。

**成本分析：**“根据你预期的使用模式和应用的基础设施即代码，以下是估算的月度成本拆解和优化建议。”

Cost Analysis MCP Server 会生成详细的成本分析报告，展示每项 AWS 服务的预计费用，并提供降低费用的具体建议。

借助 AWS MCP Servers，通常需要数天研究和实现的工作可以在几分钟内完成，而且质量、安全性和成本效率都优于同样时长的手工开发。

## MCP 辅助开发的最佳实践

为了在保持安全与代码质量的同时最大化 MCP 辅助开发的收益，开发者应遵循以下关键准则：

- 部署前始终复核生成的代码是否存在安全影响
- 把 MCP Servers 当作加速器，而不是开发者判断力与专业知识的替代品
- 让 MCP Servers 保持与最新 AWS 安全最佳实践同步
- 配置 AWS 凭证时遵循最小权限原则
- 对生成的基础设施代码运行安全扫描工具
