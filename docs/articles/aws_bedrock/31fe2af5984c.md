# Amazon SageMaker JumpStart：2026 年迄今回顾

Amazon SageMaker JumpStart 是 Amazon SageMaker AI 中的一个机器学习（ML）中心，提供经过精选的 AI 模型、解决方案模板和示例 notebook 目录。它缩短了从选择模型到完成部署所需的时间。你可以用它评估开源大语言模型（LLM），部署用于文档理解的视觉模型，或者用自己的数据微调一个紧凑模型。

SageMaker JumpStart 主要服务三类使用场景：

- 模型发现与评估——浏览来自 Alibaba（Qwen）、NVIDIA、Google、Mistral、Cohere、IBM 等提供方的数百个基础模型（FM）。每张模型卡都包含架构细节、基准测试、许可信息和示例 notebook。
- 一键部署——将你选定的模型部署到 SageMaker 实时推理端点，使用针对你的工作负载（低成本、低延迟、吞吐量或均衡）优化过的预配置设置。无需手动配置容器或实例。
- 模型定制——可直接从控制台或 SDK 使用低秩适配（LoRA）、监督微调（SFT）、直接偏好优化（DPO）、带可验证奖励的强化学习（RLVR）等技术来微调模型。无服务器定制选项可以减少基础设施管理工作。

你可以通过 SageMaker Studio 控制台（Models → JumpStart models）访问 SageMaker JumpStart，也可以通过 SageMaker Python SDK 以编程方式访问，或者借助最近推出的 deep link 集成直接从 Hugging Face 访问。

## 2026 年模型上架一览

从 2026 年 1 月到 9 月，SageMaker JumpStart 在 30 个不同的提供方处上架了 100 多个新模型。这标志着目录的一次显著扩张，其驱动力是开源模型发布节奏的加快，以及客户对模型架构、规模和能力多样选择日益增长的需求。

以下是主要贡献方的细分情况，以及我们的 [SageMaker JumpStart 页面](https://aws.amazon.com/sagemaker/ai/jumpstart/)链接：

- **Alibaba（Qwen）：** [29 个模型](https://aws.amazon.com/blogs/machine-learning/qwen3-family-of-reasoning-models-now-available-in-amazon-bedrock-marketplace-and-amazon-sagemaker-jumpstart/)，涵盖推理（Qwen 3.8-27B）、大规模混合专家（Qwen3.5-122B-A10B）、agentic 工作流（Qwen-AgentWorld-35B-A3B）、代码生成（Qwen3-Coder-Next、Qwen 3 Coder 30B）、语音识别（Qwen3-ASR-1.7B）、文本转语音（Qwen3-TTS）、embedding（Qwen3-VL-Embedding-2B）和 reranking（Qwen3-Reranker-4B）。
- **NVIDIA：** 17 个模型，包括 Cosmos3 世界基础模型系列（Super、Edge、Nano）、Cosmos Reason 7B、MSA-Search、[Nemotron 3.5 Lightning](https://aws.amazon.com/blogs/machine-learning/nvidia-nemotron-3-5-lightning-now-available-in-amazon-sagemaker-jumpstart/)、Nemotron-3-Super-120B（FP8 与 BF16）、Nemotron3 Ultra、Nemotron-Nano-12B-v2、[Nemotron 3 Nano Omni（多模态）](https://aws.amazon.com/blogs/machine-learning/nvidia-nemotron-3-nano-30b-is-now-available-in-amazon-sagemaker-jumpstart/)，以及用于视觉语言的 [Nemotron 3.5 Super VL](https://aws.amazon.com/about-aws/whats-new/2026/01/nvidia-nemotron-3.5-super-vl-on-sagemaker-jumpstart/)。
- **Mistral：** 7 个模型，包括 Ministral-3 系列（3B、8B、14B，标准版与 BF16 版）以及用于语音的 Voxtral-Mini-4B-Realtime。
- **Google：** 6 个 Gemma 4 变体，包括 gemma-4-31B-it、E2B-it、E4B-it、26B-A4B-it、assistant 和 NVFP4 量化版。
- **IBM：** 4 个模型，包括 Granite 4.0 h-micro/small/tiny，以及用于覆盖 6 种语言的多语种自动语音识别（ASR）的 granite-speech-4.1-2b。
- **Cohere：** 4 个模型，包括 Command A（A100），以及用于检索增强的 Rerank v3.5、v4.0 Fast 和 v4.0 Pro。
- **其他：** 来自 MiniMax、Zhipu AI（GLM）、DeepSeek、Moonshot AI、Allen AI、Microsoft、[Meta（Muse Spark）](https://aws.amazon.com/about-aws/whats-new/2026/01/muse-spark-open-on-sagemaker-jumpstart/)、[Reflection（Beam）](https://aws.amazon.com/about-aws/whats-new/2026/01/reflection-beam-on-sagemaker-jumpstart-and-aws-trainium/)、Black Forest Labs、JetBrains、OpenBMB、BharatGenAI、Kakao、OpenFold 等的 33 个模型。

## 模型上架亮点

2026 年上架的模型反映了我们在扩展 SageMaker JumpStart 目录时的几个重点方向。这些不只是行业趋势。它们代表了我们看到强烈客户需求、并且有重大机会帮助客户在 SageMaker 上构建生产级 AI 应用的领域。

### 扩展 NVIDIA 开放模型组合

NVIDIA 是我们的重要模型提供方之一，2026 年他们的贡献远远超出了语言模型。Cosmos3 世界基础模型提供 Super、Edge 和 Nano 三个档位，把视频生成、物理仿真和动作规划整合进单一架构，面向机器人、自主系统和数字孪生等物理 AI 应用。再结合从高效边缘推理（Nano-12B）到大规模推理（Super-120B）的 Nemotron 系列模型，SageMaker JumpStart 现在提供了品类广泛的 NVIDIA 开放模型组合。如果你基于 NVIDIA 硬件构建，可以在 SageMaker 上用优化过的容器和预配置端点部署这些模型。

### 弥合多模态差距

客户的工作负载越来越需要能处理文本以外内容的模型。2026 年，我们优先上架了原生支持视觉、语音和文档理解的模型。NVIDIA Nemotron 3 Nano Omni 在单个模型中处理文本、视觉和语音。Google Gemma 4 在多个规模上增加了视觉语言能力。IBM granite-speech-4.1-2b 处理跨六种语言的语音识别与翻译。Mistral Voxtral-Mini 支持实时语音理解。这些新增意味着客户在处理多模态工作负载时，不必再串联多个独立的预处理模型。

### 让创意 AI 触手可及

2026 年，图像和视频生成从细分领域走向主流。我们上架了来自 Black Forest Labs 的 FLUX.2 Small Decoder 和 FLUX.2-klein-base-4B，用于快速文本生成图像；Meta Muse-Glimmer-30B，用于多模态 agentic 工作流；以及 NVIDIA Cosmos3，用于视频生成。借助这些模型，你可以用与语言模型相同的一键部署体验来使用创意 AI 能力。

### 优先引入高效与量化模型

并非每个工作负载都需要前沿规模的模型，许多客户在走向生产时都专注于优化推理成本。我们上架了多个量化和紧凑模型：Zhipu AI GLM-5.2 FP8 在降低内存占用的同时提供强劲性能。JetBrains Mellum2-12B 采用混合专家架构，用于代码生成时只有 2.5B 活跃参数。OpenBMB MiniCPM5-1B 把多模态能力塞进 10 亿参数。Microsoft Phi-4-mini-instruct 和 IBM Granite 4.0 h-tiny 表明，紧凑模型可以在 ml.g5.xlarge 这类实例类型上承担生产工作负载。对于特定使用场景，这些模型可以优化延迟和总拥有成本（TCO）。

### 为特定任务上架专用模型

通用大语言模型用途广泛，但专用模型针对特定任务做了优化。2026 年，我们上架了面向自主 AI 工作流、原生支持工具调用的 Qwen-AgentWorld-35B-A3B。GLM-OCR、LightOnOCR 和 DeepSeek-OCR 负责文档文本抽取。Qwen3-Reranker-4B 和 Cohere Rerank v4.0 提升了检索增强生成（RAG）流水线中的检索精度。langcache-embed-v3-small 为语义搜索提供轻量级 embedding。Qwen3-ASR 和 Qwen3-TTS 带来语音识别与合成能力。OpenFold3 支持面向科学计算的蛋白质结构预测。借助这些模型，你可以构建每个环节都使用合适专用工具的流水线，而不是强迫单个模型做完所有事情。

### 拓宽提供方多样性

降低模型选择上的集中度风险，对企业客户很重要。2026 年，我们把目录扩展到包含 30 个提供方，相比往年更加集中的一组提供方有明显增加。Alibaba Qwen 是单一最大贡献方，共 29 个模型，横跨推理、编码、语音和检索。Zhipu AI 和 DeepSeek 带来了有竞争力的 LLM 和专用 OCR。MiniMax 和 Moonshot AI 贡献了新兴架构。Cohere 带来可靠的 reranking。BharatGenAI 和 Kakao 扩大了区域模型覆盖。这样的广度让客户在性能、成本、许可和语言支持方面有更多选择。

## SageMaker JumpStart 在 2026 年的增强

除了上架模型，SageMaker JumpStart 在 2026 年还发布了重要改进，减少了模型全生命周期（从发现到部署）中的摩擦。

### SageMaker AI 控制台上简化的 Model Hub

此前，发现 SageMaker JumpStart 模型需要先进入 SageMaker Studio，再在左侧导航中找到 SageMaker JumpStart 分区。新的 Model Hub 体验把完整的 SageMaker JumpStart 目录直接呈现在 SageMaker AI 控制台首页上。你可以按类别浏览模型，并按输入/输出模态、发布方、模型规模、许可和框架进行筛选。你还可以查看示例 notebook，并一键在 Studio 中打开模型。这避免了以往拖慢初次探索的多级导航。

### 预配置的端点部署选项

为一个模型部署选择合适的实例类型、服务容器和优化设置，通常需要在几十种组合上手工做基准测试。SageMaker JumpStart 现在提供命名的部署配置，并附带以下优化选项：

- **均衡**——在成本、延迟和吞吐量之间为通用工作负载取得均匀取舍。
- **吞吐优化**——使用 Speculative Decoding 等技术实现每秒最大 token 数，适合高吞吐的批处理。
- **延迟优化**——最低的首 token 延迟（TTFT），优先考虑交互式应用的速度。
- **成本优化**——最低的单请求基础设施成本，适合可以接受较高延迟的工作负载。

这些配置包含面向 AWS Inferentia 和 AWS Trainium 实例的 Neuron 优化方案，降低了部署复杂度和基础设施成本。你可以一键用合适的优化配置部署模型，而不必花数周手工对配置做基准测试。

### Hugging Face deep link 集成

与 Hugging Face 的新集成把模型发现直接连接到 SageMaker Studio，适用于已上架的模型。在 Hugging Face 上浏览模型时，你可以选择 **Deploy on SageMaker AI** 或 **Customize and Deploy on SageMaker AI**。你会直接进入一个配置好的 Studio 环境，模型已预加载、权限已预配置、GPU 配额可见性内建其中。这避免了在开始试验前先设置 AWS Identity and Access Management（IAM）角色、创建域或配置权限的需要。

## 入门

开始使用 SageMaker JumpStart 有三种方式：

- SageMaker Studio 控制台——打开 SageMaker Studio，导航到 Models → JumpStart models，然后浏览目录。选择一个模型查看其详情，然后选择 **Deploy** 或 **Customize**。
- SageMaker Python SDK——使用 SageMaker Python SDK 以编程方式部署模型。访问 [SageMaker JumpStart 模型目录](https://docs.aws.amazon.com/sagemaker/latest/dg/studio-jumpstart.html)获取 SDK 示例和部署指南。

- Hugging Face deep link——浏览 [HuggingFace Model Hub](https://huggingface.co/models)，选择 **Deploy on SageMaker AI**，即可直接进入 Studio 处理 SageMaker JumpStart 已上架的模型。

SageMaker JumpStart 上的每个模型都包含部署配置、示例 notebook 和文档。如需动手演练，请参阅我们的相关博文“[使用 Amazon SageMaker JumpStart 部署和评估模型](https://aws.amazon.com/blogs/machine-learning/deploy-and-evaluate-models-with-amazon-sagemaker-jumpstart/)”。

## 结论

2026 年的前三个季度对 Amazon SageMaker JumpStart 来说是一段取得重大进展的时期。随着来自 30 个提供方的 100 多个新模型上架，目录如今覆盖了广泛的能力范围。这些包括前沿推理模型、多模态视觉语言模型、用于图像和视频生成的创意 AI、语音识别与合成、光学字符识别（OCR）与文档理解、用于 RAG 的 embedding 与检索模型、agentic 工作流模型，以及专用的科学计算模型。

这些上架重点反映了我们看到最强客户需求、以及最大机会加速 AWS 上 AI 采用的领域。它们包括扩展模型组合、弥合多模态差距、让创意 AI 触手可及、优先考虑效率与量化、上架专用模型，以及拓宽提供方多样性。

结合简化后的 Model Hub、预配置部署选项和 Hugging Face deep link 集成等改进，SageMaker JumpStart 持续降低模型发现与生产部署之间的门槛。访问 [SageMaker JumpStart 模型目录](https://aws.amazon.com/sagemaker/ai/jumpstart/)探索完整阵容。
