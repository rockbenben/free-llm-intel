# Connect AWS Quick to enterprise apps and agents with MCP

Organizations need solutions for people and AI agents to securely collaborate through a single interface to the organization’s data and take actions across enterprise applications to improve productivity. The ability of an AI agent to securely and seamlessly connect with organizational knowledge bases, enterprise applications, and other AI agents is foundational to drive adoption and use of AI solutions. [Model Context Protocol (MCP)](https://modelcontextprotocol.io/about) provides a more secure, standardized and simple mechanism for such connectivity, alleviating the need for complex custom integrations.

In this blog post, you will learn how to use [AWS Quick MCP Actions integrations](https://docs.aws.amazon.com/quicksuite/latest/userguide/mcp-integration.html) to connect with hosted MCP servers for enterprise applications such as [Asana](https://developers.asana.com/docs/using-asanas-model-control-protocol-mcp-server), [Atlassian’s Jira and Confluence](https://www.atlassian.com/platform/remote-mcp-server), [Box](https://developer.box.com/guides/box-mcp/), [Canva](https://www.canva.com/help/mcp-agent-setup/), [HubSpot](https://developers.hubspot.com/mcp), [HuggingFace](https://huggingface.co/docs/hub/en/hf-mcp-server), [Intercom](https://www.intercom.com/blog/introducing-model-context-protocol-fin), [Linear](https://linear.app/docs/mcp), [Monday](https://monday.com/w/mcp), [Notion](https://developers.notion.com/docs/mcp), [PagerDuty](https://support.pagerduty.com/main/docs/pagerduty-mcp-server-integration-guide), [Workato](https://docs.workato.com/en/mcp.html) and [Zapier](https://zapier.com/mcp) as well as your existing enterprise solutions and AI agents using [Amazon Bedrock AgentCore Gateway](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/gateway.html). We will cover specific Actions setup examples for Atlassian Jira and Confluence, [AWS Knowledge MCP Server](https://awslabs.github.io/mcp/servers/aws-knowledge-mcp-server/), and [Amazon Bedrock AgentCore Gateway](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/gateway.html).

## Solution overview

With the [AWS Quick MCP client](https://docs.aws.amazon.com/quicksuite/latest/userguide/mcp-integration.html), you can connect to remote hosted MCP servers or your own hosted MCP servers. The AWS Quick service includes an MCP client that can be used to securely connect AWS Quick with AI agents and applications through MCP servers. The AWS Quick MCP client supports server-sent events (SSE) and streamable HTTP for transport, and several authentication mechanisms including three-legged OAuth (3LO), two-legged OAuth (2LO), and No Auth. AWS Quick supports [OAuth 2.0 Dynamic Client Registration](https://modelcontextprotocol.io/specification/2025-03-26/basic/authorization#dynamic-client-registration) protocol to obtain OAuth client IDs without user interaction.

You can connect AWS Quick using the MCP client to create integrations with AWS Knowledge MCP Server and the Atlassian MCP server, as shown in the following diagram.

## Prerequisites

Verify that you meet the following prerequisites to deploy the solution in your own AWS account using the step-by-step instructions in this blog post. Before you begin, make sure that you have the following:

- An [AWS account](https://docs.aws.amazon.com/accounts/latest/reference/welcome-first-time-user.html#getting-started-step1)
- AWS Quick set up with Author Pro subscription
- An Atlassian account with Jira and Confluence access
- Permission to create AWS resources and [AWS Identity and Access Management (IAM)](https://aws.amazon.com/iam) roles and policies
- Basic knowledge of AWS services
- For the Amazon Bedrock AgentCore setup:  Access to a command line environment with AWS SDK and Python installed Knowledge of AWS CLI and Python Amazon Bedrock with access enabled for Anthropic models

## AWS Quick Actions integration with Atlassian MCP server

In this section, you will create an AWS Quick Actions integration with the Atlassian MCP server to connect with your Atlassian cloud instance, and then you will use your AWS Quick Chat Agent to invoke actions defined by this integration.

- Sign on to [AWS Quick](https://docs.aws.amazon.com/quicksuite/latest/userguide/what-is.html) using credentials with an Author Pro role using your web browser.
- From the AWS Quick **Home** screen, select **Integrations** from the **Connections** section on the left navigation panel and then select the **Actions** tab in the main panel. Select the plus (+) sign in the **Model Context Protocol** tile in the **Set up a new integration section**, as shown in the following screenshot.

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/10/10/002-Integrations-Actions-MCP.png)

- On the **Create integration** screen, enter the **Name** and **Description** for your Atlassian integration. For **MCP server endpoint,** enter the URL of [Atlassian hosted MCP server](https://www.atlassian.com/blog/announcements/remote-mcp-server) as `https://mcp.atlassian.com/v1/sse`, as shown in the following screenshot, then choose **Next**.

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/10/09/image5.png)

- The Atlassian MCP server supports dynamic client registration and three-legged OAuth (3LO). The AWS Quick MCP client gets further information required for the connection from the Atlassian MCP server. On the next screen and choose **Create and continue**.

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/10/09/image7.png)

- In the pop-up window from Atlassian MCP server with a request to approve authorization for the AWS Quick MCP client. Choose **Approve**.

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/10/09/image9-1.png)

- Enter your Atlassian credentials.
 You will get a request from the Atlassian MCP to access to your Atlassian account.
- Select a specific instance, and then choose **Accept**.
 Note: The administrator of the Atlassian instance might need to allowlist the dynamic OAuth client.

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/10/09/image11.png)

AWS Quick MCP client works to establish a connection with Atlassian MCP server and retrieving the actions or tools supported by it. It can take a couple of minutes.

- When the actions are retrieved and display on your screen, choose **Next**.

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/10/09/image13.png)

- Optionally, you can share the integration with other users and groups. Because Atlassian MCP server supports 3LO, the users with whom you share the connection will only be able to invoke the actions, retrieve the content, and take the actions that they are authorized to access on Atlassian Confluence and Jira. Select **Done**.

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/10/09/image15.png)

Your Actions integration for Atlassian MCP server is now available for use.

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/10/10/010-Atlassian-MCP-08.png)

- Invoke the `atlassian-mcp` Actions integration from an AWS Quick Chat Agent, such as My Assistant, using a simple prompt such as `List the Confluence spaces and Jira projects I am authorized to access.` This will request a sign-in for you to authorize `atlassian-mcp` Actions integration to connect with Atlassian MCP server on your behalf, a part of the 3LO authentication.

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/10/09/image19.png)

- The response to your prompt will be similar to the response in the following screenshot, and it will include the details of the Jira projects and Confluence pages you are authorized to access.

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/10/09/image21.png)

- On the **Create integration** screen, use the AWS Knowledge Server hosted MCP server URL, `https://knowledge-mcp.global.api.aws`, then choose **Next**.

## Connect with solutions and agents using Amazon Bedrock AgentCore Gateway

[Amazon Bedrock AgentCore Gateway](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/gateway.html) is a centralized tools server with a unified interface where agents can discover, access, and invoke tools with native support for MCP. You can connect your enterprise solutions and agents as targets behind an Amazon Bedrock AgentCore Gateway endpoint. The AWS Quick MCP client can connect to Amazon Bedrock AgentCore Gateway through Actions Integrations, making the tools available to the chat agents and automation workflows configured on AWS Quick.

Let’s take an example (shown in the following diagram) where we need to connect to an IT agent implemented using [Amazon Bedrock Agent](https://docs.aws.amazon.com/bedrock/latest/userguide/agents-how.html) with an [Amazon Kendra](https://docs.aws.amazon.com/kendra/latest/dg/what-is-kendra.html) index that has IT help content, and an HR agent setup on OpenAI needs to be made available to AWS Quick users.

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/10/10/030-Quick-MCP-Blog-Page-2.png)

The architecture includes an Amazon Bedrock AgentCore Gateway configured with an AWS Lambda function as a target along with an MCP schema that specifies the tools it implements. The AWS Lambda function implements the [InvokeAgent API](https://docs.aws.amazon.com/bedrock/latest/APIReference/API_agent-runtime_InvokeAgent.html) to invoke the Bedrock Agent to perform an Amazon Kendra index search, which then triggers a Lambda function to call the [Amazon Kendra Retrieve API](https://docs.aws.amazon.com/kendra/latest/APIReference/API_Retrieve.html) to search and retrieve content from the enterprise Amazon Kendra index with IT help content, and the OpenAI [Responses API](https://platform.openai.com/docs/api-reference/responses) to invoke the HR agent based on OpenAI. The AgentCore Gateway uses Amazon Cognito as its inbound identity provider. The AWS Quick MCP client is configured using a 2LO authentication, allowing inbound connections to the AgentCore Gateway endpoint.

## Create an Amazon Bedrock AgentCore Gateway instance and connect it with solutions

- Create an Amazon Bedrock AgentCore Gateway instance with an Amazon Cognito authorizer and a default AWS Lambda target using [Quick Start with creating and using a gateway](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/gateway-quick-start.html).
- Open the Amazon Cognito user pool in a tab of the AWS Management Console and select **App clients** in the left navigation panel.

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/10/09/image45.jpg)

- Create a new App client for use with the AWS Quick MCP client. Choose **Create app client,** then select **Machine-to-machine application**, and then choose **Create app client**.

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/10/09/image46.png)

- For the new App client you just created, note the **Client ID**, the **Client secret,** and the token URL. You will need these parameters in subsequent steps.

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/10/09/image48.png)

- Open Amazon Bedrock AgentCore in the AWS Management Console on a new tab in your browser. Select **Gateways** in the left navigation panel, and then select the gateway you just created. Note the **Gateway resource URL**.

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/10/09/image51.jpg)

- On the **Edit Gateway** screen, select **Use existing identity provider configurations**, choose **Add client,** and then add the Client ID of the Cognito App client you created in a previous step to the list of allowed clients.

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/10/09/image52.png)

- Note the **Lambda ARN** and review the inline schema in the **Inline schema editor window**. Choose **Save**.

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/10/09/image55.jpg)

- You can modify the schema and the lambda functions to add your solutions and agents to the AgentCore gateway. The schema used for the example in this blog is in the following code snippet. For the example used in this blog, the Lambda function is also updated with the [InvokeAgent API](https://docs.aws.amazon.com/bedrock/latest/APIReference/API_agent-runtime_InvokeAgent.html) to invoke the Bedrock Agent that implements the IT agent, and the OpenAI [Responses API](https://platform.openai.com/docs/api-reference/responses) to invoke the HR agent powered by OpenAI. If you are just experimenting, you can continue with the sample tools, `get_weather` and `get_time`, created as part of [Quick Start with creating and using a Gateway](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/gateway-quick-start.html).

```
[
  {
    "description": "Get weather for a location",
    "inputSchema": {
      "properties": {
        "location": {
          "type": "string"
        }
      },
      "required": [
        "location"
      ],
      "type": "object"
    },
    "name": "get_weather"
  },
  {
    "description": "Get time for a timezone",
    "inputSchema": {
      "properties": {
        "timezone": {
          "type": "string"
        }
      },
      "required": [
        "timezone"
      ],
      "type": "object"
    },
    "name": "get_time"
  },
  {
    "description": "Get help from IT Agent for questions related to email, networking, computer hardware and password trouble",
    "inputSchema": {
      "properties": {
        "query": {
          "description": "question related to email, networking, computer hardware and password troubleshooting",
          "type": "string"
        }
      },
      "required": [
        "query"
      ],
      "type": "object"
    },
    "name": "get_help_from_it_agent"
  },
  {
    "description": "Get help from HR Agent for questions related to employee benefits and leave policies",
    "inputSchema": {
      "properties": {
        "request": {
          "description": "help query related to employee benefits and leave policies",
          "type": "string"
        }
      },
      "required": [
        "request"
      ],
      "type": "object"
    },
    "name": "get_help_from_hr_agent"
  }
]
```

Amazon Bedrock AgentCore Gateway is now ready for integration with the AWS Quick MCP client or other MCP clients.

## Create an AWS Quick MCP Actions integration with Amazon Bedrock AgentCore Gateway

- As with earlier steps, set up a new MCP integration by entering a a **Name**, **Description**, and the Gateway resource URL of your Amazon AgentCore gateway (noted earlier as the **MCP server endpoint)**. Choose **Next**. The Description includes details of the features the Actions integration provides. AWS Quick uses this description to decide the Actions to be invoked for a user prompt.

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/10/10/image56.png)

- Select **Service authentication** in **Authentication settings** or 2LO authentication. The users with whom this Actions integration is shared will use these credentials as the inbound credentials for Amazon Bedrock AgentCore Gateway. You can create 3LO authentication using identity providers such as Okta or Entra ID. Enter the **Client ID**, **Client secret** and **Token URL** of the Amazon Cognito user pool App client you created earlier. Choose **Create and continue**.

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/10/09/image58.png)

- Review the Actions made available as MCP tools by the Amazon Bedrock AgentCore Gateway.

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/10/10/image60.png)

- Optionally, share the integration with other users, then choose **Done**.

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/10/09/image62.png)

Your Actions integration with the Amazon Bedrock AgentCore gateway is now ready for use.

- You can now test the AWS Quick Actions integration by opening the newly created integration and choosing **Test action APIs**.

## Conclusion
