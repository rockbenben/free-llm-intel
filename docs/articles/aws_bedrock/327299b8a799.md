# Claude Opus 4.8 现已在 AWS 上可用

今天，我们很高兴宣布，Anthropic 最先进的 Opus 模型 Claude Opus 4.8 已在 Amazon Bedrock 和 [Claude Platform on AWS](https://aws.amazon.com/blogs/machine-learning/introducing-claude-platform-on-aws-anthropics-native-platform-through-your-aws-account/) 上可用。Claude Opus 4.8 代表着切切实实的进步，在团队于生产环境中运行的各类工作流上都带来改进：从 agentic coding 与深度知识工作，到能独立运行数小时的多阶段自主任务。借助 Amazon Bedrock 上的 Claude Opus 4.8，你可以在现有的 AWS 环境中构建，保持企业级安全与区域数据驻留，并扩展推理规模。Claude Opus 4.8 也可通过 Claude Platform on AWS 使用，在不需要区域数据驻留时，让你获得 Anthropic 的原生平台体验。

本文介绍 Opus 4.8 的改进之处，并为要把该模型集成到 Amazon Bedrock 上 agentic 系统与生产推理负载中的 AI 工程师提供实用指导。Claude Platform on AWS 的相关说明请见[文档](https://docs.aws.amazon.com/claude-platform/)。

## Claude Opus 4.8 有何不同

[Claude Opus 4.8](https://www.anthropic.com/news/claude-opus-4-8) 的设计目标是改变团队能交付给 Claude 的工作边界：在编码、agentic 任务和专业工作上都有更强的表现，并具备面向长期运行的生产工作流所需的一致性与自主性。Opus 4.8 能够跨阶段把持一个计划，更好地跟踪哪些已经做完、哪些还没做，并在出问题时调整路线，而不是抛出一个错误就停下。这应能在规模上带来更可预测的行为：输出方差更低，评审轮次更少。

在编码方面，Opus 4.8 的设计目标是能在真实代码库中导航、在动手编辑前先做规划，并在长时间的会话中保持上下文。在多阶段任务上，它能跟踪依赖关系，并在长时间运行中保持连贯。同样的自主性延伸到 agentic 工作流：它能处理复杂的依赖链和多步工具使用，且所需的监督更少，因此既适合面向客户的 agent，也适合内部 agent。在专业工作方面，Opus 4.8 能把冗长复杂的资料综合成结构化交付物，例如简报、分析和报告。

## 行业用例

Claude Opus 4.8 的能力非常适合那些最看重一致性与深度的行业。对金融服务团队来说，Opus 4.8 可协助投资研究和财报分析，在整个报告周期内携带上下文。对法律团队来说，它能支持合同审阅、尽职调查，以及动议与备忘录的初稿。在生命科学领域，它有助于文献综述、监管申报材料起草和试验数据综合。在网络安全领域，它通过把长追溯记录和大型代码库保持在上下文中，强化威胁情报综合、漏洞发现和事件响应。

## 在 Amazon Bedrock 上开始使用 Claude Opus 4.8

你可以在 [Amazon Bedrock 控制台](https://console.aws.amazon.com/bedrock/?trk=d8ec3b19-0f37-4f8c-8c12-189f913e205c&sc_channel=el)中开始使用 Claude Opus 4.8。

- 在 Amazon Bedrock 控制台中，在 **Test** 下选择 **Playground**。
- 在模型一栏选择 Claude Opus 4.8。现在，你就可以用该模型测试复杂的编码提示词。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/05/28/21036-1.png)
![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/05/28/21036-2.png)

*已选中 Claude Opus 4.8 的 Amazon Bedrock 控制台 Playground*

你也可以通过 [Anthropic Messages API](https://docs.aws.amazon.com/bedrock/latest/userguide/model-parameters-anthropic-claude-messages.html?trk=d8ec3b19-0f37-4f8c-8c12-189f913e205c&sc_channel=el) 以编程方式访问该模型，经 Anthropic SDK 或 `bedrock-mantle` 端点调用 `bedrock-runtime`；也可以继续通过 [AWS Command Line Interface (AWS CLI)](https://aws.amazon.com/cli/?trk=769a1a2b-8c19-4976-9c45-b6b1226c7d20&sc_channel=el) 和 [AWS SDK](https://aws.amazon.com/developer/tools/?trk=769a1a2b-8c19-4976-9c45-b6b1226c7d20&sc_channel=el) 在 `bedrock-runtime` 上使用 [Invoke](https://docs.aws.amazon.com/bedrock/latest/userguide/inference-api.html) 和 [Converse API](https://docs.aws.amazon.com/bedrock/latest/userguide/conversation-inference.html?trk=d8ec3b19-0f37-4f8c-8c12-189f913e205c&sc_channel=el)。

**先决条件**

- 已启用 Amazon Bedrock 访问权限的有效 AWS 账户
- 已安装并配置 AWS CLI
- Python 3.8+
- 已安装 Boto3：`pip install boto3`
- IAM 权限：`bedrock:InvokeModel` 和 `bedrock:InvokeModelWithResponseStream`

下面是一个使用 AWS SDK for Python（Boto3）的快速示例：

```
import boto3 
import json 
# Create a Bedrock Runtime client 
bedrock_runtime = boto3.client( 
    service_name="bedrock-runtime", 
    region_name="us-east-1" 
) 
# Invoke Claude Opus 4.8 
response = bedrock_runtime.invoke_model( 
    modelId="us.anthropic.claude-opus-4-8", 
    contentType="application/json", 
    accept="application/json", 
    body=json.dumps({ 
        "anthropic_version": "bedrock-2023-05-31", 
        "max_tokens": 4096, 
        "messages": [ 
            { 
                "role": "user", 
                "content": "Design a distributed architecture on AWS in Python that should support 100k requests per second across multiple geographic regions." 
            } 
        ] 
    }) 
) 
result = json.loads(response["body"].read()) 

print(result["content"][0]["text"])
```

你也可以配合 Amazon Bedrock Converse API 使用 Claude Opus 4.8，获得统一的多模型体验：

```
import boto3 
bedrock_runtime = boto3.client("bedrock-runtime", region_name="us-east-1") 
response = bedrock_runtime.converse( 
    modelId="us.anthropic.claude-opus-4-8", 
    messages=[ 
        { 
            "role": "user", 
            "content": [ 
                { 
                    "text": "Design a distributed architecture on AWS in Python that should support 100k requests per second across multiple geographic regions." 
                } 
            ] 
        } 
    ], 
    inferenceConfig={ 
        "maxTokens": 4096 
    } 
) 
print(response["output"]["message"]["content"][0]["text"]) 
```

## 可用性

Claude Opus 4.8 今天已在 Amazon Bedrock 的以下区域可用：US East (N. Virginia)、Asia Pacific (Tokyo)、Europe (Ireland) 和 Europe (Stockholm)。完整的受支持区域列表请见 [Bedrock 文档](https://docs.aws.amazon.com/bedrock/latest/userguide/model-card-anthropic-claude-opus-4-8.html)。Claude Opus 4.8 也已在北美、南美、欧洲和亚太地区的 Claude Platform on AWS 上可用。

你可以在 [Amazon Bedrock 控制台](https://console.aws.amazon.com/bedrock?trk=d8ec3b19-0f37-4f8c-8c12-189f913e205c&sc_channel=el) 中试用 Claude Opus 4.8，在 [Claude Platform on AWS](https://console.aws.amazon.com/claude-platform/) 中试用，或了解 GitHub 上的 [Getting Started notebooks](https://github.com/aws-samples/anthropic-on-aws/tree/main/notebooks)。你还可以使用 Amazon Bedrock 上的 [Advanced Prompt Optimization](https://docs.aws.amazon.com/bedrock/latest/userguide/advanced-prompt-optimization-how.html) 来释放 Opus 4.8 的全部潜力：它会拿你现有的提示词，对照你的评测标准做基准测试，并输出可直接用于生产的改写版本。
