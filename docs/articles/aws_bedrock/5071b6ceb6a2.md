# 开发人员现在可以通过全新的 AWS 体验访问 SageMaker Studio

今天，我们很高兴地[宣布](https://aws.amazon.com/about-aws/whats-new/2026/10/sagemaker-studio-social-sign-in/)，新的 Amazon SageMaker AI 客户现在只需在注册 AWS 后几步操作，即可进入一个完全配置好的 Amazon SageMaker Studio 环境。你可以使用已有的登录方式，例如 Amazon、Apple、GitHub、Google 或电子邮件地址。你无需设置高级 AWS 账户、输入信用卡信息（对大多数客户而言），也不需要手动配置环境。新客户还可获得 100 美元的 AWS Free Tier 额度，可用于 SageMaker AI 的各项功能，包括模型定制、训练作业、Studio notebook 和端点部署。

本文是我们上一篇博文[《从 Hugging Face 一键进入 Amazon SageMaker Studio》](https://aws.amazon.com/blogs/machine-learning/from-hugging-face-to-amazon-sagemaker-studio-in-one-click-2/)的延续，那篇文章介绍了从 Hugging Face 模型页面直接跳转到 SageMaker Studio 工作流的深度链接。今年早些时候，我们还将 Studio 环境的创建时间从 2 分钟缩短到约 20 秒，并在每个新的 Studio 域中预配置了模型定制权限。这些改动共同消除了开发人员进入 Studio 之后的许多摩擦。但在他们抵达那里之前，仍有一个主要障碍：创建 AWS 账户。新客户必须先验证电子邮件地址、填写联系信息、验证电话号码、提供付款详情并选择支持计划，然后才能开始构建。对于习惯了几分钟内登录并开始构建的个人开发者和初创小团队来说，这仍然是一道显著的门槛。

## 新增内容

通过本次发布，SageMaker Studio 现已与[更新后的 AWS 登录和注册体验](https://aws.amazon.com/blogs/aws/aws-reimagines-the-getting-started-experience/)集成，后者引入了创建和管理 AWS 账户的新选项，并简化了协作。新客户可以使用已有的身份创建账户，并立即开始在 SageMaker Studio 中构建。

## 全新登录体验

新客户现在可以通过 2–3 个步骤，使用 Google、GitHub、Apple 或 Amazon 账户，或使用电子邮件地址完成注册。你无需完成高级 AWS 账户注册、验证电话号码或输入信用卡信息（对大多数客户而言）：

## 最高 200 美元的 Free Tier 额度，大多数客户无需信用卡

新客户可获得 100 美元的 AWS Free Tier 额度，可用于 SageMaker AI 的各项功能，包括端点部署、模型定制、Studio notebook 和模型训练。你还有机会额外获得价值 100 美元的额度。额度会自动抵扣你的用量，并在你接近上限时通过电子邮件通知你。Free Tier 期限在 6 个月后结束，或在你用完所有额度时结束，以先到者为准。届时资源使用会自动停止，因此你不会因意外费用而感到措手不及。你随时可以添加付款详情，升级到付费计划。

## 建立在以往发布的基础之上

通过新登录体验创建的新环境包含以往发布的各项改进。模型定制、训练、评估和部署的权限均已预配置，因此你无需创建 AWS Identity and Access Management (IAM) 角色。符合条件的账户可默认访问 G5、G6 和 G4dn GPU 实例，用于端点、训练作业和 Studio notebook。此外，Studio 中的实例选择菜单会显示配额可用情况，让你可以快速看到哪些实例类型可供使用。

## 开始使用

你今天就可以试用全新的登录体验：

- 在 [Hugging Face](https://huggingface.co/models) 上浏览模型，选择 **Deploy**，选择 **Amazon SageMaker AI**，然后在受支持的模型上选择 **Customize on SageMaker AI** 或 **Deploy on SageMaker AI**。或者访问 [Amazon SageMaker Studio](https://aws.amazon.com/sagemaker/studio/) 页面，选择 **Get started with Amazon SageMaker AI**。
- 在 AWS 登录页面，选择 **Google**、**GitHub**、**Apple** 或 **Amazon**，或输入你的电子邮件地址，然后按照提示在几步内创建账户。
- 进入已完全配置好的 SageMaker Studio 环境，使用你的 Free Tier 额度开始构建。

全新登录体验适用于新的 AWS 账户。如果你已有 AWS 账户，登录方式没有任何变化。

## 结论

全新登录体验消除了从发现到使用 Amazon SageMaker AI 构建之间的最后一道主要障碍。结合更快的环境创建、预配置的权限、来自 Hugging Face 的深度链接以及默认的 GPU 访问权限，个人开发者可以快速上手。初创团队现在可以使用已有的身份，在几分钟内从寻找模型走到定制或部署模型。

要开始使用，请访问 [aws.amazon.com/sagemaker/studio](https://aws.amazon.com/sagemaker/studio/)，或在 [Hugging Face](https://huggingface.co/models) 上浏览模型。
