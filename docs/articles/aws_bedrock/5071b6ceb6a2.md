# 开发人员现在可以通过新的 AWS 体验访问 SageMaker Studio

今天，我们很高兴地宣布，新的 Amazon SageMaker AI 客户现在只需几个步骤即可在注册 AWS 后进入完全配置的 Amazon SageMaker Studio 环境。您可以使用已有的登录方法，例如 Amazon、Apple、GitHub、Google 或电子邮件地址。您无需设置高级 AWS 账户、输入信用卡（对于大多数客户）或手动配置环境。新客户还可以获得 100 美元的 AWS 免费套餐积分，这些积分适用于 SageMaker AI，包括模型自定义、培训作业、Studio 笔记本和端点部署。

这篇文章是我们上一篇文章[一键从 Hugging Face 到 Amazon SageMaker Studio](https://aws.amazon.com/blogs/machine-learning/from-hugging-face-to-amazon-sagemaker-studio-in-one-click-2/) 的后续文章，其中介绍了从 Hugging Face 模型页面直接到 SageMaker Studio 工作流程的深层链接。今年早些时候，我们还将 Studio 环境创建时间从 2 分钟缩短到约 20 秒，并在每个新的 Studio 域中预配置了模型自定义权限。总之，这些变化消除了开发人员进入 Studio 后的大部分障碍。在他们实现这一目标之前，还存在一个主要障碍：创建 AWS 账户。新客户必须验证电子邮件地址、输入联系信息、验证电话号码、提供付款详细信息并选择支持计划，然后才能开始构建。对于习惯在几分钟内登录并构建的个人开发人员和小型初创团队来说，这仍然是一个重大障碍。

## 新消息

此次发布后，SageMaker Studio 现已与[更新的 AWS 登录和注册体验](https://aws.amazon.com/blogs/aws/aws-reimagines-the-getting-started-experience/) 集成，引入了用于创建和管理 AWS 账户的新选项以及简化的协作。新客户可以使用他们已有的身份创建帐户，并立即开始在 SageMaker Studio 中进行构建。

新客户现在可以使用 Google、GitHub、Apple 或 Amazon 帐户或电子邮件地址进行注册，只需 2-3 个步骤。您无需完成高级 AWS 账户注册、验证电话号码或输入信用卡（对于大多数客户）：

## 高达 200 美元的免费套餐积分，大多数客户无需信用卡

新客户将获得 100 美元的 AWS 免费套餐积分，这些积分适用于 SageMaker AI，包括端点部署、模型定制、Studio 笔记本和模型训练。您还有机会额外获得价值 100 美元的积分。积分会自动应用到您的使用量中，并且当您接近限额时，您会收到电子邮件通知。免费套餐期将在 6 个月后或您用完所有积分后结束（以先到者为准）。此时，资源使用会自动停止，因此您不会因意外费用而感到惊讶。您可以随时通过添加付款详细信息升级到付费计划。

## 建立在之前发布的基础上

通过新的登录体验创建的新环境包括对早期发布的改进。模型自定义、训练、评估和部署的权限是预先配置的，因此您无需创建 AWS Identity and Access Management (IAM) 角色。符合条件的帐户可以默认访问端点、训练作业和 Studio 笔记本的 G5、G6 和 G4dn GPU 实例。此外，Studio 中的实例选择菜单会显示配额可用性，因此您可以快速查看哪些实例类型可供使用。

## 开始使用

您今天可以尝试新的登录体验：

- 在 [Hugging Face](https://huggingface.co/models) 上浏览模型，选择 **部署**，选择 **Amazon SageMaker AI**，然后在受支持的模型上选择 **在 SageMaker AI 上自定义** 或 **在 SageMaker AI 上部署**。或者，访问 [Amazon SageMaker Studio](https://aws.amazon.com/sagemaker/studio/) 页面并选择 **开始使用 Amazon SageMaker AI**。
- 在 AWS 登录页面上，选择 **Google**、**GitHub**、**Apple** 或 **Amazon**，或输入您的电子邮件地址，然后按照提示通过几个步骤创建您的帐户。
- 进入完全配置的 SageMaker Studio 环境，并使用您的免费套餐积分开始构建。

新的登录体验适用于新的 AWS 账户。如果您已有 AWS 账户，则登录方式不会发生变化。

## 结论

新的登录体验消除了使用 Amazon SageMaker AI 发现和构建之间的最后一个主要障碍。结合更快的环境创建、预配置的权限、Hugging Face 的深层链接以及默认的 GPU 访问，个人开发者可以快速上手。初创团队现在可以使用他们已有的身份，在几分钟内从查找模型到定制或部署模型。

要开始使用，请访问 [aws.amazon.com/sagemaker/studio](https://aws.amazon.com/sagemaker/studio/) 或在 [Hugging Face](https://huggingface.co/models) 上探索模型。
