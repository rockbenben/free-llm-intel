Claude Fable 5.2

and

Claude Mythos 5.2

bedrock-runtime

endpoint through US, AWS GovCloud (US), and Global cross-Region inference. Claude Mythos 5.1

model card to add computer use, client toolsets, compaction, and the

aws_review

data retention mode. Corrected compaction support: added Compaction to the Claude Fable 5 and Claude Fable 5.1 model cards, listed both compaction beta values on supported model cards, expanded the

compact-2026-01-12

supported-model list, and marked compaction as not supported on Claude Haiku 4.5. Added Claude Sonnet 5.5 to the models that support mid-conversation tool changes.
