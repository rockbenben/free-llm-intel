# 在 AWS 上推出 Claude Fable 5.2

今天，我们宣布 Claude Fable 5.2 和 Claude Mythos 5.2 在 Amazon Bedrock 和 AWS 上的 Claude Platform 中提供。Claude Fable 5.2 是 Anthropic 面向技术工作、能力最强的正式可用模型，在编码和科学领域树立了新标杆。Claude Mythos 5.2 通过 Anthropic 的验证计划提供，面向网络安全和生命科学领域的高级工作。

在本文中，我们将介绍这两个模型的新特性、Fable 5.2 对你的技术工作负载为何重要，以及如何在 Amazon Bedrock 上开始使用该模型进行构建。

## 为什么选择 Claude Fable 5.2

Fable 5.2 在编码、数学和科学中最难的问题上树立了新标杆。它能承接模糊的多步骤工作，验证自己的输出，并可以在无人值守的情况下运行数小时到数天。它解读 prompt、迭代、发现自己的错误，并在过程中不断优化。

在 Anthropic 的对齐测试中，与 Opus 5.5、Sonnet 5.5 和 Mythos 5.1 相比，Mythos 5.2 幻觉更少、完成任务更可靠、更稳定地呈现重要信息，并且更诚实地自我报告问题。Anthropic 预计 Fable 5.2 会有类似表现。

如果网络安全查询被拒绝，你可以在 Opus 4.8 上重试；如果生物学查询被拒绝，你可以在 Opus 5 上重试。在 Amazon Bedrock 上，重试由你的代码负责，而不是自动切换。如果被拒绝的请求命中了 prompt cache，拒绝响应中还会包含一个 fallback credit token。重试时带上该 token，就会按缓存读取计费，这样你就不必为写入同一份缓存付两次钱。有关 fallback credit 的更多信息，请查看[文档](https://docs.aws.amazon.com/bedrock/latest/userguide/claude-messages-fallback-credit.html)。

对于网络安全和生命科学领域的授权工作，Claude Mythos 5.2 可通过 [Anthropic 的验证计划](https://www.anthropic.com/news/cyber-verification-program)使用。

## Claude Fable 5.2 和 Mythos 5.2 的用例

Fable 5.2 的适用场景：

- **Agentic coding**：跨越大型多仓库代码库。
- **长时间运行的 agent**：在多日工作中协调许多 subagent。
- **科学研究**：从新的分析方法到形式化数学证明。
- **金融分析**：用于量化研究和预测。
- **3D、硬件与运动设计**：以代码生成环境、组件和仿真。

Mythos 5.2 覆盖两个高风险领域，仅通过前面提到的验证计划提供：

- **网络安全**：用于安全工程、red teaming 和渗透测试。
- **生命科学研究**：尤其是生物分子设计和研究综合。

## 数据保留与 Enterprise Frontier Safeguards

Anthropic 将 Claude Fable 5.2 指定为 [Covered Model](https://support.claude.com/en/articles/15425695-covered-models)。默认情况下，使用它需要保留数据最长 30 天并接受人工安全审查。在 Amazon Bedrock 上，由 Amazon 人员在 AWS 边界内执行审查。在调用模型之前，请在你的账户或项目上设置 `aws_review` 数据保留模式。更多详情请参阅 [Amazon Bedrock 数据保留](https://docs.aws.amazon.com/bedrock/latest/userguide/data-retention.html)。

与 AWS 合作构建的 [Enterprise Frontier Safeguards](https://www.anthropic.com/news/enterprise-frontier-safeguards)（EFS）将零数据保留（ZDR）的隐私性与检测滥用的最新保障措施结合在一起。EFS 现已可用。预计随后会推出一个将你的数据保存在你所控制的 bucket 和密钥之下的版本，该版本尚未发布。在此之前，符合条件的客户可以在 2027 年 6 月 30 日之前以零数据保留方式使用 Fable 5.2。

## 在 Amazon Bedrock 上开始使用 Claude Fable 5.2

要试用 Fable 5.2，请打开 [Amazon Bedrock 控制台](https://console.aws.amazon.com/bedrock/)，选择 **Test**、**Playground**，并选择 **Fable 5.2** 作为模型。然后你就可以直接对它运行 prompt。

以编程方式，你可以通过 [Anthropic Messages API](https://docs.aws.amazon.com/bedrock/latest/userguide/model-parameters-anthropic-claude-messages.html) 针对 `bedrock-runtime` 调用该模型（通过 Anthropic SDK）。你也可以继续通过 [AWS Command Line Interface (AWS CLI)](https://aws.amazon.com/cli/) 和 [AWS SDK](https://aws.amazon.com/developer/tools/) 使用 `bedrock-runtime` 上的 [Invoke](https://docs.aws.amazon.com/bedrock/latest/userguide/inference-api.html) 和 [Converse](https://docs.aws.amazon.com/bedrock/latest/userguide/conversation-inference.html) API。

### 前提条件

要跟随本文中的代码示例操作，你需要以下条件：

- 一个可访问 Amazon Bedrock 的有效 [AWS 账户](https://portal.aws.amazon.com/gp/aws/developer/registration/index.html)。
- 已安装 [AWS CLI](https://aws.amazon.com/cli/) 并配置了适当的凭证。
- Python 3.9 或更高版本。
- 已安装 [Boto3](https://boto3.amazonaws.com/v1/documentation/api/latest/index.html)（AWS SDK for Python）：`pip install boto3`。
- AWS Identity and Access Management（IAM）权限：`bedrock:InvokeModel` 和 `bedrock:InvokeModelWithResponseStream`。

下面是一个使用 AWS SDK for Python（Boto3）的快速示例：

```
import boto3
import json

# Create a Bedrock Runtime client
bedrock_runtime = boto3.client(
    service_name="bedrock-runtime",
    region_name="us-east-1"
)

# Invoke Claude Fable 5.2
response = bedrock_runtime.invoke_model(
    modelId="global.anthropic.claude-fable-5-2",
    contentType="application/json",
    accept="application/json",
    body=json.dumps({
        "anthropic_version": "bedrock-2023-05-31",
        "max_tokens": 4096,
        "messages": [
            {
                "role": "user",
                "content": "An S3 bucket serves 40 TB/month egress. Estimate the monthly egress cost at $0.09/GB, and state one architecture change, using AWS services, to cut it. Show the calculation, keep it under 120 words."
            }
        ]
    })
)

result = json.loads(response["body"].read())

# Fable 5.2 is a reasoning model: the response may include a thinking block
# before the text block, so select the text block rather than a fixed index.
print(next(b["text"] for b in result["content"] if b["type"] == "text"))
```

## 使用 Claude Code 中的 claude-api skill 迁移到 Claude Fable 5.2

对于已经在 Amazon Bedrock 上运行 Claude 模型的团队，Claude Code 中的 claude-api skill 可以帮助你升级到 Fable 5.2。

claude-api skill 是内置于 [Claude Code](https://code.claude.com/docs) 的开源 skill，它汇集了让 Claude API 代码良好工作的各种细节。它涵盖哪些 agent 模式适合给定任务、模型代际之间哪些参数会变化，以及何时应用 prompt caching。它随 Anthropic SDK 的演进而保持最新：当新模型发布或 API 新增功能时，该 skill 已经知晓。

### 该 skill 为 Fable 5.2 迁移做什么

当你要求 Claude Code 将你的代码库升级到 Fable 5.2 时，该 skill 会审查你的代码，并带你逐步完成：

- **更新模型引用**：在你的应用代码中将模型 ID 替换为 Fable 5.2 的 ID。
- **调整 thinking 设置**：在适合新模型的情况下，将 manual thinking 配置迁移到 adaptive thinking。
- **清理过时的参数**：移除不再适用的已弃用 beta header、参数和设置。
- **建议 effort 级别**：根据你的用例，就地推荐合适的 `output_config.effort` 设置。

该 skill 还会检测你的部署平台（包括 Amazon Bedrock、AWS 上的 Claude Platform 和其他环境），并相应调整模型 ID 格式和功能配置。例如，它会使用 Amazon Bedrock 结构化模型 ID 格式（`global.anthropic.claude-fable-5-2`）。

### 如何使用

在 Claude Code 中，直接运行迁移：

`/claude-api migrate`

它会扫描你的工作目录（或你确认的子目录或特定文件列表），并在一次引导式流程中应用迁移更改。你也可以通过对话方式调用它，告诉 Claude Code：

- *“帮我升级到 Claude Fable 5.2”*：Claude 会审查你的代码，并带你逐步完成必要的更改。
- *“提高我的缓存命中率”*：该 skill 会应用许多开发者忽略的 prompt caching 规则，帮助降低 Bedrock 上的成本。
- *“为我的 agent 添加 context compaction”*：它会带你了解用于长时间运行的 Fable 5.2 会话的 compaction 原语和 agent 模式。

claude-api skill 可在 Claude Code 中使用，也已捆绑到 CodeRabbit、JetBrains IDE（包括 Junie）、Resolve AI 和 Warp 中。它在 GitHub 上的 [anthropics/skills](https://github.com/anthropics/skills/tree/main/skills/claude-api) 开源，因此任何 coding agent 都可以集成它。

## 可用性

Claude Fable 5.2 和 Claude Mythos 5.2 今天已在 Amazon Bedrock 上通过 US Geo CRIS 和 Global CRIS inference profile 提供。完整的支持区域列表请参阅[ Bedrock 文档](https://docs.aws.amazon.com/bedrock/latest/userguide/model-cards-anthropic.html)。定价信息请参阅[ Amazon Bedrock 定价](https://aws.amazon.com/bedrock/pricing/)。这两个模型还通过 AWS 上的 Claude Platform 在该服务提供的每个区域中提供。

在 [Amazon Bedrock 控制台](https://console.aws.amazon.com/bedrock)、[AWS 上的 Claude Platform](https://console.aws.amazon.com/claude-platform/) 中试用 Claude Fable 5.2，或在 GitHub 上浏览 [Getting Started notebook](https://github.com/aws-samples/anthropic-on-aws/blob/main/notebooks/claude_fable_5_2_getting_started/claude-fable-5-2-getting-started.ipynb)。
