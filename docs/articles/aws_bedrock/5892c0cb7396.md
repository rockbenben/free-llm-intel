# 在 AWS 上介绍Claude寓言 5.2

今天，我们宣布在 Amazon Bedrock 上推出 Claude Fable 5.2 和 Claude Mythos 5.2 以及在 AWS 上推出 Claude Platform。 Claude Fable 5.2 是 Anthropic 最有能力的通用模型，用于技术工作，提高了编码和科学的标准。 Claude Mythos 5.2 可通过 Anthropic 的验证计划用于网络安全和生命科学领域的高级工作。

在这篇文章中，我们将介绍这两个模型的新增功能、为什么 Fable 5.2 对您的技术工作负载很重要，以及如何开始在 Amazon Bedrock 上使用该模型进行构建。

## 为什么是Claude寓言 5.2

《神鬼寓言 5.2》提高了编码、数学和科学领域最难问题的标准。它承担不明确的、多步骤的工作，验证自己的输出，并且可以在无人值守的情况下运行数小时至数天。它解释提示、迭代、捕获自己的错误并进行优化。

在 Anthropic 的一致性测试中，Mythos 5.2 比 Opus 5.5、Sonnet 5.5 和 Mythos 5.1 产生更少的幻觉，更可靠地完成任务，更一致地呈现重要信息，并且更诚实地自我报告问题。 Anthropic 预计《神鬼寓言 5.2》也会有类似的表现。

如果网络安全查询被拒绝，您可以在 Opus 4.8 上重试，如果生物学查询被拒绝，您可以在 Opus 5 上重试。在 Amazon Bedrock 上，重试是您的代码的工作，而不是自动切换。如果被拒绝的请求命中提示缓存，则拒绝还包括后备信用令牌。通过重试发送该令牌，并按照缓存读取进行计费，因此您无需支付两次写入相同缓存的费用。有关后备信用的更多信息，请查看[文档](https://docs.aws.amazon.com/bedrock/latest/userguide/claude-messages-fallback-credit.html)。

对于网络安全和生命科学领域的授权工作，Claude Mythos 5.2 可通过 [Anthropic 的验证程序](https://www.anthropic.com/news/cyber-verification-program) 获得。

## Claude寓言 5.2 和神话 5.2 用例

《神鬼寓言 5.2》适合的地方：

- **跨大型多存储库代码库的代理编码**。
- **长期运行的代理**，用于协调多个子代理的多日工作。
- **科学研究**从新的分析方法到形式的数学证明。
- **用于定量研究和预测的财务分析**。
- **3D、硬件和运动设计**，用于在代码中生成环境、组件和模拟。

Mythos 5.2 涵盖两个高风险领域，只能通过前面提到的验证程序获得：

- **网络安全**，用于安全工程、红队和渗透测试。
- **生命科学研究**，特别是生物分子设计和研究合成。

## 数据保留和企业前沿保障

Anthropic 将 Claude Fable 5.2 指定为[涵盖模型](https://support.claude.com/en/articles/15425695-covered-models)。默认情况下，其使用需要保留长达 30 天并进行人类安全审查。在 Amazon Bedrock 上，Amazon 人员在 AWS 边界内执行审核。在调用模型之前，在您的账户或项目上设置“aws_review”数据保留模式。有关更多详细信息，请参阅 [Amazon Bedrock 数据保留](https://docs.aws.amazon.com/bedrock/latest/userguide/data-retention.html)。

[企业前沿保障](https://www.anthropic.com/news/enterprise-frontier-safeguards) (EFS) 与 AWS 合作构建，将零数据保留 (ZDR) 隐私与检测滥用的最新保障措施相结合。 EFS 现已推出。预计将推出将数据保存在存储桶中并由您控制的密钥的版本，但尚未启动。在此之前，符合条件的客户可以在 2027 年 6 月 30 日之前以零数据保留的方式使用 Fable 5.2。

## 在 Amazon Bedrock 上开始使用 Claude Fable 5.2

要尝试 Fable 5.2，请打开 [Amazon Bedrock 控制台](https://console.aws.amazon.com/bedrock/)，选择 **Test**、**Playground**，然后选择 **Fable 5.2** 作为模型。从那里，您可以直接针对它运行提示。

通过编程方式，您可以使用 [Anthropic Messages API](https://docs.aws.amazon.com/bedrock/latest/userguide/model-parameters-anthropic-claude-messages.html) 针对“bedrock-runtime”（通过 Anthropic SDK）调用模型。您还可以通过 [AWS 命令行界面 (AWS CLI)](https://aws.amazon.com/cli/) 和 [AWS] 继续使用“bedrock-runtime”上的 [Invoke](https://docs.aws.amazon.com/bedrock/latest/userguide/inference-api.html) 和 [Converse](https://docs.aws.amazon.com/bedrock/latest/userguide/conversation-inference.html) API SDK](https://aws.amazon.com/developer/tools/)。

### 先决条件

要遵循本文中的代码示例，您需要以下内容：

- 具有 Amazon Bedrock 访问权限的活跃 [AWS 账户](https://portal.aws.amazon.com/gp/aws/developer/registration/index.html)。
- 使用适当的凭证安装并配置了 [AWS CLI](https://aws.amazon.com/cli/)。
- Python 3.9 或更高版本。
- [Boto3](https://boto3.amazonaws.com/v1/documentation/api/latest/index.html)（适用于 Python 的 AWS 开发工具包）已安装：`pip install boto3`。
- AWS Identity and Access Management (IAM) 权限：“bedrock:InvokeModel”和“bedrock:InvokeModelWithResponseStream”。

以下是使用适用于 Python 的 AWS 开发工具包 (Boto3) 的简单示例：
```
import boto3
import json

# Create a Bedrock Runtime client
bedrock_runtime = boto3.client(
    service_name="bedrock-runtime",
    region_name="us-east-1"
)

# Invoke Claude Fable 5.2
response = bedrock_runtime.invoke_model(
    modelId="global.anthropic.claude-fable-5-2",
    contentType="application/json",
    accept="application/json",
    body=json.dumps({
        "anthropic_version": "bedrock-2023-05-31",
        "max_tokens": 4096,
        "messages": [
            {
                "role": "user",
                "content": "An S3 bucket serves 40 TB/month egress. Estimate the monthly egress cost at $0.09/GB, and state one architecture change, using AWS services, to cut it. Show the calculation, keep it under 120 words."
            }
        ]
    })
)

result = json.loads(response["body"].read())

# Fable 5.2 is a reasoning model: the response may include a thinking block
# before the text block, so select the text block rather than a fixed index.
print(next(b["text"] for b in result["content"] if b["type"] == "text"))
```

## 使用 Claude Code 中的 claude-api 技能迁移到 Claude Fable 5.2

对于已经在 Amazon Bedrock 上运行 Claude 模型的团队，Claude Code 中的 claude-api 技能可帮助您升级到 Fable 5.2。

claude-api 技能是内置于 [Claude Code](https://code.claude.com/docs) 中的开源技能，它捕获使 Claude API 代码正常运行的详细信息。它涵盖了哪些代理模式适合给定的作业、模型代之间哪些参数发生变化以及何时应用提示缓存。随着 Anthropic SDK 的发展，它始终保持最新状态：当发布新模型或 API 获得某个功能时，该技能已经知道了。

### 该技能对神鬼寓言 5.2 迁移有何作用

当您要求 Claude Code 将您的代码库升级到《神鬼寓言 5.2》时，该技能会审查您的代码并引导您完成：

- **更新模型参考** 在应用程序代码中将模型 ID 交换为 Fable 5.2 ID。
- **调整思维设置** 将手动思维配置转变为适合新模型的适应性思维。
- **清理过时的参数**删除不再适用的已弃用的测试标头、参数和设置。
- **建议工作水平** 根据您的用例推荐正确的内联“output_config.effort”设置。

该技能还可以检测您的部署平台，包括 Amazon Bedrock、AWS 上的 Claude Platform 和其他环境，并相应地调整模型 ID 格式和功能配置。例如，它使用 Amazon Bedrock 结构化模型 ID 格式 (`global.anthropic.claude-fable-5-2`)。

### 如何使用它

在Claude Code中，直接运行迁移：

`/claude-api 迁移`

这将扫描您的工作目录（或您确认的子目录或特定文件列表）并在单个引导过程中应用迁移更改。您还可以通过告诉 Claude Code 以对话方式调用它：

- *“将我升级到 Claude Fable 5.2”* Claude 检查您的代码并逐步完成必要的更改。
- *“提高我的缓存命中率”*该技能应用了许多开发人员错过的提示缓存规则，有助于降低Bedrock上的成本。
- *“为我的代理添加上下文压缩”* 它会引导您了解长期运行的 Fable 5.2 会话的压缩原语和代理模式。

claude-api 技能在 Claude Code 中可用，并且还捆绑到 CodeRabbit、JetBrains IDE（包括 Junie）、Resolve AI 和 Warp 中。它在 GitHub 上的 [anthropics/skills](https://github.com/anthropics/skills/tree/main/skills/claude-api) 上开源，因此任何编码代理都可以集成它。
