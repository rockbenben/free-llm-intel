# Cohere Rerank 3.5 现已通过 Rerank API 在 Amazon Bedrock 中可用

我们很高兴地宣布，[Cohere](https://aws.amazon.com/bedrock/cohere/) 先进的重排序模型 Rerank 3.5 现已通过我们在 Amazon Bedrock 中推出的全新 [Rerank API](https://docs.aws.amazon.com/bedrock/latest/userguide/rerank.html) 提供。这一强大的重排序模型让 AWS 客户能够显著提升搜索相关性与内容排序能力。该模型同样面向 Amazon Bedrock Knowledge Base 用户开放。通过在 Amazon Bedrock 中引入 Cohere 的 Rerank 3.5，我们让企业级搜索技术更容易获得，并使各类组织能够以最少的基础设施管理工作来增强其信息检索系统。

本文将讨论为什么需要重排序（reranking）、Cohere 的 Rerank 3.5 具备哪些能力，以及如何在 Amazon Bedrock 上开始使用它。

## 面向高级检索的重排序

重排序是对 [Retrieval Augmented Generation（RAG）](https://aws.amazon.com/what-is/retrieval-augmented-generation/) 系统的一项重要增强，它新增了一层精细的第二阶段分析，把搜索结果的相关性提升到传统向量搜索的水平之上。与依赖预先算好的静态向量的 embedding 模型不同，reranker 会在查询时动态分析文档相关性，从而实现更细腻、更贴合上下文的匹配。这一能力让 RAG 系统能够在广域文档召回与精确上下文选择之间取得有效平衡，最终使语言模型的输出更准确、更可靠，同时降低出现幻觉的可能性。

现有搜索系统通过提供更具上下文相关性的结果，从重排序技术中获得显著收益，而这些结果直接影响用户满意度与业务成果。与传统关键词匹配或基础向量搜索不同，重排序会执行一次智能的第二遍分析，综合考虑语义含义、用户意图与业务规则等多重因素，以优化搜索结果的排序。具体到电商领域，重排序通过理解搜索查询与商品属性之间微妙的关系，帮助把最相关的商品呈现出来，同时还会纳入转化率、库存水平等关键业务指标。这种高级的相关性优化带来更好的商品发现、更高的转化率，以及数字商务平台上更高的客户满意度，使重排序成为任何现代企业搜索基础设施的必备组件。

## Cohere Rerank 3.5 简介

Cohere 的 Rerank 3.5 旨在增强搜索与 RAG 系统。这一智能的 cross-encoding 模型以查询和一组可能相关的文档作为输入，然后按与查询的语义相似度排序后返回文档。Cohere Rerank 3.5 擅长理解需要推理的复杂信息，能够理解企业数据与用户问题背后的含义。它可以跨 100 多种语言（包括阿拉伯语、中文、英语、法语、德语、印地语、日语、韩语、葡萄牙语、俄语和西班牙语）理解并分析企业数据与用户问题，这使其对金融、医疗、酒店与旅游业、能源、政府以及制造业等领域的全球化组织尤为有价值。

Cohere Rerank 3.5 的关键优势之一是易于实施。只需在 Amazon Bedrock 中发起一次 [Rerank API](https://docs.aws.amazon.com/bedrock/latest/userguide/rerank.html) 调用，你就可以把 Rerank 大规模集成到现有系统中，无论系统是基于关键词还是基于语义。在标准文本检索基准上，重排序能严格提升第一阶段检索的效果。

## 开始使用 Cohere Rerank 3.5

要开始通过 Rerank API 和 Amazon Bedrock Knowledge Bases 使用 Cohere Rerank 3.5，请打开 [Amazon Bedrock 控制台](https://signin.aws.amazon.com/signup?request_type=register)，点击左侧窗格中的 **Model Access**。依次点击 **Modify Access**、选中 Cohere Rerank 3.5、点击 Next 并提交。

**开始使用 Amazon Bedrock Rerank API**

由 Amazon Bedrock Rerank API 驱动的 Cohere Rerank 3.5 模型，让你可以依据输入文档与用户查询之间的语义相关性直接对其重排序——无需预先配置知识库。这种灵活性使其成为适用于多种用例的强大工具。

首先，导入必要的库并初始化 Boto3 客户端，把环境搭建起来：

```
import boto3
import json
region = boto3.Session().region_name

bedrock_agent_runtime = boto3.client('bedrock-agent-runtime',region_name=region)

modelId = "cohere.rerank-v3-5:0"
model_package_arn = f"arn:aws:bedrock:{region}::foundation-model/{modelId}"
```

接下来定义一个主函数，它根据用户查询计算相关性分数，从而对文本文档列表重新排序：

```
def rerank_text(text_query, text_sources, num_results, model_package_arn):
    response = bedrock_agent_runtime.rerank(
        queries=[
            {
                "type": "TEXT",
                "textQuery": {
                    "text": text_query
                }
            }
        ],
        sources=text_sources,
        rerankingConfiguration={
            "type": "BEDROCK_RERANKING_MODEL",
            "bedrockRerankingConfiguration": {
                "numberOfResults": num_results,
                "modelConfiguration": {
                    "modelArn": model_package_arn,
                }
            }
        }
    )
    return response['results']
```

例如，设想这样一个场景：你需要从多语言数据集中找出与退货相关的邮件。下面的示例演示了这一过程：

```
example_query = "What emails have been about returning items?"

documents = [
    "Hola, llevo una hora intentando acceder a mi cuenta y sigue diciendo que mi contraseña es incorrecta. ¿Puede ayudarme, por favor?",
    "Hi, I recently purchased a product from your website but I never received a confirmation email. Can you please look into this for me?",
    "مرحبًا، لدي سؤال حول سياسة إرجاع هذا المنتج. لقد اشتريته قبل بضعة أسابيع وهو معيب",
    "Good morning, I have been trying to reach your customer support team for the past week but I keep getting a busy signal. Can you please help me?",
    "Hallo, ich habe eine Frage zu meiner letzten Bestellung. Ich habe den falschen Artikel erhalten und muss ihn zurückschicken.",
    "Hello, I have been trying to reach your customer support team for the past hour but I keep getting a busy signal. Can you please help me?",
    "Hi, I have a question about the return policy for this product. I purchased it a few weeks ago and it is defective.",
    "早上好，关于我最近的订单，我有一个问题。我收到了错误的商品",
    "Hello, I have a question about the return policy for this product. I purchased it a few weeks ago and it is defective."
]
```

现在准备将要传入 `rerank_text()` 函数的文本源列表：

```
text_sources = []
for text in documents:
    text_sources.append({
        "type": "INLINE",
        "inlineDocumentSource": {
            "type": "TEXT",
            "textDocument": {
                "text": text,
            }
        }
    })
```

然后，指定用户查询、文本资源、期望返回的排名靠前结果数量以及模型 ARN，即可调用 `rerank_text()`：

```
response = rerank_text(example_query, text_sources, 3, model_package_arn)
print(response)
```

针对该查询，Amazon Bedrock Rerank API 配合 Cohere Rerank 3.5 生成的输出为：

```
[{'index': 4, 'relevanceScore': 0.1122397780418396},
 {'index': 8, 'relevanceScore': 0.07777658104896545},
 {'index': 2, 'relevanceScore': 0.0770234540104866}]
```

API 提供的相关性分数被归一化到 [0, 1] 区间，分数越高表示与查询的相关性越高。这里文档列表中的第 5 项最相关。（德文原句译为英文：Hello, I have a question about my last order. I received the wrong item and need to return it.）

你也可以完成以下步骤，开始将 Cohere Rerank 3.5 与 [Amazon Bedrock Knowledge Bases](https://aws.amazon.com/bedrock/knowledge-bases/) 配合使用：

- 在 Amazon Bedrock 控制台中，于导航窗格的 **Builder tools** 下选择 **Knowledge bases**。
- 选择 **Create knowledge base**。
- 填写知识库详情，例如名称、权限和数据源。
![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/11/26/Screenshot-2024-11-26-at-2.13.27 PM.png)

- 要配置数据源，请指定数据所在的位置。
- 选择一个 embedding 模型把数据转换为向量 embedding，并让 Amazon Bedrock 在你的账户中创建向量存储来存放向量数据。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/11/26/Screenshot-2024-11-26-at-2.10.32 PM.png)

选择该选项时（仅在 Amazon Bedrock 控制台中提供），Amazon Bedrock 会在你的账户中（默认）于 [Amazon OpenSearch Serverless](https://aws.amazon.com/opensearch-service/features/serverless/) 创建向量索引，从而无需你自行管理任何内容。

- 检查设置并创建知识库。
- 在 Amazon Bedrock 控制台中选择你的知识库，然后选择 **Test knowledge base**。
![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/11/22/Screenshot-2024-11-22-at-2.54.22 PM.png)
- 点击图标展开用于测试知识库的额外配置选项。
- 选择你的模型（本文中为 Cohere Rerank 3.5），然后选择 **Apply**。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/11/22/Screenshot-2024-11-15-at-2.27.35 PM.png)

配置窗格会显示新增的 **Reranking** 区域菜单，其中包含额外的配置选项。重排序后的源分块数量决定返回多少个相关性最高的分块。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2024/11/22/Screenshot-2024-11-22-at-2.53.03 PM.png)
