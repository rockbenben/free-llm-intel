# 借助 Amazon Bedrock 提升你的问题解决与战略思维能力

各行各业的组织正在利用[基础模型](https://aws.amazon.com/what-is/foundation-models/)（FM）和[大型语言模型](https://aws.amazon.com/what-is/large-language-model/)（LLM）的力量构建[生成式 AI](https://aws.amazon.com/generative-ai/) 应用，以提供全新的客户体验、提升员工生产力并推动创新。

[Amazon Bedrock](https://aws.amazon.com/bedrock/) 是一项全托管服务，提供来自领先 AI 公司的多种高性能基础模型，是构建和扩展基于 FM 的生成式 AI 应用的最简便方式。

Amazon Bedrock 上一些使用最广泛、最成功的生成式 AI 用例包括文档摘要、问答、语言翻译，以及理解并生成全新的多模态内容。

## 业务挑战

问题解决、逻辑推理和批判性思维是取得商业成功、加速决策和促进创新的关键能力。尽管战略顾问已经磨砺了这些技能，但许多知识工作者由于培训不足、缺乏合适工具而并不具备这些能力。培养这些技能不仅能提升个人生产力，还能为组织带来显著收益。

## 业务用例

在本文中，我们希望展示 Amazon Bedrock 上的一些额外生成式 AI 用例。我们将说明如何把[Amazon Bedrock 中的 Anthropic Claude 3.5 Sonnet](https://aws.amazon.com/bedrock/claude/) 用于各种与业务相关的认知任务，例如问题解决、批判性思维和创意构思——以帮助增强人类的思考能力，改善知识工作者的决策，从而加速创新。为此，我们使用了管理咨询界广泛采用的若干框架和工具，例如[相互独立、完全穷尽](https://en.wikipedia.org/wiki/MECE_principle)（MECE）、[优势、劣势、机会、威胁（SWOT）分析](https://en.wikipedia.org/wiki/SWOT_analysis)、[issue tree](https://en.wikipedia.org/wiki/Issue_tree#:~:text=Issue%20trees%20are%20useful%20in,whole%20picture%20of%20a%20problem.)、[价值链分析](https://en.wikipedia.org/wiki/Value_chain) 和[价值驱动因素树分析](https://en.wikipedia.org/wiki/Value_tree_analysis)。

## 解决方案概述

为演示这五个用例，我们使用了[Amazon Bedrock playground](https://docs.aws.amazon.com/bedrock/latest/userguide/playgrounds.html) 搭配 Anthropic 的 Claude Sonnet 3.5 LLM。在必要之处，除文本 prompt 外，我们还使用了 Anthropic Claude Sonnet 3.5 的图生文能力，以提高所生成响应的准确性。

以下各节将说明这五个用例，以及用于馈给 LLM 的 prompt 和图像、生成的响应。为提高 LLM 生成的文本响应的可解释性，我们在必要之处补充了额外的图表来配合每个 LLM 响应（例如与 LLM 生成响应对应的树状图）。

以下各节说明每个用例的解决方案流程。

### MECE

MECE 是一个广泛用于业务问题解决的框架。MECE 有助于把问题分解为定义清晰、互不重叠的部分（相互独立），但当所有部分合在一起时，它们又足够全面和穷尽，能够覆盖问题的整体（完全穷尽）。

在本例中，我们希望让 LLM 按照 MECE 原则整理一份餐厅菜单上的菜品（此处为各种炒饭选项），以此演示 MECE 原则的使用。

我们向 LLM 提供了以下 prompt：

> 以下是一些炒饭选项：鸡肉炒饭、蔬菜炒饭、羊肉炒饭、牛肉炒饭、鸡蛋炒饭、虾仁炒饭、鱿鱼炒饭
>         能否请你用 MECE（相互独立、完全穷尽）原则来排列它们？

### issue tree

issue tree 也称为逻辑树或问题解决树，是一种战略分析工具，用于把复杂问题拆解为其组成要素。这一层级化框架通过以下方式促进系统化的问题解决：

- 把主要问题分解为离散、可管理的子组件
- 以结构化、自上而下的方式组织这些要素
- 通过应用 MECE 原则实现全面覆盖

issue tree 提供的可视化呈现使利益相关者能够：

- 识别关键驱动因素和根本原因
- 确定需要进一步调查或资源投入的领域的优先次序
- 在聚焦具体方面的同时保持对问题的整体把握

采用这一方法，组织可以改进决策流程、简化战略规划，并提升问题解决工作的效率。

为演示 LLM 使用 issue tree 解决问题的能力，我们虚构了一家公司 AnyCompany Tile Factory，其利润下降了 30%。AnyCompany 的管理层希望用 issue tree 找出主要问题和次级问题，然后用它分析利润下滑的原因。为给 LLM 提供更多背景，我们提供了以下带有 issue tree 骨架结构的图。

为了向 LLM 提问，我们附上了前一张图，并使用以下文字：

### SWOT

SWOT 分析是一种战略管理工具，可用于评估一个组织、行业或项目的优势、劣势、机会和威胁。SWOT 通过识别可能影响成功的内部因素（优势和劣势）与外部因素（机会和威胁）来辅助决策和战略制定。随后，管理层可以据此制定前进策略：利用优势、弥补劣势、把握机会、缓释威胁。

在本例中，我们让 LLM 根据所提供的 SWOT 分析图，为澳大利亚高等教育行业制定前进策略。我们要求它识别该行业的四个关键战略主题，确保其方法利用固有优势、弥补劣势、把握机会并缓释威胁，这些都来自 SWOT 图中所示的内容。我们还要求 LLM 列出该行业在每个战略主题下需要开展的关键活动。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/02/21/ML-18106-P011.png)

为了向 LLM 提问，我们附上了前一张图，并使用以下文字：

> 针对澳大利亚高等教育行业的 SWOT 分析，我们希望借助你的专业知识帮助制定前进策略。请识别该行业的 4 个关键战略主题，确保你的方法利用优势、弥补劣势、把握机会、缓释 SWOT 图中所识别的威胁。在每个战略主题下，列出需要开展的关键活动。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/02/21/ML-18106-P012.png)

我们得到 LLM 的以下响应，其中包括四个战略主题和需要开展的活动：

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/02/21/ML-18106-P013.png)

### 价值链分析

价值链分析是一种战略管理工具，可帮助组织评估其价值链中的每一项价值创造活动（如进货物流或运营），以识别建立竞争优势、降低成本和提升效率的机会。

在本例中，我们希望 LLM 为 AnyCompany Tile Factory 执行价值链分析，并提出提高盈利能力的建议。作为给 LLM 的补充背景，我们提供了以下 AnyCompany 的端到端价值链图。

### 价值驱动因素树

价值驱动因素树是一种框架，用于梳理影响组织价值或营收、利润、客户满意度等特定指标的关键因素。该框架把高层业务目标和驱动因素分解为更小、可衡量的组成部分。通过这种方式，它揭示这些要素之间的因果关系，帮助洞察各种因素如何影响整体业务表现。价值驱动因素树被用于业务绩效改进、战略规划和决策。

在本例中，我们希望 LLM 为 AnyCompany Tile Factory 定义一棵价值驱动因素树，以便管理团队分析导致盈利偏低的营收、成本和效率驱动因素，并采取行动加以整改。

为了向 LLM 提问，我们使用了以下内容：

> AnyCompany Tile Factory 的利润下降了 30%。请帮助制定一棵价值驱动因素树，供 AnyCompany 管理层分析问题并采取整改行动。请考虑营收、成本和效率方面的驱动因素。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/02/21/ML-18106-P020.png)

## 结论

问题解决、批判性思维和逻辑推理是利用大脑为问题找到解决方案或达成最终目标的认知过程，尤其是在答案并非一目了然的情况下。正如本文示例所示，Amazon Bedrock 上的 Anthropic Claude 3.5 Sonnet 等 LLM 可用于提升你的认知能力，特别是在问题解决、创造性思维和创意构思方面。这反过来将有助于改善团队协作、缩短决策时间并推动创新。我们使用的示例较为基础，旨在展示可能性。要改善复杂问题解决用例中的 LLM 响应，我们建议使用与问题相关的 RAG 来源、chain-of-thought prompting，并通过 prompt engineering 提供额外的、针对具体问题的背景信息。

我们鼓励你通过 [Amazon Bedrock chat playground](https://docs.aws.amazon.com/bedrock/latest/userguide/playgrounds.html#chat-playground) 开始探索这些能力，它是 [AWS Management Console](https://aws.amazon.com/console/) 中的一个工具，提供可视化界面，可试验在不同 LLM 上运行推理并使用不同配置。
