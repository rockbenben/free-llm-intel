# Gemma 3 27B 模型现已登陆 Amazon Bedrock Marketplace 和 Amazon SageMaker JumpStart

我们很高兴宣布，Gemma 3 27B Instruct 模型现已通过 [Amazon Bedrock Marketplace](https://aws.amazon.com/bedrock/marketplace/) 和 [Amazon SageMaker JumpStart](https://aws.amazon.com/sagemaker-ai/jumpstart/) 提供。借助此次发布，开发者和数据科学家现在可以部署 Gemma 3——一个 270 亿参数的语言模型——以及其专门的指令遵循版本，从而加速在 AWS 上构建、试验和规模化部署生成式 AI 方案。

本文介绍如何在 Amazon Bedrock Marketplace 和 SageMaker JumpStart 上开始使用 Gemma 3 27B Instruct，以及如何在你的应用中使用该模型强大的指令遵循能力。

## Gemma 3 27B 概览

Gemma 3 27B 是 Google 推出的一款高性能、开放权重、多模态语言模型，旨在高效处理文本和图像输入，并具备上下文理解能力。它引入了重新设计的注意力架构、增强的多语言支持和扩展的上下文能力。凭借优化的内存占用和对长输入序列的支持，它非常适合复杂推理任务、长篇交互和视觉-语言应用。这些模型拥有 270 亿参数，并在最多 6 万亿 token 的文本上训练，专为需要高级推理、多语言能力和指令遵循的任务而优化。据 Google 介绍，Gemma3 27B Instruct 模型非常适合希望构建聊天机器人、虚拟助手和自动化内容生成工具等生成式 AI 应用的开发者、研究人员和企业。以下是它的关键特性：

- **多模态输入** – 处理文本、图像和短视频，实现跨模态的统一推理
- **长上下文支持 ** – 最多可处理 128,000 个 token，无缝处理长文档、对话和多媒体转录文本
- **多语言支持** – 开箱即用支持 35 种以上语言，预训练阶段总共接触过 140 多种语言
- **函数调用** – 通过面向 API 的自然语言接口，便于构建 agentic 工作流
- **内存高效的推理** – 提供架构更新，减少 KV-cache 占用，并引入 QK-norm 以输出更快、更准确

据 Google 描述，Gemma3 的主要用例包括：

- **问答与摘要** – 处理和压缩长文档或文章
- **视觉理解** – 图像描述、物体识别、视觉问答和文档理解
- **多语言应用** – 构建覆盖 140 多种语言的 AI 助手和工具
- **文档处理** – 分析多页文章或从长篇文本中提取信息
- **自动化工作流** – 使用函数调用创建可与其他系统交互的 AI agent

在 AWS 中部署 Gemma 3 27B 主要有两种方法：第一种方法是使用 [Amazon Bedrock Marketplace](https://aws.amazon.com/bedrock/marketplace/)，它提供了一条简化途径来访问 Amazon Bedrock API（Invoke 和 Converse）以及 [Amazon Bedrock Knowledge Bases](https://aws.amazon.com/bedrock/knowledge-bases/)、[Amazon Bedrock Agents](https://aws.amazon.com/bedrock/agents/)、[Amazon Bedrock Flows](https://aws.amazon.com/bedrock/flows/)、[Amazon Bedrock Guardrails](https://aws.amazon.com/bedrock/guardrails/) 等工具和模型评估功能。第二种方法是使用 SageMaker JumpStart——一个包含基础模型（FM）、内置算法和预构建机器学习方案的机器学习（ML）枢纽。你可以使用 [Amazon SageMaker](https://aws.amazon.com/sagemaker/) 控制台或 SDK 部署预训练模型。

## 在 Amazon Bedrock Marketplace 上部署 Gemma 3 27B Instruct

Amazon Bedrock Marketplace 提供对 150 多个专用基础模型的访问，其中包括 Gemma 3 27B Instruct。

### 先决条件

要使用 Amazon Bedrock Marketplace 试用 Gemma 3 27B Instruct 模型，你需要：

- 一个将承载你所有 AWS 资源的 AWS 账户
- 对用于托管大型语言模型（LLM）的加速实例（GPU）的访问权限

### 部署模型

要使用 **Amazon Bedrock Marketplace** 部署模型，请完成以下步骤：

- 在 Amazon Bedrock 控制台的导航窗格中，在 **Foundation models** 下选择 **Model catalog**。
- 将提供商筛选为 **Gemma**，并选择 **Gemma 3 27B Instruct**。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/05/28/ML-18880-image-1.jpeg)

关于 Gemma3 的特性、费用和设置说明，可以在其模型概览页面上找到。该资源包含集成示例、API 文档和编程示例。该模型擅长各种文本生成和图像理解任务，包括问答、摘要和推理。你还可以查看部署指南和许可证详情，开始将 Gemma3 应用到你的项目中。

- 查看模型详情、定价和部署指南，然后选择 **Deploy** 开始部署流程。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/05/28/ML-18880-image-2.jpeg)

- 在 **Endpoint name** 中，输入 endpoint 名称（1–50 个字母数字字符），或保留预先填充的默认名称。
- 在 **Number of instances** 中，输入实例数量（1–100）。
- 选择你偏好的实例类型，像 ml.g5.48xlarge 这样由 GPU 驱动的选项尤其适合高效运行 Gemma 3。

虽然默认配置通常足以满足基本需求，但你也可以自定义安全特性，例如虚拟私有云（VPC）网络、基于角色的权限和数据加密。在生产环境中，为符合组织的安全协议，这些高级设置可能需要调整。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/05/28/ML-18880-image-3.jpeg)

部署 Gemma 3 之前，请确认你的 AWS 账户对 ml.g5.48xlarge 实例有足够的配额。配额设置为 0 会导致部署失败，如下图所示。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/05/28/ML-18880-image-4.jpeg)

如需申请提高配额，打开 [AWS Service Quotas 控制台](https://us-east-1.console.aws.amazon.com/servicequotas/home?region=us-east-1)并搜索 SageMaker。找到 endpoint 用途的 ml.g5.48xlarge，选择 **Request quota increase**，然后指定你需要的限额值。

- 部署进行期间，你可以在导航窗格中选择 **Managed deployments** 来监控部署状态。
- 部署完成后，你可以选择该托管部署并选择 **Open in playground**，直接在 Amazon Bedrock playground 中测试 Gemma 3 的能力。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/05/28/ML-18880-image-5.jpeg)

现在你可以使用 playground 与 Gemma 3 交互。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/05/28/ML-18880-image-6.jpeg)

有关使用 Amazon Bedrock API 调用模型的详细步骤和示例代码，请参见[使用 API 提交 prompt 并生成响应](https://docs.aws.amazon.com/bedrock/latest/userguide/inference-api.html)以及以下代码：

```
import boto3
bedrock_runtime = boto3.client("bedrock-runtime")
endpoint_arn = "arn:aws:sagemaker:us-east-2:061519324070:endpoint/endpoint-quick-start-3t7kp"
response = bedrock_runtime.converse(
    modelId=endpoint_arn,
    messages=[
        {
            "role": "user",
            "content": [{"text": "What is Amazon doing in the field of generative AI?"}]
        }
    ],
    inferenceConfig={
        "maxTokens": 256,
        "temperature": 0.1,
        "topP": 0.999
    }
)
print(response["output"]["message"]["content"][0]["text"])
```

## 使用 SageMaker JumpStart 部署 Gemma 3 27B Instruct

SageMaker JumpStart 提供对种类丰富的公开基础模型的访问。这些预训练模型是强大的起点，可以深度定制以应对特定用例。你可以使用最先进的模型架构——例如语言模型、计算机视觉模型等——而无需从头构建。

借助 SageMaker JumpStart，你可以在安全的环境中部署模型。模型可以预配在专用的 SageMaker 推理实例上，并隔离在你的 VPC 内。部署基础模型后，你还可以利用 [Amazon SageMaker AI](https://aws.amazon.com/sagemaker-ai/) 的丰富能力进一步定制和微调，包括用于部署模型的 SageMaker 推理和用于提升可观测性的容器日志。借助 SageMaker AI，你可以简化整个模型部署流程。

使用 SageMaker JumpStart 部署 Gemma 3 模型有两种方式：

- 通过易用的 SageMaker JumpStart 界面
- 使用 SageMaker Python SDK 进行编程式部署

我们会考察这两种部署方法，帮助你判断哪种方式最符合你的需求。

要在 SageMaker JumpStart 中试用 Gemma 3 27B Instruct 模型，你需要以下先决条件：

### 使用 SageMaker Python SDK 以编程方式部署模型

要使用 SageMaker Python SDK 配合 Gemma 3，请先确认已安装该 SDK，并正确设置 AWS 权限和环境。以下代码示例展示如何以编程方式部署 Gemma 3 并运行推理：

```
import sagemaker
from sagemaker.jumpstart.model import JumpStartModel
from sagemaker import Session, image_uris
import boto3
# Initialize SageMaker session
session = sagemaker.Session()
role = sagemaker.get_execution_role()
# Specify model parameters
model_id = "huggingface-vlm-gemma-3-27b-instruct"  # or "huggingface-llm-gemma-2b" for the smaller version
instance_type = "ml.g5.48xlarge"  # Choose appropriate instance based on your needs
# Create and deploy the model
model = JumpStartModel(
    model_id=model_id,
    role=role,
    instance_type=instance_type,
    model_version="*",  # Latest version
)
# Deploy the model
predictor = model.deploy(
    initial_instance_count=1,
    accept_eula=True  # Required for deploying foundation models
)
```

## 使用 SageMaker API 运行推理

Gemma 3 模型已成功部署为 SageMaker endpoint，现在你可以开始做预测了。SageMaker SDK 提供了一种直接的方式与你的模型 endpoint 交互以执行推理任务。以下代码演示如何格式化输入并向 endpoint 发起 API 调用。该代码同时负责向模型发送请求和处理其响应，让你能轻松将 Gemma 3 集成到应用中。

```
import json
import boto3
# Initialize AWS session (ensure your AWS credentials are configured)
session = boto3.Session()
sagemaker_runtime = session.client("sagemaker-runtime")
# Define the SageMaker endpoint name (replace with your deployed endpoint name)
endpoint_name = "hf-vlm-gemma-3-27b-instruct-2025-05-07-18-09-16-221"

payload = {
    "inputs": "What is Amazon doing in the field of generative AI?",
    "parameters": {
        "max_new_tokens": 256,
        "temperature": 0.1,
        "top_p": 0.9,
        "return_full_text": False
    }
}

# Run inference
try:
    response = sagemaker_runtime.invoke_endpoint(
        EndpointName=endpoint_name,
        ContentType="application/json",
        Body=json.dumps(payload)
    )
    # Parse the response
    result = json.loads(response["Body"].read().decode("utf-8"))
    generated_text = result[0]["generated_text"].strip()
    print("Generated Response:")
    print(generated_text)
except Exception as e:
    print(f"Error during inference: {e}")
```

## 清理

为避免在探索 Gemma3 27B Instruct 模型期间使用的 AWS 资源持续产生费用，清理已部署的 endpoint 和相关资源很重要。请完成以下步骤：

- 删除 SageMaker endpoint：在 SageMaker 控制台的导航窗格中，在 **Inference** 下选择 **Endpoints**。选择与 Gemma3 27B Instruct 模型关联的 endpoint（例如 `gemma3-27b-instruct-endpoint`）。选择 **Delete** 并确认删除。这会停止该 endpoint 并阻止进一步的计算费用。
- 删除 SageMaker 模型（如适用）：
- 在 SageMaker 控制台的 **Inference** 下选择 **Models**。
- 选择与你的 endpoint 关联的模型，然后选择 **Delete**。
- 核实 Amazon Bedrock Marketplace 资源：
- 在 Amazon Bedrock 控制台的导航窗格中，选择 **Model catalog**。
- 确认通过 Amazon Bedrock Marketplace 部署的 Gemma3 27B Instruct 模型没有额外的 endpoint 在运行。

实验结束后请务必核实所有 endpoint 都已删除，以优化成本。有关管理资源的更多指导，请参阅 [Amazon SageMaker 文档](https://docs.aws.amazon.com/sagemaker/)。
