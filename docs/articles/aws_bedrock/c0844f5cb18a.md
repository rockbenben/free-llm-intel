# 在 Amazon Bedrock Knowledge Base 中使用 Marengo 3.0 进行视频与图像搜索

今天，我们宣布 [TwelveLabs Marengo Embed 3.0](https://www.twelvelabs.io/blog/marengo-3-0) 作为嵌入模型在 Amazon Bedrock Knowledge Bases 中正式可用。

视频和媒体资产在很大程度上仍然无法按语义检索。媒体、体育分析、教育、安全和零售领域的团队需要用自然语言在数小时的视频素材中找到特定片段。一个查询示例是 “show me the penalty kick in the second half”。如今要为视频构建语义搜索，需要把转写服务、帧提取 pipeline、嵌入模型、向量数据库和同步逻辑拼装成一条复杂的 pipeline。

Amazon Bedrock Knowledge Bases 是一项全托管的检索增强生成（RAG）服务，负责存储、摄取、嵌入、重排和检索。它支持视频文件（MP4、MOV）、图像（JPEG、PNG）和音轨，并提供面向 Amazon Simple Storage Service（Amazon S3）、SharePoint、Confluence 等的原生连接器。

Marengo Embed 3.0 是一个多模态嵌入模型，它把视频、音频、图像和文本联合编码到一个紧凑、存储高效的 512 维向量空间。

如今 Marengo Embed 3.0 已作为可选的嵌入模型提供，对视频、音频和图像内容的自然语言搜索成为一种全托管体验。托管知识库（Managed MKB）会自动生成多模态嵌入，把视觉、文本、语音和音频信号捕获为统一的向量表示。

## 操作演练

本演练演示如何使用 Amazon Bedrock 控制台创建一个由 Marengo 3.0 驱动的知识库（KB）。场景中包含一段 10 分钟的 [2022 年 FIFA 世界杯决赛](https://www.youtube.com/watch?v=RgqKdplLIk4&t=16s) 片段。

我们摄取该视频，并针对它运行自然语言查询。

### 前置条件

- 一个有效的 AWS 账户。如果没有，请参阅[创建 AWS 账户](https://aws.amazon.com/resources/create-account/)。
- 在受支持的区域内拥有已启用 TwelveLabs Marengo Embed 3.0 的 Amazon Bedrock 访问权限。详情请参阅 Amazon Bedrock 文档中的[模型访问](https://docs.aws.amazon.com/bedrock/latest/userguide/model-access.html)。
- 一个用于存储视频和图像文件的 Amazon S3 存储桶。
- 针对 Amazon Bedrock 和 Amazon S3 的 AWS Identity and Access Management（IAM）权限。

### 1. 准备媒体资产

首先，把视频文件上传到 Amazon S3 存储桶。无需任何预处理，因为 Managed MKB 会在内部处理分段、帧采样和转写。

![包含已上传足球视频文件的 Amazon S3 存储桶](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/09/10/ML-21835-1.png)

图 1：包含为知识库摄取而上传的足球视频文件的 Amazon S3 存储桶

### 2. 创建托管知识库

在 Amazon Bedrock 控制台中，进入 **Knowledge Bases**，然后选择 **Create Managed KB**。

![Amazon Bedrock Knowledge Bases 控制台及 Create managed KB 按钮](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/09/10/ML-21835-2.png)

图 2：Amazon Bedrock Knowledge Bases 控制台及 Create managed KB 按钮

展开 **Additional Configuration** 面板，在 **Embeddings model** 中选择 **Amazon Bedrock embeddings model**。默认选中的是 **Amazon Titan Text**。选择铅笔图标即可更改模型选择。

![知识库创建表单，包含名称、服务角色和嵌入模型字段](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/09/10/ML-21835-3.png)

图 3：知识库创建表单，展示知识库名称、服务角色和嵌入模型配置

如下一图所示，选择 **TwelveLabs/Marengo Embed 3.0**。

![模型选择对话框，已选择 TwelveLabs Marengo Embed 3.0 作为嵌入模型](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/09/10/ML-21835-4.png)

图 4：模型选择对话框，已将 TwelveLabs Marengo Embed 3.0 选为嵌入模型

接下来，展开 **Data source** 面板，把 **Data source type** 选为 **Amazon S3**，并配置包含视频资产的存储桶的 S3 URI。

![数据源面板，已选择 Amazon S3 并填入 S3 URI](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/09/10/ML-21835-5.png)

图 5：数据源配置面板，已选择 Amazon S3 并指定 S3 URI

在 **Advanced configurations** 下的 **Audio/video segmentation configuration** 部分，你可以配置音频与视频的分段时长。两种模态的默认值都是 4 秒。

![高级配置面板，展示音频与视频分段设置](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/09/10/ML-21835-6.png)

图 6：高级配置选项，包含音频与视频分段设置

保持高级参数不变，选择页面右下角的 **Create Knowledge Base**。

### 3. 同步并摄取数据

知识库创建完成后，选择 **Sync** 开始摄取。Managed MKB 会自动提取帧、转写音频、为每个分段生成 Marengo Embed 3.0 嵌入，并把向量写入索引。

![同步历史面板，展示已完成的某一数据摄取作业](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/09/10/ML-21835-7.png)

图 7：同步历史面板，展示一个已完成的数据摄取作业

### 4. 运行语义搜索

你可以使用 **Test** 功能，无需离开控制台即可测试知识库。配置要检索的源 chunk 数量、应用元数据过滤器，并运行诸如 “show me the penalty kicks from this soccer match.” 的查询。

响应会返回排序后的结果及其元数据，包括 chunk 起始时间、chunk 结束时间、源 URI 和嵌入类型，以便你按需提取相关片段。

在本例中，最靠前的结果定位到了尝试主罚点球的那些时刻。

![知识库测试面板，展示排序后的语义搜索结果与视频播放](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/09/10/ML-21835-8.png)

图 8：知识库测试界面，展示语义搜索结果、视频播放与源 chunk 时间线

### 5. 清理

要清理资源，请完成以下步骤：

- 在 Amazon Bedrock 控制台上选择 **Knowledge Bases**。
- 选中你的知识库，记下 IAM 服务角色名称以及 S3 Vector 索引的 Amazon Resource Name（ARN）。
- 选择 **Delete** 并确认。
- 在 IAM 控制台上找到此前创建知识库时创建的角色。
- 选中并删除该角色。
- 在 Amazon S3 控制台上找到你的 S3 存储桶。
- 选中并删除你为本教程上传的文件。

## 结论

随着 Marengo 3.0 在 Amazon Bedrock Knowledge Bases 中正式可用，你现在可以通过自然语言搜索释放视频、音频和图像资产的全部价值，而无需构建或管理复杂的基础设施。指向数据源、同步，然后搜索。

其业务影响横跨多个行业：

- **体育分析：**在整个赛季的素材中查找特定的战术配合、阵型或球员动作。
- **媒体与娱乐：**媒体资产管理，对媒体档案或流媒体服务内容进行语义搜索。
- **安全与安保：**在监控摄像头素材中搜索特定事件或活动。
- **教育与培训：**按概念（而不仅是关键词）定位讲座片段。
- **零售：**在产品演示视频中搜索功能展示。

### 可用性与定价

配备 Marengo Embed 3.0 的 Amazon Bedrock Managed Knowledge Bases 在美国东部（弗吉尼亚北部）区域（us-east-1）和欧洲西部（爱尔兰）区域（eu-west-1）可用。受支持模型与区域的完整列表，请参阅 [Amazon Bedrock 中按 AWS 区域提供支持的模型](https://docs.aws.amazon.com/bedrock/latest/userguide/models-regions.html)。

使用 Amazon Bedrock 的 Managed Knowledge Bases，你只需为存储和检索付费。使用 Marengo Embed 3.0 生成嵌入按标准的 Amazon [Bedrock 模型调用费率](https://aws.amazon.com/bedrock/pricing/) 计费。

更多信息请参阅[定价文档页面](https://aws.amazon.com/bedrock/pricing/?nc1=h_ls)。
