# Trellix 借助高性价比、性能出色的 Amazon Nova Micro 与 Amazon Nova Lite 模型降低成本、提升速度并增加交付灵活性

*本文与来自 Trellix 的 Martin Holste 合写。*

安全团队正在应对一个不断演变的网络安全威胁宇宙。这些威胁在形态、复杂度和所针对的攻击面上都在扩张。受限于人才与预算，团队往往不得不对要调查的事件排定优先级，从而限制了发现和识别新威胁的能力。Trellix Wise 是一项由 AI 驱动的技术，可让安全团队自动化威胁调查并为事件添加风险评分。借助 Trellix Wise，安全团队现在可以在数秒内完成过去需要多名分析师耗费数小时调查的工作，从而扩大他们能够覆盖的安全事件范围。

[Trellix](https://www.trellix.com/) 是一家领先企业，为全球超过 53,000 家客户提供网络安全领域最广泛的 AI 驱动平台，它于 2022 年由 McAfee Enterprise 与 FireEye 合并而成。该公司全面、开放且原生的 AI 驱动安全平台帮助各类组织构建抵御高级威胁的运营韧性。Trellix Wise 作为 Trellix Security Platform 的一部分提供给客户。本文讨论 Trellix 对 [Amazon Nova](https://aws.amazon.com/ai/generative-ai/nova) 基础模型（FM）的采用与评估。

随着采用范围和使用量的增长，Trellix 团队一直在探索优化 Trellix Wise 调查成本结构的方法。更小、更具成本效益的基础模型看起来很有前景，而 Amazon Nova Micro 凭借其质量与成本脱颖而出，成为一个选项。在早期评估中，Trellix 团队观察到 Amazon Nova Micro 的推理速度提升了三倍，而成本降低了近 100 倍。

Trellix 团队确定了 Amazon Nova Micro 可以补充他们对 Anthropic 的 Claude Sonnet 的使用、实现更低成本与更高整体速度的领域。此外，Trellix 的专业服务团队发现 Amazon Nova Lite 是用于代码生成与代码理解的强模型，目前正使用 Amazon Nova Lite 来加快其定制解决方案的交付工作流。

## Trellix Wise：由生成式 AI 驱动的威胁调查，为安全分析师提供协助

Trellix Wise 构建在 Amazon Bedrock 之上，并使用 Anthropic 的 Claude Sonnet 作为其主要模型。该平台使用 Amazon OpenSearch Service 存储从受监控环境中收集的数十亿条安全事件。OpenSearch Service 内置向量数据库能力，因此可以很直接地将 OpenSearch Service 中存储的数据用作 Amazon Bedrock Knowledge Bases 的检索增强生成（RAG）架构中的上下文数据。借助 OpenSearch Service 和 Amazon Bedrock，Trellix Wise 针对每个事件执行其自动化的专有威胁调查步骤。这包括检索分析所需的数据、使用其他自建机器学习（ML）模型的洞察对数据进行分析，以及进行风险评分。这种精细的方法使该服务能够解读复杂的安全数据模式，并就每个事件做出明智的决策。Trellix Wise 调查会为每个事件给出风险评分，并允许分析师深入查看分析结果，以判断是否需要人工跟进。

随着采用规模的扩大，Trellix 一直在评估改善成本与速度的方法。Trellix 团队已确定，调查中并非所有阶段都需要 Claude Sonnet 的准确性，某些阶段可以受益于更快、成本更低但对该目标任务仍然高度准确的模型。这正是 Amazon Nova Micro 帮助改善调查成本结构的地方。

## 使用 Amazon Nova Micro、RAG 与重复推理改善调查成本

威胁调查工作流包含多个步骤，从数据收集到分析，再到为事件分配风险评分。收集阶段会检索与事件相关的信息以供分析。这是通过对 Amazon Bedrock 中的模型发起一次或多次推理调用来实现的。该阶段的优先事项是最大化检索数据的完整性并尽量减少不准确性（幻觉）。Trellix 团队将该阶段确定为工作流中最适合针对速度与成本进行优化的阶段。

Trellix 团队根据他们的测试得出结论：Amazon Nova Micro 提供了两项关键优势。其速度使其能够在与一次 Claude Sonnet 推理相同的时间内处理 3-5 次推理，而其每次推理的成本几乎低 100 倍。Trellix 团队确定，通过运行多次推理，你可以最大化所需数据的覆盖范围，同时仍能降低 30 倍的成本。尽管与更大的模型相比，模型响应的变异性更高，但运行多轮可以获得更完整的响应集。通过专有的 prompt 工程和参考数据强制实施的响应限制约束了响应空间，减少了响应中的幻觉与不准确。

在实施该方法之前，Trellix 团队进行了详细测试，以审查响应的完整性、成本和速度。该团队在其生成式 AI 之旅的早期就意识到，在针对特定用例评估模型时，标准化基准并不够用。他们搭建了一个复刻信息收集工作流的测试框架，并对多个模型进行了详细评估，以在继续推进之前验证该方法的收益。Trellix 观察到的速度与成本收益帮助他们在将新方法投入生产之前验证了收益。该方法目前已在有限的试点环境中部署。作为分阶段投产的一部分，正在开展详细评估。

## 结论

在本文中，我们分享了 Trellix 如何采用并评估 Amazon Nova 模型，从而实现了显著的推理加速和更低的成本。回顾该项目，Trellix 团队认为以下是使他们取得这些成果的关键推动因素：

- 能够获得包括 Amazon Nova Micro 和 Amazon Nova Lite 这类更小但能力很强的模型在内的广泛模型选择，加快了团队轻松实验并适时采用新模型的能力。
- 能够使用预先构建的、纳入了专有数据、流程和策略的用例专用脚手架来约束响应以避免幻觉，降低了幻觉与不准确的风险。
- 能够将数据与基础模型有效集成的数据服务，简化了实现并缩短了新组件的投产时间。

“Amazon Bedrock 让我们在可用的新模型和新方法出现时能轻松评估。将 Amazon Nova Micro 与 Anthropic 的 Claude Sonnet 一起使用，使我们能够快速为客户提供最佳的覆盖范围，并保持最佳的运营成本。”Trellix 工程高级总监 Martin Holste 表示。“在我们继续评估和改进 Trellix Wise 与 Trellix Security Platform 的过程中，Amazon Bedrock 赋予我们的灵活性让我们非常满意。”
