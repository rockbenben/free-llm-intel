# Amazon Nova Act 现已成为 HIPAA 合格服务

医疗与生命科学（HCLS）组织在理赔处理、转诊协调等关键工作流上依赖重复的、手工的、基于浏览器的工作。虽然 agent 式 AI 可以自动化这些工作流，但在可能存在电子受保护健康信息（ePHI）的场景，Health Insurance Portability and Accountability Act（HIPAA）下的合规要求限制了其采用。Amazon Nova Act 现已成为 HIPAA 合格服务，因此你可以部署自主的、基于浏览器的 AI agent，在涉及 ePHI 的情况下自动化复杂的医疗工作流。

本文中你将了解 Nova Act 提供什么、HIPAA 合格资格如何适用于 agent 式 AI，以及如何开始使用。

## **关于 Amazon Nova Act**

[Amazon Nova Act](https://aws.amazon.com/nova/act/) 作为一项 AWS 服务提供，用于构建和管理可靠的 AI agent 机群，以规模化自动化生产环境的 UI 工作流。Nova Act 在浏览器中完成重复的 UI 工作流，并在适当时升级给人工主管。Nova Act 还通过 API 调用、远程[模型控制协议](https://modelcontextprotocol.io/docs/getting-started/intro)（MCP）或 agent 框架（例如 [Strand Agents](https://strandsagents.com/)）与外部工具集成。你可以把自然语言的灵活性与 Python 代码结合起来定义工作流。

Amazon Nova Act 帮助你自动化此前需要人工完成的真实浏览器任务。模型可以导航网站、填写表单、提取信息，并代表你完成多步工作流。对 HCLS 组织来说，这意味着减轻行政负担、加快理赔周转，并让常规流程执行得更一致。

## **为什么 HIPAA 合格资格对 agent 式 AI 很重要**

与只生成文本的模型不同，agent 式 AI 系统会与实时系统交互、访问数据，并执行可能涉及[受保护健康信息（](https://www.ncbi.nlm.nih.gov/books/NBK553131/)PHI）的工作流。在 [AWS 责任共担模型](https://aws.amazon.com/compliance/shared-responsibility-model/)下，我们负责底层基础设施的安全，你仍需负责配置控制措施，以在你的部署中达成 HIPAA 合规。

## **医疗行业用例**

具备 HIPAA 合格资格后，你现在可以在医疗服务提供方与支付方的门户上自动化预约排程、保险验证与事前授权。你可以在支付方网站上查询理赔状态、提交申诉并跟踪报销，无需人工介入。你还可以在提供方之间发送并跟踪转诊，并从多个系统收集数据用于合规报告。

## **开始使用**

要在 HIPAA 合格环境中开始使用 Nova Act，请完成以下步骤：

- 通过 [AWS Management Console 中的自助流程](https://repost.aws/knowledge-center/activate-artifact-baa-agreement)签署 [AWS BAA](https://console.aws.amazon.com/)，并把你的账户指定为 HIPAA 账户。
- 查阅 [Nova Act 文档](https://docs.aws.amazon.com/nova/latest/userguide/what-is-nova.html)，了解服务特定的安全配置。
- 实施安全控制，包括 [AWS Identity and Access Management (IAM)](https://aws.amazon.com/iam/) 访问策略、[AWS Key Management Service (AWS KMS)](https://aws.amazon.com/kms/) 加密与 [AWS CloudTrail](https://aws.amazon.com/cloudtrail/) 日志记录。
- 在部署涉及 ePHI 的工作负载之前，使用 [AWS Well-Architected Tool](https://aws.amazon.com/well-architected-tool/) 做一次设计评审。

关于详细的实施指导，可以考虑接洽 [AWS Professional Services](https://aws.amazon.com/professional-services/) 或 AWS 生成式 AI 能力合作伙伴。

## **需要了解的事项**

- **HIPAA 合格资格** – Amazon Nova Act 已列入 [HIPAA 合格服务清单](https://aws.amazon.com/compliance/hipaa-eligible-services-reference/)。如果你已签署 AWS BAA，就可以使用 Nova Act 处理 ePHI。
- **集成** – Nova Act 可与 [Strands Agents](https://strandsagents.com/) 框架配合，并与 [Amazon Bedrock AgentCore](https://aws.amazon.com/bedrock/agentcore/)、Amazon CloudWatch 与 IAM 集成。
- **可用性** – Amazon Nova Act 在美国东部（弗吉尼亚北部）AWS 区域可用。各区域可用服务的清单见 [AWS 区域服务能力](https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/)页面。
- **定价** – 详情请访问 [Amazon Nova Act 定价页面](https://aws.amazon.com/nova/pricing/)。
- **合规说明** – HIPAA 合格资格意味着该服务被设计为按照 HIPAA 要求使用。你需负责配置该服务以满足你具体的合规义务。本公告不构成法律或合规建议。

## **结论**

具备 HIPAA 合格资格后，你现在可以把 agent 式 AI 带入受监管的医疗环境。[立即签署你的 AWS BAA](https://console.aws.amazon.com/)，并查阅 [Nova Act 文档](https://docs.aws.amazon.com/nova-act/latest/userguide/what-is-nova-act.html)，部署你的第一个合规的 agent 式 AI 工作流。

更多信息请访问 [AWS 云安全 — HIPAA 合规](https://aws.amazon.com/compliance/hipaa-compliance/)与 [HIPAA 合格服务清单](https://aws.amazon.com/compliance/hipaa-eligible-services-reference/)。
