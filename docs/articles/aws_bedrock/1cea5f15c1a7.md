# Qwen3 系列推理模型现已在 Amazon Bedrock Marketplace 与 Amazon SageMaker JumpStart 上可用

今天，我们很高兴地宣布，[Qwen3](https://qwenlm.github.io/blog/qwen3/)——[Qwen 系列](https://huggingface.co/collections/Qwen/qwen3-67dd247413f0e2e4f653967f)中最新一代大语言模型（LLM）——已可通过 [Amazon Bedrock Marketplace](https://aws.amazon.com/bedrock/marketplace/) 与 [Amazon SageMaker JumpStart](https://aws.amazon.com/sagemaker/jumpstart/) 获取。借助此次发布，你可以部署提供 0.6B、4B、8B 与 32B 参数规模的 Qwen3 模型，在 AWS 上构建、试验并负责任地扩展你的生成式 AI 应用。

在本文中，我们演示如何在 Amazon Bedrock Marketplace 与 SageMaker JumpStart 上开始使用 Qwen3。你也可以按照类似步骤部署这些模型的蒸馏版本。

## 方案概述

[Qwen3](https://aws.amazon.com/blogs/machine-learning/qwen3-family-of-reasoning-models-now-available-in-amazon-bedrock-marketplace-and-amazon-sagemaker-jumpstart/%20%20•Uniquely%20support%20of%20seamless%20switching%20between%20thinking%20mode%20(for%20complex%20logical%20reasoning,%20math,%20and%20coding)%20and%20non-thinking%20mode%20(for%20efficient,%20general-purpose%20dialogue)%20within%20single%20model,%20ensuring%20optimal%20performance%20across%20various%20scenarios.%20%20•Significantly%20enhancement%20in%20its%20reasoning%20capabilities,%20surpassing%20previous%20QwQ%20(in%20thinking%20mode)%20and%20Qwen2.5%20instruct%20models%20(in%20non-thinking%20mode)%20on%20mathematics,%20code%20generation,%20and%20commonsense%20logical%20reasoning.%20%20•Superior%20human%20preference%20alignment,%20excelling%20in%20creative%20writing,%20role-playing,%20multi-turn%20dialogues,%20and%20instruction%20following,%20to%20deliver%20a%20more%20natural,%20engaging,%20and%20immersive%20conversational%20experience.%20%20•Expertise%20in%20agent%20capabilities,%20enabling%20precise%20integration%20with%20external%20tools%20in%20both%20thinking%20and%20unthinking%20modes%20and%20achieving%20leading%20performance%20among%20open-source%20models%20in%20complex%20agent-based%20tasks.%20%20•Support%20of%20100+%20languages%20and%20dialects%20with%20strong%20capabilities%20for%20multilingual%20instruction%20following%20and%20translation.) 是 Qwen 系列中最新一代 LLM，提供涵盖稠密模型与混合专家（MoE）模型的完整阵容。Qwen3 在推理、指令遵循、agent 能力与多语言支持上带来了突破性进展，具备以下关键特性：

- 独特地在单个模型内支持在思考模式与非思考模式之间无缝切换，从而在各种场景下都能提供最优表现。
- 推理能力显著增强，在数学、代码生成与常识逻辑推理上超越了此前的 QwQ（思考模式）与 Qwen2.5 instruct 模型（非思考模式）。
- 良好的人类偏好对齐，在创意写作、角色扮演、多轮对话与指令遵循上表现出色，带来更自然、更有吸引力、更具沉浸感的对话体验。
- 在 agent 能力上具备专长，可在思考与非思考两种模式下与外部工具精确集成，并在复杂的 agent 任务中取得开源模型中的领先表现。
- 支持超过 100 种语言与方言，具备强大的多语言指令遵循与翻译能力。

## 先决条件

要部署 Qwen3 模型，请确保你能够访问与模型规模相匹配的推荐实例类型。你可以在 Amazon Bedrock Marketplace 或 SageMaker JumpStart 控制台上找到这些实例建议。要核实你具备所需资源，请完成以下步骤：

- 打开 [Service Quotas](https://docs.aws.amazon.com/general/latest/gr/aws_service_limits.html) 控制台。
- 在 **AWS Services** 下，选择 **Amazon SageMaker**。
- 检查你对端点部署所需的实例类型拥有足够配额。
- 确认目标 AWS Region 中至少有一种这样的实例类型可用。

如有需要，请申请提高配额，并联系你的 AWS 客户团队获取支持。

### 使用 Converse API 开启与关闭推理回复

下面的代码展示如何使用 Qwen3 模型通过 Converse API，依据用例开启或关闭推理。默认情况下，Qwen3 模型的推理是开启的，但你可以在 prompt 中使用 `/no_think` 指令来简化交互。把它加到查询末尾时，推理会被关闭，模型只给出直接答案。当你需要不含解释的快速信息、对话题已经熟悉，或希望保持更快的对话节奏时，这尤其有用。撰写本文时，Converse API 尚不支持 Qwen3 模型的工具使用。请参阅本文后面的 Invoke_Model API 示例，了解如何在同一次补全中同时使用推理与工具。

```
import boto3
from botocore.exceptions import ClientError

# Create a Bedrock Runtime client in the AWS Region you want to use.
client = boto3.client("bedrock-runtime", region_name="us-west-2")

# Configuration
model_id = ""  # Replace with Bedrock Marketplace endpoint arn

# Start a conversation with the user message.
user_message = "hello, what is 1+1 /no_think" #remove /no_think to leave default reasoning on
conversation = [
    {
        "role": "user",
        "content": [{"text": user_message}],
    }
]

try:
    # Send the message to the model, using a basic inference configuration.
    response = client.converse(
        modelId=model_id,
        messages=conversation,
        inferenceConfig={"maxTokens": 512, "temperature": 0.5, "topP": 0.9},
    )

    # Extract and print the response text.
    #response_text = response["output"]["message"]["content"][0]["text"]
    #reasoning_content = response ["output"]["message"]["reasoning_content"][0]["text"]
    #print(response_text, reasoning_content)
    print(response)
    
except (ClientError, Exception) as e:
    print(f"ERROR: Can't invoke '{model_id}'. Reason: {e}")
    exit(1)
```

## 使用 SageMaker JumpStart 部署 Qwen3-32B

def deploy_model_with_retries(model_builder, model_id):

### 删除 Amazon Bedrock Marketplace 部署

如果你使用 Amazon Bedrock Marketplace 部署了模型，请完成以下步骤：

- 在 Amazon Bedrock 控制台的导航窗格中，于 **Foundation models** 下选择 **Marketplace deployments**。
- 在 **Managed deployments** 区块中，找到你要删除的端点。
- 选择该端点，然后在 **Actions** 菜单中，选择 **Delete**。
- 核对端点详情，确认你删除的是正确的部署：  端点名称 模型名称 端点状态
- 选择 **Delete** 以删除该端点。
- 在删除确认对话框中，查看警告信息，输入 `confirm`，然后选择 **Delete** 以永久移除该端点。

### 删除 SageMaker JumpStart predictor

你部署的 SageMaker JumpStart 模型如果保持运行会产生费用。如果你想停止计费，请使用以下代码删除端点。更多细节请参阅[删除端点与资源](https://docs.aws.amazon.com/sagemaker/latest/dg/realtime-endpoints-delete-resources.html)。
