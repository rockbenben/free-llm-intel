# AWS re:Invent 2026 上的 AWS Quick 完整指南

AWS Quick 是专为工作打造的 AI 工作空间：一个人创建的 dashboard、agent 和自动化，团队里所有人都能用。Quick 构建在 AWS 之上，从一开始就具备企业级的安全与治理能力，并可连接你日常使用的数据与应用。在 AWS re:Invent 2026（11 月 30 日至 12 月 4 日）上，Allianz、Cox Automotive、Mondelez、DXC 和 Southwest Airlines 等客户将与 AWS 领导者同台，分享他们如何在团队中治理、扩展 Quick 并实现规模化。无论你是业务或技术负责人、构建者，还是 IT、安全、数据或分析团队的一员，都可以用本指南找到适合你目标的 session。

[浏览 session 目录并了解更多](https://registration.awsevents.com/flow/awsevents/reinvent2026/eventcatalog/page/eventcatalog?search=quick)。

**[BIZ307: 在你的数据平台上用 AWS Quick 设计 AI 驱动的分析架构](https://registration.awsevents.com/flow/awsevents/reinvent2026/eventcatalog/page/eventcatalog?search=BIZ307)**

*演讲者：Vignessh Baskaran、Jackson Dowden*

随着组织采用 AI 驱动的分析，它们需要能把商业智能（BI）和对话式 AI 体验连接到现有数据平台的架构。在本场 session 中，我们会绘制架构模式图，说明如何把 AWS Quick 连接到结构化数据源，以及如何与第三方 catalog 和语义层集成。我们会比较可用的连接方式，包括数据源和基于 Model Context Protocol（MCP）的 action connector，并讨论各自适用的场景。讨论范围将覆盖 BI dashboard、嵌入式分析、text-to-SQL 问答和 agentic 工作流等生产用例。我们会一起解决真实世界的集成难题，包括身份验证、性能优化和治理。本场 session 适合希望在数据平台上构建 AI 驱动分析的架构师和技术负责人。

**[BIZ404: 教 Quick 记住与连接：memory 与知识图谱](https://registration.awsevents.com/flow/awsevents/reinvent2026/eventcatalog/page/eventcatalog?search=BIZ404)**
 11 月 30 日（周一）| 下午 1:30 PST
*演讲者：Thomas Delteil、Adi Kalyanpur*

与 AI 助手的每一次对话都是从零开始。你的 agent 不记得昨天什么做法有效，不重新搜索就说不出项目负责人是谁，还会重复同样的错误，因为失败从来没有被记录下来。在本场 chalk talk 中，我们将展示 AWS Quick 如何用两个原语摆脱无状态：一个是持续学习的 memory 层，后台 agent 在每次 session 之后提取可复用的知识，并用概率置信度模型为其打分；另一个是个人知识图谱，它跨你的工具连接人、项目、决策和证据，让 agent 在读第一份文档之前就已经拥有你所在世界的地图。我们会在白板上推演这套架构及其背后的取舍，然后开放提问。带上你最尖锐的问题：memory 陈旧、置信度校准、图谱噪声，或者如何让 agent 真正随时间变得更好。

**[BIZ305: 安全：agentic 时代的零信任身份与数据保护](https://registration.awsevents.com/flow/awsevents/reinvent2026/eventcatalog/page/eventcatalog?search=BIZ305)**
 11 月 30 日（周一）| 下午 2:30 PST
*演讲者：Priya Kakarla、Munish Gopal*

拖住 AI 推广的往往是安全审查，而不是能力缺口，而 agentic AI 又把门槛抬得更高。本场 chalk talk 不满足于讨论「它安全吗？」，而是讲清楚让 CISO 点头的架构。我们会在白板上推演完整的身份路径：通过 Okta、Ping 等提供商实现单点登录（SSO），并把最终用户身份传递到数据侧，从而对每个用户实时强制执行授权，覆盖 1P AWS 和 3P 数据源。然后我们把这份信任延伸到 agent：agent 身份、对每次 tool call 做确定性策略检查，以及数据保护：Purview DLP、默认 guardrails、默认拒绝（deny-by-default），以及完整的 SIEM 可审计性。

**[BIZ310: AWS Quick 的安全可扩展多租户部署模式](https://registration.awsevents.com/flow/awsevents/reinvent2026/eventcatalog/page/eventcatalog?search=BIZ310)**

**[BIZ304: 在 Quick 上构建并治理 app](https://registration.awsevents.com/flow/awsevents/reinvent2026/eventcatalog/page/eventcatalog?search=BIZ304)**
 11 月 30 日（周一）| 下午 4:00 PST

任何人都能用一句话生成 app。难的是治理它们，并让它们出现在合适的用户面前。本场 chalk talk 在白板上推演 AWS Quick Apps 的完整生命周期：用自然语言构建、无需单独托管，通过 MCP 接入数据与动作，以及三条共享路径：私有、公开 URL，以及由管理员审批工作流把关的企业内共享。

**[BIZ303: 一个上下文层，覆盖所有入口：为随处工作的 agent 提供企业知识](https://registration.awsevents.com/flow/awsevents/reinvent2026/eventcatalog/page/eventcatalog?search=BIZ303)**
 12 月 3 日（周四）| 中午 12:00 PST
*演讲者：Suren Raju、Josh DeMuth*

你的 AI agent 有多聪明，取决于它能触达的数据。在大多数企业里，这些数据散落在数十个系统中，彼此孤立、缺乏治理，最需要它们的 agent 反而看不见。在本场 chalk talk 中，我们从零设计一个上下文层：把企业知识连接进统一索引，再用知识图谱强化这个基础，图谱映射组织关系、业务规则和领域上下文，让 agent 在运行时获得按权限限定范围、能感知关系的智能。然后我们把这份智能带到用户工作的地方：浏览器、桌面、移动端、协作工具和生产力套件。每个入口独立治理，却共享同一个 agent 身份、同一份 memory 和同一套 guardrails。带上你的架构。我们会一起在白板上画出端到端的路径。

 无需预约，整周开放
*演讲者：Michelle Koh、Anupa Bhattacharyya、Christopher Lott *

Ctrl+Alt+Ship 是一个无需预约、自定进度的 lab 区域，整周开放（11 月 30 日 – 12 月 4 日），位于 Venetian 二层宴会厅。无需预约，现场提供工作站。参与者选择一条 track（Kiro、Quick 或 Connect）和一个级别（200 或 400）。两个 Quick lab 都是业务模拟，Quick 通过 MCP 连接到公司的业务系统。在 L200 的 Kōji Fresh lab 中，参与者要主导应对一家虚构新加坡食品公司的产品安全危机。他们在邮件、CRM、社交媒体和供应链中调查，向董事会和供应商汇报，用一条指令在三个系统中执行召回，并把五份数据导出变成可上董事会的图表。在 L400 的 SkyNova Airlines lab 中，14 名乘客一夜之间病倒，一位网红正在指责这家航空公司。参与者使用 Quick 跨六个系统找出规律并向董事会汇报，然后在硬性预算内为滞留乘客改签，构建一个 Flow 来执行某架停飞航班的恢复流程，并为机场转机柜台发布一个 Quick App。现场会有引导员提供帮助。

**[BIZ312: 在 AWS Quick 上用对话式 BI 构建 AI 驱动的分析](https://registration.awsevents.com/flow/awsevents/reinvent2026/eventcatalog/page/eventcatalog?search=BIZ312)**
 12 月 1 日（周二）| 下午 3:30 PST
*演讲者：Neeraj Kumar、Salim Khan*

构建一条完整的 AI 驱动分析流水线，从数据接入到对话式消费。使用 AWS Quick 的 Data Catalog 发现数据，在不把数据搬进 SPICE 的情况下实时查询，然后补充并导入元数据、继承语义，从而构建自然语言问答。在这场动手 workshop 中，你从七张原始银行表开始：没有 catalog，也没有定义。一个 agent 会检查数据并为你构建 catalog。你用自然英语提问并得到答案。一个 agent 生成 dashboard，显示哪些顶级客户正在流失。另一个 agent 了解银行的合规规则，在每个 offer 发出前做检查。然后你用 Quick Flow 把整个响应自动化，并把它包装成团队可用的自定义 app。离开时你将拥有一个由 agent 搭建、且你可以用对话式分析在自己账户里重建的银行指挥中心。

**[BIZ313: 用 AWS Quick Automate 为业务流程构建 agentic 自动化](https://registration.awsevents.com/flow/awsevents/reinvent2026/eventcatalog/page/eventcatalog?search=BIZ313)**
 12 月 2 日（周三）| 中午 12:00 PST
*演讲者：Reagan Rosario、Zuhayr Raghib*

在本场 session 中，学习如何使用 AWS Quick Automate 构建自动化。通过一个金融服务示例，探索专门的 AI agent 如何协同处理跨网页和业务应用的复杂交互。你将创建一个可用于生产的自动化，其中的 custom agent 利用知识和工具改造商户入驻流程。使用 Quick Automate 基于对话的编写方式和可视化 studio，你将配置一个包含多个 agent 的工作流、集成多个工具、测试和调试该工作流，然后用稳健的企业级控制将其部署。离开时你将掌握如何为真实用例开发 agentic 自动化。

**[BIZ311: 掌握 agent skills：从桌面构建到生产部署](https://registration.awsevents.com/flow/awsevents/reinvent2026/eventcatalog/page/eventcatalog?search=BIZ311)**
 12 月 2 日（周三）| 下午 3:00 PST
*演讲者：Jed Lechner、Leo Mentis Raj Selvaraj*

在 AWS Quick 上为你的企业构建、治理并扩展可用于生产的 agent skills。先在 Quick 上编写 custom skills，然后切换到管理员视角：把 skills 注册到 Quick Catalog 供全组织发现、配置访问策略，并大规模调度自主执行。你将通过两个业务驱动的用例部署可度量的自动化：基于联络中心数据的流失预防，以及消除手工后台工作的智能理赔处理。离开时你将带走可用的 skills、一套面向跨团队数百个 agent 的治理框架，以及一套向管理层沟通 ROI 的打法。

**[BIZ314: 用 AWS Quick、MCP 和 AgentCore 构建多 agent 工作流](https://registration.awsevents.com/flow/awsevents/reinvent2026/eventcatalog/page/eventcatalog?search=BIZ314)**
 12 月 3 日（周四）| 上午 8:30 PST
*演讲者：Vishnu Elangovan、Josh Anderson*

在 AWS Quick 内部设计并构建一个多 agent 系统，让专门的 agent 协作自动化复杂业务流程。通过 Amazon Bedrock AgentCore 上的 MCP server 连接企业系统，实现 agent 间通信，配置 OAuth 2.0 身份验证，并使用 Quick Flows 部署自主工作流。本场以在生产环境中运行、跨企业资源规划（ERP）、财务和采购协调 12+ 个 agent 的部署为蓝本，离开时你将获得一个可在自己环境中复现的、可运行的多 agent 方案。

为 AWS Quick 实施全面的安全与管理控制。动手配置身份集成、访问策略和数据治理框架。学习建立满足企业要求的监控、审计与合规控制。通过多个场景演练用户管理、内容治理，以及生产环境中 AWS Quick 环境的安全最佳实践。
