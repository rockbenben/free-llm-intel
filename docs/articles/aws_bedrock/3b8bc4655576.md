# AWS re:Invent 2026 上的 AWS Quick 完整指南

AWS Quick 是专为工作而构建的 AI 工作区，其中一个人创建的仪表板、代理和自动化可供团队中的每个人使用。 Quick 基于 AWS 构建，从一开始就具有企业安全性和治理功能，可连接到您每天使用的数据和应用程序。在 AWS re:Invent 2026（11 月 30 日至 12 月 4 日）上，Allianz、Cox Automotive、Mondelez、DXC 和 Southwest Airlines 等客户与 AWS 领导者一起登台分享他们如何在团队中管理、扩展和扩展 Quick。无论您是业务或技术领导者、构建者，还是 IT、安全、数据或分析团队的一员，都可以使用本指南来查找适合您目标的会议。

[探索会话目录并了解更多信息](https://registration.awsevents.com/flow/awsevents/reinvent2026/eventcatalog/page/eventcatalog?search=quick)。
