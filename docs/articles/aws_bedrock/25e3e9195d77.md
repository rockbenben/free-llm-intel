# 借助 Amazon SageMaker Unified Studio 中的 Amazon Bedrock，只需几次点击即可创建能与公司系统交互的生成式 AI agent

今天我们宣布，[Amazon Bedrock](https://aws.amazon.com/bedrock/ide/) 在 [Amazon SageMaker Unified Studio](https://aws.amazon.com/sagemaker/unified-studio/) 中正式可用（general availability）。

各种规模的公司都在承受越来越大的压力：随着所管理的数据、系统和客户互动量不断增长，它们必须高效运营。人工流程和割裂的信息来源会造成瓶颈、拖慢决策，使团队难以专注于更有价值的工作。[生成式 AI](https://aws.amazon.com/ai/generative-ai/) agent 提供了一种强大的解决方案：自动对接公司系统、执行任务并即时提供洞察，帮助组织在不增加复杂度的前提下扩展运营。

SageMaker Unified Studio 中的 Amazon Bedrock 通过提供统一的服务来构建 AI 驱动的方案——集中客户数据并支持自然语言交互——来应对这些挑战。它与现有应用集成，并包含 Amazon Bedrock 的关键功能，例如基础模型（FM）、prompt、knowledge base、agent、flow、评估和 guardrail。用户可以通过组织的单点登录（SSO）访问这些 AI 能力，与团队成员协作并改进 AI 应用，而无需 [AWS Management Console](https://aws.amazon.com/console/) 访问权限。

## 面向自动化工作流的生成式 AI agent

SageMaker Unified Studio 中的 Amazon Bedrock 让你可以创建并部署能与组织应用、数据库和第三方系统集成的生成式 AI agent，实现贯穿整个技术栈的自然语言交互。chat agent 在复杂信息系统与友好的沟通方式之间架起桥梁。通过使用 Amazon Bedrock 的 function 和 [Amazon Bedrock Knowledge Bases](https://aws.amazon.com/bedrock/knowledge-bases/)，agent 可以连接 [Jira](https://www.atlassian.com/software/Jira) API 等数据源，实时跟踪项目状态、检索客户信息、更新项目任务并管理偏好设置。

销售与市场团队可以快速访问客户信息及其会议偏好，项目经理也能高效管理 Jira 任务与时间线。这一精简流畅的流程提升了整个组织的生产力与客户互动。

## 方案概览

Amazon Bedrock 提供受治理的协作环境，用于在 SageMaker Unified Studio 中构建和共享生成式 AI 应用。让我们看一个实现客户管理 agent 的示例方案：

- 可以借助 Amazon Bedrock 的 chat 应用构建 agentic 对话，并将其与其他 AWS 服务（例如 [AWS Lambda](https://aws.amazon.com/lambda/) 和 [Amazon API Gateway](https://aws.amazon.com/api-gateway/)）快速构建的 function 集成。
- SageMaker Unified Studio 通过 [Amazon DataZone](https://aws.amazon.com/datazone/) 及其集成服务提供全面的数据管理方案。组织管理员可以控制成员对 Amazon Bedrock 模型和功能的访问，保持安全的身份管理与精细的访问控制。

在深入探讨 AI agent 的部署之前，让我们先梳理架构的关键步骤，如下图所示。

[![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/04/25/ML17652-architecture-diagram-002-new.png)](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/03/11/ML17652-architecture-diagram-002.png)

工作流如下：

- 用户通过组织的 SSO 从 [AWS IAM Identity Center](https://aws.amazon.com/iam/identity-center/)登录 SageMaker Unified Studio。然后用户用自然语言与 chat 应用交互。
- Amazon Bedrock 的 chat 应用调用 function，通过 API Gateway 的端点从数据库中检索 Jira 状态和客户信息。
- chat 应用使用来自 [AWS Secrets Manager](https://aws.amazon.com/secrets-manager/) 的随机 API key 向 API Gateway 认证，以安全访问该端点，并根据用户请求触发 Lambda 函数。
- Lambda 函数使用 agent 提供的必需参数调用 Jira API 或数据库来执行操作。该 agent 能够：

- 提供客户简要概览。列出最近的客户互动。检索某位客户的会议偏好。检索某个项目的未结 Jira 工单。更新某个 Jira 工单的到期日期。

## 前提条件

要跟随本方案的实施，你需要以下前提条件：

- 一个 AWS 账户
- 对 SageMaker Unified Studio 中 Amazon Bedrock 的[用户访问权限](https://docs.aws.amazon.com/sagemaker-unified-studio/latest/adminguide/amazon-bedrock-ide.html)
- 在[受支持的 AWS 区域](https://docs.aws.amazon.com/bedrock/latest/userguide/models-regions.html)中对 Amazon Bedrock 上 [Amazon Nova Pro](https://aws.amazon.com/ai/generative-ai/nova/understanding/) 的[模型访问权限](https://docs.aws.amazon.com/bedrock/latest/userguide/model-access.html?icmpid=docs_bedrock_help_panel_model_access)
- 一个 Jira 应用、Jira URL，以及你账户的 [Jira API token](https://support.atlassian.com/atlassian-account/docs/manage-api-tokens-for-your-atlassian-account/)

我们假定你熟悉 AWS 上的基础 serverless 构件，例如 API Gateway、Lambda 函数和 IAM Identity Center。本文不侧重讲解这些服务的定义，但会用它们来展示 SageMaker Unified Studio 中 Amazon Bedrock 新功能的用例。

## 部署方案

请完成以下部署步骤：

- 从 [GitHub](https://github.com/aws-samples/genai-crm-agent-demo) 下载代码。
- 获取 Lambda 函数所需的 Jira_API_KEY_ARN、Jira_URL 和 Jira_USER_NAME 的值。
- 使用下面的 [AWS CloudFormation](https://aws.amazon.com/cloudformation/) [模板](https://github.com/aws-samples/genai-crm-agent-demo/blob/main/cloudformation/resource_template.yaml)，并参考[在 CloudFormation 控制台中创建堆栈](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/cfn-console-create-stack.html)，在你偏好的 AWS 区域中启动堆栈。
- 堆栈部署完成后，从 CloudFormation 的 **Outputs** 标签页记下 API Gateway URL 的值（`ApiInvokeURL`）。
- 在 Secrets Manager 控制台上，找到 Jira_API_KEY_ARN、Jira_URL 和 Jira_USER_NAME 对应的 secret。
- 选择 **Retrieve secret**，并把第 2 步中的变量复制到 secret 的明文串中。
- 使用组织的 SSO 登录 SageMaker Unified Studio。

[![SMU 登录页](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/03/11/ML17652-SMU-login-003.png)](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/03/11/ML17652-SMU-login-003.png)

## 创建新项目

请完成以下步骤创建一个新项目：

- 在 SageMaker Unified Studio 着陆页上，[创建一个新项目](https://docs.aws.amazon.com/sagemaker-unified-studio/latest/userguide/create-new-project.html)。
- 为项目命名（例如 `crm-agent`）。
- 选择 **Generative AI application development profile** 并继续。
- 使用默认设置并继续。
- 复核后选择 **Create project** 确认。

[![Bedrock 项目创建](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/03/11/ML17652-project-creation-01.png)](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/03/11/ML17652-project-creation-01.png)

## 构建 chat agent 应用

请完成以下步骤来[构建 chat agent 应用](https://docs.aws.amazon.com/sagemaker-unified-studio/latest/userguide/create-chat-app.html)：

- 在 crm-agent 项目着陆页右侧的 **New** 区域下，选择 **Chat agent**。

它会显示 agent 应用的配置列表。

- 在 model 区域中，选择 Amazon Bedrock 支持的所需 FM。对于这个 crm-agent，我们选择 Amazon Nova Pro。
- 在 system prompt 区域中，添加以下 prompt。你也可以选择添加用户输入与模型响应的示例来改进它。

`You are a customer relationship management agent tasked with helping a sales person plan their work with customers. You are provided with an API endpoint. This endpoint can provide information like company overview, company interaction history (meeting times and notes), company meeting preferences (meeting type, day of week, and time of day). You can also query Jira tasks and update their timeline. After receiving a response, clean it up into a readable format. If the output is a numbered list, format it as such with newline characters and numbers.`

[![Bedrock chat agent](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/03/11/ML17652-chat-agent-004.png)](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/03/11/ML17652-chat-agent-004.png)

- 在 **Functions** 区域中，选择 **Create a new function**。
- 为函数命名，例如 `crm_agent_calling`。
- 对于 **Function schema**，使用 [GitHub repo](https://github.com/aws-samples/genai-crm-agent-demo/blob/main/openapi_schema/openapi_schema.json) 中的 OpenAPI 定义。

[![Bedrock function](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/03/11/ML17652-bedrock-function-005.png)](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/03/11/ML17652-bedrock-function-005.png)

- 对于 **Authentication method**，选择 **API Keys (Max. 2 Keys)** 并输入以下详情：对于 **Key sent in**，选择 **Header**。对于 **Key name**，输入 `x-api-key`。对于 **Key value**，输入 Secrets Manager 的 API Key
- 在 **API servers** 区域中，输入端点 URL。
- 选择 **Create** 完成函数创建。
- 在 chat agent 应用的 **Functions** 区域中，选择你创建的 function，然后选择 **Save** 完成应用创建。

[![Bedrock chat agent 应用](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/03/11/ML17652-chat-agent-app-006.png)](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/03/11/ML17652-chat-agent-app-006.png)

## 示例交互

### 用例 1：CRM 分析师可以用自然语言检索存储在数据库中的客户详情。

在本用例中，我们在 chat 应用中提出以下问题：

- 简要介绍一下客户 C-jkl101112。
- 列出客户 C-def456 最近 2 次互动。
- 客户 C-mno131415 偏好哪种沟通方式？
- 根据其偏好和我们最近一次互动，推荐联系 C-ghi789 的最佳时间与渠道。

chat 应用的响应如下图所示。agent 成功从数据库中检索到客户信息。它理解用户的问题，并查询数据库以找到对应答案。

## 清理

为避免产生额外费用，请完成以下步骤：

- [删除 CloudFormation 堆栈](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/cfn-console-delete-stack.html)。
- 删除 Amazon Bedrock 中的 function 组件。
- 删除 Amazon Bedrock 中的 chat agent 应用。
- [删除 SageMaker Unified Studio 中的域](https://docs.aws.amazon.com/sagemaker-unified-studio/latest/adminguide/delete-domain.html)。

## 成本

SageMaker Unified Studio 中的 Amazon Bedrock 不产生单独收费，但你会为该服务中所使用的各项 AWS 服务和资源付费。你只需为所使用的 Amazon Bedrock 资源付费，没有最低费用或预付承诺。

如果你在价格计算方面需要进一步协助，或对针对具体用例优化成本有疑问，请联系 AWS Support 或咨询你的客户经理。

## 结论

本文演示了如何使用 SageMaker Unified Studio 中的 Amazon Bedrock 构建一个生成式 AI 应用，与现有端点和数据库集成。

Amazon Bedrock 的生成式 AI 功能支持快速进行 agent 原型验证和部署，从而改变了组织构建与部署 AI 方案的方式。团队可以迅速创建、测试并上线 chat agent 应用，加快实现那些能自动化复杂任务、增强决策能力的 AI 方案。该方案的可扩展性与灵活性让组织得以将先进的 AI 能力无缝集成到现有应用、数据库和第三方系统中。

通过统一的 chat 界面，agent 可以处理项目管理、数据检索和工作流自动化——在提升用户体验的同时显著减少人工投入。通过让先进的 AI 能力更易获得、更易使用，SageMaker Unified Studio 中的 Amazon Bedrock 助力组织在当今竞争激烈的环境中达到新的生产力与客户满意度水平。
