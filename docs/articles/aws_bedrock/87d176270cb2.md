# 使用 SGLang-Neuron 在 AWS Trainium 上部署前沿 AI 模型

今天，Amazon 宣布 [SGLang-Neuron](http://github.com/sgl-project/sglang-neuron) 已公开发布，可通过一个由 RadixArk 与 Annapurna Labs 合作发布的 AWS Deep Learning Container 获取。借助 SGLang-Neuron，你可以在 [AWS Trainium](https://aws.amazon.com/ai/machine-learning/trainium/) 上用 SGLang 部署模型、生成强化学习 (RL) rollout，用的还是你今天熟悉的同一套 SGLang 接口。Trainium 是一系列 AWS AI 芯片，为大规模 AI 训练和推理带来可观的成本效益。现在，在 Trainium 上跑 SGLang 沿用你已经熟悉的 SGLang 工作流：通过 SGLang 的 server 接口启动模型，再用同样的生成 API 调用 endpoint。在这套接口之下，SGLang-Neuron 运行在原生 PyTorch 上。得益于 out-of-tree 插件设计，Trainium 支持与 SGLang 核心各自独立开发，迭代更快。

## SGLang 如何运行在 Trainium 上

SGLang-Neuron 是一个把 SGLang 与 AWS Trainium 接起来的 out-of-tree 插件。安装插件后，会通过 SGLang 的插件入口点注册 neuron platform；服务启动时设置 `SGLANG_PLATFORM=neuron` 即可选中它。SGLang 核心继续提供 API server、请求生命周期、RadixAttention 和 prefix-cache 记账。插件则实现 Trainium 专属的模型、attention、mixture of experts (MoE) 以及 graph runner。

![AWS Trainium 上的 SGLang-Neuron 架构，展示 SGLang 核心与 Trainium 插件组件](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/11/12/ML-22453-1.png)

图 1：AWS Trainium 上的 SGLang-Neuron

[TorchNeuron](https://awsdocs-neuron.readthedocs-hosted.com/en/latest/torch/index.html) 把 Trainium 注册为原生 PyTorch device。SGLang-Neuron 在模型执行路径上使用标准 PyTorch 算子，并引入用 [Neuron Kernel Interface](https://awsdocs-neuron.readthedocs-hosted.com/en/latest/nki/index.html) (NKI) 编写的 kernel 来提升性能。它借 `torch.compile` 把这些算子和 kernel 编译成可执行程序，由 graph runner 在服务期间准备并执行。

SGLang-Neuron 还支持 [PD disaggregation](https://docs.sglang.io/docs/advanced_features/pd_disaggregation)。在这种配置下，prefill server 计算 prompt 的 KV cache，并通过 [NIXL](https://github.com/ai-dynamo/nixl) 经 [Elastic Fabric Adapter (EFA)](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/efa-start-nixl.html) 把它传给 decode server，随后由 decode server 生成剩余 token。每个 server 仍使用 SGLang 的调度器和请求生命周期，插件则负责 Trainium 执行与 KV cache 传输路径。

## 使用 SGLang-Neuron 在 AWS Trainium 上部署模型

按本文操作，你需要一台 Trainium3 Amazon Elastic Compute Cloud (Amazon EC2) 实例，配一个 `pytorch-inference-sglang-neuronx` 容器。步骤如下：

- 启动容器。  `docker run --rm -it \ --privileged --ipc=host \ -v /path/to/work:/work \ public.ecr.aws/neuron/pytorch-inference-sglang-neuron:v0.1.0-neuron-py314-sdk-2.33.0-ubuntu26.04 \ /bin/bash`
- 在容器内启动 SGLang model server。  `SGLANG_PLATFORM=neuron \ python -m sglang.launch_server \ --model-path openai/gpt-oss-120b \ --tp-size 8 \ --ep-size 8 \ --kv-cache-dtype fp8_e4m3 \ --context-length 10240 \ --chunked-prefill-size 8192 \ --max-running-requests 64 \ --max-total-tokens 655360 \ --mem-fraction-static 0.8 \ --host 127.0.0.1 \ --port 30000`
- 向 model server 发一个请求。  `curl -s http://127.0.0.1:30000/v1/chat/completions \ -H 'Content-Type: application/json' \ -d '{ "model": "openai/gpt-oss-120b", "messages": [ {"role": "user", "content": "Explain why the sky appears blue."} ], "temperature": 0, "max_tokens": 128 }'`

更多配置说明见 SGLang-Neuron 入门指南，受支持的模型、特性和经过验证的配置可查阅仓库文档。

## 结论

[SGLang-Neuron](http://github.com/sgl-project/sglang-neuron) 通过原生 PyTorch，把 SGLang 那套熟悉的部署工作流带到了 [AWS Trainium](https://aws.amazon.com/ai/machine-learning/trainium/) 上。你可以先启动 [SGLang-Neuron container](https://gallery.ecr.aws/neuron/pytorch-inference-sglang-neuron)，再按 [quickstart](https://github.com/sgl-project/sglang-neuron/blob/main/docs/getting-started/quickstart.md) 部署一个受支持的模型。用你自己的工作负载试一试，通过项目仓库参与贡献，并分享反馈，帮助确定未来要支持的模型与特性。
