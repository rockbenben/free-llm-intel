# Amazon Nova Canvas 在室内设计与产品摄影中的真实应用

随着 AI 图像生成在现代业务工作流中日益处于核心位置，组织正在寻找务实的方式，把这项技术用于具体的行业挑战。尽管 AI 图像生成的潜力巨大，许多企业仍难以将其有效应用到自身独特的用例中。

在本文中，我们探讨 [Amazon Nova Canvas](https://aws.amazon.com/ai/generative-ai/nova/creative/) 如何通过先进的图像生成技术解决真实的业务挑战。我们聚焦两个具体用例，展示这项技术的能力与灵活性：

- **室内设计** – 结合分割（segmentation）的图像条件控制帮助室内设计师快速迭代设计方案，大幅减少制作客户提案所需的时间与成本
- **产品摄影 **– Outpainting 让产品摄影师无需大量实景拍摄，就能为产品创造多样的环境场景

无论你是希望简化可视化流程的室内设计公司，还是想要降低摄影成本的零售企业，本文都能帮助你使用 Amazon Nova Canvas 的高级特性来实现具体的业务目标。让我们深入了解这些强大的工具如何改变你的图像生成工作流。

## 室内设计

一家室内设计公司面临这样的问题：他们的设计师要花数小时为客户提案制作照片级真实的设计图，同一房间需要按不同主题和装饰元素做出多个迭代版本。传统的 3D 渲染既耗时又昂贵。为解决这个问题，你可以使用 Amazon Nova Canvas 的图像条件控制（分割）特性，快速对既有房间照片进行迭代。系统会分析条件图像以识别显著的内容形状，生成一张分割掩码（segmentation mask）来引导生成。生成的图像紧贴条件图像的布局，同时允许模型在每个内容区域的边界内自由创作。

本文演示如何在转换室内元素的同时保持结构完整性，因此你只需简单的 prompt 和输入图像，就能在几分钟内生成多个变体。下面的代码块给出结合分割的图像条件控制的 API 请求结构。执行这些转换的参数通过 API 请求传给模型。请确保输出图像与输入图像尺寸相同，以避免结果变形。

```
{
    "taskType": "TEXT_IMAGE",
    "textToImageParams": {
        "conditionImage": string (Base64 encoded image), #Original living room
        "controlMode": "SEGMENTATION", 
        "controlStrength": float, #Specify how closely to follow the condition       #image (0.0-1.0; Default: 0.7).
        "text": string, #A minimalistic living room
        "negativeText": string
    },
    "imageGenerationConfig": {
        "width": int,
        "height": int,
        "quality": "standard" | "premium",
        "cfgScale": float,
        "seed": int,
        "numberOfImages": int
    }
}
```

`taskType` 对象决定所执行的操作类型，并有自己的一组参数；`imageGenerationConfig` 对象包含所有任务类型（背景移除除外）通用的一般参数。要了解不同类型生成的请求/响应结构，请参阅[图像生成的请求与响应结构](https://docs.aws.amazon.com/nova/latest/userguide/image-gen-req-resp-structure.html)。

下面的 Python 代码演示通过调用 Amazon Bedrock 上的 Amazon Nova Canvas v1.0 模型，执行一次基于图像条件控制的生成：

```
import base64  #For encoding/decoding base64 data
import io  #For handling byte streams
import json  #For JSON operations
import boto3  #AWS SDK for Python
from PIL import Image  #Python Imaging Library for image processing
from botocore.config import Config  #For AWS client configuration
#Create a variable to fix the region to where Nova Canvas is enabled 
region = "us-east-1"

#Create Bedrock client with 300 second timeout
bedrock = boto3.client(service_name='bedrock-runtime', region_name=region,
        config=Config(read_timeout=300))

#Original living room image in current working directory
input_image_path = "Original Living Room.jpg"

#Read and encode the image
def prepare_image(image_path):
    with open(image_path, 'rb') as image_file:
        image_data = image_file.read()
        base64_encoded = base64.b64encode(image_data).decode('utf-8')
    return base64_encoded

#Get the base64 encoded image
input_image = prepare_image(input_image_path)

#Set the content type and accept headers for the API call
accept = "application/json"
content_type = "application/json"

#Prepare the request body
api_request = json.dumps({
       "taskType": "TEXT_IMAGE",  #Type of generation task
       "textToImageParams": {
             "text": "A minimalistic living room",  #Prompt
             "negativeText": "bad quality, low res",  #What to avoid
             "conditionImage": input_image,  #Base64 encoded original living room
             "controlMode": "SEGMENTATION"  #Segmentation mode
            },
       "imageGenerationConfig": {
             "numberOfImages": 1,  #Generate one image
             "height": 1024,  #Image height, same as the input image
             "width": 1024,  #Image width, same as the input image
             "seed": 0, #Modify seed value to get variations on the same prompt
             "cfgScale": 7.0  #Classifier Free Guidance scale
            }
})

#Call the model to generate image
response = bedrock.invoke_model(body=api_request, modelId='amazon.nova-canvas-v1:0', accept=accept, contentType=content_type)

#Parse the response body
response_json = json.loads(response.get("body").read())

#Extract and decode the base64 image
base64_image = response_json.get("images")[0]  #Get first image
base64_bytes = base64_image.encode('ascii')  #Convert to ASCII
image_data = base64.b64decode(base64_bytes)  #Decode base64 to bytes

#Display the generated image
output_image = Image.open(io.BytesIO(image_data))
output_image.show()
#Save the image to current working directory
output_image.save('output_image.png')
```

一家运动鞋公司面临这样的问题：他们需要在多种环境（跑道、户外等）中展示其多功能新款跑鞋，这需要昂贵的场地拍摄，并且每个款式都要多次摄影。为解决这个问题，你可以使用 Amazon Nova Canvas 从单张产品照片生成多样的场景。Outpainting 可用于替换图像的背景。你可以通过提供 mask prompt 来指示模型保留图像的某些部分，例如“Shoes”。mask prompt 是对图像中不应在 outpainting 过程中被改动的对象的自然语言描述。然后你可以用新的 prompt 生成不同背景下的鞋子。

除了使用 mask prompt，你也可以输入一张掩码图像，用它定义需要保留的图像区域。掩码图像必须与输入图像尺寸相同。需要编辑的区域涂成纯白，需要保留的区域涂成纯黑。Outpainting 模式是一个参数，用于定义掩码的处理方式。使用 `DEFAULT` 可在掩码区域与非掩码区域之间平滑过渡。当你希望新背景使用与原背景相近的颜色时，这种模式通常更好。不过，如果你的 prompt 要求的新背景与原背景差异很大，可能会出现光晕（halo）效果。使用 `PRECISE` 可严格遵循掩码边界。当你对背景做大幅改动时，这种模式通常更好。

本文演示如何使用 outpainting 保持产品的准确性，然后无缝地把一张棚拍照片转换为不同环境。下面的代码展示了 outpainting 的 API 请求结构：

```
{
    "taskType": "OUTPAINTING",
    "outPaintingParams": {
        "image": string (Base64 encoded image),
        "maskPrompt": string, #Shoes
        "maskImage": string, #Base64 encoded image
        "outPaintingMode": "DEFAULT" | "PRECISE", 
        "text": string,  #Product photoshoot of sports shoes on rocky terrain
        "negativeText": string
    },
    "imageGenerationConfig": {
        "numberOfImages": int,
        "quality": "standard" | "premium",
        "cfgScale": float,
        "seed": int
    }
}
```

下面的 Python 代码演示通过调用 Amazon Bedrock 上的 Amazon Nova Canvas v1.0 模型，基于 outpainting 进行背景替换。更多代码示例请参阅[代码示例](https://docs.aws.amazon.com/nova/latest/userguide/image-gen-code-examples.html)。

import io  #For handling byte streams

region = "us-east-1"

#Create Bedrock client with 300 second timeout

        config=Config(read_timeout=300))

#Original studio image of shoes in current working directory

#Read and encode the image

    with open(image_path, 'rb') as image_file:
        image_data = image_file.read()
        base64_encoded = base64.b64encode(image_data).decode('utf-8')
    return base64_encoded

#Get the base64 encoded image

#Set the content type and accept headers for the API call

#Prepare the request body

        "taskType": "OUTPAINTING",
        "outPaintingParams": {
             "image": input_image,
             "maskPrompt": "Shoes", 
             "outPaintingMode": "DEFAULT", 
             "text": "Product photoshoot of sports shoes placed on a running track outdoor",
             "negativeText": "bad quality, low res"
            },
        "imageGenerationConfig": {
             "numberOfImages": 1,
             "seed": 0, #Modify seed value to get variations on the same prompt
             "cfgScale": 7.0
            }
