# 用生成式 AI 加速营销创意构思——第 1 部分：借助 Amazon Nova 基础模型从想法到生成

营销团队面临越来越大的压力，既要快速创作有吸引力的营销活动，又要保持品牌一致性与创意质量。传统的营销活动创作流程往往涉及创意团队、利益相关方与外部代理机构之间的多轮迭代，导致周期延长、成本上升。

生成式模型（尤其是图像与视频生成模型）的出现与普及，使得在几分钟内快速迭代多个营销活动方案成为可能。尽管如此，借助生成式模型高效地创作营销活动，仍然需要高水平的能力与对生成式工具的熟练掌握，例如 prompt engineering、参数微调、guardrails 的应用等等。编辑、脚本撰写与后期制作技能对于打造出色的故事同样重要。

本文是三部曲中的第一篇，聚焦于如何使用 [Amazon Nova](https://aws.amazon.com/ai/generative-ai/nova/) 通过[生成式 AI](https://aws.amazon.com/ai/generative-ai/) 来简化、精简并加速营销活动的创作。我们展示 [Bancolombia](https://www.bancolombia.com/)——哥伦比亚最大的银行之一——如何试验使用 Amazon Nova 模型为其营销活动生成视觉素材。

## 现代营销活动的挑战

创作有吸引力的营销活动所面临的挑战远不止创意开销，它还在运营、财务与战略层面影响企业。传统的营销活动创作方式通常涉及内部团队、外部代理机构与利益相关方之间复杂的互动过程——每一方都有自己的优先级、反馈周期与审批流程。

传统营销活动创作中最显著的痛点之一，是这项工作本身极其耗时。从最初的概念开发到最终的素材产出，营销活动往往需要数周甚至数月才能从构思走向执行。这一延长的周期可能包含多轮修改、利益相关方审批与素材打磨，这些都会给内部流程带来额外开销。不过，谈到营销业务时，真正重要的是营销活动投放所处的语境。近期新闻、时尚趋势、新发布的产品以及一年中的季节等外部因素，都会影响用户对营销活动的接受度。这就是为什么时间对营销至关重要，一次延迟投放可能意味着错过关键窗口，或让竞争对手抢先抓住受众注意力。

这些传统方法在财务上的影响同样令人担忧。营销团队常常面临预算约束，却又被期望在多个渠道与投放形式上交付精致的营销活动，例如社交媒体帖子、短视频、落地页等等。与营销活动创作相关的成本——包括代理机构费用、制作开支以及延迟投放的机会成本——可能迅速攀升。根据 [Gartner 的一项调查](https://www.gartner.com/en/newsroom/press-releases/2024-05-13-gartner-cmo-survey-reveals-marketing-budgets-have-dropped-to-seven-point-seven-percent-of-overall-company-revenue-in-2024)，2024 年企业把营销预算从总预算的 9.9% 削减到 7.7%，进一步压缩了用于创作营销活动的资源与时间。正是这种预算紧缩，让 AI 工具对营销团队而言从可有可无变成了不可或缺。

除了时间与成本上的考量，营销团队还面临一种根本性的张力：他们必须在保持品牌标识一致的同时，以市场要求的速度创作新鲜、有吸引力的内容。内容还要在各类系统与格式之间实现个性化，而每种系统与格式都有自己的技术要求与最佳实践，这让挑战更加复杂。作为回应，我们看到企业正在彻底重新思考资源分配方式。许多企业正转向付费媒体，削减传统技术、精简人员编制，并收缩与代理机构的合作关系。这造成了一个有趣的局面：AI 工具一方面促成预算削减（通过让团队更高效），另一方面又帮助团队挺过这些削减。

现实世界的影响是显著的。使用生成式 AI 的营销团队如今可以在几小时内产出过去需要数天或数周才能完成的内容。这些工具不仅带来效率——它们还催生了全新的内容创作方式。这一技术转变，为部署先进的生成式模型创造了完美条件，使其能够以传统方法无法企及的规模产出高质量图像、视频及其他视觉素材。

## Amazon Nova 基础模型家族

Amazon Nova 是由 Amazon 创建的一系列[基础模型（FM）](https://aws.amazon.com/what-is/foundation-models/)，可通过 [Amazon Bedrock](https://aws.amazon.com/bedrock/) 使用 API 调用，其差异化优势在于出色的性价比。

该家族由以下子系列构成：

- **[Amazon Nova 理解模型](https://aws.amazon.com/ai/generative-ai/nova/understanding/)** – 接受文本、图像和视频输入并生成文本输出的理解模型。它们在能力、准确性、速度与成本等运行点上提供了广泛选择。由四个模型组成：Amazon Nova Micro、Amazon Nova Lite、Amazon Nova Pro、Amazon Nova Premier。
- [**Amazon Nova 创意内容生成模型**](https://aws.amazon.com/ai/generative-ai/nova/creative/) – 接受文本与图像输入并产出图像或视频输出的创意内容生成模型。由两个模型构成：[Amazon Nova Canvas](https://docs.aws.amazon.com/ai/responsible-ai/nova-canvas/overview.html)（图像生成）与 Amazon Nova Reel（视频生成）。
- [**Amazon Nova 语音到语音模型**](https://aws.amazon.com/ai/generative-ai/nova/speech/) – 仅包含一个模型 Amazon Nova Sonic，这是一个语音到语音模型，接受语音输入并生成语音与文本输出。该模型旨在提供实时、类人且上下文丰富的语音对话。

### 使用 Amazon Nova Canvas 生成图像

借助 Amazon Nova Canvas，你可以通过文本提示词生成写实的影棚级图像。Amazon Nova Canvas 能够生成最高 2K x 2K 的图像。它也能够利用文本提示词指导编辑，对已有图像进行图像编辑。请参阅 [Amazon Nova Canvas 可视化指南](https://aws.amazon.com/blogs/machine-learning/exploring-creative-possibilities-a-visual-guide-to-amazon-nova-canvas/) 探索 Nova Canvas 模型带来的可能性。要以编程方式生成图像，请输入以下代码：

```
import boto3
import base64
import io
import json
from PIL import Image
# Initialize the Bedrock client
bedrock_runtime = boto3.client(
    service_name="bedrock-runtime",
    region_name="us-east-1"  # Specify your region
)
# Define your prompt for image generation
prompt = "A serene mountain landscape with a lake at sunrise, photorealistic style"
# Create the request payload for Amazon Nova Canvas
request_payload = {
    "taskType": "TEXT_IMAGE",
    "textToImageParams": {"text": prompt},
    "imageGenerationConfig": {
           "cfgScale": 7,
           "seed": 42,
           "numberOfImages": 1,
           "width": 1024,
           "height": 1024
    }
}
# Call the Bedrock model
response = bedrock_runtime.invoke_model(
    modelId="amazon.nova-canvas-v1:0", 
    body=json.dumps(request_payload)
)
# Process the response
response_body = json.loads(response["body"].read())
image_base64 = response_body["images"][0]
# Convert base64 to image
image_data = base64.b64decode(image_base64)
image = Image.open(io.BytesIO(image_data))
# Save the image
image.save("generated_image.png")
print("Image generated and saved as 'generated_image.png'")
```

更多 Amazon Nova 示例请见 [Amazon Nova 示例 GitHub 仓库](https://github.com/aws-samples/amazon-nova-samples)。

你可以在 AWS 人工智能博客的 [Amazon Nova Canvas 与 Amazon Nova Reel 的图像与视频提示词工程](https://aws.amazon.com/blogs/machine-learning/image-and-video-prompt-engineering-for-amazon-nova-canvas-and-amazon-nova-reel/) 一文中了解 Amazon Nova Canvas 与 Amazon Nova Reel 的提示词工程。

## 使用 Amazon Nova 加速营销活动视觉素材的创作

为简化营销活动视觉素材的生成，我们提出一套由生成式 AI 辅助的自动化流程，用于从活动想法过渡到一组活动视觉素材。我们提出的流程如下：

- 你提供一段活动描述
- 系统自动检索与你当前活动相关的往期活动图像，你可以挑选那些更能代表新活动想法的图像
- 系统将生成一段参考提示词（使用 Amazon Nova Pro），用于借助 Amazon Nova Canvas 生成你的活动图像。你可以编辑这段提示词。
- 系统将为你的活动生成最多五张图像。

### 参考图像推荐

在提供图像描述之后，我们会在图像数据库中检索与我们的活动相关的图像。这样的检索会返回与活动主题密切相关的图像，它们曾用于往期活动并且在过去已被证明有效。用户可以选择其中一些参考图像，以引导新视觉素材的创作。这项技术是本系列下一篇文章的讨论主题。我们鼓励你阅读那篇文章，以更深入地了解我们如何使用多模态嵌入模型与向量数据库构建一个高效的搜索引擎。

### 使用大语言模型（LLM）创建良好的图像生成提示词

尽管 Amazon Nova 创意模型对西班牙语或德语等语言有一定理解，英语仍是唯一[完全支持的语言](https://docs.aws.amazon.com/nova/latest/userguide/what-is-nova.html#:~:text=PNG%2C%20JPEG-,Supported%20Languages,-English)。因此，用户应使用英语撰写提示词，以最大化 Amazon Nova 创意模型的能力。此外，为创意模型写提示词，需要与使用理解模型时不同的方法。即使是经验丰富的提示词工程师，也可能需要时间调整技巧，才能充分释放创意模型的潜力。对于刚接触基于 LLM 的内容生成的人来说，这条学习曲线可能尤为陡峭。

为应对这些挑战，我们使用一种[称为 metaprompting 的技术](https://www.prompthub.us/blog/a-complete-guide-to-meta-prompting)。这种方法是指示一个 LLM 为其他 FM 生成有效的提示词。例如，我们可以用 Amazon Nova Pro 为 Amazon Nova Canvas 撰写高质量的提示词以生成图像。

以下提示词模板展示了如何指示 Amazon Nova Pro 基于一段简单的图像描述（以粗体高亮）生成经过优化的文本到图像提示词：

```
You are a graphics designer named Joe that specializes in creating visualizations aided by text-to-image foundation models.

Your colleagues come to you whenever they want to craft efficient prompts for creating images with text-to-image foundation models such as Nova Canvas.
You always respond to your colleagues requests with a very efficient prompt for creating great visualizations using text-to-image foundation models.

These are some rules you will follow when interacting with your colleagues:

* Your colleagues will discuss their ideas in their native languages, so please be flexible.
* Your answers will always be in English regardless of the language your colleague used to communicate.
* Your prompt should be at most 512 characters. You are encouraged to use all of them.
* Do not give details about or resolution of the images in the prompt you will generate.
* You will always say out loud what you are thinking
* You always reason only once before creating a prompt
* No matter what you always provide a prompt to your colleagues
* You will create only one prompt
* If provided with reference image descriptions (will be in between <reference_image_description> XML tags) carefully balance the contributions of the campaigns description with the reference images to create the prompt
* Never suggest to add text to the images

Here are some guidelines you always follow when crafting effective image prompts:

* Start with a Clear Vision: Have a clear idea of the image you want the AI to generate, picturing the scene or concept in your mind in detail.
* Choose Your Subject: Clearly state the main subject of your image, ensuring it’s prominently mentioned in the prompt.
* Set the Scene: Describe the setting or background, including the environment, time of day, or specific location.
* Specify Lighting and Atmosphere: Use descriptive phrases for lighting and mood, like “bathed in golden hour light” or “mystical atmosphere”.
* Incorporate Details and Textures: Enrich your prompt with descriptions of textures, colors, or specific objects to add depth.
* Avoid using negation words in the prompt creation. The use of negations is prohibited since this usually yields unwanted effects in the generated images.
* Be Mindful of Length and Clarity: Effective prompts tend to be detailed but not overly long, providing key visual features, styles, emotions or other descriptive elements.
* Special tokens can be added to provide higher-level guidance: Like “photorealistic”, “cinematic lighting” etc. These act like keywords for the model.
* Logically ordering prompt elements and using punctuation to indicate relationships: For example, commas to separate independent clauses or colons to lead into a description.

Create a prompt for: A credit campaign for small coffee producers in the mountains of Colombia.

Output only the prompt
```

回答是：

```
A vibrant, photorealistic scene showcasing small coffee producers in the lush, 
green mountains of Colombia, bathed in golden hour light. Farmers, dressed 
in traditional attire, are engaged in the coffee harvesting process, surrounded 
by coffee plants and picturesque landscapes.The atmosphere is warm and inviting, 
with a focus on community and sustainable practices. Include elements like 
rustic wooden tools, ripe coffee cherries, and the majestic Andean backdrop. 
Avoid modern technology and urban elements.
```

如你所见，我们得到了一个符合 Amazon Nova Canvas 要求的提示词，并得到了一张高质量的图像。

我们的 metaprompt 模板包含四个部分：

- 我们设定人设与高层任务（高效地创建提示词）。
- 我们设定撰写提示词时应遵循的规则。例如，我们给出字符数限制，并要求模型只以英语作答。
- 我们设定描述提示词应如何构建的准则，但这些准则并非强制。其中还包含一些关于最终模型所使用关键词的提示，因此 metaprompt 会鼓励模型在输出中使用它们。
- 我们确定最终输出。

如果你想探索更多 metaprompting 思路，博客文章 [通过数据感知的提示词优化提升 Amazon Nova 迁移表现](https://aws.amazon.com/blogs/machine-learning/improve-amazon-nova-migration-performance-with-data-aware-prompt-optimization/) 提供了很好的洞见。关于为 Amazon Nova 理解模型撰写提示词的最佳实践，请参阅 [Amazon Nova 用户指南](https://docs.aws.amazon.com/nova/latest/userguide/prompting.html)。

## 实施最佳实践

本节为希望自动化营销活动生成的读者提出一组最佳实践。以下是一些技术考量与准则：

- **模块化架构** – 采用模块化方式实现解决方案，将图像搜索引擎与视觉生成组件分离。这便于维护与未来的增强。
- **无服务器优先** – 使用 AWS Lambda 和 Amazon API Gateway 等无服务器技术，以降低运营开销并提升可扩展性。
- **模型版本控制** – 跟踪你的实现中使用的 Amazon Nova 模型的具体版本。这有助于可复现性并便于排障。

关于安全最佳实践，请考虑以下准则：

- **最小权限访问** – 对所有组件使用遵循最小权限原则的 [AWS Identity and Access Management（IAM）](https://aws.amazon.com/iam/) 角色，尤其是在访问 Amazon Bedrock 与其他 AWS 服务时。
- **传输中与静态加密** – 确保所有数据（包括活动描述与生成的图像）在传输中与静态存储时都使用 [AWS Key Management Service（AWS KMS）](https://aws.amazon.com/kms/) 加密。
- **输入验证** – 对所有用户输入实施严格的输入验证，以帮助防止潜在的安全漏洞，尤其是在活动描述与提示词编辑阶段。
- **安全的 API 访问** – 使用 Amazon Cognito 进行用户身份认证与授权，以保护对 API 端点的访问。

为优化性能，请遵循以下准则：

- **缓存策略** – 使用 [Amazon ElastiCache](https://aws.amazon.com/elasticache/) 实现缓存层，存储频繁访问的数据，例如热门活动描述或常用参考图像。
- **异步处理** – 对于可能耗时较长的图像生成任务，实现异步处理以改善用户体验与系统响应性。
- **自动扩缩** – 为你的 Lambda 函数与 API Gateway 配置自动扩缩，以高效应对变化的负载。

关于错误处理与监控，请遵循以下准则：

- **全面的日志记录** – 使用 [Amazon CloudWatch](https://aws.amazon.com/cloudwatch/) Logs 实现详细日志记录，以捕获系统事件、用户操作与模型交互。
- **自动告警** – 设置 [CloudWatch 告警](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/AlarmThatSendsEmail.html) 以监控关键指标，并在出现异常或错误时发送通知。
- **优雅降级** – 设计系统以优雅地处理故障，例如 Amazon Nova 模型临时不可用的情况，通过实现恰当的备用机制来应对。
- **定期审计** – 定期审计你生成的内容，以核实是否符合品牌准则与伦理标准。

遵循这些最佳实践，你就能保持生成式 AI 营销活动解决方案可靠、安全且高效的实现。定期监控与维护有助于识别改进空间，并随着活动需求演进让系统保持优化。

## 结论

本文中，我们演示了如何使用 Amazon Nova 系列 FM 通过自动化的、AI 驱动的方法革新营销活动创作。通过结合用于智能提示词生成的 Amazon Nova Pro 与用于高质量图像创作的 Amazon Nova Canvas，我们展示了营销团队如何大幅减少产出有吸引力视觉素材所需的时间与资源，同时保持品牌一致性与创意质量。展望未来，该解决方案可以扩展以支持更多用例，例如：

- 与营销自动化服务集成
- 利用客户洞察进行高级个性化
- 多渠道活动素材生成
- 视觉内容的 A/B 测试自动化
