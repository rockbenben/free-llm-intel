# 使用 Strands Agents SDK 与 Tavily 构建动态网页研究 agent

*“Tavily 现已在 [AWS Marketplace](https://aws.amazon.com/marketplace/seller-profile?id=seller-mncovc7l7fqy2) 上提供，并与 Amazon Bedrock AgentCore Gateway 原生集成。这使开发者和企业能够更快地将实时网络智能嵌入安全的、由 AWS 驱动的 agent 之中。”*

![Tavily 搜索技术与 AWS Strands Agents 框架的合作关系可视化](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/07/31/image-1-31.png)

随着企业加速采用 AI，对能够自主收集、处理并综合信息的 agent 框架的需求不断增长。构建 AI agent 的传统方法往往需要大量编排代码、显式状态管理，以及难以维护和扩展的僵化架构。

[Strands Agents](https://strandsagents.com/latest/) 通过应对这些挑战简化了 agent 开发。它引入了以模型为中心的范式，将复杂性从硬编码逻辑转移到大型语言模型（LLM）本身。这大幅降低了开发开销，同时提升了 agent 的灵活性——例如，将对每种输入或输出类型编写显式逻辑的需求降到最低。通过将逻辑直接嵌入模型，只需在新一代更强的模型发布时替换模型，就能显著提升 agent 的能力。

本文介绍如何将 Strands Agents 与 Tavily 专为网络智能构建的 API 相结合，打造强大的研究 agent，在出色完成复杂信息收集任务的同时，满足企业部署所需的安全与合规标准。

## Strands Agents SDK：以模型为中心的 agent 框架

Strands Agents SDK 是一个开源框架，通过采用模型驱动的方法革新了 AI agent 开发。它提供了一个代码优先、轻量而强大的框架，用于构建 agentic 工作流。Strands Agents SDK 不需要复杂的编排代码，而是通过三个主要组件帮助开发者创建精巧的 agent：

- **Models** – 提供与领先 LLM 提供商（包括 [Amazon Bedrock](https://aws.amazon.com/bedrock/)、Anthropic、Ollama 和 LiteLLM）的灵活集成，并提供可扩展接口以便实现自定义模型提供商。
- **Tools** – 允许 agent 与外部系统交互、访问数据并操作其环境。Strands Agents 提供 20 多项内置工具能力，并帮助开发者使用简单的 Python 函数装饰器创建自定义工具。
- **Prompts** – 支持以自然语言指令引导 agent 的行为和目标。

Strands Agents 提供先进而丰富的功能集。借助 Strands Agents SDK，开发者可以用最少的代码构建智能 agent，同时保持企业级能力：

- **安全与负责任的 AI** – 提供与 guardrail 的无缝集成，用于内容过滤、个人可识别信息（PII）保护等
- **简化的 agent 开发生命周期** – 帮助开发者在本地运行 agent，并构建可自动化、作为持续集成与交付（CI/CD）pipeline 一部分的复杂评估工作流
- **灵活部署** – 支持多种部署选项，从专用服务器到无服务器
- **可观测性** – 支持 OpenTelemetry 标准，用于传输日志、指标和 trace

Strands Agents 抽象掉了构建、编排和部署智能 agent 的复杂性，提供基于自然语言的交互与控制，并结合动态输出生成。其结果是更直观、更强大的开发体验。

## Tavily：面向 AI agent 的安全、模块化网络智能

Tavily 是专为 LLM agent 设计的 API 优先的网络智能层，为实时搜索、高保真内容抽取和结构化网络爬取提供支持。Tavily 面向构建基于 AI 的系统的开发者，在精确性、速度和模块化方面精心设计。它为 Strands Agents 等 agent 框架提供无缝的集成体验。Tavily 的 API 是受领先 AI 公司信赖的企业级基础设施层。它将强大的能力与生产级的运营保证相结合，例如：

- [SOC 2 Type II 合规](https://trust.tavily.com/) – 支持一流的安全与隐私态势
- [零数据保留](https://www.tavily.com/privacy) – 不存储任何查询、payload 或用户数据，从而符合严格的内部政策和监管框架
- [与 Amazon Bedrock 和私有 LLM 即插即用](https://docs.tavily.com/sdk/python/reference#tavily-hybrid-rag-client-setup) – 支持混合云部署、私有语言模型使用以及对延迟敏感的推理栈
- [模块化端点](https://docs.tavily.com/documentation/api-reference/introduction) – 为 agent 风格的交互而设计，Tavily 提供以下专用 API：  **Search** – 在公共网络上检索按语义排序的链接和内容片段，可按域、时效或数量过滤 **Extract** – 从已知 URL 拉取原始内容或清洗后的 markdown，用于摘要、问答或嵌入 **Crawl** – 通过链接递归遍历网站，以模拟探索行为并构建站点地图

每个端点都以独立工具的形式暴露，这意味着它们可以被快速包装进你的 agent 框架的工具 schema（例如 OpenAI 的 tool-calling、LangChain、Strands 或基于 ReAct 的实现）。

## 将 Strands Agents 与 Tavily 网络基础设施相结合

通过将 Strands Agents SDK 的灵活性与 Tavily 的实时网络智能能力相结合，开发者可以构建动态的、由 LLM 驱动的 agent，使其与互联网进行智能交互。这些 agent 可以对开放式查询进行推理，基于自然语言 prompt 做出决策，并自主从网络收集、处理并交付洞见。这种集成适用于各种基于 agent 的应用。例如：

- 客户成功 agent 主动检索最新的产品文档、政策更新或外部 FAQ，以更快解决支持问题
- 内部员工助手同时从内部工具和公开可获取的信息中提取内容来回答工作场所问题，减少对知识孤岛的依赖
- 销售与营收 agent 及时呈现公司新闻和行业变化，以支持客户计划（account planning）和拓展

每个用例都受益于相同的基础：对开发者友好的 agent 框架、可组合的网络智能工具，以及 LLM 的决策能力。为了演示这在实践中如何组合起来，我们探讨一个聚焦的实现：一个为自主、高保真网络调查而设计的研究 agent。

## 研究 agent 示例

许多研究 agent 的实现需要大量开发工作，并依赖确定性逻辑或输入输出受限的工作流。相比之下，Strands 使开发者能够通过自然语言构建高度动态的 agent。Strands agent 使用 prompt engineering 动态生成多样的输出类型，并无缝接受各种自然语言输入。将 Tavily 与 Strands 结合，开启了一类专为深入、动态研究而打造的新型 agent。与硬编码的研究 pipeline 不同，这种组合帮助开发者实现以下目标：

- 在 Strands Agents 框架中将 Tavily 的端点（Search、Crawl、Extract）作为工具，快速开发强大的研究 agent，并提供对开发者友好的接口
- 将依赖 LLM 原生能力的复杂决策交给模型处理
- 随着每一代新模型（例如 Amazon Bedrock 上的 Anthropic Claude 或 [Amazon Nova](https://aws.amazon.com/ai/generative-ai/nova/)）的出现自动获得性能提升，因为灵活的 agent 架构只需极少的代码改动就能动态改进
- 将 Amazon Bedrock 的企业安全基础设施与 Tavily 的零数据保留策略相结合，为敏感研究任务打造高度安全的环境

将 Strands Agents 与 Tavily 的能力结合起来后，这些 agent 在收集行业情报并为组织提供关于趋势、竞争对手动态和新兴机会的实时洞见方面表现卓越。agent 可以开展全面的竞争分析，挖掘海量在线数据以识别行业参与者的优势、劣势和战略定位。在技术研究领域，这些 agent 能够快速吸收并综合来自多个来源的复杂信息，有助于加速创新和问题解决过程。此外，这类 agent 对监管合规监控极为宝贵：它们持续扫描并解读不断演变的法律环境，确保组织始终走在监管变化之前。Strands Agents SDK 的灵活性允许按特定行业需求进行定制——从客户服务自动化到复杂数据分析工作流，它同样有效。

## 解决方案概述

为了说明这种组合，我们创建了一个深度研究（deep researcher）实现（参见 [GitHub 仓库](https://github.com/strands-agents/samples/tree/main/03-integrations/tavily)），它使用 Strands Agents SDK 核心的 agent 循环能力，智能且自主地从 Tavily 的网络智能能力中做出选择。下图展示了该工作流。

我们将 Strands Agents SDK 配置为使用 Amazon Bedrock 上的 Anthropic Claude 4 Sonnet。Amazon Bedrock 是一项完全托管的服务，通过统一 API 提供来自领先 AI 公司的高性能基础模型（FM）供你选择。下图展示了解决方案架构。

![Deep Researcher Agent 的完整架构，说明用户、本地工具、Tavily API 与 AWS 服务之间的数据流](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/07/31/image-3-19.png)

该研究 agent 由三个主要组件构成：

- **大型语言模型** – 驱动 agent 理解查询并生成响应
- **工具** – 帮助 agent 使用 Tavily 的 API 从互联网收集信息、格式化响应，并以 Markdown 格式保存输出
- **系统 prompt** – 引导 agent 的行为，说明如何以及何时使用每个工具来实现其研究目标

在以下各节中，我们将更详细地讨论 LLM 和工具。

### 大型语言模型

LLM 会影响 agent 的行为以及所生成响应的质量。我们决定使用 Amazon Bedrock 上的 Anthropic Claude 4 Sonnet，因为它在规划和执行复杂任务方面表现出色，但你也可以使用 [Amazon Bedrock 支持的其他模型](https://docs.aws.amazon.com/bedrock/latest/userguide/models-supported.html)之一，或其他模型提供商。

```
from strands.models import BedrockModel
bedrock_model = BedrockModel(
    model_id="us.anthropic.claude-sonnet-4-20250514-v1:0",
    region_name="us-east-1",
)
agent = Agent(model=bedrock_model)
```

### 工具

工具有助于扩展 agent 的能力，并与 Tavily 等外部服务交互。我们实现了以下工具，使我们的 agent 能够在互联网上进行深度研究并提供格式化输出：

- **web_search** – 在网络上搜索相关信息
- **web_extract** – 从网页中抽取完整页面内容
- **web_crawl** – 爬取整个网站并抓取其内容
- **format_research_response** – 将原始研究内容转换为清晰、结构良好且引用正确的响应
- **write_markdown_file** – 将研究输出以 Markdown 格式保存到本地文件系统

要使用 Strands Agents SDK 定义工具，你只需用 @tool 装饰器包装一个 Python 函数，并提供包含工具描述的 Python docstring。让我们看一个示例，了解我们如何使用 Tavily 的搜索端点实现 web_search 工具。搜索端点让 agent 能够基于自然语言查询发现相关网页。结果包含 URL、标题、内容片段、语义分数，甚至匹配页面的完整内容。你可以使用以下参数微调搜索：

- **结果数量上限** – 将结果数量限制在一个上限之内
- **时间范围过滤** – 将结果限制在特定时间范围内发布的内容
- **域限制** – 将结果限制在特定域

参见以下代码：

```
@tool
def web_search(
    query: str, time_range: str | None = None, include_domains: str | None = None
) -> str:
    """Perform a web search. Returns the search results as a string, with the title, url, and content of each result ranked by relevance.
    Args:
        query (str): The search query to be sent for the web search.
        time_range (str | None, optional): Limits results to content published within a specific timeframe.
            Valid values: 'd' (day - 24h), 'w' (week - 7d), 'm' (month - 30d), 'y' (year - 365d).
            Defaults to None.
        include_domains (list[str] | None, optional): A list of domains to restrict search results to.
            Only results from these domains will be returned. Defaults to None.
    Returns:
        formatted_results (str): The web search results
    """
    client = TavilyClient(api_key=os.getenv("TAVILY_API_KEY"))
    formatted_results = format_search_results_for_agent(
        client.search(
            query=query,
            max_results=10,
            time_range=time_range,
            include_domains=include_domains
        )
    )
    return formatted_results
```

LLM 高度依赖工具的定义和描述来判断如何以及何时使用它们。为提高工具准确性，请考虑以下最佳实践：

- 清楚说明该工具应在何时使用及其功能
- 在函数签名中使用类型提示来描述参数、返回类型和默认值
- 详细说明每个参数，并提供可接受格式的示例

每个 Tavily 端点都可以作为独立工具暴露给语言模型，为 AI agent 提供灵活、细粒度的网络访问能力。通过组合这些工具，agent 在研究、摘要、竞争情报和决策等任务上的能力会大幅提升。你可以在 [GitHub 仓库](https://github.com/strands-agents/samples/tree/main/03-integrations/tavily)中找到其他工具的实现。
