# 赋能残障学生：University Startups 面向个性化学生路径的生成式 AI 方案

*本文由来自 University Startups 的 Laura Lee Williams 和 John Jabara 共同撰写。*

University Startups 总部位于马里兰州贝塞斯达，成立于 2020 年，旨在帮助高中生将教育拓展到传统课程之外。University Startups 专注于美国各地学区的特殊教育及相关服务。

高中毕业后，学生往往不知道自己想在教育和职业方面追求什么。University Startups 与 AWS 设计了一个独特的项目，帮助残障学生应对这一挑战。该项目为每名学生制定个性化的 transition plan，可在全国各地的学校使用。项目能为每名学生提供具体指导，帮助他们规划高中毕业后属于自己的成功之路。具体而言，University Startups 使用 [Amazon Bedrock](https://aws.amazon.com/bedrock/) 打造这种定制化体验，同时不增加教育工作者的工作量。在一项试点项目中，这一举措的影响力得到了成功验证：数十名师生使用 University Startups 的工具探索不同的职业路径，以及如何实现目标的建议。

在本文中，我们介绍 University Startups 如何在 AWS 上使用生成式 AI 技术，让学生能够为自己的未来——无论是继续深造还是就业——设计一份具体的计划。

## 特殊教育面临的挑战

特殊教育包括满足残障学生个人需求的服务和项目。美国有超过 750 万名 K-12 残障学生，且这一数字还在增长。需要特殊教育服务的残障学生拥有个性化教育计划（Individualized Education Program，IEP）。IEP 是一份法律要求的文档，由学生的家长、教师和专家共同制定，以确保学生的教育需求得到满足。这包括与普通教育同龄人一起学习普通教育课程，并尽可能就近入学。

IEP 文档的一个重要组成部分是 *transition plan*。transition plan 是一份阐明目标和发展方向的文档，旨在帮助残障学生为成年生活做好准备。它可以包括高等教育与职业目标规划、获得工作经验、独立生活，或任何适合该学生的选项。该计划高度个性化，贴合学生的兴趣、偏好、技能和需求。根据联邦法律，每名学生必须在 16 岁之前制定好 transition plan。

然而，资源不足学区的学校往往能力有限，无法为每名学生提供教师和心理辅导员充分的一对一关注，以制定有效的 transition plan。此外，由于这些 transition plan 要接受联邦和州政府的审计，如果计划不合规，这些学区可能面临法律和财务后果。这些挑战凸显出需要一套个性化且稳健的解决方案，为残障学生及其由家长、教师和专家组成的支持团队赋能。在此背景下，让我们看看 University Startups 与 AWS 如何合作，利用 Amazon Bedrock 开发解决方案，改进 transition plan 的制定流程。

## 解决方案概览

为应对这一挑战，University Startups 创建了 Trinity——一款 transition planning AI 助手，帮助残障学生发现自己的兴趣，制定有效且个性化的 transition plan。下图展示了如何在 workflow 中使用 Amazon Bedrock Agents，并配合其他工具，在收集信息以制定 transition plan 时提供上下文。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/07/30/ML-18688-diagramimage.png)

从宏观层面看，该解决方案使用 [Amazon Bedrock Agents](https://aws.amazon.com/bedrock/agents/) 编排完整的 workflow，通过交互式、个性化的 AI 助手体验吸引学生参与。这些 agent 使用 [AWS Lambda](https://aws.amazon.com/lambda) 函数安全地调用外部 API（例如招聘信息平台或大学数据库），获取最新的机会信息。此外，[Amazon Bedrock Flows](https://aws.amazon.com/bedrock/flows/) 可以自动完成个性化文档的生成：从这些交互中收集并综合信息，形成一份个性化的 transition plan 草稿。在整个过程中，[Amazon Bedrock Knowledge Bases](https://aws.amazon.com/bedrock/knowledge-bases/) 和 [Amazon Bedrock Guardrails](https://aws.amazon.com/bedrock/guardrails/) 等功能旨在提高所提供信息的准确性和可靠性，并使其符合安全与合规标准，为学生、家长和教育工作者构建一个安全有效的支持体系。

流程开始时，学生在教育工作者的指导下，与一个用 Amazon Bedrock Agents 构建的 agent 互动，发掘自己的偏好和兴趣。随后，该 agent 会针对学生可以在 transition plan 中探索的路径提出量身定制的建议。这些建议基于提供给 agent 的上下文，包括 IEP 文档的要求和常见的 transition plan 结构。根据这些输出，学生的家长和教师可以高效地与学生共同制定 transition plan，或继续与该 agent 互动以深入探讨。下一节我们将仔细看看这个 agent 使用的工具。

## Amazon Bedrock Agents 使用的工具和功能

Amazon Bedrock Agents 的有效性在于，它能以富有成效的方式吸引学生参与，并为家长和教育工作者提供可操作的结果。这是通过使用 Amazon Bedrock 内的功能（如 Amazon Bedrock Knowledge Bases 和 Amazon Bedrock Guardrails），并结合包括 Lambda 在内的其他 AWS 服务，为 agent 创建工具来实现的。

### 维护学生安全

该应用的一个关键组成部分是在设计时将学生安全牢记于心，尤其是在处理个人身份信息（personally identifiable information，PII）和受保护健康信息（protected health information，PHI）时。如果没有适当的保护，就可能存在数据泄露和违反合规法规的风险。

我们使用 Amazon Bedrock Guardrails 在生成式 AI 系统中实施防护措施。如果用户输入 PII 或 PHI 数据，Amazon Bedrock Guardrails 会检测到并自动拦截该请求，并返回一条预先配置的消息，例如“抱歉，你的查询违反了我们的使用政策。”我们还使用 Amazon Bedrock Guardrails 对模型响应中的 PII 进行脱敏。如果在模型响应中检测到敏感信息，guardrail 会用一个标识符（例如 {NAME-1}）对其进行掩码处理。

Amazon Bedrock Guardrails 还有助于确保该资源仅用于预期目的。技术常常让学生分心，但 Amazon Bedrock Guardrails 可以配置一组拒绝主题和内容过滤器，让学生保持专注。

### 使用相关上下文

法律要求 transition plan 包含关于学生的具体信息。然而，美国各地并没有统一的 IEP 文档格式要求。各州可能有不同的标准化格式，在某些州，各个学校系统还会设计自己的表格。

因此，该资源需要能够收集所需信息，并根据使用它的学校系统以适当的格式呈现。我们使用 Amazon Bedrock Knowledge Bases 为 agent 提供必要的上下文，使其能够针对每个用例给出准确、定制化的响应。

## 用例

为了理解该解决方案的影响并展示 Amazon Bedrock Agents 的实际运作，我们来看一个例子：学生 Noah 在试点项目中使用了 University Startups 的资源。

Noah 正准备为自己的 IEP 文档制定 transition plan。他就读的学区使用了 University Startups 的资源，因此他创建了一个账户，以获得针对其 IEP 的个性化输出。系统 agent 开始收集需求：

- agent 首先询问 Noah 目前的表现以及他可能需要的任何特殊要求。接着，agent 请 Noah 分享自己的兴趣和技能，以及高中毕业后可能想追求的方向。Noah 表示他对犯罪学感兴趣。
- 随后，agent 使用 Amazon Bedrock Guardrails 对可能已输入的敏感信息进行编辑。然后，它使用工具就 Noah 如何从事犯罪学职业提供建议，包括高等教育和实习机会。这些建议根据 Noah 的需求和地域偏好为他量身定制。
- Noah 随后选择探索另一条路径选项，系统向他提供了步骤，以发现从事犯罪学职业的其他方法。
- 最后，Noah 对收到的结果和建议感到满意，这些信息被格式化为一份 transition plan 草稿。随后，草稿被交给负责制定和定稿其 IEP 的教育工作者团队。

这一探索过程帮助 Noah 充分发掘自己的兴趣和选择，同时让他确信这些建议是根据自身需求量身定制的。它也减少了教育工作者为 IEP 会议和提交材料做准备所需的时间。

## 已验证的影响

University Startups 开发的这一解决方案，为教育工作者和学生制定 transition planning IEP 文档提供了一种安全高效的方式。通过自动化规划阶段，学生可以从容探索自己的兴趣以及高中毕业后的不同路径。在需要特殊协助的情况下，该工具还能支持师生之间的对话。一位参与试点项目的教师表示：“我认为 Trinity 是一款很棒的工具。我希望看到家长和学生一起使用它，尤其是在 IEP 会议之前。我也认为它是学生与其个案工作者/辅导员之间很好的谈话切入点。”即使在资源匮乏的学区，学生也能获得根据其需求量身定制的个性化关注，在 transition planning 过程中体现自己的视角。

对教育工作者而言，准备 transition planning 可能耗时良久，且需要高度专业化的知识。然而，使用 Trinity 资源约 10 分钟即可产出结果，有望减少教育工作者在 transition planning 上花费的平均时间。这使他们能够扩大工作规模，把时间集中在为每名学生带来可操作的结果上。

此外，该工具能够吸引学生认真分享自己的兴趣和技能。试点项目参与者 Noah 表示：“使用这个工具既简单又有帮助；它很快就向我展示了通往我未来想做工作的路径。”最重要的是，尽管该解决方案自动化了制定 transition plan 的探索过程，但它保证在每一步以及学生请求帮助时都有教育工作者亲自提供支持。在整个试点项目中，教育工作者更倾向于通过 Trinity 工具引导学生，提供一对一支持。这确保学生在整个过程中都有被认可的感觉，也确保教育工作者能够调整并验证所提供的 transition plan 建议。

## 结论

通过该解决方案，University Startups 证明了即使在资源匮乏的学区，学生（包括残障学生）也能获得个性化服务。该解决方案能够赋能学生追求自己的兴趣，制定可操作的计划，以培养技能并取得成功。将生成式 AI 融入教育资源，展示了 AI 在学习环境中的有效能力。由 Amazon Bedrock 驱动的教育工具能够处理学生多样化的需求并提供即时反馈，从而简化教育工作者创建个性化学习路径的工作。这让每位学生都能获得高质量、自适应的教学。

University Startups 联合创始人 John Jabara 分享道：

> “Amazon Bedrock 让我们得以创建一款工具，在这个重要的 transition planning 过程中捕捉学生的声音。”

截至本文发表之日，University Startups 已在 15 个州开展业务。随着 University Startups 持续扩大规模，他们计划将服务范围扩展至全国。像 Amazon Bedrock Agents 和 Amazon Bedrock Guardrails 这样的工具，在让学生平等获取教育和职业资源方面潜力巨大，而 Amazon Bedrock 正处于这一举措的前沿。
