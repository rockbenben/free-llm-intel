Agentic retrieval on fully managed Amazon Bedrock knowledge bases now integrates with

Amazon Bedrock AgentCore Memory

. Use the

memoryConfiguration

field on

AgenticRetrieveStream

to configure memory. You can restore an earlier session from short-term memory, let the agent retrieve memory records from long-term memory, or both. For more information, see

Use agentic retrieval to query a knowledge base

.
