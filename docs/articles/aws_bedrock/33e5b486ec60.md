# Pattern PXM 的 Content Brief 如何借助 AI 在电商平台上驱动转化

如今，品牌要同时应付无数事务，而让产品内容保持最新排在首位。既要解读各个平台没完没了的要求，又要在多渠道之间理清库存，还要调整产品 listing 以吸引顾客的目光，同时努力跑在不断变化的趋势和激烈竞争之前——这确实负担很重。而且说实话，想在电商这场游戏中保持领先，感觉就像在一台不断加速的跑步机上奔跑。对许多品牌来说，结果就是错失机会，以及未能完全达标的收入。

> “管理品类繁多的产品和零售商之所以极具挑战，是因为内容要求、图片、不同地区的不同语言、格式乃至所服务的目标受众都各不相同。”
>         ——Martin Ruiz，Kanto 内容专家

[Pattern](https://pattern.com/) 是电商加速领域的领先者，通过自有技术与按需专业能力的结合，帮助品牌应对在平台上销售的复杂性并实现盈利增长。Pattern 成立于 2013 年，现已扩展到全球 22 个地点、超过 1,700 名团队成员，以满足对专业电商能力日益增长的需求。

Pattern 拥有超过 38 万亿个自有电商数据点、12 项技术专利及待批专利，以及深厚的平台运营专长。Pattern 与数百个品牌（如 Nestle 和 Philips）合作，推动收入增长。作为 Amazon 上最大的第三方卖家，Pattern 利用这些专长同时优化产品 listing、管理库存，并提升品牌在多个服务上的曝光度。

本文分享 Pattern 如何利用 AWS 服务处理数万亿个数据点，交付可执行的洞见，并跨多个服务优化产品 listing。

## Content Brief：以数据为支撑的产品 listing 内容优化

Pattern 最新的创新成果 [Content Brief](https://pattern.com/blog/optimize-your-ecommerce-listings-with-pattern-pxms-content-brief) 是一款强大的 AI 驱动工具，旨在帮助品牌优化产品 listing，并加速在各大电商平台上的增长。Content Brief 借助 Pattern 超过 38 万亿个电商数据点的数据集，提供可执行的洞见和建议，帮助打造出色的产品内容，带来流量与转化。

Content Brief 分析消费者人口特征、发现行为和内容表现，让品牌全面了解其产品在平台上的位置。过去通常需要数月研究与工作的事情，现在几分钟就能完成。Content Brief 用能承担繁重工作的工具，为产品策略去掉猜测成分。其属性重要性排名会告诉你哪些产品特性值得重点呈现，而图片原型分析则确保你的视觉素材能吸引顾客。

如下图所示，图片原型功能会展示在某个品类中驱动销量的属性，让品牌能够在图片区块和 A+ 图片内容中突出最具影响力的特性。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/02/26/Picture1-new.png)

Content Brief 集成了评论与反馈分析能力。它使用情感分析处理顾客评论，识别正面和负面反馈中反复出现的主题，并标出潜在的可改进之处。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/02/26/Picture21-new.png)

Content Brief 的 Search Family 分析会把相似的搜索词归为一组，帮助品牌理解不同的顾客意图并据此调整内容。该功能结合细致的用户画像洞见，帮助营销人员为特定人群创作高度针对性的内容。它还提供竞品分析，与竞争产品做并排比较，突出品牌产品表现突出或需要改进的方面。

> “这正是我们作为企业最需要的东西。我们拥有各种倾听工具、评论情感和关键词工具，但没有一个像这样把所有东西放在同一处、还能针对我的 listing 做优化。一想到把所有那些修改写回我的 PIM 再分发到所有零售商，我就起鸡皮疙瘩。”
>         ——某财富 500 强品牌的市场营销高管

使用 Content Brief 的品牌能够更快发现增长机会、适应变化，并在数字市场中保持竞争优势。从搜索优化和评论分析，到竞品基准对比和用户画像定向，Content Brief 让品牌能够创作出有吸引力、以数据为支撑的内容，同时带来流量与转化。

Select Brands 希望提升其在 Amazon 上的表现，于是与 Pattern 合作。Content Brief 的洞见带来了更新，使其 Triple Buffet Server 这一 listing 的图片组合发生了转变。他们原来的图片组合是按平台要求制作的，而新的图片组合则根据品类和销售数据中应突出哪些产品属性的洞见做了优化。更新后的图片组合以醒目的产品亮点为特色，并用生活场景图片吸引顾客。结果是收入环比（MoM）增长 21%、流量增加 14.5%、转化率提升 21 bps。

> “Content Brief 完美说明了我们为什么选择与 Pattern 合作。仅测试一个月，我们就看到它对推动增量增长有多大的作用——即便是对已经表现不错的产品也是如此。我们有一款产品，与 Pattern 一起在不到两年时间里成长为该品类中的头部产品；而看到再加上这一层能力后，连我们本就认为很强的这款产品也能继续增长收入，着实令人兴奋。”
>         ——Eric Endres，Select Brands 总裁

想了解 Content Brief 如何帮助 Select Brands 提升其在 Amazon 上的表现，请参阅[完整案例研究](https://pattern.com/news/pattern-unveils-content-brief-by-pattern-pxm)。

## Content Brief 的 AWS 技术基座

Pattern 架构的核心，是一套精心编排的 AWS 服务。[Amazon Simple Storage Service](https://aws.amazon.com/s3/)（Amazon S3）作为存储产品图片的基石，这对全面的电商分析至关重要。[Amazon Textract](https://aws.amazon.com/textract/ocr/) 用于从这些图片中提取并分析文本，为产品呈现方式提供有价值的洞见，并支持与竞品 listing 做比较。同时，[Amazon DynamoDB](https://aws.amazon.com/dynamodb/) 充当 Content Brief 快速数据检索与处理能力的动力引擎，存储结构化与非结构化数据，包括 content brief 的对象 blob。

Pattern 的数据管理方式既创新又高效。随着数据的处理与分析，他们会在 DynamoDB 中为每个 content brief 创建一个外壳，在数据被处理和精炼的过程中逐步注入。这种方法支持快速访问部分结果，并能按需做进一步的数据转换，确保品牌能够获得最新的洞见。

## 扩展以处理 38 万亿个数据点

处理超过 38 万亿个数据点绝非易事，但 Pattern 用一套精细的扩展策略应对了这一挑战。该策略的核心是支持 GPU 的 [Amazon Elastic Container Store](https://aws.amazon.com/ecs/)（Amazon ECS），它承担自然语言处理和数据科学中计算密集的任务。这一配置让 Pattern 能根据需求动态扩展资源，即便在处理高峰期也能提供最佳性能。

为管理各 AWS 服务之间复杂的数据流转，Pattern 使用了 Apache Airflow。这一编排工具通过一个主 DAG 管理错综复杂的数据流转，并按需创建和管理大量子 DAG。这种对 Airflow 的创新用法，让 Pattern 能够在大规模下高效管理复杂且相互依赖的数据处理任务。

但扩展不只关乎算力——也关乎效率。Pattern 在其 AI 模型调用中实施了[批处理技术](https://aws.amazon.com/blogs/machine-learning/automate-amazon-bedrock-batch-inference-building-a-scalable-and-efficient-pipeline/)，在保持高吞吐的同时，使两批处理的成本最多降低 50%。他们还实施了[跨区域推理](https://aws.amazon.com/blogs/machine-learning/getting-started-with-cross-region-inference-in-amazon-bedrock/)，以提升不同地理区域的可扩展性与可靠性。

为了密切关注系统性能，Pattern 采用了 LLM 可观测性技术。他们监控 AI 模型的性能与行为，从而实现系统的持续优化，并确保 Content Brief 以最高效率运行。

## 使用 Amazon Bedrock 获得 AI 驱动的洞见

Pattern 的 Content Brief 方案中一个关键组件是 [Amazon Bedrock](https://aws.amazon.com/bedrock/)，它在他们的 AI 与机器学习（ML）能力中发挥关键作用。Pattern 使用 Amazon Bedrock 来实施一套灵活且安全的大语言模型（LLM）策略。

## 模型灵活性与优化

Amazon Bedrock 支持多种基座模型（FM），这使 Pattern 能够为每个具体任务动态选择最合适的模型。这种灵活性对于在 Content Brief 的各个方面优化性能至关重要：

- 自然语言处理——在分析产品描述时，Pattern 使用针对语言理解与生成优化的模型。
- 情感分析——在处理顾客评论时，Amazon Bedrock 支持使用针对情感分类微调过的模型。
- 图像分析——Pattern 目前使用 Amazon Textract 从产品图片中提取文本。不过，Amazon Bedrock 还提供先进的视觉语言模型，未来有可能增强图像分析能力，例如细粒度的物体识别或视觉情感分析。

能够快速在不同 LLM 上做原型验证，是 Pattern AI 策略的关键组成部分。Amazon Bedrock 提供对各种前沿模型的快速访问，以促进这一过程，让 Pattern 能够持续演进 Content Brief 并利用 AI 技术的最新进展。如今，这使团队能够构建无缝集成，并使用针对不同任务定制的多种最先进语言模型，包括新的、高性价比的 [Amazon Nova 模型](https://aws.amazon.com/ai/generative-ai/nova/)。

## Prompt 工程与效率

Pattern 的团队建立了一套精细的 prompt 工程流程，不断打磨 prompt 以同时优化质量与效率。Amazon Bedrock 支持自定义 prompt，让 Pattern 能够把模型行为精准地调整到符合自身需求，提升 AI 生成洞见的准确性与相关性。

此外，Amazon Bedrock 提供高效的推理能力，帮助 Pattern 优化 token 使用量，在保持高质量输出的同时降低成本。在处理全面电商分析所需的海量数据时，这种效率至关重要。

## 安全与数据隐私

Pattern 使用 Amazon Bedrock 的内置安全功能来保障数据保护与合规。通过采用 [AWS PrivateLink](https://aws.amazon.com/privatelink/)，Pattern 的虚拟私有云（VPC）与 Amazon Bedrock 之间的数据传输经由私有 IP 地址进行，绝不会穿越公共互联网。这种方法通过减少暴露于潜在威胁的机会，显著提升了安全性。

此外，Amazon Bedrock 的架构确保 Pattern 的数据在整个推理过程中始终留在其 AWS 账户内。这种数据隔离提供了额外一层安全保障，并有助于保持对数据保护法规的合规。

> “在不断演进的 AI 格局中，Amazon Bedrock 的灵活性至关重要，它让 Pattern 能够为其多样的电商分析需求使用最有效、最高效的模型。该服务稳健的安全功能和数据隔离能力让我们安心，因为我们知道自己的数据和客户信息在整个 AI 推理过程中都受到保护。”
>         ——Jason Wells，Pattern 首席技术官

在 Amazon Bedrock 之上，Pattern 打造了一套安全、灵活且高效的 AI 驱动方案，并持续演进以满足电商优化的动态需求。
