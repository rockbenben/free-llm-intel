# 用视觉语言模型扩展数据标注规模，为物理 AI 系统提供动力

严重的劳动力短缺正在制约制造业、物流、建筑和农业的增长。这一问题在建筑业尤为严峻：美国有近 [500,000 个岗位](https://www.abc.org/News-Media/News-Releases/abc-construction-industry-must-attract-439000-workers-in-2025)仍然空缺，而现有劳动力中有 [40%](https://www.adp.com/spark/articles/2019/02/construction-grows-but-baby-boomers-retiring-leaves-gap.aspx?q1=ES_FY25_SparkSubscribePopup)将在十年内步入退休。这些劳动力限制导致项目延期、成本攀升、开发计划被搁置。为应对这些制约，各类组织正在开发自主系统，由它们承担填补产能缺口、扩展运营能力的任务，并额外带来全天候生产力的收益。

构建自主系统需要大规模、已标注的数据集来训练 AI 模型。训练是否有效，决定了这些系统能否创造业务价值。瓶颈在于数据准备成本高昂。关键在于，对视频数据做标注——识别设备、任务与环境的相关信息——是确保这些数据可用于模型训练的必要环节。这一步可能阻碍模型部署，进而拖慢 AI 驱动的产品与服务交付给客户的速度。对于管理数百万小时视频的建筑公司而言，人工完成数据准备与标注已变得不切实际。视觉语言模型（VLM）通过解读图像与视频、响应自然语言查询，并以人工流程无法企及的速度和规模生成描述，帮助应对这一问题，提供了一种更具成本效益的替代方案。

本文将考察 [Bedrock Robotics](https://bedrockrobotics.com/)是如何应对这一挑战的。这家初创公司加入了 [AWS Physical AI Fellowship，](https://press.aboutamazon.com/aws/2025/9/massrobotics-aws-and-nvidia-launch-first-of-its-kind-physical-ai-fellowship)并与 [AWS Generative AI Innovation Center](https://aws.amazon.com/ai/generative-ai/innovation-center/)合作，应用视觉语言模型分析建筑视频素材、提取作业细节，并大规模生成带标注的训练数据集，从而改进自主建筑设备的数据准备工作。

## Bedrock Robotics：加速自主建筑设备落地的案例研究

自 2024 年起，Bedrock Robotics 一直在为建筑设备开发自主系统。该公司的产品 Bedrock Operator 是一套改装式解决方案，将硬件与 AI 模型结合，使挖掘机及其他机械能够在极少人工干预下作业。这些系统能够以厘米级精度执行挖掘、平整和物料搬运等任务。训练这些模型需要海量捕捉设备、任务与周边环境的视频素材——这是一个资源消耗极高、限制了可扩展性的过程。

VLM 通过分析这些图像与视频数据并生成文本描述，提供了一种解决方案。这使它们非常适合标注任务，而标注对于教模型如何把视觉模式与人类语言关联起来至关重要。Bedrock Robotics 利用这项技术简化了训练 AI 模型所需的数据准备工作，使设备能够自主作业。此外，通过合理的模型选择与 prompt 工程，该公司将工具识别准确率从 34% 提升到 70%。这把一个依赖人工、耗时漫长的流程转变为自动化、可扩展的 data pipeline 解决方案。这一突破加速了自主设备的部署。

这种方法为面临类似数据挑战的组织提供了一个可复制的框架，也说明了在基础模型（FM）上的战略性投入如何带来可衡量的运营成果与竞争优势。基础模型是使用自监督学习技术在海量数据上训练出来的模型，它们学习到通用表征，可适配众多下游任务。VLM 借助这类大规模预训练技术打通视觉与文本模态，从而能够跨图像与语言进行理解、分析和内容生成。

下面几节将介绍 Bedrock Robotics 标注数百万小时视频素材的流程，以及基于 VLM 的解决方案如何加速创新。

### 借助 VLM 把非结构化视频数据转化为战略资产

要让建筑设备实现自主作业，就必须从数百万小时的非结构化作业素材中提取有用信息。具体而言，Bedrock Robotics 需要在各类场景中识别工具属具、任务和工地状况。下面的图片是该数据集的示例视频帧。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/02/23/ML-2046.png)

建筑设备会搭配多种工具属具，每一类都需要准确分类，才能训练出可靠的 AI 模型。Bedrock Robotics 与创新中心合作，把创新工作聚焦在几个关键工具类别上：用于物料搬运的吊钩、用于混凝土拆除的破碎锤、用于地面平整的平地板，以及用于窄幅开挖的挖沟斗。

这些标签使 Bedrock Robotics 能够挑选相关的视频片段，并汇总出涵盖多种设备配置与作业条件的训练数据集。

### 通过有针对性的模型优化加速 AI 部署

现成的 VLM（未经 prompt 优化的 VLM）在处理建筑视频数据时表现不佳，因为它们是在网络图片上训练的，而不是挖掘机驾驶舱里的操作员视角素材。它们无法应对异常角度、设备特有的视觉细节，或因扬尘和天气导致的低可见度。它们也缺乏领域知识，难以区分挖掘斗与挖沟斗这类视觉上相似的工具。

Bedrock Robotics 与创新中心通过有针对性的模型选择和 prompt 优化解决了这一问题。团队评估了多个 VLM——包括开源方案以及 [Amazon Bedrock](https://aws.amazon.com/bedrock/?trk=572ae9ee-3a0d-4258-a24e-f5396ba81e9b&sc_channel=ps&trk=572ae9ee-3a0d-4258-a24e-f5396ba81e9b&sc_channel=ps&ef_id=CjwKCAiAv5bMBhAIEiwAqP9GuLw3dn1-30JXV1Gp_ZbUUc95xhhediy4hz5I7deWIDFZmlrYJlYNWRoChVkQAvD_BwE:G:s&s_kwcid=AL!4422!3!692006004850!e!!g!!amazon%20bedrock!21048268689!159639953975&gad_campaignid=21048268689&gbraid=0AAAAADjHtp-0RFjGQ8flyK5hf96Q2Fi6X&gclid=CjwKCAiAv5bMBhAIEiwAqP9GuLw3dn1-30JXV1Gp_ZbUUc95xhhediy4hz5I7deWIDFZmlrYJlYNWRoChVkQAvD_BwE)中可用的 FM——随后细化了 prompt，加入每个工具的详细视觉描述、易混淆工具对的判别指引，以及逐步分析视频帧的操作说明。

这些修改将一个包含 130 个视频的测试集上的分类准确率从 34% 提升到 70%，视频处理成本为每小时 $10。这些结果说明 prompt 工程如何让 VLM 适配专门任务。对 Bedrock Robotics 而言，这种定制带来了更快的训练周期、更短的上线时间，以及一条随业务需求演进而具成本效益、可扩展的标注 pipeline。

## 前路：以自动化应对劳动力短缺

**竞争优势。** 对 Bedrock Robotics 来说，视觉语言系统使其能够快速识别并提取关键数据集，从海量建筑视频素材中获得必要的洞察。凭借 70% 的整体准确率，这一具有成本效益的方法为扩展模型训练所需的数据准备提供了实用基础。它表明，战略性的 AI 创新可以化解劳动力制约，并加速行业变革。那些简化了数据准备的组织能够加快自主系统部署、降低运营成本，并在受劳动力短缺影响的行业中开拓新的增长领域。借助这一可重复的框架，面临类似挑战的制造业与工业自动化领导者可以将这些原则应用于自身领域，打造差异化竞争优势。
