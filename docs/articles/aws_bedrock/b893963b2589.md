# Gen Digital 如何使用 Amazon Bedrock AgentCore Web 搜索构建 Norton Revamp 的 AI 策划新闻引擎

现在，您的职业声誉首先体现在网上。招聘人员在回电话之前会查看 LinkedIn。客户在预订第一次会议之前会检查您的数字形象。对于雄心勃勃的专业人士来说，这种转变是一个机会：精心设计的在线声音可以打开仅凭简历无法打开的大门。

但脱颖而出需要的不仅仅是内容生成。它需要实时了解当前正在发生的事情。一位专业人士若想打造生成型人工智能思想领袖的声誉，需要对今天的突破做出反应，而不是上周的头条新闻。随着人工智能产生的噪音充斥着信息流，观众比以往任何时候都更看重真实性和及时性。

*Amazon Bedrock AgentCore 上的网络搜索* 使这一切成为可能。我们构建了 [*Norton Revamp*](https://revamp.norton.com/)，这是一个由人工智能驱动的专业声誉管理平台。其核心是一个由 AI 策划的新闻引擎，由 AgentCore Web 搜索提供支持，它将每一个内容建议、目标推荐和新闻提要项目都建立在当前引用的网络知识中。该平台于 2026 年 3 月推出，由一小群工程师构建。

在这篇文章中，我们将向您展示 [Gen](https://www.gendigital.com/us/en/) 团队如何使用 [Amazon Bedrock AgentCore](https://aws.amazon.com/bedrock/agentcore/) Web 搜索在 Norton Revamp 中构建 AI 策划的新闻引擎，以帮助客户将想法转化为引人入胜的社交媒体帖子。

## 挑战：专业内容的实时基础

与依赖静态知识库的聊天机器人不同，Norton Revamp 需要了解每个用户专业领域*现在*的趋势。网络安全专家需要当今的威胁情报。营销领导者需要本周的行业转变。传统方法（自定义网络爬虫、第三方新闻 API、静态内容数据库）都需要权衡：基础设施开销、陈旧数据、供应商复杂性或数据流出风险。

在选择 AgentCore Web Search 之前，我们评估了三种替代方案。自定义爬虫需要持续维护和实时滞后。第三方新闻 API 添加了供应商合同、API 密钥管理和离开我们的 AWS 环境的数据。静态知识库永远是陈旧的。 AgentCore Web 搜索消除了这些担忧。它完全受管理，基础设施开销为零，完全在 AWS 内运行，数据出口为零，并返回带有 URL 和发布日期的引用来源。这使得个性化的实时新闻源能够大规模实现。

## AgentCore Web Search 如何为 Norton Revamp 提供支持

Amazon Bedrock AgentCore 上的 Web 搜索是一种完全托管的 Web 搜索功能，符合模型上下文协议 (MCP)。它可作为 AgentCore Gateway 上的托管连接器使用，这是 Amazon Bedrock AgentCore 的一项功能。我们的代理发送自然语言查询，网络搜索返回相关片段、源 URL、标题和发布日期，模型使用这些来生成接地响应。

此功能支持三个核心功能：

**人工智能策划的新闻提要**

每个用户都会获得个性化的内容流，其中包含与其目标相关的最新文章和热门主题。如果您正在建立生成式 AI 思想领袖的声誉，您的源会优先考虑通过 AgentCore Web 搜索实时获取的 AI 突破、行业分析和新兴用例。与静态 RSS 聚合器不同，提要是一个目标感知发现引擎，每次会话都会刷新。

**智能内容建议**

用户会收到人工智能生成的内容创意，这些内容创意是根据其空间中的热门话题量身定制的，这些内容创意是用自己真实的声音编写的，并具有可选的人工智能生成的视觉效果。 AgentCore Web 搜索的每一个建议都基于*今天*发生的事情。三步辅导流程（分析、优化、发布）引导用户从最初的想法到在 LinkedIn 和 X 上发布的内容，并带有反馈循环，因此每次迭代人工智能都会变得更加敏锐。

**趋势意识目标设定**

用户定义一个目标。人工智能构建了包含每周主题和里程碑的个性化路线图。 AgentCore Web 搜索将实时趋势数据输入到目标生成中，因此每周主题反映当前的行业动态。该系统从过去四个星期的活动中学习，随着用户的增长而更新推荐。

## 架构和技术堆栈

![事件驱动的新闻引擎架构，展示了 Amazon Nova、AgentCore Web 搜索和基于内容生成的 AI 学习系统](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/10/29/c-ml-22210-arch-diagram.png)

图 1：Norton Revamp 新闻引擎的事件驱动架构

集成遵循事件驱动的架构。当用户设置或更新其职业目标时，Amazon Nova（通过 Amazon Bedrock）会根据目标、近期活动和参与模式生成有针对性的搜索查询。代理将这些查询发送到 AgentCore Web Search，后者完全在我们的 AWS 环境中返回引用的结果。我们的人工智能学习系统根据相关性、新近度和来源可信度对结果进行排名。然后，排名结果将作为 Amazon Nova Lite 的基础上下文，以用户真实的声音生成内容建议。参与度数据反馈到查询生成中，使新闻引擎逐渐变得更加智能。

**生成式人工智能和机器学习堆栈：**

- **Amazon Bedrock** – 用于内容生成、个性化、后期分析（批处理模式）和内容辅导的核心生成 AI 引擎。
- **Amazon Nova (Nova Lite)** – 支持内容生成、目标创建和趋势分析的主要大语言模型 (LLM)。
- **Amazon Bedrock AgentCore 上的 Web 搜索** – 通过符合 MCP 的托管连接器为新闻引擎、内容基础和趋势发现提供支持的实时 Web 检索。
- **稳定性人工智能** – 图像生成。
- **Claude（通过 Amazon Bedrock）** – 用于复杂推理任务的附加 LLM 功能。

**基础设施：** 前端的 React、TypeScript 和 Tailwind CSS。后端有 Node.js、Amazon Elastic Container Service (Amazon ECS)、AWS Lambda、Amazon DynamoDB（具有复合键模式的多表）、Amazon API Gateway、Amazon Simple Storage Service (Amazon S3)、Amazon Simple Queue Service (Amazon SQS)、Amazon EventBridge、Amazon CloudFront、Amazon CloudWatch 和 AWS Secrets Manager。通过 Terraform 管理基础设施，通过蓝绿部署实现零停机发布。

**处理管道：** 该平台运行四个管道阶段：

- **完整扫描** – 提取多达 1,000 个历史帖子，存储在 Amazon S3 中，运行 Amazon Bedrock 批量分析以了解声誉影响。
- **每日扫描** – Amazon EventBridge 触发的增量分析。
- **每周目标生成** – Lambda 会考虑过去的参与数据以及来自 AgentCore Web 搜索的实时趋势数据来生成目标。
- **内容辅导** – 通过分析、优化、发布流程进行同步 Amazon Bedrock 调用，每个步骤均以 AgentCore Web 搜索结果为基础。

## AgentCore Web 搜索集成的最佳实践

对于考虑使用 AgentCore Web Search 进行实时落地的团队：

- **投资于查询生成 –** 结构良好的查询比开放式查询产生更好的结果，因此我们专注于我们的即时工程。
- **策略性缓存 –** 实时新鲜度是重点，但有些查询不需要重新执行每个会话。我们使用符合新鲜度要求的生存时间 (TTL) 值来缓存结果。
- **建立反馈循环 –** 跟踪用户参与的网络搜索结果并将该信号反馈到查询生成中。我们的新闻引擎的相关性在前 90 天内有所提高。
- **验证源质量 –** AgentCore Web 搜索返回源 URL 和发布日期。我们构建了一个轻量级的可信度评分层来优先考虑权威来源。
