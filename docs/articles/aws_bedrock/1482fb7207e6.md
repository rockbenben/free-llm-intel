# 能交易的 agent：介绍与 Coinbase 和 Stripe 共同打造的 Amazon Bedrock AgentCore payments

我们正处在软件构建和使用方式的根本性转变之中。AI agent 正在超越那些只会等待指令的助手。它们调用 API、访问 MCP server、与其他 agent 协作，并代表用户完成复杂的多步骤任务。随着 agent 承担越来越多样化的任务，围绕它们的生态系统也在以同样的速度扩张，以满足这一需求。

再往前看，服务、工具和内容都必须为人和 agent 而设计。agent 会在需要时自行发现、评估并支付资源，而这一切都在单个执行循环内完成。支撑它们的服务也必须按这种方式定价和消费：每次调用不到一美分，实时计费。x402、ACP、MPP 和 AP2 等早期协议正在开创这一形态，各团队也在试验支持支付的 agent。组成要素正在浮现，但 agentic 经济仍处于最早期阶段，支撑其规模化发展的基础设施尚不存在。对想抢先一步的开发者来说，这条路一直很难走：你要与每个服务提供商建立定制化的计费关系、安全地管理凭证、执行支出治理、应对合规要求，并在支离破碎的格局中编写编排逻辑。这需要数月的工程投入，而且风险很高：一个配置错误的支付流程不只是给出一个糟糕的答案，它会转移真金白银。

今天，我们宣布推出 Amazon Bedrock AgentCore payments（预览版），这是 Amazon Bedrock AgentCore 中的一组新功能，让 AI agent 能够即时访问并为其所使用的资源付费，例如网页内容、API、MCP server 和其他 agent。这些能力是我们与 Coinbase 和 Stripe 合作打造的，它们提供了支撑首批功能的钱包基础设施和支付轨道。

AgentCore 是用于规模化构建、连接和优化 agent 的平台，安全性在基础设施层强制执行，agent 无法绕过。来自 Cox Automotive、Thomson Reuters 和 PGA TOUR 等公司的开发者已经在用 AgentCore 构建能够跨复杂工作流进行推理、规划和行动的 agent。随着今天的发布，这些 agent 还可以进行交易，使用它们已经依赖的同一套身份系统、agent gateway 和可观测性。Amazon Bedrock AgentCore Payment 并不是一个外挂模块，而是 agent 所依托平台的原生能力，与 agent 的其他所有行为一样受同一套管控措施约束。

## 首个面向 agent 的托管式端到端支付能力

这标志着首批专为自主 agent 打造的托管支付能力问世，覆盖从钱包认证、交易执行到支出治理和可观测性的完整生命周期，让开发者可以专注于 agent 做什么，而不必操心它们如何付款。

借助这些能力，开发者可以构建能够触达所需任何资源的 agent，无论付费还是免费，都无需手工建立每一层计费关系。一个金融研究 agent 可以动态访问实时市场数据流和付费墙后的出版物，并代表最终用户为其使用的文章和数据点付费。一个编程 agent 可以按需调用专门的 API 和付费 MCP server，无论是私有包仓库、沙箱化执行环境，还是擅长某一件事的小众第三方 agent。随着市场成熟，agent 还能处理商业交易：代表用户预订机票、预订酒店，并在各商户平台完成购买。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/05/06/images-ML-20991-1.png.jpg)

要开始使用，开发者把 agent 连接到钱包或支付服务提供商，注册一个已注资的支付来源，并设置每个会话的支出限额。AgentCore 负责管理所有凭证认证和 token 生命周期。当 agent 在执行过程中遇到付费资源时，AgentCore 会处理协议协商、重试和支付，把交易路由到相应的提供商，而不打断 agent 的推理循环。每一笔交易都可以通过开发者已用于监控 agent 行为的同一套日志、指标和追踪来观察。

AgentCore 的设计目标是与任何框架和任何协议协同工作。我们把同样的灵活性带到了 Amazon Bedrock AgentCore payments 中。开发者不必追踪不断演变的支付协议格局，也不必锁定在单一标准上。在预览版中，我们支持 x402 协议，更多协议已在规划之中。随着新协议出现，我们会在平台层面加入支持，开发者无需重建自己的 agent。

“在 Warner Bros. Discovery，随着我们超越与第三方处理器的直接 API 集成，我们正在积极探索更灵活、更可扩展的支付方式。AgentCore payments 代表了一个很有前景的方向，让我们的团队可以试验各种可能的 agent 驱动体验——例如直播体育赛事和重磅影片等优质内容，能够在用户产生兴趣的那一刻被无缝呈现并完成交易。我们尤其关注评估它在减少工程开销、简化支付编排，以及引入受治理、可追溯的交易方面的潜力，以此探索潜在的下一代商业体验。”——Mit Majithia，Warner Brothers Discovery Inc. 执行副总裁

## 微支付预览：为 agent 工作流解锁付费数据、API 和内容

我们在预览版中支持的第一个用例，是 agent 通过即时微支付来访问 API、MCP server、网页内容和其他 agent。各类服务正迅速转向按使用付费模式，过去一年 AI agent 的网络爬取快速激增，而这些交易通常不到 1 美元，甚至只有区区几美分。

开发者可以使用 AgentCore SDK 或控制台，在现有 agent 上启用 Amazon Bedrock AgentCore payments。你可以选择 Coinbase 钱包或 Stripe Privy 钱包作为支付连接方式。两种选项都支持最终用户用借记卡通过稳定币或法定货币为钱包注资。guardrail 在多个层面强制执行。在 agent 能够交易之前，最终用户必须明确授权 agent 访问和使用其钱包。在运行时，支出限额按会话强制执行，让 agent 保持在为每次执行设定的预算之内。agent 永远不会获得无限制的资金访问权，它只在明确授权和既定限额内运作。

在底层，支付流程围绕 x402 协议构建——这是一个开放的 HTTP 原生支付标准，支持即时稳定币微支付。当 agent 向一个付费 endpoint 发送请求并收到 HTTP 402 “Payment Required”响应时，支付处理会使用已配置的钱包进行认证，执行稳定币支付，附上支付凭证，并把内容回传给 agent——这一切都在执行循环内完成。payment manager 负责编排整个流程，而支付限额则始终跟踪支出是否超出会话预算。启用之后，agent 会在执行过程中开始编排支付，并在 AgentCore 控制台中提供完整的可追溯性。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/05/06/images-ML-20991-2.jpg)

为了帮助 agent 自行找到商户，我们通过 AgentCore gateway 提供 Coinbase x402 Bazaar MCP server。这个 bazaar 提供一份经过整理的 x402 endpoint 清单，agent 可以搜索、发现它们，并在与自身任务相关时付费使用——把付费服务变成 agent 可以自行找到并使用的东西，而不必让开发者对每一次集成都进行硬编码。

Heurist AI 为 AI 经济提供全栈基础设施，正在构建一个代表最终用户执行财务分析的研究 agent，并使用 AgentCore 中的支付能力。“Heurist 正在为我们的研究 agent 使用 AgentCore payments，帮助最终客户进行金融和加密货币分析以及投资建议，”Heurist AI 创始人 JW Wang 表示，“最终客户可以为研究设定预算，agent 则使用 AgentCore payments 获取准确的实时数据，通常涵盖市场、社交情绪和新闻。我们得以用很少的工作量和几行代码，就快速把支付功能集成到 agent 中。”

## 与合作伙伴生态共同打造

Coinbase 开发了 x402 协议——这一开放标准正在机器对机器支付领域迅速获得认可——并构建了 CDP 钱包基础设施和便利化服务，为预览版的微支付流程提供支撑。Coinbase 多年来一直在 AWS 上进行创新，在加密货币交易所和开发者平台领域服务数百万客户。如今，我们作为 x402 Foundation 的成员携手合作，为 agent 经济建立开放标准。

“很快，进行交易的 AI agent 数量将超过人类，它们需要为互联网而生的货币——可编程、全天候、全球化。通过把 Coinbase 的稳定币基础设施和 x402 引入 AWS AgentCore，我们为开发者提供了完整的工具栈，用来构建能以软件速度转移资金的 agent，同时具备企业所期望的信任和合规性。”——Brian Foster，Coinbase 基础设施增长与战略负责人。

Stripe 正在帮助定义 agent 时代的商业运作方式，构建让 AI agent 能够代表企业和消费者发现、协商并完成交易的工具。随着新支付能力的推出，AgentCore 在预览版中集成了由 Privy 提供支持的 Stripe 钱包基础设施作为支付连接方式，让开发者从第一天起就能直接访问 Stripe 的支付基础设施。随着我们超越微支付范畴，AWS 和 Stripe 正携手探索支持法定货币支付的路径，把 Stripe 的全球支付覆盖能力与开发者已经在上面构建的 agent 平台结合起来。

“Stripe 正在为 AI 构建经济基础设施。要让 agent 成为有意义的经济主体，它们需要持有和支配资金的方式。这就是为什么我们很高兴与 AWS 合作，让面向 agent 的稳定币钱包能够方便地提供给 AgentCore 开发者。”——Henri Stern，Stripe 旗下公司 Privy 的 CEO。

## 我们的前进方向

微支付是第一步，它回应的是我们看到需求最迫切的早期 agent 对 agent 商业模式。超越微支付之后，我们自然会扩展到更广泛的商业流程——在这些流程中，agent 不仅代表其他 agent，更代表买家行事。比如一个 agent 代表客户预订机票、预订酒店，或在各商户平台完成购买。要实现这些，需要更深度地集成支付生态、支持更多协议、更强地验证买家意图，以及覆盖整个交易生命周期的端到端可观测性。这是未来的道路，我们正为此建设。

在每个阶段，开发者体验都保持一致：配置钱包、设定策略，然后你的 agent 就可以交易。变化的是 agent 能够支付的范围和方式。我们对未来充满期待。

## 开始使用

Amazon Bedrock AgentCore payments 今日起在美国东部（弗吉尼亚北部）、美国西部（俄勒冈）、欧洲（法兰克福）和亚太地区（悉尼）开放预览。可在 AgentCore 控制台开始使用。更多详情请阅读[文档](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/payments.html)。
