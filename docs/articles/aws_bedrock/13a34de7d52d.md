# 自主财资 agents：Trovata 如何在 Amazon Bedrock 和 AgentCore 上构建 AI 原生解决方案

企业财资团队长期面临一个难题：银行数据零散分布在数十个银行门户里，报表困在电子表格中靠手工整理，遗留的财资管理系统（TMS）又无法扩展以满足现代企业的需求。对财资团队而言，这些手工流程带来延误和差错，也让他们在最关键的时刻无法做出实时的现金决策。

Trovata 是一个 AI 原生的现金与流动性管理平台，直连 10,000 多家银行，通过单一云平台服务全球企业。2023 年，Trovata 推出了首个专为财资打造的生成式 AI。如今，随着 Trovata 最新的 AI 原生更新，他们已从输出洞察，演进到部署代表财资团队行事的自主 agents。

Trovata 的客户已经看到了可量化的成效：年化成本节省 100 万美元以上，每个会计团队每天节省 5 小时以上，年度 TMS 成本降低 77%，财资报表从数小时或数天缩短到不到一分钟。

在本文中，我们将探讨 Trovata 如何在 Amazon Bedrock 和 Amazon Bedrock AgentCore 上构建自主财资 agents、这套架构如何借助支持银行品牌 AI 部署的基于角色的访问控制（RBAC）来保障安全，以及 agentic 工作流如何把企业财资从手工操作转变为企业级的实时决策。

## 解决方案概述

Trovata 作为一套 AI 原生的财资操作系统运行，通过单一系统直连 10,000 多家银行，支撑现金报告、预测、分析和资金划转。

如今，财资团队面临三重压力：

- **分散的银行数据**散落在多个门户，需要手工汇总与对账。
- **手工报表与对账**耗费熟练团队成员数小时甚至数天的时间。
- **遗留的 TMS 应用**缺乏现代运营所需的云原生架构和 AI 能力。

Trovata 从 2023 年的首款财资生成式 AI，演进到具备自主 agents 的 AI 原生能力，代表着一次根本性的转变。解决方案从静态洞察转向代替财资团队持续运行的常驻 agentic 工作流。关键在于，Trovata AI 直接内建于财资操作系统之中。它不是叠加在上层的通用聊天机器人，而是与真实财资对象绑定的嵌入式智能，并经由 agents 提供一条受治理的自动化路径。

Trovata 选择 AWS 来完成这次转型，有三个原因：其 serverless、云原生基础设施支持实时执行；Amazon Bedrock 为自然语言查询和 AI 功能提供大型语言模型（LLM）推理；Amazon Bedrock AgentCore 则负责 agent 编排，并带来 RBAC 安全、快速部署和全球规模。

支撑 Trovata AI 原生解决方案的核心 AWS 服务包括：

- **Amazon Bedrock** – 用于自然语言理解与生成的 LLM 推理。
- **Amazon Bedrock AgentCore** – agent 编排、agentic 工作流与 RBAC 安全。
- **Serverless AWS 基础设施** – 企业级的实时执行。

## 架构图

Trovata AI 架构以运行在银行品牌、受 RBAC 保护的框架内的自主财资 agents 为核心。该解决方案由若干协同工作的关键组件构成：

- **Trovata AI Chat** – 对多银行财资数据做自然语言查询，用户可以提出诸如 *“昨天我们所有账户的净现金头寸是多少？”* 之类的问题，并立即得到准确的回答。
- **AI Insights** – 自动异常检测、差异解释和趋势分析，主动把关键信息呈现出来。
- **AI Agents** – 按计划、触发器或规则运行的常驻工作流，用于监控活动、解释差异、检测异常并自动推送更新，无需人工干预。
- **Agent Builder-Configurator** – 用于构建和配置财资 agents 的管理控制台，让团队完全掌控 agent 的行为与范围。
- **Enterprise RBAC** – 基于角色的访问控制保护 agentic 工作流，确保 agents 在与人类用户相同的权限边界内运行。

## 技术实现

Trovata 在 Amazon Bedrock AgentCore 上构建其 AI 原生解决方案，把自主 agents、自然语言查询和企业访问控制结合起来。后续小节介绍团队构建了什么、主要用例，以及背后的 AgentCore 能力。

### Trovata 构建了什么：AI 原生解决方案

Trovata AI 提供直接内嵌于 Trovata 财资操作系统中的自主财资管理 agents。这些 AI agents 把可重复的运营工作变成持续运行的常驻工作流。正是这类工作，耗掉了熟练专业人员大量时间。

Agents 按计划、触发器或规则运行，监控活动、解释差异、检测异常并自动推送更新。整个系统运行在 Amazon Bedrock AgentCore 上——一个专为企业 AI 打造的安全、隔离环境。当用户提问时，AI 通过 Trovata 自己的、经过验证的 API 层检索数据、加以分析，并在这套安全基础设施内给出回答。

### 主要用例

- **现金预测** – 借助情景建模，在多银行环境中自动完成现金流预测，取代基于电子表格的手工预测。
- **自然语言查询** – 企业用户用日常英语查询银行数据。例如：*“昨天我们所有账户的净现金头寸是多少？”*。
- **异常检测** – 实时检测异常交易、余额变动或现金流模式，这些可能意味着错误、欺诈或运营问题。
- **自动对账** – 由 AI 生成跨数百个账户的对账摘要，把过去要花数小时的工作缩短到几秒。
- **Agentic workflows** – 持续自主运行、无需人工干预即可监控、分析和报告的常驻 agents。

### 来自真实客户部署的十种 agent 模式

财资团队已经开始在生产环境中构建 AI agents。Trovata 的 AI Agents Playbook 提供了一个可用的库，收录从真实客户部署中提炼的十种 agent 模式，覆盖最常见、价值最高的财资工作流。如今，多数财资团队都有 5–15 个工作流可以直接交给 AI agents。

### Trovata 使用的 AgentCore 能力

Trovata 的实现用到了 Amazon Bedrock AgentCore 的几项关键能力：

- **agent 编排** – 面向需要顺序推理与行动的复杂财资操作的多步 agentic 工作流。
- **RBAC 安全** – 基于角色的访问控制保护 agent 的操作，确保 agents 遵守组织的权限边界。
- **实时执行** – Serverless 基础设施，可在数百个银行账户上实现亚分钟级的财资报表。
- **银行品牌部署** – agents 内嵌于银行品牌工具中，银行无需自己构建 AI 就能提供 AI 驱动的财资能力。
