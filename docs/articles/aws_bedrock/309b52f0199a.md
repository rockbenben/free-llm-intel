# 使用 Amazon Nova Sonic 部署全栈语音 AI agent

AI 驱动的语音解决方案正在改变联络中心：它们让客户与 AI agent 之间进行自然对话，缩短等待时间，并大幅降低运营成本——同时不牺牲客户期待的类人交互体验。随着 [Amazon Nova Sonic 近期发布](https://aws.amazon.com/blogs/aws/introducing-amazon-nova-sonic-human-like-voice-conversations-for-generative-ai-applications/) 并登陆 [Amazon Bedrock](https://aws.amazon.com/bedrock/)，您现在可以构建复杂的对话式 AI agent，通过语音自然交流，而无需单独的语音识别和文本转语音组件。Amazon Nova Sonic 是 Amazon Bedrock 中的语音到语音模型，支持实时、类人的语音对话。

虽然许多早期的 Amazon Nova Sonic 实现侧重于本地开发，但本解决方案提供了完整的云端部署架构，您可将其作为构建真实概念验证应用的基础。该资产可通过 [AWS Cloud Development Kit](https://aws.amazon.com/cdk/)（AWS CDK）部署，并利用预配置的基础设施组件为构建更多 Amazon Nova 用例奠定基础，同时允许您自定义架构以满足特定的业务需求。

在本文中，我们展示如何为一家名为 AnyTelco 的虚构公司创建 AI 驱动的呼叫中心 agent。这个名为 Telly 的 agent 可以处理客户关于套餐和服务的咨询，并使用通过 [Model Context Protocol](https://github.com/modelcontextprotocol)（MCP）框架实现的自定义工具访问实时客户数据。

## 解决方案概览

下图概述了可部署的解决方案。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/07/11/image-1-12.png)

该解决方案由以下分层组成：

- **前端层** – 该系统的前端层在构建时兼顾可扩展性和性能：[Amazon CloudFront](https://aws.amazon.com/cloudfront/) 分配作为 Web 应用的内容分发网络。[Amazon Simple Storage Service](https://aws.amazon.com/pm/serv-s3/)（Amazon S3）托管静态资产。UI 负责音频流处理和用户交互。
- **通信层** – 通信层促成无缝的实时交互：[Network Load Balancer](https://aws.amazon.com/elasticloadbalancing/network-load-balancer/) 管理 WebSocket 连接。WebSocket 使用户浏览器与服务器之间能够建立双向交互式通信会话，这对实时音频流应用至关重要。[Amazon Cognito](https://aws.amazon.com/cognito/) 提供用户认证和 JSON Web Token（JWT）校验。Amazon Cognito 为 Web 和移动应用提供用户认证、授权和用户管理，免去构建和维护自有身份系统的需要。
- **处理层** – 处理层构成系统的计算骨干：[Amazon Elastic Container Service](https://aws.amazon.com/ecs/)（Amazon ECS）运行容器化后端服务。[AWS Fargate](https://aws.amazon.com/fargate/) 提供无服务器计算后端。编排由 Amazon ECS 引擎提供。Python 后端处理音频流并管理 Amazon Nova Sonic 交互。
- **智能层** – 智能层利用 AI 和数据技术驱动核心功能：Amazon Bedrock 中的 Amazon Nova Sonic 模型负责语音处理。[Amazon DynamoDB](https://aws.amazon.com/dynamodb/) 存储客户信息。[Amazon Bedrock Knowledge Bases](https://aws.amazon.com/bedrock/knowledge-bases/) 将基础模型（FM）与组织的数据源连接起来，使 AI 应用能够引用与您的业务相关的准确、最新信息。

## 先决条件

开始之前，请确认您具备以下条件：

- [Python](https://www.python.org/downloads/) 3.12
- [Node.js](https://nodejs.org/en/download) v20
- [npm](https://docs.npmjs.com/downloading-and-installing-node-js-and-npm) v10.8
- 一个 [AWS 账户](https://signin.aws.amazon.com/signup?request_type=register)
- 已配置好 AWS CDK（先决条件和安装说明请参阅 [Getting started with the AWS CDK](https://docs.aws.amazon.com/cdk/v2/guide/getting_started.html)）
- 已在 Amazon Bedrock 中启用 Amazon Nova Sonic（更多信息请参阅 [Add or remove access to Amazon Bedrock foundation models](https://docs.aws.amazon.com/bedrock/latest/userguide/model-access-modify.html)）
- Chrome 或 Safari 浏览器环境（撰写本文时不支持 Firefox）
- 可用的麦克风和扬声器

## 部署解决方案

您可以在 [GitHub 仓库](https://github.com/aws-samples/sample-sonic-cdk-agent) 中找到该解决方案及完整部署说明。该解决方案使用 AWS CDK 自动化基础设施部署。在您的 [AWS Command Line Interface](https://aws.amazon.com/cli)（AWS CLI）环境中使用以下终端命令开始：

```
git clone https://github.com/aws-samples/sample-sonic-cdk-agent.git 
cd nova-s2s-call-center 

# Configure environment variables
cp template.env .env

# Edit .env with your settings

# Deploy the solution 
./deploy.sh 
```

部署过程会创建两个 [AWS CloudFormation](https://aws.amazon.com/cloudformation) 堆栈：

- 用于虚拟私有云（VPC）和网络组件的网络堆栈
- 用于应用资源的堆栈

第二个堆栈的输出会给出一个 CloudFront 分配链接，点击即可进入登录页。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/07/11/image-3-2-1.jpg)

您可以使用以下 AWS CLI 命令创建 Amazon Cognito 管理员用户：

```
aws cognito-idp admin-create-user \
  --user-pool-id YOUR_USER_POOL_ID \
  --username USERNAME \
  --user-attributes Name=email,Value=USER_EMAIL \
  --temporary-password TEMPORARY_PASSWORD \
  --region YOUR_AWS_REGION
```

上述命令使用以下参数：

- `YOUR_USER_POOL_ID`：您的 Amazon Cognito user pool 的 ID
- `USERNAME`：为该用户设定的用户名
- `USER_EMAIL`：该用户的电子邮件地址
- `TEMPORARY_PASSWORD`：为该用户设置的临时密码
- `YOUR_AWS_REGION`：您的 AWS 区域（例如 `us-east-1`）

使用临时密码从 CloudFront 分配链接登录，系统会要求您设置新密码。

您可以选择 **Start Session** 开始与助手对话。针对您的用例尝试不同的 prompt 和工具。

## 自定义应用

该解决方案的一个关键特性是其灵活性——您可以根据具体用例定制 AI agent 的能力。示例实现通过自定义工具和知识集成展示了这种可扩展性：

- **客户信息查询** – 使用电话号码作为键从 DynamoDB 检索客户档案数据
- **知识库搜索** – 查询 Amazon Bedrock 知识库以获取公司信息、套餐详情和定价

这些功能展示了如何借助外部数据源和领域特定知识增强 Amazon Nova Sonic 的功能。该架构在若干关键方面专为无缝自定义而设计。

### 修改 system prompt

该解决方案包含一个 UI，您可以在其中通过修改 system prompt 来调整 AI agent 的行为。这可以快速迭代 agent 的人设、知识库和对话风格，而无需重新部署整个应用。

### 添加新工具

您还可以通过使用 MCP 框架实现额外的工具来扩展 AI agent 的能力。该过程包括：

- 实现工具逻辑，通常作为一个新的 Python 模块
- 使用 `@mcp_server.tool` 自定义装饰器向 MCP server 注册该工具，并在 `/backend/tools/mcp_tool_registry.py` 中定义工具规格，包括其名称、描述和输入 schema

例如，以下代码演示如何添加一个知识库查询工具：

```
@mcp_server.tool(
    name="lookup",
    description="Runs query against a knowledge base to retrieve information."
)
async def lookup_tool(
    query: Annotated[str, Field(description="the query to search")]
) -> dict:
    """Look up information in the knowledge base"""
    results = knowledge_base_lookup.main(query)
    return results
```

该装饰器负责处理向 MCP server 的注册，函数体包含您工具的实现逻辑。

### 扩展知识库

该解决方案使用 Amazon Bedrock Knowledge Bases 为 AI agent 提供公司特定信息。您可以使用以下内容更新该知识库：

- 常见问题及其答案
- 产品目录和规格
- 公司政策与流程

## 结论

AI agent 正在改变组织提供客户服务的方式，这些解决方案能够同时处理多个对话、全天候提供一致服务，并在保持质量的同时即时扩展、降低运营成本。本解决方案通过为 AWS 上的 Amazon Nova Sonic 应用提供可部署的基础，让这些好处变得触手可及。该解决方案展示了 AI agent 如何有效处理客户咨询、访问实时数据并提供个性化服务——同时保持客户期待的自然对话流程。

通过将 Amazon Nova Sonic 模型与稳健的云架构、安全的身份认证和灵活的工具集成相结合，组织可以快速从概念推进到概念验证。该解决方案不仅帮助构建语音 AI 应用，还帮助企业在多个行业提升客户满意度和生产力。
