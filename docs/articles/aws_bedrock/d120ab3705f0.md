# Clario 如何借助 AWS 上的生成式 AI 实现临床研究分析自动化

[临床结局评估（COA）](https://www.fda.gov/about-fda/clinical-outcome-assessment-coa-frequently-asked-questions#COADefinition)访谈是临床试验中用于评估治疗效果与安全性的重要工具。在精神病、焦虑症与情绪障碍研究中，这类评估往往决定试验的成败，也因此凸显了数据质量与可靠性的重要性。评估这些结局质量的传统做法十分复杂，需要对音视频录像进行近乎实时的审阅，既耗时又在后勤上极具挑战。访谈评估的差异性、评估技巧不佳以及其他因素都可能引入噪声，导致结果不可靠，甚至可能造成研究失败。

### **关于 Clario**

[Clario](https://www.clario.com/) 是临床试验行业领先的终点数据解决方案提供商，专注于对预先定义的特定结局（终点）进行系统性采集、管理与分析，以评估治疗的安全性与有效性。Clario 为致力于将新疗法带给患者的生命科学公司产出高质量的临床证据。自 50 多年前成立以来，Clario 已部署终点数据解决方案超过 30,000 次，支持了 100 多个国家/地区逾 710 项新药监管批准。

本文介绍 [Clario](https://clario.com/) 如何借助 [Amazon Bedrock](https://aws.amazon.com/bedrock/) 及其他 AWS 服务，构建一套 AI 驱动的解决方案，实现 COA 访谈分析的自动化与质量提升。我们将讨论 Clario 如何：

- 实现说话人分离（speaker diarization）、多语言转写与大语言模型（LLM）
- 使用向量数据库与语义搜索来评估访谈质量
- 在保持监管合规的前提下，将自动化引入复杂的评估审阅流程

## **业务挑战**

Clario 希望改造其 COA 审阅方法，在提升运营效率的同时也提高数据质量。公司需要一个系统，既能应对在全球范围内对多语言数据进行标准化审阅这一关键挑战，又能减少不同专家审阅者之间的自然差异，并在复杂的 COA 访谈流程中保持一致的评估质量。该解决方案还需要高效管理大量音频录像，同时满足严格的监管与隐私要求。Clario 寻求的能力是：在 COA 访谈过程中近乎实时地自动分析语音与对话，从而有望实现：

- 降低主观性与差异性——提供更一致、更可靠的行为健康评估，最大限度减少中心与评分者偏差。
- 提升数据质量与可信度——通过客观、标准化且可重复的访谈评估，增强试验结局的稳健性。
- 精简运营——自动化的复杂评估审阅与评分可为地理上分散的中心与申办方层面的临床团队节省时间与资源。
- 加速决策——更早获得更清晰的洞见，有助于试验申办方更快做出基于证据的 go 或 no-go 决策。

## **解决方案**

为应对这一挑战，Clario 选择了 AWS，看重其全面的人工智能与机器学习（AI/ML）能力，以及在全球范围部署 [HIPAA 合规服务](https://aws.amazon.com/compliance/hipaa-compliance/)的成熟能力。Clario 运用生成式 AI 与 [Amazon Bedrock](https://aws.amazon.com/bedrock/)（一项完全托管的服务，可访问多种高性能基础模型）的力量，获得了以下关键优势：

- **无需管理基础设施**——减轻管理 AI 模型基础设施与更新的运维负担
- **可访问多个模型**——在领先的基础模型之间比较与选择，以针对其特定的 COA 分析需求优化性能
- **内置合规特性**——原生支持数据治理、审计追踪以及临床研究必不可少的监管要求
- **快速原型与部署**——通过无服务器架构与预构建集成缩短上市时间
- **与 AWS 系统无缝集成**——与现有 AWS 服务在数据存储、处理与分析方面原生兼容
- **企业级安全与隐私控制**——先进的加密、访问控制与数据驻留选项，帮助满足严苛的行业标准
- **持续的模型改进**——自动获取模型更新与新能力，降低迁移复杂度

这一综合方案使 Clario 能够专注于其核心专长——临床研究卓越——同时通过可信且符合合规要求的系统运用前沿 AI 能力。

该解决方案集成了说话人分离、多语言转写、语义搜索与 agentic AI 等先进 AI 能力，以类似人类专家中心审阅者的方式自动审阅复杂 COA 访谈的质量。该工作流编排多个步骤：首先分析音频数据，根据声音识别访谈中的不同说话人，随后进行语音转文本转换，并归属说话人角色，以确定哪段语音对应访谈者、哪段对应研究参与者。

这些信息会依据说话人轮次与自然对话边界切分为语义上有意义的片段，每个片段都保留关键元数据。元数据示例包括时间戳、说话人角色与位置上下文。随后这些片段被向量化并存入 [Amazon OpenSearch 向量数据库](https://aws.amazon.com/opensearch-service/serverless-vector-database/)，使系统在处​​理较长访谈时能够突破基础模型的上下文窗口限制。该解决方案实现了一套精细的检索策略，其中：

- 重叠窗口确保在片段边界处不丢失上下文信息
- 定向语义搜索可识别与每项评估标准相关的特定对话片段
- 分层方法通过访谈级摘要与说话人角色，同时保留局部对话流程与全局访谈上下文
- 在评估跨多个片段的标准时，可动态组装滚动上下文窗口

这一架构使系统能够针对同一份访谈数据高效处理多个查询，同时在整个对话过程中保持上下文关系。系统利用这种语义检索能力分析访谈者与参与者之间的对话内容，并对照结构化的访谈指南与中心审阅清单进行评估。该工作流的输出包括访谈的质量评分，以及针对每个清单条目的结构化反馈，指明访谈在何处偏离既定标准。整个系统可近乎实时地提供关于 COA 访谈质量与可靠性的洞见，帮助临床试验申办方更快做出基于证据的 go 或 no-go 决策。

## **解决方案架构**

下面的架构图展示了该解决方案的实现方式：

![AWS 架构图，展示临床试验访谈分析工作流，涉及 S3、OpenSearch、Lambda 与 AI 服务](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/11/01/ML-19444-arch-diag.png)

该工作流包含以下步骤：

- 访谈产生的 COA 访谈录像（音频与视频文件）在本地通过录制应用采集（1）。这些文件经由 [AWS Direct Connect](https://aws.amazon.com/directconnect/) 以传输加密方式上传至 [Amazon Simple Storage Service（Amazon S3）](https://aws.amazon.com/s3/)（2）。上传的文件随后自动以服务端对象级加密方式存储。
- 文件上传后，Clario 的 AI 编排引擎（3）提取音频，并使用运行在 [Amazon SageMaker](https://aws.amazon.com/sagemaker/)（4）上的自定义说话人分离模型，识别不同说话人的语音片段。
- 编排引擎还会调用 Amazon Bedrock API 进行自动音频转写。Clario 使用 [Amazon Bedrock Marketplace](https://aws.amazon.com/bedrock/marketplace/)（5）中的 Whisper 模型，为 COA 访谈录像生成近乎实时的转写文本。随后转写文本被标注说话人信息与时间码，并使用嵌入模型（Amazon Titan Text Embeddings v2 模型）向量化后存入 Amazon OpenSearch（7），以供语义检索。
- 信息向量化并存储后，Clario 的 AI 编排引擎会执行一个运行在 [Amazon Elastic Kubernetes Service（Amazon EKS）](https://aws.amazon.com/pm/eks/)（3）上的基于图的 agent 系统，用于自动化 COA 访谈审阅。该 agent 实现了一个多步工作流：（1）从配置中检索该评估的结构化访谈指南，（2）加载相应的中心审阅清单标准，（3）系统性地查询 Amazon OpenSearch（7）以提取相关访谈片段。agent 依据为当前任务预先配置的图结构，遍历预定义的决策节点，将访谈回答与标准化评估标准进行比对，识别缺口或不一致之处，并生成带有佐证引用的结构化发现。
- 该 agent 使用先进的大语言模型（LLM），例如 Amazon Bedrock（6）中的 Anthropic Claude 3.7 Sonnet，将语音片段归类为访谈者或参与者，并判断每一轮访谈是否符合访谈质量标准。
- 随后 Clario 的 AI 编排引擎汇总整份访谈的审阅结果，并将信息持久化到 [Amazon Relational Database Service（Amazon RDS）](https://aws.amazon.com/rds/)（8）。
- AI 驱动的自动化审阅结果可由客户端应用（9）通过 [Amazon API Gateway 端点](https://aws.amazon.com/api-gateway/)（10）调用 Rest API 获取。

## **收益与成果**

这套 AI 驱动解决方案的初步实现已在改善 Clario 的临床试验流程方面展现出良好前景：

- 运营效率  有望将人工审阅工作量减少 90% 以上。
- 质量提升  通过自动化审阅实现最高 100% 的数据覆盖，而纯人工审阅只能对较小一部分录像进行抽查。凭借快速周转，可实现高度定向的干预，只聚焦于那些需要整改的评分者与中心。
- 业务影响  有望将中心审阅时间从数周缩短到数小时，从而缩短周转时间。提升监管申报的数据可靠性。降低研究失败与结果无法解读的风险。改善临床试验运营的可扩展性。

## **经验教训与最佳实践**

在该解决方案的开发与部署过程中，Clario 积累了宝贵的洞见与经验教训，可供其他希望实施类似 AI 驱动系统的组织借鉴：

- 负责任地开发与使用 AI 的重要性——在初期测试中，Clario 发现 LLM 偶尔会生成听起来合理但实际不准确的摘要。这一重要发现强化了在医疗健康应用中践行负责任 AI 的必要性。这促使 Clario 实施了一套验证系统：在交由人工审阅之前，先将 AI 输出与源文档交叉核对其事实准确性。
- 持续的模型评估——Clario 采用严格的模型评估流程，以在其 AI 驱动的 COA 访谈分析解决方案中维持最高水平的质量与可靠性。Clario 通过多种方式定期评估其 AI 模型的性能与准确度，包括在自定义数据集上开展跨多个模型与配置的对比研究。
- 可扩展且更安全的架构——该解决方案采用无服务器、基于云的架构，使用 Amazon Bedrock、Amazon S3 与 [AWS Lambda](https://aws.amazon.com/lambda/) 等服务，帮助 Clario 在优先保障数据安全与合规的同时有效扩展其解决方案。

## **后续步骤与结论**

Clario 的创新解决方案有望改变 COA 的审阅与评分方式，显著提升临床试验数据的可靠性，并减少人工审阅所需的时间与精力。随着 Clario 持续完善并扩展这套 AI 驱动系统的能力，它正在探索神经科学研究中的更多用例，这些研究依赖临床访谈来评估治疗的安全性与有效性。

通过运用生成式 AI 与 Amazon Bedrock 的强大功能，Clario 为临床试验数据分析树立了新标杆。这使其客户能够做出更明智的决策，并加速改变生命的疗法的研发进程。
