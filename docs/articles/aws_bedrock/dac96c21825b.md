# 使用 AWS SDK for Python（Boto3）在 Amazon Bedrock 上构建生成式 AI 应用

[Amazon Bedrock](https://aws.amazon.com/bedrock/) 是一项完全托管的服务，通过单一 API 提供来自 AI21 Labs、Anthropic、Cohere、Meta、Mistral AI、Stability AI 和 Amazon 等领先 AI 公司的高性能基础模型（FM）供选择，并提供构建生成式 AI 应用所需的一整套能力，兼顾安全性、隐私和负责任 AI。借助 Amazon Bedrock，你可以为你的用例试验并评估顶级 FM，使用微调和检索增强生成（RAG）等技术以自有数据私密地定制它们，并构建利用企业系统和数据源执行任务的 agent。由于 Amazon Bedrock 是无服务器的，你无需管理任何基础设施，还可以用你已经熟悉的 AWS 服务，安全地把[生成式 AI](https://aws.amazon.com/generative-ai/) 能力集成并部署到你的应用中。

在本文中，我们演示如何使用 Amazon Bedrock 与 [AWS SDK for Python（Boto3）](https://aws.amazon.com/sdk-for-python/)以编程方式接入 FM。

## 方案概览

该方案使用一个 AWS SDK for Python 脚本，其功能是在 Amazon Bedrock 上调用 Anthropic 的 Claude 3 Sonnet。使用该 FM，以 prompt 作为输入生成输出。下图说明了方案架构。

## 前提条件

在调用 Amazon Bedrock API 之前，请确认你已具备以下条件：

- 一个可访问 AWS 服务（包括 Amazon Bedrock）的 AWS 账户
- 已[设置好](https://docs.aws.amazon.com/cli/latest/userguide/getting-started-quickstart.html)的 [AWS Command Line Interface](https://aws.amazon.com/cli)（AWS CLI）
- 已为 [Amazon Bedrock API 设置好](https://docs.aws.amazon.com/bedrock/latest/userguide/api-setup.html)的 [AWS Identity and Access Management](https://aws.amazon.com/iam/)（IAM）用户，并为该 IAM 用户添加了相应权限
- 用于[配置](https://docs.aws.amazon.com/cli/v1/userguide/cli-chap-configure.html) AWS CLI 和权限的 IAM 用户访问密钥与私有密钥
- Amazon Bedrock 上 FM 的[访问权限](https://docs.aws.amazon.com/bedrock/latest/userguide/model-access.html#:~:text=To%20request%20access%20to%20a,want%20to%20add%20access%20to.)
- 最新版本的 [Boto3](https://boto3.amazonaws.com/v1/documentation/api/latest/index.html) 库
- 在你的集成开发环境（IDE）中配置的最低 Python 版本 3.8

## 部署方案

完成前提条件后，你就可以开始使用 Amazon Bedrock 了。先从以下步骤开始编写脚本：

- 导入所需的库：

```
import boto3
import json
```

- 设置 Boto3 客户端以使用 [Amazon Bedrock runtime](https://boto3.amazonaws.com/v1/documentation/api/latest/reference/services/bedrock-runtime.html)，并指定 AWS 区域：

```
# Set up the Amazon Bedrock client
bedrock_client = boto3.client(
    	service_name="bedrock-runtime",
    region_name="us-east-1"
)
```

- 使用[模型 ID](https://docs.aws.amazon.com/bedrock/latest/userguide/model-ids.html)定义要调用的模型。在本示例中，我们使用 Amazon Bedrock 上 Anthropic 的 Claude 3 Sonnet：

```
# Define the model ID
model_id = "anthropic.claude-3-sonnet-20240229-v1:0"
```

- 为 prompt 赋值，它就是你在调用时用来与 FM 交互的消息：

```
# Prepare the input prompt.
prompt = "Hello, how are you?"
```

[Prompt 工程技术](https://aws.amazon.com/what-is/prompt-engineering/)可以提升 FM 表现并改进结果。

在调用 Amazon Bedrock 模型之前，我们需要定义一个 [payload](https://docs.aws.amazon.com/bedrock/latest/userguide/model-parameters-anthropic-claude-messages.html)，它充当一组指令和信息，引导模型的生成过程。这个 payload 结构因所选模型而异。在本示例中，我们使用 Amazon Bedrock 上 Anthropic 的 Claude 3 Sonnet。可以把该 payload 视为模型的蓝图，为它提供必要的上下文和参数，以便根据你的具体 prompt 生成期望的文本。下面拆解这个 payload 中的关键要素：

- **anthropic_version** —— 指定你正在使用的确切 Amazon Bedrock 版本。
- **max_tokens** —— 设置模型在响应中可生成的 token 总数上限。token 是大语言模型（LLM）处理和生成的最小有意义文本单位（单词、标点、子词）。
- **temperature** —— 该参数控制生成文本的随机性程度。较高的值会带来更有创造性、可能更出人意料的输出，较低的值则得到更保守、更一致的结果。
- **top_k** —— 定义生成过程中每一步所考虑的、最可能的候选词数量。
- **top_p** —— 影响选择下一个词时的采样概率分布。较高的值偏向高频词，较低的值则允许更多样、可能更出人意料的选择。
- **messages** —— 一个数组，包含供模型处理的各条消息。
- **role** —— 定义消息中发送方的角色（对你提供的 prompt 而言就是 user）。
- **content** —— 该数组保存实际的 prompt 文本本身，以“text”类型对象表示。

- 如下定义 payload：

```
payload = {
    "anthropic_version": "bedrock-2023-05-31",
    "max_tokens": 2048,
    "temperature": 0.9,
    "top_k": 250,
    "top_p": 1,
    "messages": [
        {
            "role": "user",
            "content": [
                {
                    "type": "text",
                    "text": prompt
                }
            ]
        }
    ]
}
```

- 参数和要交互的 FM 都已设置好。现在你向 Amazon Bedrock 发送请求，提供要交互的 FM 以及你定义的 payload：

```
# Invoke the Amazon Bedrock model
response = bedrock_client.invoke_model(
    modelId=model_id,
    body=json.dumps(payload)
)
```

- 请求处理完成后，你可以显示 Amazon Bedrock 生成文本的结果：

```
# Process the response
result = json.loads(response["body"].read())
generated_text = "".join([output["text"] for output in result["content"]])
print(f"Response: {generated_text}")
```

来看完整的脚本：

```
import boto3
import json

# Set up the Amazon Bedrock client
bedrock_client = boto3.client(
    service_name="bedrock-runtime",
    region_name="us-east-1"
)

# Define the model ID
model_id = "anthropic.claude-3-sonnet-20240229-v1:0"

# Prepare the input prompt
prompt = "Hello, how are you?"

# Create the request payload
payload = {
    "anthropic_version": "bedrock-2023-05-31",
    "max_tokens": 2048,
    "temperature": 0.9,
    "top_k": 250,
    "top_p": 1,
    "messages": [
        {
            "role": "user",
            "content": [
                {
                    "type": "text",
                    "text": prompt
                }
            ]
        }
    ]
}

# Invoke the Amazon Bedrock model
response = bedrock_client.invoke_model(
    modelId=model_id,
    body=json.dumps(payload)
)

# Process the response
result = json.loads(response["body"].read())
generated_text = "".join([output["text"] for output in result["content"]])
print(f"Response: {generated_text}")
```
