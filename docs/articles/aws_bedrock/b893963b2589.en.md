## The challenge: Real-time grounding for professional content

Unlike chatbots that rely on static knowledge bases, Norton Revamp needs to understand what’s trending *right now* in each user’s professional domain. A cyber security expert needs today’s threat intelligence. A marketing leader needs this week’s industry shifts. Traditional approaches (custom web crawlers, third-party news APIs, static content databases) each carry trade-offs: infrastructure overhead, stale data, vendor complexity, or data egress risk.

We evaluated three alternatives before choosing AgentCore Web Search. Custom crawlers require ongoing maintenance and lag real time. Third-party news APIs added vendor contracts, API key management, and data leaving our AWS environment. Static knowledge bases were perpetually stale. AgentCore Web Search eliminated these concerns. It’s fully managed with zero infrastructure overhead, operates entirely within AWS with zero data egress, and returns cited sources with URLs and publication dates. This makes personalized, real-time news feeds viable at scale.

## How AgentCore Web Search powers Norton Revamp

Web Search on Amazon Bedrock AgentCore is a fully managed web search capability, compliant with the Model Context Protocol (MCP). It’s available as a managed connector on the AgentCore Gateway, a capability of Amazon Bedrock AgentCore. Our agent sends a natural-language query, and Web Search returns relevant snippets, source URLs, titles, and publication dates that the model uses to produce grounded responses.

This capability powers three core features:

**AI-curated news feed**

Every user gets a personalized content stream surfacing the latest articles and trending topics tied to their goal. If you’re building a reputation as a generative AI thought leader, your feed prioritizes AI breakthroughs, industry analysis, and emerging use cases, sourced in real time through AgentCore Web Search. Unlike a static RSS aggregator, the feed is a goal-aware discovery engine that refreshes with every session.

**Smart content suggestions**

Users receive AI-generated content ideas tailored to trending topics in their space, written in their own authentic voice, with optional AI-generated visuals. AgentCore Web Search grounds every suggestion on what’s happening *today*. A three-step coaching flow (Analyze, Refine, Post) walks users from initial ideas to published content on LinkedIn and X, with a feedback loop, so the AI gets sharper with every iteration.

**Trend-aware goal setting**

Users define a goal. The AI builds a personalized roadmap with weekly themes and milestones. AgentCore Web Search feeds real-time trend data into goal generation, so weekly themes reflect current industry movements. The system learns from the past four weeks of activity, refreshing recommendations as users grow.

## Architecture and tech stack

![Event-driven News Engine architecture showing Amazon Nova, AgentCore Web Search, and the AI Learning System grounding content generation](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/10/29/c-ml-22210-arch-diagram.png)

Figure 1: Event-driven architecture of the Norton Revamp News Engine

The integration follows an event-driven architecture. When a user sets or updates their professional goal, Amazon Nova (through Amazon Bedrock) generates targeted search queries based on the goal, recent activity, and engagement patterns. The agent sends these queries to AgentCore Web Search, which returns cited results entirely within our AWS environment. Our AI Learning System ranks the results for relevance, recency, and source credibility. The ranked results then serve as grounding context for Amazon Nova Lite to generate content suggestions in the user’s authentic voice. Engagement data feeds back into query generation, making the News Engine progressively smarter.

**Generative AI and machine learning stack:**

- **Amazon Bedrock** – Core generative AI engine for content generation, personalization, post analysis (batch mode), and content coaching.
- **Amazon Nova (Nova Lite)** – Primary large language model (LLM) powering content generation, goal creation, and trend analysis.
- **Web Search on Amazon Bedrock AgentCore** – Real-time web retrieval powering the News Engine, content grounding, and trend discovery through an MCP-compliant managed connector.
- **Stability AI** – Image generation.
- **Claude (through Amazon Bedrock)** – Additional LLM capabilities for complex reasoning tasks.

**Infrastructure:** React, TypeScript, and Tailwind CSS on the frontend. Node.js, Amazon Elastic Container Service (Amazon ECS), AWS Lambda, Amazon DynamoDB (multi-table with composite key patterns), Amazon API Gateway, Amazon Simple Storage Service (Amazon S3), Amazon Simple Queue Service (Amazon SQS), Amazon EventBridge, Amazon CloudFront, Amazon CloudWatch, and AWS Secrets Manager on the backend. Infrastructure managed through Terraform with blue-green deployment for zero-downtime releases.

**Processing pipeline:** The platform runs four pipeline stages:

- **Full Scan** – Pull up to 1,000 historical posts, store in Amazon S3, run Amazon Bedrock batch analysis for reputation impact.
- **Daily Scan** – Amazon EventBridge-triggered incremental analysis.
- **Weekly Goal Generation** – Lambda generates goals considering past engagement data plus real-time trend data from AgentCore Web Search.
- **Content Coaching** – Synchronous Amazon Bedrock calls through the Analyze, Refine, Post flow, each step grounded with AgentCore Web Search results.

## Best practices for AgentCore Web Search integration

For teams considering AgentCore Web Search for real-time grounding:

- **Invest in query generation –** Well-structured queries yield better results than open-ended ones, so we focused on our prompt engineering there.
- **Cache strategically –** Real-time freshness is the point, but some queries don’t need to re-execute every session. We cache results with time-to-live (TTL) values that match freshness requirements.
- **Build feedback loops –** Track which web search results users engage with and feed that signal back into query generation. Our News Engine’s relevance improved over the first 90 days.
- **Validate source quality –** AgentCore Web Search returns source URLs and publication dates. We built a lightweight credibility scoring layer to prioritize authoritative sources.
