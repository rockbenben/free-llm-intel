# Amazon Polly 对其生成引擎进行了重大升级

Amazon Polly 生成引擎现在提供更自然、更准确的语音输出。我们正在推出对 [Amazon Polly 生成引擎](https://docs.aws.amazon.com/polly/latest/dg/generative-voices.html) 的升级，该引擎可提供更具表现力、更准确且低延迟的语音输出。此次升级在 9 个语言环境中添加了 14 种新语音，其中包括首次全面提供印地语和芬兰语生成语音。该升级现已在生产中普遍可用。

重要的是，这是对现有生成声音的直接升级。语音名称和 API 调用保持不变，因此您现有的应用程序将继续像现在一样工作。

## 新的语音、语言和区域可用性

- **Amazon Polly 生成引擎的整体目录更大** – 共有 57 种生成声音，涵盖 11 种语言和 25 个区域设置。
- **14 个新声音** 跨越 9 个语言环境 - 美国英语（Kenneth、Nate）、澳大利亚英语（Russell、Curtis）、印度英语（Kiara、Arjun）、德语（Tina）、美国西班牙语（Carlos）、巴西葡萄牙语（Leo、Carolina）、韩语（Hyunduk）、印地语（Kiara、Arjun）和芬兰语（Suvi）。
- **生成引擎中普遍提供的网络新语言 –** 印地语和芬兰语。
- **区域扩展**至 AWS GovCloud（美国西部） – 总共 11 个 AWS 区域。

## 专为企业生产就绪的语音工作流程而构建

升级后的 Amazon Polly 生成引擎使用标准 Amazon Polly API 调用来构建您的语音应用程序。借助 Amazon Polly，您可以继续使用熟悉的 AWS 模式进行构建：调用相同的 Amazon Polly API、使用 AWS Identity and Access Management (IAM) 管理访问、使用现有应用程序和联络中心流中的输出以及监控为客户合成语音的工作负载。

此次发布旨在提高您通过现有 Amazon Polly 实施听到的语音输出质量。无需更改代码即可获得升级的语音。对于已经使用 Amazon Polly 生成语音的应用程序，升级会就地进行。对于新应用程序，相同的“SynthesizeSpeech” API 使您可以访问更大的生成语音目录集。借助 Bi-Di Streaming API `StartSpeechSynthesisStream`，您可以将文本流式传输到 Amazon Polly 并同时接收返回的合成音频。这非常适合实时应用程序，例如语音代理和游戏中的定制角色。

## 你可以构建什么

**联络中心。** 准确性在客户服务对话中最为重要。当呼叫者检查订单时，语音会正确读回跟踪号码、地址和确认码，有助于自助解决呼叫，而不是升级给人工代理。 Amazon Polly 生成语音的准确实体发音和低延迟生成使自动交互式语音应答 (IVR) 交互听起来更具对话性。

**级联语音代理。** 在语音代理框架中使用 Amazon Polly，您可以将 LLM 响应文本转换为清晰、自然的语音，并通过 WebSocket 或电话通道近乎实时地将其流式传输回用户。这使得现场对话语音成为可能。主要优点是低延迟播放、高可扩展性和成本效益。

**媒体、本地化和配音。** 将脚本转换为视频、广告、播客、产品概述和有声读物的成品音频。您可以使用一种或多种声音，无需工作室会议。更自然的语调减少了后期制作。扩大的语言环境覆盖范围（包括首次生成的印地语和芬兰语）意味着您可以通过同一管道将单个内容本地化到更多市场。

**电子学习和培训。** 大规模讲述课件、入职培训和基于知识的文章，并在源文本发生变化时立即更新。无需重新录制。更具表现力的交付支持通过长篇材料进行参与。

**辅助功能。** 提供文章、文档和应用程序的清晰、自然的口语版本，以便更多人可以通过聆听来使用您的内容：大声朗读、在旅途中或使用屏幕阅读器。

**交互式和交易体验。** 支持语音的游戏、信息亭、IVR 菜单和物联网设备，并按需生成响应。当语音需要听起来自然并可靠地读取名称、号码、产品详细信息、地址和确认信息时，请使用 Amazon Polly。

## 开始使用

您可以使用 [AWS 管理控制台](https://console.aws.amazon.com/)、[AWS 命令行界面 (AWS CLI)](https://aws.amazon.com/cli) 或 AWS 开发工具包访问新语音。

先决条件：

- 具有 Amazon Polly 访问权限的活动 AWS 账户。
- 安装并配置了 AWS 命令​​行界面 (AWS CLI)。
-Python 3.10+。
- Boto3 安装：`pip install boto3`。
- AWS Identity and Access Management (IAM) 权限：`polly:SynthesizeSpeech`。

以下是一个使用适用于 Python 的 AWS 开发工具包 (Boto3) 以及“SynthesizeSpeech” API 和生成语音的简单示例：
```
import boto3

polly = boto3.client("polly", region_name="us-east-1")

response = polly.synthesize_speech(
    Text="Hello! This is Amazon Polly's next-generation generative voice.",
    VoiceId="Kenneth",  # any generative voice in the catalogue
    Engine="generative",
    OutputFormat="mp3",
)

with open("speech.mp3", "wb") as f:
    f.write(response["AudioStream"].read())
```
您还可以使用 AWS CLI 发出相同的请求：
```
aws polly synthesize-speech \
  --region us-east-1 \
  --voice-id Kenneth \
  --engine generative \
  --output-format mp3 \
  --text "Hello! This is Amazon Polly's next-generation generative voice." \
  speech.mp3
```
要以编程方式检索完整的当前语音列表，请调用“DescribeVoices”。您可以在部署检查中使用此功能来确认所选的生成语音在应用程序运行的区域中可用。

## 可用性

下一代生成引擎和新声音现已全面上市。 14 个新的生成语音已在以下 AWS 区域推出：美国东部（弗吉尼亚北部）、美国西部（俄勒冈）、欧洲（法兰克福）、欧洲（苏黎世）、欧洲（伦敦）、亚太地区（悉尼）、亚太地区（首尔）、亚太地区（新加坡）、亚太地区（东京）、加拿大（中部）和 AWS GovCloud（美国西部）。入门，按观众：

- **开发人员** – 在现有应用程序中使用“Engine="generative"”调用“synthesize_speech”。不需要进行其他更改。
- **联络中心团队** – 改进达到 **Amazon Connect** 和 **Genesys** 自动流动。
- **所有人** – 访问 [Amazon Polly 控制台](https://console.aws.amazon.com/polly/) 中的任何语音。

有几件事需要知道：

- **标准和神经声音不受影响。**
- **语音标记在生成语音上不可用**（从今天起没有变化）。如果您的应用程序需要它们，标准语音和神经语音将继续支持它们。
- **生成引擎继续支持 SSML 标签。** 有关更多详细信息，请参阅[支持的 SSML 标签](https://docs.aws.amazon.com/polly/latest/dg/supportedtags.html)。
- **在运行时使用当前的语音可用性。** 跨区域部署时调用 `DescribeVoices` 或检查控制台。
