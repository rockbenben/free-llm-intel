# Amazon Polly 对其生成式引擎进行了重大升级

Amazon Polly 生成式引擎现在提供更自然、更准确的语音输出。我们为 [Amazon Polly 生成式引擎](https://docs.aws.amazon.com/polly/latest/dg/generative-voices.html)带来了一项升级，以低延迟提供更具表现力、更准确的语音输出。此次升级在 9 个 locale 中新增了 14 种语音，其中包括 Hindi 和 Finnish 生成式语音首次正式可用。该升级现已在生产中正式可用。

重要的是，对现有生成式语音来说，这是一次无缝升级（drop-in upgrade）。语音名称和 API 调用都没有变化，因此你现有的应用会像今天一样继续工作。

[Amazon Polly](https://aws.amazon.com/pm/polly/?trk=b671ff34-bbc7-4bfb-810d-1d5dd86754c8&sc_channel=ps&ef_id=CjwKCAjwxeHWBhBPEiwAiqtQ-T9vdBDVcvj307u_rytRQbtnrsBUgG615Vad1q2eqCjNWSGgbYPK2hoCVQ4QAvD_BwE:G:s&gads_camp=24332379316&gads_ag=206560268051&gads_ad=795877020857&gads_kw=amazon%20polly&gads_matchtype=e&gads_network=g&gads_device=c&gads_geo=9033313&gad_campaignid=24332379316&gbraid=0AAAAADjHtp8_G1AzTEjHOKxoh8gOtuJJ2&gclid=CjwKCAjwxeHWBhBPEiwAiqtQ-T9vdBDVcvj307u_rytRQbtnrsBUgG615Vad1q2eqCjNWSGgbYPK2hoCVQ4QAvD_BwE) 是一项完全托管的 AWS 服务，可把文本转换为听起来自然的语音，适用于联络中心、基于大语言模型（LLM）的智能体应用、媒体与娱乐、在线学习、无障碍以及其他需要大规模可靠语音输出的应用。

## 新语音、新语言与区域可用性

- **Amazon Polly 生成式引擎的整体目录更大** – 共有 57 种生成式语音，覆盖 11 种语言和 25 个 locale。
- **14 种新语音**，覆盖 9 个 locale – 美式英语（Kenneth、Nate）、澳大利亚英语（Russell、Curtis）、印度英语（Kiara、Arjun）、德语（Tina）、美式西班牙语（Carlos）、巴西葡萄牙语（Leo、Carolina）、韩语（Hyunduk）、Hindi（Kiara、Arjun）和 Finnish（Suvi）。
- **生成式引擎中新增并正式可用的语言 –** Hindi 和 Finnish。
- **区域扩展**至 AWS GovCloud (US-West) – 总计 11 个 AWS 区域。

## 为企业生产级语音工作流而构建

升级后的 Amazon Polly 生成式引擎使用标准的 Amazon Polly API 调用来构建你的语音应用。借助 Amazon Polly，你可以继续用熟悉的 AWS 模式来构建：调用同一个 Amazon Polly API，使用 AWS Identity and Access Management (IAM) 管理访问权限，在你现有的应用和联络中心流程中使用输出，并监控那些为客户合成语音的工作负载。

本次发布旨在提升你现有 Amazon Polly 实现所能听到的语音输出质量。你无需改动代码即可获得升级后的语音。对于已经使用 Amazon Polly 生成式语音的应用，升级会就地完成。对于新应用，同一个 `SynthesizeSpeech` API 让你可以访问更大的生成式语音目录。借助双向流式 API `StartSpeechSynthesisStream`，你可以把文本流式发送到 Amazon Polly，并同时接收合成后的音频。这非常适合语音智能体和游戏中的定制角色等实时应用。

## 你可以构建什么

**联络中心。** 在客户服务对话中，准确性最为重要。当来电者查询订单时，一把能正确读回跟踪号、地址和确认码的语音，有助于在自助服务中解决问题，而不必升级给人工坐席。Amazon Polly 生成式语音准确的实体发音和低延迟生成，让自动交互式语音应答（IVR）交互听起来更像对话。

**级联式语音智能体。** 在语音智能体框架中使用 Amazon Polly，你可以把 LLM 的回复文本转换为清晰、听起来自然的语音，并通过 WebSockets 或电话信道近乎实时地流式传回给用户。这让实时对话式语音成为可能。主要优势是低延迟播放、高可扩展性和成本效率。

**媒体、本地化与配音。** 把脚本转换为视频、广告、播客、产品概览和有声读物的成品音频。你可以使用一把语音或多把语音，无需录音棚。更自然的语调减少了后期制作。扩展后的 locale 覆盖（包括首次提供的生成式 Hindi 和 Finnish）意味着你可以用同一条流水线把同一份内容本地化到更多市场。

**在线学习与培训。** 大规模地为课件、入职培训和知识文章配音，并在源文本一变化时就更新。无需重新录音。更具表现力的表达有助于提升长内容的学习参与度。

**无障碍。** 为文章、文档和应用提供清晰、自然的口语版本，让更多人可以通过聆听来消费你的内容：朗读、在移动中收听，或配合屏幕阅读器。

**交互式与交易式体验。** 为游戏、自助终端、IVR 菜单和 IoT 设备赋予语音能力，响应按需生成。当语音需要听起来自然，并且需要可靠地读出姓名、数字、产品详情、地址和确认信息时，请使用 Amazon Polly。

## 开始使用

你可以通过 [AWS Management Console](https://console.aws.amazon.com/)、[AWS Command Line Interface (AWS CLI)](https://aws.amazon.com/cli) 或 AWS SDK 访问这些新语音。

先决条件：

- 一个可访问 Amazon Polly 的有效 AWS 账户。
- 已安装并配置好的 AWS Command Line Interface (AWS CLI)。
- Python 3.10+。
- 已安装 Boto3：`pip install boto3`。
- AWS Identity and Access Management (IAM) 权限：`polly:SynthesizeSpeech`。

下面是一个使用 AWS SDK for Python (Boto3)、调用 `SynthesizeSpeech` API 并选用生成式语音的快速示例：

```
import boto3

polly = boto3.client("polly", region_name="us-east-1")

response = polly.synthesize_speech(
    Text="Hello! This is Amazon Polly's next-generation generative voice.",
    VoiceId="Kenneth",  # any generative voice in the catalogue
    Engine="generative",
    OutputFormat="mp3",
)

with open("speech.mp3", "wb") as f:
    f.write(response["AudioStream"].read())
```

你也可以用 AWS CLI 发出同样的请求：

```
aws polly synthesize-speech \
  --region us-east-1 \
  --voice-id Kenneth \
  --engine generative \
  --output-format mp3 \
  --text "Hello! This is Amazon Polly's next-generation generative voice." \
  speech.mp3
```

要以编程方式获取完整、最新的语音列表，请调用 `DescribeVoices`。你可以在部署检查中使用它，确认所选生成式语音在你的应用运行所在的区域中可用。

## 可用性

下一代生成式引擎和新语音现已正式可用。14 种新的生成式语音在以下 AWS 区域中可用：美国东部（弗吉尼亚北部）、美国西部（俄勒冈）、欧洲（法兰克福）、欧洲（苏黎世）、欧洲（伦敦）、亚太地区（悉尼）、亚太地区（首尔）、亚太地区（新加坡）、亚太地区（东京）、加拿大（中部）以及 AWS GovCloud (US-West)。按受众划分的入门方式：

- **开发者** – 在现有应用中用 `Engine="generative"` 调用 `synthesize_speech`。无需其他改动。
- **联络中心团队** – 这些改进会自动覆盖到 **Amazon Connect** 和 **Genesys** 流程。
- **所有人** – 在 [Amazon Polly 控制台](https://console.aws.amazon.com/polly/)中访问任意语音。

需要了解的几点：

- **标准语音和神经语音不受影响。**
- **生成式语音不支持语音标记（speech marks）**（与今天一致）。如果你的应用需要它们，标准语音和神经语音仍然支持。
- **生成式引擎继续支持 SSML 标签。** 详情请参阅[受支持的 SSML 标签](https://docs.aws.amazon.com/polly/latest/dg/supportedtags.html)。
- **在运行时使用当前的语音可用性。** 跨区域部署时，请调用 `DescribeVoices` 或查看控制台。

Amazon Polly 的下一代生成式引擎今天即可使用，提供更自然、更准确的语音，新增 14 种语音（包括首次正式可用的 Hindi 和 Finnish 生成式语音），并且无需改动你的代码。定价信息请参阅 [Amazon Polly 定价页面](https://aws.amazon.com/polly/pricing/)。要开始使用，请打开 [Amazon Polly 控制台](https://console.aws.amazon.com/polly/)试用这些语音，并参阅 [Amazon Polly 文档](https://docs.aws.amazon.com/polly/)了解如何基于它们构建应用。
