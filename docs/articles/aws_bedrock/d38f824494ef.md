# 用 Amazon Nova Act 的 agentic AI 自动创建 AWS Quick Sight 数据故事

[AWS Quick Sight](https://aws.amazon.com/quicksight/) 数据故事（data stories）通过把复杂数据转化为可交互的叙述，帮助全球客户更快决策。然而，每天手工创建多个数据故事会消耗大量时间和资源，拖慢关键决策，也让团队无法专注于更有价值的分析。

每个组织都有多个业务单元，每个业务单元又会根据具体的报表需求创建并运营多个仪表盘。用户按自己的需要从这些仪表盘生成各种数据故事。目前，数据故事的创建是手工流程，用户需要撰写多段叙述，十分耗时。通过把这一过程自动化，组织可以大幅提升生产力，让用户把时间转向基于数据的决策。

本文演示 [Amazon Nova Act](https://labs.amazon.science/blog/nova-act) 如何自动创建 Quick Sight 数据故事，从而节省时间，让你专注于做出关键的数据驱动业务决策。

Amazon Nova Act 让 Web 浏览器自动化焕然一新，有助于通过 Web 界面执行复杂的真实任务。与专注于对话的传统大语言模型（LLM）不同，Amazon Nova Act 强调行动导向的能力，把复杂任务拆解为可靠的原子命令。这项变革性技术以极少的人工监督推进自主自动化，对业务生产力和 IT 运维尤为有价值。

Quick Sight 数据故事把复杂数据转化为可交互的演示，引导观看者逐步理解洞见。它会自动组合可视化、文本和图像，弥合分析师与干系人之间的落差，帮助组织有效传达数据，并在保持专业标准的同时更快决策。

借助 Amazon Nova Act 的自动化能力，你可以自动生成数据故事，减少耗时的人工投入。通过浏览器自动化，Amazon Nova Act 与 Quick Sight 无缝交互，创建定制化的数据叙述。把 Amazon Nova Act 的自动化与 Quick Sight 强大的可视化能力结合，你可以最大限度减少重复性任务，加快各团队的数据驱动决策。

## **方案概览**

在我们的方案中，Quick Sight 通过数据故事把复杂数据转化为可交互的叙述，实现更快决策。Amazon Nova Act 通过让 AI agent 自主执行复杂任务，改变了 Web 浏览器自动化的方式，简化运营以提升业务生产力。

## **prompt 最佳实践**

Amazon Nova Act 通过把 prompt 拆解为一个个独立的 act() 调用取得最佳效果，类似于给出分步指令。在撰写本文时，这是构建可重复、可靠且易维护工作流的推荐做法。本节讨论一些 prompt 最佳实践。

首先，对 agent 该做什么要规定明确、表述简洁。例如，不要使用以下代码：

`nova.act("Select the SaaS-Sales dataset")`

我们建议改用以下 prompt：

`nova.act("Click on Datasets option on the left-hand side and then select SaaS-Sales dataset ")`

此外，我们建议把较大的动作拆成更小的动作。例如，不要使用以下代码：

`nova.act("Publish dashboard as ‘test-dashboard’")`

以下 prompt 被拆分为多个独立动作：

`nova.act("select Analyses on the left-hand side”)`

`nova.act("select the ‘SaaS-Sales analysis’ ")`

`nova.act("select ‘PUBLISH’ from the top right-hand corner")`

`nova.act("In the 'Publish dashboard' dialog box, locate the input field labeled 'Dashboard name'. Enter 'test_dashboard' into this field”)`

`nova.act(“Select PUBLISH DASHBOARD”)`

## **先决条件**

使用 Amazon Nova Act 创建并发布 Quick Sight 数据故事需要以下先决条件：

- 用于认证的 API key。要生成 API key，请参阅 [Amazon Nova Act](https://nova.amazon.com/act)。
- Amazon Nova Act 的先决条件与安装说明，请参阅 [GitHub 仓库](https://github.com/aws/nova-act)。
- 一个 Pro 用户（author 或 reader）身份，用于创建 Quick Sight 数据故事。
- 一个已发布的 Quick Sight 仪表盘，包含你的 Quick Sight 数据故事所需的可视化。

**Windows 用户**请在 Windows PowerShell 中完成以下配置与安装步骤：

- 创建虚拟环境：
`python -m venv venv.`
- 激活虚拟环境：
`venv\Scripts\activate`
- 把 API key 设置为环境变量：
`$Env:NOVA_ACT_API_KEY="your_api_key"`
- 安装 Amazon Nova Act：
`pip install nova-act`
- 要运行脚本（Python 文件），使用以下命令，并指定你要运行的脚本名：
`python <script_name>.py`

为简化起见，我们把部分取值硬编码了。你可以利用 Python 的特性编写程序逻辑，把这些取值作为输入参数。

编写 prompt 有多种方式。下面几节给出示例，演示如何自动化 Quick Sight 数据故事的创建与分发。

## **配置**

运行以下代码，从 `nova_act` 模块导入 NovaAct 类，创建一个从 Quick Sight 登录页开始的 Amazon Nova 实例，并启动自动化浏览器会话：

```
from nova_act import NovaAct

nova = NovaAct(starting_page="https://quicksight.aws.amazon.com/")

nova.start()
```

**使用凭据登录**
 打开 Quick Sight 登录页后，完成以下步骤用你的凭据登录：

- 输入你的 Quick Sight 账户名并选择 Next。（在以下代码中指定 Quick Sight 账户名，或编写程序逻辑把它作为输入参数处理。）
`nova.act("enter QuickSight account name <Account Name> and select Next")`
- 输入用户名并移到密码字段。（你可以用程序逻辑把用户名配置为输入参数。）
`nova.act("Enter username and click on the password field")`
- 从命令行收集密码，并通过 Playwright 输入：
`nova.page.keyboard.type(getpass())`
- 用户名和密码填好后，选择 Sign in。
`nova.act("Click Sign in")`

如果 agent 无法聚焦到页面元素（此例中是密码字段），可以使用以下代码：

`nova.act("enter '' in the password field")`

`nova.page.keyboard.type(getpass())`

**创建新的数据故事**
 在 Quick Sight 控制台的导航窗格中选择 Data stories：

`nova.act("Select **Data stories** on the left side menu")`

`nova.act("Select **NEW DATA STORY**").`

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/09/21/selecting_new_data_story.png)

要构建数据故事，你必须完成以下步骤：

- 描述数据故事
- 从仪表盘选择可视化
- 构建数据故事

`nova.act("Please enter ‘Country wide sales data story’ into the 'Describe your data story' field and Click on + ADD")`

`nova.act("select all the visuals and select BUILD")`

`time.sleep(300)`

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/09/21/selecting_visuals_and_building_data_story.png)

在本例中，脚本默认使用单个仪表盘（Demo Dashboard）。对于多个仪表盘，需要加入 prompt 以选择数据故事要用的特定仪表盘及其可视化。此外，你可以按自己的需求描述数据故事。如果有多个可视化，你可以选择要纳入数据故事的那几个。请根据仪表盘的数据量和所汇总的可视化数量调整 time.sleep 的时长。

要查看你的数据故事，在导航窗格中选择 **Data stories**，然后选择你的数据故事。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/09/21/created_data_story.png)

## **清理资源**

要删除你创建的数据故事，请完成以下步骤：

- 登录 Quick Sight 控制台。
- 在导航窗格中选择 **Data stories**。
- 找到要删除的数据故事。
- 选择该故事旁的三点选项菜单图标。
- 从下拉菜单中选择 **Delete**。
