# 使用 Amazon Bedrock Custom Model Import 部署 Qwen 模型

[Amazon Bedrock Custom Model Import](https://aws.amazon.com/bedrock/custom-model-import/) 现已支持 [Qwen](https://qwenlm.github.io/blog/qwen2.5/) 模型。你现在可以导入 Qwen2、Qwen2_VL 和 Qwen2_5_VL 架构的自定义权重，包括 Qwen 2、2.5 Coder、Qwen 2.5 VL 和 QwQ 32B 等模型。你可以将自定义 Qwen 模型带入 Amazon Bedrock，并在全托管、serverless 的环境中部署，而无需管理基础设施或模型服务。

本文介绍如何使用 Amazon Bedrock Custom Model Import 部署 Qwen 2.5 模型，使那些希望在 AWS 基础设施内以合理成本使用先进 AI 能力的组织能够用上这些模型。

## Qwen 模型概览

Qwen 2 和 2.5 是大型语言模型家族，提供多种规模和专用变体以满足不同需求：

- **通用语言模型**：参数量从 0.5B 到 72B 的模型，包含 base 和 instruct 版本，适用于通用任务
- **Qwen 2.5-Coder**：专用于代码生成和补全
- **Qwen 2.5-Math**：专注于高级数学推理
- **Qwen 2.5-VL（vision-language）**：具备图像和视频处理能力，支持多模态应用

## Amazon Bedrock Custom Model Import 概览

Amazon Bedrock Custom Model Import 使你能够通过单一的 serverless 统一 API，把自定义模型与现有基础模型（FM）一起导入并使用。你可以按需访问导入的自定义模型，而无需管理底层基础设施。将受支持的自定义模型与 Amazon Bedrock Knowledge Bases、Amazon Bedrock Guardrails 和 Amazon Bedrock Agents 等原生工具和功能集成，可以加速生成式 AI 应用开发。Amazon Bedrock Custom Model Import 已在美国东部（弗吉尼亚北部）、美国西部（俄勒冈）和欧洲（法兰克福）AWS Region 正式可用。下面，我们将探讨如何将 Qwen 2.5 模型用于两个常见用例：作为编码助手和用于图像理解。Qwen2.5-Coder 是先进的代码模型，能力可比肩 GPT-4o 等闭源模型。它支持 90 多种编程语言，擅长代码生成、调试和推理。Qwen 2.5-VL 带来先进的多模态能力。据 Qwen 介绍，Qwen 2.5-VL 不仅能识别花朵和动物等物体，还能分析图表、从图像中提取文字、理解文档版式以及处理长视频。

## 前置条件

在使用 Amazon Bedrock Custom Model Import 导入 Qwen 模型之前，请确保已具备以下条件：

- 一个有效的 AWS 账户
- 一个用于存放 Qwen 模型文件的 [Amazon Simple Storage Service（Amazon S3）](https://aws.amazon.com/s3) 存储桶
- 创建 Amazon Bedrock 模型导入任务所需的[足够权限](https://docs.aws.amazon.com/bedrock/latest/userguide/model-import-iam-role.html)
- 已确认你的 [Region 支持 Amazon Bedrock Custom Model Import](https://docs.aws.amazon.com/bedrock/latest/userguide/model-customization-import-model.html)

## 用例 1：Qwen 编码助手

在本例中，我们将演示如何使用 Qwen2.5-Coder-7B-Instruct 模型构建编码助手

- 前往 [Hugging Face](https://huggingface.co/) 搜索并复制 Model ID Qwen/Qwen2.5-Coder-7B-Instruct：

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/06/13/ML-18505-image-1.jpeg)

在后续演练中你将使用 `Qwen/Qwen2.5-Coder-7B-Instruct`。我们不演示 fine-tuning 步骤，但你可以在导入前先进行[fine-tune](https://docs.aws.amazon.com/sagemaker/latest/dg/jumpstart-fine-tune.html)。

- 使用以下命令在本地下载模型快照。Hugging Face 的 Python 库提供了一个名为 snapshot download 的工具来完成此操作：

```
from huggingface_hub import snapshot_download

snapshot_download(repo_id=" Qwen/Qwen2.5-Coder-7B-Instruct", 
                local_dir=f"./extractedmodel/")
```

根据模型大小，这可能需要几分钟。完成后，你的 Qwen Coder 7B 模型文件夹将包含以下文件。

- **配置文件**：包括 `config.json`、`generation_config.json`、`tokenizer_config.json`、`tokenizer.json` 和 `vocab.json`
- **模型文件**：四个 `safetensor` 文件和 `model.safetensors.index.json`
- **文档**：`LICENSE`、`README.md` 和 `merges.txt`

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/06/13/ML-18505-image-2.jpeg)

- 使用 `boto3` 或命令行将模型上传到 Amazon S3：

`aws s3 cp ./extractedfolder s3://yourbucket/path/ --recursive`

- 使用以下 API 调用启动模型导入任务：

```
response = self.bedrock_client.create_model_import_job(
                jobName="uniquejobname",
                importedModelName="uniquemodelname",
                roleArn="fullrolearn",
                modelDataSource={
                    's3DataSource': {
                        's3Uri': "s3://yourbucket/path/"
                    }
                }
            )
            
```

你也可以使用 Amazon Bedrock 的 AWS Management Console 来完成此操作。

- 在 Amazon Bedrock 控制台中，从导航窗格选择 **Imported models**。
- 选择 **Import a model**。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/06/13/ML-18505-image-3.jpeg)

- 输入详细信息，包括 **Model name**、**Import job name** 和模型 **S3 location**。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/06/13/ML-18505-image-4.jpeg)

- 创建新的服务角色或使用现有服务角色。然后选择 Import model

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/06/13/ML-18505-image-5.jpeg)

- 在控制台选择 **Import** 后，导入过程中你会看到状态显示为 importing：

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/06/13/ML-18505-image-6.jpeg)

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/06/13/ML-18505-image-7.jpeg)

如果你使用自己的角色，请确保按照[为模型导入创建服务角色](https://docs.aws.amazon.com/bedrock/latest/userguide/model-import-iam-role.html)中的说明添加以下信任关系。

模型导入后，等待模型推理准备就绪，然后在 playground 中或通过 API 与模型对话。在以下示例中，我们追加 `Python` 来提示模型直接输出用于列出 S3 存储桶中对象的 Python 代码。请记住使用正确的 chat template，以所需格式输入 prompt。例如，你可以使用下面的代码在 Hugging Face 上获取任何兼容模型的正确 chat template：

```
from transformers import AutoTokenizer
tokenizer = AutoTokenizer.from_pretrained("Qwen/Qwen2.5-Coder-7B-Instruct")

# Instead of using model.chat(), we directly use model.generate()
# But you need to use tokenizer.apply_chat_template() to format your inputs as shown below
prompt = "Write sample boto3 python code to list files in a bucket stored in the variable `my_bucket`"
messages = [
    {"role": "system", "content": "You are a helpful coding assistant."},
    {"role": "user", "content": prompt}
]
text = tokenizer.apply_chat_template(
    messages,
    tokenize=False,
    add_generation_prompt=True
)
```

请注意，使用 `invoke_model` API 时，必须为导入的模型使用完整的 Amazon Resource Name（ARN）。你可以在 Bedrock 控制台中找到 Model ARN：导航到 Imported models 部分，然后查看 Model details 页面，如下图所示

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/06/13/ML-18505-image-8.jpeg)

模型准备好推理后，你可以使用 Bedrock 控制台中的 Chat Playground 或通过 API 调用模型。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/06/13/ML-18505-image-9.jpeg)

## 用例 2：Qwen 2.5 VL 图像理解

Qwen2.5-VL-* 提供多模态能力，将视觉和语言理解结合在一个模型中。本节演示如何使用 Amazon Bedrock Custom Model Import 部署 Qwen2.5-VL，并测试其图像理解能力。

### 将 Qwen2.5-VL-7B 导入 Amazon Bedrock

从 Hugging Face 下载模型并上传到 Amazon S3：

```
from huggingface_hub import snapshot_download

hf_model_id = "Qwen/Qwen2.5-VL-7B-Instruct"

# Enable faster downloads
os.environ["HF_HUB_ENABLE_HF_TRANSFER"] = "1"

# Download model locally
snapshot_download(repo_id=hf_model_id, local_dir=f"./{local_directory}")
```

接着，将模型导入 Amazon Bedrock（通过控制台或 API）：

```
response = bedrock.create_model_import_job(
    jobName=job_name,
    importedModelName=imported_model_name,
    roleArn=role_arn,
    modelDataSource={
        's3DataSource': {
            's3Uri': s3_uri
        }
    }
)
```

### 测试视觉能力

导入完成后，用图像输入测试模型。Qwen2.5-VL-* 模型要求对多模态输入进行正确的格式化：

```
def generate_vl(messages, image_base64, temperature=0.3, max_tokens=4096, top_p=0.9):
    processor = AutoProcessor.from_pretrained("Qwen/QVQ-72B-Preview")
    prompt = processor.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
    
    response = client.invoke_model(
        modelId=model_id,
        body=json.dumps({
            'prompt': prompt,
            'temperature': temperature,
            'max_gen_len': max_tokens,
            'top_p': top_p,
            'images': [image_base64]
        }),
        accept='application/json',
        contentType='application/json'
    )
    
    return json.loads(response['body'].read().decode('utf-8'))

# Using the model with an image
file_path = "cat_image.jpg"
base64_data = image_to_base64(file_path)

messages = [
    {
        "role": "user",
        "content": [
            {"image": base64_data},
            {"text": "Describe this image."}
        ]
    }
]

response = generate_vl(messages, base64_data)

# Print response
print("Model Response:")
if 'choices' in response:
    print(response['choices'][0]['text'])
elif 'outputs' in response:
    print(response['outputs'][0]['text'])
else:
    print(response)
    
```

## 定价

你可以使用 Amazon Bedrock Custom Model Import 在 Amazon Bedrock 中针对受支持的架构使用自定义模型权重，并通过 On-Demand 模式以全托管方式将其与 Amazon Bedrock 托管的 FM 一起提供服务。Custom Model Import 不收取模型导入费用。推理费用基于两个因素计费：活跃模型副本的数量及其活跃时长。计费以 5 分钟为增量，从每个模型副本首次成功调用开始。每个模型副本每分钟的价格因架构、上下文长度、Region 和计算单元版本等因素而异，并按模型副本大小分档。托管所需的自定义模型单元取决于模型的架构、参数量和上下文长度。Amazon Bedrock 会根据你的使用模式自动管理扩缩容。如果 5 分钟内没有调用，它会缩容至零，并在需要时扩容，不过这可能带来长达一分钟的冷启动延迟。如果推理量持续超过单副本并发上限，就会增加额外的副本。每个副本的最大吞吐量和并发数在导入时确定，依据包括输入/输出 token 比例、硬件类型、模型大小、架构和推理优化等因素。

更多信息请参阅 [Amazon Bedrock 定价](https://aws.amazon.com/bedrock/pricing/)。

## 清理

完成实验后，为避免持续产生费用：

- 使用控制台或 API，从 Amazon Bedrock Custom Model Import 中删除你导入的 Qwen 模型。
- 如果不再需要，也可以从 S3 存储桶中删除模型文件。

请记住，尽管 Amazon Bedrock Custom Model Import 本身不收取导入费用，但模型推理用量和存储仍会计费。

## 结论

Amazon Bedrock Custom Model Import 使组织能够使用 Qwen 2.5 等强大的公开可用模型，同时受益于企业级基础设施。Amazon Bedrock 的 serverless 特性消除了管理模型部署和运维的复杂性，使团队能够专注于构建应用而非基础设施。凭借自动扩缩容、按使用量付费以及与 AWS 服务无缝集成等特性，Amazon Bedrock 为 AI 工作负载提供了可用于生产的环境。Qwen 2.5 先进的 AI 能力与 Amazon Bedrock 托管基础设施相结合，在性能、成本和运营效率之间实现了最佳平衡。组织可以从较小的模型开始，按需扩展，同时保持对模型部署的完全控制，并受益于 AWS 的安全与合规能力。

更多信息请参阅 [Amazon Bedrock 用户指南。](https://docs.aws.amazon.com/bedrock/latest/userguide/model-customization-import-model.html)
