Amazon Bedrock now supports cost allocation by IAM principal (users and roles) for inference requests made through the

bedrock-mantle

endpoint, extending the capability previously available for

bedrock-runtime

. Tag IAM users and roles with attributes such as team, project, or cost center, activate them as cost allocation tags, and analyze

bedrock-mantle

inference costs by those tags in AWS Cost Explorer or at the line-item level in AWS Cost and Usage Report 2.0 (CUR 2.0). Available in all AWS Regions where the

bedrock-mantle

endpoint is available. For more information, see

IAM principal attribution in Amazon Bedrock

.
