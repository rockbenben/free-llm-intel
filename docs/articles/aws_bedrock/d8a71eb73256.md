# 用 OpenAI 与 AWS 加速网络防御：Daybreak Red 与 Daybreak Blue 现已在 Amazon Bedrock 上向符合条件的客户提供

网络防御者从未拥有过如此强大的能力，也从未如此需要这种能力。前沿模型如今可以跨越整个代码库进行推理，把漏洞追溯到其根本原因，并在几分钟内提出修复方案。同样的能力也为攻击者所用。这正是从漏洞被披露到被利用之间的窗口不断缩短的原因。防御者被期望跟上那些庞杂而陌生的代码库，判断哪些发现真正重要，并交付经得起考验的补丁。他们必须在完成这一切的同时，把敏感代码和漏洞数据留在一个自己可控且可审计的环境中。挑战已不再是浮出潜在问题，而是确认哪些问题真实存在、修复它们，并在窗口关闭之前完成。

AWS 一贯遵循「安全从设计之初就内建」这一原则。AI 也是如此：客户在 [Amazon Bedrock](https://aws.amazon.com/bedrock/) 上运行工作负载，从推理到完全自主的 agent，都处在他们在整个 AWS 上所依赖的同一套基础设施、控制与治理之下。今天，AWS 与 OpenAI 把这一基础延伸到了网络防御领域。来自 OpenAI 的 Daybreak Red 和 Daybreak Blue 现已在 Amazon Bedrock 上向符合条件的客户提供。Daybreak Red 提供对 GPT-5.6 Cyber 的访问，这是一款经过专门训练的网络安全模型。Daybreak Blue 提供对 GPT-5.6 Sol 的访问，其防护措施针对防御性网络安全工作进行了校准。两者都属于 Daybreak——OpenAI 的网络防御计划，它让防御者以受治理的方式使用前沿 AI，包括 agent 工具、应用红队测试，以及帮助防御者从发现问题走向经过验证的修复方案的服务。

> “AWS 与 OpenAI 抱有同一个信念：防御者应当占据优势。这次合作把 OpenAI 的 Daybreak Red 和 Daybreak Blue 带到了 Amazon Bedrock。AWS 安全团队如今正在使用这两款模型分析源代码、发现漏洞并开展红队研究。在 Bedrock 上，这些工作运行在 AWS 用于所有其他关键工作负载的同一套基础设施控制之下。随着这些模型不断进步，防御者在 Amazon Bedrock 上能用它们做到的事情也会不断拓展。”

— John Sheehan，AWS 安全副总裁

## 面向高级、经授权的网络安全工作的专用模型

从漏洞发现到修复的路径很漫长：确认可利用性、追踪有漏洞的组件如何被触达、开发一个能解决根本原因又不引入回归的修复、验证它在真实条件下依然成立，以及在披露窗口内发布补丁。防御者需要能够加速每一个环节的模型。但网络安全本质上是两用的。一个复现漏洞或逆向分析漏洞利用链的请求，无论意图如何，看起来都一模一样，通用模型通过拒绝请求来消解这种模糊性。Daybreak Red 和 Daybreak Blue 则通过上下文来消解它：谁在使用模型、工作发生在哪里，以及有哪些防护措施在治理这种访问。

对大多数安全团队来说，Daybreak Blue 是合适的起点。它支持漏洞发现、检测工程和事件响应。Daybreak Red 面向漏洞研究、漏洞利用复现和缓解措施开发等高级任务。就这些任务而言，更低的拒绝阈值（即模型拒绝请求的临界点）配以更强的身份验证、监控和访问控制，可以提升调查的速度与深度。

据 OpenAI 称，安全研究人员通过 Daybreak Red 使用 GPT-5.6 Cyber，在 Chrome 所用的 JavaScript 引擎 V8 中发现了两个此前未知的漏洞，两者串联起来可能造成内存破坏并逃逸堆沙箱。最初的漏洞已被修复，并以 CVE-2026-15903 发布，这是 2026 年 V8 CTF 仅有的四个成功的零日提交之一。

## 在你已经信任的基础上运行

网络安全工作负载会把你最敏感的输入喂给模型：专有源代码、尚未修补的漏洞细节，以及来自生产系统的实时遥测数据。在这一切流经模型之前，你需要确信它会去哪里、谁能看到它。

两款模型都运行在为高性能、安全与可靠性而构建的 Amazon Bedrock 新一代推理引擎上。零操作员访问（ZOA）在芯片层面强制执行，因此即使在推理过程中，AWS 的操作人员也无法访问你的 prompt 和补全结果。数据在传输中和静态存储时均已加密。访问由你的 AWS Identity and Access Management（IAM）策略治理，记录在 AWS CloudTrail 中，并通过虚拟私有云（VPC）端点路由。你可以在组织级别设置数据边界策略，防止数据跨账户和网络边界外泄。

你的推理数据不会用于模型训练，这两款模型也都不要求你选择与 OpenAI 共享数据。对于[自动化滥用检测](https://docs.aws.amazon.com/bedrock/latest/userguide/abuse-detection.html)，被分类器标记的流量会由 AWS 保留最多 30 天并以程序化方式处理。客户可以通过其 AWS 客户团队申请零数据保留。详情请参阅[数据保留说明](https://docs.aws.amazon.com/bedrock/latest/userguide/data-retention.html#data-retention-zdr)。

## 开始使用

Daybreak Red: GPT-5.6 Cyber 与 Daybreak Blue: GPT-5.6 Sol 现已在以下 [AWS 区域](https://docs.aws.amazon.com/bedrock/latest/userguide/models-region-compatibility.html)的 Amazon Bedrock 上向符合条件的客户提供：美国东部（俄亥俄）。访问这些模型需要注册 OpenAI 的 [Trusted Access for Cyber](https://openai.com/form/enterprise-trusted-access-for-cyber/)。要注册，请联系 OpenAI，或联系你的 AWS 客户团队获取资格方面的指导。获批之后，与你的客户团队合作在 AWS 上申请访问权限。了解更多信息，请参阅[文档](https://docs.aws.amazon.com/bedrock/latest/userguide/model-cards-openai.html)。

要探索 Amazon Bedrock 上完整的 GPT-5.6 系列，请参阅[在 Amazon Bedrock 上开始使用 OpenAI GPT-5.6 Sol、Terra 和 Luna](https://aws.amazon.com/blogs/machine-learning/get-started-with-openai-gpt-5-6-sol-terra-and-luna-on-amazon-bedrock/)。
