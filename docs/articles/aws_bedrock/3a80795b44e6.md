# 使用 Strands Agents 与 Amazon Bedrock 构建药物发现研究助手

药物发现是一个复杂、耗时的过程，研究者需要穿行于海量科学文献、临床试验数据和分子数据库之间。像 [Genentech](https://aws.amazon.com/solutions/case-studies/genentech-generativeai-case-study/) 和 [AstraZeneca](https://www.youtube.com/watch?v=mnww9PJ6ir4) 这样的生命科学客户，正在使用 AI agent 和其他生成式 AI 工具来加快科学发现的速度。这些组织的构建者已经在使用 [Amazon Bedrock](https://aws.amazon.com/bedrock) 的全托管功能，为各种用例快速部署[领域特定的工作流](https://aws.amazon.com/blogs/industries/accelerating-life-sciences-innovation-with-agentic-ai-on-aws/)，从早期的药物靶点识别到与医疗服务机构的互动。

不过，更复杂的用例可能更适合使用开源的 [Strands Agents SDK](https://strandsagents.com/latest/)。Strands Agents 采用模型驱动的方式来开发与运行 AI agent。它可与大多数模型提供方配合，包括自定义和内部的大语言模型（LLM）网关，并且 agent 可以部署在你原本托管 Python 应用的地方。

本文演示如何使用 Strands Agents 与 [Amazon Bedrock](https://aws.amazon.com/bedrock/) 创建一个强大的药物发现研究助手。这个 AI 助手可以通过 [Model Context Protocol（MCP）](https://modelcontextprotocol.io/introduction) 同时检索多个科学数据库，综合其发现，并针对药物靶点、疾病机制和治疗领域生成完整的报告。该助手已作为示例收录在开源的[医疗与生命科学 agent 工具包](https://github.com/aws-samples/amazon-bedrock-agents-healthcare-lifesciences)中，供你使用与改造。

## 方案概览

该方案使用 Strands Agents，把高性能基础模型（FM）与常见的生命科学数据源（如 [arXiv](https://arxiv.org/)、[PubMed](https://pubmed.ncbi.nlm.nih.gov/) 和 [ChEMBL](https://www.ebi.ac.uk/chembl/)）连接起来。它演示了如何快速创建 MCP server 来查询数据，并在对话式界面中查看结果。

[协同工作的、小而专注的 AI agent](https://aws.amazon.com/blogs/machine-learning/best-practices-for-building-robust-generative-ai-applications-with-amazon-bedrock-agents-part-1/)往往能比单个庞大的 agent 产出更好的结果。该方案使用一组 sub-agent，每个都有自己的 FM、指令和工具。下面的流程图展示了 orchestrator agent（橙色）如何处理用户查询，并把它们路由到负责信息检索（绿色）的 sub-agent，或负责规划、综合与报告生成（紫色）的 sub-agent。

[![研究系统架构图：通过 orchestrator 连接 Web、学术与医学数据库，产出综合报告](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/07/07/ML-19024-image-1.png)](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/07/07/ML-19024-image-1.png)

本文聚焦于在本地开发环境中使用 Strands Agents 进行构建。要在 [AWS Lambda](https://aws.amazon.com/lambda)、[AWS Fargate](https://aws.amazon.com/fargate/)、[Amazon Elastic Kubernetes Service](https://aws.amazon.com/eks/)（Amazon EKS）或 [Amazon Elastic Compute Cloud](https://aws.amazon.com/ec2/)（Amazon EC2）上部署生产 agent，请参阅 [Strands Agents documentation](https://strandsagents.com/latest/user-guide/deploy/operating-agents-in-production/)。

以下各节展示如何在 Strands Agents 中，通过定义 FM、MCP 工具和 sub-agent 来创建该研究助手。

## 前置条件

该方案需要 Python 3.10+、[strands-agents](https://pypi.org/project/strands-agents/) 以及若干额外的 Python 包。我们强烈建议使用 venv 或 [uv](https://docs.astral.sh/uv/) 之类的虚拟环境来管理这些依赖。

按以下步骤把该方案部署到本地环境：

- 从 GitHub 克隆[代码仓库](https://github.com/aws-samples/sample-build-a-life-science-research-assistant-using-strands-agents)。
- 用 `pip install -r requirements.txt` 安装所需的 Python 依赖。
- 通过[设置为环境变量](https://docs.aws.amazon.com/cli/latest/userguide/cli-configure-envvars.html)、[写入凭证文件](https://docs.aws.amazon.com/cli/latest/userguide/cli-configure-files.html)或遵循其他[受支持的方式](https://docs.aws.amazon.com/cli/latest/userguide/cli-chap-authentication.html)来配置你的 AWS 凭证。
- 按以下格式把你的 Tavily API key 保存到 .env 文件：`TAVILY_API_KEY="YOUR_API_KEY"`。

你还需要在 AWS 账户中获得对以下 Amazon Bedrock FM 的[访问权限](https://docs.aws.amazon.com/bedrock/latest/userguide/model-access-modify.html)：

- Anthropic 的 Claude 3.7 Sonnet
- Anthropic 的 Claude 3.5 Sonnet
- Anthropic 的 Claude 3.5 Haiku

## 定义基础模型

我们先使用 Strands Agents 的 `BedrockModel` 类，定义到 Amazon Bedrock 中某个 FM 的连接。我们使用 Anthropic 的 Claude 3.7 Sonnet 作为默认模型。见以下代码：

```
from strands import Agent, tool
from strands.models import BedrockModel
from strands.agent.conversation_manager import SlidingWindowConversationManager
from strands.tools.mcp import MCPClient
# Model configuration with Strands using Amazon Bedrock's foundation models
def get_model():
    model = BedrockModel(
        boto_client_config=Config(
            read_timeout=900,
            connect_timeout=900,
            retries=dict(max_attempts=3, mode="adaptive"),
        ),
        model_id="us.anthropic.claude-3-7-sonnet-20250219-v1:0",
        max_tokens=64000,
        temperature=0.1,
        top_p=0.9,
        additional_request_fields={
            "thinking": {
                "type": "disabled"  # Can be enabled for reasoning mode
            }
        }
    )
    return model
```

## 定义 MCP 工具

MCP 规定了 AI 应用如何与其外部环境交互的标准。目前已有数千个 MCP server，包括面向生命科学工具与数据集的 server。该方案为以下对象提供了示例 MCP server：

- [arXiv](https://arxiv.org/) – 开放获取的学术文章库
- [PubMed](https://pubmed.ncbi.nlm.nih.gov/) – 生物医学文献的同行评审引文库
- [ChEMBL](https://www.ebi.ac.uk/chembl/) – 经人工整理的、具有类药特性的生物活性分子数据库
- [ClinicalTrials.gov](https://clinicaltrials.gov/) – 美国政府的临床研究数据库
- [Tavily Web Search](https://www.tavily.com/) – 用于从公共互联网查找近期新闻及其他内容的 API

Strands Agents 简化了我们为 agent 定义 MCP client 的过程。在这个示例中，你使用标准 I/O 连接各个工具。不过，Strands Agents 也支持[使用 Streamable-HTTP Events 传输的远程 MCP server](https://strandsagents.com/latest/user-guide/concepts/tools/mcp-tools/#2-streamable-http)。见以下代码：

```
# MCP Clients for various scientific databases
tavily_mcp_client = MCPClient(lambda: stdio_client(
    StdioServerParameters(command="python", args=["application/mcp_server_tavily.py"])
))
arxiv_mcp_client = MCPClient(lambda: stdio_client(
    StdioServerParameters(command="python", args=["application/mcp_server_arxiv.py"])
))
pubmed_mcp_client = MCPClient(lambda: stdio_client(
    StdioServerParameters(command="python", args=["application/mcp_server_pubmed.py"])
))
chembl_mcp_client = MCPClient(lambda: stdio_client(
    StdioServerParameters(command="python", args=["application/mcp_server_chembl.py"])
))
clinicaltrials_mcp_client = MCPClient(lambda: stdio_client(
    StdioServerParameters(command="python", args=["application/mcp_server_clinicaltrial.py"])
))
```

## 定义专用 sub-agent

规划 agent 审视用户的问题，并制定使用哪些 sub-agent 与工具的计划：

```
@tool
def planning_agent(query: str) -> str:
    """
    A specialized planning agent that analyzes the research query and determines
    which tools and databases should be used for the investigation.
    """
    planning_system = """
    You are a specialized planning agent for drug discovery research. Your role is to:
    
    1. Analyze research questions to identify target proteins, compounds, or biological mechanisms
    2. Determine which databases would be most relevant (Arxiv, PubMed, ChEMBL, ClinicalTrials.gov)
    3. Generate specific search queries for each relevant database
    4. Create a structured research plan
    """
    model = get_model()
    planner = Agent(
        model=model,
        system_prompt=planning_system,
    )
    response = planner(planning_prompt)
    return str(response)
```

类似地，综合 agent 把来自多个来源的发现整合成一份完整的报告：

```
@tool
def synthesis_agent(research_results: str) -> str:
    """
    Specialized agent for synthesizing research findings into a comprehensive report.
    """
    system_prompt = """
    You are a specialized synthesis agent for drug discovery research. Your role is to:
    
    1. Integrate findings from multiple research databases
    2. Create a comprehensive, coherent scientific report
    3. Highlight key insights, connections, and opportunities
    4. Organize information in a structured format:
       - Executive Summary (300 words)
       - Target Overview
       - Research Landscape
       - Drug Development Status
       - References
    """
    model = get_model()
    synthesis = Agent(
        model=model,
        system_prompt=system_prompt,
    )
    response = synthesis(synthesis_prompt)
    return str(response)
```

## 定义编排 agent

我们还定义了一个编排 agent 来协调整个研究工作流。该 agent 使用 Strands Agents 的 `SlidingWindowConversationManager` 类来保存对话中最近 10 条消息。见以下代码：

```
def create_orchestrator_agent(
    history_mode,
    tavily_client=None,
    arxiv_client=None,
    pubmed_client=None,
    chembl_client=None,
    clinicaltrials_client=None,
):
    system = """
    You are an orchestrator agent for drug discovery research. Your role is to coordinate a multi-agent workflow:
    
    1. COORDINATION PHASE:
       - For simple queries: Answer directly WITHOUT using specialized tools
       - For complex research requests: Initiate the multi-agent research workflow
    
    2. PLANNING PHASE:
       - Use the planning_agent to determine which databases to search and with what queries
    
    3. EXECUTION PHASE:
       - Route specialized search tasks to the appropriate research agents
    
    4. SYNTHESIS PHASE:
       - Use the synthesis_agent to integrate findings into a comprehensive report
       - Generate a PDF report when appropriate
    """
    # Aggregate all tools from specialized agents and MCP clients
    tools = [planning_agent, synthesis_agent, generate_pdf_report, file_write]
    # Dynamically load tools from each MCP client
    if tavily_client:
        tools.extend(tavily_client.list_tools_sync())
    # ... (similar for other clients)
    conversation_manager = SlidingWindowConversationManager(
        window_size=10,  # Maintains context for the last 10 exchanges
    )
    orchestrator = Agent(
        model=model,
        system_prompt=system,
        tools=tools,
        conversation_manager=conversation_manager
    )
    return orchestrator
```

## 示例用例：探索近期的乳腺癌研究

要测试这个新助手，请运行 streamlit run application/app.py 启动聊天界面，并在浏览器中打开本地 URL（通常是 http://localhost:8501）。下面的截图展示了与研究 agent 的一次典型对话。在这个示例中，我们这样要求助手：“Please generate a report for HER2 including recent news, recent research, related compounds, and ongoing clinical trials.”。助手首先利用手中可用的各种工具制定一份完整的研究计划。它决定先做网络搜索，查找 HER2 的近期新闻，以及 PubMed 和 arXiv 上的科学文章。它还会查看 ChEMBL 中与 HER2 相关的化合物以及正在进行的临床试验。它把这些结果综合成一份报告，并生成包含引用的发现输出文件。

[![Amazon Bedrock 驱动的药物发现 agent 聊天界面，展示为 HER2 生成研究报告的系统化过程](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/07/07/ML-19024-image-2.jpeg)](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/07/07/ML-19024-image-2.jpeg)

以下是一份生成报告的节选：

```
Comprehensive Scientific Report: HER2 in Breast Cancer Research and Treatment
1. Executive Summary
Human epidermal growth factor receptor 2 (HER2) continues to be a critical target in breast cancer research and treatment development. This report synthesizes recent findings across the HER2 landscape highlighting significant advances in understanding HER2 biology and therapeutic approaches. The emergence of antibody-drug conjugates (ADCs) represents a paradigm shift in HER2-targeted therapy, with trastuzumab deruxtecan (T-DXd, Enhertu) demonstrating remarkable efficacy in both early and advanced disease settings. The DESTINY-Breast11 trial has shown clinically meaningful improvements in pathologic complete response rates when T-DXd is followed by standard therapy in high-risk, early-stage HER2+ breast cancer, potentially establishing a new treatment paradigm.
```

值得注意的是，你无需为完成这项任务定义逐步流程。只要给助手一份文档齐全的工具清单，它就能自行决定使用哪些工具以及使用的顺序。
