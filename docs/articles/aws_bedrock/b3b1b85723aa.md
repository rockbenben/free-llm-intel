# 安全地向客户发布前沿模型

让 AWS 成为运行任何工作负载时最安全的地方，是我们的目标；为此，自二十多年前 AWS 创立以来，我们就持续深入投入各项服务的安全性。我们的 AI 服务（例如 Amazon Bedrock）建立在这一基础之上，也秉持同样的专注。Bedrock 为客户提供世界级的性能、安全与隐私，以及任何地方都能获得的最广泛的模型选择。去年，我们推出了 Bedrock Mantle，具备[业界领先的隐私保护](https://aws.amazon.com/blogs/machine-learning/exploring-the-zero-operator-access-design-of-mantle/)与模型权重保护。我们经常听到客户希望在新模型发布后尽快获得访问权限，Bedrock 正是这样做的，同时提供客户期望从 AWS 获得的企业级功能。我们很高兴 Anthropic 的 Claude Fable 5 模型重新在 Bedrock 上向客户开放，并且带有更强的防护措施来防止滥用。

在发布模型时，我们不仅考虑对客户的责任，也考虑对互联网与整个社会的责任。最新一代前沿模型（例如 Anthropic 的 Claude Mythos）具备强大的新能力，尤其是在网络安全领域。作为 Project Glasswing 的一员，我们得以亲身感受这一点，也迫切希望把 Mythos 级模型交到防御者手中。作为防御者，我们有机会用这些模型让我们共同依赖的系统变得显著更安全。但在这样做的同时，我们也必须确保：在给公司、政府和学术机构留出先行保护自身资产的机会之前，不会让对手获得实质性的先进可见性与能力。把握这一平衡是广泛发布模型的关键挑战，这也是我们一直与 Anthropic 及 Project Glasswing 的其他行业伙伴紧密合作、完善这类新模型防护措施的原因。我们一致认为，阻止对手获得深度漏洞研究能力，是这些防护措施最重要的目标。

对 AI 而言这也是一个激动人心的时期，新能力几乎每天都在涌现。我们相信，在安全且保护隐私的环境中把这些先进模型的能力提供给所有客户，对于确保他们获得诸多收益而不制造安全风险至关重要。随着我们对现有防护措施效果的了解不断加深、新模型不断发布，持续开发新的防护措施十分重要。我们将继续与合作伙伴迭代，交付更多价值，并积极回应行业的变化。

同样重要的是，确保这些模型发布后出现的任何问题都得到妥善处理。Anthropic 发布了一篇博客 [Redeploying Fable 5](https://www.anthropic.com/news/redeploying-fable-5)，说明他们如何看待这类新模型的能力，以及他们针对上报问题作出响应的承诺与 SLA。我们赞赏 Anthropic 在阐明这套面向具备网络能力的模型的问题严重程度与响应框架时所展现的透明度与协作精神，也期待随着我们不断学习与完善，整个行业能持续对话。

我们的 AI Red Team 与 Anthropic 合作，进一步改进了 Fable 的防护。我们相信其最新的防护措施造就了一个非常强大的模型，同时进一步降低了被对手滥用的风险。它在大多数领域兑现了推理能力大幅增强的承诺，又没有给对手带来显著的新攻击能力。当防护措施被触发时，它会自动回退到 Opus 4.8——这本身就是一个已经公开可用、世界级的模型。

我们赞赏 Anthropic 的合作以及对防御者的承诺，并期待与他们以及行业其他伙伴携手，继续安全、稳妥地提供前沿模型。
