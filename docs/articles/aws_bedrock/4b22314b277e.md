# Rocket 如何借助 Amazon Bedrock Agents 简化购房体验

[Rocket Companies](https://rocket.com/) 是一家总部位于底特律的金融科技公司，使命是“Help Everyone Home”。尽管很多人把它视为一家抵押贷款机构，但 Rocket 的使命覆盖整个房屋所有权旅程：从找到理想的房子、购买、融资，到使用你的房屋净值。Rocket 通过把复杂变简单而成长，赋权客户借助直观、技术驱动的方案走完房屋所有权旅程。Rocket 的 Web 与移动应用把房源搜索、融资与贷后服务整合为一次无缝体验。通过把数据分析与自身的 11PB 数据同先进自动化相结合，Rocket 加快了从贷款审批到贷后服务的每一个环节，同时在大规模下依然保持个性化的服务质感。

以客户为先的方式是 Rocket 一切工作的核心。凭借可定制的数字工具以及来自资深抵押贷款银行家的专业指导，Rocket 力求快速、准确且安全地为每位客户匹配合适的产品与合适的支持。

随着[生成式 AI](https://aws.amazon.com/generative-ai/) 的出现，Rocket 看到了更进一步的机会。买房依然可能让人感到不堪重负。这促使 Rocket 提出一个问题：我们怎样才能在任何时间、任何渠道都提供客户所期待的同样值得信赖的指导？答案是 Rocket AI Agent——一个对话式 AI 助手，旨在改变客户与 Rocket 数字资产互动的方式。Rocket AI Agent 构建在 [Amazon Bedrock Agents](https://aws.amazon.com/bedrock/agents/) 之上，融合了深厚的领域知识、个性化指导，以及代表客户执行有意义动作的能力。自上线以来，它已成为 Rocket 客户体验的核心部分。与不使用 Rocket AI Agent 的客户相比，使用它的客户完成贷款的可能性高出三倍。

由于它直接嵌入 Rocket 的 Web 与移动服务中，因此能在客户恰好需要的时间与地点提供支持。本文探讨 Rocket 如何用 Amazon Bedrock Agents 把这一愿景变为现实，开启一个 AI 驱动支持的新时代——始终可用、深度个性化，并且生来就能采取行动。

## 认识 Rocket AI Agent：个性化的 AI 房屋所有权指南

Rocket AI Agent 目前已在 Rocket 的大多数网页与移动应用中可用。它在贷款发起、贷后服务阶段，甚至 Rocket 的第三方经纪系统（Rocket Pro）中为客户提供帮助，基本上在客户与 Rocket 数字渠道互动的任何地方都能与之相遇。Rocket AI Agent 是一个专门打造的 AI agent，其设计目标不止于回答问题。它提供实时的个性化指导，并在需要时采取行动。它提供：

- **全天候、多语言协助**，通过 Rocket 的网站与移动服务提供
- **上下文感知**。Rocket AI agent 知道客户当时正在浏览哪个页面，并据此调整回复
- **实时答案**，涵盖抵押贷款选项、利率、文件与流程
- **引导式自助操作**，例如填写预审批表单或安排付款
- **个性化体验**，借助 Rocket 的专有数据与用户上下文
- **无缝转接**，在需要人工支持时转接到 Rocket Mortgage 的银行家

无论是想知道自己的托管账户为何发生变化，还是想了解如何获得再融资资格，Rocket AI Agent 都会以清晰、自信和可执行的方式作答。

## Amazon Bedrock Agents

[Amazon Bedrock Agents](https://aws.amazon.com/bedrock/agents/) 是一项全托管、基于云的能力，客户用它可以在 [Amazon Web Services](https://aws.amazon.com/)（AWS）上快速构建、测试并扩展 agentic AI 应用。凭借内置的集成与安全性，像 Rocket 这样的客户使用 Amazon Bedrock Agents，安全可靠地从概念验证加速走向生产。这些 agent 使用[推理与行动（ReAct）框架](https://aws.amazon.com/blogs/machine-learning/getting-started-with-amazon-bedrock-agents-custom-orchestrator/)扩展[基础模型](https://aws.amazon.com/what-is/foundation-models/)（FM），使其能够解读用户意图、规划并执行任务，并像熟练的数字助手那样与企业数据和 API 无缝集成。

Agent 使用 FM 分析用户请求，将其拆解为可执行的步骤，检索相关数据，并触发下游 API 来完成任务。这让 Rocket AI Agent 得以从被动支持走向主动协助，帮助客户实时应对复杂的金融流程。Rocket AI Agent 所使用的 Amazon Bedrock Agents 关键能力包括：

- [**Agent 指令**](https://docs.aws.amazon.com/bedrock/latest/userguide/agents-how.html#agents-btl) – 设定 agent 的目标与角色（例如抵押贷款贷后服务专家），从而支持目标导向的行为
- [**Amazon Bedrock Knowledge Bases**](https://aws.amazon.com/bedrock/knowledge-bases/) – 从 Rocket 的学习中心与其他专有文档中提供快速、准确的信息检索
- [**Action group（动作组）**](https://docs.aws.amazon.com/bedrock/latest/userguide/agents-action-create.html) – 定义安全操作——例如提交销售线索或安排付款——agent 可以通过与 Rocket 的后端服务交互来执行这些操作
- [**Agent memory（agent 记忆）**](https://docs.aws.amazon.com/bedrock/latest/userguide/agents-memory.html) – 保留记忆让 Rocket AI Agent 能在多轮对话中保持上下文感知，以更自然、更个性化的交互提升用户体验。
- [**Amazon Bedrock Guardrails**](https://aws.amazon.com/bedrock/guardrails/) – 通过确保 agent 停留在恰当的主题边界内，支持 Rocket 的负责任 AI 目标。

通过把结构化推理与跨系统行动的能力结合起来，Amazon Bedrock Agents 让 Rocket AI Agent 能够交付结果，而不只是答案。

## Rocket AI Agent 如何工作：架构概览

Rocket AI Agent 是一项集中化的能力，部署在 Rocket 的全套数字资产中，其设计兼顾规模、灵活性与针对具体任务的精确性。其架构的核心是一个不断扩展的领域专用 agent 网络，目前有八个，每个都聚焦于不同职能，例如贷款发起、贷后服务或经纪支持。这些 agent 在统一界面之后协同工作，提供无缝、具备上下文感知的协助。下图展示了方案架构。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/06/03/RocketAgents.jpg)

以下是塑造 Rocket AI Agent 架构的三个基础要素：

- **客户端发起：** 客户使用 Rocket 移动应用或网页中的聊天功能
- **Rocket AI Agent API：** Rocket 的 AI Agent API 为支撑聊天功能的各个 agent 提供统一的 API 接口
- **Agent 路由：** AI Agent API 依据静态条件（例如客户进入聊天时所处的 Web 或移动端资产）或使用基于 LLM 的意图识别，把请求路由到正确的 Amazon Bedrock agent
- **Agent 处理：** agent 把任务拆分为子任务，确定正确的顺序，并在处理过程中执行动作与知识查询
- **任务执行：** agent 使用知识库中的 Rocket 数据查找信息、把结果发送给客户，并执行动作以完成工作
- **Guardrails：** 通过拦截偏离体验目标的主题与语言，执行 Rocket 的[负责任 AI](https://aws.amazon.com/ai/responsible-ai/) 政策
- **Prompt 管理：** 帮助 Rocket 管理其 AI agent 的 prompt 库，并针对特定 FM 优化 prompt

这种模块化、可扩展的设计让 Rocket 能够高效、一致地服务多样化的客户需求，跨越各项服务以及整个房屋所有权生命周期。

## 影响与成果

自 Rocket AI Agent 上线以来，我们在客户旅程与内部运营中都看到了变革性的改进：

- **转化率提升三倍**（从网站流量到贷款结清），因为 Rocket AI Agent 能全天候获取线索，即便在传统营业时间之外也是如此。
- **运营效率提升**，尤其体现在聊天拦截（chat containment）上。随着 AI 助手投入用于支持正在了解 Rocket 产品的潜在客户，Rocket 转接到客户关怀部门的量下降了 85%，转接到贷后服务专家的量下降了 45%。这种向人工 agent 交接的减少，释放了团队产能，使其能够专注于更复杂、更高影响的客户需求。
- **客户满意度（CSAT）得分更高**，68% 的客户在贷后服务与贷款发起的聊天交互中给出高满意度评价。主要驱动因素包括快速响应、清晰沟通与准确信息，这些都有助于增强客户信任、减少摩擦。
- **更强的客户参与度**，用户独立完成了更多任务，这得益于直观、个性化的自助能力。
- **更强的个性化与灵活性**。Rocket AI Agents 会适应每位客户在房屋所有权旅程中所处的阶段及其偏好，并按客户意愿提供升级到银行家的能力。这种个性化支持体现了 Rocket “Help Everyone Home” 的核心使命——在客户所在之处与之相会，并给他们继续前进的信心。
- **扩展语言支持**，包括西班牙语协助，以更好地服务多元化且不断增长的人群。

Rocket 已把 Rocket AI Agents 部署到其各项数字服务中，包括贷后服务门户与第三方经纪系统，在客户互动的任何地方提供连贯的体验。通过在这些触点上提供一致、契合品牌的支持，Rocket 正在改变客户体验房屋所有权的方式。借助 Amazon Bedrock Agents 的个性化能力，Rocket 可以按客户的具体情境与偏好定制每一次交互，通过可扩展的智能互动把“Help Everyone Home”的使命落到实处。

## 经验教训

在 Rocket AI Agent 的开发与部署过程中，Rocket 团队总结出若干关键经验，这些经验塑造了其技术策略与整体客户体验。这些洞见可以为其他规模化构建生成式 AI 应用的组织提供有价值的指引：

- **谨慎整理数据：** 生成式 AI 所生成回答的质量与其源数据的质量和结构密切相关。Rocket 用 Amazon Bedrock Knowledge Bases 构建了企业知识库，后者在内部使用 [Amazon Kendra](https://aws.amazon.com/kendra/) 在 Rocket 的内容库中进行检索，这些内容库包括常见问题、合规文档与贷后服务工作流。
- **限制每个 agent 的任务范围：** Rocket 发现，为每个 agent 分配 3–5 个动作的紧凑范围，会带来更易维护、更易测试且表现更优的 agent。例如，付款 agent 只专注于安排付款、提供到期日这类任务，而再融资 agent 负责利率模拟与线索获取。每个 agent 的能力都使用带良好文档化接口的 Amazon Bedrock action groups，并分别监控其任务解决率。
- **优先考虑优雅升级：** 升级并不是失败，而是用户信任的关键一环。Rocket 使用置信度分数与特定关键词触发器设置了不确定性阈值，用来识别某次交互可能需要人工协助的情形。在这些情况下，Rocket AI Agent 会主动把会话转交给在线支持人员，或让用户选择是否升级。这避免了令人沮丧的对话循环，并确保复杂或敏感的交互获得适当程度的人工照护。
- **预期用户行为会演变：** 真实世界的使用是动态的。客户会以意想不到的方式与系统交互，模式也会随时间变化。投入可观测性与用户反馈闭环对快速适应至关重要。
- **从一开始就使用**[**跨区域推理**](https://docs.aws.amazon.com/bedrock/latest/userguide/cross-region-inference.html)**：** 为了提供可扩展、有韧性的模型性能，Rocket 在开发早期就启用了跨区域推理。这使推理请求可以被路由到受支持地理范围内最优的 [AWS 区域](https://docs.aws.amazon.com/glossary/latest/reference/glos-chap.html#region)，通过根据容量自动分配负载来改善延迟与模型可用性。在产品发布或利率变动等流量高峰时段，这种架构让 Rocket 避开了区域性服务配额瓶颈，保持响应能力，并通过利用多个 AWS 区域的计算容量提升吞吐量。结果是在突发、不可预测的负载条件下也能提供更顺畅、更一致的体验。

这些经验提醒我们：尽管生成式 AI 能释放强大的能力，但深思熟虑的实现方式才是交付可持续价值与可信体验的关键。

## 下一步：走向多 agent 协作

Rocket 才刚刚开始释放 agentic AI 的潜力。在领域专用 agent 取得成功的基础上，下一阶段的重点是通过由 Amazon Bedrock Agents 支持的[多 agent 协作](https://aws.amazon.com/blogs/aws/introducing-multi-agent-collaboration-capability-for-amazon-bedrock/)来扩展这些能力。这一演进将让 Rocket 能够跨领域编排 agent，交付智能的端到端体验，映射真实客户旅程的复杂度。

通过让各个 agent 无缝协同工作，Rocket 正在为一个未来打下基础：AI 不仅回答问题，还能主动走完整个工作流——从发现与资格判断，到贷后服务乃至更远的环节。

### 为 Rocket 带来的收益

多 agent 协作标志着 Rocket 在构建 agentic AI 驱动体验的旅程中向前迈出变革性的一步——从第一个问题到最终签字，重塑房屋所有权体验。通过让多个专用 agent 在单次对话中协同，Rocket 可以在其数字服务中释放出更高水平的智能、自动化与个性化。

- **端到端个性化：** 通过让多个领域专用 agent（例如再融资、贷后服务与贷款选项）共享上下文并协同，Rocket 可以给出更贴合、更智能的回答，并随客户的房屋所有权旅程实时演进。
- **后台集成：** 借助能够调用安全后端 API 与工作流的 agent，Rocket 可以开始自动化部分后台运营，例如文档核验、跟进与线索路由，从而提升速度、准确性与运营效率。
- **上下文切换：** 在一次聊天中在贷后服务、贷款发起与再融资之间流畅切换。
- **编排：** 处理跨越多个 Rocket 业务单元的多步骤任务。

借助多 agent 编排，Rocket 正在为一个始终可用、深度个性化的助手奠定基础——它不仅回答问题，还能从房源搜索到贷款结清乃至更远的环节推动有意义的成果。这代表着 Rocket“Help Everyone Home”使命的下一章。

## 结论

Rocket AI Agent 不只是一个数字助手。它是由 agentic AI 驱动的、被重新构想的客户互动方式。通过把 Amazon Bedrock Agents 与 Rocket 的专有数据及后端系统结合，Rocket 打造出一种更智能、更可扩展、也更具人情味的体验，全天候可用，无需等待。

Rocket 说得简单：“与 AWS 一起，我们才刚刚起步。我们的目标是让每位客户都能自信地向前迈进，并最终 Help Everyone Home。”
