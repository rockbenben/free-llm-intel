# 推出 Amazon Bedrock AgentCore Code Interpreter

AI agent 已经来到一个关键的转折点：它们生成复杂代码的能力，已经超出在生产环境中安全执行这些代码的能力。部署 agentic AI 的组织面临一个根本性困境：尽管大语言模型（LLM）能够产出复杂的代码脚本、数学分析与数据可视化，但执行这些 AI 生成的代码会引入显著的安全漏洞与运维复杂性。

本文中，我们介绍 [Amazon Bedrock AgentCore Code Interpreter](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/code-interpreter-tool.html)，这是一项完全托管的服务，让 AI agent 能够在隔离的 sandbox 环境中安全执行代码。我们讨论在部署需要计算能力的 AI agent 时，AgentCore Code Interpreter 如何帮助解决围绕安全性、可扩展性与基础设施管理的难题。我们逐一介绍该服务的核心功能，用实际示例演示它的工作方式，并展示如何借助 Strands、LangChain 和 LangGraph 等流行框架开始构建你自己的 agent。

## AI 生成代码带来的安全与可扩展性挑战

设想一个例子：AI agent 需要分析某产品多年期的销售预测数据，以理解其中的异常、趋势与季节性。这项分析应当以逻辑为依据、可重复、能安全地处理数据，并且能够在必要时扩展到大数据集与多次迭代。尽管 LLM 擅长理解与解释概念，它们缺乏直接操作数据或大规模执行一致数学运算的能力。仅靠 LLM 本身往往不足以完成这类复杂的数据分析任务，因为它们在处理大型数据集、执行精确计算与生成可视化方面存在固有限制。这正是代码解释与执行工具变得不可或缺的原因——它们提供执行精确计算、高效处理大型数据集，以及通过编程语言与专用库创建可复现分析的能力。此外，实现代码解释能力还伴随重要的考量。组织必须维护安全的 sandbox 环境以帮助防止恶意代码执行、管理资源分配并维护数据隐私。这套基础设施需要定期更新、稳健监控以及谨慎的扩缩容策略，以应对不断增长的需求。

传统的 AI 系统代码执行方式存在若干局限：

- **安全漏洞** —— 在生产环境中执行不受信任的 AI 生成代码，会使组织暴露于代码注入威胁、未授权系统访问以及潜在的数据泄露。如果没有适当的 sandbox 隔离，恶意或构造拙劣的代码可能危及整个基础设施栈。
- **基础设施开销** —— 构建安全的执行环境需要大量 DevOps 专业能力，包括容器编排、网络隔离、资源监控与安全加固。许多组织缺乏正确实现这些系统的专门知识。
- **可扩展性瓶颈** —— 传统代码执行环境难以应对 AI agent 产生的动态、不可预测的工作负载。峰值需求可能压垮静态基础设施，而空闲期又会浪费计算资源。
- **集成复杂性** —— 把安全的代码执行能力与现有 AI 框架连接起来，往往需要定制开发，从而带来维护开销并限制其在各开发团队之间的采用。
- **合规挑战** —— 企业环境要求全面的审计轨迹、访问控制与合规认证，而这些在定制方案中很难实现与维护。

这些障碍使组织无法充分利用 AI agent 的计算能力，把其应用局限于简单、确定性的任务，而无法用于那些本可最大化业务价值的、复杂且依赖代码的 workflow。

## 推出 Amazon Bedrock AgentCore Code Interpreter

借助 AgentCore Core Interpreter，AI agent 可以在 sandbox 环境中安全地编写与执行代码，提高准确性，并扩展其解决复杂端到端任务的能力。这项专门打造的服务通过提供一个专为 agentic AI 工作负载设计的、完全托管的企业级代码执行系统，把一直阻碍 AI agent 部署的安全、可扩展性与集成难题降到最低。AgentCore Code Interpreter 是从零开始为 AI 生成代码而设计与构建的，具备内置防护措施、动态资源分配，以及与流行 AI 框架的无缝集成。它提供高级配置支持与对流行框架的无缝集成，使开发者能够为复杂 workflow 与数据分析构建强大的 agent，同时满足企业安全要求。

## 转变 AI agent 的能力

AgentCore Code Interpreter 通过满足若干关键的企业要求，为高级用例提供支撑：

- **更强的安全态势** —— 可配置的网络访问选项既包括完全隔离的环境（通过帮助阻止 AI 生成代码访问外部系统来提供更强的安全性），也包括受控的网络连接（为特定开发需求与用例提供灵活性）。
- **零基础设施管理** —— 完全托管的服务把对专门 DevOps 资源的需求降到最低，在保持企业级可靠性与安全性的同时，把上市时间从数月缩短到数天。
- **动态可扩展性** —— 自动资源分配无需人工介入即可应对变化的 AI agent 工作负载，在峰值需求期间提供低延迟的会话启动时间，同时优化空闲期的成本。
- **与框架无关的集成** —— 它与 [Amazon Bedrock AgentCore Runtime](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/agents-tools-runtime.html) 集成，原生支持 Strands、LangChain、LangGraph 和 CrewAI 等流行 AI 框架，使团队能够利用既有投入，同时保持开发速度。
- **企业合规** —— 内置的访问控制与全面的审计轨迹有助于满足监管合规要求，且不增加额外开发开销。

## 专为 AI agent 代码执行而打造

AgentCore Code Interpreter 代表着 AI agent 与计算资源交互方式的转变。该操作会处理 agent 生成的代码，在安全环境中运行它，并返回执行结果，包括输出、错误与生成的可视化产物。该服务作为一个安全、隔离的执行环境运行，AI agent 可以在其中运行代码（Python、JavaScript 与 TypeScript）、执行复杂数据分析、生成可视化并执行数学计算，而不会危及系统安全。每次执行都在专用的 sandbox 环境中进行，与其他工作负载以及更广泛的 AWS 基础设施完全隔离。AgentCore Code Interpreter 与传统执行环境的区别，在于它针对 AI 生成的工作负载进行了优化。该服务通过智能资源管理、自动错误处理以及专门为不受信任代码执行设计的内置安全防护措施，应对 AI 生成代码的不可预测性。

AgentCore Code Interpreter 的关键功能与能力包括：

- **安全的 sandbox 架构：** 低延迟的会话启动时间与基于计算的会话隔离，实现完整的工作负载分离；支持隔离 sandbox 与受控公共网络两种模式的可配置网络访问策略；通过为每个会话设置内存与 CPU 使用上限来实现资源约束，帮助防止过度消耗（参见 [AgentCore Code Interpreter 服务配额](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/bedrock-agentcore-limits.html#code-interpreter-service-limits)）
- **高级会话管理：** 持久化会话状态支持多步代码执行 workflow；面向复杂数据处理 pipeline 的基于会话的文件存储；自动清理会话与资源；支持具有可配置超时的长时间运行计算任务
- **完整的 Python 运行时环境：** 预装 pandas、numpy、matplotlib、scikit-learn 和 scipy 等数据科学库；支持 seaborn 和 bokeh 等流行可视化库；通过 sympy 与 statsmodels 提供数学计算能力；可在 sandbox 边界内为特殊需求安装自定义包
- **文件操作与数据管理：** 上传数据文件、用代码处理并取回结果；具备自动加密的安全文件传输机制；支持在 sandbox 内直接与 [Amazon Simple Storage Service](https://aws.amazon.com/s3)（Amazon S3）之间上传与下载文件；支持 CSV、JSON、Excel 与图片等多种文件格式；提供带自动清理的临时存储以增强安全性；支持使用 Amazon Bedrock AgentCore SDK 与 API 在 sandbox 内直接运行 [AWS Command Line Interface](https://aws.amazon.com/cli)（AWS CLI）命令
- **企业集成功能：** 基于 [AWS Identity and Access Management](https://aws.amazon.com/iam/)（IAM）的访问控制与细粒度权限管理；[AWS CloudTrail](https://aws.amazon.com/cloudtrail) 集成提供用于合规的审计轨迹

## AgentCore Code Interpreter 的工作方式

为理解 AgentCore Code Interpreter 的功能，我们来看 AI agent 发出一个典型数据分析请求时，系统如何编排整个流程，如下图所示。

![](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/08/01/ML-19494-image-1.png)

该 workflow 由以下关键组件构成：

- **部署与调用** —— 使用 Strands、LangChain、LangGraph 或 CrewAI 等框架构建并部署一个 agent（例如部署在 AgentCore Runtime 上）。当用户发送一个 prompt（例如“分析这份销售数据，并按销售区域向我展示趋势”），AgentCore Runtime 会启动一个安全、隔离的会话。
- **推理与工具选择** —— agent 底层的 LLM 分析 prompt，判断需要执行一次计算，随后选择 AgentCore Code Interpreter 作为合适的工具。
- **安全的代码执行** —— agent 生成一段代码片段，例如使用 pandas 库读取数据文件、使用 matplotlib 绘图。这段代码被传给 AgentCore Code Interpreter，后者在其专用、已 sandbox 化的会话中执行它。agent 可以读写该会话专属文件系统中的文件。
- **观察与迭代** —— AgentCore Code Interpreter 把执行结果——例如某个计算值、一个数据集、一张图表图片或一条错误信息——返回给 agent。这一反馈回路使 agent 能够通过调试自己的代码并改进思路来开展迭代式问题求解。
- **上下文与记忆** —— 在会话存续期间，agent 为对话的后续轮次维护上下文。或者，整个交互可以持久化到 [Amazon Bedrock AgentCore Memory](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/memory-getting-started.html) 中，用于长期存储与检索。
- **监控与可观测性** —— 在整个过程中，都可获得 agent 执行的详细追踪，从而洞察 agent 行为、性能指标与日志，用于调试与审计。

## 真实世界的实际应用与用例

AgentCore Code Interpreter 可应用于那些仅靠 LLM 难以解决的真实业务问题。

### 用例 1：自动化财务分析

可以让 agent 承担对财务数据按需进行分析的任务。在此示例中，用户在一个 prompt 中提供了计费数据的 CSV 文件，并要求分析与可视化：“使用下面提供的计费数据，绘制一张按产品类别展示总支出金额的柱状图…… 生成图表后，请对结果作简要解读……”该 agent 执行以下动作：

- agent 收到 prompt 与包含原始数据的数据文件。
- 它调用 AgentCore Code Interpreter，生成使用 pandas 库解析数据并载入 DataFrame 的 Python 代码。随后 agent 生成另一段代码块，按类别对数据分组并汇总成本，并要求 AgentCore Code Interpreter 执行它。
- agent 使用 matplotlib 生成柱状图，AgentCore Code Interpreter 将其保存为图片文件。
- agent 同时返回研究结论的文字摘要与生成图表的 PNG 图片。

### 用例 2：交互式数据科学助手

AgentCore Code Interpreter 的有状态会话支持对话式、迭代式的数据分析 workflow。在此示例中，一位数据科学家用 agent 进行探索性数据分析。workflow 如下：

- 用户提供一个 prompt：“加载 dataset.csv 并提供描述性统计。”
- agent 生成并执行 `pandas.read_csv('dataset.csv')` 以及随后的 `.describe()`，并返回统计表。
- 用户提示：“绘制列 A 与列 B 的散点图。”
- agent 使用会话中已加载的数据集，生成 `matplotlib.pyplot.scatter()` 代码并返回图表。
- 用户提示：“运行一个简单的线性回归并提供 R^2 值。”
- agent 使用 scikit-learn 库生成代码，拟合模型并计算 R^2 指标。

这展示了迭代式代码执行能力，它使 agent 能够与用户逐轮推进复杂的数据科学问题。

## 设置并配置 AgentCore Code Interpreter

完成以下设置与配置步骤：

- 安装 bedrock-agentcore [Python SDK](https://github.com/aws/bedrock-agentcore-sdk-python)：

```
pip install bedrock-agentcore
```

- 导入 AgentCore Code Interpreter 与其他库：

```
from bedrock_agentcore.tools.code_interpreter_client import code_session
from strands import Agent, tool
import json
```

- 定义 system prompt：

```
SYSTEM_PROMPT  """You are a helpful AI assistant that validates all answers through code execution.

TOOL AVAILABLE:
- execute_python: Run Python code and see output
```

- 为 agent 定义代码执行工具。在工具定义中，我们使用 invoke 方法执行由 LLM 驱动的 agent 生成的 Python 代码。如果会话不存在，它会自动启动一个 serverless 的 AgentCore Code Interpreter 会话。

```
@tool
def execute_python(code: str, description: str = "") -> str:
"""Execute Python code in the sandbox."""

if description:
code = f"# {description}\n{code}"

print(f"\n Generated Code: {code}")

with code_session("us-west-2") as code_client:
response = code_client.invoke("executeCode", {
"code": code,
"language": "python",
"clearContext": False
})

for event in response["stream"]:
return json.dumps(event["result"])
```

- 配置 agent：

```
agent  Agent(
tools[execute_python],
system_promptSYSTEM_PROMPT,
callback_handler
)
```
