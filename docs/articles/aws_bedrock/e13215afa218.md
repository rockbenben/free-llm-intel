# INRIX 如何借助 Amazon Bedrock 加速交通规划

*本文由来自 INRIX 的 Shashank Saraogi、Nat Gale 与 Durran Kelly 共同撰写。*

现代交通管理的复杂性远远超出单纯的道路监控，它还涵盖从联网汽车、移动设备、道路传感器与重大事件监测系统在全球范围内收集的巨量数据。对于管理城市、郊区与乡村交通流的交通主管部门而言，挑战在于如何有效地处理并对这个庞大的信息网络采取行动。这项任务要求在即时运营需求（例如事故期间实时重定向交通）与旨在提升机动性与安全性的战略性长期规划之间取得平衡。

传统上，分析这些复杂的数据模式并产出可执行的洞见是一项资源密集、需要大量协作的过程。随着[生成式 AI](https://aws.amazon.com/ai/generative-ai/) 近来的进展，我们有机会改变处理、理解并基于交通数据采取行动的方式，从而构建更高效、更灵敏的交通管理系统。

本文中，我们与 [Amazon Web Services](https://aws.amazon.com/)（AWS）客户 [INRIX](https://inrix.com/) 合作，演示如何用 [Amazon Bedrock](https://aws.amazon.com/bedrock/) 基于丰富的交通数据为特定城市地点确定最佳对策，以及如何在街景图像中自动可视化这些对策。与传统使用概念图的做法相比，这一方式能显著加速规划。

INRIX 率先把联网车辆的 GPS 数据用于交通情报。20 多年来，INRIX 一直是基于探针的联网车辆与设备数据及洞见领域的领先者，支撑着汽车、企业与公共部门的各类用例。INRIX 的产品范围从面向金融服务业的[用于支持投资决策的 tickerized 数据集](https://inrix.com/press-releases/tickerized-vehicle-data-from-inrix-now-available-on-exabel/)，到费城与旧金山两市[公共路权的数字孪生](https://inrix.com/press-releases/philly-right-of-way/)。INRIX 是[第一家开发众包交通网络的公司](https://inrix.com/resources/inrix-a-history-of-innovation/)，并且持续在实时出行运营领域保持领先。

2024 年 6 月，[加利福尼亚州交通部（Caltrans）选择 INRIX](https://inrix.com/press-releases/genai-safety-caltrans/)开展概念验证，探索一个由生成式 AI 驱动的方案，以提升弱势道路使用者（VRU）的安全性。该问题陈述力图把 Caltrans 的资产、事故与兴趣点（POI）数据同 INRIX 的 50 PB 数据湖结合起来，以预判高风险位置，并快速生成经过实证验证的安全措施，以降低事故发生的可能性。该方案基于实时与历史数据以及行业研究和手册训练，为风险评估、位置优先级排序与项目实施提供了一套全新的系统性、以安全为基础的方法论。

## 方案概览

INRIX 于 2023 年 11 月发布了 [INRIX Compass](https://inrix.com/learn/inrix-compass-gen-ai/)。INRIX Compass 是一个利用生成式 AI 与 INRIX 的 50 PB 数据湖来解决交通难题的应用。该方案以 INRIX Compass 生成的对策作为输入，采用 AWS 无服务器架构，并用 [Amazon Nova Canvas](https://aws.amazon.com/ai/generative-ai/nova/creative/) 作为图像可视化器。关键组件包括：

- 对策生成：INRIX Compass 为选定地点生成对策；[Amazon API Gateway](https://aws.amazon.com/api-gateway/) 与 [Amazon Elastic Kubernetes Service](https://aws.amazon.com/eks/)（Amazon EKS）管理 API 请求与响应；[Amazon Bedrock Knowledge Bases](https://aws.amazon.com/bedrock/knowledge-bases/) 与 [Anthropic 的 Claude 模型](https://aws.amazon.com/bedrock/claude/) 提供[检索增强生成（RAG）](https://aws.amazon.com/what-is/retrieval-augmented-generation/)的实现
- 图像可视化：API Gateway 与 [AWS Lambda](https://aws.amazon.com/pm/lambda/?trk=73f686c8-9606-40ad-852f-7b2bcafa68fe&sc_channel=ps&ef_id=Cj0KCQjwqv2_BhC0ARIsAFb5Ac9JNeng4ci9WDMGQyes6pqvmBtUadHExWZMWO0Gmlh0bOOfXzAWUD0aArU6EALw_wcB:G:s&s_kwcid=AL!4422!3!651212652666!e!!g!!lambda!909122559!45462427876&gbraid=0AAAAADjHtp_BpgRFwjeE4GL_95TW8twhH&gclid=Cj0KCQjwqv2_BhC0ARIsAFb5Ac9JNeng4ci9WDMGQyes6pqvmBtUadHExWZMWO0Gmlh0bOOfXzAWUD0aArU6EALw_wcB) 处理来自 API Gateway 的请求，Amazon Bedrock 在获得 Amazon Nova Canvas 的模型访问权限后提供图像生成与 in-painting

## INRIX Compass 用于生成对策

借助 INRIX Compass，用户可以提出自然语言查询，例如 `对弱势道路使用者而言风险最高的前五个位置在哪里？` 以及 `你能为这些位置中的每一个推荐一套经过验证的安全对策吗？` 此外，用户还可以深入探究造成风险因素的道路特征，并在路网中找到符合这些条件的相似位置。在幕后，Compass AI 使用 RAG 与由 Amazon Bedrock 驱动的[基础模型](https://aws.amazon.com/what-is/foundation-models/)（FM）查询路网，以识别存在系统性风险因素与异常安全模式的位置并为其排定优先级。该方案基于行业知识，为运营与设计解决方案以及对策提供按优先级排序的建议。

## 对策的图像可视化

生成对策建议只是交通规划的第一步。图像可视化还需要一个关键的下一步：准备概念图。由于涉及多个专业团队，这一过程传统上非常耗时，这些团队包括：

- 交通工程师，负责评估技术可行性与安全标准
- 城市规划师，负责核实方案与城市发展目标的一致性
- 景观建筑师，负责整合环境与美学要素
- CAD 或可视化专家，负责绘制详细的技术图纸
- 安全分析师，负责评估对道路安全的潜在影响
- 公共工程部门，负责把关实施可行性
- 交通运营团队，负责评估对交通流与管理的影响

这些团队协同工作，根据城市设计师与其他利益相关方的反馈创建并反复改进各种可视化结果。每一轮迭代通常都包含多轮评审、调整与批准，往往大幅拉长时间线。城市特有的规则与设计要求进一步放大了复杂度，这些要求往往需要大量定制。此外，地方性法规、环境考量与社区反馈也必须纳入设计过程。因此，这个漫长而昂贵的过程经常导致安全对策的实施被推迟。为简化这一难题，INRIX 通过使用生成式 AI 技术，在可视化阶段开创了一种创新方式。这一原型方案支持概念图的快速迭代，便于各团队高效评审，有望把设计周期从数周缩短到数天。此外，该系统结合了使用参考图像与精心构建的 prompt 的 few-shot 学习方法，使城市特有的要求可以无缝融入生成的输出。这一方式不仅加速了设计过程，还支持不同项目之间的一致性，同时保持对地方标准的合规。

## 用 Amazon Nova Canvas 生成概念化可视化

INRIX 使用 Amazon Nova 模型开发并原型化了这一方案。Amazon Nova Canvas 通过文生图生成与图生图变换能力提供先进的图像处理。该模型为调整配色方案与操纵布局提供了精细的控制，以实现期望的视觉效果。为促进[负责任 AI](https://aws.amazon.com/ai/responsible-ai/) 的落地，Amazon Nova Canvas 内置了安全措施，包括水印与内容审核系统。

该模型支持全面的图像编辑操作。这些操作涵盖基础的图像生成、从现有图像中移除对象、在场景中替换对象、创建图像变体，以及修改图像背景。这种多面性使 Amazon Nova Canvas 适用于各种需要精细图像编辑的专业应用。

## Compass AI 中的 in-painting 实现

Amazon Nova Canvas 与 INRIX Compass 既有的自然语言分析能力集成。最初的 Compass 系统基于以下内容生成基于文本的对策建议：

- 历史交通数据分析
- 当前环境状况
- 用户指定的要求

INRIX Compass 的可视化特性专门使用 Amazon Nova Canvas 的[图像生成](https://docs.aws.amazon.com/nova/latest/userguide/image-generation.html)与 [in-painting 能力](https://docs.aws.amazon.com/nova/latest/userguide/prompting-image-inpainting.html)。In-painting 通过两种不同的方式实现对象替换：

- 二值掩膜精确定义了要替换的目标区域。
- 文本 prompt 指明要替换的对象，让模型能够解读并修改指定元素，同时与周围图像的上下文保持视觉一致性。这一功能在保留整体图像构图与上下文相关性的同时，实现新元素的无缝融入。所开发的界面同时支持图像生成与 in-painting 两种方式，提供全面的图像编辑能力。

该实现采用两阶段流程来可视化交通对策。首先，系统使用图像生成功能，为提议实施干预措施的具体经纬度坐标创建对应的街景视图。在完成初始图像创建之后，in-painting 能力可在生成的街景场景中精确放置对策。这种按顺序推进的方式能在真实的地理情境中准确可视化所提议的改动。

Amazon Bedrock API 通过 Amazon Nova Canvas 模型实现图像编辑与生成。响应以 base64 格式包含生成或修改后的图像，可以解码并处理，以便在应用中进一步使用。Amazon Bedrock 的生成式 AI 能力支持快速迭代，并可在单张图像中同时可视化多个对策。RAG 的实现可以通过纳入县一级的法规、标准化设计模式与上下文要求，进一步扩展这条 pipeline 的能力。这些技术的集成为对策部署工作流带来了显著的精简。此前需要大量时间与资源的人工可视化流程，如今可以通过自动化生成与修改高效完成。这种自动化在部署周期与成本效益两方面都带来了实质性的改善。

## 结论

INRIX 与 AWS 的合作展现了 AI 在解决复杂交通难题方面的变革潜力。通过使用 Amazon Bedrock FM，INRIX 借助高效的可视化方案，把其庞大的 50 PB 数据湖转化为可执行的洞见。本文只聚焦了一个具体的交通用例，但 Amazon Bedrock 与 Amazon Nova 支撑着广泛的应用，从文本生成到视频创作。海量数据与先进 AI 能力的结合，持续为全球更智能、更高效的交通系统铺平道路。
