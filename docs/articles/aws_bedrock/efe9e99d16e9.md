# Netsertive 如何借助 Amazon Bedrock 与 Amazon Nova 打造可扩展的 AI 助手，从实时数据中提炼有价值的洞察

*本文与来自 Netsertive 的 Herb Brittner 共同撰写。*

[Netsertive ](https://netsertive.com/)是为多门店品牌与加盟商提供服务的领先数字营销解决方案提供商，帮助企业最大化本地广告效果、提升互动，并获得深入的客户洞察。

随着客户对从其通话跟踪数据中获得更多可执行洞察的需求不断增长，Netsertive 需要一个能够从每一通电话中释放商业智能的解决方案，让加盟商更容易改善客户服务并提升转化率。团队在寻找一个单一而灵活的系统，能够同时完成以下几件事：

- **理解电话内容** – 自动生成通话所谈内容的摘要
- **判断客户情绪** – 判定来电者是满意、不满还是中立
- **识别重要话题** – 提取与常见服务、问题、故障以及竞品提及相关的关键词
- **提升坐席表现** – 提供辅导方面的建议与意见
- **追踪长期表现** – 针对单个门店、区域以及全国范围生成趋势报告

关键在于，这套新系统需要与其现有的 Multi-Location Experience（MLX）平台顺畅协作。MLX 平台专为拥有众多门店的企业设计，帮助他们同时管理全国性与本地营销。它让企业能够在多个线上渠道投放活动，包括搜索引擎、社交媒体、展示广告、视频、联网电视和在线评论，同时管理 SEO、商家信息、评论、社交媒体发布以及各门店的独立网页。

本文将介绍 Netsertive 如何借助 [Amazon Bedrock](https://aws.amazon.com/bedrock/) 与 [Amazon Nova](https://aws.amazon.com/ai/generative-ai/nova/)，将生成式 AI 驱动的助手引入 MLX，让平台的下一个世代落地。

## 解决方案概览

作为一家运营完整数字营销解决方案的公司，Netsertive 负责活动执行，同时通过其 Insights Manager 产品提供关键的成功指标。该平台具备针对具体门店的内容管理能力以及强大的线索捕获功能，可从多个来源收集数据，包括付费广告活动、自然网站流量以及归因表单。借助 CRM 集成与通话跟踪功能，MLX 构建起客户数据与营销洞察的无缝流转。这种托管服务、自动化工具与分析能力的组合，使 MLX 成为企业优化数字营销工作、同时借助 Netsertive 在活动管理方面专业能力的单一事实来源。为了满足在平台上从客户通话跟踪数据中提供更多可执行洞察的诉求，Netsertive 评估了多种方案。在对比了不同的工具与模型之后，他们决定采用 Amazon Bedrock 与 Amazon Nova Micro 模型。这一选择源于 Amazon Bedrock 的 API 驱动方式、其丰富的大语言模型（LLM）选择，以及 Amazon Nova Micro 模型本身的性能。他们选择 Amazon Nova Micro，是基于它能够以低成本提供快速响应，同时给出稳定而智能的洞察——这对 Netsertive 而言是关键因素。凭借每秒超过 200 个 token 的生成速度与出色的语言理解能力，这款纯文本模型被证明非常适合 Netsertive。下图展示了其 MLX 平台如何接收实时电话，并在 Amazon Bedrock 中使用 Amazon Nova Micro 处理实时电话。

![面向 Netsertive 的 AWS 架构，展示 EKS、Aurora、Bedrock 与洞察管理及通话报告工作流的集成](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2025/06/05/ml-18574-Arch.jpeg)

实时通话处理流程包含以下步骤：

- 当有电话呼入时，会立即路由到 Lead API。该过程会同时捕获实时通话转写文本与来电者的重要元数据。系统会持续处理新到达的通话，从而实现来电通信的实时处理。
- 捕获到的转写文本会被转发至 Amazon Bedrock 进行分析。系统目前对所有客户使用标准化的基础 prompt，其架构设计还支持按客户定制 prompt，作为额外的一层上下文。
- Amazon Nova Micro 处理转写文本并返回结构化的 JSON 响应。该响应包含多个分析组件：对话的情感分析、简洁的通话摘要、识别出的关键术语、整体通话主题分类，以及针对改进的具体辅导建议。
- 所有分析结果会连同其关联的关键指标一起系统化地存入 [Amazon Aurora](https://aws.amazon.com/rds/aurora/) 数据库。这可确保处理后的数据得到恰当的索引，既能立即访问，也可供未来分析使用。

聚合报告调度流程包含以下步骤：

- 聚合分析流程会按每周与每月计划自动启动。每次运行时，系统会收集落在指定时间范围内的通话数据。
- 该聚合分析同时使用 Amazon Bedrock 与 Amazon Nova Micro，并应用专门为趋势分析设计的 prompt。该 prompt 与实时分析所用的不同，重点在于识别多通电话之间的模式与洞察。

两条工作流产生的处理后聚合数据会通过 UI 转化为展示趋势分析与对比指标的综合报告。这为相关方提供了关于表现模式与长期趋势的有价值洞察，同时允许用户深入查看具体指标。

## 成果

用生成式 AI 构建实时通话数据分析方案的落地过程，对 Netsertive 而言是一段具有变革意义的旅程。他们基于 Amazon Bedrock 上的 Amazon Nova Micro 打造的新功能 Call Insights AI，只需几分钟就能产出可执行的洞察，而此前的人工通话复核流程对通话量大的客户往往要耗费数小时甚至数天。Netsertive 在约 1 周的快速评估期内测试了不同的工具与模型，随后选定了 Amazon Bedrock 与 Amazon Nova Micro。他们的开发方式有条不紊，并以客户为中心。Call Insights AI 功能是基于客户的直接反馈与内部营销专业判断加入平台路线图的。整个开发过程，从创建并测试其 Amazon Nova Micro prompt，到将 Amazon Bedrock 与 MLX 平台集成，在进入 beta 发布之前约 30 天内完成。实时通话数据分析的转变不只是处理更多电话——它更在于对客户互动形成更全面的理解。通过落地 Amazon Bedrock 与 Amazon Nova Micro，Netsertive 能够更好地理解通话的目的与价值、增强度量能力，并向更自动化、更高效的分析体系迈进。这一演进不仅能精简运营，还能为客户提供有关其数字营销表现的更多可执行洞察。

## 结论

本文介绍了 Netsertive 如何借助 Amazon Bedrock 与 Amazon Nova，将生成式 AI 驱动的助手引入 MLX。该解决方案帮助其扩展 MLX 平台，为客户提供即时、可执行的洞察，打造出更具吸引力、信息更丰富的用户体验。通过使用 Amazon Bedrock 先进的自然语言处理能力以及高性能、低延迟的 Amazon Nova Micro 模型，Netsertive 构建出一套全面的通话智能系统，其能力超越单纯的转写与情感分析。

该项目的成功展现了生成式 AI 在推动商业智能与运营效率方面的变革潜力。如需进一步了解如何使用 Amazon Bedrock 与 Amazon Nova 构建强大的生成式 AI 助手与应用，请参阅 [Generative AI on AWS](https://aws.amazon.com/ai/generative-ai/)。
