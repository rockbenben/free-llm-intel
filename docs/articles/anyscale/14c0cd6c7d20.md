# Ray 1.0 正式发布

作者：Eric Liang | 2020 年 9 月 30 日

### Ray 1.0 发布

今天，我们很高兴宣布 [Ray 1.0](https://github.com/ray-project/ray) 发布。Ray 1.0 带来了[稳定 API](https://docs.ray.io/en/master/package-ref.html)和全新的[通用 serverless](https://ray2020.sched.com/event/dhCy/ray-a-general-purpose-serverless-substrate-eric-liang-anyscale)特性，两者都是迈向"为分布式计算提供通用 API"这一目标的重要一步。本次版本共有 67 位贡献者和 458 次提交，是 Ray [迄今最大的](https://github.com/ray-project/ray/releases)一次发布。此外，1.0 还为不断壮大的 Ray 生态带来了许多新的社区[库集成](https://docs.ray.io/en/master/ray-libraries.html)。

### 新特性

Ray 1.0 让构建和组合高可扩展的库、应用与服务比以往任何时候都更容易。要点如下：

**要资源，不要机器：**构建能在不同机型、集群与云之间可移植运行的分布式应用是一项挑战。Ray 1.0 让这件事变简单：[autoscaler](https://docs.ray.io/en/master/cluster/autoscaling.html)能根据应用的[资源请求](https://docs.ray.io/en/master/advanced.html#accelerator-types)智能选择最优[节点类型](https://docs.ray.io/en/master/cluster/autoscaling.html#multiple-node-type-autoscaling)。此外，Ray 1.0 引入了[placement group API](https://docs.ray.io/en/master/placement-group.html)，实现对调度的细粒度控制。

**生产级服务：**通用 serverless 框架同时承载离线批处理与在线服务负载。Ray 1.0 随附 [Ray Serve](https://docs.ray.io/en/master/serve/)——一个生产级微服务与 ML 服务库。对于自定义服务应用，Ray 1.0 还引入了[分离式](https://docs.ray.io/en/master/actors.html?highlight=lifetime#actor-lifetimes)（detached）actor 生命周期、[AsyncIO](https://docs.ray.io/en/master/async_api.html) actor，以及经由 [Prometheus](https://docs.ray.io/en/master/ray-metrics.html?highlight=prometheus) 的应用级指标。Ray 服务应用可部署在多种[云服务商](https://docs.ray.io/en/master/cluster/cloud.html)和 [Kubernetes](https://docs.ray.io/en/master/cluster/kubernetes.html)上。

**自动内存管理**：Ray 1.0 用户可以告别"object evicted"错误，这要归功于全自动的[内存管理](https://docs.ray.io/en/master/memory-management.html)。应用性能与内存占用可在 [Ray dashboard](https://docs.ray.io/en/master/ray-dashboard.html)中调试。想了解 Ray 如何以高性能、可靠性与容错实现分布式引用计数，请阅读全新的 [Ray 1.0 白皮书](https://docs.ray.io/en/master/whitepaper.html)。

**Java 与 Windows 支持：**Ray 1.0 为 Java 和 Windows 平台带来原生支持。这意味着你现在可以用 Ray 构建[跨语言](https://docs.ray.io/en/master/cross-language.html)与[分布式 Java](https://medium.com/distributed-computing-with-ray/build-distributed-java-applications-with-ray-90b381eff564)应用，也可以[在 Windows 上安装 Ray](https://docs.ray.io/en/master/installation.html#windows-support)。

### 社区动态

**社区集成**：越来越多的[社区库](https://docs.ray.io/en/master/ray-libraries.html)与 Ray 1.0 集成以实现分布式执行：[ClassyVision](https://classyvision.ai/tutorials/ray_aws)、[Dask](https://docs.ray.io/en/master/dask-on-ray.html)、[Flambe](https://github.com/asappresearch/flambe)、[Horovod](https://horovod.readthedocs.io/en/stable/ray_include.html)、[HuggingFace](https://huggingface.co/transformers/master/main_classes/trainer.html#transformers.Trainer.hyperparameter_search)、[Intel Analytics Zoo](https://analytics-zoo.github.io/master/#ProgrammingGuide/rayonspark/)、[MARS](https://docs.ray.io/en/master/mars-on-ray.html)、[Modin](https://github.com/modin-project/modin)、[RayDP](https://github.com/Intel-bigdata/oap-raydp)、[Seldon Alibi](https://github.com/SeldonIO/alibi)和 [SpaCy](https://pypi.org/project/spacy-ray/)。这意味着这些库的用户现在可以用 Ray 扩展其应用，Ray 用户也能在分布式应用中轻松使用这些库。

**开源**：在 Anyscale，我们很自豪与开源社区共同开发 Ray。许多关键贡献由社区驱动——例如高可用、多租户与 placement group 等正在进行的项目由[蚂蚁集团](https://www.antgroup.com/en)主导，针对不同云的 autoscaler 改进则来自[Amazon](https://aws.amazon.com/)和[Microsoft](https://azure.microsoft.com/en-us/)。
