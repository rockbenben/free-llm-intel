# 用 Ray、NVIDIA Triton Inference Server 与 TensorRT-LLM 实现低延迟生成式 AI 模型服务

作者：Neelay Shah 和 Akshay Malik | 2024 年 3 月 13 日

在之前的[博客](https://www.anyscale.com/blog/tackling-the-cost-and-complexity-of-serving-ai-in-production-ray-serve)中，我们讲了 [Ray Serve](https://docs.ray.io/en/latest/serve/index.html) 的灵活、可扩展与简洁如何帮助你提升硬件利用率、更快把 AI 应用送上生产。随着 AI 模型越来越大、越来越复杂，市场已经认同：优化模型推理以降低 GPU 成本至关重要。现在，Anyscale 与 NVIDIA 联手，把 Ray Serve 与 RayLLM 的开发者生产力，同 [NVIDIA Triton Inference Server](https://www.nvidia.com/en-us/ai-data-science/products/triton-inference-server/) 软件与 [NVIDIA TensorRT-LLM 库](https://github.com/NVIDIA/TensorRT-LLM)的前沿优化结合起来。

## **用 Ray Serve 与 RayLLM 做模型服务**

Ray Serve 是构建于 Ray 之上、用于搭建端到端 AI 应用的可扩展模型服务库。它提供简单的 Python API，从 PyTorch 等框架搭建的深度学习神经网络，到任意业务逻辑，都能服务化。Ray Serve 尤其适合[模型组合](https://docs.ray.io/en/latest/serve/model_composition.html#serve-model-composition)与多模型服务：你可以构建由多个 ML 模型组成的复杂推理服务，各部分独立自动扩缩，获得最优硬件利用。2023 年，Anyscale 在用户体验与性价比上大力投入，服务着 LinkedIn、[Samsara](https://raysummit.anyscale.com/agenda/sessions/233)、[DoorDash](https://raysummit.anyscale.com/agenda/sessions/146) 这样的 Ray Serve 用户（[LinkedIn 演讲](https://youtu.be/JqpefcQS1a4?feature=shared)）。开发者们注意到了这一点——去年采用量增长 10 倍，无论初创还是大企业都在寻找更快更省地服务 AI 模型的方式。

[RayLLM](https://github.com/ray-project/ray-llm) 是构建在 Ray Serve 上的 LLM 服务方案，让部署与管理各种开源 LLM 变得轻松。它提供大量经过优化、开箱即用的预配置开源 LLM，也支持自带模型。它还提供完全兼容 OpenAI 的 API，让你可以轻松迁移并接入 LangChain、LlamaIndex 等现有 LLM 工具链。由于构建在 Ray Serve 之上，自动扩缩、多 GPU 支持与多节点推理一应俱全。

## **用 NVIDIA Triton Inference Server 与 TensorRT-LLM 部署 AI**

Triton Inference Server 是 NVIDIA 开发的开源软件平台，用于在生产环境中部署和服务 AI 模型。它帮助企业降低模型服务基础设施的复杂度、缩短新 AI 模型上生产的时间、扩大 AI 推理与预测容量。Triton Inference Server 支持 TensorFlow、PyTorch、ONNX 等多种深度学习框架，提供加速 GPU 与 CPU 推理的优化，被 [Amazon](https://resources.nvidia.com/en-us-inference-customer-story/nvidia-amazon-custom)、[Microsoft](https://resources.nvidia.com/en-us-inference-customer-story/ai-for-dev-solution)、[Oracle](https://blogs.nvidia.com/blog/ai-inference-oci-triton/)、[Siemens](https://resources.nvidia.com/en-us-inference-customer-story/Amazon-accelerates-customer)、[American Express](https://resources.nvidia.com/en-us-inference-customer-story/american-express-prevents-fraud) 等大量企业用于规模化部署高效的深度学习模型。

[TensorRT-LLM](https://github.com/NVIDIA/TensorRT-LLM) 是一个用于定义、优化并执行 LLM 推理的开源库。它保留了 FasterTransformer 的核心功能，配合 TensorRT 深度学习编译器，并以开源 Python API 快速支持新模型与定制。量化、in-flight batching、注意力优化等特性都收纳在简化的 Python API 之后，用以优化 LLM 的延迟与吞吐。

## **发挥最大潜力：Ray Serve 与 RayLLM 结合 Triton Inference Server 和 TensorRT-LLM**

*Ray Serve 与 NVIDIA Triton Inference Server。*

在 23.12 版本中，Triton Inference Server 提供了 [Python API](https://github.com/triton-inference-server/tutorials/tree/main/Triton_Inference_Server_Python_API)，让开发者可以把 Triton Inference Server 的优化无缝嵌入运行在 Ray Serve 上的 Python 应用。对 Ray Serve 用户，这意味着 ML 模型性能的提升——下文的基准就是证明；也意味着能用上 NVIDIA Triton Inference Server 的高级推理服务能力，例如 [Model Analyzer](https://github.com/triton-inference-server/model_analyzer)——它根据指定的应用 SLA 推荐最优模型配置。Ray Serve 用户还受益于 Triton Inference Server 的高可靠性——在 [WealthSimple](https://www.nvidia.com/en-us/case-studies/machine-learning-models-and-inference/) 等客户处达到 99.999% 的可用性。Triton Inference Server 用户现在也可以用 Ray Serve 构建包含业务逻辑、多模型且自动扩缩的复杂应用，用 Python 简化 AI 开发。

*NVIDIA 吞吐与延迟对比。*

RayLLM v0.5 同时支持 TensorRT-LLM 与 vLLM，让开发者为 LLM 部署选择最优后端。

请查阅[这份指南](https://docs.ray.io/en/master/serve/tutorials/triton-server-integration.html)在 Ray Serve 上试用 Triton Inference Server。从[这里](https://github.com/ray-project/ray-llm)开始使用 Ray LLM，部署经 TensorRT-LLM 优化的模型。
