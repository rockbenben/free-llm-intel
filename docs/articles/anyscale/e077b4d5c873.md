## 核心要点

用下一代 ML 平台持续优化机器学习（ML）训练平台，对跟上快速演进的 AI 与 ML 技术版图至关重要。本文梳理 Airbnb 演讲中的洞见：他们把先进 ML 技术集成进自身基础设施的历程。我们将探讨优化 ML 平台的重要性、Kubernetes、Ray 及其他工具的角色，以及在 ML 训练中实现成本效率、可扩展性与性能的挑战和解法。

- Airbnb 已有基于 Kubernetes 的 ML 基础设施，但发现 K8s 在支撑 ML 负载上有缺口：不支持分数 GPU、运行指标暴露、开发者可用性、大模型扩展等问题。
- 他们采纳 Ray 来补齐缺口。Ray 的好处包括：本地轻松做原型、远程执行并动态控制运行时、支持 PyTorch 等最新 ML 框架与 DeepSpeed 等优化库。
- 成本效率方面，他们在 AWS 上用 auto-scaling groups、Kubernetes cluster auto-scaler 与 KubeRay 搭建了完全弹性的 Ray 集群，把资源碎片化降到最低。
- 训练效率方面，他们使用 AWS EFA 与 RDMA 让 worker 之间拥有高吞吐网络——这对分布式训练很重要。
- 借助 Ray，他们能在 8× A100 GPU 上训练最高 12B 参数的模型，基准测试达到每块 A100 150 TFLOPS。
- 展望未来，他们计划研究 30B+ 参数模型的模型并行、集成 Aviary 以降低服务成本、并整合训练引擎。

## ML 的快速演进

在谈优化策略之前，先理解为何必须持续增强 ML 平台。ML 领域以不断创新为特征：新算法、新框架、新硬件架构层出不穷。跟上这些发展，是确保 ML 模型保持竞争力与有效性的前提。

Airbnb 的历程是这一现象的绝佳案例。他们引入 Ray 等先进 ML 平台以有效应对变化的版图。这种适应力至关重要——在 ML 领域保持前沿，就必须善用最新的工具与技术。

## Kubernetes 的角色

Kubernetes 是现代 ML 基础设施的基本构件，为部署和管理 ML 应用提供可扩展、灵活的环境。Airbnb 把 Kubernetes 集成进 ML 基础设施，正体现了它的地位。

Kubernetes 让 ML 从业者把应用封装为 K8s 原生资源，从而简化管理、改善资源利用，并支持扩缩与服务发现。最终得到的是流程顺畅、高效的 ML 开发过程。

## 用 Ray 服务 ML

开源分布式计算框架 Ray 在 Airbnb 的 ML 基础设施中扮演关键角色。Ray 支撑分布式 ML 训练，让 ML 从业者高效驾驭多块 GPU。

Ray 最重要的优势之一是能无缝扩展 ML 负载。无论是训练数十亿参数的模型，还是做复杂计算，Ray 都提供所需的弹性。这份可扩展性确保即使模型规模与复杂度增长，ML 模型仍能快而有效地训练。

## ML 训练的成本效率

成本效率是 ML 训练的头号关切。ML 模型——尤其是大型深度学习模型——资源密集、训练昂贵。在维持或提升模型性能的同时优化成本，是关键挑战。

Airbnb 的成本效率策略包括几项：

1. **临时集群（Ephemeral Clusters）**：按需创建临时集群，把闲置资源降到最低。这些集群可为 ML 负载的特定需求量身定制，确保资源利用经济高效。

2. **资源管理**：实施资源管理系统，控制资源分配与使用，防止过度配置和不必要开销。

3. **自动扩缩容**：利用自动扩缩特性，按负载需求动态调整资源，既避免闲置也避免过载。

## 扩展 ML 负载

随着 ML 模型越来越复杂，可扩展性的需求愈发迫切。Airbnb 对 3D 模型并行的探索是典型例子。这一方案瞄准超过 300 亿参数的模型：节点间用流水线并行、节点内 worker 用张量并行。

这种程度的扩展让 ML 从业者有底气挑战最难的问题——例如训练超大规模语言模型——因为他们确信能有效驾驭分布式计算资源。

## 集成新技术

ML 领域持续演进，新技术与新方法不断涌现。把这些进展集成进现有基础设施既有挑战又不可或缺——这是保持竞争力的条件。

Airbnb 对用 Aviary 做在线服务的探索，是其拥抱新技术决心的写照。这一集成旨在通过连续批处理（continuous batching）等特性降低服务成本。接纳 Aviary 这类创新，能显著影响 ML 部署的成本效益。

## 快节奏开源社区的挑战

ML 社区的创新速度既是恩赐也是挑战。它让你能触及最尖端工具与技术，也要求不断适应与学习。Airbnb 的经验表明：必须积极与开源社区互动，才能掌握信息、有效利用最新进展。

## 结语

用下一代 ML 平台优化 ML 训练平台，不只是跟进最新技术的问题，更关乎让 ML 基础设施能高效释放这些技术的威力。Kubernetes、Ray 及其他工具正是达成这份效率的关键。

成本效率、可扩展性与适应力是 ML 平台优化的核心考量。Airbnb 的历程是一份宝贵的案例研究，展示了组织如何在不断演进的 ML 技术版图中航行。

总之，企业必须把 ML 平台优化视为长期过程。通过接纳新工具、新策略与新技术，他们不仅能跟上 ML 领域的快速演进，还能保持领先，交付更强大、更经济的 ML 解决方案。
