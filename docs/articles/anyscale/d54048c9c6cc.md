# 灵活、跨语言的分布式模型推理框架：Ray Serve 的 Java API

作者：[Tengwei Cai、Yang Liu、Chengxi Luo、Xiaofeng Yang、Simon Mo](https://www.anyscale.com/blog?author=tengwei-cai-yang-liu-chengxi-luo-xiaofeng-yang-simon-mo) | 2022 年 12 月 13 日

本文是来自 [Ant Group](https://www.antgroup.com/en/) 与 [Anyscale](https://www.anyscale.com/) Ray 团队的 Ray 贡献者撰写的客座博客，展示如何使用带 Java API 的 Ray Serve 这一跨语言、分布式模型推理框架。

## 什么是 Ray Serve？

[Ray Serve](https://docs.ray.io/en/latest/serve/index.html) 是构建在 [Ray](https://ray.io) 框架之上的在线模型推理框架，且不绑定具体的推理服务框架。与其他推理服务框架相比，Ray Serve 侧重于弹性伸缩、优化由多个模型组成的推理图，以及大量模型复用少量硬件的场景。它凸显了 Ray 灵活的调度能力与高性能 RPC。Ray Serve 支持任意机器学习框架来服务模型，自带 batch 处理功能以提升吞吐，并原生支持 [FastAPI](https://docs.ray.io/en/latest/serve/http-guide.html?highlight=FASTApi#fastapi-http-deployments) 框架。

## Ray 背景

Ray 旨在为分布式计算提供一套通用 API。实现这一目标的核心一环，是提供简单而通用的编程抽象，把繁重的工作都交给系统。正是这一理念，使开发者能够把 Ray 与既有的 Python 和 Java 库及系统一起使用。

Ray 力图让分布式应用与库的开发与组合*在一般意义上*成为可能。具体而言，这包括粗粒度的弹性工作负载（即各种[无服务器计算](https://medium.com/riselab/two-missing-links-in-serverless-computing-stateful-computation-and-placement-control-964c3236d18)）、机器学习训练（例如 [Ray Train](https://docs.ray.io/en/latest/train/train.html)）、在线 serving（例如 [Ray Serve](https://docs.ray.io/en/latest/serve/index.html)）、数据处理（例如 [Ray Datasets](https://docs.ray.io/en/master/data/dataset.html)、[Modin](https://modin.readthedocs.io/en/latest/)、[Dask-on-Ray](https://github.com/ray-project/ray/pull/9857)）以及临时性计算（例如并行化 Python 应用、把不同的分布式框架粘合在一起）。

Ray 的 API 让开发者能够在一个分布式应用中轻松组合多个库。例如，Ray task 与 actor 可以调用同样运行在 Ray 中的分布式训练（例如 [torch.distributed](https://docs.ray.io/en/master/raysgd/raysgd_pytorch.html)）或在线 [serving 工作负载](https://docs.ray.io/en/master/serve/)，也可以被它们调用。从这个意义上说，Ray 是一个出色的「分布式胶水」系统，因为它的 API 足够通用、性能足够好，可以充当许多不同类型工作负载之间的接口。

## Ray Serve 与 Java

Java 是计算机行业的主流编程语言之一，大量用户把 Java 作为自己的主要语言。自 Ray 2.0 起，Ray Serve 原生支持 Java。用户可以把[自己的 Java 代码部署为 Deployment](https://docs.ray.io/en/latest/serve/tutorials/java.html)，并通过 Java API 调用和管理它。同时，Python API 也能跨语言地作用于 Java Deployment，反之亦然。

在本文中，我们将详细介绍 [Ray Serve 的 Java 部分](https://docs.ray.io/en/latest/serve/managing-java-deployments.html)，并用简单的步骤逐段演示如何开始搭配 Java 使用 Ray Serve。

### 启动 Ray Serve

启动 Serve 进程的方式与 Ray Serve 的 Python API 相同。在 Java 中使用 Ray Serve 之前，需要先执行启动操作，拉起 Serve 的 Controller 与 Proxy 角色。例如：

```
1Serve.start(/*detached=*/true, /*dedicatedCpu=*/false, /*config=*/null);
```

### 创建 deployment

通过在 *Serve.deployment() * 接口中指定完整的类名，用户可以创建并部署一个 deployment：

```
1public static class Counter {
2
3    private AtomicInteger value;
4
5    public Counter(String value) {
6      this.value= new AtomicInteger(Integer.valueOf(value));
7    }
8
9    public String call(String delta) {
10      return String. valueOf(value. addAndGet(Integer. valueOf(delta)));
11    }
12  }
13
14  public void create() {
15    Serve.deployment()
16        .setName("counter")
17        .setDeploymentDef(Counter.class.getName())
18        .setInitArgs(new Object[] {"1"})
19        .setNumReplicas(1)
20        .create()
21        .deploy(/*blocking=*/true);
22  }
```

### 访问 deployment

deployment 创建成功后，就可以通过它的名称来查询：

```
1public Deployment query() {
2    Deployment deployment = Serve.getDeployment("counter");
3    return deployment;
4  }
```

### 调用 deployment

Java 的 Serve deployment 可以通过 Java 的 RayServeHandle 调用，例如：

```
1Deployment deployment = Serve.getDeployment("counter");
2System.out.println(deployment.getHandle().remote("10").get());
```

同样，它也可以通过 HTTP 调用：

```
1curl -d '"10"' http://127.0.0.1:8000/counter
```

### 更新 deployment

一次 deployment 之后，可以修改它的配置重新部署。例如，下面的代码把「counter」的副本数改为 2：

```
1public void update() {
2    Serve.deployment()
3        .setName("counter")
4        .setDeploymentDef(Counter.class.getName())
5        .setInitArgs(new Object[] {"2"})
6        .setNumReplicas(1)
7        .create()
8        .deploy(/*blocking=*/true);
9  }
```

#### 配置 deployment

通过 Java API，你还可以配置 deployment：

- 扩缩 deployment 的 replica 数量
- 以及指定每个 replica 的 CPU 或 GPU 资源

#### 横向扩展 deployment

*numReplicas* 参数控制部署多少个 replica。你可以动态调整这个参数，例如：

```
1public void scaleOut() {
2    Deployment deployment = Serve.getDeployment("counter");
3
4    // Scale up to 2 replicas.
5    deployment.options().setNumReplicas(2).create().deploy(/*blocking=*/true);
6
7    // Scale down to 1 replica.deployment.options
8    deployment.options().setNumReplicas(1).create().deploy(/*blocking=*/true);
9  }
```

### 资源管理（CPU、GPU）

通过 deployment 的 *rayActorOptions* 参数，你可以设置每个 deployment replica 与给定资源（例如一块 GPU）的绑定：

```
1public void manageResource() {
2    Map<String, Object> rayActorOptions = new HashMap<>();
3    rayActorOptions.put("num_gpus", 1);
4    Serve.deployment()
5        .setName("counter")
6        .setDeploymentDef(Counter.class.getName ())
7        .setRayActorOptions(rayActorOptions)
8        .create()
9        .deploy(/*blocking=*/true);
10  }
```

### 跨语言 deployment

通过 Java API，你还可以跨语言地部署并调用 Python deployment。假设 */path/to/code/ 目录*下有一个 Python 文件 *counter.py *：

```
1from ray import serve
2
3@serve.deployment
4class Counter(object):
5    def __init__(self, value):
6      self. value = int(value)
7
8    def increase(self, delta):
9        self. value += int(delta)
10        return str(self.value
```

部署并调用这个 Python deployment 的示例如下：

```
1import io.ray.api.Ray;
2import io.ray.serve.api.Serve;
3import io.ray.serve.deployment.Deployment;
4import io .ray.serve.generated.DeploymentLanguage;
5import java.io.File;
6
7public class ManagePythonDeployment {
8
9  public static void main(String[] args) {
10
11    System. setProperty(
12        "ray.job.code-search-path",
13        System.getProperty("java.class.path") + File.pathSeparator + "/path/to/code/");
14
15    Serve.start(true, false, null) ;
16
17    Deployment deployment =
18        Serve.deployment()
19            .setDeploymentLanguage(DeploymentLanguage.PYTHON)
20            .setName("counter")
21            .setDeploymentDef("counter.Counter")
22            .setNumReplicas(1)
23            .setInitArgs(new Object[] {"1"})
24            .create();
25    deployment.deploy(/*blocking=*/true);
26
27    System.out.println(Ray.get(deployment.getHandle().method("increase").remote("2")));
28  }
29}
```

## 总结

总而言之，在这篇简短的、逐步展开的上手教程中，我们通过代码示例展示了你有多容易上手使用 Ray Serve 的跨语言能力，尤其是 Ray Serve 对 Java 的支持。尽管在 Ray 2.0 中 Java 支持仍是实验性的，我们仍鼓励你尝试我们的 [Java 教程 ](https://docs.ray.io/en/latest/serve/tutorials/java.html)并通过提交遇到的 issue 向我们反馈。
