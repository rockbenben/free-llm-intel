# 开源 LLM：可用于生产，还是低质量玩具？

作者：Anyscale Ray Team | 2023 年 11 月 20 日

*本文是 Ray Summit 2023 精彩回顾系列的一部分，我们总结了近期这场 LLM 开发者大会中最激动人心的演讲。*

## 核心要点

- LLaMA 等开源大语言模型（LLM）可以胜任生产用例。Anyscale、Hugging Face 等公司提供开源 LLM 的托管服务，让它们用起来很轻松。
- 开源 LLM 可以比 GPT-3 这类专有模型便宜得多（例如便宜 30 倍），同时对许多应用提供足够好的性能。这一成本差距让一些产品/用例成为可能——若用专有模型则根本不可行。
- 微调后的开源 LLM 有时甚至能胜过 GPT-4 这类最大的专有通用 LLM。但微调不是万能药——它对语言格式的塑造比对事实信息的注入更有效。
- 开源 LLM 目前在某些方面落后于专有模型：输出质量、精确遵循指令、函数模板（function templates）支持、大上下文窗口。但许多差距正在被积极攻克。
- 开源与专有 LLM 混合使用可以取得不错的成本/性能折衷。演讲者举了一个例子：5% 的查询发给 GPT-4，95% 发给一个开源 LLM。

开源语言模型（LLM）正日益成为生产可用之选，挑战着"它们是低质量玩具"的旧观念。本文探讨开源 LLM 与 GPT-4 这类专有模型相比的强项与短板，深入模型质量、指令遵循、函数模板、上下文窗口大小等因素，凸显开源 LLM 的成本效益与在各种应用中的可行潜力。

## 开源 LLM：可用于生产，还是低质量玩具？

近年来，语言模型的版图发生巨变，开源模型赢得关注，挑战了它们只是低质量玩具的看法。这引出了问题：开源 LLM 真的能胜任生产应用吗？为回答它，我们拆解近期题为《Open Source LLMs: Viable for Production or a Low-Quality Toy?》演讲中的洞见，比较开源 LLM 与专有模型的强弱。

## 质量很重要

演讲先直面房间里的大象：模型质量。历史上，GPT-4 这类专有 LLM 被视为高质量输出的金标准：它们在类比推理、规划和生成精炼回答方面表现出色。但演讲者带来一个转折——Llama 70b 等开源 LLM 绝不可轻视。虽然 GPT-4 可能在某些任务上领先，开源 LLM 已能与专有对手抗衡，在摘要与微调等任务上尤其如此。

## 指令遵循：对齐与灵活

一个出人意料的发现是：专有 LLM 得益于 RLHF（基于人类反馈的强化学习），在被明确指令时表现出更好的服从性。开源 LLM 则可能还需要额外一步微调，才能确保精确遵循指令。不过演讲者提出一个变通之道：用会"指挥"其他 LLM 的任务专用 LLM，取得更好的性能与成本效益。

## 函数模板：锁定输出格式

专有 LLM 带来一个便利特性——函数模板。它让用户锁定期望的输出格式，免去后处理纠错。最初缺乏这一特性的开源 LLM 正在追赶。虽然并非所有开源模型都已提供函数模板，从进行中的项目看，这一差距有望很快弥合。

## 上下文窗口：越大越好

上下文窗口大小对处理信息至关重要，专有 LLM 一直凭借更大的窗口保持领先。Llama 70b 等开源模型在这方面可能落后，但一些有前景的项目正着手解决这一限制。随着技术演进，人们寄望开源 LLM 很快追平乃至超过专有模型的上下文窗口。

## 成本效益：开源 LLM 的优势

开源 LLM 最令人信服的论点之一是成本效益。演讲强调，开源模型不是便宜一点点，而是能便宜得夸张。这一成本优势打开了无限可能，让某些应用在专有模型下财务上不可行的情况下变得经济可行。

## 前路：挑战与机遇

尽管开源 LLM 已取得长足进步，挑战犹存。质量提升、上下文窗口扩展、函数模板集成，都是开源社区持续的努力方向。然而开源 LLM 的潜力毋庸置疑：它们在多种任务上挑战专有模型的能力，加上成本优势，使其成为开发者与企业的强劲选项。

## 结语：为合适的活选合适的工具

总之，关于开源 LLM 是生产可用还是只是玩具的争论，正在倒向"可用"一边。演讲提供了细致的视角，提醒我们按需选择合适的工具。开源 LLM 不是万能方案，但它们带来的成本优势与能力，可以在特定场景中被有效利用。

随着开源社区持续创新、补齐当前短板，开源 LLM 的前景光明。开发者与企业都应密切关注这一快速演进的版图，随时拥抱这些日益强大且高性价比的语言模型带来的机会。
