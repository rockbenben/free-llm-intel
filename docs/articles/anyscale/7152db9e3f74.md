- 他们为推荐与计算机视觉任务使用多种 ML 模型。负载包括推荐、媒体理解与大语言模型。

## Netflix 基于 Ray 的异构训练集群

全球流媒体巨头 Netflix 以其数据驱动的内容个性化著称。为此，他们依赖一个以 GPU 集群支撑模型训练与推荐系统的强健机器学习平台。本文探讨 Netflix 的异构训练集群，聚焦其对 Ray 与 GPU 的使用。

## 理解异构训练集群

异构训练集群是 Netflix 机器学习基础设施的重要组成部分。这类集群汇集 CPU、GPU 等不同类型硬件，服务广泛的机器学习负载。借此，Netflix 能高效支撑从推荐系统到大语言模型的各种用例。

## 个性化在 Netflix 中的角色

Netflix 成功的核心在于为用户个性化内容推荐。平台首页为每个 profile 深度定制，首页上的一切都由推荐驱动。这些推荐来自分析用户观看历史与偏好的复杂机器学习模型。

## 机器学习负载

Netflix 的机器学习负载可分为三大类：

1. 推荐用例：涉及稠密特征模型，与稀疏特征拼接，使用多个 MLP（多路 MLP）。特点是数据集庞大，需在多 GPU 上分布式训练。

2. 多模态用例：Netflix 的研究者处理多样数据源，包括文本、图像、音频、视频等。这些数据集可能极其庞大，因而需要分布式数据并行。

3. 大语言模型：这一新兴用例以较小的数据集训练超大规模语言模型。由于基于 Transformer 的架构，计算强度非常高。

## 高效计算与 GPU 利用

为充分利用 GPU 集群，Netflix 采用了一系列策略：

1. 自定义算子：使用自定义算子提升计算效率，降低组合复杂运算时的开销。

2. 最先进算子：Netflix 利用 TensorFlow 与 PyTorch 的最先进算子，改善内存使用与整体模型性能。

3. GPU 通信：Netflix 优化 GPU 通信，兼顾不同模型规模与 batch 大小。他们探索 TensorFlow 原生方案与 embedding 表等稀疏权重处理，为负载找到最合适的方式。

## 数据存储与管理

高效的数据存储与管理对机器学习工作流至关重要。Netflix 的策略包括：

1. 本地 SSD 磁盘：用于高速数据访问，但扩展性有限。

2. S3 流式读取：提供云端存储方案，但存在性能瓶颈。

3. FSx for Lustre：这一高吞吐文件系统帮助高效读取大数据集，并与 GPU 集群集成。

4. 数据加载优化：为优化数据加载、缓解 CPU 瓶颈，他们用 Ray 把数据加载卸载到远端 CPU。

## 资源分配与调度

Netflix 通过资源分配与调度策略确保异构训练集群被高效使用。他们采用资源池（resource pools）概念，按机器能力分组，让需要 GPU 资源的研究者更简单地申请资源。

## 挑战与未来方向

尽管基础设施相当成熟，Netflix 仍承认存在挑战：要容纳多样化负载、跟进新兴 GPU 技术。他们还在构建中心化的作业调度器与队列系统，以最大化资源利用率、减少团队间争抢。

## 结语

Netflix 用 Ray 与 GPU 技术构建异构训练集群，印证了 AI 与 ML 在娱乐产业的威力，也凸显了高效数据管理、计算与资源分配对打造个性化流媒体体验的重要性。随着机器学习与 GPU 技术持续演进，Netflix 将如何演进其基础设施、继续为全球数百万观众提供优质内容推荐，令人期待。
