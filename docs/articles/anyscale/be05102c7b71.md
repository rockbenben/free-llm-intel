[Hydra](https://hydra.cc/) 来自 Facebook AI，是一个用于优雅地配置复杂应用的框架。自首发布以来，Hydra 已成为深受研究者和实践者欢迎的流行框架。我们很高兴地宣布：用户现在可以通过全新的 [Hydra Ray Launcher](https://hydra.cc/docs/plugins/ray_launcher) 把作业扩展并启动到云端！

[Ray](https://github.com/ray-project/ray) 是一个与 Hydra 的需求完美契合的库。[Ray 是一个简单而强大的 Python 库，用于并行与分布式编程](https://ray.io/)，拥有出色的 ML 库生态（分布式训练、强化学习、模型服务），以及丰富的社区库与集成（例如 [Dask on Ray](https://docs.ray.io/en/master/dask-on-ray.html)、[Horovod on Ray](https://horovod.readthedocs.io/en/stable/ray_include.html)）。

Hydra Ray Launcher 让你能够以 3 种不同方式轻松配置并在 Ray 上启动你的应用。你可以通过以下方式启动应用：

- 在 AWS EC2 上启动或连接一个 Ray 集群，用于短时集群
- 如果你有一个长期运行的 Ray 集群，则连接到现有的 Ray 集群。
- 在本地启动一个新的 Ray 集群。

### LinkWalkthrough（实操演示）

下面我们将带你完成安装，并运行 launcher 提供的示例应用。更多细节请查阅 Hydra Ray Launcher 的[文档](https://hydra.cc/docs/plugins/ray_launcher)。

#### Link**安装**

`pip install hydra-ray-launcher --pre`

#### Link**启动到 AWS 集群**

在 AWS 上启动 Ray 应用，只需设置 `hydra/launcher=aws`。这会让你的应用运行在一个新建或已有的 AWS EC2 Ray Cluster 上。AWS 启动能力构建在 Ray 的 cluster launcher CLI 之上（[了解更多](https://medium.com/distributed-computing-with-ray/a-step-by-step-guide-to-scaling-your-first-python-application-in-the-cloud-8761fe331ef1)）。cluster launcher CLI 需要[一份 autoscaler yaml](https://docs.ray.io/en/master/cluster/cloud.html#aws-gcp-azure) 来做集群配置。

你可以像配置任何 Hydra 应用一样配置你的集群：yaml、严格配置（strict config）与命令行覆盖。

```
1@hydra.main(config_name="config")
2def my_app(cfg: DictConfig) -> None:
3    log.info(f"Executing task {cfg.task}")
4    time.sleep(1)
5
6if __name__ == "__main__":
7    my_app()
```

#### Link**在现有 Ray 集群上启动**

你也可以通过配置 launcher 连接到集群，把应用启动到现有的 Ray 集群上。例如，你可能想在本机上运行同一个 Ray 脚本，访问你之前启动的 Ray 集群。

HydraLaunchExistingRayCluster

#### Link**在本地拉起一个新 Ray 集群启动（用于测试）**

想在本地快速测试，可以在初始化时直接起一个 Ray 集群。注意唯一的差别是把 hydra launcher 指定为 ray，而上一例中用的是 `ray_aws`。

#### Link后续步骤

更多 launcher 细节请查阅 Hydra Ray Launcher 的[文档](https://hydra.cc/docs/plugins/ray_launcher)。想进一步了解 Hydra，请访问 Hydra [官网](https://hydra.cc/)并加入[社区](https://github.com/facebookresearch/hydra#community)。想进一步了解 [Ray](https://ray.io/%27)，请查阅 [Ray 文档](https://docs.ray.io/en/master/)、[Anyscale Academy 上的 Ray 教程](https://github.com/anyscale/academy)，并加入 [Ray 论坛](https://discuss.ray.io/)。
