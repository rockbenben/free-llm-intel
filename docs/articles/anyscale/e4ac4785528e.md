# 什么是超参数调优？

作者：[Juan Navas](https://www.anyscale.com/blog?author=juan-navas) | 2022 年 2 月 8 日

💡 *本文是超参数调优系列的第 1 篇。如果你想动手看看不同的调优方法，请务必阅读第 2 篇*[*如何在 XGBoost 上调整超参数*](https://www.anyscale.com/blog/how-to-tune-hyperparameters-on-xgboost)*，以及第 3 篇*[*如何使用 Ray Tune 分配超参数调整*](https://www.anyscale.com/blog/how-to-distribute-hyperparameter-tuning-using-ray-tune)*。*

超参数调优是控制机器学习模型行为的关键环节。如果我们没有正确地调优超参数，估计出来的模型参数就会给出次优结果，因为它们没有让损失函数最小化。这意味着模型会犯更多错误。在实际中，准确率、混淆矩阵这类关键指标都会变差。

本文将给出一些超参数的例子，并深入介绍几种超参数调优方法。随后，在本系列接下来的两篇文章中，我们将演示[如何在 XGBoost 上调整超参数](https://www.anyscale.com/blog/how-to-tune-hyperparameters-on-xgboost)以及[如何做分布式超参数调优](https://www.anyscale.com/blog/how-to-distribute-hyperparameter-tuning-using-ray-tune)。

## 什么是超参数？

在机器学习中，我们需要区分参数和超参数。学习算法会针对给定的数据集学习或估计模型参数，并在继续学习的过程中不断更新这些值。学习完成后，这些参数就成为模型的一部分。例如，神经网络中的每个权重和偏置都是一个参数。

而超参数则专属于算法本身，因此我们无法从数据中算出它们的值。我们用超参数来计算模型参数。对同一个数据集，不同的超参数值会产生不同的模型参数值。

超参数调优指的是：为一个学习算法找到一组最优的超参数值，使这套优化后的算法能用于任何数据集。这样一组超参数能让模型性能最大化，把预先定义的损失函数压到最小，从而以更少的错误得到更好的结果。要注意，学习算法是基于输入数据来优化损失的，它试图在给定的设置内找到最优解；而超参数恰恰精确地描述了这个设置本身。

例如，如果我们在做自然语言处理（NLP）模型，用来调参的算法很可能是神经网络、支持向量机（SVM）、贝叶斯网络和极端梯度提升（XGB）。

稍后我们会详细讨论如何进行超参数调优。

### 超参数类型

神经网络中一些需要调优的重要超参数有：

- **隐藏层数量**：这是在让神经网络尽可能简单（快且泛化）与正确分类输入数据之间做权衡。我们可以从四到六的值开始，然后在增大或减小这个超参数时检查数据上的预测准确率。
- **每层节点/神经元数量**：在决定每层用多少个神经元时，更多并不总是更好。增加神经元数量在某个限度内是有帮助的。但过宽的网络层可能会记住训练数据集，导致网络在新数据上准确率下降。
- **学习率**：模型参数是迭代调整的，而学习率控制每一步调整的幅度。学习率越低，参数估计的变化越小。这意味着拟合模型需要更长时间（和更多数据），但也意味着我们更有可能真正找到最小损失。
- **动量（Momentum）**：动量通过抵抗参数值的剧烈变化，帮助我们避免陷入局部极小值。它鼓励参数沿着它们*已经*在变化的方向继续变化，从而有助于防止每次迭代时的锯齿形震荡。建议从较低的动量值开始，再按需往上调。

我们认为以下是调优 SVM 的关键超参数：

- **C**：这是在平滑的决策边界（更通用）与紧贴数据的决策边界（对训练数据更准确）之间的权衡。取值偏低可能让模型把部分训练数据分类错，取值偏高则可能导致模型过拟合。过拟合产生的是一个对当前数据集过于具体、对将来的数据可能不适用、对将来的观测也不可靠的分析。
- **Gamma**：它是我们选作支持向量的数据样本影响半径的倒数。取值高意味着影响半径小、决策边界也小，不会考虑到相对接近的数据样本。这种高取值会导致过拟合。取值低意味着远处数据样本的影响显著，于是模型无法从数据集中捕捉到正确的决策边界。

XGBoost 需要调优的重要超参数有：

- `**max_depth**` 和 `**min_child_weight**`：这两个参数控制树的结构。`max_depth` 定义从根节点到最远叶节点的最大节点数（默认值是 6）。`min_child_weight `是在树中创建一个新节点所需的最小权重。
- `**learning_rate**`：它决定每一步的修正量，因为每一轮 boosting 都在纠正上一轮的错误。learning_rate 的取值范围是 0 到 1，默认值为 0.3。
- `**n_estimators**`：它定义集成中树的数量。默认值是 100。注意，如果我们用的是原生 XGBoost 而不是 scikit-learn，就要用 `num_boost_rounds` 而不是 `n_estimators`。
- `**colsample_bytree**` 和 `**subsample**`：这两个参数控制每一轮使用数据集的哪些样本。它们有助于避免过拟合。`subsample` 是使用样本的比例，取值 0 到 1，默认值为 1。`colsample_bytree` 定义列（特征）的比例，取值 0 到 1，默认值为 1。

在这些例子里，超参数偏向任何一端都会对模型的预测能力产生负面影响。诀窍是为每个超参数找到刚好的取值，让模型表现良好并给出尽可能好的结果。

## 调优超参数的方法

既然我们已经理解超参数是什么以及调优它们的重要性，接下来就需要知道如何选择它们的最优值。我们可以用人工方法或自动化方法来找到这些最优超参数值。

手工调优超参数时，我们通常从推荐的默认值或经验法则开始，然后用试错的方式在一段取值范围内搜索。但手工调优既繁琐又耗时。当超参数很多、取值范围又很宽时，它并不实用。

自动化的超参数调优方法用算法来搜索最优值。如今最流行的几种自动化方法是网格搜索、随机搜索和贝叶斯优化。下面我们逐一详细来看。

### 网格搜索

网格搜索是一种「暴力」式的超参数调优方法。我们先把可能的离散超参数值排成一个网格，然后用每一种可能的组合去拟合模型。我们记录每一组对应的模型表现，最后选出产生最佳表现的那一组组合。

hyperparameter-tuning-grid-search

网格搜索是一种穷举算法，能够找到超参数的最佳组合。但它的缺点是慢。用每一种可能的组合拟合模型通常需要很强的算力和大量时间，而这些未必具备。

### 随机搜索

随机搜索方法（顾名思义）是随机地挑选取值，而不是像网格搜索那样使用一组预先定义好的值。

随机搜索在每次迭代中尝试一组随机的超参数组合并记录模型表现。若干次迭代之后，它返回产生最佳结果的那一组组合。

![hyperparameter-tuning-random-search](https://images.ctfassets.net/xjan103pcp94/5DTA6ixwjbGYE2veJVaFcL/0af9813a2bf88151a03ce7bbf4dc292a/hyperparameter-tuning-random-search.png)随机搜索在每次迭代中尝试一组随机的超参数组合，并记录模型表现。若干次迭代之后，它返回产生最佳结果的那一组组合。

hyperparameter-tuning-random-search

当我们有几个搜索范围相对较大的超参数时，随机搜索就很合适。我们可以把范围离散化（例如 [5-100]，步长 5），仍然能得到一组相当不错的组合。

好处是，要得到可比较的结果，随机搜索通常比网格搜索花的时间更少。它还确保我们最终不会得到一个偏向用户随意选定的那几组取值的模型。缺点是结果可能并不是最优的超参数组合。

### 贝叶斯优化

网格搜索和随机搜索效率相对较低，因为它们常常要评估大量不合适的超参数组合。它们在选择下一组超参数时不考虑之前迭代的结果。

贝叶斯优化方法走的是另一条路。它把寻找最优超参数当作一个优化问题来处理。在选择下一组超参数组合时，这个方法会考虑之前的评估结果，然后应用一个概率函数来挑出最可能产生最佳结果的组合。这种方法能在相对很少的迭代里就找到相当不错的超参数组合。

当目标函数未知时——也就是没有可以用来求最大值或最小值的解析表达式——数据科学家会选择概率模型。他们把学习算法应用到数据集上，用算法的结果来定义目标函数，并把各种超参数组合作为输入域。

这个概率模型基于过去的评估结果。它估计的是某一组超参数的目标函数结果出现的概率：

> P( 结果 | 超参数 )

这个概率模型是目标函数的一个「代理」（surrogate）。目标函数可以是比如均方根误差（RMSE）。我们用训练数据和该组超参数来计算目标函数，并设法对它做优化（求最大还是求最小，取决于所选的目标函数）。

与目标函数相比，把概率模型作用在超参数上在计算上很便宜，所以这种方法通常会在每次运行目标函数后更新并改进这个代理概率模型。更好的超参数预测，能减少我们为取得好结果所需的目标函数评估次数。

高斯过程、随机森林回归和树结构 Parzen 估计器（TPE）都是代理模型的例子。

经过几次迭代，借助从「目标」函数得到的评估（观测），代理模型在坐标 x=-0.35、y=-0.8 处找到了最小值。注意该点附近有好几次评估，对应的是最近几轮迭代，因为模型已经几乎找到最小值、产生的值彼此接近（不同颜色的点对应不同的迭代）。

贝叶斯优化模型的实现比较复杂。幸运的是，我们可以用 [Ray Tune](https://docs.ray.io/en/latest/tune/api_docs/suggestion.html#bayesian-optimization-tune-suggest-bayesopt-bayesoptsearch) 这类现成的库来简化这个过程。这种模型值得一用，因为它能在相对很少的迭代里找到足够好的超参数组合。

当目标函数在算力和时间上代价高昂时，贝叶斯优化很有用。与网格搜索或随机搜索相比，它的一个缺点是我们必须顺序地计算贝叶斯优化（下一次迭代依赖上一次），因此它不支持分布式处理。所以，贝叶斯优化耗时更长，但使用的计算资源更少。

## 后续步骤

我们应当做模型超参数调优，以确保机器学习模型和数据能给出好结果。我们可以在三种超参数调优方法中选一种——网格搜索、随机搜索和贝叶斯优化。如果用训练数据评估模型会很快，我们可以选网格搜索方法；否则应当选随机搜索或贝叶斯优化，以节省时间和计算资源。
