数眼智能控制台完成 2.4 版本升级，围绕资金管理、企业报销、订阅续费和 API 调用优化四个方向做了改进，以下是具体变化。

## **01 钱包管理重构**

原来分散在不同页面的资金信息，现在统一归入「钱包管理」模块，分为三个子页：

![](https://ico.shuyanai.com/backend/o/63715171-f3f9-464a-a77f-d209dc99e628.png)

**额度充值** — 查看当前余额、历史消耗、请求次数，支持 7¥ 至 70,000¥ 快速充值，大额享阶梯折扣

![](https://ico.shuyanai.com/backend/o/8c303f15-e86d-44ba-ac35-22f585ba4b41.png)

**Coding Plan** — 集中展示所有订阅套餐，按需选购

![](https://ico.shuyanai.com/backend/o/6d723aaf-640c-459a-bbac-00b9cf29b4df.png)

**邀请奖励** — 推广返佣明细一目了然，支持一键划转至账户余额

余额、套餐、推广收益三件事在一个页面内完成，不用再来回切换。

## **02 发票管理上线**

国内控制台左侧菜单新增「发票管理」入口：

![](https://ico.shuyanai.com/backend/o/e6fc2ac3-e7d9-4e55-8d58-41df0b62e63e.png)

- 支持企业增值税普通发票和个人发票开具
- 可保存发票抬头信息，下次开票无需重复填写
- 支持按历史订单查询和申请开票
- 所有开票申请经人工审核，确保信息准确

企业用户的财务报销流程可以直接在控制台内完成，无需线下沟通。

## **03 订阅套餐支持自动续费**

购买 Pro Coding Plan（¥299.96/月）、Lite Coding Plan 等订阅套餐时，可以开启自动续费，优先从钱包余额扣款。套餐到期前系统自动完成续费，模型调用权益无缝衔接。

![](https://ico.shuyanai.com/backend/o/de84ba95-d720-4ae3-b5e0-8488c63f5e83.png)

随时可在控制台关闭自动续费。

## **04 API Key 新增调用策略**

![](https://ico.shuyanai.com/backend/o/17488a07-e129-4fd2-8fa7-71d8373a8793.png)

创建 API Key 时，分组设置中新增两种调用策略：

| 策略 | 逻辑 | 适合场景 |
| --- | --- | --- |
| 价格优先 | 自动路由到当前可用节点中价格最低的 | 开发测试、批量任务、成本敏感 |
| 稳定优先 | 优先路由到响应快、可用率高的节点 | 线上生产、关键业务 |

创建 Key 时还可以配置以下安全选项：

- **过期时间** — 永久 / 1 个月 / 1 天 / 1 小时
- **额度上限** — 设置该 Key 的最大消费额度，防止意外超支
- **IP 白名单** — 限制允许调用的来源 IP
- **模型白名单** — 限定该 Key 可调用的模型范围

适合团队场景下为不同成员或项目分发不同权限的 Key。

## **05 对公转账支持**

企业用户大额充值现在可以选择对公转账。充值时选择该方式，系统会展示对公账户信息和转账指引，到账后余额自动更新。

![](https://ico.shuyanai.com/backend/o/a8636e29-f46c-4d04-a828-3c076f969e9a.png)

以上功能已全部上线，登录[数眼智能控制台](https://shuyanai.com)即可使用。
