# 从脚本到生图生视频 跟着15秒案例上手

刷到一条有剧情、有反转的AI漫剧，你是不是也想过：这个故事，我好像也能做？

真准备动手，又卡住了：剧本怎么写？男女主怎么才能一直长同一张脸？图画好了，怎么让人物动起来？

这次，带大家在数眼智能里完整走一遍。先用文本模型写脚本，再用AI生图做角色和镜头画面，最后接上AI生视频。先做出一条15秒的小故事，把流程跑通，再慢慢加长。

# 先看案例 这15秒到底讲什么

打开数眼智能**【智能体】**，在**【视频特效】**里找到**【Ai漫剧】**，就能看到古装轻喜剧《房中秘术》。点开**【一键同款】**，可以查看它的视频提示词。案例使用Seedance 2.0，画面是9:16竖屏，时长15秒，分辨率1080p。

现在，数眼智能也支持Seedance 2.5了。看完这个案例，还可以沿用它的提示词，换成Seedance 2.5再试一版。同样一个故事，换个模型会怎么演？正好跟着这次教程一起看看。

剧情很简单：男主夜里偷偷看书，女主见他慌忙藏起来，又瞥见书名《房中秘术》，一下起了疑心。她抢过书翻开，里面居然是屋顶梁架、瓦片排列和院子漏雨位置的草图。原来，他正琢磨着替她修屋顶。

结尾再补一句“你刚才……想歪得很大声”，误会就变成了笑点。

两个人、一间书房、一个反转，这种小故事就很适合拿来练手。下面沿用这个案例的剧情，把提示词拆成方便操作的教学版。人物服装和部分台词也做了简化，照着走一遍，再换成自己的故事就行。

# 第一步 让文本模型把故事拆成镜头

先进入**【文本生成】。GLM-5.3、MiniMax-M3、DeepSeek-V4-Flash、Kimi-K3**都可以用来写故事、改对白、拆分镜。选一个开始就好，第一轮先把剧情说清楚。

这里最容易踩的坑，是让AI写出一大段小说，后面却不知道怎么拍。直接告诉它：我要15秒、两个角色、一个场景，每个镜头要做什么都写清楚。

这段可以直接复制

请把下面的故事改编成15秒、9:16竖屏的古装轻喜剧。

故事：男主夜里在书房看一本《房中秘术》，女主见他藏书，误以为他有秘密。抢来一看，里面是帮她修漏雨屋顶的图纸，最后用一句俏皮话收尾。

只保留男女主两个人，地点始终是夜晚的书房。拆成4个镜头，按0—3秒、3—6秒、6—10秒、10—15秒安排。

每个镜头分别写清画面、人物动作、简短台词和镜头运动。总对白尽量控制在40字以内，给表情和翻书动作留时间。最后分别给出角色生图提示词、场景关键帧提示词和视频提示词。用分段文字输出，不要表格。

拿到脚本，先对照这四拍看看：开头藏书，接着抢书，中间揭晓图纸，最后一句话反转。观众能顺着看懂，就可以往下做了。

如果AI给了太多台词，继续追一句：“对白再短一点，把解释改成翻书特写和人物反应。”让画面替你讲故事，15秒才不会挤。

# 第二步 先把男女主的样子定下来

接着切到**【图片生成】**。这里可以选择Seedream 5.0 Lite、Seedream 4.5、Seedream 4.0。这次先用Seedream 5.0 Lite做角色参考图。

这个案例里有个很实用的做法：男女主各准备一张“近身照＋三视图”。近身照看清脸，正面、侧面、背面把发型和衣服交代完整，后面生成视频就有了明确的参考。

教程里，给女主定一套浅青色衣裙，男主穿月白色长袍。选定以后，后面的镜头都沿用这套设定。

**女主参考图提示词**

> 古装轻喜剧女主角色设定图，成年年轻女性，气质清秀灵动，黑色长发半挽髻，佩戴一支简洁玉簪，穿浅青色古装衣裙。写实古装短剧质感，自然皮肤纹理，柔和均匀光线，纯白背景。同一张图左侧是清晰的近身半身照，右侧依次排列正面全身、侧面全身、背面全身。所有视图保持同一张脸、同一发型、同一套服装和身体比例。无文字、无水印。

**男主参考图提示词**

> 古装轻喜剧男主角色设定图，成年年轻男性，面容清俊，黑发束起，戴简洁玉冠，穿月白色古装长袍，腰间系深青色腰带。写实古装短剧质感，自然皮肤纹理，柔和均匀光线，纯白背景。同一张图左侧是清晰的近身半身照，右侧依次排列正面全身、侧面全身、背面全身。所有视图保持同一张脸、同一发型、同一套服装和身体比例。无文字、无水印。

出图后，把两张图分别保存成“女主参考图”和“男主参考图”。先看清楚：正面和侧面是不是同一个人？玉簪、玉冠、腰带有没有乱变？这一轮挑稳了，后面会省下不少返工。

**再做一张书房关键帧**

关键帧就是某个镜头里最重要的一张静态画面。这里先做男主藏书、女主刚进门的一刻。把男女主参考图上传到支持参考图的图片生成选项里，再输入：

> 参考已上传的男女主角色图，保持两人的脸、发型和服装一致。9:16竖版，写实古装轻喜剧画面。夜晚书房，红木书案上有古籍、烛台和青瓷茶盏，窗外下着细雨，冷蓝月光与室内暖金烛光交织。月白长袍男主坐在画面左侧，正把一本深蓝封面的古籍收向身侧，神情略慌；浅青衣裙女主站在右侧门口，疑惑地看着他。中景，两人面部清楚，动作停在刚被发现的一瞬间，不新增人物，不生成字幕和水印。

先看这张图能不能一眼读懂“他在藏，她在看”。如果看不懂，就改构图或动作。静态画面顺了，再让它动起来，会更容易判断哪里需要调整。

# 第三步 把图片接到AI生视频

角色图和关键帧准备好，就切到【视频生成】。这里可以选择Seedance 2.5、Seedance 2.0、Kling V3、MiniMax-Hailuo 2.3等模型。这次可以选Seedance 2.5，试着把前面准备好的故事和图片做成视频。它单次最长可选30秒，跟着这个案例练习，先做15秒就好。

先练一个让图片动起来的短镜头

在支持图片输入的模式里上传刚才的书房关键帧，选择可用的短时长。提示词重点补动作：人怎么动，镜头怎么走，最后停在哪里。

> 以这张书房画面为视觉参考，保持男女主的脸、发型、服装和人物位置一致。男主把书往身侧轻轻收起，抬眼看向门口；女主向前走半步，视线落在书上，露出疑惑表情。镜头缓慢推近，烛火轻微摇曳，衣袖自然摆动。动作幅度小，人物不说话，最后停在两人对视的瞬间。不新增人物，不切换场景，不生成字幕。

这一步，你就完成了“AI生图→AI生视频”的衔接。图负责定人物和构图，视频提示词负责补动作，分工很清楚。

同一段剧情 换个模型看看会怎么演

想接着做完整故事，可以回到【视频特效】→【Ai漫剧】，打开《房中秘术》的【一键同款】，复制案例提示词。接着进入【视频生成】，选择Seedance 2.5，放入准备好的男女主参考图，让提示词中的图1、图2与上传素材一一对应。

想看两个模型的差别，就用同一版提示词、同一组参考图，分别在Seedance 2.0和Seedance 2.5里生成一版。时长统一为15秒，比例统一为9:16，分辨率也选两边都支持的同一档。第一轮先把这些条件保持一致，更容易看清各自的表现。

你可以直接复用案例里的原提示词，也可以复制下面的教学版。选定一版后，两边都用这一版即可。

角色参考图主要告诉模型“这个人长什么样”，书房关键帧主要告诉模型“这一镜怎么构图”。如果使用首帧模式，就放对应关键帧；使用角色参考模式，就按页面要求放角色图，别把两种用途弄混。

**15秒教学版视频提示词**

> 生成15秒、9:16竖屏古装轻喜剧。图1是女主参考图，图2是男主参考图，保持两人的脸、发型、服装和身体比例一致。夜晚书房，红木书案、古籍、烛台、青瓷茶盏，窗外细雨，室内暖金烛光。写实古装短剧质感。0—3秒：中景。男主坐在书案旁看书，发现女主进门，赶紧把书收向身侧。女主问：“藏什么呢？”3—6秒：女主走近，拿过那本《房中秘术》，看看书，再挑眉看他。男主欲言又止。6—10秒：书页特写，里面是屋顶梁架和瓦片排列草图。男主解释：“想把你的屋顶修好。”10—15秒：切回两人。女主松了口气，又嘴硬地问：“那你慌什么？”男主轻笑：“你刚才，想歪得很大声。”女主愣一下，神情由疑惑转为羞恼。

台词简短，口型自然，动作连贯，角色不换脸、不换发型服装。书封如需出现文字，只保留“房中秘术”四字，书内以维修图纸为主。不要自动添加对白字幕，不新增人物。

书名是这个误会的关键。生成后要单独检查封面文字；如果字不清楚，可以在后期补上。图纸也要看得出屋顶和瓦片，反转才能成立。

把两版视频放在一起看：男主藏书的动作，哪版更自然？女主从怀疑到松口气，哪版表情更到位？翻开图纸和说出最后一句台词，哪版留的停顿更有喜剧感？再听听对白、看看口型，挑出更适合自己作品的版本。

如果15秒里翻书太快、对白挤在一起，就回到分镜，把藏书、抢书、图纸特写、两人反应分别做成短镜头，再剪到一起。不必每次都把整段推倒重来。

# 第四步 看完一遍 把不顺的地方修好

第一次出片，先别急着发。跟着剧情看一遍，重点盯住这几个地方。

人物有没有变：女主的玉簪还在不在，男主的腰带有没有换色，切到特写时还是不是同一张脸。

动作接不接得上：书上一秒在男主手里，下一秒怎么到了女主手里；翻开的方向对不对，手指有没有明显变形。

反转能不能看懂：图纸有没有给够停留时间；男主解释修屋顶时，画面是否已经让观众看到证据。

声音顺不顺：生成结果如带对白，听一遍有没有漏字、抢话，口型是否自然。需要补配音、音乐、字幕或拼接镜头时，再做相应后期处理。

哪里出问题，就回到对应步骤改。脸不对，检查角色参考图；动作太乱，减掉多余动作；笑点没出来，给图纸和表情多留一点时间。

# 第五步 发布文案也顺手写出来

视频定下来，再回到**【文本生成】**，把最终剧情发进去，让它接着写标题、简介和互动文案。这一步以成片为准，已经删掉的情节就别再写进简介了。

**发布文案提示词**

> 请给这条15秒古装轻喜剧写发布文案：男主藏起一本《房中秘术》，女主误会后抢书，发现里面是替她修漏雨屋顶的图纸，结尾两人用一句俏皮话化解误会。输出3个20字以内的标题、一段50至80字的简介、一个能让观众接话的评论区问题，以及5个相关话题词。语气轻松，像在跟朋友分享一个小故事。标题不要提前揭晓图纸反转，不要编造播放量。比如标题可以写：“他藏的这本书，把她气笑了”。评论区再接一句：“这事要是你撞见，会先问清楚，还是直接翻书？”

第一次做 先把这条短片做完

不会写脚本，就让文本模型先给一版；不会画角色，就从参考图开始；不知道视频提示词怎么写，就先让一个简单动作跑通。

跟着这套流程做完，你就有了第一套角色图、分镜和视频素材。下次换一个误会、换一个结尾，又能继续做下一集。
