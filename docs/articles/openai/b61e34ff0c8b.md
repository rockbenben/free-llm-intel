# 对神经网络策略的对抗攻击

## 摘要

人们已知机器学习分类器容易受到攻击者恶意构造的输入的侵害，从而被强制误分类。这类对抗样本在计算机视觉应用中已被广泛研究。在本工作中，我们证明对抗攻击针对强化学习中的神经网络策略同样有效。具体而言，我们表明现有的对抗样本构造技术可被用于显著降低已训练策略在测试时的性能。我们的威胁模型考虑能够向策略的原始输入引入微小扰动的攻击者。我们在白盒和黑盒设定下，针对一类对抗样本攻击，刻画了不同任务和训练算法的脆弱程度。无论所学任务或训练算法为何，我们都观察到即使使用不干扰人类感知的小幅对抗扰动，性能仍显著下降。视频见 [此链接](http://rll.berkeley.edu/adversarial)。

**作者**：Sandy Huang、Nicolas Papernot、Ian Goodfellow、Yan Duan、Pieter Abbeel
