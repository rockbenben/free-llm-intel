# 推出 Grid Protectors Program

启动一项全国性计划，帮助我们将来的计算园区支撑起可靠、可负担的电力。

今天，我们推出 **Grid Protectors Program**，这是一项全国性行动，旨在为我们开工建设所在社区的家庭和企业提供可负担、可靠的电力。我们将与公用事业公司、监管机构以及政策制定者合作，为我们未来的园区制定相应安排，让它们在电网承压时减少用电需求。

无论是在北方寒潮中为家中供暖，还是在南方热浪里开着空调，家庭都需要可靠的电力。我们的目标，是让园区的用电弹性成为一种资源，好让公用事业公司在社区最需要的时刻调用它。

据预测，美国的数据中心容量到 2030 年将超过 [100 吉瓦](https://about.bnef.com/insights/data-centers/six-things-to-know-about-bnefs-new-us-data-center-capacity-outlook/)，这给了我们一个一代人一遇的机会：通过建设那些能在社区最需要时调节自身用电的园区，来加强电网。

通过 Grid Protectors，我们的雄心是把这种弹性变成我们建设和运营未来园区的核心部分。这意味着在设施设计阶段就要做到需要时能减少用电，并与公用事业公司一起商定：需求可以减少多少、多快减少、能持续多久。这些安排会因地点而异，随着它们逐一敲定，我们也会分享更多承诺。

根据当地的需求和可用设备，我们还将与电网运营商合作，用场内的发电或储能来供电，并借助电池和电力控制来平抑需求的变化。

输电线路、变电站以及其他电网基础设施的建设，无论需求高低，都是一笔固定成本。通过在电网有余量时多用电、在电网承压时少用电，我们能够帮助分担这些基础设施的费用，同时减少为满足峰值需求而进行昂贵升级的需要。这有助于为其他用户把成本压下来。

美国需要更多电力来支撑经济增长，而 AI 正成为这部分需求中日益重要的一块。家庭和小型企业不应该被要求为某个计算园区的用电买单。我们一贯承诺自行承担自己的能源成本，包括我们所用的电力，以及为服务我们园区所需的基础设施。大型计算设施应当自付成本，并帮助公用事业公司管理好它们所依赖的那些系统。

## 佐治亚州的范例

对于规划中的 Effingham County 园区，我们已承诺承担服务这一项目所需的全部基础设施和电力服务成本。园区一旦投运，我们就能在需要的时刻削减我们所抽取的电力，帮助把电力留给其他用户。

我们[与 Georgia Power 达成的协议还包括](https://www.georgiapower.com/news-hub/press-releases/georgia-power-to-serve-openai-project-in-effingham-county.html)最高 1,000 兆瓦的灵活需求响应能力，在极端高温时腾出电力，帮助数十万户家庭保持空调运转。就规模而言，这大约相当于 700,000 户家庭的平均用电需求——比 Washington, D.C. 和 Boston 两城加起来的户数还要多。

这些计算设施与哪怕几年前建的数据中心都已大不相同，让我们在用电需求上可以做到灵活。

这意味着我们可以调低自身的需求，让家庭、小型企业和其他电费用户继续有电可用。建设电网资产代价高昂，而 Georgia Power 表示，这种弹性能够减少它为满足未来增长而需要新建的发电装机量。尽管园区仍在开发中，我们有意把 Effingham 作为 Grid Protectors 的一个试点，建立在这份已经为未来园区提供了范本的协议之上。

想象一家度假小镇上的餐厅。它需要为旺季备足餐桌和后厨空间，却必须全年为这份容量买单。常客帮助它把设施用起来，并在旅游淡季分担账单。我们愿意做的，就是成为那位常客。

用电需求也会随季节起落，不同地区在各不相同的时间迎来各自最大的峰值。我们的计算园区则需要全年用电。有了合适的协议，这份稳定的需求能够帮助把电网的固定成本摊到更多的售电量上，而弹性则让我们在系统最繁忙时削减需求。我们仍然要承担自己园区所产生的成本；目标是让其他用户也从中受益。

我们的协议也在为 Georgia Power 更广泛的降本计划添砖加瓦、帮客户降低成本。这家公用事业公司[预计从 2029 年起每年能为客户省下约 $950 million](https://www.georgiapower.com/news-hub/press-releases/contract-openai-approved-part-portfolio-delivering-950-million-annual-savings.html)，这来自它的大负荷用电协议组合和预期增长，其中包括 Project Camellia。它估计，对一户用电 1,000 千瓦时的典型居民用户而言，每月至少能带来 $15 的收益。

## 展望未来

佐治亚州的协议只是一个起点。在 OpenAI，通过我们的 Grid Protectors 计划，我们看到一个机会：即便在紧急和高需求的时刻，也能帮助社区灯火通明。我们将与公用事业公司、监管机构和政策制定者合作，为我们未来建设的园区制定切实可行的安排——这些安排要反映当地的电网需求，在电网承压时帮助园区支撑电网，并承担我们自己造成的成本。如果某个项目被推迟、缩减或取消，长期合同和财务担保能够保护其他用户。

弹性并不能取代对新能源供给和输电的投入。在这些投入之外，我们的 Grid Protectors 计划能够帮助让电网更加可靠，并保护家庭和小微企业，不让他们去承担 AI 基础设施的成本。这正是我们希望我们的计算园区达到的标准。
