# 电网保护者计划简介

启动一项国家计划，帮助我们未来的计算园区支持可靠、负担得起的电力。

今天，我们推出**电网保护者计划**，这是一项全国性努力，旨在为我们所在社区的家庭和企业提供负担得起的、可靠的电力。我们将与公用事业公司、监管机构和政策制定者合作，为未来的园区制定安排，以减少电网紧张时的电力需求。

无论是在北方寒流期间为房屋供暖，还是在南方热浪期间运行空调，家庭都需要可靠的电力。我们的目标是使校园灵活性成为公用事业公司在社区最需要时可以调用的资源。

随着美国数据中心容量预计到 2030 年将超过 [100 吉瓦](https://about.bnef.com/insights/data-centers/six-things-to-know-about-bnefs-new-us-data-center-capacity-outlook/)，我们有千载难逢的机会通过建设可以在社区最需要时调整电力使用的园区来加强电网。

通过 Grid Protectors，我们的目标是使这种灵活性成为我们建设和运营未来园区的核心部分。这意味着设计设施以在需要时减少用电量，并与公用事业公司合作，就减少需求量、减少速度和减少时间等达成一致。这些安排将因地点而异，我们将在最终确定后分享额外的承诺。

根据当地需求和可用设备，我们还将与电网运营商合作，通过现场发电或存储提供电力，并使用电池和电力控制来平滑需求的变化。

无论需求高低，输电线、变电站和其他电网基础设施建设都是固定成本。通过在电网有空间时使用更多电力并在电力紧张时减少使用，我们可以帮助支付基础设施费用，同时限制为满足高峰需求而进行昂贵的升级的需要。这有助于降低其他客户的成本。

美国需要更多的电力来支持经济增长，而人工智能正在成为这一需求的重要组成部分。不应要求家庭和小型企业补贴计算园区的电力需求。我们始终致力于支付自己的能源成本，包括我们使用的电力以及为我们的校园提供服务所需的基础设施。大型计算设施应该支付其成本并帮助公用事业公司管理他们所依赖的系统。

## 乔治亚州的一名模特

对于我们规划的埃芬汉县园区，我们承诺支付该项目所需的全部基础设施和电力服务费用。一旦园区投入运营，我们就可以减少在需要时消耗的电力，从而帮助为其他客户节省电力。

我们与佐治亚电力公司达成的协议还包括高达 1,000 兆瓦的灵活需求响应，释放电力以帮助数十万家庭在酷暑期间保持空调运行。就规模而言，这相当于大约70万户家庭的平均电力需求。这比华盛顿特区和波士顿的家庭总和还多。

这些计算设施与几年前建造的数据中心有很大不同，使我们能够灵活地满足电力需求。

这意味着我们可以拒绝我们的需求，以便家庭、小企业和其他纳税人继续拥有权力。建设电网资产成本高昂，乔治亚电力公司表示，这种灵活性可以减少为满足未来增长而需要建设的新一代发电量。尽管园区仍在开发中，但我们打算让埃芬汉作为电网保护者的试点，以已经为未来园区提供模型的协议为基础。

想象一下度假小镇里的一家餐馆。它需要足够的桌子和厨房空间来应对旺季，但它必须为全年的容量付费。常客帮助保持其使用并在旅游业放缓时支付账单。我们建议成为该常客。

电力需求也会随着季节的变化而升降，不同地区在不同的时间面临最大的高峰。我们的计算园区全年都需要电力。通过正确的协议，稳定的需求可以帮助将电网的固定成本分摊到更多的电力销售上，而灵活性可以让我们在系统最繁忙时减少需求。我们仍然需要支付校园造成的成本；我们的目标是让其他客户也受益。

我们的协议还有助于乔治亚电力公司降低客户成本的更广泛计划。该公用事业公司[预计从 2029 年开始，每年可为客户节省约 9.5 亿美元](https://www.georgiapower.com/news-hub/press-releases/contract-openai-approved-part-portfolio-delivering-950-million-annual- savings.html)，其大负荷协议组合和预期增长（包括 Camellia 项目）。据估计，使用 1,000 千瓦时的典型住宅客户每月至少可获得 15 美元的收益。

＃＃ 期待

格鲁吉亚协议是一个起点。在 OpenAI，通过我们的电网保护者计划，我们看到了帮助社区即使在紧急情况和高需求时期也能保持供电的机会。我们将与公用事业公司、监管机构和政策制定者合作，为我们未来建设的园区制定切实可行的安排——反映当地电网需求的安排，帮助园区在电网面临压力时支持电网，并支付我们创造的成本。如果项目被推迟、减少或取消，长期合同和财务保证可以保护其他客户。

灵活性不能取代对新能源供应和传输的投资。除了这些投资之外，我们的电网保护者计划还可以帮助提高电网的可靠性，并保护家庭和小型企业免于承担人工智能基础设施的成本。这就是我们希望我们的计算园区达到的标准。
