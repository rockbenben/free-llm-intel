# 面向现实世界的不良内容检测整体方法

阅读论文。

我们提出一种整体性方法，用于构建稳健、实用的自然语言分类系统，服务于现实世界的内容审核。这样一个系统的成功依赖于一环环精心设计并执行的步骤，包括内容分类体系与标注说明的设计、数据质量控制、用于捕捉罕见事件的主动学习管线，以及让模型稳健、避免过拟合的多种方法。我们的审核系统经过训练，可检测广泛的不良内容类别，包括色情内容、仇恨内容、暴力、自残和骚扰。该方法可泛化到差异很大的多种内容分类体系，可用于创建优于现成模型的高质量内容分类器。
