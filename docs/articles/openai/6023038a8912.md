# Asana 借助 Codex，两周完成原需5年的工程工作

Asana 使用 OpenAI Codex，在两周内以约1.2万美元的成本替换了过时的测试系统。

Asana 用大约两周完成了原预计需要五年的工作。

Asana 帮助团队协调工作。其平台利用 AI 智能体和自动化功能，帮助客户管理、跟踪和执行工作。Asana 将同样的方法用于工程团队：员工使用由前沿模型驱动的 OpenAI Codex 处理大型代码库变更，然后审查并批准每项拟议变更。

在这个项目中，Codex 帮助 Asana 的工程师移除了过时的测试系统 Enzyme；该系统此前导致公司的代码更难升级。模型与基础设施成本约为1.2万美元，而 Asana 估计原用人方案的成本约为600万美元。

> “并非每个耗时数年的项目都能压缩到几周内完成。但智能体能让工程师有更多空间精研技艺，也让曾经不可能完成的工作值得一试。”

—Amritansh Raghav，Asana 首席技术官

原有测试工具 Enzyme 已不再得到积极维护，逐渐成为 Asana 前端技术栈现代化的障碍。Asana 使用由前沿模型驱动的 Codex 完成了这项工作。只需一段五句话的提示词，最多四个编程智能体便可并行工作，每个智能体分别使用一份独立的代码库副本。一名工程师每天检查两次进度，并审查每项拟议变更。相比繁复的配置，简单的指令效果更好。

在两个自然周内累计投入1.5周的工程工时后，Enzyme 被彻底移除。模型与基础设施成本合计约1.2万美元。相比之下，原方案预计至少需要五年，成本估计约为600万美元。此次经历让公司重新判断哪些长期软件项目切实可行、值得启动。

完成此次迁移后，Asana 可以在其他迁移、重写和性能问题上测试智能体；这些工作曾被认为需要数年时间。团队希望，在人工继续审查工作的同时，工程师能有更多空间专注于技艺本身。
