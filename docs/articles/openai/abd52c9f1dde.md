# 借助 Kiro 中的 GPT‑5.6 为开发者带来更高性价比


GPT‑5.6 模型系列现已登陆 Kiro。Kiro 是一款软件开发智能体，能为大规模 AI 原生编码带来严谨的工程实践和质量保障。此次更新为 Kiro 用户带来了 OpenAI 最新的旗舰模型系列，包括 Sol、Terra 和 Luna，并将其融入团队规划、构建、审查和测试软件的开发工作流。这些模型协同工作，可以帮助开发者用更少的迭代产出更高质量的代码，并提升每个 Token 的价值。

GPT‑5.6 可让每个 Token 完成更多有价值的工作，以更低成本实现更强性能，并按需提供处理复杂任务所需的能力。在 Kiro 中，开发者可将这些能力用于以需求、代码库和团队标准为基础的长时间开发任务。

Kiro 可将高层次意图转化为清晰的需求、技术设计和可执行任务。这种结构化上下文有助于 GPT‑5.6 理解团队正在构建什么、系统应如何运作，以及最终实现需要达成什么目标。

借助 Kiro 中的 GPT‑5.6，开发者可以：

- 将产品构想和需求转化为结构化的实施计划。
- 更稳定地完成复杂的多步骤编码任务。
- 通过规范驱动开发，让 AI 编码更有条理。
- 结合整个代码库的上下文和既定团队标准开展工作。
- 在实施更改前，于关键检查点审查并完善模型的工作成果。
- 使用基于属性的测试来检查实现是否正确。

OpenAI 与 AWS 还携手优化了 Kiro 环境和 OpenAI 模型。测试发现，在 Terminal-Bench 2.1 中，GPT‑5.6 Terra 在 Kiro 中成功完成任务时，成本降低了约 82%。Kiro 的规范驱动方法从一开始就以清晰的需求、技术设计和任务上下文为模型提供依据，使其能以更少的失误更快得出可行的解决方案。对开发者而言，这意味着可以完成更多工作、减少无效投入，并从每次编码过程中获得更高价值。
