# 通过对比预训练得到文本与代码嵌入

## 摘要

文本嵌入（text embeddings）在许多应用中都是有用的特征，例如语义检索和文本相似度计算。以往工作通常会针对不同用例训练定制模型，在数据集选择、训练目标和模型架构上各有差异。本工作表明，在大规模无监督数据上做对比预训练（contrastive pre-training），可以得到高质量的文本与代码向量表示。同一批无监督文本嵌入，不仅在线性探针（linear-probe）分类上取得了新的业界领先结果，还表现出很强的语义检索能力，有时甚至能与微调后的模型竞争。在 7 个任务的线性探针分类准确率平均值上，我们最好的无监督模型相比此前最好的无监督和有监督文本嵌入模型，分别取得 4% 和 1.8% 的相对提升。同一批文本嵌入在大规模语义检索上评估时，在 MSMARCO、Natural Questions 和 TriviaQA 基准上相比此前最好的无监督方法分别取得 23.4%、14.7% 和 10.6% 的相对提升。与文本嵌入类似，我们在（文本, 代码）对上训练代码嵌入模型，在代码搜索上取得相比此前最好工作 20.8% 的相对提升。
