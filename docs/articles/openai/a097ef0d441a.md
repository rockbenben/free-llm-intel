# 适合所有人的 GPT‑6 和智能 UI


上个月，我们为付费客户推出了首款 GPT-6 模型，今天，我们通过为每周使用 ChatGPT 的超过 12 亿人构建的新 GPT-6 模型，将下一代智能带给更多人。

## 引入智能 UI

我们已经训练 GPT-6 使用文本、视觉效果和交互元素来撰写回复，并根据您的问题选择它们的组合方式。借助智能 UI，响应可以包括图形、可点击按钮、表单、图表和可直接在对话中使用的交互式体验。

格式取决于您要问的内容。并排比较可能效果最好。通过交互式图表进行解释可能更容易理解。当简单的文本答案是最有用的响应时，ChatGPT 可以为您提供。

### 对日常问题的更多视觉回应

ChatGPT 可以通过展示计划如何组合在一起来使计划更易于遵循。周日烤肉的时间可以放在食谱旁边，或者公路旅行的站点可以显示在地图上，并注明哪些地方值得绕道。

### 更轻松地学习复杂主题

视觉和交互式解释可让您探索事物的工作原理、更改输入以查看会发生什么，或逐步解决问题。

### 只需询问即可创建互动体验

您还可以要求 ChatGPT 为手头的任务创建一个工具，例如用于探索如何增加储蓄的计算器、与朋友共进晚餐的分钱器，或者您可以在对话中玩的游戏。

## 智能 UI 的工作原理

借助智能 UI，我们让 GPT‑6 能够自由地为每个问题创建最有用的界面，同时在网络和移动设备上保持快速且熟悉的体验。

我们构建了一个本地可流式组件库，以及一个在模型生成接口时处理接口的编译器。图书馆为每个响应提供了熟悉的设计基础，同时让模型室决定如何将各个部分组合在一起。编译器允许界面在模型生成时逐渐显示，而无需等待整个响应完成。

我们扩展了训练方法，帮助模型对内容、布局、视觉效果和交互做出深思熟虑的决策。这包括评估它创建的界面的清晰度、实用性和完整性。 GPT-6 学会了使用组件库并做出良好的设计决策，包括如何清晰地组织信息、何时使用交互性以及何时简单的文本响应就足够了。

改进模型的设计判断并扩展其可创建的内容仍有工作要做，但智能 UI 标志着人们与 ChatGPT 交互方式的重大转变。 ChatGPT 可以将 UI、数据和操作结合起来，为人们探索、理解信息和与信息交互创造全新的方式，而不是将每个问题都放入相同的对话格式中。

## 安全部署 GPT-6

当我们为更多人带来更智能的人工智能时，我们致力于改进它识别现实世界风险的方式、它响应的诚实程度以及它对人们设定的限制的尊重程度。 GPT-6 在每个领域都取得了进展，以 Astra 的多项安全进步为基础，更好地抵制绕过其安全培训的企图，遵循保障措施，并更清楚地了解相对于 GPT-5.6 Sol 可以做什么和不能做什么。我们根据现实世界使用的经验教训更新了其安全培训，以加强对涉及网络攻击、生物威胁和暴力的高风险滥用的保护。在对抗性测试中，GPT-6 对绕过其安全训练的尝试表现出更强的抵抗力，特别是针对跨多个回合的攻击。 GPT-6 还经过培训，可以在较高风险的情况下安全响应，同时避免不必要地拒绝无害的请求。这包括使用对话历史记录和相关上下文来识别单个提示中可能不明显的风险。

我们在整个培训过程中进行一致性评估，评估诚实度和对安全限制的反应。 GPT-6 更擅长识别和传达其自身能力的局限性，包括当它缺乏回答所需的信息或工具时。有关结果和我们的审查的更多详细信息，请参阅[**系统卡**⁠（在新闻中打开）](https://deploymentsafety.openai.com/gpt-6-october)。

## 可用性

具有智能 UI 的 GPT‑6 今天开始在全球范围内的 ChatGPT Plus、Pro、Business 和 Enterprise 级别的 Chat 选项卡中推出。从明天开始，推出范围将扩大到 Free 和 Go 级别。企业可用性取决于工作场所管理设置。

ChatGPT 中的 GPT-6 由适用于 Plus、Pro、Business 和 Enterprise 层的 GPT-6 Sol 以及适用于 Free 和 Go 层的 GPT-6 Luna 提供支持。两者都适合日常对话。

此更新适用于 ChatGPT 中的聊天体验。作为此版本的一部分，为 Work 和 Codex 提供支持的模型不会发生变化。

## 接下来会发生什么

我们的使命是向全人类安全地提供通用人工智能的好处。 GPT-6 为每周使用 ChatGPT 的超过 12 亿人带来了我们在智能方面的最新进展。

智能 UI 是向 ChatGPT 迈出的一步，它可以围绕您想要做的事情塑造界面。

Over time, we want ChatGPT to create more of the interfaces people need for everyday tasks. You should be able to describe what you want to accomplish and work with an experience built around it.

For decades, people have had to learn how to use software, navigating fixed interfaces designed around particular tasks. We believe the future will be different. Instead of people adapting to software, software will adapt to people.
