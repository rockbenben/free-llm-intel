# 面向所有人的 GPT‑6 与 Intelligent UI


上个月我们为付费客户推出了最早的 GPT‑6 模型；今天，我们用一款新的 GPT‑6 模型把这一代智能带给更多人——它是为每周使用 ChatGPT 的超过 12 亿人打造的。

ChatGPT 中的 GPT‑6 引入了 Intelligent UI，这是一项新的能力，让 ChatGPT 能用完全可交互的用户界面快速作答：日常的回答变得更可视化，复杂的主题更容易学会，还能当场快速造出一个工具来解手头的任务。

## 推出 Intelligent UI

我们训练 GPT‑6 用文本、视觉和交互元素来组织回答，并根据你的问题决定它们如何组合。有了 Intelligent UI，回答里可以出现图形、可点按的按钮、表单、图表，以及你能直接在对话中使用的交互体验。

用什么形式，取决于你在问什么。一项比较也许并排放最合适。一段讲解也许借助可交互的图解才更好懂。而当一条简单的文本回答就是最有用的响应时，ChatGPT 也可以只给你文本。

### 日常问题，更可视化的回答

ChatGPT 能把各项内容如何衔接展示出来，让一份计划更容易照着走。周日烤肉各环节的时间可以排在菜谱旁边，公路旅行的各个停靠点可以标在地图上，并注明哪里值得绕一段路。

### 更容易学会复杂主题

可视且可交互的讲解让你能探究某个东西是怎么运转的、改一下输入看看会怎样，或者一步一步把一道题做下来。

### 只需开口，就能创建交互体验

你还可以让 ChatGPT 为手头的任务造一个工具，比如一个用来推演存款能长到多少的计算器、一个和朋友聚餐时分摊账单的工具，或者一个能在对话里直接玩起来的游戏。

## Intelligent UI 如何工作

在 Intelligent UI 上，我们给了 GPT‑6 充分的自由度，为每一个问题创造最有用的界面，同时让网页端和移动端的体验都保持轻快、熟悉。

我们构建了一套原生、可流式输出的组件库，并配了一个编译器，在模型生成界面的同时就加以处理。组件库为每条回答提供一个熟悉的设计底子，同时把各部分如何组合的空间留给模型决定。编译器让界面随模型的生成逐步显现，不必等到整条回答完成。

我们扩展了训练方法，帮助模型在内容、布局、视觉和交互上做出有斟酌的决策，其中包括从清晰度、有用性和完整性几个方面评估它造出来的界面。GPT‑6 学会了使用这套组件库并做出好的设计判断，包括如何把信息组织清楚、何时该用交互，以及何时一条简单的文本回答就够了。

要进一步提升模型的设计判断力、拓展它能创造的东西，前面还有不少工作要做，但 Intelligent UI 标志着人与 ChatGPT 交互方式的一次重要转变。ChatGPT 不再把每个问题都塞进同一种对话形式，而是能把 UI、数据和动作组合起来，为人们创造出探索、理解并与信息交互的全新方式。

## 安全地部署 GPT‑6

当我们把更智能的 AI 带给更多人，也在努力改进它识别现实世界风险的方式、它回应时的诚实程度，以及它对人们所设边界的遵守程度。GPT‑6 在这几个方面都有进展：它承接了 Astra 的若干安全进展，相比 GPT‑5.6 Sol 更能抵御绕过其安全训练的企图，更遵循安全保护措施，也更清楚地说明自己能做什么、不能做什么。我们根据现实使用中吸取的教训更新了它的安全训练，加强了针对涉及网络攻击、生物威胁和暴力的高风险滥用的防护。在对抗性测试中，GPT‑6 对绕过其安全训练的企图表现出更强的抵抗力，尤其是那些在多轮之间不断调整自身的攻击。GPT‑6 也经过训练，能在较高风险的场景中安全回应，同时避免对无害请求做不必要的拒绝。这包括利用对话历史和相关上下文，去识别单条 prompt 上并不明显的风险。

我们贯穿整个训练过程运行了对齐评测，考察诚实程度以及对安全限制的回应。GPT‑6 更能识别并说清自身能力的边界，包括它缺少作答所需的信息或工具的时候。结果的更多细节以及我们的评审见 [**系统卡**](https://deploymentsafety.openai.com/gpt-6-october)。

## 可用性

今天起，带 Intelligent UI 的 GPT‑6 在 Chat 标签页面向 ChatGPT Plus、Pro、Business 和 Enterprise 各档开始全球推送。从明天起，推送范围扩展到 Free 和 Go 档。Enterprise 的可用性取决于工作区管理员的设置。

ChatGPT 中的 GPT‑6 在 Plus、Pro、Business 和 Enterprise 各档由 GPT‑6 Sol 驱动，在 Free 和 Go 各档由 GPT‑6 Luna 驱动。两者都针对日常对话做了调优。

本次更新适用于 ChatGPT 中的 Chat 体验。为 Work 和 Codex 提供支持的模型不在这次发布的变更之列。

## 接下来

我们的使命是把通用人工智能的好处安全地交付给全人类。GPT‑6 把我们在智能上的最新进展，带给每周使用 ChatGPT 的超过 12 亿人。

Intelligent UI 是朝这样一个 ChatGPT 迈出的一步：它能围绕你要做的事来塑造界面。

随着时间推移，我们希望 ChatGPT 创造出更多人们完成日常任务所需的界面。你应当能描述自己想要完成什么，然后在一个围绕它构建起来的体验里工作。

几十年来，人们一直得去学习如何使用软件，在一个个为特定任务设计的固定界面中摸索。我们相信未来会有所不同。不再是人去适应软件，而是软件来适应人。
