# 隆重推出 ChatGPT Plus

我们正在推出 ChatGPT 的试点订阅计划，这是一种会话式人工智能，可以与您聊天、回答后续问题并质疑不正确的假设。

## This post covers the original Plus launch.

For current plans and features, see:

ChatGPT pricing


Release notes



新订阅计划 ChatGPT Plus 将以每月 20 美元的价格提供，订阅者将享有以下诸多好处：

- 即使在高峰期也能正常访问 ChatGPT
- 更快的回复速度
- 优先访问新功能和改进功能

ChatGPT Plus 现面向美国和世界各地的用户开放。[A](https://openai.com/zh-Hans-CN/index/chatgpt-plus/#citation-bottom-A)

我们珍视免费用户，并将继续提供免费 ChatGPT 访问。通过提供此订阅定价，我们将能够支持尽可能多的人免费访问。

## 从研究预览版中学习

我们推出 ChatGPT 作为研究预览版，是为了进一步了解系统的优缺点，并收集用户反馈，帮助我们改进其局限性。自那时以来，数百万人向我们提供了反馈意见，我们也进行了多次[重要更新⁠（在新窗口中打开）](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)，我们看到用户在草拟和编辑内容、集思广益、编程帮助和学习新知识等多个专业用途中发现了价值。

## 我们的未来计划

我们计划根据您的反馈和需求完善和扩展这一服务。我们还将很快推出（[ChatGPT API 候补名单⁠（在新窗口中打开）](https://share.hsforms.com/1u4goaXwDRKC9-x9IvKno0A4sk30)），并且正在积极探索低成本计划、商业计划和数据包等方案，以提供更多可用性。
