# OpenAI Microscope

插图：Ben Barry

我们推出 [OpenAI Microscope⁠（在新窗口打开）](https://microscope.openai.com/)——一个可视化集合，展示八个视觉“模式生物”（interpretabilty 研究中常被研究的模型）中每一个重要层和神经元的可视化。Microscope 让分析这些神经网络内部形成的特征更容易；在我们走向理解这些复杂系统的路上，希望它能帮助研究社区。

现代神经网络的能力是数千个神经元（有时上万个甚至更多！）相互作用的结果。为了理解它们的行为，我们希望能快速、轻松地细查这些神经元的相互作用，并分享观察结果。在协作环境中尤其如此。例如，一位研究员可能猜想：

> InceptionV1 4c:447⁠（在新窗口打开）是一个汽车检测器，由一个车轮检测器（4b:373⁠（在新窗口打开））和一个车窗检测器（4b:237⁠（在新窗口打开））构成。

当有人做出这样的论断时，如果其他人能快速浏览这些神经元、验证论断并有新发现，就会很有价值。这正是 OpenAI Microscope 的目标。

Microscope 系统性地可视化若干常用视觉模型中的每个神经元，并让所有神经元都可被链接。我们希望这能以多种方式支持可解释性社区：

- 尽管这些模型和可视化已经开源（我们参与维护 [lucid 库⁠（在新窗口打开）](https://github.com/tensorflow/lucid/)，Microscope 中的所有可视化都由它生成），但可视化神经元仍然繁琐。Microscope 把探索神经元的反馈回路从数分钟缩短到数秒。这一快速反馈回路对我们在持续的 [circuits 项目⁠（在新窗口打开）](https://distill.pub/2020/circuits/zoom-in/) 中发现诸如高低频检测器这类意外特征不可或缺。
- 让模型和神经元可链接，使得对关于这些神经元的研究论断可以立即接受检验与进一步探索。它还消除了关于“正在讨论哪个模型哪个神经元”的混淆（InceptionV1 的五个版本里我们说的是哪一个来着？）。这对协作极有帮助，尤其是身处不同机构的研究员之间。
- 可解释性作为 ML 领域的美妙之处之一，在于它的可及性。与许多其他领域相比，它需要的算力相对少。但系统性地可视化神经网络仍可能需要数百 GPU 小时。我们希望通过共享可视化成果，帮助可解释性保持高度的可及性。

正如生物学家常聚焦研究少数“模式生物”，Microscope 聚焦于详细探索少量模型。我们的首个版本包括九个常被研究的视觉模型，以及多种我们发现对研究它们特别有用的可视化技术。我们计划在未来几个月扩展到其他模型和技术。

我们很期待看到社区如何使用 Microscope，并鼓励你复用这些资源。特别是，我们认为它在支持 [Circuits 协作⁠（在新窗口打开）](https://distill.pub/2020/circuits/zoom-in/)——一个通过分析单个神经元及其连接来逆向工程神经网络的项目——或类似工作方面有很大潜力。
