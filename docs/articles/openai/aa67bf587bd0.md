# ChatGPT 入门

学习使用 ChatGPT 的基础知识，以及如何开始你的第一次对话。

## 什么是 ChatGPT？

ChatGPT 是一个对话式 AI 助手，它通过理解自然语言并实时生成接近人类的回复，帮助你思考、写作和解决问题。

ChatGPT 构建在大语言模型之上，因此能够协助处理广泛的任务。可在 [什么是 AI](https://openai.com/academy/what-is-ai/) 中进一步了解大语言模型。

当你需要快速的答案、解释、头脑风暴、改写或简短草稿时，使用 **Chat**；当你希望 ChatGPT 完成一个更大的任务并产出清晰、可审阅的成果（如简报、分析报告、演示文稿、电子表格或周期性更新）时，使用 **Work**。你可以从简单的 Chat 开始，当任务需要更多上下文、工具或后续跟进时再转到 Work。

可在[此处](https://learn.chatgpt.com/docs/use-chatgpt)了解更多关于使用 ChatGPT 的内容。

## 开始你的第一次对话

[打开 ChatGPT](http://www.chatgpt.com)，一个新建对话已经在等你。

要开始使用，只需输入一个**提示词（prompt）**。提示词就是你输入或分享给 ChatGPT 的问题或指令，用来开启一段对话。它通常是文本，但也可以是图片、音频或文件。你的提示词会引导模型，使其生成有用的回复。

不知道从哪里开始？复制并粘贴下面这个提示词，看看 ChatGPT 能为你做什么（把方括号替换成关于你自己的更多信息）：

*告诉我如何用 ChatGPT 让我的生活更轻松。我是一名[关于你或你的工作的描述]。给我 5 件我现在就能做的事，并为每件配一个提示词。*

阅读回复，然后通过追问或补充更多细节来进一步优化它。

可在[此处](https://learn.chatgpt.com/docs/prompting)了解提示词基础。

## 为 ChatGPT 找到好的使用场景

寻找有用的 ChatGPT 使用场景的一个好方法，是从你已经在对话形式下完成的工作入手：写草稿、头脑风暴、总结长文、把粗略笔记整理成更清晰的消息，或理清一个问题。这些都是很好的早期使用场景，因为它们容易尝试、风险低、即刻有用。如果 ChatGPT 能帮你更快地得到更好的第一稿、整理你的思路，或减少盯着空白页发呆的时间，那通常说明这个任务很适合它。

在此基础上，更强的使用场景往往是那些频繁重复、涉及多个步骤或需要长期上下文的任务。这正是 Projects、自定义 GPT 或 Skills 等工具更有用的地方：它们帮你组织源材料、保持指令一致，并把一次性的提示词变成可重复的工作流。一个好的经验法则是：先从简单的聊天任务开始，注意那些你做了不止一次的事，然后为你想做得更快、更稳定、更高质量的工作搭建更结构化的配置。

可[在此](https://learn.chatgpt.com/use-cases)探索 ChatGPT 的使用场景。

## 在 ChatGPT 中使用语音

说话通常比打字更快，而聆听能让交互更自然、更解放双手。语音功能能在繁忙的日子里节省时间、支持无障碍使用，并解锁新的工作流，比如边走边头脑风暴、多任务并行时起草文档，或大声练习演讲。

ChatGPT 的语音功能让你可以直接对 ChatGPT 说话并听到口头回复，或用听写把你的语音转成文字。通过聊天窗口上的图标，你可以在 **语音模式**（实时双向对话，你说它听、它说你听）或**听写**（说话并看到文字出现在输入框中，以便进一步修改）之间选择。

例如，你可以大声提出一个问题，ChatGPT 会以对话方式回复；或者口述会议记录，快速生成书面纪要。

语音聊天中的音频和视频片段会与转写文本一起保存在你的聊天记录中，只要聊天仍保留在你的历史里，它们就会被留存。

可在 OpenAI 帮助中心了解更多：[语音模式常见问题](https://help.openai.com/articles/8400625-voice-mode-faq)
