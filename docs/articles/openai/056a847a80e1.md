# Reptile：一种可规模化的元学习算法

我们开发了一种简单的元学习算法 Reptile。它的做法是：反复采样一个任务、对其执行随机梯度下降，并把初始参数朝该任务上学到的最终参数方向更新。Reptile 是最速下降算法（Shortest Descent）在元学习设定下的应用，在数学上与一阶 MAML（著名 MAML 算法的一个版本）相似，只需要对 SGD 或 Adam 这类优化器的黑盒访问，计算效率与性能也与之相近。

元学习是“学习如何学习”的过程。元学习算法接收一个任务分布，其中每个任务都是一个学习问题，它产出一个快速学习者——一个能从少量样例中泛化的学习者。一个被充分研究的元学习问题是少样本分类（few-shot classification）：每个任务是一个分类问题，学习者对每个类别只看到 1–5 个输入-输出样例，然后必须对新输入进行分类。下面你可以体验我们基于 Reptile 的 1-shot 分类交互式演示。

## Reptile 如何工作

与 MAML 一样，Reptile 寻求一种神经网络参数的初始化，使得网络可以用新任务的少量数据进行微调。但 MAML 需要对梯度下降算法的计算图进行展开（unroll）并求导，而 Reptile 只是以标准方式对每个任务执行[随机梯度下降（SGD）⁠（在新窗口中打开）](https://en.wikipedia.org/wiki/Stochastic_gradient_descent)——不展开计算图、不计算任何二阶导数。这使得 Reptile 的计算量和内存占用都低于 MAML。伪代码如下：

作为最后一步的替代方案，我们可以把 Φ−W \Phi - W Φ−W 当作梯度，代入更复杂的优化器，如 [Adam⁠（在新窗口中打开）](https://arxiv.org/abs/1412.6980)。

这个方法居然有效，起初令人惊讶。如果 k=1 k=1 k=1，该算法就对应“联合训练”——即在所有任务的混合分布上执行 SGD。虽然联合训练在某些情况下能学到有用的初始化，但当 zero-shot 学习不可能时（例如输出标签被随机置换时），它几乎学不到东西。Reptile 要求 k>1 k>1 k>1，此时更新依赖于损失函数的高阶导数；正如我们在论文中所示，这与 k=1 k=1 k=1（联合训练）的行为非常不同。

为分析 Reptile 为何有效，我们用[泰勒级数⁠（在新窗口中打开）](https://en.wikipedia.org/wiki/Taylor_series)近似该更新。我们证明，Reptile 更新最大化了同一任务不同 mini-batch 梯度之间的内积，这对应着泛化的提升。这一发现在元学习设定之外，对解释 SGD 的泛化性质也可能有启示。我们的分析表明，Reptile 与 MAML 执行的更新非常相似，包含同样两项、只是权重不同。

在实验中，我们展示了 Reptile 与 MAML 在少样本分类的 [Omniglot⁠（在新窗口中打开）](https://github.com/brendenlake/omniglot) 和 [Mini-ImageNet⁠（在新窗口中打开）](https://arxiv.org/abs/1606.04080) 基准上性能相近。Reptile 收敛到解的速度还更快，因为其更新的方差更低。

我们对 Reptile 的分析提示了通过不同 SGD 梯度组合可得到的大量不同算法。在下图中，假设我们在每个任务上用不同的 mini-batch 执行 k 步 SGD，得到梯度  g1,g2,…,gk g_1, g_2, \dots, g_k  g1​,g2​,…,gk​。下图展示了把每种求和组合作为元梯度时在 Omniglot 上获得的学习曲线。 g2 g_2  g2​​ 对应一阶 MAML，即 MAML 原论文提出的算法。纳入更多梯度会带来更快的学习，因为方差被降低了。请注意，只使用 g1 g_1  g1​​（对应 k=1 k=1 k=1）在该任务上没有任何进展——正如预测，因为 zero-shot 性能无法提升。
