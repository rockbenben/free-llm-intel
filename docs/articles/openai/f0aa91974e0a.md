# 加强国家安全领域的民主监督

OpenAI正在发起一项新倡议，帮助民主监督机构获得所需的专业知识和工具，以了解并监督政府在国家安全领域使用AI的情况。

正在加载…

AI正在改变民主政府保护民众的方式。它可以帮助阻止网络攻击、保护关键基础设施、更早发现威胁，并帮助公职人员在危机中更清晰地掌握局势。如果运用得当，这些工具可以增强国家安全。

民主监督有助于确保公共权力的运用始终对其服务的民众负责。随着AI让国家安全工作变得更快、能力更强，负责监督这项工作的机构也需要跟上步伐。AI可能基于缺失或过时的背景信息、配置不当的目标或存在偏差的假设，以极快速度大规模采取行动，导致错误在扩散前更难通过人工发现。监督对于AI在国家安全领域的应用尤为重要，因为相关决策可能因必要而涉及保密，并可能造成影响重大的后果。

在我们的[国家安全原则](https://openai.com/index/government-national-security-partnerships/)指导下，我们在国家安全部署中采取保障措施、确保人类作出实质性判断并开展适当监督，尤其是在影响重大的场景中。这些原则还将帮助监督机构建设相应能力列为优先事项，使其能够跟上AI应用的速度和规模。

## 确保监督跟上AI应用步伐

政府机构已经拥有监督国家安全活动的既定权限和职责。当AI参与这些活动时，监督方式可能也需要相应演变。传统监督方式需要投入大量人力；如果要求小型团队沿用纸质文件时代的方法，审查以机器速度运行的系统，监督工作几乎不可能完成。

OpenAI认为，能力越强的系统越需要有力的监督，我们也以此原则要求自己。根据我们的[准备框架](https://openai.com/index/updating-our-preparedness-framework/)，先进模型在部署前须经过严格审查，以了解其能力并确定保障措施是否充分。部署后，这项审查还会通过持续监测和事件复盘继续进行；我们从中获得的经验将用于强化保障措施，并指导未来的模型开发。

OpenAI不承担、也不应承担对政府的监督职能。这项责任属于民选官员以及为此设立的公共机构。我们的作用是在监督机构履行现有职责时，以技术为其提供支持。

以下三项原则将指导这项工作。

***第一，AI应增强而非取代人类和机构的判断。***政府行为是否合法、适当并符合适用规则和政策，应由获得授权的机构和依法设立的监督机构作出判断。

***第二，政府对AI的使用应当可追溯，并能让获授权的监督机构清楚理解。***审查人员应能了解AI如何影响决策，同时保护机密、隐私和安全敏感信息。

***第三，应利用AI为民主监督机构赋能。*** 对政府使用AI的情况进行人工监督，无法适应规模化应用。随着AI被应用于国家安全及其他影响重大的政府工作，监督机构也应依照其职责，以负责任、清晰透明的方式使用AI。

## OpenAI将采取的行动

未来一年，我们计划通过以下方式推进这项倡议：

- 我们将与获得授权的官员合作，寻找切实可行的机会，通过AI工具或技术支持提高监督成效。
- 我们将向民主政府监督机构提供价值500万美元的培训、技术支持和OpenAI额度，支持其以负责任的方式采用和评估AI工具。
- 我们将与监督机构合作试点相关工具，帮助获授权的审查人员检查AI辅助政府决策的相关记录，包括有关输入、输出和工具使用情况，从而更好地了解AI如何影响结果。在可行情况下，工具将具备互操作性或不依赖特定模型。证据、输出结果和调查结论将由参与机构而非OpenAI掌控，并且仅供获得授权的政府官员查阅。
- 我们将与公民社会和技术专家展开交流，让他们的观点为OpenAI开发这些工具以及履行相关责任的方式提供参考。

## 我们面前的选择

AI既可能让权力更加集中，也可以帮助民主机构更有效地行使和制约权力。技术本身不会决定我们将迎来怎样的未来，但人类机构和企业此刻作出的选择会。

我们将根据以下标准衡量这项倡议的进展：获授权的审查人员能否更好地履行职责，以及公众是否有更充分的理由相信政府AI系统正按预期用途使用。

随着政府使用AI的方式不断演变，OpenAI将继续支持负责监督AI应用的机构。
