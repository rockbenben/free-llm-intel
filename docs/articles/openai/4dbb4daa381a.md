# 智能时代的产业政策

以人为本的构想

阅读文档


*6 月 9 日更新：非常感谢大家对“智能时代的产业政策”的高度关注。我们已收到超过 400 份反馈，目前不再通过 *[*newindustrialpolicy@openai.com*⁠](mailto:newindustrialpolicy@openai.com)* 接收新的提交，相关团队正在对潜在的资助接收方进行评估。*

随着我们向超人工智能 (Superintelligence) 迈进，渐进式的政策更新已无法应对挑战。为了开启这场至关重要的讨论，OpenAI 提出了[一系列以人为本的政策构想](http://cdn.openai.com/pdf/561e7512-253e-424b-9734-ef4098440601/Industrial%20Policy%20for%20the%20Intelligence%20Age.pdf)。这些方案旨在增加机遇、共享繁荣，并构建具有韧性的社会制度，从而确保先进 AI 技术能够惠及每一个人。

这些构想虽然极具雄心，但仍处于初步探索阶段。我们将其视为讨论的起点，而非最终定论或全面建议；我们真诚地邀请各界通过民主程序，对这些想法进行补充、完善、质疑或抉择。为持续推动这一进程，OpenAI 正在采取以下行动：

- 广泛收集反馈：通过专属邮箱 [newindustrialpolicy@openai.com⁠](mailto:newindustrialpolicy@openai.com) 接收并整理各界意见
- 设立专项试点项目：提供最高 10 万美元的奖学金/研究资助，以及最高 100 万美元的 API 额度，支持深化这些政策构想及其相关课题的研究工作
- 搭建对话平台：将于 5 月在华盛顿特区的 OpenAI 工作坊 (OpenAI Workshop) 组织专题讨论
