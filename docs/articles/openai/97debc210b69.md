# 开发者现在可以向 ChatGPT 提交应用

开发者可以把应用提交给我们审核和发布，用户可以在 ChatGPT 的应用目录里找到这些应用。

在今年的 DevDay，我们把应用功能正式带进了 ChatGPT。从今天起，开发者可以按照我们的[应用提交指南](https://developers.openai.com/apps-sdk/app-developer-guidelines)提交应用，通过审核的应用将在 ChatGPT 中发布。应用能够为 ChatGPT 对话带来新的上下文，让用户可执行更多操作，例如订购杂货、将大纲转换为幻灯片，或搜索公寓房源。为了帮助开发者打造用户喜爱的高质量应用，我们基于 DevDay 以来的经验整理并发布了一系列资源，包括关于[优秀 ChatGPT 应用的最佳实践](https://developers.openai.com/blog/what-makes-a-great-chatgpt-app)、用于构建原生聊天界面的[开源 UI 库](https://github.com/openai/apps-sdk-ui)，以及一份循序渐进的[快速入门指南](https://developers.openai.com/apps-sdk/quickstart/)。

我们还在 ChatGPT 内上线了全新的应用目录，用户可以在其中浏览精选应用，或搜索已发布的应用。你可以从工具菜单进入应用目录，也可以直接访问 chatgpt.com/apps。开发者还可以在其他平台使用深度链接，将用户直接带到目录中的应用页面。

用户连接应用后，只需在对话中通过 @ 提及应用名称，或从工具菜单中选择，即可触发应用运行。我们也在探索更智能的方式，让相关且有用的应用在对话中自动浮现（例如基于对话上下文、应用使用习惯，以及用户偏好等信号），同时为用户提供清晰的反馈渠道。

## 应用构建、提交与变现

打造出色的 ChatGPT 应用，关键在于围绕真实的用户意向进行设计。开发者可以使用目前处于测试阶段的 Apps SDK，构建原生于聊天场景的体验，将上下文与可执行操作直接带入 ChatGPT。优秀的应用通常聚焦明确、在对话中直观易用，并能清晰地创造价值 — 要么完成从对话开始的实际工作流程，要么在 ChatGPT 内实现完全 AI 原生的全新体验。我们建议在开发早期就查看[应用提交指南](https://developers.openai.com/apps-sdk/app-developer-guidelines)，以打造高质量的应用。要查阅更多文档和示例，请访问[开发者资源中心](https://developers.openai.com/apps-sdk)。

当应用准备就绪后，开发者可以在 [OpenAI 开发者平台](https://platform.openai.com/apps-manage)提交应用以供审核，并查看审批进度。提交内容包括 MCP 连接信息、测试指南、目录元数据，以及可用国家/地区设置。首批通过审核的应用将从新年开始陆续上线。符合质量与安全标准的应用将有资格发布到应用目录中，而那些深受用户喜爱的应用未来可能会在目录中获得更突出的位置，甚至由 ChatGPT 主动推荐。

目前尚处于早期阶段，开发者可以从他们的 ChatGPT 应用跳转到自有网站或原生应用，以完成实体商品的相关交易。我们也在持续探索更多变现方式，包括数字商品等选项，并会在深入了解开发者构建方式和用户使用习惯后，逐步分享更多信息。

## 安全与隐私

所有开发者都必须遵循[应用提交指南](https://developers.openai.com/apps-sdk/app-developer-guidelines)中关于安全、隐私与透明度的要求。应用需符合 OpenAI 的使用政策，适用于所有用户群体，并在访问第三方内容时遵守相应的服务条款。每次应用提交都必须附带清晰的隐私政策，同时我们要求开发者仅收集让应用正常运行所需的信息。

当用户连接新的应用时，我们会告知可能与第三方共享的数据类型，并提供该应用的隐私政策供用户查看。用户也可以通过设置来管理个性化设置和数据共享方式，尤其是决定应用是否能够访问记忆内容和过往对话。用户始终拥有完全的掌控权：随时断开应用连接，应用将立即失去访问权限。

## 展望未来

这只是一个起点。未来，我们希望 ChatGPT 中的应用能成为对话的自然延伸，帮助用户从想法迈向行动，同时为开发者打造一个蓬勃发展的生态体系。随着我们不断从开发者和用户的反馈中学习，我们会持续优化整体体验。此外，我们还计划进一步壮大 ChatGPT 的应用生态，让应用更容易得到发现，并扩展开发者触达用户和实现变现的方式。
