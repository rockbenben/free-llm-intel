# OpenAI 先锋计划

在应用域推进模型表现与真实世界评估。

今天我们宣布 OpenAI Pioneers Program（先锋计划），旨在推动 AI 落地到真实世界用例。该计划聚焦于创建评估（evals），为"什么叫好"树立标杆，并为构建者提供在其领域优化模型表现的工具。

随着各行业 AI 采用速度的加快，我们需要理解并改善它在世界中的影响。创建领域专属的评估是更好反映真实用例的一种方式，能帮助团队在实际的高风险环境中评估模型表现。对推理模型做微调也已被证明是提升广泛应用表现的有力手段——所需的数据和精力更少。

通过先锋计划，我们将与在高影响力垂直领域构建新产品的公司合作，由我们的研究团队以定制化的方式帮它们扩展产品能力。计划中的公司将得到 OpenAI 研究者的支持，共同创建：

## 面向行业的领域专属评估

我们相信，法律、金融、保险、医疗、会计等行业都缺少一个统一的模型基准评测依据。

我们很高兴在未来几个月里，与每个行业的多家公司协助创建评估。我们的团队将与每家公司深度协作，设计贴合其领域的评估——建立清晰的基准来指导模型开发、提升对 AI 系统的信任，并公开分享。行业专属评估将在稍后发布。

## 针对三个行业专属用例的定制微调模型

计划中的公司将有机会与我们的团队合作，用强化微调（RFT）创建模型改进——这是一种模型定制技术，能为领域内的一小组任务创建"专家模型"——并针对公司最重要的三个用例训练定制模型。借助 RFT，公司能更好地解决客户痛点、改善模型低效之处。

我们的团队会引导公司走完微调流程。之后公司可以自行决定如何部署这些模型——它们应当已经可以直接用于大规模生产环境。

首期学员将聚焦于创业公司，它们将帮助奠定 OpenAI 先锋计划的基础。我们正在为首期挑选几家创业公司，每家都在做高价值的应用型用例，让 AI 在其中产生真实世界的影响。
