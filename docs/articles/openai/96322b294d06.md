# 用参数噪声实现更好的探索

我们发现，给强化学习算法的参数加入自适应噪声，往往能提升性能。这种探索方法实现简单、极少降低性能，值得在任何问题上试一试。

参数噪声让我们能以远快于其他方法的速度教会智能体任务。在 [HalfCheetah](https://gym.openai.com/envs/HalfCheetah-v1) Gym 环境（见上图）上学习 20 个回次（episode）后，策略得分约为 3,000，而用传统动作噪声训练的策略只得约 1,500。

参数噪声是把自适应噪声加到神经网络策略的参数上，而不是加到它的动作空间上。传统强化学习用动作空间噪声来改变智能体下一刻各动作出现的概率。参数空间噪声则直接把随机性注入智能体的参数，改变其决策类型，使决策始终完全取决于智能体当下感知到的内容。这项技术介于[进化策略](https://blog.openai.com/evolution-strategies/)（操纵策略参数，但不影响策略在每次 rollout 探索环境时所采取的动作）与 [TRPO](https://blog.openai.com/openai-baselines-ppo/)、[DQN](https://blog.openai.com/openai-baselines-dqn/)、DDPG 等深度强化学习方法（不碰参数，只在策略的动作空间加噪声）之间。

参数噪声帮助算法更有效地探索环境，带来更高分和更优雅的行为。我们认为原因在于：以审慎方式向策略参数加噪，能让智能体的探索在不同时间步之间保持一致；而向动作空间加噪导致的探索更不可预测，且与智能体参数特有的任何东西都不相关。

此前已有[研究](http://people.idsia.ch/~juergen/ecml2008rueckstiess.pdf)尝试把参数噪声用于策略梯度。我们把这一成果扩展为：证明该技术适用于基于深度神经网络的策略，并且可以应用于 on-policy 和 off-policy 两类算法。

在研究过程中，我们遇到三个问题：

- 网络不同层对扰动的敏感度不同。
- 策略权重的敏感度可能随训练推进而变化，使我们难以预测策略将要采取的动作。
- 选择合适的噪声尺度很难，因为参数噪声在训练中如何影响策略，直觉上不易把握。

我们用[层归一化（layer normalization）](https://arxiv.org/abs/1607.06450)处理第一个问题，它确保被扰动层的输出（即下一层的输入）仍处于相近的分布。

对于第二和第三个问题，我们引入一个自适应方案来调节参数空间扰动的幅度。其做法是度量扰动对动作空间的影响，看动作空间的噪声水平是高于还是低于设定目标。这个技巧把"选择噪声尺度"的问题转移到更可解释的动作空间。

## 基线与基准

我们还发布[基线代码](https://github.com/openai/baselines)，在 DQN、Double DQN、Dueling DQN、Dueling Double DQN 和 DDPG 中集成了这项技术。

我们提供了以下基准：在 [Atari 游戏](https://github.com/openai/baselines-results/blob/master/param-noise/atari.md)语料子集上，DDQN 使用与不使用参数噪声的表现；以及在 [Mujoco 仿真器](https://github.com/openai/baselines-results/blob/master/param-noise/mujoco.md)的一系列连续控制任务上，DDPG 三个变体的表现。

## 开发历程

最初开展这项研究时，我们发现施加到 DQN 的 Q 函数上的扰动有时过于极端，会导致算法反复执行同一个动作。为解决这个问题，我们加入了一个独立的输出头，像 DDPG 那样显式表示策略（在常规 DQN 中，策略只由 Q 函数隐式表示），使设置与我们的其他实验更接近。然而，在为本次发布准备代码时，我们跑了一个*不带*独立策略头、仅用参数空间噪声的实验。结果发现，它的表现与我们带独立策略头的版本相当，而实现要简单得多。后续实验进一步确认独立策略头确实没有必要——由于我们改变了噪声重新缩放的方式，算法可能早已比我们早期实验时更好。这带来了一个更简单、更易实现、训练成本更低的算法，而结果依然非常接近。值得牢记的是：AI 算法——尤其是强化学习——[可能以无声而隐蔽的方式失败](https://blog.openai.com/openai-baselines-dqn/)，从而诱使人们围绕被漏掉的 bug 去工程化地打补丁。
