Codex 现已登陆 ChatGPT 移动应用，因此无论你身在何处，都能随时掌握进展；同时，Codex 还能在你的笔记本电脑、开发机或远程环境中持续完成工作。

随着智能体开始承担运行时间更长的工作，一种新的协作节奏正在形成。为了让工作持续推进，你需要能够轻松回答问题、查看 Codex 的发现、调整方向、批准下一步操作，或加入新的想法。

如今，每周已有超过 400 万人使用 Codex，我们也看到这些微小时刻有多么重要。一次快速查看，就能让线程继续推进，避免不必要的返工，或帮助 Codex 在正确的上下文中取得进展。现在，你可以直接在手机上做到这一点。

## 随时随地连接正在进行的工作

ChatGPT 移动应用中的 Codex 提供了功能完整的移动体验，让你能用 Codex 完成工作。当你连接到任何一台正在运行 Codex 的机器时（无论是你的笔记本电脑、专用 Mac mini，还是受管控的远程环境），应用都会加载该环境的实时状态，让你能够在活跃线程、审批、插件和项目上下文之间流畅切换。

这不仅仅是远程控制单个任务，或向你的电脑派发新任务。从手机上，你可以处理所有线程、查看输出、批准命令、切换模型，或启动新的工作。你的文件、凭证、权限和本地设置都会保留在 Codex 运行所在的机器上，而更新会实时回传到你的手机，包括截图、终端输出、差异、测试结果和审批。

在底层，Codex 使用安全的中继层，让受信任的机器能够跨设备保持可访问，而无需直接暴露在公共互联网中。这个中继层还会在你登录 ChatGPT 的任何设备之间同步活跃会话状态和上下文。

## 在关键时刻介入

随着 Codex 在更长时间段内处理工作，及时指导会越来越成为确保这些工作真正有用的重要部分。通过手机，你可以在想到任务时立即启动它，在需要你判断时为其解除阻塞，并在结果逐步成形的过程中始终紧跟进展。

有了口袋里的 Codex，现在你可以：

- **在等咖啡时开始排查一个 bug。**由于 Codex 直接在你的开发环境中运行，它可以开始检查相关文件、在浏览器中复现问题、运行测试，并着手修复。如果 Codex 需要进一步说明或继续执行的权限，你可以直接在手机上回复或批准。在它工作的过程中，你还可以通过截图、终端输出和测试结果随时跟进，并最终在回到电脑前查看生成的差异。
- **在通勤途中做出决策****。**出门去办公室前，你让 Codex 处理一项需要较长时间推进的重构任务，并打算到工位后再查看结果。通勤途中，Codex 找到了两种可行方案，需要你的指示才能继续。你可以直接在手机上查看权衡、选择路径，等你到达时，任务已经按你希望的方向继续推进。
- **在快速变化的客户沟通前做好更充分准备。**连续开完几场会后，你发现一个支持问题正在 Slack、电子邮件、文档和基于浏览器的工具之间不断演变，而下一场客户电话会议马上就要开始。你可以在手机上让 Codex 汇总最新进展、标出关键待解问题，并为这次沟通准备一份简明摘要。如果又有新细节出现，你还可以在加入会议前让 Codex 刷新总结。
- **趁灵感还新鲜时，把新想法转化为实际推进。**无论你是在吃午饭、散步，还是听到什么内容突然有了想法，你都可以通过在手机上开启新线程或将其加入当前工作，把它发送给 Codex。这样，在你回到工位之前，任务就已经开始成形，而不会让你完全脱离激发灵感的当下。

## 在企业环境中运行 Codex

许多团队已经在受管控的远程环境中进行开发，这些环境提供经过批准的依赖项、凭证、安全策略和计算资源。

随着 Remote SSH 现已正式可用，Codex 可以直接连接到这些环境。桌面应用会自动检测你 SSH 配置中的主机，并让你像在本地一样，在远程机器中创建项目和运行线程。

连接后，这些环境还可以通过同一套安全中继基础设施，在你已获授权的 ChatGPT 设备之间访问。这意味着你可以在桌面端启动工作、在手机上引导执行，并让长时间运行的任务持续推进，而无需一直绑定在某一台机器前。

我们还发布了多项更新，进一步扩展团队大规模自动化、自定义和管理 Codex 的方式：

- **程序化访问 Token** 提供了具备范围限制的凭证，可直接从 ChatGPT 工作空间设置中签发，用于 CI 流水线、发布工作流和内部自动化。
- [**Hooks**⁠（在新窗口中打开）](https://developers.openai.com/codex/remote-connections) 现也已正式可用，可用于扫描提示中的敏感信息、运行验证器、记录对话、创建记忆，或针对特定代码仓库和目录自定义 Codex 行为。
- **支持在本地环境中以符合 HIPAA 要求的方式使用 Codex**（CLI、IDE、App），适用于 ChatGPT Enterprise 工作空间，帮助医疗机构以更高的速度和信心支持患者护理和运营工作流。

## 可用性

ChatGPT 移动应用中的 Codex 正在 iOS 和 Android 上向所有套餐逐步推出预览版，包括 Free 和 Go，并覆盖所有受支持地区。更新 ChatGPT 移动应用和 macOS 上的 Codex 应用即可体验。支持将手机连接到 Windows 上的 Codex 应用也即将推出。

Remote SSH 和 Hooks 也面向所有套餐开放。程序化访问 Token 适用于 Enterprise 和 Business 套餐。符合 HIPAA 要求的使用方式仅支持符合条件的 ChatGPT Enterprise 工作空间，且仅限在本地环境中使用 Codex 时适用。
