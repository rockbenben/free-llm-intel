# OpenAI 关于非营利组织与公共利益公司的声明

作者：Bret Taylor


OpenAI 计划进行架构调整，现有 OpenAI 非营利组织将控制一家公共利益公司 (PBC)，并直接共享其发展成果。自诞生之初，OpenAI 便以非营利组织的身份立足，至今初心未改，未来亦将坚守此道 — 坚持非营利组织的领导，以指引企业未来发展。

[正如我们之前宣布的](https://openai.com/index/evolving-our-structure/)，以及在[与 Microsoft 签署的无约束力谅解备忘录](https://openai.com/index/joint-statement-from-openai-and-microsoft/)中明确指出的，OpenAI 非营利组织将保持对该公共利益公司的持续控制权，并持有其股权。今天，我们宣布，新股权价值将超 1,000 亿美元，使 OpenAI 跻身全球资源最为雄厚的慈善组织之列。此次资本重组还将使我们能够筹集到完成使命所需的资金，并确保随着 OpenAI 公共利益公司的发展壮大，OpenAI 非营利组织的资源也将相应增加，从而让我们能够发挥前所未有的社会影响力。

这一架构再次彰显了我们的核心使命 — 确保通用人工智能 (AGI) 惠及全人类。我们公共利益公司的章程与管理机制将明确规定，安全决策必须始终以这一使命为指引。我们将继续与加利福尼亚州和特拉华州检察长保持紧密协作，这是我们强化工作方法的重要一环。我们承诺，将抓紧学习、积极行动，确保我们的工具对每个人都安全有益，同时倡导将安全作为全行业发展的重中之重。

作为下一阶段的重要举措，OpenAI 非营利组织已正式启动[一项 5,000 万美元资助计划](https://openai.com/index/people-first-ai-fund/)的首轮申请，旨在为非营利组织和社区组织提供以下三大领域的支持：AI 素养与公众认知、社区创新以及经济机遇。而这，仅仅只是开始。此次资本重组，将为我们开启更多可能性。

我们满怀期待，倾听各方声音、汲取智慧，携手共绘新篇章：让慈善的力量、创新的火花与社区的领导力交相辉映，不仅塑造 AI 的未来应用图景，更定义“智能时代”的崭新风貌。
