# 隆重介绍 OpenAI


OpenAI 是一家非营利的人工智能研究公司。我们的目标是以最有可能造福全人类的方式推进数字智能，不受生成财务回报的束缚。由于我们的研究没有财务义务在身，我们可以更专注于对人类产生积极影响。

我们相信 AI 应当是个人意志的延伸，并本着自由的精神，尽可能广泛、均衡地分发。这项事业的前景不确定，工作也很艰难，但我们相信目标和结构是对的。我们希望这正是这个领域最优秀的人最在意的事。

## 背景

人工智能一直是一个充满意外的领域。早期，人们以为解决了某些任务（比如国际象棋）就能让我们发现人类水平的智能算法。然而，每个任务的解法都被证明远没有人们希望的那么通用（比如在海量的走法中做搜索）。

过去几年则带来了另一种意外。一项被探索了几十年的 AI 技术——深度学习——开始在五花八门的问题领域拿到最先进的成果。在深度学习里，你不再为每个问题手写一个新算法，而是设计一种架构，它能根据喂给它的数据自我变形成各种各样的算法。

这条路在模式识别问题上成果斐然，比如图像物体识别、机器翻译、语音识别。但我们也开始看到，计算机[有创造力⁠(opens in a new window)](https://www.wired.co.uk/news/archive/2015-09/01/art-algorithm-recreates-paintings)、会[做梦⁠(opens in a new window)](https://www.theguardian.com/technology/2015/jun/18/google-image-recognition-neural-network-androids-dream-electric-sheep)、能[体验世界⁠(opens in a new window)](http://www.bloomberg.com/features/2015-preschool-for-robots/) 是什么样子。

## 展望未来

今天的 AI 系统能力令人印象深刻但狭窄。看起来我们会不断削减它们的限制，极端情况下它们几乎会在所有智力任务上达到人类水平。人类水平的 AI 能给社会带来多大好处，难以估量；而如果建造或使用不当，它可能给社会造成多大伤害，同样难以想象。

## OpenAI

鉴于 AI 这段出人意料的历程，人类水平 AI 何时近在咫尺很难预测。当它真的到来时，需要有一家领先的研究机构，能为所有人的良好结果把优先级放在自身利益之上。

我们希望把 OpenAI 发展成这样的机构。作为非营利组织，我们的目标是创造属于所有人的价值，而非属于股东。研究人员会被强烈鼓励发表自己的工作——无论是论文、博客还是代码，我们的[专利⁠](https://openai.com/approach-to-patents/)（如果有的话）将与世界共享。我们将与其他许多机构的同行自由合作，也期待与企业一起研究和部署新技术。

OpenAI 的研究总监是 [Ilya Sutskever⁠(opens in a new window)](http://www.cs.toronto.edu/~ilya/)，机器学习的世界专家之一。我们的 CTO 是 [Greg Brockman⁠(opens in a new window)](https://twitter.com/gdb)，曾任 Stripe 的 CTO。这个团队的其他创始成员都是世界级的研究工程师和科学家：[Trevor Blackwell⁠(opens in a new window)](http://www.trevorblackwell.com/#)、[Vicki Cheung⁠(opens in a new window)](https://vickicheung.com/)、[Andrej Karpathy⁠(opens in a new window)](http://cs.stanford.edu/people/karpathy/)、[Durk Kingma⁠(opens in a new window)](http://dpkingma.com/)、[John Schulman⁠(opens in a new window)](http://www.eecs.berkeley.edu/~joschu/)、[Pamela Vagata⁠(opens in a new window)](https://www.linkedin.com/in/pamela-vagata-8396074) 和 [Wojciech Zaremba⁠(opens in a new window)](http://cs.nyu.edu/~zaremba/)。Pieter Abbeel、Yoshua Bengio、Alan Kay、Sergey Levine 和 Vishal Sikka 是该团队的顾问。OpenAI 的联席主席是 Sam Altman 和 Elon Musk。

Sam、Greg、Elon、Reid Hoffman、Jessica Livingston、Peter Thiel、Amazon Web Services（AWS）、Infosys 和 [YC Research⁠(opens in a new window)](https://ycr.org/) 正在捐赠支持 OpenAI。这些资助者共承诺 10 亿美元，不过我们预计未来几年只会花其中很小一部分。
