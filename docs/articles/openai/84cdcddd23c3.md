# Superhuman

Superhuman 携手 OpenAI 开启电子邮件新纪元。


工作转向线上之后，大约 10 亿职场人每天要花将近 [3 个小时处理邮件](https://business.adobe.com/blog/perspectives/if-you-think-email-is-dead-think-again)。折算下来，人类每年花在邮件上的时间约为 1 万亿小时。

Superhuman 的目标是减少管理收件箱的时间。他们用 [OpenAI 的 API⁠](https://openai.com/api/) 打造了一套新一代 AI 邮件产品，为用户节省时间、创造价值、提升参与度。

## 爆满的收件箱

在任何公司，都有相当大比例的员工（Superhuman 估计在 30–50%，覆盖财务、销售、支持等岗位）整天进进出出邮件，与爆满的收件箱搏斗。邮件太容易被漏看——导致延误；更糟的是被处理不当——导致错误甚至声誉受损。

Superhuman 就是从解决这个问题起步的，其广受欢迎的产品内置了一整套邮件自动化，并与 Gmail、Outlook 等常用邮件服务集成。之后 AI 来了，给了这家公司把愿景再推一层、彻底变革邮件体验的机会。

> "我们许多人一年写的邮件量相当于好几部小说。算上花的时间、读的和写的，邮件正是 AI 为人们日常生活大幅增值的完美场所。"

Rahul Vohra，Superhuman 创始人兼 CEO

## 携手 OpenAI 重新构想邮件体验

Superhuman 在 Superhuman AI 上进展飞速，其背后由 OpenAI 的 API 驱动。他们已经推出了大量 GPT 驱动的功能，例如：

- **Write with AI（用 AI 写作）**：把一段书面提示词变成一封完整邮件
- **Rewrite in Your Voice（用你的声音改写）**：按用户本人的写作风格和语气改写邮件
- **Write with Your Voice（用你的声音写）**：把口述内容变成一封完整邮件，用户说几句话就能写完邮件
- **Auto Summarize（自动摘要）**：为用户收件箱里的每封邮件和每个会话实时显示一行摘要
- **Instant Reply（即时回复）**：从情境化的回复选项中挑选，一键回复邮件

从一开始，与 OpenAI 合作就是 Superhuman AI 路线图的核心，原因有几方面：

- **创业文化与支撑**："OpenAI 自己就是一家创业公司，所以懂得怎样极致快地工作，" Vohra 说。"我们与 OpenAI 团队的各位——工程师、市场增长、高管——保持高频互动。"
- **隐私优先**：Superhuman 嵌入在机密邮件线程中，客户自然关心数据保护。因为 OpenAI 对符合条件的用例提供零数据保留（ZDR），Superhuman 得以满足其严格的隐私与合规要求。
- **性能与成本最优**：OpenAI 的 API 提供一系列性能与成本特性不同的模型，让 Superhuman 能做明白的取舍。"OpenAI 是这个领域毫无争议的领导者，其模型比次优模型领先少则六个月、多则一年以上，无论模型输出质量还是速度都是如此，" Vohra 补充道。

## 收件箱清零速度快一倍

Superhuman 推出 Superhuman AI 后大获成功，用户采用率高、工作流更快：

- **AI 功能启用率高**：超过 *85%* 的 Superhuman 用户启用了新的 GPT 驱动功能。
- **参与度持续增长**：使用数据显示，用户不只是开启功能，而且使用频率随时间不断上升。例如，用户平均每周使用 Write with AI 功能 *25 次*，这个数字自上线以来增长了 *55%*。
- **处理邮箱速度翻倍**："我们的 AI 功能帮助客户以大约两倍于以前的速度处理完收件箱，" Vohra 说。
- **写邮件速度翻倍**：Superhuman 的 Instant Reply 用 OpenAI 的 API 起草回复，用户只需点发送。"beta 阶段，用户写邮件的速度比以前快一倍，" Vohra 说。"乘上我们用户发送的邮件数量，仅这一个功能每周就能为你省出一个多小时。"

## 按下邮件未来的"前进"键

"想象你早晨醒来，收件箱里每个邮件线程都有一句话摘要和一份回复草稿，点发送就行，" Vohra 说。这在几年前听起来可能异想天开。但 Superhuman 已经基于 OpenAI 的 API 构建并上线了这种端到端体验。每封邮件自动带上 AI 生成的摘要，用户可以从多个 AI 起草的回复中任选其一即时发送。"得益于这些 AI 功能，Superhuman 过去一年用户基数快速增长，每周新增用户数翻了一倍多。"

下一步是什么？Superhuman 设想这样一个世界：基于 GPT 的智能体很快就能自动过滤、分诊、回复邮件——安排会议和预约，并在网上与现实世界执行基本操作。Instant Reply 的成功证明，这个智能体主导的邮件未来并不遥远。

> "Superhuman 和 OpenAI 在希望 AI 走向何方上高度一致。我们都相信技术会提升人类成就的能力上限。"

Rahul Vohra，Superhuman 创始人兼 CEO
