# 鲁棒的对抗输入

我们制作的图像在从不同缩放和视角观看时，仍能可靠地欺骗神经网络分类器。这对上周的一项论断构成了挑战——该论断称，自动驾驶汽车很难被恶意欺骗，因为其图像来自多种缩放、角度和视角等。


未经处理的[对抗样本⁠（在新窗口中打开）](https://blog.openai.com/adversarial-example-research/)在图像变换下确实会失效。下面展示同一张猫的图片，经对抗扰动后，在于 [ImageNet⁠（在新窗口中打开）](http://www.image-net.org/) 上训练的 [Inception v3⁠（在新窗口中打开）](https://arxiv.org/abs/1512.00567) 中被错误分类为台式电脑。仅 1.002 倍的缩放，就使正确标签“虎斑猫”的分类概率反超对抗标签 `desktop computer`。


然而，我们一直怀疑：只要刻意努力，就能造出鲁棒的对抗样本——毕竟对抗样本已被证明能够[迁移⁠（在新窗口中打开）](https://arxiv.org/pdf/1607.02533.pdf)到物理世界。

## 尺度不变的对抗样本

对抗样本可以用一种名为投影梯度下降的优化方法制造：寻找对图像的小幅扰动，任意地欺骗分类器。

我们优化的不是“从单一视角看是对抗的输入”，而是在一个庞大的[随机分类器集成⁠（在新窗口中打开）](https://people.eecs.berkeley.edu/~liuchang/paper/transferability_iclr_2017.pdf)上优化——这些分类器在分类前会随机重新缩放输入。针对这样的集成做优化，能得到尺度不变的鲁棒对抗样本。


即使我们只限于修改属于猫的那些像素，也能造出一张同时在所有目标尺度上都保持对抗性的扰动图像。

## 变换不变的对抗样本

通过在训练扰动中加入随机旋转、平移、缩放、噪声和均值偏移，同样的技术能产出一个在这些变换下仍保持对抗性的单一输入。


我们的变换在测试时随机采样，表明该样本对整个变换分布都不变。
