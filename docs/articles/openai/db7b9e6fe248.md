# Oracle 如何借助 ChatGPT 和 Codex 将数天的工作缩短至几分钟

在招聘、工程和运营领域，Oracle 借助 ChatGPT 工作和 Codex，将专业知识转化为高效、可重复执行的工作流程。

从人才招聘团队到 Oracle Applications Lab，再到 IT 部门，Oracle 已有超过十万名员工在使用 ChatGPT 工作和 Codex。在这些团队中，过去需要依靠专业人员、耗时数天的工作，如今任何人都能在几分钟内完成。招聘人员省去了数天的市场调研；业务用户只需描述想要的结果，无须四处查找报表；技术负责人也能独立构建过去需要整个团队花费数月才能完成的工具。

> “我们使用 ChatGPT 工作构建了人才市场情报工具，真正革新了招聘流程中前期工作的开展方式。”

—Jan Ackerman，Oracle 高级副总裁兼全球人才招聘负责人

## 让招聘调研更高效

人才招聘团队使用 ChatGPT 工作构建了一款人才市场情报工具。输入职位描述后，工具就能调研同类岗位、对标薪酬，并评估相关地区的人才储备。这款工具为招聘人员提供了与用人经理沟通前所需的重要信息，而过去整理这些信息需要 2–4 天。

“我们的能力实现了从零到一百的飞跃，”Oracle 高级副总裁兼全球人才招聘负责人 Jan Ackerman 表示。“现在，我们坐下来，用这款通过 [ChatGPT] 工作构建的工具，只需大约 15 到 20 分钟就能做好准备。”

流程不仅更快，也更统一。过去，招聘人员在不同招聘任务中梳理用人需求的方式各不相同。有了人才市场情报工具，这一流程得以统一，无论与哪位招聘人员合作，每位用人经理都能获得同等质量的数据和洞察。

## 让业务用户更快获得所需答案

Oracle Applications Lab 团队协助运营 Oracle 的多项核心业务流程。他们为公司的各类对象、关系和规则构建了本体模型，让 Codex 能将用日常语言提出的业务问题转化为可靠的 SQL 查询。业务用户描述想要的结果后，Codex 会判断需要调用哪些内部系统，收集信息，并返回分析、报表或应用程序。

这改变了以往的工作方式。Lam 表示，一位用户向工具提出问题后找到了他。通常，她需要花上几个小时才能得出这个问题的答案。她告诉 Lam：“用了新工具，我提交请求后，几乎立刻就得到了回复。”她按以往的人工流程核对结果后，发现数据完全一致。

在生产工程领域，站点可靠性工程师使用 Codex 收集故障的相关背景信息，并自动调出适用的处置手册。站点可靠性工程师因此能将更多时间用于指导决策，而不是查找信息。“过去需要一个小时才能解决的普通简单故障，现在几分钟就能处理好，”Lam 表示。

即使 Codex 承担了更多工作，Lam 仍特别强调，这一切并非无需人工干预就能自行运转。仍然需要有人确保底层系统构建得当。

> “如今，业务用户只需描述想要的结果，不必再四处查找报表。这是一个重大转变。我甚至会称之为一场业务变革。”

—Richard Lam，Oracle Applications Lab 集团副总裁

## 管理者的经验之谈

虽然工具由 AI 构建，但人仍需对产出负责。以下几点经验尤为重要：

- **设定恰当的约束。**“你仍然必须以高度负责的态度对待系统设计、架构、安全，以及你希望 Codex 如何组织代码，”Lam 表示。
- **用原型代替规格文档。**“通常，我会把[我的想法]写在纸上，但现在，我会把它做成原型，”副总裁兼首席信息官技术顾问 Barry Shilmover 表示。
- **对代码负责。**“如果你不与 Codex 并肩协作，最终就会得到大量无法维护的代码，”Lam 表示。

## 下一步

Oracle 团队正借助 AI 彻底改变公司的运营方式。从招聘、分析到工程，各业务条线只需描述期望的结果，再由 Codex 和 ChatGPT 解决具体如何完成工作的问题。Oracle 已有数以千计的 ChatGPT 和 Codex 用户，员工们将 AI 用于各种各样的工作任务。正如 Shilmover 所说：“我不知道答案是什么，因为我还不知道接下来要解决的问题是什么。我只知道，我首先会做的事情之一，就是借助 Codex 来解决它。”
