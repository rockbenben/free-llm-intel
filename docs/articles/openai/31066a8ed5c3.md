# GPT‑2：1.5B 发布

作为 [GPT‑2⁠](https://openai.com/index/better-language-models/) [分阶段发布⁠](https://openai.com/index/gpt-2-6-month-follow-up/) 的最后一个模型发布，我们放出 GPT‑2 的最大版本（15 亿参数），并同时发布[代码与模型权重⁠（在新窗口中打开）](https://github.com/openai/gpt-2-output-dataset)，以促进对 GPT‑2 模型输出的检测。虽然自 8 月以来已有更大的语言模型发布，我们仍按最初的分阶段发布计划推进，以便为社区提供一个完整分阶段发布流程的试验案例。我们希望这一案例对未来强大模型的开发者有所助益，并正与 AI 社区就负责任发布持续积极对话。

## 我们的发现

**1. 人类觉得 GPT‑2 的输出可信。**我们在康奈尔大学的合作伙伴调查了人们按模型规模给 GPT‑2 文本打"可信度分"的情况。人们给 1.5B 模型打了 10 分制中的 6.91 分，略高于 774M 模型的输出（6.72），显著高于中等规模 355M 模型（6.07）。这些结果让我们更倾向于发布 1.5B 模型，因为相对 774M，人所感知到的可信度增量似乎很低。

**2. GPT‑2 可被微调用于滥用。**我们在米德尔伯里亚国际研究学院恐怖主义、极端主义与反恐研究中心（CTEC）的合作伙伴发现，极端主义团体可以将 GPT‑2 用于滥用，具体是在四种意识形态立场——白人至上主义、马克思主义、圣战伊斯兰主义和无政府主义——上微调 GPT‑2 模型。CTEC 证明了可以创建能为这些意识形态生成合成宣传内容的模型。他们还表明，尽管对合成输出的检测准确率不高，基于机器学习的检测方法仍能让专家有合理理由怀疑某个行为者在生成合成文本。

**3. 检测颇具挑战。**我们预计，基于内容的合成文本检测是一个长期挑战。为检验机器学习方法今天能否派上用场，我们内部开展了检测研究，开发了一个[检测模型⁠（在新窗口中打开）](https://github.com/openai/gpt-2-output-dataset)，对 1.5B GPT‑2 生成文本的检测率约为 95%。[A](https://openai.com/index/gpt-2-1-5b-release/#citation-bottom-A) 我们认为这一准确率不足以独立承担检测任务，需要与基于元数据的方法、人类判断和公众教育相结合才能更有效。我们发布这个模型以推动合成文本检测研究，尽管这确实会让接触它的对手更有能力规避检测。

我们发现检测准确率高度依赖于训练和测试中所用的采样方法；同时也发现，跨多种采样技术训练能让检测更可靠。如下图所示，我们观察到更大模型的输出更难分类，但在更大模型输出上训练能让检测结果更准确、更鲁棒。我们预计这一趋势会持续：随着模型规模增大，检测将更具挑战性。

**4. 目前尚未见到滥用的强证据。**虽然我们看到一些关于 GPT‑2 可能增强垃圾邮件、钓鱼这类"高数量/低收益"操作的讨论，但尚未见到编写代码、文档的实例或滥用案例。我们认为，合成文本生成器的输出越可靠、越连贯，被滥用的可能性就越高。我们也承认，我们无法知晓所有威胁，有动机的行为者即使没有模型发布也能复刻语言模型。

**5. 我们需要研究偏见的标准。**语言模型存在偏见。弄清楚如何研究、讨论并解决这些偏见，是整个 AI 研究社区面临的挑战。我们从两个路径应对偏见问题：

- 在 GitHub 上随模型发布 [model card（模型说明卡）⁠（在新窗口中打开）](https://github.com/openai/gpt-2/blob/master/model_card.md)[B](https://openai.com/index/gpt-2-1-5b-release/#citation-bottom-B)，让人们了解 GPT‑2 这类语言模型固有的问题。
- 对 GPT‑2 中的部分偏见进行定性的内部评估：我们探测了 GPT‑2 在性别、种族和宗教方面的一些偏见，并据这些发现完善 model card。这些探测并不全面，也凸显了在偏见分析框架上开展协作的必要性。

## 后续步骤

过去 9 个月 GPT‑2 的经历，让我们对在 AI 领域建立负责任发布规范所面临的挑战与机遇获得了宝贵洞见。我们正通过参与 "AI 合作伙伴关系"组织（Partnership on AI）的 "机器学习负责任发布规范"项目、以及与研究社区同行的讨论，继续推进这一议题。
