# 全新改进的嵌入模型

Read documentation




新模型 `text-embedding-ada-002` 取代了文本搜索、文本相似度和代码搜索所用的五个独立模型，在多数任务上都胜过我们此前最强的模型 Davinci，同时价格低了 99.8%。

嵌入（embeddings）是把概念转换成的数字序列形式的数值化表示，让计算机能够更容易理解概念之间的关系。自从 OpenAI [/embeddings](https://beta.openai.com/docs/api-reference/embeddings) 接口 [首次上线⁠](https://openai.com/index/introducing-text-and-code-embeddings/) 以来，许多应用都借助嵌入来实现内容个性化、推荐与搜索。


你可以像之前那样，仅用两行代码通过我们的 [OpenAI Python 库](https://github.com/openai/openai-python) 查询 [/embeddings](https://beta.openai.com/docs/api-reference/embeddings) 接口来使用新模型：

```
import openai
response = openai.Embedding.create(
  input="porcine pals say",
  model="text-embedding-ada-002"
)
```

## 模型改进

**性能更强**。`text-embedding-ada-002` 在文本搜索、代码搜索和句子相似度任务上全面超越所有旧版嵌入模型，在文本分类上表现也与之相当。每一类任务我们都使用 [旧版嵌入研究](https://arxiv.org/abs/2201.10005) 所用的数据集进行评估。

**能力统一**。我们合并了上文展示的五个独立模型（`text-similarity`、`text-search-query`、`text-search-doc`、`code-search-text` 与 `code-search-code`）为单一新模型，从而显著简化了 [/embeddings](https://beta.openai.com/docs/api-reference/embeddings) 接口的使用方式。这一单一表示在多样化的文本搜索、句子相似度和代码搜索基准上表现优于我们之前的所有嵌入模型。

**更长的上下文**。新模型的上下文长度提升 4 倍，从 2048 增至 8192，处理长文档时更方便。

**更小的嵌入维度**。新嵌入仅 1536 维，是 `davinci-001` 嵌入的 1/8，在使用向量数据库时性价比更高。

**更低的价格**。与相同规模的旧模型相比，新嵌入模型价格降低 90%。新模型的性能达到或超过旧的 Davinci 模型，价格却低 99.8%。

总体而言，新的嵌入模型是自然语言处理和代码任务中更为强大的工具。我们非常期待看到我们的客户用它如何在各自领域打造出能力更强的应用。

## 局限

新版 `text-embedding-ada-002` 模型在 SentEval 线性探测分类基准上尚未超过 `text-similarity-davinci-001`。对于需要在嵌入向量之上训练一个轻量线性层来做分类预测的任务，我们建议把新模型与 `text-similarity-davinci-001` 对比一下，选择表现更优者。

有关我们嵌入模型一般性局限的说明，请查看嵌入文档中的 [Limitations & Risks](https://beta.openai.com/docs/guides/embeddings/limitations-risks) 章节。

## 嵌入 API 的实际应用示例

[**Kalendar AI**](https://kalendar.ai/) 是一款销售触达产品，借助嵌入在包含 3.4 亿份资料的资料库中，把合适的销售话术匹配到合适的客户。这一自动化机制依赖客户资料嵌入与销售话术嵌入之间的相似度来排序出最合适的匹配，相比旧方法消除了 40–56% 的无效触达。

在线工作空间公司 [**Notion**](https://www.notion.so/) 将使用 OpenAI 的新嵌入来提升 Notion 搜索，超越当前的关键词匹配系统。
