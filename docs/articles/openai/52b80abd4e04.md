# Harvey 借助 GPT‑6 Astra，将法律背景资料转化为更优质的文稿

GPT‑6 Astra 生成结构更清晰、更贴合上下文的法律文书，让律师腾出时间专注于策略。

开始开发










Harvey 帮助律师事务所和企业内部法务团队，在涵盖诉讼、并购等业务的复杂法律工作流程中安全部署 AI。客户使用 Harvey，将海量信息转化为复杂的法律文书。借助 GPT‑6 Astra，Harvey 能够在起草过程中纳入更多上下文，并生成更多结构化输出。

> “我们可以为模型提供更多上下文，生成质量越来越高的结构化输出。”

—Gabe Pereyra，Harvey 联合创始人兼总裁

## 生成内容更完整、格式更规范的文书

Harvey 使用 GPT‑6 Astra，帮助律师分析、整合与具体法律事务相关的信息，并据此起草文书。这些信息包括法院信息、律师事务所文件、判例研究及其他法律背景资料。

Harvey 发现，与其他模型相比，GPT‑6 Astra 在文书格式和上下文理解方面有显著提升，帮助客户获得内容更完整、更贴合依据材料的文书。

## 将律师的偏好融入起草过程

Harvey 的记忆面板将个人偏好直接融入文书起草流程。律师可以设置偏好，例如使用编号列表、优先采用 EDGAR 作为信息来源，或根据优先级用不同颜色标记问题。

这些偏好与原始资料、备忘录草稿并列显示，让律师能更清晰地引导输出。由于 GPT‑6 Astra 能够处理更多上下文，Harvey 可以生成质量更高的法律文书，让客户将更多时间用于制定策略。
