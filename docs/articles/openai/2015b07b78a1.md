# ChatGPT 现已成为你攻坚克难的得力伙伴

ChatGPT Work 是一款智能体，它能够跨越你的应用与文件执行操作，在需要时花费数小时持续跟进项目，并将你的目标切实转化为最终成果

我们正式推出 ChatGPT Work — ChatGPT 内置的一款智能体，旨在协助你应对更具挑战性的任务。它能够跨越你的应用与工作流收集信息，生成电子表格、演示文稿、文档及 Web 应用等最终交付物。面对复杂的项目，它能将其拆解为更小的步骤并独立完成，即使需要耗费数小时也能持续跟进。

凭借内置的 Codex 技术，ChatGPT 如今已不再局限于回答问题，而是能够跨越网页端、移动端与桌面端协助你完成实际工作。每周有超 500 万人使用 Codex。尽管它最初是为开发者打造的编程智能体，但现在已有超 100 万人将其用于软件开发之外的工作，这表明它的能力完全可以支持更广泛的任务。

为了更好地管理这些任务，ChatGPT Work 搭载了我们最新的前沿模型 GPT‑5.6，[该模型也于今日同步推出⁠](https://openai.com/zh-Hans-CN/index/gpt-5-6/)。GPT‑5.6 使 ChatGPT 在执行多步骤任务推理，以及生成符合你的模板和参考文件的资料时，达到了行业前沿水平。

学习使用 ChatGPT Work 最好的方法，就是交给它一项你已经非常熟悉的任务：分析月末预算差异、将源材料转化为营销活动简报，或是准备一场销售会议。你可以随时跟进它的进度、回答它的提问、调整执行方向，并对关键操作进行审批。

你甚至可以通过一条简单的请求，让 ChatGPT Work 接管整个工作流。例如，它可以将客户调研转化为营销活动简报，利用该简报生成营销素材，并对这些素材进行调整以适应不同的市场，同时确保在每一个步骤中都贯穿相应的背景信息。

即便你未携带电脑或手机，ChatGPT Work 也能通过定时任务 (Scheduled Tasks) 保持项目的顺利推进。例如，它可以独立地将来自 Microsoft Teams 和 Slack 的新消息更新到文档或演示文稿中，然后与你的团队分享重要的修改内容。

## 随时随地开展工作，在桌面端获得更强体验。

ChatGPT Work 旨在让你无论身处何处，都能保持任务的顺利推进。你可以用手机要求它开启一项任务，在途中审查草案，或在会议间隙查看长周期工作流的进度。当你回到办公桌前，你可以在网页端继续推进同一项工作。

为了带来更强大的体验，全新的 ChatGPT 桌面端应用现在提供更多功能。在桌面端，ChatGPT 可以调用你的本地文件与应用来完成任务。针对基于网页的工作，ChatGPT 全新的内置浏览器能将网站、工具与在线文件汇集于一处，让你在同一个界面下持续推进工作。

即日起，Codex 应用将与全新的 ChatGPT 桌面端应用合并。Codex 依然是面向开发者与技术专业人员的那款强大的编程智能体，并且[现已带来全新功能](https://learn.chatgpt.com/docs/whats-new#take-on-ambitious-work-with-chatgpt-work)，覆盖核心工作流，包括代码差异 (diffs) 内的内联编辑 (inline editing)、侧边栏中的 PR 审查、更快的计算机使用 (由 GPT‑5.6 驱动)，以及在单一项目中支持多个代码仓库。

## 直接从你的应用与工作流中生成演示文稿、电子表格、文档及站点

要开始使用 ChatGPT Work，请使用插件连接你日常工作所在的工具与背景信息。

插件能够将 ChatGPT 与各类应用及系统连接起来，如 Slack 与 Microsoft Teams、Google Drive 与 SharePoint、电子邮件、日历、CRM、项目进度追踪工具以及其他内部工具。ChatGPT 会根据你的提示词自动判断何时应调用某个插件，但你也可以在提示词中输入“@”加上应用名称，直接指示 ChatGPT 从特定应用中提取信息。全新的统一插件目录将各类插件汇集于一处，ChatGPT 还会在对话过程中为你推荐相关的插件。

连接好应用与工具后，ChatGPT 便能理解你要完成的目标，从相关数据源中提取信息，生成文档、演示文稿及分析报告；同时，它能在后台持续打磨草案，让你始终把控全局。

我们同时也在公开测试阶段推出了 ChatGPT 中的站点 (Sites) 功能。借助站点，你可以将工作成果或创意转化为交互式站点或 Web 应用，并通过 URL 与团队或公众分享。当你想创建实时数据面板、项目进度追踪表、发布日程表、原型、内部门户及交互式报告时，站点能够派上用场。你可以直接在 ChatGPT 中测试构建的站点，并为你的项目引入最新的网页信息。随着底层信息的变动，ChatGPT 还能对它们进行自动更新。

## 将重复性任务交由 AI 处理，专注于更具价值的工作

ChatGPT Work 能够帮你分担重复性任务，让你腾出精力去处理更具影响力的工作。

定时任务 (Scheduled Tasks) 允许你让 ChatGPT 执行一次操作，或按既定计划及特定事件重复执行，亦或持续监控随时间发生的变化。

定时任务可以利用已连接的应用与浏览器，以完成以下工作：

- 每周审查 Slack 中的新动态，并更新周期性会议议程。
- 每天早上检查网站与数据面板，总结发生的变化，并发送分析报告。
- 监控新的客户反馈，将反复出现的问题转化为具有优先级的产品创意。
- 当收到包含新反馈的电子邮件时，自动更新演示文稿。

你依然可以完全掌控 ChatGPT 与你协作的方式。由你来决定它可以访问哪些内容，何时向你确认进度，以及在执行操作前何时需要你的审批。随着优先事项的变化，你可以随时审查进度并调整工作方向。

## 在网页及桌面端应用中更高效地完成工作

在桌面端，ChatGPT 现已包含一个内置浏览器，帮助你在同一个界面下从网络搜集信息、使用基于网页的工具，并完善基于网页的工作。

你可以要求 ChatGPT 研究特定市场、比对信息来源、从网站抓取信息，或在应用内直接打开并完善来自 Google Workspace 与 Microsoft 365 的文件。它能利用浏览器引入最新的背景信息、在网页上执行步骤，并在你审查与指导结果时保持工作的顺利推进。

在桌面端，计算机使用 (Computer Use) 功能让 ChatGPT 能够代表你使用计算机，在后台跨应用、工具与浏览器执行任务 — 包括点击、打字，以及将文件移动到指定位置。你可以将其用于一次性任务，也可以在周期性工作涉及计算机操作时，将其作为定时任务的一部分。

我们同时也在更新 Chrome 扩展程序，以便你能够在 Chrome 的侧边栏中直接使用 ChatGPT。这些功能基于我们从 Atlas 和用户研究中积累的经验，从而更好地理解智能体工具在提升网页工作实用性方面的作用。我们将开始逐步下线独立的 Atlas 浏览器，并会与用户分享如何平滑过渡到 ChatGPT 的相关信息。

## 面向组织的安全与治理

即使 ChatGPT 为你的团队承担了更多实质性工作，你的组织依然能保持全面掌控。ChatGPT 建立在 ChatGPT Enterprise 的安全性、隐私保护、合规性及工作区管理[基础](https://openai.com/business-data/)之上。Enterprise 与 Edu 的管理员可以集中管理访问权限、ChatGPT 可调用的公司业务信息、可连接的工具，以及它能执行的操作。[合规 API](https://help.openai.com/en/articles/9261474-openai-compliance-platform-for-enterprise-customers) 能够规模化提供对 ChatGPT Work 对话与操作的可见性，以支持企业监管要求。

控制功能会根据不同的环境量身定制。在网页端，管理员可以管理对插件及已连接工具的访问，为云环境配置浏览器使用与网络访问权限，并限制在已连接系统中的敏感操作。在桌面端，ChatGPT Work 基于 Codex 的[企业治理模型](https://developers.openai.com/codex/enterprise/governance)和[管理员控制功能](https://developers.openai.com/codex/enterprise/admin-setup)，为涉及本地文件、应用、浏览器及工具的工作引入了企业级防护措施 — 这其中也包括管理智能体网络访问的策略。

自动审核 (Auto-review) 功能利用我们先进的模型，在涉及已连接工具及 API 的关键操作发生前进行审查，从而增加了一层额外的保护，有助于防止未经授权分享敏感信息。

## 可用性与定价

ChatGPT Work 于今日起在网页端与移动端陆续推出，率先面向 Pro、Enterprise 与 Edu 用户开放，并将在未来几天内扩展至 Plus 与 Business 用户。[更新后的 ChatGPT 桌面端应用](https://chatgpt.com/download/)于今日起面向全球的 Mac 和 Windows 用户开放，Chat、Work 及 Codex 功能为所有套餐（包括免费套餐）的用户提供。

如果你已经在用 Codex 应用，只需像往常一样更新，它便会升级为全新的 ChatGPT 桌面端应用。开发者可以在打开桌面端应用时，将 Codex 设为默认视图，并选择 Codex 的徽标作为应用图标。桌面端的 Codex 项目依然可以通过 ChatGPT 移动应用在移动设备上随时访问。现有的 ChatGPT 桌面端应用将更名为 ChatGPT Classic。

ChatGPT Work 专为处理耗时更长、复杂度更高的工作而设计，而非简单的聊天请求，因此它的使用方式有所不同。用量会根据所需工作量的大小而变化，更复杂的任务可能会消耗你套餐内更多的包含额度。ChatGPT Work 遵循[与 Codex 相同的使用结构](https://help.openai.com/articles/20001275)。

随着该功能的广泛采用，ChatGPT Enterprise 和 Edu 管理员还可以在[管理控制台](https://help.openai.com/articles/20001001)中设置[支出控制](https://admin.openai.com)，以管理 ChatGPT Work 的使用情况。为了支持各团队的高影响力工作，管理员无需进行普遍提额，而是可以通过设置工作空间级别的默认值、配置群组限制、为需要更多额度的个人创建独立例外规则，并审核附带用户提交项目详情与理由的加额申请，来实现精准管控。
