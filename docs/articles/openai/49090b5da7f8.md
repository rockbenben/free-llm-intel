# 通过在精选数据集上训练改善语言模型行为

我们最新的研究发现，通过在一个小型精选数据集上微调，可以改善语言模型在特定行为价值观方面的表现。

阅读论文

我们发现，通过在不到 100 个示例的精选价值观数据集上微调，可以改善语言模型在特定行为价值观方面的表现。我们还发现，随着模型变大，这一过程会更加有效。尽管该技术仍处于早期，我们正在寻找愿意试用它的 OpenAI API 用户，并乐于见到大家把这些及其他技术用于生产场景的方法。

语言模型几乎可以输出任何类型的文本、任何语气或个性，取决于用户的输入。我们的方法旨在让语言模型的运营者拥有工具，把这个无所不包的行为集合收窄为一组受约束的价值观。OpenAI 提供护栏和监控以确保模型用例符合我们的[章程⁠](https://openai.com/charter/)，但我们认为，为模型选择哪一套符合章程的具体价值观，是我们的用户必须针对自己的具体应用做出的选择。

我们的定性探测显示，价值观定向模型在更大程度上遵守期望行为：[A](https://openai.com/index/improving-language-model-behavior/#citation-bottom-A)

恰当或理想的语言模型行为，与恰当的人类行为一样，无法归结为单一普适标准；理想行为因应用和社会语境而异。我们开发了一套通过打造价值观定向数据集来改善特定社会语境下行为的过程。我们的分析显示，行为上有统计显著的改善，同时不损害下游任务表现。它还表明我们的过程在更大的模型上更有效，意味着人们将能用相对更少的样本把大语言模型的行为调整到自己的价值观。由于为庞大人群界定价值观有边缘化少数声音的风险，我们力求让这一过程与从头重训相比具有较好的可扩展性。

## 我们的过程

我们是在为一家 API 客户实现“尊重”这一用例的过程中发展出这套方法的。步骤如下：

### 第一步：敏感话题类别与期望行为的界定

我们挑选了我们认为直接影响人类福祉的类别，并主要依据美国和国际人权法、以及追求人类平等的西方社会运动（例如美国民权运动）来描述每个类别中的期望行为。

- *虐待、暴力与威胁（包括自残）*：反对暴力或威胁；鼓励向相关当局求助。
- *身体健康与心理健康*：不诊断疾病或开处方；反对将非传统医药作为医疗科学替代手段。
- *人类特征与行为*：反对不健康的审美或讨喜标准；支持“好”与“讨人喜欢”是主观的。
- *不公正与不平等（包括针对社会群体的歧视）*：反对人类的不公正与不平等，或加剧二者的行为，包括有害的刻板印象与偏见，尤其是依据国际法针对特定社会群体的。
- *政治观点与 destabilization（颠覆）*：除非侵犯人权或法律，否则保持无党派立场；反对破坏民主进程的干预。
- *关系（恋爱、家庭、朋友等）*：反对未经同意的行为或背信行为；支持经双方同意的标准，其具体内容因文化语境和个人需求而异。
- *性活动（包括色情）*：反对非法及非自愿的性活动。
- *恐怖主义（包括白人至上主义）*：反对恐怖活动或对恐怖主义的威胁。

请注意，我们选择的类别并不穷尽。虽然在评估中我们对每个类别赋予同等权重，但优先次序取决于语境。

### 第二步：制作数据集与微调

我们制作了包含 80 个文本样本的价值观定向数据集；每个样本为问答格式，长度在 40 到 340 词之间。（就数量级而言，我们的数据集约 120KB，约为 GPT-3 训练数据的 0.000000211%。[B](https://openai.com/index/improving-language-model-behavior/#citation-bottom-B)

从零训练一个大型语言模型需要海量数据。例如，GPT-3 在 570GB 数据上训练。参见 [[Brown, Mann, Ryder, Subbiah et al](https://arxiv.org/abs/2005.14165)]。）

随后我们使用标准微调工具，在该数据集上对 GPT-3 模型（1.25 亿到 1,750 亿参数）进行微调。

### 第三步：模型评估

我们使用定量与定性指标[C](https://openai.com/index/improving-language-model-behavior/#citation-bottom-C)：由人类评估对预定价值观的遵守程度；毒性评分[D](https://openai.com/index/improving-language-model-behavior/#citation-bottom-D)

毒性评分无法捕捉毒性的所有细微之处，且本身带有偏见：[[Dixon et al](https://dl.acm.org/doi/pdf/10.1145/3278721.3278729)] 描述了人口统计偏见——毒性评分会把身份词误报为阳性；[[Sap et al](https://www.aclweb.org/anthology/P19-1163/)] 描述了种族偏见——评分更容易把非裔美国人英语判为有毒。这正是我们开展更多评估的原因。

——通过 Perspective API 打分；并使用共现指标考察性别、种族和宗教。我们根据评估结果按需更新价值观定向数据集。我们评估了三组模型：

- *基础 GPT-3 模型*[E](https://openai.com/index/improving-language-model-behavior/#citation-bottom-E)
- *价值观定向 GPT-3 模型*：如上所述在我们的价值观定向数据集上微调
- *对照 GPT-3 模型*：在规模与写作风格相近的数据集上微调

每个提示取 3 个样本，每类别 5 个提示，共 40 个提示（每种模型规模 120 个样本），并由 3 位不同的人工评估者给每个样本打分。评分从 1 到 5，5 表示文本最符合指定的情感立场。

人工评估显示，*价值观定向模型*的输出最贴合指定行为，且有效性随模型规模增大而提高。

## 展望

我们惊讶于在如此小的数据集上微调竟如此有效。但我们相信这只是冰山一角，仍有重要问题悬而未决：

- 设计价值观定向数据集时应咨询谁？
- 当用户收到的输出与其自身价值观不符时，谁该负责？
- 这项研究如何推广到非英语语言，以及语言之外的生成模型（图像、视频、音频）？
- 这一方法对真实世界提示分布的稳健性如何？[F](https://openai.com/index/improving-language-model-behavior/#citation-bottom-F)
- 我们的研究试验的是问答格式。

在社会中运行的语言模型和 AI 系统必须适应其所处的社会，而在此过程中听取广泛多元的声音至关重要。我们认为，最终的成功需要 AI 研究人员、社区代表、政策制定者、社会科学家等共同参与，弄清我们希望这些系统在世界上如何行事。
