# 万里挑一：致敬定义 AI 未来的客户

全球已有超过 100 万客户利用 OpenAI 支持团队，并开拓新的机遇。以下是其激励我们的几种方式。

正在加载…

没有两个客户会以完全相同的方式使用 AI。

今年，我们见证了用户逐步从尝试 AI 技术转向利用 AI 改变工作方式。

他们在其组织中推广 ChatGPT，以协助写作、编码、研究、数据分析、设计，以及每天数以百计的小任务。他们构建代理，用于自动执行曾经耗时数小时的工作流。开发人员借助 Codex 提高工作效率并解决更复杂的问题。各大企业基于我们的 API 开发全新的产品，涉及语音、视频、图片和其他模态。

当我们询问客户 AI 为其带来哪些价值时，75% 的人告诉我们，他们正在完成以前力所难及的任务。

我们很高兴每天都能与这些团队共同合作，并向其学习。以下是我们的客户如何利用 OpenAI 实现更多可能，助其成长为有史以来增速最快的业务平台的部分方式。
