# 用全新多模态审核模型升级 Moderation API

我们推出一个基于 GPT-4o 的新模型，能更准确地检测有害文本和图像，帮助开发者构建更健壮的审核系统。

今天，我们在 [Moderation API](https://platform.openai.com/docs/guides/moderation) 中推出新的审核模型 `omni-moderation-latest`。该模型基于 [GPT-4o⁠](https://openai.com/index/gpt-4o-and-more-tools-to-chatgpt-free/)，同时支持文本和图像输入，比旧模型更准确，在非英语语言上尤其如此。与上一版本一样，该模型使用 OpenAI 的 GPT 分类器，在仇恨、暴力、自残等类别中评估内容是否应被标记；同时新增了对更多伤害类别的检测能力。此外，它通过校准概率分数来反映内容命中被检测类别的可能性，从而对审核决策提供更精细的控制。新审核模型对所有开发者通过 Moderation API 免费使用。

自 2022 年我们首次[发布⁠](https://openai.com/index/new-and-improved-content-moderation-tooling/) Moderation API 以来，自动审核系统需要处理的内容量与多样性都在增长——尤其是越来越多 AI 应用在生产环境中达到巨大规模。我们希望今天的升级能帮助更多开发者受益于我们安全系统中的最新研究与投入。

各行各业的公司——从社交媒体平台、效率工具到生成式 AI 平台——都在使用 Moderation API 为用户打造更安全的产品。例如，Grammarly 将 Moderation API 作为其 AI 沟通辅助产品安全护栏的一部分，确保产品输出安全且公平。同样，ElevenLabs 把 Moderation API 与自研方案结合，扫描其音频 AI 产品生成的内容，防止并标记违反其政策的输出。

更新后的审核模型带来多项重大改进：

- **覆盖六大类别的多模态伤害分类**：新模型可以评估一张图像（单独或与文本结合）含有害内容的可能性。当前支持的类别包括：暴力（`violence` 和 `violence/graphic`）、自残（`self-harm`、`self-harm/intent` 和 `self-harm/instruction`）以及性相关内容（`sexual`，但不含 `sexual/minors`）。其余类别目前仅支持文本，我们正在努力未来把多模态支持扩展到更多类别。
- **两个新增的纯文本伤害类别**：与旧模型相比，新模型还能检测两个额外类别的伤害：`illicit`，覆盖关于如何实施不当行为的指示或建议（例如“如何行窃”这类短语）；以及 `illicit/violent`，覆盖涉及暴力的不当行为的同类内容。
- **更准确的分数，尤其是非英语内容**：在涵盖 40 种语言的测试中，与旧模型相比，新模型在我们的内部多语言评估上提升 42%，在 98% 的受测语言上均有提升。对高棉语（Khmer）或斯瓦蒂语（Swati）等低资源语言，提升达 70%；我们看到最大提升的语言是泰卢固语（6.4 倍）、孟加拉语（5.6 倍）和马拉地语（4.6 倍）。旧模型对非英语语言支持有限，而新模型在西班牙语、德语、意大利语、波兰语、越南语、葡萄牙语、法语、中文、印度尼西亚语上的表现，甚至都超过旧模型的英语表现。

- **校准后的分数**：新模型的分数现在更准确地代表内容违反相关政策的可能性，并且在未来的各审核模型之间将显著更加一致。

AI 内容审核系统帮助执行平台政策、减轻人工审核员的工作负担，对维系数字平台的健康至关重要。正因如此，与我们的[旧模型⁠](https://openai.com/index/new-and-improved-content-moderation-tooling/)一样，新审核模型通过 Moderation API 向所有开发者免费开放，速率限制视使用层级而定。上手请见我们的 [Moderation API 指南](https://platform.openai.com/docs/guides/moderation)。
