# 用数千个 AI agent 从生物数据里挖出新研究线索

OpenAI、PerturbAI 与 Scripps Research 如何用分布式 AI agent，帮科学家从上百万个脑细胞的数据里识别有前景的研究线索

[阅读论文](https://www.biorxiv.org/content/10.64898/2026.10.15.759436v1)

*来看 OpenAI、PerturbAI 与 Scripps Research 如何并行部署数千个 AI agent，在来自上百万脑细胞的复杂数据里找出有前景的生物学关联。*

*⁠*

*视频来源：PerturbAI。*

如果科学家能在几分钟而不是几个月里发现关于阿尔茨海默病和帕金森病的新线索，会怎样？OpenAI、[PerturbAI](http://perturb.ai) 与 [Scripps Research](http://scripps.edu) 联手，用[由 GPT‑Rosalind 驱动的数千个 AI agent](https://www.biorxiv.org/content/10.64898/2026.10.15.759436v1)，只花 32 分钟就分析并解读了来自[数百万小鼠脑细胞](https://huggingface.co/datasets/perturbai/wholebrain_crispr_atlas)的既有实验数据。这些 agent 把基因扰动带来的效应与科学文献里的发现连了起来，找出一些出人意料、能帮助科学家理解疾病并确定新疗法研究方向的生物学关联。这项工作展示了 AI 如何帮研究者去挖掘更多大规模生物实验所揭示的内容。

现代实验产生的数据，远多于科学家能彻底研究的量。研究者如今能改动数千个基因，并测量它们的效应在数百万个细胞上的表现。但要弄清这些结果对人类疾病意味着什么，就得把复杂的实验发现与几十年来散落的科学知识连到一起。这正是 AI 能帮科学家找出那些本来会被错过的有前景线索的地方。

> “我们构建细胞图谱，是为了让其他科学家能做出我们还想象不到的发现。AI 可以帮助更多研究者探索这些资源，把意外的观察变成待检验的新问题。”

—Sarah Teichmann 博士，剑桥大学干细胞医学讲席教授、Human Cell Atlas 创始联席主席

团队把分析分给数千个由 GPT‑Rosalind 驱动的 AI agent，我们把这种做法称为分布式生物学推理。这些 agent 检视了一份[全脑 CRISPR 图谱](https://www.biorxiv.org/content/10.64898/2026.03.16.711480v1)，那是一份展示基因扰动如何影响小鼠脑中不同类型细胞的数据集。每个 agent 调查一处基因扰动、分析细胞反应、检索科学文献，并对结果提出解释。它们的报告被汇总成一份推理图谱，把基因、细胞效应、相关论文和可能的生物学机制连在一起。

研究团队估计，如果人工做同等规模的分析与文献调研，一处扰动一处扰动地过，要花上几个月至一年。这些 agent 复现了人工分析得出的发现，同时挖出了额外的线索。它们对新颖性和科学价值的评估，也与盲评的人类专家判断相一致。这些发现有助于给验证上述生物学机制所需的后续实验排出优先级。

其中一些洞见指向理解脑部疾病的新线索。这些 agent 发现两个与疾病相关的基因影响脑细胞的方式存在出人意料的差异，还发现胆固醇调控与神经退行性变之间可能存在关联。这些发现可以帮助科学家研究疾病如何发展，以及未来的疗法可以在哪里介入。

> “有时候线索本来就在那里，散落在不同领域——我们只是还没把它们连起来。神经元功能与胆固醇代谢之间可能的联系说明，这些碎片一旦被凑到一起，就能给我们一种思考疾病生物学的新方式。”

—Tomasz Nowakowski 博士，UCSF 神经外科副教授

研究者今天就可以开始探索这些发现。这份推理图谱已经[公开可用](https://github.com/jinlabneurogenomics/distributed_agent)，科学家可以借此比较相关基因、追查出人意料的反应，并找出值得追下去的有前景线索。新发现常常出现在不同领域的研究者把各自专长凑到一起、用出人意料的方式把熟悉的想法连起来的时候。AI 能把新数据与散落在各学科的知识连起来，从而显著放大这类连接。机会不止是更快分析数据。把 AI 与实验生物学、人类专长和科学文献结合起来，我们就能帮科学家把他们更多的数据变成可检验的想法。

## 大规模实验，出人意料的线索

一项实验最有意思的线索，有时在科学家本来要探究的那个故事之外。而在一个覆盖数千处扰动的数据集里，这类线索很容易错过。

这些 agent 发现了 Tsc1 与 Tsc2 之间一处出人意料的差异——这两个基因协同控制 mTOR，而 mTOR 是细胞生长、代谢与衰老的一个关键调控因子。扰动其中任一基因，在几组神经元上都有相似的效应。但在负责协调运动的小脑里，扰动 Tsc2 改变了数十个参与神经元通讯的基因的活性，而扰动 Tsc1 几乎没有带来变化。

这一差异可能与人类疾病相关。在结节性硬化症患者身上，小脑的异常与 TSC2 突变强相关。虽然降低 mTOR 活性的药物可以治疗某些脑肿瘤和癫痫发作，但与这种疾病相关的学习困难和行为困难仍然难以处理。这些 agent 锁定了一组值得调查的特定神经元和细胞变化：哪些变化可能被现有药物纠正，哪些又可能指向新的治疗思路？这就给研究者留下了一组更具体、可以拿到实验室里检验的问题。

## 把活拆开，把推理做深

如果把整个数据集交给单个 agent，它能做得和数千个并行工作的 agent 一样好吗？我们在固定模型与资源的前提下测了这件事。随着工作量增大，单个 agent 检索的文献越来越少，在最大的工作量下只引用了 11 篇参考文献，而分布式 agent 引用了 700 多篇。人类专家也更偏好分布式 agent 给出的解读。

科学家的时间有限，往往只盯数据里最强的信号。分布式 agent 能帮助审视更宽范围的反应，包括细微或出人意料的那些，并把它们与相关科学文献连起来。并行运行这些 agent 让大量扰动可以同时被调查。这帮助科学家探索一项实验所含的更多内容，找出那些本来会被错过的有前景线索。

*在最大的工作量下，分布式 agent 引用了 700 多篇参考文献，单个 agent 只有 11 篇。*

## 找到下一个值得做的实验

一项发现如果能指向一个值得做的实验，它就更有价值。这些 agent 就在 *DCTN1* 上找到了这样一条线索——这个基因的突变会导致 Perry 综合征，一种带有帕金森样症状的神经退行性疾病。

DCTN1 参与神经元内部的货物转运。在这份全脑 CRISPR 图谱里，扰动 Dctn1 提高了参与合成胆固醇的一批基因的表达。这些 agent 把这一观察与研究联系起来——那些研究提示，胆固醇转运出问题可能让细胞制造更多胆固醇。由此引出一个供后续实验检验的问题：DCTN1 被扰动后，会不会改变胆固醇在神经元内部的分布，而这些变化会不会促成神经退行性变？如果是这样，恢复正常的胆固醇分布有没有可能帮助保护神经元？

人类专家也认为这一假说新颖、有分量、值得跟进。这个例子说明，把一个意外的结果与既有知识连起来，就能把一条线索变成可检验的想法，并可能成为治疗疾病的一个新方向。

在盲评比较中，人类专家有 75% 的情况更偏好分布式 agent 的报告而非单个 agent 的报告。

发现的主角仍然是科学家。通过挖出更多有前景的线索，AI 可以帮助研究者决定该追哪些想法、设计实验并解读结果。目标是把生物实验中更多的信息转化为知识，并随着时间帮助指导更好药物的研发。
