# 收集人类反馈

RL-Teacher 是我们训练接口的开源实现，通过偶尔的人类反馈（而非手工设计的奖励函数）来训练 AI。其底层技术是迈向安全 AI 系统的一步，但也适用于奖励难以指定的强化学习问题。

本发布包含三个主要组件：

- 一个 [奖励预测器](https://github.com/nottombrown/rl-teacher/blob/master/rl_teacher/teach.py)，可插入任意智能体，学习预测该智能体可能采取的、人类会认可的动作。
- 一个 [示例智能体](https://github.com/nottombrown/rl-teacher/tree/master/agents)，通过奖励预测器指定的函数进行学习。RL-Teacher 自带三种已集成的算法，包括 [OpenAI Baselines PPO](https://blog.openai.com/openai-baselines-ppo/)。
- 一个 [Web 应用](https://github.com/nottombrown/rl-teacher/tree/master/human-feedback-api)，供人类给出反馈，为训练奖励预测器提供数据。

整个系统（不含智能体）不到 1000 行 Python 代码。配置好你的 Web 服务器后，可以通过运行以下命令启动一个实验：

#### Bash

```
1$ python rl_teacher/teach.py -p human --pretrain_labels 175 -e Reacher-v1 -n human-175
```

人类可以通过一个简单的 Web 界面（如上所示）给出反馈，该界面可以在本地运行（不推荐）或部署在另一台机器上。完整文档见项目的 [GitHub 仓库](https://github.com/nottombrown/rl-teacher)。我们很期待看到 AI 研究员和工程师用这项技术做出什么——有任何实验结果请 [联系我们⁠](mailto:jack@openai.com?Subject=RL_Teacher)！
