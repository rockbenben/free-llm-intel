# OpenAI Scholars 2018：认识我们的学者

我们首届 OpenAI Scholars 项目已经开始，你现在可以跟随这群经验丰富的软件开发者如何转型为机器学习从业者。

2019 年 Scholar Yuhao Wan。摄影：Blake Tucker


我们首届 [OpenAI Scholars⁠(opens in a new window)](http://blog.openai.com/openai-scholars/) 项目已经开始，[你⁠(opens in a new window)](http://www.christinemcleavey.com/)[可⁠(opens in a new window)](http://codedolapo.wordpress.com/openai/)[以⁠(opens in a new window)](http://www.hannahishere.com/)[跟⁠(opens in a new window)](http://www.hollygrimm.com/)[随⁠(opens in a new window)](http://www.lifeasalgorithm.com/posts)[这⁠(opens in a new window)](http://www.everyd-ai.com/blog)[一⁠(opens in a new window)](http://iconix.github.io/blog)[群⁠(opens in a new window)](https://medium.com/@sophiaarakelyan) 经验丰富的软件开发者如何转型为机器学习从业者。8 个 OpenAI Scholars 名额吸引了 700 多位申请人；我们依据一份标准化评估清单逐一审查，以最大化公平。我们希望这批学者能激励更多开发者也完成向机器学习的转型。

OpenAI Scholars 于 6 月 1 日开学，每周发表博文记录进展，最终以一个开源的期末项目收官。学者们已经写过 [基于模型的 RL⁠(opens in a new window)](http://hollygrimm.com/rl_modelbased)、[使用 softmax 做音频分类⁠(opens in a new window)](http://www.hannahishere.com/openai-scholar-week-3/)、[用简单英语讲深度学习⁠(opens in a new window)](http://everyd-ai.com/2018-06-08/deep-learning/)、[k 近邻算法⁠(opens in a new window)](https://lifeasalgorithm.com/posts/a-closer-look-at-the-k-nearest-neighbors-algorithm) 以及 [注意力机制⁠(opens in a new window)](https://iconix.github.io/dl/2018-07-06/not-enough-attention#understanding-attention)。

来认识一下学者们：


我们挑选 Scholar 的标准是：扎实的技术功底、有意思的个人经历、展现过的自驱力——像这样一个自我主导的项目，这些都非常重要。他们都是刚刚踏入这个领域的新人，我们希望他们的进展能展示机器学习有多容易进入。本轮 Scholars 项目结束后，我们会分享他们的期末项目，以及一份关于本项目的案例研究。

感谢 AWS 为学者们提供算力额度。
