# 为 API 客户推出更多企业级功能

我们与众多企业合作，帮助他们从零构建 AI 方案，并在其组织与产品中安全部署 AI，客户包括 [Klarna⁠](https://openai.com/customer-stories/klarna)、[摩根士丹利⁠](https://openai.com/customer-stories/morgan-stanley)、[Oscar⁠](https://openai.com/customer-stories/oscar)、[Salesforce⁠](https://openai.com/customer-stories/salesforce) 和 [Wix⁠](https://openai.com/customer-stories/wix)。我们通过新功能进一步深化对企业的支持——这些功能对大型企业和在我们平台上快速扩张的任何开发者都很有用。

## 更强的企业级安全性

我们推出了 Private Link，让客户能够确保 Azure 与 OpenAI 之间的直接通信，同时把对公开互联网的暴露降到最低。我们还上线了原生[多因素认证⁠（在新窗口中打开）](https://help.openai.com/en/articles/7967234-enabling-multi-factor-authentication-mfa-with-openai)（MFA），帮助满足日益严格的访问控制合规要求。这些是在我们现有[企业安全功能栈⁠（在新窗口中打开）](https://trust.openai.com/)基础上的新增项，后者包括 SOC 2 Type II 认证、单点登录（SSO）、静态数据 AES-256 加密与传输中 TLS 1.2 加密，以及基于角色的访问控制。我们还为需要 HIPAA 合规的医疗企业提供[业务伙伴协议⁠（在新窗口中打开）](https://help.openai.com/en/articles/8660679-how-can-i-get-a-business-associate-agreement-baa-with-openai)（BAA），并为具备合格用例的 API 客户提供零数据保留政策。

## 更好的管理控制

借助新的 [Projects⁠（在新窗口中打开）](https://help.openai.com/en/articles/9186755) 功能，组织可以对 OpenAI 内的单个项目实现更细粒度的控制与监督，包括：将角色和 API 密钥限定到特定项目、限制或指定可用的模型、设置基于用量和速率的限额，在授予访问权的同时避免意外的超支。项目所有者还可以创建服务账户 API 密钥——它不与任何个人用户绑定，即可授予项目访问权限。

## Assistants API 改进

我们对 Assistants API 做了多项更新，实现更精准的检索、对模型行为与完成任务所用工具更灵活的控制，以及更好的成本管理。这些功能包括：

- 通过 'file_search' 改进检索：每个助手（assistant）最多可摄取 10,000 个文件，相比此前 20 个的文件上限提升 500 倍。该工具更快，通过多线程搜索支持并行查询，并增强了重排序与查询改写。
- 支持流式输出，实现实时对话式响应——这是开发者和企业的头号请求之一。
- API 中新增 'vector_store' 对象：文件可以加入向量存储，并自动完成解析、切块和嵌入，为文件检索做好准备。向量存储可以在多个助手和线程之间复用，简化文件管理和计费。
- 控制每次运行（run）使用的最大 token 数，并可限制每次运行使用的前置与近期消息数量，帮助你管理 token 用量成本。
- 新增 'tool_choice' 参数：在一次特定运行中选择某个具体工具（如 'file_search'、'code_interpreter' 或 'function'）。
- API 支持微调后的 GPT‑3.5 Turbo 模型（起步阶段支持 'gpt-3.5-turbo-0125' 的微调）。

## 更多的成本管理选项

为帮助组织在不超出预算的情况下扩展 AI 用量，我们新增了两种降低稳定负载与异步负载成本的方式：

- **承诺吞吐的折扣用量：**在 GPT‑4 或 GPT‑4 Turbo 上保持稳定的每分钟 token 数（TPM）用量的客户，可以申请预置吞吐（provisioned throughput）权限，根据承诺规模获得 10%–50% 的折扣。
- **异步负载的降本：**客户可以使用新的 [Batch API⁠（在新窗口中打开）](https://platform.openai.com/docs/api-reference/batch) 异步运行非紧急负载。Batch API 请求按共享价格的五折计费，提供高得多的速率限制，并在 24 小时内返回结果。非常适合模型评估、离线分类、摘要和合成数据生成等用例。

我们计划持续新增聚焦企业级安全、管理控制和成本管理的功能。了解更多发布信息，请访问 [API 文档⁠（在新窗口中打开）](https://platform.openai.com/docs/introduction)，或[联系我们的团队⁠](https://openai.com/contact-sales)探讨贵企业的定制方案。
