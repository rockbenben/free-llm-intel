# Amp 借助 OpenAI 模型，让 AI 智能体承担编程之外的工作

了解 Amp 如何借助 GPT‑6 Astra、超高速模式、GPT‑Live‑1 和“使用 ChatGPT 登录”，不断拓展智能体的能力边界。

[开始使用 OpenAI 进行开发](https://openai.com/startups/)

公司规模: 初创企业

区域: 北美

行业: 科技

产品: API


[Amp](https://ampcode.com/) 正在打造一款前沿 AI 智能体，帮助开发者将雄心勃勃的构想变成可运行的软件。在 Amp 首席执行官 Quinn Slack 看来，模型的每一次进步，都意味着有机会拓展智能体的能力：从帮助开发者决定要构建什么，到编写代码、设计页面。

Amp 根据用户的实际使用效果来选择和推荐模型，而 OpenAI 模型占据了 Amp 中大部分的 Token 用量。Quinn 分享道：“OpenAI 非常透明，采取了哪些安全防护措施，用户都知道，也能理解。这让 OpenAI 模型用起来非常省心。你可以在 Amp 中用 OpenAI 模型完成所有工作，而且用得很满意。”

> “OpenAI 模型一直在稳步提升，我们的用户对此非常认可。”

—Quinn Slack，Amp 首席执行官兼技术团队成员

## 通过“使用 ChatGPT 登录”降低开发成本

随着开发者将更多工作交给智能体，Token 成本可能成为制约因素。Quinn 提到，一些 Amp 用户每周会消耗 100 亿个 Token。他认为，如果用户对每一点用量都精打细算，可能就无法充分探索智能体的能力。

为了缓解这一问题，Amp 集成并推出了“使用 ChatGPT 登录”功能。Quinn 表示，这让 Amp 用户可以使用更多 Token 和 OpenAI 模型，包括 GPT‑6 Astra，也让他们更愿意把大型任务交给智能体。

他说：“有了‘使用 ChatGPT 登录’，大家就能放下顾虑，不必对每一个 Token 都精打细算。”“而一旦你真正放手，给智能体更多发挥空间，就会发现它能做的事远超想象。”Quinn 表示，他看到用户让智能体制定计划、决定要构建什么，并在产品发布后继续推进工作。

## 借助 GPT‑6 Astra 进行写作、设计与创作

Amp 希望智能体能参与产品开发和增长过程中的所有工作。Amp 自己的 20 人团队就是这样使用智能体的，市场营销也不例外。Quinn 说：“我们没有专人负责这件事，但有一个专门负责的智能体。”团队依靠智能体改善新用户体验，并帮助更多人通过搜索及其他渠道发现 Amp。

要做好这些工作，高质量的文案和设计至关重要。GPT‑6 Astra 帮助团队编写文档、设计页面，达到 Amp 的严苛标准。

> “我们的设计和写作风格非常独特。我们在这方面很挑剔，但 GPT-6 Astra 的表现一直让我们很满意。”

—Quinn Slack，Amp 首席执行官兼技术团队成员

回到家中，Quinn 也在继续尝试 GPT‑6 Astra 的各种用法。他把自家的房屋图纸交给它，让它在 Blender 中创建了一个 3D 模型。随后，他和孩子们把这个模型变成了游戏：在房子里加上一条漂流河，或是满屋追逐大蒜——这个点子的灵感来自孩子们的祖母不喜欢大蒜。他说：“就在几个月前，这还是做不到的。”

## 通过 GPT‑Live‑1 与智能体对话

Amp 最近发布了内置的对话式 AI 助手 Puck，帮助用户启动和管理其他智能体。用户可以让 Puck 启动智能体来排查程序错误、协调多个智能体，或查找之前关于某个技术问题的对话。

借助由 GPT‑Live‑1 驱动的“呼叫 Puck”功能，用户可以与 Puck 实时交谈，甚至可以通过手表与它对话。Quinn 设想，人们可以借助它，在离开电脑时继续让智能体工作，即使出门跑步也不例外。

## 借助超高速模式加快智能体工作流

Amp 一直在测试 GPT‑6 Astra 的超高速模式。Quinn 表示，速度提升正在改变人们使用智能体的方式。如今，人们常常在等待智能体完成任务的间隙，切换到其他智能体任务上。响应更快，就可能让用户不必同时兼顾那么多智能体，或让智能体有更多时间在返回结果前检查自己的工作。

> “大家从未见过表现这么出色、速度又这么快的模型。”

—Quinn Slack，Amp 首席执行官兼技术团队成员

对 Amp 而言，下一步是将更多编程前后的工作交给智能体，让开发者无需事事亲力亲为，也能将构想推进得更远。“人类会创造出什么，仍是未知数，而我们都有机会共同见证。能参与其中，真的很酷。”Quinn 说。
