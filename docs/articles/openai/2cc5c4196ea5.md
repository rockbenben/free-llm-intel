# OpenAI 经济研究交流平台介绍

一项新计划，旨在支持有关 AI 经济影响的严谨外部研究。

征求提案

提交提案


***2026年8月5日更新****：当前研究团队名单请见*[*此处。*](https://openai.com/economic-research-exchange/)

AI 正在重塑人们的工作方式、企业的运营方式，以及创意的产生与传播方式。要理解这些变化，不能只靠个别事例。我们需要以现实证据为基础开展严谨的实证研究，并汇聚广泛的研究者群体共同参与。

今天，OpenAI 正式推出 OpenAI 经济研究交流平台，以支持外部研究者就 AI 的经济影响开展具有重要影响力的研究。入选研究者将通过该平台，与 OpenAI 经济研究团队开展结构化的项目合作，旨在就 AI 如何影响劳动者、企业、机构及整体经济形成可信且独立的证据。

我们正在征集探讨 AI 经济影响相关重要问题的研究项目。提案应说明，如何在审慎治理和隐私保护的前提下使用 OpenAI 工具来解答这些问题。我们希望利用 OpenAI 工具和数据集，推动严谨可信、能够突破传统数据集局限的研究。同时，还要明确保障用户隐私，并确保负责任地使用数据。

入选研究者将开展范围经过审慎界定的项目，并设立明确的里程碑、数据治理和评审流程。我们欢迎具备扎实实证研究能力，并在应用因果推断、测量、劳动经济学、生产率、企业、教育、创业、公共财政、区域经济学、发展、不平等或相关领域拥有专业知识的研究者提交提案。

该交流平台建立在 OpenAI 为改进 AI 经济影响衡量方法而开展的更广泛工作之上，其中包括 OpenAI Signals。通过支持一系列外部研究合作，我们希望扩大可供研究者、政策制定者、企业和公众使用的证据基础，帮助他们应对这一技术快速变革的时期。

提案将依据方法严谨性、可行性、与交流平台重点方向的契合度、里程碑的明确程度，以及能否为 AI 的经济影响提供可信外部证据等标准进行评估。

有关申请流程的更多信息，请[在此](https://openai.com/index/economic-research-exchange-request-for-proposals/)查看征集提案，或发送邮件至 [econresearch@openai.com⁠](mailto:econresearch@openai.com)。申请现已开放，请[在此](https://openai.com/form/economic-research-exchange/)提交，截止日期为2026年7月5日。我们将评审提交的申请，并于2026年7月31日前通知入选研究者。
