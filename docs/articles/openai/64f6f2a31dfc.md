# 投资 Merge Labs

交互方式的进步，推动着计算能力的进步。每当人们获得一种更直接表达意图的方式，技术就会变得更强大、更有用。

脑机接口（BCI）是一个重要的新前沿领域。它开启了沟通、学习以及与技术交互的全新方式。脑机接口将为所有人创造一种自然、以人为本的方式，让人与 AI 实现无缝交互。这正是 OpenAI 参与 Merge Labs 种子轮融资的原因。

Merge Labs 是一家研究实验室，其长期使命是连接生物智能与人工智能，以最大限度提升人类的能力、自主性和体验。它正在开发[全新的脑机接口路径⁠（在新窗口中打开）](https://merge.io/)，通过融合生物学、设备和 AI，打造更安全、并能以更高带宽与大脑交互的接口。

在 Merge 的技术路径中，AI 将发挥核心作用。它将加速生物工程、神经科学和设备工程等领域的研发进程。此外，高带宽接口也将受益于 AI 操作系统 — 它能够解读意图、适应个体差异，并在信号有限且噪声较大的情况下可靠运行。OpenAI 将与 Merge Labs 在科学基础模型及其他前沿工具上展开合作，以加速这一领域的进展。

我们很高兴支持并携手 Merge Labs，将这一宏大愿景变为现实，并最终打造出真正对人们有用的产品。

Merge Labs 的联合创始人包括研究人员 Mikhail Shapiro、Tyson Aflalo 和 Sumner Norman，他们在脑机接口领域开创了全新的技术路径。同时，技术创业者 Alex Blania、Sandro Herbig 以及以个人身份参与的 Sam Altman，也为团队提供了有力补充。

如果你对他们的使命感到兴奋，可以通过[此链接⁠（在新窗口中打开）](https://merge.io/careers)与他们联系。
