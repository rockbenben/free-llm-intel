# 10BedICU

10BedICU 使用 OpenAI 的 API 改善印度的重症监护基础设施。

印度在医疗可及性方面面临重大挑战：医患比例悬殊、地理障碍和经济约束。例如，印度肿瘤医生与癌症患者的比例约为 [1:2000](https://www.business-standard.com/article/current-affairs/india-has-1-8-mn-cancer-patients-but-only-one-oncologist-to-treat-every-2-000-114052401140_1.html)，与美国 1:100 形成鲜明对比。10BedICU 作为 [eGov 基金会](https://egov.org.in/) 的一项倡议成立，旨在弥合这些差距。10BedICU 的目标是提升印度的重症监护基础设施，让印度最缺乏服务的社区也能获得优质医疗。如今，10BedICU 正在使用 OpenAI 模型来应对重症监护工作流的高要求，让医生能够触达更多患者。

## 在最需要的时刻提供救治

创始人斯里坎特·纳德哈穆尼（Srikanth Nadhamuni）在 2021 年毁灭性的新冠 Delta 波期间萌生了 10BedICU 的想法——短短几个月内病例超过 2000 万。印度每 10 万人仅有 2.3 张 ICU 病床，医疗基础设施迅速被压垮。10BedICU 迅速响应，在政府医院建立 ICU 单元，配备最新医疗设备，并部署名为 CARE 的远程医疗平台。该平台支持与专科医生的远程会诊，把重症监护带到更多农村地区。

"10BedICU 与政府医院合作，因为付不起私立医院费用的人大多去政府医院接受重症监护，"纳德哈穆尼解释说，"10BedICU 提供尖端医疗设备，政府则承担包括医院场地在内的持续运营成本。"

这种公私合作模式让 10BedICU 能够在印度的危急时刻快速募资并扩张。如今，10BedICU 是横跨九个邦、200 多家医院的网络，通过 CARE 电子病历（EMR）平台彼此连接。

如今，最糟糕的新冠时期已经过去，10BedICU 得以在以往不存在专科医疗的政府医院持续提供专业医疗服务。"有了 10BedICU，我们现在能治疗那些原本需要转诊到专科医疗中心的患者，比如心脏、脑血管和呼吸衰竭病例。我们正在降低优质医疗的门槛，"阿萨姆邦卡里姆甘杰市民医院高级医官苏布兰什·巴塔查尔亚（Subranshu Bhattacharya）博士说。

## 建立在 OpenAI 模型之上

印度专科医生的短缺仍然存在。"我们的远程医疗方案正在试图弥合这一缺口，但即使在大城市，专科医生也不够，"纳德哈穆尼解释说，"AI 可以让我们向前迈出很多步——简化医务人员的工作，让他们一天有能力服务更多患者。"

10BedICU 一直在为 CARE 平台开发一整套软件工具，帮助医务人员完成日常工作、提升国家的重症监护基础设施水平。"在高风险的医疗环境中，精确与准确至关重要，"纳德哈穆尼说，"OpenAI 提供了我们满足这些关键标准所需的坚实技术底座，以及强大的多模态能力。"

10BedICU 不收集个人身份信息，并与州政府合作确保遵守隐私和数据治理法律。新功能与参与的州和医院在闭环反馈机制下共同测试，新工具的推出节奏缓慢而迭代。

10BedICU 目前正在开发由 OpenAI 驱动的三款工具：

- **CARE Scribe：** 使用 OpenAI 的 Whisper API 和 GPT-4，CARE Scribe 自动转写医患对话，并把这些对话直接转换为结构化的 EMR 记录。CARE Scribe 支持英语、印地语、马拉雅拉姆语和孟加拉语，让护士可以用母语说话。它目前正在以马拉雅拉姆语为主要语言的喀拉拉邦一家姑息治疗中心测试，预计可将医务人员向 EMR 软件录入数据的时间减少 50% 以上，让医务人员有更多时间与患者直接交流。由于医务人员现在可以用母语表达，CARE Scribe 还带来了更高质量的数据采集。
- **CARE Device Connect：** 该工具使用 GPT-4 Vision，把老旧、不兼容的医院监护仪数据整合进 CARE 平台。通过高分辨率摄像头捕捉监护仪读数并实时上传数据，CARE Device Connect 实现了连续的患者监护——这在重症监护场景中可能至关重要。10BedICU 正与卡纳塔克邦合作，在 43 家医院试点该工具，并希望借助 CARE Device Connect 推动现有 ICU 向"SmartICU"转型。
- **CARE Discharge Summary：** 这款同样由 GPT-4 驱动的工具自动汇总患者病历，确保照护的无缝衔接。CARE Discharge Summary 目前正在印度 50 家医院试点，在服务于病历冗长的患者时尤其有效——有时能为医生和护士每位患者节省一个多小时的文书工作。

"有了 OpenAI，10BedICU 不只是在改善医疗——我们在强化印度的医疗基础设施，确保任何有需要的人都能获得他们应得的照护，"纳德哈穆尼说。

曼尼普尔邦卫生与家庭福利部长萨帕姆·兰詹（Sapam Ranjan）对此表示认同："10BedICU 对 AI 的整合显著推进了重症监护，尤其是在偏远地区，让印度更多的人得以享受优质医疗成为现实。"
