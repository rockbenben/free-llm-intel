# 为法律专业人士定制模型

Harvey 与 OpenAI 合作，为法律专业人士打造定制训练的模型。


过去一年里，Harvey 已经确立了自己作为面向法律、税务和金融领域从业者的安全生成式 AI 平台的地位。团队扩展到 100 多人，2023 年收入增长超过 10 倍，并在 B 轮融资中筹集 8,000 万美元，估值达 7.15 亿美元。

最近，Harvey 与 OpenAI 合作构建了一个定制训练的判例法模型。这让 Harvey 能够交付帮助完成复杂推理任务、广泛领域知识，甚至超出单次模型调用能力范围的 AI 系统——例如起草文档、回答复杂诉讼场景中的问题，以及在数百份合同之间识别实质性差异。

## 重新定义法律科技中 LLM 的边界

Harvey 由 Winston Weinberg 与 Gabe Pereyra 联合创办。Weinberg 曾从事反垄断与证券诉讼业务的律师，Pereyra 是一位 AI 研究者，此前在 Google Brain 和 Meta 参与大语言模型（LLM）的工作。他们看到一个机会——用 LLM 综合信息并呈现给律师审阅。

"交易工作和诉讼都越来越复杂——一场跨境并购可能涉及数十万份合同，一次诉讼可能要审阅数百万封邮件，"Weinberg 解释道。有了 AI 帮助综合文档，律师可以把更少时间花在对法律和起草法律文本上、把更多时间花在决策和帮助客户上。

一个早期的验证时刻出现在 Weinberg 和 Pereyra 抓取 Reddit r/legaladvice 板块房东/租客问题、用 GPT-3 生成答案，并把结果与律师分享时。"100 个问题里有 86 个，律师说他们可以直接把答案发给客户、无需修改，"Weinberg 说。"那一刻让我们'啊哈'了。"

## 与 OpenAI 一起打造首个定制训练的判例法模型

在判例法研究上，Harvey 团队希望实现一种体验——你可以把客户的问题复制粘贴进判例法模型，它会详尽地回答，并列出所有来源。他们先试了明显的方法：通过公开 API 微调基础模型，以及搭建检索增强生成（RAG）系统。但在这样一个独特复杂、开放式的问题上，他们遇到了这些方法的局限。

"如果只做检索，你可以回答你不真正擅长的法律领域里的一些非常简单的问题——但那对大多数律师来说其实没那么有用，"Weinberg 解释道。"做判例法研究时，你是在为自己的论证找弹药，那难得多。"

基础模型擅长推理，但缺乏法律工作所需的知识。于是 Harvey 决定与 OpenAI 合作构建一个定制训练的模型，让他们能够在基础模型中注入新的知识、以及围绕这些知识进行推理的方式。

"这些问题没有一个干净利落的方案，"Pereyra 说。"我们很大程度上是一起坐下来，让律师解释判例法研究的工作方式，让研究者展示我们已经做的，并从 OpenAI 那里学习我们有哪些杠杆可以用来处理这一问题。"

Harvey 与 OpenAI 一起加入所需的深度上下文，先加入特拉华州的判例法，再扩展到涵盖所有美国判例法。他们为定制训练的判例法模型加入了相当于 100 亿 token 量的数据。

## 达成高度相关、准确并带来源引用的结果

为测试判例法模型，Harvey 与十家最大的律师事务所合作。他们为律师呈现同一问题下定制判例法模型的输出与 GPT-4 输出的对照。他们被反应之强烈所惊讶。

"97% 的情况下，律师更喜欢判例法模型的输出，"Weinberg 说。"通常是因为它更长、更完整。它进入了问题所问的细微之处，也覆盖了更多相关判例。"

减少幻觉是 Harvey 构建定制模型的动机之一，这一投入得到了回报。"判例法模型不仅不会编造案例，而且每一句话实际上都有它所引用的判例支撑，"Weinberg 说。

在把这一能力推向更多用户的同时，Harvey 也期待探索判例法模型的其他应用，例如起草答辩书与动议，或者帮助律师理解判例法在不同司法辖区之间的差异。

## 为下一代 LLM 而构建

Pereyra 为其他 AI 领域创始人提出这样的建议："不要按今天模型的能力去构建——要按照模型未来会到的地方去构建。去啃更复杂版本的问题，这样当模型更强的版本出来时，它们不会已经被顺带解决了。"

Harvey 下一步要做什么？他们的一个重点是 agentic——如何把多次模型调用组合成一个可用的输出。这将简化用户体验，减少用户所需的提示工程和打字。

他们的愿景是让 Harvey 成为团队中一位支持性的成员。"法律工作的总量在增长，初级律师花无数小时做那些复杂但常规的任务，"Weinberg 说。"我们的机会——不只是在法律领域，而是在所有专业服务领域——是接管常规任务，让专业人士可以把时间聚焦在与客户的互动上。"

"这是一次前沿研究，"Pereyra 说。"我们需要一个愿意投入资源尝试新事物的伙伴。我们考察了所有选项，但我们只信任与 OpenAI 一起构建定制训练的模型。"

> "这是一次前沿研究。我们需要一个愿意投入资源尝试新事物的伙伴。我们考察了所有选项，但我们只信任与 OpenAI 一起构建定制训练的模型。"

Gabe Pereyra，AI 研究者兼联合创始人
