# 评估代码生成模型经济影响的研究议程

## 摘要

OpenAI 正在制定一项研究计划，以评估代码生成模型的经济影响，并邀请外部研究者开展合作。在代码上训练的大语言模型（LLM）能力快速进步，使得研究其对个人、企业和社会的经济影响愈发重要。Codex 是 OpenAI 通过在 GitHub 上数十亿行公开代码上对 GPT‑3 进行微调而开发的 LLM，已有研究表明，在一组评估问题样本上，它能以 28.8% 的比例生成功能正确的代码（Chen et al. 2021）。这对编程的未来以及依赖编程的行业经济学可能产生重要影响。在本文档中，我们提出了评估 Codex 对政策制定者、企业和公众所关注的经济因素影响的研究议程。我们从以下角度论证这一研究议程的价值：代码生成模型在软件开发中潜在广泛的适用性；随着模型能力提升，其他 LLM 创造重大社会与经济影响的潜力；以及利用 Codex 生成证据、建立可推广到未来模型经济影响研究的方法论的价值。我们建议学术与政策研究聚焦于研究代码生成模型及其他 LLM，使其经济影响的证据可用于三个关键领域的决策：部署政策、AI 系统设计与公共政策。为指导这项研究，我们在经济影响范畴内列出了六个优先结果领域，我们计划用 Codex 进行研究：生产率、就业、技能发展、企业间竞争、消费品价格与经济不平等。针对每个领域，我们简要回顾关于 AI 对这些结果影响的既有文献，阐述我们认为构成上述三个决策领域关键输入的若干问题，并给出可以用 Codex 开展的研究示例。为推动基于这一初步研究议程的工作，我们宣布面向外部研究者的[意向征集⁠](https://openai.com/index/economic-impacts/)，邀请他们与 OpenAI 的研究人员和客户合作，更好地衡量代码生成模型及其他 LLM 的经济影响。
