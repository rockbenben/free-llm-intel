# OpenAI 与亚马逊宣布建立战略合作伙伴关系

正在加载…

**最新消息：**

- 亚马逊云科技 (AWS) 与 OpenAI 将共同构建由 OpenAI 模型驱动的有状态运行时环境 (Stateful Runtime Environment)。该环境将在 Amazon Bedrock 上推出，助力 AWS 客户构建生产规模的生成式 AI 应用与智能体。
- AWS 将成为 OpenAI Frontier 的独家第三方云分发渠道。该平台支持机构构建、部署及管理 AI 智能体团队。
- OpenAI 将通过 AWS 基础设施消耗 2 吉瓦 (GW) 的 Trainium 算力容量，以支持对“有状态运行时环境”、Frontier 以及其他高级工作负载的需求。
- OpenAI 与亚马逊将开发定制化模型，旨在为亚马逊面向客户的应用提供支持。
- 亚马逊将向 OpenAI 投资 500 亿美元。

OpenAI 与亚马逊 (NASDAQ: AMZN) 今日宣布建立多年期战略合作伙伴关系，旨在推动全球企业、初创公司及终端消费者的 AI 创新。亚马逊还将向 OpenAI 投资 500 亿美元：其中首笔 150 亿美元已确定投入；其余 350 亿美元将在未来数月内于特定条件达成后陆续到位。

## 合作伙伴关系将为全球企业赋能，提供全新高级 AI 功能

OpenAI 与亚马逊将共同开发由 OpenAI 模型驱动的有状态运行时环境 (Stateful Runtime Environment)，并通过 Amazon Bedrock 提供服务。

有状态开发环境是前沿模型应用的下一代演进方向，它能让模型无缝调用算力、内存和身份认证等要素。“有状态运行时环境”允许开发者保留上下文、记住此前的工作任务、跨软件工具及数据源协同，并获取算力支持。该环境专为处理持续性的项目和工作流而设计。

这些有状态开发环境将经过专门优化，以在 AWS 基础设施上实现最佳运行效果，并与 Amazon Bedrock AgentCore 及各项基础设施服务深度集成，从而确保客户的 AI 应用与智能体能与运行在 AWS 上的其他基础设施应用实现无缝协同。“有状态运行时环境”预计将在未来数月内正式上线。

## 为 AWS 客户带来 OpenAI 最先进的企业级平台

AWS 将成为 OpenAI Frontier 的独家第三方云分发渠道。随着各行业 AI 部署需求的加速增长，此举将进一步扩大 OpenAI 先进企业级平台的覆盖范围。

Frontier 助力机构构建、部署及管理 AI 智能体团队。该平台集成了共享上下文、内置治理及企业级安全保障，支持智能体跨业务系统运行，且无需开发者管理底层基础设施。随着企业从 AI 实验阶段转向生产实践，Frontier 能够助力其快速、安全地在全球范围内将强大的 AI 能力无缝集成到现有工作流中。

## OpenAI 将采用 Trainium 算力，以支持亚马逊日益增长的客户需求

OpenAI 与 AWS 正在将其[现有的 380 亿美元多年期协议⁠](https://openai.com/index/aws-and-openai-partnership/)扩大至 1000 亿美元，期限为 8 年。此次扩展包括 OpenAI 承诺通过 AWS 基础设施消耗约 2 吉瓦 (GW) 的 Trainium 算力容量，以支持有状态运行时 (Stateful Runtime)、Frontier 及其他高级工作负载的需求。该协议降低了大规模生产智能的成本并提升了效率。

在此框架下，OpenAI 锁定了长期算力容量，并与 AWS 合作在其广泛的计算生态中部署定制化芯片。这将支持企业按需消费智能，且无需管理底层基础设施。

此项承诺涵盖了 Trainium3 及下一代 Trainium4 芯片，将为广泛的高级 AI 工作负载提供算力支持。预计于 2027 年开始交付的 Trainium4 将带来又一次重大的性能飞跃，包括显著提升的 FP4 计算性能、更宽的内存带宽以及更高的显存 (HBM) 容量，为不断进化的大规模 AI 系统提供支撑。

## 可用于支持 Amazon 面向客户应用的定制模型

OpenAI 与亚马逊将合作开发定制化模型，供亚马逊开发者用于赋能各项面向客户的应用。亚马逊团队将能够针对直接服务客户的 AI 产品与智能体对 OpenAI 模型进行灵活调优。这些功能将与亚马逊开发者现有的模型资源（包括 Amazon Nova 系列）形成互补，为团队大规模构建与交付产品提供又一利器。
