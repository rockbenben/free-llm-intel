# Nubank 携手 OpenAI 提升客户体验


Nubank 成立于 2013 年，是全球最大的数字金融服务平台之一。它改变了数百万拉丁美洲用户的理财方式，提供免手续费账户、免年费信用卡以及流畅的个性化客户服务。如今，Nubank 在巴西、墨西哥和哥伦比亚为超过 1.14 亿客户提供服务。

借助与 OpenAI 共同开发的 AI 解决方案，Nubank 同时改善了客户体验和内部效率：

- **企业内部知识搜索**：让员工即时获取公司信息，从而更快、更明智地做出决策。
- **呼叫中心副驾**：为客服人员提供对话摘要和推荐答案，提高客户满意度并缩短每张工单的处理时间。
- **AI 助手**：可解决 55% 的一级咨询，每月处理超过 200 万次聊天，并将聊天响应时间缩短 70%。
- **欺诈质量保障**：利用 GPT‑4o 视觉能力分析交易和文档，简化欺诈检测流程并提供优质服务。

## 通过定制企业搜索提高工作效率

Nubank 最初与 OpenAI 合作创建了一套定制企业搜索解决方案，让员工能够快速查阅常见问题、品牌指南和内部政策。

该解决方案由 GPT‑4o 和 GPT‑4o mini 驱动，融合检索增强生成（RAG）技术来检索相关文档并确定其优先级，无需浏览彼此孤立且信息不完整的存储库，即可提供准确答案。

该解决方案还使用基于 Nubank 领域专属内容训练的微调模型，并结合语义搜索，优先呈现与用户查询最相关的结果。

这款工具采用聊天式界面，迅速得到广泛使用：每月有**超过 5,000 名员工**使用它来提高工作效率、加快入职流程并更高效地解决问题。

客服人员、开发者和新员工都能更快、更准确地获取信息，并从中受益。

## 借助 GPT-4o 提升客户服务

企业搜索的成功为知识检索和情境感知型辅助奠定了坚实基础，也让 Nubank 能够应对许多公司如今面临的挑战：在用户规模不断扩大的同时，依然提供卓越的客户服务。

Nubank 与 OpenAI 共同开发了**呼叫中心副驾**，通过整合该银行的知识库和聊天记录，为客服人员提供实时协助。该副驾基于 GPT‑4o 构建，具备文本、语音等实时多模态能力，能够快速响应并理解情境，而这些对优质客户支持至关重要。

借助副驾，客服支持可全天 24 小时持续提供；超过 45% 的 Nubank 客服人员正在使用其核心功能：

- **下一条回复建议**：向客服人员推荐最佳答案，确保回复准确且富有同理心。
- **聊天摘要**：快速提供当前或过往对话的背景信息。
- **分步指导**：简化技术问题和复杂咨询，减轻员工的认知负担。
- **AI 驱动的聊天服务：**每月处理超过 200 万次聊天和电子邮件，无需转交人工客服即可解决超过 50% 的一级咨询。在 OpenAI 的帮助下，Nubank 将聊天响应时间缩短了 70%，为客户提供更快速、更准确的体验。

Nubank 还构建了一款由 GPT‑4o 驱动的 **AI 助手**，直接回答客户的问题。该助手最多可自动进行 5 轮交互，之后再转交人工处理；它每月管理超过 200 万次聊天，让客服人员能够专注于更复杂的问题。

这些解决方案帮助 Nubank 以更高的准确率将问题解决速度提升至原来的 **2.3 倍**，同时保持卓越的服务质量和出色的交易净推荐值（tNPS）。

## 利用视觉能力应对和预防欺诈

为持续改善面向所有人的数字金融服务，Nubank 正在试点一项利用 GPT‑4o 视觉能力的解决方案，以便更一致、更高质量地应对欺诈事件。

GPT‑4o 视觉能力结合自然语言处理与图像识别，可以同时分析文本和视觉数据。Nubank 正利用这项技术仔细审查交易记录、客户沟通内容和提交的文档，识别可能表明存在欺诈的模式和异常。

此类分析遵循欺诈预防政策和监管要求，并由专门团队监督。
