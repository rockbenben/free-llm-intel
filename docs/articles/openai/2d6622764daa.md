# GPT‑5 系统卡增强版：GPT‑5‑Codex

阅读系统卡


GPT‑5‑Codex 是专为 Codex 智能体驱动编程优化的 GPT‑5 版本。与前代模型 codex-1 相同，该模型通过在各种环境下对真实世界中的编码任务进行强化学习训练，生成的代码能够密切反映人类的风格和 PR 偏好，精确遵从指令，并能反复运行测试，直到获得通过的结果。

该模型可在终端或 IDE 中通过 Codex 命令行界面和 IDE 扩展本地使用，也可通过 Codex 网页端、GitHub 及 ChatGPT 移动应用在云端使用。

本增强版概述了为 GPT‑5‑Codex 实施的全面安全措施。其详细阐述了模型层面的应对措施，例如针对高风险任务的专项安全培训和提示注入机制，以及产品层面的防护手段，包括智能体沙箱隔离和可配置网络访问权限。
