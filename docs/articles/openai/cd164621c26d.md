# 利用 ChatGPT 中的公司知识库功能更智能地工作

一种通过整合关联工具中的背景信息，提供深入业务洞察的全新方式。


ChatGPT 能帮助解答各种问题，但完成工作所需的背景信息往往散落在内部工具中：文档、文件、消息、邮件、工单和项目追踪系统。这些工具之间并不总是相互关联，而真正需要的答案通常分散在其中。

今天，我们推出适用于 ChatGPT Business、Enterprise 和 Edu 套餐的公司知识库功能。公司知识库功能将关联应用中的背景信息引入 ChatGPT，提供针对具体业务的精准回复，以便你制定决策、采取行动并完成工作。

借助公司知识库功能，关联应用（如 Slack、SharePoint、Google Drive 及 GitHub）中的信息将变得更易获取、更有价值。该功能由经过训练的 GPT‑5 提供支持，可跨多源信息进行综合分析，提供更全面精准的答复。每条回复均附带清晰引文，以便你了解信息来源并信任结果。

例如，如果你即将与客户通话，ChatGPT 可根据你 Slack 帐户频道中的最新消息、与客户往来邮件中的关键细节、Google Docs 中的上次通话记录以及自上次会面以来 Intercom 支持工单上报的信息，为你生成一份综合简报。

自今日起，所有 ChatGPT Business、Enterprise 和 Edu 套餐用户均可使用公司知识库功能。该功能完全遵循你所在公司的现有权限设置，确保 ChatGPT 仅可访问已被授权查看的内容。

## 操作方式

首先，点击消息编辑器下方的“公司知识库”。首次使用时，需要关联你的工作应用。之后，每当启用此功能时，ChatGPT 都会检索你的所有应用，为回答注入相关背景信息。

在生成回答时，你可以通过侧边栏实时查看 ChatGPT 的检索过程及信息使用逻辑。回答完成后，系统会清晰展示所有参考来源及其引用的具体内容片段。然后，你可点击任意引文，以打开原始来源，获取更多详细信息。

[立即开始使用](http://chatgpt.com/?company-knowledge)或在我们的[帮助中心](https://help.openai.com/en/articles/12628342)了解更多信息。

## 助力洞察工作动态

公司知识库功能能够通过多维度检索解决信息冲突，在处理模糊问题和无明确答案的情境时更具优势。当团队意见不一致或决策尚未敲定时，此功能尤为实用。例如，当询问*“*公司明年的目标最终如何确定？*”*时，ChatGPT 能归纳讨论要点并突出不同观点，助你与团队共同制定相应的后续行动方案。

此外，该功能还能提供更均衡、全面的回答。例如，当提出“汇报移动端产品发布的客户反馈”时，它不仅会概括客户情绪，还会提供相关的支持工单、客户评价，甚至会推荐后续步骤。这能让你更全面地了解实际情况，从而做出更明智的决策。

得益于在搜索过程中同步思考并运用时间筛选功能，公司知识库功能擅长定位时效性信息。例如，当要求*“*简要汇报公司近期的业绩表现”时，ChatGPT 会从多个 Slack 频道和 Google Docs 及 Google Sheets 中提取信息，按时效性和质量对来源进行排序，为你呈现最新动态。它还能追溯特定时间段的信息，比如“回顾我们第一季度的公司业绩”，省去你手动翻查历史文件与消息的繁琐。

## 公司数据始终保持私密、安全可控

随着 ChatGPT 在工作中发挥越来越大的作用，我们正赋予组织更多控制权，使其能够管理用户访问权限、数据存储位置以及数据保护方式。

- **管控：**Enterprise 和 Edu 套餐管理员可以管理整个工作空间中支持公司知识库功能的关联应用的访问权限。他们能创建自定义角色并[设置群组级权限](https://help.openai.com/en/articles/11750701-rbac)，确保用户仅访问所需内容。
- **隐私**：公司知识库功能完全遵循你所在公司的现有权限设置，ChatGPT 仅可访问每个用户已获准查看的内容。**OpenAI 默认绝不使用你的数据进行训练。**
- **安全：**所有数据均受行业标准加密保护。[SSO](https://help.openai.com/en/articles/10468051-sso-overview) 和 [SCIM](https://help.openai.com/en/articles/9627404-openai-chatgpt-scim-integration-faq) 简化了大规模安全访问管理，[IP 允许列表](https://help.openai.com/en/articles/12111596-ip-allowlisting-for-chatgpt)确保仅限授权 IP 地址访问 ChatGPT。
- **合规**：管理员可通过[企业合规 API](https://help.openai.com/en/articles/9261474-compliance-apis-for-enterprise-customers)访问对话日志，满足报告与监管要求。

[了解更多⁠](https://openai.com/business-data/)有关我们的企业级安全防护、数据隐私和合规计划的信息。

### 使用方法

公司知识库功能远不止回答“如何提交费用报销单？”这类问题。它能让 ChatGPT 即时了解你的工作背景，从而在起草计划、编写报告或跟进新项目等任务中发挥更大作用，而无需你额外说明当前工作内容。

使用该功能可帮你实现：

- **将客户洞察转化为战略文档：**ChatGPT 能够整合 Slack 频道中的最新客户反馈、Google Slides 里的调查结果分析，以及支持工单中的核心议题，为产品路线规划提供决策依据。
- **基于实时信息生成报告：**营销活动结束后，ChatGPT 可从 HubSpot 提取活动相关的联系人信息与交易记录，结合 Google Docs 中的方案说明与复盘纪要，以及邮件讨论中的要点内容，自动生成效果总结。
- **制定发布计划**：ChatGPT 会扫描 GitHub 代码库中的待办事项，检索 Linear 里的相关工单，并梳理 Slack 工程频道中的未解决缺陷报告，从而协助规划下个功能版本的发布。它能汇总待处理事项、已追踪事项及待记录事项。

## 局限性和后续计划

当前使用公司知识库功能时，需要在开启新对话时手动选择该功能。如果未选择，ChatGPT 可能仍会调用关联应用协助回答问题，但回复内容将缺乏深度分析和详细引用。我们正致力于在未来数月内整合这些功能体验。

当公司知识库功能开启时，ChatGPT 无法搜索网页，也无法生成图表或图像。你可以将公司知识库功能关闭，并在同一会话中继续工作，以便使用这些其他功能，同时保留现有上下文。在未来数月内，我们计划将公司知识库功能与 ChatGPT 的全部功能进行整合。

我们将持续增加对更多工具的支持，使公司知识库功能的回复更加全面。本周，我们推出了面向 Asana、GitLab Issues、ClickUp 等[众多](https://chatgpt.com/features/connectors)工具的新连接器。
