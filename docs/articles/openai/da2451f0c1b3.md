# Spinning Up in Deep RL

迈出第一步

（在新窗口打开）

插画：Leandro Castelao

加载中…

我们发布 Spinning Up in Deep RL，一份教育资料，目的是让任何人都能学会成为深度强化学习的熟练实践者。Spinning Up 包含极其清晰的 RL 代码示例、教学练习、文档和教程。

在 OpenAI，我们相信深度学习——尤其是深度强化学习——将在强大 AI 技术的发展中扮演核心角色。虽然已经有大量资料能让人快速上手深度学习，但深度强化学习的入门门槛更高。我们设计 Spinning Up，就是为了帮助大家学会使用这些技术，并培养对它们的直觉。

做 Spinning Up 的灵感来自我们与 OpenAI [Scholars⁠(在新窗口打开)](https://blog.openai.com/openai-scholars-2019/) 和 [Fellows⁠(在新窗口打开)](https://blog.openai.com/openai-fellows-interns-2019/) 计划的合作：我们观察到，即使机器学习经验很少甚至没有的人，只要有合适的指导和资源，也能很快成长为实践者。Spinning Up in Deep RL 正是为这个需求而建，并已纳入 2019 年度 Scholars 与 Fellows [学员批次⁠(在新窗口打开)](https://blog.openai.com/openai-scholars-2019/) 的课程体系。

我们还看到，具备 RL 能力有助于人们参与像 [AI 安全⁠(在新窗口打开)](https://blog.openai.com/concrete-ai-safety-problems/) 这样的交叉研究领域，那里需要把强化学习和别的技能混着用。有太多人来问"想从零开始学 RL 该怎么走"，于是我们决定把平时零散给出的建议正式整理出来。

Spinning Up in Deep RL 由以下几个核心部分组成：

- 一份简短的 [RL 入门⁠(在新窗口打开)](https://spinningup.openai.com/en/latest/spinningup/rl_intro.html)，讲术语、算法种类和基础理论。
- 一篇[文章⁠(在新窗口打开)](https://spinningup.openai.com/en/latest/spinningup/spinningup.html)，谈如何成长为一名 RL 研究者。
- 一份按主题整理的[重要论文⁠(在新窗口打开)](https://spinningup.openai.com/en/latest/spinningup/keypapers.html)清单。
- 一个文档完善的[代码仓库⁠(在新窗口打开)](https://github.com/openai/spinningup)，其中是简短、独立的实现：Vanilla Policy Gradient（VPG）、Trust Region Policy Optimization（TRPO）、Proximal Policy Optimization（PPO）、Deep Deterministic Policy Gradient（DDPG）、Twin Delayed DDPG（TD3）以及 Soft Actor-Critic（SAC）。
- 以及[一些练习⁠(在新窗口打开)](https://spinningup.openai.com/en/latest/spinningup/exercises.html)，当作热身。

## 支持

我们为这个项目制定了如下支持计划：

- **高带宽软件支持期**：发布后的头三周，我们会快速处理 bug 修复、安装问题，以及文档中的错误或含糊之处。我们会努力把用户体验理顺，让用 Spinning Up 自学尽可能轻松。
- **2019 年 4 月做大版本评审**：大约在发布六个月后，我们会根据社区反馈认真评审这个包的现状，并公布后续修改计划。
- **内部开发公开同步**：如果我们在与 Scholars 和 Fellows 协作过程中修改了 Spinning Up in Deep RL，我们会把改动推到公开仓库，立即对所有人可用。

## OpenAI 的教育工作

Spinning Up in Deep RL 是 OpenAI 一项新教育计划的一部分，我们正在"把它转起来"，以兑现 [OpenAI 宪章⁠(在新窗口打开)](https://blog.openai.com/openai-charter/) 十条原则中的一条："努力建立一个全球社区，共同应对 AGI 的全球性挑战"。我们希望 Spinning Up 能让更多人熟悉深度强化学习，并用它来推动安全且广泛惠及人类的 AI。

**我们将在 2019 年 2 月 2 日于 OpenAI 旧金山办公室办一场 Spinning Up in Deep RL 工作坊**。内容包括 3 小时讲授材料，以及 5 小时半结构化的动手编程、项目开发和分组讨论——全程由 OpenAI 技术团队的人支持。理想的参与者有软件工程经验、折腾过 ML，但不要求正式的机器学习经验。如果你想参加，请填写我们的[简短申请表⁠(在新窗口打开)](https://docs.google.com/forms/d/e/1FAIpQLSdWbG3H3JYC2Vp-bC1yeP1SL_DSi6laLNjW1RjvEEzlA1V6rg/viewform)。申请将于 2018 年 12 月 8 日截止，录取通知在 2018 年 12 月 17 日发出。

如果你想一边与他人交流、教育他人，一边帮我们把 AI 的边界往前推，不妨考虑申请[到 OpenAI 工作⁠](https://openai.com/careers/)。

我们也会与其他机构合作，用这些材料帮助教育更多人。第一个合作伙伴是加州大学伯克利分校的 [Center for Human-Compatible AI⁠(在新窗口打开)](https://humancompatible.ai/)（CHAI），我们将在 2019 年初与他们合办一场深度 RL 工作坊，形式与我们在 OpenAI 计划举办的 Spinning Up 工作坊类似。我们希望这只是众多合作的第一个。

## Hello World

想了解深度 RL 算法的实际表现，最好的办法就是直接把它们跑起来。用 Spinning Up，这简单到只需：

#### Plain Text

```
1python -m spinup.run ppo --env CartPole-v1 --exp_name hello_world
```

训练结束后，你会拿到一份说明，告诉你怎么查看实验数据、观看你训练出的 agent 的视频。

Spinning Up 的实现兼容来自 [Classic Control⁠(在新窗口打开)](https://gym.openai.com/envs/#classic_control)、[Box2D⁠(在新窗口打开)](https://gym.openai.com/envs/#box2d) 或 [MuJoCo⁠(在新窗口打开)](https://gym.openai.com/envs/#mujoco) 任务组的 Gym 环境。

我们为 Spinning Up 设计代码时心里想着的是新手，让它简短、友好，尽可能容易学习。我们的目标是写最小实现，展示理论如何变成代码，避开深度 RL 库里常见的那一层层抽象与遮蔽。我们宁要清晰、不要模块化——各实现之间的代码复用严格限制在日志和并行化工具上。代码都做了注释，让你随时知道在发生什么，并在对应的 readthedocs 页面上配有背景材料（以及伪代码）。
