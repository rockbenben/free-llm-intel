# 智能时代的网络安全

一项推动 AI 赋能网络防御普及化的行动计划

阅读完整计划



人工智能正在重塑网络安全格局。一方面，AI 能够协助防御者识别漏洞、实现修复自动化并加快响应速度；但与此同时，不法分子也在利用同样的技术来扩大攻击规模、降低准入门槛，并提升攻击的复杂性。

当前，美国及其盟友正面临瞬息万变的网络威胁环境，私营部门的创新者肩负着应对这一挑战的重要责任。OpenAI 始终郑重对待这一职责，并在今天发布了这份行动计划。该计划吸取了联邦与各州政府及大型商业实体中网络安全与国家安全专家的意见，由以下五大支柱组成：

- 普及网络防御能力
- 深化政府与行业的协同联动
- 加强前沿网络能力的安全保障
- 确保部署过程的可视化与掌控力
- 赋能用户实现自我保护

我们的计划阐述了 OpenAI 将如何履行既定承诺：通过构建必要的基础设施，为网络防御者提供支撑。我们的目标是让社会各界的信任方都能公平获取并使用防御工具。在智能时代构建防御韧性，既需要依托民主体制与流程，也需要扩大技术的准入范围，从而切实保护社区、关键系统以及国家安全。
