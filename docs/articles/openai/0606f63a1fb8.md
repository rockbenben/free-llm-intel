# 我们为保护用户隐私，如何应对《纽约时报》的数据留存要求

***2025 年 10 月 22 日更新：***

*经过数月的诉讼，我们已不再受要求无限期留存消费者 ChatGPT 与 API 内容的法律命令约束。我们在此前命令下的义务已于 2025 年 9 月 26 日终止。*

*我们已恢复*[*标准数据留存实践*⁠（在新窗口中打开）](https://help.openai.com/en/articles/8983778-chat-and-file-retention-policies-in-chatgpt)*：*

- ***已删除的 ChatGPT 对话**** 和 ****临时聊天（Temporary Chats）**** 将在 *[30 天内*⁠（在新窗口中打开）](https://help.openai.com/en/articles/8983778-chat-and-file-retention-policies-in-chatgpt)*从我们系统中自动删除。*
- ***API 数据**** 同样将在 *[30 天后*⁠（在新窗口中打开）](https://platform.openai.com/docs/faq/faq)自动删除。

*《纽约时报》仍在要求 OpenAI 保留 2025 年 4 月至 9 月间特定的一组用户数据。因此，尽管我们今后不再被要求无限期留存新增用户数据，也不再被要求留存源自欧洲经济区、瑞士或英国的任何对话，我们仍将安全存储 2025 年 4 月至 9 月的有限历史用户数据。这些数据仍处于封存状态，只有经过审计的小规模 OpenAI 法务与安全团队可以访问，且除履行法律义务外不得用于任何用途。这批数据目前****不会移交****给《纽约时报》、法院或任何其他人。我们将继续抗击《纽约时报》的这种过度索取，捍卫长期以来的隐私规范。*

*正如《纽约时报》自己的社论版在 2020 年所写，用户“*[应当能够控制自己的个人数据会发生什么⁠（在新窗口中打开）](https://www.nytimes.com/2020-04-07/opinion/digital-privacy-coronavirus.html)*”。*

信任与隐私是我们产品的[核心](https://openai.com/security-and-privacy/)。

我们为你提供掌控数据的工具——包括便捷退出选项，以及将[已删除的 ChatGPT 聊天⁠（在新窗口中打开）](https://help.openai.com/en/articles/8983778-chat-and-file-retention-policies-in-chatgpt)和 API 内容在 30 天内从 OpenAI 系统中永久移除。

《纽约时报》和其他原告在对我们的无根据诉讼中，提出了一个宽泛且不必要的要求：无限期保留消费者 ChatGPT 和 API 客户数据。

这与我们对用户做出的隐私承诺根本冲突。它背弃了长期以来的隐私规范，削弱了隐私保护。

我们坚定地认为这是《纽约时报》的越界索取。我们正继续上诉这一命令，以便始终把你的信任与隐私放在首位。

——Brad Lightcap，OpenAI 首席运营官

## 对你疑问的解答

**《纽约时报》等原告为何提出这一要求？**

- 《纽约时报》正在起诉 OpenAI。作为其无根据诉讼的一部分，他们近期请求法院强制我们从现在起无限期保留所有用户内容，理由只是猜测也许能找到支持其案情的东西。
- 我们坚定认为这是越界。它危及你的隐私，却无助于实际解决诉讼。这正是我们抗击它的原因。

**我的数据会受影响吗？**

- 会，如果你持有 ChatGPT Free、Plus、Pro 或 Team 订阅，或你使用 OpenAI API（且没有零数据留存协议）。
- 不影响 ChatGPT Enterprise 或 ChatGPT Edu 客户。
- 不影响在我们 ZDR 修订条款下使用零数据留存端点的 API 客户。

**到目前为止你们如何挑战这一命令？**

- 自始我们就主张，原告保全“所有输出数据”的请求范围过宽，与我们的隐私承诺冲突。我们提交了动议，请求治安法官（Magistrate Judge）重新考虑保全命令，并指出无限期留存用户数据有悖行业规范和我们自己的政策。
- 5 月 27 日出庭时，法院澄清 ChatGPT Enterprise 不在保全范围内。
- 我们还已向地区法院法官上诉该命令。

**如果我是签有零数据留存协议的企业客户怎么办？**

- 你不受影响。作为使用我们零数据留存（ZDR）API 的企业客户，我们从不留存你发送的提示或我们返回的回答。由于这些数据从未存储，法院命令不会涉及它们。

**如果我在 ChatGPT 中删除了我的数据，按这一命令还会被留存吗？**

- 《纽约时报》要求我们保留甚至[已删除的 ChatGPT 聊天⁠（在新窗口中打开）](https://help.openai.com/en/articles/8983778-chat-and-file-retention-policies-in-chatgpt)和 API 内容——这些内容通常会在 30 天内从我们系统中自动移除。
- 不影响 ChatGPT Enterprise 或 ChatGPT Edu 客户。

**你们将如何存储我的数据？谁能访问？**

- 法院命令所涉内容被单独存储在安全系统中，并处于“法律保全（legal hold）”保护之下，即除履行法律义务外不得访问或用于任何目的。
- 只有经过审计的小规模 OpenAI 法务与安全团队在履行法律义务所必需时才能访问这些数据。

**这些数据会分享给《纽约时报》、其他原告或任何其他人吗？**

- 这些数据不会自动分享给《纽约时报》或任何其他人。它们被锁定在独立的法律保全之下，意味着安全存储、只能按严格法律规程访问。
- 如果原告以任何方式继续施压获取，我们将在每一步为你的隐私而战。

**OpenAI 会把这些数据保留多久？法院命令有已知截止日期或审查期吗？**

- 目前，法院命令迫使我们从现在起持续留存消费者 ChatGPT 与 API 内容。我们正在积极挑战该命令，如果成功，我们将恢复标准数据留存实践。

**这一法院命令是否违反 GDPR 或我在欧洲或其他隐私法下的权利？**

- 我们此刻采取措施予以遵从，因为我们必须守法，但《纽约时报》的要求不符合我们的隐私标准。正因如此我们提出挑战。

**这会改变你们的训练政策吗？**

- 企业客户：我们默认不使用企业数据训练模型，该法院命令不改变这一点。
- 消费者客户：在设置中，由你决定你的聊天是否用于帮助改进 ChatGPT，该命令也不改变这一点。

**你们会持续向我们通报吗？**

- 会。我们承诺透明，并将持续让你了解情况。我们会分享有意义的更新，包括命令的任何变化及其对你数据的影响。

**你们的数据留存政策是什么？**

- [ChatGPT Free、Plus、Pro⁠（在新窗口中打开）](https://help.openai.com/en/articles/8983778-chat-and-file-retention-policies-in-chatgpt)：当你删除聊天（或你的账号）时，聊天立即从你的账号中移除，并计划在我们系统中于 30 天内永久删除，除非因法律或安全原因必须留存，或如[此处⁠（在新窗口中打开）](https://help.openai.com/en/articles/8809935-how-to-delete-and-archive-chats-in-chatgpt)所述。
- [ChatGPT Team](https://openai.com/enterprise-privacy/)：每位终端用户自行控制其对话是否留存。任何已删除或未保存的对话会在 30 天内从我们系统移除，除非法律要求我们留存。
- [ChatGPT Enterprise 与 ChatGPT Edu](https://openai.com/enterprise-privacy/)：由你的工作区管理员控制客户内容留存时长。任何已删除的对话会在 30 天内从我们系统移除，除非法律要求我们留存。
- [API](https://openai.com/enterprise-privacy/)：基于我们 API 构建的企业客户，按其使用的端点与配置自行控制客户内容为维持应用状态所需的留存时长（见[此处⁠（在新窗口中打开）](https://platform.openai.com/docs/guides/your-data#storage-requirements-and-retention-controls-per-endpoint)）。30 天后，API 输入和输出会从 OpenAI 日志中移除，除非法律要求我们留存。
- 零数据留存 API：若企业客户使用零数据留存端点，输入与输出从不记录，也不会为维持应用状态而留存。
