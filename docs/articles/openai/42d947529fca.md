# OpenAI Scholars 2019：结课项目

第二期 OpenAI Scholars 已经结束，八位学者全部完成了令人兴奋的结课项目，并在 OpenAI 的 Scholars Demo Day（学者展示日）上展示。

2019 年学者 Janet Brown。摄影：Blake Tucker

过去三个月里，我们看到来自软件、医学、物理、儿童发展等领域的资深工程师，如何通过我们的教育资源与导师辅导的组合，成长为机器学习实践者。

- [回看展示日（在新窗口中打开）](https://www.youtube.com/watch?v=4u218xVkjmQ)

## 项目

我们的学者在各个专业领域展示了核心技术能力和自我驱动力——对于这样一个自主性极强的项目，这些都是至关重要的素质。他们每个人进入机器学习领域时都是相对的新手，我们希望他们的进步能展示机器学习其实多么易于入门。想开启你的学习之旅，可以看看我们的[教育材料⁠](https://openai.com/index/spinning-up-in-deep-rl/)。关于下一期学者项目的申请信息将于 7 月公布。敬请期待！

*感谢 AWS 为学者们提供算力额度。也特别感谢我们尽职尽责的社区导师们，他们抽出时间为学者的项目提供建议。*
