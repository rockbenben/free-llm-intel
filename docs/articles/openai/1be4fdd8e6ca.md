# OpenAI 将收购 Pierre Computer Company, Inc.

扩展 Codex 用于编写、理解和审查代码的工具。

今天，我们宣布 OpenAI 将收购 [Pierre Computer Company, Inc](https://pierre.computer/).（简称“Pierre”）。这家公司打造了 [Code Storage](https://code.storage/) 和一系列出色的开源开发者工具。如果你曾在 Codex 应用中浏览文件或审查代码变更，那么你早已体验过 Pierre 的 Trees 和 Diffs 库。我们很高兴能与 Pierre 团队携手，在开发者已有的 Git 工作流基础上进一步改进，让这些流程适应团队与编程智能体协作的方式。

在自身的工程实践中，我们发现：随着越来越多的工作并行开展，围绕 Git 构建的系统也需要随之演进。本周早些时候，我们分享了如何借助 Pando [扩展 OpenAI 的 Git 系统](https://openai.com/index/scaling-git-at-openai/)。Pando 是我们为工程师和智能体自研的源代码管控后端。我们希望与 Pierre 团队一起，为现代软件开发树立标准：从智能体创建的第一个分支，到代码部署上线的精彩瞬间。我们希望让 Codex 成为开发者与智能体实现远大项目构想的平台。

## 在智能体时代，兼顾精工细作与规模化能力

我们一直很欣赏 Pierre 在 Git 协作的另一个关键环节中倾注的心血：即开发者如何审查代码。这份心血，透过 Codex 使用的这些库可见一斑。Trees 让开发者能快速定位项目文件，Diffs 则让代码变更一目了然。这两款工具都能让开发者轻松审查和浏览大量代码，同时保持出色的性能。

对细节的关注，也贯穿于 Pierre 的其他工作中。Diffs 的*编辑*模式让审查者在发现问题时，就能即时修改那一行代码。Pierre 最近发布了 *Highlights*，这是一款速度极快的语法高亮工具，能随开发者输入或智能体流式输出代码而实时更新。这个将编辑器嵌入 Diff 的小团队，还设计了 Code Storage 的 API。Code Storage 服务让应用能够使用 Git 存储代码并跟踪其历史记录。

## 将这些成果汇聚到 Codex

Pierre 打造了深受开发者喜爱的工具。未来，我们将携手推出惠及所有人的新产品和平台。收购完成后，我们的目标是推动整个行业的源代码管控迈向未来。我们希望 Codex 能将企业交付的代码与员工所做的决策联系起来，并具备满足未来需求的规模化能力。

Pierre 的开源项目将继续保持开源状态，我们也将继续为这些项目贡献力量。收购完成后，客户可以继续使用 Code Storage，同时我们将着手把它的各项功能整合到 Codex 中。

*本次收购的交割须满足惯常交割条件，包括获得监管批准。在交割完成之前，OpenAI 和 Pierre 将继续作为两家独立公司运营。*
