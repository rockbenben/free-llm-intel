# 卢旺达选举内容：政治评论网络

OpenAI 封禁了来自卢旺达、在选举前用 AI 生成党派评论的账号。

*本案例研究最初发表于 OpenAI [2024 年 10 月](https://cdn.openai.com/threat-intelligence-reports/influence-and-cyber-operations-an-update_October-2024.pdf)报告。*

## 行为者

我们封禁了一批源自卢旺达的 ChatGPT 账号，它们在该国选举前生成党派性推文。该活动与卢旺达境内人员相关联。我们的最初线索来自克莱姆森大学（Clemson University）研究者发布的报告。

## 行为

该活动专注于批量生成短评，通常带话题标签。我们确认这些评论由 X 上一批账号发布，其中一些发帖量极高，每小时数百条推文。某些情况下，同一条推文被许多不同账号发布。在挫败初始活动后，我们又识别并封禁了生成类似内容的新注册账号。

*该网络生成、由多个 X 账号发布的一条评论。*

## 生成内容

这一活动最好被理解为"主题与变奏"。操作者大量发布关于卢旺达爱国阵线（Rwandan Patriotic Front）给国家带来好处的帖子。他们的帖子通常使用两三个主要话题标签：#RPFOnTop、#PKNiWowe 和 #ToraKagame24。多数评论是英文，但该网络也用法语和卢旺达语（Kinyarwanda）产生大量评论。由于该行动就其选定的每个话题生成数量极大的评论，其许多帖子在措辞和结构上高度相似。这展示了内容生成的一个特征，或可作为揭露此类活动的线索：在围绕特定主题的短文本中，可用于传达该信息的同义表达与句式是有限的。AI 生成能造出更多变体，但数量越大，越容易流露出"家族相似性"。

*该网络生成并发布在 X 上的英文评论。*

## 影响评估

该网络发布内容量大——至少数千条推文。然而，我们在调查中识别的线上帖子，没有一条收到超过个位数的回复、点赞或分享，许多完全没有。这种"高发布量、低互动"的组合是刷评垃圾网络的典型特征。如此多帖子使用相同话题标签，暗示其目标之一可能是把标签推上热搜，从而让网络内容出现在没有关注其账号的人面前。（以推动话题标签成趋势为目标的活动，早在无 AI 时代就有报道，至少可追溯到 2017 年。）调查期间，我们确实发现该行动推动的某几个话题标签一度进入 X 卢旺达地区热搜前十，尽管使用该标签的绝非只有该行动的账号：例如这一标签……
