# OpenAI GPT‑4.5 系统卡（System Card）

## GPT-4.5 系统卡

特定风险领域

- 违禁内容
- 越狱
- 模型错误

Preparedness 记分卡

- CBRN（化生核放）：Medium（中）
- 网络安全：Low（低）
- 说服能力：Medium（中）
- 模型自主性：Low（低）

## 记分卡评级

- Low（低）
- Medium（中）
- High（高）
- Critical（严重）

只有缓解后评分为 "medium" 或更低的模型才能部署。
只有缓解后评分为 "high" 或更低的模型才能继续开发。

## 引言

我们正在发布 OpenAI GPT‑4.5 的研究预览版，这是我们迄今最大、知识面最广的模型。GPT‑4.5 继承 GPT‑4o 并进一步扩大预训练规模，相比我们强大的 STEM 导向推理模型，它被设计得更具通用性。我们使用新的监督技术并结合监督微调（SFT）和人类反馈强化学习（RLHF）等传统方法进行训练，与 GPT‑4o 所用方法类似。部署前我们进行了大量安全评估，未发现相对现有模型有任何显著的安全风险上升。

早期测试显示，与 GPT‑4.5 交互的感觉更自然。它更广的知识库、更强的用户意图对齐和更高的情商，使其非常适合写作、编程和解决实际生活问题等任务——且幻觉更少。

我们以研究预览形式分享 GPT‑4.5，以更好地理解其优势与局限。我们仍在探索它的能力，并期待看到人们以我们可能未曾预料的方式使用它。

本 system card 阐述了我们如何构建和训练 GPT‑4.5、评估其能力并强化安全性，遵循 OpenAI 的安全流程与 Preparedness Framework（制备框架）。
