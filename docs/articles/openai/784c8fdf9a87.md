# 语言模型可以解释语言模型中的神经元

我们用 GPT-4 自动撰写大型语言模型中神经元行为的解释，并为这些解释打分。我们发布了一个数据集，包含 GPT-2 中每个神经元的（不完美的）解释与评分。

语言模型变得越来越强大、部署越来越广，但我们对它们内部如何工作的理解仍非常有限。例如，仅从输出很难判断模型是否使用了有偏的启发式或存在欺骗行为。可解释性（interpretability）研究旨在通过观察模型内部来揭示更多信息。

可解释性研究的一种简单思路，是先弄清各个组件（神经元和注意力头）在做什么。传统上这需要人类[手动⁠（在新窗口打开）](https://distill.pub/2020/circuits/curve-detectors/)[检查⁠](https://openai.com/index/microscope/)[神经元⁠（在新窗口打开）](https://transformer-circuits.pub/2022/solu/index.html)，弄清它们表示数据的哪些特征。这一流程难以扩展：对拥有数百亿或数千亿参数的神经网络很难套用。我们提出一种自动化流程，使用 GPT-4 生成并对神经元行为的自然语言解释打分，并将其应用于另一个语言模型的神经元。

这项工作是我们 [对齐研究路径⁠](https://openai.com/index/our-approach-to-alignment-research/) 三大支柱中的第三项：我们希望把对齐研究工作本身自动化。这一路径的一个可取之处在于，它能随 AI 发展的步伐一起扩展。随着未来模型作为助手变得越来越聪明、越来越有用，我们将找到更好的解释。

## 我们发现的结果

使用我们的打分方法，我们可以开始衡量技术对网络不同部分的适用程度，并设法改进目前解释不佳的部分。例如，我们的技术对更大的模型效果不佳，可能是因为更深的层更难解释。

尽管绝大多数解释得分很低，我们相信现在可以用 ML 技术进一步提升生成解释的能力。例如，我们发现在以下方面改进可以提升得分：

- *迭代解释。* 让 GPT-4 提出可能的反例，再根据神经元的激活修订解释，可以提高得分。
- *用更大的模型生成解释。* 随着解释模型能力的提升，平均得分上升。但即使 GPT-4 给出的解释也不如人类，说明仍有改进空间。
- *改变被解释模型的架构。* 使用不同激活函数训练的模型，解释得分更高。

我们在 OpenAI API 上开源了数据集和可视化工具，包含由 GPT-4 撰写的 GPT-2 全部 307,200 个神经元的解释，以及[使用公开可用模型⁠（在新窗口打开）](https://github.com/openai/automated-interpretability)进行解释和打分的代码。我们希望研究社区开发出新技术，生成得分更高的解释，以及用解释来探索 GPT-2 的更好工具。

我们发现了 1000 多个解释得分至少 0.8 的神经元，意味着按 GPT-4 的判断，这些解释涵盖了神经元高激活行为的大部分。这些被解释得很好的神经元大多没什么意思。不过，我们也发现了许多 GPT-4 没看懂的有趣神经元。随着解释的改进，我们有望快速获得对模型计算有意思的定性理解。

## 展望

我们的方法目前有许多[局限⁠（在新窗口打开）](https://openaipublic.blob.core.windows.net/neuron-explainer/paper/index.html#sec-limitations)，希望能在未来的工作中解决。

- 我们聚焦简短的自然语言解释，但神经元的行为可能非常复杂，无法简洁描述。例如，神经元可能高度多义（polysemantic，表示许多不同概念），或表示人类不理解、没有对应词汇的单一概念。
- 我们最终希望自动发现并解释实现复杂行为的整个[神经回路⁠（在新窗口打开）](https://distill.pub/2020/circuits/zoom-in/)——神经元和注意力头协同工作。目前的方法只把神经元行为解释为原始文本输入的函数，未说明其下游影响。例如，一个在句号上激活的神经元，可能是在提示下一个词应大写，也可能是句计数器在加一。
- 我们解释了神经元的行为，但没有尝试解释产生该行为的机制。这意味着即使高分解释在分布外文本上也可能表现很差，因为它们只是在描述相关性。
- 我们的整体流程计算量相当大。

我们对这一方法的扩展与推广感到兴奋。最终，我们希望像可解释性研究员那样，用模型来形成、检验并迭代完全通用的假设。

我们最终想要解释我们最大的模型，以便在部署前后发现对齐与安全问题。但在这些技术能揭示不诚实等行为之前，我们还有很长的路要走。
