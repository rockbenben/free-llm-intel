# OpenAI《欧盟经济蓝图》




今天，OpenAI 发布《欧盟经济蓝图》，提出一系列建议，旨在帮助欧洲把握人工智能带来的机遇，推动整个地区经济可持续增长，并确保人工智能由欧洲开发、在欧洲部署、为欧洲服务。

其潜力显而易见。人工智能能够推动新的科学突破，让教育更具包容性，提高生产力，为大中小企业注入动力，并开启全新的创意形式。这些益处已在整个地区成为现实：德国马克斯·普朗克学会和法国巴黎政治学院等欧洲实验室及高校的研究人员正在运用人工智能；爱沙尼亚的学校已开始部署 ChatGPT Edu；德国则拥有美国以外数量最多、基于 OpenAI 技术进行开发的 API 开发者。但要大规模实现这些巨大收益，欧洲必须带着紧迫感和明确目标采取行动。

这份蓝图倡导欧洲核心的创业精神、卓越科研和个人自由，也彰显欧盟对社会包容与基本权利的承诺，并为人工智能驱动的增长勾勒出一条可行的前进道路。

## 我们提出了四项原则，以充分释放欧洲的人工智能潜力：

- **夯实并拓展人工智能持续增长所需的基础——芯片、数据、能源和人才
**芯片、数据、能源和人才是赢得人工智能竞争的关键——在这场竞赛中，欧洲有能力也必须参与竞争。在人工智能时代，这些基础要素将决定谁能引领全球。欧洲必须保障这些资源的供应并推动其发展，以维护自身繁荣和竞争优势。
- **确保欧盟规则精简且协调一致，推动而非阻碍人工智能发展
**正如 Mario Draghi 在报告中指出的那样，欧洲当前的监管环境往往过于复杂。欧盟政策制定者应着力减少单一市场内部的壁垒：简化数字规则体系，取消重复或过时的提案，并协调统一相关规则，从而吸引开发和支持前沿人工智能所需的投资。
- **推动人工智能在各行业、各地区和全社会广泛应用，最大限度释放其机遇
**提高人工智能的普及程度和素养，是确保其为欧洲大中小企业、公共服务和整个社会带来积极影响的关键。掌握理解、运用和塑造人工智能技术的技能，是确保人工智能改善所有欧盟公民生活并增强欧盟竞争力的关键。
- **确保以负责任的方式构建人工智能，并体现欧洲价值观
**欧盟和人工智能行业必须携手合作，确保随着人工智能工具日益融入欧洲人的日常生活，用户能够放心信赖自己和家人使用的产品。同样重要的是，赋予个人根据自身具体需求和偏好切实掌控及个性化设置这些工具的能力。建立这种信任，对于推动人工智能得到广泛接纳并惠及全社会至关重要。

为成为欧盟政策制定者的建设性合作伙伴，我们提出以下以推广应用为重点的初步构想，力求让上述建议产生显著成效：

- **人工智能算力扩展计划：**到 2030 年，将欧盟的算力至少提高 300%，重点建设针对推理优化的低延迟、地理分布式基础设施，作为以训练为重点的人工智能工厂的补充。
- **人工智能加速基金：**设立一项规模达 10 亿欧元的专项基金，快速资助能够体现人工智能明确社会或经济价值的试点项目。
- **一亿名人工智能公民***：*到 2030 年，通过以欧盟所有官方语言免费提供的在线课程，为一亿名欧洲人教授人工智能基础技能。
- **青年人工智能数字自主行动倡议**：设立一项由欧盟资助的倡议，支持开发与年轻人共同设计的人工智能应用。这可以包括与教育机构、青年委员会和儿童安全组织开展参与式设计冲刺，共同打造能够反映年轻人需求和价值观的功能。

为跟上人工智能技术的快速发展，这份蓝图将持续更新。我们将继续与欧洲各国政府合作，从中了解如何审慎引导人工智能技术造福公众，并据此不断完善我们的原则。

为此，我们正在欧洲各地举办一系列人工智能经济活动，收集见解和反馈，为政策建议和迭代式部署提供参考。

我们已在布鲁塞尔和巴黎举办活动，为这项工作提供参考，并将很快在华沙和慕尼黑举办更多活动。

OpenAI 坚信，凭借正确的愿景和执行力，欧洲能够利用人工智能应对当今时代最严峻的挑战——从改善医疗和教育，到推动绿色转型——并在此过程中让所有人受益。

我们期待与欧洲携手实现这一目标。
