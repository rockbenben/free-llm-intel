# 介绍 SimpleQA

一个名为 SimpleQA 的事实性基准，用来衡量语言模型回答简短、寻答式问题的能力。

阅读论文（在新窗口打开）

人工智能中一个悬而未决的问题是：如何训练出能够产出事实正确回答的模型。当前的语言模型有时会产生虚假输出，或给出缺乏证据支撑的答案，这一问题被称为“幻觉”。能够生成更准确、幻觉更少的回答的语言模型更值得信赖，也能被用于更广泛的应用。为了衡量语言模型的事实性，我们正在[开源⁠(在新窗口打开)](https://github.com/openai/simple-evals/)一个名为 SimpleQA 的新基准。

## 关于 SimpleQA 基准

事实性是个复杂的话题，因为它很难衡量——评估任意给定论断的事实性本就充满挑战，而语言模型又能生成包含数十条事实论断的长补全。在 SimpleQA 中，我们聚焦于简短、寻答式的查询，这缩小了基准的范围，但让衡量事实性变得容易处理得多。

对于 SimpleQA，我们的目标是创建一个具备以下特性的数据集：

- **高正确性。** 问题的参考答案由来自两名独立 AI 训练师的来源支撑，且问题的编写方式使得预测答案易于评分。
- **多样性。** SimpleQA 涵盖广泛主题，从科技到电视节目和电子游戏。
- **对前沿模型有挑战性。** 与 [TriviaQA⁠(在新窗口打开)](https://aclanthology.org/P17-1147/)（2017）或 [NQ⁠(在新窗口打开)](https://aclanthology.org/Q19-1026/)（2019）等已经饱和的旧基准相比，SimpleQA 被设计为对前沿模型更大的挑战（例如 GPT‑4o 得分不到 40%）。
- **良好的研究者体验。** 由于问答简洁，SimpleQA 运行起来快速简单。无论通过 OpenAI API 还是其他前沿模型 API，评分都很高效。此外，凭借 4326 个问题，SimpleQA 作为评估基准的方差应相对较低。

我们雇佣 AI 训练师浏览网页，创建简短、寻答式的问题和对应答案。要纳入数据集，每个问题都必须满足一套严格标准：它必须有一个单一、不容置疑的答案以便评分；问题的答案不应随时间改变；且大多数问题必须能诱发 GPT‑4o 或 GPT‑3.5 中至少一个的幻觉。为了进一步提升数据集质量，第二名独立 AI 训练师在不看到原始回答的情况下回答每个问题。只有两名 AI 训练师答案一致的问题才被纳入。

作为质量的最终验证，我们让第三名 AI 训练师回答从数据集中随机抽取的 1000 个问题。我们发现第三名训练师的答案与原始一致答案匹配的概率为 94.4%，不一致率为 5.6%。随后我们人工检视了这些例子，发现在 5.6% 的不一致中，有 2.8% 是由于评分的假阴性或第三名训练师的人为错误（例如答案不完整或误读来源），剩余 2.8% 则是由于问题本身的真实问题（例如问题含糊，或不同网站给出相互矛盾的答案）。因此，我们估计该数据集的固有错误率约为 3%。

## 用 SimpleQA 比较语言模型

为了给问题评分，我们使用一个带提示词的 ChatGPT 分类器，它同时看到模型的预测答案和标准答案，然后把预测答案评为“correct”（正确）、“incorrect”（错误）或“not attempted”（未作答）之一。

## 用 SimpleQA 衡量大语言模型的校准

像 SimpleQA 这样的事实性基准还能让我们衡量一个被称为“校准”（calibration）的科学现象，即语言模型是否“知道自己知道什么”。衡量校准的一种方式是直接要求语言模型陈述它对自己答案的置信度，使用的提示词为：“请给出你最好的猜测，并附上你认为该答案正确的置信度百分比。”然后我们可以绘制模型陈述的置信度与它实际准确度之间的相关性。一个完美校准的模型，其实际准确度应与陈述的置信度一致。例如，在所有模型陈述置信度为 75% 的提示词上，完美校准模型的准确度也应是 75%。

这一结果见下图。陈述置信度与准确度之间的正相关是一个令人安心的信号，说明模型对置信度有某种把握。我们看到 o1‑preview 比 o1‑mini 校准得更好，gpt4o 比 gpt4o-mini 校准得更好，这与[先前工作⁠(在新窗口打开)](https://arxiv.org/abs/2207.05221)显示的更大模型校准更好相符。然而，表现明显低于直线 y=x 意味着模型一贯高估自己的置信度。因此，就陈述置信度而言，大语言模型的校准有很大提升空间。

衡量校准的另一种方式是把同一个问题问语言模型 100 次。由于语言模型在重复尝试时可能给出不同答案，我们可以评估某一特定答案的出现频率是否与其正确性相符。更高的频率通常表示模型对自己的答案更有信心，因为它在反复给出同一个答案。一个校准良好的模型，其实际准确度应与频率一致。

## 结论

SimpleQA 是一个简单但对评估前沿模型事实性颇具挑战的基准。SimpleQA 的一个主要局限在于其范围——虽然 SimpleQA 很准确，但它只在“简短、寻答式、只有一个可验证答案”的受限设定下衡量事实性。提供准确简短答案的能力，与撰写包含大量事实的长篇回答的能力之间是否相关，仍是一个开放的研究问题。我们希望开源 SimpleQA 能推动更可信、更可靠 AI 的研究向前发展，并邀请研究者用它来评估语言模型的事实性，向我们提供反馈。
