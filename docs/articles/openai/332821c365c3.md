# OpenAI Scholars 2021：最终项目

我们自豪地宣布，2021 届 [OpenAI Scholars⁠](https://openai.com/scholars/) 已完成为期六个月的导师计划，并在 OpenAI 的津贴与支持下产出了一个开源研究项目。

*2019 届 OpenAI Scholar Edgar Barraza。摄影：Blake Tucker*

在创造出 GPT‑3 和 DALL·E 的 OpenAI 顶尖研究员身边共事，我们的 Scholars 探索了 AI 安全、对比学习、生成建模、缩放定律、多目标任务的自动编码、测试时计算、NLP 分词策略，以及基于人类反馈的摘要等主题。

作为课程的收官，我们的九位 Scholars 分享了自己的工作，以及 Scholars 计划如何影响了他们的职业生涯。下文阅读关于他们各自及其项目的更多内容。
