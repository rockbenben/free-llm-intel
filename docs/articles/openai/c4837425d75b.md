# OpenAI 收购 Sky 的开发商 Software Applications Incorporated

升级人们在电脑上使用 AI 的方式。

加载中……

AI 的进步不只是推进智能，还在于通过那些懂上下文、能贴合你的意图、无缝协作的界面把它释放出来。这正是我们兴奋地分享的原因：OpenAI 已收购 Software Applications Incorporated，也就是 Sky 的开发商。

Sky 是 Mac 上一款强大的自然语言界面。有了 Sky，AI 就与你并肩工作，无论你是写作、规划、编程，还是打理日常。Sky 能理解你屏幕上显示的内容，并能调用你的应用采取行动。

我们将把 Sky 对 macOS 的深度集成和产品匠心融入 ChatGPT，团队成员全部加入 OpenAI。

"我们正在构建这样一个未来：ChatGPT 不只是回应你的提示词，而是帮你把事情办成。Sky 与 Mac 的深度集成，加速了我们把 AI 直接带进人们每天所用工具的愿景。"——Nick Turley，ChatGPT 副总裁兼负责人

"我们一直希望电脑能更赋能、更可定制、更直观。有了 LLM，我们终于能把这些碎片拼到一起。这正是我们打造 Sky 的原因——一个漂浮在你桌面上、帮你思考和创作的 AI 体验。我们非常激动能加入 OpenAI，把这份愿景带给数亿人。"——Ari Weinstein，Software Applications Incorporated 联合创始人兼 CEO

在着手整合 Sky 的能力过程中，敬请留意更多更新。

*披露：与 Sam Altman 相关的一只投资基金对 Software Applications Incorporated 持有被动投资。本次收购由 Nick Turley 和 Fidji Simo 主导，并经 OpenAI 董事会独立的交易与审计委员会批准。*
