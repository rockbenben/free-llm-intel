# ChatGPT 广告的新购买方式

我们正在扩展 ChatGPT 广告，为广告主推出新的购买与管理营销活动的方式——并围绕我们的广告原则来构建。

我们正迈出 ChatGPT 广告试点的下一步：让企业更便捷地参与，同时保持体验有用、私密，并与 ChatGPT 的回答清晰区隔。广告主现在可以通过合作伙伴，或全新的自助广告管理工具（Ads Manager）测试版来创建 ChatGPT 广告。我们还引入了按点击付费（CPC）竞价和扩展的效果衡量工具，让企业以更灵活的方式购买、管理和理解营销活动表现，而无需向广告主分享对话或个人信息。这些更新让更多企业更容易参与进来，也为构建一个贴合人们使用 ChatGPT 方式的更广泛广告平台打下基础。

## 扩展企业购买 ChatGPT 广告的途径

起初，我们直接与一小批广告主合作，在 ChatGPT 中投放广告。随着试点扩大，我们通过合作伙伴拓宽了接入渠道，现在又为广告主推出自助工具测试版。

我们一直与领先的代理合作伙伴协作，包括 Dentsu（电通）、Omnicom（宏盟）、Publicis（阳狮）和 WPP，支持企业购买 ChatGPT 广告。我们还增加了 Adobe、Criteo、Kargo、Pacvue 和 StackAdapt 等技术合作伙伴，并将持续投入和扩展我们的伙伴生态。
通过这些合作伙伴，广告主可以用自己已在使用的工具和流程接入 ChatGPT 广告、助力业务增长。这些伙伴协助支持营销活动的预算管理、竞价与广告创意，而所有投放决策由 OpenAI 的广告系统控制。

今天，我们开始逐步推出自助 Ads Manager 测试版，允许广告主注册并直接购买将在 ChatGPT 中展示的广告。

Ads Manager 让各种规模的公司——从中小型企业、初创公司到全球品牌——都能更便捷地通过 ChatGPT 拓展业务。企业可以在该门户注册为广告主、添加支付信息、设置预算、出价与投放节奏、上传广告、启动并管理营销活动、查看表现数据。

随着持续测试和打磨体验，我们将逐步向更多企业开放 Ads Manager。有意了解更多企业可在[此处](https://ads.openai.com/)注册账号。

## 推出 CPC 竞价

在试点的第一阶段，广告主可按 CPM（千次展示成本）购买 ChatGPT 广告，作为在全新环境中初步了解需求、投放和早期表现的一种方式。现在，我们加入按点击付费（CPC）竞价，让广告主的支出与人们看到广告后采取的行动更直接地对齐。

这一点很重要，因为许多 ChatGPT 对话都是主动且指向决策的：人们常在了解某个品类、比较选项或决定下一步做什么。在这些时刻，一次点击是有意义的信号——说明广告切题、帮助某人向前迈进。广告主仅在产生点击结果时被计费。

我们将继续支持 CPM 与 CPC 购买，并预期随时间推移支持更多竞价与优化方式，让广告主为其最看重的结果而优化。

## 开发更多衡量结果的方式

在广告试点期间，被要求最多的能力之一就是更强大的效果衡量，帮助广告主理解表现以及结果的驱动因素。

我们最近上线了转化 API（Conversions API）和基于像素（pixel）的衡量，让广告主更好地理解用户与广告互动之后发生了什么，例如购买、留资、注册或其他有意义的行动。

这些工具的设计目标是在提升衡量的同时保护用户隐私。广告主收到的是聚合的表现洞见，帮助其理解营销活动影响，但无法访问个人对话。

更好的衡量不仅能帮助广告主理解表现，也有助于改善 ChatGPT 使用者的体验。更强的信号帮助我们展示更相关的广告、提升广告匹配质量，并构建对真实结果（而非仅仅曝光量）负责的优化系统。

## 构建 ChatGPT 广告平台

我们在 ChatGPT 上做广告仍处于早期，我们的重心始终是支持更广泛地获取强大 AI，并坚持我们的[原则⁠](https://openai.com/index/our-approach-to-advertising-and-expanding-access/)：ChatGPT 的回答保持独立、对话保持私密、用户始终掌控自己的体验。

当人们用 ChatGPT 探索自己可能的需求、评估选项并做出决策时，我们看到一个令人兴奋的机会：通过广告帮助他们发现相关的产品与服务。未来，我们计划持续演进广告平台，推出新形式、新目标与新能力，帮助企业以有用且贴题的方式触达顾客，并为各种规模的企业提供成长与蓬勃发展的机会。
