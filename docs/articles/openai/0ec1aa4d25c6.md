# 策略梯度与软 Q-learning 之间的等价性

## 摘要

无模型（model-free）强化学习的两大主流方法是策略梯度方法和 Q-learning 方法。Q-learning 方法在可行的情况下可以是高效且样本高效的，然而人们并不很好地理解它们为何有效，因为从经验上看，它们估计出的 Q 值非常不准确。一个部分的解释可能是：Q-learning 方法其实在暗中实现策略梯度更新——我们证明，在熵正则化（entropy-regularized）强化学习的设定下，Q-learning 与策略梯度方法之间存在精确的等价关系，“软”（熵正则化）Q-learning 与一种策略梯度方法完全等价。我们还指出了 Q-learning 方法与自然策略梯度方法之间的联系。在实验上，我们探索了 Q-learning 和策略梯度的熵正则化版本，发现在 Atari 基准上它们的表现与标准版本相当（或略好）。我们还表明这一等价性在实际设定中同样成立：我们构造了一种 Q-learning 方法，在不使用目标网络或 ϵ-greedy 探索调度的情况下，紧密复现了 A3C 的学习动态。
