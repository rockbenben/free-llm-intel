# OpenAI 模型即将登陆 Google Cloud


OpenAI 正与 [Google Cloud](https://cloud.google.com/blog/products/ai-machine-learning/google-cloud-brings-openai-models-to-customers) 合作，将 OpenAI 的前沿模型和 [Codex](http://chatgpt.com/codex/) 智能体工作流引入 Google Cloud 的 Model Garden。此次集成将让客户能够原生访问这些模型，并依托 Google Cloud 的数据治理能力和高性能基础设施，大规模运行复杂的智能体工作流。

Google Cloud 长期投入机器学习和 AI，已成为承载 AI 工作负载的重要平台，吸引了众多构建这些工作负载的开发者和数据科学家。将 OpenAI 模型引入其 Model Garden 后，这些团队便能在现有工作环境中使用 OpenAI 的前沿模型，帮助企业实现软件开发生命周期的现代化、构建智能体工作流，并改变人们的工作方式。

对于受监管行业的组织而言，部署 AI 需要掌控敏感数据的访问权限和使用方式。此次集成将把 OpenAI 的前沿模型与 Google Cloud 内置的访问控制、集中式数据治理和高性能基础设施相结合，支持要求严苛的企业工作负载。

Google Cloud 客户将能够通过 Model Garden 购买 OpenAI 前沿模型，并在 Google Cloud Marketplace 完成交易。已承诺 Google Cloud 消费额度的企业，可将这些采购费用计入其 GCP 承诺消费额。

此外，OpenAI 模型也将很快在 Google Antigravity 和 Gemini Agent 中推出，让企业客户能够灵活选择模型，为每项任务选用最佳模型。通过 Google Cloud 拓宽使用渠道，我们为企业探索和使用前沿模型提供了更多选择，并帮助它们从评估迈向更广泛的应用。

> “Google Cloud 是领先的平台，支持开发者和企业构建 AI 智能体、编写软件并将 AI 付诸应用。通过此次合作，我们将把最强大的模型和 Codex 带到客户已在使用的开发环境中，这是重要的一步。我们将携手壮大智能体生态系统，让客户在如何使用前沿 AI 方面拥有更多选择。”

—Greg Brockman，OpenAI 总裁兼联合创始人

> “我们致力于为客户提供丰富的模型选择，包括 OpenAI 的模型，让他们能为每项任务选择合适的模型，从而帮助他们实现最佳质量并降低成本。”

—Thomas Kurian，Google Cloud 首席执行官
