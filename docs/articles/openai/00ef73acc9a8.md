# 骗局：伪造的俄罗斯“水军”错误消息

OpenAI 封禁了一个很可能源自美国的账号，该账号利用 AI 伪造了一条声称检测到“俄罗斯水军”活动的 ChatGPT 假错误消息。

*本案例研究最初发表于 OpenAI 的*[2024 年 10 月](https://cdn.openai.com/threat-intelligence-reports/influence-and-cyber-operations-an-update_October-2024.pdf)*报告。*

## 行为者

6 月 18 日，X 上的一条帖子看似曝光了一个俄罗斯水军账号：该账号使用 GPT‑4o 的额度已经用尽。这条帖子迅速走红。我们的调查显示，该帖子是一场骗局，不可能出自我们的模型。不过，同一 X 账号更早发布的帖子确实是由我们的模型生成的，显然意在挑起争议。此类活动很可能源自美国。经进一步调查，我们封禁了该 OpenAI 账号；公开报道显示，该 X 账号也已被停用。

## 行为

这场骗局由一个 OpenAI 账号和一个 X 账号共同构成。起初，该 OpenAI 账号使用我们的模型生成简短的对抗性评论，用于回复其他人在 X 上的帖子，随后由该 X 账号发布出去。这类活动发生在 6 月中旬。6 月 18 日，该 X 账号发布了一条看似来自俄语用户的 JSON 错误消息：该用户试图生成支持特朗普总统的内容，但额度已耗尽。这条消息并非由我们的模型生成，看起来是人工伪造的。其中包含一段看似 JSON 的代码片段，但它并不是有效的 JSON，并且对我们模型名称的引用也是错误的。

*假账号（顶部和底部的帖子，已认证账号）与 X 上另一位用户最初的争论。俄语内容大意为：“你要在推特上为特朗普政府唱赞歌，说英语”。（来源）*

这条骗局帖子迅速走红，相关推文被转发数千次，引发 LinkedIn 和 Reddit 上的多帖讨论以及多家媒体问询，甚至出现了对该事件的辟谣。

## 补全内容

就实际使用我们的模型生成的内容而言，该账号背后的行为者针对各种话题向其他 X 用户生成反驳言论，话题从奇幻游戏、摩托车，一直延伸到“世界是不是平的”之类的争论。在大多数情况下，对模型的主要指令就是要“好斗”，比起任何特定意识形态，这才是共同主题。开源情报报道显示，该 X 账号的一条帖子使用了一个歧视残障的词语来贬低与其争论对象的智力。该词语并非由我们的模型生成，看起来是在评论发布前经其他途径加入的。

## 影响评估

这是一个不同寻常的情况，与本报告讨论的其他案例正好相反：不是我们的模型被用于试图欺骗人们，而很可能是非 AI 的活动被用来就“我们模型的使用情况”欺骗人们。如一张截图所示，原始推文获得了 5 次转发、14 次引用和 3 个赞。而围绕这条推文发出的帖子则至少实现了上千倍的扩散——并在其他社交媒体平台上被进一步放大，还引来了主流媒体的问询。按 Breakout Scale（出圈等级），这场骗局处于第 3 类的上限，若主流媒体加以放大，便几乎要进入第 4 类。这是一堂生动的课：社交媒体放大一个投其所好的骗局可以有多快。但它同时也表明，俄罗斯影响力行动曾经拥有的神秘感，已被外界对其能力远为怀疑的看法所取代。这场骗局之所以能吸引受众，一个原因似乎是它迎合了一种信念：俄罗斯水军不仅还是人类，而且有时蠢得可笑。
