借助 Daybreak 开展漏洞研究


过去，Check Point 的漏洞研究流程需要数小时才能完成。据 Check Point 首席技术官 Jonathan Zanger 介绍，作为 OpenAI Daybreak 防御网络的成员，该公司借助 Daybreak 将这项工作的耗时缩短到了几分钟。Daybreak 让防御方能够使用 OpenAI 的前沿网络安全模型，分析漏洞、推演攻击路径，并识别代码和配置中的安全缺口。

Check Point 通过 AI、工作空间、云和网络安全产品，为超过 10 万家组织提供安全防护。Check Point Research 团队凭借漏洞研究专长，调查新出现的漏洞，并将研究成果转化为面向客户的防护措施，支持公司以预防为先的安全策略。Daybreak 加快了这项研究，缩短了从理解漏洞到制定防御措施的过程。

> “OpenAI 正将前沿网络安全智能交到防御方手中，让 Check Point 这样的公司能够将这种智能转化为威胁预防能力。”

—Jonathan Zanger，Check Point 首席技术官

## 将漏洞研究转化为客户防护

“我们看到的网络威胁越来越多，而且这些威胁也越来越复杂，”Zanger 表示。对 Check Point 而言，要跟上威胁的变化，就必须迅速将新披露的漏洞信息转化为客户防护措施。“当新漏洞出现时，我们的职责就是尽快确保客户得到保护，免受其害。”

这项工作依赖专业分析师：他们调查漏洞，将研究结果转化为安全特征或失陷指标，供 Check Point 的系统用于识别威胁。这类研究需要专业知识，而此前团队的研究能力受限于可投入这项工作的分析师人数。

Check Point 使用 OpenAI Daybreak，让这一流程中的更多环节实现自动化。“我们利用 Daybreak 加速这一流程并实现自动化，现在只需几分钟就能完成，而不再需要数小时，”Zanger 表示。这种价值源于模型针对安全问题进行推理的能力。

> “OpenAI Daybreak 能够理解漏洞、分析不同的攻击模式，并扫描代码以识别安全缺口。”

—Jonathan Zanger，Check Point 首席技术官

Zanger 还指出，模型在理解复杂代码和配置、识别系统可能遭受攻击的方式方面，也取得了进展。Check Point 如今认为，这些能力已足够成熟，可以融入其网络安全工作流程。在漏洞研究中，Daybreak 为调查工作提供支持，为制定安全特征或失陷指标提供依据，让分析师能够更快地从理解威胁迈向制定防护措施。

## 借助 Daybreak 构建自主网络安全防御

Check Point 也正在与 OpenAI 合作，利用 Daybreak 开发其智能体网络安全编排解决方案。按照 Zanger 描述的方案，系统将持续监控客户环境，同时遵守明确的操作边界，并在执行影响重大的操作前获得人工批准。客户将设定安全目标，系统则会解释发现的问题、建议采取的措施及相关风险，以便客户决定下一步行动。

如今，漏洞研究只需几分钟就能完成，Check Point 下一步的重点是修复漏洞。该公司希望利用 Daybreak 的能力，让安全团队能够更轻松地修复发现的安全缺口。

> “将 OpenAI 的 Daybreak 与我们现有的安全工作流程相结合，能让自动化达到实时预防威胁的水平。”

—Jonathan Zanger，Check Point 首席技术官

对 Check Point 的客户而言，更快的研究有助于开发针对新发现漏洞的防护措施。借助 Daybreak，Check Point 希望在这些进展的基础上实现更自主的防御，同时由客户设定安全目标，并批准影响重大的操作。
