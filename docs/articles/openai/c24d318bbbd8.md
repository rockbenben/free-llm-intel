# 一致性模型

扩散模型已显著推进图像、音频和视频生成领域，但它们依赖迭代采样过程，导致生成缓慢。为克服这一限制，我们提出一致性模型（consistency models）——一类通过将噪声直接映射到数据来生成高质量样本的新模型族。它们在设计上支持快速单步生成，同时仍允许多步采样，用算力换取样本质量。它们还支持零样本（zero-shot）数据编辑，如图像修复（inpainting）、上色和超分辨率，而无需在这些任务上显式训练。一致性模型既可以通过蒸馏预训练的扩散模型来训练，也可以完全作为独立生成模型训练。通过大量实验，我们证明它们在单步和少步采样上优于现有的扩散模型蒸馏技术，在一步生成上创下 CIFAR-10 FID 3.55、ImageNet 64x64 FID 6.20 的当时最先进水平。当独立训练时，一致性模型成为新的一族生成模型，在 CIFAR-10、ImageNet 64x64 和 LSUN 256x256 等标准基准上可以超越现有的一步、非对抗式生成模型。

**作者**：Yang Song、Prafulla Dhariwal、Mark Chen、Ilya Sutskever
