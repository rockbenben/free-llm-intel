# GPT‑5.6 现已成为 Microsoft 365 Copilot 的首选模型


今天，OpenAI 发布了 GPT‑5.6。它将成为 Microsoft 365 Copilot 在 Word、Excel、PowerPoint、聊天和 Cowork 中新的首选模型。对 Microsoft 365 客户而言，此次更新将 OpenAI 最新的旗舰模型系列带入人们每天使用的生产力工具中，帮助他们在各类工作流中借助更强大的 AI 辅助进行创作、分析和协作。GPT‑5.6 是 OpenAI 最新的旗舰模型系列，能让每个 Token 产出更有用的工作成果，以每美元成本实现更强性能，并可按需处理最复杂的任务。

借助 GPT‑5.6，Microsoft 365 用户可以在他们已经依赖的各个应用中，用更少的力气产出更高质量的工作成果：

- 在 Word 中，GPT‑5.6 可以帮助人们起草、编辑和完善文档，减少提示轮次。
- 在 Excel 中，它可以在更高效使用 Token 的同时支持更深入的分析，帮助用户更快从数据走向洞察。
- 在 PowerPoint 中，它可以帮助将早期想法转化为更精致、更具视觉吸引力的演示文稿，同时减少手动指导。
- 在 Cowork 中，它可以帮助用户完成复杂的跨职能工作，并在减少手动协调的情况下产出更高质量的成果。

“我们迫不及待想让客户看到 Microsoft 365 中的 GPT‑5.6 将带来什么，让他们能在每天使用的工具中更高效地借助 AI 工作，”Microsoft Copilot & Agents Core 总裁 Nitin Agrawal 表示。“借助由 OpenAI 最新模型提供支持的 Copilot，无论客户是在起草文档、分析数据、制作演示文稿，还是开展跨团队协作，都能在 Word、Excel、PowerPoint、Cowork 和 Copilot 聊天中产出更精致的成果。我们很高兴继续与 OpenAI 共同打造更强大的 AI 体验，并将其带给世界各地的个人和组织。”

“每天都有数百万人在 Microsoft 365 中写作、分析、创作和协作，”OpenAI API 产品负责人 Nikunj Handa 表示。“通过 OpenAI API 将 GPT‑5.6 引入 Microsoft 365 Copilot，我们正在帮助组织从每个 Token 中获得更有用的工作成果，并在他们已使用的工具中从 AI 获得更多价值。”

除了以原生方式提供这些模型外，Microsoft 还将通过 API 直接访问 OpenAI 模型，将 GPT‑5.6 带给 Microsoft 365 客户。

我们与 Microsoft 的合作始终旨在将先进 AI 的益处带给更多个人和组织，我们很高兴继续在这一共同承诺之上向前推进。
