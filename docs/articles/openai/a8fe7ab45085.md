# 用 ChatGPT Work 处理数据科学工作流

了解数据科学团队如何借助 ChatGPT Work，把问题、仪表盘和原始数据转化为可供审阅的分析成果。

借助 ChatGPT Work，数据科学团队可以更快地把零散的输入变成可用的分析成果。从仪表盘、指标定义、导出数据、实验笔记和业务背景出发，ChatGPT Work 帮助组装出交付物的第一稿——包括图表、注意事项、来源链接和待评审的问题——让团队能够验证成果并放心分享。
