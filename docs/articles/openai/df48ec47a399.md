# 微调 API 新增视觉能力

开发者现在可以用图片加文本来微调 GPT‑4o，提升视觉能力

***2026 年 5 月 8 日更新****：OpenAI 正在逐步关停微调平台。新用户已经无法访问该平台，但现有用户在未来几个月内仍可创建训练任务。所有微调得到的模型都会继续提供推理服务，直到其基础模型被*[*弃用*](https://developers.openai.com/api/docs/deprecations)*。完整时间线见*[*这里*](https://developers.openai.com/api/docs/deprecations)*。*

今天，我们推出 GPT‑4o[1](https://openai.com/index/introducing-vision-to-the-fine-tuning-api/#citation-bottom-1) 的[视觉微调](http://platform.openai.com/docs/guides/fine-tuning/vision) 能力，让微调除了文本之外也能使用图片。开发者可以定制模型，让它具备更强的图像理解能力，从而支持这样一些应用：增强版视觉搜索、面向自动驾驶或智慧城市的更好目标检测，以及更精准的医学影像分析。

自我们首次在 GPT‑4o 上推出微调以来，已有数十万开发者用纯文本数据集定制我们的模型，以提升特定任务上的表现。但对很多场景来说，只用文本来微调，性能提升达不到预期。

## 工作原理

视觉微调的流程与文本微调相似——开发者可以按[正确格式](https://platform.openai.com/docs/guides/fine-tuning/preparing-your-dataset) 准备自己的图像数据集，然后把数据集上传到我们的平台。开发者最少只用 100 张图片就能提升 GPT‑4o 在视觉任务上的表现，用更大规模的文本与图像数据还能把性能推得更高。

我们与一小批受信合作伙伴协作，以更好理解视觉微调在真实世界里的应用。我们很高兴展示几个他们做出来的例子。

### Grab 提升道路上图像检测与理解的能力

[Grab](https://www.grab.com/sg/) 是头部的送餐与网约车公司，它把司机采集的街景影像转成地图数据，支撑 [GrabMaps](https://www.grab.com/sg/press/tech-product/grab-to-be-fully-powered-by-its-own-mapping-technology-by-q3-2022/)——一项地图服务，为其整个东南亚业务提供底图。只用 100 个样本做视觉微调，Grab 就教会了 GPT‑4o 正确定位交通标志并数出车道分隔线，从而打磨其地图数据。结果是：相比基座 GPT‑4o 模型，Grab 把车道数准确率提升了 20%，限速标志定位准确率提升了 13%，让它原本靠人工的地图生产流程更好地实现了自动化。

一个由视觉微调后的 GPT‑4o 正确标注、而 GPT‑4o 基座模型标注错误的限速标志示例。

### Automat 提升用于自动化业务流程的桌面 bot 成功率

[Automat](https://www.runautomat.com/) 是一家企业自动化公司，构建桌面与网页 agent 来处理文档、基于 UI 执行动作，从而自动化业务流程。借助视觉微调和一批屏幕截图数据集，Automat 训练 GPT‑4o 根据自然语言描述在屏幕上定位 UI 元素，把其 RPA agent 的成功率从 16.60% 提升到 61.67%——相比基座 GPT‑4o 性能提升 272%。此外，Automat 只用 200 张非结构化保险单据图片训练 GPT‑4o，就在信息抽取任务上把 F1 分数提高了 7%。

桌面 bot 用网站截图做视觉微调后，成功识别 UI 元素中心的示例。

### Coframe 提升数字内容创作的质量

[Coframe](https://www.coframe.com/) 正在打造一款 AI 增长工程助手，帮助企业持续创建并测试网站与 UI 的多种变体，以优化业务指标。这项任务的一个核心环节，是根据网站其余部分自主生成符合品牌调性的新板块。Coframe 给 GPT‑4o 的任务是：基于图片和现有代码生成网站的下一个板块。用图片和代码微调 GPT‑4o 后，模型生成"视觉风格一致、布局正确"网站的能力相比基座 GPT‑4o 提升了 26%。

模型需要对齐风格的现有网站。

## 安全与隐私

我们会持续对微调后的模型运行自动化安全评估（safety evals）并监控使用情况，确保应用符合我们的使用政策。与其他所有 API 服务一样，视觉微调受我们的[企业级隐私⁠](https://openai.com/enterprise-privacy/) 承诺约束。微调模型完全由你掌控，业务数据的所有权也完全归你。未经你明确许可，我们不会用本服务的输入或输出来训练我们的模型。

## 可用性与定价

视觉微调能力今天起对所有处于付费[用量等级](https://platform.openai.com/docs/guides/rate-limits/usage-tiers) 的开发者开放。这些能力支持最新的 GPT‑4o 模型快照 `gpt-4o-2024-08-06`。开发者可以用与我们 [Chat 接口](https://platform.openai.com/docs/guides/vision) 相同的格式，把已有的微调训练数据扩展到图像。

到 2024 年 10 月 31 日为止，我们每天免费提供 100 万训练 token 用于图像微调 GPT‑4o。2024 年 10 月 31 日之后，GPT‑4o 微调训练的费用为每 100 万 token 25 美元；推理费用为每 100 万输入 token 3.75 美元、每 100 万输出 token 15 美元。图像输入会先按图像大小被 token 化，然后按与文本输入相同的单 token 价格计费。更多细节见 [API 定价⁠](https://openai.com/api/pricing/) 页面。

要开始使用，请访问[微调控制台](https://platform.openai.com/finetune)，点击"create"，并在基础模型下拉菜单中选择 `gpt-4o-2024-08-06`。要了解如何用图片微调 GPT‑4o，请查看我们的[文档](https://platform.openai.com/docs/guides/fine-tuning#vision)。
