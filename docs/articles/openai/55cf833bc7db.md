# AI 训练如何扩展规模

阅读论文（在新窗口中打开）

我们发现，梯度噪声尺度（gradient noise scale）这一个简单的统计指标，能够在大量任务上预测神经网络训练的可并行程度。由于复杂任务的梯度往往噪声更大，未来更大的 batch size 很可能愈发有用，从而移除 AI 系统进一步增长的一个潜在限制。更广泛地看，这些结果表明神经网络训练不必被视为一门神秘的艺术，而可以被严格化、系统化。

过去几年，AI 研究人员在通过数据并行加速神经网络训练方面取得了越来越多的成功——数据并行把大批数据切分到许多机器上。研究人员已在[图像分类⁠（在新窗口中打开）](https://arxiv.org/abs/1807.11205)和[语言建模⁠（在新窗口中打开）](https://arxiv.org/abs/1808.01371)中成功使用数万的 batch size，在为游玩 Dota 2 的 [RL agent⁠（在新窗口中打开）](https://blog.openai.com/openai-five/)甚至达到了百万级。这些大批次让越来越多的算力可以被高效地投入单个模型的训练，是 AI 训练[算力⁠（在新窗口中打开）](https://blog.openai.com/ai-and-compute/)快速增长的重要助推器。然而，过大的 batch size 会表现出算法收益的急剧递减，而且为何某些任务的这一上限更高、某些更低，并不清楚。[A](https://openai.com/index/how-ai-training-scales/#citation-bottom-A)

我们发现，通过测量梯度噪声尺度——一个量化网络梯度信噪比的简单统计量[B](https://openai.com/index/how-ai-training-scales/#citation-bottom-B)——我们可以近似预测最大可用 batch size。直观地说，噪声尺度衡量的是模型（在训练的给定阶段）所看到的数据变异程度。当噪声尺度小时，并行看大量数据会很快变得冗余；而当它大时，我们仍能从海量 batch 数据中学到很多东西。

这类统计量被广泛用于[样本⁠（在新窗口中打开）](https://en.wikipedia.org/wiki/Sample_size_determination#Estimation_of_a_mean)[量⁠（在新窗口中打开）](https://www.itl.nist.gov/div898/handbook/ppc/section3/ppc333.htm)[选择⁠（在新窗口中打开）](http://www.optimization-online.org/DB_FILE/2011/11/3226.pdf)，也曾被[提出⁠（在新窗口中打开）](https://arxiv.org/abs/1206.1106)在[深度⁠（在新窗口中打开）](https://arxiv.org/abs/1706.05699)[学习⁠（在新窗口中打开）](https://arxiv.org/abs/1610.05792)[中⁠（在新窗口中打开）](https://arxiv.org/abs/1612.05086)使用，但从未在现代训练流程中被系统地测量或应用。我们在上图所示的大量机器学习任务上验证了这一预测，包括图像识别、语言建模、Atari 游戏和 Dota。具体地，我们对所有这些任务在不同 batch size 下做了训练（并分别为每种设置调节学习率），把训练加速效果与噪声尺度的预测值进行比较。由于大批次往往需要细致而昂贵的调参或特殊的学习率调度才能见效，提前知道上限对训练新模型具有重大的实践价值。

我们发现，用一个权衡关系来可视化这些实验结果很有帮助：训练所需的时间（wall time）与训练所用的总算力（与成本成正比）。在很小的 batch size 下，把批次翻倍可以让我们用一半的时间完成训练而不增加算力（我们用两倍的芯片跑一半的时长）。在很大的 batch size 下，更多的并行不再带来更快的训练。曲线中间有一个“拐点”，而梯度噪声尺度能预测拐点出现的位置。

我们绘制这些曲线的方法是：设定一个性能水平（比如在 Atari 游戏 Beam Rider 中得到 1000 分），然后观察在不同 batch size 下训练到该性能所需的时间。在性能目标的许多不同取值下，结果与我们模型的预测都相当吻合。

## 梯度噪声尺度中的规律

我们在梯度噪声尺度中观察到若干规律，为 AI 训练的未来提供了线索。

第一，在我们的实验中，噪声尺度在训练过程中通常会增大一个数量级甚至更多。直观地说，这意味着网络在训练早期学习任务中更“显眼”的特征，后期才学习更精微的特征。例如在图像分类器的情形中，网络可能先学会识别大多数图像中都存在的小尺度特征（如边缘或纹理），之后才把这些碎片组合成猫、狗这样更一般的概念。要看遍边缘或纹理的全部种类，网络只需看少量图像即可，因此噪声尺度较小；而当网络对更大物体的了解更多时，它可以一次处理多得多的图像而不必看到重复数据。

我们看到一些[初步迹象⁠（在新窗口中打开）](https://arxiv.org/pdf/1812.06162.pdf)表明，同一数据集上不同模型之间也存在同样效应——更强的模型有更高的梯度噪声尺度，但只是因为它们达到了更低的损失。因此有证据显示，训练中噪声尺度的增大并不只是收敛的副产物，而是随模型变强而发生。如果这是真的，我们预期未来更强的模型将拥有更高的噪声尺度，因而更易于并行。

第二，主观上更难的任务也更适合并行化。在监督学习的语境中，存在一条从 MNIST 到 SVHN 再到 ImageNet 的清晰递进。在强化学习的语境中，则存在从 Atari Pong 到 [Dota 1v1⁠（在新窗口中打开）](https://blog.openai.com/dota-2/)再到 [Dota 5v5⁠（在新窗口中打开）](https://blog.openai.com/openai-five/)的清晰递进，最优 batch size 相差超过 10,000 倍。因此，随着 AI 进军新的、更难的任务，我们预期模型能够容忍更大的 batch size。

## 意义

数据并行的程度显著影响 AI 能力进步的速度。更快的训练使更强的模型成为可能，并通过更快的迭代加速研究。

在此前的研究《[AI 与算力⁠（在新窗口中打开）](https://blog.openai.com/ai-and-compute/)》中，我们观察到用于训练最大规模 ML 模型的算力每 3.5 个月翻一番，并指出这一趋势由经济因素（在算力上花钱的意愿）与算法上并行训练的能力共同驱动。后一因素（算法可并行性）更难预测，其上限也未被充分理解，但我们的工作代表着将其系统化、定量化的一步。特别是，我们有证据表明：更难的任务、以及同一任务上更强的模型，将允许比我们迄今所见更激进的数据并行，为训练算力的持续快速指数增长提供关键驱动。（这还未考虑近期在[模型并行⁠（在新窗口中打开）](https://arxiv.org/abs/1811.02084)上的进展，后者可能在数据并行之上实现进一步并行）。

训练算力的持续增长及其明显可预测的算法基础，进一步凸显了未来数年 AI 能力快速提升的可能性，并强调了对“确保此类系统[安全可靠⁠（在新窗口中打开）](https://blog.openai.com/concrete-ai-safety-problems/)”以及“[负责任地使用它们⁠（在新窗口中打开）](https://blog.openai.com/preparing-for-malicious-uses-of-ai/)”进行研究的紧迫性。AI 政策的一个核心挑战，将是弄清如何利用此类指标对未来 AI 系统的特征做出预测，并据此设计让社会最大化这些技术收益、最小化其风险的政策。

OpenAI 既致力于持续开展严谨分析，以洞察 AI 的未来走向，也致力于采取行动应对这些分析所提出的问题。

## 脚注

- A：一项与本工作平行开展的补充[研究⁠（在新窗口中打开）](https://arxiv.org/abs/1811.03600)对大批量训练做了细致的实验检验，并详尽地综述了既有文献，澄清了早期工作中的多处不一致。他们发现不同任务之间并行潜力差异显著，我们的工作似乎解释了其中相当大的一部分差异。他们的工作还表明大批量训练不影响泛化。我们相信，像这篇以及[其他⁠（在新窗口中打开）](https://arxiv.org/abs/1712.00409)这样的系统性综述对该领域极具价值，我们致力于持续从事“AI 的科学”研究。
- B：训练神经网络时，我们通常一次只处理一小*批（batch）*数据，因此只能得到真实网络梯度的含噪估计。我们发现*梯度噪声尺度* B_noise=E[|G_true−Ĝ|²] / |Ĝ_true|²（期望取在单个数据点上）估计了最大可用 batch size。当梯度由大小为 B 的批次计算时，估计梯度与真实梯度之间的归一化距离为 E[|Ĝ_B−Ĝ_true|²/|Ĝ_true|²] = B_noise/B。增大 B 不再显著降低梯度噪声的临界点出现在 B ≈ B_noise 处，这也正是训练速度收益开始递减的点。
