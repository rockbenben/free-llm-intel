# OpenAI 与 Target 合作，在零售领域打造 AI 驱动的新体验

**要点：**

- *借助 ChatGPT 内的 Target 应用，顾客可以获得个性化推荐、用多商品购物篮把所需全部加入购物车，并通过 Drive Up（车道取货）、到店自提或配送完成结账。*
- *根据合作，Target 将继续使用 OpenAI API 和 ChatGPT Enterprise 提升员工生产力、增强顾客体验。*
- *Target 加入了一个不断壮大的阵营——超过 100 万家 OpenAI 企业客户正利用 OpenAI 模型支撑其核心产品与平台。*

Target 与 OpenAI 的合作正在深化：全新的 ChatGPT 内 Target 应用即将上线，同时 Target 继续使用前沿模型帮助团队更快、更聪明地工作，并交付出色的顾客体验。

Target 与 OpenAI 的合作是其更大战略的一部分——用技术提升顾客、团队成员和供应商伙伴的体验。它支撑 Target 把 AI 融入业务肌理的目标：让与顾客的交互更简单、更愉悦，并给团队提供削减日常琐事摩擦的智能工具。

“AI 转型的很大一部分正发生在企业内部，Target 是一个绝佳范例，展示了有雄心、有速度的转型是什么样子。”OpenAI 应用业务 CEO Fidji Simo 表示，“我们很高兴与 Target 合作，他们正把智能编织进业务，为客户和员工创造有用且愉悦的体验。”

作为这一努力的一部分，Target 将继续依赖 ChatGPT Enterprise——它被设计为可安全地处理专有数据——来加快工作、摆脱琐事，给团队留出更多创造空间。目前它已在 Target 总部全面铺开，供 18,000 名员工使用。

AI 正在融入 Target 的建设与运营方式。它[支撑](https://corporate.target.com/news-features/article/2025/10/technology-powering-growth)更优的供应链预测、精简门店流程，并驱动更个性化的数字体验。OpenAI 从多个方面支持这些工作：

- Target 的 **Agent Assist** 和 **Store Companion** 帮助客服中心与门店团队用心服务顾客。这些工具即时提供最相关的信息，提升准确性、加快支持速度。而且不只是问答——它们可以进行价格匹配、发起退货，并在聊天中解决各种问题，流畅得如同与一位门店员工交谈。
- Target 的 **Shopping Assistant** 和 **Gift Finder** 使用 AI 驱动的对话与推荐工具简化浏览，并根据收礼人的兴趣、年龄或场合帮助顾客找到个性化礼物建议。
- **Guest Assist** 和 **JOY** 解决方案帮助 Target 顾客和供应商伙伴更快地解决各类问题，必要时还辅以人工支持。JOY 基于 3,000 多条 FAQ 的庞大知识库训练，可即时向供应商提供答复。

这些方案共同展示了 Target 如何用 AI 不只是自动化任务，而是真正增强服务——让顾客更快得到答案，让员工有更多时间投入有意义的互动。

**ChatGPT 里的 Target 应用**

在此基础上，全新的 ChatGPT 内 Target 应用将带来精心策划的对话式购物体验。该应用下周以 beta 形式上线，购物者可以在其中求取灵感、浏览并组合多商品购物篮、购买生鲜食品，并选择自己偏好的履约方式结账——包括 Drive Up、到店自提和配送。

“在 Target，一切都始于顾客，这意味着要在顾客所在的任何地方与他们相遇，包括 ChatGPT 这样的新兴空间——每天有数百万消费者在那里。”Target 执行副总裁兼首席信息与产品官 Prat Vemana 表示，“我们很自豪成为最早把购物带入这一新渠道的零售商之一，与 OpenAI 合作，让通过 ChatGPT 里的 Target 应用发现商品像在逛我们的货架一样轻松愉悦。我们的目标很简单：让每一次交互都自然、有帮助、给人灵感，就像和朋友聊天一样。”

例如，用户可以在 ChatGPT 中@Target 应用并说：“帮我策划一个家庭假日电影之夜”，即刻获得精选建议——舒适毯子、蜡烛、零食、拖鞋等等。用户可以浏览选项、组装完美购物篮，并通过自己的 Target 账户结账。不久后，Target 还将加入 Target Circle 会员关联、当日送达等新功能。

**零售企业规模的合作**

Target 与 OpenAI 的合作反映了其更广泛的战略：不只是使用 AI，而是让业务运行在 AI 之上——提升个性化、加速商品发现、强化运营，创造神奇的顾客体验。这也体现了 Target 在推动整个零售行业更大转变中的角色：领先者正把智能变成客户体验、内部运营和日常工作流的核心部分。

随着 AI 在更多企业中成为基础能力，这类合作展示了零售商如何不仅用智能跟上步伐，更点燃下一波创新与顾客惊喜。而 OpenAI 处于支持这一转变的独特位置，因为我们的平台覆盖 AI 转型的完整弧线——而非单个产品或用例。
