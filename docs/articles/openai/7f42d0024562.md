# 多智能体群体中基于情境的组合性语言的涌现

## 摘要

通过在大规模语料中捕捉统计模式，机器学习推动了自然语言处理的重大进展，包括机器翻译、问答和情感分析。然而，要让智能体与人类进行智能交互，仅仅捕捉统计模式是不够的。本文研究基于情境的组合性语言能否作为在多智能体群体中实现目标的手段而涌现，以及如何涌现。为此，我们提出一个多智能体学习环境和学习方法，促使一种基本的组合性语言涌现。这种语言表现为智能体随时间发出的一串串抽象离散符号，却仍具有连贯结构，拥有确定的词汇和语法。我们还观察到，当语言交流不可用时，指点、引导等非语言交流方式的涌现。
