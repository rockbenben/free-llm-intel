# OpenAI Baselines：DQN

查看代码（在新窗口打开）

配图：Ben Barry

我们开源 OpenAI Baselines——这是我们内部用来复现强化学习算法、并达到与已发表结果相当性能的努力。我们将在未来几个月陆续发布这些算法；今天的发布包含 DQN 及其三个变体。

强化学习的结果很难复现：性能噪声很大，算法有许多活动部件因而容易藏有细微 bug，而且很多论文并不报告所有必要的技巧。通过发布已知可靠的实现（以及创建它们的最佳实践），我们希望确保表面上的 RL 进展绝不来自与有 bug 或调参不足的现有算法版本作比较。

本文包含我们在正确实现 RL 算法时使用的一些最佳实践，以及我们首次发布的细节：[DQN⁠](https://openai.com/index/openai-baselines-dqn/#dqn) 及其三个变体，这些都是由 DeepMind 开发的算法。

## 最佳实践

*与随机基线比较：*在下面的视频中，一个智能体在游戏 H.E.R.O. 中采取随机动作。如果你在训练的早期看到这种行为，就很容易自欺欺人地以为智能体正在学习。所以你应该始终验证你的智能体胜过随机智能体。

*警惕不破坏运行的 bug*：当我们抽查十种流行的强化学习算法重实现时，我们注意到其中六个存在由社区成员发现、并被作者确认的细微 bug。这些 bug 从轻微的——[在某些样本上忽略梯度⁠(在新窗口打开)](https://github.com/devsisters/DQN-tensorflow/issues/16)、或[实现因果卷积时出错⁠(在新窗口打开)](https://github.com/ibab/tensorflow-wavenet/issues/29)——到严重的——[报告高于真实结果的分数⁠(在新窗口打开)](https://github.com/trigeorgis/mdm/issues/6)。

*像你的智能体那样看世界：*和多数深度学习方法一样，对于 DQN 我们倾向于把环境图像转为灰度，以减少训练所需的计算量。这本身也会制造 bug：当我们在 Seaquest 上运行 DQN 算法时，发现我们的实现表现很差。当我们检查环境后，才发觉原因是我们后处理的图像里根本没有鱼，如下图所示。

在把屏幕图像转换为灰度时，我们错误地校准了绿色颜色值的系数，导致鱼消失。发现这个 bug 后，我们调整了颜色值，算法便能再次看到鱼了。

为了将来调试这类问题，Gym 现在含有一个 [play⁠(在新窗口打开)](https://github.com/openai/gym/blob/master/gym/utils/play.py) 函数，让研究者能够轻松地看到 AI 智能体所看到的相同观测。

*先修 bug，再调超参*：调试之后，我们开始校准超参数。我们最终发现，设定 epsilon 的退火调度——一个控制探索率的超参数——对性能影响巨大。我们的最终实现把 epsilon 在前 100 万步降到 0.1，然后在接下来 2400 万步降到 0.01。如果我们的实现里有 bug，那我们很可能为了应付尚未诊断出的故障而调出一组不同的超参数。

*再次核对你对论文的解读*：在 DQN 的 [Nature⁠(在新窗口打开)](https://www.nature.com/nature/journal/v518/n7540/full/nature14236.html) 论文中，作者写道：“我们也发现把更新中的误差项裁剪 [...] 到 -1 和 1 之间很有用。”。这句话有两种解读——裁剪目标，或裁剪计算梯度时的乘性项。前者看似更自然，但它会导致梯度在高误差转移上为零，从而带来次优性能，正如某个 [DQN 实现⁠(在新窗口打开)](https://github.com/devsisters/DQN-tensorflow/issues/16)中所发现的那样。后者才是正确的，并有一个简单的数学解释——[Huber 损失⁠(在新窗口打开)](https://en.wikipedia.org/wiki/Huber_loss)。你可以通过检查梯度是否如你所料来发现这类 bug——在 TensorFlow 中用 [compute_gradients⁠(在新窗口打开)](https://www.tensorflow.org/api_docs/python/tf/train/GradientDescentOptimizer#compute_gradients) 就能轻松做到。

本文中的多数 bug，都是通过反复过代码、并逐行思考哪里可能出错而发现的。每个 bug 事后看都很显然，但即使是有经验的研究者也往往会低估找出实现中所有 bug 需要对代码过多少遍。

## 深度 Q 学习

- [**DQN**⁠(在新窗口打开)](http://www.nature.com/nature/journal/v518/n7540/full/nature14236.html)：一种把 Q 学习与深度神经网络结合的强化学习算法，让 RL 能应用于复杂、高维的环境，如电子游戏或机器人。
- [**Double Q Learning**⁠(在新窗口打开)](https://arxiv.org/abs/1509.06461)：纠正标准 DQN 算法有时会高估与特定动作相关联数值的倾向。
- [**Prioritized Replay**⁠(在新窗口打开)](https://arxiv.org/abs/1511.05952)：扩展 DQN 的经验回放功能，学会回放那些真实奖励与预期奖励显著背离的记忆，从而让智能体能够纠正自己正在形成的错误假设。
- [**Dueling DQN**⁠(在新窗口打开)](https://arxiv.org/abs/1511.06581)：把神经网络拆成两个——一个学会估计每个时间步的价值，另一个计算每个动作的潜在优势，二者合为一个动作-优势 Q 函数。

