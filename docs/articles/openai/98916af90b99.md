# 向美国证券交易委员会（SEC）保密提交 S-1 草案

我们最近保密提交了一份 S-1。我们预计这件事会泄露，所以就直接宣布了。我们尚未决定具体时间；这可能还需要一段时间，因为有些我们想做的事，作为非上市公司可能更容易推进。但这涉及一系列复杂的取舍，而这让我们可以选择在最终证明更合适时更早上市。

*本公告依据经修订的 1933 年《证券法》第 135 条规则发布，并不构成出售任何证券的要约，亦不构成购买任何证券的要约邀请。任何要约、购买要约邀请或任何证券销售，均将根据《证券法》的注册要求进行。*
