# 对抗鲁棒性在扰动类型之间的迁移

## 摘要

我们研究深度神经网络的对抗鲁棒性在不同扰动类型之间的迁移。尽管关于对抗样本的大部分工作聚焦于 L∞ L_∞ L∞​ 和 L2 L_2 L2​ 有界扰动，但这些扰动并不能涵盖攻击者可用的所有扰动类型。本工作针对在 ImageNet 100 类子集上对抗训练的模型，评估了 5 种不同类型的 32 种攻击。我们的实证结果表明，要在很大范围的扰动幅度上进行评估，才能理解对抗鲁棒性是否会在扰动类型之间迁移。我们还证明，对某种扰动类型的鲁棒性未必蕴含、有时甚至损害对其他扰动类型的鲁棒性。鉴于这些结果，我们建议对抗防御的评估应在多样的扰动类型和幅度上进行。
