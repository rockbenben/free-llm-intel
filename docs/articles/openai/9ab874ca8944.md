我们发布新一类强化学习算法——近端策略优化（Proximal Policy Optimization，PPO），表现与最先进方法相当或更好，实现和调参却简单得多。凭借易用和优秀的表现，PPO 已成为 OpenAI 的默认强化学习算法。

[策略梯度方法⁠(opens in a new window)](http://karpathy.github.io/2016-05-31/rl/) 是用深度神经网络做控制近来一系列突破的基石，从[电子游戏⁠(opens in a new window)](https://www.nature.com/nature/journal/v518/n7540/full/nature14236.html) 到 [3D 运动⁠(opens in a new window)](https://arxiv.org/abs/1506.02438) 再到[围棋⁠(opens in a new window)](https://www.nature.com/nature/journal/v529/n7587/full/nature16961.html)。但用策略梯度方法取得好结果很具挑战，因为它们对步长选择非常敏感——太小，进展慢得没救；太大，信号被噪声淹没，或者性能发生灾难性跌落。它们的样本效率也常常很差，学个简单任务要花几百万（甚至几十亿）个时间步。

研究者试图用 [TRPO⁠(opens in a new window)](https://arxiv.org/abs/1502.05477)、[ACER⁠(opens in a new window)](https://arxiv.org/abs/1611.01224) 这类方法消除这些缺陷——通过约束或以其他方式控制策略更新的幅度。这些方法各有取舍——ACER 比 PPO 复杂得多，需要额外编写离策略（off-policy）修正代码和回放缓冲区，而在 Atari 基准上只比 PPO 好一点点；TRPO——虽然对连续控制任务很有用——却难以兼容那些在策略和价值函数之间共享参数、或使用辅助损失函数的算法，而处理 Atari 等视觉输入重要的领域问题正需要这些。

## PPO

监督学习里，我们可以轻松实现损失函数、对它做梯度下降，只需相对少量调参就能非常有信心拿到出色结果。强化学习的成功之路就不这么明显了——算法有许多难以调试的活动部件，要花大力气调参才能得到好结果。PPO 在实现难度、样本复杂度和调参便利性之间取得平衡：它试图在每一步计算一个更新，在最小化损失函数的同时确保与旧策略的偏差相对较小。

我们[此前⁠(opens in a new window)](https://channel9.msdn.com/Events/Neural-Information-Processing-Systems-Conference/Neural-Information-Processing-Systems-Conference-NIPS-2016/Deep-Reinforcement-Learning-Through-Policy-Optimization)详细介绍过 PPO 的一个变体，用自适应 [KL⁠(opens in a new window)](https://en.wikipedia.org/wiki/Kullback%E2%80%93Leibler_divergence) 惩罚来控制每次迭代中策略的变化。新变体使用了一种在其他算法中不常见的新目标函数：

L^{CLIP}(\theta) = \hat{E}_{t}[ min(r_t(\theta))\hat{A}_t, clip(r_t(\theta), 1 - \varepsilon, 1 + \varepsilon) \hat{A}_t ) ]

- θ \theta θ 是策略参数
- E^t \hat{E}_{t} 表示对时间步 t 的经验期望
- rt r_t 是新旧策略下概率的比值
- A^t \hat{A}_t 是时刻 t 的优势估计值
- ε \varepsilon ε 是超参数，通常取 0.1 或 0.2

这个目标实现了一种与随机梯度下降兼容的信赖域（Trust Region）更新方式，并通过去掉 KL 惩罚和自适应更新简化了算法。测试显示，该算法在连续控制任务上表现最佳，在 Atari 上几乎追平 ACER——尽管实现要简单得多。

## Baselines：PPO、PPO2、ACER 与 TRPO

本次发布的 [baselines⁠(opens in a new window)](https://github.com/openai/baselines) 包含 PPO 和 TRPO 的可扩展并行实现，两者都用 MPI 传递数据，都用 Python3 和 TensorFlow。我们还会把用于训练上述机器人的预训练策略加入 [Roboschool⁠](https://openai.com/index/roboschool/) 的 [agent zoo⁠(opens in a new window)](https://github.com/openai/roboschool/tree/master/agent_zoo)。

**更新**：我们还发布 PPO 的 GPU 版实现 PPO2，在 Atari 上比当前 PPO baseline 快约 3 倍。此外我们发布 ACER（带经验回放的 Actor Critic）的实现，一种样本高效的策略梯度算法。ACER 利用回放缓冲区，让每段采样经验能进行多次梯度更新，还使用经 Retrace 算法训练的 Q 函数近似。
