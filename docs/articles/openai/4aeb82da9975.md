# Cognition 借助 GPT‑6 Astra 帮助 Devin 测试自身工作

GPT‑6 Astra 提升 Devin 测试软件并证明其正常运行的能力，旨在帮助工程师减少代码审查、交付更多成果。

Cognition 是 Devin 背后的公司。Devin 是一名自主软件工程师，服务于世界各地的企业，从大型银行到科技初创公司。随着 Cognition 的工程团队编写越来越多的代码，审查这些工作已成为一项挑战。Cognition 认为，GPT‑6 Astra 能够测试自身工作并展示结果，有助于提高代码审查效率。

> “Astra 的一大改进，是它能够测试并证明自己的工作确实如预期般正常运行。”

Walden Yan，Cognition 联合创始人

## 测试软件并展示结果

Cognition 正在将 GPT‑6 Astra 应用于旗下全线产品。Yan 表示：“我们一直在用它改进各类产品，包括 Devin 这一核心云智能体，以及我们的 CLI 和桌面端产品。”

在一个示例中，Devin 使用 Astra 测试一款名为 *Otter Run* 的 iPhone 游戏，并返回游戏在模拟器中运行的录像，同时附上一份报告，说明哪些检查已通过、哪些方面尚未测试。

录像展示应用的运行表现，报告则记录测试范围。工程师可以利用这些输出检查软件的运行方式，并了解仍有哪些问题需要处理。

Yan 表示，Astra 还能帮助 Cognition“更快得多”地回复客户。当客户发来错误截图时，团队可以将其交给使用 Astra 的 Devin；它会修复问题，并返回一张展示修复结果的截图。

## 迈向更少的人工代码审查

Cognition 认为，借助 GPT‑6 Astra 增强测试能力，是提高审查流程效率的一条路径。让 Devin 测试自身工作并提供结果证据，可帮助工程师评估变更，同时减少人工检查代码的工作量。

> “我们预计，随着时间推移，需要人工查看的代码会越来越少，而最终交付的成果会越来越多。对于 GPT-6，我们最期待的正是这一点。”

Walden Yan，Cognition 联合创始人
