# OpenAI Scholars 2019：认识我们的学者

我们这一期八位学者（从 550 名申请者中选出）汇聚了文学、哲学、细胞生物学、统计学、经济学、量子物理和商业创新方面的集体专长。

2019 级学者 Jonathan Michaux。摄影：Blake Tucker

我们的学者正把这些专业背景应用到当前 AI 研究中，并在继续成长为机器学习实践者的过程中记录他们的进展。

这是我们第二期 OpenAI Scholars。他们的项目于二月开始，将在完成一个开源的最终项目时结束。在整个项目期间，学者们通过博客向研究社区分享他们的进展。我们的学者正在努力的一些应用包括：

- 将强化学习应用于机器人操作
- 改进自然语言处理中的推理与推断
- 将强化学习算法应用于情感分析

## 认识这些学者

我们的学者在各个专家领域都展现出核心技术能力，以及自我驱动力——对于这些自主性很强的项目来说，这是关键素养。他们每个人都是以相对新手的身份进入机器学习这一领域的，我们希望他们的进展能展示机器学习有多平易可入。要开启你的学习之旅，可以看看我们的部分[教育资料⁠](https://openai.com/index/spinning-up-in-deep-rl/)。

*感谢 AWS 为学者们提供算力积分。另外感谢我们敬业的社区导师们，他们抽出时间为学者们的项目提供建议。*
