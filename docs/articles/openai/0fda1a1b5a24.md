# 一位天体物理学家如何用 Codex 辅助模拟黑洞

Codex 帮助 Chi-kwan Chan（郑志远）改进并测试模拟黑洞周围电子与离子运动的算法。

黑洞周围的引力极端到一旦靠得足够近，任何东西都无法逃逸——光也不例外。像 Chi-kwan Chan 这样的天体物理学家用计算机模拟和观测来研究黑洞。但当前的算法与算力限制了模拟能达到的真实程度。

借助 Codex，Chan——亚利桑那大学与斯特沃德天文台的研究者——正在攻克这一难题。

他说，黑洞是检验爱因斯坦广义相对论的最佳场所之一。广义相对论目前是我们对引力的最好解释：引力不是把物体互相拉拢的力，而是质量与能量对时空的弯曲。

Chan 是国际事件视界望远镜（EHT）合作组织的成员，该组织在 2019 年发布了首张黑洞照片。团队目前正在采集观测数据，以制作首段超大质量黑洞视频，对象是 M87 星系中心的黑洞。

但要把观测转化为科学理解，需要海量的数据处理、大规模计算工作流，以及能模拟宇宙中最极端物理过程的模拟能力。

由于光无法逃离黑洞，科学家转而研究其周围称为“事件视界”的区域——这是一条物质无法逃逸的边界。“这是一张无法回头的表面，”Chan 说。在这条边界外旋进的会发出光，天体物理学家能够看到、测量并模拟它。

EHT 于 2019 年发布的照片展示了嵌入在事件视界附近炽热等离子体中的黑洞阴影。Chan 参与开发了团队用于解读观测数据的模拟与计算工具。此后，Chan 和同事们持续改进仪器与观测能力，团队正从静态图像走向视频。

一段由超级计算机模拟生成的短视频，展示了银河系中心黑洞周围等离子体的运动。

**应对“螺旋”难题**

Chan 及其团队最大的拦路虎之一，是为黑洞周围的等离子体建模。等离子体是由带电荷的电子和离子组成的炽热物质。

在许多模拟中，科学家把等离子体简化为流体，用熟知的方程来模拟其绕黑洞的运动。这在较稠密、电子与离子不断相互碰撞的等离子体中相当有效。

但在 Chan 等人研究的超大质量黑洞附近，某些区域热而稀薄，粒子极少彼此相遇。“它们几乎不相互碰撞，”他说。取而代之，粒子主要沿磁力线螺旋前进。

要正确模拟这种行为，研究者必须追踪数万亿电子和离子绕黑洞快速盘旋的轨迹。标准模拟必须计算每一个微小的回旋，迫使计算机采用极小的时间步长。

结果，即便世界上最快的超算，也把大部分时间花在这些微小粒子运动的计算上，而不是模拟科学家真正想研究的更大尺度行为。

“几十年来，这限制了我们对黑洞等离子体模拟的真实程度，”Chan 说。

**用 AI 构建更好的数字孪生**

Chan 猜测新的数学技术可以帮助绕过这些限制中的某些。基本思路是从数学上改变模拟追踪粒子运动的方式，使计算机不再必须直接跟踪每一圈微小螺旋。

“但手工探索所有数学可能性要耗费巨量时间，”Chan 说。于是他转向 Codex，帮助推导候选算法并用已知解来检验它们。

Codex 生成了许多可能的方案——并不全对。“但那没关系，”Chan 说。“大多数科学想法都会失败。重要的是这些算法是可检验的。一旦找到有效的一个，它就可能解锁以前不可能的模拟。”

一些 AI 系统会直接给出结果而不展示得出结论所用的步骤。但 Chan 的团队使用 Codex 来提出并实现他们可以检查、测试并在物理上理解的数值方案。

大语言模型仍会犯错，许多科学家对在治疗中研究使用 AI 仍持谨慎态度。但 Chan 认为，科学或许是当今 AI 系统最好的用途之一，正因为科学想法可以被严格检验。

“我们不会因一个想法来自爱因斯坦、来自一位聪明的学生、或来自 AI 模型就接受它，”他说。“只有经过反复检验之后我们才接受。”

Chan 把 AI 视为能帮助研究者探索更多想法、更快测试、加速发现，同时植根于验证与可复现性的工具。

如果 Chan 用 Codex 测试的这些方法成功，新算法终将让科学家能够模拟黑洞周围数万亿的粒子。这将使研究者得以探索几十年来无法触及的物理。
