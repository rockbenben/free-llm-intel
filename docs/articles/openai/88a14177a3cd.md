# OpenAI LP 公司


我们的使命是确保通用人工智能（AGI）造福全人类，主要途径是努力构建安全的 AGI，并把其益处与世界分享。

我们[亲历⁠](https://openai.com/index/openai-five/) [见证⁠](https://openai.com/index/better-language-models/) 了最引人注目的 AI 系统需要最多的[计算能力⁠](https://openai.com/index/ai-and-compute/)——算法创新之外也是如此——于是决定比创立 OpenAI 时的规划更快扩张。未来几年，我们需要在大规模云端算力上投入数十亿美元、吸引并留住顶尖人才、建造 AI 超级计算机。

我们希望在继续服务使命的同时提升募资能力，而我们已知的任何既有法律结构都无法恰到好处地平衡两者。我们的解决方案是创建 OpenAI LP——一种营利与非营利的混合体，我们称之为"有限利润"（capped-profit）公司。

OpenAI LP 的根本设想是：如果我们使命达成，投资者和员工可以获得有上限的回报，这让我们既能募集投资资本，又能以类创业的股权激励吸引人才。但超出该上限的任何收益——如果我们成功，我们预计创造的价值将比应付给 OpenAI LP 投资者和员工的份额高出几个数量级——都归最初的 OpenAI Nonprofit 实体所有。

往后（在本文中以及其他场合），"OpenAI" 指 OpenAI LP（目前雇佣了我们大部分员工），最初的实体称为 "OpenAI Nonprofit"。

## 使命优先

我们把 OpenAI LP 设计成使命优先——确保安全和有益的 AGI 被创造和采用——置于为投资者创造回报之前。

甚至在 OpenAI LP 的结构上，使命也是第一位的。虽然我们寄望于下文所述机制能一直运作到使命完成，但世界变化时我们可能更新实现方式。无论世界如何演变，我们对使命的承诺——法律和个人的——都不改变。

OpenAI LP 的首要信托义务是推进 [OpenAI Charter⁠](https://openai.com/charter/)（宪章）的目标，公司由 OpenAI Nonprofit 的董事会控制。所有投资者和员工签署的协议都约定：OpenAI LP 对宪章的义务永远排第一，即使牺牲其部分或全部经济利益。

我们的员工和投资者文件以这样的紫色大框开头。普通合伙人（general partner）指 OpenAI Nonprofit（法定名称为 "OpenAI Inc"）；有限合伙人（limited partners）指投资者和员工。

同一时间只允许少数董事会成员在合伙企业中持有经济利益。此外，只有在无此类利益的董事会成员之间，才能就有限合伙人利益与 OpenAI Nonprofit 使命可能冲突的事项投票——包括任何向投资者和员工付款的决定。

我们文件中的另一条款规定 OpenAI Nonprofit 保留控制权。

如上所述，投资者和员工的经济回报有上限（上限按每位有限合伙人逐一预先商定）。任何超额收益都归 OpenAI Nonprofit。我们的目标是确保我们成功时创造的大部分价值（无论是金钱还是其他）惠及所有人，所以我们认为这是重要的第一步。我们第一轮投资者的回报上限为其投资额的 100 倍（与我们面对的风险相称），随着进展推进，我们预计后续轮次的这一倍数会更低。

## OpenAI 做什么

我们的日常工作不变。今天我们相信，专注于开发新的 AI 技术而非商业产品，能创造最大价值。我们的结构为长期如何获取回报留下了灵活空间，但我们希望等造出安全的 AGI 之后再考虑这个问题。

OpenAI LP 目前约有 100 名员工，分为三大方向：能力（capabilities，推进 AI 系统能做什么）、安全（safety，确保这些系统符合人类价值观）、政策（policy，确保对此类系统有恰当治理）。OpenAI Nonprofit 治理 OpenAI LP，运营 [Scholars⁠](https://openai.com/index/openai-scholars/)、[Fellows⁠](https://openai.com/index/openai-fellows-interns-2019/) 等教育项目，并主办政策倡议。OpenAI LP 正在（以更快的速度和更大的规模）延续在 OpenAI Nonprofit 启动的开发路线图，该路线图已在[强化学习⁠](https://openai.com/index/openai-five/)、[机器人⁠](https://openai.com/index/learning-dexterity/) 和[语言⁠](https://openai.com/index/better-language-models/) 上产出突破。


## 安全

我们对 AGI 帮助解决人类正在失败、且今天没有明显解法的行星规模问题的潜力感到兴奋。但同时，我们也担心 AGI 引发剧变的可能——无论是机器执行操作者错误指定的目标、恶意人类利用已部署系统，还是失控的经济增长未能改善人类生活。正如我们[宪章⁠](https://openai.com/charter/) 所述，为了避免一场使安全难以优先的竞争竞赛，我们愿意与价值观一致的组织合并（即使这意味着投资者回报减少甚至为零）。
