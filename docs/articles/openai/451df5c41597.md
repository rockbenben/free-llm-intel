# OpenAI 管理团队更新

我们高兴地宣布多项高管职位变动，它们既反映了我们近期的进展，也将确保我们在迈向下一个重要里程碑的途中保持动能。

**Greg Brockman** 将出任总裁（President），这一新职位体现了他独特的组合：既在我们的关键路径上亲自贡献代码，又参与公司战略。他目前专注于训练我们的旗舰 AI 系统。

**Brad Lightcap** 在 OpenAI 的成长中发挥了关键作用，通过统管财务、法务、人员和运营团队，扩展了我们的组织结构、团队和资本基础。他将出任首席运营官（COO）并扩大职责范围，与应用 AI 团队合作，打磨我们的业务与商业战略。他还将继续管理 OpenAI 创业基金（OpenAI Startup Fund）。

**Mira Murati** 在过去 18 个月里出色地领导了我们的研究、产品和合作伙伴职能。最近，她促成了这些职能的协同，推动我们的 [DALL·E⁠](https://openai.com/index/dall-e-2/) 研究成功发布。Mira 将出任首席技术官（CTO），这也反映了她在 OpenAI 这些关键领域中的领导力。

**Chris Clark** 将出任非营利与战略倡议负责人（Head of Nonprofit and Strategic Initiatives）。他将负责 OpenAI 非营利母体的运营，并主导关键战略项目，包括我们与使命契合伙伴的关系。

这些高管背后是一流的团队，他们是 OpenAI 的血脉，不断推动人工智能研究与部署的最前沿。很高兴与公司上下如此出色的人才和领导者共事。我们都对未来充满期待。（而且我们在[招聘⁠](https://openai.com/careers/)！）
