# Rogo 借助 OpenAI o1 扩展 AI 驱动的金融研究

[Rogo](https://rogo.ai/) 是一个企业级 AI 金融平台，正在改变投行、私募股权公司和资产管理公司的工作方式。

通过微调 OpenAI 的模型并整合 S&P Global、Crunchbase、FactSet 等广泛金融数据集，Rogo 为数干名金融专业人士提供实时金融情报，把他们的重心从手工劳动转向高价值决策。

自 2024 年走出隐身状态以来，Rogo 已经：

- 服务超过 **5000 名银行家**，客户包括上市投行和超大型私募股权公司。
- 为分析师每周节省 **10 小时以上**，用于会议准备、公司画像和市场研究等任务。
- 借助 OpenAI 模型驱动其解决方案，年经常性收入（**ARR）增长 27 倍**。

“几十年来一直没有公司真正颠覆金融工作流，”Rogo 联合创始人兼 CTO Tumas Rackaitis 说。“我们打造 Rogo，是为了让它成为每个投行家每天赖以生存的基础工具——就像 Bloomberg，但专注深度金融洞见。”

## 为现代金融公司释放时间与洞见

Rogo 使用 OpenAI 的多种模型交付一个安全方案，直接融入金融专业人士的日常工具流，释放时间用于创收、高杠杆的工作。

在几十个用例中，OpenAI API 让 Rogo 构建的平台能够提供：

- **准确、实时的洞见**：用户几秒内即可从公告文件、会议记录和演示稿中提取可执行洞见，并生成端到端、可直接演示的材料。
- **自动化尽调**：Rogo 整合私有数据室，生成定制化问题清单，提供写作辅助，并帮助跟踪客户互动，每周为分析师节省多达 10 小时，帮助团队更快完成会议准备。
- **协作工作流**：初级和资深从业者都依靠 Rogo 简化构建市场图谱、做竞品分析等任务，使其成为合伙人与分析师共享的资源。

“在用 Rogo 之前，我要花几小时翻遍几十份文档和文件。现在，我需要的数据即时可取，”一家领先上市投行的分析师说。

## 微调 OpenAI 模型以自动化金融工作

Rogo 适配了 OpenAI 的安全模型以应对金融工作的独特挑战。通过微调 OpenAI 模型并整合 S&P Global、Crunchbase、FactSet 等海量数据集，公司能够搜索和分析超过 5000 万份金融文档。

其模型架构分层设计，以平衡性能、成本与用例要求：

- **GPT-4o** 驱动 Rogo 的聊天式问答，并处理深度金融分析。
- **o1-mini** 用于将金融数据上下文化并结构化，以支撑有效搜索。
- **o1** 保留用于评估、合成数据生成和高级推理工作流。

这一思路让 Rogo 通过把例行任务交给较小模型、把最先进能力留给高风险场景来优化成本。一支由前银行家和投资人组成的团队还负责审核并标注数据集，确保面向金融终端用户的准确性与相关性。

Rogo 机器学习（ML）引擎的核心是一个为处理复杂金融工作流而设计的 agent 框架，包括多步查询规划与理解、上下文管理和高效搜索。其输出在桌面、移动和平板上均可访问，方便用户随时获取洞见。

“我们用 OpenAI 最新的模型获取独有的深度复杂金融洞见，这对私募股权公司、对冲基金这类投资基金更有价值，”Rackaitis 说。“这些洞见随后可以蒸馏进更小的模型，提供极致的速度与效率——这对投行这种高速环境至关重要。”

## 以 OpenAI 持续演进的模型驱动增长

Rogo 团队选择 OpenAI，是因为其卓越的推理能力、健壮的 API，以及同时处理通用与领域特定任务的灵活性。

“OpenAI 提供的工具生态——微调、function calling 和多模态能力——确保我们能满足客户现在和未来的复杂需求，”Rackaitis 说。

两个团队还共享一种实验文化。Rogo 由前银行家和投资人组成的部署团队与客户一起实时打磨功能，而 OpenAI 稳定的模型进步让 Rogo 能快速迭代。

Rogo 持续扩展其平台能力。12 月，Rogo 聘请 Joseph Kim 担任 AI 负责人。Joseph 从 Google 的 Gemini 团队加入 Rogo，此前专注于用人类与机器反馈的强化学习改进生成式语言模型。
