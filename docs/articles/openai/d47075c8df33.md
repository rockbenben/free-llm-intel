# Roboschool：机器人学校

我们发布 Roboschool：一套开源的机器人仿真软件，与 OpenAI Gym 集成。


加载中...

Roboschool 提供了一批新的 OpenAI Gym 环境，用于在仿真中控制机器人。其中 8 个环境是既有 MuJoCo 实现的免费替代品，并经过重新调参以产生更真实的运动。我们还加入了若干新的、有挑战性的环境。

Roboschool 还能让你轻松在同一环境里同时训练多个 agent。

[Gym⁠(在新窗口打开)](https://gym.openai.com/) 上线后，我们从许多用户那里听到的一个问题是：[MuJoCo⁠(在新窗口打开)](https://mujoco.org/) 组件需要付费授权（尽管 MuJoCo 最近为个人学习和课程用途增加了[免费⁠(在新窗口打开)](https://www.roboti.us/license.html) 学生授权）。Roboschool 去掉了这个限制，让任何人不管预算多少都能做研究。Roboschool 基于 [Bullet 物理引擎⁠(在新窗口打开)](http://bulletphysics.org/)，这是一个开源、授权条款宽松的[许可证⁠(在新窗口打开)](https://github.com/bulletphysics/bullet3/blob/master/LICENSE.txt) 物理库，也被 [Gazebo⁠(在新窗口打开)](http://gazebosim.org/) 和 [V-REP⁠(在新窗口打开)](http://www.coppeliarobotics.com/) 等其他仿真软件使用。

## 环境

Roboschool 自带 12 个环境，既有 MuJoCo 用户熟悉的任务，也有新的挑战，例如更难的 Humanoid 行走任务和一个双人对战 Pong 环境。我们计划随时间扩充这个集合，也期待社区的贡献。

对于已有的 MuJoCo 环境，除了把它们移植到 Bullet，我们还做了改动使其更真实。下面是我们移植的三个环境，以及它们与原有环境的差异说明。

## 交互式与鲁棒的控制

在此前的若干个 OpenAI Gym 环境里，目标是学出一个行走控制器。但那些环境只涉及这个问题的一个很基础的版本——目标只是往前走。实际上，行走策略会学到一条固定的循环轨迹，让状态空间的大部分从未被访问过。而且最终策略往往非常脆弱：轻轻一推就常常让机器人跌倒。

我们用 3D 人形机器人增加了两个环境，让移动（locomotion）问题更有趣也更具挑战。这些环境要求*交互式控制*——机器人必须朝一面旗帜跑去，而旗子的位置会随时间随机变化。

HumanoidFlagrun 的设计目标是教会机器人减速和转向：要求朝旗子跑去，而旗子位置随机变化。

HumanoidFlagrunHarder 在此基础上允许机器人摔倒，并给它时间重新站起来；每个回合开始时机器人可能是站着的也可能是躺在地上的，而且它会持续被白色方块撞击，被推离自己的路线。

我们为 [HumanoidFlagrun⁠(在新窗口打开)](https://github.com/openai/roboschool/blob/master/agent_zoo/RoboschoolHumanoidFlagrun_v0_2017may.py) 和 [HumanoidFlagrunHarder⁠(在新窗口打开)](https://github.com/openai/roboschool/blob/master/agent_zoo/RoboschoolHumanoidFlagrunHarder_v0_2017may.py) 都附带了训练好的策略。它们走得没有常规 humanoid 那么快、那么自然，但这些策略能从很多困境中恢复，而且会转向。这个策略本身仍然是一个没有内部状态的多层感知机，所以我们认为在某些情况下，agent 会用它的手臂来存储信息。

## 多人

Roboschool 支持在同一环境里同时运行和训练多个 agent。我们从 RoboschoolPong 起步，后续还会有更多环境。

在多人训练下，你可以让同一个 agent 分别代表双方来对打（也就是自己和自己玩），也可以用同一套算法训练两个不同的 agent，甚至可以让两套算法互相对抗。

多智能体设定带来一些有趣的挑战。如果同时训练双方玩家，你多半会看到这样一条学习曲线——它来自某种策略梯度方法：

Pong 的学习曲线，双方策略由同时运行的策略梯度算法更新。

事情经过是这样的：

- Agent1（绿色）学会了有时能打到上方的球，于是它总往上方移动。
- Agent2（紫色）发现对手在上方，于是把球发到底部，并过拟合于"对方不在这一侧"。
- Agent1 最终发现自己移动到底部就能防守，但从此它一直待在底部，因为 Agent2 总是把球发到底部。

就这样，两个策略来回振荡，训练好几个小时都没学到任何有用的东西。和生成对抗网络一样，在对抗设定中学习很棘手；但我们认为这是个有趣的研究问题，因为即使在简单环境里，这种互动也能演化出精妙的策略，还能自然形成课程（curriculum）。
