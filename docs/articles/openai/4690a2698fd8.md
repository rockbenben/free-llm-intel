# 运用人工智能拓展经济机遇

Fidji Simo - CEO, Applications


每当与人们讨论人工智能时，最常被问及的问题便是：“这对我的工作意味着什么？”或“它将如何影响我的公司？”

我的回答是：我相信人工智能将为更多人带来比历史上任何其他技术更多的机遇。它既能帮助企业提升运营效率，也能让每个人都将创意转化为收入，更将催生许多当今尚未出现的全新职业。

但人工智能也将带来颠覆性影响。工作形态将发生改变，企业必须适应新形势，从轮班工人到首席执行官，我们所有人都必须学习如何以新的方式开展工作。

在 OpenAI，我们无法回避这种颠覆性影响。但我们*能够*做到的是帮助更多人熟练掌握人工智能，并将他们与需要其技能的公司联系起来，从而为人们提供更多经济机遇。

这一切始于技术普及，正因如此，每周数亿使用 ChatGPT 的用户中，绝大多数都可免费享受这项服务。我们希望让尽可能多的人掌握人工智能并受益于这项技术。但同样重要的是，确保这些人懂得*如何*运用人工智能来提升工作效率、塑造周边世界，并以全新方式掌控自己的命运。

正因如此，我们正与众多组织携手合作，从沃尔玛、约翰迪尔等大型雇主，到波士顿咨询公司、埃森哲等专业服务机构，再到求职招聘平台 Indeed，以及德克萨斯州商业协会、湾区委员会等社区组织，乃至特拉华州州长办公室等政府机构，共同助力所有人把握人工智能带来的机遇。我们正携手推进两项重大举措：

首先，我们正在努力构建 **OpenAI 招聘平台**。

无论是企业需要招聘精通人工智能的员工，还是个人寻求特定任务的协助，找到合适人选并非易事。OpenAI 招聘平台将汇聚各层级经验丰富的专业候选人才，为所有希望施展技能者提供机遇。我们将运用人工智能技术，助力精准匹配企业需求与劳动者能力。

值得注意的是，该招聘平台不仅是大企业吸引人才的渠道，更设有专项通道助力本地企业提升竞争力，同时帮助地方政府发掘所需的人工智能人才，从而更好地服务民众。例如，德克萨斯州商业协会希望借助该平台，将数千家德州雇主与能够助力企业实现现代化的人才联系起来。

我们也意识到，无论通过招聘平台还是其他渠道招聘，雇主都需要确信候选人真正精通人工智能技术。大多数企业（包括小型企业）都认为人工智能是其未来发展的关键。我们接触的大多数公司都希望确保员工掌握使用我们工具的方法。

这正是我们推出全新 **OpenAI 认证**计划的初衷。

[研究表明](https://www.bcg.com/publications/2024/gen-ai-increases-productivity-and-expands-capabilities)，精通人工智能的员工比缺乏人工智能技能的员工更具价值、更高效，且收入更高。正因如此，我们在今年早些时候推出了 OpenAI Academy，这是一个免费在线学习平台，已帮助超过 200 万人获得掌握人工智能工具所需的资源、研讨会和社区支持。

如今我们将进一步拓展 OpenAI Academy，推出不同级别的人工智能熟练度认证体系，涵盖从职场基础应用到人工智能定制化岗位，再到提示工程设计等技能。我们显然将运用人工智能技术来教授人工智能技能：任何人都能在 ChatGPT 的学习模式下备考认证，并且在应用内即可获得资质认证。企业还可将此项认证纳入自身学习与发展计划。

OpenAI 承诺到 2030 年前为 1,000 万美国公众提供认证服务。我们将与启动合作伙伴共同推进此项计划，其中包括全球最大私营雇主：沃尔玛。沃尔玛指出：

*“在沃尔玛，我们深知零售业的未来不仅取决于技术本身，更取决于懂得运用技术的人才。通过为员工提供人工智能培训，我们将当代最强大的技术交予他们手中，赋予他们改写行业规则、塑造零售未来的能力。” 
*—John Furner，沃尔玛美国公司首席执行官

我们意识到，提升技能或再培训项目的效果好坏参半，并非总能带来更好的工作或更高的收入。但通过深入研究过往成败经验，我们正在设计项目，以更好地满足员工与企业的需求。例如，依托我们的启动合作伙伴和招聘平台，我们确保培训内容紧密围绕雇主的实际需求和所需员工技能，从而更高效地实现人才供需匹配。我们正在采用更注重实质性技能培养的方式来开展培训，而不是传统的点击式认证。

这些新举措的推出，也是我们响应白宫提升全民人工智能素养号召的具体实践。在持续构建这些项目的同时，我们将继续专注于满足劳动者和雇主的需求。

这一切的核心在于我们致力于打造什么样的未来。如果我们希望让更多人而不仅仅是少数幸运者掌握更多能力，就必须帮助所有人在各个层面都能抓住人工智能带来的机遇。我们还有很长的路要走，但这是迈向理想征途的重要一步。
