# Rox“全押”OpenAI

Rox 将商业经验与深厚的 LLM 专业能力同 OpenAI 的模型相结合，让每位销售都成为前 1% 的顶尖销售。

[Rox⁠（在新窗口中打开）](https://www.rox.com/) 正在重塑销售团队管理与增长营收的方式。其平台把碎片化数据整合为统一的事实记录系统（system of record），并通过由 OpenAI 驱动的、全天候运行的 AI agent 集群交付洞见。

Rox 团队具备 AI 与数据集成方面的深厚专长。Rox 联合创始人兼 AI 负责人 Avanika Narayan 从其博士研究中汲取经验——她将 LLM 应用于数据整理、工作流自动化等企业任务。

“我们看到营收团队中有丰富的人际互动与协作，但意识到它们必须扎根于数据，”她分享道。由此形成了三层愿景：事实记录系统、工作流系统，以及 AI 驱动的助手——并用 OpenAI 的 API 将其变为现实。

## 回应营收团队不断演进的需求

对 Rox 而言，2024 年创业不仅关乎时机，更关乎机遇。按用量计费模式的兴起、销售运营向 AI 驱动的转型，暴露出许多营收团队体系中的缺口。

OpenAI 的 API 赋予 Rox 足够的灵活性，能处理从数据清洗、长工作流到面向市场进入（go-to-market）策略的细腻销售触达的一切工作。“使用 OpenAI 的 API 让我们能创造新事物，为 GTM 工作流注入创造力，”Rox 的创始 AI 工程师之一 Amol Singh 指出。

平台的设计立于三层：

- **数据层：** Rox 使用 GPT‑4o mini 这样的小模型，把来自各数据仓库的碎片化数据统一起来，使其结构化、易检索。
- **智能层：** 中档模型执行复杂推理并排定行动优先级，与销售代表协作、增强其任务。
- **交互层：** GPT‑4o 等高级模型和 OpenAI Realtime API 生成邮件、管理 LinkedIn 触达、准备支持语音的会议简报。

核心是“Rox Agent Swarm（agent 集群）”——一支为每个客户账户配备的全天候 AI agent 队伍。

销售代表离线时，agent 持续监控账户；工作时间内，它们通过接手重复性任务、浮现可执行的洞见，让代表生产力提升 50%。

## 构建 Rox：由顶尖销售经验定义的可配置营收平台

Rox 的创业历程由早期实验与客户反馈塑造。团队起初探索了一个开放式聊天界面，但发现它不符合销售的需求；“销售需要的是贴合其特定工作流的方案，输出要更有创造力、更独特，”Rox 的创始 AI 工程师之一 Alex Derhacobian 说。

团队转而打造一个端到端可配置的平台，每个 agent 都适配该代表的具体客户与工作流。

这一路径得益于与 Ramp、Couchbase、Confluent 等公司的合作，还通过将顶尖销售的最佳实践沉淀进 Rox 平台，把高绩效销售的专业能力扩展到整个团队。

团队把加速开发归功于日更迭代的路线。“按传统做法，这需要多名数据工程师和一整个团队。我们两个人就做到了，这要感谢 OpenAI 的模型，也让构建变得容易太多，”Singh 说。

## 销售接受管道翻倍

使用 Rox 的销售团队报告了显著提升：

- **每周节省 8 小时以上：** 代表重新拿回了此前耗在行政事务上的时间，得以聚焦更高价值的客户互动。
- **客户互动提升 35%：** agent 帮助代表随时响应关键账户变化，在要紧时刻主动触达。
- **销售管道 2 倍 ROI：** beta 客户看到销售接受管道（sales-accepted pipeline）翻倍增长，促使许多团队在更大范围推广 Rox、并增加在平台上管理的账户数量。

Rox 在企业客户中迅速获得牵引力，七个月内从 0 增长到 25 个账户。

Rox 的平台构建于 OpenAI 之上，数据取自公开可得的信息。

## 选择对的伙伴共建

OpenAI 的模型是 Rox 方法的核心，让各类任务都能灵活构建 AI 方案。“OpenAI 有一整个模型库供你选择，能力各异、价格各异，”Narayan 说。

这种灵活性让 Rox 可以为数据处理部署高性价比模型，把高档模型留给复杂推理任务。

Rox 的联合创始人分享了构建高效 AI 方案的三条关键经验：

- **先建坚实的数据层：** “最重要的是把数据层搭好，解决上下文管理问题，”Derhacobian 分享道。对半结构化和非结构化数据建立索引，才能确保洞见可执行。
- **专注应用 AI：** Rox 选择与 OpenAI 合作而非自研模型。“我们不是来做研究或造基础模型的。我们与 OpenAI 合作，交付出色的应用，”Rox 联合创始人兼 CEO Ishan Mukherjee 说。
- **快速迭代：** 现代应用 AI 允许更快的节奏。“我们几乎每天发布，”Rox 的创始 AI 工程师之一 Damon Lin 说，他们把成功归功于持续迭代。

## 用 OpenAI 释放 GTM 营收潜力

Rox 设想这样一个未来：营收团队从一天开始到结束都在平台上完成，全副武装地拥有有效触达客户所需的洞见与支持。

团队计划扩展 Rox 的多模态能力和长周期任务辅助。一项由 OpenAI Realtime API 驱动的语音新功能，已经在帮助销售以详尽的实时简报准备会议。

携手 OpenAI，Rox 将持续赋能由人主导的销售职能，最大化 GTM 营收潜力。
