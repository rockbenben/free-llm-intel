# Atlassian 与 OpenAI 深化合作，将企业知识转化为行动

正在加载…

Atlassian 与 OpenAI 正在深化合作，将 GPT‑6 系列前沿模型引入 Atlassian 平台的各个部分，为 AI 体验提供支持，帮助团队规划、开发并交付工作成果。两家公司能力的结合，将为双方的共同客户提供更多使用 Atlassian 产品和 OpenAI 的方式。

根据一项新协议，OpenAI 前沿模型将为 Atlassian 平台及 Rovo 中的各类智能体提供支持。Rovo 将 OpenAI 的智能能力与 Atlassian 的 Teamwork Graph 相结合。Teamwork Graph 是一个企业上下文层，将人员、项目、文档和决策关联起来，让 AI 深入理解公司的运作方式。

此次深化合作延续了双方自 2023 年开始的协作，同时，Atlassian 也在扩大自身对 Codex 和 ChatGPT Enterprise 的应用。超过 3,000 名 Atlassian 开发者在终端、IDE 和代码审查工作流中使用 Codex。通过由 Teamwork Graph 支持的 Atlassian 插件，Codex 用户可以访问相关工作项和技术文档，帮助开发者编写、测试和交付软件。

随着 OpenAI 持续提升模型能力、效率和性价比，这项协议让 Atlassian 能够更广泛地使用最新的 OpenAI 前沿模型，包括 GPT‑6 Astra 和 GPT‑5.6 系列。

> “将 OpenAI 的前沿能力与 Atlassian 的 Teamwork Graph 相结合，能让企业工作充分融入组织内部的丰富背景信息。在我们构建开放平台的过程中，此次合作的深化让客户能够将全球领先的模型无缝融入日常工作，使其扎根于实际业务场景。”

—Jamil Valliani，Atlassian AI 产品负责人

> “将 OpenAI 前沿模型与 Atlassian 相结合，能够把强大的智能体能力整合到企业实际运营的场景中。通过这项合作，我们让团队更容易从了解工作情况迈向采取行动。”

—Nikunj Handa，OpenAI API 产品负责人

随着合作不断深化，OpenAI 将继续依靠 Jira 协助管理公司各部门的关键工作流。两家公司致力于携手将前沿智能引入企业现有的工具，让 AI 智能体自然融入团队的工作方式。

## 将 OpenAI 模型与企业知识相连接

通过 OpenAI API，Atlassian 能够随着模型的进步，将新的推理能力直接引入 Rovo，让客户在现有工具中使用能力日益强大的 AI。

例如，正在筹备产品发布的产品经理可以询问 Rovo，团队是否在按计划推进。借助 Teamwork Graph，Rovo 可以关联 Jira 工单、Confluence 文档和相关讨论，识别工程开发中的阻碍，标记未按时达成的里程碑，并呈现需要关注的决策。OpenAI 模型帮助将这些信息转化为清晰的发布准备情况评估和后续行动建议，让团队减少汇总梳理信息的时间，把更多精力用于推进工作。

双方的合作还延伸到了 Atlassian 自有产品之外。通过适用于 ChatGPT 和 Codex 的 Atlassian 插件及 Teamwork Graph CLI 插件，客户可以将 ChatGPT 和 Codex 接入现有工作流，让 AI 在相应权限范围内访问相关项目信息、文档和开发上下文。

最近，Atlassian 推出了[插件扩展⁠（在新窗口中打开）](https://community.atlassian.com/forums/discussion/3288784/bring-your-atlassian-work-into-chatgpt-and-codex)，可将 Jira 工作项、Confluence 内容和人员信息直接引入 ChatGPT 和 Codex 的提示词中。其固定显示的 Atlassian Home 还展示了已分配的工作、近期的 Loom 视频、项目和 Bitbucket 拉取请求，帮助团队获取相关背景信息并采取行动。

## 迈向新一代 AI 驱动的团队协作

两家公司正在探索与 Jira 更深入的集成，让团队能够更轻松地向 AI 智能体分配工作、跟踪进度、记录决策并审查结果。结合 Atlassian 用于衡量开发者生产力和工程效能的平台 DX，这些能力有望帮助工程负责人衡量 AI 对开发速度、周期时长和开发者体验的影响，同时确保控制权始终掌握在人类手中。
