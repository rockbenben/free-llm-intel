# 生成式模型

Illustration: Ludwig Pettersson

Loading…

本文介绍四个共享同一主题的项目：增强或使用生成式模型——机器学习中无监督学习技术的一个分支。除了介绍我们的工作，本文也会带你更多了解生成式模型：它们是什么、为什么重要、未来可能走向哪里。

我们在 OpenAI 的核心愿望之一，是开发出能让计算机理解我们这个世界算法和技术。

你很容易忘记自己其实知道这么多：你理解世界由三维环境构成，物体会移动、碰撞、互动；有人会走、会说、会思考；动物会吃草、会飞、会跑、会叫；显示器上呈现着用语言编码的信息——天气如何、谁赢了篮球赛、1970 年发生了什么。

浩如烟海的信息就在那里，而且大部分容易获取——要么在原子的物理世界里，要么在比特的数字世界里。唯一棘手的，是开发出能分析、理解这座数据宝藏的模型和算法。

**生成式模型是通向这一目标最有希望的路径之一**。训练生成式模型，我们先在某个领域收集大量数据（想象数百万张图像、句子或声音等），然后训练一个模型去生成与之相似的数据。这背后的直觉可以用 Richard Feynman 的一句名言概括：

> "What I cannot create, I do not understand."（我不能创造的，我也就不理解。）

Richard Feynman

诀窍在于：我们用作生成式模型的神经网络，其参数量远小于训练数据量，所以模型被迫去发现并高效内化数据的本质，才能把数据生成出来。

生成式模型有很多近期[应用⁠](https://openai.com/index/generative-models/#going-forward)。但从长远看，它们有潜力自动学习数据集的自然特征——不管是类别、维度，还是别的什么。

## 生成图像

举个具体例子。假设我们有一个庞大的图像集合，比如 [ImageNet⁠(opens in a new window)](http://www.image-net.org/) 数据集的 120 万张图（记住，将来这可能是来自互联网或机器人的海量图像或视频集合）。如果像通常那样把每张图缩放到宽高 256，我们的数据集就是一大块 `1,200,000x256x256x3`（约 200GB）的像素。这是数据集中的几张示例图：

这些图像是我们的视觉世界长什么样的例子，我们称之为"来自真实数据分布的样本"。现在我们来构建生成式模型，希望训练它从零开始生成这样的图像。具体来说，本例中的生成式模型可以是一个输出图像的大型神经网络，我们把这些输出称为"来自模型的样本"。

## DCGAN

一个这样的近期模型是 Radford 等人的 [DCGAN 网络⁠(opens in a new window)](https://github.com/Newmu/dcgan_code)（见下图）。这个网络的输入是从[均匀分布⁠(opens in a new window)](https://en.wikipedia.org/wiki/Uniform_distribution_(continuous)) 抽取的 100 个随机数（我们称之为*码*（code），或*潜变量*，图中红色），输出一张图（这里是右侧 64x64x3 的图像，绿色）。随着码逐步变化，[生成的图像⁠(opens in a new window)](https://github.com/Newmu/dcgan_code#walking-from-one-point-to-another-in-bedroom-latent-space) 也随之变化——这表明模型学到了描述世界长相的特征，而不是死记硬背一些样本。

网络（黄色）由标准的[卷积神经网络⁠(opens in a new window)](http://cs231n.github.io/convolutional-networks/) 组件构成，比如[反卷积层⁠(opens in a new window)](http://datascience.stackexchange.com/questions/6107/what-are-deconvolutional-layers)（卷积层的反向）、[全连接层⁠(opens in a new window)](http://cs231n.github.io/convolutional-networks/#fc) 等：

DCGAN 以随机权重初始化，所以随便输入一个随机码只会生成完全随机的图像。但如你所想，网络有几百万个可调参数，目标是找到一组参数，让随机码生成的样本看起来像训练数据。换句话说，我们希望模型分布在图像空间上与真实数据分布吻合。

## 训练生成式模型

假设我们用刚初始化的网络生成 200 张图，每次用不同的随机码。问题是：该如何调整网络参数，让它未来产生更可信的样本？注意我们并不处于简单的监督设定，对这 200 张生成图没有任何显式的*期望目标*；我们只想让它们看起来真。绕开这个问题的巧妙办法是[生成对抗网络（GAN）⁠(opens in a new window)](http://arxiv.org/abs/1406.2661) 的思路。我们引入第二个*判别器*网络（通常是标准卷积神经网络），尝试判断输入图像是真实还是生成的。比如，把 200 张生成图和 200 张真实图喂给判别器，把它当标准分类器训练来区分两种来源。但这还不是全部——关键在这里——我们还可以穿过判别器和生成器一起[反向传播⁠(opens in a new window)](http://neuralnetworksanddeeplearning.com/chap2.html)，求出该如何修改生成器的参数，让它那 200 张样本更能迷惑判别器。于是两个网络陷入了一场博弈：判别器努力分辨真假，生成器努力制造让判别器信以为真的图。最终，生成器网络输出的图像在判别器眼中与真实图像无法区分。

匹配这两个分布还有一些别的办法，下文简单讨论。但在展开之前，先看两段生成式模型样本的动画，直观感受一下训练过程。两种情形下，生成器的样本都从噪乱开始，随时间收敛到更可信的图像统计特性：

VAE 学习生成图像（对数时间）

GAN 学习生成图像（线性时间）

这令人兴奋——这些神经网络正在学习视觉世界长什么样！这些模型通常只有约 1 亿参数，所以在 ImageNet 上训练的网络必须把 200GB 像素数据（有损地）[压缩⁠(opens in a new window)](http://prize.hutter1.net/) 进 100MB 的权重。这激励它去发现数据中最显著的特征：比如它会学到相近的像素往往同色，世界由水平或垂直边缘、不同色块构成。最终，模型可能发现更多复杂规律：存在某些类型的背景、物体、纹理，它们以某些可能的布局出现，或在视频里随时间以某些方式变化等等。

## 更一般的表述

数学上，我们把示例数据集 x1,…,xn x_1, \ldots, x_n x1​,…,xn​ 看作来自真实数据分布 p(x) p(x) p(x) 的样本。下面这张示例图里，蓝色区域表示图像空间中高概率（超过某阈值）包含真实图像的部分，黑点是我们的数据点（每个都是数据集中的一张图）。我们的模型同样描述了一个分布 p^θ(x) \hat{p}_{\theta}(x) p^​θ​(x)（绿色），它由如下方式隐式定义：从单位[高斯分布⁠(opens in a new window)](https://en.wikipedia.org/wiki/Normal_distribution)（红色）取点，再通过（确定性的）神经网络——我们的生成式模型（黄色）——映射。我们的网络是带参数 θ \theta θ 的函数，调整这些参数就会调整生成的图像分布。于是我们的目标就是找到参数 θ \theta θ，产生一个与真实数据分布高度吻合的分布（例如让[KL 散度⁠(opens in a new window)](https://en.wikipedia.org/wiki/Kullback%E2%80%93Leibler_divergence)[损失⁠(opens in a new window)](https://en.wikipedia.org/wiki/Loss_function) 很小)。因此，你可以想象绿色分布一开始是随机的，训练过程迭代地调整参数 θ，把它拉伸、挤压，让它更好地贴合蓝色分布。

## 生成式模型的三种进路

多数生成式模型都是这个基本框架，差别在细节。这里举三个流行的方法让你感受一下多样性：

- [生成对抗网络（GANs）⁠(opens in a new window)](http://arxiv.org/abs/1406.2661)，上文已讨论过，把训练过程表述为两个独立网络之间的博弈：一个生成器网络（如前所述）和一个判别网络，后者试图把样本分类为来自真实分布 p(x) p(x) p(x) 还是模型分布 p^(x) \hat{p}(x) p^​(x)。每当判别器发现两个分布的差异，生成器就稍微调整参数把差异抹掉，直到最后（理论上）生成器精确复现真实数据分布，判别器只能随机猜，找不到任何差异。
- [变分自编码器（VAEs）⁠(opens in a new window)](https://arxiv.org/abs/1312.6114) 让我们把这个问题放到[概率图模型⁠(opens in a new window)](https://en.wikipedia.org/wiki/Graphical_model) 框架里表述，目标是最大化数据对数似然的[下界⁠(opens in a new window)](https://en.wikipedia.org/wiki/Variational_Bayesian_methods)。
- 自回归模型，如 [PixelRNN⁠(opens in a new window)](http://arxiv.org/abs/1601.06759)，转而训练一个网络，对每个像素、以其之前的像素（左侧和上方）为条件建模条件分布。这类似于把图像的像素喂进 [char-rnn⁠(opens in a new window)](http://karpathy.github.io/2015-05-21/rnn-effectiveness/)，只不过 RNN 在图像上横竖两个方向跑，而不是一维字符序列。

所有这些思路各有利弊。例如，VAE 让我们能在带潜变量的复杂概率图模型中同时完成学习和高效贝叶斯推断（例如参见 [DRAW⁠(opens in a new window)](https://arxiv.org/abs/1502.04623)，或体现近期较复杂模型苗头的 [Attend Infer Repeat⁠(opens in a new window)](http://arxiv.org/abs/1603.08575)）。但其生成的样本往往略微模糊。GAN 目前生成最锐利的图像，但因训练动态不稳定而更难优化。PixelRNN 的训练过程非常简单稳定（[softmax 损失⁠(opens in a new window)](https://en.wikipedia.org/wiki/Softmax_function)），目前给出最好的对数似然（即生成数据的可信度）。但采样时效率较低，也不便为图像提供简单的低维*码*。这些模型都是活跃的研究领域，我们很期待它们未来的发展！

## 我们近期的贡献

OpenAI 对生成式模型非常兴奋，刚刚发布了四个推进前沿的项目。每项贡献我们都同时发布技术报告和源代码。

[**改进 GAN**⁠(opens in a new window)](https://arxiv.org/abs/1606.03498)（[代码⁠(opens in a new window)](https://github.com/openai/improved-gan)）。如前所述，GAN 是很有前景的一族生成式模型：与其他方法不同，它们产出的图像干净锐利，学到的码也包含关于纹理的宝贵信息。但 GAN 被表述为两个网络间的博弈，让它们保持平衡很重要（也很难！）：比如它们可能在解之间振荡，生成器也倾向于坍缩。在这项工作中，Tim Salimans、Ian Goodfellow、Wojciech Zaremba 等同事提出了若干让 GAN 训练更稳定的新技术。这些技术让我们能把 GAN 规模化，得到漂亮的 `128x128` ImageNet 样本：

除了生成好看的图，我们还引入了一个用 GAN 做[半监督学习⁠(opens in a new window)](https://en.wikipedia.org/wiki/Semi-supervised_learning) 的方法：让判别器额外输出一个输入类别标签。这个方法让我们在 [MNIST⁠(opens in a new window)](http://yann.lecun.com/exdb/mnist/)、[SVHN⁠(opens in a new window)](http://ufldl.stanford.edu/housenumbers/) 和 CIFAR-10 上、在标注样本极少的设定下取得了最先进结果。比如在 MNIST 上，每类只用 10 个有标签样本、配合全连接神经网络就达到 99.14% 准确率——与用全部 60,000 个有标签样本做全监督的最好结果非常接近。这一点非常有前景，因为在实践中有标签样本往往代价高昂。

生成对抗网络是相对新的模型（两年前才提出），我们预期在提升其训练稳定性方面还将看到更快速的进展。

[**改进 VAE**⁠(opens in a new window)](http://arxiv.org/abs/1606.04934)（[代码⁠(opens in a new window)](https://github.com/openai/iaf)）。在这项工作中，Durk Kingma 和 Tim Salimans 引入了一种灵活、可计算扩展的方法，提升[变分推断⁠(opens in a new window)](https://www.cs.jhu.edu/~jason/tutorials/variational.html) 的精度。具体来说，此前大多数 VAE 用粗糙的[近似后验⁠(opens in a new window)](http://www.cs.princeton.edu/courses/archive/spr06/cos598C/papers/chapter2.pdf) 训练，其中每个潜变量相互独立。[近期扩展⁠(opens in a new window)](http://arxiv.org/abs/1505.05770) 通过在链中让每个潜变量以其之前的变量为条件来应对这一问题，但引入的序贯依赖使计算低效。这项工作的核心贡献——*逆自回归流*（inverse autoregressive flow，IAF）——是一种新思路：与以往工作不同，它能并行计算丰富近似的后验，并让其灵活度几乎任意。

[**InfoGAN**⁠(opens in a new window)](https://arxiv.org/abs/1606.03657)（[代码⁠(opens in a new window)](https://github.com/openai/InfoGAN)）。Peter Chen 等同事提出 InfoGAN——GAN 的扩展，能学到解耦、可解释的图像表示。普通 GAN 达成了复现数据分布的目标，但码空间的布局和结构是*未指定*的——把单位高斯映射到图像有很多可行解，最后得到的那个可能错综复杂、高度纠缠。InfoGAN 通过加入新目标为该空间施加额外结构：最大化表示变量小子集与观测之间的[互信息⁠(opens in a new window)](https://en.wikipedia.org/wiki/Mutual_information)。这个方法的结果相当出色。例如下面的 3D 人脸图中，我们只改变码的一个连续维度、固定其余。从每行的五个示例可以清楚看出，所得的码维度捕捉到了可解释的维度——模型或许已经*理解*了存在相机角度、表情变化等概念，而没有任何人告诉它这些特征存在、很重要：

我们也注意到，此前已有工作获得过漂亮的解耦表示（如 Kulkarni 等人的 [DC-IGN⁠(opens in a new window)](https://arxiv.org/abs/1503.03167)），但那些方法依赖额外监督，而我们的方法是完全无监督的。

接下来两个近期项目处于[强化学习⁠(opens in a new window)](https://en.wikipedia.org/wiki/Reinforcement_learning)（RL）设定（OpenAI 另一个[聚焦⁠](https://openai.com/index/openai-gym-beta/) 领域），但都包含生成式模型组件。

[**通过贝叶斯神经网络实现好奇心驱动的深度强化学习探索⁠(opens in a new window)**](http://arxiv.org/abs/1605.09674)（[代码⁠(opens in a new window)](https://github.com/openai/vime)）。在高维连续空间中高效探索，是强化学习至今未解决的挑战。没有有效的探索方法，我们的智能体会[到处乱撞⁠(opens in a new window)](http://karpathy.github.io/2016-05-31/rl/)，直到随机撞进有奖励的情境。这在许多简单玩具任务里够用，但如果想把这些算法应用到高维动作空间的复杂场景（机器人领域常见），就远远不够。在这篇论文中，Rein Houthooft 等同事提出 VIME——一种利用生成式模型不确定性做探索的实用方法。VIME 让智能体自我激励：主动寻找令人意外的状态-动作。我们展示了 VIME 能改进一系列[策略搜索⁠(opens in a new window)](https://en.wikipedia.org/wiki/Reinforcement_learning#Direct_policy_search) 方法，并在奖励稀疏的更现实任务中取得显著进展（例如智能体必须在没有任何引导下学会运动基本技能的情形）。

最后，我们想额外收录一个"第五项目"：[**生成式对抗模仿学习⁠(opens in a new window)**](http://arxiv.org/abs/1606.03476)（[代码⁠(opens in a new window)](https://github.com/openai/imitation)），Jonathan Ho 等同事在其中提出*模仿学习*的新方法。Jonathan Ho 今夏作为实习生加入 OpenAI。这项工作在斯坦福完成大部分，我们把它作为 GAN 在 RL 上一个相关且极具创造力的应用收录于此。标准强化学习设定通常要求你设计一个奖励函数来描述智能体的期望行为。但实践中，为了把细节调对，往往要经历昂贵的试错。相比之下，模仿学习让智能体从示范样本中学习（例如机器人遥操作提供的示范），省去了设计奖励函数。

流行的模仿方法采用两阶段流水线：先学一个奖励函数，再对它跑 RL。这样的流水线可能很慢，而且因为间接，很难保证最终策略表现好。这项工作展示如何借助与 GAN 的联系，直接从数据中提取策略。因此该方法可以在困难的 [OpenAI Gym⁠(opens in a new window)](https://gym.openai.com/) 环境上、用专家示范（不带奖励）学习策略，如 [Ant⁠(opens in a new window)](https://gym.openai.com/envs/Ant-v1) 和 [Humanoid⁠(opens in a new window)](https://gym.openai.com/envs/Humanoid-v1)。

## 展望未来

生成式模型是一个快速推进的研究领域。随着我们持续改进这些模型、扩大训练和数据集规模，我们可以预期最终能生成完全可信的图像或视频样本。这本身就能用于许多应用，比如按需生成艺术，或"把我的笑容调大一点"这样的 Photoshop++ 命令。目前已知的其他应用还包括[图像去噪⁠(opens in a new window)](https://math.berkeley.edu/~sethian/2006/Applications/ImageProcessing/noiseremoval.html)、[图像修复（inpainting）⁠(opens in a new window)](https://en.wikipedia.org/wiki/Inpainting)、[超分辨率⁠(opens in a new window)](https://en.wikipedia.org/wiki/Super-resolution_imaging)、[结构化预测⁠(opens in a new window)](https://en.wikipedia.org/wiki/Structured_prediction)、强化学习中的[探索⁠(opens in a new window)](https://en.wikipedia.org/wiki/Reinforcement_learning#Exploration)，以及在标注数据昂贵时用于神经网络[预训练⁠(opens in a new window)](http://image.diku.dk/shark/sphinx_pages/build/html/rest_sources/tutorials/algorithms/deep_denoising_autoencoder_network.html)。

然而，这项工作的更深层承诺在于：在训练生成式模型的过程中，我们将赋予计算机对世界及其构成的理解。
