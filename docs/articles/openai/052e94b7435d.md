# 11 月 6 日来旧金山参加 OpenAI 首届开发者大会

线下参会的开发者注册将在数周后开放，全球开发者都可观看主题演讲直播。

请在 2023 年 11 月 6 日莅临旧金山，参加我们的首届开发者大会 OpenAI DevDay。

这场为期一天的活动将把来自世界各地的数百名开发者与 OpenAI 团队聚在一起，抢先体验新工具、交流想法。线下参会者还可以参加由 OpenAI 技术人员主持的分论坛。

自 2020 年推出 API 以来，我们持续更新它以纳入最先进的模型，让开发者只需一次简单的 API 调用，就能以前所未有的便利把前沿 AI 集成到自己的项目中。今天，超过 200 万开发者正在把 GPT-4、GPT-3.5、DALL·E 和 Whisper 用于广泛的用例——从[把智能助手集成进现有应用⁠](https://openai.com/index/introducing-chatgpt-and-whisper-apis/)，到构建[全新的应用⁠](https://openai.com/index/function-calling-and-other-api-updates/)以及[前所未有的服务⁠](https://openai.com/index/gpt-3-5-turbo-fine-tuning-and-api-updates/)。

“我们期待展示我们的最新成果，帮助开发者构建全新的东西，”OpenAI CEO Sam Altman 表示。

欲了解更多，请访问 [devday.openai.com](https://devday.openai.com)，并注册订阅提醒，数周后开放报名时将通知你。有意线下参会的媒体请联系 [devdaypress@openai.com⁠](mailto:devdaypress@openai.com)。
