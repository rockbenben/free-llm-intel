# 隆重推出 GPT Store

我们将推出 GPT 商店，帮助您找到有用且流行的 ChatGPT 定制版本。

## This page covers the GPT Store launch.

For the current ChatGPT experience and workspace capabilities:



Explore ChatGPT Work


我们[发布 GPT⁠](https://openai.com/index/introducing-gpts/) 已经两个月了，用户已经创建了超过 300 万个 ChatGPT 定制版本。许多创建者分享了他们的 GPT 供他人使用。今天，我们开始向 ChatGPT Plus、Team 和 Enterprise 用户推出 GPT Store，这样您就可以找到有用和流行的 GPT。请访问 [chatgpt.com/gpts⁠（在新窗口中打开）](https://chatgpt.com/gpts/) 进行浏览。

## 发现商店中的流行趋势

商店提供由我们的合作伙伴和社区开发的各种 GPT。在社区排行榜上浏览流行和趋势 GPT，包括 DALL·E、写作、研究、编程、教育和生活方式等类别。

## 每周新增特色 GPT

我们还将重点介绍有用和有影响力的 GPT。我们的首批特色 GPT 包括：

- 来自 [AllTrails⁠（在新窗口中打开）](https://chat.openai.com/g/g-KpF6lTka3-alltrails) 的个性化路径推荐
- 使用 [Consensus⁠（在新窗口中打开）](https://chat.openai.com/g/g-bo0FiWLY7-researchgpt) 搜索和综合 2 亿篇学术论文的结果
- 利用可汗学院的 [Code Tutor⁠（在新窗口中打开）](https://chat.openai.com/g/g-HxPrv1p8v-code-tutor-khanmigo-lite) 扩展您的编码技能
- 使用 [Canva⁠（在新窗口中打开）](https://chat.openai.com/g/g-alKfVrz9K-canva) 设计演示文稿或社交文章
- 用 [Books⁠（在新窗口中打开）](https://chat.openai.com/g/g-z77yDe7Vu) 查找下一本读物
- 使用 [CK-12 Flexi⁠（在新窗口中打开）](https://chat.openai.com/g/g-cEEXd8Dpb-ck-12-flexi) AI 辅导员随时随地学习数学和科学知识

## 在商店中加入您的 GPT

创建您自己的 GPT 非常简单，不需要任何编码技能。

如果您想在商店中分享 GPT，您需要：

- 将您的 GPT 保存为 **Everyone**（**任何人的链接**都不会在商店中显示）。
- 验证您的生成器配置文件（**设置** → **生成器配置文件** → **启用您的姓名或经过验证的网站**）。

请查看我们最新的[使用政策⁠](https://openai.com/policies/usage-policies/)和 [GPT 品牌指南⁠](https://openai.com/brand/#gpts-in-chatgpt)，以确保您的 GPT 符合规定。为了帮助确保 GPT 遵守我们的政策，除了我们在产品中内置的现有安全措施外，我们还建立了一个新的审核系统。审核过程包括人工审核和自动审核。用户还[可以举报⁠（在新窗口中打开）](https://help.openai.com/en/articles/8554982-how-can-i-report-an-inappropriate-gpt) GPT。

## 构建者可根据 GPT 使用情况获得收益

我们将在第一季度推出 GPT 构建者收入计划。作为第一步，美国构建者将根据用户对其 GPT 的参与度获得报酬。随着时间的推移，我们将提供有关支付标准的详细信息。

## Team 和 Enterprise 客户可以管理 GPT

今天，我们宣布了面向各种规模团队的新 [ChatGPT Team⁠（在新窗口中打开）](https://chatgpt.com/business/business-plan) 套餐。Team 客户可以访问 GPT Store 的私人部分，其中包括安全发布到您工作区的 GPT。GPT Store 即将面向 [ChatGPT Enterprise⁠（在新窗口中打开）](https://chatgpt.com/business/enterprise) 客户推出，将包括增强的管理控制功能，如选择如何共享内部 GPT 以及哪些外部 GPT 可以在您的企业内部使用。与 ChatGPT Team 和 Enterprise 的所有用途一样，我们不会使用您与 GPT 的对话来改进我们的模型。

在 [chatgpt.com/gpts⁠（在新窗口中打开）](https://chatgpt.com/gpts) 探索 GPT。
