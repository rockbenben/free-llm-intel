# 权重归一化：一种加速深度神经网络训练的简单重参数化

## 摘要

我们提出权重归一化（weight normalization）：对神经网络中权重向量的一种重参数化，把权重向量的长度与其方向解耦。通过以这种方式重参数化权重，我们改善了优化问题的条件数，并加快了随机梯度下降的收敛。我们的重参数化受批归一化（batch normalization）启发，但不会在 mini-batch 的样本之间引入任何依赖。这意味着我们的方法也能成功应用于 LSTM 这类循环模型，以及深度强化学习或生成模型等对噪声敏感、批归一化不太适合的应用。尽管我们的方法简单得多，它仍能提供接近完整批归一化的大部分加速。此外，我们方法的计算开销更低，允许在相同时间内执行更多优化步。我们在监督图像识别、生成建模和深度强化学习等应用中展示了本方法的有效性。
