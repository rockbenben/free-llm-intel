# GPT‑5 系统卡更新：GPT‑5.2

阅读系统卡


## 介绍

GPT‑5.2 是 GPT‑5 系列中最新的模型家族，相关说明请参阅我们的[博客⁠](https://openai.com/zh-Hans-CN/index/introducing-gpt-5-2/)。该模型采用的全面安全缓解机制，与 [GPT‑5 系统卡⁠](https://openai.com/zh-Hans-CN/index/gpt-5-system-card/)和 [GPT‑5.1 系统卡⁠](https://openai.com/zh-Hans-CN/index/gpt-5-system-card-addendum-gpt-5-1/)中所描述的内容基本一致。

在本系统卡中，我们也将 GPT‑5.2 Instant 称为 gpt-5.2-instant，将 GPT‑5.2 Thinking 称为 gpt-5.2-thinking。
