# Neural MMO：一个大规模多智能体游戏环境

我们发布 Neural [MMO⁠（在新窗口中打开）](https://en.wikipedia.org/wiki/Massively_multiplayer_online_game)——一个面向强化学习 agent 的大规模多智能体游戏环境。我们的平台支持数量庞大且可变的 agent，处于一个持久、开放式结束的任务之中。众多 agent 与物种的存在带来了更好的探索、分化出的生态位形成，以及更高的整体能力。

近年来，多智能体场景已成为深度强化学习研究的有效[平台⁠（在新窗口中打开）](https://www.pommerman.com/)[：⁠（在新窗口中打开）](https://arxiv.org/abs/1902.00506)[⁠（在新窗口中打开）](https://arxiv.org/abs/1207.4708)[⁠（在新窗口中打开）](https://blog.openai.com/openai-five/)[⁠（在新窗口中打开）](https://www.nature.com/articles/nature24270)[⁠（在新窗口中打开）](https://deepmind.com/blog/capture-the-flag/)。尽管有此进展，多智能体强化学习仍面临两大挑战。我们需要创造复杂性上限极高的开放式任务：现有环境要么复杂但[过于⁠](https://openai.com/five/)[狭窄⁠（在新窗口中打开）](https://deepmind.com/blog/alphastar-mastering-real-time-strategy-game-starcraft-ii/)，要么开放但[过于⁠（在新窗口中打开）](https://arxiv.org/abs/1712.00600)[简单⁠（在新窗口中打开）](https://arxiv.org/abs/1709.04511)。持久性和大规模群体等属性至关重要，但我们还需要更多**基准环境**，以在存在大规模群体与持久性的条件下量化学习进展。大型多人在线游戏（MMO）这一游戏类型模拟了一个由可变数量玩家组成、在持久广阔环境中竞争的大型生态体系。

为应对这些挑战，我们构建 Neural MMO 时满足以下标准：

- **持久性（Persistence）**：agents 在其他学习中的 agent 共存的条件下同时学习，环境不重置。策略必须考虑长时间跨度，并适应其他 agent 行为可能发生的快速变化。
- **规模（Scale）**：环境支持庞大且可变的实体数量。我们的实验在 100 个并发服务器上，各让 128 个并发 agent 运行至多达 1 亿次生命周期。
- **效率（Efficiency）**：计算入门门槛很低。我们能在单台桌面 CPU 上训练出有效策略。
- **扩展性（Expansion）**：与现有的 [MMO⁠（在新窗口中打开）](https://oldschool.runescape.com/)[⁠（在新窗口中打开）](https://worldofwarcraft.com/en-us/)[⁠（在新窗口中打开）](https://en.wikipedia.org/wiki/Massively_multiplayer_online_game) 类似，我们的 Neural MMO 设计上可随新内容更新。当前核心特性包括：基于瓦片地形的程序化生成、食物与水源觅食系统，以及策略性战斗系统。未来存在开源驱动扩展的空间。

## 环境

**玩家**（*agents*）可以加入任何可用的**服务器**（*环境*），每台服务器包含按可配置规模自动生成的瓦片游戏地图。一些瓦片（如盛产食物的森林瓦片和草地瓦片）可通行，另一些（如水面和实心岩石）不可通行。agents 在环境边缘的随机位置出生。为了维持生命值，它们必须获取食物和水，并避免来自其他 agents 的战斗伤害。踏入森林瓦片或靠近水面瓦片会分别补充 agent 的食物或水的一部分。但森林瓦片的食物供给有限，只能缓慢随时间恢复。这意味着 agents 必须争夺食物瓦片，同时定期从无限的水面瓦片补水。玩家使用三种战斗风格交战，为增添风味分别称为*Melee（近战）、Range（远程）和 Mage（法师）*。

**输入**：agents 观察以自身当前位置为中心的正方形瓦片裁剪区域，包括瓦片地形类型和其中 agents 的部分属性（生命、食物、水和位置）。

**输出**：agents 输出下一个游戏 **tick**（*时间步*）的动作选择。动作由一次移动和一次攻击组成。

## 模型

作为简单基线，我们使用[朴素策略梯度⁠（在新窗口中打开）](https://spinningup.openai.com/en/latest/algorithms/vpg.html)训练一个小型全连接架构，仅有的增强是价值函数基线和奖励折扣。我们不为达成特定目标给予 agent 奖励——agent 只优化其**寿命**（*轨迹长度*）：其寿命中每存活一个 tick 获得奖励 1。我们通过对所有玩家取最大值，把变长观测（例如周围玩家列表）转换为定长向量（[OpenAI Five⁠](https://openai.com/five/) 也用了这个技巧）。源码发布包含我们的完整分布式训练实现，基于 [PyTorch⁠（在新窗口中打开）](https://pytorch.org/) 和 [Ray⁠（在新窗口中打开）](https://ray.readthedocs.io/en/latest/#)。

## 评估结果

agents 的策略从若干**群体**中均匀采样——不同群体中的 agents 共享架构，但只有同一群体内的 agents 共享权重。初步实验表明，agent 的能力随多智能体交互的增加而提升。增大并发玩家数量上限会放大探索；增加群体数量会放大生态位形成——即各个群体散布到地图不同区域觅食的趋势。

### 服务器合并锦标赛：多智能体互动放大能力

MMO 界并没有跨多台服务器评估玩家相对能力的标准流程。不过，MMO 服务器有时会进行合并——把多台服务器的玩家群体放进同一台服务器。我们通过合并不同服务器上训练出的玩家群体，实现了“锦标赛”式评估，从而可以直接比较不同实验设置下学到的策略。我们改变测试时的规模，发现在更大设置中训练的 agents 始终胜过更小设置中训练的 agents。

### 群体数量增加放大探索

在自然界中，动物之间的竞争会促使它们分散开来以避免冲突。我们观察到地图覆盖率随并发 agent 数量增加而上升。agents 之所以学会探索，只是因为其他 agent 的存在为此提供了天然激励。

### 物种数量增加放大生态位形成

在足够大、资源足够丰富的环境中，我们发现随着群体数量增加，不同群体的 agents 会彼此分离、散布于地图上以避免竞争。由于实体无法在与自己共享权重的同伴（即同群体 agents）的竞争中胜出，它们倾向于寻找资源足以养活本群体的地图区域。DeepMind 的[并行多智能体研究⁠（在新窗口中打开）](https://arxiv.org/abs/1812.07019)也独立观察到了类似效应。

## 其他洞见

我们通过把一个 agent 固定在假设地图裁剪区域的中心，来可视化 agent 之间的依赖关系：对该 agent 可见的每个位置，我们展示如果该处存在第二个 agent，价值函数会是什么。我们发现，无论在觅食还是战斗环境中，agents 学到的策略都依赖于其他 agents 的策略。仅仅训练几分钟后，agents 就学会了“靶心”式回避图，从而更有效地开始觅食。随着 agents 掌握环境的战斗机制，它们开始恰当地评估有效交战距离和接近角度。

## 下一步

我们的 Neural MMO 解决了以往游戏环境的两个关键局限，但还有许多尚未解决。这个 Neural MMO 在[环境⁠](https://openai.com/five/)[复杂度⁠（在新窗口中打开）](https://deepmind.com/blog/alphastar-mastering-real-time-strategy-game-starcraft-ii/)与[群体⁠（在新窗口中打开）](https://arxiv.org/abs/1712.00600)[规模⁠（在新窗口中打开）](https://arxiv.org/abs/1709.04511)之间取得了折中。我们设计这一环境时就以开源扩展为目标，供研究社区在其上继续建设。
