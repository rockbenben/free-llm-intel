# 深度线性网络中的非线性计算


我们已经证明，深度线性网络——以浮点算术实现——实际上并非线性，而是能执行非线性计算。我们用[进化策略⁠](https://openai.com/index/nonlinear-computation-in-linear-networks/#ES) 在线性网络中寻找利用这一特性的参数，让我们得以解决非平凡的问题。

神经网络由"线性层 + tanh 或 ReLU 之类的非线性"层层堆叠而成。如果没有非线性，连续的线性层在理论上与单个线性层数学等价。所以浮点算术的非线性程度竟足以训练出深度网络，是一件令人意外的事。

## 背景

计算机使用的数字不是完美的数学对象，而是用有限比特做的近似表示。计算机常用浮点数来表示数学对象。每个浮点数由尾数和指数组合表示。在 IEEE 的 float32 标准中，尾数用 23 位，指数用 8 位，符号位 1 位。

Image Credit: [Wikipedia⁠(opens in a new window)](https://en.wikipedia.org/wiki/Single-precision_floating-point_format)

由于这些约定和所用的二进制格式，最小的正规非零数（二进制）是 *1.0..0 x 2^-126*，下文我们称之为 *min*。而下一个可表示的数是 *1.0..01 x 2^-126*，可以写成 *min + 0.0..01 x 2^-126*。不难看出，第 2 个数与第 1 个数之间的间隔，比 0 到 min 的间隔小了 2^20 倍。在 float32 中，当数小于最小可表示数时会被映射为零。由于这种"下溢（underflow）"，在零附近，所有涉及浮点数的计算都变得非线性。

这些限制的一个例外是[次正规数（denormal numbers）⁠(opens in a new window)](https://en.wikipedia.org/wiki/Denormal_number)，在某些计算硬件上可以被禁用。虽然 GPU 和 cuBLAS 默认启用 denormals，TensorFlow 的所有原语都编译时关闭了 denormals（设置 `ftz=true` 标志）。这意味着任何用 TensorFlow 写的非矩阵乘法运算都自带隐式非线性（前提是计算尺度接近 1e-38）。

所以，虽然一般而言任意"数学"数与其标准浮点表示的差别很小，但在零附近存在一个大缺口，近似误差可能非常显著。

这会导致一些熟悉的数学规则失效的奇特现象。例如，(a+b)×c (a + b) \times c (a+b)×c 不再等于 a ×c+b× c \times c + b \times c ×c+b× c

例如设 a=0.4×min a = 0.4 \times min a=0.4×min，b=0.5×min b = 0.5 \times min b=0.5×min，c=1/ min c = 1 / min c=1/ min。

那么：(a+b)×c=(0.4×min+0.5×min)×1/min=(0+0)×1/min=0 (a+b) \times c = (0.4 \times min + 0.5 \times min) \times 1 / min = (0 + 0) \times 1 / min = 0 (a+b)×c=(0.4×min+0.5×min)×1/min=(0+0)×1/min=0。然而：(a×c)+(b×c)=0.4×min/min+0.5×min×1/min= 0.9 (a \times c) + (b \times c) = 0.4 \times min / min + 0.5 \times min \times 1 / min = 0.9 (a×c)+(b×c)=0.4×min/min+0.5×min×1/min= 0.9。

再举一例，设 a=2.5×min a = 2.5 \times min a=2.5×min，b=−1.6×min b = -1.6 \times min b=−1.6×min，c=1× min c = 1 \times min c=1× min。

那么：(a+b)+c=(0)+1×min=min (a+b) + c = (0) + 1 \times min = min (a+b)+c=(0)+1×min=min。然而：(b+c)+a=(0×min)+2.5×min=2.5× min (b+c) + a = (0 \times min) + 2.5 \times min = 2.5 \times min (b+c)+a=(0×min)+2.5×min=2.5× min。

在最小的尺度上，基本的加法运算已经变成非线性了！

## 用进化策略利用非线性

我们想知道这种固有非线性能否被当作计算非线性来利用——那样深度线性网络就能做非线性计算。挑战在于，现代自动微分库对这种最小尺度上的非线性"视而不见"。因此，靠反向传播训练神经网络来利用它们是困难甚至不可能的。

我们可以用[进化策略（ES）⁠(opens in a new window)](https://blog.openai.com/evolution-strategies/) 在不依赖符号微分的情况下估计梯度。用 ES 我们确实能把 float32 的近零行为当作计算非线性来利用。在 MNIST 上，通过反向传播训练的深度线性网络训练准确率 94%、测试准确率 92%；而同一个线性网络用 ES 训练、并确保激活值足够小、落在 float32 的非线性区间时，可以达到 99% 以上训练准确率和 96.7% 测试准确率。训练表现的提升源于 ES 利用了 float32 表示中的非线性。这些强大的非线性让任意一层都能生成新特征——底层特征的非线性组合。网络结构如下：
