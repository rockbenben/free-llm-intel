# LifeVal

衡量 AI 在日常生活的真正重要任务上的进步。

OpenAI 的使命，是确保通用人工智能（AGI）惠及全人类。对于目前每周使用 ChatGPT 的超过十亿人而言，我们希望打造出能够帮助人们应对日常生活实际挑战的 AI，比如寻找托儿服务、办理政府事务、制定预算、为入学做准备、改良菜谱、订购生鲜杂货、设计健身计划等等。

当一个人希望有人帮忙让生活更轻松时，他需要的不只是建议，或者一段聊天回复。要成为一个真正有用的个人助手，ChatGPT 应当能够采取行动，把事情真正办成。

为了衡量模型在日常任务上随时间推移的表现，我们构建了一套任务评测，覆盖了用户最希望从 AI 和个人 agent 那里获得帮助的那些领域。在过去一年里，我们用这套评测来跟踪并推动模型在日常任务上性能的提升。

## 背景

为了找出人们最看重的任务，我们从两项追踪美国及全球各地人们如何分配时间的大型研究入手：[American Time Use Survey](https://www.bls.gov/tus/) 和 [Multinational Time Use Study](https://www.timeuse.org/mtus)。这两份数据集合在一起，提供了一份详尽的日常生活任务目录，覆盖不同人群、不同时段、不同季节里人们所做的事。为了弄清人们在哪些地方最看重 AI 的帮助，我们在这些已有调查的基础上，新增了一项覆盖 3,995 名受访者、在人口结构上具有代表性的调查。针对每一项任务，我们设计了一系列问题，用来识别普通人最希望从个人助手那里获得帮助的领域。由此得到的任务涵盖了人们最想获得帮助的最重要领域，包括照护、健康、教育、家庭事务管理、个人理财、购物，以及办理政府事务。

## 为什么这很重要

要确保 AGI 惠及全人类，我们就需要衡量并提升模型在关乎普通人生活之事上的进步。这意味着要超越对模型知识的学术测评，真正去衡量 AI 模型在帮助人们应对决策、管理日常事务、把有意义的事情办成方面做得有多好。我们希望 LifeVal 是朝这一目标迈出的一步。
