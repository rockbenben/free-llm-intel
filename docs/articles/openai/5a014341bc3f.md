# 生命值

衡量人工智能在日常生活中重要任务上的进展。

OpenAI 的使命是确保通用人工智能造福全人类。对于目前每周使用 ChatGPT 的超过 10 亿人，我们希望构建人工智能来帮助应对日常生活中的实际挑战，例如寻找托儿服务、获得政府服务、制定预算、为上学做准备、修改食谱、订购杂货、设计锻炼计划等等。

当有人寻求帮助让他们的生活更轻松时，他们需要的不仅仅是建议或聊天回复。要成为真正有帮助的个人助理，ChatGPT 应该能够采取实际行动来完成工作。

为了衡量模型在日常任务中随时间的表现，我们对任务进行了评估，涵盖了用户最需要人工智能和个人代理帮助的领域。我们使用此评估来跟踪和推动过去一年中日常任务模型性能的改进。

＃＃ 背景

为了确定人们最看重的任务，我们首先进行了两项大型研究，追踪人们在美国和国际上如何度过时间：[美国时间使用调查](https://www.bls.gov/tus/) 和[跨国时间使用研究](https://www.timeuse.org/mtus)。这些数据集共同提供了人们在不同人口统计、一天中的时间和季节中执行的日常生活任务的详细目录。为了了解人们在哪些方面最看重人工智能的帮助，我们在现有调查的基础上进行了一项针对 3,995 名受访者的新的具有人口代表性的调查。对于每项任务，我们都会提出各种问题，以确定人们最需要私人助理帮助的领域。由此产生的任务涵盖了人们需要帮助的最重要领域，包括护理、健康、教育、家庭管理、个人财务、购物和获得政府服务。
