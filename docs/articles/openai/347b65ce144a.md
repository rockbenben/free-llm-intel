# Sam Altman在联合国安全理事会的讲话

正在加载…

今天，OpenAI首席执行官Sam Altman就人工智能议题在联合国安全理事会发表讲话。他谈到了AI在拓展机遇方面的潜力、确保强大系统始终处于人类控制之下的重要性，以及在AI安全领域开展国际合作的必要性。

## 以下为现场讲话实录

谢谢主席先生和各位阁下。我很荣幸来到这里，在这个重要时刻与各位交流。

多年来，我们一直在讨论人工智能，但最近几周和几个月，情况似乎有所不同。模型的迅速进步让时间表显得更加紧迫，潜在收益更加切实可见，但同时也让利害关系和风险变得更加迫在眉睫。

我们面前有两条路可选。AI既可能带来一个创造与发现的新文艺复兴，也可能带来一场充满动荡与混乱的新工业革命。

文艺复兴时期，新工具、新思想和新制度拓展了人们对自身能力的想象。AI可以在我们这个时代发挥这样的作用。我相信，人们的能力远超自己的想象。但本应赋能人类的有限技术却制约了人们，不仅令人分心，还常常夺走他们的注意力。

最理想的AI，不是把人变成庞大机器中的齿轮，也不是优化生活的每个环节，直至其中的人性消失殆尽。它应让人们在日益复杂的世界中拥有更大的自主权，更有能力学习、创造、发现、建设和参与。有许多事情AI无法自动化，也不应该自动化。

AI应为人而建，而不是仅仅为了让机器自身运转得更快。一些致力于构建AI的人所发表的言论过于反乌托邦，听起来就像拙劣科幻电影的情节。

任何如此强大的事物，也都会令人心生畏惧。当下的局面十分复杂：我们既看到了巨大的潜力，同时也感受到完全可以理解的焦虑。

这些模型可以帮助人们发现新知识，研发新药、改善医疗和教育，并建设生产力更高的经济体。它们可以成为新工具，帮助人们追逐如今看似遥不可及的梦想与抱负。对于普通人而言，生活的复杂程度已经大幅增加。AI既可以成为抵御这种复杂性的工具，也可以成为推动前所未有的发现与创新的工具。

另一方面，随着AI系统能力和自主性不断增强，它们的进步速度可能超过我们的制度建设，将权力集中到极少数人手中，或作出人们无法再理解或控制的决策。

随着我们日益接近能够改进自身及其后续版本的系统，这种担忧变得尤为重要。这通常被称为“递归式自我改进”。随着AI构建过程日益自动化，AI的发展步伐可能会迅速加快。此时此刻，我们必须极为谨慎。

我基本赞同Bengio教授的观点。不过，我认为不是三种，而是两种——AI的发展可能以两种方式走向极其糟糕的结局，而我们必须避免它们。

第一，我们可能会将未来的控制权拱手让给AI。风险在于，它的发展速度可能快到人们无法跟上变化，也无法在必要时进行干预。这显然会带来可怕的后果。

行业绝不能因为收益巨大，觉得放慢脚步代价太高，就接受过度的技术风险。在竞争中击败其他公司，并不能成为仓促决策的理由。我们也不认为自己被困在一场无法放慢脚步的竞赛中。过去，我们曾主动放慢发展速度。今后，我们也会这样做。如果我们无法对系统的对齐、可监控性和安全性作出必要保证，我们不希望构建这样的系统；而且我们认为，任何人都不应构建这样的系统。

我们必须了解这些系统正在做什么，并以有力证据证明，即使它们变得极其聪明，也会按照人类的意图行事。事实上，越是当它们变得极其聪明时，就越应如此。无论人们认为灾难风险是10%、1%、12%，还是0.1%，都不重要。这些风险水平没有一个是可以接受的。除非有极其充分的理由确信模型能够始终处于人类控制之下，否则我们就不应训练这样的模型。

这是事情可能走向失控的一种方式。另一种风险是，这些系统可能会将过多权力集中到极少数人手中。任何个人、公司或国家，都不应利用最强大的AI模型把自己的世界观强加给其他所有人。如果一家公司或一个国家认为，只有自己才值得托付这项技术，就可能借此为几乎任何其他行为辩护。我们必须拒绝这种逻辑，即使它对某个行为方而言十分便利。

我相信，我们能够找到一条务实的道路，化解这两方面的问题。在OpenAI，我们以一个明确目标来思考这些问题：AI应让人们对自己的生活拥有更大的自主权。让人们能更自由地按照自己的意愿生活。让人们更有能力解决大大小小的问题，改善所在的社区。我们不想陷入盲目乐观的误区。同样也不想陷入末日论的误区。被任何一个极端裹挟，都无助于我们妥善应对眼前的挑战。尤其是在这个时刻，世界及其人民正面临诸多严峻挑战，而这项技术能够帮助解决这些问题。因此，我们努力在这两个极端之间走一条中间道路。

对我们而言，这意味着三项原则。

第一，随着AI能力不断增强，人必须始终处于AI决策的核心。对齐并非一个抽象的研究问题。这项工作的目标，是确保这些系统始终可靠地处于人类控制之下，体现人类价值观，并帮助人们引导后续发展。我们并不打算，也绝不能将人类判断或人类价值观自动化。

第二，科学进步和经济增长的成果必须由人民创造、为人民服务。AI应帮助研究人员取得发现、医生治疗患者、教师教导学生、创业者创办企业，帮助社区解决曾经遥不可及的问题，并带来更多可能。人类不断进步的历程，从来不是工具取代人的自主能动性。真正的进步在于，合适的工具让人们更有能力。我相信，它所带来的进步将远超我们的想象。

第三，这项技术必须赋能每一个人。美好的未来，将来自人们充分发挥自身潜能，为自己、社区、国家乃至整个世界创造价值。我们或许是这项技术的建设者之一，但并不是这个故事的主角。我们的职责是赋能世界各地的人们，并相信人类才智与能力所蕴含的奇迹。

如今，我们拥有了能够发现前所未知知识的模型。以我们在数学领域取得的进展为例。三年前的夏天，我们的模型应付小学数学还算可以。两年前的夏天，它们在高中数学竞赛中已表现不俗。去年夏天，我们在最负盛名的国际数学竞赛中达到了金牌水平。就在今年夏天的几周前，我们的一个模型解决了千禧年大奖难题之一——纳维-斯托克斯方程。

这些方程用于飞机设计、天气预报和血流研究。我们解决数学问题，并不是为了数学问题本身，而是为了帮助人们发现新知识，并运用这些知识改善医疗健康、提高生活水平，让世界各地的每个人都能释放更大潜能。仍有无数未知等待我们探索。

但至关重要的是，企业不能取代民主程序。

如果AI要体现民主原则，最重要的决策就不能只由旧金山的实验室作出。这些决策必须通过民主程序来塑造，并由对其所服务人民负责的政府参与制定。

在国际层面，这需要各方开展合作。回顾历史，每当强大的新技术出现，即使彼此竞争、关系并不融洽的国家，也曾为了共同利益和集体福祉走到一起。我们认为，现在也必须如此。

我们需要建立一种机制，使各国和国际层面的前沿AI标准相互补充。这些标准应涵盖能力衡量、风险评估、防护措施充分性判定，以及随着系统自主性增强，如何确保人类继续实施切实有效的监督。

我们需要统一标准，让各国能够比较证据、核查合规情况，并以共同的语言和认知理解正在发生的变化。

我们需要准确、迅速的事件报告机制，以及分类和报告规程，让全世界能从失败中吸取教训，避免其演变为灾难。

我们还需要在各国政府、关键基础设施运营方和技术专家之间建立安全渠道，以共享新发现的漏洞和新威胁。

显然，这些标准不应固化现有企业的优势，也不应偏袒任何一种商业模式。它们必须同时支持开放模型和闭源模型的开发者、新进入者和成熟实验室，并兼顾国家自主权与国际合作。各国政府应自行决定如何将这些标准纳入本国法律体系。但如果我们能在全球层面就何为可靠证据、有效防护和良好监督达成共识，所有人都将从中受益。

我们并非掌握所有答案，也非常愿意听取任何更好的想法。我们愿与各位携手合作，竭尽全力探索前进之路。

我们正站在十字路口。一条路通向这样的世界：权力高度集中，决策过程不透明，人们觉得这项一生中最重要的技术正强加于自己。另一条路则通向这样的世界：AI为人服务，因为人们通过民主制度参与决定并引导它如何发展；科学进步真正改善生活；更多人能够参与塑造未来；这项技术继续赋予个人和社区更大的力量，让他们按照自己的意愿生活。在这样的未来，潜能得以实现，处处充满振奋与惊喜。

我们相信，这样的未来值得我们共同建设。非常感谢。
