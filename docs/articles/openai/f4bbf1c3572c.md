# Snowflake 与 OpenAI 合作，将前沿智能引入企业数据生态


**核心要点：**

- 这项价值 2 亿美元的新协议，将 OpenAI 的前沿智能直接接入 Snowflake 平台。
- 企业客户可在 Snowflake 中使用 OpenAI 构建 AI 智能体，并直接从自身数据中生成数据洞察。
- 在本次合作框架下，OpenAI 是 Snowflake 平台的核心模型能力之一。

OpenAI 与 Snowflake 达成了为期多年、价值 2 亿美元的合作，将 OpenAI 的前沿智能直接接入 Snowflake，其中包括 [Snowflake Cortex AI⁠（在新窗口中打开）](https://www.snowflake.com/en/product/features/cortex/) 和 [Snowflake Intelligence⁠（在新窗口中打开）](https://www.snowflake.com/en/product/snowflake-intelligence/)。

Snowflake 是一款数据与 AI 平台，超 12600 家企业借助它构建、使用并共享数据、应用程序与 AI 能力。借助 Snowflake，组织可充分发挥自身数据的价值，并通过直观易用的 AI 数据云激活 AI 能力。该数据云支持无缝连接协作，且以企业信赖的安全与治理机制为核心基础构建而成。

在本次合作框架下，Snowflake 客户可借助 Snowflake Cortex AI 等工具，结合 OpenAI 模型（如 GPT‑5.2），基于自身企业数据构建定制化应用程序与智能体。他们还能在 Snowflake Intelligence 中借助 OpenAI 以自然语言提问，让每位员工都能随时获取洞察，而系统会自动执行业务数据的检索与分析步骤，无需用户自行编写代码。

“通过将 OpenAI 模型接入企业数据体系，Snowflake 让组织能够基于自身最宝贵的资产，借助已信赖的安全合规平台构建并部署 AI，”Snowflake 首席执行官 Sridhar Ramaswamy 表示。“如今，客户可在 Snowflake 中整合自身全部企业知识，结合 OpenAI 模型的世界级智能，构建强大、可靠且值得信赖的 AI 智能体。我们携手为 AI 创新树立全新标准，助力企业自信实现转型，同时始终坚守严格的安全与合规规范。”

“Snowflake 是一款备受信赖的平台，是企业管理与激活核心数据的枢纽，”OpenAI 应用业务首席执行官 Fidji Simo 表示。“本次合作将我们的先进模型直接接入该环境，让 AI 智能体与应用的部署更便捷，助力企业缩小 AI 能力与当前可创造价值之间的差距。”

此外，借助 Snowflake Cortex AI Functions，团队可直接通过 SQL 调用 OpenAI 模型分析各类数据。无论是行列数据、文本、图像还是音频，AI 都能自然融入他们已熟悉并信赖的技术语言体系。

## 加速企业 AI 应用落地

借助 OpenAI 与 Snowflake，客户如今可将强大的推理、分析及多模态智能直接应用于自身可信数据，助力企业在全球范围内更快、更规模化地部署 AI。

Snowflake 为金融服务、医疗健康、零售、媒体、制造及公共部门等众多行业的组织提供支持，助力各垂直领域的团队借助数据更高效地运营业务。本次合作所带来的可能性已经在企业中引发共鸣：

“随着我们在 Canva 上拓展视觉 AI 产品，OpenAI 与 Snowflake 在快速为用户提供全新创意工具的过程中发挥了关键作用，”Canva 数据科学负责人 Helen Crossley 表示。“我们的平台正在持续拓展，Snowflake 是公司管理与激活数据的核心基础，我们很期待探索在 Snowflake Cortex AI 中借助 OpenAI 模型，如何帮助我们拓展这一基础。将先进 AI 模型与企业数据打通的能力，让我们能够快速推进并测试新想法，同时不会影响安全性与性能表现。”

“随着 WHOOP 持续扩大规模，决策的速度与精准度对我们至关重要，”WHOOP 业务分析高级总监 Matt Luizzi 表示。“向员工推出 Snowflake Intelligence 并开发 Cortex Agents 的举措，为 WHOOP 提供了安全合规的数据分析与决策方式。借助 Snowflake Cortex AI 中直接可用的 OpenAI 模型，我们能通过高级推理与分析进一步增强这些智能体，同时始终保持严格的安全与治理规范。本次合作将帮助我们持续推动 AI 成为企业实用的日常工具。”

展望未来，Snowflake 与 OpenAI 团队将紧密协作，推出基于 OpenAI Apps SDK、AgentKit 及企业共享工作流 API 的新功能。作为这项工作的一部分，Snowflake 将继续使用 ChatGPT Enterprise，帮助员工更快地做出决策、简化工作流程，并提升协作效率。

ServiceNow 的合作伙伴生态拓展了 OpenAI 与全球顶尖企业的合作版图，包括[埃森哲⁠](https://openai.com/index/accenture-partnership/)、[沃尔玛⁠（在新窗口中打开）](https://corporate.walmart.com/news/2025/10/14/walmart-partners-with-openai-to-create-ai-first-shopping-experiences)、[PayPal⁠（在新窗口中打开）](https://newsroom.paypal-corp.com/2025-10-28-OpenAI-and-PayPal-Team-Up-to-Power-Instant-Checkout-and-Agentic-Commerce-in-ChatGPT)、[Intuit⁠](https://openai.com/index/intuit-partnership/)、[塔吉特⁠](https://openai.com/index/target-partnership/)、[赛默飞世尔⁠（在新窗口中打开）](https://corporate.thermofisher.com/us/en/index/newsroom/Our-stories/Thermo-fisher-scientific-open-ai-collaboration.html)、[纽约梅隆银行⁠](https://openai.com/index/bny/)、[摩根士丹利⁠](https://openai.com/index/morgan-stanley/)、[西班牙对外银行 (BBVA)⁠](https://openai.com/index/bbva-collaboration-expansion/) 等众多企业。

全球已有逾 100 万家企业客户选择使用 OpenAI，使其成为迄今[增长最快的商业平台⁠](https://openai.com/index/1-million-businesses-putting-ai-to-work/)。
