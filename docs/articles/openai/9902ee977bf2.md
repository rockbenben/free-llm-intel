# OpenAI 黑客松

3 月 3 日周六，来 OpenAI 位于旧金山 Mission District 的办公室听分享、参加黑客松。


3 月 3 日周六，来 OpenAI 位于旧金山 Mission District 的办公室听分享、参加黑客松。（RSVP 已截止。场地有限，我们会筛选邀请名单——确认邮件将在几天内发出。）当天日程：

- 上午 8:30：开门，供应咖啡和糕点。
- 上午 9-11 点：[Sam Altman](https://en.wikipedia.org/wiki/Sam_Altman)、[Dario Amodei](https://www.linkedin.com/in/dario-amodei-3934934)、[Josh Achiam](https://www.linkedin.com/in/joshua-achiam-13887199) 和 [Alec Radford](https://twitter.com/alecrad) 的分享。
- 上午 11 点-晚 7 点：黑客松！提供午餐。可以带着你想折腾的项目来，也可以和现场结识的伙伴一起想一个，或者干脆来混吃混喝找乐子。如果你想找灵感，不妨试试我们的[研究需求清单（Requests for Research）](https://blog.openai.com/requests-for-research-2/)——不过任何项目都欢迎，不限于机器学习！

请参阅我们的[行为准则⁠](https://openai.com/events/code-of-conduct.txt)和[黑客松条款⁠](https://openai.com/events/hackathon.txt)。没有评委、奖项或比赛——只是给你一块场地、一段时间，去做一个项目！

想参加哪个环节都可以。这一天的目标是更多地了解 AI，并和一群志同道合的人一起打磨一个酷炫的项目。
