日本家电零售商长期面临一项挑战：在人员紧缺的情况下，如何让顾客在门店营业时间之外也能获得专业的销售支持。从 ANA Holdings 拆分成立的 AI 客服公司 avatarin 与 Yamada Holdings 合作，将资深销售人员的知识转化为全天候多语言购物智能体。

Kurashi-Marugoto AI 智能体基于 OpenAI 的 GPT‑Realtime 构建，支持自然的语音对话，并引导顾客完成从发现商品到作出购买决定的全过程。在 Yamada Denki 网上商城为期两周的公开体验活动中，约 3 万人使用了该智能体；92% 的调查反馈为正面评价。

> “这并非传统聊天机器人的延伸。这是一次借助 AI 拓展客户服务可能性的尝试。我们认为，这是零售业‘界面革命’的开端。”

Akira Fukabori，avatarin 首席执行官

## 从回答问题到理解顾客

早在 Yamada Denki 项目之前，avatarin 就已与 OpenAI 展开合作，利用 OpenAI API 进行语音识别、咨询分析和员工培训。这些早期实践帮助团队了解如何将 AI 真正应用于实际场景。这个购物智能体是团队首次将这些经验直接带给顾客的重要机会。

Fukabori 认为，GPT‑Realtime 的一项关键优势，是能够在一次对话体验中融合语音、文本和视觉理解。

“对我们而言，单一模型的表现超越了以往见过的专业语音识别系统。它能以低延迟处理语音、文本和图像。这正是我们选择 GPT‑Realtime 的原因。这项技术不再要求人去适应机器的规则，而是能更自然地适应人们的沟通方式。”

传统聊天机器人只会等待正确的关键词。avatarin 的智能体则会倾听并理解语境。它能回应顾客的疑虑和不断变化的偏好，并捕捉具体细节，将泛泛的回答转化为实用的建议。

Fukabori 用一个日常购物难题来说明其中的区别。

“顾客想要的不是聊天机器人。他们想要的是智能。‘我家有四口人，需要一台冰箱，但厨房很小。我该选哪一款？’真正的客户服务，就是能够回答这个问题。”

## 让零售专业知识开口说话

avatarin 围绕三项关键特质设计了这个智能体：

- **确保商品信息准确，同时不拖慢对话。**检索增强生成系统让智能体的回答以商品信息为依据，而 GPT‑Realtime 则确保交互响应迅速。因此，顾客既能进行流畅的语音对话，也能获得基于相关商品数据的信息。
- **将 Yamada Denki 的销售经验转化为对话设计。**销售人员需要了解的信息会因商品类别而有很大差异。avatarin 将 Yamada Denki 的客户服务经验融入智能体的对话流程和提示词中。当顾客改变需求或暂时偏离话题时，系统也能灵活应对；同时，防护机制会让对话始终围绕购物体验展开。
- **设计一个不仅会回答、也会提问的智能体。**许多传统聊天机器人只会等待顾客给出下一条指令。avatarin 则采取了更主动的方式。智能体会继续追问，以发掘顾客的真实需求，推动对话从简单的一问一答转向有引导的商品探索。

OpenAI 与 avatarin 合作设计复杂的提示词结构、优化全天候语音服务的 API 成本，并分享实施最佳实践。这些支持让 avatarin 能够专注于将 Yamada Denki 的服务模式转化为准确、敏捷且富有鲜明品牌特色的体验。

Fukabori 表示：“它能如此自然地理解我们的意图，这令我非常振奋；有时，它还会展现出超越人类能力的智能火花。”

## 当对话转化为洞察

短短两周的公开体验活动就让成效清晰可见：

- 约 3 万名用户
- 全天候语音和文本多语言支持
- 92% 的调查反馈为正面评价

最重要的发现并不只是使用规模。每次对话都揭示了顾客在意什么、为何犹豫，以及哪些信息可以帮助他们作出决定。Fukabori 解释道：“在传统网购中，这些洞察很难被发现。有了 AI 智能体，它们就会自然地呈现在对话中。”

这项服务也为零售创造了新的服务时机。门店关门后，顾客仍可提出问题，也能坦率地谈论预算或顾虑，无须承受销售压力。

每次对话结束时都会进行简短的语音调查，让反馈自然地成为购物体验的延续。

顾客称这个智能体“比真人销售人员更容易沟通”，也很喜欢能够毫无压力地反复提问。

对 avatarin 而言，其意义远不止促成销售。更好的对话也能揭示如何改进服务、营销以及下一次客户体验。

## 一种智能。一个品牌。贯穿每个界面。

avatarin 设想，未来由一个 AI 智能体在网页、电话和实体门店中无缝服务顾客。无需为每个渠道设置独立系统，同一种智能就能延续顾客的情境信息。由此实现连贯体验：无论在哪里互动，始终面对同一位顾客、延续同一场对话、代表同一个品牌。

Yamada Holdings 的业务涵盖家电、住宅、金融服务等领域，这一愿景有望让 AI 成为人们日常生活中值得信赖的伙伴。这一目标不只是打通渠道，更是创造出能够体现企业品牌与待客之道的 AI。

OpenAI 的技术正在助力这一愿景加速实现。Fukabori 表示：“AI 显然已经迈入高速发展阶段。我迫不及待地想看看，我们能用这种非凡的智能创造出什么。”

但 avatarin 并不希望每家公司都以同一种方式说话。“我们希望人们在每个界面都能体验到一种体现各家公司身份与品牌特色的智能。这正是我们所说的‘一种智能。一个品牌。贯穿每个界面。’单一用途 AI 的时代已经结束。我相信，OpenAI 将引领通用多模态智能的下一个时代。”
