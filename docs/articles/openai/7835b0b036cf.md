# 微软投资并与 OpenAI 合作，支持我们打造 beneficial AGI

插图：Justin Jay Wang × DALL·E

微软将向 OpenAI 投资 10 亿美元，支持我们构建具有广泛经济收益的人工智能通用能力（AGI）。我们 partnering 开发微软 Azure 内的一个硬件与软件平台，其规模将能支撑 AGI。我们将联合开发新的 Azure AI 超算技术，微软将成为我们的独家云服务商——因此我们会共同努力，进一步扩展 Microsoft Azure 在大规模 AI 系统方面的能力。

自 2012 年起每年，世界都见证了 AI 能力一次新的阶跃式进步。尽管这些进步横跨非常不同的领域——[视觉](https://medium.com/coinmonks/paper-review-of-alexnet-caffenet-winner-in-ilsvrc-2012-image-classification-b93598314160)（2012）、[简单电子游戏](https://danieltakeshi.github.io/2016-12-01/going-deeper-into-reinforcement-learning-understanding-dqn/)（2013）、[机器翻译](https://blog.acolyer.org/2016-06-02/sequence-to-sequence-learning-with-neural-networks/)（2014）、[复杂棋盘游戏](https://deepmind.com/research/alphago/)（2015）、[语音合成](https://deepmind.com/blog/wavenet-generative-model-raw-audio/)（2016）、[图像生成](https://www.youtube.com/watch?v=G06dEcZ-QTg)（2017）、[机器人控制⁠](https://openai.com/index/learning-dexterity/)（2018）和[文本写作⁠](https://openai.com/index/better-language-models/)（2019）——它们都由同一种方法驱动：深度神经网络的创新应用，加上不断增长的[计算能力⁠](https://openai.com/index/ai-and-compute/)。但即便如此，今天的 AI 系统构建在每个明确定义的任务上仍需大量人工工程。

相比之下，AGI 将是能够把一门学科精通到世界专家水平的系统，并能精通的领域多于任何一位人类——像一件融汇居里、图灵和巴赫技能的工具。处理问题的 AGI 能看见任何人类都看不到的跨学科联系。我们希望 AGI 与人协作，解决当前无解的跨学科难题，包括应对气候变化、可负担的高质量医疗和个性化教育等全球挑战。我们认为它的影响应当是让每个人都获得经济自由，去追求自己最感充实的事，为我们所有人的生活创造今天难以想象的新机遇。

OpenAI 团队及其家人在 2019 年 7 月的 offsite 上。

OpenAI 正在产出一系列日益强大的 AI 技术，这需要大量资本投入算力。覆盖成本最显而易见的方式是做产品，但那意味着转移重心。因此我们打算改为授权部分 AGI 之前的技术，微软将成为我们商业化的首选伙伴。

我们相信，打造 beneficial 的 AGI 将是人类历史上最重要的技术发展，有可能塑造人类的轨迹。我们面前是一条艰难的技术道路，需要软件工程与 AI 研究在超大规模算力上的统一协作，但仅有技术成功还不够。要完成我们的使命——确保 AGI（无论是否由我们造出）惠及全人类——我们需要保证 AGI 的安全稳健部署；让社会为其影响做好准备；让其经济上行空间被广泛共享。如果我们达成这一使命，我们就实现了微软与 OpenAI 共同的价值观：赋能每一个人。
