# 微软与 OpenAI 合作关系的全新篇章

正在加载…

自 2019 年起，微软与 OpenAI 始终秉持共同愿景：推动人工智能负责任发展，让其惠及更广泛人群。从对研究机构的投资起步，双方已发展成为业内最成功的合作伙伴之一。随着合作进入新阶段，我们签署了新的最终协议，在既有基础上深化伙伴关系，为双方组织的长期成功奠定基础。

首先，微软支持 OpenAI 董事会推进公益公司 (PBC) 的组建及资本重组。资本重组后，微软对 OpenAI 集团 PBC 的投资估值约为 1,350 亿美元，按转换后摊薄计算约占 27% 股权（涵盖全体所有者——员工、投资者及 OpenAI 基金会）。若排除 OpenAI 近期融资轮次的影响，微软在营利性 OpenAI 公司中的转换后持股比例为 32.5%。

协议保留了推动双方成功合作的关键要素——OpenAI 仍为微软前沿模型合作伙伴，微软继续享有知识产权专属权及 Azure API 独家使用权，直至实现通用人工智能 (AGI)。

协议同时完善并新增条款，使双方能够独立推进创新与发展。

变更要点：

- OpenAI 宣布实现 AGI 后，该声明须经独立专家小组验证。
- 微软对模型及产品的知识产权保护期延长至 2032 年，现涵盖 AGI 之后的模型，并设有相应安全防护措施。
- 微软对研究成果的知识产权（定义为模型与系统开发中使用的保密方法）将持续至专家小组验证 AGI 或 2030 年止（以先到者为准）。研究知识产权包括仅用于内部部署或研究的模型等。此外，研究知识产权不包含模型架构、模型权重、推理代码、微调代码以及任何与数据中心软硬件相关的知识产权；微软保留上述非研究类知识产权。
- 微软知识产权现已排除 OpenAI 消费级硬件。
- OpenAI 现可与第三方联合开发部分产品。与第三方共同开发的 API 产品将独家部署于 Azure 平台。非 API 产品可部署于任意云服务提供商。
- 微软现可独立或联合第三方推进 AGI 研发。
- 若微软使用 OpenAI 知识产权开发 AGI，在 AGI 正式宣告前，相关模型须满足计算资源门槛要求；该门槛远高于当前训练顶尖模型的系统规模。
- 收益分成协议将持续至专家小组验证 AGI 成立，但付款周期将相应延长。
- OpenAI 已签约增购 2,500 亿美元 Azure 服务，微软不再享有作为 OpenAI 计算服务供应商的优先承接权。
- OpenAI 现可向美国政府国家安全客户开放 API 接口，不受云服务提供商限制。
- OpenAI 现可发布符合必要能力标准的开放权重模型。

随着双方合作迈入新篇章，两家公司比以往任何时候都更有能力持续打造满足现实需求的产品，为所有人及所有企业创造全新机遇。
