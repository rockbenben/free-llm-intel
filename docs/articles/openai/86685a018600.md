# OpenAI 宣布收购 TBPN

深化全球 AI 领域的对话与交流

*Fidji Simo 于今日早些时候向公司全体员工发布了以下消息：*

我很高兴地宣布，我们已经完成对 [TBPN](https://www.tbpn.com/) 的收购。本次收购为我们带来了一支顶尖团队，他们拥有敏锐的编辑直觉、深刻的受众理解力，以及汇聚科技、商业与文化领域最具影响力发声者的卓越能力。

TBPN 取得的成就可谓独树一帜，它是目前 AI 领域开发者与从业者进行日常对话的核心阵地之一。你们中的许多人已经是它的忠实观众，并依靠它来紧跟行业前沿动态。

在思考 OpenAI 未来的传播策略时，我意识到传统的传播模式已不再适用于我们。我们不是一家普通的公司。我们正在推动一场重大的技术变革。确保通用人工智能 (AGI) 惠及全人类是我们的使命。因此，我们有责任去开辟一个空间，让关于 AI 变革的理性、建设性对话得以展开，并确保开发者和技术使用者始终处于这些讨论的核心。

这正是 TBPN 的长项。因此，与其从零开始打造，不如将他们纳入麾下，在支持其发展壮大的同时，保留其独特的灵魂。其中最核心的一点是编辑独立性。TBPN 将继续自主运营其节目、筛选嘉宾并自行做出内容决策。这是其公信力的基石，也是我们在收购协议中明确承诺并予以保护的核心条款。

此外，我也非常期待将他们出色的传播与营销直觉引入团队。他们曾助力众多品牌在数字化浪潮中脱颖而出。凭借对行业趋势的精准把控，他们在营销创意上的见解令我印象深刻。我非常期待该团队能将这些才华延伸至节目之外，以创新的方式向世界推介 AI，帮助大众更透彻地理解这项技术对日常生活的深远影响。

TBPN 将加入我们的战略部门 (Strategy org)，向 Chris Lehane 汇报。让我们热烈欢迎 Jordi、John、Dylan 以及整个团队的加入。

*TBPN 官方声明：*

*“在过去的一年里，我们不仅身处观察 OpenAI 的‘第一排’，更见证了整个生态系统的脉动，实时报道着每一项新闻、公告与发布。尽管我们有时会对行业持批判态度，但在深入了解 Sam 及 OpenAI 团队后，最让我们印象深刻的，是他们听取反馈的开放心态，以及确保技术发展不偏离正轨的坚定承诺。对我们而言，能从旁观者的评论，转而亲身参与到这项技术的全球推广与普及中，并产生实质性的改变，这意义非凡。”*

*— Jordi Hays，TBPN 联合创始人兼联合主持人*

**关于 TBPN**

Technology Business Programming Network (TBPN) 是一档提供每日直播的科技谈话节目，也是全球增长最快的媒体公司之一。节目由企业家 Jordi Hays 与 John Coogan 共同主持，于太平洋时间周一至周五 11:00 - 14:00 播出。《纽约时报》近期曾评价 TBPN 为“硅谷的新宠”。在 Coogan、Hays 及总裁 Dylan Abruscato 的带领下，TBPN 在科技生态圈迅速走红。受众可以通过 [X](https://x.com/tbpn)、[YouTube](https://www.youtube.com/@tbpnlive)、[Spotify](https://open.spotify.com/show/2L6WMqY3GUPCGBD0dX6p00)、[Apple Podcasts](https://podcasts.apple.com/us/podcast/tbpn/id1772360235)、[LinkedIn](https://www.linkedin.com/company/tbpn/)、[Substack](https://tbpn.substack.com/) 以及 [Instagram](https://www.instagram.com/tbpn) 订阅关注。
