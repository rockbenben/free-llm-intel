# PixelCNN++：用离散化逻辑混合似然等方法改进 PixelCNN

阅读论文（在新窗口中打开）

## 摘要

PixelCNN 是近期提出的一类强大且似然可计算（tractable）的生成模型。本文讨论我们的 PixelCNN 实现，代码发布于 [此链接⁠（在新窗口中打开）](https://github.com/openai/pixel-cnn)。我们的实现对原始模型做了多项修改，既简化了结构，又提升了性能。1）我们对像素使用离散化逻辑混合似然，而非 256 路 softmax，发现这能加快训练。2）我们以整个像素而非 R/G/B 子像素为条件，简化了模型结构。3）我们使用下采样，高效捕捉多尺度结构。4）我们引入额外的快捷连接（short-cut connections），进一步优化速度。5）我们用 dropout 对模型做正则化。最后，我们在 CIFAR-10 上给出了最先进的（state-of-the-art）对数似然结果，证明了这些修改的价值。
