# 度量古德哈特定律

古德哈特定律有一句名言："当一个度量成为目标，它就不再是一个好的度量。"虽然它源自经济学，但在 OpenAI，当我们思考如何优化那些难以测量或测量成本高昂的目标时，也必须直面它。我们常常不得不引入某个更易测量或更低成本的**代理目标**（proxy objective），但这样做时，必须小心不要过度优化它。

例如，在我们让 GPT‑3 这类模型[对齐⁠](https://openai.com/alignment/)人类意图与价值观的工作中，我们希望优化诸如"这条回答有多[有帮助⁠](https://openai.com/index/instruction-following/)？""这个说法在[事实层面⁠](https://openai.com/index/webgpt/)有多准确？"这类复杂目标——它们需要人类仔细核查。因此，我们训练一个模型来预测这些人类偏好，即所谓的**奖励模型**（reward model），并把奖励模型的预测当作代理目标来用。但与此同时，跟踪真实目标被优化的程度同样重要。

本文我们将看看做好这件事背后的一些数学。我们聚焦于一个特别容易分析的场景：我们能够获得真实目标。实际上，连人类偏好也可能无法度量我们真正关心的东西，但本文暂且搁置这个问题。

## Best-of-n 采样

优化代理目标的方式有很多种，最简单的或许是 **best-of-n 采样**，也叫**拒绝采样**或**重排序**（reranking）。我们简单地采样 n 次，取代理目标得分最高的那个。

虽然方法极简，它实际上可以与强化学习等更先进的技术相媲美，代价是更多的推理时算力。例如在 [WebGPT⁠](https://openai.com/index/webgpt/) 中，我们的 best-of-64 模型超过了强化学习模型，部分原因或许是 best-of-64 模型得以浏览多得多的网站。即便只用 best-of-4，人类偏好也有显著提升。

此外，best-of-n 采样性能可靠、数学上易于分析，非常适合用来对古德哈特定律及相关现象做实证研究。

## best-of-n 采样的数学

让我们更形式化地研究 best-of-n 采样。假设我们有某个样本空间 S（比如所有可能问答对的集合）、S 上的一个概率分布 P、一个真实目标（或"奖励"）`R_true : S → ℝ`，以及一个代理目标 `R_proxy : S → ℝ`。假设我们以某种方式优化了 `R_proxy`，从而得到某个新分布 `P′`。那么：

- 期望 `E_{x′∼P′}[R_true(x′)]` 度量我们把真实目标优化得如何。
- [KL 散度](https://en.wikipedia.org/wiki/Kullback%E2%80%93Leibler_divergence) `D_KL(P′∥P)` 度量我们做了多少优化。例如，若 `P′` 是通过"从 P 中采样，取第一个落在某个子集 S′⊆S 内的样本"得到的，那么这个 KL 散度就是"P 的样本落在 S′"概率的负对数。

事实证明，在 best-of-n 采样的情形下，这两个量都可以用来自 P 的样本高效估计。

先看期望。朴素做法是用蒙特卡洛估计器：多次运行 best-of-n 采样，在这些样本上度量真实目标并取平均。但有一个更好的估计器。如果我们从 P 一共取了 N≥n 个样本，就可以同时考虑这些样本的*每一个*大小为 n 的子集，按每个样本作为"子集中代理目标最优者"的子集数目为权重加权，然后取真实目标分数的加权平均。这个权重就是二项式系数 `C(k−1, n−1)`，其中 k 是该样本按代理目标的名次，从 1（最差）到 N（最好）。[A](https://openai.com/index/measuring-goodharts-law/#citation-bottom-A)

这些权重之和为 `C(N, n)`，由此还给出了[曲棍球恒等式](https://en.wikipedia.org/wiki/Hockey-stick_identity)的一个证明。关于此处估计器的形式化推导，见 [WebGPT 论文](https://arxiv.org/pdf/2112.09332.pdf)附录 I。

这个估计器不仅更高效地利用了样本，还允许不同 n 值之间复用样本。至于 KL 散度，令人惊讶的是，它对任意连续概率分布 P（即 P 无原点质量）都有一个精确公式。有人可能会朴素地猜测答案是 `log n`，因为 best-of-n 做的事有点像取分布的前 1/n——这个猜测大致正确：精确答案是 `log n − (n−1)/n`。[B](https://openai.com/index/measuring-goodharts-law/#citation-bottom-B)

这两个估计器结合起来，让我们能轻松分析：随着对代理目标施加的优化量增加，真实目标如何变化。

## 超越 best-of-n 采样

best-of-n 采样的主要局限在于 KL 散度随 n 对数增长，因此只适合施加少量优化。

要施加更多优化，我们通常使用强化学习。在我们迄今研究过的场景中，比如[摘要⁠](https://openai.com/index/learning-to-summarize-with-human-feedback/#optimizingtherewardmodel)，我们通常能在强化学习下达到约 10 [纳特](https://en.wikipedia.org/wiki/Nat_(unit))的 KL，之后真实目标才开始因古德哈特定律而下降。若用 best-of-n 达到这个 KL，n 需要取到约 60,000。我们期望随着奖励建模与强化学习实践的改进，能够达到大得多的 KL。

然而，纳特与纳特并不等价。实证上，在小的 KL 预算下，best-of-n 对代理目标和真实目标的优化都优于强化学习。直觉上，best-of-n 是"蛮力"方法，这使它比强化学习更具信息论效率，但在大 KL 时计算效率更低。[C](https://openai.com/index/measuring-goodharts-law/#citation-bottom-C)
