投资机构的优势是一笔笔交易积累起来的，但每项决策背后的判断依据，往往只存在于少数资深投资人的头脑中。当他们离职时，机构便背上了 [Terminal X](https://www.terminal-x.ai/) 所说的“记忆债务”：文件也许留了下来，推理思路却随之流失。

Terminal X 的 Capital Memory 操作系统正是为了逐步化解这笔债务而设计的。该公司的前线部署工程师曾是摩根大通和黑石的金融与投资专业人士。他们与各家客户的投资团队并肩工作，为机构设计智能体架构，将其投资方法编码到机构自有的智能体中，并部署在本地或机构自己的云环境中。

GPT‑6.1 Sol 和 GPT‑6 Luna 等 OpenAI 模型负责这些智能体内部的推理。Terminal X 的评估智能体则依据机构的标准，为智能体的输出评分。与排名第二的模型相比，GPT‑6.1 Sol 帮助评估智能体多识别出约 25% 偏离基金投资约束的建议，在运行相同工作流时，单次查询成本降低了约 30%。

> “GPT-6.1 Sol 的长上下文推理能力和 Token 效率，让我们能够构建更深入的评估流程。这有助于我们的评估智能体让投资判断变得可衡量、可审计。”

—Hyun Hong，Terminal X 联合创始人兼首席执行官

## 将各机构顶尖投资人的推理思路编码到系统中

Terminal X 为每家客户构建智能体，使其能够遵循该机构顶尖投资人的方式开展投资。Terminal X 的工程师会在客户现场工作数周，从机构认可的备忘录中逆向梳理其方法，并记录从未成文的流程，例如信贷团队如何筛选借款人，或共同投资团队在撰写备忘录前会查阅哪些资料。

接着，这些流程被编码到数百个按资产类别和策略定制的智能体中，每个投资阶段还配有相应的子智能体。GPT‑6.1 Sol 负责需要判断力和超大上下文窗口的环节：整合投资逻辑、识别关键考量因素，以及评估是否符合机构的投资约束。GPT‑6 Luna 则负责处理量大、Token 效率比推理深度更重要的步骤。

这些智能体在各机构的私有数据室内工作。该环境专供企业共享和管理敏感投资数据。智能体处理英语、韩语、日语和中文文档，并将学到的内容存储为机构记忆：这是一种带版本记录的资料，记录某个业务团队如何做出某类决策，涵盖历史分析、委员会决策、工作流指令和机构观点。

工程师将每条记忆转化为 Terminal X 平台上可重复执行的工作流。平台会为生产环境中的每次查询保留完整记录，包括执行步骤、检索来源、所用模型和推理过程，以供审计。

据 Terminal X 介绍，这种方法为客户显著节省了成本。其中一家私募股权机构报告称，通过自动化尽职调查和投资备忘录工作流，按年计算可节省 240 万美元。

## 用评估智能体为回答评分，持续改进系统

为了按照机构自身的标准检查智能体的回答，Terminal X 构建了评估智能体。它是一个基于 GPT‑6.1 Sol 和其他 OpenAI 模型编排的工作流，旨在像副总裁审阅分析师的工作成果一样，审阅智能体的每一份输出。

评估智能体按照包含 54 项标准的评分细则，逐一检查每份输出。它会检查：数据、可比对象、市场一致预期数据和引文是否来自正确的来源？论述是否站得住脚？建议是否符合机构观点？

![Terminal X 评估运行工具将生成的投资备忘录与标准答案对比，并高亮显示候选模型中已修正的 EBITDA 倍数。](https://images.ctfassets.net/kftzwdyauwt9/2TfOmA6DYwo9dYjcrmzQPt/e23da6e7e88388dbdd3ec932ad3cf85f/terminal-x-eval-agent-paper-background-thin-border.png?w=3840&q=90&fm=webp)

每项检查的结果均为“通过”或“不通过”。每个不通过项都会附上一句话说明原因，以及更合适的来源或修正后的文本，并被记录为一条记忆。例如，遗漏的来源、选错的可比对象，或偏离机构观点的投资逻辑，都会被编码为该业务团队的新工作流指令或新测试用例。

Terminal X 联合创始人兼首席技术官 Ken Lee 表示：“每个回答都会经过评估，而分析师的每一次修正，都让系统更了解这家机构的运作方式。”“所以，机构用得越久，系统的思考方式就越接近他们自己的团队。”

## 逐一测试模型，按任务选择

Terminal X 根据自己的评估结果选择模型。在 500 次经过评分的判断中，基于 GPT‑6.1 Sol 的评估智能体与资深人工审核者的判断一致率为 88.6%，而排名第二的模型为 86.4%，提升了 220 个基点。

在识别投资风格漂移这类错误时，GPT‑6.1 Sol 表现更出色。例如，一只并购基金的投资任务是寻找交易价格低于资产净值（NAV）的私有化候选标的，评估其业务的投资价值与风险，并设计融资结构。当情景模型预示市场转向时，交易建议却开始转向投资困境债权或提供救助融资。基于 GPT‑6.1 Sol 的评估智能体比排名第二的模型多识别出约 25% 的此类偏离。

GPT‑6.1 Sol 在长上下文任务中的 Token 效率，使 Terminal X 能在相同预算内构建更深入的审核工作流。系统先依据基金的投资约束检验投资逻辑，再对照基金近期的交易进行检查。对于不确定的判断，系统会重新运行评估，智能体在核对并协调各次结果后再报告。

这种更深入的审核，标出了同类模型单次审核时放行的交易。此外，GPT‑6.1 Sol 运行相同工作流时，在速度相近的情况下，单次查询成本比排名第二的模型低约 30%。

## 让每位投资人都拥有自己的记忆

借助 GPT‑6.1 Sol 和 GPT‑6 Luna，Terminal X 已构建 1,700 条机构记忆，运行超过 100 万次定制工作流，周活跃用户数达到月活跃用户数的 81%。

Terminal X 的下一步是将机构记忆从业务团队延伸到个人，记录每位投资专业人士在实际工作中采用的标准，而不只是他们口头描述的标准。

对 Terminal X 联合创始人兼首席执行官 Hyun 而言，这正是关键所在：“未来十年胜出的机构，将把自身的判断力沉淀为自己掌握的数据。我们的工作就是让这种判断力变得可衡量，从而能够留存、改进和复用。”
