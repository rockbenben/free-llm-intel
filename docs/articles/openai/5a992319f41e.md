Codex 正是为 [GitHub Copilot⁠（在新窗口中打开）](https://copilot.github.com/) 提供动力的模型——一个月前我们与 GitHub 合作构建并发布了它。Codex 精通十余种编程语言，现在能够解读自然语言中的简单命令并代表用户执行——这使得为现有应用构建自然语言界面成为可能。我们现在邀请企业和开发者基于 OpenAI Codex 通过我们的 API 进行构建。

OpenAI Codex 是 GPT-3 的后代；其训练数据既包含自然语言，也包含来自公开来源的数十亿行源代码，包括 GitHub 公开仓库中的代码。OpenAI Codex 最擅长 Python，但同样精通十余种语言，包括 JavaScript、Go、Perl、PHP、Ruby、Swift、TypeScript 甚至 Shell。它针对 Python 代码的记忆为 14KB，而 GPT-3 只有 4KB——因此执行任何任务时可纳入的上下文信息多出 3 倍以上。

GPT-3 的主要技能是根据自然语言提示生成自然语言，这意味着它只能通过读者的思想来影响世界。OpenAI Codex 具备 GPT-3 的大部分自然语言理解能力，但产出的是可运行的代码——意味着你可以用英语向任何带 API 的软件发出命令。OpenAI Codex 让计算机更好地理解人的意图，从而让每个人都能用电脑做更多事情。

当程序员知道要构建什么之后，写代码这件事可以分解为：(1) 把问题拆解成更简单的问题；(2) 把这些简单问题映射到已有的代码（库、API 或函数）。后者大概是编程中最不有趣的部分（也是最高的入门门槛），而恰恰是 OpenAI Codex 最擅长的。

OpenAI Codex 是一个通用编程模型，意味着它几乎可以应用于任何编程任务（尽管效果不一）。我们已成功用它做转译（transpilation）、解释代码和重构代码。但我们知道自己只触及了可能性的表面。

我们现在通过 API 以私有 beta 形式发布 OpenAI Codex，目标是尽快在安全范围内扩展规模。在初始阶段，OpenAI Codex 将免费提供。OpenAI 将继续在 GPT-3 奠定的安全基础上推进——审查应用并逐步放量，同时与开发者密切合作，了解我们的技术在现实世界产生的影响。
