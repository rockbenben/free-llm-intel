# OpenAI《前沿治理框架》

用于说明我们的安全与安保实践如何符合新兴法律要求的框架。

阅读《前沿治理框架》



今天，我们发布 OpenAI 的《前沿治理框架》，说明我们的安全与安保实践如何与新兴法律要求保持一致，包括加州《前沿 AI 透明度法案》和欧盟《AI 法案》中的《通用人工智能行为准则》要求。

准备框架仍然是我们界定并落实如何管理先进 AI 系统最严重风险方法的基础，其中也包括超出现行法律要求的内部实践。《前沿治理框架》将该方法中的相关部分应用到一份聚焦具体监管义务的公开治理文件中。

该框架涵盖多个领域的风险评估与缓解，包括网络攻击、CBRN 风险、有害操纵和失控，以及模型报告、安全风险管理、事件响应、外部专家意见和框架更新。

随着模型能力、评估方法和监管要求的发展，我们预计这一方法将持续演进，并将相应更新《前沿治理框架》。

《前沿治理框架》可在[此处](https://cdn.openai.com/pdf/e37d949b-8c9f-4d76-b99e-4272f4631a7e/openai-frontier-governance-framework.pdf)查看。
