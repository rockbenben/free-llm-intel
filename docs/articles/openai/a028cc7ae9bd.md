# 立即开始使用 ChatGPT

## This launch post is outdated.

Release notes



我们的核心使命是让 ChatGPT 等工具广泛普及，让人们体验人工智能的益处。来自 185 个国家/地区超过 1 亿人每周使用 ChatGPT 学习新知识、寻找创意灵感并解答疑问。即日起，您可以立即使用 ChatGPT，无需注册。我们正在逐步推广这项服务，旨在让所有对人工智能感兴趣的人都能轻松使用。

我们可能会使用您提供给 ChatGPT 的信息来改进我们为所有人提供的模型。如果您愿意，无论您是否创建帐户，都可以在“设置”中关闭此功能。在我们的[帮助中心](https://help.openai.com/en/articles/5722486-how-your-data-is-used-to-improve-model-performance)详细了解我们如何使用内容来训练模型以及您的选择。

我们还为此体验引入了额外的内容保护措施，例如屏蔽更多类别的提示和生成。

创建帐户有很多好处，包括可以保存和查看聊天记录、分享聊天记录，以及解锁语音对话和自定义指令等其他功能。

对于一直对人工智能的潜力感到好奇，但又不想完成创建账户步骤的用户，现在即可开始使用 ChatGPT。
