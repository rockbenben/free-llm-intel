# OpenAI 与微软联合声明


自 2019 年以来，微软与 OpenAI 始终致力于以负责任的方式推动人工智能的发展，并使其惠及大众。这段始于科研领域的合作伙伴关系，如今已演变为科技界最具影响力的协作范例之一 — 其核心基石是双方的互信、深度的技术融合以及对创新的长期承诺。

随着近期业界对 AI 投资与合作的关注度日益提升，且 OpenAI 于[今日宣布](https://openai.com/index/scaling-ai-for-everyone/)了新的融资进展及合作伙伴，我们希望确保这些公告在双方既有的合作框架内得到准确解读。今日公布的所有信息均未改变微软与 OpenAI 之间的合作条款，相关条款已在 [2025 年 10 月的联合博客](https://openai.com/index/next-chapter-of-microsoft-openai-partnership/)中对外披露。

**合作关系依然稳固且仍然是核心。**立足于多年深厚的协作基础与共同成就，微软与 OpenAI 将持续深化在科研、工程及产品开发领域的紧密合作。

**知识产权合作关系保持不变。**微软继续拥有对 OpenAI 模型及产品知识产权的独家许可与访问权。OpenAI 与亚马逊等伙伴的合作一直包含在双方的协议框架内，微软也十分期待看到他们共同创造的成果。

**商业逻辑与收益分成关系保持不变。**现有的收益分成安排保持不变。该安排始终涵盖了 OpenAI 与其他云服务商合作所产生的收益分成。

**Azure 仍是无状态 OpenAI API 的独家云提供商。**微软是提供 OpenAI 模型及 IP 访问权限的无状态 API 的独家云供应商。客户和开发者可以直接从 OpenAI 或通过微软购买这些 API，并从 Azure 的全球基础设施、安全性及企业级规模化能力中获益。OpenAI 与任何第三方（包括亚马逊）合作产生的针对 OpenAI 模型的无状态 API 调用，均将托管于 Azure。

**OpenAI 的第一方产品（包括 Frontier）将继续托管在 Azure 上。**

**AGI 的定义及判定流程保持不变。**合同中关于通用人工智能 (AGI) 的定义，以及判定其是否已实现的流程均保持不变。

**合作伙伴关系支持 OpenAI 的成长。**随着规模不断扩大， OpenAI 仍拥有在其他平台投入额外算力的灵活性，包括通过“星际之门”(Stargate) 等大规模基础设施项目。

双方的合作模式旨在为微软和 OpenAI 预留独立追求新机遇的空间，同时保持深度协作。目前，双方正通过共同或独立的方式践行这一模式。

我们始终致力于维护双方的合作伙伴关系及共同愿景。我们将继续并肩作战，交付强大的 AI 工具，推动负责任的研发，并确保 AI 技术能够造福全球的个人与机构。
