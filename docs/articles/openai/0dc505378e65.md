# OpenAI Scholars 2020：开放申请

我们现正接受第三期 OpenAI Scholars 的申请。

2019 年 Scholar Fatma Tarlaci。摄影：Blake Tucker

我们现正接受第三期 OpenAI Scholars 的申请。这是一个为期 4 个月的全时项目，我们为 8 位来自代表性不足群体的个人提供津贴与导师指导，帮助他们学习深度学习并开源一个项目。第二期 Scholars 近期发布了他们的项目，并在 2019 年 Scholars 演示日上展示了成果。

## 我们为何做这件事

多样性是 AI 对世界产生积极影响的核心——要确保未来的先进 AI 系统为惠及所有人而建，多样性必不可少。虽然我们期望部分 Scholar 未来加入 OpenAI，但我们希望这个项目提升整个大领域的多样性。

## 我们寻找什么样的人

我们欢迎满足以下条件、*任何经验水平与背景* 的人——“做 AI 必须读博士”是常见的误解（许多 OpenAI 员工并没有博士学位）。

我们希望候选人擅长编写软件（2 年以上软件工程经验），但不要求此前的机器学习经验。这是一个远程项目，面向已持有美国工作许可、身处美国时区的任何人。我们请所有 Scholar 将学习深度学习的经历[记录下来⁠（在新窗口中打开）](https://fatmatarlaci.wordpress.com/)，以期鼓舞更多人加入这一领域。

符合以下条件即可申请：

- 你属于科学与工程领域代表性不足的群体。我们的目标是让这个项目尽可能包容。如果你认为自己属于此处未列出、但在科学与工程中代表性不足的群体，请提交申请并在申请中说明。
- 你有 2 年以上软件工程经验（不要求机器学习经验）。
- 你已持有美国工作许可，且在项目期间身处美国。
- 你熟练使用 Python 编程（其他语言有帮助，但整个项目你将主要用 Python 编写）。

我们将依据以下标准遴选：

- **技术能力。** 技术功底越强，你就能把越多时间聚焦在深度学习本身。
- **自我驱动。** 我们寻找在大型挑战性项目上有自主推进经验、能胜任独立工作的人。
- **领导力。** 我们希望听到热衷于社群建设、并会激励他人（项目内与项目外）投身深度学习学习的人的声音。

申请将按滚动方式评审。
