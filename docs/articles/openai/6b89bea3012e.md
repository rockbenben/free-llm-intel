# 摔跤中的元学习

我们证明，在仿真机器人摔跤任务中，一个元学习智能体能够快速击败更强的非元学习智能体；我们还展示了元学习智能体能适应物理故障。

我们扩展了[模型无关元学习（MAML）⁠（在新窗口打开）](https://arxiv.org/abs/1703.03400)算法，把它的目标函数改为针对环境*对*进行优化，而不是像原版 MAML 那样针对单个环境。MAML 初始化智能体的策略，使得在新环境（或任务）上只需少量参数更新，智能体就能在该环境中做得更好。执行时的策略参数更新通过对梯度上升完成，利用与新环境最初几轮交互中收集的奖励。通过成对环境训练，我们能够创造出可快速适应未见环境的策略——只要新环境与以往环境偏差不至于太离谱。

为了测试我们的持续适应方法，我们设计了 3 种智能体——Ant（4 腿）、Bug（6 腿）和 Spider（8 腿）——并搭建了一个多回合游戏：每个智能体与同一对手打多场比赛，并在回合之间调整策略参数，以更好地反制对手的策略。测试中我们发现，能调整战术的智能体远比固定策略的智能体更强。在训练了上百个智能体（其中一些学到固定策略，另一些学会适应）之后，我们评估了每个智能体的适应度。

边学边用也能让智能体应对自己身体的异常变化，例如适应自身某些肢体随时间失去功能。这提示我们可用这类技术开发既能应对外部环境变化、也能应对自身身体或内部状态变化的智能体。

作为大规模多智能体研究的一部分，我们正在探索元学习。此外，我们[发布了本工作使用的 MuJoCo 环境和训练好的策略⁠（在新窗口打开）](https://github.com/openai/robosumo)，方便其他人在这些系统上做实验。
