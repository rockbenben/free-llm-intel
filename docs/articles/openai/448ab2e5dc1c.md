# 关于基于解码器的生成模型的定量分析

阅读论文（在新窗口中打开）

## 摘要

过去几年，生成模型取得了显著进步，能够产出令人信服的图像及其他模态样本。许多强大生成模型的一个共同组件是解码器网络——一种定义生成分布的参数化深度神经网络。例子包括变分自编码器、生成对抗网络和生成矩匹配网络。遗憾的是，由于 log-likelihood 估计不可计算，这类模型的性能难以量化，而检查样本也可能产生误导。我们提出使用模拟重要性采样（Annealed Importance Sampling）评估基于解码器模型的 log-likelihood，并用双向蒙特卡洛验证其准确性。评估代码见 [此链接⁠（在新窗口中打开）](https://github.com/tonywu95/eval_gen)。利用这一技术，我们分析了基于解码器模型的性能、现有 log-likelihood 估计器的有效性、过拟合程度，以及这些模型遗漏数据分布重要模式（modes）的程度。
