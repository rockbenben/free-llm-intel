NTT DATA集团是一家总部位于日本的全球性IT服务公司，业务涵盖咨询、系统开发和运营。随着人工智能重塑商业环境，该公司正在转变其增长模式，从通过增加员工人数来扩大收入，转变为通过人工智能创造更大的价值。

为了支持这一转型，NTT DATA 集团在公司范围内推出了 ChatGPT Enterprise，并推出了帮助员工将人工智能融入日常工作的计划。在此基础上，该公司已将 Codex 的员工人数扩大到约 9,000 人。如今，技术和非技术团队不仅使用人工智能通过对话探索想法，而且还使用人工智能来执行明确定义的任务。

## 公司范围内的 ChatGPT 企业版采用为 Codex 奠定了基础

在 2025 年 5 月与 OpenAI 建立全球战略合作伙伴关系后，NTT DATA 集团开始在公司内部部署 ChatGPT Enterprise。它建立了一个内部的 OpenAI 卓越中心（CoE），通过许可证分发、技术验证、活动、用例开发、使用情况监控、知识资源以及员工充分利用 AI 所需的系统来支持其采用。

因此，ChatGPT Enterprise 已成为 NTT DATA 集团日常工作的主要 AI 工具之一。在一项内部调查中，超过 96% 的受访者表示对 ChatGPT Enterprise 感到满意，超过 95% 的受访者表示生产力有所提高。

通过日常使用，员工积累了使用人工智能进行研究、写作和内容创作的经验。这些习惯和技能为该组织迈向下一步做好了准备：将明确定义的任务委派给 Codex。

## 早期应用案例为 Codex 的发展奠定了基础

Codex 的潜力首次得到证明，其成功案例之一是实现了关键系统复杂事件分析的自动化。这项工作以前需要五名经验丰富的工程师，耗时三天才能完成。使用 Codex，整个过程仅需 30 分钟即可完成。

这一成果很快引起了高层领导的关注，并成为 Codex 能够实现的目标的一个早期证明。Codex 不仅仅是一个编码助手，它还可以根据指令独立进行调查、执行、测试和修改。这种主动性有助于在公司内部建立起发展势头。

NTT DATA集团人工智能技术部门的佐藤博明表示：“Codex改变了公司上下对人工智能的看法。”“人工智能可以主导工作的想法，其影响堪比 ChatGPT 的出现。”自那次早期成功以来，NTT DATA 集团的各个团队一直在不断寻找新的用例，以利用 Codex 的独特功能。

> “Codex 的意义不只是帮助开发者更快编写代码。随着 ChatGPT Enterprise 融入员工思考、探索想法和解决问题的方式，Codex 为一种新的工作方式打开了大门。它让 AI 能够研究、组织、执行和验证工作，使每位员工都能改变履行自身职责的方式。”

—NTT DATA Group 全球 AI 办公室负责人 Yuji Shono

## 将 Codex 的潜力拓展到工程领域之外

事件分析所展现的潜力不仅限于软件开发。NTT DATA 集团秉持“零客户”理念，将自身组织视为第一个客户，并鼓励员工在日常工作中尝试人工智能。因此，Codex 的应用范围正在从工程师扩展到各个职能部门的非技术员工。

佐藤解释说：“通过我们的‘零客户’方法，我们积极推动在公司内部使用人工智能。”“Codex 具有巨大的潜力，许多部门的员工都在寻找将其应用到自己工作中的方法。”

非技术员工已经在使用 Codex 来构建轻量级工具、组织大量文件、在 Excel 中分析数据、汇总文档以及编写重复性流程脚本。这些通常是人们想要自动化但手动处理又太耗时的任务。

例如，员工使用 Codex 从信用卡账单中提取交通费用，并将其转入差旅费用表格。Codex 可以跨多个文件进行操作，了解每张纸的结构和输入规则，并帮助验证已完成的传输，从而简化以前手动且繁琐的工作。

另一个重要的转变是，非技术员工现在可以完成以前需要工程师支持的工作。例如，以前创建分析报告需要使用商业智能工具准备数据并构建仪表板。借助 Codex，员工可以直接分析原始数据并创建所需的报告，从而提高效率，同时减少对专业工具和技能的依赖。

这样一来，Codex 所做的就不仅仅是支持软件开发了。它降低了曾经需要专业知识才能从事的工作的门槛，使没有开发经验的员工也能创造出可以在其工作中使用的实用成果。

## 为所有人创造一个安全的环境来使用 Codex

为了在整个组织内推广 Codex 的使用，而不是将其限制在单个团队或员工中，NTT DATA 集团意识到需要一个每个人都能安全、自信地使用它的环境。这一基础不仅对公司自身的员工很重要，而且对公司所支持的各行各业的客户也很重要。

为了使 Codex 能够被企业使用，OpenAI CoE 制定并推出了安全指南以及实用的采用指南。这些指南明确了可以使用哪些数据、Codex 可以连接到哪些系统、如何管理网络流量、应用哪种沙箱模式、何种自动化级别是合适的，以及在哪些情况下需要人工审核。这创造了一种环境，让技术和非技术岗位的员工都能自信地探索使用 Codex 的新方法。

有了这样的安全和治理基础，Codex 的应用范围已经超越了少数高级用例。如今，Codex 已逐渐成为约 9,000 名员工日常工作的一部分。

> “打造安全且治理完善的环境，对于员工放心使用 Codex 至关重要。我们的愿景是让 Codex 不只是工程师的工具。我们希望它自然融入每位员工的日常工作，包括非技术岗位的员工，帮助大家把专业知识和想法转化为更大的影响力。”

—NTT DATA Group 全球 AI 办公室负责人 Yuji Shono

## 结果一览

NTT DATA 集团采用 Codex 已经超越了实验阶段，并在整个组织内取得了切实成果。

- 仅用30分钟就完成了一项复杂的事故分析，而此前五位经验丰富的工程师需要三天才能完成这项分析。
- 发布使用指南并开展实践培训后，Codex 的每周活跃用户增加了 1.4 倍。
- 利用 Playwright 实现内部系统操作自动化，减少日常例行任务所花费的时间，并通过将自动化功能打包为技能，实现了全组织范围内的采用。

## 领导力课程

NTT DATA 集团的经验总结了在整个组织中嵌入 Codex 的五条经验教训。

- 将 ChatGPT Enterprise 融入日常工作，帮助员工养成与人工智能协作所需的习惯。
- 广泛部署 ChatGPT 企业版，通过同伴学习和口碑传播创造网络效应
- 创造一个员工能够安全使用人工智能的环境，并提供适当的安全和隐私保护。
- 将部署视为起点，然后利用使用数据、调查和员工访谈不断改进推广计划。
- 由卓越中心识别并概括高影响力用例，然后将其作为可复用的最佳实践进行分享，并辅以适当的保障措施。

## 将组织知识转化为客户价值

NTT DATA集团的目标不仅仅是提高单个任务的效率。通过将人工智能融入日常工作，该公司正在创造一个人和人工智能都能发挥各自优势、更快创造更大价值的环境。

员工使用 ChatGPT Enterprise 来加深思考，并使用 Codex 来执行任务以达到既定目标。人设定方向并评估结果，而人工智能则解释信息并推动工作向前发展。通过让技术和非技术员工都参与到这种协作中来，NTT DATA 集团正在拓展个人能力，并加强整个组织的执行力。

凭借其卓越中心、员工社区以及强大的安全与治理，该公司在各个部门内识别出具有高影响力的用例，并将其转化为可重用的流程和最佳实践，从而更广泛地共享。

通过“人工智能驱动型公司”的愿景，NTT DATA集团旨在提升每位员工的知识和专业技能，创造新的服务和业务流程，并帮助客户转变运营模式，实现增长。该公司计划通过在其自身组织内展示人工智能的价值，将这种影响扩展到更广泛的客户和社会。
