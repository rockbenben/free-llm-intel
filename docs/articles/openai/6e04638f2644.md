# OpenAI 与 Schibsted Media Group 达成合作

ChatGPT 用户现在将能访问 Schibsted 旗下多个媒体品牌的内容。

Schibsted Media Group 今天宣布与 OpenAI 建立新的合作伙伴关系，将其部分出版刊物的内容——如国家级报纸 VG、Aftenposten、Aftonbladet 和 Svenska Dagbladet——整合进包括 ChatGPT 在内的 OpenAI 产品。这些文章将用于提供最新的新闻摘要，并清晰署名回溯到 Schibsted Media 的品牌，让用户能够核验信息。

这一合作将把 Schibsted Media 的内容带到新的受众面前，同时让 ChatGPT 能用来自北欧各地最新、最相关的信息，更好地回应其 3 亿用户的查询。

Schibsted Media 早已在其业务内部运用 AI，并为读者、听众和观众打造更具参与感的体验。这包括 Aftonbladet 的 AI 聊天机器人——它回答了超过 60 万个读者关于美国总统大选的问题——以及一个提供每周新闻个性化摘要、帮助读者跟进时事的工具。公司还使用 AI 驱动的文字转语音技术将新闻文章转为音频，用文字转视频方案把文章变成生动的多媒体内容——提升了其内容的可及性与触达。

Schibsted Media Group CEO Siv Juvik Tveitnes 表示：“这一合作是 Schibsted Media 更广泛努力的一部分，即以支持和强化新闻业的方式整合 AI。把我们的编辑专业能力与 OpenAI 的技术和洞见结合，我们持续 adaptation，确保新闻业与技术进步共同演进。”

“随着 AI 驱动的平台日益影响人们搜索和接触信息的方式，这一合作让我们有机会探索新的商业路径。通过尽早参与，我们能更好地理解并帮助塑造高质量新闻在 AI 驱动环境中如何分发、变现和持续，”她补充道。

OpenAI 媒体合作负责人 Varun Shetty 表示：“我们与 Schibsted Media 的合作推进了我们支持全球优质新闻、增强 ChatGPT 体验的目标，让人们能获取相关且及时的新闻内容。这是我们整体战略的一部分，让出版者借助先进 AI 技术受益。”
