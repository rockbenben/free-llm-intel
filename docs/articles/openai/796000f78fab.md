隆重推出新一代对话式应用功能，现已在 ChatGPT 内全面上线。开发人员现可通过全新 Apps SDK 即刻开启构建，该工具目前已开放预览版。

ChatGPT 中的各类应用能自然融入对话中。您既可在 ChatGPT 适时推荐时发现它们，也可直接通过名称调用。这些应用不仅能响应自然语言指令，也配备了可在聊天界面直接操作的交互式界面。

对 ChatGPT 用户而言，这些应用会在聊天中与用户互动，基于现有信息实时调整，助力用户释放创意、高效学习以及获享更多功能。对开发者而言，通过 Apps SDK 进行开发，意味着能在合适的时机触达超 8 亿 ChatGPT 用户。

自今日起，欧盟以外地区的已登录 ChatGPT 用户（涵盖免费版、Go、Plus 及 Pro 套餐）均可使用应用功能。我们的试点合作伙伴 Booking.com、Canva、Coursera、Figma、Expedia、Spotify 及 Zillow 即日起也将于其业务覆盖地区上线该服务，初期支持英语版本。更多试点合作伙伴将于今年晚些时候陆续推出，同时我们预计很快将向欧盟用户开放应用服务。

开发人员即日起便可使用全新 Apps SDK 预览版进行应用构建与测试，该 SDK 基于[模型上下文协议⁠（在新窗口中打开）](https://modelcontextprotocol.io/docs/getting-started/intro) (MCP) 构建并作为开放标准发布。要开始构建，请访问我们的[文档⁠（在新窗口中打开）](https://developers.openai.com/apps-sdk)查看指南与示例应用，随后可通过 ChatGPT 中的开发人员模式开展应用测试。

今年晚些时候，我们将开始接受应用提交以进行审核和发布，并分享更多关于开发人员如何实现应用变现的详细信息。

## 如何在 ChatGPT 中使用应用功能？

当您在消息开头输入可用应用名称时（例如“Spotify，为我本周五的派对创建歌单”），ChatGPT 将自动在对话中启动该应用，并结合相关背景信息为您提供帮助。首次使用应用时，ChatGPT 会提示您建立连接，确保您清楚哪些数据可能与应用共享。

当某项应用与对话内容相关时，ChatGPT 也会主动推荐使用相关应用。例如，若您提及购置新房，ChatGPT 便会推荐 Zillow 应用，您可直接在 ChatGPT 内的交互式地图上浏览符合预算的房源信息。

ChatGPT 全新推出的应用功能的强大之处在于：它将地图、歌单、演示文稿等常见交互元素与全新的对话互动方式完美融合。您可以先拟定大纲，再让 Canva 将其转化为幻灯片演示文稿；或者在 Coursera 上选修课程，边观看视频边让 ChatGPT 对其中某个内容进行深入阐述。

随着更多开发人员使用 Apps SDK 进行构建，应用功能将持续释放更多的可能性。由于这些应用会直接出现在聊天界面中，您可以在最需要它们的时候轻松找到。

## 当前上线的应用

我们与一小部分早期合作伙伴共同推出了首批应用，这些应用现已在 ChatGPT 平台上线。基于他们的反馈意见，我们完善了现已向开发人员开放的 Apps SDK 预览版。

## 即将推出的应用

我们也很高兴地宣布，今年晚些时候将上线另外 11 家合作伙伴及其应用服务。

## 如何使用 Apps SDK 进行构建？

ChatGPT 中的应用功能由 Apps SDK 提供支持，该开发套件预览版自今日起面向开发人员开放。Apps SDK 基于模型上下文协议 (MCP) 构建，这项开放标准使 ChatGPT 能够连接外部工具与数据。我们在 MCP 基础上进行扩展，使开发人员能够同步设计应用逻辑与交互界面。将 Apps SDK 开源后，基于此标准构建的应用将能在任何采纳该标准的平台上运行。

开发人员可使用自有代码定义应用界面与对话逻辑，并直接连接其后端系统，使现有客户能直接登录或使用高级功能。

我们已发布包含设计指南的开发文档及开源示例库，帮助开发人员设计出融合了交互与对话功能的使用体验。

此次预览版旨在让开发人员尽早体验这些工具、收集反馈，并共同构建新一代应用。更多可复用组件与高效开发工具即将陆续推出。

## 安全与隐私

根据我们的政策要求，ChatGPT 中提供的应用须遵循 OpenAI 使用政策，确保内容适合所有受众，并遵守关于第三方集成的合作伙伴规则。这些标准旨在为用户打造安全积极的使用体验。

开发人员还需制定明确的隐私政策，仅收集所需最低限度的数据，并对权限使用保持透明。当用户首次连接应用时，ChatGPT 会提示建立连接，以便用户了解哪些数据可能会与开发人员共享。今年晚些时候，我们将推出更精细的数据控制功能，使用户能够自主决定各类应用在提供个性化服务时可使用的数据类型。

为使开发人员了解相关要求，我们已发布[开发人员指南⁠（在新窗口中打开）](http://developers.openai.com/apps-sdk/app-developer-guidelines)草案，其中概述了应用在 ChatGPT 平台上线须满足的标准。

## 下一步计划

今年晚些时候，我们将在 ChatGPT Business、Enterprise 以及 Edu 套餐中推出应用功能。我们还将开放应用提交，方便开发者在 ChatGPT 上发布应用，同时推出专门的目录，供用户浏览和搜索。符合开发人员指南标准的应用将获得目录收录资格，其中达到更高设计与功能标准的应用不仅会在目录中突出显示，还将在对话场景中获得优先推荐。

我们也将公布变现方案细节，包括对新型《代理商业协议》([Agentic Commerce Protocol⁠](https://openai.com/index/buy-it-in-chatgpt/)) 的支持，该开放标准可实现 ChatGPT 内的即时结算功能。

这仅仅是 ChatGPT 应用生态的开端，它将为用户带来全新实用功能，同时为开发人员创造更多机遇。
