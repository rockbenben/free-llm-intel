# 筹备我们的下一次安全冲刺，加固 OpenAI


我们正在规划 OpenAI 的下一次内部安全冲刺（security sprint），把新的研究者和安全伙伴与我们自己的团队聚到一起，用我们自己的模型来检验并加固我们的系统。我们与 Cathedral 达成合作，对方的研究者将和我们团队并肩使用 OpenAI 的模型来挑战我们的防线，为发现弱点带来差异化的专业能力与方法，帮助我们保护自己的平台。

> 「OpenAI 正在树立一个重要的范例：与外部安全公司合作，并用自己的模型持续检验和加固自身的防线。每一家公司都应该思考如何把这些能力用起来。我们很高兴能与 OpenAI 的团队协作，把他们的模型与安全专业能力同我们的研究结合起来，去发现弱点、验证修复，并把这种持续防御的思路做得更扎实。」

**Gavin Kliger，Cathedral 首席执行官兼联合创始人**

我们同时也在对自家的[安全 Bug Bounty 项目](https://openai.com/index/security-on-the-path-to-agi/)[做出改进](https://openai.com/index/rewarding-defenders-with-bigger-bug-bounties/)，其中包括把 critical 级发现的赏金提高到原来的四倍多。我们希望研究者挑战我们的假设，帮助我们既加固自己的系统，也加固我们用来防御这些系统的 methods。

这是我们持续用 AI 发现和修复自身系统弱点这项长期工作的一部分。上一次冲刺已经表明这套做法能交付什么。我们把 25% 的产品工程师投入到发现和修复系统弱点上。工程师们借助 Codex 调查各项发现、在隔离环境中复现漏洞，并准备好补丁供评审。

我们在那份工作之上继续推进，因为仅靠传统的网络防御已经不再够用。近期行业里的一起起事件说明威胁可以出现得多快，也说明构建连续的防御闭环、赶在攻击者之前发现并修复弱点有多重要。

让 [defender’s window](https://openai.com/index/the-defenders-window/)（防御者窗口）保持敞开，要求各组织用前沿的网络能力来加固自己的系统。我们正在用我们最有能力的模型来强化自身防线，并把这些能力开放给 [Daybreak](https://openai.com/daybreak/) 客户。我们已承诺投入 [$1 billion](https://openai.com/index/daybreak-for-frontline-defenders/)，在 6 个月内为保护关键服务和数字基础设施的一线防御者提供带补贴的访问。我们同时也在分享上一次冲刺积累的[架构与经验](https://openai.com/the-defense-factory/)，以及我们面向业界与政府、赋能网络防御者的[蓝图](https://openai.com/index/empowering-cyber-defenders/)。

我们会继续推进模型能力、用它们加固自己的系统，并为可信赖的防御者扩大访问范围。让防御者的窗口保持敞开需要整个行业一起行动，而这些工作必须从现在开始。
