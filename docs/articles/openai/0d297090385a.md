# 准备下一次安全冲刺以强化 OpenAI

我们正在计划 OpenAI 的下一次内部安全冲刺，将新的研究人员和安全合作伙伴与我们自己的团队聚集在一起，使用我们的模型来测试和增强我们的系统。我们正在与 Cathedral 合作，其研究人员将与我们的团队一起使用 OpenAI 的模型来挑战我们的防御，带来差异化的专业知识和方法来发现弱点并帮助我们保护我们的平台。

> “OpenAI 通过与外部安全公司合作并使用自己的模型来不断测试和加强其防御，树立了重要的榜样。每个公司都应该考虑如何将这些功能发挥作用。我们很高兴与 OpenAI 的团队合作，将他们的模型和安全专业知识与我们的研究相结合，以发现弱点、测试修复并加强这种持续防御的方法。”

**Gavin Kliger，Cathedral 首席执行官兼联合创始人**

我们还对我们的安全漏洞赏金计划进行改进，包括将关键发现的奖励增加四倍以上。我们希望研究人员挑战我们的假设，并帮助加强我们的系统和我们用来捍卫它们的方法。

这是我们不断努力使用人工智能来不断发现和修复系统中的弱点的一部分。我们的上一次冲刺展示了这种方法可以带来什么。我们投入了 25% 的产品工程师来查找和修复系统中的弱点。使用 Codex，工程师调查了结果，在隔离环境中重现了漏洞并准备了补丁以供审查。

我们正在开展这项工作，因为仅靠传统的网络防御已经不够了。整个行业最近发生的事件表明，威胁出现的速度有多快，以及建立持续的防御循环以在攻击者之前发现并修复弱点是多么重要。

保持[防御者之窗](https://openai.com/index/the-defenders-window/)开放需要组织使用前沿网络能力来强化其系统。我们正在使用最强大的模型来加强我们自己的防御，并将其提供给 [Daybreak](https://openai.com/daybreak/) 客户。我们已承诺在六个月内投入 [10 亿美元](https://openai.com/index/daybreak-for-frontline-defenders/)，为保护基本服务和数字基础设施的一线防御者提供访问补贴。我们还分享了上一次冲刺的[架构和经验教训](https://openai.com/the-defense-factory/)，以及我们的[蓝图](https://openai.com/index/empowering-cyber-defenders/)，以增强跨行业和政府的网络防御者的能力。

我们将不断改进我们的模型，利用它们来增强我们自己的系统，并扩大可信赖的防御者的访问范围。保持防守者的窗口打开将在整个行业中采取行动，而这项工作需要现在就开始。
