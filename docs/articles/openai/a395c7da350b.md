# OpenAI 与 ServiceNow 在企业工作流方面扩大合作

ServiceNow 将把 OpenAI 的模型和 agent 带入从开发到安全各个环节的工作流，并把 ChatGPT Work 和 Codex 开放给员工。


OpenAI 和 ServiceNow 正在扩大双方的合作，让更多我们的模型和 agent 进入 ServiceNow 的产品，并把 ServiceNow 的工作流与 ChatGPT 和 Codex 打通。我们一起，让企业更容易用 AI 构建应用、处理 IT 请求并解决安全问题。

这次扩大合作，建立在我们[一月宣布](https://openai.com/index/servicenow-powers-actionable-enterprise-ai-with-openai/)的合作基础之上，让 OpenAI 参与到 ServiceNow 为客户以及在其自身业务中所做的更多工作中。

## 通过 ChatGPT 与 ServiceNow 协同工作

一项新的 ServiceNow 集成会把业务上下文和工作流操作直接带进 ChatGPT，帮助团队在同一段对话中调查问题并推进下一步。IT 团队成员无需离开 ChatGPT，就能找到相似事件、评估一次改动的风险，并更新一条 ServiceNow 记录。

客户把自己的 ServiceNow 实例接入 ChatGPT，并选择要开放哪些能力。ServiceNow 的 Action Fabric 会套用既有的业务规则和权限，因此人们能执行的操作会反映其所在组织的配置与访问权限。

ServiceNow 还在预览 ChatGPT 内的交互式体验。在一个示例中，值班工程师可以在 ChatGPT 内查看关联的监控告警、近期改动和受影响的服务，然后指派合适的团队并推进修复。

## 用 OpenAI 驱动更多 ServiceNow 产品

我们还计划在三个方面开发新能力：

- **应用开发：** ServiceNow 的 AI Workflow Factory 计划接入 Codex，帮助开发者利用 ServiceNow 的业务上下文和平台能力构建应用。OpenAI 的模型还将支撑 Build Agent 和 Autonomous Engineer，以支持应用开发与现代化改造。
- **网络安全：** 一套联合安全方案将把 OpenAI 的网络安全能力与 ServiceNow 的资产、身份和业务上下文结合起来，帮助团队调查漏洞、排出风险优先级并协调修复。
- **语音：** ServiceNow 的 Super Intelligence Control Tower 中将提供由 OpenAI 驱动的体验，让人们用口头描述一个 AI 用例，并通过追问补全评估字段、收集缺失的信息。

## 把 ChatGPT Work 和 Codex 带给所有 ServiceNow 员工

ServiceNow 计划让所有员工都能使用 ChatGPT Work 和 Codex，把使用范围扩展到工程组织之外。工程师可以用 Codex 探索代码库、做出改动并运行测试，而业务各条线上的团队则可以在日常工作中使用 ChatGPT Work。ServiceNow 还计划在内部安全工作中使用 OpenAI 的能力。OpenAI 自身也在自己的运营中使用 ServiceNow 的工作流，这一切都由 Super Intelligence Control Tower 提供支撑。

## 可用性

ServiceNow MCP 插件今天已在 OpenAI marketplace 上线，增强后的能力预计在 2026 年底推出。Super Intelligence Control Tower 中的语音能力预计在 2027 年第一季度推出。由 OpenAI 驱动的安全能力预计于 2027 年 1 月进入早期访问，正式可用时间计划在 2027 年第二季度。AI Workflow Factory 中的 Codex 预计在 2027 年可用。
