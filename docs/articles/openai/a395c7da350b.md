# OpenAI 和 ServiceNow 扩大跨企业工作流程的合作伙伴关系

ServiceNow 将把 OpenAI 模型和代理引入从开发到安全的工作流程中，并将 ChatGPT Work 和 Codex 扩展到员工。

OpenAI 和 ServiceNow 正在扩大我们的合作伙伴关系，将更多的模型和代理引入 ServiceNow 产品，并将 ServiceNow 工作流程与 ChatGPT 和 Codex 连接起来。我们共同致力于让企业更轻松地使用 AI 构建应用程序、解决 IT 请求和解决安全问题。

此次扩展建立在我们一月份宣布的合作伙伴关系的基础上，将 OpenAI 引入 ServiceNow 为其客户和自身业务所做的更多工作中。

## 通过 ChatGPT 使用 ServiceNow

新的 ServiceNow 集成将把业务上下文和工作流程操作直接引入 ChatGPT，帮助团队调查问题并在同一对话中采取下一步。 IT 团队成员将能够在不离开 ChatGPT 的情况下找到类似事件、评估更改风险并更新 ServiceNow 记录。

客户将 ChatGPT 连接到他们自己的 ServiceNow 实例并选择要提供的功能。 ServiceNow 的 Action Fabric 应用现有的业务规则和权限，因此人们可以采取的操作反映了其组织的配置和访问权限。

ServiceNow 还在 ChatGPT 内预览交互体验。在一个示例中，值班工程师将能够查看链接的监控警报、最近的更改和受影响的服务，然后分配合适的团队并致力于在 ChatGPT 中进行修复。

## 使用 OpenAI 为更多 ServiceNow 产品提供支持

我们还计划在三个领域开发新功能：

- **应用程序开发：** ServiceNow 的 AI Workflow Factory 中计划的 Codex 集成将帮助开发人员使用 ServiceNow 的业务上下文和平台功能构建应用程序。 OpenAI 模型还将为构建代理和自主工程师提供支持，以支持应用程序开发和现代化。
- **网络安全：**联合安全解决方案将 OpenAI 的网络安全功能与 ServiceNow 的资产、身份和业务环境相结合，帮助团队调查漏洞、确定风险优先级并协调补救措施。
- **语音：** ServiceNow 超级智能控制塔中由 OpenAI 驱动的体验将让人们大声描述 AI 用例，帮助填充评估字段并通过后续问题收集缺失的信息。

## 将 ChatGPT Work 和 Codex 带给所有 ServiceNow 员工

ServiceNow 计划让所有员工都能访问 ChatGPT Work 和 Codex，从而扩展到其工程组织之外。工程师可以使用 Codex 探索代码库、进行更改和运行测试，而整个企业的团队可以在日常工作中使用 ChatGPT Work。 ServiceNow还计划在其内部安全工作中使用OpenAI能力。 OpenAI 还在我们自己的运营中使用 ServiceNow 工作流程，并得到超级智能控制塔的支持。

## 可用性

ServiceNow MCP 插件现已在 OpenAI 市场上提供，预计将于 2026 年底提供增强功能。超级智能控制塔中的语音功能预计将于 2027 年第一季度提供。OpenAI 支持的安全功能预计将于 2027 年 1 月进入抢先体验阶段，计划于 2027 年第二季度全面上市。AI Workflow Factory 中的 Codex 预计将于 2027 年推出。
