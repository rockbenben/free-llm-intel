# Cursor 被 SpaceX 收购后，我们作出的相关决定


今天，我们已通知 SpaceX，计划逐步终止向 Cursor 提供 OpenAI 模型的合同，并提议于 2026 年 11 月 12 日停止服务。为尽可能延长开发者通过 Cursor 使用我们模型的时间，我们按照合同约定给予了最长的提前通知期。这是一个极其艰难的决定，因为我们非常重视让广大开发者都能使用我们的模型。我们之所以作出这一决定，是因为根据 Elon Musk 旗下公司违反合同的过往情况，我们无法确信 SpaceX 会按照我们的服务条款使用我们的技术。

与 SpaceX 这样的大型合作伙伴合作时，我们通常会通过定制合同来确保对方遵守我们的服务条款，并确保集成方案在规模化应用中保障安全。Musk 收购 Twitter（现已并入 SpaceX）后，该公司[违反了⁠（在新窗口中打开）](https://www.nytimes.com/2023/04/27/technology/elon-musk-ai-openai.html)与我们的合同条款（同时还违反了许多其他合同）。今年早些时候，Musk 在宣誓作证时[承认⁠（在新窗口中打开）](https://www.forbes.com/sites/antoniopequenoiv/2026/04/30/elon-musk-admits-xai-distilled-openai-data-to-train-models-heres-what-that-means/)，如今同样已并入 SpaceX 的 xAI 违反了 OpenAI 的服务条款（这些条款与 xAI 自己的条款相似）。

我们与 Cursor 签订的定制协议规定，控制权变更后，我们只有一段有限的时间可以解除合同。随着 AI 能力不断进步，我们也肩负起更高层面的责任，必须确保即将推出的模型 [Astra](https://openai.com/index/responding-next-frontier-critical-cyber-capabilities/) 按照我们的条款使用。综合考虑以上因素，我们决定在不向 Cursor 提供未来模型的前提下，将合同解除日期推迟到我们所能允许的最晚时间。

我们与 Cursor 合作了近四年，非常尊重他们的团队、产品，以及他们为开发者社区所取得的成就。我们知道，受这一决定影响最大的是那些依赖 Cursor 中 OpenAI 模型的开发者。我们十分重视他们在此次过渡期间的体验，并愿意竭尽所能为他们提供支持。
