# 设计即智识自由

ChatGPT 的设计目标是有用、可信、可塑，让你能把它变成"你自己的"工具。

全球每天有数百万人使用 ChatGPT。人们求助它最常见的原因很简单：学习。随着 AI 不仅变得更强大，而且在不同文化、职业和政治观点之间被更广泛地使用，这些工具支持智识自由就变得至关重要。所谓智识自由，就是帮助人们提出自己的问题、遵循自己的推理、自己下判断。

在 OpenAI，我们构建 ChatGPT 时体现这些价值观：以客观为默认、赋予用户强控制力、并以透明的原则指导模型的行为。

## 以客观为默认

我们相信 ChatGPT 默认应保持客观，尤其是在涉及相互竞争的政治、文化或意识形态观点的话题上。目标不是给出唯一答案，而是帮助用户探索多种视角。

我们也公开了内部指引，任何人都可以自行查看我们如何处理这些情形。我们的 [Model Spec](https://model-spec.openai.com/2025-04-11.html) 列出了我们努力注入系统的价值观，包括对有用性、安全、中立和智识自由的承诺。如果 ChatGPT 的回应让你感觉不对劲，Model Spec 有助于澄清该行为是否有意为之、原因为何。

## 捍卫智识自由

Model Spec 的核心原则之一是智识自由：即相信人们应当能够用 AI 探索各种想法——包括有争议的、艰难的想法——而不被导向某种特定的世界观。

这并不意味着毫无边界。模型经过训练，以避免造成伤害、侵犯隐私或协助危险活动。但在学习复杂或敏感话题时，ChatGPT 被设计为开放、审慎、有求必应——而不是说教或拒人千里。它还被设计为具备[协作性](https://model-spec.openai.com/2025-02-12.html#seek_truth)：不应简单附和你的观点，也不应对你所说的一切照单验证。

我们知道这种平衡需要用心把握。过度谨慎会限制探索；过多主见则显得越俎代庖。我们在持续打磨模型处理这些时刻的方式，以更好地体现这种分寸感。

## 由你掌控的个性化

客观是默认值，但我们知道这不等于一刀切。人们带着不同的目标和情境使用 ChatGPT，有时他们希望体验随之调整。

无论你是在日常生活中使用 ChatGPT，还是把它引入组织，我们都认为它应当可定制，以满足你的需求。今年春天我们[推出了新设置](https://openai.com/global-affairs/the-power-of-personalized-ai/)，让个性化 ChatGPT 更容易：调整语气、设定指令、或定义回应应有的风格。

教师可能想要清晰的解释和来源；护理人员可能想要共情和鼓励。有的用户偏好谨慎，有的想要直接。这些控制不会改变事实——但能帮助定制事实的传达方式，让 ChatGPT 在更广泛的情形中都更有帮助。

## 评估我们的工作，才能持续改进

把这件事做对是一个持续的过程，而且我们不是独自进行。

过去几个月，我们与来自政治光谱各端的用户和公民社会组织举行了反馈会，以更好理解 ChatGPT 在真实对话中的表现。这些会议帮助我们暴露差距、更深入理解用户预期，并为今后评估模型行为提供依据。

我们还启动了一项新计划，改进我们对政治偏见与客观性的评估。传统评估——依据评分标准衡量模型回复的测试——未必反映人们实际如何使用 ChatGPT。大多数用户不会让 ChatGPT 在一道多选题式的"立场罗盘"里选答案，甚至不会直接问 ChatGPT 关于它自身信念的问题。因此我们正在开发专门用于识别政治 bias 的新评估，并植根于日常使用：人们如何提问、如何探索想法、如何学习。这将让我们更清楚地理解平衡、准确和可信在实践中是什么样子——而不仅是理论上的。

偏见评估复杂且需要细微判断；我们不指望关起门来就能把所有事做对。我们欢迎反馈，并将很快分享更多关于我们做法的信息，希望这能对 AI 生态中处理同一挑战的其他人有所帮助。
