# 与美国新闻项目（American Journalism Project）合作支持本地新闻

一项新的 500 万（美元）以上合作旨在探索人工智能（AI）的发展如何支持繁荣、创新的本地新闻业，并确保本地新闻机构参与塑造这一新兴技术的未来。

*此消息最初由 American Journalism Project 发布，原文可参阅*[此处⁠（在新窗口中打开）](https://www.theajp.org/news-insights/announcements/american-journalism-project-announces-new-partnership-with-openai-to-support-local-news)*。*

American Journalism Project（AJP，美国新闻项目）是致力于重建本地新闻的领先风险慈善（venture philanthropy）机构，今日宣布与 ChatGPT 背后的 AI 研究与部署公司 OpenAI 建立新合作，共同探索人工智能（AI）的发展如何支持繁荣、创新的本地新闻业。

OpenAI 承诺向 AJP 提供 500 万美元，支持 AJP 扩大其工作，并提供最多 500 万美元的 OpenAI API 额度，帮助其受资助机构在组织内评估和部署新兴 AI 技术。此次协作意在建立本地新闻行业与 OpenAI 之间的对话渠道，并开发能够协助本地新闻机构的工具。

AJP 首席执行官 Sarabeth Berman 表示：“为确保本地新闻业继续成为我们民主制度的重要支柱，我们必须明智地看待新技术的潜在力量与陷阱。在生成式 AI 的早期阶段，我们有机会确保本地新闻机构及其社区参与塑造它的影响。通过这项合作，我们旨在推动 AI 增强而非危害新闻业的途径。”

新闻机构使用 AI 存在重大机会：它可以深化对公共数据与信息的分析；加强并个性化用户体验；开发传递信息的新形态。同时，AI 也给开发者、记者和社会带来重要挑战，包括虚假与错误信息可能增长扩散，以及围绕偏见、隐私和版权的复杂问题。

通过这项合作，AJP 志在为社区驱动的本地新闻机构搭建支持体系，借助 AI 扩展其能力。合作还将支持 AJP 重建本地新闻、在地方层面创建更健康的信息生态以对抗错误信息与虚假信息传播的努力。

OpenAI 首席执行官 Sam Altman 表示：“我们自豪地支持 American Journalism Project 通过重建美国本地新闻业来巩固我们民主制度的使命。这次协作彰显了我们的使命与信念：AI 应惠及所有人，并应被用作增强工作的工具。我们期待与 AJP 及其受资助方合作，形成有价值的反馈回路，探索 AI 技术如何助力本地新闻工作。”

AJP 及其本地新闻机构组合将利用 OpenAI 的资金，从多个方向试验人工智能的应用：

- **创建技术与 AI 工作室：** AJP 将组建一支团队，评估 AI 在本地新闻行业中的应用。该工作室将为 AJP 资助的组织提供专家辅导，在其探索如何最好地利用 AI 工具时补充能力，并促进与 OpenAI 及开发支持高质量新闻、遏止虚假信息传播之 AI 应用的供应商等外部伙伴的协作与反馈回路。作为这项工作的一部分，工作室将跨 AJP 资助组织组建学习社群，在实验展开过程中记录并分享最佳实践、指南与经验。
- **进行试点投资：** AJP 将向其约十个受资助组织直接发放资助，帮助它们探索利用 AI 能力的机会。这些受资助方将试点并试验多种 AI 应用；它们的工作将为整个本地新闻行业示范如何最好地使用 AI 驱动的工具。
- **来自 OpenAI 的 API 额度：** 除 500 万美元资金外，OpenAI 还将向 AJP 及其受资助组织提供最多 500 万美元 API 额度，供其选择构建并使用基于该技术的工具。

American Journalism Project 是应对本地新闻市场失灵的领先风险慈善机构，正在全美建立并推动新一代非营利本地新闻机构。鼓励采用新技术以增进公共利益的新闻业，一直是 AJP 风险式支持的核心组成部分。迄今为止，AJP 已从地方与全国资助方募集 1.39 亿美元应对本地新闻危机，并支持了全美 41 家非营利本地新闻机构。

AJP 成立于 2019 年，其根基是以下证据：健全的新闻业是健康民主的必要组成。本地新闻确保公众保持知情与参与。在互联网时代，本地新闻的显著衰落已对公民生活造成可度量的后果——削弱了居民追究社区、商业与政府领袖责任的能力，也削弱了邻里围绕共同关切彼此联结的能力。

OpenAI 成立于 2015 年，是一家致力于让通用人工智能惠及全人类的研究与部署公司。公司目前由一家非营利机构治理，并遵循其最初的章程。

## 关于 American Journalism Project

American Journalism Project 是一家专注于本地新闻的风险慈善机构。我们相信公民新闻是一项公共产品，并通过构建为民主所需的本地新闻提供资金与维持的商业模式来重新想象它的未来。我们向本地非营利新闻机构提供资助以建设其收入与业务运营，与社区合作创办新机构，并在领导者成长、维持其新闻编辑室的过程中予以辅导。了解更多关于 American Journalism Project 的信息，请[访问我们的网站⁠（在新窗口中打开）](https://www.theajp.org/)。
