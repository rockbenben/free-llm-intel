# 全球新闻合作：Le Monde 与 Prisa Media

我们已与国际金融媒体 Le Monde（《世界报》）和 Prisa Media 达成合作，把法语和西班牙语新闻内容带入 ChatGPT。

我们持续改进 ChatGPT，并支持新闻行业为用户传递实时、权威信息这一关键作用。我们很高兴宣布与 **Le Monde** 和 **Prisa Media** 及其旗下媒体（如 El País、Cinco Días、As 和 El Huffpost）建立合作伙伴关系。这些合作将使 ChatGPT 用户能够在 ChatGPT 中接触 Le Monde 和 Prisa Media 关于近期事件的高质量内容，其内容也将用于我们的模型训练。

**OpenAI 首席运营官 Brad Lightcap** 表示：“我们致力于通过应用新的 AI 技术、为内容创作者拓展机会来支持新闻业。与 Le Monde 和 Prisa Media 的合作中，我们的目标是让全球 ChatGPT 用户以互动且有深度的新方式连接新闻。”

> “与 Le Monde 和 Prisa Media 的合作中，我们的目标是让全球 ChatGPT 用户以互动且有深度的新方式连接新闻。”

Brad Lightcap，OpenAI 首席运营官

未来数月内，ChatGPT 用户将能通过带有署名的精选摘要以及指向原文的增强链接，与这些出版方的相关新闻内容进行互动，用户也可以从新闻网站获取更多资讯或相关文章。

**Le Monde 首席执行官 Louis Dreyfus** 对此表示认同：“在 Le Monde 迎来创刊 80 周年之际，与 OpenAI 的这项合作让我们能够扩大触达范围，并坚守我们大规模提供准确、经过核实、平衡的新闻报道的承诺。与 OpenAI 合作，确保我们的权威内容能被更广泛、更多元的受众接触和欣赏。

媒体格局的每一次转变都为 Le Monde 带来了新的机遇。从向数字平台转型到拥抱免费媒体时代，Le Monde 始终抓住这些时刻，彰显其对独立性、专业能力和新闻操守的承诺。

自 2010 年以来，Le Monde 已成为数字媒体的开拓者：在调整组织结构与运营方式的同时，坚定恪守核心原则。到 2024 年，Le Monde 已确立其作为法国头号新闻媒体的地位，拥有超过 60 万订户、每日 220 万独立用户，每月产生超过 6.32 亿次页面浏览。

我们与 OpenAI 的合作是一项战略举措，旨在确保向 AI 用户传播可靠信息，同时守护我们的新闻信誉与收入来源。”

**Prisa Media 董事长兼首席执行官 Carlos Nuñez** 补充道：“与 OpenAI 携手为我们开辟了触达受众的新途径。借助 ChatGPT 的能力，我们能够以新颖的方式呈现有深度的高质量新闻，触达那些寻求可信、独立内容的读者。这是迈向新闻未来的坚实一步——技术与人类专业素养在此融合，丰富读者的阅读体验。

这是 Prisa Media 数字化旅程的新篇章。我们正不断巩固作为最大的西语媒体集团的地位，在我们的核心市场——西班牙、拉美和美国——运营着领先的媒体品牌。我们的触达规模已达每日超过 700 万独立用户、每月逾 16.5 亿次页面浏览，并明确聚焦于发展文本之外的数字内容形态：在音频方面，我们每月提供 9,000 万总收听小时和 5,100 万次音频下载；在视频方面，月度视频播放量超过 1.41 亿次。”

我们与 Le Monde、Prisa Media 以及 Axel Springer 的合作，帮助新闻机构以新方式触达受众。它们建立在我们与 American Journalism Project 支持创新地方新闻项目的协作、以及与 The Associated Press（美联社）的合作之上——后者也为我们的模型训练提供内容。这些伙伴关系统一体现了我们的愿景：开发先进的 AI 工具，赋能新闻业等行业，解决原本力不能及的问题。
