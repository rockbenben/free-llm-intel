# 为长周期工作做满 Codex 调优

Codex 如何帮助工作在单条提示词之外持续推进

在这份白皮书中，Jason Liu 分享了把 Codex 用作持久工作区的实用策略：保留上下文、管理复杂工作流，帮助长周期项目维持推进势头。

学习如何把宏大目标拆解为可验证的步骤、如何在多条工作线之间保持连续性，以及何时把执行交给 Codex、何时人的监督最有价值。

完整指南见[此处](https://cdn.openai.com/pdf/8a9f00cf-d379-4e20-b06f-dd7ba5196a11/OAI_WhitePaper_Codex-maxxing26.pdf)。
