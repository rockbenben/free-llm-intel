# OpenAI 与微软延长合作伙伴关系

我们高兴地宣布，OpenAI 与微软将延长合作伙伴关系。

微软的这项多年期、数十亿美元的投资，延续其在 2019 年和 2021 年的既有投资，将让我们得以继续独立研究，开发日益安全、有用且强大的 AI。

为践行"让先进 AI 造福全人类"的使命，OpenAI 仍是一家[利润封顶公司⁠](https://openai.com/index/openai-lp/)，由 OpenAI 非营利组织治理。这一结构让我们能够筹集履行使命所需的资本，同时不牺牲我们的核心信念：广泛共享红利，并把安全放在首位。

微软认同我们的愿景与价值观，我们的合作伙伴关系对彼此的进步都至关重要。

- 我们共同打造多台由 Azure 驱动的超级计算系统，用于训练我们全部的模型。Azure 独特的架构设计，在为 AI 训练与推理负载交付一流性能与规模方面起到了关键作用。微软将加大对这些系统的投资，以加速我们的独立研究；Azure 仍将是 OpenAI 研究、API 与产品所有工作负载的唯一云服务商。
- [从真实使用中学习⁠](https://openai.com/index/language-model-safety-and-misuse/)——并把学到的经验纳入——是开发安全而有用的强大 AI 系统的关键环节。使用规模的扩大也有助于让 AI 的红利广泛分发。因此，我们通过与微软合作，经由我们的 API 和 [Azure OpenAI 服务](https://azure.microsoft.com/en-us/blog/general-availability-of-azure-openai-service-expands-access-to-large-advanced-ai-models-with-added-enterprise-benefits/) 部署我们的技术——让企业和开发者能够基于 GPT、DALL·E 和 Codex 构建应用。我们还携手把 OpenAI 的技术构建进 GitHub Copilot、Microsoft Designer 等应用。
- 为构建并部署安全的 AI 系统，我们的团队定期协作，评审并综合共同经验教训——并用它们为我们的系统迭代更新、未来研究，以及在全行业安全使用这些强大 AI 系统的最佳实践提供参考。

我们期待与微软继续协作、推进这一进程。
