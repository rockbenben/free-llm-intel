# RL²：借助慢速强化学习实现快速强化学习（RL²: Fast reinforcement learning via slow reinforcement learning）

阅读论文

## 摘要

深度强化学习（deep RL）已经成功地自动学会复杂行为；然而，其学习过程需要数量极大的尝试。相比之下，动物仅凭寥寥几次尝试就能学会新任务，因为它们受益于对世界的先验知识。本文试图弥合这一差距。我们不是去设计一个“快速”的强化学习算法，而是主张把它表示为一个循环神经网络（RNN）并从数据中学习它。在我们提出的方法 RL² 中，算法被编码在 RNN 的权重里，而这些权重通过一个通用目的（“慢速”）的 RL 算法被缓慢地学习。这个 RNN 接收一个典型 RL 算法所能接收的全部信息，包括观测、动作、奖励和终止标志；并且它在某个马尔可夫决策过程（MDP）内的各回合（episode）之间保留自身状态。RNN 的激活存储了“快速”RL 算法在当前（此前未见过的）MDP 上的状态。我们在小规模与大规模问题上对 RL² 进行了实验评估。在小规模一侧，我们训练它求解随机生成的多臂老虎机问题和有限 MDP。RL² 训练完成后，它在新 MDP 上的表现接近于带有最优性保证的人工设计算法。在大规模一侧，我们在一个基于视觉的导航任务上测试 RL²，并证明它能扩展到高维问题。
