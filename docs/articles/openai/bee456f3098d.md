# Color Health

[Color Health](https://www.color.com/) 正与 OpenAI 合作，开创加速癌症患者获得治疗的新路径。他们的新 copilot（副驾驶）应用使用 GPT-4o 识别缺失的检查诊断、生成定制化检查方案，使医疗服务提供者能够就癌症筛查与治疗做出循证决策。

Color 改善医疗可及性的工作已有十年，自创立以来服务了超过 700 万患者。2023 年，他们与美国癌症协会（American Cancer Society）合作，帮助雇主和健康保险计划掌控癌症——美国第二大死因，也是美国医疗支出的第一推手。

## Color 的副驾驶正帮助临床医生制定个性化、完整的治疗启动方案

Color Health 使用 OpenAI 的 API，把患者医疗数据与临床知识整合起来。成果是一个副驾驶应用：它为医疗服务提供者生成个性化、完整的治疗方案，供其在患者照护中审阅和使用。

"Color 的愿景，是让癌症专业知识在能对患者医疗决策产生最大影响的时间与地点触手可及，"Color Health CEO Othman Laraki 表示。

"作为一家医疗公司，改善可及性与公平的技术，必须与支持患者安全与隐私的技术齐头并进。OpenAI 符合 HIPAA 的数据保护标准是关键。"

副驾驶应用输出的每一步都由临床医生分析，必要时修改后才呈现给患者。工作流程如下：

- 提取、处理并归一化患者信息——如家族病史与个体风险因素——连同临床指南和来自可信来源的数据。Color 团队尤其对 GPT-4o 的能力印象深刻：它能从冗长、结构不一、措辞各异的信息中（常以 PDF 或临床笔记等形式出现）提取并归一化埋藏其中的内容。
- 基于这些数据，回答关键问题，例如"这位患者应该做哪些筛查？"，以识别缺失的诊断项并生成个性化筛查计划。它还生成完成诊断检查所需的文书，如医疗必要性文件和保险预授权。
- 人在环（clinician-in-the-loop）评估输出，其中包含来源信息。临床医生可以编辑副驾驶的输出，这也有助于打磨未来的迭代版本。
- 一旦临床医生对结果满意，即可把这些信息加入患者既有的治疗计划。

## 漏掉的筛查和延误的癌症治疗影响患者结局

癌症的筛查、诊断和治疗出了名地复杂而耗时。而每一次延误都有代价：治疗被推迟仅仅四周的患者，[死亡风险高出 6%–13%](https://www.bmj.com/content/371/bmj.m4087)。

筛查需求也往往高度个体化。例如，Color 超过三分之一的患者需要比标准指南更早、不同的筛查方案，因为其个体风险因素未被标准指南覆盖。"我亲眼见过为高风险患者制定个性化癌症筛查计划的复杂性，"Color 全科医生 Keegan Duchicela 说，"指南不断更新，个体风险因素也并不总是即刻清晰。"

筛查之外，诊断检查带来更多挑战。为一个患者记录并执行一次诊断检查可能耗时数周，多数患者在第一次肿瘤科就诊时并没有完整的检查资料。"如今，肿瘤治疗中存在真实的缺口，取决于患者在哪里得到初步诊断，"斯坦福大学医学院教授、执业肿瘤学家 Allison Kurian 医生说，"我的许多患者需要数周才能完成适当治疗所需的全部检查与评估，其间宝贵时间被白白流失，还给临床医生增加了额外的行政负担。"

## 与 OpenAI 一起构建快速、安全、可靠的可行性验证

Color 于 2023 年开始与 OpenAI 合作，目标是用 AI 改善癌症患者的照护与健康公平。带着癌症筛查、诊断与治疗中的种种难题，Color 寻找的方案需要能够：

- 解读格式不一的患者数据
- 分析密集的医疗指南
- 保护患者数据隐私
- 支持"临床医生在环"的工作流设计，确保患者安全
- 与电子健康档案（EHR）和医院核心系统整合

在初期探索中，Color 建立了快速实验的方法，包括测试 GPT-4 和 GPT-4o 在复杂任务上的表现，例如从癌症诊断临床指南的 PDF 中提取信息。这些 PDF 往往是数百页的复杂流程图，勾画基于诊断检查的照护路径。OpenAI 与 Color 共同开发出一种方法：让 GPT-4 Vision 描述这些流程图的截图，这种方式在保证输出准确性上最有效。

OpenAI 还指导 Color 团队用标准 ChatGPT 界面原型化临床工作流，并用自定义 GPT 生成样例病例——在投入大量工程资源之前就拿到有效的可行性验证。

借助 OpenAI 的专家指导、强大模型和符合 HIPAA 的数据保护标准，Color 得以专注于拆解复杂的医疗决策、打磨提示词、设计"临床医生在环"的工作流，从而打造出副驾驶的第一版。

例如，OpenAI 工程师指导 Color 使用检索增强生成（RAG）而非模型微调来提升输出质量，并改写临床文档以便 ChatGPT 更容易处理。经过反复实验，Color 最终选择 OpenAI 作为其 AI 方案提供商，把 GPT-4o 置于其前沿副驾驶应用的核心。

## 缩短癌症患者开始治疗的时间

为衡量这一工具的影响，Color 正与加州大学旧金山分校海伦·德勒尔综合癌症中心（UCSF HDFCCC）合作。在首次实施中，Color 与 UCSF 将进行回顾性评估，随后开展定向推广。根据评估结果，双方有望把副驾驶整合进 UCSF 全部新发癌症病例的临床工作流。

"UCSF 是采用前沿技术改善患者照护的领导者，"UCSF HDFCCC 院长 Alan Ashworth 博士（英国皇家学会院士）说，"患者投诊初治肿瘤医生时常常带着不完整的检查资料，而汇总并准确判断这些资料何时补全所耗费的时间，让医生无法在其执业范围内充分发挥。我们关注那些能提高诊前病历整理效率与准确性的工具，帮助 UCSF 的癌症患者避免治疗启动上的昂贵延误。"

美国癌症协会 CEO Karen Knudsen 博士对此表示认同。"把 AI 技术与数字化临床工作流结合起来加速这一流程，对所有相关方——患者及其临床医生，以及承担治疗费用的支付方——都是积极的进步。"

Color 对副驾驶的推广采取审慎路线，已开始面向自有临床医生的初步导入，只在有限数量的病例中使用该工具。这些病例接受多层质量保障：

- 使用副驾驶医疗服务提供者能识别出缺失的化验、影像或活检与病理结果，数量是没有使用副驾驶者的 4 倍。
- 使用副驾驶后，临床医生分析患者病历并识别缺口平均只需 5 分钟。没有副驾驶时，数据分散割裂，可能造成数周延误。

2024 年下半年，Color 计划用该副驾驶应用为超过 20 万名患者提供由 AI 生成、经医生审核的个性化照护方案。
