# 基于 CLIP 潜变量的层次化文本条件图像生成

## 摘要

以 CLIP 为代表的对比模型已被证明能学习同时捕获语义与风格的鲁棒图像表征。为了利用这些表征进行图像生成，我们提出一个两阶段模型：先验（prior）根据文本描述生成 CLIP 图像嵌入，解码器则以该图像嵌入为条件生成图像。我们表明，显式地生成图像表征能提升图像多样性，而真实感与描述相似度几乎不损失。以图像表征为条件的解码器还能生成保留原图语义与风格、同时改变表征中不存在的非本质细节的图像变体。此外，CLIP 的联合嵌入空间支持以零样本方式进行的语言引导图像编辑。解码器我们使用扩散模型；先验则同时尝试了自回归与扩散模型，发现后者计算效率更高、样本质量更好。
