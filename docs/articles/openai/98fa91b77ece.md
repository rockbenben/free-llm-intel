# 基于人类偏好的学习

Read paper

(opens in a new window)


构建安全 AI 系统的一步，是让人类不再需要亲手编写目标函数——因为用一个简单代理去代表复杂目标，或者把复杂目标写得稍有偏差，都可能导致不期望甚至危险的行为。我们与 DeepMind 的安全团队合作，开发了一种算法，只需告诉它两个候选行为哪个更好，它就能推断人类想要什么。

我们提出一种学习算法，用少量人类反馈就能解决现代的 RL 环境。带人类反馈的机器学习系统[此前⁠(opens in a new window)](https://papers.nips.cc/paper/4805-a-bayesian-approach-for-policy-learning-from-trajectory-preference-queries)[就⁠(opens in a new window)](https://link.springer.com/chapter/10.1007/978-3-319-02675-6_46)已被[探索⁠(opens in a new window)](https://arxiv.org/abs/1208.0984)[过⁠(opens in a new window)](https://hal.inria.fr/hal-00980839)，但我们对这一方法做了规模化，使它能在复杂得多的任务上工作。我们的算法只需要人类评估者提供 900 比特的反馈，就学会了后空翻——一个看似简单、容易判断但[很难精确指定⁠](https://openai.com/index/deep-reinforcement-learning-from-human-preferences/#bflip) 的任务。

我们的算法用了人类评估者约 900 个单独比特的反馈就学会了后空翻。

整体训练过程是 human、agent 对目标的理解、RL 训练之间的三步反馈循环。

我们的 AI 智能体一开始在环境里随机行动。每隔一段时间，把两段它的行为视频给人看，由人判断哪一段更接近完成目标——在这个例子里是后空翻。AI 逐渐建立一个对任务目标的模型：找到最能解释人类判断的奖励函数，然后用 RL 学习如何实现该目标。随着行为变好，它持续在它最不确定的轨迹对（哪个更好）上向人类征求反馈，进一步修正对目标的理解。

我们的方法展现出可观的样本效率——如前所述，后空翻视频所需的人类反馈不足 1000 比特。它花了人类评估者不到一小时的时间，与此同时策略在后台累计了约 70 小时的总经验（以远快于实时的速度仿真）。我们会继续降低人类需要提供的反馈量。加速版的训练过程见下面视频。

我们在模拟机器人和 Atari 领域的许多任务上测试了这个方法（不告诉智能体奖励函数：即在 Atari 中也拿不到游戏分数）。我们的智能体能从人类反馈中学习，在我们测试的许多环境中达到强劲甚至超人的表现。在下面的动画里，你可以看到用我们的技术训练的智能体在玩各种 Atari 游戏。每帧右侧的横条表示每个智能体对自己当前行为能得多少人类评估者认可的预测。这些可视化表明，用人类反馈训练的智能体学会了重视 Seaquest 里的氧气（左）、在 Breakout 和 Pong 里预判奖励（中）、或琢磨出 Enduro 里撞车后如何恢复（右）。

注意，反馈不必与环境自身的奖励函数一致：例如，我们可以训练智能体在 Enduro 里精准地与其他车辆保持并排，而不是为最大化分数而超越它们。我们还发现，从反馈中学习有时反而胜过用常规奖励函数做强化学习——因为人类塑造奖励比编写环境奖励的人更好。

## 挑战

我们算法的表现取决于人类评估者对"行为看起来对不对"的直觉，所以如果人类对任务把握不好，提供的反馈帮助就有限。与此相关，在某些领域，我们的系统可能让智能体学会欺骗评估者的策略。例如，一个本应抓取物体的机器人，把手臂摆到摄像头和物体之间，让自己*看起来*在抓——如下图。

我们通过加入视觉线索（上面动画中的粗白线）让人类评估者更容易估计深度，解决了这个具体问题。

本文描述的研究是与 DeepMind 的 Jan Leike、Miljan Martic 和 Shane Legg 合作完成的。我们两家组织计划在长期 AI 安全相关的议题上继续合作。我们认为这类技术是迈向安全 AI 系统的一步——系统能学习以人为中心的目标，并能补充和扩展强化学习、模仿学习等现有方法。本文代表了我们安全工作组的代表性工作；如果你有志于研究这样的问题，欢迎[加入我们⁠](https://openai.com/careers/)！

## 脚注

作为对比，我们自己手写奖励函数（右上动画）花了两个小时才让机器人后空翻，虽然也成功了，但远不如仅靠人类反馈训练出来的那版优雅（左上）。我们认为有很多情形，人类反馈能让我们比手工打磨目标函数更直观、更快地指定一个具体目标。

你可以在 [gym⁠(opens in a new window)](https://github.com/openai/gym) 中用以下 Hopper 奖励函数复现这个后空翻：

#### Python

```
1def reward_fn(a, ob):2    backroll = -ob[7]3    height = ob[0]4    vel_act = a[0] * ob[8] + a[1] * ob[9] + a[2] * ob[10]5    backslide = -ob[5]6    return backroll * (1.0 + .3 * height + .1 * vel_act + .05 * backslide)
```
