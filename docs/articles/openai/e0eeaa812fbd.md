# 推出 iOS 版 ChatGPT 应用

ChatGPT 应用会同步你的对话、支持语音输入，并把我们的最新模型改进带到你的指尖。

在 App Store 下载（在新窗口打开）

自 ChatGPT 发布以来，我们从用户那里听说他们喜欢在移动场景下使用 ChatGPT。今天，我们推出 iOS 版 ChatGPT 应用。

ChatGPT 应用免费使用，并在各设备之间同步你的历史记录。它还集成了我们的开源语音识别系统 [Whisper⁠](https://openai.com/index/whisper/)，从而实现语音输入。[ChatGPT Plus 订阅用户⁠](https://openai.com/index/chatgpt-plus/) 可以在 iOS 上独家使用 [GPT‑4 的能力⁠](https://openai.com/product/gpt-4/)、抢先体验新功能并获得更快的响应时间。

探索 ChatGPT 的多面用途：

- 即时解答：获得准确信息，无需在广告或多个搜索结果中翻找。
- 定制建议：在烹饪、旅行规划或撰写贴心消息时寻求指导。
- 创意灵感：生成礼物点子、拟出演示大纲，或写一首恰到好处的诗。
- 专业协助：通过点子反馈、笔记摘要和技术主题辅助来提升生产力。
- 学习机会：按自己的节奏探索新语言、现代历史等更多内容。

我们从美国开始推广，并将在未来几周扩展到更多国家。我们很期待看到你怎么使用这个应用。在收集用户反馈的同时，我们致力于持续改进 ChatGPT 的功能与安全。

借助 iOS 版 ChatGPT 应用，我们正朝着[我们的使命⁠](https://openai.com/about/)再迈一步：把最前沿的研究转化为赋能人们的有用工具，同时不断让它们更易获取。

又及：安卓用户，下一个就是你们！ChatGPT 很快就要来到你们的设备上。
