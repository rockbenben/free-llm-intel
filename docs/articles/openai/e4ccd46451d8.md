# 推出 Activation Atlases

阅读论文· 试用演示

我们创造了[*激活图谱*](https://distill.pub/2019/activation-atlas)（activation atlases，与 Google 研究员[合作](https://ai.googleblog.com/2019/03/exploring-neural-networks.html)完成），这是一种用来可视化神经元之间交互所能表示内容的新技法。随着 AI 系统被部署到越来越敏感的场景，更好地理解它们的内部决策过程，能帮助我们识别弱点并调查失败。

现代神经网络[常常](https://www.technologyreview.com/s/604087/the-dark-secret-at-the-heart-of-ai/)被批评为[一个“黑箱”](https://www.nytimes.com/2017/11/21/magazine/can-ai-be-taught-to-explain-itself.html)。尽管它们在各种问题上都很成功，我们对它们内部如何做决策的理解却十分有限。激活图谱是一种新的视角，可以看到这个箱子里发生的一部分事情。

激活图谱建立在特征可视化（feature visualization）之上，后者是研究神经网络隐藏层所能表示内容的技法。特征可视化领域的[早期](https://pdfs.semanticscholar.org/65d9/94fb778a8d9e0f632659fb33a082949a50d3.pdf)[工作](https://arxiv.org/pdf/1312.6034v2.pdf)主要聚焦于[单个神经元](https://distill.pub/2017/feature-visualization/)。通过采集数十万个神经元相互交互的样本并加以可视化，激活图谱从单个神经元走向了可视化这些神经元共同表示的空间。

理解神经网络内部在做什么并不仅仅出于科学好奇心——我们理解的匮乏削弱了审计神经网络的能力，在高利害场景下也难以确保它们安全。通常，若要部署一段关键软件，人可以审查代码中所有的执行路径，甚至做形式化验证；但对神经网络而言，目前我们做这种审查的能力要受限得多。借助激活图谱，人类能够发现神经网络中未被预料到的问题——例如网络依赖虚假相关来对图像分类的地方，或在两个类别之间复用同一个特征而导致奇怪 bug 的地方。人类甚至可以利用这种理解去“[攻击](https://arxiv.org/pdf/1312.6199.pdf)”模型，修改图像来欺骗它。

举个例子，可以创建一种特殊类型的激活图谱，来展示网络如何区分煎锅和炒锅。我们看到的许多东西都在意料之中：煎锅更方一些，而炒锅更圆、更深。但模型似乎也学到了煎锅和炒锅可以通过周围的食物来区分——特别是，炒锅的判断会受到面条存在的支撑。在图像角落加上面条，就能有 45% 的概率骗过模型！这类似于[对抗贴片](https://arxiv.org/pdf/1712.09665.pdf)这类工作，但它是基于人类理解的。

其他基于“让网络过度激活某些特征检测器”设计的人类攻击往往更有效（有的成功率高达 93%）。但面条的例子尤其有趣，因为它是模型抓住了与正确答案相关、但并非因果的东西。这在结构上类似于我们可能尤为担心的一类错误，比如公平性和偏见问题。

激活图谱的效果超出我们的预期，并强烈提示：神经网络的激活对人类而言可以是有意义的。这让我们更加乐观地相信，在视觉模型中实现某种强意义上的可解释性是可能的。

我们很高兴能与 Google 的研究员[合作](https://ai.googleblog.com/2019/03/exploring-neural-networks.html)完成这项工作。我们相信，在与安全相关的研究上携手协作，有助于在 AI 研究推进的过程中为社会确保最好的结果。
