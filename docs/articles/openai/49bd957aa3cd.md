# 进化策略梯度

阅读论文

查看代码

我们正在发布一种名为“进化策略梯度”（Evolved Policy Gradients，EPG）的实验性元学习方法。该方法对学习型 agent 的损失函数进行进化，从而能够在新任务上实现快速训练。用 EPG 训练的 agent 在测试时可以完成训练范围之外的基本任务，例如导航到房间另一侧的物体——而训练时该物体被放在另一侧。

EPG 训练 agent 具备一种关于“在新任务上取得进展意味着什么”的先验概念。EPG 不是通过学习到的策略网络来编码先验知识，而是将其编码为学习到的 [损失](https://en.wikipedia.org/wiki/Loss_function)[函数](https://arxiv.org/abs/1506.05254)。随后 agent 可以利用这个被定义为时间卷积神经网络的损失函数，在新任务上快速学习。我们已经证明 EPG 可以泛化到*分布外*（out of distribution）的测试时任务，表现出与其他流行元学习算法定性不同的行为。在测试中，我们还发现 EPG 训练 agent 的速度快于现成的策略梯度方法 [PPO](https://blog.openai.com/openai-baselines-ppo/)。EPG 与先前关于为 RL agent [进化](http://www2.hawaii.edu/~nreed/ics606/papers/Ackley91learningEvolution.pdf)[奖励](http://www.ece.uvic.ca/~bctill/papers/ememcog/Niekum_etal_2010.pdf)[函数](https://web.eecs.umich.edu/~baveja/Papers/IJCAIGSLL2016.pdf)[的](https://papers.nips.cc/paper/4146-reward-design-via-online-gradient-ascent.pdf)研究工作相关，但把这一思想推广为进化一个完整的损失函数——这意味着损失函数必须在内部有效地学会一种 RL 算法。

EPG 背后的直觉来自我们都熟悉的体验：学习新技能时，过程中挫败与喜悦交替出现。假设你刚开始学习拉小提琴。即使没有人指导，你也会立刻对“该尝试什么”有所感觉；听着自己发出的声音，你也能判断自己是否在进步——这是因为你实际上可以调用形状非常好的[内部奖励函数](http://www-anw.cs.umass.edu/legacy/pubs/2009/singh_l_b_09.pdf)，它们源自你在其他运动任务上的既往经验，并通过生物演化而来。相比之下，大多数强化学习（RL）agent 面对每个新任务时不使用先验知识，完全依赖外部奖励信号来引导初始行为。从这样一张白纸出发，当前 RL agent 学习简单技能所需时间[远长于](https://arxiv.org/abs/1604.00289)人类也就不足为奇了。EPG 朝着这样的方向迈出了一步：agent 不再是白纸，而是知道在新任务上取得进展意味着什么——因为它过去曾在相似任务上体验过“取得进展”。

EPG 由两个优化循环构成。在内循环中，agent 从零开始学习解决从任务族中采样的特定任务。任务族可以是“把夹爪移动到目标位置 [x, y]”，而该族中的一个具体任务可以是“把夹爪移动到位置 [50, 100]”。内循环使用[随机梯度下降](https://en.wikipedia.org/wiki/Stochastic_gradient_descent)（SGD）针对外循环提出的损失函数优化 agent 的策略。外循环评估内循环学习后取得的回报，并使用[进化策略](https://blog.openai.com/evolution-strategies/)（ES）调整损失函数的参数，以提出能带来更高回报的新损失函数。

与当前 RL 方法相比，学习到的损失函数具有多项优势：用 ES 进化损失函数，让我们能够优化真正的目标（最终训练出的策略表现），而非短期回报；EPG 还允许损失函数自适应于环境和 agent 历史，从而对标准 RL 算法有所改进。

近期有一批关于[元学习](https://arxiv.org/abs/1611.02779)[策略](https://arxiv.org/abs/1611.05763)的[研究](https://arxiv.org/abs/1707.03141)[工作](https://arxiv.org/abs/1703.03400)，值得追问：为什么学习损失函数，而不是直接学习策略？学习循环策略往往会对当前任务过拟合，而学习策略初始化在探索方面表达能力有限。我们的动机在于，我们预期损失函数是一种能够在差异极大的任务之间很好泛化的对象。手工设计的损失函数确实如此：一个精心设计的 RL 损失函数，例如 [PPO](https://blog.openai.com/openai-baselines-ppo/) 中的损失函数，可以非常普适地应用，从打 Atari 游戏到控制机器人都能使用。

为了测试 EPG 的泛化能力，我们做了一个简单实验。我们进化 EPG 损失函数，使“蚂蚁”能够有效地走向竞技场右半区域随机放置的目标。然后我们冻结该损失函数，给蚂蚁一个新目标，这次位于竞技场的*左*半区域。令人惊讶的是，蚂蚁学会了向左走！它们的学习曲线如下（图中红线）：

这一结果令我们兴奋，因为它展示了对*训练分布之外*任务的泛化。这类泛化可能相当难以实现。我们将 EPG 与另一种名为 [RL2](https://arxiv.org/abs/1611.02779) 的元学习算法进行了比较。RL2 试图直接学习能够适应新任务的策略。在我们的实验中，RL2 确实成功让蚂蚁走向屏幕右半区域的目标。然而，当测试时目标位于屏幕左半区域时，它在定性上失败了，只是一个劲向右走。从某种意义上说，它对训练任务集（即向右走）“过拟合”了。

与所有元学习方法一样，我们的方法仍有诸多局限。目前，我们一次只能针对一个小任务族训练出有效的 EPG 损失函数，例如让蚂蚁向左和向右走。但该任务族的 EPG 损失函数几乎不可能适用于截然不同的任务，比如玩《太空侵略者》。相比之下，标准 RL 损失函数*确实*具备这种普适性——同一个损失函数可以用来学习极其多样的技能。EPG 以牺牲普适性换取了性能提升。要达到既优于标准 RL 方法、又具备同等普适性的元学习方法，还有很长的路要走。
