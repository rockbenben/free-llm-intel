# OpenAI 扩大与 Oracle 的合作伙伴关系，将其应用程序引入 ChatGPT

让企业借助 Oracle 能做的事情更进一步——在 ChatGPT 之中，以及通过由 OpenAI 提供动力的新产品。

[了解更多](https://openai.com/business/partners/oracle/)[联系销售](https://openai.com/contact-sales/)


OpenAI 与 Oracle 正把 Oracle 的应用程序和数据引入 ChatGPT，并用 OpenAI 的模型和产品为 Oracle 的新产品与服务提供动力。我们共同致力于帮助企业借助 AI 运行核心业务、构建更好的应用程序，并强化安全。

这建立在双方横跨 OpenAI API、ChatGPT Work 和 Codex 的商业关系之上。Oracle [报告⁠](https://openai.com/index/oracle/)称，其 ChatGPT 活跃用户达 13 万，Codex 活跃用户超过 9.5 万。其招聘团队用 ChatGPT Work 做市场调研，这类调研过去需要两到四天才能汇总完成，如今准备工作只需 15–20 分钟。

OpenAI 与 Oracle 共享同一个愿景：一个 agent 就绪的企业，人与 AI agent 在同一个互联环境中跨业务应用协同工作。我们的目标是让 Oracle 软件更容易被发现、使用和管理，提供更简单的管理方式、统一的登录入口，以及由各组织自身权限与审批所管控的访问。这将帮助企业把 AI 扩展到核心业务的各个环节，并从他们已经在用的软件中获得更多价值。

## 在 ChatGPT 中使用 Oracle

Oracle 正在开发 [Oracle AI Workspace⁠](https://openai.com/business/partners/oracle/)，通过与 Oracle 应用程序和数据的集成，把这一愿景带入 ChatGPT。目标是让人们可以描述自己需要完成的事情、找到正确的信息，并在一处完成已获批准的业务工作流。

例如，一位新加入财务团队的成员可以用 ChatGPT 调查成本、理解采购决策，并弄清月末关账之前还剩哪些工作。预期的体验是把财务、采购和计划应用中的信息汇聚到一起，帮助更多员工在组织自身的权限与审批范围内使用 Oracle 软件。

## 把 AI 带入 Oracle 的产品

与 Oracle AI Workspace 一同，Oracle 还宣布了使用 OpenAI 模型和工具构建的更新与新产品：

- **Oracle AI Security Mesh** 旨在帮助客户使用 OpenAI 的网络安全模型发现并修复应用程序和基础设施中的漏洞。Oracle 负责管理测试基础设施，帮助客户在安全且已获授权的范围内运用这些能力。
- **Oracle AI SMB Bundle** 把 ChatGPT Business 和 Codex 与 Oracle 应用程序以及可周期性获得的 Oracle Cloud Infrastructure 额度结合起来，帮助小型企业构建产品并管理运营。
- **Oracle App Composer** 旨在帮助团队用 Codex 等 AI 工具构建应用程序，将其连接到已获批准的 Oracle 数据和工作流，并在组织内共享。Oracle 负责在 Oracle Cloud Infrastructure 上的部署，并内置公司权限与访问控制。

## 通过 Oracle Marketplace 使用 OpenAI

美国的 Oracle 客户可以通过 [Oracle Marketplace⁠](https://openai.com/index/openai-on-oracle-cloud/) 购买 OpenAI API、Codex 和 ChatGPT Work 的使用权，沿用现有的采购流程，并可使用符合条件的 Oracle Universal Credits。
