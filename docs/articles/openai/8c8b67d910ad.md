我们发布 CoinRun，这是一个训练环境，提供了衡量智能体把经验迁移到新情境能力的指标，并且已经帮助澄清了强化学习中一个[长期存在的⁠(opens in a new window)](https://arxiv.org/pdf/1810.12282.pdf) [谜题⁠(opens in a new window)](https://arxiv.org/pdf/1810.00123.pdf)。CoinRun 在复杂度上取得了理想的平衡：该环境比《索尼克》这类传统平台游戏更简单，但对最先进算法仍构成像样的泛化挑战。


## 泛化挑战

对最先进的深度强化学习[A](https://openai.com/index/quantifying-generalization-in-reinforcement-learning/#citation-bottom-A)（RL）算法来说，跨任务泛化仍然很难。虽然训练出的智能体可以完成复杂任务，却很难把经验迁移到新环境。尽管大家都知道 RL 智能体容易过拟合——即死盯环境的具体细节，而不是学到可泛化的技能——但 RL 智能体的基准测试仍然在它训练所用的环境上评估。这相当于在监督学习里拿训练集当测试集！

此前的工作使用 [Sonic 基准⁠(opens in a new window)](https://arxiv.org/abs/1804.03720)、[程序化生成的网格迷宫⁠(opens in a new window)](https://arxiv.org/abs/1804.06893) 和 [General Video Game AI 框架⁠(opens in a new window)](https://arxiv.org/abs/1806.10729) 来研究这个问题。在所有这些工作中，泛化能力都通过在不同的关卡集合上训练和测试智能体来衡量。在我们的 Sonic 基准上训练的智能体在训练关卡上表现出色，但在没有任何微调的测试关卡上表现很差。在类似的过拟合展示中，程序化生成迷宫上训练的智能体学会了记住大量训练关卡，而 GVG-AI 智能体在训练期间没见过的难度设置下表现糟糕。

## 游戏规则

CoinRun 的设计对现有算法可 tractable（可处理），并模仿了索尼克这类平台游戏的风格。CoinRun 的关卡是[程序化生成⁠(opens in a new window)](https://en.wikipedia.org/wiki/Procedural_generation) 的，为智能体提供了大量且易于计量的训练数据。每个 CoinRun 关卡的目标很简单：收集关卡尽头的唯一一枚硬币。智能体和硬币之间横着若干静态和动态障碍。碰到障碍会导致智能体立即死亡。环境中唯一的奖励来自收集硬币，且该奖励是一个固定的正常数。当智能体死亡、硬币被收集，或经过 1000 个时间步后，关卡结束。

## 评估泛化

我们训练了 9 个玩 CoinRun 的智能体，每个可用的训练关卡数量不同。前 8 个智能体分别在 100 到 16,000 关不等的集合上训练。最后一个智能体在无限制的关卡集合上训练，因此它从不重复看到同一个关卡。我们用策略训练智能体，采用[常见的⁠(opens in a new window)](https://www.nature.com/articles/nature14236) 3 层[卷积架构⁠(opens in a new window)](https://en.wikipedia.org/wiki/Convolutional_neural_network)，我们称之为 Nature-CNN。智能体用[近端策略优化⁠(opens in a new window)](https://arxiv.org/abs/1707.06347)（[PPO⁠(opens in a new window)](https://blog.openai.com/openai-baselines-ppo/#ppo)）训练共 256M 个时间步。由于一局平均持续 100 个时间步，固定训练集的智能体会把每个训练关卡看过数千到数百万次。而在无限制集合上训练的最后那个智能体，大约会看到 200 万个不同的关卡——每个恰好一次。

下面各图中的每个数据点，由最终智能体在 10,000 局中的平均表现得到。测试时，智能体在从未见过的关卡上评估。我们发现当训练关卡少于 4,000 关时会发生严重的过拟合。**事实上，即使有 16,000 个训练关卡，我们仍能看到过拟合！**不出所料，在无限制关卡集合上训练的智能体表现最好，因为它们能访问的数据最多。这些智能体在下图中以虚线表示。

我们把 Nature-CNN baseline 与 [IMPALA⁠(opens in a new window)](https://arxiv.org/abs/1802.01561) 使用的卷积架构做了比较，发现如下图所示，IMPALA-CNN 智能体在任何训练集上的泛化都*好得多*。

## 提升泛化表现

在后续实验中，我们使用固定的 500 个 CoinRun 关卡作为训练集。baseline 智能体在这么少的关卡上很难泛化，正适合用作基准的训练集。我们鼓励其他研究者也在同样这 500 个关卡上训练，直接比较测试时的表现。利用这个训练集，我们研究了几种正则化技术的影响：

- **Dropout 和 L2 正则化**：两者都明显缩小泛化差距，其中 L2 正则化的影响更大。
- **数据增强**（修改版 [Cutout⁠(opens in a new window)](https://arxiv.org/abs/1708.04552)）和 [**批归一化**⁠(opens in a new window)](https://arxiv.org/abs/1502.03167)：数据增强和批归一化都显著提升泛化。
- **环境随机性**：带随机性的训练比上述任何技术都更能提升泛化（细节见[论文⁠(opens in a new window)](https://arxiv.org/abs/1812.02341)）。

## 附加环境

我们还开发了两个额外环境来研究过拟合：CoinRun 的变体 **CoinRun-Platforms**，以及一个简单的迷宫导航环境 **RandomMazes**。在这些实验中，我们使用原版 IMPALA-CNN 架构后接一个 [LSTM⁠(opens in a new window)](http://colah.github.io/posts/2015-08-Understanding-LSTMs/)，因为在这些环境中记忆是取得好成绩的必要条件。


在 CoinRun-Platforms 中，有多枚硬币，智能体要在 1000 步时限内尽量收集。硬币随机散布在关卡的平台上。CoinRun-Platforms 的关卡是更大的固定尺寸，所以智能体必须更主动地探索，偶尔还要原路返回。

**CoinRun-Platforms** 在 2B 时间步后的最终训练与测试表现，随训练关卡数量的变化。

当我们把 CoinRun-Platforms 和 RandomMazes 都跑一遍 baseline 实验时，智能体在所有情况下都严重过拟合。RandomMazes 的过拟合尤其明显——即使用上 20,000 个训练关卡，泛化差距仍然相当大。

## 下一步

我们的结果为理解 RL 泛化的底层挑战提供了洞见。借助程序化生成的 CoinRun 环境，我们可以精确量化这种过拟合。有了这个指标，我们可以更好地评估关键的架构和算法决策。我们相信从这个环境学到的经验会更快地适用于更复杂的场景，也希望用这个基准（以及类似的其他基准）迭代出泛化能力更强的智能体。

我们对未来研究的建议如下：

- 研究环境复杂度与良好泛化所需关卡数量之间的关系
- 研究不同的循环架构是否更适合这些环境中的泛化
- 探索有效组合不同正则化方法的方式

## 脚注

- A 即使是[令人印象深刻的⁠(opens in a new window)](https://deepmind.com/blog/capture-the-flag/) RL 策略，训练时也常常不使用 dropout、批归一化等监督学习技术。然而在 CoinRun 的泛化设定下，我们发现这些技术确实有正面作用，我们之前的 RL 策略其实是在对特定 MDP 过拟合。
