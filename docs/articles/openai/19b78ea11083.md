# 深度双倍下降

阅读论文（在新窗口打开）。

我们表明，[双倍⁠（在新窗口打开）](https://arxiv.org/abs/1812.11118)[下降⁠（在新窗口打开）](https://arxiv.org/abs/1710.03667)[现象⁠（在新窗口打开）](https://arxiv.org/abs/1809.09349)存在于 CNN、ResNet 和 transformer 中：随着模型规模、数据规模或训练时长的增加，性能先变好、再变差、然后又变好。这一效应通常靠精细的正则化来规避。虽然该行为看起来相当普遍，但我们尚未完全理解其成因，并将对该现象的进一步研究视为重要的研究方向。

许多现代深度学习模型类别，包括 CNN、ResNet 和 transformer，在不使用 early stopping 或正则化时都表现出此前被观察到的[双倍⁠（在新窗口打开）](https://arxiv.org/abs/1812.11118)[下降⁠（在新窗口打开）](https://arxiv.org/abs/1710.03667)[现象⁠（在新窗口打开）](https://arxiv.org/abs/1809.09349)。峰值可预期地出现在模型恰好勉强能拟合训练集的“临界区间”。随着我们增加神经网络的参数量，测试误差先下降、再上升，并在模型刚好能够拟合训练集时迎来第二次下降。

无论是经典统计学家的常识“*模型太大更差*”，还是现代机器学习范式“*模型越大越好*”，都不成立。我们发现训练轮次（epoch）上也存在双倍下降。令人惊讶的是，我们表明这些现象会导致“更多数据反而有害”的区间：在更大的训练集上训练深度网络，实际表现反而更差。

## 模型维度的双倍下降

1. 存在“更大模型更差”的区间。

模型维度的双倍下降现象可能导致“用更多数据训练反而有害”的区间。上方图表中，测试误差的峰值出现在插值阈值附近——此时模型恰好勉强能拟合训练集。

在我们观察到的所有情形中，凡影响插值阈值的改变（如更换优化算法、改变训练样本数或标签噪声量），都会相应改变测试误差峰值的位置。双倍下降现象在加入标签噪声的设定中最明显；没有噪声时，峰值更小、容易错过。加入标签噪声会放大这一普遍行为，便于我们研究。

## 样本维度的非单调性

2. 存在“样本更多反而有害”的区间。

上方图表展示了在无附加标签噪声的机器翻译任务上训练的 transformer。如预期，增加样本数会使曲线整体下移到更低的测试误差。但由于更多样本需要更大的模型才能拟合，增加样本数也会把插值阈值（及测试误差峰值）向右推移。

对中等模型规模（红色箭头），这两种效应叠加，我们看到用多 4.5 倍的样本训练反而损害了测试表现。

## 轮次维度的双倍下降

3. 存在“训练更久会逆转过拟合”的区间。

上方图表展示测试与训练误差作为模型规模和优化步数的函数。对给定的优化步数（固定纵坐标），测试与训练误差呈现模型规模的双倍下降；对给定的模型规模（固定横坐标），随着训练进行，测试与训练误差先降、后升、再降——我们称此现象为轮次维度的双倍下降。

*总体而言，测试误差的峰值系统性地出现在模型恰好勉强能拟合训练集之处。*

我们的直觉是：在插值阈值上的模型，实际上只存在唯一一个能拟合训练数据的模型，强迫它去拟合哪怕稍有噪声或错设的标签，都会破坏其全局结构——也就是说，不存在既插值训练集又在测试集上表现良好的“好模型”。然而在过参数化区间，能拟合训练集的模型有很多，其中存在好模型。此外，随机梯度下降（SGD）的隐式偏好会把它引向这些好模型，原因我们尚未理解。

彻底理解深度神经网络中双倍下降背后的机制，我们留作一个重要的开放问题。
