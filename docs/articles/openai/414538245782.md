# 微软与 OpenAI 的合作伙伴关系进入新阶段

修订协议为长期发展扫清障碍


面对日新月异的技术革新，我们必须推动合作伙伴关系持续演进，从而为客户创造更多价值，并实现双赢。今天，我们宣布签署一份修订协议。本协议以灵活性、确定性以及“让 AI 惠及大众”为中心，旨在简化双方的合作模式与协作流程。修订协议带来的更高预见性，不仅强化了我们共同构建并运营大规模 AI 平台的能力，也赋予了双方探索全新机遇的灵活空间。协议核心条款如下：

- 微软将继续担任 OpenAI 的首选云合作伙伴。除非微软无法或选择不提供必要的功能支持，否则 OpenAI 的产品将优先在 Azure 上发布。OpenAI 现已获准通过任何云服务提供商向客户交付其全线产品。
- 微软对 OpenAI 模型及产品的 IP 授权将延长至 2032 年，但该授权性质已转为非独占模式。
- 微软将停止向 OpenAI 支付营收分成。
- OpenAI 向微软支付的营收分成将按原定比例持续至 2030 年，且不受 OpenAI 技术演进的影响，但需遵循约定的总额上限。
- 作为主要股东，微软将一如既往地直接参与并支持 OpenAI 的成长。

尽管本次修订简化了合作架构，但双方共同愿景的宏大程度丝毫不减。从建设吉瓦 (GW) 级的新型数据中心，到联合研发下一代芯片，再到利用 AI 强化网络安全防御，我们对未来协作充满期待，致力于让 AI 技术惠及全球各地的用户与组织。
