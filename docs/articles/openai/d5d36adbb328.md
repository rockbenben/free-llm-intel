# 作为强化学习可扩展替代方案的进化策略

我们发现，作为一种已有数十年历史的优化技术，进化策略（ES）在现代强化学习基准（如 Atari/MuJoCo）上可与标准强化学习（RL）技术匹敌，同时克服了 RL 的诸多不便。

具体而言，ES 实现更简单（无需[反向传播](http://neuralnetworksanddeeplearning.com/chap2.html)）、更易在分布式环境中扩展、不受稀疏奖励场景困扰、且[超参数](https://www.quora.com/What-are-hyperparameters-in-machine-learning)更少。这个结果出人意料，因为 ES 本质上只是在高维空间里"爬山"：每步仅沿若干随机方向做[有限差分](https://en.wikipedia.org/wiki/Finite_difference)。

我们的发现延续了"用几十年前的老想法取得强劲结果"的现代趋势。例如，2012 年的 "AlexNet" [论文](https://papers.nips.cc/paper/4824-imagenet-classification-with-deep-convolutional-neural-networks)展示了如何设计、扩展并训练卷积神经网络（CNN），在图像识别任务上取得极强结果——彼时多数研究者认为 CNN 不是计算机视觉的有前途之路。同样，2013 年的[深度 Q-Learning 论文](https://arxiv.org/abs/1312.5602)展示了如何把 Q-Learning 与 CNN 结合成功解决 Atari 游戏，用激动人心的实验（而非理论）成果重新激活了 RL 这一研究领域。 同样，我们的工作证明 ES 能在 RL 基准上取得强劲表现，打破了"ES 方法不可能应用于高维问题"的普遍信念。

ES 易于实现和扩展。在 80 台机器、1,440 个 CPU 核的集群上运行，我们的实现只用 10 分钟就能训练出一个 3D MuJoCo 人形行走者（A3C 在 32 核上约需 10 小时）。使用 720 核，我们也能在 Atari 上取得与 A3C 相当的表现，同时把训练时间从 1 天压缩到 1 小时。

下文我们先简略介绍传统 RL 方法，再对比我们的 ES 方法，讨论 ES 与 RL 的取舍，最后重点展示部分实验。

## 强化学习

先快速看看 RL 如何工作。假设给定某个环境（如游戏），我们要在其上训练一个智能体。为描述智能体的行为，我们定义一个策略函数（智能体的大脑），计算智能体在任何情境下应如何行动。实践中，策略通常是一个神经网络：输入游戏当前状态，计算采取各允许动作的概率。典型策略函数约有 1,000,000 个参数，于是我们的任务归结为：找到这组参数的精确设置，使策略打得好（即赢下多数对局）。

*上图：在乒乓球（Pong）游戏中，策略可以取屏幕像素，计算把玩家球拍（右侧绿色）向上、向下移动或不动的概率。*

策略的训练过程如下。从随机初始化开始，让智能体与环境互动一段时间，收集互动回合（例如每回合是一局 Pong）。我们由此得到完整记录：遇到了什么状态序列、每个状态采取了什么动作、每一步的奖励是多少。作为示例，下图是三个各持续 10 个时间步的假想环境回合。每个矩形是一个状态，矩形为绿色表示该步奖励为正（例如刚把球打过对手），红色表示为负（例如漏球）：

这张图提示了改进策略的配方：凡是通向绿色状态的动作都是好的，通向红色区域的动作是坏的。随后我们用反向传播计算网络参数的小幅更新，让那些状态下绿色动作未来更可能、红色动作更不可能。我们预期更新后的策略会更好一点。然后迭代：再收集一批回合、再做一次更新，依此类推。

**通过给动作注入噪声来探索。** RL 中常用的策略是随机性的——只计算各动作的概率。这样，训练过程中智能体可能多次处于特定状态，由于采样，不同时刻会采取不同动作。这提供了学习所需信号：有些动作带来好结果、被鼓励，有些行不通、被抑制。因此我们说，通过学习过程中向智能体动作注入噪声（每步从动作分布采样）引入了探索。这与接下来要描述的 ES 形成对照。

## 进化策略

**关于"进化"。** 深入 ES 方法前，务必注意：尽管名字里有"进化"，ES 与生物进化关系极少。这些技术的早期版本可能受生物进化启发，在抽象层面也可视为采样一个个体种群、让成功个体决定后代的分布。但其数学细节已被高度抽象，脱离生物进化甚远，最好把 ES 简单看作一类黑盒随机优化技术。

**黑盒优化。** 在 ES 中，我们完全忘掉存在智能体、环境、神经网络，忘掉互动按时间发生等等。整个设定是：1,000,000 个数进去（恰好描述策略网络的参数），1 个数出来（总奖励），我们想找这 100 万个数的最优设置。数学上，我们说在对输入向量 w（网络的参数/权重）优化函数 f(w)，但对 f 的结构不作任何假设，只要求能求值（因此叫"黑盒"）。

**ES 算法。** 直觉上，这个优化是"猜测-检验"过程：从随机参数出发，反复 1) 随机微调猜测，2) 把猜测朝更有效的微调方向挪一点。具体来说，每步我们取参数向量 w，用高斯噪声抖动 w，生成例如 100 个略有差异的参数向量 w1…w100 组成的种群。然后独立评估这 100 个候选：在环境中运行对应的策略网络一段时间，累加各自的全部奖励。更新后的参数向量成为这 100 个向量的加权和，每个权重与其总奖励成正比（即更成功的候选权重更高）。数学上你会注意到，这等价于用有限差分估计参数空间中期望奖励的梯度——只是仅沿 100 个随机方向做。另一种理解：我们仍然在做 RL（确切说是策略梯度，或 [REINFORCE](http://www-anw.cs.umass.edu/~barto/courses/cs687/williams92simple.pdf)），智能体的动作是用高斯策略发出整个参数向量。

*上图：只有两个参数、奖励函数如色场（红=高，蓝=低）的 ES 优化过程。每次迭代展示当前参数值（白色）、抖动样本种群（黑色）和估计梯度（白色箭头）。我们沿箭头方向不断挪动参数直至收敛到局部最优。可用此 notebook 复现该图。*

**代码示例。** 为把核心算法讲具体、突出其简单，这里给一个用 ES 优化二次函数的短例（或看带更多注释的[更长版本](https://gist.github.com/karpathy/77fbb6a8dac5395f1b73e7a89300318d)）：

#### Python

```
1import numpy as np2solution = np.array([0.5, 0.1, -0.3])3def f(w): return -np.sum((w - solution)**2)45npop = 50      # population size6sigma = 0.1    # noise standard deviation7alpha = 0.001  # learning rate8w = np.random.randn(3) # initial guess9for i in range(300):10  N = np.random.randn(npop, 3)11  R = np.zeros(npop)12  for j in range(npop):13    w_try = w + sigma*N[j]14    R[j] = f(w_try)15  A = (R - np.mean(R)) / np.std(R)16  w = w + alpha/(npop*sigma) * np.dot(N.T, A)
```

*简单示例：在某个解点附近最小化一个二次函数*

**给参数注入噪声。** 注意，优化目标与 RL 优化的完全一致：期望奖励。但 RL 在动作空间注入噪声并用反向传播计算参数更新，而 ES 直接在参数空间注入噪声。换种说法：RL 是对动作"猜测-检验"，ES 是对参数"猜测-检验"。由于噪声注入在参数上，我们可以使用确定性策略（实验中也确实用了）。也可以同时在动作和参数上加噪声，兼取两法之长。

## ES 与 RL 的取舍

相比 RL 算法，ES 享有多个优势（部分略技术化）：

- **无需反向传播。** ES 只需策略的前向计算，不需要反向传播（也不需要价值函数估计），代码更短，实际快 2–3 倍。在内存受限系统上，也不必为后续更新保留回合记录。还无需担心 RNN 的梯度爆炸。最后，我们可以探索大得多的策略函数类，包括不可微的网络（如二值网络）或含复杂模块的网络（如寻路、各种优化层）。
- **高度可并行。** ES 各工作节点之间只需传递少量标量，而 RL 必须同步整个参数向量（可能是数百万个数）。直觉上，这是因为我们能控制每个 worker 的随机种子，各 worker 可在本地重建其他 worker 的扰动。于是节点间通信只需每次扰动的奖励。结果：在我们的实验中，向优化加入数千个 CPU 核时观察到接近线性的加速。
- **更高的稳健性。** RL 实现中若干难以设定的超参数在 ES 中被绕开。例如 RL 并非"尺度无关"，Atari 中 frame-skip 超参数设置不同可带来截然不同的学习效果（包括彻底失败）。如我们工作所示，ES 对任意 frame-skip 的表现都大致相当。
- **结构化探索。** 一些 RL 算法（尤其策略梯度）以随机策略初始化，常表现为长时间原地乱抖。Q-Learning 因使用 ε-greedy 策略而缓解了这一点：取 max 的操作会让智能体持续做某个一致动作（例如按住左箭头）。与原地乱抖相比，这在游戏里更可能做成事。类似 Q-Learning，ES 不受这些问题困扰，因为我们可以用确定性策略实现一致的探索。
- **长时程信用分配。** 对 ES 与 RL 梯度估计做数学研究可以看到：当回合内时间步很长、动作有持久影响、或缺乏好的价值函数估计时，ES 格外有吸引力。

反过来，我们也发现实践中应用 ES 的挑战。一个核心问题是：ES 要奏效，对参数加噪声必须导致不同结果，才能拿到梯度信号。正如论文中详述的，我们发现使用 virtual batchnorm 可以缓解这一问题，但要有效地参数化神经网络、使其行为随噪声而变化，仍需进一步工作。相关困难的一个例子：在 Montezuma's Revenge 中，随机网络几乎不可能在第一关拿到钥匙，而随机动作偶尔可以。

## 相关工作

ES 源自神经进化文献，其在 AI 中历史悠久，完整综述超出本文范围。但建议有兴趣的读者查看 [Wikipedia](https://en.wikipedia.org/wiki/Neuroevolution)、[Scholarpedia](http://www.scholarpedia.org/article/Neuroevolution) 和 Jürgen Schmidhuber 的[综述文章（6.6 节）](https://arxiv.org/abs/1404.7828)。与我们方法最贴近的是 Wierstra 等 2014 年的[自然进化策略](http://www.jmlr.org/papers/volume15/wierstra14a/wierstra14a.pdf)。与该工作及它所启发的许多研究相比，我们的专注点在于：把这些算法扩展到大规模分布式设定、寻找使其与深度神经网络配合更好的组件（如 [virtual batch norm](https://arxiv.org/abs/1606.03498)），以及在现代 RL 基准上评估它们。

也值得注意：神经进化相关方法近来在机器学习文献中有所回潮，例如 [HyperNetworks](https://arxiv.org/abs/1609.09106)、[Large-Scale Evolution of Image Classifiers](https://arxiv.org/abs/1703.01041) 和 [Convolution by Evolution](https://arxiv.org/abs/1606.02580)。

## 结论

我们的工作表明：在现代"智能体-环境"基准上，神经进化方法可与强化学习方法竞争，同时在代码复杂度与大规模分布式扩展的容易程度上带来显著好处。我们还期待重访这一脉络的其他想法能做出更精彩的工作，如间接编码方法，或连同网络结构一起进化。

**关于监督学习的说明。** 还要注意：监督学习问题（如图像分类、语音识别或业界大多数任务）可以直接用反向传播计算损失精确梯度，因此不受上述发现影响。例如我们在初步实验中发现，用 ES 估计 MNIST 手写数字识别的梯度，比反向传播慢多达 1,000 倍。只有在必须靠采样估计期望奖励梯度的 RL 场景中，ES 才有竞争力。
