# 神经语言模型的缩放定律

Read paper




## 摘要

我们研究语言模型在交叉熵损失上的经验缩放定律。损失会随模型规模、数据集规模和训练所用算力以幂律缩放，其中一些趋势跨越七个数量级以上。其他架构细节，比如网络宽度或深度，在一个较宽范围内影响极小。简单的方程刻画了过拟合对模型/数据集规模的依赖，以及训练速度对模型规模的依赖。借助这些关系，我们可以确定固定算力预算的最优分配方式。更大的模型显著更节省样本，因此算力最优的训练涉及在相对较少的数据上训练非常大的模型，并在收敛之前显著提前停止。
