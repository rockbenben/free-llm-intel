# ChatGPT Sites

用 Codex 创建轻量级网站或应用。

ChatGPT sites 是一种从 Codex 创建并分享在线网站或轻量级应用的方式。

你描述自己的需求，与 Codex 一起构建，然后部署一个工作区里的人可以打开和使用的网站。

当你有一件工作需要一个“安放之处”时，网站会很有用：一个发布跟踪器、一个用于每周复盘的仪表盘、一个用于比较选项的计算器，或一个新项目的入门页面。

## 什么是内部站点或应用？

内部站点是为组织或工作区内部人员创建的网页。它给团队提供一个可以反复回来的、服务某件具体工作的地方。

例如，一个内部站点可以把产品发布的里程碑、负责人、链接和风险汇聚到一起。团队成员不必翻阅多份文档，只需打开一个页面就能查看最新信息。

轻量级应用与之类似，但包含人们与信息互动的方式。计算器可能要求输入几项数据并显示结果。仪表盘可能帮助人们以统一的格式审阅信息。

这些工具的范围通常小于完整的软件产品。它们往往是为一个团队、一个项目或一项例行工作流而创建的。

| **形态** | **适合做什么** | **示例** |
| --- | --- | --- |
| 文档 | 阅读或分享信息 | 一份书面发布计划 |
| 内部站点 | 给一个群体一个可回访的页面 | 带里程碑和链接的发布跟踪器 |
| 轻量级应用 | 帮助人们处理信息 | 用于比较项目方案的计算器 |
| 更大的软件项目 | 支持更复杂或长期的产品需求 | 需要高级基础设施的定制系统 |

## ChatGPT sites 能做什么

在 Codex 桌面应用中，你可以让 Codex 为一件真实的工作构建网站或轻量级应用。

Codex 帮助创建站点，并从构建它的工作区直接部署。你可以检查结果、告诉 Codex 要改什么，并在准备好供他人使用时部署更新版本。

ChatGPT sites 内置托管、访问控制、存储和数据库支持。

## 从小而聚焦的用例开始

一个好的第一个站点应为一个明确的群体解决一个清晰的问题。

| **如果你的团队需要……** | **你可以创建……** | **包括……** |
| --- | --- | --- |
| 跟踪一次发布 | 发布跟踪器 | 里程碑、负责人、链接和风险 |
| 每周审阅信息 | 仪表盘 | 周会审阅所用的信息 |
| 比较选项 | 计算器 | 输入、假设和清晰的结果 |
| 帮助新成员加入项目 | 入门页面 | 背景、资源和下一步 |
| 组织一个项目 | 内部页面 | 关键链接、更新和参考材料 |

有用的站点可以很小。目标是做出一个人们能为了特定任务打开并使用的东西。

## 如何在 Codex 中构建站点

### 1. 描述你的需求

先告诉 Codex 你想创建什么、谁会使用它。

例如：

*为我们的跨职能团队构建一个发布跟踪器。包括里程碑、负责人、链接、风险和一个每周更新区。让页面在我们每周复盘时易于快速浏览。*

### 2. 审查第一个版本

打开站点，检查它是否体现了你想到的工作流。

查看内容、结构、标签，以及任何计算或交互元素。像一个第一次打开它的团队成员那样测试主要体验。

### 3. 让 Codex 修改

你可以继续对话，描述你想调整的地方。

例如：

*把风险部分移到页面更靠上的位置。为里程碑负责人添加筛选。让每周更新更容易快速浏览。*

### 4. 部署站点

站点准备好后，让 Codex 部署它。

Codex 会提供已部署版本的 URL。如果站点没有自动部署，可以要求：

*部署这个站点并给我 URL。*

在 Chrome 中打开部署后的链接，在分享前再检查一次站点。目前不支持应用内浏览器。

### 5. 分享给合适的人

准备好扩大访问范围时，点击 Codex 回合末尾的 Share（分享）按钮。

根据你的工作区设置，你可以把站点分享给特定的人或群组。之后也可以回到 Codex 侧边栏的站点页面，查看站点设置并管理访问权限。

对于 Enterprise 工作区，由管理员控制 ChatGPT sites 是否可用。

## 分享前先审查

站点可能包含计划、分析、项目信息或用户输入。分享之前，同时检查内容和受众。

## 用自动化让站点保持更新

目前站点还不能直接连接实时数据。如果站点里的信息经常变化，你可以创建一个单独的自动化，按计划收集最新更新并为站点准备刷新后的版本。例如，自动化可以在每个工作日上午查看已批准的项目跟踪器，总结变化，并以统一格式整理最新的里程碑、负责人和风险。然后你可以审阅更新并按需刷新站点。

ChatGPT sites 面向聚焦的网站和轻量级应用。有些项目可能仍需要别的工具或更大的工程投入。

## 试一试

从一个支持团队已经理解的真实项目的站点开始。

*为这个项目的新成员构建一个入门站点。包括简短概览、关键文档、团队名录、常见问题和第一周清单。在开始构建之前，先提出一个简单的页面结构，并向我问清你需要的问题。*

或者试试计算器：

*构建一个帮助团队比较项目方案的轻量级应用。先向我询问输入项、假设和评分规则。然后创建一个展示分数计算过程的结果页面。*

## 常见问题

### 我需要懂编程吗？

你可以用通俗语言描述想要的站点来开始。Codex 可以构建第一版，并根据你的反馈进行修改。

### 站点和完整软件产品是一回事吗？

站点适合聚焦的内部工具、页面、仪表盘或计算器。更复杂的产品可能仍需要一个独立的工程项目。

### 部署后还能更新站点吗？

让 Codex 做出修改、审查新版本，并在准备好时部署更新。

### 站点能连接我所在组织的数据吗？

目前站点还不能直接连接实时数据源。对于经常变化的信息，用单独的自动化按计划收集更新，然后审阅变化并按需刷新站点。

### 管理员应该审查什么？

管理员应确认 ChatGPT sites 是否启用、谁能创建和分享站点、工作区里存在哪些站点、谁能访问它们，以及站点何时应当被移除。
