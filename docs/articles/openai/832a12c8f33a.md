# 学习永不止步：AI 如何让学习持续发生


随着学生重返校园，OpenAI 发布了一份新报告，介绍学生和教育工作者目前如何利用 ChatGPT 将学习延伸到课堂之外。

长期以来，学生往往只能等到上课时才能提问或寻求帮助。教师既要处理行政事务，又要兼顾数十名学生。问题出现时，家长和辅导老师未必随时都能提供帮助。如今，AI 正在改变这一切，让学生能在需要时随时获得指导、反馈和练习。

一项注重隐私保护的分析发现，各年龄段用户每周与 ChatGPT 进行多达 7000 万次旨在检验知识掌握情况的对话，包括核查错误认知和请求更多练习。在美国，学年期间，与课堂学习和家庭作业相关的消息（提示词）数量在高峰时每周超过 4.6 亿条，并会在周日晚间上升。即使在暑假期间，这类消息每周仍超过 1.8 亿条。

对学生而言，持续学习意味着趁课堂内容记忆犹新时，在课外也能获得代数方面的帮助。对教师而言，这意味着可以在第一声上课铃响起前，针对不同能力水平调整作业；也意味着减少处理重复性文书工作的时间，把更多精力投入教学。对在家使用另一种语言的家庭而言，这意味着可以用自己理解的语言接收学校通知，从而更好地支持孩子成长进步。

报告还重点介绍了美国各地以富有成效、创意且有意义的方式使用 AI 的教师和学生。

AI 无法取代教师的判断、家长的鼓励，也无法替代学生在学习中必须付出的努力。但在适当的指导和保障措施下，AI 可以让教育工作者有更多时间专注于教学，并让更多人在更多时候获得个性化支持。
