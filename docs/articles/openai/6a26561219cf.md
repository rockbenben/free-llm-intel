# GamePad：一个定理证明的学习环境

## 摘要

在本文中，我们介绍了一个名为 GamePad 的系统，可用于探索把机器学习方法应用于 Coq 证明助手中的定理证明。Coq 这类交互式定理证明器让用户以逐步方式构造可被机器检查的证明。因此，它们为在人类监督下探索定理证明提供了机会。我们使用 GamePad 为一个简单的代数重写问题合成证明，并为一个 Feit-Thompson 定理的形式化训练基线模型。我们处理了基于战术的定理证明中自然出现的两类任务：局面评估（即预测剩余证明步数）和战术预测（即预测下一个证明步骤）。
