# 训练一致性模型的改进技术

Read paper

(opens in a new window)


一致性模型（consistency models）是一类新兴的生成模型，无需对抗训练即可一步采样出高质量数据。当前的一致性模型通过从预训练扩散模型蒸馏并使用 LPIPS 等学习度量来达到最优样本质量。但蒸馏会把一致性模型的质量限制在预训练扩散模型的水平，而 LPIPS 会给评估带来不良偏置。为应对这些挑战，我们提出一致性训练（consistency training）的改进技术——一致性模型不经蒸馏、直接从数据学习。我们深入探讨一致性训练背后的理论，发现了一个此前被忽视的缺陷，并通过从教师一致性模型中去掉指数移动平均（Exponential Moving Average）来解决它。为替代 LPIPS 等学习度量，我们采用稳健统计中的伪 Huber 损失（Pseudo-Huber loss）。此外，我们为一致性训练目标引入对数正态噪声调度，并提出每隔固定训练迭代数将总离散化步数翻倍。再加上更好的超参数调优，这些改动使一致性模型在 CIFAR-10 和 ImageNet 64×64 上单步采样分别取得 2.51 和 3.25 的 FID 分数。相比以往的一致性训练方法，这标志着 3.5 倍和 4 倍的提升。通过两步采样，我们在这两个数据集上把 FID 进一步降到 2.24 和 2.77，无论一步还是两步设置下都超越了蒸馏所得的分数，并收窄了一致性模型与其他最先进生成模型之间的差距。
