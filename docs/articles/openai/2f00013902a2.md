# Replit 借助 GPT‑5.6 Luna 让更多人能够创作软件

Replit 推出由 GPT‑5.6 Luna 支持的免费模式，让任何人都能将想法变成可运行的软件，而不必担心 Token 成本。

随着模型能力不断提升，其经济性也在迅速变化。更高的性价比让先进智能能够切实应用于更多产品、工作流程和场景。对于软件创作而言，这一转变正在缩短从产生想法到构建出可用成果的距离。

[Replit](https://replit.com/customers) 与 OpenAI 长期以来一直秉持同一个目标：无论技术背景如何，让任何有想法的人都能创作软件。在自然语言软件开发刚开始成形时，Replit 就率先采用 GPT‑3，并使用 OpenAI 模型进行构建。如今，GPT‑5.6 Luna 正在为 Replit 免费模式提供支持，展现 GPT‑5.6 系列的性价比与 OpenAI 最近的降价如何让更多人能够大规模使用这项技术。

> “你将首次获得一种出色的体验，可以在免费模式下构建应用、智能体和各种软件。而这一切都由 GPT-5.6 Luna 提供支持。”

—Amjad Masad，Replit 联合创始人兼首席执行官

## 让强大模型惠及广大用户

对 Replit 而言，模型成本曾是软件创作广泛普及的最后几项障碍之一。GPT‑5.6 Luna 融合了强大能力、高性价比和可靠的大规模推理，让免费模式得以面向数百万用户开放。

> “感谢 OpenAI 以及你们最近的降价，让我们能够向数百万用户提供免费模式。”

—Amjad Masad，Replit 联合创始人兼首席执行官

## 帮助每个人在构建前完善想法

借助 Replit 免费模式，用户无需消耗使用额度，即可在几秒内获得快速、准确的答案、建议、反馈和分析。由于 Agent 能理解用户项目的完整上下文，因此可以在用户进入构建模式前，帮助他们规划、构思、完善、优化和探索想法。

这种连贯性至关重要。Replit 并未将探索与创作割裂开来，而是让任何人都能在同一环境中完善想法，并将其变成可运行的软件。当任务需要更高级的推理时，Replit 可将其转交给 GPT‑5.6 Sol，随后再回到由 GPT‑5.6 Luna 支持的免费模式，同时保留项目上下文。

## 让每个人都能参与构建的共同愿景

对 OpenAI 和 Replit 而言，免费模式体现了更优的模型经济性可以释放怎样的潜力。随着智能变得更强大、更实惠，软件创作将不再局限于少数专家，而能惠及任何有想法且可以上网的人。

> “如果我们能创造一个让任何可以上网的人都能打造产品、创办初创企业并顺利起步的世界，我相信，我们将见证一场前所未有、堪比文艺复兴的创业热潮。”

—Sam Altman，OpenAI 首席执行官

这让更多人有机会利用软件解决问题、改善社区或将想法变为现实。Masad 称软件是"一种赋予人们强大能力的工具"，并表示，如果能让有能力进行构建的人数增加 100 倍，就能让更多人获得这一机会。

通过将 GPT‑5.6 Luna 与围绕项目上下文打造的体验相结合，Replit 正在把模型性价比的提升转化为更广泛的使用机会。这让双方朝着合作背后的共同愿景又迈进一步：任何有想法的人都应该能够动手构建。
