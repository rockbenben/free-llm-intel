# 具备对手学习意识的学习

阅读论文



## 摘要

多智能体设定在机器学习中正迅速变得重要。这既包括近期大量关于深度多智能体强化学习的工作，也可以扩展到分层强化学习、生成对抗网络以及去中心化优化。在所有这些设定中，多个学习智能体的存在使训练问题变成非平稳的，常常导致训练不稳定或最终结果不理想。我们提出 LOLA（Learning with Opponent-Learning Awareness，具备对手学习意识的学习）：每个 agent 都会去塑造环境中其他 agent 预期的学习过程。LOLA 的学习规则中包含一项，用来刻画一个 agent 的策略对其他 agent 预期参数更新的影响。结果表明，两个 LOLA agent 相遇时，在重复囚徒困境（iterated prisoners' dilemma）中会涌现出以牙还牙（tit-for-tat）策略，从而实现合作，而独立学习则不会。在这一场景中，LOLA 相比朴素学习器拿到更高的收益，并且能抵抗更高阶梯度方法的利用。用在重复的猜硬币（matching pennies）博弈上，LOLA agent 会收敛到纳什均衡。在一场循环赛（round robin）中，我们展示 LOLA agent 成功地塑造了文献中一系列多智能体学习算法的学习过程，在 IPD 上取得最高的平均回报。我们还表明，LOLA 更新规则可以用策略梯度估计器的一个扩展来高效计算，因此该方法适用于无模型（model-free）RL。这样一来，方法就能扩展到大的参数空间和输入空间以及非线性函数逼近器。我们把 LOLA 应用到一个内含社会困境（social dilemma）的网格世界任务上，使用循环策略和对手建模。通过显式考虑另一个 agent 的学习过程，LOLA agent 出于自身利益学会了合作。代码见[此链接⁠(在新窗口打开)](https://github.com/alshedivat/lola)。
