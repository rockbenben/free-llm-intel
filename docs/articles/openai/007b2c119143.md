# Instacart 与 OpenAI 合作打造 AI 购物体验

**核心要点：**

- 有了 ChatGPT 里的 Instacart 应用，用户可以浏览生鲜食品、加入购物车，并通过 OpenAI Instant Checkout 无缝结账，全程不用离开对话。
- 这一全新体验建立在 OpenAI 与 Instacart 长期合作的基础上，双方一直在共同推动 AI 驱动的购物。

OpenAI 和 Instacart 正在深化双方的长期合作，把首个完全集成的生鲜购物与 Instant Checkout 即时结账支付应用带入 ChatGPT。通过 ChatGPT 里的 Instacart 应用，用户可以从一顿饭的灵感一路走到送货上门，全程不离开对话。这次集成在 OpenAI 前沿模型的助力下，接入了 Instacart 实时的生鲜零售网络和履约能力。

Instacart 是首个在 ChatGPT 内直接提供结账体验的应用，底层由 [Agentic Commerce Protocol](https://openai.com/index/buy-it-in-chatgpt/) 驱动。

"Instacart 和 ChatGPT 正在重新定义 AI 购物的可能性，" Instacart 首席技术官 Anirban Kundu 表示。"基于 Agentic Commerce Protocol 打造的这一体验，为日常生活中最基本的环节之一——买菜喂饱一家人——带来了智能的实时支持。我们共同创造了一种无缝且安全的方式，让人们把简单的对话变成现实世界的行动，帮助顾客轻松地从灵感出发，到购物车装满，再到从门店送货到家。"

"有了直接内置在 ChatGPT 里的 Instacart 应用，用户在一次流畅的对话中就能从餐食规划走到结账，" ChatGPT 负责人、副总裁 Nick Turley 说。"这是我们愿景落地的又一步——AI 给出有用的建议，并直接连接现实世界的服务，为人们的日常生活省下时间和精力。"

举一个这种新体验的例子：用户可以问 ChatGPT "帮我在 Instacart 上买做苹果派的材料"，ChatGPT 就会调出 Instacart 应用。当用户提到食物、食谱或用餐点子时，ChatGPT 也会主动推荐这个应用。

用户连接应用并用自己的 Instacart 账号登录后，Instacart 应用会在 OpenAI 模型的帮助下，从本地零售商那里找到合适的商品，拼出一个待确认的购物车。之后，用户可以直接在 ChatGPT 内的 Instacart 应用里结账并安全支付——不需要切换标签页。Instacart 随后会通过其可靠的平台匹配采买员，完成订单的拣货和配送。

## 合作的延展

ChatGPT 里的 Instacart 应用是两家公司长期合作的延续。Instacart 是 OpenAI [Operator](https://openai.com/index/introducing-operator/) 研究预览版最早的贡献者之一，提供了宝贵反馈，帮助确保这项技术满足真实世界需求的同时尊重既有惯例。

如今，Instacart 持续使用 OpenAI API 与其自研技术形成互补，通过个性化推荐，帮助顾客节省时间、寻找灵感，并自信地做出与食物相关的决策。

Instacart 还使用 ChatGPT Enterprise 支撑内部工作流，帮助员工更快、更聪明地打造更个性化的客户体验。此外，Instacart 用 OpenAI 的 Codex 驱动了一个内部编码代理。

这次合作升级进一步延伸了 OpenAI 与全球最大、最成熟企业的合作版图，包括 [Accenture](https://openai.com/index/accenture-partnership/)、[Walmart](https://corporate.walmart.com/news/2025-10-14/walmart-partners-with-openai-to-create-ai-first-shopping-experiences)、[Salesforce](https://www.salesforce.com/news/press-releases/2025-10-14/openai-partnership-expansion-announcement/)、[PayPal](https://newsroom.paypal-corp.com/2025-10-28-OpenAI-and-PayPal-Team-Up-to-Power-Instant-Checkout-and-Agentic-Commerce-in-ChatGPT)、[Intuit](https://openai.com/index/intuit-partnership/)、[Target](https://openai.com/index/target-partnership/)、[Thermo Fisher](https://corporate.thermofisher.com/us/en/index/newsroom/Our-stories/Thermo-fisher-scientific-open-ai-collaboration.html)、[BNY](https://www.wsj.com/articles/bny-americas-oldest-bank-signs-multiyear-deal-with-openai-74987d1d?gaa_at=eafs&gaa_n=AWEtsqfSmObbQFCZOy4JBHnm1deYz6_WcJa0ETCyryA8EMyIAT7C9Nc1ZUZGLm2Oejw%3D&gaa_ts=69209805&gaa_sig=xrOe0zyM-gm4Sh4iPKjx6PFtsWjVmHwHOqdO2nCiVeINJqnTWfAUeX5z8MJYum0EeWnrHHwU0CBiVmHp_p_Y6g%3D%3D)、[Morgan Stanley](https://openai.com/index/morgan-stanley/)、BBVA 等许多公司。

全球有超过 100 万企业客户正在直接使用 OpenAI——这是有史以来增长最快的商业平台。
