# 用能量函数学习概念

我们开发了一个[基于能量的模型（energy-based model）](https://arxiv.org/abs/1708.06008)，它能快速学会识别并生成以二维点集表达的概念实例，例如"接近""上方""之间""最近""最远"。我们的模型只需五次示范就能学会这些概念。我们还展示了跨领域迁移：用二维粒子环境中学到的概念，去解决三维物理仿真机器人上的任务。

人类智能的许多标志——从有限经验中泛化、抽象推理与规划、类比推理、创造性解决问题、语言能力强——都要求把经验凝练为*概念*，概念是理解和推理的基本构件。我们的技术让智能体从任务中学习并提取概念，再用这些概念在各种领域解决其他任务。例如，我们的模型可以把二维粒子环境中学到的概念，直接用于在三维物理机器人环境执行同样的任务——**无需在新环境中重新训练**。

本工作使用能量函数，让智能体学会*分类*和*生成*简单概念，并用它们解决诸如在差异极大的环境中于两点间导航之类的任务。概念的例子包括视觉的（"红色""方形"）、空间的（"内部""上方"）、时间的（"慢""之后"）、社交的（"攻击性""乐于助人"）等。如 [DeepMind](https://deepmind.com/blog/imagine-creating-new-visual-concepts-recombining-familiar-ones/) 和 [Vicarious](https://www.vicarious.com/2018-02-07/learning-concepts-through-sensorimotor-interactions/) 的其他研究所示，这些概念一旦学会，就成为智能体理解与推理的基本构件。

*能量函数让我们构建的系统既能生成（左）也能识别（右）像"方形"这样的基本概念。*

能量函数的工作原理是对世界状态的*偏好*进行编码，这使得拥有不同可用动作（改变力矩 vs 直接改变位置）的智能体，能学到在不同情境下都有效的策略——这大致相当于形成了对简单事物的概念性理解。

## 工作原理

为构造能量函数，我们把概念用[能量模型](http://yann.lecun.com/exdb/publis/pdf/lecun-06.pdf)在数学上表示。能量模型的思想根植于物理学，直觉是：被观察到的事件和状态代表低能量构型。

我们为每个概念定义能量函数 E(x, a, w)，其中：

- 模型观察到的世界状态（x）
- 对该状态中实体的[注意力掩码](http://akosiorek.github.io/ml/2017-10-14/visual-attention.html)（a）
- 一个用作条件输入的连续值向量（w），指明当前计算能量所对应的概念

世界状态由实体集合及其属性与位置组成（如下方的圆点，兼具位置和颜色属性）。用于"识别"的注意力掩码表示模型对某个实体集合的聚焦。能量模型输出一个正数，指示概念是否被满足（能量为零即满足，能量高则不满足）。当注意力掩码聚焦在一组代表该概念的实体上时，概念即被满足——这既要求实体处于正确位置（改变 x，即生成），也要求聚焦的是正确的实体（改变 a，即识别）。

我们把能量函数构建为一个基于[关系网络架构](https://arxiv.org/abs/1706.01427)的神经网络，这使它接受任意数量的实体作为输入。训练过程优化的就是这个能量函数的参数；其他函数都从能量函数隐式导出。

这一方法让我们能用能量函数学习单个网络，同时执行**生成与识别**。这使得从生成中学到的概念可以反过来用于识别，反之亦然。（注：通过[镜像神经元](https://www.ncbi.nlm.nih.gov/pubmed/21227300)，动物身上已经观察到类似效应。）

## 单网络训练

我们的训练数据由（注意力掩码，状态）轨迹组成，针对希望模型学习的特定概念预先生成。训练时，先就某个概念集给模型少量示范（通常为 5 次），然后给它一个新环境（X0），请它预测下一个状态（X1）和下一个注意力掩码（a）。我们优化能量函数，使训练数据中的下一状态和下一注意力掩码被赋予低能量值。与[变分自编码器](https://arxiv.org/abs/1606.05908)这类生成模型类似，模型有动力学到能有用地压缩任务某侧面的取值。我们在一个二维粒子环境中，用涉及视觉、空间、邻近、时间关系和数量概念的组合训练了模型。

## 关键结果

我们在一系列任务上评估了这一方法，以检验单个系统在识别和生成同属一个概念的事物上表现如何：我们的系统能学会对特定空间关系集合分类和生成，能以特定方式引导实体穿越场景，或能对数量（一、二、三或更多）与邻近这类概念形成良好判断。

当模型能在"学习生成概念（通过移动状态向量 x 中的实体）"与"学习识别概念（通过改变固定状态向量上的注意力掩码）"之间共享经验时，表现更好：对同时接受这两种操作训练的模型进行评估，发现它们在每种单独操作上都优于只针对该单一操作训练的模型。我们还发现了[迁移学习](https://en.wikipedia.org/wiki/Transfer_learning)的迹象——只在识别情境下训练的能量函数，即使没有显式训练生成，在生成任务上也表现出色。
