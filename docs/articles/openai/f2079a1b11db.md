# 审查完成，Altman 和 Brockman 继续领导 OpenAI

任命新董事会成员，并引入治理结构增强措施


OpenAI 董事会特别委员会今日宣布 WilmerHale 的审查已经完成。该律所对 OpenAI 前董事会成员、OpenAI 高管、前董事会顾问及其他相关证人进行了数十次访谈；审阅了超过 30,000 份文件；并评估了各项公司行为。基于 WilmerHale 整理的记录，并遵循特别委员会的建议，董事会对 Sam Altman 先生和 Greg Brockman 先生继续领导 OpenAI 表达了充分信心。

"我们一致认定，Sam 和 Greg 是 OpenAI 的合适领导者，" OpenAI 董事会主席 Bret Taylor 表示。

Sam Altman 将以 CEO 身份重新加入 OpenAI 董事会。

OpenAI 董事会今日还宣布选出三位新任董事会成员，作为扩充董事会承诺的一部分，包括：

- **Sue Desmond-Hellmann 博士**，*比尔及梅琳达·盖茨基金会前 CEO，Pfizer 董事会成员，总统科学和技术顾问委员会成员。*
- **Nicole Seligman**，*索尼前 EVP 暨全球总法律顾问、索尼娱乐总裁；Paramount Global、Meira GTx 和 Intuitive Machines, Inc. 董事会成员。*
- **Fidji Simo**，*Instacart CEO 兼董事长，Shopify 董事会成员*

新成员拥有领导全球性组织、应对复杂监管环境的经验，背景覆盖技术、非营利和董事会治理。他们将与现任董事 Adam D'Angelo、Larry Summers、Bret Taylor，以及 Greg、Sam 和 OpenAI 高级管理层密切共事。

Taylor 还表示："作为董事会主席，我非常高兴欢迎 Sue、Nicole 和 Fidji 加入 OpenAI 董事会。他们的经验和领导力将使董事会能够有效监督 OpenAI 的成长，并确保我们追求 OpenAI 的使命——确保人工通用智能惠及全人类。"

董事会还宣布通过了 OpenAI 治理结构的重要改进。关键增强措施包括：

- 采用一套新的公司治理准则；
- 强化 OpenAI 的利益冲突政策；
- 设立举报热线，为所有 OpenAI 员工和承包商提供匿名报告渠道；以及
- 增设委员会，包括专注于 OpenAI 核心使命落地与推进的使命与战略委员会（Mission & Strategy committee）。

扩员后的董事会将把完善治理程序、最好地实现 OpenAI 使命这一关键工作放在首位。"我们认识到，自己为全人类的福祉管护变革性技术的角色有多重大，" Taylor 补充道。

特别委员会肯定了 WilmerHale 在开展这项大规模审查中的重要工作，并感谢 OpenAI 现任和前任董事会成员、顾问和员工的配合。OpenAI 董事会特别委员会发布了一份调查结论摘要。

## WilmerHale 审查与结论摘要

2023 年 12 月 8 日，特别委员会委托 WilmerHale 对以下事件进行审查：2023 年 11 月 17 日 Sam Altman 和 Greg Brockman 被从 OpenAI 董事会移除、以及 Altman 先生被解除 CEO 职务一事。WilmerHale 审阅了超过 30,000 份文件；进行了数十次访谈，对象包括 OpenAI 前董事会成员、OpenAI 高管、前董事会顾问和其他相关证人；并评估了各项公司行为。

特别委员会为 WilmerHale 提供了开展全面审查所需的资源和权限。许多 OpenAI 员工以及现任和前任董事会成员配合了审查。WilmerHale 就审查进展和结论向特别委员会做了多次汇报。

WilmerHale 评估了此前已引起前董事会注意的管理与治理问题，也评估了其在审查过程中发现的其他问题。WilmerHale 认定，前董事会与 Altman 先生之间的信任破裂，引发了 11 月 17 日的事件。

WilmerHale 审阅了前董事会 11 月 17 日发布的公开声明，结论是该声明准确记述了前董事会的决定及其理由。WilmerHale 发现，前董事会当时相信其行动会缓解内部管理挑战，并未预料到会造成公司动荡。WilmerHale 还认定，前董事会的决定并非源于对产品安全或安保、研发节奏、OpenAI 财务状况、或其对投资人/客户/商业伙伴言论的担忧，而是前董事会与 Altman 先生关系破裂、信任丧失的结果。WilmerHale 发现，前董事会在压缩的时间表内执行了其决定，未提前通知关键利益相关方，也没有进行彻底调查或给 Altman 先生回应关切的机会。WilmerHale 认定，前董事会解除 Altman 先生职务在其广泛裁量权范围内，但同时认定其行为并不必然导致免职。

在审阅 WilmerHale 的结论后，特别委员会建议全体董事会追认 11 月 21 日重新聘用 Altman 先生和 Brockman 先生的决定。在了解审查结论后，特别委员会对 Altman 先生和 Brockman 先生继续领导 OpenAI 表达了充分信心。

特别委员会高兴地宣布审查结束，并期待继续推进 OpenAI 的重要工作。
