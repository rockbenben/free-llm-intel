# OpenAI 在 Linux 基金会旗下联合创立 Agentic AI Foundation

AAIF 旨在通过捐赠包括 OpenAI 的 AGENTS.md 在内的一系列开放标准，推动开源智能体 AI（Agentic AI）生态的发展。


今日，OpenAI 宣布与 Anthropic 和 Block 共同发起成立 Linux 基金会旗下的 [Agentic AI 基金会 (AAIF)](https://aaif.io/)，并获得 Google、Microsoft、AWS、Bloomberg 及 Cloudflare 等公司的支持。该基金会致力于为开放、可互操作的基础设施提供中立治理，以支持智能体系统从实验阶段平稳过渡至真实生产环境。

作为本次倡议的核心部分，我们将 [AGENTS.md](http://agents.md) 捐赠给基金会。AGENTS.md 是一种简单、开放的格式，用于为智能体提供项目专属的指令与上下文。此举旨在确保该标准能够获得社区的长期支持与广泛采纳。

### 为何开放标准至关重要

开发者正迅速采用 AI 来构建功能更强大的智能体系统 — 从编码助手到工作流自动化，再到客户服务代理。2025 年，这些系统已开始从原型走向实用，在商业与消费场景中承担起实际工作。

我们坚信，唯有在支持互操作性的开放标准基础上，实验性智能体向现实世界系统的大规模过渡才能真正实现。开放标准能使智能体更安全、更易于构建、且更能跨工具与平台移植，同时有助于在这一新兴领域成熟之际，避免生态系统走向碎片化。

随着越来越多的智能体开始承担实际职责，生态分裂的代价将愈发高昂。倘若缺乏共同约定与中立治理，智能体的开发很可能分化成互不兼容的“孤岛”，从而限制其可移植性、安全性乃至整体发展进程。

AAIF 正是为应对此关键挑战而生。

### 共建开放生态

过去一年中，OpenAI 在构建开放的智能体基础设施方面做出了显著贡献。我们与全球开发者、研究人员及行业伙伴紧密合作，共同验证了开放协议在实际应用中的可行性。

我们贡献了多项核心构建模块，包括 [Agents SDK](https://platform.openai.com/docs/guides/agents-sdk)、[Apps SDK](https://developers.openai.com/apps-sdk/) 和 [Agentic Commerce Protocol](https://developers.openai.com/commerce/)，以及 [gpt-oss 模型⁠](https://openai.com/index/introducing-gpt-oss/)和 [Codex CLI](https://developers.openai.com/codex/cli/) 等开源项目仅 Codex 一项，就已协助完成了 GitHub 上超过 200 万次公开拉取请求的合并。

我们亦是 Model Context Protocol（MCP）的早期采用者与核心贡献者，并将其作为 ChatGPT 中[连接器](https://chatgpt.com/features/connectors/)与[应用⁠](https://openai.com/index/introducing-apps-in-chatgpt/)的底层基础。就在上周，我们宣布与 Anthropic 和 MCP-UI 达成合作，通过 [MCP Apps](http://blog.modelcontextprotocol.io/posts/2025-11-21-mcp-apps/) 将 Apps SDK 的能力扩展至所有 MCP 开发者，从而更轻松地构建跨平台的、由智能体驱动的交互式体验。

这些实践为 AAIF 奠定了坚实基础，证明了开放且可互操作的基础设施能够获得整个生态的真正接纳。

### 捐赠 [AGENTS.md](http://agents.md)

AGENTS.md 始于一个常见问题的实用解决方案：Codex 需要一种可预测的方式来获取项目特定的说明（例如编码规范、构建步骤与测试要求），以确保智能体能在代码库中安全、高效地工作。

借助 [AGENTS.md](http://agents.md)，我们引入了一种轻量级 Markdown 文件格式，设计上与 [README.md](http://readme.md) 并列存在于同一代码库中它提供了一套简单、可互操作的标准，为 AI 编码智能体提供一致的项目指引，使其能在不同的代码库与工具链中可靠运行。这种基于 Markdown 的约定，显著增强了智能体在多样化仓库与构建系统中的行为可预测性。

这一最初的内部方案，很快就在整个生态系统中引发共鸣。自 2025 年 8 月发布以来，AGENTS.md 已被超过 60,000 个开源项目及智能体框架采纳，使用者包括 Amp、Codex、Cursor、Devin、Factory、Gemini CLI、GitHub Copilot、Jules 和 VS Code 等。这标志着，随着智能体进入生产环境，业界正日益围绕共享、供应商中立的规范形成共识。

将 AGENTS.md 贡献给 AAIF 确保了以下三点：

- 开发者和企业可以通过一种可移植、统一的方式，为智能体提供所需的上下文信息。
- 这种格式可以在开放环境中不断演进，吸收来自众多工具和社区的意见和反馈。
- 其发展方向不会因采用率的增长而被任何单一公司所主导。

除 [AGENTS.md](http://agents.md) 外，AAIF 的其他联合创始方也将各自贡献一个关键项目：Anthropic 的 [Model Context Protocol（MCP）](https://github.com/modelcontextprotocol)以及 Block 的 [goose](https://block.github.io/goose)。

### Agentic AI 基金会的使命

AAIF 旨在提供一个中立平台，供各界协作制定、治理并扩展智能体互操作性标准。我们对 AAIF 的目标明确而简单：建立一个共享、中立的平台，用以构建能惠及全球开发者、企业及广大开源社区的智能体系统。

AAIF 将作为 Linux 基金会旗下的一个定向基金运作。Linux 基金会作为非营利组织，拥有数十年管理 Linux 内核、Kubernetes、Node.js 和 PyTorch 等关键开源项目的丰富经验。Linux 基金会成熟的中立治理模式、社区建设能力以及对广谱技术长期可持续性的维护承诺，将确保基础性基础设施的发展不受任何单一实体控制。

Agentic AI 基金会由 OpenAI、[Block](https://block.xyz/)、[Anthropic](https://www.anthropic.com/)、[Google](https://www.google.com/)、[Microsoft](http://microsoft.com)、[Amazon](https://aws.amazon.com/)、[Bloomberg](https://www.bloomberg.com/) 和 [Cloudflare](https://www.cloudflare.com/) 共同发起成立，旨在通过共同投资、开放开发与社区主导的标准制定，推动智能体 AI 朝着透明、协作、符合公共利益的方向演进。

我们诚挚欢迎所有类型的贡献者（工具开发者、研究人员、企业及个人开发者）加入我们，共同塑造并推进这项意义深远的工作。点击[此处](https://enrollment.lfx.linuxfoundation.org/?project=agentic-ai-foundation)了解 [AGENTS.md](http://agents.md) 的更多相关信息，并参与 AAIF 的相关工作
