# OpenAI Codex 驱动下一代应用

通过 OpenAI API，Codex 现已为涵盖多种用例的 70 个应用提供支持。

***2025 年 5 月 16 日更新：**** 我们发布了 Codex——一个可并行处理许多任务的云端软件工程 agent。*[ *了解更多*⁠](https://openai.com/index/introducing-codex/)*。*

[OpenAI Codex⁠](https://openai.com/index/openai-codex/) 是基于 GPT-3 的自然语言转代码系统，能把简单的英语指令转换为十余种主流编程语言。Codex 去年 8 月通过我们的 API 发布，是 [GitHub Copilot](https://copilot.github.com/) 的主要构件。

我们做 Codex 的动机是辅助开发者的工作、提升生产力。Codex 帮助计算机更好地理解人的意图，让每个人都能用计算机做更多的事。这是我们构建造福全人类的通用 AI 这一使命的组成部分。

对企业客户，微软的 Azure OpenAI Service 为开发者提供 Codex 及我们其他模型（如 GPT-3 和 embeddings）的访问，并内置企业级能力。微软在其 Build 大会上[宣布](https://blogs.microsoft.com/ai/azure-openai-service-helps-customers-accelerate-innovation-with-large-ai-models-microsoft-expands-availability/)：此前仅限受邀使用的 Azure OpenAI Service 现开放限量访问预览。我们已经看到 Azure OpenAI Service 在众多行业的新应用，从医疗到金融服务。

## 应用与行业

自通过我们的 [API⁠](https://openai.com/api/) 发布以来，我们与开发者紧密合作，在 Codex 之上构建应用。这些应用以创造、学习、生产力和解决问题等多种方式利用该系统的能力。

使用 Codex 的应用：

[**GitHub Copilot**](https://copilot.github.com/) 是一个 AI 结对程序员，在代码编辑器内提供整行或整个函数的建议。

通过与 Codex 的深度集成，GitHub Copilot 能把注释转成代码、自动补全重复代码、建议测试并展示备选方案。

GitHub Copilot 支持 Visual Studio、Visual Studio Code 等环境，兼容广泛的框架与语言；对某些编程语言，它建议的代码约占如今数万名开发者所写代码的 35%。

微软在其 Build 开发者大会上[宣布](https://blogs.microsoft.com/ai/how-ai-makes-developers-lives-easier-and-helps-everybody-learn-to-develop-software/)，GitHub Copilot 将于今夏转为正式可用（GA）。

[**Pygma**](https://pygma.app/) 致力于把 Figma 设计转成高质量代码。

Pygma 用 Codex 把 Figma 设计转换为不同前端框架，并匹配开发者的编码风格与偏好。Codex 让 Pygma 帮用户即时完成过去要花数小时的任务。

> “Codex 让我能以极少的编码为我的应用集成创新功能。作为一个没有深厚机器学习背景的人，像灵活的代码微调这样的功能自建起来极其困难。有了 Codex，它几乎开箱即用。”——Emile Paffard-Wray，Pygma 创始人

[**Replit**](https://replit.com/) 是一个支持任何编程语言的平台，让用户实时协作项目、学习代码，并与学习者与创造者社区分享作品。

Replit 借助 Codex 用简单语言描述一段代码在做什么，让每个人都能获得高质量的解释与学习工具。用户可以选中代码片段并点击 “Explain Code”，用 Codex 理解其功能。

> “Codex 帮助 Replit 上的学习者更好地理解他们遇到的代码。语义化的代码理解能为那些想快速把想法变成可运行代码的人提供什么，我们才刚刚触及表面。”——Amjad Masad，Replit 创始人

[**Warp**](https://www.warp.dev/) 是一个基于 Rust 的终端，自底向上重新构想，帮助个人和团队在命令行中更高效。

终端命令通常难记、难找、难拼。用户常常不得不离开终端去网上搜索答案，即便如此结果也未必给出他们要执行的正确命令。Warp 使用 Codex，让用户在终端内直接运行自然语言命令搜索，并立即得到可用的结果。

> “Codex 让 Warp 能把终端变得更好用、更强大。开发者用自然语言搜索整条命令，而不是靠记忆或一点点拼凑。由 Codex 驱动的命令搜索已成为我们的杀手级功能之一。”——Zach Lloyd，Warp 创始人

[**Machinet**](https://machinet.net/) 使用 Codex 生成智能单元测试模板，帮助专业 Java 开发者编写高质量代码。

Machinet 从自建机器学习系统转向使用 Codex 后，开发速度提升数倍。Codex 的灵活性让他们能轻松添加新功能与新能力，为用户节省时间、提升生产力。

> “Codex 是我们武器库中一件出色的工具。它不仅让我们生成更有意义的代码，还帮助我们找到了产品架构的一种新设计，带我们走出了局部最优。”——Vladislav Yanchenko，Machinet 创始人
