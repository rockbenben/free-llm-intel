# OpenAI 中 AI 的应用

探索 OpenAI 的产品与 API 如何把 AI 带入真实场景。

OpenAI 创立时便怀有一个长期目标：让先进 AI 造福人类。早期的工作聚焦于研究与实验，随后转向大规模模型开发。随着时间推移，OpenAI 开始通过面向消费者的产品和开发者平台发布模型，让个人、团队和组织都能把 AI 应用到自己的工作中。

从宏观层面看，OpenAI 目前以两种方式支持 AI 应用：

1）通过 OpenAI 产品直接访问，例如 ChatGPT 或 Codex。这些是人们可以立即用于学习、工作、创意和构建的工具。

2）通过 API 提供可组合的构建模块。开发者可以据此把模型的智能集成到自己的工作流程、产品和系统中。

以下各节概述了最常见的 OpenAI 产品及其设计用途。

## ChatGPT

ChatGPT 是 OpenAI 主要的面向用户的产品——一个帮助人们写作、思考、学习和解决问题的对话式界面。它面向通用场景设计，支持摘要、头脑风暴、辅导、规划等任务。

还有面向机构和组织的 ChatGPT 版本，例如 ChatGPT Enterprise 或 ChatGPT Business，提供更强的管理控制、隐私功能、协作与部署支持。

了解更多关于 [ChatGPT⁠（在新窗口打开）](https://chatgpt.com/) 的信息。

## Codex

Codex 是 OpenAI 面向 AI 辅助软件开发的产品。它经过优化，擅长理解代码、编写代码、重构、调试，并帮助用户完成编程任务——通常通过 IDE 或工作流式的界面，而非通用聊天体验。

了解更多关于 [Codex⁠（在新窗口打开）](https://chatgpt.com/codex/) 的信息。

## OpenAI API（开发者平台）

OpenAI API 提供对 OpenAI 模型的可编程访问。开发者可以构建生成文本或图像、分析内容、编写或解读代码、推理问题以及与工具交互的应用。OpenAI 正是通过 API 来支持大规模的自定义 AI 应用——从内部自动化到消费级产品。

了解更多关于 [OpenAI API⁠](https://openai.com/api/) 的信息。

在所有这些工具背后，OpenAI 的核心目标始终一致：通过用心的产品设计、开发者工具和真实世界的安全保障，让强大的模型能力变得有用、安全、可及。
