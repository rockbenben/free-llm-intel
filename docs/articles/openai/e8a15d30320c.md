# 造福于众

OpenAI 董事会主席 Bret Taylor


OpenAI 已完成资本重组，简化了公司架构。该非营利组织继续掌控营利实体，并在 AGI 问世前获得了获取重大资源的直接途径。

非营利机构（现更名为 OpenAI Foundation）持有营利公司的股权，当前估值约 1,300 亿美元，使其成为史上资源最雄厚的慈善组织之一。随着 OpenAI 营利公司达到估值里程碑，资本重组还赋予该基金会额外所有权。

OpenAI 的使命——确保 AGI 造福全人类——将通过商业实体与基金会双轨推进。OpenAI 作为公司的成功程度越高，非营利组织的股权价值就越高，这些资金将用于支持其慈善事业。

OpenAI Foundation 初期将重点投入 250 亿美元资金，覆盖两大领域：

- **健康与疾病治疗。**OpenAI Foundation 将资助加速医疗突破的研究，使所有人都能受益于更快的诊断、更优的治疗和治愈方案。具体举措包括创建开源且负责任构建的前沿健康数据集，以及资助科研人员。
- **AI 韧性技术方案。**正如互联网需要全面的网络安全生态系统——保护电网、医院、银行、政府、企业和个人——我们现在需要为 AI 构建平行韧性层。OpenAI Foundation 将投入资源支持 AI 韧性的实用技术方案，旨在最大化 AI 效益并最小化其风险。

此举基于 5,000 万美元的 [People-First AI Fund](https://openai.com/index/people-first-ai-fund/) 基金，同时借鉴了 [Nonprofit Commission](https://openai.com/index/nonprofit-commission-report/) 的建议。

## 使命核心

OpenAI 于 2015 年以非营利组织身份创立，其使命是确保通用人工智能造福全人类。时至今日，OpenAI 仍作为非营利机构坚守这一使命。

OpenAI Foundation 负责管理 2019 年成立的营利性业务，始终将使命置于核心。该营利实体现已转型为公共利益公司——OpenAI Group PBC，其使命与 OpenAI Foundation 完全一致，确保公司使命与商业成功同步推进。了解更多[组织架构](https://openai.com/our-structure/)详情。

本次资本重组维持了当前业内最强大的使命导向治理结构。 
 
此次重组历经近一年与加利福尼亚州及特拉华州总检察长办公室的建设性对话后完成。基于这些讨论，我们实施了多项改进措施，相信这些调整将使 OpenAI——以及我们所服务的公众——受益匪浅。

## 未来发展路径

OpenAI Foundation 与 OpenAI Group 将协同共进，积极应对 AI 发展带来的重大挑战与机遇。这包括让智能成为惠及众生的工具、构建安全且符合人类利益的系统、加速科学发现进程，以及强化全球协作与韧性。

我们坚信，强大的技术必须以符合人类共同利益的方式发展。资本重组的完成使我们能够持续推动 AI 前沿，并通过更新的公司架构确保技术进步惠及所有人。
