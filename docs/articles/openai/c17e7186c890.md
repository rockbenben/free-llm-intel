# 通过 Oracle 云承诺额度，直接使用 OpenAI 模型与 Codex

企业现在可以直接使用现有的 Oracle 云采购承诺，为团队接入 OpenAI 最先进的模型与 Codex，无需新增采购流程。


***2026 年 8 月 7 日更新：****现在，Oracle 客户可以通过 Oracle 云市场 (Oracle Marketplace)，利用现有的采购流程和符合条件的 Oracle 信用额度 (Oracle Universal Credits)，购买 OpenAI 模型的 API、Codex 及 ChatGPT 工作访问权限。Oracle 是首批通过其云市场为客户提供这些服务购买渠道的合作伙伴之一。Oracle 云市场上的 OpenAI 服务目前已在美国上线，并将于近期登陆更多地区。*

许多企业希望沿用已经建立并验证过的采购流程和治理体系来推进 AI 落地。为支持这一需求，OpenAI 与 Oracle 正展开合作，让 Oracle Cloud Infrastructure (OCI) 客户能够更便捷地访问 OpenAI 前沿模型与 Codex。

未来几周内，Oracle 客户将能够通过 OCI 使用符合条件的 Oracle Universal Credits，直接调用 OpenAI 模型与 Codex。这意味着客户无需建立新的采购路径，即可在现有采购流程和云承诺体系下获得 OpenAI 能力。

借助 OpenAI 模型，团队能够构建 AI 应用、分析复杂信息、实现业务流程自动化，并打造全新的客户与员工体验。

对于已经采用 Oracle 云承诺计划的企业而言，此次合作有助于让 AI 部署与既定云战略及成熟的企业流程保持一致。我们的目标，是降低企业将先进 AI 引入核心业务时的落地门槛，在尊重现有技术治理与决策机制的前提下，加速 AI 应用部署。

通过在 OCI 上进一步扩展 OpenAI 能力的可用性，OpenAI 与 Oracle 正帮助更多企业从 AI 愿景迈向生产级价值落地。

相关功能将在未来数周内陆续开放。

如需了解详细信息、上线时间及可用范围，请联系 Oracle 客户经理。
