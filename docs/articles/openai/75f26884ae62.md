# 生成对抗网络、逆强化学习与基于能量模型之间的联系

阅读论文（在新窗口打开）。

## 摘要

生成对抗网络（GAN）是近期提出的一类生成模型，其中生成器通过优化一个由判别器同时学习得到的代价函数来训练。虽然“学习代价函数”的思想在生成建模领域相对较新，但在控制与强化学习（RL）领域，代价学习早已被长期研究，通常用于从示范中进行模仿学习。在这些领域中，学习可观察行为背后的代价函数被称为逆强化学习（IRL）或逆最优控制。尽管 RL 中的代价学习与生成建模中的代价学习之间的联系乍看似乎只是表面的，我们在本文中证明：某些 IRL 方法在数学上实际上与 GAN 等价。特别地，我们展示了最大熵 IRL 的一种基于采样的算法与一种 GAN 之间的等价性——后者的生成器密度可被评估，并作为额外输入提供给判别器。有趣的是，最大熵 IRL 是基于能量模型（EBM）的一个特例。我们讨论了“GAN 是训练基于能量模型的算法”这一解释，并把该解释与其他近期尝试连接 GAN 与 EBM 的工作联系起来。通过正式揭示 GAN、IRL 与 EBM 之间的联系，我们希望三个社区的研究者都能更好地识别并把可迁移的思想从一个领域应用到另一个领域，尤其是开发更稳定、更可扩展的算法——这是三个领域共同面临的重大挑战。
