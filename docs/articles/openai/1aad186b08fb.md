# OpenAI 全面标准化使用 PyTorch

我们将 OpenAI 的深度学习框架标准化为 PyTorch。

我们正把 OpenAI 的深度学习框架标准化为 [PyTorch](https://pytorch.org/)。过去，我们会根据各框架的相对优势在不同框架中实现项目。现在，我们选择统一标准，让团队更容易创建并共享我们模型的优化实现。

作为这一步的一部分，我们刚刚发布了 [Spinning Up in Deep RL⁠](https://openai.com/index/spinning-up-in-deep-rl/) 的[支持 PyTorch 的版本](https://github.com/openai/spinningup)。Spinning Up 是 OpenAI 出品的开源教育资源，让学习深度强化学习更容易。我们也在为我们高度优化的 [blocksparse 内核⁠](https://openai.com/index/block-sparse-gpu-kernels/) 编写 PyTorch 绑定，并将在未来几个月内开源这些绑定。

选择 PyTorch 的主要原因是提升我们在 GPU 上大规模研究的效率。在 PyTorch 中尝试和执行新的研究想法非常容易；例如，切换到 PyTorch 后，我们在生成建模研究想法上的迭代时间从数周缩短到了数天。我们也很高兴能与迅速壮大的开发者社区——包括 Facebook、微软等机构——一起推进 GPU 的规模与性能。

展望未来，我们将主要以 PyTorch 作为深度学习框架，但在有特定技术理由时也会使用其他框架。我们的许多团队已经完成切换，我们也期待在未来几个月为 PyTorch 社区作出贡献。
