# OpenAI 将收购 Astral

加速 Codex 增长，为下一代 Python 开发者工具提供动力


今天我们宣布，OpenAI 将收购 [Astral](https://astral.sh/)，把强大的开源开发者工具纳入我们的 Codex 生态系统。

Astral 已打造出一些得到广泛使用的开源 Python 工具，借助 **uv、Ruff，**和** ty** 等现代工具帮助开发者更高效地工作。这些工具支撑着数百万开发者的工作流，已成为现代 Python 开发基础的一部分。秉持开发者优先的理念，交易完成后，OpenAI 计划继续支持 Astral 的开源产品。通过将 Astral 的工具和工程专长带到 OpenAI，我们将加快 Codex 相关工作，并拓展 AI 在整个软件开发生命周期中的能力。

## 将 Codex 扩展到编程之外

自今年年初以来，Codex 的用户增长已达 3 倍，使用量增长达 5 倍，目前每周活跃用户已超过 200 万。

我们对 Codex 的目标，是超越仅仅生成代码的 AI，迈向能够参与整个开发工作流的系统 — 帮助规划变更、修改代码库、运行工具、验证结果，并长期维护软件。Astral 的开发者工具正处于这一工作流之中。交易完成后，通过将这些系统与 Codex 集成，我们将使 AI 智能体能够更直接地与开发者每天已在依赖的工具协同工作。

## 强化 Python 生态系统

Python 已成为现代软件开发中最重要的语言之一，支撑着从 AI 和数据科学到后端系统及开发者基础设施的方方面面。

Astral 的开源工具已在这一生态系统中发挥关键作用：

- uv 简化依赖项和环境管理
- Ruff 提供极快的 lint 检查和格式化
- ty 帮助在代码库中贯彻类型安全

这些工具共同帮助开发者管理项目、保障质量，并在开发过程中尽早发现错误。随着 Astral 加入 OpenAI，我们将继续支持这些开源项目，同时探索它们如何与 Codex 更顺畅地协作 — 让 AI 系统能够覆盖完整的 Python 开发工作流。我们的目标很简单：在保持工作流所依赖的可靠性和性能的同时，帮助开发者更高效地工作。

## 未来展望

本次收购的完成仍需满足惯常的交割条件，包括获得监管批准。在交割完成前，OpenAI 和 Astral 将继续保持彼此独立运营。

交易完成后，Astral 团队将加入 OpenAI 的 Codex 团队。随着时间推移，我们将探索更深入的集成方式，使 Codex 能更直接地与开发者已在使用的工具交互，帮助 Codex 发展为贯穿开发生命周期的真正协作者。我们的目标始终不变：构建能够帮助人们更快地创造、学习和构建的 AI 系统，并让强大的开发工具惠及世界各地更多人。我们期待在交易完成后欢迎 Astral 团队加入 OpenAI。
