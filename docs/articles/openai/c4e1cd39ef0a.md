# OpenAI Scholars 2020：期末项目

第三期 OpenAI Scholars 学员在云端的 Demo Day（演示日）上展示了自己的期末项目，呈现了过去五个月的研究成果。

这些项目研究的问题包括：分析 GPT-2 如何表示语法、衡量在 Coinrun 上训练的模型的可解释性、用脑部记录预测癫痫发作。关于下一期 Scholars 学员及如何申请的更多信息，将于今秋公布。

[OpenAI Scholars⁠](https://openai.com/index/openai-scholars/) 计划为来自代表性不足群体的个人提供奖学金和导师指导，让他们学习深度学习并开源一个项目。

我们的 Scholars 学员在各个专业领域都展现出了扎实的核心技术技能和自我驱动力——对于这样一个自主性很强的计划，这些能力至关重要。他们每个人进入机器学习领域时都还是相对的新人，我们希望他们的进步能说明机器学习其实多么容易上手。
