# OpenAI 与康泰纳仕达成合作

我们将增强由 AI 驱动的新闻发现与分发。

我们宣布与康泰纳仕（Condé Nast）建立合作，将在我们的产品中展示来自 Vogue、《纽约客》（The New Yorker）、Condé Nast Traveler、GQ、《建筑文摘》（Architectural Digest）、Vanity Fair、Wired、Bon Appétit 等顶级品牌的内容，包括 ChatGPT 和我们的 SearchGPT 原型。

随着 [SearchGPT 原型](https://openai.com/index/searchgpt-prototype/)的推出，我们正在测试新的搜索功能，让查找信息和可靠内容来源更快、更直观。我们把对话式模型与来自互联网的信息结合，为你提供快速、及时且来源清晰相关的回答。SearchGPT 提供到新闻故事的直链，让用户可以轻松地从源头探索更深入的内容。我们计划未来把这些功能中最优秀的部分直接集成进 ChatGPT。

我们与新闻伙伴协作，收集关于 SearchGPT 设计与性能的反馈和洞见，确保这些集成能增强用户体验，并为 ChatGPT 的未来更新提供依据。

> "我们致力于与 Condé Nast 及其他新闻发布方合作，确保随着 AI 在新闻发现与分发中扮演更大角色，它始终保持准确、正直，并对优质报道保持尊重。"
>
> ——Brad Lightcap，OpenAI 首席运营官

Condé Nast 加入了一份不断壮大的发布方名单：美联社（Associated Press）、Axel Springer、《大西洋月刊》（The Atlantic）、Dotdash Meredith、《金融时报》（Financial Times）、Le Monde、NewsCorp、Prisa Media、《时代》（TIME）、Vox Media 等——与我们一道，把新闻业更深度地融入 AI 服务。
