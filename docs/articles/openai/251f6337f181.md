# 随人工智能价值同步扩展的商业模式

作者：Sarah Friar，OpenAI 首席财务官


我们最初发布 ChatGPT 研究预览版，是为了探索当前沿智能直接交付到用户手中时会发生什么。

随之而来的，是其在全球范围内的爆发式普及与深层次应用，其规模超出了所有人的预判。

人们不仅仅是在“试用”AI，而是将其深度融入进生活的点滴。学生用它解决深夜遇到的课业难题；家长用它规划行程和管理预算；创作者用它突破“空白页”的焦虑。越来越多人借助 ChatGPT 理解生活：梳理健康症状、准备就诊咨询，以及引导复杂的决策。在疲惫、高压或犹豫不决时，人们利用 ChatGPT 来理清思路。

随后，这种生产力杠杆被带入了职场。

起初，这种改变体现在细微之处：会议前的草稿润色、电子表格的最后一次复核、或者是为了调整语气而重写客户邮件。但很快，它成为了日常工作流的有机组成部分。工程师推理代码的速度更快了；市场营销人员的活动洞察更犀利了；财务团队的场景模拟更清晰了；管理人员在处理艰难谈话时也有了更充分的背景支撑。

最初源于好奇心的工具，现已演变为帮助人们提升产出、加速决策和高效运营的基础设施。

这种转变正是我们构建 OpenAI 的核心所在。作为一家研究与部署公司，我们的职责是缩小人工智能进化的前沿与个人、企业及国家/地区实际落地应用之间的鸿沟。

随着 ChatGPT 成为人们日常完成实务所依赖的工具，我们遵循一个简单且持久的原则：我们的商业模式应随人工智能交付的价值同步扩展。

我们有计划地践行这一原则：随着用户对功能和可靠性要求的提升，我们推出了消费者订阅服务。随着 AI 进入团队和工作流程，我们推出了工作空间订阅，并引入按量计费模式，使成本随实际完成的工作量同步变动。此外，我们还打造了平台业务，支持开发者和企业通过 API 嵌入人工智能。在这一模式下，客户的投入与所创造的价值保持正向增长。

近期，我们将同一原则应用于商业服务。人们来到 ChatGPT 不仅仅是为了提问，更是为了决定下一步行动：买什么、去哪里、选哪个。帮助用户从“探索”转向“行动”，既为用户创造了价值，也为服务他们的合作伙伴创造了机会。广告业务适应了这一发展趋势：当用户接近决策点时，只要选项标注清晰且确实有用，相关推荐就具有真实的价值。

在所有路径中，我们都坚持同一标准：变现方式应该与体验本身自然融合。如果不能增加价值，它就不该存在。

我们的周活跃用户 (WAU) 和日活跃用户 (DAU) 数据持续创下历史新高。这种增长由算力、前沿研究、产品和变现共同构成的“飞轮”驱动。算力投入驱动尖端研究，实现模型能力的跨越式提升。更强的模型催生更好的产品，推动 OpenAI 平台的广泛普及。广泛普及带动收入增长，而收入则为下一波算力投入和创新提供资金。这是一个不断自我强化的循环。

回顾过去三年，我们服务客户的能力（以收入衡量）与可用算力直接挂钩：算力规模年均增长 3 倍。2023 年为 0.2 GW，2024 年为 0.6 GW，2025 年达到约 1.9 GW（较 2023 年增长 9.5 倍）。营收规模同样呈 3 倍年增速。2023 年年度经常性收入 (ARR) 为 20 亿美元，2024 年为 60 亿美元，2025 年超过 200 亿美元（较 2023 年增长 10 倍）。在如此量级下实现这种增长是史无前例的。我们坚信，如果这些阶段拥有更多算力，客户采用速度和变现能力还会有所提升。

算力是 AI 领域最稀缺的资源。三年前，我们依赖单一算力供应商；如今，我们正与多元化生态系统中的多家供应商合作。这种转变增强了我们的韧性，更重要的是，带来了算力的确定性。在算力定义规模的市场中，我们可以更有信心地规划、融资并部署产能。

这使得算力从一项固定约束转变为一个可主动管理的投资组合。当模型能力更为关键时，我们在顶级硬件上训练前沿模型。当效率比规模更重要时，我们会在成本更低的基础设施上承载高负载的工作量。由此，我们在降低延迟、提升吞吐的同时，可以将人工智能服务的成本控制在“每百万 Token 仅需几美分”。这让 AI 真正成为日常工作流的基石，而非仅限于昂贵的特定场景。

在算力层之上，是一个横跨文本、图像、语音、代码和 API 的产品平台。个人和组织都借助它来更高效地思考、创造和运作。下一阶段是智能体和工作流自动化 — 它们能持续运行、承接长期上下文，并跨工具采取行动。对于个人来说，这意味着 AI 将能够管理项目、协调计划并执行具体任务。对于组织来说，AI 将成为知识型工作的核心操作系统。

随着这些系统从“新鲜事物”转变为“生活习惯”，用户的使用程度正变得愈发深入且具有持久性。这种可预测性增强了平台的经济稳定性，并为长期投资提供了有力支撑。

我们的商业模式正在完成闭环。起初，我们仅提供订阅服务。如今，我们运营着一个多层次的体系，其中包括：面向个人和团队的订阅服务；以广告和商业合作支撑的免费层，旨在推动更广泛的采用；以及按用量计费、面向生产环境的 API。未来的发展将超越我们现有的销售范畴。随着人工智能渗透进科学研究、药物研发、能源系统和金融建模，全新的经济模式将应运而生。授权许可、基于 IP 的协议、以及基于产出成果的定价都将在价值创造中发挥作用。这正是互联网的演进历程，人工智能也将沿着同样的路径不断发展。

这套体系的有效运行离不开强有力的纪律。获取世界顶级的算力需要提前数年做出承诺，且增长并不总是呈完美的线性轨迹：有时产能领先于需求，有时需求则迫使产能追赶。我们通过保持资产负债表的轻量化、采取合作而非自持的模式，以及在供应商和硬件类型等方面打造灵活的合同结构来管理这种波动。资本根据真实的需求信号分批投入，这让我们在增长信号明确时能果断前行，而不至于在市场尚未证明具体价值前过度透支未来。

这种纪律性界定了我们 2026 年的核心目标：务实落地。目前的优先事项是缩小“AI 技术的可能性”与“个人、企业及国家/地区日常应用现状”之间的鸿沟。这一机遇巨大且紧迫，特别是在医疗、科学和企业领域。在这些场景下，更出色的人工智能将直接转化为更优的现实成果。

基础设施提升了我们的交付能力，创新拓展了人工智能的边界，应用落地扩大了受益人群，而营收增长则为下一次飞跃提供资金。这就是人工智能实现规模化并成为全球经济基石的逻辑所在。
