# 使用 Skills

创建可复用的工作流，引导 ChatGPT 完成重复性任务。

Skills 把你已有的工作方式变成可复用的工作流，让 ChatGPT 能够稳定地照着执行——这样你不必花时间反复解释步骤、格式和要求，可以把更多精力放在拿到扎实的结果上。

如果你发现自己一直在重复使用同一条提示词，或一遍遍粘贴同一个模板，skills 就是为解决这个问题而设计的。

## 什么是 skills？

一个 **skill（技能）**是一个可复用、可分享的工作流，它告诉 ChatGPT 如何完成某项具体任务。不必每次都从头开始，你把流程定义一次，之后每当任务出现时都可以可靠地套用。

一个 skill 通常包括：

- **名称和描述**：帮助 ChatGPT 识别何时该用这个 skill。
- **工作流指令**：对工作流的分步指引——通常写在一个叫 SKILL.md 的文件里。
- **资源**：工作流所依赖的辅助材料，如模板、示例、品牌规范、schema 或工具访问权限。

## 为什么要用 skills？

当从 ChatGPT 获得好输出取决于遵循一套可重复的方法时，skills 最有用——尤其是涉及多个步骤、结构化格式或特定要求的任务。

skills 有助于：

- **一致性**：更少遗漏章节，语气和格式更少漂移，更贴近期望的格式。
- **内置最佳实践**：对普通用户足够轻量，又以领域专家（SME）认可的工作流为根基。
- **分享打法**：团队可以直接在 ChatGPT 中使用同一套标准流程，而不必依赖非正式的、没有文档化的知识。
- **跨场景复用**：构建一次，即可在不同的对话和使用场景中广泛应用。

## SKILL.md 文件是什么？

**SKILL.md** 文件就是一个 skill 的"打法手册"：一份纯文本指令集，告诉 ChatGPT 如何稳定地执行某个工作流。它用 **Markdown**（文件名里的 ".md"）书写——一种轻量格式化风格，使用简单的符号，比如 "#" 表示标题、"-" 表示列表——因此在大多数工具中都容易阅读和编辑。

因为它是纯文本、基于 Markdown 的，所以 **SKILL.md 是可移植的**。它可以跨工具分享、做版本管理和复用。它还被设计为一项[**开放标准**](https://agentskills.io/home)，因此类似的模式也可能出现在其他 AI 应用和平台中。

一个典型的 SKILL.md 文件会定义：

- 这个 skill 做什么
- 需要的输入
- 分步指令
- 要求的输出格式
- 完成前的最终检查

## 如何构建和使用 skills

### 1）想一个可重复的任务

好的第一个 skill 来自你经常做的工作——尤其是一致性很重要的工作。这可能包括月度报告、周期性的管理层更新，或符合合规要求的摘要。

确保你清楚输入（用户通常会提供什么，比如文件、链接、上下文、字段）、输出（最终成品期望的格式、语气和长度），以及任何护栏（必须包含什么、什么绝不能发生）。

我们在 skills 中通常见到几种不同的模式：

- **可复用流程（多步骤工作流）**：顺序很重要、目标是照既定打法执行的任务——例如符合合规要求的报告、财务对账逻辑，或从多个数据源生成高管报告。
- **基于工具的工作流（稳定地使用系统）**：依赖可靠地从特定工具或系统中拉取、整合信息的工作——例如用 Gong 提取客户洞察，或从已连接的数据源生成摘要。
- **规范与标准（语气、结构、质量线）**：强制统一语气、格式或质量的工作流——即使底层内容在变化也是如此——例如按照风格指南和辅助材料起草博客文章。

*设计提示：* *skills 通常最好作为****可自由组合的小积木****，而不是一个庞大的端到端 skill。对复杂工作流，考虑拆分成更小的 skills。*

### 2）写下指令

*如果你是第一次构建 skill，先打开一个新对话，用"帮我做一个 skill……"向 ChatGPT 发起提示。你也可以在 ChatGPT 之外构建 skill，然后*[*上传它们*](https://help.openai.com/articles/20001066-skills-in-chatgpt)*。*

请 ChatGPT 创建一个 skill，并在提示词的其余部分描述你希望 ChatGPT 构建的 skill。一组强健的指令通常包括：

- 待完成的工作（job-to-be-done）
- 需要的输入
- 分步流程（编号步骤很有帮助）
- 要求的输出格式（附上示例很有帮助）
- 最终质量检查

*提示：用说话或听写的方式向 ChatGPT 口述工作流，可以更快地生成第一版。*

### 3）审阅并安装 skill

ChatGPT 会生成一份 skill 草稿，并提供安装选项。审阅草稿，按需完善指令，然后选择 **Install（安装）**把它加入你的工作区。

### 4）在日常工作中使用它

一旦在你的工作区中启用，ChatGPT 可以在相关场景自动使用某个 skill——你也可以通过 @ 提及的方式显式选择它。

### 5）分享或私有

如果你的工作区设置允许，你可以把工作区里的 skill 分享给他人，甚至代他们安装。注意：工作区所有者完全掌控谁可以分享和安装 skills。

## skills、GPTs 和 projects 如何协同

这些工具服务于不同但互补的目的。下面是一个简单的框架，帮你理解它们如何配合：

- **Skills：** 教会 ChatGPT 如何完成特定任务的可复用工作流
- **GPTs：** 面向目标的 ChatGPT 定制版本，用于扩展团队专业能力，或协助按时间推进的项目
- **Projects：** 团队基于相同的上下文、文件和对话，朝着共同目标协作
