# OpenAI 的 API 现已开放，无需排队

安全方面的进展让更大范围开放成为可能。

OpenAI 致力于 AI 的安全部署。自 API 发布以来，我们让应用部署更快、更顺畅，同时不断加入新的安全功能。防护措施上的进步使我们能够取消 GPT-3 的候补名单。从今天起，[支持国家](https://beta.openai.com/docs/supported-countries)的开发者可以[注册](https://beta.openai.com/signup)并立即开始使用我们的 API 进行实验。

过去一年我们对 API 的改进包括：更听从人类指令的 [Instruct 系列](https://beta.openai.com/docs/engines/instruct-series-beta)模型、面向更真实[问答](https://beta.openai.com/docs/guides/answers)的专用端点，以及帮助开发者抵御滥用的免费[内容过滤器](https://beta.openai.com/docs/engines/content-filter)。我们的相关工作也让我们能够在应用[上线](https://beta.openai.com/docs/going-live)前进行审查、监测滥用、在产品扩展时支持开发者，并更好地[理解这项技术的影响](https://beta.openai.com/docs/safety-best-practices/understanding-safety-risks)。

其他变化包括：改进后的 Playground，便于用我们的模型做原型；收录数十条提示词、助开发者上手的[示例库](https://beta.openai.com/examples)；以及把自然语言翻译成代码的新模型 [Codex](https://openai.com/index/openai-codex/)。

已有数以万计的开发者正通过我们的平台使用强大的 AI 模型。我们相信，通过易用的 API 开放这些模型，会有更多开发者找到富有创造力的方式，把 AI 应用到大量有用的场景和开放问题上。

为确保基于 API 的应用被负责任地构建，我们提供[工具](https://beta.openai.com/docs/engines/content-filter)并帮助开发者践行[最佳实践](https://beta.openai.com/docs/safety-best-practices)，让他们能快速、安全地把应用投入生产。随着系统演进、我们持续改进防护措施的能力，预计我们将继续简化开发者的使用流程、完善[使用指南](https://beta.openai.com/docs/usage-guidelines)，并随时间允许更多用例。

作为这一方向的又一步，我们同时更新[内容指南](https://beta.openai.com/docs/usage-guidelines/content-guidelines)，明确 API 可以用来生成什么样的内容。我们的政策一直禁止以违背 [Charter](https://openai.com/charter/) 所述原则的方式使用 API，仇恨言论等内容仍属禁止之列。

为帮助开发者确保应用按其预期用途使用、防止潜在滥用并遵守我们的内容指南，我们为开发者提供免费的内容过滤器。我们正与部分客户一起测试面向特定内容类别的定向过滤器。

我们同时禁止 API 上的某些类型内容，例如成人内容——目前我们的系统还无法可靠区分其有害与可接受的用法。我们持续让内容过滤器更健壮，并打算随系统改进，允许某些类别内可接受的用法。

我们很高兴防护措施已到位，能把 GPT-3 开放给更多开发者。随着防护措施持续改进，我们将在进一步提升用户体验的同时扩展 API 的用途。今天就[注册](https://beta.openai.com/signup)试试吧。

- [API 内容指南](https://beta.openai.com/docs/usage-policies/content-guidelines)

我们禁止用户故意生成——或放任他人故意生成——以下类别的内容：

| 仇恨：基于身份表达、煽动或宣扬仇恨的内容。 | 骚扰：意图骚扰、威胁或霸凌个人的内容。 | 暴力：宣扬或美化暴力，或以他人的苦难与羞辱为乐的内容。 |
| --- | --- | --- |
| 自残：宣扬、鼓励或描绘自残行为（如自杀、自割、进食障碍）的内容。 | 成人：意在刺激性兴奋（如性行为描写）或宣扬性服务的内容（性教育与身心健康除外）。 | 政治：试图影响政治进程或用于竞选活动的内容。 |
| 垃圾信息：未经请求的大批量内容。 | 欺骗：虚假或误导性的内容，如企图欺诈个人散布虚假信息。 | 恶意软件：试图生成勒索软件、键盘记录器、病毒或其他意在造成某种伤害的软件的内容。 |

我们也与希望把 API 用于研究、或构建用例以应对相关危害的研究人员合作。
