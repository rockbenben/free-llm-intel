# 与 Stack Overflow 的 API 合作

*编者按：这条消息最初由 Stack Overflow [在此](https://stackoverflow.co/company/press/archive/openai-partnership/)发布。*

OpenAI 与 Stack Overflow 通过 OverflowAPI 的接入走到一起：为 OpenAI 的用户和客户提供准确、经过审核的数据底座，让 AI 工具能快速找到问题的解法，使技术人员专注于优先任务。OpenAI 还将在 ChatGPT 中直接呈现来自 Stack Overflow 经过验证的技术知识，让用户轻松获得可信、署名规范、准确、高度技术化的知识与代码——背后是 15 年来为 Stack Overflow 平台贡献的数百万开发者。

作为本次协作的一部分：

- OpenAI 将使用 Stack Overflow 的 OverflowAPI 产品，并与 Stack Overflow 合作，提升使用其产品的开发者所获的模型表现。这一集成将帮助 OpenAI 利用 Stack Overflow 社区的增强内容与反馈改进其 AI 模型，并在 ChatGPT 内向 Stack Overflow 社区提供署名，促进与内容的深度互动。
- Stack Overflow 将在其 OverflowAI 的开发中使用 OpenAI 模型，并与 OpenAI 合作，利用内部测试的洞察最大化 OpenAI 模型的性能。OpenAI 与 Stack Overflow 的合作将进一步推动其"通过集体知识赋能全世界发展技术"的使命——Stack Overflow 将能打造更好的产品，造福 Stack Exchange 社区的健康、成长与活跃。

"向尽可能多的语言、文化、主题和行业学习，确保我们的模型能服务每个人。开发者社区对我们双方都格外重要。与 Stack Overflow 的深度合作将帮助我们在各平台上提升用户与开发者的体验，"OpenAI 首席运营官 Brad Lightcap 表示。

"Stack Overflow 是全球最大的开发者社区，拥有超过 5900 万个问答。通过与 OpenAI 这一行业领先的伙伴关系，我们努力重新定义开发者体验，以社区之力、一流数据和 AI 体验促进效率与协作，"Stack Overflow CEO Prashanth Chandrasekar 表示，"我们在 OverflowAPI 上的目标，以及推动负责任 AI 时代的工作，就是用经过审核、可信、准确的数据树立新标准——它们将是技术解决方案赖以构建并交付给用户的地基。"

Stack Overflow 与 OpenAI 之间的首批新集成和新能力将于 2024 年上半年上线。在此之后，OpenAI 与 Stack Overflow 的合作还将使 Stack Overflow 能够持续[再投资于社区驱动的功能](https://stackoverflow.blog/2024/03/27/community-products-reflections-and-looking-ahead/)。要了解 Stack Overflow 的 API 解决方案与合作，请访问 [https://stackoverflow.co/api-solutions/](https://stackoverflow.co/api-solutions/)。
