# Daybreak Red 现已在 AWS GovCloud (US-East) 上线

继 Daybreak 模型在 Amazon Bedrock 上线后，获批客户现在可以通过 Daybreak Red，[在 AWS GovCloud (US-East) 中](https://aws.amazon.com/about-aws/whats-new/2026/10/openai-daybreak-red-govcloud-east/)使用 GPT‑5.6 Cyber。此次扩展为政府安全团队提供了一种新途径，让他们能够在用于支持关键任务的 AWS 环境中运用先进的网络安全能力。

Daybreak Red 提供对 OpenAI 专门训练的网络安全模型的访问权限，用于开展经授权的漏洞研究、漏洞利用验证和安全测试。GPT‑5.6 Cyber 可以帮助防御人员调查复杂的软件安全缺陷、在受控环境中复现漏洞，并制定缓解措施。在实施修复方案之前，应由具备资质的安全从业人员审核相关发现和建议方案。

## 为政府团队带来前沿网络安全能力

对政府机构而言，采用先进的网络安全能力，不能只看模型性能。团队还需要遵循既定的安全、治理和运营要求。

GPT‑5.6 Cyber 在 AWS GovCloud (US-East) 上线后，符合条件的团队便可通过 Amazon Bedrock 将其融入这些工作流程。防御人员可以用它深入分析安全调查结果、评估其影响并检验修复方案，从而将漏洞研究转化为防御能力的实际提升。

Daybreak Red 为经过验证的防御人员开展经授权的网络安全工作提供了更大的空间，减少对此类任务的拒绝，同时加强身份验证、监控和访问控制。

对于 Amazon Bedrock 上的 Daybreak Red，推理数据不会用于训练模型，客户也无需与 OpenAI 共享其 Daybreak Red 数据。

## 开始使用

使用前需获得 OpenAI Daybreak Red 审批，并由 AWS 完成资源配置。如需开始使用，请填写[Daybreak 申请表](https://openai.com/form/enterprise-trusted-access-for-cyber/)，或联系你的 OpenAI 或 AWS 客户团队，了解申请资格。获批后，请与你的 AWS 客户团队协作，开通访问权限。获得 Daybreak Red 审批并不意味着会自动开通 AWS 上的模型访问权限。

进一步了解 [AWS 上的 Daybreak 模型](https://openai.com/index/daybreak-models-are-now-available-on-aws/)。
