# Codex：全面赋能各类角色、工具与工作流

全新推出专属角色插件、站点功能以及批注工具，助力团队全方位释放 Codex 的强大潜能


如今，Codex 的每周活跃用户已突破 500 万。Codex 最初是一款软件开发工具，现在也能帮助人们完成越来越多类型的工作。目前，非开发者群体（涵盖分析师、营销人员、运营人员、设计师、研究员、投资人及银行业务人员等）[约占 Codex 用户总数的 20%⁠](https://openai.com/zh-Hans-CN/index/codex-for-knowledge-work/)，且该群体的增长速度是开发者群体的 3 倍多。

今天，我们隆重推出一系列全新功能，旨在助你更高效地驾驭日常工作：量身定制的插件 (plugin) 能让 Codex 完美契合你的特定角色与常用工具；便捷的批注 (annotation) 功能支持你在当前界面实时打磨和优化生成结果；此外，我们还提供了交互式网站与应用创建功能的前瞻预览 — 只需通过链接 (URL)，即可在工作空间内轻松分享你的成果。

在 OpenAI 内部，非技术团队正借助 Codex 轻松构建内部应用、筹备高管汇报材料、搭建数据看板，并将创意简报迅速转化为严格遵循品牌规范与设计限制的落地成果。在 Zapier，团队利用 Codex 从 Slack、Google Docs 和 Coda 等协作工具中高效提取关键知识，并基于这些背景信息快速生成项目复盘报告、事件响应预案以及功能需求工单。而在 NVIDIA，研究人员则运用 Codex 大幅加速了实验工作流。无论是探索前沿的研究灵感，还是为机器学习基础设施编写底层脚本，整体研发效率均实现了显著跃升。

## 让 Codex 契合团队工作流

只有真正融入团队现有的工作方式，Codex 才能发挥最大效用：无缝对接你常用的工具，随时为你生成所需的各类材料。

借助插件 (plugin)，Codex 能够轻松适配团队现有的工具、业务背景与工作流。今天，我们正式推出六款全新的专属角色插件，让 Codex 能够赋能更广泛的知识型工作，全程无需编写任何代码：

- 每款角色专属插件都整合了相关的应用、技能、指令和工作流。这些插件共涵盖 62 款热门应用和 110 项技能。
- [**数据分析插件**](https://chatgpt.com/plugins/share/32687761205248ae9b517f3d30ad8dd1)帮助分析师和业务团队用数据解答问题。团队可以借助 Snowflake、Databricks Genie、Hex 和 Tableau 等工具，探索产品和业务数据，分析关键指标变化的原因，并创建报告和仪表板。未来还将支持更多工具。
- [**创意制作插件**](https://chatgpt.com/plugins/share/a826391706e14c90816f2ceba9cc8b49)帮助营销和创意团队将创意简报转化为可供审阅的素材。团队可以借助 Figma、Canva、Shutterstock、Picsart 和 Fal 等工具，创建营销活动看板，制作并优化不同版本的展示广告，以及生成产品生活场景图或可直接用于电商的成套图片。
- [**销售插件**](https://chatgpt.com/plugins/share/22ec24462a4a410bba1c56c099f6101c)帮助销售团队结合客户背景信息，开展推动成交的各项工作。销售团队可以借助 Salesforce、HubSpot、Slack、Outreach、Clay、Rox 和 Actively 等工具，识别重点客户和商机信号、准备客户会议、完成后续跟进、更新客户记录、制定成交计划，并评估存在成交风险的商机。
- [**产品设计插件**](https://chatgpt.com/plugins/share/37f657dbc41f408d9b05b52d30b8b527)旨在将初步构想转化为可供团队评审的原型。团队可以探索产品方向、审查用户流程、基于线上网页制作原型，并将静态截图转化为可交互的界面，还能在 Figma 和 Canva 等工具中继续完善这些成果。
- [**公开股票投资插件**](https://chatgpt.com/plugins/share/8f2f2fb7215f4688a0853afd038f2a1a)帮助投资者理解市场和公司信息。投资者可以利用 Moody’s、Daloopa、Datasite、FactSet、LSEG、S&P、PitchBook 和 Hebbia 提供的信息，分析财报、对比公司、跟踪市场信号，并评估投资逻辑是否得到进一步支持或有所削弱。
- [**投资银行插件**](https://chatgpt.com/plugins/share/479468a8d5224cb2976c0fe6c6e599b5)帮助投行从业者将研究和尽职调查成果转化为可直接交付客户的材料。他们可以利用可靠的数据准备业务推介材料、开展可比公司和可比交易分析，并根据尽职调查结果提出建议。

所有插件均开箱即用。不仅如此，团队还可以根据自身的工作流对这些插件进行灵活调整，甚至针对内部的系统与业务流程，量身打造并分享专属的自定义插件。

更多专属角色插件即将陆续上线，涵盖企业财务、私募股权投资、营销战略、战略咨询以及法务等核心业务领域。而这一切仅仅是个起点：我们正致力于构建一个高度开放的生态系统。未来，我们的合作伙伴将能够直接在 Codex 和 ChatGPT 中自主开发并轻松部署他们的专属插件。

## 借助站点功能，轻松分享你的成果

针对 Business 与 Enterprise 客户，Codex 现已开放一项前瞻预览功能：支持创建并分享可托管的交互式网站与应用程序。

站点 (Site) 是一个承载你无限创意的新型画布 (canvas)。Codex 能够将你的构思、分析与计划，直接转化为数据看板、规划器、评审工作空间、项目看板、内容画廊以及轻量级工具。如今，只需一个链接 (URL)，你就能将生成的站点分享给工作空间内的任何成员。它为团队打造了一个绝佳的共享阵地，让大家可以在此共同探讨工作、提供反馈、追踪进度并协同制定决策。

让 Codex 为即将到来的客户业务回顾搭建一个站点，它便会生成一个交互式网页，里面清晰罗列相关的产品更新、待解决问题、使用趋势以及该客户的后续规划。你也可以让它基于财务模型构建一个场景规划器 (scenario planner)，让高管们能够直观地比对各项假设，彻底告别在冗长的文档标签页中来回翻找的操作。你还能让它将产品发布材料转化为一个实时更新的信息中心，方便团队随时查看最新的对外口径、里程碑节点、项目负责人及核心决策。此外，当细节发生变化时，只需一句话，Codex 就能让这个站点始终保持最新状态。

团队再也不用为了迁就某个单一工具或文件的局限性而妥协，而是可以量身定制真正贴合工作需求的站点。而且，站点绝非静态页面。它们不仅能用来追踪重大项目的进展、为客服代表提供指引，还能作为团队存放创意简报的专属资料库。

目前，我们也正与 Vercel、Wix、Base44、Replit、Lovable、Figma、Webflow 以及 Emergent 等早期合作伙伴携手，积极推进站点合作伙伴生态系统的建设。

## 巧用批注细致打磨你的创作

开发者们早已习惯在 Codex 中使用批注功能来优化代码、Markdown 文件以及 Codex 生成的网站。借助批注 (annotation)，你只需选中想要调整的特定部分，并告诉 Codex 需要做哪些修改即可。如今，这种高效的工作方式已全面拓展至你创建的各类内容中，无论是文档、电子表格还是幻灯片，都能轻松驾驭。

选中站点中的导航栏，让 Codex 更新字体样式；高亮投资逻辑中的某个论断，让 Codex 追溯其数据来源；或是标记幻灯片上的图表，要求 Codex 提供更清晰的标签。Codex 会将修改动作聚焦于你选中的内容上。这样一来，你可以在保留已有满意成果的同时，对局部细节进行精雕细琢，彻底告别推倒重来的烦恼。当你的初稿完成，进入需要人工判断、整合反馈与不断迭代的阶段时，批注功能无疑让 Codex 变得更加得心应手。

## 可用性与快速入门

角色专属插件正在支持的地区面向 Codex 用户陆续推出。你可以从 Codex 插件目录安装这些插件，Codex 会协助你完成设置。Codex 也可以帮助你自定义插件。对于 Business 和 Enterprise 工作空间，[管理员可在工作空间设置中管理](https://help.openai.com/articles/20001256)相关应用的权限。

站点功能正通过 Codex 应用，以预览版形式向 Business 和 Enterprise 团队陆续开放。[Enterprise 管理员可在管理员设置中启用站点](https://developers.openai.com/codex/sites#get-started-with-sites)。

欢迎探索更多团队使用 Codex 的成功案例；或者直接与我们的团队取得联系，即刻开启你的 Codex 之旅。
