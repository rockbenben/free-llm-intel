# Codex 正成为人人可用的生产力工具

阅读报告

（在新窗口中打开）

正在加载…

OpenAI 今日发布了[一份新报告⁠（在新窗口中打开）](https://cdn.openai.com/pdf/the-next-era-of-knowledge-work.pdf)《*知识工作的新纪元*》，展示了 Codex 如何不再只是一个编码工具。它正越来越多地帮助各行各业的人们自动化日常工作、加快推进速度，并消除现代知识工作中的瓶颈。

Codex 目前每周活跃用户已超过 500 万，自 2 月推出桌面应用以来增长超过 6 倍。虽然开发者仍是最大的用户群体，但知识工作者现在约占用户的 20%，且增长速度超过前三者的三倍。

数据表明，一场更广泛的转变正在发生。知识工作者主要使用 Codex 创建报告、电子表格、演示文稿、合同和其他工作成果。他们也越来越多地将其用于研究、数据分析、工作流自动化，以及构建过去需要工程支持的轻量级工具。

增长最快的知识工作者任务是数据分析、研究和知识成果创建。与此同时，用户越来越多地并行运行多项 Codex 任务，从而能够同时调查数据、起草材料并自动化工作流。这种速度提升可能会重塑 AI 对工作的长期影响：Codex 可以帮助人们承担更具雄心的项目，扩大其职责范围，并可能加速职业发展。

在各个行业中，模式相似：人们正在使用 Codex 来减少现代工作的阻力。它帮助他们查找分散在各系统中的信息，协调跨工具和团队的工作，产出高质量交付物，并推动项目通过审查和审批流程。

如需更深入了解知识工作者如何使用 Codex，请阅读[完整报告⁠（在新窗口中打开）](https://cdn.openai.com/pdf/the-next-era-of-knowledge-work.pdf)。
