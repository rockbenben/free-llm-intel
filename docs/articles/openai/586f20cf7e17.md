# 基于预测奖励的强化学习

阅读论文（在新窗口中打开）

查看代码（在新窗口中打开）

[来源⁠（在新窗口中打开）](https://www.mobygames.com/game/nes/super-mario-bros)

我们开发了[随机网络蒸馏（Random Network Distillation，RND）⁠](https://openai.com/index/reinforcement-learning-with-prediction-based-rewards/#RNDjump)——一种基于预测的方法，用好奇心鼓励强化学习 agent 探索其环境。它[A](https://openai.com/index/reinforcement-learning-with-prediction-based-rewards/#citation-bottom-A) 首次在《蒙特祖玛的复仇》[Montezuma's Revenge⁠（在新窗口中打开）](https://www.retrogames.cz/play_124-Atari2600.php?language=EN)上超越了普通人平均水平。RND 取得了最先进（state-of-the-art）的性能：在既不使用示范数据、也无法访问游戏底层状态的情况下，它能周期性地找到全部 24 个房间并通关第一关。

RND 通过衡量“在已访问状态下预测一个固定的随机神经网络输出有多难”，来激励对[陌生状态⁠](https://openai.com/index/reinforcement-learning-with-prediction-based-rewards/#implementationjump)的访问。在陌生状态中，输出难以猜测，因此奖励很高。它可以应用于任何强化学习算法，实现简单且易于高效扩展。下文我们发布了一个 RND 参考实现，可复现我们论文中的结果。

## 在《蒙特祖玛的复仇》上的进展

agent 要实现目标，首先必须探索环境中什么是可能的、什么构成向目标迈进。许多游戏的奖励信号自带一种“课程”，即便简单的探索策略也足以达成游戏目标。在[引入 DQN 的开创性工作⁠（在新窗口中打开）](https://www.nature.com/articles/nature14236)中，《蒙特祖玛的复仇》是 **DQN 唯一拿到普通人平均分（4.7K）0% 的游戏**。简单的探索策略几乎不可能获得任何奖励，也不可能看到这一关卡 24 个房间中的少数几个之外。自那以后，蒙特祖玛复仇的进展在许多人看来就等同于探索技术的进展。

[2016⁠（在新窗口中打开）](https://arxiv.org/abs/1606.01868) 年取得了重大进展：把 DQN 与基于计数的探索加成相结合，得到一个探索了 15 个房间、最高分 6.6K、平均奖励约 3.7K 的 agent。自那以后，RL agent 分数的[重大⁠（在新窗口中打开）](https://arxiv.org/abs/1805.11593)[提升⁠（在新窗口中打开）](https://arxiv.org/abs/1805.11592)只来自于利用人类[专家⁠（在新窗口中打开）](https://arxiv.org/abs/1809.03447)的[示范⁠（在新窗口中打开）](https://blog.openai.com/learning-montezumas-revenge-from-a-single-demonstration/)，或访问[模拟器⁠（在新窗口中打开）](https://blog.openai.com/learning-montezumas-revenge-from-a-single-demonstration/)的底层状态。

我们运行了一个大规模 RND 实验，配备 1024 个 rollout worker，**9 次运行的平均回报达到 10K**，最佳平均回报为 14.5K。每次运行发现 20 至 22 个房间。此外，一个规模较小但运行时间更长的实验中，10 次运行里有 1 次**取得了 17.5K 的最佳回报——相当于通过第一关并找到全部 24 个房间**。下图比较了这两个实验，展示平均回报随参数更新次数的变化。

## 好奇心驱动学习的大规模研究

在开发 RND 之前，我们与 UC Berkeley 的合作者共同研究了*完全不使用*环境特定奖励的学习。好奇心给了我们对 agent 与任意环境交互的一种更简单的教导方式，而无须大量设计任务特定的奖励函数、再指望它对应于解决任务。[ALE⁠（在新窗口中打开）](https://github.com/mgbellemare/Arcade-Learning-Environment)、[Universe⁠（在新窗口中打开）](https://github.com/openai/universe)、[Malmo⁠（在新窗口中打开）](https://github.com/Microsoft/malmo)、[Gym⁠（在新窗口中打开）](https://github.com/openai/gym)、[Gym Retro⁠（在新窗口中打开）](https://github.com/openai/retro/)、[Unity⁠（在新窗口中打开）](https://github.com/Unity-Technologies/ml-agents)、[DeepMind Lab⁠（在新窗口中打开）](https://github.com/deepmind/lab)、[CommAI⁠（在新窗口中打开）](https://github.com/facebookresearch/CommAI-env) 等项目通过标准化接口，为 agent 提供了大量可交互的仿真环境。使用不依赖于具体环境细节的通用奖励函数的 agent，可以在众多环境中获得基本水平的能力，从而使其在没有精心设计的奖励的情况下也能判断什么行为是有用的。

- [阅读论文（在新窗口中打开）](https://arxiv.org/abs/1808.04355)
- [查看代码（在新窗口中打开）](https://github.com/openai/large-scale-curiosity)

在标准强化学习设定中，每个离散时间步 agent 向环境发送一个动作，环境则返回下一个观测、转移奖励和回合结束标志。在我们的[上一篇论文⁠（在新窗口中打开）](https://arxiv.org/abs/1808.04355)中，我们要求环境[只⁠（在新窗口中打开）](https://pathak22.github.io/noreward-rl/)[输出⁠（在新窗口中打开）](https://arxiv.org/abs/1606.01868)下一个观测。在那里，agent 从经验中学习一个下一状态预测模型，并把预测误差用作内在奖励。因此它会被不可预测之物吸引。例如，只有当游戏分数显示在屏幕上且变化难以预测时，它才会觉得分数变化有奖励。agent 通常会觉得与新对象的交互有奖励，因为这类交互的结果往往比环境的其他方面更难预测。

与[先前⁠（在新窗口中打开）](https://arxiv.org/abs/1507.00814)[工作⁠（在新窗口中打开）](https://pathak22.github.io/noreward-rl/)类似，我们尝试通过选择对观测的特征建模，来避免对环境的所有方面（无论是否相关）建模。令人惊讶的是，我们发现即使*随机特征*也效果很好。

## 好奇的 agent 会做什么？

我们在 50 多个不同环境中测试了 agent，观察到从看似随机行动到刻意与环境交互的各种能力水平。令我们惊讶的是，在某些环境中，agent 尽管从未通过外在奖励被告知游戏目标，却达成了游戏目标。

**打砖块（Breakout）** 训练早期，agent 在见到新的砖块布局时会经历内在奖励的激增；在训练数小时后首次通关时也是如此。

**乒乓（Pong）** 我们训练 agent 同时控制两块拍板，它学会了让球保持在场内、形成长回合。即使与游戏内置 AI 对战，agent 也试图拖延比赛而不是取胜。

**保龄球（Bowling）** agent 学会的水平超过了直接最大化（截断后）外在奖励训练出的 agent。我们认为这是因为 agent 被全中（strike）后难以预测的记分牌闪烁所吸引。

**马里奥（Mario）** 内在奖励与游戏目标——通过各关卡——特别一致。agent 因发现新区域而获得奖励，因为新区域的细节无法预测。结果，agent 发现了 11 个关卡、找到隐藏房间，甚至击败了Boss。

## 噪声电视问题

就像被随机结果吸引的赌场赌徒，agent 有时会因“噪声电视问题”（noisy-TV problem）而被自己的好奇心困住。agent 找到环境中的一个随机性来源并不断观察它，在这些转移上始终体验高内在奖励。盯着播放雪花噪点的电视就是这样的陷阱。我们用一个字面上的演示来说明这一点：把 agent 放进一个 Unity 迷宫环境，里面摆着一台随机换台的电视。

虽然噪声电视问题在理论上令人担忧，但对于像蒙特祖玛的复仇这样大体确定的环境，我们预期好奇心会驱动 agent 发现房间、与对象交互。我们尝试了若干种下一状态预测式好奇心的变体，把探索加成与游戏分数结合。

在这些实验中，agent 通过一个有噪控制器控制环境：该控制器以一定概率重复上一个动作而不是当前动作。这种 sticky actions 设定被[建议⁠（在新窗口中打开）](https://arxiv.org/abs/1709.06009)作为在 Atari 这类完全确定游戏中的训练最佳实践，以防止死记硬背。Sticky actions 使房间之间的转移变得不可预测。

## 随机网络蒸馏

由于下一状态预测天然容易受噪声电视问题影响，我们识别出预测误差的以下相关来源：

- **因子 1**：预测误差在预测器无法从既往样本泛化处偏高。新经验因而对应高预测误差。
- **因子 2**：预测目标本身是随机的，导致预测误差偏高。
- **因子 3**：预测所需信息缺失，或预测器的模型类别过于有限、无法拟合目标函数的复杂度，导致预测误差偏高。

我们判定因子 1 是有用的误差来源，因为它量化了经验的新奇性；而因子 2 和 3 造成噪声电视问题。为避开因子 2 和 3，我们开发了 RND——一种新的探索加成，基于**在给定下一状态本身的条件下，预测一个固定的、随机初始化的神经网络在其上的输出**。

直觉在于：预测模型在与训练所见相似的状态上误差很低。特别地，agent 对一个随机初始化神经网络输出的预测，在新奇状态中会比对频繁访问的状态不准。使用一个合成预测问题的好处在于：我们可以让它成为确定性的（绕过因子 2），并落在预测器可表示的函数类内（绕过因子 3）——方法是让预测器与目标网络采用相同架构。这些选择使 RND 对噪声电视问题免疫。

我们使用 [近端策略优化⁠（在新窗口中打开）](https://arxiv.org/abs/1707.06347)（[PPO⁠（在新窗口中打开）](https://blog.openai.com/openai-baselines-ppo/#ppo)）的一个变体，把探索加成与外在奖励结合——该变体为两路奖励流使用**两个价值头**。这允许我们对不同奖励采用不同折扣率，并把有回合与无回合的回报结合起来。**有了这份额外的灵活性，我们最好的 agent 在蒙特祖玛的复仇第一关中通常能找到 24 个房间里的 22 个，并偶尔在找到剩余两个房间后通过第一关。**同一方法在 Venture 和 Gravitar 上也取得最先进性能。

## 实现细节很重要

对噪声电视问题的易感度等大局考量，对选择合适的探索算法很重要。然而我们发现，在这个简单算法中把看似细小的细节做对，决定了 agent 是终生困在第一关、还是能够通过第一关。为了增加训练稳定性，我们避免特征饱和，并把内在奖励控制在一个可预测的范围内。我们还注意到，**每次发现并修复一个 bug，RND 的性能都有显著提升**（我们最喜欢的一个 bug 是不小心把一个数组置零，导致外在回报被当作无回合处理；我们是在困惑于外在价值函数为何“规律得可疑地”呈周期性之后，才意识到这一点）。把这些细节做对，即便是与既有工作在概念上相似的算法，也是取得高性能的重要部分。这也是在可能情况下偏爱更简单算法的原因之一。

## 未来方向

我们为后续研究提出以下路径：

- 分析不同探索方法各自的收益，并发现把它们结合的新方式。
- 在许多不同环境中无奖励地训练好奇的 agent，研究其向有奖励目标环境的迁移。
- 研究涉及长时间跨度协调决策的全局探索。
