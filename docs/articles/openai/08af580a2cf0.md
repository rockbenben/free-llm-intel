# 用 GPT‑4 做内容审核

我们使用 GPT‑4 进行内容政策制定与内容审核决策，实现更一致的标注、更快的政策迭代反馈回路，并减少人工审核者的参与。

内容审核对维系数字平台的健康至关重要。使用 GPT‑4 的内容审核系统让政策变更的迭代大大提速——周期从数月缩短到数小时。GPT‑4 还能解读冗长内容政策文档中的规则与细微之处，并即时适应政策更新，从而带来更一致的标注。我们认为这描绘了数字平台更光明的未来图景：AI 可以按照平台专属政策审核线上内容，并减轻大量人工审核者的精神负担。任何拥有 OpenAI API 访问权限的人都能实现这套方法，搭建自己的 AI 辅助审核系统。

## 内容审核的挑战

内容审核需要一丝不苟的投入、敏感度、对上下文的深刻理解，还要能快速适应新场景，因此既耗时又困难。传统上，这一重担落在人工审核者身上：他们要在海量内容中筛除有毒与有害材料，辅以小型的垂直领域机器学习模型。这一流程天生缓慢，并可能给人类审核者带来精神压力。

## 使用大语言模型

我们正在探索用 LLM 来应对这些挑战。GPT‑4 这样的大语言模型能理解并生成自然语言，适用于内容审核。模型可以依据提供给它的政策准则作出审核判断。

有了这套系统，内容政策的制定与定制流程从数月缩减到数小时。

- 政策准则写好后，政策专家通过识别少量示例并按政策为其分配标签，创建一份黄金数据集。
- 然后，GPT‑4 阅读政策并为同一数据集分配标签，且看不到答案。
- 通过检查 GPT‑4 判断与人类判断之间的分歧，政策专家可以让 GPT‑4 给出其标签背后的推理，分析政策定义中的模糊之处、消除困惑，并相应地在政策中提供更多澄清。重复第 2、3 步，直到我们对政策质量满意为止。

这一迭代流程产出被精炼过的内容政策，并转化为分类器，使政策与内容审核得以规模化部署。

可选地，为在规模上处理海量数据，我们可以用 GPT‑4 的预测去微调一个远更小的模型。


这个简单却强大的想法，为传统内容审核方法带来多项改进：

- **更一致的标签。** 内容政策持续演化且往往非常细密。不同的人对政策的解读可能有差异，或有些审核者需要更久才能消化新政策变更，导致标注不一致。相比之下，LLM 对措辞的细微差异很敏感，能即时适应政策更新，为用户提供一致的内容体验。
- **更快的反馈回路。** 政策更新周期——制定新政策、标注、收集人工反馈——往往漫长而拖沓。GPT‑4 能把这一过程缩短到数小时，从而对新型伤害更快响应。
- **减轻精神负担。** 持续接触有害或冒犯性内容会导致人类审核者的情绪耗竭与心理压力。把这类工作自动化，有利于相关人员的福祉。

我们如何利用 GPT‑4 进行内容审核的流程示意：从政策制定到规模化审核。

与主要依赖模型自身内化的“安全与否”判断的 Constitutional AI（[Bai 等，2022⁠（在新窗口中打开）](https://arxiv.org/abs/2212.08073)）不同，我们的方法让平台专属的内容政策迭代快得多、省力得多。我们鼓励信任与安全（Trust & Safety）从业者尝试这一内容审核流程——任何有 OpenAI API 访问权限的人今天就可以复现同样的实验。


我们正在积极探索进一步提升 GPT‑4 预测质量的方法，例如引入思维链（chain-of-thought）推理或自我批判。我们也在试验识别未知风险的方式，并受 Constitutional AI 启发，尝试让模型依据“何谓有害”的高层描述来识别潜在有害内容。这些发现将反过来指导现有内容政策的更新，或全新风险领域政策的制定。

## 局限

语言模型的判断容易受到训练期间可能引入模型的非期望偏见影响。与任何 AI 应用一样，其结果和输出需要由人保持在回路中，仔细监控、验证和改进。通过减少语言模型可胜任的审核环节中的人工参与，可以把人力更集中于处理政策完善最需要的复杂边缘案例。在我们持续打磨与发展这一方法的过程中，我们承诺保持透明，并会持续与社区分享我们的经验与进展。
