# Introducing ChatGPT Wallet

与支付网络、银行和商家共同构建可信的智能体支付。

我们推出 ChatGPT Wallet，为智能体的安全支付树立新标杆。它是首款让智能体在无需接触用户真实卡片信息的情况下完成支付的钱包，并要求每笔购买都经过安全检查，同时保留现有卡片权益与符合资格的争议保护。ChatGPT Wallet 由 American Express、Mastercard 和 Visa 合作打造，初期将通过 [dots⁠](https://openai.com/index/introducing-dots/) 面向美国的 ChatGPT Pro 订阅用户开放。伴随 ChatGPT Wallet，我们还将发布工具和指南，帮助商家为使用智能体的客户提供支持。

每周有 12 亿人使用 ChatGPT，其中许多人借助它研究商品、比较选项并决定购买什么。借助 ChatGPT Wallet，我们现在帮助用户完成购买，并让他们的智能体拥有一种商家可用现有系统受理的支付方式。

要受理来自 ChatGPT Wallet 的付款，网站需要确保智能体不会被无意拦截，支付与风控系统也需要识别由智能体发起的合法购买。我们先从面向 ChatGPT Pro 用户的有限开放起步，以便从真实使用场景中学习，并与商家、银行和支付网络合作，提升兼容性与可靠性。

## 购买流程

ChatGPT Wallet 为智能体提供了一种代表用户安全支付的方式。用户只需添加一次卡片，之后每笔购买只需批准，无需重新输入支付信息。

每次购买前，用户会核对商品、总额和所选卡片，然后通过 Face ID 或指纹扫描等安全检查予以批准。每次批准都会生成一条清晰的记录，表明该笔购买是用户授权智能体进行的。

用户批准后，支付网络会提供一个 payment token——替代用户真实卡片信息的凭据——其中包含卡号、安全码和有效期。款项会计入用户所选的卡片，而 ChatGPT Wallet 不会向商家或智能体共享用户的真实卡片信息。

我们正构建由智能体主导的商务，使其可靠地融入现有系统。用户保留其卡片现有的权益，以及与商家发生符合条件争议时的保护，例如商品存在缺陷的情形。银行和支付网络则贡献其在交易评估方面的专业能力。用户直接与商家交易，商家得以保留客户关系，以及对定价、履约、退货和客户服务的掌控。

随着时间推移，我们预计用户将能够通过设定明确的参数——如支出限额、购买类别或时间段——把购买完全委托给智能体，并以建立在现有保护之上的强化保障措施预先批准这些购买，包括生物识别核验和清晰的授权记录。

## 帮助商家为智能体商务做好准备

智能体商务仍处于早期阶段。随着智能体开始承担更多购物和采购任务，许多网站和支付系统仍在适应这一模式。部分网站可能会无意中阻断通过 ChatGPT Wallet 或其他智能体支付产品完成的购买，我们正专注于帮助商家完成这一过渡。

伴随 ChatGPT Wallet，我们还将发布 [Commerce Partner Playbook](https://developers.openai.com/commerce)，其中包含工具和实用指南，帮助商家通过现有网站和系统为使用智能体的客户提供支持。内容涵盖提供商品信息、确保智能体可访问，以及与支付和风控服务商合作以减少不必要的拒付。商家可以从与客户最相关的方面入手：

- **帮助客户找到准确的商品信息。 **[在 ChatGPT 中认领你的商家](https://openai.com/index/introducing-businesses-chatgpt/) 并在验证后更新商家信息、上传包含当前定价和库存状况的商品 feed。
- **确保 ChatGPT 智能体可以访问你的网站。** 配置 CDN 或防火墙，使用 Web Bot Auth 识别签名请求，并确认常规站点安全措施没有无意中拦截 ChatGPT 智能体。浏览器访问无需插件或商品 feed。
- **与支付和风控服务商合作以支持智能体购买。 **Wallet 的 payment tokens 可与现有结账流程配合使用，但风控系统仍可能将智能体发起的合法购买标记为可疑，导致拒付或取消。你可以与服务商合作，了解它们如何识别这些交易。我们还正与 Forter、Riskified、Sardine 和 Signifyd 等防欺诈合作伙伴，以及 Adyen、Checkout.com 和 Stripe 等支付服务商合作，帮助它们的系统识别智能体发起的合法购买。
- **为智能体提供更多与你的商家协作的方式。** 构建插件，让智能体通过你的现有系统查询库存、管理购物车或执行其他操作。网站还可以添加 WebMCP 工具。

## 可用范围

ChatGPT Wallet 今日起在 dots 中逐步推出，用户可以让自己的 dot 代为完成购买。初期将面向美国境内 18 岁及以上、持有符合条件的美国发行卡片的 ChatGPT Pro 订阅用户开放。我们将与商家、银行和支付网络合作，从早期使用中学习并扩大开放范围，帮助更多客户和商家从智能体商务中受益。
