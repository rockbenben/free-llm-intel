# Gondola 团队借助 Codex 开发更多产品，实现营收翻倍

Gondola 帮助创意人才获得认可和工作机会。借助 Codex，其首席工程师的产出提升了 50%，ChatGPT 则让日常工作更简单。

在经营自己的创意制作公司 Fresh Tape Media 时，Jared Kleinstein 发现了一个问题：社交媒体上涌现出许多精彩的创意作品，但幕后的创作者却没有得到应有的认可。于是，他创建了 [Gondola](https://gondola.cc/) 平台，帮助创意人才展示作品、证明作品的影响力，并通过作品赢得下一个工作机会。

对于 Gondola 的小团队来说，最大的制约之一，是能够承担的产品开发和运营工作量有限。即便是小规模试验，也要与核心产品的优先事项争夺工程资源；查找信息和起草文稿，也需要在各种工具和系统中翻找资料。

如今，团队使用 Codex 将更多想法变成软件，并通过 ChatGPT 简化日常运营。整个团队的月度工程产出提升了 25%，其中首席工程师的产出提升了 50%。公司营收已超过去年同期的两倍。对 Jared 而言，这让他对团队能做到什么有了新的认识。

> “使用 OpenAI 后，我们对自己这样规模的公司能做出什么，有了更大的抱负。”

—Jared Kleinstein，Gondola 创始人兼首席执行官

## 借助 Codex，让业务团队与工程师共同开发

Gondola 的许多产品想法，直接来自业务拓展团队和管理层在客户交流中获得的洞察，以及他们亲身遇到的运营问题。在使用 Codex 之前，他们需要先明确需求、编写需求文档，然后等待工程师腾出时间来开发第一个版本。

如今，这些团队成员可以使用 Codex Cloud 探索代码库、制作界面或工作流原型，并验证设想，往往在工程师介入之前就能做出可运行的初版。Jared 和 Gondola 的创作者与客户合作经理 Jojo Hesketh 都已将各自有史以来首次提交的代码合并到了主代码库。

> “产品经理的工作不必再止步于写出产品需求文档。他们可以直接向工程团队交付一个可运行的原型。”

—Jared Kleinstein，Gondola 创始人兼首席执行官

Programs 就是一个例子。Gondola 开发了这款工具，帮助企业寻找创意人才、审核申请者、管理项目和追踪预算，并计划用它协助处理合同和付款事宜。

Jojo 牵头推进了 Programs，并使用 Codex 制作工作流原型，再交由工程师完善和发布。团队最初使用 GPT‑5.4，通过 GPT‑5.5 完成了大部分工作，之后则使用 GPT‑6.1 开发后续功能、进行优化和修复缺陷。

Jared 估计，Codex 节省了数天、甚至数周的开发时间，还让团队发布的 Programs 比完全手工编写代码时的缺陷更少。Jared 说：“我们能快速制作原型，舍弃行不通的方案，保留有效的方案，Programs 功能因此受益。”

![在 Gondola 中搜索和追踪社交媒体内容的演示。](https://images.ctfassets.net/kftzwdyauwt9/3F5ftJp6446ugr5LGTYtjI/7675183af70038f17a8bb522f7bf870a/gondola-inline-02.gif?w=3840&q=90&fm=webp)

Gondola 的工程师通过命令行界面（CLI）和编辑器工具使用 Codex，加快功能实现，并在 GitHub 中用它审查拉取请求。公司将 Codex 连接到代码仓库、开发环境和 Slack，让产品背景信息能够为开发工作提供参考。架构、安全、数据处理，以及是否达到生产环境部署要求，仍由工程师负责把关。

## 加快开发，及时满足客户需求

在使用 Codex 之前，一些时效性很强的想法可能一直留在待办清单中，等待工程资源，而机会就这样错过了。但今年夏天，Codex 帮助 Gondola 赶在时机尚好时，开发并测试了世界杯创作者地图。

团队借助 Codex，将已有数据快速转化为满足客户当下需求的产品体验：一张能让品牌、球队和代理机构在世界杯举办城市寻找摄影师和摄像师的地图。

Jojo 同样牵头推进了创作者地图，并使用 Codex 制作了功能完整、可运行的原型。随后，工程师很快完成了打磨，让产品得以上线。Jared 形容这次开发“快得惊人”，因为项目范围小且相对独立，还有明确且不可延后的截止日期。他认为，与不使用 Codex 相比，创作者地图和 Programs 在发布时都更完善，缺陷也更少。

## 借助 ChatGPT，让小团队也能高效运营

产品开发只是 Gondola 运营工作的一部分。团队还使用 ChatGPT 准备提案、管理日程、跨公司系统查找信息，以及自动执行任务。

Gondola 使用 ChatGPT 制作了一份每日报告模板，员工每天早上可以先用它来规划一天的工作。它整合了 Google Workspace（包括 Gmail、日历、表格和云端硬盘），以及 Asana、Slack、QuickBooks、天气信息和其他来源，帮助员工全面了解当天的安排。

Jared 表示，手动准备这样一份详尽的报告需要“花上很多很多小时”，但配置好 ChatGPT 后，就能快速生成。对于影响重大的工作成果，在对外发送或用于业务决策之前，仍会由人工审核。

## 释放更多精力，帮助创意人才蓬勃发展

自 2026 年初采用 Codex 以来，按已合并的代码变更数量衡量，Gondola 首席工程师的月度交付量提升了约 50%。在工程人员数量不变的情况下，整个团队的产出提升了约 25%。团队交付的变更规模也更大了，而拉取请求（PR）的审查时间保持稳定。

Gondola 表示，在未增加薪酬成本或显著增加运营开支的情况下，公司营收已超过去年同期的两倍。公司帮助品牌聘用的创作者人数也达到了去年同期的 2.5 倍。

> “OpenAI 让产品人员更有能力动手开发，让工程师有更多时间攻克技术难题，也让业务团队有更多时间与客户、合作伙伴和创意人才交流。”

—Jared Kleinstein，Gondola 创始人兼首席执行官

展望未来，Gondola 希望 AI 能承担更多工作，帮助企业与创意人才建立联系。对 Programs 而言，这可能意味着减少寻找人才、管理预算与审批、处理合同以及支付报酬所需的协调工作。

Gondola 希望不断拓展这支小团队的交付能力，践行公司的创立初衷：帮助创意人才凭作品获得认可，并赢得下一个工作机会。
