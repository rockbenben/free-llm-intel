# 困惑与智力

作者：Jakub Pachocki，OpenAI 首席科学家

从远处看，现代人工智能的构建方式似乎与过去几十年软件的构建方式类似：使用针对特定功能的多种技术。确实有多种方法，但它们不是从头开始设计，而是“利用”来自更简单且难以解释的过程的智能：在非常大的数据集上训练压缩器（或[等效地]（https://en.wikipedia.org/wiki/Shannon%27s_source_coding_theorem）预测器）。[1](https://openai.com/index/perplexity-and-intelligence/#citation-bottom-1)

我相信跟踪训练更好的压缩器的进展速度是理解人工智能进步弧线的关键。在这篇文章中，我主张建立困惑度（或等效的交叉熵损失）作为模型开发人员之间进行比较并告知共享安全标准的指标。作为第一步，我为 OpenAI 的预训练进度提供了更多的透明度。发布我们的内部困惑度测量结果需要考虑一些因素；它让竞争对手更清楚地了解我们的立场，但这种担忧被整个行业建立[共享](https://darioamodei.com/post/we-must-pace-the-frontier)安全措施的紧迫性所抵消。 OpenAI 希望这能够成为为未来的配速工作建立共享科学基础的一步。

人工智能开发的一个简化但基本信息丰富的观点是，首先，构建一台大型计算机，然后使用它在大型非结构化数据集上“预训练”模型（压缩器），然后在不同的环境中应用各种技术（例如提示、微调或强化学习）以激发该模型的潜在功能。算法的进步可以模糊训练阶段之间的区别，但我们仍然可以将具有难以预测的突发能力的人工智能的创建（我之前称之为“[外星人思维]（https://openai.com/index/an-alien-mind/）”）与随后的有针对性的诱导分开。

多年来，我们衡量这一关键“智能基础”进展的主要方法一直保持非常稳定 - 我们一直在保留的数据集上跟踪模型的“困惑度”。[2](https://openai.com/index/perplexity-and-intelligence/#citation-bottom-2)，[3](https://openai.com/index/perplexity-and-intelligence/#citation-bottom-3) 困惑度衡量模型平均预测下一个标记的程度；较低的困惑度意味着更好的预测。本博文开头的图显示了从 GPT-3.5 开始，我们的模型的该指标是如何演变的。

主要由这一指标描述的模型的功能范围是惊人的。 GPT-2 在旧数据集 [4](https://openai.com/index/perplexity-and-intelligence/#citation-bottom-4) 上设置了新的最先进的困惑度，可以说是第一个能够一致地制定连贯的文本段落的模型。下一个重大飞跃是 GPT-3，它能够在给出一些任务示例的情况下进行学习。 GPT-3.5 在我们当前的主要评估数据集上的对数困惑度约为 0.99，能够进行流畅的对话，并构成了原始 ChatGPT 的基础。 GPT-4 的得分约为 0.91，能够熟练有效地利用思维链推理，这推动了后续有针对性地激发这种能力并创建现代推理模型。现在，当我们的损失已降至 0.8 以下时，我们看到了网络安全和数学等领域变革能力的出现。我想再次强调的是，一旦满足这些精确的困惑度阈值，这些能力就会出现，这一点根本不清楚“先验”——它们从根本上可以被视为这一指标进展中的新兴潜在能力。

随着人工智能的快速发展，我们衡量下游能力的范围和方式可能会迅速改变。在大多数现代基准上评估 GPT-2 和 GPT-3 没有什么意义；当时使用的基准在 GPT-4 附近基本饱和。相比之下，我相信关注预训练的进展可能会提供有用的信息。

进步速度的一个特殊变化来自于人工智能对其自身发展的贡献越来越大。最常讨论的指标围绕人工智能在开发周期的各个阶段增强和取代人类研究人员；最终的拐点是“完全递归自我改进”，该过程将完全自动化，无需人工监督。除了考虑这种状态是我们为了维持人类控制而显然应该避免的事情之外，我发现这个一般框架遗漏了一些至关重要的东西。人工智能参与开发过程的一个关键部分：预训练的算法研究，可能会带来潜在的改变。

最近，我们在另一个领域目睹了前所未有的加速。一年多来，我们一直在向我们的模型提出数学中的开放问题，作为评估模型的方法之一。一旦我们升级到对数困惑度 ~0.76 的模型，它就开始产生突破性的结果。对于我们许多以前在数学和相关领域工作过的人来说，看到我们长期思考的问题在一个 Slack 线程中一个接一个地得到解决，感觉非常超现实。经历过这些，我们可以进行推断——这种突然的转变在深度学习研究中也是合理的。虽然这个领域更多地依赖于实验，但多年来简单的见解一直被忽视。因此，到 2027 年，我们可以想象看到类似的基本预训练进步[5](https://openai.com/index/perplexity-and-intelligence/#citation-bottom-5)。虽然我预计人工智能也将极大地促进对齐和监控方面的进展，但我认为进展不太可能快到足以实现预训练的全部潜在加速。

鉴于新的令人惊讶的能力出现的主要方式是压缩方面的进步，无论开发过程的自动化程度如何，植根于困惑的衡量标准都可以为我们提供通用智能的共同基准。从最近的进展推断，当我们进入~0.68-0.7 log-perplexity 窗口时，我们应该期待进一步的变革能力。我不知道这些功能是什么，我们今天可能不会测试它们。与此同时，我们还应该期待当前占主导地位的一致性审计形式的[进一步退化](https://alignment.openai.com/cot-monitorability-model-lifecycle)，以及评估和培训意识的进一步提高。我认为前沿模型开发人员应该共同努力建立共享规范，以在首次使用此类模型时评估这些模型和红队安全案例，包括共享透明度标准。我进一步提出基于困惑度和其他测量的“共同限制”，开发人员承诺在我们理解和监控人工智能行为的能力达到某个具体里程碑（例如开发 CoT 监视器的继任者）之前不会跨越这些限制。也就是说，我想要一个行业标准，规定开发的第一个限制，通过我们可以跨实验室跟踪的一些关键指标来衡量，以及在超越它之前我们具体需要实现什么。我希望这能引导建立一个共同框架来设定连续的限制并加快进一步的发展步伐。

困惑度作为共享指标面临着挑战：

- **跨实验室比较的困难。 **不同的开发人员使用不同的评估数据集并在不同的数据混合物上进行训练。在这里，我们报告了我们一直在跟踪的主数据集上的数字；我相信，如果我们建立透明度目标，我们就可以找到可转移的方法来比较不同基础模型的质量。
- **脱离可操作的评估。 **困惑并不直接对应于我们关心的任务。关心它的原因是我们可以预期它的进步将导致全新功能的出现。
- **不考虑预训练之外的进步。 **最值得注意的是，思想链推理并不会减少模型所实现的复杂性，尽管它会导致能力的急剧增加。
- **未知楼层。 **我们不期望损失为 0，这相当于能够完全确定地预测数据集。但我们不知道数据的固有熵是多少。当我们接近它时，困惑度的明显进展将会放缓，但困惑度的较小增益将对应于模型智能的较大飞跃。

与此同时，困惑度作为一个指标经受住了时间的考验，许多研究团队在优化方面投入了大量精力，并且它继续在一般智力方面带来持续的收益。我相信它可以在标准化我们如何谈论人工智能进展方面发挥重要作用，并希望看到整个行业的透明度更高。

## 脚注

- 1值得注意的是，这个意义上的“压缩器”是能够通过预测看不见的数据来执行压缩的东西，而不是像GZIP文件这样的压缩工件——也就是说，在给定语料库上训练的最好的压缩器不一定“记住”语料库的内容。
- 2在实践中，我们通常跟踪困惑度的*log*，也称为*交叉熵损失*。
- 3自 GPT-3.5 以来我们一直使用的主要保留数据集来自我们的内部代码库，这些是此处报告的数字（针对固定快照）。
- 4考虑到 GPT-2 和 GPT-3 的训练内容，它们预测代码的能力并不能很好地反映它们的一般能力。这展示了使用困惑度作为共享指标来选择数据集所带来的潜在挑战；然而，将它们与一般文本的现代模型联合评估仍然应该提供信息。我选择报告我们内部代码库的困惑，因为我想分享我们今天最依赖的数据来衡量 OpenAI 预训练的进展。
- 5在 OpenAI 模型的损失图中，您可以看到 2026 年急剧加速。我们将其主要归因于长期研究和计算投资的结果，只有一小部分归因于自动化。然而，对于最新的模型，[我们已经看到来自 AI 的有意义的设计贡献](https://openai.com/index/research-acceleration-jagged-frontier/#where-big-ideas-come-from)。
