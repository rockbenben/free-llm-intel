# 神经 GPU 的扩展与局限





## 摘要

Neural GPU 是一个较新的模型，能够以泛化到任意长度输入的方式学习多位二进制加法和二进制乘法等算法。我们展示了两种提升 Neural GPU 表现的简单方法：精心设计课程，以及增大模型规模。后者需要省内存的实现，因为 Neural GPU 的朴素实现非常吃内存。我们发现这些技术扩大了 Neural GPU 能解决的算法问题集合：我们学会了执行所有算术运算（并泛化到任意长的数字），且参数采用十进制表示（令人意外的是，此前还做不到）。我们还成功训练 Neural GPU 求值需要遵守运算优先级、含多个操作数的长算术表达式，尽管这些只在二进制表示下成功，且达不到完美精度。此外，我们通过研究 Neural GPU 的失败模式来获得对它的理解。我们发现，能正确泛化到任意长数字的 Neural GPU 在高度对称、非典型的输入上仍会算错：例如，一个在最多 100 位十进制乘法上泛化近乎完美的 Neural GPU，可能在 000000…002×000000…002 上失败，却在 2×2 上成功。这些失败模式让人联想到对抗样本。
