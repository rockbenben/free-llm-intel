# FFJORD：面向可扩展可逆生成模型的自由形式连续动力学

Read paper

(opens in a new window)


## 摘要

有一类颇具前景的生成模型：它通过一个可逆神经网络，把简单分布中的点映射到复杂分布。这类模型的基于似然的训练要求限制其架构，以便廉价地计算 Jacobian 行列式。另一种做法是：如果变换由常微分方程给出，则可以使用 Jacobian 的迹。在本文中，我们采用 Hutchinson 迹估计器，为对数密度给出可扩展、无偏的估计。最终得到一个连续时间可逆生成模型，同时具备无偏密度估计、单趟采样，并且不限制神经网络架构。我们在高维密度估计、图像生成和变分推断上验证了我们的方法，在精确似然方法中达到 SOTA，并保持采样高效。
