# GPT-3 驱动下一代应用

已有 300 多款应用通过我们的 API 为用户提供 GPT-3 驱动的搜索、对话、文本补全等高级 AI 特性。


自我们第一款商业产品——[OpenAI API](https://beta.openai.com/)——[上线⁠](https://openai.com/index/openai-api/) 已过 9 个月，如今有 300 多款应用在使用 GPT-3，全球有数万名开发者在我们的平台上构建。我们目前平均每天生成 45 亿词，并持续扩大生产流量规模。

给定任何文本提示——比如一个短语或一句句子——GPT-3 会返回一段自然语言文本补全。开发者只需展示一些示例或"提示词"，就能"编程"GPT-3。我们把 API 设计得对任何人都足够简单，同时也灵活到足以让机器学习团队更具生产力。

## 应用与行业

到目前为止，已有超过 300 款应用跨不同类别和行业使用 GPT-3，从生产力和教育到创意和游戏。这些应用利用了 GPT-3 多样化的能力（也帮我们发现了新的能力！）。以下是一些：

**Viable** 借助 GPT-3 从客户反馈中提取有用洞见，并以易懂的摘要呈现，帮助企业更好地理解客户。

Viable 用 GPT-3 从问卷、帮助台工单、在线聊天记录、评论等中识别主题、情绪与情感。它会从这些汇总反馈中拉出洞见，并在数秒内提供摘要。

例如，如果提问 *结账体验中是什么让客户感到沮丧？*，Viable 也许会给出这样的洞见：*客户对结账流程感到沮丧，因为加载太慢。他们还希望在结账时能修改地址，并保存多种支付方式。*

> GPT-3 从自然语言中识别主题并生成摘要的能力，让 Viable 能帮助各个行业企业的产品、客户体验和营销团队，更深入理解客户的需求与诉求。

Daniel Erickson，Viable CEO

**Fable Studio** 正在创造一种全新的互动故事类型，并用 GPT-3 来驱动他们的故事型"虚拟存在（Virtual Beings）"。

Lucy 是 Neil Gaiman 与 Dave McKean 的 [Wolves in the Walls](https://fable-studio.com/wolves-in-the-walls) 中的主角——这部作品被 Fable 改编成荣获艾美奖的 VR 体验——借助 GPT-3 生成的对白，她可以与人们自然对话。Lucy 作为嘉宾参加了 2021 年 Sundance 电影节，并展示了她自己的电影 *Dracula*。

**Algolia** 把 GPT-3 用在他们的 Algolia Answers 产品中，为客户提供相关、极速的语义搜索。

OpenAI API 上线之时，Algolia 就与 OpenAI 合作，把 GPT-3 与他们先进的搜索技术整合，构建出新的 Answers 产品——更好地理解客户的问题，并把他们连接到内容中真正回答他们问题的部分。Algolia Answers 帮助出版商和客户支持帮助台使用自然语言提问，并浮现非平凡的解答。在 210 万篇新闻文章上对 GPT-3 做测试之后，Algolia 看到 91% 及以上的精度，并且 Algolia 能够准确回答复杂自然语言问题的频率是 BERT 的四倍。

"Algolia Answers 在那些仅靠文本搜索难以回答的问题上表现优异，"澳大利亚 ABC 的产品经理 Peter Buffington 说。"它可以针对像'火山为什么会喷发？'这样的问题，从我们的新闻档案里返回非常相关、常青的内容。"

> GPT-3 让 Algolia 能在 Algolia Answers 产品中回答比以往更复杂的查询——识别更深的上下文信息、提升结果质量，并在数秒内交付。

Dustin Coates，Algolia 产品与 GTM 经理

## 平台改进

在我们扩大接入的同时，团队也在持续改进平台——从实现内容过滤器，到为开发者提供新功能。近期我们上线的包括：

- **Answers 接口**：在给定提示中，会先搜索用户提供的资料（文档、知识库等）以拿到相关上下文、加入提示后再由 GPT-3 补全。可以用来构建客户支持机器人等应用，无需微调。
- **Classifications 接口**：无需微调即可利用带标注的训练数据。通过搜索与输入查询最相近的例子并加入提示，它通常能匹敌最先进微调模型的表现，提供一个易于配置、易于适配的 autoML 方案。
- **增强搜索接口**：为 Answers 和 Classifications 接口提供后端支撑，能扩展到大量文档，同时廉价且迅速。
- **安全**：偏见与滥用是整个行业的重要问题，我们非常认真地对待。我们会审查所有申请，只批准那些负责任地使用 GPT-3 的生产用途。我们要求开发者在进入生产之前实现安全措施，例如速率限制、用户验证与测试，或人在回路要求。我们也会主动监控滥用迹象，并 "[红队](https://en.wikipedia.org/wiki/Red_team)" 应用以发现潜在漏洞。此外，我们还开发并部署了一个内容过滤器，把文本分类为安全、敏感或不安全。目前我们设置成偏保守，这带来更高的假阳性率。
- [**提示库**](https://beta.openai.com/examples)：为数十种用例提供起步提示设计示例，用户可以在 Playground 里直接开始编程——例如电子表格生成器、语法纠正器、机场代码提取器。

## 不断成长的开发者社区

我们有一个不断成长的、遍布全球、由数万名开发者组成的社区，主要分布在北美、欧洲、亚洲和大洋洲。我们也发现，我们的开发者中有许多人并非具备传统 AI 或软件工程背景。几位开发者告诉我们，他们第一次接触 API 或编程就是在 OpenAI 界面上——这让我们很欣慰。

> 对我自己以及其他以使命为驱动的 innovators 来说，OpenAI 借助 GPT-3 终于给了我们能够推动社区变革的工具。有了自然语言处理，技术经验不再是障碍，我们可以真正专注于解决现实世界的问题。在我与很多初次开发者的合作中，那些在 GPT-3 上构建得最成功的人往往是优秀的沟通者——因为他们能解锁提示设计中的细微之处。— Abran Maldonado，Create Labs 联合创始人

> 因为使用自然语言提示，用 GPT-3 编程感觉比传统编码更像是一种创意过程。我相信 AI 未来会被集成进每一个产品，我非常享受与来自全球、经验水平各异的开发者一起通过 API 打造创新应用。— Natalie Pistunovich，Aerospike 首席开发者布道师、Women Techmakers Berlin 创始人
