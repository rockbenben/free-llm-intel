# GPT-6.1 Sol 帮助 CodeRabbit 加强复杂代码库的安全性

随着人工智能加速软件开发，工程和应用程序安全团队需要方法来调查代码更改并解决漏洞，同时让人们保持控制。 CodeRabbit 使用 [GPT-6.1 Sol](https://openai.com/index/introducing-gpt-6-1-sol/) 作为其安全代理中的主要模型，以将审查范围扩展到单个更改之外，并帮助开发人员了解复杂代码库中的风险。

拉取请求可能会影响应用程序中其他地方的共享库、依赖项和保护措施。 GPT-6.1 Sol 帮助 CodeRabbit 连接文件和组件之间的行为，以发现潜在的安全问题。 CodeRabbit 的审查独立于编写代码的代理并补充了现有的扫描程序。其系统还使用其他前沿模型和安全工具。

在拉取请求审查期间，Sol 帮助分析开发人员工作时的更改。在深度扫描中，它支持跨存储库进行更广泛的调查，包括依赖关系和组件如何交互。 CodeRabbit Secure 将该调查扩展到链接存储库（例如共享身份验证库），以帮助团队了解弱点如何影响更广泛的系统。

CodeRabbit 报告使用 GPT-6.1 Sol 来标记数千个存储库和组织中的安全相关问题。这些发现反馈到了开发人员已经用来审查和改进代码的拉取请求工作流程中。

CodeRabbit Secure 将调查与补救联系起来。对于用户选择的结果，它可以尝试在隔离的沙箱中进行漏洞利用验证，而无需测试生产系统。对于受支持的问题，它可以起草一个拉取请求，其中包含建议的修复方案，供人员审查和批准。

这项工作展示了前沿推理如何支持软件安全：了解单个变更之外的风险，帮助验证发现并将其转化为建议的修复方案。人工审核员仍然负责决定发布哪些更改。

了解有关 GPT-6.1 Sol 的更多信息 [此处](https://openai.com/index/introducing-gpt-6-1-sol/)。了解有关 CodeRabbit Secure 的更多信息 [此处](https://www.coderabbit.ai/security)。
