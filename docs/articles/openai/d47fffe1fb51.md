# 英国主权人工智能的新篇章


今年早些时候，我们与英国政府签署了一份谅解备忘录，旨在让更多英国民众、企业和机构受益于人工智能技术的潜力，并推动实现英国《人工智能行动计划》的目标。我们希望与英国政府携手，以人工智能驱动经济增长，加快私营和公共部门采用人工智能，并增强英国的主权人工智能能力，让人工智能在英国广泛普及，立足英国、服务英国。

今天，我们乘势而上，宣布与英国司法部达成一项新协议，让公务员能够使用 ChatGPT 并从中受益；同时，使用 API 平台、ChatGPT Enterprise 和 ChatGPT Edu 的客户也可选择英国数据驻留。

今天，我们的许多英国重要客户将齐聚伦敦参加 OpenAI Frontiers 活动。英国大法官兼司法大臣、副首相 David Lammy 也将出席，与大家共同探讨英国在人工智能领域的机遇。副首相还将详细介绍司法部如何为公共部门采用人工智能树立新标准。

## 英国司法部

与司法部达成的新协议将把 ChatGPT 引入公务员队伍，帮助他们节省时间、提高工作效率，并提供更优质的公共服务。该协议将支持司法部的[《司法人工智能行动计划》⁠（在新窗口中打开）](https://www.gov.uk/government/publications/ai-action-plan-for-justice)，并让 2,500 名员工能够使用 ChatGPT Enterprise。此前开展的试点项目取得了成功，结果显示，人工智能可帮助多项日常工作节省时间，包括写作辅助、合规与法律事务、数据与研究流程以及文档分析。

在英国政府的其他部门，已有多款工具采用 OpenAI 技术，其中包括旨在减轻公务员行政负担的白厅人工智能助手“Humphrey”，以及为政策制定流程提供支持的“Consult”。后者可自动整理公众咨询意见，将过去通常需要官员数周完成的工作缩短至几分钟，同时仍由专家作出重要决策。

**英国副首相兼大法官 David Lammy 表示：**“我们与 OpenAI 的合作让英国稳居全球科技革命的前沿，不仅引领全球创新，也借助技术为英国各地带来公平与机遇。”

**OpenAI 首席执行官 Sam Altman 表示：**“过去一年，英国使用我们产品的人数增长了三倍。看到他们利用人工智能节省时间、提高生产力并完成更多工作，令人振奋。公务员正使用 ChatGPT 改进公共服务，老牌企业也在重新构想运营模式。我们很自豪能继续支持英国及其政府的人工智能计划。”

## 推出英国数据驻留

我们与英国政府签署的谅解备忘录重点之一，是增强英国的主权人工智能能力。我们此前已宣布推出 Stargate UK。这是与 NVIDIA 和 Nscale 建立的人工智能基础设施合作项目，旨在利用本地算力运行 OpenAI 世界领先的人工智能模型，尤其服务于对司法管辖区有特定要求的专业应用场景。

除 Stargate UK 外，我们还将于 10 月 24 日星期五推出英国数据驻留选项，让英国客户和开发者可以选择将数据存储在英国，以满足当地的数据保护偏好或要求。根据上述协议，司法部将率先从这项服务中受益。

如需进一步了解数据驻留，请访问我们的帮助页面[此处⁠（在新窗口中打开）](https://help.openai.com/en/articles/9903489-data-residency-for-chatgpt)。

OpenAI 的技术已成为英国数百万人不可或缺的工具。按 OpenAI 付费订阅用户和 API 开发者数量计算，英国已跻身全球前五大市场。每天，英国各地的个人、开发者、机构、初创企业和领先企业都在使用我们的工具发掘新的经济机遇，其中包括 NatWest、Virgin Atlantic、本土独角兽 Synthesia 和牛津大学。

通过英国数据驻留、新的公共部门合作关系以及谅解备忘录框架下持续开展的工作，我们正帮助英国为可信、安全地采用人工智能奠定基础。我们期待与英国政府继续合作，让更多英国民众、企业和机构从人工智能中受益。
