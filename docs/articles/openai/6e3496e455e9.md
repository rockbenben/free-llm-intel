# ChatGPT 数据分析功能改进

今天，我们开始逐步推出数据分析的增强功能：

- 直接从 Google Drive 和 Microsoft OneDrive 上传最新版本的文档
- 在新的可展开视图中与表格和图表交互
- 自定义图表并下载，用于演示文稿和文档

数据分析改进将在未来几周内向 ChatGPT Plus、Team 和 Enterprise 用户在我们的新旗舰模型 GPT-4o 中开放。

## ChatGPT 数据分析是如何工作的

这些改进建立在 ChatGPT 理解数据集并用自然语言完成任务的能力之上。首先上传一个或多个数据文件，ChatGPT 会代你编写并运行 Python 代码来分析数据。它能处理多种数据任务，例如合并和清洗大型数据集、制作图表、挖掘洞见。这让初学者更容易进行深度分析，也为专家省下做例行数据清洗的时间。

> “ChatGPT 是我分析客户数据的工具之一——这些数据已经大到 Excel 处理不过来。它帮我梳理海量数据集，让我能独自做更多数据探索，缩短获得有价值洞见所需的时间。”

David Vaughn，The Carlyle Group 副总裁

## 直接从 Google Drive 和 Microsoft OneDrive 添加文件

无需先把文件下载到桌面再上传给 ChatGPT，现在你可以直接从 Google Drive 或 Microsoft OneDrive 添加多种文件类型。这让 ChatGPT 能更快地理解你的 Google Sheets、Docs、Slides，以及 Microsoft Excel、Word 和 PowerPoint 文件。

## 实时处理表格

当你添加数据集时，ChatGPT 会生成一个交互式表格，你可以将其展开为全屏视图，在分析过程中跟随它的更新。点击特定区域即可追问，或从 ChatGPT 的建议提示中选择一项，深入你的分析。

例如，你可以让 ChatGPT 合并多个月的支出电子表格，并按支出类别创建数据透视表。

> “ChatGPT 会带我一步步完成数据分析，帮我更好地理解洞见。它让我的工作更有成就感、帮我学习，并腾出时间专注于工作中更具战略性的部分。”

Lauren Nowak，Afterpay 市场经理

## 自定义可直接用于演示的图表

你现在可以在对话中自定义并与柱状图、折线图、饼图和散点图交互。悬停查看图表元素、提出更多问题，或选择颜色。准备好后即可下载，用于演示文稿或文档。

例如，你可以直接从 Google Drive 选择包含公司最新用户数据的 Google Sheet，让 ChatGPT 创建按用户群（cohort）展示的留存率图表。

这些新交互特性覆盖多种图表类型；对暂不支持交互的图表，ChatGPT 会生成静态版本。

## 全面的安全与隐私

和 ChatGPT 的任何功能一样，信任与数据隐私是 OpenAI 使命的核心。我们不会使用 ChatGPT [Team](https://chatgpt.com/business/business-plan) 和 [Enterprise](https://chatgpt.com/business/enterprise) 客户的数据训练，ChatGPT Plus 用户可以通过其 [数据控制](https://help.openai.com/en/articles/5722486-how-your-data-is-used-to-improve-model-performance) 选择退出训练。了解更多关于我们的 [隐私与安全政策⁠](https://openai.com/enterprise-privacy)，包括 ChatGPT Enterprise 的 SAML SSO、合规与数据加密。
