# 让更多可信赖的伙伴使用前沿网络安全模型

扩展Daybreak网络安全合作伙伴计划，弥合日益扩大的防御差距。

成为Daybreak合作伙伴


我们正将OpenAI的前沿网络安全模型带给保护全球各地组织的安全合作伙伴。我们携手将前沿智能直接融入防御人员已经依赖的产品、服务和安全运营。如今，更多组织能够发现严重漏洞、更快修复漏洞，并领先于以机器速度演进的威胁。

AI改变网络安全的速度，已经超过大多数组织的应对能力。攻击者能够以越来越快的速度和越来越大的规模识别漏洞、开发利用程序，并在复杂系统中横向移动。与此同时，安全团队所保护的软件和基础设施中存在越来越多的薄弱环节，他们必须对此加以应对。发现这些漏洞只是第一步。更难的挑战在于判断哪些漏洞构成真正的威胁，并在其遭到利用之前完成修复。仍有太多防御人员无法使用可帮助他们完成这项工作的前沿模型。

我们的Daybreak网络安全合作伙伴计划汇聚了领先的安全与服务合作伙伴，包括[Accenture](https://www.accenture.com/)、[IBM](https://www.ibm.com/)、[Capgemini](https://www.capgemini.com/about-us/technology-partners/openai/)、[Cognizant](https://www.cognizant.com/)、[EY](https://www.ey.com/)、[KPMG](https://kpmg.com/)、[PwC](https://www.pwc.com/)、[NCC Group](https://www.nccgroup.com/)和[SpecterOps](https://specterops.io/)；技术合作伙伴则包括[Palo Alto Networks](https://www.paloaltonetworks.com/)、[CrowdStrike](https://www.crowdstrike.com/)、[Cisco](https://www.cisco.com/)、[Sophos](https://www.sophos.com/)、[Akamai](https://www.akamai.com/)、[Fortinet](https://www.fortinet.com/)和[Cloudflare](https://www.cloudflare.com/)。这些合作伙伴拥有深厚的安全专业知识，并与世界各地的组织建立了稳固的合作关系。通过将我们的前沿网络安全模型融入其服务，我们可以帮助更多防御人员发现严重漏洞、验证哪些漏洞真正重要，并更快完成修复。

## 从发现漏洞到修复漏洞

一份漏洞报告并不能保护组织。真正的保护来自判断薄弱环节能否被实际利用、识别面临风险的系统、制定修复方案，并将修复部署到生产环境。

Daybreak网络安全合作伙伴将OpenAI最先进的网络安全模型融入其现有的客户保护工作。他们熟悉客户的系统，了解其安全团队的运作方式，并能帮助判断哪些漏洞真正重要以及应如何修复。

合作伙伴可根据项目需要，在复杂的企业系统中协助开展漏洞发现与验证、红队测试、渗透测试、事件响应和修复。

## 将前沿模型融入现有安全运营

大多数组织希望先进安全能力能够融入团队现有的工作方式，并与他们用来保护业务的平台、服务提供商和工作流程集成。

通过Daybreak网络安全合作伙伴计划，获批合作伙伴可以将OpenAI的前沿网络安全模型融入安全产品、托管服务和客户项目。

合作伙伴可以根据自身需求和具体工作，通过Daybreak Access使用Daybreak Blue或Daybreak Red。Daybreak Blue支持广泛的防御性安全工作流程，而Daybreak Red专为更专业且受到严格治理的工作而设计，包括红队测试和渗透测试。

这为组织提供了一种切实可行的方式，使其无需自行构建和运行专门的网络安全AI项目，也能受益于前沿网络安全模型。

## 扩大使用范围，配以相应保障措施

Daybreak网络安全合作伙伴在可信且受治理的项目中使用OpenAI的受控访问模型。根据具体工作，保障措施可包括身份验证、明确的测试范围、日志记录、监控和人工监督。

底层模型的访问权限始终由获批合作伙伴持有，不会直接转交给客户。合作伙伴与组织共同界定每个项目的边界、审查发现结果，并在采取行动前运用自身专业知识进行研判。

这种方式既能让更多组织获得先进的防御能力，也能保留敏感安全工作所需的监督机制。
