# 用 ChatGPT Work 处理运营工作流

探索业务运营团队如何用 ChatGPT Work，把分散的项目背景、指标、跟踪表和干系人输入，变成可用于决策的简报、更新、决策包和权衡模型。

业务运营工作往往散落在项目跟踪表、KPI 仪表盘、规划文档、会议纪要、Slack 消息串、电子表格和高管需求之间。ChatGPT Work 帮助把这些上下文汇聚起来，并产出交付物的首个可用版本：一份偏离轨道的简报、战略项目进展更新、领导层决策包、进度汇报或情景模型。判断和建议仍由你的团队负责；ChatGPT Work 帮助工作草稿更快地送达对的人手中。
