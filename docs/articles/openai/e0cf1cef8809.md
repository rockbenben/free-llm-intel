# 通过学习深度逆动力学模型实现从模拟到现实的迁移（Transfer from simulation to real world through learning deep inverse dynamics model）

阅读论文

## 摘要

在模拟中开发控制策略，通常比在现实世界中直接开展实验更实际、更安全。这对由规划和优化得到的策略适用，对由强化学习得到的策略更是如此——后者往往极其耗费数据。然而，一个在模拟中成功的策略，部署到真实机器人上时常常行不通。尽管如此，该策略在模拟中所做之事的整体要旨，在现实世界里往往仍然成立。本文研究这样一类情境：模拟中所经历的状态序列对现实世界而言仍然合理，即便控制的细节并不合理——当关键差异在于细节层面的摩擦、接触、质量和几何属性时就可能是这样。在执行期间，每一步我们的方法都会计算那个基于模拟的控制策略本会做什么，但不把这些控制直接执行到真实机器人上，而是计算模拟所预期得到的下一状态会是什么，随后依赖一个学习到的深度逆动力学模型来决定哪一个真实世界的动作最适合达成那些下一状态。深度模型的好坏取决于它的训练数据，因此我们还提出了一种数据收集方法来（增量地）学习深度逆动力学模型。我们的实验表明，我们的方法相比于为应对模拟与现实之间模型不一致而开发的多种基线——包括输出误差控制和高斯动力学自适应——表现出更有优势的结果。
