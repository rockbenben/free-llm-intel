# “垃圾邮件叔叔”行动：加剧美国两极分化的影响活动

OpenAI 封禁了源自中国、利用 AI 生成美国政治内容并研究个人、社会运动和网络社区的账号。

正在加载…

*本案例研究最初发布于 OpenAI 的*[*2025 年 6 月*⁠（在新窗口中打开）](https://cdn.openai.com/threat-intelligence-reports/5f73af09-a3a3-4a55-992e-069237681620/disrupting-malicious-uses-of-ai-june-2025.pdf)*报告。*

## 行动方

在 Meta 同行提供线索后，我们封禁了多个与[源自中国的影响行动⁠（在新窗口中打开）](https://about.fb.com/wp-content/uploads/2022/11/CIB-Report_-China-Russia-Sept-2022.pdf)有关的 ChatGPT 账号。该行动生成了立场两极分化的社交媒体内容，为美国政治话语中争议议题的对立双方造势，其中包括发布在 X、Bluesky 等平台上的文本和 AI 生成的头像。

## 行为

该网络使用我们的模型执行多项任务，主要是生成支持或批评关税的社交媒体评论。这些账号询问我们的模型何时发帖最能提升受众互动，表明其采取了精心策划的放大传播策略。

*该威胁行为方使用我们的模型生成了这两条推文的文字，分别为关税争论的双方造势。*

其次，这些账号利用我们的图像生成能力制作风格化标志，并将其用作社交平台上的头像，为虚构身份提供包装。这些账号尤其注重塑造批评美国现政府的美国退伍军人形象。

*发布该网络生成内容的 Bluesky 账号。“正义退伍军人”标志使用我们的模型生成。*

最后，这些账号持续索要代码和方法，以使用 Tweepy、Nitter 和 Bluesky 公共 API 等工具，从 X、Bluesky 等社交平台提取用户资料、关注者列表及其他个人数据。此外，这些账号还使用我们的模型获取指导，以便分析个人资料中的个人特征和组织关系，可能用于对个人进行分类，或推断其关联和属性。

## 生成内容

这些账号围绕美国政治话语生成了两极分化的内容，而且往往是在同一批行动会话中生成。这与影响行动的已知手法一致，其目的很可能是利用现有政治分歧，而非宣传特定的意识形态立场。鉴于内容数量之多，且重点面向美国受众，我们将这次行动命名为“垃圾邮件叔叔”。

*由虚构身份发布的推文，文字由我们的模型生成。*

## 影响

采用衡量影响行动（IO）影响力的[“突破量表”⁠（在新窗口中打开）](https://www.brookings.edu/articles/the-breakout-scale-measuring-the-impact-of-influence-operations/)，我们会将其评为第 2 类：活动遍及多个平台，但未形成突破性传播，或互动极少。发布由我们模型生成内容的社交媒体账号几乎没有获得真实用户的互动。该网络在 X 上发布的大多数帖子几乎没有获赞或转发，只有少数帖子获得了一些互动。部分社交媒体账号拥有数千名关注者，但我们无法评估这些关注者的真实性，而且关注者数量似乎并未转化为帖子互动。
