# 将 Codex 扩展至全球企业

OpenAI 推出 Codex Labs 并联手顶级系统集成商 (GSI)，旨在加速 Codex 在工程组织中的落地

联系我们

了解更多

4 月初，我们曾分享过每周有超过 300 万名开发者使用 Codex。仅仅两周后，这一数字已增长至超过 400 万。

除了个人用户的采用，我们还看到企业正迅速将 Codex 引入包括工程及其他领域的实际工作流中。

各家公司正将 Codex 应用于软件开发的整个生命周期。维珍航空 (Virgin Atlantic) 利用它来扩大测试覆盖率并提升团队开发速度，从而减少技术债并优化性能；Ramp 利用它来加速代码审查；Notion 利用它快速构建新功能；思科 (Cisco) 利用它来理解并推导大型互联代码代码仓库中的逻辑；乐天 (Rakuten) 则将其用于事故响应等场景。一旦领导层看到团队在速度、产出和杠杆效应上的提升，Codex 的应用往往会从一个团队迅速扩展到整个公司。此外，Codex 的能力正[超越编程领域⁠（在新窗口中打开）](https://developers.openai.com/codex/use-cases?category=knowledge-work)，开始支持基于浏览器的任务、图像生成、记忆功能，以及跨工具和应用程序的协作。

这种势头正开始向工程之外的领域延伸。各团队正利用 Codex 整合不同工具的信息背景，梳理关键点，将碎片化的信息转化为实用的工作成果（如简报、计划、检查清单、草稿及后续跟进事项），并据此采取行动。这为企业创造了更大的机遇，帮助每一个团队（而不仅仅是编写代码的团队）提升运转效率。

我们希望帮助更多企业实现这一目标。

## 推出 Codex Labs

正因如此，我们决定推出 [Codex Labs](https://openai.com/form/codex-labs/)。

Codex Labs 旨在让 OpenAI 的专家直接进入组织内部，帮助团队利用 Codex 解决实际问题。通过实战工作坊和研讨会，企业组织可以了解 Codex 的适用场景、如何将其集成到现有工作流中，以及如何从早期尝试转向可复制的规模化部署。我们的目标很简单：帮助企业更快地从 Codex 中获得实际价值。

## 与合作伙伴共同扩展 Codex 的企业级应用

目前我们看到的市场需求，已经超过了我们直接帮助所有企业快速采用 Codex 的能力。因此，我们正与全球领先的系统集成商 (GSI) 合作，以扩大这一影响力。

这些公司深谙大型企业的运作之道。他们擅长软件交付的现代化改造、新系统的集成，可支持复杂组织内部的变革，并协助客户完成从试点到正式投产的跨越。

目前，我们的合作伙伴包括：埃森哲 (Accenture)、凯捷 (Capgemini)、CGI、高知特 (Cognizant)、印孚瑟斯 (Infosys)、普华永道 (PwC) 以及塔塔咨询服务 (TCS)。

这些合作伙伴将协助企业客户在软件开发的整个生命周期中，识别并部署高价值的 Codex 应用场景，实现从试点项目到生产级部署的转化。同时，他们也在内部使用 Codex，通过改变自身团队的运作方式，总结出可复用的经验，从而更好地将 Codex 带给客户。

## 开始使用

如需将 Codex Lab 引入贵组织，[请填写此意向表](https://openai.com/form/codex-labs/)，或联系 OpenAI 团队以了解更多详情。你也可以[下载应用](https://openai.com/codex/)，开启 Codex 体验。

## 未来展望

Codex 正在成为企业构建软件和运行生产环境工作负载的一部分。我们渴望帮助更多组织将其投入实际应用，并非常期待与合作伙伴共同在全球范围内扩大这项工作的规模。
