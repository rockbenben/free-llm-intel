# 变分有损自编码器

## 摘要

表示学习旨在把观测数据的某些方面，以适合下游任务（如分类）的形式呈现于学到的表示中。例如，对 2D 图像的好表示也许只描述全局结构，而丢弃细节纹理的信息。在本文中，我们提出一种简单但有原则支撑的方法来学习这样的全局表示：将变分自编码器（VAE）与 RNN、MADE、PixelRNN/CNN 等神经自回归模型结合。我们提出的 VAE 模型让我们能控制全局潜编码可以学到什么；通过相应地设计架构，我们可以强制全局潜编码丢弃无关信息（如 2D 图像中的纹理），从而 VAE 只以有损方式“自编码”数据。此外，通过利用自回归模型同时充当先验分布 p(z) 和解码分布 p(x|z)，我们能大幅提升 VAE 的生成建模表现，在 MNIST、OMNIGLOT 和 Caltech-101 Silhouettes 密度估计任务上取得新的业界最优结果。
