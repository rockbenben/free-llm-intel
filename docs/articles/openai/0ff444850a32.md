# OpenAI 模型、Codex 和托管智能体上线 AWS

今天，OpenAI 与 AWS 正在扩大双方的战略合作，帮助企业在其 AWS 环境中利用 OpenAI 的能力进行构建。我们很高兴为 AWS 客户提供对顶尖前沿模型、智能体和工具的访问，这些能力可在他们现有使用的系统、安全协议、合规要求和工作流中运行。

此次与 Amazon 扩大的合作涵盖三个关键领域，均于今天以限量预览形式推出：

- AWS 上的 OpenAI 模型
- AWS 上的 Codex
- 由 OpenAI 提供支持的 Amazon Bedrock 托管智能体

这些能力共同为组织提供了更多方式，可在应用开发、软件工程和智能体工作流中使用 OpenAI，同时仍在他们已在 AWS 上使用的基础设施、安全、治理和采购工作流内进行构建。

## 让 AWS 客户能够使用 OpenAI 模型和 API

对许多公司而言，要大规模使用 AI，就需要将最优秀的模型引入其团队已经使用的系统中。这就是为什么我们要在 Amazon Bedrock 上推出 OpenAI 模型，包括我们最强的前沿模型 GPT‑5.5。

客户现在可以在 AWS 中使用 OpenAI 模型进行构建，同时结合他们已依赖的服务、安全控制、身份系统和采购流程。

对开发者而言，这意味着他们在利用 OpenAI 构建时拥有更大的灵活性，无论是开发新的 AI 应用、将智能嵌入现有产品，还是构建能够推理、采取行动并支持更复杂业务流程的智能体工作流。

对企业而言，这意味着从实验到生产有了一条清晰且统一的路径，因为 OpenAI 的能力现已可在其最重要工作负载已经运行的 AWS 环境中获得。

## 将 Codex 引入 AWS

如今，每周有超过 400 万人使用 Codex，团队在整个软件开发生命周期中使用它 — 编写代码、解释系统、重构应用、生成测试、现代化改造遗留代码库，并加速一系列超越编码本身的专业工作流。越来越多的团队还通过连接他们每天使用的应用和工具来使用 Codex，以加速研究、分析和基于文档的工作，从总结源材料到创建简报、幻灯片和电子表格。

Codex 是 OpenAI 的前沿编码运行框架 (harness) 和产品套件，而现在，组织可以通过由 Amazon Bedrock 直接提供的 OpenAI 模型来驱动 Codex。这使任何拥有 AWS 消费承诺并可访问 Bedrock 的公司，都能顺畅地开始使用 OpenAI 强大的编码智能体和产品。

客户只需将 Codex 配置为使用 Bedrock 作为提供方即可开始使用。这为客户带来了他们所期待的 AWS 企业级特性 — 包括安全性、计费和高可用性。所有客户数据均由 Amazon Bedrock 处理，符合条件的客户还可将 Codex 使用量计入其 AWS 云承诺。

Bedrock 上的 Codex 现已提供限量预览。客户可通过 Bedrock API 将 Codex 配置为使用 Amazon Bedrock，首先支持 Codex CLI、Codex 桌面应用和 Visual Studio Code 扩展。

## 推出由 OpenAI 提供支持的 Amazon Bedrock 托管智能体

我们还将推出由 OpenAI 提供支持的 [Amazon Bedrock 托管智能体](https://aws.amazon.com/bedrock/managed-agents-openai/)，为企业在其可信赖的 AWS 环境中部署高级智能体提供一种新方式。

借助 Bedrock 托管智能体，组织可以构建能够保持上下文、执行多步骤工作流、使用工具并在复杂业务流程中采取行动的智能体。这有助于客户更快地从实验走向生产，同时让智能体开发与他们对 AWS 所期待的基础设施、安全和运营标准保持一致。

对企业而言，Bedrock 托管智能体让团队能够专注于让智能体真正服务于实际工作，而不是围绕它们组装基础设施。它能够处理部署、工具使用、编排和治理中更复杂的部分，并内置与 Amazon 安全和合规控制的集成。因此，能够在真实企业环境中运行的智能体，从原型到生产的路径将更快实现。

## 拓展企业利用 AI 进行构建的方式

我们与 Amazon 的战略合作重点在于帮助组织以生产级规模部署先进 AI。随着 OpenAI 模型、Codex 和托管智能体现已登陆 Amazon Bedrock，客户能够以更快、更安全的路径让 AI 在整个业务中发挥作用。我们很期待看到贵组织构建的成果。
