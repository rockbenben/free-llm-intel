# 更快的 Python 物理仿真

我们开源了一个基于 MuJoCo 引擎、面向机器人仿真的高性能 Python 库，它是我们过去一年机器人研究的成果。

本库是我们深度学习[机器人研究](https://blog.openai.com/robots-that-learn/)的核心工具之一，现以 [mujoco-py](https://github.com/openai/mujoco-py)（我们为 MuJoCo 提供的 Python 3 绑定）的重大版本形式发布。mujoco-py [1.50.1.0](https://github.com/openai/mujoco-py/releases) 带来了一系列新能力和显著的性能提升。新特性包括：

- 高效处理并行仿真
- GPU 加速的无头（headless）3D 渲染
- 直接访问 MuJoCo 函数与数据结构
- 支持全部 [MuJoCo 1.50 特性](https://www.mujoco.org/changelist.html)，例如其改进的接触求解器

## 批量仿真

轨迹优化与强化学习中的许多方法（如 [LQR](https://en.wikipedia.org/wiki/Linear%E2%80%93quadratic_regulator)、[PI2](http://www.jmlr.org/papers/v11/theodorou10a.html) 和 [TRPO](https://arxiv.org/abs/1502.05477)）都能从并行运行多个仿真中受益。mujoco-py 借助 [OpenMP](http://www.openmp.org/) 实现数据并行，并借助 [Cython](http://cython.org/) 和 [NumPy](http://www.numpy.org/) 实现直接内存访问管理，从而让批量仿真更高效。

对新版本 [MjSimPool](https://github.com/openai/mujoco-py/blob/master/mujoco_py/mjsimpool.pyx) 接口的[朴素用法](https://gist.github.com/jonasschneider/d8bacaec035b99c7f303aafa4f67a0f3)，相比旧版可获得 400% 的加速；相比一种使用 Python [multiprocessing 包](https://docs.python.org/3/library/multiprocessing.html) 达到同等并行度的、经过优化且受限的使用模式，仍有约 180% 的加速。大部分加速来自对各类 MuJoCo 数据结构访问时间的缩短。可参阅 `[examples/simpool.py](https://github.com/openai/mujoco-py/blob/master/examples/simpool.py)` 了解 MjSimPool 的使用导览。

## 高性能纹理随机化

我们在 OpenAI 的许多项目中使用[域随机化（domain randomization）](https://arxiv.org/abs/1703.06907)技术。最新版 mujoco-py 支持无头 GPU 渲染；与基于 CPU 的渲染相比可获得约 40 倍加速，让我们每秒能生成数百帧合成图像数据。在上面这段（放慢了的）动画中，我们用这项技术改变我们某个机器人的纹理，帮助它在从仿真迁移到真实世界时识别自己的身体。随机化纹理生成的示例可参见 [examples/disco_fetch.py](https://github.com/openai/mujoco-py/blob/master/examples/disco_fetch.py)。

## 用 mujoco-py 玩转虚拟现实

mujoco-py 暴露的 API 足以在不写任何额外 C++ 代码的情况下实现虚拟现实交互。我们用 mujoco-py 将 MuJoCo 的 [C++ VR 示例](https://www.mujoco.org/book/programming.html#saVive)移植成了 Python。如果你有 HTC Vive VR 设备，可以用[这个示例](https://github.com/openai/mujoco-py/blob/master/examples/mjvive.py)试用（该支持被视为实验性质，但我们内部已使用了一段时间）。

## API 与用法

上手 mujoco-py 最简单的方式是使用 [MjSim 类](https://github.com/openai/mujoco-py/blob/master/mujoco_py/mjsim.pyx)。它是对仿真模型与数据的封装，让你可以轻松推进仿真步、并从相机传感器渲染图像。下面是一个简单示例：

#### Python

```
1from mujoco_py import load_model_from_path, MjSim23model = load_model_from_path("xmls/tosser.xml")  45sim = MjSim(model)6sim.step()7print(sim.data.qpos)8# => [ -1.074e-05   1.043e-04  -3.923e-05   0.000e+00   0.000e+00]
```

对于高级用户，我们提供了多个更底层的接口，可直接访问 MuJoCo C 结构体与函数的内部。更多细节参阅 [README](https://github.com/openai/mujoco-py/blob/master/README.md)和[完整文档](https://openai.github.io/mujoco-py/build/html/index.html)。
