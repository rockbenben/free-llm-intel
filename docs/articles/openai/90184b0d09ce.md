# 测试针对未知对手的鲁棒性

Read paper






我们开发了一种方法，用于评估神经网络分类器能否可靠防御训练时未见过的对抗攻击。我们的方法产出一个新指标——UAR（Unforeseen Attack Robustness，未知攻击鲁棒性），用来评估单个模型对未预料攻击的鲁棒性，并凸显出必须在更多样的未知攻击上度量性能的必要性。

现代神经网络在众多基准任务上达到了很高准确率。但它们仍然容易被[*对抗样本*⁠](https://openai.com/index/adversarial-example-research/)攻破——那是对手为了骗过网络而对输入做的微小但精心设计的畸变。例如下面这个带 L∞ L_\infty L∞​ 畸变的对抗样本，与原图相比每个 RGB 像素值最多差 32；人类仍能分类这张改动后的图，但标准神经网络会以很高的置信度分错。

由不同畸变类型的对抗攻击生成的样本图（黑天鹅）。每种畸变都以骗过网络为优化目标。


部署在真实世界的 AI 系统需要对未知攻击保持鲁棒，但迄今多数防御只针对特定的已知攻击类型。该领域在加固模型抵御这类攻击上确有进展；然而，对一种畸变的鲁棒性[往往](https://arxiv.org/abs/1712.02779)[不能](https://arxiv.org/abs/1709.04114)[迁移](https://arxiv.org/abs/1903.10484)[到](https://arxiv.org/abs/1902.08265)[对模型设计者未知的攻击的鲁棒性上](https://arxiv.org/abs/1904.13000)。因此，只针对单一畸变类型做评估，会让人对真实世界中的模型产生虚假安全感——它可能依然容易被[假眼镜](https://dl.acm.org/citation.cfm?id=2978392) 和[对抗贴纸](https://arxiv.org/abs/1712.09665) 这类未知攻击所伤。

一个对抗鲁棒性迁移不佳的例子。起初，针对畸变 A 加固会同时提升对畸变 A 和 B 的鲁棒性。但随着进一步加固，对畸变 B 的对抗鲁棒性被损害，而对畸变 A 基本持平；（A = _L_∞​，B = _L_1​）。模型对畸变 A 的准确率在加固等级 8 处达到峰值，因为那已足以防御该攻击，继续加固反而伤害干净数据准确率；细节见完整论文。

## 方法原则

我们创建了一个三步法，评估模型对一种新的保留畸变类型的表现。我们的方法在多种畸变幅度上针对多样的未知攻击做评估，并把结果与一个知晓畸变类型的强防御做对比。它还产出一个新指标 UAR，评估模型对未知畸变类型的对抗鲁棒性。

### 1. 针对多样的未知畸变类型做评估

典型的对抗防御论文只对广泛研究的 L∞ L_\infty L∞​ 或 L2 L_2 L2​ 畸变类型做评估。然而我们[证明](http://arxiv.org/abs/1908.08016)，在这两种畸变上评估得到的对抗鲁棒性信息高度相似。[A](https://openai.com/index/testing-robustness/#citation-bottom-A) 我们得出的结论是：仅用 Lp L_p Lp​​ 畸变做评估，不足以预测对其他畸变类型的对抗鲁棒性。我们建议研究者用与训练中用到的不相似的对抗畸变来评估模型。我们提供 L1 L_1 L1​、L2 L_2 L2​-JPEG、Elastic（弹性变换）和 Fog（雾）攻击作为起点。我们的[代码包](https://github.com/ddkang/advex-uar) 提供了多种攻击的实现、预训练模型和校准。

### 2. 选择经过强模型校准的宽畸变幅度范围

我们发现，畸变幅度范围选得太窄会反转关于对抗鲁棒性的定性结论。选择范围时，我们观察同一攻击在不同畸变幅度下生成的图像，选取人仍能识别的最大范围。但如下图所示，拥有大畸变预算的攻击只会把预算用在强防御上。我们建议通过对抗训练过的模型来选一个经过校准的畸变幅度范围（我们的[代码包](https://github.com/ddkang/advex-uar) 也为大量攻击提供了校准好的幅度）。

对同一强攻击作用于不同防御模型的样本图（espresso maker）。攻击越强的防御，造成的视觉畸变越大。

### 3. 以对抗训练模型为基准度量对抗鲁棒性

我们开发了新指标 UAR，把模型对抗某种攻击的鲁棒性与针对该攻击的对抗训练做比较。对抗训练是一种强防御，通过在受对抗攻击的图像上训练来利用对对手的了解。[B](https://openai.com/index/testing-robustness/#citation-bottom-B) 面对未知的对抗攻击，UAR 接近 100 意味着表现可以比肩事先知晓该攻击的防御——这是个很有挑战的目标。

我们计算了对抗训练模型在若干不同畸变类型上的 UAR 分数。如下图所示，对抗训练带来的鲁棒性并不能广泛迁移到未知畸变上。事实上，对已知畸变的鲁棒性甚至可能降低对未知畸变的鲁棒性。这些结果凸显了必须针对 Elastic、Fog、Gabor、Snow 等多样性显著更高的攻击做评估。
