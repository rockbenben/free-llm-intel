# 鲁棒分类的计算局限与双赢结果

## 摘要

我们延续对"学习鲁棒分类器中统计/计算权衡"的研究，此前 Bubeck、Lee、Price 和 Razenshteyn 的工作给出了一些分类任务的例子，在这些任务中：(a) 小扰动范围内存在高效的鲁棒分类器；(b) 非鲁棒分类器可以被高效学习；但 (c) 在大数分解难题假设下，学习鲁棒分类器在计算上是困难的。而在大扰动范围内，他们的任务是否存在鲁棒分类器，似乎与计算数论中的重要开放问题相关。本工作从三个方向扩展了他们的成果。

第一，我们展示了这样一些分类任务：即使存在计算无界的鲁棒分类器，计算上高效的鲁棒分类也不可能实现。为此我们依赖平均情况困难函数的存在性。

第二，我们展示了大扰动范围内难以鲁棒学习的分类任务。即：虽然存在对大扰动鲁棒的高效分类器，学习任何非平凡的鲁棒分类器在计算上都是困难的。我们的第一个构造依赖单向函数的存在，第二个依赖"带噪声学习奇偶问题"（LPN）的困难性。在后一设定中，不仅存在非鲁棒分类器，还存在一个高效算法——在获得多项式量训练样本后即可生成全新的带标签样本（即 Kearns 等人（1994）所称的"生成"）。

第三，我们证明任何这样的反例都蕴含某些密码学原语（如单向函数）的存在。由此得到一个双赢场景：要么我们能学会一个高效的鲁棒分类器，要么我们能构造新的密码学原语实例。
