# 用 ChatGPT Work 处理日常工作

了解团队如何借助 ChatGPT Work，把日常工作的输入变成可审阅的简报、摘要、演示文稿、工作簿、计划和流程文档。

当工作背后已经有真实上下文时——日历、消息、邮件、文档、仪表盘、电子表格、跟踪表、演示文稿和讨论历史——ChatGPT Work 最能发挥价值。不要从空白提示词开始，而是把工作流中团队已在使用的材料交给 Work agent，请它产出成果的第一个可用版本。那可能是一份每日简报、每周更新、决策备忘录、发布工具包、财务复盘，或一份团队可以检查、编辑并直接投入使用的流程审计。

可[在此](https://learn.chatgpt.com/docs/get-started-with-work)了解如何开始使用 ChatGPT Work。
