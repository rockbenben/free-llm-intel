Ted Taylor 在半导体行业干了 25 年后进入餐饮业。如今他是一名独立特许经营商，在新墨西哥州经营三家 Schlotzsky's 与 Cinnabon 合牌餐厅。

经营快餐餐厅，意味着要在顾客体验和大量顾客看不见的活儿之间找平衡，比如菜单定价、人员排布、设备维护和规章制度。Ted 用 OpenAI 的技术把这些都做得更快。

用 ChatGPT，Ted 给调研和起草这类耗时任务提速；他用 ChatGPT Work 汇集并分析定价、销售、预测、排班和用工方面的大量数据，并请它给出每家餐厅需要在哪里投入精力的建议，由此把重新定价的时间缩短 95%，每次薪资处理省下 4 小时。

> “ChatGPT Work 的建议好到，先从它开始、再作调整要快得多。”

—Ted Taylor，独立特许经营商，Schlotzsky's 与 Cinnabon

## 几分钟给三个市场的菜单重新定价

菜单重新定价是一年一度的工程，要综合考量配方成本、单品热度、本地竞对定价、份量，以及堂食与外卖订单不同的经济账。Ted 用 ChatGPT Work 把这些因素收到一起，在 1 - 2 小时内拿到定价建议，而不是过去花 5 天。

> “过去我要花几天功夫去分析、给出单品级的定价；而 ChatGPT Work 转眼就吃透了，而且做得更彻底。”

—Ted Taylor，独立特许经营商，Schlotzsky's 与 Cinnabon

Ted 先让 ChatGPT Work 依据本地竞对的价格走势、份量和相对的餐品质量做调研，定出定价目标和定价策略。接着他交给 ChatGPT Work 一份分类整理好的菜单项清单，上面有各单品当前的堂食价和外卖价。他会说明每组价格整体希望涨多少、哪些单品该涨得多些或少些，主要依据此前 ChatGPT 给出的分析。

加上单品级的销售历史和供应商价格后，他还能把分析做得更细。ChatGPT Work 可以用这些输入来估算调价对销售的影响，并围绕货品成本目标优化单品定价。

ChatGPT Work 返回一张电子表格，给出建议的堂食价和外卖价。它甚至会把这次调价和一套整体定价策略联系起来，而这套策略旨在优化顾客留存、把价格冲击降到最低、以及把加购项放到最佳位置这些经营结果。

Ted 第一次用 ChatGPT Work 做定价时，同时也手工跑了一遍分析。“ChatGPT Work 做了更深一层的本地比对，帮我避开了一些会让个别单品失去竞争力的涨价，”他说。Ted 当即改成用 ChatGPT 来产出第一批建议。

## 寻找优化用工、腾出现金流的办法

Ted 用 ChatGPT Work 从两个方面帮他管理用工成本：复盘三家餐厅的用工走势，以及试一种更好的周排班做法。

做用工分析时，Ted 给 ChatGPT Work 开了销售与用工数据的只读权限。他每次跑分析，它就把排班工时、预算工时和实际工时，与预测销售和实际销售放在一起比对。它还会复盘过去 12 周，以照顾那些总是高于或低于自己销售预测的门店。生成的报告会标出加班、比计划更长的班次和排班空缺，并指出经理该复核什么。

在排班试验里，Ted 给 ChatGPT Work 一份员工名册，写明每个人的岗位、培训、可排班时间和薪资，再附上门店在不同销售水平下的人力需求。他和那位经理把 ChatGPT Work 提出的班表与她原本会排的班表做比较，找出了缺失的规则——比如高峰期什么时候该加人——并据此打磨了给 ChatGPT Work 的指令。

ChatGPT Work 现在能为那家门店产出完整班表。经理通读检查，必要时调整，再录入餐厅的排班系统。Ted 估计，排班做得更好，最终能让三家餐厅的小时工成本下降相当于销售额一到两个百分点，也就是每年多腾出 $50,000 到 $100,000 的自由现金流，可以用来提高薪资、发奖金、投入经营，或增加利润分成。

## 用 ChatGPT Work 加速后台任务

Ted 也把 ChatGPT Work 用在日常运营上，从制定人事制度，到现金对账，再到管理物料与维修申请。

新墨西哥州开始要求餐厅就体液污染事件留有书面处置流程时，Ted 用 ChatGPT 大约 30 秒就写出一份草案。他需要为员工手册配一份社交媒体政策时，ChatGPT 帮他很快起草了指引，后来一家外部人事公司审阅过，一个字都没改。

Ted 每月用 ChatGPT Work 对他三家餐厅的现金做对账。他上传每家门店的现金交易数据和银行记录，ChatGPT Work 就把逐笔交易和对应的存款相比较。月度对账过去要三个小时，现在只要 5-10 分钟。他还用 ChatGPT Work 汇总薪资输入，从每个薪资周期里砍掉了 4 个小时的手工活。

为了让餐厅运转更顺，Ted 还用 ChatGPT Work 搭了一个网页门户，员工可以在里面申领物料或报修。门户通过一个专门的邮箱通知他，并跟踪每条申请的进度。

## 有更多时间改进生意，而不只是让它转下去

Ted 用 ChatGPT Work 的办法，对任何小企业主都实用。他把自己做决策时会用的数据和准则同样交给 ChatGPT，再把它给出的结果与自己动手会怎么做做个比较。随着对结果越来越有信心，他把用法扩展到业务周围更多的任务上，但每一条都在落地前先复核结果。

对 Ted 来说，ChatGPT Work 的价值不止于省下的工时。他现在能去做那些本来可能跳过的分析，也能把更多时间花在顾客、员工和把生意做大上。
