# 用 ChatGPT 分析数据

在 ChatGPT、Excel 或 Google Sheets 中探索、分析数据，并把数据变成清晰的洞察与行动。

ChatGPT 能以极低的准备成本帮你从原始数据走到有用的洞察。你可以直接在 ChatGPT 中上传 CSV 或 Excel 文件、粘贴一张表格，或连接数据源（如果你的工作区支持），然后用朴素的语言开始提问。如果你的工作区设置允许，你还可以在 Excel 和 Google Sheets 之内使用 ChatGPT。

不必为每个问题都构建公式、数据透视表或仪表盘——你可以快速探索数据、整理表格、生成简单可视化，并以易于分享的格式提炼关键结论。它在流程早期尤其有用——当你还在弄清楚数据里有什么、识别异常、决定往哪里深挖时。它还能把发现转译成他人可以审阅和据此行动的摘要。

## 在 ChatGPT 中直接做数据分析

- 从你要支持的决策开始。一个简单的框架是：*“我正在基于 ___ 来决定 ___。”* 这会告诉 ChatGPT“完成”是什么样子，让分析保持聚焦。
- 提供你的数据以及关键上下文——定义、时间范围，以及各重要列的含义。你可以通过**文件上传**或使用**已连接的应用**来提供数据。
- 要求一个方法，而不只是答案。例如，先要求一份探索性数据分析（EDA）摘要，再给出待验证的假设。这比直接跳到结论能带来更结构化、更可靠的结果。
- 如果可视化有帮助，明确提出来——画什么、如何分组，以及坐标轴标签或单位等必须有的元素。
- 要求可复用的输出，比如一张干净的最终表格，或一份把发现转成行动的简短高管摘要。

| **任务** | **上下文** | **期望输出** |
| --- | --- | --- |
| 分析这些数据并总结关键洞察。 | 使用我们 Shopify 店铺最近 30 天的样本数据集。 | 提供一份结构化的关键洞察摘要，包括各渠道和产品中突出的表现、表现不佳领域的识别（如低转化的渠道）以及值得注意的模式。包含 4–6 条按优先级排列的观察，以及下一步要调查的 5 个具体后续分析或问题。 |
| 审阅并分析我们的销售漏斗数据。 | 使用来自 [活动名称] 的 [已连接分析应用] 的数据。 | 产出一组清晰分节的输出：(1) 漏斗中观察到的关键模式，(2) 解释这些模式的假设（如把新手引导视为主要驱动），(3) 推荐的实验或测试。洞察按业务影响排序，重点放在转化瓶颈和发力点上。 |
| 用数据识别流程中的问题或低效环节 | 审阅所附的当前流程文档以及客服工单数据 CSV。 | 输出一份按优先级排列的运营问题与瓶颈清单（如升级延迟、重复工单驱动因素），每条都有数据信号支撑。包括每个问题为何重要的清晰推理，加上建议立即改进或调查的领域，并分为速赢与深层修复两组。 |

## 在 Excel 或 Google Sheets 中做数据分析

如果你的很多工作直接在电子表格里进行，[ChatGPT for Excel and Google Sheets](https://chatgpt.com/apps/spreadsheets/) 能让你不离开惯用工具就更快地构建、更新和理解这些工作。它位于工作簿内的侧边栏中，你可以用朴素的语言请求改动，并直接在表格中查看结果。可以把 ChatGPT for Excel 或 Google Sheets 理解为电子表格机制和初轮分析的“产品内协作者”。

请注意，要在 Excel 工作簿或 Google Sheet 中使用 ChatGPT，你还必须在该载体上启用插件。参见 [ChatGPT for Excel](https://help.openai.com/en/articles/20001063-chatgpt-for-excel-and-google-sheets#excel) 和 [ChatGPT for Google Sheets](https://help.openai.com/en/articles/20001063-chatgpt-for-excel-and-google-sheets#google-sheets) 的安装说明。

你的提示词把“要保留什么”描述得越好，结果就越好。实践中，当明确指定使用哪些工作表、哪些工作表不要改、想要什么输出，以及是否让 ChatGPT 在编辑前先解释其计划时，提示词效果最佳。

| **目标** | **提示词** |
| --- | --- |
| 整理一个工作簿 | “为高管审阅整理这个工作簿。统一标签和格式、去除重复项、尽可能修复损坏的公式，并准确总结你做了哪些改动。” |
| 理解模型逻辑 | “解释收入如何在这个模型中流向毛利和 EBITDA。指出关键的驱动单元格，并标出任何不寻常的假设。” |
| 更新假设 | “只更新 Inputs 工作表上的假设，不要更改格式。然后列出所有发生变化的下游工作表并总结影响。” |
| 构建 KPI 包 | “使用 Revenue、Opex 和 Headcount 工作表，为领导层构建一份月度 KPI 汇总，包括收入增长、毛利率、EBITDA 利润率，以及部门层面对计划的差异。” |
| 为审阅做准备 | “在编辑任何内容之前，先概述你的计划。告诉我你将修改哪些工作表、预计添加哪些公式，以及需要我确认的假设。” |

## 成功要点

- 帮 ChatGPT 帮你：提前说明“好”是什么样子——包括你关注哪个成功指标、看的时间范围，以及想比较哪些组或分层。
- 如果数字真的很重要，你也可以让它展示结论是怎么得出的——包括它做的假设、计算指标用的公式，以及对缺失数据或异常尖峰的快速检查。
- 定几条简单规则也有助于分析保持可信。例如，你可以告诉它不要把相关性当作因果、指出数据的任何局限、标出看起来不对劲的地方。在分享结果或做决定之前，做一次快速的现实检验——挑几个关键数字抽查核验，确保一切对得上。
