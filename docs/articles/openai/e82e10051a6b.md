# Ada 用 GPT-4 树立客户服务新标准

Ada 正在推动客户服务支出领域 [1000 亿美元级的转变](https://www.forbes.com/sites/louiscolumbus/2018/04/30/sizing-the-market-value-of-artificial-intelligence/?subId3=xid:fr1605104619702abi&sh=8ba4d26ffe97)，而站在这一转型前沿的，是其 AI 原生的客服自动化平台。[Ada](https://www.ada.cx/?utm_source=partner&utm_medium=referral&utm_campaign=openai-casestudy-2024) 成立于 2016 年，如今估值 12 亿美元、累计融资 2 亿美元；客户包括 Verizon、YETI、Canva 和 Square。

Ada 与 AI 结缘已久——自创立起就是 AI 原生平台。产品第一代建立在自研自训的定制自然语言处理（NLP）模型之上。但他们发现了一个落差：平台"能接住"的客户问题数量，与真正被满意"解决"的问题数量并不一致。

> "我们对 OpenAI 和行业正在发生的事感到非常兴奋。2022 年，我们决定全力投入，用 LLM 的推理能力重建产品。"
>
> —— Mike Gozzo，首席产品与技术官

## 定义一个客服新指标：解决率

客服行业的标准指标是"拦截率"（containment rate），衡量完全由聊天机器人处理、未转人工的客户咨询数量。理论上提高拦截率就能降低客服运营成本。但 Ada 团队发现了这个指标的问题。

"包括 Ada 在内的许多方案都能轻松做到 80%–100% 的拦截率，但如果你真的打开那些对话记录、读一读客户的体验，会发现质量相当差，"Gozzo 说。

把精力聚焦在对话实际解决得怎么样，Ada 团队确信他们能为客服行业树立新标准。

Ada 最初将 GPT-4 与其历史数据结合，构建了一套新的评估框架，能够评估对话被自动解决的程度。Ada 的系统按客户是否获得相关、准确、安全的回复（无需人工介入）为每段对话评分。"在测试中，我们的系统与人工阅读对话的一致性达到 80%–90%，"Gozzo 说。

## 实战检验模型，最终选择 OpenAI

理解了解决率之后，Ada 有了产品的北极星指标。除了用 OpenAI 的 API 做评估，他们还决定与 OpenAI 合作打造新一代 AI Agent。

Ada 此前就使用过 OpenAI 的模型，主要用来为 NLP 模型生成训练数据。在把 OpenAI 的 API 拿到新用例上实测时，Ada 注意到了若干差异化优势：

- **推理质量：** Ada 搭建了合成测试框架，模拟数十万终端客户与其系统对话，从而对模型的可扩展性与质量做压力测试。"我们定期评估每一个主流模型，通常在其发布后几周内，到目前为止还没有人在我们的评估集上超过 OpenAI，"Gozzo 说。
- **延迟：** 要为 Ada 的语音用例确保最佳表现，低延迟模型是关键。"在实时推理方面，GPT-4o 让延迟和整体质量都实现了大跃升，"Gozzo 说。
- **微调：** Ada 使用 OpenAI 的微调 API 输出给定回复中幻觉程度的置信分，并在工具链的其他环节使用该分数，把系统中的幻觉数量降到最低。"我们同样期待未来能用微调进一步提升系统的推理能力，以及这项技术让更小、更便宜的模型逼近前沿模型表现的潜力，"Gozzo 说。

## 借助 OpenAI，解决率翻倍

如今，Ada 的 AI Agent 采用多 agent 架构：一个中央规划 agent 加一组子 agent，全部由 OpenAI 的 API 驱动。"每当你要与一家使用 Ada 的企业沟通，你的问题都会经过 OpenAI 模型的多轮处理——理解、反思、调用工具、引入知识——直到生成答案，"Gozzo 解释道。

Ada 产品的上一版本拦截率为 70%，但解决率只有 30%。迁移到新系统的客户取得了相近的拦截效果，而解决率通常可达 60%，表现最好的客户超过 80%。

"从上一代技术到这一代，我们能在优质体验下自动解决的对话量翻了一番，"Gozzo 说。对 Ada 的客户而言，这个指标对 ROI 有巨大的下游影响，包括全职人力（FTE）节省、客户满意度、留存与新客签约。

*原因：* 机器人提供了无关链接，没有回应客户的问题。

*状态：* 已解决
*原因：* AI Agent 采取了恰当的行动，解决了客户咨询。

## 借助 AI，100% 解决是可以实现的

Ada 对自己解决客户问题的能力如此有信心，以至于把目标定为 100% 解决率——这在几年前还像是幻想。"现在，100% 解决是时间问题，而不是能不能的问题，"Gozzo 说。

市场也在转变——Ada 谈自动解决时几乎不再遇到怀疑。"企业越来越内行，"Gozzo 说，"他们认真思考 AI 战略，并主动把这类技术引入自己的运营。"客户可以像培训人类客服一样，对 Ada 基于 LLM 的 AI Agent 进行上手、度量与辅导。Ada 未来 12 个月的目标是大幅提升产品的透明度，并给客户更多可操控的调节杆。

这种可能性感是双向的。"与 OpenAI 合作相比，其他伙伴身上少见的一点，是这里纯粹的兴奋与好奇，"Gozzo 说，"团队里的每个人似乎都真心热衷于这件事。超越商业关系之外，我们在共同构建某样东西，这真的令人耳目一新。"
