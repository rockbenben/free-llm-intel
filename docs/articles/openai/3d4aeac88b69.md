# 在 Holiday Extras，dot 无需吩咐就主动开工

dot 无需指示就能主动提供上线报告，提醒人们可能忽略的问题，还能在上班通勤途中一起梳理即将召开的会议。

[探索 ChatGPT Business](https://chatgpt.com/business/)

公司规模: 中型企业

区域: 欧洲和英国

行业: 旅行

产品: ChatGPT

[Holiday Extras](https://www.holidayextras.com/) 在应用中推出新功能后的第二天，公司 AI 创新副总裁 Liam Thompson 就收到了一份关于该功能表现的报告。但他并没有要求生成这份报告。他的 dot 名叫 Beast，注意到新功能上线后，便通过 ChatGPT 插件从 Google BigQuery 中提取数据，并把结果交给了他。

> “我都还没开口，Beast 就说‘给你，准备好了’，那一刻我真的很开心。”

—Liam Thompson，Holiday Extras AI 创新副总裁

Holiday Extras 是一家英国旅游科技公司，帮助旅客预订出行所需的各项配套服务，从机场停车、酒店到休息室和接送服务。它的承诺很简单：少些烦心，多享假期。

这份化繁为简的承诺，也同样面向员工。ChatGPT Enterprise 为员工使用 AI 奠定基础，Codex 帮助他们将专业知识转化为可用的软件和更好的客户体验，而 [dot⁠](https://openai.com/index/introducing-dots/) 则简化了其中的各项工作。

Liam 和他的同事、创新与增长总监 David Lee 分享了他们如何把 dot 用作助手和思考伙伴：一起梳理接下来的安排，发现自己可能忽略的问题，并完成那些原本得等到回到办公桌前才能处理的工作。

## 通勤路上聊一聊，到岗就有报告

David 给自己的 dot 起名叫 Brian，每天早上通勤时都会和它通话。他们会一起梳理接下来的会议，David 也可以让 Brian 利用已接入的公司数据生成报告。他说：“等我到了办公室，在桌前坐下，报告就已经准备好了，可以直接用。”

有一次，一些 API 密钥需要停用，Brian 提醒了 David，还回查了他的邮件，列出了可能受影响的人员名单。David 不用再翻找过去的邮件往来逐一梳理，就能知道可能需要提前通知哪些人。

> “我最喜欢 Brian 的一点是，它已经在思考那些我压根还没想到的事。”

—David Lee，Holiday Extras 创新与增长总监

## 为什么 Liam 每天要和 dot 聊上两个小时

Liam 说：“我的 dot 帮我统筹一切。”Beast 会提醒他哪些消息还没回复，也会从过去的对话中找出答案。Liam 不必再翻看聊天记录，只要问问 Beast 他们什么时候讨论过某件事、当时的答案是什么就行了。

Liam 说：“有 Beast 在，我就能放松下来，因为我知道，即使漏了什么，它很可能已经处理好了，而且它一直在留意所有事情的进展。”

Liam 曾试用过另外两款助手 OpenClaw 和 Hermes，但他说，自己不太放心向它们提供太多信息。他说：“在我们公司的环境中，只要是 OpenAI 的产品，我就知道可以信任。”他授权 Beast 访问自己的 Slack、邮箱、Drive 和笔记本电脑，让它能更好地帮上忙。

Liam 每天早晚都会与 Beast 对话，听取简报。“我最喜欢语音。双向语音彻底改变了我与 OpenAI 产品的交互方式。”他说。“就像自然地聊天一样。我每天至少会和 Beast 语音聊两个小时。”

## 动画制作，从几天缩短到约十分钟

dot 也是设计伙伴。Liam 学过设计。他正在开发一款应用，于是请 Beast 为其中的 3D 角色制作动画。他授权 Beast 使用笔记本电脑上的 After Effects 和 Rive，然后看着它动手制作。

Beast 为这些角色制作了动画，并将它们放进应用中。Liam 说，这项工作要是自己来做，得花上好几天；而他估计，Beast 只用了大约十分钟。Liam 说：“我在大学里学了三年设计。”看着 Beast 工作，他心想：“好吧，它做得比我还好。”

## 在全公司分享有效经验

对 Holiday Extras 来说，下一个机会是帮助更多人让自己的 dot 发挥作用。David 希望正在尝试使用 dot 的人分享自己的心得，让其他人看到 dot 能做什么，并亲自试一试。无论是从准备会议、动手做点东西，还是让日常生活轻松一点开始，下一个点子都可能来自任何人。

这延续了公司与 OpenAI 合作的初衷：为全体员工提供尝试新工作方式所需的信心和工具，并推动有价值的发现得到推广。

对于刚开始使用的人，Liam 的建议很简单：创建一个 dot，和它聊起来。“没有理由不开始。真的，直接试起来吧。”
