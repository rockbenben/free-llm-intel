# OpenAI 参股 Thrive Holdings，加速企业采用 AI

正在加载…

OpenAI 和 Thrive Holdings 正在联手推动 AI 在企业中的加速采用。

Thrive Holdings 通过投资、并购和参与建设，布局一批有望在长期技术驱动转型中获益的企业。

OpenAI 和 Thrive Holdings 将携手合作，为企业核心运营带来既直接又可复制扩展的成效。最初的侧重点是会计和 IT 服务，因为这些职能运行高容量、规则驱动、流程繁重的工作流程，OpenAI 的平台可以在这些领域产生立竿见影的成效。

OpenAI 将在 Thrive Holdings 旗下公司内常驻研究、产品和工程团队，在强化服务质量的同时，提升交付速度、准确性和成本效率。这项合作将形成一套可复制的模式，并推广到更多行业。“AI 正在重塑企业的组织方式，以及企业为客户创造价值的方式，”OpenAI 的首席运营官 Brad Lightcap 说道，“通过与 Thrive Holdings 的合作，我们希望向外界展现：一旦将前沿 AI 研究与落地实践快速推广到整家企业，就有可能颠覆企业的运作方式和客户互动方式。”"我们希望这次合作能成为全球企业和行业与 OpenAI 深度合作的模型。”

Thrive Capital 和 Thrive Holdings 的首席执行官兼创始人 Joshua Kushner 表示：“我们很高兴能与 OpenAI 开展进一步合作，将其前沿模型、产品和服务嵌入到最有潜力通过技术创新和普及应用而受益匪浅的行业。”“历史经验表明，技术对行业的改造通常是自外而内发生的。”我们相信，这次变革将由内向外展开：当各领域专家和从业者将 AI 视为日常工作的基础工具时，他们就会从内部重塑自己的专业领域。我们收购的企业，构成了推动这种演进所需的合适回报机制 — 既汇聚了行业专业经验，又积累了真实世界数据，有助于提升模型在特定任务和能力上的表现。
