# AI 基础

了解 AI 的基本概念，包括它是什么、如何工作、如何被使用。

欢迎！如果你是 AI 新手，入门并不需要技术背景。最有帮助的是一张简单的领域地图——让你理解 AI 系统能做什么、它们如何被包装交付，以及如何根据你的需求选择合适的工具。

## 什么是 AI？

**人工智能（AI）**是一个广泛的软件类别，能够识别模式、从数据中学习并产出有用的结果。

你可能已经在日常场景中见过 AI，比如：

- 地图应用为你绕行拥堵重新规划路线
- 银行把一笔消费标记为"异常"
- 客服聊天机器人回答常见问题

AI 是一个类别——不是某个单一工具。在这个类别中有**模型（models）**：从数据中学习、再把所学应用到新情境中的训练完成的系统。有些模型专注于语音、视觉或预测。

你很可能是通过使用对话式 AI 工具（如 ChatGPT）开始你的 AI 之旅。ChatGPT 背后的模型专注于语言——它们被称为**大语言模型（large language models）**。

## 理解大语言模型如何工作

**大语言模型（LLM）**是专为处理语言而设计的模型。它从大量来自众多来源的文本中学习模式，从而能够以有用的方式生成和转换文本。LLM 并不像人那样"知道"事情，而是根据上下文预测最可能出现的下一段语言。随着时间推移，算力、训练方法和大规模数据集获取能力的进步，使得构建更大、更强的 LLM 成为可能。

OpenAI 和其他前沿研究实验室把这些模型作为其产品的核心来构建，然后通过面向用户的产品（如 ChatGPT 或 Codex）以及 API 提供它们；开发者可以利用这些 API 用自己的方式构建 AI 工具，或把 AI 集成进现有软件。

## 模型如何随时间演进

当这些研究实验室的模型完成训练并通过内部评估与安全测试后，就会作为新模型发布。当你听说某个 AI 模型被"训练"时，通常指的是**两个阶段**——可以想象成一个人先学习、再在工作中不断精进。

第一个阶段是**预训练（pre-training）**：模型从海量文本中学习通用模式，从而获得摘要、起草、翻译、解释等广泛技能。

这就像一位新员工花几周时间阅读一切能找到的资料——手册、优秀范例、过往项目、常见问题——直到理解这份工作的"轮廓"。

接着这位"员工"开始上手干活，一位"经理"对其进行辅导：说得更清楚、提出好的后续问题、把握合适的语气、遵守公司规范。这就是**后训练（post-training）**。这一阶段帮助模型更可靠地遵循指令、以有用的风格交流，并更好地处理棘手情况。

后训练也是重点做**安全检查**的阶段——通过训练减少有害输出、避开不应满足的请求，并在话题敏感或不确定时更谨慎地回应。

随着模型不断更新和训练，你可能会注意到语气或回复的变化。如果你想要一致的结果，请明确说明你的目标、受众、格式和约束——同时要预期在涉及安全或不确定性时模型会更加谨慎。

## 推理模型与非推理模型

不同的模型针对不同的权衡做了调优——比如速度、深度，以及对多步骤指令的遵循程度。有些模型被设计为在日常任务（起草、摘要、改写、头脑风暴）中快速、流畅地响应；另一些则被设计为在回答前花更多算力*思考*问题，这能提升在完成更困难、多步骤任务时的可靠性。

**非推理模型**（有时标注为 "Instant"）针对快速、流畅的输出做了优化。当任务比较直接、你主要想要推进速度时，它们是很好的默认选择：把笔记变成消息、润色措辞、生成备选方案或提取要点。

**推理模型**（有时标注为 "Thinking"）经过训练，更擅长深思熟虑、循序渐进地解决问题——比如规划、复杂分析、疑难调试，或带有约束和边界情况的决策。它们可能耗时更长，但通常更善于跟踪多个变量、避免浅层错误。

如果你刚入门，不必担心模型选择——ChatGPT 的默认体验设计为*自动切换*，让你专注于问题本身而不是设置。

随着时间推移，当你了解自己偏好什么（速度还是深度、快速草稿还是审慎分析）之后，可以开始尝试可选的控制项：例如大多数时候选择 **Auto**，在任务复杂或影响重大时切换到 **Thinking**。

## 小结

一个简单的层次结构如下：

- **AI** = 整个领域
- **模型** = 执行特定任务的训练完成的系统
- **大语言模型（LLM）** = 专注于理解和生成语言的模型，由 AI 研究实验室长期训练而来
- **ChatGPT** = 帮助你高效使用 LLM 的产品

建立这张图景后，你就可以接着学习如何用 ChatGPT 这类工具获得出色结果——先从如何与它对话、拿到你想要的结果学起。
