# Rakuten 将数据与 AI 结合，释放客户洞察与价值

乐天集团（Rakuten Group）拥有超过 18 亿名全球会员，在其涵盖电商、金融科技、数字内容和通信的 70 多项在线服务生态中互动。乐天同时以多种方式开展 B2B 业务：帮助超过 57,000 家日本商家向日本消费者线上销售；为国际市场上的大型企业提供电商和广告解决方案；以及建设和运营移动网络。

随着乐天不断为客户创造更多价值，数据的重要性怎么强调都不为过。这既包括乐天服务生态中海量的交易与行为数据，也包括保存在 PDF 或 Word 文档里的内部业务数据。"对我们来说，数据资产 *就是最重要的企业资产*，" 乐天集团 AI for Business 总经理 Yusuke Kaji 说。

借助 AI，乐天正在找到发挥这一资产价值的创新方式："我们相信，以 OpenAI 开发的模型为代表的 AI 模型，是放大我们在数据之上所能创造影响的途径，" Kaji 说。总部位于东京的乐天与 OpenAI 合作，正在为全世界的公司树立一个标杆：如何把安全与隐私放在最前面来推进生成式 AI 项目。

## 利用数据改善客户服务、购物体验与 B2B 咨询

乐天很快就用上了 OpenAI 的 API：他们从 GPT‑3.5 开始构建，甚至在 ChatGPT Enterprise 发布之前就为员工做出了自己的内部聊天机器人。

乐天的目标是成为一家 "AI 赋能公司"（AI empowerment company）。他们把 Code Interpreter 和 RAG（检索增强生成）与 OpenAI 的模型结合使用，从复杂的非结构化数据中理解和提取价值，成果以新的方式赋能了客户和企业：

- 过去，用户提交客服工单后要等几天才能得到回复。"把 OpenAI 的 API 与 RAG 用在我们的内部知识库上之后，我们现在可以自动回应用户并为他们提供帮助，" Kaji 说。这一创新大幅改善了响应时间和效率。
- 购物时很少有人有时间翻阅数百条用户评价，所以乐天正在开发一项提取关键话题、总结评价的功能。"这将让用户以远为结构化的方式获取和浏览信息，" Kaji 说。
- 知识检索对乐天的 B2B 业务影响也很大。乐天顾问如今正在用公司海量数据中的可执行洞察——如市场分析和销售趋势——赋能商家和企业。

## 把隐私与安全作为第一要务

生成式 AI 是新生的领域，日本也在探索政策问题。任何涉及大公司的事件，都可能让未来数年的创新裹足不前。"在日本，信任极其重要，" Kaji 说，"一旦失去，重建信任将花费非常漫长的时间。"

正因如此，乐天认为必须找到一个认真对待安全的伙伴。经过大量评估和彻底的尽职调查，他们选择了与 OpenAI 合作。

在持续探索用模型和数据创新的过程中，始终把隐私与安全置于一切之上。"在我们做的每件事里，我们都确保以最高标准设好护栏，保护我们的用户和客户，" Kaji 说。

## 与 OpenAI 一起抵达 AI 赋能

随着乐天继续基于 OpenAI 的 API 构建，他们对全新的实时语音和视觉能力感到兴奋。例如，他们可以基于只以音频形式存在的内部会议数据，生成会议行动项、邮件沟通和多语言翻译。乐天还看到机会，在其生态中构建更多对话式的 AI 体验。这一切又回到了数据：这些体验提供关于用户需求的更丰富的数据，进而催生更好的产品。

"点击和曝光只是用户偏好的代理指标。随着我们把 LLM 更深地融入用户体验，我们可以通过对话输入直接理解用户的痛点或偏好，" Kaji 说，"如果我们能好好捕获和管理这类新数据，就能提供更好的服务。"

乐天的信条是赋能个人与社会——而在 2024 年，他们无法想象没有 AI 还能实现目标。在乐天看来，AI 代表一种新的赋能层级，例如它可以帮助小微企业在数字世界中保持竞争力。"作为全球创新领导者，我们把拥抱 AI 视为自己的责任，目标是创造一个更美好、更乐观的未来。OpenAI 一直是这段旅程中理想的伙伴，" Kaji 说。
