# 教会模型用语言表达不确定性





## 摘要

我们展示：GPT-3 模型可以学会用自然语言表达对自己答案的不确定性——无需使用模型 logits。给定一个问题，模型会同时给出答案和一个置信水平（例如"90% 置信"或"高置信"）。这些水平映射到经过良好校准的概率。该模型在分布偏移下仍保持中等程度的校准，并对其自身答案的不确定性敏感，而不是模仿人类的示例。据我们所知，这是模型首次被证明能用自然语言表达对自身答案的、经过校准的不确定性。为了测试校准，我们引入了 CalibratedMath 任务集。我们把用语言表达的不确定性（"言语化概率"）的校准与从模型 logits 中提取的不确定性做了比较。两类不确定性都能在分布偏移下泛化其校准。我们还提供了证据，说明 GPT-3 泛化校准的能力依赖于预训练潜表征——这些表征与其答案的认知不确定性存在相关性。
