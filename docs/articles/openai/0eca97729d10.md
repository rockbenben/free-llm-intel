# GPT‑5 与智能工作新时代


今天，我们隆重推出 [GPT‑5⁠](https://openai.com)，这是 OpenAI 迄今为止最智能、最快捷、最实用的模型，也是将智能置于每项业务核心的重要一步。

GPT‑5 整合并超越了 OpenAI 在前沿智能领域的先前突破，涵盖 4o、OpenAI o 系列推理、智能体以及[高级数学](https://x.com/markchen90/status/1946571252937728307)能力。随着 BNY Mellon、加州州立大学、Figma、Intercom、Lowe’s、摩根士丹利、软银、T-Mobile 等企业已率先为员工配备 AI 技术——目前已有 [500 万](https://x.com/bradlightcap/status/1951389149149405618)付费用户使用 ChatGPT 商业产品——并开始借助 API 重新构想其运营模式。

GPT‑5 在准确性、速度、推理能力、背景信息识别、结构化思维和问题解决能力方面实现了重大突破。当企业开始将 GPT‑5 应用于探索新的应用场景时，真正的魔力将得以展现。以下是早期反馈：

GPT‑5 的发布正值每周有 7 亿人使用 ChatGPT。强大的 AI 技术如今已更深入地融入我们的生活和工作方式，消费者对该技术的日益熟悉正激励企业为员工提供直接访问 OpenAI 的权限，以提升生产力、效率和创造力。

借助 GPT‑5，采用 AI 技术的企业将迅速受益于其统一的 ChatGPT 体验，并在更高级的应用场景中，其在[智能体和编码⁠](https://openai.com)方面的增强型 API 性能将得到进一步提升。我们预计，早期采用 GPT‑5 驱动的 AI 技术将推动企业的行业领导地位，从而为组织在高风险工作中带来更优的决策、更高效的协作以及更快速的成果。

ChatGPT Team 版客户今天即可使用 GPT‑5，Enterprise 和 Edu 版将于下周推出。GPT‑5 现已通过 OpenAI API 开放，开发人员可立即[在此](http://platform.openai.com)开始使用。

Team、Enterprise 及 Edu 版客户也将很快获得 GPT‑5 Pro 的使用权限，该版本通过扩展推理能力，可提供更加可靠且详细的答案。
