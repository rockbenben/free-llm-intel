# 无监督情感神经元

我们开发了一个无监督系统。尽管训练目标只是预测 Amazon 评论文本的下一个字符，它却学会了极佳的情感表征。

配图：Ludwig Pettersson

使用这一表征的[线性模型⁠](https://openai.com/index/unsupervised-sentiment-neuron/#methodology) 在规模小但被深入研究的数据集 Stanford Sentiment Treebank 上达到了最先进的（state-of-the-art）情感分析准确率（我们得到 91.8% 的准确率，此前最好成绩为 90.2%），并且只用以往监督系统 1/30 到 1/100 的标注样本即可匹敌其性能。我们的表征中还有一个独特的[“情感神经元⁠](https://openai.com/index/unsupervised-sentiment-neuron/#sentimentneuron)””，几乎承载了全部情感信号。

在 Stanford Sentiment Treebank 上，我们的系统用远少的数据击败了其他方法。

我们的模型两个变体（绿线与蓝线）匹敌全监督方法（用 6,920 个样本训练的灰色虚线）所需的标注样本数。我们的 L1 正则化模型（在 Amazon 评论上以无监督方式预训练）只需 11 个标注样本即可匹配 [multichannel CNN]([https://arxiv.org/abs/1408.5882⁠（在新窗口中打开）](https://arxiv.org/abs/1408.5882)) 的性能，用 232 个样本即可匹配最先进的 CT-LSTM 集成模型。

模型学到一个可解释的特征令我们极为惊讶——仅仅[预测⁠（在新窗口中打开）](http://karpathy.github.io/2015-05-21/rnn-effectiveness/) Amazon 评论的下一个字符，就“发现”了情感这一概念。我们相信这一现象并非我们模型的特例，而是某些大型神经网络的普遍属性：这些网络被训练来预测输入中的下一步或下一维度。

## 方法

我们首先在 8,200 万条 Amazon 评论语料上训练了一个 4,096 单元的[乘法 LSTM⁠（在新窗口中打开）](https://arxiv.org/abs/1609.07959)（mLSTM），预测文本块的下一个字符。训练在 4 块 NVIDIA Pascal GPU 上耗时一个月，模型每秒处理 12,500 个字符。

这 4,096 个单元（只是一串浮点向量）可被视为模型所读字符串的特征向量。训练完 mLSTM 后，我们把这些单元取线性组合、并利用可用的监督数据学习组合权重，从而把模型变成一个情感分类器。

## 情感神经元

在用 L1 正则化训练线性模型时，我们注意到它使用的已学习单元少得惊人。深入挖掘后，我们发现确实存在单个“情感神经元”，对情感值高度有预测力。

与类似模型一样，我们的模型可以用来生成文本。不同之处在于，我们有一个直接“旋钮”控制生成文本的情感：只需覆写情感神经元的数值即可。

情感神经元逐字符调整其数值。

有趣的是，系统在句子和短语完结后也会大幅更新。例如，在 “*And about 99.8 percent of that got lost in the film*” 中，“*lost*” 之后有负向更新，句末还有更大的更新，尽管 “*in the film*” 本身不含情感内容。

## 无监督学习

标注数据是当今机器学习的燃料。收集数据容易，但可扩展地标注数据很难。只有对那些回报足以匹配投入的重要问题——如机器翻译、语音识别、自动驾驶——生成标注才可行。

机器学习研究者长久以来梦想开发[无监督⁠（在新窗口中打开）](https://en.wikipedia.org/wiki/Word2vec)[学习⁠（在新窗口中打开）](https://arxiv.org/abs/1506.06726)[算法⁠（在新窗口中打开）](http://www.mitpressjournals.org/doi/pdfplus/10.1162/neco.2006.18.7.1527)，[以⁠（在新窗口中打开）](http://www-cs.stanford.edu/~acoates/papers/coatesng_nntot2012.pdf)[学到⁠（在新窗口中打开）](https://arxiv.org/abs/1505.05192)数据集的良好表征，然后仅用少量标注样本解决任务。我们的研究表明：在海量数据上简单训练大型的“下一步预测”模型，可能就是构建具有良好表征学习能力的系统的好方法。

## 下一步

我们的结果是无监督通用表征学习上令人鼓舞的一步。这些结果来自我们的探索——能否把语言建模的副产品学成高质量表征——并在精心挑选的数据集上放大了既有模型。然而底层现象仍更显神秘而非明朗。

- 对长文档数据集，这些结果没有那么强。我们猜测字符级模型很难在上百到上千个时间步内记住信息。我们认为值得尝试能够自适应运行时间尺度的层级模型。进一步放大这些模型，可能进一步提升表征保真度以及在情感分析及类似任务上的表现。
- 输入文本越偏离评论数据，模型表现越差。值得验证：扩大文本样本语料是否仍能产生同样信息量丰富、且适用于更广领域的表征。
- 我们的结果提示：在某些设定下，超大规模的下一步预测模型能学到极佳的无监督表征。训练大型神经网络预测海量视频集合中的下一帧，可能得到用于物体、场景和动作分类器的无监督表征。

总的来说，理解模型、训练方案与数据集的哪些属性能稳定产生如此出色的表征，至关重要。
