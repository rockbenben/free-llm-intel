# OpenAI 与 Scale 合作，为企业微调模型提供支持

OpenAI 的客户可以借助 Scale 的 AI 专业能力，定制我们最先进的模型。

OpenAI 与 Scale 联手，帮助更多企业从微调我们最先进的模型中获益。

企业在生产环境中部署 AI 时，期望高性能、可引导性和定制化。我们近期[推出⁠](https://openai.com/index/gpt-3-5-turbo-fine-tuning-and-api-updates/)了 GPT‑3.5 Turbo 的微调服务，并将在今秋把微调带到 GPT‑4。通过微调，企业可以在专有数据上安全地定制我们最先进的模型，让我们最强大的模型更加实用。一如既往，进出微调 API 的数据归客户所有，OpenAI 或任何其他组织都不会用它训练其他模型。

我们选择 Scale 作为首选合作伙伴来扩展微调能力的红利，看中的正是它帮助企业安全、高效地用数据驱动 AI 的经验。打造稳健的企业级功能，需要严格的数据富化与模型评估。Scale 的客户现在可以像通过 OpenAI 一样微调 OpenAI 模型，同时受益于 Scale 的企业 AI 专业能力与 Data Engine。

Scale 已通过为 Brex 微调 GPT‑3.5 展示了客户价值。更多细节见[此处](https://scale.com/blog/open-ai-scale-partnership-gpt-3-5-fine-tuning)。
