# 与 Vox Media 达成内容与产品合作

*编者按：这条消息最初由 Vox Media 发布，原文见[此处](https://www.voxmedia.com/e/23930524)。*

现代媒体行业的领军者 [Vox Media](https://corp.voxmedia.com/) 今日宣布与 OpenAI 建立广泛的战略合作。Vox Media 旗下广受尊重的媒体矩阵——包括 Vox、The Verge、Eater、《New York》杂志、The Cut、Vulture 和 SB Nation——将为 ChatGPT 的 1 亿用户提供内容支持，并获得品牌署名与受众导流。两家公司还将利用 OpenAI 的技术，为 Vox Media 的消费者和广告合作伙伴开发创新产品。

通过这一合作，ChatGPT 及未来的产品将汲取 Vox Media 屡获殊荣的媒体品牌所积累的可信新闻与专业能力。同时，OpenAI 将用 Vox Media 的档案库增强其技术——这些档案蕴藏着深厚、可靠、可问责的信息与新闻。这份协议认可了该公司工作与知识产权的价值，同时把它们向新受众开放，让公众获得更好的信息。

自 2011 年创立以来，Vox Media 持续开发并拥抱为其用户跨平台服务的新科技；这一新合作将增强公司以生成式 AI 创新的能力。作为协议的一部分，Vox Media 将与 OpenAI 协作，利用其技术构建面向受众和内部应用的能力。OpenAI 的技术将帮助消费者从 Vox Media 的品牌中发现有价值的推荐与信息。在诸多用途中，Vox Media 将持续增强其联盟电商产品 [The Strategist Gift Scout](https://nymag.com/strategist/gift-scout.html)——它像一个增强版搜索工具，使用 OpenAI 工具为购物者匹配 Strategist 认可的最佳礼物。

Vox Media 还将利用 OpenAI 技术巩固其一方数据平台 Forte 的领先优势。Forte 于 2019 年推出，专为驱动广告主的效果而建，其定向曝光的表现是其他数据源的 2 倍。该平台覆盖 Vox Media 旗下全部站点及其广告市场 [Concert](https://concert.io/)。广告主将从与 OpenAI 的合作中受益：更强大的创意优化和受众细分定向，带来更高的投放效果。

"我们非常激动能与 OpenAI 合作。这份协议与我们的目标一致——利用生成式 AI 为我们的受众和客户创新，保护和提升我们工作与知识产权的价值，提高生产力和可发现性，让旗下杰出记者与创作者的才华和创造力如虎添翼，"Vox Media 联合创始人、董事长兼 CEO Jim Bankoff 表示。

"随着媒体与技术版图的变化，让准确、可信的信息触达公众至关重要。这份合作认识到：人类的创造力和优质新闻是负责任地部署生成式 AI 的关键组成部分，"Vox Media 总裁 Pam Wasserstein 说。

"我们很高兴与 Vox Media 合作，在 AI 与媒体的交汇点为我们的受众提供最佳体验。携手并进，我们既能推进创新，又能放大新闻工作者的价值，"OpenAI 首席运营官 Brad Lightcap 说。
