# 隆重推出 OpenAI 政府版


今天，我们正式推出 OpenAI 政府版，这是一项旨在将我们最先进的 AI 工具带给美国各地公共服务人员的全新计划。我们支持美国政府努力采用一流的技术，并将这些工具用于服务公共利益。我们的目标是解锁能够提升政府工作人员能力的 AI 解决方案，帮助他们减少繁文缛节和文书工作，让他们能够更多地专注于每天来上班的目的：服务美国人民。

OpenAI 政府版整合了我们现有的美国政府技术服务——包括已公布的客户及合作伙伴关系，以及我们的 [ChatGPT Gov⁠](https://openai.com/global-affairs/introducing-chatgpt-gov/) 产品——随着相关工作的扩展，这些业务现已被统一纳入该计划框架下。我们与美国国家实验室、空军研究实验室、美国国家航空航天局 (NASA) 以及美国国税局 (IRS) 的既有合作关系都将纳入 OpenAI 政府版框架下。

通过 OpenAI 政府版，我们将为美国联邦、州及地方政府提供以下服务：

- 包括通过 ChatGPT Enterprise 和 [ChatGPT Gov⁠](https://openai.com/global-affairs/introducing-chatgpt-gov/) 在安全合规的环境中使用我们最先进的模型。
- 针对国家安全需求的定制模型，该服务将以有限方式提供。
- 提前了解这些模型当前及未来的能力。

我们很高兴地宣布，我们的首个 OpenAI 政府合作项目将与美国国防部通过其首席数字与人工智能办公室 (CDAO) 开展试点计划。该合同的最高金额为 2 亿美元，将利用 OpenAI 在行业领先的人工智能技术，帮助国防部探索和验证前沿人工智能如何革新其行政运营。这包括优化士兵及其家属的医疗服务获取方式，简化项目和采购数据的分析流程以更快识别问题与机遇，以及支持主动网络防御和工作流程自动化。与所有国家安全相关工作一样，所有应用场景均符合 OpenAI 的[使用政策⁠](https://openai.com/policies/usage-policies/)。

通过这些举措，我们的目标是既改善公共服务的日常体验，又帮助政府雇员在关键使命中得到更多赋权、提升效能、增强信心并获得更多支持。我们已经看到 OpenAI 如何帮助州级公共服务人员减少重复性任务的时间，更多地专注于高影响力的工作。例如，参与 OpenAI 试点项目的宾夕法尼亚州政府雇员发现，ChatGPT 帮助他们将日常事务性工作的处理时间缩短了约 105 分钟/天。而且我们已经看到它如何提升公共服务质量。在洛斯阿拉莫斯、劳伦斯利弗莫尔和桑迪亚国家实验室，我们正在部署 OpenAI 模型以加速科研进程、增强国家安全战备能力并推动公共部门创新。

我们才刚刚开始，期待帮助政府领导人利用 AI 更好地服务公众。我们致力于与各机构紧密合作，通过安全可靠的强大工具推动其使命的实现。
