# 采用与动作相关的分解基线降低策略梯度方差





## 摘要

策略梯度方法在深度强化学习中取得了巨大成功，但深受梯度估计高方差之苦。在长视野（long horizons）或高维动作空间的问题上，高方差问题尤为严重。为缓解这一问题，我们推导出一个无偏的、与动作相关的方差缩减基线（baseline），它充分利用随机策略本身的结构形式，且对 MDP 不做任何额外假设。我们通过理论分析和数值结果展示并量化了动作相关基线带来的收益，包括对最优状态相关基线次优性的分析。最终成果是一个计算高效的策略梯度算法，可以扩展到高维控制问题——我们在一个合成的 2000 维目标匹配任务上对此进行了验证。实验结果表明，动作相关基线在标准强化学习基准以及高维手部操作和合成任务上都能带来更快的学习。最后我们展示，将额外信息纳入基线以改进方差缩减这一总体思路，可以推广到部分可观测任务和多智能体任务。
