# 我们优化 ChatGPT 的目标

我们把 ChatGPT 设计成帮助你取得进展、学习新东西、解决问题。

Loading…

我们打造 ChatGPT，帮助你以你想要的每一种方式 thriving（蒸蒸日上）。取得进展、学习新东西或解决一个问题——然后回到你的生活。我们的目标不是抓住你的注意力，而是帮助你善用注意力。

我们不去用停留时长或点击量衡量成功，我们更关心你离开产品时是否做完了你原本要做的事。

我们也会关注你是否日/周/月回流，因为那说明 ChatGPT 足够有用、值得回来。

我们的目标与你的目标是一致的。如果 ChatGPT 真的能帮到你，你就会希望它为你做更多，然后决定长期订阅。

一个有用的 ChatGPT 体验大概长这样：

- "帮我准备一次和老板的艰难对话。" ChatGPT 会捕捉让你发挥最佳状态所需的东西，通过练习场景或为你量身定制一段打气，让你能踏实、自信地走进去。
- "我需要理解我的化验结果。" 它解释那些数字，帮助你向医生提出正确的问题，让你和医生能够基于更多信息个性化你的方案。
- "我卡住了——帮我把思绪理清楚。" 它充当回音板，同时把思维工具交给你，让你更清晰地思考。

很多时候，产品里更少的时间恰恰说明它起效了。借助 ChatGPT Agent 等新能力，现在它甚至能在你不在 App 里的情况下帮你达成目标——预约医生、总结你的收件箱，或者筹备一场生日会。

## 关于健康使用

我们并不总能做对。今年早些时候，一次更新让模型过于迎合，有时讲出来的是"好听的话"而非"真正有用的话"。我们 [回滚了](https://openai.com/index/sycophancy-in-gpt-4o/)、改变了我们使用反馈的方式，并正在改进我们如何衡量长期的现实有用性，而不是仅看你当下是否喜欢那个回答。

我们也知道，AI 相比以往的技术会显得更具回应性和更个人化，这对处于心理或情绪困境中的脆弱人群尤其如此。对我们而言，帮助你 thriving 意味着在你挣扎时在那里、帮助你保有对自己时间的掌控，在你面对个人挑战时引导而非替你决定。

正因如此，我们一直在推动 ChatGPT 的这些改变：

- **在你挣扎时支持你。** ChatGPT 被训练为以脚踏实地的诚实来回应。有过一些情况，我们的 4o 模型在识别妄想或情绪依赖的迹象上表现不足。虽然罕见，我们仍在持续改进模型，并开发能更好识别心理或情绪困扰迹象的工具，让 ChatGPT 能够恰当回应，并在必要时把人指向循证资源。
- **让你掌控自己的时间。** 从今天开始，你会在长时间会话中看到温和的提醒，鼓励你休息一下。我们会持续调整提醒出现的时机与方式，让它们显得自然而有用。
- **帮助你解决个人难题。** 当你问"我该和男朋友分手吗"这类问题时，ChatGPT 不应该给你一个答案。它应该帮你把问题想清楚——提问、权衡利弊。面向高风险个人决策的新行为即将上线。

## 向专家学习

我们正与专家紧密合作，改进 ChatGPT 在关键时刻——比如某人出现心理或情绪困扰迹象时——的回应方式。

- **医学专业能力。** 我们与来自 30 多个国家、超过 90 位医生（精神科医生、儿科医生和全科医生）合作，构建了用于评估复杂、多轮对话的自定义评分规则。
- **研究合作。** 我们正在与 HCI（人机交互）研究者和临床医生合作，请他们反馈我们如何识别令人担忧的行为、优化我们的评估方法，并对产品的安全防护做压力测试。
- **顾问小组。** 我们正在召集一个由心理健康、青少年发展和 HCI 领域专家组成的顾问小组。这个小组会帮助我们确保方法反映最新的研究和最佳实践。

这项工作仍在进行，随着推进我们会分享更多信息。

## 展望未来

帮助你 thriving 的目标不会改变。我们的方法会随着从现实使用中不断学习而持续演化。我们用同一个问题检验自己：如果我们爱的人向 ChatGPT 寻求支持，我们会不会放心？把答案推向毫无保留的"会"，就是我们的事业。
