# OpenAI 任命美军退役上将 Paul M. Nakasone 进入董事会

Nakasone 为不断壮大的董事会带来网络安全经验；他将加入董事会的安全与安保委员会。

今天，**美军退役上将 Paul M. Nakasone** 加入了我们的董事会。作为网络安全领域的顶尖专家，Nakasone 的任命体现了 OpenAI 对安全与安保的承诺，也凸显出随着 AI 技术影响不断扩大，网络安全的日益重要。

作为首要任务，Nakasone 将加入董事会的[安全与安保委员会⁠](https://openai.com/index/openai-board-forms-safety-and-security-committee/)。该委员会负责就 OpenAI 所有项目与运营中的关键安全与安保决策向全体董事会提出建议。

[OpenAI 系统的安全⁠](https://openai.com/index/reimagining-secure-infrastructure-for-advanced-ai/)——从保护我们运营的大型 AI 训练超算，到守护敏感的模型权重和客户托付给我们的数据——是达成我们使命的核心。随着 AI 技术在通往通用人工智能（AGI）的道路上能力越来越强，我们也在随时间推移变得更能抵御日益复杂的网络安全威胁。

Nakasone 的洞见也将助力 OpenAI 更好地理解如何用 AI 强化网络安全——快速检测并响应网络安全威胁。我们相信，AI 有潜力在这一领域为医院、学校、金融机构等频遭网络攻击的各类机构带来显著收益。

"人工智能有可能对人们的生活产生巨大的正面影响，但只有把这些创新安全地构建和部署出来，这种潜力才可能兑现，"OpenAI 董事会主席 Bret Taylor 说。"Nakasone 上将在网络安全等领域无与伦比的经验，将帮助 OpenAI 在'确保通用人工智能造福全人类'的使命中行稳致远。"

Nakasone 上将分享了他加入董事会的感想："OpenAI 对使命的执着与我的价值观和公共服务经历高度契合。我期待为 OpenAI 确保通用人工智能安全、造福全世界人民的努力贡献力量。"

**美军退役上将 Paul M. Nakasone** 是网络安全、技术发展和全球网络防御领域的顶尖专家。在其陆军军旅生涯中，他参与创建了美国网络司令部（U.S. Cyber Command），并是该司令部任期最长的领导人，同时执掌过美国国家安全局（NSA），肩负保卫美国数字基础设施、提升国家网络防御能力的重任。他曾在陆军的各级指挥与参谋岗位任职，服役于美国、韩国、伊拉克和阿富汗的精锐网络部队。
