# Ilya Sutskever 将离开 OpenAI，Jakub Pachocki 出任首席科学家

## Sam 致全公司的信

> Ilya 和 OpenAI 即将分道扬镳。这让我非常难过：Ilya 无疑是我们这个时代最伟大的头脑之一，是我们这个领域的指路明灯，也是我的挚友。他的才华与远见世人皆知；他的温暖与慈悲虽不那么为人所知，却同样珍贵。没有他，就没有今天的 OpenAI。尽管他将去从事对个人意义重大的事业，我仍永远感谢他在此所做的一切，并承诺完成我们共同开启的使命。我很庆幸能与这样一位真正卓越的天才、这样一位一心为人类争取最好未来的人相伴这么久。Jakub 将担任我们的新任首席科学家。Jakub 同样无疑是我们这个时代最伟大的头脑之一；我很激动能由他接棒。他主导过我们许多最重要的项目，我坚信他会带领我们在"确保 AGI 造福全人类"的使命上快速而安全地前进。

## 关于 Jakub Pachocki

Jakub 是 OpenAI 的首席科学家。自 2017 年以来，他领导了多项变革性的研究工作。此前，他担任研究总监，主导了 GPT‑4 与 OpenAI Five 的开发，以及大规模强化学习和深度学习优化的基础研究。在帮助公司重新聚焦深度学习系统规模化愿景方面，他发挥了关键作用。Jakub 拥有卡内基梅隆大学理论计算机科学博士学位。
