细节更清晰、生成更迅速、编辑更精准，并提供更出色的创作与分享工具


每周，人们通过 ChatGPT 图像和 API 中的 GPT‑Image 模型创作超过 30 亿张图像。今天，我们将通过 ChatGPT 图像 2.5 拓展你的创作空间。这款全新的先进图像模型可呈现更清晰的细节、更精准的编辑和更快的生成速度，为创意工作流全面提效。

图像 2.5 能呈现更自然的光线和更丰富的纹理，更好地保留参考照片中的主体，并在多轮交互中更可靠地遵循编辑指令。与图像 2.0 相比，我们还将图像生成延迟最多降低了 50%，让你能够更快地生成图像并完善创意。

在 ChatGPT 中，我们还推出了一系列产品功能，让你更好地掌控创作过程。[Sketch](http://chatgpt.com/sketch) 是一项新功能，可让你直接在 ChatGPT 中绘图，并将其作为最终图像的参考。模板让你能更轻松地开始创作传单、产品照片等热门图像格式。现在，你还可以直接在图像上添加评论，进行更有针对性的编辑；也可以分享用过的提示词，让其他人用自己的照片和细节尝试你的创意。

所有桌面端、移动端和网页版的 ChatGPT、ChatGPT 工作及 Codex 用户均可使用图像 2.5。

面向开发者，我们将在 API 中推出两款新模型。GPT‑Image‑2.5 Flare 在质量、编辑和速度方面带来同样的提升；GPT‑Image‑2.5 Sunburst 则以更长的生成时间，为细致的创意工作提供更高一级的精准度。

## 创作过程中的图像保真度

最能打动人的图像，往往扎根于现实中的人物、地点和记忆。图像 2.5 更善于基于参考照片，将熟悉的主体转换到新的场景、视觉风格和构图中。图像主体更易辨认，光线和纹理更自然，鲜明特征也更容易得到保留。

对于使用 API 进行构建的团队，同样的保真度让参考图驱动的工作流更可靠，使各种变体都能忠实于原始素材。

## 精准编辑

我们让针对性编辑变得更加轻松，使最终图像更贴合你的真实构想。图像 2.5 更擅长只修改你指定的内容，同时保持其他细节不变，即使面对更复杂的主体和背景也是如此。

对于使用图像 API 的开发者，这让用户能够只更新产品、背景或一段文案等单个元素，同时保留周围的主体、构图和品牌风格。

## 多轮编辑一致性

在较长的 ChatGPT 对话中，图像 2.5 能在多次编辑中更可靠地遵循具体指令。先前的修改更有可能保持一致，每次新编辑都能承接已有成果，而不会随着时间推移降低图像质量。

这种一致性对生产工作流同样重要，因为开发者需要有针对性地修改内容，而不必重新制作整个素材。

以下视频由多张图像组成，展示了模型在多轮交互中保持图像质量的能力提升。

## 智能与风格改进

图像 2.5 更善于理解复杂的视觉指令，并将其转化为协调一致的结果。包含现实信息的图像内容更加准确，模型也能处理包括透明背景在内的更复杂布局。它还能更准确地呈现视觉风格，让图像更贴合你的艺术构想。

对于开发者和企业而言，这让复杂创意简报的执行更加可靠。即使指令越来越具体，模型也更有可能保留所要求的视觉方向、构图和各项细节，而不会逐渐偏离。无论是生成一系列符合品牌调性的创意素材、保持既定层级结构的 UI 概念，还是符合指定结构的演示文稿视觉内容，这一点都至关重要。

## 用 Sketch 将创意绘制成真

有时，表达一个想法最清楚的方式就是把它画出来。

我们推出了新功能 Sketch，让你可以直接在 ChatGPT 中绘图，并将其用作视觉参考。现在，你可以快速勾勒房间布局、正在构思的服装轮廓，或随手画一幅有趣的涂鸦，再由 ChatGPT 将草图变成完整图像。添加风格描述及其他所需细节，确保生成结果体现你的构想。

你不必是专业艺术家，这只是让最终图像更贴近心中构想的另一种方式。若要[亲自试用](http://chatgpt.com/sketch)，只需在 ChatGPT 中输入“@Sketch”。

## 优化提示词结构，获得更佳结果

有时，你很清楚自己想做什么，只是需要一点帮助来迈出第一步。

我们将为一些最热门的创意格式推出模板。无需从空白画布开始，你可以选择“海报”或“周边商品”等模板，再添加需要传达的信息、设计元素或风格等细节，打造个性化结果。

## 分享你的最佳创意

## API 中的 Images 2.5

开发者正通过图像 API，将图像生成工作流融入创意、营销、零售和媒体团队日常使用的产品中。

我们将在 API 中发布两款新图像模型：

**GPT‑Image‑2.5 Flare** 将质量、编辑和速度方面的同等提升带入 API，是大多数应用的默认选择；与 GPT‑Image‑2 相比，它能以低 50% 的延迟生成质量更高的图像。它广泛适用于创作者内容和社交媒体内容、产品体验、视觉搜索、快速图像原型设计和大批量生成等场景。

**GPT‑Image‑2.5 Sunburst** 专为高端视觉工作流打造，可在多次编辑中提供更精细的控制。它适用于创作与编辑工作流，例如可直接用于制作的营销活动创意素材或精致的产品图像。

## 我们的安全承诺

我们致力于让图像生成既实用、富有创意，又安全可靠。ChatGPT 图像 2.5 延续了现有的安全防护措施，通过检查提示词和图像来帮助防止生成有害内容。我们继续使用 C2PA 元数据和不可见水印，帮助识别由我们的工具生成的图像。你可以在系统卡中详细了解我们的评估和方法。
