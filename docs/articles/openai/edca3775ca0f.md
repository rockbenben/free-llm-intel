# 通过与甲骨文公司达成 4.5GW 合作协议，Stargate（星际之门）项目取得新进展

新的数据中心容量将推动就业、经济增长以及惠及更多人群的人工智能的发展。


甲骨文与 OpenAI 已达成协议，将在美国增加 4.5GW 的 Stargate 数据中心容量。此项投资将创造新的就业机会，加速美国的再工业化进程，并助力推动美国在人工智能领域的领导地位。这标志着 [Stargate⁠](https://openai.com/zh-Hans-CN/index/announcing-the-stargate-project/)——OpenAI 的人工智能基础设施平台及其长期愿景——在将人工智能的益处带给每个人方面迈出了重要一步。

与我们在得克萨斯州阿比林的 Stargate I 站点合作，此次与甲骨文的额外合作将使我们正在开发的 Stargate 人工智能数据中心容量超过 5GW，这将运行超过 200 万个芯片。这将显著推动我们实现今年 1 月在白宫宣布的承诺，即在未来四年内向美国投资 5,000 亿美元，用于建设 10GW 的人工智能基础设施。我们现在预计将超越最初的承诺，这得益于与甲骨文和软银等合作伙伴的强劲合作势头。

这也将推动未来几年通过 Stargate 项目预计创造的数十万个就业岗位中的相当一部分。我们估计，建设、开发和运营今天宣布的额外 4.5GW 数据中心容量，将在美国创造超过十万个就业岗位，涵盖施工和运营等多个岗位。该估算包括运营 Stargate 数据中心所需的直接全职岗位，短期施工岗位（如得克萨斯州阿比林市 Stargate I 站点中众多高技能电工），以及间接岗位（如制造和本地服务岗位）。

与此同时，阿比林市 Stargate I 的建设工作正在推进，部分设施已投入运行。甲骨文公司上月已开始交付首批 Nvidia GB200 机架，我们近期已启动早期训练和推理工作负载，利用这一算力推动 OpenAI 下一代前沿研究的边界。Stargate I 项目已创造了数千个就业岗位，随着运营规模的扩大，预计还将创造更多岗位，其中包括来自 20 多个州的电工、设备操作员和技术人员等专业岗位。

与甲骨文的合作，以及与软银的合作伙伴关系正以强劲的势头稳步推进。这两者对于满足 OpenAI 不断增长的算力需求至关重要。与软银合作，我们正在迅速推进现场评估，并重新构想数据中心的设计，以支持先进的人工智能技术。这些努力将为使用我们工具的用户带来更强大、更可靠的人工智能解决方案。

过去六个月中，对 Stargate 的日益增长的兴趣帮助我们塑造并扩展了这一努力的愿景。Stargate 是 OpenAI 的综合性人工智能基础设施平台，涵盖与甲骨文、软银和 CoreWeave 的持续数据中心合作，以及通过 [OpenAI 国家合作计划⁠](https://openai.com/global-affairs/openai-for-countries/) (OpenAI for Countries) 项目对美国基础设施进行的国际投资。该项目基于我们与微软长期且持续的计算合作关系，微软将继续作为 Stargate 的技术合作伙伴。

Stargate 是一个雄心勃勃的项目，旨在把握我们面前的历史性机遇。这一机遇正通过全球合作伙伴、政府和投资者的强力支持逐步实现——其中包括白宫的重要领导作用，白宫已认识到人工智能基础设施在推动创新、经济增长和国家竞争力方面将发挥的关键作用。
