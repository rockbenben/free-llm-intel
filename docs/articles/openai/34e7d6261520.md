# Cisco 如何借助 OpenAI 以机器速度开展防御

Cisco 将网络情报与 OpenAI 模型相结合，构建适应性更强的防御体系。

Cisco 构建网络与安全基础设施，帮助各类组织连接并保护其系统。随着攻击者利用 AI 扩大自动化攻击的规模，并以机器速度开发漏洞利用手段，企业基础设施的防御方式也必须随之演进。将 Cisco 海量的网络遥测数据与前沿 AI 推理能力相结合，能为防御方提供抢先应对新兴威胁所需的工具。OpenAI 以零数据保留、严格的客户数据边界和可验证的隔离机制为核心，严谨地保护企业数据隐私。这使 Cisco 能够放心地在关键任务系统中部署前沿智能技术，同时兼顾客户的首要需求，保护敏感遥测数据。

## 整合网络情报，强化防御

Cisco 的防御从威胁传播的地方——网络——入手。Patel 介绍了安全防护的转变：从单一的安全边界，转向分布在微服务、容器和集群中的控制措施。他说：“我们可以在每个微服务、每个 Kubernetes 容器和每个 Kubernetes 集群前部署一套微型安全技术栈，将安全防护融入网络架构。”

应用层的控制措施可以将通信限制在各项服务必需的连接范围内，减少攻击者可用于扩散的路径。安全团队还可以更有针对性地隔离受影响的系统，让未受影响的服务在调查和响应期间继续运行。

Patel 表示，将这些网络情报与 OpenAI 模型相结合，使 Cisco 能够利用机器处理海量数据的能力，对信号进行关联分析。“两个信号单独看可能都没有异常，但放在一起，就可能揭示出有价值的模式。网络情报让我们能够对整个网络的数据进行关联分析，从中获得洞察，为安全运营提供依据。”

## 从调查到修复

Patel 指出了防御方面临的一项紧迫挑战：攻击者利用漏洞的速度，与组织修补漏洞所需的时间之间存在差距。他认为，AI 可以帮助缩小这一差距，让防御方有能力调查更多威胁，并更快作出响应。“AI 为攻击者带来了速度和规模优势。利用 AI 进行防御，是保障安全的前提。”他说。

他认为，Daybreak 和 GPT‑6 Astra 等项目带来的进步，增强了 Cisco 及其客户的安全防护。Patel 表示：“我们能够更高效地发现并修补漏洞，同时缩短调查、响应和修复所需的时间。”

> “Daybreak 和 GPT-6 Astra 不仅让我们的安全防护水平实现了跃升，也为客户带来了同样的提升。”

—Jeetu Patel，Cisco 总裁兼首席产品官

Patel 认为，可以依托团队现有的漏洞发现与处理流程，逐步引入这些能力。“这些能力可以融入现有的扫描工作流，因此无需从根本上改变团队的工作方式。”

## 重新思考智能体时代的安全

随着智能体的自主性不断增强，安全团队也需要区分两种情况：恶意干扰，以及智能体以非预期方式追求正当目标。Patel 表示，这需要结合安全遥测数据与可观测性数据，让团队既能评估威胁，也能评估智能体的行为。

他提出了三项重点：保护智能体免受恶意攻击，检测并拦截非预期行为，以及近乎实时地开展防护。在这些重点的指引下，安全策略和控制措施正朝着能够随智能体行动动态调整的方向演进。

通过 Daybreak 防御网络，Cisco 和 OpenAI 正在探索如何帮助安全团队更快地评估风险暴露情况、确定处置优先级，并在 Cisco Cloud Control 中实施适当的控制措施。在 Patel 看来，这有助于让防御方重新获得优势。

> “OpenAI 让我们能够以机器的速度和规模开展行动，正在将优势转向防御方。”

—Jeetu Patel，Cisco 总裁兼首席产品官
