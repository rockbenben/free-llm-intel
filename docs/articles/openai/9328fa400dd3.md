# OpenAI 向乌克兰开放网络安全工具，助力民用防御


OpenAI 今日宣布，将向乌克兰政府开放 Daybreak 计划，以支持民用基础设施的网络防御。OpenAI 将与乌克兰数字化转型部合作，为乌克兰团队提供相关工具，帮助其识别软件漏洞，并更快地开发和测试修复方案。

乌克兰驻旧金山总领事 Dmytro Kushneruk 与 OpenAI 国家安全政策负责人 Sasha Baker 在联合国大会期间宣布了这一消息。

在乌克兰基础设施持续遭受实体攻击的同时，乌克兰防御者还面临着来自俄罗斯的持续网络攻击。乌克兰国家计算机应急响应小组 CERT-UA 在 2025 年[处理了](https://info.poda.gov.ua/news/251006)近 6,000 起网络安全事件，其中包括针对医院系统、能源行业和电信业的攻击，凸显出为乌克兰民众提供基本服务的机构所承受的压力。

OpenAI 的 Daybreak 让网络防御者能够使用先进 AI 开展经授权的安全工作，包括审查旧版软件、调查可疑活动、验证漏洞和测试修复方案。

乌克兰的网络防御者每天都在抵御攻击，保护基本服务。我们很自豪能够为他们提供支持。借助 Daybreak，公共和私营机构有机会在新兴威胁造成影响之前加强网络防御。乌克兰已身处前线，其防御者现在就需要支持。我们希望为他们提供更强大的工具，帮助他们发现并修复漏洞，保护人们赖以生存的关键网络。

—Sasha Baker，OpenAI 国家安全政策负责人

乌克兰已经证明，即使承受最极端的压力，网络防御仍是国家安全的核心组成部分。保护民用基础设施，意味着既要抵御实体攻击，也要抵御数字攻击，让人们能够继续生活、工作并获得基本服务。现在，我们正投入技术和资源支持这项工作，帮助乌克兰政府利用 AI 加强网络防御。

—George Osborne，OpenAI for Countries 负责人

OpenAI 已向法国、德国、波兰等欧洲国家的防御者开放其网络安全模型。欧盟网络安全局 ENISA 已利用这些模型识别欧盟各机构所用软件中的漏洞，目前这些漏洞均已修复。

在波兰，国家网络安全机构 CERT Polska 使用 OpenAI 模型，协助发现了第三方路由器软件中的六个漏洞。供应商已发布修复方案；CERT Polska 确认，这些方案能够阻止其观察到的攻击。
