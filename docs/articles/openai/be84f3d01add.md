# 可解释且具教学意义的示例





## 摘要

老师会刻意挑选最有信息量的示例展示给学生。然而，如果老师和学生都是神经网络，那么老师网络学会给出的示例虽然能有效教会学生，通常却是不可解释的。我们展示：迭代地——而非联合地——训练学生与老师，可以产出可解释的教学策略。我们从两个角度评估可解释性：(1) 度量老师涌现出的策略与各领域直观策略之间的相似度；(2) 开展人类实验，评估老师的策略在教人类时的有效性。我们证明，老师网络学会了挑选或生成可解释的、具有教学意义的示例，用来教授基于规则、概率、布尔以及层级结构的概念。
