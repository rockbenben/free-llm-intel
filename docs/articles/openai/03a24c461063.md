# Match Group

Match Group 是在线婚恋领域的全球领导者，旗下产品包括 Tinder、Hinge 和 OkCupid。他们正在把 AI 新时代融入产品与内部运营，发现 ChatGPT Enterprise 正让员工更快乐、更有创造力、更成功。

## 打造伟大产品，技术只是其中之一

Match Group 不断打磨产品，力求创造点燃新联结的、神奇的用户体验。为此，他们也需要持续帮助员工成长、彼此连接。

> “当人们知识面广博、能够跨越自己的传统职能协作时，就更有创新性。”

Mark Kantor，Match Group 创新副总裁

然而，当团队成员“语言不通”时，协作可能卡壳——有时真是字面意义上的。“我们在首尔和日本的工作室需要与美国团队协作，”Kantor 说。这些团队的许多成员英语并不流利，深入的技术交流因此很困难。

更多时候，连接上的缺口其实是技能与知识的差异，使员工无法充分表达创造力，或跨团队、跨职能顺畅工作。设计师和产品经理可能有一个新项目点子，却没有能有效做出原型的编程能力；写作能力较弱的成员，可能难以形成有力的提案或高质量文档。有了 AI，这些挑战如今都可以跨越。

> “我们的团队对提升生产力、协作与创造力的能力非常乐观。我们真心相信 AI 有改变工作场所、提升员工幸福感的潜力。”

Will Wu，Match Group 首席技术官

## 借力 ChatGPT Enterprise，打造更快乐、更高效的公司

Match Group 迅速评估了 ChatGPT Enterprise 的潜力——不仅用于打造更好的产品，也用于赋能员工。他们的发现令人振奋：“当我们真正开始讨论 AI 战略、动手用 ChatGPT 体验模型的推理能力时，大家的想象力彻底放飞了，”Wu 说。

Match Group 开始探索集成 OpenAI API 构建新产品与新功能，例如帮助用户以更少的精力创建更深入、更真实的个人资料。与此同时，他们快速采用 ChatGPT Enterprise 并推广给数千名员工。ChatGPT 带来的效果甚至超出了管理层最初的预期。“ChatGPT 有很多显而易见的用法，但随着更多员工获得使用权，他们发现了令人惊喜的用法，把它的价值带上了新台阶——你会意识到我们才刚刚触及可能性冰山一角，”Kantor 说。

Match Group 观察到员工用 ChatGPT Enterprise 改善了：

- **跨职能协作。** 围绕技术主题的协作已成为 ChatGPT Enterprise 最有价值的用途之一，产品经理和设计师找到了开发原型的新方式——即使他们不懂编程。
- **产品可用性焦点小组。** 设计团队试验了 GPT‑4 的多模态能力来做模拟用户研究。通过上传线框图并让 ChatGPT 模仿特定用户画像，设计师可以一边提问、一边让这位“用户”浏览界面并给出反馈。
- **工程效率。** 工程师们用 ChatGPT Enterprise 修 bug、写文档、设计新 API 架构等等。“有一个时刻让我大开眼界：一个团队在一天之内拼出了一个 iOS 应用来完成功能原型，”Wu 分享道。“让我震惊的是，做出这个原型的工程师*从来*没有开发过 iOS 应用——他们是用 ChatGPT 现场把应用搭出来的。”
- **知识共享。** Match Group 正在探索创建对企业工作区内所有员工开放的自定义 GPT。例如，构建一个能通读并检索全部内部文档的 GPT，可以帮助团队成员更好地理解从信任与安全政策到技术决策的各类信息。“ChatGPT 催生了一种自导向学习的文化，”Wu 说。
- **翻译与国际化协作。** “用 ChatGPT 做翻译，让我们的国际团队以前所未有的方式与全球同事真正连接，促成了大量超越语言和文化的协作，”Kantor 说。

> “ChatGPT 正在帮助人们以新方式学习。”

Mark Kantor，Match Group 创新副总裁

## 为人与产品全面加速

随着把 AI 更深地融入产品与运营，Match Group 很高兴能深化与 OpenAI 的合作。

> “OpenAI 的支持，对于确保我们在公司内部以负责任的方式推出 AI 至关重要。”

Will Wu，Match Group 首席技术官

“与 OpenAI 客户团队的协作非常有共创感、有支持、有成效，让我们能在正确的时间与正确的人进行正确的对话，”Wu 说。借助 ChatGPT Enterprise“为全体员工提速”，Match Group 计划在 OpenAI API 之上，把 AI 融入在线婚恋旅程的每个环节。“Match Group 的每个团队要么正在积极构建 AI 来改进产品，要么正在积极设计和思考它能在哪些方面发挥作用，”Kantor 说。“AI 不仅会成为员工和团队每天使用的、让他们更高效更快乐的工具，我们还会找到把 AI 负责任地加入产品的方式，让顾客更容易建立联结。”
