# 出资 5000 万美元，与社区共建

OpenAI 启动首期 5000 万美元基金，支持非营利与社区组织，其方向参考了独立的 OpenAI 非营利委员会报告。

在 OpenAI，我们相信 AI 应当帮助人类解决最难的难题，这也包括赋能那些奋战在这项工作一线的组织。

昨天，独立的 OpenAI 非营利委员会报告[正式发布](https://openai.com/index/nonprofit-commission-report/)。该报告汲取了 500 多家非营利组织和社区专家的意见——他们代表着超过 700 万美国人——通过委员会系列倾听会贡献了研究发现。

我们正在回应委员会的呼吁，为一线和使命驱动的组织提供即时、直接的支持——这些组织常以有限资源为社区提供重要服务。

因此今天，我们宣布启动首期 5000 万美元基金，支持非营利与社区组织。这一行动延续了[非营利委员会](https://openai.com/index/nonprofit-commission-advisors/)的精神，以及本周[OpenAI 非营利共创日](https://openai.com/global-affairs/openai-nonprofit-jam/)的氛围——该活动在美国十个地点召集了 1000 名非营利组织领导者，共同借助人工智能的潜力进行构建。目标是一致的：倾听、学习、与社区共建。

通过这只基金，我们将与合作伙伴一起，在教育、经济机会、社区组织和医疗健康等领域释放 AI 的变革潜力，扩大影响、促进创新。我们还将支持由社区主导的研究与创新，探索用 AI 增进公共利益。

这一新倡议建立在 OpenAI 现有的努力和"确保 AGI 造福全人类"的使命之上。虽然这只基金将通过 AI 解决难题提供即时支持，但这只是我们愿景的早期一步——我们希望通过伙伴合作和创新项目推进更广泛的工作。我们对新的治理结构在未来数年扩大我们的影响力感到兴奋。

我们相信，"AI 如何最好地帮助社区"的答案很多就在社区自身之中。我们很自豪与他们共建，而这只是开始。我们期待很快分享更多信息。
