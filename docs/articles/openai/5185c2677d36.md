# #Exploration：深度强化学习中基于计数的探索研究

阅读论文

## 摘要

已知在求解小型离散马尔可夫决策过程（MDP）时，基于计数（count-based）的探索算法与表格型强化学习（RL）方法结合使用可以达到接近最优的表现。人们普遍认为基于计数的方法无法应用于高维状态空间，因为大多数状态只会出现一次。近期的深度 RL 探索策略能够借助复杂启发式方法处理高维连续状态空间，这些方法通常依赖“面对不确定性时的乐观主义”或内在动机。在本工作中，我们描述了一个令人惊讶的发现：对经典基于计数方法的简单推广，即可在多种高维和/或连续的深度 RL 基准上达到接近最先进（state-of-the-art）的性能。我们将状态映射为哈希码，从而可以用哈希表统计其出现次数，再依据经典的基于计数探索理论据此计算奖励加成。我们发现，简单哈希函数就能在许多棘手任务上取得出人意料的好结果。此外，我们证明领域相关的可学习哈希码可以进一步提升结果。详细分析揭示了好哈希函数的两个重要方面：1）具有适当的粒度；2）编码与求解 MDP 相关的信息。这一探索策略在连续控制任务和 Atari 2600 游戏上均取得接近最先进的性能，为需要大量探索的 MDP 求解提供了一个简单而强大的基线。
