# OpenAI 与 Microsoft 的联合声明


OpenAI 与 Microsoft 签署了一项不具约束力的谅解备忘录 (MOU)，为双方下一阶段的合作提供指引。目前，双方正在积极协作，以确定一份具体协议的合约条款。通过携手合作，我们将始终秉持共同的安全承诺，专注于为人类提供最好的 AI 工具。
