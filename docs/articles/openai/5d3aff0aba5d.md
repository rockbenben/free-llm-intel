# Daybreak 模型现已在 AWS 上线


今年早些时候，OpenAI 前沿模型和 Codex 已在 AWS 正式上线，为企业将先进 AI 投入生产环境提供了新途径。今天，我们将介绍与 AWS 合作的下一步：通过 Amazon Bedrock 提供 Daybreak 能力。

借助 [Daybreak Access](https://openai.com/form/enterprise-trusted-access-for-cyber/)，防御人员可以在现有 AWS 环境中使用前沿网络安全模型。AWS 现已提供 Daybreak Blue 和 Daybreak Red 两种访问级别：

- **Daybreak Blue **提供前沿通用模型的访问权限，包括 GPT‑5.6 Sol，并配有针对经授权防御性安全工作的安全防护措施。
- **Daybreak Red **提供专门训练的网络安全模型，用于经授权的漏洞研究、漏洞利用验证和安全测试。

这些模型有助于加快漏洞研究、检测工程和事件响应，覆盖从初步发现到修复方案验证的全过程。它们还支持漏洞利用复现和缓解措施开发等复杂工作流。

## 将前沿网络安全能力引入 AWS

对企业而言，采用专业网络安全能力，仅有出色的模型性能还不够。企业还需要完成安全审查、治理、采购和访问控制，并建立团队能够支持的运营模式。

符合条件的客户可以通过 Amazon Bedrock，在其现有的 AWS 软件构建、安全防护和运营环境中使用 Daybreak，包括 Daybreak Red 和 Daybreak Blue。这为安全团队提供了更明确的路径，使其能够通过熟悉的 AWS 安全、治理和运营工作流应用前沿 AI。

OpenAI 与 AWS 携手帮助更多组织将先进的网络安全能力投入生产环境。

## 开始使用

使用 Daybreak Red 和 Daybreak Blue 需要加入 [Daybreak Access](https://openai.com/form/enterprise-trusted-access-for-cyber/)。获批后，您可以通过 Amazon Bedrock 控制台访问该模型，也可以使用 bedrock-mantle 端点，通过 Responses API 访问。如需了解更多信息，请参阅[文档。](https://docs.aws.amazon.com/bedrock/latest/userguide/model-cards-openai.html)
