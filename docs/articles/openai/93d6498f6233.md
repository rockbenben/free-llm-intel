我们在 CLIP 中发现了这样的神经元：无论概念以字面、符号还是抽象方式呈现，它们都以相同方式响应。这或许能解释 CLIP 为何能准确识别概念那些出人意料的视觉呈现形式，也是理解 CLIP 及同类模型所学到的关联与偏见的重要一步。

十五年前，Quiroga 等人[1](https://openai.com/index/multimodal-neurons/#citation-bottom-1) 发现人脑拥有多模态神经元。这些神经元响应的是围绕某个共同高层主题聚合的一组抽象概念，而不是任何具体的视觉特征。其中最著名的是"Halle Berry 神经元"——一个同时登上[Scientific American⁠(opens in a new window)](https://www.scientificamerican.com/article/one-face-one-neuron) 和[纽约时报⁠(opens in a new window)](https://www.nytimes.com/2005-07-05/science/a-neuron-with-halle-berrys-name-on-it.html) 的神经元，它对照片、素描以及文字"Halle Berry"都有响应（但对其他名字没有）。

两个月前，OpenAI 发布了 [CLIP⁠](https://openai.com/index/clip/)，一个通用视觉系统，性能与 ResNet-50 持平[2](https://openai.com/index/multimodal-neurons/#citation-bottom-2)，却在一些最难的基准数据集上超过现有视觉系统。这些挑战性数据集——*ObjectNet*、*ImageNet Rendition*、*ImageNet Sketch*——考的是模型对"认不出来"的鲁棒性：不只是简单畸变或光照、姿态变化，而是完全的抽象与重构——素描、卡通，甚至物体的雕塑。

现在，我们发布在 CLIP 中存在多模态神经元的发现。例如，其中一个"Spider-Man（蜘蛛侠）神经元"（与"Halle Berry 神经元"惊人地相似）会对一张蜘蛛图片、"spider"这个单词的图片，以及穿着戏服或以漫画形象呈现的"Spider-Man"做出响应。

我们在 CLIP 中发现多模态神经元，暗示了人工视觉系统与自然视觉系统可能共有的机制——抽象。我们发现 CLIP 的最高层把图像组织成一个松散的语义观念集合，这既简洁地解释了模型的通用性，也解释了这种表示的紧凑性。

借助可解释性（interpretability）工具，我们前所未有地透视了 CLIP 权重中丰富的视觉概念。在 CLIP 内部，我们发现跨越人类视觉词汇很大一部分的高层概念——地理区域、面部表情、宗教图像、名人等等。通过探测每个神经元对下游的影响，我们能一窥 CLIP 是如何完成分类的。

## CLIP 中的多模态神经元

我们的[论文⁠(opens in a new window)](https://distill.pub/2021/multimodal-neurons/) 建立在近十年解读卷积网络的研究之上，[3](https://openai.com/index/multimodal-neurons/#citation-bottom-3), [4](https://openai.com/index/multimodal-neurons/#citation-bottom-4), [5](https://openai.com/index/multimodal-neurons/#citation-bottom-5), [6](https://openai.com/index/multimodal-neurons/#citation-bottom-6), [7](https://openai.com/index/multimodal-neurons/#citation-bottom-7), [8](https://openai.com/index/multimodal-neurons/#citation-bottom-8), [9](https://openai.com/index/multimodal-neurons/#citation-bottom-9), [10](https://openai.com/index/multimodal-neurons/#citation-bottom-10), [11](https://openai.com/index/multimodal-neurons/#citation-bottom-11), [12](https://openai.com/index/multimodal-neurons/#citation-bottom-12) 起点是一个观察：许多经典技术可以直接应用于 CLIP。我们用两种工具理解模型的激活：*特征可视化（feature visualization）*[6](https://openai.com/index/multimodal-neurons/#citation-bottom-6:2), [5](https://openai.com/index/multimodal-neurons/#citation-bottom-5:2), [12](https://openai.com/index/multimodal-neurons/#citation-bottom-12:2)——通过在输入上做基于梯度的优化来最大化神经元的激发；以及*数据集样本*[4](https://openai.com/index/multimodal-neurons/#citation-bottom-4:2)——查看数据集中使某个神经元最大激活的图像的分布。

用这些简单技术，我们发现 CLIP RN50x4（按 EfficientNet 缩放规则放大 4 倍的 ResNet-50）中绝大多数神经元都容易解读。这些神经元看起来正是"多面神经元（multi-faceted neurons）”[11](https://openai.com/index/multimodal-neurons/#citation-bottom-11:2) 的极端例子——只是抽象层级更高，响应多个不同的情形。

Loading...

确实，我们惊讶地发现许多这样的类别似乎在呼应颞叶内侧的神经元——那是在植入颅内深度电极的癫痫病人身上记录到的。其中包括响应情绪的神经元[17](https://openai.com/index/multimodal-neurons/#citation-bottom-17)、动物[18](https://openai.com/index/multimodal-neurons/#citation-bottom-18) 和名人[1](https://openai.com/index/multimodal-neurons/#citation-bottom-1:2)。

但我们对 CLIP 的探究揭示了更多奇异而精妙的抽象，包括看起来会计数的神经元 [[17⁠(opens in a new window)](https://microscope.openai.com/models/contrastive_4x/image_block_4_5_Add_6_0/17), [202⁠(opens in a new window)](https://microscope.openai.com/models/contrastive_4x/image_block_4_5_Add_6_0/202), [310⁠(opens in a new window)](https://microscope.openai.com/models/contrastive_4x/image_block_4_5_Add_6_0/310)]、响应艺术风格的神经元 [[75⁠(opens in a new window)](https://microscope.openai.com/models/contrastive_4x/image_block_4_5_Add_6_0/75), [587⁠(opens in a new window)](https://microscope.openai.com/models/contrastive_4x/image_block_4_5_Add_6_0/587), [122⁠(opens in a new window)](https://microscope.openai.com/models/contrastive_4x/image_block_4_5_Add_6_0/122)]，甚至有识别数字篡改痕迹图像的 [[1640⁠(opens in a new window)](https://microscope.openai.com/models/contrastive_4x/image_block_4_5_Add_6_0/1640)]。

## 缺席的概念

虽然这一分析展示了概念的广度，我们要指出：仅停留在神经元层面的简单分析，无法完整刻画模型的行为。例如 CLIP 的作者们已证明该模型能够非常精确地定位[19](https://openai.com/index/multimodal-neurons/#citation-bottom-19)（附录 E.4，图 20），粒度细到城市乃至社区级别。事实上我们有个轶事：把个人照片跑过 CLIP 后，我们注意到 CLIP 常能认出照片是否摄于旧金山，有时甚至能认出具体社区（如 "Twin Peaks"）。

然而，尽管我们尽力寻找，并没有发现"旧金山"神经元；从归因来看，旧金山似乎也不能漂亮地分解成"加利福尼亚""城市"这样有意义的单元概念。我们相信这份信息编码在模型激活的某个地方，只是方式更罕见、更复杂——可能表现为一个方向，或某个更复杂的流形。我们认为这是进一步研究的富矿方向。

## 抽象的陷阱

CLIP 的抽象程度暴露出一条我们认为此前系统不具备的攻击向量。与许多深度网络一样，模型最高层的表示完全被这些高层抽象主导。但 CLIP 的区别在于程度——它的多模态神经元能在字面与符号之间泛化，这可能是一把双刃剑。

通过一系列精心设计的实验，我们证明可以利用这种化约式行为，把模型骗去做出荒谬的分类。我们观察到，CLIP 中神经元的激发常常可以通过它对*文字图片*的响应来控制，这提供了攻击模型的简单入口。

例如，"金融"神经元 [[1330⁠(opens in a new window)](https://microscope.openai.com/models/contrastive_4x/image_block_4_5_Add_6_0/1330)] 会对存钱罐图片响应，也会对字符串 "$$$" 响应。通过强制金融神经元激发，我们能骗模型把一只狗分类成存钱罐。

## 真实世界中的攻击

我们把这类攻击称为*排版攻击（typographic attacks）*。我们相信上述攻击远不只是学术层面的顾虑。通过利用模型稳健阅读文字的能力，我们发现哪怕是*手写文字的摄影照片*也常能骗过模型。与 Adversarial Patch[21](https://openai.com/index/multimodal-neurons/#citation-bottom-21) 一样，这种攻击在真实环境中生效；但与那些攻击不同，它只需要纸和笔。

我们还认为这些攻击可能以更隐蔽、不显眼的形式存在。一张图交给 CLIP 后，会以许多微妙而精细的方式被抽象，而这些抽象可能对常见模式过度抽象——过度简化，并因此过度泛化。

## 偏见与过度泛化

我们的模型尽管是在经过筛选的互联网子集上训练的，仍然继承了后者大量未经检查的偏见与关联。我们发现许多关联看似无害，但也发现了若干 CLIP 持有的关联可能造成表征性伤害的情形，比如贬低某些个人或群体。

例如，我们观察到一个"中东"神经元 [[1895]⁠(opens in a new window)](https://microscope.openai.com/models/contrastive_v2/image_block_4_2_Add_6_0/1895) 与恐怖主义有关联；还有一个"移民"神经元 [[395]⁠(opens in a new window)](https://microscope.openai.com/models/contrastive_v2/image_block_4_2_Add_6_0/395) 会对拉丁美洲响应。我们甚至发现一个既对深色皮肤人群、也对大猩猩激发的神经元 [[1257⁠(opens in a new window)](https://microscope.openai.com/models/contrastive_4x/image_block_4_5_Add_6_0/1257)]，与其他模型中我们认为不可接受的早期照片标签事故如出一辙[22](https://openai.com/index/multimodal-neurons/#citation-bottom-22)。

这些关联给此类强大视觉系统的应用带来了明显的挑战。[A](https://openai.com/index/multimodal-neurons/#citation-bottom-A) 无论是微调还是零样本使用，这些偏见与关联很可能留存在系统之中，其影响在部署时既可能显见、也可能几乎不可见。许多有偏行为可能难以事先预料，从而难以度量和纠正。我们相信这些可解释性工具能帮助实践者提前应对潜在问题——提前发现其中一些关联与歧义。

我们对 CLIP 自身的理解仍在演进，我们也还在决定是否会发布以及会如何发布 CLIP 的大版本。我们希望社区对已发布版本以及我们今天公布的工具的进一步探索，既能推进对多模态系统的普遍理解，也能帮助我们自己的决策。

## 结语

随着《Multimodal Neurons in Artificial Neural Networks》的发表，我们也放出一些自己用来理解 CLIP 的工具——OpenAI [Microscope⁠(opens in a new window)](https://microscope.openai.com/) 目录已更新，为 CLIP RN50x4 的每个神经元加入了特征可视化、数据集样本和文本特征可视化。我们还发布 CLIP [RN50x4⁠(opens in a new window)](https://github.com/openai/CLIP) 和 [RN101⁠(opens in a new window)](https://github.com/openai/CLIP) 的权重，进一步支持此类研究。我们认为这些对 CLIP 的探究只是理解其行为的冰山一角，欢迎研究社区加入，共同提升我们对 CLIP 及同类模型的理解。
