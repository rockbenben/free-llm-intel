# 多目标强化学习：面向机器人学的挑战性环境与研究邀约

## 摘要

本报告的目的有二。其一，介绍一套基于现有机器人硬件、具有挑战性的连续控制任务（已集成至 OpenAI Gym）。任务包括使用 Fetch 机械臂的推物、滑物和抓放（pick & place），以及使用 Shadow 灵巧手（Shadow Dexterous Hand）的手内物体操作。所有任务均为稀疏的二元奖励，并遵循多目标强化学习（RL）框架——通过额外交给 agent 一个输入来告知其要做什么。报告的第二部分提出了一套改进 RL 算法的具体研究思路，其中多数与多目标 RL 和事后经验回放（Hindsight Experience Replay）相关。
