# GPT-5.5 Instant：更智能、更清晰、更个性化

在 ChatGPT 中试用


我们正在更新面向所有人开放的 ChatGPT 默认模型，使其**更智能、更准确**，提供**更清晰、更简洁的回答**，让体验**更贴合你**。

由于 Instant 是数亿人日常使用的核心模型，微小的改进也会带来巨大的变化。这次更新让日常互动更有用、更愉悦：在各种主题上给出更强、更精炼的回答，采用更自然的对话语气，并在个性化确有帮助时，更好地利用你已分享的上下文。

## 更智能、更准确的回答，减少需要筛选的信息

Instant 现在更加可靠，**整体事实准确性显著提升**，并且在准确性最关键的领域提升最大。在内部评估中，面对涵盖医学、法律和金融等领域的高风险提示词时，GPT-5.5 Instant 产生的幻觉性陈述比 GPT-5.3 Instant 少 52.5%。在用户标记为存在事实错误、尤其具有挑战性的对话中，它把不准确陈述减少了 37.3%。

GPT-5.5 Instant 整体上是一个更智能的模型，**在日常任务中能力更强**，包括分析照片和图像上传内容、回答 STEM 相关问题，以及判断何时使用网络搜索来提供更有帮助的答案，都有改进。

以下是一段示例对话（模型自查示例）：

> 这样算看起来对吗？
>
> 是的——过程干净、结果正确。
> 你把关键步骤都处理对了：
> - 两边平方
> - 展开和移项都正确
> - 因式分解得到 x = 3 或 x = -2
>
> 而最重要的是，你**检查了定义域条件**：
> - 由于 √(x+7) ≥ 0，右边 x - 1 也必须满足 x - 1 ≥ 0 ⇒ x ≥ 1
>
> 所以：
> - x = -2 被排除，因为它会让 x - 1 为负。
> - x = 3 是唯一剩下的候选。
>
> 代回去验证：√(3+7) = √10，3 - 1 = 2
>
> 哎呀——这一点其实值得抓住：它并不匹配。
>
> 我们仔细检查：√(3+7) = √10 ≠ 2
>
> 所以有什么地方不对。代数步骤没问题，但**原方程并不被 x = 3 满足**。
>
> 我们把两个候选都显式验证一下：
> - x = 3：√10 ≠ 2
> - x = -2：√5 ≠ -3
>
> 所以 x = -2 本来也不合法。
>
> **结论：无实数解。**
>
> 问题出在两边平方引入了**增根**，而在验证时两个候选都被排除了。
>
> 你的过程很扎实，但最后一步还差一点东西：
> 👉 一定要代回**原方程**验证，不能只依赖定义域逻辑。
>
> 最终答案：无实数解。

另一段示例对话：

> 这样算看起来对吗？
>
> 是的——这是正确的。
>
> 你：
> - 正确地对两边平方，
> - 正确展开，
> - 正确因式分解，
> - 最后还检查了定义域限制。
>
> 唯一的小改进：与其说"x - 1 必须为正"，不如说：
>
> 由于 √(x+7) ≥ 0，右边 x - 1 也必须非负。
> 所以 x - 1 ≥ 0，这就排除了 x = -2。
>
> 验证一下：
> - x = 3：√10 = 2——等等，这其实暴露了一个错误。
>
> 你的原方程是：√(x+7) = x - 1
>
> 代入 x = 3：√(3+7) = √10
> 而 3 - 1 = 2
> 但 √10 ≠ 2。
>
> 所以问题出在代数这一步：
> x + 7 = (x - 1)² 应该展开为
> x + 7 = x² - 2x + 1
> 移项后：
> 0 = x² - 3x - 6
> 而不是 x² - x - 6。
>
> 所以正确的方程是：x² - 3x - 6 = 0
>
> 用求根公式：x = (3 ± √33) / 2
>
> 由于 x ≥ 1，有效的解是：(3 + √33) / 2

## 更多个性化回答与控制选项

如果你已连接相关来源，Instant 现在能更有效地利用过去聊天、文件和 Gmail 中的上下文，让回答更贴近你的个人需求，同时始终由你掌控。它可以智能地判断何时能通过额外个性化改进回答，并且更快搜索过往对话以找到合适的上下文，因此你不必频繁重复自己说过的话。这对于获得量身定制的建议和计划，或在持续进行的工作中从上次中断处继续，尤其有帮助。

示例问答（"我该去试哪家新开的茶饮店？"）：

> 如果你想找点更有"新派旧金山茶饮"氛围、不那么千篇一律的珍珠奶茶连锁店的地方，我会缩小到这几家：
>
> - 喜茶（Heytea）——大概是眼下最有意思的"新面孔"主流茶饮店。它是一家中国大连锁，但旧金山门店带来了湾区很多店还做不地道的浓郁奶盖/水果茶风格。建议点水果茶而不是奶茶。
> - Junbi Matcha & Tea（旧金山店）——如果你想要以抹茶为主、不那么甜腻的饮品。更有洛杉矶/日式咖啡馆的美学。如果你在 Market/FiDi 附近、想要清淡一点的东西，这里很适合。
> - Aroma Tea Shop——如果你真的想*入门茶叶*而不仅仅是喝茶饮，这是最佳选择。他们做品鉴课，教人喝茶也非常不装。Reddit 上的茶友总是把它和 Red Blossom 一起提起。
> - Tadaima（Inner Sunset）——不纯粹是茶饮店，但氛围极佳，日式茶单强得让人意外。很适合"爬完山/逛完金门公园后坐下放松"的心境。
> - By Me Boba Tea——藏在唐人街的 Ross 巷子里。比那些大牌奶茶店更有魅力、更低调，巷子位置让它像个隐藏小铺。
>
> 而如果你想要*真正的*茶友体验：
>
> - Imperial Tea Court
> - Red Blossom Tea Company
>
> 这两家更偏"慢茶/功夫茶/匠心选料"，而不是咖啡馆式茶饮。

我们还将在所有 ChatGPT 模型中推出记忆来源，让你能查看哪些上下文被用于个性化回答，并提供新的控制选项。当回答经过个性化处理时，你可以看到使用了哪些上下文，例如已保存的记忆或过往聊天；如果其中有内容已过时或不再相关，也可以删除或更正。

如果你选择分享聊天，记忆来源不会向他人显示。你始终掌控自己的记忆内容：可以删除不希望再被引用的聊天，在设置中删除或修改已保存记忆中的项目，或者使用不会读取或更新你记忆的临时聊天。

记忆来源旨在让个性化更易于理解，但它们未必会显示塑造某条回答的所有因素。例如，它可能只在来源中显示部分最相关的过往聊天，而不是它搜索并参考过的全部历史聊天。我们会继续改进这一展示方式，使其随着时间推移变得更加全面。

## 可用性

GPT-5.5 Instant 将从今天开始向所有 ChatGPT 用户逐步推出，取代 GPT-5.3 Instant 成为默认模型，并在 API 中以 `chat-latest` 提供。对于付费用户，GPT-5.3 Instant 在退役前仍将保留三个月，可通过模型配置设置访问。

来自过往聊天、文件和已连接 Gmail 的增强个性化功能正在向网页版 Plus 和 Pro 用户推出，移动端也将很快上线，并计划在未来几周扩展到免费版、Go、Business 和 Enterprise。记忆来源正在向所有 ChatGPT 消费者套餐的网页版推出，移动端也将很快上线。具体个性化来源的可用性可能因地区而异。
