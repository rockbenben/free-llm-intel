# Basis 把 OpenAI 模型进步变成可信 agent，为会计行业扩容

基于 OpenAI o3、o3-Pro、GPT-4.1 和 GPT-5 构建，Basis 的 AI agent 帮助会计事务所节省多达 30% 的时间，扩大咨询与增长所需的产能。

有些初创公司用 AI 解决某个时点的问题；另一些则构建随 AI 进步而变好的系统。[Basis](https://www.getbasis.ai/)属于后者。

Basis 创立于 2023 年，为头部会计事务所构建 AI agent——专为以这些任务所需的可靠性与深度承担结构化会计工作而设计。团队使用 OpenAI o3、o3-Pro、GPT-4.1 和 GPT-5 驱动 AI agent，帮助会计事务所自动化对账、分录和财务摘要等重复任务，同时让会计师对决策如何做出保有完全的可见性与过程控制权。结果是最高 30% 的时间节省，以及面向高杠杆工作（如客户咨询和承接新业务）的产能提升。

随着 OpenAI 模型的演进，Basis 把这些改进复利式积累。每次新发布都扩展 agent 能处理的任务范围，提升推理质量、加快复核，并解锁更复杂的工作流。

“我们从第一天起就与 OpenAI 合作，”Basis 联合创始人 Mitchell Troyanovsky 说。“每次模型改进都拓宽我们 agent 能承担的工作。随着推理能力提升，我们解锁更复杂、运行更长的工作流，并赋予 agent 更大的自主权。”

## 把会计任务路由给合适的 OpenAI 模型

Basis 把会计视为一套工作流系统，每个工作流都有自己的上下文与复杂度。为支撑这一点，团队构建了多 agent 架构，为合适的工作分配合适的 OpenAI 模型。

每个任务都从一个监督 agent 开始——最初基于 OpenAI o3 构建，现已迁移到 GPT-5——它协调整个过程：依据任务、复杂度、延迟需求和输入类型，把步骤路由给专门的子 agent。GPT-5 是 Basis 迄今评估过的在推理、一致性和可解释性上最强的模型，非常适合在最少监督下引导 agent 完成高上下文的工作流。

子 agent 由多种模型驱动，选择依据是一套内部基准，对每个模型的关键能力与特性打分。在对速度敏感的交互中，比如复核中途的澄清提问或即时反馈，Basis 依赖 GPT-4.1。

在更复杂的场景中——如解读异常交易模式、解决模糊分类，或管理月末结账这类多步骤流程——Basis 的 agent 再次依赖 GPT-5 的深度推理能力。

这种编排让 Basis 能随着模型能力增长持续提升任务覆盖与准确率。

## 用 OpenAI 推理验证 agent 输出

在会计领域，自动化只有在可复核时才最有用。Basis 的 agent 独立行动，但通过中央层共享上下文，呈现假设、数据来源和每个决策背后的逻辑。Basis 最初依赖 OpenAI o3-Pro 在各工作流中扩展推理，随后在 GPT-5 发布后迁移到它，看中其推理结构化流程、并解释结论如何得出的能力。

以一条会计分录为例。监督 agent 审阅支持材料、检索数据、引用共享上下文与最佳实践，并协调子 agent 完成工作。会计师看到的不仅是分录，还有清晰的解释：用了什么数据、为什么那样映射、系统对其推荐的置信度如何。

“我们所做的一切都依赖推理，”Troyanovsky 指出。“这正是 OpenAI 的模型——尤其是 GPT-5——如此关键的原因。通过把 test-time compute 扩展到早期模型无法支持的程度，同时仍暴露模型的推理过程，我们能给出解释，让客户对正在发生的事既有可见性又有控制权。”

这种推理也支撑了监督 agent 按上下文精确路由任务的能力。随着系统成熟，Basis 从任务自动化迈向了真正的工作流派发。Function calling 推动了这一步，让 agent 能完成——而不只是提议——对账、分录等多步骤流程，其方式贴合会计师实际的思考与工作路径。

## 以推理与可复核性驱动模型基准测试

每次新模型发布，Basis 团队都会在真实会计工作流上运行详细基准，不仅评估准确率，还评估模型能多清晰地解释其推理。这帮助团队决定各类任务依赖哪些模型、以及 agent 何时可以安全地承接新工作流。GPT-5 是 Basis 技术栈中迄今最强的模型，凭借在并行工具调用和高级推理上的表现，非常适合需要深度与精确的工作流。

GPT-5 表现突出的一个领域是并行工具调用——这是 Basis agent 在单个工作流内协调多个结构化动作的关键能力。在 Basis 的工具调用基准（测试模型同时启用代码解释器和网页搜索、并行使用多个工具的能力）上，GPT-5 取得了 100% 的成功率，同时在所有推理基准上领先其他模型。

GPT-5 提供了他们规模化所需的性能，部分归功于与 OpenAI 团队的紧密协作。在整个开发过程中，Basis 分享了真实案例与边缘情况，并贡献反馈，帮助塑造模型在生产环境中的行为。

“OpenAI 的模型在性能和部署速度上一贯保持领先，”Troyanovsky 说。“推理能力与易用性的结合，让我们的架构成为可能。也正是这种进步让 OpenAI 成为如此有价值的伙伴。我们不只是对模型改进做出反应，我们也在帮助推动它们。”

## 与 OpenAI 一起扩展信任，而不只是任务

如今，Basis 服务着美国相当比例的大型会计事务所。使用 Basis 的事务所平均报告 30% 的时间节省，并随着信任增长不断扩大 agent 的职责。更重要的是，他们正在收回服务客户、探索新业务领域、深化咨询关系的产能。

“OpenAI 在这场转变中起了关键作用，”Troyanovsky 说。“他们的模型不只是性能好，还塑造了我们如何构建、构建什么。随着模型演进，我们 agent 能力边界也在扩展，进而会计师能做到的事也在扩展。”
