Perplexity 使用 Astra 编写沟通内容、修改软件并监控生产系统，而且与使用早期模型相比，所需过问的频率大幅降低。

作为一款由 AI 驱动的答案引擎，Perplexity 高度重视搜索和准确性。因此，处理海量信息的能力至关重要。联合创始人兼首席战略官 Johnny Ho 指出，模型的代码编写能力每提升一次，Perplexity 的搜索引擎也会随之改进。模型能够编写更出色的程序，搜索网络和内部信息，并将其高度精炼地汇总。

但 Johnny 表示，真正的挑战是如何将这些信息能力应用于现实系统。GPT‑6 Astra 让这一切变得更加容易。

> “我们可以让模型编写沟通内容、修改现实系统并监控生产软件，而前几代模型无法做到这些。”

—Johnny Ho，Perplexity 联合创始人兼首席战略官

## 让模型完成测试

对 Johnny 而言，AI 最实用的应用之一就是测试代码。由于手动测试时间有限，他会让 GPT‑6 Astra 围绕应用构建一个小型测试程序。

模型会生成与其他服务所发送内容相仿的真实响应，例如语言模型 API 或连接器的响应。模型通过代替这些服务，检查应用如何响应，并从头到尾测试整个工作流。

> “我们确实能够放心地让它处理完整的端到端系统，而且与使用前几代模型时相比，我们过问的频率低得多。”

—Johnny Ho，Perplexity 联合创始人兼首席战略官
