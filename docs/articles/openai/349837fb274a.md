# OpenAI Fellows 2018 夏季期：最终项目

我们的首期 OpenAI Fellows 已圆满结束：六位学员在为期 6 个月的学徒训练中，从机器学习新手成长为 OpenAI 的核心贡献者。

在这段时间里，我们看到理论物理、生物工程等其他科学领域的专业素养如何迸发洞见、推动 AI 研究前行。全部 6 位 Fellow 都撰写或参与了论文，并在嵌入 OpenAI 研究团队期间完成了探索全新研究想法的项目。

我们下一期 Fellow 的研究项目正在进行，我们也在遴选[下一批学员⁠（在新窗口中打开）](https://blog.openai.com/openai-fellows-interns-2019/)。我们同样高兴地欢迎多位 Fellow 以全职技术人员身份正式加入 OpenAI。
