# DALL·E 3 现已登陆 ChatGPT Plus 与 Enterprise

我们构建了一套安全缓解组合，让 DALL·E 3 具备更大范围发布的条件，并分享我们在溯源（provenance）研究上的进展。

## ChatGPT 中的 DALL·E 3

ChatGPT 现在可以通过一段简单对话创作独一无二的图像——这一新功能今天起向 Plus 和 Enterprise 用户开放。描述你脑海中的画面，ChatGPT 会提供一组视觉方案供你打磨和迭代，把它变为现实。你可以直接在对话中要求修改。其背后是我们最强的图像模型 [DALL·E 3](https://openai.com/index/dall-e-3/)。

## 研究

DALL·E 3 是多项研究进展的集大成之作，既有 OpenAI 内部的，也有外部的。与前代相比，DALL·E 3 生成的图像不仅更具视觉冲击力，细节也更清晰。DALL·E 3 能够可靠地渲染复杂细节，包括文字、手和面孔。此外，它尤其擅长响应长而详细的提示词，并支持横版和竖版两种画幅比例。这些能力来自训练一个最先进的图像描述生成器（image captioner），为我们训练模型所用图像生成更好的文字描述。DALL·E 3 再基于这些改进后的描述训练，从而得到一个更加留意用户所给描述文字的模型。这一过程的更多细节见我们的[研究论文](https://cdn.openai.com/papers/dall-e-3.pdf)。

## 负责任开发与部署

我们使用多层安全体系来限制 DALL·E 3 生成潜在有害图像的能力，包括暴力、成人或仇恨内容。安全检测会在用户提示词以及生成图像呈现给用户之前对其运行。我们还与早期用户和专业红队人员合作，识别并弥补新模型能力带来的安全体系覆盖缺口。例如，反馈帮助我们找到了血腥内容生成（如色情图像）的边缘案例，并对模型生成"足以误导人的图像"的能力做了压力测试。

在为 DALL·E 3 部署所做的准备工作中，我们还采取措施降低模型生成在世艺术家风格内容、公众人物图像的可能性，并改善生成图像中的人群代表性。有关 DALL·E 3 大规模部署准备工作的更多详情，请阅读 [DALL·E 3 系统卡](https://openai.com/index/dall-e-3-system-card/)。

用户反馈将持续帮助我们改进。ChatGPT 用户可以用旗帜图标向我们的研究团队反馈不安全输出，或与用户给定提示词不符的输出。倾听多元广泛的用户社区、获得真实世界的理解，对负责任地开发和部署 AI 至关重要，也是我们使命的核心。

我们正在研究和评估一版溯源分类器（provenance classifier）的初始版本——这是一种新的内部工具，可帮助我们判断图像是否由 DALL·E 3 生成。在早期内部评估中，对未经修改的图像，它识别"是否由 DALL·E 生成"的准确率超过 99%；当图像经历过常见修改（如裁剪、缩放、JPEG 压缩，或在生成图像的小部分上叠加文字或从真实图像剪下的元素）时，准确率仍保持在 95% 以上。尽管内部测试结果强劲，该分类器只能告诉我们图像"很可能"由 DALL·E 生成，还不能支持决定性结论。这一溯源分类器未来可能成为一系列技术中的一种，帮助人们判断音频或视觉内容是否由 AI 生成。这是需要 AI 价值链各方协作的挑战，也包括面向用户分发内容的平台。我们预期会在这个工具如何工作、最适用于何处等方面收获大量认识，并随时间改进我们的方案。

## 创作控制

DALL·E 3 被设计为会拒绝"以某位在世艺术家的风格生成图像"的请求。我们还为创作者提供[选择退出](https://share.hsforms.com/1_OuT5tfFSpic89PqN6r1CQ4sk30)的选项，让其作品不参与我们未来图像生成模型的训练。
