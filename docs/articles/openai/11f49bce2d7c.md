# Paf 工程团队创建 85 个自定义 GPT，大幅提升开发者生产力

Paf 在全公司范围内采用了 ChatGPT Enterprise，工程师们每天使用自定义 GPT 加速日常开发任务。Paf 还将 ChatGPT Enterprise 集成进 grit:lab 编程学院（gritlab.ax），从第一天起就以 AI 增强、系统架构师式的思维培养下一代软件开发人员。除了面向开发者与 grit:lab 学员的广泛用例之外，Paf 70% 的员工都在积极使用 ChatGPT Enterprise，覆盖财务、人力资源、市场和客户支持等业务团队。

## 评估多种 AI 模型

Paf 是一家国际游戏公司，1966 年由红十字会、救救儿童组织（Save the Children）和 Folkhälsan 在奥兰群岛创立，是负责任博彩行业的领导者。Paf 拥有来自 29 个国家的约 315 名员工，成立以来已为社会贡献超过 4.475 亿欧元。

作为一家立志站在技术浪潮前沿的组织，Paf 很早就认识到 AI 的变革潜力。当生成式 AI 开始受到关注时，公司迅速采用并评估多种 AI 系统，以理解这项技术如何推动其员工和业务运营前进。

在寻找理想生成式 AI 方案的工程中，Paf 尝试过 LLAMA、Claude 和 GPT‑4。当团队进行正面对比的准确性与成本比较时，GPT‑4 比竞品准确 25%，且价格并不更高。Paf 决定采用 GPT‑4 作为其 AI 方案。

## 创建自定义 GPT，精简开发流程

Paf 向 100 名开发者的整个团队推出了 ChatGPT Enterprise，如今视其为日常任务不可或缺的工具。“我每天用 ChatGPT 20 次，做样板代码生成或学习新编程语言之类的任务，”前端开发者 Krista Koivisto 说。除把 ChatGPT Enterprise 用于通用编码辅助外，工程团队还创建了 85 多个自定义 GPT 来支持特定用例。

工程团队最喜爱的自定义 GPT 应用之一，是一**套专门的编码 GPT**，帮助精简从后端基础设施创建到前端组件生成的整个开发流程：

- **Swagger GPT**：按照 Paf 的编码标准，把 Swagger JSON API 定义转换为 TypeScript 服务端点定义。
- **TypeScript GPT**：使用端点定义编写后端服务代码，复用现有的会话校验函数。
- **GraphQL Nexus GPT**：生成 GraphQL Nexus schema，集成现有辅助函数以与前端交互。
- **Relay GPT**：基于 GraphQL Nexus schema 创建用于与后端通信的 React Relay hooks。
- **React GPT**：按照 Paf 的 React 与 TypeScript 风格指南及核心组件库编写 React 组件。

“专注型 GPT 避免让模型负载过重，也能抑制幻觉，”Koivisto 说。“我们能用少得多的努力自动生成可工作的样板实现。”通过把定制 GPT 串联起来而非依赖通用模型，Paf 的开发者可以快速生成准确、标准化的应用流程与 API，几乎实现自动化。

## 赋能每位工程师成为系统架构师

基于开发团队自定义 GPT 的成功，Paf 已将 ChatGPT Enterprise 集成进 grit:lab 编程学院，加速 65 名有志开发者的培训。Grit:lab 学员把 ChatGPT 用于各种编码相关任务，包括：

- 理解新的编程概念
- 高效调试代码错误
- 学习不同语言的语法与结构
- 快速生成测试数据

这种 AI 增强的软件开发方式正在造就一类新型软件开发人员——他们从起步阶段就拥有更多系统架构师的知识。“借助 ChatGPT，初级开发者能在更高、更系统的层面上思考，”DevOps 工程师 Kim Grippenberg 说。她指出，无论是 grit:lab 学员还是 Paf 的初级开发者，在 AI 辅助下的成长速度都快了数年。开发者不必再纠缠于语法错误和编码基础，而可以专注于整体应用与系统设计。

## ChatGPT 产出相当于 12 名员工

未来一年，Paf 计划把 ChatGPT Enterprise 与 OpenAI API 全面集成到所有流程中。“AI 会留下来，要么你在火车上，”首席技术官 Fredrik Wiklund 说，“要么你站在站台上，看着它开走。”公司设想 GPT 最终承担更多编码任务，如编写、测试和部署软件，把开发者解放出来专注于更高层次、系统层面的工作。

这种 AI 增强的方式将让 Paf 以接近远大于自身的公司的速度创新。通过把生成式 AI 融入业务每个环节，Paf 将最大化其对员工、客户和所服务社区的积极影响。

“我们估计 ChatGPT 完成了相当于 12 名全职员工的工作量，”Wiklund 评论道。“它对我们业务的影响超出了预期，而这只是开始。”
