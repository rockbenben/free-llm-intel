# 推出面向金融服务的 ChatGPT

专为金融服务打造的前沿智能



我们推出面向金融服务的 ChatGPT。这是一种量身打造的“ChatGPT工作”体验，将内置金融数据与 [GPT‑6 Astra⁠](https://openai.com/index/gpt-6-astra/) 的推理能力相结合，帮助团队开展研究、构建财务模型并制作定制客户材料。

这款产品由我们与 Morgan Stanley 和 Evercore 的设计合作共同塑造。此次合作让我们能够精准识别 OpenAI 可以为金融机构解决的重大难题，并指导我们打造切实助力每位银行从业者日常工作的解决方案。

Daloopa、PitchBook、LSEG News 和 Crunchbase 等提供商的内置优质数据，消除了使用 MCP 连接器和访问数据时的难题。这些数据由 OpenAI 编制索引并托管，以提高准确性并支持精细引用等新功能，让银行从业者可以追溯数字和论断的来源，并随着分析推进核查依据。

产品还原生提供包括 GPT‑6 Astra 在内的先进前沿智能，并将在新模型发布后持续提供开箱即用的最新模型。在 ChatGPT 企业级安全与治理控制的支持下，公司还可以集中管理访问权限和数据连接。

## 数据是所有金融分析的基础

面向金融服务的 ChatGPT 汇集团队所需的金融数据，并提供符合专业预期的详尽信息。我们纳入了优质金融数据，简化了与现有提供商的连接，并提升了 MCP 性能。

*面向金融服务的 ChatGPT 汇集内置数据、已连接的数据源和金融分析工作流程。*

### 优质金融数据，开箱即用

面向金融服务的 ChatGPT 收录 Daloopa、PitchBook、LSEG News 和 Crunchbase 等提供商的数据集，涵盖财报电话会议记录、财务报表、公司基本面、非上市公司等内容。

团队可以立即使用这些数据集，无需另行协商合同或设置连接器。我们在 OpenAI 基础设施上为这些数据编制索引并进行托管，从而改进检索、延迟表现以及产品体验中的数据呈现方式。

对于开展损益标准化分析的银行从业者而言，这意味着能够查看调整后 EBITDA 背后的调节表和附注，了解排除了哪些成本，并决定如何将其用于估值。

合作伙伴是这项工作的核心。随着数据覆盖范围扩大，我们将继续加深模型对这些数据集的理解。我们将对模型进行后训练，使其能够像顶尖分析师一样查找、解读和使用这些数据。

*将数字和论断追溯到具体表格与段落，并突出显示辅助信息以供核查。*

### 更可靠地连接金融数据提供商

要通过 MCP 连接器高效接入数据提供商，并非易事。我们重点优化了金融服务领域最常用的一批 MCP 连接器，使其可以直接在产品中使用。这样，团队便能减少排查请求问题的时间，将更多精力投入分析。

除此之外，我们的连接器生态系统还涵盖 50 多种连接器，包括 Datasite、Box、Preqin、FactSet 和 Intapp。

## 使用 GPT‑6 Astra 开展金融分析

在金融服务工作所需的三项核心能力上，GPT‑6 Astra 均达到业界先进水平：信息检索、金融推理和成果生成。

它可以浏览并理解金融文档中的数字、表格及其辅助附注。它可以接收输入、运行金融分析并得出结论。它还能整合所有这些工作，准确生成文档、电子表格和幻灯片。

基准测试

我们在产品中构建了基础能力，使其能够跨多个来源开展研究、追踪不同时期的数字，并解读公开数据中的注释。分析完成后，团队可以制作交互式图表和可视化内容。

*通过交互式图表比较公司业绩，并可查看底层数据和来源。*

## 将分析转化为团队可用的成果

在面向金融服务的 ChatGPT 中，管理员可以通过专用管理页面发布 Excel、Word 和 PowerPoint 模板。配置公司模板和风格指南后，团队可以按照公司的格式与风格，将分析转化为估值模型、研究报告和推介材料。

*向使用公司模板的团队发布这些模板。*

## 依托值得信赖的安全与治理开展工作

保护重大非公开信息和客户机密对金融机构至关重要。面向金融服务的 ChatGPT 建立在 ChatGPT Enterprise 的 SAML SSO、SCIM 预配和基于角色的访问控制之上。

默认情况下，贵公司的业务数据不会用于训练我们的模型。数据在静态存储和传输过程中均经过加密，管理员还可以配置工作空间的数据保留期限。合规团队可以通过 OpenAI 合规平台导出受支持的工作空间日志，并将其纳入现有审计和调查工作流程。

公司可以按角色管理技能和应用的访问权限，并启用或停用应用中受支持的读取和写入操作。还可以创建多个工作空间，以实施信息隔离。

## 拓展行业的可能性

面向金融服务的 ChatGPT 是我们服务全行业客户的一种方式，但我们也认识到，要满足金融行业的需求，还需要多种解决方案。OpenAI 长期以来一直与创新者携手，开拓新颖的 AI 解决方案。金融服务公司和开发者可以使用我们的 API，针对自己最了解的需求构建专用应用。OpenAI 提供前沿模型以及将其投入实际应用的能力。金融机构、数据提供商和软件合作伙伴则带来专业知识、可信信息和客户关系。
