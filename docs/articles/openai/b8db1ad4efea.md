# OpenAI 与微软

我们正在与微软合作，开始把大部分大规模实验放到 Azure 上跑。

Illustration: Justin Jay Wang

Loading…

我们正在与微软合作，开始把大部分大规模实验放到 Azure 上跑。这会让 Azure 成为 OpenAI 深度学习和 AI 使用的主要云平台，让我们能开展更多研究并把成果与全世界分享。

加速我们进展的最重要因素之一是获得更多、更快的计算机；对像强化学习和 [生成模型⁠](https://openai.com/index/generative-models/) 这样的新兴 AI 技术尤其如此。Azure 通过构建针对深度学习优化的硬件配置给我们留下了深刻印象——他们在规模化下提供带 InfiniBand 互联的 K80 GPU。他们的路线图同样令人兴奋——不久之后应当会把 Pascal GPU 引入他们的云。

未来几个月，我们会使用数千至数万这种机器，同时增加我们运行的实验数量和所训练模型的规模。

我们会把这段合作的成果与所有人分享：除了发表我们的研究结果，我们还会持续发布开源软件，让人们更方便地在云上运行大规模 AI 负载。我们也会持续给微软团队反馈，让 Azure 的能力能跟得上我们对 AI 的理解。

能与另一家同样坚信 [让 AI 使用权普惠⁠(opens in a new window)](https://news.microsoft.com/features/democratizing-ai/) 之重要性的机构合作，非常令人振奋。我们期待通过这段合作加速整个 AI 社区。
