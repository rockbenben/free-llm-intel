# OpenAI 前沿模型和 Codex 现已在 AWS 上可用

帮助企业通过现有的安全、治理和部署工作流将 AI 投入生产

开始在 AWS 上使用 OpenAI


如今，OpenAI 前沿模型和 Codex 在 AWS 上普遍可用，为数百万 AWS 客户开辟了一条新路，使他们能够通过已用于业务运营的平台使用 OpenAI 进行构建。

对于企业来说，这消除了采用人工智能的最大障碍之一：通过现有的安全、合规、采购、计费和治理工作流程，将前沿人工智能应用到生产中。客户现在可以将 OpenAI 功能引入 AWS 环境，并采用其团队已经信任的控制方式，帮助他们更快地从评估进入实际部署。

## 将 OpenAI 功能引入 AWS 环境

OpenAI on AWS 使企业能够获得 OpenAI 的前沿能力、熟悉的 AWS 运营模式以及更快的生产路径。它们有两种方式：

[**Amazon Bedrock 上的 OpenAI 模型**](https://aws.amazon.com/bedrock/openai/)允许团队使用 AWS 原生安全和治理控制来构建 AI 应用程序。

[**Amazon Bedrock 上的 Codex**](https://developers.openai.com/codex/amazon-bedrock) 将OpenAI 领先的软件工程智能体（每周有超过 500 万人使用）引入 AWS，帮助团队在已经构建和发布的环境中编写、审查、调试和更新代码。

这些产品共同帮助客户以更少的摩擦采用 OpenAI，并在 AWS（商业云和政府云区域）中使用现有的最佳模型。

## 帮助客户从感兴趣到付诸实施

随着客户开始使用这些功能，AWS 路径有助于减少采购、安全审查和生产准备方面的摩擦。通过在熟悉的 AWS 环境中提供 OpenAI 功能，企业可以将更少的时间用于克服操作障碍，将更多的时间用于建设。

> “在 Amgen，我们专注于以有助于加速潜在新疗法交付的方式应用先进 AI，同时为团队配备先进工具。OpenAI 的 GPT‑5.5 和前沿模型在能力、质量和一致性方面带来了令人信服的进步，而在问题复杂且对科学准确性和决策质量标准极高的领域，这些进步至关重要。在 AWS 上提供这些模型，为我们在负责任 AI 框架内探索和扩展这些能力提供了一条重要新路径，其中包括覆盖整个企业的安全、治理和运营框架。”

— Sean Bruich，Amgen 高级副总裁兼首席技术官

> “Autodesk 是服务于设计和创造我们周围世界的人们的技术平台。建筑设计等工作流具有高度迭代性，需要团队之间的精确性、协调和持续完善。随着 OpenAI 模型和 Codex 现已在 Amazon Bedrock 上正式发布，我们的团队正在评估可扩展且安全的 AWS 基础设施上的前沿 AI 能力和 AI 驱动开发工具，如何帮助加速开发工作流，并支持客户做出更明智的决策。”

## 下一步工作，包括网络可用性

AWS 上的 OpenAI 是客户将前沿人工智能引入他们已经构建、治理和运输的环境的更广阔道路的起点。我们将继续扩大通过 AWS 提供的 OpenAI 功能，以便团队能以更少的摩擦和更大的信心从评估转向生产。

这包括 Daybreak 的未来可用性，OpenAI 的愿景是改变软件的构建和防御方式。Daybreak 包括网络模型和 Codex Security，旨在通过将安全代码审查、威胁建模、补丁验证、依赖性风险分析、检测和修复指导引入日常开发循环，帮助网络防御者更早地看到风险，更早地采取行动，并通过设计使软件更具弹性。

随着客户可以使用 Daybreak 等专业功能，AWS 可以为安全团队提供一条重要的途径，使他们能够利用已经使用的安全、治理、采购和运营框架来采用这些功能。

OpenAI 和 AWS 可以共同帮助更多组织在生产中应用先进的人工智能。
