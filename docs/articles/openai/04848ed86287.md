# OpenAI Fellows 2018 秋季班：最终项目

我们的第二期 OpenAI Fellows 已经结业。每位 Fellow 在为期 6 个月的学徒期内，从机器学习新手成长为 OpenAI 的核心贡献者。我们目前正在对下一期 OpenAI Fellows 2019 夏季班的申请进行滚动审阅。

在这段时间里，我们看到古典音乐、统计学、数学等其他科学领域的专长如何催生洞见、推动 AI 研究前进。全部 6 位 Fellow 在融入 OpenAI 研究团队期间，都[完成⁠](https://openai.com/index/openai-fellows-fall-2018/#christine)了[探索⁠](https://openai.com/index/openai-fellows-fall-2018/#jacob)[新颖⁠](https://openai.com/index/openai-fellows-fall-2018/#todor)[研究⁠](https://openai.com/index/openai-fellows-fall-2018/#mark)[想法⁠](https://openai.com/index/openai-fellows-fall-2018/#lei)的[项目⁠](https://openai.com/index/openai-fellows-fall-2018/#mikhail)。

我们也很高兴地欢迎全部 6 位秋季班 Fellow 以正式技术人员身份加入 OpenAI！

## 下一步

我们要祝贺 2018 秋季班的 Fellows 取得的杰出成果，并感谢他们对 OpenAI 的贡献。期待他们的研究继续推进！如果你想从新手成长为能产出世界级 ML 贡献的人，不妨申请我们的下一期 OpenAI Fellows（2019 年 7 月开学）。我们现已开放申请并滚动审阅，请[尽早申请⁠（在新窗口中打开）](https://jobs.lever.co/openai/f5c8d70e-c8a2-4696-82e1-635d106e649c)！
