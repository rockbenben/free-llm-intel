[JetBrains⁠（在新窗口打开）](https://www.jetbrains.com) 打造的智能软件开发工具被全球超过 1500 万工程师使用。它的产品套件包括广受欢迎的集成开发环境（IDE），比如 PyCharm、IntelliJ IDEA，以及 Kotlin 编程语言。

怀着把繁琐任务从开发者工作流中移除的使命感，JetBrains 将 OpenAI 的 API 纳入了它的 AI Assistant 产品。反响相当亮眼——77% 的开发者表示自己效率更高，55% 的人因此有更多时间专注于更有趣味的任务。

## 将 AI 嵌入开发者软件

JetBrains 的 IDE 历来包含代码补全、代码检查等功能，帮助开发者提升效率。这些功能贯穿软件开发的整个生命周期，从写代码、测代码，到在各种环境中构建项目。

这些工具基于启发式模型，聪明且懂上下文。既然 JetBrains 已经在做提供智能建议的工具，探索 AI 就是水到渠成的事——尤其在生成式 AI 近来飞速发展的背景下，像自动补全式代码补全和上下文代码建议这样的功能，正在改变开发者的工作方式。

JetBrains 看到了实现跨越式前进的机会，开发出 AI Assistant——一款把 OpenAI 的 API 集成进 JetBrains IDE 产品的新工具。

## 用 OpenAI 的 API 加速软件开发流程

JetBrains 相信，把 LLM 集成进 IDE 能为客户带来巨大价值，但想在锁定某家供应商之前先考察一番选项。

JetBrains 评估了所有主流的 LLM 供应商，最终选择 OpenAI 作为第一家 LLM 供应商，原因如下：

- **先进的推理能力：** JetBrains 发现 OpenAI 的 API 功能最智能，其中先进的推理能力尤其突出。
- **技术客户支持：** JetBrains AI 团队负责人 Vladislav Tankov 强调，OpenAI 技术团队的支持非常出色。在 JetBrains 集成过程中遇到挑战时，这份指引起到了关键作用："和我们打交道的开发者，是真正在乎我们做什么、怎么做的人。"
- **领先的技术性能：** 在 JetBrains 对各家 LLM 供应商的对比分析中，OpenAI 的 API 在延迟、准确率、吞吐量等技术指标上表现突出。

> "和我们打交道的开发者，是真正在乎我们做什么、怎么做的人。"

Vladislav Tankov，JetBrains AI 团队负责人

确定以 OpenAI 的 API 作为 LLM 供应商后，JetBrains 便得以在 AI Assistant 产品里解锁一系列能力：

- 开发者可以把写测试、给变量命名这类琐碎、缺乏创造力的任务交给 AI Assistant。
- 开发者可以用自然语言写提示词，在编写业务逻辑时获得代码建议。
- AI Assistant 能生成文档、撰写提交信息（commit message）。
- AI Assistant 能解释代码、重构代码片段。
- AI Assistant 能说明报错的含义，并给出解决问题的修复建议。

## JetBrains AI Assistant 提升开发者表现

JetBrains AI Assistant 已成为**公司 24 年历史上增长最快的产品**，客户满意度极高。使用该产品的开发者强调了：

- **空前的生产力提升：** "我做了 30 年开发。想不出有什么东西比 JetBrains AI Assistant 更能大幅提升效率。"一位受访者是这么说的。
- **花在信息检索上的时间变少：** 78% 的受访开发者表示查找信息的时间减少了，从而有更多时间投入更有趣味的任务。
- **降低切换成本：** "JetBrains AI Assistant 就在 IDE 里运行，不像别的助手还得开着浏览器。"一位工程师说，这简化了开发者工作流，让任务更容易完成。
- **效率提升：** 77% 的受访开发者表示时间利用更高效，71% 表示能更快完成任务。
- **一个头脑风暴工具：** 一位工程师强调 JetBrains AI Assistant 已成帮他摆脱卡壳的得力工具："我太喜欢了。它能缓解冒名顶替综合征，因为你随时可以问 LLM 求助。"

## 打造下一代懂上下文的 AI 编程工具

JetBrains 正在开发多项新功能，进一步加速软件开发：

- **项目结构生成：** 团队已经做出原型，能从文本提示词生成定制的项目目录。初步结果令人兴奋。
- **终端工作流自动化：** 团队认为，自动化各种必要但琐碎的常见终端任务潜力巨大。
- **与 JetBrains** [**代码洞察⁠（在新窗口打开）](https://www.jetbrains.com/datagrip/features/coding_assistance.html)**深度集成：** "我们的 IDE 非常了解用户项目的代码库，所以我们在探索把这些上下文和能力提供给 LLM 供应商，做出全新的功能。"JetBrains AI 团队负责人 Vladislav Tankov 说。
