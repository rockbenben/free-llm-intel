# 支持 Distill 创刊

我们很高兴支持 Distill 今日创刊——这是一种新型期刊，旨在出色地传播机器学习成果（无论是新成果还是已有成果）。

Distill 是一个网站及配套工具集，让人们更容易借助现代 Web 技术解释机器学习概念。例如，人们已经用这个平台探讨过 [t-SNE 算法的微妙设置](http://distill.pub/2016/misread-tsne/)、[揭秘合成图像中的棋盘伪影](http://distill.pub/2016/deconv-checkerboard/)，以及揭开 [手写生成](http://distill.pub/2016/handwriting/) 循环神经网络的黑箱。

Andrej 将担任该刊物的指导委员会成员，Greg 正在资助 [Distill 机器学习清晰度奖](http://distill.pub/prize/)，以表彰在传播机器学习及相关主题思想方面的杰出工作（发表于任何平台均可！）
