# GPT‑4o 的谄媚问题：发生了什么、我们在做什么

我们已回滚上周 ChatGPT 中的 GPT‑4o 更新，现在人们使用的是行为更均衡的早期版本。被撤下的那次更新过度讨好或过度附和——常被称为谄媚（sycophantic）。

我们正在积极测试新的修复方案。我们正改进收集与纳入反馈的方式，更重视长期用户满意度；同时引入更多个性化功能，让用户对 ChatGPT 的行为方式有更大掌控。

我们想解释发生了什么、为什么重要，以及我们如何应对谄媚问题。

## 发生了什么

在上周的 GPT‑4o 更新中，我们做了若干调整，旨在改善模型的默认个性，让它在各类任务中更自然、更有效。

在塑造模型行为时，我们从 [Model Spec⁠（在新窗口中打开）](https://model-spec.openai.com/2025-04-11.html)所列的基线原则与指令出发。我们还通过纳入用户信号——如对 ChatGPT 回答的点赞/点踩反馈——教会模型如何应用这些原则。

然而在这次更新中，我们过于聚焦短期反馈，没有充分考虑用户与 ChatGPT 的交互如何随时间演化。结果，GPT‑4o 偏向于过度支持却言不由衷的回答。

## 为什么重要

ChatGPT 的默认个性深深影响着你的体验与信任。谄媚的交互会让人不舒服、不安，甚至造成痛苦。我们没做好，正在努力把它做对。

我们的目标是让 ChatGPT 帮助用户探索想法、做出决定、构想可能性。

我们把 ChatGPT 的默认个性设计得体现我们的使命，有用、支持、尊重不同的价值观与经历。然而这些可贵品质中的每一个——比如努力有用或给予支持——都可能产生意外副作用。而每周有 5 亿人在各种文化与情境中使用 ChatGPT，单一默认设定不可能满足所有偏好。

## 我们如何应对谄媚问题

除了回滚最新的 GPT‑4o 更新，我们还在采取更多措施重新校准模型行为：

- 改进核心训练技术和 system prompt，明确引导模型远离谄媚。
- 构建更多护栏，提升[诚实与透明⁠（在新窗口中打开）](https://model-spec.openai.com/2025-04-11.html#avoid_sycophancy)——这是我们 Model Spec 中的原则。
- 扩大更多用户在部署前测试并直接反馈的途径。
- 持续扩展我们的评估，在 [Model Spec⁠（在新窗口中打开）](https://model-spec.openai.com/) 和[我们正在持续进行的研究⁠](https://openai.com/index/affective-use-study/)的基础上，未来帮助识别谄媚之外的问题。

我们还相信，用户应对 ChatGPT 的行为有更多控制权，并在安全与可行范围内，如果对默认行为不认同，可以自行调整。

今天，用户已经可以通过自定义指令等功能给模型具体指示、塑造其行为。我们还在构建更便捷的新方式。例如，用户将能够给出实时反馈以直接影响自己的交互，并从多个默认个性中选择。

此外，我们正在探索把更广泛、民主化的反馈纳入 ChatGPT 默认行为的新方式。希望这些反馈能帮助我们更好反映全世界多元的文化价值观，理解你期待 ChatGPT 如何演化——不止一次交互一次地，而是随时间演进。

感谢每一位为此发声的人。这正在帮助我们为你打造更有用的好工具。
