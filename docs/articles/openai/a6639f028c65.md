# Typeform

Typeform 借助 GPT-3.5 与 GPT-4，把在线表单演进为动态、对话式的数据收集体验。

View product


自 2012 年起，Typeform 一直在革新企业从客户那里收集信息的方式。联合创始人 David Okuniev 一直认为，表单应该尽可能引人入胜、尽可能自然。公司以"一次只问一个问题"——就像人类对话那样——的开创性做法而闻名。

在让表单更接近人类对话这件事上，Typeform 通过 [Formless](https://formless.ai/) 迈出了巨大的一步——这是一张由 AI 驱动、目前处于 beta 的平台。

Formless 代表着一种全新的数据收集方式——顾名思义，它完全不需要传统的表单结构。业务用户只需提供基本指令，包括要收集哪些信息。剩下的部分交由基于 OpenAI 的 GPT-3.5 Turbo 和 GPT-4 构建的平台完成。

在填答者一方，体验模仿一场真实的对话——下一个问题是对上一个回答的回应。而且这是双向的：填答者可以像与人交流那样，反追问自己的问题。

> "Formless 的魔法在于，我们把打造'让人愉快又极其强大的表单体验'这件事变得容易十倍——客户从未见过这样的表单——但它能做复杂的计算、条件与流转。"

David Okuniev，Typeform 联合创始人

Formless 提供了充分利用 OpenAI 技术的一系列能力，从创建与管理表单，一直到分析结果。

在设置表单时，创建者可以"训练 AI"，让它学习任何主题，以便回答与该主题相关的问题。AI 也可以个性化配置成品牌自己的语调。尤为关键的是，对话支持任意语言——平台会根据填答者浏览器的语言设置自动翻译文本。

最后，Formless 让从客户那里规模化地获取有价值的洞察变得前所未有地简单。企业可以使用平台由 AI 驱动的自然语言分析，把对话式回答转换成符合企业所需结构的任何数据。之后，借助平台的 DataPilot 功能，他们可以与 AI"聊自己的数据"、提问，并整合来自不同来源的信息。这一整套能力让品牌能够快速、轻松地对 Formless 的结果采取行动。

Formless 从零开始就构建在 OpenAI 最新的模型之上，如果没有 GPT-4，它很可能无法实现。这对 Typeform 团队是一项重要成就，而他们对 OpenAI 技术的投入并不是新事。"我们自 GPT 2.0 起就在与它合作，那时团队正在做 VideoAsk.com，"首席产品官 Oji Udezue 说，"而现在：Formless.ai。Formless 是我们革命性的新产品，让表单基本上彻底消失。这是我们'让 Web 本身更对话化'这种执念的集大成——而且我们才刚刚触及表面。"
