# Glow：更好的可逆生成模型

我们推出 *Glow*，一种使用可逆 1x1 卷积的可逆生成模型。它扩展了 [先前⁠（在新窗口打开）](https://arxiv.org/abs/1410.8516)[工作⁠（在新窗口打开）](https://arxiv.org/abs/1605.08803) 中关于可逆生成模型的研究，并简化了架构。我们的模型能生成逼真的高分辨率图像，支持高效采样，并能发现可用于操纵数据属性的特征。我们发布模型代码和一个在线可视化工具，方便大家探索并在这些结果之上继续构建。

## 动机

生成式建模是指观察数据（例如一组人脸照片），然后学习一个描述这些数据如何生成的模型。学习逼近数据生成过程需要学习数据中存在的*全部结构*，成功的模型应能合成与数据相似的输出。精确的生成模型有广泛的应用，包括 [语音合成⁠（在新窗口打开）](https://arxiv.org/abs/1609.03499)、[文本分析与合成⁠（在新窗口打开）](https://blog.openai.com/language-unsupervised/)、[半监督学习⁠（在新窗口打开）](https://arxiv.org/abs/1406.5298) 和 [基于模型的控制⁠（在新窗口打开）](https://arxiv.org/abs/1803.10122)。我们提出的技术同样可以应用于这些问题。

Glow 是一种可逆生成模型，也叫*基于流的生成模型*，是 [NICE⁠（在新窗口打开）](https://arxiv.org/abs/1410.8516) 和 [RealNVP⁠（在新窗口打开）](https://arxiv.org/abs/1605.08803) 技术的扩展。与 [GAN⁠（在新窗口打开）](https://en.wikipedia.org/wiki/Generative_adversarial_network) 和 [VAE⁠（在新窗口打开）](https://arxiv.org/abs/1312.6114) 相比，基于流的生成模型迄今在研究社区中得到的关注很少。

基于流的生成模型的优点包括：

- 精确的潜变量推断与对数似然评估。在 VAE 中，只能近似推断与某数据点对应的潜变量取值；GAN 则完全没有推断潜变量的编码器。而在可逆生成模型中，这一切无需近似即可精确完成。这不仅带来精确的推断，还使我们可以优化数据的精确对数似然，而不是它的下界。
- 高效推断与高效合成。自回归模型（如 [PixelCNN⁠（在新窗口打开）](https://arxiv.org/abs/1606.05328)）也是可逆的，但此类模型的合成难以并行化，在并行硬件上通常效率低下。而 Glow（以及 RealNVP）这类基于流的生成模型，无论推断还是合成都易于高效并行。
- 对下游任务有用的潜空间。自回归模型的隐藏层边际分布未知，使得对数据进行有效操纵更加困难。在 GAN 中，数据点通常无法直接表示到潜空间中，因为它们没有编码器，且可能对数据分布不具有完整支撑。可逆生成模型和 VAE 则没有这个问题，支持各种应用，例如数据点之间的插值以及对既有数据点的有意义修改。
- 巨大的内存节省潜力。如 [RevNet 论文⁠（在新窗口打开）](https://arxiv.org/abs/1707.04585) 所述，在可逆神经网络中计算梯度所需的内存是常数级的，而非随深度线性增长。

## 结果

与基于流的生成模型此前已发表的最佳结果 RealNVP 相比，我们使用这些技术在标准基准上取得了显著提升。

| **数据集** | **RealNVP** | **Glow** |
| --- | --- | --- |
| CIFAR-10 | 3.49 | 3.55 |
| Imagenet 32x32 | 4.28 | 4.09 |
| Imagenet 64x64 | 3.98 | 3.81 |
| LSUN（bedroom） | 2.72 | 2.38 |
| LSUN（tower） | 2.81 | 2.46 |
| LSUN（church outdoor） | 3.08 | 2.67 |

*以各数据集测试集上的每维度比特数衡量的量化表现，对比 [RealNVP 模型⁠（在新窗口打开）](https://arxiv.org/abs/1605.08803) 与我们的 Glow 模型。*

Glow 模型能够高效生成逼真的高分辨率图像。在 NVIDIA 1080 Ti GPU 上，我们的模型生成一张 256 x 256 的样本约需 130 毫秒。与 [先前⁠（在新窗口打开）](https://arxiv.org/abs/1802.05751) 的工作一致，我们发现从降低温度的模型中采样往往得到质量更高的样本。上述样本是通过将潜变量的标准差按 0.7 的温度缩放得到的。

### 潜空间插值

我们还可以在任意两张人脸之间插值：用编码器分别编码两张图像，再从中间点采样。注意，输入是任意人脸而非模型自身的样本，这为“模型对完整目标分布具有支撑”提供了证据。

### 潜空间操纵

我们可以在没有标签的情况下训练基于流的模型，然后把学到的潜表示用于下游任务，例如操纵输入的属性。这些语义属性可以是人脸的头发颜色、图像的风格、音乐的音高，或文本句子的情绪。由于基于流的模型拥有完美的编码器，你可以编码输入，分别计算具备与不具备某属性的输入的平均潜向量。两者之间的向量方向即可用来把任意输入朝着该属性方向操纵。

上述过程只需要相对少量的标注数据，且可以在模型训练完成之后进行（训练阶段不需要标签）。使用 GAN 的 [先前⁠（在新窗口打开）](https://arxiv.org/abs/1606.03657)[工作⁠（在新窗口打开）](https://arxiv.org/abs/1711.05415) 需要单独训练一个编码器；使用 VAE 的 [方法⁠（在新窗口打开）](https://arxiv.org/abs/1804.03599)[之一⁠（在新窗口打开）](https://arxiv.org/abs/1803.05428) 只保证解码器与编码器对分布内数据兼容。另一些方法直接学习表示变换的函数，如 [Cycle-GAN⁠（在新窗口打开）](https://arxiv.org/abs/1703.10593)，但每个变换都需要重新训练。

## 贡献

我们的主要贡献，也是与早期 RealNVP 工作的分歧点，是引入了可逆 1x1 卷积，同时移除其他组件，整体上简化了架构。

RealNVP 架构由两类层的序列构成：棋盘掩码层和通道掩码层。我们移除了棋盘掩码层，简化架构。通道掩码层等效于重复以下步骤：

- 沿通道维度反转顺序来置换输入。
- 沿特征维度的中线把输入分为 A、B 两部分。
- 把 A 输入一个浅层卷积神经网络，根据该网络的输出对 B 做线性变换。
- 拼接 A 和 B。

通过链接这些层，A 更新 B，然后 B 更新 A，然后 A 又更新 B，如此往复。这种二部图式的信息流显然相当僵化。我们发现把步骤（1）的反转置换改为一个（固定的)*洗牌*置换可以提升模型表现。

更进一步，我们还可以*学习*最优置换。学习置换矩阵是一个离散优化问题，不适合梯度上升。但由于置换操作只是方阵线性变换的特例，我们可以在卷积神经网络中实现这一点——置换通道等价于输入输出通道数相同的 1x1 卷积操作。于是我们用学习到的 1x1 卷积替换固定置换。1x1 卷积的权重初始化为随机旋转矩阵。如下方图表所示，这一操作带来了显著的建模改进。我们还证明，优化目标函数所需的计算可以通过权重的 LU 分解高效完成。

我们的主要贡献——可逆 1x1 卷积——带来了显著的建模改进。

此外，我们移除批归一化，改用激活归一化层（activation normalization）。这一层只做 activations 的平移和缩放，并带有[数据相关初始化⁠（在新窗口打开）](https://arxiv.org/abs/1602.07868)：给定初始的一个小批量数据即归一化 activations。这使得我们可以把小批量大小降至 1（对大图）并扩大模型规模。

## 规模

我们的架构结合各种优化技术，例如 [梯度检查点⁠（在新窗口打开）](https://github.com/openai/gradient-checkpointing)，让我们能在超出以往的规模上训练基于流的生成模型。我们使用 [Horovod⁠（在新窗口打开）](https://github.com/uber/horovod) 轻松在多台机组成的集群上训练模型；演示中使用的模型在 5 台机器、每台 8 块 GPU 上训练。借助这一配置，我们训练了拥有超过一亿参数的模型。

## 研究方向

我们的工作表明，训练基于流的模型生成逼真的高分辨率图像是可行的，且学到的潜表示可以方便地用于数据操纵等下游任务。我们建议以下几个未来方向：

- **在似然上与其他模型类别竞争。** 自回归模型和 VAE 在对数似然上优于基于流的模型，但它们的缺点分别是采样低效和推断不精确。可以把基于流的模型、VAE 和自回归模型结合起来，取长补短；这将是未来一个有趣的方向。
- **改进架构，提高计算与参数效率。** 为了生成逼真的高分辨率图像，人脸生成模型使用了约 2 亿参数和约 600 个卷积层，训练代价高昂。深度较小的模型在学习长程依赖上表现较差。使用[自⁠（在新窗口打开）](https://arxiv.org/abs/1802.05751)[注意力⁠（在新窗口打开）](https://arxiv.org/abs/1805.08318)架构，或进行[渐进式⁠（在新窗口打开）](https://arxiv.org/abs/1710.10196)训练以扩展到高分辨率，都可能让 Glow 模型的训练在计算上更廉价。

最后，如果你想在研究中使用 Glow，我们鼓励你阅读 [我们的论文⁠（在新窗口打开）](https://arxiv.org/abs/1807.03039) 了解更多细节，或查看这个 [Github 仓库⁠（在新窗口打开）](https://github.com/openai/glow) 中的代码。
