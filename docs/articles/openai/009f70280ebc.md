# OpenAI 将收购 Ona

通过安全、由客户控制的云基础设施扩展 Codex，支持软件与知识工作中长时间运行的智能体。


今天，我们宣布 OpenAI 将收购 [Ona](http://ona.com)，把其安全的云端执行与编排技术纳入我们快速扩展的 Codex 生态系统。

每周有超过 500 万人使用 Codex 来研究、分析、构建和自动化工作，较今年早些时候增长了 400%。Codex 最初是面向软件开发者的工具，如今帮助更广泛的人群从一个初始请求出发，完成复杂工作并交付最终成果。

随着 Codex 能力不断增强，其最有价值的工作正从数分钟延展到数小时甚至数天。我们认为，人们应该能够委派更具雄心的工作，而不必一直受限于工作开始时所在的那台机器。工作应能在初始会话结束后继续进行；借助 Codex，人们可以在任何地方保持连接并查看进度、提供指引、做出决策和审阅结果。

Ona 将帮助我们实现这一点。其技术提供安全、持久化的环境，让智能体能够访问推进工作所需的工具、系统和上下文。

通过将 Ona 纳入 OpenAI，我们将把 Codex 扩展到不再受单一设备或活跃会话限制的工作中，并帮助更多组织在生产环境中安全部署智能体。

## 为 Codex 提供一个持久的工作场所

多年来，Ona 一直帮助开发者将软件开发从本地机器迁移到云端。该公司已帮助 200 万名开发者在安全、可复现的云环境中工作，并支持多个双方共同的客户。

这一经验与 Codex 的下一阶段直接相关：让智能体即使在笔记本电脑合上后，仍能在客户的云环境中继续工作。

## 在生产工作流中扩展 Codex

随着组织从试验智能体转向在生产工作流中部署智能体，强大的模型只是其所需能力的一部分。

组织应能放心地让人们受益于持久的智能体式工作，因为他们知道智能体运行在满足其安全、治理和运营要求的环境中。这意味着能够控制它们在哪里运行、可以访问什么、凭据如何限定范围、活动如何记录，以及工作如何流转到审阅环节。

Ona 由客户控制的执行模型将允许智能体在组织自己的云环境中运行，同时由 OpenAI 提供驱动体验的智能和编排能力。这让组织能够更好地控制其基础设施、数据和安全边界，同时不限制 Codex 所能完成的工作。

> “智能体需要的不只是智能；它们还需要一个可信赖的工作空间。我们打造 Ona，是为了向智能体提供企业所需的云环境，其中包含上下文、控制与协作能力。加入 OpenAI 让我们能够把这一基础带入 Codex，帮助组织充满信心地部署智能体，并让人们对自己的工作拥有更大的能动性。”

—Johannes Landgraf，Ona 联合创始人兼首席执行官

> “企业需要强大的智能体，既能完成实际工作，又能满足其环境的安全与控制要求。Ona 将帮助我们让 Codex 更易于在生产工作流中安全部署，服务那些在信任和规模方面有最高标准的客户。”

—Thibault Sottiaux，OpenAI 核心产品负责人

## 未来展望

本次收购须满足惯常交割条件，包括获得所需的监管批准。在交易完成前，OpenAI 和 Ona 将继续作为相互独立的公司运营。

交易完成后，Ona 团队将加入 OpenAI，并与 Codex 团队合作，推进安全、持久的企业执行能力，帮助 Codex 扩展到全球更多企业。

我们很高兴欢迎 Ona 团队加入 OpenAI。我们将共同构建 AI 系统，帮助个人和企业创造并完成更多工作，同时满足现实部署中的安全与控制要求。我们将共同帮助工程团队在整个软件生命周期中安全地承担持续性工作，从运行测试、解决问题，到应用现代化、处理漏洞，并长期支持复杂工作流。
