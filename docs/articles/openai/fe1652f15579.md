# “腐败评论”：对反腐败基金会的批评行动

OpenAI 封禁了使用 AI 生成批评俄罗斯反腐败基金会及相关人物评论的账号。

*本案例研究最初发表于 OpenAI [2024 年 10 月](https://cdn.openai.com/threat-intelligence-reports/influence-and-cyber-operations-an-update_October-2024.pdf)报告。*

## 行为者

我们封禁了一小簇活动：使用我们的 API 生成评论，再发布到 X 上。这些评论通常批评由已故的阿列克谢·纳瓦利内创立的反腐败基金会（Anti-Corruption Foundation）成员。鉴于其聚焦社交媒体评论、并针对腐败提出指控，我们把这一行动称为"Corrupt Comment"（腐败评论）。

## 行为

该行为者用我们的模型生成英文评论，再由 X 上的假账号发布——常常回复在俄语帖子之下。虽然这些评论以回复形式发布，但并不是作为回复生成的：我们没有发现该行动使用我们的模型读取或分析社交媒体内容、构思相关回应的迹象。活动狭窄地聚焦于反腐败基金会（按俄语缩写称 FBK，由已故俄罗斯社会活动家纳瓦利内创立）的高级人物。操作者使用我们的 API 生成批评该基金会、其领导层以及纳瓦利内盟友的评论。这些评论随后被发布在 X 上，回复该基金会成员的帖子。发布评论的 X 账号大多创建于 2023 年 12 月，零粉丝，其帖子也没有收到任何回复。

*俄罗斯反对派政治人物柳博夫·索博利（Lyubov Sobol）的推文，以及发布本行动内容的账号在其下的回复。对比索博利帖子的互动量与假账号帖子的零互动。*

X 上部分账号的头像是从互联网各处抄来的风景图。另一些使用假头像，带有"用较早期 AI 生成"的特征——即生成对抗网络（GAN），这一技术早在 2019 年就有报道。

## 生成内容

该行动生成的评论主要批评 FBK，质疑其透明度。与卢旺达案例一样，这种做法最好被理解为"主题与变奏"：用许多不同的帖子传递同一个核心信息。

*本行动某账号 6 月 24 日的三条推文，均回复纳瓦利内的盟友，都是同一核心主题的变奏。*
