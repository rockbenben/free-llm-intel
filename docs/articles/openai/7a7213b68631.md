# ChatGPT 智能体系统卡

阅读系统卡


ChatGPT 智能体是 OpenAI o3 同系列的新型智能体模型，它结合了深入研究和 Operator 的双重优势。它集成了：

- 深入研究功能：支持多步骤研究流程，生成高质量分析报告
- Operator 功能：通过远程可视化浏览器环境执行任务
- 终端工具：提供受限网络访问的代码执行、数据分析以及生成幻灯片或电子表格
- 通过第一方连接器访问外部数据源和应用（例如 Google Drive）。

自项目启动以来，我们始终将安全视为系统固有的一部分，在 Operator 研究预览版中已有的强大控制措施基础上，进一步添加了额外安全措施，以应对更广泛的用户覆盖范围和终端访问等新风险。有关更多详细信息，请参阅下文的“产品特定风险应对措施”部分。

根据[防范准备框架⁠](https://openai.com/index/updating-our-preparedness-framework/)，我们判定本次发布属于生物和化学领域的高能力级别，已触发相应防护机制。尽管我们没有确凿证据表明该模型能实质性帮助新手造成严重生物危害——我们[定义的高能力阈值](https://cdn.openai.com/pdf/18a02b5d-6b67-4cec-ab64-68cdfbddebcd/preparedness-framework-v2.pdf)——但我们选择采取预防性措施。
