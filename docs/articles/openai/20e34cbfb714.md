# Codex：全能型助手


我们现发布 Codex 的重大更新，致力于将其打造为更强大的协作伙伴。目前，全球已有超过 300 万名开发者每周通过 Codex 在软件开发的整个生命周期中实现加速。

此次更新后，Codex 不仅能与你并肩操作电脑，还能深度集成更多日常工具与应用。它现在具备了生成图像、记住个性化偏好、从历史操作中学习的能力，并能胜任各类持续性、重复性的任务。此外，Codex 应用进一步深化了对开发者工作流的支持，涵盖了 PR 审查、多文件及终端视图查看、通过 SSH 连接远程开发机 (Devbox) 等核心场景。内置的应用程序浏览器更能助力开发者在前端设计、应用及游戏开发中实现更快速的迭代升级。

## 拓展 Codex 在代码编写之外的能力边界

凭借后台计算机使用 (Computer use) 能力，Codex 现在能够像人类一样，通过视觉识别、点击和输入，自主操控电脑上的各类应用程序。即便有多个智能体在你的 Mac 上并行工作，它们也能与你互不干扰，确保你在其他应用中的日常操作流畅如初。对于开发者而言，这一特性在前端效果调试、应用测试，以及操作那些未开放 API 的应用时尤为得心应手。

与此同时，Codex 开始实现与 Web 环境的原生协作。新版应用集成了内置浏览器，支持你直接在页面上进行标注，从而为智能体提供精准的操作指令。目前，这一功能已在前端及游戏开发中展现出核心价值；未来，我们计划进一步拓展其能力，让 Codex 不仅能处理 localhost 的 Web 应用，更能全面掌控浏览器的所有操作场景。

现在，Codex 已支持调用 [gpt-image-1.5](https://developers.openai.com/api/docs/models/gpt-image-1.5) 来生成并迭代图像。结合屏幕截图与代码能力，它能助力开发者在同一工作流中，为产品原型、前端设计、视觉效果图及游戏开发快速构建视觉元素。

我们还同步发布了 90 多款新增插件。通过整合各项技能、应用集成及 MCP 服务端，Codex 能够以更丰富的方式获取上下文，并在各类工具间执行操作。其中，深受开发者青睐的新插件包括：用于管理 JIRA 的 Atlassian Rovo，以及 CircleCI、CodeRabbit、GitLab Issues、Microsoft 套件、Neon by Databricks、Remotion、Render 和 Superpowers 等。

## 贯穿软件开发的整个生命周期

Codex 应用现已支持处理 GitHub 评审意见、运行多标签终端，并开启了通过 SSH 连接远程开发机 (Devbox) 的 Alpha 测试。此外，你可以在侧边栏直接打开文件，并对 PDF、电子表格、演示文稿及文档进行富文本预览；全新的摘要面板则能帮你实时追踪智能体的任务计划、参考来源及产出成果。

这些改进共同构建了一个统一的工作空间，让开发者在编写代码、核查输出、评审变更以及与智能体协同办公等各个环节之间，实现更高效的无缝切换。

## 任务延续与长期自动化

我们增强了自动化 (Automation) 功能，支持重复使用既有的对话线程，从而完整保留之前积累的上下文信息。现在，Codex 能够自主规划未来工作，并自动唤醒以继续执行长期任务，任务周期甚至可以跨越数天或数周。

目前，众多团队正利用自动化功能处理各类事务：从合入挂起的 Pull request，到跟进待办事项，以及在 Slack、Gmail 和 Notion 等跨平台工具中实时掌控瞬息万变的沟通动态。

同时，我们推出了记忆功能 (memory) 的预览版。这让 Codex 能够记住过往经验中有价值的上下文，包括你的个人偏好、曾做出的修正，以及那些费时获取的信息。这不仅能显著加快后续任务的完成速度，更能确保产出质量达到此前必须依靠大量“自定义指令”才能实现的水准。

Codex 现在还会主动提议后续工作，帮你无缝衔接进度。结合项目背景、已连接的插件及记忆功能，Codex 可以为你建议如何开启新一天的办公，或从何处继续之前的项目。例如，Codex 能识别 Google Docs 中需要你关注的未处理评论，并从 Slack、Notion 及你的代码库中提取相关背景，最后为你提供一份按优先级排序的行动清单。

## 可用性

即日起，这些更新将面向登录了 ChatGPT 账号的 Codex 桌面应用用户陆续推送。

个性化功能（包括上下文感知建议和记忆功能）将很快向 Enterprise、Edu 以及欧盟和英国用户开放。计算机使用 (Computer use) 功能首发支持 macOS，并将于近期推向欧盟和英国市场。

如果你此前一直在终端或编辑器中使用 Codex，不妨尝试将其应用到你的整个工作流中。如果你尚未体验过 Codex，欢迎[下载应用⁠](https://openai.com/codex/)，开启高效开发之旅。

## 未来展望

自 Codex 发布仅一年以来，开发者的使用方式已发生了翻天覆地的变化：从最初单纯依靠 Codex 编写代码，到如今越来越多地利用它来剖析系统架构、调取上下文信息、评审代码、排查故障、协同团队工作，并推动长期项目的持续演进。

我们的使命是确保 AGI 造福全人类。这其中便包括缩小“心中所想”与“手下所成”之间的鸿沟。此次更新使 Codex 能够深度参与到软件构建过程中的各类工具、工作流及决策环节中。而这仅仅是一个开始。
