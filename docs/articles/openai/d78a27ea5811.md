# 我们对 Axios 开发工具被入侵事件的应对

我们最近发现一起涉及第三方开发工具 Axios 的安全问题，它是一起被广泛报道的[更大范围行业事件](https://cloud.google.com/blog/topics/threat-intelligence/north-korea-threat-actor-targets-axios-npm-package)的一部分。出于高度谨慎，我们正在采取措施保护"认证我们的 macOS 应用是合法的 OpenAI 应用"这一流程。我们未发现 OpenAI 用户数据被访问、我们的系统或知识产权被泄露、或我们的软件被篡改的任何证据。

#### 请在 2026 年 5 月 8 日前更新你的 macOS 应用

我们正在更新安全证书，这将要求所有 macOS 用户把 OpenAI 应用更新到最新版本。这有助于防止任何——尽管可能性很小——有人分发伪装成 OpenAI 的假应用的风险。你可以通过应用内更新或下面的官方链接安全更新：

- [ChatGPT 桌面版](https://chatgpt.com/download/)
- [Codex 应用](https://chatgpt.com/codex/)
- [Codex CLI](https://developers.openai.com/codex/cli)
- [Atlas](https://chatgpt.com/atlas)

信息的安全与隐私是我们的首要任务。我们承诺保持透明，在问题出现时迅速行动。下面分享更多技术细节和常见问题。

### 发生了什么，我们正在做什么

2026 年 3 月 31 日（UTC），广泛使用的第三方开发库 Axios[在一次更大范围的软件供应链攻击中被入侵](https://cloud.google.com/blog/topics/threat-intelligence/north-korea-threat-actor-targets-axios-npm-package)。当时，我们在 macOS 应用签名流程中使用的一个 GitHub Actions 工作流下载并执行了一个恶意版本的 Axios（1.14.1 版）。该工作流有权访问用于签名 macOS 应用（包括 ChatGPT 桌面版、Codex、Codex-cli 和 Atlas）的证书和公证材料。这张证书帮助客户确认软件来自合法开发者 OpenAI。

我们对该事件的分析得出结论：由于恶意载荷执行时机、证书注入作业的时点、作业本身的顺序及其他缓解因素，该工作流中的签名证书很可能未被恶意载荷成功窃取。尽管如此，出于高度谨慎，我们按证书已泄露处理，正在吊销并轮换它。

自 2026 年 5 月 8 日起，我们 macOS 桌面应用的旧版本将不再获得更新或支持，并可能无法正常运行。以下版本是使用我们更新后证书签署的最早版本：

- ChatGPT Desktop：1.2026.051
- Codex App：26.406.40811
- Codex CLI：0.119.0
- Atlas：1.2026.84.2

### 调查与补救工作

作为调查与响应的一部分，我们聘请了一家第三方数字取证与事件响应公司，轮换我们的 macOS 代码签名证书，用新证书发布了所有相关 macOS 产品的新构建，并正与 Apple 合作确保用旧证书签署的软件无法再被新公证。我们还审查了用旧证书进行的全部软件公证记录，确认这些密钥没有发生异常公证，并验证我们发布的软件没有被未经授权的改动。目前，我们没有发现既有软件安装被入侵或存在风险的证据。

假如该证书真的被恶意行为者成功窃取，他们可以用来签署自己的代码，使其看起来像合法的 OpenAI 软件。我们已经停止用旧证书进行新的软件公证，因此未经授权的第三方用旧证书签署的新软件，默认会被 macOS 安全保护机制拦截——除非用户显式绕过。一旦我们在 2026 年 5 月 8 日完成证书吊销，用旧证书签署的应用的新下载和首次启动也将被 macOS 安全保护拦截。

本次事件的根本原因是 GitHub Actions 工作流中的一处配置错误，我们已修复。具体来说，涉事 action 使用了浮动 tag，而非特定的 commit hash，且没有为新软件包配置 minimumReleaseAge。

## 常见问题

**OpenAI 的产品或用户数据被泄露了吗？**

没有。我们未发现 OpenAI 产品或用户数据被泄露或暴露的证据。

**你们见过以 OpenAI 名义签署的恶意软件吗？**

没有。我们未发现可能暴露的公证与代码签名材料被滥用的证据，并确认了受影响材料涉及的全部公证事件均属预期。

**我需要改密码吗？**

不需要。密码和 OpenAI API key 未受影响。

**这影响 iOS、Android、Linux 或 Windows 吗？**

不影响。这只涉及 OpenAI 的 macOS 应用，不影响我们软件的网页版。

**为什么要我更新 Mac 应用？**

OpenAI 发现 macOS 应用签名流程涉及的一个 GitHub Actions 工作流存在暴露。由于暴露的工作流与 macOS 应用签名相关，我们主动轮换用于 OpenAI macOS 应用的公证与代码签名材料。更新可确保你运行的是用最新证书签署的版本，该证书帮助客户确认软件来自合法开发者 OpenAI。

**我在哪里下载更新后的 macOS 应用？**

请只通过应用内更新或以下官方网页下载 OpenAI 应用：

- [ChatGPT](https://chatgpt.com/download/)
- [Codex](https://chatgpt.com/codex/)
- [Codex-cli](https://developers.openai.com/codex/cli)
- [Atlas](https://chatgpt.com/atlas)

不要安装来自邮件、消息、广告或第三方下载站链接的应用。对通过邮件、短信、聊天消息、广告、文件分享链接或第三方下载站发来的可疑 "OpenAI""ChatGPT""Codex" 安装包要保持警惕。

**2026 年 5 月 8 日之后会怎样？**

自 2026 年 5 月 8 日起，我们 macOS 桌面应用的旧版本将不再获得更新或支持，并可能无法正常运行。以下版本是使用更新后证书签署的最早版本：

- ChatGPT Desktop：1.2026.051
- Codex App：26.406.40811
- Codex CLI：0.119.0
- Atlas：1.2026.84.2

**为什么不立即吊销证书？**

我们已设法阻止用受影响的公证材料对 macOS 应用进行任何进一步公证。这意味着任何用受影响证书冒充 OpenAI 应用的欺诈应用将缺少公证，因而默认会被 macOS 安全保护拦截——除非用户显式绕过这些保护。

由于用旧证书的新公证已被阻止，而吊销又可能导致 macOS 拦截用旧证书签署应用的新下载和首次启动，我们给用户留出 30 天窗口完成更新，以尽量减少扰动。这个窗口有助于降低用户风险，并让受影响的客户端通过内置更新机制完成升级，确保被恰当地修复。

我们正与合作伙伴一起监测签名证书被滥用的任何指标；如果在此期间发现恶意活动，我们将加快吊销时间表。
