# OpenAI 与 Dell Technologies 合作，将 Codex 引入混合和本地部署企业环境


OpenAI 与 Dell Technologies 正在合作，帮助更多企业在其最重要的数据、系统和工作流所在的环境中部署 Codex。

Codex 正成为 OpenAI 增长最快的企业产品之一。如今，每周有超过 400 万开发者使用 Codex，企业也已将其用于整个软件开发生命周期，从代码审查和测试覆盖到事件响应，以及在大型代码库中的推理。

而且，Codex 正在超越编码场景。团队开始使用由 Codex 驱动的智能体，在各类工具间收集上下文、准备报告、分发产品反馈、筛选销售线索、撰写跟进内容，并协调跨业务系统的工作。

为了扩大这种采用，企业需要 Codex 能在其数据、系统和工作流所在的混合及本地部署环境中安全运行，例如 Dell AI Data Platform 和 Dell AI Factory。

通过此次合作，Codex 将连接 Dell AI Data Platform。许多企业已使用该平台在本地存储、组织和治理企业数据。此次合作将帮助客户让 Codex 更贴近使智能体真正有用的内部上下文：代码库、文档、业务系统、运营知识和团队工作流。

Dell 和 OpenAI 还将探索 Codex 如何连接 Dell AI Factory，企业使用该平台为其 AI 工作负载提供支持。探索内容包括让 Codex、ChatGPT Enterprise 及其他基于 API 的解决方案与 AI Factory 对接，以准备数据、管理记录系统、运行测试，并部署与企业混合或本地 Dell 基础设施集成的 AI 应用。

> “与 OpenAI 的合作，将 Dell 行业领先的企业级基础设施与 OpenAI 前沿的智能体 AI 框架和模型结合在一起。搭载 OpenAI Codex 的 Dell AI Factory 将使企业能够在企业数据所在之处、在其本地环境内部署 AI，为客户提供一条在大规模部署 AI 智能体方面切实且安全的路径。”

—Dell Technologies 基础设施解决方案事业群高级副总裁兼首席技术官 Ihab Tarazi

对客户而言，结果是一条更切实可行的生产落地路径。Codex 可部署在更靠近企业数据和系统的位置，并具备大型组织所需的控制能力，以及支持软件开发和知识工作中更多用例的灵活性。

通过将 Codex 连接到 Dell 环境中受治理的企业数据，客户能够以更完整的生产工作上下文来构建、测试、自动化、分析并采取行动。

我们希望这能帮助更多企业更快采用 Codex，将其扩展到更多高价值工作流中，并把 AI 智能体转变为可重复用于真实工作的系统。
