# Bet Bot：赌博垃圾信息网络

OpenAI 封禁了一批账户，这些账户通过一家以色列初创公司接入其模型，在 X 上生成对话并向用户发送赌博网站链接。

*本案例研究最初发表于 OpenAI 的 [*2024 年 10 月*](https://cdn.openai.com/threat-intelligence-reports/influence-and-cyber-operations-an-update_October-2024.pdf)* 报告。*

## 行为主体

我们封禁了一组利用我们的 API 与 X 上的用户生成对话、并向其发送赌博网站链接的账户。此次行动通过一家以色列初创公司访问我们的模型。鉴于该行动专注于分享赌博网站链接，并大规模使用很可能为自动化的 X 账户，我们将这次行动命名为 "Bet Bot"。

## 行为方式

与 "Bad Grammar" 和 "A2Z" 行动类似，这次行动利用我们的模型管理用于社交媒体的多个虚假人设。例如，它生成个人简介、研究要关注的社交媒体账户、分析帖子和评论，并起草英文回复，随后将这些回复发布到 X 上。X 上的这些账户通常使用 AI 生成的头像，配有体育主题的背景图和简介，个别声称自己位于英国足球重镇如曼彻斯特或利物浦，且大多创建于 2023 年 12 月或 2024 年 6 月。

*与此次行动相关的典型 X 账户。注意其足球主题、创建日期、账号名与用户名的不一致，以及极少的粉丝数。我们评估其头像很可能是用 AI 生成的（扭曲的文字是潜在的开源特征指标）。背景图取自 Shutterstock 的原创作品。该账户在我们的调查期间已被 X 封禁。*

尽管其中一些账户使用了 AI 生成的头像——这类头像本被设计成看起来独一无二——该行动有时仍在多个账户之间重复使用这些图片。还有一些账户使用了可疑、不合常理的昵称，例如 "KobeBryantJohnson"。即便是在这样一个相对精细的行动中，操作者有时也会走捷径，反而可能削弱了自己的效果。

*与此次行动相关的两个 X 账户。注意其相同的头像和极少的粉丝数，除一人外，其余关注者也都由该行动运营。*

该行动的补全内容分为两类。一类被设计并投放为 X 上的公开评论。通常，该行动会挑选一段已有不止一人参与讨论的简短对话，生成一条回复评论，然后由其某个虚假人设把这条回复发到评论区。

*"Ollie Smith" 虚假账户在 X 上的典型评论，由我们的模型生成，回复的是一位与该行动无关的 X 用户发布的足球主题评论。这段对话涉及英格兰队在 2024 年 6 月 30 日欧洲杯上对阵斯洛伐克的比赛。*

另一类补全内容看起来是为私信（DM）设计的。在这些情况下，该行动的输入模仿真实用户的消息，输出则被精心构造为回复。由于私信属于受限的非公开服务，我们无法确认这些回复是否被实际发送；但某些实例中，该行动的提示词表明确实发生过包含多轮交流的对话。我们在 X 上识别出的所有虚假人设粉丝数都极低，通常只有个位数或低两位数的粉丝量。典型情况是，每个虚假账户关注六七个到十几个同类账户，因此即便这些本就很低的粉丝数也是人为抬高的。不过，少数账户确实也吸引了一些看似真实的关注者。

## 补全内容

该行动面向公众的大部分内容涉及各类体育项目，尤其是足球，也包括棒球、篮球、垒球、橄榄球和冰球。通常，每个虚假账户在 X 上的少量帖子会提及美国或英国政治，但这些内容没有一致的意识形态立场，也不支持某个特定候选人或政党。

*网络中另一个虚假账户关于垒球和政治的评论样例。每张图中，一位认证用户发布了帖子，一位与该行动无关的第二位用户回复了它，再由 Bet Bot 运营的账户回复第二位用户。*

很可能用于私信的内容几乎从不涉及政治，而是始终提及赌博。有时其中包含来自 bit[.]ly 等公开链接缩短服务的 URL。我们调查的所有链接都指向在线赌博网站。实质上，这次行动看起来是一条内容生成管线：用关于体育、偶尔涉及政治的公开评论来掩饰其虚假账户，然后通过私信向人们发送赌博链接垃圾信息。

## 影响

这似乎并不是以操纵政治结果为目标的影响行动，而是一个试图引诱人们访问赌博网站的现代垃圾信息网络。但它体现了一整套独特的手段、技术和流程（TTP），其中包括疑似的私信行为。考虑到其明显使用了非公开消息，且我们不清楚有多少人——如果有的话——点击了赌博链接，我们的评估依据是部分证据，且主要来自操作者的补全内容。一些提示词表明确实发生过包含多轮交流的对话，但这些对话中常见真实用户对赌博链接表示怀疑，或声称自己不在线赌博。这些虚假账户的粉丝数也极低，说明其潜在受众有限。然而，我们的证据确实表明，该行动中至少有部分账户找到了通过私信在 X 上与真人互动的方式，且至少维持了足够长的时间以发送链接。这意味着它们具备了跳出虚假人设自身信息茧房的能力。因此，依据 Breakout Scale（突破量表），我们将此活动归为第 2 类：即活动限于单一平台，并有部分证据显示一些真实用户与其互动。
