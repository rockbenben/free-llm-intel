# 基于第三人称视角的模仿学习

Read paper

(opens in a new window)


## 摘要

强化学习（RL）使得训练能在复杂不确定环境中实现精巧目标的智能体成为可能。强化学习的一个关键难点是为智能体指定一个待优化的奖励函数。传统上，RL 中的模仿学习（imitation learning）被用来克服这一问题。遗憾的是，迄今为止的模仿学习方法往往要求以第一人称视角提供演示：即给智能体提供一串状态，并说明它在每个状态下本应采取的动作。这类模仿学习虽然强大，却受制于一个相对困难的问题——收集第一人称演示。人类解决这个问题的方式是向第三人称演示学习：观察他人执行任务、推断出任务本身，然后自己完成同样的任务。

在这篇论文中，我们提出一种无监督的第三人称模仿学习方法。这里的"第三人称"指：当智能体获得一份教师从不同视点达成同一目标的演示时，它能正确地在一个简单环境中达成该简单目标；"无监督"指：智能体只拿到这些第三人称演示，并没有教师状态与学生状态之间的对应关系。我们方法的核心洞察在于：可以利用领域混淆（domain confusion）领域的最新进展，得到在训练过程中至关重要的领域无关（domain agnostic）特征。为了验证我们的方法，我们报告了在 pointmass 领域、reacher 领域和倒立摆上从第三人称演示成功学习的实验。
