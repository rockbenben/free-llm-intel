# OpenAI 与 Hearst 的内容合作

Hearst 旗下标志性品牌将精选的生活方式与本地新闻内容带入 OpenAI 的产品。

*编者按：这则消息最初由 Hearst 发布，原文可参阅*[此处⁠（在新窗口中打开）](https://www.hearst.com/-/hearst-and-openai-announce-strategic-content-partnership)*。*

Hearst 今日宣布与 OpenAI 建立新的内容合作关系，将 Hearst 丰富的报纸与本土杂志内容整合进 OpenAI 的产品，提升两家公司产品对用户的价值与触达。

作为合作的一部分，OpenAI 将把 Hearst 旗下享有盛誉的可信新闻品牌内容——包括 *Houston Chronicle、San Francisco Chronicle、Esquire、Cosmopolitan、*ELLE*、Runner's World、Women's Health* 等——纳入其先进 AI 产品。此次合作覆盖 20 多个杂志品牌和 40 多家报纸，为 ChatGPT 每周 2 亿用户带来海量生活方式内容。从本地新闻到时尚、家居设计，以及健康、健身和汽车洞见，用户如今能与塑造其日常生活的各类话题建立更广、更深的连接。

Hearst 报业总裁 Jeff Johnson 表示：“随着生成式 AI 走向成熟，由专业记者生产的新闻必须处于所有 AI 产品的核心。这份协议让 Hearst 报业屡获殊荣的记者们创造的可信、精选内容，能够进入 ChatGPT 等 OpenAI 产品——从而产出更及时、更相关的结果。”

Hearst 杂志总裁 Debi Chirichella 表示：“与 OpenAI 的合作将帮助我们推动杂志内容的未来演进。这次协作确保在 OpenAI 产品不断演进的同时，我们高质量的写作与专业能力、文化与历史语境，以及署名与可信度都得到彰显。”

OpenAI 首席运营官 Brad Lightcap 表示：“把 Hearst 的可信内容带入我们的产品，提升了我们为用户提供有吸引力、可靠信息的能力。”

ChatGPT 中的 Hearst 内容将带有规范的信息来源标注和直接链接，提供透明度，并方便用户访问 Hearst 原始内容。

Hearst 在杂志和报纸之外的其他业务不在此次合作范围内。
