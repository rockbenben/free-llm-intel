# MLE-bench

评估机器学习智能体的机器学习工程能力

阅读论文

（在新窗口打开）

我们推出 MLE-bench，一个用来衡量 AI 智能体在机器学习工程（machine learning engineering）上表现如何的基准。为此，我们从 Kaggle 挑选了 75 个与 ML 工程相关的竞赛，组成一套多样化的挑战性任务，考验真实的 ML 工程技能，比如训练模型、准备数据集、跑实验。我们用 Kaggle 公开的排行榜为每个竞赛建立了人类基线。我们使用开源的智能体脚手架（scaffold），在基准上评测了多个前沿语言模型，发现表现最好的组合——用 AIDE 脚手架的 OpenAI o1-preview——在 16.9% 的竞赛中至少达到了 Kaggle 铜牌水平。除主要结果外，我们还研究了 AI 智能体的各种资源扩展（resource-scaling）形式，以及来自预训练的污染（contamination）影响。我们把[基准代码开源⁠（在新窗口打开）](https://github.com/openai/mle-bench/)，以推动未来围绕理解 AI 智能体 ML 工程能力的研究。
