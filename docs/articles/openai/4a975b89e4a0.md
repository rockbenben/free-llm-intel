# 三星电子为员工部署 ChatGPT 和 Codex

这是我们迄今规模最大的部署之一


- ChatGPT Enterprise 和 Codex 面向韩国三星电子全体员工及全球 Device eXperience (DX) 员工开放
- 三星的全球部署是 OpenAI 迄今规模最大的企业级上线之一
- 三星电子将在从研发、制造到营销、企业职能及其他业务领域的运营中使用 ChatGPT 和 Codex

三星电子正在向全球员工部署 ChatGPT Enterprise 和 Codex，以加速全公司的 AI 采用。根据协议，ChatGPT 和 Codex 将面向韩国三星电子全体员工，以及其 Device eXperience (DX) 部门全球所有员工开放。这是 OpenAI 迄今规模最大的企业部署之一。

三星电子计划在广泛职能中将 ChatGPT 和 Codex 用于技术和非技术工作，包括软件开发、营销、产品开发和制造，以提升员工生产力和解决问题的能力。Codex 最初是软件开发工具，但正日益适用于更多类型的工作。

借助 ChatGPT，三星电子员工可以更高效地完成各类知识型任务，包括搜索和分析信息、起草文档、开发创意以及解读数据。ChatGPT Enterprise 提供企业级能力，使组织能够安全、有效地使用 AI，包括数据保护、用户和访问管理以及安全控制。这些能力让三星电子员工能够在公司安全政策和治理框架内使用先进 AI。

Codex 不仅可以通过编写、审查和调试代码等任务提升开发者生产力，也能提升非技术团队日常工作的效率。例如，员工可以使用 Codex 将想法转化为可运行的软件、内部工具、网站和自动化工作流。

目前，每周有超过 500 万人使用 Codex 处理技术和非技术工作流，并支持各类岗位。自 2026 年 2 月 1 日以来，Codex 在韩国的周活跃用户数已增长近 800%。

“对 OpenAI 而言，这一具有历史意义的部署尤其重要，因为作为技术和制造领域的全球领导者，三星电子正以核心平台的方式拥抱 AI，用于改善全球员工的工作和创新方式，而不是把 AI 局限于某些团队或职能的工具，”OpenAI 韩国总经理 Harrison Kim 表示。

“OpenAI 将与三星电子紧密合作，帮助其员工借助 ChatGPT 和 Codex 提升能力，更快地从想法走向执行，解决复杂问题，并创造新的产品和服务。”

OpenAI 与三星电子此前已在全球 AI 基础设施领域展开合作。三星电子正与 OpenAI 合作，供应下一代 AI 基础设施所需的先进存储半导体。随着三星电子采用 ChatGPT Enterprise，两家公司的关系正从 AI 基础设施扩展到员工队伍转型和全公司 AI 采用。

同样在韩国，首尔大学最近开始向其社区的全部 47,000 名成员提供 ChatGPT Edu，包括学生、教师和员工，作为其向 AI 原生校园转型的一部分。OpenAI 还与 Kakao 合作，让用户能够直接在 KakaoTalk 群聊中向 ChatGPT 提问并接收回答，将 ChatGPT 带入韩国广泛使用的日常通讯平台。

韩国各行各业的公司也在使用 ChatGPT Enterprise、OpenAI API 和 Codex，包括 LG Electronics、LG Uplus、LG CNS、GS E&C、Samsung SDS、TVING、Krafton、Toss、MUSINSA、Korea Zinc、Nexen Tire 和 HanaTour。
