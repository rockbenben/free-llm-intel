# 推出 ChatGPT 与 Whisper API

开发者现在可以通过我们的 API，把 GPT‑3.5 Turbo 和 Whisper 模型集成到自己的应用和产品中。

*2024 年 4 月 24 日更新：ChatGPT API 这一名称已停用。本博客中提及的 ChatGPT API 均指 GPT‑3.5 Turbo API。*

ChatGPT 和 Whisper 模型现已在我们的 API 上提供，让开发者能够使用前沿的语言（不只是聊天！）和语音转文本能力。通过一系列系统级优化，自 12 月以来我们已把 ChatGPT 的成本降低了 90%；现在我们把这部分节省让利给 API 用户。开发者现在可以在 API 中使用我们开源的 Whisper large-v2 模型，结果更快也更划算。GPT‑3.5 API 用户可以期待持续的模型改进，并可选择专属容量以对模型进行更深入的控制。我们也认真倾听了开发者的反馈，并完善了 API 服务条款，以更好地满足他们的需求。

## GPT-3.5 API

**模型**：我们今天发布的 ChatGPT 模型家族 `gpt-3.5-turbo`，与 ChatGPT 产品中使用的是同一个模型。它的定价为每 1k token 0.002 美元，比我们现有的 GPT‑3.5 模型便宜 10 倍。它也是我们在许多非聊天用例上最好的模型——我们看到早期测试者从 `text-davinci-003` 迁移到 `gpt-3.5-turbo` 只需对他们的提示词做少量调整。

**API**：传统上，GPT 模型消费的是非结构化文本，对模型而言表示为一串“token”。ChatGPT 模型则消费的是一串消息以及元数据。（供好奇者参考：在底层，输入仍然被渲染成一串“token”供模型消费；模型使用的原始格式是一种叫做 [Chat Markup Language](https://github.com/openai/openai-python/blob/120d225b91a8453e15240a49fb1c6794d8119326/chatml.md)（“ChatML”）的新格式。）

## ChatGPT 升级

我们不断改进 ChatGPT 模型，也希望把这些增强提供给开发者。使用 `gpt-3.5-turbo` 模型的开发者总能获得我们推荐的稳定模型，同时仍可以灵活选择某个特定模型版本。例如，今天我们发布 `gpt-3.5-turbo-0301`，它将至少支持到 6 月 1 日，我们会在 4 月把 `gpt-3.5-turbo` 更新到一个新的稳定版本。[模型页面](https://platform.openai.com/docs/models)会提供切换更新信息。

## 专属实例

我们现在也为那些希望对特定模型版本和系统性能有更深入控制的用户提供专属实例。默认情况下，请求运行在与其他用户共享的算力基础设施上，这些用户按请求付费。我们的 API 运行在 Azure 上；使用专属实例时，开发者将按时间段为一份专门用于处理其请求的算力基础设施分配付费。

开发者可以完全控制实例的负载（更高负载提升吞吐量，但会让每个请求变慢），可以选择启用更长上下文限制等功能，并可以锁定模型快照。

对于每天运行超过约 4.5 亿 token 的开发者来说，专属实例在经济上是划算的。此外，它让开发者能够直接针对硬件性能优化其工作负载，相比共享基础设施可以大幅降低成本。如需咨询专属实例，[联系我们⁠](https://openai.com/contact-sales/)。

## Whisper API

[Whisper⁠](https://openai.com/index/whisper/) 是我们于 2022 年 9 月开源的语音转文本模型，受到了开发者社区的极大好评，但运行起来也可能有难度。我们现在已通过 API 提供 large-v2 模型，可按需便捷访问，定价为每分钟 0.006 美元。此外，我们高度优化的服务栈确保了相比其他服务更快的性能。

Whisper API 通过我们的 `transcriptions`（按源语言转录）或 `translations`（转录为英语）端点提供，并支持多种格式（m4a、mp3、mp4、mpeg、mpga、wav、webm）：

## 以开发者为中心

过去六个月，我们一直在收集 API 客户的反馈，以了解如何更好地服务他们。我们做了具体的改变，例如：

- 通过 API 提交的数据不再被用于改进服务（包括模型训练），除非组织主动选择加入
- 为 API 用户实施默认的 30 天数据保留策略，并根据用户需求提供更严格的保留选项
- 取消我们的上线前审核（通过改进我们的自动化监控实现）
- 改进开发者文档
- 简化我们的[服务条款与使用政策](https://platform.openai.com/docs/usage-policies)，包括数据所有权相关条款：用户拥有模型的输入和输出。

过去两个月，我们的可用性既没有达到我们自己的预期，也没有达到用户的预期。我们工程团队的首要目标现在是生产用例的稳定性——我们深知，要确保 AI 造福全人类，就必须成为一个可靠的服务提供商。请在接下来的几个月里监督我们提升可用性！

我们相信 AI 能为每个人带来难以置信的机遇和经济赋能，而实现这一点最好的方式就是让每个人都能用它来构建。我们希望今天宣布的这些改变能催生大量让所有人都能受益的应用。开始构建由 ChatGPT 和 Whisper 驱动的下一代应用吧。
