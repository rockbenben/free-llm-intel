# OpenAI 董事会关于非营利委员会报告的声明



OpenAI 董事会对独立非营利委员会成员表现出的敬业精神及其广泛的工作参与表示衷心感谢。该委员会由 OpenAI 于 4 月[正式组建⁠](https://openai.com/index/nonprofit-commission-advisors/)，旨在通过“利益相关者参与机制”，广泛听取各方意见，总结 OpenAI 的公益慈善事业在应对长期系统性问题方面的经验教训，并据此提出针对性建议。[随附的报告](https://cdn.openai.com/pdf/016dcd99-2a6c-476c-a6b4-0a976b1c1ca1/the-openai-nonprofit-commission-report.pdf)真实反映了该委员会的独立调查发现。

我们高度赞赏委员会在报告中所展现出的专业素养，并对在调研过程中慷慨分享洞察的社区领袖及一线实践者们致以谢忱。正是由于这些宝贵的贡献，OpenAI 非营利组织得以更清晰地明确方向，从而更好地履行其核心使命：确保通用人工智能 (AGI) 惠及全人类。

在推进这一使命的过程中，我们将始终秉持倾听与学习的态度，与身处变革一线的伙伴们并肩同行。这也是董事会的一项坚定承诺：我们将全力支持一个资源充沛、由使命驱动且能积极响应社会需求的非营利组织，为我们致力于服务的社区创造真正价值。
