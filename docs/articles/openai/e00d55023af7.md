# 我们处理政府和国家安全合作伙伴关系的策略

阅读这些原则



各国政府逐步将前沿 AI 系统应用于越发重要的工作，包括国家安全领域。这让 AI 实验室、政府和公民社会必须就这些工具应如何用于敏感场景展开新的合作。

我们认为，民主社会应当能够利用 AI 来保护人民、捍卫关键基础设施、提供公共服务，并应对新出现的威胁；在网络防御和生物安全等领域，AI 能够为防御方带来切实优势。但能力日益增强的 AI 系统必须以强化民主问责制、高价值人类判断能力和法治体系的方式部署，并且应加强民主制度，而不是一味集中权力。

**今天，我们发布 OpenAI 的国家安全原则，以清晰呈现我们如何处理政府合作伙伴关系以及我们的技术在国家安全领域的应用。**

随着我们的技术持续进步，这些原则体现了全公司共同努力的成果：为我们在国家安全和执法领域的工作制定更全面的方针。我们邀请了资深国家安全专家 David Kris 协助推进这一流程并提供独立判断，在公司内部举办了多场会议以听取意见，并与来自研究、安全、政策和政府合作等多个团队的员工进行了交流。

随着我们在关键防御领域，尤其是网络安全和生物安全方面扩大与美国政府及盟友伙伴的合作，我们即将正式发布这些原则。过去一个月，作为我们 [Daybreak⁠](https://openai.com/daybreak/) 网络防御计划的一部分，我们已与澳大利亚、加拿大、日本、韩国、法国、德国、波兰、荷兰以及 ENISA 等欧盟机构建立了可信网络访问权限合作伙伴关系。我们还与英国政府围绕网络安全、测试和评估领域建立了不断深化且值得信赖的合作关系。我们在生物安全领域也采取类似做法。上个月，我们还宣布向部分支持公共健康和生物防御任务的美国政府及盟友伙伴扩大对 GPT‑Rosalind 模型的可信访问权限。

这些原则适用于我们当前和未来的国家安全及执法合作伙伴关系，包括我们与美国战争部的现有合作。今年早些时候宣布该协议时，我们阐明了几项合同限制条款：不得使用 OpenAI 技术进行大规模国内监控；不得使用 OpenAI 技术指挥自主武器系统；不得使用 OpenAI 技术作出高风险自动化决策。这些限制条款与我们今天分享的原则一致。

我们认为，正确的做法是明确我们技术的可用与禁用范围，并保持信息透明。然而，AI 在政府应用中最具深远影响的问题，特别是在国家安全领域，应通过民主程序来决策。企业的职责在于为这些决策提供参考依据，而非单方面做出决定。因此，我们支持通过立法为 AI 在部分最高风险的军事应用中设立安全边界，包括国内监控、自主武器系统以及其他直接影响美国国家安全的高风险应用。
