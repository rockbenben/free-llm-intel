# 师生课程学习

## 摘要

我们提出师生课程学习（TSCL）——一个自动课程学习框架：学生（Student）尝试学习复杂任务，教师（Teacher）从给定任务集中自动挑选子任务供学生训练。我们描述了一族教师算法，其直觉是：学生应更多练习那些进步最快的任务，即学习曲线斜率最大的任务。此外，教师算法还通过选择学生表现正在变差的任务来解决遗忘问题。我们证明，在两个任务上——用 LSTM 做小数加法、在 Minecraft 中导航——TSCL 与精心手工设计的课程成绩持平或更优。使用自动生成的课程，我们解决了直接在"解迷宫"上训练时完全无法解决的 Minecraft 迷宫，且学习速度比均匀采样子任务快一个数量级。
