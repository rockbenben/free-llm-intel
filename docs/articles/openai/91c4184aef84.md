# 通过无监督学习提升语言理解

Illustration: Ben Barry


我们用一套可扩展、与任务无关的系统在一系列多样的语言任务上取得了最先进结果，并且我们也在发布这套系统。我们的方法是两个已有理念的结合：[transformer⁠(opens in a new window)](https://arxiv.org/abs/1706.03762) 和 [无监督预训练⁠(opens in a new window)](https://arxiv.org/abs/1511.01432)。这些结果提供了一个有说服力的例子：监督学习方法配上无监督预训练非常好用；这个理念过去许多人探索过，我们希望我们的结果能激励更多人去研究在更大、更多样的数据集上应用这一想法。

我们的系统分两个阶段：先以无监督方式在海量数据上训练一个 transformer 模型——用语言建模作为训练信号——然后在小得多的监督数据集上微调这个模型，帮它解决具体任务。我们是在 [sentiment neuron⁠](https://openai.com/index/unsupervised-sentiment-neuron/) 工作之后发展这一方法的，当时我们注意到无监督学习技术在足够多的数据上训练后能产出出人意料地具判别力的特征。这一次我们想进一步探索：能不能做一个模型，用无监督方式在大量数据上训练，然后微调它，让它在许多不同任务上都取得好表现？我们的结果表明这个方法好得出人意料——同一个核心模型只需极少的适配，就能微调到截然不同的任务上。

这项工作建立在 [Semi-supervised Sequence Learning⁠(opens in a new window)](https://arxiv.org/abs/1511.01432) 引入的方法之上，该工作展示了如何用 LSTM 的无监督预训练加监督微调来提升文档分类表现。它也扩展了 [ULMFiT⁠(opens in a new window)](https://arxiv.org/abs/1801.06146)——那项研究表明单一一个与数据集无关的 LSTM 语言模型可以通过微调在各种文档分类数据集上拿到最先进结果；我们的工作则展示如何用基于 Transformer 的模型在这条路上成功，覆盖文档分类之外更广的任务，比如常识推理、语义相似度、阅读理解。它与 [ELMo⁠(opens in a new window)](https://allennlp.org/elmo) 相似但更与任务无关——ELMo 也纳入了预训练，但要靠任务定制的架构才能在一大套任务上拿到最先进结果。

取得这些结果几乎没做什么调参。所有数据集都使用同一个前向语言模型、不做任何集成，而且大多数报告的结果用的是一套完全相同的超参数。

让我们格外兴奋的一个结果，是方法在三个数据集上的表现——[COPA⁠(opens in a new window)](http://people.ict.usc.edu/~gordon/copa.html)、[RACE⁠(opens in a new window)](https://arxiv.org/abs/1704.04683) 和 [ROCStories⁠(opens in a new window)](http://cs.rochester.edu/nlp/rocstories/)——它们是为测试常识推理和阅读理解而设计的。我们的模型在这三个数据集上以大幅优势创下新的最先进纪录。一般认为这些数据集需要跨句推理和大量世界知识才能解决，这说明我们的模型主要通过无监督学习提升了这些技能。这意味着通过无监督技术培养复杂的语言理解能力是有希望的。

## 为什么是无监督学习？

监督学习是机器学习近来大多数成功的核心。但它要大量、精心清洗、造价昂贵的数据集才能工作得好。无监督学习的吸引力正在于有望解决这些短板。由于去掉了人工显式标注这一瓶颈，它也很好地契合[算力持续增长⁠(opens in a new window)](https://blog.openai.com/ai-and-compute/) 和原始数据日益丰富的趋势。无监督学习是一个[非常⁠(opens in a new window)](https://arxiv.org/abs/1611.09842) [活跃⁠(opens in a new window)](https://arxiv.org/abs/1606.03657) 的[研究⁠(opens in a new window)](https://arxiv.org/abs/1712.06651) [领域⁠(opens in a new window)](https://arxiv.org/abs/1603.09246) [……](https://arxiv.org/abs/1606.05579)，但它的实际用途常常仍然有限。

近来有一波努力，尝试用无监督学习给系统补充海量无标签数据，以进一步提升语言能力；用无监督技术训练的词的表示可以吃下 TB 级的数据，与监督学习结合后能改善一系列 NLP 任务的表现。直到不久前，这些 NLP 无监督技术（比如 [GLoVe⁠(opens in a new window)](https://nlp.stanford.edu/projects/glove/) 和 [word2vec⁠(opens in a new window)](https://arxiv.org/abs/1310.4546)）用的都是简单模型（词向量）和简单训练信号（词的局部共现）。[Skip-Thought Vectors⁠(opens in a new window)](https://arxiv.org/abs/1506.06726) 是更早展示更复杂方法潜力的一个著名例子。而现在新的技术在进一步推高表现，包括使用预训练的句子表示模型、上下文词向量（以 [ELMo⁠(opens in a new window)](https://allennlp.org/elmo) 和 [CoVE⁠(opens in a new window)](https://einstein.ai/research/learned-in-translation-contextualized-word-vectors) 为代表），以及像我们这样用定制架构把无监督预训练和监督微调融合起来的方法。

我们还注意到，可以借助底层语言模型本身去执行任务，而完全不用在这些任务上训练过。例如，在"从选择题里挑正确答案"这类任务上，随着底层语言模型变强，表现稳步提升。虽然这些方法的绝对表现与监督最先进水平相比往往仍然不高（在问答上甚至还比不过简单的滑动窗口 baseline），但这种行为在一大批任务上都很稳健，令人鼓舞。随机初始化、不携带任何任务与世界知识的网络用这些启发式方法做不出高于随机的表现。这为"生成式预训练为何能提升下游任务表现"提供了一些理解。

我们还可以利用模型已有的语言能力做情感分析。在由正面和负面影评句子组成的 Stanford Sentiment Treebank 数据集上，我们可以用语言模型来猜一篇影评是正面还是负面：在句子后面输入单词 "very"，看模型预测 "positive" 还是 "negative" 的概率更高。这种完全不针对任务调整模型的做法，表现与经典 baseline 持平[（约 80% 准确率⁠(opens in a new window)](https://nlp.stanford.edu/~socherr/EMNLP2013_RNTN.pdf)）。

我们的工作也是对 transformer 架构稳健性与实用性的验证，表明它足够灵活，无需复杂的任务定制或调参就能在各种任务上取得最先进结果。

## 短板

这个项目还有几个值得一提的未决问题：

- **算力需求**：很多先前的 NLP 方法是在单块 GPU 上从零训练相对小的模型。我们的方法需要一个昂贵的预训练步骤——8 块 GPU 跑一个月。幸运的是，这只需做一次，而且我们发布模型，让别人可以跳过这一步。它也是一个大模型（与先前工作相比），因此消耗更多算力和内存——我们使用 37 层（12 block）的 Transformer 架构，训练序列最长 512 token。大多数实验在 4 卡和 8 卡系统上完成。好在模型微调到新任务非常快，一定程度缓解了额外的资源需求。
- **通过文本认识世界的局限与偏差**：书籍和互联网上唾手可得的文本不包含关于世界的完整、甚至准确的信息。[近期工作⁠(opens in a new window)](https://arxiv.org/abs/1705.11168) 表明某些信息仅靠文本很难学到，[另一项工作⁠(opens in a new window)](https://arxiv.org/abs/1803.02324) 则表明模型会学习并利用数据分布中的偏差。
- **泛化仍然脆弱**：虽然我们的方法在一大批任务上提升了表现，当前的深度学习 NLP 模型仍会出现令人惊讶、违反直觉的行为——尤其在系统性、对抗性或分布外评估时。我们的方法对此并不免疫，不过我们观察到一些进步迹象。在文本蕴含上，相比先前纯神经方法，我们的方法展现了更好的词汇鲁棒性。在 [Glockner et al. (2018)⁠(opens in a new window)](https://arxiv.org/abs/1805.02266) 提出的数据集上，我们的模型达到 83.75%，与 [KIM⁠(opens in a new window)](https://arxiv.org/abs/1711.04289) 表现相仿——后者通过 WordNet 引入了外部知识。

## 未来

- **扩展这套方法**：我们观察到语言模型表现的提升与下游任务的提升高度相关。我们目前用的是商用硬件（一台 8 GPU 机器）和只有几千本书（约 5GB 文本）的训练数据集。这说明沿"更多算力和数据"这条久经验证的路，还有很大提升空间。
- **改进微调**：我们的方法目前非常简单。使用更精巧的适配和迁移技术（如 [ULMFiT⁠(opens in a new window)](https://arxiv.org/abs/1801.06146) 中探索的那些），很可能还有大幅提升空间。
- **更好理解生成式预训练为何有效**：虽然我们在文中讨论了一些自己倾向的解释，更有针对性的实验和研究将帮助区分各种竞争性解释。例如，我们观察到的收益中，有多少来自处理更宽上下文的能力提升，多少来自世界知识的增加？
