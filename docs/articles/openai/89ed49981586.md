我们为 [Lean⁠(opens in a new window)](https://leanprover.github.io/) 构建了一个神经定理证明器，它学会求解各种有挑战性的高中奥林匹克数学题，包括来自 [AMC12⁠(opens in a new window)](https://www.maa.org/math-competitions/amc-1012) 和 [AIME⁠(opens in a new window)](https://www.maa.org/math-competitions/invitational-competitions) 竞赛的题目，以及两道改编自 [IMO⁠(opens in a new window)](https://www.imo-official.org/) 的题目。[A](https://openai.com/index/formal-math/#citation-bottom-A) 该证明器使用语言模型来寻找形式化命题的证明。每当我们找到一个新证明，就把它用作新的训练数据，从而改进神经网络，让它能迭代地求解越来越难的命题。

我们在 [miniF2F⁠(opens in a new window)](https://arxiv.org/abs/2109.00110) 基准测试上取得了新的最先进成绩（41.2% 对 29.3%），这是一组难度很高的高中奥赛题集合。我们的方法被称为*命题课程学习*（statement curriculum learning），其做法是人工收集一组难度不等、但没有证明的命题，其中最难的命题与我们瞄准的基准测试相似。最初我们的神经证明器很弱，只能证明其中少数几个。我们迭代地搜索新证明，并用新发现的证明重新训练神经网络；经过 8 轮迭代后，在 miniF2F 上测试时，我们的证明器已经强大得多。

形式化数学是一个值得研究的激动人心的领域，因为（i）它极其丰富，你可以证明任意定理，而这些证明需要推理、创造力和洞察力；（ii）它与游戏相似——AI 在游戏领域已取得非凡成功——它有自动判定证明是否成功的方式（即由形式系统验证）。如下面这个简单的例子所示，证明一个形式化命题需要生成一串证明步骤，每一步都是对一个策略（tactic）的调用。[B](https://openai.com/index/formal-math/#citation-bottom-B)

这些策略以数学术语作为参数，每次策略调用都会把当前待证的命题转换成更容易证明的命题，直到没有任何东西需要证明。


我们观察到，生成策略所需的原创数学术语的能力——没有神经语言模型就做不到这一点——是从我们的训练过程中涌现出来的。下面的证明就是一个例子：证明步骤 `use n + 1`（完全由我们的模型生成）提出用 `n + 1` 作为解，形式化证明的其余部分则依靠 `[ring_exp](https://leanprover-community.github.io/mathlib_docs/tactic/ring_exp.html)` 策略来验证它确实是有效的。


我们还观察到，我们的模型和搜索过程能够产出串联多个非平凡推理步骤的证明。在下面的证明中，模型首先使用逆否命题，得到存在性命题（`∃ (x : ℝ), f x ≠ a * x + b`），然后生成一个见证项 `use (0 : ℝ)`，并借助 `[norm_num](https://leanprover-community.github.io/mathlib_docs/tactics.html#norm_num)` 策略完成证明。

形式化数学存在两大挑战，使得直接套用强化学习不太可能成功。

- （i）**无限动作空间**：形式化数学不仅有极大的搜索空间（比如围棋），还有无限的动作空间。在证明搜索的每一步，模型不是从一个规整的有限动作集中选择，而是要从一个复杂且无限的策略集合中选择，其中还涉及需要生成的外源数学术语（例如，生成一个用作见证的数学命题——“存在 *x* 使得……”这类步骤中的对象，或者一个 cut，即在证明中途引入并衔接一个引理）。
- （ii）**缺乏自我对弈**：与双人游戏相反，证明器不是在和对手对弈，而是在和一组待证命题较劲。当遇到一个实在太多的命题时，没有明显的重构方式能让证明器先生成一些较容易的中间命题来练手。这种不对称性使得在双人游戏中取得成功的自我对弈算法无法直接套用。

在我们的工作中，通过在搜索证明的过程中从语言模型采样动作，解决了无限动作空间的问题。语言模型能够生成策略调用，以及常常作为参数所需的原创数学术语。对于缺乏自我对弈的问题，我们的出发点是一个观察：自我对弈在双人游戏中的关键作用是提供无监督的课程。我们的方法论提出用一个难度不等的辅助问题命题集合（不需要证明）来替代这个无监督课程。我们通过实验表明，只要这些辅助问题的难度跨度足够大，我们的训练过程就能解决一个难度递增的课程，最终泛化到我们真正关心的问题上。

虽然这些结果令人极其振奋——它们表明深度学习模型在与形式系统交互时具备非平凡的数学推理能力——但我们距离这些竞赛中优等生的水平仍有很远的差距：只是偶尔、而不是稳定地解出有挑战性的奥赛题。尽管如此，我们希望这项工作能激发该领域的研究热情，尤其是面向 [IMO 大挑战⁠(opens in a new window)](https://imo-grand-challenge.github.io/) 的研究，也希望我们提出的*命题课程学习*方法能帮助加速自动推理领域的整体进展。

## 脚注

- A 这些题目不是普通的数学练习题，它们是让美国（AMC12、AIME）或全世界（IMO）最优秀的高中生互相竞技的题目。
- B 形式系统接受的构件是低层的（类似汇编代码），人类很难直接写出。策略是搜索过程，能从更高层的指令生成这些构件，以辅助形式化。
