# 欢迎 Pieter 和 Shivon！

我们又有两条团队更新。

插图：Justin Jay Wang × DALL·E

- **Pieter Abbeel**。[Pieter](http://www.cs.berkeley.edu/~pabbeel) 是 UC Berkeley 教授，专攻让机器人学习。早在 OpenAI 诞生之前他就在为我们提供建议，如今他从 Berkeley 休假，全职与我们共事。Pieter 和他的实验室成员近年来主导了[机器人学习](http://www.bloomberg.com/features/2015-preschool-for-robots/)和[深度强化学习（RL）](http://rll.berkeley.edu/deeplearningrobotics/)领域一些最引人注目的进展。我们将一起探索把无监督学习与 RL 结合的方法——我们相信这能解决当今 RL 算法的根本局限。
- **Shivon Zilis**。[Shivon](http://www.shivonzilis.com/) 是 [Bloomberg Beta](https://github.com/Bloomberg-Beta/Manual) 专注机器智能的合伙人。她对这一领域的演进有着极其开阔的视野（并就这一版图[撰写](http://techcrunch.com/2015-11-26/machine-intelligence-in-the-real-world/)[过](https://www.oreilly.com/ideas/the-current-state-of-machine-intelligence-2-0)[大量](https://medium.com/@shivon/the-current-state-of-machine-intelligence-f76c20db2fe1)文章）。过去几个月我们一直向她求教，如今她正式成为 OpenAI 的顾问。

能与两位合作，我们无比兴奋。欢迎 Pieter 和 Shivon！
