# OpenAI、Grupo Folha 与 Grupo UOL 宣布战略内容合作

OpenAI 在巴西的首个媒体合作，将把 Folha de S.Paulo 和 UOL 的新闻带入 ChatGPT。

从今天起，全球超过 9 亿的 ChatGPT 周活跃用户将能够访问高质量新闻，并看到基于 Folha de S.Paulo 和 UOL 报道生成的摘要。这是 OpenAI 在巴西的首个媒体合作，也植根于我们与全球新闻机构协作的更大努力之中。

通过与多个市场的出版方合作——包括美国、英国、法国、德国，以及现在的巴西——OpenAI 致力于把可靠的报道整合进 AI 驱动的体验，帮助以强调署名、透明度和回链原始来源的方式把新闻带入 ChatGPT。正如 Folha de S.Paulo 总编辑 Sérgio Dávila 所说：*“像 OpenAI 这样的人工智能巨头愿意展示 Folha de S.Paulo 和 UOL 生产的内容，恰恰印证了专业新闻的重要性。”*

*“Folha de S.Paulo 和 UOL 是巴西最权威的原创报道来源之一。通过让它们的新闻在 ChatGPT 中可及，我们希望为 ChatGPT 带来更有用、更及时、更贴近本地相关的回答，同时支撑更广泛的新闻生态，”* OpenAI 媒体合作副总裁 Varun Shetty 表示。

这一合作为 Folha de S. Paulo 和 UOL 触达新的全球受众创造了机会，也将帮助用户在 ChatGPT 上发现可信信息。*“AI 将定义新闻行业的下一个时代，而 Folha 希望参与塑造这个未来。通过与 OpenAI 合作，我们把 Folha 置于这场变革的前沿，为拓展可信新闻的传播范围、相关性和影响力创造新的方式，”* Folha de S.Paulo 联席首席执行官 Carlos Ponce de Leon 表示。

*“AI 平台得益于可靠的消息来源，因此它们与高质量内容的创作者合作顺理成章，”* UOL 首席执行官 Paulo Samia 表示。对于 UOL 内容总监 Murilo Garavello 而言，*“我们希望自己的新闻出现在巴西人使用的每一个场景中——也让真实的信息尽可能广泛地传播。”* 巴西目前是全球 ChatGPT 最大的市场之一，月活跃用户超过 5000 万，每天交换的消息约有 1.4 亿条。

通过这一合作，Grupo Folha 和 Grupo UOL 还将获得 Codex、ChatGPT Enterprise 和 API 的使用权限，以探索 AI 支持其新闻工作的新方式、为读者开发创新产品与功能，并优化内部工作流程与业务运营。
