# ChatGPT 中停用 GPT-4o、GPT-4.1、GPT-4.1 mini 与 OpenAI o4-mini

2026 年 2 月 13 日，我们将连同[此前已宣布停用的⁠](https://openai.com/index/gpt-5-1/) GPT-5（Instant 和 Thinking）一起，在 ChatGPT 中停用 GPT-4o、GPT-4.1、GPT-4.1 mini 和 OpenAI o4-mini。API 方面暂时没有任何变化。

虽然这一公告涉及多个旧模型，但 GPT-4o 值得特别说明。

在我们最初弃用它、随后又在 GPT-5 发布期间恢复访问之后，我们对人们日常如何使用它有了更深的了解。听取了一部分 Plus 和 Pro 用户的明确反馈后，我们把 GPT-4o 带了回来——他们表示需要更多时间迁移创意生成等关键用例，并且更喜欢 GPT-4o 的对话风格和温度。

这些反馈直接塑造了 GPT-5.1 和 GPT-5.2：个性方面的改进、对创意生成的更强支持，以及更多[自定义 ChatGPT 回复方式](https://help.openai.com/en/articles/11899719-customizing-your-chatgpt-personality)的选项。你可以选择 Friendly 等基础风格和语气，以及控制温度、热情度等。我们的目标是让人们对自己的使用体验（而不仅是 ChatGPT 的能力）拥有更多控制和自定义空间。

我们今天宣布 GPT-4o 即将停用，因为这些改进已经就位，也因为绝大多数使用已转向 GPT-5.2——每天仍选择 GPT-4o 的用户只有 0.1%。

更广泛地说，我们正在用户指出需要改进的方面持续提升 ChatGPT，包括进一步改进个性与创造力，以及解决不必要的拒答、过度谨慎或说教式的回复——相关更新即将到来。我们正在继续朝一个为 18 岁以上成年人设计的 ChatGPT 版本推进，其原则是“像成年人一样对待成年人”，在恰当的保护措施内扩大用户的选择与自由。为配合这一点，我们已在大多数市场为 18 岁以下用户推出了[年龄预测](https://help.openai.com/en/articles/12652064-age-prediction-in-chatgpt)。

这样的变化需要时间适应，我们会始终清晰说明改什么、何时改。我们知道失去对 GPT-4o 的访问会让一些用户沮丧，这个决定我们绝非轻率做出。停用模型从来都不容易，但它能让我们专注于改进大多数人今天使用的模型。
