# 学会合作、竞争与沟通

View code







智能体为争夺资源而竞争的多人（multiagent）环境，是通往 AGI 道路上的垫脚石。多智能体环境有两个有用的性质：第一，它天然自带课程——环境的难度由你对手的水平决定（如果你在和自己克隆体竞争，环境难度就恰好与你的水平匹配）。第二，多智能体环境没有稳定均衡：无论一个智能体多聪明，总有让它变得更聪明的压力。这类环境与传统环境的感觉非常不同，我们要把它们玩明白还需要很多研究。

我们开发了一种新算法 [MADDPG](https://arxiv.org/abs/1706.02275)，用于多智能体环境中的集中训练与分散执行，让智能体学会彼此合作与竞争。

MADDPG 训练了四个红色智能体去追逐两个绿色智能体。红色智能体学会了彼此配合、合力追逐单个绿色智能体，从而获得更高奖励。绿色智能体则学会了分头行动：当一个被追时，另一个设法避开红色智能体、靠近水源（蓝色圆圈）。

MADDPG 扩展了一个叫 [DDPG](https://arxiv.org/abs/1509.02971) 的强化学习算法，并从 [actor-critic 强化学习](http://webber.physik.uni-freiburg.de/~hon/vorlss02/Literatur/sutton/6/node7.html) 技术中汲取灵感；其他团队也在[探索](https://arxiv.org/abs/1605.07736) 这些思路的[变体](https://arxiv.org/abs/1605.06676) 和[并行实现](https://arxiv.org/abs/1705.08926)。

我们把仿真中的每个智能体当作一个「演员」（actor），每个演员都从一个「评论家」（critic）那里获得建议，帮助它决定在训练中应强化哪些动作。传统做法中，评论家尝试预测某个动作在特定状态下的*价值*（即我们期望未来获得的奖励），供智能体——*演员*——用来更新其策略。这比直接使用波动很大的奖励更稳定。为了让训练多个能以全局协调方式行动的智能体变得可行，我们增强了评论家，让它们能访问所有智能体的观测和动作，如下图所示。

我们的智能体在测试时不需要访问中央评论家；它们基于自身观测、结合对其他智能体行为的预测来行动。由于集中式评论家是为每个智能体独立学习的，我们的方法还能用来建模智能体之间任意的奖励结构，包括奖励相互对立的对抗情形。


我们在各种任务上测试了这套方法，它全部优于 DDPG。在上面的动画中你可以看到，从左到右：两个 AI 智能体试图前往某个位置，并学会分头行动以向对手隐藏自己想去的位置；一个智能体向另一个智能体[传达某个地标的名称](https://blog.openai.com/learning-to-communicate/)；三个智能体协调前往各地标且互不相撞。


## 传统强化学习吃力的地方

传统的去中心化 RL 方法——DDPG、actor-critic 学习、深度 Q-learning 等——在多智能体环境中学习很吃力，因为在每个时间步，每个智能体都要一边行动、一边学着预测其他智能体的动作。在竞争情形下尤其如此。MADDPG 采用集中式评论家，为智能体提供关于同伴观测和潜在动作的信息，把不可预测的环境变成可预测的环境。

使用策略梯度方法还带来额外挑战：由于方差高，奖励不稳定时很难学到正确的策略。我们还发现，加入评论家虽然提升了稳定性，但仍无法解决我们的若干环境，比如合作沟通。看起来，在训练时考虑他人的动作对学习协作策略很重要。

## 早期研究

在开发 MADDPG 之前，使用去中心化技术时，我们注意到当说话者发出的「该去哪」的信息前后不一致时，听者智能体往往学会忽略说话者。随后智能体会把与说话者信息相关的所有权重置为 0，相当于把自己弄聋。一旦发生这种情况，训练很难恢复，因为没有任何反馈，说话者永远不知道自己说的对不对。为了解决这个问题，我们参考了[一个近期分层强化学习项目](https://arxiv.org/abs/1703.01161) 中提出的技术，它允许我们强制听者把说者的话语纳入决策过程。这个修复没起作用——虽然它迫使听者注意说者，却帮不了说者弄清楚该说什么才相关。我们的集中式评论家方法有助于应对这些挑战，它帮助说者学会哪些话语可能与其他智能体的动作相关。更多结果可以看下面的视频：

## 下一步

智能体建模在 AI 研究中[历史悠久](https://link.springer.com/article/10.1007/s10458-005-2631-2)，其中很多场景早已被研究过。许多[先前的研究](http://ieeexplore.ieee.org/document/4445757/) 考虑的是时间步很少、状态空间很小的游戏。深度学习让我们能处理复杂的视觉输入，RL 则给了我们跨越长时间段学习行为的工具。现在我们可以用这些能力同时训练多个智能体，而它们不需要知道环境的动态（环境在每个时间步如何变化），这样我们就能在从环境高维信息中学习的同时，处理更广泛的沟通与语言问题。如果有兴趣探索演化智能体的不同方法，欢迎[加入 OpenAI⁠](https://openai.com/careers/)。
