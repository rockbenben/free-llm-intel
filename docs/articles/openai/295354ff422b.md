# 图像 2.6 隆重登场

更快的图像生成速度，更好地掌控每一轮编辑

我们在 ChatGPT、Codex 和 API 中推出了图像 2.6，让你的创意更快成为现实。你可以用 GIF 让图像动起来，比如为品牌吉祥物或角色制作动画，或把产品照片变成亮眼的循环动图。你还可以更快地创作出精美的视觉作品，并进行更精准的调整，在编辑过程中保持角色、产品和品牌细节一致。

如今，全球用户每周通过 ChatGPT、Codex 和 API 生成 40 亿张图像，平均每天超过 5 亿张。

## 迭代更快，视觉效果更专业

图像 2.6 的图像生成速度比以前快 50%。在 API 中，开发者可以选择 GPT‑Image‑2.6 Flare 或 GPT‑Image‑2.6 Sunburst。将图像质量设为低时，Flare 最快只需六秒就能生成图像。对于细节和精度要求较高的任务，将图像质量设为中或高时，Sunburst 可以生成更高质量的图像，并在多轮编辑中更好地保持图像一致性。Flare 还改进了海报、产品图片和其他专业视觉作品的布局效果。

## 通过 API 创作和编辑的更多方式

借助图像 2.6，开发者可以更灵活地创建和编辑图像，并将成果用于项目的下一阶段。ChatGPT 已有的图像标注功能现已加入 API，让团队能够精确指出要修改的位置和内容。导出的 SVG 文件可直接用于网站、应用和印刷品。

开发者可以通过新增的复杂度参数，调整模型在处理请求时投入多少精力进行规划。较低的复杂度适合快速编辑。图像质量控制视觉细节和保真度，复杂度则影响场景内容的丰富程度。

> “GPT‑Image‑2.6 兼顾速度与创作控制，帮助你生成和编辑图像，同时保留角色、产品或品牌独有的细节。我们很高兴将它引入 Figma Weave，让团队在可复用的工作流中又多了一款强大的创作模型。”

—Itay Schiff，Figma Weave 创意总监

对于大多数编辑任务，我们建议将复杂度设为低以加快编辑速度，并根据工作流需求选择图像质量。如果场景中的元素多或限制条件多，可以尝试将复杂度设为中或高。
