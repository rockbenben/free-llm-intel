# OpenAI 将 GPT‑3 技术授权给微软

OpenAI 已同意把 GPT‑3 授权给微软，用于微软自己的产品和服务。

加载中…

OpenAI 在 6 月发布了首个商业产品：一个 [API⁠](https://openai.com/index/openai-api/)，让开发者调用先进技术来构建新的应用与服务。这个 API 提供一个强大的通用语言模型 [GPT‑3⁠(在新窗口打开)](https://arxiv.org/abs/2005.14165)，迄今已收到数万个申请。

除了通过 OpenAI API 提供 GPT‑3 及未来模型，作为去年宣布的[多年期合作伙伴关系⁠(在新窗口打开)](https://news.microsoft.com/2019-07-22/openai-forms-exclusive-computing-partnership-with-microsoft-to-build-new-azure-ai-supercomputing-technologies/) 的一部分，OpenAI 也同意把 GPT‑3 授权给微软用于其自身的产品与服务。这笔交易不影响通过 OpenAI API 继续使用 GPT‑3，现有和未来的用户都可以照常通过我们的 API 构建应用。

与大多数为单一用途设计的 AI 系统不同，OpenAI 的 API 如今提供的是通用的"文本进、文本出"接口，用户可以拿它尝试几乎任何英语语言任务。GPT‑3 是当前 API 背后最强的模型，有 1750 亿参数。API 今天还提供其他若干模型，以及其它技术和过滤器，让开发者可以为自己的用途定制 GPT‑3 和其他语言模型。
