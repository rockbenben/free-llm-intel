# GPTs 来了

现在，你可以创建 ChatGPT 的自定义版本，把指令、额外知识和各种技能组合在一起。

## 本篇介绍的是 GPTs 的发布。

ChatGPT Work

我们正在推出可由你为特定目的创建的 ChatGPT 自定义版本——称为 GPTs。GPTs 是任何人定制 ChatGPT 的新方式，让它在日常生活、特定任务、工作或家庭中更有帮助——然后你还可以把你的创作分享给别人。例如，GPTs 可以帮你[学习任何桌游的规则、教孩子数学或设计贴纸⁠](https://openai.com/chatgpt/#do-more-with-gpts)。

任何人都能轻松构建自己的 GPT——无需写代码。你可以为自己做、仅供公司内部使用，或面向所有人。创建过程就像开启一段对话：给它指令和额外知识，再选择它能做什么（比如搜索网页、生成图片或分析数据）。来 [chatgpt.com/create⁠（在新窗口中打开）](https://chatgpt.com/create) 试试。

部分示例 GPTs 今天已向 ChatGPT Plus 和 Enterprise 用户开放体验，包括 [Canva⁠（在新窗口中打开）](https://chat.openai.com/g/g-alKfVrz9K-canva) 和 [Zapier AI Actions⁠（在新窗口中打开）](https://zapier.com/blog/gpt-assistant/)。我们计划很快向更多用户提供 GPTs。

### GPTs 让你为特定用途定制 ChatGPT

自 ChatGPT 发布以来，人们一直要求以各种方式定制 ChatGPT 来契合自己的具体用法。我们在 7 月推出了 Custom Instructions（自定义指令），可以设置一些偏好，但对更多控制权的请求不断涌来。许多重度用户维护着一份精心编写的提示词和指令集清单，手动把它们复制进 ChatGPT。现在，GPTs 替你包办了这一切。

### 最好的 GPTs 将由社区发明

我们相信，最出色的 GPTs 将来自社区中的创造者。无论你是教育者、教练，还是单纯喜欢打造实用工具的人，你都不需要懂编程，就能做出一个 GPT 并分享你的专业知识。

### GPT Store 本月晚些时候推出

从今天起，你可以创建 GPTs 并公开分享。本月晚些时候，我们将上线 GPT Store，收录由认证构建者打造的作品。进入商店后，GPTs 将可被搜索，并可能登上排行榜。我们还会在生产力、教育、“纯属好玩”等类别中，聚光灯推荐我们发现的最有用、最有趣的 GPTs。未来几个月，你还将能够根据使用你 GPT 的人数获得收入。

### 我们构建 GPTs 时兼顾隐私与安全

一如既往，在 ChatGPT 中你的数据由你掌控。你与 GPTs 的对话不会分享给构建者。如果某个 GPT 使用第三方 API，由你决定数据是否可以发送到该 API。当构建者用自己的 actions 或知识定制其 GPT 时，构建者可以选择用户与该 GPT 的对话是否可用于改进和训练我们的模型。这些选择建立在用户已有的[隐私控制⁠（在新窗口中打开）](https://help.openai.com/en/articles/7730893-data-controls-faq)之上，包括将整个账户退出模型训练的选项。

我们建立了新系统，帮助依据我们的[使用政策⁠](https://openai.com/policies/usage-policies/)审查 GPTs。这些系统叠加在现有缓解措施之上，旨在防止用户分享有害 GPTs，包括涉及欺诈活动、仇恨内容或成人主题的作品。我们还采取措施构建用户信任，允许构建者验证身份。我们将持续监控并了解人们如何使用 GPTs，更新并强化我们的安全缓解措施。如果你对某个具体 GPT 有顾虑，也可以在 GPT 分享页使用举报功能通知我们团队。

GPTs 会越来越有用、越来越聪明，最终你将能够让它们在现实世界中承担真实任务。在 AI 领域，这类系统常被讨论为“agent”（智能体）。我们认为朝着这一未来渐进式推进很重要，因为它需要细致的技术与安全工作——也给社会留出适应时间。我们一直在深入思考其社会影响，很快会分享更多分析。

### 开发者可以把 GPTs 连入现实世界

除了使用我们的内置能力，你还可以通过为 GPT 开放一个或多个 API 来定义自定义 actions。与 plugins 一样，actions 让 GPTs 能够整合外部数据或与真实世界交互。把 GPTs 连到数据库、接入邮箱，或让它成为你的购物助手。例如，你可以整合一个旅行列表数据库、连接用户的邮箱收件箱，或促成电商下单。

actions 的设计汲取了我们 plugins beta 的经验，让开发者对模型及其 API 的调用方式拥有更大控制权。从 plugins beta 迁移也很简单：你可以用现成的 plugin manifest 为 GPT 定义 actions。

### 企业客户可以部署仅限内部的 GPTs

自几个月前 ChatGPT Enterprise 发布以来，早期客户表达了希望按自身业务进一步定制的意愿。GPTs 回应了这一诉求：你可以为特定用例、部门或专有数据集创建 ChatGPT 的定制版本。Amgen、Bain、Square 等早期客户已经在用内部 GPTs 做各种事情，比如打造体现品牌风格的营销材料、帮助客服团队回答客户问题、协助新入职的软件工程师完成 onboarding。

企业客户周三起即可上手 GPTs。你可以让公司内的用户无需代码设计仅限内部使用的 GPTs，并安全地发布到你的工作区。通过管理控制台，你可以选择 GPTs 如何共享，以及是否允许在你的企业内使用外部 GPTs。与 ChatGPT Enterprise 上的所有使用一样，我们不会使用你与 GPTs 的对话来改进我们的模型。

### 我们希望更多人参与塑造 AI 的行为

我们设计 GPTs 就是为了让更多的能和我们一起构建。让社区参与对我们“构建安全且造福人类的 AGI”的使命至关重要。它让每个人都能看到广泛而多样的实用 GPTs，对未来的可能性有更具体的感受。而通过把“建什么”的决定权扩大到不仅限于掌握先进技术的人群，我们很可能会得到更安全、对齐更好的 AI。这种“与人共创、而非仅为人代建”的诉求，也推动我们推出 OpenAI API，并研究把民主输入纳入 AI 行为的方法——我们很快会分享更多内容。

### 我们让 ChatGPT Plus 更新、更简洁

最后，ChatGPT Plus 现已包含截至 2023 年 4 月的最新信息。我们也听到了你们对模型切换器繁琐的抱怨。从今天起，不再需要在模型间跳来跳去，你需要的一切尽在一处。无需切换即可使用 DALL·E、浏览和数据分析。你还可以附加文件，让 ChatGPT 搜索 PDF 及其他文档。访问 [chatgpt.com⁠（在新窗口中打开）](https://chatgpt.com) 找到我们。
