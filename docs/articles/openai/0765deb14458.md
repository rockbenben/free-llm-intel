# Airbnb 扩大 GPT‑6 Astra 和 OpenAI 前沿模型的使用范围


根据一项新协议，Airbnb 将扩大其工程和产品开发团队对 OpenAI 前沿模型的使用范围，其中包括 GPT‑6 Astra。

此次扩展以 Airbnb 对 Codex 的应用及其与 OpenAI 的长期合作为基础。Airbnb 工程师使用内部 AI 助手编写软件，并创建由 Codex 以及 GPT‑5.6 Sol、Terra 和 Luna 等模型驱动的远程 AI 智能体。

根据新协议，Airbnb 可通过 OpenAI API 和 Amazon Bedrock 更广泛地使用 OpenAI 模型。与此同时，开发者、构建者和企业正加速采用 GPT‑6 Astra，其中许多用户此前已经受益于 GPT‑5.6 Terra 和 Luna 更出色的[性价比与效率](https://openai.com/index/advancing-the-price-performance-frontier-with-gpt-5-6/)。

Airbnb 对 GPT‑6 Astra 的早期应用已在编码之外展现出优异成效。Astra 可帮助 Airbnb 工程师排查棘手的错误、完善系统设计并集思广益探索工程方案，从而加快工作进度。在一项涉及战略文档和其他非编码工作的测试中，一名 Airbnb 用户表示，仅需 3 至 4 轮即可获得出色成果，而使用其他模型则需要 20 多轮。

> “我们的开发团队交付的功能数量比一年前增加了约 80%。包括 GPT‑6 Astra 在内的 OpenAI 前沿模型是我们开发者工具体系的关键组成部分，帮助我们保持这一势头，更快地打造更出色的产品。”

—Ahmad Al-Dahle，Airbnb 首席技术官

> “Airbnb 一直在利用 AI 重新构想软件开发方式，而扩大 GPT‑6 Astra 等模型的使用范围，将为其团队提供更强大的工具，帮助他们更快地将创意转化为产品。随着 Airbnb 将 OpenAI 的能力应用于工程工作以及为数百万房客和房东打造的体验，我们很自豪能够进一步深化双方合作。”

—Dali Rajic，OpenAI 首席营收官

Airbnb 还利用 OpenAI 模型为搜索、欺诈防范、房客与房东支持以及保险理赔等场景提供助力。通过在整个平台深入应用 AI 和机器学习，Airbnb 能更好地了解房客的需求，识别可能存在欺诈的内容或索赔，在旅行计划发生变化时为房客提供帮助，并让房东更快、更便捷地获得保险赔款。

随着 Airbnb 将更多旅行环节整合到同一款应用中，涵盖住宿、服务、体验、机场接送、汽车租赁等，OpenAI 前沿模型可为构建这些功能的团队提供更强大的工具，帮助他们加快进度并探索未来方向。
