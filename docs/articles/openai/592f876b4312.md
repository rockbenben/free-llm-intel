# OpenAI 黑客松战报

3 月 3 日，我们举办了首届黑客松，100 位人工智能社区成员参加。

3 月 3 日，我们举办了首届 [黑客松⁠（在新窗口中打开）](https://blog.openai.com/hackathon/)，100 位人工智能社区成员参加。活动公布后两天内就收到 500 多个报名——如果你这次没赶上，欢迎下次再来报名！

感谢 [Cirrascale⁠（在新窗口中打开）](http://www.cirrascale.com/) 在黑客松期间提供 GPU 机器。

## 人群

我们的报名者包括高中生、行业从业者、非营利组织的工程师（不只是 OpenAI 自己的！）、大学研究人员等等，兴趣从医疗健康一直覆盖到 AGI。这次我们只能容纳一百人，因此尽量挑选了一群背景和经验水平都足够多元的参与者。尤其地，我们努力实现性别均衡；许多参会者告诉我们，这种代表性让他们在黑客松中的体验更好。

## 演讲

当天以一系列关于 OpenAI 使命和我们研究关注技术主题的演讲开场。Sam Altman 就 AGI 时间表、安全问题以及避免 AI 军备竞赛的重要性回答了提问。Sam 讲述了他个人如何转而关注 AI 安全：他视之为一个投入不足、探索不足，却可能影响每个人的领域。Josh Achiam 介绍了强化学习——我们的主要研究方向之一；我们已开源他演讲的[幻灯片和示例代码⁠（在新窗口中打开）](https://github.com/jachiam/rl-intro)。Ilya Sutskever 谈了基于 RL agent 的自博弈；相关工作的概览见我们最近的[博客⁠（在新窗口中打开）](https://blog.openai.com/meta-learning-for-wrestling/)[文章⁠（在新窗口中打开）](https://blog.openai.com/competitive-self-play/)以及[代码⁠（在新窗口中打开）](https://github.com/openai/robosumo)[发布⁠（在新窗口中打开）](https://github.com/openai/multiagent-competition)。Alec Radford 对种类繁多的 GAN 做了教程与综述，我们已公开[教程代码⁠（在新窗口中打开）](https://github.com/Newmu/gan_tutorial)。

## 动手开发

演讲结束后，黑客正式开始。在 8 小时的编程冲刺中，参与者完成了数十个 AI 项目，主题从安全到医疗无所不包。以下是一些我们特别喜欢的项目：

- Jiale Xian、Clarence Leung、Kyle Zheng、Madeline Hawkins 和 Stergios Hetelekides 做了一个图像分类器，用于识别痛风湿患者应当避开的高嘌呤海鲜。

- [Arthur Juliani⁠（在新窗口中打开）](https://twitter.com/awjuliani/status/970496935982333953) 实现了带好奇心内在奖励的 PPO，并训练了一个撞塌积木塔的 agent：

- 高中生 Ethan Knight 和 Osher Lerner 基于我们的[研究需求⁠（在新窗口中打开）](https://github.com/openai/requests-for-research/blob/master/_requests_for_research/natural-q-learning.html)之一，完成了基于 [Natural Q-Learning⁠（在新窗口中打开）](https://github.com/hyperdo/natural-gradient-deep-q-learning) 的工作。
- Malhar Patel 和 Lee Redden 开发了 [AeroEnv⁠（在新窗口中打开）](https://github.com/LeeRedden/OpenAIHackathon)，一个面向实体机器人的 Gym 接口。
- Rodger Luo 在 Processing（面向媒体艺术家的编程工具）中实现了 [Q-learning⁠（在新窗口中打开）](https://github.com/RodgerLuo/RL_Processing)。
- Andy Matuschak 打造了 [scrying pen⁠（在新窗口中打开）](https://andymatuschak.org/scrying-pen/)——一个基于 [SketchRNN⁠（在新窗口中打开）](https://github.com/tensorflow/magenta-demos/tree/master/sketch-rnn-js) 的趣味机械辅助素描工具。
- James Giammona 和 Brad Neuberg 提出了 RL agent 如何回避环境中未曾见过的危险区域的[想法⁠（在新窗口中打开）](https://paper.dropbox.com/doc/Safety-Distance-Move-Slow-and-Dont-Break-Things-JlrnhtfqENPdfcfTTWfaT?_tk=share_copylink)。
