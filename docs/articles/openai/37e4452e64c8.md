[Cogent Security](https://www.cogent.com/) 看到，企业面临的安全风险比以往任何时候都多，而最难的并不是发现漏洞，而是修复漏洞。修复工作复杂，且涉及多个团队。这需要结合上下文理解企业环境：攻击者可能如何利用漏洞，哪些业务系统面临风险，以及哪些更改可以安全实施。

Cogent 为企业构建网络防御工厂 (Cyber Defense Factory)，以自主发现并消除这些风险。这些工厂旨在帮助防御人员以机器速度行动，应对漏洞发现和利用不断加速的趋势。

该公司的 AI 智能体将 GPT‑6.1 Sol 和 GPT‑5.6 与企业上下文和管控措施相结合，完成从调查到修复验证的全流程工作。智能体评估风险敞口，执行获准的更改，并确认风险已被消除。Cogent 还利用 Cyber 和 Daybreak 开展内部研究，探索攻击路径和防御能力。

> “OpenAI 模型持续执行长时间任务的能力，让企业防御的自主性迈上新台阶：AI 智能体如今能够完成从调查到修复验证的全流程工作。”

—Geng Sng，Cogent 联合创始人兼首席技术官

## 为智能体提供上下文和行动权限

Cogent 的上下文引擎为每位客户维护一个企业知识图谱，涵盖资产、漏洞、身份、归属和依赖关系。专门的后台智能体持续核对并整合各安全工具和系统中的信息，让调查和修复智能体对环境形成一致的理解。

GPT‑6 Astra 负责这项工作的前期规划和复杂推理。由此形成了 Cogent 联合创始人兼首席技术官 Geng Sng 所说的“企业记忆执行框架”。他表示：“我们不必每接到一项新任务，就从头了解一遍整个环境。”复用上下文可以降低延迟和推理成本，减少结果不一致的情况。

Cogent 的智能体策略定义了各企业允许的更改和审批要求，其策略执行引擎 TRACE 会在执行工具调用前检查调用是否符合策略。这些检查基于确定性规则，无需额外的模型推理。

智能体网关独立检查授权，高风险工作则可在隔离的沙盒中运行。客户可以委托智能体开展调查，要求更改须经审批，或允许在限定范围内自主修复。

## 从漏洞披露到修复验证

当用于运行网站的编程语言 PHP 被披露存在名为 PHP2Shell 的严重安全漏洞时，客户求助于 Cogent 已在其环境中部署的网络防御工厂。

GPT‑6.1 Sol 和 GPT‑6 Astra 为调查和修复规划提供了深度推理能力。借助 Cogent 的上下文层，智能体识别受影响的系统，评估风险敞口，并制定兼顾应用依赖关系和运营约束的方案。随后，智能体按照客户定义的审批和执行工作流编排修复操作，并验证问题是否已解决。

据 Cogent 介绍，客户正在利用其网络防御工厂加快漏洞修复，并提升调查能力。借助 Cogent，一家《财富》1000 强汽车行业客户将严重漏洞的平均修复时间缩短了 75%，一家《财富》500 强 IT 服务客户则将漏洞分流吞吐量提升至原来的 5 倍。

交易平台 MarketAxess 表示，Cogent 帮助其确定优先处理哪些风险敞口：“Cogent 从攻击者的视角审视我们的环境。它会追踪从互联网通往易受攻击系统的路径，并检查沿途的管控措施。我们现在将修复工作聚焦于最大的风险，以及攻击者可能利用的入侵路径。”MarketAxess 全球首席信息安全官 Vijay Bala 表示。

## Cogent 为何选择 OpenAI 模型和 Codex 进行开发

Cogent 持续评估其他闭源和开源方案。据其介绍，OpenAI 模型在长时间运行的安全任务中推理能力更强，输出更忠实于实际情况，处理技术代码库时幻觉更少，执行也更可靠。这些模型能够以串行和并行方式衔接工具调用，同时在整个修复工作流中保留上下文。

对于复杂调查，Cogent 优先考虑推理质量；对于较简单的工作，则优先考虑成本。Cogent 使用 GPT‑6.1 Sol 执行通用任务，使用 GPT‑5.6 处理对高级推理要求较低的日常漏洞管理任务。

> “与其他供应商的模型相比，OpenAI 模型的成本效益更高。这对我们来说是一大优势，尤其是在运行这些庞大的智能体集群时。”

—Geng Sng，Cogent 联合创始人兼首席技术官

使用 OpenAI 模型还减少了 Cogent 为修复漏洞和部署补丁而需要开发的配套软件。Geng 表示：“过去我们必须在执行框架层面完成的许多工作，现在都不再需要了。”他还分享道，OpenAI API“简化了请求路由和智能体编排，显著减少了内部工程开销，并加快了我们将复杂安全工作流推向市场的速度”。

Cogent 的大多数工程师也选择使用 Codex 进行开发。Geng 表示，与在开源编程环境中使用相同模型相比，将 Codex 与 OpenAI 模型搭配使用能让他们的开发效率更高。Geng 说：“Codex 自带工具，我们不用再自己开发。”

## 拓展自主网络防御能力

通过网络安全受信访问 (Trusted Access for Cyber) 和 Daybreak 计划，Cogent 为其内部红队测试和攻击路径研究获得了技术支持。Daybreak Red 是 Daybreak 中的一个访问层级，为团队提供专用 OpenAI 模型，用于开展经授权的攻击性安全研究和漏洞研究。Geng 表示：“善于进攻，才能做好防御。”

> “通过网络安全受信访问 (Trusted Access for Cyber) 和 Daybreak 计划，我们能够探索身份、资源和网络管控中的漏洞可能如何串联成攻击链。我们利用这些研究来了解智能体的能力，以及接下来应构建哪些防御能力。”

—Geng Sng，Cogent 联合创始人兼首席技术官

作为企业构建自身网络防御工厂的关键合作伙伴，Cogent 计划进一步拓展能力。其发展路线图包括不断提升修复的自主性，让智能体能够执行范围更广、复杂度更高的修复操作，从简单的配置更改，到跨越不同企业系统的多步骤工作流。

该公司还在开发自主发现和验证能力。其目标是建立一个闭环系统，在发现并消除风险的同时，持续从每个漏洞中学习，改进后续的调查和修复。
