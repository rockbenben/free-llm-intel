# Altera 用 GPT-4o 打造人机协作的新领域

Robert Yang 博士大半辈子都在构建受大脑启发的 AI。

2023 年，当 OpenAI 的语言模型广泛可用时，Yang 辞去了 MIT 助理教授的职位，创办了 [Altera.AL](https://altera.al/)——一个致力于构建“数字人（digital humans）”的研究实验室：让人们与具备基本人类品质的 agent 互动的新方式。

如今担任 Altera CEO 的 Yang 憧憬这样一个未来：AI agent 不只是协助人类；他相信很快它们就会与人类互动、协作，甚至拥有情绪体验。他与三位联合创始人——Andrew Ahn 博士、Nico Christie 和 Shuying Luo——用 GPT-4o 打造了 Altera 的首款产品：首批能像朋友一样[和你一起玩 Minecraft](https://playlabs.altera.al/discover)的自主 agent。

## 解决长期自主运行中的数据退化

正如自动化通过承担重复性任务来扩展人类的能力，Altera 团队相信，数字人将能够富有成效地协作，甚至与人建立情感纽带。这可能表现为：

- 能连续协作数天甚至数周、主动解决问题的数字“同事”
- 长时程多 agent 世界，在其中我们可以衡量（虚拟社会）对经济政策、广告等等的反应

但 Altera 在着手构建时遇到了独特的挑战。最紧迫的问题是“数据退化”现象——这是所有 AI 模型在长时间跨度中做自主决策时都会困扰它们的难题。

“AI agent 与世界互动，实时做决策，但它们自己的输出会变成未来的输入，数据质量因此随时间退化，”Yang 解释道。“这是大多数 AI Agent 系统都会遇到的问题，但对我们这些要自主存活数小时甚至更久的数字人来说，它成了最亟需解决的问题之一。”

## 借助 GPT-4 增强认知与情感 AI

为对抗数据退化、提升 AI agent 的长期自主性，Altera 求助于 OpenAI 的语言模型，事实证明它们在维持决策过程的完整性上起了关键作用。

OpenAI 的先进模型让 Altera 得以构建首批能像朋友一样与人一起打游戏的 AI agent。这些 agent 实现了更长、更复杂的互动，避免了此前限制其潜力的性能快速下滑。

通过将 OpenAI 的 GPT 模型与 Altera 模拟人脑结构（包括前额叶皮层）的并行多模块系统结合，公司创造出了能够模拟认知功能的 agent。“我们的复合系统*并行地组合*多个模块，每个模块都由 OpenAI 模型驱动。这些模块的灵感来自大脑功能，如注意瓶颈、工作记忆和社会认知，”Yang 说。

> “这让我们的 agent 思考更快、处理情绪，并最终建立长期的自我意识。”

—Altera CEO Robert Yang 博士

Altera 观察到，在 OpenAI 模型驱动下，他们的数字人表现出更高的稳定性，能更有效地处理复杂任务。即便使用较便宜的模型，OpenAI 提供的表现也优于市场上的其他选项。

## 创造未来：有目的地构建数字人

截至 2024 年中，Altera 的数字人单次可自主运行长达四小时——相比市面上其他 AI 模型是大幅提升。

##### 长期基准：Minecraft 中的独特物品收集

Altera 愿景的早期成功引发了广泛关注，尤其是其首款产品——能在 Minecraft 等虚拟环境中游玩和互动的数字人。它也在为未来更复杂的多 agent 模拟打基础。

Altera 计划扩展其努力，构建能够进行细腻、长期交互的数字人社会，应用场景从游戏到生产力以及更多领域。与 OpenAI 的合作使 Altera 处于引领者的位置：创造一个数字生活与人类生活以启智方式交汇的世界。
