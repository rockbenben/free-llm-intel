# ChatGPT 免费开放，助力退役美军顺利转型

正在加载…

每年，美国有数十万军人脱下军装，开启全新的生活。这一转变意义深远，既充满希望，也伴随着诸多挑战：求职、评估教育路径、了解并申请应得福利、安置住房、规划财务，以及适应截然不同的生活节奏。数据显示，近一半“9·11”事件后的退役军人表示，他们在融入社会的过程中曾面临不小的困难。

OpenAI 的使命，是让人工智能真正惠及全人类，其中也包括那些曾为国家奉献，如今正踏上新生活旅程的退役军人。

今天，我们正式宣布：凡是在退役或离队前后 12 个月内的美国现役军人及退役军人，均可免费获得一年期的 ChatGPT Plus 服务。这项计划源自 OpenAI 的退役军人员工，他们每天都在使用 AI 工具，深知 ChatGPT 在人生新阶段中能发挥怎样的作用。从撰写简历、探索职业方向，到规划未来发展，他们亲身体验过 AI 带来的价值。

通过免费使用 ChatGPT Plus，正在转型的军人们将能够：

- 打造并优化简历，让军旅经历在社会语境中清晰呈现
- 模拟面试，练习常见问题并获得反馈建议
- 轻松了解各类福利、表格和手续流程
- 制定具体可行的住房、教育、搬迁和财务规划
- 随时获取支持，无需排队或预约

有兴趣的美国现役军人和退役军人可点击[此处⁠（在新窗口中打开）](https://chatgpt.com/veterans-claim)，了解详情。他们可获得对最新模型和功能的访问权限，浏览由 OpenAI 退役军人撰写的 [100 个退役军人专属对话范例⁠（在新窗口中打开）](https://chatgpt.com/use-cases/veterans)，以及观看在 OpenAI Academy 发布的[定制入门视频⁠（在新窗口中打开）](https://academy.openai.com/home/resources/veterans)。本次计划由 OpenAI 携手 SheerID 推出，借助其基于授权的身份验证平台，确保服务精准覆盖正在退役阶段的军人群体，助力他们顺利开启人生新篇章。

退役军人所展现出的领导力、纪律性与适应力，深深塑造了这个国家。他们值得拥有与之匹配的强大工具。这项计划，是我们向所有退役军人表达敬意的方式，希望这能为他们迈向人生新阶段提供切实帮助。
