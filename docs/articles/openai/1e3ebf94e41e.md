# Retell AI 借助 GPT‑4o 让语音 agent 自动化可定制且无需写代码

并将电话处理成本最多降低 80%。

[Retell AI](https://www.retellai.com/?gad_source=1&gad_campaignid=22631383658&gbraid=0AAAAA-CHgsazAH6JHNNQ8ohoOgs3s3mBc&gclid=Cj0KCQjwjdTCBhCLARIsAEu8bpKzcNyAA8yOYow_kv72pXycA5Z5PmHddQZYMwnwa4HWub73Id8XMmYaAoAJEALw_wcB) 正从第一性原理重建呼叫中心。他们没有去改造遗留的电话话术脚本系统，而是打造了一个 AI 原生、无代码的平台，能快速部署听起来自然的语音 agent，回答问题、安排预约、处理行政事务——不需要等待音乐、话术脚本或繁重工程。

这类技术被称为语音自动化（voice automation），能让企业即时、全天候地处理来电，同时消除排队等待、降低运营成本、提升客户满意度。

通过紧密跟踪 OpenAI 模型发布并快速集成，Retell 能在几天内把新能力交付给客户。正如联合创始人兼 CTO Zexia Zhang 所说：“因为模型持续变强，我们的平台也持续变强。我们不只是扩展得更快，而是以更简洁的技术栈去解决更复杂的问题。”

这一路线正在见效：使用 Retell 的团队报告电话处理成本最多下降 80%，Retell 在各部署中收获高达 90 的 NPS。

## 用 GPT‑4o 解锁实时、拟人的对话

要实现自然对话，Retell 需要一个能超越脚本化对答的 AI 提供方——能理解上下文、遵循逻辑、实时触发正确动作。在评估了多个 LLM 之后，OpenAI 凭借精度与性能脱颖而出。

“OpenAI 的模型在速度、可靠性与智能之间取得了最佳平衡，”Zhang 说。“我们测试 function calling 时，GPT 模型不仅最准确，响应也最快。这种性能水平对真实世界对话至关重要。”

Retell 的语音 agent 使用 function calling 来安排预约、甄别销售线索、处理行政事务。每种场景下，模型都需要跨多轮对话进行推理，并在正确的时间调用正确的 API。

“它补上了精彩通话最后缺失的一块，”Zhang 补充道。“有了 GPT‑4o，agent 终于表现得像人：它会倾听、会推理、自然地回应。”

来看 Retell AI 的实况演示：听起来自然的语音、低延迟、近乎即时的响应。

## 选择 GPT‑4o 与 GPT‑4.1，以速度实现精度

GPT‑4o 是一个转折点：它让 Retell 无需大量提示词工程或硬编码逻辑，就能构建动态对话流——安排预约、处理异议、确认细节。Retell 的客户不再需要串联脆弱的指令、手动管理上下文窗口，或为每个用例编写 3,000 token 的提示词，现在通过一个简单的 UI 即可定义行为：写下高层目标，选择几个条件或动作，其余交给模型。

“通常这类工作流需要大量手工逻辑、兜底提示词、外部记忆、JSON 强制约束，”Retell 联合创始人兼 CEO Bing Wu 说。“我们过去要花数周构建各种变通方案，现在客户几天就能上线。”

OpenAI 原生的 function calling 接口是另一把钥匙。竞品模型往往需要东拼西凑的方案或自定义 schema 强制。GPT‑4o 提供了更自然、更可靠的接口，在多轮 function calling 中达成 70% 以上的成功率——几乎是在没有精心提示、仅依靠模型对函数描述的理解情况下，Retell 从替代方案所见成绩的两倍。

Retell 还用 GPT‑4o 推出了整片新能力，例如：

- 通话后分析与结果评估
- 只需极少提示词工程的可配置 agent 工作流
- 反驳应对、多槽位预约等动态对话流

这一切由一支 11 人的精干团队构建并交付，Retell 的客户无需复杂配置即可使用。借助 GPT‑4o，Retell 快速从想法走到可处理真实对话的、生产就绪的 agent。

这种速度至今未减。Retell 持续集成 OpenAI 的最新模型，包括 GPT‑4.1，以拓展其 agent 的能力边界。每一次发布都带来新机会：响应更敏捷的行为、更紧密的 CRM 集成、更聪明的工作流——都在数天内交付到客户手中。

## 用 OpenAI 自动化完整的客户对话生命周期

Retell 精益、模型原生的方式如今支撑着语音自动化的完整生命周期——从接起电话到度量结果。他们正在收获真实成效：

- 电话处理成本最多降低 80%
- 全天候 24/7 可用，CSAT 得分 85% 以上，匹敌甚至超过人工坐席
- 合格通话转接成功率 85-90%
- 上线 16 个月内营收 1,400 万美元
- 月环比平均增长 25%

伴随每一次新模型发布（如 GPT‑4.1），Retell 都解锁新功能：更高级的对话流、向人工坐席的智能暖转接（warm transfer）或升级、更强的拨号器、更深的 CRM 集成、实时分析、更聪明的通话评分与质量保证（QA）。所有这些都内置于一个直观的平台，让团队快速上线自定义 agent，而不增加运营负担。

“我们已不只是在构建 agent，”Zhang 说。“我们在为客户对话的未来打造基础设施。”
