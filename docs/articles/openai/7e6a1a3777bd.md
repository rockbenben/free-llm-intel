# OpenAI 扩大领导层，任命 Fidji Simo 为新成员


*Sam 今天早些时候向公司分享了这条消息：*

大家好——我有一条令人兴奋的消息要分享。我原本计划几周后再公布，但因为泄密事件我们加速了时间表。

我们创立 OpenAI 的初衷是作为一个研究实验室，致力于确保通用人工智能 (AGI) 惠及所有人。

过去两年半以来，我们开始着手两项重大举措。首先，我们已发展成为一家服务于全球数亿用户的全球性产品公司，并保持着快速增长的势头。近期，我们还转型为基础设施公司，致力于构建支持研发并以前所未有的规模交付 AI 工具的系统。如本周早些时候所讨论的，我们还将运营一家规模最大的非营利机构。

这些每一项都是庞大的工程，足以支撑一家大型公司独立运营。我们处于一个得天独厚的地位，能够以这样的速度扩展业务，从而同时推进所有这些项目，而引进卓越的领导者是确保这一切顺利进行的关键。

为了加强我们的执行力，我很高兴宣布 Fidji Simo 将加入我们，担任应用业务的首席执行官，直接向我汇报。我将继续担任 OpenAI 的首席执行官，并直接监督 OpenAI 所有核心业务板块——研究、计算和应用——的成功，确保我们在所有领域保持一致和协同。我将与我们的董事会紧密合作，确保我们的非营利机构产生最大的积极影响。

应用部门整合了现有业务和运营团队，负责将我们的研究成果传递并惠及全球，而 Fidji 正是领导这一团队的理想人选。作为 OpenAI 董事会成员过去一年，Fidji 已为公司做出了巨大贡献。她将在未来几个月内从 Instacart 的职位过渡，并于今年晚些时候加入 OpenAI。

在新的职位上，Fidji 将专注于推动我们“传统”公司职能的扩展，以支持公司进入下一阶段的增长。我对这些领域充满热情，并将继续密切参与公司关键决策。Fidji 拥有罕见的领导力、产品和运营专长，以及对确保我们的技术惠及所有人的真诚承诺。

除了支持 Fidji 和我们的应用团队外，我将加大对研究、计算和安全系统的关注，这些部门将继续直接向我汇报。确保我们能够安全地构建超级智能，并具备支持我们雄心勃勃目标所需的基础设施。我们依然是完整的 OpenAI。

Fidji 分享了以下内容：

> “在这个关键时刻加入 OpenAI，既是一种莫大的荣幸，也是一种重大的责任。这家组织有潜力以前所未有的速度推动人类潜能的释放，我将全力以赴，确保这些应用成果最终服务于公共利益。”

Fidji 的领导力让我对我们的未来更加充满信心，我们正不断努力，朝着成为我们所追求的超级智能公司迈进。

—— Sam
