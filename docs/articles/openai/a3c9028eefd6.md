# Clay 借助 Codex 和 ChatGPT 帮助销售团队赢得订单

接入 ChatGPT 和 Codex 后，Clay 用户可以研究销售机会，把数据转化为可执行的市场推广方案。GPT‑6 系列模型负责其中的推理工作。

[使用 OpenAI 开始开发](https://openai.com/startups/)

公司规模：初创企业

地区：北美

行业：科技

产品：API、Codex、ChatGPT

即使销售团队掌握了大量关于潜在客户的数据，也可能难以判断哪些信息最重要，或据此制定能打动客户的销售方案。[Clay](https://www.clay.com/) 是一个能够持续学习的营收平台，旨在解决这个问题。借助 GPT‑6 Astra、GPT‑6 Sol 等模型，Clay 用户可以建立企业和联系人名单，利用 agent 补充记录，再用这些信息制定和执行市场推广方案。

Clay 也通过 Codex 和 ChatGPT 的插件，把这些功能带到客户日常工作的工具中，让用户更方便地创建和运行市场推广流程、研究客户和销售机会。

> “Clay 接入 ChatGPT 后，销售人员能进一步了解他们想争取的客户。这些丰富的背景信息直接呈现在他们平时工作的地方。”

——Clay AI 负责人 Jeff Barg

## 为销售人员提供行动所需的背景信息

Clay 与 Codex 的集成让工作流开发者可以直接在 Codex 中制定和执行市场推广方案，也让销售人员能够查阅数据，用来研究某个客户或了解自己正在推进的订单。

Jeff 看到过销售人员把内部系统和公开数据集的信息结合起来，判断怎样向客户说明产品的价值最有效。“客户喜欢用 Codex 处理各类销售任务，”他说，“我们发现，优秀的销售人员从中获益最多。”

Clay 的 ChatGPT 插件把同样的客户数据带到了销售人员已有的另一个工具里。销售人员可以留在 ChatGPT 中了解更多潜在客户的信息。Jeff 说：“效果非常好。”

## 按任务匹配模型能力和成本

OpenAI 模型为 Claygent 的调研、潜在客户筛选、资料补充和信号识别提供支持。帮助用户搭建工作流、协调 Clay 其他 agent 的那个 agent 也使用 OpenAI 模型。

Clay 主要使用 GPT‑6 Sol，用 GPT‑6 Astra 处理难度更大的任务，用 GPT‑6 Luna 处理对成本敏感的工作。通过搭配这些模型，Clay 既能完成后台调研和文案撰写，也能支持与用户直接互动的 agent。

> “GPT-6 Sol 非常适合市场推广方案。它的判断力很强，能够设计周期较长、以明确成果为目标的市场推广任务。”

——Clay AI 负责人 Jeff Barg

Clay 通过 Responses API，在同一个接口上使用能力和成本各异的模型。Jeff 说：“不同价位的 OpenAI 模型都能走同一个 Responses API，这一点对我们很有吸引力。”

## 构建贯穿全流程、能够持续改进的方案

GPT‑6 Astra 还帮助 Jeff 编写和测试软件。过去，他要花大量时间手动检查自己开发的功能。现在，他可以让 GPT‑6 Astra 承担更多检查工作。

他解释道：“GPT‑6 Astra 彻底打通了工程流程，也改变了我开发软件的方式。现在我可以让 Astra 写代码、补测试、实际运行测试并验证功能，再把验证过程录下来上传到 PR。这省了我很多事。”

对 Clay 的客户来说，Jeff 认为 GPT‑Live‑1 可以让他们通过语音使用 Clay 和 Codex，也可以帮助潜在客户了解产品。Clay 正在开发面向主动咨询客户的销售拓展功能，让 agent 能向潜在客户展示产品或服务。Jeff 也认为，Decisions API 为 Clay 集成模型并拓展使用场景提供了另一种方式。

Clay 希望覆盖市场推广的完整流程，让 agent 根据执行结果不断改进。Jeff 的目标是让工作流开发者“把软件工程领域已经发生的同样转变带到市场推广中”。
