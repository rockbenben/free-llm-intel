# Clay 借助 Codex 和 ChatGPT 帮助销售团队赢得订单

ChatGPT 和 Codex 集成帮助 Clay 用户调研交易，并将数据转化为进入市场打法（go-to-market plays），而 GPT‑6 模型负责推理。

[开始使用 OpenAI 构建](https://openai.com/startups/)

公司规模：初创企业

地区：北美

行业：科技

产品：API、Codex、ChatGPT

即便销售团队掌握大量潜在客户数据，他们仍可能难以判断什么最重要，也难以制定制胜的推销方案。[Clay](https://www.clay.com/) 是一款自学习收入引擎，正是为解决这一问题而设计。借助 GPT‑6 Astra、GPT‑6 Sol 及其他模型，Clay 让用户能够构建公司和人员名单，通过智能体丰富这些记录，并将这些信息用于进入市场打法。

Clay 还通过 Codex 和 ChatGPT 插件，把这些能力带到客户 already 工作的地方，让创建和运行进入市场工作流、调研客户与交易变得更加容易。

> “ChatGPT 中的 Clay 让销售代表能够更深入地了解他们试图推销的客户。它把所有这些丰富的上下文带到了他们已经在使用的地方。”

—Jeff Barg，Clay 人工智能负责人

## 为销售代表提供更多可据以行动的上下文

Clay 的 Codex 集成让构建者能够在 Codex 中创建并运行进入市场打法，同时让销售代表获取可用于调研客户或理解其试图成交的交易的所需数据。

Jeff 见过销售代表将自有系统的信息与公开数据集结合，以确定如何最好地向客户传达产品价值。“客户很喜欢用 Codex 完成销售中的许多不同任务，”他说，“我们看到最优秀的销售代表从中获得了最大的赋能。”

Clay 的 ChatGPT 插件把同样的客户数据带入销售代表已经在使用的另一个工具，帮助他们在不离开 ChatGPT 的情况下更深入地了解潜在客户。Jeff 说：“这非常成功。”

## 让智能水平与成本匹配任务需求

OpenAI 模型为 Claygent 的调研、资格认定、数据丰富和信号检测提供支持，也为帮助用户构建工作流并协调其他 Clay 智能体的智能体提供支持。

Clay 将 GPT‑6 Sol 作为主要模型，较难的任务使用 GPT‑6 Astra，对成本敏感的工作则使用 GPT‑6 Luna。这一模型组合既支持后台调研和文案撰写，也支持用户直接交互的智能体。

> “GPT-6 Sol 非常适合进入市场打法。它直觉很好，能够构建长周期、以结果为导向的进入市场任务。”

—Jeff Barg，Clay 人工智能负责人

Responses API 让 Clay 通过同一接口使用不同水平的智能与成本。“在不同价格点上拥有相同的 Responses API，是 OpenAI 模型对我们极具吸引力的一点，”Jeff 说。

## 构建可随时间自我改进的端到端打法

GPT‑6 Astra 还帮助 Jeff 构建和测试软件。过去，他大部分时间都花在手动检查自己构建的功能上；现在，他可以让 GPT‑6 Astra 承担更多此类工作。

他解释道：“GPT‑6 Astra 确实改变了我构建软件的方式，因为它完全闭合了工程流程的环路。现在我可以让 Astra 编写代码、添加测试，然后实际运行测试、测试功能、记录结果并上传到 PR 中。这大大简化了我的工作。”

对于 Clay 的客户，Jeff 认为 GPT‑Live‑1 是一种通过语音使用 Clay 和 Codex、帮助潜在客户了解产品的方式。Clay 正在开发入站销售开发功能，让智能体能够向潜在客户展示产品或服务。他还认为 Decisions API 是将模型集成到 Clay 并开拓新用例的另一条途径。

Clay 的目标是端到端承载进入市场工作流，让智能体在从结果中学习的过程中不断改进。对 Jeff 而言，目标是赋能构建者“把软件工程领域发生的那种转变带到进入市场领域”。
