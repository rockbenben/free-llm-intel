# 通过 L₀ 正则化学习稀疏神经网络

## 摘要

我们提出一种用于神经网络的 L₀ 范数正则化的实用方法：在训练过程中通过鼓励权重恰好变为零来剪枝网络。这种正则化很有意义，因为（1）它能大幅加速训练与推断，（2）它能提升泛化能力。著名的模型选择准则 AIC 和 BIC 都是 L₀ 正则化的特例。然而，由于权重的 L₀ 范数不可微，我们无法把它直接作为正则项纳入目标函数。我们提出一个解决方案：引入一组非负随机门（stochastic gates），由它们共同决定把哪些权重置为零。我们证明，有些出人意料的是，对于门的某些分布，所得门控权重的期望 L₀ 范数关于分布参数是可微的。我们进一步提出门的*硬具体（hard concrete）*分布：先把二值具体（binary concrete）分布“拉伸”，再用 hard-sigmoid 变换其样本。门的分布参数随后可以与原始网络参数联合优化。因此，我们的方法允许用随机梯度下降直接而高效地学习模型结构，并以有原则的方式实现条件计算。我们通过大量实验展示了由此产生的方法与正则项的有效性。
