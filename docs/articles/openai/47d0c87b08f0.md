## 摘要

我们推出 Codex——一个在 GitHub 公开代码上微调的 GPT 语言模型，并研究其编写 Python 代码的能力。一个独立的 Codex 生产版本为 GitHub Copilot 提供动力。在我们新发布、用于衡量“从 docstring 合成程序”功能正确性的评估集 HumanEval 上，我们的模型解决了 28.8% 的问题，而 GPT-3 为 0%，GPT-J 为 11.4%。此外，我们发现从模型中重复采样是解决困难提示的一个效果出奇好的策略：使用该方法，每个问题采样 100 次即可解决我们 70.2% 的问题。对我们模型的细致考察揭示了其局限，包括难以处理描述冗长操作链的 docstring，以及难以将操作绑定到变量。最后，我们讨论了部署强大代码生成技术可能带来的更广泛影响，涵盖安全、信息安全与经济层面。
