# OpenAI 宣布领导层变动

加载中……

*首席技术官 Mira Murati 被任命为临时 CEO 领导 OpenAI；Sam Altman 离开公司。*

*寻找正式继任者的工作正在进行中。*

OpenAI, Inc. 的董事会——这家 501(c)(3) 非营利组织是所有 OpenAI 活动的最高治理机构——今日宣布，Sam Altman 将卸任 CEO 并离开董事会。公司首席技术官 Mira Murati 将出任临时 CEO，即刻生效。

Mira 在 OpenAI 领导团队任职五年，在 OpenAI 成长为全球 AI 领导者的过程中发挥了关键作用。她带来了独特的能力组合，理解公司的价值观、运营和业务，并且已经在领导公司的研究、产品和安全职能。鉴于她任职时间长、深入参与公司方方面面，包括在 AI 治理和政策方面的经验，董事会认为她是这个职位的难得人选，并预计在她正式启动正式招聘寻找常任 CEO 期间，过渡会平稳无缝。

Altman 的离开，是在董事会经过审慎的复核程序之后做出的，复核结论是：他与董事会的沟通未能始终坦诚，妨碍了董事会履行职责的能力。董事会不再有信心他能继续领导 OpenAI。

董事会在一份声明中表示："OpenAI 的架构是经过深思熟虑设计的，为推进我们的使命服务：确保通用人工智能造福全人类。董事会始终全心投入这一使命。我们感谢 Sam 对 OpenAI 创立和成长做出的众多贡献。同时，我们认为随着向前推进，需要新的领导。作为公司研究、产品和安全职能的领导者，Mira 出任临时 CEO 极为称职。我们对她在此期间领导 OpenAI 的能力有最高程度的信心。"

OpenAI 董事会由 OpenAI 首席科学家 Ilya Sutskever、独立董事——Quora CEO Adam D'Angelo、科技创业者 Tasha McCauley，以及乔治城大学安全与新兴技术中心的 Helen Toner 组成。

作为此次过渡的一部分，Greg Brockman 将卸任董事会主席，但会保留他在公司的职位，向 CEO 汇报。

OpenAI 于 2015 年作为一家非营利组织创立，核心使命是确保通用人工智能造福全人类。2019 年，OpenAI 进行了重组，以便公司能为实现这一使命筹集资本，同时保留非营利组织的使命、治理和监督。董事会多数成员为独立董事，独立董事不持有 OpenAI 的股权。尽管公司经历了戏剧性的增长，推进 OpenAI 使命、守护其《章程》原则始终是董事会的根本治理责任。
