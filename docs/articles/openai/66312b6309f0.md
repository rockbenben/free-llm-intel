# NVIDIA 工程师与研究员如何用 Codex 构建

团队使用搭载 GPT-5.5 的 Codex 交付生产系统，并把研究想法变成可运行的实验。

公司规模：企业级

地区：北美

行业：科技

产品：Codex

成果：10 倍——端到端研究工作流的速度提升

成果：4 万——获得 Codex 使用权的 NVIDIA 员工

在 NVIDIA，工程师正把 Codex 作为复杂工程工作和端到端机器学习实验的默认工具。基于 GPT-5.5、在生产环境中运行于 NVIDIA GB200 和 GB300 基础设施上的 Codex，能处理更长、更自主的会话——不止于执行，还能发现原 prompt 中不曾包含的问题与想法。

> “Codex 是我们处理复杂工程任务的首选工具，有了 GPT-5.5，它能发现我程序里其他模型找不到的 bug 和缺口。”

——Dennis Hannusch，高级软件工程师

## 构建并交付生产系统

NVIDIA 的 coding agents 团队帮助全公司工程师在真实开发工作流中有效采用和使用 AI 工具。搭载 GPT-5.5 的 Codex 已成为他们处理复杂工程任务的首选。

“我个人感觉 Codex 配 GPT-5.5 自主性强得多，几乎不需要人盯着，”agents 团队的高级软件工程师 Dennis Hannusch 解释。“我能进行包含多次上下文压缩的长会话，发现它依然保持顶尖准确率、能把工作保持在上下文里。而且它很擅长策略性地选对工具和选对 skills。”

Hannusch 已经用 Codex 把一个内部平台从 MVP 演进到生产就绪系统，一路改进可扩展性和可靠性——这件事在早期模型上一直很棘手。

该团队还用 Codex 在几小时内搭出一个类似 Riverside 的内部播客录制应用。“鉴于我们的隐私限制，采购软件本来要花好几周，”Hannusch 解释。

使用带计算机交互能力的 Codex 桌面应用，系统在构建过程中还能自行测试视频与音频录制功能。“我什么都不用做——它完全是自主构建并测试的，”他说。“Codex 彻底改变了‘什么东西值得做’的门槛。”

> “仅就运行实验而言就是 10 倍的速度提升，因为它能处理整个端到端的机器学习研究工作流。”

——Shaunak Joshi，AI 研究员

## 运行完整研究工作流

对 NVIDIA 的研究团队来说，Codex 已基本自动化了研究闭环：从确定研究方向，到编写机器学习实验脚本，再到在远程机器上运行实验。

“GPT-5.5 作为创意伙伴是一大块解锁，尤其是在知识工作方面，”NVIDIA 的 AI 研究员 Shaunak Joshi 说。

团队把 Codex 用作研究 agent，让模型指向强化学习等领域的大量相关论文语料。“与竞品相比，GPT-5.5 显得更有创造力，”Joshi 说。“它帮我沿着整条证据链追溯片段，并建议了一个想法知识图谱，真的帮我可视化了各概念如何关联。”

在确定假设后，Codex 会在机器学习基础设施上编写训练模型的脚本。Codex 应用支持 SSH，因此 Joshi 发现他再也不用操心远程主机的登录和配置；他可以在笔记本上轻松运行大型机器学习负载。

> “如果你有一个性能不佳的旧代码库，Codex 的机器翻译非常在行。所以很多人把自己的 Python 仓库交给 GPT-5.5，它重写成 Rust，效率提升大约 20 倍。”

——Shaunak Joshi，AI 研究员
