# GPT‑3.5 Turbo 微调与 API 更新

开发者现在可以带入自己的数据，针对各自用例定制 GPT‑3.5 Turbo。


GPT‑3.5 Turbo 的微调现已开放，GPT‑4 的微调今秋推出。这次更新让开发者能够定制在自己的用例上表现更好的模型，并大规模运行这些定制模型。早期测试显示，微调后的 GPT‑3.5 Turbo 在某些窄任务上可以追平甚至超过基础 GPT‑4 水平的能力。和我们的所有 API 一样，进出微调 API 的数据归客户所有，OpenAI⁠(https://openai.com/api-data-privacy/)（或其他任何组织）不会用它来训练其他模型。

## 微调用例

自 GPT‑3.5 Turbo 发布以来，开发者和企业一直希望定制模型，为用户打造独特且有差异化的体验。随着本次发布，开发者现在可以运行监督微调，让模型在自己的用例上表现得更好。

在私有 beta 阶段，微调客户已经能在常见用例上显著提升模型表现，例如：

- **更强的可控性**：微调可以让企业让模型更好地遵循指令，比如输出更简洁、始终用指定语言回复。例如，开发者可以用微调确保模型在被要求用德语时始终以德语回复。
- **可靠的输出格式**：微调提升了模型稳定格式化回复的能力——这对要求特定响应格式的应用（如代码补全、构造 API 调用）至关重要。开发者可以用微调把用户提示词更可靠地转换成高质量的 JSON 片段，供自己的系统使用。
- **定制语气**：微调是打磨模型输出质感（如语气）的好方法，让它更贴合企业品牌的声音。有鲜明品牌语调的企业可以用微调让模型的语气与其保持一致。

除了性能提升，微调还能让企业在保持相近表现的前提下**缩短提示词**。GPT‑3.5‑Turbo 的微调模型现在支持 4k token——是此前微调模型的两倍。早期测试者把指令直接微调进模型本身，将提示词长度减少了最多 90%，从而加快每次 API 调用并降低成本。

微调与[其他技术](https://platform.openai.com/docs/guides/gpt-best-practices)（如提示词工程、信息检索、函数调用）结合时威力最大。参阅我们的[微调指南](https://platform.openai.com/docs/guides/fine-tuning)了解更多。函数调用以及 `gpt-3.5-turbo-16k` 的微调支持将于今秋晚些时候推出。


## 安全

微调部署的安全性对我们非常重要。为了在微调过程中保留默认模型的安全特性，微调训练数据会经过我们的 Moderation API 和一个由 GPT‑4 驱动的审核系统，以检测与我们安全标准冲突的不安全训练数据。

## 定价

微调费用分为两块：初始训练成本和使用成本：

- 训练：$0.008 / 1K Tokens
- 使用输入：$0.012 / 1K Tokens
- 使用输出：$0.016 / 1K Tokens

例如，一个 `gpt-3.5-turbo` 微调任务，训练文件为 100,000 token、训练 3 个 epoch，预期成本为 $2.40。

## 更新后的 GPT-3 模型

7 月我们曾[宣布⁠](https://openai.com/index/gpt-4-api-general-availability/)，原始 GPT‑3 基础模型（`ada`、`babbage`、`curie`、`davinci`）将于 2024 年 1 月 4 日下线。今天，我们提供 `babbage-002` 和 `davinci-002` 作为这些模型的替代品，既可作为基础模型，也可作为微调模型。客户可以通过 [Completions API](https://platform.openai.com/docs/api-reference/completions) 访问这些模型。

这些模型可以用我们的新 API 端点 `/v1/fine_tuning/jobs` 进行微调。这个新端点支持分页、扩展性更强，以支持微调 API 未来的演进。从 `/v1/fine-tunes` 迁移到更新后的端点很直接，更多细节见我们新的[微调指南](https://platform.openai.com/docs/guides/fine-tuning)。旧的 `/v1/fine-tunes` 端点就此弃用，将于 2024 年 1 月 4 日下线。
