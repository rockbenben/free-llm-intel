# OpenAI 与 PwC 携手重塑 CFO 职能体系

正在加载…

财务团队是组织进行规划、资本配置、风险管理以及决策制定的核心。为了助力财务部门应对日益增长的需求，PwC 与 OpenAI 正展开深度合作，利用 AI 智能体 (AI agent) 重新定义 CFO 职能体系。这些智能体能够实现工作流自动化、跨系统协同、识别风险与洞察，并在强化治理与人工监督的前提下，支持更科学的决策。

PwC 与 OpenAI 正围绕财务的核心运营节奏构建 AI 智能体，涵盖从规划、预测、报告，到采购、支付、司库、税务以及会计结账等整个流程。

此次合作的独特之处在于其“实战导向”，而非仅停留在理论设计层面。例如，PwC 与 OpenAI 正在 OpenAI 内部的财务组织中构建一个采购智能体，并将这些实战经验推广至更多核心财务工作流的智能体开发中。

## 围绕真实财务工作流构建智能体

OpenAI 已经在其内部财务组织中广泛应用 AI 智能体，利用 ChatGPT 和 Codex 等工具支持投资者关系、司库、税务、报告、企业发展及合同审查等工作流。现在，PwC 与 OpenAI 正基于这些成熟经验，帮助其他 CFO 在其组织中部署 AI 智能体。

在实践中，这意味着协助财务团队实现重复性工作的自动化，跨系统整合背景信息，并在明确的治理与人工监督下支持更优决策。智能体可以辅助监测支付及异常情况、根据政策审查合同或发票、随业务环境变化更新预测数据、准备报告材料，并在月度或季度结账前揭示风险。

[Codex⁠](https://openai.com/codex/) 可以协助团队构建并调整这些工作流背后的工具，例如面板、开支追踪器和异常管理系统。[工作空间智能体](https://openai.com/index/introducing-workspace-agents-in-chatgpt/) (Workspace Agent) 能让团队在既有工具中实现工作流的可复用性，而技能 (Skill) 与连接器 (Connector) 则确保智能体遵循核准的流程，并能在正确的企业业务语境下运行。

PwC 凭借在财务转型、内控及交付执行方面的深厚专业积淀，助力这些工作流从原型转入真实的生产环境。随着智能体工作流规模的扩大，CFO 也需要对 AI 的使用情况、Token 消耗及预估支出具备可见性，以便财务团队能够像管理其他企业运营成本一样对 AI 的采用进行治理。通过合作，PwC 与 OpenAI 正在将“AI 原生财务”的内部经验转化为一条务实路径，助推 CFO 在其组织中全面部署智能体工作流。

## OpenAI 作为零号客户

OpenAI 财务组织是将 AI 智能体应用于财务工作的“零号客户”(customer zero)。通过这一真实的生产环境，公司旨在验证企业级工作流、治理模型、运行时控制以及“人类与智能体协作”模式。

OpenAI 财务团队在使用这些工具方面已取得显著成效。例如，借助 Codex，在团队规模不变的情况下合同处理量提升了 5 倍；而在最近的融资过程中，通过 IR-GPT 管理了超过 200 场投资者互动。

通过此次合作，PwC 与 OpenAI 将基于上述实践经验，助力更多企业实现 CFO 职能体系的现代化。PwC 提供财务转型、内控及执行交付方面的专业能力；OpenAI 则提供模型与产品能力，确保企业能够在财务团队既有的平台上，实现智能体工作流的构建、适配与治理。
