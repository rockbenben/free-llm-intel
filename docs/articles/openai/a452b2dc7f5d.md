# 隆重推出 ChatGPT Pro

拓宽前沿人工智能的应用。

立即开始



随着人工智能技术日臻成熟，它将解决日益复杂和关键的问题。而支持这些功能所需的计算能力也显著增加。

今天，我们新增 ChatGPT Pro，一个每月 200 美元的套餐，可以大规模访问 OpenAI 的最佳模型和工具。该套餐包含对我们最智能的模型 OpenAI o1 以及 o1‑mini、GPT‑4o 和 Advanced Voice 的无限制访问权限。此外，它还包含 o1 pro 模式，这是 o1 的一个版本，能够使用更多计算资源进行更深入的思考，并为最棘手的问题提供更精准的答案。未来，我们预计将在此套餐中添加更多强大的计算密集型生产力功能。

ChatGPT Pro 为研究人员、工程师以及其他日常使用研究级智能的人员提供了一种方法，助其提升工作效率，并始终站在人工智能技术的前沿。

## 应对更棘手的问题需要更强大的思考能力

ChatGPT Pro 提供我们最智能的模型版本，该模型能够更长时间思考，从而生成更可靠的回复。根据外部专家测试人员的评估，o1 pro 模式能够提供更可靠、更准确、更全面的回复，尤其是在数据科学、编程和案例分析等领域。

与 o1 和 o1‑preview 相比，o1 pro 模式在数学、科学和编程等具有挑战性的机器学习基准测试中表现更优。

##### 博士级科学问题（GPQA 钻石级）

为了突出 o1 pro 模式的主要优势（更高的可靠性），我们使用了更严格的评估设置：只有当模型**在四次尝试中能够四次**正确回答问题（“4/4 可靠性”），而不是只有一次，才被认为解决了问题。

## ChatGPT Pro 资助计划

为了推动一些造福人类的领域更快取得重大进展，我们将向美国领先机构的医学研究人员提供 10 个 ChatGPT Pro 订阅名额，并计划在未来将 Pro 资助对象扩展到其他地区和研究领域。首批十个资助名额将授予以下研究人员：

- [**Catherine Brownstein**⁠（在新窗口中打开）](https://www.childrenshospital.org/research/researchers/catherine-brownstein)，公共卫生硕士、博士，波士顿儿童医院和哈佛医学院助理教授，专攻罕见病和孤儿病新基因的发现
- [**Justin Reese**⁠（在新窗口中打开）](https://www.linkedin.com/in/justin-reese-3419b24/)，博士，伯克利实验室计算机研究科学家，利用复杂的生物医学数据提取新知识以应对人类疾病
- [**Rhoda Au**⁠（在新窗口中打开）](https://profiles.bu.edu/Rhoda.Au)，博士，波士顿大学乔巴尼安和阿维迪西亚医学院解剖学和神经生物学教授，研究衰老和痴呆症
- [**Derya Unutmaz**⁠（在新窗口中打开）](https://x.com/DeryaTR_)，医学博士，杰克逊基因组医学实验室教授，研究衰老和癌症免疫疗法

## 下一步计划

我们将逐步为 Pro 版增加更多功能，以解锁更多计算密集型任务。我们还将继续为其他订阅用户提供诸多新功能。如需了解更多信息或订阅，请访问 [ChatGPT⁠（在新窗口中打开）](https://chatgpt.com/#pricing)。
