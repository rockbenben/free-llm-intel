# 与《时代》建立战略内容合作伙伴关系

通过 OpenAI 过去 101 年积累的丰富档案，用户将能获取来自《时代》(TIME) 的最新及历史内容，以增强 OpenAI 产品、并在回应用户查询时加以展示。

今天，《时代》和 OpenAI 宣布一项多年期内容协议与战略合作伙伴关系，将《时代》值得信赖的新闻带入 OpenAI 的产品，包括 ChatGPT。

通过这次合作，OpenAI 将获得《时代》过去 101 年丰富档案中最新及历史内容的使用权，用于增强其产品并在回应用户查询时加以展示——并附有指向 Time.com 原始来源的引用和链接。这一新伙伴关系进一步推进了《时代》扩大全球获取准确、可信信息渠道的承诺。

“在我们 101 年的历史中，《时代》始终拥抱创新，以确保我们值得信赖的新闻的传播方式随技术一同演进，”《时代》首席运营官 Mark Howard 表示。“我们与 OpenAI 的这一伙伴关系推进了我们的使命——在全球扩大获取可信信息的渠道，并持续拥抱把《时代》新闻带给全球受众的创新方式。”

“我们与《时代》合作，让人们更容易通过我们的 AI 工具获取新闻内容，并通过为原始来源提供恰当署名来支持有信誉的新闻业，”OpenAI 首席运营官 Brad Lightcap 表示。

这一合作也将使《时代》获得 OpenAI 技术的使用权，为其受众开发新产品，并获得机会提供宝贵的反馈、分享实际应用，以完善和增强在 ChatGPT 及其他 OpenAI 产品中新闻的呈现方式，塑造新闻体验的未来。
