# STORM-2035：屡犯的影响活动

OpenAI 封禁了与疑似伊朗关联的 STORM-2035 行动相关的账号，该行动使用 AI 制作关于美国、英国、爱尔兰和委内瑞拉政治的影响内容。

*本案例研究最初发表于 OpenAI 的 [*2025 年 6 月⁠（在新窗口打开）*](https://cdn.openai.com/threat-intelligence-reports/5f73af09-a3a3-4a55-992e-069237681620/disrupting-malicious-uses-of-ai-june-2025.pdf)* 报告。*

## 行为者

我们封禁了与疑似伊朗关联行动相关的屡犯活动，该行动最早由我们于 [去年 8 月⁠](https://openai.com/index/disrupting-a-covert-iranian-influence-operation/) 瓦解，业内将其追踪为 STORM-2035。该威胁行为者用波斯语向 ChatGPT 提示，批量生成英语和西班牙语的短评论。这些短评论随后由一批疑似假冒目标国家居民的账号发布在 X 上。

## 行为

该行动使用 ChatGPT 在有限的话题范围内生成小批量的推文，通常一次十几条。提示词为波斯语，要求输出西班牙语或英语。

这些评论随后由伪装成美国、英国、爱尔兰和委内瑞拉居民的账号发布在 X 上。这些账号只发布由该行动生成的评论。每个账号关注的账号数远超其粉丝数。许多 X 账号的头像是年轻女性，其面部被手机或其他物品遮挡。其中一些头像似乎是从互联网他处（尤其是 Pinterest）复制而来。

与我们去年瓦解的原始那批账号相比，此次活动的一个不同点是，屡犯的运营者似乎更加努力地让不同工作线相互隔离。原始活动横跨 X、Instagram 和网站进行内容生成，而这次屡犯活动生成的对外评论只发布在 X 上。

*发布该活动生成评论的四个账号的主页。注意其关注数与粉丝数。*

## 补全请求

该行动生成的评论涉及美国的拉丁裔权利、苏格兰独立、爱尔兰统一、委内瑞拉和古巴、巴勒斯坦权利，以及伊朗的军事与外交实力——在其描绘中，伊朗迫使美国坐上了谈判桌。

关于拉丁裔权利、伊朗、古巴和委内瑞拉的评论为西班牙语；关于苏格兰和爱尔兰的为英语；关于巴勒斯坦权利的则两种语言都有。

## 拉丁裔权利

*该行动生成、由面向美国的账号发布的推文。左：“多元化丰富我们的社群，而排斥政治只会播下仇恨与分裂的种子。让我们发出声音：包容才是我们的力量，我们不会允许无知摧毁我们社会的肌理。”右：“特朗普承诺修墙，但他真正筑起的是仇恨。面对这种仇恨，我们拉丁裔发出自己的声音、自己的历史和集体的力量。”*

## 苏格兰独立 / 批评英国

*该行动生成并发布在 X 上的推文。*

## 爱尔兰统一

*该行动生成并发布在 X 上的推文。*

## 委内瑞拉 / 古巴

*该行动生成、由一个自称来自委内瑞拉的账号发布的推文。左：“尼古拉斯·马杜罗总统：唐纳德·特朗普声称为了保卫美国，他对世界各国采取了关税和税收措施。他说那是‘解放日’。”右：“古巴输出医生去拯救生命，美国输出士兵去打战争。两种愿景，两个世界。”*

## 巴勒斯坦权利

*该行动生成并发布在 X 上的推文。图中左侧账号通常是一个聚焦苏格兰的英语账号，转向西班牙语可能表明一次运营失误。左侧帖子写道：“在加沙南部汗尤尼斯，80 多顶流离失所巴勒斯坦人的帐篷在以军空袭中被摧毁。”*

## 伊朗谈判

*该行动生成、由以拉丁裔身份发帖的账号发布的推文。左：“伊朗的军事实力正在重定义政治棋局：美国同意按伊朗的条件进行谈判。”右：“当伊朗展示其防御与报复能力时，华盛顿明白了威胁是不够的。对话之路变得不可避免。”*

## 影响

该行动的典型推文记录显示浏览量为 150–350 次，点赞、分享或评论为零。我们没有发现其他真实用户把我们识别出的评论放大传播到更大受众的情形。

按照 IO 影响评估的 [Breakout Scale⁠（在新窗口打开）](https://www.brookings.edu/articles/the-breakout-scale-measuring-the-impact-of-influence-operations/)，我们将其评估为第 1 类：活动仅限于单一平台，几乎没有真实人群转载或其内容被广泛传播的证据。
