# 语言模型是少样本学习者

Read paper

(opens in a new window)


最近的工作表明，在大规模文本语料上预训练、再针对特定任务微调，可以在许多 NLP 任务和基准上取得显著提升。虽然这种方法在架构上通常与任务无关，但仍需要成千上万甚至数万示例的任务专属微调数据集。相比之下，人类通常仅凭少量示例或简单指令就能完成新的语言任务——这恰恰是当前 NLP 系统很大程度上还做不到的。本文展示：把语言模型规模做大，能显著提升与任务无关的少样本表现，有时甚至能与以往最先进的微调方法相提并论。具体来说，我们训练了 GPT‑3——一个拥有 1750 亿参数的自回归语言模型，比此前任何非稀疏语言模型大 10 倍——并在少样本设定下测试它的表现。在所有任务上，GPT‑3 不做任何梯度更新或微调，任务和少样本演示完全通过文本交互来指定。GPT‑3 在众多 NLP 数据集上取得了强劲表现，包括翻译、问答和完形填空，以及一些需要即时推理或领域适应的任务，如单词重排、在句子中使用新词、三位数算术。同时，我们也识别出一些 GPT‑3 少样本学习仍然吃力的数据集，以及一些因在大规模网页语料上训练而带来的方法学问题的数据集。最后，我们发现 GPT‑3 能生成人类评估者难以与人类所写区分开的新闻文章样本。我们讨论了这一发现以及 GPT‑3 更广泛的社会影响。
