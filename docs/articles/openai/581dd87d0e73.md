# 竞争性自我博弈

查看代码。阅读论文。插图：Ben Barry。

我们发现，自我博弈能让模拟 AI 自行发现擒抱、躲闪、虚晃、踢球、接球、扑球等身体技能，而无需刻意设计一个为这些技能量身定制的环境。自我博弈确保环境对 AI 而言始终处于恰好能促其进步的难度。结合我们 Dota 2 自我博弈的结果，我们日益确信：自我博弈将成为未来强大 AI 系统的核心部分。

我们在一系列基础游戏中设置了多个模拟 3D 机器人之间的竞赛：给每个 agent 简单目标（把对手推出相扑圈、在阻止对手的同时到达圈的另一侧、把球踢进球门或阻止对方这样做，等等），然后分析涌现出的不同策略。

agent 起初会因有助探索的行为（如站立、向前走）获得密集奖励，随后这些奖励逐渐退火至零，转而只按胜负给奖励。尽管奖励很简单，agent 学会了擒抱、躲闪、虚晃、踢球、接球、扑球这些微妙行为。每个 agent 的神经网络策略都用[近端策略优化](https://arxiv.org/abs/1707.06347)独立训练。

要理解复杂行为如何从简单目标与竞争压力的组合中涌现，我们来分析相扑任务。这里我们取[先前工作](https://arxiv.org/abs/1506.02438)中用于训练人形行走的密集奖励定义，去掉速度项，加上到圈心的负 L2 距离，将其作为相扑 agent 的密集探索奖励。agent 起初可在圈内用这个奖励做探索，随后我们缓慢退火到零，让 agent 在剩余训练迭代中学会优化竞赛奖励——把对方推出圈外。

虽然可以设计需要这些技能的任务和环境，但这需要人类设计者付出心力与巧思，且 agent 行为的复杂程度会被人类设计者能提出的问题所封顶。通过让 agent 在成千上万轮与不断变强的自己的对局中演化，我们可以打造出层层自我提升的 AI 系统；我们的 [Dota 2 项目⁠](https://openai.com/index/more-on-dota-2/)就见过类似现象——自我博弈让我们创造出能在单人版电竞中击败顶级人类选手的 RL agent。

## 迁移学习

这些 agent 还展示了迁移学习：把一个场景中学到的技能应用到另一个从未见过的场景中取得成功。一例是：我们把在相扑自我博弈任务上训练的 agent 面对“受风力干扰保持站立”的任务。尽管从未见过有风环境、从未观察到风力，agent 仍设法保持直立；而用经典强化学习训练出来的行走 agent 会立刻摔倒。

## 过拟合

我们的 agent 一度出现另一种过拟合：共同学习出的策略恰好克制特定对手，但面对特征不同的新对手就会失效。我们通过让每个 agent 与多个不同对手对局（而不只是单个）来应对。这些可能的对手来自并行训练的策略集合以及训练早期阶段的策略。有了对手多样性，agent 必须学习通用策略，而非针对某一特定对手的策略。

此外，我们[发布了](https://github.com/openai/multiagent-competition)本工作使用的 MuJoCo 环境与训练好的策略，以便他人在这些系统上实验。如果你想从事自我博弈系统研究，我们[正在招聘⁠](https://openai.com/careers/)！
