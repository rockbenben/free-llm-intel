# Hebbia 的深度研究自动化 90% 的金融与法律工作，由 OpenAI 驱动

投资人、银行家、顾问和律师花费大量时间翻阅市场与股票研究报告、虚拟数据室、合同和监管文件，以做出高风险决策。

[Hebbia⁠（在新窗口打开）](http://hebbia.com) 决心改变这一点，推出了 Matrix——一个多 agent AI 平台，旨在端到端处理最复杂的金融与法律工作流。

Matrix 不依赖单一 AI 模型，而是并行编排多个 AI agent，同时调用 OpenAI 的 o3-mini、o1 和 GPT-4o。结果是：一位“AI 助理”能在数秒内完成过去整个团队需要数天乃至数周的工作；深度研究可以处理任意规模的离线数据，自动化 **90%** 的金融与法律工作。

> “我们不只是在做一个聊天机器人。我们在创建一个应对世界上最复杂工作的 agentic 操作系统。”

George Sivulka，Hebbia CEO

## 为专业任务达到业界领先的准确率

与早期客户合作时，Hebbia 团队认识到当今 AI 驱动研究的关键瓶颈不在模型本身——而在于对世界私有信息的信息检索。

网络搜索几乎总能从在线来源检索答案，但基于检索增强生成（RAG）的工具在离线文档上举步维艰。许多时候，答案并未在文档中明确写出，传统检索因此无能为力。

Hebbia 转而构建了分布式编排引擎，提升金融与法律深度研究任务的准确率。

该引擎克服了 RAG 的局限，实际上给了 OpenAI 模型一个“无限”上下文窗口，为高价值离线数据打造最准确的深度研究 agent。

在一个覆盖复杂法律与金融文档、兼顾定量与定性任务的严格基准上，Hebbia 配合 o1 达到 92% 准确率——而开箱即用的 RAG 只有 68%。

Hebbia 的 Matrix 为 OpenAI 模型提供了无限的有效上下文窗口。

## 用 agent 集群应对复杂性

由 OpenAI o1 的高级推理与 Hebbia 的 agent 编排引擎驱动，其 Matrix 平台：

- 将复杂查询分解为结构化的分析步骤
- 把任务智能路由到最适合的 AI 模型
- 处理完整文档而非仅摘录
- 带着完整引用合成答案，确保透明
- 运行比其他任何 AI 应用工具都更大的 LLM 处理任务
- 构建可自我改进的索引，能主动更新用户

由此得到的是一个 AI agent 平台，能够起草投资委员会备忘录、解读错综复杂的法律条款，并从近乎无限数量的文档中抽取多步洞见。

Matrix 的 agent 集群架构。

## 为金融公司与律所交付真实价值

Hebbia 的多 agent 编排方法——而非单 agent 聊天机器人——为客户交付了显著价值：

- 投行家每笔交易节省 **30–40 小时**，用于制作营销材料、准备客户会议和回应交易对手。
- 私募信贷团队**自动化**贷款条款与契约的抽取，省去数天的人工合同审阅和巨额第三方开支。
- 私募股权公司每笔交易在筛选、尽职调查和专家网络研究上节省 **20–30 小时**。
- 律便将信贷协议审阅时间缩短 **75%**，每小时节省 **2000 美元** 律师费。

然而，价值不仅限于效率提升。各公司还在做以前根本做不到的事。

例如，私募股权公司和投行家都在借助 Matrix 的无限有效上下文窗口，利用远超任何单人所能综合的历史数据。律师们甚至开始在进行的交易中使用 Matrix，引用过往交易结构，实时识别新的谈判筹码。

在这些用例中，自 Matrix 发布以来，Hebbia 客户的 AI 采用率迅速攀升。上个月，法律与金融专业人士通过 Hebbia 平台处理的非结构化数据量超过了此前 12 个月的总和。

真实价值正在驱动 OpenAI 模型组合的真实使用。

## 推动更深的洞见与更快的决策

Hebbia 的多 agent 系统让专业人士能够针对世界上最复杂、最安全、离线的数据做细致提问的深度研究。用 OpenAI 的 o1 做推理、GPT-4o 做通用处理、较小的模型做定向任务，Hebbia 能持续打磨 AI 大规模处理专业工作的方式。

随着企业 AI 采用的增长，真正的差异化因素不再是模型规模或速度——而是 AI 能多好地融入真实工作流并交付准确、可辩护的洞见。

由 OpenAI 模型驱动的 Matrix 正让金融与法律团队获得更深的洞见、更快的工作流，以及在决策上的竞争优势。
