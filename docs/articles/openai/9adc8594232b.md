# OpenAI 与 Apple 宣布合作，将 ChatGPT 集成到 Apple 的体验中

今年晚些时候登陆 iOS、iPadOS 和 macOS。


*编者注：这则消息发布于 Apple 2024 年全球开发者大会。你也可以在[这里⁠(opens in a new window)](https://www.apple.com/newsroom/2024/06/introducing-apple-intelligence-for-iphone-ipad-and-mac/)读到相关报道。*

Apple 正在把 ChatGPT 集成到 iOS、iPadOS 和 macOS 的体验中，让用户无需在工具间来回切换就能使用 ChatGPT 的能力——包括图像和文档理解。

Siri 也可以在合适的时候调用 ChatGPT 的智能。Apple 用户会在任何问题（连同文档或照片）发送给 ChatGPT 之前先被询问，然后 Siri 直接呈现答案。

此外，ChatGPT 将进入 Apple 系统级的写作工具（Writing Tools），帮助用户为自己正在撰写的任何内容生成素材。用户还可以调用 ChatGPT 的图像工具，以多种风格生成配图来衬托所写内容。

在 Siri 和 Writing Tools 中访问 ChatGPT 时内置了隐私保护——请求不会被 OpenAI 存储，用户的 IP 地址会被遮蔽。用户也可以选择连接自己的 ChatGPT 账户，此时按 ChatGPT 的政策应用其数据偏好。

由 GPT‑4o 驱动的 ChatGPT 集成将于今年晚些时候登陆 iOS、iPadOS 和 macOS。用户无需创建账户即可免费使用；ChatGPT 订阅者可以连接账户，直接在这些体验中访问付费功能。

> 我们很高兴与 Apple 合作，以一种全新的方式把 ChatGPT 带给他们的用户。Apple 与我们同样致力于安全与创新，这次合作与 OpenAI 的使命一致——让人人用上先进 AI。我们将与 Apple 一起，让人们更容易享受到 AI 能提供的好处。

Sam Altman，OpenAI CEO
