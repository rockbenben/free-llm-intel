# OpenAI 与 Reddit 达成合作伙伴关系

*编者按：本文最初由 [*Reddit*⁠（在新窗口打开）](https://www.redditinc.com/blog/reddit-and-oai-partner) 发布。*

保持互联网的开放性至关重要，而开放的一部分含义是：Reddit 内容应当对那些促进人类学习、研究如何在线上构建社区、归属感与赋能的人可得。Reddit 是一个独特大而充满活力的社区，长期以来都是互联网上重要的对话空间。此外，借助 LLM、ML 和 AI，Reddit 能为所有人提升用户体验。

据此，Reddit 与 OpenAI 今天宣布一项合作，将在多个方面惠及 Reddit 和 OpenAI 的用户社区：

- OpenAI 将把增强的 Reddit 内容带入 ChatGPT 和新产品，帮助用户发现并参与 Reddit 社区。为此，OpenAI 将访问 Reddit 的 Data API，该接口提供来自 Reddit 的实时、结构化、独有的内容。这将让 OpenAI 的 AI 工具更好地理解并展示 Reddit 内容，尤其是近期话题。
- 这一合作还将使 Reddit 为 redditors 和版主带来新的 AI 驱动功能。Reddit 将基于 OpenAI 的 AI 模型平台，实现其强大的愿景。
- 最后，OpenAI 将成为 Reddit 的广告合作伙伴。

> “我们非常激动能与 Reddit 合作，用独一份的及时且相关信息增强 ChatGPT，并探索以 AI 功能丰富 Reddit 体验的可能性。”

Brad Lightcap，OpenAI COO

> “Reddit 已成为互联网上最大的开放档案库之一，收录着关于万事万物真实、贴切、始终新鲜的人类对话。把它纳入 ChatGPT 符合我们对互联互联网的信仰，帮助人们更多找到他们想要的东西，也帮助新人群在 Reddit 上找到社区。”

Steve Huffman，Reddit 联合创始人兼 CEO

*OpenAI 披露：Sam Altman 是 Reddit 的股东。这一合作由 OpenAI COO 主导，并经其独立董事会批准。*
