# OpenAI 与英国政府宣布建立战略合作伙伴关系，以推动人工智能驱动的增长


OpenAI 与英国政府今日宣布建立战略合作伙伴关系，旨在加速人工智能的采用，并助力实现英国《人工智能机遇行动计划》的目标及其通过人工智能实现共同繁荣的愿景。

OpenAI 首席执行官 Sam Altman 与英国科学、创新与技术大臣 Peter Kyle 议员签署了一份谅解备忘录 (MOU)，重点在于释放人工智能的经济和社会效益。该谅解备忘录将涵盖在公共服务和私营部门两方面探索人工智能应用的合作，以及基础设施建设与技术信息交流，以推动英国人工智能驱动的增长。

OpenAI 的技术已对数百万英国人至关重要。英国是全球付费订阅用户和 API 开发者市场的前三大市场之一。每天，个人、开发者、机构、初创企业和英国领先企业都在借助我们的技术释放经济机遇——从 Natwest 和 Virgin Atlantic，到本土独角兽 Synthesia 以及牛津大学等知名机构。

**英国科技大臣 Peter Kyle 表示：**“人工智能将在推动全国范围内所需的变革中发挥核心作用——无论是改善国民保健服务 (NHS)、打破机会壁垒，还是促进经济增长。”这就是为什么我们必须确保英国在人工智能的研发与应用中处于核心地位，以便确保人工智能真正为我们所用。

“没有像 OpenAI 这样的公司推动这一国际革命，这一目标是无法实现的。”这一合作将使更多相关工作在英国开展，创造高薪科技岗位，推动基础设施投资，并关键性地使我国掌握这一改变世界技术的未来发展方向。

**Sam Altman 表示：**“人工智能是国家建设的核心技术，将重塑经济并推动增长。英国在科学领导力方面拥有深厚底蕴，其政府通过《人工智能机遇行动计划》率先认识到人工智能的潜力。”现在，是时候通过将雄心转化为行动，实现计划的目标，为所有人带来繁荣。”

该谅解备忘录合作基于英国政府与 OpenAI 的共同愿景，旨在利用英国在科学、创新和人才方面的优势，维护一个以民主价值观为根基的全球领先的英国人工智能生态系统。该合作包括非约束性承诺，旨在探索：

- 如何在政府和私营部门广泛部署先进的人工智能模型，以帮助公务员更高效地工作，并支持中小企业和公民更有效地利用公共服务。
- 实现《人工智能机遇行动计划》中概述的基础设施优先事项的潜在途径，认识到英国自主能力在实现人工智能经济效益中的重要性。
- 扩大 OpenAI 与英国人工智能安全研究所（UK AI Security Institute）现有的合作关系，包括开发新的技术信息共享计划，合作深化政府各部门对模型能力的理解，并探索安全研究合作。

除与英国政府签署的合作协议外，OpenAI 还确认了其扩大在英国业务布局的意图。OpenAI 的首个国际办事处于 2023 年在伦敦正式成立。自成立以来，该团队已发展至超过 100 名员工，涵盖研究与工程等领域——为 OpenAI 前沿模型的开发做出贡献——以及市场拓展职能，旨在支持英国企业、开发者和初创公司利用人工智能工具推动业务增长。OpenAI 将在夏季公布更多关于其扩展计划的细节。

英国政府已利用我们的 API 开发了一个人工智能聊天机器人，使数千家小型企业能够更轻松地从 GOV.UK 获取有关商业规则和支持的信息。

OpenAI 技术还支撑着白厅人工智能助手“Humphrey”中的多个工具，该助手旨在通过减轻行政负担来加快公务员体系的运作效率。此外，该技术还应用于“Consult”这一定制化工具，该工具通过自动整理公众对咨询的反馈来加速政策制定过程——将官员们需要数周才能完成的任务在几分钟内完成，同时将重要决策交由专家处理。
