# 人工智能信任建立措施：研讨会论文集

## 摘要

基础模型未来可能打开多条危害国家安全的通道：事故、意外升级、非故意冲突、武器扩散、对人文外交的干扰，都只是长长清单中的几项。由 OpenAI 地缘政治团队与加州大学伯克利风险与安全实验室共同举办的“人工智能信任建立措施”研讨会聚集了一个多利益相关方群体，共同思考缓解基础模型给国际安全带来潜在风险的工具与策略。信任建立措施（CBM）起源于冷战，指能降低敌意、防止冲突升级、增进各方互信的行动。CBM 的灵活性使其成为驾驭基础模型格局快速变化的关键工具。与会者识别出以下直接适用于基础模型的 CBM，本会议论文集将作进一步阐释：1. 危机热线；2. 事件共享；3. 模型卡、透明度报告与系统卡；4. 内容溯源与水印；5. 协作红队与桌面推演；6. 数据集与评估共享。由于多数基础模型开发者是非政府实体，许多 CBM 需要更广泛的利益相关方社区参与。这些措施既可以由 AI 实验室实施，也可以由相关政府主体实施。
