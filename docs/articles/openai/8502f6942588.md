# 发掘后端系统的细枝末节

*摄影：Jake Stangel*

## 最初是什么让你对工程产生兴趣？

我很幸运在很小的时候发现了编程，并把它当作探索其他主题的入口。初中时，一个朋友让我接触了德州仪器计算器自带的那一版 BASIC 语言（在这种每个程序只能用 27 个单字母变量、还严重依赖 GOTO 语句的限制下，我的代码一如既往地没法维护）。尽管如此，我们还是写出了一些简单程序：文字冒险游戏、一个让计算器互联聊天的应用，还有惯常的一元二次方程求解助手。

后来，我写了更复杂的程序：一个演示牛顿法的可视化辅助工具，还有一个估算行星及其卫星位置的轨道计算器——它引起了学校 Linux 社团的注意。很快，我就跟 NDISwrapper 较劲，试图让笔记本的 CardBus WiFi 网卡工作起来，还用 Compiz 把桌面窗口"点着"了！这种通过代码探索发现的模式贯穿高中和之后，成就了我今天对工程的热情。

## 是什么让你来到 OpenAI？

在上一份工作中，我从后端岗转去全栈岗，结果发现自己不喜欢前端工作和 UX 设计。我想回到更靠近后端系统的岗位，并怀念学术生涯里与 Linux 环境打交道的那种感觉。OpenAI 提供的正是我想要的转变，甚至超出期待：很难找到比参与 OpenAI 超算集群更契合我需求的工作了。

## 在 OpenAI，你专注于解决什么问题？

探索式的 AI 工作流天生快节奏：研究人员希望从 arXiv 拿下一篇预印本就能试验新方法，不被运行代码的平台掣肘。这些工作流也极其复杂——研究人员的行事方式很像数学家：靠职业生涯积累的直觉，去设计解决本周吸引他们的那个问题。而这些运行时正跑在世界上规模最大的超算之上，又添一层复杂性；处理倒数第二层（penultimate layer）正是我的团队介入的地方。我们努力在研究需求成为进度阻塞之前先未雨绸缪；做不到时，我们就与研究团队协作，识别瓶颈并尽可能快地实施绕行方案。

## 你认为在 OpenAI 做超算与在别处有何不同？

坦率说，我们运转的规模大得惊人。第三方硬件厂商常向我们吐露：我们碰到的问题他们前所未见。这通常只是因为，我们的部署把比其他客户更多的硬件塞进了一台连续的超算里；偶尔也是因为我们性能预期的结果。多数模型训练方法需要同步的特性，造成了整个集群实际上以最慢节点的速度运行。

我们最重要的模型在数十亿美元级的超算上训练，因此我们会去追查大多数人会容忍的性能退化。看到一处一行的改动进了内核主线，知道它每周能为我们整个机队省下约 6 天算力；或是在新驱动发布说明里看到一行，知道那源于我们的发现、修复如今已上行合入——这些都让人兴奋。

## 你在 OpenAI 典型的一天是什么样的？

我的日子通常是写代码、调查问题和开会的混合体。会议占据我的周二（好在通常只有周二），一周其余时间在调试与编码之间分配。发现的问题一般转化为编码工作，比如撰写设计文档、给 PR 分支推一个快速热修复、或添加被动健康检查逻辑，把有问题的硬件挡在集群之外。

深挖问题需要一点侦探功夫。对研究的影响从含糊其辞（"我的任务好像比昨天跑得慢"）到可怕的具体（"我觉着要是通过以太网卡推超过 30Gbps，就会引发内核恐慌？"）。这种组合想必你很熟悉：一切符合预期的日子富有产出，而预期被打破、有机会学新东西时则令人兴奋。

> "OpenAI 提供了深挖那些在别处被忽视的计算角落的机会。"

## 每天是什么让你充满干劲？

我几乎不会在脑子里没有一件待办之事的情况下去上班，而且我清楚是哪个团队、哪个项目、哪些研究人员会从任务的及时完成中受益。OpenAI 是我就职过的最大雇主，能即时感知自己工作的影响，对我的日常动力至关重要。我也乐于发掘系统的细枝末节。OpenAI 不是我第一个做后端系统的雇主，但这是我第一次进入 HPC（高性能计算）领域。

我们打交道的许多技术，纯粹因为这个领域特有的性能诉求而存在。在之前的雇主那里，我不需要操心硬件的物理拓扑——比如确保通信发生在同一 NUMA 域内、让 GPU 通过 Nvidia 的 GPUDirect 使用同盘的 NVMe 或 InfiniBand 设备、或把系统进程绑定到特定 CPU 以避免与研究运行时形成"吵闹邻居"冲突。OpenAI 让我有机会深挖那些在别处被忽视的计算层面，这让我对手头的任务始终保持兴趣。

## 你在哪里获得激励？

没有比看着我们的研究团队在改进模型上取得进展更鼓舞人心的了。许多团队会搭建 Slack 机器人或简单的试验场，让你可以交互和测试仍在开发中的模型，看着模型随训练继续变好！

我还用流行的 :meow_party: Slackmoji 给各个 Slack 频道里鼓舞人心的内容打标签。自 2020 年中入职以来，我收藏了 400 多个带 :meow_party: 标签的帖子，平均每周近 4 个！
