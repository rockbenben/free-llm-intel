# ChatGPT Enterprise 现已在 AWS Marketplace 上线

[在 AWS Marketplace 中查看](https://aws.amazon.com/marketplace/pp/prodview-sscra4m7iracg)

即日起，ChatGPT Enterprise 正式上线 AWS Marketplace。此次上线让组织能够沿用现有的 AWS 采购和结算渠道，更便捷地查找、购买和管理 ChatGPT Enterprise，并将符合条件的支出计入其 AWS 承诺消费额。

每周有超过[ 12 亿人使用 ChatGPT](https://openai.com/index/chatgpt-ads-expands-26-new-countries/)。ChatGPT Enterprise 通过 ChatGPT、ChatGPT 工作、Codex 和 dot，将这种熟悉的体验带入工作场景。随着 ChatGPT Enterprise 上线 AWS Marketplace，AWS 客户可获得与直接从 OpenAI 购买时相同的模型、功能和使用体验，新功能也将同步发布。

这些 OpenAI 产品[与 Amazon Bedrock 中提供的 OpenAI 模型相辅相成](https://openai.com/index/openai-on-aws/)。开发者可以使用 Amazon Bedrock 中的 OpenAI 模型构建 AI 应用和智能体，企业各部门的团队则可在日常工作中使用 ChatGPT Enterprise。组织可以根据自身的工作负载和治理要求，选择合适的使用方式。

—Matt Yanchyshyn，AWS 负责 AWS Marketplace 和合作伙伴服务的副总裁

> “企业越来越依赖 AWS 和 OpenAI 来应用 AI，而我们的合作就是要让两者更好地协同，为企业创造更大价值。现在，双方的共同客户可以通过他们已经信赖的云服务商，为团队引入 ChatGPT。我们正与 AWS 携手，简化 AI 的采用流程，帮助更多组织释放大规模应用 AI 的潜力。”

—Chris Grusz，OpenAI 云合作伙伴关系董事总经理
