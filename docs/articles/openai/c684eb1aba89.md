# 提升 OpenAI 的销售效率与客户成功


*本文属于系列报道之一，聚焦 OpenAI 如何基于我们的技术构建自有解决方案。*

## 管理增长

增长虽是良性挑战，却伴随着不少压力。不到一年时间，我们的市场拓展团队规模扩大了三倍，几乎每周都有新产品发布。这种高速发展带来了结构性挑战：客户需求持续增长，但系统和流程却难以跟上。

销售代表常常为了一次半小时的通话耗费一小时的时间准备，在数十个系统间来回切换才能拼凑出完整的背景信息。与此同时，客户每周向团队发送数百条产品咨询，既占用了专家时间又延缓了交易进程。

这就导致了这样一个后果：即便是最资深的销售人员，也把大量时间耗费在搜寻背景信息和寻求答案上，而无暇深耕客户关系。

## 是团队伙伴，而非工具

团队需要的不是又一个面板，而是能降低准备工作负担并集中管理产品知识的一套方法。

这个构想催生了基于 OpenAI 自动化平台、通过 Slack 交付的 **GTM Assistant**。它聚焦于两大痛点：

- **客户调研与准备**：每日会议简报及回顾，涵盖客户历史、通话记录、Salesforce 活动及版本更新。
- **产品问答**：即时从精选知识库中获取答案，并附可追溯至原始文档的链接。

GTM Assistant 并非一套需要管理的新系统，而是直接嵌入销售代表的日常工作流程中。

## 定义“卓越标准”

GTM Assistant 的突破性意义不仅在于节省时间，更是捕捉了顶尖销售人员的成功经验并分享给所有成员。

顶级销售代表直接参与 GTM Assistant 的开发，共同定义会议简报编写和产品回复等工作的“卓越标准”。他们依靠自己的专业知识对系统进行训练。每次评估、修正与优化不仅提升了 Assistant 效能，更将顶尖销售者的习惯推广至整个组织。信任是首要成功要素，而这种信任源于与最佳终端用户携手打造解决方案。

> “我们不断反复探讨‘优秀’的具体标准，深入剖析每条回复，并将‘优秀’转化为系统可执行的规范。”

Scotty Huhn，GTM 创新部

这种实践方法成为该项目的核心特征。销售代表不再是被动使用工具的用户，而是成了系统的设计者。主题专家不再只是回答问题，而是成为知识循环的构建者。

## 可感知的成效

使用效果迅速显现。如今，销售代表：

- 通过 GTM Assistant 平均**每周完成 22 次消息交互**，涵盖每日简报、工作总结及问答环节
- 平均**生产力提升 20%**——相当于每周可多出约一天的时间用于服务客户和管理更大的客户群

GTM Assistant 也在持续优化升级。每周产品专家都会审核样本、修补漏洞、为系统推送更新。

“这就像拥有一位每周都能重塑技能的虚拟同事，”Huhn 如是说。

客户可真切感受到使用前后的变化。在 Slack 中滞留的疑问数分钟内得到解答。会议基于最新数据和产品更新高效启动。交易进程显著加速。

## 从解答到行动

在赢得信任的基础上，Assistant 已开始试点下一项功能：通话后自动记录 CRM 更新、主动识别重要使用模式、起草客户跟进函件并自动发送。原本耗时数小时的工作正逐步实现后台自动化。

> “关键突破在于训练它识别成功会议的特征。如今它已成为全天候的团队伙伴，既能提升客户成果，又能优化团队日常运作。”

Scotty Huhn，GTM 创新部

## 实现卓越销售规模化

GTM Assistant 并非旨在取代销售人员，而是放大他们的影响力，推动客户走向成功。通过将轻量级的评估嵌入日常流程，团队构建了一个新体系，该体系能让知识自由流动，工作流程紧跟交易节奏灵活调整，销售代表成为所用技术的共同主人。

当顶尖销售人员获得 AI Assistant 支持，将个人卓越转化为提升整个组织的系统时，无限可能就此开启。
