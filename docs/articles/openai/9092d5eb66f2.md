AI 正逐步融入新加坡航空的客户服务、员工支持和技术开发。新加坡航空使用 OpenAI API 打造面向客户的体验，并在面向员工、具备治理机制的内部 AI 平台 Jarvis 中使用 OpenAI 模型。公司还将 OpenAI 模型用于软件开发工作流程，以提供更个性化的服务、提升工作效率，并帮助团队更高效地开展开发工作。

> “在为客户提供更个性化的体验、提升各项业务的工作效率方面，AI 是我们工作的核心。我们正与 OpenAI 合作，开发 AI 驱动的功能，让客户的出行更轻松、更顺畅，同时帮助员工提高工作效率和成效。”

—George Wang，新加坡航空信息技术高级副总裁

在这些应用中，新加坡航空将 OpenAI 模型与编排、内部数据管控、验证和人工审核相结合，让各团队能够以统一、负责任的方式将 AI 引入生产工作流程。

## 从预设脚本服务转向对话式支持

面向客户的聊天机器人 Kris，是新加坡航空最广为人知的 AI 应用之一。新加坡航空通过 OpenAI API，将 Kris 从传统的对话流程系统升级为由 LLM 驱动的对话式体验，客户满意度随之提升至原来的 2 倍。

与此同时，新加坡航空为客服人员部署了 AI 辅助工具，包括由 OpenAI API 支持的通话摘要功能，让客服人员减少通话后的事务处理时间，将更多时间用于服务客户。新加坡航空客服人员的平均处理时长缩短了约 10%。

在早期基于对话流程的聊天机器人设计中，每个话题都需要手动配置，每条流程都需要预先编写。这使得服务覆盖范围难以扩大。如果某种用户意图未被预先纳入，即使客户的请求本可通过自助服务解决，对话也更容易转而需要客服人员介入。

新加坡航空通过 OpenAI API，将 Kris 升级为完全由 LLM 驱动的对话式体验。聊天机器人不再依赖预设流程，而是能够理解客户用自然语言表达的意图，依据知识库作答，处理多话题对话，并在必要时连同相关上下文一起转交客服人员。

如今，客户可以通过 Kris 进行一般咨询、提出特殊需求、获取实时航班异常信息，以及办理部分业务。新加坡航空正持续扩展 Kris 的功能，将其覆盖范围拓展至预订变更、行李业务办理，以及更复杂的智能体交互。

> “借助 OpenAI，Kris 已成为功能更强大的自助服务渠道。它能更自然地理解客户意图，帮助客户找到正确答案，并在需要客服人员介入时，为他们提供更清晰的上下文。”

—Jude Anand Suresh，新加坡航空客户服务信息技术副总裁

## 帮助客户用自然语言探索出行方案

航班推荐工具让客户能够用自然语言描述理想的行程，而不必反复调整筛选条件、日期和目的地。过去一年，其使用量增长至原来的近 3 倍。

> “航班推荐工具让探索出行方案的过程更像一场自然的对话。它通过 API 接入 OpenAI 模型，帮助客户表达需求，更快地找到合适的选项。”

—Andy Koh，新加坡航空应用服务（销售、营销与货运）副总裁

航班推荐工具基于 OpenAI API 构建，通过编排层连接票价和余票数据。它能够理解客户意图、调用相关工具，并以自然语言给出个性化的出行建议。

团队还设置了安全防护机制，用于验证输入和输出、处理恶意或不当查询、减少幻觉、处理个人身份信息 (PII)，并确保通过身份验证后仅可访问每次查询所需的上下文。新加坡航空正准备进一步引入更自然的聊天机器人交互方式，让客户能够持续完善出行想法，而不必重新开始搜索。

## 将 AI 引入软件开发生命周期

除了面向客户的体验，新加坡航空还在软件开发生命周期的部分环节中使用 OpenAI 模型，帮助团队更高效地规划、细化、测试和审核工作。在软件开发生命周期的部分活动中，团队的工作效率提升幅度最高达 20%。

如今，AI 已贯穿整个交付生命周期，而不再局限于编写代码。团队利用生成式 AI 模型辅助细化需求、分析利益相关方会议内容、编写产品规格、识别边缘情况、创建测试用例、开展架构评审，并将复杂工作拆分为更小、更易测试的任务。

在开发一项商业功能时，团队在开发开始前使用 OpenAI API 审视既有假设、识别模糊的需求，并找出边缘情况。这些内容明确后，AI 帮助将其转化为设计方案、实施计划和测试用例，随后生成代码。

在部署期间及之后，AI 还帮助团队理解系统在生产环境中的运行表现，并标记可能被忽视的问题。随着 AI 参与工作流程的每个环节，团队成员不再亲自制作每一项交付物，而是在整个交付生命周期中指导、审核和验证 AI 的产出。这意味着他们可以专注于真正需要人类判断的工作，例如确定优先级、架构设计、治理，以及实现利益相关方期望的成果。

总体而言，OpenAI 模型正帮助新加坡航空提升需求质量、扩大测试覆盖范围，并更好地遵循内部标准。团队利用这些工作流程生成用于测试的边缘情况、评审架构方案，并在工作进入开发生命周期的后续阶段前辅助人工验证。

## 让员工更轻松地使用 AI

除了工程团队，新加坡航空还通过内部 AI 平台 Jarvis，让各业务部门都能使用 AI。Jarvis 由 OpenAI 模型驱动，让员工能够在治理框架下将 AI 用于日常工作，从总结文档到创建自定义工作流程。

员工使用 Jarvis 在安全环境中处理 PDF、Word 文档、Excel 文件、PowerPoint 演示文稿及其他类型的文件，同时为日常工作创建自定义工作流程和轻量级知识库。如今，新加坡航空超过 60% 的员工每月都会使用 Jarvis，且使用比例仍在持续上升。

- 使用 AI 辅助工具的客服人员，**平均处理时长缩短约 10%**
- 过去一年，面向客户的出行方案探索工具 — 航班推荐工具的月度用户数**增长至原来的 3 倍**

## 展望未来

新加坡航空正持续扩大 AI 在客户和员工工作流程中的应用。对 Kris 而言，下一阶段的重点是深化自助服务，增加更多业务办理功能，帮助客户直接在聊天中解决需求。航班推荐工具正向更自然的对话式出行探索体验迈进，让客户能够通过多轮对话完善想法，而不必重新开始搜索。

随着 Jarvis 向各业务部门开放，新加坡航空正着力帮助更多员工将 AI 用于日常岗位工作。这些举措与面向客户的创新相结合，正帮助新加坡航空打造这样的未来：AI 让出行更顺畅，让员工工作更高效，也让企业更敏捷地响应不断变化的需求。
