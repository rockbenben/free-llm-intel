# DALL·E：推出外绘（Outpainting）

用任意尺寸的 DALL·E 图像延伸创意，讲更大的故事。

插图：August Kamp × DALL·E，基于约翰内斯·维米尔的《戴珍珠耳环的少女》外绘而成。

今天我们推出 Outpainting（外绘）——一项帮助用户延伸创造力的新功能：把图像延续到原始边界之外，仅用自然语言描述，就能以相同风格添加视觉元素，或把故事引向新方向。

[DALL·E⁠](https://openai.com/index/dall-e-2/)的 Edit（编辑）功能已经支持在生成或上传的图像内部做修改，即 Inpainting（内补）。现在，通过 Outpainting，用户可以扩展原始图像，创建任意宽高比的大幅图像。Outpainting 会考虑图像已有的视觉元素——包括阴影、反射和纹理——以维持原图的语境。

今天，超过一百万人正把 DALL·E——这个根据自然语言描述生成原创图像与艺术作品的 AI 系统——当作创作工具。艺术家们已经用新的 Outpainting 功能创作了出色的作品，并在此过程中帮助我们更好地理解它的能力。
