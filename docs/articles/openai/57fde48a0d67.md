# 欧洲数据驻留功能上线

数据驻留建立在 OpenAI 的企业级数据隐私、安全和合规计划之上，为全球客户提供支持。


**2026 年 1 月 16 日更新**

我们已扩展数据驻留服务，为符合条件的 ChatGPT Enterprise、ChatGPT Edu 和 ChatGPT 医疗保健版客户提供面向美国或欧洲的区域内 GPU 推理选项。[了解更多](https://help.openai.com/en/articles/9903489-data-residency-and-inference-residency-for-chatgpt)。

**2025 年 11 月 25 日更新**

我们已经在全球范围内扩展了静态数据驻留选项。想了解更多地区的可用情况，请查看我们的[最新更新](https://openai.com/index/expanding-data-residency-access-to-business-customers-worldwide/)。

**2025 年 10 月 27 日更新**

除了欧洲，我们还将静态数据驻留扩展到英国、美国、日本、加拿大、韩国、新加坡、澳大利亚、印度和阿联酋，适用于符合条件的 API 客户，以及新的 ChatGPT Enterprise 和 ChatGPT Edu 工作空间。

我们宣布 ChatGPT Enterprise、ChatGPT Edu 和 API 平台将在欧洲提供数据驻留服务。此举将帮助在欧洲运营的组织，在使用 OpenAI 产品开展业务和构建 AI 解决方案时，满足本地数据主权要求。数据驻留建立在 OpenAI 现有的企业级数据隐私、安全和合规特性之上。

## 在欧洲启用数据驻留：ChatGPT Enterprise、ChatGPT Edu 和 API 平台

通过数据驻留，API 客户现在可以选择在欧洲处理符合条件的端点数据，而新的 ChatGPT Enterprise 和 Edu 客户则可以选择将用户内容静态存储在欧洲。

## API 平台

符合条件的客户可以在 API 平台控制面板中创建一个新[项目](https://help.openai.com/en/articles/9186755-managing-your-work-in-the-api-platform-with-projects)，并选择欧洲作为区域，从而启用欧洲数据驻留。通过这些项目发起的 API 请求会在欧洲区域内由 OpenAI 处理，并且不会保留数据 — 也就是说，模型的请求和响应不会在我们的服务器上进行静态存储。目前，欧洲数据驻留只能在新建项目时配置，已有的项目无法在创建后再更改为将数据驻留在欧洲。

## ChatGPT Enterprise 和 Edu

新的 ChatGPT 工作空间可以设置为在欧洲进行数据驻留，使客户内容能够在该区域进行静态存储。这包括你在 Enterprise 或 Edu 工作空间中与 ChatGPT 的对话、定制 GPT 的交互，以及用户输入、上传文件和涉及文本、视觉、图像的内容。

## OpenAI 企业级数据隐私、安全与合规

数据驻留功能建立在 OpenAI 强大的数据隐私、安全和合规体系之上。如今，OpenAI 已与欧洲数百家组织合作 — 从初创公司、大型企业到学术机构 — 包括 Booking.com、BBVA、Zalando、Klarna、牛津大学、雅诗兰黛集团、Ipsos、瑞再保险 (Swiss Re)、斯堪尼亚 (Scania)、Spotify 和桑坦德银行 (Santander) 等。

这些特性包括：

- **高级加密技术**：我们使用 AES-256 来保护静态数据，并利用 TLS 1.2+ 来保护客户与 OpenAI 之间，以及 OpenAI 与服务提供商之间传输的数据，确保数据在存储和传输过程中的机密性与完整性。
- **不使用客户数据进行训练**：默认情况下，OpenAI 的模型不会使用 ChatGPT Business 套餐或 API 的数据进行训练，除非客户明确选择共享数据。
- **全面的数据保护**：我们的数据保护实践支持符合 GDPR、CCPA 等隐私法规，并遵循 CSA STAR 和 SOC 2 Type 2 标准。
- **数据处理附录 (DPA)**：我们提供完整的 [DPA](https://openai.com/policies/data-processing-addendum/)，明确了 GDPR 及其他隐私法规下的角色与责任，帮助组织满足合规要求。

对于 API 平台和 ChatGPT 企业产品，你的数据始终保持机密、安全，并完全归你所有。数据驻留功能进一步增强了在欧洲运营的组织对数据的掌控力。
