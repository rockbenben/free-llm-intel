# 收购 Statsig，Vijaye Raji 出任 Applications CTO

我们正在扩充 Applications 的领导层——这个组织负责让我们的研究触达世界并惠及世界。

随着我们把 ChatGPT 规模化，并构建新的应用服务全球数亿人和企业，我们的雄心是把 AI 研究的前沿推进，并把它变成人们喜爱的直观、安全、有用的工具。这需要强大的工程系统、快速迭代，以及对质量与可靠性的长期专注。

在收购 Statsig 之后，Vijaye Raji 将出任 [Applications⁠](https://openai.com/index/leadership-expansion-with-fidji-simo/) 的 CTO，向 Fidji Simo 汇报。作为一名亲自动手的构建者和值得信赖的领导者，Vijaye 将负责 ChatGPT 和 Codex 的产品工程，职责范围横跨核心系统与产品线，包括基础设施和 Integrity。他作为 Statsig 创始人与 CEO、以及在 Meta 领导大规模消费者工程十年的经历，为扩展我们下一代产品同时带来了创业愿景与运营专长。

*“Vijaye 在大规模构建新的消费者与 B2B 产品和系统方面有着非凡的记录。他加入之时，我们的模型正在打开全新的构建方式，他的领导将帮助把这些进展转化为安全的 applications——用许多新工具赋能人们改善生活，帮助企业放大影响，让开发者更快更好地构建产品。”*

**—Fidji Simo，OpenAI Applications CEO**

## Statsig 加入 OpenAI

作为这一转变的一部分，我们正在收购 Statsig——业界最受信赖的实验平台之一，为包括 OpenAI 在内的一些全球最具创新力的公司提供 A/B 测试、功能开关和实时决策支持。

Vijaye 和他的团队创立 Statsig 时相信：最好的产品来自快速实验、紧密的反馈回路和数据驱动的决策。

Statsig 平台早已在我们如何快速发布与学习的过程中扮演核心角色。把它收归内部将强化我们在整个 Applications 组织加速实验的能力，并为我们服务的人和企业打造更好、响应更敏捷的体验。

*“加入 OpenAI 出任 Applications 的 CTO，是一个非凡的机会——让我把扩展消费者与企业产品的经验投入我深切相信的使命：以能够解决难题、可靠、并真正惠及各地人们的的方式推进 AI。与 Statsig 同行的旅程令我深感欣慰，它把我带到这一刻，也让我坚信我们会继续帮助团队每天发布更好的软件。”*

**—Vijaye Raji，候任 OpenAI Applications CTO**

收购完成后，Statsig 员工将成为 OpenAI 员工。Statsig 将继续独立运营，并从西雅图办公室服务其客户群。我们将以审慎的态度推进任何未来的整合，确保现有客户的连续性，并让团队专注于他们最擅长的事。

*收购的交割须满足惯例的交割条件，包括获得监管批准。*
