# 费加罗集团与 OpenAI 合作，将《费加罗报》的新闻报道引入 ChatGPT

通过此次合作，用户将能在 ChatGPT 中通过摘要和节选发现《费加罗报》的新闻报道，并通过附带的链接阅读原文。

费加罗集团与 OpenAI 今日[宣布建立战略合作伙伴关系](https://www.groupefigaro.com/uploads/a014d3b4-4841-4a25-bee0-82f5360c1f77.pdf)，帮助更多人发现并阅读《费加罗报》的新闻报道。此次合作涵盖《费加罗报》及旗下相关刊物的最新报道和历史存档内容，涉及新闻、商业、文化和生活方式等领域。用户将能通过摘要和节选发现这些文章，并通过附带的链接阅读原文。

> “此次合作体现了费加罗集团的愿景：与人工智能研究和部署领域的领军企业建立实质性的合作关系。费加罗集团拥有深厚的新闻采编传统和备受信赖的品牌，背后是一支由 600 多名记者组成的团队，为读者提供可靠的信息来源。将这些优势与 OpenAI 的技术专长和全球影响力相结合，将带来新的创新机遇，为我们的读者创造长期价值。”

— Marc Feuillée，Groupe Figaro 首席执行官

> “《费加罗报》的报道帮助读者理解影响法国乃至世界的新闻事件，我们希望借助 AI，让更多人发现这些报道。我们致力于与出版机构携手，支持优质新闻报道，并将其带给新的受众，此次合作正是这一承诺的体现。”

— Varun Shetty，OpenAI 媒体合作副总裁

《费加罗报》将保持完全的编辑独立性，并保留对其新闻报道的控制权。此次合作延续了 OpenAI 与全球新闻机构的合作，旨在让可靠信息更易被发现，为出版机构开发负责任的 AI 应用，并探索让受众接触和阅读原创报道的新方式。

《费加罗报》还计划在多个团队中引入 ChatGPT Enterprise，为日常工作提供支持。在自身 AI 章程和编辑标准的指导下，《费加罗报》将探索 OpenAI 技术在工作流程和读者服务中的更多应用。
