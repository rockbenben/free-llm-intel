# Travelers 携手 OpenAI 在全美部署 AI 理赔服务


公司规模:

大型企业

区域:

北美

行业:

金融

产品:

API

成果

90%

客户通过 AI 理赔助手完成理赔申请


当客户在发生交通事故后致电 Travelers 时，他们需要即时帮助，并确信理赔流程会顺利进行。但要大规模提供这种支持，可能会成为运营挑战。灾害事件可能在短短几天内产生超过 100,000 件理赔申请——去年，Travelers 处理了超过 150 万件理赔申请，并赔付损失超过 230 亿美元。

为帮助管理这些激增的需求并改善客户体验，Travelers 构建了 AI 理赔助手，这是一款由 OpenAI Realtime API 和前沿模型驱动的完全自主语音解决方案。该助手通过自然对话引导客户完成汽车财产损失理赔的首次报损，回答保单问题、收集详细信息并提交理赔申请。在八个州上线后，Travelers 在两个月内将该助手扩展至全美；如今，使用 AI 助手的客户中有 85–90% 会通过 AI 完成理赔申请。

“OpenAI 实时模型的突出之处在于它能够在那样的环境中运行，”Travelers 车险和财产理赔高级副总裁 Patrick Gee 表示。在幕后，Travelers 将 OpenAI 模型连接到其理赔基础设施、编排系统和内部工具，以便在企业规模下安全运行。客户可以全天候获得支持，无需经历任何等待时间——即使在灾害事件期间也是如此——同时理赔专业人员可以专注于需要人工专业知识的更复杂案件。
