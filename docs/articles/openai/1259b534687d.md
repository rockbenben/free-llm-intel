# Richpanel 帮助企业在 30 天内实现 50% 的客服自动化

Richpanel 用 GPT‑6 Astra 和 GPT‑6.1 Sol 为 AI 客服 agent 配备工具和操作流程，用 GPT‑6 Luna 处理客服对话。

[使用 OpenAI 开始开发](https://openai.com/startups/)

公司规模：初创企业

地区：亚太及大洋洲

行业：科技

产品：API

AI 客服 agent 除了要知道怎样回答客户，还得能实际解决问题。为此，它们需要调用合适的工具，并能查阅相应的操作指引。

据 Richpanel 首席执行官 Amit RG 介绍，人工客服为一位客户提供服务时，可能用到二三十种工具，而他们遵循的流程可能从来没有形成书面记录。

为此，[Richpanel](https://www.richpanel.com/) 使用 OpenAI 模型配置 AI 客服 agent 执行操作所需的工具和流程，也用这些模型处理与客户的对话。

> “如今卡住我们的，是智能之外的方方面面。”

——Richpanel 首席执行官 Amit RG

## 为 AI 客服建立工具和操作流程

部署客服 agent 往往需要一名驻场工程师将其接入客户系统，并明确它应当如何工作。Amit 发现，许多企业抽不出工程师来做这件事。他想到：“如果承担驻场工程师职责的是一个 AI agent，会怎么样？”

于是，Richpanel 开发了一个负责配置 agent 的 AI 管理助手。客户开始称它为 Boss AI。它编写操作流程，并规定 Richpanel 的一线客服 agent、copilot 和质检 agent 如何调用各自所需的工具。

Richpanel 为 Boss AI 选用了 GPT‑6 Astra 和 GPT‑6.1 Sol。在配置其他 agent 要使用的工具和遵循的流程时，Richpanel 优先考虑准确性。

## 在客服运营中平衡模型能力与成本

Richpanel 的一线客服 agent 要处理数十万场对话，因此，单次交互成本是选择模型时的重要因素。Richpanel 用 GPT‑6 Luna 和其他 OpenAI 模型来处理这类工作。Amit 表示，copilot 和质检 agent 也采用同样的选型思路。

“重要的是在成本和模型能力之间找到平衡，”Amit 说。Richpanel 的客户可能已经在使用低成本的外包客服。在这一成本基准上，客服自动化也得算得过账。

Amit 表示，OpenAI 提供的模型既能处理长上下文和耗时更长的任务，也能控制成本。Richpanel 可以用推理能力更强的模型配置客服 agent，再用成本更低的模型处理后续对话。

> “OpenAI 模型能够处理长上下文和执行周期更长的任务，同时保持很高的成本效益。”

——Richpanel 首席执行官 Amit RG

## 提高联络中心的自动化率和客户满意度

2026 年 10 月接受采访时，Amit 表示，Richpanel 在此前六个月里完成了约 300 次 AI 客服部署。

Richpanel 向客户保证，在最初 30 天内达到 50% 的自动化率，否则退款。Amit 表示，这些部署都兑现了这一承诺。他还说：“在每次部署中，AI 客服的客户满意度都高于人工客服。”
