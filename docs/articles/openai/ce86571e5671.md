# “鱼食”行动：源自俄罗斯的内容农场活动

OpenAI 封禁了与 Rybar 网络有关联的账号，其中部分可能源自俄罗斯；这些账号利用 AI，在网站和社交平台上开展多语种影响活动。

## 行动者

我们封禁了一批与 Telegram 和 X 上的“Rybar”（俄语为“Рыбарь”，意为“渔夫”）网络有关联的 ChatGPT 账号。其中至少部分账号可能源自俄罗斯。该网络生成的内容被发布到互联网各处，有时由带有“Rybar”品牌的账号发布，有时则由未公开声明与“Rybar”存在关联的社交媒体账号发布。另有一名用户要求 ChatGPT 代表“Rybar”拟订在非洲开展秘密干预活动的商业计划。鉴于这些行动者利用 ChatGPT 为“Rybar”网络及其他渠道提供内容，我们将此次行动命名为“鱼食”。

## 行为

我们在该网络中发现的主要活动，是生成用于发布到社交媒体的内容。用户通常使用俄语输入提示，但生成的内容涵盖多种语言，尤以俄语、英语和西班牙语为主。其中部分内容随后由带有“Rybar”品牌的社交媒体账号及“Rybar”主网站发布到网上。另有一名用户生成了宣传“Rybar”品牌的 Sora 视频。

除生成由“Rybar”品牌账号发布到网上的内容外，本案的主要用户还批量生成了英语评论。通过开源调查技术，我们发现其中许多生成的评论与 Rybar 的 Telegram 频道所发布内容在措辞上完全一致。右上：带有 Rybar 品牌标识的英语推文。这些内容由多个 X 和 Telegram 账号发布到网上，均未公开声明与 Rybar 有关联。右下：西班牙语文本及带有 Rybar 品牌标识的信息图，发布于西班牙语——简而言之，ChatGPT 相关活动涉及的网站是 andaluciamorisca[.]org。这些活动似乎充当了上述账号的内容农场。我们无法独立确认这些账号最终通过何种机制将 AI 生成的内容发布到网上；这些账号似乎有时也会发布并非由我们的模型生成的内容。

此次行动的一名用户根据俄语提示生成并发布到网上的文本。左侧：Rybar 的 Telegram 频道上的俄语帖子。右上：带有 Rybar 品牌标识的英语推文。右下：西班牙语文本及带有 Rybar 品牌标识的信息图，发布于西班牙语网站 andaluciamorisca.org。

值得注意的是，至少有一次（如下图所示），威胁行动者用一个提示词一次生成了七条推文。我们发现其中六条分别由不同的 X 账号发布。根据 X 的统计数据，浏览量最高的推文超过 15 万次，最低的仅有 57 次。截至 2026 年 1 月 26 日，推文浏览量最高的账号拥有超过 60 万名关注者；截至同日，浏览量最低的账号有 827 名关注者。由于所有推文均由一个提示词一次生成，这表明决定每条推文浏览量高低的因素更可能是各账号的关注者数量，而非内容由 AI 生成这一属性。

六个不同的 X 账号在网上发布了六条推文，其文本与此次行动的主要 ChatGPT 账号批量生成的一组评论相符。

四个不同的 Telegram 账号发布了四则帖子，其文本与此次行动的主要 ChatGPT 账号批量生成的一组评论相符。值得注意的是，帖子 2 引用了帖子 1，帖子 4 引用了帖子 3，但四则帖子的文本都与此次行动生成的内容相符。

除生成内容外，该行动的主要账号还要求 ChatGPT 将一份“Rybar”可向未具名客户提供的服务清单翻译成英语，其中包括运营 X 和 Telegram 账号、创建一个聚焦非洲的双语“调查新闻”网站、在法语媒体上付费刊发内容，以及建立扩散账号网络。另一个提示词要求模型编辑一份提案，内容似乎涉及一支已派驻实地、可能位于非洲的选举干预团队。该提案不仅包括线上活动，也包括实地活动，例如建立当地代理人网络和组织大型活动。第三个提示词讨论了一场以刚果民主共和国（刚果（金））为重点的信息行动。后续提示词询问了布隆迪和喀麦隆的选举流程，并概述了在马达加斯加开展行动的方案，其中包括煽动当地抗议活动。所涉金额相当可观：最具雄心的项目估计年度预算高达 60 万美元。

同一用户偶尔还会为一家名为“REST Media”的新闻机构生成宣传材料；开源研究人员已将该机构与 Rybar [联系起来⁠（在新窗口中打开）](https://dfrlab.org/2025/09/23/sanctioned-russian-actor-linked-to-new-media-outlet-targeting-moldova/)。上述同一批 Telegram 频道在网上发布了部分宣传材料。例如，8 月，本案的主要 ChatGPT 用户输入了一篇 REST Media 的文章。该文章指控德国正在摩尔多瓦建立影响力网络，用户随后要求我们的模型围绕此文生成一组评论。其中三条评论随后由三个不同的 Telegram 频道发布，每则帖子都附有指向 REST 文章的链接。

三则 Telegram 帖子的内容，与此次行动的主要用户通过一个提示词生成的一组评论相符。每则帖子都附有指向 REST Media 的链接。

## 生成内容

此次行动生成的内容与多年来俄罗斯秘密影响行动的典型内容相似。这些内容通常赞扬俄罗斯及其盟友（如白俄罗斯），批评乌克兰，并指责西方国家干涉他国内政。

## 影响

Rybar 网络在各社交媒体平台拥有大量关注者，仅其主要俄语 Telegram 频道就约有 140 万订阅者。许多发布此次行动内容的 X 和 Telegram 账号也拥有数万名关注者。不过，我们未观察到主流新闻机构放大传播其内容，也未能发现非洲当地存在与商业提案描述相符的实地活动。

按照影响行动（IO）的[影响力突破量表⁠（在新窗口中打开）](https://www.brookings.edu/articles/the-breakout-scale-measuring-the-impact-of-influence-operations/)（将 IO 分为 1 级〔最低〕至 6 级〔最高〕），鉴于此次行动在社交媒体上的广泛传播，我们将其评估为第 3 级的最高水平（覆盖多个平台上的多个社群）。
