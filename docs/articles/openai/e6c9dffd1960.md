# 为你的应用定制 GPT-3

一条命令完成微调。

开发者现在可以用自己的数据微调 GPT-3，创建契合其应用的定制版本。定制让 GPT-3 在更广泛的使用场景中变得可靠，也让模型运行更便宜、更快捷。

你可以使用几乎任何形态和规模的数据集，也可以根据用户反馈逐步补充数据。通过微调，一家 API 客户把正确输出从 83% 提升到 95%；另一家每周从产品中补充新数据，把错误率降低了 50%。

要开始，只需在 OpenAI 命令行工具中用你提供的文件运行一条命令。你的定制版本会开始训练，随后立即可在我们的 API 中使用。

- [阅读文档](https://beta.openai.com/docs/guides/fine-tuning)

去年我们[训练了 GPT-3](https://arxiv.org/abs/2005.14165)并开放在[我们的 API](https://openai.com/api/) 中。只需几个示例，GPT-3 就能完成多种多样的[自然语言任务](https://beta.openai.com/examples/)——这个概念叫少样本学习（few-shot learning）或提示设计（prompt design）。定制 GPT-3 能带来更好的结果，因为你可以提供的示例远多于提示设计所能容纳的。

不到 100 个示例就能开始看到微调 GPT-3 的好处，且随着数据增多、性能持续提升。在我们[去年 6 月发布的研究](https://openai.com/index/improving-language-model-behavior/)中，我们展示了不到 100 个示例的微调就能提升 GPT-3 在特定任务上的表现。我们还发现：示例数量每翻一倍，质量大致线性提升。

在我们最具挑战性的研究数据集之一[小学数学题（GSM8K）](https://openai.com/index/grade-school-math/)上，微调 GPT-3 相比提示设计能达到的水平，把准确率提高了 2 到 4 倍。

定制 GPT-3 提升了输出的可靠性，给出更一致的结果，让你可以把它用于生产场景。一家客户发现，定制 GPT-3 把不可靠输出的频率从 17% 降到 5%。由于定制版本是为你自己的应用调校的，提示词可以短得多，从而降低成本、改善延迟。

无论是文本生成、摘要、分类，还是 GPT-3 能执行的任何其他自然语言任务，定制 GPT-3 都会提升表现。

## 由 GPT-3 定制版本驱动的应用

**Keeper Tax** 帮助自由职业者和独立承包户处理报税。客户关联其金融账户后，Keeper Tax 用多个模型提取文本并分类交易。基于分类后的数据，Keeper Tax 找出容易被忽略的可抵扣项，并帮助客户直接在应用内报税。通过定制 GPT-3，Keeper Tax 能持续改进结果。Keeper Tax 每周新增约 500 个训练示例来微调模型，带来每周约 1% 的准确率提升，把准确率从 85% 提高到 93%。

**Viable** 帮助企业从客户反馈中提取洞见。通过定制 GPT-3，Viable 能把海量非结构化数据转化为易读的自然语言报告，突出显示最主要的客户抱怨、表扬、请求与疑问。定制 GPT-3 提高了 Viable 报告的可靠性：使用 GPT-3 定制版本后，客户反馈摘要的准确率从 66% 提升到 90%。产出的是客户制定产品决策所需的切实、直观的信息。

**Sana Labs** 是 AI 赋能学习领域的全球领先者。Sana 学习平台借助最新的 ML 突破为每位个体定制内容，为企业打造个性化学习体验。通过用自有数据定制 GPT-3，Sana 的问答与内容生成从"语法正确但泛泛而谈"升级为高准确输出，带来 60% 的改进，让学习者的体验从根本上更个性化、更有效。

**Elicit** 是一名 AI 研究助手，帮助人们直接用学术论文的发现回答研究问题。该工具先从大规模论文语料中找到最相关的摘要，再用一个 GPT-3 定制版本生成论文就该问题提出的论断（如有）。在三个重要指标上，GPT-3 定制版本全面胜过提示设计：结果更易理解（提升 24%）、更准确（提升 17%）、总体更好（提升 33%）。

所有 API 客户今天就可以定制 GPT-3。请注册并查阅[微调文档](https://beta.openai.com/docs/guides/fine-tuning)开始使用。
