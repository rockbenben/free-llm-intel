# API 中的模型蒸馏

用大型前沿模型的输出来微调一个高性价比模型——全程在 OpenAI 平台上完成

我们推出一项新的模型蒸馏（Model Distillation）服务，为开发者提供一体化工作流，可直接在 OpenAI 平台内管理整条蒸馏流水线。这让开发者能够轻松地利用 o1-preview、GPT-4o 等前沿模型的输出，去微调并提升 GPT-4o mini 等更具性价比模型的性能。

模型蒸馏是指用更强模型的输出微调更小的、高性价比模型，使其在特定任务上以更低的成本匹敌先进模型的表现。此前，蒸馏是一个多步骤、易出错的过程：开发者要在彼此割裂的工具之间手动编排多个操作，从生成数据集到微调模型、再到衡量性能改进。而蒸馏本质上是迭代的，开发者需要反复运行每个步骤，带来大量工作量和复杂度。

我们新的 Model Distillation 套件包括：

- [**Stored Completions**](http://platform.openai.com/docs/api-reference/chat/create#chat-create-store)**：** 开发者现在可以轻松生成用于蒸馏的数据集——通过我们的 API 自动捕获并存储 GPT-4o、o1-preview 等模型产生的输入-输出对。借助 Stored Completions，你可以用生产数据轻松构建数据集，用于评估和微调模型。开发者可查阅[集成指南](http://platform.openai.com/docs/guides/distillation)了解如何选择开启补全存储。
- [**Evals**](http://platform.openai.com/docs/guides/evals)（测试版）： 开发者现在可以在我们的平台上创建并运行自定义评估，衡量模型在具体任务上的表现。Evals 提供了一种一体化的性能度量方式，无需再手写评估脚本、拼接各种日志工具。你可以使用 Stored Completions 的数据，或上传现有数据集来搭建评估。Evals 也可独立于微调使用，定量评估模型在你用例上的表现。
- [**Fine-tuning（微调）**](https://platform.openai.com/docs/guides/fine-tuning)**：** Stored Completions 与 Evals 与我们既有的微调服务完全打通。这意味着开发者可以在微调用任务中使用由 Stored Completions 创建的数据集，并用 Evals 对微调后的模型运行评估——全部在平台内完成。

### 如何使用模型蒸馏

首先，[创建一个评估](http://platform.openai.com/docs/guides/evals)，用于衡量你要蒸馏的目标模型（本例中为 GPT-4o mini）的性能。这个评估将持续检验蒸馏后模型的表现，帮助你决定是否部署它。

接下来，用 Stored Completions 基于 GPT-4o 在你想要微调 GPT-4o mini 的任务上的真实输出，创建一个蒸馏数据集。操作方法是在 Chat Completions API 中设置 `store: true` 标志，即可自动存储这些输入-输出对且不影响延迟。这些已存储的补全可以被查看、筛选和打标签，以构建用于微调或评估的高质量数据集。

#### Python

```
1response = client.chat.completions.create(2  model="gpt-4o",3  messages=[4    {5      "role": "user",6      "content": [7        {8          "type": "text",9          "text": "what's the capital of the USA?"10        }11      ]12    }13  ],14  store=True,15  metadata={"username": "user123", "user_id": "123", "session_id": "123"}
```

最后，用这个数据集微调 GPT-4o mini。创建微调模型时，Stored Completions 可直接作为训练文件使用。模型微调完成后，你可以回到 Evals，检验微调后的 GPT-4o mini 与 GPT-4o 相比是否满足你的性能标准。

微调是一个迭代过程。如果初步结果不理想，你可能需要完善数据集、调整训练参数，或捕获更多模型表现欠佳的具体样例。目标是逐步改进蒸馏后的模型，直到它足以胜任生产环境。

## 可用性与定价

Model Distillation 即日起面向所有开发者开放，可用于蒸馏我们的任何模型，包括 GPT-4o 和 o1-preview。另提醒：我们还在为 GPT-4o mini 提供每天 200 万免费训练 token、为 GPT-4o 提供每天 100 万免费训练 token，直至 10 月 31 日，帮助开发者上手蒸馏。超出该限额后，训练和运行蒸馏模型的费用与我们标准微调价格相同，可在 [API 定价页](https://openai.com/api/pricing)查询。

Stored Completions 免费。处于测试阶段的 Evals 按所用 token 以标准模型价格计费。在今年年底之前，开发者若[选择加入](https://help.openai.com/en/articles/9930750-sharing-evaluations-with-openai)与 OpenAI 分享其 Evals，即可免费运行评估（每周最多 7 次）。与我们分享的 Evals 将用于帮助我们改进和评估未来的模型。

更多信息请查阅 [Model Distillation 文档](http://platform.openai.com/docs/guides/distillation)。
