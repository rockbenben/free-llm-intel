# 在线规划，离线学习：通过基于模型的控制实现高效学习与探索

## 摘要

我们提出 POLO（plan online and learn offline，在线规划、离线学习）框架，用于拥有内部模型的智能体需要在世界中持续行动和学习的场景。我们的工作建立在局部基于模型的控制、全局价值函数学习与探索三者之间的协同关系之上。我们研究了局部轨迹优化如何化解价值函数中的近似误差，以及它如何稳定并加速价值函数学习。反过来，我们也研究了近似价值函数如何帮助缩短规划时域、并得到超越局部解的更优策略。最后，我们展示了如何把轨迹优化与价值函数近似的不确定性估计结合，实现时间上协调的探索。这种探索对于快速而稳定地学习价值函数至关重要。组合这些组件，就能解决复杂的仿真控制任务——如人形机器人行走和灵巧的手内操作——所需经验折到真实世界只相当于几分钟。
