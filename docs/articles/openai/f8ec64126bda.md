# 推动负责任的人工智能在欧洲发展

正在加载…

每天，欧洲各地有数百万人使用 OpenAI 的工具学习、创作、工作和处理日常事务。我们的工具也为该地区各种规模的企业和各国政府提供支持。我们相信，负责任的人工智能能够帮助提升欧洲的竞争力并促进繁荣。随着《欧盟人工智能法案》进入下一阶段，我们将分享如何依据欧盟框架加强安全性、信息安全、透明度和来源溯源工作，以及我们将如何随着人工智能的发展不断改进实践。

## 我们对负责任人工智能的长期承诺

我们的使命是确保通用人工智能造福全人类。这一使命也意味着我们始终肩负着充分发挥人工智能益处、扩大使用机会并管理风险的责任。因此，多年来，我们持续制定治理方法，并支持切实可行的规则，帮助人们安全地从人工智能中受益，而这也是《欧盟人工智能法案》的核心目标。这些规则必须务实、适度且基于风险，才能在推进治理的同时支持创新。秉持这些原则，我们参与制定并签署了两项行为准则：欧盟的[《通用人工智能（GPAI）行为准则》⁠（在新窗口中打开）](https://digital-strategy.ec.europa.eu/en/policies/contents-code-gpai)和[《人工智能生成内容透明度行为准则》⁠（在新窗口中打开）](https://digital-strategy.ec.europa.eu/en/policies/code-practice-ai-generated-content)。两项准则均通过广泛的多利益相关方参与流程制定，并以我们在安全性、信息安全、透明度、问责和来源溯源方面推进的工作为基础。

## 构建和部署安全可靠的人工智能

GPAI 行为准则为通用人工智能模型的透明度、安全性和信息安全建立了共同框架。我们通过内部治理以及与外部专家、政府和同行机构合作，为这一框架提供支持。多年来，我们在发布模型前对其进行广泛测试，随重大版本发布[系统卡⁠（在新窗口中打开）](https://deploymentsafety.openai.com/)，通过我们的[红队测试网络](https://openai.com/index/red-teaming-network/)邀请外部专家参与模型测试，并公开维护[模型规范⁠（在新窗口中打开）](https://model-spec.openai.com/2025-12-18.html)，让公众了解我们如何塑造模型行为。

我们也在不断加强支撑这些工作的治理框架。我们的[准备框架](https://openai.com/index/updating-our-preparedness-framework/)自2023年起实施，并于2025年更新，其中阐明了我们如何识别、评估和管理先进人工智能系统带来的严重风险。我们的[前沿治理框架](https://openai.com/index/openai-frontier-governance-framework/)以此为基础，说明我们的安全和信息安全实践如何与新兴法律要求保持一致，包括《欧盟人工智能法案》的 GPAI 行为准则。这些框架共同将负责任人工智能原则转化为风险评估、防护措施、模型报告、信息安全、事件响应、外部专家意见和持续更新等方面的实际决策。

负责任的人工智能治理也需要超越单一企业的共同努力。通过[前沿模型论坛](https://openai.com/index/frontier-model-forum/)、与[美国 CAISI 和英国 AISI](https://openai.com/index/us-caisi-uk-aisi-ai-update/)的合作，以及在[第三方评估](https://openai.com/index/trustworthy-third-party-evaluations-foundations/)实践方面的工作，我们为整个生态系统的共享安全研究、外部测试和更清晰的评估标准提供了支持。

## 提升透明度与信任

我们对《人工智能生成内容透明度行为准则》的支持，建立在多年来为改善人工智能生成媒体的来源溯源而开展的研究、产品开发与合作之上。人们应当能够更充分地了解自己在网上看到的内容，包括这些内容是否由人工智能创作或编辑。OpenAI 的[来源溯源方法](https://openai.com/index/advancing-content-provenance/)依靠两个相互补充的系统：内容凭证（[C2PA⁠（在新窗口中打开）](https://help.openai.com/en/articles/8912793-c2pa-and-synthid-in-openai-generated-images#what-is-the-c2pa-standard-and-what-does-it-enable)）帮助内容携带详细的背景信息，而在元数据未能保留时，SynthID 水印则有助于保留识别信号。除图像外，我们正将这项工作扩展至音频输出。按照我们在该准则下作出的承诺，随着标准和工具不断成熟，我们正努力将 OpenAI 系统的来源溯源措施扩展至包括文本在内的各种模态。我们还希望通过提供信号、工具和指南，支持使用我们模型进行开发的客户和开发者履行各自的透明度义务。来源溯源仍是一个不断发展的领域：元数据可能丢失，标签可能无法跨平台传递，也没有任何一种信号是完美的。因此，我们支持采用多层次的方法，并与更广泛的生态系统持续合作。

## 在实践中调整治理：网络安全案例

网络安全是尤其需要动态且务实治理的领域之一。能够帮助防御人员识别和修复漏洞的能力，同样也可能带来新的滥用风险。我们通过[网络安全可信访问（TAC）计划⁠（在新窗口中打开）](https://help.openai.com/en/articles/20001258-openai-daybreak-trusted-access-for-cyber-overview)帮助合法防御人员使用人工智能，同时减少滥用，从而增强整体韧性。

我们致力于部署这些先进能力，为欧洲的防御人员提供支持。自2026年5月初启动 OpenAI 欧盟网络安全行动计划以来，我们一直与欧盟及各国网络安全机构、私营部门合作伙伴和关键基础设施运营方合作，为其提供最先进的网络安全模型，最终增强整个欧洲大陆的网络韧性。这一方法与欧盟委员会的[《网络安全与人工智能行动计划》⁠（在新窗口中打开）](https://digital-strategy.ec.europa.eu/en/library/eu-action-plan-cybersecurity-and-artificial-intelligence)一致。该计划呼吁采取协调一致的方法，应对先进人工智能带来的风险，同时发挥其增强网络韧性的潜力，包括为网络安全用途提供对先进人工智能系统的安全访问。

## 继续与整个生态系统携手合作

随着《欧盟人工智能法案》继续实施，我们将不断完善合规方法，并向监管机构和更广泛的生态系统学习。随着技术进步，规则必须保持足够的灵活性，以便适应变化，让个人、企业和组织从中受益。要让欧洲切实享受智能时代带来的益处，务实、适度且基于风险的方法至关重要。

为支持客户和开发者做好实施《欧盟人工智能法案》的准备，我们提供模型文档、系统卡、安全信息、使用政策以及来源溯源和验证工具指南等实用资源。随着实施工作的推进，我们将继续更新这些资源。如需了解更多信息，请参阅我们的[帮助中心文章⁠（在新窗口中打开）](https://help.openai.com/articles/12141645)，了解 OpenAI 应对《欧盟人工智能法案》的方法以及我们为客户提供的指南。
