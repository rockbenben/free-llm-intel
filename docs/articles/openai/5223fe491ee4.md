# GPT-4o System Card 附录：4o 图像生成

阅读 System Card

## 引言

4o 图像生成是一种全新的图像生成方法，能力远强于我们早期的 DALL·E 3 系列模型。它能够创建照片级真实的输出。它可以将图像作为输入并对其进行变换。它能够遵循精细的指令，包括可靠地在图像中融入文字。而且，由于它原生嵌入在我们全模态 GPT-4o 模型的架构深处，4o 图像生成能够运用它所掌握的一切知识，以微妙而富有表现力的方式发挥这些能力，创造出既美观又有用的图像。

4o 图像生成受益于我们现有的安全基础设施，也受益于我们在部署 DALL·E 和 Sora 过程中积累的经验。同时，这些新能力也带来了一些新风险。本 GPT-4o System Card 附录描述了我们重点关注的边际风险，以及我们为应对这些风险所开展的工作。
