# ChatGPT 自定义指令

我们推出自定义指令，让你对 ChatGPT 的回答方式有更多控制。设定你的偏好，ChatGPT 会在所有后续对话中记住它们。

我们引入自定义指令，让你能把 ChatGPT 调校得更贴合你的需求。该功能今天起在 Plus 套餐开放 beta，并在未来数周扩展到所有用户。自定义指令允许你添加偏好或要求，让 ChatGPT 在生成回答时予以考虑。

我们听到过你们的反馈：每次都要从零开始一次 ChatGPT 对话，很 friction。通过与[来自 22 个国家的用户⁠](https://openai.com/index/insights-from-global-conversations/)交流，我们更深刻地理解了可控性（steerability）在让模型有效反映每个人多样背景与独特需求上的关键作用。

今后 ChatGPT 会在每次对话中考虑你的自定义指令。模型每次回答都会参考这些指令，你不必在每个对话里重复陈述偏好或信息。

例如，老师写教案不必再反复说明自己教的是三年级科学。偏好非 Python 语言下高效代码的开发者——说一次就被记住。为大家庭买菜也更容易了，模型会把 6 人份计入购物清单。

## 插件

添加指令还能改善你使用[插件](https://help.openai.com/en/articles/7183286-how-do-i-access-plugins#h_3f79a921af)的体验——把你使用的插件所需的相关信息分享给它。例如，如果你在指令中写明居住的城市，又使用一个帮你订餐厅的插件，模型在调用插件时可能会带上你的城市。

## Beta

尤其在 beta 期间，ChatGPT 不会总能完美解读自定义指令——有时会忽略指令，或在不该应用时应用它们。

## 安全

我们调整了安全措施，以适应用户指导模型的新方式。例如，我们的 Moderation API 旨在确保违反[使用政策⁠](https://openai.com/policies/usage-policies/)的指令不会被保存。模型也可以拒绝或忽略会导致违反使用政策回答的指令。

## 隐私

我们可能使用你的自定义指令来改善面向用户的模型表现，但你可以通过[数据控制](https://help.openai.com/en/articles/7730893-data-controls-faq)关闭这一选项。[与 ChatGPT 对话一样](https://help.openai.com/en/articles/5722486-how-your-data-is-used-to-improve-model-performance)，在用于改进模型表现之前，我们会采取措施移除自定义指令中发现的个人标识符。关于我们如何使用对话改进模型表现及你的选择，详见[帮助中心](https://help.openai.com/en/articles/5722486-how-your-data-is-used-to-improve-model-performance)。

## 立即体验

Plus 用户可以通过加入自定义指令 beta 立即使用：

- 网页端：点击你的名字 → Settings（设置）→ Beta features（beta 功能）→ 启用 Custom instructions。此后点击你的名字时，菜单里会出现自定义指令。
- iOS 端：进入设置 → 新功能 → 打开 Custom instructions。自定义指令将出现在设置中。

该功能目前尚未在英国和欧盟开放。
