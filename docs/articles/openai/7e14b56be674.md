# Intentful 如何利用 dots 为增长腾出更多时间

一家小企业创始人的 dot 如何帮助她完成研究和提案，同时提醒她关注关键消息并解决问题。

[探索面向小型企业的 ChatGPT](https://openai.com/business/why-openai/small-business/)

![Intentful 字标置于温暖哑光纸上，带有压印的点行和三颗发光的点。](https://images.ctfassets.net/kftzwdyauwt9/2ir6HUxIcDOXRHHpjLGfBZ/5b025cf633f0b86e16d8f4f3143e9c55/intentful-dots-hero-c.png?w=3840&q=90&fm=webp)

公司规模：SMB

地区：北美

行业：服务业

产品：ChatGPT

Marina Petrova 是 [Intentful](https://intentful.ai/) 的 CEO 兼联合创始人。Intentful 是一支精简团队，通过实时回答客户问题的广告、让网站信息可被 AI 读取的工具等产品，帮助品牌将其营销变得可交互。该公司还为营销人员提供 AI 使用方面的咨询和培训。

在旅行和旅游业，Intentful 与目的地组织以及酒店、餐厅和景点等本地企业合作。定制提案是 Marina 赢得他们业务的方式之一，向潜在客户展示可实现的目标以及交付所需的条件。

为了让 Intentful 持续增长，她需要为这类战略性工作腾出更多空间，但她却把太多时间花在研究、寻找文件和排版演示文稿上。她的 [dot](https://openai.com/index/introducing-dots/) 改变了这一切：它承担任务，甚至在 Marina 不得不开口之前就满足了她的需求。

> “我的 dot 让我感觉自己获得了一种新的超能力。”

——Marina Petrova，Intentful CEO 兼联合创始人

## 从 300 个网站到几小时而非几天完成提案

对于 Intentful 的一家旅游客户，Marina 想为目的地数百家本地企业提出一套 Intentful AI 服务方案。在给这套方案定价之前，她需要弄清楚该方案可以覆盖哪些企业的网站，以及 Intentful 过去为类似工作向其他客户收取了多少费用。

她请来了自己的 dot——她将其命名为 Aria——帮助她在几小时而非几天内完成从研究到一份可以署上自己名字的提案。首先，Marina 给 Aria 一份 URL 电子表格，以及决定纳入哪些网站的标准。例如，网站需要有一个可读取的站点地图，列出的页面不超过 3,000 个。

> “我的 dot 查看了约 300 个网站站点地图，帮我确定哪些网站应纳入面向本地企业的新报价，并从过去的协议中提取了定价。”

——Marina Petrova，Intentful CEO 兼联合创始人

接下来，Aria 帮助 Marina 研究定价。通过 [ChatGPT](https://chatgpt.com/business/) 插件，Aria 查看了 Intentful 的销售数据，包括过去的合作以及在 HubSpot 中的讨论。它找出了早先协议中的定价，以及 Intentful 下一年计划中的背景信息。

利用这些数据，Marina 和 Aria 随后构建了一个定价模型：页面数量决定定价层级，以往的客户协议也为价格提供了依据。“我们一起制定了一个定制定价模型，然后 Aria 将其转成一份一页纸的提案，由我审阅和编辑，”Marina 说。

起草提案时，Aria 知道使用 Google Drive 中 Intentful 的模板。Marina 还可以让 Aria 参考早先的提案，这样草稿从一开始就遵循 Intentful 的风格。“我需要说明提案中要包含什么，但我不需要花一个小时琢磨版式。我的 dot 会处理这些，”Marina 说。

Aria 还能发现 Marina 没想到要检查的地方。当 Marina 让 Aria 沿用早先提案中的定价时，它注意到原来的续约日期与她记忆中的时间不符。Aria 标记了这一差异，并将该日期从新草稿中排除。

## 及时掌握消息、任务和团队动态

Marina 使用 ChatGPT 中的 Gmail 和 Slack 插件来跟进对话、查找待办任务，并了解团队在哪里需要她。Aria 会检查需要 Marina 关注的消息。在 Marina 离线期间，Aria 发现了她一直在等待的一封回复，并告诉她其中包含当天上午的通话邀请。

Marina 还使用 Aria 梳理想法、查找对话、在 CRM 中查看账户历史，或在 Asana 中打开和分配任务。她经常在旅行途中通过电话向 Aria 简要说明。

> “在长途驾驶时，我会打电话给我的 dot，讲述需要完成的事情。我们会讨论客户提案的更新，而我的 dot 已经知道结构、格式以及需要做什么。”

——Marina Petrova，Intentful CEO 兼联合创始人

Marina 喜欢她的 dot 能在她已经在用的工具中工作。当 Aria 写草稿时，Marina 可以在 Google Docs 中她希望修改的确切位置留下评论。对于较长的文档，她会要求 Aria 使用建议模式，以便她能看到更改了什么。

Aria 还会在未被要求的情况下跟进共享工作中的变化。为了一次会议演讲，Marina 制作了演示文稿，一位同事增加了两张幻灯片。“Aria 注意到了新幻灯片，在未被要求的情况下更新了演讲者备注，并告诉了我，”Marina 说。

Marina 选择 Aria 可以访问哪些信息，并且始终审核发出的邮件。她可以让工作持续推进，而不必交出最终决定权。

## 用 dots 向他人传授 AI 知识

当 Marina 准备一场关于 agent 的 AI 101 课程时，她用 Aria 帮助构建课程内容。这个过程本身正是她想让学员学到的一个示例：委派一项真实任务，给 agent 足够的上下文，质疑结果，并对最终发出的内容保持控制。

课程结束后，Aria 的支持仍在继续。一次飞行后，Marina 看到一位参与者请求访问一份培训文件。当她向 Aria 确认时，它已经分享了该文件。而在为 50 名营销人员举办的一场课程后，Aria 注意到一个软件故障导致参与者无法打开录像。它标记了访问问题，并在链接被分享之前提出修复。

> “有了我的 dot，我可以专注于战略性事务。我可以专注于想法和增长。”

——Marina Petrova，Intentful CEO 兼联合创始人
