# Intentful 如何借助 dots 腾出更多时间发展业务

一位小企业创始人的 dot 帮她做调研、写提案，也会提醒她留意重要消息，并帮她解决问题。

[了解面向小企业的 ChatGPT](https://openai.com/business/why-openai/small-business/)

![Intentful 字标印在暖色哑光纸上，纸面有一排排压凸的圆点，其中三个圆点发亮。](https://images.ctfassets.net/kftzwdyauwt9/2ir6HUxIcDOXRHHpjLGfBZ/5b025cf633f0b86e16d8f4f3143e9c55/intentful-dots-hero-c.png?w=3840&q=90&fm=webp)

公司规模：中小企业

地区：北美

行业：服务业

产品：ChatGPT

Marina Petrova 是 [Intentful](https://intentful.ai/) 的首席执行官和联合创始人。这家精干的小团队帮助品牌把营销做成可交互的体验，产品包括能实时回答客户问题的广告、让 AI 能读懂网页信息的工具等。公司还为营销人员提供 AI 使用方面的咨询与培训。

在旅行和旅游领域，Intentful 的合作对象包括旅游目的地的管理推广机构，以及酒店、餐厅和景区等当地商户。Marina 争取客户时，会为对方量身定制提案，说明能做什么以及落地需要哪些条件。

要让 Intentful 继续增长，她需要给这类战略工作留出更多时间，但调研、找文件和排版演示文稿占去了太多时间。她的 [dot⁠](https://openai.com/index/introducing-dots/) 改变了这一切。它会接手任务，甚至在 Marina 开口前就主动处理她需要做的事。

> “有了我的 dot，我觉得自己多了一项超能力。”

——Intentful 首席执行官兼联合创始人 Marina Petrova

## 从调研 300 家网站到拿出提案，耗时从几天缩短到几小时

Marina 想向 Intentful 的一位旅游业客户提议，为当地数百家商户提供一套 Intentful 的 AI 服务。为这套服务定价前，她要先弄清哪些商户的网站可以纳入服务范围，以及 Intentful 过去为其他客户做类似项目时收过多少钱。

她请自己的 dot 帮忙，还给它起了个名字叫 Aria。过去需要几天时间才能完成的工作，现在只需几小时就能从调研推进到写出一份她愿意署名的提案。Marina 先给了 Aria 一份包含 URL 的电子表格，并告诉它网站的入选标准。例如，网站得有一份可读取的站点地图，列出的页面不能超过 3,000 个。

> “我的 dot 检查了约 300 家网站的站点地图，帮我确定哪些网站可以纳入面向当地商户的新服务，还从以前的合同里找出了价格。”

——Intentful 首席执行官兼联合创始人 Marina Petrova

接下来，Aria 帮 Marina 调研定价。通过 [ChatGPT](https://chatgpt.com/business/) 插件，Aria 查阅了 Intentful 的销售数据，包括 HubSpot 里以往的合作记录和沟通内容。它找出了之前合同里的报价，也梳理了 Intentful 下一年度的计划中与定价有关的信息。

据此，Marina 和 Aria 建立了一套定价模型。报价档位由网页数量决定，具体价格也参考以往的客户合同。“我们一起推敲出了一套定制的定价模型，然后 Aria 把它写成一页提案，我再审阅和编辑，”Marina 说。

起草提案时，Aria 知道要用 Intentful 存在 Google Drive 里的模板。Marina 也可以指定一份早先的提案作为参考，让初稿从一开始就符合 Intentful 的风格。Marina 说：“我需要交代提案要写哪些内容。至于怎么排版，我用不着花一个小时去琢磨。我的 dot 会处理。”

Aria 还能发现 Marina 没想到要核对的问题。Marina 请 Aria 沿用一份旧提案中的价格时，它发现原来的续约日期和她记得的时间对不上。Aria 提醒了她，并在新稿里省略了这个日期。

## 及时掌握消息、任务和团队动态

Marina 用 ChatGPT 里的 Gmail 和 Slack 插件跟进对话、查找待办，了解团队在哪些事情上需要她。Aria 会查看有没有需要 Marina 关注的消息。有一次，Marina 没在线，Aria 发现了她一直在等的回复，提醒她对方提议当天上午通话。

Marina 还会和 Aria 一起梳理想法、查找对话、在 CRM 中查看客户的历史记录，或在 Asana 中创建并分配任务。出行时，她经常打电话向 Aria 交代工作。

> “长途开车时，我会给我的 dot 打电话，把待办捋一遍。我们会聊到客户提案有哪些地方要更新，我的 dot 已经知道提案的结构、格式和具体要做什么。”

——Intentful 首席执行官兼联合创始人 Marina Petrova

Marina 喜欢她的 dot 能直接在她惯用的工具里工作。Aria 写好初稿后，Marina 可以在 Google Docs 中需要修改的具体位置留下评论。文档较长时，她会让 Aria 用建议模式修改，以便查看改了哪些内容。

即使没人提醒，Aria 也会跟进共享工作中的变化。有一次，Marina 做了会议演示文稿，一位同事加了两页幻灯片。“Aria 发现多了两页，主动更新了演讲者备注，还通知了我，”Marina 说。

Marina 决定 Aria 可以访问哪些信息，所有对外邮件在发出前也都由她审核。这样，她可以让工作继续推进，同时保留最终决定权。

## 用 dots 教别人使用 AI

Marina 准备一节介绍 agent 的 AI 入门课时，请 Aria 帮忙备课。这个过程本身就是她希望学员掌握的做法。把一项真实的任务委派给 agent，给足背景信息，对结果提出质疑，并亲自把关对外发送的内容。

课后，Aria 也在继续提供支持。有一次航班落地后，Marina 看到有位学员申请访问培训文件。她向 Aria 确认时，文件已经分享出去了。另一次，为 50 位营销人员授课结束后，Aria 发现一个软件故障导致学员无法打开录像。它在链接发出前指出了这个访问问题，并提出帮忙修复。

> “有了我的 dot，我就能专注于战略工作，专注于想法和业务增长。”

——Intentful 首席执行官兼联合创始人 Marina Petrova
