# 企业可在 Cloudflare Agent Cloud 中利用 OpenAI 模型驱动智能体工作流

正在加载…

**核心提要：**

- 数百万家企业现可直接在 Cloudflare Agent Cloud 中调用 OpenAI 的前沿模型。
- 借助 OpenAI，使用 Cloudflare Agent Cloud 的企业能够部署由 GPT‑5.4 等模型驱动的智能体，以处理实际业务。
- 企业可将基于 Codex 运行框架 (Harness) 构建的智能体部署至 Cloudflare 平台。

Cloudflare 正在进一步扩大其 Agent Cloud 平台对 OpenAI 前沿模型（包括 [GPT‑5.4⁠](https://openai.com/index/introducing-gpt-5-4/)）的支持力度，惠及 Agent Cloud 平台上的数百万客户。通过 Agent Cloud，企业可部署由 OpenAI 模型驱动的 AI 智能体，以执行实际任务。例如，企业可以将 Agent Cloud 与 OpenAI 产品结合使用，在确保安全且具备生产就绪的环境中，自动处理客户响应、系统更新及报表生成等任务。

Agent Cloud 构建于 [Cloudflare Workers AI⁠（在新窗口中打开）](https://www.cloudflare.com/developer-platform/products/workers-ai/) 之上。作为边缘 AI 模型运行平台，Workers AI 助力企业轻松构建并部署 AI 应用与智能体，从而在全球范围内提供极速且实时的用户体验。

Cloudflare 首席技术官 Dane Knecht 表示：“通过将 OpenAI 强大的模型能力直接引入 Cloudflare 环境，我们缩短了‘智能’与‘终端用户’之间的距离。这让开发者能够构建精密的 AI 驱动应用与智能体，它们不仅智力卓越，而且具备极速响应和全球扩展的原生能力。无论是利用 Codex 优化开发工作流，还是大规模部署 AI 应用，我们很自豪能为下一代 AI 原生技术栈提供基础设施支撑。”

此次在 Agent Cloud 中深化与 OpenAI 的合作，标志着 Cloudflare 在为各类企业引入先进 AI 功能（包括 [Codex⁠](https://openai.com/codex/) 等工具）方面迈出了坚实一步。目前，Codex 运行框架已在 Cloudflare Sandbox（一个用于构建、运行及测试 AI 应用的安全虚拟环境）中正式上线，并将在近期接入 Workers AI。

OpenAI Codex 产品负责人 Rohan Varma 指出：“云端智能体正迅速成为开展业务的基石。通过与 Cloudflare 合作，我们大幅降低了开发者的门槛，使其能够更便捷地部署基于 GPT‑5.4 和 Codex 的生产级智能体，从而在大规模企业工作负载中发挥实效。”

开发者与客户可通过[点击此链接⁠（在新窗口中打开）](https://developers.cloudflare.com/ai-gateway/usage/providers/openai/)，在 Cloudflare 平台中使用 OpenAI 的功能。

Cloudflare 此举进一步延伸了 OpenAI 产品在全球顶尖企业[“智能层”中的应用⁠](https://openai.com/index/next-phase-of-enterprise-ai/)，其中包括[埃森哲⁠](https://openai.com/index/accenture-partnership/)、[沃尔玛⁠（在新窗口中打开）](https://corporate.walmart.com/news/2025/10/14/walmart-partners-with-openai-to-create-ai-first-shopping-experiences)、[Intuit⁠](https://openai.com/index/intuit-partnership/)、[赛默飞世尔⁠（在新窗口中打开）](https://corporate.thermofisher.com/us/en/index/newsroom/Our-stories/Thermo-fisher-scientific-open-ai-collaboration.html)、[纽约梅隆银行⁠](https://openai.com/index/bny/)、[州立农业保险⁠（在新窗口中打开）](https://newsroom.statefarm.com/state-farm-advances-ai-vision-through-collaboration-with-openai/)、[摩根士丹利⁠](https://openai.com/index/morgan-stanley/)、[西班牙对外银行 (BBVA) ⁠](https://openai.com/index/bbva-collaboration-expansion/)等。目前，全球已有超 [100 万家企业⁠](https://openai.com/index/1-million-businesses-putting-ai-to-work/)客户选择 OpenAI，Codex 的周活跃用户达 300 万，OpenAI API 每分钟处理的 Token 数量已突破 150 亿个。
