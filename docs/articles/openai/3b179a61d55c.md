# OpenAI 宣布董事会新成员

Sue Desmond-Hellmann 博士、Nicole Seligman、Fidji Simo 加入董事会；Sam Altman 重新加入董事会


我们宣布董事会新增三名成员，这是我们致力于扩展的第一步：**前比尔及梅琳达·盖茨基金会的首席执行官****Sue Desmond-Hellmann ***博士*、*索尼公司前执行副总裁兼总法律顾问 ***Nicole Seligman**，以及 *Instacart 首席执行官兼董事长 ***Fidji Simo**。此外，首席执行官 **Sam Altman** 将重新加入 OpenAI 董事会。

Sue、Nicole 和 Fidji 拥有领导全球组织和应对复杂监管环境的丰富经验，专业背景涵盖技术、非营利组织及董事会治理等领域。他们将与现任董事会成员 Adam D’Angelo、Larry Summers 和 Bret Taylor 以及 Sam 和 OpenAI 的高级管理层密切合作。

OpenAI 董事会主席 Bret Taylor 表示：“我非常高兴欢迎 Sue、Nicole 和 Fidji 加入 OpenAI 董事会。他们的经验和领导力将使董事会能够监督 OpenAI 的发展，并确保我们践行‘让人工通用智能造福全人类’的使命。”

**Sue Desmond-Hellmann 博士**是一位非营利组织领导者和医生。Sue Desmond-Hellmann 博士、目前担任辉瑞公司董事会成员和总统科学技术顾问委员会成员。她曾担任宝洁公司、Meta (Facebook) 和比尔及梅琳达·盖茨医学研究所的董事。 2014 年至 2020 年，她担任比尔及梅琳达·盖茨基金会的首席执行官。2009 年至 2014 年，她担任加州大学旧金山分校 (UCSF) 教授兼校长，是第一位担任该职位的女性。她还曾担任 Genentech 公司产品开发总裁，在首个基因靶向抗癌药物的研发中发挥了领导作用。

**Nicole Seligman** 是全球公认的企业和公民领袖及律师。她目前在三家上市公司董事会任职：Paramount Global、MeiraGTx Holdings PLC 和 Intuitive Machines, Inc。Seligman 曾在索尼集团担任多个高级领导职务，包括索尼公司的执行副总裁兼总法律顾问，负责监督包括全球法律和合规事务在内的职能工作。她还曾担任索尼娱乐公司总裁，同时担任索尼美国公司总裁。Seligman 目前还在纽约市的 Schwarzman Animal Medical Center 和 The Doe Fund 担任非营利领导职务。此前，Seligman 曾担任华盛顿特区 Williams & Connolly LLP 诉讼业务的合伙人，处理复杂的民事和刑事案件，并为包括 William Jefferson Clinton 总统和 Hillary Clinton 在内的众多客户提供咨询服务。她曾担任美国最高法院 Thurgood Marshall 大法官的法律助理。

**Fidji Simo** 是消费技术行业的资深人士，拥有超过 15 年领导全球顶尖企业运营、战略及产品开发的经验。她是 Instacart 的首席执行官兼董事长，同时也是 Shopify 的董事会成员。加入 Instacart 之前，Simo 曾担任 Facebook 应用程序副总裁兼负责人。在 Facebook 工作的最近十年里，她负责 Facebook 应用的运营，包括动态消息、快拍、群组、视频、市场、游戏、新闻、约会、广告等功能。Simo 创立了 [Metrodora 研究所](https://www.metrodora.co/)，这是一家多学科医疗诊所和研究基金会，致力于神经免疫轴疾病的护理和治疗，并担任 Metrodora 基金会的主席。
