# 扩大联邦、州、地方和部落政府的AI使用范围与网络防御能力

一项开创性协议将为联邦、州、地方和部落政府免除许可费并提供使用费五折优惠，同时扩大对公共部门网络防御人员的支持和使用权限。


美国公务人员，包括奋战在网络防御一线的人员，都应能使用最出色的AI工具。今天，OpenAI for Government与美国联邦总务管理局（GSA）宣布达成一项新的多年期协议，以延续去年面向联邦政府推出的优惠。这项开创性协议将把许可费降至0美元（通常为每位用户每月15美元），并将使用费减半，同时进一步加强对公共部门网络防御人员的支持。OpenAI还将向所有州、地方和部落政府提供同样的优惠。

帮助政府提高工作效能，让服务更快捷、更便利、更安全、更可靠，是让每个人都能从AI中受益的重要途径。公务人员应参与塑造AI在政府中的应用方式。第一步，就是让他们能够使用包括GPT‑6 Astra在内的一流工具，同时提供有力保障、可预测的成本，并尊重其公共服务使命。目前，已有超过100万名政府雇员通过我们的现有协议使用ChatGPT；此次合作升级后，美国约2300万名公共部门工作人员均有资格参与。

过去一年，公务人员已经展示了扩大OpenAI工具使用范围所能带来的成果：

- Daybreak Access正在帮助政府网络防御人员更快、更高质量地开展漏洞研究、恶意软件分析和安全工具开发。
- 美国疾病控制与预防中心（CDC）加快了公共卫生文献综述工作，将以往需要数天乃至数月的流程缩短到大多数初步报告在30分钟内完成；92%的参与专家表示工作效率有所提升
- 佐治亚州税务局将税表数字化所需时间从最长两周缩短至15分钟
- 北卡罗来纳州财政厅使用ChatGPT发现了价值数百万美元、可能返还给居民的无人认领财产
- 劳伦斯利弗莫尔国家实验室使用ChatGPT加快初步核聚变研究模型的开发，将原本可能耗时数月的工作压缩至数小时

借此次公告之机，我们还将加大对政府网络防御人员的支持，帮助他们保护应急响应、交通、公共卫生、公用事业及其他关键系统。OpenAI总裁Greg Brockman近期发表的文章《防御者之窗》和一封全行业公开信均呼吁业界与政府立即采取集体行动。根据新政策，每个通过验证的政府实体都将获准使用面向高级网络防御人员的Daybreak Blue，价格为标准商业定价的五折，并可获得规模化培训与赋能支持，以促进采用。这些防御人员还可申请以标准商业价格使用Daybreak Red，开展高级漏洞研究、漏洞利用验证和红队测试。

此次公告进一步拓展了Daybreak for Frontline Defenders计划。OpenAI上周宣布为该计划投入10亿美元，在全球范围内为一线网络防御人员提供使用补贴、培训、技术支持和合作机会。

## 根据今天公布的计划，OpenAI将提供：

- 扩大使用范围：该协议的优惠将首次从联邦政府扩大至州、地方和部落政府
- 降低使用成本：标准的每位用户每月15美元许可费将降至0美元，无最低承诺；符合条件的联邦、州、地方和部落政府机构还可享受使用费五折优惠
- Daybreak Blue使用权限与培训：每个通过验证的政府实体都将获准以标准商业定价的五折使用Daybreak Blue，并获得规模化培训与赋能支持，帮助政府领导者和网络防御人员有效使用模型，抢先发现漏洞。
- 长期使用：协议期限为27个月，自2026年10月1日起至2028年12月31日止，为各机构采用AI提供稳定基础
- 实用的采用支持：OpenAI将提供采购指南、使用量估算、支出控制、引导上手、FinOps指导、网络研讨会，并扩展Government Academy，帮助所有公务人员熟练、自信地使用AI
- 安全且负责任的部署：ChatGPT Enterprise不会使用包括输入或输出在内的业务数据来训练或改进OpenAI模型；参与机构将继续享有所选合格服务对应的保护措施

AI应让公务人员有更多时间投入真正重要的工作：服务民众、保护美国人民赖以生存的关键系统，以及解决棘手问题。通过扩大AI在各级政府的使用范围，我们可以帮助将人的潜能转化为公共价值，并确保全美各地社区都能从AI中受益。
