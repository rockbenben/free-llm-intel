# GPT‑5.2 系统卡附录：GPT‑5.2 Codex

阅读系统卡


## 介绍

GPT‑5.2‑Codex 是我们迄今最前沿的智能体编码模型，赋能复杂的软件工程实践。GPT‑5.2‑Codex 基于 [GPT‑5.2⁠](https://openai.com/index/introducing-gpt-5-2/)，并针对 Codex 智能体编码进行了优化，具体改进包括：通过上下文压缩提升长程任务执行能力；在重构、迁移等大规模任务中具备更出色的性能；在 Windows 环境下实现更优表现；以及在网络安全方面显著增强。

本系统卡概述了为 GPT‑5.2‑Codex 实施的全面安全措施。它详细介绍了模型层级的缓解措施（例如针对有害任务和提示注入的专业安全训练）以及产品层级的缓解措施（如代理沙盒与可配置网络访问）。

GPT‑5.2‑Codex 在我们的“准备框架”下接受了评估。它在网络安全领域具备较强能力，但未达到该领域的高 (High) 能力级别。我们预计当前能力快速增长的趋势将持续，这些模型将在不久的将来达到网络安全领域的高能力阈值。与其他近期模型类似，它在生物学领域被视为具备高能力级别；并将按照我们在 GPT‑5 系列其他模型中使用的同等级安全防护措施进行部署。该模型在 AI 自我提升方面未达到高能力级别。
