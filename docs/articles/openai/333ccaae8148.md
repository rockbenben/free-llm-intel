# GPT‑6 Astra：面向工作场景的下一代智能模型

我们最强大的模型，专为完成企业所需的各种工作而打造。


上周，我们推出了全球最智能、对齐程度最高的模型 GPT‑6 Astra，该模型现已登陆 ChatGPT 工作、Codex 和 API。Astra 在计算机操作、浏览、专业工作、软件工程、网络安全和科学领域均达到业界领先水平，让团队能够以无与伦比的速度、准确度和判断力处理最具挑战性的专业工作。

## 全球最擅长处理复杂工作的模型

大多数 AI 系统必须先由企业准备数据、重新设计工作流并构建定制集成，之后才能创造价值。Astra 改变了这一点。在 ChatGPT 工作和 Codex 中，它既能编写代码，也能操作人们日常使用的应用程序，即使这些应用程序没有 API。这意味着企业从第一天起就能在现有工作流中运用 AI，无需大量准备或工程开发。

上线短短几天，我们已经看到客户开始使用 Astra：从优化 GPU、发现财务报表中的差异，到制作更符合品牌调性的演示文稿，不一而足。

## 为关键工作提供更完善的安全保障与控制措施

让 AI 访问业务系统，前提是企业能够确信它会如何行动。为此，Astra 已成为我们迄今对齐程度最高的模型，更能遵循人类意图和授权范围。

在训练期间，我们通过[内部计算机操作安全基准⁠](https://openai.com/index/gpt-6-astra/#:~:text=Internal%20computer%20use%20safety%20benchmark%20(lower%20is%20better))测试了 Astra。该基准以最具挑战性的业务场景测试模型，例如泄露机密信息、将仪表板分享给过多人员或删除数据。在这项评估中，Astra 输出意外结果的频率比 GPT‑5.6 Sol 低 89%，比 Claude Fable 5.1 低 74.7%。额外确认和自动审查进一步提升了 GPT‑6 Astra 和 GPT‑5.6 Sol 的表现。

组织还可以自行决定 Astra 的部署范围。新的企业管理控制功能可限制其仅访问获批的网站和桌面应用程序、管理上传与下载文件，并控制浏览历史记录。ChatGPT 工作和 Codex 还提供确认策略等安全措施，要求模型在执行可能造成严重后果的操作前获得批准，并自动审查可能不安全或未经授权的工具调用。借助这些控制功能，团队可以从受限配置起步，再逐步扩大访问范围。

为进一步拓展访问范围，除了 Astra 之外，我们还将在 ChatGPT 桌面端中发布新的企业插件。借助最新的浏览器操作能力，Oracle Analytics、Power BI（Microsoft Fabric 服务）、Navan 和 Avalara 的插件让用户可以更轻松地访问熟悉的企业应用程序。

[Astra](https://deploymentsafety.openai.com/gpt-6-astra) 也是首个达到[关键网络安全能力阈值⁠](https://openai.com/index/path-to-astra/)的模型，该阈值依据我们的[准备框架⁠](https://openai.com/index/updating-our-preparedness-framework/)制定。随着模型能力的增强，我们也[加强了防护措施](https://deploymentsafety.openai.com/gpt-6-astra)，以防止滥用和模型执行未经授权的操作，包括训练 Astra 遵守安全与安保边界、增强其抵御绕过安全措施企图的能力，以及部署旨在拦截有害响应的自动检查机制。

经批准，符合条件的 API 客户可在支持的端点使用零数据保留。
