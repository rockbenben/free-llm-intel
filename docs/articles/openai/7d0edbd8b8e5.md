# OpenAI Scholars 2018：结业项目

我们的首届 OpenAI Scholars 已完成项目。

摄影：Blake Tucker

我们的首届 [OpenAI Scholars⁠（在新窗口打开）](https://blog.openai.com/openai-scholars/) 现已完成项目。在过去三个月里，我们看到有经验的软件开发者可以多么快地成长为机器学习实践者。[全部八位学者⁠（在新窗口打开）](https://blog.openai.com/openai-scholars-class-2018/)都产出了激动人心的结业项目，并将在机器学习领域继续工作或执教。

我们将在 OpenAI 举办一场 [Scholars Demo Day⁠](https://openai.com/index/openai-scholars-2018-final-projects/#demoday)，展示他们的工作。我们的学者将谈论他们这个夏天的工作，随后是问答、交流以及与学者和其他 OpenAI 同事的茶点时光。活动对所有感兴趣的人开放——只需点击下方链接 RSVP！

- [为 Demo Day 报名（在新窗口打开）](https://docs.google.com/forms/d/1ZdK7Q6xPQ-5j5FDIW1X0jHVa_stpZ-q3uTpU_ecpUTg/edit)

我们计划在 2019 年继续举办 Scholars 项目。该项目面向在这个领域代表性不足群体的开放，我们认为只有领域有更好的代表性，AI 才能惠及每个人。我们还将在未来几个月发布关于首届学者的案例研究，帮助其他组织在自己公司推出类似举措。

## 学者展示日

作为首届学者的收官，我们将于 9 月 20 日把全部学者与 ML 社区成员一起召集到 OpenAI 办公室举办展示日。届时学者们将展示自己的工作，与其他参与者讨论他们的经历和未来的 ML 目标。如果你感兴趣并希望参加，请[在此报名⁠（在新窗口打开）](https://docs.google.com/forms/d/1ZdK7Q6xPQ-5j5FDIW1X0jHVa_stpZ-q3uTpU_ecpUTg/edit)。我们会录制他们的演讲以便日后分享。

我们迫不及待想看到我们的学者未来继续为 ML 社区做出贡献！
