# Endex 借助 OpenAI 推理模型构建金融分析的未来

[Endex](https://endex.ai/) 是面向金融公司的 AI 平台，正在开发一款能够检索、综合并对复杂金融数据进行推理的 AI 分析师。他们与 OpenAI 紧密合作，重塑投资专业人士的工作流。

“金融专业人士需要的不只是搜索结果，而是结构化的思考和深度分析，”Endex CEO Tarun Amasa 表示。“我们设想这样一个未来：每家都能获得数字分析师团队，无缝增强那些耗时的流程。”

通过评估并整合 OpenAI 的一系列模型——包括 GPT-4o、o1-mini、o1-preview 和 o3-mini——Endex 将公司的内部数据、公开披露文件和可信金融来源连接起来，以增强研究并强化关键工作流。

## 为 AI 驱动的金融带来分析师级精度

在金融领域，精度至关重要，但许多 AI 工具会漏掉影响决策的关键细节。例如，EBITDA 对账中一处被遗漏的调整，或被忽视的“控制权变更条款”，都可能改变一笔投资的财务前景。

Endex 采取了不同的方法。其 agent 不依赖检索增强生成（RAG），而是使用 OpenAI 的推理模型，像金融分析师一样检索并思考数据：提取事实、识别不一致、为指标提供语境。

Endex 的 agent 自主处理财务报告、市场数据和公司专有知识，完成以下任务：

- 先例交易概览
- 业绩表现摘要
- 投资委员会（IC）备忘录准备
- 数据室尽职调查

“OpenAI o 系列型号的长上下文窗口、指令遵循和推理能力带来了显著差异，”Amasa 说。“模型不只是在大海捞针，它们能像资深分析师那样分析金融数据并检测差异。”

> “模型不只是在大海捞针，它们能像资深分析师那样分析金融数据并检测差异。”

Tarun Amasa，Endex CEO

agent 可以以邮件、文档、Excel 模型或幻灯片的形式交付成果，让分析师能够自信地把 agent 的结论追溯到来源，真正成为投资团队的延伸。

## 为金融公司实现更高准确率与自动化

Endex 在使用 OpenAI 推理模型上取得了突破性表现，支撑精确的金融工作流：

- **多步金融推理**：此前 Endex 依赖复杂提示、链式补全和多道验证步骤。借助 OpenAI o1，他们在不牺牲准确率的情况下简化了这一过程。
- **更快更高效的 AI**：使用 OpenAI o3-mini，Endex 在每轮三分之一的延迟下提升了智能水平，支持分析机密信息包（CIP）和自动化金融模型对账等精细的多步工作流。
- **AI 驱动的交叉核验**：Endex 的 agent 现在能够识别金融数据中的差异，标记脚注中的重述，并带着针对性引用揭示不一致之处。这让分析师专注于决策而非手工核验。
- **多模态分析**：Endex 的 Finance Agent Retrieval（FAR）基准测评模型对表格与图表数据的上下文使用能力——金融专业人士的关键信息来源。OpenAI o1 的视觉能力让 Endex 能够处理投资者演示材料、内部 deck、Excel 模型和 8-K 文件，并取得了领先的 FAR 分数。
- **交付物自动化**：Endex 生成详细报告，减少了金融分析传统上需要的人工劳动。这种自动化让专业人士专注高价值策略，而非数据排版。

“金融专业人士需要结构化、可引用的推理和对细节的关注，传统 LLM 在这种连贯性水平上力不从心，”Amasa 指出。“OpenAI 的推理系列模型是首个持续达到这一质量标准的。”

## 以专家评估开发金融 agent

Endex 平台的核心是一套严格的评估与测试框架，由其与 OpenAI 密切协作开发。

这套系统让 Endex 工程团队能够直接在 OpenAI 平台内追踪模型输出，监控响应延迟、首 token 生成时间和推理深度等关键指标。专业人士随后可在真实场景中评估输出。

通过盲测用户评估，金融专家在 **70%** 的情况下更偏好 OpenAI o1 模型生成的回答，胜过非推理模型。Endex 还持续跟踪响应延迟和首 token 生成时间等性能指标，以不断优化系统。

通过 [强化学习](https://openai.com/residency/) 对 GPT-4o mini 和 OpenAI o1 系列等模型进行微调——这对先例交易分析等研究密集型任务至关重要——也改善了实体抽取和查询意图映射。

“我们与 OpenAI 的合作解锁了按专业人士期待的推理与输出风格定制模型行为的工具，”Endex 联合创始人 Pratham Soni 表示。“我们已部署强化微调模型，把我们的定制数据集转化为针对性的推理改进。”

## 规模化 AI 驱动的金融分析

OpenAI 对 Endex 的成长不可或缺——不只是作为模型供应商，更是作为在打磨评估技术、拓展 AI 驱动金融分析边界上的战略合作者。

“这段合作中最让我兴奋的是我们对垂直领域 AI 的共同愿景。我们的工作超越 API——是构建将改变金融分析师工作方式的 agent-用户界面，”Amasa 说。

Endex 团队看到了巨大的规模化机遇。他们计划持续打磨自主分析师能力，确保技术能为客户处理日益复杂的金融任务。

“我们的客户将成为先驱——在一个 AI 系统不只是工具、而是真正同事的世界里，”Amasa 说。“借助 OpenAI 的模型，我们正在构建能够规划、推理并执行金融分析的系统。以前这简直只存在于科幻小说里。”

> “我们的客户将成为先驱——在一个 AI 系统不只是工具、而是真正同事的世界里。”

Tarun Amasa，Endex CEO
