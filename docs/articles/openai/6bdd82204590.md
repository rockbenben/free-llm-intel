# 宣布设立 OpenAI 伦敦办公室

我们很高兴宣布 OpenAI 的首次国际扩张——在英国伦敦设立新办公室。

我们在伦敦设立的首个国际办公室，标志着 OpenAI 成长历程中的一个里程碑，体现了我们拓展业务版图的承诺：吸纳多元视角，加速我们的使命——确保通用人工智能（AGI）惠及全人类。

“我们非常兴奋将研发版图延伸到伦敦这座以深厚文化和卓越人才库闻名全球的城市，”OpenAI 人力副总裁 Diane Yoon 表示，“我们渴望组建覆盖研究、工程、市场进入及其他领域的充满活力的团队，强化我们创建并推广安全 AGI 的努力。”

> “我们非常兴奋将研发版图延伸到伦敦这座以深厚文化和卓越人才库闻名全球的城市。”

Diane Yoon

摄影：Stuart Bailey

伦敦充满活力的科技生态和卓越的人才，使其成为 OpenAI 首个国际办公室的理想选址。伦敦团队将专注于推进 OpenAI 前沿的研究与工程能力，同时与本地社群和政策制定者围绕我们的使命展开协作。

“我们把这次扩张视为吸引世界级人才、推动 AGI 开发与政策创新的机会，”OpenAI CEO Sam Altman 补充道，“我们对未来充满期待，也期待看到伦敦办公室为构建和部署安全 AI 做出的贡献。”

> “我们把这次扩张视为吸引世界级人才、推动 AGI 开发与政策创新的机会。”

Sam Altman
