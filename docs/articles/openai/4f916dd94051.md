# 全新升级的内容审核工具

阅读文档

为帮助开发者保护其应用免受潜在滥用，我们推出更快、更准确的[审核（Moderation）端点](https://beta.openai.com/docs/api-reference/moderations)。该端点为 OpenAI API 开发者免费提供[GPT 驱动⁠](https://openai.com/index/customized-gpt-3/)的分类器，用于检测不良内容——这是[利用 AI 系统⁠](https://openai.com/index/critiques/)辅助人类监督这些系统的一个实例。我们还发布了描述方法的[技术论文](https://arxiv.org/abs/2208.03274)，以及用于评估的[数据集](https://github.com/openai/moderation-api-release)。

给定一段文本输入，Moderation 端点会评估内容是否属于色情、仇恨、暴力或鼓吹自残——这些是我们[内容政策](https://beta.openai.com/docs/usage-guidelines/content-policy)禁止的内容。该端点在训练时注重快速、准确，并在各类应用中保持稳健表现。重要的是，它能降低产品“说错话”的概率，即便大规模部署给用户也是如此。由此，AI 能够在教育等敏感场景中释放价值——否则在这些场景难以放心使用。

Moderation 端点帮助开发者受益于我们的基础设施投入。开发者无需自行构建和维护分类器——正如我们在[论文](https://arxiv.org/abs/2208.03274)中记录的那样，这是一个繁重的过程——而是可以通过一次 API 调用访问准确的分类器。

作为 OpenAI [让 AI 生态更安全⁠](https://openai.com/index/best-practices-for-deploying-language-models/)[承诺⁠](https://openai.com/charter/)的一部分，我们提供该端点，允许对所有 OpenAI API 生成的内容进行免费审核。例如，OpenAI API 客户 [Inworld](https://www.inworld.ai/) 使用 Moderation 端点帮助其 AI 虚拟角色保持适合受众的言行。借助 OpenAI 的技术，Inworld 可以专注于其核心产品：打造令人难忘的角色。目前我们不支持对第三方流量进行监控。

想上手 Moderation 端点，请查看[文档](https://beta.openai.com/docs/guides/moderation/overview)。训练过程与模型性能的更多细节见我们的[论文](https://arxiv.org/abs/2208.03274)。我们还发布了[评估数据集](https://github.com/openai/moderation-api-release)，其中包含在上述类别下标注的 Common Crawl 数据，希望它能推动该领域的进一步研究。
