# 我们对欧盟文本溯源规则的做法

在当下技术的限度内推动透明。

加载中…

[内容溯源](https://openai.com/index/advancing-content-provenance/) 帮助人们理解内容来自哪里、是如何被创建或编辑的，以及其中是否包含与我们模型相关的信号。我们已经公开提供了识别由我们模型生成的图像和音频的工具。今天，我们分享针对 EU AI Act 的文本水印做法，以及它如何融入我们更广泛的工作。

EU AI Act 要求生成式 AI 提供商让生成的文本能够以机器可读的方式被识别。文本水印与检测仍属早期技术，存在显著局限，关于其收益与负责任使用的观点也仍在形成之中。我们的分阶段做法既反映 EU AI Act 的要求，也反映技术的局限，并着重透明地说明文本水印能与不能告诉人们什么：

- 从今天起，全球 API 客户将可以对部分模型选择启用文本水印。在 API 中，文本水印默认仍将保持关闭。
- 在未来几周，我们将为欧盟境内符合条件的 ChatGPT 和 Codex 文本输出添加隐形水印。
- 我们正在开放对我们文本水印检测器的访问申请。访问权限最初仅限于经批准的研究人员和专家组织，他们能帮助我们评估和改进该技术。以上内容仅适用于文本溯源——我们对音频和图像的验证工具，包括我们的 [openai.com/verify](https://openai.com/verify) 网页工具和我们的 [Content Provenance API（在新窗口中打开）](https://developers.openai.com/api/docs/guides/content-provenance)，将继续向希望了解某个图像或音频文件是否由我们某套系统生成的组织公开开放。

## 我们的水印如何工作、表现如何

我们的文本水印技术 textGrain 会在模型的用词选择中加入一种隐形统计信号。我们的检测器通过寻找该信号来评估一段文本是否包含 OpenAI 水印。关于 textGrain 工作原理的更多细节见我们的[技术报告（在新窗口中打开）](https://cdn.openai.com/pdf/e9508624-d767-41b6-a26d-e34ca798ada6/textgrain-entropy-calibrated-watermarking-for-language-model-text.pdf)，该报告将在未来几周更新更多细节。我们还计划将这项技术开源，以便其他人可以在其基础上继续构建。

在我们的评测中，textGrain 的表现达到或超过了我们测试的其他方案，包括用于文本的 SynthID。即便如此，理想条件下的强劲表现并不能保证日常使用中的可靠检测。

检测器可能犯两类错误：在并不存在水印时报告有水印——误报——或漏掉实际存在的水印——漏报。下面的评测展示了其中的一些挑战：

- **较短或受约束更强的文本更难检测。** 在 1% 的目标误报率下，对于心理学这类内容，我们的检测器能在约 80% 的 200 token 片段中识别出水印，而 400 token 片段的识别率约为 95%。在数学这类用词灵活性较低的内容上，检测率明显更低。
- **编辑会削弱水印。** 在一项针对 400 token 片段的评测中，将 10% 的词替换为同义词会使检测率从约 92% 降至 66%。替换 25% 的词则降至 17%。

这些局限促成了我们的决定：初期仅向经批准的研究人员和专家组织提供检测器访问权限，他们能帮助我们评估可靠性与负责任的使用方式。

该图展示了在 1% 的目标误报率下，针对 [ELI5 数据集（在新窗口中打开）](https://huggingface.co/datasets/rexarski/eli5_category) 中数学与心理学问题的加水印回复的检测结果。检测效果随文本长度增加而提升，但在数学这类用词灵活性较低的内容上整体明显更低。

## 文本水印不能告诉你什么

文本水印只就我们的系统在一段文本中扮演的角色提供有限的信号。理解检测结果能得出什么、不能得出什么非常重要。

- **水印不衡量人为贡献。** 它可以表明 OpenAI 系统生成或处理了片段的一部分，但不能说明其中投入了多少人类判断、编辑或创意。
- **水印不确立所有权或责任。** 它无法确定文本归谁所有、其使用是否合法、是否需要披露，以及由谁负责。
- **水印不识别用户。** 它不会将某个人、组织、账户、prompt 或对话与文本关联起来。
- **水印不验证准确性。** 它不能告诉你一段文本是否真实、是否具有误导性、是否有害，或是否被置于恰当的语境中。
- **未检测到水印并不能证明是人类创作。** 用 OpenAI 工具生成的文本可能过短、经过编辑或被翻译过，导致检测无法可靠工作。它也可能来自不受支持的模型、产生于水印启用之前，或由其他公司的工具生成。

## 我们的下一步

- **在欧盟推出文本水印。** 未来几周，我们将仅在欧盟为所有套餐中符合条件的 ChatGPT 和 Codex 用户引入文本水印。我们不会在推出时把文本水印设为全球默认。这种区域性做法为我们留出了从真实使用和反馈中学习的空间。
- **为 API 客户开放可选择的加水印输出。** 从今天起，全球 API 客户将可以对部分模型选择启用加水印的文本输出。这让客户能够自行决定水印如何契合其透明度义务以及他们为用户提供的体验。我们也在与云合作伙伴协作，计划在未来几周为通过其服务访问的 OpenAI 模型输出提供水印能力。
- **向研究人员和专家组织提供检测器访问权限。** 经批准的研究人员和专家组织从今天起即可[提交申请](https://openai.com/form/content-provenance-api/)。按照 [Code of Practice（在新窗口中打开）](https://digital-strategy.ec.europa.eu/en/policies/code-practice-ai-generated-content)，访问权限将最初按个案逐一审批发放，以支持文本溯源的评估与改进。该工具会报告是否检测到 OpenAI 水印，而不会识别用户或透露其 prompt 或对话。鉴于漏检与误报的风险，我们不会在推出时将其公开。

随着技术、标准和证据的演进，我们预期会对这一做法的每个部分进行复审。

## 我们在内容溯源上的更广泛做法

没有任何单一的溯源技术足以独当一面，因此我们采取分层做法，将开放标准、持久水印与验证工具结合起来。

我们为受支持的图像输出添加 Content Credentials，符合 [C2PA 合规标准（在新窗口中打开）](https://c2pa.org/conformance/)，在受支持的图像和音频中嵌入隐形 [SynthID（在新窗口中打开）](https://deepmind.google/models/synthid/) 水印，并通过 [openai.com/verify](https://openai.com/verify) 和我们的 [Content Provenance API（在新窗口中打开）](https://developers.openai.com/api/docs/guides/content-provenance) 提供图像与音频验证。这些技术互为补充：Content Credentials 可以记录文件的来源与历史，而隐形水印能在元数据被移除时仍保留信号。

正如我们在[选举保障工作](https://openai.com/index/election-safeguards-2026/)中所述，溯源可以帮助人们和平台评估可能具有误导性的 AI 生成内容，包括深度伪造。我们将这些信号与政策、滥用检测、举报、调查和执法措施相结合，并与研究人员、标准组织、平台和公民社会合作，让溯源在整个更广泛的生态中发挥用处。

将溯源扩展到文本，必须考虑到文本极易被改写、翻译或编辑。正如我们在[六月](https://openai.com/index/supporting-eu-trustworthy-ai-ecosystem/)所讨论的，我们的做法必须反映当前技术的现实局限。我们将持续改进检测能力，研究水印在编辑与翻译下的存续情况，并探索更有意义地区分 AI 辅助与 AI 创作的方法。随着证据、标准和监管要求的发展，我们会调整自己的做法；当我们认为结果能够被负责任地解读时，会扩大检测器的访问范围。
