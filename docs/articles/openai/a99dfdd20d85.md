# Shield 帮助技术人员使用 OpenAI 移交遗留门户工作

借助 GPT‑6 Astra，Shield 的 Forge 平台中的 agent 能够浏览遗留门户，让技术人员专注于需要他们处理的问题。

对许多中小型企业而言，外包的 IT 服务提供商要处理各种事务，小到员工被锁在笔记本电脑之外，大到配置错误的防火墙导致整个办公室断网。

Shield 打造了 [Forge](https://shieldtp.com/forge)——一个面向 IT 服务提供商的 AI 操作系统。该平台将业务数据与客户上下文汇聚在一起，帮助服务商端到端地完成 IT 支持任务。这意味着其 agent 还需要能在技术人员每天使用的老旧门户中工作。借助 OpenAI 的 GPT‑6 Astra，Shield 现在可以把受支持的浏览器任务交给 agent，而不必让技术人员登录并手动完成。

> “唯一需要请来人工技术人员的时候，应该是需要他们的判断力，而不是因为访问受阻。”

—Mayank Jain，Shield 技术负责人

## 访问成为瓶颈

“如果客户被锁在电脑之外，或者遭遇钓鱼攻击，速度就是头等大事，”Jain 说，“无论你是要解决他们的问题，还是要升级给人工处理，都希望尽可能快地完成。”

在使用 GPT‑6 Astra 之前，Forge 的 agent 可能会卡在无法访问的系统中。客户那时只能等待技术人员来完成这一步。

Shield 曾用较早的模型尝试 computer use——即由 AI 模型读取屏幕、点击并输入。Jain 说，它们不够可靠，也不够快。“通常，没有 API 的系统都是些老式系统，界面也不太好看，连人用起来都很费劲，”Jain 说。

## 像技术人员一样工作的 agent

技术人员一天中的大部分时间都花在管理工单、设备和软件许可证的门户里。其中许多系统没有 API，因此 agent 需要像人一样浏览屏幕。

Forge 的 AI Engineer 把工作分配给 computer-use agent，由 GPT‑6 Astra 浏览界面以完成受支持的任务。技术人员决定它可以自主执行哪些操作，以及哪些环节需要他们审核或批准。

Shield 表示，这些浏览器工作流已经上线，在其各家 IT 服务商中每月运行数千次。电话、现场工作和远程桌面任务仍需人工参与。

“GPT‑6 Astra 让我们的 agent 能够真正承担技术人员的工作：登录那些可能没有 API 访问权限的门户和遗留网站，执行六个月前只有人类才能完成的任务，”Shield 技术负责人 Mayank Jain 说。

> “最让我震惊的是 GPT-6 Astra 在 computer use 上的自然程度。我们以前也见过模型执行 computer use，但你能明显看到它们在摸索如何浏览 UI 时磕磕绊绊。有了 GPT-6 Astra，感觉就像在看着一个人四处点击。”

—Mayank Jain，Shield 技术负责人

## 技术人员可以移交的更多工作

Jain 表示，在 computer-use 任务上，GPT‑6 Astra 平均比 Shield 此前使用的旧模型快 35-40%。他还说，在使用 AI 处理的工单上，客户满意度更高，而解决速度是关键因素。

Shield 报告称执行更快、失败更少、超时更少。其团队花在为 agent 撰写详细指令或帮它完成一项任务上的时间也更少了。

## 下一步

Shield 正在测试远程桌面工作流，让 agent 能够直接在计算机桌面上执行更复杂的操作。

Jain 说：“有了 GPT‑6 Astra，Forge 现在真正成了我们人工技术人员的延伸。”
