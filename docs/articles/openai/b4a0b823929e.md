# 借助 Q 系综实现 UCB 探索

Read paper

(opens in a new window)


## 摘要

我们展示如何利用一组 Q*-函数在深度强化学习中实现更有效的探索。我们建立在 bandit 场景中已成熟的算法之上，并将其适配到 Q-learning 场景。我们提出一种基于置信上界（UCB，Upper Confidence Bound）的探索策略。实验显示，我们在 Atari 基准上取得了显著提升。
