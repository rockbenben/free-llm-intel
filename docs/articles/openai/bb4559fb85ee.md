# 多智能体互动中涌现的工具使用

我们观察到，智能体在一个简单捉迷藏游戏中学会了逐渐复杂的工具使用。在我们全新的模拟捉迷藏环境中训练后，智能体建立起一系列六个截然不同的策略与反策略，其中一些连我们自己都不知道环境支持。这种简单环境中自监督的涌现复杂性进一步提示：多智能体协同进化终有一天可能产生极其复杂和智能的行为。

在我们的环境里，智能体进行团队制捉迷藏。躲藏方（蓝色）的任务是避开搜寻方（红色）的视线，搜寻方的任务是盯住躲藏方。环境中散布着可被抓取并锁定的物体，还有随机生成的不可移动房间与墙壁，智能体必须学会穿行其间。开局前，躲藏方有一段准备期，期间搜寻方被固定，给躲藏方逃跑或改造环境的机会。

环境对智能体与物体互动没有任何显式激励；唯一的监督来自捉迷藏目标本身。智能体获得团队奖励：若所有躲藏者都未被发现，躲藏方得 +1，任一躲藏者被看到则得 -1；搜寻方获得相反奖励——全部躲藏者被藏好为 -1，否则为 +1。为把智能体行为限制在合理范围内，如果跑出试验区太远会被罚分。准备阶段所有智能体得 0 分。

## 自动课程与涌现行为

随着智能体在捉迷藏中彼此对抗训练，**多达六个截然不同的策略涌现出来**。每个新策略都创造出此前不存在的压力，迫使智能体进化到下一阶段。注意：对智能体而言，与物体互动或探索都没有直接激励；下面展示的涌现策略，是多智能体竞争与捉迷藏简单动力学所诱发的[*自动课程*](https://arxiv.org/pdf/1903.00742.pdf)的结果。

## 训练捉迷藏智能体

我们使用与训练 [OpenAI Five](https://openai.com/index/openai-five/) 和 [Dactyl](https://openai.com/index/learning-dexterity/) 相同的训练基础设施与算法。但在我们的环境中，每个智能体独立行动，使用自己的观测与隐记忆状态。智能体使用以实体为中心的世界状态表示，该表示对物体与其他智能体是*置换不变*（permutation invariant）的。

每个物体先被嵌入，再经过一个带掩码的残差自注意力模块——类似于 [transformer](https://arxiv.org/pdf/1706.03762.pdf) 中使用的结构，只是注意力作用于物体而非时间。不在智能体视线前方或视线内的物体被掩蔽，智能体对其一无所知。

智能体策略用[自我对弈](https://openai.com/index/competitive-self-play/)和[近端策略优化](https://openai.com/index/openai-baselines-ppo/)训练。优化期间，智能体可以在其价值函数中使用关于被遮蔽物体和其他智能体的特权信息。

我们发现，大规模训练对智能体逐级走完各个涌现阶段至关重要。下面展示不同批量大小下，智能体到达阶段 4（坡道防御）所需的时间与回合数。我们发现，增大批量能大幅缩短收敛的墙钟时间，但在 32k 及以上对样本效率影响不大。然而，8k 和 16k 批量在限定的回合数内从未到达阶段 4。

## 多智能体竞争 vs. 内在动机

本工作展示了证据：智能体通过捉迷藏中的自监督自动课程学到了复杂策略与反策略。另一种无监督学习技能的方法是*内在动机*（intrinsic motivation）——用模型误差、状态计数等指标激励智能体探索。我们在环境中运行了基于计数的探索：智能体显式记录访问过的状态，并被激励前往鲜少访问的状态。这一设定下主要的建模选择是状态表示；例如，在第一个基线中我们只把 2-D 箱子位置纳入状态，于是智能体只被激励去把箱子推到新位置并与之互动。然后我们把它与另一个基于计数的策略做比较——后者使用捉迷藏智能体获得的完整状态。

由此可见，在捉迷藏中训练的智能体，其行为在质上围绕远更贴近人类可理解的活动（如构筑庇护所），而由内在动机驱动的智能体则看似漫无目的地搬动物体。此外，随着状态空间复杂性增加，我们发现内在动机方法与环境中物体的互动越来越失去意义。因此我们相信，随着环境在规模与复杂性上持续增长，多智能体竞争将是在无监督下生成与人类相关技能的、更可扩展的方法。

## 以迁移与微调作为评估

上一节我们定性比较了捉迷藏学到的行为与内在动机学到的行为。然而随着环境规模扩大，定性衡量进展会越来越难。在多智能体场景中，只追踪奖励是不够的评估指标——它无法明确指示智能体是在均衡进步还是停滞不前。ELO 或 TrueSkill 等指标能更可靠地衡量相对旧策略版本或群体中其他策略的表现是否在进步；但这些指标仍然无法说明：表现提升源自新适应，还是源自已学技能的精进。最后，使用环境特有统计量（如物体移动）也可能含糊（例如只追踪绝对移动量，无法说明智能体朝哪个方向移动），而且随着环境扩张，设计充分的指标将变得困难而昂贵。

我们提议使用一组针对"我们认为智能体终将获得的能力"的领域专用智力测试。在这些设定上的迁移表现，可以作为表示质量或技能的量化度量。我们把它与基于计数探索的预训练以及从零训练的基线做比较。

虽然捉迷藏智能体在许多迁移任务上表现更好，但它并未显著提升表现或收敛时间。从其行为看，我们知道它具备在捉迷藏中精确搬动物体构筑庇护所的潜在技能；但在样本数很少的训练下，它并不具备把该技能用于其他语境的能力。

我们认为迁移结果好坏参半的根源，在于智能体学到的技能表示彼此纠缠、难以微调。随着未来环境更多样、智能体必须在更多语境中使用技能，我们相信会看到更可泛化的技能表示，以及这一评估方法更强的信号。我们还开源了这些评估任务，作为衡量我们环境中学习进展的手段。

## 出人意料的行为

我们已经展示：智能体能够在高保真物理模拟器中习得精巧的工具使用；不过一路走来到达这个结果，吸取了许多教训。构建环境并不容易，而且智能体找到意料之外的方式利用你构建的环境或物理引擎，是常事。
