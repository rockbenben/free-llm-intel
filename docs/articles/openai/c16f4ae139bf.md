# TruthfulQA：衡量模型如何模仿人类的虚假说法

## 摘要

我们提出一个基准，用来衡量语言模型在生成问题答案时是否诚实。该基准包含 817 个问题，横跨 38 个类别，涵盖健康、法律、金融和政治。我们精心设计了一些问题，部分人会因错误的信念或误解而答错。要表现得好，模型必须避免生成那种从模仿人类文本中学来的错误答案。我们测试了 GPT-3、GPT-Neo/J、GPT-2 和一个基于 T5 的模型。最好的模型在 58% 的问题上是诚实的，而人类表现为 94%。模型生成了许多模仿流行误解、有可能欺骗人类的错误答案。越大的模型通常越不诚实。这与其他 NLP 任务形成对比——在那些任务里，性能随模型规模提升。然而，如果错误答案是从训练分布中学来的，这个结果其实在预料之中。我们建议：单靠扩大模型规模，在提升诚实度上不如用模仿之外的训练目标做微调有前途。
