# 关于通过元强化学习学会探索的若干思考

阅读论文



## 摘要

我们考虑元强化学习（meta reinforcement learning）中的探索问题。我们提出两种新的元强化学习算法：E-MAML 和 E-RL²。结果在我们新设计的"Krazy World"环境以及一组迷宫环境上给出。我们表明，在探索很重要的任务上，E-MAML 和 E-RL² 能带来更好的表现。
