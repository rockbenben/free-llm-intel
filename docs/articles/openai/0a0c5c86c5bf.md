# Codex 现已全面开放

$ npm i -g @openai/codex


我们宣布 Codex 正式上线，并推出三项新功能，使其对工程团队的实用性更上一层楼：

- **全新 Slack 集成：**直接在团队频道或对话线程中向 Codex 委派任务或提问，如同与同事协作般便捷。
- **Codex SDK：**将驱动 Codex CLI 的同款智能体嵌入您的工作流、工具和应用中，无需额外调优即可在 [GPT‑5‑Codex⁠](https://openai.com/index/introducing-upgrades-to-codex/) 上实现顶尖性能。
- **全新管理工具：**通过环境控制、监控和分析面板**，**ChatGPT 工作区管理员现在能够更清晰地掌控 Codex，实现大规模管理。

自 [Codex 云智能体⁠](https://openai.com/index/introducing-codex/)于 5 月推出研究预览版以来，Codex 已逐步发展成为更可靠、功能更强大的编码协作工具。现在您可在任何编码场景中使用它——无论是编辑器、终端还是云端，所有操作均通过您的 ChatGPT 帐户实现无缝连接。自 8 月初以来，Codex 日均使用量增长超过 10 倍，而 GPT‑5‑Codex 作为我们有史以来增长最快的模型之一，在发布后的三周内已处理超过 40 万亿个字符。

Codex 现已被全球开发人员广泛采用，用户涵盖 Duolingo、Vanta 等初创公司，以及思科、乐天 (Rakuten) 等大型企业。在 OpenAI 内部，它已成为我们构建流程的核心组成部分：如今几乎所有工程师都在使用 Codex，而今年 7 月时使用率仅略超半数。每周合并的拉取请求增加了 70%，且 Codex 会自动审核几乎所有 PR，在关键问题进入生产环境前及时发现。

Codex 的全面开放使用，既彰显了全球开发人员与团队对其的快速接纳，更印证了它正在深刻改变我们的开发模式。

## Codex 在 Slack 中的应用

在 Slack 频道或对话中标记 @Codex，它将自动从对话中收集所需背景信息，选择合适的环境，并通过链接返回 Codex 云端完成的任务。您可在此处合并修改、持续迭代，或将任务拉取至本地计算机继续处理。在[文档](http://developers.openai.com/codex/integrations/slack)中了解如何设置 Slack 集成。

## Codex SDK

GPT‑5‑Codex 专为 Codex 训练——特别是为驱动 Codex CLI 的开源智能体实现而设计。我们还优化了智能体实现方案，使其提示词、工具定义和智能体循环在 GPT‑5‑Codex 等模型上能更快、更精准地交付结果。

借助 Codex SDK，您只需几行代码即可将相同智能体集成到自有工程工作流和应用中。该 SDK 提供结构化输出以解析智能体回复，并内置背景信息管理功能以恢复会话。该 SDK 现已支持 TypeScript，更多语言版本即将推出。

## 新管理员功能

ChatGPT 管理员现在可以编辑或删除工作空间中的 Codex 云环境——例如，用于清除敏感信息或清理未使用的环境。他们还可通过 Codex CLI 和 IDE 扩展强制实施更安全的本地使用默认设置，例如通过托管配置定义覆盖规则，或监控 Codex 执行的操作。新增的分析面板可帮助管理员追踪 CLI、IDE 和网页端的使用情况，并评估 Codex 提供的代码审核质量。

在[管理员指南](https://developers.openai.com/codex/enterprise)中了解有关配置新控件的更多信息。

## Codex 实际应用案例

### 思科：代码审核速度提升 50%

在思科，工程师们正借助 Codex 加速复杂代码提交请求的审核流程，将审核时间缩短高达 50%。减少手动检查的时间投入，使他们能将更多精力倾注于具有变革意义的核心工作。Codex 通过同时审核人工编写的代码及其自身生成的代码，助力工程师维持高标准的同时，实现更快速、更具突破性的产品发布。

### Instacart：自动化代码清理

在 Instacart，Codex SDK 已与他们的后台编码智能体平台 Olive 集成。工程师只需单击一下，即可启动远程开发环境并完成端到端任务，同时利用 Codex 进行代码编辑和变更测试。Codex 能自动清理技术债务（如废弃代码和过期实验），从而提升代码质量并降低代码库延迟。它还能处理重复性强且已知变更，有效减少积压任务，显著提升工程效率。

## 可用性与定价更新

即日起，Slack 集成和 Codex SDK 将面向 ChatGPT Plus、Pro、Business、Edu 及Enterprise 套餐的开发人员开放，而全新管理员功能将面向 Business、Edu 及Enterprise 套餐用户提供。

自 10 月 20 日起，Codex 云任务也将计入您的 Codex 使用额度。了解各套餐 Codex 定价详情，请点击[此处](https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan)。
