# 现实世界中的垃圾邮件检测

我们造出了世界上第一个完全在仿真中训练、并部署到物理机器人上的"Spam 检测"AI。（Spam 这里是午餐肉罐头品牌，一语双关垃圾邮件。）

## 仿真到现实的迁移

深度学习驱动的机器人系统卡在数据采集上：仅训练感知系统就需要几十万张图像，成本极高。生成仿真数据倒是便宜，但仿真与现实的差距大到人们通常在转到真实世界时要把模型从头重训。

我们已经[证明⁠(opens in a new window)](https://arxiv.org/abs/1703.06907)，域随机化（domain randomization）——一个让在仿真图像上训练的检测器迁移到真实图像的既有思路——在杂乱场景中效果很好。方法很简单：在仿真场景中随机改变颜色、纹理、光照条件和相机设置。生成的数据集变化足够丰富，在其上训练的深度神经网络就能泛化到现实。

随机生成的场景。每一帧里都有 Spam 午餐肉，常常藏在干扰物中间。我们的 Spam 模型素材来自 YCB 数据集。

## 我们的实现

检测器是基于 [VGG16⁠(opens in a new window)](https://www.cs.toronto.edu/~frossard/post/vgg16/) 架构的神经网络，在仿真图像中预测 Spam 罐头的精确三维位置。尽管它只在仿真场景上训练过，得到的网络却能在真实图像中检测出 Spam——即使现场摆满了从未见过的"干扰物"、排列方式也随机。
