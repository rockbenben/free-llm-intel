# 推进国家科学的新时代


美国的领导地位始终由科学领导力驱动。推动经济增长、国家安全和更美好生活的技术——从能源、计算到医学、航空航天和先进制造——都始于发现、构建和部署的能力。

前沿AI可以拓展这种能力。它可以帮助将数十年的科学进步压缩到数年内完成，强化支撑美国创新的机构，并赋予研究人员解决曾被认为遥不可及的问题的新能力。

OpenAI 致力于将这些能力带给美国科学界。我们正与美国政府、国家实验室、大学和研究人员合作，将前沿模型与成就美国卓越科学的人才、超级计算机、模拟和设施连接起来。

我们的目标是帮助科学家探索更多想法、更快检验假设，并更迅速地从洞见走向经过验证的成果。这需要将前沿模型与研究环境中的工具、工作流程、专业知识和基础设施相结合，把AI从工具转变为国家战略科学基础设施。

## 我们的承诺

作为美国能源部 [Genesis Mission](http://energy.gov/genesis-mission) 的一部分，OpenAI 将通过广泛访问、前沿能力、技术协作和聚焦科学攻关来支持参与研究人员。我们将：

- 为国家实验室和大学约 2,000 名 Genesis 研究人员提供价值 400 万美元的 Codex 访问权限 ，将先进的编码和推理能力融入他们的日常工作。
- 投入 300 万美元的 API 支持，用于两项大型科学行动，以针对重大科学挑战测试前沿模型。
- 参与研究人员每支出 250 万美元，最高可获得 1,000 万美元的 API 使用额度，从而扩大 Genesis 研究人员能够支持的工作。
- 为从事符合条件的生物学项目的特定国家实验室研究人员提供 GPT‑Rosalind 专业生物科学能力的访问权限。
- 让可信赖的国家实验室负责人提前访问特定模型和功能，以便他们准备有效使用这些模型和功能所需的工作流程、评估和基础设施。
- 为特定国家实验室网络安全研究人员扩大对先进网络能力的可信访问，帮助他们加强防御研究并保护关键系统。

这些承诺建立在我们与国家实验室体系合作的基础之上。在与九个国家实验室共同举办的 [AI Jam Session](https://openai.com/global-affairs/1000-scientist-ai-jam-session/) 中，1,000 多名科学家在特定领域问题上测试了前沿模型，并提供了结构化反馈。

我们还在洛斯阿拉莫斯国家实验室的超级计算机 Venado 上[部署了先进推理模型](https://openai.com/index/us-department-of-energy-collaboration/)，作为国家核安全管理局各实验室的共享资源。这项工作探索了前沿推理如何与高性能计算结合，支持复杂研究。

在生物科学领域，[OpenAI 与洛斯阿拉莫斯开发了评估](https://openai.com/index/openai-and-los-alamos-national-laboratory-work-together/)，用于研究科学家如何在真实实验室环境中安全使用多模态AI系统。这项工作可以帮助研究人员了解，当能力日益增强的系统被纳入具有重大影响的科学工作时，会出现哪些机遇与风险。

## 支持 Genesis Mission

去年，我们启动了与[能源部 Genesis Mission 的正式合作](https://openai.com/index/us-department-of-energy-collaboration/)，该计划汇集了能源部、其 17 个国家实验室、大学和行业力量。Genesis 旨在将AI与联邦科学数据、先进计算、实验设施和专家团队相结合，并在十年内让美国研究与创新的生产力和影响力翻一番。

我们的支持将结合两种互补方式：一是广泛访问，让研究人员能够开发前沿模型的实际用途；二是为少数雄心勃勃的挑战集中投入资源。

首批大型行动计划包括：

- **高温超导体突破。**这项行动将结合前沿AI、模拟、材料专业知识和实验，探索能在更高温度和实用压力下工作的超导材料，有望为能源、交通、医学、科学仪器和国家安全等领域带来益处。
- **机器可触达前沿图谱。**这项行动将考察AI在哪些领域或许已经能够利用现有知识、数据和计算支持有意义的科学进展，帮助研究人员和政府区分哪些问题新近变得可处理，哪些仍需要来自物理世界的证据。

这些行动可以共同帮助建立可重复的方法，将AI应用于艰巨的国家科学挑战。

## 对国家科学事业的长期承诺

任何单一公司、实验室、大学或政府机构都无法独自实现这一机遇。

政府可以协调优先事项，并投资共享基础设施。实验室和大学可以界定重要问题，并维护科学标准。行业可以贡献前沿能力、工程专业知识和规模化部署。研究人员必须始终处于核心位置：界定问题、选择方法、质疑输出并验证结果。

美国一次又一次地将科学领导力转化为国家实力。前沿AI提供了重塑这一模式的机会——所建立的优势不依赖某个单一模型或一时领先，而是根植于一种更深层的国家能力，能够将前沿智能应用于重要问题。

OpenAI 致力于与科学家、国家实验室、大学和政府携手建设这种能力，并帮助将前沿AI转化为持续的科学和经济进步。
