电信运营商掌握着来自使用情况、计费、网络活动和位置的丰富客户信号，但仍难以及时将这些信号转化为个性化行动。Circles 看到了围绕这一挑战重塑电信体验的机会，并借助 OpenAI 构建 AI 原生电信技术栈，实时打通客户支持、个性化、运营和变现。

由此打造的客户体验以 Circles 的 AI 礼宾助手为核心，这一对话式界面由 OpenAI API 平台提供支持。在新加坡，Circles 的 AI 个性化功能帮助将每用户平均收入（ARPU）提高了 22%，并将客户流失率降低了 9%。作为 AI 礼宾助手背后的多智能体架构，CareX 如今可自主解决 65% 的客户支持问题。

Circles 创立于新加坡，是一家科技公司，其 SaaS 平台帮助数字电信运营商推出并运营由 AI 驱动的客户体验。该公司还在新加坡运营自有的消费者电信业务 Circles.Life。Circles 成立于 2014 年，与遍布六大洲 14 个国家的电信运营商合作。

## 构建 AI 礼宾助手

传统电信客户支持通常是被动响应式的。客户往往要在菜单间反复操作、重复提供信息，并在问题发生后等待协助。尽管运营商掌握着来自使用情况、计费、网络活动和位置的丰富客户数据，但如何及时将这些信号转化为个性化行动始终是一项挑战。为解决这一问题，Circles 基于 OpenAI API 构建了 AI 礼宾助手，打造出一个旨在提供主动式、情境感知型客户互动的对话界面。

AI 礼宾助手将搜索、账户管理、客户支持和个性化推荐整合为一体化体验。它能理解客户的实时情境，例如正在浏览漫游选项或查询账单问题，进而将请求转交给合适的专业智能体、推荐相关操作并解决问题，无需客户重复提供信息或辗转于多个流程。

> “AI 应当为用户赋能，而不是迫使他们适应过时的体验流程。OpenAI 在帮助 Circles 将这一愿景扩展至全球的过程中发挥了关键作用。借助 AI 礼宾助手，我们不再只是提供简单答案，而是交付现实成果；同时兼顾成本与延迟，为运营商和客户创造最大价值。”

—Awais Malik，Circles 全球首席增长官

## 使用 CareX 编排客户支持

CareX 是为 Circles AI 礼宾助手提供支持的专有多智能体架构。它将能够理解每位客户历史记录和当前活动的编排智能体，与分别负责计费、订阅、网络管理和账户服务的专业智能体相结合。

与传统聊天机器人不同，CareX 旨在理解客户请求、采取行动并解决问题。例如，当客户提出账单问题时，编排智能体会综合客户的应用情境、账户历史记录和具体请求，再将其转交给合适的专业智能体。该智能体只会收到解决问题所需的信息。如有需要，AI 智能体会将案例连同完整情境信息无缝转交给人工客服。

这一方法已经取得了可量化的成效。在一次早期部署中，一家运营商在第一周内就实现了 55% 的自主解决率。如今，在已支持的工作流中，CareX 无需人工干预即可自主解决 65% 的客户服务互动。

随着 CareX 扩展到实时语音支持，该平台的目标是在包括文本和语音在内的整个工作流中实现 95% 的自主解决率。这会将同样由 AI 驱动的问题解决能力延伸至许多客户优先使用的渠道，同时让服务更自然、更即时，也更易于使用。

## 使用 Xplore IQ 实现客户价值个性化

Xplore IQ 基于 OpenAI API 构建，是 Circles 由 AI 驱动的个性化引擎。它综合客户行为、账户历史记录和实时信号，确定最相关的下一步行动，包括推荐漫游套餐或升级资费方案，以及在客户流失发生前加以预防。

Xplore IQ 以高度个性化的推荐取代大范围营销活动，帮助运营商在恰当的时机与客户互动。在新加坡，Circles 通过比较收到 AI 推荐和未收到此类推荐的客户，衡量其影响。在 AI 推荐组中，更多客户升级资费方案并订阅附加服务，推动 ARPU 提高了 22%；及时且切合需求的推荐还帮助将客户流失率降低了 9%。

## 使用 Codex 提升工程效率

除了面向客户的 AI 产品，Circles 还在内部使用 Codex，提高工程、信息安全和事件管理团队的工作效率。各团队使用 Codex 加快设计、编码辅助和测试，同时仍由专业人员负责验证和最终审核。

通过应用于设计、编码辅助和单元测试，Codex 将开发效率提高了 29%，让工程师能够将时间投入到价值更高的产品创新中。

## 始终以治理为核心

为电信行业构建 AI，需要为客户和运营商双方设置保障措施。Circles 会在客户信息到达模型层之前实施自动控制，包括在将个人身份信息传递给大语言模型（LLM）之前识别并加密这些信息。专业智能体仅能在限定范围内访问完成特定问题解决任务所需的信息，而不能不受限制地访问完整的客户资料。

随着 AI 驱动的体验在电信环境中规模化，Circles 还通过人工转交路径、分阶段推出、速率限制、回滚机制和商业保障措施，帮助维持运营控制。

## 未来展望

Circles 正与 OpenAI 合作扩展其 AI 原生电信技术栈，包括增强 CareX 的可观测性并引入实时语音支持，让客户互动更自然、更便捷。从长远来看，该公司希望打造对话式、情境感知型电信体验，超越传统的应用导航方式，帮助运营商提供更主动、更个性化的客户互动。
