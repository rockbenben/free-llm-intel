# 瓦解一项伊朗隐蔽影响行动

我们封禁了与一项伊朗影响行动相关的账号，该行动利用 ChatGPT 生成围绕多个议题的内容，其中包括美国总统竞选。我们没有看到这些内容触达有意义受众的迹象。

OpenAI 致力于防止滥用并提升 AI 生成内容的透明度。这包括我们在检测和阻止 [隐蔽影响行动⁠](https://openai.com/index/disrupting-malicious-uses-of-ai-by-state-affiliated-threat-actors/)（IO）方面的工作——此类行动试图在隐藏幕后行为者真实身份或意图的同时操纵公众舆论或影响政治结果。在 2024 年多国举行选举的背景下，这一点尤为重要。我们全年都在扩展这一领域的工作，包括利用我们自己的 AI 模型来更好地检测和理解滥用行为。

本周，我们识别并下架了一批 ChatGPT 账号，它们正在为一条被认定为 [Storm-2035](https://cdn-dynmedia-1.microsoft.com/is/content/microsoftcorp/microsoft/final/en-us/microsoft-brand/documents/5bc57431-a7a9-49ad-944d-b93b7d35d0fc.pdf) 的伊朗隐蔽影响行动生成内容。我们已禁止这些账号使用我们的服务，并将持续监控任何进一步违反我们政策的企图。该行动利用 ChatGPT 生成了围绕一系列议题的内容——包括对美国大选中两侧候选人的评论——随后通过社交媒体账号和网站发布。

与我们 [五月报告⁠](https://openai.com/index/disrupting-malicious-uses-of-ai-by-state-affiliated-threat-actors/) 的隐蔽影响行动类似，该行动似乎也没有获得有意义的受众互动。我们识别出的绝大多数社交媒体帖子几乎没有或完全没有点赞、分享或评论。我们同样未发现这些网页文章在社交媒体上被转发的迹象。按照布鲁金斯学会的 [Breakout Scale](https://www.brookings.edu/articles/the-breakout-scale-measuring-the-impact-of-influence-operations/)（以 1（最低）到 6（最高）的量表评估隐蔽 IO 的影响），该行动处于第 2 类的低端（在多个平台活动，但没有证据表明真实人群转载或其内容被广泛传播）。我们的调查受益于微软 [上周发布的](https://blogs.microsoft.com/on-the-issues/2024-08-08/iran-targeting-2024-us-election/) 关于该行动的信息。

我们的调查显示，该行动将 ChatGPT 用于两个目的：生成长篇文章和较短的社交媒体评论。第一条工作线产出关于美国政治和全球事件的文章，发布在五个伪装成进步派和保守派新闻媒体的网站上。第二条工作线创作英文和西班牙文的短评论，发布在社交媒体上。我们识别出 X 平台上的十几个账号和 Instagram 上的一个账号参与了该行动。其中一些 X 账号伪装成进步派，另一些伪装成保守派。他们生成部分评论的方式，是要求我们的模型改写其他社交媒体用户发布的评论。

该行动围绕若干主题生成内容：主要是加沙冲突、以色列参加奥运会、美国总统大选——较小程度上涉及委内瑞拉政治、美国拉丁裔社群的权利（以西班牙语和英语），以及苏格兰独立。他们在政治内容之间穿插关于时尚和美容的评论，可能是为了显得更真实，或试图积累粉丝。

尽管该行动并未带来有意义的受众互动，我们仍然严肃对待任何企图将我们的服务用于外国影响行动的行为。因此，在把这些账号移出我们的服务之后，作为支持更广泛社群瓦解此类活动的工作的一部分，我们与政府、竞选阵营和行业利益相关方分享了威胁情报。OpenAI 将继续致力于通过与行业、公民社会和政府合作，并利用生成式 AI 的力量为我们的工作提供乘数效应，从而大规模发现和缓解此类滥用。我们将继续发布此类发现，以促进信息共享和最佳实践。

*该行动生成并发布在其两个网站上的两篇文章标题。我们没有看到这些文章在社交媒体上被广泛分享的证据。*

*该行动生成的关于美国选举候选人的帖子，由 X 上两个不同账号发布。这些帖子互动量很低或没有互动。*

*该行动用英语和西班牙语生成的关于美容的帖子，由 X 上两个不同账号发布。我们把这些图片送入了我们的 *[*DALL·E 3 分类器⁠*](https://openai.com/index/understanding-the-source-of-what-we-see-and-hear-online/)*，其判定这些图片并非由我们的服务生成。这些帖子互动量很低或没有互动。*
