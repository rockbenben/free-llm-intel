# “星际之门”(Stargate) 项目正式启动


“星际之门”项目是一家新公司，打算在未来四年内投资 5,000 亿美元，为 OpenAI 在美国建设新一代人工智能基础设施。我们将立即开始投入 1,000 亿美元。这一基础设施将确保美国在人工智能领域的领先地位，为美国创造数十万个就业机会，并为全世界带来巨大的经济效益。该项目不仅将支持美国的再工业化，还将为保护美国及其盟国的国家安全提供战略能力。

“星际之门”的初始股权投资人包括软银、OpenAI、甲骨文和 MGX。软银和 OpenAI 是“星际之门”的主要合作伙伴，软银负责财务，OpenAI 负责运营。孙正义将担任董事长。

Arm、微软、英伟达、甲骨文和 OpenAI 是最初的主要技术合作伙伴。目前，从德克萨斯州开始的建设工作正在进行中，随着最终协议的敲定，我们正在评估全国范围内更多园区的潜在选址。

作为“星际之门”的一部分，甲骨文、英伟达和 OpenAI 将密切合作，共同构建和运营这一计算系统。这延续了 OpenAI 与英伟达自 2016 年起的长期合作，以及 OpenAI 与甲骨文的新近伙伴关系。

这也是建立在 OpenAI 与微软现有合作关系的基础上。OpenAI 将继续增加对 Azure 的使用，同时继续与微软合作，利用额外的计算能力来训练领先的模型并提供出色的产品和服务。

我们所有人都期待着继续建设和发展人工智能，特别是 AGI，以造福全人类。我们相信，在这条道路上，新的一步至关重要，它将使有创造力的人们能够想出如何利用人工智能来提升人类。

我们希望与[整个数据中心基础设施建设领域](https://openai.com/form/stargate-infrastructure/)的**公司建立联系**，从电力、土地、建筑到设备，以及中间的所有环节。

***2025 年 1 月 31 日更新****：有关我们的计划和优先事项的更多详情，感兴趣的潜在合作伙伴可以查看我们针对土地和电力的*[*招标书 (RFP)*](https://cdn.openai.com/sg/stargate-request-for-proposal-rfp.pdf)*，或我们针对建筑/工程公司的场地设计服务的*[*资格要求书 (RFQ)*](https://cdn.openai.com/sg/stargate-request-for-qualification-rfq.pdf)*。*
