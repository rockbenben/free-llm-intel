# OpenAI o3 与 o4-mini 系统卡附录：Codex

Codex 是一个云端编程 agent。Codex 由 codex-1 驱动——codex-1 是为软件工程优化的 OpenAI o3 版本。codex-1 通过在多种环境的真实编码任务上进行强化学习训练，生成与人类风格和 PR 偏好高度贴近的代码，严格遵循指令，并迭代运行测试直至通过。

用户可以要求 Codex 执行编码任务，或回答关于代码库的问题。每个 agent 都在各自的云容器中运行，且无互联网访问。容器预先装载用户的代码以及由用户定义的开发环境，包括用户指定的任何依赖、配置或工具。完成设置后，互联网访问被禁用，模型的执行轨迹开始运行。在该环境中，Codex 可以读取和编辑文件，并执行命令，包括测试、linter 和类型检查器。

Codex 经过训练，会通过引用终端日志和文件为其操作提供可验证的证据，让用户能够校验模型的工作。任务完成后，用户可以检查结果、请求进一步完善，或导出生成的 diff——既可以将其转换为 GitHub pull request，也可以复制下来用于本地测试与开发。
