# OpenAI 的支持者

我们很高兴欢迎新捐赠者加入 OpenAI。

Illustration: Justin Jay Wang × DALL·E

Loading…

我们很高兴欢迎以下新捐赠者加入 OpenAI：[Jed McCaleb⁠(opens in a new window)](https://www.stellar.org/about/jed-mccaleb/)、[Gabe Newell⁠(opens in a new window)](http://www.valvesoftware.com/company/people.html)、[Michael Seibel⁠(opens in a new window)](http://www.michaelseibel.com/)、[Jaan Tallinn⁠(opens in a new window)](https://www.cser.ac.uk/team/jaan-tallinn/)，以及 [Ashton Eaton⁠(opens in a new window)](https://en.wikipedia.org/wiki/Ashton_Eaton) 和 [Brianne Theisen-Eaton⁠(opens in a new window)](https://en.wikipedia.org/wiki/Brianne_Theisen-Eaton)。[Reid Hoffman⁠(opens in a new window)](https://twitter.com/reidhoffman) 正在大幅增加他的贡献。[Pieter Abbeel⁠(opens in a new window)](https://people.eecs.berkeley.edu/~pabbeel/)（已在我们这里完成学术休假）、[Julia Galef⁠(opens in a new window)](https://juliagalef.com/) 和 [Maran Nelson⁠(opens in a new window)](https://twitter.com/marannelson) 正在成为 OpenAI 的顾问。另外，Elon Musk 将离开 OpenAI 董事会，但会继续向组织捐赠并提供建议。随着 Tesla 越来越专注于 AI，这也消除了 Elon 未来潜在的冲突。

我们正在扩大资助者基础，为 OpenAI 的下一阶段做准备。下一阶段将加大对人才的投入，以及做出人工智能重大突破所需的算力资源。OpenAI 成立于两年多前，自那以来，我们把[研究工作⁠](https://openai.com/news/research/) 与应用工作相结合，通过[机器人⁠](https://openai.com/index/robots-that-learn/) 和 [Dota⁠](https://openai.com/index/more-on-dota-2/) 方面的工作拓展 AI 系统能力的边界。这会继续下去，同时在未来几个月里，大家还可以期待我们阐明迎接 OpenAI 下一阶段所依据的原则，以及我们希望推动变革、确保 AI 造福全人类的政策领域。

董事会现由 Greg Brockman、Ilya Sutskever、Holden Karnofsky 和 Sam Altman 组成。我们很快会增设一位董事，并计划逐步扩充董事会。如果你想在这一使命上与我们共事，欢迎[加入 OpenAI⁠](https://openai.com/careers/)。
