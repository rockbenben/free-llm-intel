# 用 AI 强化 NATO 及盟国的网络防御

各国政府和国家网络机构保护着人们、公共服务和经济所依赖的系统。通过 Daybreak，我们把先进的 AI 交到可信的防御方手中，用于经授权的安全工作——从审查软件、调查可疑活动，到验证漏洞、开发和测试修复方案。

## 强化 NATO 的网络防御

OpenAI 与 NATO 通信与信息局（NCIA）合作，为 NATO 的核心机构提供先进网络安全模型的访问权限，帮助保护盟国网络。作为这项工作的一部分，NATO 每月使用的原始输入与输出 token 高达 3000 亿。

NATO 对 OpenAI 工具的早期使用表明，有能力的网络防御者可以把前沿模型投入实际工作，支持 NATO 维护成员国自由与安全的使命。这同时也有助于提升负责昼夜守护盟国网络的多国团队的网络安全专业能力，并积累可供欧洲乃至整个联盟防御者借鉴的经验。

OpenAI 还[支持](https://ccdcoe.org/news/2026/exercise-crossed-swords-tests-cyber-operations-and-multi-domain-coordination/)了 2026 年的 Crossed Swords 演习。该演习由 NATO 合作网络防御卓越中心（CCDCOE）组织，新增了一条训练线：参与者在技术环境中使用 OpenAI Daybreak，构建、部署并评估用于网络行动的 AI agent。这项训练让参与者以操作员身份与 AI agent 并肩工作，并强调要保持人工监督。

OpenAI 始终全面恪守 NATO 关于负责任采用 AI 的原则，并致力于交付安全可靠的解决方案。

> “AI 驱动的网络防御模型代表着网络安全领域的一次代际跃升。它们加快漏洞发现、以机器速度探测新兴威胁，让防御方得以领先于对手。对 NATO 来说，这些技术增强了我们的网络韧性，提升了作战优势，也强化了我们以空前的规模和速度保护关键数字基础设施的能力。随着采用规模扩大，我们将更深入地理解 token 消耗、使用模式以及 AI 模型的底层经济性。这些认识将帮助我们优化成本、评估相互竞争的方案，并做出有理有据的采购决策。”

—Dr Dylan Browne，NCIA 局长

> “捍卫我们民主制度的人，应该拥有最先进的技术站在他们这一边。NATO 的网络防御者守护着对联盟安全至关重要的网络。通过 Daybreak，我们把更有能力的工具交到他们手中，帮助他们在攻击者加以利用之前发现并修复漏洞。我们期待与 NATO 及各盟国深化这项合作，把 AI 的进步转化为更强的网络防御。”

—Sasha Baker，OpenAI 国家安全政策负责人

## 支持盟国政府

在 NATO 之外，我们已经向欧洲的防御方开放了网络模型的使用权限，包括 EU 的 ENISA，以及法国（ANSSI）、德国和波兰的国家网络机构。

- **乌克兰数字转型部** 正在[使用](https://openai.com/index/openai-extends-cyber-access-to-ukraine-for-civilian-defense/) OpenAI 的 Daybreak 工具加强民用基础设施的网络防御。该计划旨在帮助乌克兰团队更快地发现软件漏洞、开发和测试修复方案，支持那些在持续网络攻击中守护关键服务的防御者。
- **EU 的网络机构 ENISA** 使用我们的模型，在 EU 各机构普遍使用的软件中发现了四个漏洞，四个漏洞的修复均已发布（[1](https://www.cve.org/CVERecord?id=CVE-2026-73432),[https://www.cve.org/CVERecord?id=CVE-2026-73431](https://www.cve.org/CVERecord?id=CVE-2026-73431)[2](https://www.cve.org/CVERecord?id=CVE-2026-73431),[https://www.cve.org/CVERecord?id=CVE-2026-73405](https://www.cve.org/CVERecord?id=CVE-2026-73405)[3](https://www.cve.org/CVERecord?id=CVE-2026-73405),[https://www.cve.org/CVERecord?id=CVE-2026-73374](https://www.cve.org/CVERecord?id=CVE-2026-73374)[4](https://www.cve.org/CVERecord?id=CVE-2026-73374)）。一份 11 月的[https://www.enisa.europa.eu/sites/default/files/2026-11/ENISA_CERTEU_JOINTREPORT_Final.pdf](https://www.enisa.europa.eu/sites/default/files/2026-11/ENISA_CERTEU_JOINTREPORT_Final.pdf)[ENISA 与 CERT-EU 联合报告](https://www.enisa.europa.eu/sites/default/files/2026-11/ENISA_CERTEU_JOINTREPORT_Final.pdf)还描述了针对 27 个软件项目的审查，这些项目使用了前沿模型（包括通过 Daybreak 访问的 OpenAI 模型）以及 Codex 安全插件等工具。在测试过的模型中，由软件维护者评估的 88 个潜在问题里有 95% 被确认为真实问题，这体现出把 AI 与人的专业能力结合起来所具有的价值。
- **CERT Polska** 使用 OpenAI 模型协助发现 [MikroTik RouterOS 中的六个漏洞](https://cert.pl/en/posts/2026/09/vulnerabilities-in-mikrotik-routeros-actively-exploited/#Research-supported-by-LLMs)，并与厂商协调披露。研究人员主导了这项工作，在真实系统上测试发现结果并验证其影响，AI 则加快了分析和潜在漏洞的探索。MikroTik 发布了修复，CERT Polska 确认这些修复能阻止其观察到的攻击，为网络运维方提供了一种保护受影响设备的具体办法。

我们将继续与各国政府、国家网络机构和国际伙伴合作，把前沿 AI 能力转化为更强大、更安全、更有韧性的系统，帮助防御方发现弱点、更快修复，并保护人们日常依赖的服务。
