# 好奇心驱动学习的大规模研究

## 摘要

强化学习算法依赖于精心设计的环境奖励，而这些奖励对 agent 而言是外在的。然而，为每个环境手工设计密集奖励并逐一标注并不可扩展，这催生了对 agent 内在奖励函数的需求。好奇心是一类以内在使用预测误差作为奖励信号的内在奖励函数。在本文中：(a) 我们首次对纯好奇心驱动的学习（即完全没有任何外在奖励）进行大规模研究，覆盖 54 个标准基准环境，包括 Atari 游戏套件。结果显示出惊人的良好表现，且好奇心内在目标与许多游戏环境手工设计的外在奖励之间高度一致。(b) 我们研究了用不同特征空间计算预测误差的影响，表明随机特征对许多流行的 RL 游戏基准已经足够，但学习得到的特征似乎泛化更好（例如在《超级马里奥兄弟》的新关卡上）。(c) 我们指出了基于预测的奖励在随机性环境中的局限。游戏视频与代码见 [此链接⁠（在新窗口中打开）](https://pathak22.github.io/large-scale-curiosity/)。
