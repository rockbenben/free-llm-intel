# OpenAI 与卫报传媒集团启动内容合作

ChatGPT 用户现在将能获取来自《卫报》的新闻报道。

加载中……

OpenAI 与卫报传媒集团（Guardian Media Group）今日宣布一项战略合作，将把《卫报》编辑内容中更高质量的新闻报道带到 ChatGPT 的全球用户面前。

借助这一合作，ChatGPT 每周 3 亿的全球用户将能直接访问《卫报》可信的报道，并获得扩展摘要。此举旨在拓宽《卫报》的传播范围，把它的新闻与全球感兴趣受众连接起来。

内容出现时会附上指向《卫报》的署名，以提供透明度并给出获取信息的链接。

《卫报》还将在整个公司范围内推广 ChatGPT Enterprise，目标是为读者和业务运营开发新产品、新功能和新工具。

卫报传媒集团是 theguardian.com 的出版方——它是全球最大的英语优质新闻网站之一——同时也出版《卫报》报纸，该报两个多世纪前以《曼彻斯特卫报》（Manchester Guardian）之名创办。

今天的公告距《卫报》发布其[对 AI 的态度⁠（在新窗口打开）](https://www.theguardian.com/help/insideguardian/2023/jun/16/the-guardians-approach-to-generative-ai)正好一年，那份声明聚焦于确保其对生成式 AI 的使用处于人类监督之下，并服务于读者、业务及其更广泛的使命。

卫报传媒集团首席财务与运营官 Keith Underwood 表示："这次与 OpenAI 的新合作，体现了我们屡获殊荣的新闻报道背后的知识产权与价值，把我们的传播力和影响力拓展到新受众和创新平台服务。"

OpenAI 首席运营官 Brad Lightcap 说："我们与卫报传媒集团的合作，推进了我们支持世界级新闻业的目标，并通过提供相关、及时的内容访问来丰富 ChatGPT 体验。这是我们帮助出版人和受众从先进 AI 技术中受益的整体战略的一部分。"
