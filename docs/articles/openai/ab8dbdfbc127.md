# 2019 OpenAI 机器人研讨会

我们于 2019 年 4 月 27 日举办了首届 OpenAI 机器人研讨会。

Photo: Blake Tucker


会学习的机器人是一条激动人心的前进路径，但在如何推进上存在不同的方法和观点。本次活动把机器人学与机器学习社区、学界与业界领袖汇聚在一起，搭建一个交流平台，交换想法、回应构建复杂机器人系统中尚未解决的问题。

## 为什么办这个活动？

[会学习的机器人⁠](https://openai.com/index/robots-that-learn/) 是一种将让机器人融入我们日常生活的进展。虽然我们对其实现路径有一些想法，但我们认为与其他组织和学科的人交换并讨论想法同样重要。打造这样的机器人本质上是一项跨学科工作——不仅需要技术能力，也需要更深的理解，以便这些机器人能够被安全部署、并在现实世界中与人类互动。

## 参与者

我们在办公室接待了约 80 位外部参会者，另有约 200 人通过全天直播远程加入。除了来自 Google、Facebook、NVIDIA 等业界实验室的参与者，还有来自 [斯坦福⁠(opens in a new window)](https://www.stanford.edu/)、[加州大学伯克利分校⁠(opens in a new window)](https://www.berkeley.edu/)、[CMU⁠(opens in a new window)](https://www.cmu.edu/) 和 [MIT⁠(opens in a new window)](http://www.mit.edu/) 等高校的学生、博士后与教授。参会者中也不乏爱好者、艺术家、机器人学家和机器学习研究者。

## 下一步

我们对本次活动的成果极为满意——这是一场实验性质的形式，而我们的预期被大大超出。白天的演讲在我们团队内部引发了有趣的讨论，带来了一些新的想法（例如自监督）和视角（例如传统机器人 vs 深度学习机器人）。和参会者与讲者交流后，可以明显感到每个人都从本次活动获益，并带着一种共识离开：解决同一批问题的方法其实非常多元。基于这些反馈，我们计划在未来重复这一形式，可能办成年度研讨会。后续活动的详情我们会择期公布。

如果你也想参与我们"会学习的机器人"方向的研究，欢迎联系我们！[我们正在招人⁠](https://openai.com/careers/)。
