# 集体对齐：就我们的 Model Spec 征集公众意见

我们在全球调查了 1,000 多人，了解他们希望我们的模型如何行为，并把他们的观点与我们的 Model Spec 做对比。我们的大众与规范总体一致，而我们采纳了分歧中暴露出的修改。

没有任何单个人或机构应该为所有人定义理想的 AI 该如何行为。

要履行"确保 AGI 造福全人类"的使命，OpenAI 需要构建能够反映我们所服务的所有人多元价值观与优先事项的系统。我们通过多种方式做到这一点，包括外部反馈表、专家意见和全球倾听会。另一种方式是"集体对齐"（collective alignment）——一项汇集关于模型应如何行为的各种视角的研究工作。AI 系统应遵循哪些价值观，这个问题很复杂，我们并没有全部答案，在主观、有争议或高风险的情境下尤其如此。随着 AI 能力越来越强、越来越深地融入人们的生活，它们的默认行为——以及个性化的边界——应当反映广泛的视角与价值观，这一点至关重要。

大概永远不存在让所有人都满意的单一 AI 行为集合。这也是我们投入个性化和自定义人格的原因。但模型的默认值威力巨大，我们希望听取公众意见来共同塑造它们。

今天，我们分享作为集体对齐研究方向一部分所采取的几步早期行动。我们收集了全球 1,000 多人的输入，将其转化为可执行的指南，并经过内部评审更新了我们的 [Model Spec](https://openai.com/index/sharing-the-latest-model-spec/)。在许多情况下，参与者的偏好与现行 Model Spec 一致。在另一些情况下，分歧暴露了可以澄清的措辞，或被转化为提案送交内部评审。我们采纳了一些改动，把另一些推迟到后续工作，还有一些基于原则或可行性原因未予采纳。最后，我们把[公开输入数据集分享到 HuggingFace](https://huggingface.co/datasets/openai/collective-alignment-1)，供 AI 研究生态在此方向上开展后续工作。这里附上数据集中的若干样例：

## Model Spec 的改动

今天的工作聚焦于在人群中共享的偏好。我们从人群反馈中识别出两类提案：一类是"澄清"（即参与者期望的行为与 Model Spec 既有原则一致，只是现行文本的表述留下了解读空间）；另一类是"原则变更"（即参与者期望的行为与 Model Spec 中的原则不一致）。虽然公众意见在指令层级的各层都很有价值，但越往上层（尤其是平台层），改动被采纳的可能性越低。

在下文详述的数据收集过程中，参与者审阅的是合成的提示词与回复示例，而不是直接审阅 Spec 文档本身。每名参与者按自己的偏好对某个提示词的四种可能回复排序。为了把他们的隐式偏好与我们明示的原则做比较，我们构建了 Model Spec Ranker（MSR）：一个推理模型，按照给定 Spec 对参与者排过的同一提示词的四种回复也进行排序。

Model Spec Ranker 有局限。由于推理模型并非完美的规则执行者，而 Spec 本身天然欠规定，排序所用的基座模型不同，解读偏差就会不同。尽管 Model Spec Ranker 被提示只需"应用 Spec"，它此前在人类偏好相关数据上训练过，这很可能影响它对预期行为的解读。例如，考虑 Model Spec 中的这句话："模型通常应满足意见谱上任何立场的请求。"这句话可以有多种解读，实践中会导致不同的排序。

总体而言，我们发现在使用 GPT-5 Thinking 时，人群观点与 Model Spec Ranker 的排序大体一致。平均而言，人们约 80% 的情况下与 Model Spec Ranker 意见一致。具体地说，我们在诚实与谦逊原则（[表达不确定性](https://model-spec.openai.com/2025-04-11.html#express_uncertainty)、[避免越位](https://model-spec.openai.com/2025-04-11.html#avoid_overstepping)）、[公平](https://model-spec.openai.com/2025-04-11.html#uphold_fairness)和[客观](https://model-spec.openai.com/2025-04-11.html#assume_objective_pov)上观察到高度一致（图 1）。出现分歧的地方，集中在"言论边界"上——政治内容、色情或血腥内容，以及对伪科学或阴谋论的批评。

*图 1：我们用 GPT-5 Thinking 在 1–5 的量表上为数据集中每段对话与 Spec 某章节的相关度打分，并在相关度为 5 的样本上计算章节层面的一致率（误差线为自助法 95% 置信区间）。*

### 已采纳的拟议改动

利用收集到的意见，我们将更新 Spec。这些改动将随下一版 Model Spec 很快发布。

### 未采纳的拟议改动

虽然人群偏好与 Spec 之间的部分分歧带来了澄清或更新，另一些分歧则提出了让我们现阶段无法采纳的现实挑战。有两个领域格外突出：

- [定制化的政治内容](https://model-spec.openai.com/2025-04-11.html#avoid_targeted_political_manipulation)：许多参与者支持生成更定制化的政治内容。我们未采纳这一改动，鉴于大规模个性化政治定向的风险以及我们在该领域的审慎立场。无法确定参与者在反馈时是否考虑过这些风险。
- [面向自愿成年人的情色内容](https://model-spec.openai.com/2025-04-11.html#no_erotica_or_gore)：相当大比例的人群支持放开情色内容。虽然这与我们此前意图的立场一致，但我们还有更多研究与产品工作要做，才能以正确方式部署它，因此这里未采纳任何改动。

## 我们做了什么

### 收集外部反馈

我们招募了约 1,000 名参与者，审阅价值观敏感领域中的模型行为。参与者居住在 19 个国家（原籍超过 50 个），符合英文阅读准入条件，并可用母语书写理由。约三分之一居住在美国，其余来自墨西哥、南非、荷兰、智利、英国、印度、肯尼亚、日本等。作为首次试验，参与者池在年龄、性别、种族、教育和 AI 使用上覆盖了广泛分布的视角。下方的参与者汇总统计可供查阅。

我们没有要求参与者通读整份 Spec 并评论，而是请他们审阅与 Spec 相关的、我们预先挑选的提示词和回复。这些提示词偏向"理想模型行为可能主观"的场景。这让我们有机会了解参与者在许多具体示例上的细致推理，并可与我们的原则、我们的理由以及 Model Spec Ranker 的解释做对比。对这些提示词的回复是这样生成的：生成 3 条涵盖不同现实观点的回复（关于如何作答最优），另用 GPT-4o 添加 1 条。对每个提示词，参与者看到 4 条候选回复，进行排序、解释选择、给预先写好的评分细则打分，并撰写自己的评分细则（图 2）。参与者至少审阅 5 个、至多 20 个提示词。

*图 2：参与者对理想行为可能具有主观性的模型回复进行排序。我们把他们的排序、理由和评分条项转化为 Model Spec 的修改提案。*

### 提出 Model Spec 修改提案

#### 从数据中推断规则

我们考察了把参与者反馈转化为具体 Model Spec 提案的方式，测试了两种互补路径，聚焦参与者观点与基于现行 Spec 的 Model Spec Ranker 输出之间最大的差距。

- 全自动回路。一个推理模型检查来自排序和理由的分歧区域，提出能改善其与参与者一致性的 Spec 修改，并用 Model Spec Ranker 检验提案，筛选出能提升与人群排序一致度的那些。
- 人类优先回路。研究者在整体审阅人类偏好后提出 Spec 更新。我们用一个推理模型判断人群的书面理由对每项改动意图是支持、反驳还是未置可否，以此验证提案。

两种路径各有取舍。人类优先回路允许全自动回路无法稳定复现的创造性思考与推理。例如，在某段具体对话中，人类优先回路能推断出"人群会看重对间接自杀意图的回应"，而 AI 优先方法漏掉了这种微妙之处。同时，人类优先回路的扩展性不如全自动回路，随着我们倾听的人数增加将难以为继。

在全自动回路中，我们尝试了两种与 Spec 相关的提案算法。两者都负责识别参与者排序与 MSR 排序之间的分歧模式：一个版本把大批量对话提供给推理模型，另一个版本一次只扫描一段对话。后者让模型能对更具体或更微妙的问题深入思考，而大批量输入则擅长发现跨对话的更宏观模式。实践中，我们发现两种方法产出的提案大量重叠。重要的是，自动回路锚定在 ranker 对 Spec 的解读上，因此结果会随所用基座模型而变化。

人类优先与全自动回路都有局限。判断对话层面的理由是否支持更通用的 Spec 更新，并非精确科学。要得到真值，需要回头直接向人类询问对拟议改动本身、以及它对模型行为的下游影响的看法。

#### 从拟议规则到实践中的改动

从观察到的偏好走到实践中的 Spec 改动，还包括经过 OpenAI 的内部评审流程。评审中的权衡把人群偏好与正在进行的产品或行为改动、我们的安全政策，以及数据集中无法直接观察的风险放在一起考量——例如宽松规则是否会使平台上的大规模操纵成为可能、模型能否可靠推断用户意图、以及实际部署约束。此外，我们的研究设计揭示的是个体在具体提示词上的偏好，未必考虑影响现行 Model Spec 政策的更广泛社会因素（例如大规模定向政治说服的可能）。因此，在做出更具后果性的改动之前，需要更多的审议和专家意见。

在这些讨论中，研究团队手动迭代提案，同时紧贴内部评审，寻找让 Spec 反映已识别偏好的最佳方式。

Spec 更新提案与验证是活跃的研究领域，本质上是一个充满噪声的社会技术过程的一部分。我们相信我们的方法让 Spec 更接近公众偏好，但仍有大量工作要做。这是端到端集体对齐流程的第一次迭代，未来工作将聚焦于扩展并改进引出、分析、验证与治理的每个阶段。随着未来规模化，我们期待与公众的对齐不断改善。

### 局限

这是一项早期实验，带有明显的局限：

- **样本量与提示词：** 我们为征集意见预先挑选的提示词塑造了反馈内容；参与者池虽然多样，但相对全球人口仍然很小。此外，英文阅读要求及其他准入标准引入了选择偏差。
- **Model Spec Ranker：** 归根结底，这项研究需要判定 Spec 如何适用于各条回复，而 Spec 天然欠规定，无偏或客观的判定并不可行。准确衡量这类 ranker 的性能仍是关键工作。未来研究应检验结果如何随不同基座模型变化，以及某些解读是否更契合特定视角。
- **Spec 解读：** 在内部评审阶段，我们能获得"金标准"的意图解读，但这类反馈无法扩展到规则提案阶段——那里需要数十万条回复排序。
- **正当性关切：** 我们这项工作的一个核心目标，是提升我们塑造模型行为方式的正当性。一个大量环节自动化的端到端更新流程，正当性可能不足，因为这些自动环节对人不那么透明易懂。
- **最终提案的解读：** 我们没有就最终的 model spec 提案直接向参与者验证，因此我们的解读未必完全契合其意图。
- **人群内部的分歧：** 我们知道参与者之间的分歧很重要，它们揭示了任何单一默认值都无法让[所有人](https://openai.com/global-affairs/the-power-of-personalized-ai/)满意的价值权衡与文化鸿沟。这正是我们期待在未来研究中探索的。
- **基线比较：** 基线模型回复生成于我们的[安全续写（safe-completions）工作](https://openai.com/index/gpt-5-safe-completions/)之前，因此不反映我们最新的模型行为。
- **成对偏好、反思与权衡：** 参与者孤立地评判行为差异，而不权衡原则之间的取舍（例如只考虑情色内容而不考虑儿童安全或情感依赖）。我们的方法也尚未捕捉原则在实践中如何互动、如何随时间变化。要改进这一点，需要纳入更多上下文、给予更多审议时间的更深引出方法。

## 结论

我们考察了公众偏好与我们 Model Spec 的一致程度，发现既有一致的领域，也有分歧的领域。这项研究与我们的[个性化投入](https://openai.com/index/memory-and-new-controls-for-chatgpt/)以及[让模型在安全边界内更有帮助](https://openai.com/index/gpt-5-safe-completions/)的工作互补。虽然今天的样本量天然限制了研究，我们很兴奋能把集体对齐扩展到更多人、更多视角。此外，尽管今天的工作只更新了一组默认值，它也指向了未来可定义多组默认值、分别反映不同视角与价值体系的研究方向。

当人们使用我们的模型时，默认值和边界很重要。集体对齐帮助我们理解默认值和边界给人什么感受、是否与人类价值的多样性一致。通过公开分享我们的方法、数据集以及我们推导和考量过的改动，我们希望邀请社区参与，为 AI 研究生态中构建"反映人类价值多样性"的系统做出更大贡献。我们经此过程采纳的更新将很快写入 Model Spec。
