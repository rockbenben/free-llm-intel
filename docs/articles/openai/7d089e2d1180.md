# 指令层级：训练 LLM 优先遵循特权指令

## 摘要

今天的 LLM 容易受到 prompt 注入、jailbreak 及其他攻击，让攻击者能用他们自己的恶意 prompt 覆盖模型的原始指令。在本工作中，我们提出，这类攻击背后的主要漏洞之一，是 LLM 常把 system prompt（例如来自应用开发者的文本）与来自不可信用户和第三方的文本视为同等优先级。为解决这一问题，我们提出一个指令层级（instruction hierarchy），明确定义当不同优先级的指令冲突时模型应如何行事。随后我们提出一种数据生成方法来展示这种层级式指令遵循行为，教会 LLM 选择性地忽略低特权指令。我们将该方法应用于 GPT-3.5，结果显示其鲁棒性大幅提升——即便是训练期间未见过的攻击类型——同时对标准能力的损耗极小。
