# OpenAI 与 GEDI 合作提供意大利新闻内容

此次合作将丰富意大利及全球数百万用户的 ChatGPT 体验。


*编者注：这则消息最初由 *[*GEDI*](https://www.gedi.it/en/media/news/openai-and-gedi-announce-strategic-partnership-bring-italian-language-news-content)* 发布。*

意大利媒体集团 GEDI 与 ChatGPT 背后的 AI 研究与部署公司 OpenAI 今天宣布建立战略合作，把 GEDI 旗下高质量新闻产品组合中的意大利语内容带给 OpenAI 的用户。

根据合作条款，ChatGPT 用户将能访问 GEDI 旗下出版物（包括 *La Repubblica* 和 *La Stampa*）注明来源的引语、内容和链接。

此次协作将把 GEDI 可信赖的新闻业纳入 OpenAI 产品——包括 ChatGPT 和 SearchGPT 原型——以提升其对意大利用户的相关性和准确性。

合作还为两家机构开辟了机会，可在 AI 功能与应用上进一步协作，改善意大利读者获取和互动新闻的方式。

GEDI 董事长 John Elkann 表示："与 OpenAI 签署的合作是 GEDI 数字化转型旅程的一部分，也认可了它在意大利媒体版图中生产高质量内容的领先地位。从今天起，ChatGPT 用户可以依托我们出版物的文章和深度分析，就广泛主题获得高质量信息，尤其聚焦意大利语境。"

> "得益于 ChatGPT 开发的先进翻译能力，这项协议也让 GEDI 能够触达更广泛的国际受众。"

John Elkann，GEDI 董事长

OpenAI CEO Sam Altman 表示："我们与全球出版商合作很重要，这样每个人都能用自己的语言获取准确可靠的信息。这次合作认可了 GEDI 的高质量新闻业，也将提升意大利及全球数百万人的 ChatGPT 体验。"
