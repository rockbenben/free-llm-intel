# Decagon 与 OpenAI 规模化交付高性能全自动客服

[Decagon](https://decagon.ai/) 于 2023 年创立，迅速成为客服自动化的关键玩家，服务公司包括 Curology、BILT、Duolingo、Eventbrite、Notion 和 Substack。OpenAI 的模型对其在不借助人工的情况下交付快速、可靠的回复至关重要。

从大型企业到技术先锋型初创公司，Decagon 帮助企业全球范围内处理数百万次支持对话，同时不牺牲质量与速度。公司组合使用 OpenAI 的多个模型——包括 GPT-3.5、4、4o、4 Turbo 和 OpenAI o1-mini——打造超越回复生成、服务整个客户生命周期的 agentic 机器人。

## 用 OpenAI 交付快速、细腻、可扩展的方案

Decagon 的客户需要能处理复杂咨询的可扩展高质量支持。两位创始人此前成功退出过 AI 公司，他们认识到市场需要一种超越基础自动化、能在海量交互中既细腻又快速响应的支持方案。

“我们深知延迟直接影响客户满意度。做实时客服时，每一秒都算数，”Decagon 联合创始人兼 CTO Ashwin Sreenivas 说。

但要在保证精确度的同时维持高自动化水平，仅靠传统自动化工具是不够的——需要能对复杂任务进行推理的先进 AI 模型。借助 OpenAI 的模型，Decagon 团队架构出一个灵活的方案，让客户能按自身需求完全定制工作流。

## 用 GPT 与微调达成最佳性能

Decagon 创造性地组合使用 OpenAI 的 GPT 模型，为满足不同客户的多样需求提供灵活性与定制化。OpenAI 的平台还帮助 Decagon 团队在多种任务上优化性能：“我们发现不同模型各有擅长，”Sreenivas 说。

例如，Decagon 微调了 GPT-3.5，在客户查询进入检索增强生成（RAG）工作流前先改写查询。“我们试过一堆其他模型配置，就客户查询而言，微调 GPT-3.5 给了我们最高的性能，”Sreenivas 说。

在其他工作流中，公司用 GPT-4 处理复杂决策任务，让平台能高效处理 API 请求和其他精细操作。

Decagon 的方式确保客户交互管线的每一环节都由最适合该任务的模型支撑，速度与准确率兼得。Decagon 联合创始人兼 CEO Jesse Zhang 说：“这让我们既能捕获客户的业务逻辑，又能为 agent 打造所有此前 LLM 出现前不可能存在的软件接口面。”

## 以强评估获得卓越准确率与灵活性

把 OpenAI 的模型与 Decagon 的定制工作流结合，公司大幅提升了其客户客服自动化的质量。“对我们最大的一位客户，我们处理其全球支持的 91%，全程无人参与，”Sreenivas 说。

Decagon 平台与 OpenAI 模型的可配置性，使其能适应每个客户的具体要求，确保最高性能与无缝集成。

一大关键优势是 Decagon 快速评估并集成新模型的能力。

“每当有新模型发布，我们都能非常、非常快地跑完评估，”Sreenivas 说。这种灵活性让 Decagon 保持前沿，确保平台始终运行当下最准确、最高效的模型。

## 与 OpenAI 一起进击客服下一个前沿

随着持续增长，Decagon 专注于扩展能力以支持更广泛的客户需求。公司已经在用 OpenAI 模型的版本——这对 Decagon 快速部署 AI 客服至关重要。“对新客户，我们的核心基础设施几天内就能跑起来，”Sreenivas 说。

展望未来，Decagon 正在探索如何用语音能力进一步增强其 AI agent，目标是把语音客服交互也做到同样的自动化水平与准确率。

通过持续用最新的 OpenAI 技术驱动平台，Decagon 已占据引领 AI 客服下一波创新的有利位置。
