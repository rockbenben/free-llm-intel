# OpenAI 任命 Dan Driscoll 为国家安全现代化高级顾问

Dan Driscoll 将加入 OpenAI，担任国家安全现代化高级顾问，与高级领导层和外部合作伙伴合作，就先进人工智能如何加强国家和网络安全提供建议，特别注重与美国盟友合作，推动其负责任的使用。

在这个新设立的角色中，Dan 将与 OpenAI 团队以及政府、行业、学术界和联盟机构的领导者合作，推进支持民主人工智能建设的实用现代化举措。他还将帮助 OpenAI 内部团队了解全球国家安全机构的运营需求。

丹此前曾担任第 26 任陆军部长，负责监督陆军的运营、现代化和资源。他带来了兵役、高级政府领导和私营部门的经验。

丹将在其职位上为我们的公共和私营部门合作伙伴提供现代化政策和战略选择方面的建议，以解锁人工智能的实际用途，以改善国家安全，并帮助确保世界正在构建人工智能以支持民主原则。他将努力确定运营需求、制度变革和新兴人工智能功能的结合点。 Dan 的任命体现了我们致力于帮助民主机构负责任地使用先进人工智能来加强共享安全的承诺，并以 OpenAI 与盟友和合作伙伴的合作为基础，根据其 [Daybreak](https://openai.com/daybreak/) 计划加强网络弹性并保护基本服务。

> “人工智能应该赋予人们更多的生活权力，人们应该对其发展方式拥有发言权。美国拥有与其他国家合作推广民主人工智能的绝佳机会，我很高兴欢迎 Dan Driscoll 加入 OpenAI，以加强美国的领导力并帮助我们实现这一目标。”

萨姆·奥特曼

> “我的大部分职业生涯都在公共服务领域度过，首先是作为一名士兵，最近担任陆军部长和 ATF 代理主任。服务的人们应该得到我们可以放在他们手中的最好的工具。国家安全要求的变化速度比过去五十年来的任何时候都快。这项技术将帮助他们通过简化文书工作、理解更多信息并更快地向正确的人提供正确的答案来跟上步伐。我加入 OpenAI 是为了帮助美国和我们的盟友将这项技术应用到公共服务中。为保障我们安全的人们负责任地工作。”

丹·德里斯科尔

**丹·德里斯科尔**是美国第 26 任陆军部长。作为部长，他负责监督近 100 万现役、警卫和预备役士兵以及超过 265,000 名陆军文职人员的行动、现代化和资源分配。他推动陆军转型，重点是加速新技术的部署、改革采办和建设一支更有能力的军队。丹曾是陆军军官和商界领袖，拥有兵役、法律和私营部门的经验。
