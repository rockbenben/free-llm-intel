# 走进 JetBrains — 一家正在重塑全球代码编写方式的企业

通过将 OpenAI 模型集成到其工具和工作流程中，JetBrains 正在重新定义开发人员借助 AI 进行设计、推理与软件构建的方式

如果你不编写软件，你可能从未听说过 JetBrains。

但如果你是开发人员，你几乎肯定会使用它的产品。

这家公司是现代软件开发的幕后推手，其工具为全球约 1500 万名专业工程师（其中不乏来自《财富》100 强中 88 家企业的工程师）提供支持，同时也是 Kotlin（安卓官方编程语言）的缔造者。如果你用过 IntelliJ、PyCharm、WebStorm、GoLand 或 Rider，就相当于体验过 JetBrains 的产品。

我们与 JetBrains 产品负责人 Kris Kang 进行了深入交流，探寻该团队如何运用 OpenAI 模型改变开发人员的构建方式，即提升他们的能力上限，而非取代他们的工作。

> “开发人员不只是编写代码，他们还会审查代码，进行推理，并设计系统。AI 能够提供的帮助，远不止于单纯的打字环节。”

Kris Kang，JetBrains 产品负责人

### JetBrains 如何应用 OpenAI 技术

Kang 告诉我们：“全球有超过 1500 万名开发人员在使用 JetBrains 的产品。如今，我们正在将 OpenAI 技术融入这一工作流之中。”这一转变不仅仅关乎自动化，更核心的是赋能。它旨在保护开发人员的工作流连贯性，减少重复性劳动，让工程师能够专注于设计、架构与判断，因为这些技能能够让你在 AI 时代获得更持久的竞争优势。

在内部，JetBrains 团队正在运用以下技术：

- ChatGPT
- GPT‑5
- Codex

在外部，客户可以在 JetBrains 旗下的编程智能体 Junie 和 AI 助手（用于聊天辅助）中选择启用 GPT‑5。

> “我们使用 ChatGPT，使用 GPT-5，也使用 Codex……Junie 选用的大语言模型 (LLM) 之一便是 GPT-5。”

Kris Kang，JetBrains 产品负责人

现在，工程师们已经开始将实际任务委托给智能体，并且见证了这些任务的顺利完成。Kang 表示，“我给一个由 GPT‑5 支持的智能体分配了任务，而且任务的难度越来越高；令人意外的是，其中许多任务都能成功完成。”

JetBrains 的衡量标准并非只有速度，而是持续的工程卓越性。“这不仅仅是生成代码那么简单 — 代码必须安全、易读且可维护。”Kang 继续说道。

JetBrains 从两个维度考量技术带来的影响：

**速度：**减少样板代码，降低背景信息切换频率，加快迭代速度。

**质量：**代码需易读、可评审、可维护，而非那些看似巧妙却会在生产环境中崩溃的输出。

### 来自 Kris 的领导力启示

**从人类感到棘手的环节入手：**文档编写、测试、审核、工作交接。

**保护深度工作：**背景信息切换对效率的损耗，远比打字速度慢带来的影响更大。

**构建混合式而非替代式工作流：**AI 负责起草，人类负责设计与审核。

**提高基础工作的标准：**明确的目标定位与扎实的架构设计，将成为效能倍增器。

**开展具有复利效应的实验：**高效迭代胜过即时验证。

> “聊天功能为你提供助力，而智能体则能带来跨越式提升。”

Kris Kang，JetBrains 产品负责人

### 未来展望

未来的工程师将：

- 设计系统
- 为智能体提供指导与约束
- 更高效地审核与推理
- 更自信地快速交付产品

不是减少工作量，而是让工作更具价值。

> “那些善于利用 AI 进行实验的人，将随着时间的推移获得复利式优势。”

Kris Kang，JetBrains 产品负责人
