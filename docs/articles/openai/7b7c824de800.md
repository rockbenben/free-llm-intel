# OpenAI 漏洞赏金计划公告

参与我们的 Bug Bounty 计划（在新窗口打开）。

## 我们对安全 AI 的承诺

OpenAI 的使命是创造造福每个人的 AI 系统。为此，我们在研究与工程上大力投入，确保我们的 AI 系统安全稳固。但和任何复杂技术一样，我们明白漏洞与缺陷可能出现。

我们相信，透明与协作是应对这一现实的关键。因此，我们邀请全球的安全研究员、道德黑客和技术爱好者社区帮助我们识别并修复系统中的漏洞。我们很高兴在既有的协调披露承诺基础上，为符合资格的漏洞信息提供奖励。你的专业能力与警惕将直接影响我们系统和用户的安全。

## 介绍 Bug Bounty 计划

OpenAI Bug Bounty 计划是我们认可并奖励那些为保持技术与公司安全作出贡献的安全研究员之宝贵洞察的方式。欢迎你报告在我们系统中发现的漏洞、缺陷或安全问题。通过分享你的发现，你将扮演让技术对所有人更安全的关键角色。

我们与领先的漏洞赏金平台 Bugcrowd 合作，管理提交与奖励流程，为所有参与者提供顺畅的体验。详细的参与指南与规则见我们的 [Bug Bounty Program 页面⁠（在新窗口打开）](https://bugcrowd.com/openai)。

## 激励与奖励

为激励测试并表达我们的感谢，我们将根据所报问题的严重程度与影响提供现金奖励。奖励从低危发现的 200 美元到杰出发现最高 20000 美元不等。我们重视你的贡献，并承诺认可你的付出。

## 共同保持安全

在 OpenAI，我们认识到安全的至关重要，并视其为一项协作工程。我们邀请安全研究社区参与我们的 Bug Bounty 计划。

想贡献更多？我们正在招聘——请到招聘页面查看空缺的[安全岗位⁠](https://openai.com/careers/search/?c=security)。加入我们，一起确保技术前沿的安全。
