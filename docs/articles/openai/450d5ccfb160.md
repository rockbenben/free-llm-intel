# 面向企业的新使用情况分析与更新后的支出控制

新的使用情况分析和更新后的支出控制，让 ChatGPT Enterprise 管理员在 AI 部署中拥有更高可见性、控制力和信心。


随着 AI 成为日常工作的一部分，组织需要能够像管理任何关键业务投资一样，以同样严谨的方式管理 AI。公司需要清晰了解使用情况、采用情况和支出，才能充满信心地扩展应用，并理解 AI 在哪些方面创造价值。

今天，我们为 ChatGPT Enterprise 推出额度使用情况分析和更新后的支出控制。这些功能可帮助公司跟踪额度使用情况、了解采用模式，并就如何在组织内部署 AI 作出更明智的决策。凭借更清晰的可见性和更灵活的控制，组织可以主动管理成本，为团队提供所需访问权限，并让 AI 投资聚焦于最重要的工作。

## 全局管理控制台中的新额度使用情况分析

全局管理控制台将 ChatGPT 和 Codex 的额度使用情况整合到一个视图中，让管理员能够按用户、产品和模型更细致地查看额度消耗明细，从而了解支出来源，以及这些支出如何对应到实际额度使用。这样可以更轻松地区分由高价值工作带来的使用增长，以及可能需要更仔细审查的使用模式。

现在，管理员可以：

- 跟踪一段时间内的使用情况和额度趋势
- 识别主要用户和新出现的额度使用模式
- 按工作空间细分额度支出，包括按用户、产品和模型查看
- 通过统一的 Cost API 访问相同的额度使用数据，以便在自己的系统中进行更深入分析

*显示 ChatGPT 和 Codex 使用情况及额度消耗的分析概览。*

—Ryan Oksenhorn，Zipline 联合创始人

## 围绕团队的工作方式设置支出控制

今年早些时候，我们为 ChatGPT Enterprise 中的自定义角色推出了精细化的[额度使用限制⁠（在新窗口中打开）](https://help.openai.com/en/articles/20001001-setting-usage-limits-for-custom-roles-in-chatgpt-enterprise)，帮助工作空间所有者管理不同类型用户对高级模型的使用，而不必采用一刀切的限制。

*最终用户查看支出控制并请求提高限额的视图。*

现在，管理员还可以为其 ChatGPT Enterprise 工作空间设置默认限额，为特定群组配置限额，并为需要更多容量的人员创建个人例外设置。员工可以查看自己的额度使用情况与可用预算的对比，在需要时请求更多额度，并说明正在处理的工作背景，帮助管理员作出明智决策。这样，个别重度用户可以继续工作而不中断，也无需提高其他所有人的限额。

这些更新后的控制共同帮助公司更审慎地大规模部署智能能力，同时为团队提供完成高影响力工作所需的能力。
