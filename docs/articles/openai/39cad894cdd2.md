# AT&T 正在用 OpenAI 重塑内部法务工作

AT&T 正在 LegalEdge 的基础上，探索支持其法务团队的新方式。

公司规模：Enterprise

地区：全球

AT&T 的内部法务部门在全球有数百名律师和法律专业人员。要给业务出主意，他们得先把事实、文档和相关的过往工作拼起来，往往还要用上分散在各个团队里的专长。对 AT&T 高级执行副总裁兼总法律顾问 David McAtee 而言，让这份经验更容易被取用，正是这个部门的工作得以改进的核心。

AT&T 正与 OpenAI 一起搭建这下一阶段。“我们与 OpenAI 的合作会让我们建起那套管道，为全公司的知识层供能，我们所有人都会从里面取用。”McAtee 说。

这次合作建立在 LegalEdge 之上。LegalEdge 是 AT&T 的一支队伍，由律师、法律专业人员、技术人员和项目经理组成，专注把 AI 用在重大法律事务上。下一步是把公司积累的更多专长接到摆在律师案头的工作上。

需求来自整个业务，法务团队要快速响应，又不能漏掉风险。提建议之前，他们得先弄清问题、把相关背景收齐，再决定什么要先处理。这让案件受理成为保护业务的关键一环。AT&T 首席合规官 Bill Ryan 把一项规划中的举措描述成一套受理系统，“有一扇前门，在那里用自然语言受理”。这套系统会给请求分类并排定优先级，把它们与相关先例、研究和过往工作连起来，并给负责的法律专业人员提供历史背景和推荐的第一步动作。

这样律师就有了一个信息更充分的起点，花在收集评估材料上的时间会更少。Ryan 把机会看成帮这个部门把判断力用到业务更多需求上。

“最让我对未来兴奋的，是我们能在更大的规模上输出法律判断。”他说。

在 McAtee 看来，指导这项工作的那个原则依然清楚：“决策永远由律师来做。”这次合作的目标，是把更好的信息放到够得着的地方，好让律师把更多时间用在施展专长上。
