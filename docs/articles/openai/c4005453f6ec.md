# 用 OpenAI 构建 OpenAI

全新系列：揭秘 OpenAI 如何运用自身技术驱动运作

正在加载…

*首席商务官 Giancarlo “GC” Lionetti 将开启系列专题，讲述 OpenAI 如何基于自有技术构建解决方案。*

AI 已超越实验阶段，正作为工作的基础设施从局部试点演进为影响日常决策的系统。尽管我们的模型在速度、成本和能力上持续提升，但应用过程却很少一帆风顺。部署速度往往快于组织为驾驭这项技术所需做出的变革速度。

在 OpenAI 内部，我们同样面临这种发展与适应之间的张力。以 AI 驱动业务意味着要直面所有客户的共同困惑：从何入手？如何将新工具融入现有工作流程？在环境不断变化时如何衡量进展？当我与客户会面时，他们最常问的问题是：“OpenAI 如何使用 OpenAI？”

我们的方法是将 AI 视为提升专业能力的实践手段。

每家公司的运转都离不开专业能力。构筑客户信任的销售人员、解决最棘手问题的客户支持主管以及在复杂性中寻找规律的工程师都在发挥各自的专业能力。AI 对这些专业能力进行编码并在各团队中传播，从而放大每个专业领域的影响力。

这就是我们的构建方式。市场拓展 (GTM)、产品和工程团队深入研究日常工作流程，定义卓越标准，并在数周而非数个季度内实现变革。我们决定聚焦少数高杠杆系统，发挥倍增效应。各团队通过实战部署测试系统，与客户同步锤炼实战能力。

## OpenAI 自用技术实践

今日推出“OpenAI 自用技术实践”系列文章，将展示我们如何在企业内部运用 AI。每个故事都围绕真实痛点与解决方案展开，旨在分享可供企业借鉴的模式。

以下是首批实践案例：

- [**GTM Assistant**⁠](https://openai.com/index/openai-gtm-assistant/)：基于 Slack、可整合帐户背景信息与专家知识的工具。它能简化调研流程、会议准备及产品问答，提升销售效率并改善成果。
- [**DocuGPT**⁠](https://openai.com/index/openai-contract-data-agent/)⁠：将合同转化为结构化可检索数据的智能体。财务团队可借此大规模实现更快速、更统一的审核工作。
- [**研究助手**⁠](https://openai.com/index/openai-research-assistant/)⁠：将数百万支持工单转化为对话洞察的系统。团队能在数分钟而非数周内发现趋势并响应客户反馈。
- [**支持代理**⁠](https://openai.com/index/openai-support-model/)⁠：基于 AI 智能体、持续评估和动态知识循环的运营模型。它可将每次交互转化为训练数据，提升服务质量，使客服代表成为系统的构建者而非工单处理者。
- [**入站销售助理**⁠](https://openai.com/index/openai-inbound-sales-assistant/)⁠：为每位潜在客户定制回复，即时解答产品与合规问题，并将合格潜在客户的全部背景信息发给销售代表。该系统可将错失的商机转化为实际收入。
