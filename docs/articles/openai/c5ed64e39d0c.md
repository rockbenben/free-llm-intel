# 介绍 Realtime API

开发者如今可以在自己的应用里构建快速的语音到语音体验

*2025 年 8 月 28 日更新：我们宣布了 Realtime API 的正式可用。*[*点此了解更多*](https://openai.com/index/introducing-gpt-realtime/)*。*

*2025 年 2 月 3 日更新：我们不再限制 Realtime API 上的并发会话数量。Realtime API 最新的速率限制请查阅我们的*[*文档*](https://platform.openai.com/docs/guides/rate-limits?tier=free)*。*

*2024 年 10 月 30 日更新：我们新增了五个音域更广、表现力更强的语音*。*文本和音频输入现在也提供缓存计费，缓存文本输入降到每 100 万 token 2.50 美元、缓存音频输入降到每 100 万 token 20 美元。*[*点此了解更多*](https://platform.openai.com/docs/guides/realtime)*。*

*2024 年 10 月 17 日更新：Chat Completions API 现已支持音频输入和输出。*[*点此开始*](https://platform.openai.com/docs/guides/audio)*。*

今天，我们推出 Realtime API 的公测版，让所有付费开发者都能在自己的应用里构建低延迟的多模态体验。和 ChatGPT 的高级语音模式（Advanced Voice Mode）类似，Realtime API 支持自然的语音到语音对话，使用 API 中已有的[六种预设语音](https://platform.openai.com/docs/guides/text-to-speech)。

我们同时也在 [Chat Completions API](https://platform.openai.com/docs/guides/chat-completions) 中引入音频输入和输出，以服务那些不需要 Realtime API 低延迟优势的场景。有了这次更新，开发者可以把任意文本或音频输入传给 [GPT-4o⁠](https://openai.com/index/hello-gpt-4o/)，并让模型以文本、音频或两者组合来回应。

从语言应用、教育软件到客户支持体验，开发者早已在用语音体验与用户建立连接。现在有了 Realtime API，很快再加上 Chat Completions API 的音频能力，开发者不必再把多个模型拼接起来支撑这些体验。取而代之的是，一次 API 调用就能构建自然的对话体验。

## 工作原理

以前要做出类似的语音助手体验，开发者得先用 [Whisper⁠](https://openai.com/index/whisper/) 这类自动语音识别模型把音频转成文本，再把文本交给文本模型做推理或思考，然后用[文本转语音](https://platform.openai.com/docs/guides/text-to-speech)模型把输出念出来。这种方式往往会丢失情绪、强调和口音，还带来明显的延迟。有了 Chat Completions API，开发者一次 API 调用就能处理整个流程，只不过它仍然比真人对话慢。Realtime API 则通过直接流式传输音频输入和输出改善这一点，带来更自然的对话体验。它还能像 ChatGPT 的高级语音模式那样自动处理打断。

底层实现上，Realtime API 允许你创建一条持久的 WebSocket 连接，与 GPT-4o 交换消息。该 API 支持[函数调用（function calling）](https://platform.openai.com/docs/guides/function-calling)，让语音助手能通过触发动作或拉入新上下文来响应用户请求。例如，语音助手可以代用户下单，或检索相关的客户信息来个性化它的回应。

### 支撑客服坐席、语言学习助手等场景

作为迭代式部署策略的一部分，我们一直和几家合作伙伴一起测试 Realtime API，边做边收集反馈。几个颇具前景的早期用例包括：

Healthify 是一款营养与健身教练应用，它用 Realtime API 让用户能与 AI 教练 Ria 自然对话，并在需要时引入人类营养师提供个性化支持。

Speak 是一款语言学习应用，它用 Realtime API 支撑其角色扮演功能，鼓励用户练习一门新语言的对话。

## 可用性与定价

Realtime API 今天起以公测版向所有付费开发者逐步开放。Realtime API 的音频能力由新模型 `gpt-4o-realtime-preview` 驱动。

Chat Completions API 中的音频将在未来几周发布，作为新模型 `gpt-4o-audio-preview`。借助 `gpt-4o-audio-preview`，开发者可以向 GPT-4o 输入文本或音频，并以文本、音频或两者接收回应。

Realtime API 同时使用文本 token 和音频 token。文本输入 token 定价为每 100 万 5 美元，输出为每 100 万 20 美元。音频输入定价为每 100 万 token 100 美元，输出为每 100 万 token 200 美元。这大约相当于每分钟音频输入 0.06 美元、每分钟音频输出 0.24 美元。Chat Completions API 中的音频价格相同。

## 安全与隐私

Realtime API 使用多层安全防护来降低 API 被滥用的风险，包括自动化监控，以及人工审查被标记的模型输入和输出。Realtime API 构建在与驱动 ChatGPT 高级语音模式相同版本的 GPT-4o 之上，我们对它进行了审慎评估，兼顾自动化和人工评测，其中包括依据我们的[准备框架（Preparedness Framework）⁠](https://openai.com/preparedness)所做的评估，详见 [GPT-4o 系统卡⁠](https://openai.com/index/gpt-4o-system-card/#observed-safety-challenges-evaluations-and-mitigations)。Realtime API 还复用了我们为高级语音模式搭建的同一套音频安全基础设施，测试表明它有助于降低潜在伤害。

把我们要服务的输出挪用或分发出去用于发垃圾信息、误导他人或以其他方式伤害他人，违反我们的[使用政策⁠](https://openai.com/policies/usage-policies/)——我们会主动监控潜在滥用行为。我们的政策还要求开发者明确告知用户他们正在与 AI 交互，除非从上下文中已一目了然。

上线之前，我们用外部红队网络测试了 Realtime API，发现它没有引入任何现有缓解措施未覆盖的高风险缺口。和所有 API 服务一样，Realtime API 受我们的[企业隐私⁠](https://openai.com/enterprise-privacy/)承诺约束。未经你明确许可，我们不会用本服务的输入或输出来训练模型。

## 上手

未来几天，开发者可以在 [Playground](https://platform.openai.com/playground/realtime) 里开始基于 Realtime API 构建，也可以使用我们的[文档](http://platform.openai.com/docs/guides/realtime)和[参考客户端](https://github.com/openai/openai-realtime-api-beta)。

我们还与 [LiveKit](https://docs.livekit.io/agents/openai/) 和 [Agora](https://www.agora.io/en/products/agora-openai-conversational-ai-sdk/) 合作，创建了包含回声消除、重连、声音隔离等音频组件的客户端库；并与 [Twilio](https://www.twilio.com/en-us/blog/twilio-openai-realtime-api-launch-integration) 合作，把 Realtime API 集成到 [Twilio 的语音 API](https://www.twilio.com/en-us/voice) 中，让开发者能通过语音通话无缝地构建、部署 AI 虚拟坐席并与客户连接。

## 下一步

在迈向正式可用的过程中，我们正积极收集反馈以改进 Realtime API。我们计划引入的一些能力包括：

- **更多模态：** 起初 Realtime API 只支持语音，我们计划陆续加入视觉、视频等更多模态。
- **更高的速率限制：** 目前该 API 对 Tier 5 开发者的限制约为 100 个并发会话，Tier 1-4 更低。我们会逐步提高这些限制，以支撑更大规模的部署。
- **官方 SDK 支持：** 我们会把 Realtime API 的支持集成进 OpenAI 的 Python 和 Node.js SDK。
- **提示词缓存：** 我们会加入对[提示词缓存（Prompt Caching）](http://platform.openai.com/docs/guides/prompt-caching)的支持，让此前的对话轮次可以打折重新处理。
- **扩展模型支持：** Realtime API 也将在该模型的后续版本中支持 GPT-4o mini。

我们期待看到开发者如何利用这些新能力，为他们的用户创造出从教育、翻译、客服到无障碍等各类场景中引人入胜的音频新体验。
