# GPT-5.5 系统卡

Read the System Card



## 1. 引言

GPT-5.5 是一款为复杂现实工作设计的新模型，能编写代码、在线检索、分析信息、创建文档和电子表格，并在多个工具间切换以完成任务。与更早的模型相比，GPT-5.5 能更早理解任务，需要的引导更少，更有效地使用工具，会检查自己的工作，并持续进行直到完成。

我们让该模型接受了完整的部署前安全评估套件和 Preparedness Framework（防范框架），包括针对高级网络安全和生物能力的定向红队测试，并在发布前从近 200 家抢先体验合作伙伴那里收集了真实用例的反馈。我们随 GPT-5.5 一同发布了迄今最强的一整套防护措施，旨在减少滥用的同时保留高级能力的合法、有益用途。

我们通常将 GPT-5.5 的安全结果视为 GPT-5.5 Pro 的有力替代指标——后者是同一底层模型，采用一种利用并行测试时算力的设置。如下文所述，在某些情况下我们会单独评估 GPT-5.5 Pro，因为我们判断该设置可能实质性地影响相关风险或相应的防护策略。除另有说明外，系统卡中的结果描述的都是在离线环境下运行的评估。

*本卡于 2026 年 4 月 24 日更新，补充了关于在 API 中部署 GPT-5.5 和 GPT-5.5 Pro 时防护措施的信息。*
