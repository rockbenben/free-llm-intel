# 用 ChatGPT 做研究

用搜索和深度研究（deep research）从全网查找、分析并综合信息。

ChatGPT 可以成为有用的研究伙伴，因为它能迅速汇集来自众多来源的信息，让你更容易探索想法、发现规律、理解复杂主题。通过对上下文进行推理、引用来源并生成清晰、结构化的摘要，它帮助把开放性的问题变成明确洞见。

用 ChatGPT 搜索公开互联网有两种不同方式——**搜索（search）**和**深度研究（deep research）**。下面分别说明两者，以及各自适合什么时候用。

## ChatGPT 搜索

ChatGPT 搜索让 ChatGPT 能够把来自互联网的最新信息直接带入你的对话。这意味着你可以超越 ChatGPT 内置的训练知识，获得关于时事、市场趋势、竞争对手动态，或其训练数据未涵盖的细分细节的即时答案。

不必在多个浏览器标签之间来回切换并自行总结信息——搜索会直接把这些更新带进 ChatGPT，简化你的研究过程、节省时间。它也便于把新鲜的网页数据与 ChatGPT 模型的推理和总结能力结合起来。

### 如何在聊天中使用搜索

- 在 ChatGPT 中打开一个新对话。
- 提出一个需要当前或详细信息的问题（例如*"2025 年医疗保健领域前三大 AI 趋势是什么？"*），或从工具菜单点击 **Web Search（网页搜索）**。
- 留意模型回复旁边的小地球图标 🌐——它表示使用了搜索。
- 点击回复中的引用链接，查看原始来源。
- 用澄清性提示词继续追问，比如*"把这份内容总结成给高管看的 3 个要点"*或*"把它转成一封面向客户的邮件草稿"*。

### 其他注意事项

- **引用**：做决策前务必核查被链接的来源，因为搜索结果反映的是网上可获得的内容。
- **范围**：搜索不能替代专业数据库（如订阅制研究工具或专有数据）。
- **管理员设置**：在企业环境中，Workspace 所有者可以选择启用或禁用搜索。

更多内容见：[OpenAI 帮助中心：ChatGPT 搜索](https://help.openai.com/articles/9237897-chatgpt-search?q=chatgpt)

## 深度研究

ChatGPT 中的深度研究利用推理能力，快速从全网收集、总结并解读大量信息，帮助你比标准网页搜索更全面地回答复杂问题。

每一份输出都被设计成有据可查的，带有清晰的来源引用，便于核实和引用信息。深度研究在寻找冷门、反直觉的信息方面尤其有效——这些信息原本需要查阅大量来源才能找到。

与传统网页搜索不同，深度研究是**具备 agent 性质的**：它会主动规划并执行一个多步骤的研究过程——搜索、评估来源、优化查询、综合发现——而不是简单返回一串链接。

### 如何在聊天中使用深度研究

1. 打开 ChatGPT，从工具菜单中选择 **deep research（深度研究）**

2. 提出一个清晰、详细的提示词。写明你的主题、目标、时间范围和关键细节。如果深度研究需要更多上下文，它会自动提出后续问题。

- *我正在为[受众/决策/会议]研究[主题]。请提供一份报告，包括近期关键机会与风险，以及 3-5 条可执行洞见。*

3. 审阅你的报告

- 深度研究在探索网络时可能运行 5–30 分钟。报告完成时你会收到通知。
- 你可以提出后续问题或要求进一步分析，深度研究会按需优化输出。

## 搜索 vs. 深度研究

这两个功能听起来相似，但各自最适合的用途不同。下面是两者的简要对比：

|  | **搜索** | **深度研究** |
| --- | --- | --- |
| **目的** | 快速从网络或已连接来源检索**具体事实**、文档或最新信息。 | 对需要跨多个来源推理与综合的复杂或模糊问题，进行**多步骤、深入的分析**。 |
| **典型用途** | 查找最近的新闻稿、产品规格表、新闻文章或单个数据点（例如"去年夏季奥运会的观众人数是多少？"）。 | 探索更宏观的问题，如"哪些因素影响大型国际体育赛事的上座率？"或"不同国家如何筹备举办奥运会？" |
| **输出深度** | 返回简洁的结果、直接的答案或链接——类似于智能网页搜索。 | 生成**长篇、有证据支撑的摘要**，通常带有引用、权衡分析和推理步骤。 |
| **速度** | 快——通常几秒钟。 | 较慢——由于多步推理，可能需要几分钟甚至更久。 |
| **新鲜度** | 优先使用**最新可得**信息；适合突发新闻或时效性数据。 | 在相关时会使用新来源，但重点在于**情境化理解**，而非单纯求新。 |
| **问题复杂度** | 最适合**定义清晰、具体**的查询。 | 最适合**开放式、探索性**或没有唯一正确答案的**战略性**问题。 |
