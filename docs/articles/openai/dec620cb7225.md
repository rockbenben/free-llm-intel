# dot 正式登场

创建你的 dot




**dot 是能力强大、全天候运行的智能体，旨在处理各种事务。**它们带来一种全新的 AI 协作方式：了解你看重的事，持续为你推进工作、分担重要任务，让你腾出更多时间与精力。

*[素材：《实验室直播》发布短片]*

dot 拥有前沿智能，随时为你提供支持。它们由 GPT‑6 Astra 驱动，拥有自己的云电脑，能从反馈中持续学习，全天候为实现你的目标而工作。通过我们的插件生态系统，dot 可以轻松连接超过 4000 款应用，获取所需工具，在你需要的地方提供帮助。

无论通过 ChatGPT、Slack 还是 Teams，你都能随时联系 dot。你可以在协作过程中提问、探讨想法或提供反馈；需要把事情聊清楚时，也可以直接发起语音通话。合作越多，dot 就越了解你的偏好、思考方式，以及你认为什么样的成果才算好。

dot 的神奇之处在于，它能按你的方式交付成果，有时甚至赶在你想到开口之前。有了 dot 相伴，那些你曾因缺乏时间或支持而没能推进的宏大构想和项目，也开始变得切实可行。

在 OpenAI 内部，我们正逐渐体会到，有智能助手始终并肩工作会是什么样。Slack 中出现一个 Bug，dot 就会立即着手排查。收到新的设计稿后，dot 会将其转化为可运行的应用，让团队专注于客户反馈。进入新的规划周期，dot 会帮助大家协调步调，按期推进工作。在 OpenAI 之外，一位早期测试者的 dot 注意到他忘记向一家出版机构开具发票，于是准备好了发票，并在他批准后发送。

现在，你可以先从自己的主力 dot 开始体验，为它取个名字，打造属于你的助手。未来，我们希望让多个 dot 组成团队，协作为你完成工作。我们正向符合条件市场的 Pro、Business Premium 和 Enterprise 套餐用户逐步推出 dot，并计划很快向更多用户开放。我们也在展示专家型 dot 的预览：它们拥有用于访问管理的独立身份，使用由 IT 团队配置的硬件，并支持与企业核心业务记录系统深度集成，从而在组织内承担明确的职责。

## dot 可以独立工作

dot 可以利用自己的云电脑、浏览器和你已连接的应用，完成几乎任何任务。

你可以随时打开 dot 的云电脑，检查它的工作。除了自己的设备，dot 还可以连接其他设备。你也可以授权它连接并使用你的笔记本电脑，直接在你的设备上与你协作。

你的 dot 能接手项目并持续推进，同时兼顾其他项目。你可以不断交给它新的任务和想法，无需在多条对话线程间来回切换，也不必指导每一个步骤。

## dot 是你的延伸

借助清楚你目标和标准的 dot，你无需指导每一个步骤，也能推进更多工作。以下是一些实际场景：

**将反馈转化为经过测试的修复方案**

假如你正在开发一款应用。你的 dot 会持续关注客户反馈，找出反复出现的需求，确定小幅改进和 Bug 修复的范围，完成开发和测试，并将完整的 PR (Pull Request) 连同展示修改效果的视频交给你审查。你可以一边审查 dot 准备的修复和改进，一边继续开发下一项重要功能。

**根据范围变化调整发布计划**

假如你正在主导一次产品发布。你的 dot 熟悉目标受众、产品定位和创意标准。产品范围变化时，它会梳理这对整体叙事的影响，相应调整发布材料，并起草相关素材和文档的修改方案。等你回来时，发布计划和创意素材已按你设定的方向调整妥当，等待你审阅。

**根据新证据更新分析**

假如你是一名科学家。你的 dot 熟悉你的研究问题和评估证据的方法。收到新数据后，它会重新运行分析、探究出乎意料的结果，并更新论文中的图表。如果研究结论发生变化，它会相应修改解释说明，并标记需要你审查的部分。等你从实验室回来，工作成果就已反映最新证据。

**根据需求变化更新提案**

假如你是一名销售主管，正推动一笔企业客户交易通过技术审查。你的 dot 会对照产品文档，核查客户需求和历史记录，找出仍需测试的内容，为一项关键集成构建概念验证 (PoC)，并推荐一位有类似交易经验的解决方案工程师。随着需求和测试结果的变化，它会更新提案和测试计划，并标记尚未解决的问题。你和工程师则可以专注于与客户沟通，并审批向客户作出的各项承诺。

**实现内容制作自动化**

假如你是一名内容创作者。你的 dot 熟悉你的语气，也知道受众关注什么。收到新的访谈文稿后，它会挑出适合制作短片的精彩片段，准备节目要点 (show notes)，并起草社交帖子供你审批。它会将你的修改同步到所有材料中，并不断学习哪些内容能引起共鸣，让你有更多时间专注于创作。

## dot 融入你的工作流

与你的 dot 协作，就像聊天一样简单。你可以在桌面端、网页端和移动端的 ChatGPT 中给 dot 发消息或与它通话。dot 也可以主动发消息，汇报进度、提出问题，或请你作出决定。

你也可以在 Slack 和 Teams 中给 dot 发消息（短信功能即将推出）。在 ChatGPT 中启动项目，通过 Slack 与项目团队共享上下文，再让 dot 跟进后续工作。dot 会跨渠道保留上下文，因此无论你通过哪个渠道联系它，它都能掌握完整背景。

## 你始终掌控全局

dot 在 ChatGPT 现有保护措施的基础上，针对其能够执行的工作增加了[额外的安全与隐私防护机制](https://openai.com/index/how-we-build-safety-security-and-privacy-into-dots/)。你可以设定边界、跟踪进度，并在需要时参与决策。

### 内置防护机制

每个 dot 都在自己的云电脑上工作。除非你选择连接自己的电脑，否则你的电脑及其内容会与 dot 的云电脑保持分离。登录受支持的网站时，dot 可以使用已保存的密码，而不会向模型暴露密码内容。

当你没有主动与 dot 协作时，它也会在后台寻找能帮上忙的事情。我们将这一过程称为“主动研究 (proactive research)”。开展这项工作时，dot 会通过仅有只读权限的工具访问你已连接的应用。这些工具无法发送消息、修改应用内容，也无法控制你的浏览器或电脑。

dot 内置的安全防护机制有助于抵御恶意指令，并监测潜在的有害行为。如果我们的监控系统发现安全隐患，可以暂停或停止 dot 的工作。

### 访问与权限控制

你可以选择允许 dot 访问哪些应用，并在现有的 ChatGPT 应用控制面板中管理权限。

dot 内置的规则明确了何时可以独立行动、何时需要请求批准。通过自定义规则 (Custom Rules)，你可以允许特定操作、要求事先批准，或禁止某些操作。内置的安全要求始终有效。你可以在活动视图 (Activity View) 中跟踪工作进度（包括后台工作），并根据需要调整 dot 的工作方向。

默认情况下，我们不会使用 ChatGPT Business、Enterprise 或 Edu 工作空间的内容来改进模型。使用个人 ChatGPT 套餐时，你可以决定是否将 dot 的对话和工作内容用于[改进我们的模型⁠（在新窗口中打开）](https://help.openai.com/articles/7730893-data-controls-in-chatgpt)。我们不会直接使用主动研究内容或 dot 给自己记录的笔记来训练模型。如果其中的信息为符合训练条件的对话或任务提供了参考，我们仍可能根据你的设置将其用于模型训练。

### 操作审查与审批

对于可能影响你的账户或分享信息的操作，dot 会通过[自动审查 (auto-review)⁠（在新窗口中打开）](https://learn.chatgpt.com/docs/sandboxing/auto-review)，核对其是否符合你的指令、自定义规则 (Custom Rules) 和安全要求。这有助于判断哪些工作可以继续、哪些需要审批，以及哪些必须由你亲自完成。某些敏感任务，例如更改密码，始终需要你亲自操作。

你可以通过[我们的 dot 安全博客](https://openai.com/index/how-we-build-safety-security-and-privacy-into-dots/)、[帮助中心⁠（在新窗口中打开）](http://help.openai.com/articles/20001529)和[系统卡片⁠（在新窗口中打开）](https://deploymentsafety.openai.com/gpt-6-astra/change-log)，进一步了解我们针对 dot 采取的安全措施。dot 仍可能出错，因此请务必审查可能产生重大影响的工作。

## 专为贵组织打造的专家型 dot

你的 dot 为你处理工作，**专家型 dot (specialist dot)** 则在组织内承担专门职责。公司会为每个 dot 配置独立的身份、凭据，以及完成任务所需的系统访问权限。dot 会在工作过程中根据新信息作出调整，并通过团队反馈不断改进。我们正在借鉴 OpenAI 内部早期测试的经验，持续完善这些能力。测试涵盖采购、发票处理、邮件营销、客户支持和商业合同等领域。

我们将从面向企业的试点项目开始。工程团队会直接与各组织合作，明确每个 dot 的职责、可使用的工具，以及人工审查和批准其工作的流程。如果你有希望交由专家型 dot 处理的工作，我们期待听听你的想法。

### 将专家型 dot 引入 Microsoft Agent 365

我们还在与微软合作，将专家型 dot 接入 Agent 365 的企业治理与安全控制体系，让企业能够通过现有的微软工具管理 dot。

## 开始使用 dot

即日起，[符合条件的市场⁠（在新窗口中打开）](https://help.openai.com/articles/20001530)中的 Pro 和 Business Premium 用户将陆续可以在 ChatGPT 中使用 dot。Enterprise 用户（包括 Edu 和医疗保健版用户）可在工作空间管理员启用该功能后体验测试版。

你的 Pro 或 Business Premium 套餐已包含首个 dot，无需额外付费。它全天候在线，随时与你交流、帮你思考，并跟进你关心的事项。套餐还包含用于深度工作的使用额度，发布后的首个月可享更高额度。未来，你还可以添加更多 dot，并通过提高运行速度或增加每月可承担的工作量，提升每个 dot 的产出。

你与 dot 的对话不计入你的 ChatGPT 使用额度。如果你让 dot 在 Codex 或“ChatGPT 工作”中启动或管理任务，这些任务仍会照常计入使用额度。

首先，在 ChatGPT 桌面应用或电脑浏览器中创建你的首个 dot，连接应用，再让它作个自我介绍。完成初始设置后，你就可以通过 ChatGPT 移动应用向它发送消息。

我们会持续观察 dot 在日常工作中的表现，并据此改进。我们也会尽可能分享积累的经验，以此指导后续开发。
