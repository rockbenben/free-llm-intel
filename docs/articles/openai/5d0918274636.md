# OpenAI 网络安全资助计划

我们的目标是通过资助和其他支持，促进面向防御方的 AI 驱动网络安全能力的发展。

***2026 年 2 月 5 日更新：**** 我们正在升级网络安全资助计划，转向聚焦我们模型的大规模部署以加速网络防御。随着 GPT-5.3-Codex 的发布，我们推出 *[Trusted Access for Cyber（网络可信访问）*](https://openai.com/index/trusted-access-for-cyber/)*，并承诺投入 1,000 万美元的 API 额度。*

我们启动网络安全资助计划（Cybersecurity Grant Program）——一项 100 万美元的计划，用于提升并量化 AI 驱动的网络安全能力，促进高水平的 AI 与网络安全讨论。

我们的目标是与全球防御方合作，通过 AI 的应用以及同心者的协调行动改变网络安全的攻守态势，守护共同安全。

**我们的计划旨在：**

- **赋能防御方**：我们希望确保最前沿的 AI 能力首先、最大程度地惠及防御方。
- **度量能力**：我们正在开发量化 AI 模型网络安全能力的方法，以更好地理解并提升其效能。
- **提升讨论水平**：我们致力于推动 AI 与网络安全交叉领域的严谨讨论，鼓励对该领域的挑战与机遇形成全面而细致的理解。

网络安全的一种传统观点认为，格局天然使攻击者优于防御者。这可以用一句老话概括：“防御必须次次正确，攻击者只需成功一次。”尽管攻击者面临的约束更少并利用其灵活性，这或许属实，但防御方拥有更有价值的东西——朝着保护人们安全这一共同目标的协同。

以下是我们团队提出的一些一般项目构想：

- 从网络防御方收集和标注数据，用于训练防御型网络安全 agent
- 检测并缓解社会工程学手段
- 自动化事件分诊
- 在源代码中识别安全问题
- 协助网络或设备取证
- 自动修补漏洞
- 优化补丁管理流程，改进安全更新的优先级、调度和部署
- 开发或改进 GPU 上的机密计算（confidential compute）
- 创建蜜罐与欺骗技术，误导或诱捕攻击者
- 协助逆向工程师为恶意软件创建签名与基于行为的检测
- 分析组织的安全控制措施并与合规体系比对
- 协助开发者创建[设计即安全、默认即安全⁠（在新窗口中打开）](https://www.cisa.gov/sites/default/files/2023-04/principles_approaches_for_security-by-design-default_508_0.pdf)的软件
- 协助终端用户采纳安全最佳实践
- 帮助安全工程师和开发者创建稳健的威胁模型
- 为防御方产出与其组织相关、贴合重点的威胁情报
- 帮助开发者将代码移植到内存安全的语言

## 立即申请！

如果你认同我们对安全而创新的 AI 驱动未来的愿景，欢迎你提交提案，与我们一起致力于增强防御性网络安全技术。

OpenAI 将滚动评审并接受资金或其他支持的申请。我们会强烈偏好 AI 在防御性网络安全中的实际应用（工具、方法、流程）。我们将在 100 万美元的资金池中，以 1 万美元为单位，以 API 额度、直接资助和/或等价物形式发放资助。

攻击性安全（offensive-security）项目暂不在资助考虑范围内。

所有项目都应计划以最大化公共利益与共享的方式进行许可或分发，我们会优先支持对此有清晰规划的申请。

请在[此处⁠](https://openai.com/form/cybersecurity-grant-program/)提交你的提案。
