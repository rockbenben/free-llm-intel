# GPT‑5.1 Instant 和 GPT‑5.1 Thinking 系统卡附录

阅读系统卡


## 介绍

正如我们在[博客⁠](https://openai.com/index/gpt-5-1)中所述，GPT‑5.1 Instant 和 GPT‑5.1 Thinking 是我们 GPT‑5 模型的下一代版本。GPT‑5.1 Instant 比我们之前的聊天模型更具对话感，具备更强的指令遵循能力和自适应推理能力，使其能够决定何时思考后再做出回应。GPT‑5.1 Thinking 更加精确地根据每个问题调整思考时间。GPT‑5.1 Auto 将继续自动为每个问题匹配最合适的模型，因此在大多数情况下，用户无需自己选择。

这些模型的全面安全缓解措施与我们在 [GPT‑5 系统卡⁠](https://openai.com/index/gpt-5-system-card/)中描述的基本相同。本系统卡附录提供了这些新模型版本的最新基准安全指标。正如我们在最近的 GPT‑5 系统卡[关于敏感对话的附录⁠（在新窗口中打开）](https://cdn.openai.com/pdf/3da476af-b937-47fb-9931-88a851620101/addendum-to-gpt-5-system-card-sensitive-conversations.pdf)中指出的那样，我们已经扩大了作为部署前安全审查一部分的基准安全评估，包括心理健康评估（涵盖用户可能出现孤立妄想、精神病或躁狂迹象的情况）和情感依赖评估（涵盖与不健康的情感依赖或对 ChatGPT 的依恋相关的输出）。

在本卡中，我们也将 GPT‑5.1 Instant 称为 gpt-5.1-instant，将 GPT‑5.1 Thinking 称为 gpt-5.1-thinking。
