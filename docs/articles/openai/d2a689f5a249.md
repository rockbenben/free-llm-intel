# Sam Altman 回归担任 CEO，OpenAI 组建新的初始董事会

Mira Murati 出任 CTO，Greg Brockman 回归担任总裁。阅读 CEO Sam Altman 和董事长 Bret Taylor 的内部信。


*以下是 CEO Sam Altman 与董事长 Bret Taylor 今天下午分享给全公司的信。*

## Sam 写给全公司的信

我将回归 OpenAI 担任 CEO。Mira 会回到 CTO 的岗位。新的初始董事会由 Bret Taylor（董事长）、Larry Summers 和 Adam D'Angelo 组成。

我从未像现在这样对未来感到兴奋。在一个不明朗、也史无前例的局面里，我非常感谢每个人的努力，我相信我们的韧劲和精神在行业中是独一份的。对于实现我们使命的成功概率，我感到非常、非常好。

在谈接下来做什么之前，我想先说几声感谢。

我爱并敬重 Ilya，我认为他是这个领域的指路明灯，是一位难得的人。我对他没有一丝怨气。虽然 Ilya 不再担任董事，但我们希望继续工作上的关系，也在讨论他可以怎样继续在 OpenAI 工作。

我感谢 Adam、Tasha 和 Helen，我们一起找到了这个最有利于使命的解决方案。我很期待继续与 Adam 共事，也由衷感谢 Helen 和 Tasha 在这件事上投入的巨大精力。

也要感谢 Emmett，他在帮助我们达成这个结果的过程中起了关键而建设性的作用。Emmett 对 AI 安全的投入、对各方利益的平衡，大家都看在眼里。

Mira 在整件事中做得非常出色，全程无私地为使命、为团队、为公司服务。她是一位了不起的领导者，没有她就没有今天的 OpenAI。谢谢你。

我和 Greg 是经营这家公司的伙伴。我们一直没想好怎么在组织架构图上表达这一点，但我们会找到办法。在此之前，我只想把它说清楚。谢谢你从最一开始所做的一切，也谢谢你自己从这件事开始、在过去一周里如何处理它。

领导团队——Mira、Brad、Jason、Che、Hannah、Diane、Anna、Bob、Srinivas、Matt、Lilian、Miles、Jan、Wojciech、John、Jonathan、Pat，还有很多人——显然已经完全可以在我不在的情况下经营公司。有人说，评价一位 CEO 的一个方式是看他如何挑选并培养潜在继任者；按这个指标，我做得比我意识到的要好得多。我很清楚这家公司处在很可靠的人手里，我也希望这一点对大家足够清楚。谢谢你们所有人。

Jakub、Szymon 和 Aleksander 是杰出的人才，我很高兴他们重新加入，推动我们和我们的研究往前走。谢谢。

致你们所有人，我们的团队：我相信一定会有人写下关于这段时期的书，我希望书里第一句讲的就是整个团队有多了不起。既然我们走过了这一切，我们没有失去一名员工。你们彼此支撑、支撑这家公司、支撑我们的使命。对于一支要安全地造出 AGI 的团队来说，最重要的能力之一就是在压力和不确定中稳住，并全程保持好的判断力。满分。谢谢你们所有人。

Satya、Kevin、Amy 和 Brad 自始至终都是极好的伙伴，从头到尾都把轻重缓急拿捏得恰到好处。他们给我们兜底，并且准备好在我们无法达成首要目标时接纳我们所有人。我们选择与微软合作显然是正确的决定，我也很高兴我们的新董事会将把微软作为无投票权的观察员纳入其中。谢谢。

致我们的合作伙伴和用户：谢谢你们留在我们身边。我们真切感受到了涌来的支持与善意，它帮我们所有人撑过了这一切。我们没有失去一位客户，这件事会驱动我们为你更努力地工作，我们所有人都迫不及待地想回到工作中。

Will Hurd、Brian Chesky、Bret Taylor 和 Larry Summers 把自己的生活按下了暂停键，为支持使命做了海量的工作。我不知道他们是怎么做得这么好的，但他们确实做到了。谢谢。

Ollie 这整段时间也把自己的生活按下了暂停，只为尽他所能帮忙，除此之外还一如既往地给出无条件的爱与支持。谢谢你，我爱你。

**那么接下来是什么？**

我们有三个当务之急。

推进我们的研究计划，并进一步投入我们的全栈安全工作——安全一直是我们的工作命脉。我们的研究路线图很清楚；这段时间虽然艰难，却异常让人专注。我和你们一样兴奋；我们会把这场危机变成机会！这部分我会和 Mira 一起推进。

继续改进并部署我们的产品、服务我们的客户。让人们得以体验 AI 的好处与前景、并有机会参与塑造它，这很重要。我们仍然相信，好产品是做到这一点最好的方式。这部分我会和 Brad、Jason、Anna 一起，确保我们对用户、客户、伙伴和世界各地政府的坚定承诺清清楚楚。

Bret、Larry 和 Adam 会全力投入一件极其重要的任务：组建一个视角多元的董事会，改进我们的治理结构，并监督对近期事件的独立审查。我期待与他们在这几步关键工作上紧密配合，让每个人都能对 OpenAI 的稳定有信心。

我非常期待和你们一起把"造出有益于人类的 AGI"这件事做完——世界上最好的团队，世界上最好的使命。

爱你们的，

Sam

## Bret 写给全公司的信

我代表 OpenAI 董事会，向整个 OpenAI 社区表达谢意，尤其是所有 OpenAI 员工——在过去一周里，大家齐心协力为公司找到了一条向前的路。你们的努力让这家了不起的组织得以继续履行它的使命：确保通用人工智能惠及全人类。Sam、Mira 和 Greg 重新一起领导公司、推动它向前，我们非常高兴。我们期待与他们、也与你们所有人共事。

作为董事会，我们专注于加强 OpenAI 的公司治理。我们打算这样做：

- 我们将组建一个资质过硬、背景多元的董事会，成员都是杰出个体，其集体经验能覆盖 OpenAI 使命的广度——从技术到安全到政策。我们很高兴这个董事会将包含一名微软的无投票权观察员。
- 我们将进一步稳固 OpenAI 这个组织，以便持续服务我们的使命。这包括召集一个董事会独立委员会，监督对近期事件的审查。
- 我们将完善 OpenAI 的治理结构，让所有利益相关方——用户、客户、员工、合作伙伴和社区成员——都能相信 OpenAI 会持续繁荣。

OpenAI 比以往任何时候都更重要。ChatGPT 已经让人工智能成为数亿人日常生活的一部分。它的普及使 AI——它的好处与它的风险——成为几乎所有关于政府、商业和社会未来对话的核心议题。

我们理解这些讨论的分量，也理解 OpenAI 在这些令人心生敬畏的新技术的开发与安全中所处的中心位置。你们每个人都扮演着关键角色，确保我们真正迎接住这些挑战。我们承诺倾听你们、向你们学习，我也希望很快能和你们每一个人交流。

很庆幸能成为 OpenAI 的一部分，也期待与你们所有人共事。

谢谢你，Bret Taylor，OpenAI 董事长

*2023 年 12 月 8 日更新，来自 Bret Taylor，OpenAI 董事会董事长*

如前所述，OpenAI 董事会已组建一个由 Bret Taylor 和 Larry Summers 组成的委员会，负责监督对近期事件的审查。该委员会约谈了多家一流律师事务所来做这项审查，最终选定 WilmerHale 的 Anjan Sahni 和 Hallie B. Levin。Anjan 和 Hallie 经验丰富，我们完全相信他们能够有效、及时地完成审查。在审查进行期间，董事会将继续采取措施加强 OpenAI 的公司治理、组建一个资质过硬且多元的、由杰出个体构成的董事会，并监督 OpenAI 这项重要使命：确保通用人工智能惠及全人类。
