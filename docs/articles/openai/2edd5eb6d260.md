# OpenAI 组织更新

对 OpenAI 而言，这是剧变与增长的一年。

对 OpenAI 而言，这是剧变与增长的一年。5 月，我们推出了 GPT‑3——迄今最强大的语言模型；不久后发布了首个商业产品：一个可以用简单自然语言提示词安全访问 AI 模型的 API。我们为团队这些及其他研究突破感到自豪，它们都是我们使命的一部分——打造安全可靠、造福全人类的通用 AI。

今天我们宣布，研究副总裁 Dario Amodei 将在供职近五年后离开 OpenAI。这段时间里，Dario 对我们的研究做出了巨大贡献：与团队一起打造 GPT‑2 和 GPT‑3，并与 Ilya Sutskever 作为联席负责人共同确立研究方向。

Dario 始终与我们秉持负责任的 AI 这一目标。他和几位 OpenAI 同事正筹划一个新项目，据他们所说，新项目可能少一些产品开发、多一些研究。我们支持他们的选择，也感恩共事的时光。

"我们非常感谢 Dario 过去四年半的贡献。祝他和他的联合创始人新项目一切顺利，也期待未来多年与他们保持协作关系，"OpenAI CEO Sam Altman 表示。

在本月初的员工大会上宣布离职消息时，Dario 对同事们说："我要感谢 Sam，感谢每个人。我真的为我们共同完成的工作感到骄傲。祝大家一切都好，我相信 OpenAI 未来会做出非常了不起的事情。我们共享同一个目标——安全的人工通用智能造福人类，因此我们这个领域的每一个人都有责任携手合作，确保一切顺利。"

OpenAI 同时也在做几项组织调整，以更好地聚焦研究、产品与安全的融合。Mira Murati 将出任研究、产品与合作高级副总裁，承担新的职责，这也是对她领导力的肯定——她在 API 推广期间和全公司范围内都展现了出色的领导力。

Sam 补充道："OpenAI 的使命是审慎、负责任地发展通用人工智能。随着新年到来，我们对研究——尤其安全领域——的关注比以往任何时候都更强烈。让 AI 更安全是全公司的优先事项，也是 Mira 新角色的关键部分。"

"GPT‑3 和我们开发的其他 AI 模型仍处于早期阶段，但我们正开始更好地理解它们的行为、如何让模型更安全、如何与人类偏好对齐，"Mira 在谈及新角色时说。"我们的方针是谨慎使用这些模型：既改进人们日常生活中已在使用的产品，也创造新产品——这一切都让我们积累安全部署的经验。同时，我们将继续开展并发布关于 AI 影响与挑战的研究，独立于我们眼前的产品目标。"

1 月，我们的团队将带着新的研究和 API 进展更新归来。

OpenAI 全体祝大家新年快乐！
