# 论一阶元学习算法

阅读论文



## 摘要

本文研究元学习（meta-learning）问题：存在一个任务分布，我们希望在遇到从该分布中采样的、此前从未见过的任务时，agent 能表现出色（也就是学得很快）。我们分析了一类算法，它们只用一阶导数做元学习更新，学出一套参数初始化，使其可以在新任务上被快速微调。这一族算法包含并推广了一阶 MAML（first-order MAML）——通过忽略二阶导数得到的 MAML 近似。它还包含 Reptile，这是我们在这里提出的新算法：反复采样一个任务、在其上训练，然后把初始化朝该任务训练后的权重移动。我们扩展了 Finn 等人的结果，证明一阶元学习算法在若干成熟的少样本（few-shot）分类基准上表现良好，并给出理论分析来帮助理解这些算法为什么有效。
