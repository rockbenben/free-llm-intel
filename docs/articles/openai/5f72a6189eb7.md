# Indeed 借助 OpenAI 为数百万求职者提供带上下文的岗位匹配

[Indeed⁠（在新窗口中打开）](https://www.indeed.com/about) 的使命是帮助人们找到工作，是全球第一的招聘网站[1](https://openai.com/index/indeed/#citation-bottom-1)。每月超过 3.5 亿独立访客[2](https://openai.com/index/indeed/#citation-bottom-2)来到 Indeed，连接超过 350 万雇主和 3,200 多万个职位。更重要的是，每 3 秒就有一人通过 Indeed 成功入职[3](https://openai.com/index/indeed/#citation-bottom-3)。

自创立以来，AI 一直驱动着平台上求职者与雇主之间的数百万次连接，例如“Invite to Apply”（邀请投递）功能会基于简历、Indeed 个人资料和其他资历，向求职者发送 AI 生成的职位推荐。AI 的进步——尤其是生成式 AI——正在以新颖而令人兴奋的方式帮助求职者与岗位相匹配。借助 OpenAI 的 GPT 模型与微调能力，Indeed 强化了“Invite to Apply”功能中的个性化语言，更好地解释候选人的背景或过往经历为何与该职位契合。

## 岗位匹配中的早期 AI 实验

Indeed 的早期 AI 模型能有效地把求职者与雇主职位相匹配，并给出简短的匹配说明。但 Indeed 的产品与工程团队相信，OpenAI 的 GPT 模型可以做得更多：通过理解自然语言，提供更有上下文的解释，说明候选人*为什么*会收到某个具体职位推荐。

为职位推荐添加更有洞察力的“为什么”，成为 Indeed 团队与 OpenAI 合作的目标。

Indeed 的工程团队于 2023 年开始与 OpenAI 合作，按照 Chat Completions API 的 OpenAI 文档开发，并不断迭代其 few-shot prompting。在整个开发过程中，团队进行了严格的 A/B 测试，并在实施阶段和上线后持续监控和评估每一项改动。

## 微调 OpenAI API 以实现个性化匹配解释

Indeed 发现，用 few-shot-prompting 训练模型作答能有效增加解释中有价值的“为什么”，但在 Indeed 的巨大规模下，这导致 token 消耗过高。为提升效率，OpenAI 与 Indeed 共同微调了一个更小的 GPT 模型，能够交付表现相当的结果，而 token 用量减少 60%。

作为微调过程的一部分，他们利用 GPT-4 做数据增强，并制定了专门的内容规范。团队还建立了一套标注流程，包括为 LLM 生成的输出打标签、构建用于自动化评估的基准真值（ground truth），以及补充帮助模型理解细微差异的上下文。

进一步测试验证了职位推荐中个性化表达的价值——它扩大了合格候选人的储备。为了扩展个性化职位推荐，Indeed 与 OpenAI 合作采用专属实例（dedicated instances），并于 2024 年 1 月完成配置。Indeed 工程团队成功将微调后的 GPT 模型部署到这些实例上，从而能够为多得多数百万求职者个性化推荐工作机会。

“数十年来我们一直在投资自研的 AI 匹配技术，以连接求职者与雇主。无论匹配做得多好，可解释性都是任何成功推荐系统的关键。把 OpenAI 的 GPT 解释能力与 Indeed 自有的专有 AI 和庞大的市场数据结合，能让我们更快地把更多人连接到工作——这对求职者、雇主和社会都是共赢。”Indeed CEO Chris Hyams 表示。

## GPT 个性化带来可验证的增长

GPT 生成的个性化信息的实际效果，通过一个多阶段实验得到验证：在数月时间内，实验规模扩大到每天近 2,000 万条信息。

“我们一直在测试各种方法改善 Invite to Apply 体验，为求职者找到更相关的机会。微调 OpenAI 的 GPT 模型帮助我们在日发送量从 100 万增长到 2,000 万的同时，依然交付更个性化的推荐。”Indeed 平台产品经理 Horatio Lun 表示。

Indeed 团队将 Invite to Apply 的传统职位匹配版本与带有面向申请人额外定制上下文的 GPT 版本进行了对比。性能提升立竿见影：

- **职位投递发起量增长 20%**
- **后续环节成功率提升 13%**，表明不仅更多人更愿意投递，而且雇主认为这些申请人确实匹配，最终带来更多录用

通过为“Invite to Apply”功能启用 GPT 驱动的上下文，Indeed 在合格候选人数和录用数上均实现增长，测试期间对营收产生了正面影响。

“重要的是，我们能够以 ROI 为正的方式利用 OpenAI，因此我们看到大量机会继续投资这一新基础设施，以帮助我们增长营收。”Indeed CEO Chris Hyams 表示。

而 Invite to Apply 只是 Indeed 借助 OpenAI 技术取得成功的例子之一。Indeed 已有近十款产品在使用 OpenAI，提供更个性化、更有吸引力的体验，帮助求职者发现新机会、帮助雇主更快招聘。
