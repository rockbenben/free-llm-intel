# Codex 如何成为 OpenAI 创意团队的协作伙伴


*本文是介绍 OpenAI 如何在内部使用自身技术和 API 的系列文章之一。文中介绍的工具目前已在 OpenAI 内部投入使用，我们将其作为示例分享，希望展示前沿 AI 如何支持各团队完成实际工作。*

大多数人认为，Codex 只是为工程师和开发者打造的，但对于 OpenAI 创意专家 Chad Nelson 而言，Codex 已经成为解决创意问题的出色协作伙伴。Chad 的工作是探索 OpenAI 模型能为创意团队带来哪些可能性，然后将这些可能性转化为演示、工作流，以及可供品牌合作伙伴借鉴的创意。

Chad 习惯了在标准创意软件的限制下工作，而 Codex 却给他留下了深刻印象：Codex 能帮助他打造更好的工具、构建自定义工作流，并基于项目的完整背景生成营销活动大纲。

> “I’m actually bringing Codex sketches, storyboards, and design style guides—things that you wouldn’t assume Codex could understand. But it not only understands those things, it actually helps me collaborate and create utilizing those different assets.”

—Chad Nelson, Creative Specialist, OpenAI

## 构建读懂需求简报的自定义工具

“在整个职业生涯中，我所使用的工具根本无法理解我在做什么项目、服务哪个品牌，或者试图推广什么产品，”Chad 说道。“而 Codex 和 ChatGPT 则可以掌握这些背景信息。它们明白我正在为*哪个*客户服务，推广的是*哪款*产品，并且有着*哪些*战略目标。”

Codex 还能理解品牌手册、风格指南、字体和构图 — 有了这些知识，它能更好地契合项目的创意需求。

营销活动的方向取决于它所服务的品牌、产品，以及你希望在作品中传达的情感特质。Chad 发现，Codex 能够整合所有这些背景信息，并跨越不同信息来源协同工作，这是传统工具无法做到的。

他还利用 Codex 来创建和定制工具，以解决特定问题。

通过自然语言，他可以描述自己想要的工作流，并要求 Codex 协助构建。这可能涉及连接 API 密钥、创建原型界面，或者设计一个让他能够探索视觉处理效果的自定义 UI。

“借助 Codex，我能够真正地创建工具、用户界面、滑块和控件，”他说。“我可以调整镜头构图或光影，并打造具有深度和立体感的实时阴影。”

## 拓宽创意的边界

Codex 也在加速创意探索的进程。最近，Chad 只有一天的时间为某位新客户构思一系列营销活动创意。通常情况下，他可能会探索五个方向；如果时间充裕，大概能想出十个。而且其中很多方向可能只是同一个想法的变体。

在 Codex 的帮助下，Chad 首先向系统输入了项目背景：具体品牌及其产品、一些指导原则，以及客户的目标。他还提供了他希望该活动传达何种基调的说明。

仅仅一天的时间，Chad 和 Codex 就合作构思了 50 个营销活动方向，随后他进行了筛选，提炼出 10 个非常有潜力的创意。“Codex 让我能够挥洒创意，以更自由的方式去探索各种不同的选择，”他说。

凭借丰富的创意库，即使时间紧迫，Chad 也能在提案中提供一套更有说服力的方案。

## 更快地将概念转化为原型

对于那些常常拖慢工作进度的环节（如初步构思、工作流设计以及技术实现），Codex 为创意团队提供了强大的助力。

当 Chad 脑海中有了原型的构想，他只需将其描述出来，便能着手构建。如果某个工作流需要依赖新的模态或 API 集成，他可以要求 Codex 协助进行连接。如果遇到瓶颈，他可以用自然语言解释问题，并在不打断创意心流的情况下将问题解决。

对于创意工作者而言，这缩短了创意与执行之间的距离：

- 曾经需要移交他人处理的技术障碍，如今也能融入同一个创作过程之中。
- 创意总监可以直接调整构图和光影控制，而无需编写冗长的提示词。
- 设计师能够直接制作界面原型，而无需等待他人对自定义工具进行需求规划和开发。
- 团队可以探索更多概念，同时始终将人类的判断力放在主导地位。

从更广的层面来看，Chad 的经历展示了创意团队使用 AI 的新方式：在工作成型的过程中，构建出他们所需系统，用于创作、评估并不断打磨创意。

“通过使用 Codex，我学到的一点是，如果你对某个创意工作流、解决方案或界面有了想法，直接向它提问即可，”他说。“告诉它你在想什么，可能短短 10 分钟后，你就能看到该想法的原型了。”
