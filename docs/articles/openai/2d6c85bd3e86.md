# 从仿真中泛化

我们最新的机器人技术让完全在仿真中训练、再部署到物理机器人上的控制器，能在完成简单任务的同时对环境中的突发变化作出反应。也就是说，我们用这些技术构建的是闭环系统，而非此前的开环系统。

仿真器无需在外观或动力学上与真实世界一致；相反，我们对环境的相关方面进行随机化，从摩擦力到动作延迟再到传感器噪声。我们的新结果提供了更多证据：通用机器人可以完全通过在仿真中训练、再在真实世界做少量自校准来构建。

## 动力学随机化

我们开发了[动力学随机化⁠（在新窗口中打开）](https://arxiv.org/abs/1710.06537)技术，训练机器人适应未知的真实世界动力学。在训练过程中，我们对决定环境动力学的九十五项属性进行大规模随机化，例如改变机器人本体每个连杆的质量、被操作对象的摩擦与阻尼、对象所在桌子的高度、动作之间的延迟、观测噪声等等。

我们用这一方法训练了一个基于 [LSTM⁠（在新窗口中打开）](http://colah.github.io/posts/2015-08-Understanding-LSTMs/) 的策略，让机器人在桌面上推动曲棍球球饼。我们的前馈网络在[这项任务上会失败⁠](https://openai.com/index/generalizing-from-simulation/#pusher_fail)，而 LSTM 可以利用过去的观测来分析世界的动力学并相应调整行为。

## 从视觉到动作

我们还在仿真中使用强化学习（RL）端到端地训练了一个机器人，并把得到的策略部署到物理机器人上。由此构建的系统无需特殊传感器即可将视觉直接映射为动作，并能适应视觉反馈。

关于仿真机器人的 RL 成果如此丰富，容易让人以为 RL 可以轻松解决大多数机器人任务。但常见的 RL 算法只在小扰动动作能带来奖励增量变化的任务上表现良好。有些机器人任务的奖励很简单，比如行走——可以按行进距离打分。但大多数任务并[不如此⁠](https://openai.com/index/learning-from-human-preferences/)——要为积木堆叠定义密集奖励，你得编码机械臂接近积木、机械臂以正确姿态接近积木、积木被抬离地面、积木与目标位置的距离等诸多条件。

我们花了数月时间尝试让常规 RL 算法在抓取-放置任务上奏效而未能成功，最终开发了新的强化学习算法[事后经验回放（HER）⁠（在新窗口中打开）](https://arxiv.org/pdf/1707.01495.pdf)，让智能体能够从二元奖励中学习：把失败假装成自己本来就想达成的目标，并据此进行学习。（打个比方：你本想找加油站，结果来到一家披萨店。你仍然不知道哪里能加油，但你现在知道了哪里能吃披萨。）我们还对视觉形状使用[域随机化⁠](https://openai.com/index/spam-detection-in-the-physical-world/)，学出足以应对物理世界的鲁棒视觉系统。

我们的 HER 实现采用带非对称信息的 actor-critic 技术（*actor* 是策略；*critic* 是一个网络，接收动作/状态对并估计其 Q 值即未来奖励之和，为 actor 提供训练信号）。critic 能访问仿真器的完整状态，而 actor 只能访问 RGB 和深度数据。这样 critic 可以提供完全准确的反馈，而 actor 只使用真实世界中存在的数据。

## 代价

两种技术都增加了计算需求：动力学随机化使训练速度降低约 3 倍，而从图像而非状态学习则慢约 5–10 倍。

我们认为构建通用机器人有三条路径：在庞大的物理机器人集群上训练、让仿真器越来越贴近真实世界、以及随机化仿真器让模型泛化到真实世界。我们越来越相信第三条会是解决方案中最重要的一环。
