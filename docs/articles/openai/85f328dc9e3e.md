# 借助美国国家实验室巩固美国的 AI 领导地位

OpenAI 最新的推理模型系列将由国家顶尖科学家使用，以推动科学突破。


我们自豪地宣布，OpenAI 已与美国国家实验室（U.S. National Laboratories）签署协议，用我们最新的推理模型为它们的科学研究强力加速。与国家的顶尖科学家共享我们的技术，与我们"确保 AGI 造福人类"的使命一致，我们也相信美国政府实现这一目标的关键伙伴。

OpenAI 与美国国家实验室的合作，延续了美国政府与私营产业长期协作的传统——确保技术创新转化为医疗、能源等关键领域的切实改善。这也体现了我们一贯的承诺：赋能顶尖开发者安全地利用我们的模型——把数据变成智能，把智能变成解决方案、突破与发现。

国家实验室约有 15,000 名科学家，横跨众多学科，推进我们对自然和宇宙的认知。根据本协议，OpenAI 将与 Microsoft 合作，在 Venado 上部署 o1 或其他 o 系列模型——Venado 是洛斯阿拉莫斯国家实验室（LANL）的一台 NVIDIA 超级计算机，将供洛斯阿拉莫斯、劳伦斯利弗莫尔和桑迪亚国家实验室的研究人员共享。Venado 专为驱动材料科学、可再生能源、天体物理学等领域的科学突破而设计。

我们最先进的模型将在以下关键方向发挥作用：

- 加速支撑美国全球技术领导地位的基础科学
- 发现疾病治疗与预防的新途径
- 增强网络安全，保护美国电网
- 释放自然资源的全部潜力、革新国家能源基础设施，开启美国能源领导的新纪元
- 在生物、网络等自然和人造威胁显现之前加强检测，提升美国安全
- 深化我们对支配宇宙力量的理解——从基础数学到高能物理

国家实验室还主导一项全面的核安全计划，聚焦降低核战争风险、保护全球核材料与核武器。这一用途影响极为重大，我们认为 OpenAI 支持它是我们国家安全承诺的一部分。我们的合作将支持这项工作，并对用例进行审慎、有选择性的审查，由持有安全许可的 OpenAI 研究人员就 AI 安全提供咨询。

随着先进 AI 持续重塑全球地缘政治，这次合作为 OpenAI 提供了引导这场变革的重要机会。这建立在我们与洛斯阿拉莫斯国家实验室[此前成功的合作⁠](https://openai.com/index/openai-and-los-alamos-national-laboratory-work-together/) 之上——当时我们与湿实验室紧密合作，评估最先进模型在制造生物武器（如人类设计的疫情）方面的风险。我们预计这次接触会带来更广泛的安全合作，覆盖化学、生物、放射、核（CBRN）等各类风险。此外，作为我们 AI 算力基础设施的优选合作伙伴，我们以与 Microsoft 的合作为基础，并借鉴与国家实验室合作的宝贵经验，期待未来共同开发更多项目，支持美国政府，并服务于确保 AGI 造福全人类的使命。

这是一个新纪元的开端：AI 将推进科学、巩固国家安全、支持美国政府各项计划。我们深深感激能有机会参与这场变革，感谢国家实验室的领导者们和政府官员对我们的信任，也感谢 Microsoft——我们长久的伙伴关系让这些进展成为可能。
