# GPT-6.1Terra

## 大规模提供快速、强大的计算机操作能力

我们推出了 **GPT-6.1 Terra**：一款快速、高效的模型，兼具细致的视觉推理、精准的计算机操作能力，以及更清晰、更自然的写作表现。 与 GPT‑5.6 Terra 相比，它实现了显著提升，擅长处理日常工作中的各类沟通和计算机任务，从起草提案、解读技术图纸，到填写表单和剪辑视频。

Terra 持续拓展我们各模型系列在成本与智能水平之间的平衡边界，在速度、能力和成本之间实现了新的平衡。其标准 API 价格比 GPT-5.6 Terra 和 GPT-6.1 Sol 低 50%，让开发者能够以可行的成本将大批量工作自动化，例如读取收到的发票并将其详细信息录入会计软件。在 ChatGPT 工作和 Codex 中，使用 GPT-6.1 Terra 能让你的套餐发挥更大价值：相同的使用额度可完成的任务比使用 GPT‑5.6 Terra 更多，比使用 GPT‑6.1 Sol 或 GPT‑6 Astra 则要多得多。

## 从视觉理解到实际行动

我们使用 **Agents’ Last Exam** 来评估 GPT-6.1 Terra 的计算机操作能力。这项专业任务基准测试涵盖了将建筑图纸转换为 3D 模型，以及逐镜头审看动画电影、为修复团队创建带时间码的记录等任务。在中等推理强度下，GPT-6.1 Terra 的得分比 GPT-5.6 Terra 高出 15 个百分点，而成本约为后者的三分之一。它的表现甚至可与 GPT-6 Astra 相媲美，而每个 Token 的价格仅为后者的十分之一。在最高推理强度下，Terra 的 Token 使用效率是 Claude Opus 5.5 的三倍以上，每个 Token 的价格为后者的四分之一，因此每项任务的成本约为后者的九分之一。Terra 的速度也快得多，完成任务的速度是 GPT-6 Astra 和 GPT-6.1 Sol 的**三倍以上**。

在视觉推理基准测试 **MMMU-Pro** 中，GPT-6.1 Terra 在所有推理设置下的表现均优于 GPT-5.6 Terra。它甚至以低得多的成本，取得了接近我们能力最强的前沿模型 GPT-6 Astra 以及 GPT-6.1 Sol 的分数。

**OSWorld 2.1** 测试 AI 智能体使用桌面应用完成多步骤任务的能力，例如根据技术图纸构建 3D 模型。 推理强度设为“中”时，GPT-6.1 Terra 就能超越 GPT-5.6 Terra 的最佳成绩，而每项任务的成本仅为后者的一小部分。

## 事实准确性与编程能力显著提升

今年，我们投入了大量资源，以减少模型产生的幻觉和事实错误。 在我们由易诱发错误的提示词构成的内部基准测试中，低推理强度下的错误率从 GPT-5.6 Terra 的 53.6% 降至 GPT-6.1 Terra 的 16.7%，下降了近 37 个百分点。 在最高推理强度下，错误率下降了 18 个百分点，降至 4.3%，接近 GPT-6 Astra 和 GPT-6.1 Sol 的水平。

在软件工程方面，GPT-6.1 Terra 相比 GPT-5.6 Terra 实现了大幅提升。 **Terminal-Bench 4.0** 测试编程智能体通过命令行解决问题的能力，例如修复加载时出现布局偏移的网页。 在最高推理强度下，GPT‑6.1 Terra 能够解决 50.3% 的任务，超过 GPT‑5.6 Terra 已公布成绩 21.5% 的两倍。 对于最复杂的编程任务，GPT-6.1 Sol 和 GPT-6 Astra 仍然是更好的选择。

**Terminal-Bench-Science 0.1** 测试智能体使用代码执行科研任务的能力，例如追踪延时视频中的细胞分裂。 在最高推理强度下，GPT-6.1 Terra 以更低的成本超越了 GPT-6.1 Sol，与 Opus 5.5 的分差不到五分，而估算成本还不到其五分之一。

## 安全与对齐

在让强大的 AI 更高效、更易于获取和使用的同时，我们也持续开展训练和测试，并完善安全防护措施。GPT‑6.1 Terra 达到了我们准备框架中网络安全领域的“严重”风险阈值，并保留了为 GPT‑6 Astra 开发的防护措施。

GPT-6.1 Terra 延续了 GPT-6 系列在对齐方面的改进。我们的评估显示，与 GPT-5.6 Terra 相比，GPT-6.1 Terra 更有可能在任务范围内行事，并如实向用户说明自身局限和潜在障碍。在我们的提示词注入测试中，GPT-6.1 Terra 对旨在使其偏离用户任务的恶意指令也表现出了很强的抵抗力。更多详情请参阅[系统卡](https://deploymentsafety.openai.com/gpt-6-1-terra)。

## 定价与可用性

即日起，所有 Plus、Pro、Enterprise 和 Edu 用户均可在 ChatGPT 工作和 Codex 中使用 GPT-6.1 Terra。 开发者也可以通过 OpenAI API，以 `gpt-6.1-terra` 调用该模型。

标准 API 定价为：每百万输入 Token 1 美元，每百万缓存输入 Token 0.05 美元，每百万输出 Token 5 美元。
