# OpenAI 收购 Global Illumination

整个团队已加入 OpenAI。

OpenAI 已收购 [Global Illumination](https://ill.inc/) 团队。该公司由 Thomas Dimson、Taylor Gordon 和 Joey Flynn 创立。整个团队已加入 OpenAI，参与我们包括 ChatGPT 在内的核心产品工作。Global Illumination 一家一直在利用 AI 构建创意工具、基础设施和数字体验的公司。该团队此前曾在 Instagram 和 Facebook 早期负责产品设计与构建，也在 YouTube、Google、Pixar、Riot Games 及其他知名公司做出过重要贡献。我们非常期待他们在 OpenAI 创造的影响。
