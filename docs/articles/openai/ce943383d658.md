# 用 ChatGPT Work 处理财务工作流

了解财务团队如何借助 ChatGPT Work，为月度经营回顾、报告、差异分析和规划构建可审阅的成果。

借助 ChatGPT Work，财务团队可以更快地把真实的工作输入变成可审阅的交付物。从你已在使用的结账工作簿、收入与支出仪表盘、预测更新、以往的月度经营回顾和负责人笔记出发，ChatGPT Work 帮助把这些上下文转化为团队可审阅、可完善、可分享的具体成果，而且无需编写代码。使用它可以让你少花时间拼凑第一稿，把更多时间用于打磨叙事、核验数字和准备下一个决策。

可在我们的[点播网络研讨会](https://academy.openai.com/home/clubs/work-users-ynjqu/videos/codex-for-everyday-work-recording-2026-05-06)中了解如何用 ChatGPT 处理日常财务工作。
