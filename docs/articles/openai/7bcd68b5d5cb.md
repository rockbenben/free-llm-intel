# 企业 AI 的下一阶段

来自首席营收官 Denise Dresser 的一封信

我在 OpenAI 的第一个 90 天刚刚结束，有机会会见了数百位客户。最令我触动的是他们强烈的紧迫感与准备度。我的整个职业生涯都处在技术与企业转型的交汇点，然而我从未见过这样的信念以如此快的速度、如此一致地席卷各行各业。这些领导者认识到 AI 是他们这一生最具决定性的变革，他们在向我们请教如何围绕 AI 重塑自己的公司。

本季度我们的业务表现也反映出这种信念。依托消费端的强势，企业收入现已占我们营收的 40% 以上，并有望在 2026 年底与消费端持平。Codex 刚刚达到 300 万周活跃用户，我们的 API 每分钟处理超过 150 亿 token，GPT-5.4 正在推动 agentic 工作流上的创纪录使用量。我们看到来自 Goldman Sachs、Phillips、State Farm 等新客户的需求，也在与 Cursor、DoorDash、Thermo Fisher、LY Corporation 等既有客户共同成长。

显然，我们已经过了实验阶段。AI 正在做真正的工作，因此每家公司都在面对两个核心问题：

- 我们如何把最强的 AI 应用到整个业务，而不仅仅是个别的 co-pilot 和助手？
- 我们如何让 AI 融入人们的日常工作，帮助他们释放全部潜能？

这些问题将决定企业在未来几年如何运营和竞争，而我们的企业战略正指向这一点：Frontier 作为治理公司全部 agent 的底层智能层，统一的 AI superapp 作为员工解决问题的首要体验入口。

OpenAI 处于塑造企业 AI 未来的独特位置，因为我们是少数构建全栈的公司之一——从基础设施、模型到员工每天使用的界面。我们在倾听客户，并迅速成为 AI 的核心基础设施，让全世界的人们和大大小小的企业能够放心构建、自信迈入工作的未来。

## 让 agent 服务于全公司

正如我们此前分享过的，世界正处于[能力溢出⁠](https://openai.com/index/ai-for-self-empowerment/)（capability overhang）阶段——AI 模型已经能做到的事，远超大多数人和企业今天用它们做的事。我们致力于弥合这一差距，让前沿智能可用、可信，并嵌入到工作真正的完成方式中。

我反复听到的一句话是：企业已经受够了互不打通、只会制造混乱的 AI 单点方案。他们希望 AI 成为业务的统一操作层——AI 同事扎根于公司上下文，连接内部系统和外部数据源，并受恰当的权限与管控约束。这正是 [OpenAI Frontier⁠](https://openai.com/index/introducing-openai-frontier/) 提供的东西，它正在帮助 Oracle、State Farm、Uber 等客户在全公司范围构建、部署和管理 agent。其他方案把 agent 嵌入单一产品或环境，而 Frontier 让 agent 能穿梭于公司的系统与数据之间，跨工具工作，并随时间持续进化。

在作为一家构建前沿模型的研究公司之外，我们还是一家部署公司。我们把与数百家大型企业在集成 AI agent 上直接合作所学到的东西，变成了可扩展的基础设施。我们与 [Frontier Alliances⁠](https://openai.com/index/frontier-alliance-partners/) 合作伙伴 McKinsey & Company、Boston Consulting Group（BCG）、Accenture、Capgemini，以及 Amazon Web Services（AWS）、Databricks、Snowflake 等其他伙伴一起，帮助企业把 OpenAI 的智能集成进他们已在依赖的基础设施与数据生态。例如，我们与 AWS 共同打造的[有状态运行时环境（Stateful Runtime Environment）⁠](https://openai.com/index/amazon-partnership)让 agent 可以轻松保持上下文、记住先前的工作，并在企业的工具与数据间操作，从而在处理复杂真实用例时有效得多。

## 赋能个人与团队

随着 AI 在全公司扩展，它也必须毫不费力地出现在每个人、每个团队的日常工作中。这就是我们在构建统一 AI superapp 的原因：一个员工全天与 AI agent 一起工作、在已有工具上完成任务并执行操作的地方。这一体验将集 ChatGPT、Codex、agentic 浏览以及更广泛能力之大成，成倍放大个人员工和小团队所能完成的事。

最近几个月，我们看到一种转变：走在最前面的人已经从“用 AI 帮忙做任务”转向“管理 agent 团队替他们做任务”。这一转变始于 Codex 等 agentic 工具——自年初以来其使用量增长了 5 倍以上。其中包括 GitHub、Nextdoor、Notion、Wonderful 等客户，它们在构建能端到端执行工程工作的多 agent 系统。我们还开始看到各部门的员工在自身工作流中采用 agent。例如，我们的销售团队用一个 agent 引入新业务：该 agent 研究入站线索、按标准打分、向合格线索发送个性化邮件，并替他们更新 CRM。

我们很高兴为企业带来让 agent 对每个人都更易得的新方案。OpenAI 最大的优势之一是连接个人与职业场景的能力。ChatGPT 有 9 亿周用户，这意味着员工已经知道如何与它协作。对企业来说，这减少了推广摩擦，加速到来每位员工都能把繁琐任务委派出去、承担更雄心项目的时刻。

--

在 OpenAI 的第一个季度让我比以往任何时候都更确信：AI 转型正比多数人意识到的更快发生。企业需要一个理解这场转型规模、能帮助他们自信前行的伙伴。这意味着在他们已依赖的系统中与他们相遇，给他们一条从实验到部署的务实路径，并通过恰当的定价与打包让采用更容易。最重要的是，他们希望信任那个帮助他们完成转型的公司——一个真正投资他们的成功、为他们需求而建的公司。

在 OpenAI，我在每个层级、每个职能都感受到这份投入。我们全心专注于持续赢得一项权利：帮助企业——以及企业背后的每个人——以清晰、信心和信任，为 AGI 的未来重塑公司。这是一生的机遇与责任，对于我们正在与客户和伙伴共同构建的东西，我再兴奋不过。
