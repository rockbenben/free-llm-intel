# OpenAI 的技术目标

OpenAI 的使命是构建安全的 AI，并确保 AI 的收益尽可能广泛、均衡地分配。

我们试图作为一个更大社区的一部分来构建 AI，也希望一路分享我们的计划与能力。我们同时在巩固组织的治理结构，将于今年晚些时候分享相关思考。

### 我们的度量指标

为智能定义一个度量指标并不容易，但我们需要一个来衡量进度、聚焦研究。因此，我们正在构建一个“活”的指标，用来衡量一个 agent 在广泛环境中达成用户预期目标的能力。

## 目标 1：衡量我们的进展

该指标将由一系列共享统一动作与观测[空间](https://gym.openai.com/docs#spaces)的 [OpenAI Gym](https://gymlibrary.dev/) 环境组成（这样单个 agent 可以通跑所有环境），涵盖游戏、机器人和语言任务。我们的实现会随时间演进，并将持续向社区同步。

### 我们的研究

我们把相当比例的研究精力投入基础研究。我们将不断开发和检验新想法，尤其是那些难以被现有世界观容纳的想法。这一点很重要——以我们现在的想法，不足以实现长期目标。

## 目标 2：打造一台家用机器人

我们正在努力让一台实体机器人（现成货架产品，非 OpenAI 制造）完成基本家务。针对特定任务已有[定位](https://en.wikipedia.org/wiki/Simultaneous_localization_and_mapping)[建图](https://en.wikipedia.org/wiki/Motion_planning)技术，但我们相信学习算法终将变得[足够可靠](http://www.bloomberg.com/features/2015-preschool-for-robots/)http://www.theverge.com/2016/3/9/11186940/google-robotic-arms-neural-network-hand-eye-coordination，造出通用机器人。更广泛地说，机器人是检验 AI 众多难题的良好试验场。

## 目标 3：构建具备有用自然语言理解能力的 agent

我们计划构建一个能执行由语言指定的复杂任务、并在任务含糊时主动要求澄清的 agent。如今，监督类语言任务已有不少有前景的算法，如[问答](http://arxiv.org/pdf/1503.08895.pdf)https://arxiv.org/pdf/1601.01705v4.pdf、[句法](http://arxiv.org/pdf/1603.06042.pdf)[分析](https://arxiv.org/pdf/1412.7449.pdf)和[机器](http://arxiv.org/pdf/1409.3215.pdf)[翻译](https://arxiv.org/pdf/1409.0473.pdf)，但对于更高阶的语言目标——如持续对话、完全理解一篇文档、遵循复杂的自然语言指令——还没有可用的算法。我们预计要为这些问题开发新的学习算法和范式。

## 目标 4：用单个 agent 解决多种游戏

我们要训练一个足够强大的 agent，能解决我们初始指标中的任何游戏。游戏是高度多样化的虚拟微世界，要快速而出色地学会玩游戏，需要在[生成模型⁠](https://openai.com/index/generative-models/)和[强化学习](http://karpathy.github.io/2016-05-31/rl/)上取得重大进展。（我们深受 [DeepMind](https://deepmind.com/) 开创性工作的启发——过去几年他们在该领域取得了[令人瞩目的](http://www.nature.com/nature/journal/v518/n7540/full/nature14236.html)[成果](http://www.nature.com/nature/journal/v529/n7587/full/nature16961.html)。）

我们的项目和基础研究都有共享的内核，任何一项的进展都可能惠及其余。每个项目都捕捉了目标达成的不同侧面，并因其显著推进我们指标的潜力而被选中。

这些项目我们才刚起步，随着获得更多数据，细节可能变化。我们也预计会不断加入新项目。
