# 借大模型进化

## 摘要

本文秉持这样一个洞见：经训练生成代码的大语言模型（LLM），能大幅提升遗传编程（GP）中施加于程序的变异算子的有效性。由于这类 LLM 的训练数据包含连续的变化与修改，它们可以近似人类可能做出的改动。为了凸显这种"借大模型进化"（evolution through large models, ELM）的广泛意涵，在主实验中，ELM 结合 MAP-Elites 生成了数十万个可用的 Python 程序实例，能在 Sodarace 领域输出可正常行走的机器人——而原始 LLM 在预训练中从未见过该领域。这些实例进而帮助自举训练一个新的条件语言模型，使其能针对特定地形输出合适的行走器。在一个此前零训练数据的领域里，自举出可为给定语境输出恰当产物的新模型——这种能力对开放式学习（open-endedness）、深度学习和强化学习都有深远含义。本文深入探讨这些含义，期望激发 ELM 所开启的研究新方向。

**作者**：Joel Lehman、Jonathan Gordon、Shawn Jain、Kamal Ndousse、Cathy Yeh、Kenneth O. Stanley
