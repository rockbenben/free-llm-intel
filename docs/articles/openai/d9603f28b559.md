# Zelma

Zelma 用 GPT‑4 让教育数据变得人人可用。


Zelma 是一个由 GPT‑4 驱动的研究助手，它正在让美国各地的家长、教师、学校管理者和政策制定者都能用上教育数据。

他们在解决什么问题？在美国，3 到 8 年级的每一名学生都会参加标准化考试，但关于学生表现的数据却基本没被挖掘、也没被好好利用，散落在不同来源、不同格式里。考试数据能有力揭示学生在英语语言艺术（ELA）和数学上学得怎么样，可以细到学区和人群分组层面。可那些本可以塑造教育未来的关键洞见，对大多数家长、记者、教育工作者和政策制定者来说其实遥不可及。

认识到这个缺口，Brown 大学经济学家、畅销书作者 Emily Oster 博士决定改变这一局面。"Zelma 让家长和政策制定者都能用大白话，就地拿到针对自己最关心问题的教育洞见，"Oster 博士解释。Zelma 是怎么做到的？Oster 博士在 Brown 大学带的学生研究团队花了一年时间收集数据，并把它细致地清洗成统一格式。随后 Zelma 与 [Novy](https://www.novy.ai/) 合作，用 OpenAI 的 API 让这些数据活起来。

Novy 用 [function calling（函数调用）](https://platform.openai.com/docs/guides/function-calling) 来告诉 GPT‑4 展示数据时可以从哪些可视化和字段中挑选。为了 Zelma 的"Ask a Question"（提个问题）视图，他们[微调](https://platform.openai.com/docs/guides/fine-tuning) 了一个模型，做出一个"数据感知"的输入联想，能根据有数据可答的问题来提示用户。他们还把已知正确的示例图表[做嵌入⁠](https://openai.com/blog/introducing-text-and-code-embeddings) 并存进向量数据库，用来提升棘手边缘情形的准确率。

最大的挑战是猜人们会怎么措辞自己的问题，同时把提示词保持在 Zelma 的知识范围之内。"我们通过有意设计 Zelma 的用户体验来解决这一点，用设计去引导用户提出 Zelma 能回答的问题，"Oster 博士解释。关键做法包括：

- **给出示例提示词。** 由于 Zelma 只覆盖教育数据中的一个特定领域，这些建议能帮助用户理解 Zelma 的知识范围，以及该怎么措辞自己的提示。
- **把所有问题公开。**⁠（[在新窗口打开](https://www.zelma.ai/featured)）这样大家能从别人问过的问题里学习，同时也阻止用户提交大量无关查询。
- **展示 SQL 代码。** Zelma 会给出自己的推理逻辑，帮你快速核对答案。对不写代码的人，它也会用大白话解释涉及的各项因素。
- **解释背景。** Zelma 会通过定义和标记值得注意的事件（比如全州测评的变化）来提供上下文，帮你理解可能影响某一年数据的外部因素。

现在，你可以一键列出[明尼苏达州数学表现最好的 5 个非特许学校学区](https://www.zelma.ai/q/4DGXDNgmrg)，然后发现它们的达标率都在 77% 上下。而一句简单的提示，就能浮现出[加州历年 ELA 成绩中的种族差异](https://www.zelma.ai/q/Bwa3h5FFss)，同时提示 2015 年测评有过变动，因此 2015 年及之后的成绩与之前年份不可比。

这意味着校董会成员可以在开会时用 Zelma 快速生成数据可视化，让决策建立在数据之上。家长可以比较周边学区的历史考试成绩，从而更明智地决定在哪儿养育孩子。州长的幕僚长可以引用 Zelma，找出本州表现最好的学校，并查看这些年的成绩变化幅度。

> "Zelma 给 K-12 学区负责人提供了一个直观、对话式的平台，能即时把学生学习数据可视化——这些视图过去往往要学区领导团队花上几小时甚至几天才能做出来。通过把这份数据平民化，Zelma 让系统里的成年人更容易就学生结果展开具体对话，也把公众注意力引向学生福祉。"

Caitlin Sullivan，Leading Now 联合创始人兼执行总监

从分散的数据门户和电子表格，到一个好用的网站，Zelma 把零散数据变成了有意义的分析。Zelma 与其他用例一起——[在课堂上支持教师⁠](https://openai.com/blog/teaching-with-ai)、[帮助学生按自己的节奏学习⁠](https://openai.com/customer-stories/khan-academy)——共同展示了生成式 AI 能如何加强我们的教育体系。Zelma 也是一个有力的例子，说明 OpenAI 的工具与产品可以怎样让数据对所有人更有用、更易获取。
