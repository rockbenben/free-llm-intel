# 与《大西洋月刊》的内容与产品合作

我们让《大西洋月刊》的报道与故事对我们的数百万用户更易被发现。

*编者按：这条消息最初由《大西洋月刊》发布，原文见[此处](https://www.theatlantic.com/press-releases/archive/1857/11/atlantic-product-content-partnership-openai/678529/)。*

今天，《大西洋月刊》（*The Atlantic*）宣布与 OpenAI 建立战略内容与产品合作，使其成为 OpenAI 旗下的高端新闻源。*The Atlantic* 的文章将在包括 ChatGPT 在内的 OpenAI 产品中被发现；作为伙伴，*The Atlantic* 还将参与塑造新闻在未来实时发现产品中如何呈现与展示。检索出 *The Atlantic* 内容的查询会附带署名，并链接到 [theatlantic.com](http://theatlantic.com/) 阅读全文。

作为协议的一部分，*The Atlantic* 与 OpenAI 还在产品与技术上协作：*The Atlantic* 的产品团队将获得 OpenAI 技术的优先访问权，提供反馈并分享用例，以塑造并改进 ChatGPT 及其他 OpenAI 产品中的未来新闻体验。*The Atlantic* 目前正在开发一个名为 Atlantic Labs 的实验性微型网站，探索 AI 如何帮助开发新产品与新功能，以更好地服务其新闻业与读者——并将试点 OpenAI 及其他新兴技术于其中。

"我们相信，用 AI 模型进行搜索，终将成为人们浏览互联网的根本方式之一，"*The Atlantic* CEO Nicholas Thompson 表示，"我们很高兴与 OpenAI 合作，让《大西洋月刊》的报道与故事触达其数百万用户，并在新闻如何呈现于其平台上拥有发言权。"

"在我们的产品中接入《大西洋月刊》的报道，将让用户更深入地与发人深省的新闻互动。我们致力于支持高质量新闻与出版生态，"OpenAI 首席运营官 Brad Lightcap 说。

*The Atlantic* 正在最大化其雄心：在坚守卓越新闻的同时推动全公司增长——延续近期宣布的里程碑：订阅量突破 100 万并[实现盈利](https://www.theatlantic.com/press-releases/archive/2024/03/atlantic-tops-1-million-subscriptions-and-profitability/677905/)。它追求像与 OpenAI 这样的合作——这些合作认可《大西洋月刊》独立新闻与叙事的巨大价值，并以负责任的方式开拓读者增长与可发现性。4 月，*The Atlantic* 连续第三年荣膺 2024 年全国杂志奖（National Magazine Awards）的最高荣誉[综合卓越奖](https://www.theatlantic.com/press-releases/archive/2024/04/the-atlantic-wins-top-honor-at-national-magazine-awards/677949/)——这是美国杂志编辑协会年度评奖中最具分量的类别，并另获三项报道奖。该刊还在 2021、2022 和 2023 年首次摘得普利策奖，其获奖作品体现了它新闻的深度与广度。
