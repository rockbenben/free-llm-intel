# Paradigm：用 AI 改善患者获取临床试验的途径

Paradigm 使用 OpenAI 的 API 改善患者获取临床试验的途径。

查看产品

临床试验是我们发现新疗法的方式，也可能是一种挽救生命的治疗手段。[Paradigm](https://www.paradigm.inc/) 正在用技术打破医疗行业的壁垒——把临床试验带给更多人（例如癌症患者），同时减少医生和护士的文书负担，应对临床医生的职业倦怠。

## 临床试验入组机制失灵

评估患者病历，是让患者入组某个可能提供最佳治疗选项的临床试验的主要瓶颈。医疗服务提供者很少有时间去检索临床试验、理解正在开展的试验细节，然后再对患者进行匹配和资格审核。结果是：大多数临床试验被离试验地点近的患者填满，造成筛选过程的偏差，并让许多患者无法获得本可救命的开创性治疗。

为解决这一问题，Paradigm 部署并优化了传统最佳实践——医疗领域专用的 ML 与 NLP 模型，用于抽取和解读病历数据。这些模型在由资深临床医生策划的黄金数据集上训练和评估。然而，这种方式既慢又繁重。

> “我们部署了经过微调的顶尖医疗模型，还做了进一步优化。你要花大量时间，而且必须逐用例处理：每一类信息都要单独构建、训练和验证一个模型。”

Paradigm 首席战略官 Jonathan Hirsch

由于传统模型的效果有限，必须由临床医生人工复核模型输出，以确认达到质量标准。

## 用 GPT-4 评估临床试验数据集

Paradigm 认为，LLM 具备总结非结构化文本的能力，很适合他们的用例，可以取代一次性的 ML 建模方式。他们探索了两条路：接入在医疗用例上训练的定制 LLM，或通过 OpenAI 的 API 接入 GPT-4。

Paradigm 原以为需要一个专业的医疗模型才能取得好结果。他们“震惊地”发现，在复杂的数据评估任务上，GPT-4 的表现超过了一支训练有素的人类专家团队。

最终，他们选择 OpenAI 的理由有几点：

- **准确率**：Paradigm 在专家策划的黄金数据集上做了严格评估。GPT-4 在精确率/召回率混合指标上至少比最先进（state-of-the-art）的 ML 模型高 10%。有些情况下，他们看到了“难以置信”的提升。“OpenAI 的准确率高于我们对行业最佳实践、专家训练模型的既有部署和优化，有时甚至超过我们受训的临床医生。”Hirsch 说，“信息越复杂、分布的位置越多，GPT-4 就越好。”
- **易用性**：“从产品角度看，一切都很轻松。API 好用，也容易集成进我们的技术栈。”团队还欣赏 OpenAI 支持中包含的高质量 API 文档：“与其他机构相比，我们在使用 OpenAI 时更能自给自足。”
- **多模态输入与长上下文窗口**：这两个特性对病历数据都至关重要。
- **安全与监管合规**：“真正说服我们与 OpenAI 合作的，是你们对支持监管合规的严肃态度，包括支持我们满足 HIPAA 要求。既然我们服务于医疗机构和患者，监管合规对我们是不可妥协的要求。”

## GPT-4 提升产品速度、数据质量并降低运营成本

- **抽取新数据元素只需几天而非几个月**：GPT-4 颠覆了 Paradigm 对核心基础设施的思考方式，彻底取代了为每个数据组件逐一构建 ML 模型的过程。这大大加速了 Paradigm 的产品路线图，使他们能够快速拓展新的合作医疗机构和试验类型。
- **模型验证所需的资深临床医生时间减少 90%**：Paradigm 估计，与以往专用 ML 模型相比，评估 GPT-4 的输出只需要十分之一的数据量。
- **准确率提升 10%**：数据比以往更准确——在许多情况下甚至超过人类专家——GPT-4 减少了模型结果对专家人工干预的需求。Paradigm 及其合作医疗机构的医生和护士得以把更多时间花在患者护理上，而不是阅读文档。
- **更公平地获取试验机会**：虽然仍在验证中，Paradigm 相信 GPT-4 能更准确地为服务不足的患者做试验筛查。这些患者的病历往往结构化数据更少、非结构化数据更多（如笔记），而这正是 GPT-4 擅长抽取和解读的。

## 每分钟评估数百名患者

展望未来，Paradigm 对如何利用 GPT-4 的自然语言理解能力进一步减轻临床医生负担感到兴奋。临床团队无需编写代码来分析数据，而是可以直接就患者数据与 ChatGPT 对话，了解患者的试验资格、缺失信息和下一步行动。

Paradigm 对如何继续提升患者筛查速度充满信心。借助 GPT-4，他们的平台有望**每分钟评估数百名患者**。作为对比，一位典型的护士研究协调员每天大约只能人工审核 50 名患者*。这些效率提升可以带来这样一个世界：患者能更容易地获得临床试验机会，医生和护士能把更多时间用于患者护理、更少时间用于文书，新的救命疗法也能更快上市。
