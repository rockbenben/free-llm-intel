# OpenAI Codex 联动 Figma：实现代码与设计的无缝衔接


要点：

- 全新的 Codex 到 Figma 集成，帮助用户在代码与设计画布之间无缝切换，更快迭代并交付产品。
- Figma MCP Server 将 Codex 直接连接到其设计平台以及 Figma Make 和 FigJam 等工具。
- 这一全新集成拓展了两家公司之间的合作伙伴关系，其中包括在 ChatGPT 中提供 Figma 应用，以及将最新的 OpenAI 模型引入 Figma 平台。

OpenAI 与 Figma 正通过一项全新的代码到设计集成加深双方合作，将 Figma 直接连接到 Codex。产品构建者可以轻松从 Codex 生成 Figma 设计，也可以把 Figma 文件中的设计转化为代码实现。

Figma 是一个设计和产品开发平台，让团队可以实时共同创建、制作原型并迭代数字产品。借助 MCP 这一开源标准（它让 AI 智能体能够与外部数据源、应用和工具对接），Codex 到 Figma 的集成为团队在代码实现与设计画布之间切换提供了一种更快、更顺畅的方式。

在实际使用中，团队可以将 [Figma Design](https://www.figma.com/design/)、[Figma Make](https://www.figma.com/make/) 或 [FigJam](https://www.figma.com/figjam/) 中的细节带入 Codex，用代码来实现这些设计。通过这一全新集成，用户现在还可以把代码中的 UI 转换成可编辑的 Figma 设计，在把改动带回代码之前，先在画布上探索新想法和不同迭代方案。

这带来了全新的双向往返工作流，让 Figma 和 OpenAI 的用户可以从任何一个环节出发，在兼顾速度与匠心品质的前提下不断推进。无论产品想法最初是来自提示词、代码还是设计，Figma MCP Server 都能连接其中最好的创意，并在整个过程中确保上下文不会丢失。

“随着构建软件的门槛不断降低，软件的产出量将呈指数级增长。问题不再是你*能不能*做，而是*做什么*以及如何让它脱颖而出。”Figma 首席设计官 Loredana Crisan 表示，“通过这项集成，团队可以在最佳想法的基础上构建，而不仅仅停留在第一个想法上，并把优秀的代码能力与 Figma 无限画布可提供的创造力、协作体验和匠心水准结合起来。”

“这项集成让 Codex 为更广泛的构建者和企业带来更多价值，因为它不再刻意区分用户的初始身份是设计师还是工程师。”Codex 产品负责人 Alexander Embiricos 表示，“工程师可以在不打断工作流的情况下进行可视化迭代，设计师则可以在不必成为全职程序员的前提下，更接近真实的代码实现方式进行工作。角色之间的边界开始变得模糊，因为系统会持续在设计意图与最终成果之间进行转换。”

全新的 Codex 到 Figma 集成建立在两家公司坚实的合作基础之上。Figma 在其平台上的多款工具中使用 OpenAI 模型，并且是 2025 年最早上线 ChatGPT 应用的合作伙伴之一。Figma 还在整个组织内部部署了 ChatGPT Enterprise，帮助员工全面提升 AI 素养。

**延续 Codex 的发展势头**

Codex 于 2025 年 1 月首次以 CLI 形式发布。Codex 将最强大的智能体编码模型与直观的产品体验结合在一起，融入构建者和开发者的工作流 — 现已覆盖终端 CLI、IDE 扩展、网页端，此外，适用于 macOS 的 [Codex 桌面应用](https://openai.com/index/introducing-the-codex-app/)也已上线。

Codex 应用通过无缝体验，让用户可以与智能体进行多任务协作，并实现后台工作流自动化。将 Figma 连接到 Codex，即可把“代码优先”工作流的高效便捷，与协作型画布的精细设计结合起来，解锁一种强大的新方式，实现从原型到生产应用的全流程支持。

全球各地的构建者日益将 Codex 视为从想法到落地的协作伙伴。每周有超过 100 万人使用 Codex；自今年年初以来，Codex 的使用量增长了 400% 以上。从产品设计师、数据科学家，到工程师、研究人员和产品构建者，大家都在使用 Codex 缩短从灵感到应用之间的距离。

Cisco、NVIDIA、Ramp 和 Datadog 等公司正采用 Codex 赋能员工，Harvey、Sierra 等初创公司也迎头赶上。

要开始体验，只需在 Codex 桌面应用中直接安装 [Figma MCP Server](https://help.figma.com/hc/en-us/articles/32132100833559)。
