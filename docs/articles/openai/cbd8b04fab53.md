# Scott Wu：OpenAI o1 与编码

欢迎认识 OpenAI o1——一系列全新的人工智能模型，设计上更注重在回应前进行深入思考。这一系列新 AI 模型能够处理复杂任务，跟以往模型相比，能够解决科学、编码和数学领域更具挑战性的问题。

> “编写能够稳定运行且表现优异的代码需要付出巨大努力。而我认为现在真正令人兴奋的是，每个人都将能够编写出更多这样的代码。”

Scott Wu，Cognition 首席执行官兼联合创始人
