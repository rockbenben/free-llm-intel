# 在 ChatGPT 中使用项目

用共享上下文和历史，把工作组织进专属空间。

ChatGPT 中的项目（Projects）是为某项具体工作或某个关注领域设立的专属空间。一个项目可以在一处保存对话、文件、指令和相关上下文，让你不必每次开始新对话时重复交代同样的背景。

项目对持续数日或数周的工作尤其有用。你不必把材料散落在多个独立对话里，而是可以把所有东西集中在同一处，需要时回到同一上下文中。在某些套餐上，你还可以邀请他人在项目内协作。

## 如何创建项目

- 从左侧菜单打开 **Projects（项目）**。
- 创建一个新项目并命名。
- 随后你可以添加文件、设置项目指令，或把已有对话移入项目。如果你的套餐支持共享，还可以邀请协作者。

*对于 ChatGPT Enterprise 客户，管理员可以在工作区层面管理共享项目。可用性也可以通过基于角色的访问控制按组管理。*

## 项目为什么有用

人们使用 ChatGPT 的很多事情会超出单次对话的范围。你可能想在几天里反复研究一个主题、分阶段打磨一份草稿，或随时间补充材料。

没有项目时，这些上下文会变得分散。你可能需要重复上传同样的文件、重复同样的指令，或在过去的对话里翻找你曾经做过的工作。

项目通过把相关材料——对话、文件和指令——保持在同一处来解决这个问题。这创造了更稳定的工作上下文，让你更容易接续上次进度，长期产出更一致的结果。

## 什么时候该用项目

一个经验法则是：当你的工作存在持续上下文时，就用项目。可能包括：

- 一个你在一段时间里持续研究的主题
- 一个有多个草稿版本的写作项目
- 一个周期性的规划流程
- 一组围绕同一目标的文件和对话
- 一个需要多人访问相同材料的共享工作

如果你的任务简短且自包含，普通对话可能就够了。如果你预计会反复回来，项目通常是更合适的选择。

## 示例用例

项目的用例很广泛。根据你组织信息的方式，它们对工作和个人用途都同样有用。

| **场景** | **项目如何帮忙** |
| --- | --- |
| 持续研究 | 把笔记、源文件和相关对话放在一起，让你能在已有工作上继续构建 |
| 写作与编辑 | 把草稿、参考材料和指令存在一处，让各次修改保持关联 |
| 规划 | 围绕一个目标组织计划、想法和支持文档 |
| 学习一个主题 | 把问题、学习材料、总结和后续对话汇集在一起 |
| 个人事务管理 | 帮助管理周期较长的事情，如旅行规划、求职、预算或重大决策 |
| 共享协作 | 在支持共享时，让协作者访问相同的文件、指令和对话历史 |

## 仅项目记忆

创建项目时，你可能可以选择**仅项目记忆（project-only memory）**。该设置通过把聊天上下文限制在项目内，让项目保持自包含。

启用仅项目记忆后，对话可以引用同一项目内的其他对话，但不会引用项目之外的对话。当你想把某个工作领域隔离开、或在项目之间维持清晰边界时，这很有用。

## 共享项目

在支持的套餐上，项目可以分享给他人。共享项目让协作者在同一项目内基于相同的文件、指令和对话历史工作。项目中的每个人都能实时看到更新，减少了维护同一工作多个副本的需要。
