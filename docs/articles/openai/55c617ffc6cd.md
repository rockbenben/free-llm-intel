# OpenAI 打造全球装备最精良的非营利组织，新委员会将提供洞见

OpenAI 本就是一家非营利组织，也早已在用 AI 帮助人们解决棘手问题。它的目标是打造有史以来全球装备最精良的非营利组织——把潜在的历史级财务资源与某种更强大的东西结合起来：能够放大人类创造力本身的技术。

想象一种公益：它投资于社区的能力，将随着其关联公司价值的增长而增长。

想象一种公益：其通货不仅是资金，还有基础能力——自电力以来最具影响力的技术，由领先的 AI 公司打造，交到加州各地、全美乃至海外非营利组织的手中。

想象一下：当研究、发现、诊断、药物开发、教学以及对进步与成效的研究都能由 AI 规模化时，被释放出来的善款可以派上什么用场。

OpenAI 相信，创新应为所有人创造机会。其董事会已指示公司召集一个精选的专家团队，帮助 OpenAI 的公益事业理解非营利组织当前在履行使命时面临的最紧迫、最顽固的问题。该委员会还将纳入卫生、科学、教育和公共服务领域的领导者与社区的反馈——尤其是 OpenAI 所在的加利福尼亚州。委员会成员将于 4 月公布，并在 90 天内向 OpenAI 董事会提交洞见；董事会将在 2025 年结束前很早的阶段推动 OpenAI 非营利实体的演进时考虑这些洞见。

董事会认识到，与公益界以及最贴近一线工作的人交流，对于帮助 OpenAI 的公益事业最佳地部署其潜在的历史级资源至关重要。指导原则——也是该委员会任务的重要部分——是确保 OpenAI 的创新为人服务，而不是相反**。**
