# Retro Contest：结果公布

我们首届 Retro Contest——探索能够从既往经验中泛化的算法——现已结束。

尽管尝试了许多方法，顶尖成绩全部来自对现有算法（如 PPO 和 Rainbow）的调优或扩展。前路仍长：训练后的最高分为 4,692，而理论满分是 10,000。这些结果验证了我们的 Sonic 基准是一个值得社区深耕的好问题：获胜方案都是通用的机器学习方法，而非针对比赛的取巧 hack，说明这道题无法“作弊”通过。


在两个月的比赛中，共有 923 支队伍注册，229 支队伍向排行榜提交了方案。我们的自动评估系统对提交的算法共执行了 4,448 次评估，平均每支队伍约 20 次。参赛者在排行榜上能看到自己的分数攀升；排行榜基于我们用关卡编辑器制作的 5 个低质量关卡组成的测试集。点击[排行榜条目⁠（在新窗口中打开）](https://contest.openai.com/leaderboard)，你可以观看 agent 在其中一关上的游玩过程。

由于参赛者会以分数和 agent 试玩关卡视频的形式收到提交反馈，他们很容易对排行榜测试集过拟合。因此，最终评估使用了一个完全不同的测试集。提交截止后，我们取出前十名参赛者的最新提交，让他们的 agent 在 11 个由资深关卡设计师制作的定制 Sonic 关卡上接受测试。为降低噪声，每位参赛者在每个关卡上评估 3 次，环境使用不同的随机种子。最终评估改变了排名，但变化不大。

## 走近获胜者


### Dharmaraja

Dharmaraja 是一支六人团队，成员包括 Qing Da、Jing-Cheng Shi、Anxiang Zeng、Guangda Huzhang、Run-Ze Li 和 Yang Yu。[Qing Da⁠（在新窗口中打开）](http://www.daqings.net/) 和 Anxiang Zeng 来自中国杭州阿里巴巴搜索部门 AI 团队。近年来，他们与南京大学计算机系副教授 [Yang Yu⁠（在新窗口中打开）](http://lamda.nju.edu.cn/yuy) 一起研究如何将强化学习应用于现实世界问题，尤其是电商场景。

Dharmaraja 的方案是 joint PPO（见我们的[技术报告⁠（在新窗口中打开）](https://arxiv.org/abs/1804.03720)）的一个变体，外加若干改进。第一，使用 RGB 图像而非灰度图；第二，使用略微扩展的动作空间，加入更多常用按键组合；第三，使用扩展的奖励函数，奖励 agent 访问新状态（以屏幕的感知哈希判断）。除这些改动外，团队还尝试了许多没有奏效的做法：[DeepMimic⁠（在新窗口中打开）](https://arxiv.org/abs/1804.02717)、通过 [YOLO⁠（在新窗口中打开）](https://arxiv.org/abs/1506.02640) 做目标检测，以及一些 Sonic 专属的点子。

- [获取源代码（在新窗口中打开）](https://github.com/eyounx/RetroCodes)


### Mistake

mistake 队由 Peng Xu 和 Qiaoling Zhong 组成。两人都是北京的中国科学院计算机网络信息科学重点实验室/计算技术研究所二年级研究生。业余时间里，Peng Xu 喜欢打篮球，Qiaoling Zhong 喜欢打羽毛球。他们最爱的电子游戏是《魂斗罗》和《马力欧》。

Mistake 的方案基于 Rainbow 基线。他们做了若干提升性能的修改：为 n-step Q learning 选择了更好的 n 值；在模型中多加了一层 CNN，使训练更慢但更好；降低了 DQN 目标网络更新间隔。此外，团队还尝试过与 Rainbow 的联合训练，但发现在他们的情况下反而损害了性能。

- [获取源代码（在新窗口中打开）](https://github.com/xupe/mistake-in-retro-contest-of-OpenAI)


### Aborg

Aborg 队是 Alexandre Borghi 的单人之师。2011 年完成计算机科学博士学业后，Alexandre 先在法国的多家公司工作，之后移居英国，担任深度学习研究工程师。作为电子游戏与机器学习双料爱好者，他把大部分业余时间用于钻研深度强化学习，这驱使他参加了 OpenAI Retro Contest。

Aborg 的方案与 Dharmaraja 一样，是加入大量改进的 joint PPO 变体：使用来自 Game Boy Advance 和 Master System Sonic 游戏的更多训练关卡；采用不同的网络架构；以及专为快速学习设计的微调超参数。关于最后一点，Alexandre 注意到微调最初 15 万个时间步不稳定（性能有时反而变差），于是调整学习率解决了这个问题。除上述改动外，Alexandre 还尝试过若干无效方案：不同优化器、[MobileNetV2⁠（在新窗口中打开）](https://arxiv.org/abs/1801.04381)、使用彩色图像等。

- [获取源代码（在新窗口中打开）](https://github.com/aborghi/retro_contest_agent)

## 经验与下一步

比赛有可能颠覆“什么方法最有效”的主流共识，因为参赛者会尝试各种迥异的方法，而最好的会胜出。在这场特定的比赛中，表现最好的方法与我们 OpenAI 赛前发现的成功方法并没有根本差异。

我们很高兴看到多个顶尖方案利用了迁移学习——从训练关卡进行微调。但我们也惊讶地发现，一些最高提交只是我们基线算法的调优版本。这凸显了超参数的重要性，尤其是在 Rainbow DQN 这类 RL 算法中。

我们计划在几个月后再办一届比赛。随着人们了解赛况、开始深入思考强化学习中快速学习与泛化问题，我们希望并预期更多不走寻常路的方法能在第二轮成功。到时再见——我们期待看着你们的创新方案一路攀上记分板。
