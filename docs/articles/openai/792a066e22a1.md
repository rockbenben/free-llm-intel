# 华特迪士尼公司与 OpenAI 达成重大协议，把迪士尼品牌的经典角色引入 Sora

这项合作为娱乐行业的负责任 AI 应用树立了新标杆。


- *在这项为期三年的授权合作中，Sora 将能够基于用户相关提示生成短视频，供粉丝观看与分享，内容涵盖迪士尼、漫威、皮克斯和星球大战等品牌的 200 多个角色。*
- *协议指出，部分根据粉丝灵感生成的 Sora 短视频将会上线 Disney+，供用户观看。*
- *迪士尼与 OpenAI 重申双方对负责任使用 AI 的共同承诺，确保用户安全，并保护创作者权益。*
- *除了授权合作外，迪士尼还将成为 OpenAI 的重要客户，使用 OpenAI API 打造全新的产品、工具与体验（包括 Disney+），并在内部部署 ChatGPT 供员工使用。*
- *根据协议，迪士尼将向 OpenAI 进行 10 亿美元的股权投资，并获授购买额外股权的认股权证。*

华特迪士尼公司与 OpenAI 达成协议，迪士尼将成为 Sora — OpenAI 的短视频生成式 AI 平台 — 首个大型内容授权合作伙伴。这项合作把两家在创意与创新领域的领军者紧密结合，为充满想象力的故事表达开启全新的可能性。

在这项三年授权合作中，Sora 将能够根据用户相关提示生成短视频，供粉丝观看与分享，内容涵盖迪士尼、漫威、皮克斯与星球大战等品牌的 200 多个动画角色、面具角色与生物角色，并包括服装、道具、载具与标志性场景。此外，ChatGPT 图像也将能够根据用户的简短提示，在数秒内生成完整图像，使用的同样是这些知识产权内容。协议不包含任何演员的肖像或声音。

除了授权合作外，迪士尼还将成为 OpenAI 的重要客户，使用 OpenAI API 打造全新的产品、工具与体验（包括 Disney+），并在内部部署 ChatGPT 供员工使用。

根据协议，迪士尼将向 OpenAI 进行 10 亿美元的股权投资，并获授购买额外股权的认股权证。

双方在协议中重申了对负责任使用 AI 的共同承诺，确保用户安全，并保护创作者的权益。两家公司将携手推动以人为本的 AI，尊重创意产业，并拓展故事表达的边界。

此次交易仍需完成最终协议的谈判，并通过必要的公司及董事会审批，以及满足惯常的交割条件。

“科技创新一直推动着娱乐行业的演进，为我们带来全新的方式，去创造和分享伟大的故事。”华特迪士尼公司首席执行官 Robert A. Iger 表示，“人工智能的快速发展对我们行业来说是一个重要时刻。通过与 OpenAI 合作，我们将以审慎且负责任的方式，利用生成式 AI 扩大我们的故事影响力，同时尊重并保护创作者及其作品。将迪士尼的经典故事/角色与 OpenAI 的突破性技术相结合，可让想象力与创造力真正落到迪士尼粉丝手中，为他们提供前所未有的工具，以更丰富、更具个性化的方式感受心仪的迪士尼角色与故事。”

“在故事创作领域，迪士尼堪称全球标杆，我们非常期待通过合作，让 Sora 和 ChatGPT 图像帮助人们以全新的方式创作和体验精彩内容。”OpenAI 联合创始人兼首席执行官 Sam Altman 表示，“这项协议展示了 AI 公司与创意领袖如何以负责任的方式开展合作，推动有益社会的创新，尊重创意，并帮助作品触达更广泛的受众。”

根据授权协议，粉丝将能够在 Disney+ 上观看精选的 Sora 生成视频。OpenAI 与迪士尼也将合作利用 OpenAI 的模型，为 Disney+ 订阅用户打造全新的体验，进一步拓展与迪士尼故事和角色互动的新方式。Sora 和 ChatGPT 图像预计将在 2026 年初开始，根据粉丝灵感，生成包含迪士尼品牌授权角色的视频。

粉丝能够在创作中使用的角色包括：米奇老鼠 (Mickey Mouse)、米妮老鼠 (Minnie Mouse)、莉萝 (Lilo)、史迪奇 (Stitch)、爱丽儿 (Ariel)、贝儿 (Belle)、野兽 (Beast)、灰姑娘 (Cinderella)、超能陆战队的大白 (Baymax)、辛巴 (Simba)、木法沙 (Mufasa)，以及来自《魔法满屋 (Encanto)》《冰雪奇缘 (Frozen)》《头脑特工队 (Inside Out)》《海洋奇缘 (Moana)》《怪兽电力公司 (Monsters Inc.)》《玩具总动员 (Toy Story)》《飞屋环游记 (Up)》《疯狂动物城 (Zootopia)》等作品的角色。此外，还包括漫威与卢卡斯影业旗下的标志性动画或插画版本角色，如黑豹 (Black Panther)、美国队长 (Captain America)、死侍 (Deadpool)、格鲁特 (Groot)、钢铁侠 (Iron Man)、洛基 (Loki)、雷神 (Thor)、灭霸 (Thanos)、达斯·维达 (Darth Vader)、韩·索罗 (Han Solo)、卢克·天行者 (Luke Skywalker)、莱娅 (Leia Organa)、曼达洛人 (The Mandalorian)、冲锋队士兵 (Stormtroopers)、尤达 (Yoda) 等。

根据协议，OpenAI 承诺继续在行业内保持领先地位，落实负责任的措施以进一步建立信任并提升安全性，具体包括适龄政策与其他合理的服务控制。此外，OpenAI 与迪士尼重申了共同承诺，确保落实严格的管控措施，以防止生成非法或有害内容，尊重内容所有者对模型输出内容的权利，并保障个人对其声音与肖像使用的合理控制权利。
