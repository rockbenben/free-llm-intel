# 面向机器人抓取的领域随机化与生成模型

## 摘要

基于深度学习的机器人抓取因算法改进和数据可用性提升而取得了显著进展。然而，当前最优模型往往只在少至数百或数千个独立物体实例上训练，因此泛化能力可能成为一个挑战。

在这项工作中，我们探索了一种新的数据生成管线，用于训练执行抓取规划的深度神经网络，把领域随机化的思想应用于物体合成。我们生成了数百万个独立的、不真实的程序化生成物体，并在这些物体上训练一个深度神经网络来执行抓取规划。由于给定物体的成功抓取分布可能是高度多峰的，我们提出一种自回归抓取规划模型，把场景的传感器输入映射到可能抓取上的概率分布。该模型让我们能够在测试时高效地采样抓取动作（或完全避免采样）。

我们在仿真和真实世界环境中评估了模型架构与数据生成管线。我们发现，尽管只在随机物体上训练过，在仿真中测试时对未见过的真实感物体可以达到 90% 以上的成功率。我们还展示了在真实世界抓取尝试中 80% 的成功率，尽管训练数据只有随机的仿真物体。
