# 用 ChatGPT Work 处理销售工作流

探索销售团队如何用 ChatGPT Work，把客户账户背景、客户对话和商机信号，变成管道简报、会议材料包、预测复盘和账户计划。

销售工作往往散落在 CRM 字段、通话记录、邮件串、Slack 讨论、演示文稿、客户文档和账户信号之中。ChatGPT Work 帮助把这些上下文汇聚起来，产出交付物的首个可用版本——无论是按优先级排列的账户简报、会议准备材料包、预测风险复盘、账户策略包，还是停滞商机诊断。销售和管理者仍负责关系策略与判断；ChatGPT Work 帮助工作草稿更快地到达团队面前。

## 为 ChatGPT Work 安装销售插件

ChatGPT Work 的**销售插件**帮助销售团队把客户上下文带入推动商机前进的工作中。销售团队可以用它找出高优先级账户和信号、准备客户会议、完成跟进、更新客户记录、制定成单计划、复盘有风险的交易，所用工具包括 Salesforce、HubSpot、Slack、Outreach、Clay、Rox 和 Actively。已经安装了 ChatGPT Work？点击[**这里**⁠（在新窗口打开）](https://chatgpt.com/plugins/share/22ec24462a4a410bba1c56c099f6101c)安装 Sales 插件。
