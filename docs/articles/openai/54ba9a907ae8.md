# 面向中间填充的语言模型高效训练

## 摘要

我们证明，自回归语言模型在对数据集施加一个简单的变换后即可学会填充文本（infill）——该变换只是把文档中间的一段文本移到文档末尾。尽管这种数据增强近年来备受关注，我们提供了大量证据表明：以这一方式变换大比例数据来训练模型，不会损害原有的从左到右生成能力，这一点在跨多种规模规模的困惑度（perplexity）与采样评估中得到衡量。鉴于中间填充（FIM）训练的实用性、简单性和高效性，我们建议未来的自回归语言模型默认采用 FIM 进行训练。为此，我们对关键超参数进行了一系列消融实验，包括数据变换频率、变换结构以及填充片段的选择方法。基于这些消融结果，我们给出了训练 FIM 模型的强默认设置与最佳实践。我们已在 API 中发布了按最佳实践训练的最优填充模型，并公开填充基准（infilling benchmarks）以助力后续研究。
