# 用于分层强化学习的随机神经网络

## 摘要

深度强化学习近年来取得了许多引人注目的成果。然而，稀疏奖励或长时域的任务仍然构成重大挑战。为应对这些重要问题，我们提出一个通用框架：先在预训练环境中学到有用的技能，再利用习得的技能在下游任务中更快学习。我们的方法结合了内在动机与分层方法的一些优势：有用技能的学习由单一代理奖励引导，而该奖励的设计几乎不需要关于下游任务的领域知识。然后在这类技能之上训练高层策略，显著改善探索，使下游任务中的稀疏奖励问题得以应对。为了高效预训练大跨度的技能，我们使用随机神经网络并结合信息论正则项。实验表明，这一组合能以高样本效率学到跨度宽广、可解释性强的技能，并在广泛的下游任务上一致地大幅提升学习表现。
