# 对深度强化学习中的安全探索进行基准测试

阅读论文（在新窗口打开）。

## 摘要

强化学习（RL）agent 需要探索其环境，通过试错学习最优策略。在许多环境中，安全是关键关切，某些错误是不可接受的：例如，与人交互的机器人系统在探索过程中绝不应伤害人类。虽然当前典型做法是几乎完全在模拟环境中训练 RL agent（在那里安全顾虑很小），但我们预计，模拟现实世界复杂性（如人机交互）的挑战将促使 RL agent 转向直接在现实世界中训练——在那里安全顾虑至高无上。因此，我们持这样一种立场：安全探索应被视为 RL 研究的关键焦点领域，而本工作为推进安全探索研究作出三点贡献。第一，基于安全强化学习的广泛既有工作，我们提议将约束 RL 作为安全探索的主要形式化标准。第二，我们发布 Safety Gym 基准套件——一组全新的高维连续控制环境，用于度量约束 RL 的研究进展。最后，我们在 Safety Gym 环境上对若干约束深度 RL 算法进行基准测试，建立可供未来工作参照的基线。
