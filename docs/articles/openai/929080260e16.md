# DALL·E API 现已开放公测

从今天起，开发者可以开始基于 DALL·E API 构建应用。

开发者现在可以通过我们的 API，把 [DALL·E](https://openai.com/index/dall-e-2/) 直接集成进自己的应用与产品。已有超过 300 万人使用 DALL·E 延伸创造力、加速工作流，每天生成超过 400 万张图像。开发者用同样的技术开始构建，只需几分钟。

## 最先进的图像生成

DALL·E 的灵活性让用户可以创作和编辑从艺术风到照片级真实的原创图像。DALL·E 擅长遵循自然语言描述，用户只需平实地说出想看到什么。随着研究演进，我们会持续把最新成果带入 API，包括图像质量、延迟、可扩展性和易用性方面的进展。

## 内建审核

我们把在向全球 300 万艺术家和用户部署 DALL·E 期间积累的信任与安全经验融入其中：开发者可以放心发布，因为内建的缓解措施——比如仇恨符号和血腥内容过滤器——会处理好审核中的难点。作为 OpenAI 负责任部署承诺的一部分，我们将继续把信任与安全置于首位，让开发者专注构建。

## DALL·E 应用

我们与几家早期客户密切合作，他们已经把 DALL·E 建进了各自的应用与产品，覆盖多种用例。

**Microsoft** 正把 DALL·E 带入一款名为 [Designer](https://designer.microsoft.com/) 的新平面设计应用，帮助用户制作专业品质的社交媒体帖、邀请函、电子明信片、图形等。

Microsoft 还在 Bing 和 Microsoft Edge 中通过 Image Creator 集成 DALL·E，当搜索结果给不出用户想要的图片时，用户可以直接生成。

[**CALA**](https://ca.la/) 是全球首个时尚与生活方式操作系统。CALA 把整个设计流程——从产品构思一直到电商落地与订单履约——统一到一个数字平台上。由 DALL·E 驱动，CALA 新的 AI 工具将允许用户从自然语言描述或上传的参考图生成新的设计想法。

[**Mixtiles**](https://www.mixtiles.com/) 是一家快速成长的照片创业公司。他们用软件和简易悬挂体验，帮助数百万人做出漂亮的照片墙。Mixtiles 使用 DALL·E API 创作并装裱触动人心的艺术作品，通过引导用户完成捕捉童年记忆、梦想目的地等内容的创作流程。

我们很期待客户会用 DALL·E 做出什么、迸发出什么创意。

## 用 OpenAI 的强大模型构建

DALL·E 加入 [GPT-3](https://beta.openai.com/docs/guides/completion)、[Embeddings](https://beta.openai.com/docs/guides/embeddings) 和 [Codex](https://beta.openai.com/docs/guides/code)，成为我们 API 平台的一员，为开发者增添可用于创造全新体验与应用的新构件。所有 API 客户今天就可以使用 DALL·E API。
