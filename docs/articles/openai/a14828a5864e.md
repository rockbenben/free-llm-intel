# 法院驳回马斯克拖慢 OpenAI 的最新企图

我们欢迎法院 2025 年 3 月 4 日的裁决——它驳回了马斯克为了个人利益拖慢 OpenAI 的最新企图。

这场诉讼从头到尾关心的都是什么对马斯克和他的营利性 AI 公司有利。事实是，他当年想把一个营利性的 OpenAI 并入特斯拉——他[自己的邮件](https://openai.com/index/elon-musk-wanted-an-openai-for-profit/)就是这么写的。我们拒绝了他，他于是离开，因为他无法夺取控制权。后来当他看到没有他我们依然取得的进展，马斯克开始诉诸毫无根据的诉讼，同时仍试图照抄我们的打法，用他自己的、价值数十亿的营利公司开发竞争模型。

上周，法院驳回了马斯克申请初步禁令的请求，认定他未能"证明其主张在实体上有胜诉可能"。事实上法院走得更远，直接把他的几项主张从案件中整体驳回。这一裁决让我们离终结这场荒唐诉讼大大迈进了一步。

随着马斯克逐渐明白的道理——事实很重要，尤其是在法庭上。而最重要的事实，是他不断歪曲的那一条：非营利部门不会消失。不管马斯克怎么说，眼下根本没有什么非营利"改制"。

我们欢迎在法庭上说清楚的机会：我们完全打算（1）把非营利部门保留为我们实现使命工作的关键组成部分，并且（2）确保它不只是被一门成功的生意供养，而是处于比以往更强的位置。同样重要的是要指出，我们已经拥有营利性子公司多年——任何新结构都只是让业务能更好地支持非营利部门。

[我们的董事会已经非常明确](https://openai.com/index/why-our-structure-must-evolve-to-advance-our-mission/)地表示：我们打算强化非营利部门，使其能长期兑现使命。我们不是在卖掉它，而是在加倍投入它的工作。它将在我们拟议的公共利益公司（public-benefit corporation）中持有可观股份，使其成为历史上资源最雄厚的非营利组织之一。

从某种角度看，马斯克 2017 年说我们需要让 OpenAI 的结构演进，这句话说对了。他把自己的 AI 公司 xAI 注册为公共利益公司，这也说明他懂这个道理。但在这场毫无根据、出于自私算计的诉讼、支撑它的虚假指控、以及那场所谓"出价"之类的卑小伎俩上，他错了。法院已经正确看穿了这最新的企图，我们相信法院会继续如此。
