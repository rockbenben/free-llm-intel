# 用于图像输入机器人学习的非对称 Actor-Critic

## 摘要

深度强化学习（RL）已在许多序贯决策领域被证明是一种强大的技术。但机器人学给 RL 带来诸多挑战，最突出的是在物理系统上训练既昂贵又危险，这激发了人们用物理仿真器学习控制策略的浓厚兴趣。虽然近期若干工作表明把仿真中训练的策略迁移到真实世界颇有前景，但它们往往没有充分利用"在仿真器中工作"的优势。在这项工作中，我们利用仿真器的全状态可观测性来训练更好的策略——这些策略的输入只是部分观测（RGBD 图像）。为此我们采用 actor-critic 训练算法：critic 基于完整状态训练，而 actor（即策略）只接收渲染图像作为输入。我们在一系列仿真任务上用实验证明，使用这种非对称输入显著提升了性能。最后，我们把该方法与域随机化结合，展示了在若干任务上的真实机器人实验，如抓取、推动和移动方块。我们在不使用任何真实世界数据训练的情况下实现了从仿真到现实的迁移。
