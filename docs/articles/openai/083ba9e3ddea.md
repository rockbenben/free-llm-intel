# Scout24 如何用 AI 打造下一代房地产搜索

Scout24 正用生成式 AI 重新构想人们发现“在哪里生活、怎样生活”的方式。

Scout24 运营着德国最大的房地产平台，把找房者、房主、房东和经纪人在一个生态系统中连接起来。多年来，AI 一直支撑着其反欺诈、营销效率和房产估值等领域，而强大语言模型的兴起带来了一个为客户打造新事物的机会：一个智能的、对话式的房地产助手。

我们与 Scout24 首席技术官 Gertrud Kolb 坐下来聊了聊她的团队如何构建由 GPT‑5 驱动的搜索体验、他们对“智能交互”学到了什么，以及在上线前如何在创新与质量、信任之间取得平衡。

> “保持好奇，保持开放，动手去做。彼此交流、互相学习——并且享受其中。”

——Gertrud Kolb，Scout24 首席技术官

### 成果一览

- GPT‑5 驱动 Scout24 的对话式搜索助手 HeyImmo
- 自适应回答格式：简明摘要、要点列表，或带图片预览的直接房源
- 基于 OpenAI Evals 框架自建自定义评测体系，定义并度量回答质量
- 全公司范围的“蜂群测试”，校准预期并对边缘情况做压力测试
- 为速度、可靠性与快速改进而构建的架构
- 与 OpenAI 解决方案架构师紧密协作，改进安全性、质量与用户体验

### 上线过程内部

Scout24 的首要优先级是搜索——平台的核心功能。但当团队开始用 OpenAI 做原型时，他们意识到客户想要的不仅是更好的结果，而是指引。“我们很快就发现这不仅仅关乎搜索。我们需要一个房地产专家助手——一个陪练伙伴——引导你走完整个平台体验，”Gertrud 说。

这一洞察催生了会提出澄清问题、浮现相关房源、总结备选项、并根据用户需要调整回答格式的对话式助手。有人想要要点；有人想要完整摘要；还有人想马上看到房源。理解“智能交互究竟意味着什么”成了最大的挑战之一。

Scout24 还必须找到合适的技术架构。早期的想法倾向于复杂的多 agent 框架，但团队有意做了简化：使用 function calling 与聚焦的组件，以便快速交付并从用户处学习。延迟、相关性、性能和回答结构成为核心议题。

最重要的经验之一，是理解“质量”。为了解决这个问题，Scout24 受 OpenAI evals 框架启发构建了自有的评测模型——帮助团队定义“足够好”究竟意味着什么，并在众多场景中度量它。他们还结合了广泛的内部测试——几乎全体员工都受邀试用产品、提供反馈并对边缘情况做压力测试。公司一度推迟上线，以确保体验达到自己设定的标准。

在整个开发过程中，Scout24 与 OpenAI 团队密切合作。Gertrud 形容这种协作在提升回答质量、塑造响应结构、以及对齐“AI 驱动的搜索体验什么是好”方面“助益极大”。

这种迭代工程、严格评测与广泛测试的结合，为一个既智能又可信的客户体验奠定了基础。

### Scout24 的领导者经验

- 从 AI 能改变产品核心之处入手——并从那里迭代。
- 质量很重要：定义“足够好”，并构建度量它的工具。
- 大规模内部测试能揭示真实的用户预期。
- 尽早发布、快速学习——但要知道何时放慢。
- 产品团队与技术专家之间的紧密伙伴关系的会加速推进。

### 下一步

Scout24 当前的焦点是互联互通：把房地产助手扩展到找房者、房东、房主和经纪人各方。从帮助经纪人产出经核实的户型图，到为找房者提供更个性化的指引，团队看到许多深化体验、强化市场网络效应的机会。

> “对每一个客户群体，我们都有大量 AI 驱动功能的想法。我们才刚刚开始。”

——Gertrud Kolb，Scout24 首席技术官
