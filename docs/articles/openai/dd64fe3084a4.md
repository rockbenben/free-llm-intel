# GPT‑5.3‑Codex 系统卡

阅读系统卡


## 简介

GPT‑5.3‑Codex 是迄今为止能力最强的智能体编程模型，它结合了 GPT‑5.2‑Codex 的前沿编程性能以及 GPT‑5.2 的推理和专业知识能力。这使其能够承担涉及研究、工具使用和复杂执行的长期运行任务。就像同事一样，你可以在 GPT‑5.3‑Codex 工作时对其进行引导和交互，而不会丢失上下文。

与其他近期模型类似，它在生物学领域被视为具备高能力级别；并将按照我们在 GPT‑5 系列其他模型中使用的同等级安全防护措施进行部署。该模型在 AI 自我提升方面未达到高能力级别。

这是我们首次根据《准备框架》，将发布的产品定级为网络安全领域的“高能力”，并为此启动了相关的安全保障措施。我们目前没有确凿证据表明该模型已达到我们的“高”阈值，但由于无法排除其具备达到该阈值能力的可能，我们采取了预防性措施。我们针对网络安全高能力的保障措施依赖于一套分层安全栈，旨在阻碍并干扰威胁行为者，同时我们也在努力使这些能力能尽可能轻松地供网络防御者使用。
