# OpenAI 被 Gartner 评为企业级编程智能体领导者




OpenAI 被 Gartner®《企业级 AI 编程智能体魔力象限™》评为领导者象限。我们认为，这一评估反映了我们在支持 Codex 企业级大规模部署方面取得的进展。Codex 每周有超过 400 万人使用，[Cisco⁠](https://openai.com/index/cisco/)、[Datadog⁠](https://openai.com/index/datadog/)、[Dell Technologies⁠](https://openai.com/index/dell-codex-enterprise-partnership/) 和 [NVIDIA⁠](https://openai.com/index/nvidia/) 等公司也在使用。自 Gartner 今年早些时候进行评估以来，我们已通过推出 [GPT‑5.5⁠](https://openai.com/index/introducing-gpt-5-5/) 显著提升了 Codex，同时增强了工具使用能力、提升了性能速度，并加深了对企业软件开发工作流的支持。

2026 年 Gartner 企业级 AI 编程智能体魔力象限™。来源：Gartner，2026 年 4 月。

软件开发正变得越来越智能体化。开发者正从自动补全迈向将复杂任务委托给 Codex。Codex 能理解大型代码库、使用工具、进行修改、运行测试，并为人工审查准备工作成果。对企业而言，机会在于兼顾速度与控制：帮助团队更快构建，同时保持其所需的治理、安全性和可审计性。

在该报告中，Gartner 认可了 Codex 在“执行能力”和“愿景完整性”两方面的优势。Gartner 认可了 Codex 在智能体化软件开发、企业治理、沙箱隔离和灵活部署选项方面的优势。Gartner 强调了 Codex 广泛的开发者触达面——包括 Codex 应用、IDE 扩展、CLI、SDK 和基于云的编排——以及审批关卡、RBAC、可定制策略、操作系统级沙箱隔离和可审计的工作空间治理等企业控制能力。

我们认为，这些优势帮助 OpenAI 成为 Cisco 的合适合作伙伴。Cisco 使用 Codex 开发了其 AI Defense 安全平台的大部分内容，将交付时间从数个季度缩短到数周。Cisco AI 软件与平台产品高级副总裁 DJ Sampath 分享了 Codex 如何改变 Cisco 构建软件的方式。

在我们看来，最好的编程智能体将把前沿模型能力与深度集成的产品体验结合起来。这就是为什么我们要将 Codex 打造成能够推理复杂任务、使用开发者工具、在受控环境中运行，并提供组织在整个软件开发生命周期部署 AI 所需的治理、安全性和控制能力。

“企业不再只问 AI 是否能编写高质量代码；他们还在问，如何安全地大规模部署智能体系统，将其作为业务的新运营层。对我们而言，Gartner 的认可反映了我们在 Codex 上看到的发展势头。如今，Codex 已成为 OpenAI 增长最快的企业产品之一，并正从编程辅助扩展到更广泛的企业工作流。”

——OpenAI 首席营收官 Denise Dresser

在获得这一认可的同时，Codex 也在持续为企业改进。近期更新包括 [Codex Security 和 GPT‑5.5‑Cyber⁠](https://openai.com/index/gpt-5-5-with-trusted-access-for-cyber/)、[移动端支持⁠](https://openai.com/index/work-with-codex-from-anywhere/)、[面向托管开发环境的远程 SSH⁠](https://openai.com/index/work-with-codex-from-anywhere/)、[有范围限制的程序化访问 Token 和 Hook⁠](https://openai.com/index/work-with-codex-from-anywhere/)、[支持符合 HIPAA 要求的使用⁠](https://openai.com/index/work-with-codex-from-anywhere/)、[Amazon Bedrock 上的 Codex⁠](https://openai.com/index/openai-on-aws/)，以及通过 [Codex Labs 和 GSI 合作伙伴⁠](https://openai.com/index/scaling-codex-to-enterprises-worldwide/) 扩展的部署支持，其中包括 Accenture、Capgemini、Cognizant、Infosys、PwC 和 TCS。
