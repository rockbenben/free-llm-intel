# Xiaomi MiMo 现已接入全球顶级 Agent 框架 Hermes Agent，并限免两周

Xiaomi MiMo-V2 系列现已正式支持 Hermes Agent！

作为面向 Agent 时代的旗舰基座，Xiaomi MiMo-V2 系列大模型正式携手全球顶尖的 Agent 开源框架 Hermes Agent，实现官方集成接入。

**Hermes Agent 是：**

- 当前全球最受关注的开源 Agent 框架之一
- 具备自我进化、跨会话记忆能力，从任务中自动积累经验，越用越强
- 支持全平台通信

mimo‑v2‑pro 凭借 1M 长上下文能力、原生强工具调用与深度 Agent 专项优化，全面适配 Hermes Agent 自进化技能、跨会话记忆、复杂工作流等核心特性。

mimo‑v2‑omni 则进一步拓展感知边界，融合图像、视频、音频与文本的全模态理解能力，助力 Hermes Agent 成为是真正看得见、听得懂、能动手的全模态 Agent。

**诚邀全球开发者试用 ，限免两周**

- **限免周期：** 4 月 8 日 - 4 月 22 日 12:00（北京时间，UTC+8），共两周。
- **使用方式：** 更新 Hermes Agent 至最新版，通过 Nous Portal 即可免费调用 Xiaomi mimo‑v2-pro、omni、flash 模型。

从「执行任务」到「自我进化」，MiMo 携手 Hermes Agent，让你的 AI Agent 实现“越用越聪明”。
