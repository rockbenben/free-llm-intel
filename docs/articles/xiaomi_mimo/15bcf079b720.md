# Xiaomi MiMo Token Plan 正式发布

2025 年以来，大模型的能力边界被不断刷新。但对于大多数开发者和用户而言，“用得起”仍然是比“好不好用”更前置的问题。按量计费的模式下，每一次调用都伴随着对成本的不确定。

我们不希望这样。我们相信——**好的技术不应该只是少数人的特权，它应该像水和电一样，以可预期的价格，成为每个人触手可及的生产力。**

因此，我们正式推出 Xiaomi MiMo Token Plan。

### MiMo Token Plan：化繁为简

我们设计 Token Plan 的初心，就是希望计费方式足够透明、简单、直接，任何用户都能看得懂、用得爽。

**1. 透明设计，简单直接**——统一 Credit 点数体系，按 token 使用量换算 credit 消耗量，助你轻松安排用量规划。

> mimo-v2-omni 256k 上下文：1x（消耗 1 Token = 1 Credit）
> 
> 
> mimo-v2-pro 256k 上下文： 2x（消耗 1 Token = 2 Credits）
> 
> 
> mimo-v2-pro 256k~1M 上下文： 4x（消耗 1 Token = 4 Credits）
> 
> 
> mimo-v2-tts：0x（限时免费，不消耗 Credit）

**2. 无 5 小时 token 使用限额**——支持集中消耗 token ，高强度养龙虾或编程，体验拉满、不被打断。

**3. 购买套餐用户可享新模型优先内测体验权**——先进好用，快人一步。

### 四档定价，为你而设

Token Plan 提供四档套餐，无论你对 AI 的使用频率和深度如何，都能找到适合的方案：

- **Lite（中国 ¥39/月，海外 $6/月）** —— 0.6亿（60M）Credits，可执行约 **120 个中等~复杂任务** 。适合刚接触 AI 开发的探索者，以一杯咖啡的价格开始。
- **Standard（中国 ¥99/月，海外 $16/月）** —— 2亿（200M）Credits，可执行约 **400 个中等~复杂任务** 。为日常依赖 AI 提效的办公与开发者用户打造的主力方案。
- **Pro（中国 ¥329/月，海外 $50/月）** —— 7亿（700M） Credits，可执行约 **1400 个中等~复杂任务** 。面向将 AI 深度嵌入工作流的专业用户。
- **Max（中国 ¥659/月，海外 $100/月）** —— 16亿（1600M）Credits，可执行约 **3200 个中等~复杂任务** 。为全天候高强度使用的开发者准备，近乎无限制的使用体验。

> 所有套餐首次购买均享 88 折优惠，该优惠仅限 1 次。

### 专为主流 AI 工具适配

专为 Claude Code、OpenClaw、OpenCode、Kilo Code、Cline 等主流 AI 工具、开发平台适配，助你高效提升生产力。

### 这只是开始

自动续费、套餐升级、更灵活的用量管理，都在开发中。如果你在使用中有任何想法或建议，我们真心期待你的反馈。

Token Plan 是 MiMo 的新起点，我们的目标从未改变：**做最好的模型，定最合理的价格，让更多人真正用起来。**
