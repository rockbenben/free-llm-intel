# Xiaomi MiMo 开放平台

## 2026-9-22 批量推理（Batch API）功能上线

批量推理是无需实时响应需求的离线大批量数据处理方案，接口兼容 OpenAI，适合执行模型评测、数据标注、批量回归等场景，支持通过 SDK 或 控制台创建异步任务处理请求。

## 2026-9-15 新增站内信功能

平台公告、系统通知将通过站内信实时推送，重要消息不再遗漏。

## 2026-6-23 支持 OpenAI Responses API

支持兼容 OpenAI Responses API 格式的调用接口，可适配 Codex 等代码工具。

## 2026-6-11 邀请有礼活动升级

邀请好友首次购买 Token Plan ，可以赠金返现，好友享首单折扣。

## 2026-4-29 邀请有礼活动上线

邀创造者体验 MiMo V2.5 小米顶尖模型，注册即得 ¥10 体验金。体验金可抵扣 API 调用付费（Token Plan 除外）。

## 2026-4-23 Token Plan 自动订阅服务上线

- 支持完整的月度和年度两种周期的订阅服务，支持当前套餐续订、新套餐升级
- 套餐权益新增 **mimo-v2.5-pro、mimo-v2.5、mimo-v2.5-tts-voiceclone、mimo-v2.5-tts-voicedesign、mimo-v2.5-tts** 五款最新模型
- 全部模型取消按照上下文长度阶梯计算不同消耗系数的逻辑（即 256k～1M，2 倍消耗速度）
- 开启多种限时优惠活动
- 老用户专属上线福利“用量焕新重置”
- 首开自动续费优惠：未订阅过套餐的新用户首次开通自动续费享 77 折、订阅过套餐的老用户首次开通自动续费享 7 折，首开自动续费优惠与首购优惠互斥，每个账号仅享受 1 次；
- 连续包年：相比连续包月享 88 折优惠，首购/首开自动续费优惠不参与包年；
- 夜间优惠消耗速率：非高峰期（北京时间 0:00-8:00，即 UTC 16:00-24:00） 0.8x 消耗系数。

## 2026-4-3 Token Plan 全新发布

- 提供四档套餐，统一 Credit 额度体系，按 Token 使用量换算消耗，支持套餐升级和用量查询
- 可灵活调用 mimo-v2-pro / omni / tts，共享额度
- 适配主流 AI 编程工具：OpenClaw ｜ Claude Code ｜ OpenCode ｜ Kilocode ｜ Cline ...

## 2026-3-3 mimo-v2-flash 更新

**模型插件能力**

- mimo-v2-flash 支持使用联网搜索工具，获取实时的公开网络信息

## 2026-02-10 企业实名认证及对公支付功能上线

- **实名认证**
- 新增对「国内企业」的实名认证；
- 新增对「国内非大陆用户」的实名认证；
- 支持个人实名认证的账号变更为企业账号。

**B2B 企业网银充值**

- 企业认证的账号支持通过企业网银对公支付；
- 支持企业订单退款及开票。

## 2026-01-26 计费功能上线

**模型推理服务计费**

- 模型推理服务按照 token 消耗计费，支持查看并下载账单，查看实时余额

## 2026-01-20 充值功能上线

**充值开票系统**

- 国内用户个人实名认证
- 全球用户充值、退款、开票、余额预警、计量计费及账单

**免费额度发放**

- 老用户免费额度自动到账，新用户注册即送免费体验额度

## 2025-12-16 Xiaomi MiMo API 开放平台发布

**API Key 管理与用量追踪**

- 支持在控制台快速创建、配置 API Key，实现模型调用鉴权
- 可实时查看、导出Token 消耗、调用次数等用量数据

**一站式开发者文档中心**

- 提供平台快速上手指南、模型 API 文档与集成扩展方法
- 包含模型介绍、调试示例与常见问题排查方案
