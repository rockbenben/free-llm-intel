### 01 从回答问题到交付成果

真实工作很少从一个干净的提示词开始。表格、图片、视频、PDF、录音，乃至未解压的压缩包，往往同时构成任务的上下文。MiMo Desktop 可以直接读取这些素材，无需预先整理或转换格式。

用户只需用自然语言说明目标，MiMo Desktop 会理解素材、拆解任务、并调用工具执行，并最终交付可继续编辑的成果：文档、表格、幻灯片、网页、图片、音频、视频，甚至是3D 模型、App 或软件工程项目。

> 例：PPT 工作流： 混合素材输入 → 事实与数据梳理 → 叙事结构设计 → 图表与版式生成 → 交付可继续修改的 PPT

> 例： Figma 工作流： 自然语言输入 → 理解任务 → 规划工作流 → 调用 MCP 控制 Figma → 实时生成设计元素 → 交付成果

生成轻量游戏原型、复杂数据网页、Office 文件，以及需要动态交互的 Demo 时，成果可立即预览、提问并继续迭代，无需预先搭建本地前端环境。

### 03 在成果上继续工作

交付不是会话的终点。用户可以直接选中会话或产物的任意元素、文本段落、图表或表格区域，用自然语言描述下一步工作或修改要求。选区会限定作用范围，MiMo Desktop 只处理用户希望修改的部分，不必重新生成完整成果，也不必重复交代任务背景。

每次修改都会保留版本记录。用户可以比较不同方案，也可以随时回退历史版本。

> 例：在 PPT 中局部修改：选中范围→ 描述修改意见 → 局部实时重生成

### 04 Smart 调度：为任务匹配合适的执行路径

用户无需在开始任务前先判断该选用哪个模型、哪个 Agent，或哪套执行框架。MiMo Desktop 内置 「Smart」调度模式，可自动评估任务类型、复杂程度、交付要求和执行成本，再自动匹配最适合当前任务的执行路径。

- **任务评估**：识别任务属于办公、编程、研究、设计还是混合场景，并判断所需推理深度、工具范围和交付标准。
- **模型路由**：在标准模型与旗舰模型之间动态选择。日常任务优先标准模型、速度快、成本低；复杂推理、长链路执行和高质量交付使用旗舰模型、产出质量更高。可用模型型号以当前版本为准。
- **Harness / Agent / Skill 路由**：根据任务类型选择办公、代码或研究 Harness / Agent；大型任务可拆分给多个 Agent，分别负责调研、规划、执行和复核，并在执行过程中自动调用不同 Skill 以拓展能力、满足交付质量。
- **多会话协同：** 可按需组成多角色会话团队。多会话之间可相互通信、彼此协作，每个会话在推进项目的过程中，都有独立的记忆、工作区和任务状态。

「Smart」 调度可最大化节省用户心智成本，自动在质量、速度和成本之间做出最优选择。

### 05 浏览器操控：既是信息入口，也是执行环境

MiMo Desktop 可以自主控制电脑浏览器，读取浏览页面、执行交互操作，包括打开网页、检索信息、填写表单和提取素材。浏览器不只是信息来源，也作为任务执行环境的一部分。

从浏览器中获得的信息可直接进入当前任务，用于调研、分析、整理和内容制作，最大化节省用户自行检索和跨应用传递内容的时间。生成网页类成果时，MiMo Desktop 也可以在同一工作流中用浏览器检查关键交互，自动验证成果。

### 06 电脑操控：进入桌面环境（仅限海外版）

对于需要跨应用协作的任务，MiMo Desktop 可以读取屏幕内容，操作键盘和鼠标打开文件、核对数据，以及跨应用传递信息。关键步骤执行后，系统会校验结果，必要时修正或停止。

对于稳定、重复的流程，用户可通过 Record & Replay 功能记录一次完整操作，后续可通过自然语言指令让 MiMo Desktop 自动重新执行。

### 07 让长任务成本可控

长任务不仅要高质量完成，更要控制计算成本。MiMo Desktop 通过模型路由、局部编辑和上下文缓存机制的优化，减少不必要成本支出。

「Smart」调度按任务复杂度选择合适模型；局部编辑只处理与重新生成需要修改的内容；高缓存命中优化最大程度减少缓存部分的重复计算量。三种机制结合，分别降低模型选择、变更范围和重复上下文计算带来的 Token 消耗。

在长任务实际测试中，**同会话的缓存命中率最高可达 99%，跨会话最高可达 95%** ，帮助用户最大化控制任务成本。
