# Xiaomi MiMo Claw 正式版｜旗舰模型+金山办公，全新订阅服务上线

Xiaomi MiMo Claw 是一款云端轻量化 Claw 类产品，让用户低门槛快速体验 MiMo 模型与 Agent 能力。正式版现已发布，搭载与 OpenClaw 框架官方深度适配的 MiMo-V2.5-Pro 旗舰模型。

本次联动金山办公生态，推出全链路文档办公提效方案；新增多项 OpenClaw 核心便捷能力；同时**升级免费用户权益，单次体验时长延长**，并面向高频、专业用户上线 TokenPlan 分层订阅，满足不同使用需求。

### 一、能力升级

#### 1. MiMo 旗舰模型赋能，Agent 能力跨越式升级

- **原生协议兼容**：MiMo-V2.5-Pro 为 OpenClaw 官方预置模型，原生适配 MCP 工具调用协议，内置技能语义解析能力，无需额外配置提示词工程。
- **百万级超长上下文**：搭载长上下文记忆调度架构，适配长链路复杂任务，支持单会话千次以上连续工具调用，有效减少多步骤任务上下文丢失、逻辑断裂问题。
- **MTP 三层解码架构**：依托 MTP 三层解码技术，在 OpenClaw 标准 Agent 工作流测试中，全链路任务推理吞吐效率提升约 3 倍，实现框架专属性能优化。

#### 2. 联动金山办公，实现办公文档一站式闭环

- **多格式兼容**：支持 Word、Excel、PPT、PDF 四大主流文件格式，超 95% 文档类型，覆盖学习、职场、统计多场景。
- **全流程闭环服务**：打通 AI 智能生成、高清在线预览、实时在线编辑全链路，无三方平台跳转，一站式办公提效。
- **轻量化高效使用**：支持自定义指令创作，也可依托内置模板，一键生成标准化文档。

#### 3. 算力效率升级，Token 成本可控

在 ClawEval 基准测试中，MiMo-V2.5-Pro 模型任务达标率（Pass³）达 63.8%，依托其优异的 Token 利用效率，同等任务效果下，MiMo Claw 的 Token 消耗较其他同类产品降低约 40%-60%。同时 MiMo Claw 兼容 TokenPlan 各梯度订阅，提供强有力算力保障。

#### 4. 云端免部署，7×24h 专属服务

- MiMo Claw 采用全云端托管模式，无需本地环境配置、不占用本地设备资源。专属个人 Agent 助力全天候在线，支持后台任务续跑、智能自主纠错，减少本地设备故障导致的任务中断问题。
- 集成多渠道消息对接、文件管理、多任务并行、异常修复等实用功能，有效降低普通用户使用 AI Agent 的操作门槛。

### 二、用户权益

#### 1. 免费e户权益升级

- 创建即可免费使用，免费用户每日单次体验时长延长。
- 开放全部核心功能，功能配置贴合日常 Agent 使用场景，可满足日常轻度办公使用需求。

#### 2. 过往用户权益兼顾

- **叠加升级规则**：支持在原有 TokenPlan 套餐基础上自由加购 MiMo Claw 权益；套餐升级时，各项权益、费用独立核算，订单生效后统一重置月度/年度有效期。
- **权益取消规则**：已叠加 Claw 权益的套餐支持取消服务，平台将按照未使用时间折算剩余价值。
- **历史活动额度通用**：过往 100T 专项活动、订阅调价活动等渠道赠送额度，均可正常使用。

### 三、订阅服务

如果您有更高频使用及高峰算力保障诉求，我们推出了 TokenPlan 分层订阅服务：

#### 1. 全套餐适配，支持灵活叠加

- MiMo Claw 作为独立 Agent 服务，可灵活叠加至 TokenPlan 所有月度、年度套餐（Lite / Standard / Pro / Max）。直接叠加 MiMo Claw 服务开通即可使用，尽可能兼容存量用户权益。

#### 2. 双订阅入口，自主灵活选购

为提升订阅灵活性，平台开放双独立购买入口：

- **TokenPlan 入口**：在 MiMo Platform 订阅 TokenPlan 套餐时，可自主勾选 MiMo Claw 服务，一键叠加开通，算力额度及高阶 Agent 权益即时生效。
- **Claw 专属入口**：在 MiMo Studio 订阅 TokenPlan 套餐，默认自动包含 MiMo Claw 服务，不同订阅档位对应固定服务定价。

#### 3. 限时订阅定价

为回馈新老用户，MiMo Claw 月度、年度订阅现已开启限时特惠活动。

- 首次特惠：**¥ 14.9/月**
- 限时优惠：**¥ 19.9/月、¥ 233.8/年**
