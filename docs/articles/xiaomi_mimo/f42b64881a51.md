# 关于 MiMo-V2.5-Pro-UltraSpeed 限时体验延期的通知

MiMo-V2.5-Pro-UltraSpeed 限时体验（内测）已圆满结束，感谢每一位参与者。正式商业版近期上线，敬请期待。

感谢大家对 Xiaomi MiMo-V2.5-Pro-UltraSpeed 的关注与支持。**经团队评估，我们决定延长 UltraSpeed 限时体验窗口，让更多开发者有机会接入体验 1000 tokens/s 的推理能力。**

我们深信极致的推理速度将带来行业全新的使用场景与范式。

自 MiMo-V2.5-Pro-UltraSpeed 上线以来，我们收到了来自各行各业开发者的踊跃申请。

截止 6 月 23 日，我们已收到超过 6.6 万个使用申请，来自众多世界 500 强公司、行业头部企业与个人开发者，涵盖法律、金融、通信、物流、汽车制造、文化传媒、高校等多个领域，远超我们的预期。

看到社区对 MiMo-V2.5-Pro-UltraSpeed 迫切而真实的需求，我们希望让更多用户有机会体验到 1000 tokens/s 带来的范式变革，因此我们决定**延长 MiMo-V2.5-Pro-UltraSpeed 的聊天体验与 API 接入体验期限**。

本次延期后，您可继续申请 MiMo-V2.5-Pro-UltraSpeed 内测，已审核通过的用户可继续使用。

具体下线时间将根据资源情况另行安排，届时我们会提前告知，确保大家有充足的时间做好迁移与适配准备。
