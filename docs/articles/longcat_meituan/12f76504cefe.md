## 版本: 2026-04-20 [​](https://longcat.chat/platform/docs/zh/ChangeLog.html#版本-2026-04-20)

### LongCat-2.0-Preview 发布 [​](https://longcat.chat/platform/docs/zh/ChangeLog.html#longcat-2-0-preview-发布)

- LongCat-2.0-Preview的核心特性如下：面向Agent开发场景，原生支持工具调用、多步推理和长上下文任务；在代码生成、自动化工作流和复杂指令执行上表现突出；深度适配 Claude Code、OpenClaw、OpenCode和Kilo Code等生产力工具。
- 初始额度5,000,000 Tokens/天，[提交模型使用反馈](https://longcat.chat/platform/feedback)，每次有效的反馈都将有机会获得额度刷新，每日最多可获得120,000,000 Tokens。
- 调用指南请参考：[LongCat API 开放平台接口文档](https://longcat.chat/platform/docs/zh/api-docs)。
