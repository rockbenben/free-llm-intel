## 版本: 2026-09-10 

### 全新推出企业服务 

LongCat API 开放平台推出面向企业用户的服务能力：

- **企业认证**：新增企业认证功能，账号认证前的原有权益全部保留。
- **开具发票**：面向企业认证用户新增自助开具发票功能，详情见[常见问题-发票问题](https://longcat.chat/platform/docs/zh/faq#%E5%8F%91%E7%A5%A8%E9%97%AE%E9%A2%98)。
- **专属权益**：面向企业用户提供 API 按量付费阶梯折扣及其他专属服务，详情见[常见问题-账号认证与权益](https://longcat.chat/platform/docs/zh/faq#%E8%B4%A6%E5%8F%B7%E8%AE%A4%E8%AF%81%E4%B8%8E%E6%9D%83%E7%9B%8A)。
