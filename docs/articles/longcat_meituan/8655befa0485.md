## 摘要

NoisyAgent 是一个 agentic 训练框架，它将环境的不完美纳入 agent 学习过程，以提升在真实世界随机环境中的鲁棒性。

由 [Qwen/Qwen2.5-Coder-32B-Instruct](https://huggingface.co/Qwen/Qwen2.5-Coder-32B-Instruct) 生成

[大语言模型](https://huggingface.co/papers?q=large%20language%20models)（LLM）的最新进展推动了 LLM 作为[交互式 agent](https://huggingface.co/papers?q=interactive%20agents) 的广泛部署，使其能够进行[推理](https://huggingface.co/papers?q=reasoning)、[规划](https://huggingface.co/papers?q=planning)和[工具使用](https://huggingface.co/papers?q=tool%20use)。尽管在现有基准上表现强劲，这类 agent 在真实世界环境中部署时往往出现明显退化，因为真实环境本质上是随机且不完美的。我们认为，这种差异源于理想化训练设置与真实世界交互动态之间的根本性不匹配——当前范式依赖于精心整理的任务指令以及稳定、受控良好的环境。为填补这一空白，我们提出 NoisyAgent，一个将[环境不完美](https://huggingface.co/papers?q=environmental%20imperfections)显式纳入 [agent 学习](https://huggingface.co/papers?q=agent%20learning)过程的 [agentic 训练框架](https://huggingface.co/papers?q=agentic%20training%20framework)。我们识别出真实世界场景中交互噪声的两大来源：[用户噪声](https://huggingface.co/papers?q=user%20noise)，它刻画用户交互中的模糊性与可变性；以及[工具噪声](https://huggingface.co/papers?q=tool%20noise)，它反映工具执行中的失败与异常。我们通过在训练环境中修改用户交互模式并模拟工具执行结果，将这类扰动引入[训练流程](https://huggingface.co/papers?q=training%20pipeline)。为稳定训练，同时鼓励 agent 处理日益具有挑战性的不完美情况，噪声仅施加于一部分 [rollout](https://huggingface.co/papers?q=rollout)，并随着模型适应当前噪声水平而逐步提升难度。大量实验表明，我们的方法在噪声和动态环境下持续提升 agent 鲁棒性。我们的分析揭示，在噪声条件下训练也能在理想化基准上带来性能提升，这表明受控地暴露于环境噪声有助于促进更具[泛化性的推理](https://huggingface.co/papers?q=generalizable%20reasoning)与[决策行为](https://huggingface.co/papers?q=decision-making%20behaviors)。我们的发现凸显了建模交互不完美对于弥合 agent 训练与[真实世界部署](https://huggingface.co/papers?q=real-world%20deployment)之间差距的重要性。
