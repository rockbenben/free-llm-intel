# Groq Changelog

## 2025-04-21 (Python SDK v0.22.0, TypeScript SDK v0.19.0)

### [ADDED] Compound Beta 与 Compound Beta Mini 系统

Compound Beta 和 Compound Beta Mini 是内置网络搜索与代码执行能力的智能体工具体系。在与实时数据交互时，这些系统能简化你的工作流，免除自行添加工具去搜索网络的负担。阅读更多关于 [Groq 上的 agentic tooling](https://console.groq.com/docs/agentic-tooling) 的内容，或现在就把模型切换为 `compound-beta` 或 `compound-beta-mini` 开始使用。

**性能：**

- Compound Beta (`compound-beta`)：350 tokens/秒 (TPS)，延迟约 4,900 ms
- Compound Beta Mini (`compound-beta-mini`)：275 TPS，延迟约 1,600 ms

**使用示例：**

```curl
curl "https://api.groq.com/openai/v1/chat/completions" \
 -X POST \
 -H "Content-Type: application/json" \
 -H "Authorization: Bearer ${GROQ_API_KEY}" \
 -d '{
 "messages": [
 {
 "role": "user",
 "content": "what happened in ai this week?"
 }
 ],
 "model": "compound-beta",
 }'
```
