### Changed[Python SDK v0.31.0, TypeScript SDK v0.30.0](#python-sdk-v0310-typescript-sdk-v0300)

The Python SDK has been updated to v0.30.0 and the Typescript SDK has been updated to v0.27.0.

**Key Changes:**

* Added support for `high`, `medium`, and `low` options for `reasoning_effort` when using GPT-OSS models to control their reasoning output. [Learn more about how to use these options to control reasoning tokens.](https://console.groq.com/docs/reasoning#reasoning-effort)
* Added support for [browser\_search](https://console.groq.com/docs/browser-search) and [code\_interpreter](https://console.groq.com/docs/code-execution) as function/tool definition types in the `tools` array in a chat completion request. Specify one or both of these as tools to allow GPT-OSS models to automatically call them on the server side when needed.
* Added an optional `include_reasoning` boolean option to chat completion requests to allow configuring if the model returns a response in a `reasoning` field or not.
