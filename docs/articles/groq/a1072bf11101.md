# Groq Changelog

## 2026-04-18 (Python SDK v1.2.0, TypeScript SDK v1.1.2)

### [ADDED] MiniMax M2.5 与 Qwen3-VL 32B Instruct（企业版）

`minimaxai/minimax-m2.5` 和 `qwen/qwen3-vl-32b-instruct` 现已面向企业客户在 GroqCloud 上提供。

- [`minimaxai/minimax-m2.5`](https://console.groq.com/docs/model/minimaxai/minimax-m2.5) — MiniMax 最新的通用模型，可用于企业级工作负载。
- [`qwen/qwen3-vl-32b-instruct`](https://console.groq.com/docs/model/qwen/qwen3-vl-32b-instruct) — Qwen 3 VL Instruct (32B)，一款面向多模态企业场景的视觉-语言模型。

如需开通，请联系你的 Groq 客户团队。

### [ADDED] Orpheus Arabic Saudi 新增音色

[`canopylabs/orpheus-arabic-saudi`](https://console.groq.com/docs/model/canopylabs/orpheus-arabic-saudi) 新增两个音色：

- **Abdullah** — 现为默认音色
- **Aisha**

Arabic Saudi 模型现共支持六个音色：Abdullah、Fahad、Sultan、Lulwa、Noura 和 Aisha。音频样例与用法示例见 [Orpheus TTS 文档](https://console.groq.com/docs/text-to-speech/orpheus)。

### [CHANGED] Python SDK v1.2.0 与 TypeScript SDK v1.1.2

继 [2025 年 12 月 v1.0.0 正式发布](https://github.com/groq/groq-python/releases/tag/v1.0.0)之后，两个 SDK 在第一季度进行了一系列更新。

**Python SDK** ([v1.2.0](https://github.com/groq/groq-python/releases/tag/v1.2.0))

- **v1.2.0** — 在与用户参数合并时保留硬编码的查询参数；确保文件数据作为单个参数发送；改进 multipart 请求的文件复制性能；为查询和表单序列化引入数组 indices 格式。
- **v1.1.2** — 对 endpoint 路径参数做净化处理；除非显式设置，否则不向 Pydantic 传递 `by_alias`；提升 `typing-extensions` 的最低版本。
- **v1.1.0** — 新增二进制请求流式传输支持，并提供自定义 JSON 编码器以支持扩展类型；弃用 Python 3.9。

**TypeScript SDK** ([v1.1.2](https://github.com/groq/groq-typescript/releases/tag/v1.1.2))

- **v1.1.1** — 恢复 `defaultParseResponse` 中的流式支持；修复 abort-signal 内存泄漏，避免过早移除 abort 监听器；保留已嵌入路径中的 URL 参数；锁定打过补丁的 `minimatch` 版本以应对 CVE-2026-27…。
- **v1.1.2** — 迁移 GitHub Actions OIDC token；更新依赖。

## 2026-01-30 (Python SDK v1.0.0, TypeScript SDK v1.1.0)

### [CHANGED] 全平台从 PlayAI 迁移至 Orpheus TTS

继 2025 年 12 月宣布弃用 `playai-tts` 和 `playai-tts-arabic` 之后，文本转语音已在全平台迁移至 Canopy Labs 的 [Orpheus](https://console.groq.com/docs/text-to-speech/orpheus) 模型。更新的 Orpheus 模型凭借语音方向控制带来更强的表现力、更快的推理以及更好的音质。

[Groq Chat](https://chat.groq.com) 现使用 Orpheus，聊天设置中提供以下音色：

- **English** ([`canopylabs/orpheus-v1-english`](https://console.groq.com/docs/model/canopylabs/orpheus-v1-english)) — autumn、diana、hannah、austin、daniel、troy
- **Arabic** ([`canopylabs/orpheus-arabic-saudi`](https://console.groq.com/docs/model/canopylabs/orpheus-arabic-saudi)) — fahad、sultan、lulwa、noura

如果你仍直接使用了 `playai-tts` 或 `playai-tts-arabic`，请在[弃用页面](https://console.groq.com/docs/deprecations)列出的停用日期之前迁移到对应的 Orpheus 模型。
