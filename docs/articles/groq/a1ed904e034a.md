##### **Llama 3 现已通过 GroqChat 和 GroqCloud™ 向开发者开放**

以下是过去 36 小时内发生的事情：

- **4 月 18 日，中午：** [Meta 发布](https://ai.meta.com/blog/meta-llama-3/)其最新大语言模型（LLM）Llama 3 的多个版本。
- **4 月 19 日，午夜：** Groq 发布运行在其 LPU™ 推理引擎上的 Llama 3 8B (8k) 和 70B (4k, 8k)，开发者社区可通过 [groq.com](https://groq.com/) 和 [GroqCloud™ Console](https://console.groq.com/playground) 使用。
- **4 月 19 日，上午 10 点：** [ArtificialAnalysis.ai](http://ArtificialAnalysis.ai) 发布其第一组 [Llama 3 基准测试](https://artificialanalysis.ai/models/llama-3-instruct-70b/providers)结果。

> Artificial Analysis 独立测试表明，Groq 在 Llama 3 8B 上达到 877 tokens/s 的吞吐量，在 Llama 3 70B 上达到 284 tokens/s，是所有提供商中最高的，且领先超过 2 倍。Groq 的报价同样具有价格竞争力，两款模型的定价均不高于其他提供商。结合 Llama 3 出色的质量，Groq 的方案对广泛的使用场景都极具吸引力，包括那些需要与 LLM 进行大量交互的新兴场景，例如 AI 智能体。——George Cameron，ArtificialAnalysis.ai 联合创始人

## 吞吐量

Groq 为 Llama 3 70B 提供 284 tokens/s 的吞吐量，比其他提供商快 3-11 倍以上。

## 吞吐量与价格

ArtificialAnalysis.ai 使用的混合价格（输入/输出）为 $0.64/1M tokens，而 Groq 目前对 Llama 3 70B 的[定价](https://groq.com/)为输入 $0.59、输出 $0.79（每 1M tokens）。

## 延迟与吞吐量

以发送 API 请求后收到第一个 token 块的秒数衡量的延迟，对比每秒 token 数衡量的吞吐量，Groq 的表现是 0.3 秒对 282 tokens/s。

## 总响应时间

以收到 100 个输出 token 的时间衡量（由延迟和吞吐量指标计算得出），Groq 用时 0.6 秒。
