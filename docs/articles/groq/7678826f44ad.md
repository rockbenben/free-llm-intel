# Moonshot AI Kimi 2 Instruct

### 新增[Moonshot AI Kimi 2 Instruct](#moonshot-ai-kimi-2-instruct)

[Kimi K2 Instruct](https://console.groq.com/docs/model/moonshotai/kimi-k2-instruct) 是 Moonshot AI 最先进的 Mixture-of-Experts（MoE）语言模型，总参数量为 1 万亿，激活参数为 320 亿。它为 agentic 智能而设计，在 tool use、编程以及跨领域的自主问题解决上表现出色。

Kimi K2 Instruct 非常适合 agentic 用例和编程。[在这里了解更多关于如何使用工具的信息。](https://console.groq.com/docs/tool-use)

**主要特性：**

* 131K token 上下文窗口
* 最多 16K 输出 token
* MoE 架构，拥有 384 个专家（每个 token 选用 8 个）
* 在 agentic 和编程用例上超过 GPT-4.1

**性能指标：**

* LiveCodeBench 上 Pass@1 为 53.7%（编程能力）
* SWE-bench Verified 上单次尝试准确率 65.8%
* MMLU 上 exact match 为 89.5%
* Tau2 零售任务上 Avg@4 为 70.6%

**使用示例：**

curl

```
curl https://api.groq.com/openai/v1/chat/completions \
  -H "Authorization: Bearer $GROQ_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "moonshotai/kimi-k2-instruct",
    "messages": [
      {
        "role": "user",
        "content": "Explain why fast inference is critical for reasoning models"
      }
    ]
  }'
```
