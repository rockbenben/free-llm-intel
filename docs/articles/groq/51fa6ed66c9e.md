# Python SDK v0.23.0, TypeScript SDK v0.20.0

### 变更[Python SDK v0.23.0, TypeScript SDK v0.20.0](#python-sdk-v0230-typescript-sdk-v0200)

Python SDK 已更新至 v0.23.0，TypeScript SDK 已更新至 v0.20.0。

**主要变更：**

* `groq.files.content` 现在返回一个 `Response` 对象，以便按需把内容解析成文本（用于 `jsonl` 文件），或作为 blob 处理通用文件类型。此前把它声明为 JSON 对象的返回类型是错误的，那会导致 SDK 遇到报错而不是返回文件内容。Typescript 中的示例用法：

curl

```
const response = await groq.files.content("file_XXXX");
const file_text = await response.text();
```

* `BatchCreateParams` 现在接受 `string` 作为 `completion_window` 的入参，从而可以使用 `24h` 到 `7d` 之间的时长。使用更长的 completion window 会让你的 batch 任务有更大的机会在不超时的情况下顺利完成。对于较大的 batch 请求，建议把它们拆分为多个 batch 任务。[了解更多关于批处理的最佳实践](https://console.groq.com/docs/batch)。
* 更新了 chat completion 的 `model` 参数，移除已弃用的模型并加入更新的 production 模型。  
  * 移除：`gemma-7b-it` 和 `mixtral-8x7b-32768`。
  * 新增：`gemma2-9b-it`、`llama-3.3-70b-versatile`、`llama-3.1-8b-instant` 和 `llama-guard-3-8b`。
  * 关于 Groq 模型最新的信息，请查看 [models 页面](https://console.groq.com/docs/models)，或了解我们的 [弃用政策](https://console.groq.com/docs/deprecations)。
* 为 chat completion 新增了可选的 `metadata` 参数，以提升与 OpenAI chat completion API 的兼容性。[了解更多关于从 OpenAI 切换到 Groq 的信息](https://console.groq.com/docs/openai)。
