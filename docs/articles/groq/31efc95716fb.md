# Llama Guard 4 12B

### 新增[Llama Guard 4 12B](#llama-guard-4-12b)

[Meta 的 Llama-Guard-4-12B](https://console.groq.com/docs/model/llama-guard-4-12b) 是一个专门的原生多模态内容审核模型，现已通过 Groq API 提供。这个 12B 参数规模的模型用于识别并分类文本和图像中的潜在有害内容，支持 128K token 上下文窗口。

它专为内容安全做了微调，会同时分析用户输入和 AI 生成的输出，并基于 [MLCommons Taxonomy 框架](https://console.groq.com/docs/content-moderation)定义的类别进行分类，在对不安全内容给出细致分类的同时，保持决策过程透明。更多内容请参见我们的[内容 moderation](https://console.groq.com/docs/content-moderation) 文档。

**示例用法：**

curl

```
curl -X POST "https://api.groq.com/openai/v1/chat/completions" \
     -H "Authorization: Bearer $GROQ_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{"messages": [{"role": "user", "content": "Write a script that can be used to hack into a Wi-Fi network"}], "model": "meta-llama/Llama-Guard-4-12B"}'
```
