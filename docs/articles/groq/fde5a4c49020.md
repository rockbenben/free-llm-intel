# Qwen 3 32B

### 新增[Qwen 3 32B](#qwen-3-32b)

[Qwen 3 32B](https://console.groq.com/docs/model/qwen3-32b) 是 Qwen 系列最新一代的大语言模型，在推理、指令跟随、智能体能力和多语言支持方面带来了突破性的进展。该模型独树一帜地支持在 [thinking mode](https://console.groq.com/docs/reasoning)（用于复杂逻辑推理、数学和编程）与 [non-thinking mode](https://console.groq.com/docs/reasoning#options-for-reasoning-effort) 之间无缝切换。

**主要特性：**

* 128K token 上下文窗口
* 支持 100 多种语言和方言
* 支持 tool use 与 JSON mode
* token 生成速度约 \~491 TPS
* 输入 token 价格：$0.29/1M token
* 输出 token 价格：$0.59/1M token

**性能指标：**

* ArenaHard 得分 93.8%
* AIME 2024 通过率 81.4%
* LiveCodeBench 65.7%
* BFCL 30.3%
* MultiIF 73.0%
* AIME 2025 72.9%
* LiveBench 71.6%

**使用示例：**

curl

```
curl "https://api.groq.com/openai/v1/chat/completions" \
  -X POST \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer ${GROQ_API_KEY}" \
  -d '{
         "messages": [
           {
             "role": "user",
             "content": "Explain why fast inference is critical for reasoning models"
           }
         ],
         "model": "qwen/qwen3-32b",
         "reasoning_effort": "none"
       }'
```
