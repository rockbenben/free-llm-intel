# Python SDK v0.25.0, TypeScript SDK v0.22.0

### 变更[Python SDK v0.25.0、TypeScript SDK v0.22.0](#python-sdk-v0250-typescript-sdk-v0220)

Python SDK 已更新至 v0.25.0，TypeScript SDK 已更新至 v0.22.0。

**主要变更：**

* 弃用了使用 [agentic tooling 系统](https://console.groq.com/docs/agentic-tooling)时的 `exclude_domains` 和 `include_domains` 参数。请改用新的 `search_settings` 参数来指定要检索或忽略的域名。
