# MiniMax M2.5 与 Qwen3-VL 32B Instruct 上线（企业版）

### 新增[MiniMax M2.5 与 Qwen3-VL 32B Instruct（Enterprise）](#minimax-m25-and-qwen3vl-32b-instruct-enterprise)

`minimaxai/minimax-m2.5` 和 `qwen/qwen3-vl-32b-instruct` 现已面向 Enterprise 客户在 GroqCloud 上提供。

* [minimaxai/minimax-m2.5](https://console.groq.com/docs/model/minimaxai/minimax-m2.5) — MiniMax 最新的通用模型，可用于 Enterprise 工作负载。
* [qwen/qwen3-vl-32b-instruct](https://console.groq.com/docs/model/qwen/qwen3-vl-32b-instruct) — Qwen 3 VL Instruct（32B），面向多模态 Enterprise 用例的视觉-语言模型。

如需获取访问权限，请联系你的 Groq 客户团队。
