# Python SDK v0.29.0, TypeScript SDK v0.26.0

### 变更[Python SDK v0.29.0、TypeScript SDK v0.26.0](#python-sdk-v0290-typescript-sdk-v0260)

Python SDK 已更新至 v0.29.0，TypeScript SDK 已更新至 v0.26.0。

**主要变更：**

* 为 [agentic tool 系统](https://console.groq.com/docs/agentic-tooling)（[compound-beta](https://console.groq.com/docs/agentic-tooling/compound-beta) 和 [compound-beta-mini](https://console.groq.com/docs/agentic-tooling/compound-beta-mini)）的 `search_settings` 参数新增 `country` 字段。这个新参数让你可以优先展示来自特定国家的搜索结果。支持的完整国家列表见 [Agentic Tooling 文档](https://console.groq.com/docs/agentic-tooling#search-settings)。
