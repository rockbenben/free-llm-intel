# Compound Beta 与 Compound Beta Mini 系统

### 新增[Compound Beta 与 Compound Beta Mini 系统](#compound-beta-and-compound-beta-mini-systems)

Compound Beta 和 Compound Beta Mini 是内置网页搜索与代码执行的 agentic 工具系统。这些系统简化了你与实时数据交互时的工作流，让你不必再自己添加工具去搜索网页。更多阅读请见[Groq 上的 agentic tooling](https://console.groq.com/docs/agentic-tooling)，或者直接切换到 `compound-beta` 或 `compound-beta-mini` 就开始使用。

**性能：**

* Compound Beta（`compound-beta`）：350 tokens 每秒（TPS），延迟约 \~4,900 ms
* Compound Beta Mini（`compound-beta-mini`）：275 TPS，延迟约 \~1,600 ms

**示例用法：**

curl

```
curl "https://api.groq.com/openai/v1/chat/completions" \
  -X POST \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer ${GROQ_API_KEY}" \
  -d '{
         "messages": [
           {
             "role": "user",
             "content": "what happened in ai this week?"
           }
         ],
         "model": "compound-beta",
       }'
```
