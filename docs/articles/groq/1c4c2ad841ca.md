# Groq Changelog

## 2025-04-14 (Python SDK v0.22.0, TypeScript SDK v0.19.0)

### [ADDED] Meta Llama 4 支持

Meta 的 Llama 4 Scout (17Bx16MoE) 和 Maverick (17Bx128E) 模型现已通过 Groq API 提供，支持图像理解与文本生成，具备 128K token 上下文窗口、最多 5 张图片的图像输入、function calling/工具调用以及 JSON 模式。详见我们的 [tool use](https://console.groq.com/docs/tool-use) 和 [vision](https://console.groq.com/docs/vision) 文档。

**性能（由 [AA](https://artificialanalysis.ai/) 基准测试）：**

- Llama 4 Scout (`meta-llama/llama-4-scout-17b-16e-instruct`)：当前 607 tokens/秒 (TPS)
- Llama 4 Maverick (`meta-llama/llama-4-maverick-17b-128e-instruct`)：当前 297 TPS

**使用示例：**

```curl
curl "https://api.groq.com/openai/v1/chat/completions" \
 -X POST \
 -H "Content-Type: application/json" \
 -H "Authorization: Bearer ${GROQ_API_KEY}" \
 -d '{
 "messages": [
 {
 "role": "user",
 "content": "why is fast inference crucial for ai apps?"
 }
 ],
 "model": "meta-llama/llama-4-maverick-17b-128e-instruct",
 }'
```

# Groq Changelog

这是 Groq API 与 Groq SDK 的官方更新日志，记录变更内容及其发生时间。

## 目的

本仓库按时间倒序（最新在前）记录了 Groq API 以及 [Python](https://github.com/groq/groq-python) 和 [TypeScript](https://github.com/groq/groq-typescript) SDK 的变更历史，帮助你跟踪最新动态。每周一发布。

## 如何订阅更新

1. **Watch 本仓库**：点击本页面右上角的 "Watch" 按钮，即可在我们推送更新时收到通知
2. **Star 本仓库**：Star 收藏以便日后查看
3. **RSS 订阅**：通过 GitHub 的 RSS feed 订阅

## 我们跟踪的类别

- **Added**：新功能、新模型或新能力
- **Fixed**：Bug 修复
- **Deprecated**：即将移除的功能
- **Removed**：已被移除的功能
