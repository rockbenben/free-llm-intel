# Python SDK v0.26.0, TypeScript SDK v0.23.0

### 变更[Python SDK v0.26.0、TypeScript SDK v0.23.0](#python-sdk-v0260-typescript-sdk-v0230)

Python SDK 已更新至 v0.26.0，TypeScript SDK 已更新至 v0.23.0。

**主要变更：**

* 使用 [agentic tooling 系统](https://console.groq.com/docs/agentic-tooling)时的 `search_settings` 参数现在包含一个新字段：`include_images`。将其设为 `true` 可在搜索结果中包含图像，设为 `false` 则从搜索结果中排除图像。
* 使用 [agentic tooling 系统](https://console.groq.com/docs/agentic-tooling)时，每个已执行工具的输出都新增了 `code_results`。该字段可以包含 `png`（当代码执行产出图像时，以 Base64 格式编码）和 `text`（代码执行的文本输出）。
