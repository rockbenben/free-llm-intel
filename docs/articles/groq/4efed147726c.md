# Compound Beta 检索设置

### 新增[Compound Beta 检索设置](#compound-beta-search-settings)

Groq 的 Compound Beta 与 Compound Beta Mini agentic 工具系统现在支持基于域名的检索过滤，通过两个新参数实现：`exclude_domains` 和 `include_domains`。

* `exclude_domains` 允许你指定应当从网页检索结果中排除的域名。
* `include_domains` 让你把网页检索限制为只返回指定域名的结果。

排除 Wikipedia 的示例用法：

curl

```
curl "https://api.groq.com/openai/v1/chat/completions" \
  -X POST \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer ${GROQ_API_KEY}" \
  -d '{
         "messages": [
           {
             "role": "user",
             "content": "Tell me about the history of Bonsai trees in America"
           }
         ],
         "model": "compound-beta-mini",
         "exclude_domains": ["wikipedia.org"]
       }'
```

[在我们的文档中了解更多关于检索设置的内容](https://console.groq.com/docs/agentic-tooling#search-settings)，包括[使用域名通配符的高级用法](https://console.groq.com/docs/agentic-tooling#domain-filtering-with-wildcards)。
