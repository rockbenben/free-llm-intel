# Groq Changelog

## 2025-09-05 (Python SDK v0.31.1, TypeScript SDK v0.32.0)

### [ADDED] Moonshot AI Kimi K2 Instruct 0905

[Kimi K2-0905](https://console.groq.com/docs/model/moonshotai/kimi-k2-instruct-0905) 以 day zero 支持将 Moonshot AI 的前沿模型带到 GroqCloud，提供生产级速度、低延迟和可预期成本，助力更上一层的智能体编程应用。

这一最新版本相较原版 Kimi K2 有显著提升，包括可媲美前沿闭源模型的智能体编程能力，以及大幅改进的前端开发表现。[了解更多关于如何使用工具的信息。](https://console.groq.com/docs/tool-use)

**核心特性：**

- **256K 上下文窗口** - 迄今 GroqCloud 上所有模型中最大的上下文窗口
- **提示缓存** - 缓存 token 最多节省 50% 成本，响应速度大幅加快
- **领先的性价比** - 200+ t/s，混合价格 $1.50/M token（输入 $1.00/M；输出 $3.00/M）
- **更强的智能体编程** - 代码生成更可靠，尤其是复杂的多轮交互

**使用示例：**

```curl
curl https://api.groq.com/openai/v1/chat/completions \
 -H "Authorization: Bearer $GROQ_API_KEY" \
 -H "Content-Type: application/json" \
 -d '{
 "model": "moonshotai/kimi-k2-instruct-0905",
 "messages": [
 {
 "role": "user",
 "content": "Explain why fast inference is critical for reasoning models"
 }
 ]
 }'
```

## 2025-09-04 (Python SDK v0.31.1, TypeScript SDK v0.32.0)

### [ADDED] Groq Compound 与 Compound Mini

[Compound](https://console.groq.com/docs/compound/systems/compound)（`groq/compound`）和 [Compound Mini](https://console.groq.com/docs/compound/systems/compound-mini)（`groq/compound-mini`）是 Groq 生产就绪的智能体 AI 系统，将网络搜索、代码执行和浏览器自动化整合到单次 API 调用中。这两个系统从 beta 升级为正式可用（GA），以领先的品质、低延迟和成本效率，为自主智能体应用提供前沿级性能。

Compound 基于 OpenAI 的 GPT-OSS-120B 和 Meta 的 Llama 模型构建，在各项基准上准确率提升约 25%、错误减少约 50%，超越 OpenAI 的 Web Search Preview 和 Perplexity Sonar。[了解更多关于 agentic tooling 的信息。](https://console.groq.com/docs/compound)

**核心特性：**

- **内置服务端工具** - [网络搜索](https://console.groq.com/docs/web-search)、[代码执行](https://console.groq.com/docs/code-execution)、[Wolfram Alpha](https://console.groq.com/docs/wolfram-alpha) 和[并行浏览器自动化](https://console.groq.com/docs/browser-automation)
- **生产级稳定性** - 正式可用，速率限制和可靠性进一步提升
- **前沿性能** - 在 SimpleQA 和 RealtimeEval 基准上优于竞品系统
- **单次 API 调用** - 复杂智能体工作流无需客户端编排

**增强能力：**

- [并行浏览器自动化](https://console.groq.com/docs/browser-automation)（最多同时 10 个浏览器）
- 高级搜索，可从网页结果中提取更丰富的上下文
- [Wolfram Alpha 集成](https://console.groq.com/docs/wolfram-alpha)，实现精确的数学与科学计算
- 改进的 markdown 渲染，输出更结构化、便于下游消费

**使用示例：**

```curl
curl https://api.groq.com/openai/v1/chat/completions \
 -H "Authorization: Bearer $GROQ_API_KEY" \
 -H "Content-Type: application/json" \
 -d '{
 "model": "groq/compound",
 "messages": [
 {
 "role": "user",
 "content": "Research the latest developments in AI inference optimization and summarize key findings"
 }
 ]
 }'
```
