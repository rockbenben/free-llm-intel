# Python SDK v0.28.0, TypeScript SDK v0.25.0

### 变更[Python SDK v0.28.0、TypeScript SDK v0.25.0](#python-sdk-v0280-typescript-sdk-v0250)

Python SDK 已更新至 v0.28.0，TypeScript SDK 已更新至 v0.25.0。

**主要变更：**

* 为 chat completion 的 assistant 消息新增 `reasoning` 字段。当 [reasoning\_format](https://console.groq.com/docs/reasoning#options-for-reasoning-format) 被设为 `"parsed"` 时，这里就是 assistant 给出的 reasoning 输出。该字段只能与 Qwen 3 模型一起使用。
* 为 Qwen 3 模型（目前仅 [qwen/qwen3-32b](https://console.groq.com/docs/model/qwen3-32b)）新增 [reasoning\_effort](https://console.groq.com/docs/reasoning#options-for-reasoning-effort) 参数。设为 `"none"` 可禁用 reasoning。
