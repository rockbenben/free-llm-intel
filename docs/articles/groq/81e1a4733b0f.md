# GPT-OSS 120B 启用提示词缓存

### 新增[为 GPT-OSS 120B 启用 prompt caching](#prompt-caching-enabled-for-gptoss-120b)

[openai/gpt-oss-120b](https://console.groq.com/docs/model/openai/gpt-oss-120b) 现已启用自动 prompt caching。缓存命中会自动带来：

* 缓存的输入 token **节省 50% 成本**（$0.075/M 对比 $0.15/M）
* 通过复用计算带来**更低的延迟**
* **更高的有效速率限制** \- 缓存 token 不计入速率限制

无需任何配置 —— 当你的请求与近期请求共享相同前缀时，你会自动从缓存中受益。[了解更多关于 prompt caching 的信息](https://console.groq.com/docs/prompt-caching)。
