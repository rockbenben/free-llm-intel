# MCP 连接器（测试版）

### 新增[MCP 连接器（测试版）](#mcp-connectors-beta)

[MCP 连接器](https://console.groq.com/docs/tool-use/remote-mcp/connectors)提供了一种简化的方式来集成常用业务应用，你不必再自己构建 MCP server。Groq 现已支持 Google Workspace 连接器，借助基于 Model Context Protocol（MCP）的预置集成，让你即时访问 Gmail、Google Calendar 和 Google Drive。

**可用的连接器：**

* [**Gmail**](https://console.groq.com/docs/tool-use/remote-mcp/connectors#gmail-example) \- 读取和搜索邮件
* [**Google Calendar**](https://console.groq.com/docs/tool-use/remote-mcp/connectors#google-calendar-example) \- 查看日历事件
* [**Google Drive**](https://console.groq.com/docs/tool-use/remote-mcp/connectors#google-drive-example) \- 搜索并访问文件和文档

**主要特性：**

* **零配置** \- 预置连接器省去了开发自定义 MCP server 的需要
* **OAuth 2.0 认证** \- 安全访问 Google Workspace 服务
* **兼容 OpenAI Responses API** \- 与已有的 Responses API 工作流无缝衔接

**各连接器可用的工具：**

* **Gmail**：`get_profile`、`search_emails`、`get_recent_emails`、`read_email`
* **Google Calendar**：`get_profile`、`search`、`search_events`、`read_event`
* **Google Drive**：`get_profile`、`search`、`recent_documents`、`fetch`

**使用示例：**

curl

```
curl https://api.groq.com/openai/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $GROQ_API_KEY" \
  -d '{
    "model": "openai/gpt-oss-120b",
    "tools": [{
      "type": "mcp",
      "server_label": "Gmail",
      "connector_id": "connector_gmail",
      "authorization": "ya29.A0AR3da...",
      "require_approval": "never"
    }],
    "input": "Show me unread emails from this week"
  }'
```

了解更多关于 Groq 上 [MCP 连接器](https://console.groq.com/docs/tool-use/remote-mcp/connectors)和 [Remote MCP](https://console.groq.com/docs/tool-use/remote-mcp) 的信息。

MCP 连接器目前处于 beta 阶段。欢迎在 [Community](https://community.groq.com) 分享你的反馈。
