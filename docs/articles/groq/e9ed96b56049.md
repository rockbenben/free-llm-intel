# Groq Changelog

## 2025-12-01 (Python SDK v0.37.0, TypeScript SDK v0.37.0)

### [ADDED] MCP Connectors（Beta）

[MCP Connectors](https://console.groq.com/docs/tool-use/remote-mcp/connectors) 提供了一种简化的方式来集成主流商业应用，无需自行构建定制的 MCP 服务器。Groq 现已支持 Google Workspace 连接器，通过基于 Model Context Protocol (MCP) 的预构建集成，让你可以即时访问 Gmail、Google Calendar 和 Google Drive。

**可用连接器：**

- [**Gmail**](https://console.groq.com/docs/tool-use/remote-mcp/connectors#gmail-example) - 读取和搜索邮件
- [**Google Calendar**](https://console.groq.com/docs/tool-use/remote-mcp/connectors#google-calendar-example) - 查看日历事件
- [**Google Drive**](https://console.groq.com/docs/tool-use/remote-mcp/connectors#google-drive-example) - 搜索并访问文件与文档

**核心特性：**

- **零配置** - 预构建的连接器免去开发自定义 MCP 服务器的需要
- **OAuth 2.0 认证** - 安全访问 Google Workspace 服务
- **兼容 OpenAI Responses API** - 与现有 Responses API 工作流无缝协作

**各连接器可用工具：**

- **Gmail**: `get_profile`, `search_emails`, `get_recent_emails`, `read_email`
- **Google Calendar**: `get_profile`, `search`, `search_events`, `read_event`
- **Google Drive**: `get_profile`, `search`, `recent_documents`, `fetch`

**使用示例：**

```curl
curl https://api.groq.com/openai/v1/responses \
 -H "Content-Type: application/json" \
 -H "Authorization: Bearer $GROQ_API_KEY" \
 -d '{
 "model": "openai/gpt-oss-120b",
 "tools": [{
 "type": "mcp",
 "server_label": "Gmail",
 "connector_id": "connector_gmail",
 "authorization": "ya29.A0AR3da...",
 "require_approval": "never"
 }],
 "input": "Show me unread emails from this week"
 }'
```

在 Groq 上了解更多关于 [MCP Connectors](https://console.groq.com/docs/tool-use/remote-mcp/connectors) 和 [Remote MCP](https://console.groq.com/docs/tool-use/remote-mcp) 的信息。

MCP Connectors 目前处于 beta 阶段。欢迎在 [Community](https://community.groq.com) 分享你的反馈。
