今天，恰是我们上线 GroqCloud 一周年的这一周，我们正在庆祝如今在 GroqCloud 上的 100 万开发者！仅仅一年，这个由建造者、创客和创新者组成的社区就交付了令人惊叹的应用，参加并赢得了黑客松，把创新产品化，甚至创立了公司。我们还持续迎来了 Dev Tier 的数千名付费客户，以及用我们基于 LPU 的系统构建 AI 方案的企业。

https://www.youtube.com/watch?v=Qfp6-OBZHA4

一切始于去年此时我们的走红。48 小时内我们收到约 3,000 个 API 访问申请，GroqChat 提交了约 100 万个提示词，众多行业影响力人物在 YouTube 和 X 上与我们一起兴奋——包括 Matt Shumer，他制作了一些精彩的 GroqChat 演示，从 [AI 问答引擎](https://x.com/mattshumer_/status/1759448999457693816?s=20)到两分钟内[写小说](https://x.com/mattshumer_/status/1759624554836537492?s=20)。Groq 还[登上 CNN](https://www.youtube.com/watch?v=pRUddK6sxDg)，对我们的 CEO 兼创始人 Jonathan Ross 进行了采访。

在新的一年，我们会更多地出现在美国、中东、南亚、欧盟以及线上的各个场合。过去一年让我们看到众多富有灵感的作品，我们迫不及待想知道工程师们会用我们的快速 AI 推理方案做出什么。我们将持续创新，把最好的带给你们。

一如既往，欢迎并感谢大家向我们由开源社区驱动的 [Groq API Cookbook](https://github.com/groq/groq-api-cookbook/tree/main/tutorials/jigsawstack-prompt-engine) 投稿！这个持续更新的仓库汇集了好用的技巧、酷炫的应用和富有启发性的演示，我们很自豪能与所有人分享。

别忘了，我们已经开放了 Dev Tier 的自助开通——这意味着你可以用更高的速率限制和更多服务选项（如 Flex Pricing 弹性定价和 Batch Processing 批处理）把你的构建、应用和方案推向极致。欢迎在拥有 2.2 万多名成员的 [Discord 社区](https://discord.com/invite/groq)分享你的项目，并在社交媒体帖子中 @ 我们，让我们评论、点赞和转发。

感谢你们帮助我们了解自身体验、迭代我们的产品与服务；教会我们看到：当用快速推理和超低延迟释放开发者的创造力时，可能性有多大。再次感谢你们让过去一年成为载入史册的一年，没有你们就没有今天的我们。我们会继续在推理上创新，请继续交付你们的成果，我们一起 **Build Fast（快速构建）！**
