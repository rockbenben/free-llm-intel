# Moonshot AI Kimi K2 Instruct 0905

### 新增[Moonshot AI Kimi K2 Instruct 0905](#moonshot-ai-kimi-k2-instruct-0905)

[Kimi K2-0905](https://console.groq.com/docs/model/moonshotai/kimi-k2-instruct-0905) 把 Moonshot AI 最前沿的模型带上 GroqCloud，并提供 day zero 支持，为更上一层的 agentic coding 应用交付生产级的速度、低延迟和可预期的成本。

这一最新版本相比最初的 Kimi K2 有显著提升，包括足以与前沿闭源模型匹敌的 agentic coding 能力，以及好得多的前端开发表现。[在这里了解更多关于如何使用工具的信息。](https://console.groq.com/docs/tool-use)

**主要特性：**

* **256K 上下文窗口** \- GroqCloud 迄今所有模型中最大的上下文窗口
* **Prompt caching** \- 缓存命中的 token 最多省下 50% 成本，响应速度快上许多
* **领先的性价比** \- 200+ t/s，混合价格 $1.50/M token（输入 $1.00/M；输出 $3.00/M）
* **改进的 agentic coding** \- 代码生成更可靠，在复杂的多轮交互中尤其如此

**使用示例：**

curl

```
curl https://api.groq.com/openai/v1/chat/completions \
  -H "Authorization: Bearer $GROQ_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "moonshotai/kimi-k2-instruct-0905",
    "messages": [
      {
        "role": "user",
        "content": "Explain why fast inference is critical for reasoning models"
      }
    ]
  }'
```
