# Python SDK v0.31.1, TypeScript SDK v0.32.0

### 变更[Python SDK v0.31.1、TypeScript SDK v0.32.0](#python-sdk-v0311-typescript-sdk-v0320)

Python SDK 已更新至 v0.31.1，TypeScript SDK 已更新至 v0.32.0。

**主要变更：**

* 改进了 chat completion 的消息类型定义，以更好地兼容 OpenAI。这修复了在某些不同消息格式下出现的错误。
* 新增对新版 Groq Compound 工具的支持（[Wolfram Alpha](https://console.groq.com/docs/wolfram-alpha)、[Browser Automation](https://console.groq.com/docs/browser-automation)、[Visit Website](https://console.groq.com/docs/visit-website)）
