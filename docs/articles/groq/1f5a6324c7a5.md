# Groq Changelog

## 2025-05-08 (Python SDK v0.24.0, TypeScript SDK v0.21.0)

### [ADDED] Compound Beta Search Settings（Compound Beta 搜索设置）

Groq 的 Compound Beta 与 Compound Beta Mini 智能体工具体系现已支持基于域名的搜索过滤，通过两个新参数实现：`exclude_domains` 和 `include_domains`。

 - `exclude_domains` 允许你指定应从网络搜索结果中忽略的域名。
 - `include_domains` 允许你将网络搜索限定为只返回指定域名的结果。

在搜索中排除 Wikipedia 的示例用法：

```sh
curl "https://api.groq.com/openai/v1/chat/completions" \
 -X POST \
 -H "Content-Type: application/json" \
 -H "Authorization: Bearer ${GROQ_API_KEY}" \
 -d '{
 "messages": [
 {
 "role": "user",
 "content": "Tell me about the history of Bonsai trees in America"
 }
 ],
 "model": "compound-beta-mini",
 "exclude_domains": ["wikipedia.org"]
 }'
```

[在我们的文档中了解更多关于搜索设置的信息](https://console.groq.com/docs/agentic-tooling#search-settings)，包括[使用域名通配符的高级用法](https://console.groq.com/docs/agentic-tooling#domain-filtering-with-wildcards)。

### [CHANGED] Python SDK v0.24.0, TypeScript SDK v0.21.0

Python SDK 已更新至 v0.24.0，TypeScript SDK 已更新至 v0.21.0。

**主要变更：**

 - 为 Compound Beta [搜索设置](https://console.groq.com/docs/agentic-tooling#search-settings)新增域名过滤支持。使用 [`compound-beta`](https://console.groq.com/docs/agentic-tooling/compound-beta) 或 [`compound-beta-mini`](https://console.groq.com/docs/agentic-tooling/compound-beta-mini) 模型时，可用 `include_domains` 将搜索限定到特定域名，或用 `exclude_domains` 忽略来自某些域名的结果。
