# Groq Changelog

## 2025-06-25 (Python SDK v0.29.0, TypeScript SDK v0.26.0)

### [CHANGED] Python SDK v0.29.0, TypeScript SDK v0.26.0

Python SDK 已更新至 v0.29.0，TypeScript SDK 已更新至 v0.26.0。

**主要变更：**

- 为[智能体工具系统（agentic tool systems）](https://console.groq.com/docs/agentic-tooling)（[`compound-beta`](https://console.groq.com/docs/agentic-tooling/compound-beta) 和 [`compound-beta-mini`](https://console.groq.com/docs/agentic-tooling/compound-beta-mini)）的 `search_settings` 参数新增了 `country` 字段。这个新参数允许你优先展示来自特定国家的搜索结果。完整的支持国家列表请参阅 [Agentic Tooling 文档](https://console.groq.com/docs/agentic-tooling#search-settings)。
