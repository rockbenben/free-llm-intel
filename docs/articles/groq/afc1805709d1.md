# 远程模型上下文协议（MCP）上线

### 新增[Remote Model Context Protocol (MCP)](#remote-model-context-protocol-mcp)

Remote Model Context Protocol（MCP）server 集成现已在 GroqCloud 上以 Beta 形式提供，它通过 Anthropic 开放的 MCP 标准把 AI 模型连接到数千个外部工具。开发者可以把任意远程 MCP server 连到托管在 GroqCloud 上的模型，从而构建具备工具能力、更快且成本更低的 AI 应用。

Groq 的实现与 OpenAI Responses API 以及 OpenAI 远程 MCP 规范完全兼容，因此开发者可以从 OpenAI 零代码改动地切换到 Groq，同时享受 Groq 的速度与可预期的成本。

**为什么远程 MCP 重要：**

* **通用接口** \- 通过一个开放标准连接数千个远程 MCP server 与工具
* **执行更快** \- 往返延迟低于同类方案
* **成本更低** \- 同样的体验，只需一小部分价格
* **无缝迁移** \- 保留你的 connector 代码，只需更换 endpoint

**支持的模型：**凡是支持 [tool use](https://console.groq.com/docs/tool-use) 的模型都可以用 Remote MCP，例如：

* `openai/gpt-oss-20b`
* `openai/gpt-oss-120b`
* `moonshotai/kimi-k2-instruct-0905`
* `qwen/qwen3-32b`
* `meta-llama/llama-4-maverick-17b-128e-instruct`
* `meta-llama/llama-4-scout-17b-16e-instruct`
* `llama-3.3-70b-versatile`
* `llama-3.1-8b-instant`

**MCP 入门教程：**借助下面这些由我们的发布合作伙伴提供的教程，学习如何把各类 MCP server 及其可用工具（例如网页搜索）轻松地集成进你基于 Groq API 的应用：

* [BrowserBase MCP](https://github.com/groq/groq-api-cookbook/blob/main/tutorials/mcp-browserbase)：用自然语言命令进行网页自动化
* [Browser Use MCP](https://github.com/groq/groq-api-cookbook/tree/main/tutorials/mcp-browseruse)：自主浏览网页并与之交互
* [Exa MCP](https://github.com/groq/groq-api-cookbook/blob/main/tutorials/mcp-exa)：实时网页搜索与抓取
* [Firecrawl MCP](https://github.com/groq/groq-api-cookbook/blob/main/tutorials/mcp-firecrawl)：企业级网页抓取能力
* [HuggingFace MCP](https://github.com/groq/groq-api-cookbook/blob/main/tutorials/mcp-huggingface)：获取实时的 HuggingFace 模型数据
* [Parallel MCP](https://github.com/groq/groq-api-cookbook/blob/main/tutorials/mcp-parallel)：可访问实时数据的实时搜索
* [Stripe MCP](https://docs.stripe.com/mcp)：把发票流程自动化
* [Tavily MCP](https://github.com/groq/groq-api-cookbook/blob/main/tutorials/mcp-tavily)：构建实时研究智能体

**使用示例：**

curl

```
curl -X POST "https://api.groq.com/openai/v1/responses" \
  -H "Authorization: Bearer $GROQ_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-oss-120b",
    "input": "What models are trending on Huggingface?",
    "tools": [
      {
        "type": "mcp",
        "server_label": "Huggingface",
        "server_url": "https://huggingface.co/mcp"
      }
    ]
  }'
```
