# OpenAI GPT-OSS 20B & OpenAI GPT-OSS 120B

### 新增[OpenAI GPT-OSS 20B & OpenAI GPT-OSS 120B](#openai-gptoss-20b--openai-gptoss-120b)

[GPT-OSS 20B](https://console.groq.com/docs/model/openai/gpt-oss-20b) 和 [GPT-OSS 120B](https://console.groq.com/docs/model/openai/gpt-oss-120b) 是 OpenAI 开源的先进（state-of-the-art）Mixture-of-Experts（MoE）语言模型，表现可以与他们的前沿模型 o4-mini 和 o3-mini 持平。它们具备[推理](https://console.groq.com/docs/reasoning)能力、内置的 [browser search](https://console.groq.com/docs/browser-search) 和 [code execution](https://console.groq.com/docs/code-execution)，并支持 [structured outputs](https://console.groq.com/docs/structured-outputs)。

**主要特性：**

* 131K token 上下文窗口
* 最多 32K 输出 token
* 运行速度分别约为 \~1000+ TPS 和 \~500+ TPS
* MoE 架构，分别拥有 32 和 128 个专家（expert）
* 在众多基准上超过 OpenAI 的 o4-mini
* 内置 [browser search](https://console.groq.com/docs/browser-search) 和 [code execution](https://console.groq.com/docs/code-execution)

**性能指标（[20B](https://console.groq.com/docs/model/openai/gpt-oss-20b)）：**

* 85.3% MMLU（通用推理）
* 60.7% SWE-Bench Verified（编程）
* 98.7% AIME 2025（配合工具做数学）
* 75.7% MMMLU 平均分（多语言）

**性能指标（[120B](https://console.groq.com/docs/model/openai/gpt-oss-120b)）：**

* 90.0% MMLU（通用推理）
* 62.4% SWE-Bench Verified（编程）
* 57.6% HealthBench Realistic（健康）
* 81.3% MMMLU 平均分（多语言）

**使用示例：**

curl

```
curl https://api.groq.com/openai/v1/chat/completions \
  -H "Authorization: Bearer $GROQ_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-oss-20b",
    "messages": [
      {
        "role": "user",
        "content": "Explain why fast inference is critical for reasoning models"
      }
    ]
  }'
```
