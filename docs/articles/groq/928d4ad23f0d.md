# Groq Changelog

## 2025-08-05 (Python SDK v0.31.0, TypeScript SDK v0.30.0)

### [ADDED] OpenAI GPT-OSS 20B 与 OpenAI GPT-OSS 120B

[GPT-OSS 20B](https://console.groq.com/docs/model/openai/gpt-oss-20b) 和 [GPT-OSS 120B](https://console.groq.com/docs/model/openai/gpt-oss-120b) 是 OpenAI 开源的尖端混合专家（MoE）语言模型，表现可与其前沿的 o4-mini 和 o3-mini 模型相媲美。它们具备[推理](https://console.groq.com/docs/reasoning)能力，内置[浏览器搜索](https://console.groq.com/docs/browser-search)和[代码执行](https://console.groq.com/docs/code-execution)，并支持[结构化输出](https://console.groq.com/docs/structured-outputs)。

**核心特性：**

- 131K token 上下文窗口
- 最大输出 32K token
- 运行速度分别约为 1000+ TPS 和 500+ TPS
- MoE 架构，分别拥有 32 和 128 个专家
- 在许多基准测试上超越 OpenAI 的 o4-mini
- 内置[浏览器搜索](https://console.groq.com/docs/browser-search)和[代码执行](https://console.groq.com/docs/code-execution)

**性能指标（[20B](https://console.groq.com/docs/model/openai/gpt-oss-20b)）：**

- MMLU 85.3%（通用推理）
- SWE-Bench Verified 60.7%（编程）
- AIME 2025 98.7%（借助工具解题）
- MMMLU 平均 75.7%（多语言）

**性能指标（[120B](https://console.groq.com/docs/model/openai/gpt-oss-120b)）：**

- MMLU 90.0%（通用推理）
- SWE-Bench Verified 62.4%（编程）
- HealthBench Realistic 57.6%（健康）
- MMMLU 平均 81.3%（多语言）

**使用示例：**

```curl
curl https://api.groq.com/openai/v1/chat/completions \
 -H "Authorization: Bearer $GROQ_API_KEY" \
 -H "Content-Type: application/json" \
 -d '{
 "model": "openai/gpt-oss-20b",
 "messages": [
 {
 "role": "user",
 "content": "Explain why fast inference is critical for reasoning models"
 }
 ]
 }'
```

### [ADDED] Responses API（Beta）

[Groq 的 Responses API](https://console.groq.com/docs/responses-api) 与 OpenAI 的 Responses API 完全兼容，便于你将高级对话式 AI 能力集成到应用中。[Responses API](https://console.groq.com/docs/responses-api) 同时支持文本和图像输入，输出文本，支持有状态对话，并可通过 function calling 连接外部系统。

该功能目前处于 beta 阶段——欢迎在 [Community Forum](https://community.groq.com/) 反馈你的意见！

**使用示例：**

```curl
curl https://api.groq.com/openai/v1/responses \
 -H "Content-Type: application/json" \
 -H "Authorization: Bearer $GROQ_API_KEY" \
 -d '{
 "model": "llama-3.3-70b-versatile",
 "input": "Tell me a fun fact about the moon in one sentence."
 }'
```

### [CHANGED] Python SDK v0.31.0, TypeScript SDK v0.30.0

Python SDK 已更新至 v0.30.0，TypeScript SDK 已更新至 v0.27.0。

**主要变更：**

 - 使用 GPT-OSS 模型时，`reasoning_effort` 新增 `high`、`medium`、`low` 选项以控制其推理输出。[了解更多关于如何用这些选项控制推理 token。](https://console.groq.com/docs/reasoning#reasoning-effort)
 - 在 chat completion 请求的 `tools` 数组中，新增将 [`browser_search`](https://console.groq.com/docs/browser-search) 和 [`code_interpreter`](https://console.groq.com/docs/code-execution) 作为 function/tool 定义类型的支持。指定其中之一或两者，即可允许 GPT-OSS 模型在需要时于服务端自动调用它们。
 - 为 chat completion 请求新增可选的 `include_reasoning` 布尔选项，用于配置模型是否在 `reasoning` 字段中返回响应。该选项不受 GPT-OSS 模型支持。
