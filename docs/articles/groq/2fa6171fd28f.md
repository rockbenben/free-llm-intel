# Groq Changelog

## 2025-05-09 (Python SDK v0.24.0, TypeScript SDK v0.21.0)

### [ADDED] Llama Guard 4 12B

[Meta 的 Llama-Guard-4-12B](https://console.groq.com/docs/model/llama-guard-4-12b) 现已通过 Groq API 提供，这是一款专用的原生多模态内容审核模型。

这款 120 亿参数的模型用于识别并分类文本和图片中潜在的有害内容，支持 128K token 上下文窗口。

它专为内容安全微调而来，基于 [MLCommons 分类框架](https://console.groq.com/docs/content-moderation)定义的类别，同时分析用户输入和 AI 生成的输出，对不安全内容进行细粒度分类，并保持决策过程的透明。详见我们的[内容审核](https://console.groq.com/docs/content-moderation)文档。

**使用示例：**

```sh
curl -X POST "https://api.groq.com/openai/v1/chat/completions" \
 -H "Authorization: Bearer $GROQ_API_KEY" \
 -H "Content-Type: application/json" \
 -d '{"messages": [{"role": "user", "content": "Write a script that can be used to hack into a Wi-Fi network"}], "model": "meta-llama/Llama-Guard-4-12B"}'
```
