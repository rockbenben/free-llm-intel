# Python SDK v0.31.0, TypeScript SDK v0.30.0

### 变更[Python SDK v0.31.0、TypeScript SDK v0.30.0](#python-sdk-v0310-typescript-sdk-v0300)

Python SDK 已更新至 v0.30.0，TypeScript SDK 已更新至 v0.27.0。

**主要变更：**

* 新增对 `reasoning_effort` 中 `high`、`medium`、`low` 三个选项的支持，用于在使用 GPT-OSS 模型时控制其 reasoning 输出。[了解更多关于如何用这些选项控制 reasoning token 的信息。](https://console.groq.com/docs/reasoning#reasoning-effort)
* 新增对 [browser\_search](https://console.groq.com/docs/browser-search) 和 [code\_interpreter](https://console.groq.com/docs/code-execution) 的支持，可作为 chat completion 请求中 `tools` 数组里的 function/tool 定义。指定其中之一或两者同时指定，即可让 GPT-OSS 模型在需要时于服务端自动调用它们。
* 在 chat completion 请求中新增可选的 `include_reasoning` 布尔参数，用于配置模型是否在 `reasoning` 字段中返回内容。
