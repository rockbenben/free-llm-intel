# Python SDK v0.30.0, TypeScript SDK v0.27.0

### 变更[Python SDK v0.30.0、TypeScript SDK v0.27.0](#python-sdk-v0300-typescript-sdk-v0270)

Python SDK 已更新至 v0.30.0，TypeScript SDK 已更新至 v0.27.0。

**主要变更：**

* 改进了 chat completion 的消息类型定义，以更好地兼容 OpenAI。这修复了在某些不同消息格式下出现的错误。
