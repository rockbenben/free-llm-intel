# Groq Changelog

## 2025-04-23 (Python SDK v0.23.0, TypeScript SDK v0.20.0)

### [CHANGED] Python SDK v0.23.0, TypeScript SDK v0.20.0

Python SDK 已更新至 v0.23.0，TypeScript SDK 已更新至 v0.20.0。

**主要变更：**

 - `groq.files.content` 现在返回 `Response` 对象，以便将 `jsonl` 文件解析为文本，或将通用文件类型解析为 blob。
 - `BatchCreateParams` 的 `completion_window` 输入现接受 `string` 类型，以支持 `24h` 到 `7d` 之间的时间窗口。
 - 更新了 chat completion 的 `model` 参数，移除已弃用的模型并加入更新的 production 模型。
 - 新增可选的 chat completion `metadata` 参数以提升兼容性。
