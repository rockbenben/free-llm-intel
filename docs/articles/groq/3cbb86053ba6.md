# Responses API（Beta）

### 新增[Responses API（Beta）](#responses-api-beta)

[Groq 的 Responses API](https://console.groq.com/docs/responses-api) 与 OpenAI 的 Responses API 完全兼容，让你可以轻松地把高级对话式 AI 能力集成到自己的应用中。[Responses API](https://console.groq.com/docs/responses-api) 支持文本和图像输入，并产出文本输出、有状态（stateful）的对话，以及用于连接外部系统的 function calling。

该功能目前处于 beta 阶段——欢迎在我们的 [Community Forum](https://community.groq.com/) 上告诉我们你的反馈！

**示例用法：**

curl

```
curl https://api.groq.com/openai/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $GROQ_API_KEY" \
  -d '{
    "model": "llama-3.3-70b-versatile",
    "input": "Tell me a fun fact about the moon in one sentence."
  }'
```
