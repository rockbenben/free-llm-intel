# Meta Llama 4 Support

### 新增[Meta Llama 4 支持](#meta-llama-4-support)

Meta 的 Llama 4 Scout（17Bx16MoE）与 Maverick（17Bx128E）模型用于图像理解与文本生成，现已通过 Groq API 提供，支持 128K token 上下文窗口、最多 5 张图像的图像输入、function calling／tool use 以及 JSON 模式。更多阅读请见我们的 [tool use](https://console.groq.com/docs/tool-use) 和 [vision](https://console.groq.com/docs/vision) 文档。

**性能（由 [AA](https://artificialanalysis.ai/) 基准测试）：**

* Llama 4 Scout（`meta-llama/llama-4-scout-17b-16e-instruct`）：当前 607 tokens 每秒（TPS）
* Llama 4 Maverick（`meta-llama/llama-4-maverick-17b-128e-instruct`）：当前 297 TPS

**示例用法：**

curl

```
curl "https://api.groq.com/openai/v1/chat/completions" \
  -X POST \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer ${GROQ_API_KEY}" \
  -d '{
         "messages": [
           {
             "role": "user",
             "content": "why is fast inference crucial for ai apps?"
           }
         ],
         "model": "meta-llama/llama-4-maverick-17b-128e-instruct",
       }'
```
