### 变更[Batch API 在验证时检查模型访问权限](#batch-api-checks-model-access-at-validation)

如果某个 batch 指定了你的组织无权使用的模型，现在会在验证阶段就失败，任何请求都不会执行。该 batch 以 `status: "failed"` 和 `request_counts.total: 0` 结束。`errors.data[]` 数组会为每个被拒绝的模型提供一个条目，其中包含与同步 API 为该模型返回的相同 `code` 和 `message`（`model_not_found`、`model_decommissioned`、`model_terms_required`、`model_permission_blocked_org` 或 `model_permission_blocked_project`）、`param: "body.model"`，以及使用该模型的第一个请求所在的 `line`。在此变更之前，这类 batch 会进入 `in_progress`，并且每个请求都会在错误文件中以 404 失败。参见 [Batch API 文档](https://console.groq.com/docs/batch)。
