### 已更改[Python SDK v1.6.0 和 TypeScript SDK v1.5.0](#python-sdk-v160-and-typescript-sdk-v150)

这两个 SDK 在第二季度都收到了一系列更新。

**Python SDK** ([v1.6.0](https://github.com/groq/groq-python/releases/tag/v1.6.0))

* **v1.3.0** — 支持通过环境变量设置 headers；多部分文件数组的固定字段名称格式。
* **v1.4.0** — 支持急切验证 pydantic 迭代器。
* **v1.5.0** — API 规范更新。
* **v1.6.0** — CI 和工作流程模板更新。

**TypeScript SDK** ([v1.5.0](https://github.com/groq/groq-typescript/releases/tag/v1.5.0))

* **v1.2.0** — 支持通过环境变量设置标头。
* **v1.2.1** — 升级了 `tsc-multi` 以实现 Node 26 兼容性。
* **v1.3.0** — API 规范更新；为省略可选正文的请求发送内容类型标头。
* **v1.4.0 / v1.4.1** — CI 工作流程在 Node 24 上运行；依赖项更新。
* **v1.5.0** — API 规范更新。
