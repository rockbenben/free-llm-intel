# Groq Changelog

## 2025-09-23 (Python SDK v0.31.1, TypeScript SDK v0.32.0)

### [ADDED] Remote Model Context Protocol (MCP)

Remote Model Context Protocol (MCP) 服务器集成现已在 GroqCloud 上以 Beta 形式提供，通过 Anthropic 开放的 MCP 标准将 AI 模型与数千种外部工具连接起来。开发者可以把任意远程 MCP 服务器接入 GroqCloud 上托管的模型，从而构建具备工具能力、更快且更低成本的 AI 应用。

Groq 的实现完全兼容 OpenAI Responses API 和 OpenAI 远程 MCP 规范，开发者无需改动任何代码即可从 OpenAI 切换到 Groq，同时享受 Groq 的速度与可预期的成本。

**为什么 Remote MCP 重要：**

- **通用接口** - 通过一个开放标准连接数千个远程 MCP 服务器和工具
- **更快执行** - 往返延迟低于同类方案
- **更低成本** - 相同体验只需几分之一价格
- **无缝迁移** - 保留你的连接器代码，只改 endpoint

**支持的模型：**

Remote MCP 在所有支持[工具调用](https://console.groq.com/docs/tool-use)的模型上可用，例如：

- `openai/gpt-oss-20b`
- `openai/gpt-oss-120b`
- `moonshotai/kimi-k2-instruct-0905`
- `qwen/qwen3-32b`
- `meta-llama/llama-4-maverick-17b-128e-instruct`
- `meta-llama/llama-4-scout-17b-16e-instruct`
- `llama-3.3-70b-versatile`
- `llama-3.1-8b-instant`

**MCP 入门教程：**

借助这些来自我们生态伙伴的教程，学习如何通过 Groq API 把各种 MCP 服务器及其可用工具（如网络搜索）轻松集成到你的应用中：

- [BrowserBase MCP](https://github.com/groq/groq-api-cookbook/blob/main/tutorials/mcp-browserbase)：用自然语言指令实现网页自动化
- [Browser Use MCP](https://github.com/groq/groq-api-cookbook/tree/main/tutorials/mcp-browseruse)：自主浏览与交互网站
- [Exa MCP](https://github.com/groq/groq-api-cookbook/blob/main/tutorials/mcp-exa)：实时网络搜索与抓取
- [Firecrawl MCP](https://github.com/groq/groq-api-cookbook/blob/main/tutorials/mcp-firecrawl)：企业级网页抓取能力
- [HuggingFace MCP](https://github.com/groq/groq-api-cookbook/blob/main/tutorials/mcp-huggingface)：获取实时的 HuggingFace 模型数据
- [Parallel MCP](https://github.com/groq/groq-api-cookbook/blob/main/tutorials/mcp-parallel)：带实时数据访问的搜索
- [Stripe MCP](https://docs.stripe.com/mcp)：自动化开票流程
- [Tavily MCP](https://github.com/groq/groq-api-cookbook/blob/main/tutorials/mcp-tavily)：构建实时研究智能体

**使用示例：**

```curl
curl -X POST "https://api.groq.com/openai/v1/responses" \
 -H "Authorization: Bearer $GROQ_API_KEY" \
 -H "Content-Type: application/json" \
 -d '{
 "model": "openai/gpt-oss-120b",
 "input": "What models are trending on Huggingface?",
 "tools": [
 {
 "type": "mcp",
 "server_label": "Huggingface",
 "server_url": "https://huggingface.co/mcp"
 }
 ]
 }'
```

[了解更多关于 GroqCloud MCP 支持的信息](https://console.groq.com/docs/mcp)
