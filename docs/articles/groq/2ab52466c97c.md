# Python SDK v0.24.0, TypeScript SDK v0.21.0

### 变更[Python SDK v0.24.0、TypeScript SDK v0.21.0](#python-sdk-v0240-typescript-sdk-v0210)

Python SDK 已更新至 v0.24.0，TypeScript SDK 已更新至 v0.21.0。

**主要变更：**

* Compound Beta 的[搜索设置](https://console.groq.com/docs/agentic-tooling#search-settings)新增对域名过滤的支持。使用 `include_domains` 可以把检索限定到指定域名，或使用 `exclude_domains` 从某些域名中排除结果，适用于 [compound-beta](https://console.groq.com/docs/agentic-tooling/compound-beta) 或 [compound-beta-mini](https://console.groq.com/docs/agentic-tooling/compound-beta-mini) 模型。
