# Orpheus Arabic Saudi 新增语音

### 新增[Orpheus Arabic Saudi 的新语音](#new-voices-for-orpheus-arabic-saudi)

[canopylabs/orpheus-arabic-saudi](https://console.groq.com/docs/model/canopylabs/orpheus-arabic-saudi) 新增两个语音：

* **Abdullah** — 现为默认语音
* **Aisha**

Arabic Saudi 模型现在共支持六个语音：Abdullah、Fahad、Sultan、Lulwa、Noura 和 Aisha。音频样例与示例用法见 [Orpheus TTS 文档](https://console.groq.com/docs/text-to-speech/orpheus)。
