**据 ArtificialAnalysis.ai 称，Groq 代表推理速度的"阶跃式变化"**

我们迎来了今年第二个月，也迎来第二个 LLM 基准测试，[这次来自 ArtificialAnalysis.ai](https://artificialanalysis.ai/models/llama-2-chat-70b)。剧透一下：Groq LPU™ 推理引擎表现太过出色，以至于图表坐标轴不得不延长，才能在"延迟 vs 吞吐量"图上把 Groq 画进去。不过在深入结果之前，先说说测试设置。

该基准测试针对 [Meta AI 的 Llama 2 Chat (70B)](https://llama.meta.com/)，涵盖质量、延迟、吞吐量（tokens/秒）、价格等多个指标。Groq 与其他 API 托管提供商一同参与，包括 Microsoft Azure、Amazon Bedrock、Perplexity、Together.ai、Anyscale、Deepinfra、Fireworks 和 Lepton。

ArtificialAnalysis.ai 以独立第三方身份进行的基准测试，从多个关键性能指标对比各家托管提供商，包括吞吐量 vs 价格、延迟 vs 吞吐量、随时间变化的吞吐量、总响应时间以及吞吐量波动。这些基准是"实时"的，即每三小时（每天八次）更新一次；测试提示词各不相同，长度约 100 tokens，生成约 200 个输出 token。这样的测试设计旨在反映真实使用场景，并度量吞吐量（tokens/秒）和延迟（首 token 时间）随时间的变化。ArtificialAnalysis.ai 还有采用更长提示词的其他基准，以反映检索增强生成（RAG）用例。

> "ArtificialAnalysis.ai 独立测试表明，Groq 的 Llama 2 Chat (70B) API 达到 241 tokens/s 的吞吐量，速度是其他托管提供商的两倍以上。Groq 代表着可用速度的阶跃式变化，让大语言模型得以解锁新的应用场景。"——Micah Hill-Smith，ArtificialAnalysis.ai 联合创始人

## 结果

##### [ArtificialAnalysis.ai](https://artificialanalysis.ai/) 的基准测试显示，Groq 几乎在所有类别中都领先其他提供商，尤其是在吞吐量和接收 100 个输出 token 的总响应时间上，Groq 分别达到 241 tokens/s 和 0.8 秒。

##### 下面是部分结果的详细情况。

## 延迟 vs 吞吐量

- **延迟：** 发送 API 请求后收到第一个 token 块所需的时间（秒）
- **吞吐量：** 模型生成 token 期间每秒收到的 token 数（即从 API 收到第一个块之后）
- 越低越右越好，绿色区域代表最具吸引力的象限

### 吞吐量

- **吞吐量：** 模型生成 token 期间每秒收到的 token 数（即从 API 收到第一个块之后）
- 越高越好

## 总响应时间

- **总响应时间：** 收到 100 token 响应所需时间，根据延迟和吞吐量估算
- 越低越好
