GroqCloud™ 为需要即时响应能力的复杂 AI 方案提供快速推理。但当你的用例扩张、需求超出"快"本身时怎么办？这就是批处理（Batch Processing）登场的时候——现在你可以在 GroqCloud 上大规模处理海量工作负载。

假设你有大规模数据集需要分析或摘要，或者有大批图片需要生成描述，又或者要对新的 AI 程序做验证与质量测试。GroqCloud Batch Processing API 面向 Developer 和 Enterprise Tier 客户开放，正是这些场景及更多场景的理想解决方案。

批处理允许用户将非时间敏感的请求打包，或提交大规模工作负载，并在 24 小时内获得返回。它让批量处理变得简单，非常适合大规模数据分类、翻译、文档摘要、图生文等工作负载。相比普通按需价格，所有任务均享 75 折（25% 折扣），且不占用速率限额。

## Whisper 转录批处理的新功能

我们增强了 Whisper 转录能力，新增批处理支持，并带来强大的新功能：

- **三个 Whisper 版本均可用于批处理：** 在 Whisper Large v3、Distill-Whisper 和 Whisper Large v3 Turbo 中选择最适合你需求的模型。
- **词级时间戳：** 为音频转录的每个词提供精确时间戳，非常适合 YouTube 视频、字幕和社交媒体。[阅读我们的博客了解更多。](https://groq.com/build-fast-with-word-level-timestamping)
- **更流畅的工作流：** 非常适合批量视频/音频转录和生成字幕。

虽然 Whisper 与 chat completions 批处理之间的流水线（pipelining）目前尚不支持，但你可以通过分别运行两个独立的批处理工作负载轻松达成目标。
