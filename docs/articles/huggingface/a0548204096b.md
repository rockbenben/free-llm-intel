# Habana Labs 与 Hugging Face 合作加速 Transformer 模型训练

*加州，圣克拉拉与旧金山，2022 年 4 月 12 日*

在深度学习的驱动下，transformer 模型在自然语言处理、计算机视觉、语音等众多机器学习任务上都能取得最先进的性能。然而，大规模训练这些模型往往需要大量的算力，使得整个过程变得不必要的漫长、复杂且昂贵。

今天，[Habana® Labs](https://habana.ai/)（高效、专用深度学习处理器领域的先驱）与 [Transformer](https://github.com/huggingface/transformers) 模型之家 Hugging Face 高兴地宣布，双方将携手让高质量 transformer 模型的训练变得更简单、更快捷。得益于 Habana 的 [SynapseAI 软件套件](https://habana.ai/training-software/) 与 Hugging Face [Optimum 开源库](https://github.com/huggingface/optimum) 的集成，数据科学家和机器学习工程师如今只需几行代码，就能在 Habana 处理器上加速他们的 Transformer 训练任务，既提升生产力，又降低训练成本。

[Habana Gaudi](https://habana.ai/training/) 训练方案为亚马逊的 EC2 DL1 实例和超微（Supermicro）的 X12 Gaudi AI 训练服务器提供动力，其性价比相比同类训练方案最高可节省 40% 的成本，让客户花更少的钱完成更多训练。每颗 Gaudi 处理器都集成了十个 100 Gigabit 以太网端口，使系统能够轻松且具成本效益地从 1 颗扩展到数千颗 Gaudi。Habana 的 SynapseAI® 从设计之初就为释放 Gaudi 的性能与易用性而优化，支持 TensorFlow 和 PyTorch 框架，重点面向计算机视觉与自然语言处理应用。

Hugging Face 在 Github 上拥有 60,000+ 颗星、30,000+ 个模型，以及数百万的月度访问量，是开源软件史上增长最快的项目之一，也是机器学习社区的首选之地。

凭借 [Hardware Partner Program（硬件合作伙伴计划）](https://huggingface.co/hardware)，Hugging Face 为 Gaudi 的先进深度学习硬件提供顶级的 Transformer 工具集。此次合作将推动面向 Habana Gaudi 训练的 transformer 模型库快速扩充，把 Gaudi 的高效率与易用性带到自然语言处理、计算机视觉、语音等众多客户场景中。

"*我们很高兴能与 Hugging Face 及其众多开源开发者合作，共同满足对 transformer 模型日益增长的需求——这些模型将从 Gaudi 训练平台的高效性、易用性与可扩展性中获益*"，Habana Labs 软件产品管理负责人 Sree Ganesan 表示。

"Habana Gaudi 为深度学习模型训练带来了全新水平的效率，我们非常兴奋能通过 Optimum，让 Transformer 用户以极少的代码改动就能轻松用上这种性能"，Hugging Face 产品总监 Jeff Boudier 表示。

要了解如何开始使用 Habana Gaudi 进行训练，请访问 [https://developer.habana.ai](https://developer.habana.ai)。

如需了解更多关于 Hugging Face 与 Habana Gaudi 合作的信息，请访问 [https://huggingface.co/Habana](https://huggingface.co/Habana)。
