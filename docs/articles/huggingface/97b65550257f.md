## 1. ONNX 是什么？

[ONNX，即 Open Neural Network eXchange](https://onnx.ai) 是表示机器学习模型的开放标准和格式。ONNX 定义了一组通用算子和一种通用文件格式，用于表示 PyTorch、TensorFlow 等各种框架中的深度学习模型。

用 NETRON 可视化的伪 ONNX 图

当模型被导出为 ONNX 格式时，这些算子被用来构建计算图（常称为`中间表示`intermediate representation），描述数据在神经网络中的流动。

> 重要：ONNX 不是运行时。ONNX 只是一种表示形式，可与 ONNX Runtime 等运行时一起使用。受支持的加速器列表见[这里](https://huggingface.co/blog/convert-transformers-to-onnx)。

➡️[了解更多关于 ONNX 的信息。](https://onnx.ai/about.html)

## 2. Hugging Face Optimum 是什么？

[Hugging Face Optimum](https://github.com/huggingface/optimum) 是一个开源库，也是 [Hugging Face Transformers](https://github.com/huggingface/transformers) 的扩展。它提供了性能优化工具的统一 API，以便在加速硬件上实现训练和运行模型的最高效率，并包含在 [Graphcore IPU](https://github.com/huggingface/optimum-graphcore) 和 [Habana Gaudi](https://github.com/huggingface/optimum-habana) 上获得优化性能的工具包。

Optimum 可用于转换、量化、图优化、加速训练与推理，并支持 [transformers pipelines](https://huggingface.co/docs/transformers/main/en/main_classes/pipelines#pipelines)。

下面你可以看到一个典型的开发者旅程，展示如何将 Optimum 与 ONNX 结合使用。

## 4. 如何把 Transformers 模型（BERT）转换为 ONNX？

目前有三种方式可以把 Hugging Face Transformers 模型转换为 ONNX。本节中，你将学习如何用全部三种方法导出用于 `text-classification` 的 [distilbert-base-uncased-finetuned-sst-2-english](https://huggingface.co/distilbert-base-uncased-finetuned-sst-2-english)，从底层 `torch` API 到 `optimum` 最友好的高层 API。每种方法做的事情完全相同

### 用 `torch.onnx` 导出（底层）

[torch.onnx](https://pytorch.org/docs/stable/onnx.html) 通过 `export` 方法把模型 checkpoint 转换为 ONNX 图。但你需要提供大量取值，如 `input_names`、`dynamic_axes` 等。

首先需要安装一些依赖：

```
pip install transformers torch
```

用 `export` 导出我们的 checkpoint

```
import torch
from transformers import AutoModelForSequenceClassification, AutoTokenizer

# load model and tokenizer
model_id = "distilbert-base-uncased-finetuned-sst-2-english"
model = AutoModelForSequenceClassification.from_pretrained(model_id)
tokenizer = AutoTokenizer.from_pretrained(model_id)
dummy_model_input = tokenizer("This is a sample", return_tensors="pt")

# export
torch.onnx.export(
    model, 
    tuple(dummy_model_input.values()),
    f="torch-model.onnx",  
    input_names=['input_ids', 'attention_mask'], 
    output_names=['logits'], 
    dynamic_axes={'input_ids': {0: 'batch_size', 1: 'sequence'}, 
                  'attention_mask': {0: 'batch_size', 1: 'sequence'}, 
                  'logits': {0: 'batch_size', 1: 'sequence'}}, 
    do_constant_folding=True, 
    opset_version=13, 
)
```

### 用 `transformers.onnx` 导出（中层）

[transformers.onnx](https://huggingface.co/docs/transformers/serialization#exporting-a-model-to-onnx) 借助配置对象把模型 checkpoint 转换为 ONNX 图，这样你就不必提供 `dynamic_axes` 等复杂配置。

首先需要安装一些依赖：

```
pip install transformers[onnx] torch
```

用 `transformers.onnx` 导出我们的 checkpoint。

```
from pathlib import Path
import transformers
from transformers.onnx import FeaturesManager
from transformers import AutoConfig, AutoTokenizer, AutoModelForSequenceClassification

# load model and tokenizer
model_id = "distilbert-base-uncased-finetuned-sst-2-english"
feature = "sequence-classification"
model = AutoModelForSequenceClassification.from_pretrained(model_id)
tokenizer = AutoTokenizer.from_pretrained(model_id)

# load config
model_kind, model_onnx_config = FeaturesManager.check_supported_model_or_raise(model, feature=feature)
onnx_config = model_onnx_config(model.config)

# export
onnx_inputs, onnx_outputs = transformers.onnx.export(
        preprocessor=tokenizer,
        model=model,
        config=onnx_config,
        opset=13,
        output=Path("trfs-model.onnx")
)
```

### 用 Optimum 导出（高层）

[Optimum](https://huggingface.co/docs/optimum/onnxruntime/modeling_ort#switching-from-transformers-to-optimum-inference) Inference 提供了用 `ORTModelForXxx` 类把普通 Transformers 模型转换为 ONNX 的方法。要把你的 Transformers 模型转换为 ONNX，只需给 `from_pretrained()` 方法传入 `from_transformers=True`，模型就会加载并借助底层 [transformers.onnx](https://huggingface.co/docs/transformers/serialization#exporting-a-model-to-onnx) 包转换为 ONNX。

首先需要安装一些依赖：

```
pip install optimum[onnxruntime]
```

用 `ORTModelForSequenceClassification` 导出我们的 checkpoint

```
from optimum.onnxruntime import ORTModelForSequenceClassification

model = ORTModelForSequenceClassification.from_pretrained("distilbert-base-uncased-finetuned-sst-2-english",from_transformers=True)
```

用 Optimum 转换最棒的地方在于，你可以立即用这个 `model` 运行预测，或在 [pipeline 内部加载它](https://huggingface.co/docs/optimum/onnxruntime/modeling_ort#switching-from-transformers-to-optimum-inference)。
