# 带注释的扩散模型

在这篇博文中，我们将深入理解**去噪扩散概率模型**（Denoising Diffusion Probabilistic Models，又称 DDPM、扩散模型、基于分数的生成模型，或干脆叫[自编码器](https://benanne.github.io/2022/01/31/diffusion.html)）——研究者已经用它取得了（无条件/条件）图像、音频、视频生成的卓越成果。热门的栗子（截至撰写时）包括 OpenAI 的 [GLIDE](https://arxiv.org/abs/2112.10741) 和 [DALL-E 2](https://openai.com/dall-e-2/)、海德堡大学的 [Latent Diffusion](https://github.com/CompVis/latent-diffusion)、以及 Google Brain 的 [ImageGen](https://imagen.research.google/)。

我们将精读 DDPM 原始论文（[Ho et al., 2020](https://arxiv.org/abs/2006.11239)），基于 Phil Wang 的[实现](https://github.com/lucidrains/denoising-diffusion-pytorch)逐步用 PyTorch 复现——它本身又基于[原版 TensorFlow 实现](https://github.com/hojonathanho/diffusion)。注意，用扩散做生成建模的想法其实早在（[Sohl-Dickstein et al., 2015](https://arxiv.org/abs/1503.03585)）就已提出；不过真正发扬光大是在（[Song et al., 2019](https://arxiv.org/abs/1907.05600)）（斯坦福大学）以及独立改进该方法的（[Ho et al., 2020](https://arxiv.org/abs/2006.11239)）（Google Brain）。

## 什么是扩散模型？

和归一化流、GAN、VAE 等其他生成模型相比，（去噪）扩散模型其实并不复杂：它们都是把某个简单分布的噪声转换成数据样本。这里也一样——**神经网络学习从纯噪声开始逐步去噪数据**。

再具体一点看图像，整套设定由两个过程构成：

- 由我们选定的、固定（预定义）的前向扩散过程 $q$，往图像里逐步加入高斯噪声，直到变成纯噪声
- 学出来的反向去噪扩散过程 $p_\theta$，其中神经网络被训练成从纯噪声出发逐步去噪，直到得到一张真实图像。

![](https://huggingface.co/blog/assets/78_annotated-diffusion/diffusion_figure.png)

前向和反向过程都以 $t$ 为索引，发生在有限个时间步 $T$ 内（DDPM 作者取 $T=1000$）。从 $t=0$ 开始，我们从数据分布中采样一张真实图像 $\mathbf{x}_0$（比如 ImageNet 里的一张猫图），前向过程在每个时间步 $t$ 从高斯分布采一些噪声，加到上一个时间步的图像上。只要 $T$ 足够大、且每步加噪声的安排是良性的，经过这个渐进过程，到 $t=T$ 时你会得到一个所谓的[各向同性高斯分布](https://math.stackexchange.com/questions/1991961/gaussian-distribution-is-isotropic)。

## 更数学化的表述

把它写得更正式一些，因为我们最终需要一个可优化的损失函数给神经网络去最小化。

设 $q(\mathbf{x}_0)$ 是真实数据分布，比如"真实图像"的分布。我们可以从该分布采样得到图像，$\mathbf{x}_0 \sim q(\mathbf{x}_0)$。我们定义前向扩散过程 $q(\mathbf{x}_t | \mathbf{x}_{t-1})$，它在每个时间步 $t$ 按照已知的方差调度 $0 < \beta_1 < \beta_2 < ... < \beta_T < 1$ 加入高斯噪声：$q(\mathbf{x}_t | \mathbf{x}_{t-1}) = \mathcal{N}(\mathbf{x}_t; \sqrt{1 - \beta_t} \mathbf{x}_{t-1}, \beta_t \mathbf{I})$。

回顾一下，正态分布（也叫高斯分布）由两个参数定义：均值 $\mu$ 和方差 $\sigma^2 \geq 0$。基本上，时间步 $t$ 的每张（略微更噪的）新图像都采自一个**条件高斯分布**，其 $\mathbf{\mu}_t = \sqrt{1 - \beta_t} \mathbf{x}_{t-1}$、$\sigma^2_t = \beta_t$。实际操作是采样 $\mathbf{\epsilon} \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$，然后令 $\mathbf{x}_t = \sqrt{1 - \beta_t} \mathbf{x}_{t-1} + \sqrt{\beta_t} \mathbf{\epsilon}$。

注意 $\beta_t$ 在每个时间步 $t$ 并不恒定（所以带下标）——实际上要定义一个所谓的**"方差调度"**，可以是线性、二次、余弦等等（后文会看到），有点像学习率调度。

于是从 $\mathbf{x}_0$ 出发，我们得到 $\mathbf{x}_1, ..., \mathbf{x}_t, ..., \mathbf{x}_T$，若调度设置得当，$\mathbf{x}_T$ 就是纯高斯噪声。

现在，假如我们知道条件分布 $p(\mathbf{x}_{t-1} | \mathbf{x}_t)$，就能反向跑这个过程：采样一段随机高斯噪声 $\mathbf{x}_T$，然后逐步"去噪"，最终得到来自真实分布的样本 $\mathbf{x}_0$。

可惜我们并不知道 $p(\mathbf{x}_{t-1} | \mathbf{x}_t)$。它是不可计算的——要算这个条件概率，得知道所有可能图像的分布。因此，我们用神经网络来**逼近（学习）这个条件概率分布**，记作 $p_\theta (\mathbf{x}_{t-1} | \mathbf{x}_t)$，$\theta$ 是神经网络参数，由梯度下降更新。

好，也就是说神经网络要表示反向过程的一个（条件）概率分布。如果我们假设这个反向过程也是高斯的，那回顾一下：任何高斯分布都由两个参数定义：

- 用 $\mu_\theta$ 参数化的均值；
- 用 $\Sigma_\theta$ 参数化的方差；

于是过程可参数化为 $p_\theta (\mathbf{x}_{t-1} | \mathbf{x}_t) = \mathcal{N}(\mathbf{x}_{t-1}; \mu_\theta(\mathbf{x}_{t},t), \Sigma_\theta (\mathbf{x}_{t},t))$，其中均值和方差同时以噪声水平 $t$ 为条件。

所以，神经网络需要学习/表示均值和方差。不过 DDPM 作者决定**把方差固定下来，只让神经网络学习（表示）这个条件概率分布的均值 $\mu_\theta$**。论文原文：

> First, we set $\Sigma_\theta ( \mathbf{x}_t, t) = \sigma^2_t \mathbf{I}$ to untrained time dependent constants. Experimentally, both $\sigma^2_t = \beta_t$ and $\sigma^2_t = \tilde{\beta}_t$ (see paper) had similar results.

（译注：即把方差设为未经训练的、随时间变化的常数；实验发现 $\sigma^2_t = \beta_t$ 与 $\sigma^2_t = \tilde{\beta}_t$ 结果相近。）

这一点后来在 [Improved diffusion models](https://openreview.net/pdf?id=-NEXDKk8gZ) 论文中得到改进——神经网络除了均值也学习反向过程的方差。

我们继续，假设神经网络只需要学习/表示这个条件概率分布的均值。

## 定义目标函数（对均值做重参数化）

为了推出学习反向过程均值的目

标函数，作者观察到 $q$ 与 $p_\theta$ 的组合可以看作一个变分自编码器（VAE）（[Kingma et al., 2013](https://arxiv.org/abs/1312.6114)）。因此可以用**变分下界**（也称 ELBO）来最小化关于真实数据样本 $\mathbf{x}_0$ 的负对数似然（ELBO 的细节请参考 VAE 论文）。结果是，这个过程的 ELBO 是每个时间步 $t$ 损失项之和，$L = L_0 + L_1 + ... + L_T$。按前向 $q$ 过程与反向过程的构造，除了 $L_0$ 之外，每个损失项实际上都是**两个高斯分布之间的 KL 散度**，可以显式写成关于均值的 L2 损失！

前向过程 $q$ 构造的一个直接推论（如 Sohl-Dickstein 等所示）是：可以在任意噪声水平对 $\mathbf{x}_t$ 以 $\mathbf{x}_0$ 为条件进行采样（因为高斯之和仍是高斯）。这非常方便：不需要反复应用 $q$ 来采样 $\mathbf{x}_t$。我们有 $q(\mathbf{x}_t | \mathbf{x}_0) = \cal{N}(\mathbf{x}_t; \sqrt{\bar{\alpha}_t} \mathbf{x}_0, (1- \bar{\alpha}_t) \mathbf{I})$

其中 $\alpha_t := 1 - \beta_t$、$\bar{\alpha}_t := \Pi_{s=1}^{t} \alpha_s$。我们称这个式为"漂亮性质"。这意味着我们只需采样高斯噪声、按适当比例缩放后加到 $\mathbf{x}_0$ 上，就能直接得到 $\mathbf{x}_t$。注意 $\bar{\alpha}_t$ 是已知的方差调度 $\beta_t$ 的函数，因而同样已知、可预先计算。这让我们在训练时可以**优化损失 $L$ 中的任意一项**（换种说法：训练时随机采样 $t$，优化 $L_t$）。

这个性质的另一重美妙之处（Ho et al. 指出）是：经过一番推导（可参考[这篇极好的博客](https://lilianweng.github.io/posts/2021-07-11-diffusion-models/)），我们可以**重参数化均值，让神经网络学习（预测）加入的噪声**（通过网络 $\mathbf{\epsilon}_\theta(\mathbf{x}_t, t)$ 预测噪声水平 $t$ 的噪声），而不是直接预测均值——把它代入构成损失的 KL 项中。也就是说，我们的神经网络成了一个噪声预测器，而非（直接的）均值预测器。均值可以这样计算：

$\mathbf{\mu}_\theta(\mathbf{x}_t, t) = \frac{1}{\sqrt{\alpha_t}} \left( \mathbf{x}_t - \frac{\beta_t}{\sqrt{1- \bar{\alpha}_t}} \mathbf{\epsilon}_\theta(\mathbf{x}_t, t) \right)$

于是对随机时间步 $t$（其中 $\mathbf{\epsilon} \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$），最终的目标函数 $L_t$ 形如：

$\| \mathbf{\epsilon} - \mathbf{\epsilon}_\theta(\mathbf{x}_t, t) \|^2 = \| \mathbf{\epsilon} - \mathbf{\epsilon}_\theta( \sqrt{\bar{\alpha}_t} \mathbf{x}_0 + \sqrt{(1- \bar{\alpha}_t) } \mathbf{\epsilon}, t) \|^2.$

这里 $\mathbf{x}_0$ 是初始（真实、未污染）图像，右边能看到由固定前向过程给出的噪声水平 $t$ 的直接采样；$\mathbf{\epsilon}$ 是时间步 $t$ 采样的纯噪声，$\mathbf{\epsilon}_\theta (\mathbf{x}_t, t)$ 是我们的神经网络。神经网络用真实噪声与预测高斯噪声之间的简单均方误差（MSE）来优化。

训练算法现在长这样：

![](https://huggingface.co/blog/assets/78_annotated-diffusion/training.png)

换句话说：

- 从真实的、未知且可能很复杂的数据分布 $q(\mathbf{x}_0)$ 中随机采样 $\mathbf{x}_0$
- 在 $1$ 到 $T$ 之间均匀采样噪声水平 $t$（即一个随机时间步）
- 从高斯分布采样一些噪声，并用水平 $t$ 的噪声污染输入（用上文定义的"漂亮性质"）
- 让神经网络根据污染后的图像 $\mathbf{x}_t$ 预测这段噪声（即按已知调度 $\beta_t$ 施加在 $\mathbf{x}_0$ 上的噪声）

实践中，这一切都在数据批次上进行——毕竟大家都用随机梯度下降来优化神经网络。

## 神经网络

神经网络需要接收某个时间步的带噪图像，返回预测的噪声。注意预测的噪声是一个张量，其尺寸/分辨率与输入图像一致。所以从技术上说，网络输入输出同形状的张量。用什么类型的网络？

这里通常使用的结构和[自编码器](https://en.wikipedia.org/wiki/Autoencoder)很相似——你大概还在"深度学习入门"教程里见过。自编码器在编码器和解码器之间有一个所谓的"瓶颈"层。编码器先把图像编码成更小的隐藏表示（即"瓶颈"），解码器再把隐藏表示解码回真实图像。这迫使网络只在瓶颈层保留最重要的信息。

架构上，DDPM 作者选了 **U-Net**，由（[Ronneberger et al., 2015](https://arxiv.org/abs/1505.04597)）提出（当时它在医学图像分割上是 SOTA）。和任何自编码器一样，这个网络中间有一个确保网络只学最重要信息的瓶颈。关键的是，它引入了编码器和解码器之间的残差连接，大幅改善梯度流（灵感来自 [He et al., 2015](https://arxiv.org/abs/1512.03385) 的 ResNet）。

![](https://huggingface.co/blog/assets/78_annotated-diffusion/unet_architecture.jpg)

可以看到，U-Net 先对输入做下采样（降低空间分辨率），之后再执行上采样。

下面我们一步步实现这个网络。

### 网络辅助组件

首先，定义实现神经网络时会用到的一些辅助函数和类。重要的是，我们定义一个 `Residual` 模块，它简单地把某个函数的输入加到该函数的输出上（换句话说，给某个函数加一条残差连接）。

我们还为上/下采样操作定义了别名。

```
def exists(x):
    return x is not None

def default(val, d):
    if exists(val):
        return val
    return d() if isfunction(d) else d


def num_to_groups(num, divisor):
    groups = num // divisor
    remainder = num % divisor
    arr = [divisor] * groups
    if remainder > 0:
        arr.append(remainder)
    return arr


class Residual(nn.Module):
    def __init__(self, fn):
        super().__init__()
        self.fn = fn

    def forward(self, x, *args, **kwargs):
        return self.fn(x, *args, **kwargs) + x


def Upsample(dim, dim_out=None):
    return nn.Sequential(
        nn.Upsample(scale_factor=2, mode="nearest"),
        nn.Conv2d(dim, default(dim_out, dim), 3, padding=1),
    )


def Downsample(dim, dim_out=None):
    # No More Strided Convolutions or Pooling
    return nn.Sequential(
        Rearrange("b c (h p1) (w p2) -> b (c p1 p2) h w", p1=2, p2=2),
        nn.Conv2d(dim * 4, default(dim_out, dim), 1),
    )
```

### 位置编码

由于神经网络的参数在所有时间步（噪声水平）之间共享，作者采用正弦位置编码来表征 $t$，灵感来自 Transformer（[Vaswani et al., 2017](https://arxiv.org/abs/1706.03762)）。这让神经网络在处理的每一张图上都知道自己处于哪个时间步（噪声水平）。

`SinusoidalPositionEmbeddings` 模块接收形状为 `(batch_size, 1)` 的张量作为输入（即一个批次中若干张带噪图像的噪声水平），把它转换为形状 `(batch_size, dim)` 的张量，`dim` 是位置编码的维度。后面会看到，这个编码会被加到每个残差块上。

```
class SinusoidalPositionEmbeddings(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.dim = dim

    def forward(self, time):
        device = time.device
        half_dim = self.dim // 2
        embeddings = math.log(10000) / (half_dim - 1)
        embeddings = torch.exp(torch.arange(half_dim, device=device) * -embeddings)
        embeddings = time[:, None] * embeddings[None, :]
        embeddings = torch.cat((embeddings.sin(), embeddings.cos()), dim=-1)
        return embeddings
```

### ResNet 块

接下来定义 U-Net 的核心构件。DDPM 作者用了宽 ResNet 块（Wide ResNet block，[Zagoruyko et al., 2016](https://arxiv.org/abs/1605.07146)），而 Phil Wang 把标准卷积层换成了"权重标准化"版本，与组归一化（group normalization）搭配效果更好（详见 [Kolesnikov et al., 2019](https://arxiv.org/abs/1912.11370)）。

```
class WeightStandardizedConv2d(nn.Conv2d):
    """
    https://arxiv.org/abs/1903.10520
    weight standardization purportedly works synergistically with group normalization
    """

    def forward(self, x):
        eps = 1e-5 if x.dtype == torch.float32 else 1e-3

        weight = self.weight
        mean = reduce(weight, "o ... -> o 1 1 1", "mean")
        var = reduce(weight, "o ... -> o 1 1 1", partial(torch.var, unbiased=False))
        normalized_weight = (weight - mean) * (var + eps).rsqrt()

        return F.conv2d(
            x,
            normalized_weight,
            self.bias,
            self.stride,
            self.padding,
            self.dilation,
            self.groups,
        )


class Block(nn.Module):
    def __init__(self, dim, dim_out, groups=8):
        super().__init__()
        self.proj = WeightStandardizedConv2d(dim, dim_out, 3, padding=1)
        self.norm = nn.GroupNorm(groups, dim_out)
        self.act = nn.SiLU()

    def forward(self, x, scale_shift=None):
        x = self.proj(x)
        x = self.norm(x)

        if exists(scale_shift):
            scale, shift = scale_shift
            x = x * (scale + 1) + shift

        x = self.act(x)
        return x


class ResnetBlock(nn.Module):
    """https://arxiv.org/abs/1512.03385"""

    def __init__(self, dim, dim_out, *, time_emb_dim=None, groups=8):
        super().__init__()
        self.mlp = (
            nn.Sequential(nn.SiLU(), nn.Linear(time_emb_dim, dim_out * 2))
            if exists(time_emb_dim)
            else None
        )

        self.block1 = Block(dim, dim_out, groups=groups)
        self.block2 = Block(dim_out, dim_out, groups=groups)
        self.res_conv = nn.Conv2d(dim, dim_out, 1) if dim != dim_out else nn.Identity()

    def forward(self, x, time_emb=None):
        scale_shift = None
        if exists(self.mlp) and exists(time_emb):
            time_emb = self.mlp(time_emb)
            time_emb = rearrange(time_emb, "b c -> b c 1 1")
            scale_shift = time_emb.chunk(2, dim=1)

        h = self.block1(x, scale_shift=scale_shift)
        h = self.block2(h)
        return h + self.res_conv(x)
```

### 注意力模块

接着定义注意力模块，DDPM 作者把它插在各卷积块之间。注意力是著名的 Transformer 架构（[Vaswani et al., 2017](https://arxiv.org/abs/1706.03762)）的构件，而 Transformer 已在 AI 的各个领域大放异彩——从 NLP、视觉到[蛋白质折叠](https://www.deepmind.com/blog/alphafold-a-solution-to-a-50-year-old-grand-challenge-in-biology)。Phil Wang 用了两种注意力变体：一种是常规多头自注意力（Transformer 那种），另一种是[线性注意力](https://github.com/lucidrains/linear-attention-transformer)（[Shen et al., 2018](https://arxiv.org/abs/1812.01243)），其时间/内存开销随序列长度线性增长，而常规注意力是二次的。

关于注意力机制的详细讲解，请阅读 Jay Alammar 的[精彩博客](https://jalammar.github.io/illustrated-transformer/)。

```
class Attention(nn.Module):
    def __init__(self, dim, heads=4, dim_head=32):
        super().__init__()
        self.scale = dim_head**-0.5
        self.heads = heads
        hidden_dim = dim_head * heads
        self.to_qkv = nn.Conv2d(dim, hidden_dim * 3, 1, bias=False)
        self.to_out = nn.Conv2d(hidden_dim, dim, 1)

    def forward(self, x):
        b, c, h, w = x.shape
        qkv = self.to_qkv(x).chunk(3, dim=1)
        q, k, v = map(
            lambda t: rearrange(t, "b (h c) x y -> b h c (x y)", h=self.heads), qkv
        )
        q = q * self.scale

        sim = einsum("b h d i, b h d j -> b h i j", q, k)
        sim = sim - sim.amax(dim=-1, keepdim=True).detach()
        attn = sim.softmax(dim=-1)

        out = einsum("b h i j, b h d j -> b h i d", attn, v)
        out = rearrange(out, "b h (x y) d -> b (h d) x y", x=h, y=w)
        return self.to_out(out)

class LinearAttention(nn.Module):
    def __init__(self, dim, heads=4, dim_head=32):
        super().__init__()
        self.scale = dim_head**-0.5
        self.heads = heads
        hidden_dim = dim_head * heads
        self.to_qkv = nn.Conv2d(dim, hidden_dim * 3, 1, bias=False)

        self.to_out = nn.Sequential(nn.Conv2d(hidden_dim, dim, 1), 
                                    nn.GroupNorm(1, dim))

    def forward(self, x):
        b, c, h, w = x.shape
        qkv = self.to_qkv(x).chunk(3, dim=1)
        q, k, v = map(
            lambda t: rearrange(t, "b (h c) x y -> b h c (x y)", h=self.heads), qkv
        )

        q = q.softmax(dim=-2)
        k = k.softmax(dim=-1)

        q = q * self.scale
        context = torch.einsum("b h d n, b h e n -> b h d e", k, v)

        out = torch.einsum("b h d e, b h d n -> b h e n", context, q)
        out = rearrange(out, "b h c (x y) -> b (h c) x y", h=self.heads, x=h, y=w)
        return self.to_out(out)
```

### 组归一化

DDPM 作者在 U-Net 的卷积/注意力层之间穿插组归一化（[Wu et al., 2018](https://arxiv.org/abs/1803.08494)）。下面定义 `PreNorm` 类，用于在注意力层之前施加 groupnorm（后文可见）。关于 Transformer 里归一化该放在注意力之前还是之后，曾有一场[论战](https://tnq177.github.io/data/transformers_without_tears.pdf)。

```
class PreNorm(nn.Module):
    def __init__(self, dim, fn):
        super().__init__()
        self.fn = fn
        self.norm = nn.GroupNorm(1, dim)

    def forward(self, x):
        x = self.norm(x)
        return self.fn(x)
```

### 条件 U-Net

现在所有构件都定义好了（位置编码、ResNet 块、注意力、组归一化），是时候定义整个神经网络了。回顾一下，网络 $\mathbf{\epsilon}_\theta(\mathbf{x}_t, t)$ 的职责是：接收一批带噪图像及各自的噪声水平，输出图像中加入过的噪声。更正式地说：

- 网络输入是形状 `(batch_size, num_channels, height, width)` 的带噪图像批次，和形状 `(batch_size, 1)` 的噪声水平批次，输出形状 `(batch_size, num_channels, height, width)` 的张量

网络这样搭建：

- 首先，对带噪图像批次施加一个卷积层，并计算噪声水平的位置编码
- 然后，执行一串下采样阶段。每个下采样阶段由 2 个 ResNet 块 + groupnorm + 注意力 + 残差连接 + 下采样操作组成
- 在网络中部，再次应用 ResNet 块，穿插注意力
- 然后，执行一串上采样阶段。每个上采样阶段由 2 个 ResNet 块 + groupnorm + 注意力 + 残差连接 + 上采样操作组成
- 最后，接一个 ResNet 块和一个卷积层

说到底，神经网络就像乐高积木一样把层叠起来（但理解它怎么运转很重要，参见 [Karpathy 的文章](http://karpathy.github.io/2019-04-25/recipe/)）。

```
class Unet(nn.Module):
    def __init__(
        self,
        dim,
        init_dim=None,
        out_dim=None,
        dim_mults=(1, 2, 4, 8),
        channels=3,
        self_condition=False,
        resnet_block_groups=4,
    ):
        super().__init__()

        # determine dimensions
        self.channels = channels
        self.self_condition = self_condition
        input_channels = channels * (2 if self_condition else 1)

        init_dim = default(init_dim, dim)
        self.init_conv = nn.Conv2d(input_channels, init_dim, 1, padding=0) # changed to 1 and 0 from 7,3

        dims = [init_dim, *map(lambda m: dim * m, dim_mults)]
        in_out = list(zip(dims[:-1], dims[1:]))

        block_klass = partial(ResnetBlock, groups=resnet_block_groups)

        # time embeddings
        time_dim = dim * 4

        self.time_mlp = nn.Sequential(
            SinusoidalPositionEmbeddings(dim),
            nn.Linear(dim, time_dim),
            nn.GELU(),
            nn.Linear(time_dim, time_dim),
        )

        # layers
        self.downs = nn.ModuleList([])
        self.ups = nn.ModuleList([])
        num_resolutions = len(in_out)

        for ind, (dim_in, dim_out) in enumerate(in_out):
            is_last = ind >= (num_resolutions - 1)

            self.downs.append(
                nn.ModuleList(
                    [
                        block_klass(dim_in, dim_in, time_emb_dim=time_dim),
                        block_klass(dim_in, dim_in, time_emb_dim=time_dim),
                        Residual(PreNorm(dim_in, LinearAttention(dim_in))),
                        Downsample(dim_in, dim_out)
                        if not is_last
                        else nn.Conv2d(dim_in, dim_out, 3, padding=1),
                    ]
                )
            )

        mid_dim = dims[-1]
        self.mid_block1 = block_klass(mid_dim, mid_dim, time_emb_dim=time_dim)
        self.mid_attn = Residual(PreNorm(mid_dim, Attention(mid_dim)))
        self.mid_block2 = block_klass(mid_dim, mid_dim, time_emb_dim=time_dim)

        for ind, (dim_in, dim_out) in enumerate(reversed(in_out)):
            is_last = ind == (len(in_out) - 1)

            self.ups.append(
                nn.ModuleList(
                    [
                        block_klass(dim_out + dim_in, dim_out, time_emb_dim=time_dim),
                        block_klass(dim_out + dim_in, dim_out, time_emb_dim=time_dim),
                        Residual(PreNorm(dim_out, LinearAttention(dim_out))),
                        Upsample(dim_out, dim_in)
                        if not is_last
                        else nn.Conv2d(dim_out, dim_in, 3, padding=1),
                    ]
                )
            )

        self.out_dim = default(out_dim, channels)

        self.final_res_block = block_klass(dim * 2, dim, time_emb_dim=time_dim)
        self.final_conv = nn.Conv2d(dim, self.out_dim, 1)

    def forward(self, x, time, x_self_cond=None):
        if self.self_condition:
            x_self_cond = default(x_self_cond, lambda: torch.zeros_like(x))
            x = torch.cat((x_self_cond, x), dim=1)

        x = self.init_conv(x)
        r = x.clone()

        t = self.time_mlp(time)

        h = []

        for block1, block2, attn, downsample in self.downs:
            x = block1(x, t)
            h.append(x)

            x = block2(x, t)
            x = attn(x)
            h.append(x)

            x = downsample(x)

        x = self.mid_block1(x, t)
        x = self.mid_attn(x)
        x = self.mid_block2(x, t)

        for block1, block2, attn, upsample in self.ups:
            x = torch.cat((x, h.pop()), dim=1)
            x = block1(x, t)

            x = torch.cat((x, h.pop()), dim=1)
            x = block2(x, t)
            x = attn(x)

            x = upsample(x)

        x = torch.cat((x, r), dim=1)

        x = self.final_res_block(x, t)
        return self.final_conv(x)
```

## 定义前向扩散过程

前向扩散过程在 $T$ 个时间步内，把噪声逐步加入来自真实分布的图像。加入方式遵循一个**方差调度**。原版 DDPM 作者采用线性调度：

> 我们把前向过程的方差设为从 $\beta_1 = 10^{-4}$ 线性增到 $\beta_T = 0.02$ 的常数。

不过（[Nichol et al., 2021](https://arxiv.org/abs/2102.09672)）证明，采用余弦调度能得到更好的结果。

下面我们为 $T$ 个时间步定义各种调度（稍后再选定其一）。

```
def cosine_beta_schedule(timesteps, s=0.008):
    """
    cosine schedule as proposed in https://arxiv.org/abs/2102.09672
    """
    steps = timesteps + 1
    x = torch.linspace(0, timesteps, steps)
    alphas_cumprod = torch.cos(((x / timesteps) + s) / (1 + s) * torch.pi * 0.5) ** 2
    alphas_cumprod = alphas_cumprod / alphas_cumprod[0]
    betas = 1 - (alphas_cumprod[1:] / alphas_cumprod[:-1])
    return torch.clip(betas, 0.0001, 0.9999)

def linear_beta_schedule(timesteps):
    beta_start = 0.0001
    beta_end = 0.02
    return torch.linspace(beta_start, beta_end, timesteps)

def quadratic_beta_schedule(timesteps):
    beta_start = 0.0001
    beta_end = 0.02
    return torch.linspace(beta_start**0.5, beta_end**0.5, timesteps) ** 2

def sigmoid_beta_schedule(timesteps):
    beta_start = 0.0001
    beta_end = 0.02
    betas = torch.linspace(-6, 6, timesteps)
    return torch.sigmoid(betas) * (beta_end - beta_start) + beta_start
```

先用 $T=300$ 的线性调度，并从 $\beta_t$ 定义好我们需要的各种变量，比如方差的累积乘积 $\bar{\alpha}_t$。下面每个变量都只是 1 维张量，存储从 $t$ 到 $T$ 的值。重要的是，我们还定义一个 `extract` 函数，用来按一批索引抽取对应的 $t$ 索引值。

```
timesteps = 300

# define beta schedule
betas = linear_beta_schedule(timesteps=timesteps)

# define alphas 
alphas = 1. - betas
alphas_cumprod = torch.cumprod(alphas, axis=0)
alphas_cumprod_prev = F.pad(alphas_cumprod[:-1], (1, 0), value=1.0)
sqrt_recip_alphas = torch.sqrt(1.0 / alphas)

# calculations for diffusion q(x_t | x_{t-1}) and others
sqrt_alphas_cumprod = torch.sqrt(alphas_cumprod)
sqrt_one_minus_alphas_cumprod = torch.sqrt(1. - alphas_cumprod)

# calculations for posterior q(x_{t-1} | x_t, x_0)
posterior_variance = betas * (1. - alphas_cumprod_prev) / (1. - alphas_cumprod)

def extract(a, t, x_shape):
    batch_size = t.shape[0]
    out = a.gather(-1, t.cpu())
    return out.reshape(batch_size, *((1,) * (len(x_shape) - 1))).to(t.device)
```

```
def p_losses(denoise_model, x_start, t, noise=None, loss_type="l1"):
    if noise is None:
        noise = torch.randn_like(x_start)

    x_noisy = q_sample(x_start=x_start, t=t, noise=noise)
    predicted_noise = denoise_model(x_noisy, t)

    if loss_type == 'l1':
        loss = F.l1_loss(noise, predicted_noise)
    elif loss_type == 'l2':
        loss = F.mse_loss(noise, predicted_noise)
    elif loss_type == "huber":
        loss = F.smooth_l1_loss(noise, predicted_noise)
    else:
        raise NotImplementedError()

    return loss
```

这里的 `denoise_model` 就是我们上面定义的 U-Net。我们用真实噪声与预测噪声之间的 Huber 损失。

## 采样

由于训练期间要不断从模型采样（跟踪进展），我们在下面定义采样代码。采样即论文的 Algorithm 2：

从扩散模型生成新图像的过程就是把扩散过程反着跑：从 $T$ 开始，从

高斯分布采样纯噪声，然后用神经网络逐步去噪（借助它学到的条件概率），直到时间步 $t = 0$。如上所示，把均值的重参数化代入、使用我们的噪声预测器，就能推出略微更干净一些的图像 $\mathbf{x}_{t-1}$。别忘了方差是预先已知的。

理想情况下，最终得到的图像看起来就像来自真实数据分布。

下面的代码实现了这个过程。

```
@torch.no_grad()
def p_sample(model, x, t, t_index):
    betas_t = extract(betas, t, x.shape)
    sqrt_one_minus_alphas_cumprod_t = extract(
        sqrt_one_minus_alphas_cumprod, t, x.shape
    )
    sqrt_recip_alphas_t = extract(sqrt_recip_alphas, t, x.shape)
    
    # Equation 11 in the paper
    # Use our model (noise predictor) to predict the mean
    model_mean = sqrt_recip_alphas_t * (
        x - betas_t * model(x, t) / sqrt_one_minus_alphas_cumprod_t
    )

    if t_index == 0:
        return model_mean
    else:
        posterior_variance_t = extract(posterior_variance, t, x.shape)
        noise = torch.randn_like(x)
        # Algorithm 2 line 4:
        return model_mean + torch.sqrt(posterior_variance_t) * noise 

# Algorithm 2 (including returning all images)
@torch.no_grad()
def p_sample_loop(model, shape):
    device = next(model.parameters()).device

    b = shape[0]
    # start from pure noise (for each example in the batch)
    img = torch.randn(shape, device=device)
    imgs = []

    for i in tqdm(reversed(range(0, timesteps)), desc='sampling loop time step', total=timesteps):
        img = p_sample(model, img, torch.full((b,), i, device=device, dtype=torch.long), i)
        imgs.append(img.cpu().numpy())
    return imgs

@torch.no_grad()
def sample(model, image_size, batch_size=16, channels=3):
    return p_sample_loop(model, shape=(batch_size, channels, image_size, image_size))
```

注意，上面的代码是原始实现的简化版。我们发现这个简化版（与论文 Algorithm 2 一致）和采用了[截断](https://github.com/hojonathanho/diffusion/issues/5)的[原版复杂实现](https://github.com/hojonathanho/diffusion/blob/master/diffusion_tf/diffusion_utils.py)效果一样好。

```
samples = sample(model, image_size=image_size, batch_size=64, channels=channels)

# show a random one
random_index = 5
plt.imshow(samples[-1][random_index].reshape(image_size, image_size, channels), cmap="gray")
```

## 延伸阅读

DDPM 论文证明了扩散模型是（无条件）图像生成的一条有前途的路。此后这一方向得到了（巨大的）改进，尤其在文本条件图像生成上。下面列一些重要的（但远非全部的）后续工作：

- Improved Denoising Diffusion Probabilistic Models（[Nichol et al., 2021](https://arxiv.org/abs/2102.09672)）：发现除均值外学习条件分布的方差有助提升性能
- Cascaded Diffusion Models for High Fidelity Image Generation（[Ho et al., 2021](https://arxiv.org/abs/2106.15282)）：提出级联扩散，用多个扩散模型组成的流水线生成分辨率递增的图像，实现高保真合成
- Diffusion Models Beat GANs on Image Synthesis（[Dhariwal et al., 2021](https://arxiv.org/abs/2105.05233)）：证明扩散模型可以超越当时最先进的生成模型——通过改进 U-Net 架构并引入分类器引导
- Classifier-Free Diffusion Guidance（[Ho et al., 2021](https://openreview.net/pdf?id=qw8AKxfYbI)）：证明不需要分类器也能引导扩散模型——用单个神经网络同时训练条件与无条件扩散模型
- Hierarchical Text-Conditional Image Generation with CLIP Latents (DALL-E 2)（[Ramesh et al., 2022](https://cdn.openai.com/papers/dall-e-2.pdf)）：用先验模型把文本描述转成 CLIP 图像嵌入，再由扩散模型解码为图像
- Photorealistic Text-to-Image Diffusion Models with Deep Language Understanding (ImageGen)（[Saharia et al., 2022](https://arxiv.org/abs/2205.11487)）：证明大型预训练语言模型（如 T5）与级联扩散结合，在文生图上表现出色

注意，这份清单只收录到本文撰写时（2022 年 6 月 7 日）为止的重要工作。

就目前来看，扩散模型的主要（也许唯一）缺点，是生成一张图像需要多次前向传播（GAN 这类生成模型则不然）。不过已有[研究](https://arxiv.org/abs/2204.13902)证明，少至 10 个去噪步也能实现高保真生成。
