#### **1. ML 是如何给金融带来积极影响的？**

我们都知道 ML 是所有行业的颠覆性力量，同时不断创造新的商业机会。不少金融产品因为 ML 而被创造或改变，比如个性化保险和定向营销。

颠覆和利润固然好，但我最喜欢的金融影响，是 ML 引发的关于"金融决策中的信任"的讨论。

过去，贷款审批、利率确定、组合管理等金融决策都由具备相关专业能力的人完成。本质上，人们把金融决策托付给"其他人"或"专家"（而且常常不加质疑）。

当 ML 试图自动化这个决策过程时，人们问："我们凭什么信任一个模型？"模型像是来取代诚实劳动者的厄运黑箱。但正是这场争论开启了关于金融决策信任与伦理的讨论——无论涉及的是谁或是什么。

作为行业，我们仍在定义这场讨论，但多亏了金融中的 ML，讨论比以前更透明了。

#### **2. 金融领域最大的 ML 挑战是什么？**

公司情况我不便置评，但成熟的金融机构和所有长寿组织一样，有一场持续的斗争：遗留系统。

金融组织存在已久，一路演化到今天，不知不觉间竟成了"科技公司"。这类组织既要拥抱前沿技术以应对新锐对手，又要保持支撑整个金融世界运转的稳健性。

这场内部博弈被机构的风险偏好拉向一边。金融——毕竟谈的是钱——风险通常随解决方案规模线性增长。但这之上还有系统故障会带来的其它形式的风险，比如监管风险和声誉风险。这种叠加的风险，加上把庞大成熟系统迁移到新技术栈的复杂性，至少在我看来，是采用 ML 这类前沿技术的最大挑战。

#### **3. 人们在把 ML 融入金融应用时常犯什么错误？**

ML 尽管近来备受关注，在软件工程领域仍然算相对年轻的学科。ML 应用的部署往往没有一个定义清晰的过程。艺术家/工程师能交付一个 ML 应用，但它周边的世界还不熟悉这套技术流程。在技术世界与非技术世界的交界处，我见过最多的"错误"。

为正确的业务与 ML KPI 做优化、定义正确的目标函数或期望的标签，都很不容易。我见过一些应用白白浪费，就因为预测窗口不对，或者预测的标签不对。

最糟的结果是：这种错位没能在开发阶段被发现，而是带进了生产环境。

应用由此可能制造出不期望的用户行为，或者干脆在度量/预测错误的东西。遗憾的是，我们往往给 ML 团队配上了工具和算力，却没配上扎实的流程和沟通缓冲带。而在一个定义不清的流程里，开头的错误会随着每一步不断放大。

#### **4. ML 的未来最让你兴奋的是什么？**

ML 不断有新东西出来，很难不兴奋。这个领域变化之快，令人耳目一新。

目前我们擅长解决一个个独立问题：计算机视觉、下一词预测、数据点生成等等，但还做不到同时处理多个问题。我很期待看到我们如何把这种行为建模成数学表达——它们现在看起来彼此矛盾。希望我们很快能做到！

#### **1. ML 是如何给金融带来积极影响的？**

机器学习在许多方面都对金融业产生了重大的积极影响。例如，它在打击金融犯罪、识别欺诈交易上发挥了作用。ML 是 KYC（Know Your Customer，了解你的客户）筛查和 AML（反洗钱）等应用中的关键工具。随着全球金融机构 AML 罚款增加、制裁格局不断变化、洗钱复杂度上升，银行正在加大对 KYC 和 AML 技术的投入，其中很多都由 ML 驱动。ML 正在革新这个行业的多个方面，尤其通过自动化各类流程、辅助分析师更高效准确地工作，带来巨大的效率提升。

ML 的一个关键优势是能从海量数据中学习并发现隐藏模式。金融业在数字化上focus，产出的数字数据前所未有地多，人类理解、处理并据此决策变得越来越难。ML 正在帮助人类理解数据、从中提炼信息、做出更明智的决策。在 Moody's Analytics，我们使用 ML 并帮助客户更好地管理风险、满足业务和行业需求。

#### **2. 金融领域最大的 ML 挑战是什么？**

- 在不影响真阳性的前提下减少假阳性——regtech（监管科技）领域不少使用 ML 的应用依赖告警。监管严格、决策错误 financial 影响巨大，人工调查既耗时又费力。ML 当然能辅助人类分析师做出正确决策。但如果一个 ML 系统产生大量假阳性，分析师的工作反而更难。把握好这个平衡，是 ML 在金融中的重要挑战。
- 基础研究与教育中的 ML 和金融中的 ML 之间的鸿沟——由于金融业的强监管属性，在 ML 领域，基础研究与金融行业之间的思想、数据和资源交流很有限，当然也有少数例外。这导致能满足金融行业需求的 ML 研究稀缺。我认为需要付出更多努力缩小这一差距，否则金融行业要利用最新 ML 进展会越来越难。
- 遗留基础设施与数据库——许多金融机构仍背着遗留基础设施，这让应用现代 ML 技术尤其难以集成。在发展新基础设施、让 ML 专业人士创新并产生更大影响方面，金融业不妨借鉴科技行业的关键理念、文化和最佳实践。整个行业的 ML 落地（operationalizing）无疑存在挑战。
- 数据与模型治理——这个行业需要投入更多数据和模型治理工作。我们收集的数据越来越多，就应该投入更多精力收集高质量、正确的数据。当 ML 模型参与决策时，必须格外谨慎。需要为不同金融应用开发恰当的模型治理措施和框架。这个领域的一大挑战是缺乏能把数据和模型治理落地的工具与技术——而在这个行业运行 ML 系统往往正需要这些。在理解训练数据中的偏差、并把消减偏差变成整体流程中的常规做法上，也应有更多投入。保证可审计性、模型和数据血缘（lineage）一直是 ML 团队的难点。
- 可解释性与可诠释性——开发既高精度又可解释、可诠释的模型是大挑战。现代深度学习模型常常优于更传统的模型，但缺乏可解释性与可诠释性。金融中的大多数应用都要求可解释。采纳该领域的最新进展、确保开发出的模型既可解释又能给出可说明的预测，一直是挑战。

#### **3. 人们在把 ML 融入金融应用时常犯什么错误？**

- 没吃透数据，也没吃透在其上训练的 ML 模型的原始预测。
- 不分析失败尝试、不从中吸取教训。
- 不理解最终应用以及它将被如何使用。
- 在简单方案可能就够用时硬上复杂技术。

#### **4. ML 的未来最让你兴奋的是什么？**

现代 ML 模型如何在海量数据上用自监督学习学到文本、音频、图像、视频、代码等的丰富表征，让我大为震撼。未来一定是多模态的，通过 ML 的视角理解多模态内容一直在稳步前进。我认为这在不远的将来会扮演关键角色，我很兴奋，也期待成为这些进展的一部分。

#### **1. ML 是如何给金融带来积极影响的？**

机器学习和人工智能对金融整体、尤其银行业，产生了深远而积极的影响。银行业有很多应用在做决策时必须考虑众多因素（特征），而这正是 ML 的传统强项。比如我们人人依赖的信用评分，就是由机器学习算法算出来的。

多年以来，有趣的是 ML 还帮助消除了决策中的人为偏见，提供了前后一致的算法化决策方式。例如在信用卡/贷款审批和房贷中，现代 AI 技术能把更多因素（自由文本、行为趋势、社交与金融往来）纳入决策考量，同时还能识别欺诈。

#### **2. 金融领域最大的 ML 挑战是什么？**

金融银行业的行业属性带来很多挑战。首先，它是高度监管的行业，许多方面都受政府监督。常用的数据往往是非常私人、可识别身份的数据（社会安全号、银行流水、税务记录等）。因此，在构建私密且无偏的 ML/AI 模型上必须付出大量心力。许多政府法规要求模型必须可解释。比如一笔贷款被拒，就有根本性的义务解释为什么被拒。

另一方面，在其他行业可能稀缺的数据，在金融行业却极其丰富（例如房贷记录必须保存 30 年）。数据数字化的当前趋势加上更复杂 AI/ML 技术的爆发，为应用这些进展创造了独一无二的机会。

#### **3. 人们在把 ML 融入金融应用时常犯什么错误？**

最常见的错误之一是不理解模型或技术背后的工作原理、优势和短板就直接使用。人们倾向于把 AI/ML 模型当"黑箱"。在金融领域，理解模型并能解释其输出尤其重要。另一个错误是没有在具有代表性的输入空间上全面测试模型。模型性能、验证、推理能力和模型监控（重训练周期）在选择模型时都需要考虑。

#### **4. ML 的未来最让你兴奋的是什么？**

现在正是投身应用 ML 和 AI 的好时代。AI/ML 技术即便没有重新定义，也确实在重塑许多科学学科。当前正在发生的一切将如何重塑未来，让我非常兴奋。

我刚做 NLP 时，曾被神经网络/语言模型的能力震撼：它们能生成一个数字或向量（我们现在叫嵌入）来表示一个词、一个带语法的句子，甚至一个段落。我们对更贴切、更具上下文的嵌入的探索从未停歇。

我们已经远超文本的"简单"嵌入，进化到在我看来更加惊人的"多模态"嵌入。我最兴奋的、最期待的就是生成并摆弄这些新嵌入，让未来的应用更精彩。
