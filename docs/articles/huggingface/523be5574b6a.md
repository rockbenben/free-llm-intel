[llama.cpp server](https://github.com/ggml-org/llama.cpp/tree/master/tools/server) 现已内置 **router 模式（路由模式）**，让你可以在多个模型之间动态加载、卸载和切换，无需重启。

> 提醒：llama.cpp server 是一个轻量、兼容 OpenAI 的 HTTP 服务器，用于在本地运行 LLM。

这一功能回应了把 Ollama 风格模型管理带入 llama.cpp 的热烈呼声。它采用多进程架构，每个模型运行在自己的进程中，因此某个模型崩溃时不会影响其他模型。

## 快速上手

通过**不指定模型**来启动 router 模式的服务器：

```
llama-server
```

它会自动从你的 llama.cpp 缓存（`LLAMA_CACHE` 或 `~/.cache/llama.cpp`）中发现模型。如果你之前通过 `llama-server -hf user/model` 下载过模型，它们会自动可用。

你也可以指向一个包含 GGUF 文件的本地目录：

```
llama-server --models-dir ./my-models
```

## 特性

- **自动发现**：扫描你的 llama.cpp 缓存（默认）或自定义的 `--models-dir` 文件夹中的 GGUF 文件
- **按需加载**：模型在首次被请求时自动加载
- **LRU 淘汰**：当达到 `--models-max`（默认 4）上限时，最久未使用的模型会被卸载
- **请求路由**：请求中的 `model` 字段决定由哪个模型处理

## 示例

### 与指定模型对话

```
curl http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "ggml-org/gemma-3-4b-it-GGUF:Q4_K_M",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

首次请求时，服务器自动把模型加载进内存（加载时间取决于模型大小）。后续对该模型的请求即时响应，因为它已经加载好了。

### 列出可用模型

```
curl http://localhost:8080/models
```

返回所有发现的模型及其状态（`loaded`、`loading` 或 `unloaded`）。

### 手动加载模型

```
curl -X POST http://localhost:8080/models/load \
  -H "Content-Type: application/json" \
  -d '{"model": "my-model.gguf"}'
```

### 卸载模型以释放显存

```
curl -X POST http://localhost:8080/models/unload \
  -H "Content-Type: application/json" \
  -d '{"model": "my-model.gguf"}'
```

## 关键选项

| Flag | Description |
| --- | --- |
| `--models-dir PATH` | 存放 GGUF 文件的目录 |
| `--models-max N` | 同时加载的最大模型数（默认：4） |
| `--no-models-autoload` | 禁用自动加载；必须显式调用 `/models/load` |

所有模型实例都继承 router 的设置：

```
llama-server --models-dir ./models -c 8192 -ngl 99
```

所有被加载的模型都将使用 8192 上下文并全量卸载到 GPU。你也可以用 [presets](https://github.com/ggml-org/llama.cpp/pull/17859) 为每个模型单独定义设置：

```
llama-server --models-preset config.ini
```

```
[my-model]
model = /path/to/model.gguf
ctx-size = 65536
temp = 0.7
```

## Web UI 同样支持

[内置 Web UI](https://github.com/ggml-org/llama.cpp/tree/master/tools/server/webui) 也支持模型切换。只需从下拉菜单选择一个模型，它会自动加载。
