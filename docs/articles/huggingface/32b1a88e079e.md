# H Company 全新 Holo2 模型领跑 UI 定位任务

距我们发布第一批 Holo2 模型仅两个月，H Company 携迄今最大的 UI 定位（UI localization）模型归来：**Holo2-235B-A22B Preview**。该模型在 [Screenspot-Pro](https://gui-agent.github.io/grounding-leaderboard/) 上创下 78.5% 的全新 State-of-the-Art（SOTA）纪录，并在 OSWorld G 上取得 79.0%。

Holo2-235B-A22B Preview 已在 [Hugging Face](https://huggingface.co/Hcompany/Holo2-235B-A22B) 上线，这是一个聚焦于 UI 元素定位的研究版本发布。

[![benchmark_table_light (3)](https://cdn-uploads.huggingface.co/production/uploads/698224a939bac08a1b6e0488/5dezFBy4-KimAIQR5_1j1.png)](https://cdn-uploads.huggingface.co/production/uploads/698224a939bac08a1b6e0488/5dezFBy4-KimAIQR5_1j1.png)

**Agentic 定位（Agentic Localization）**

高分辨率的 4K 界面对定位模型来说是个挑战：小尺寸的 UI 元素在大屏幕上难以精确标定。而借助 agentic 定位，Holo2 能够迭代式地细化预测，每一步都提升精度，在所有 Holo2 模型规模上带来 10-20% 的相对增益。

**Holo2-235B-A22B 在 ScreenSpot-Pro 上的表现**

Holo2-235B-A22B Preview 在单步模式下即可在 ScreenSpot-Pro 上达到 70.6% 的准确率；在 agent 模式下，仅需 3 步就取得 78.5%，在最具挑战性的 GUI grounding 基准上创下新的 state-of-the-art。

[![cost_perf_screenspot_pro_light (2)](https://cdn-uploads.huggingface.co/production/uploads/698224a939bac08a1b6e0488/nht6cib9ua4mfPcM2C1I1.png)](https://cdn-uploads.huggingface.co/production/uploads/698224a939bac08a1b6e0488/nht6cib9ua4mfPcM2C1I1.png)

**使用 SkyPilot 训练**

大规模训练 Holo2 模型需要在多个云服务商之间协调工作负载。H Company 使用 [SkyPilot](https://skypilot.readthedocs.io/) 作为统一接口，在基于 Kubernetes（k8s）的集群上启动训练任务。通过抽象掉基础设施的复杂性，SkyPilot 让研究人员专注于模型开发，而不必去管理 k8s manifest 或维护多套部署脚本。
