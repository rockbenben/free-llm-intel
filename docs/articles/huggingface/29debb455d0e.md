# Kakao Brain 开源 ViT、ALIGN 与新文本-图像数据集 COYO

本文另有语言版本：[简体中文](https://huggingface.co/blog/zh/vit-align)。

Alara Dirik、Unso Eun Seo Jo、Minwoo Byeon

Kakao Brain 与 Hugging Face 很高兴发布全新的开源图文数据集 [COYO](https://github.com/kakaobrain/coyo-dataset)（包含 7 亿个配对），以及在其上训练的两个新视觉语言模型 [ViT](https://github.com/kakaobrain/coyo-vit) 和 [ALIGN](https://github.com/kakaobrain/coyo-align)。这是 ALIGN 模型有史以来第一次以免费开源的形式对外发布，也是 ViT 和 ALIGN 模型首次连同训练数据集一同发布。

Kakao Brain 的 ViT 和 ALIGN 模型沿用了 Google 对应原始模型中给出的相同架构与超参数，只是在开源的 [COYO](https://github.com/kakaobrain/coyo-dataset) 数据集上进行了训练。Google 的 [ViT](https://ai.googleblog.com/2020/12/transformers-for-image-recognition-at.html) 和 [ALIGN](https://ai.googleblog.com/2021/05/align-scaling-up-visual-and-vision.html) 模型虽然使用了海量数据集训练（ViT 用了 3 亿张图片，ALIGN 用了 18 亿个图文配对），但由于这些数据集并未公开，旁人无法复现。对于那些希望在能够接触训练数据的前提下复现视觉语言建模的研究者来说，这一贡献尤其有价值。关于 Kakao ViT 和 ALIGN 模型的更多详细信息可以在[这里](https://huggingface.co/kakaobrain)找到。

本文将介绍全新的 [COYO](https://github.com/kakaobrain/coyo-dataset) 数据集、Kakao Brain 的 ViT 与 ALIGN 模型以及如何使用它们。以下是几个要点：

- 史上第一个开源的 ALIGN 模型！
- 第一批在开源数据集 [COYO](https://github.com/kakaobrain/coyo-dataset) 上训练的开放 ViT 与 ALIGN 模型
- Kakao Brain 的 ViT 和 ALIGN 模型性能与 Google 版本相当
- ViT 和 ALIGN 的演示已在 HF 上线！你可以用自己挑选的样本图片在线体验这两个模型

## 性能对比

Kakao Brain 发布的 ViT 和 ALIGN 模型性能与 Google 对其实现的报告基本持平，某些任务上甚至更好。Kakao Brain 的 `ALIGN-B7-Base` 模型虽然训练所用的配对数量少得多（7 亿对 vs 18 亿对），但在 Image KNN 分类任务上与 Google 的 `ALIGN-B7-Base` 表现相当，而在 MS-COCO 检索的图像到文本、文本到图像任务上表现更佳。Kakao Brain 的 `ViT-L/16` 在 384 和 512 两种模型分辨率下，于 ImageNet 和 ImageNet-ReaL 上的评测结果与 Google 的 `ViT-L/16` 相近。这意味着，当用户需要访问训练数据时，社区可以用 Kakao Brain 的 ViT 和 ALIGN 模型来复现 Google 的 ViT 与 ALIGN 发布成果。我们很高兴看到这些性能达到最先进水平的模型以开源、透明的方式发布！

## COYO 数据集

这次模型发布的特别之处，在于模型是在免费、可访问的 COYO 数据集上训练的。[COYO](https://github.com/kakaobrain/coyo-dataset#dataset-preview) 是一个包含 7 亿个配对的图文数据集，与 Google 的 `ALIGN 1.8B` 图文数据集类似——后者是从网页上收集的"含噪" alt-text 与图片配对——但 COYO 是开源的。`COYO-700M` 和 `ALIGN 1.8B` 之所以被称为"含噪"，是因为它们只做了极少的过滤。`COYO` 与另一个开源图文数据集 `LAION` 相似，但存在以下差异：`LAION` 2B 是一个规模大得多、包含 20 亿个英文配对的数据集，而 `COYO` 只有 7 亿个配对；不过 `COYO` 的每条数据都附带更丰富的元数据，让用户在使用时拥有更大的灵活性和更细粒度的控制。下表列出了具体差异：`COYO` 为全部配对提供了美学分数，配备了更健壮的水印分数，以及人脸数量数据。

| COYO | LAION 2B | ALIGN 1.8B |
| --- | --- | --- |
| 使用 CLIP ViT-B/32 和 ViT-L/14 模型计算图文相似度分数，作为元数据提供；但不做任何过滤，以避免可能的剔除偏差 | 使用 CLIP（ViT-B/32）提供图文相似度分数——仅保留阈值 0.28 以上的样本 | 极少，仅基于频率的过滤 |
| 对图像和文本都做 NSFW 过滤 | 仅对图像做 NSFW 过滤 | [Google Cloud API](https://cloud.google.com/vision) |
| 以元数据形式提供人脸识别（人脸数量）数据 | 无人脸识别数据 | NA |
| 7 亿个配对，全部为英文 | 20 亿英文 | 18 亿 |
| 来自 CC 2020 年 10 月 - 2021 年 8 月 | 来自 CC 2014-2020 | NA |
| 美学分数 | 美学分数（部分） | NA |
| 更健壮的水印分数 | 水印分数 | NA |
| 托管在 Hugging Face Hub | 托管在 Hugging Face Hub | 未公开 |
| 英文 | 英文 | 英文？ |

## ViT 与 ALIGN 的工作原理

那这些模型到底能做什么？我们先简要讨论一下 ViT 和 ALIGN 模型的工作方式。

ViT——Vision Transformer——是 [Google 在 2020 年提出](https://ai.googleblog.com/2020/12/transformers-for-image-recognition-at.html)的一个视觉模型，其架构与文本 Transformer 十分相似。它是视觉领域的一种全新思路，不同于自 2012 年 AlexNet 以来一直主导视觉任务的卷积神经网络（CNN）。在性能相当的情况下，它的计算效率比 CNN 高出至多四倍，而且与具体领域无关。ViT 的输入是一张图像，图像被切分成一串图像小块（patch）——就像文本 Transformer 接收一串文本一样——并为每个小块加上位置嵌入，从而学习图像的结构。ViT 的表现尤其值得一提的在于它出色的性能-算力权衡。Google 的部分 ViT 模型已经开源，但训练它们所用的 JFT 3 亿图像-标签配对数据集并未公开。而 Kakao Brain 的 ViT 在 [COYO-Labeled-300M](https://github.com/kakaobrain/coyo-dataset/tree/main/subset/COYO-Labeled-300M)（已公开发布）上训练，发布的模型在各类任务上表现与 Google 版本相近，其代码、模型和训练数据（COYO-Labeled-300M）全部对外开放，以保证可复现性与开放科学。

ViT 工作方式的可视化说明来自 Google Blog

[随后 Google 推出了 ALIGN](https://ai.googleblog.com/2021/05/align-scaling-up-visual-and-vision.html)——2021 年发布的大规模图像与噪声文本嵌入模型——这是一个在"含噪"图文数据上训练的视觉-语言模型，可用于图像文本检索等各类视觉与跨模态任务。ALIGN 采用简洁的双编码器架构，在图文配对上训练，通过对比损失函数进行学习。ALIGN 的"含噪"训练语料在规模与鲁棒性之间取得了很好的平衡。在此以前，视觉语言表示学习都是在带有手工标签的大规模数据集上训练的，而这类标签需要大量的预处理工作。ALIGN 的语料直接使用图像的 alt-text 数据——也就是图片加载失败时显示的那段文字——把它当作图像的描述。这样得到的数据集虽然难免含噪，但规模大得多（18 亿对），使得 ALIGN 在各类任务上都能达到最先进水平。Kakao Brain 的 ALIGN 是该模型的第一个开源版本，在 `COYO` 数据集上训练，且表现优于 Google 报告的结果。

ALIGN 模型示意图来自 Google Blog

## 如何使用 COYO 数据集

我们可以借助 🤗 Datasets 库，用一行代码方便地下载 `COYO` 数据集。想要预览 `COYO` 数据集，或了解数据梳理流程和其中包含的元属性，可以访问 Hub 上的[数据集页面](https://huggingface.co/datasets/kakaobrain/coyo-700m)，或者原始的 Git [代码仓库](https://github.com/kakaobrain/coyo-dataset)。首先安装 🤗 Datasets 库：`pip install datasets`，然后下载数据。

```
>>> from datasets import load_dataset

>>> dataset = load_dataset('kakaobrain/coyo-700m')
>>> dataset
```

虽然比 `LAION` 数据集小得多，但 `COYO` 仍然是一个庞然大物，包含 7.47 亿个图文配对，把整个数据集下载到本地可能并不现实。如果只想下载数据集的一个子集，我们只需给 `load_dataset()` 方法传入 `streaming=True` 参数，创建一个可迭代数据集，随用随取地下载数据。

```
>>> from datasets import load_dataset

>>> dataset = load_dataset('kakaobrain/coyo-700m', streaming=True)
>>> print(next(iter(dataset['train'])))
```

## 如何从 Hub 使用 ViT 与 ALIGN

接下来动手试试新的 ViT 和 ALIGN 模型。由于 ALIGN 是新加入 🤗 Transformers 的模型，我们需要安装最新版本的库：`pip install -q git+https://github.com/huggingface/transformers.git`，然后导入要用到的模块和库，从 ViT 的图像分类任务开始。请注意，新加入的 ALIGN 模型会在库的下一个发布版本中进入 PyPI 包。

```
import requests
from PIL import Image
import torch
from transformers import ViTImageProcessor, ViTForImageClassification
```

接着，我们从 COCO 数据集中随机下载一张"沙发上的两只猫和遥控器"的图片，并对图像做预处理，把它转成模型期望的输入格式。这一步可以借助对应的预处理器类（`ViTProcessor`）轻松完成。为了初始化模型和预处理器，我们使用 Hub 上的[某一个 Kakao Brain ViT 仓库](https://huggingface.co/models?search=kakaobrain/vit)。请注意，从仓库初始化预处理器，可以保证预处理出的图像符合该特定预训练模型所要求的格式。

```
url = 'http://images.cocodataset.org/val2017/000000039769.jpg'
image = Image.open(requests.get(url, stream=True).raw)

processor = ViTImageProcessor.from_pretrained('kakaobrain/vit-large-patch16-384')
model = ViTForImageClassification.from_pretrained('kakaobrain/vit-large-patch16-384')
```

剩下的步骤很简单：我们对图像做预处理，然后作为输入送进模型，得到类别 logits。Kakao Brain 的 ViT 图像分类模型是在 ImageNet 标签上训练的，输出的 logits 形状为 (batch_size, 1000)。

```
# preprocess image or list of images
inputs = processor(images=image, return_tensors="pt")

# inference
with torch.no_grad():
    outputs = model(**inputs)

# apply SoftMax to logits to compute the probability of each class
preds = torch.nn.functional.softmax(outputs.logits, dim=-1)

# print the top 5 class predictions and their probabilities
top_class_preds = torch.argsort(preds, descending=True)[0, :5]

for c in top_class_preds:
    print(f"{model.config.id2label[c.item()]} with probability {round(preds[0, c.item()].item(), 4)}")
```

这样就完成了！为了让流程更简单、代码更短，我们还可以使用便捷的图像分类 [pipeline](https://huggingface.co/docs/transformers/main_classes/pipelines#transformers.ImageClassificationPipeline)，把 Kakao Brain 的 ViT 仓库名作为目标模型传入来初始化 pipeline。之后传入图片的 URL、本地路径或一个 Pillow 图像对象即可，还可以选择性地用 `top_k` 参数返回前 k 个预测。我们来给那张猫和遥控器的图片取前 5 个预测结果。

```
>>> from transformers import pipeline

>>> classifier = pipeline(task='image-classification', model='kakaobrain/vit-large-patch16-384')
>>> classifier('http://images.cocodataset.org/val2017/000000039769.jpg', top_k=5)
[{'score': 0.8223727941513062, 'label': 'remote control, remote'}, {'score': 0.06580372154712677, 'label': 'tabby, tabby cat'}, {'score': 0.0655883178114891, 'label': 'tiger cat'}, {'score': 0.0388941615819931, 'label': 'Egyptian cat'}, {'score': 0.0011215205304324627, 'label': 'lynx, catamount'}]
```

如果你想进一步试验 Kakao Brain 的 ViT 模型，可以前往它在 🤗 Hub 上的 [Space](https://huggingface.co/spaces/adirik/kakao-brain-vit)。

下面来试试 ALIGN。它可以用来获取文本或图像的多模态嵌入，也可以执行零样本图像分类。ALIGN 在 transformers 中的实现和用法与 [CLIP](https://huggingface.co/docs/transformers/main/en/model_doc/clip) 类似。第一步是下载预训练模型及其处理器，该处理器既能预处理图像也能预处理文本，使它们符合 ALIGN 视觉编码器和文本编码器的输入格式要求。同样，我们先导入要用到的模块，并初始化预处理器和模型。

```
import requests
from PIL import Image
import torch
from transformers import AlignProcessor, AlignModel


url = 'http://images.cocodataset.org/val2017/000000039769.jpg'
image = Image.open(requests.get(url, stream=True).raw)

processor = AlignProcessor.from_pretrained('kakaobrain/align-base')
model = AlignModel.from_pretrained('kakaobrain/align-base')
```

我们先从零样本图像分类开始。为此，我们提供一组候选标签（自由文本），让 AlignModel 判断哪个描述更贴合这张图像。先把图像和文本输入都做好预处理，再送入 AlignModel。

```
candidate_labels = ['an image of a cat', 'an image of a dog']

inputs = processor(images=image, text=candidate_labels, return_tensors='pt')

with torch.no_grad():
    outputs = model(**inputs)

# this is the image-text similarity score
logits_per_image = outputs.logits_per_image  

# we can take the softmax to get the label probabilities
probs = logits_per_image.softmax(dim=1)  
print(probs)
```

完成了，就这么简单。如果想用 Kakao Brain 的 ALIGN 模型做更多零样本图像分类实验，直接去 🤗 Hub 上的[演示页面](https://huggingface.co/spaces/adirik/ALIGN-zero-shot-image-classification)即可。请注意，`AlignModel` 的输出还包含 `text_embeds` 和 `image_embeds`（参见 ALIGN 的[文档](https://huggingface.co/docs/transformers/main/en/model_doc/align)）。如果我们不需要为零样本分类计算逐图像、逐文本的 logits，可以直接用 `AlignModel` 类提供的便捷方法 `get_image_features()` 和 `get_text_features()` 来获取视觉和文本嵌入。

```
text_embeds = model.get_text_features(
    input_ids=inputs['input_ids'],
    attention_mask=inputs['attention_mask'],
    token_type_ids=inputs['token_type_ids'],
)
image_embeds = model.get_image_features(
    pixel_values=inputs['pixel_values'],
)
```

另一种做法是直接使用 ALIGN 独立的视觉编码器和文本编码器来获取多模态嵌入。这些嵌入随后可以用于训练目标检测、图像分割、图像描述生成等各类下游任务的模型。下面看看如何用 `AlignTextModel` 和 `AlignVisionModel` 获取这些嵌入。请注意，AlignProcessor 这个便捷类也可以分别只预处理文本或只预处理图像。

```
from transformers import AlignTextModel


processor = AlignProcessor.from_pretrained('kakaobrain/align-base')
model = AlignTextModel.from_pretrained('kakaobrain/align-base')

# get embeddings of two text queries
inputs = processor(['an image of a cat', 'an image of a dog'], return_tensors='pt')

with torch.no_grad():
    outputs = model(**inputs)

# get the last hidden state and the final pooled output 
last_hidden_state = outputs.last_hidden_state
pooled_output = outputs.pooler_output
```

推理时把 `output_hidden_states` 和 `output_attentions` 参数设为 True，还可以返回全部的隐藏状态和注意力权重。

```
with torch.no_grad():
    outputs = model(**inputs, output_hidden_states=True, output_attentions=True)

# print what information is returned
for key, value in outputs.items():
    print(key)
```

对 `AlignVisionModel` 做同样的事情，获取一张图像的多模态嵌入。

```
from transformers import AlignVisionModel


processor = AlignProcessor.from_pretrained('kakaobrain/align-base')
model = AlignVisionModel.from_pretrained('kakaobrain/align-base')

url = 'http://images.cocodataset.org/val2017/000000039769.jpg'
image = Image.open(requests.get(url, stream=True).raw)

inputs = processor(images=image, return_tensors='pt')

with torch.no_grad():
    outputs = model(**inputs)

# print the last hidden state and the final pooled output 
last_hidden_state = outputs.last_hidden_state
pooled_output = outputs.pooler_output
```

和 ViT 一样，我们也可以用零样本图像分类 [pipeline](https://huggingface.co/docs/transformers/main_classes/pipelines#transformers.ZeroShotImageClassificationPipeline) 来进一步简化工作。看看如何用这个 pipeline，凭自由文本候选标签在真实场景的图片上做分类。

```
>>> from transformers import pipeline

>>> classifier = pipeline(task='zero-shot-image-classification', model='kakaobrain/align-base')
>>> classifier(
...     'https://huggingface.co/datasets/Narsil/image_dummy/raw/main/parrots.png',
...     candidate_labels=['animals', 'humans', 'landscape'],
... )
[{'score': 0.9263709783554077, 'label': 'animals'}, {'score': 0.07163811475038528, 'label': 'humans'}, {'score': 0.0019908479880541563, 'label': 'landscape'}]

>>> classifier(
...    'https://huggingface.co/datasets/Narsil/image_dummy/raw/main/parrots.png',
...    candidate_labels=['black and white', 'photorealist', 'painting'],
... )
[{'score': 0.9735308885574341, 'label': 'black and white'}, {'score': 0.025493400171399117, 'label': 'photorealist'}, {'score': 0.0009757201769389212, 'label': 'painting'}]
```
