# 欢迎使用 Hub 上的推理提供商 🔥

今天，我们在 Hub 的模型页面上正式集成了四家出色的无服务器（serverless）推理提供商（Inference Providers）——**fal、Replicate、Sambanova、Together AI**。它们同样无缝接入了我们的客户端 SDK（JS 和 Python），让你能比以往任何时候都更轻松地探索在心仪提供商上运行的各类模型的无服务器推理。

我们在 Hub 上托管无服务器 Inference API 已经很久了（v1 是 2020 年夏天上线的——时光飞逝 🤯）。它确实让探索和原型验证变得简单，但我们已经把核心价值主张打磨到了与社区协作的大数据集/大模型的存储、版本管理与分发上。与此同时，无服务器提供商蓬勃发展，Hugging Face 通过一组优秀提供商提供统一、便捷的无服务器推理访问，时机已经成熟。

正如我们通过与 AWS、Nvidia 等优秀伙伴合作，在模型页面的 Deploy 按钮中提供专用部署选项一样，与下一代无服务器推理提供商合作、提供以模型为中心的无服务器推理，也是顺理成章的事。

这能做什么？以恰逢其时的 DeepSeek-ai/DeepSeek-R1 为例——过去几天它已经火出圈 🔥：

[SambaNova](https://huggingface.co/sambanovasystems) 联合创始人兼 CEO Rodrigo Liang："我们很高兴与 Hugging Face 合作加速其 Inference API。Hugging Face 的开发者现在可以在大量最优秀的开源模型上获得快得多的推理速度。"

[Replicate](https://huggingface.co/replicate) 创始设计师 Zeke Sikelianos："Hugging Face 事实上就是开源模型权重之家，在让 AI 走向世界方面是关键力量。Replicate 内部就把 Hugging Face 作为首选的权重注册中心，我们很荣幸成为这次发布中首批登场的推理提供商。"

**这只是开始，接下来几周我们会和社区一起把它做得更好（[讨论帖](https://huggingface.co/spaces/huggingface/HuggingDiscussions/discussions/49)）！**

## 工作原理

### 网站 UI 中

- 在用户账号设置里，你可以：

- 为你已注册的提供商配置自己的 API key。不配也能用——你的请求会经 HF 路由转发。
- 按偏好给提供商排序。这会影响模型页中的 widget 和代码片段。

- 如前所述，调用 Inference API 有两种模式：

- 自备 key（请求直接发往推理提供商，使用你在该提供商的 API key）；或
- 由 HF 路由（此时你不需要提供商的 token，费用直接记在你的 HF 账号上，而不是提供商的账号）

- 模型页面会展示第三方推理提供商（与当前模型兼容的那些，按用户偏好排序）

### 使用客户端 SDK

#### Python：huggingface_hub

下面的例子展示如何以 Together AI 作为推理提供商使用 DeepSeek-R1。你可以用 [Hugging Face token](https://huggingface.co/settings/tokens) 走 Hugging Face 自动路由，也可以用你自己的 Together AI API key（如果有）。

安装 `huggingface_hub` v0.28.0 或更新版本（[发布说明](https://github.com/huggingface/huggingface_hub/releases/tag/v0.28.0)）。

```
from huggingface_hub import InferenceClient

client = InferenceClient(
    provider="together",
    api_key="xxxxxxxxxxxxxxxxxxxxxxxx"
)

messages = [
    {
        "role": "user",
        "content": "What is the capital of France?"
    }
]

completion = client.chat.completions.create(
    model="deepseek-ai/DeepSeek-R1", 
    messages=messages, 
    max_tokens=500
)

print(completion.choices[0].message)
```

**注意：** 你也可以用 OpenAI 客户端库调用 Inference Providers，[这里有 DeepSeek 模型的示例](https://huggingface.co/deepseek-ai/DeepSeek-R1?inference_provider=together&language=python&inference_api=true)。

下面是用 [FLUX.1-dev](https://huggingface.co/black-forest-labs/FLUX.1-dev)（运行在 [fal.ai](https://fal.ai/models/fal-ai/flux/dev) 上）从文本提示词生成图片的方法：

```
from huggingface_hub import InferenceClient

client = InferenceClient(
    provider="fal-ai",
    api_key="xxxxxxxxxxxxxxxxxxxxxxxx"
)

# output is a PIL.Image object
image = client.text_to_image(
    "Labrador in the style of Vermeer",
    model="black-forest-labs/FLUX.1-dev"
)
```

想换到别的提供商，只需改一下 provider 名，其他一切不变：

```
from huggingface_hub import InferenceClient

client = InferenceClient(
-	provider="fal-ai",
+	provider="replicate",
    api_key="xxxxxxxxxxxxxxxxxxxxxxxx"
)
```

#### JS：@huggingface/inference

```
import { HfInference } from "@huggingface/inference";

const client = new HfInference("xxxxxxxxxxxxxxxxxxxxxxxx");

const chatCompletion = await client.chatCompletion({
    model: "deepseek-ai/DeepSeek-R1",
    messages: [
        {
            role: "user",
            content: "What is the capital of France?"
        }
    ],
    provider: "together",
    max_tokens: 500
});

console.log(chatCompletion.choices[0].message);
```

### HTTP 调用

我们把路由代理直接暴露在 huggingface.co 域名下，你可以直接调用；对 OpenAI 兼容 API 特别有用。只需把 base URL 换成 `https://router.huggingface.co/{:provider}`。

下面是用 cURL、以 Sambanova 作为推理提供商调用 Llama-3.3-70B-Instruct 的方法。

```
curl 'https://router.huggingface.co/sambanova/v1/chat/completions' \
-H 'Authorization: Bearer xxxxxxxxxxxxxxxxxxxxxxxx' \
-H 'Content-Type: application/json' \
--data '{
    "model": "Llama-3.3-70B-Instruct",
    "messages": [
        {
            "role": "user",
            "content": "What is the capital of France?"
        }
    ],
    "max_tokens": 500,
    "stream": false
}'
```

## 计费

直接请求——即使用推理提供商自己的 key 时——由对应提供商计费。例如使用 Together AI 的 key，费用记在你的 Together AI 账号上。

路由请求——即通过 Hub 认证时——你只需支付提供商的标准 API 费率。我们不加任何差价，只把提供商成本原样透传。（未来我们可能与提供商伙伴达成收入分成协议。）
