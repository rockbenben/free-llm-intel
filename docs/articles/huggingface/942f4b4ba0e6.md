# 使用 Python 入门情感分析

情感分析（sentiment analysis）是按照数据的情感倾向（如正面、负面、中性）对其进行自动打标签的过程。情感分析让企业能够大规模地分析数据、发现洞察并实现流程自动化。

过去，情感分析往往仅限于研究者、机器学习工程师，或具备自然语言处理经验的数据科学家。但近年来，AI 社区构建了一些出色的工具，让人人都有机会用上机器学习。如今，你只需要几行代码、完全没有任何机器学习经验，就能使用情感分析！🤯

在本指南中，你将学到使用 Python 入门情感分析所需的一切，包括：

- [如何在 Python 中使用预训练的情感分析模型](https://huggingface.co/blog/sentiment-analysis-python#2-how-to-use-pre-trained-sentiment-analysis-models-with-python)
- [如何构建你自己的情感分析模型](https://huggingface.co/blog/sentiment-analysis-python#3-building-your-own-sentiment-analysis-model)
- [如何用情感分析与 Python 分析推文](https://huggingface.co/blog/sentiment-analysis-python#4-analyzing-tweets-with-sentiment-analysis-and-python)

## 1. 什么是情感分析？

情感分析是一种[自然语言处理](https://en.wikipedia.org/wiki/Natural_language_processing)技术，用于识别给定文本的极性。情感分析有多种不同的形式，其中最广泛使用的技术之一是把数据标注为正面、负面和中性。举个例子，我们来看看这些提到了 [@VerizonSupport](https://twitter.com/VerizonSupport) 的推文：

- *"dear @verizonsupport your service is straight 💩 in dallas.. been with y’all over a decade and this is all time low for y’all. i’m talking no internet at all."* → 会被标注为「负面」。
- *"@verizonsupport ive sent you a dm"* → 会被标注为「中性」。
- *"thanks to michelle et al at @verizonsupport who helped push my no-show-phone problem along. order canceled successfully and ordered this for pickup today at the apple store in the mall."* → 会被标注为「正面」。

情感分析能够以大规模、实时（real-time）的方式处理数据。例如，你想分析数千条推文、产品评论或支持工单吗？与其手动逐一浏览这些数据，你可以用情感分析自动了解人们谈论某个特定话题的方式、为数据驱动的决策获取洞察，并自动化业务流程。

情感分析被广泛应用于各种场景，例如：

- 分析社交媒体提及，了解人们谈论你的品牌与谈论你的竞品时的口碑差异。
- 分析来自调查和产品评论的反馈，快速获取客户喜欢你产品什么、不喜欢你产品什么的洞察。
- 实时分析新收到的支持工单，检测出愤怒的客户并采取相应措施以防止客户流失。

## 2. 如何在 Python 中使用预训练的情感分析模型

既然我们已经了解了什么是情感分析，就可以动手玩一玩情感分析模型了！🎉

在 [Hugging Face Hub](https://huggingface.co/models) 上，我们正在构建公开的、规模最大的模型与数据集集合，以让人人都有机会用上机器学习 🚀。在 Hub 上，你可以找到超过 27,000 个由 AI 社区分享的模型，它们在情感分析、目标检测、文本生成、语音识别等任务上达到了最先进（state-of-the-art）的性能。Hub 免费使用，大多数模型都提供了一个组件（widget），让你可以直接在浏览器中测试它们！

Hub 上公开可用的[情感分析模型](https://huggingface.co/models?pipeline_tag=text-classification&sort=downloads&search=sentiment)超过 215 个，用 Python 接入它们只需要 5 行代码：

```
pip install -q transformers
from transformers import pipeline
sentiment_pipeline = pipeline("sentiment-analysis")
data = ["I love you", "I hate you"]
sentiment_pipeline(data)
```

这段代码使用了 [pipeline 类](https://huggingface.co/docs/transformers/main_classes/pipelines) 来基于 Hub 上可用的模型进行预测。它使用[默认的情感分析模型](https://huggingface.co/distilbert-base-uncased-finetuned-sst-2-english?text=I+like+you.+I+love+you) 来分析文本列表 `data`，并输出如下结果：

```
[{'label': 'POSITIVE', 'score': 0.9998},
 {'label': 'NEGATIVE', 'score': 0.9991}]
```

通过提供模型名称，你可以使用一个更适合你的语言或使用场景（use case）的特定情感分析模型。例如，如果你想要一个用于推文的情感分析模型，可以指定该 [model id](https://huggingface.co/finiteautomata/bertweet-base-sentiment-analysis)：

```
specific_model = pipeline(model="finiteautomata/bertweet-base-sentiment-analysis")
specific_model(data)
```

## 3. 构建你自己的情感分析模型

在本节中，我们将介绍两种方法，讲述如何用自己的数据和评判标准对情感分析模型进行微调。第一种方法使用 [🤗Transformers](https://github.com/huggingface/transformers) 的 Trainer API，这是一个拥有 5 万星标和 1000 多位贡献者的开源库，需要更多的编码和经验。第二种方法更简单直接，它使用 [AutoNLP](https://huggingface.co/autonlp)，这是一个无需代码、无需机器学习经验即可自动训练、评估和部署最先进 NLP 模型的工具。

#### 2. 预处理数据

微调 DistilBERT 做情感分析需要数据。因此，我们用 [🤗Datasets](https://github.com/huggingface/datasets/) 库来下载并预处理 IMDB 数据集，以便你随后用这些数据来训练模型：

```
from datasets import load_dataset
imdb = load_dataset("imdb")
```

IMDB 是一个庞大的数据集，所以我们创建更小的数据集，以便更快地训练和测试：

```
small_train_dataset = imdb["train"].shuffle(seed=42).select([i for i in list(range(3000))])
small_test_dataset = imdb["test"].shuffle(seed=42).select([i for i in list(range(300))])
```

为了预处理数据，你将使用 [DistilBERT tokenizer](https://huggingface.co/docs/transformers/v4.15.0/en/model_doc/distilbert#transformers.DistilBertTokenizer)：

```
from transformers import AutoTokenizer
tokenizer = AutoTokenizer.from_pretrained("distilbert-base-uncased")
```

接下来，你使用 [map 方法](https://huggingface.co/docs/datasets/about_map_batch.html) 为数据集的两个切分（训练集和测试集）准备模型的文本输入：

```
def preprocess_function(examples):
   return tokenizer(examples["text"], truncation=True)
 
tokenized_train = small_train_dataset.map(preprocess_function, batched=True)
tokenized_test = small_test_dataset.map(preprocess_function, batched=True)
```

为加速训练，我们使用一个 data_collator 把训练样本转换为 PyTorch 张量（tensor），并以合适的 [padding](https://huggingface.co/docs/transformers/preprocessing#everything-you-always-wanted-to-know-about-padding-and-truncation) 量把它们拼接起来：

```
from transformers import DataCollatorWithPadding
data_collator = DataCollatorWithPadding(tokenizer=tokenizer)
```

#### 3. 训练模型

预处理完成后，你就可以着手训练模型了 🚀

你将丢弃 DistilBERT 模型的预训练头（pretraining head），把它换成一个针对情感分析微调过的分类头（classification head）。这使你能够把知识从 DistilBERT 迁移到你自己的模型 🔥

训练时，你将使用 [Trainer API](https://huggingface.co/docs/transformers/v4.15.0/en/main_classes/trainer#transformers.Trainer)，它专为微调 [Transformers](https://github.com/huggingface/transformers)🤗 模型（如 DistilBERT、BERT 和 RoBERTa）而优化。

首先，把 DistilBERT 定义为你的基础模型：

```
from transformers import AutoModelForSequenceClassification
model = AutoModelForSequenceClassification.from_pretrained("distilbert-base-uncased", num_labels=2)
```

然后，定义你用来评估微调模型好坏的指标（[准确率和 f1 分数](https://huggingface.co/metrics)）：

```
import numpy as np
from datasets import load_metric
 
def compute_metrics(eval_pred):
   load_accuracy = load_metric("accuracy")
   load_f1 = load_metric("f1")
  
   logits, labels = eval_pred
   predictions = np.argmax(logits, axis=-1)
   accuracy = load_accuracy.compute(predictions=predictions, references=labels)["accuracy"]
   f1 = load_f1.compute(predictions=predictions, references=labels)["f1"]
   return {"accuracy": accuracy, "f1": f1}
```

接下来，登录你的 [Hugging Face 账户](https://huggingface.co/join)，以便管理你的模型仓库。`notebook_login` 会在 notebook 中启动一个组件，你需要在其中添加你的 [Hugging Face token](https://huggingface.co/settings/token)：

```
from huggingface_hub import notebook_login

```

就快好了！在训练模型之前，你需要定义训练参数，并用到目前为止构建的所有对象来定义一个 Trainer：

```
from transformers import TrainingArguments, Trainer
 
repo_name = "finetuning-sentiment-model-3000-samples"
 
training_args = TrainingArguments(
   output_dir=repo_name,
   learning_rate=2e-5,
   per_device_train_batch_size=16,
   per_device_eval_batch_size=16,
   num_train_epochs=2,
   weight_decay=0.01,
   save_strategy="epoch",
   push_to_hub=True,
)
 
trainer = Trainer(
   model=model,
   args=training_args,
   train_dataset=tokenized_train,
   eval_dataset=tokenized_test,
   tokenizer=tokenizer,
   data_collator=data_collator,
   compute_metrics=compute_metrics,
)
```

现在，是时候在情感分析数据集上微调模型了！🙌 你只需调用 Trainer 的 `train()` 方法：

```
trainer.train()
```

就这样！你成功微调出了一个用于情感分析的 DistilBERT 模型！🎉

训练时间取决于你使用的硬件和数据集中的样本数量。在我们的例子中，用 GPU、以 3,000 个样本微调模型花了将近 10 分钟。用于训练的样本越多，模型就越准确，但训练可能会明显变慢。

接下来，计算评估指标，看看你的模型有多好：

```
trainer.evaluate()
```

在我们的例子中，准确率为 88%，f1 分数为 89%。对于仅用 3,000 个样本训练的情感分析模型来说，这相当不错！

### 3. 用 Tweepy 搜索推文

到这里，你已经准备好开始用 Twitter API 抓取推文了 🎉。你将使用 [Tweepy Cursor](https://docs.tweepy.org/en/v3.5.0/cursor_tutorial.html) 来提取 1,000 条提到 #NFTs 的推文：

```
# Helper function for handling pagination in our search and handle rate limits
def limit_handled(cursor):
   while True:
       try:
           yield cursor.next()
       except tweepy.RateLimitError:
           print('Reached rate limite. Sleeping for >15 minutes')
           time.sleep(15 * 61)
       except StopIteration:
           break
 
# Define the term you will be using for searching tweets
query = '#NFTs'
query = query + ' -filter:retweets'
 
# Define how many tweets to get from the Twitter API
count = 1000
 
# Let's search for tweets using Tweepy
search = limit_handled(tweepy.Cursor(api.search,
                       q=query,
                       tweet_mode='extended',
                       lang='en',
                       result_type="recent").items(count))
```

### 4. 对推文运行情感分析

现在，你可以把新学到的技能派上用场，对你的数据运行情感分析！🎉

你将使用 Hub 上一个针对[推文情感分析](https://huggingface.co/finiteautomata/bertweet-base-sentiment-analysis)微调过的模型。与本文其他几节一样，你会用 [pipeline 类](https://huggingface.co/docs/transformers/main_classes/pipelines) 通过该模型进行预测：

```
from transformers import pipeline
 
# Set up the inference pipeline using a model from the 🤗 Hub
sentiment_analysis = pipeline(model="finiteautomata/bertweet-base-sentiment-analysis")
 
# Let's run the sentiment analysis on each tweet
tweets = []
for tweet in search:
   try:
     content = tweet.full_text
     sentiment = sentiment_analysis(content)
     tweets.append({'tweet': content, 'sentiment': sentiment[0]['label']})
 
   except:
     pass
```
