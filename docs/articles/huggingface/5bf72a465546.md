我们兴奋地宣布 **`langchain_huggingface`** 正式发布——这是 LangChain 中由 Hugging Face 与 LangChain 共同维护的伙伴包（partner package）。这个新的 Python 包旨在把 Hugging Face 最新开发的能量带入 LangChain，并保持与时俱进。

# 取之于社区，用之于社区

LangChain 中所有与 Hugging Face 相关的类都由社区编写。我们在其中茁壮成长，但随着时间的推移，其中一些类因为缺少内部视角而逐渐过时。

通过成为伙伴包，我们的目标是缩短把 Hugging Face 生态新功能带给 LangChain 用户所需的时间。

**`langchain-huggingface`** 与 LangChain 无缝集成，在 LangChain 生态中高效使用 Hugging Face 模型。这项合作不只是共享技术，更是对持续维护和改进这一集成的共同承诺。

## **快速上手**

上手 **`langchain-huggingface`** 很简单。安装并开始使用这个[包](https://github.com/langchain-ai/langchain/tree/master/libs/partners/huggingface)的方法如下：

```
pip install langchain-huggingface
```

包装好了，来逛逛里面都有什么！

## LLM

### HuggingFacePipeline

在 `transformers` 中，[Pipeline](https://huggingface.co/docs/transformers/main_classes/pipelines) 是 Hugging Face 工具箱里最万能的工具。LangChain 主要为 RAG 与 Agent 用例而设计，因此这里的 pipeline 范围收敛到以下以文本为主的任务：`"text-generation"`、`"text2text-generation"`、`"summarization"`、`"translation"`。

模型可以直接通过 `from_model_id` 方法加载：

```
from langchain_huggingface import HuggingFacePipeline

llm = HuggingFacePipeline.from_model_id(
    model_id="microsoft/Phi-3-mini-4k-instruct",
    task="text-generation",
    pipeline_kwargs={
        "max_new_tokens": 100,
        "top_k": 50,
        "temperature": 0.1,
    },
)
llm.invoke("Hugging Face is")
```

你也可以先自己定义 pipeline，再传给这个类：

```
from transformers import AutoModelForCausalLM, AutoTokenizer,pipeline

model_id = "microsoft/Phi-3-mini-4k-instruct"
tokenizer = AutoTokenizer.from_pretrained(model_id)

model = AutoModelForCausalLM.from_pretrained(
    model_id,
    load_in_4bit=True,
    #attn_implementation="flash_attention_2", # if you have an ampere GPU
)
pipe = pipeline("text-generation", model=model, tokenizer=tokenizer, max_new_tokens=100, top_k=50, temperature=0.1)
llm = HuggingFacePipeline(pipeline=pipe)
llm.invoke("Hugging Face is")
```

使用这个类时，模型会加载到本地缓存并使用你电脑的硬件，因此可能受限于电脑可用资源。

### HuggingFaceEndpoint

这个类同样有两种用法。你可以用 `repo_id` 参数指定模型。这些 endpoint 使用[无服务器 API](https://huggingface.co/inference-api/serverless)，对使用 [pro 账户](https://huggingface.co/subscribe/pro)或 [enterprise hub](https://huggingface.co/enterprise)的人尤其有利；不过普通用户只要在运行代码的环境中配上 HF token，也能获得相当可观的请求额度。

```
from langchain_huggingface import HuggingFaceEndpoint

llm = HuggingFaceEndpoint(
    repo_id="meta-llama/Meta-Llama-3-8B-Instruct",
    task="text-generation",
    max_new_tokens=100,
    do_sample=False,
)
llm.invoke("Hugging Face is")
```

```
llm = HuggingFaceEndpoint(
    endpoint_url="<endpoint_url>",
    task="text-generation",
    max_new_tokens=1024,
    do_sample=False,
)
llm.invoke("Hugging Face is")
```

在底层，这个类使用 [InferenceClient](https://huggingface.co/docs/huggingface_hub/en/package_reference/inference_client)，能够服务从无缝 API 到已部署 TGI 实例的广泛用例。

### ChatHuggingFace

每个模型都有自己最适配的特殊 token。缺少这些 token，模型表现会大打折扣。

从消息列表转为补全 prompt 时，多数 LLM 分词器里有一个叫 [chat_template](https://huggingface.co/docs/transformers/chat_templating) 的属性。

想更深入地了解各模型的 chat_template，欢迎访问我做的这个 [Space](https://huggingface.co/spaces/Jofthomas/Chat_template_viewer)！

这个类是其他 LLM 之上的封装。它接收消息列表作为输入，然后用 `tokenizer.apply_chat_template` 方法生成正确的补全 prompt。

```
from langchain_huggingface import ChatHuggingFace, HuggingFaceEndpoint

llm = HuggingFaceEndpoint(
    endpoint_url="<endpoint_url>",
    task="text-generation",
    max_new_tokens=1024,
    do_sample=False,
)
llm_engine_hf = ChatHuggingFace(llm=llm)
llm_engine_hf.invoke("Hugging Face is")
```

上面的代码等价于：

```
# with mistralai/Mistral-7B-Instruct-v0.2
llm.invoke("<s>[INST] Hugging Face is [/INST]")

# with meta-llama/Meta-Llama-3-8B-Instruct
llm.invoke("""<|begin_of_text|><|start_header_id|>user<|end_header_id|>Hugging Face is<|eot_id|><|start_header_id|>assistant<|end_header_id|>""")
```

## Embeddings

Hugging Face 上有大量非常强大的 embedding 模型，可以直接在你的流水线中使用。

先选一个模型。挑选 embedding 模型的好去处是 [MTEB 排行榜](https://huggingface.co/spaces/mteb/leaderboard)。

### HuggingFaceEmbeddings

这个类使用 [sentence-transformers](https://sbert.net/) embeddings。它在本地计算 embedding，因而消耗你电脑的资源。

```
from langchain_huggingface.embeddings import HuggingFaceEmbeddings

model_name = "mixedbread-ai/mxbai-embed-large-v1"
hf_embeddings = HuggingFaceEmbeddings(
    model_name=model_name,
)
texts = ["Hello, world!", "How are you?"]
hf_embeddings.embed_documents(texts)
```

### HuggingFaceEndpointEmbeddings

`HuggingFaceEndpointEmbeddings` 与 `HuggingFaceEndpoint` 之于 LLM 的做法非常类似——它同样在底层使用 InferenceClient 来计算 embeddings。既可用于 hub 上的模型，也可用于 TEI 实例，无论其部署在本地还是线上。

```
from langchain_huggingface.embeddings import HuggingFaceEndpointEmbeddings

hf_embeddings = HuggingFaceEndpointEmbeddings(
    model= "mixedbread-ai/mxbai-embed-large-v1",
    task="feature-extraction",
    huggingfacehub_api_token="<HF_TOKEN>",
)
texts = ["Hello, world!", "How are you?"]
hf_embeddings.embed_documents(texts)
```
