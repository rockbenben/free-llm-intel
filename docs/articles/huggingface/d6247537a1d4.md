# 伦理与社会通讯 #3：Hugging Face 的伦理开放

本文另有[简体中文](https://huggingface.co/blog/zh/ethics-soc-3)版本。

## 使命：开放且美好的 ML

在民主化好的机器学习的使命中，我们审视支持 ML 社区工作如何同时赋能对潜在危害的检查与预防。开放开发与开放科学让权力去中心化，使许多人能共同构建反映自身需求与价值观的 AI。虽然[开放让更广泛的视角得以贡献于研究和 AI 整体，但它面临风险管控更弱的张力](https://arxiv.org/abs/2302.04844)。

对 ML 制品进行治理面临独特挑战，因为这些系统动态且快速演化。事实上，随着 ML 模型愈发先进、能产生越来越多样的内容，有害或非预期输出的可能性也在增长，需要发展稳健的治理与评估策略。此外，ML 模型的复杂性及其处理的海量数据，加剧了识别和应对潜在偏见与伦理问题的难度。

作为平台 hosting 方，我们认识到潜在放大对用户乃至全世界造成伤害所伴随的责任。这些危害往往以依赖情境的方式不成比例地影响少数群体。我们采取的方法是针对每个情境分析其中的张力，并向全公司和 Hugging Face 社区的讨论开放。虽然许多模型都可能放大危害——尤其是歧视性内容——我们正在采取一系列步骤识别最高风险的模型并决定行动方案。重要的是，来自多元背景的活跃视角，是理解、衡量和缓解影响不同人群的潜在危害的关键。

我们在改进文档实践的同时打造工具与防护措施，确保开源科学赋能个体并持续减少潜在危害。

## 伦理性类别

我们促进美好开放 ML 工作的第一个主要方面，是推广把价值观与利益相关方关怀置于优先的 ML 开发工具和正面范例。这帮助用户采取具体步骤解决悬而未决的问题，并为 ML 开发中事实上有害的做法提出可行的替代方案。

为帮助用户发现并参与伦理性 ML 工作，我们整理了一组标签。这 6 个高层类别基于我们对社区成员贡献的 Spaces 的分析，旨在提供一种无行话的思考伦理技术的方式：

- 严谨（Rigorous）的工作特别注重以最佳实践进行开发。在 ML 中，这可能意味着检验失效案例（包括开展偏见与公平性审计）、通过安全措施保护隐私、确保潜在用户（技术与非技术）了解项目的局限。
- 知情同意（Consentful）的工作[支持](https://www.consentfultech.io/)使用这些技术并受其影响的人的自我决定权。
- 社会关怀（Socially Conscious）的工作向我们展示技术如何支持社会、环境和科学努力。
- 可持续（Sustainable）的工作突出并探索让机器学习在生态上可持续的技术。
- 包容（Inclusive）的工作拓宽机器学习世界中建设者与受益者的范围。
- 探究（Inquisitive）的工作照亮不平等与权力结构，促使社区反思其与技术的关系。

更多内容见 [https://huggingface.co/ethics](https://huggingface.co/ethics)

请留意这些词汇——我们会使用这些标签，并根据社区贡献更新它们，出现在 Hub 上的一些新项目中！

## 防护措施

对开放发布采取"全有或全无"的视角，忽略了决定一个 ML 制品正面或负面影响的多样化情境。对 ML 系统如何分享与复用拥有更多控制手段，能支持协作开发与分析，同时降低助长有害用途或滥用的风险；从而允许更多的开放与参与，共享创新红利。

我们与贡献者直接沟通并处理了紧迫问题。为把这项工作提升一个台阶，我们正在建设基于社区的流程。这种方式同时赋能 Hugging Face 的贡献者和受贡献影响的人，共同决定我们平台上可用的模型与数据在局限、分享和附加机制上的必要安排。我们关注的三个主要方面是：制品的来源、开发者如何处理该制品，以及该制品被如何使用。据此，我们：

- 上线了[标记（flagging）功能](https://twitter.com/GiadaPistilli/status/1571865167092396033)，让社区判断 ML 制品或社区内容（模型、数据集、space 或讨论）是否违反我们的[内容指南](https://huggingface.co/content-guidelines)，
- 监控社区讨论板，确保 Hub 用户遵守[行为准则](https://huggingface.co/code-of-conduct)，
- 为下载量最高的模型撰写详尽的模型卡，记录社会影响、偏见、预期用途与超范围使用，做了扎实的文档工作，
- 创建引导受众的标签，例如可加入仓库卡片元数据的 "Not For All Audiences" 标签，以避免未经请求的暴力和色情内容，
- 倡导为[模型](https://www.licenses.ai/blog/2022/8/26/bigscience-open-rail-m-license)使用 [Open Responsible AI Licenses (RAIL)](https://huggingface.co/blog/open_rail)，例如 LLM 的 [BLOOM](https://huggingface.co/spaces/bigscience/license)、[BigCode](https://huggingface.co/spaces/bigcode/license)，
- 开展[研究](https://arxiv.org/abs/2302.04844)，分析哪些模型和数据集具有最高的滥用/恶意使用潜在可能或有此类记录。

**如何使用标记功能：** 在任意 Model、Dataset、Space 或 Discussion 上点击标记图标：

![screenshot pointing to the flag icon to Report this model](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/ethics_soc_3/flag2.jpg) * While logged in, you can click on the "three dots" button to bring up the ability to report (or flag) a repository. This will open a conversation in the repository's community tab. *

说明你标记此项的原因：

![screenshot showing the text window where you describe why you flagged this item](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/ethics_soc_3/flag1.jpg) * Please add as much relevant context as possible in your report! This will make it much easier for the repo owner and HF team to start taking action. *

在把开放科学置于优先地位的同时，我们逐案审视潜在危害，并提供协作学习与共同承担责任的机会。当用户标记某个系统时，开发者可以直接而透明地回应关切。本着这种精神，我们要求仓库所有人尽合理努力处理报告——尤其当举报者花时间描述了问题。我们也强调，报告与讨论受与平台其余部分相同的交流规范约束。若讨论出现仇恨或辱骂行为，版主可以中止或关闭讨论（见[行为准则](https://huggingface.co/code-of-conduct)）。

如果某个模型被我们社区标记为高风险，我们会考虑：

- 在 Hub 的 trending 标签页和信息流中降低该 ML 制品的可见度，
- 要求启用 gating 功能以管理对 ML 制品的访问（见[模型](https://huggingface.co/docs/hub/models-gated)和[数据集](https://huggingface.co/docs/hub/datasets-gated)文档），
- 要求将模型设为私有，
- 禁用访问。

**如何添加 "Not For All Audiences" 标签：**

编辑模型/数据卡 → 在 tags 部分加入 `not-for-all-audiences` → 打开 PR 并等待作者合并。合并后，仓库将显示以下标签：

![screenshot showing where to add tags](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/ethics_soc_3/nfaa_tag.png)

任何带有 `not-for-all-audiences` 标签的仓库被访问时会显示以下弹窗：

![screenshot showing where to add tags](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/ethics_soc_3/nfaa2.png)

点击 "View Content" 即可正常查看该仓库。如果你希望始终无弹窗查看带 `not-for-all-audiences` 标签的仓库，可在用户的 [Content Preferences](https://huggingface.co/settings/content-preferences) 中修改设置。

![screenshot showing where to add tags](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/ethics_soc_3/nfaa1.png)

开放科学需要防护措施，我们的目标之一就是营造一种能理性权衡不同价值的环境。托管并提供模型访问，加上培育社区与讨论，能让多元群体评估社会影响，共同指引什么是美好的机器学习。
