想象一下移动 Cadiere 抓取器、抓住胆囊并将其抬起，所有这些都在生成的实时响应的手术场景中进行。今天，我们更进一步推出了 Cosmos3-H-Dreams，通过迄今为止最令人信服的体内图像，将交互式生成模拟引入到临床手术的视觉和程序复杂性中。

我们的第一个 [Cosmos-H-Dreams](https://huggingface.co/blog/nvidia/cosmos-h-dreams) 版本基于 Cosmos-Predict2.5 构建，为 dVRK 桌面缝合带来了交互式生成模拟，这是手术机器人的基础试验场。作为世界基础模型 (WFM)，Cosmos-H-Dreams 展示了数值模拟的替代方案：它不是明确地建模场景几何、组织变形和物理交互，而是直接从同步视频和机器人运动学中学习视觉动力学，从而产生高度真实的交互式桌面任务模拟。

如今，[Cosmos3-H-Dreams](https://github.com/isaac-for-healthcare/cosmos3-h-dreams) 通过在 CMR Surgical Versius 平台上的临床​​手术过程中学习视频和机器人运动学记录来提高这一功能。据我们所知，这是第一个经过临床胆囊切除术记录训练以支持实时运动控制的实时生成手术模拟器。 Cosmos3-H-Dreams 由 Cosmos 3 提供支持，并通过 NVIDIA 加速流推理库 FlashDreams 进行加速，可在单个 NVIDIA RTX PRO 6000 GPU 上交互式运行。

## 1. 从桌面任务到临床场景

在像 Cosmos-H-Dreams 这样的受控桌面环境中，仪器在相对简单的背景下运行。然而，在人体内部，微小的仪器运动可能会影响整个场景：组织在牵引力下拉伸，反射发生变化，结构被遮挡，烟雾会改变可见度。给定初始图像和提供的工具操作，生成模拟器必须捕获这些响应，同时在生成每个新视频块时保留解剖结构和仪器。小误差会随着时间的推移而累积，逐渐改变仪器的几何形状或解剖结构，从而使得时间一致性至关重要。

因此，视觉真实感是验证的起点，而不是生物力学准确性的证明。生成的场景还必须遵循控制：平移、旋转和夹具命令应产生连贯的解剖结果。忽略这些命令的看似合理的部署无法充当交互式环境。

在实时控制循环中保持这种保真度和响应能力需要低延迟生成。 Cosmos3-H-Dreams 通过专门用于临床胆囊切除术的模型来解决这一问题，并经过提炼以进行实时生成，将动作条件交互带入具有复杂解剖结构、组织运动和闭塞的场景中。

## 2. Cosmos3-H-Dreams 有什么新功能？

### 2.1 Cosmos 3 基础和更丰富的手术控制

Cosmos3-H-Dreams 建立在 [Cosmos3-H-Embodied-Nano](https://huggingface.co/nvidia/Cosmos3-H-Embodied-Nano) 之上，这是一个在 [Open-H-Embodiment](https://huggingface.co/datasets/nvidia/PhysicalAI-Robotics-Open-H-Embodiment) 上预训练的 160 亿参数模型，以及专门负责策划胆囊切除术视频和运动学的双向教师。样本选择针对两个可见的、啮合的仪器，一个左 Cadiere 抓握器和一个右单极钩，并限制相机命令以强调仪器驱动的交互。

该模型使用 28 个动作维度：双臂的姿势和夹具信息，以及能量控制、拇指杆轴和拇指杆按钮。训练使用 832 x 480 视频，动作以 10 Hz 对齐；该采样率与运行时生成吞吐量不同。

### 2.2 从老师到四步、两步学生

Cosmos3-H-Dreams 将专为长期自回归部署而设计的师生培训管道与通过 FlashDreams 进行的加速流式推理相结合。

我们首先在 24 个未来帧上调整双向教师，然后将范围扩展到 72 帧，10 Hz 下的 2.4 和 7.2 秒。这为教师提供了更长的序列来学习手术动力学。

接下来，蒸馏将双向教师转变为因果学生，可以在新动作到来时生成短块视频。因果教师强制让学生为使用记录的上下文进行连续生成做好准备。然后，在老师和博学的批评家的指导下，自我强迫在自己生成的环境中对其进行训练。这有助于解决交互式部署期间错误的累积问题。

第一个发布的学生对每个生成的块使用四个去噪步骤。然后，我们通过两步计划进一步培训该学生以生成第二个发布检查点。两步模型是单独训练的，而不是简单的四步模型以更少的采样步骤运行。

更少的去噪步骤会导致更快的推理时间，但代价是较低的视觉质量。这两个检查点都让开发人员探索视觉质量和推理成本之间的平衡。

### 2.3 通过 FlashDreams 进行流式传输

[FlashDreams](https://github.com/NVIDIA/flashdreams) 提供加速流运行时。长期部署还需要管理模型的注意力历史记录。 Cosmos3-H-Dreams 集成使用经过调整的 FadeMem 模块，该模块可在长期部署期间整合不断增长的键/值缓存。这补充了自强迫：蒸馏解决了模型如何从其生成的历史中学习的问题，而缓存整合则解决了在流生成期间如何存储历史的问题。

## 3. 探索看不见的轨迹

在临床手术过程中，可能会出现并发症，或者外科医生有执行“新”动作的空间。因此，模拟器必须能够概括训练数据之外的内容，并生成具有看不见的运动的连贯帧。下面的演示展示了 Cosmos3-H-Dreams 根据 VR 耳机记录的仪器动作生成不同的胆囊切除术场景。

两个视频以相同的初始帧开始，但遵循不同的动作序列，说明仪器控制如何导致同一场景的不同连续性和物理上精确的组织变形。

此外，这些推出使我们能够检查仪器是否遵循控制，组织是否对相互作用做出一致的反应，以及解剖结构和仪器外观是否随着时间的推移保持一致。

## 4. 适应您自己的数据和控制器

Cosmos3-H-Dreams 包括胆囊切除术的四步和两步检查点。该系统可以适用于具有同步视频和兼容动作表示的其他数据集和实施例。为了在您自己的数据集上训练实时学生模型，我们在[分步指南](https://github.com/NVIDIA-Medtech/Cosmos3-H-Embodied-Nano/blob/main/cosmos3_h_embodied/tutorial_teacher_training_and_self_forcing.md)中提供了教师微调和自我强制蒸馏的完整方法。它描述了数据准备、公共教师培训工具和蒸馏阶段。控制器集成必须使用与训练相同的操作约定和规范化。

## 5.下一步是什么

视觉写实主义的进步开辟了几个研究方向：

- **对整个过程进行建模。** 扩大覆盖范围和时间一致性，以便可以系统地探索胆囊切除术的所有阶段，并具有明确的任务边界和成功标准。
- **连接生成模拟和数值模拟。** 将学到的视觉真实感与显式几何、接触和组织力学相结合。数值模型和测量数据可以帮助约束和验证变形，使模拟行为可检查且令人信服。
- **与外科医生一起评估。** 评估解剖准确性、器械行为和组织反应，将专家反馈转化为可重复的基准。
- **支持更多仪器。**超越两种受控工具，实现更丰富的协调、遮挡和交互。
- **制定自主手术政策。** 将世界行动模型与 Cosmos3-H-Dreams 耦合到闭环中，以便政策可以学习定义的胆囊切除术子任务。

这些是研究方向，而不是已建立的临床能力。 Cosmos3-H-Dreams 是一个研究模拟器，而不是经过验证的患者护理系统。它为在日益现实的环境中研究手术相互作用提供了基础。
