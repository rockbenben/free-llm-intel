### Holo1

[Holo1](https://huggingface.co/collections/Hcompany/holo1-683dd1eece7eb077b96d0cbd) 是第一个专门为深度 web UI 理解和精确定位设计的开源 Action VLM 家族。家族包含 Holo1-3B 和 Holo1-7B 两个模型，后者在常用 UI 定位基准上达到 76.2% 的平均准确率——是小尺寸模型中的最高分。H Company 已在 [Hugging Face](https://huggingface.co/collections/Hcompany/holo1-683dd1eece7eb077b96d0cbd) 开源发布这些模型，连同包含 1,639 个拟人化 UI 任务的 [WebClick](https://huggingface.co/datasets/Hcompany/WebClick) 基准。

## 配合 Transformers 使用

Holo1 模型基于 Qwen2.5-VL 架构，与 transformers 完全兼容。这里给出一个简单的使用示例。你可以如下加载模型和 processor。

```
from transformers import AutoModelForImageTextToText, AutoProcessor
import torch
model = AutoModelForImageTextToText.from_pretrained(
    "Hcompany/Holo1-3B",
    torch_dtype=torch.bfloat16,
    attn_implementation="flash_attention_2",
    device_map="auto",
)

processor = AutoProcessor.from_pretrained("Hcompany/Holo1-3B")
```

加载图像并预处理。

```
image_url = "https://huggingface.co/Hcompany/Holo1-3B/resolve/main/calendar_example.jpg" 


guidelines = "Localize an element on the GUI image according to my instructions and output a click position as Click(x, y) with x num pixels from the left edge and y num pixels from the top edge."
instruction = "Select July 14th as the check-out date"
messages = [
        {
            "role": "user",
            "content": [
                {
                    "type": "image",
                    "url": image_url,
                },
                {"type": "text", "text": f"{guidelines}\n{instruction}"},
            ],
        }
    ]


inputs = processor.apply_chat_template(
    messages,
    tokenize=True,
    add_generation_prompt=True,
    return_tensors="pt",
    return_dict=True,
).to(model.device)
```

现在可以推理了。

```
generated_ids = model.generate(**inputs, max_new_tokens=128)

decoded = processor.batch_decode(generated_ids, skip_special_tokens=True, clean_up_tokenization_spaces=False)

# Click(352, 348)
```

### Surfer-H

Web 自动化是 AI 对企业最具实用价值的应用之一，但到目前为止，各种方案往往为了性能牺牲性价比。把我们的 Holo1 Action Models 放到 Hugging Face 上之后，用户现在可以在真实 web 任务上实现 92.2% 准确率、每个任务只需 0.13 美元的 web 自动化方案。

[Surfer-H](https://www.hcompany.ai/surfer-h) 依赖 Holo1 开放权重模型家族。它是一个实现完整 web 任务自动化的模块化架构，能执行阅读、思考、点击、滚动、输入和校验。其设计灵活而模块化，由三个独立组件组成：负责规划并驱动 agent 行为的 Policy 模型、理解视觉 UI 以实现精确交互的 Localizer 模型、确认任务是否成功完成的 Validator 模型。不同于依赖自定义 API 或脆弱封装的其他 agent，Surfer-H 完全通过浏览器操作——就像一个真实用户。
