# 在 NVIDIA DGX Cloud 上用 H100 GPU 轻松训练模型

本文另有中文版本 [简体中文](https://huggingface.co/blog/zh/train-dgx-cloud)。

> 更新：该服务已停用，自 2025 年 4 月 10 日起不再可用。

今天，我们兴奋地宣布 **Train on DGX Cloud** 上线——这是 Hugging Face Hub 上面向 Enterprise Hub 组织的新服务。Train on DGX Cloud 让开源模型与 NVIDIA DGX Cloud 的加速计算基础设施轻松结合。我们共同打造这项服务，让 Enterprise Hub 用户只需几次点击，就能在 [Hugging Face Hub](https://huggingface.co/models) 内使用最新的 NVIDIA H100 Tensor Core GPU，微调 Llama、Mistral、Stable Diffusion 等热门生成式 AI 模型。

## 告别 GPU 荒

这一新体验建立在我们[去年宣布的战略合作](https://nvidianews.nvidia.com/news/nvidia-and-hugging-face-to-connect-millions-of-developers-to-generative-ai-supercomputing)之上，旨在简化开源生成式 AI 模型在 NVIDIA 加速计算上的训练与部署。开发者和组织面临的主要问题之一是 GPU 供应稀缺，以及编写、测试、调试 AI 模型训练脚本的耗时工作。Train with DGX Cloud 为这些挑战提供了简单的解决方案：提供即时可用的 NVIDIA GPU，首发即是在 NVIDIA DGX Cloud 上的 H100。此外，Train with DGX Cloud 依托 Hugging Face AutoTrain 和 Hugging Face Spaces，提供无代码的简单训练任务创建体验。

[Enterprise Hub](https://huggingface.co/enterprise) 组织可以为团队提供即时可用的强大 NVIDIA GPU，只需按训练任务实际使用的计算实例分钟数付费。

Hugging Face AutoTrain 作者 Abhishek Thakur 表示：「*Train on DGX Cloud 是训练生成式 AI 模型最简单、最快、最易触达的方式——即时使用强大 GPU、按量付费、无代码训练三者合一。*」「它将成为全世界数据科学家的游戏规则改变者！」

NVIDIA DGX Cloud 副总裁 Alexis Bjorlin 表示：「*今天发布的由 DGX Cloud 驱动的 Hugging Face AutoTrain，是简化 AI 模型训练的重要一步。把 NVIDIA 的云超级计算机与 Hugging Face 友好的界面集成，我们正在赋能各组织加速其 AI 创新。*」

## 工作原理

在 NVIDIA DGX Cloud 上训练 Hugging Face 模型从未如此简单。下面是一个微调 Mistral 7B 的分步教程。

*注意：使用 Train on DGX Cloud 需要你所在的组织拥有 [Hugging Face Enterprise](https://huggingface.co/enterprise) 订阅*

你可以在受支持的生成式 AI 模型的模型页面上找到 Train on DGX Cloud。当前支持的模型架构有：Llama、Falcon、Mistral、Mixtral、T5、Gemma、Stable Diffusion 和 Stable Diffusion XL。

打开 "Train" 菜单，选择 "NVIDIA DGX Cloud"——这将打开一个界面，让你选择企业组织。

然后，点击 "Create new Space"。首次使用 Train on DGX Cloud 时，服务会在你的组织内创建一个新的 Hugging Face Space，供你使用 AutoTrain 创建将在 NVIDIA DGX Cloud 上执行的训练任务。之后要创建另一个训练任务时，会自动跳转回已有的 AutoTrain Space。

进入 AutoTrain Space 后，你可以配置 Hardware、Base Model、Task 和 Training Parameters 来创建训练任务。

硬件方面，你可以选择 NVIDIA H100 GPU（提供 1x、2x、4x 和 8x 实例）或 L40S GPU（即将推出）。训练数据集必须直接上传到 "Upload Training File(s)" 区域，当前支持 CSV 和 JSON 文件。请确保列映射正确，参照页面示例。训练参数方面，你可以直接编辑右侧的 JSON 配置，例如把 epoch 数从 3 改成 2。

一切设置好后，点击 "Start Training" 开始训练。AutoTrain 会先验证你的数据集，然后请你确认训练。

打开 Space 的 "logs" 即可监控训练过程。

训练完成后，你的微调模型会被上传到 Hugging Face Hub 你所选命名空间下的一个新私有仓库。

Train on DGX Cloud 今天起面向所有 Enterprise Hub 组织开放！来试试，告诉我们你的反馈！

## Train on DGX Cloud 定价

Train on DGX Cloud 按训练任务期间所用 GPU 实例的分钟数计费。当前训练任务定价：H100 实例每 GPU 小时 8.25 美元，L40S 实例每 GPU 小时 2.75 美元。费用在任务完成后计入你 Enterprise Hub 组织当前的月度账期。你随时可以在企业组织的账单设置中查看当前和历史的用量。

| NVIDIA GPU | GPU Memory | On-Demand Price/hr |
| --- | --- | --- |
| [NVIDIA L40S](https://www.nvidia.com/en-us/data-center/l40/) | 48GB | $2.75 |
| [NVIDIA H100](https://www.nvidia.com/de-de/data-center/h100/) | 80 GB | $8.25 |

例如，在单块 NVIDIA L40S 上用 1500 条样本微调 Mistral 7B 约需 10 分钟，花费约 0.45 美元。

## 我们才刚刚开始

我们非常激动能与 NVIDIA 合作，在开放科学、开源与云服务中推动加速机器学习的民主化。

我们在开放科学上的合作通过 [BigCode](https://huggingface.co/bigcode) 实现了 [StarCoder 2 15B](https://huggingface.co/bigcode/starcoder2-15b) 的训练——一个完全开源、最先进的代码 LLM，在 600 多种语言上训练。

我们在开源上的合作正在为新推出的 [optimum-nvidia 库](https://github.com/huggingface/optimum-nvidia)注入动力，在最新 NVIDIA GPU 上加速 LLM 推理，并已用 Llama 2 达到每秒 1,200 token。

我们在云服务上的合作诞生了今天的 Train on DGX Cloud。我们还在与 NVIDIA 一起优化推理、让 Hugging Face 社区更容易用上加速计算，依托我们在 [NVIDIA TensorRT-LLM](https://developer.nvidia.com/blog/optimizing-inference-on-llms-with-tensorrt-llm-now-publicly-available/) 和 [optimum-nvidia](https://github.com/huggingface/optimum-nvidia) 上的合作。此外，Hugging Face 上一些最受欢迎的开源模型将登陆今天 GTC 上宣布的 [NVIDIA NIM microservices](https://developer.nvidia.com/blog/nvidia-nim-offers-optimized-inference-microservices-for-deploying-ai-models-at-scale/)。
