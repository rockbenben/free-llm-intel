# SyGra：为 LLM 和 SLM 构建数据的一站式框架

当我们想到构建一个模型——无论是大语言模型（LLM）还是小语言模型（SLM）——首先需要的是数据。虽然有海量开放数据可用，但它们很少正好是训练或对齐模型所要求的格式。在实践中，我们常常遇到原始数据不够用的情形。我们需要更结构化、更领域特定、更复杂、或更贴合当前任务的数据。来看几个常见的场景：

#### 缺少复杂场景

你从一个简单数据集出发，但模型在高级推理任务上失败。你该如何生成更复杂的数据集来提升性能？

#### 知识库转 Q&A

你已经有一个知识库，但它不是 Q&A 格式。你如何把它转换成可用的问答数据集？

#### 从 SFT 到 DPO

你已经准备好了一个监督微调（SFT）数据集。但现在你想用直接偏好优化（DPO）来对齐模型。你如何生成偏好对（preference pairs）？

#### 问题的深度

你有一个 Q&A 数据集，但问题很浅。你如何创建深入、多轮或重推理的问题？

#### 领域特定的中训练

你拥有一个庞大的语料库，但需要为某个特定领域的中训练（mid-training）过滤和精选数据。

#### PDF 与图像转文档

你的数据藏在 PDF 或图像里，你需要把它们转换成结构化文档，用来构建 Q&A 系统。

#### 增强推理能力

你已经有推理数据集，但想推动模型产生更好的"思考 token（thinking tokens）"以进行逐步解题。

#### 质量过滤

并非所有数据都是好数据。你如何自动过滤掉低质量样本，只保留高价值的样本？

#### 从小上下文到大上下文

你的数据集只有小段上下文，但你想构建面向 RAG（检索增强生成）流水线优化的大上下文数据集。

#### 跨语言转换

你有德语数据集，但需要把它们翻译、改编并复用到英语的 Q&A 系统中。这样的例子不胜枚举。在现代 AI 模型的工作里，围绕数据构建的需求永无止境。

## SyGra 登场：一个框架应对所有数据挑战

这就是 [SyGra](https://github.com/ServiceNow/SyGra) 的用武之地。[SyGra](https://github.com/ServiceNow/SyGra) 是一个低代码/无代码框架，旨在为 LLM 和 SLM 简化数据集的创建、转换与对齐。你无需编写复杂的脚本和流水线，可以专注于提示工程（prompt engineering），而把繁重的活儿交给 [SyGra](https://github.com/ServiceNow/SyGra)。
[SyGra](https://github.com/ServiceNow/SyGra) 的关键特性：

- ✅ Python 库 + 框架：通过 SyGra 库轻松集成进现有 ML 工作流。
- ✅ 支持多种推理后端：与 vLLM、Hugging Face TGI、Triton、Ollama 等无缝协作。
- ✅ 低代码/无代码：无需繁重工程即可构建复杂数据集。
- ✅ 灵活的数据生成：从 Q&A 到 DPO、从推理到多语言，SyGra 都能适配你的用例。

## SyGra 为何重要

数据是 AI 的基石。数据的质量、多样性和结构往往比微调模型架构更重要。通过实现灵活、可扩展的数据集创建，SyGra 帮助团队：

- 加速模型对齐（SFT、DPO、RAG 流水线）。
- 用即插即用的工作流节省工程时间。
- 提升模型在复杂和领域特定任务上的稳健性。
- 减少人工数据集精选的工作量。
