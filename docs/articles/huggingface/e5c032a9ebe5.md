# 为 Hugging Face 用户带来 Serverless GPU 推理

本文另有[简体中文](https://huggingface.co/blog/zh/cloudflare-workers-ai)版本。

更新（2024 年 11 月）：该集成已不再可用。请切换到 Hugging Face Inference API、Inference Endpoints 或其他部署方案来满足你的 AI 模型需求。

今天，我们非常兴奋地宣布 **Deploy on Cloudflare Workers AI**——Hugging Face Hub 上的新集成。Deploy on Cloudflare Workers AI 让使用开放模型如同使用 serverless API 一样简单，由部署在 Cloudflare 边缘数据中心的先进 GPU 提供支撑。从今天起，我们把 Hugging Face 上一些最受欢迎的开放模型集成进 Cloudflare Workers AI，由我们的生产级方案（如 [Text Generation Inference](https://github.com/huggingface/text-generation-inference/)）驱动。

有了 Deploy on Cloudflare Workers AI，开发者无需管理 GPU 基础设施和服务器，就能以极低的运营成本构建稳健的生成式 AI 应用：只为你使用的算力付费，不为闲置容量买单。

## 面向开发者的生成式 AI

这一新体验扩展了我们[去年宣布的战略合作](https://blog.cloudflare.com/partnering-with-hugging-face-deploying-ai-easier-affordable)，简化开放生成式 AI 模型的访问与部署。开发者和组织面临的主要问题之一是 GPU 稀缺，以及为开始构建而部署服务器产生的固定成本。Deploy on Cloudflare Workers AI 为这些挑战提供了简单、低成本的方案：以[按请求付费](https://developers.cloudflare.com/workers-ai/platform/pricing)的模式，serverless 地访问热门 Hugging Face 模型。

看一个具体例子。假设你开发一个 RAG 应用，每天约 1000 个请求，使用 Meta Llama 2 7B，输入 1k token、输出 100 token。LLM 推理的生产成本约为每天 1 美元。

[![cloudflare pricing](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/cloudflare-workers-ai/pricing.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/cloudflare-workers-ai/pricing.png)

"我们很高兴这么快把这个集成落地。把 Cloudflare 全球 serverless GPU 网络的力量交到开发者手中，配上 Hugging Face 上最受欢迎的开源模型，将为我们全球社区开启大量激动人心的创新。"Cloudflare CTO John Graham-Cumming 表示。

## 工作原理

在 Cloudflare Workers AI 上使用 Hugging Face 模型非常简单。下面以最新上线的 Nous Research 模型 Hermes 2 Pro on Mistral 7B 为例，逐步说明使用方法。

所有可用模型见这个 [Cloudflare Collection](https://huggingface.co/collections/Cloudflare/hf-curated-models-available-on-workers-ai-66036e7ad5064318b3e45db6)。

*注意：你需要 [Cloudflare 账号](https://developers.cloudflare.com/fundamentals/setup/find-account-and-zone-ids/)和 [API Token](https://dash.cloudflare.com/profile/api-tokens)的访问权限。*

你会在所有受支持模型的页面上找到 Deploy on Cloudflare 选项，包括 Llama、Gemma 或 Mistral 等模型。

[![model card](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/cloudflare-workers-ai/model-card.jpg)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/cloudflare-workers-ai/model-card.jpg)

打开 "Deploy" 菜单，选择 "Cloudflare Workers AI"——这会打开一个界面，包含如何使用该模型和发送请求的说明。

*注意：如果你想用的模型没有 "Cloudflare Workers AI" 选项，说明目前尚不支持。我们正在与 Cloudflare 一起扩大模型可用范围。你可以向 [api-enterprise@huggingface.co](mailto:api-enterprise@huggingface.co) 发送你的需求。*

[![inference snippet](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/cloudflare-workers-ai/modal.jpg)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/cloudflare-workers-ai/modal.jpg)

该集成目前可通过两种方式使用的：[Workers AI REST API](https://developers.cloudflare.com/workers-ai/get-started/rest-api/)，或在 Worker 中直接使用 [Cloudflare AI SDK](https://developers.cloudflare.com/workers-ai/get-started/workers-wrangler/#1-create-a-worker-project)。选择你偏好的方式，把代码复制到你的环境中。使用 REST API 时，需要确保 `[ACCOUNT_ID](https://developers.cloudflare.com/fundamentals/setup/find-account-and-zone-ids/)` 和 `[API_TOKEN](https://dash.cloudflare.com/profile/api-tokens)` 变量已定义。

就这样！现在你可以开始向托管在 Cloudflare Workers AI 上的 Hugging Face 模型发送请求了。注意使用模型所要求的正确 prompt 和模板。
