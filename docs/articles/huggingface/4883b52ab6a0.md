TLDR：展望未来，我们的目标是让 Transformers 成为跨框架的枢纽：只要一个模型架构被 transformers 支持，你就可以预期它在整个生态其余部分都获得支持。

Transformers 创建于 2019 年，紧随 BERT 这一 Transformer 模型的发布。自那以来，我们持续致力于加入最先进架构：最初聚焦 NLP，随后扩展到音频与计算机视觉。如今，transformers 已然是 Python 生态中 LLM 与 VLM 的默认库。

Transformers 目前支持 300 多个模型架构，平均每周新增约 3 个架构。我们追求这些架构的及时发布：对最受追捧的架构（Llama、Qwen、GLM 等）实现 day-0 支持。

## 一个模型定义库

随着时间的推移，Transformers 已成为 ML 生态的核心组件，成为模型多样性方面最完整的工具箱之一；它被集成进所有流行的训练框架，如 Axolotl、Unsloth、DeepSpeed、FSDP、PyTorch-Lightning、TRL、Nanotron 等。

最近，我们与最流行的推理引擎（vLLM、SGLang、TGI……）紧密合作，让它们把 `transformers` 作为后端。价值是显著的：模型一旦加入 `transformers`，就能在这些推理引擎中可用，*同时享受每个引擎各自的强项*：推理优化、专用 kernel、动态批处理等。

举个例子，在 vLLM 中使用 `transformers` 后端是这样的：

```
from vllm import LLM

llm = LLM(model="new-transformers-model", model_impl="transformers")
```

新模型就这么简单地享受到了 vLLM 超高速、生产级的服务！

更多细节阅读 [vLLM 文档](https://blog.vllm.ai/2025-04-11/transformers-backend.html)。

我们也在与 [llama.cpp](https://github.com/ggml-org/llama.cpp) 和 [MLX](https://github.com/ml-explore/mlx) 非常紧密地合作，让 `transformers` 与这些建模库的实现之间具备良好的互操作性。例如，得益于社区的大量投入，现在在 `transformers` 中[加载 GGUF 文件](https://huggingface.co/docs/transformers/en/gguf)做进一步微调已经非常容易。反过来，transformers 模型也能轻松[转换为 GGUF 文件](https://github.com/ggml-org/llama.cpp/blob/master/convert_hf_to_gguf.py)供 llama.cpp 使用。

MLX 同理：transformers 的 safetensors 文件与 MLX 的模型直接兼容。

我们非常自豪 `transformers` 格式正被社区采纳，带来我们所有人受益的互操作性。用 Unsloth 训练一个模型，用 SGLang 部署它，再导出到 llama.cpp 在本地运行！我们的目标是持续支持社区走下去。

## 追求更简单的模型贡献方式

为了让社区更省事地把 transformers 用作模型定义的参考，我们努力显著降低模型贡献的门槛。这件事我们已经做了好几年，未来几周会大幅加速：

- 每个模型的 modeling 代码将进一步简化；为最重要的组件（KV cache、不同 Attention 函数、kernel 优化）提供清晰简洁的 API
- 我们会弃用冗余组件，让 API 只保留一条简单的使用路径：通过弃用慢分词器（slow tokenizers）鼓励高效的分词，同理改用快速的向量化视觉处理器。
- 我们将继续强化 *modular*（模块化）模型定义的工作，目标是新模型只需要极少的代码改动。6000 行的贡献、新模型改 20 个文件，这些都将成为过去。

## 这对你有什么影响？

### 作为模型用户，这意味着什么

作为模型用户，未来你会在你使用的工具之间看到更强的互操作性。

这不代表我们打算把你锁死在实验里用 `transformers`；恰恰相反，得益于这种建模标准化，你可以预期用于训练、推理与生产的工具能高效地协同工作。

### 作为模型创作者，这意味着什么

作为模型创作者，这意味着一次贡献就能让你的模型在所有集成了该建模实现的下游库中可用。这些年来我们反复看到：发布一个模型压力很大，而把它集成进所有重要库往往是巨大的时间黑洞。

通过以社区驱动的方式标准化模型实现，我们希望降低各领域跨库贡献的门槛。

我们坚信，这一重新聚焦的方向将有助于标准化一个常常面临碎片化风险的生态。我们很想听到你对团队所选方向的反馈，也欢迎对如何达成目标的改进建议。请来 Hub 上的 [transformers-community support 标签页](https://huggingface.co/spaces/transformers-community/support)找我们！
