## 引言

在医学影像领域，仿真一直是弥补数据缺口的重要手段。但在医疗机器人领域，仿真迄今往往太慢、过于孤立，或难以转化到真实系统。

NVIDIA Isaac for Healthcare 是一个面向 AI 医疗机器人的开发者框架，帮助医疗机器人开发者解决这些挑战——它提供横跨仿真与硬件的、集数据采集、训练、评估于一体的流水线。具体来说，Isaac for Healthcare v0.4 发布为医疗开发者提供了端到端的 [SO-ARM 入门工作流](https://github.com/isaac-for-healthcare/i4h-workflows/blob/main/workflows/so_arm_starter/README.md)和[自建手术室（bring your own operating room）教程](https://github.com/isaac-for-healthcare/i4h-workflows/blob/main/tutorials/assets/bring_your_own_or/README.md)。SO-ARM 入门工作流降低了 MedTech 开发者的门槛，让他们体验从仿真到训练再到部署的完整流程，立刻开始在真实硬件上构建和验证自主能力。

本文将带你走完这个入门工作流及其技术实现细节，帮你在比以往可想象的更短的时间内，打造一台手术助手机器人。

## SO-ARM 入门工作流：打造具身手术助手

SO-ARM 入门工作流带来探索手术辅助任务的新方式，为开发者提供一条完整的自主手术辅助端到端流水线：

- 用 LeRobot 在 SO-ARM 上采集真实世界数据与合成数据
- 微调 GR00t N1.5，在 IsaacLab 中评估，然后部署到硬件

这条工作流给开发者一个安全、可重复的环境，在进入手术室（Operating Room）之前先把辅助技能练好磨熟。

### 技术实现

该工作流实现了一条结合仿真与真实硬件的三阶段流水线：

- 数据采集：用 SO101 和 LeRobot 混合仿真遥操作与真实世界遥操作演示
- 模型训练：在双相机视觉的混合数据集上微调 GR00T N1.5
- 策略部署：在物理硬件上做实时推理，使用 RTI DDS 通信

值得注意的是，策略训练所用数据超过 93% 由仿真合成生成——印证了仿真在弥合机器人数据缺口上的实力。

### Sim2Real 混合训练方法

该工作流把仿真数据与真实数据混合，以应对根本矛盾：在真实世界训练机器人昂贵且有限，而纯仿真又常常无法捕捉真实世界的复杂性。方法上大约用 70 个仿真 episodes 覆盖多样场景和环境变化，再配 10-20 个真实 episodes 提供真实感和落地锚定。这种混合训练产出的策略，泛化能力超过任何单一领域。

### 硬件要求

工作流需要：

- GPU：支持 RT Core 的架构（Ampere 或更新），GR00T N1.5 推理需 ≥30GB 显存
- SO-ARM101 Follower（跟随臂）：带双相机视觉（手腕+房间）的 6 自由度精密操作臂。SO-ARM101 采用 WOWROBO 视觉组件，含一个手腕相机和 3D 打印转接件
- SO-ARM101 Leader（主臂）：用于专家演示采集的 6 自由度遥操作接口

值得注意的是，开发者可以在一台 [DGX Spark](https://www.nvidia.com/en-us/products/workstations/dgx-spark/) 上跑完全部仿真、训练和部署（物理 AI 本需 3 台计算机）。

### 数据采集实现

[![so100-healthcare-real-demo](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot-blog/nvidia-healthcare/lerobotxnvidia-healthcare-real-demo.gif)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot-blog/nvidia-healthcare/lerobotxnvidia-healthcare-real-demo.gif)

用 SO-ARM101 硬件或 LeRobot 支持的其他版本做真实世界数据采集：

```
python lerobot-record \ 
  --robot.type=so101_follower \ 
  --robot.port=<follower_port_id> \ 
  --robot.cameras="{wrist: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30}, room: {type: opencv, index_or_path: 2, width: 640, height: 480, fps: 30}}" \ 
  --robot.id=so101_follower_arm \ 
  --teleop.type=so101_leader \ 
  --teleop.port=<leader_port_id> \ 
  --teleop.id=so101_leader_arm \ 
  --dataset.repo_id=<user>/surgical_assistance/surgical_assistance \ 
  --dataset.num_episodes=15 \ 
  --dataset.single_task="Prepare and hand surgical instruments to surgeon" 
```

### 仿真遥操作控制

对没有实体 SO-ARM101 硬件的用户，工作流提供基于键盘的遥操作，关节控制如下：

- 关节 1（shoulder_pan）：Q（+）/ U（-）
- 关节 2（shoulder_lift）：W（+）/ I（-）
- 关节 3（elbow_flex）：E（+）/ O（-）
- 关节 4（wrist_flex）：A（+）/ J（-）
- 关节 5（wrist_roll）：S（+）/ K（-）
- 关节 6（gripper）：D（+）/ L（-）
- R 键：重置录制环境
- N 键：将 episode 标记为成功

### 模型训练流水线

采集完仿真与真实数据后，转换并合并数据集用于训练：

```
# Convert simulation data to LeRobot format
python -m training.hdf5_to_lerobot \ 
  --repo_id=surgical_assistance_dataset \ 
  --hdf5_path=/path/to/your/sim_dataset.hdf5 \ 
  --task_description="Autonomous surgical instrument handling and preparation" 

# Fine-tune GR00T N1.5 on mixed dataset 
python -m training.gr00t_n1_5.train \ 
  --dataset_path /path/to/your/surgical_assistance_dataset \ 
  --output_dir /path/to/surgical_checkpoints \ 
  --data_config so100_dualcam 
```

训练好的模型可以处理诸如 "Prepare the scalpel for the surgeon"（帮外科医生准备手术刀）或 "Hand me the forceps"（把镊子递给我）这样的自然语言指令，并执行相应的机器人动作。配合最新的 LeRobot 发布版（0.4.0），你将可以直接在 LeRobot 里原生微调 Gr00t N1.5！

## 端到端仿真采集-训练-评估流水线

仿真融入闭环时才最有威力：采集 → 训练 → 评估 → 部署。

v0.3 起，IsaacLab 支持这条完整流水线：

### 在仿真中生成合成数据

- 用键盘或硬件控制器遥操作机器人
- 捕获多相机观测、机器人状态与动作
- 创建含真实环境中无法安全采集的边角情况的多样化数据集

### 训练与评估策略

- 与 Isaac Lab 的 RL 框架深度集成，支持 PPO 训练
- 并行环境（同时数千个仿真）
- 内置轨迹分析与成功指标
- 跨多样场景的统计验证

### 将模型转换为 TensorRT

- 面向生产部署的自动优化
- 支持动态 shape 与多相机推理
- 验证实时性能的基准工具

这把从实验到部署的时间压缩下来，让 sim2real 成为日常开发中切实可用的一环。
