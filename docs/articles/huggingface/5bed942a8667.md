# 图机器学习入门

本文也提供[简体中文](https://huggingface.co/blog/zh/intro-graphml)版本。

在这篇博客文章中，我们介绍图机器学习（graph machine learning）的基础知识。

我们首先研究图是什么、为什么要用图，以及如何最好地表示它们。接着简要介绍人们如何在图上进行学习——从前神经网络方法（同时探讨图的特征），到通常所说的图神经网络（Graph Neural Networks）。最后，我们一窥面向图的 Transformer 的世界。

## 图（Graphs）

### 什么是图？

从本质上讲，图就是对由关系连接起来的若干条目的描述。

图的例子包括社交网络（Twitter、Mastodon，以及任何把论文和作者关联起来的引用网络）、分子、知识图谱（knowledge graphs，例如 UML 图、百科全书，以及任何页面间有超链接的网站）、以句法树形式表达的句子、任意 3D 网格，还有更多！因此，说图无处不在绝非夸张。

图的（或网络的）条目称为其*节点*（nodes，或顶点），而它们的连接称为其*边*（edges，或链接）。例如，在社交网络中，节点是用户，边是用户之间的关系；在分子中，节点是原子，边是它们之间的分子键。

- 若图的节点或边带有类型，则称其为**异质的**（heterogeneous）（例：条目既可以是论文也可以是作者的引用网络拥有带类型的节点，而关系带类型的 XML 图拥有带类型的边）。它无法仅通过拓扑来表征，还需要额外信息。本文聚焦于同质图（homogeneous graphs）。
- 图也可以是**有向的**（directed）（像关注者网络，A 关注 B 并不意味着 B 关注 A），或是**无向的**（undirected）（像分子，原子之间的关系是双向的）。边可以连接不同的节点，也可以把某个节点连到它自身（自边 self-edges），但并非所有节点都必须被连接。

如果你想利用自己的数据，就必须先考虑它最恰当的刻画方式（同质/异质、有向/无向，等等）。

### 图用来做什么？

我们来看一可以在图上完成的任务清单。

在**图级别**（graph level），主要任务有：

- 图生成（graph generation），用于药物发现中生成新的、合理的分子，
- 图演化（给定一张图，预测它会如何随时间演化），用于物理学中预测系统的演化，
- 图级别预测（以图为输入的分类或回归任务），例如预测分子的毒性。

在**节点级别**（node level），通常是节点属性预测。例如，[Alphafold](https://www.deepmind.com/blog/alphafold-a-solution-to-a-50-year-old-grand-challenge-in-biology) 使用节点属性预测，根据分子的整体图来预测原子的 3D 坐标，从而预测分子在 3D 空间中如何折叠——这是一个困难的生物化学问题。

在**边级别**（edge level），要么是边属性预测，要么是缺失边预测。边属性预测有助于药物副作用预测：给定一对药物来预测不良反应。缺失边预测则用于推荐系统，预测图中两个节点是否相关。

也可以在**子图级别**（sub-graph level）开展工作，如社区检测或子图属性预测。社交网络用社区检测来确定人们如何互联。子图属性预测则见于行程规划系统（如 [Google Maps](https://www.deepmind.com/blog/traffic-prediction-with-advanced-graph-neural-networks)），用于预测到达时间。

完成这些任务有两种途径。

当你想预测某张特定图的演化时，你工作在**直推式**（transductive）设定下，一切（训练、验证、测试）都在同一张图上完成。*如果你的设定如此，请务必小心！从单张图构造 train/eval/test 数据集并非易事。* 然而，大量工作是用不同的图来完成的（分别划分 train/eval/test），这称为**归纳式**（inductive）设定。

### 我们如何表示图？

处理图时常用的表示方式有两种：

- 作为其所有边的集合（可补充上其所有节点的集合）
- 或作为其所有节点之间的邻接矩阵（adjacency matrix）。邻接矩阵是一个方阵（节点规模 * 节点规模），标明哪些节点与哪些节点直接相连（当 (n_i) 与 (n_j) 相连时 (A_{ij} = 1)，否则为 0）。*注意：大多数图并非稠密连接，因此其邻接矩阵是稀疏的，这可能使计算更困难。*

然而，尽管这些表示看起来熟悉，千万别被表象迷惑！

图与机器学习中的典型对象非常不同，因为它们的拓扑结构比"一个序列"（如文本和音频）或"一个有序网格"（如图像和视频）要复杂得多：即使可以表示为列表或矩阵，它们的表示也不应被视作有序对象！

这是什么意思？如果你有一句话并打乱其中的词，你会造出另一个新句子。如果你有一张图并重排它的列，你会造出一张新图像。

左边是 Hugging Face 的 logo——右边是打乱后的 Hugging Face logo，这是一张截然不同的新图像。

但对图而言并非如此：如果你打乱它的边列表，或打乱邻接矩阵的列，它仍然是同一张图。（我们在下文更正式地解释这一点，参见置换不变性 permutation invariance。）

左边是一张小图（节点为黄色，边为橙色）。中间是它的邻接矩阵，行列按节点字母顺序排列：从节点 A 那一行（第一行）可以看出，它与 E 和 C 相连。右边是打乱后的邻接矩阵（列不再按字母排序），它同样是该图的一个合法表示：A 仍然与 E 和 C 相连。

## 通过机器学习表示图

在图上做机器学习的常规流程是：先为你的目标条目（节点、边，或整张图，取决于你的任务）生成有意义的表示，再用这些表示训练一个面向目标任务的预测器。我们想要（就像其他模态一样）对对象的数学表示施加约束，使得相似的对象在数学上也彼此接近。不过在图机器学习中，这种"相似"很难严格定义：例如，两个节点是在拥有相同标签时更相似，还是拥有相同邻居时更相似？

注意：*在下文各节中，我们将聚焦于生成节点表示。一旦有了节点级表示，就可以得到边级或图级的信息。边级信息可以拼接节点对的表示，或做点积。图级信息可以对所有节点级表示拼接而成的张量做全局池化（平均、求和等），但这会在图上平滑并丢失信息——递归的层次化池化或许更合理；也可以添加一个虚拟节点（virtual node），让它与图中所有其他节点相连，并将其表示用作整张图的表示。*

### 前神经网络方法

#### 直接使用工程化特征

在神经网络出现之前，图及其目标条目可以按任务以特征组合的方式表示。如今这些特征仍用于数据增强和[半监督学习](https://arxiv.org/abs/2202.08871)，尽管也存在[更复杂的特征生成方法](https://arxiv.org/abs/2208.11973)；根据你的任务，找到如何把这些特征最好地提供给网络可能至关重要。

**节点级**特征可以提供关于重要性的信息（这个节点对图有多重要？）和/或基于结构的信息（节点周围的图是什么形状？），并且可以组合使用。

节点**中心性**（centrality）衡量节点在图中的重要性。它可以通过递归累加每个邻居的中心性直到收敛来计算，也可以通过节点间最短距离度量等方式计算。节点的**度**（degree）是它直接拥有的邻居数量。**聚类系数**（clustering coefficient）衡量节点的邻居之间有多互联。**graphlets 度向量**统计以某个给定节点为根的不同 graphlets 数量——graphlets 是用给定数量的互联节点所能构造的所有迷你图（用三个互联节点，你可以得到一条含两条边的线，或一个含三条边的三角形）。

2 到 5 个节点的 graphlets（Pržulj, 2007）

**边级**特征用更细致的连通信息来补充表示，包括两个节点之间的**最短距离**、它们的**共同邻居**，以及它们的 **Katz 指数**（即两个节点之间长度不超过某个值的可行走的数量——可直接由邻接矩阵计算）。

**图级特征**包含关于图相似性与特异性的抽象信息。整体的 **graphlet 计数**虽然计算代价高昂，却提供了子图形状的信息。**核方法**（Kernel methods）通过各种"节点袋"（bag of nodes）方法（类似于词袋）来衡量图之间的相似度。

### 基于游走的方法

[**基于游走的方法**](https://en.wikipedia.org/wiki/Random_walk)利用从节点 i 随机游走到节点 j 的概率来定义相似度度量；这些方法同时融合了局部与全局信息。例如 [**Node2Vec**](https://snap.stanford.edu/node2vec/) 模拟图上节点间的随机游走，然后用 skip-gram 处理这些游走，[就像我们对句子中的词所做的那样](https://arxiv.org/abs/1301.3781)，以计算 embedding。这些方法还可用于[加速](https://arxiv.org/abs/1208.3071)[**PageRank 方法**](http://infolab.stanford.edu/pub/papers/google.pdf)的计算——后者会为每个节点分配一个重要性得分（基于它与其他节点的连通性，例如以随机游走访问它的频率来评估）。

然而，这些方法有其局限：它们无法为新节点得到 embedding，无法精细地捕捉节点之间的结构相似性，也无法使用附加特征。

## 图神经网络

神经网络能够泛化到未见过的数据。考虑到我们前面提到的表示约束，要在图上工作，一个合适的神经网络应该具备什么性质？

它应该：

- 具有置换不变性（permutation invariant）：公式：f(P(G))=f(G)f(P(G))=f(G)f(P(G))=f(G)，其中 f 为网络，P 为置换函数，G 为图。解释：一张图及其置换经过网络后应得到相同的表示
- 具有置换等变性（permutation equivariant）：公式：P(f(G))=f(P(G))P(f(G))=f(P(G))P(f(G))=f(P(G))，其中 f 为网络，P 为置换函数，G 为图。解释：先对节点置换再送入网络，应等价于对其表示进行置换

典型的神经网络，如 RNN 或 CNN，并不具备置换不变性。因此人们引入了一种新架构——[图神经网络（Graph Neural Network）](https://ieeexplore.ieee.org/abstract/document/1517930)（最初是以状态机的形式提出的）。

GNN 由层层堆叠而成。一个 GNN 层把一个节点表示为其邻居与自身在前一层表示的组合（**聚合** aggregation），再加上通常的非线性激活来引入非线性——邻居信息通过**消息传递**（message passing）流动。

**与其他模型的比较**：CNN 可以看作一个邻居规模固定（通过滑动窗口）且带顺序的 GNN（它不具备置换等变性）。而不带位置 embedding 的 [Transformer](https://arxiv.org/abs/1706.03762v3) 可以看作一个作用在全连接输入图上的 GNN。

### 聚合与消息传递

从邻居节点聚合消息的方式有很多种，例如求和、取平均。沿着这一思路的著名工作包括：

- [图卷积网络（Graph Convolutional Networks）](https://tkipf.github.io/graph-convolutional-networks/)对节点的归一化邻居表示取平均（实际上大多数 GNN 都是 GCN）；
- [图注意力网络（Graph Attention Networks）](https://petar-v.com/GAT/)根据重要性学习为不同邻居加权（类似 Transformer）；
- [GraphSAGE](https://snap.stanford.edu/graphsage/)在不同跳数上采样邻居，然后通过多步 max pooling 聚合它们的信息。
- [图同构网络（Graph Isomorphism Networks）](https://arxiv.org/pdf/1810.00826v3.pdf)通过对邻居节点表示求和后施加一个 MLP 来聚合表示。

**选择聚合方式**：某些聚合技术（尤其是 mean/max pooling）在为"邻域相似但不同的节点"生成可精细区分的表示时会遇到失败情形（例如，通过 mean pooling，一个含 4 个节点、表示为 1,1,-1,-1、平均为 0 的邻域，无法与一个只含 3 个节点、表示为 -1, 0, 1 的邻域区分开）。

### GNN 的层数与过平滑问题

每新增一层，节点表示所涵盖的节点就越多。

一个节点经过第一层，是其直接邻居的聚合。经过第二层，它仍是直接邻居的聚合，但这一次邻居的表示已包含了邻居自己的（第一层）邻居。经过 n 层后，所有节点的表示成为其距离为 n 的所有邻居的聚合；因此，如果图的直径小于 n，就变成整张图的聚合！

如果你的网络层数过多，就有每个节点都变成整张图聚合的风险（并且各节点的表示会收敛为同一个）。这就是所谓的**过平滑问题**（the oversmoothing problem）。

可以通过以下方法缓解：

- 调整 GNN 规模，使层数足够小，不至于把每个节点近似成整个网络（先分析图的直径与形状）
- 增加每层的复杂度
- 在消息处理中加入非消息传递层（如简单的 MLP）
- 加入 skip-connection（跳跃连接）。

过平滑问题是图机器学习中的一个重要研究方向，因为它阻碍了 GNN 的规模化——而 Transformer 已被证明在其他模态中可以良好地扩展规模。

## 图 Transformer

不带位置编码层的 Transformer 具有置换不变性，而 Transformer 又以扩展性好著称，所以近来人们开始探索把 Transformer 适配到图上（[综述](https://github.com/ChandlerBang/awesome-graph-transformer)）。大多数方法聚焦于表示图的最佳方式——寻找最佳特征、表示位置信息的最佳方式，并修改注意力机制以适配这些新数据。

以下是一些有趣的方法，它们在撰写本文时最难用的基准之一——[斯坦福的 Open Graph Benchmark](https://ogb.stanford.edu/)——上取得了 state-of-the-art 或接近 SOTA 的结果：

- [*Graph Transformer for Graph-to-Sequence Learning*](https://arxiv.org/abs/1911.07470)（Cai 和 Lam，2020）提出了一个图编码器，将节点表示为其 embedding 与位置 embedding 的拼接，将节点关系表示为它们之间的最短路径，并把两者结合进一个关系增强的自注意力中。
- [*Rethinking Graph Transformers with Spectral Attention*](https://arxiv.org/abs/2106.03893)（Kreuzer 等，2021）提出了谱注意力网络（Spectral Attention Networks，SANs）。它将节点特征与学习到的位置编码（由 Laplacian 的特征向量/特征值计算）相结合，用作注意力中的 key 和 query，而注意力的 value 则为边特征。
- [*GRPE: Relative Positional Encoding for Graph Transformer*](https://arxiv.org/abs/2201.12787)（Park 等，2021）提出了图相对位置编码 Transformer。它通过将图级位置编码与节点信息相结合、边级位置编码与节点信息相结合来表示一张图，并在注意力中融合两者。
- [*Global Self-Attention as a Replacement for Graph Convolution*](https://arxiv.org/abs/2108.03348)（Hussain 等，2021）提出了边增强 Transformer（Edge Augmented Transformer）。该架构分别对节点和边做 embedding，并在一个改造过的注意力中聚合它们。
- [*Do Transformers Really Perform Badly for Graph Representation*](https://arxiv.org/abs/2106.05234)（Ying 等，2021）提出了微软的 [**Graphormer**](https://www.microsoft.com/en-us/research/project/graphormer/)，它在推出时曾在 OGB 上夺得第一。该架构在注意力中用节点特征作为 query/key/value，并在注意力机制中把它们的表示与中心性、空间、边编码的组合相加。

最新的方法是 [*Pure Transformers are Powerful Graph Learners*](https://arxiv.org/abs/2207.02505)（Kim 等，2022），它提出了 **TokenGT**。该方法把输入图表示为节点与边 embedding 的一个序列（以正交归一的节点标识符和可训练的类型标识符加以增强），不使用位置 embedding，并把这个序列作为输入喂给 Transformer。它极为简单，却十分巧妙！

另有稍显不同的工作 [*Recipe for a General, Powerful, Scalable Graph Transformer*](https://arxiv.org/abs/2205.12454)（Rampášek 等，2022），它提出的不是一个模型，而是一个名为 **GraphGPS** 的框架。它能把消息传递网络与线性（长程）Transformer 相结合，轻松构建混合网络。该框架还包含若干工具，用于计算位置与结构编码（节点、图、边级）、特征增强、随机游走等。

用 Transformer 处理图仍是一个方兴未艾的领域，但它前景可观，因为它有望缓解 GNN 的若干局限，例如扩展至更大/更稠密的图，或在不引入过平滑的情况下增大模型规模。
