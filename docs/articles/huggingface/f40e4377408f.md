# 在 Hugging Face Spaces 上可视化蛋白质

在这篇文章中，我们将看看如何在 Hugging Face Spaces 上可视化蛋白质。

**2024 年 5 月更新**

虽然下面描述的方法仍然有效，但你大概率想省点时间，改用 [Molecule3D Gradio Custom Component](https://www.gradio.app/custom-components/gallery?id=simonduerr%2Fgradio_molecule3d)。这个组件允许用户实时修改蛋白质可视化，也能更容易地设置默认视图。直接这样安装：

```
pip install gradio_molecule3d
```

```
from gradio_molecule3d import Molecule3D

reps =    [
    {
      "model": 0,
      "chain": "",
      "resname": "",
      "style": "stick",
      "color": "whiteCarbon",
      "residue_range": "",
      "around": 0,
      "byres": False,
    }
  ]

with gr.Blocks() as demo:
    Molecule3D(reps=reps)
```

## 动机 🤗

蛋白质对我们生活影响巨大——从药物到洗衣粉。针对蛋白质的机器学习是一个快速发展的领域，帮助我们设计新奇有趣的蛋白质。蛋白质是复杂的三维对象，通常由一系列称为氨基酸的构件组成，这些氨基酸在三维空间中排布，赋予蛋白质其功能。出于机器学习目的，蛋白质可以被表示为坐标、图、或用于蛋白质语言模型的 1D 字母序列。

著名的蛋白质 ML 模型是 AlphaFold2，它利用相似蛋白质多重序列比对和结构模块来预测蛋白质序列的结构。

自 AlphaFold2 首秀以来，涌现了更多同类模型，如 OmegaFold、OpenFold 等（更多见这个[列表](https://github.com/yangkky/Machine-learning-for-proteins)或这个[列表](https://github.com/sacdallago/folding_tools)）。

## 眼见为实

蛋白质结构是我们理解蛋白质功能不可或缺的一环。如今已有若干工具可以在浏览器中直接可视化蛋白质，如 [mol\*](https://huggingface.co/blog/molstar.org) 或 [3dmol.js](https://3dmol.csb.pitt.edu/)。在这篇文章中，你将学习如何用 3Dmol.js 和 HTML block 把结构可视化集成进你的 Hugging Face Space。

## 前置条件

请确保已安装 `gradio` Python 包（见[安装指南](https://huggingface.co/getting_started)），并具备 Javascript/JQuery 基础知识。

## 看看代码

先看看如何构建我们界面的最小可运行 demo，然后再深入 3Dmol.js 的配置。

我们将构建一个简单的 demo 应用，接受 4 位 PDB 编码或一个 PDB 文件。应用会从 RCSB 蛋白质数据库（RCSB Protein Databank）获取对应 pdb 文件并展示，或使用上传的文件展示。

```
import gradio as gr

def update(inp, file):
    # in this simple example we just retrieve the pdb file using its identifier from the RCSB or display the uploaded file
    pdb_path = get_pdb(inp, file)
    return molecule(pdb_path) # this returns an iframe with our viewer
    

demo = gr.Blocks()

with demo:
    gr.Markdown("# PDB viewer using 3Dmol.js")
    with gr.Row():
        with gr.Box():
            inp = gr.Textbox(
                placeholder="PDB Code or upload file below", label="Input structure"
            )
            file = gr.File(file_count="single")
            btn = gr.Button("View structure")
        mol = gr.HTML()
    btn.click(fn=update, inputs=[inp, file], outputs=mol)
demo.launch()
```

`update`：这是处理蛋白质并返回带查看器 `iframe` 的函数。

我们的 `get_pdb` 函数也很简单：

```
import os
def get_pdb(pdb_code="", filepath=""):
    if pdb_code is None or len(pdb_code) != 4:
        try:
            return filepath.name
        except AttributeError as e:
            return None
    else:
        os.system(f"wget -qnc https://files.rcsb.org/view/{pdb_code}.pdb")
        return f"{pdb_code}.pdb"
```

那么，Gradio 没有把 3Dmol 直接作为 block 提供，如何可视化蛋白质呢？我们用 `iframe` 实现。

返回 `iframe` 的 `molecule` 函数概念上如下：

```
def molecule(input_pdb):
    mol = read_mol(input_pdb)
    # setup HTML document
    x = ("""<!DOCTYPE html><html> [..] </html>""") # do not use ' in this input
    return f"""<iframe  [..] srcdoc='{x}'></iframe>
```

这样搭建有点笨拙，但由于现代浏览器的安全规则，这是必要的。

3Dmol.js 的配置相当容易，文档提供了[一些示例](https://3dmol.csb.pitt.edu/)。

我们返回文档的 `head` 需要加载 3Dmol.js（它同时也会加载 JQuery）。

```
<head>    
    <meta http-equiv="content-type" content="text/html; charset=UTF-8" />
    <style>
    .mol-container {
    width: 100%;
    height: 700px;
    position: relative;
    }
    .mol-container select{
        background-image:None;
    }
    </style>
    <script src="https://cdnjs.cloudflare.com/ajax/libs/jquery/3.6.3/jquery.min.js" integrity="sha512-STof4xm1wgkfm7heWqFJVn58Hm3EtS31XFaagaa8VMReCXAkQnJZ+jEy8PCC/iT18dFy95WcExNHFTqLyp72eQ==" crossorigin="anonymous" referrerpolicy="no-referrer"></script>
    <script src="https://3Dmol.csb.pitt.edu/build/3Dmol-min.js"></script>
</head>
```

`.mol-container` 的样式可用来修改分子查看器的尺寸。

`body` 如下：

```
<body>
    <div id="container" class="mol-container"></div>
    <script>
        let pdb = mol // mol contains PDB file content, check the hf.space/simonduerr/3dmol.js for full python code
        $(document).ready(function () {
            let element = $("#container");
            let config = { backgroundColor: "white" };
            let viewer = $3Dmol.createViewer(element, config);
            viewer.addModel(pdb, "pdb");
            viewer.getModel(0).setStyle({}, { cartoon: { colorscheme:"whiteCarbon" } });
            viewer.zoomTo();
            viewer.render();
            viewer.zoom(0.8, 2000);
            })
    </script>
</body>
```

我们用模板字面量（反引号）把 pdb 文件直接存进 html 文档，然后用 3dmol.js 输出。

就这样！现在你可以把你喜爱的蛋白质 ML 模型接进一个好用有趣的 gradio 应用，直接可视化预测或重新设计的结构。如果你在预测结构的性质（例如每个氨基酸结合配体的可能性），3Dmol.js 还支持基于原子属性使用自定义 `colorfunc`。

完整代码可查看 3Dmol.js space 的[源代码](https://huggingface.co/spaces/simonduerr/3dmol.js/blob/main/app.py)。

生产级示例可看 [ProteinMPNN](https://hf.space/simonduerr/ProteinMPNN) space：用户上传一个主链，逆向折叠模型 ProteinMPNN 预测新的最优序列，然后可以对所有预测序列运行 AlphaFold2，验证它们是否采用输入的原始主链。那些按 AlphaFold2 预测以高 pLDDT 分数采用相同结构的成功重设计，应当拿去实验室验证。
