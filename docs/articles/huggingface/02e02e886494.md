# 神经超采样（NSS）来了！

[![image/png](https://cdn-uploads.huggingface.co/production/uploads/6682a9252200824e2ddc667f/mKBLpNTALoOAsoj8O3opP.png)](https://cdn-uploads.huggingface.co/production/uploads/6682a9252200824e2ddc667f/mKBLpNTALoOAsoj8O3opP.png)

Arm 推出的新一代 AI 超分辨率（upscaling）解决方案——神经超采样（Neural Super Sampling, NSS）现已发布，图形与游戏开发者今天即可开始尝试！

## 由机器学习提升画质

NSS 专为在未来移动设备上实现实时性能而设计，这些设备搭载 [Arm Neural Technology](https://newsroom.arm.com/news/arm-announces-arm-neural-technology)。不过，延迟取决于实现因素，例如 GPU 配置、分辨率和使用场景。在下方的 Enchanted Castle 演示视频中，NSS 将 GPU 工作负载降低了 50%。在持续性能配置下，模型以 540p 渲染并在仅 4ms 内升采样到 1080p。

您的浏览器不支持 video 标签。

## 了解我们的 NSS 模型

神经超采样（NSS）是 Arm 开发的一个用于实时时序超采样的参数预测模型，针对移动 GPU 上的 Neural Accelerator（NX）执行进行了优化。它通过从低分辨率时序输入重建高质量的输出帧，以更低计算成本实现高分辨率渲染。NSS 尤其适合移动游戏、XR 及其他受功耗约束的图形场景。

立即上手我们的 [NSS 模型](https://huggingface.co/Arm/neural-super-sampling)。

## 我们如何训练模型

请查看 [Neural Graphics Dataset](https://huggingface.co/datasets/Arm/neural-graphics-dataset)：一整套参考图像和图像序列，以及训练、验证和测试神经超采样算法所需的运动、深度及其他数据。[![](https://huggingface.co/datasets/Arm/neural-graphics-dataset/resolve/main/bistro-output-colour-gamma.jpg)](https://huggingface.co/datasets/Arm/neural-graphics-dataset/resolve/main/bistro-output-colour-gamma.jpg)

当前版本的数据集仅包含有限的数据，用于演示 NSS 模型的开发流程。虽然该流程尚未提供可用于完整模型（再）训练的全面数据集，但请持续关注 [Neural Graphics Model Gym](https://github.com/arm/neural-graphics-model-gym) 的后续发布——Arm 将在其中提供用于采集和转换内容以供模型训练与再训练使用的工具。

## 今天就开始用 NSS 做实验！

NSS 已通过两个插件集成进 Unreal Engine，即 [面向 Unreal® Engine 的 NSS 插件](https://github.com/arm/neural-graphics-for-unreal/)和[面向 Vulkan ML 扩展的 Unreal® NNE 插件](https://github.com/arm/ml-extensions-for-vulkan-unreal-plugin/)。

关于在 Unreal® Engine 中使用 NSS 的分步说明，请查看我们的学习路径：

- **面向 Vulkan® ML 扩展快速上手**：[ML extensions for Vulkan® 快速上手指南](https://learn.arm.com/learning-paths/mobile-graphics-and-gaming/vulkan-ml-sample/)
- **Unreal 快速上手**：[NSS 快速上手指南](https://learn.arm.com/learning-paths/mobile-graphics-and-gaming/nss-unreal/)，用于将 NSS 集成到 Unreal Engine
