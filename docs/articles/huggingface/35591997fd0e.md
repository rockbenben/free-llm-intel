# 用 Gradio 2.0 使用与混搭 Hugging Face 模型

> 本文转载自 Gradio 博客。

**[Hugging Face Model Hub](https://huggingface.co/models)** 上有超过 10,000 个由用户提交的机器学习模型。你能找到各种各样的自然语言处理模型，例如在芬兰语和英语之间翻译，或识别中文语音。最近，Hub 还扩展到了图像分类和音频处理模型。

Hugging Face 一直致力于让模型易于访问、易于使用。`transformers` 库让你能用几行代码加载一个模型。模型加载后，便可通过编程对新数据做预测。*但使用机器学习模型的不只是程序员！* 机器学习中一个日益常见的场景是**向跨学科团队演示模型**，或让**非程序员使用模型**（以帮助发现偏见、失败点等）。

**[Gradio 库](https://gradio.app/)** 让机器学习开发者非常轻松地基于模型创建演示和 GUI，并以如同分享 Google Docs 链接一样简单的方式免费与合作者共享。现在，我们很高兴地宣布，Gradio 2.0 库让你***仅需 1 行代码*，就能通过 GUI *加载并使用几乎任何 Hugging Face 模型***。这是一个例子：

[![GIF of Gradio 2.0](https://huggingface.co/blog/assets/22_gradio/recording-20.gif)](https://huggingface.co/blog/assets/22_gradio/recording-20.gif)

默认情况下，它会使用 HuggingFace 托管的 Inference API（你可以提供自己的 API key，也可以无需 API key 使用公开访问），或者你也可以运行 `pip install transformers`，在本地运行模型计算。

想要自定义演示吗？你可以通过传入自己的参数来覆盖 [Interface 类](https://gradio.app/docs)的任何默认参数：

[![GIF of Gradio 2.0](https://huggingface.co/blog/assets/22_gradio/recording-21.gif)](https://huggingface.co/blog/assets/22_gradio/recording-21.gif)

***等等，还有更多！*** Model Hub 上已有 10,000 个模型，我们把模型看作不仅仅是独立的代码单元，而是可以**组合与混搭**的乐高积木，用来构建更复杂的应用和演示。

例如，Gradio 允许你*并行*加载多个模型（想象一下，你想对比 Hugging Face 上 4 个不同的文本生成模型，看看哪个最适合你的用例）：

[![GIF of Gradio 2.0](https://huggingface.co/blog/assets/22_gradio/recording-22.gif)](https://huggingface.co/blog/assets/22_gradio/recording-22.gif)

或者把模型*串联*起来。这让构建基于多个机器学习模型的复杂应用变得容易。例如，这里我们仅用 3 行代码就构建了一个既能翻译又能摘要芬兰语新闻文章的应用：

[![GIF of Gradio 2.0](https://huggingface.co/blog/assets/22_gradio/recording-24.gif)](https://huggingface.co/blog/assets/22_gradio/recording-24.gif)

你甚至可以把多个*串联*的模型相互*并行*对比（这个就留给你自己动手尝试吧！）。想体验以上任何功能，只需安装 Gradio（`pip install gradio`），再挑选一个你想试用的 Hugging Face 模型。用 Gradio 和 Hugging Face 开始构建吧 🧱⛏️
