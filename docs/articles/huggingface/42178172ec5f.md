# Hugging Face 与 Graphcore 合作打造 IPU 优化的 Transformers

> 在 2021 年 AI 硬件峰会上，Hugging Face 宣布启动新的硬件合作伙伴计划（Hardware Partner Program），包括设备优化模型和软件集成。在这里，Graphcore——智能处理单元（Intelligence Processing Unit, IPU）的创造者、该计划的创始成员——解释了其与 Hugging Face 的合作将如何帮助开发者轻松加速最先进 Transformer 模型的使用。

Graphcore 与 Hugging Face 是两家有着共同目标的公司——让创新者更容易驾驭机器智能的力量。

Hugging Face 的硬件合作伙伴计划将让使用 Graphcore 系统的开发者能够以生产规模部署为我们的智能处理单元（IPU）优化的最先进 Transformer 模型，且编码复杂度极低。

## 什么是智能处理单元？

IPU 是为 Graphcore 的 IPU-POD 数据中心计算系统提供动力的处理器。这种新型处理器专为满足 AI 与机器学习的特定计算需求而设计。细粒度并行、低精度运算以及处理稀疏性的能力等特性都被写入了我们的芯片。

Graphcore 的 IPU 没有采用 GPU 那样的 SIMD/SIMT 架构，而是使用了大规模并行的 MIMD 架构，将超高带宽内存紧邻处理器核放置，直接位于芯片裸片之上。

这一设计带来了高性能和新层次的效率，无论是运行当今最流行的模型（如 BERT 和 EfficientNet），还是探索下一代 AI 应用。

软件在释放 IPU 能力方面起着至关重要的作用。我们的 Poplar SDK 自 Graphcore 创立之初就与处理器协同设计。如今它与标准机器学习框架（包括 PyTorch 和 TensorFlow）完整集成，也与 Docker、Kubernetes 等编排与部署工具集成。

让 Poplar 兼容这些广泛使用的第三方系统，使开发者能够轻松地把模型从其他计算平台移植过来，并开始利用 IPU 先进的 AI 能力。

## 面向生产优化 Transformers

Transformers 彻底改变了（双关语有意为之）AI 领域。像 BERT 这样的模型被 Graphcore 客户广泛用于 NLP 及更多领域的海量应用。这些多才多艺的模型可以完成特征抽取、文本生成、情感分析、翻译等诸多功能。

Hugging Face 已经承载了数百个 Transformers，从法语的 CamemBERT 到把 NLP 经验应用到计算机视觉的 ViT。Transformers 库平均每月被下载 200 万次，需求持续增长。

凭借超过 50,000 名开发者的用户群——Hugging Face 见证了一个开源项目有史以来最快的采用速度。

如今，通过硬件合作伙伴计划，Hugging Face 正在把顶级的 Transformer 工具集与当今最先进的 AI 硬件连接起来。

借助全新的开源库与工具包 Optimum，开发者将能够访问由 Hugging Face 认证的硬件优化模型。

这些模型由 Graphcore 与 Hugging Face 合作开发，首批 IPU 优化模型将于今年晚些时候出现在 Optimum 上。最终，它们将覆盖从视觉、语音到翻译和文本生成的广泛应用。

Hugging Face CEO Clément Delangue 表示："开发者都想要最新的硬件——比如 Graphcore IPU，但他们总要纠结是否得学新的代码或流程。有了 Optimum 和 Hugging Face 硬件计划，这根本不成问题。它就是即插即用。"

## 最先进模型遇上最先进硬件

在宣布与 Hugging Face 合作之前，我们就已经通过一个特殊的、Graphcore 优化的、使用 PyTorch 的 Hugging Face BERT 实现，展示了 IPU 加速最先进 Transformer 模型的能力。

该示例的完整细节见 Graphcore 博客[《在 IPU 上训练 BERT-Large 详解》](https://www.graphcore.ai/posts/bert-large-training-on-the-ipu-explained)。

BERT 在 Graphcore 系统上相对于在相当 GPU 系统上的戏剧性基准结果，对于目前在非 IPU 上运行这一流行 NLP 模型的人来说无疑是一个诱人的前景。

这种加速对机器学习研究者和工程师而言可能是颠覆性的，为他们赢回宝贵的训练时间，并让他们在开发新模型时能够进行更多次迭代。

如今，通过 Hugging Face 平台——以其优雅简洁和卓越的模型丰富度——Graphcore 用户将能够释放这样的性能优势。

Hugging Face 与 Graphcore 携手，正帮助更多人驾驭 Transformers 的力量，加速 AI 革命。
