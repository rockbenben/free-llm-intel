# OlmoEarth 嵌入向量发布：从 OlmoEarth Studio 导出自定义嵌入用于下游分析

📄 技术报告：[https://allenai.org/papers/olmoearth](https://allenai.org/papers/olmoearth) | 📊 文档：[https://docs.olmoearth.allenai.org/embeddings](https://docs.olmoearth.allenai.org/embeddings) | 💻 了解更多 OlmoEarth：[https://allenai.org/olmoearth](https://allenai.org/olmoearth)

[![OlmoEarth embeddings concept illustration: a grid of numeric embedding values connected by lines to points on a globe](https://www.datocms-assets.com/64837/1776965297-olmoearth-embeddings-blog-google-docs-image-1.png)](https://www.datocms-assets.com/64837/1776965297-olmoearth-embeddings-blog-google-docs-image-1.png)

我们用于构建对地观测模型的平台 [OlmoEarth Studio](https://olmoearth.allenai.org/) 现在支持计算并导出**嵌入向量（embedding vectors）**——由我们的开源 OlmoEarth 基础模型生成的、对地观测数据的紧凑数值表示。[源码](https://github.com/allenai/olmoearth_pretrain)和[模型权重](https://huggingface.co/collections/allenai/olmoearth)与[研究论文](https://allenai.org/papers/olmoearth)一并对公众开放，社区可以完整检视这些嵌入是如何生成的。

嵌入向量是借力 OlmoEarth 的一条快速、经济的入口：它们支持广泛的下游任务，从相似度搜索到分割再到无监督探索。地表特征相似的位置会得到相似的向量；差异大的位置则相距很远。OlmoEarth 嵌入在我们自己的基准测试和[独立评估](https://arxiv.org/abs/2603.02080)中都表现出色。导出的云优化 GeoTIFF（COG）轻量且易于共享。通过 Studio UI 或 API 选择你的关注区域、时间范围、编码器变体、分辨率和影像源，就能拿到一份可随意使用的 COG。如果你的应用需要更高性能，Studio 还支持[监督微调（SFT）](https://docs.olmoearth.allenai.org/model-fine-tuning)。

自定义计算的嵌入现已向 OlmoEarth Studio 用户开放。有意获取访问权限请[联系我们](https://allenai.org/olmoearth)。使用公开可用的 OlmoEarth 模型自行计算嵌入的说明见[这里](https://github.com/allenai/rslearn/blob/master/docs/examples/OlmoEarthEmbeddings.md)。

## 在 Studio 中计算嵌入

[![World map of OlmoEarth embeddings with each land pixel colored by its k-means cluster, revealing coherent biome and land-cover structure across continents](https://www.datocms-assets.com/64837/1776965912-olmoearth-embeddings-blog-google-docs-image-2-1.png)](https://www.datocms-assets.com/64837/1776965912-olmoearth-embeddings-blog-google-docs-image-2-1.png)

*基于季节性 Sentinel-2 影像、覆盖 110 万样本的 OlmoEarth 嵌入全局结构。颜色表示 PCA 降维后嵌入空间中的 15 个 k-means 簇。*

计算嵌入遵循 Studio 中任何其它预测相同的流程：先配置模型并运行，然后下载结果。有几个参数可用于定制输出：

- **关注区域：** 绘制或上传任意多边形；Studio 负责影像获取和切片。
- **时间跨度：** 1-12 个月度周期。
- **编码器变体：** Nano（128 维，140 万参数）、Tiny（192 维，620 万参数）或 Base（768 维，8900 万参数）。
- **空间分辨率：** 每像素 10 米、20 米、40 米或 80 米。
- **影像源：** Sentinel-2 L2A、Sentinel-1 RTC，或两者兼用。

[![Four false-color renderings of the same embedding raster side by side, each mapping the embedding bands to color differently](https://www.datocms-assets.com/64837/1776966011-olmoearth-embeddings-blog-google-docs-image-3.png)](https://www.datocms-assets.com/64837/1776966011-olmoearth-embeddings-blog-google-docs-image-3.png)

*同一嵌入栅格应用不同可视化选项的效果。*

Studio 交付的 COG 每个嵌入维度一个波段。向量以**有符号 8 位整数**（int8）存储，取值范围 -127 到 +127，-128 保留为 nodata。要恢复浮点向量，参见 olmoearth_pretrain 中的 [dequantize_embeddings](https://github.com/allenai/olmoearth_pretrain/blob/main/olmoearth_pretrain/evals/embedding_transforms.py)。

由于一切都是按需计算、而非取自预计算的全局存档，你的嵌入恰好反映你关心的条件。你可以生成月度嵌入来捕捉季节性动态，而不只是年度快照。

## 你能用 OlmoEarth 嵌入做什么

下面的示例全部使用 40 米分辨率、Sentinel-2 L2A 合成影像（多数示例为年度合成，变化检测为月度）的 OlmoEarth-v1-Tiny（192 维）嵌入。Tiny 是轻量编码器但性能依然很强；在你自己的应用中，可以换成更大的变体，代价是更多的计算和存储。

### 相似度搜索：找到"更像这个"的地方

选一个查询像素，抽取它的嵌入，然后与所有其他像素计算余弦相似度。结果是一张热力图，显示整个景观中与查询像素最像和最不像的区域。

[![Sentinel-2 imagery of farmland around Merced, California with the query pixel boxed in blue, beside the matching cosine-similarity heatmap in which the urban core and road corridors glow yellow against dark cropland](https://www.datocms-assets.com/64837/1776966099-olmoearth-embeddings-blog-google-docs-image-4-2.png)](https://www.datocms-assets.com/64837/1776966099-olmoearth-embeddings-blog-google-docs-image-4-2.png)

这个查询位于加州 Merced 市中心附近。城市肌理和道路走廊连贯地亮起，而农田地块保持暗色。模型在没有任何标签的情况下区分出了建成地表与耕地。

把查询换成一个小的农业窗口：我们将查询向量定义为该窗口上嵌入向量的均值，然后拉出相似度最高和最低位置的 Sentinel-2 影像，看看模型认为什么相似、什么不相似。

[![Embedding cosine similarity, query versus highest and lowest: an overview tile and the blue query patch above three high-similarity agricultural patches at 0.91, 0.89, and 0.89, and three low-similarity patches at -0.05 (airport), 0.03 (reservoir), and 0.08 (arid rangeland)](https://www.datocms-assets.com/64837/1776966200-olmoearth-embeddings-blog-google-docs-image-5-2.png)](https://www.datocms-assets.com/64837/1776966200-olmoearth-embeddings-blog-google-docs-image-5-2.png)

最相似的区块（0.89 及以上）全是有灌溉农田的地块。最不相似的（接近零）是机场及其周边裸地、水库及其周边旱地，以及干旱牧场。没有训练数据、没有标签，只是嵌入空间里的一次点积。

### 少样本分割：给地表打标签

相似度搜索回答的是"哪里像这个？"，但有时你需要在整个区域上得到离散标签。由于表示本身已经足够丰富，一个简单的线性分类器就能用极少量带标签像素生成全覆盖的土地利用图。

为验证这一点，我们只在越南 Ca Mau（沿海红树林区域）标注了 *60 个像素*（每类 20 个）。以 [ESA WorldCover 2021](https://esa-worldcover.org/en) 作为三个类别（红树林、水体、其他）的标签来源，我们每类随机采样 20 个像素，训练了一个带逐特征标准化的逻辑回归，然后对区域内每个像素做预测。

[![Few-shot classification from 60 labeled pixels over Ca Mau, Vietnam: Sentinel-2 RGB, the ESA WorldCover reference map, and the predicted mangrove/water/other map at F1 0.84](https://www.datocms-assets.com/64837/1776966290-olmoearth-embeddings-blog-google-docs-image-6-2.png)](https://www.datocms-assets.com/64837/1776966290-olmoearth-embeddings-blog-google-docs-image-6-2.png)

仅用 60 个标注像素，分类器就产出了一张连贯的地图，*加权 F1 = 0.84*。红树林、潮汐水道和开阔水面在整个区域都被清晰划分。分类器很快饱和：从 30 个标签增加到 300 个，准确率几乎不变——因为重活是嵌入在干的。

分析的核心只有几行 Python：

```
import rasterio
import numpy as np
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

# Load the 192-band embedding COG exported from Studio
with rasterio.open("embeddings.tif") as ds:
    emb = ds.read().astype(np.float32)  # (192, H, W)

C, H, W = emb.shape
X = emb.reshape(C, -1).T  # (H*W, 192)

# Train on labeled pixels, predict everywhere
clf = make_pipeline(StandardScaler(), LogisticRegression(max_iter=2000))
clf.fit(X[train_idx], labels[train_idx])
prediction = clf.predict(X).reshape(H, W)
```

这是一个*线性探针（linear probe）*，是基础模型的标准评估方式。一个在 192 维上的逻辑回归仅凭这么少的标签就能恢复出地表覆盖边界，说明 Tiny 编码器在预训练中已经组织了这些生态学上的区分。更大的变体（Base，768 维）编码的表示更加丰富。

如果你有地面真值多边形、野外调查点位或一份粗略的现有地图，你可以训练类似的分类器，为你自己的关注区域生成全覆盖地图。

### 变化检测：发现哪里发生了变化

由于 Studio 能以任意时间分辨率（月度到年度）生成嵌入，你可以直接对比两个时期，找出地表条件发生变化的位置。下面我们对同一区域分别计算了 2023 年 9 月和 2024 年 9 月的月度 Sentinel-2 嵌入，并测量逐像素余弦距离。加州 Butte County 的 Park Fire（2024 年 7-9 月）过火区立刻显现出来。

[![Wildfire change detection from OlmoEarth embeddings: Sentinel-2 imagery of Butte County, California in September 2023 and September 2024, beside a cosine-distance map where the Park Fire burn scar glows orange and yellow](https://www.datocms-assets.com/64837/1776966463-olmoearth-embeddings-blog-google-docs-image-7-1.png)](https://www.datocms-assets.com/64837/1776966463-olmoearth-embeddings-blog-google-docs-image-7-1.png)

无需标签、无需训练——只要两份嵌入 COG 和几行 Python。

### 无监督探索：看看模型眼中的世界

有时你既没有查询位置，也没有参考标签，只想理解嵌入中存在什么结构。主成分分析（PCA）是一个干净的做法：降到三维，映射到 R/G/B，显示为假彩色图像。相似的嵌入会自动获得相似的颜色。

[![OlmoEarth embedding structure over Flevoland, the Netherlands: Sentinel-2 RGB beside a PCA false-color image mapping PC1, PC2, and PC3 to red, green, and blue, which reproduces the polder parcel grid](https://www.datocms-assets.com/64837/1776966500-olmoearth-embeddings-blog-google-docs-image-8-2.png)](https://www.datocms-assets.com/64837/1776966500-olmoearth-embeddings-blog-google-docs-image-8-2.png)

荷兰的 Flevoland 是一片围垦圩田景观，农业地块呈规则网格状。PCA 假彩色图像高保真地复现了这些边界。不同的作物类型、水体和城市区域各自呈现出分明的色调。嵌入在从未被告知什么是地块、什么是作物的情况下，就把景观结构内化了。

这种无监督视图是一种快速方式，让你看到模型在你的关注区域上学到了哪些结构。

### 从导出到洞见

相似度搜索、少样本分割、变化检测和 PCA 探索都是在标准栅格数据上的简单操作，几秒钟就能跑完。力量来自嵌入本身：学到的表示把对地观测数据压缩成向量，这些向量从众多传感器和数百万训练样本中提炼了关于每个位置的丰富信息。

自定义嵌入导出现已可用。创建一个项目、配置一个嵌入模型，然后[计算你的嵌入](https://docs.olmoearth.allenai.org/embeddings)。导出的 GeoTIFF 适用于任何地理空间工具：QGIS、GDAL、rasterio，或你自己的脚本。要端到端复现本文的示例，参见[嵌入教程](https://github.com/allenai/olmoearth_projects/tree/main/tutorials/embeddings)，其中包含[相似度搜索](https://github.com/allenai/olmoearth_projects/tree/main/tutorials/embeddings/src/olmoearth_embeddings_tutorial/similarity)、[少样本分割](https://github.com/allenai/olmoearth_projects/tree/main/tutorials/embeddings/src/olmoearth_embeddings_tutorial/segmentation)、[变化检测](https://github.com/allenai/olmoearth_projects/tree/main/tutorials/embeddings/src/olmoearth_embeddings_tutorial/change_detection)和 [PCA 可视化](https://github.com/allenai/olmoearth_projects/tree/main/tutorials/embeddings/src/olmoearth_embeddings_tutorial/pca)的可用代码。想零本地环境上手体验，可以试试 [Colab notebook](https://colab.research.google.com/drive/1JnhFn0IfDJEn49S4sKuCS-mv_b4T2tU0?usp=sharing)。

## 更进一步：微调

本文的所有示例都使用冻结的嵌入、不做任何任务特定训练。嵌入是借力 OlmoEarth 的绝佳入口：生成结果快速经济、在资源受限环境中表现良好、且易于共享。对于需要更高性能的应用，OlmoEarth Studio 还支持 [SFT](https://docs.olmoearth.allenai.org/model-fine-tuning)——在你自己的标签上训练任务专用的模型头，其效果通常优于在冻结特征上做线性探针。

### 局限性

虽然我们一直在改进预训练方法，但重要的一点是用上文介绍的某些技术检查嵌入对你具体用例的质量。性能也取决于输入影像的质量——持续云层覆盖、大气伪影，或合成周期内的缺失观测，都会影响最终向量。

*Sentinel-2 L2A 影像来自欧洲航天局（ESA），经 Microsoft Planetary Computer 获取。红树林参考数据使用 ESA WorldCover 2021 v200。全局聚类可视化使用 OlmoEarth-v1-Base（768 维）与季节性 Sentinel-2 合成，patch size 为 8，在 110 万预训练样本上得到实例级嵌入。*
