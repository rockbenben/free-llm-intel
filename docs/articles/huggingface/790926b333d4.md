#### **1. ML 给 SaaS 带来了哪些积极影响？**

ML 在很多方面惠益了 SaaS 产品。

**a. 提升应用内的自动化水平：** 例如，用 NLP（自然语言处理）理解服务请求的上下文、把工单路由到组织内合适团队的服务工单分发器。

**b. 降低代码复杂度：** 基于规则的系统随着规则不断添加会变得臃肿难管，推高维护成本。例如，与以往的规则系统相比，基于 ML 的语言翻译系统更准、更稳健，代码量却少得多。

**c. 更好的预测带来成本节约。** 预测更准确，就能减少供应链中的缺货积压，还能因仓储成本下降而省钱。

#### **2. SaaS 里最大的 ML 挑战是什么？**

a. 把 ML 应用产品化，需要的远不止一个模型。模型要能对外提供服务、检测和适应数据分布的变化等等，这给 ML 系统的部署和维护带来了巨大的额外负担。

b. 在大多数大型组织里，数据往往各成孤岛、维护不善，于是大量时间被花在数据合并、预处理、清洗等活动上，开发基于 ML 的应用因此要付出大量的时间和精力。

#### **3. 人们把 ML 集成进 SaaS 时常犯的错误是什么？**

不够关注业务背景和要解决的问题，反而一门心思用最新的算法和新开源的库。其实很多目标用朴素的传统 ML 技术就能达成。

#### **4. 你对 ML 的未来最兴奋的是什么？**

通用人工智能能力如果建设好、管理好，对人类的改变远超想象。我希望我们能在医疗和交通领域看到巨大进展。AI 在放射影像上的益处已经显现，节省了大量人力，让人可以专注于更复杂的任务。自动驾驶汽车和卡车也已经在改变交通行业。

#### **1. ML 给 SaaS 带来了哪些积极影响？**

ML 在把海量嘈杂的机器生成或用户生成数据转化为各类业务问题的答案（个性化、预测、推荐等）方面起到了改变游戏规则的作用，并通过 SaaS 影响到广泛的行业垂直领域。

#### **2. SaaS 里最大的 ML 挑战是什么？**

缺少能覆盖更广泛行业用例的 ML 训练数据。既要作为面向所有行业的通用解决方案，又得想办法处理业务衍生的垂直化需求，或者影响模型质量的领域偏移（domain shift）问题。

#### **3. 人们把 ML 集成进 SaaS 产品时常犯的错误是什么？**

没有给用户足够的灵活性去融入他们的业务知识，或其他对业务成功至关重要的人工因素。例如在自助式产品推荐里，如果用户能控制推荐结果的多样性，那就太好了。

#### **4. 你对 ML 的未来最兴奋的是什么？**

ML 已经取得了巨大成功，而且它还在快速演进以解决当前的局限（如数据缺乏、领域偏移、领域知识的融入）。

会有更多 ML 技术被用于解决业务或客户需求。例如：可解释 ML 让用户理解和信任模型输出；反事实预测（counterfactual prediction）让用户估计"如果换一个业务决策，结果会怎样"。

#### **1. ML 给 SaaS 带来了哪些积极影响**

机器学习让对话数据的转录成为可能，帮助人们解锁新的洞见和理解。人们现在可以轻松查看谈话内容、目标摘要、要点、谁说得最多、谁问了最好的问题、下一步是什么等等。这对邮件和视频会议（如今比以往更普遍）等大量交互场景都非常有用。

在 [Chorus.ai](https://huggingface.co/blog/chorus.ai)，我们在录音的同时实时转录对话，用的是叫 [Wave2Vec](https://arxiv.org/abs/1904.05862) 的算法。🤗 [Hugging Face 最近发布了他们自己用于训练的 Wave2Vec](https://huggingface.co/docs/transformers/model_doc/wav2vec2) 版本，让我们受益匪浅。这一代 Transformer 语音技术强得惊人，把我们的错误率降低了 30%。

转录完成后就能深入内容——这就是 NLP 的用武之地。我们大量依赖 [Hugging Face Transformers](https://huggingface.co/docs/transformers/index)，识别录音和邮件中大约 20 类主题；比如是在谈价格、签合同，还是下一步安排——这些主题要么通过邮件发送、要么在会中讨论，现在提取这些信息轻而易举，不用翻遍所有对话记录。

这让人们的工作出色得多。

#### **2. SaaS 里最大的 ML 挑战是什么？**

最大的挑战是判断什么时候该用 ML。

哪些问题能用 ML 解决、哪些不该用？很多时候我们在某个 ML 模型上取得了突破，但一个计算更轻的启发式模型其实更适合手头的这个问题。

这就需要强有力的 AI 战略。——想清楚最终产品要怎么工作、要有多高的效率。

还有一个问题是怎么把你构建的 ML 模型以低环境/计算足迹推上生产。大家都在为此发愁：如何高效地让模型在生产环境运行，又不过度烧资源。

一个很好的例子是我们迁移到 Wav2Vec 框架的时候：它要求把对话音频切成 15 秒的片段喂给这个大模型。期间我们发现，大量喂进去的片段是纯静音——这很常见，比如有人没到场，或者一个人在会上等另一个人加入。

只需再加一个非常轻的模型来判断何时不要把静音片段送进这个庞大复杂的 ML 模型，我们就能节省大量算力/能源。这就是工程师可以换个简单思路为模型生产提速省钱的例子。还有更多机会让工程师更聪明一些，在不烧太多资源的前提下把模型优化得更好。

#### **3. 人们把 ML 集成进 SaaS 时常犯的错误是什么？**

多问自己：我的方案是最聪明的方案吗？有没有更好的拆解方式、更高效的解法？

我们一开始做说话人识别时直接上了 ML 方法，结果并不如视频会议服务商提供的数据准确。

后来我们学到，最好的做法是先拿会议提供商提供的"谁在说话"元数据，再叠加一个智能 embedding 模型。这段学习曲线让我们损失了宝贵的时间。如果当初先停下来理解还有哪些值得投入的数据源、能更高效地加速，就不该用那个大型 ML 方案。

跳出框架思考，不要拿到别人做的东西就只是"我有个主意让它更好"。哪里可以靠更好地理解问题来做得更聪明？

#### **4. 你对 ML 的未来最兴奋的是什么？**

我觉得我们正处在又一场革命中间。对我们来说，Wave2Vec 模型让错误率下降 30% 太震撼了。过去我们干上好几年每次只能降 1%，而这次短短 3 个月就看到了巨大提升，而且我们知道这才刚开始。学术界正在发生更大、更聪明的事。这些预训练模型让我们能做到以前想都不敢想的事情，非常令人兴奋！

我们还看到很多 NLP 的技术进入语音、视觉等其他领域并为其赋能。

另一件让我非常兴奋的事是生成模型！我们最近与一家叫 [Bria.ai](https://bria.ai/) 的公司合作，他们用厉害的 GAN 来生成图像。你拿一张库存照片，说"摘掉眼镜"、"戴上眼镜"或"加点头发"，它就完美照做。思路是用它来生成数据。我们可以拿会议里没人笑的照片，让他们"笑起来"，从而构建一个微笑检测数据集。这会带来变革——你可以把 1 张图变成 100 张图。同样，这也会适用于语音生成，在客服行业会是一个强大的应用。

#### **还有什么想补充的吗？**

——把模型投入生产是很有挑战的事。我相信数据科学团队内部必须嵌入工程能力，工程师应该成为 AI 团队的一部分。这将是未来一次重要的结构性转变。

#### **1. 最喜欢的 ML 商业应用？**

我最喜欢的 ML 应用是网络安全。

就数据而言，网络安全对任何公司（政府或非政府）仍然是最关键的部分。机器学习有助于识别网络威胁、打击网络犯罪（包括网络霸凌），并实现对安全漏洞的快速响应。ML 算法能基于用户数据快速分析最可能的漏洞以及潜在的恶意软件和间谍软件应用，能发现终端进入模式的异常并将其识别为潜在的数据泄露。

#### **2. 你最大的 ML 挑战是什么？**

最大的 ML 挑战是阿拉伯语的语音转文本。能解读阿拉伯语的系统有一些，但都不够准。阿拉伯语是 26 个国家的官方语言，有 2.47 亿母语者和 2,900 万非母语使用者，是一门词汇丰富、方言众多、结构复杂的语言。

如果想从阿拉伯语文本中得到准确的洞见，情感挖掘工具必须直接以阿拉伯语读取数据，否则细微含义会在翻译中丢失。把文本翻译成英语或其他语言可能完全改变阿拉伯语词的含义，甚至连词根都变。所以算法必须在阿拉伯语数据集上训练，并使用专门的阿拉伯语词性标注器。因为这些挑战，至今大多数公司都无法提供准确的阿拉伯语语音转文本。

#### **3. 人们集成 ML 时常犯的错误是什么？**

公司在尝试集成 ML 时最常犯的错误是训练数据不足。多数 ML 模型无法区分"好数据"和"不够的数据"，因此训练集往往被当作相关的，在大多数情况下直接照搬其结果。这个挑战并不只存在于中小企业，大型公司同样如此。

无论 ML 流程如何，公司都需要在机器学习的早期阶段引入人的因素，确保训练数据集对期望结果是可靠且完备的。

不过，只要对准确、全面、持续更新的训练数据做彻底审查，公司就能为成功的 ML 项目打下必要的基础。

#### **4. 未来 5-10 年你预计 ML 在哪里影响最大？**

未来 5-10 年，ML 影响最大的将是医疗行业的转型。

**互联医院与连接式护理：**

借助预测式医疗，指挥中心可以分析临床和位置数据，实时监测整个医疗网络的供需情况。有了 ML，医疗专业人员能更快、更有效地发现高风险患者，从而消除系统瓶颈。你可以更快地追踪传染病扩散、更好地管控疫情、更准确地识别高风险患者——尤其是遗传病，等等。

**更好的员工与患者体验：**

预测式医疗网络有望缩短等待时间、改善员工工作流，并应对不断增长的行政负担。通过从每位患者、每次诊断和每例手术中学习，ML 有望打造既能适配医院员工又能适配患者的体验。这会改善健康结果、缓解临床医生短缺与职业倦怠，同时让系统财务上可持续。
