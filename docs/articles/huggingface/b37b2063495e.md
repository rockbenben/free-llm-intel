# Open-R1：DeepSeek-R1 的完全开源复现

## DeepSeek-R1 是什么？

如果你曾被一道难题难住过，就知道多思考一会儿、仔细推演有多有用。[OpenAI 的 o1 模型](https://x.com/polynoamial/status/1834280155730043108)证明：当 LLM 被训练成也这么做——在推理时投入更多算力——它们在数学、编程、逻辑这类推理任务上会显著变强。

然而，OpenAI 推理模型背后的配方一直严守秘密。直到上周，DeepSeek 发布了他们的 [DeepSeek-R1](https://huggingface.co/deepseek-ai/DeepSeek-R1) 模型，随即引爆了互联网（还有[股市！](https://x.com/KobeissiLetter/status/1883831022149927352)）。

除了表现与 o1 相当甚至更好，[DeepSeek-R1](https://huggingface.co/deepseek-ai/DeepSeek-R1) 的发布还配了一份详尽的[技术报告](https://github.com/deepseek-ai/DeepSeek-R1/tree/main)，列出了其训练配方的关键步骤。这套配方包含若干创新，最引人注目的是用纯强化学习教会一个基座语言模型如何推理，而***完全不用***人工监督。如下图所示，只要有一个够强的基座模型和一份高质量的数据混合，做一款强大的推理模型现在非常简单的。

不过，DeepSeek-R1 的发布仍留下若干问题：

- **数据采集：** 那些推理专用的数据集是怎么整理的？
- **模型训练：** DeepSeek 没有发布训练代码，所以哪些超参数最有效、它们在不同模型家族和规模上如何变化，都不得而知。
- **扩展规律：** 训练推理模型时，算力和数据的权衡是什么？

这些问题促使我们启动 [Open-R1 项目](https://github.com/huggingface/open-r1)：系统性地重建 DeepSeek-R1 的数据与训练流水线、验证其结论、并推进开放推理模型的边界。通过构建 Open-R1，我们旨在阐明强化学习如何增强推理，与开源社区分享可复现的洞见，并为未来模型利用这些技术打下基础。

本篇博客梳理 DeepSeek-R1 背后的关键要素、我们计划复现哪些部分，以及如何参与 Open-R1 项目。

开始吧 🚀！

## 他们是怎么做到的？

DeepSeek-R1 是建立在 [DeepSeek-V3](https://huggingface.co/deepseek-ai/DeepSeek-V3-Base) 基础之上的推理模型。和所有优秀的推理模型一样，它始于一个强大的基座模型，而 DeepSeek-V3 正有这样的底气。这个 671B 的 Mixture of Experts（MoE）模型与 Sonnet 3.5、GPT-4o 这样的重量级选手打得有来有回。尤其令人印象深刻的是它的训练成本有多低——仅 550 万美元——得益于 Multi Token Prediction（MTP）、Multi-Head Latent Attention（MLA）等架构改动，以及大量（真的很多）硬件优化。

DeepSeek 还引入了两个模型：DeepSeek-R1-Zero 和 DeepSeek-R1，各自采用不同的训练路径。DeepSeek-R1-Zero 完全跳过监督微调，全靠强化学习（RL），并用 Group Relative Policy Optimization（GRPO）让流程更高效。它采用一个简单的奖励系统引导模型，根据答案的准确性和结构给予反馈。这条路帮助模型 develop 出有用的推理技能，比如把问题分解成步骤、检查自己的输出。不过它的回答常常缺乏条理、难以阅读。

这时 DeepSeek-R1 登场了。它从一个「冷启动」阶段开始，在一小组精心编写的样例上微调，改善清晰度与可读性。随后又经过更多 RL 和精修步骤，包括用基于人类偏好和可验证的奖励双重手段拒绝低质量输出，最终造就一个既会推理、又能输出整洁一致答案的模型。

听起来很美，但到底缺了什么？我们来看看拼图里缺的那些块。

## Open-R1：缺失的拼图

DeepSeek-R1 的发布是社区的天大福音，但他们没有公开*一切*——尽管模型权重是开放的，训练模型所用的数据集和代码并没有 😢。

*Open-R1* 的目标就是补上这些缺失的拼图，让整个科研和产业社区都能用这些配方和数据集构建相似甚至更好的模型。而且这一切都在开放环境下进行，社区里的每个人都能参与贡献！

如下图所示，我们的作战计划是：

- **第 1 步：** 复现 R1-Distill 系列模型——从 DeepSeek-R1 蒸馏出一份高质量推理想数据集。
- **第 2 步：** 复现 DeepSeek 用于制造 R1-Zero 的纯 RL 流水线。这涉及为数学、推理和编程整理新的大规模数据集。
- **第 3 步：** 证明我们可以走通 base model → SFT → RL 的多阶段训练。

这些合成数据集可以让人只需微调，就能把现有或全新的 LLM 变成推理模型。涉及 RL 的训练配方则是任何人从零构建类似模型的起点，也让研究者能在其上开发更先进的方法。

注意我们不想止步于数学数据集。其他领域大有可为——显而易见的是编程，还有医学这类科学领域——推理模型在那里可能产生重大影响。

这项倡议不只是复制结果——而是与社区分享洞见。通过记录什么有效、什么无效、为什么，我们希望帮别人少走弯路、少浪费时间和算力。
