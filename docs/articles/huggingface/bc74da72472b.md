# 首届开源 AI Game Jam 来啦 🎮

## 用 AI 工具释放你的创造力，一个周末做出一款游戏！

我们非常兴奋地宣布首届 **Open Source AI Game Jam**（开源 AI 游戏开发马拉松）正式启动，你将使用 AI 工具创造一款游戏。

AI 有潜力提升游戏体验和开发工作流，我们很期待看到你能完成什么：把 Stable Diffusion 这类生成式 AI 工具融入你的游戏或工作流，解锁新功能、加速开发流程。

从贴图生成到栩栩如生的 NPC，再到逼真的文本转语音，可能性无穷无尽。

📆 记住日期：本次 game jam 将于 **7 月 7—9 日**（周五到周日）举行。

**免费领取 Game Jam 参赛名额** 👉 [https://itch.io/jam/open-source-ai-game-jam](https://itch.io/jam/open-source-ai-game-jam)

## 我们为什么举办这次活动？

在一些流行 game jam 限制使用 AI 工具的当下，我们认为**搭建一个专门展示 AI 为游戏开发者带来的惊人可能性**的平台至关重要，尤其是当这些工具是**开放、透明、可获取**的时候。

我们希望看到这类 game jam 蓬勃发展，用工具赋能独立开发者，提升生产力、释放全部潜能。

## 什么是 AI 工具？

AI 工具，特别是像 Stable Diffusion 这样的生成式工具，为游戏开发打开了一个全新的可能性世界。

从加速工作流到游戏内功能，你可以利用 AI 进行贴图生成、塑造栩栩如生的 AI 非玩家角色（NPC），以及实现逼真的文本转语音功能。

领取 Game Jam 免费参赛名额 👉 [https://itch.io/jam/open-source-ai-game-jam](https://itch.io/jam/open-source-ai-game-jam)

## 谁可以参加？

**欢迎所有人参加 Open Source AI Game Jam**，不论水平高低、身在何处。你可以单人参赛，也可以组建任意规模的团队。

## 有哪些要求？

参赛游戏应可以在网页（如 itch.io）或 Windows 上游玩。此外，**你必须至少在游戏或工作流中整合一个开源 AI 工具**。

我们会提供更多细节来指导你完成整个过程。

## 我可以使用现有素材吗？

当然！**你可以使用你合法拥有的任何现有素材、代码或 AI 工具**。

我们希望确保公平，并让你自由利用手头的资源。

## 有主题吗？

有，主题将在 game jam 开始时公布。

## 游戏如何评审？

参与者将根据三个标准对其他游戏评分：**趣味性、创造力和主题契合度**。评委将从前十名中展示并选出优胜者。
