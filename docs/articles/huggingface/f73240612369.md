# 欢迎 Stable-baselines3 加入 Hugging Face Hub 🤗

在 Hugging Face，我们为深度强化学习研究者与爱好者生态贡献力量。因此我们很高兴宣布已将 [Stable-Baselines3](https://github.com/DLR-RM/stable-baselines3) 集成进 Hugging Face Hub。

[Stable-Baselines3](https://github.com/DLR-RM/stable-baselines3) 是最受欢迎的 PyTorch 深度强化学习库之一，让你能在各种环境（Gym、Atari、MuJoCo、Procgen……）中轻松训练和测试智能体。有了这次集成，你可以托管保存好的模型 💾，也可以加载社区提供的强大模型。

本文将演示具体做法。

### 安装

要把 stable-baselines3 与 Hugging Face Hub 一起使用，只需安装这 2 个库：

```
pip install huggingface_hub
pip install huggingface_sb3
```

### 寻找模型

我们目前正在上传玩 Space Invaders、Breakout、LunarLander 等的智能体模型。除此之外，你可以在[这里找到所有社区 stable-baselines-3 模型](https://huggingface.co/models?other=stable-baselines3)。

找到你需要的模型后，只需复制仓库 id：

[![Image showing how to copy a repository id](https://huggingface.co/blog/assets/47_sb3/repo_id.jpg)](https://huggingface.co/blog/assets/47_sb3/repo_id.jpg)

### 从 Hub 下载模型

这次集成最棒的功能是，你可以非常轻松地把保存好的模型从 Hub 加载到 Stable-baselines3。

为此你只需复制存放你模型的 repo-id，以及仓库中模型 zip 文件的文件名。

例如 `sb3/demo-hf-CartPole-v1`：

```
import gym

from huggingface_sb3 import load_from_hub
from stable_baselines3 import PPO
from stable_baselines3.common.evaluation import evaluate_policy

# Retrieve the model from the hub
## repo_id = id of the model repository from the Hugging Face Hub (repo_id = {organization}/{repo_name})
## filename = name of the model zip file from the repository including the extension .zip
checkpoint = load_from_hub(
    repo_id="sb3/demo-hf-CartPole-v1",
    filename="ppo-CartPole-v1.zip",
)
model = PPO.load(checkpoint)

# Evaluate the agent and watch it
eval_env = gym.make("CartPole-v1")
mean_reward, std_reward = evaluate_policy(
    model, eval_env, render=True, n_eval_episodes=5, deterministic=True, warn=False
)
print(f"mean_reward={mean_reward:.2f} +/- {std_reward}")
```

### 分享模型到 Hub

只需一分钟，你就能把保存好的模型放进 Hub。

首先，上传模型需要登录 Hugging Face：

- 如果你使用 Colab/Jupyter Notebooks：

```
from huggingface_hub import notebook_login
notebook_login()
```

- 否则：

```
huggingface-cli login
```

然后，在本例中我们训练一个玩 CartPole-v1 的 PPO 智能体，并推送到新仓库 `ThomasSimonini/demo-hf-CartPole-v1` `

```
from huggingface_sb3 import push_to_hub
from stable_baselines3 import PPO

# Define a PPO model with MLP policy network
model = PPO("MlpPolicy", "CartPole-v1", verbose=1)

# Train it for 10000 timesteps
model.learn(total_timesteps=10_000)

# Save the model
model.save("ppo-CartPole-v1")

# Push this saved model to the hf repo
# If this repo does not exists it will be created
## repo_id = id of the model repository from the Hugging Face Hub (repo_id = {organization}/{repo_name})
## filename: the name of the file == "name" inside model.save("ppo-CartPole-v1")
push_to_hub(
    repo_id="ThomasSimonini/demo-hf-CartPole-v1",
    filename="ppo-CartPole-v1.zip",
    commit_message="Added Cartpole-v1 model trained with PPO",
)
```

动手试试，把你的模型分享给社区吧！
