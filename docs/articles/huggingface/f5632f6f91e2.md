# 宣布 NeurIPS 2025 E2LM 竞赛：语言模型的早期训练评估

🔗[Competition website](https://e2lmc.github.io/) | ✍️[Registration form](https://e2lmc.github.io/registration) | 💬[Discord channel](https://discord.gg/9aYU5fA4) | 📝[Competition proposal](https://arxiv.org/abs/2506.07731)

[![image](https://e2lmc.github.io/photo-noise.png)](https://e2lmc.github.io/photo-noise.png)

加入我们一起构建能捕捉 LLM 早期阶段推理与科学知识能力的基准！

大语言模型（LLM）的开发通常始于一系列 ablation 实验，系统评估各种模型架构、数据配比和训练超参数。这一阶段通常被称为训练的早期阶段。在此期间，研究者主要关注两个关键指标：训练损失曲线和评估分数。然而，现有评估基准往往无法在 LLM 训练的初始阶段（约 200B token 的量级）提供有意义或具区分度的信号，使人们难以从进行中的实验得出决定性洞见。

在这场竞赛中，我们希望共同构建新的基准，有效捕捉 LLM 早期训练阶段的相关信号，特别面向科学知识领域。

## 如何参与

竞赛将在一个专门的 Hugging Face 组织上举办——报名竞赛请通过此注册链接 👉 [https://e2lmc.github.io/registration](https://e2lmc.github.io/registration)。参赛者需要提交其方案，方案基于 [lm-evaluation-harness](https://github.com/EleutherAI/lm-evaluation-harness) 库，通过一个 HuggingFace Space 提交。竞赛期间将维护一个实时排行榜以追踪有前景的提交。模型规模不大，人人都可轻松运行——在免费的 Google Colab GPU 上即可。我们还提供[一份完整的入门套件](https://e2lmc.github.io/starter_kit)，内含多个 notebook 帮助你快速开始竞赛。

## 评估指标

每份提交将用三个不同分数评估：*信号质量分数（ScoreSQ）*、*排名一致性分数（ScoreRC）*和*科学知识符合度分数（ScoreCS）*。这些标准组合成一个全局分数用于最终排名。此外，所有提交将系统性地应用两个验证流程：(i) 验证与既有科学知识领域的一致性，(ii) 检测潜在信息泄露，特别是问题 prompt 中是否含有答案。总分按加权和计算：

Score = α1 × Score

SQ

+ α2 × Score

RC

+ α3 × Score

CS

其中 αSQ、αRC 和 αCS 是反映各标准相对重要性的权重系数。我们设定权重为 α1 = 0.5、α2 = 0.1、α3 = 0.4，从而更加重视信号质量与科学知识符合度——我们认为这是评估提交最重要的两个指标。

参赛者可利用提供的三个小语言模型（0.5B、1B 和 3B，训练量从 0 到 200B token）检查点及随附的评分算法（在入门套件的 notebook 中提供）本地计算信号质量子分。另外两个子分则无法独立计算，因为相应检查点——从 200GT 到 1T token 的模型，以及仅在网页数据上训练的 0.5B 参数模型——在整个竞赛期间都将保密。不过，全局分数会在提交时通过 Hugging Face 竞赛 space 自动计算，让参赛者可追踪自己的总体表现。此安排旨在防止专门针对已发布检查点过度定制的解决方案。

每个评估指标的更多细节，以及在最先进基准上的完整评分结果，可在[竞赛方案](https://arxiv.org/abs/2506.07731)中查看。
