# 从零开始训练 CodeParrot 🦜

在这篇博客中，我们来看构建 [GitHub CoPilot](https://copilot.github.com/) 背后的技术需要什么——那是一个在程序员写代码时提供建议的应用。在这份手把手指南里，我们将学习如何从零开始训练一个名为 CodeParrot 🦜 的大型 GPT-2 模型。CodeParrot 可以自动补全你的 Python 代码——去[这里](https://huggingface.co/spaces/lvwerra/codeparrot-generation)试试。开始从零构建吧！

[![codeparrot](https://huggingface.co/blog/assets/40_codeparrot/codeparrot.png)](https://huggingface.co/blog/assets/40_codeparrot/codeparrot.png)

## 构建大规模源代码数据集

第一件事是拿到一个大规模训练数据集。目标是训练一个 Python 代码生成模型，于是我们访问 Google BigQuery 上可用的 GitHub 数据转储，筛出所有 Python 文件。结果是一个 180GB、包含 2000 万个文件的数据集（可在[这里](http://hf.co/datasets/transformersbook/codeparrot)获取）。初步训练实验后，我们发现数据集中的重复样本严重拖累了模型性能。进一步调查数据集后发现：

- 0.1% 的唯一文件占了全部文件的 15%
- 1% 的唯一文件占了全部文件的 35%
- 10% 的唯一文件占了全部文件的 66%

想更了解我们的发现可以看[这条 Twitter 推文串](https://twitter.com/lvwerra/status/1458470994146996225)。我们移除了重复项，并应用了 [Codex 论文](https://arxiv.org/abs/2107.03374)中的同样清洗启发式规则。Codex 就是 CoPilot 背后的模型，是一个在 GitHub 代码上微调的 GPT-3 模型。

清洗后的数据集仍有 50GB，已发布在 Hugging Face Hub 上：[codeparrot-clean](http://hf.co/datasets/lvwerra/codeparrot-clean)。有了它，我们就可以设置一个新的分词器并训练模型。

## 初始化分词器与模型

首先我们需要一个 tokenizer。专门在代码上训练一个，让它把代码切分得很好。我们可以拿一个现有的 tokenizer（比如 GPT-2），用 `train_new_from_iterator()` 方法直接在我们自己的数据集上训练。然后把它推到 Hub 上。注意，为保持代码块紧凑，示例代码中省略了 import、参数解析和日志。完整的代码（含预处理和下游任务评估）可以在[这里](https://github.com/huggingface/transformers/tree/master/examples/research_projects/codeparrot)找到。

```
# Iterator for Training
def batch_iterator(batch_size=10):
    for _ in tqdm(range(0, args.n_examples, batch_size)):
        yield [next(iter_dataset)["content"] for _ in range(batch_size)]

# Base tokenizer
tokenizer = GPT2Tokenizer.from_pretrained("gpt2")
base_vocab = list(bytes_to_unicode().values())

# Load dataset
dataset = load_dataset("lvwerra/codeparrot-clean", split="train", streaming=True)
iter_dataset = iter(dataset)

# Training and saving
new_tokenizer = tokenizer.train_new_from_iterator(batch_iterator(),
                                                  vocab_size=args.vocab_size,
                                                  initial_alphabet=base_vocab)
new_tokenizer.save_pretrained(args.tokenizer_name, push_to_hub=args.push_to_hub)
```

关于 tokenizer 以及如何构建它们，请在 [Hugging Face 课程](https://huggingface.co/course/chapter6/1?fw=pt)中了解更多。

看到那个毫不起眼的 `streaming=True` 参数了吗？这个小小的改动影响很大：不用下载完整（50GB）数据集，而是按需流式读取单个样本，省下大量磁盘空间！关于 streaming 的更多信息请看 [Hugging Face 课程](https://huggingface.co/course/chapter5/4?fw=pt)。

接下来初始化一个新模型。我们采用与 GPT-2 large（15 亿参数）相同的超参数，并调整 embedding 层以适配我们的新 tokenizer，同时加一些稳定性改进。`scale_attn_by_layer_idx` 标志确保按层 id 缩放注意力，`reorder_and_upcast_attn` 主要确保以全精度计算注意力以避免数值问题。我们把刚初始化的模型推到 tokenizer 所在的同一个仓库。

```
# Load codeparrot tokenizer trained for Python code tokenization
tokenizer = AutoTokenizer.from_pretrained(args.tokenizer_name)

# Configuration
config_kwargs = {"vocab_size": len(tokenizer),
                 "scale_attn_by_layer_idx": True,
                 "reorder_and_upcast_attn": True}

# Load model with config and push to hub
config = AutoConfig.from_pretrained('gpt2-large', **config_kwargs)
model = AutoModelForCausalLM.from_config(config)
model.save_pretrained(args.model_name, push_to_hub=args.push_to_hub)
```

有了高效的 tokenizer 和新鲜初始化的模型，我们就可以开始真正的训练循环了。

## 实现训练循环

我们用 [🤗 Accelerate](https://github.com/huggingface/accelerate) 库训练：它允许我们把训练从笔记本电脑扩展到多 GPU 机器，而不用改一行代码。只需创建一个 accelerator，做些参数整理工作：

```
accelerator = Accelerator()
acc_state = {str(k): str(v) for k, v in accelerator.state.__dict__.items()}

parser = HfArgumentParser(TrainingArguments)
args = parser.parse_args()
args = Namespace(**vars(args), **acc_state)
samples_per_step = accelerator.state.num_processes * args.train_batch_size
set_seed(args.seed)
```

现在可以开训了！让我们用 `huggingface_hub` 客户端库克隆存放新 tokenizer 和模型的仓库，然后 checkout 到一个新分支用于这次实验。这样设置后，我们可以并行跑很多实验，最后只把最好的那个合并进主分支。

```
# Clone model repository
if accelerator.is_main_process:
    hf_repo = Repository(args.save_dir, clone_from=args.model_ckpt)

# Checkout new branch on repo
if accelerator.is_main_process:
    hf_repo.git_checkout(run_name, create_branch_ok=True)
```

tokenizer 和模型可以直接从本地仓库加载。由于处理的是大模型，训练期间最好打开[梯度检查点](https://medium.com/tensorflow/fitting-larger-networks-into-memory-583e3c758ff9)来降低 GPU 显存占用。

```
# Load model and tokenizer
model = AutoModelForCausalLM.from_pretrained(args.save_dir)
if args.gradient_checkpointing:
    model.gradient_checkpointing_enable()
tokenizer = AutoTokenizer.from_pretrained(args.save_dir)
```

接下来是数据集。用固定上下文长度的样本能让训练更简单。为了不浪费太多数据（有些样本太短或太长），我们可以用 EOS token 把很多样本拼接起来再切块。

[![codeparrot](https://huggingface.co/blog/assets/40_codeparrot/buffer.png)](https://huggingface.co/blog/assets/40_codeparrot/buffer.png)

一起准备的序列越多，丢弃的 token 比例就越小（上一张图中的灰色部分）。由于我们想流式读取数据集而不是全部提前准备好，所以使用 `IterableDataset`。完整的数据集类如下：

```
class ConstantLengthDataset(IterableDataset):
    def __init__(
        self, tokenizer, dataset, infinite=False, seq_length=1024, num_of_sequences=1024, chars_per_token=3.6
    ):
        self.tokenizer = tokenizer
        self.concat_token_id = tokenizer.bos_token_id
        self.dataset = dataset
        self.seq_length = seq_length
        self.input_characters = seq_length * chars_per_token * num_of_sequences
        self.epoch = 0
        self.infinite = infinite

    def __iter__(self):
        iterator = iter(self.dataset)
        more_examples = True
        while more_examples:
            buffer, buffer_len = [], 0
            while True:
                if buffer_len >= self.input_characters:
                    break
                try:
                    buffer.append(next(iterator)["content"])
                    buffer_len += len(buffer[-1])
                except StopIteration:
                    if self.infinite:
                        iterator = iter(self.dataset)
                        self.epoch += 1
                        logger.info(f"Dataset epoch: {self.epoch}")
                    else:
                        more_examples = False
                        break
            tokenized_inputs = self.tokenizer(buffer, truncation=False)["input_ids"]
            all_token_ids = []
            for tokenized_input in tokenized_inputs:
                all_token_ids.extend(tokenized_input + [self.concat_token_id])
            for i in range(0, len(all_token_ids), self.seq_length):
                input_ids = all_token_ids[i : i + self.seq_length]
                if len(input_ids) == self.seq_length:
                    yield torch.tensor(input_ids)
```

缓冲区里的文本被并行 tokenize，然后拼接起来。样本按块被 yield 出来，直到缓冲区清空、流程重新开始。如果设置 `infinite=True`，数据集迭代器到底后会重新启动。

```
def create_dataloaders(args):
    ds_kwargs = {"streaming": True}
    train_data = load_dataset(args.dataset_name_train, split="train", streaming=True)
    train_data = train_data.shuffle(buffer_size=args.shuffle_buffer, seed=args.seed)
    valid_data = load_dataset(args.dataset_name_valid, split="train", streaming=True)
    
    train_dataset = ConstantLengthDataset(tokenizer, train_data, infinite=True, seq_length=args.seq_length)
    valid_dataset = ConstantLengthDataset(tokenizer, valid_data, infinite=False, seq_length=args.seq_length)
    
    train_dataloader = DataLoader(train_dataset, batch_size=args.train_batch_size)
    eval_dataloader = DataLoader(valid_dataset, batch_size=args.valid_batch_size)
    return train_dataloader, eval_dataloader

train_dataloader, eval_dataloader = create_dataloaders(args)
```

开始训练前，还要设置优化器和学习率调度。我们不想对 bias 和 LayerNorm 权重施加 weight decay，所以用一个辅助函数把它们排除在外。

```
def get_grouped_params(model, args, no_decay=["bias", "LayerNorm.weight"]):
    params_with_wd, params_without_wd = [], []
    for n, p in model.named_parameters():
        if any(nd in n for nd in no_decay): params_without_wd.append(p)
        else: params_with_wd.append(p)
    return [{"params": params_with_wd, "weight_decay": args.weight_decay},
            {"params": params_without_wd, "weight_decay": 0.0},]

optimizer = AdamW(get_grouped_params(model, args), lr=args.learning_rate)
lr_scheduler = get_scheduler(name=args.lr_scheduler_type, optimizer=optimizer,
                             num_warmup_steps=args.num_warmup_steps,
                             num_training_steps=args.max_train_steps,)
```

还剩一个大问题：所有这些数据和模型如何分布在多块 GPU 上。这听起来复杂，但在 🤗 Accelerate 里实际只要一行代码。

```
model, optimizer, train_dataloader, eval_dataloader = accelerator.prepare(
    model, optimizer, train_dataloader, eval_dataloader)
```

底层它会使用 DistributedDataParallel：一个批次被发给每个 GPU worker，每个 worker 有自己的模型副本，在本地计算梯度，然后聚合起来更新每个 worker 上的模型。

[![codeparrot](https://huggingface.co/blog/assets/40_codeparrot/ddp.png)](https://huggingface.co/blog/assets/40_codeparrot/ddp.png)

我们还想时不时在验证集上评估模型，那就写一个干这件事的函数。评估自动以分布式方式完成，我们只需从各 worker 收集所有损失，并报告[困惑度](https://huggingface.co/course/chapter7/3#perplexity-for-language-models)。

```
def evaluate(args):
    model.eval()
    losses = []
    for step, batch in enumerate(eval_dataloader):
        with torch.no_grad():
            outputs = model(batch, labels=batch)
        loss = outputs.loss.repeat(args.valid_batch_size)
        losses.append(accelerator.gather(loss))
        if args.max_eval_steps > 0 and step >= args.max_eval_steps:
            break
    loss = torch.mean(torch.cat(losses))
    try:
        perplexity = torch.exp(loss)
    except OverflowError:
        perplexity = float("inf")
    return loss.item(), perplexity.item()
```

现在可以写主训练循环了。它看起来和普通的 PyTorch 训练循环几乎一样。偶尔会看到某些地方我们用了 accelerator 的函数而不是原生 PyTorch。另外，每次评估后我们会把模型推到分支上。

```
# Train model
model.train()
completed_steps = 0
for step, batch in enumerate(train_dataloader, start=1):
    loss = model(batch, labels=batch, use_cache=False).loss
    loss = loss / args.gradient_accumulation_steps
    accelerator.backward(loss)
    if step % args.gradient_accumulation_steps == 0:
        accelerator.clip_grad_norm_(model.parameters(), 1.0)
        optimizer.step()
        lr_scheduler.step()
        optimizer.zero_grad()
        completed_steps += 1
    if step % args.save_checkpoint_steps == 0:
        eval_loss, perplexity = evaluate(args)
        accelerator.wait_for_everyone()
        unwrapped_model = accelerator.unwrap_model(model)
        unwrapped_model.save_pretrained(args.save_dir, save_function=accelerator.save)
        if accelerator.is_main_process:
            hf_repo.push_to_hub(commit_message=f"step {step}")
        model.train()
    if completed_steps >= args.max_train_steps:
        break
```

调用 `wait_for_everyone()` 和 `unwrap_model()` 时，我们确保所有 worker 都就绪，并移除之前由 `prepare()` 加上的模型包装层。我们还使用了梯度累积和梯度裁剪——都很容易实现。最后，训练完成后我们做最后一次评估、保存最终模型并推到 Hub。

```
# Evaluate and save the last checkpoint
logger.info("Evaluating and saving model after training")
eval_loss, perplexity = evaluate(args)
log_metrics(step, {"loss/eval": eval_loss, "perplexity": perplexity})
accelerator.wait_for_everyone()
unwrapped_model = accelerator.unwrap_model(model)
unwrapped_model.save_pretrained(args.save_dir, save_function=accelerator.save)
if accelerator.is_main_process:
    hf_repo.push_to_hub(commit_message="final model")
```

搞定！这就是从零训练一个完整 GPT-2 模型的全部代码，不到 150 行。我们没有展示脚本的 import 和日志，好让代码更紧凑。现在真的来训练吧！

用这份代码，我们为我们即将出版的 [Transformers 与 NLP 图书](https://learning.oreilly.com/library/view/natural-language-processing/9781098103231/)训练了模型：一个 [110M](https://hf.co/lvwerra/codeparrot-small) 和一个 [1.5B](https://hf.co/lvwerra/codeparrot) 参数的 GPT-2 模型。我们用 16×A100 GPU 机器分别训练了 1 天和 1 周。足够喝杯咖啡、读上一两本书了！

## 评估

对预训练来说这仍然算比较短的训练时间，但相比同类模型，我们已经能观察到不错的下游性能。我们在 OpenAI 的 HumanEval 基准上评估了模型——该基准由 Codex 论文引入，用接近 200 道编程题衡量代码生成模型的性能。

[![codeparrot](https://huggingface.co/blog/assets/40_codeparrot/humaneval.png)](https://huggingface.co/blog/assets/40_codeparrot/humaneval.png)

注意，我们训练 CodeParrot 大约只用了 250-300 亿 token，而 GPT-neo 用了 3000 亿 token，Codex 用了 3000 亿（GPT-3 checkpoint）+ 1000 亿（代码）token。所以这份投入的性价比绝对超值。

那 *pass@k* 指标到底是什么？简单说，它衡量的是：给定模型 *k* 个候选生成结果时，至少有一个程序通过某编程题单元测试的概率。顾名思义，指标随 k 增大而升高，因为更多候选意味着更可能解出题目。你可以用 `datasets` 计算这个指标：

```
from datasets import load_metric

code_eval = datasets.load_metric("code_eval")
test_cases = ["assert add(2,3)==5"]
candidates = [["def add(a,b): return a*b", "def add(a, b): return a+b"]]
pass_at_k, results = code_eval.compute(references=test_cases, predictions=candidates, k=[1, 2])

print(pass_at_k)

# -> {'pass@1': 0.5, 'pass@2': 1.0}
```

你还可以用 `datasets` 加载 OpenAI 的 HumanEval 数据集：

```
from datasets import load_dataset

dataset = load_dataset("openai_humaneval")
```
