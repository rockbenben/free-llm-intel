# Spaces Dev Mode 发布，带来无缝开发体验

Hugging Face Spaces 让你能在几分钟内创建并部署 AI 驱动的 demo。Hugging Face 社区已创建了超过 500,000 个 Spaces，而且还在增长！作为 [Hugging Face Spaces](https://huggingface.co/spaces) 的一部分，我们最近发布了「Dev Mode」支持，让你构建 Spaces 的体验更加无缝。

Spaces Dev Mode 允许你通过 VS Code 或 SSH 直接连接你的 Space。一键即可连上你的 Space 并开始编辑代码，不再需要用 git 把本地更改推送到 Space 仓库。下面我们来看看如何在 Space 的设置中启用这个功能 🔥

## 启用 Dev Mode

Spaces Dev Mode 目前处于 beta 阶段，面向 [PRO 订阅用户](https://huggingface.co/pricing#pro)开放。想了解更多关于 Spaces Dev Mode 的信息，请查看[文档](https://huggingface.co/dev-mode-explorers)。创建 space 后，前往 Settings。

[![dev-mode-settings-1](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/spaces-dev-mode/dev-mode-settings-1.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/spaces-dev-mode/dev-mode-settings-1.png)

在 Settings 页面向下滚动，点击 "Enable Dev Mode"。你的 Space 会自动重启。

[![dev-mode-settings-2](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/spaces-dev-mode/dev-mode-settings-2.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/spaces-dev-mode/dev-mode-settings-2.png)

## 连接 VS Code

当 Space 处于 Running 状态后，你可以一键连接本地或浏览器中的 VS Code！你也可以使用 SSH，在你偏好的其他 IDE 中建立与 Space 的连接。

[![dev-mode-connect](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/spaces-dev-mode/dev-mode-connect.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/spaces-dev-mode/dev-mode-connect.png)

举个例子，我们来修改这个 Gradio Space 的配色主题。编辑完代码后，无需推送更改、也无需重建 Space 容器来测试——直接进入你的 Space，点击 "Refresh"。

[![dev-mode-refresh](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/spaces-dev-mode/dev-mode-refresh.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/spaces-dev-mode/dev-mode-refresh.png)

就这样！对更改满意后，你可以提交并合并，让更改持久生效。

[![dev-mode-update](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/spaces-dev-mode/dev-mode-update.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/spaces-dev-mode/dev-mode-update.png)
