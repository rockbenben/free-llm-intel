我们非常兴奋地宣布：**OVHcloud** 现已成为 Hugging Face Hub 上受支持的推理提供方（Inference Provider）！OVHcloud 加入了我们不断壮大的生态，拓展了在 Hub 模型页面上直接进行 serverless 推理的广度与能力。Inference Providers 还与我们的客户端 SDK（JS 与 Python 均有）无缝集成，用你偏好的提供方调用各种模型变得轻而易举。

这次发布让你比以往任何时候都更容易在 Hugging Face 上访问 gpt-oss、Qwen3、DeepSeek R1、Llama 等热门开放权重模型。你可以在 Hub 上浏览 OVHcloud 的组织页 [https://huggingface.co/ovhcloud](https://huggingface.co/ovhcloud)，并在 [https://huggingface.co/models?inference_provider=ovhcloud&sort=trending](https://huggingface.co/models?inference_provider=ovhcloud&sort=trending) 试用受支持的热门模型。

OVHcloud AI Endpoints 是一项全托管的 serverless 服务，通过简单的 API 调用提供来自顶级研究实验室的前沿 AI 模型。该服务提供有竞争力的按 token 计价，最低至每百万 token 0.04 欧元。

服务运行在位于欧洲数据中心的安全基础设施上，为欧洲用户确保数据主权与低延迟。平台支持结构化输出（structured outputs）、function calling，以及文本和图像处理的多模态能力等高级特性。

OVHcloud 的推理基础设施为生产环境而生，首个 token 响应时间在 200 毫秒以内，非常适合交互式应用和 agentic 工作流。服务同时支持文本生成与 embedding 模型。你可以在 [https://www.ovhcloud.com/en/public-cloud/ai-endpoints/catalog/](https://www.ovhcloud.com/en/public-cloud/ai-endpoints/catalog/) 了解更多关于 OVHcloud 平台与基础设施的信息。

关于如何把 OVHcloud 作为 Inference Provider 使用，请阅读其专属文档页面。

## 工作原理

### 在网站 UI 中

在你的用户账号设置中，你可以：

- 为你已签约的各个提供方设置自己的 API key。若不设置自定义 key，你的请求将经由 HF 路由。
- 按偏好对提供方排序。这会影响模型页面上的 widget 和代码片段。

[![provider_HF](https://cdn-uploads.huggingface.co/production/uploads/691ca54ee1e4ac5a319e443c/ptWLP8cqPh5zNikiz-c5H.jpeg)](https://cdn-uploads.huggingface.co/production/uploads/691ca54ee1e4ac5a319e443c/ptWLP8cqPh5zNikiz-c5H.jpeg)

如前所述，调用 Inference Providers 有两种模式：

- **自定义 key**（请求直接发往推理提供方，使用你在对应推理提供方申请的 API key）
- **经由 HF 路由**（这种情况下你不需要提供方的 token，费用直接计入你的 HF 账号，而非提供方账号）

[![Inference Providers](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/inference-providers/explainer.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/inference-providers/explainer.png)

模型页面会展示第三方推理提供方（与当前模型兼容的那些，按用户偏好排序）

## 从客户端 SDK 调用

### Python（huggingface_hub）

下面的例子演示如何用 OVHcloud 作为推理提供方调用 OpenAI 的 gpt-oss-120b。你可以用 Hugging Face token 经由 Hugging Face 自动路由，或使用你自己的 OVHcloud AI Endpoints API key（如果你有）。

**注意：**这需要较新版本的 huggingface_hub（>= 1.1.5）。

```
import os
from huggingface_hub import InferenceClient

client = InferenceClient(
    api_key=os.environ["HF_TOKEN"],
)

completion = client.chat.completions.create(
    model="openai/gpt-oss-120b:ovhcloud",
    messages=[
        {
            "role": "user",
            "content": "What is the capital of France?"
        }
    ],
)

print(completion.choices[0].message)
```

### JS（@huggingface/inference）

```
import { InferenceClient } from "@huggingface/inference";

const client = new InferenceClient(process.env.HF_TOKEN);

const chatCompletion = await client.chatCompletion({
    model: "openai/gpt-oss-120b:ovhcloud",
    messages: [
        {
            role: "user",
            content: "What is the capital of France?",
        },
    ],
});

console.log(chatCompletion.choices[0].message);
```

## 计费

计费方式如下：

- 对于**直连请求**，即当你使用某个推理提供方的 key 时，由对应提供方对你计费。例如，使用 OVHcloud 的 API key 就计入你的 OVHcloud 账号。
- 对于**路由请求**，即当你通过 Hugging Face Hub 鉴权时，你只需支付标准提供方 API 费率。我们不加任何加价——只是原样透传提供方成本。（未来我们可能会与合作提供方达成收入分成协议。）
