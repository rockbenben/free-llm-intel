在让 [Claude Code](https://huggingface.co/blog/hf-skills-training) 训练开源模型的工作基础上，我们现在让 [Codex](https://developers.openai.com/codex/) 走得更远。我们给了 Codex 访问 [Hugging Face Skills](https://github.com/huggingface/skills) 仓库的权限——其中包含面向机器学习与 AI 任务的技能，例如训练或评估模型。有了 HF skills，一个 coding agent 可以：

- 对语言模型做微调并施加 RL 对齐
- 审阅、解读并基于 Trackio 的实时训练指标采取行动
- 评估 checkpoint 并根据评估结果行动
- 从实验生成报告
- 导出模型并用 GGUF 量化以便本地部署
- 把模型发布到 Hub

本教程挖得更深，展示其工作原理以及你自己如何使用。那我们开始吧。

> Codex 使用 AGENTS.md 文件完成专业任务，而 Claude Code 使用「Skills」。幸运的是，「HF-skills」同时兼容两种方式，可在 Claude Code、Codex 或 Gemini CLI 等主流 coding agent 中工作。

有了 `HF-skills`，你可以这样告诉 Codex：

```
Fine-tune Qwen3-0.6B on the dataset open-r1/codeforces-cots
```

然后 Codex 会：

- 校验你的数据集格式
- 选择合适的硬件（0.6B 模型选 t4-small）
- 使用并更新带 Trackio 监控的训练脚本
- 把任务提交到 Hugging Face Jobs
- 报告任务 ID 与预估成本
- 在你询问时查看进度
- 出问题的时候帮你调试

模型在 Hugging Face GPU 上训练，你去做别的事。训练完成后，你的微调模型就出现在 Hub 上、随取随用。

这不是玩具 demo。该扩展支持生产环境使用的同样训练方法：监督微调、直接偏好优化，以及带可验证奖励的强化学习。你可以训练 0.5B 到 7B 参数的模型、把它们转成 GGUF 用于本地部署，并运行组合多种技术的多阶段流水线。

## 目标：端到端的机器学习实验

在 Claude Code 教程中我们探索过这种单 prompt 方式。而现在我们可以更进一步，让 OpenAI Codex 执行端到端的机器学习实验。例如，Codex 应该能监控进度、评估模型、维护一份随时更新的训练报告。这让工程师可以把实验委托给 Codex，以更放手的方式审阅报告。也让 Codex 能基于训练报告和评估结果自行做出更多决策。

我们开始吧！

## 安装与配置

开始之前你需要：

- 一个带 [Pro](https://hf.co/pro) 或 [Team / Enterprise](https://hf.co/enterprise) 计划的 Hugging Face 账户（Jobs 需要付费计划）
- 来自 [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens) 的写权限 token
- 已安装并配置好的 [Codex](https://developers.openai.com/codex/)

### 安装 Codex

Codex 是 OpenAI 的 AI coding agent，包含在 ChatGPT Plus、Pro、Business、Edu 和 Enterprise 计划中。Codex 把 AI 辅助直接带入你的开发工作流。

安装与配置说明见 [Codex 文档](https://developers.openai.com/codex/)。

### 安装 Hugging Face Skills

Hugging Face Skills 仓库包含一个 `AGENTS.md` 文件，Codex 会自动检测并使用它。

克隆仓库：

```
git clone https://github.com/huggingface/skills.git
cd skills
```

Codex 会自动检测仓库中的 `AGENTS.md` 文件并加载 skills。你可以用以下命令验证指令已加载：

```
codex --ask-for-approval never "Summarize the current instructions."
```

更多细节见 [Codex AGENTS 指南](https://developers.openai.com/codex/)。

### 连接 Hugging Face

用 `hf auth login` 命令加来自 [hf.co/settings/tokens](https://huggingface.co/settings/tokens) 的写权限 token 完成 Hugging Face 认证：

```
hf auth login
```

Codex 支持 [MCP（Model Context Protocol）](https://developers.openai.com/codex/)服务器。你可以配置 Hugging Face MCP 服务器获得额外的 Hub 集成能力。在你的 `~/.codex/config.toml` 文件中加入以下内容，即可把 Hugging Face MCP 服务器添加到 Codex 配置：

```
[mcp_servers.huggingface]
command = "npx"
args = ["-y", "mcp-remote", "https://huggingface.co/mcp?login"]
```

在[设置](https://huggingface.co/settings/mcp)页面配置 Hugging Face MCP Server，启用如 Jobs 等相关 MCP 服务器。

然后启动 Codex，你会被引导至 Hugging Face MCP 认证页面。

## 你的第一个 AI 实验

我们来走一遍完整示例。我们将微调一个小模型来提升代码求解能力，使用 [open-r1/codeforces-cots](https://huggingface.co/datasets/open-r1/codeforces-cots) 数据集与 [openai_humaneval](https://huggingface.co/datasets/openai/openai_humaneval) 基准。

> open-r1/codeforces-cots 数据集收录了 Codeforces 题目与解答，很适合用于指令微调模型去解决高难度编程问题。

### 指示 Codex 做端到端微调实验

在项目目录中启动 Codex，然后给它一条简单清晰的指令：

```
Start a new fine-tuning experiment to improve code solving abilities on using SFT. 
- Maintain a report for the experiment. 
- Evaluate models with the openai_humaneval benchmark
- Use the open-r1/codeforces-cots dataset
```

> 你会注意到，我们比 Claude Code 教程里的单 prompt 方式前进了一步：给指令加了更多细节，也给实验加了更多步骤。
> 不妨自己在这个实验上迭代，用更开放的问题试试，比如「提升代码求解能力的最佳模型是什么？」或「代码求解任务的最佳数据集是什么？」

Codex 分析你的请求并准备训练配置。对一个 0.6B 模型加 demo 数据集，它选择 `t4-small`——对该模型规模够用、且是最便宜的选项。Codex 会在 `training_reports/<model>-<dataset>-<method>.md` 新建一份报告，形如下面的示例。随着实验推进，Codex 会用最新信息和每次运行的报告更新它。

示例训练报告

```

### 更新训练报告

随着实验推进，Codex 会用最新信息和每次运行的报告更新该报告。你可以在 `training_reports/<model>-<dataset>-<method>.md` 文件中查看。

例如，实验进行中时 Codex 会把报告标题更新为 `sft-a10g` - `TBD` - `In Progress`。

```
# `base-humaneval-a10g` - `2025-12-09 13:47:47 UTC` - `In Progress`
```

它可以链接到运行日志与 Trackio 日志。

```
## Run Logs

[Run Logs](https://huggingface.co/jobs/burtenshaw/6938272ec67c9f186cfe1ae3)

```

它还会把评估结果更新进一张汇总表格。

```

### 数据集校验

数据集格式与处理是训练失败最常见的原因，通常训练脚本里也为此做了大量工作。Codex 能在任务启动前校验数据集，并可为 TRL 定义配置或单独处理数据集。

大多数情况下，Codex 会在训练前校验数据集，但你也可以随时在提交任务前先检查数据集校验结果。

```
Check if open-r1/codeforces-cots works for SFT training.
```

Codex 在 CPU 上做一次快速检查（花费不到一分钱）并报告：

```
Dataset validation for my-org/conversation-data:

SFT: ✓ READY
  Found 'messages' column with conversation format

DPO: ✗ INCOMPATIBLE
  Missing 'chosen' and 'rejected' columns
```

如果你的数据集需要转换，Codex 可以在训练前预处理数据集。

```
Preprocess the dataset open-r1/codeforces-cots to use 'good_response' and 'bad_response' instead of 'chosen' and 'rejected'.
```

Codex 会预处理数据集并更新训练脚本的新配置。

### 提交前审阅

在 Codex 提交任何任务之前，你会看到配置：

```
I'll fine-tune Qwen/Qwen3-0.6B on open-r1/codeforces-cots using SFT.

Configuration:
- Hardware: t4-small (~$0.75/hour)
- Estimated time: ~20 minutes
- Estimated cost: ~$0.30
- Output: username/qwen-codeforces-cots-sft

The model will be pushed to Hub automatically. Should I submit?
```

这是你调整任何东西的机会：改输出仓库名、换硬件、或让 Codex 修改训练参数。你批准后，任务即被提交。

例如，你可以让 Codex 先跑个测试：

```
Do a quick test run on 100 examples.
```

### 用训练报告跟踪进度

提交后，你可以用训练报告跟踪进度，获取运行日志和 Trackio 日志的链接。你还可以让 Codex 拉取日志、总结进度并更新训练报告。Codex 在运行任务的同时，会不断用最新信息更新训练报告。

### 使用你的模型

训练完成后，你的模型就在 Hub 上：

```
from transformers import AutoModelForCausalLM, AutoTokenizer

model = AutoModelForCausalLM.from_pretrained("burtenshaw/qwen3-codeforces-cots-sft")
tokenizer = AutoTokenizer.from_pretrained("burtenshaw/qwen3-codeforces-cots-sft")
```

Transformers 作为标准很好用，我们也可以轻松把训练好的模型转成 GGUF 用于本地部署。这是因为训练技能包含把模型转成 GGUF 的指令与支持脚本。

```
Convert my fine-tuned model to GGUF with Q4_K_M quantization.
Push to username/my-model-gguf.
```

然后 Codex 转换为 GGUF、应用量化并推送到 Hub。如果我们训练的是 LoRA 适配器，它会把 LoRA 适配器合并进基座模型。

接着在本地使用：

```
llama-server -hf <username>/<model-name>:<quantization>

# For example, to run the Qwen3-1.7B-GGUF model on your local machine:
llama-server -hf unsloth/Qwen3-1.7B-GGUF:Q4_K_M
```

### 硬件与成本

Codex 根据你的模型规模选择硬件，但理解其中的取舍能帮你做出更好的决策。你可以用[硬件指南](https://github.com/huggingface/skills/blob/main/hf-llm-trainer/skills/model-trainer/references/hardware_guide.md)查看硬件选项与成本，不过 Codex 会代劳并选出最佳选项。

对 **1B 参数以下的极小模型**，`t4-small` 就很合适。这类模型训练很快——完整跑一遍约 $1-2。非常适合教学或实验性运行。

对 **小模型（1-3B）**，升级到 `t4-medium` 或 `a10g-small`。训练需要几小时，成本 $5-15。

对 **中等模型（3-7B）**，你需要 `a10g-large` 或 `a100-large` 配合 LoRA。全量微调放不下，但 LoRA 让这些模型非常可训。生产用途预算 $15-40。

对 **大模型（7B+）**，这个 HF skills 任务目前还不适合该规模。不过敬请期待，我们正在做！
