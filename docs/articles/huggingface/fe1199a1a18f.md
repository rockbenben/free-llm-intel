我们很高兴地宣布 LeRobot 一系列重大进展，旨在让开源机器人学习比以往任何时候都更强大、更可扩展、更易用！从彻底革新的数据集，到多功能的编辑工具、新的仿真环境，再到为硬件打造的开创性插件系统，LeRobot 持续演进，以满足前沿具身 AI 的需求。

## 太长不看

## 数据集：为下一波大规模机器人学习做好准备

我们彻底改造了数据集基础设施，推出 **LeRobotDataset v3.0**，采用新的分块 episode 格式和流式能力。这对处理 [OXE](https://huggingface.co/collections/lerobot/open-x-embodiment)（Open X Embodiment）和 [Droid](https://huggingface.co/datasets/lerobot/droid_1.0.1) 这样的海量数据集是颠覆性的，带来无与伦比的效率和可扩展性。

### Datasets v3.0 有何新特性？

- 为大规模而设计的分块 Episode：新格式支持 OXE 级别（> 400GB）的数据集，带来前所未有的可扩展性。
- 高效视频存储 + 流式：享受更快的加载时间和无缝的视频数据流式传输。
- 统一的 Parquet 元数据：告别散落的 JSON！所有 episode 元数据现在存放在统一、结构化的 Parquet 文件里，更易于管理和访问。
- 更快加载与更好性能：数据集初始化时间显著缩短，内存使用更高效。

我们还提供了一个转换脚本，便于把你现有的 v2.1 数据集迁移到新的 v3.0 格式，确保平滑过渡。在我们的上一篇 [博客](https://huggingface.co/blog/lerobot-datasets-v3) 中阅读更多。开源机器人不断升级！

### 新功能：数据集编辑工具！

用 LeRobot 数据集工作变得轻松多了！我们引入了一套强大的实用工具，用于灵活的数据集编辑。

用新的 `lerobot-edit-dataset` CLI，你现在可以：

- 从现有数据集中删除特定 episode。
- 按分数或 episode 索引切分数据集。
- 轻松添加或移除特征。
- 把多个数据集合并成一个统一的数据集。

```
# Merge multiple datasets into a single dataset.
lerobot-edit-dataset \
    --repo_id lerobot/pusht_merged \
    --operation.type merge \
    --operation.repo_ids "['lerobot/pusht_train', 'lerobot/pusht_val']"

# Delete episodes and save to a new dataset (preserves original dataset)
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --new_repo_id lerobot/pusht_after_deletion \
    --operation.type delete_episodes \
    --operation.episode_indices "[0, 2, 5]"
```

这些工具简化了你的工作流，让你以前所未有的方式筛选和优化机器人数据集。详情查看 [文档](https://huggingface.co/docs/lerobot/using_dataset_tools)！

## 仿真环境：扩展你的训练场

我们持续扩展 LeRobot 的仿真能力，为你的机器人策略提供更丰富、更多样的训练环境。

[![libero-demo](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot-blog/release-v0.4.0/lerobot-libero-groot-v040.gif)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot-blog/release-v0.4.0/lerobot-libero-groot-v040.gif)

### LIBERO 支持

LeRobot 现在正式支持 [LIBERO](https://libero-project.github.io/intro.html)，它是面向视觉-语言-动作（VLA）策略的最大开放基准之一，拥有 130 多个任务！这是迈向打造 VLA 首选评估中心的一大步，实现了便于集成、为评估任意 VLA 策略提供统一设置。

查看 [LIBERO 数据集](https://huggingface.co/datasets/HuggingFaceVLA/libero) 和我们的 [文档](https://huggingface.co/docs/lerobot/en/libero) 开始上手！

### Meta-World 集成

我们集成了 [Meta-World](https://meta-world.github.io)，这是测试机器人操作多任务与泛化能力的首要基准，包含 50 多个多样的操作任务。这一集成，加上我们对 `gymnasium ≥ 1.0.0` 和 `mujoco ≥ 3.0.0` 的标准化使用，确保了确定性的随机种子和稳健的仿真基础。

今天就用 [Meta-World 数据集](https://huggingface.co/datasets/lerobot/metaworld_mt50) 训练你的策略！

## 代码库：人人可用的强大工具

我们让机器人控制更灵活、更易用，为数据采集和模型训练开启新的可能。

### 新的数据处理流水线

把数据从机器人送到模型（再送回！）是件棘手的事。原始传感器数据、关节位置和语言指令并不匹配 AI 模型所期望的格式。模型需要归一化、成批的张量，并在正确的设备上；而你的机器人硬件需要具体的动作命令。

我们很高兴引入 **Processors（处理器）**：一个全新的模块化流水线，充当数据的通用翻译器。可以把它想象成一条装配线，每个 `ProcessorStep` 负责一项具体的工作——比如归一化、对文本做分词、或把数据搬到 GPU。

你可以把这些步骤串成一条强大的流水线，完美管理你的数据流。我们甚至创建了两种不同的类型来简化生活：

- `PolicyProcessorPipeline`：为模型打造。它熟练地处理成批张量，用于高性能训练和推理。
- `RobotProcessorPipeline`：为硬件打造。它处理单个数据点（如一个观测或动作），用于实时机器人控制。

```
# Get environment state
obs = robot.get_observation()

# Rename, Batch, Normalize, Tokenize, Move Device ... 
obs_processed = preprocess(obs)

# Run inference
action = model.select_action(obs_processed)

# Unnormalize, Move Device ...
action_processed = postprocess(action)

# Execute action
robot.send_action(action_processed)
```

这套系统让你轻松把任意策略接到任意机器人，确保数据在每一步都处于完美格式。在我们的 [Processors 介绍文档](https://huggingface.co/docs/lerobot/introduction_processors) 中了解更多。

### 轻松多 GPU 训练

训练大型机器人策略变得快多了！我们把 [Accelerate](https://github.com/huggingface/accelerate) 直接集成进训练流水线，让你 **只用一条命令** 就能跨多 GPU 扩展实验：

```
accelerate launch \
  --multi_gpu \
  --num_processes=$NUM_GPUs \
  $(which lerobot-train) \
  --dataset.repo_id=${HF_USER}/my_dataset \
  --policy.repo_id=${HF_USER}/my_trained_policy \
  --policy.type=$POLICY_TYPE \
  # ... More training configuration flags
```

无论你是在微调一个策略还是跑大规模实验，LeRobot 现在都替你处理分布式训练的所有复杂细节。这意味着你可以大幅缩短训练时间：2 块 GPU 减半，3 块 GPU 降到三分之一，以此类推。

查看 [文档](https://huggingface.co/docs/lerobot/multi_gpu_training) 来加速你的机器人学习！

## 策略：释放开放世界的泛化能力

[![groot-demo](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot-blog/release-v0.4.0/lerobot-libero-groot2-v040.gif)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot-blog/release-v0.4.0/lerobot-libero-groot2-v040.gif)

### PI0 与 PI0.5

在开源机器人领域的一个重大里程碑中，我们把 Physical Intelligence 的 **pi0** 和 **pi0.5** 策略集成进了 LeRobot！这些视觉-语言-动作（VLA）模型代表着朝解决机器人开放世界泛化问题迈出的重要一步。是什么让 π₀.₅ 具有革命性？

- 开放世界泛化：设计用于适应全新的环境和场景，在物理、语义和环境层面上做泛化。
- 在异构数据上共同训练：从多模态网络数据、口头指令、子任务命令以及多环境机器人数据的多样混合中学习。
- 与 Physical Intelligence 协作：向 [Physical Intelligence 团队](https://huggingface.co/physical-intelligence) 的开创性工作致以诚挚感谢！

你可以在 Hugging Face Hub 上找到这些模型：[pi0.5_base](https://huggingface.co/lerobot/pi05_base)、[pi0_base](https://huggingface.co/lerobot/pi0_base)，以及它们针对 Libero 调优的版本。更多细节查看 [Physical Intelligence 研究](https://www.physicalintelligence.company/blog/pi05)。

### GR00T N1.5

另一个令人兴奋进展是，得益于与 NVIDIA 机器人团队的出色协作，我们把 **NVIDIA 的 GR00T N1.5** 集成进了 LeRobot！这个开放基础模型是机器人泛化推理与技能的强引擎。作为一个跨具身（cross-embodiment）模型，它接受多模态输入（如语言和图像），在多样环境中执行复杂操作任务，标志着通用机器人的又一次大跨越。是什么让 GR00T N1.5 成为颠覆者？

- 泛化推理与技能：作为跨具身基础模型而设计，GR00T N1.5 擅长泛化推理和操作任务，语言遵循能力有所提升。
- 广泛的异构训练：它从海量数据集学习，融合了真实采集的人形机器人数据、由 NVIDIA Isaac GR00T Blueprint 生成的合成数据，以及互联网规模的视频数据。
- 与 NVIDIA 协作：我们很高兴与 [NVIDIA 团队](https://huggingface.co/nvidia) 合作，把这个最先进模型带给开源的 LeRobot 社区！

你可以在 Hugging Face Hub 上找到模型：[GR00T-N1.5-3B](https://huggingface.co/nvidia/GR00T-N1.5-3B)。更多细节查看 [NVIDIA 研究页](https://research.nvidia.com/labs/gear/gr00t-n1_5/) 和 [官方 GitHub 仓库](https://github.com/NVIDIA/Isaac-GR00T)。

这些策略在 `lerobot` 中的原生集成，是让机器人学习尽可能开放、可复现的一大步。今天就试试它们，分享你的运行，让我们一起推进具身 AI 的前沿！

## 机器人：插件系统开启硬件集成新时代

硬件爱好者的大新闻！我们推出了一个全新的插件系统，彻底改变你集成第三方硬件到 LeRobot 的方式。现在，连接任意机器人、相机或遥操作器就像 `pip install` 一样简单，无需修改核心库。

### 关键收益

- 可扩展性：在独立的 Python 包中开发和集成自定义硬件。
- 可扩展性：支持不断成长的设备生态，而不让核心库臃肿。
- 社区友好：降低社区贡献的门槛，营造更协作的环境。

在我们的 [文档](https://huggingface.co/docs/lerobot/integrate_hardware#using-your-own-lerobot-devices-) 中学习如何创建你自己的插件。

```
pip install lerobot_teleoperator_my_awesome_teleop
lerobot-teleoperate --teleop.type=my_awesome_teleop
```

### Reachy 2 集成

得益于新的插件系统，我们还把 Pollen Robotics 的 [Reachy 2](https://www.pollen-robotics.com/reachy/) 加入了 LeRobot！Reachy 2 既可用于真实机器人控制，也可用于仿真，让你立刻就能试验遥操作和自主演示。

### 手机集成

得益于强大的新流水线系统，你现在可以 **直接用手机**（iOS/Android）遥操作你的从臂。手机充当遥操作设备，我们的 `RobotProcessor` 流水线处理所有转换，让你轻松在不同动作空间（如末端执行器空间）驱动机器人。[查看示例！](https://github.com/huggingface/lerobot/tree/main/examples/phone_to_so100)
