# AutoRound 是什么？Intel 面向 LLM 与 VLM 的先进量化技术

随着大语言模型（LLM）和视觉-语言模型（VLM）的规模和复杂度持续增长，如何高效部署它们变得越来越有挑战性。量化通过缩小模型体积和降低推理延迟提供了一条解决路径。Intel 的 [AutoRound](https://github.com/intel/auto-round) 正是一款在精度、效率与兼容性之间取得平衡的前沿量化工具。

**AutoRound** 是 Intel 研发的仅权重量化（weight-only post-training quantization，PTQ）方法。它使用带符号的梯度下降联合优化权重取整与裁剪范围，在大多数场景下以极小的精度损失实现精确的低比特量化（如 INT2 - INT8）。例如在 INT2 下，其相对精度比主流基线方法高出至多 **2.1 倍**。下图概览了 AutoRound 的核心算法。更多细节请参阅[我们的论文](https://arxiv.org/abs/2309.05516)。

![algorithm overview<](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/auto-round/autoround_overview.png)

尽管性能强劲，AutoRound 依然快速而轻量——在 light 模式下量化一个 72B 模型只需 **A100 GPU 上 37 分钟**。它还支持混合比特调优、lm-head 量化、导出 GPTQ/AWQ/GGUF 格式，以及灵活的调优配方（recipes）。

# 核心优势

## 低比特宽度下的卓越精度

**AutoRound** 交出了极具前景的结果，尤其是在低比特量化场景。在多种任务上的评估显示，2-bit 精度下它以显著优势超越主流方法（[来源](https://arxiv.org/abs/2309.05516)）。在 4-bit 下，如 [Low-Bit Open LLM Leaderboard](https://huggingface.co/spaces/Intel/low_bit_open_llm_leaderboard) 所展示的，AutoRound 在多数情况下仍保持竞争力。

## 2. 广泛的兼容性

### 模型

**LLM：** AutoRound 支持几乎所有主流 LLM 架构，包括 Qwen、LLaMA、DeepSeek 等知名模型。Hugging Face 上已提供现成的量化模型，可见 [OPEA](https://huggingface.co/OPEA)、[Kaitchup](https://huggingface.co/kaitchup) 和 [fbaldassarri](https://huggingface.co/fbaldassarri) 等 collection。

**VLM：** AutoRound 支持 10 多个视觉-语言模型（VLM），包括 Mistral-Small-3.1、Gemma3 等。完整列表见 [README](https://github.com/intel/auto-round?tab=readme-ov-file#vlm-support-matrix)，现成量化模型可在 [OPEA Hugging Face collection](https://huggingface.co/collections/OPEA/vlms-autoround-675bc712fdd6a55ebaf11bfa) 找到。对于尚未支持的模型，你仍可以用 `--iters 0` 应用我们的 RTN 方法：无需调优，但会有一些精度损失。

### 3. 灵活/高效的量化

AutoRound 只需 200 个调优步和很小的校准数据集（最少 128 个样本）就能达到高精度。相比计算量更大的 int2 方法，这种效率意味着更快的量化时间和更低的资源消耗。

# AutoRound 快速上手

## 安装

```
pip install auto-round
```

## 量化与序列化

目前仅支持离线模式生成量化模型。

### 命令行使用

```
auto-round \
    --model Qwen/Qwen3-0.6B \
    --bits 4 \
    --group_size 128 \
    --format "auto_round,auto_awq,auto_gptq" \
    --output_dir ./tmp_autoround
```

AutoRound 还提供另外两个配方：`auto-round-best` 与 `auto-round-light`，分别面向最高精度和更快速度。

```
auto-round-best \
    --model Qwen/Qwen3-0.6B \
    --output_dir ./tmp_autoround
```

对于 2 bits，我们推荐使用 `auto-round-best` 或 `auto-round`。三个配方的对比见下表。

### AutoRound API 使用

这套设置在精度与调优成本之间提供更好的折中，任何场景下都推荐使用。

```
from transformers import AutoModelForCausalLM, AutoTokenizer
from auto_round import AutoRound

model_name = "Qwen/Qwen3-0.6B"
model = AutoModelForCausalLM.from_pretrained(model_name)
tokenizer = AutoTokenizer.from_pretrained(model_name)
bits, group_size, sym = 4, 128, True
autoround = AutoRound(
    model,
    tokenizer,
    bits=bits,
    group_size=group_size,
    sym=sym,
    # enable_torch_compile=True,
)

output_dir = "./tmp_autoround"
autoround.quantize_and_save(output_dir, format='auto_round,auto_awq,auto_gptq') 
```

AutoRound API 用法中的 best/light 设置或混合比特配置，请参考 [AutoRound README](https://github.com/intel/auto-round/blob/main/docs/step_by_step.md#api-usage)

## 推理

AutoRound 会根据已安装的库自动选择可用的最佳后端，并在发现更好后端时提示用户安装额外的库。更多细节参见 [HF README](https://github.com/huggingface/transformers/blob/main/docs/source/en/quantization/auto_round.md#inference) 或 [AutoRound README](https://github.com/intel/auto-round/blob/main/docs/step_by_step.md#4-inference)。

### CPU/Intel GPU/CUDA

```
from transformers import AutoModelForCausalLM, AutoTokenizer

model_name = "OPEA/Qwen2.5-1.5B-Instruct-int4-sym-inc"
model = AutoModelForCausalLM.from_pretrained(model_name, device_map="auto", torch_dtype="auto")
tokenizer = AutoTokenizer.from_pretrained(model_name)
text = "There is a girl who likes adventure,"
inputs = tokenizer(text, return_tensors="pt").to(model.device)
print(tokenizer.decode(model.generate(**inputs, max_new_tokens=50, do_sample=False)[0]))
```

### 将 GPTQ/AWQ 转换为 AutoRound

大多数 GPTQ/AWQ 模型可以转换为 AutoRound 格式，以获得更好的兼容性以及对 Intel 设备的支持。请注意，模型序列化后量化配置会被修改。

```
from transformers import AutoModelForCausalLM, AutoTokenizer, AutoRoundConfig

model_name = "ybelkada/opt-125m-gptq-4bit"
quantization_config = AutoRoundConfig()
model = AutoModelForCausalLM.from_pretrained(model_name, device_map="cpu", torch_dtype="auto",
                                             quantization_config=quantization_config)
tokenizer = AutoTokenizer.from_pretrained(model_name)
text = "There is a girl who likes adventure,"
inputs = tokenizer(text, return_tensors="pt").to(model.device)
print(tokenizer.decode(model.generate(**inputs, max_new_tokens=50, do_sample=False)[0]))
```

# 结语

AutoRound 为大型语言模型和视觉-语言模型的训练后量化带来了有意义的进阶。它把高精度、出色的效率，与对主流模型、设备和导出格式的广泛兼容结合在一起，让低比特量化既实用又强大。无论你是在大规模部署 LLM，还是在 VLM 的边缘推理上做实验，AutoRound 都能提供你所需的工具和灵活性，以最小开销达到最佳性能。欢迎你来试用，并加入这个不断壮大的社区，一起拓展高效 AI 部署的边界。
