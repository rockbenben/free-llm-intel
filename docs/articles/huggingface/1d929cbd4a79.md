## Hugging Face 已经进入你的IDE

介绍这个集成，我本可以干巴巴地罗列功能——但那样太无聊，而且[文档](https://www.jetbrains.com/help/pycharm/hugging-face.html)里都有。不如我们来走一遍实际操作。假设我在写一个 Python 应用，决定让它具备和用户聊天的能力。不只是文字聊天——我们还希望用户能粘贴图片，应用能自然地聊这些图。

如果你不太了解当前机器学习的最新水平，这个需求听起来可能很吓人。别怕：在代码里右键，选择 "Insert HF Model"，你会看到一个对话框：[![dialog_box_screenshot](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/pycharm-integration/dialog_box_screenshot.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/pycharm-integration/dialog_box_screenshot.png)
同时用图片和文字聊天叫 "image-text-to-text"：用户输入图片和文本，模型输出文本。在左侧往下滑找到它。默认情况下模型列表按 Likes 排序——但记住，老模型哪怕已经落后于时代，往往也积累了大量点赞。判断模型新旧，看模型名下方的小字：最后更新日期。我们挑一个又新又火的：`microsoft/Phi-3.5-vision-instruct`。

对某些模型类别，你可以选 "Use Model" 让它自动粘贴一段基础代码到你的 notebook 里，但通常更好的办法是翻阅右侧的模型卡（Model Card），直接抓现成的示例代码。对话框右边就是完整的模型卡，和 Hugging Face Hub 上一模一样。我们就这么干，把它粘贴进代码！

[![code_snippet_screenshot](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/pycharm-integration/code_snippet_screenshot.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/pycharm-integration/code_snippet_screenshot.png) 你们公司的网络安全负责人可能会抱怨你从网上抄了一段来路不明的文本、连读都没读完就运行——真遇到这种情况，就叫他书呆子，然后继续。看哪：我们现在有了一个能愉快聊图的模型——这个例子里，它在阅读并点评一份微软幻灯片截图的问答。随便玩这个例子，试试你自己的聊天、你自己的图片。跑通之后，把这段代码包进一个类，就能直接用在你的应用里了。我们只用了十分钟就拿到了最先进水平的开源机器学习，甚至没打开浏览器。

> 这些模型可能很大！如果遇到内存错误，试试更大显存的 GPU，或者把示例代码里的 20 改小。你也可以去掉 device_map="cuda"，把模型放进 CPU 内存——代价是速度。

## 秒开模型卡

接下来，换个视角。你不是这段代码的作者，而是要审阅它的同事。也许你就是前面那位网络安全负责人，还在为"书呆子"的事耿耿于怀。你看着这段代码，完全不知道自己在看什么。别慌——把鼠标悬停在模型名上，整张模型卡立刻浮现。你可以迅速确认这个模型的来历和它的预期用途。

（如果你平时做别的、两周前写的代码全忘了，这同样非常好用）

## 本地模型缓存

你可能注意到：第一次运行这段代码需要下载模型，之后加载就快得多。模型已经存进了你的本地缓存。还记得之前那个神秘的 🤗 小图标吗？点它一下，缓存中的所有东西一览无余：[![model_cache_screenshot](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/pycharm-integration/model_cache_screenshot.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/pycharm-integration/model_cache_screenshot.png)

这是找到自己正在使用的模型的巧妙办法；不需要时也可以一键清掉、腾出磁盘空间。它对"两周失忆症"场景同样有用——如果你记不清当时用的是哪个模型，八成就在这列表里。不过要提醒：2024 年大多数可用的、可生产的模型都 >1GB，缓存涨得飞快！

## AI 时代的 Python

在 Hugging Face，我们倾向于把开源 AI 看作开源哲学的自然延伸：开源软件为开发者和用户解决问题，创造出可以被集成进代码的新能力，开源模型做的是同一件事。人们容易被复杂性晃了眼，因为实现细节太新、太令人兴奋而过度关注它们——但模型的存在意义是**为你干活**。把架构和训练的细节抽象掉，它们本质上就是**函数**——代码里的工具，把某类输入变换成某类输出。

所以这些功能水到渠成。正如 IDE 早已能为你调出函数签名和 docstring，它们也可以为你调出训练好模型的示例代码和模型卡。这样的集成，让引入一个聊天或图像识别模型像导入任何一个普通库一样顺手。我们毫不怀疑这就是代码的未来，也希望这些功能对你有用！
