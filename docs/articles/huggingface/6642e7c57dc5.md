# Space 密钥泄露事件披露

本周早些时候，我们的团队检测到有人对 Spaces 平台进行了未授权访问，具体涉及 Spaces secrets（空间密钥）。因此，我们怀疑有一部分 Spaces secrets 可能在未获授权的情况下被访问。

作为第一步补救措施，我们已撤销了其中涉及的大量 HF token。被撤销 token 的用户已经收到邮件通知。**我们建议你刷新任何密钥或 token，并考虑将你的 HF token 切换为细粒度访问令牌（fine-grained access tokens），它已成为新的默认选项。**

我们正与外部网络安全取证专家合作，调查此事并审查我们的安全政策与流程。

在过去几天里，我们还对 Spaces 基础设施的安全性做了其他重大改进，包括彻底移除 org token（从而提升可追溯性和审计能力）、为 Spaces secrets 实施密钥管理服务（KMS）、加固并扩展系统识别泄露 token 并主动使其失效的能力，以及更全面地提升整体安全水平。我们也计划在不久的将来——一旦细粒度访问令牌实现功能对等——彻底废弃"经典"的读写 token。我们将继续调查任何可能的相关事件。

最后，我们也已向执法机构和数据保护当局报告了此次事件。

对于此次事件可能造成的干扰，我们深表歉意，也理解它可能给你带来的不便。我们承诺将以此为契机，加强整个基础设施的安全性。如有任何问题，请联系 [security@huggingface.co](mailto:security@huggingface.co)。
