# **使用 NVIDIA Nemotron 开放模型建造鬼屋**

或者更确切地说……

# **嘘！现在离开我的草坪！**

[![博客缩略图](https://cdn-uploads.huggingface.co/product/uploads/6ab2a746c7d0655b3d8dfbb9/5bIvVxc791He8vRKSa BH4.png)](https://cdn-uploads.huggingface.co/product/uploads/6ab2a746c7d0655b3d8dfbb9/5bIvVxc791He8vRKSaBH4.png)

**TL;DR：** MonsterHouse 是我为万圣节创建的交互式投影。他听着“不给糖就捣蛋”的游戏，用一艘脾气暴躁的老海盗船的声音回答，当游客记住他们的举止时，他的态度就会软化。他基于 [NVIDIA Nemotron Voice Agent](https://github.com/NVIDIA-AI-Blueprints/nemotron-voice-agent) 和 NVIDIA [Nemotron ASR](https://huggingface.co/nvidia/nemotron-speech-streaming-en-0.6b)、[Nemotron 3.5 Bolt E4B] 构建4GB](https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Bolt-E4B-4GB)、[Magpie TTS Zeroshot](https://build.nvidia.com/nvidia/magpie-tts-zeroshot) 和 [Audio2Face-3D](https://github.com/NVIDIA/Audio2Face-3D)，并且他在单个工作站上运行。

我希望孩子们在万圣节期间来到我家，以一种有趣而独特的方式互动。房子将负责并分发零食，但脾气暴躁而不是可怕。不知何故，我的解决办法是给车库门一个嘴，教他抱怨。

这就是怪物屋：一栋脾气暴躁的老建筑，充满海盗故事，笑容灿烂，对“请”表示怀疑。 NVIDIA Nemotron Voice Agent 提供对话基础。 Nemotron Speech 负责聆听，Bolt E4B 负责大脑，NVIDIA Magpie TTS Zeroshot 负责现场语音，NVIDIA Audio2Face-3D 负责木嘴说话。

### **怪物屋如何运作**

> 听力：NVIDIA Nemotron 3 ASR 将访客语音转换为文本。 [nemotron-speech-streaming-en-0.6b.q8_0.gguf ]  
> 思考：NVIDIA Nemotron 3.5 Bolt E4B 4GB，一种用于对话代理的开放小语言模型，编写每条回复。 LoRA 适配器提供了个性。  
> 说话：NVIDIA Magpie TTS Zeroshot 根据角色的简短参考样本对每个回复进行语音。  
> 动画：NVIDIA Audio2Face-3D 在虚幻引擎 5 中将干净的语音转换为嘴巴动画。  
> 视觉：NVIDIA Nemotron 3 Nano Omni 描述服装，而 YOLO 和 ByteTrack 则对访客进行计数和跟踪。  
> 运行它：NVIDIA Nemotron Voice Agent 通过 NVIDIA RTX PRO 6000 Blackwell Max-Q 和 NVIDIA RTX PRO 4000 Blackwell 协调一台工作站上的所有内容。

### **充满碎片的笑容**

首先是嘴。我想象着车库的木制门板裂成锯齿状的嘴唇，每当他张开那张该死的嘴时，地狱燃烧的火焰就会从远处照亮车道。他需要看起来古老、富有表现力，并且对访客的存在感到轻微的冒犯。

[![fireMouth](https://cdn-uploads.huggingface.co/product/uploads/6ab2a746c7d0655b3d8dfbb9/CzzK5VpTMFR9Azps_6Qbv .png)](https://cdn-uploads.huggingface.co/product/uploads/6ab2a746c7d0655b3d8dfbb9/CzzK5VpTMFR9Azps_6Qbv.png)*A一个有很多话要说的房子，没有什么表情。*

创建自定义动画装备是构建中劳动密集型部分之一。在将其提交后，我可以导出 Audio2Face-3D 稍后可以制作动画的面部表情形状。角色 SkelMesh 在 Autodesk Maya 中构建，然后导出到虚幻引擎中，在门后添加虚拟火焰和效果。他没有眼睛，没有眉毛，也不眨眼，是一个令人惊讶的经济怪物。

当构建角色的所有废话都在进行时，NVIDIA 构建了 Nemotron 语音代理。原本应该是构建中最困难的部分现在变得相当有趣、迭代且简单。我已经为倾听、对话和演讲奠定了基础。房子已经有嘴了。现在他终于可以找到可以抱怨的事情了。

### **教导不礼貌**

这所房子需要一个像它的性格一样脾气暴躁的过去，所以我设计了一个背景故事，说这所房子是用一艘沉没的海盗船的木材建造的，被其暴风雨的过去所困扰。航海方面的抱怨现在有了理由。这就是这艘船，转世为房地产，但对此并不完全满意。

表演需要一个指南，一条从问候到告别的路径，同时提供沿途的款待。首先，房子会用诸如“我正忙着发牢骚，去打扰邻居吧！”之类的话来拒绝访客。但坚持会让他疲惫不堪。一句“请”立刻就能突破，一句“谢谢”就赢得了热烈的告别。一旦有访客赢得了他的青睐，我就希望他能一直被吸引。没有人愿意与同一个车库门谈判两次。

这就是语音代理真正发挥作用的地方。您可以选择任何您喜欢的LLM。因为我希望系统能够脱离电网并且完全独立，所以我有一个内存和计算预算。

这个角色需要的不仅仅是“脾气暴躁”的提示。它必须遵循主对话流程，响应访客实际所说的内容，跟踪遭遇状态，并为管道的其余部分留下足够的计算能力。

在测试了十多个模型后，我选择了 [Bolt E4B](https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Bolt-E4B-4GB) 来提供实时对话。它是一个开放的小语言模型，专为本地会话代理和交互角色而构建，这是对会说话的车库门的合理描述。我使用 4 位量化版本（名称中的“4GB”）作为默认响应模型，并使用 [BF16 检查点](https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Bolt-E4B-4GB-BF16) 进行比较。

如果现在还不是很明显，我在 NVIDIA 工作，因此我能够在 Bolt E4B 公开发布之前对其进行测试，并发现它是一个可靠的选择，其占用空间比其他领先者 Qwen3 30B-A3B 和 Qwen 3.6 35B-A3B 更小。

它在 Nemotron 语音代理管道内工作，将访客所说的话转化为下一个适当的不情愿的答复。

博尔特提供了对话基础。我的提示、应用程序逻辑和 LoRA 适配器经过数千个经过审查的示例对话的训练，将其塑造成这艘特别顽固的船。

创建包含超过 5000 个多轮对话的数据集意味着我可以为每个我认为足够好的模型训练 LoRA。有些人花了大约一个小时来训练，有些人花了几个小时。当地代理运行了所有操作并对结果进行了基准测试。该代理和一个非常大的LLM首先创建并判断了数据集。这发生在晚上或我白天工作的时候。

LoRA 就位后，我会检查回复的连续性、时间和音调，基准模型和适配器的质量、重复性和速度，然后聆听表演。这座房子最终应该屈服，而不是变成一个令人愉快的看门人。一点点的抵抗也是魅力的一部分。与车库门无休止的争论并非如此。

### **值得等待的声音**

[![图片](https://cdn-uploads.huggingface.co/product/uploads/6ab2a746c7d0655b3d8dfbb9/iVLQ71tHCdvLRIuaJ6oLk.pn g)](https://cdn-uploads.huggingface.co/product/uploads/6ab2a746c7d0655b3d8dfbb9/iVLQ71tHCdvLRIuaJ6oLk.png)*两个快捷方式，两个输出。创作的文本会跳过新的对话生成，保存的音频会跳过合成。干净的言语驱动动画与观众效果分开。*

如果他投诉时间过长，鬼屋就会失去权威。在整个答案完成之前，管道会发布可朗读的文本，因此房子可以在句子的其余部分仍在进行中时开始说话。准备好的问候语和糖果笑话涵盖了熟悉的遭遇：文本库保存了语言模型工作，缓存的录音保存了语音合成。即使是脾气暴躁的人也能从排练中受益。
```
median end-of-speech-to-audio with Bolt Q4 & TTS = 1.70 seconds
median end-of-speech-to-audio cached responses = 0.72 seconds
(note: speech-end detection currently waits for 300 ms of silence )
```
[NVIDIA Magpie TTS Zeroshot](https://build.nvidia.com/nvidia/magpie-tts-zeroshot) 将文本转换为女王英语。其零样本语音调节使用短参考样本而不是经过训练的语音；我的提供了脾气暴躁的海盗角色。该房子有七种情绪，从脾气暴躁和威胁到有趣和高兴，由提示模板决定并由LLM提供的情绪标签选择每行的交付方式。由于每种情绪都需要不同的 3-10 秒语音样本，因此我在 UI 的工具选项卡上添加了“采样您的语音”块。然后，我可以用我最快乐的海盗或愤怒的海盗声音阅读并记录一行示例文本。当“开始”时间到时，Bolt E4B 决定要说什么，Magpie 将文本转化为带有适当的喜悦或绝望的语音。

接下来是 [Audio2Face-3D](https://github.com/NVIDIA/Audio2Face-3D) 和我在 Epic 的虚幻引擎中创建的 3D 角色场景。默认模型权重最适合干净、中性的男性或女性声音，不要太低沉，也不要太高（根据您的用例选择适当的性别模型）。我希望房子有一种非常低沉、恶魔般的声音，带有回声和室内乐。在这种情况下，由于我的声音样本没有那么戏剧化的分量，这实际上是一个好处。 Audio2Face-3D 从样本中获取清晰的语音，第二个音频流添加了可调节的实时声音效果，可在扬声器中播放。

为了让一切顺利运行，我将工作分配给一对 GPU：语言和语音模型管道在 NVIDIA RTX PRO 6000 Blackwell Max-Q 上运行，带有 Audio2Face-3D 的虚幻引擎图形在 NVIDIA RTX PRO 4000 Blackwell 上运行。内存不是问题，计算才是问题。无论代理管道正在进行什么处理，我都希望动画保持一致的帧速率。

声音、动画和效果必须结合在一起。一个令人信服的怪物需要的不仅仅是快速的答案；它需要听起来好像投诉属于建筑物。就我而言，他确实如此。可以进行同步音频传输的调整。我发现我可以设置它们并忘记它们。 （100ms 补偿 Audio2Face-3D 缓冲）

### **怪物有一个控制台**

一路走来，“让房子说话”需要一个充满控件的界面。我可以试听缓存的台词、调整开场气氛、跟随对话、更改语音处理并调整嘴巴动画。选项卡涵盖对话、模型选择、录音、提示、性能监控和摄像头反馈，音板和自定义对话字段让我可以把话放到他嘴里。还有模型加载控件和虚幻引擎连接指示器，因为有时怪物并不生闷气。他已断开连接。

[![图片](https://cdn-uploads.huggingface.co/product/uploads/6ab2a746c7d0655b3d8dfbb9/8AZqpHSWLOS4hpRwACGOY.pn g)](https://cdn-uploads.huggingface.co/product/uploads/6ab2a746c7d0655b3d8dfbb9/8AZqpHSWLOS4hpRwACGOY.png)* MonsterHouse 控制台，带有音板、自定义台词、开场气氛和对话流程。*

火焰和光芒也加入了这一行动。可编辑的规则将视觉提示与交付联系起来：现场提示从语音开始，而录制的表演可以遵循保存的时间线。我可以在不重建场景的情况下引导情绪的变化。

实时模式运行“不给糖就捣蛋”的角色。演示模式说服 The house 解释自己。麦克风模式让我可以直接在房子里说话，绕过识别、对话生成和语音合成。我干净的声音带动嘴巴；观众听到的是经过处理的版本。房子认为这是财产。我认为这是一个有用的后备。

### **下一次敲门**

[NVIDIA Nemotron 3 Nano Omni](https://huggingface.co/nvidia/Nemotron-3-Nano-Omni-30B-A3B-Reasoning-BF16) 是一款为房屋提供视觉环境的 VLM。作为可选的观察者，它解释摄像机图像并描述可见的服装，以便角色有特定的反应。我不想重新发明每一个轮子，而是选择了流行的对象检测和跟踪模型 YOLO 和 ByteTrack 来对当前视野中的人员进行计数和跟踪。将这些工作分开，可以让观众注意到一个群体，而无需要求 Omni 叙述每一帧。

为了进行一个相当荒谬的测试，我给 Omni 播放了一段五只穿着戏服的绵羊在门口的视频。它保存的分析确定了海盗、吸血鬼、女巫、南瓜和幽灵服装。这就是我希望房子使用的视觉环境。显然，连牲畜都有比我更详尽的万圣节计划。

[![图片](https://cdn-uploads.huggingface.co/product/uploads/6ab2a746c7d0655b3d8dfbb9/v5ff_abLrivfqmxH5ZPqf.pn g)](https://cdn-uploads.huggingface.co/product/uploads/6ab2a746c7d0655b3d8dfbb9/v5ff_abLrivfqmxH5ZPqf.png)*五在综合测试重播中非常毛茸茸的“不给糖就捣蛋”游戏。服装标签来自保存的 Omni 分析；框和轨道 ID 仅供说明。*

这些羊是一个综合测试，并不是万圣节之夜成功的证据。真实的车道组、服装和夜间照明仍需要测试。检测确实会触发自动问候，但我担心流行的服装识别和适当的机智反驳可能需要一些后期培训。由于房子没有眼睛，他称他的访客意识为回声定位。我让他拥有那个。

还有更多工作要做：动画总是可以改进，完整的性能测试需要真实的访问者，并且有一天会自动提供糖果。我还没有达到最初的目标，让他去管理万圣节，而我和家人一起去看其他邻居的食尸鬼。但这仍然是这一切的重点。有一天，一个孩子会遇到一栋脾气暴躁的老房子，尝试一点善意，就会发现这栋老木头也有柔软的地方。并分发棒棒糖。

### **塑造你自己的不讲道理的性格**

MonsterHouse 代码本身并未打包发布，但它使用的每个 NVIDIA 模型现已可用，并且 NVIDIA Nemotron 语音代理可以帮助您实现大部分功能。这就是我要走的路。

> 从语音管道开始。克隆 NVIDIA Nemotron Voice Agent 并运行通用助手示例。您将获得包含 Nemotron 语音 ASR、LLM 和 Magpie TTS 的级联管道，以及语音活动检测和话语结束处理，因此您的角色知道何时说话。  
> 让 Bolt E4B 成为大脑。语音代理包括用于云、服务器和单 GPU 部署的 Bolt E4B 配置文件。您可以首先在 build.nvidia.com 上尝试该模型。尝试对话模式以获得简短的语音就绪回复，并禁用推理以进行更简单的交流。  
> 赋予它个性。从系统提示符和一些连接的示例对话开始。在您的应用程序中保留对话状态，例如谁已经说了“请”，而不是要求模型记住它。当提示还不够时，训练一个 LoRA 适配器； NVIDIA NeMo AutoModel 为 Bolt E4B 提供了 LoRA 配方。  
> 给它一个声音。 Magpie TTS 多语言是语音代理的默认设置。对于自定义角色，Magpie TTS Zeroshot 根据简短的参考样本进行工作。在 build.nvidia.com 上尝试一下，并请求访问权限以自行运行它。 [确认：访问路径和链接] 仅使用您有权使用的声音。  
> 给它一个面孔。 NVIDIA Audio2Face-3D 将语音转换为角色的面部动画。给它提供干净的语音，然后添加效果。  
> 可选：给它眼睛。语音代理的 Nemotron Omni Assistant Subagents 示例添加了对 Nemotron 3 Nano Omni 的实时网络摄像头理解。如果您需要计数，请将其与轻型人员追踪器配对。

> 缓存的响应库和为您最常用的台词保存的音频将使即使是缓慢的怪物也感觉很快。  事实上，如果您碰巧受到计算能力的限制，那么您没有理由不能拥有一个仅使用 Nemotron 3 ASR（一个 Python 对话路由器）以及所有缓存音频的 Live 版本。  您可以使用 Bolt E4B 和 Magpie 管道离线生成 100 个响应，然后使用缓存进行显示。  我将为互动南瓜做这个。
