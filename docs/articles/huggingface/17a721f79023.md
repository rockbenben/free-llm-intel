# 让数千个开源 LLM 在 Vertex AI Model Garden 中绽放

今天，我们非常兴奋地宣布 **Deploy on Google Cloud** 正式上线——这是 Hugging Face Hub 上的一项新集成，可以用 Vertex AI 或 Google Kubernetes Engine (GKE) 把数千个基础模型轻松部署到 Google Cloud。Deploy on Google Cloud 让你能在自己的 Google Cloud 账户内把开放模型部署为 API Endpoint，既可以直接从 Hugging Face 模型卡发起，也可以在 Vertex Model Garden（Google Cloud 用于发现、定制和部署 Google 及 Google 合作伙伴各类模型的统一入口）中操作。从今天起，我们基于自己的生产级方案 [Text Generation Inference](https://github.com/huggingface/text-generation-inference/)，为最受欢迎的开放模型提供推理支持。

有了 Deploy on Google Cloud，开发者无需管理基础设施和服务器，就能直接在自己安全的 Google Cloud 环境中构建可生产的生成式 AI 应用。

## 一场为 AI 构建者而生的合作

这一新体验建立在我们[今年早些时候宣布的战略合作](https://huggingface.co/blog/gcp-partnership)之上，进一步简化 Google 客户访问和部署开放生成式 AI 模型的流程。开发者和组织面临的主要难题之一，是安全、可靠地部署模型所耗费的时间和资源。Deploy on Google Cloud 为这些挑战提供了一个简单、托管的解决方案，为 Hugging Face 模型提供专用配置和资产。整个过程只是简单的点击操作，就能在 Google Cloud 的 Vertex AI 上创建一个可生产的 Endpoint。

Google 产品经理 Wenming Ye 表示："Vertex AI 的 Model Garden 与 Hugging Face Hub 的集成，让发现和部署开放模型变得无比顺滑——无论你是在 Hub 上开始，还是直接进入 Google Cloud Console，都能在 Vertex AI 和 GKE 上部署。我们迫不及待想看到 Google 开发者用 Hugging Face 模型构建出什么。"

## 工作原理——从 Hub 出发

在 Google Cloud 上部署 Hugging Face 模型极其简单。下面手把手演示如何部署 [Zephyr Gemma](https://console.cloud.google.com/vertex-ai/publishers/HuggingFaceH4/model-garden/zephyr-7b-gemma-v0.1;hfSource=true;action=deploy?authuser=1)。从今天起，[所有带 "text-generation-inference"](https://huggingface.co/models?pipeline_tag=text-generation-inference&sort=trending) 标签的模型都将得到支持。

[![模型卡](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/google-cloud-model-garden/model-card.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/google-cloud-model-garden/model-card.png)

打开 "Deploy" 菜单，选择 "Google Cloud"。这会把你直接带到 Google Cloud Console，在那里你可以用 1 次点击在 Vertex AI 或 GKE 上部署 Zephyr Gemma。

[![vertex-ai-model-garden](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/google-cloud-model-garden/vertex-ai-model-garden.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/google-cloud-model-garden/vertex-ai-model-garden.png)

进入 Vertex Model Garden 后，你可以选择 Vertex AI 或 GKE 作为部署环境。用 Vertex AI 时，点击 "Deploy" 即可一键部署模型。用 GKE 时，可以按照说明和 manifest 模板把模型部署到新建或正在运行的 Kubernetes 集群上。

## 工作原理——从 Vertex Model Garden 出发

Vertex Model Garden 是 Google 开发者为生成式 AI 项目查找即用模型的地方。从今天起，Vertex Model Garden 带来全新体验，可以轻松部署 Hugging Face 上最受欢迎的开放 LLM！

你可以在 Google Vertex AI Model Garden 中找到新的 "Deploy From Hugging Face" 选项，直接在 Google Cloud 控制台内搜索并部署 Hugging Face 模型。

[![deploy-from-huggingface.png](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/google-cloud-model-garden/deploy-from-huggingface.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/google-cloud-model-garden/deploy-from-huggingface.png)

点击 "Deploy From Hugging Face" 后会弹出一个表单，可以快速搜索模型 ID。Hugging Face 上数百个最受欢迎的开放 LLM 都已备好经过测试、即开即用的硬件配置。

[![model-selection.png](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/google-cloud-model-garden/model-selection.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/google-cloud-model-garden/model-selection.png)

找到想部署的模型后选中它，Vertex AI 会预填好将模型部署到 Vertex AI 或 GKE 所需的全部配置。你甚至可以通过 "viewing it on Hugging Face" 确认自己选对了模型。如果使用的是受限访问（gated）模型，记得提供你的 Hugging Face access token，以便授权下载模型。

[![from-deploy.png](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/google-cloud-model-garden/from-deploy.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/google-cloud-model-garden/from-deploy.png)

就这样！从 Vertex Model Garden 直接把 Zephyr Gemma 这样的模型部署到你自己的 Google Cloud 账户，只需要几次点击。

## 我们才刚刚开始

我们非常兴奋能与 Google Cloud 协作，让 AI 更开放、更普惠。在 Google Cloud 上部署开放模型从未如此简单——无论你从 Hugging Face Hub 开始，还是在 Google Cloud 控制台内操作。而这还只是开始——敬请期待，我们将带来更多在 Google Cloud 上用开放模型构建 AI 的体验！
