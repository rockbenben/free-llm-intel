# 如何在 AWS 上部署和微调 DeepSeek 模型

作者：Simon Pagezy（pagezyhf）、Jeff Boudier（jeffboudier）、David Corvoysier（dacorvo）

这是一份持续更新的文档，演示如何用 Hugging Face 在 AWS 上部署和微调 DeepSeek R1 模型。

## 什么是 DeepSeek-R1？

如果你曾被一道难题卡住，就知道"多想一会儿、仔细推演"有多有用。[**OpenAI 的 o1 模型**](https://x.com/polynoamial/status/1834280155730043108)证明：当 LLM 被训练成也这么做——在推理时投入更多算力——它们在数学、编码、逻辑等推理任务上的能力会显著提升。

但 OpenAI 推理模型背后的配方一直严守秘密。直到上周，DeepSeek 发布了他们的 [**DeepSeek-R1**](https://huggingface.co/deepseek-ai/DeepSeek-R1) 模型，随即刷爆了互联网（和**股市**！）。

DeepSeek AI 开源了 DeepSeek-R1-Zero、DeepSeek-R1，以及六个基于 Llama 和 Qwen 架构、从 DeepSeek-R1 蒸馏出的稠密模型。全部见 [DeepSeek R1 合集](https://huggingface.co/collections/deepseek-ai/deepseek-r1-678e1e131c0169c0bc89728d)。

我们与 Amazon Web Services 合作，让开发者更容易在 AWS 服务上部署最新的 Hugging Face 模型，构建更好的生成式 AI 应用。

下面梳理如何用 Hugging Face 在 AWS 上部署和微调 DeepSeek R1 模型。

## 部署 DeepSeek R1 模型

### 用 Hugging Face Inference Endpoints 在 AWS 部署

[**Hugging Face Inference Endpoints**](https://ui.endpoints.huggingface.co/) 提供了一种简单安全的方式，把机器学习模型部署在 AWS 上的专属计算资源中用于生产。Inference Endpoints 让开发者和数据科学家都能创建 AI 应用而无需管理基础设施：几次点击完成部署，用自动扩缩容应对海量请求，用 scale-to-zero 降低基础设施成本，并提供高级安全能力。

用 Inference Endpoints，你可以部署 DeepSeek-R1 的 6 个蒸馏模型中的任意一个，也可以部署 Unsloth 制作的 DeepSeek R1 量化版：<https://huggingface.co/unsloth/DeepSeek-R1-GGUF>。在模型页面点击 Deploy，再选 HF Inference Endpoints。你会被重定向到 Inference Endpoint 页面——我们已经帮你选好了优化推理容器和运行该模型的推荐硬件。创建端点后，你就能以 8.3 美元/小时在 AWS 上向 DeepSeek R1 发查询 🤯。

在 [Inference Endpoints 模型目录](https://endpoints.huggingface.co/catalog?task=text-generation)中，你可以找到 DeepSeek R1 和蒸馏模型、以及其他热门开放 LLM，均已配置好优化部署方案。

#### GPU 上的蒸馏模型

你可以直接用 Jumpstart，或用 Python SageMaker SDK，通过 Hugging Face LLM DLC 把 DeepSeek 蒸馏模型部署到 Amazon SageMaker AI。下面这段视频演示如何在 AWS 控制台里操作：

[![jumpstart-deployment.gif](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/deepseek-aws/jumpstart-deployment.gif)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/deepseek-aws/jumpstart-deployment.gif)

看过了用 Jumpstart 部署，我们再走一遍用 Python SageMaker SDK 部署 DeepSeek-R1-Distill-Llama-70B。

代码片段可以在模型页面的 Deploy 按钮下拿到！

[![deploy_sagemaker_sdk.gif](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/deepseek-aws/deploy_sagemaker_sdk.gif)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/deepseek-aws/deploy_sagemaker_sdk.gif)

先说几个前置条件。确保你已经[配置好](https://docs.aws.amazon.com/sagemaker/latest/dg/onboard-quick-start.html) SageMaker Domain、在 SageMaker 有足够[配额](https://docs.aws.amazon.com/general/latest/gr/sagemaker.html)，并有一个 JupyterLab [空间](https://docs.aws.amazon.com/sagemaker/latest/dg/studio-updated-jl-user-guide-create-space.html)。对 DeepSeek-R1-Distill-Llama-70B，你需要把 ml.g6.48xlarge 用于端点的默认配额提到 1。

供参考，下面是我们对各蒸馏变体推荐的硬件配置：

| **模型** | **实例类型** | **每副本 GPU 数** |
| --- | --- | --- |
| deepseek-ai/DeepSeek-R1-Distill-Llama-70B | ml.g6.48xlarge | 8 |
| deepseek-ai/DeepSeek-R1-Distill-Qwen-32B | ml.g6.12xlarge | 4 |
| deepseek-ai/DeepSeek-R1-Distill-Qwen-14B | ml.g6.12xlarge | 4 |
| deepseek-ai/DeepSeek-R1-Distill-Llama-8B | ml.g6.2xlarge | 1 |
| deepseek-ai/DeepSeek-R1-Distill-Qwen-7B | ml.g6.2xlarge | 1 |
| deepseek-ai/DeepSeek-R1-Distill-Qwen-1.5B | ml.g6.2xlarge | 1 |

进入 notebook 后，确保安装最新版 SageMaker SDK。

```
!pip install sagemaker --upgrade
```

然后实例化一个 sagemaker_session，用来确定当前区域和执行角色。

```
import json
import sagemaker
import boto3
from sagemaker.huggingface import HuggingFaceModel, get_huggingface_llm_image_uri

try:
    role = sagemaker.get_execution_role()
except ValueError:
    iam = boto3.client("iam")
    role = iam.get_role(RoleName="sagemaker_execution_role")["Role"]["Arn"]
```

用 Python SDK 创建 SageMaker Model 对象：

```
model_id = "deepseek-ai/DeepSeek-R1-Distill-Llama-70B"
model_name = hf_model_id.split("/")[-1].lower()

# Hub Model configuration. https://huggingface.co/models
hub = {
    "HF_MODEL_ID": model_id,
    "SM_NUM_GPUS": json.dumps(8)
}

# create Hugging Face Model Class
huggingface_model = HuggingFaceModel(
    image_uri=get_huggingface_llm_image_uri("huggingface", version="3.0.1"),
    env=hub,
    role=role,
)
```

把模型部署到 SageMaker 端点并测试：

```
endpoint_name = f"{model_name}-ep"

# deploy model to SageMaker Inference
predictor = huggingface_model.deploy(
    endpoint_name=endpoint_name,
    initial_instance_count=1,
    instance_type="ml.g6.48xlarge",
    container_startup_health_check_timeout=2400,
)
  
# send request
predictor.predict({"inputs": "What is the meaning of life?"})
```

就这样，你部署了一个 Llama 70B 推理模型！

因为底层用的是 TGI v3 容器，针对给定硬件的最优参数会自动选择。

测试完成后记得删除端点。

```
predictor.delete_model()
predictor.delete_endpoint()
```

#### Neuron 上的蒸馏模型

再走一遍在 Neuron 实例（如 AWS Trainium 2 和 AWS Inferentia 2）上部署 DeepSeek-R1-Distill-Llama-70B 的流程。

代码片段可以在模型页面的 Deploy 按钮下拿到！

[![deploy_neuron.gif](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/deepseek-aws/deploy_neuron.gif)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/deepseek-aws/deploy_neuron.gif)

部署到 Neuron 实例的前置条件相同。确保已[配置好](https://docs.aws.amazon.com/sagemaker/latest/dg/onboard-quick-start.html) SageMaker Domain、有足够[配额](https://docs.aws.amazon.com/general/latest/gr/sagemaker.html)，并有 JupyterLab [空间](https://docs.aws.amazon.com/sagemaker/latest/dg/studio-updated-jl-user-guide-create-space.html)。对 DeepSeek-R1-Distill-Llama-70B，你需要把 `ml.inf2.48xlarge` 用于端点的默认配额提到 1。

然后实例化 `sagemaker_session`，用来确定当前区域和执行角色。

```
import json
import sagemaker
import boto3
from sagemaker.huggingface import HuggingFaceModel, get_huggingface_llm_image_uri

try:
    role = sagemaker.get_execution_role()
except ValueError:
    iam = boto3.client("iam")
    role = iam.get_role(RoleName="sagemaker_execution_role")["Role"]["Arn"]
```

用 Python SDK 创建 SageMaker Model 对象：

```
image_uri = get_huggingface_llm_image_uri("huggingface-neuronx", version="0.0.25")
model_id = "deepseek-ai/DeepSeek-R1-Distill-Llama-70B"
model_name = hf_model_id.split("/")[-1].lower()

# Hub Model configuration
hub = {
    "HF_MODEL_ID": model_id,
    "HF_NUM_CORES": "24",
    "HF_AUTO_CAST_TYPE": "bf16",
    "MAX_BATCH_SIZE": "4",
    "MAX_INPUT_TOKENS": "3686",
    "MAX_TOTAL_TOKENS": "4096",
}

# create Hugging Face Model Class
huggingface_model = HuggingFaceModel(
    image_uri=image_uri,
    env=hub,
    role=role,
)
```

把模型部署到 SageMaker 端点并测试：

```
endpoint_name = f"{model_name}-ep"

# deploy model to SageMaker Inference
predictor = huggingface_model.deploy(
    endpoint_name=endpoint_name,
    initial_instance_count=1,
    instance_type="ml.inf2.48xlarge",
    container_startup_health_check_timeout=3600,
    volume_size=512,
)
  
# send request
predictor.predict(
    {
        "inputs": "What is is the capital of France?",
        "parameters": {
            "do_sample": True,
            "max_new_tokens": 128,
            "temperature": 0.7,
            "top_k": 50,
            "top_p": 0.95,
        }
    }
)
```

就这样，你在 Neuron 实例上部署了一个 Llama 70B 推理模型！底层会自动从 Hugging Face 下载预编译模型，加快端点启动。

测试完成后记得删除端点。

```
predictor.delete_model()
predictor.delete_endpoint()
```

### 用 Hugging Face Neuron Deep Learning AMI 在 EC2 Neuron 上部署

本指南详述如何在 `inf2.48xlarge` AWS EC2 实例上导出、部署并运行 DeepSeek-R1-Distill-Llama-70B。

先说前置条件。确保你已在 [Marketplace](https://aws.amazon.com/marketplace/pp/prodview-gr3e6yiscria2) 订阅 Hugging Face Neuron Deep Learning AMI——它提供在 Trainium & Inferentia 上训练和部署 Hugging Face 模型所需的全部依赖。然后在 EC2 上用该 AMI 启动一个 inf2.48xlarge 实例并通过 SSH 连接。没操作过的话可以看我们的分步[指南](https://huggingface.co/docs/optimum-neuron/en/guides/setup_aws_instance)。

连上实例后，一条命令即可把模型部署到端点：

```
docker run -p 8080:80 \
    -v $(pwd)/data:/data \
    --device=/dev/neuron0 \
    --device=/dev/neuron1 \
    --device=/dev/neuron2 \
    --device=/dev/neuron3 \
    --device=/dev/neuron4 \
    --device=/dev/neuron5 \
    --device=/dev/neuron6 \
    --device=/dev/neuron7 \
    --device=/dev/neuron8 \
    --device=/dev/neuron9 \
    --device=/dev/neuron10 \
    --device=/dev/neuron11 \
    -e HF_BATCH_SIZE=4 \
    -e HF_SEQUENCE_LENGTH=4096 \
    -e HF_AUTO_CAST_TYPE="bf16" \
    -e HF_NUM_CORES=24 \
    ghcr.io/huggingface/neuronx-tgi:latest \
    --model-id deepseek-ai/DeepSeek-R1-Distill-Llama-70B \
    --max-batch-size 4 \
    --max-total-tokens 4096
```

从 Hugging Face 缓存下载编译好的模型并启动 TGI 端点需要几分钟。

然后测试端点：

```
curl localhost:8080/generate \
    -X POST \
    -d '{"inputs":"Why is the sky dark at night?"}' \
    -H 'Content-Type: application/json'
```

测试完成后记得暂停这台 EC2 实例。
