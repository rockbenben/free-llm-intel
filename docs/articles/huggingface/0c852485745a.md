# 🤗 Datasets 全新的音频与视觉文档

开放且可复现的数据集是推进优质机器学习的必需品。与此同时，作为大语言模型的"火箭燃料"，数据集的规模也在急剧增长。2020 年，Hugging Face 推出了 🤗 Datasets——一个专注于以下目标的库：

- 一行代码访问标准化数据集。
- 快速高效处理大规模数据集的工具。

多亏社区的力量，我们在 [Datasets Sprint](https://discuss.huggingface.co/t/open-to-the-community-one-week-team-effort-to-reach-v2-0-of-hf-datasets-library/2176) 中添加了数百种涵盖多种语言和方言的 NLP 数据集！🤗 ❤️

但文本数据集只是开始。数据还以更丰富的形态存在，比如 🎵 音频、📸 图像，甚至是音频加文本或图像加文本的组合。在这些数据集上训练的模型催生了令人惊叹的应用，例如描述图像内容或回答关于图像的问题。

🤗 Datasets 团队一直在构建工具和新特性，让这些数据集类型的处理尽可能简单，带来最佳的开发者体验。我们沿途补充了新文档，帮助你了解如何加载和处理音频与图像数据集。

## 快速上手

[Quickstart](https://huggingface.co/docs/datasets/quickstart)（快速上手）是新用户了解一个库功能 TLDR 的首选之地。因此我们更新了 Quickstart，加入如何使用 🤗 Datasets 处理音频和图像数据集的内容。选择你想处理的数据模态，即可看到端到端示例，演示如何加载并处理数据集、为 PyTorch 或 TensorFlow 训练做好准备。

Quickstart 中另一个新内容是 `to_tf_dataset` 函数，它把数据集转换为 `tf.data.Dataset`，就像熊妈妈呵护幼崽一样省心。这意味着你不必写任何 shuffle 或加载 batch 的代码，就能让数据集与 TensorFlow 良好配合。一旦把数据集转成 `tf.data.Dataset`，就可以用惯常的 TensorFlow 或 Keras 方法训练模型。

现在就去看 [Quickstart](https://huggingface.co/docs/datasets/quickstart)，学习如何处理不同数据模态的数据集，并试用新的 `to_tf_dataset` 函数！

挑选属于你的数据集冒险吧！

## 专项指南

每种数据模态在加载和处理上都有各自的细节。例如，加载音频数据集时，音频信号会由 `Audio` 特性自动即时解码并重采样。这与加载文本数据集大不相同！

为了让各模态专属文档更易发现，我们新增了专门的章节，聚焦讲解如何加载和处理每种模态。如果你在寻找某种数据模态的具体信息，先看这些专门章节。与此同时，通用型的、可广泛使用的函数记录在 General Usage（通用用法）章节。按这种方式重组文档，也能让我们更好地扩展到未来计划支持的其他数据类型。

这些指南按章节组织，覆盖 🤗 Datasets 最核心的方面。

查阅[专项指南](https://huggingface.co/docs/datasets/how_to)，了解更多关于加载和处理不同模态数据集的内容。

## ImageFolder

通常，🤗 Datasets 用户需要[编写数据集加载脚本](https://huggingface.co/docs/datasets/dataset_script)来下载并生成带有合适 `train` 和 `test` 划分的数据集。而有了 `ImageFolder` 数据集构建器，你无需写任何代码就能下载并生成图像数据集。加载用于图像分类的图像数据集，只需要把数据组织成这样的目录结构：

```
folder/train/dog/golden_retriever.png
folder/train/dog/german_shepherd.png
folder/train/dog/chihuahua.png

folder/train/cat/maine_coon.png
folder/train/cat/bengal.png
folder/train/cat/birman.png
```

把 🐶 数据集上传到 Hub 并预览时，它看起来应该大致如此。

图像标签会根据目录名生成并存入 `label` 列。`ImageFolder` 让你即刻上手图像数据集，省去了编写数据集加载脚本的时间与精力。

等等，还有更好的！如果你有一个包含图像数据集元信息的文件，`ImageFolder` 还能用于图像描述（image captioning）、目标检测等其他图像任务。例如，目标检测数据集通常带有*边界框（bounding boxes）*——图中标识物体位置的坐标。`ImageFolder` 可以利用这个文件，把每张图的边界框和类别元数据与文件夹中对应的图像关联起来：

```
{"file_name": "0001.png", "objects": {"bbox": [[302.0, 109.0, 73.0, 52.0]], "categories": [0]}}
{"file_name": "0002.png", "objects": {"bbox": [[810.0, 100.0, 57.0, 28.0]], "categories": [1]}}
{"file_name": "0003.png", "objects": {"bbox": [[160.0, 31.0, 248.0, 616.0], [741.0, 68.0, 202.0, 401.0]], "categories": [2, 2]}}

dataset = load_dataset("imagefolder", data_dir="/path/to/folder", split="train")
dataset[0]["objects"]
{"bbox": [[302.0, 109.0, 73.0, 52.0]], "categories": [0]}
```

只要你有包含所需信息的元数据文件，就可以用 `ImageFolder` 为几乎任何类型的图像任务加载数据集。更多细节见 [ImageFolder](https://huggingface.co/docs/datasets/image_load) 指南。

## 接下来是什么？

正如 🤗 Datasets 库的第一代产品把文本数据集标准化、让其下载和处理变得极其简单一样，我们非常兴奋地把同等级别的易用性带到音频和图像数据集上。我们希望通过这一切，用户能更轻松地跨各种模态训练、构建和评估模型与应用。

未来几个月，我们会持续增加新特性和工具来支持音频与图像数据集的处理。🤗 Hugging Face 内部的"小道消息"是：一个叫 `AudioFolder` 的东西很快就来！🤫 等待之余，欢迎看看[音频处理指南](https://huggingface.co/docs/datasets/audio_process)，然后动手试试像 [GigaSpeech](https://huggingface.co/datasets/speechcolab/gigaspeech) 这样的音频数据集。

关于处理音频和图像数据集有任何疑问或反馈，欢迎加入[论坛](https://discuss.huggingface.co/)。如果发现任何 bug，请开一个 [GitHub Issue](https://github.com/huggingface/datasets/issues/new/choose)，我们会来处理。

想更冒险一点？来为 [Hub](https://huggingface.co/datasets) 上不断壮大的社区驱动音频与图像数据集集合贡献一份力量！在 Hub 上[创建数据集仓库](https://huggingface.co/docs/datasets/upload_dataset)并上传你的数据集。如果需要帮助，就在你仓库的 **Community tab** 发起讨论，并 @ 一位 🤗 Datasets 团队成员，帮你冲过终点线！
