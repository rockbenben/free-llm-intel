## 教程

我们将使用新的 [Hugging Face DLC](https://github.com/aws/deep-learning-containers/tree/master/huggingface) 和 [Amazon SageMaker 扩展](https://sagemaker.readthedocs.io/en/stable/frameworks/huggingface/sagemaker.huggingface.html#huggingface-estimator)，用 `transformers` 和 `datasets` 库在 `summarization`（摘要）任务上训练一个分布式 Seq2Seq-transformer 模型，然后把模型上传到 [huggingface.co](http://huggingface.co) 并测试它。

至于 [分布式训练策略](https://huggingface.co/transformers/sagemaker.html#distributed-training-data-parallel)，我们将使用 [SageMaker Data Parallelism](https://aws.amazon.com/blogs/aws/managed-data-parallelism-in-amazon-sagemaker-simplifies-training-on-large-datasets/)，它已被内置进 [Trainer](https://huggingface.co/transformers/main_classes/trainer.html) API。要使用数据并行，我们只需在 `HuggingFace` estimator 里定义 `distribution` 参数。

```
# configuration for running training on smdistributed Data Parallel
distribution = {'smdistributed':{'dataparallel':{ 'enabled': True }}}
```

本教程中，我们用一台 Amazon SageMaker Notebook Instance 来运行训练任务。你可以 [在这里学习如何设置一台 Notebook Instance](https://docs.aws.amazon.com/sagemaker/latest/dg/nbi.html)。

**我们要做什么：**

- 搭建开发环境并安装 sagemaker
- 选择 🤗 Transformers `examples/` 脚本
- 配置分布式训练和超参数
- 创建一个 `HuggingFace` estimator 并开始训练
- 把微调后的模型上传到 [huggingface.co](http://huggingface.co)
- 测试推理

#### 模型与数据集

我们要在 [samsum](https://huggingface.co/datasets/samsum) 数据集上微调 [facebook/bart-large-cnn](https://huggingface.co/facebook/bart-large-cnn)。*"BART 是一个序列到序列模型，以去噪作为预训练目标。"* [[REF](https://github.com/pytorch/fairseq/blob/master/examples/bart/README.md)]

`samsum` 数据集包含约 1.6 万条带摘要的、类似即时通讯的对话。

```
{"id": "13818513",
 "summary": "Amanda baked cookies and will bring Jerry some tomorrow.",
 "dialogue": "Amanda: I baked cookies. Do you want some?\r\nJerry: Sure!\r\nAmanda: I'll bring you tomorrow :-)"}
```

## 选择 🤗 Transformers `examples/` 脚本

[🤗 Transformers 仓库](https://github.com/huggingface/transformers/tree/master/examples) 包含若干 `examples/` 脚本，用于对从 `language-modeling` 到 `token-classification` 的任务做微调。就我们的情况而言，使用 `seq2seq/` 示例里的 `run_summarization.py`。

***注意**：你可以照搬本教程，在不同的 examples 脚本上训练你的模型。*

由于 `HuggingFace` Estimator 内置了 git 支持，我们可以把一个 [存在 GitHub 仓库里的训练脚本](https://sagemaker.readthedocs.io/en/stable/overview.html#use-scripts-stored-in-a-git-repository) 指定为 `entry_point` 和 `source_dir`。

我们将使用 `transformers 4.4.2` DLC，这意味着需要把分支配置为 `v4.4.2` 以拉取兼容的示例脚本。

```
#git_config = {'repo': 'https://github.com/huggingface/transformers.git','branch': 'v4.4.2'} # v4.4.2 is referring to the `transformers_version you use in the estimator.
# used due an missing package in v4.4.2 
git_config = {'repo': 'https://github.com/philschmid/transformers.git','branch': 'master'} # v4.4.2 is referring to the `transformers_version you use in the estimator.
```

### 配置分布式训练和超参数

接下来，我们定义 `hyperparameters` 并配置分布式训练策略。作为超参数，我们可以定义任意 [Seq2SeqTrainingArguments](https://huggingface.co/transformers/main_classes/trainer.html#seq2seqtrainingarguments) 以及 [run_summarization.py](https://github.com/huggingface/transformers/tree/main/examples/legacy/seq2seq#sequence-to-sequence-training-and-evaluation) 中定义的那些。

```
# hyperparameters, which are passed into the training job
hyperparameters={
    'per_device_train_batch_size': 4,
    'per_device_eval_batch_size': 4,
    'model_name_or_path':'facebook/bart-large-cnn',
    'dataset_name':'samsum',
    'do_train':True,
    'do_predict': True,
    'predict_with_generate': True,
    'output_dir':'/opt/ml/model',
    'num_train_epochs': 3,
    'learning_rate': 5e-5,
    'seed': 7,
    'fp16': True,
}

# configuration for running training on smdistributed Data Parallel
distribution = {'smdistributed':{'dataparallel':{ 'enabled': True }}}
```

由于我们使用 [SageMaker Data Parallelism](https://aws.amazon.com/blogs/aws/managed-data-parallelism-in-amazon-sagemaker-simplifies-training-on-large-datasets/)，我们的 `total_batch_size` 将是 `per_device_train_batch_size` * `n_gpus`。

### 创建 `HuggingFace` estimator 并开始训练

训练前的最后一步是创建一个 `HuggingFace` estimator。Estimator 负责端到端的 Amazon SageMaker 训练。我们定义哪个微调脚本应被用作 `entry_point`、应使用哪个 `instance_type`，以及传入哪些 `hyperparameters`。

```
from sagemaker.huggingface import HuggingFace

# create the Estimator
huggingface_estimator = HuggingFace(
      entry_point='run_summarization.py', # script
      source_dir='./examples/seq2seq', # relative path to example
      git_config=git_config,
      instance_type='ml.p3dn.24xlarge',
      instance_count=2,
      transformers_version='4.4.2',
      pytorch_version='1.6.0',
      py_version='py36',
      role=role,
      hyperparameters = hyperparameters,
      distribution = distribution
)
```

`instance_type` 我们用 `ml.p3dn.24xlarge`，它含 8x NVIDIA A100，`instance_count` 为 2。这意味着我们将在 16 块 GPU 上运行训练，`total_batch_size` 为 16*4=64。我们要用 64 的 `total_batch_size` 训练一个 4 亿参数模型，简直是哇塞。开始训练时调用 `.fit()` 方法。

```
# starting the training job
huggingface_estimator.fit()
```

### 把微调后的模型上传到 [huggingface.co](http://huggingface.co)

既然我们的模型取得了相当不错的分数，我们要把它上传到 [huggingface.co](http://huggingface.co)，创建一个 `model_card`，并用 Hosted Inference 组件测试它。上传模型需要 [在这里创建一个账号](https://huggingface.co/join)。

我们可以用下面的片段从 Amazon S3 下载模型并解压。

```
import os
import tarfile
from sagemaker.s3 import S3Downloader

local_path = 'my_bart_model'

os.makedirs(local_path, exist_ok = True)

# download model from S3
S3Downloader.download(
    s3_uri=huggingface_estimator.model_data, # s3 uri where the trained model is located
    local_path=local_path, # local path where *.tar.gz will be saved
    sagemaker_session=sess # sagemaker session used for training the model
)

# unzip model
tar = tarfile.open(f"{local_path}/model.tar.gz", "r:gz")
tar.extractall(path=local_path)
tar.close()
os.remove(f"{local_path}/model.tar.gz")
```

在把模型上传到 [huggingface.co](http://huggingface.co) 之前，我们需要创建一个 `model_card`。`model_card` 描述模型，包含超参数、结果，并指明训练用了哪个数据集。要创建 `model_card`，我们在 `local_path` 里创建一个 `README.md`

```
# read eval and test results 
with open(f"{local_path}/eval_results.json") as f:
    eval_results_raw = json.load(f)
    eval_results={}
    eval_results["eval_rouge1"] = eval_results_raw["eval_rouge1"]
    eval_results["eval_rouge2"] = eval_results_raw["eval_rouge2"]

    eval_results["eval_rougeLsum"] = eval_results_raw["eval_rougeLsum"]

with open(f"{local_path}/test_results.json") as f:
    test_results_raw = json.load(f)
    test_results={}
    test_results["test_rouge1"] = test_results_raw["test_rouge1"]
    test_results["test_rouge2"] = test_results_raw["test_rouge2"]
    test_results["test_rougeL"] = test_results_raw["test_rougeL"]
    test_results["test_rougeLsum"] = test_results_raw["test_rougeLsum"]
```

在 `my_bart_model` 里有了已解压的模型和模型卡之后，我们可以用 `huggingface_hub` SDK 创建一个仓库并上传到 [huggingface.co](https://huggingface.co)——或者直接到 [https://huggingface.co/new](https://huggingface.co/new) 创建一个新仓库并上传。

```
from getpass import getpass
from huggingface_hub import HfApi, Repository

hf_username = "philschmid" # your username on huggingface.co
hf_email = "philipp@huggingface.co" # email used for commit
repository_name = f"{hyperparameters['model_name_or_path'].split('/')[1]}-{hyperparameters['dataset_name']}" # repository name on huggingface.co
password = getpass("Enter your password:") # creates a prompt for entering password

# get hf token
token = HfApi().login(username=hf_username, password=password)

# create repository
repo_url = HfApi().create_repo(token=token, name=repository_name, exist_ok=True)

# create a Repository instance
model_repo = Repository(use_auth_token=token,
                        clone_from=repo_url,
                        local_dir=local_path,
                        git_user=hf_username,
                        git_email=hf_email)

# push model to the hub
model_repo.push_to_hub()
```
