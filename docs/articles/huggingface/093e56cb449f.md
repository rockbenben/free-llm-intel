# 用块稀疏矩阵打造更小更快的语言模型

## 省空间、省时间，一个零一个零地节省

在之前的[博客](https://medium.com/huggingface/is-the-future-of-neural-networks-sparse-an-introduction-1-n-d03923ecbd70)和[文章](https://medium.com/huggingface/sparse-neural-networks-2-n-gpu-performance-b8bc9ce950fc)中，我们介绍了稀疏矩阵，以及它们能为神经网络带来哪些改进。

基本假设是：完整的稠密层（dense layer）往往是过剩的，可以在不显著损失精度的情况下加以剪枝。某些情况下，稀疏线性层甚至可以*提升精度和/或泛化能力*。

主要问题在于，目前可用的支持稀疏代数计算的代码严重缺乏效率。而我们也[仍在等待](https://openai.com/blog/openai-pytorch/) PyTorch 的官方支持。

正因如此，我们不再等待，今年夏天抽时间填补了这个"空白"。今天，我们兴奋地**发布扩展库 [pytorch_block_sparse](https://github.com/huggingface/pytorch_block_sparse)**。

无论是独立使用，还是更好地与[蒸馏（distillation）](https://medium.com/huggingface/distilbert-8cf3380435b5)和[量化（quantization）](https://medium.com/microsoftazure/faster-and-smaller-quantized-nlp-with-hugging-face-and-onnx-runtime-ec5525473bb7)等其他方法结合，这个库都能构建出既**更小又更快**的**网络**——Hugging Face 认为这对于让任何人以**低成本**在生产环境中使用神经网络、并**改善最终用户体验**至关重要。

## 用法

所提供的 `BlockSparseLinear` 模块可以直接替换 `torch.nn.Linear`，在你的模型中使用它非常简单：

```
# from torch.nn import Linear
from pytorch_block_sparse import BlockSparseLinear

...

# self.fc = nn.Linear(1024, 256)
self.fc = BlockSparseLinear(1024, 256, density=0.1)
```

该扩展还提供了 `BlockSparseModelPatcher`，可以"就地"修改现有模型，这一点在这个[示例 notebook](https://github.com/huggingface/pytorch_block_sparse/blob/master/doc/notebooks/ModelSparsification.ipynb)中有所展示。这样的模型随后可以照常训练，无需更改你的模型源代码。

## NVIDIA CUTLASS

本扩展基于 [Yulhwa Kim](https://github.com/YulhwaKim) 的 [cutlass tilesparse](https://github.com/YulhwaKim/cutlass_tilesparse) 概念验证实现。

它使用基于 **[CUTLASS](https://developer.nvidia.com/blog/cutlass-linear-algebra-cuda/)** 的 **C++ CUDA 模板**来实现块稀疏（block-sparse）矩阵乘法。

CUTLASS 是一系列 CUDA C++ 模板的集合，用于实现高性能 CUDA kernel。借助 CUTLASS，无需编写汇编语言代码，就有可能在自定义 kernel 上逼近 cuBLAS 的性能。

最新版本包含了所有 **Ampere Tensor Core 原语**，在有限精度损失下带来 **10 倍甚至更高的加速**。pytorch_block_sparse 的后续版本将利用这些原语，因为块稀疏与 Tensor Core 的要求 100% 兼容。

## 性能

就库的当前阶段而言，稀疏矩阵的性能大约比经过 cuBLAS 优化的稠密对应版本慢约两倍，我们有信心在未来进一步改进。

这相对 PyTorch 稀疏矩阵已是巨大提升：PyTorch 目前的实现比稠密实现慢了一个数量级。

但更重要的是，使用稀疏矩阵带来的性能收益会随稀疏度增长，因此一个 **75% 稀疏的矩阵**大约比等效稠密矩阵**快 2 倍**。

内存节省更为显著：在 **75% 稀疏度**下，如你所料，内存消耗可降低至原来的 **1/4**。

## 未来工作

能够高效地训练块稀疏线性层只是第一步。稀疏模式（sparsity pattern）目前在初始化时就固定下来，而在学习过程中对其进行优化，无疑会带来大幅提升。

因此在未来版本中，你可以期待一些工具来衡量参数的"有用性"，从而**优化稀疏模式**。**NVIDIA Ampere 的块内 50% 稀疏模式**可能又会带来一次显著的性能提升，就如同升级到更新版本的 CUTLASS 一样。

所以，敬请期待近期更多关于稀疏性的好消息！
