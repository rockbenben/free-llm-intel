# 推出 LiveCodeBench 排行榜——代码 LLM 的整体、无污染评估

我们很高兴地推出 [LiveCodeBench 排行榜](https://huggingface.co/spaces/livecodebench/leaderboard)。它基于 LiveCodeBench——一个由 UC Berkeley、MIT 和 Cornell 研究人员开发的新基准，用于度量 LLM 的代码生成能力。

LiveCodeBench 按时间从各大编程竞赛平台收集题目，并标注每道题的发布时间。这些标注让模型可以在不同时间窗口发布的题集上接受评测，从而支持"随时间评估"的策略，帮助检测和防止数据污染。除了常规的代码生成任务，LiveCodeBench 还评估自我修复（self-repair）、测试输出预测和代码执行，为下一代 AI 编程智能体所需的编码能力提供更整体的视角。

## LiveCodeBench 场景与评估

LiveCodeBench 的题目精选自编程竞赛平台：LeetCode、AtCoder 和 CodeForces。这些网站定期举办竞赛，题目考察参赛者的编程与解题能力。每道题包含一段自然语言题面和示例输入输出，目标是写出能通过一组隐藏测试的程序。每场比赛都有数千名参与者，这保证了题目在清晰度和正确性上经过了充分检验。

LiveCodeBench 用收集到的题目构建了四个编程场景：

- **代码生成（Code Generation）。** 给模型题目描述（含自然语言说明和示例测试，即输入输出对），让它生成正确解法。评估基于生成代码的功能正确性，由一组测试用例判定。
- **自我修复（Self Repair）。** 和上面的代码生成场景一样，模型拿到题面并生成候选程序；若出错，则把错误反馈（异常信息或失败的测试用例）给它，让它生成修复。评估使用同样的功能正确性指标。
- **代码执行（Code Execution）。** 给模型一段由函数（f）加一个测试输入组成的程序片段，让它预测程序在该测试输入上的输出。评估基于执行式正确性指标：只要断言 `assert f(input) == generated_output` 通过，模型的输出就算正确。
- **测试输出预测（Test Output Prediction）。** 给模型题面加一个测试输入，让它生成该输入的期望输出。测试完全由题面生成，不需要函数的实现，输出用精确匹配校验评估。

[![场景总览](https://livecodebench.github.io/images/LCB_holistic_tasks.png)](https://livecodebench.github.io/images/LCB_holistic_tasks.png)

每个场景都用 Pass@1 指标评估。该指标刻画生成正确答案的概率，按正确回答数占总尝试数的比值计算，即 `Pass@1 = total_correct / total_attempts`。

## 防止基准污染

污染是当前 LLM 评估的主要瓶颈之一。即便在 LLM 编码评估领域，也已有关于 HumanEval 等标准基准被污染和过拟合的实证报告（[[1]](https://arxiv.org/abs/2403.05530) 和 [[2]](https://arxiv.org/abs/2311.04850)）。

正因如此，LiveCodeBench 给每道题标注发布日期：这样，对于训练截止日期为 D 的新模型，我们可以在 D 之后发布的题目上计算得分，度量它对未见问题的泛化能力。

LiveCodeBench 用"随时间滚动（scrolling over time）"特性把这一做法正式固化下来——你可以选择特定时间窗口内的题目。在上面的排行榜里就能体验！

## 发现

我们发现：

- 虽然模型表现跨不同场景大体相关，但在我们使用的 4 个场景上，相对表现和排序会有变化
- `GPT-4-Turbo` 在多数场景中表现最佳。并且它在自我修复任务上的优势更大，凸显其采纳编译器反馈的能力。
- `Claude-3-Opus` 在测试输出预测场景上反超 `GPT-4-Turbo`，显示出更强的自然语言推理能力。
- `Mistral-Large` 在测试输出预测、代码执行这类自然语言推理任务上明显表现更好。

## 如何提交？

要在 LiveCodeBench 上评估你的代码模型，可按以下步骤：

- 环境设置：可以用 conda 创建一个新环境并安装 LiveCodeBench

```
git clone https://github.com/LiveCodeBench/LiveCodeBench.git 
cd LiveCodeBench
pip install poetry
poetry install
```

- 评估新的 Hugging Face 模型，你可以很方便地用

```
python -m lcb_runner.runner.main --model {model_name} --scenario {scenario_name}
```

来评估不同场景。对新模型家族，我们实现了可扩展框架：按 [github README](https://github.com/LiveCodeBench/LiveCodeBench) 所述修改 `lcb_runner/lm_styles.py` 和 `lcb_runner/prompts` 即可支持新模型。

- 结果生成后，填写[这个表单](https://forms.gle/h2abvAHh6UnhWzzd9)提交。
