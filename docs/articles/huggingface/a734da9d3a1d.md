[llama.cpp × AMD Benchmark](https://ggml-org-llamacpp-amd-bench.static.hf.space/index.html) 仪表盘现已在 Hugging Face 上线。它让你可以跨不同的 llama.cpp 构建、模型和量化方式，跟踪 prompt 处理与文本生成的性能，从而探索本地推理在 AMD Ryzen 和 Radeon 硬件上的表现。

本地推理性能会随着模型、kernel 和构建的演进而变化。我们希望任何 AMD 开发者都能轻松查看这些变化：选择硬件、模型和构建，比较不同量化，并持续跟踪性能随时间的变化。基准测试工作流和底层结果都是公开的，因此你也可以查看我们是如何对推理性能进行基准测试的。

## 快速开始

你可以在 Configuration 侧边栏中选择 **Hardware**、**Model** 和 **llama.cpp build**。当前可选的硬件为 Radeon 8060S (gfx1151) 和 Radeon AI Pro R9700S (gfx1201)。

- 在 **Overview** 标签页中，针对同一硬件、模型和构建比较不同量化。两张图表分别显示 PP512（512 个输入 token，不生成）和 TG128（生成 128 个 token），两者都从上下文深度零开始。
- 在 **Build history** 标签页中，跟踪所选硬件、模型和量化下所有已记录构建的 PP512 与 TG128。
- 在 **Context** **scaling** 标签页中，查看在所选构建、硬件、模型和量化下，token 生成吞吐量随已有上下文增长的变化情况。

## 这些数字的含义

仪表盘展示两项独立的测试，均以每秒 token 数计量：

| 测试 | 负载 | 有助于评估的内容 |
| --- | --- | --- |
| **PP512** | 处理 512 个输入 token | 模型处理 prompt 的速度 |
| **TG128** | 生成 128 个 token | 模型产出输出的速度 |

两项测试都从上下文深度零（`n_depth=0`）开始。PP512 衡量在不生成的情况下处理 512 个输入 token；TG128 衡量在没有既有上下文的情况下生成 128 个 token。图表中绘制的数值是平均吞吐量（`avg_ts`）。这些是有用的参考负载，而 Context scaling 标签页则让你探索 token 生成吞吐量随上下文增长的变化。

## 我们如何运行基准测试

我们基准测试的对象是通过 [llama-install.sh](https://github.com/ggml-org/llama-install.sh) 分发的预编译二进制文件，该项目是 [llama.app](https://llama.app/) 背后的构建与安装项目。公开的 [gfx1151](https://github.com/ggml-org/llama-install.sh/blob/master/.github/workflows/bench-gfx1151.yml) 和 [gfx1201](https://github.com/ggml-org/llama-install.sh/blob/master/.github/workflows/bench-gfx1201.yml) 工作流每周定时运行，使用 [llama-bench 工具](https://github.com/ggml-org/llama.cpp/tree/master/tools/llama-bench) 在 Flash Attention 开启和关闭两种情况下运行标准基准测试，每个配置重复 10 次。

模型集合会不断演进，目前包括 Inkling 2 Mini、Qwen、Gemma、gpt-oss 和 LFM 模型，涵盖 dense 与 mixture-of-experts（混合专家）架构。可用的 GGUF 格式包括 `Q4_K_M`、`Q8_0`、其他量化格式，以及 `BF16` 和 `F16` 等更高精度的格式。

## 查看并复用结果

探索器直接读取 Hugging Face 上公开的 [ggml-org/install.sh-benches-data Storage Bucket](https://huggingface.co/buckets/ggml-org/install.sh-benches-data)。图表标题旁的 **data source** 链接会打开所选构建、硬件和模型对应的文件夹。

标准结果使用 `<build>/<hardware>/<model>/<quant>.jsonl`。负载扫描在同一文件夹下使用 `<quant>-tg.jsonl` 文件名。

你可以用它们来调查某个结果、制作自己的图表，或与本地运行结果进行比较。
