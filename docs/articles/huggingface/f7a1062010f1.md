Gemma 3n 在 Google I/O 上以*预览*形式公布。端侧社区非常兴奋，因为这是一个从底层设计、用来在你的硬件上 **本地运行** 的模型。不仅如此，它还是原生 **多模态** 的，支持图像、文本、音频和视频输入 🤯

今天，Gemma 3n 终于上线了最常用的开源库，包括 transformers & timm、MLX、llama.cpp（文本输入）、transformers.js、ollama、Google AI Edge 等。

本文用一些实用代码片段演示如何在这些库里使用这个模型，以及为其他领域微调它有多容易。

## 今天发布的模型

> 这是 Gemma 3n 发布合集

今天发布了两种模型大小，每种都有两个变体（base 基座与 instruct 指令）。模型名采用了一套非标准命名法：它们叫 `gemma-3n-E2B` 和 `gemma-3n-E4B`。参数数量前的 `E` 代表 `Effective`（等效）。它们的实际参数量分别是 `5B` 和 `8B`，但得益于内存效率的改进，它们只需 2B 和 4B 的 VRAM（GPU 显存）。

因此，这些模型在硬件支持上表现得像 2B 和 4B，但在质量上却超过 2B/4B。`E2B` 模型最少可以在 2GB GPU 显存上运行，而 `E4B` 只需 3GB GPU 显存即可运行。

| 大小 | Base | Instruct |
| --- | --- | --- |
| 2B | [google/gemma-3n-e2b](https://hf.co/google/gemma-3n-e2b) | [google/gemma-3n-e2b-it](https://hf.co/google/gemma-3n-e2b-it) |
| 4B | [google/gemma-3n-e4b](https://hf.co/google/gemma-3n-e4b) | [google/gemma-3n-e4b-it](https://hf.co/google/gemma-3n-e4b-it) |

## 模型细节

除了语言解码器，Gemma 3n 还使用一个 **音频编码器** 和一个 **视觉编码器**。我们在下面列出它们的主要特性，并说明它们如何被加入 `transformers` 和 `timm`，因为这两个实现是其他实现的参考。

- **视觉编码器（MobileNet-V5）。** Gemma 3n 使用了 MobileNet 的一个新版本：MobileNet-v5-300，它已被加入今天发布的新版 `timm`。特性：3 亿参数。支持 `256x256`、`512x512` 和 `768x768` 分辨率。在 Google Pixel 上达到 60 FPS，用少 3 倍的参数超过了 ViT Giant。
- **音频编码器：** 基于通用语音模型（Universal Speech Model，USM）。以 `160ms` 的块处理音频。支持语音转文本和翻译功能（例如英语到西班牙语/法语）。
- **Gemma 3n 架构与语言模型。** 架构本身已被加入今天发布的新版 `transformers`。该实现会派生到 `timm` 来做图像编码，因此 MobileNet 架构只有一个参考实现。

### 架构亮点

- **MatFormer 架构：** 一种嵌套 transformer 设计，类似套娃（Matryoshka）嵌入，允许把各层子集提取出来当作独立模型。E2B 和 E4B 是一起训练的，把 E2B 配置为 E4B 的子模型。用户可以根据硬件特性和内存预算"混搭"层。
- **逐层嵌入（Per-Layer Embeddings，PLE）：** 把嵌入卸载到 CPU，从而降低加速器内存占用。这就是为什么 E2B 模型虽然实际有 5B 参数，却只占用大致相当于 2B 参数模型的 GPU 显存。
- **KV 缓存共享：** 加速音频和视频的长上下文处理，prefill 比 Gemma 3 4B 快 2 倍。

### 性能与基准：

- **LMArena 分数：** E4B 是第一个达到 1300+ 分数的 10B 以下模型。
- **MMLU 分数：** Gemma 3n 在各个尺寸（E4B、E2B 以及若干 Mix-n-Match 配置）上表现出有竞争力的性能。
- **多语言支持：** 文本支持 140 种语言，多模态交互支持 35 种语言。

## 用 transformers 推理

运行推理（或要微调）请安装最新版 timm（用于视觉编码器）和 transformers。

```
pip install -U -q timm
pip install -U -q transformers
```

### 用 pipeline 推理

上手 Gemma 3n 最简单的方式是用 transformers 里的 pipeline 抽象：

```
import torch
from transformers import pipeline

pipe = pipeline(
   "image-text-to-text",
   model="google/gemma-3n-E4B-it", # "google/gemma-3n-E4B-it"
   device="cuda",
   torch_dtype=torch.bfloat16
)

messages = [
   {
       "role": "user",
       "content": [
           {"type": "image", "url": "https://huggingface.co/datasets/ariG23498/demo-data/resolve/main/airplane.jpg"},
           {"type": "text", "text": "Describe this image"}
       ]
   }
]

output = pipe(text=messages, max_new_tokens=32)
print(output[0]["generated_text"][-1]["content"])
```

输出：

```
The image shows a futuristic, sleek aircraft soaring through the sky. It's designed with a distinctive, almost alien aesthetic, featuring a wide body and large
```

### 用 transformers 做详细推理

从 Hub 初始化模型和处理器，并写出 `model_generation` 函数，它负责处理提示词并在模型上运行推理。

```
from transformers import AutoProcessor, AutoModelForImageTextToText
import torch

model_id = "google/gemma-3n-e4b-it" # google/gemma-3n-e2b-it
processor = AutoProcessor.from_pretrained(model_id)
model = AutoModelForImageTextToText.from_pretrained(model_id).to(device)

def model_generation(model, messages):
    inputs = processor.apply_chat_template(
        messages,
        add_generation_prompt=True,
        tokenize=True,
        return_dict=True,
        return_tensors="pt",
    )
    input_len = inputs["input_ids"].shape[-1]

    inputs = inputs.to(model.device, dtype=model.dtype)

    with torch.inference_mode():
        generation = model.generate(**inputs, max_new_tokens=32, disable_compile=False)
        generation = generation[:, input_len:]

    decoded = processor.batch_decode(generation, skip_special_tokens=True)
    print(decoded[0])
```

由于模型支持所有模态作为输入，下面简要说明如何通过 transformers 使用它们。

#### 仅文本

```
# Text Only

messages = [
    {
        "role": "user",
        "content": [
            {"type": "text", "text": "What is the capital of France?"}
        ]
    }
]
model_generation(model, messages)
```

输出：

```
The capital of France is **Paris**. 
```

#### 与音频交错

```
# Interleaved with Audio

messages = [
    {
        "role": "user",
        "content": [
            {"type": "text", "text": "Transcribe the following speech segment in English:"},
            {"type": "audio", "audio": "https://huggingface.co/datasets/ariG23498/demo-data/resolve/main/speech.wav"},
        ]
    }
]
model_generation(model, messages)
```

输出：

```
Send a text to Mike. I'll be home late tomorrow.
```

#### 与图像/视频交错

对视频的支持是把图像帧集合起来实现的

```
# Interleaved with Image

messages = [
    {
        "role": "user",
        "content": [
            {"type": "image", "image": "https://huggingface.co/datasets/ariG23498/demo-data/resolve/main/airplane.jpg"},
            {"type": "text", "text": "Describe this image."}
        ]
    }
]
model_generation(model, messages)
```

输出：

```
The image shows a futuristic, sleek, white airplane against a backdrop of a clear blue sky transitioning into a cloudy, hazy landscape below. The airplane is tilted at
```

## 用 MLX 推理

Gemma 3n 对 MLX 提供全 3 种模态的 day 0 支持。请务必升级你的 mlx-vlm 安装。

```
pip install -u mlx-vlm
```

从视觉开始：

```
python -m mlx_vlm.generate --model google/gemma-3n-E4B-it --max-tokens 100 --temperature 0.5 --prompt "Describe this image in detail." --image https://huggingface.co/datasets/ariG23498/demo-data/resolve/main/airplane.jpg
```

然后是音频：

```
python -m mlx_vlm.generate --model google/gemma-3n-E4B-it --max-tokens 100 --temperature 0.0 --prompt "Transcribe the following speech segment in English:" --audio https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/audio-samples/jfk.wav
```

### 用 llama.cpp 推理

除了 MLX，Gemma 3n（仅文本）也能开箱即用地配合 llama.cpp。请务必从源码安装 llama.cpp / Ollama。

查看 llama.cpp 的安装说明：[https://github.com/ggml-org/llama.cpp/blob/master/docs/install.md](https://github.com/ggml-org/llama.cpp/blob/master/docs/install.md)

你可以这样运行：

```
llama-server -hf ggml-org/gemma-3n-E4B-it-GGUF:Q8_0
```

### 用 Transformers.js 和 ONNXRuntime 推理

最后，我们还为 [gemma-3n-E2B-it](https://huggingface.co/onnx-community/gemma-3n-E2B-it-ONNX) 模型变体发布了 ONNX 权重，使其能在各种运行时和平台上灵活部署。对于 JavaScript 开发者，Gemma3n 已被集成进 [Transformers.js](https://github.com/huggingface/transformers.js)，自 [3.6.0](https://github.com/huggingface/transformers.js/releases/tag/3.6.0) 版起可用。

关于如何用这些库运行该模型的更多信息，请查看 [模型卡](https://huggingface.co/onnx-community/gemma-3n-E2B-it-ONNX#usage) 的使用部分。
