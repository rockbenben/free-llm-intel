# 用 Gradio MCP Servers 为你的 LLM 提升技能

你是否曾希望你喜欢的大语言模型（LLM）不只是回答问题？如果它能替你编辑图片、浏览网页或整理你的收件箱呢？

现在它可以了！在这篇博客中，我将向你展示：

- MCP 协议是什么，以及它的工作原理为何类似于我们熟悉的智能手机应用——只不过面向的是 LLM。
- 如何通过"MCP 应用商店"找到数千个 MCP server。
- 如何把这样一个 server 添加到你喜欢的大模型中，赋予它新能力。我们将用一个示例演示 [Flux.1 Kontext[dev]](https://huggingface.co/spaces/black-forest-labs/FLUX.1-Kontext-Dev)，它可以根据纯文本指令编辑图片。

## MCP 简要介绍

**Model Context Protocol（MCP）**是一个开放标准，让开发者能够在 LLM 与一组工具之间建立安全的双向连接。例如，如果你创建了一个暴露"视频转录"工具的 MCP server，就可以把一个 LLM 客户端（如 Cursor、Claude Code 或 Cline）连接到这个 server。之后，LLM 就懂得如何根据你的请求转录视频并使用这个工具。

简而言之，MCP server 是为你的 LLM 赋予新能力、从而提升技能的标准方式。可以把它想象成你智能手机上的应用。手机本身不会编辑图片，但你可以从应用商店下载一个应用来做到。那么，要是有一个 MCP server 的应用商店该多好？🤔

## Hugging Face Spaces：MCP 应用商店

Hugging Face [Spaces](https://hf.co/spaces) 是全球最大的 AI 应用集合。这些 space 中的大多数用 AI 模型完成某一专门任务，例如：

- [Image Background Removal](https://huggingface.co/spaces/not-lain/background-removal)
- [OCR](https://huggingface.co/spaces/prithivMLmods/Multimodal-OCR)
- [Text-to-Speech Synthesis](https://huggingface.co/spaces/ResembleAI/Chatterbox)

这些 space 用 [Gradio](https://gradio.app) 实现——一个用于创建 AI 驱动 Web 服务的开源 Python 包。从 `5.28.0` 版本起，**Gradio 应用支持 MCP 协议。**

这意味着 Hugging Face Spaces 就是那个能为你的 LLM 提供数千种 AI 能力的地方， aka **MCP 应用商店！**

想逛逛这个应用商店？访问这个[链接](https://huggingface.co/spaces?filter=mcp-server)。也可以手动在 `https://hf.co/spaces` 中筛选 `MCP Compatible`。

## 示例：一个能编辑图片的 LLM

[Flux.1 Kontext[dev]](https://huggingface.co/spaces/black-forest-labs/FLUX.1-Kontext-Dev) 是一个令人印象深刻的模型，能根据纯文本 prompt 编辑图片。例如，你让它"把我的头发染成蓝色"并上传一张你的照片，模型会返回这张照片——但你的头发变成了蓝色！
