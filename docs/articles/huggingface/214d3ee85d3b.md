## 写给生物学家的入门：语言模型到底是个啥？

用于处理蛋白质的模型很大程度上受 BERT、GPT 这类大型语言模型的启发。所以要理解这些模型如何工作，我们得把时间拨回到 2016 年左右，那时它们还不存在。Donald Trump 还没当选，Brexit 还没发生，深度学习（DL）是那个每天都在刷新纪录的当红新技术。DL 成功的关键，在于它用人工神经网络去学习数据中复杂的模式。但 DL 有一个致命问题——它需要**大量**数据才能工作得好，而很多任务上这些数据根本拿不到。

假设你想训练一个 DL 模型，输入一个英文句子、判断它在语法上是否正确。于是你拼凑出训练数据，看起来大概是这样的：

| Text | Label |
| --- | --- |
| The judge told the jurors to think carefully. | Correct |
| The judge told that the jurors to think carefully. | Incorrect |
| … | … |

理论上，这个任务在当时是完全可行的——如果你把这样的训练数据喂给一个 DL 模型，它能学会预测新句子在语法上是否正确。但在实践中，效果并不好，因为在 2016 年，大多数人为每个想要训练的任务都随机初始化一个新模型。这意味着**模型只能从训练数据里的样本学到它所需要知道的一切！**

要体会这有多难，假设你是一个机器学习模型，我正在给你一些我想让你学习的任务的训练数据。就是这些：

| Text | Label |
| --- | --- |
| Is í an stiúrthóir is fearr ar domhan! | 1 |
| Is fuath liom an scannán seo. | 0 |
| Scannán den scoth ab ea é. | 1 |
| D’fhág mé an phictiúrlann tar éis fiche nóiméad! | 0 |

我这里选了一门我希望你之前从没见过语言，所以我猜你大概不会很有信心说自己已经学会了这个任务。也许在几百上千个样本之后，你会开始注意到输入里一些反复出现的词或模式，从而做出比随机猜测更好的判断；但即便如此，一个新词或不寻常的措辞肯定能把你难住、让你猜错。并非巧合的是，当时 DL 模型的表现也就到这个程度！

现在用英语试试同一个任务：

| Text | Label |
| --- | --- |
| She's the best director in the world! | 1 |
| I hate this movie. | 0 |
| It was an absolutely excellent film. | 1 |
| I left the cinema after twenty minutes! | 0 |

现在就简单了——任务不过是预测一条影评是正面（1）还是负面（0）。仅凭两个正面样本和两个负面样本，你大概能以接近 100% 的准确率完成它，因为**你已经对英语词汇和语法、以及围绕电影和情绪表达的文化背景拥有大量现成的知识。**没有这些知识，事情就更像第一个任务——你需要读数量巨大的样本才能开始看出输入里一些表面的模式，而即使你花时间去研究几十万条样本，你的猜测仍然远不如在英语任务里只看了四条样本之后那么准。

### 关键突破：迁移学习

在机器学习里，我们把这种把先验知识迁移到新任务的概念叫做"**迁移学习（transfer learning）**"。让 DL 用上这种迁移学习，在 2016 年前后是整个领域的一个主要目标。预训练词向量之类的东西（它们非常有趣，但超出了本篇博客的范围）在 2016 年确实已经存在，也能把一些知识转移到新模型里，但这种知识迁移仍然相对表面，模型还是需要大量训练数据才能工作得好。

这种局面一直持续到 2018 年，两篇重磅论文落地，分别引入了 [ULMFiT](https://arxiv.org/abs/1801.06146) 和后来的 [BERT](https://arxiv.org/abs/1810.04805)。这是第一批真正让自然语言迁移学习跑通的论文，其中 BERT 尤其标志着预训练大语言模型时代的开始。两篇论文共通的诀窍在于，它们利用了深度学习里人工神经网络的内部结构——先在一个训练数据非常丰富的文本任务上长时间训练一个神经网络，然后把整个神经网络复制到新任务上，只改动对应网络输出的那几个神经元。

[![transfer learning](https://huggingface.co/blog/assets/119_deep_learning_with_proteins/transfer_learning.png)](https://huggingface.co/blog/assets/119_deep_learning_with_proteins/transfer_learning.png)

*[ULMFiT 论文](https://arxiv.org/abs/1801.06146)中的这张图，展示了在三个不同任务上使用迁移学习 versus 从头训练模型所带来的巨大性能提升。很多情况下，使用迁移学习的性能相当于拥有 100 倍以上训练数据。别忘了这是 2018 年发表的——现代大语言模型还能做得更好！*

之所以这样做管用，是因为在解决任何非平凡任务的过程中，神经网络会学到输入数据的很多结构——视觉网络给定原始像素，会学会识别线条、曲线和边缘；文本网络给定原始文本，会学到语法结构的细节。而这些信息并不是任务专属的——迁移学习之所以奏效的关键原因在于**解决一个任务所需要知道的很多东西并不只属于那个任务！** 要分类影评，你并不需要懂多少关于影评的东西，但你确实需要广博的英语知识和文化背景。通过选一个训练数据丰富的任务，我们能让神经网络学到那种"领域知识"，随后再把它应用到我们真正关心的、训练数据可能难得多的新任务上。

到这里，希望你理解了什么是迁移学习，也理解了大语言模型不过是在大量文本数据上训练过的大神经网络，这使它成为迁移到新任务的绝佳候选。下面我们会看这些同样的技术如何应用到蛋白质上，不过我得先为我另一类读者写一篇入门。如果你已经熟悉，可以跳过这部分！

## 写给机器学习从业者的入门：蛋白质到底是个啥？

要把一整个学位浓缩成一句话：蛋白质干很多事情。有些蛋白质是**酶（enzymes）**——它们充当化学反应的催化剂。当你身体把营养转化为能量时，从食物到肌肉运动的每一步都由一种酶来催化。有些蛋白质是**结构性的**——它们提供稳定性和形状，例如在结缔组织中。如果你看过化妆品广告，大概率见过 **collagen（胶原蛋白）**、**elastin（弹性蛋白）** 和 **keratin（角蛋白）** 这些词——它们是构成我们皮肤和头发结构的很多蛋白质。

另一些蛋白质在健康与疾病中至关重要——大家大概都记得关于 COVID-19 病毒**刺突蛋白（spike protein）**  endless 的新闻报道。COVID 刺突蛋白会结合人体细胞表面一种叫 ACE2 的蛋白质，从而进入细胞并投递它的病毒 RNA。由于这种相互作用对感染至关重要，在疫情期间，对这些蛋白质及其相互作用的建模是一个巨大的研究焦点。

蛋白质由多种**氨基酸（amino acids）** 组成。氨基酸是相对简单的分子，都共享同一个分子骨架；这种骨架的化学性质使氨基酸能够融合到一起，从而让单个分子连成一条长链。这里关键要理解的是，氨基酸只有那么几种——20 种标准氨基酸，再加上视具体生物而定可能的几种罕见而奇怪的。蛋白质之所以有巨大多样性，是因为**这些氨基酸可以以任意顺序组合**， resulting 的蛋白质链因此可以有截然不同的形状和功能，因为链的不同部分会相互粘附、折叠。这里可以把文本当类比——英语只有 26 个字母，但想想你用这 26 个字母的各种组合能写出多少种不同的东西！

事实上，由于氨基酸种类太少，生物学家可以给每一种分配一个唯一的字母。这意味着你可以把一个蛋白质写成一串文本！例如，假设一个蛋白质的氨基酸链是 Methionine、Alanine 和 Histidine。这些氨基酸[对应的字母](https://en.wikipedia.org/wiki/Amino_acid#Table_of_standard_amino_acid_abbreviations_and_properties)就是 M、A、H，于是我们可以把这条链写成"MAH"。不过大多数蛋白质含有成百甚至上千个氨基酸，而不是只有三个！

[![protein structure](https://huggingface.co/blog/assets/119_deep_learning_with_proteins/protein_structure.png)](https://huggingface.co/blog/assets/119_deep_learning_with_proteins/protein_structure.png)

*这张图展示了某种蛋白质的两种表示。所有氨基酸都含有一段 Carbon-Carbon-Nitrogen 序列。当氨基酸融合成蛋白质时，这个重复模式会贯穿它的整个长度，被称为蛋白质的"骨架"。但氨基酸在"侧链"（即连接在这个 C-C-N 骨架上的原子）上各不相同。下图使用泛指的侧链，标记为 R1、R2、R3，它们可以是任意氨基酸。上图中，中间那个氨基酸有一个 CH3 侧链——这表明它是* Alanine *（丙氨酸），用字母 A 表示。*（[图片来源](https://commons.wikimedia.org/wiki/File:Peptide-Figure-Revised.png)）

尽管我们可以把蛋白质写成文本串，蛋白质其实并不是一种"语言"，至少不是 Noam Chomsky 会认可的任何一种语言。但它们确实有几个类似语言的特征，从机器学习角度看，使它们与文本是一个非常接近的领域：蛋白质是在一个固定的小字母表上的长字符串，虽然理论上任何字符串都可能，但实践中只有一小部分字符串真正"讲得通"。随机的文本是垃圾，随机的蛋白质只是一团无定形的糊状物。

而且，如果你孤立地看蛋白质的某一部分，信息就会丢失，就像你只读从一篇更大文本里摘出的一个句子会丢失信息一样。一个蛋白质区域可能只有在蛋白质其他部分的稳定与矫正之下才呈现出它的自然形状！这意味着长程相互作用——那种能被全局自注意力很好捕捉的——对正确建模蛋白质非常重要。

到这里，希望你已经对什么是蛋白质、以及生物学家为何如此关心它们有了一个模糊的概念——尽管它们的氨基酸"字母表"很小，却拥有结构与功能上的巨大多样性，而仅仅从氨基酸的原始"字符串"就能理解并预测这些结构和功能，将会是一种极其有价值的研究工具。

## 把二者结合：蛋白质机器学习

现在我们已经看到语言模型的迁移学习是如何运作的，也看到了蛋白质是什么。有了这些背景，下一步就不太难了——我们能把同样的迁移学习思想用在蛋白质上！我们不再是在一个涉及英文文本的任务上预训练模型，而是在一个输入是蛋白质、但训练数据丰富的任务上训练它。一旦做到这点，我们的模型 hopefully 就学到了关于蛋白质结构的很多知识，正如语言模型学到关于语言结构的很多知识那样。这让预训练蛋白质模型成为迁移到任何其他基于蛋白质任务上的绝佳候选！

生物学家关心的、想让蛋白质模型去训练的是哪类机器学习任务？最有名的蛋白质建模任务是**蛋白质折叠（protein folding）**。这个任务是给定像"MLKNV…"这样的氨基酸链，预测该蛋白质最终折叠成的形状。这是一个极其重要的任务，因为准确地预测一个蛋白质的形状和结构，就能 insight 很多关于它在干什么、以及如何干的信息。

人们早在现代机器学习之前就在研究这个问题——一些最早的巨型分布式计算项目，如 Folding@Home，用原子级模拟、以惊人的时空分辨率来建模蛋白质折叠；而 *蛋白质晶体学（protein crystallography）* 整个领域则用 X 射线衍射来观察从活细胞中分离出的蛋白质的结构。

但和许多其他领域一样，深度学习的到来改变了一切。AlphaFold，尤其是 AlphaFold2，使用带若干蛋白质专属改进的 transformer 深度学习模型，仅凭原始氨基酸序列就在预测新蛋白质结构上取得了卓越结果。如果你感兴趣的是蛋白质折叠，我们强烈建议看看 [我们的 ESMFold notebook](https://colab.research.google.com/github/huggingface/notebooks/blob/main/examples/protein_folding.ipynb)——ESMFold 是一个与 AlphaFold2 类似的新模型，但它更像一个"纯"深度学习模型，运行不需要任何外部数据库或搜索步骤。因此配置过程轻松得多、模型跑得快得多，同时仍保持出色的准确度。

[![folding example](https://huggingface.co/blog/assets/119_deep_learning_with_proteins/folding_example.png)](https://huggingface.co/blog/assets/119_deep_learning_with_proteins/folding_example.png)

*同二聚体（homodimeric）* P. multocida *蛋白质**Glucosamine-6-phosphate deaminase* 的预测结构。这个结构和可视化是用上面链接的 ESMFold notebook 在几秒内生成的。颜色越蓝表示结构置信度越高的区域。*

不过蛋白质折叠并不是唯一感兴趣的任务！生物学家可能想用蛋白质做的分类任务种类繁多——也许他们想预测这个蛋白质会在细胞的哪个部位发挥作用，或者在蛋白质被合成之后其中的哪些氨基酸会接受某些修饰。用机器学习的语言，当你想分类整个蛋白质时（例如预测它的亚细胞定位），这类任务叫做**序列分类（sequence classification）**；当你想分类每个氨基酸时（例如预测哪些单独的氨基酸会接受翻译后修饰），则叫做**token 分类（token classification）**。

但关键要点在于，尽管蛋白质与语言非常不同，它们几乎可以用完全相同的机器学习方法来处理——在一个庞大的蛋白质序列数据库上大规模预训练，再**迁移学习**到各种训练数据可能稀疏得多的感兴趣任务上。事实上，在某些方面它甚至比 BERT 这样的大语言模型更简单，因为不需要复杂的切词和解析——蛋白质没有"词"的分界，所以最简单的做法就是把每个氨基酸直接转换成一个输入 token。

## 听起来很酷，但我不知道从哪儿入手！

如果你已经熟悉深度学习，你会发现微调蛋白质模型的代码与微调语言模型的代码极其相似。我们为 [PyTorch](https://colab.research.google.com/github/huggingface/notebooks/blob/main/examples/protein_language_modeling.ipynb) 和 [TensorFlow](https://colab.research.google.com/github/huggingface/notebooks/blob/main/examples/protein_language_modeling-tf.ipynb) 都准备了示例 notebook，如果你好奇的话。你可以从像 [UniProt](https://www.uniprot.org/) 这样的开放访问蛋白质数据库里获得海量带标注的数据，它既有 REST API 也有友好的网页界面。你主要的难点会是找到有趣的研究方向来探索，这多少超出了本文的范围——但我确信外面有很多生物学家很想和你合作！

反过来，如果你是生物学家，你大概已经有了好几个想尝试的想法，但可能对一头扎进机器学习代码有点发怵。别慌！我们设计示例 notebook（[PyTorch](https://colab.research.google.com/github/huggingface/notebooks/blob/main/examples/protein_language_modeling.ipynb)、[TensorFlow](https://colab.research.google.com/github/huggingface/notebooks/blob/main/examples/protein_language_modeling-tf.ipynb)）时，让数据加载部分与其余部分相当独立。这意味着如果你心里有一个**序列分类**或 **token 分类**任务，你要做的只是构建一个蛋白质序列列表和一个对应的标签列表，然后把我们的数据加载代码换成任何能加载或生成这两个列表的代码。

虽然链接的具体示例使用 [ESM-2](https://www.biorxiv.org/content/10.1101/2022.07.20.500902v1) 作为基础预训练模型（因为它是当前的最先进），但领域内的人大概也熟悉 Rost 实验室，它的模型如 [ProtBERT](https://huggingface.co/Rostlab/prot_bert)（[论文链接](https://www.biorxiv.org/content/10.1101/2020.07.12.199554v3)）是同类中最早的模型之一，在生物信息学社区引发了极大兴趣。链接示例中的大部分代码只需把检查点路径从 `facebook/esm2...` 改成类似 `Rostlab/prot_bert`，就能切换到以 ProtBERT 为基础。
