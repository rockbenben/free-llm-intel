今天，我们在 [d1 决策模型家族](https://www.liquid.ai/blog/d1-decision-model)中发布两个开源决策模型：[d1-3B](https://huggingface.co/LiquidAI/d1-3b) 和 [d1-omni-600M](https://huggingface.co/LiquidAI/d1-omni-600M)（实验性）。

- **Decision Index 0.2.1 上 10B 以下最佳决策模型：** d1-3B 得分 48.57，领先于所有 4B 和 9B 模型，也领先于 Decider 35B-A3B（47.11）。
- **多模态：** d1-3B 支持文本与图像，而 d1-omni-600M 支持文本与图像，或文本与音频
- **快：** d1-3B 回答一个问题在 NVIDIA Jetson AGX Thor 上耗时 16 ms，在 Jetson AGX Orin 上耗时 26 ms，在 Jetson Orin Nano 上耗时 50ms

## 我们如何为边缘侧构建决策模型

这些开源 d1 决策模型构建在我们的 Liquid Foundation Models（LFM）之上。与我们的生成式模型不同，决策模型不产出 tokens，而是在一次前向传播中给出答案。

d1-3B 与 d1-omni-600M 是从两个差异很大的 backbone 训练出来的：

- **d1-3B** 从 [LFM2.5-VL-3B](https://huggingface.co/LiquidAI/LFM2.5-VL-3B) 训练而来，这是我们最新的 VLM，为 decoder-only 结构。它接受文本和图像作为输入。
- **d1-omni-600M** 从 [LFM2.5-Encoder-350M](https://huggingface.co/LiquidAI/LFM2.5-Encoder-350M) 训练而来，那是一个双向 encoder。它额外加了视觉与音频 encoder 以处理这三种模态。它接受文本加图像，或文本加音频作为输入。这个模型目前处于早期研究发布阶段，仍在继续开发。

## 基准测试结果

我们在七个公开数据集上对 d1-3B 与 d1-omni-600M 做了基准测试，覆盖阅读理解、毒性检测、意图分类、医学 QA 与跨语言理解。d1-3B 取得 82.9 的平均分，是表中最高的，并超过 Decider 4B。d1-omni-600M 得分 78.4，以四分之一的参数量超过了 Decider 2B（77.1）。

| 基准 | d1-omni-600M | d1-3B | Decider 2B | Decider 4B |
| --- | --- | --- | --- | --- |
| SQuAD 2.0 | 74.0 | **83.3** | 67.7 | 76.0 |
| Civil Comments | **95.8** | 93.3 | 93.6 | 92.8 |
| MASSIVE intent | 86.1 | 86.9 | 81.1 | **88.3** |
| PubMedQA | 61.3 | **68.3** | 65.7 | 63.3 |
| BoolQ | 77.7 | 86.3 | 87.3 | **89.0** |
| XNLI | 74.7 | 85.6 | 85.0 | **88.6** |
| PAWS-X | **79.5** | **76.4** | 59.5 | 69.8 |
| **平均** | 78.4 | **82.9** | 77.1 | 81.1 |

我们验证了 d1-3B 在其 LFM2.5-VL-3B backbone 的视觉能力上得以保留（在标准视觉基准上），也验证了 d1-omni-600M 能处理这三种模态。我们不在这里报告任何视觉或音频基准，因为 Decision Index v0.3 只包含一个私有的视觉分区，而音频决策基准目前仍是一个未解问题。

## 速度

我们与 NVIDIA 合作，在 NVIDIA 技术栈上评测了 d1-3B，覆盖 NVIDIA GeForce RTX 4090、NVIDIA Jetson AGX Thor、Jetson AGX Orin 64 GB 与 Jetson Orin Nano。由于 d1-omni-600M 还是早期研究发布版本，本次发布我们不报告它的任何速度数字。

**边缘推理。** d1-3B 在每一台被测设备上都能在 50 ms 内回答一个问题。三个问题只耗费单个问题 1.3x 的时间，其中 AGX Thor 从 16 ms 变为 20 ms。

|  | 一个问题 | 三个问题 | 3.4K-token 状态 | 384px 图像 | 64 个状态，打包 |
| --- | --- | --- | --- | --- | --- |
| Apple M5 Pro | 30 ms | 41 ms | 640 ms | 62 ms | 78 / s |
| Jetson AGX Thor | 16 ms | 20 ms | 220 ms | 35 ms | 262 / s |
| Jetson AGX Orin 64 GB | 26 ms | 35 ms | 560 ms | 83 ms | 110 / s |
| Jetson Orin Nano | 50 ms | 73 ms | 1,640 ms | 202 ms | 38 / s |

**GPU 推理。** 在 GPU 上，d1-3B 在两个平台上都能在 10 ms 内回答一个问题，并在 18 ms 内处理一张 384px 图像。

|  | 一个问题 | 三个问题 | 3.4K-token 状态 | 384px 图像 | 64 个状态，打包 |
| --- | --- | --- | --- | --- | --- |
| NVIDIA RTX 4090 | 8 ms | 21 ms | 102 ms | 17 ms | 475 / s |
| AMD MI325X | 9 ms | 14 ms | 44 ms | 18 ms | 1,106 / s |

## 如何使用开源 d1 决策模型

当你需要快速、结构化的决策，包括多模态输入时，就用 d1 决策模型。d1-3B 在它的尺寸上提供最高的决策质量，而 d1-omni-600M 适合那些占用空间（footprint）要紧的场景。

安装依赖（需要 `transformers>=5.14`）：

```
pip install "transformers>=5.14" torch torchvision pillow
```

这些模型自带各自的代码，因此要用 `trust_remote_code=True` 来加载它：

```
import io
import urllib.request

import torch
from PIL import Image
from transformers import AutoModel

device = "cuda" if torch.cuda.is_available() else "mps" if torch.backends.mps.is_available() else "cpu"
model = AutoModel.from_pretrained("LiquidAI/d1-3B", trust_remote_code=True,
                                  dtype=torch.float32 if device == "cpu" else torch.bfloat16).to(device)

# Several named questions over one text state, answered in one pass
questions = {
    "refund": {"type": "noul", "instructions": "Is the customer asking for a refund?"},
    "team": {"type": "choice", "instructions": "Which team should handle this?",
             "criteria": {"billing": "Charges, refunds, invoices", "technical": "App or site faults",
                          "fraud": "Suspected unauthorised use"}},
    "urgency": {"type": "score", "instructions": "How urgent is this?",
                "criteria": ["Can wait", "Today", "Blocking the customer now"]},
}
print(model.system_one("I was charged twice this month, please refund one of them.", questions))

# An image as the whole state
url = "http://images.cocodataset.org/val2017/000000039769.jpg"  # two cats on a sofa
photo = Image.open(io.BytesIO(urllib.request.urlopen(url).read()))
print(model.system_one(None, {"cats": {"type": "choice", "instructions": "How many cats are there?",
                                       "criteria": {"one": "One", "two": "Two", "more": "Three or more"}}},
                       images=[photo]))

# Many requests, packed together with no padding
tickets = ["Where is my parcel? It was due Monday.", "The app crashes when I open settings."]
print(model.system_one_batch([(t, {"team": questions["team"]}) for t in tickets]))
```

为篇幅所限，我们只收录 d1-3B 的示例。如何运行 d1-omni-600M 请看 [d1-omni-600M 的 model card](https://huggingface.co/LiquidAI/d1-omni-600M)。
