# Groq 加入 Hugging Face Inference Providers 🔥

[![banner image](https://huggingface.co/blog/assets/inference-providers/welcome-groq.jpg)](https://huggingface.co/blog/assets/inference-providers/welcome-groq.jpg)

我们兴奋地宣布：**Groq** 现已成为 Hugging Face Hub 上受支持的推理提供方（Inference Provider）！Groq 加入我们不断成长的生态，直接扩展了 Hub 模型页面上 serverless 推理的广度与能力。Inference Providers 还与我们的客户端 SDK（JS 和 Python 均支持）无缝集成，让你能极其方便地用首选提供方调用各种模型。

[Groq](https://groq.com) 支持多种文本与对话模型，包括最新的开源模型，如 [Meta 的 Llama 4](https://huggingface.co/meta-llama/Llama-4-Maverick-17B-128E-Instruct?inference_provider=groq)、[Qwen 的 QWQ-32B](https://huggingface.co/Qwen/QwQ-32B?inference_provider=groq) 等等。

Groq 技术的核心是 Language Processing Unit（LPU™）——一种全新的端到端处理单元系统，为存在串行依赖的计算密集型应用（如大语言模型 LLM）提供最快速的推理。LPU 的设计目标是克服 GPU 在推理上的局限，显著降低延迟、提升吞吐，因此非常适合实时 AI 应用。

Groq 为公开可用的模型提供快速 AI 推理。他们提供 API，让开发者可以轻松把这些模型集成到自己的应用中，并以按需、按用量付费的方式访问大范围公开可用的 LLM。

你现在就能把 Groq 的 Inference API 作为 Huggingface 上的 Inference Provider 使用。我们非常期待看到你基于这个新提供方构建什么。

关于如何把 Groq 用作 Inference Provider，请阅读其专属[文档页](https://huggingface.co/docs/inference-providers/providers/groq)。

受支持模型列表见[这里](https://huggingface.co/models?inference_provider=groq&sort=trending)。

## 工作原理

### 在网站上

- 在你的用户账号设置中，你可以：

- 为你已注册的提供方设置自己的 API key。若不设置自定义 key，你的请求将通过 HF 路由。
- 按偏好给提供方排序。这会影响模型页面上的 widget 和代码片段。

- 如前所述，调用 Inference Providers 有两种模式：

- 自定义 key（请求直接用你对应推理提供方自己的 API key 发往该推理提供方）
- 由 HF 路由（这种情况下你不需要提供方的 token，费用直接计入你的 HF 账号而非提供方账号）

- 模型页面会展示第三方推理提供方（与当前模型兼容的提供方，按用户偏好排序）

### 从客户端 SDK

#### Python：使用 huggingface_hub

下面的例子展示如何用 Groq 作为推理提供方来使用 Meta 的 Llama 4。你可以用 [Hugging Face token](https://huggingface.co/settings/tokens)自动经由 Hugging Face 路由，或者如果你有 Groq API key 也可以直接使用。

从源码安装 `huggingface_hub`（见[说明](https://huggingface.co/docs/huggingface_hub/installation#install-from-source)）。官方支持将很快随 v0.33.0 版本发布。

```
import os
from huggingface_hub import InferenceClient

client = InferenceClient(
    provider="groq",
    api_key=os.environ["HF_TOKEN"],
)

messages = [
    {
        "role": "user",
        "content": "What is the capital of France?"
    }
]

completion = client.chat.completions.create(
    model="meta-llama/Llama-4-Scout-17B-16E-Instruct",
    messages=messages,
)

print(completion.choices[0].message)
```

#### JS：使用 @huggingface/inference

```
import { InferenceClient } from "@huggingface/inference";

const client = new InferenceClient(process.env.HF_TOKEN);

const chatCompletion = await client.chatCompletion({
  model: "meta-llama/Llama-4-Scout-17B-16E-Instruct",
  messages: [
    {
      role: "user",
      content: "What is the capital of France?",
    },
  ],
  provider: "groq",
});

console.log(chatCompletion.choices[0].message);
```

## 计费

对于直接请求——即使用推理提供方自己的 key 时——由对应提供方向你计费。例如，如果你使用 Groq API key，费用记在你的 Groq 账号上。

对于路由请求——即通过 Hugging Face Hub 认证时——你只需支付标准的提供方 API 费率。我们不加任何溢价，只是把提供方成本原样传递。（未来，我们可能会与提供方伙伴达成收入分成协议。）
