# 欢迎加入 Falcon 3 开放模型家族！

我们推出 Falcon3——一个参数不超过 100 亿的 decoder-only 大语言模型家族，由阿布扎比的[技术创新研究所（TII）](https://www.tii.ae/ai-and-digital-science)开发。通过推进性能与训练效率的边界，本次发布体现了我们持续致力于发展开放、可及的大型基础模型。

Falcon3 是此前版本的自然演进，着重扩展模型在科学、数学和代码方面的能力。

本迭代包含五个 base 模型：

- [Falcon3-1B-Base](https://huggingface.co/tiiuae/Falcon3-1B-Base)
- [Falcon3-3B-Base](https://huggingface.co/tiiuae/Falcon3-3B-Base)
- [Falcon3-Mamba-7B-Base](https://huggingface.co/tiiuae/Falcon3-Mamba-7B-Base)
- [Falcon3-7B-Base](https://huggingface.co/tiiuae/Falcon3-7B-Base)
- [Falcon3-10B-Base](https://huggingface.co/tiiuae/Falcon3-10B-Base)

在开发这些模型时，我们融入了多项关键创新，在提升性能的同时降低训练成本：

- **transformer 模型的一次预训练：**我们在 7B 模型上进行了单次大规模预训练，使用 1024 块 H100 GPU，消费 14 万亿 token——涵盖网页、代码、STEM 以及精选的高质量多语言数据。
- **深度上 scaling 以提升推理：**基于近期关于模型深度影响的研究，我们通过复制冗余层把 7B 模型上 scaling 成 10B 参数模型，并用 2 万亿 token 的高质量数据继续预训练。由此得到 Falcon3-10B-Base，在 13B 参数以下模型中取得了最先进的 zero-shot 和 few-shot 表现。
- **知识蒸馏打造更好的小模型：**为提供紧凑高效的替代方案，我们利用剪枝与知识蒸馏技术开发了 Falcon3-1B-Base 和 Falcon3-3B-Base，使用不到 100B 精选高质量数据，重新定义了预训练效率。
- **纯 SSM：**我们在 [Falcon Mamba 7B](https://huggingface.co/tiiuae/falcon-mamba-7b) 基础上追加 1.5 万亿 token 的高质量数据继续训练，得到 Falcon3-Mamba-7B-Base。值得注意的是，更新后的模型在推理和数学能力上显著提升。
- **其他变体：**Falcon3 家族的所有模型都提供 Instruct、GGUF、GPTQ-Int4、GPTQ-Int8、AWQ 和 1.58-bit 等变体，为广泛应用提供灵活性。

## 核心亮点

Falcon3 展示了大语言模型在中小规模上的极限，在常见基准上表现高性能：

- [Falcon3-1B-Base](https://huggingface.co/tiiuae/Falcon3-1B-Base) 超越 SmolLM2-1.7B，与 gemma-2-2b 相当。
- [Falcon3-3B-Base](https://huggingface.co/tiiuae/Falcon3-3B-Base) 胜过更大的 Llama-3.1-8B 和 Minitron-4B-Base 等模型，凸显知识蒸馏式预训练的收益。
- [Falcon3-7B-Base](https://huggingface.co/tiiuae/Falcon3-7B-Base) 在 9B 以下规模中性能顶尖，与 Qwen2.5-7B 相当。
- [Falcon3-10B-Base](https://huggingface.co/tiiuae/Falcon3-10B-Base) 作为最先进模型，在 13B 以下类别中成绩强劲。
- 所有基于 transformer 的 Falcon3 模型与 [Llama](https://ai.meta.com/research/publications/the-llama-3-herd-of-models/) 架构兼容，便于更好地融入 AI 生态。
- [Falcon3-Mamba-7B](https://huggingface.co/tiiuae/Falcon3-Mamba-7B-Base) 继续保持最强状态空间语言模型（SSLM）的地位，在 7B 规模上与领先的 transformer LLM 匹敌甚至超越，并支持更长的 32K 上下文长度。由于与原版 [Falcon Mamba 7B](https://huggingface.co/tiiuae/falcon-mamba-7b) 架构相同，用户可以毫不费力地无缝集成 Falcon3-Mamba-7B。
- 我们 base 模型集合的 instruct 版本在各类基准上进一步表现出众，Falcon3-7B-Instruct 和 Falcon3-10B-Instruct 在开放排行榜上超越了 13B 以下所有 instruct 模型。

## 增强能力

我们用内部评估管道（基于 [lm-evaluation-harness](https://github.com/EleutherAI/lm-evaluation-harness)）评估模型并报告原始分数。评估凸显了 Falcon3 家族擅长的关键领域，反映了对提升科学领域、推理与通用知识能力的侧重：

- **数学能力：**Falcon3-10B-Base 在 MATH-Lvl5 上得 22.9、GSM8K 上得 83.0，展示在复杂数学任务上增强的推理。
- **编程能力：**Falcon3-10B-Base 在 MBPP 上得 73.8，Falcon3-10B-Instruct 在 Multipl-E 上得 45.8，反映其在编程相关任务上的泛化能力。
- **扩展上下文长度**：Falcon3 家族模型支持最多 32k token（1B 支持 8k 上下文除外），并有实用地改进，如 BFCL 得分 86.3（Falcon3-10B-Instruct）。
- **推理提升：**Falcon3-7B-Base 和 Falcon3-10B-Base 在 BBH 上分别得 51.0 和 59.7，反映推理能力增强，10B 模型比 7B 表现出更好的推理性能。
- **科学知识扩展：**MMLU 基准上的表现展示专业知识的进步，Falcon3-7B-Base 得 67.4/39.2（MMLU/MMLU-PRO），Falcon3-10B-Base 得 73.1/42.5（MMLU/MMLU-PRO）。

## 模型规格与基准结果

Falcon3 家族的详细规格见下表。[Falcon3-7B-Base](https://huggingface.co/tiiuae/Falcon3-7B-Base) 的架构以 256 的头维度为特征，配合为此维度优化的 [FlashAttention-3](https://arxiv.org/abs/2407.08608) 可获得高吞吐。这些 decoder-only 模型中，transformer 版本跨越 18 到 40 层，mamba 版本为 64 层；所有模型共享 SwiGLU 激活函数，词表大小为 131K token（Mamba-7B 为 65K）。Falcon3-7B-Base 用最大的数据量训练，确保概念与知识的全面覆盖，其他变体所需数据少得多。

下表突出 Falcon3-7B-Base 和 Falcon3-10B-Base 在关键基准上的表现，显示其在通用、数学、推理和常识理解领域的竞争力。欢迎查看模型卡，我们提供了额外评估结果（如 MT-Bench、Alpaca 等）。

如下表所示，instruct 模型与同规模及更小规模的模型相比也展示了有竞争力乃至更优的表现。

### Instruct 模型

Falcon3-1B-Instruct 和 Falcon3-3B-Instruct 在所评估基准上取得稳健表现。具体地，Falcon3-1B 在 IFEval（54.4）、MUSR（40.7）和 SciQ（86.8）上表现有竞争力，Falcon3-3B 则进一步增益——尤其在 MMLU-PRO（29.7）和 MATH（19.9）——展现了清晰的 scaling 效应。虽然它们并非在所有指标上超过所有竞争模型，但 Falcon 模型相对 Qwen 和 Llama 在推理与常识理解上表现出强劲成绩。在我们的内部评估管道中：

- 我们使用 [lm-evaluation harness](https://github.com/EleutherAI/lm-evaluation-harness)。
- 我们报告**原始分数**，通过应用 chat template **不带 fewshot_as_multiturn** 获得（与 Llama3.1 不同）。
- 所有模型使用相同的 batch-size。

此外，Falcon3-7B 和 Falcon3-10B 在所评估基准上表现稳健。Falcon3-7B 在推理（Arc Challenge: 65.9、MUSR: 46.4）和数学（GSM8K: 79.1）上有竞争力，Falcon3-10B 进一步改进，尤其是 GSM8K（83.1）和 IFEval（78），显示出清晰的 scaling 收益。

## 开源承诺

秉承促进 AI 普惠与协作的使命，Falcon3 家族所有模型均以 [**Falcon LLM 许可证**](https://falconllm.tii.ae/falcon-terms-and-conditions.html)发布。希望 AI 社区认为这些模型对研究、应用开发和进一步实验有价值。Falcon3 不是终点，而是我们打造更有能力、更高效、更专业化基础模型努力的延续。2025 年 1 月，我们将进一步发布 Falcon3 家族的其他模型，具备增强的多模态能力——包括图像、视频和音频支持——以及涵盖我们方法的完整技术报告。欢迎社区反馈与协作，共同完善和推进这些技术。
