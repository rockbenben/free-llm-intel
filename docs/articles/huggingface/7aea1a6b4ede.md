# NLP 课程正在升级为 LLM 课程！

[![image/gif](https://cdn-uploads.huggingface.co/production/uploads/62d648291fa3e4e7ae3fa6e8/I6Pq5TftMqjLOqZzKNplg.gif)](https://cdn-uploads.huggingface.co/production/uploads/62d648291fa3e4e7ae3fa6e8/I6Pq5TftMqjLOqZzKNplg.gif)

教育始终处于 Hugging Face「让 AI 大众化」使命的核心位置，而我们正在通过为 [hf.co/learn](https://hf.co/learn) 做一次大升级为这一使命加码！过去 3 年来，我们的 [NLP 课程](https://huggingface.co/huggingface-course)一直是开源 AI 社区的首选学习资源，现在是时候焕然一新了。我们要更新并扩充它，以跟上 AI 领域所有激动人心的进展（在几乎每周都有突破的当下，这并不容易！）

在实验性的 [smol-course](https://github.com/huggingface/smol-course) 和规模庞大的 [agents course](https://huggingface.co/agents-course) 中，我们感受到了大家的热情——10 万名学生报名，以一种全新、有趣、互动的方式学习 AI agent！

在过去几个月里，我们为"NLP"课程新增了若干章节，包括微调 LLM 以及构建 Deepseek R1 这类推理模型。这些新章节已经不再适合放在"NLP"这面旗帜之下，于是我们寻找了一个更贴切、更现代的名字，最终定为 **The LLM course（LLM 课程）**。

[![image/png](https://cdn-uploads.huggingface.co/production/uploads/62d648291fa3e4e7ae3fa6e8/an9U4x7L7rhUEFH_qgYc4.png)](https://cdn-uploads.huggingface.co/production/uploads/62d648291fa3e4e7ae3fa6e8/an9U4x7L7rhUEFH_qgYc4.png)

## NLP 课程的原有材料会怎么样？

我们将保留聚焦于经典 NLP 任务（如分类、命名实体识别和检索）的现有材料。这些主题依然重要，因为：

- 我们并不是什么事情都需要 LLM！
- 学生们仍然能从这些可以在本地运行、且易于理解解释的更简单任务中受益。

事实上，在未来几个月里，我们会更新并现代化这些经典章节，纳入 [Sentence Transformers](https://huggingface.co/sentence-transformers)、Zero Shot 分类的新进展以及 [ModernBert](https://huggingface.co/blog/modernbert) 等方法。

## 会有新章节吗？

会。我们的重点是增加新章节，让最前沿的研究成果能被更广泛的受众理解，并兼容 transformers、Spaces 和 Hugging Face Hub 等工具。例如，我们会加入关于微调、推理和检索的章节。

我们希望新章节更加开源、更贴近社区，而不是只围绕 Hugging Face 自家的库。`transformers` 库已成为 LLM 建模代码的事实标准参考，但模型的消费、微调和落地发生在各种各样的框架中，这是好事！例如，在[第 11 章「微调 LLM」](https://huggingface.co/learn/nlp-course/en/chapter11/1)和[第 12 章「推理模型」](https://huggingface.co/learn/nlp-course/en/chapter12/1)中，我们与那些极大地补充了 Hugging Face 库能力的库和工具进行了协作，包括：

- [LlamaIndex](https://huggingface.co/llamaindex)
- [LangChain](https://huggingface.co/langchain-ai)
- [Unsloth](https://huggingface.co/unsloth)
- [Marimo](https://huggingface.co/marimo-team)
- [Maxime Labonne](https://huggingface.co/mlabonne)

在未来几个月里，我们计划扩展协作范围，纳入更多作者、维护者和公司。我们希望课程材料能覆盖你正在使用的最佳工具！

## 会有交互式练习和直播课吗？

会——在学生确实需要的时候。我们将专注于可靠的文字材料和能多年保持实用价值的编程练习。但对于学生们希望同步参与的热门主题，我们会构建交互式练习并举办直播课。
