# 在 Habana Gaudi 上入门 Transformers

Julien Simon（juliensimon）

本文另有简体中文版：[简体中文](https://huggingface.co/blog/zh/getting-started-habana)。

几周前，我们高兴地[宣布](https://huggingface.co/blog/habana)[Habana Labs](https://habana.ai) 与 [Hugging Face](https://huggingface.co/) 将达成合作，加速 Transformer 模型训练。

Habana Gaudi 加速器在机器学习模型训练上的性价比，比最新的基于 GPU 的 Amazon EC2 实例最高高出 40%。我们非常兴奋能把这样的性价比优势带给 Transformers 🚀

在这篇实战文章中，我会演示如何在 Amazon Web Services 上快速搭好一个 Habana Gaudi 实例，然后微调一个 BERT 模型做文本分类。照例，所有代码都会给出，方便你在自己的项目里复用。

开始吧！

## 在 AWS 上搭建 Habana Gaudi 实例

使用 Habana Gaudi 加速器最简单的方式，是启动一个 Amazon EC2 [DL1](https://aws.amazon.com/ec2/instance-types/dl1/) 实例。这类实例配备 8 颗 Habana Gaudi 处理器，借助 [Habana Deep Learning Amazon Machine Image](https://aws.amazon.com/marketplace/server/procurement?productId=9a75c51a-a4d1-4470-884f-6be27933fcc8)（AMI）就能轻松用起来。该 AMI 预装了 [Habana SynapseAI® SDK](https://developer.habana.ai/) 以及运行 Gaudi 加速 Docker 容器所需的工具。如果你想用其他 AMI 或容器，[Habana 文档](https://docs.habana.ai/en/latest/AWS_Quick_Starts/index.html)里有说明。

我在 us-east-1 区域的 [EC2 控制台](https://console.aws.amazon.com/ec2sp/v2/) 里，先点击 **Launch an instance**，给实例起个名字（"habana-demo-julsimon"）。

然后，我在 Amazon Marketplace 里搜索 Habana AMI。

选择 Habana Deep Learning Base AMI (Ubuntu 20.04)。

接着，选择 *dl1.24xlarge* 实例规格（唯一可选的规格）。

之后，选择我用 `ssh` 连接实例时使用的密钥对。如果你还没有密钥对，可以就地创建一个。

下一步，我确认实例允许入站 `ssh` 流量。为了简单起见我没有限制来源地址，但在你自己的账号里一定要做限制。

默认情况下，这个 AMI 启动的实例只有 8GB Amazon EBS 存储，这里不够用。我把存储加到 50GB。

然后，我给实例指定一个 Amazon IAM 角色。实际生产中，这个角色应只包含运行训练任务所需的最小权限集，比如从你的某个 Amazon S3 桶读数据的权限。这里不需要该角色，因为数据集会从 Hugging Face hub 下载。如果你不熟悉 IAM，强烈建议阅读 [Getting Started](https://docs.aws.amazon.com/IAM/latest/UserGuide/getting-started.html) 文档。

接着，我让 EC2 把我的实例以 [Spot Instance](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/using-spot-instances.html) 方式开通——这是降低每小时 13.11 美元成本的好办法。

最后，我启动实例。几分钟后实例就绪，我可以用 `ssh` 连上去。Windows 用户可以按[文档](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/putty.html)用 *PuTTY* 做同样的事。

```
ssh -i ~/.ssh/julsimon-keypair.pem ubuntu@ec2-18-207-189-109.compute-1.amazonaws.com
```

在这个实例上，最后一步准备工作是拉取 Habana 的 PyTorch 容器，这是我用来微调模型的框架。关于其他预构建容器以及如何构建自己的容器，可查看 Habana [文档](https://docs.habana.ai/en/latest/Installation_Guide/index.html)。

```
docker pull \
vault.habana.ai/gaudi-docker/1.5.0/ubuntu20.04/habanalabs/pytorch-installer-1.11.0:1.5.0-610
```

镜像拉到实例后，我以交互模式运行它。

```
docker run -it \
--runtime=habana \
-e HABANA_VISIBLE_DEVICES=all \
-e OMPI_MCA_btl_vader_single_copy_mechanism=none \
--cap-add=sys_nice \
--net=host \
--ipc=host vault.habana.ai/gaudi-docker/1.5.0/ubuntu20.04/habanalabs/pytorch-installer-1.11.0:1.5.0-610
```

现在可以微调我的模型了。

## 在 Habana Gaudi 上微调文本分类模型

我先在刚启动的容器里 clone [Optimum Habana](https://github.com/huggingface/optimum-habana) 仓库。

```
git clone https://github.com/huggingface/optimum-habana.git
```

然后从源码安装 Optimum Habana 包。

```
cd optimum-habana
pip install .
```

接着，进入包含文本分类示例的子目录，安装所需的 Python 包。

```
cd examples/text-classification
pip install -r requirements.txt
```

现在可以启动训练任务了：它会从 Hugging Face hub 下载 [bert-large-uncased-whole-word-masking](https://huggingface.co/bert-large-uncased-whole-word-masking) 模型，并在 [GLUE](https://gluebenchmark.com/) 基准的 [MRPC](https://www.microsoft.com/en-us/download/details.aspx?id=52398) 任务上微调。

请注意，我这里从 Hugging Face hub 获取 BERT 的 Habana Gaudi 配置，你也可以用自己的。此外还有其他流行模型受到支持，其配置文件可在 [Habana 组织页](https://huggingface.co/Habana)找到。

```
python run_glue.py \
--model_name_or_path bert-large-uncased-whole-word-masking \
--gaudi_config_name Habana/bert-large-uncased-whole-word-masking \
--task_name mrpc \
--do_train \
--do_eval \
--per_device_train_batch_size 32 \
--learning_rate 3e-5 \
--num_train_epochs 3 \
--max_seq_length 128 \
--use_habana \
--use_lazy_mode \
--output_dir ./output/mrpc/
```

2 分 12 秒后任务完成，拿到了 0.9181 的出色 F1 分数，再多训几轮还能更高。

最后同样重要的一点：我终止 EC2 实例以避免不必要的花费。看看 EC2 控制台里的 [Savings Summary](https://console.aws.amazon.com/ec2sp/v2/home/spot)，多亏 Spot Instances 我省了 70%——每小时只花 3.93 美元而不是 13.11 美元。
