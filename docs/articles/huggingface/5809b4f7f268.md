##### Anyscale 团队 Richard Liaw 撰写的客座博文

凭借前沿的研究实现、数千个触手可及的训练好的模型，Hugging Face 的 [transformers](https://github.com/huggingface/transformers) 库已成为当今自然语言处理成功与增长的关键。

任何机器学习模型要取得好性能，用户往往需要实现某种参数调优。然而几乎所有人（[1](https://medium.com/@prakashakshay90/fine-tuning-bert-model-using-pytorch-f34148d58a37)、[2](https://mccormickml.com/2019/07/22/BERT-fine-tuning/#advantages-of-fine-tuning)）要么干脆忽略超参数调优，要么在小搜索空间上做一个简单的网格搜索。

不过，简单实验就能展示先进调优技术的收益。下面是[在 BERT 上的一次近期实验](https://medium.com/distributed-computing-with-ray/hyperparameter-optimization-for-transformers-a-guide-c4e32c6c989b)，模型来自 [Hugging Face transformers](https://github.com/huggingface/transformers)，数据集是 [RTE](https://aclweb.org/aclwiki/Textual_Entailment_Resource_Pool)。像 [PBT](https://docs.ray.io/en/latest/tune/api_docs/schedulers.html#population-based-training-tune-schedulers-populationbasedtraining) 这样的遗传优化技术，相比标准超参数优化技术可以带来大幅性能提升。

| **Algorithm** | **Best Val Acc.** | **Best Test Acc.** | **Total GPU min** | **Total $ cost** |
| --- | --- | --- | --- | --- |
| Grid Search | 74% | 65.4% | 45 min | $2.30 |
| Bayesian Optimization +Early Stop | 77% | 66.9% | 104 min | $5.30 |
| Population-based Training | 78% | 70.5% | 48 min | $2.45 |

如果你在用 [Transformers](https://github.com/huggingface/transformers)，你会希望有一种简单的方式接入强大的超参数调优方案，同时不放弃 Transformers 框架的可定制性。

[![alt_text](https://huggingface.co/blog/assets/06_ray_tune/ray-hf.jpg)](https://huggingface.co/blog/assets/06_ray_tune/ray-hf.jpg)

在 Transformers 3.1 发布版中，[Hugging Face Transformers](https://github.com/huggingface/transformers) 与 [Ray Tune](https://docs.ray.io/en/latest/tune/index.html) 联手提供了简单而强大的集成。[Ray Tune](https://docs.ray.io/en/latest/tune/index.html) 是一个流行的超参数调优 Python 库，开箱即用提供许多最先进算法，并与一线工具集成，如 [Weights and Biases](https://wandb.ai/) 和 tensorboard。

为了演示这个新的 [Hugging Face](https://github.com/huggingface/transformers) + [Ray Tune](https://docs.ray.io/en/latest/tune/index.html) 集成，我们利用 [Hugging Face Datasets 库](https://github.com/huggingface/datasets)在 [MRPC](https://www.microsoft.com/en-us/download/details.aspx?id=52398) 上微调 BERT。

运行本示例，请先执行：

**`pip install "ray[tune]" transformers datasets scipy sklearn torch`**

只需加几行代码，即可插入 Ray 的标准调优算法之一。

```
from datasets import load_dataset, load_metric
from transformers import (AutoModelForSequenceClassification, AutoTokenizer,
                          Trainer, TrainingArguments)

tokenizer = AutoTokenizer.from_pretrained('distilbert-base-uncased')
dataset = load_dataset('glue', 'mrpc')
metric = load_metric('glue', 'mrpc')

def encode(examples):
    outputs = tokenizer(
        examples['sentence1'], examples['sentence2'], truncation=True)
    return outputs

encoded_dataset = dataset.map(encode, batched=True)

def model_init():
    return AutoModelForSequenceClassification.from_pretrained(
        'distilbert-base-uncased', return_dict=True)

def compute_metrics(eval_pred):
    predictions, labels = eval_pred
    predictions = predictions.argmax(axis=-1)
    return metric.compute(predictions=predictions, references=labels)

# Evaluate during training and a bit more often
# than the default to be able to prune bad trials early.
# Disabling tqdm is a matter of preference.
training_args = TrainingArguments(
    "test", evaluation_strategy="steps", eval_steps=500, disable_tqdm=True)
trainer = Trainer(
    args=training_args,
    tokenizer=tokenizer,
    train_dataset=encoded_dataset["train"],
    eval_dataset=encoded_dataset["validation"],
    model_init=model_init,
    compute_metrics=compute_metrics,
)

# Default objective is the sum of all metrics
# when metrics are provided, so we have to maximize it.
trainer.hyperparameter_search(
    direction="maximize", 
    backend="ray", 
    n_trials=10 # number of trials
)
```

默认情况下，每个 trial 使用 1 个 CPU，如有可用则可选 1 个 GPU。通过传入 `resources_per_trial` 参数，你可以在并行的超参数搜索中利用多块 [GPU](https://docs.ray.io/en/latest/tune/user-guide.html#resources-parallelism-gpus-distributed)。

你也可以轻松切换不同的调优算法，如 [HyperBand](https://docs.ray.io/en/latest/tune/api_docs/schedulers.html#asha-tune-schedulers-ashascheduler)、[贝叶斯优化](https://docs.ray.io/en/latest/tune/api_docs/suggestion.html)、[基于群体的训练（Population-Based Training）](https://docs.ray.io/en/latest/tune/api_docs/schedulers.html#population-based-training-tune-schedulers-populationbasedtraining)：

运行本示例，请先执行：**`pip install hyperopt`**

```
from ray.tune.suggest.hyperopt import HyperOptSearch
from ray.tune.schedulers import ASHAScheduler

trainer = Trainer(
    args=training_args,
    tokenizer=tokenizer,
    train_dataset=encoded_dataset["train"],
    eval_dataset=encoded_dataset["validation"],
    model_init=model_init,
    compute_metrics=compute_metrics,
)

best_trial = trainer.hyperparameter_search(
    direction="maximize",
    backend="ray",
    # Choose among many libraries:
    # https://docs.ray.io/en/latest/tune/api_docs/suggestion.html
    search_alg=HyperOptSearch(metric="objective", mode="max"),
    # Choose among schedulers:
    # https://docs.ray.io/en/latest/tune/api_docs/schedulers.html
    scheduler=ASHAScheduler(metric="objective", mode="max"))
```
