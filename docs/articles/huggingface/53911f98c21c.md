[**LFM2.5-24B-A2B**](https://huggingface.co/LiquidAI/LFM2.5-24B-A2B) 是一个 24B 参数、激活参数只有 2B 的推理模型，专为在端侧运行快速、私密的智能体而打造。它会先思考再作答，会调用工具，能在主流智能体 harness 里完成多步骤任务。由于每个 token 只有 2B 参数处于激活状态，每个推理 token 都很便宜，于是你可以让智能体在自己的硬件上持续运行。

- **一流的智能体能力：** 在智能体任务与工具使用任务上和 Qwen3.6-35B-A3B 不相上下——后者的总参数与激活参数都多出约 50%。LiveClaw 上得分 48.09，对方为 38.19。
- **MoE 速度的推理：** 始终先思考再作答。每个 token 只有 2B 激活参数，因此每个推理 token 都很便宜。
- **高效推理：** 在 Apple M5 Max 上达到 184 tok/s，在单张 NVIDIA B300 GPU 上输出最高可达 21K tok/s。

## 我们如何构建只有 2B 激活参数的推理智能体

LFM2.5-24B-A2B 建立在 [LFM2-24B-A2B](https://huggingface.co/LiquidAI/LFM2-24B-A2B) 之上，并沿用了它的架构：40 层，每个 MoE block 含 64 个 expert、采用 top-4 routing，同样是门控短卷积（gated short convolutions）与 GQA 的混合结构。上下文窗口从 32K token 扩大到 131K token；一次[原地 tokenizer 扩展](https://www.liquid.ai/blog/tokenizer-expansion)把词表从 65K token 翻倍到 128K token，从而改善非拉丁文字的 tokenization。与前代不同，它是一个只做推理（reasoning-only）的模型，会在给出最终答案之前产出显式的思维链（chain of thought）。

预训练的规模从约 17T token 提升到约 33T token。中期训练（mid-training）随后加入 2T token 的 32K 上下文数据，配比偏向推理、数学、代码、指令遵循和多语言文本；再加入 300B token 的 131K 上下文数据，配比偏向长上下文数据。工具调用与多轮轨迹贯穿这两个阶段。后训练（post-training）分五个阶段把基座模型变成一个智能体：

- **监督微调（SFT，Supervised fine-tuning）**
- **教师模型专业化（Teacher specialization）**
- **多领域 on-policy 蒸馏（MOPD），非智能体任务：** 在非智能体任务上蒸馏这些专业化教师模型。
- **MOPD，智能体任务：** 第二个蒸馏阶段，聚焦智能体任务。
- **智能体强化学习（Agentic RL）：** 在智能体 harness 内训练模型，例如 [OpenClaw](https://openclaw.ai)、[Hermes Agent](https://hermes-agent.nousresearch.com)、[Pi](https://pi.dev) 和 [OpenCode](https://opencode.ai)。

## 基准测试结果

我们在 16 个基准上把 LFM2.5-24B-A2B 与 Qwen3.6-35B-A3B、Gemma-4-26B-A4B-it 和 Nemotron-3.5-Lightning 进行对比，覆盖工具使用与智能体工作流、知识、指令遵循、数学和编程。它是这一组里最小的模型，却能跟总参数与激活参数都多出约 50% 的 MoE 相抗衡。

| 基准 | LFM2.5-24B-A2B | Qwen3.6-35B-A3B | Gemma-4-26B-A4B-it | Nemotron-3.5-Lightning (30B-A3B) |
| --- | --- | --- | --- | --- |
| AutomationBench | **27.69** | 8.72 | 5.46 | 2.61 |
| BFCLv4 | **65.01** | 65.00 | 57.09 | 53.78 |
| ToolSandbox | **80.71** | 75.02 | 72.09 | 75.13 |
| LiveClaw | **48.09** | 38.19 | 41.25 | 37.72 |
| PinchBench | 83.18 | **89.93** | 77.12 | 84.20 |
| τ³-Bench Banking | **8.04** | 7.63 | 4.54 | 7.01 |
| WebArena Verified | 26.75 | **37.62** | 25.62 | 28.69 |
| GPQA Diamond | 74.42 | **83.69** | 74.90 | 72.42 |
| AA-Omniscience | -24.90 | -24.35 | -59.39 | **-3.58** |
| HLE | 7.40 | 7.69 | **8.57** | 5.65 |
| IFEval | **96.75** | 93.06 | 92.00 | 94.19 |
| IFBench | **74.69** | 64.21 | 47.44 | 71.67 |
| Multi-IF | **84.38** | 81.53 | 82.19 | 82.34 |
| MATH-500 | 96.04 | **96.73** | 95.66 | 96.40 |
| SWE-Bench Verified (OpenCode) | 51.00 | **66.20** | 25.80 | 53.40 |
| SciCode | 32.71 | **37.35** | 35.42 | 27.78 |

*所有模型都在 vLLM 上评测，并使用各个基准推荐的生成参数。

对你的应用来说，它的强项是工具使用和指令遵循。在 8 个工具使用与智能体基准中，LFM2.5-24B-A2B 在 5 个上领先或持平对手（AutomationBench、BFCLv4、ToolSandbox、LiveClaw 和 τ³-Bench Banking），而在 AutomationBench 上它的得分超过次优模型的三倍。3 个指令遵循基准它也全部领先。知识密集型基准（如 GPQA Diamond、HLE 和 AA-Omniscience）以及编程基准（如 SWE-Bench Verified (OpenCode) 和 SciCode）仍然是更大的模型占优，所以知识密集型的负载要把 LFM2.5-24B-A2B 与检索或网页搜索搭配起来用。

这些结果让 LFM2.5-24B-A2B 成为一个扎实的底座，适合那些需要推理、调用工具并在你的设备上可靠运行的智能体。

## CPU 与 GPU 上的推理速度

LFM2.5-24B-A2B 发布即打通了整个推理生态，包括 llama.cpp、MLX、vLLM、SGLang 和 ONNX。

**端侧推理。** 在所对比的 MoE 中，LFM2.5-24B-A2B 速度最快：在 M5 Max 上解码 184 tokens/s，在 Ryzen AI Max+ 395 上解码 114 tokens/s。相比次优模型最高快 1.7 倍，同时内存占用最少。

## 如何使用 LFM2.5-24B-A2B

当你需要会推理、会调用工具，又能在自己设备上稳定运行的智能体时，就选 LFM2.5-24B-A2B。

安装最新版本的 `transformers`（兼容 `transformers>=5.0.0`）：

```
pip install -U transformers
```

然后加载并运行模型：

```
from transformers import AutoModelForCausalLM, AutoTokenizer, TextStreamer

model_id = "LiquidAI/LFM2.5-24B-A2B"
model = AutoModelForCausalLM.from_pretrained(
    model_id,
    device_map="auto",
    dtype="bfloat16",
#   attn_implementation="flash_attention_2" <- uncomment on compatible GPU
)
tokenizer = AutoTokenizer.from_pretrained(model_id)
streamer = TextStreamer(tokenizer, skip_prompt=True, skip_special_tokens=True)

prompt = "What is C. elegans?"

input_ids = tokenizer.apply_chat_template(
    [{"role": "user", "content": prompt}],
    add_generation_prompt=True,
    return_tensors="pt",
    tokenize=True,
)["input_ids"].to(model.device)

output = model.generate(
    input_ids,
    do_sample=True,
    temperature=0.1,
    top_k=50,
    repetition_penalty=1.05,
    max_new_tokens=512,
    streamer=streamer,
)
```

### 在你的智能体 harness 中使用它

用任意 OpenAI 兼容后端在本地把 LFM2.5-24B-A2B 起成服务，然后让你的智能体 harness 指向它。例如，配合 Hermes Agent：

```
hermes config set model.provider custom
hermes config set model.base_url http://localhost:8080/v1
hermes config set model.default LFM2.5-24B-A2B
hermes config set model.context_length 131072
hermes config set model.api_mode chat_completions
hermes config set agent.tool_use_enforcement true
```

端口取决于你使用的服务后端：llama.cpp 和 MLX 用 `8080`，vLLM 用 `8000`，SGLang 用 `30000`，LM Studio 用 `1234`。OpenClaw 和 Pi 的配置见[模型卡](https://huggingface.co/LiquidAI/LFM2.5-24B-A2B)，完整搭建步骤见[我们的指南](https://docs.liquid.ai/examples/agent-harnesses)。视频示例请看我们的[发布博客](https://www.liquid.ai/blog/lfm2-5-24b-a2b)。
