# 用 Transformers 做图分类

Clémentine Fourrier（clefourrier）

本文另有中文版本 [简体中文](https://huggingface.co/blog/zh/graphml-classification)。

在上一篇[博客](https://huggingface.co/blog/intro-graphml)里，我们探讨了图上机器学习的部分理论内容。这一篇会探索如何用 Transformers 库做图分类。（你也可以跟着下载 demo notebook，[见这里](https://github.com/huggingface/blog/blob/main/notebooks/graphml-classification.ipynb)！）

目前，Transformers 里唯一可用的图 transformer 模型是微软的 [Graphormer](https://arxiv.org/abs/2106.05234)，所以这里我们就用它。我们很期待看到人们还会用和集成哪些其他模型 🤗

## 前置条件

要跟着本教程，你需要安装 `datasets` 和 `transformers`（版本 >= 4.27.2），可以用 `pip install -U datasets transformers` 完成。

## 数据

要使用图数据，你可以从自己的数据集开始，也可以用 [Hub 上可用的那些](https://huggingface.co/datasets?task_categories=task_categories:graph-ml&sort=downloads)。我们聚焦于使用已有的数据集，但欢迎你[添加自己的数据集](https://huggingface.co/docs/datasets/upload_dataset)！

### 加载

从 Hub 加载图数据集非常简单。我们加载 `ogbg-mohiv` 数据集（斯坦福 [Open Graph Benchmark](https://ogb.stanford.edu/) 的一个基线），它存放在 `OGB` 仓库里：

```
from datasets import load_dataset

# There is only one split on the hub
dataset = load_dataset("OGB/ogbg-molhiv")

dataset = dataset.shuffle(seed=0)
```

这个数据集已经有三个 split——`train`、`validation` 和 `test`，每个 split 都包含我们关心的 5 列（`edge_index`、`edge_attr`、`y`、`num_nodes`、`node_feat`），用 `print(dataset)` 就能看到。

如果你有别的图库，可以用它们来绘制图并进一步检查数据集。例如，用 PyGeometric 和 matplotlib：

```
import networkx as nx
import matplotlib.pyplot as plt

# We want to plot the first train graph
graph = dataset["train"][0]

edges = graph["edge_index"]
num_edges = len(edges[0])
num_nodes = graph["num_nodes"]

# Conversion to networkx format
G = nx.Graph()
G.add_nodes_from(range(num_nodes))
G.add_edges_from([(edges[0][i], edges[1][i]) for i in range(num_edges)])

# Plot
nx.draw(G)
```

### 格式

在 Hub 上，图数据集大多以图的列表形式存储（用 `jsonl` 格式）。

单个图是一个字典，下面是我们图分类数据集的期望格式：

- `edge_index` 包含边中节点的索引，存储为一个含两个平行边索引列表的列表。  **类型**：2 个整数列表组成的列表。 **示例**：一个含四个节点（0、1、2 和 3）、连接为 1->2、1->3 和 3->1 的图，会有 `edge_index = [[1, 1, 3], [2, 3, 1]]`。你可能注意到这里节点 0 没有出现，因为它本身不属于任何边。这就是下一个属性重要的原因。
- `num_nodes` 标明图中可用的节点总数（默认假设节点按顺序编号）。  **类型**：整数  **示例**：在上面的例子里，`num_nodes = 4`。
- `y` 把每个图映射到我们想从它预测的东西（可以是一个类别、一个属性值，或为不同任务的若干个二值标签）。 **类型**：整数列表（多类分类）、浮点数列表（回归），或由 0 和 1 组成的列表的列表（多任务二分类） **示例**：我们可以预测图的大小（small = 0，medium = 1，big = 2）。这里 `y = [0]`。
- `node_feat` 包含图中每个节点可用的特征（若存在），按节点索引排序。 **类型**：整数列表组成的列表（可选）  **示例**：上面我们的节点可以有，比如，类型（像分子里不同的原子）。这会给出 `node_feat = [[1], [0], [1], [1]]`。
- `edge_attr` 包含图中每条边可用的属性（若存在），遵循 `edge_index` 的顺序。 **类型**：整数列表组成的列表（可选） **示例**：上面我们的边可以有，比如，类型（像分子键）。这会给出 `edge_attr = [[0], [1], [1]]`。

### 预处理

图 transformer 框架通常会对数据集做特定的预处理，以生成有助于底层学习任务（我们这里是分类）的附加特征和属性。这里我们用 Graphormer 的默认预处理，它会生成入度/出度信息、节点之间的最短路径矩阵，以及其他模型感兴趣的属性。

```
from transformers.models.graphormer.collating_graphormer import preprocess_item, GraphormerDataCollator

dataset_processed = dataset.map(preprocess_item, batched=False)
```

也可以在 DataCollator 的参数里即时应用这个预处理（把 `on_the_fly_processing` 设为 True）：并非所有数据集都像 `ogbg-molhiv` 这么小，对于大图，事先存储所有预处理后的数据可能开销太大。

## 模型

### 加载

这里我们加载一个已有的预训练模型/checkpoint，并在我们的下游任务上微调它，这是一个二分类任务（因此 `num_classes = 2`）。我们也可以把模型微调到回归任务（`num_classes = 1`）或多任务分类上。

```
from transformers import GraphormerForGraphClassification

model = GraphormerForGraphClassification.from_pretrained(
    "clefourrier/pcqm4mv2_graphormer_base",
    num_classes=2, # num_classes for the downstream task 
    ignore_mismatched_sizes=True,
)
```

我们更详细地看看。

对模型调用 `from_pretrained` 方法会为我们下载并缓存权重。由于类别数（用于预测）取决于数据集，我们在 `model_checkpoint` 之外同时传入新的 `num_classes` 和 `ignore_mismatched_sizes`。这样会确保创建一个专属于我们任务的自定义分类头，因而很可能不同于原始的解码器头。

也可以创建一个随机初始化的新模型从头训练，既可以参照某个已知 checkpoint 的参数，也可以手动挑选。

### 训练或微调

为了简单地训练模型，我们会用一个 `Trainer`。要实例化它，我们需要定义训练配置和评估指标。最重要的是 `TrainingArguments`，它是一个包含所有用于自定义训练属性的类。它需要一个文件夹名，用来保存模型的 checkpoint。

```
from transformers import TrainingArguments, Trainer

training_args = TrainingArguments(
    "graph-classification",
    logging_dir="graph-classification",
    per_device_train_batch_size=64,
    per_device_eval_batch_size=64,
    auto_find_batch_size=True, # batch size can be changed automatically to prevent OOMs
    gradient_accumulation_steps=10,
    dataloader_num_workers=4, #1, 
    num_train_epochs=20,
    evaluation_strategy="epoch",
    logging_strategy="epoch",
    push_to_hub=False,
)
```

对于图数据集，反复试验 batch 大小和梯度累积步数尤为重要，以便在训练足够多样本的同时避免内存溢出错误。

最后一个参数 `push_to_hub` 允许 Trainer 在每个保存步于训练过程中定期把模型推送到 Hub。

```
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=dataset_processed["train"],
    eval_dataset=dataset_processed["validation"],
    data_collator=GraphormerDataCollator(),
)
```

在用于图分类的 `Trainer` 里，传入给定图数据集对应的特定数据整理器很重要，它会把单个图转换为用于训练的批次。

```
train_results = trainer.train()
trainer.push_to_hub()
```

模型训练完成后，可以用 `push_to_hub` 把它连同所有相关的训练产物一起保存到 hub。

由于这个模型相当大，在 CPU（IntelCore i7）上训练/微调 20 个 epoch 大约要花一天。要更快，你可以改用强大的 GPU 和并行化，比如在 Colab notebook 里或在你选择的集群上直接运行代码。
