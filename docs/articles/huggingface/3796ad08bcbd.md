## 什么是分词？

语言模型不读原始文本。它们消费的是通常称为 **token ID 或 input ID** 的整数序列。分词就是把原始文本转换成这些 token ID 的过程。（可以在[这个分词 playground](https://huggingface.co/spaces/Xenova/the-tokenizer-playground) 里可视化体验分词。）

分词是贯穿自然语言处理和文本处理的广泛概念。本文聚焦于使用 [`transformers`](https://github.com/huggingface/transformers) 和 [`tokenizers`](https://github.com/huggingface/tokenizers) 库为大语言模型（LLM）做的分词。

```
from transformers import AutoTokenizer
tokenizer = AutoTokenizer.from_pretrained("HuggingFaceTB/SmolLM3-3B")

text = "Hello world"
tokens = tokenizer(text)

print(tokens["input_ids"])
# [9906, 1917]

print(tokenizer.convert_ids_to_tokens(tokens["input_ids"]))
# ['Hello', 'Ġworld']
```

> Ġworld（上面）是一个单独的 token，代表带空格的字符序列 " world"。

**token** 是模型看到的最小字符串单元。它可以是一个字符、一个词，或像 "play"、"##ing" 这样的子词块（"##" 是一种模式，现在不完全理解也没关系 🤗）。**词表（vocabulary）**把每个唯一 token 映射到 token ID。

```
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("HuggingFaceTB/SmolLM3-3B")
print(tokenizer.vocab)

# {'ÎĹÎľ': 106502, 'ĠPeel': 89694, '.languages': 91078, ...}
```

好的分词器会把文本*压缩*成尽可能少的 token。token 更少，就意味着在不增大模型的前提下能用更多上下文。训练分词器归根到底是为目标数据集找到最好的压缩规则。比如处理中文语料时，有时会有[非常惊喜的发现 😉](https://x.com/suchenzang/status/1697862650053660721)。

## 分词管线

分词分阶段进行。每个阶段变换文本后传给下一个：

| 阶段 | 作用 | 示例 |
| --- | --- | --- |
| **Normalizer（规范化器）** | 标准化文本（小写化、unicode 规范化、空白清理） | `"HELLO World"` → `"hello world"` |
| **Pre-tokenizer（预分词器）** | 把文本切成初步块 | `"hello world"` → `["hello", " world"]` |
| **Model（模型）** | 应用分词算法（BPE、Unigram 等） | `["hello", " world"]` → `[9906, 1917]` |
| **Post-processor（后处理器）** | 添加特殊 token（BOS、EOS、padding） | `[9906, 1917]` → `[1, 9906, 1917, 2]` |
| **Decoder（解码器）** | 把 token ID 转回文本 | `[9906, 1917]` → `"hello world"` |

每个组件都是*独立的*。你可以换 [normalizer](https://huggingface.co/docs/tokenizers/en/api/normalizers) 或改[算法](https://huggingface.co/docs/tokenizers/en/api/models)，而不必重写其他任何东西。

> 可以通过 _tokenizer 访问基于 Rust 的分词器。本节会深入讲这一点。

```
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("google/gemma-3-270m-it")

print(f"{tokenizer._tokenizer.normalizer=}")
# Replace(...)

print(f"{tokenizer._tokenizer.pre_tokenizer=}")
# Split(...)

print(f"{tokenizer._tokenizer.model=}")
# BPE(...)

print(f"{tokenizer._tokenizer.post_processor=}")
# TemplateProcessing(...)

print(f"{tokenizer._tokenizer.decoder=}")
# Sequence(decoders=[Replace(...), ByteFallback(), Fuse()])
```

## 分词算法

现代语言模型分词器以以下几种算法为主：

- **字节对编码（BPE）**：迭代合并出现频率最高的字符对。该算法是确定性的、应用最广。（延伸阅读：[BPE](https://huggingface.co/learn/llm-course/en/chapter6/5)）

```
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("openai/gpt-oss-20b")
print(tokenizer._tokenizer.model)

# BPE(...)
```

- **Unigram**：走概率路线，从一个很大的初始词表中选出最可能的切分。相比严格的 BPE 更灵活。（延伸阅读：[Unigram](https://huggingface.co/learn/llm-course/en/chapter6/7)）

```
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("google-t5/t5-base")
print(tokenizer._tokenizer.model)

# Unigram(...)
```

- **WordPiece**：类似 BPE，但合并准则基于似然。（延伸阅读：[WordPiece](https://huggingface.co/learn/llm-course/en/chapter6/6)）

```
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("bert-base-uncased")
print(tokenizer._tokenizer.model)

# WordPiece(...)
```

## 通过 transformers 访问 tokenizers

[`tokenizers`](https://github.com/huggingface/tokenizers) 库是一个基于 Rust 的分词引擎：快、高效、完全与语言模型无关。它负责把文本变成 token ID、再变回来的机制。`tokenizers` 是通用工具，实现了分词算法，但没有实现"把算法接到具体语言模型上"的那些约定。

看看直接用 `tokenizers` 配 [`SmolLM3-3B`](http://hf.co/HuggingFaceTB/SmolLM3-3B) 模型会发生什么：

```
from tokenizers import Tokenizer

tokenizer = Tokenizer.from_pretrained("HuggingFaceTB/SmolLM3-3B")
text = "Hello world"
encodings = tokenizer.encode(text)

print(encodings.ids)
# [9906, 1917]
print(encodings.tokens)
# ['Hello', 'Ġworld']
```

输出是原样分词结果：token ID 和它们对应的字符串片段，仅此而已。

再想想缺了什么。`SmolLM3-3B` 是一个*对话模型*。与它交互时，输入通常组织成带 "user"、"assistant" 等角色的对话，语言模型期望有特殊格式 token 来标示这些角色。原始的 `tokenizers` 库完全没有这些概念。

### 如何弥合原始分词与模型需求之间的鸿沟？

`transformers` 库就是这座桥。它以"模型定义库"著称，但同时提供了一层分词器抽象，把原始 `tokenizers` 后端包起来，加上面向模型的功能。

用 `transformers` 的包装做同样的分词：

```
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("HuggingFaceTB/SmolLM3-3B")

# Format a conversation using the model's chat template
prompt = "Give me a brief explanation of gravity in simple terms."
messages = [{"role": "user", "content": prompt}]
text = tokenizer.apply_chat_template(
    messages,
    tokenize=False,
    add_generation_prompt=True,
)

print(text)

#
