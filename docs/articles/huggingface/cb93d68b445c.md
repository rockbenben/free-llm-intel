现在，您可以将 Hugging Face 组织关联到您的 Google Cloud 帐号，这样您的 Hugging Face 使用情况就会显示在您的 Google Cloud 账单上，而不是从信用卡中扣除。开始使用[在 Google Cloud Marketplace 上](https://console.cloud.google.com/marketplace/product/huggingface-public/hugging-face-hub)。

## 为什么通过 Google Cloud 付款？

Hugging Face 是团队查找、构建和运行开放模型的地方：从托管私有模型和数据集，到使用 [Jobs](https://huggingface.co/docs/hub/jobs-overview) 运行 GPU 工作负载、使用 [Inference Endpoints](https://huggingface.co/docs/inference-endpoints) 部署模型、通过 [Inference Providers](https://huggingface.co/docs/inference-providers) 调用数千个模型，或在 GPU [Spaces](https://huggingface.co/docs/hub/spaces-overview) 上托管演示。

如果您的公司已经在 Google Cloud 上运行，那么仅仅为了使用这些服务而添加新供应商和公司信用卡可能会减慢速度。通过 Google Cloud Marketplace 关联您的组织：

- **一张账单**：您的 Hugging Face 使用情况会显示在您现有的 Google Cloud 发票上，位于其余云支出旁边。
- **没有新供应商加入**：购买将通过您现有的 Google Cloud 结算帐号和采购流程进行。
- **一切都涵盖**：将您的组织升级到 [团队或企业](https://huggingface.co/enterprise) 订阅、即用即付计算（作业、推理端点、推理提供商、GPU 空间、ZeroGPU 配额扩展）以及 [公共 Hugging Face 定价](https://huggingface.co/pricing) 的额外存储。

如果您是 Hugging Face 组织的管理员，请按照以下步骤进行设置。

### 1. 在 Google Cloud Marketplace 上订阅 Hugging Face

前往 Google Cloud Marketplace 上的 [Hugging Face Hub 列表](https://console.cloud.google.com/marketplace/product/huggingface-public/hugging-face-hub)，选择您要使用的 Google Cloud 项目，然后点击“订阅”。

[![Hugging Face Hub 在 Google Cloud Marketplace 上列出](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/marketplace-product-listing.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/marketplace-product-listing.png)

您现在位于订阅页面。选择要收费的计费帐户，查看并接受条款，然后单击“订阅”。

[![包含计费帐户选择和条款的订阅页面](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/marketplace-subscribe-page.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/marketplace-subscribe-page.png)

下订单后，Google Cloud 会要求您完成 Hugging Face 帐户的设置。点击“注册Hugging Face”即可重定向到Hugging Face。

[![订单请求已发送至 Hugging Face，并带有“通过 Hugging Face 注册”按钮](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/marketplace-order-sent-signup.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/marketplace-order-sent-signup.png)

### 2. 链接您的 Hugging Face 组织

您现在位于 Hugging Face，可以在其中选择要链接到您的 Google Cloud 帐户的组织。仅列出您作为管理员的组织。选择它并确认。

[![选择 Hugging Face 组织链接到 Google Cloud帐户](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/select-organization-to-link.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/select-organization-to-link.png)

然后，您将被重定向到您组织的计费设置。付款方式部分现在显示关联的 Google Cloud 帐户，且状态为待处理。

[![组织结算设置将关联的 Google Cloud 帐户显示为待定](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/billing- payment-method-pending.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/billing- payment-method-pending.png)

每个云市场订阅都经过 Hugging Face 团队的审核，然后才开始通过 Hugging Face 计费。在订阅待处理期间，使用量将继续按组织现有的付款方式（如果有）计费。

### 3. 订阅已批准

您的订阅获得批准后，您将收到一封电子邮件，确认您的 Google Cloud 帐户与 Hugging Face 组织已关联。已存档信用卡的组织会在下一个计费周期开始时切换到云市场计费。没有信用卡备案的免费层组织通常会立即切换，因此他们的付费使用会立即通过云市场进行计费。

[![确认 Marketplace 帐户已被批准作为付款的电子邮件方法](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/approval-confirmation-email.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/approval-confirmation-email.png)

要进行确认，请打开[您的组织](https://huggingface.co/settings/organizations) 的结算设置：Google Cloud 帐号现在显示为组织的有效付款方式。

[![组织结算设置显示 Google Cloud 帐号作为有效付款方法](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/billing- payment-method-active.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/billing- payment-method-active.png)

### 恭喜！

您的组织现在通过您的 Google Cloud 帐号进行计费。您组织的所有成员都可以使用 Hugging Face 计算服务，并且使用情况将显示在您的 Google Cloud 账单上。

有几件事值得了解：

- **Google Cloud 取代信用卡** 作为组织的付款方式。使用情况会进行计量并向 Google Cloud 报告，因此当组织通过市场进行计费时，无法添加积分。
- **包含的积分仍然适用**：如果您的组织有团队或企业订阅，则在向 Google Cloud 报告任何即用即付使用情况之前，会应用每月包含的积分。
- **随时从[组织设置](https://huggingface.co/settings/organizations)的结算部分监控您的使用情况**，并在 Google Cloud 控制台的[结算报告](https://console.cloud.google.com/billing)中查找费用。
- **链接和取消链接都会经过审核**：这两个操作都会记录在您组织的[审核日志](https://huggingface.co/docs/hub/audit-logs)中。

感谢您的阅读！您可以在[计费文档](https://huggingface.co/docs/hub/billing#cloud-providers-partnerships)中找到更多详细信息。如果您有任何疑问，请通过 [billing@huggingface.co](mailto:billing@huggingface.co) 与我们联系。
