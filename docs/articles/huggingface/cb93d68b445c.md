现在可以把 Hugging Face 组织关联到自己的 Google Cloud 账号，Hugging Face 的用量就会记在 Google Cloud 账单上，而不再从信用卡扣款。可以从 [Google Cloud Marketplace](https://console.cloud.google.com/marketplace/product/huggingface-public/hugging-face-hub) 开始。

## 为什么通过 Google Cloud 付款？

Hugging Face 是团队查找、构建和运行开放模型的地方：托管私有模型和数据集、用 [Jobs](https://huggingface.co/docs/hub/jobs-overview) 跑 GPU 工作负载、用 [Inference Endpoints](https://huggingface.co/docs/inference-endpoints) 部署模型、通过 [Inference Providers](https://huggingface.co/docs/inference-providers) 调用数千个模型，或在 GPU [Spaces](https://huggingface.co/docs/hub/spaces-overview) 上托管演示。

如果公司本来就跑在 Google Cloud 上，只为用这些服务就新增一家供应商、再办一张企业信用卡，会把事情拖慢。通过 Google Cloud Marketplace 关联组织之后：

- **一张账单**：Hugging Face 的用量出现在现有的 Google Cloud 发票上，与其他云支出列在一起。
- **无需新增供应商**：购买走现有的 Google Cloud 结算账号和采购流程。
- **全都覆盖**：把组织升级到 [Team 或 Enterprise](https://huggingface.co/enterprise) 订阅、即用即付的计算（Jobs、Inference Endpoints、Inference Providers、GPU Spaces、ZeroGPU 配额扩展），以及按 [Hugging Face 公开定价](https://huggingface.co/pricing) 计费的额外存储。

如果你是 Hugging Face 组织的管理员，按下面的步骤一步步设置。

### 1. 在 Google Cloud Marketplace 上订阅 Hugging Face

打开 Google Cloud Marketplace 上的 [Hugging Face Hub 商品页](https://console.cloud.google.com/marketplace/product/huggingface-public/hugging-face-hub)，选好要用的 Google Cloud 项目，点击「Subscribe」。

[![Google Cloud Marketplace 上的 Hugging Face Hub 商品页](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/marketplace-product-listing.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/marketplace-product-listing.png)

现在到了订阅页面。选择用于扣款的结算账号，查看并接受条款，然后点击「Subscribe」。

[![含结算账号选择与条款的订阅页面](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/marketplace-subscribe-page.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/marketplace-subscribe-page.png)

下单之后，Google Cloud 会让你完成 Hugging Face 账号的设置。点击「Sign up with Hugging Face」，就会跳转到 Hugging Face。

[![订单请求已发送到 Hugging Face，页面上有「Sign up with Hugging Face」按钮](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/marketplace-order-sent-signup.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/marketplace-order-sent-signup.png)

### 2. 关联 Hugging Face 组织

现在到了 Hugging Face，可以在这里选择要关联到 Google Cloud 账号的组织。列表里只显示你担任管理员的组织。选中并确认。

[![选择要关联到 Google Cloud 账号的 Hugging Face 组织](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/select-organization-to-link.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/select-organization-to-link.png)

随后会跳转到组织的结算设置。付款方式一栏现在显示已关联的 Google Cloud 账号，状态为待处理。

[![组织结算设置中，已关联的 Google Cloud 账号显示为待处理](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/billing-payment-method-pending.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/billing-payment-method-pending.png)

每一笔云市场订阅都要先经 Hugging Face 团队审核，之后付费用量才会开始通过它计费。订阅待处理期间，用量仍按组织现有的付款方式（如有）计费。

### 3. 订阅获批

订阅获批后，你会收到一封邮件，确认 Google Cloud 账号与 Hugging Face 组织已关联。已留存信用卡的组织会在下一个计费周期开始时切换到云市场计费；没有留存信用卡的免费层组织通常会立即切换，付费用量马上就通过云市场计费。

[![确认 Marketplace 账号已获批作为付款方式的邮件](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/approval-confirmation-email.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/approval-confirmation-email.png)

想确认的话，打开[你的组织](https://huggingface.co/settings/organizations) 的结算设置：Google Cloud 账号现在已显示为组织当前生效的付款方式。

[![组织结算设置中，Google Cloud 账号显示为当前生效的付款方式](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/billing-payment-method-active.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/hub-gcp-marketplace/billing-payment-method-active.png)

### 恭喜！

你的组织现在通过 Google Cloud 账号计费。组织里的所有成员都能使用 Hugging Face 的计算服务，用量会体现在 Google Cloud 账单上。

有几点值得了解：

- **Google Cloud 取代信用卡**，成为组织的付款方式。用量会被计量并上报给 Google Cloud，因此组织通过云市场计费期间，无法再充值积分。
- **内含积分仍然有效**：如果组织订的是 Team 或 Enterprise 订阅，每月内含的积分会先抵扣，之后才把即用即付的用量上报给 Google Cloud。
- **随时监控用量**：到[组织设置](https://huggingface.co/settings/organizations) 的结算版块查看，费用则可在 Google Cloud 控制台的[账单报告](https://console.cloud.google.com/billing) 里找到。
- **关联与解除关联都有审计**：两个操作都会记进组织的[审计日志](https://huggingface.co/docs/hub/audit-logs)。

感谢阅读！更多细节见[计费文档](https://huggingface.co/docs/hub/billing#cloud-providers-partnerships)。如有疑问，请通过 [billing@huggingface.co](mailto:billing@huggingface.co) 联系我们。
