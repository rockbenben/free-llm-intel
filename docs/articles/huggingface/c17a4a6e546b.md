# 伦理与社会通讯 #1

Hello, world!

Hugging Face 源自开源公司，创立于若干关键技术伦理价值观之上：*协作*、*责任*与*透明*。在开放环境中编码，意味着你的代码——以及其中的每一个选择——对全世界可见，与你的账号相关联，供他人批评和补充。当研究社区开始使用 Hugging Face Hub 托管模型和数据时，社区直接把*可复现性*融入为公司另一项基本价值观。随着 Hugging Face 上的数据集和模型数量增长，Hugging Face 的成员们落地了[文档要求](https://huggingface.co/docs/hub/models-cards)和[免费的指导课程](https://huggingface.co/course/chapter1/1)，用围绕*可审计性*与*理解*（理解造就当今技术的数学、代码、流程与人）的补充性价值观，回应研究社区新形成的价值诉求。

如何在 AI 中落实伦理仍是一个开放的研究领域。尽管关于应用伦理与人工智能的理论和学术研究已存在数十年，AI 开发内部经过应用和检验的伦理实践只是在最近 10 年才开始涌现。这部分是因为机器学习模型——AI 系统的构件——的进步早已超出衡量它的基准，导致机器学习系统被广泛采用于影响日常生活的一系列实际应用中。对我们这些致力于推动伦理知情的 AI 的人来说，加入一家部分建立在伦理原则之上、正处于成长期、而全世界人民也开始直面 AI 伦理问题的机器学习公司，是一个从根本上塑造未来 AI 面貌的机会。这是一种新型的现代 AI 实验：一家*从一开始*就把伦理放在心上的技术公司应该是什么样子？用伦理的视角聚焦机器学习，[民主化*好的* ML](https://huggingface.co/huggingface)意味着什么？

为此，我们在全新的 Hugging Face *伦理与社会*通讯中分享了一些近期的思考与工作，该通讯将在每个分点和至点、即每季度发布一期。就是现在这篇！它由我们——"伦理与社会常驻小组"（Ethics and Society regulars）——编写，这是一个横跨公司的开放团体，成员以平等的身份聚在一起，探讨机器学习在更广阔社会背景下的处境以及 Hugging Face 在其中扮演的角色。我们坚信我们**不**应该是一个专职团队：一家公司要让基于价值观的决策贯穿全部工作与流程，就需要所有相关方共同承担责任制，承认并学习我们工作背后的伦理利害。

我们在持续研究关于"好的"ML 之含义的实践与研究，试图给出一些可以定义它的标准。这是一个进行中的过程，我们从展望未来 AI 的多种可能图景入手，在当下创造我们所能创造的，使我们抵达一个能调和个体与更广泛 ML 社区所持不同价值的状态。我们把这一路径扎根于 Hugging Face 的创立原则：

- 我们寻求与开源社区*协作*。这包括提供现代化的[文档](https://huggingface.co/docs/hub/models-cards)与[评估](https://huggingface.co/blog/eval-on-the-hub)工具，以及[社区讨论](https://huggingface.co/blog/community-update)、[Discord](http://discuss.huggingface.co/t/join-the-hugging-face-discord/)，并为希望以兼顾多种价值的方式分享成果的贡献者提供个人支持。
- 我们寻求在思考与流程的演进过程中保持*透明*。这包括在项目[启动之初](https://huggingface.co/blog/ethical-charter-multimodal)分享具体项目的价值观文章，以及我们对 [AI 政策](https://huggingface.co/blog/us-national-ai-research-resource)的思考。我们也从社区对这些工作的反馈中获益，把它们当作学习"该怎么做"的资源。
- 我们把创建这些工具和产出物立足于对当下与未来影响的*责任*。将此置于优先地位，带来了让机器学习系统更*可审计*、更*可理解*（包括对 ML 之外领域专家）的项目设计——例如[教育项目](https://huggingface.co/blog/education)，以及我们[无需编程的 ML 数据分析实验工具](https://huggingface.co/spaces/huggingface/data-measurements-tool)。

基于这些根本，我们采取一种以项目的具体情境及其可预见影响为中心的价值观落实方式。因此，这里不提供任何全球通用的价值观或原则清单；相反，我们持续分享[项目专属的思考](https://huggingface.co/blog/ethical-charter-multimodal)，比如本通讯，并将随着理解加深分享更多内容。由于我们相信社区讨论是识别不同价值诉求及受影响人群的关键，我们最近开放了渠道：任何能联网访问 Hugging Face Hub 的人都可以对[模型、数据和 Spaces 直接提供反馈](https://huggingface.co/blog/community-update)。除了开放讨论的工具，我们还制定了[行为准则](https://huggingface.co/code-of-conduct)和[内容指南](https://huggingface.co/content-guidelines)，帮助讨论沿我们认为对包容性社区空间重要的维度展开。我们开发了用于安全 ML 开发的 [Private Hub](https://huggingface.co/blog/introducing-private-hub)、让开发者更容易严格评估模型的[评估库](https://huggingface.co/blog/eval-on-the-hub)、[分析数据偏斜与偏差的代码](https://github.com/huggingface/data-measurements-tool)，以及[追踪模型训练碳排放的工具](https://huggingface.co/blog/carbon-emissions-on-the-hub)。我们还在制定[新的开放且负责任的 AI 许可](https://huggingface.co/blog/open_rail)，一种直接回应 AI 系统可能造成伤害的现代许可形式。而本周，我们上线了对模型和 Spaces 仓库进行"标记"（flag）的功能，以便报告伦理与法律问题。

未来几个月，我们还将编写多篇关于价值观、张力与伦理落实的文章。我们欢迎（也渴望）对我们全部工作的反馈，并希望继续通过技术与价值观的双重视角与 AI 社区互动。

感谢阅读！🤗

~ Meg，代表伦理与社会常驻小组
