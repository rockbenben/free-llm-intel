# Prodigy-HF 发布：与 Hugging Face 的直接集成

[Prodigy](https://prodi.gy/) 是 [Explosion](https://explosion.ai/) 公司打造的标注工具，这家公司以创建 [spaCy](https://spacy.io/) 而闻名。它是一个完全可脚本化的产品，拥有庞大的社区。产品功能很多，包括与 spaCy 的紧密集成和主动学习能力。但它最主要的特性是可以通过 Python 进行程序化的自定义。

为了促进这种可定制性，Explosion 开始发布[插件](https://prodi.gy/docs/plugins)。这些插件以开放的方式与第三方工具集成，鼓励用户构建定制化的标注工作流。不过，有一个定制特别值得专门庆祝：上周，Explosion 推出了 [Prodigy-HF](https://github.com/explosion/prodigy-hf)，提供直接与 Hugging Face 技术栈集成的代码 recipe。这在 [Prodigy 支持论坛](https://support.prodi.gy/)上是被反复请求的功能，所以我们非常高兴它终于上线了。

## 功能

第一个主要功能是该插件可以在你标注的数据上训练并复用 Hugging Face 模型。也就是说，如果你一直在我们的界面里为命名实体识别标注数据，可以直接基于这些数据微调 BERT 模型。

Prodigy NER 界面长什么样。

安装插件后，你可以在命令行调用 `hf.train.ner` recipe，直接在你自己的数据上训练 transformer 模型。

```
python -m prodigy hf.train.ner fashion-train,eval:fashion-eval path/to/model-out --model "distilbert-base-uncased"
```

这会在你存于 Prodigy 的数据集上微调 `distilbert-base-uncased` 模型并保存到磁盘。类似地，该插件也支持通过几乎相同的接口进行文本分类模型训练。

```
python -m prodigy hf.train.textcat fashion-train,eval:fashion-eval path/to/model-out --model "distilbert-base-uncased"
```

这提供了极大的灵活性，因为该工具直接集成了 Hugging Face transformers 的 `AutoTokenizer` 和 `AutoModel` 类。Hub 上的任何 transformer 模型都只需一条命令就能在你自己的数据集上微调。这些模型会被序列化保存到磁盘，意味着你可以把它们上传到 Hugging Face Hub，或者复用来辅助你标注数据。这能省下大量时间，对 NER 任务尤其如此。要复用已训练的 NER 模型，可以使用 `hf.correct.ner` recipe。

```
python -m prodigy hf.correct.ner fashion-train path/to/model-out examples.jsonl
```

这会给你与之前类似的界面，但现在模型预测也会一并显示在界面中。

### 上传

同样令人兴奋的第二个功能是：你现在还可以把标注好的数据集发布到 Hugging Face Hub。如果你有分享数据集给他人使用的意愿，这非常合适。

```
python -m prodigy hf.upload <dataset_name> <username>/<repo_name>
```

我们特别喜欢这个上传功能，因为它鼓励协作。人们可以各自独立标注自己的数据集，但在把数据分享给更广泛的社区时，大家都能从中受益。

## 更多精彩即将到来

我们希望这种与 Hugging Face 生态的直接集成能让更多用户放心实验。Hugging Face Hub 为各种任务、各种语言提供了*大量*[模型](https://huggingface.co/models)。我们真心希望这次集成让数据标注变得更简单，即使你面对的是更领域特定、更实验性的用例。

该库的更多功能已在路上，如有更多问题，欢迎到 [Prodigy 论坛](https://support.prodi.gy/)提问。

我们还要感谢 Hugging Face 团队对这个插件的反馈，特别是 @davanstrien，是他建议加入上传功能的。谢谢！
