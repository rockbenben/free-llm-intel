## Llama Nemotron Nano VL 简介

[Llama Nemotron Nano VL](https://huggingface.co/nvidia/Llama-3.1-Nemotron-Nano-VL-8B-V1) 是 [NVIDIA Nemotron](https://www.nvidia.com/en-us/ai-data-science/foundation-models/nemotron/) 模型家族的最新成员，是一个为突破智能文档处理（IDP）和光学字符识别（OCR）边界而设计的视觉语言模型（VLM）。它以高精度、小模型体积和多模态能力，实现对复杂文档信息的无缝提取与理解——包括 PDF、图像、表格、图表、公式和示意图，非常适合金融、医疗、法律、政府等各行业的文档工作流自动化。

## 高精度的 Llama Nemotron Nano VL OCR

Llama Nemotron Nano VL 在 [OCRBench v2 基准](https://huggingface.co/spaces/ling99/OCRBench-v2-leaderboard)上展现出非凡精度。该基准用真实世界的 OCR 与文档理解任务考验模型，涵盖多种文档类型上的文本识别、表格抽取和元素解析。模型的高级能力让它在真实企业场景中的表现优于当前领先的 VLM。

### Llama Nemotron Nano VL 在 OCRBench v2 上的表现：

- **文本识别**：Llama Nemotron Nano VL 擅长发现并提取文本，在发票处理等真实 OCR 任务中达到高精度。
- **元素解析**：模型能准确识别并提取表格、图表、图像等关键文档元素，这对理解复杂文档至关重要。
- **表格抽取**：从文档中抽取表格数据非常精准，适用于财务报表及类似场景。
- **定位（Grounding）**：还支持在查询和输出中使用边界框进行定位，增强模型响应的可解释性。

## 模型架构与创新

Llama Nemotron Nano VL 构建在 [Llama-3.1-8B-Instruct](https://huggingface.co/meta-llama/Llama-3.1-8B-Instruct) 和 [C-RADIOv2-VLM-H](https://huggingface.co/nvidia/C-RADIOv2-VLM-H) 之上，后者是一个视觉 Transformer（ViT），作为视觉特征提取的主干。这让模型能处理文档中各种各样的视觉元素，包括图表、图形和其他复杂可视化。

### 核心技术

#### 强大的视觉基础

**C-RADIOv2-VLM-H 视觉 Transformer（ViT）**：模型视觉理解的核心组件。C-RADIO 支持对含复杂视觉元素文档的高分辨率处理。它作为视觉主干在各视觉领域表现出色，使模型能以高分辨率处理多图理解。这项技术支撑了模型处理含图像、示意图、图表、表格等视觉元素的复杂文档的能力。

C-RADIO 使用多种蒸馏技术在多分辨率数据上训练。训练期间我们对权重施加了乘性噪声以提升泛化。

Llama Nemotron VL 进一步采用了一种动态聚合编码 patch 特征的设计，在不牺牲空间连续性的前提下支持高分辨率输入。这一策略能高效处理任意宽高比的文档，同时保留局部细节和全局上下文。它能在不损害计算效率与覆盖范围的情况下，对密集视觉内容（如小字号、多栏排版、复杂图表）做细粒度分析。由于高分辨率分块（tiling）上的创新，模型还能更好地保留信息、更少失真。

用这一强大视觉基础武装 Llama-3.1 8B LLM，Llama Nemotron Nano VL 在文档解析与解读上交付了无与伦比的精度。

#### 面向文档智能的高质量数据

Llama Nemotron Nano VL 的训练使用了多个开源数据集，以及来自 NVIDIA 基于 VLM 的 OCR 解决方案 [NeMo Retriever Parse](https://build.nvidia.com/nvidia/nemoretriever-parse) 的数据。这赋予了文本和表格解析以及定位能力，让 Llama Nemotron Nano VL 在文档理解任务上达到行业领先水平。用于训练该 OCR 方案的合成表格抽取数据集，也用于训练 Llama Nemotron Nano VL 8B VLM，以实现更优的表格理解与抽取。

Llama Nemotron Nano VL 在文本识别、视觉推理等任务上表现出色，并展现出先进的图表与示意图理解能力。它可以在归一化空间中预测边界框坐标，实现定位类任务和文本指代。

强劲表现的背后是高质量的领域内数据，加上跨文档类型、语言和版式的多样化训练分布。健壮的数据策略通过选择性策展、针对性增强和能澄清任务意图、减少歧义的格式化手段，确保对高难度使用场景的覆盖——从而让模型有效泛化到真实应用。

##### 预训练

Llama Nemotron Nano VL 经过两阶段训练：先预训练，再监督微调（SFT）。初始预训练阶段聚焦语言与视觉两个域之间的跨模态对齐，通过训练一个多层感知机（MLP）连接器来实现，它充当两种模态之间的接口。

训练过程使用了大而多样的数据集合集。这个总计约 150 万样本的聚合数据集包含公开数据、合成生成数据以及内部策划的数据。预训练阶段所用数据集概览见图 1。

图 1：Llama Nemotron Nano VL 预训练所用数据集的构成

##### 监督微调

在监督微调阶段，Llama-Nemotron-Nano-VL 在合成、公开和内部策划数据集的组合上端到端训练。数据涵盖大量任务，包括但不限于：OCR、文本定位、表格解析和通用文档 VQA（视觉问答）。

Llama Nemotron Nano VL 的文档理解能力很大程度上归功于以 OCR 为核心的 SFT 数据配比。除了简单 OCR，许多数据集还涉及预测正确阅读顺序、重构 markdown 格式并附带语义类别（如 Caption、Title、章节标题）以及每个文本块边界框等任务。模型还被训练解析 LaTeX 格式的数学公式，并按提示以 LaTeX、HTML 或 markdown 格式抽取表格。

为确保跨各领域的鲁棒性，我们对文档图像施加仿射和光度增强。为了进一步提升表格和图表解析表现，我们让不同数据集中的表格和图表可以互换嵌入到整页文档中。这让模型能够处理多样的文档版式与结构。

大量内部创建的数据集基于 NeMo Retriever Parse 的训练数据。其中包括 NVPDFTex——一套带真实标签的 arxiv 文档集，标签为按阅读顺序排布的格式化文本，附边界框和文本语义类别，以及 LaTeX 表格和公式；由人工标注的 Common Crawl PDF；带 markdown 格式和表格的 Wikipedia 渲染文本；以及一批针对表格解析能力和密集 OCR 的合成数据集。此外，训练配比还纳入了多个公开数据集，如 DocLayNet、FinTabNet 和 PubTables-1M，我们对它们的真实标签做了修正。

### 推荐提示词

为了确保输出严格按你需要的格式生成，我们建议**在提示词里写明详细指令**。下面提供一些示例，说明在不同任务上该怎么写：

#### 按阅读顺序抽取文档，附定位和语义类别

```
Parse this document in reading order as mathpix markdown with LaTeX equations and tables. Fetch the bounding box for each block along with the corresponding category from the following options: Bibliography, Caption, Code, Footnote, Formula, List-item, Page-footer, Page-header, Picture, Section-header, TOC (Table-of-Contents), Table, Text and Title. The coordinates should be normalized ranging from 0 to 1000 by the image width and height.
Your answer should be in the following format:\n[{{"bbox": [x1, y1, x2, y2], "category": category, "content": text_content)}}...].
```

#### 面向 RD-TableBench 的表格抽取

```
Convert the image to an HTML table. The output should begin with <table> and end with </table>. Specify rowspan and colspan attributes when they are greater than 1. Do not specify any other attributes. Only use the b, br, tr, th, td, sub and sup HTML tags. No additional formatting is required.
```

#### 带定位的表格抽取

```
Transcribe the tables as HTML and extract their bounding box coordinates. The coordinates should be normalized ranging from 0 to 1000 by the image width and height and the answer should be in the following format:\n[(x1, y1, x2, y2, html table), (x1, y1, x2, y2, html table)...].
```

## OCRBench v2 基准：更深入地看

[OCRBench v2](https://huggingface.co/spaces/ling99/OCRBench-v2-leaderboard) 是一个高级基准，旨在校验 OCR 模型在多样真实文档类型和版式上的能力。它包含超过 **1 万组人工验证的问答对**，严格评估模型在视觉文本定位、表格解析、示意图推理和键值抽取上的能力。

Llama Nemotron Nano VL 在该基准上胜过其他 VLM，并在 **ChartQA**、**AI2D** 等基准上取得很强精度，使它成为希望自动化文档工作流（例如）的企业的诱人选择：

- 发票与收据处理
- 合规与身份证件分析
- 合同与法律文档审阅
- 医疗与金融文档处理

高精度、强大的版式感知推理、单 GPU 即可高效部署——这些组合让它成为大型企业自动化的理想之选。
