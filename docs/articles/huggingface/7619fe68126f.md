# Jupyter 牵手 Hugging Face

**我们很高兴地宣布，对托管在 Hugging Face Hub 上的 Jupyter notebook 的支持得到了改进！**

从作为重要的学习资源，到成为模型开发的关键工具，Jupyter notebook 已成为机器学习众多领域的核心组成部分。notebook 交互式、可视化的特性，让你在发展模型、数据集和演示的过程中能够快速获取反馈。对许多人来说，他们第一次接触机器学习模型训练就是通过 Jupyter notebook，许多从业者也把 notebook 作为开发和交流工作成果的关键工具。

Hugging Face 是一个协作式机器学习平台，社区已共享了超过 15 万个模型、2.5 万个数据集和 3 万个 ML 应用。Hub 提供模型和数据集的版本管理工具，包括 model card 和用于自动化版本管理流程的客户端库。然而，仅有一份记录了超参数的 model card 并不足以实现最佳的可复现性，而这正是 notebook 可以帮忙的地方。除了这些模型、数据集和演示之外，Hub 还托管着 7000 多个 notebook。这些 notebook 通常记录了某个模型或数据集的开发过程，并能提供指导与教程，展示他人如何使用这些资源。因此，我们对 Hub 上 notebook 托管支持的改进感到十分兴奋。

## 我们改了什么？

从底层来看，Jupyter notebook 文件（通常以 `ipynb` 扩展名共享）其实是 JSON 文件。虽然可以直接查看这些文件，但这种格式并非为人类阅读而设计。我们现已为托管在 Hub 上的 notebook 添加了渲染支持，这意味着 notebook 现在将以人类可读的格式显示。

Hub 上托管的 notebook 渲染前后的对比。

## 为什么我们对在 Hub 上托管更多 notebook 感到兴奋？

- Notebook 有助于说明人们如何使用你的模型和数据集；将 notebook 与你的模型、数据集放在同一处分享，能让他人更容易地使用你在 Hub 上创建和共享的资源。
- 许多人用 Hub 来打造自己的机器学习作品集（portfolio）。现在你也可以用 Jupyter Notebook 来丰富这份作品集。
- 支持一键直接在 [Google Colab](https://medium.com/google-colab/hugging-face-notebooks-x-colab-722d91e05e7c) 中打开托管在 Hub 上的 notebook，让 Hub 上的 notebook 体验更强大。敬请期待后续公告！
