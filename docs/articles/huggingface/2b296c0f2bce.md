# 使用 Dell Enterprise Hub 构建本地 AI

Jeff Boudier（jeffboudier）、Philipp Schmid（philschmid）、Balachandran Rajendran（balaatdell，DellTechnologies）、Ian Roche（ianr007，DellTechnologies）

[![DELL World Keynote announcement Hugging Face](https://huggingface.co/blog/assets/dell-enterprise-hub/thumbnail.jpg)](https://huggingface.co/blog/assets/dell-enterprise-hub/thumbnail.jpg)

今天我们宣布 Dell Enterprise Hub，这是 Hugging Face 上一个全新的体验，让你可以用 Dell 平台在本地（on-premise）轻松训练和部署开放模型。

在 [dell.huggingface.co](https://dell.huggingface.co) 试用。

## 企业需要用开放模型构建 AI

在构建 AI 系统时，开放模型是满足企业安全性、合规性和隐私要求的最佳方案：

- 基于开放模型构建，能让公司理解、拥有并掌控自己的 AI 功能，
- 开放模型可以托管在企业安全的 IT 环境内，
- 在本地训练和部署开放模型能保护客户数据。

但在本地基础设施里使用大语言模型（LLM）往往需要数周的反复试错，要应对容器、并行、量化以及各种内存溢出错误。

有了 Dell Enterprise Hub，我们让用 Dell 平台在本地训练和部署 LLM 变得轻松，把数周的工程工作压缩到几分钟。

## Dell Enterprise Hub：本地 LLM 变得简单

Dell Enterprise Hub 提供了一份精心挑选的清单，收录当下最先进的开放模型，包括 [Meta 的 Llama 3](https://huggingface.co/meta-llama/Meta-Llama-3-70B-Instruct)、[Mistral AI 的 Mixtral](https://huggingface.co/mistralai/Mixtral-8x22B-Instruct-v0.1)、[Google 的 Gemma](https://huggingface.co/google/gemma-7b) 等。

要访问 Dell Enterprise Hub，你只需要一个 Hugging Face 账号。

[![catalog](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/dell/catalog.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/dell/catalog.png)

Dell Enterprise Hub 从底层就是为企业设计的，并针对 Dell 平台做了优化。

你可以按许可证或模型大小轻松筛选可用模型。

[![catalog-filter](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/dell/catalog-filter.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/dell/catalog-filter.png)

选定模型后，你可以查看一张为企业使用而设计的详尽模型卡。一眼就能看到关于该模型的关键信息、它的规模，以及哪些 Dell 平台能很好地支持它。

来自 Meta、Mistral 和 Google 的许多模型需要授权才能访问模型权重。由于 Dell Enterprise Hub 建立在 Hugging Face 用户账号之上，你的账号权限会延续到 Dell Enterprise Hub，你只需要获取一次授权。

## 用 Dell Enterprise Hub 部署开放模型

选定一个可部署的模型后，在你的 Dell 环境里部署它非常简单。只需选择一个受支持的 Dell 平台，以及你用于部署的 GPU 数量。

[![deploy](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/dell/deploy.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/dell/deploy.png)

当你把提供的脚本粘贴进你的 Dell 环境终端或服务器，一切就会自动完成，把你的模型变成一个托管在你 Dell 平台上的 API 端点。Hugging Face 为每个 Dell 平台优化了部署配置，考虑了可用的硬件、内存和连接能力，并定期在 Dell 基础设施上测试，以便开箱就提供最佳结果。

## 用 Dell Enterprise Hub 训练开放模型

微调模型通过基于公司专属训练数据更新模型权重，来提升模型在特定领域和用例上的表现。已有证据表明，微调后的开放模型能胜过像 GPT-4 这样最好的可用闭源模型，为驱动特定 AI 功能提供更高效、更高性能的模型。由于公司专属训练数据往往包含机密信息、知识产权和客户数据，对企业合规而言，在本地做微调非常重要，这样数据永远不会离开公司安全的 IT 环境。

用 Dell Enterprise Hub 在本地微调开放模型和部署模型一样简单。主要额外的参数是向优化过的训练容器提供训练数据集所在的 Dell 环境本地路径，以及完成后把微调后的模型上传到哪里。训练数据集可以是 CSV 或 JSONL 格式的文件，遵循[这份规范](https://dell.huggingface.co/faq#how-should-my-dataset-look)。

[![train](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/dell/train.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/dell/train.png)

## 用 Dell Enterprise Hub 自带你的模型（BYOM）

如果你想在不离开安全环境的前提下在本地部署自己的模型呢？

有了 Dell Enterprise Hub，一旦你训练好一个模型，它就会托管在你本地安全环境中你所选的路径上。部署它只是再选一下"Deploy Fine-Tuned"标签这么简单的一步。

而如果你是用 Dell Enterprise Hub 支持的某种模型架构自己训练了模型，你可以用完全相同的方式部署它。

只需在你即将运行所提供代码片段的环境里，把本地路径设置为你存放模型权重的位置。

[![deploy-fine-tuned](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/dell/deploy-fine-tuned.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/dell/deploy-fine-tuned.png)

部署之后，模型作为一个 API 端点对外提供，按照兼容 OpenAI 的 [Messages API](https://huggingface.co/docs/text-generation-inference/en/messages_api) 发送请求即可轻松调用。这让把一个用 OpenAI 搭建的原型迁移到一个用 Dell Enterprise Hub 搭建的安全本地部署变得极其容易。
