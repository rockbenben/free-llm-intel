# 用 InstructPix2Pix 对 Stable Diffusion 进行指令微调

Sayak Paul (sayakpaul)

本文探索用指令微调（instruction-tuning）教会 [Stable Diffusion](https://huggingface.co/blog/stable_diffusion) 按指令来转换或处理输入图像。用这个方法，我们可以拿一张输入图像加一条"指令"来提示 Stable Diffusion，比如——*对这张自然图像应用卡通滤镜*。

| [![schematic](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/instruction-tuning-sd/schematic.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/instruction-tuning-sd/schematic.png) |
| --- |
| **图 1**：我们探索 Stable Diffusion 的指令微调能力。图中我们用不同的变换指令和输入图像提示一个指令微调过的 Stable Diffusion 系统。微调后的系统似乎能学会输入提示词中描述的这些变换。彩色放大查看效果最佳。 |

"教 Stable Diffusion 遵循用户指令对输入图像执行**编辑**"这一思想出自 [InstructPix2Pix: Learning to Follow Image Editing Instructions](https://huggingface.co/papers/2211.09800)。我们讨论如何扩展 InstructPix2Pix 的训练策略，让它遵循更具体的指令，服务于图像转换（如卡通化）和低层图像处理（如图像去雨）这类任务。内容包括：

- [指令微调简介](https://huggingface.co/blog/instruction-tuning-sd#introduction-and-motivation)
- [这项工作背后的动机](https://huggingface.co/blog/instruction-tuning-sd#introduction-and-motivation)
- [数据集准备](https://huggingface.co/blog/instruction-tuning-sd#dataset-preparation)
- [训练实验与结果](https://huggingface.co/blog/instruction-tuning-sd#training-experiments-and-results)
- [潜在应用与局限](https://huggingface.co/blog/instruction-tuning-sd#potential-applications-and-limitations)
- [开放问题](https://huggingface.co/blog/instruction-tuning-sd#open-questions)

我们的代码、预训练模型和数据集在[这里](https://github.com/huggingface/instruction-tuned-sd)。

## 引言与动机

指令微调是一种以监督方式教会语言模型遵循指令完成任务的方法，由 Google 在 [Fine-tuned Language Models Are Zero-Shot Learners](https://huggingface.co/papers/2109.01652)（FLAN）中提出。近期的 [Alpaca](https://crfm.stanford.edu/2023-03-13/alpaca.html) 和 [FLAN V2](https://huggingface.co/papers/2210.11416) 等工作都说明了指令微调对各类任务有多有益。

下图展示了指令微调（也叫"指令微调/instruction-finetuning"）的形式化。在 [FLAN V2 论文](https://huggingface.co/papers/2210.11416)中，作者拿一个预训练语言模型（例如 [T5](https://huggingface.co/docs/transformers/model_doc/t5)），在示例数据集上微调，如下图所示。

| [![flan_schematic](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/instruction-tuning-sd/flan_schematic.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/instruction-tuning-sd/flan_schematic.png) |
| --- |
| **图 2**：FLAN V2 示意图（取自 FLAN V2 论文）。 |

用这套方法，可以为大量不同任务构造示例，使指令微调成为多任务训练目标：

| **输入** | **标签** | **任务** |
| --- | --- | --- |
| Predict the sentiment of the following sentence: "The movie was pretty amazing. I could not turn around my eyes even for a second."（预测下面这句话的情感） | Positive | 情感分析 / 序列分类 |
| Please answer the following question. What is the boiling point of Nitrogen?（请回答：氮的沸点是多少？） | 320.4F | 问答 |
| Translate the following English sentence into German: "I have a cat."（把这句英文翻译成德语） | Ich habe eine Katze. | 机器翻译 |
| … | … | … |
|  |  |  |

秉持类似理念，FLAN V2 作者在一个由数千任务组成的混合集上做指令微调，实现了对未见任务的零样本泛化：

| [![flan_dataset_overview](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/instruction-tuning-sd/flan_dataset_overview.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/instruction-tuning-sd/flan_dataset_overview.png) |
| --- |
| **图 3**：FLAN V2 训练与测试任务混合（取自 FLAN V2 论文）。 |

我们这项工作的动机一部分来自 FLAN 系列工作，一部分来自 InstructPix2Pix。我们想探索：能否用具体指令加输入图像来提示 Stable Diffusion，按需处理图像。

[预训练的 InstructPix2Pix 模型](https://huggingface.co/timbrooks/instruct-pix2pix)擅长遵循一般性指令，但面对涉及特定变换的指令可能就力不从心：

| [![cartoonization_results](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/instruction-tuning-sd/cartoonization_results.jpeg)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/instruction-tuning-sd/cartoonization_results.jpeg) |
| --- |
| **图 4**：我们观察到，对输入图像（左列），我们的模型（右列）比预训练 InstructPix2Pix 模型（中列）更忠实完成"卡通化"。第一行很有意思——预训练 InstructPix2Pix 几乎完全失败。彩色放大查看最佳。原图见[这里](https://huggingface.co/datasets/sayakpaul/sample-datasets/resolve/main/Instruction-tuning-sd/cartoonization_results.png)。 |

但 InstructPix2Pix 的发现仍然可以被我们利用来服务定制需求。

另一方面，[卡通化](https://github.com/SystemErrorWang/White-box-Cartoonization)、[图像去噪](https://paperswithcode.com/dataset/sidd)、[图像去雨](https://paperswithcode.com/dataset/raindrop)等任务的成对数据集都是公开可用的，我们可以借鉴 FLAN V2 把它们构造成带指令提示的数据集。这样一来，FLAN V2 探索的指令模板化思路就能迁移到本工作中。

## 数据集准备

### 卡通化

早期实验里，我们直接提示 InstructPix2Pix 做卡通化，结果不符合预期。我们试了各种推理时超参数组合（如 image guidance scale、推理步数），结果依然不给力。这促使我们换一种思路。

如前文所暗示，我们想同时受益于两个世界：

**(1)** InstructPix2Pix 的训练方法，和 **(2)** FLAN 创建指令提示数据集模板的灵活性。

我们先为卡通化任务构造指令提示数据集。图 5 展示了我们的数据创建流程：

| [![itsd_data_wheel](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/instruction-tuning-sd/itsd_data_wheel.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/instruction-tuning-sd/itsd_data_wheel.png) |
| --- |
| **图 5**：我们卡通化数据创建流程示意（彩色放大查看最佳）。 |

具体来说，我们：

- 请 [ChatGPT](https://openai.com/blog/chatgpt) 为指令 "Cartoonize the image." 生成 50 个同义句。
- 然后取 [Imagenette 数据集](https://github.com/fastai/imagenette)的随机子集（5000 个样本），用预训练的 [Whitebox CartoonGAN](https://github.com/SystemErrorWang/White-box-Cartoonization) 模型生成这些图像的卡通化版本。卡通化版本就是我们的模型要学习的标签。某种程度上，这相当于把 Whitebox CartoonGAN 学到的偏好迁移到我们的模型。
- 然后按以下格式创建示例：

| [![cartoonization_dataset_overview](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/instruction-tuning-sd/cartoonization_dataset_overview.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/instruction-tuning-sd/cartoonization_dataset_overview.png) |
| --- |
| **图 6**：最终卡通化数据集样例（彩色放大查看最佳）。 |

最终的卡通化数据集在[这里](https://huggingface.co/datasets/instruction-tuning-vision/cartoonizer-dataset)。数据准备细节见[这个目录](https://github.com/huggingface/instruction-tuned-sd/tree/main/data_preparation)。我们用这个数据集微调 InstructPix2Pix 做了实验，结果不错（详见"训练实验与结果"一节）。

接着我们继续看能否把该方法推广到低层图像处理任务：图像去雨、去噪、去模糊。

### 低层图像处理

我们聚焦 [MAXIM](https://huggingface.co/papers/2201.02973) 探索过的常见低层图像处理任务，具体实验包括：去雨、去噪、低光增强、去模糊。

我们从下列数据集中各取不同数量的样本，构造一个加了提示词的单一数据集：

| **任务** | **提示词** | **数据集** | **样本数** |
| --- | --- | --- | --- |
| 去模糊 | "deblur the blurry image" | [REDS](https://seungjunnah.github.io/Datasets/reds.html)（`train_blur` 和 `train_sharp`） | 1200 |
| 去雨 | "derain the image" | [Rain13k](https://github.com/megvii-model/HINet#image-restoration-tasks) | 686 |
| 去噪 | "denoise the noisy image" | [SIDD](https://www.eecs.yorku.ca/~kamel/sidd/) | 8 |
| 低光增强 | "enhance the low-light image" | [LOL](https://paperswithcode.com/dataset/lol) | 23 |
|  |  |  |  |

上述数据集通常以输入-输出对形式提供，所以不用担心真值问题。最终数据集在[这里](https://huggingface.co/datasets/instruction-tuning-vision/instruct-tuned-image-processing)。成品长这样：

| [![low_level_img_proc_dataset_overview](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/instruction-tuning-sd/low_level_img_proc_dataset_overview.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/instruction-tuning-sd/low_level_img_proc_dataset_overview.png) |
| --- |
| **图 7**：最终低层图像处理数据集样例（彩色放大查看最佳）。 |

总体上，这套设置与 FLAN 的思路一脉相承——创建不同任务的混合。这也让我们只训一个模型、训练一次，就能在混合中的所有任务上表现不错。这与低层图像处理领域的常规做法差别很大：MAXIM 这样的工作提出能建模多种低层任务的单一模型架构，但训练仍然在各个数据集上独立进行。

## 训练实验与结果

我们的训练实验基于[这个脚本](https://github.com/huggingface/diffusers/blob/main/examples/instruct_pix2pix/train_instruct_pix2pix.py)。训练日志（含验证样本和超参数）都发布在 Weight and Biases 上：

- [卡通化](https://wandb.ai/sayakpaul/instruction-tuning-sd/runs/wszjpb1b)（[超参数](https://wandb.ai/sayakpaul/instruction-tuning-sd/runs/wszjpb1b/overview?workspace=)）
- [低层图像处理](https://wandb.ai/sayakpaul/instruction-tuning-sd/runs/2kg5wohb)（[超参数](https://wandb.ai/sayakpaul/instruction-tuning-sd/runs/2kg5wohb/overview?workspace=)）

训练时我们探索了两个选项：

- 从现有 [InstructPix2Pix 检查点](https://huggingface.co/timbrooks/instruct-pix2pix)微调
- 从现有 [Stable Diffusion 检查点](https://huggingface.co/runwayml/stable-diffusion-v1-5)出发，用 InstructPix2Pix 训练方法微调

实验发现，第一个选项能让我们更快适应自己的数据集（以生成质量衡量）。

训练与超参数细节请查阅[我们的代码](https://github.com/huggingface/instruction-tuned-sd)和相应的 Weights and Biases 运行页。

## 潜在应用与局限

在图像编辑世界里，领域专家心中的想法（要做什么任务）与编辑工具里实际要执行的操作（如 [Lightroom](https://www.adobe.com/in/products/photoshop-lightroom.html)）之间存在断层。如果有简单办法把自然语言目标翻译成低层图像编辑原语，用户体验会非常顺滑。有了 InstructPix2Pix 这类机制，可以说我们正在靠近那个境界。

但挑战依然存在的：

- 这些系统需要能处理大尺寸高分辨率原图。
- 扩散模型经常在图像空间里凭空发挥或曲解指令。对现实的图像编辑应用来说，这不可接受。

## 开放问题

我们承认实验只是初步的，没有对实验中各因素做深入消融。因此这里列出实验过程中冒出的几个开放问题：

- ***数据集扩大规模会怎样？*** 对生成样本质量的影响如何？我们只用了少量样本做实验；作为对比，InstructPix2Pix 训练用了超过 30000 个样本。
- ***训练更久有什么影响？尤其是任务混合更宽时。*** 我们的实验没做超参数调优，更别提训练步数的消融了。
- ***这个方法对"指令微调"世界常见的更宽任务混合泛化如何？*** 低层图像处理我们只覆盖四个任务：去雨、去模糊、去噪、低光增强。往混合中添加更多任务、配更有代表性的样本，能否帮助模型泛化到未见任务，或任务的组合（例如"先给图像去模糊再去噪"）？
- ***在线使用同一指令的不同变体能否提升性能？*** 卡通化任务中，我们在数据集构建**期间**从 ChatGPT 生成的同义指令集中随机抽样。但如果把随机抽样放到训练期间做会怎样？低层图像处理用的是固定指令，如果对每个任务和输入图像也套用同义指令的方法会怎样？
- ***改用 ControlNet 训练方案会怎样？*** [ControlNet](https://huggingface.co/papers/2302.05543) 同样允许让预训练文生图扩散模型以额外图像为条件（如语义分割图、canny 边缘图等）。感兴趣的话，可以用本文介绍的数据集，参考[这篇帖子](https://huggingface.co/blog/train-your-controlnet)做 ControlNet 训练。

## 结论

本文展示了我们对 Stable Diffusion "指令微调"的探索。预训练的 InstructPix2Pix 擅长遵循一般图像编辑指令，但遇到更具体的指令就可能崩溃。为缓解这一问题，我们介绍了如何准备数据集以进一步微调 InstructPix2Pix 并给出结果。如前所述，结果还是初步的，但我们希望这项工作能为研究类似问题的研究者提供基础，并激励他们继续探索这些开放问题。
