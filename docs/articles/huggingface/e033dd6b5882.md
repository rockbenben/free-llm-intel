# 从云到开发者：Hugging Face 与 Microsoft 深化合作

今天在 Microsoft Build 大会上，我们很高兴宣布一系列新功能与合作：Microsoft 与 Hugging Face 深化战略合作，让开放模型和开源 AI 在任何地方都更易于使用。我们将一起在开放科学、开源、云、硬件和开发者体验各个层面赋能 AI 构建者——各条线的当日公告请看下文！

[![MS BUILD Keynote announcement Hugging Face](https://huggingface.co/blog/assets/microsoft-collaboration/thumbnail.jpg)](https://huggingface.co/blog/assets/microsoft-collaboration/thumbnail.jpg)

## 面向云端 AI 构建者的合作

我们很高兴宣布在 Microsoft Azure 上用开放模型构建 AI 的两大新体验。

### Azure Model Catalog 中扩充的 HF 合集

一年前，Hugging Face 和 Microsoft [在 Azure Model Catalog 中推出了 Hugging Face Collection](https://huggingface.co/blog/hugging-face-endpoints-on-azure)。该合集已被数百个 Azure AI 客户使用，自上线以来提供了上千个开放模型。今天，我们把一些最受欢迎的开放大语言模型加入该合集，支持从 Azure AI Studio 一键直接部署。

新增模型包括 [Meta 的 Llama 3](https://huggingface.co/meta-llama/Meta-Llama-3-70B-Instruct)、[Mistral AI 的 Mistral 7B](https://huggingface.co/mistralai/Mistral-7B-Instruct-v0.2)、[Cohere for AI 的 Command R Plus](https://huggingface.co/CohereForAI/c4ai-command-r-plus)、[Qwen 的 Qwen 1.5 110B](https://huggingface.co/Qwen/Qwen1.5-110B-Chat)，以及来自 Hugging Face 社区、在 [Open LLM Leaderboard](https://huggingface.co/spaces/HuggingFaceH4/open_llm_leaderboard) 上表现最好的部分微调模型。

要在你自己的 Azure 账号中部署这些模型，可以从 Hugging Face Hub 上的模型卡出发，选择 "Deploy on Azure" 选项：

[![model-hub-azure](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/microsoft-collaboration/model-hub-azure.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/microsoft-collaboration/model-hub-azure.png)

也可以直接在 [Azure AI Studio](https://ai.azure.com) 的 Hugging Face Collection 中找到模型，点击 "Deploy"：

[![ai-studio-deploy](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/microsoft-collaboration/ai-studio-deploy.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/microsoft-collaboration/ai-studio-deploy.png)

### 用 Azure 上新出的 AMD MI300X 构建 AI

今天，Microsoft 宣布基于最新 AMD Instinct MI300 GPU 的 [Azure ND MI300X 虚拟机](https://techcommunity.microsoft.com/t5/azure-high-performance-computing/azure-announces-new-ai-optimized-vm-series-featuring-amd-s/ba-p/3980770)（VM）在 Azure 上正式可用。Hugging Face 与 AMD 和 Microsoft 协作，让 Hugging Face 模型在新虚拟机上取得了出色性能以及极佳的性价比。

这项工作借助我们与 [AMD 的深度合作](https://huggingface.co/blog/huggingface-and-optimum-amd)和我们的开源库 [Optimum-AMD](https://github.com/huggingface/optimum-amd)，在 AMD Instinct GPU 上对 Hugging Face 开源库与模型进行优化、ROCm 集成和持续测试。

## 面向开放科学的合作

Microsoft 一直把一些最受欢迎的开放模型发布到 Hugging Face 上，[Hugging Face Hub 上的 Microsoft 组织](https://huggingface.co/microsoft)目前有近 300 个模型。

其中包括最近的 [Phi-3 模型家族](https://huggingface.co/collections/microsoft/phi-3-6626e15e9585a200d2d761e3)，采用宽松的 MIT 许可证，性能远超其体量。例如，Phi-3 mini 仅 38 亿参数就超越了众多 70-100 亿参数的大语言模型，使其成为端侧应用的优秀候选。

为展示 Phi-3 的能力，Hugging Face 已[把 Phi-3 mini 部署进 Hugging Chat](https://huggingface.co/chat/models/microsoft/Phi-3-mini-4k-instruct)——其免费的消费级应用，可与最优秀的开放模型对话并创建助手。

## 面向开源的合作

Hugging Face 与 Microsoft 已合作 3 年，通过 [optimum 开源库](https://github.com/huggingface/optimum)让[导出 Hugging Face 模型并在 ONNX Runtime 中使用](https://huggingface.co/docs/optimum/onnxruntime/overview)变得简单。

最近，Hugging Face 和 Microsoft 专注通过 WebGPU 实现本地推理，利用了 [Transformers.js](https://github.com/xenova/transformers.js) 和 [ONNX Runtime Web](https://onnxruntime.ai/docs/get-started/with-javascript/web.html)。更多关于该合作的内容见 ONNX Runtime 团队的这篇[社区文章](https://huggingface.co/blog/Emma-N/enjoy-the-power-of-phi-3-with-onnx-runtime)。

要感受 WebGPU 的威力，看看这个 [Phi-3 演示](https://x.com/xenovacom/status/1792661746269692412)——在浏览器本地以每秒超过 70 个 token 的速度生成！

## 面向开发者的合作

最后，今天我们发布一个新集成，让开发者用 Hugging Face Spaces 和 VS Code 构建 AI 应用比以往任何时候都简单！

Hugging Face 社区已用 Spaces 在 Hub 上创建了 50 万多个 AI 演示应用。借助新的 Spaces Dev Mode，Hugging Face 用户可以把他们的 Space 轻松连接到本地 VS Code，或拉起一个 Web 托管的 VS Code 环境。

[![dev-mode](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/microsoft-collaboration/dev-mode.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/microsoft-collaboration/dev-mode.png)

Spaces Dev Mode 目前处于 beta，向 [PRO 订阅用户](https://huggingface.co/pricing#pro)开放。要了解更多信息，请看 [Spaces Dev mode 介绍：无缝的开发者体验](https://huggingface.co/blog/spaces-dev-mode)或[文档](https://huggingface.co/dev-mode-explorers)。
