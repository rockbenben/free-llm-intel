# 使用 Hugging Face Dataset Viewer API 与 MotherDuck DuckDB-NSQL-7B 实现 Text2SQL

如今，在各类任务中集成 AI 能力——尤其是利用大语言模型（LLM）——已经越来越普遍，例如文本生成、分类、图生文、图生图等。

开发者们越来越意识到这些应用的潜在价值，它们能增强核心工作，比如撰写脚本、Web 开发，以及现在的数据交互。过去，为数据分析写出有见地的 SQL 查询主要是数据分析师、SQL 开发、数据工程师或相关领域专业人士的工作，他们要驾驭 SQL 方言语法的种种细节。但随着 AI 方案的出现，局面正在改变。这些先进模型提供了与数据交互的新途径，有望以更高效、更深入的方式简化流程、发现洞察。

如果不用深入写代码，就能从数据集里挖出有趣的洞察，会怎样？要获得有价值的信息，你得写出专门的 `SELECT` 语句，考虑要展示哪些列、来源表是哪张、所选行的过滤条件、聚合方式以及排序偏好。这种传统方式涉及一连串命令：`SELECT`、`FROM`、`WHERE`、`GROUP`、`ORDER`。

但如果你不是资深开发者，又想发挥数据的价值呢？这时你就不得不求助 SQL 专家——这正暴露了可用性与可及性上的缺口。

AI 与 LLM 技术的突破性进展正好填补了这个鸿沟。想象一下，你可以毫不费力地与数据对话：只需用自然语言说出你的信息需求，模型就把你的请求翻译成查询。

最近几个月，这一领域进展迅猛。[MotherDuck](https://motherduck.com/) 和 [Numbers Station](https://numbersstation.ai/) 发布了它们的最新成果：[DuckDB-NSQL-7B](https://huggingface.co/motherduckdb/DuckDB-NSQL-7B-v0.1)，一个专为 [DuckDB SQL](https://duckdb.org/) 设计的最先进 LLM。这个模型的使命是什么？让用户能毫不费力地从数据中挖掘洞察。

DuckDB-NSQL-7B 最初基于 Meta 的 [Llama-2–7b](https://huggingface.co/meta-llama/Llama-2-7b) 模型，用覆盖通用 SQL 查询的广泛数据集微调而来，之后又用 DuckDB text-to-SQL 数据对做了进一步打磨。值得注意的是，它的能力不止于写出 `SELECT` 语句：它能生成大量有效的 DuckDB SQL 语句，涵盖官方文档和扩展，是数据探索与分析的多面手。

本文将学习如何用 DuckDB-NSQL-7B 模型处理 text2sql 任务，用 Hugging Face dataset viewer API 获取 parquet 文件，并用 duckdb 完成数据检索。

![text2sql 流程](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/duckdb-nsql-7b/text2sql-flow.png)
 *text2sql 流程*

### 如何使用模型

- 使用 Hugging Face `transformers` pipeline

```
from transformers import pipeline

pipe = pipeline("text-generation", model="motherduckdb/DuckDB-NSQL-7B-v0.1")
```

- 使用 transformers 的 tokenizer 和 model

```
from transformers import AutoTokenizer, AutoModelForCausalLM

tokenizer = AutoTokenizer.from_pretrained("motherduckdb/DuckDB-NSQL-7B-v0.1")
model = AutoModelForCausalLM.from_pretrained("motherduckdb/DuckDB-NSQL-7B-v0.1")
```

- 用 `llama.cpp` 加载 `GGUF` 格式模型

```
from llama_cpp import Llama

llama = Llama(
       model_path="DuckDB-NSQL-7B-v0.1-q8_0.gguf", # Path to local model
       n_gpu_layers=-1,
)
```

`llama.cpp` 的主要目标是以最少的配置实现 LLM 推理，并在多种硬件上（本地和云端）达到最先进性能。我们将采用这种方式。

### 覆盖 12 万+ 数据集的 Hugging Face Dataset Viewer API

数据是任何机器学习工作的关键组成部分。Hugging Face 是宝贵的资源，提供超过 12 万个免费开放数据集，涵盖 CSV、Parquet、JSON、音频、图像等多种格式。

Hugging Face 上托管的每个数据集都配有完整的数据集查看器（dataset viewer）。查看器提供统计概览、数据规模评估、全文搜索和高效过滤等核心功能，帮助用户轻松探索与评估数据集，在机器学习工作流中做出明智决策。

本演示将使用 [world-cities-geo](https://huggingface.co/datasets/jamescalam/world-cities-geo) 数据集。

![数据集查看器](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/duckdb-nsql-7b/dataset-viewer.png)
 *world-cities-geo 数据集的查看器*

在背后，Hub 上每个数据集都由 [Hugging Face dataset viewer API](https://huggingface.co/docs/datasets-server/index) 处理，它提供信息并支持以下功能：

- 列出数据集的**切分、列名和数据类型**
- 获取数据集**规模**（行数或字节数）
- 下载并查看数据集中**任意索引处的行**
- 在数据集中**搜索**某个词
- 基于查询字符串对行进行**过滤**
- 获取关于数据的**统计洞察**
- 将数据集作为 **parquet 文件**访问，以便在你的首选处理或分析框架中使用

在本演示中，我们使用的就是最后这项功能：自动转换的 parquet 文件。

### 从文本指令生成 SQL 查询

首先，[下载](https://huggingface.co/motherduckdb/DuckDB-NSQL-7B-v0.1-GGUF/blob/main/DuckDB-NSQL-7B-v0.1-q8_0.gguf) DuckDB-NSQL-7B-v0.1 的量化模型版本。

![下载模型](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/duckdb-nsql-7b/download.png)
 *下载模型*

或者，你可以执行以下代码：

```
huggingface-cli download motherduckdb/DuckDB-NSQL-7B-v0.1-GGUF DuckDB-NSQL-7B-v0.1-q8_0.gguf --local-dir . --local-dir-use-symlinks False
```

接下来安装所需依赖：

```
pip install llama-cpp-python
pip install duckdb
```

对于 text-to-SQL 模型，我们使用的提示词结构如下：

```
   ### Instruction:
   Your task is to generate valid duckdb SQL to answer the following question.
   ### Input:
   Here is the database schema that the SQL query will run on:
   {ddl_create}
  
   ### Question:
   {query_input}
   ### Response (use duckdb shorthand if possible):
```

- **ddl_create** 是把数据集 schema 表示为 SQL `CREATE` 命令的内容
- **query_input** 是用自然语言表述的用户指令

因此我们需要把 Hugging Face 数据集的 schema 告知模型。为此，先从 [jamescalam/world-cities-geo](https://huggingface.co/datasets/jamescalam/world-cities-geo) 数据集中获取第一个 parquet 文件：

```
GET https://huggingface.co/api/datasets/jamescalam/world-cities-geo/parquet
```

```
{
   "default":{
      "train":[
         "https://huggingface.co/api/datasets/jamescalam/world-cities-geo/parquet/default/train/0.parquet"
      ]
   }
}
```

该 [parquet 文件](https://huggingface.co/api/datasets/jamescalam/world-cities-geo/parquet/default/train/0.parquet)托管在 Hugging Face viewer 的 `refs/convert/parquet` 修订版本下：

![parquet 文件](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/duckdb-nsql-7b/parquet.png)
 *Parquet 文件*

- 模拟从 parquet 文件第一行创建 [DuckDB](https://duckdb.org/) 表

```
import duckdb
con = duckdb.connect()
con.execute(f"CREATE TABLE data as SELECT * FROM '{first_parquet_url}' LIMIT 1;")

result = con.sql("SELECT sql FROM duckdb_tables() where table_name ='data';").df()
ddl_create = result.iloc[0,0]
con.close()
```

得到的 `CREATE` schema DDL 是：

```
CREATE TABLE "data"(
    city VARCHAR, 
    country VARCHAR, 
    region VARCHAR,
    continent VARCHAR, 
    latitude DOUBLE, 
    longitude DOUBLE, 
    x DOUBLE, 
    y DOUBLE, 
    z DOUBLE
);
```

如你所见，它与数据集查看器中的列完全对应：

![数据集列](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/duckdb-nsql-7b/columns.png)
 *数据集的列*

- 现在，我们可以用 **ddl_create** 和 **query** 输入构造提示词

```
prompt = """### Instruction:
   Your task is to generate valid duckdb SQL to answer the following question.
   ### Input:
   Here is the database schema that the SQL query will run on:
   {ddl_create}
  
   ### Question:
   {query_input}
   ### Response (use duckdb shorthand if possible):
   """
```

如果用户想知道**阿尔巴尼亚的城市**，提示词将长这样：

```
query = "Cities from Albania country"
prompt = prompt.format(ddl_create=ddl_create, query_input=query)
```

发送给 LLM 的展开后提示词如下：

```
### Instruction:
Your task is to generate valid duckdb SQL to answer the following question.

### Input:
Here is the database schema that the SQL query will run on:
CREATE TABLE "data"(city VARCHAR, country VARCHAR, region VARCHAR, continent VARCHAR, latitude DOUBLE, longitude DOUBLE, x DOUBLE, y DOUBLE, z DOUBLE);
  
### Question:
Cities from Albania country

### Response (use duckdb shorthand if possible):
```

- 是时候把提示词送进模型了

```
from llama_cpp import Llama

llm = Llama(
       model_path="DuckDB-NSQL-7B-v0.1-q8_0.gguf",
       n_ctx=2048,
       n_gpu_layers=50
   )
pred = llm(prompt, temperature=0.1, max_tokens=1000)
sql_output = pred["choices"][0]["text"]
```

输出的 SQL 命令会指向一张 `data` 表，但我们并没有真实的表，只是引用了 parquet 文件，所以要把所有 `data` 出现的位置替换成 `first_parquet_url`：

```
sql_output = sql_output.replace("FROM data", f"FROM '{first_parquet_url}'")
```

最终输出是：

```
SELECT city FROM 'https://huggingface.co/api/datasets/jamescalam/world-cities-geo/parquet/default/train/0.parquet' WHERE country = 'Albania'
```

- 最后，就是在数据集上直接执行生成的 SQL，再次借助 DuckDB 的能力：

```
con = duckdb.connect()
try:
   query_result = con.sql(sql_output).df()
except Exception as error:
   print(f"❌ Could not execute SQL query {error=}")
finally:
   con.close()
```

直接调用搜索或过滤 API 也能得到同样的结果：

- 使用 [/search](https://huggingface.co/docs/datasets-server/search?code=python#search-text-in-a-dataset) API

```
import requests
API_URL = "https://datasets-server.huggingface.co/search?dataset=jamescalam/world-cities-geo&config=default&split=train&query=Albania"
def query():
    response = requests.get(API_URL)
    return response.json()
data = query()
```

- 使用 [filter](https://huggingface.co/docs/datasets-server/filter) API

```
import requests
API_URL = "https://datasets-server.huggingface.co/filter?dataset=jamescalam/world-cities-geo&config=default&split=train&where=country='Albania'"
def query():
    response = requests.get(API_URL)
    return response.json()
data = query()
```
