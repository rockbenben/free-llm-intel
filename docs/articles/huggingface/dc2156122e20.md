## 引言

[![image/png](https://cdn-uploads.huggingface.co/production/uploads/67c205dafa508474d715f1d6/3-bCN66Qu3qZ3lQJU5Ykh.png)](https://cdn-uploads.huggingface.co/production/uploads/67c205dafa508474d715f1d6/3-bCN66Qu3qZ3lQJU5Ykh.png)

[NVIDIA Isaac GR00T](https://developer.nvidia.com/isaac/gr00t)（Generalist Robot 00 Technology）是一个用于构建机器人基础模型和数据流水线的研发平台，目标是加速智能、可适应机器人的诞生。

今天我们宣布 [Isaac GR00T N1.5](https://huggingface.co/nvidia/GR00T-N1.5-3B) 可用——这是 Isaac GR00T N1 的首次重大更新。Isaac GR00T N1 是全球首个面向通用人形机器人推理与技能训练的开源基础模型。这个跨本体（cross-embodiment）模型处理包括语言和图像在内的多模态输入，在多样化环境中执行操作任务，并可通过后训练适配到特定本体、任务和环境。

在本文中，我们将演示如何用单台 SO-101 机械臂的遥操作数据对 GR00T N1.5 进行后训练（微调）。

[![image/gif](https://cdn-uploads.huggingface.co/production/uploads/67b8da81d01134f89899b4a7/rbIZbAfvia_oWaztGlRbu.gif)](https://cdn-uploads.huggingface.co/production/uploads/67b8da81d01134f89899b4a7/rbIZbAfvia_oWaztGlRbu.gif)

*GR00T N1.5 技术博客：[https://research.nvidia.com/labs/gear/gr00t-n1_5/](https://research.nvidia.com/labs/gear/gr00t-n1_5/)*

## 分步教程

GR00T N1.5 现在适用于使用各种机器人形态的开发者，并且可以用便宜、开源的 LeRobot SO-101 机械臂轻松微调和适配。

这份灵活性来自 [`EmbodimentTag`](https://github.com/NVIDIA/Isaac-GR00T/blob/main/getting_started/4_deeper_understanding.md#embodiment-action-head-fine-tuning) 系统：它可以针对不同的机器人平台无缝定制模型，让爱好者、研究者和工程师都能把先进的人形推理与操作能力调校到自家硬件上。

### 步骤 0：安装

进入安装环节前，请确认你满足[前置条件](https://github.com/NVIDIA/Isaac-GR00T?tab=readme-ov-file#prerequisites)。

#### 0.1 克隆 [Isaac-GR00T 仓库](https://github.com/NVIDIA/Isaac-GR00T/tree/main)

```
git clone https://github.com/NVIDIA/Isaac-GR00T
cd Isaac-GR00T
```

#### 0.2 创建环境

```
conda create -n gr00t python=3.10
conda activate gr00t
pip install --upgrade setuptools
pip install -e .[base]
pip install --no-build-isolation flash-attn==2.7.1.post4 
```

### 步骤 1：数据准备

用户可以用任何 LeRobot 数据集微调 GR00T N1.5。本教程以[桌面清理任务](https://huggingface.co/spaces/lerobot/visualize_dataset?dataset=youliangtan%2Fso100-table-cleanup)为例。

需要注意的是，SO-100 或 SO-101 的数据集并不在 GR00T N1.5 的最初预训练范围内，因此我们要把它作为 `new_embodiment` 来训练。

[![image/png](https://cdn-uploads.huggingface.co/production/uploads/67c205dafa508474d715f1d6/fu3Xd1XX4fP2TYJ6hv38Z.png)](https://cdn-uploads.huggingface.co/production/uploads/67c205dafa508474d715f1d6/fu3Xd1XX4fP2TYJ6hv38Z.png)

#### 1.1 创建或下载数据集

本教程你可以按这些[说明](https://huggingface.co/docs/lerobot/getting_started_real_world_robot#record-a-dataset)自己录制数据集（推荐），也可以从 Hugging Face 下载 [so101-table-cleanup](https://huggingface.co/datasets/youliangtan/so101-table-cleanup) 数据集。`--local-dir` 参数指定数据集在你机器上的保存位置。

```
huggingface-cli download \
    --repo-type dataset youliangtan/so101-table-cleanup \
    --local-dir ./demo_data/so101-table-cleanup
```

#### 1.2 配置 Modality 文件

`modality.json` 文件提供状态和动作模态的额外信息，让数据集"GR00T 兼容"。用下面这条命令把 `getting_started/examples/so100_dualcam__modality.json` 复制到数据集的 `<DATASET_PATH>/meta/modality.json`：

```
cp getting_started/examples/so100_dualcam__modality.json ./demo_data/so101-table-cleanup/meta/modality.json
```

注意：对于 [so100_strawberry_grape](https://huggingface.co/datasets/youliangtan/so100_strawberry_grape/tree/main) 这类单摄像头配置，请运行：

```
cp getting_started/examples/so100__modality.json ./demo_data/<DATASET_PATH>/meta/modality.json
```

完成这些步骤后，就可以用 GR00T 的 `LeRobotSingleDataset` 类加载数据集。加载示例脚本如下：

```
python scripts/load_dataset.py --dataset-path ./demo_data/so101-table-cleanup --plot-state-action --video-backend torchvision_av
```

## 步骤 2：微调模型

微调 GR00T N1.5 使用 Python 脚本 `scripts/gr00t_finetune.py`。在终端执行以下命令开始微调：

```
python scripts/gr00t_finetune.py \
   --dataset-path ./demo_data/so101-table-cleanup/ \
   --num-gpus 1 \
   --output-dir ./so101-checkpoints  \
   --max-steps 10000 \
   --data-config so100_dualcam \
   --video-backend torchvision_av
```

小贴士：默认微调设置需要约 25G VRAM。如果你的 VRAM 没这么多，试试给 `gr00t_finetune.py` 加上 `--no-tune_diffusion_model` 参数。

## 步骤 3：开环评估

训练完成、生成微调后的策略之后，可以运行以下命令在开环设置下可视化它的表现：

```
python scripts/eval_policy.py --plot \
   --embodiment_tag new_embodiment \
   --model_path ./so101-checkpoints \
   --data_config so100_dualcam \
   --dataset_path ./demo_data/so101-table-cleanup/ \
   --video_backend torchvision_av \
   --modality_keys single_arm gripper
```

恭喜！你已经成功把 GR00T-N1.5 微调到了一个新的本体上。

## 步骤 4：部署

成功微调并评估策略后，最后一步是把它部署到真实机器人上，在现实世界运行。

要连接你的 **SO-101** 机器人并开始评估，在终端执行以下命令：

- 先把策略作为服务器运行：

```
python scripts/inference_service.py --server \
    --model_path ./so101-checkpoints \
    --embodiment-tag new_embodiment \
    --data-config so100_dualcam \
    --denoising-steps 4
```

- 在另一个终端，把评估脚本作为客户端运行。记得按你的实际配置更新机器人的端口和 id，以及摄像头的索引和参数。

```
python getting_started/examples/eval_lerobot.py \
    --robot.type=so100_follower \
    --robot.port=/dev/ttyACM0 \
    --robot.id=my_awesome_follower_arm \
    --robot.cameras="{ wrist: {type: opencv, index_or_path: 9, width: 640, height: 480, fps: 30}, front: {type: opencv, index_or_path: 15, width: 640, height: 480, fps: 30}}" \
    --policy_host=10.112.209.136 \
    --lang_instruction="Grab pens and place into pen holder."
```

由于我们用不同的语言指令微调了 GR00T-N1.5，用户可以使用[数据集](https://huggingface.co/datasets/youliangtan/so101-table-cleanup/blob/main/meta/tasks.jsonl)中的任务提示来引导策略，例如：

> "Grab tapes and place into pen holder".
