## 第 1 天：美术风格

游戏开发流程的第一步**是确定美术风格**。为农场游戏确定美术风格，我们将使用一个叫 Stable Diffusion 的工具。Stable Diffusion 是一个根据文字描述生成图像的开源模型。我们用这个工具为游戏创造一个视觉风格。

### 配置 Stable Diffusion

运行 Stable Diffusion 有几个选择：*本地*或*在线*。如果你在台式机上、有一块还不错的 GPU、想要全功能的工具集，我推荐[本地](https://huggingface.co/blog/ml-for-games-1#locally)。否则，你可以跑一个[在线](https://huggingface.co/blog/ml-for-games-1#online)方案。

#### 本地

我们将用 [Automatic1111 WebUI](https://github.com/AUTOMATIC1111/stable-diffusion-webui) 在本地运行 Stable Diffusion。这是本地运行 Stable Diffusion 的流行方案，但确实需要一些技术知识来配置。如果你是 Windows、有至少 8GB 显存的 Nvidia GPU，请按下面步骤操作。其他平台的情况，可在 [GitHub 仓库 README](https://github.com/AUTOMATIC1111/stable-diffusion-webui) 找说明，或者改用[在线](https://huggingface.co/blog/ml-for-games-1#online)方案。

##### 在 Windows 上安装：

**要求**：至少 8GB 显存的 Nvidia GPU。

- 安装 [Python 3.10.6](https://www.python.org/downloads/windows/)。**安装时务必勾选 "Add Python to PATH"。**
- 安装 [git](https://git-scm.com/download/win)。
- 在命令提示符中输入以下内容克隆仓库：

```
git clone https://github.com/AUTOMATIC1111/stable-diffusion-webui.git
```

- 下载 [Stable Diffusion 1.5 权重](https://huggingface.co/runwayml/stable-diffusion-v1-5)，放入克隆仓库的 `models` 目录。
- 运行克隆仓库中的 `webui-user.bat` 启动 WebUI。
- 访问 `localhost://7860` 使用 WebUI。如果一切正常，界面大概长这样：

### 生成概念图

我们来生成一些概念图。步骤很简单：

- 输入你想要的东西。
- 点击生成。

但如何得到你真正想要的结果？写提示（prompting）本身就是一门艺术，所以最初生成的图像不理想很正常。网上有很多提升提示词技巧的优秀资源。我做过一个 20 秒的[短视频](https://youtube.com/shorts/8PGucf999nI?feature=share)讲这个话题。你也可以看这份更详尽的[文字指南](https://www.reddit.com/r/StableDiffusion/comments/x41n87/how_to_get_images_that_dont_suck_a/)。

这些资源共同强调的一点是：用 [lexica.art](https://lexica.art/) 这样的网站看看别人用 Stable Diffusion 生成了什么。寻找与你想要的风格相似的图像，获得灵感。这里没有标准答案，但用 Stable Diffusion 1.5 生成概念图时有几条建议：

- 用 *isometric（等距）、simple（简单）、solid shapes（实心块面）*这类词约束输出的*形式*。这样得到的风格在游戏中更容易复刻。
- 有些关键词如 *low poly*，虽然切题，但往往产出质量更低。试着找到不降低画质的替代关键词。
- 使用具体艺术家的名字，是一种把模型导向特定风格并获得更高质量的强大手段。

### 带进 Unity

现在，如何把概念图变成游戏？我们将使用 [Unity](https://unity.com/)——一款流行的游戏引擎——让游戏活起来。

- 用 [Unity 2021.9.3f1](https://unity.com/releases/editor/whats-new/2021.3.9) 和 [Universal Render Pipeline](https://docs.unity3d.com/Packages/com.unity.render-pipelines.universal@15.0/manual/index.html) 创建一个 Unity 项目。
- 用基本形状搭建场景块。例如加一个立方体：*右键 -> 3D Object -> Cube*。

- 参照概念图设置你的 [Materials（材质）](https://docs.unity3d.com/Manual/Materials.html)。我用的是内置基础材质。

- 设置你的 [Lighting（光照）](https://docs.unity3d.com/Manual/Lighting.html)。我用暖色阳光（#FFE08C，强度 1.25）配柔和环境光（#B3AF91）。

- 设置你的 [Camera（摄像机）](https://docs.unity3d.com/ScriptReference/Camera.html)，**使用正交投影**以匹配概念图的投影方式。

- 加点水。我用 Unity 资产商店的 [Stylized Water Shader](https://assetstore.unity.com/packages/vfx/shaders/stylized-water-shader-71207)。

- 最后设置 [Post-processing（后处理）](https://docs.unity3d.com/Packages/com.unity.render-pipelines.universal@7.1/manual/integration-with-post-processing.html)。我用 ACES 色调映射和 +0.2 曝光。
