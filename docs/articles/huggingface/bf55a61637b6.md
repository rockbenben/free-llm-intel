# LeRobot v0.6.0：想象、评估、改进

这次新版本做的是把机器人学习循环闭合起来：能在行动前想象未来的策略、能告诉你机器人何时成功的奖励模型、能把失败转化为训练数据的部署 CLI，以及衡量这一切的六个新仿真基准。它还带来深度传感、VLM 驱动的数据集标注、自定义视频编码、在 HF Jobs 上的云端训练，以及一个精简得多的安装。

## TL;DR

LeRobot v0.6.0 引入会学习想象未来的世界模型策略（VLA-JEPA、FastWAM、LingBot-VA）、一波新的 VLA（GR00T N1.7、MolmoAct2、EO-1、EVO1、Multitask DiT）和全新的奖励模型 API（Robometer、TOPReward）。它随附统一在 `lerobot-eval` 下的六个新仿真基准、带 DAgger 式人在回路纠正的 `lerobot-rollout` CLI、FSDP 训练和 HF Jobs 云训练。数据集获得深度支持、自动语言标注流水线、自定义视频编码，数据加载最快提速 2 倍——这一切都建立在一个更轻的安装之上。

## 世界模型：会想象的政策

机器人领域正在追问一个大问题：世界模型真的能帮助机器人策略吗？v0.6.0 为 LeRobot 带来三个策略来帮助回答这个问题。每一个都在训练中想象未来，而每一个都选择了不同的路径让这份想象力负担得起。

### VLA-JEPA

VLA-JEPA 教一个紧凑的 VLA（基于 Qwen3-VL-2B）在学习行动的同时预测未来 latent：训练期间，一个 JEPA 世界模型必须根据模型自己的动作预知即将到来的画面。妙处在于世界模型在推理时消失，于是你以零额外推理成本获得世界模型的监督。Hub 上有三个可直接使用的 checkpoint，包括一个用于微调的 DROID 预训练基座：

```
lerobot-train \
  --policy.path=lerobot/VLA-JEPA-Pretrain \
  --dataset.repo_id=${HF_USER}/my_dataset \
  --policy.repo_id=${HF_USER}/my_finetuned_policy
```

更多见 [VLA-JEPA 文档](https://huggingface.co/docs/lerobot/v0.6.0/vla_jepa)和[论文](https://arxiv.org/abs/2602.10098)。

### LingBot-VA

LingBot-VA 走得更远：一个自回归视频-动作模型，逐 chunk 同时预测未来视频和动作，并把真实观测回填，让想象保持脚踏实地。你甚至可以保存机器人想象的内容（`--policy.save_predicted_video=true`），与实际情况对比。推理在单张 24–32 GB GPU 上即可运行。技术细节见[文档](https://huggingface.co/docs/lerobot/v0.6.0/lingbot_va)和[论文](https://arxiv.org/pdf/2601.21998)。

[![LingBot-VA 想象 rollout 与真实 rollout](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot-blog/release-v0.6.0/gifs/lingbot_va_viz_1.gif)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot-blog/release-v0.6.0/gifs/lingbot_va_viz_1.gif)

### FastWAM

FastWAM 把它论文标题里的问题抛了出来：world action model 需要在测试时想象未来吗？它把约 5B 参数的视频生成专家与一个紧凑的动作专家装进同一个网络，让模型真正学会「做梦」出自己的 rollout。推理时则完全跳过做梦，直接对动作 chunk 去噪。可从 [lerobot/fastwam_base](https://huggingface.co/lerobot/fastwam_base) 微调，更多阅读[文档](https://huggingface.co/docs/lerobot/v0.6.0/fastwam)。

## VLA：模型动物园持续扩张

### GR00T N1.7

我们把 NVIDIA GR00T 集成升级到了 GR00T N1.7——NVIDIA 跨具身基座模型最新的开放代际。N1.7 换掉了原来的 VLM，改由 Cosmos-Reason2-2B（基于 Qwen3-VL）驱动一个 flow-matching 动作头；我们的集成与 NVIDIA 原版 Isaac-GR00T 实现对齐测试：相同输入，相同输出。Flash-attention 现在是可选项，所以 `pip install 'lerobot[groot]'` 开箱即用，并且可以直接加载 [NVIDIA 发布的 checkpoint](https://huggingface.co/nvidia/GR00T-N1.7-3B)。

> GR00T N1.7 在 LeRobot 中取代了 N1.5。如果你需要 N1.5，请 pin lerobot==0.5.1。

### MolmoAct2

MolmoAct2——Allen Institute for AI 的视觉-语言-动作模型——现已移植进 LeRobot，全生命周期覆盖：微调（全量或 LoRA）、评估和真机部署。带着校准校正的现成 checkpoint，意味着你可以在 SO-100/101 上直接 zero-shot 运行：

```
lerobot-rollout \
  --policy.path=lerobot/MolmoAct2-SO100_101-LeRobot \
  --robot.type=so100_follower \
  --robot.port=/dev/ttyACM0 \
  --robot.cameras='{cam0: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30}, cam1: {type: opencv, index_or_path: 2, width: 640, height: 480, fps: 30}}' \
  --task="pick up the red cube" --duration=30
```

推理在 bf16 下约 12 GB 即可装下，LoRA 微调在单张 24 GB GPU 上就能跑。完整部署指南见 [MolmoAct2 文档](https://huggingface.co/docs/lerobot/v0.6.0/molmoact2)。

[![MolmoAct2 在 LeRobot 中的 Zero-Shot 表现](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot-blog/release-v0.6.0/gifs/molmoact2_4.gif)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot-blog/release-v0.6.0/gifs/molmoact2_4.gif)

### EO-1

EO-1 是一个在上游用视觉-文本-动作交错数据预训练的 VLA，加入 LeRobot：Qwen2.5-VL-3B 骨干加 flow-matching 动作头，由论文作者之一贡献。用标准 `lerobot-train` 工作流配合 `--policy.type=eo1` 训练。细节见[文档](https://huggingface.co/docs/lerobot/v0.6.0/eo1)和[论文](https://arxiv.org/abs/2508.21112)。

### Multitask DiT

Multitask Diffusion Transformer 策略把 TRI Large Behavior Models 的配方带进 LeRobot：一个约 4.5 亿参数的 diffusion transformer，以 CLIP 视觉与语言嵌入为条件，一个模型学习许多任务、用自然语言选择。它同时支持 diffusion 和 flow-matching 目标，而且小到你自己就能训练。见[文档](https://huggingface.co/docs/lerobot/v0.6.0/multi_task_dit)。

### EVO1

VLA 未必要很大。EVO1 把策略压进 0.77B 参数——InternVL3-1B 骨干加 flow-matching 动作头——小到在普通 GPU 上就能微调并实时运行。它开箱自带两阶段微调和 Real-Time Chunking 支持。见 [EVO1 文档](https://huggingface.co/docs/lerobot/v0.6.0/evo1)和[论文](https://arxiv.org/abs/2511.04555)。

## 奖励模型：知道你的机器人何时成功

成功检测与进度估计是机器人学习循环中缺失的环节，v0.6.0 给它们安了家。LeRobot 现在有了统一的奖励模型 API（`lerobot.rewards`），与策略 API 呼应，一个接口背后有四个奖励模型——HIL-SERL 奖励分类器、SARM，以及两个新成员：

### Robometer

Robometer 是一个预训练的通用奖励模型：把 [lerobot/Robometer-4B](https://huggingface.co/lerobot/Robometer-4B) 指向任何 LeRobot 数据集，它就能从原始视频加语言指令给出任务进度和成功评分，无需任务特定训练。它基于 Qwen3-VL-4B，通过超过一百万条机器人轨迹数据集上的轨迹比较训练而成（[RSS 2026 论文](https://arxiv.org/abs/2603.02115)）。

[![LeRobot Robometer](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot-blog/release-v0.6.0/gifs/rm_robometer.gif)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot-blog/release-v0.6.0/gifs/rm_robometer.gif)

### TOPReward

TOPReward 彻底 zero-shot：完全没有奖励权重。它包一个现成 VLM（Qwen3-VL），读取给定轨迹视频和任务指令下 token "True" 的对数概率。任何够格的 VLM 都能变成奖励函数。

两者都附带标注脚本，可以把逐帧进度曲线写入你的数据集，直接用于奖励感知行为克隆（RA-BC）、数据集质量检查和进度叠加视频。参见 [Robometer](https://huggingface.co/docs/lerobot/v0.6.0/robometer) 和 [TOPReward](https://huggingface.co/docs/lerobot/v0.6.0/topreward) 文档。

## 数据集：加载更快、数据更丰富

### 你的编解码器你做主

录制不再被一种硬编码编解码器锁死。新的 `--dataset.rgb_encoder.*` 选项暴露了完整的编码面（编解码器、质量、像素格式、GOP、预设），`vcodec=auto` 会先探测 NVENC、VideoToolbox、VAAPI、QSV 这类硬件编码器，再回落到默认的软件 AV1 编码器。对已有数据集，一条命令就能全部重编码：

```
lerobot-edit-dataset \
    --repo_id ${HF_USER}/my_dataset \
    --operation.type reencode_videos \
    --operation.rgb_encoder.vcodec h264 \
    --operation.rgb_encoder.crf 23
```

完整细节见[视频编码文档](https://huggingface.co/docs/lerobot/v0.6.0/video_encoding_parameters)。

### 端到端深度支持

插上 Intel RealSense，设 `use_depth: true`，LeRobot 就端到端录制深度图：以毫米采集，压成紧凑的 12-bit 深度视频流与 RGB 相机并存，训练时再解码回物理单位。深度在录制期间和 `lerobot-dataset-viz` 中都能实时渲染，并且支持 SO-100/101、Koch、OpenArm、reBot、Unitree G1 等多种机型。

[![LeRobot 深度相机](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot-blog/release-v0.6.0/gifs/depth2.gif)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot-blog/release-v0.6.0/gifs/depth2.gif)

### 规模化语言标注

你的数据集不再每回合只有一条任务字符串。LeRobot 数据集现在原生存储丰富语言标注（带时间戳的子任务、计划、记忆、纠正、语音，以及逐相机的 VQA 对），新的 `lerobot-annotate` CLI 用一个「观看」你回合的 VLM 自动填好它们：

```
lerobot-annotate \
    --repo_id=${HF_USER}/my_dataset \
    --new_repo_id=${HF_USER}/my_dataset_annotated \
    --vlm.model_id=Qwen/Qwen2.5-VL-7B-Instruct \
    --push_to_hub=true
```

随后一个 YAML recipe 层在采样时把这些标注渲染成 chat 风格的训练消息——正是明天那些长程、会说话的机器人策略要训练的数据。用 HF Jobs 扩展规模，更多了解请看[标注流水线文档](https://huggingface.co/docs/lerobot/v0.6.0/annotation_pipeline)。

### 数据加载最快提速 2 倍

在视频数据集上训练现在开箱快约 2 倍：多相机帧并行解码，dataloader worker 之间传紧凑的 uint8 帧（进程间内存减少 4 倍），常驻 worker 让解码器缓存跨 epoch 保活。加载大数据集的子集（`episodes=[...]`）从几分钟降到毫秒（我们的基准：275 秒降到 0.06 秒）。采样现在也是确定且可续跑的，中断的训练能以完全相同的样本重启。

## 基准：一个 CLI 评估所有

v0.5.0 在 LeRobot 插下了「VLA 评估中心」的旗；v0.6.0 让它名副其实——新增六个仿真基准，全部通过同一个 `lerobot-eval` CLI 运行，每个都有文档页、Docker 镜像和一个在 CI 中冒烟验证过的 SmolVLA 基线 checkpoint：

- [LIBERO-plus](https://huggingface.co/docs/lerobot/v0.6.0/libero_plus) 用约 10,000 个 LIBERO 扰动变体、横跨七个轴（从光照、相机视角到改写的指令）对 VLA 做压力测试。它告诉你策略什么时候会崩。
- [RoboTwin 2.0](https://huggingface.co/docs/lerobot/v0.6.0/robotwin) 在 SAPIEN 上覆盖 50 个双臂操作任务并采用强域随机化，附带 Hub 上[超过 10 万条可直接训练的轨迹](https://huggingface.co/datasets/lerobot/robotwin_unified)。
- [RoboCasa365](https://huggingface.co/docs/lerobot/v0.6.0/robocasa) 在移动操作平台上覆盖 2,500 个程序生成厨房中的 365 个厨房任务，是我们阵列中任务面最大的。
- [RoboCerebra](https://huggingface.co/docs/lerobot/v0.6.0/robocerebra) 评估长程行为：回合串联 3 到 6 个子目标、接受语言接地的中间指令，另配 6,660 个回合的数据集。
- [RoboMME](https://huggingface.co/docs/lerobot/v0.6.0/robomme) 是一场记忆考试：你的策略能数清重复次数、追踪隐藏物体、模仿演示过的流程吗？4 个记忆套件的 16 个任务。
- [VLABench](https://huggingface.co/docs/lerobot/v0.6.0/vlabench) 考察操作中的知识与推理，从物理问题到从头到尾冲一杯咖啡这类复合任务。

```
lerobot-eval \
  --policy.path=lerobot/smolvla_robotwin \
  --env.type=robotwin \
  --env.task=beat_block_hammer \
  --eval.n_episodes=100 --eval.batch_size=1
```

仿真器后端需要特定系统依赖和自己的安装步骤；每个文档页都给了准确配方，不想折腾环境的话，每个基准都提供现成 Docker 镜像。

连同 LIBERO、Meta-World 和 NVIDIA IsaacLab-Arena，同一家之下已有九个基准家族；新的[添加新基准指南](https://huggingface.co/docs/lerobot/v0.6.0/adding_benchmarks)详细说明了怎么接入你自己的基准。评估也更快了：并行 eval 现在默认使用异步向量化环境，基准测试显示最快提速 2 倍。

[![LeRobot 基准](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot-blog/release-v0.6.0/gifs/benchmarks2.gif)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot-blog/release-v0.6.0/gifs/benchmarks2.gif)

## 训练与推理

### `lerobot-rollout`：部署自有 CLI

过去部署策略是在 `lerobot-record` 上打补丁。新的 `lerobot-rollout` CLI 让部署成为独立工作流，支持可插拔策略和推理后端（包括给跑得慢的兼容 VLA 用的 Real-Time Chunking）。`base` 策略就是单纯跑策略。`sentry` 持续录制，滚动切换 episode 并随手上传到 Hub。`highlight` 维护一个环形缓冲，按键时保存最近 N 秒，精彩瞬间绝不丢失。`episodic` 复刻经典的 episode/reset 录制工作流。而 `dagger` 把部署变成数据收集。

用 DAgger 策略，你看着你的策略运行，它在出错的一瞬间你按一下键（或 USB 脚踏），用主臂接管记录纠正动作，然后交还控制权。带驱动的 leader 在你接管前会被驱动到 follower 的位姿，交接因此无抖动。每一帧纠正都打上 `intervention` 标记，产出的数据集直接可用于下一次微调：

```
lerobot-rollout \
    --strategy.type=dagger \
    --policy.path=${HF_USER}/my_policy \
    --robot.type=so100_follower \
    --robot.port=/dev/ttyACM0 \
    --teleop.type=so101_leader \
    --teleop.port=/dev/ttyACM1 \
    --dataset.repo_id=${HF_USER}/dagger_corrections \
    --dataset.single_task="Grasp the block"
```

部署、收集纠正、微调、循环：机器人学习的飞轮现在只是一个 CLI 开关。阅读[部署文档](https://huggingface.co/docs/lerobot/v0.6.0/inference)。

### FSDP：训练比你的 GPU 更大的模型

机器人基础模型已经超出单卡容量。LeRobot 训练现已通过 Accelerate 支持 FSDP（fully sharded data parallel）：参数、梯度和优化器状态分片到多块 GPU，checkpoint 会被聚合回普通的单文件 `model.safetensors`，和其他策略一样加载。你甚至可以在不同 GPU 数量上恢复 FSDP 运行。见[多 GPU 训练文档](https://huggingface.co/docs/lerobot/v0.6.0/multi_gpu_training)。

### 用 HF Jobs 云端训练

没有 GPU？没关系。完全相同的 `lerobot-train` 命令现在加一个标志就能在云上跑：

```
lerobot-train \
  --dataset.repo_id=${HF_USER}/so101_test \
  --policy.type=act \
  --policy.repo_id=${HF_USER}/my_policy \
  --job.target=a10g-small
```

LeRobot 会在需要时把本地数据集推到私有 Hub 仓库、提交 job、把日志流到你的终端，结束后把训练好的策略推上 Hub。用 `--job.target` 从 T4 选到 8x H200（算力按量计费）。[查看文档](https://huggingface.co/docs/lerobot/v0.6.0/hardware_guide#hugging-face-jobs)

## 代码库：更精简、更整洁

- `pip install lerobot` 如今是真正的轻量安装，基础依赖减少约 40%。按功能划分的 extras（`[training]`、`[core_scripts]`、`[evaluation]`……）覆盖其余部分，缺依赖的报错会直接告诉你要加哪个 extra。**如果你只用 LeRobot 数据集，不再需要安装硬件相关依赖了 ;)**
- 支持的 PyTorch 移到 2.7–2.11，Linux `uv` 安装开箱 pin 好 CUDA 12.8 wheels。`--policy.dtype=bfloat16` 现在通过 Accelerate 驱动真正的混合精度训练。
- 提交进仓库的 `uv.lock` 是 CI、Docker 和开发唯一的依赖权威清单，文档为每一步提供了 `uv` 安装路径——甚至用一个 flag 就能选你的 CUDA wheel。
- `--display_mode=foxglove` 把遥操作、录制和 rollout 流到 [Foxglove](https://foxglove.dev)——机器人世界许多人已经在用的可视化工具。远程配置也能用，且 `lerobot-dataset-viz` 获得了可拖动的数据集回放。
- 可 pip 安装的 `lerobot_env_*` 包现在会自注册它们的环境。插件系统覆盖全部五类组件：机器人、相机、遥操作器、策略和环境。
- 录制时的键盘控制现在支持 Wayland、SSH 远程、无头机器，以及不需要辅助功能权限的 macOS。

> 完整清单和破坏性变更的迁移指引见 release notes。

- LeLab 把整个 LeRobot 工作流（校准、遥操作、录制、本地或 HF Jobs 训练、部署）搬进浏览器 UI，无需 CLI。目前支持 SO-ARM101。[试试看！](https://github.com/huggingface/leLab)
