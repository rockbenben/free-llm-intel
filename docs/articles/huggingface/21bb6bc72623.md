# 使用自定义数据集微调语义分割模型

**本指南将演示如何微调 SegFormer——一个最先进的语义分割模型。我们的目标是为一个披萨配送机器人搭建一个模型，让它能看出该往哪儿开、并识别障碍物 🍕🤖。我们会先使用 🤗 hub 上一个现成的分割数据集，然后用 [`🤗 transformers`](https://huggingface.co/transformers) 微调一个预训练的 SegFormer 模型；这是一个开源库，提供了最先进模型的易用实现。在此过程中，你还会了解如何使用 Hugging Face Hub——最大的开源模型与数据集目录。**

语义分割是对图像中每个像素进行分类的任务。你可以把它看作一种更精确的图像分类方式。它在医学影像、自动驾驶等领域有广泛的应用。例如，对我们的披萨配送机器人来说，重要的是确切地知道人行道在图像中的位置，而不仅仅是有没有人行道。

因为语义分割本质上是一种分类任务，用于图像分类和语义分割的网络架构非常相似。2014 年，Long 等人的[一篇开创性论文](https://arxiv.org/abs/1411.4038)将卷积神经网络用于语义分割。最近，Transformer 已被用于图像分类（例如 [ViT](https://huggingface.co/blog/fine-tune-vit)），如今它们也被用于语义分割，进一步推动了该领域的最高水平。

[SegFormer](https://huggingface.co/docs/transformers/model_doc/segformer) 是 Xie 等人于 2021 年提出的一个语义分割模型。它有一个分层的 Transformer 编码器，且不使用位置编码（与 ViT 不同），并配有一个简单的多层感知机解码器。SegFormer 在多个常见数据集上取得了最先进的性能。我们来看看我们的披萨配送机器人在人行道图像上的表现如何。

我们先从安装必要的依赖开始。因为我们要把数据集和模型推送到 Hugging Face Hub，所以需要安装 [Git LFS](https://git-lfs.github.com/) 并登录 Hugging Face。

在你的系统上，`git-lfs` 的安装方式可能有所不同。请注意，Google Colab 已预装了 Git LFS。

```
pip install -q transformers datasets evaluate segments-ai
apt-get install git-lfs
git lfs install
huggingface-cli login
```

## 1. 创建/选择数据集

任何机器学习项目的第一步都是凑齐一个好的数据集。为了训练一个语义分割模型，我们需要一个带有语义分割标签的数据集。我们既可以使用 Hugging Face Hub 上现有的数据集，例如 [ADE20k](https://huggingface.co/datasets/scene_parse_150)，也可以通过给图像标注相应的分割图来创建自己的数据集。

对于我们的披萨配送机器人，我们可以使用现有的自动驾驶数据集，例如 [CityScapes](https://www.cityscapes-dataset.com/) 或 [BDD100K](https://bdd100k.com/)。然而，这些数据集是由行驶在马路上的汽车采集的。由于我们的配送机器人会在人行道上行驶，这些数据集中的图像与我们的机器人在真实世界会看到的数据之间会存在错配。

我们不想让配送机器人犯迷糊，所以我们用拍摄于人行道上的图像创建了自己的语义分割数据集。它发布在 [segments/sidewalk-semantic](https://huggingface.co/datasets/segments/sidewalk-semantic)。这件事可以用 [CVAT](https://www.cvat.ai/) 或 [Segments.ai](https://segments.ai/) 这样的标注平台来完成。

### 使用 Hub 上的数据集

这里我们会加载完整标注的人行道数据集。请注意，你可以[直接在浏览器中](https://huggingface.co/datasets/segments/sidewalk-semantic)查看这些样例。

```
hf_dataset_identifier = "segments/sidewalk-semantic"
```

## 2. 加载并准备用于训练的 Hugging Face 数据集

既然我们已经创建了一个新数据集并把它推送到了 Hugging Face Hub，就可以用一行代码加载这个数据集。

```
from datasets import load_dataset

ds = load_dataset(hf_dataset_identifier)
```

我们对数据集做随机打乱，并把它划分为训练集和测试集。

```
ds = ds.shuffle(seed=1)
ds = ds["train"].train_test_split(test_size=0.2)
train_ds = ds["train"]
test_ds = ds["test"]
```

我们提取标签数量和人类可读的 id，以便后面正确地配置分割模型。

```
import json
from huggingface_hub import hf_hub_download

repo_id = f"datasets/{hf_dataset_identifier}"
filename = "id2label.json"
id2label = json.load(open(hf_hub_download(repo_id=hf_dataset_identifier, filename=filename, repo_type="dataset"), "r"))
id2label = {int(k): v for k, v in id2label.items()}
label2id = {v: k for k, v in id2label.items()}

num_labels = len(id2label)
```

### 图像处理器与数据增强

SegFormer 模型期望输入具有某种特定的形状。为了把训练数据转换成所需的形状，我们可以使用 `SegFormerImageProcessor`。我们本可以用 `ds.map` 函数预先对整份训练数据集应用图像处理器，但这样会占用大量磁盘空间。取而代之，我们会使用一个*变换（transform）*，它只在某批数据真正被用到时才对其进行准备（即时处理）。这样，我们无需等待进一步的数据预处理就能开始训练。

在我们的变换里，我们还会定义一些数据增强，让模型对不同光照条件更有韧性。我们会使用 `torchvision` 的 [`ColorJitter`](https://pytorch.org/vision/main/generated/torchvision.transforms.ColorJitter.html) 函数，随机改变这一批次中图像的亮度、对比度、饱和度和色调。

```
from torchvision.transforms import ColorJitter
from transformers import SegformerImageProcessor

processor = SegformerImageProcessor()
jitter = ColorJitter(brightness=0.25, contrast=0.25, saturation=0.25, hue=0.1) 

def train_transforms(example_batch):
    images = [jitter(x) for x in example_batch['pixel_values']]
    labels = [x for x in example_batch['label']]
    inputs = processor(images, labels)
    return inputs


def val_transforms(example_batch):
    images = [x for x in example_batch['pixel_values']]
    labels = [x for x in example_batch['label']]
    inputs = processor(images, labels)
    return inputs


# Set transforms
train_ds.set_transform(train_transforms)
test_ds.set_transform(val_transforms)
```

## 3. 微调一个 SegFormer 模型

### 加载要微调的模型

SegFormer 的作者定义了 5 个尺寸递增的模型：B0 到 B5。下面的图表（取自原始论文）展示了这些不同模型在 ADE20K 数据集上与其他模型相比的性能。

来源

这里，我们会加载最小的 SegFormer 模型（B0），它在 ImageNet-1k 上做过预训练，体积只有大约 14MB！使用一个小模型，能确保我们的模型在披萨配送机器人上顺畅运行。

```
from transformers import SegformerForSemanticSegmentation

pretrained_model_name = "nvidia/mit-b0" 
model = SegformerForSemanticSegmentation.from_pretrained(
    pretrained_model_name,
    id2label=id2label,
    label2id=label2id
)
```

### 配置 Trainer

要在我们的数据上微调模型，我们会使用 Hugging Face 的 [Trainer API](https://huggingface.co/docs/transformers/main_classes/trainer)。使用 Trainer 需要配置好训练设置和一个评估指标。

首先，我们配置 [`TrainingArguments`](https://huggingface.co/docs/transformers/main_classes/trainer#transformers.TrainingArguments)。它定义了所有训练超参数，例如学习率、epoch 数量、保存模型的频率等等。我们还指定训练结束后把模型推送到 hub（`push_to_hub=True`），并指定一个模型名（`hub_model_id`）。

```
from transformers import TrainingArguments

epochs = 50
lr = 0.00006
batch_size = 2

hub_model_id = "segformer-b0-finetuned-segments-sidewalk-2"

training_args = TrainingArguments(
    "segformer-b0-finetuned-segments-sidewalk-outputs",
    learning_rate=lr,
    num_train_epochs=epochs,
    per_device_train_batch_size=batch_size,
    per_device_eval_batch_size=batch_size,
    save_total_limit=3,
    evaluation_strategy="steps",
    save_strategy="steps",
    save_steps=20,
    eval_steps=20,
    logging_steps=1,
    eval_accumulation_steps=5,
    load_best_model_at_end=True,
    push_to_hub=True,
    hub_model_id=hub_model_id,
    hub_strategy="end",
)
```

接下来，我们定义一个函数来计算我们想用的评估指标。因为我们做的是语义分割，所以会使用[平均交并比（mean Intersection over Union，mIoU）](https://huggingface.co/spaces/evaluate-metric/mean_iou)，它可直接在 [`evaluate` 库](https://huggingface.co/docs/evaluate/index)中使用。IoU 表示分割遮罩的重叠程度。平均 IoU 是所有语义类别 IoU 的平均值。关于图像分割评估指标的概览，可以看看[这篇博客](https://www.jeremyjordan.me/evaluating-image-segmentation-models/)。

因为我们的模型输出的 logits 尺寸为 height/4 和 width/4，所以在计算 mIoU 之前必须先把它们上采样放大。

```
import torch
from torch import nn
import evaluate

metric = evaluate.load("mean_iou")

def compute_metrics(eval_pred):
  with torch.no_grad():
    logits, labels = eval_pred
    logits_tensor = torch.from_numpy(logits)
    # scale the logits to the size of the label
    logits_tensor = nn.functional.interpolate(
        logits_tensor,
        size=labels.shape[-2:],
        mode="bilinear",
        align_corners=False,
    ).argmax(dim=1)

    pred_labels = logits_tensor.detach().cpu().numpy()
    metrics = metric.compute(
        predictions=pred_labels,
        references=labels,
        num_labels=len(id2label),
        ignore_index=0,
        reduce_labels=processor.do_reduce_labels,
    )
    
    # add per category metrics as individual key-value pairs
    per_category_accuracy = metrics.pop("per_category_accuracy").tolist()
    per_category_iou = metrics.pop("per_category_iou").tolist()

    metrics.update({f"accuracy_{id2label[i]}": v for i, v in enumerate(per_category_accuracy)})
    metrics.update({f"iou_{id2label[i]}": v for i, v in enumerate(per_category_iou)})
    
    return metrics
```

最后，我们就可以实例化一个 `Trainer` 对象了。

```
from transformers import Trainer

trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=train_ds,
    eval_dataset=test_ds,
    compute_metrics=compute_metrics,
)
```

训练器配置好后，训练就像调用 `train` 函数一样简单。我们不必操心 GPU 的管理，训练器会替我们处理好。

```
trainer.train()
```

训练完成后，我们可以把微调好的模型和图像处理器推送到 Hub。

这还会自动用我们的结果创建一张模型卡（model card）。我们会在 `kwargs` 里提供一些额外信息，让模型卡更完整。

```
kwargs = {
    "tags": ["vision", "image-segmentation"],
    "finetuned_from": pretrained_model_name,
    "dataset": hf_dataset_identifier,
}

processor.push_to_hub(hub_model_id)
trainer.push_to_hub(**kwargs)
```

## 4. 推理

接下来是令人兴奋的部分——使用我们微调好的模型！本节将演示如何从 hub 加载模型并用它做推理。

不过，多亏了由[托管推理 API](https://api-inference.huggingface.co/docs/python/html/index.html)驱动的酷炫小部件（widget），你也可以直接在 Hugging Face Hub 上试用你的模型。如果你在上一步已经把模型推送到 Hub，就应该能在模型页面上看到一个推理小部件。你可以通过在模型卡里定义示例图像的 URL，为小部件添加默认示例。可参考[这张模型卡](https://huggingface.co/tobiasc/segformer-b0-finetuned-segments-sidewalk/blob/main/README.md)作为示例。

### 从 Hub 使用模型

我们先用 `SegformerForSemanticSegmentation.from_pretrained()` 从 Hub 加载模型。

```
from transformers import SegformerImageProcessor, SegformerForSemanticSegmentation

processor = SegformerImageProcessor.from_pretrained("nvidia/segformer-b0-finetuned-ade-512-512")
model = SegformerForSemanticSegmentation.from_pretrained(f"{hf_username}/{hub_model_id}")
```

接下来，我们从测试数据集中加载一张图像。

```
image = test_ds[0]['pixel_values']
gt_seg = test_ds[0]['label']
image
```

要对这张测试图像做分割，我们先用图像处理器对图像进行预处理，然后再把它前向传播通过模型。

我们还需要记得把输出的 logits 上采样到原始图像的尺寸。要得到实际的类别预测，只需对 logits 施加一个 `argmax`。

```
from torch import nn

inputs = processor(images=image, return_tensors="pt")
outputs = model(**inputs)
logits = outputs.logits  # shape (batch_size, num_labels, height/4, width/4)

# First, rescale logits to original image size
upsampled_logits = nn.functional.interpolate(
    logits,
    size=image.size[::-1], # (height, width)
    mode='bilinear',
    align_corners=False
)

# Second, apply argmax on the class dimension
pred_seg = upsampled_logits.argmax(dim=1)[0]
```
