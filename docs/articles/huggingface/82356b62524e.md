# DeepInfra 上线 Hugging Face 推理提供商🔥

[![banner image](https://huggingface.co/blog/assets/inference-providers/welcome-deepinfra.jpg)](https://huggingface.co/blog/assets/inference-providers/welcome-deepinfra.jpg)

我们非常高兴地宣布：**DeepInfra** 现已成为 Hugging Face Hub 上的受支持推理提供商（Inference Provider）！

DeepInfra 加入了我们不断壮大的生态，扩展了 Hub 模型页面上无服务器（serverless）推理的广度与能力。Inference Providers 也与我们面向 JS 和 Python 的客户端 SDK 无缝集成，用最偏好的提供商调用各类模型超级简单。

[DeepInfra](https://deepinfra.com) 是一个无服务器 AI 推理平台，提供业界最有性价比的按 token 定价之一。凭借 100 多个模型的目录，DeepInfra 让开发者用极少的配置就能把广泛的 AI 能力集成进自己的应用。

DeepInfra 支持非常宽泛的模型类型——从 LLM 到文生图、文生视频、嵌入等等。作为本次初始集成的一部分，DeepInfra 率先在 Hugging Face 上上线**对话与文本生成任务**的支持，可以访问 [DeepSeek V4](https://huggingface.co/deepseek-ai/DeepSeek-V4-Pro?inference_provider=deepinfra)、[Kimi-K2.6](https://huggingface.co/moonshotai/Kimi-K2.6?inference_provider=deepinfra)、[GLM-5.1](https://huggingface.co/zai-org/GLM-5.1?inference_provider=deepinfra) 等热门开放权重 LLM。**更多任务**（文生图、文生视频、嵌入等）的支持即将推出！

如何把 DeepInfra 用作推理提供商，详见其[专门文档页](https://huggingface.co/docs/inference-providers/providers/deepinfra)。

DeepInfra 支持的全部模型列表见[这里](https://huggingface.co/models?inference_provider=deepinfra&sort=trending)。

在 Hugging Face 上关注 DeepInfra：[https://huggingface.co/DeepInfra](https://huggingface.co/DeepInfra)。

## 工作原理

### 在网站 UI 中

- 在你的用户账户设置里，你可以：

- 为你注册过的提供商设置自己的 API key。不设置自定义 key 的话，请求将经由 HF 路由。
- 按偏好对提供商排序。这会影响模型页上的 widget 和代码片段。

- 如前所述，调用 Inference Providers 有两种模式：

- 自定义 key（请求直达推理提供商，使用你在对应推理提供商的 API key）
- 由 HF 路由（这种方式不需要提供商的 token，费用直接记到你的 HF 账户而非提供商账户）

- 模型页面会展示第三方推理提供商（与当前模型兼容的那些，按用户偏好排序）

### 通过客户端 SDK

DeepInfra 可通过 Hugging Face SDK 使用——Python 的 `huggingface_hub`（>= 1.11.2）和 JavaScript 的 `@huggingface/inference`。

以下示例展示如何通过 DeepInfra 使用 [DeepSeek V4 Pro](https://huggingface.co/deepseek-ai/DeepSeek-V4-Pro)。用 [Hugging Face token](https://huggingface.co/settings/tokens) 认证即可——请求会自动路由到 DeepInfra。

#### 从你最爱的 Agent Harness

Hugging Face Inference Providers 已集成进多数 Agent Harness——包括 Pi、OpenCode、Hermes Agents、OpenClaw 等。这意味着你可以把 DeepInfra 托管的模型直接插进你惯用的工具，无需任何额外胶水代码。全部集成列表见[这里](https://huggingface.co/docs/inference-providers/en/integrations/index)。

#### 用 Python

```
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://router.huggingface.co/v1",
    api_key=os.environ["HF_TOKEN"],
)

completion = client.chat.completions.create(
    model="deepseek-ai/DeepSeek-V4-Pro:deepinfra",
    messages=[
        {
            "role": "user",
            "content": "Write a Python function that returns the nth Fibonacci number using memoization."
        }
    ],
)

print(completion.choices[0].message)
```

#### 用 JS

```
import { OpenAI } from "openai";

const client = new OpenAI({
    baseURL: "https://router.huggingface.co/v1",
    apiKey: process.env.HF_TOKEN,
});

const chatCompletion = await client.chat.completions.create({
    model: "deepseek-ai/DeepSeek-V4-Pro:deepinfra",
    messages: [
        {
            role: "user",
            content: "Write a Python function that returns the nth Fibonacci number using memoization.",
        },
    ],
});

console.log(chatCompletion.choices[0].message);
```

## 计费

直接请求——即你使用推理提供商的 key 时——由对应提供商计费。例如用 DeepInfra API key，就在你的 DeepInfra 账户中计费。

路由请求——即你通过 Hugging Face Hub 认证时——只需支付提供商 API 的标准费率。我们不加任何附加费，提供商成本原样透传。（未来我们可能与提供商伙伴建立收入分成协议。）
