随着 [Aya Vision 家族](https://huggingface.co/collections/CohereForAI/c4ai-aya-vision-67c4ccd395ca064308ee1484)——我们全新的 **8B** 与 **32B** 参数视觉语言模型（VLM）——的发布，我们正在应对 AI 最大的挑战之一：*把多语言能力带进多模态模型*。

Aya Vision 是 [Cohere For AI](https://cohere.com/research) 最新的开放权重多语言多模态模型家族，旨在为跨 **23 种语言**的语言与视觉理解提供坚实基础。它建立在 [Aya Expanse](https://huggingface.co/collections/CohereForAI/c4ai-aya-expanse-671a83d6b2c07c692beab3c3)——最先进的多语言语言模型——的成功之上，并用一组先进技术加以扩展，包括：合成标注、通过翻译与复述扩大多语言数据规模、多模态模型合并——这些关键方法在多语言场景下同时提升了语言与视觉理解。

因此，我们的模型在多种任务上表现优异，包括图像描述、视觉问答、文本生成，以及把文本和图像翻译成清晰自然的语言文本。我们在一系列数据集上评估了 Aya Vision 模型，包括我们新发布的开放式视觉-语言基准 [AyaVisionBench](https://huggingface.co/datasets/CohereForAI/AyaVisionBench)，以及翻译成 23 种语言的 Wild Vision Bench 多语言版本（[mWildVision](https://huggingface.co/datasets/CohereForAI/m-WildVision)）——两者都面向研究开放。

在成对比较中，Aya Vision 32B 胜过体积超过其 2 倍的模型，例如 Llama-3.2 90B Vision、Molmo 72B 和 Qwen2.5-VL 72B：在 AyaVisionBench 上胜率 50% 到 64%，在 mWildVision 上跨 23 种语言平均胜率 52% 到 72%。

[![aya vision win rates](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/aya-vision/aya-vision-combined-win-rates.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/aya-vision/aya-vision-combined-win-rates.png)

我们精简高效的模型 Aya Vision 8B 在同参数量级中取得多模态多语言的最佳表现，胜过 Qwen2.5-VL 7B、Pixtral 12B、Gemini Flash 1.5 8B、Llama-3.2 11B Vision、Molmo-D 7B 和 Pangea 7B 等领先模型：在 AyaVisionBench 上胜率最高达 79%，在 mWildBench 上达 81%。

[![efficiency vs performance trade offs](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/aya-vision/efficiency-vs-performance.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/aya-vision/efficiency-vs-performance.png)

我们把 [8B](https://huggingface.co/CohereForAI/aya-vision-8b) 和 [32B](https://huggingface.co/CohereForAI/aya-vision-32b) 两个模型都以开放权重发布给研究社区，以进一步加速多语言多模态的进步。在这篇博客中，我们分享 Aya Vision 模型背后的关键技术细节。

## Aya Vision 的架构与训练

[![aya vision architecture](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/aya-vision/image-8.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/aya-vision/image-8.png)

对一个高性能的视觉语言模型来说，用*任意分辨率*处理图像非常重要，尤其是高分辨率图像。为了让 Aya Vision 具备这一能力，我们对任何高分辨率图像动态缩放并切分成多个 tile，从图像编码器中生成丰富的图像特征。在 Aya Vision 模型中，我们用近期发布的 [SigLIP2-patch14-384](https://huggingface.co/blog/siglip2) 模型作为视觉编码器的初始化。

动态缩放虽然实现了高分辨率图像处理，但也让更多图像 token 流经视觉-语言连接器和 LLM decoder。为改善延迟与吞吐，我们使用一种叫 [Pixel Shuffle](https://arxiv.org/pdf/2404.16821) 的下采样方法，把图像 token 数量压缩 4 倍。下采样后，图像 token 通过视觉-语言连接器对齐到语言模型的输入 embedding，并送入 LLM decoder。

文本解码器使用我们的多语言语言模型。对 Aya Vision 8B，我们使用从 [Cohere Command R7B](https://huggingface.co/CohereForAI/c4ai-command-r7b-12-2024) 初始化的 LLM，以获得更好的指令遵循与世界知识，并进一步用 [Aya Expanse 配方](https://huggingface.co/blog/aya-expanse)（包含多语言多样数据、模型合并与偏好训练）做后训练。对 Aya Vision 32B，我们基于最先进的多语言性能，从 [Aya Expanse 32B](https://huggingface.co/CohereForAI/aya-expanse-32b) 初始化语言模型。

### 训练过程

Aya Vision 模型的训练分 **2 个阶段**——*视觉-语言对齐*与*监督微调（SFT）*。在视觉-语言对齐阶段，只训练视觉-语言连接器，视觉编码器和语言模型权重保持冻结。这通过将图像编码器特征映射到语言模型 embedding 空间，建立基础的视觉-语言理解。在 SFT 阶段，我们在 23 种语言的多样化多模态任务上同时训练连接器和语言模型。

[![step by step improvement](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/aya-vision/step-by-step-improvement.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/aya-vision/step-by-step-improvement.png)

## 多模态数据增强与语言覆盖扩展

[![multilingual synthetic annotation](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/aya-vision/image-9.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/aya-vision/image-9.png)

开发多语言视觉语言模型的最大挑战之一，是确保在被代表性不足的语言上也有强劲表现。为应对这点，我们首先用一批高质量的英文数据集采集合成标注，为多语言多模态标注打下基础。完成英文数据集的合成标注后，我们把大量数据翻译成 23 种语言。为避免翻译痕迹、在保持高精确答案的同时维持流畅的文本特质，我们又把翻译后的 prompt/generation 对与原始高质量合成样本比对复述，在真实数据集稀缺的地方扩大语言覆盖。这同时提升了语言流畅度与视觉-文本对齐，让 Aya Vision 在多种语言中表现出更优的图像理解。

我们的 8B 模型若仅用原始学术数据集做监督微调，在 AyaVisionBench 跨 23 种语言对多语言 VLM Pangea 7B 的胜率为 40.9%；而加入合成标注和多语言数据放大后，胜率达到 58.1%，提升 17.2 个百分点。这一显著改善展示了对多语言数据覆盖大力投入的影响力。

## 多模态模型合并

[![multimodal merging](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/aya-vision/image-10.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/aya-vision/image-10.png)

一个最先进的视觉语言模型不仅要精通图像理解，还要能在对话语境中胜任——模型需要对图像和文本输入都生成高质量响应。受此前关于模型合并（把多个训练好的模型 combine 起来的技术）研究的启发，我们把基础语言模型与微调后的视觉-语言模型合并。

模型合并增强了最终模型的生成能力，使 [AyaVisionBench](https://huggingface.co/datasets/CohereForAI/AyaVisionBench) 上跨 23 种语言对 Pangea 7B 的胜率达到 70%，比合并前的多模态胜率提升 11.9 个百分点。

多模态模型合并也让 Aya Vision 模型在纯文本任务上表现出色——在 mArenaHard 数据集上与领先视觉语言模型的对比可以证明。

## 扩展到 32B

最后，我们把配方从 8B 扩展到 32B，产出了最先进的开放权重多语言视觉语言模型——Aya Vision 32B。得益于文本骨干更强的初始化，其胜率显著提升，并超越了体积超过它 2 倍的模型，如 Llama-3.2 90B Vision、Molmo 72B 和 Qwen2.5-VL 72B：在 AyaVisionBench 上胜率 49% 到 63%，在 mWildVision 上跨 23 种语言平均胜率 52% 到 72%。

[![aya vision benchmark](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/aya-vision/aya-vision-bench.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/aya-vision/aya-vision-bench.png)

## Aya Vision Benchmark——多语言评估数据

随 Aya Vision 模型，我们还发布了一个高质量的多语言视觉-语言基准 [AyaVisionBench](https://huggingface.co/datasets/CohereForAI/AyaVisionBench)。它基于真实世界应用构建，覆盖 23 种语言、9 个不同任务类别，每种语言 135 个图像-问题对。

我们把这套评估集提供给研究社区，以推进多语言多模态评估。数据集旨在评估模型执行多样化视觉-语言任务的能力，包括图像描述、图表与图形理解、找出两张图的差异、通用视觉问答、OCR、文档理解、文本转录、涉及逻辑与数学的推理，以及把截图转换为代码。通过纳入多语言与多任务类型，数据集为评估跨语言与多模态理解提供了一个宽广且具挑战性的框架。

构建这个数据集时，我们首先从 [Cauldron](https://huggingface.co/datasets/HuggingFaceM4/the_cauldron) 的保留测试集中挑选图像——这是一个源自 50 个高质量数据集的大集合，确保训练期间从未见过这些图像。然后为每张图生成一个明确需要视觉上下文才能回答的问题。这些问题为合成生成，随后经过两阶段验证精炼：先由人类标注者审查并验证每个问题，确保其清晰、相关、且真正依赖图像。这种严格的挑选与验证流程保证数据集成为评估视觉语言模型在多语言与真实世界场景中的稳健基准。

## 为真实应用而生

交流发生在多种形态、多种语言之中。凭借领先的研发，我们发布了一个在 23 种语言中促成连接——无论是文本还是视觉——的模型。

Aya Vision 有广泛的实际应用，一个值得注意的例子是它[上线了 WhatsApp](https://cohere.com/research/aya/whatsapp)——世界上使用最广的通信平台之一。这让一个庞大的、说着各种语言的全球用户群体，能在自己每天沟通的平台上使用 Aya Vision 的能力。
