## 新功能

过去几个月，Hub 上的公开模型仓库从 1 万涨到超过 1.6 万个！致敬社区——大家与世界分享了这么多出色模型。除了数字，我们还有一大堆酷炫的新功能要介绍！

### Spaces Beta（[hf.co/spaces](https://huggingface.co/spaces)）

Spaces 是一个简单免费的方案，把机器学习 demo 应用直接托管在你的个人或组织 [hf.co](http://hf.co/) 主页上。我们支持两个很棒的 SDK，让你用 Python 轻松做出酷炫应用：[Gradio](https://gradio.app/) 和 [Streamlit](https://streamlit.io/)。几分钟就能部署一个应用并分享给社区！🚀

Spaces 支持[配置 secrets](https://huggingface.co/docs/hub/spaces-overview#managing-secrets)、允许[自定义 requirements](https://huggingface.co/docs/hub/spaces-dependencies)，甚至可以[直接从 GitHub 仓库管理](https://huggingface.co/docs/hub/spaces-github-actions)。可以在 [hf.co/spaces](https://huggingface.co/spaces) 注册加入 beta。以下是我们的一些心头好！

- 在 [Chef Transformer](https://huggingface.co/spaces/flax-community/chef-transformer) 的帮助下创作菜谱
- 用 [HuBERT](https://huggingface.co/spaces/osanseviero/HUBERT) 做语音转文本
- 用 [DINO 模型](https://huggingface.co/spaces/nateraw/dino-clips)在视频里做分割
- 用 [Paint Transformer](https://huggingface.co/spaces/akhaliq/PaintTransformer) 把一张画变成新画
- 或者干脆浏览现有 [100 多个 Spaces](https://huggingface.co/spaces)里的任意一个！

[![Landing page of Spaces](https://huggingface.co/blog/assets/27_summer_at_huggingface/spaces_landing.png)](https://huggingface.co/blog/assets/27_summer_at_huggingface/spaces_landing.png)

### TensorBoard 集成

六月下旬，我们为所有模型上线了 TensorBoard 集成。只要仓库里有 TensorBoard trace，就会自动为你启动一个免费的 TensorBoard 实例。公开和私有仓库都支持，任何产生 TensorBoard trace 的库都适用！

[![Image of a TensorBoard Instance](https://huggingface.co/blog/assets/27_summer_at_huggingface/tensorboard.png)](https://huggingface.co/blog/assets/27_summer_at_huggingface/tensorboard.png)

### 指标

七月，我们加入了在模型仓库列出评估指标的能力——把它们写进模型卡📈。只要在模型卡的 `model-index` 部分添加评估指标，它就会在你的模型仓库里醒目地展示。

[![Evaluation Metrics](https://huggingface.co/blog/assets/27_summer_at_huggingface/metrics.png)](https://huggingface.co/blog/assets/27_summer_at_huggingface/metrics.png)

这还不够——这些指标会自动关联到对应的 [Papers With Code](https://paperswithcode.com/) 排行榜。也就是说，你一旦把模型分享到 Hub，就能把自己的结果与社区其他模型并排对比。💪

看看[这个仓库](https://huggingface.co/nateraw/vit-base-beans-demo)的例子，仔细读它[模型卡](https://huggingface.co/nateraw/vit-base-beans-demo/blob/main/README.md#L12-L25)的 `model-index` 部分，学学怎么自己配置，并在 Papers with Code 上[自动](https://paperswithcode.com/sota/image-classification-on-beans)找到指标。

### 新 Widget

Hub 有 18 个 widget，让用户直接在浏览器里试用模型。

随着我们最新集成 Sentence Transformers，我们又加了两个新 widget：特征提取和句子相似度。

最新的**音频分类**widget 支持很多酷炫用例：语种识别、[街声检测](https://huggingface.co/speechbrain/urbansound8k_ecapa) 🚨、[命令识别](https://huggingface.co/speechbrain/google_speech_command_xvector)、[说话人识别](https://huggingface.co/speechbrain/spkrec-xvect-voxceleb)等等！今天就能用 `transformers` 和 `speechbrain` 模型体验🔊（小心，试某些模型时你可能需要大声吼出来）

我们的[结构化数据分类](https://huggingface.co/julien-c/wine-quality)早期 demo 配合 Scikit-learn 也能体验。最后我们还为图像模型加了新 widget：**文生图**、**图像分类**、**目标检测**。来试试用 Google 的 ViT 模型做图像分类（[这里](https://huggingface.co/google/vit-base-patch16-224)），用 Facebook AI 的 DETR 做目标检测（[这里](https://huggingface.co/facebook/detr-resnet-50)）！

### JAX/FLAX Sprint

七月，我们举办了史上最大的[社区活动](https://discuss.huggingface.co/t/open-to-the-community-community-week-using-jax-flax-for-nlp-cv/7104)，近 800 人参加！这场与 JAX/Flax 和 Google Cloud 团队联合组织的活动，通过提供免费 TPUv3，把计算密集的 NLP、计算机视觉和语音项目开放给了更广泛的工程师和研究者。参与者创建了 170 多个模型、22 个数据集、38 个 Spaces demo 🤯。所有精彩 demo 和项目可在[这里](https://huggingface.co/flax-community)浏览。

活动围绕 JAX/Flax、Transformers、大规模语言建模等主题做了分享，全部录播[在此](https://github.com/huggingface/transformers/tree/master/examples/research_projects/jax-projects#talks)。

我们非常激动地分享 3 支获胜队伍的作品！

- [Dall-e mini](https://huggingface.co/spaces/flax-community/dalle-mini)。DALL·E mini 是一个能用你给的任意提示词生成图像的模型！它比原版 DALL·E 小 27 倍，结果依然惊艳。  [![Image generated of an avocado in space](https://huggingface.co/blog/assets/27_summer_at_huggingface/dalle.png)](https://huggingface.co/blog/assets/27_summer_at_huggingface/dalle.png)
- [DietNerf](https://huggingface.co/spaces/flax-community/DietNerf-Demo)。DietNerf 是一个 3D 神经视图合成模型，面向少样本 3D 场景重建、用 2D 视图学习。这是论文 "Putting Nerf on a Diet"（[链接](https://arxiv.org/abs/2104.00677)）的第一个开源实现。  [![Generated 3D object with NeRF](https://huggingface.co/blog/assets/27_summer_at_huggingface/diet_nerf.png)](https://huggingface.co/blog/assets/27_summer_at_huggingface/diet_nerf.png)
- [CLIP RSIC](https://huggingface.co/spaces/sujitpal/clip-rsicd-demo)。CLIP RSIC 是在遥感图像数据上微调的 CLIP 模型，实现零样本卫星图像分类和描述生成。这个项目展示了微调 CLIP 模型在专业领域的威力。  [![CLIP search](https://huggingface.co/blog/assets/27_summer_at_huggingface/clip.png)](https://huggingface.co/blog/assets/27_summer_at_huggingface/clip.png)

除了这些很酷的项目，社区活动让多语种的超大模型、多模态模型训练成为可能，同样令人兴奋。例如，一些低资源语言第一次有了开源大 LM，如[斯瓦希里语](https://huggingface.co/models?language=sw)、[波兰语](https://huggingface.co/flax-community/papuGaPT2)和[马拉地语](https://huggingface.co/spaces/flax-community/roberta-base-mr)。

## 开源

### Transformers 新动态

这个夏天对 🤗 Transformers 是令人振奋的夏天：库达到 50,000 star、累计下载 3000 万次、贡献者接近 1000 人！🤩

有什么新东西？JAX/Flax 现在是第三个支持框架，Hub 上有超过 [5000](https://huggingface.co/models?library=jax&sort=downloads) 个模型！你可以找到持续维护的、面向文本分类等不同任务的[示例](https://github.com/huggingface/transformers/tree/master/examples/flax)。我们也在大力改进 TensorFlow 支持：所有[示例](https://github.com/huggingface/transformers/tree/master/examples/tensorflow)都被重写得更加稳健、更符合 TensorFlow 习惯、更清晰，包括摘要、翻译、命名实体识别等示例。

现在可以轻易把你的模型发布到 Hub，包括自动生成模型卡、评估指标和 TensorBoard 实例。借助新的 [`transformers.onnx` 模块](https://huggingface.co/transformers/serialization.html?highlight=onnx)，导出 ONNX 模型的支持也更强了。

```
python -m transformers.onnx --model=bert-base-cased onnx/bert-base-cased/
```

最近 4 个版本带来了许多酷炫新模型！

- [DETR](https://huggingface.co/transformers/model_doc/detr.html) 可以做快速端到端目标检测和图像分割。社区[教程](https://github.com/NielsRogge/Transformers-Tutorials/tree/master/DETR)值得一看！

[![DETR image](https://huggingface.co/blog/assets/27_summer_at_huggingface/detr.png)](https://huggingface.co/blog/assets/27_summer_at_huggingface/detr.png)

- [ByT5](https://huggingface.co/transformers/model_doc/byt5.html) 是 Hub 上第一个无分词器模型！所有可用 checkpoint 在[这里](https://huggingface.co/models?search=byt5)。
- [CANINE](https://huggingface.co/transformers/model_doc/canine.html) 是 Google AI 的又一个无分词器模型（纯编码器），直接在字符级工作。全部（多语言）checkpoint 在[这里](https://huggingface.co/models?search=canine)。
- [HuBERT](https://huggingface.co/transformers/model_doc/hubert.html?highlight=hubert) 在下游音频任务上有激动人心的结果，比如[命令分类](https://huggingface.co/superb/hubert-base-superb-ks)和[情感识别](https://huggingface.co/superb/hubert-base-superb-er)。模型在[这里](https://huggingface.co/models?filter=hubert)。
- [LayoutLMv2](https://huggingface.co/transformers/model_doc/layoutlmv2.html) 和 [LayoutXLM](https://huggingface.co/transformers/model_doc/layoutxlm.html?highlight=layoutxlm) 是两款令人惊叹的模型，能结合文本、版面和视觉信息解析文档图像（如 PDF）。我们做了个 [Space demo](https://huggingface.co/spaces/nielsr/LayoutLMv2-FUNSD) 让你直接体验！demo notebook 在[这里](https://github.com/NielsRogge/Transformers-Tutorials/tree/master/LayoutLMv2)。

[![LayoutLM object detection](https://huggingface.co/blog/assets/27_summer_at_huggingface/layout.png)](https://huggingface.co/blog/assets/27_summer_at_huggingface/layout.png)

- [BEiT](https://huggingface.co/transformers/model_doc/beit.html) 来自微软研究院，让自监督 Vision Transformer 超越了有监督训练，其预训练目标巧妙借鉴了 BERT。
- [RemBERT](https://huggingface.co/transformers/model_doc/rembert.html?)，一个大规模多语言 Transformer，在 zero-shot 迁移上超过 XLM-R（以及参数规模相近的 mT5）。
- [Splinter](https://huggingface.co/transformers/model_doc/splinter.html)，可用于少样本问答。只给 128 个样本，Splinter 就能在 SQuAD 上达到约 73% F1，比基于 MLM 的模型高 24 个点！

Hub 现在集成进了 `transformers`：不离开 Python 运行时就能推送配置、模型和分词器文件到 Hub！`Trainer` 现在每次保存 checkpoint 时都可以直接推送到 Hub：

[![Saving a checkpoint](https://huggingface.co/blog/assets/27_summer_at_huggingface/save_checkpoint.png)](https://huggingface.co/blog/assets/27_summer_at_huggingface/save_checkpoint.png)

### Datasets 新动态

多亏社区的一切给力贡献，[https://huggingface.co/datasets](https://huggingface.co/datasets) 上已有 1400 个公开数据集。💯

`datasets` 的支持面持续扩大：可用于 JAX、处理 parquet 文件、使用远程文件，并在自动语音识别、图像分类等领域获得更广支持。

用户也可以直接把数据集托管并与社区分享——把数据文件上传到 Dataset Hub 上的仓库即可。

[![Untitled](https://huggingface.co/blog/assets/27_summer_at_huggingface/streaming.png)](https://huggingface.co/blog/assets/27_summer_at_huggingface/streaming.png)

数据集方面有哪些亮点？微软的 CodeXGlue [数据集](https://huggingface.co/datasets?search=code_x_glue)覆盖多种编码任务（补全、生成、检索等）、C4 和 [MC4](https://huggingface.co/datasets/mc4) 这类超大数据集，还有 [RussianSuperGLUE](https://huggingface.co/datasets/russian_super_glue)、[DISFL-QA](https://huggingface.co/datasets/disfl_qa) 等等。

### 欢迎新库加入 Hub

除了对基于 `transformers` 的模型深度集成，Hub 也在与开源 ML 库建立良好伙伴，提供免费模型托管与版本管理。我们靠开源库 [huggingface_hub](https://github.com/huggingface/huggingface_hub) 和新的 Hub [文档](https://huggingface.co/docs/hub/main)来实现这一点。

所有 spaCy 官方 pipeline 现在都能在 spaCy 官方[组织页](https://huggingface.co/spacy)找到，任何用户都能用一条命令 `python -m spacy huggingface-hub` 分享自己的 pipeline。详情见 [https://huggingface.co/blog/spacy](https://huggingface.co/blog/spacy)。所有 spaCy 官方模型都可以直接在 Hub 的 demo [Space](https://huggingface.co/spaces/spacy/pipeline-visualizer) 里试用！

[![spaCy NER example](https://huggingface.co/blog/assets/27_summer_at_huggingface/spacy_ner.jpeg)](https://huggingface.co/blog/assets/27_summer_at_huggingface/spacy_ner.jpeg)

另一个令人兴奋的集成是 Sentence Transformers。详情见[发布博客](https://huggingface.co/blog/sentence-transformers-in-the-hub)：Hub 上有 200 多个[模型](https://huggingface.co/models?library=sentence-transformers)，能轻松与社区分享你的模型，也能复用社区的模型。

还不止！Hub 上现在有 100 多个 Adapter Transformers；Speechbrain 模型也能通过浏览器里的 widget 试用，做音频分类等不同任务。想深入了解我们与更多 ML 库集成到 Hub 的合作，见[这里](https://huggingface.co/docs/hub/libraries)。

## 解决方案

### **即将推出：Infinity**

Transformers 延迟低到 1 毫秒？🤯🤯🤯

我们打磨了一套非常利落的方案，为前沿 Transformer 模型带来无人能及的效率，供企业在自己的基础设施中部署。

- Infinity 以单一容器交付，可以部署在任何生产环境。
- BERT 类模型在 GPU 上可实现 1ms 延迟，CPU 上 4-10ms 🤯🤯🤯
- Infinity 满足最高安全要求，无需互联网访问即可集成进你的系统，进出流量完全由你掌控。

⚠️ 欢迎参加 [9 月 28 日的直播发布与演示](https://app.livestorm.co/hugging-face/hugging-face-infinity-launch?type=detailed)，届时 Infinity 将首次公开亮相！

### **新品：硬件加速**

Hugging Face 正[与 Intel、Qualcomm、GraphCore 等领先 AI 硬件加速器合作](http://hf.co/hardware)，让前沿的生产性能触手可及，并在 SOTA 硬件上扩展训练能力。作为这段旅程的第一步，我们[发布了新的开源库](https://huggingface.co/blog/hardware-partners-program)：🤗 Optimum——面向生产性能的训练与推理优化工具箱 🏎。详见[博客](https://huggingface.co/blog/graphcore)。

### **新品：SageMaker 推理**

我们与 AWS 达成了[新集成](https://huggingface.co/blog/deploy-hugging-face-models-easily-with-amazon-sagemaker)，让在 SageMaker 部署 🤗 Transformers 比以往更简单🔥。代码片段直接从 🤗 Hub 模型页上复制！在 [文档](https://huggingface.co/docs/sagemaker/inference)了解如何让 SageMaker 用上 transformers，或看这些[视频教程](https://youtube.com/playlist?list=PLo2EIpI_JMQtPhGR5Eo2Ab0_Vb89XfhDJ)。

有问题请到论坛提问：[https://discuss.huggingface.co/c/sagemaker/17](https://discuss.huggingface.co/c/sagemaker/17)

## 研究

在 BigScience，我们七月举办了自项目启动以来的首次线下活动 BigScience Episode #1。第二次活动 BigScience Episode #2 在 2021 年 9 月 20 日举行，有 BigScience 工作组的技术分享与进展汇报，以及 Jade Abbott（Masakhane）、Percy Liang（Stanford CRFM）、Stella Biderman（EleutherAI）等特邀讲者。我们在 Jean Zay 上完成了第一次大规模训练——一个仅英文的 13B 解码器模型（详情[见这里](https://github.com/bigscience-workshop/bigscience/blob/master/train/tr1-13B-base/chronicles.md)），第二个模型的架构正在确定中。组织工作组已提交下半年算力预算申请：Jean Zay V100 共 2,500,000 GPU 小时。🚀

六月，我们与 Yandex 研究团队共享了合作成果：[DeDLOC](https://arxiv.org/abs/2106.10207)，一种协作训练大型神经网络的方法——不用 HPC 集群，而用各种唾手可得的资源，如 Google Colaboratory 或 Kaggle notebook、个人电脑或可抢占式 VM。依靠这个方法，我们靠 40 位志愿者训练出了孟加拉语模型 [sahajBERT](https://huggingface.co/neuropark/sahajBERT)！而且我们的模型能与前沿掰手腕——在 Soham 新闻文章分类数据集的下游分类任务上甚至[做到了最好](https://huggingface.co/neuropark/sahajBERT-NCC)。更多细节见这篇[博客](https://huggingface.co/blog/collaborative-training)。这条研究方向非常迷人，因为它可能让模型预训练（从财务角度看）更普惠。

六月，我们的论文 [How Many Data Points is a Prompt Worth?](https://arxiv.org/abs/2103.08493)（提示词值多少个数据点？）在 NAACL 获得最佳论文奖。论文统一和比较了传统微调与 prompting 两种适配预训练模型的路径，发现人类编写的提示词相当于新任务上千个监督数据点。也可以读它的[博客](https://huggingface.co/blog/how_many_data_points/)。

[![Prompt](https://huggingface.co/blog/assets/27_summer_at_huggingface/prompt.png)](https://huggingface.co/blog/assets/27_summer_at_huggingface/prompt.png)

我们期待今年的 EMNLP，我们有四篇论文被接收！

- 我们的论文 "[Datasets: A Community Library for Natural Language Processing](https://arxiv.org/abs/2109.02846)" 记录了拥有 300 多贡献者的 Hugging Face Datasets 项目。这个社区项目让研究者轻松访问数百个数据集，催生了跨数据集 NLP 的新用例，并在索引、大数据集流式读取等方面有先进特性。
- 我们与达姆施塔特工业大学的研究者合作的论文（["Avoiding Inference Heuristics in Few-shot Prompt-based Finetuning"](https://arxiv.org/abs/2109.04144)）也被接收。论文表明，prompt 微调的语言模型（在少样本设定下表现强劲）仍然会学表面启发式（所谓*数据集偏置*），而 zero-shot 模型不会踩这个坑。
- 我们的投稿 "[Block Pruning For Faster Transformers](https://arxiv.org/abs/2109.04838v1)" 也被接收为长文。论文展示如何用块稀疏同时获得又快又小的 Transformer。实验中，SQuAD 上的模型比 BERT 快 2.4 倍、小 74%。
