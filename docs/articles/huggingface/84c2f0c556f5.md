# 推出 Open Ko-LLM 排行榜：引领韩国 LLM 评估生态

在大语言模型（LLM）快速演进的格局中，构建一个「生态」从未像今天这样重要。这一趋势在多个重大进展中清晰可见，比如 Hugging Face 推动 NLP 大众化，以及 Upstage 构建生成式 AI 生态。

受这些行业里程碑启发，2023 年 9 月，我们在 [Upstage](https://upstage.ai/) 发起了 [Open Ko-LLM Leaderboard](https://huggingface.co/spaces/upstage/open-ko-llm-leaderboard)。我们的目标是快速开发并引入一个面向韩语 LLM 数据的评估生态，与全球开放、协作的 AI 开发浪潮对齐。

Open Ko-LLM Leaderboard 的愿景是培育一个有活力的韩语 LLM 评估生态，通过让研究者分享结果、发掘 LLM 领域被埋没的才能来促进透明。说到底，我们在努力为韩语 LLM 扩大竞技舞台。为此，我们搭建了一个开放平台，个人可以注册自己的韩语 LLM、与其他模型同台竞技。我们还想做一个能捕捉韩语独特特征与文化的排行榜——为了这个目标，我们确保 Ko-MMLU 这类翻译基准数据集能体现韩语的独特属性。

## 排行榜的设计选择：为公平新建私有测试集

Open Ko-LLM Leaderboard 的独特基准方式是其标志，具体：

- 采用韩语数据集，而非普遍使用的英语基准。
- 不公开测试集——与多数排行榜公开测试集相反：我们决定为 Open Ko-LLM 全新构建数据集并保持私有，以防止测试集污染、确保更公平的比较框架。

我们承认开放基准能为研究社区带来更广泛的影响和实用性，但选择封闭测试集环境，是出于营造更可控、更公平的比较分析之用意。

## 评估任务

Open Ko-LLM Leaderboard 采用以下五种评估方法：

- **Ko-ARC**（AI2 Reasoning Challenge）：Ko-ARC 是评估科学思维与理解的多选题测试，衡量解决科学问题所需的推理能力，考察复杂推理、问题求解技能和科学知识理解。评估指标关注准确率，反映模型从选项中选对答案的频率，从而衡量其驾驭并运用科学原理的能力。
- **Ko-HellaSwag**：Ko-HellaSwag 以生成式或多选式设置评估情境理解与预测能力，测试给定情境下预测最可能后续场景的能力，是模型对情境理解与推理能力的指标。指标为评估预测质量的准确率，具体取决于采用多选还是生成方式来测。
- **Ko-MMLU**（Massive Multitask Language Understanding）：Ko-MMLU 以多选形式评估覆盖广泛主题和领域的语言理解能力。这种宽覆盖测试展示模型在各领域的表现，凸显其语言理解的广度与深度。关键指标是各任务总体准确率和分领域表现，指出不同知识域的强弱项。
- **Ko-Truthful QA**：Ko-Truthful QA 实际是评估模型真实性与事实准确性的多选基准。不同于自由生成回答的生成式格式，在多选设置中，模型要从一组选项里选出最准确、最真实的回答。这种方式强调模型在受约束选择框架内辨别真实与准确的能力。其主要指标关注模型选择的准确性，衡量其与已知事实的一致性以及从给定选项中识别最真实回答的能力。
- **Ko-CommonGEN V2**：为 Open Ko-LLM Leaderboard 新做的基准，评估 LLM 在给定条件下能否产出符合韩国常识的输出，考察模型用韩语产出语境与文化相关输出的能力。

## 排行榜实况：Ko-LLM 的气压计

Open Ko-LLM Leaderboard 超出了预期，提交模型数已超 1,000。作为对照，原版英文 Open LLM Leaderboard 目前收录 4,000 多个模型，Ko-LLM 排行榜上线仅五个月就达到了其四分之一。我们感谢这样广泛的参与——它展示了韩语 LLM 开发的火热兴趣。

尤其值得注意的是比赛的多元：个人研究者、企业、学术机构同场竞技，包括 KT、Lotte Information & Communication、Yanolja、MegaStudy Maum AI、42Maru、韩国电子通信研究院（ETRI）、KAIST 和高丽大学。其中一个出色的提交是 KT 的 [Mi:dm 7B 模型](https://huggingface.co/KT-AI/midm-bitext-S-7B-inst-v1)——它不仅登顶 7B 及以下参数模型，还开放了公众使用，意义非凡。

我们还观察到，更普遍地，两类模型在排行榜上表现强劲：

- 经过跨语言迁移或韩语微调的模型（如 Upstage 的 [SOLAR](https://huggingface.co/upstage/SOLAR-10.7B-v1.0)）
- 从 LLaMa2、Yi、Mistral 微调而来的模型——印证了依托扎实基础模型做微调的重要性。

管理这么大的排行榜并非没有挑战。Open Ko-LLM Leaderboard 力求与 Open LLM Leaderboard 的理念紧密对齐，尤其在与 Hugging Face 模型生态的整合上。这一策略让排行榜门槛低、易于参加——这是其运转的关键因素。不过基础设施存在限制：整个排行榜依赖 16 块 A100 80GB GPU。这套配置在跑超过 300 亿参数的模型时很吃力，因为它们需要过多算力，导致大量提交长时间停在 pending 状态。解决这些基础设施问题是 Open Ko-LLM Leaderboard 未来改进的重中之重。

## 我们的愿景与下一步

放在真实环境中审视，我们认识到当前排行榜模式存在若干局限：

- **数据过时**：SQUAD、KLEU 这类数据集会随时间过时。数据持续演进变化，而现有排行榜固定在某一时点，随着每天新增数百条数据，它们越来越不能反映当下。
- **无法反映真实世界**：在 B2B 和 B2C 服务中，数据不断来自用户或行业积累，边角案例和异常值持续出现。真正的竞争优势在于对这些情况响应得好，而当前排行榜系统没有度量这种能力的手段。真实世界的数据永远在生成、变化、演进。
- **比赛的正当性存疑**：许多模型专门针对测试集调优以获得好成绩，可能造成测试集内部的另一种过拟合。因此当前排行榜系统是「排行榜中心」而非「真实世界中心」的。

所以我们计划进一步发展排行榜，让它解决这些问题，成为一个被广泛认可的可靠资源。通过纳入一批与真实用例强相关的基准，我们希望让排行榜不仅更相关，而且对企业真正有用。我们立志弥合学术研究与实际应用之间的鸿沟，将持续更新和增强排行榜，吸收研究社区和行业从业者的双方反馈，确保基准严谨、全面、常新。通过这些努力，我们希望对该领域的进步有所贡献——提供一个准确度量并推动 LLM 解决现实、有影响力问题的平台。

如果你在做数据集并希望与我们合作，我们很乐意交流。可以联系 [chanjun.park@upstage.ai](mailto:chanjun.park@upstage.ai) 或 [contact@upstage.ai](mailto:contact@upstage.ai)！

顺带一提，我们认为真实在线环境下的评估——相比基于基准的评估——非常有意义。即便在基于基准的评估之内，基准也需要每月更新，或更具体地考察领域特定方面——我们鼓励这样的倡议。
