# Hugging Face 与 IBM 围绕 watsonx.ai 达成合作——面向 AI 构建者的新一代企业级工作室

抛开所有炒作，AI 正在对社会和企业产生深远影响，这一点难以否认。从初创公司到大企业再到公共部门，我们接触的每一位客户都在积极试验大语言模型和生成式 AI，识别最有前景的用例，并逐步把它们投入生产。

我们收到客户的第一大反馈是：不会有单一模型统治一切。他们理解「为每个用例构建最合适的模型」的价值——既最大化模型在企业数据上的相关性，又优化算力预算。当然，隐私和知识产权同样是首要关切，客户希望确保自己保持完全的控制权。

随着 AI 进入每个部门和业务单元，客户也意识到需要训练和部署大量不同的模型。在一家大型跨国组织中，这可能意味着任意时刻都要运行数百甚至数千个模型。考虑到 AI 创新的速度，更新的、更高性能的模型架构也会促使客户比预期更快地替换模型，进一步强化了快速、无缝地在生产中训练和部署新模型的需求。

这一切只有在标准化和自动化的前提下才会发生。组织负担不起为每个新项目从零构建模型、工具和基础设施。幸运的是，过去几年出现了一些非常积极的发展：

- **模型标准化**：[Transformer](https://arxiv.org/abs/1706.03762) 架构如今已是自然语言处理、计算机视觉、音频、语音等深度学习应用的事实标准。构建在多种用例上都表现良好的工具和工作流变得更简单。
- **预训练模型**：[数十万个](https://huggingface.co/models)预训练模型近在咫尺。你可以直接在 [Hugging Face](https://huggingface.co) 上发现和测试它们，并快速筛选出有前景的模型用于项目。
- **开源库**：Hugging Face 的[库](https://huggingface.co/docs)让你用一行代码下载预训练模型，几分钟内就能用自己的数据开始实验。从训练到部署再到硬件优化，客户可以依赖一套一致的、社区驱动的工具，它们从笔记本到生产环境都有相同的表现。

此外，我们的云合作伙伴关系让客户可以在任意规模上使用 Hugging Face 的模型和库，而不必担心基础设施采购和技术环境搭建。这让高质量模型的快速交付容易得多，无需重复造轮子。

继与 AWS 在 Amazon SageMaker、微软在 Azure Machine Learning 上的合作之后，我们非常激动能与 IBM 在其全新 AI 工作室 [watsonx.ai](https://www.ibm.com/products/watsonx-ai) 上合作。[watsonx.ai](http://watsonx.ai) 是新一代企业级工作室，供 AI 构建者训练、验证、微调和部署传统 ML 以及由基础模型驱动的新生成式 AI 能力。

IBM 决定把开源作为 watsonx.ai 的核心，我们完全同意！watsonx.ai 构建在 [RedHat OpenShift](https://www.redhat.com/en/technologies/cloud-computing/openshift) 之上，将同时提供云和本地部署版本。这对那些因严格合规规则无法使用云、或更习惯在自有基础设施上处理机密数据的客户是天大的好消息。过去，这类客户往往不得不自建 ML 平台；现在他们有了一个开源、即插即用的替代方案，并且可以用标准 DevOps 工具进行部署和管理。

在底层，watsonx.ai 还集成了许多 Hugging Face 开源库，例如 [transformers](https://github.com/huggingface/transformers)（GitHub 星标 10 万+！）、[accelerate](https://github.com/huggingface/accelerate)、[peft](https://github.com/huggingface/peft)，以及我们的 [Text Generation Inference](https://github.com/huggingface/text-generation-inference) 服务器等。我们很高兴与 IBM 合作，共同打造 watsonx AI 与数据平台，让 Hugging Face 客户能原生地使用自己的 Hugging Face 模型和数据集，成倍放大 AI 在业务中的影响。

此外，IBM 也开发了自有的大语言模型系列，我们将与其团队合作，把这些模型开源并让它们轻松地提供在 Hugging Face Hub 上。

了解更多，请观看 IBM Research 高级副总裁兼主任 Darío Gil 博士与我们 CEO Clem Delangue 在 IBM THINK 2023 主题演讲中[宣布我们的合作](https://youtu.be/FrDnPTPgEmk?t=1077)、[导览 watsonx 平台](https://youtu.be/FrDnPTPgEmk?t=283)并展示 IBM [大语言模型系列](https://youtu.be/FrDnPTPgEmk?t=586)的内容。

我们的联合团队目前正在紧张工作中。我们等不及要向大家展示成果了！科技界最具标志性的公司与一家势头强劲的新创企业联手进军企业 AI……谁能想到呢？

这是个令人着迷的时代。敬请期待！
