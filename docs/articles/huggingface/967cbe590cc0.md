# HuggingChat 推出社区工具（Community Tools）

今天我们在 HuggingChat 上发布最新功能：Community Tools（社区工具）！它可以把你在 HuggingFace 上喜欢的任意 Space，变成可以由 HuggingChat 中的模型直接调用的工具。

随着这个功能，我们也在扩展 HuggingChat 支持的模态。你现在可以用社区工具理解图像、生成视频，或用 text-to-speech 模型作答。可能性无穷无尽，任何人都能用 Hugging Face 上的 Spaces 创建工具！到[这里](https://huggingface.co/chat/tools)探索现有工具。

本文中我们将看几个创建社区工具的用例：

- [把社区 Space 变成工具](https://huggingface.co/blog/community-tools#turning-a-community-Space-into-a-tool)
- [自己创建自定义工具](https://huggingface.co/blog/community-tools#creating-a-custom-tool-yourself)
- [用社区工具增强你的助手](https://huggingface.co/blog/community-tools#enhance-your-assistants-with-community-tools)
- [基于你自己的文档创建 RAG 工具](https://huggingface.co/blog/community-tools#create-a-rag-tool-on-your-own-documents)

## 把社区 Space 变成工具

你可以把任何人的公开 Space 变成工具。这在直接使用最新模型时很方便。这里以 [DamarJati/FLUX.1-RealismLora](https://huggingface.co/spaces/DamarJati/FLUX.1-RealismLora) 为例。

先[创建一个新工具](https://huggingface.co/chat/tools/new)并填写各字段。一旦你把 Space URL 填入 *Hugging Face Space URL* 字段，可用的函数和参数就会自动填充。

有些字段需要正确填写，才能保证工具的最佳表现。

- **Tool Description（工具描述）：** 描述会传给 LLM，用于解释这个工具能做什么。保持简短，说明工具的用途。
- **AI Function Name（AI 函数名）：** 工具以代码函数的形式表示。这就是你的工具的函数名。保持简短、唯一、自解释。
- **Arguments（参数）：** 这些是 LLM 可以填写的工具参数。可以是：**Required（必填）：** 模型必须填入值才能使用该工具，这就要求把参数描述清楚。**Optional（可选）：** 提供了默认值，但模型可以在需要时覆盖。**Fixed（固定）：** 创建工具时值就固定，模型无法更改。

你随时可以查看其他工具的定义，更好地理解如何创建工具。[（示例）](https://huggingface.co/chat/tools/000000000000000000000001/edit)

工具创建好后，我们就能启用它，并开始配合支持工具的模型使用！

## **自己创建自定义工具**

利用现有 Spaces 能覆盖很多用例，但如果你会写基本的 Python，同样可以轻松为自己创建自定义工具。由于 LLM 自己很不擅长挑选随机数，我们做一个简单的掷骰子工具示例。

先在 Hugging Face 上[创建一个新的 Gradio Space](https://huggingface.co/new-space?sdk=gradio)。免费的 *CPU Basic* 档就够用。你的 Space 必须是公开的，才能在 HuggingChat 内使用。

在你的 space 仓库里创建一个简单的 [`app.py`](http://app.py) 应用，以掷骰子为例：

```
import gradio as gr
import random

def roll_dice(sides=6):
    return random.randint(1, sides)

demo = gr.Interface(
    fn=roll_dice,
    inputs=gr.Number(value=6, label="Number of Sides"),
    outputs="text",
    title="Dice Roller",
    description="Enter the number of sides for the dice and get the roll result."
)

demo.launch()
```

如果你不熟悉 Gradio——创建界面的上手非常容易，文档在[这里](https://www.gradio.app/docs/gradio/interface)。

> 你可以在单个 Space 里放多个函数，以便更轻松地管理你的工具。

完成后推送更改，等 Space 部署好，你就能像之前那样在 HuggingChat 中为它创建社区工具。

## 用社区工具增强你的助手

你可以直接前往[工具页面](https://huggingface.co/chat/tools)挑选喜欢的工具启用，也可以把工具打包进一个助手。

[创建助手](https://huggingface.co/chat/settings/assistants/new)时，如果使用支持工具调用的模型，现在会有选择工具的选项。搜索工具名称并最多添加 3 个不同的工具。在我们的例子里，创建一个能访问图像生成和掷骰子工具的 Game Master（游戏主持人）助手。

> 你可以使用系统指令字段来告诉模型何时使用这些工具。

## 基于你自己的文档创建 RAG 工具

配合本次发布，我们创建了一个简单的 RAG 工具，你可以轻松复制它，从而直接在 HuggingChat 中对自己的文档提问。先把[这个 Space](https://huggingface.co/spaces/nsarrazin/rag-tool-template)复制到你自己的账号。然后把你希望解析的文件放入该 Space 的 `sources/` 文件夹。

Space 启动后，你就能像前文所说，在 HuggingChat 中把它变成工具。
