# PaliGemma 2 Mix——Google 的新一代指令视觉语言模型

## TL;DR

去年 12 月，Google 发布了 PaliGemma 2：新的预训练（**pt**）PaliGemma 视觉语言模型（VLM）家族，基于 [SigLIP](https://huggingface.co/collections/google/siglip-659d5e62f0ae1a57ae0e83ba) 和 [Gemma 2](https://huggingface.co/collections/google/gemma-2-release-667d6600fd5220e7b967f315)。模型有三种尺寸（3B、10B、28B）和三种分辨率（224x224、448x448、896x896）。

今天，Google 发布 PaliGemma 2 **mix**：在多种视觉语言任务混合数据上微调，包括 OCR、长短字幕描述等。

PaliGemma 2 预训练（**pt**）变体是很适合*迁移*到手头任务的视觉语言模型。所有 **pt** checkpoint 都是为下游任务微调而生、也为此发布。

[![PaliGemma2 Architecture](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/paligemma/paligemma2_arch.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/paligemma/paligemma2_arch.png)

mix 模型能让你快速了解：把预训练 checkpoint 微调到下游任务大约能到什么水平。PaliGemma 模型家族的主要目的，是提供能在下游任务上学得更好的预训练模型，而不是做一个多面手聊天模型。Mix 模型给出的是一个很好的信号：**pt** 模型在一组学术数据集混合上微调后的表现如何。

> 关于 PaliGemma 2 的更多细节可阅读对应博客。

所有 mix 模型和 demo 都在[这个 collection](https://huggingface.co/collections/google/paligemma-2-mix-67ac6a251aaf3ee73679dcc4)中。

## PaliGemma 2 Mix 模型

PaliGemma 2 mix 模型能完成多种任务，可按子任务归类如下。

- **通用视觉-语言任务**：视觉问答、图像指代（referring）
- **文档理解**：信息图视觉问答、图表与示意图理解
- **图像中的文字识别**：文本检测、带文字图像的描述、对含文字图像的视觉问答
- **定位类任务**：目标检测、图像分割

> 注意这份子任务清单并不穷尽，完整任务列表见 PaliGemma 2 论文。

对 PaliGemma 2 mix 模型下提示时，可以使用**开放式提示词**。在上一代 PaliGemma 预训练模型上，我们需要按想要完成的任务在提示词前加任务前缀（依语言而定）。加前缀的方式仍然可用，但开放式提示词效果更好。带任务前缀的提示词形如：

- "caption {lang}"：漂亮的 COCO 风格短字幕
- "describe {lang}"：更长、更具描述性的字幕
- "ocr"：光学字符识别
- "answer {lang} {question}"：就图像内容问答
- "question {lang} {answer}"：根据给定答案生成问题

只有两个任务必须依赖任务前缀：目标检测和图像分割。提示词形如：

- "detect {object description}"：定位图像中列出的对象并返回其边界框
- "segment {object description}; {object description}"：定位对象在图像中占据的区域，生成该对象的图像分割

想立刻上手，可以直接跳到[本章节](https://huggingface.co/blog/paligemma2mix#inference-and-fine-tuning-using-transformers)，或试试[这个 demo](https://huggingface.co/spaces/google/paligemma2-10b-mix)。

## 用 Transformers 推理与微调

你可以用 transformers 使用 PaliGemma 2 mix 模型。

```
from transformers import (
    PaliGemmaProcessor,
    PaliGemmaForConditionalGeneration,
)
from transformers.image_utils import load_image
import torch

model_id = "google/paligemma2-10b-mix-224"

url = "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/tasks/car.jpg"
image = load_image(url)

# Load the model and the processor
model = PaliGemmaForConditionalGeneration.from_pretrained(model_id, torch_dtype=torch.bfloat16, device_map="auto").eval()
processor = PaliGemmaProcessor.from_pretrained(model_id)

# Prepare the inputs
prompt = "describe en"
model_inputs = processor(text=prompt, images=image, return_tensors="pt").to(torch.bfloat16).to(model.device)
input_len = model_inputs["input_ids"].shape[-1]

# Infer and postprocess the inference outputs
with torch.inference_mode():
    generation = model.generate(**model_inputs, max_new_tokens=100, do_sample=False)
    generation = generation[0][input_len:]
    decoded = processor.decode(generation, skip_special_tokens=True)
    print(decoded)
```

我们有一份[深入讲解微调 PaliGemma 2 的教程](https://github.com/merveenoyan/smol-vision/blob/main/Fine_tune_PaliGemma.ipynb)。同一个 notebook 也可以用来微调 mix checkpoint。
