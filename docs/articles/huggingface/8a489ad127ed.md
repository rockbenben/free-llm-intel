# 欢迎 spaCy 加入 Hugging Face Hub

[spaCy](https://github.com/explosion/spaCy) 是用于高级自然语言处理的流行库，在业界被广泛使用。spaCy 让命名实体识别、文本分类、词性标注等任务的 pipeline 易于使用和训练，并让你构建强大的应用来处理和分析海量文本。

Hugging Face 让你能非常轻松地把 spaCy pipeline 分享给社区！只需一条命令，你就能上传任意 pipeline 包，配有美观的 model card，所有必需元数据都会自动生成。推理 API 目前开箱支持 NER，你可以在浏览器中交互式地试用你的 pipeline。你还会获得一个包的实时 URL，可以在任何地方通过 `pip install` 安装它，从原型到生产一路顺畅！

### 查找模型

超过 60 个官方模型可以在 [spaCy](https://hf.co/spacy) 组织下找到。这些模型来自[最新的 3.1 版本](https://explosion.ai/blog/spacy-v3-1)，你现在就可以试用最新发布的模型！此外，你可以在这里找到所有来自社区的 spaCy 模型：[https://huggingface.co/models?filter=spacy](https://huggingface.co/models?filter=spacy)。

### Widgets

这次集成包含对 NER widget 的支持，因此所有带 NER 组件的模型都开箱即用地拥有该功能！文本分类和 POS 的支持也即将推出。

### 使用现有模型

Hub 上的所有模型都可以直接用 `pip install` 安装。

```
pip install https://huggingface.co/spacy/en_core_web_sm/resolve/main/en_core_web_sm-any-py3-none-any.whl
```

```
# Using spacy.load().
import spacy
nlp = spacy.load("en_core_web_sm")

# Importing as module.
import en_core_web_sm
nlp = en_core_web_sm.load()
```

打开仓库时，你可以点击 `Use in spaCy`，就会得到一个可用的代码片段，用来安装并加载模型！

[![snippet](https://huggingface.co/blog/assets/23_spacy/snippet.png)](https://huggingface.co/blog/assets/23_spacy/snippet.png) [![snippet](https://huggingface.co/blog/assets/23_spacy/snippet2.png)](https://huggingface.co/blog/assets/23_spacy/snippet2.png)

你甚至可以向 Inference API 发送 HTTP 请求来调用模型，这在对生产环境很有用。下面是一个简单请求的例子：

```
curl -X POST  --data '{"inputs": "Hello, this is Omar"}' https://api-inference.huggingface.co/models/spacy/en_core_web_sm
>>> [{"entity_group":"PERSON","word":"Omar","start":15,"end":19,"score":1.0}]
```

对于更大规模的使用场景，可以点击 "Deploy > Accelerated Inference"，查看如何用 Python 实现这一点。

### 分享你的模型

不过最酷的可能是：现在你可以用 `spacy-huggingface-hub` [库](https://github.com/explosion/spacy-huggingface-hub)非常轻松地与社区分享你的模型。该库为 `spaCy` CLI 扩展了一个新命令 `huggingface-hub push`。

```
huggingface-cli login
python -m spacy package ./en_ner_fashion ./output --build wheel
cd ./output/en_ner_fashion-0.0.0/dist
python -m spacy huggingface-hub push en_ner_fashion-0.0.0-py3-none-any.whl
```

一分钟内，你就能把打包好的模型放上 Hub，直接在浏览器中试用，并与社区其余成员分享。所有必需的元数据都会替你上传，甚至还附带一张漂亮的 model card。

快来试试，把你的模型分享给社区吧！

## 想把你的库集成到 Hub 吗？

这次集成得益于 [`huggingface_hub`](https://github.com/huggingface/huggingface_hub) 库，它内置了我们所有的 widget 以及所有被支持库的 API。如果你想把自己的库集成到 Hub，我们有为你准备的[指南](https://huggingface.co/docs/hub/models-adding-libraries)！
