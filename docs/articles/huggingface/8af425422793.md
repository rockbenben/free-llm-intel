# LLM 性能对比：用 LoRA 在灾难推文分析任务上深入评测 Roberta、Llama 2 与 Mistral

本文另有中文版本 [简体中文](https://huggingface.co/blog/zh/Lora-for-sequence-classification-with-Roberta-Llama-Mistral)。

## 引言

在快速演变的自然语言处理（NLP）领域，我们经常需要对比不同的语言模型，看哪个模型在特定任务上表现最好。这篇博客文章对比了三个模型：RoBERTa、Mistral-7b 和 Llama-2-7b，我们用它们来应对一个常见问题——对灾难相关推文进行分类。需要说明的是，Mistral 和 Llama 2 是拥有 70 亿参数的大模型；相比之下，RoBERTa-large（355M 参数）是相对较小的模型，在本对比研究中作为基线使用。

在本文中，我们使用了 PEFT（参数高效微调）技术：LoRA（Large Language Models 的低秩适配），在序列分类任务上微调预训练模型。LoRA 的设计目标是在大幅减少可训练参数数量的同时，保持较强的下游任务性能。

本篇博客的主要目标是：使用 Hugging Face 上的三个预训练模型——[meta-llama/Llama-2-7b-hf](https://huggingface.co/meta-llama/Llama-2-7b-chat-hf)、[mistralai/Mistral-7B-v0.1](https://huggingface.co/mistralai/Mistral-7B-v0.1) 和 [roberta-large](https://huggingface.co/roberta-large)——实现面向序列分类任务的 LoRA 微调。

## 预训练模型

### RoBERTa

RoBERTa（Robustly Optimized BERT Approach）是 Meta AI 研究团队提出的 BERT 模型的进阶变体。BERT 是基于 transformer 的语言模型，使用自注意力机制获取上下文词表示，并以掩码语言模型目标进行训练。注意 BERT 是仅编码器（encoder-only）模型，用于自然语言理解任务（如序列分类和 token 分类）。

RoBERTa 是一个常用于微调的模型，适合作为我们实验的基线。更多信息可查看 Hugging Face 上的模型[卡片](https://huggingface.co/docs/transformers/model_doc/roberta)。

### Llama 2

Llama 2 系列模型（Large Language Model Meta AI）属于 Meta AI 推出的大语言模型（LLM）家族。Llama 2 模型大小不一，参数规模从 70 亿到 650 亿不等。

Llama 2 是自回归语言模型，基于 transformer 解码器架构。生成文本时，Llama 2 将词序列作为输入，使用滑动窗口迭代预测下一个 token。Llama 2 的架构与 GPT-3 等模型略有不同：例如，Llama 2 采用 SwiGLU 激活函数而非 ReLU，并使用旋转位置编码（RoPE）代替绝对可学习位置编码。

近期发布的 Llama 2 引入了架构上的改进，通过把上下文长度扩展到最多 4096 个 token、并使用分组查询注意力（GQA）解码，更好地利用超长序列。

### Mistral 7B

Mistral 7B v0.1 拥有 73 亿参数，是 Mistral AI 推出的首个 LLM。Mistral 7B 架构中采用的主要新技术有：

- 滑动窗口注意力（Sliding Window Attention）：用基于滑动窗口的注意力取代全注意力（平方级计算开销），每个 token 最多可以关注上一层的 4,096 个 token（线性计算开销）。这一机制使 Mistral 7B 能够处理更长的序列，高层可以访问超出 4,096 token 窗口范围的历史信息。
- 分组查询注意力（Grouped-query Attention）：Llama 2 也使用了该技术，通过缓存序列中已解码 token 的 key 和 value 向量来优化推理过程（缩短处理时间）。

## LoRA

PEFT（Parameter Efficient Fine-Tuning，参数高效微调）是一系列技术的集合（p-tuning、prefix-tuning、IA3、Adapters 和 LoRA），旨在用少得多的训练参数微调大模型，同时保持全量微调通常可达的性能水平。

LoRA（Low-Rank Adaptation，低秩适配）是一种与 Adapter 层类似的 PEFT 方法，其主要目标是减少模型的可训练参数。LoRA 的运作方式是冻结预训练权重，仅学习一个低秩更新矩阵。

## 配置 Trainer

### 评估指标

首先定义用于对比三个模型的性能指标：F1 分数、召回率、精确率和准确率：

```
import evaluate
import numpy as np

def compute_metrics(eval_pred):
    # All metrics are already predefined in the HF `evaluate` package
    precision_metric = evaluate.load("precision")
    recall_metric = evaluate.load("recall")
    f1_metric= evaluate.load("f1")
    accuracy_metric = evaluate.load("accuracy")

    logits, labels = eval_pred # eval_pred is the tuple of predictions and labels returned by the model
    predictions = np.argmax(logits, axis=-1)
    precision = precision_metric.compute(predictions=predictions, references=labels)["precision"]
    recall = recall_metric.compute(predictions=predictions, references=labels)["recall"]
    f1 = f1_metric.compute(predictions=predictions, references=labels)["f1"]
    accuracy = accuracy_metric.compute(predictions=predictions, references=labels)["accuracy"]
    # The trainer is expecting a dictionary where the keys are the metrics names and the values are the scores. 
    return {"precision": precision, "recall": recall, "f1-score": f1, 'accuracy': accuracy}
```

### 支持加权损失的自定义 Trainer

如文章开头所述，正负类别的分布不均衡。我们需要用加权交叉熵损失训练模型来应对这一点。而 `Trainer` 类不支持传入自定义损失，因为它期望直接从模型输出中获得损失。

因此需要定义自定义的 `WeightedCELossTrainer`，重写 `compute_loss` 方法，基于模型预测和输入标签计算加权交叉熵损失：

```
from transformers import Trainer

class WeightedCELossTrainer(Trainer):
    def compute_loss(self, model, inputs, return_outputs=False):
        labels = inputs.pop("labels")
        # Get model's predictions
        outputs = model(**inputs)
        logits = outputs.get("logits")
        # Compute custom loss
        loss_fct = torch.nn.CrossEntropyLoss(weight=torch.tensor([neg_weights, pos_weights], device=model.device, dtype=logits.dtype))
        loss = loss_fct(logits.view(-1, self.model.config.num_labels), labels.view(-1))
        return (loss, outputs) if return_outputs else loss
```

## 结论

在这篇博客中，我们使用 LoRA 对比了三个大语言模型（LLM）——RoBERTa、Mistral 7b 和 Llama 2——在灾难推文分类任务上的性能。从性能结果看，RoBERTa 大幅领先 Mistral 7B 和 Llama 2。这引出了一个思考：对于短序列二分类这样的任务，我们真的需要复杂的大模型吗？

从这项研究中可以得出的一个经验是：选择 LLM 时应考虑具体的项目需求、可用资源和性能要求。

此外，对于相对*简单*的短序列预测任务，RoBERTa 这类基础模型依然具有竞争力。

最后，我们展示了 LoRA 方法既可以应用于编码器模型（RoBERTa），也可以应用于解码器模型（Llama 2 和 Mistral 7B）。
