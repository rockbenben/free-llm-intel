# 迈向多模态：Prezi 如何利用 Hub 与专家支持计划加速其 ML 路线图

人人都知道，一幅出色的视觉作品抵得上一千句话。视觉传达软件公司 Prezi 的团队正在把这一洞见付诸实践——他们的 Prezi 演示文稿把图像与文本融合成高度动态的展示。

Prezi 加入了 Hugging Face 专家支持计划（Expert Support Program），以充分发挥现代机器学习的潜力。过去几个月里，Hugging Face 支持 Prezi 把更小、更高效的开源模型集成到其 ML 工作流中。这次合作恰逢其时，因为多模态模型正变得越来越强大。

我们最近与 [Prezi](https://prezi.com/) 的后端工程师 [Máté Börcsök](https://www.linkedin.com/in/mateborcsok/?originalSubdomain=hu) 坐下来聊了聊他们在[专家支持计划](https://huggingface.co/support)中的体验。在这段短视频中，Máté 带我们了解了他们的一些机器学习工作，并分享了与我们团队通过专家支持计划协作的体验。

*如果你想像 Máté 和他的团队一样，在我们的专家帮助下加速你的机器学习路线图，请访问 [hf.co/support](https://huggingface.co/support) 了解专家支持计划并申请报价。*

## 文字稿与补充细节：

### 自我介绍

我叫 Máté，是 Prezi 的一名后端工程师。Prezi 是一款让你的想法活起来的在线演示工具。

### HF 专家支持计划如何帮助你构建 AI？

我们在 Prezi 的旗舰 AI 产品是 Prezi AI，它帮助用户更快创建更好的 Prezi 演示文稿。用户先提供一个 prompt 以及对想要创建的演示文稿的描述，系统随后自动生成一份草稿演示文稿供其起步。这是一个复杂的系统，会调用不同服务，结合闭源模型和各类素材提供方来构建演示文稿的结构。

我们加入计划时已经有这个系统的一个版本，我们的专家审查了整个流程并提出了改进建议。我们的管道里有一个搜索系统，为每一份独特的演示文稿寻找合适的素材（图片和文本）。在这个语境下，一条重要的建议比如：在系统中加入一个开源 re-ranker 模型——它能比 LLM 更便宜、更快、更好地为你的演示文稿找到最佳图片或文本。

我们的用例天然就是多模态的，因为演示文稿融合了图像与文本。每周都有大量模型发布，我们的专家帮助我们拨开炒作迷雾，理解哪些模型对我们有用、哪些没用。这帮我们节省了大量时间，因为我们正在用视觉模型、文本模型和视觉语言模型（VLM）的组合来解决我们独特的挑战。多模态机器学习很有难度，这些指导真的非常宝贵。我们不是机器学习工程师，我们是一边走一边学的。

### 你最喜欢的 Inference Endpoints 功能是哪个？

我强烈推荐大家看看 [Endpoint Model Catalog](https://ui.endpoints.huggingface.co/catalog)。它是一份精选模型清单，这些模型与 Inference Endpoints 配合良好、零配置即可使用。我很喜欢可以设置 Endpoint 在几分钟后进入睡眠，这样就不会烧钱。它还支持某些模型所需的单卡与四卡 A100 实例。保持模型更新也很简单：Inference Endpoints 让我们一键部署最新版本，或用 Git hash 回滚到任意旧版本。这些功能在 AWS 上都不容易获得，所以对我们来说非常省心。即使某个模型还没进入 [catalog](https://ui.endpoints.huggingface.co/catalog)，让它跑起来也相对容易——至少在有我们专家支持的情况下是这样。

### 哪些团队最能从专家支持中受益？

与 Hugging Face 的合作为我们打开了机器学习的大门。我们的专属专家让我们能接触一个 ML 专家社区，他们能回答我们最天马行空的问题。如前所述，我们不是机器学习工程师。我们的专家引导我们做正确的事，分享嵌入、重排和目标检测方面的最佳实践与最先进模型，教我们如何微调新的视觉语言模型、收集和整理数据。这些事情大多我们自己也能做，但他的指导带来了巨大的提速，让我们专注于对用户真正有意义的任务。

通过专家支持计划，我们组建了一支世界级团队，帮助客户更快构建更好的 ML 解决方案。我们的专家会在你从研究到生产机器学习的旅程中按需答疑并寻找方案。请访问 [hf.co/support](https://huggingface.co/support) 了解更多并申请报价。
