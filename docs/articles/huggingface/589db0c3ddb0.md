[MusicGen](https://huggingface.co/docs/transformers/main/en/model_doc/musicgen) 是一个强大的音乐生成模型，接收文本提示和可选的旋律，输出音乐。本博客将指导你使用 [Inference Endpoints](https://huggingface.co/inference-endpoints) 通过 MusicGen 生成音乐。

Inference Endpoints 允许我们编写称为[自定义 handler（custom handlers）](https://huggingface.co/docs/inference-endpoints/guides/custom_handler)的自定义推理函数。当模型不被 `transformers` 的高层抽象 `pipeline` 原生支持时，它们尤其有用。

`transformers` pipelines 为运行基于 `transformers` 的模型推理提供了强大抽象。Inference Endpoints 借助 pipeline API，只需几次点击即可轻松部署模型。不过，Inference Endpoints 也可以用来部署没有 pipeline 的模型，甚至非 transformer 模型！这通过一个我们称为[自定义 handler](https://huggingface.co/docs/inference-endpoints/guides/custom_handler)的自定义推理函数实现。

我们以 MusicGen 为例演示这一过程。要为 MusicGen 实现自定义 handler 并部署它，我们需要：

- 复制（Duplicate）我们要提供服务的 MusicGen 仓库，
- 在 `handler.py` 中编写自定义 handler、在 `requirements.txt` 中声明依赖，并把它们加入复制的仓库，
- 为该仓库创建 Inference Endpoint。

或者直接用最终成果，部署我们的[自定义 MusicGen 模型仓库](https://huggingface.co/reach-vb/musicgen-large-fp16-endpoint)——我们正是按上面步骤做的 :)

### 开始吧！

首先，用[仓库复制器](https://huggingface.co/spaces/huggingface-projects/repo_duplicator)把 [facebook/musicgen-large](https://huggingface.co/facebook/musicgen-large) 仓库复制到我们自己的账户。

然后，把 `handler.py` 和 `requirements.txt` 加入复制的仓库。先看看如何用 MusicGen 做推理。

```
from transformers import AutoProcessor, MusicgenForConditionalGeneration

processor = AutoProcessor.from_pretrained("facebook/musicgen-large")
model = MusicgenForConditionalGeneration.from_pretrained("facebook/musicgen-large")

inputs = processor(
    text=["80s pop track with bassy drums and synth"],
    padding=True,
    return_tensors="pt",
)
audio_values = model.generate(**inputs, do_sample=True, guidance_scale=3, max_new_tokens=256)
```

听听它长什么样：

（您的浏览器不支持音频元素。）

另外，你也可以用一段音频样本对输出施加条件（condition）：即生成一段互补的音频，把文本生成的音频与输入音频结合起来。

```
from transformers import AutoProcessor, MusicgenForConditionalGeneration
from datasets import load_dataset

processor = AutoProcessor.from_pretrained("facebook/musicgen-large")
model = MusicgenForConditionalGeneration.from_pretrained("facebook/musicgen-large")

dataset = load_dataset("sanchit-gandhi/gtzan", split="train", streaming=True)
sample = next(iter(dataset))["audio"]

# take the first half of the audio sample
sample["array"] = sample["array"][: len(sample["array"]) // 2]

inputs = processor(
    audio=sample["array"],
    sampling_rate=sample["sampling_rate"],
    text=["80s blues track with groovy saxophone"],
    padding=True,
    return_tensors="pt",
)
audio_values = model.generate(**inputs, do_sample=True, guidance_scale=3, max_new_tokens=256)
```

来听听：

（您的浏览器不支持音频元素。）

两种情况下，`model.generate` 方法都生成音频，其原理与文本生成相同。更多细节见我们的 [how to generate](https://huggingface.co/blog/how-to-generate) 博客。

好！基础用法介绍完了，让我们来部署 MusicGen，既为乐趣也为收益！

首先，在 `handler.py` 中定义自定义 handler。我们可以使用 [Inference Endpoints 模板](https://huggingface.co/docs/inference-endpoints/guides/custom_handler#3-customize-endpointhandler)，用自定义推理代码覆写 `__init__` 和 `__call__` 方法。`__init__` 初始化模型和 processor，`__call__` 接收数据并返回生成的音乐。修改后的 `EndpointHandler` 类如下。👇

```
from typing import Dict, List, Any
from transformers import AutoProcessor, MusicgenForConditionalGeneration
import torch

class EndpointHandler:
    def __init__(self, path=""):
        # load model and processor from path
        self.processor = AutoProcessor.from_pretrained(path)
        self.model = MusicgenForConditionalGeneration.from_pretrained(path, torch_dtype=torch.float16).to("cuda")

    def __call__(self, data: Dict[str, Any]) -> Dict[str, str]:
        """
        Args:
            data (:dict:):
                The payload with the text prompt and generation parameters.
        """
        # process input
        inputs = data.pop("inputs", data)
        parameters = data.pop("parameters", None)

        # preprocess
        inputs = self.processor(
            text=[inputs],
            padding=True,
            return_tensors="pt",).to("cuda")

        # pass inputs with all kwargs in data
        if parameters is not None:
            with torch.autocast("cuda"):
                outputs = self.model.generate(**inputs, **parameters)
        else:
            with torch.autocast("cuda"):
                outputs = self.model.generate(**inputs,)

        # postprocess the prediction
        prediction = outputs[0].cpu().numpy().tolist()

        return [{"generated_audio": prediction}]
```

为简单起见，这个示例我们只从文本生成音频，不用旋律施加条件。接着创建一个 `requirements.txt` 文件，列出运行推理代码所需的全部依赖：

```
transformers==4.31.0
accelerate>=0.20.3
```

把这两个文件上传到仓库，就足以提供服务了。

[![inference-files](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/ie_musicgen/files.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/ie_musicgen/files.png)

现在可以创建 Inference Endpoint 了。前往 [Inference Endpoints](https://huggingface.co/inference-endpoints) 页面，点击 `Deploy your first model`。在 "Model repository" 字段中输入复制仓库的标识符，然后选择想要的硬件并创建 endpoint。对 `musicgen-large` 来说，任何至少 16GB 内存的实例都够用。

[![Create Endpoint](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/ie_musicgen/create_endpoint.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/ie_musicgen/create_endpoint.png)

创建 endpoint 后，它会自动启动并准备好接收请求。

[![Endpoint Running](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/ie_musicgen/endpoint_running.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/ie_musicgen/endpoint_running.png)

我们可以用下面的片段查询 endpoint。

```
curl URL_OF_ENDPOINT \
-X POST \
-d '{"inputs":"happy folk song, cheerful and lively"}' \
-H "Authorization: {YOUR_TOKEN_HERE}" \
-H "Content-Type: application/json"
```

可以看到输出是如下波形序列。

```
[{"generated_audio":[[-0.024490159,-0.03154691,-0.0079551935,-0.003828604, ...]]}]
```

听起来是这样：

（您的浏览器不支持音频元素。）

你也可以用 `huggingface-hub` Python 库的 `InferenceClient` 类访问 endpoint。

```
from huggingface_hub import InferenceClient

client = InferenceClient(model = URL_OF_ENDPOINT)
response = client.post(json={"inputs":"an alt rock song"})
# response looks like this b'[{"generated_text":[[-0.182352,-0.17802449, ...]]}]

output = eval(response)[0]["generated_audio"]
```

你可以按任何方式把生成的序列转成音频。比如用 Python 的 `scipy` 把它写成 .wav 文件。

```
import scipy
import numpy as np

# output is [[-0.182352,-0.17802449, ...]]
scipy.io.wavfile.write("musicgen_out.wav", rate=32000, data=np.array(output[0]))
```

大功告成！

## 结论

在这篇博文中，我们演示了如何用带自定义推理 handler 的 Inference Endpoints 部署 MusicGen。同样的技术适用于 Hub 上任何没有对应 pipeline 的模型。你只需在 `handler.py` 中覆写 `Endpoint Handler` 类，并添加反映项目依赖的 `requirements.txt`。
