Hugging Face 的 [*datasets* 库](https://huggingface.co/docs/datasets/index)不仅提供对 7 万多个公开数据集的访问，还为自定义数据集提供了非常便捷的数据准备流水线。

[Renumics Spotlight](https://github.com/Renumics/spotlight) 让你创建**交互式可视化**，以**识别数据中的关键簇**。因为 Spotlight 理解 Hugging Face 数据集内的数据语义，你可以**一行代码直接上手**：

```
import datasets
from renumics import spotlight

ds = datasets.load_dataset('speech_commands', 'v0.01', split='validation')

spotlight.show(ds)
```

[![](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/scalable-data-inspection/speech_commands_vis_s.gif)](https://github.com/Renumics/spotlight)

Spotlight 让你能**利用模型结果**（如预测和嵌入），更深入地理解数据子段与模型失效模式：

```
ds_results = datasets.load_dataset('renumics/speech_commands-ast-finetuned-results', 'v0.01', split='validation')
ds = datasets.concatenate_datasets([ds, ds_results], axis=1)

spotlight.show(ds, dtype={'embedding': spotlight.Embedding}, layout=spotlight.layouts.debug_classification(embedding='embedding', inspect={'audio': spotlight.dtypes.audio_dtype}))
```

数据检视（data inspection）在几乎所有 ML 开发阶段都是非常重要的任务，但也可能极其耗时。

> "人工检视数据大概是机器学习里价值/声望比最高的活动了。" —— Greg Brockman

[Spotlight](https://renumics.com/docs) 帮助你沿两个维度**让数据检视更可规模化**：搭建并维护自定义数据检视工作流；找到需要检视的相关数据样本与簇。下面几节我们基于 Hugging Face 数据集展示一些示例。

## Spotlight 🤝 Hugging Face datasets

*datasets* 库的若干特性使它成为处理 ML 数据集的理想工具：它在同一张 Arrow 表里同时存储表格数据（如元数据、标签）与非结构化数据（如图像、音频）。*datasets* 还通过 features（例如 images、audio）及额外的任务元数据来描述重要的数据语义。

Spotlight 直接构建在 *datasets* 库之上，这意味着数据可视化与检视不需要复制或预处理数据集。Spotlight 把表格数据载入内存以实现高效的客户端数据分析；内存消耗大的非结构化样本（如音频、图像、视频）则按需惰性加载。多数情况下，数据类型与标签映射会直接从数据集推断。这里我们一行代码可视化 CIFAR-100 数据集：

```
ds = datasets.load_dataset('cifar100', split='test')
spotlight.show(ds)
```

当数据类型不明确或未指定时，Spotlight API 允许手动指派：

```
label_mapping = dict(zip(ds.features['fine_label'].names, range(len(ds.features['fine_label'].names))))
spotlight.show(ds, dtype={'img': spotlight.Image, 'fine_label': spotlight.dtypes.CategoryDType(categories=label_mapping)})
```

## **利用模型结果做数据检视**

直接浏览原始非结构化数据集往往收获很少。利用模型结果（如预测或嵌入）有助于发现关键数据样本与簇。Spotlight 提供多种可视化选项（如相似度图、混淆矩阵），专门利用模型结果。

我们建议把预测结果直接存进 Hugging Face 数据集。这不仅让你受益于 datasets 库的批处理能力，还保留了标签映射。

我们可以用 [*transformers* 库](https://huggingface.co/docs/transformers)在 CIFAR-100 图像分类问题上计算嵌入与预测。先用 pip 安装库：

```
pip install renumics-spotlight datasets transformers[torch]
```

现在可以计算富化数据（enrichment）：

```
import torch
import transformers

device = torch.device("cuda:0" if torch.cuda.is_available() else "cpu")
model_name = "Ahmed9275/Vit-Cifar100"
processor = transformers.ViTImageProcessor.from_pretrained(model_name)
cls_model = transformers.ViTForImageClassification.from_pretrained(model_name).to(device)
fe_model = transformers.ViTModel.from_pretrained(model_name).to(device)

def infer(batch):
    images = [image.convert("RGB") for image in batch]
    inputs = processor(images=images, return_tensors="pt").to(device)
    with torch.no_grad():
        outputs = cls_model(**inputs)
        probs = torch.nn.functional.softmax(outputs.logits, dim=-1).cpu().numpy()
        embeddings = fe_model(**inputs).last_hidden_state[:, 0].cpu().numpy()
    preds = probs.argmax(axis=-1)
    return {"prediction": preds, "embedding": embeddings}

features = datasets.Features({**ds.features, "prediction": ds.features["fine_label"], "embedding": datasets.Sequence(feature=datasets.Value("float32"), length=768)})
ds_enriched = ds.map(infer, input_columns="img", batched=True, batch_size=2, features=features)
```

如果不想跑完整推理，也可以下载为 CIFAR-100 预计算好的模型结果来跟随本教程：

```
ds_results = datasets.load_dataset('renumics/spotlight-cifar100-enrichment', split='test')
ds_enriched = datasets.concatenate_datasets([ds, ds_results], axis=1)
```

现在我们可以用这些结果在 Spotlight 中交互式探索相关数据样本与簇：

```
layout = spotlight.layouts.debug_classification(label='fine_label', embedding='embedding', inspect={'img': spotlight.dtypes.image_dtype})
spotlight.show(ds_enriched, dtype={'embedding': spotlight.Embedding}, layout=layout)
```

## 定制数据检视工作流

可视化布局可以在 GUI 中交互地修改、保存与加载：你可以选择不同的小组件类型与配置。*Inspector* 小组件支持展示多模态数据样本，包括文本、图像、音频、视频与时间序列。

你也可以通过 [Python API](https://renumics.com/api/spotlight/) 定义布局。这个选项对构建自定义数据检视与数据整备工作流尤其有用，涵盖 EDA、模型调试与模型监控任务。

Python API 配合数据问题（data issues）小组件，为把既有脚本的结果（如数据质量检查或模型监控）集成进可规模化的数据检视工作流提供了极佳途径。

## 在 Hugging Face Hub 上使用 Spotlight

你可以直接在本地 NLP、音频、CV 或多模态数据集上使用 Spotlight。如果你想在 Hugging Face Hub 上展示数据集或模型结果，可以用 Hugging Face Space 启动一个 Spotlight 可视化。

我们已经为 Hub 上许多流行的 NLP、音频和 CV 数据集准备好了[示例 Space](https://huggingface.co/renumics)。只需复制其中一个，并在 `HF_DATASET` 变量中指定你的数据集。

你还可以选择性指定一个包含模型结果的数据集，以及其他配置项，如划分（splits）、子集或数据集版本。
