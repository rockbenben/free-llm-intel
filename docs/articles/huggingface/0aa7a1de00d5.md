# 我们的新定价方案上线

你可能已经注意到，我们的[定价页面](https://huggingface.co/pricing)最近有了很大变化。

首先，我们将关停 Inference API 服务的付费档（Paid tier）。Inference API 仍将对所有人免费开放。但如果你需要快速、企业级的推理即服务（inference as a service），我们推荐你了解我们全新的解决方案：[Inference Endpoints](https://huggingface.co/inference-endpoints)。

伴随 Inference Endpoints，我们最近还为 [Spaces](https://huggingface.co/spaces/launch) 引入了硬件升级选项，让你可以用自己选择的硬件来运行 ML 演示。使用这些服务无需订阅，只需在[账单设置](https://huggingface.co/settings/billing)中为你的账户添加一张信用卡即可。你也可以为[你的任意组织](https://huggingface.co/settings/organizations)绑定支付方式。

你的账单设置页面集中管理了我们所有付费服务的相关信息。在那里，你可以管理个人 PRO 订阅、更新支付方式，并查看过去三个月的用量。我们所有付费服务和订阅的用量将在每月初结算扣费，并会生成一份合并账单（consolidated invoice）供你留存。

**TL;DR**：**在 HF，我们的商业模式是为 AI 提供便捷的算力接入**，通过 AutoTrain、Spaces 和 Inference Endpoints 等直接从 Hub 访问的服务实现。关于我们的定价与计费系统，请[阅读更多](https://huggingface.co/docs/hub/billing)。

如有任何疑问，欢迎随时联系我们，我们期待你的反馈 🔥
