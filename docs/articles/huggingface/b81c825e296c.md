# 用 BLIP-2 实现零样本图像到文本生成

本指南介绍 Salesforce Research 的 [BLIP-2](https://huggingface.co/docs/transformers/main/en/model_doc/blip-2)，它提供一系列最先进的视觉-语言模型，现已可在 [🤗 Transformers](https://huggingface.co/transformers) 中使用。我们将演示如何用它做图像描述、带提示词的图像描述、视觉问答和基于对话的提示。

## 引言

近年来，计算机视觉和自然语言处理进步迅速。但现实世界的许多问题天生就是多模态的——涉及多种不同类型的数据，比如图像和文本。视觉-语言模型面临的挑战正是把模态融合起来，从而打开广泛应用的大门。视觉-语言模型可以处理的图像到文本任务包括图像描述、图文检索和视觉问答。图像描述可以帮助视障人士、生成有用的产品描述、识别文本之外的不当内容等等。图文检索可以应用于多模态搜索，以及自动驾驶等应用。视觉问答可以辅助教育、支撑多模态聊天机器人，并服务于各种特定领域的信息检索应用。

现代计算机视觉和自然语言模型能力更强了，但与前辈相比体积也膨胀了很多。预训练单个模态的模型已经既耗资源又昂贵，而端到端的视觉-语言预训练成本更是高得离谱。[BLIP-2](https://arxiv.org/pdf/2301.12597.pdf) 通过引入一种新的视觉-语言预训练范式来应对这一挑战：它可以利用任意「预训练视觉编码器 + LLM」的组合，而无需端到端地预训练整个架构。这让它在多个视觉-语言任务上取得最先进结果的同时，显著减少了可训练参数量和预训练成本。此外，这条路还通向了多模态的类 ChatGPT 模型。

## BLIP-2 的内部构造

BLIP-2 通过在现成的、冻结的预训练图像编码器与冻结的大语言模型之间插入一个轻量的 Querying Transformer（Q-Former）来弥合视觉与语言模型之间的模态鸿沟。Q-Former 是 BLIP-2 中唯一可训练的部分；图像编码器和语言模型都保持冻结。

![BLIP-2 框架总览](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/blip-2/q-former-1.png)

Q-Former 是一个 transformer 模型，由两个共享同一套自注意力层的子模块组成：

- 图像 transformer：与冻结的图像编码器交互，抽取视觉特征
- 文本 transformer：可以同时充当文本编码器和文本解码器

![Q-Former 架构](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/blip-2/q-former-2.png)

图像 transformer 从图像编码器中抽取固定数量的输出特征，与输入图像分辨率无关，其输入是可学习的 query 嵌入。queries 还可以通过同一套自注意力层与文本交互。

Q-Former 的预训练分两个阶段。第一阶段，图像编码器冻结，Q-Former 用三个损失训练：

- 图文对比损失（Image-text contrastive loss）：计算每个 query 输出与文本输出 CLS token 之间的成对相似度，取最高者。query 嵌入与文本彼此「看不见」。
- 图像引导文本生成（Image-grounded text generation）：queries 之间可以互相注意，但不能注意文本 token；文本使用因果掩码，且可以注意所有 queries。
- 图文匹配损失（Image-text matching loss）：queries 和文本可以互相看到，输出一个 logit 来指示文本与图像是否匹配。负例通过困难负样本挖掘（hard negative mining）获得。

在第二个预训练阶段，query 嵌入已经通过信息瓶颈携带了与文本相关的视觉信息。这些嵌入现在作为视觉前缀（visual prefix）输入给 LLM。这一预训练阶段实质上是一个使用因果 LM 损失的图像引导文本生成任务。

作为视觉编码器，BLIP-2 使用 ViT；作为 LLM，论文作者用了 OPT 和 Flan T5 模型。OPT 和 Flan T5 的预训练 checkpoint 都可以在 [Hugging Face Hub](https://huggingface.co/models?other=blip-2) 找到。如前所述，这种预训练方法允许任意视觉骨干与任意 LLM 组合。

## 在 Hugging Face Transformers 中使用 BLIP-2

借助 Hugging Face Transformers，你可以轻松下载预训练 BLIP-2 模型并在自己的图像上运行。如果你想跟着本文示例操作，请使用大内存的 GPU 环境。

先安装 Transformers。由于这个模型刚加入 Transformers 不久，我们需要从源码安装：

```
pip install git+https://github.com/huggingface/transformers.git
```

接下来需要一张输入图像。《纽约客》每周都会在其读者间举办[漫画配文大赛](https://www.newyorker.com/cartoons/contest#thisweek)，我们就拿其中一幅漫画来考验 BLIP-2。

```
import requests
from PIL import Image

url = 'https://media.newyorker.com/cartoons/63dc6847be24a6a76d90eb99/master/w_1160,c_limit/230213_a26611_838.jpg'
image = Image.open(requests.get(url, stream=True).raw).convert('RGB')  
display(image.resize((596, 437)))
```

![纽约客漫画](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/blip-2/cartoon.jpeg)

输入图像有了。现在需要预训练的 BLIP-2 模型和对应的预处理器来准备输入。所有可用的预训练 checkpoint 列表可以在 [Hugging Face Hub](https://huggingface.co/models?other=blip-2) 找到。这里我们加载一个使用 Meta AI 预训练 OPT 模型的 BLIP-2 checkpoint，参数量 27 亿。

```
from transformers import AutoProcessor, Blip2ForConditionalGeneration
import torch

processor = AutoProcessor.from_pretrained("Salesforce/blip2-opt-2.7b")
model = Blip2ForConditionalGeneration.from_pretrained("Salesforce/blip2-opt-2.7b", torch_dtype=torch.float16)
```

注意，BLIP-2 是个罕见案例：不能用 Auto API（如 AutoModelForXXX）加载模型，必须显式使用 `Blip2ForConditionalGeneration`。不过你可以用 `AutoProcessor` 获取合适的处理器类——这里是 `Blip2Processor`。

我们用 GPU 来加速文本生成：

```
device = "cuda" if torch.cuda.is_available() else "cpu"
model.to(device)
```

### 图像描述

来看看 BLIP-2 能不能零样本地给《纽约客》漫画配文。给图像做描述不需要向模型提供任何文本提示词，只需要预处理后的输入图像。没有文本提示时，模型会从 BOS（序列起始）token 开始生成文本，从而产出一条描述。

```
inputs = processor(image, return_tensors="pt").to(device, torch.float16)

generated_ids = model.generate(**inputs, max_new_tokens=20)
generated_text = processor.batch_decode(generated_ids, skip_special_tokens=True)[0].strip()
print(generated_text)
```

```
"two cartoon monsters sitting around a campfire"
```

对于一个从未在《纽约客》风格漫画上训练过的模型，这个描述准确得令人印象深刻！

### 带提示词的图像描述

我们可以在图像描述的基础上提供一个文本提示词，模型会在图像条件下接着把它续写下去。

```
prompt = "this is a cartoon of"

inputs = processor(image, text=prompt, return_tensors="pt").to(device, torch.float16)

generated_ids = model.generate(**inputs, max_new_tokens=20)
generated_text = processor.batch_decode(generated_ids, skip_special_tokens=True)[0].strip()
print(generated_text)
```

```
"two monsters sitting around a campfire"
```

```
prompt = "they look like they are"

inputs = processor(image, text=prompt, return_tensors="pt").to(device, torch.float16)

generated_ids = model.generate(**inputs, max_new_tokens=20)
generated_text = processor.batch_decode(generated_ids, skip_special_tokens=True)[0].strip()
print(generated_text)
```

```
"having a good time"
```

### 视觉问答

视觉问答的提示词必须遵循特定格式："Question: {} Answer:"

```
prompt = "Question: What is a dinosaur holding? Answer:"

inputs = processor(image, text=prompt, return_tensors="pt").to(device, torch.float16)

generated_ids = model.generate(**inputs, max_new_tokens=10)
generated_text = processor.batch_decode(generated_ids, skip_special_tokens=True)[0].strip()
print(generated_text)
```

```
"A torch"
```

### 基于对话的提示

最后，我们可以通过把每个生成的回答拼接进对话，做出一个类 ChatGPT 的界面。我们用一些文本向模型提问（比如 "What is a dinosaur holding?"），模型生成回答（"a torch"），我们可以把它拼进对话，然后再问下一轮，逐步构建上下文。不过要确保上下文不超过 512 个 token，因为 BLIP-2 使用的语言模型（OPT 和 T5）的上下文长度就是 512。

```
context = [
   ("What is a dinosaur holding?", "a torch"),
   ("Where are they?", "In the woods.")
]
question = "What for?"
template = "Question: {} Answer: {}."

prompt = " ".join([template.format(context[i][0], context[i][1]) for i in range(len(context))]) + " Question: " + question + " Answer:"

print(prompt)
```

```
Question: What is a dinosaur holding? Answer: a torch. Question: Where are they? Answer: In the woods.. Question: What for? Answer:
```

```
inputs = processor(image, text=prompt, return_tensors="pt").to(device, torch.float16)

generated_ids = model.generate(**inputs, max_new_tokens=10)
generated_text = processor.batch_decode(generated_ids, skip_special_tokens=True)[0].strip()
print(generated_text)
```

```
To light a fire.
```

## 结论

BLIP-2 是一个零样本视觉-语言模型，可以通过图像以及图像加文本提示完成多种图像到文本任务。它是一种有效且高效的方法，可以应用于众多场景的图像理解，尤其是在示例稀缺的情况下。

该模型通过在两个预训练模型之间插入一个 transformer 来弥合视觉与自然语言模态的鸿沟。新的预训练范式让它能够同时跟上两个单模态各自的最新进展。

如果你想学习如何针对各种视觉-语言任务微调 BLIP-2，可以看看 [Salesforce 的 LAVIS 库](https://github.com/salesforce/LAVIS)，它对模型训练提供了全面支持。

想亲眼看 BLIP-2 运行，可以试试它在 [Hugging Face Spaces](https://huggingface.co/spaces/Salesforce/BLIP2) 上的 demo。
