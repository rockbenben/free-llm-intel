# Hugging Face 与 FriendliAI 合作，为 Hub 上的模型部署提速

FriendliAI 的推理基础设施现已集成进 Hugging Face Hub，作为"Deploy this model"按钮中的一个选项，让生成式 AI 模型的服务化更简单、更快速。

[![Hugging Face and FriendliAI partner to supercharge model deployment on the Hub](https://huggingface.co/blog/assets/friendliai-partnership/thumbnail.png)](https://huggingface.co/blog/assets/friendliai-partnership/thumbnail.png)

## 携手推动 AI 创新

Hugging Face 致力于赋能开发者、研究者与企业，让它们在 AI 中不断创新。我们的共同优先事项，是构建有影响力的合作伙伴关系，简化工作流，为 AI 社区提供前沿工具。

今天，我们很高兴宣布 HF 与 FriendliAI 的合作。FriendliAI 是加速生成式 AI 推理领域的领导者，此次合作将提升开发者部署和管理 AI 模型的方式。这一集成把 FriendliAI Endpoints 作为部署选项引入 Hugging Face Hub，让开发者直接获得高性能、高性价比的推理基础设施。

FriendliAI 被 [Artificial Analysis](https://huggingface.co/ArtificialAnalysis) 评为最快的基于 GPU 的生成式 AI 推理服务商，其突破性技术包括 continuous batching、原生量化和一流的自动扩缩容。凭借这些技术，FriendliAI 不断刷新 AI 推理服务性能的标准，为规模化部署生成式 AI 模型提供更快的处理速度、更低的延迟和可观的成本节约。通过这一合作，Hugging Face 用户和 FriendliAI 客户都能以无与伦比的效率和可靠性，毫不费力地部署开源或自定义的生成式 AI 模型。

## 让模型部署更简单

去年，FriendliAI 推出了 [Hugging Face 集成](https://friendli.ai/docs/guides/dedicated_endpoints/huggingface_tutorial)，让用户能够在 Friendli Suite 平台内直接部署 Hugging Face 模型。借助该集成，用户可以访问 Hugging Face 上数千个受支持的开源模型，并能轻松部署私有模型。FriendliAI 当前支持的模型架构列表见[这里](https://friendli.ai/models)。

今天，我们把这个集成推得更远——在 Hugging Face Hub 内直接提供同样的能力，带来一键部署的无缝体验。你可以用 Friendli Suite 账户，从 Hugging Face Hub 的模型卡直接部署模型。

[![Friendli Inference deployment option in Hugging Face](https://huggingface.co/datasets/FriendliAI/documentation-images/resolve/main/friendliai-partnership/deployment-option.png)](https://huggingface.co/datasets/FriendliAI/documentation-images/resolve/main/friendliai-partnership/deployment-option.png)

选择 Friendli Endpoints 会跳转到 FriendliAI 的模型部署页面。在那里，你可以在 NVIDIA H100 GPU 上部署模型，同时与经过优化的开源模型互动。部署页面为设置 Friendli Dedicated Endpoints（面向生成式 AI 推理的托管服务）提供了直观的界面。此外，在你的部署还在处理时，可以直接在页面上与开源模型聊天，轻松探索和测试它们的能力。

### 在 Friendli Dedicated Endpoints 上用 NVIDIA H100 部署模型

借助 FriendliAI 先进的 GPU 优化推理引擎，Dedicated Endpoints 以托管服务的形式提供快速且经济的推理。开发者只需在模型部署页面点击 "Deploy now"，即可用 Friendli Dedicated Endpoints 在 NVIDIA H100 GPU 上轻松部署开源或自定义模型。

H100 GPU 很强大，但规模化运行的成本也不菲。使用 FriendliAI 优化的服务，你可以在保持峰值性能的同时减少所需 GPU 数量，显著降低成本。除成本效率之外，Dedicated Endpoints 还简化了基础设施管理的复杂性。

[![Deploy Hugging Face models in the model deployment page](https://huggingface.co/datasets/FriendliAI/documentation-images/resolve/main/friendliai-partnership/deploy-model-status-fast.gif)](https://huggingface.co/datasets/FriendliAI/documentation-images/resolve/main/friendliai-partnership/deploy-model-status-fast.gif)

### 用 Friendli Serverless Endpoints 推理开源模型

Friendli Serverless Endpoints 是希望高效推理开源模型的开发者的完美选择。该服务为 FriendliAI 优化的模型提供易用的 API，以低成本保证高性能。你可以直接在模型部署页面上与这些强大的开源模型聊天。

[![Try out Serverless Endpoints in the model deployment page](https://huggingface.co/datasets/FriendliAI/documentation-images/resolve/main/friendliai-partnership/deploy-model-surprise-me.gif)](https://huggingface.co/datasets/FriendliAI/documentation-images/resolve/main/friendliai-partnership/deploy-model-surprise-me.gif)
