# 用 Presidio 在 Hub 上试验自动 PII 检测

本文另有中文版本 [简体中文](https://huggingface.co/blog/zh/presidio-pii-detection)。

在 Hugging Face，我们注意到我们 Hub 上托管的机器学习（ML）数据集中存在一个令人担忧的趋势：未经说明的个人私密信息。这给 ML 从业者带来了独特的挑战。在这篇博客中，我们将探讨包含一类被称为个人可识别信息（Personally Identifying Information, PII）的私密信息的数据集的不同类型、它们引发的问题，以及我们在 Dataset Hub 上正在试验的、帮助应对这些挑战的新功能。

## 含 PII 的数据集类型

我们注意到两类包含 PII 的数据集：

- **标注过的 PII 数据集**：像 [Ai4Privacy 的 PII-Masking-300k](https://huggingface.co/datasets/ai4privacy/pii-masking-300k) 这样的数据集，专门用于训练 PII 检测模型，这类模型用于检测并遮蔽 PII。例如，这些模型可以协助在线内容审核，或提供匿名化数据库。
- **预训练数据集**：这些是通常通过网络爬取获取的超大规模数据集，动辄数 TB。虽然这类数据集一般会经过过滤以移除某些类型的 PII，但由于数据总量巨大、且 PII 检测模型并不完美，仍会有少量敏感信息漏网。

## ML 数据集中 PII 的挑战

ML 数据集中存在 PII 会给从业者带来多重挑战。首先是隐私顾虑，PII 可能被用来推断个人的敏感信息。此外，如果处理不当，PII 还会影响 ML 模型的性能。例如，如果模型在包含 PII 的数据集上训练，它可能学会把某些 PII 与特定结果相关联，导致有偏的预测，或者从训练集中生成 PII。

## Dataset Hub 上的新实验：Presidio 报告

为帮助应对这些挑战，我们正在 Dataset Hub 上试验一项新功能，它使用 [Presidio](https://github.com/microsoft/presidio)——一个开源的最先进 PII 检测工具。Presidio 依赖检测模式和机器学习模型来识别 PII。

有了这个新功能，用户将能看到一份估计数据集中 PII 存在情况的报告。这些信息对 ML 从业者很有价值，能帮助他们在训练模型前做出知情决策。例如，如果报告显示某个数据集包含敏感 PII，从业者可以决定使用 Presidio 等工具进一步过滤该数据集。

数据集的所有者也能从该功能中受益：在发布数据集之前，用报告来验证自己的 PII 过滤流程。

## 结论

ML 数据集中存在 PII 是 ML 社区面临的持续演化的挑战。在 Hugging Face，我们承诺保持透明，并帮助从业者应对这些挑战。通过在 Dataset Hub 上试验 Presidio 报告等新功能，我们希望能赋能用户做出知情决策，构建更稳健、更符合伦理的 ML 模型。
