# MTEB：大规模文本嵌入基准

MTEB 是一个用于衡量文本嵌入模型在多样嵌入任务上性能的大规模基准。

🥇 [榜单](https://huggingface.co/spaces/mteb/leaderboard)为当前最优秀的文本嵌入模型在各类任务上的表现提供了全貌视图。

📝 [论文](https://arxiv.org/abs/2210.07316)介绍了 MTEB 中任务与数据集的背景知识，并分析了榜单结果！

💻 [Github repo](https://github.com/embeddings-benchmark/mteb)包含对任意模型进行基准测试并提交到榜单的代码。

[![MTEB Leaderboard](https://huggingface.co/blog/assets/110_mteb/leaderboard.png)](https://huggingface.co/spaces/mteb/leaderboard)

## 为什么是文本嵌入？

文本嵌入是编码语义信息的文本向量表示。由于机器需要数值输入才能进行计算，文本嵌入是许多下游 NLP 应用的关键组件。例如，Google 用文本嵌入[驱动其搜索引擎](https://cloud.google.com/blog/topics/developers-practitioners/find-anything-blazingly-fast-googles-vector-search-technology)。文本嵌入还可用于[通过聚类在海量文本中发现模式](https://txt.cohere.ai/combing-for-insight-in-10-000-hacker-news-posts-with-text-clustering/)，或作为文本分类模型的输入，例如我们最近的 [SetFit](https://huggingface.co/blog/setfit) 工作。不过，文本嵌入的质量高度依赖于所用的嵌入模型。MTEB 正是为帮你找到各类任务上最好的嵌入模型而设计的！

## MTEB

🐋 **Massive（海量）**：MTEB 涵盖 8 类任务的 56 个数据集，目前[榜单](https://huggingface.co/spaces/mteb/leaderboard)上汇总了超过 2000 组结果。

🌎 **Multilingual（多语言）**：MTEB 包含多达 112 种语言！我们已在双语挖掘、分类和 STS 上基准测试了多个多语言模型。

🦚 **Extensible（可扩展）**：无论是新任务、数据集、指标还是榜单新增项，任何贡献都热烈欢迎。请查看 GitHub 仓库[提交到榜单](https://github.com/embeddings-benchmark/mteb#leaderboard)或[解决开放的 issue](https://github.com/embeddings-benchmark/mteb/issues)。希望你我同行，一起寻找最好的文本嵌入模型！

## 模型

在 MTEB 的首轮基准中，我们聚焦于宣称最先进的模型以及 Hub 上的热门模型。这导致 transformer 类模型占比很高。🤖

![MTEB Speed Benchmark](https://huggingface.co/blog/assets/110_mteb/benchmark.png)

*Models by average English MTEB score (y) vs speed (x) vs embedding size (circle size).*

为了方便你找到最适合任务的最佳模型，我们把模型归入以下三类：

**🏎 极速优先** [Glove](https://huggingface.co/sentence-transformers/average_word_embeddings_glove.6B.300d)这类模型速度很快，但缺乏上下文感知，导致 MTEB 平均分较低。

**⚖️ 速度与性能兼顾** 稍慢但显著更强的 [all-mpnet-base-v2](https://huggingface.co/sentence-transformers/all-mpnet-base-v2) 或 [all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2) 在速度与性能之间提供了良好平衡。

**💪 性能优先** 像 [ST5-XXL](https://huggingface.co/sentence-transformers/sentence-t5-xxl)、[GTR-XXL](https://huggingface.co/sentence-transformers/gtr-t5-xxl) 或 [SGPT-5.8B-msmarco](https://huggingface.co/Muennighoff/SGPT-5.8B-weightedmean-msmarco-specb-bitfit) 这样的数十亿参数模型在 MTEB 上占据统治地位。它们往往也产生更大的嵌入向量，例如 [SGPT-5.8B-msmarco](https://huggingface.co/Muennighoff/SGPT-5.8B-weightedmean-msmarco-specb-bitfit) 产生 4096 维嵌入，需要更多存储空间！

模型性能在不同任务和数据集上差异很大，因此我们建议在决定使用哪个模型前查看[榜单](https://huggingface.co/spaces/mteb/leaderboard)的各个标签页！

## 为你的模型做基准

使用 [MTEB 库](https://github.com/embeddings-benchmark/mteb)，你可以对任何产生嵌入的模型进行基准测试，并把结果添加到公开榜单。来看一个快速示例！

首先安装库：

```
pip install mteb
```

接下来在数据集上对模型做基准，例如在 [Banking77](https://huggingface.co/datasets/mteb/banking77) 上测试 [komninos word embeddings](https://huggingface.co/sentence-transformers/average_word_embeddings_komninos)。

```
from mteb import MTEB
from sentence_transformers import SentenceTransformer

model_name = "average_word_embeddings_komninos"
model = SentenceTransformer(model_name)

evaluation = MTEB(tasks=["Banking77Classification"])
results = evaluation.run(model, output_folder=f"results/{model_name}")
```

这会生成一个 `results/average_word_embeddings_komninos/Banking77Classification.json` 文件！

然后你可以把结果提交到榜单：将其添加到 Hub 上任一模型的 `README.md` 元数据中。

运行我们的[自动脚本](https://github.com/embeddings-benchmark/mteb/blob/main/scripts/mteb_meta.py)生成元数据：

```
python mteb_meta.py results/average_word_embeddings_komninos
```

## 脚本会生成一个形如下的 `mteb_metadata.md` 文件： ```sh

## tags: - mteb model-index: - name: average_word_embeddings_komninos results: - task: type: Classification dataset: type: mteb/banking77 name: MTEB Banking77Classification config: default split: test revision: 0fd18e25b25c072e09e0d92ab615fda904d66300 metrics: - type: accuracy value: 66.76623376623377 - type: f1 value: 66.59096432882667

```
把这段元数据添加到 Hub 上任一模型的 `README.md` 顶部，就像这个 [SGPT-5.8B-msmarco](https://huggingface.co/Muennighoff/SGPT-5.8B-weightedmean-msmarco-specb-bitfit/blob/main/README.md) 模型一样，刷新后它就会出现在[榜单](https://huggingface.co/spaces/mteb/leaderboard)上！
