在这篇博文中，我们将演示如何把开源 LLM 部署到 [Hugging Face Inference Endpoints](https://ui.endpoints.huggingface.co/)——我们的托管 SaaS 方案，让模型部署变得简单。此外，我们还会教你如何做响应流式输出，并测试端点性能。开始吧！

开始之前，先温习一下 Inference Endpoints 的知识。

## 什么是 Hugging Face Inference Endpoints

[Hugging Face Inference Endpoints](https://ui.endpoints.huggingface.co/) 提供了一种简单安全的方式来部署机器学习模型用于生产。Inference Endpoints 让开发者和数据科学家无需管理基础设施就能构建 AI 应用：把部署过程简化到几次点击，通过自动扩缩容应对大请求量，用 scale-to-zero 降低基础设施成本，并提供高级安全能力。

对 LLM 部署来说最重要的几个特性：

- [轻松部署](https://huggingface.co/docs/inference-endpoints/index)：几次点击就能把模型部署成生产级 API，无需操心基础设施或 MLOps。
- [成本效率](https://huggingface.co/docs/inference-endpoints/autoscaling)：享受自动 scale-to-zero 能力——端点不用时缩减基础设施以降低成本；同时按端点运行时长计费，确保经济性。
- [企业级安全](https://huggingface.co/docs/inference-endpoints/security)：把模型部署在安全的离线端点中，只能通过 VPC 直连访问；拥有 SOC2 Type 2 认证背书，并提供 BAA 和 GDPR 数据处理协议以增强数据安全与合规。
- [LLM 优化](https://huggingface.co/text-generation-inference)：为 LLM 优化——借助 Text Generation Inference 的 Paged Attention 实现高吞吐，通过定制 transformers 代码和 Flash Attention 实现低延迟
- [全面的任务支持](https://huggingface.co/docs/inference-endpoints/supported_tasks)：开箱即用地支持 🤗 Transformers、Sentence-Transformers 和 Diffusers 的任务与模型，也容易定制，可启用说话人分离等高级任务或任何机器学习任务和库。

Inference Endpoints 的入口：[https://ui.endpoints.huggingface.co/](https://ui.endpoints.huggingface.co/)

## 1. 如何部署 Falcon 40B instruct

首先，你需要用绑定了支付方式（可在**[这里](https://huggingface.co/settings/billing)**添加）的用户或组织账号登录，然后访问 Inference Endpoints：**[https://ui.endpoints.huggingface.co](https://ui.endpoints.huggingface.co/endpoints)**

然后点击 “New endpoint”。选择仓库、云和区域，调整实例和安全设置——我们这里选 `tiiuae/falcon-40b-instruct`——即可部署。

[![Select Hugging Face Repository](https://huggingface.co/blog/assets/155_inference_endpoints_llm/repository.png)](https://huggingface.co/blog/assets/155_inference_endpoints_llm/repository.png)

Inference Endpoints 会根据模型体积建议一个足以运行模型的实例类型，这里是 `4x NVIDIA T4` GPU。为了获得 LLM 的最佳性能，把实例改成 `GPU [xlarge] · 1x Nvidia A100`。

*注：如果无法选择该实例类型，需要[联系我们](mailto:api-enterprise@huggingface.co?subject=Quota%20increase%20HF%20Endpoints&body=Hello,%0D%0A%0D%0AI%20would%20like%20to%20request%20access/quota%20increase%20for%20%7BINSTANCE%20TYPE%7D%20for%20the%20following%20account%20%7BHF%20ACCOUNT%7D.)申请实例配额。*

[![Select Instance Type](https://huggingface.co/blog/assets/155_inference_endpoints_llm/instance-selection.png)](https://huggingface.co/blog/assets/155_inference_endpoints_llm/instance-selection.png)

然后点击 “Create Endpoint” 即可部署模型。10 分钟后，端点就应该上线并可以接收请求了。

## 2. 测试 LLM 端点

端点概览页提供了 Inference Widget 的访问，可以用它手动发送请求，方便你快速用不同输入测试端点，并分享给团队成员。这些 Widget 不支持参数——因此结果会是一段“短”生成。

[![Test Inference Widget](https://huggingface.co/blog/assets/155_inference_endpoints_llm/widget.png)](https://huggingface.co/blog/assets/155_inference_endpoints_llm/widget.png)

Widget 还会生成一条你可以直接用的 cURL 命令。加上你的 `hf_xxx` 就能测试。

```
curl https://j4xhm53fxl9ussm8.us-east-1.aws.endpoints.huggingface.cloud \
-X POST \
-d '{"inputs":"Once upon a time,"}' \
-H "Authorization: Bearer <hf_token>" \
-H "Content-Type: application/json"
```

你可以用不同参数控制生成，在请求负载的 `parameters` 属性中定义。目前支持以下参数：

- `temperature`：控制模型随机性。值越低模型越确定，值越高越随机。默认 1.0。
- `max_new_tokens`：生成的最大 token 数。默认 20，最大 512。
- `repetition_penalty`：控制重复的可能性。默认 `null`。
- `seed`：随机生成使用的种子。默认 `null`。
- `stop`：用于停止生成的 token 列表。一旦生成其中某个 token，生成就停止。
- `top_k`：top-k 过滤保留的最高概率词表 token 数。默认 `null`，即关闭 top-k 过滤。
- `top_p`：nucleus 采样保留的最高概率 token 累计概率，默认 `null`
- `do_sample`：是否使用采样；否则使用贪心解码。默认 `false`。
- `best_of`：生成 best_of 个序列并返回 logprobs 最高的那个，默认 `null`。
- `details`：是否返回生成详情。默认 `false`。
- `return_full_text`：返回完整文本还是只返回生成部分。默认 `false`。
- `truncate`：是否把输入截断到模型最大长度。默认 `true`。
- `typical_p`：typical 概率阈值。默认 `null`。
- `watermark`：生成使用的水印。默认 `false`。

## 3. 在 Javascript 和 Python 中流式接收响应

向 LLM 请求并生成文本可能既耗时又是迭代过程。改善用户体验的一个好办法是把 token 边生成边流式推给用户。下面是用 Python 和 JavaScript 流式接收 token 的两个例子。Python 使用 [Text Generation Inference 的客户端](https://github.com/huggingface/text-generation-inference/tree/main/clients/python)，JavaScript 使用 [HuggingFace.js 库](https://huggingface.co/docs/huggingface.js/main/en/index)

### Python 流式请求

首先安装 `huggingface_hub` 库：

```
pip install -U huggingface_hub
```

创建一个 `InferenceClient`，传入端点 URL、凭证和想用的超参数

```
from huggingface_hub import InferenceClient

# HF Inference Endpoints parameter
endpoint_url = "https://YOUR_ENDPOINT.endpoints.huggingface.cloud"
hf_token = "hf_YOUR_TOKEN"

# Streaming Client
client = InferenceClient(endpoint_url, token=hf_token)

# generation parameter
gen_kwargs = dict(
    max_new_tokens=512,
    top_k=30,
    top_p=0.9,
    temperature=0.2,
    repetition_penalty=1.02,
    stop_sequences=["\nUser:", "<|endoftext|>", "</s>"],
)
# prompt
prompt = "What can you do in Nuremberg, Germany? Give me 3 Tips"

stream = client.text_generation(prompt, stream=True, details=True, **gen_kwargs)

# yield each generated token
for r in stream:
    # skip special tokens
    if r.token.special:
        continue
    # stop if we encounter a stop sequence
    if r.token.text in gen_kwargs["stop_sequences"]:
        break
    # yield the generated token
    print(r.token.text, end = "")
    # yield r.token.text
```

把 `print` 换成 `yield` 或你想把 token 流向过去的函数即可。

[![Python Streaming](https://huggingface.co/blog/assets/155_inference_endpoints_llm/python-stream.gif)](https://huggingface.co/blog/assets/155_inference_endpoints_llm/python-stream.gif)

### JavaScript 流式请求

首先安装 `@huggingface/inference` 库。

```
npm install @huggingface/inference
```

创建一个 `HfInferenceEndpoint`，传入端点 URL、凭证和想用的超参数。

```
import { HfInferenceEndpoint } from '@huggingface/inference'

const hf = new HfInferenceEndpoint('https://YOUR_ENDPOINT.endpoints.huggingface.cloud', 'hf_YOUR_TOKEN')

//generation parameter
const gen_kwargs = {
  max_new_tokens: 512,
  top_k: 30,
  top_p: 0.9,
  temperature: 0.2,
  repetition_penalty: 1.02,
  stop_sequences: ['\nUser:', '<|endoftext|>', '</s>'],
}
// prompt
const prompt = 'What can you do in Nuremberg, Germany? Give me 3 Tips'

const stream = hf.textGenerationStream({ inputs: prompt, parameters: gen_kwargs })
for await (const r of stream) {
  // # skip special tokens
  if (r.token.special) {
    continue
  }
  // stop if we encounter a stop sequence
  if (gen_kwargs['stop_sequences'].includes(r.token.text)) {
    break
  }
  // yield the generated token
  process.stdout.write(r.token.text)
}
```

把 `process.stdout` 调用换成 `yield` 或你想把 token 流向过去的函数。

[![Javascript Streaming](https://huggingface.co/blog/assets/155_inference_endpoints_llm/js-stream.gif)](https://huggingface.co/blog/assets/155_inference_endpoints_llm/js-stream.gif)

## 结论

在这篇博文中，我们演示了如何用 Hugging Face Inference Endpoints 部署开源 LLM、如何用高级参数控制文本生成，以及如何把响应流式传给 Python 或 JavaScript 客户端以改善体验。使用 Hugging Face Inference Endpoints，你可以几次点击就把模型部署成生产级 API、用自动 scale-to-zero 降低成本，并把模型部署进有 SOC2 Type 2 认证背书的安全离线端点。
