# Hugging Face 与 AMD 合作，为 CPU 和 GPU 平台加速最先进模型

无论是语言模型、大语言模型还是基础模型，transformer 在预训练、微调和推理时都需要大量计算。为帮助开发者和组织用基础设施预算换来最多的性能，Hugging Face 长期以来一直与硬件公司合作，充分利用各自芯片上的加速特性。

今天，我们高兴地宣布 AMD 正式加入我们的[硬件合作伙伴计划](https://huggingface.co/hardware)。我们的 CEO Clément Delangue 在 AMD 于旧金山举办的[数据中心与 AI 技术首发活动](https://www.amd.com/en/solutions/data-center/data-center-ai-premiere.html)上发表主题演讲，启动这一激动人心的新合作。

AMD 与 Hugging Face 携手在 AMD CPU 和 GPU 上实现最先进的 transformer 性能。这一合作对整个 Hugging Face 社区都是极好的消息——社区很快就能受益于用于训练和推理的最新 AMD 平台。

多年来，深度学习硬件的选择一直很有限，价格和供应也日益成为隐忧。这项新合作不仅将赶上竞争对手，还有助于缓解市场动态带来的压力：它应当树立新的性价比标杆。

## 受支持的硬件平台

在 GPU 方面，AMD 与 Hugging Face 将首先在面向企业的 Instinct MI2xx 和 MI3xx 系列上合作，随后是面向消费者的 Radeon Navi3x 系列。在初期测试中，AMD [近期报告](https://youtu.be/mPrfh7MNV_0?t=462)称，MI250 训练 BERT-Large 快 1.2 倍、训练 GPT2-Large 快 1.4 倍，领先其直接竞争对手。

在 CPU 方面，两家公司将合作优化客户端 Ryzen 和服务器 EPYC CPU 的推理。正如此前几篇文章所讨论的，CPU 对于 transformer 推理可以是很好的选择，尤其是在结合量化等模型压缩技术时。

最后，本次合作还将涵盖 [Alveo V70](https://www.xilinx.com/applications/data-center/v70.html) AI 加速器，它能以更低的功耗需求带来惊人的性能。

## 受支持的模型架构与框架

我们计划支持用于自然语言处理、计算机视觉和语音的最先进 transformer 架构，例如 BERT、DistilBERT、ROBERTA、Vision Transformer、CLIP 和 Wav2Vec2。当然，生成式 AI 模型也会提供（如 GPT2、GPT-NeoX、T5、OPT、LLaMA），包括我们自己的 BLOOM 和 StarCoder 模型。最后，我们还将支持更传统的计算机视觉模型（如 ResNet 和 ResNext）以及深度学习推荐模型——这对我们来说尚属首次。

我们会尽力在上述平台上为 PyTorch、TensorFlow 和 ONNX Runtime 测试并验证这些模型。请记住，并非所有模型都能在所有框架或所有硬件平台上同时用于训练和推理。

## 未来之路

我们最初的重点是确保对我们社区最重要的模型在 AMD 平台上开箱即用表现出色。我们将与 AMD 工程团队紧密合作，借助最新的 AMD 硬件与软件特性优化关键模型以实现最佳性能。我们会将 [AMD ROCm SDK](https://www.amd.com/graphics/servers-solutions-rocm) 无缝集成进我们的开源库，从 transformers 库开始。

在此过程中，我们无疑会发现进一步优化训练与推理的机会，并将与 AMD 紧密协作，以确定在这项合作中未来投入的最佳方向。我们预期这项工作将催生一个面向 AMD 平台的新 [Optimum](https://huggingface.co/docs/optimum/index) 库，帮助 Hugging Face 用户以尽可能少（甚至无需）代码改动来利用这些平台。
