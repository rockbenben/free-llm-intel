# CO2 排放与 🤗 Hub：扛起先行大旗

## 什么是 CO2 排放？为什么它很重要？

气候变化是我们面临的最大挑战之一，减少二氧化碳（CO2）等温室气体的排放是应对这一问题的重要环节。

训练和部署机器学习模型会因所用计算基础设施的能耗而产生 CO2：从 GPU 到存储，一切都需要能量才能运行，并在此过程中排放 CO2。

[![Image of recent Transformer models and their carbon footprints](https://huggingface.co/blog/assets/60_carbon_emissions_on_the_hub/transformer_carbon_footprints.png)](https://huggingface.co/blog/assets/60_carbon_emissions_on_the_hub/transformer_carbon_footprints.png)

> 图中：近期发布的 Transformer 模型及其碳足迹

CO2 排放量的多少取决于多种因素，例如运行时间、所用硬件，以及能源的碳排放强度。

使用下文介绍的工具，既能帮助你追踪并报告自己的排放量（这对提升我们整个领域的透明度至关重要！），也能帮助你依据碳足迹来选择模型。

## 如何用 Transformers 自动计算你自己的 CO2 排放


## 如何使用 Hugging Face Hub 查找低排放模型

模型现在已上传到 Hub，那么如何在 Hub 上搜索模型的同时兼顾环保呢？`huggingface_hub` 库新增了一个专门用于此搜索的特殊参数：`emissions_threshold`。你只需指定克数的下限或上限，就能得到所有落在该范围内的模型。

例如，我们可以搜索训练排放最多为 100 克的所有模型：

```
from huggingface_hub import HfApi

api = HfApi()
models = api.list_models(emissions_thresholds=(None, 100), cardData=True)
len(models)
>>> 191
```

还真不少！这也有助于找到更小的模型，因为它们在训练过程中通常不会释放那么多碳。

我们可以仔细看看其中一个，确认它确实符合我们的阈值：

```
model = models[0]
print(f'Model Name: {model.modelId}\nCO2 Emitted during training: {model.cardData["co2_eq_emissions"]}')

>>> Model Name: esiebomajeremiah/autonlp-email-classification-657119381
    CO2 Emitted during training: 3.516233232503715
```

类似地，我们也可以搜索一个下限值，找出训练期间排放大量 CO2 的超大模型：

```
models = api.list_models(emissions_thresholds=(500, None), cardData=True)
len(models)
>>> 10
```

现在来看看其中一个具体排放了多少 CO2：

```
model = models[0]
print(f'Model Name: {model.modelId}\nCO2 Emitted during training: {model.cardData["co2_eq_emissions"]}')

>>> Model Name: Maltehb/aelaectra-danish-electra-small-cased
    CO2 Emitted during training: 4009.5
```

这可是相当多的 CO2！

如你所见，只需几行代码，我们就能快速筛查准备使用的模型，确保自己做到了环保自觉！

## 如何用 `transformers` 报告你的碳排放

如果你使用 `transformers`，借助 `codecarbon` 集成，你可以自动追踪并报告碳排放。只要你的机器上安装了 `codecarbon`，`Trainer` 对象就会在训练时自动加上 `CodeCarbonCallback`，在你训练的过程中为你存储碳排放数据。

因此，如果你运行类似这样的代码……

```
from datasets import load_dataset
from transformers import AutoModelForSequenceClassification, AutoTokenizer, Trainer, TrainingArguments
​
ds = load_dataset("imdb")
model = AutoModelForSequenceClassification.from_pretrained("bert-base-cased", num_labels=2)
tokenizer = AutoTokenizer.from_pretrained("bert-base-cased")
​
def tokenize_function(examples):
    return tokenizer(examples["text"], padding="max_length", truncation=True)
​
​
small_train_dataset = ds["train"].shuffle(seed=42).select(range(1000)).map(tokenize_function, batched=True)
small_eval_dataset = ds["test"].shuffle(seed=42).select(range(1000)).map(tokenize_function, batched=True)
​
​
training_args = TrainingArguments(
    "codecarbon-text-classification",
    num_train_epochs=4,
    push_to_hub=True
)
​
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=small_train_dataset,
    eval_dataset=small_eval_dataset,
)
​
trainer.train()
```

……你会在 `codecarbon-text-classification` 目录下得到一个名为 `emissions.csv` 的文件。该文件会记录不同训练运行的碳排放。然后，在你准备好之后，可以把用于训练最终模型的那次运行的排放数据写入它的模型卡（model card）。📝

下面是一个把这些数据写入模型卡顶部的示例：

[![Visual of organizing the co2_eq_emissions in a Model Card file](https://huggingface.co/blog/assets/60_carbon_emissions_on_the_hub/metadata_example.png)](https://huggingface.co/blog/assets/60_carbon_emissions_on_the_hub/metadata_example.png)

关于 `co2_eq_emissions ` 元数据格式的更多参考，请查看 [Hub 文档](https://huggingface.co/docs/hub/model-cards-co2)。
