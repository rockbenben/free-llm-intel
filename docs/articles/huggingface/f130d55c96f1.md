**本指南演示如何用 [`🤗 transformers`](https://huggingface.co/transformers) 使用 [CLIPSeg](https://huggingface.co/docs/transformers/main/en/model_doc/clipseg)——一个零样本图像分割模型。CLIPSeg 生成的粗略分割掩码可用于机器人感知、图像修复（inpainting）等众多任务。如果你需要更精确的分割掩码，我们也会演示如何在 [Segments.ai](https://segments.ai/?utm_source=hf&utm_medium=blog&utm_campaign=clipseg) 上打磨 CLIPSeg 的结果。**

图像分割是计算机视觉领域的一个经典任务。它让计算机不仅知道图像里有什么（分类）、物体在哪里（检测），还知道这些物体的轮廓是什么。掌握物体轮廓对机器人、自动驾驶等领域至关重要。例如，机器人必须知道物体的形状才能正确抓取。分割还可以与[图像修复](https://t.co/5q8YHSOfx7)结合，让用户用文字描述想替换图像的哪一部分。

大多数图像分割模型的一个局限是：只能处理固定类别列表。比如，你没法把在一个橙子上训练的分割模型直接拿来分割苹果。要给分割模型教一个新类别，就得标注新类别数据、再训练一个新模型，既贵又费时。但如果有一个模型不用任何额外训练就能分割几乎任何物体呢？这正是零样本分割模型 [CLIPSeg](https://arxiv.org/abs/2112.10003) 做到的事。

目前 CLIPSeg 仍有局限。比如模型使用 352 x 352 像素的图像，输出分辨率相当低。这意味着处理现代相机拍摄的图片时，不能指望像素级的结果。若要更精确的分割，可以微调一个最先进的分割模型，如[我们之前的博客](https://huggingface.co/blog/fine-tune-segformer)所示。那种情况下，也可以先用 CLIPSeg 生成粗略标签，再到 [Segments.ai](https://segments.ai/?utm_source=hf&utm_medium=blog&utm_campaign=clipseg) 这类标注工具里精修。在介绍怎么做之前，先看看 CLIPSeg 的原理。

## CLIP：CLIPSeg 背后的魔法模型

[CLIP](https://huggingface.co/docs/transformers/main/en/model_doc/clip)（**C**ontrastive **L**anguage–**I**mage **P**re-training，对比语言-图像预训练）是 OpenAI 在 2021 年开发的模型。你给它一张图或一段文字，它会输出输入的抽象*表示*。这个抽象表示也叫*嵌入（embedding）*，其实就是一个向量（一串数字），可以想成高维空间中的一个点。CLIP 的训练目标是让相似图片和文字的表示彼此相似。也就是说，如果输入一张图和一个与它匹配的文字描述，图像和文本的表示会很接近（高维空间中的两点靠得很近）。

起初这看起来没什么用，实际上却非常强大。举个例子，看 CLIP 如何从未经过分类任务训练就能给图像分类：分类时，把图像和想要选择的各个类别一起输入 CLIP（比如输入一张图和 "apple"、"orange" 这些词）。CLIP 会返回图像的嵌入和每个类别的嵌入。接下来只需检查哪个类别嵌入离图像嵌入最近，et voilà！是不是像魔法一样？

更厉害的是，CLIP 不只能分类，还能用于[图像搜索](https://huggingface.co/spaces/DrishtiSharma/Text-to-Image-search-using-CLIP)（能看出这和分类很像吗？）、[文生图模型](https://huggingface.co/spaces/kamiyamai/stable-diffusion-webui)（[DALL-E 2](https://openai.com/dall-e-2/) 就基于 CLIP）、目标检测（[OWL-ViT](https://arxiv.org/abs/2205.06230)），以及对我们最重要的：图像分割。现在你明白为什么 CLIP 是机器学习的真正突破了。

CLIP 效果好的原因，是它在海量带文字说明的图像数据集上训练。数据集包含多达 4 亿个取自网络的图像-文本对。这些图像覆盖各种各样的物体和概念，CLIP 能为其中每一种创建出色的表示。

## CLIPSeg：用 CLIP 做图像分割

[CLIPSeg](https://arxiv.org/abs/2112.10003) 是一个利用 CLIP 表示生成分割掩码的模型，由 Timo Lüddecke 和 Alexander Ecker 发表。他们在冻结的 CLIP 模型之上训练了一个基于 Transformer 的解码器，实现了零样本图像分割。解码器接收两张输入：待分割图像的 CLIP 表示，以及你想分割的目标的 CLIP 表示，然后生成二值分割掩码。更准确地说，解码器不只用待分割图像的最终 CLIP 表示，还使用了 CLIP 部分层的输出。

Source

解码器在 [PhraseCut 数据集](https://arxiv.org/abs/2008.01187)上训练，该数据集包含超过 34 万个短语及其对应的图像分割掩码。作者还尝试了各种数据增广来扩充数据集规模。目标不仅是分割数据集中出现的类别，还要能分割从未见过的类别。实验确实表明解码器可以泛化到未见类别。

CLIPSeg 的一个有趣特性是：查询（待分割图像）和提示词（图像中想分割的目标）都以 CLIP 嵌入的形式输入。提示词的 CLIP 嵌入既可以来自一段文字（类别名），**也可以来自另一张图**。这意味着你可以拿一张橙子的示例图，让 CLIPSeg 在照片里分割橙子。

这个叫"视觉提示（visual prompting）"的技巧，在你想分割的东西难以描述时特别有用。比如想分割 T 恤照片上的 logo，很难描述它的形状，而 CLIPSeg 让你直接把 logo 的图当提示词就行。

CLIPSeg 论文里有一些提升视觉提示效果的技巧。他们发现裁剪查询图像（让它只包含你想分割的物体）帮助很大；把查询图像背景虚化和调暗也有一点帮助。下一节我们用 [`🤗 transformers`](https://huggingface.co/transformers) 亲自动手试视觉提示。

## 在 Hugging Face Transformers 中使用 CLIPSeg

用 Hugging Face Transformers 可以方便地下载预训练 CLIPSeg 模型并跑在你的图像上。先安装 transformers。

```
!pip install -q transformers
```

下载模型只需实例化即可。

```
from transformers import CLIPSegProcessor, CLIPSegForImageSegmentation

processor = CLIPSegProcessor.from_pretrained("CIDAS/clipseg-rd64-refined")
model = CLIPSegForImageSegmentation.from_pretrained("CIDAS/clipseg-rd64-refined")
```

现在加载一张图片来试分割。我们选 [Calum Lewis](https://unsplash.com/@calumlewis) 拍的一张诱人的早餐照。

```
from PIL import Image
import requests

url = "https://unsplash.com/photos/8Nc_oQsc2qQ/download?ixid=MnwxMjA3fDB8MXxhbGx8fHx8fHx8fHwxNjcxMjAwNzI0&force=true&w=640"
image = Image.open(requests.get(url, stream=True).raw)
image
```

### 文本提示

先定义几个想要分割的文本类别。

```
prompts = ["cutlery", "pancakes", "blueberries", "orange juice"]
```

输入准备好了，进行预处理并喂给模型。

```
import torch

inputs = processor(text=prompts, images=[image] * len(prompts), padding="max_length", return_tensors="pt")
# predict
with torch.no_grad():
  outputs = model(**inputs)
preds = outputs.logits.unsqueeze(1)
```

最后可视化输出。

```
import matplotlib.pyplot as plt

_, ax = plt.subplots(1, len(prompts) + 1, figsize=(3*(len(prompts) + 1), 4))

[ax[i+1].imshow(torch.sigmoid(preds[i][0])) for i in range(len(prompts))];
[ax[i+1].text(0, -15, prompt) for i, prompt in enumerate(prompts)];
```

## 用 CLIPSeg 在 Segments.ai 上做预标注

可以看到，CLIPSeg 的结果有点模糊、分辨率很低。想获得更好的效果，可以微调一个最先进的分割模型，如[我们上一篇博客](https://huggingface.co/blog/fine-tune-segformer)所讲。微调需要带标签的数据。本节演示如何用 CLIPSeg 生成粗略分割掩码，再到带智能分割标注工具的 [Segments.ai](https://segments.ai/?utm_source=hf&utm_medium=blog&utm_campaign=clipseg) 上精修。

首先到 [https://segments.ai/join](https://segments.ai/join?utm_source=hf&utm_medium=blog&utm_campaign=clipseg) 注册账号并安装 Segments Python SDK，然后用 API key 初始化 Segments.ai Python 客户端。key 可在[账号页面](https://segments.ai/account?utm_source=hf&utm_medium=blog&utm_campaign=clipseg)找到。

```
!pip install -q segments-ai
```

```
from segments import SegmentsClient
from getpass import getpass

api_key = getpass('Enter your API key: ')
segments_client = SegmentsClient(api_key)
```

接下来用 Segments 客户端从数据集中加载一张图像。我们用 [a2d2 自动驾驶数据集](https://www.a2d2.audi/a2d2/en.html)。也可以按[这些说明](https://docs.segments.ai/tutorials/getting-started?utm_source=hf&utm_medium=blog&utm_campaign=clipseg)创建自己的数据集。

```
samples = segments_client.get_samples("admin-tobias/clipseg")

# Use the last image as an example
sample = samples[1]
image = Image.open(requests.get(sample.attributes.image.url, stream=True).raw)
image
```

还需要从数据集属性里拿到类别名。

```
dataset = segments_client.get_dataset("admin-tobias/clipseg")
category_names = [category.name for category in dataset.task_attributes.categories]
```

现在可以照旧对图像使用 CLIPSeg。这次还会把输出放大到与输入图像相同的尺寸。

```
from torch import nn

inputs = processor(text=category_names, images=[image] * len(category_names), padding="max_length", return_tensors="pt")

# predict
with torch.no_grad():
  outputs = model(**inputs)

# resize the outputs
preds = nn.functional.interpolate(
    outputs.logits.unsqueeze(1),
    size=(image.size[1], image.size[0]),
    mode="bilinear"
)
```

再次可视化结果。

```
len_cats = len(category_names)
_, ax = plt.subplots(1, len_cats + 1, figsize=(3*(len_cats + 1), 4))
[a.axis('off') for a in ax.flatten()]
ax[0].imshow(image)
[ax[i+1].imshow(torch.sigmoid(preds[i][0])) for i in range(len_cats)];
[ax[i+1].text(0, -15, category_name) for i, category_name in enumerate(category_names)];
```

接着要把各预测合并成一张分割图。做法很直接：每个像素块取 sigmoid 值最大的类别，同时把所有低于某个阈值的值排除。

```
threshold = 0.1

flat_preds = torch.sigmoid(preds.squeeze()).reshape((preds.shape[0], -1))

# Initialize a dummy "unlabeled" mask with the threshold
flat_preds_with_treshold = torch.full((preds.shape[0] + 1, flat_preds.shape[-1]), threshold)
flat_preds_with_treshold[1:preds.shape[0]+1,:] = flat_preds

# Get the top mask index for each pixel
inds = torch.topk(flat_preds_with_treshold, 1, dim=0).indices.reshape((preds.shape[-2], preds.shape[-1]))
```

快速可视化一下结果。

```
plt.imshow(inds)
```

最后，把预测上传到 Segments.ai。步骤是：先把位图转成 png 文件，再把文件上传到 Segments，最后把标签添加到该 sample。

```
from segments.utils import bitmap2file
import numpy as np

inds_np = inds.numpy().astype(np.uint32)
unique_inds = np.unique(inds_np).tolist()
f = bitmap2file(inds_np, is_segmentation_bitmap=True)

asset = segments_client.upload_asset(f, "clipseg_prediction.png")

attributes = {
      'format_version': '0.1',
      'annotations': [{"id": i, "category_id": i} for i in unique_inds if i != 0],
      'segmentation_bitmap': { 'url': asset.url },
  }

segments_client.add_label(sample.uuid, 'ground-truth', attributes)
```

看看[上传到 Segments.ai 的预测](https://segments.ai/admin-tobias/clipseg/samples/71a80d39-8cf3-4768-a097-e81e0b677517/ground-truth)，它并不完美。但你可以手动修正最明显的错误，然后用修正后的数据集训练一个比 CLIPSeg 更好的模型。

## 结论

CLIPSeg 是一个同时支持文本和图像提示的零样本分割模型。它在 CLIP 上加了一个解码器，几乎能分割任何东西。不过目前输出的分割掩码分辨率还很低，如果对精度有要求，多半仍需要微调另一个分割模型。

注意，零样本分割领域还有更多研究正在进行，后续会有更多模型加入。例如 [GroupViT](https://huggingface.co/docs/transformers/model_doc/groupvit) 已经在 🤗 Transformers 中可用。想了解分割研究的最新动态，可以在 Twitter 上关注我们：[@TobiasCornille](https://twitter.com/tobiascornille)、[@NielsRogge](https://twitter.com/nielsrogge) 和 [@huggingface](https://twitter.com/huggingface)。

如果想学习如何微调一个最先进的分割模型，请看我们之前的博客：[https://huggingface.co/blog/fine-tune-segformer](https://huggingface.co/blog/fine-tune-segformer)。
