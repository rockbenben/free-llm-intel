[CWE-bench](https://cwe-bench.com/) 旨在测试前沿网络能力的极限。 In our continued pursuit to push the horizon at [Collinear AI](https://collinear.ai/), CWE-bench v2 opens up a [public set of 100 tasks](https://huggingface.co/datasets/collinear-ai/cwe-bench) that anyone can run and evaluate their models on.设置与以前相同。 An agent gets a checkout of a real open-source repository and a short instruction, with the goal of finding and fixing a security weakness without breaking existing functionality.评分是完全程序化的，因此结果是确定性的，任何人都可以重现它们，而无需额外成本。我们所有的程序性检查都是在LLM评审小组的帮助下策划的，这些评审小组将它们朝着硬度和公平的方向发展。我们还维护一个[held-out set](https://www.cwebench.com)，以便我们可以持续跟踪模型未见过的任务的进度。要在保留集上评估您的模型，请联系 [cyber@collinear.ai](mailto:cyber@collinear.ai)。

我们的目标是详尽无遗。防守者必须预测攻击者可能进入的方式，并每次都做到正确。这 100 项任务涵盖 91 个不同的 CWE，涵盖广泛的漏洞类别。在这里表现良好的模型必须了解潜在攻击者可以利用的多个弱点。仅仅认识到熟悉的模式是不够的。

作为我们不断提高质量的不懈努力的一部分，对于每项任务，我们都会检查以下问题是否正确：

- 该说明读起来是否像真实的说明而不是评估设置？
- 每个分级行为都可以从指令中推断出来吗？
- 验证者是否检查行为是否正确，而不是检查某个修复的特定结构？
- 起始代码是否失败而参考修复是否通过？
- 原始功能在新修复后是否仍然有效？
- 验证者是否会失败记忆的解决方案，例如已知的上游补丁？

每项任务也都经过手工审核。开源该套件也是提高质量努力的一部分。我们欢迎对任何任务的反馈以及对公共集的贡献。

## 从集线器运行它

每个任务都是一个独立的 [Harbor](https://harborframework.com/) 任务（一个 Docker 化环境、一条指令和一个确定性验证器），并且数据集附带一个 `registry.json`。因此，Harbor 可以直接从 Hugging Face 存储库运行整个基准测试，而无需自己克隆任何内容：
```
harbor run --repo "https://huggingface.co/datasets/collinear-ai/cwe-bench" -d cwe-bench@2.0 -k 4 \
  --agent <agent> --model <model> --env docker \
  --allow-agent-host <model API host>
```
`-k 4` 每个任务运行 4 次尝试，报告的分数是所有 400 次试验的平均奖励。数据集是门控的：首先在[数据集页面](https://huggingface.co/datasets/collinear-ai/cwe-bench)上接受其访问条件。 Harbor 使用 git 获取任务，因此也将您的 HF 令牌保存到 git 的凭证助手一次：
```
hf auth login --token $HF_TOKEN --add-to-git-credential
```
这些任务也被标记为“rl-environment”：相同的环境和验证者可以为训练防御代理提供奖励，而不仅仅是评估它们。
