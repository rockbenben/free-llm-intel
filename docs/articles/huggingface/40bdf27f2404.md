# 介绍 🤗 Accelerate

## 🤗 Accelerate

在你的**原始** PyTorch 训练脚本上运行任意类型的设备。

PyTorch 之上的大多数高层库都支持分布式训练和混合精度，但它们引入的抽象要求用户在学习新 API 之后才能定制底层训练循环。🤗 Accelerate 是为那些喜欢对训练循环拥有完全控制权、却不愿编写（并维护）使用分布式训练（单节点或多节点的多 GPU、TPU 等）或混合精度训练所需的样板代码的 PyTorch 用户而创建的。后续计划包括支持 fairscale、deepspeed、AWS SageMaker 特有的数据并行和模型并行。

它提供两样东西：一个抽象掉样板代码的简单而一致的 API，以及一个启动器命令，用来轻松地在各种配置上运行这些脚本。

### 轻松集成！

我们先来看一个例子：

```
  import torch
  import torch.nn.functional as F
  from datasets import load_dataset
+ from accelerate import Accelerator

+ accelerator = Accelerator()
- device = 'cpu'
+ device = accelerator.device

  model = torch.nn.Transformer().to(device)
  optim = torch.optim.Adam(model.parameters())

  dataset = load_dataset('my_dataset')
  data = torch.utils.data.DataLoader(dataset, shuffle=True)

+ model, optim, data = accelerator.prepare(model, optim, data)

  model.train()
  for epoch in range(10):
      for source, targets in data:
          source = source.to(device)
          targets = targets.to(device)

          optimizer.zero_grad()

          output = model(source)
          loss = F.cross_entropy(output, targets)

-         loss.backward()
+         accelerator.backward(loss)

          optimizer.step()
```

只需往任何标准 PyTorch 训练脚本中添加五行的代码，你现在就能在任意类型的分布式设置上运行该脚本，也能选择开启或关闭混合精度。🤗 Accelerate 甚至替你处理设备放置，于是你可以把上面的训练循环进一步简化：


相比之下，要让这段代码在分布式训练下运行所需的改动如下：

```
+ import os
  import torch
  import torch.nn.functional as F
  from datasets import load_dataset
+ from torch.utils.data import DistributedSampler
+ from torch.nn.parallel import DistributedDataParallel

+ local_rank = int(os.environ.get("LOCAL_RANK", -1))
- device = 'cpu'
+ device = device = torch.device("cuda", local_rank)

  model = torch.nn.Transformer().to(device)
+ model = DistributedDataParallel(model)  
  optim = torch.optim.Adam(model.parameters())

  dataset = load_dataset('my_dataset')
+ sampler = DistributedSampler(dataset)
- data = torch.utils.data.DataLoader(dataset, shuffle=True)
+ data = torch.utils.data.DataLoader(dataset, sampler=sampler)

  model.train()
  for epoch in range(10):
+     sampler.set_epoch(epoch)  
      for source, targets in data:
          source = source.to(device)
          targets = targets.to(device)

          optimizer.zero_grad()

          output = model(source)
          loss = F.cross_entropy(output, targets)

          loss.backward()

          optimizer.step()
```

这些改动会让你的训练脚本在多个 GPU 上工作，但你的脚本随后就无法在 CPU 或单个 GPU 上工作了（除非你开始到处添加 if 语句）。更烦人的是，如果你想在 TPU 上测试你的脚本，你就得改动不同的代码行。混合精度训练也一样。🤗 Accelerate 的承诺是：

- 把对你训练循环的改动保持到最低限度，好让你学尽量少的东西。
- 让同样的函数适用于任何分布式配置，好让你只需学一个 API。

### 它是怎么工作的？

要看这个库在实践中如何工作，我们逐一查看需要往训练循环中添加的每一行代码。

```
accelerator = Accelerator()
```

除了给你将使用的主对象之外，这一行会从环境中分析分布式训练运行的类型并执行必要的初始化。你可以通过向这个构造函数传入 `cpu=True` 或 `fp16=True` 来强制在 CPU 上训练或进行混合精度训练。这两个选项也可以通过脚本的启动器来设置。

```
model, optim, data = accelerator.prepare(model, optim, data)
```

这是 API 的主体部分，它会准备三类主要对象：模型（`torch.nn.Module`）、优化器（`torch.optim.Optimizer`）和数据加载器（`torch.data.dataloader.DataLoader`）。

#### 模型

模型准备工作包括把它包装进合适的容器（例如 `DistributedDataParallel`），并把它放到合适的设备上。和常规分布式训练一样，你需要为保存、或访问其特定方法而解包你的模型，这可以用 `accelerator.unwrap_model(model)` 完成。

#### 优化器

优化器也被包装进一个特殊容器，它会在 step 中执行必要的操作以使混合精度工作。如果其 state dict 非空或从检查点加载，它还会妥善处理设备放置。

#### 数据加载器

这是大部分魔法隐藏之处。如你在代码示例中所见，这个库不依赖 `DistributedSampler`，它实际上能与你传给数据加载器的任何采样器配合工作（如果你曾经不得不为你自定义的采样器写一个分布式版本，现在不再需要了！）。数据加载器被包装进一个容器，它只抓取采样器中与当前进程相关的索引（如果你使用 `IterableDataset`，则跳过其他进程的批次），并把批次放到合适的设备上。

为了做到这点，Accelerate 提供了一个实用函数，它会同步分布式训练期间运行的各个进程上的随机数生成器。默认情况下，它只同步你采样器的 `generator`，所以你的数据增强在每个进程上会有所不同，但随机打乱是相同的。当然，如果你需要，也可以用这个工具来同步更多的 RNG。

```
accelerator.backward(loss)
```

这最后一行添加了反向传播所需的步骤（主要是为了混合精度，但其他集成在这里也需要一些自定义行为）。

### 评估怎么办？

评估可以在所有进程上照常运行，或者如果你只想在主进程上运行，你可以使用这个方便的测试：

```
if accelerator.is_main_process():
    # Evaluation loop
```

但你也能用 Accelerate 非常容易地运行分布式评估，下面就是你需要往评估循环中添加的内容：

```
+ eval_dataloader = accelerator.prepare(eval_dataloader)
  predictions, labels = [], []
  for source, targets in eval_dataloader:
      with torch.no_grad():
          output = model(source)

-     predictions.append(output.cpu().numpy())
-     labels.append(targets.cpu().numpy())
+     predictions.append(accelerator.gather(output).cpu().numpy())
+     labels.append(accelerator.gather(targets).cpu().numpy())

  predictions = np.concatenate(predictions)
  labels = np.concatenate(labels)

+ predictions = predictions[:len(eval_dataloader.dataset)]
+ labels = label[:len(eval_dataloader.dataset)]

  metric_compute(predictions, labels)
```

和训练一样，你需要添加一行来准备你的评估数据加载器。然后你可以直接用 `accelerator.gather` 来跨进程收集预测和标签的张量。最后要添加的一行把预测和标签截断到你数据集中的样本数，因为准备好的评估数据加载器会多返回几个元素，以确保每个进程上的批次都有相同的大小。

### 一个统御所有的启动器

使用 Accelerate 的脚本与你的传统启动器（例如 `torch.distributed.launch`）完全兼容。但记住它们所有的参数有点烦人，而当你配置好一个有 4 块 GPU 的实例后，你会用全部 GPU 来跑大多数训练。Accelerate 附带一个实用的 CLI，分两步工作：

```
accelerate config
```

这会触发一个关于你配置的小问卷，它会创建一个配置文件，你可以用它来编辑你的训练命令的所有默认值。然后

```
accelerate launch path_to_script.py --args_to_the_script
```

会用那些默认值启动你的训练脚本。你唯一要做的就是提供你的训练脚本所需的所有参数。

要让这个启动器更出色，你可以用它通过 SageMaker 生成一个 AWS 实例。查看[这份指南](https://huggingface.co/docs/accelerate/sagemaker.html)了解怎么做！

### 如何参与？

要开始，只需 `pip install accelerate`，或查看更多安装选项请参阅[文档](https://huggingface.co/docs/accelerate/installation.html)。

Accelerate 是一个完全开源的项目，你可以在 [GitHub](https://github.com/huggingface/accelerate) 上找到它、查看它的[文档](https://huggingface.co/docs/accelerate/)，或浏览我们的[基础示例](https://github.com/huggingface/accelerate/tree/main/examples)。如果你遇到任何问题或希望这个库支持的某个特性，请告诉我们。所有问题，[论坛](https://discuss.huggingface.co/c/accelerate) 是该去查看的地方！

要看更复杂的情境示例，你可以查看官方的 [Transformers 示例](https://github.com/huggingface/transformers/tree/master/examples)。每个文件夹都包含一个利用 Accelerate 库的 `run_task_no_trainer.py`！
