# 在 DeepResearch Bench 上测评开源 Llama Nemotron 模型

**贡献者：** David Austin, Raja Biswas, Gilberto Titericz Junior, NVIDIA

[NVIDIA 的 AI-Q Blueprint](https://build.nvidia.com/nvidia/aiq)——这款领先的、可移植的开源深度研究 agent——近期攀升至 [Hugging Face「LLM with Search」榜单（DeepResearch Bench）](https://huggingface.co/spaces/Ayanami0730/DeepResearch-Leaderboard)的榜首。这是开源 AI 技术栈的重要进步，证明开发者可及的模型同样能驱动与闭源方案匹敌甚至更强的先进 agentic 工作流。

AI-Q 的特别之处是什么？它融合了两个高性能开源 LLM——Llama 3.3-70B Instruct 与 Llama-3.3-Nemotron-Super-49B-v1.5——来统筹长上下文检索、agentic 推理与稳健的综合。

## 核心技术栈：模型选择与技术创新

- [Llama 3.3-70B Instruct](https://build.nvidia.com/meta/llama-3_3-70b-instruct)：源自 Meta 的 Llama 系列、采用开放许可证可无限制部署，是流畅、结构化报告生成的基础。
- [Llama-3.3-Nemotron-Super-49B-v1.5](https://build.nvidia.com/nvidia/llama-3_3-nemotron-super-49b-v1_5)：针对推理优化的精简变体。通过神经架构搜索（NAS）、知识蒸馏以及多轮监督学习和强化学习构建，擅长多步推理、query 规划、工具调用与反思——且显存占用更小，可在标准 GPU 上高效部署。

**AI-Q 参考示例还包含**：

- [NVIDIA NeMo Retriever](https://build.nvidia.com/explore/retrieval)：用于可扩展的多模态检索（内部+外部）。
- [NVIDIA NeMo Agent toolkit](https://developer.nvidia.com/nemo-agent-toolkit)：用于编排复杂的多步 agentic 工作流。

该架构支持对本地数据和网页数据进行并行、低延迟检索，非常适合有隐私、合规要求，或为降低延迟需要本地部署的用例。

## 用 Llama Nemotron 进行深度推理

NVIDIA Llama Nemotron Super 不只是一个微调过的 instruct 模型——它经过后训练以获得显式的 agentic 推理能力，并支持通过 system prompt 切换推理 ON/OFF。你可以在标准聊天 LLM 模式下使用它，也可以切换到用于 agent pipeline 的深度 chain-of-thought 推理，实现动态、上下文感知的工作流。

要点：

- **多阶段后训练**：融合指令跟随、数学/程序化推理和工具调用能力。
- **透明的模型谱系**：可直接追溯到 Meta 的开放权重，且在合成数据和调优数据集方面有更高的开放性。
- **效率**：49B 参数、支持最长 128K token 上下文窗口，可在单张 H100 GPU 甚至更小规格上运行，推理成本可预测且速度快。

## 评估：指标的透明与稳健

AI-Q 的核心优势之一是透明——不仅输出透明，推理轨迹和中间步骤同样透明。在开发过程中，NVIDIA 团队同时利用了标准指标和新增指标，例如：

- **幻觉检测**：每个事实性论断在生成时都会被核查。
- **多源综合**：从分散的证据中综合出新见解。
- **引用可信度**：对「论断-证据」关联进行自动评估。
- [**RAGAS**](https://docs.ragas.io/en/latest/concepts/metrics/available_metrics/nvidia_metrics/) 指标：对检索增强生成准确性的自动评分。

该架构非常适合细粒度、按步骤的评估与调试——而这正是 agentic pipeline 开发中最大的痛点之一。

## 基准测试结果：DeepResearch Bench

DeepResearch Bench 用 100 多个长上下文、真实世界的研究任务（覆盖科学、金融、艺术、历史、软件等领域）来评估 agent 技术栈。与传统 QA 不同，这些任务需要报告级别的综合写作和复杂的多跳推理：

- **截至 2025 年 8 月，AI-Q 在「LLM with Search」类别中取得总分 40.52**，目前位居所有完全开放许可技术栈之首。
- **最强指标**：全面性（报告的深度）、洞察力（分析的质量）以及引用质量。

## 写给 Hugging Face 开发者社区

- Llama-3.3-Nemotron-Super-49B-v1.5 与 Llama 3.3-70B Instruct 都可直接在 Hugging Face 上使用/下载。用几行 Python 就能把它们接入你自己的 pipeline，或用 vLLM 部署以获得快速推理和工具调用支持（代码/服务示例见模型卡）。
- 开放的后训练数据、透明的评估方法和宽松的许可证，让实验和复现成为可能。

## 小结

开源生态正在快速缩小差距——在某些领域甚至已经领先——尤其是在真正重要的现实世界 agent 任务上。基于 Llama Nemotron 构建的 AI-Q 证明：要达到最先进的结果，无需在透明度和控制权上妥协。

从 Hugging Face 或 [build.nvidia.com](https://huggingface.co/blog/nvidia/build.nvidia.com) 试用这套技术栈，或把它改造进你自己的研究 agent 项目。
