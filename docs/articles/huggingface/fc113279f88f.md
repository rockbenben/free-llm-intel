🤗 Diffusers 很高兴迎来它的一周年！这是激动人心的一年，我们为在社区和开源贡献者的帮助下所走过的历程感到自豪与感恩。去年，DALL-E 2、Imagen 和 Stable Diffusion 等文本生成图像模型凭借从文本生成惊艳逼真图像的能力吸引了全世界的目光，引发了对生成式 AI 的兴趣与开发热潮。但对这些强大模型的访问却十分有限。

在 Hugging Face，我们的使命是通过协作、互帮互助来民主化优质的机器学习，共同建设一个开放且合乎伦理的 AI 未来。这一使命激励我们创建了 🤗 Diffusers 库，让*每个人*都能试验、研究，或只是玩玩文本生成图像模型。正因如此，我们把该库设计成一个模块化的工具箱，你可以自定义扩散模型的各个组件，也可以开箱即用地直接上手。

在 🤗 Diffusers 满一岁之际，这里概述一下我们在社区帮助下为库添加的一些最值得关注的功能。我们为一个积极推动易用性、把扩散模型拓展到超越纯文本生成图像、并在方方面面给人灵感的活跃社区感到自豪，也深怀感激。

## 追求逼真

生成式 AI 模型以创造逼真图像著称，但如果你仔细观察，会注意到某些看起来不对劲的地方，比如一只手生成出多余的手指。今年，DeepFloyd IF 和 Stability AI 的 SDXL 模型通过进一步提升生成图像的质量使其更加逼真，引起了轰动。

[DeepFloyd IF](https://stability.ai/blog/deepfloyd-if-text-to-image-model) - 一个模块化扩散模型，包含生成图像的不同流程（例如，图像被上采样 3 倍以产生更高分辨率的图像）。与 Stable Diffusion 不同，IF 模型直接在像素层面工作，并使用一个大语言模型来编码文本。

[Stable Diffusion XL (SDXL)](https://stability.ai/blog/sdxl-09-stable-diffusion) - Stability AI 的最新 Stable Diffusion 模型，参数量远超前代 Stable Diffusion 2。它生成超逼真的图像，利用一个基础模型来紧密贴合 prompt，并有一个专注于精细细节和高频内容的 refiner 模型。

现在就前往 DeepFloyd IF 的[文档](https://huggingface.co/docs/diffusers/v0.18.2/en/api/pipelines/if#texttoimage-generation)和 SDXL 的[文档](https://huggingface.co/docs/diffusers/v0.18.2/en/api/pipelines/stable_diffusion/stable_diffusion_xl)，了解如何开始生成你自己的图像吧！

## 视频管线

文本生成图像管线很酷，但文本生成视频更酷！我们目前支持两种文本生成视频管线，[VideoFusion](https://huggingface.co/docs/diffusers/main/en/api/pipelines/text_to_video) 和 [Text2Video-Zero](https://huggingface.co/docs/diffusers/main/en/api/pipelines/text_to_video_zero)。

如果你已经熟悉文本生成图像管线，使用文本生成视频管线非常相似：

```
import torch
from diffusers import DiffusionPipeline
from diffusers.utils import export_to_video

pipe = DiffusionPipeline.from_pretrained("cerspense/zeroscope_v2_576w", torch_dtype=torch.float16)
pipe.enable_model_cpu_offload()

prompt = "Darth Vader surfing a wave"
video_frames = pipe(prompt, num_frames=24).frames
video_path = export_to_video(video_frames)
```

我们预计在 🤗 Diffusers 的第二年里，文本生成视频将经历一场变革，我们很期待看到社区在这些之上构建什么，以拓展从语言生成视频的边界！

## 文本生成 3D 模型

除了文本生成视频，得益于 OpenAI 的 [Shap-E](https://hf.co/papers/2305.02463) 模型，我们现在也支持文本生成 3D。Shap-E 通过对一个庞大的 3D-文本配对数据集进行编码来训练，而一个扩散模型以编码器的输出为条件。你可以为电子游戏、室内设计和建筑设计 3D 资产。

现在就通过 [`ShapEPipeline`](https://huggingface.co/docs/diffusers/main/en/api/pipelines/shap_e#diffusers.ShapEPipeline) 和 [`ShapEImg2ImgPipeline`](https://huggingface.co/docs/diffusers/main/en/api/pipelines/shap_e#diffusers.ShapEImg2ImgPipeline) 试用吧。

## 图像编辑管线

图像编辑是时尚、材料设计和摄影领域中最实用的用例之一。随着扩散模型的出现，图像编辑的可能性不断扩展。

🤗 Diffusers 中有许多支持图像编辑的[管线](https://huggingface.co/docs/diffusers/main/en/using-diffusers/controlling_generation)。有让你把期望的编辑描述为一个 prompt 的图像编辑管线，有从图像中移除概念的方法，甚至还有一套统一多种生成方法、以创造全景图等高质量图像的管线。有了 🤗 Diffusers，你可以现在就试验图像编辑的未来！

## 更快的扩散模型

扩散模型因其迭代步骤而以耗时著称。有了 OpenAI 的 [Consistency Models](https://huggingface.co/papers/2303.01469)（一致性模型），图像生成过程大大加快。在一颗现代 CPU 上生成一张 256x256 分辨率的图像只需四分之三秒！你可以在 🤗 Diffusers 中通过 [`ConsistencyModelPipeline`](https://huggingface.co/docs/diffusers/main/en/api/pipelines/consistency_models) 试用这一点。

在更快的扩散模型之上，我们还提供了许多用于加速推理的优化技术，比如 [PyTorch 2.0 的 `scaled_dot_product_attention()`（SDPA）和 `torch.compile()`](https://pytorch.org/blog/accelerated-diffusers-pt-20)、切片注意力（sliced attention）、前馈分块（feed-forward chunking）、VAE tiling、CPU 与模型卸载（offloading）等等。这些优化节省内存，从而转化为更快的生成，并让你能在消费级 GPU 上运行推理。当你用 🤗 Diffusers 分发一个模型时，所有这些优化都立即得到支持！

除此之外，我们还支持特定的硬件和格式，比如 ONNX、用于 Apple Silicon 计算机的 `mps` PyTorch 设备、Core ML 等。

要了解更多关于我们如何用 🤗 Diffusers 优化推理，请查看[文档](https://huggingface.co/docs/diffusers/optimization/opt_overview)！

## 伦理与安全

生成式模型很酷，但它们也能产有害和 NSFW（不适宜工作场所）内容。为帮助用户负责任且合乎伦理地与这些模型交互，我们添加了一个 [`safety_checker`](https://github.com/huggingface/diffusers/blob/main/src/diffusers/pipelines/stable_diffusion/safety_checker.py) 组件，用于标记推理期间生成的不当内容。模型创作者可以选择是否将此组件纳入他们的模型。

此外，生成式模型也可被用于制造虚假信息。今年早些时候，[Balenciaga 教皇](https://www.theverge.com/2023/3/27/23657927/ai-pope-image-fake-midjourney-computer-generated-aesthetic)尽管是假的，却因图像逼真而走红。这凸显了区分生成内容与人类内容的机制的重要性和需求。正因如此，我们为 SDXL 模型生成的图像添加了一个隐形水印，帮助用户获得更好的知情。

这些功能的开发以我们的[伦理章程](https://huggingface.co/docs/diffusers/main/en/conceptual/ethical_guidelines)为指导，你可以在文档中找到它。

## 对 LoRA 的支持

微调扩散模型成本高昂，对多数消费级 GPU 而言力所不及。我们加入了低秩适配（Low-Rank Adaptation，[LoRA](https://huggingface.co/papers/2106.09685)）技术以弥合这一差距。借助 LoRA——一种参数高效微调方法——你可以更快地微调大型扩散模型并消耗更少内存。相比原模型，得到的模型权重也非常轻量，因此你可以轻松共享自定义模型。如果你想了解更多，[我们的文档](https://huggingface.co/docs/diffusers/main/en/training/lora)展示了如何使用 LoRA 对 Stable Diffusion 进行微调和推理。

除 LoRA 之外，我们还支持其他用于个性化生成的[训练技术](https://huggingface.co/docs/diffusers/main/en/training/overview)，包括 DreamBooth、文本反演（textual inversion）、自定义扩散（custom diffusion）等！

## Torch 2.0 优化

PyTorch 2.0 [引入了对](https://pytorch.org/get-started/pytorch-2.0/#pytorch-2x-faster-more-pythonic-and-as-dynamic-as-ever) `torch.compile()` 和 `scaled_dot_product_attention()`（一种更高效的注意力机制实现）的支持。🤗 Diffusers [为这些功能提供一流支持](https://huggingface.co/docs/diffusers/optimization/torch2.0)，带来推理延迟的大幅加速，有时甚至能快上两倍以上！

除视觉内容（图像、视频、3D 资产等）之外，我们还加入了对音频的支持！查看[文档](https://huggingface.co/docs/diffusers/using-diffusers/audio)了解更多。
