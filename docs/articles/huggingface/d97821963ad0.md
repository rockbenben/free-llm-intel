## Waypoint-1 是什么？

Waypoint-1 是 Overworld 的实时交互式视频扩散模型，可通过文本、鼠标和键盘进行控制与 prompt。你可以给模型一些帧、运行模型，它就会创造一个你可以走入并与之交互的世界。

模型主干是一个帧因果（frame-causal）rectified flow transformer，在 10,000 小时多样化电子游戏画面上训练，并搭配控制输入与文本标注。Waypoint-1 是潜在（latent）模型，意味着它在压缩帧上训练。

现有世界模型的标准做法是拿预训练视频模型，用简短简化的控制输入做微调。相比之下，Waypoint-1 从一开始就围绕交互体验训练。其他模型的控制很简陋：每隔几帧才能移动或旋转一次镜头，且有严重的延迟问题。而 Waypoint-1 在控制方面完全没有限制。你可以用鼠标自由移动镜头、按键盘上任意键，而且全部零延迟。每一帧都以你的控制作为上下文生成。此外，模型运行足够快，即使在消费级硬件上也能提供无缝体验。

## 它是如何训练的？

Waypoint-1 通过 diffusion forcing 预训练——该技术让模型学会根据过去的帧对未来的帧去噪。应用因果注意力掩码，任意帧中的一个 token 只能关注本帧或过去帧的 token，不能关注未来帧。每帧被随机加噪，因此模型学会逐帧独立去噪。推理时可以逐帧对新帧去噪，从而生成一个程序化的新帧流。

虽然 diffusion forcing 提供了一个很强的基线，但随机对所有帧加噪与逐帧自回归 rollout 并不对齐。这种推理不匹配导致误差累积、长 rollout 充满噪声。为解决该问题，我们用 self forcing 做后训练——该技术让模型在与推理行为一致的模式下学习产生逼真输出。通过 DMD 的 self-forcing 还额外带来一次通过程 CFG 和少步去噪的好处。

## 推理库：[WorldEngine](https://github.com/Wayfarer-Labs/world_engine)

[WorldEngine](https://github.com/Wayfarer-Labs/world_engine) 是 Overworld 面向交互式世界模型流式推理的高性能推理库。它提供用纯 Python 构建推理应用的核心工具，针对低延迟、高吞吐、可扩展性和开发简单性优化。运行时循环为交互而生：消费上下文帧图像、键盘/鼠标输入和文本，输出图像帧用于实时流式播放。

Waypoint-1-Small（2.3B）在 5090 上运行时，WorldEngine 能维持约 30,000 token-passes/秒（单次去噪；每帧 256 token），在 4 步时达到 30 FPS、2 步时达到 60 FPS。

性能来自四项针对性优化：

- [AdaLN 特征缓存](https://arxiv.org/html/2412.18911v1)：只要 prompt 条件化与时间步在前后向传播之间不变，就通过缓存复用避免重复的 AdaLN 条件投影。
- [Static Rolling KV Cache + Flex Attention](https://arxiv.org/pdf/2412.05496)
- Matmul 融合：使用融合 QKV 投影的标准推理优化。
- [Torch Compile](https://docs.pytorch.org/docs/stable/generated/torch.compile.html)，采用 `torch.compile(fullgraph=True, mode="max-autotune", dynamic=False)`

```
from world_engine import WorldEngine, CtrlInput

# Create inference engine
engine = WorldEngine("Overworld/Waypoint-1-Small", device="cuda")

# Specify a prompt
engine.set_prompt("A game where you herd goats in a beautiful valley")

# Optional: Force the next frame to be a specific image
img = pipeline.append_frame(uint8_img)  # (H, W, 3)

# Generate 3 video frames conditioned on controller inputs
for controller_input in [
        CtrlInput(button={48, 42}, mouse=[0.4, 0.3]),
        CtrlInput(mouse=[0.1, 0.2]),
        CtrlInput(button={95, 32, 105}),
]:
    img = engine.gen_frame(ctrl=controller_input)
```
