# 用 Claude 和 Hugging Face 生成图像

本文由 shaun smith（evalstate）撰写。

> **TL;DR:** 通过将 Claude 连接到 Hugging Face Spaces，现在可以比以往更轻松地使用最先进的 AI 模型生成细节丰富的图像。本文介绍具体方法和原因，并介绍近期发布的几款模型：它们擅长生成自然图像，或生成包含文本的图像。

> 2025 年 10 月更新：Anthropic 更新 Connector Directory Policy 后，你需要使用 "Add custom connector" 选项，并将 Remote MCP server URL 设置为 https://huggingface.co/mcp?login，才能在 Claude 中使用图像生成和其他 Gradio Spaces。

## 简介

图像生成模型近期的进展提升了生成真实图像和融入高质量文本的能力。通过将这些模型直接连接到 Claude，使用它们也比以往更容易。

这种图像生成方式的优势有：

- AI 可以帮助构建更详细的提示词，从而提升生成图像的质量。
- AI 可以"看到"生成的图像，然后帮助迭代设计和技术细节，直到得到理想结果。
- 可以轻松切换到最新模型，或选择最适合当前需求的模型。

首先，创建一个免费的 [Hugging Face 账号](https://huggingface.co/join)，然后在聊天输入框的 "Search and tools" 菜单中连接 Claude。下方视频展示了所需的完整步骤：

将 Claude 连接到 Hugging Face

在后台，Claude 现在已配置为可以使用 [Hugging Face MCP Server](https://huggingface.co/mcp?login) 提供的工具，从而无缝扩展自身能力。其中包括运行在我们创新的 [ZeroGPU](https://huggingface.co/docs/hub/spaces-zerogpu) 驱动的 Spaces 上的最新 AI 应用。你的 Hugging Face 账号会提供免费额度，可用于调用这些大型且强大的模型。

Claude 连接到 Hugging Face 后，下面将展示如何配置 Claude 可调用的图像生成工具。

## 用 Flux.1 Krea Dev 生成自然图像

[FLUX.1 Krea [dev]](https://huggingface.co/black-forest-labs/FLUX.1-Krea-dev) 旨在消除生成图像中常见的"AI 感"，例如塑料感皮肤、过度饱和的色彩，或过于平滑的纹理。如果你想要看起来像专业摄影师拍摄、而不是由计算机生成的图像，Krea 能提供其他 AI 模型难以做到的真实纹理、自然光照和可信的审美效果。关于他们是如何做到的，可以阅读[他们的博客](https://www.krea.ai/blog/flux-krea-open-source-release)。

Krea 图像生成器示例

若要在 Claude 中使用 **Krea**，前往 [`huggingface.co/mcp/settings`](https://huggingface.co/settings/mcp)，并将 `mcp-tools/FLUX.1-Krea-dev` 添加到你的 "Spaces Tools"。这就是启用 Claude 生成美观、逼真图像所需的全部操作。

在 MCP Settings 中添加 Space

然后，可以在 Claude 中尝试这样的提示词：

> "Use Krea to create an image of a vibrant garden with victorian house".

即可开始生成图像。

## Qwen Image

[Qwen-Image](https://huggingface.co/Qwen/Qwen-Image) 是一个强大的 AI 图像生成器，擅长遵循提示词并准确渲染文本，非常适合设计海报、标识、信息图和营销材料等对文字质量要求较高的内容。关于 Qwen-Image 模型的更多信息，可以阅读他们的[博客文章](https://qwenlm.github.io/blog/qwen-image/)。

Qwen-Image 图像生成器示例

若要使用 **Qwen-Image**，在你的 [MCP Servers 设置](https://huggingface.co/settings/mcp)页面添加 `mcp-tools/qwen-image`，然后确认它已在 Claude 中启用，即可开始使用。

Qwen-Image 自带提示词增强器（Prompt Enhancer），可帮助编写适合该模型的详细提示词。若要试用，可以在提示词菜单中选择 "Qwen Prompt Enhancer"，输入你的想法后提交给 Claude。

在 Claude 中使用 Qwen Prompt Enhancer

你也可以同时启用 Krea 和 Qwen-Image，并让 Claude 同时使用两者来比较结果。例如："Use Krea and Qwen to generate a street scene with 'Hugging Face' graffiti sprayed on the wall"。
