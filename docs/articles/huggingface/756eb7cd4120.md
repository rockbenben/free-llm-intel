## Sentence Transformers 模型如何工作

在 Sentence Transformer 模型中，你把一段变长文本（或图像像素）映射为一个固定大小的嵌入，代表该输入的含义。想入门嵌入，先看我们的[上一篇教程](https://huggingface.co/blog/getting-started-with-embeddings)。本文聚焦文本。

Sentence Transformers 模型的工作方式是：

- **第 1 层**——输入文本通过一个预训练 Transformer，可以直接从 [Hugging Face Hub](https://huggingface.co/models?pipeline_tag=fill-mask&sort=downloads) 获取。本教程使用 "[distilroberta-base](https://huggingface.co/distilroberta-base)" 模型。Transformer 对所有输入 token 输出上下文相关的词嵌入——可以想象成文本中每个 token 都有一个嵌入。
- **第 2 层**——这些嵌入经过一个池化（pooling）层，把整个文本汇总成单个定长嵌入。例如 mean pooling 会对模型产出的嵌入求平均。

下图概括了这个过程：

[![](https://huggingface.co/blog/assets/95_training_st_models/training_process.png)](https://huggingface.co/blog/assets/95_training_st_models/training_process.png)

记得先安装 Sentence Transformers 库：`pip install -U sentence-transformers`。落到代码上，这个两步流程很简单：

```
from sentence_transformers import SentenceTransformer, models

## Step 1: use an existing language model
word_embedding_model = models.Transformer('distilroberta-base')

## Step 2: use a pool function over the token embeddings
pooling_model = models.Pooling(word_embedding_model.get_word_embedding_dimension())

## Join steps 1 and 2 using the modules argument
model = SentenceTransformer(modules=[word_embedding_model, pooling_model])
```

从上面的代码可以看出，Sentence Transformers 模型由模块（modules）组成——一个按顺序连续执行的层列表。输入文本进入第一个模块，最终输出来自最后一个组件。别看简单，上面的模型正是 Sentence Transformers 的典型架构。需要的话还能加更多层，比如 dense、bag of words、卷积层。

为什么不直接把 BERT 或 RoBERTa 这类 Transformer 模型拿来就生成句子/文本级的嵌入？至少有两个理由。

- 预训练 Transformer 做语义搜索的算力开销很大。例如在 10,000 个句子的集合里找最相似的一对，[用 BERT 大约需要 5,000 万次推理计算（约 65 小时）](https://arxiv.org/abs/1908.10084)。而 BERT 的 Sentence Transformers 版本把时间压到约 5 秒。
- Transformer 模型不加训练就直接产出质量很差的句子表示。把 BERT 的 token 嵌入求平均作为句子嵌入，[效果甚至不如 2014 年的 GloVe 嵌入](https://arxiv.org/abs/1908.10084)。

本节我们在从零创建 Sentence Transformers 模型。如果想微调已有模型，可以跳过上面的步骤，直接从 Hugging Face Hub 导入。多数 Sentence Transformers 模型能在 ["Sentence Similarity"](https://huggingface.co/models?pipeline_tag=sentence-similarity) 任务里找到。这里我们加载 "sentence-transformers/all-MiniLM-L6-v2"：

```
from sentence_transformers import SentenceTransformer

model_id = "sentence-transformers/all-MiniLM-L6-v2"
model = SentenceTransformer(model_id)
```

接下来是最关键的部分：数据集格式。

## 如何为训练 Sentence Transformers 模型准备数据集

要训练 Sentence Transformers 模型，你得用某种方式告诉它两个句子具有某种程度的相似度。因此数据里的每个样本都需要一个标签或结构，让模型能判断两个句子是相似还是不同。

遗憾的是，准备 Sentence Transformers 训练数据没有唯一正确的做法，很大程度上取决于你的目标和数据结构。如果数据没有显式标签（这是最常见的情况），可以从句子所在文档的构造中推导。例如，同一份报告里的两个句子应该比不同报告里的两个句子更可比较；相邻句子可能比不相邻的句子更可比较。

此外，数据的结构决定了你能用哪个损失函数——下一节展开。

别忘了本文的[配套 Notebook](https://colab.research.google.com/github/huggingface/blog/blob/main/notebooks/95_Training_Sentence_Transformers.ipynb)已包含全部代码。

多数数据集配置会是以下四种形态之一（下面会给出每种情形的例子）：

- 情形 1：样本是一对句子，外加一个表示相似程度的标签，标签是整数或浮点数。这个情形适用于原本为自然语言推理（NLI）准备的数据集，因为它们包含带"是否互相蕴含"标签的句子对。
- 情形 2：样本是一对正面（相似）句子，**没有**标签。例如释义对、全文与其摘要对、重复问题对、(`query`, `response`) 对、或(`source_language`, `target_language`) 对。自然语言推理数据集把蕴含句配对后也可以整理成这种格式。数据做成这个样子非常适合使用 `MultipleNegativesRankingLoss`——Sentence Transformers 最常用的损失函数之一。
- 情形 3：样本是一个句子加一个整数标签。这种格式可以被损失函数轻松转换为三句（三元组）：第一句是"anchor"，第二句是与 anchor 同类别的"positive"，第三句是不同类别的"negative"。每个句子有一个整数标签表示其类别。
- 情形 4：样本是一个三元组（anchor, positive, negative），句子没有类别或标签。

作为示例，本教程你将用第四种情形的数据集训练一个 Sentence Transformer，随后用第二种情形的数据配置对它做微调（请参考本文的[配套 Notebook](https://colab.research.google.com/github/huggingface/blog/blob/main/notebooks/95_Training_Sentence_Transformers.ipynb)）。

注意，Sentence Transformers 模型既可以用人工标注训练（情形 1 和 3），也可以用从文本格式自动推导的标签训练（主要是情形 2；虽然情形 4 不需要标签，但除非像 [`MegaBatchMarginLoss`](https://www.sbert.net/docs/package_reference/losses.html#megabatchmarginloss) 那样做处理，否则更难找到现成的三元组数据）。

Hugging Face Hub 上对上述每种情形都有数据集。而且 Hub 上的数据集带有 Dataset Preview 功能，下载前就能查看数据结构。以下是每种情形的数据集样例：

- 情形 1：如果你有（或能构造出）表示两个句子相似程度的标签——例如 {0,1,2}，0 表示矛盾、2 表示蕴含——就可以采用与自然语言推理相同的设置。看看 [SNLI 数据集](https://huggingface.co/datasets/snli)的结构。
- 情形 2：[Sentence Compression 数据集](https://huggingface.co/datasets/embedding-data/sentence-compression)的样本由正面句对构成。如果你的数据每个样本有超过两个正面句子，比如 [COCO Captions](https://huggingface.co/datasets/embedding-data/coco_captions_quintets) 或 [Flickr30k Captions](https://huggingface.co/datasets/embedding-data/flickr30k_captions_quintets) 这样的五元组，可以把样本格式化为多组不同的正面句对。
- 情形 3：[TREC 数据集](https://huggingface.co/datasets/trec)用整数标签标示每个句子的类别。[Yahoo Answers Topics 数据集](https://huggingface.co/datasets/yahoo_answers_topics)的每个样本含三个句子和一个主题标签，因此每个样本可以拆成三个。
- 情形 4：[Quora Triplets 数据集](https://huggingface.co/datasets/embedding-data/QQP_triplets)是无标签的（anchor, positive, negative）三元组。

下一步是把数据集转换成 Sentence Transformers 模型能理解的格式。模型不接受原始字符串列表：每个样本必须转为 `sentence_transformers.InputExample` 类，再转成 `torch.utils.data.DataLoader` 类以便批处理和打乱样本。

用 `pip install datasets` 安装 Hugging Face Datasets，然后用 `load_dataset` 导入数据集：

```
from datasets import load_dataset

dataset_id = "embedding-data/QQP_triplets"
dataset = load_dataset(dataset_id)
```

本指南使用一个无标签的三元组数据集，即上面说的第四种情形。

用 `datasets` 库可以探索数据集：

```
print(f"- The {dataset_id} dataset has {dataset['train'].num_rows} examples.")
print(f"- Each example is a {type(dataset['train'][0])} with a {type(dataset['train'][0]['set'])} as value.")
print(f"- Examples look like this: {dataset['train'][0]}")
```

输出：

```
- The embedding-data/QQP_triplets dataset has 101762 examples.
- Each example is a <class 'dict'> with a <class 'dict'> as value.
- Examples look like this: {'set': {'query': 'Why in India do we not have one on one political debate as in USA?', 'pos': ['Why can't we have a public debate between politicians in India like the one in US?'], 'neg': ['Can people on Quora stop India Pakistan debate? We are sick and tired seeing this everyday in bulk?'...]
```

可以看到 `query`（anchor）只有一句话，`pos`（positive）是一个句子列表（我们打印的这条只有一句），`neg`（negative）是一个含多句话的列表。

把样本转换成 `InputExample`。为简单起见：（1）[embedding-data/QQP_triplets](https://huggingface.co/datasets/embedding-data/QQP_triplets) 数据集只用其中一个 positive 和一个 negative；（2）只用可用样本的 1/2。增加样本量能取得明显更好的结果。

```
from sentence_transformers import InputExample

train_examples = []
train_data = dataset['train']['set']
# For agility we only 1/2 of our available data
n_examples = dataset['train'].num_rows // 2

for i in range(n_examples):
  example = train_data[i]
  train_examples.append(InputExample(texts=[example['query'], example['pos'][0], example['neg'][0]]))
```

把训练样本转成 `Dataloader`。

```
from torch.utils.data import DataLoader

train_dataloader = DataLoader(train_examples, shuffle=True, batch_size=16)
```

下一步是选择一个能匹配数据格式的损失函数。

## 训练 Sentence Transformers 模型的损失函数

还记得数据可能的四种格式吗？每种都有与之对应损失函数。

情形 1：一对句子加一个相似程度标签。损失函数会优化到：（1）标签最接近的句子在向量空间中也靠近；（2）标签相距最远的句子尽可能远。具体损失取决于标签形态——整数用 [`ContrastiveLoss`](https://www.sbert.net/docs/package_reference/losses.html#contrastiveloss) 或 [`SoftmaxLoss`](https://www.sbert.net/docs/package_reference/losses.html#softmaxloss)；浮点数可用 [`CosineSimilarityLoss`](https://www.sbert.net/docs/package_reference/losses.html#cosinesimilarityloss)。

情形 2：如果只有两个相似句子（两个 positive）且没有标签，可以用 [`MultipleNegativesRankingLoss`](https://www.sbert.net/docs/package_reference/losses.html#multiplenegativesrankingloss) 函数。也可以用 [`MegaBatchMarginLoss`](https://www.sbert.net/docs/package_reference/losses.html#megabatchmarginloss)，它会把你的样本转成三元组 `(anchor_i, positive_i, positive_j)`，其中 `positive_j` 充当 negative。

情形 3：当样本是 `[anchor, positive, negative]` 形式的三元组、且各句有整数标签时，损失函数优化模型使 anchor 与 positive 在向量空间中比 anchor 与 negative 更接近。可以用 [`BatchHardTripletLoss`](https://www.sbert.net/docs/package_reference/losses.html#batchhardtripletloss)，它要求数据带整数标签（例如 1、2、3），并假定同标签的样本相似。因此 anchor 和 positive 必须有相同标签，而 negative 必须不同。此外也可以用 [`BatchAllTripletLoss`](https://www.sbert.net/docs/package_reference/losses.html#batchalltripletloss)、[`BatchHardSoftMarginTripletLoss`](https://www.sbert.net/docs/package_reference/losses.html#batchhardsoftmargintripletloss) 或 [`BatchSemiHardTripletLoss`](https://www.sbert.net/docs/package_reference/losses.html#batchsemihardtripletloss)。它们之间的差异超出本文范围，可在 Sentence Transformers 文档中查阅。

情形 4：如果三元组里的句子没有标签，应该用 [`TripletLoss`](https://www.sbert.net/docs/package_reference/losses.html#tripletloss)。该损失最小化 anchor 与 positive 的距离，同时最大化 anchor 与 negative 的距离。

下图汇总了各种数据集格式、Hub 上的示例数据集以及对应的合适损失函数。

[![](https://huggingface.co/blog/assets/95_training_st_models/datasets_table.png)](https://huggingface.co/blog/assets/95_training_st_models/datasets_table.png)

选损失函数在概念上最难。落到代码上只有两行：

```
from sentence_transformers import losses

train_loss = losses.TripletLoss(model=model)
```

数据集一旦按期望格式整理好、合适的损失函数就位，fit/训练一个 Sentence Transformers 就很简单了。

## 如何训练或微调 Sentence Transformer 模型

> "SentenceTransformers 在设计上就让微调你自己的句子/文本嵌入模型很容易。它提供了大部分构件，你可以像搭积木一样为你的特定任务调校嵌入。" —— Sentence Transformers 文档

训练或微调长这样：

```
model.fit(train_objectives=[(train_dataloader, train_loss)], epochs=10) 
```

记住：如果你是在微调已有的 Sentence Transformers 模型（参见[配套 Notebook](https://colab.research.google.com/github/huggingface/blog/blob/main/notebooks/95_Training_Sentence_Transformers.ipynb)），直接在它上面调用 `fit` 即可。如果是全新的 Sentence Transformers 模型，必须先在"Sentence Transformers 模型如何工作"一节中那样把它定义出来。

就这样！你拥有了一个全新的或更好的 Sentence Transformers 模型。想把它分享到 Hugging Face Hub 吗？

首先登录 Hugging Face Hub。你需要在[账号设置](http://hf.co/settings/tokens)里创建一个 `write` token。然后有两种登录方式：

- 在终端输入 `huggingface-cli login` 并粘贴 token。
- 如果在 Python notebook 里，用 `notebook_login`。

```
from huggingface_hub import notebook_login

notebook_login()
```

然后，通过训练好的模型调用 `save_to_hub` 方法即可分享。默认上传到你的账号下；传给 `organization` 参数可以上传到某个组织。`save_to_hub` 会自动生成模型卡、推理 widget、示例代码片段及更多细节。用 `train_datasets` 参数可以把你训练用的数据集列表自动写进 Hub 的模型卡：

```
model.save_to_hub(
    "distilroberta-base-sentence-transformer", 
    organization= # Add your username
    train_datasets=["embedding-data/QQP_triplets"],
    )
```

在[配套 Notebook](https://colab.research.google.com/github/huggingface/blog/blob/main/notebooks/95_Training_Sentence_Transformers.ipynb)里，我用 [embedding-data/sentence-compression](https://huggingface.co/datasets/embedding-data/sentence-compression) 数据集和 [`MultipleNegativesRankingLoss`](https://www.sbert.net/docs/package_reference/losses.html#multiplenegativesrankingloss) 损失对这个同款模型做了微调。

## Sentence Transformers 有什么局限？

在语义搜索上，Sentence Transformers 模型远优于裸 Transformer 模型。但什么场景它不擅长？如果你的任务是分类，用句子嵌入就找错了方向——那种情况下 🤗 [Transformers 库](https://huggingface.co/docs/transformers/tasks/sequence_classification)是更好的选择。
