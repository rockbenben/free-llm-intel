# Hugging Face Fellow（研究员）项目正式启动

Fellowship 是一个由来自不同背景的杰出人士组成的网络，他们为机器学习开源生态贡献力量 🚀。项目的目标是赋能关键贡献者，让他们的影响力得以放大，同时激励更多人参与贡献。

## Fellowship 如何运作 🙌🏻

这是 Hugging Face 对贡献者精彩工作的支持！成为 Fellow 对每个人的意义都不相同。关键问题是：

❓ **贡献者需要什么才能产生更大影响？Hugging Face 该如何支持他们，让他们去做自己一直想做的那个项目？**

欢迎各种背景的 Fellow！机器学习的进步依赖于自下而上的贡献。每个人都有独特的技能与知识组合，可以以多种方式推动这一领域的民主化。每位 Fellow 实现影响力的方式各不相同，而这恰恰是美好之处 🌈。Hugging Face 支持他们继续以自己的方式创造和分享。

## 如何成为 Fellow

Fellow 目前由 Hugging Face 团队成员或其他 Fellow 提名。潜力者如何被看见？主要标准是他们为开源机器学习的民主化做出了贡献。

如何贡献？以他们喜欢的方式。以下是首批 Fellow 的一些例子：

- **María Grandury** - 创建了[最大的西语 NLP 社区](https://somosnlp.org/)，并组织了一场 Hackathon，产出 23 个 Spaces、23 个数据集和 33 个模型，推进了西语 SOTA（[见 Hub 上的这个 Organization](https://huggingface.co/hackathon-pln-es)）。👩🏼‍🎤
- **Manuel Romero** - 向 Hugging Face Hub 贡献了[超过 300 个模型](https://huggingface.co/mrm8488)。他训练了多个西语 SOTA 模型。🤴🏻
- **Aritra Roy Gosthipathy**：为 Transformers 库贡献了新的 TensorFlow 架构，改进 Keras 工具，并参与创建了 Keras 工作组（例如他的 [Vision Transformers 教程](https://twitter.com/RisingSayak/status/1515918406171914240)）。🦹🏻
- **Vaibhav Srivastav** - 在语音领域的倡导者。他主导了 [ML4Audio 工作组](https://github.com/Vaibhavs10/ml-with-audio)（[见录像](https://www.youtube.com/playlist?list=PLo2EIpI_JMQtOQK_B4G97yn1QWZ4Xi4Tu)）和论文讨论活动。🦹🏻
- **Bram Vanroy** - 从一开始就在帮助众多贡献者和 Hugging Face 团队。自 2019 年 9 月起，他在 Transformers 库中提报了多个 [issue](https://github.com/huggingface/transformers/issues/1332) 并合并了 [pull request](https://github.com/huggingface/transformers/pull/1346)。🦸🏼
- **Christopher Akiki** - 参与了多个冲刺活动、工作坊、[Big Science](https://t.co/oIRne5fZYb)，还有很酷 demo！看看他最近的一些项目，比如他的 [TF-coder](https://t.co/NtTmO6ngHP) 和[收入统计浏览器](https://t.co/dNMO7lHAIR)。🦹🏻‍♀️
- **Ceyda Çınarel** - 在各种冲刺活动中为许多成功的 Hugging Face 与 Spaces 模型做出贡献。看看她的 [ButterflyGAN Space](https://huggingface.co/spaces/huggan/butterfly-gan) 或[用 CLIP 搜索反应 GIF](https://huggingface.co/spaces/flax-community/clip-reply-demo)。👸🏻

此外，在一些战略方向上，Hugging Face 也在寻找开源贡献。这些方向会频繁更新在[包含具体项目的 Fellowship 文档](https://docs.google.com/document/d/11mh36a4fgBlj8sh3_KoP2TckuPcnD-_S_UAtsEWgs50/edit)中。如果你想承接这些方向的项目、获得支持或被提名为 Fellow，请不要犹豫，到 [Hugging Face Discord](https://t.co/1n75wi976V?amp=1) 的 #looking-for-collaborators 频道留言。也可参考下面的**"我在哪里、如何贡献？"**一问。

如果你是在校学生，可以考虑申请 [Student Ambassador Program（校园大使项目）](https://huggingface.co/blog/ambassadors)。申请截止日期是 2022 年 6 月 13 日。

Hugging Face 正在积极建设一种重视多样性、公平与包容的文化。Hugging Face 有意营造一个人人受到尊重与支持、无关身份与出身的社区。这对构建开放机器学习的未来至关重要。Fellowship 不会因种族、宗教、肤色、国籍、性别、性取向、年龄、婚姻状况、退伍军人身份或残疾状况而歧视任何人。

## 常见问题

- **我刚开始参与贡献，可以成为 Fellow 吗？**

Fellow 的提名基于其开源与社区贡献。如果你想加入 Fellowship，最好的起点就是开始贡献！如果你还是学生，[Student Ambassador Program](https://huggingface.co/blog/ambassadors) 可能更适合你（申请截止日期 2022 年 6 月 13 日）。

- **我在哪里、如何贡献？**

取决于你的兴趣。这里提供一些可贡献方向的思路，但你应该去做让**你**兴奋的事！

- 通过 Hub 与社区分享令人兴奋的模型。可以是计算机视觉、强化学习以及任何 ML 领域！
- 使用不同开源库创作教程和项目——例如 Stable-Baselines 3、fastai 或 Keras。
- 组织线下冲刺活动，在不同语言或细分领域推广开源机器学习。例如，[Somos NLP Hackathon](https://huggingface.co/hackathon-pln-es) 聚焦西语使用者；[HugGAN 冲刺活动](https://github.com/huggingface/community-events/tree/main/huggan) 聚焦生成模型。
- 翻译 [Hugging Face 课程](https://github.com/huggingface/course#-languages-and-translations)、[Transformers 文档](https://github.com/huggingface/transformers/blob/main/docs/TRANSLATING.md)或 [Educational Toolkit](https://github.com/huggingface/education-toolkit/blob/main/TRANSLATING.md)。
- [包含具体项目的文档](https://docs.google.com/document/d/11mh36a4fgBlj8sh3_KoP2TckuPcnD-_S_UAtsEWgs50/edit)，其中的贡献会特别有价值。Hugging Face 团队会频繁更新文档中的新项目。

如果你想参与某个特定项目，请到 [Hugging Face Discord](https://hf.co/join/discord) 的 #looking-for-contributors 频道分享。

- **我会成为 Hugging Face 的员工吗？**

不会，Fellowship 并不意味着你是 Hugging Face 的员工。不过，欢迎你在包括 LinkedIn 在内的任何场合提到自己是 Hugging Face Fellow。Hugging Face 正在成长，未来这可能是更深度关系的良好起点 😎。最新机会请关注 [Hugging Face 招聘板](https://hf.co/jobs)。

- **Fellowship 期间我能获得权益吗？**

能，权益将取决于每位 Fellow 的具体需求与他们想开展的项目。

- **有截止时间吗？**

没有。项目的加入是持续进行的，取决于现任 Fellow 或 Hugging Face 团队成员的提名。请注意，获得提名不一定保证最终入选 Fellow。
