# 欢迎 Gemma —— Google 全新的开源 LLM

> 本文发布两个月后 Gemma 模型推出了更新，最新版本见该 collection。

Gemma——Google 今天发布的全新最先进开源 LLM 家族！看到 Google 持续加码开源 AI 令人振奋，我们也很激动地以 Hugging Face 的全量集成支持这次发布。

Gemma 有两个尺寸：7B 参数版，适合在消费级 GPU 和 TPU 上高效部署与开发；2B 版适合 CPU 和端侧应用。两者都有 base（基座）和 instruction-tuned（指令微调）两种变体。

我们与 Google 协作，确保在 Hugging Face 生态中的最佳集成。4 个开放访问模型（2 个 base + 2 个微调版）已在 Hub 上。本次同步发布的特性与集成包括：

- [Hub 上的模型](https://huggingface.co/models?search=google/gemma)，含模型卡和许可证
- [🤗 Transformers 集成](https://github.com/huggingface/transformers/releases/tag/v4.38.0)
- 与 Google Cloud 的集成
- 与 Inference Endpoints 的集成
- 用 🤗 TRL 在单张 GPU 上微调 Gemma 的示例

## Gemma 是什么？

Gemma 是 Google 基于 Gemini 打造的 4 个全新 LLM 模型。它有两个尺寸：2B 和 7B 参数，各含 base（预训练）和指令微调版本。所有变体都能在各种消费级硬件上运行，甚至不用量化，上下文长度为 8K tokens：

- [gemma-7b](https://huggingface.co/google/gemma-7b)：7B 基座模型。
- [gemma-7b-it](https://huggingface.co/google/gemma-7b-it)：7B 基座的指令微调版。
- [gemma-2b](https://huggingface.co/google/gemma-2b)：2B 基座模型。
- [gemma-2b-it](https://huggingface.co/google/gemma-2b-it)：2B 基座的指令微调版。

首发一个月后，Google 发布了新的指令模型版本。该版本在编程能力、事实性、指令遵循和多轮对话质量上更好，模型也没那么爱以 "Sure," 开头了。

- [gemma-1.1-7b-it](https://huggingface.co/google/gemma-1.1-7b-it)
- [gemma-1.1-2b-it](https://huggingface.co/google/gemma-1.1-2b-it)

那么 Gemma 到底怎么样？下面是基座模型在 [LLM Leaderboard](https://huggingface.co/spaces/HuggingFaceH4/open_llm_leaderboard) 上与其他开放模型对比的概览（分数越高越好）：

| 模型 | 许可证 | 可商用？ | 预训练规模 [tokens] | Leaderboard 分数 ⬇️ |
| --- | --- | --- | --- | --- |
| [LLama 2 70B Chat（参照）](https://huggingface.co/meta-llama/Llama-2-70b-hf) | Llama 2 license | ✅ | 2T | 67.87 |

Gemma 7B 是一款非常强的模型，性能与 7B 量级最佳模型相当，包括 Mistral 7B。Gemma 2B 在这个尺寸上很有意思，但在 leaderboard 上的得分不及同等规模的优等生（比如 Phi 2）。我们期待收到社区关于真实使用场景的反馈！

提醒一下：LLM Leaderboard 特别适合衡量预训练模型的质量，对聊天模型的衡量则一般。对聊天模型，我们建议再跑 MT Bench、EQ Bench 和 lmsys Arena 等基准！

### 提示词格式

基座模型没有提示词格式。与其他基座模型一样，可以用来把输入序列续写成合理的下文，或做 zero-shot/few-shot 推理。它们也是在你自己的用例上做微调的绝佳底座。Instruct 版本的对话结构非常简单：

```
<start_of_turn>user
knock knock<end_of_turn>
<start_of_turn>model
who is there<end_of_turn>
<start_of_turn>user
LaMDA<end_of_turn>
<start_of_turn>model
LaMDA who?<end_of_turn>
```

要有效使用，必须精确复现这个格式。后面我们会展示用 `transformers` 提供的 chat template 复现 instruct 提示词有多简单。

### 探索未知

技术报告包含了基座模型的训练与评估流程信息，但对数据集构成和预处理没有过多细节。我们知道模型用来自多种来源的数据训练，主要是网页文档、代码和数学文本。数据经过过滤，移除了 CSAM 内容和 PII，并做了许可证核查。

同样，对 Gemma instruct 模型，SFT 和 [RLHF](https://huggingface.co/blog/rlhf) 所用的微调数据集及相关超参数也未公布。

### 使用 🤗 Transformers

通过 Transformers [4.38 版本](https://github.com/huggingface/transformers/releases/tag/v4.38.0)，你可以使用 Gemma 并发挥 Hugging Face 生态里所有工具的能力，包括：

- 训练和推理脚本与示例
- 安全文件格式（`safetensors`）
- 与工具集成：bitsandbytes（4-bit 量化）、PEFT（参数高效微调）、Flash Attention 2
- 运行模型生成的实用函数与辅助工具
- 用于部署的模型导出机制

此外，Gemma 模型兼容带 CUDA graphs 的 `torch.compile()`，推理时有约 4 倍加速！

要在 transformers 中使用 Gemma，先确保装了较新的 `transformers` 版本：

```
pip install --upgrade transformers
```

下面这段展示如何用 transformers 使用 `gemma-7b-it`。它需要约 18GB 内存，包括 3090 或 4090 这类消费级 GPU。

```
from transformers import pipeline
import torch

pipe = pipeline(
    "text-generation",
    model="google/gemma-7b-it",
    model_kwargs={"torch_dtype": torch.bfloat16},
    device="cuda",
)

messages = [
    {"role": "user", "content": "Who are you? Please, answer in pirate-speak."},
]
outputs = pipe(
    messages,
    max_new_tokens=256,
    do_sample=True,
    temperature=0.7,
    top_k=50,
    top_p=0.95
)
assistant_response = outputs[0]["generated_text"][-1]["content"]
print(assistant_response)
```

> Avast me, me hearty. I am a pirate of the high seas, ready to pillage and plunder. Prepare for a tale of adventure and booty!

我们使用 `bfloat16`，因为那是参考精度，所有评估都是这么跑的。在你的硬件上 `float16` 可能更快。

你也可以自动量化模型，以 8-bit 甚至 4-bit 模式加载。4-bit 加载只需约 9GB 内存，兼容大量消费级显卡和 Google Colab 的全部 GPU。4-bit 加载生成 pipeline 的方式是：

```
pipeline = pipeline(
    "text-generation",
    model=model,
    model_kwargs={
        "torch_dtype": torch.float16,
        "quantization_config": {"load_in_4bit": True}
    },
)
```

关于用 transformers 使用这些模型的更多细节，请看[模型卡](https://huggingface.co/gg-hf/gemma-7b)。

### JAX 权重

所有 Gemma 变体都可以用 PyTorch（如上文所述）或 JAX / Flax 使用。要加载 Flax 权重，需要使用仓库的 `flax` revision，如下：

```
import jax.numpy as jnp
from transformers import AutoTokenizer, FlaxGemmaForCausalLM

model_id = "google/gemma-2b"

tokenizer = AutoTokenizer.from_pretrained(model_id)
tokenizer.padding_side = "left"

model, params = FlaxGemmaForCausalLM.from_pretrained(
        model_id,
        dtype=jnp.bfloat16,
        revision="flax",
        _do_init=False,
)

inputs = tokenizer("Valencia and Málaga are", return_tensors="np", padding=True)
output = model.generate(**inputs, params=params, max_new_tokens=20, do_sample=False)
output_text = tokenizer.batch_decode(output.sequences, skip_special_tokens=True)
```

> ['Valencia and Málaga are two of the most popular tourist destinations in Spain. Both cities boast a rich history, vibrant culture,']

关于如何在 Colab 的 TPU 上并行化 JAX 推理，请查看[这份 notebook](https://colab.research.google.com/github/sanchit-gandhi/notebooks/blob/main/jax_gemma.ipynb)的完整实操指南！

## 与 Google Cloud 的集成

你可以通过 Vertex AI 或 Google Kubernetes Engine（GKE）在 Google Cloud 上部署和训练 Gemma，使用 [Text Generation Inference](https://huggingface.co/docs/text-generation-inference/index) 和 Transformers。

要部署来自 Hugging Face 的 Gemma 模型，进入[模型页](https://huggingface.co/google/gemma-7b-it)，点击 [Deploy -> Google Cloud。](https://huggingface.co/google/gemma-7b-it)这会打开 Google Cloud Console，你可以在那里一键把 Gemma 部署到 Vertex AI 或 GKE。Text Generation Inference 为 Gemma 在 Google Cloud 上的运行提供支撑，也是我们 [与 Google Cloud 合作](https://huggingface.co/blog/gcp-partnership)的首个集成。

[![deploy on GCP](https://huggingface.co/blog/assets/gemma/gcp-deploy.png)](https://huggingface.co/blog/assets/gemma/gcp-deploy.png)

你也可以通过 Vertex AI Model Garden 直接访问 Gemma。

要调优来自 Hugging Face 的 Gemma 模型，进入[模型页](https://huggingface.co/google/gemma-7b-it)，点击 [Train -> Google Cloud。](https://huggingface.co/google/gemma-7b-it)这会打开 Google Cloud Console，里面有可以在 Vertex AI 或 GKE 上调优 Gemma 的 notebook。

[![train on GCP](https://huggingface.co/blog/assets/gemma/gcp-train-gemma.png)](https://huggingface.co/blog/assets/gemma/gcp-train-gemma.png)

## 与 Inference Endpoints 的集成

你可以在 Hugging Face 的 [Inference Endpoints](https://ui.endpoints.huggingface.co/new?repository=google%2Fgemma-7b-it) 上部署 Gemma，后端使用 Text Generation Inference。[Text Generation Inference](https://github.com/huggingface/text-generation-inference) 是 Hugging Face 开发的生产就绪推理容器，让大语言模型部署变得简单。它具有连续批处理、token 流式输出、多 GPU 张量并行加速推理，以及生产级的日志和追踪。

要部署 Gemma 模型，进入[模型页](https://huggingface.co/google/gemma-7b-it)，点击 [Deploy -> Inference Endpoints](https://ui.endpoints.huggingface.co/new?repository=google/gemma-7b-it) 组件。可在我们之前的博客中了解更多关于 [用 Hugging Face Inference Endpoints 部署 LLM](https://huggingface.co/blog/inference-endpoints-llm) 的内容。Inference Endpoints 通过 Text Generation Inference 支持 [Messages API](https://huggingface.co/blog/tgi-messages-api)，这意味着只需改个 URL，你就能从其他封闭模型切换到开放模型。

```
from openai import OpenAI

# initialize the client but point it to TGI
client = OpenAI(
    base_url="<ENDPOINT_URL>" + "/v1/",  # replace with your endpoint url
    api_key="<HF_API_TOKEN>",  # replace with your token
)
chat_completion = client.chat.completions.create(
    model="tgi",
    messages=[
        {"role": "user", "content": "Why is open-source software important?"},
    ],
    stream=True,
    max_tokens=500
)

# iterate and print stream
for message in chat_completion:
    print(message.choices[0].delta.content, end="")
```

## 用 🤗 TRL 微调

训练 LLM 在工程和算力上都充满挑战。本节看看 Hugging Face 生态中有哪些工具，能让你在消费级 GPU 上高效训练 Gemma。

下面是微调 Gemma 使用 OpenAssistant [chat 数据集](https://huggingface.co/datasets/OpenAssistant/oasst_top1_2023-08-25)的示例命令。我们用 4-bit 量化和 [QLoRA](https://arxiv.org/abs/2305.14314) 节省内存，目标覆盖所有 attention 块的 linear 层。

首先，安装 🤗 TRL 的 nightly 版本并克隆仓库以获得[训练脚本](https://github.com/huggingface/trl/blob/main/trl/scripts/sft.py)：

```
pip install -U transformers trl peft bitsandbytes
git clone https://github.com/huggingface/trl
cd trl
```

然后运行脚本：

```
accelerate launch --config_file examples/accelerate_configs/multi_gpu.yaml --num_processes=1 \
    trl/scripts/sft.py \
    --model_name google/gemma-7b \
    --dataset_name OpenAssistant/oasst_top1_2023-08-25 \
    --per_device_train_batch_size 2 \
    --gradient_accumulation_steps 1 \
    --learning_rate 2e-4 \
    --save_steps 20_000 \
    --use_peft \
    --lora_r 16 --lora_alpha 32 \
    --lora_target_modules q_proj k_proj v_proj o_proj \
    --load_in_4bit \
    --output_dir gemma-finetuned-openassistant
```

在单张 A10G 上大约需要 9 小时训练，但通过调整 `--num_processes` 为你可用的 GPU 数，可以轻松并行化。
