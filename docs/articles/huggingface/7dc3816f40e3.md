# Mac 上的 Stable Diffusion XL：进阶 Core ML 量化

Pedro Cuenca

pcuenq

Orhon

Atila

guest

[Stable Diffusion XL](https://stability.ai/stablediffusion) 昨天发布了，非常棒。它能生成大尺寸（1024x1024）高质量图像；用一些新技巧提升了提示词遵循度；得益于噪声调度器的最新研究，它可以毫不费力地产出很暗或很亮的图像；而且它是开源的！

代价是模型大了很多，因此在消费级硬件上更慢也更难跑。用 [Hugging Face diffusers 库的最新版本](https://github.com/huggingface/diffusers/releases/tag/v0.19.0)，你可以在 16GB 显存的 CUDA 设备上运行 Stable Diffusion XL，这意味着 Colab 免费档也能用上它。

过去几个月的事实表明，人们确实非常希望把 ML 模型跑在本地，原因五花八门：隐私、便利、更容易做实验、不按量计费。Apple 和 Hugging Face 两边都在努力探索这个方向。我们展示过[如何在 Apple Silicon 上运行 Stable Diffusion](https://machinelearning.apple.com/research/stable-diffusion-coreml-apple-silicon)，也展示过如何利用 [Core ML 的最新进展，用 6-bit palettization 改善体积与性能](https://huggingface.co/blog/fast-diffusers-coreml)。

针对 Stable Diffusion XL，我们做了几件事：

- 把[基础模型移植到 Core ML](https://huggingface.co/apple/coreml-stable-diffusion-xl-base)，供你在原生 Swift 应用中使用。
- 更新了 [Apple 的转换与推理仓库](https://github.com/apple/ml-stable-diffusion)，你可以自己转换模型，包括你感兴趣的任何微调版本。
- 更新了 [Hugging Face 的 demo 应用](https://github.com/huggingface/swift-coreml-diffusers)，演示如何使用从 Hub 下载的新一代 Core ML Stable Diffusion XL 模型。
- 探索了[混合位 palettization（mixed-bit palettization）](https://github.com/apple/ml-stable-diffusion#-mbp-post-training-mixed-bit-palettization)——一种进阶压缩技术，在把质量损失降到最小、可控的同时实现显著的体积缩减。你也可以把同样的技术用到自己的模型上！

一切均已开源、即刻可用，我们开始吧。

## 使用 Hugging Face Hub 上的 SD XL 模型

作为本次发布的一部分，我们发布了两个不同版本的 Stable Diffusion XL Core ML 模型。

- [`apple/coreml-stable-diffusion-xl-base`](https://huggingface.co/apple/coreml-stable-diffusion-xl-base)：完整 pipeline，未做量化。
- [`apple/coreml-stable-diffusion-mixed-bit-palettization`](https://huggingface.co/apple/coreml-stable-diffusion-mixed-bit-palettization)：包含（除其他产物外）一个完整 pipeline，其中 UNet 替换为混合位 palettization *配方（recipe）*，达到相当于每参数 4.5 bit 的压缩。体积从 4.8GB 降到 1.4GB，缩减 71%，在我们看来质量依然很好。

两个模型都可以用 Apple 的 [Swift 命令行推理应用](https://github.com/apple/ml-stable-diffusion#inference)或 Hugging Face 的 [demo 应用](https://github.com/huggingface/swift-coreml-diffusers)来体验。下面是用后者跑全新 Stable Diffusion XL pipeline 的示例：

[![Screenshot of Stable Diffusion XL running on Mac](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/stable-diffusion-xl-coreml/sdxl-swift-screenshot.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/stable-diffusion-xl-coreml/sdxl-swift-screenshot.png)

与之前的 Stable Diffusion 发布一样，我们预计社区会为不同领域做出各种新颖的微调版本，其中很多会被转换成 Core ML。可以关注 [Hub 上的这个过滤器](https://huggingface.co/models?pipeline_tag=text-to-image&library=coreml&sort=trending)随时探索！

Stable Diffusion XL 可在运行 macOS 14 公开测试版的 Apple Silicon Mac 上工作。目前使用 `ORIGINAL` 注意力实现，面向 CPU + GPU 计算单元。注意：refiner 阶段尚未移植。

## 什么是混合位 Palettization？

[上个月我们讨论过 6-bit palettization](https://huggingface.co/blog/fast-diffusers-coreml)：一种训练后量化方法，把 16-bit 权重转成每参数仅 6 bit。这能显著缩小模型体积，但想更进一步就棘手了——比特数越低，模型质量受影响越大。

想让模型更小的一个选项是使用*训练时*量化：在微调模型的同时学习量化表。这个方法效果很好，但每个想转换的模型都要跑一轮微调。

我们探索了另一条路：**混合位 palettization**。不再是所有参数都用 6 bit，我们逐个检查模型、为*每一层*决定量化比特数。决策依据是该层对整体质量退化的贡献程度——用少量输入样本，比较量化模型与 `float16` 原始模型之间的 PSNR 来度量。我们对每层尝试几种位宽：`1`（！）、`2`、`4` 和 `8`。如果某层用 2 bit 时退化明显，就换 `4`，以此类推。一些对保持质量至关重要的层可能保留 16-bit。

用这个方法，我们可以实现比如平均 2.8 bit 的有效量化，并对每一种尝试的组合测量质量退化影响。这让我们对"目标质量与体积预算下最合适的量化方案"有更充分的信息。

为说明该方法，看看我们某次分析运行得到的量化"配方"（如何生成后文解释）：

```
{
  "model_version": "stabilityai/stable-diffusion-xl-base-1.0",
  "baselines": {
    "original": 82.2,
    "linear_8bit": 66.025,
    "recipe_6.55_bit_mixedpalette": 79.9,
    "recipe_4.50_bit_mixedpalette": 75.8,
    "recipe_3.41_bit_mixedpalette": 71.7,
  },
}
```

这告诉我们：以 float16 下的 PSNR 衡量，原始模型质量约 82 dB。做一个天真的 8-bit 线性量化会掉到 66 dB。但接着有一个平均每参数 6.55 bit 的配方，仍把 PSNR 保持在 80 dB。第二、第三个配方进一步缩小模型体积，同时 PSNR 依然高于 8-bit 线性量化的水平。

从视觉上看，对提示词 `a high quality photo of a surfing dog`，用相同种子分别运行三个配方的结果如下：

| 3.41-bit | 4.50-bit | 6.55-bit | 16-bit（原始） |
| --- | --- | --- | --- |
| [![3.41](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/stable-diffusion-xl-coreml/a_high_quality_photo_of_a_surfing_dog.7667.final_3.41-bits.jpg)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/stable-diffusion-xl-coreml/a_high_quality_photo_of_a_surfing_dog.7667.final_3.41-bits.jpg) | [![4.50](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/stable-diffusion-xl-coreml/a_high_quality_photo_of_a_surfing_dog.7667.final_4.50-bits.jpg)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/stable-diffusion-xl-coreml/a_high_quality_photo_of_a_surfing_dog.7667.final_4.50-bits.jpg) | [![6.55](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/stable-diffusion-xl-coreml/a_high_quality_photo_of_a_surfing_dog.7667.final_6.55-bits.jpg)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/stable-diffusion-xl-coreml/a_high_quality_photo_of_a_surfing_dog.7667.final_6.55-bits.jpg) | [![16-bit](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/stable-diffusion-xl-coreml/a_high_quality_photo_of_a_surfing_dog.7667.final_float16_original.jpg)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/stable-diffusion-xl-coreml/a_high_quality_photo_of_a_surfing_dog.7667.final_float16_original.jpg) |

初步结论：

- 在我们看来，所有图像在真实感方面质量都不错。6.55 和 4.50 版本在这方面与 16-bit 版本很接近。
- 相同种子产生类似的构图，但不会保留相同细节，例如狗的品种可能不同。
- 随着压缩增强，提示词遵循度可能下降。这个例子中，激进的 3.41 版本丢了冲浪板。PSNR 只比较整体像素差异，并不关心图像中的主体。你需要亲自检查结果，按自己的用例评估。

这个技术对 Stable Diffusion XL 格外合适：相比上一版参数量增至三倍，我们却能把 UNet 体积维持在大致相同水平。但它并不只适用于 XL！你可以把该方法用于任何 Stable Diffusion Core ML 模型。

## 混合位配方如何生成？

下图展示了 `stabilityai/stable-diffusion-xl-base-1.0` 的信号强度（PSNR，单位 dB）随模型体积缩减（占 float16 体积的百分比）的变化。`{1,2,4,6,8}`-bit 各条曲线通过逐步对更多层做固定位宽 palettization 生成。层按"单独对端到端信号强度的影响"从小到大排序，从而尽量推迟累积压缩的影响。mixed-bit 曲线则基于：一旦某层单独对端到端信号完整性的影响跌破阈值，就回退到更高的位数。注意，除 1-bit 外，所有基于 palettization 的曲线在同一模型体积下都优于线性 8-bit 量化。

[![PSNR-vs-size-reduction-plot](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/stable-diffusion-xl-coreml/stabilityai_stable-diffusion-xl-base-1.0_psnr_vs_size.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/stable-diffusion-xl-coreml/stabilityai_stable-diffusion-xl-base-1.0_psnr_vs_size.png)

混合位 palettization 分两阶段运行：*分析*和*应用*。

分析阶段的目标是在 mixed-bit 曲线上找出若干点（图中在所有曲线最上方的棕色那条），让我们可以选择想要的质量-体积权衡。如前文所述，我们逐层迭代，选择结果高于给定 PSNR 阈值的最低位宽。对多个阈值重复该过程，得到不同的量化策略。因此该过程的产物是一组量化配方，每个配方只是一个 JSON 字典，写明模型每一层应使用的比特数。参数量很少的层被忽略，为简单起见保留 float16。

应用阶段则按配方逐层执行 palettization，使用 JSON 中指定的比特数。

分析是个耗时的过程，且需要 GPU（`mps` 或 `cuda`），因为要跑多次推理。分析完成后，应用配方只需几分钟。

我们为每个阶段提供了脚本：

- [`mixed_bit_compression_pre_analysis.py`](https://github.com/apple/ml-stable-diffusion/tree/main/python_coreml_stable_diffusion/mixed_bit_compression_pre_analysis.py)
- [`mixed_bit_compression_apply.py`](https://github.com/apple/ml-stable-diffusion/tree/main/python_coreml_stable_diffusion/mixed_bit_compression_apply.py)

## 转换微调模型

如果你此前已把 Stable Diffusion 模型转换到 Core ML，用[命令行转换器](https://github.com/apple/ml-stable-diffusion#-using-stable-diffusion-xl)转换 XL 的过程非常相似：新增一个标志指明模型属于 XL 家族，这种情况下必须使用 `--attention-implementation ORIGINAL`。

想了解流程入门，可以看[仓库中的说明](https://github.com/apple/ml-stable-diffusion#-converting-models-to-core-ml)或我们[之前的博客](https://huggingface.co/blog/diffusers-coreml)，记得使用上面提到的标志。

### 运行混合位 Palettization

把 Stable Diffusion 或 Stable Diffusion XL 模型转成 Core ML 之后，你可以选择性地用上述脚本应用混合位 palettization。

因为分析过程很慢，我们已为最受欢迎的模型准备了配方：

- [Stable Diffusion 1.5 配方](https://huggingface.co/apple/coreml-stable-diffusion-mixed-bit-palettization/blob/main/recipes/runwayml-stable-diffusion-v1-5_palettization_recipe.json)
- [Stable Diffusion 2.1 配方](https://huggingface.co/apple/coreml-stable-diffusion-mixed-bit-palettization/blob/main/recipes/stabilityai-stable-diffusion-2-1-base_palettization_recipe.json)
- [Stable Diffusion XL 1.0 base 配方](https://huggingface.co/apple/coreml-stable-diffusion-mixed-bit-palettization/blob/main/recipes/stabilityai-stable-diffusion-xl-base-1.0_palettization_recipe.json)

你可以下载后在本地应用做实验。

此外，我们还把 Stable Diffusion XL 分析中最好的三个配方应用到了 Core ML 版 UNet 上，并发布在[这里](https://huggingface.co/apple/coreml-stable-diffusion-mixed-bit-palettization/tree/main/unet-mbp-sdxl-1-base)。尽管拿去玩，看它们适合你什么场景！

最后，如开头所说，我们创建了一个[完整的 Stable Diffusion XL Core ML pipeline](https://huggingface.co/apple/coreml-stable-diffusion-mixed-bit-palettization)，使用 `4.5-bit` 配方。
