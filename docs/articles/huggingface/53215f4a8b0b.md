在今天举行的 Microsoft Build 大会上，Satya Nadella 宣布与 Hugging Face 扩大合作，让 Hugging Face 丰富多样的开放模型能够轻松部署在 Azure 的安全基础设施上。

如果你今天就访问 [Azure AI Foundry](https://ai.azure.com)，会发现一个大幅扩充的合集：超过 10,000 个 Hugging Face 模型，只需几次点击即可部署，为处理文本、音频和图像的 AI 应用提供动力。而这才刚刚开始！

## 动手构建的时刻到了——一次升级的合作

2 年前，微软与 Hugging Face [开始合作](https://huggingface.co/blog/hugging-face-endpoints-on-azure)，让开放模型在 Azure 上更易获取——当时 Hub 上有 20 万个开放模型。

如今 Hugging Face 上已接近 200 万个开放模型，覆盖广泛的任务、模态、领域和语言，是时候把我们的合作提升到新高度了。今天宣布的新合作为双方共赢建立了框架，大幅拓展 Azure 客户能从 Hugging Face 获得的收益。

> "开源是 AI 加速前进的方式——其核心是透明、选择与社区。这次合作代表了我们对该势头的承诺。把 Hugging Face 充满活力的模型生态与 Azure 安全的企业级基础设施结合，我们赋予开发者挑选最适合工作的模型的自由——同时帮助组织安全地、规模化地创新。"

-- *Asha Sharma，微软企业副总裁*

让更多开放模型更易触达 Azure 客户，便于在与企业私有数据并列的安全环境中部署，将使企业能够构建 AI 应用与 agent，同时完全掌控自己的技术和数据。

> 我们正在让企业掌控自己的 AI 命运：在自己的 Azure 账户内安全部署最优秀的开放模型，构建值得信赖、可验证的 AI 应用。

-- *Clement Delangue，Hugging Face CEO 兼联合创始人*

## 如何在 Azure AI Foundry 中使用 Hugging Face

我们来到 Azure AI Foundry，选择 Model Catalog（模型目录）。在这里你现在可以在 Hugging Face Collection 下找到超过 10,000 个模型。

该合集收录了 Hugging Face 上最受欢迎、趋势领先的模型，覆盖处理文本、音频和图像的广泛任务——包括文本生成、特征提取、fill-mask（填空）、翻译、句子相似度识别、图像分类、图像分割、文生图、图生文、自动语音识别以及音频分类。

为了让 Azure AI Foundry 上的 Hugging Face 合集达到企业可用标准，我们只收录满足以下条件的模型：

- 已通过 Hugging Face 安全测试、筛查各类漏洞，包括 [ProtectAI Guardian](https://huggingface.co/docs/hub/en/security-protectai) 与 [JFrog 安全扫描器](https://huggingface.co/docs/hub/en/security-jfrog)
- 模型权重以 [safetensors](https://huggingface.co/docs/safetensors/main/en/index) 格式存储，规避潜在的 Pickle 漏洞
- 不含[远程代码](https://huggingface.co/docs/transformers/main/en/models#custom-models)，避免运行时插入任意代码。

此外，微软与 Hugging Face 将持续测试推理容器漏洞，并按需维护和修补。

假设你想部署广受欢迎的 [Microsoft Phi-4 Reasoning Plus](https://huggingface.co/microsoft/Phi-4-reasoning-plus) 开放模型。

首先，在 Azure AI Foundry 的 Hugging Face 合集中选中该模型，点击 "Deploy" 按钮。表单允许你选择 VM、实例数量与部署参数，再点击一下就启动部署流程！

另外，如果你更喜欢在 Hub 上浏览模型，也可以从模型页入手——"Deploy on Azure ML" 选项会把你带到 Azure AI Machine Learning Studio 中同样的部署入口。

## Azure AI Foundry 上还将有更多 Hugging Face

我们对如今在 Azure AI Foundry 内直接可用的大量新 Hugging Face 模型和新模态感到非常兴奋，但我们不会止步于此！

在未来数周数月，你可以期待一连串 updates 滚雷般到来：

- Day-0 发布——Hugging Face 将与微软合作，让顶级模型提供商的新模型在登陆 Hugging Face 当天即进入 Azure AI Foundry
- 趋势模型更新——Hugging Face 将持续监测热门模型，每天将其接入 Azure AI Foundry
- 新模态——Hugging Face 与微软将共同支持更多模态和领域专用任务，包括视频、3D、时间序列、蛋白质等
- Agents 与工具——小型、高效、专用的开放模型使它们成为构建强大而安全的 AI agent 与应用的理想选择

如果你在 Azure 上，用开放模型构建的时刻到了！
