#### **1. ML 是如何给电商带来积极影响的？**

我会说，ML 在某些具体场景把不可能变成了可能，比如欺诈防范；而在绝大多数其他领域，它以我们想象不到的方式优化了流程和流转。

介于两者之间，有一些应用用 ML 把用户体验拉升到了下一个层级——否则那种体验会贵得难以实现（但也许做得到）。比如用户在商品和优惠之间浏览时，旅程中被注入的发现感和"缘分感"（serendipity）。

我们的搜索、推荐、广告、信用评分、内容审核、多个关键维度的预测、物流等等核心业务，都至少用机器学习优化了一个基本指标。

我们甚至用 ML 来优化基础设施的预留与使用方式。

#### **2. 电商领域最大的 ML 挑战是什么？**

除了摆在面前的所有技术挑战（比如越来越强的实时性和个性化），最大的挑战始终是关注终端用户。

电商的市场份额逐年扩大，而机器学习永远是概率性的方法，给不了 100% 的完美。我们要小心：在持续优化产品的同时，别忘了长尾和每一个个体的体验。

最后，还有一个不断增大的挑战：在多渠道、多业务的世界里协调并促进数据（输入和输出）共存——市场、物流、信贷、保险、线下门店支付等等。

#### **3. 人们在把 ML 融入电商时常犯什么错误？**

最常见的错误是工具和问题不匹配、用错了地方。

比如，一开始就搞复杂的，而不是先上最简单的基线；比如，不去度量"有/没有机器学习"的影响；比如，在还不清楚预期收益边界的情况下就投入技术。

最后同样重要：只想短期，忘了隐藏的影响、技术债、维护成本等等。

#### **4. ML 的未来最让你兴奋的是什么？**

站在战壕里、像十年前那样亲手打磨技术的视角来看，我最欣慰的是：作为行业，我们正在解决这个挑战里那些缓慢、重复、枯燥的大部分环节。

目标当然一直在移动，新的困难不断出现。但我们在引入成熟工具和实践方面越做越好，这会带来更短的建模循环——说到底就是缩短了上线时间。

#### **1. ML 是如何给工程领域带来积极影响的？**

工程的应用面广，可以涵盖大量领域。话虽如此，最近我们看到 ML 正在影响一系列工程层面——从机器人、汽车工程等显而易见的领域，到化学、土木工程等不那么显而易见的领域。ML 的应用范围之广，使得只要存在由既往劳动过程记录构成的训练数据，就足以尝试让 ML 影响你的底线。本质上，我们身处一个 ML 已深刻影响各类原本仅由人操作的工程流程自动化的时代。

#### **2. 工程领域最大的 ML 挑战是什么？**

- 最大的挑战在于如何操作化、部署 ML 训练出的方案，使人类操作可以被替换且后果最小。我们如今在完全自动驾驶汽车上看到这一点。以几乎不危及人类或人类赖以运转的流程为前提去自动化，是非常难的。这个现象中最让我担忧的典型例子是 ML 与偏见（bias）。一个现实是：在包含偏见决策（即便制作者并未察觉）的数据上训练出的 ML 模型，会在运行中复现这种偏见。在把 ML 纳入工程时，必须把偏见问题放在最显眼的位置，避免把系统性种族主义传播到未来的技术进步中、进而伤害弱势群体。在从有偏过程产生的数据上训练 ML 系统，注定会重蹈覆辙——尤其是当训练 ML 方案的人没有清醒意识到待自动化流程中所有形式的数据时。
- 工程中 ML 的另一个关键挑战是，这个领域在很大程度上以"需要解决问题"为特征，而解决问题常常需要创造力。就现在而言，ML 智能体真正"有创意"、能"跳出框框思考"的好例子还很少，因为当前的 ML 解法往往只是对全部可能解的搜索的结果。依我浅见，尽管很多解可以通过这些方法找到，但在 ML 能在多种问题空间中稳定展现创造力之前，它在工程上会有某种天花板。话虽如此，那个天花板依然很高，工程中的 ML 应用还有很多可以达成。

#### **3. 人们在把 ML 融入工程时常犯什么错误？**

在小数据集上用火力过猛的 ML 技术，是我常见到的工程融入 ML 的错误之一。比如深度学习正把 AI 和 ML 带到短时间内难以想象的高度，但根据你的问题空间，它未必是你解决问题的最佳方法。往往在小型训练集、有限硬件条件下，更简单的方法同样有效甚至更好。

另外，没有为你的 ML 方案搭建有效的 CI/CD（持续集成/持续部署）结构，也是我常见的错误。一次训练好的模型往往并不够用——不仅因为数据随时间变化，资源和人员也在变。今天的 ML 从业者需要：

- 在数据变化时保障稳定的数据流，并持续重训练新模型以保持准确和有用；
- 建立相应结构，让新训练的模型能无缝替换旧模型，同时
- 把对 ML 模型输出消费方的干扰降到最低。

#### **4. ML 的未来最让你兴奋的是什么？**

ML 的未来持续令人兴奋，几乎每个月都有让业内专家都惊叹的进展见诸报道。随着 1) ML 技术精进、对资深从业者和新人都更易上手，2) 日常硬件越来越快，3) 微型化边缘设备的功耗问题越来越不是问题，4) 内存限制随时间缓解——工程领域 ML 的天花板在未来多年都会一片光明。

#### **1. ML 是如何给教育带来积极影响的？**

线上按需教育内容让全球数十亿人的终身学习前所未有的可及。几十年的认知科学研究表明，教育内容的相关性、形式和顺序对学生的学习成效影响很大。深度学习内容检索与推荐算法的进步，大幅提升了我们规模化创建定制化、高效学习路径的能力，并且能随时间适应每个学生的需求。

#### **2. 教育领域最大的 ML 挑战是什么？**

我认为 MLOps 技术是整个行业改进 ML 的关键机会领域。今天 MLOps 技术的状态让我想起 2015-16 年前后的容器编排大战。ML 的 Train-Deploy-Monitor 技术栈存在多种相互竞争的方案，每个都有热情的社区布道、大型组织背书。如果最终出现一种主导愿景，MLOps 工程模式的共识就可能随之而来，从而降低当前给 ML 团队造成摩擦的决策复杂度。

#### **3. 人们在把 ML 融入现有产品时常犯什么错误？**

我见过各种规模的组织在起步 ML 时犯两个关键错误。第一个是低估了"投资有丰富实操 ML 经验的资深领导者"的重要性。ML 战略与运营领导力需要超出 BI/分析领域通常水平、也超出那些只给入门介绍的培训项目所能提供的技术深度。第二个错误是太晚着手设计、测试和落地生产部署流水线。有效的原型模型可能在仓库里搁几个月甚至几年，等 ML 流水线开发。这会给组织造成巨大的机会成本，并让 ML 团队沮丧到增加离职风险。

#### **4. ML 的未来最让你兴奋的是什么？**

我最兴奋的是指导下一代 ML 领导者的机会。我的职业生涯始于云计算平台刚刚起步、ML 工具远不如今天成熟的年代。当时探索 ML 实验和部署的不同工程模式很令人兴奋，因为成熟的最佳实践很罕见。但那种探索也意味着太多技术上的和带人的教训只能靠吃苦头学会。把这些教训分享给下一代 ML 领导者，能帮助他们把这个领域推向比过去十多年所见更远、更快的地方。

#### **1. ML 是如何给 SaaS 带来积极影响的？**

机器学习在 SaaS 中已真正进入运营状态，驱动从个性化、语义与图像搜索、推荐到异常检测以及大量其他业务场景的多种用途。真正的影响在于：ML 越来越多地直接 baked 进应用里，成为一种预期，而且往往对终端用户不可见。例如在 Elastic，我们投资了面向异常检测的 ML，针对终端安全与 SIEM 做了优化。它开箱即用地提供了强大火力，融合了时间序列分解、聚类、相关性分析、贝叶斯分布建模等不同技术。对安全分析师而言，最大的好处是威胁检测以许多不同方式被自动化了——时间偏离、异常地理位置、统计稀有度等众多因素相关的异常会很快浮出水面。这就是融入 ML 带来的巨大正面影响。

#### **2. SaaS 领域最大的 ML 挑战是什么？**

要最大化 ML 的收益，存在一个双重挑战：既要为不熟悉机器学习的用户交付价值，也要为经验丰富的数据科学家交付价值。这两类人的需求 obviously 天差地别。如果一个 ML 能力完全是黑箱，它很可能过于僵化或简单，产生不了真正影响；反过来，如果只提供开发者工具箱，那只有当企业自带数据科学团队时才用得上。把握正确平衡的关键是：让 ML 足够开放，使数据科学团队对模型有透明度和控制权；同时内置久经沙场的模型，让非专业人士也能轻松配置和部署。

#### **3. 人们在把 ML 融入 SaaS 时常犯什么错误？**

要把它做对，任何集成的模型都必须能在规模上工作——意味着支持海量数据集，同时保证结果仍然高性能且准确。举个真实例子说明。向量搜索的兴趣激增：文本、图像、事件等各种东西都可以用向量表示。向量可以用来刻画内容之间的相似性，非常适合搜索相关性和推荐等场景。难点在于开发能比较向量的算法，同时权衡速度、复杂度和成本。在 Elastic，我们花了很多时间评估和基准测试向量搜索模型的性能。我们最终选择了一种叫 Hierarchical Navigable Small World 图（HNSW）的近似最近邻（ANN）算法，基本上是按向量彼此之间的相似度把它们映射到一张图上。在各种 ANN 基准测试中，HNSW 带来了速度和精度一个数量级的提升。这只是一个非平凡决策的例子——越来越多的产品和工程团队需要做出这样的决策，才能成功把 ML 融入产品。

#### **4. ML 的未来最让你兴奋的是什么？**

机器学习会变得像网购一样简单。尤其是 NLP 的巨大进步，让 ML 通过理解上下文、意图和含义变得更"人性化"。我认为我们正处于基础模型时代，它将向许多有趣的方向开花。在 Elastic，我们对自己的 Hugging Face 集成感到非常高兴，也已经兴奋地看到客户如何把 NLP 用于可观测性、安全和搜索。
