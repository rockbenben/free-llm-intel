# DuckDB：在 Hugging Face Hub 的 5 万多个数据集上运行 SQL 查询

Hugging Face Hub 致力于向所有人开放数据集的访问，并提供工具帮助用户探索和理解它们。你能找到许多用于训练流行大语言模型（LLM）的数据集，例如 [Falcon](https://huggingface.co/datasets/tiiuae/falcon-refinedweb)、[Dolly](https://huggingface.co/datasets/databricks/databricks-dolly-15k)、[MPT](https://huggingface.co/datasets/mosaicml/dolly_hhrlhf) 和 [StarCoder](https://huggingface.co/datasets/bigcode/the-stack)。有解决数据集中公平性与偏见问题的工具，如 [Disaggregators](https://huggingface.co/spaces/society-ethics/disaggregators)，也有预览数据集内部样本的工具，如 Dataset Viewer。

用 Dataset Viewer 预览 OpenAssistant 数据集。

我们很高兴地分享，最近又新增了一项帮助你分析 Hub 上数据集的功能：你可以用 DuckDB 对 Hub 上存储的任何数据集运行 SQL 查询！根据 2022 年 [StackOverflow 开发者调查](https://survey.stackoverflow.co/2022/#section-most-popular-technologies-programming-scripting-and-markup-languages)，SQL 是第三大流行的编程语言。我们同时也想要一个专为运行分析查询而设计的快速数据库管理系统（DBMS），这就是我们对集成 [DuckDB](https://duckdb.org/) 感到兴奋的原因。我们希望这能让更多用户访问并分析 Hub 上的数据集！

## TLDR

[数据集查看器（dataset viewer）](https://huggingface.co/docs/datasets-server/index)**会自动把 Hub 上所有公开数据集转换为 Parquet 文件**，你可以通过点击数据集页面顶部的 "Auto-converted to Parquet" 按钮查看。你也可以用一个简单的 HTTP 调用获取 Parquet 文件 URL 列表。

```
r = requests.get("https://datasets-server.huggingface.co/parquet?dataset=blog_authorship_corpus")
j = r.json()
urls = [f['url'] for f in j['parquet_files'] if f['split'] == 'train']
urls
['https://huggingface.co/datasets/blog_authorship_corpus/resolve/refs%2Fconvert%2Fparquet/blog_authorship_corpus/blog_authorship_corpus-train-00000-of-00002.parquet',
 'https://huggingface.co/datasets/blog_authorship_corpus/resolve/refs%2Fconvert%2Fparquet/blog_authorship_corpus/blog_authorship_corpus-train-00001-of-00002.parquet']
```

创建到 DuckDB 的连接，并安装、加载 `httpfs` 扩展，以允许读写远程文件：

```
import duckdb

url = "https://huggingface.co/datasets/blog_authorship_corpus/resolve/refs%2Fconvert%2Fparquet/blog_authorship_corpus/blog_authorship_corpus-train-00000-of-00002.parquet"

con = duckdb.connect()
con.execute("INSTALL httpfs;")
con.execute("LOAD httpfs;")
```

连接建立后，你就可以开始编写 SQL 查询了！

```
con.sql(f"""SELECT horoscope, 
    count(*), 
    AVG(LENGTH(text)) AS avg_blog_length 
    FROM '{url}' 
    GROUP BY horoscope 
    ORDER BY avg_blog_length 
    DESC LIMIT(5)"""
)
```

要了解更多，请查看[文档](https://huggingface.co/docs/datasets-server/parquet_process)。

## 从数据集到 Parquet

[Parquet](https://parquet.apache.org/docs/) 文件是列式的（columnar），这使它们在存储、加载和分析上更高效。当处理大数据集时这一点尤其重要，而在 LLM 时代我们越来越多地遇到这种数据集。为支持这一点，数据集查看器会自动把 Hub 上的任何公开数据集转换并发布为 Parquet 文件。Parquet 文件的 URL 可以通过 [`/parquet`](https://huggingface.co/docs/datasets-server/quick_start#access-parquet-files) 端点获取。

## 用 DuckDB 分析

DuckDB 在运行复杂分析查询时展现出令人惊叹的性能。它能够直接在一个远程 Parquet 文件上执行 SQL 查询而没有任何额外开销。借助 [`httpfs`](https://duckdb.org/docs/extensions/httpfs) 扩展，DuckDB 可以通过 `/parquet` 端点提供的 URL 查询诸如存储在 Hub 上的数据集等远程文件。DuckDB 还支持一次查询多个 Parquet 文件，这非常便利，因为数据集查看器会把大数据集切分成更小的 500MB 块。
