# 分析很重要

分析和指标是理解你的部署状态的基石。你的 [Inference Endpoints](https://endpoints.huggingface.co) 是否超载？它们正在处理多少请求？把相关指标以良好的可视化形式实时呈现，对监控和调试至关重要。

我们意识到自己的分析仪表盘需要一次升级。由于我们自己大量调试 endpoints，我们和用户的痛点感同身受。因此我们坐下来规划并做了多项改进，为你带来更好的体验。

# 有什么新内容？

⏰ 实时指标：数据现在实时更新，确保你获得精确到秒的 endpoint 性能视图。无论你监控的是请求延迟、响应时间还是错误率，现在都能看到事件发生的那一刻。我们还重构了分析仪表盘的后端，确保数据快速加载，尤其是高流量 endpoint。不再干等指标填充，打开仪表盘即刻获得洞察。
