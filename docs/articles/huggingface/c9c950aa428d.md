# 用 ONNX Runtime 加速超过 13 万个 Hugging Face 模型

## 什么是 ONNX Runtime？

ONNX Runtime 是一款跨平台机器学习工具，可用于加速各种各样的模型，尤其是那些支持 ONNX 的模型。

## Hugging Face 对 ONNX Runtime 的支持

Hugging Face 是一个开源社区，允许用户构建、训练和部署数十万个公开可用的机器学习模型，其上有超过 13 万个支持 ONNX 的模型。这些支持 ONNX 的模型，包括日益流行的许多大语言模型（LLM）和云端模型，都可以借助 ONNX Runtime 提升性能并获得其他收益。例如，用 ONNX Runtime 加速 whisper-tiny 模型可以改善每次推理的平均延迟，相比 PyTorch 最高可获得 74.30% 的提升。ONNX Runtime 与 Hugging Face 紧密协作，确保站上最受欢迎的模型都得到支持。总计，ONNX Runtime 支持超过 90 种 Hugging Face 模型架构，其中包括 11 种最受欢迎的架构（流行度以上传至 Hugging Face Hub 的对应模型数量衡量）：

| 模型架构 | 大约模型数量 |
| --- | --- |
| BERT | 28180 |
| GPT2 | 14060 |
| DistilBERT | 11540 |
| RoBERTa | 10800 |
| T5 | 10450 |
| Wav2Vec2 | 6560 |
| Stable-Diffusion | 5880 |
| XLM-RoBERTa | 5100 |
| Whisper | 4400 |
| BART | 3590 |
| Marian | 2840 |
