# Snorkel AI × Hugging Face：为企业解锁基础模型

*本文转自 2023 年 4 月 6 日首先发表于 [Snorkel 博客](https://snorkel.ai/snorkel-hugging-face-unlock-foundation-models-for-enterprise/) 的一篇文章，作者 Friea Berg。*

随着 OpenAI 发布 [GPT-4](https://openai.com/research/gpt-4)、Google 推出 Beta 版的 [Bard](https://gizmodo.com/google-bard-chatgpt-ai-rival-released-1850248162)，全球的企业都渴望借助基础模型（foundation model）的力量。而随着这份热情升温，人们也愈发意识到：大多数公司和组织其实并没有能力真正用好基础模型。

基础模型给企业带来了一整套独特的挑战。它们前所未有的规模使得企业自行托管既困难又昂贵；而直接把现成的基础模型用于生产场景，则可能意味着糟糕的性能，或重大的治理与合规风险。

Snorkel AI 正是弥合基础模型与企业实际用例之间鸿沟的桥梁，并已为 Pixability 这样的 AI 创新者[取得了令人瞩目的成果](https://snorkel.ai/how-pixability-uses-foundation-models-to-accelerate-nlp-application-development-by-months/)。我们与 [Hugging Face](https://huggingface.co/)——以其庞大的即用型开源模型仓库而闻名——携手，为企业在开发 AI 应用时提供更灵活的自由度与更多选择。

## Snorkel Flow 中的基础模型

Snorkel Flow 开发平台让用户能够针对自己的具体用例[适配基础模型](https://snorkel.ai/snorkel-flow/foundation-model-development/)。应用开发从检查所选基础模型"开箱即用"地在你的数据上所做的预测开始。这些预测成为相应数据点训练标注的初始版本。Snorkel Flow 帮助用户识别模型中的错误模式，并通过[程序化标注（programmatic labeling）](https://snorkel.ai/programmatic-labeling/)高效纠正它们——程序化标注可以用启发式规则或[提示（prompts）](https://snorkel.ai/combining-foundation-models-with-weak-supervision/)来更新训练标注。随后，基础模型可以在更新后的标注上进行微调并再次评估，如此反复"检测并纠正"，直到适配后的基础模型达到足以部署的高质量。

Hugging Face 通过让 15 万多个开源模型即时可用、来源统一，助力这一强大的开发流程。其中许多模型是在领域特定数据上专门化的，例如 BioBERT 和 SciBERT 模型曾被用来展示[如何用 ML 识别药物不良事件](https://snorkel.ai/adverse-drug-events-how-to-spot-them-with-machine-learning/)。一个——或者更好的是，[多个](https://snorkel.ai/combining-foundation-models-with-weak-supervision/)——专门的基座模型，能让用户在初始预测、改进标注的提示，或为部署微调最终模型上抢得先机。

## Hugging Face 如何提供帮助？

Snorkel AI 与 Hugging Face 的合作为 Snorkel Flow 的基础模型能力注入了强大动力。最初我们只提供了少量基础模型。每一个都需要一个专属服务，这让我们难以经济高效地为企业提供灵活性，以利用飞速增长的模型种类。采用 Hugging Face 的 Inference Endpoint 服务后，我们得以扩展用户可用的基础模型数量，同时把成本控制在可管理的范围。

Hugging Face 的服务让用户点击几下就能创建一个模型 API 并立即使用。关键在于，这项新服务具备"暂停与恢复"能力，让我们能在客户需要时激活模型 API，不需要时让它休眠。

"我们惊喜地发现 Hugging Face Inference Endpoint 服务的搭建是多么简单……所有配置选项都不言自明，同时我们还能获得所需的各种选项，比如在哪个云上运行、需要何种安全级别等。"

– Snorkel CTO 兼联合创始人 Braden Hancock

## 这对 Snorkel 客户有何帮助？

很少有企业有资源从零开始训练自己的基础模型。虽然许多企业可能具备内部专业知识来微调自己版本的基础模型，却常常在为该任务收集所需数据量上犯难。Snorkel 以数据为中心的基础模型开发平台，加上与 Hugging Face 等行业领先创新者的契合，把基础模型的力量送到了用户指尖。

#### "借助 Snorkel AI 和 Hugging Face Inference Endpoints，企业将以开源为核心，加速其以数据为中心的 AI 应用。机器学习正成为构建技术的默认方式，而从开源构建让企业能够为自身用例打造合适的方案，并掌控他们提供给客户的体验。我们很高兴看到 Snorkel AI 基于开放的 Hugging Face 模型和我们的机器学习生产服务 Inference Endpoints，为企业实现自动化的数据标注。"

Clement Delangue，联合创始人兼 CEO，Hugging Face

## 结论

Snorkel 与 Hugging Face 联手，让大型公司、政府机构和 AI 创新者从基础模型中获取价值变得前所未有地简单。能够使用 Hugging Face 全面的基础模型中心（hub），意味着用户可以选择最契合自身业务需求的模型，而无需投入训练它们所需的资源。这次集成是让更多人能够使用基础模型、使其更易于被全球企业获取的重要一步。
