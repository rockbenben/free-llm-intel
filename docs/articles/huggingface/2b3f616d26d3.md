在[上一篇文章](https://huggingface.co/blog/hf-torchneuron)中，我们介绍了 TorchNeuron，它是 AWS Trainium 的本机 PyTorch 后端（“torch-neuronx”包）。有了它，Transformers 在 Trainium 上运行自己的建模代码，就像在任何其他设备上一样，因此 Hub 上的任何 Transformers 模型都可以运行。哪些实际上是这样做的？

[torch-neuronx 模型支持](https://huggingface.co/spaces/aws-neuron/torch-neuronx-model-support) Space 回答了 Hub 上最流行模型的问题。它告诉您模型是否可以在 Trainium 上未经修改地运行，并为您提供自行运行该模型的脚本。

[![torch-neuronx 模型支持](https://huggingface.co/spaces/aws-neuron/torch-neuronx-model-support/resolve/main/thumbnail.jpg)](https://huggingface.co/spaces/aws-neuron/torch-neuronx-model-support)

## 查找模型

该空间在 **选定** 视图中打开：我们根据下载量和趋势分数从 Hub 上的顶级模型中挑选出我们自己选择的模型。每行给出结果、模型分片的 Trainium 核心数量、运行的挂起时间（包括编译）以及峰值设备内存。

要查找给定模型，请切换到 **趋势** 或 **下载** 视图并键入其名称的一部分。这些视图遵循中心自己的排名，一次一项任务，无论模型是否经过测试。当某个模型被故意遗漏时，空间会告诉您原因（大多数时候它没有优先考虑，有时它确实不兼容）。您还可以选择 Neuron 编译器 (`neuronx-cc`) 和 Transformer 的版本进行查看。

> 在撰写本文时，仅测试了 Transformers 模型，我们的选择仅限于文本生成和图像-文本到文本模型。我们计划扩展到扩散器、句子转换器和其他转换器任务。

## 自己运行一下

选择一个模型以查看如何运行它。空间列出了测试模型的神经元堆栈、要在其上安装的软件包以及运行的“run.py”脚本。该脚本遵循 [TorchNeuron 公告](https://huggingface.co/blog/hf-torchneuron) 的配方：它使用“from_pretrained”加载模型，在需要时进行分片，然后使用静态缓存和“torch.compile(backend="neuron")”生成。

在具有该堆栈的 Trainium2 (`trn2`) 实例上，例如在 [AWS Neuron 深度学习容器](https://github.com/aws-neuron/deep-learning-containers#torch-neuronx) 中，安装软件包，然后运行：
```
python3 run.py
```
不需要“torchrun”：当模型分片时，脚本会启动自己的“torch.distributed”排名。

第一次运行从编译模型的图表开始。要跳过该步骤，请从公共 [NEFF 缓存](https://huggingface.co/buckets/aws-neuron/torch-neuronx-neff-cache) 存储桶复制测试期间构建的同一编译器的图表。 Space 为您提供命令以及正确的编译器版本：
```
hf buckets sync hf://buckets/aws-neuron/torch-neuronx-neff-cache/neuronxcc-<version> /tmp/neff_cache
```
## “运行”是什么意思

每个测试都将模型加载到“trn2”实例上，并在能够承受其重量的最小数量的 Trainium 核心上进行分片。大多数模型都采用张量并行性进行分片。没有张量并行计划的专家混合模型仅使用专家并行性。然后测试生成 32 个令牌并检查它们。在单核上，将令牌与相同检查点的 CPU 运行的令牌进行比较。当模型被分片时，一个小的判断模型会检查文本是否是流利的英语。

在撰写本文时，仅测试了适合 4 个 Trainium2 设备的模型，这意味着最多 16 个内核。 “PASS”没有说明吞吐量或更长的代数。

## 结果是一个数据集

空间显示的所有内容均来自公共 [`aws-neuron/torch-neuronx-model-support`](https://huggingface.co/datasets/aws-neuron/torch-neuronx-model-support) 数据集，每对 `neuronx-cc` 和库版本有一个 Parquet 文件。

每行保存模型的结果、失败时的错误、整个堆栈的版本以及运行的“run.py”。可以直接查询：
```
import pandas as pd

df = pd.read_parquet("hf://datasets/aws-neuron/torch-neuronx-model-support/data")
df[df.model_id == "Qwen/Qwen3-0.6B"][["neuronx_cc", "library", "library_version", "neuron_cores", "result"]]
```
[数据集卡](https://huggingface.co/datasets/aws-neuron/torch-neuronx-model-support)给出了每个结果的确切含义。

下次您想知道模型是否在 Trainium 上运行时，请[查找](https://huggingface.co/spaces/aws-neuron/torch-neuronx-model-support)。
