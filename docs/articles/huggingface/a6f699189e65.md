## **什么是强化学习？**

要理解强化学习，我们先从宏观视角说起。

### **宏观视角**

强化学习背后的思想是：一个智能体（AI）通过**与环境交互**（反复试错）并**接收奖励**（负向或正向）作为对动作的反馈，从环境中学习。

从与环境的交互中学习，**来源于我们天然的经验。**

比如，想象把你弟弟放到一个他从没玩过的电子游戏前，把手柄交给他，然后走开。

你弟弟会通过与环境（电子游戏）交互来探索——按下某个按钮（动作）。他吃到一枚金币，这是 +1 奖励。奖励是正向的，他立刻就明白了：在这个游戏里**必须吃金币。**

但接着，**他又按了右方向**，撞到了一个敌人，他死了——奖励 -1。

通过与环境反复试错，你弟弟明白了：**在这个环境里要吃金币，但得避开敌人。**

**在没有任何监督的情况下**，这个孩子玩游戏的水平会越来越高。

人类和动物就是这样学习的——**通过交互。**强化学习只是一种**从行动中学习的计算化方法。**

### **形式化定义**

换成正式的定义：

> 强化学习是解决控制任务（也称决策问题）的一种框架：通过构建智能体，让它与环境交互、反复试错，并把接收到的奖励（正向或负向）作为唯一反馈，从而从环境中学习。

⇒ 那强化学习到底是怎么运作的？

## **强化学习框架**

### **RL 过程**

RL 过程：状态、动作、奖励、下一状态的循环

来源：

Reinforcement Learning: An Introduction，Richard Sutton 与 Andrew G. Barto

为了理解 RL 过程，我们想象一个智能体正在学习玩平台游戏：

- 我们的智能体从**环境**接收到**状态 S0S_0S0​**——我们拿到游戏（环境）的第一帧画面。
- 基于这个**状态 S0S_0S0​**，智能体采取**动作 A0A_0A0​**——我们的智能体向右移动。
- 环境进入一个**新状态 S1S_1S1​**——新的画面。
- 环境给智能体一些**奖励 R1R_1R1​**——我们还没死 *(正向奖励 +1)*。

这个 RL 循环输出一个由**状态、动作、奖励和下一状态**组成的序列。

智能体的目标是最大化它的累计奖励，即**期望回报（expected return）**。

### **奖励假说：强化学习的核心思想**

⇒ 为什么智能体的目标是最大化期望回报？

因为 RL 建立在**奖励假说（reward hypothesis）**之上：一切目标都可以被描述为**期望回报（期望累计奖励）的最大化**。

所以在强化学习中，**要拥有最好的行为**，我们就需要**最大化期望累计奖励。**

### **马尔可夫性质**

在论文里，你会看到 RL 过程被称为**马尔可夫决策过程（Markov Decision Process，MDP）**。

后面的单元我们还会再讲马尔可夫性质。但如果你今天只需要记住一点，那就是：马尔可夫性质意味着我们的智能体做决策时**只需要当前状态**，而**不需要它过去所有状态和动作的历史**。

### **观测/状态空间**

观测/状态是**智能体从环境获得的信息。**对于电子游戏，它可能是一帧画面（一张截图）；对于交易智能体，它可能是某只股票的价值，等等。

*观测（observation）*和*状态（state）*之间有一个区别：

- *状态 s*：是对世界状态的**完整描述**（没有隐藏信息），存在于完全可观测的环境中。

动作空间是环境中**所有可能动作**的集合。

动作可以来自*离散*或*连续*空间：

- *离散空间*：可能动作的数量是**有限的**。

同样以超级马里奥兄弟为例，只有 4 个方向加跳跃这几个动作。

### **奖励与折扣**

奖励在 RL 中是根本性的，因为它是智能体的**唯一反馈**。依靠奖励，我们的智能体才知道**刚才的动作好不好。**

每个时间步 t 的累计奖励可以写成：

累计奖励等于序列中所有奖励的总和。

等价于：

累计奖励 = rt+1 (rt+k+1 = rt+0+1 = rt+1)+ rt+2 (rt+k+1 = rt+1+1 = rt+2) + ...

但在实际中，**我们不能简单地把它们直接相加。**越早到来的奖励（游戏刚开始时的奖励）**越可能兑现**，因为它们比长期的未来奖励更可预测。

假设你的智能体是那只每步只能移动一格的鼠鼠，而你的对手是会移动的猫。目标是**在被猫吃掉之前吃到尽可能多的奶酪。**

从图中可以看到，**吃到近处奶酪的概率比吃到靠近猫的奶酪更高**（离猫越近越危险）。

因此，**靠近猫的奖励即使更大（奶酪更多），也会被更多地打折**，因为我们不确定真能吃到它。

对奖励做折扣的过程是这样的：

- 我们定义一个折扣率，叫 gamma。**它必须介于 0 和 1 之间**，通常取 **0.99 到 0.95** 之间。

- gamma 越大，折扣越小，意味着我们的智能体**更看重长期奖励。**
- 反过来，gamma 越小，折扣越大，意味着我们的**智能体更看重短期奖励（最近的奶酪）。**

2. 然后，每个奖励都会被折扣为 gamma 的时间步次幂。随着时间步增加，猫离我们越来越近，**未来奖励兑现的可能性也越来越小。**

### 任务类型

任务是强化学习问题的一个**实例**。任务可以分为两类：episodic（回合式）和 continuing（持续式）。

#### 回合式任务

这种情况下，任务有起点和终点（**终止状态**），从而形成一个个“回合”：一系列状态、动作、奖励和新状态的列表。

例如，想想超级马里奥兄弟：一个回合从进入新关卡开始，**在你死亡或到达关卡终点时结束。**

新回合开始。

#### 持续式任务

这类任务会永远持续下去（没有终止状态）。这种情况下，智能体必须**学会如何选择最佳动作，同时与环境保持交互。**

例如，一个做自动化股票交易的智能体。这个任务没有起点也没有终止状态。**它会一直运行，直到我们决定让它停下。**

## **探索/利用权衡**

最后，在看各种求解强化学习问题的方法之前，我们还得讨论另一个非常重要的主题：*探索/利用权衡（exploration/exploitation trade-off）。*

- 探索（Exploration）：通过尝试随机动作来探索环境，以**获取关于环境的更多信息。**
- 利用（Exploitation）：**利用已知的信息来最大化奖励。**

记住，我们 RL 智能体的目标是最大化期望累计奖励。但**我们可能掉进一个常见的陷阱。**

举个例子：

在这个游戏里，鼠鼠可以获得**无限数量的小奶酪**（每个 +1）。但在迷宫顶部，有一大堆奶酪（+1000）。

然而，如果只注重利用，我们的智能体永远到不了那大堆奶酪。它只会**利用最近的奖励来源**，哪怕那个来源很小（利用）。

但如果智能体做一点点探索，它就可能**发现这个大奖励**（那堆大奶酪）。

这就是所谓的探索/利用权衡。我们需要在**多大程度探索环境**和**多大程度利用对环境的已有认知**之间做好平衡。

因此，我们必须**定义一条规则来处理这个权衡**。后续章节我们会介绍处理它的不同方式。

如果还是有点绕，**想想一个现实问题：选餐馆：**

- *探索*：去你从没去过的餐馆，冒着体验很差的风险，**但也有机会收获一段美妙的体验。**

## **求解 RL 问题的两大主流方法**

⇒ 学完 RL 框架，我们该怎么求解 RL 问题？

换句话说，如何构建一个 RL 智能体，让它能**选择最大化期望累计奖励的动作？**

### **策略 π：智能体的大脑**

策略（Policy）**π** 是我们智能体的**大脑**，它是一个函数，告诉我们**在当前状态下该采取什么动作**。它定义了智能体在某一时刻的**行为**。

把策略想象成智能体的大脑，一个在给定状态下告诉我们该采取什么动作的函数

把策略想象成智能体的大脑，一个在给定状态下告诉我们该采取什么动作的函数

这个策略**正是我们要学习的函数**。我们的目标是找到最优策略 **π*——智能体按其行动时能最大化期望回报**的策略。我们**通过训练**找到这个 **π*。

有两种训练智能体、寻找最优策略 π* 的途径：

- **直接**教智能体在给定状态下**该做什么动作**：**基于策略的方法（Policy-Based Methods）。**
- 间接地，先**教智能体判断哪些状态更有价值**，然后采取**通向更有价值状态**的动作：基于价值的方法（Value-Based Methods）。

### **基于策略的方法**

在基于策略的方法中，**我们直接学习一个策略函数。**

这个函数会把每个状态映射到该状态下最好的对应动作，**或映射到该状态下所有可能动作上的一个概率分布。**

这里可以看到，策略（确定性）

直接指出了每一步该采取的动作。

策略有两种类型：

- *确定性（Deterministic）*：在给定状态下，策略**永远返回同一个动作。**

action = policy(state)

- *随机型（Stochastic）*：输出**动作上的概率分布。**

policy(actions | state) = 当前状态下所有动作构成的集合上的概率分布

给定一个初始状态，我们的随机策略会输出该状态下各可能动作的概率分布。

小结：

### **基于价值的方法**

在基于价值的方法中，我们不是训练策略函数，而是**训练一个价值函数**，把状态映射到**处于该状态的期望价值**。

一个状态的价值，是智能体**从该状态出发、并按我们的策略行动**时能获得的**期望折扣回报**。

“按我们的策略行动”只是意味着我们的策略是**“走向价值最高的状态”。**

这里可以看到，我们的价值函数**为每个可能的状态定义了价值。**

多亏了价值函数，每一步我们的策略都会选择价值函数定义下价值最大的状态：-7，然后 -6，然后 -5（依此类推），直到达成目标。

## **强化学习里的“深度”**

⇒ 我们刚才讲的是强化学习。那“深度”体现在哪里？

深度强化学习引入**深度神经网络来求解强化学习问题**——“深度”之名由此而来。

例如，下一篇文章里，我们会先做 Q-Learning（经典强化学习），再做 Deep Q-Learning，两者都是基于价值的 RL 算法。

你会看到区别在于：第一种方法用**传统算法**构建一张 Q 表，帮我们在每个状态下找到该做的动作。

第二种方法则用**神经网络**（来近似 q 值）。

图示灵感来自 Udacity 的 Q learning notebook

如果你还不熟悉深度学习，强烈建议看一下 [fastai 的 Practical Deep Learning for Coders（免费）](https://course.fast.ai/)

信息量很大，我们总结一下：

- 强化学习是一种从行动中学习的计算方法。我们构建一个智能体，让它**通过反复试错与环境交互**，并以接收到的奖励（负向或正向）作为反馈来学习。
- 任何 RL 智能体的目标都是最大化其期望累计奖励（也称期望回报），因为 RL 建立在**奖励假说**之上：**一切目标都可以描述为期望累计奖励的最大化。**
- RL 过程是一个循环，输出**状态、动作、奖励和下一状态**的序列。
- 计算期望累计奖励（期望回报）时会对奖励做折扣：越早到来的奖励（游戏开始时）**越可能兑现**，因为它们比长期的未来奖励更可预测。
- 要解决一个 RL 问题，你想找到**一个最优策略**。策略是你 AI 的“大脑”，告诉我们**在给定状态下该做什么动作**。最优策略则给出**最大化期望回报**的那些动作。
- 找到最优策略有两条路：直接训练你的策略——**基于策略的方法**；训练一个价值函数，告诉你智能体在每个状态能获得的期望回报，并用这个函数来定义策略——**基于价值的方法。**
- 最后，我们之所以说“深度”强化学习，是因为我们引入**深度神经网络来估计该做的动作（基于策略）或估计状态的价值（基于价值）**，故名“深度”。
