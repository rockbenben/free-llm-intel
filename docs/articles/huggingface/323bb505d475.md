# 欢迎 Gradio 5

这篇文章也有中文版 [简体中文](https://huggingface.co/blog/zh/gradio-5)。

过去几个月我们一直在埋头苦干，现在很高兴宣布 **Gradio 5 稳定版发布**。

有了 Gradio 5，开发者可以用几行 Python 构建**可用于生产的机器学习 Web 应用**——高性能、可扩展、设计精美、无障碍可达，并遵循 Web 安全最佳实践。

想试试 Gradio 5，只需在终端输入：

```
pip install --upgrade gradio
```

然后开始构建你的[第一个 Gradio 应用](https://www.gradio.app/guides/quickstart)。

## Gradio 5：可用于生产的机器学习应用

如果你以前用过 Gradio，可能会好奇 Gradio 5 有什么不同。

我们在 Gradio 5 上的目标，是倾听并解决 Gradio 开发者在构建生产级 Gradio 应用时反馈最多的痛点。比如，我们听到一些开发者说：

- 「Gradio 应用加载太慢」→ Gradio 5 带来了重大性能改进，包括支持通过服务端渲染（SSR）来服务 Gradio 应用，浏览器里几乎瞬时加载。*再也看不到转圈了*！🏎️💨

- 「这个 Gradio 应用看起来过时了」→ Gradio 5 刷新了许多核心组件的设计，包括按钮、选项卡、滑块，以及高层聊天机器人界面，让它们更现代。我们还发布了一组全新内置主题，让你轻松做出面貌一新的 Gradio 应用 🎨
- 「我用 Gradio 做不了实时应用」→ 我们在 Gradio 里解锁了低延迟流式传输！我们会在能提速的地方自动使用 base64 编码和 websocket，通过自定义组件支持 WebRTC，并大幅扩充了聚焦常见流式用例的文档和示例 demo，例如基于网络摄像头的目标检测、视频流、实时语音转写与生成、以及对话式聊天机器人。🎤
- 「LLM 不认识 Gradio」→ Gradio 5 自带一个实验性 AI Playground，你可以用 AI 生成或修改 Gradio 应用，并立刻在浏览器里预览：[https://www.gradio.app/playground](https://www.gradio.app/playground)

Gradio 5 在提供这些能力的同时，保持了 Gradio 简单直观的对开发者友好的 API。既然 Gradio 5 立志成为面向各类机器学习应用的生产级 Web 框架，我们也在 Web 安全方面做了大量改进（包括完成了一次第三方审计）——相关内容见后续文章！

## 破坏性变更

在 Gradio 4.x 中没有触发任何弃用警告的 Gradio 应用，在 Gradio 5 中应当继续正常工作，仅有[少数例外，Gradio 5 的破坏性变更列表见这里](https://github.com/gradio-app/gradio/issues/9463)。

## Gradio 的下一步？

Gradio 5 中的许多改动，是为了支撑未来几周将要发布的新技术。敬请期待：

- Gradio 多页面应用，以及原生导航栏和侧边栏
- 支持用 PWA 在移动端运行 Gradio 应用，未来可能还有原生应用支持
- 更多媒体组件，支持图像和视频等领域的新模态
- 更丰富的 DataFrame 组件，支持常见的电子表格式操作
- 一行代码集成机器学习模型与 API 服务商
- 进一步降低 Gradio 应用内存占用的改进

还有更多！有了 Gradio 5 提供的构建 Web 应用的坚实地基，我们很期待*真正开始*让开发者用 Gradio 构建各种各样的 ML 应用。
