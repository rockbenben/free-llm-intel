# 在 Apple Silicon 上用 Core ML 运行 Stable Diffusion

Pedro Cuenca（pcuenq）

多亏了 Apple 的工程师，你现在可以用 Core ML 在 Apple Silicon 上运行 Stable Diffusion 了！

[这个 Apple 仓库](https://github.com/apple/ml-stable-diffusion)提供了基于 [🧨 Diffusers](https://github.com/huggingface/diffusers) 的转换脚本和推理代码，我们很喜欢它！为了让你尽可能省事，我们自己转换了权重，并把模型的 Core ML 版本放进了 [Hugging Face Hub](https://hf.co/apple)。

**更新**：在本文写成几周后，我们创建了一个原生 Swift 应用，你可以在自己的硬件上毫不费力地运行 Stable Diffusion。我们发布了 [Mac App Store 上的应用](https://apps.apple.com/app/diffusers/id1666309574)，以及 [允许其他项目使用它的源代码](https://github.com/huggingface/swift-coreml-diffusers)。

本文其余部分会指导你怎么在自己的代码里使用已转换的权重，或者自己转换更多权重。

## 可用的 Checkpoint

官方 Stable Diffusion checkpoint 已经转换好、随时可用：

- Stable Diffusion v1.4：[已转换](https://hf.co/apple/coreml-stable-diffusion-v1-4) [原始](https://hf.co/CompVis/stable-diffusion-v1-4)
- Stable Diffusion v1.5：[已转换](https://hf.co/apple/coreml-stable-diffusion-v1-5) [原始](https://hf.co/runwayml/stable-diffusion-v1-5)
- Stable Diffusion v2 base：[已转换](https://hf.co/apple/coreml-stable-diffusion-2-base) [原始](https://huggingface.co/stabilityai/stable-diffusion-2-base)
- Stable Diffusion v2.1 base：[已转换](https://hf.co/apple/coreml-stable-diffusion-2-1-base) [原始](https://huggingface.co/stabilityai/stable-diffusion-2-1-base)

Core ML 支持你设备里所有可用的计算单元：CPU、GPU 和 Apple 的神经引擎（NE）。Core ML 还能让模型的不同部分在不同设备上运行，以最大化性能。

每个模型都有若干变体，会根据你使用的硬件给出不同的性能。我们建议你都试一试，留下在你系统上表现最好的那个。详情见下。

## 性能说明

每个模型有几个变体：

- "Original" attention 与 "split_einsum"。这是关键 attention 块的两种替代实现。`split_einsum` 是 [Apple 之前引入的](https://machinelearning.apple.com/research/neural-engine-transformers)，兼容所有计算单元（CPU、GPU 和 Apple 神经引擎）。而 `original` 只兼容 CPU 和 GPU。尽管如此，`original` 在某些设备上可能比 `split_einsum` 更快，所以不妨一试！
- "ML Packages" 与 "Compiled" 模型。前者适合用 Python 推理，而 Swift 代码需要 `compiled` 版本。Hub 里的 `compiled` 模型把庞大的 UNet 权重拆分成多个文件，以兼容 iOS 和 iPadOS 设备。这对应于 [`--chunk-unet` 转换选项](https://github.com/apple/ml-stable-diffusion#-converting-models-to-core-ml)。

在本文撰写之时，我在我的 MacBook Pro（M1 Max，32 GPU 核，64 GB）上，用以下组合得到了最好的结果：

- `original` attention。
- `all` 计算单元（详情见下一节）。
- macOS Ventura 13.1 Beta 4 (22C5059b)。

用这些配置，用 Core ML 版 Stable Diffusion v1.4 生成一张图只花了 18 秒 🤯。

> ⚠️ 注意
> macOS Ventura 13.1 引入了若干 Core ML 的改进，而 Apple 的实现需要它们。如果你用更早版本的 macOS，你可能会得到黑图——以及慢得多的时间。

每个模型仓库按树状结构组织，提供这些不同的变体：

```
coreml-stable-diffusion-v1-4
├── README.md
├── original
│   ├── compiled
│   └── packages
└── split_einsum
    ├── compiled
    └── packages
```

你可以按下面的方式下载并使用你需要的变体。

## Python 中的 Core ML 推理

### 前置条件

```
pip install huggingface_hub
pip install git+https://github.com/apple/ml-stable-diffusion
```

### 下载模型 Checkpoint

要在 Python 里跑推理，你必须使用存放在 `packages` 文件夹里的版本之一，因为编译后的版本只兼容 Swift。你可以选择用 `original` 还是 `split_einsum` 的 attention 风格。

下面是从 Hub 下载 `original` attention 变体的方式：

```
from huggingface_hub import snapshot_download
from pathlib import Path

repo_id = "apple/coreml-stable-diffusion-v1-4"
variant = "original/packages"

model_path = Path("./models") / (repo_id.split("/")[-1] + "_" + variant.replace("/", "_"))
snapshot_download(repo_id, allow_patterns=f"{variant}/*", local_dir=model_path, local_dir_use_symlinks=False)
print(f"Model downloaded at {model_path}")
```

上面的代码会把下载的模型快照放进一个叫 `models` 的目录里。

### 推理

下载好模型快照后，最简单的跑推理方式是使用 Apple 的 Python 脚本。

```
python -m python_coreml_stable_diffusion.pipeline --prompt "a photo of an astronaut riding a horse on mars" -i models/coreml-stable-diffusion-v1-4_original_packages -o </path/to/output/image> --compute-unit ALL --seed 93
```

`<output-mlpackages-directory>` 应指向上一步你下载的 checkpoint，而 `--compute-unit` 表示你允许用于推理的硬件。它必须是以下选项之一：`ALL`、`CPU_AND_GPU`、`CPU_ONLY`、`CPU_AND_NE`。你还可以提供可选的输出路径和一个用于可复现的随机种子。

推理脚本假定使用的是存放在 Hub 上 `CompVis/stable-diffusion-v1-4` 的 Stable Diffusion 原始版本。如果你用别的模型，你*必须*用 `--model-version` 选项在推理命令行里指定它的 Hub id。这对已被支持的模型和你自己训练或微调的自定义模型都适用。

对于 Stable Diffusion 1.5（Hub id：`runwayml/stable-diffusion-v1-5`）：

```
python -m python_coreml_stable_diffusion.pipeline --prompt "a photo of an astronaut riding a horse on mars" --compute-unit ALL -o output --seed 93 -i models/coreml-stable-diffusion-v1-5_original_packages --model-version runwayml/stable-diffusion-v1-5
```

对于 Stable Diffusion 2 base（Hub id：`stabilityai/stable-diffusion-2-base`）：

```
python -m python_coreml_stable_diffusion.pipeline --prompt "a photo of an astronaut riding a horse on mars" --compute-unit ALL -o output --seed 93 -i models/coreml-stable-diffusion-2-base_original_packages --model-version stabilityai/stable-diffusion-2-base
```

## Swift 中的 Core ML 推理

在 Swift 里跑推理会比 Python 略快一些，因为模型已经以 `mlmodelc` 格式编译好了。这在应用启动、加载模型时会 noticeable，但如果你之后连续生成多次，应该就感觉不到了。

### 下载

要在你的 Mac 上用 Swift 跑推理，你需要 `compiled` checkpoint 版本之一。我们建议用 Python 代码在本地下载它们，代码与上面演示的类似，只是使用 `compiled` 变体之一：

```
from huggingface_hub import snapshot_download
from pathlib import Path

repo_id = "apple/coreml-stable-diffusion-v1-4"
variant = "original/compiled"

model_path = Path("./models") / (repo_id.split("/")[-1] + "_" + variant.replace("/", "_"))
snapshot_download(repo_id, allow_patterns=f"{variant}/*", local_dir=model_path, local_dir_use_symlinks=False)
print(f"Model downloaded at {model_path}")
```

### 推理

要跑推理，请克隆 Apple 的仓库：

```
git clone https://github.com/apple/ml-stable-diffusion
cd ml-stable-diffusion
```

然后借助 Swift Package Manager 的能力使用 Apple 的命令行工具：

```
swift run StableDiffusionSample --resource-path models/coreml-stable-diffusion-v1-4_original_compiled --compute-units all "a photo of an astronaut riding a horse on mars"
```

你需要在 `--resource-path` 里指定上一步下载的某个 checkpoint，所以请确保它包含扩展名为 `.mlmodelc` 的已编译 Core ML 包。`--compute-units` 必须是以下值之一：`all`、`cpuOnly`、`cpuAndGPU`、`cpuAndNeuralEngine`。

更多细节请参考 [Apple 仓库里的说明](https://github.com/apple/ml-stable-diffusion)。

## 自带你的模型

如果你创建了与 Stable Diffusion 兼容的自有模型（例如你用了 Dreambooth、Textual Inversion 或微调），那么你就得自己转换模型。好在 Apple 提供了一个转换脚本让你能做到这一点。

对于这个任务，我们建议你遵循[这些说明](https://github.com/apple/ml-stable-diffusion#converting-models-to-coreml)。
