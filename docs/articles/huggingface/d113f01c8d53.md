# SetFit：无需 prompt 的高效小样本学习

本文另有[简体中文](https://huggingface.co/blog/zh/setfit)版本。

![](https://huggingface.co/blog/assets/103_setfit/setfit_curves.png)

*相比标准微调，SetFit 的样本效率显著更高，且对噪声更鲁棒。*

用预训练语言模型做小样本学习，已经成为应对数据科学家噩梦——面对几乎没有标签的数据 😱——的一个有前景的方案。

我们与 [Intel Labs](https://www.intel.com/content/www/us/en/research/overview.html) 和 [UKP Lab](https://www.informatik.tu-darmstadt.de/ukp/ukp_home/index.en.jsp) 的研究伙伴合作，Hugging Face 隆重推出 SetFit：一个高效的 [Sentence Transformers](https://sbert.net/) 小样本微调框架。SetFit 在极少标注数据下就能取得高准确率——例如在客户评论（CR）情感数据集上每类仅 8 条标注样本时，SetFit 就能与在全部 3k 样本上微调的 RoBERTa Large 匹敌 🤯！

与其他小样本学习方法相比，SetFit 有几个独特之处：

🗣 **没有 prompt 或 verbaliser**：现行的小样本微调技术需要手工设计的 prompt 或 verbaliser，把样本转换成适合底层语言模型的格式。SetFit 彻底摒弃 prompt，直接从少量标注文本样例生成丰富的嵌入。

🏎 **训练快**：SetFit 不需要 T0 或 GPT-3 这样的大规模模型即可取得高准确率。因此它的训练与推理通常快一个数量级甚至更多。

🌎 **多语言支持**：SetFit 可以搭配 Hub 上任何 Sentence Transformer 使用，这意味着只需微调一个多语言 checkpoint，就能做多语言文本分类。

更多细节请查看我们的[论文](https://arxiv.org/abs/2209.11055)、[数据](https://huggingface.co/SetFit)和[代码](https://github.com/huggingface/setfit)。在这篇博客中，我们将解释 SetFit 的工作原理，以及如何训练你自己的模型。开始吧！

## 它是如何工作的？

SetFit 的设计兼顾效率与简洁。SetFit 先在一小批标注样本（通常每类 8 或 16 条）上微调一个 Sentence Transformer 模型，然后用微调后的 Sentence Transformer 生成的嵌入训练一个分类头。

![](https://huggingface.co/blog/assets/103_setfit/setfit_diagram_process.png)

*SetFit 的两阶段训练过程*

SetFit 利用了 Sentence Transformers 基于成对句子生成稠密嵌入的能力。在初始微调阶段，它通过对比学习利用有限的标注输入数据：用类内与类外采样构造正例对和负例对。Sentence Transformer 模型在这些对（或三元组）上训练，为每个样本生成稠密向量。第二步，分类头在编码出的嵌入及其类别标签上训练。推理时，未见样本经过微调后的 Sentence Transformer 生成嵌入，送入分类头输出类别预测。

只需把底座 Sentence Transformer 换成多语言模型，SetFit 就能在多语言场景中无缝工作。在我们的[实验](https://arxiv.org/abs/2209.11055)中，SetFit 在德语、日语、普通话、法语和西班牙语的分类任务上——无论同语言还是跨语言设置——都展现出令人期待的表现。

## SetFit 的基准测试

虽然 SetFit 基于比现有小样本方法小得多的模型，它在多种基准上与最先进的小样本方法持平甚至更好。在 [RAFT](https://huggingface.co/spaces/ought/raft-leaderboard)（一个小样本分类基准）上，使用 [`all-roberta-large-v1`](https://huggingface.co/sentence-transformers/all-roberta-large-v1) 模型的 SetFit Roberta 以 3.55 亿参数超过 PET 和 GPT-3，仅略低于人类平均水平和 110 亿参数的 T-few——后者体积是 SetFit Roberta 的 30 倍。SetFit 还在 11 个 RAFT 任务中的 7 个上超过人类基线。

| Rank | Method | Accuracy | Model Size |
| --- | --- | --- | --- |
| 2 | T-Few | 75.8 | 11B |
| 4 | Human Baseline | 73.5 | N/A |
| 6 | SetFit (Roberta Large) | 71.3 | 355M |
| 9 | PET | 69.6 | 235M |
| 11 | SetFit (MP-Net) | 66.9 | 110M |

*RAFT 榜单上的知名方法（截至 2022 年 9 月）*

在其他数据集上，SetFit 也展现出跨任务的鲁棒性。如下图所示，仅用每类 8 个样本，它通常就胜过 PERFECT、ADAPET 和微调的原生 transformer。SetFit 还与 T-Few 3B 相当——尽管它无需 prompt 且小 27 倍。

## 训练与推理都很快

![](https://huggingface.co/blog/assets/103_setfit/bars.png)

比较 T-Few 3B 与 SetFit (MPNet) 的训练成本与平均表现（每类 8 条标注样本）。

由于 SetFit 用相对小的模型就能达到高准确率，它的训练速度极快、成本低得多。例如，在 NVIDIA V100 上用 8 条标注样本训练 SetFit 只需 30 秒，成本 $0.025。相比之下，训练 T-Few 3B 需要 NVIDIA A100，耗时 11 分钟，同样实验成本约 $0.7——贵了 28 倍。事实上，SetFit 能在 Google Colab 提供的单块 GPU 上运行，你甚至可以在 CPU 上几分钟内完成训练！如上图所示，SetFit 的提速并未牺牲模型性能。[推理](https://arxiv.org/abs/2209.11055)同样有可观收益，对 SetFit 模型做蒸馏可获得 123 倍加速 🤯。

## 训练你自己的模型

为了让社区都能用上 SetFit，我们创建了一个小巧的 `setfit` [库](https://github.com/huggingface/setfit)，几行代码即可训练你自己的模型。第一步是安装：

```
pip install setfit
```

然后导入 `SetFitModel` 和 `SetFitTrainer` 这两个简化 SetFit 训练流程的核心类：

```
from datasets import load_dataset
from sentence_transformers.losses import CosineSimilarityLoss

from setfit import SetFitModel, SetFitTrainer
```

现在从 Hugging Face Hub 下载一个文本分类数据集。我们用客户评论数据集 [SentEval-CR](https://huggingface.co/datasets/SetFit/SentEval-CR)：

```
dataset = load_dataset("SetFit/SentEval-CR")
```

为模拟只有少量标注样本的真实场景，我们从训练集每类采样 8 条：

```
# Select N examples per class (8 in this case)
train_ds = dataset["train"].shuffle(seed=42).select(range(8 * 2))
test_ds = dataset["test"]
```

有了数据集，下一步从 Hub 加载预训练的 Sentence Transformer 并实例化 `SetFitTrainer`。这里我们用在大量数据集上表现出色的 [paraphrase-mpnet-base-v2](https://huggingface.co/sentence-transformers/paraphrase-mpnet-base-v2) 模型：

```
# Load SetFit model from Hub
model = SetFitModel.from_pretrained("sentence-transformers/paraphrase-mpnet-base-v2")

# Create trainer
trainer = SetFitTrainer(
    model=model,
    train_dataset=train_ds,
    eval_dataset=test_ds,
    loss_class=CosineSimilarityLoss,
    batch_size=16,
    num_iterations=20, # Number of text pairs to generate for contrastive learning
    num_epochs=1 # Number of epochs to use for contrastive learning
)
```

最后一步是训练和评估：

```
# Train and evaluate!
trainer.train()
metrics = trainer.evaluate()
```

就这样——你已经训练出了第一个 SetFit 模型！记得把模型推到 Hub 上 :)

```
# Push model to the Hub
# Make sure you're logged in with huggingface-cli login first
trainer.push_to_hub("my-awesome-setfit-model")
```

这个示例用的是一种特定的底座模型，但任何 [Sentence Transformer](https://huggingface.co/models?library=sentence-transformers&sort=downloads) 模型都可以换进来，以获得不同的性能与任务适配。例如，换用多语言 Sentence Transformer 底座就能把小样本分类扩展到多语言场景。
