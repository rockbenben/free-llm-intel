# 推出 Pull Request 与讨论区 🥳

[![Pull requests and discussions on the hub](https://huggingface.co/blog/assets/76_community_update/community-update.png)](https://huggingface.co/blog/assets/76_community_update/community-update.png)

我们兴奋地宣布最新协作功能的发布：在 Hugging Face Hub 上推出 pull request（拉取请求）与讨论区！

Pull request 和讨论区今天已在[社区标签页](https://huggingface.co/gpt2/discussions)下对所有仓库类型开放：模型、数据集和 Spaces。社区的任何成员都可以创建并参与讨论区和 pull request，让协作不仅发生在团队内部，也发生在与社区所有其他成员之间！

这是 Hub 有史以来最大的一次更新，我们迫不及待想看到社区成员用它开始协作 🤩。

全新的 "Community" 标签页也与多年来关于伦理 ML 的提议相契合。反馈与迭代在合乎伦理的机器学习软件开发中占据核心位置。我们深信，把它纳入社区的工具箱，将解锁 ML 中全新的良性模式、协作与进步。

讨论区和 pull request 的一些用例示例：

- 在 model card 中提出建议，以改进对伦理偏见的披露。
- 让用户标记某个 Space 演示中令人担忧的生成内容。
- 提供一个场所，让模型和数据集作者能够与社区成员直接对话。
- 让他人来改进你的仓库！例如，用户可能想提供 TensorFlow 权重！

## 讨论区

[![Discussions on the Hugging Face Hub](https://huggingface.co/blog/assets/76_community_update/new-discussion.png)](https://huggingface.co/blog/assets/76_community_update/new-discussion.png)

[讨论区（Discussions）](https://huggingface.co/gpt2/discussions?type=discussion)让社区成员能够提问、作答，并直接与仓库所有者及社区分享想法和建议。任何人都可以在仓库的社区标签页中创建并参与讨论。

## Pull Request

[![Pull requests on the Hugging Face Hub](https://huggingface.co/blog/assets/76_community_update/new-pr.png)](https://huggingface.co/blog/assets/76_community_update/new-pr.png)

[Pull request](https://huggingface.co/gpt2/discussions?type=pull_request)让社区成员能够直接从网站上开启、评论、合并或关闭 pull request。开启 pull request 最简单的方式是使用 "Files and versions" 标签页中的 "Collaborate" 按钮，它能让你非常轻松地进行单文件贡献。

在底层，我们的 pull request 不使用 fork 和 branch，而是使用被称为 `refs` 的自定义 "branch"，直接存储在源仓库上。这种方式避免了为模型/数据集的每个新版本都创建一个 fork。

## 与其他 git 托管平台有何不同

从宏观层面看，我们的目标是构建一个比其他 git 托管平台（如 GitHub）的 PR 与 Issue 更简单的版本：

- 不涉及 fork：贡献者直接把内容推送到源仓库上一个特殊的 `ref` branch
- 不再硬性区分 issue 与 PR：它们本质上是同一回事，所以我们在同一列表中展示
- 面向 ML 精简优化（即模型/数据集/Spaces 仓库），而非任意仓库
