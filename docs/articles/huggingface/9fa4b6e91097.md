不久前，我发布了一个用 Sentence Transformers 和 Gradio 构建的[播放列表生成器](https://huggingface.co/spaces/NimaBoscarino/playlist-generator)，之后又写了一篇[关于我如何把项目变成有效学习体验的反思](https://huggingface.co/blog/your-first-ml-project)。但我到底是怎么*构建*这个播放列表生成器的？在这篇文章里，我们会拆解这个项目，聚焦**两个**技术细节：嵌入是如何生成的，以及这个*多步骤* Gradio 演示是如何搭建的。

正如我们在[Hugging Face 博客之前的文章](https://huggingface.co/blog/getting-started-with-embeddings)中探讨的，Sentence Transformers（ST）是一个提供句子嵌入生成工具、用途广泛的库。由于我手头有一个歌词数据集，我决定利用 ST 的语义搜索功能，从给定文本提示词生成播放列表。具体目标是：为提示词创建一个嵌入，用它在一组*预先计算好的歌词嵌入*中做语义搜索，生成一组相关的歌曲。这一切都用新的 Blocks API 包装进一个 Gradio 应用，托管在 Hugging Face Spaces 上。

我们会用到 Gradio 稍微进阶一些的用法，如果你是这个库的新手，建议先读一读[Blocks 入门](https://gradio.app/introduction_to_blocks/)再来看本文的 Gradio 部分。另外注意：虽然我不会公开歌词数据集，但**歌词嵌入已发布在 Hugging Face Hub 上**（[数据集](https://huggingface.co/datasets/NimaBoscarino/playlist-generator)），你可以拿它玩。开冲！🪂

## Sentence Transformers：嵌入与语义搜索

嵌入是 Sentence Transformers 的**核心**！关于**嵌入是什么以及如何生成，我们在之前的文章里已经讲过**（[https://huggingface.co/blog/getting-started-with-embeddings](https://huggingface.co/blog/getting-started-with-embeddings)），建议先读完那篇再看本文。

Sentence Transformers 提供了大量预训练嵌入模型！它甚至包含用你自己的训练数据微调这些模型的教程，但对很多用例（比如对歌词语料做语义搜索），预训练模型开箱即用就表现出色。不过可用的嵌入模型这么多，该选哪一个呢？

[ST 文档](https://www.sbert.net/docs/pretrained_models.html)列出了许多可选模型，附带各自的评估指标和部分预期用途说明。**[MS MARCO 系列模型](https://www.sbert.net/docs/pretrained-models/msmarco-v5.html)**是在 Bing 搜索引擎的查询上训练的，但由于它们在其他领域同样表现良好，我认为其中任何一个都适合这个项目。播放列表生成器只需要找到具有某种语义相似度的歌曲，而且我并不追求某个特定性能指标，所以随手选了 [sentence-transformers/msmarco-MiniLM-L-6-v3](https://huggingface.co/sentence-transformers/msmarco-MiniLM-L-6-v3)。

ST 中每个模型的输入序列长度都可配置（有上限），超出部分会被截断。我选的模型最大序列长度是 512 个 word piece，结果发现这往往不足以嵌入一整首歌。好在有个简单的办法能把歌词切成模型能消化的小片段——分段（verse）！一旦我们把歌曲按段落切开并嵌入每一段，就会发现搜索效果好得多。

歌曲被切分为段落，然后每个段落分别嵌入。

要实际生成嵌入，调用 Sentence Transformers 模型的 `.encode()` 方法并传入字符串列表即可。之后随你喜欢的方式保存嵌入——我这里选择了 pickle。

```
from sentence_transformers import SentenceTransformer
import pickle

embedder = SentenceTransformer('msmarco-MiniLM-L-6-v3')
verses = [...] # Load up your strings in a list
corpus_embeddings = embedder.encode(verses, show_progress_bar=True)

with open('verse-embeddings.pkl', "wb") as fOut:
    pickle.dump(corpus_embeddings, fOut)
```

要想把嵌入分享给别人，你甚至可以把 Pickle 文件上传到 Hugging Face 数据集。[读这篇教程了解更多](https://huggingface.co/blog/getting-started-with-embeddings#2-host-embeddings-for-free-on-the-hugging-face-hub)，或[访问 Datasets 文档](https://huggingface.co/docs/datasets/upload_dataset#upload-with-the-hub-ui)亲自动手试试！简而言之，在 Hub 上创建新数据集后，只需点击下面的 "Add file" 按钮即可手动上传你的 Pickle 文件。

你可以在 Hub 上手动上传数据集文件。

现在剩下的最后一步，就是用这些嵌入做语义搜索了！下面的代码加载嵌入、为给定字符串生成新嵌入，并在歌词嵌入上运行语义搜索找出最接近的命中。为了更方便处理结果，我还喜欢把它们放进 Pandas DataFrame。

```
from sentence_transformers import util
import pandas as pd

prompt_embedding = embedder.encode(prompt, convert_to_tensor=True)
hits = util.semantic_search(prompt_embedding, corpus_embeddings, top_k=20)
hits = pd.DataFrame(hits[0], columns=['corpus_id', 'score'])
# Note that "corpus_id" is the index of the verse for that embedding
# You can use the "corpus_id" to look up the original song
```

由于我们搜索的是任何与提示词匹配的段落，语义搜索很可能从同一首歌里找到多个段落。去掉重复后，可能只剩几首不同的歌。如果调大 `util.semantic_search` 的 `top_k` 参数以增加取回的段落嵌入数量，就能找到更多歌曲。凭实验经验，当我设置 `top_k=20` 时，几乎总能得到至少 9 首不同的歌。

## 制作一个多步骤 Gradio 应用

对于演示应用，我希望用户输入文本提示词（或从示例中选一个），然后执行语义搜索找出最相关的前 9 首歌。之后，用户应能从结果歌曲中选择，查看歌词——这也许会让他们明白为什么选了这些歌。下面来看怎么做！

在 [Gradio 演示代码](https://huggingface.co/spaces/NimaBoscarino/playlist-generator/blob/main/app.py)开头，应用在启动时从 Hugging Face datasets 加载嵌入、映射关系和歌词。

```
from sentence_transformers import SentenceTransformer, util
from huggingface_hub import hf_hub_download
import os
import pickle
import pandas as pd

corpus_embeddings = pickle.load(open(hf_hub_download("NimaBoscarino/playlist-generator", repo_type="dataset", filename="verse-embeddings.pkl"), "rb"))
songs = pd.read_csv(hf_hub_download("NimaBoscarino/playlist-generator", repo_type="dataset", filename="songs_new.csv"))
verses = pd.read_csv(hf_hub_download("NimaBoscarino/playlist-generator", repo_type="dataset", filename="verses.csv"))

# I'm loading the lyrics from my private dataset, with my own API token
auth_token = os.environ.get("TOKEN_FROM_SECRET") 
lyrics = pd.read_csv(hf_hub_download("NimaBoscarino/playlist-generator-private", repo_type="dataset", filename="lyrics_new.csv", use_auth_token=auth_token))
```

Gradio 的 Blocks API 让你构建*多步骤*界面，意味着你可以为演示设计相当复杂的流程。这里我们看几个代码片段，但[完整代码在项目中，可以实际运行体验](https://huggingface.co/spaces/NimaBoscarino/playlist-generator/blob/main/app.py)。对这个项目，我们希望用户选择文本提示词，语义搜索完成后，用户能够从结果中选一首歌查看歌词。用 Gradio 可以迭代式地搭建：先定义初始输入组件，然后在按钮上注册 `click` 事件。另外还有一个 `Radio` 组件，它会被更新为显示播放列表的歌曲名。

```
import gradio as gr

song_prompt = gr.TextArea(
    value="Running wild and free",
    placeholder="Enter a song prompt, or choose an example"
)

fetch_songs = gr.Button(value="Generate Your Playlist!")

song_option = gr.Radio()

fetch_songs.click(
    fn=generate_playlist,
    inputs=[song_prompt],
    outputs=[song_option],
)
```

这样一来，点击按钮时，Gradio 会抓取 `TextArea` 的当前值并传给一个函数，如下所示：

```
def generate_playlist(prompt):
    prompt_embedding = embedder.encode(prompt, convert_to_tensor=True)
    hits = util.semantic_search(prompt_embedding, corpus_embeddings, top_k=20)
    hits = pd.DataFrame(hits[0], columns=['corpus_id', 'score'])
    # ... code to map from the verse IDs to the song names
    song_names = ... # e.g. ["Thank U, Next", "Freebird", "La Cucaracha"]
    return (
        gr.Radio.update(label="Songs", interactive=True, choices=song_names)
    )
```

在这个函数里，我们用文本提示词执行语义搜索。如上所见，要更新应用中 Gradio 组件，函数只需返回用 `.update()` 方法创建的组件。由于我们通过 `output` 参数把 `song_option` 的 `Radio` 组件连到了 `fetch_songs.click`，`generate_playlist` 就能控制 `Radio` 组件的可选项！

你还可以对 `Radio` 组件做类似的处理，让用户选择查看哪首歌的歌词。[到 Hugging Face Spaces 上的代码里看细节！](https://huggingface.co/spaces/NimaBoscarino/playlist-generator/blob/main/app.py)

## 一些想法

对这类项目来说，Sentence Transformers 和 Gradio 是很棒的选择！ST 提供了快速生成嵌入和以最少代码运行语义搜索所需的工具函数。拥有大量预训练模型可用也极其有用——这类事情我们完全不必自己造模型、训模型。用 Gradio 构建演示意味着我们只需要专注 Python 编码，而[把 Gradio 项目部署到 Hugging Face Spaces 也简单得不行](https://huggingface.co/docs/hub/spaces-sdks-gradio)！

这个项目里还有很多我希望有时间构建的东西，比如以下这些我以后可能探索的想法：

- 对接 Spotify 自动生成播放列表，甚至也许用 Spotify 的嵌入式播放器让用户即刻试听。
- 使用 **[HighlightedText** Gradio 组件](https://gradio.app/docs/#highlightedtext)标出语义搜索命中的具体段落。
- 制作嵌入空间的可视化，比如 [Radamés Ajna 的这个 Space](https://huggingface.co/spaces/radames/sentence-embeddings-visualization)。

虽然歌曲*歌词*不会发布，但我已经**[公开了段落嵌入及其与各歌曲的映射](https://huggingface.co/datasets/NimaBoscarino/playlist-generator)**，你可以自由地把玩和发挥创意！
