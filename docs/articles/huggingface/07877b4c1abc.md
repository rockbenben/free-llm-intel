# SmolVLM2：让视频理解走进每台设备

## 太长不看：SmolVLM 现在能看 📺 了，视觉理解还更强

SmolVLM2 代表我们对视频理解的思路转变——从需要大量算力的巨型模型，转向哪里都能跑的高效模型。目标很简单：让视频理解在所有设备和使用场景中都触手可及，从手机到服务器。

我们发布三种规模的模型（2.2B、500M 和 256M），第 1 天就支持 MLX（*Python 和* Swift API）。所有模型和演示都放在[这个合集](https://huggingface.co/collections/HuggingFaceTB/smolvlm2-smallest-video-lm-ever-67ab6b5e84bf8aaa60cb17c7)里。

想立刻试试 SmolVLM2？来玩我们的[交互式聊天界面](https://huggingface.co/spaces/HuggingFaceTB/SmolVLM2)，通过简单直观的界面测试 SmolVLM2 2.2B 的视觉与视频理解能力。

## 技术细节

我们引入三个新模型：256M、500M 和 2.2B 参数。2.2B 模型是视觉和视频任务的首选，而 500M 与 256M 是**有史以来发布的最小视频语言模型**。

别看它们小，论每单位内存消耗的性能，它们胜过所有现存模型。看 Video-MME（视频领域的权威科学基准），SmolVLM2 在 2B 档与前沿模型家族并驾齐驱，在更小档位则是领头羊。

*Video-MME 之所以突出，在于其覆盖面广：多样的视频类型、不同时长的片段（11 秒到 1 小时）、多种数据模态（含字幕和音频），以及覆盖 900 段视频、共 254 小时的高质量专家标注。更多了解见[这里](https://video-mme.github.io/home_page.html)。*

### SmolVLM2 2.2B：视觉与视频的新星

与之前的 SmolVLM 家族相比，我们的新 2.2B 模型在带图数学题、照片文字识别、复杂图表理解、科学视觉问题上更强。这体现在各基准的表现上：

视频任务方面，2.2B 性价比出色。在我们评估的多个科学基准中，特别值得一提的是 Video-MME 上的表现——超越了所有现有的 2B 模型。

我们之所以能在视频/图像性能上取得良好平衡，得益于 [Apollo: An Exploration of Video Understanding in Large Multimodal Models](https://apollo-lmms.github.io/) 发表的数据配比经验。

它极其省内存——甚至在免费的 Google Colab 上都能跑。

Python 代码

```
# Install transformers from `main` or from this stable branch:
!pip install git+https://github.com/huggingface/transformers@v4.49.0-SmolVLM-2

from transformers import AutoProcessor, AutoModelForImageTextToText
import torch

model_path = "HuggingFaceTB/SmolVLM2-2.2B-Instruct"
processor = AutoProcessor.from_pretrained(model_path)
model = AutoModelForImageTextToText.from_pretrained(
    model_path,
    torch_dtype=torch.bfloat16,
    _attn_implementation="flash_attention_2"
).to("cuda")

messages = [
    {
        "role": "user",
        "content": [
            {"type": "video", "path": "path_to_video.mp4"},
            {"type": "text", "text": "Describe this video in detail"}
        ]
    },
]

inputs = processor.apply_chat_template(
    messages,
    add_generation_prompt=True,
    tokenize=True,
    return_dict=True,
    return_tensors="pt",
).to(model.device, dtype=torch.bfloat16)

generated_ids = model.generate(**inputs, do_sample=False, max_new_tokens=64)
generated_texts = processor.batch_decode(
    generated_ids,
    skip_special_tokens=True,
)

print(generated_texts[0])
```

### 再小一点：500M 和 256M 视频模型

在今天之前，没有人敢发布这么小的视频模型。

我们的新 [SmolVLM2-500M-Video-Instruct](https://huggingface.co/HuggingFaceTB/SmolVLM2-500M-Video-Instruct) 模型视频能力非常接近 SmolVLM 2.2B，而体积只是其零头：用不到四分之一的参数就拿到同样的视频理解能力 🤯。

然后还有我们的小实验：SmolVLM2-256M-Video-Instruct。可以把它看作我们的"那要是……呢"项目——如果我们能把小模型的边界再往前推一推会怎样？几周前 [IBM 基于我们的 SmolVLM-256M-Instruct](https://ds4sd.github.io/docling/examples/pictures_description/) 做出了[成绩](https://huggingface.co/HuggingFaceTB/SmolVLM-256M-Instruct)，受此启发，我们想看看视频理解到底能压到多小。虽然它更像一个实验性发布，我们还是希望它能激发一些有创意的应用和专门的微调项目。

## 用 Transformers 和 MLX 跑 SmolVLM2

我们把 SmolVLM2 在第 1 天就做成 transformers 和 MLX 可用。本节包含视频与多图的不同推理方案和教程。

### Transformers

用 SmolVLM2 模型跑推理最简单的方式是对话式 API——应用 chat template 会自动准备所有输入。

加载模型如下。

```
# Install transformers from `main` or from this stable branch:
!pip install git+https://github.com/huggingface/transformers@v4.49.0-SmolVLM-2

from transformers import AutoProcessor, AutoModelForImageTextToText
import torch

processor = AutoProcessor.from_pretrained(model_path)
model = AutoModelForImageTextToText.from_pretrained(
    model_path,
    torch_dtype=torch.bfloat16,
    _attn_implementation="flash_attention_2"
).to("cuda")
```

#### 视频推理

在 chat template 里传视频，用 `{"type": "video", "path": {video_path}` 即可。完整示例见下。

```
messages = [
    {
        "role": "user",
        "content": [
            {"type": "video", "path": "path_to_video.mp4"},
            {"type": "text", "text": "Describe this video in detail"}
        ]
    },
]

inputs = processor.apply_chat_template(
    messages,
    add_generation_prompt=True,
    tokenize=True,
    return_dict=True,
    return_tensors="pt",
).to(model.device, dtype=torch.bfloat16)

generated_ids = model.generate(**inputs, do_sample=False, max_new_tokens=64)
generated_texts = processor.batch_decode(
    generated_ids,
    skip_special_tokens=True,
)

print(generated_texts[0])
```

#### 多图推理

除了视频，SmolVLM2 还支持多图对话。同样通过 chat template 使用这套 API，每张图可以用文件系统路径、URL 或 `PIL.Image` 对象提供：

```
messages = [
    {
        "role": "user",
        "content": [
            {"type": "text", "text": "What are the differences between these two images?"},
          {"type": "image", "url": "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/bee.jpg"},
          {"type": "image", "url": "https://huggingface.co/datasets/huggingface/documentation-images/resolve/0052a70beed5bf71b92610a43a52df6d286cd5f3/diffusers/rabbit.jpg"},            
        ]
    },
]

inputs = processor.apply_chat_template(
    messages,
    add_generation_prompt=True,
    tokenize=True,
    return_dict=True,
    return_tensors="pt",
).to(model.device, dtype=torch.bfloat16)

generated_ids = model.generate(**inputs, do_sample=False, max_new_tokens=64)
generated_texts = processor.batch_decode(
    generated_ids,
    skip_special_tokens=True,
)

print(generated_texts[0])
```

### 用 MLX 推理

要在 Apple Silicon 设备上用 Python 通过 MLX 跑 SmolVLM2，可以使用优秀的 [mlx-vlm 库](https://github.com/Blaizzy/mlx-vlm)。首先，从[这个分支](https://github.com/Blaizzy/mlx-vlm/pull/208)安装 `mlx-vlm`：

```
pip install git+https://github.com/pcuenca/mlx-vlm.git@smolvlm
```

然后可以用这条一行命令对单张图做推理，它使用 [SmolVLM2 的未量化 500M 版本](https://huggingface.co/HuggingFaceTB/SmolVLM2-500M-Video-Instruct-mlx)：

```
python -m mlx_vlm.generate \
  --model mlx-community/SmolVLM2-500M-Video-Instruct-mlx \
  --image https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/bee.jpg \
  --prompt "Can you describe this image?"
```

我们还做了一个视频理解的简单脚本，用法如下：

```
python -m mlx_vlm.smolvlm_video_generate \
  --model mlx-community/SmolVLM2-500M-Video-Instruct-mlx \
  --system "Focus only on describing the key dramatic action or notable event occurring in this video segment. Skip general context or scene-setting details unless they are crucial to understanding the main action." \
  --prompt "What is happening in this video?" \
  --video /Users/pedro/Downloads/IMG_2855.mov \
  --prompt "Can you describe this image?"
```

注意系统提示词很重要，它把模型引导到期望的行为上。你可以用它，比如描述所有场景和转场，或者给出一句话摘要。

#### Swift MLX

Swift 语言同样受支持，途径是 [mlx-swift-examples 仓库](https://github.com/ml-explore/mlx-swift-examples)——我们的 iPhone 应用就是用它构建的。

在[我们进行中的 PR](https://github.com/ml-explore/mlx-swift-examples/pull/206)合并之前，需要从[这个 fork](https://github.com/cyrilzakka/mlx-swift-examples)编译项目，然后在你的 Mac 上这样使用 `llm-tool` CLI。

图像推理：

```
./mlx-run --debug llm-tool \
    --model mlx-community/SmolVLM2-500M-Video-Instruct-mlx \
    --prompt "Can you describe this image?" \
    --image https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/bee.jpg \
    --temperature 0.7 --top-p 0.9 --max-tokens 100
```

视频分析也支持，并且可以提供系统提示词。我们发现系统提示词对视频理解尤其有用——用它把模型引导到我们关心的细节程度。这是一个视频推理示例：

```
./mlx-run --debug llm-tool \
    --model mlx-community/SmolVLM2-500M-Video-Instruct-mlx \
    --system "Focus only on describing the key dramatic action or notable event occurring in this video segment. Skip general context or scene-setting details unless they are crucial to understanding the main action." \
    --prompt "What is happening in this video?" \
    --video /Users/pedro/Downloads/IMG_2855.mov \
    --temperature 0.7 --top-p 0.9 --max-tokens 100
```

### 微调 SmolVLM2

你可以用 transformers 🤗 在视频上微调 SmolVLM2。为了演示，我们在 Colab 上用 [VideoFeedback](https://huggingface.co/datasets/TIGER-Lab/VideoFeedback) 数据集的视频-字幕对微调了 500M 版本。由于 500M 版本很小，最好做全量微调而不是 QLoRA 或 LoRA；同时你可以尝试对 cB 版本用 QLoRA。微调 notebook 见[这里](https://github.com/huggingface/smollm/blob/main/vision/finetuning/SmolVLM2_Video_FT.ipynb)。
