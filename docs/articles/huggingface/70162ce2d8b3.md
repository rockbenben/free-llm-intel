# 用 diffusers 训练你的 ControlNet

本文另有[简体中文](https://huggingface.co/blog/zh/train-your-controlnet)版本。

## 引言

[ControlNet](https://huggingface.co/blog/controlnet) 是一种神经网络结构，通过添加额外条件实现对扩散模型的精细控制。这项技术随论文 [Adding Conditional Control to Text-to-Image Diffusion Models](https://huggingface.co/papers/2302.05543) 首次亮相，并迅速席卷开源扩散模型社区——作者发布了 8 种不同的条件来控制 Stable Diffusion v1-5，包括姿态估计、深度图、Canny 边缘、素描，[以及更多](https://huggingface.co/lllyasviel)。

[![ControlNet pose examples](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/136_train-your-controlnet/pose_image_1-min.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/136_train-your-controlnet/pose_image_1-min.png)

在这篇博客中，我们将逐步详细讲解我们如何训练 [*Uncanny* Faces 模型](https://huggingface.co/blog/train-your-controlnet#)——一个基于 3D 合成脸部的面部姿态模型（那种"诡异"面孔其实是意外产物，接着往下看就知道它是怎么来的）。

## 开始为 Stable Diffusion 训练你自己的 ControlNet

训练自己的 ControlNet 需要 3 步：

- **规划你的条件**：ControlNet 足够灵活，可以把 Stable Diffusion 调教到很多任务上。预训练模型展示了五花八门的条件，社区也做了其他尝试，比如以[像素化色板](https://huggingface.co/thibaud/controlnet-sd21-color-diffusers)为条件。
- **构建数据集**：条件定下来之后，就该建数据集了。你可以从零构建，也可以用现有数据集的子集。训练模型需要数据集中有三列：真实图像 `image`、条件图像 `conditioning_image` 和 `prompt`。
- **训练模型**：数据集就绪后，就该训练了。多亏 [diffusers 训练脚本](https://github.com/huggingface/diffusers/tree/main/examples/controlnet)，这一步反而是最省事的。你需要一块至少 8GB 显存的 GPU。

## 1. 规划你的条件

规划条件时，想清楚两个问题很有帮助：

- 我想用哪一类条件？
- 是否已有现成模型能把"普通"图像转换成我的条件？

在我们的例子里，我们考虑使用面部关键点条件。理由是：1. 通用的关键点 ControlNet 效果很好；2. 面部关键点是相当普及的技术，有很多模型能在普通照片上计算面部关键点；3. 让 Stable Diffusion 跟随某个面部关键点、或模仿你自己的面部表情，应该很好玩。

[![Example of face landmarks](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/136_train-your-controlnet/segmentation_examples.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/136_train-your-controlnet/segmentation_examples.png)

## 2. 构建数据集

好！我们决定做面部关键点的 Stable Diffusion 条件。那么准备数据集需要：

- 真实图像 `image`：本例中就是人脸照片
- `conditioning_image`：本例中是把面部关键点可视化出来的图像
- `caption`：描述这些图像的文本

本项目我们选用了微软的 `FaceSynthetics` 数据集：它包含 10 万张合成脸部图像。还有其他用真实人脸的面部研究数据集，比如 `Celeb-A HQ`、`FFHQ`——但我们决定在这个项目里用合成脸。

[![Face synthetics example dataset](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/136_train-your-controlnet/face_synethtics_example.jpeg)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/136_train-your-controlnet/face_synethtics_example.jpeg)

`FaceSynthetics` 数据集听起来是个很棒的起点：它有人脸的真实图像、按 iBUG 68 面部关键点格式标注的关键点，以及人脸的分割图。

[![Face synthetics descriptions](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/136_train-your-controlnet/segmentation_sequence.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/136_train-your-controlnet/segmentation_sequence.png)

完美了吧？可惜并不是。还记得"规划条件"那一步的第二个问题吗——我们应该有能把普通图像转换成条件的模型。而事实上，没有已知的模型能把人脸转成该数据集这种标注关键点格式。

[![No known segmentation model](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/136_train-your-controlnet/segmentation_no_known.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/136_train-your-controlnet/segmentation_no_known.png)

于是我们改走另一条路：

- 使用 `FaceSynthetics` 数据集的人脸真实图像 `image`
- 找一个能把任意人脸图像转成 iBUG 68 面部关键点格式的已知模型（我们用了 SOTA 模型 [SPIGA](https://github.com/andresprados/SPIGA)）
- 写一段自定义代码，把面部关键点渲染成漂亮的可视化掩码，作为 `conditioning_image`
- 保存为 [Hugging Face Dataset](https://huggingface.co/docs/datasets/index)

[在这里](https://huggingface.co/datasets/pcuenq/face_synthetics_spiga)可以找到把 `FaceSynthetics` 的真实图像转成可视化掩码并保存为 Hugging Face Dataset 的代码。

现在数据集里有了真实 `image` 和 `conditioning_image`，还差一步：每张图像的文本描述。这一步强烈建议做；你也可以用空提示词试试看效果如何。由于 `FaceSynthetics` 没有现成 caption，我们跑了 [BLIP 描述生成](https://huggingface.co/docs/transformers/model_doc/blip)。为所有图像生成 caption 的代码见[这里](https://huggingface.co/datasets/multimodalart/facesyntheticsspigacaptioned)。

这样我们就得到了最终数据集！[Face Synthetics SPIGA with captions](https://huggingface.co/datasets/multimodalart/facesyntheticsspigacaptioned) 为 `FaceSynthetics` 的 10 万张图像提供了真实图像、分割图和文本描述。可以训练模型了！

[![New dataset](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/136_train-your-controlnet/new_dataset.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/136_train-your-controlnet/new_dataset.png)

## 3. 训练模型

[数据集](https://huggingface.co/datasets/multimodalart/facesyntheticsspigacaptioned)就绪，开始训练模型！虽然按理说这应该是整个流程里最难的一环，但有了 [diffusers 训练脚本](https://github.com/huggingface/diffusers/tree/main/examples/controlnet)，它反而成了最简单的。我们用了一块在 [LambdaLabs](https://lambdalabs.com) 租的单卡 A100，价格 1.10 美元/小时。

### 我们的训练经历

我们把模型训练了 3 个 epoch（即 10 万张图会被模型"看"3 遍），批大小为 4（每一步给模型看 4 张图）。结果证明这练过头了，出现过拟合（它开始偏离真实人脸的概念——比如提示词里写 "shrek" 或 "a cat" 不再能做出史莱克或猫，反而画出人；而且开始无视风格）。

只训 1 个 epoch（模型"看过"10 万张图之后），它就已经收敛到能跟随姿态、且不过拟合。所以是有效的，但是……因为我们用的是 FaceSynthetics 数据集，模型学到的是一副诡异的 3D 风格脸，而不是逼真的人脸。这也不难理解——我们用的毕竟是合成脸数据集而不是真实人脸，而且这种效果反而很适合做趣味/梗图。这里是 [uncannyfaces_25K](https://huggingface.co/multimodalart/uncannyfaces_25K) 模型。

在这个交互表格里，你可以拨动下面的刻度，看模型经历了多少训练步数、对训练过程有什么影响。大约 15K 步时它开始学会姿态，25K 步左右成熟。

### 我们是怎么训练的

首先要做的就是安装依赖：

```
pip install git+https://github.com/huggingface/diffusers.git transformers accelerate xformers==0.0.16 wandb
huggingface-cli login
wandb login 
```

然后运行 [train_controlnet.py](https://github.com/huggingface/diffusers/blob/main/examples/controlnet/train_controlnet.py)：

```
!accelerate launch train_controlnet.py \
 --pretrained_model_name_or_path="stabilityai/stable-diffusion-2-1-base" \
 --output_dir="model_out" \
 --dataset_name=multimodalart/facesyntheticsspigacaptioned \
 --conditioning_image_column=spiga_seg \
 --image_column=image \
 --caption_column=image_caption \
 --resolution=512 \
 --learning_rate=1e-5 \
 --validation_image "./face_landmarks1.jpeg" "./face_landmarks2.jpeg" "./face_landmarks3.jpeg" \
 --validation_prompt "High-quality close-up dslr photo of man wearing a hat with trees in the background" "Girl smiling, professional dslr photograph, dark background, studio lights, high quality" "Portrait of a clown face, oil on canvas, bittersweet expression" \
 --train_batch_size=4 \
 --num_train_epochs=3 \
 --tracker_project_name="controlnet" \
 --enable_xformers_memory_efficient_attention \
 --checkpointing_steps=5000 \
 --validation_steps=5000 \
 --report_to wandb \
 --push_to_hub
```

下面逐项拆解这些设置，同时介绍一些把训练显存压到最低 8GB 的优化技巧。

- `pretrained_model_name_or_path`：想使用的 Stable Diffusion 基础模型（我们选了 v2-1，因为它画人脸更好）
- `output_dir`：模型保存的目录
- `dataset_name`：训练使用的数据集。本例是 [Face Synthetics SPIGA with captions](https://huggingface.co/datasets/multimodalart/facesyntheticsspigacaptioned)
- `conditioning_image_column`：数据集中条件图像列的名称（本例 `spiga_seg`）
- `image_column`：数据集中真实图像列的名称（本例 `image`）
- `caption_column`：数据集中图像描述列的名称（本例 `image_caption`）
- `resolution`：条件图像与真实图像的分辨率（本例 `512x512`）
- `learning_rate`：学习率。我们发现 `1e-5` 在这组例子上效果很好，你也可以试试 `1e-4` 到 `2e-6` 之间的不同取值
- `validation_image`：训练时偷看效果用的！每隔 `validation_steps` 步会对这些验证图像跑一次推理，让你看到训练进展。这里填入本地路径的任意数量条件图像
- `validation_prompt`：与验证图像配套运行的提示词，可以是任何能检验模型是否训得好的内容
- `train_batch_size`：训练批次大小，要放得进 GPU。因为有 A100 我们可以用 `4`；如果你的 GPU 显存较低，建议降到 `1`
- `num_train_epochs`：每个 epoch 表示训练集中的图像被模型"看"多少遍。我们试过 3 个 epoch，但最佳效果其实只要稍微多于 1 个 epoch；3 个 epoch 会让模型过拟合
- `checkpointing_steps`：每 `x` 步保存一个中间检查点（本例 `5000`）。每 5000 步保存一次中间检查点
- `validation_steps`：每隔 `x` 步运行一次 `validaton_prompt` 和 `validation_image`
- `report_to`：训练日志上报到哪里。我们用了 Weights and Biases，它给了我们一份漂亮的报告。把 `train_batch_size` 从 `4` 降到 `1` 可能对显存小的 GPU 仍不够，下面针对每种显存给出需要追加的参数
- `push_to_hub`：把训练完成的最终模型推送到 Hugging Face Hub 的参数

### 适配 16GB 显存的 GPU

```
pip install bitsandbytes

--train_batch_size=1 \
--gradient_accumulation_steps=4 \
--gradient_checkpointing \
--use_8bit_adam
```

批大小 1 配合 4 步梯度累积，等效于我们示例里原本批大小 4 的效果。此外启用了梯度检查点和 8-bit Adam，进一步节省显存。

### 适配 12GB 显存的 GPU

```
--gradient_accumulation_steps=4 \
--gradient_checkpointing \
--use_8bit_adam
--set_grads_to_none
```

### 适配 8GB 显存的 GPU

请参考[我们的指南](https://github.com/huggingface/diffusers/tree/main/examples/controlnet#training-on-an-8-gb-gpu)

## 4. 结论！

这次训练 ControlNet 的经历非常有趣。我们成功训出了一个能跟随真实人脸姿态的模型——尽管它画出来的是诡异的 3D 风格脸而非逼真的人脸，这源于它的训练数据集，但也自有它的魅力和趣味。
