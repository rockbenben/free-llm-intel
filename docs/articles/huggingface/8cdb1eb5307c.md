# 如何在 Space 中托管 Unity 游戏

本文另有中文版本 [简体中文](https://huggingface.co/blog/zh/unity-in-spaces)。

你知道可以把 Unity 游戏托管在 Hugging Face Space 里吗？不知道？没错，真的可以！

Hugging Face Spaces 是构建、托管和分享 demo 的简单方式。虽然它通常用于机器学习演示，但也可以托管可玩的 Unity 游戏。这里有一些例子：

- [Huggy](https://huggingface.co/spaces/ThomasSimonini/Huggy)
- [Farming Game](https://huggingface.co/spaces/dylanebert/FarmingGame)
- [Unity API Demo](https://huggingface.co/spaces/dylanebert/UnityDemo)

下面是把你的 Unity 游戏托管到 Space 的方法。

## 第 1 步：使用 Static HTML 模板创建 Space

首先，前往 [Hugging Face Spaces](https://huggingface.co/new-space) 创建一个 space。

选择 "Static HTML" 模板，给你的 Space 起个名字，然后创建它。

## 第 2 步：用 Git 克隆该 Space

使用 Git 把新建的 Space 克隆到本地机器。可以在终端或命令提示符中运行以下命令：

```
git clone https://huggingface.co/spaces/{your-username}/{your-space-name}
```

## 第 3 步：打开你的 Unity 项目

打开你想托管到 Space 的 Unity 项目。

## 第 4 步：把 Build Target 切换到 WebGL

前往 `File > Build Settings`，把 Build Target 切换为 WebGL。

## 第 5 步：打开 Player Settings

在 Build Settings 窗口中，点击 "Player Settings" 按钮，打开 Player Settings 面板。

## 第 6 步（可选）：下载 Hugging Face Unity WebGL 模板

你可以下载 Hugging Face Unity WebGL 模板（[在此](https://github.com/huggingface/Unity-WebGL-template-for-Hugging-Face-Spaces)）来提升游戏在 Space 中的外观。下载该仓库并把它放进你的项目文件即可。

然后，在 Player Settings 面板中，把 WebGL 模板切换为 Hugging Face。具体做法：在 Player Settings 中点击 "Resolution and Presentation"，再选择 Hugging Face WebGL 模板。

## 第 7 步：把 Compression Format 改为 Disabled

在 Player Settings 面板中，前往 "Publishing Settings" 区块，把 Compression Format 改为 "Disabled"。

## 第 8 步：构建你的项目

回到 Build Settings 窗口，点击 "Build" 按钮。选择一个保存构建文件的位置，Unity 就会为 WebGL 构建项目。

## 第 9 步：复制 Build 文件夹的内容

构建过程结束后，前往存放构建文件的文件夹。把 build 文件夹中的文件复制到你在[第 2 步](https://huggingface.co/blog/unity-in-spaces#step-2-use-git-to-clone-the-space)中克隆的仓库里。

## 第 10 步：为大文件存储启用 Git-LFS

进入你的仓库。使用以下命令跟踪大型构建文件。

```
git lfs install
git lfs track Build/* 
```

## 第 11 步：推送你的更改

最后，使用以下 Git 命令推送更改：

```
git add .
git commit -m "Add Unity WebGL build files"
git push
```

## 完成！

恭喜！刷新你的 Space。现在你应该可以在 Hugging Face Space 里玩你的游戏了。
