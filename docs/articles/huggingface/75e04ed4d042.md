# 推出 Palmyra-mini 家族：强大、轻量、随时可以推理！

![](https://huggingface.co/Writer/palmyra-mini-thinking-b/resolve/main/logo-mini-b%20benchmark-performance.png?download=true)

WRITER 团队兴奋地宣布发布 Palmyra-mini 家族的三款新开放模型。这些模型设计得强大、轻量，并在其规模（1.5B 到 1.7B）下性能出色，非常适合需要高效推理的广泛应用场景。

- [palmyra-mini](https://huggingface.co/Writer/palmyra-mini)：一款强大、轻量的非思考（non-thinking）基座模型。
- [palmyra-mini-thinking-a](https://huggingface.co/Writer/palmyra-mini-thinking-a)：针对复杂推理与逻辑优化的专门变体。
- [palmyra-mini-thinking-b](https://huggingface.co/Writer/palmyra-mini-thinking-b)：另一款专门变体，擅长数学公式与推理。

"thinking"（思考）模型采用思维链（Chain of Thought, CoT）方法训练，提升了它们的推理能力。我们很期待社区用这些新模型构建出什么！

为方便使用，我们同时提供了 GGUF 和 MLX 量化版本：

- [palmyra-mini-GGUF](https://huggingface.co/Writer/palmyra-mini-GGUF)
- [palmyra-mini-thinking-a-GGUF](https://huggingface.co/Writer/palmyra-mini-thinking-a-GGUF)
- [palmyra-mini-thinking-b-GGUF](https://huggingface.co/Writer/palmyra-mini-thinking-b-GGUF)
- [palmyra-mini-MLX-BF16](https://huggingface.co/Writer/palmyra-mini-GGUF)
- [palmyra-mini-thinking-a-MLX-BF16](https://huggingface.co/Writer/palmyra-mini-thinking-a-MLX-BF16)
- [palmyra-mini-thinking-b-MLX-BF16](https://huggingface.co/Writer/palmyra-mini-thinking-b-MLX-BF16)

## 基准亮点：

- palmyra-mini：我们改进后的非推理基座模型，在 Big Bench Hard (get-answer)(exact_match) 上取得 52.6% 的得分，是各类生成式任务的出色全能选手。
- palmyra-mini-thinking-a：处理复杂逻辑挑战时，这款变体是你的首选。它采用思维链（CoT）方法训练，在 GSM8K（strict match）上取得令人印象深刻的 82.87%，展现了强大的推理能力。在本次发布的模型中，它的整体基准平均分最高。
- palmyra-mini-thinking-b：这款模型不断突破问题求解的边界，在 AMC23 上拿下扎实的 92.5%。当你需要一个能"思考"着攻克高难度任务的模型时，它是绝佳选择。在 AIME24、AIME25、GPQA、HMMT25、HLE、MMLU_PRO、MATH500、LCB 这些基准中，相对于本次发布的其他模型，它的平均分最高。

## 脚注：

由于所有基座模型均为 Qwen 架构，推理应可在主流推理框架上运行，例如 vLLM、SGLang、TRTLLM、TGI。

对于 palmyra-thinking-b，其基座模型为 [https://huggingface.co/nvidia/OpenReasoning-Nemotron-1.5B](https://huggingface.co/nvidia/OpenReasoning-Nemotron-1.5B)。我们对其进行了 RL 微调，并观察到它能够提升性能。虽然强化学习提升了单次（pass@1）准确率，但它降低了采样多样性，导致 majority@64 表现相比 SFT 基座模型有所下降。这凸显了准确率与多样性之间的权衡，我们相信对这些发现的透明呈现将激发关于模式坍缩（mode collapse）、小模型性能等领域的进一步研究。

通过这项工作，我们努力探索小参数模型所能达到的边界，也很期待看到社区如何在不牺牲性能质量的前提下持续提升推理效率。
