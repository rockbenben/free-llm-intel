# 在 Hugging Face Hub 上分享你的开放 ML 数据集！

如果你在做数据密集型研究或机器学习项目，就需要一种可靠的方式来分享和托管数据集。Common Crawl、ImageNet、Common Voice 这样的公共数据集对开放 ML 生态至关重要，但它们的托管和分享可能并不容易。

Hugging Face Hub 让托管和分享数据集变得丝滑无比，包括 [Nvidia](https://huggingface.co/nvidia)、[Google](https://huggingface.co/google)、[Stanford](https://huggingface.co/stanfordnlp)、[NASA](https://huggingface.co/ibm-nasa-geospatial)、[THUDM](https://huggingface.co/THUDM) 和 [Barcelona Supercomputing Center](https://huggingface.co/BSC-LT) 在内的众多领先研究机构、公司和政府部门都信赖它。

在 Hugging Face Hub 上托管数据集，你会立即获得能最大化工作影响力的功能：

- [慷慨的限额](https://huggingface.co/blog/researcher-dataset-sharing#generous-limits)
- [数据集查看器](https://huggingface.co/blog/researcher-dataset-sharing#dataset-viewer)
- [第三方库支持](https://huggingface.co/blog/researcher-dataset-sharing#third-party-library-support)
- [SQL 控制台](https://huggingface.co/blog/researcher-dataset-sharing#sql-console)
- [安全性](https://huggingface.co/blog/researcher-dataset-sharing#security)
- [触达与曝光](https://huggingface.co/blog/researcher-dataset-sharing#reach-and-visibility)

## 慷慨的限额

### 支持大数据集

Hub 可以托管 TB 级数据集，并有很高的[单文件和单仓库限额](https://huggingface.co/docs/hub/en/repositories-recommendations)。如果你有数据要分享，Hugging Face datasets 团队可以帮你选择适合社区使用的上传格式。[🤗 Datasets 库](https://huggingface.co/docs/datasets/index)让上传下载文件很轻松，甚至可以从零创建一个数据集。🤗 Datasets 还支持数据集流式加载（streaming），无需下载整个数据集就能处理大数据集。对于计算资源较少的研究者使用你的数据集，或者从超大数据集中选一小部分做测试、开发、原型验证，这一点价值连城。

![Screenshot of the file size information for a dataset](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/researcher-dataset-sharing/filesize.png)
 *Hugging Face Hub 能够托管机器学习研究常产生的那种大规模数据集。*

*注：[Xet 团队](https://huggingface.co/xet-team)正在开发后端更新，将把单文件限额从当前的 50 GB 提升到 500 GB，同时改善存储和传输效率。*

## 数据集查看器

Hub 不止托管数据，还提供强大的探索工具。用 Datasets Viewer，用户可以直接在浏览器里探索和交互 Hub 上托管的数据集。别人不用先下载就能查看、探索你的数据，门槛极低。

Hugging Face datasets 支持多种模态（音频、图像、视频等）和文件格式（CSV、JSON、Parquet 等）以及压缩格式（Gzip、Zip 等）。详见 [Datasets 文件格式](https://huggingface.co/docs/hub/en/datasets-adding#file-formats)页面。

![Screenshot of the Datasets Viewer](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/datasets/infinity-instruct.png)
 *Infinity-Instruct 数据集的 Dataset Viewer。*

Datasets Viewer 还内置一些让数据集探索更轻松的功能。

### 全文检索

内置全文检索是 Datasets Viewer 最强大的功能之一。数据集中的任何文本列立刻变得可搜索。

Arxiver 数据集包含 6.34 万行转换为 Markdown 的 arXiv 研究论文。用全文检索，很容易找到包含某个特定作者（比如下面的 Ilya Sutskever）的论文。

### 排序

Datasets Viewer 支持点击列标题对数据集排序，方便找出数据集中最相关的样本。

## 第三方库支持

Hugging Face 很幸运地与主流开源数据工具建立了第三方集成。数据集一旦托管在 Hub 上，就立刻与用户最熟悉的工具兼容。

以下是 Hugging Face 开箱即用的部分库：

| 库 | 描述 | PyPi 月下载量（2024） |
| --- | --- | --- |
| [Pandas](https://huggingface.co/docs/hub/datasets-pandas) | Python 数据分析工具包。 | **258M** |
| [Spark](https://huggingface.co/docs/hub/datasets-spark) | 分布式环境下的实时大规模数据处理工具。 | **29M** |
| [Datasets](https://huggingface.co/docs/hub/datasets-usage) | 🤗 Datasets 是一个用于访问和分享音频、计算机视觉、自然语言处理（NLP）数据集的库。 | **17M** |
| [Dask](https://huggingface.co/docs/hub/datasets-dask) | 并行与分布式计算库，扩展现有 Python 和 PyData 生态。 | **12M** |
| [Polars](https://huggingface.co/docs/hub/datasets-polars) | 构建在 OLAP 查询引擎之上的 DataFrame 库。 | **8.5M** |
| [DuckDB](https://huggingface.co/docs/hub/datasets-duckdb) | 进程内 SQL OLAP 数据库管理系统。 | **6M** |
| [WebDataset](https://huggingface.co/docs/hub/datasets-webdataset) | 为大数据集编写 I/O 管道的库。 | **871K** |
| [Argilla](https://huggingface.co/docs/hub/datasets-argilla) | 面向重视高质量数据的 AI 工程师与领域专家的协作工具。 | **400k** |

这些库大多能一行代码加载或流式读取数据集。

这里是 Pandas、Polars 和 DuckDB 的一些示例：

```
# Pandas example
import pandas as pd
df = pd.read_parquet("hf://datasets/neuralwork/arxiver/data/train.parquet")

# Polars example 
import polars as pl
df = pl.read_parquet("hf://datasets/neuralwork/arxiver/data/train.parquet")

# DuckDB example - SQL queries
import duckdb
duckdb.sql("SELECT * FROM 'hf://datasets/neuralwork/arxiver/data/train.parquet' LIMIT 10")
```

集成库的更多信息见 [Datasets 文档](https://huggingface.co/docs/hub/en/datasets-libraries)。除了上面列出的库，还有很多支持 Hugging Face Hub 的社区工具，比如 [Lilac](https://lilacml.com/) 和 [Spotlight](https://github.com/Renumics/spotlight)。

## SQL 控制台

[SQL Console](https://huggingface.co/blog/sql-console) 提供一个完全在浏览器中运行的交互式 SQL 编辑器，无需任何配置即可立即探索数据。关键特性包括：

- **一键打开**：单击即可打开 SQL Console 查询数据集
- **可分享、可嵌入的结果**：分享并嵌入有趣的查询结果
- **完整的 DuckDB 语法**：使用完整 SQL 语法，内置正则、列表、JSON、嵌入向量等函数

每个公共数据集上都应该能看到一个新的 **SQL Console** 徽章。点一下就能打开 SQL Console 查询该数据集。

在 Magpie-Ultra 数据集中查询高质量推理指令的示例。

## 安全性

让数据集易于访问很重要，保护敏感数据同样关键。Hugging Face Hub 提供了健壮的安全功能，帮你在面向合适受众分享数据的同时保持控制权。

### 访问控制

Hugging Face Hub 对数据集的访问对象提供独特的访问控制选项。

- **Public（公开）**：任何人都能访问数据集。
- **Private（私有）**：只有你和组织内成员能访问数据集。
- **Gated（受限）**：通过两种方式控制数据集访问：**自动批准**：用户须先提供必要信息（如姓名和邮箱）并同意条款才能获得访问权；**人工批准**：你逐个审核并批准/拒绝访问请求。

关于受限数据集的更多细节见 [gated datasets 文档](https://huggingface.co/docs/hub/en/datasets-gated)。想要更细粒度的控制，Enterprise 计划支持[创建资源安全组](https://huggingface.co/docs/hub/en/security-resource-groups)、使用 [SSO](https://huggingface.co/docs/hub/en/security-sso) 等功能。

### 内置安全扫描

除了访问控制，Hugging Face Hub 还提供多种安全扫描器：

| 特性 | 描述 |
| --- | --- |
| [恶意软件扫描](https://huggingface.co/docs/hub/en/security-malware) | 在每次 commit 和访问时扫描文件中的恶意软件与可疑内容 |
| [密钥扫描](https://huggingface.co/docs/hub/en/security-secrets) | 拦截含有硬编码密钥和环境变量的数据集 |
| [Pickle 扫描](https://huggingface.co/docs/hub/en/security-pickle) | 扫描 pickle 文件，并为 PyTorch 权重显示经过验证的导入 |
| [ProtectAI](https://huggingface.co/docs/hub/en/security-protectai) | 使用 Guardian 技术拦截含 pickle、Keras 及其他漏洞的数据集 |

想深入了解这些扫描器，见安全扫描器文档。

## 触达与曝光

一个安全、功能强大的平台很有价值，但研究的真正影响力来自触达对的受众。对分享数据集的研究者来说，触达与曝光至关重要——它能最大化研究影响、支撑可复现性、促进协作，让宝贵数据惠及更广泛的科学社区。

Hugging Face Hub 上有超过 500 万活跃建设者，为研究者提供了社区参与和曝光的有力工具。你可以期待：

### 更好的社区参与

- 每个数据集自带讨论区，方便社区交流
- 组织（Organization）可以把多个数据集集中归组、协作管理
- 数据集使用与影响力指标

### 更广的触达

- 接触庞大活跃的研究者、开发者与从业者社区
- SEO 优化的 URL，让你的数据集更容易被发现
- 融入模型、数据集、库的更大生态
- 数据集与相关模型、论文、demo 之间的清晰链接

### 更好的文档

- 可定制的 README，支撑全面文档
- 支持详细的数据集描述与规范的学术引用
- 链接到相关研究论文与出版物

## 我该怎么在 Hugging Face Hub 上托管数据集？

了解了在 Hub 上托管数据集的好处后，你可能想知道如何开始。这里有一批全面的资料指引你：

- 关于[创建](https://huggingface.co/docs/datasets/create_dataset)和[在 Hub 上分享数据集](https://huggingface.co/docs/datasets/upload_dataset)的通用指南
- 各模态的专门指南：创建[音频数据集](https://huggingface.co/docs/datasets/audio_dataset)、创建[图像数据集](https://huggingface.co/docs/datasets/image_dataset)、创建[视频数据集](https://huggingface.co/docs/datasets/video_dataset)
- 关于[仓库结构组织](https://huggingface.co/docs/datasets/repository_structure)的指引，让数据集能被自动从 Hub 加载

想分享大数据集的话，以下页面会很有用：

- [仓库限制与建议](https://huggingface.co/docs/hub/repositories-recommendations)提供了分享大数据集时需要考虑的一般性指引。
- [大型上传技巧](https://huggingface.co/docs/huggingface_hub/guides/upload#tips-and-tricks-for-large-uploads)页说明了如何把大数据集上传到 Hub。

如果你在上传数据集到 Hub 时需要更多帮助，或要上传特别大的数据集，请联系 [datasets@huggingface.co](mailto:datasets@huggingface.co)。
