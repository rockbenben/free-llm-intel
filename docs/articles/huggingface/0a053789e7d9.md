# Llama 2 来了——在 Hugging Face 获取它

## 引言

Llama 2 是 Meta 今天发布的一系列最先进（state-of-the-art）开放访问大语言模型，我们很高兴全面支持这次发布，在 Hugging Face 提供完整集成。Llama 2 采用非常宽松的社会化许可（community license），可用于商业。代码、预训练模型、微调模型今天全部放出 🔥

我们与 Meta 合作确保平滑接入 Hugging Face 生态。你可以在 Hub 上找到 12 个开放访问模型（3 个基座模型和 3 个微调模型，含 Meta 原始 checkpoint 及对应的 `transformers` 模型）。本次发布的特性与集成包括：

- [Hub 上的模型](https://huggingface.co/meta-llama)，附带模型卡和许可证。
- [Transformers 集成](https://github.com/huggingface/transformers/releases/tag/v4.31.0)
- 用单卡 GPU 微调小型版本的示例
- 与 [Text Generation Inference](https://github.com/huggingface/text-generation-inference) 集成，实现快速高效的生产级推理
- 与 Inference Endpoints 集成

## 为什么是 Llama 2？

Llama 2 发布引入了一系列预训练和微调 LLM，规模从 7B 到 70B 参数（7B、13B、70B）。预训练模型相比 Llama 1 有重大改进：训练 token 多 40%、上下文长度大幅扩展（4k token 🤯）、70B 模型采用分组查询注意力（grouped-query attention）以实现快速推理 🔥！

不过，这次发布最令人兴奋的是微调模型（Llama 2-Chat）——它们用[人类反馈强化学习（RLHF）](https://huggingface.co/blog/rlhf)针对对话应用做了优化。在广泛的有用性和安全基准上，Llama 2-Chat 模型表现优于多数开放模型，按人工评估与 ChatGPT 相当。论文见[这里](https://huggingface.co/papers/2307.09288)。

## 推理

本节介绍运行 Llama 2 模型推理的几种途径。在使用这些模型之前，请先在官方 [Meta Llama 2](https://huggingface.co/meta-llama) 仓库申请访问权限。

### 使用 transformers

借助 transformers [4.31 版本](https://github.com/huggingface/transformers/releases/tag/v4.31.0)，你已经可以使用 Llama 2 并利用 HF 生态中的全部工具，例如：

- 训练与推理脚本及示例
- 安全文件格式（`safetensors`）
- 与 bitsandbytes（4-bit 量化）、PEFT（参数高效微调）等工具的集成
- 运行模型生成的实用函数与辅助工具
- 将模型导出以部署的机制

确保使用最新的 `transformers` 发布版，并已登录你的 Hugging Face 账号。

```
pip install transformers
huggingface-cli login
```

下面的代码片段演示如何用 transformers 跑推理。只要选择 GPU runtime，它就能在 Colab 免费层上运行。

```
from transformers import AutoTokenizer
import transformers
import torch

model = "meta-llama/Llama-2-7b-chat-hf"

tokenizer = AutoTokenizer.from_pretrained(model)
pipeline = transformers.pipeline(
    "text-generation",
    model=model,
    torch_dtype=torch.float16,
    device_map="auto",
)

sequences = pipeline(
    'I liked "Breaking Bad" and "Band of Brothers". Do you have any recommendations of other shows I might like?\n',
    do_sample=True,
    top_k=10,
    num_return_sequences=1,
    eos_token_id=tokenizer.eos_token_id,
    max_length=200,
)
for seq in sequences:
    print(f"Result: {seq['generated_text']}")
```

### 使用 text-generation-inference 与 Inference Endpoints

**[Text Generation Inference](https://github.com/huggingface/text-generation-inference)** 是 Hugging Face 开发的生产级推理容器，让大语言模型的部署变得简单。它支持连续批处理（continuous batching）、token 流式输出、多 GPU 张量并行加速推理，以及生产级的日志与追踪。

你可以在自己的基础设施上试用 Text Generation Inference，也可以使用 Hugging Face 的 **[Inference Endpoints](https://huggingface.co/inference-endpoints)**。要部署 Llama 2 模型，前往 **[模型页面](https://huggingface.co/meta-llama/Llama-2-7b-hf)** 并点击 **[Deploy -> Inference Endpoints](https://ui.endpoints.huggingface.co/new?repository=meta-llama/Llama-2-7b-hf)** 组件。

- 7B 模型：建议选 "GPU [medium] - 1x Nvidia A10G"。
- 13B 模型：建议选 "GPU [xlarge] - 1x Nvidia A100"。
- 70B 模型：建议选 "GPU [2xlarge] - 2x Nvidia A100" 并开启 `bitsandbytes` 量化，或 "GPU [4xlarge] - 4x Nvidia A100"

*注意：访问 A100 可能需要发邮件到 **[api-enterprise@huggingface.co](mailto:api-enterprise@huggingface.co)** 申请提升配额*

关于如何用 [Hugging Face Inference Endpoints 部署 LLM，详见我们的博客](https://huggingface.co/blog/inference-endpoints-llm)。该[博客](https://huggingface.co/blog/inference-endpoints-llm)包含支持的超参数信息，以及如何用 Python 和 Javascript 流式获取响应。

## 用 PEFT 微调

训练 LLM 在技术和算力上都颇具挑战。本节我们看看 Hugging Face 生态中有哪些工具能在简单硬件上高效训练 Llama 2，并演示如何在单块 NVIDIA T4（16GB——Google Colab）上微调 7B 版本。更多内容见 [Making LLMs even more accessible 博客](https://huggingface.co/blog/4bit-transformers-bitsandbytes)。

我们做了一个用 QLoRA 和 [`trl`](https://github.com/lvwerra/trl) 的 [`SFTTrainer`](https://huggingface.co/docs/trl/v0.4.7/en/sft_trainer) 对 Llama 2 做指令微调的[脚本](https://github.com/lvwerra/trl/blob/main/examples/scripts/sft_trainer.py)。

下面是用 `timdettmers/openassistant-guanaco` 微调 Llama 2 7B 的示例命令。脚本在提供 `merge_and_push` 参数时可以把 LoRA 权重合并进模型权重并保存为 `safetensor` 权重。这让训练完的微调模型可以直接用 text-generation-inference 和 inference endpoints 部署。

先 pip 安装 `trl` 并克隆脚本：

```
pip install trl
git clone https://github.com/lvwerra/trl
```

然后就可以运行脚本：

```
python trl/examples/scripts/sft_trainer.py \
    --model_name meta-llama/Llama-2-7b-hf \
    --dataset_name timdettmers/openassistant-guanaco \
    --load_in_4bit \
    --use_peft \
    --batch_size 4 \
    --gradient_accumulation_steps 2
```

## 如何向 Llama 2 写提示词

开放访问模型一个常被忽视的优势，是你对聊天应用的 `system` 提示词拥有完全控制权。这决定了聊天助手的行为——甚至可以带点个性——但对于藏在 API 背后的模型，这是遥不可及的。

Llama 2 发布没几天我们就补上这一节，因为社区大量询问如何给模型写提示词、如何修改 system prompt。希望能帮到你！

第一轮对话的提示词模板如下：

```
<s>[INST] <<SYS>>
{{ system_prompt }}
<</SYS>>

{{ user_message }} [/INST]
```

这个模板遵循模型的训练流程，详见 [Llama 2 论文](https://huggingface.co/papers/2307.09288)。我们可以用任何想要的 `system_prompt`，但关键是格式必须与训练时一致。

说得更明白些：当用户在[我们的 13B 聊天演示](https://huggingface.co/spaces/huggingface-projects/llama-2-13b-chat)中输入一段文字（`There's a llama in my garden 😱 What should I do?`）发起对话时，实际发送给语言模型的内容是：

```
<s>[INST] <<SYS>>
You are a helpful, respectful and honest assistant. Always answer as helpfully as possible, while being safe.  Your answers should not include any harmful, unethical, racist, sexist, toxic, dangerous, or illegal content. Please ensure that your responses are socially unbiased and positive in nature.

If a question does not make any sense, or is not factually coherent, explain why instead of answering something not correct. If you don't know the answer to a question, please don't share false information.
<</SYS>>

There's a llama in my garden 😱 What should I do? [/INST]
```

可以看到，特殊的 `<<SYS>>` token 之间的指令为模型提供了上下文，让它知道我们期望它如何回应。之所以有效，是因为训练时用的正是同一格式，且搭配了大量面向不同任务的 system prompt。

随着对话推进，人与"机器人"之间的*所有*交互都会以 `[INST]` 定界符包裹后追加到前面的提示之后。多轮对话所用的模板遵循以下结构（🎩 感谢 [Arthur Zucker](https://huggingface.co/ArthurZ) 做的最终澄清）：

```
<s>[INST] <<SYS>>
{{ system_prompt }}
<</SYS>>

{{ user_msg_1 }} [/INST] {{ model_answer_1 }} </s><s>[INST] {{ user_msg_2 }} [/INST]
```

模型是无状态的，不会"记住"对话的先前片段，我们必须每次都提供全部上下文，对话才能继续。这也是为什么**上下文长度**是一个极其重要、要尽量拉满的参数——它让更长的对话和更多的信息使用成为可能。

### 忽略之前的指令

在基于 API 的模型上，人们用各种技巧试图覆盖 system prompt、改变模型默认行为。这些方案虽然想象力丰富，但对开放访问模型来说并不必要：任何人都可以使用不同的提示词，只要遵循上面描述的格式。我们相信这将是研究者的重要工具——用来研究提示词对期望特性与非期望特性的影响。例如，当人们[被过分谨慎的回答惊到时](https://twitter.com/lauraruis/status/1681612002718887936)，你可以试试[换一个提示词是否有效](https://twitter.com/overlordayn/status/1681631554672513025)。（🎩 感谢 [Clémentine Fourrier](https://huggingface.co/clefourrier) 提供本例链接。）

在我们的 [`13B`](https://huggingface.co/spaces/huggingface-projects/llama-2-13b-chat) 和 [`7B`](https://huggingface.co/spaces/huggingface-projects/llama-2-7b-chat) 演示里，只要展开 "Advanced Options"、直接写下你想要的指令，就能轻松体验这个功能。你也可以复制这些演示，私下用于娱乐或研究！
