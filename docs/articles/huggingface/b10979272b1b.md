## **什么是 RL？简短回顾**

在 RL 中，我们构建一个能**做出明智决策**的 agent。比如一个**学习玩电子游戏的** agent；或者一个交易 agent，通过决定**买什么股票、何时卖出**来**最大化自己的收益**。

但为了做出智能决策，我们的 agent 将通过**试错的方式与环境交互**，并接收奖励（正或负）作为**唯一的反馈**，从环境中学习。

它的目标**是最大化期望累计奖励**（因为奖励假说）。

**agent 的决策过程称为策略 π**：给定一个状态，策略会输出一个动作或动作上的概率分布。也就是说，给定对环境的观察，策略会提供 agent 应当执行的动作（或每个动作对应的多个概率）。

**我们的目标是找到最优策略 π***，即能带来最好期望累计奖励的策略。

要找到这个最优策略（也就是求解 RL 问题），有**两大类 RL 方法**：

- *基于策略的方法（Policy-based）*：**直接训练策略**，学习给定状态该采取什么动作。
- *基于价值的方法（Value-based）*：**训练价值函数**，学习**哪个状态更有价值**，然后用这个价值函数**选择通向它的动作**。

本章我们**将深入基于价值的方法。**

## **基于价值方法的两种类型**

在基于价值的方法中，**我们学习一个价值函数**，它把**状态映射到处于该状态的期望值**。

一个状态的价值，是 agent 如果**从该状态出发、随后按照我们的策略行动**所能得到的**期望折扣回报**。

如果你忘了什么是折扣，可以[读这一节](https://huggingface.co/blog/deep-rl-intro#rewards-and-the-discounting)。

> 但「按照我们的策略行动」是什么意思？毕竟基于价值的方法里没有策略啊——我们训练的是价值函数，不是策略。

记住，**RL agent 的目标是拥有最优策略 π**。

我们已经学过，要找最优策略有两条路：

- *基于策略的方法*：**直接训练策略**，为给定状态选择动作（或该状态上动作的概率分布）。这种情况下我们**没有价值函数**。

策略以状态为输入，输出在该状态该取什么动作（确定性策略）。

因此，**我们不用手工定义策略的行为；训练会自己定义它。**

- *基于价值的方法*：**间接地训练一个价值函数**，输出某个状态或某个状态-动作对的价值。有了这个价值函数，我们的策略**据此采取行动**。

但由于我们没有训练策略，**就需要指定它的行为**。例如，如果希望策略在给定价值函数时总能采取带来最大奖励的动作，我们就**构造一个贪心（Greedy）策略**。

给定一个状态，我们（训练出来的）动作价值函数输出该状态下每个动作的价值，然后我们的贪心策略（由我们定义）选取状态-动作对价值最大的那个动作。

所以无论你用什么方法求解问题，**你都会有一个策略**。只是在基于价值的方法里，你并不训练它——你的策略**只是一个你指定的简单函数**（比如贪心策略），而这个策略**利用价值函数给出的值来选择动作**。

区别在于：

- 在基于策略的方法中，**通过直接训练策略找到最优策略。**
- 在基于价值的方法中，**找到最优价值函数就意味着拥有最优策略。**

实际上，多数时候在基于价值的方法里，你会使用**Epsilon-Greedy 策略**来处理探索/利用的权衡——本单元第二部分讲 Q-Learning 时会说到它。

那么，价值函数有两种类型：

### **动作价值函数**

在动作价值函数中，对每个状态-动作对，动作价值函数**输出期望回报**：agent 从该状态出发、执行该动作、此后永远遵循策略。

注：动作价值函数的示例中，我们没有填满所有状态-动作对。

无论选哪种价值函数（状态价值或动作价值函数），**价值都是期望回报**。

但问题在于：这意味着**要计算每个状态或每个状态-动作对的值，都需要对 agent 从该状态出发能拿到的所有奖励求和**。

这会是个繁琐的过程——**贝尔曼方程正是来帮忙的。**

## **贝尔曼方程：简化我们的价值估计**

贝尔曼方程**简化了状态价值或状态-动作值的计算**。

以我们目前所学，计算 V(St)V(S_t)V(St​)（某状态的价值）时，需要计算从该状态出发的回报、然后永远遵循策略。（下面例子中我们定义的策略是贪心策略，且为简化起见不对奖励做折扣。）

所以为了计算 V(St)V(S_t)V(St​)，我们需要对期望奖励求和，即：

计算状态 1 的价值：如果 agent 从该状态出发、此后每一步都遵循贪心策略（选取通往最佳状态值的动作），所得奖励之和。

然后，要计算 V(St+1)V(S_{t+1})V(St+1​)，我们需要计算从状态 St+1S_{t+1}St+1​ 出发的回报。

计算状态 2 的价值：如果 agent 从该状态出发、此后每一步都遵循**策略**，所得奖励之和。

你看，如果每个状态价值或状态-动作价值都要这样算，过程相当繁琐。

不必对每个状态或每个状态-动作对计算期望回报——**我们可以用贝尔曼方程。**

贝尔曼方程是一个递归方程，思路是这样：不必对每个状态从头开始计算回报，而是把任何状态的价值看作：

**即时奖励 Rt+1R_{t+1}Rt+1​ + 后继状态的折扣价值（ gamma∗V(St+1)gamma * V(S_{t+1})gamma∗V(St+1​)）。**

为简化起见，这里不做折扣，即 gamma = 1。

回到我们的例子，状态 1 的价值 = 从该状态出发的期望累计回报。

计算状态 1 的价值：如果 agent **从状态 1 出发**、此后每一步都遵循**策略**，奖励之和。

这等价于 V(St)V(S_{t})V(St​) = 即时奖励 Rt+1R_{t+1}Rt+1​ + 下一状态的折扣价值 gamma∗V(St+1)gamma * V(S_{t+1})gamma∗V(St+1​)

为简化起见，这里不做折扣，即 gamma = 1。

- V(St+1)V(S_{t+1}) V(St+1​) 的价值 = 即时奖励 Rt+2R_{t+2}Rt+2​ + 下一状态的折扣价值（ gamma∗V(St+2)gamma * V(S_{t+2})gamma∗V(St+2​)）。
- 以此类推。

概括一下，贝尔曼方程的思想是：与其把每个价值都按期望回报之和来计算（那是**一个漫长的过程**），不如把它**等价于即时奖励 + 后继状态的折扣价值之和**。

## **蒙特卡洛 vs 时序差分学习**

深入 Q-Learning 之前，最后要讲的是两种学习方式。

记住，RL agent 是**通过与环境交互来学习**的。思路是**利用所经历的轨迹**，根据它获得的奖励来**更新自己的价值或策略**。

蒙特卡洛和时序差分学习是训练价值函数或策略函数的两种不同**策略**，二者都**用经验来求解 RL 问题**。

一方面，蒙特卡洛**要用完一整回合的体验**才学习；另一方面，时序差分**只用一步 ( St,At,Rt+1,St+1S_t, A_t, R_{t+1}, S_{t+1}St​,At​,Rt+1​,St+1​ ) 来学习。**

我们将**用一个基于价值方法的例子**把两者都讲清楚。

### **蒙特卡洛：在回合结束时学习**

蒙特卡洛会等到回合结束，计算 GtG_tGt​（回报），并把它用作更新 V(St)V(S_t)V(St​) 的**目标**。

也就是说，它需要**一整回合的完整交互**才能更新我们的价值函数。

举个例子：

- 每回合都**从相同的起点开始**。
- **agent 用策略执行动作**。例如使用 Epsilon-Greedy 策略——一个在探索（随机动作）与利用之间交替的策略。
- 我们获得**奖励和下一个状态**。
- 如果猫吃到老鼠，或老鼠移动超过 10 步，回合终止。
- 回合结束时，我们得到一个状态、动作、奖励、下一状态的列表。
- **agent 把总奖励 GtG_tGt​ 加起来**（看看自己表现如何）。
- 然后**根据公式更新 V(st)V(s_t)V(st​)**

- 再带着**这份新知识开始新一局**

随着回合越跑越多，**agent 会玩得越来越好**。

例如，如果用蒙特卡洛训练一个状态价值函数：

- 价值函数刚刚开始训练，**所以每个状态返回 0 值**
- 学习率（lr）为 0.1，折扣率为 1（= 不折扣）
- 我们的老鼠**探索环境，执行随机动作**

- 老鼠走了超过 10 步，回合结束。

- 得到了状态、动作、奖励、next_state 的列表，**需要计算回报 GtG{t}Gt**
- Gt=Rt+1+Rt+2+Rt+3...G_t = R_{t+1} + R_{t+2} + R_{t+3} ...Gt​=Rt+1​+Rt+2​+Rt+3​...
- Gt=Rt+1+Rt+2+Rt+3…G_t = R_{t+1} + R_{t+2} + R_{t+3}…Gt​=Rt+1​+Rt+2​+Rt+3​…（为简化，不对奖励做折扣）。
- Gt=1+0+0+0+0+0+1+1+0+0G_t = 1 + 0 + 0 + 0+ 0 + 0 + 1 + 1 + 0 + 0Gt​=1+0+0+0+0+0+1+1+0+0
- Gt=3G_t= 3Gt​=3
- 现在可以更新 V(S0)V(S_0)V(S0​) 了：

- 新的 V(S0)=V(S0)+lr∗[Gt—V(S0)]V(S_0) = V(S_0) + lr * [G_t — V(S_0)]V(S0​)=V(S0​)+lr∗[Gt​—V(S0​)]
- 新的 V(S0)=0+0.1∗[3–0]V(S_0) = 0 + 0.1 * [3 – 0]V(S0​)=0+0.1∗[3–0]
- 新的 V(S0)=0.3V(S_0) = 0.3V(S0​)=0.3

### **时序差分学习：在每一步学习**

- **时序差分则只等待一次交互（一步）St+1S_{t+1}St+1​**
- 就构成 TD 目标，用 Rt+1R_{t+1}Rt+1​ 和 gamma∗V(St+1)gamma * V(S_{t+1})gamma∗V(St+1​) 来更新 V(St)V(S_t)V(St​)。

**TD** 的思路是**每一步都更新 V(St)V(S_t)V(St​)**。

但因为我们没有玩完整个回合，没有 GtG_tGt​（期望回报）。取而代之，**我们用 Rt+1R_{t+1}Rt+1​ 加上下一状态的折扣价值来估计 GtG_tGt​**。

这称为自举（bootstrapping）。之所以这么叫，**因为 TD 的更新部分基于已有的估计 V(St+1)V(S_{t+1})V(St+1​)，而不是完整的采样 GtG_tGt​。**

这个方法叫 TD(0)，也即**一步 TD（在任何单独一步之后就更新价值函数）**。

还是用同一个例子：

- 价值函数刚刚开始训练，所以每个状态返回 0 值。
- 学习率（lr）为 0.1，折扣率为 1（不折扣）。
- 我们的老鼠探索环境，执行了一个随机动作：**向左走**
- 它获得奖励 Rt+1=1R_{t+1} = 1Rt+1​=1，因为**它吃到了一块奶酪**

现在可以更新 V(S0)V(S_0)V(S0​)：

新的 V(S0)=V(S0)+lr∗[R1+gamma∗V(S1)−V(S0)]V(S_0) = V(S_0) + lr * [R_1 + gamma * V(S_1) - V(S_0)]V(S0​)=V(S0​)+lr∗[R1​+gamma∗V(S1​)−V(S0​)]

新的 V(S0)=0+0.1∗[1+1∗0–0]V(S_0) = 0 + 0.1 * [1 + 1 * 0–0]V(S0​)=0+0.1∗[1+1∗0–0]

新的 V(S0)=0.1V(S_0) = 0.1V(S0​)=0.1

我们刚刚更新了状态 0 的价值函数。

接下来**继续用更新后的价值函数与环境交互**。

总结一下：

- 蒙特卡洛从完整回合更新价值函数，用的是**该回合实际准确的折扣回报**。
- TD 学习从单步更新价值函数，所以把我们没有的 GtG_tGt​ 替换成**一个估计回报，即 TD 目标**。

那么在正式学习 Q-Learning 之前，把刚才内容捋一遍：

价值函数有两种类型：

- 状态价值函数：输出 agent **从给定状态出发**、此后一直按策略行动的期望回报。
- 动作价值函数：输出 agent 从给定状态出发、**在该状态执行给定动作**、此后一直按策略行动的期望回报。
- 在基于价值的方法中，**策略是我们手工定义的**，因为我们训练的是价值函数而不是策略。思路是：有了最优价值函数，我们就**会拥有最优策略**。

学习价值函数的策略有两类方法：

- *蒙特卡洛方法*：从完整回合更新价值函数，用**该回合实际准确的折扣回报**。
- *TD 学习方法*：从单步更新价值函数，把没有的 Gt 替换成**估计回报，即 TD 目标**。
