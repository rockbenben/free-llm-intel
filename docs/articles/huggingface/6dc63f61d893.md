# 欢迎 PaddlePaddle 加入 Hugging Face Hub

我们很高兴分享 Hugging Face 与 [PaddlePaddle](https://www.paddlepaddle.org.cn/en)（百度飞桨）之间的一次开源合作——我们有着共同的使命：通过开源推动并普及 AI！

PaddlePaddle 由百度于 2016 年首次开源，让各种水平的开发者都能大规模采用和落地深度学习。截至 2022 年第四季度，PaddlePaddle 已服务超过 535 万开发者和 20 万家企业，在中国深度学习平台中市场份额排名第一。PaddlePaddle 拥有许多流行的开源仓库，例如 [Paddle](https://github.com/PaddlePaddle/Paddle) 深度学习框架、覆盖不同模态的模型库（如 [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR)、[PaddleDetection](https://github.com/PaddlePaddle/PaddleDetection)、[PaddleNLP](https://github.com/PaddlePaddle/PaddleNLP)、[PaddleSpeech](https://github.com/PaddlePaddle/PaddleSpeech)）、用于模型压缩的 [PaddleSlim](https://github.com/PaddlePaddle/PaddleSlim)、用于模型部署的 [FastDeploy](https://github.com/PaddlePaddle/FastDeploy) 等等。

[![thumbnail](https://huggingface.co/blog/assets/126_paddlepaddle/thumbnail.jpg)](https://huggingface.co/blog/assets/126_paddlepaddle/thumbnail.jpg)

**随着 [PaddleNLP](https://huggingface.co/docs/hub/paddlenlp) 率先推进，PaddlePaddle 将逐步把其各库与 Hugging Face Hub 集成。** 很快你就能在 Hub 上把玩 PaddlePaddle 全套出色的预训练模型，覆盖文本、图像、音频、视频和多模态！

## 查找 PaddlePaddle 模型

你可以在 Model Hub 上用 [PaddlePaddle library 标签](https://huggingface.co/models?library=paddlepaddle)筛选，找到所有 PaddlePaddle 模型。

![PaddlePaddle Tag](https://huggingface.co/blog/assets/126_paddlepaddle/paddle_tag.png)

Hub 上已有超过 75 个 PaddlePaddle 模型。举例来说，你可以找到我们的多任务信息抽取模型系列 [UIE](https://huggingface.co/PaddlePaddle/uie-base)、SOTA 中文语言模型 [ERNIE 3.0 模型系列](https://huggingface.co/PaddlePaddle/ernie-3.0-nano-zh)，以及在整个流程中融合了布局知识增强的新型文档预训练模型 [Ernie-Layout](https://huggingface.co/blog/PaddlePaddle/ernie-layoutx-base-uncased) 等等。

也欢迎查看 HuggingFace Hub 上的 [PaddlePaddle](https://huggingface.co/PaddlePaddle) 组织。除了上述模型，你还可以探索我们的 Spaces，包括文生图 [Ernie-ViLG](https://huggingface.co/spaces/PaddlePaddle/ERNIE-ViLG)、跨模态信息抽取引擎 [UIE-X](https://huggingface.co/spaces/PaddlePaddle/UIE-X)，以及出色的多语言 OCR 工具包 [PaddleOCR](https://huggingface.co/spaces/PaddlePaddle/PaddleOCR)。

## Inference API 与 Widget

PaddlePaddle 模型可通过 [Inference API](https://huggingface.co/docs/hub/models-inference) 使用。你可以用 cURL 通过 HTTP 访问，也可以用 Python 的 requests 库或任何你喜欢的方式发起网络请求。

[![inference_api](https://huggingface.co/blog/assets/126_paddlepaddle/inference_api.png)](https://huggingface.co/blog/assets/126_paddlepaddle/inference_api.png)

支持某个[任务](https://huggingface.co/tasks)的模型配有交互式 widget，让你直接在浏览器里体验模型。

[![widget](https://huggingface.co/blog/assets/126_paddlepaddle/widget.png)](https://huggingface.co/blog/assets/126_paddlepaddle/widget.png)

## 使用现有模型

想看看如何加载某个特定模型，可以点击 `Use in paddlenlp`（或未来支持的其他 PaddlePaddle 库），你会得到一段可用的加载代码！

[![snippet](https://huggingface.co/blog/assets/126_paddlepaddle/snippet.png)](https://huggingface.co/blog/assets/126_paddlepaddle/snippet.png)

## 分享模型

取决于具体的 PaddlePaddle 库，你可能可以直接推送到 Hub 来分享模型。例如，用 `save_to_hf_hub` 方法即可分享 PaddleNLP 模型。

```
from paddlenlp.transformers import AutoTokenizer, AutoModelForMaskedLM

tokenizer = AutoTokenizer.from_pretrained("PaddlePaddle/ernie-3.0-base-zh", from_hf_hub=True)
model = AutoModelForMaskedLM.from_pretrained("PaddlePaddle/ernie-3.0-base-zh", from_hf_hub=True)

tokenizer.save_to_hf_hub(repo_id="<my_org_name>/<my_repo_name>")
model.save_to_hf_hub(repo_id="<my_org_name>/<my_repo_name>")
```
