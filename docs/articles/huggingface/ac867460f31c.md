# Hugging Face 与微软合作，在 Azure 上推出 Hugging Face 模型目录

[![Hugging Face Endpoints on Azure](https://huggingface.co/blog/assets/75_hugging_face_endpoints_on_azure/01.jpg)](https://huggingface.co/blog/assets/75_hugging_face_endpoints_on_azure/01.jpg)

今天，我们兴奋地宣布 Hugging Face 扩展了与微软的合作，把 Hugging Face Hub 上的开源模型带入 Azure Machine Learning。我们一起构建了一个全新的 Hugging Face Hub Model Catalog，直接内嵌于 Azure Machine Learning Studio，其中收录了来自 [Hugging Face Hub](https://huggingface.co/models) 的数千个最受欢迎的 Transformers 模型。借助这次新集成，你现在只需几次点击，就能把 Hugging Face 模型部署到托管 endpoint 上，运行在安全、可扩展的 Azure 基础设施中。

[![Hugging Face Model Catalog](https://huggingface.co/blog/assets/75_hugging_face_endpoints_on_azure/02.jpg)](https://huggingface.co/blog/assets/75_hugging_face_endpoints_on_azure/02.jpg)

这一新体验建立在我们去年宣布的战略伙伴关系之上——当时我们在 Azure Marketplace 中推出了作为新托管应用的 Azure Machine Learning Endpoints，以简化在 Azure 上部署大语言模型的体验。虽然之前的 marketplace 方案是很有前景的第一步，但它存在一些局限，只有通过 Azure Machine Learning 的原生集成才能克服。为了解决这些挑战并改善客户体验，我们与微软合作，在 Azure Machine Learning Studio 中为 Hugging Face 用户提供完全集成的体验。

Hugging Face [托管着超过 20 万个开源模型](https://huggingface.co/models)，每天模型下载量超过 100 万次，是机器学习领域的首选之地。但把 Transformers 部署到生产环境仍然是一个挑战。

开发者和组织面临的主要问题之一，是部署和扩展生产级推理 API 非常困难。最简单的选项当然是依赖云端 AI 服务。尽管它们极易使用，但这些服务通常只由有限的一组模型驱动，可能并不支持你需要的[任务类型](https://huggingface.co/tasks)，而且无法深度定制（或根本不能定制）。另一方面，云端 ML 服务或自建平台能给你完全的控制权，但代价是更多的时间、复杂度和成本。此外，许多公司有严格的安全、合规与隐私要求，规定他们只能在拥有管理控制权的基础设施上部署模型。

Hugging Face 首席布道师 Julien Simon 表示：「借助新的 Hugging Face Hub model catalog 与 Azure Machine Learning 的原生集成，我们与微软的合作翻开了新的一页：为企业客户提供极其简单的方式，在安全的 Azure 环境内部署 Hugging Face 模型进行实时推理。」

微软 Azure AI 平台企业副总裁 John Montgomery 表示：「将 Hugging Face 的开源模型集成进 Azure Machine Learning，体现了我们用业界领先的 AI 工具赋能开发者的承诺。这次合作不仅简化了大语言模型的部署流程，还提供了安全、可扩展的实时推理环境。这是我们使命中激动人心的一步：在 Azure 基础设施的支撑下，加速 AI 项目，把创新方案迅速而安全地带入市场。」

在 Azure Machine Learning 上部署 Hugging Face 模型从未如此简单：

- 在 Azure Machine Learning Studio 中打开 Hugging Face 注册表。
- 点击 Hugging Face Model Catalog。
- 按任务或许可证筛选并搜索模型。
- 点击模型磁贴打开模型页面，选择实时部署（real-time deployment）选项来部署模型。
- 选择 Azure 实例类型并点击部署。

[![Creating a Hugging Face Endpoint on Azure](https://huggingface.co/blog/assets/75_hugging_face_endpoints_on_azure/03.jpg)](https://huggingface.co/blog/assets/75_hugging_face_endpoints_on_azure/03.jpg)

几分钟内，你就可以测试你的 endpoint，并把它的推理 API 加入你的应用。就是这么简单！
