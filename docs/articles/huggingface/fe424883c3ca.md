# Falcon-Emirati：当 LLM 学会方言、文化与微妙之处

[![image](https://cdn-uploads.huggingface.co/production/uploads/659bc8a7b0f43ed69f0b2300/Wq7IUqy86uY6JcIpgCwJx.png)](https://cdn-uploads.huggingface.co/production/uploads/659bc8a7b0f43ed69f0b2300/Wq7IUqy86uY6JcIpgCwJx.png)

[试用 Falcon Emirati →](https://chat.falconllm.tii.ae/?model=Falcon-Emirati-7B)

阿拉伯语实际上是共用同一个名称的一整个语系。现代标准阿拉伯语（Modern Standard Arabic，MSA）是你在新闻或教科书里读到的那种，但它很少是人们日常交流时真正说的话。在阿联酋（UAE），日常对话、幽默、谈判和讲故事用的都是阿联酋阿拉伯语（Emirati Arabic），这是一种海湾方言，有自己的词汇、自己的节奏，还有紧紧包裹其周围的文化。阿联酋诗歌，尤其是纳巴蒂诗歌（nabati poetry），连同谚语和短小轶事，承载着无法通过逐字直译存活下来的含义。一个只懂 MSA 的模型，可以把一句阿联酋语逐词翻译出来，却仍然错过它真正表达的意思。

这正是 Falcon-Emirati-7B 要填补的缺口。它是一个在 Falcon-H1-Arabic 之上做方言专精的模型，目标是像母语者那样理解和生成阿联酋阿拉伯语：包括词汇、语气，以及背后的文化语境。

## 基于 Falcon-H1-Arabic 构建

我们并非从零开始。Falcon-Emirati-7B 构建在 Falcon-H1-Arabic 之上，那是我们的阿拉伯语模型家族，今年早些时候已经为这门语言树立了新的标杆。Falcon-H1-Arabic 采用 Falcon-H1 混合架构：状态空间模型（State Space Models，Mamba）与 Transformer 注意力在每个 block 内部并行运行，它们的输出在每个 block 的投影（projection）之前被融合。这种组合让它在长序列上享有 Mamba 的线性时间效率，同时保留了注意力机制对长程依赖的精确处理——这对阿拉伯语这样形态丰富的语言至关重要。该家族横跨三个规模（3B、7B 和 34B 参数），上下文窗口最高达 128K 和 256K tokens，并且已经在 MSA 与多种方言阿拉伯语（海湾、黎凡特、埃及、马格里布）连同英语及多语言数据的广泛混合体上完成训练。

这给了我们一个强大的起点：一个已经广泛理解阿拉伯语、能良好处理长上下文、并已内置一定方言接触经验的模型。Falcon-Emirati-7B 在这一基础上，专门向阿联酋方言推进——那些词汇、语法，以及文化常识，是再强的通用阿拉伯语模型也无法自行习得的。

我们专门选择 7B 这一变体来构建 Falcon-Emirati-7B。它是该家族中的最佳平衡点：足够大，能承载方言适配所需的微妙之处；又足够小，使训练和推理都保持切实可行。34B 模型或许能把质量再推高一点，但其训练和服务成本对于一款方言专精的对话模型来说并不划算；而 3B 模型没有为我们要追求的那种文化与语言理解的深度留足余量。7B 在质量与训练/推理成本之间给了我们最好的平衡。

## 为什么方言适配如此困难

把一个通用阿拉伯语模型变成阿联酋方言专精模型，听起来像是比构建底层基础模型更轻松的活儿。其实不然。几件事让它真正变得困难：

- **阿联酋语主要是一种口语方言。** 它在网上书面的出现频率远低于 MSA，甚至低于其他海湾和黎凡特方言，因此可供学习的原始文本本就没那么多。
- **含义往往不是字面的。** 习语、谚语和诗歌用典依赖的是共享的文化语境，而非表面词汇。
- **没有既定的操作手册。** 对于多少方言数据才算够、如何将其与 MSA 和通用阿拉伯语配比、以及哪个训练阶段（继续预训练、SFT 还是偏好优化）对方言习得起决定性作用，都没有一份记载清晰的配方。

最后这一点塑造了我们的工作方式。构建 Falcon-Emirati-7B 的很大一部分靠的是反复试错：测试不同的数据配比、训练阶段和监督策略，同时借助人工判断和基准分数来搞明白究竟什么才真正起到了作用。

## 我们对数据的处理方式

我们在 Falcon-H1-Arabic 预训练之上搭建了一条专用的阿联酋数据流水线，利用三类互补的数据源。

### 1. 真实的阿联酋方言网络数据

我们从阿联酋的网站和论坛抓取并整理了以该方言原生书写的内容，而非从 MSA 翻译或转写而来。这是我们获取事实依据（ground truth）的地方：阿联酋人在线上和线下实际如何书写和说话，日常的表达方式，口头俗语，以及真实使用中阿联酋语与 MSA 之间那种自然的来回切换。

### 2. 关于阿联酋文化与身份的 MSA 数据

除了方言文本，我们还引入了专门讲述阿联酋文化、传统和语言的 MSA 语料：关于本地习俗、价值观、历史和社会规范（包括外界如何看待和给阿联酋人贴标签）的文章和参考资料。这并不会教模型用方言书写，但它教会模型：当阿联酋话题被提及时，模型到底在谈些什么——诸如传统、礼仪，以及母语者天生就知道的那些背景。

### 3. 由词汇表和风格规则引导的合成数据

仅有真实的方言文本，并不足以覆盖一款对话模型日常实际需要处理的各类主题。于是我们生成了大量阿联酋方言的合成数据来填补空白。我们并没有让生成模型即兴用一种"海湾味"的阿拉伯语乱写。我们用严格规则、以及专为阿联酋词汇和语法构建的词汇表与词典来约束它。正是这些护栏，决定了合成输出究竟读起来是地道的阿联酋语，还是虽然语法无误、但在真正说这种方言的人听来却不对劲。

## 寻找合适的适配配方

既然 MSA 到方言的适配没有标准配方，我们就把训练策略本身当作一个要靠实验来搞明白的东西。我们针对以下问题做了消融实验：注入多少方言数据、在训练的哪个阶段注入，如何权衡真实抓取数据与合成数据以免模型过拟合到合成模式上，以及到底需要多少 MSA 文化语境才能让它真正扎根于文化、而不只是表面流畅。每一步我们都依赖自动评分与母语者评审的混合，因为仅靠自动指标无法充分刻画自然度、语气或文化契合度，不足以单独采信。

## 评测方法

我们在整个训练过程中用两种互补的方式追踪进展：

### 母语者人工评估

阿联酋母语者直接审阅模型输出，评判的不只是答案是否正确，还有它是否"听起来对"：自然度、语气、文化得体性。这些是基准分数不会告诉你、但母语者的耳朵一眼就能捕捉到的东西。

### 基于 Alyah 的自动评测

在定量追踪上，我们使用了 [**Alyah**](https://huggingface.co/datasets/tiiuae/alyah-emirati-benchmark)（الياه，意为"北极星"），这是我们的团队和社区专门发布、用于评测阿拉伯语 LLM 阿联酋方言能力的一个基准。Alyah 是一个完全原生的多选题基准，包含 1,173 个样本，由阿联酋母语者手工采集，覆盖从日常问候与礼仪，到修辞语言、传统知识，再到阿联酋诗歌等类别——正是方言与文化最为关键、通用阿拉伯语模型往往力不从心的那些类别。关于 Alyah 的构建与类别细分的完整细节见我们的 [基准博客文章](https://huggingface.co/blog/tiiuae/emirati-benchmarks)，关于底层模型家族的背景见 [Falcon-H1-Arabic 发布说明](https://huggingface.co/blog/tiiuae/falcon-h1-arabic)。

## 结果

Falcon-Emirati-7B 在 Alyah 上取得 **84.83%**，领先于我们与之对比的所有其他阿拉伯语和多语言模型，其中包括若干个体量数倍于它的模型。下面的图表展示了它在 Alyah 排行榜上、与一组具有代表性的领先指令微调模型相比所处的位置。

*Alyah 准确率（%），指令微调模型。由于 Falcon-Emirati-7B 构建于 Falcon-H1-Arabic 家族之上，该家族的模型被排除在本次对比之外。*

## 结果告诉我们什么

从这组对比中有几点尤其显眼。仅凭规模并不能换来方言能力。这里一些最大的多语言模型得分明显低于更小、对方言更敏感的模型，这告诉你阿联酋语能力必须刻意去训练，而不是靠规模顺带获得的副产品。表现最好的模型往往本身就是阿拉伯语原生或以阿拉伯语为重点的，这与我们自己在消融实验中看到的一致：通用的阿拉伯语与方言覆盖是一个必要的起点，但要弥合剩下的差距，仍然需要针对性的、方言专项的工作，尤其是在 Alyah 最难的部分——比如诗歌、传统知识，以及语言与方言这一类别本身。

这也与 Alyah 基准发布所揭示的更广泛结论相符：一旦进入真正的方言化、深深植根于文化的内容，即便是强模型也会出现明显的性能退化。这个差距不会随着模型变大就自行弥合，它需要专门为该方言构建的数据和评测。

## 超越多选题：LLM 作为评审（LLM-as-Judge）评测

多选题准确率告诉你的是：模型能否在四个选项中识别出正确答案。它并不能告诉你：当有人直接和它说话时，模型是否会自己真正产出阿联酋阿拉伯语。所以在 Alyah 之外，我们做了第二轮评测：在同一批 1,173 个 Alyah 问题上进行开放式生成，由一个 LLM 评审（Gemini 3.7 Flash）针对五个模型打分——Falcon-Emirati-7B、ALLaM-7B-Instruct-preview、gemma-3-27b-it、Jais-2-8B-Chat 和 Fanar-2-27B-Instruct，它们是从 Alyah 排行榜上挑选出的最强竞争对手。

评审从两个独立维度为每个答案打分：内容是否正确，以及（相互独立地）答案是否真的以阿联酋方言而非 MSA 给出。我们同时报告一个部分得分版本（评审的分级评估）和一个更严格的通过/失败版本，外加每个模型拒答（不作答）的频率。

*在同一批问题上由 LLM 评审判定的方言保真度：答案究竟是真正以阿联酋语给出，还是模型默认退回 MSA？*

Falcon-Emirati-7B 在正确性上领先，但真正的差距体现在第二张图。在方言保真度上，Falcon-Emirati-7B 得 0.52（部分得分），而 ALLaM 为 0.05、gemma-3-27b-it 为 0.03、Jais-2-8B-Chat 为 0.02、Fanar-2-27B-Instruct 实际上为 0.00。这不是一个小优势，在低端它接近两个数量级。实际意味着：其他模型往往知道正确答案，但默认用现代标准阿拉伯语说出来，即便有人直接用阿联酋语问它。Falcon-Emirati-7B 是这五个中唯一一个能稳定地以被提问时所用的方言作答的模型。

Fanar-2-27B-Instruct 因第二个原因同样引人注目：它比其他任何模型都更频繁地拒答，26.2% 的情况下拒绝作答，而对比组中其余每个模型都低于 5%。再加上它 0.27（部分得分）的正确性——五个里最低——这描绘出一个既不愿、也不能就阿联酋专属内容进行应答的模型，而不只是一个用了错误语域的模型。

[![Dialect fidelity by category](https://cdn-uploads.huggingface.co/production/uploads/659bc8a7b0f43ed69f0b2300/sklbQUT3s8CXmcse-BPln.png)](https://cdn-uploads.huggingface.co/production/uploads/659bc8a7b0f43ed69f0b2300/sklbQUT3s8CXmcse-BPln.png)

*按 Alyah 类别划分的方言保真度，部分得分。Falcon-Emirati-7B 是唯一一个稳定切换到阿联酋语的模型；其余模型在几乎所有类别里都停留在 MSA。*

把方言保真度按类别拆开，这一规律就更清楚了。它在 Alyah 的每一个类别里都成立，从日常问候到诗歌，这说明它不是为某几类问题学来的一个小把戏，而是模型在阿联酋语作为预期语域时默认转向何种语域的一次整体转变。竞争对手模型表现相对较好的唯一一处——问候与日常用语——也正是阿联酋语与 MSA 重叠最多的类别，所以它是最容易让一个通用阿拉伯语模型碰巧听起来正确无比的地方。

### 逐类别的两两对比

作为审视同一问题的第三个视角，我们做了面对面的两两评审：对每个 Alyah 问题，评审（Gemini 3.7 Flash）会同时看到 Falcon-Emirati-7B 的答案和一个竞争对手模型的答案（不知道哪个是哪个），并被要求挑出更好的那一个。下面的雷达图展示了按类别得到的、针对三个竞争对手模型——Jais-2-8B-Chat、ALLaM-7B-Instruct-preview 和 Fanar-2-27B-Instruct——的胜率。

[![pairwise_combined](https://cdn-uploads.huggingface.co/production/uploads/659bc8a7b0f43ed69f0b2300/ruWwB7xCdfiETIgD4wmyy.png)](https://cdn-uploads.huggingface.co/production/uploads/659bc8a7b0f43ed69f0b2300/ruWwB7xCdfiETIgD4wmyy.png)

*按类别的两两胜率，Falcon-Emirati-7B 对阵 Jais-2-8B-Chat、ALLaM-7B-Instruct-preview 和 Fanar-2-27B-Instruct，由 Gemini 3.7 面对面评审。*

Falcon-Emirati-7B 在三个对手面前都赢下了多数类别，在最依赖方言与文化流畅度的类别里更是以悬殊优势取胜。对阵 Jais-2-8B-Chat，差距最大的是诗歌与创意表达（0.69 对 0.31）和语言与方言（0.62 对 0.38）。对阵 ALLaM-7B-Instruct-preview，同样是这两个类别差距最大：诗歌与创意表达（0.66 对 0.34）和语言与方言（0.58 对 0.42）。对阵 Fanar-2-27B-Instruct，差距是三者对决中最宽的，且 Falcon-Emirati-7B 赢下每一个类别，在诗歌与创意表达（0.88 对 0.12）以及宗教与社交敏感度（0.80 对 0.20）上达到顶点。

竞争对手模型能稳住阵脚的唯一类别是问候与日常用语：Falcon-Emirati-7B 以微弱劣势输给 Jais-2-8B-Chat（0.46 对 0.54），与 ALLaM-7B-Instruct-preview 打成 0.50 平手，但对阵 Fanar-2-27B-Instruct 仍以明显优势取胜（0.70 对 0.30）。这与上面方言保真度细分所呈现的结论大体一致——问候是阿联酋语与 MSA 重叠最多的类别，所以它是最容易让通用阿拉伯语模型即便没有专门方言训练也听起来像母语者的地方。在方言更鲜明的各处——诗歌、修辞语言、传统知识——Falcon-Emirati-7B 的优势在我们测试过的每一个竞争对手模型面前都稳固成立。

## 理解阿联酋文化

语言也关乎理解对话背后的文化。我们在 [ArabCulture-Dialogue](https://huggingface.co/datasets/Almheiri/ArabCulture-Dialogue) 的阿联酋部分上评测了 Falcon-Emirati-7B，那是一个用于阿拉伯语文化理解的基准。在其多选题任务中，模型要从三个选项里选出在文化上最得体的回应。更多内容见 [研究论文](https://aclanthology.org/2026.acl-long.963/)。

我们在同样这 **283 个阿联酋场景**上测试了全部四个模型，分别用阿联酋阿拉伯语和现代标准阿拉伯语，并配以不同程度的位置信息。

[![Cultural understanding accuracy: Falcon-Emirati-7B 85.57%, ALLaM 83.39%, Jais-2 73.79%, Fanar-2 71.50%.](https://cdn-uploads.huggingface.co/production/uploads/65b79f63d919aa79555d17e1/78dgJaRrFACpGTBJkSuTE.png)](https://cdn-uploads.huggingface.co/production/uploads/65b79f63d919aa79555d17e1/78dgJaRrFACpGTBJkSuTE.png)

*阿联酋多选题任务上的总体准确率，在两种语言变体和所有位置设置上取平均。这些是我们的评测结果。*

**Falcon-Emirati-7B 得 85.57%，为四个被测模型中最高**，领先于 ALLaM-7B（83.39%）、Jais-2-8B（73.79%）和 Fanar-2-27B（71.50%）。这些结果凸显了它在阿联酋对话中识别文化得体回应的能力。

## 负责任的 AI 与局限

和任何语言模型一样，Falcon-Emirati-7B 会反映其训练数据中的偏见，有时会出错，尤其是在罕见表达、高度本地化的指涉，或我们数据很少的边缘情况上。方言与文化微妙之处在某些地方是主观的，即便是母语者，也未必总在"正确"答案上达成一致。我们建议在你自己的具体用例上先评估模型，再把它用于任何敏感、官方或高风险的场景；我们也诚挚欢迎来自阿联酋社区的反馈，帮助我们持续改进模型和 Alyah。
