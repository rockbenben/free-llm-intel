# Gradio 加入 Hugging Face！

*Gradio 加入 Hugging Face！通过收购机器学习初创公司 Gradio，Hugging Face 将能够为用户、开发者和数据科学家提供所需工具，以取得高水平成果，创造更好的模型和工具……*

嗯，上面这种关于收购的段落实在太常见了，以至于算法都能写出来。事实上，真有一个算法写了！！这第一段是用 [Acquisition Post Generator](https://huggingface.co/spaces/abidlabs/The-Acquisition-Post-Generator) 生成的——这是 **Hugging Face Spaces** 上的一个机器学习 demo。你也可以在浏览器里自己运行：给出任意两家公司的名字，你就能得到一篇宣布它们收购传闻文章的合理开头！

Acquisition Post Generator 就是用我们的开源库 Gradio 构建的——这只是我们近期与 Hugging Face 的多次合作之一。而我兴奋地宣布，这些合作正迎来一个里程碑：🥁 **Hugging Face 收购 Gradio**（是的，第一段虽然可能是算法写的，但它是真的！）

作为 Gradio 的创始人之一，我对我们旅程的下一步感到无比兴奋。我仍清晰地记得 2019 年我们是如何开始的：作为斯坦福的博士生，我很难把一个医学计算机视觉模型分享给我的合作者——一位医生。我需要他测试我的机器学习模型，但他不懂 Python，也无法轻松地在自己的图像上运行模型。我设想了一种工具，能让机器学习工程师极其简单地构建并分享计算机视觉模型的 demo，从而带来更好的反馈和更可靠的模型 🔁

我召集了我才华横溢的室友 Ali Abdalla、Ali Abid 和 Dawood Khan，在 2019 年发布了 Gradio 的第一个版本。我们稳步扩展，覆盖机器学习的更多领域，包括文本、语音和视频。我们发现，需要分享机器学习模型的不只是研究者：产业界的跨学科团队——从初创公司到上市公司——都在构建模型，需要在内部调试或对外展示它们，Gradio 两者都能帮上忙。自我们首次发布这个库以来，大家已经用 Gradio 构建了超过 30 万个 demo。没有贡献者社区、没有支持我们的投资人，没有今年加入我们团队的出色的 Ahsen Khaliq，这一切都不可能实现。

用 Gradio 构建的 demo 和 GUI 正在把机器学习的力量交给越来越多的人，因为它们让非技术用户也能访问、使用模型并给出反馈。而 Hugging Face 对我们的收购，是这条「无障碍化」道路上的下一步。Hugging Face 已经彻底推动了机器学习民主化，让任何软件工程师都能用几行代码使用最先进模型。与 Hugging Face 携手，我们要把这件事推得更远，让任何有网络接入和浏览器的人都能用上机器学习。有了 Hugging Face，我们将继续发展 Gradio，把它变成与任何人、在任何地方分享你的机器学习模型的最佳方式 🚀

除了 Gradio 与 Hugging Face 共同使命感之外，让我欣喜的还有我们将加入的这个团队。Hugging Face 卓越的开放与创新文化广为人知。过去几个月里，我也了解了它的创始人们：他们是极好的人，真心关怀 Hugging Face 的每一个人，并愿意为他们挺身而出。代表整个 Gradio 团队，没有比这更让我们激动的了——我们将与他们一起共建机器学习的未来 🤗
