Gradio 是一个用于创建交互式机器学习应用的流行 Python 库。传统上，Gradio 应用依赖服务器端基础设施运行，这对需要托管应用的开发者来说是一道门槛。

于是 Gradio-lite（`@gradio/lite`）登场了：这个库借助 [Pyodide](https://pyodide.org/en/stable/)，把 Gradio 直接带进浏览器。在这篇博文中，我们将探索 `@gradio/lite` 是什么、过一遍示例代码，并讨论它为运行 Gradio 应用带来的好处。

## `@gradio/lite` 是什么？

`@gradio/lite` 是一个 JavaScript 库，让你能在浏览器内直接运行 Gradio 应用。它通过 Pyodide（一个基于 WebAssembly 的 Python 运行时）实现这一点，使 Python 代码可以在浏览器环境中执行。有了 `@gradio/lite`，你可以**为 Gradio 应用编写普通 Python 代码**，它们将**在浏览器中无缝运行**，无需服务器端基础设施。

## 快速上手

我们来用 `@gradio/lite` 做一个 "Hello World" Gradio 应用。

### 1. 引入 JS 和 CSS

首先新建一个 HTML 文件（如果还没有的话）。用以下代码引入 `@gradio/lite` 包对应的 JavaScript 和 CSS：

```
<html>
    <head>
        <script type="module" crossorigin src="https://cdn.jsdelivr.net/npm/@gradio/lite/dist/lite.js"></script>
        <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@gradio/lite/dist/lite.css" />
    </head>
</html>
```

注意，你一般应使用最新可用的 `@gradio/lite` 版本。[可用版本在这里查看](https://www.jsdelivr.com/package/npm/@gradio/lite?tab=files)。

### 2. 创建 `<gradio-lite>` 标签

在 HTML 页面 body 的某个位置（你希望渲染 Gradio 应用的地方），创建一对开闭的 `<gradio-lite>` 标签。

```
<html>
    <head>
        <script type="module" crossorigin src="https://cdn.jsdelivr.net/npm/@gradio/lite/dist/lite.js"></script>
        <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@gradio/lite/dist/lite.css" />
    </head>
    <body>
        <gradio-lite>
        </gradio-lite>
    </body>
</html>
```

注意：可以给 `<gradio-lite>` 标签加 `theme` 属性，强制使用深色或浅色主题（默认遵循系统主题）。例如：

```
<gradio-lite theme="dark">
...
</gradio-lite>
```

### 3. 在标签内编写你的 Gradio 应用

现在，照常编写你的 Gradio 应用，用 Python！记住 Python 中空格与缩进是有意义的。

```
<html>
    <head>
        <script type="module" crossorigin src="https://cdn.jsdelivr.net/npm/@gradio/lite/dist/lite.js"></script>
        <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@gradio/lite/dist/lite.css" />
    </head>
    <body>
        <gradio-lite>
        import gradio as gr

        def greet(name):
            return "Hello, " + name + "!"
        
        gr.Interface(greet, "textbox", "textbox").launch()
        </gradio-lite>
    </body>
</html>
```

就这么简单！现在用浏览器打开这个 HTML 页面，就能看到渲染出的 Gradio 应用！注意初次加载可能稍慢，因为 Pyodide 在浏览器中安装需要一些时间。

**调试说明**：要查看 Gradio-lite 应用的错误，请打开浏览器的开发者检查器。所有错误（包括 Python 错误）都会打印在那里。

## 更多示例：添加额外文件与依赖

如果你想创建一个跨多文件的 Gradio 应用怎么办？或者有自定义 Python 依赖？`@gradio/lite` 两者都能做到！

### 多文件

在 `@gradio/lite` 应用里添加多个文件非常直接：使用 `<gradio-file>` 标签。你可以用任意多个 `<gradio-file>` 标签，但每个都必须带 `name` 属性，而你 Gradio 应用的入口文件应带 `entrypoint` 属性。

示例如下：

```
<gradio-lite>

<gradio-file name="app.py" entrypoint>
import gradio as gr
from utils import add

demo = gr.Interface(fn=add, inputs=["number", "number"], outputs="number")

demo.launch()
</gradio-file>

<gradio-file name="utils.py" >
def add(a, b):
    return a + b
</gradio-file>

</gradio-lite>		
```

### 额外依赖

如果你的 Gradio 应用还有别的依赖，通常可以[用 micropip 在浏览器中安装它们](https://pyodide.org/en/stable/usage/loading-packages.html#loading-packages)。我们做了一个封装让这件事格外方便：只需按 `requirements.txt` 的语法列出依赖，并用 `<gradio-requirements>` 标签包起来。

下面这里安装了 `transformers_js_py`，以便直接在浏览器中运行文本分类模型！

```
<gradio-lite>

<gradio-requirements>
transformers_js_py
</gradio-requirements>

<gradio-file name="app.py" entrypoint>
from transformers_js import import_transformers_js
import gradio as gr

transformers = await import_transformers_js()
pipeline = transformers.pipeline
pipe = await pipeline('sentiment-analysis')

async def classify(text):
    return await pipe(text)

demo = gr.Interface(classify, "textbox", "json")
demo.launch()
</gradio-file>

</gradio-lite>	
```

**试一试**：你可以在[这个 Hugging Face Static Space](https://huggingface.co/spaces/abidlabs/gradio-lite-classify) 中看到该示例运行——Static Space 可以免费托管静态（无服务器）Web 应用。访问页面后，你将能在没有网络的情况下运行机器学习模型！

## 使用 `@gradio/lite` 的好处

### 1. 无服务器部署

@gradio/lite 的首要优势是消除了对服务器基础设施的需求。这简化了部署、降低了服务器相关成本，也让分享你的 Gradio 应用更容易。

### 2. 低延迟

在浏览器中运行，使 @gradio/lite 为用户提供低延迟交互。数据无需在服务器间往返，响应更快、体验更顺滑。

### 3. 隐私与安全

由于所有处理都发生在用户浏览器内，`@gradio/lite` 提升了隐私与安全性。用户数据留在他们自己的设备上，让人对数据处理更安心。

### 局限

- 目前使用 `@gradio/lite` 最大的局限是：Gradio 应用初次在浏览器中加载通常需要更长时间（一般 5-15 秒）。因为浏览器需要先加载 Pyodide 运行时才能执行 Python 代码。
- 并非每个 Python 包都受 Pyodide 支持。虽然 `gradio` 和许多其他流行包（包括 `numpy`、`scikit-learn`、`transformers-js`）可以在 Pyodide 中安装，但如果你的应用依赖很多，值得检查这些依赖是否包含在 Pyodide 中、或能否[用 `micropip` 安装](https://micropip.pyodide.org/en/v0.2.2/project/api.html#micropip.install)。
