## Granite Speech 5.0 2B：更准确、更稳健、更可控

`granite-speech-5.0-2b` 是参数数量相同的 `granite-speech-4.1-2b` 的后继版本。它可以转录英语、法语、德语、西班牙语、葡萄牙语和日语，并进行这些语言的英语互译，以及英语到意大利语和普通话的翻译。它接受了 390,000 小时的公共音频以及为日语 ASR、关键词偏差和翻译构建的合成数据的训练。

与 4.1 2B Speech 相比的新增内容：

- **更准确、更稳健的英语 ASR：** 英语短格式基准的准确性更高，并且更好地处理噪音、混响和远处麦克风语音。
- **语言 ID 提示：** 在提示中命名输入语言以引导多语言转录。
- **更好的长篇翻译和会话翻译：** 翻译可以通过更自然的语音而保持更长时间，而不仅仅是短读句子。
- **关键字最多列出 2,000 个术语：** 在每种受支持的语言中，对产品名称、人物和首字母缩略词进行偏向转录和翻译。
- **根据要求标点和大写：** 在提示中要求格式化输出；在我们的测试集中，大写 F1 的范围为 89.7 到 99.5。

该模型在 Apache 2.0 下发布，支持 Transformers、vLLM、llama.cpp 和 Apple Silicon 的 mlx-audio。

## Granite Speech 5.0 Turbo CTC：现在支持多种语言，更强大，甚至更快

当我们在 8 月份推出 Turbo CTC 时（https://huggingface.co/blog/ibm-granite/granite-speech-5-0-470m-turboctc），它是一个专为速度而构建的纯英语、470M 参数编码器。此版本保留了这一足迹，并添加了用户最需要的三件事：

- **多语言转录：** 英语、日语、西班牙语、德语、法语、意大利语和葡萄牙语。
- **原生标点符号和大写：** 文本可供阅读，无需单独的标点符号或大写步骤。
- **在困难的声学环境中更加稳健：** 明确针对混响音频的训练使 Turbo CTC 在回声室和远场录音中更加稳健。

它也更快。通过编译单个 Conformer 块并在整个堆栈中重用其图，我们缩短了预热时间，并将 Turbo CTC 在 Open ASR 排行榜上推至 19,870 RTFx，高于发布时的约 12,600 RTFx：在相同的精度水平下，速度提高了约 1.6 倍。

*图 2：Open ASR 排行榜上的平均 WER 与 RTFx（英文简写，9 个公开测试集，截至 2026 年 10 月）。 WER 越低，RTFx 越高越好； RTFx 采用对数刻度。*

## Granite Speech 4.1 2B Plus：更擅长谁在何时说什么

更新后的“granite-speech-4.1-2b-plus”针对企业实际拥有的录音进行了调整：会议、支持电话以及对几位演讲者的长时间采访。它保留了 4.1 的名称，因为架构、提示格式和 API 都没有改变，因此它是当前模型的直接替代品，并改进了权重。此次修订改进了四个方面：

- **发言者归属：**更准确地标记发言者。单词分类错误率 (WDER) 下降了 7%，说话者归因的 WER (cpWER) 总体下降了 7%。
- **时间戳：** 平均时间戳偏移 (AAS) 减少一半以上，从而在字幕、搜索和审阅方面产生更严格的时间安排。
- **长语音性能：** 长格式测试集的 WER 下降 24%。
- **关键字偏差：** 20 个术语的关键字列表中，偏差关键字的错误下降了 45%。

## 开始吧

不确定选择哪个型号？从这里开始：

- **需要高转录准确性、翻译或关键字偏差？** 使用 [granite-speech-5.0-2b](https://huggingface.co/ibm-granite/granite-speech-5.0-2b)。
- **需要原始速度或设备上转录？** 使用 [granite-speech-5.0-470m-turboctc](https://huggingface.co/ibm-granite/granite-speech-5.0-470m-turboctc)，并在浏览器中使用我们的 [WebGPU 流演示](https://huggingface.co/blog/ibm-granite/DEMO_URL) 进行尝试。
- **处理会议或多发言者通话？** 使用 [granite-speech-4.1-2b-plus](https://huggingface.co/ibm-granite/granite-speech-4.1-2b-plus)。

这些模型均在 Apache 2.0 许可下发布，并在 Transformers 中提供本机支持。每个模型卡上都有完整的评估结果、架构详细信息、训练数据和使用示例。我们建议将它们与 [Granite Guardian](https://huggingface.co/collections/ibm-granite/granite-guardian) 配对，以进行需要额外风险检测的生产部署。

尝试一下，让我们知道您的想法！
