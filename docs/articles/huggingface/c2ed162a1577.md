## Granite Speech 5.0 2B：更准确、更稳健、更多控制

`granite-speech-5.0-2b` 是 `granite-speech-4.1-2b` 在相同参数量下的后继者。它可以转写英语、法语、德语、西班牙语、葡萄牙语和日语，并在这些语言之间与英语互译，另外还支持英语到意大利语和普通话的翻译。它在 390,000 小时的公开音频上训练，并加入了为日语 ASR、关键词偏置和翻译构建的合成数据。

与 4.1 2B Speech 相比的新变化：

- **更准确、更稳健的英语 ASR：** 在英语短音频基准上准确率更高，对噪声、混响和远场麦克风语音的处理更好。
- **Language ID prompting：** 在 prompt 中指定输入语言，以引导多语言转写。
- **更好的长音频与对话式翻译：** 面对更长、更自然的语音（而不只是简短朗读的句子），翻译也能维持质量。
- **最多 2,000 个词条的关键词列表：** 在所有支持的语言中，把转写和翻译偏向产品名、人名和缩写。
- **按需输出标点与大小写：** 在 prompt 中要求格式化输出；在我们的各测试集上，大小写 F1 介于 89.7 到 99.5 之间。

该模型以 Apache 2.0 许可发布，支持 Transformers、vLLM、llama.cpp，以及在 Apple Silicon 上通过 mlx-audio 使用。

## Granite Speech 5.0 Turbo CTC：现已多语言、更稳健，而且更快

我们在[八月推出 Turbo CTC](https://huggingface.co/blog/ibm-granite/granite-speech-5-0-470m-turboctc) 时，它是一个仅支持英语、为速度而生的 470M 参数编码器。这次修订保持同样的体量，并加入了用户最想要的三件事：

- **多语言转写：** 英语、日语、西班牙语、德语、法语、意大利语和葡萄牙语。
- **原生标点与大小写：** 转写结果开箱即可阅读，无需单独的标点或大小写恢复步骤。
- **在困难声学条件下更稳健：** 明确针对混响音频的训练，让 Turbo CTC 在回声较强的房间和远场录音中更稳健。

它也更快了。通过把单个 Conformer block 编译一次并在整个堆栈中复用其计算图，我们缩短了 warmup 时间，把 Turbo CTC 在 Open ASR Leaderboard 上的成绩推到 19,870 RTFx，而发布时约为 12,600 RTFx：在同等准确率水平下，大约快了 1.6 倍。

*图 2：Open ASR Leaderboard 上的平均 WER 与 RTFx（英语短音频，9 个公开测试集，截至 2026 年 10 月）。WER 越低、RTFx 越高越好；RTFx 为对数刻度。*

## Granite Speech 4.1 2B Plus：更清楚谁说了什么、什么时候说的

更新后的 `granite-speech-4.1-2b-plus` 针对企业实际拥有的录音做了调优：会议、客服通话，以及多位说话人持续很久的访谈。它保留 4.1 这个名字，是因为架构、prompt 格式和 API 都没有变化，所以它是当前模型的直接替换，只是权重更好。本次修订改进了四个方面：

- **说话人归属：** 对谁说谁的标注更准确。词级分离错误率（WDER）下降 7%，带说话人归属的 WER（cpWER）整体下降 7%。
- **时间戳：** 平均时间戳偏移（AAS）减少一半以上，让字幕、搜索和复核中的时间更紧凑。
- **长音频表现：** 长音频测试集上的 WER 下降 24%。
- **关键词偏置：** 使用 20 词条的关键词列表时，被偏置关键词的错误率下降 45%。

| 能力 | 指标 | 上一版本 | 更新后的模型 |
| --- | --- | --- | --- |
| 时间戳，全部语音 | AAS（平均时间戳偏移） | 210.86 | **98.54** |
| 时间戳，短语音 | AAS（平均时间戳偏移） | 29.27 | **26.20** |
| 关键词偏置 | 偏置词 WER，20 词条列表 | 11.79 | **6.48** |
| 长音频语音 | WER，长音频测试集 | 13.53 | **10.22** |
| 说话人归属 | WDER | 4.40 | **4.10** |
| 带说话人归属的转写 | cpWER | 30.50 | **28.48** |

*表 1：所有指标都是错误率，因此越低越好。更详细的结果见[模型卡](https://huggingface.co/ibm-granite/granite-speech-4.1-2b-plus)。*

## 开始使用

不确定该选哪个模型？从这里开始：

- **需要高转写准确率、翻译或关键词偏置？** 使用 [granite-speech-5.0-2b](https://huggingface.co/ibm-granite/granite-speech-5.0-2b)。
- **需要极致速度或端侧转写？** 使用 [granite-speech-5.0-470m-turboctc](https://huggingface.co/ibm-granite/granite-speech-5.0-470m-turboctc)，并可在浏览器中试用我们的 [WebGPU 流式 demo](https://huggingface.co/blog/ibm-granite/DEMO_URL)。
- **要处理会议或多说话人通话？** 使用 [granite-speech-4.1-2b-plus](https://huggingface.co/ibm-granite/granite-speech-4.1-2b-plus)。

这些模型都以 Apache 2.0 许可发布，并在 Transformers 中提供原生支持。完整的评测结果、架构细节、训练数据和使用示例都在各自的模型卡上。对于需要额外风险检测的生产部署，我们建议把它们与 [Granite Guardian](https://huggingface.co/collections/ibm-granite/granite-guardian) 搭配使用。

不妨试一试，并告诉我们你的想法！
