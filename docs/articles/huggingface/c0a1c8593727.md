我们很高兴发布 Holotron-12B——来自 H Company 的多模态 computer-use 模型。Holotron-12B 基于开放的 NVIDIA Nemotron-Nano-2 VL 模型，在 H Company 的专有数据配比上做后训练，是我们研究实验室紧密协作的成果，旨在打造一种主要为生产环境下的规模与性能而优化的新型模型。

H Company 是 NVIDIA Inception 计划的一员。

模型现已可在 Hugging Face 上获取。

# 我们为什么打造 Holotron-12B

如今多数多模态模型主要优化的是静态视觉或指令遵循。而 Holotron-12B 与我们的 Holo2 模型一样，目标不同：作为 computer-use 智能体的策略模型，必须在交互式环境中高效地感知、决策和行动。

通过 Holotron-12B，我们想创造一个能在生产环境中高效、有效扩展的模型——能处理含多图长上下文、同时在 agent 基准上保持良好表现。NVIDIA Nemotron 模型在推理侧提供了坚实的基础，而开发 Holotron-12B 让我们看到，经过进一步训练这个模型还能完成多得多的事情。

## 用混合 SSM 架构实现高吞吐推理

Holotron-12B 推理效率的大幅跃升，得益于其底层的 Nemotron 架构——它采用混合 State-Space Model（SSM）与注意力机制。与纯 transformer 模型不同，这一设计为高吞吐 serving 而优化。状态空间模型避免了完整注意力机制的二次计算成本，为长上下文推理提供更优的可扩展性，尤其惠及涉及多图、长交互历史的 agentic 工作负载。就推理而言，SSM 的主要贡献是显著缩小的内存占用：vanilla attention 要为每个 token、每层存储 K 和 V 激活（即臭名昭著的 KV Cache），而 SSM 是线性循环模型，每层每条生成序列只存储一个常数状态，与序列长度无关。

在 WebVoyager Benchmark 上评测时，该模型在一个真实世界多模态 agentic 工作负载上表现出色：长上下文、多张高分辨率图像、以及 100 个 benchmark worker 的高请求并发。在单块 H100 GPU 上运行、使用带最新 SSM 优化（v0.14.1）的 vLLM，Holotron-12B 相比 Holo2-8B 实现了超过 2 倍的吞吐量。这使 Holotron-12B 成为吞吐受限工作负载的诱人选择，例如数据生成、标注和在线强化学习。

在一个受控实验设置中（见图 2），随着并发升高，Holotron-12B 仍在高效扩展：总 token 吞吐量稳定上升，在最大并发 100 时达到 8.9k tokens/s。相比之下，Holo2-8B 的总 token 吞吐在 5.1k tokens/s 处更快见顶。这一行为凸显了 Nemotron 架构的关键优势——更有效、更高效的 VRAM 利用和更小的总体内存占用，让同样的硬件可以支撑大得多的有效 batch size。即便在大 batch size 下，Holotron-12B 仍保持强劲吞吐。

## 训练与评估 Holotron-12B

Holotron-12B 分两个阶段训练。我们从 Nemotron-Nano-12B-v2-VL-BF16——NVIDIA 发布的多模态基座模型——出发，然后在 H Company 专有的 localization 与 navigation 数据配比上做监督微调，聚焦屏幕理解、grounding 和 UI 级交互。

最终 checkpoint 在约 140 亿 token 上训练。

## Agent 基准

在 computer-use 与导航基准上，Holotron-12B 相对 Nemotron 基座模型显示出显著改进，并与成熟的 agent 模型并驾齐驱。其 WebVoyager 性能从 35.1% 提升到 80.5%，超过 Holo2-8B 在该基准上的表现，展示了模型在 agentic 设置下的有效工作能力。

## Localization 基准

在 OS-World-G、GroundUI、WebClick 等 localization 与 grounding 基准上，Holotron-12B 相对 Nemotron 基座模型也有实质提升。

# 结论

Holotron-12B 证明：配合正确的训练设置与基础设施工作，NVIDIA Nemotron VL 模型为真实世界的多模态智能体提供了坚实基础。

该模型提供强劲的 agent 性能、显著改善的推理吞吐，以及一条清晰的未来改进路径——尤其在更高分辨率的视觉训练方面。

我们期待看到其他人用 Holotron-12B 构建什么。模型与 checkpoints 现已在 Hugging Face 上提供，采用 NVIDIA Open Model License。

# 下一步：用 Nemotron 3 Omni 扩展 agentic 智能的未来

NVIDIA 今日宣布发布 Nemotron 3 Omni。在 Holotron-12B 成功的基础上，我们正在准备对这一代多模态模型进行后训练。借助 Nemotron 3 家族增强的混合 SSM-Attention 与 MoE 架构基础，我们目标是随着新发布的 Nemotron 3 Omni，在推理能力与多模态精度上实现更大跃升。随着这一演进把 Holotron 从研究推向商业应用，它为企业带来的高吞吐、低延迟性能，正是大规模自主「computer use」部署所要求的。
