在这篇博文中，我们介绍 Falcon-Edge 系列的关键亮点与设计理由——一套基于 BitNet 架构、以三值（ternary）格式提供的强大、通用、可微调语言模型。

汲取我们在 BitNet 上的经验，Falcon-Edge 引入并验证了一种新的预训练范式：单次训练流程即可产出全谱输出，同时得到非量化与量化两种模型变体。这一完整方案产出三种模型：bfloat16 格式的非 BitNet 模型、原生 BitNet 模型，以及一个专为轻松微调设计的预量化 BitNet 变体——让用户与开发者能精确地把这些模型调适到自己的具体应用与需求。

Falcon-Edge 现有两种规模——10 亿与 30 亿参数——每种规模都有 base 与指令微调两个版本。可在[我们的专属 Hugging Face 合集](https://huggingface.co/collections/tiiuae/falcon-edge-series-6804fd13344d6d8a8fa71130)中探索 Falcon-Edge 系列。

## 引言

大语言模型（LLM）在设计上天然庞大、资源密集。随着在边缘设备上高效部署这些模型的需求增长，模型压缩研究不断加速。近期的工作，如 DeepSeek 与 Llama 4，尝试用更低精度的格式（低至 FP8）训练以改善部署扩展性。另一方面，许多最先进方法强调训练后量化。与这些路径不同，BitNet 引入了一种根本不同的范式：降低精度训练仍依赖浮点格式，训练后量化是在全精度训练后调整权重，而 BitNet 直接以可能的最低精度——三值权重（{-1, 0, 1}）——在训练期间运作，实现端到端的超高效模型设计。

这些三值权重正在为一种「无 matmul」的 LLM 设计铺路，其在实践中显著更快、极其省内存。这一创新路径的主要挑战在于 BitNet 模型需要预训练，对普通用户而言计算量大且昂贵。

## Falcon-Edge，一系列通用的模型

更仔细地看推理时 BitNet 线性层的公式（用 Python 代码表示）：

```
def activation_norm_quant(x):
    scale = 127.0 / x.abs().max(dim=-1, keepdim=True).values.clamp_(min=1e-5)
    y = (x * scale).round().clamp_(-128, 127)
    return y, scale

class BitLinear(nn.Linear):
    
    def post_quant_process(self, input, input_scale, weight_scale):
        out = input / (input_scale * weight_scale)
        return out

    def forward(self, input):
        w = self.weight
        w_quant = unpack_weights(w, dtype=self.dtype)
        input_quant, input_scale = self.activation_quant(input)
        y = F.linear(input_quant.to(self.dtype), w_quant)
        y = self.post_quant_process(y, self.weight_scale, input_scale)
        if self.bias is not None:
            y += self.bias.view(1, -1).expand_as(y)
        return y
```

归一化 activation_norm_quant 以 int8 格式量化激活值，然后通过除以 x_scale 以半精度把激活值算回来。由于模型是在「假 8-bit 激活量化」下训练的，我们认为可以近似：

```
x_quant, x_scale = activation_norm_quant(x)
x ~= (x_quant / x_scale)
```

因此，与其在训练后量化模型，不如在量化权重之后注入权重 scale，从而得到模型非 BitNet 版本足够好的「近似」：

```
def _weight_quant(w):
    scale = 1.0 / w.abs().mean().clamp_(min=1e-05)
    u = (w * scale).round().clamp_(-1, 1)
    return u, scale

for param_name, param_value in state_dict.items():
    if _is_param_to_not_quantize(param_name):
        continue

    param_value, param_scale = _weight_quant(param_value)
    param_value = param_value / param_scale

    state_dict_quant[param_name] = param_value
```

我们对 1B 与 3B base 模型的 bfloat16 变体跑了端到端评估验证了这一点，结果如下：

[![image/png](https://cdn-uploads.huggingface.co/production/uploads/62441d1d9fdefb55a0b7d12c/CILFS2bQkTw9cS0DrAO7_.png)](https://cdn-uploads.huggingface.co/production/uploads/62441d1d9fdefb55a0b7d12c/CILFS2bQkTw9cS0DrAO7_.png)

模型的 `bfloat16` 对应版本可以直接通过 Hugging Face transformers 加载，在 `from_pretrained` 函数中传入 `revision="bfloat16"`：

```
import torch

from transformers import AutoModelForCausalLM, AutoTokenizer
from trl import SFTTrainer

model_id = "tiiuae/Falcon-E-1B-Base"

tokenizer = AutoTokenizer.from_pretrained(model_id, revision="prequantized")
model = AutoModelForCausalLM.from_pretrained(
    model_id,
    torch_dtype=torch.bfloat16,
    revision="bfloat16"
)
```

## Falcon-Edge，一系列可微调的 BitNet 模型

据我们所知，[除微软最近的发布外](https://huggingface.co/collections/microsoft/bitnet-67fddfe39a03686367734550)，此前的 BitNet 发布只放出最终量化模型，只能用于推理。与微软的发布类似，我们通过放出预量化权重来拓展 BitNet 模型研究与应用的可达性。这样，用户可以针对目标领域微调，或对 BitNet checkpoint 做继续预训练——只要把 `nn.Linear` 层替换为 `BitnetLinear` 层，并确保训练后把模型量化回 BitNet 格式。由于权重对应的是预量化权重，如果不把 `nn.Linear` 层替换成 `BitnetLinear` 层就直接做文本生成，输出会是乱码。

预量化权重可以通过 Hugging Face 的 transformers 库下载，把 `revision` 参数指定为 `prequantized`：

```
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer

model_id = "tiiuae/Falcon-E-1B-Base"

tokenizer = AutoTokenizer.from_pretrained(model_id, revision="prequantized")
model = AutoModelForCausalLM.from_pretrained(
    model_id,
    torch_dtype=torch.bfloat16,
    revision="prequantized"
)
```

通过这种方式，我们希望助力围绕「社区制作的首批强大 1-bit 微调模型」的生态。我们把在预量化权重上微调所需的全部工具方法打包进一个名为 `onebitllms` 的 Python 包，让大家能轻松上手、微调自己版本的强大 BitNet 模型——下一节详细介绍。

## 发布 `onebitllms`——面向 1-bit LLM 训练的轻量 Python 工具包

[![image/png](https://cdn-uploads.huggingface.co/production/uploads/62441d1d9fdefb55a0b7d12c/fFHDDM8DDI82XAtmcMD8p.png)](https://cdn-uploads.huggingface.co/production/uploads/62441d1d9fdefb55a0b7d12c/fFHDDM8DDI82XAtmcMD8p.png)

本次发布中，我们还推出 `onebitllms`——一个轻量 Python 包，可接入你常用的 LLM 微调工具，用于微调任意预量化 BitNet 模型。写作本文时，`onebitllms` 提供以下主要功能：

- 工具方法：把预量化 checkpoint 转换为 BitNet 训练格式，以便喂给你喜爱的任何 LLM 微调框架。我们目前已在 Hugging Face 的 `trl` 库上测试了本库。
- 工具方法：把训练好的 checkpoint 量化为 BitNet 格式，或转为常规的 `bfloat16` 格式。
- 更细粒度的控制：裸 `BitnetLinear` 与 Triton kernel，可注入到你的预训练框架中使用。

目前该框架仅支持全量微调。虽然本次发布的模型规模相对较小，但为 BitNet 模型支持参数高效微调（PEFT）方法，仍是面向未来 BitNet 模型的一个令人兴奋且有影响力的开放问题。

要开始使用，直接通过 `pip` 或从源码安装本包，并看看[源码](https://github.com/tiiuae/onebitllms)里的 `examples/` 目录。

```
import torch

from transformers import AutoModelForCausalLM, AutoTokenizer
from trl import SFTTrainer
from onebitllms import replace_linear_with_bitnet_linear, quantize_to_1bit

model_id = "tiiuae/Falcon-E-1B-Base"

tokenizer = AutoTokenizer.from_pretrained(model_id, revision="prequantized")
model = AutoModelForCausalLM.from_pretrained(
    model_id,
    torch_dtype=torch.bfloat16,
    revision="prequantized"
)
model = replace_linear_with_bitnet_linear(model)

trainer = SFTTrainer(
    model,
    ...
)

trainer.train()

quantize_to_1bit(output_directory)
```

借这个包，我们希望加速三值格式 LLM 的研究与开发，并期待看到社区基于 *Falcon-Edge* 及其他未来强大 BitNet 模型衍生出众多变体。

## 走得更远

我们相信这次发布打开了多个有趣方向——在所有可能的后续方向中，我们目前认为以下开放问题会让 BitNet 模型在不远的将来更有影响力：

- *为 BitNet 架构编写更强的 GPU 推理 kernel*：借鉴 [`bitnet.cpp`](https://github.com/microsoft/BitNet) 背后的核心思路，我们希望这次发布能说服研究社区着力开发强大的 BitNet GPU 推理 kernel——让它们在 GPU 上比原生模型更快。
- *为 BitNet 微调支持 PEFT 方法*：这仍是一个未被探索的研究问题，可能为 BitNet 模型打开多种新的可能性。
- *更严谨地考察 BitNet checkpoint 的通用性*：虽然我们观察到仅注入权重 scale 就能得到一个不错的非 BitNet checkpoint，但我们相信还有更多研究可做，以最小化 BitNet checkpoint 与其 `bfloat16` 对应版本之间的性能差，直至完全无损。
- *关于多模态 BitNet 模型*：我们希望这些 BitNet 基础模型连同 `onebitllms` 包，能成为首批多模态 BitNet VLM（视觉语言模型）等工作的地基。
- *更优化的 BitNet 训练 kernel*：编写我们的 kernel 时，我们采取两阶段方案——先计算全局最大值，之后按块使用它做归一化。这一做法可以改进以写出更高效的 kernel。在我们的测试中，估计非 BitNet 预训练与 BitNet 预训练之间的开销约 20%。我们很快会发布 BitNet 训练开销的更多详尽数字。
