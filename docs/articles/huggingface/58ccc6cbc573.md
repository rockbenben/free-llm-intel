## Skops 发布

在 Hugging Face，我们致力于解决开源机器学习的各种问题，包括安全开放地托管模型、支持可复现性、可解释性与协作。我们很高兴向你介绍我们的新库：Skops！用 Skops，你可以把 scikit-learn 模型托管到 Hugging Face Hub，为模型创建文档化的模型卡，并与他人协作。

我们走一遍端到端示例：先训练一个模型，再一步步看如何用 Skops 把 sklearn 投入生产。

```
# let's import the libraries first
import sklearn
from sklearn.datasets import load_breast_cancer
from sklearn.tree import DecisionTreeClassifier
from sklearn.model_selection import train_test_split

# Load the data and split
X, y = load_breast_cancer(as_frame=True, return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42
)

# Train the model
model = DecisionTreeClassifier().fit(X_train, y_train)
```

你可以使用任何模型文件名和序列化方式，比如 `pickle` 或 `joblib`。目前我们的后端用 `joblib` 加载模型。`hub_utils.init` 会在本地创建一个文件夹，包含给定路径下的模型，以及记录模型训练环境配置的配置文件。传给 `init` 的数据和任务，能帮助 Hugging Face Hub 在模型页启用推理 widget，并提供让模型可被发现的特性。

```
from skops import hub_utils
import pickle

# let's save the model
model_path = "example.pkl"
local_repo = "my-awesome-model"
with open(model_path, mode="bw") as f:
    pickle.dump(model, file=f)

# we will now initialize a local repository
hub_utils.init(
    model=model_path, 
    requirements=[f"scikit-learn={sklearn.__version__}"], 
    dst=local_repo,
    task="tabular-classification",
    data=X_test,
)
```

现在仓库包含序列化后的模型与配置文件。配置包含以下内容：

- 模型的特征，
- 模型的依赖要求，
- 取自我们传入的 `X_test` 的一个示例输入，
- 模型文件名，
- 此处要解决的任务名。

接下来创建模型卡。模型卡要符合 Hugging Face Hub 的格式：一个 markdown 部分加一个元数据区——即顶部的 `yaml` 部分。元数据区的键定义见[这里](https://huggingface.co/docs/hub/models-cards#model-card-metadata)，用于模型的可发现性。模型卡内容由模板决定，模板包含：

- 顶部用于元数据的 `yaml` 部分（例如模型许可证、库名等）
- 带自由文本与待填部分的 markdown 部分（例如模型的简要描述）。以下部分由 `skops` 提取填入模型卡：
- 模型的超参数，
- 模型的交互式图示，
- 元数据方面，库名、任务标识符（例如 tabular-classification）以及推理 widget 所需的信息会被填好。

我们会演示如何以编程方式传入信息来填充模型卡。你可以查看 `skops` 默认模板及其各部分的[文档](https://skops.readthedocs.io/en/latest/model_card.html)，了解模板需要哪些内容；模板本身长什么样见[这里](https://github.com/skops-dev/skops/blob/main/skops/card/default_template.md)。

你可以通过实例化 `skops` 的 `Card` 类来创建模型卡。模型序列化时，任务名和库名会被写入配置文件。卡片元数据也需要这些信息，所以你可以用 `metadata_from_config` 方法从配置文件提取元数据，并在创建卡片时传入。你可以用 `add` 补充信息与元数据。

```
from skops import card

# create the card 
model_card = card.Card(model, metadata=card.metadata_from_config(Path(destination_folder)))

limitations = "This model is not ready to be used in production."
model_description = "This is a DecisionTreeClassifier model trained on breast cancer dataset."
model_card_authors = "skops_user"
get_started_code = "import pickle \nwith open(dtc_pkl_filename, 'rb') as file: \n    clf = pickle.load(file)"
citation_bibtex = "bibtex\n@inproceedings{...,year={2020}}"

# we can add the information using add
model_card.add(
    citation_bibtex=citation_bibtex,
    get_started_code=get_started_code,
    model_card_authors=model_card_authors,
    limitations=limitations,
    model_description=model_description,
)

# we can set the metadata part directly
model_card.metadata.license = "mit"
```

接下来我们评估模型，并用 `add` 添加评估方法的描述。指标通过 `add_metrics` 添加，会被解析成表格。

```
from sklearn.metrics import (ConfusionMatrixDisplay, confusion_matrix,
                            accuracy_score, f1_score)
# let's make a prediction and evaluate the model
y_pred = model.predict(X_test)
# we can pass metrics using add_metrics and pass details with add
model_card.add(eval_method="The model is evaluated using test split, on accuracy and F1 score with macro average.")
model_card.add_metrics(accuracy=accuracy_score(y_test, y_pred))
model_card.add_metrics(**{"f1 score": f1_score(y_test, y_pred, average="micro")})
```

我们还可以像下面这样用 `add_plot` 往卡片添加任意自选的图。

```
import matplotlib.pyplot as plt
from pathlib import Path
# we will create a confusion matrix
cm = confusion_matrix(y_test, y_pred, labels=model.classes_)
disp = ConfusionMatrixDisplay(confusion_matrix=cm, display_labels=model.classes_)
disp.plot()

# save the plot
plt.savefig(Path(local_repo) / "confusion_matrix.png")

# the plot will be written to the model card under the name confusion_matrix
# we pass the path of the plot itself
model_card.add_plot(confusion_matrix="confusion_matrix.png")
```

把模型卡保存到本地仓库。文件名应为 `README.md`，因为这是 Hugging Face Hub 期望的。

```
model_card.save(Path(local_repo) / "README.md")
```

现在可以把仓库推送到 Hugging Face Hub，用 `hub_utils` 的 `push`。Hugging Face Hub 认证需要 token，因此你要在 `notebook_login`（从 notebook 登录）或 `huggingface-cli login`（从 CLI 登录）中传入你的 token。

```
# if the repository doesn't exist remotely on the Hugging Face Hub, it will be created when we set create_remote to True
repo_id = "skops-user/my-awesome-model"
hub_utils.push(
    repo_id=repo_id,
    source=local_repo,
    token=token,
    commit_message="pushing files to the repo from the example!",
    create_remote=True,
)
```

模型推送到 Hub 后，除非仓库是私有的，任何人都能使用它。你可以用 `download` 下载模型。除模型文件外，仓库还包含模型配置与环境依赖要求。

```
download_repo = "downloaded-model"
hub_utils.download(repo_id=repo_id, dst=download_repo)
```

此时仓库中的推理 widget 已启用，可以进行预测。

[![Hosted Inference Widget](https://huggingface.co/blog/assets/94_skops/skops_widget.png)](https://huggingface.co/blog/assets/94_skops/skops_widget.png)

如果你的项目依赖发生了变化，可以用 `update_env` 更新环境。

```
hub_utils.update_env(path=local_repo, requirements=["scikit-learn"])
```
