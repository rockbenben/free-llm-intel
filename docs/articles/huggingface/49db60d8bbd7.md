过去几年，大家都在用 Claude 和 OpenAI 当编码助手，但如果你看看 [Open R1](https://huggingface.co/open-r1) 这样的开源项目带来的进展，它们的吸引力就没那么大了。从下面 [LiveCodeBench](https://livecodebench.github.io) 的评测可以看到，7B 参数版本超过了 Claude 3.7 Sonnet 和 GPT-4o。而这些模型正是许多工程师在 Cursor、VSCode 等应用中的日常主力。

[![evals](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/olympic-coder-lmstudio/lcb-evals.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/olympic-coder-lmstudio/lcb-evals.png)

评测虽好，但我想亲自动手、感受 commit 的滋味！本博文聚焦如何现在就把这些模型集成进你的 IDE。我们将配置 OlympicCoder 7B——OlympicCoder 两个变体中较小的一个——并使用量化版本以求最佳的本地推理效果。我们要用的技术栈是：

- OlympicCoder 7B。来自 [LMStudio Community](https://huggingface.co/lmstudio-community/OlympicCoder-7B-GGUF) 的 4bit GGUF 版本
- LM Studio：简化 AI 模型运行的工具
- Visual Studio Code（VS Code）
- [Continue](https://www.continue.dev/)——一个面向本地模型的 VS Code 扩展

需要说明，我们选这套栈纯粹为了简单。你可能想尝试更大的模型和/或不同的 GGUF 文件，甚至其他推理引擎如 [llama.cpp](https://github.com/ggml-org/llama.cpp)。

[![generation](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/olympic-coder-lmstudio/generation.gif)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/olympic-coder-lmstudio/generation.gif)

# 1. 安装 LM Studio

LM Studio 就像 AI 模型的控制面板。它与 Hugging Face hub 集成来拉取模型，帮你找到正确的 GGUF 文件，并暴露一个 API 供其他应用与模型交互。

简而言之，它让你无需复杂配置就能下载并运行模型。

- 打开 LM Studio 官网：在浏览器访问 [https://lmstudio.ai/download](https://lmstudio.ai/download)。
- 选择你的操作系统：点击对应你电脑（Windows、Mac 或 Linux）的下载按钮。
- 安装 LM Studio：运行下载的文件并按提示操作，和装普通软件一样。

# 2. 获取 [OlympicCoder 7B](https://huggingface.co/open-r1/OlympicCoder-7B)

我们需要的 GGUF 文件托管在 hub 上。可以在 LMStudio 中通过 'Use this model' 按钮直接打开 hub 上的模型：

[![model_page](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/olympic-coder-lmstudio/model_page.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/olympic-coder-lmstudio/model_page.png)

这会跳转到 LMStudio 应用并在你的机器上打开，只需选一个量化方式。我选了 `Q4_K_M`，因为它在大多数设备上表现都不错。如果你算力充裕，可以试试 `Q8_*` 系列。

如果想跳过 UI，也可以用命令行通过 `LMStudio` 加载模型：

```
lms get lmstudio-community/OlympicCoder-7B-GGUF
lms load olympiccoder-7b
lms server start
```

# 3. 把 LM Studio 连到 VS Code

这是关键部分。我们现在需要把 VSCode 与 LMStudio 提供的模型服务集成起来。

- 在 LM Studio 的 'Developer' 标签页激活服务器。这会在 `http://localhost:1234/v1` 暴露端点。

[![lmstudio](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/olympic-coder-lmstudio/lm-studio.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/olympic-coder-lmstudio/lm-studio.png)

- **安装 VS Code 扩展**来连接本地服务器。我选了 Continue.dev，但还有其他选项。在 VSCode 中打开扩展视图（点击左侧边栏的方块图标，或按 Ctrl+Shift+X / Cmd+Shift+X）。搜索 "Continue" 并安装来自 "Continue Dev" 的扩展。
- **在 Continue.dev 中配置新模型**。打开 Continue 标签页，在模型下拉菜单中选择 'add new chat model'。这会打开一个 json 配置文件。你需要指定模型名，即 olympiccoder-7b。

[![continue](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/olympic-coder-lmstudio/continue_dev.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/olympic-coder-lmstudio/continue_dev.png)

# 🚀 你拥有了本地编码助手！

通过这套配置，VSCode 里大多数核心 AI 功能都可使用，例如：

- **代码补全：** 开始输入，AI 会建议如何补完你的代码。
- **生成代码：** 让它写一个函数或整块代码。例如，你可以输入（依扩展不同，写在注释或聊天窗口里）：// Write a function to reverse a string in JavaScript
- **解释代码：** 选中一段代码，让 AI 解释它的行为。
- **重构代码：** 让 AI 把代码写得更干净或更高效。
- **编写测试：** 让 AI 为你的代码生成单元测试。

# 🏋️‍♀️ OlympicCoder 是什么性格？

OlympicCoder 不是 Claude。它在基于编程竞赛挑战的 [CodeForces-CoTs](https://huggingface.co/datasets/open-r1/codeforces-cots) 数据集上做了优化。这意味着别指望它特别友好、事事解释。请撸起袖子，准备迎接一位毫无保留、专攻难题的竞赛型选手。

你可以把 OlympicCoder 与其他模型混搭，获得更全面的编码体验。例如，要从二分查找里榨出毫秒，找 OlympicCoder；要设计面向用户的 API，就选 Claude-3.7-sonnet 或 [Qwen-2.5-Coder](https://huggingface.co/Qwen/Qwen2.5-Coder-32B-Instruct)。
