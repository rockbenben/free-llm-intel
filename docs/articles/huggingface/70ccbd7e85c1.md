# 使用 Inference API 部署 AI Comic Factory

我们最近发布了 [Inference for PROs](https://huggingface.co/blog/inference-pro)，这是我们面向更广泛用户开放更大模型的新服务。这一机会为使用 Hugging Face 作为平台来运行终端用户应用打开了新的可能性。

这类应用的一个例子就是 [AI Comic Factory](https://huggingface.co/spaces/jbilcke-hf/ai-comic-factory)——一个广受欢迎的 Space。成千上万的用户用它创作自己的 AI 漫画分镜，并形成了自己的常驻用户社区。他们分享自己的作品，有些人甚至提交了 pull request。

在本教程中，我们将演示如何 fork 并配置 AI Comic Factory 以避免长时间排队，并使用 Inference API 把它部署到你自己的私有空间。这不需要很强的技术能力，但建议对 API、环境变量有一定了解，并对 LLM 与 Stable Diffusion 有基本认识。

## 开始使用

首先，确保你注册了 [PRO Hugging Face 账号](https://huggingface.co/subscribe/pro)，因为这将使你获得 Llama-2 和 SDXL 模型的访问权限。

## AI Comic Factory 的工作原理

AI Comic Factory 与其他运行在 Hugging Face 上的 Space 略有不同：它是一个 NextJS 应用，使用 Docker 部署，并采用客户端-服务器架构，需要两个 API 才能工作：

- 一个语言模型 API（目前为 [Llama-2](https://huggingface.co/docs/transformers/model_doc/llama2)）
- 一个 Stable Diffusion API（目前为 [SDXL 1.0](https://huggingface.co/docs/diffusers/api/pipelines/stable_diffusion/stable_diffusion_xl)）

## 复制（Duplicate）该 Space

要复制 AI Comic Factory，请进入该 Space 并[点击 "Duplicate"](https://huggingface.co/spaces/jbilcke-hf/ai-comic-factory?duplicate=true)：

[![duplicate-space-1.jpg](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/165_ai_comic_factory/duplicate-space-1.jpg)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/165_ai_comic_factory/duplicate-space-1.jpg)

你会注意到 Space 的所有者、名称和可见性已经自动填好，你可以保持这些值不变。

你的 Space 副本将运行在一个对资源需求不高的 Docker 容器中，因此你可以使用最小规格的实例。官方的 AI Comic Factory Space 使用的是更大的 CPU 实例，因为它要服务庞大的用户群体。

要在你的账号下运行 AI Comic Factory，你需要配置你的 Hugging Face token：

[![duplicate-space-2.jpg](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/165_ai_comic_factory/duplicate-space-2.jpg)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/165_ai_comic_factory/duplicate-space-2.jpg)

## 选择 LLM 和 SD 引擎

AI Comic Factory 支持多种后端引擎，可通过两个环境变量进行配置：

- `LLM_ENGINE` 用于配置语言模型（可选值为 `INFERENCE_API`、`INFERENCE_ENDPOINT`、`OPENAI`）
- `RENDERING_ENGINE` 用于配置图像生成引擎（可选值为 `INFERENCE_API`、`INFERENCE_ENDPOINT`、`REPLICATE`、`VIDEOCHAIN`）

我们的重点是让 AI Comic Factory 在 Inference API 上运行，因此两者都需要设置为 `INFERENCE_API`：

[![duplicate-space-3.jpg](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/165_ai_comic_factory/duplicate-space-3.jpg)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/165_ai_comic_factory/duplicate-space-3.jpg)

关于其他引擎和供应商的更多信息，可以在项目的 [README](https://huggingface.co/spaces/jbilcke-hf/ai-comic-factory/blob/main/README.md) 和 [.env](https://huggingface.co/spaces/jbilcke-hf/ai-comic-factory/blob/main/README.md) 配置文件中找到。

## 配置模型

AI Comic Factory 预配置了以下模型：

- `LLM_HF_INFERENCE_API_MODEL`：默认值为 `meta-llama/Llama-2-70b-chat-hf`
- `RENDERING_HF_RENDERING_INFERENCE_API_MODEL`：默认值为 `stabilityai/stable-diffusion-xl-base-1.0`

你的 PRO Hugging Face 账号已经为你提供了这些模型的访问权限，所以你无需做任何操作或修改。

## 更进一步

AI Comic Factory 对 Inference API 的支持还处于早期阶段，一些功能——例如使用 SDXL 的 refiner 步骤或实现图像放大（upscaling）——尚未移植过来。

尽管如此，我们希望这些信息能帮助你开始 fork 并调整 AI Comic Factory，以满足你自己的需求。

欢迎自由试验社区中的其他模型，祝你玩得开心！
