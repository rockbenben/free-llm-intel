# 如何使用对抗性数据动态训练模型

##### 你将学到

- 💡 动态对抗数据收集的基本思想，以及它为什么重要。
- ⚒ 如何动态收集对抗数据并用它们训练模型——以 MNIST 手写数字识别任务为例。

## 动态对抗数据收集（DADC）

静态基准虽然是评估模型性能的常用方式，却存在很多问题：会被刷爆（饱和）、带有偏见或漏洞，还常常驱使研究者追逐指标上的微小提升，而不是构建人类真正可信可用的模型 [1](https://dynabench.org/about)。

动态对抗数据收集（DADC）作为缓解静态基准部分问题的一种方法，前景可观。在 DADC 中，人类创造样本去*骗倒*最先进（SOTA）模型。这个过程带来两个好处：

- 让你能量出模型到底有多健壮；
- 产出的数据可以用来进一步训练更强的模型。

"骗模型"和"用收集到的对抗数据训练模型"这一过程重复多轮，最终得到与人类对齐、更健壮的模型 [1](https://aclanthology.org/2022.findings-acl.18.pdf)。

## 用对抗性数据动态训练你的模型

下面我将演示如何从用户那里动态收集对抗数据，并用它们训练模型——还是用 MNIST 手写数字识别任务。

在 MNIST 手写数字识别任务中，模型学习的目标是：给定一张 `28x28` 的手写数字灰度图（见下图示例），预测出对应的数字。数字范围是 0 到 9。

[![](https://i.imgur.com/1OiMHhE.png)](https://i.imgur.com/1OiMHhE.png)

> 图片来源：mnist | Tensorflow Datasets

这个任务被公认为计算机视觉的*hello world*，在标准（静态）基准测试集上训练出高精度的模型非常容易。然而事实证明，这些 SOTA 模型依然难以在人类亲手写下数字（并输入模型）时给出正确预测——研究者认为，这主要是因为静态测试集没有充分体现人类书写的极大多样性。因此需要人在回路，为模型提供*对抗性*样本，帮助它更好地泛化。

本教程分为以下几节：

- 配置你的模型
- 与模型交互
- 标记（flag）你的模型
- 把一切拼装起来

### 配置你的模型

首先，你要定义模型结构。我下面这个简单模型由两个卷积网络串一个 50 维全连接层，再接一个 10 类的输出层。最后用 softmax 激活函数把模型输出转换成类别上的概率分布。

```
# Adapted from: https://nextjournal.com/gkoehler/pytorch-mnist
class MNIST_Model(nn.Module):
    def __init__(self):
        super(MNIST_Model, self).__init__()
        self.conv1 = nn.Conv2d(1, 10, kernel_size=5)
        self.conv2 = nn.Conv2d(10, 20, kernel_size=5)
        self.conv2_drop = nn.Dropout2d()
        self.fc1 = nn.Linear(320, 50)
        self.fc2 = nn.Linear(50, 10)

    def forward(self, x):
        x = F.relu(F.max_pool2d(self.conv1(x), 2))
        x = F.relu(F.max_pool2d(self.conv2_drop(self.conv2(x)), 2))
        x = x.view(-1, 320)
        x = F.relu(self.fc1(x))
        x = F.dropout(x, training=self.training)
        x = self.fc2(x)
        return F.log_softmax(x)
```

定义了结构之后，你需要在标准的 MNIST 训练/开发数据集上训练它。

### 与模型交互

到这里，假设你已经有了训练好的模型。虽然训练过了，但我们要用人在回路的对抗数据把它练得更健壮。为此，你需要一种方式让用户和它交互：具体地说，让用户能在画布上手写/画出 0-9 的数字，让模型去分类。这些都可以用 [🤗 Spaces](https://huggingface.co/spaces) 完成——它能快速轻松地为你 ML 模型搭一个演示。关于 Spaces 及其构建方法，可以在[这里](https://huggingface.co/spaces/launch)了解更多。

下面是一个与 `MNIST_Model` 交互的简单 Space——该模型我训练了 20 个 epoch（测试集准确率 89%）。你在白色画布上写一个数字，模型就从图像预测数字。完整的 Space 在[这里](https://huggingface.co/spaces/chrisjay/simple-mnist-classification)。来试试骗过这个模型😁。用你最搞笑的字迹写；往画布边上画；放飞自我！

### 标记（flag）你的模型

成功骗到上面的模型了吗？😀 如果骗到了，是时候*标记*你的对抗样本了。标记包括：

- 把对抗样本保存进数据集
- 收集到一定数量的样本后，用这些对抗样本训练模型
- 重复步骤 1-2 若干轮

我写了一个自定义 `flag` 函数来做以上所有事。更多细节欢迎查阅完整代码[这里](https://huggingface.co/spaces/chrisjay/mnist-adversarial/blob/main/app.py#L314)。

## 结论

动态对抗数据收集（DADC）正在机器学习社区中获得越来越多的关注，作为一种收集多样、不饱和、与人类对齐的数据集并改进模型评估与任务表现的方式。通过让模型在回路、动态收集人类生成的对抗数据，我们可以提升模型的泛化潜力。

这种"骗模型—用对抗收集的数据训练模型"的过程应当重复多轮 [1](https://aclanthology.org/2022.findings-acl.18.pdf)。[Eric Wallace 等人](https://aclanthology.org/2022.findings-acl.18)在自然语言推理任务上的实验表明：短期内非对抗的标准数据收集表现更好，但从长期看，动态对抗数据收集的准确率最高，而且优势明显。
