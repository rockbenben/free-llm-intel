# 科学家为 AI agent 划下的界线

把研究任务交给 AI，并不意味着科学家就不再对工作是如何完成的负责。例如，用 AI 做文献综述的研究者，需要核查系统是否忽略了相互矛盾的证据，或者是否提出了所引论文并不支持的论断。把数据分析交给 agent 式系统的人，需要理解它用了哪些方法、访问了哪些文件，以及结果能否被成功复现。把部分实验流程自动化的研究者，需要确信系统遵守物理安全约束，比如温度上限或材料毒性；而处理人类受试者数据的研究者，则需要确信系统能保护受试者的隐私、限制谁可以访问其信息。研究者还需要明确的机构指南，用来核实和披露 AI 辅助完成的工作。

这些伦理与安全问题，是我们在“AI 用于科学”这一方向上工作的核心。负责任的科学不止于准确性——科学领域之所以有伦理研究规范，是因为科学家和科学界过去的行动与选择；这些规范同样涵盖研究如何开展、会产生什么影响。我们希望 AI 工具能拓展科学家所能取得的成果，同时不损害他们审视证据、验证方法的能力，以及——或许最重要的是——为自己的研究结果负责的能力。

为了更清楚地理解这需要什么，我们访谈了 17 位从事自然科学、应用科学和社会科学的科学家，了解他们对负责任地开发 AI agent 的看法。这类系统能够使用工具，并以不同程度的自主性执行研究任务。访谈依托的是此前调研工作中建立起来的研究者网络——我们想了解，科学家会如何引导 AI 的发展，使其体现各自领域的责任。我们问他们：在哪些环节欢迎 agent 的协助、可能出什么问题，以及需要什么样的防护措施，才愿意让 agent 参与自己的研究。

我们对这些问题的兴趣，源自评估 Ai2 所开发模型安全性的工作。随着我们把重心扩展到“AI 用于科学”，我们发现，针对科学应用的大量安全研究都强调生物学、核物理等领域的灾难性风险。我们同样需要一些方法，来评估 agent 在其被使用的领域中是否遵循了负责任研究行为的标准。

我们的主要发现之一与信任有关。在所有访谈中，我们归纳出 *科学信任* 的五个维度：验证、隐私、客观性、问责和透明。它们共同反映出一些超出“AI 系统是否给出正确答案”的关切。研究者还需要理解答案是何以得出的、保护敏感信息、识别偏见，并确定由谁来负责核实并为 AI 辅助得出的结果担责。这些都是负责任研究行为的问题。

另一项主要发现则表明，科学家应当参与决定 agent 承担哪些研究任务、这些 agent 如何运行，以及它们的表现如何被评估。即便结果在技术上是正确的，如果研究者无法检查它是如何产生的，或者 agent 访问了研究者未授权的机密数据或文件，这样的结果也可能不适合用于科学研究。

第三项关键发现关乎科学的未来。受访者分成两派：一派为 AI 驱动的进步感到兴奋，另一派则对人类科学家的角色怀有存在层面的担忧。他们提议开展 AI 使用方面的培训，并把制定和执行指南列为首要而紧迫的挑战。

## 帮助研究者核查工作

对我们访谈中的许多参与者来说，AI agent 的吸引力始于那些耗时的研究任务——处理大型数据集、写代码、记录实验流程，以及处理重复性的行政工作。把这些活动自动化，可以让研究者腾出更多时间用于野外工作、指导学生，或构思新想法。它还能让分析那些人工难以逐一检视的数据量成为可能。

但把研究任务交出去，也相应地产生了一种需求：核实 AI 系统所完成的工作。

有几位参与者提到，他们会把 AI 生成的答案与原始文献对照核查，而不是直接接受摘要的表面结论。他们担心的是：自信满满的回复里藏着不易察觉的不准确之处；以及工具只检索支持某一偏好假说的研究，从而强化既有假设。

但核查 AI 系统给出的最终答案，只是挑战的一部分。研究者可能还需要知道 agent 漏掉了哪些来源、它是否遵循了所要求的方法，以及它在这个过程中访问了哪些信息。

我们的访谈提示了，面向科学研究的 AI agent 评估可以如何更好地反映这些关切。例如，一个文献综述基准可以检验 agent 是否会忽略相互矛盾的证据，或得出其来源并不支持的结论。一个代码基准不仅可以评估生成的代码能否运行，还可以评估 agent 是否访问了其授权范围之外的文件。对数据处理 agent 的评估，则可以把它们的方法和结果与既有的人工流程作对比。

这些例子指向一个更长远的目标——一个参与式基准：由科学家参与界定 agent 应当对照检验的研究实践与安全要求。我们希望评估的，不只是 Ai2 或其他地方开发的系统能否完成被交付的任务，还有它们是否遵循了其所服务领域的标准。

这些评估方案目前仍只是有待与科学家共同开发和测试的提案，而不是成熟的解决方案。但它们为我们在 Ai2 的工作提供了一个方向：构建开放的科研工具，意味着让它们的行为和局限更容易被考察，并让研究社区在界定“什么才算可信的表现”时拥有一席之地。

## 让科学判断始终在回路之中

在把 AI 工具用于科学这件事上，核查只是其中一项考量。受访者还提出了一个更根本的问题——当 AI 接手研究过程中的一部分工作时，科学专长会变成什么样？

一位事业早期的生物学家谈到，自己在习得那些希望将来教给学生的技能时，会有意限制 AI 的使用。另一位研究者则质疑：如果研究者在这个过程中什么也没学到，仅仅产出正确结果是否足够——即便输出完美，“得到这些完美输出的人，从中真的获得了什么吗？”

一些参与者担心，AI 辅助的研究可能会削弱学习，不过自动化的价值在某种程度上取决于研究者和具体任务。经验丰富的科学家为了省时，把熟悉的流程委派出去是合理的；而仍在学习该流程的人，则可能从亲手完成中获益。

在涉及智力贡献的活动上，参与者划出的界线也不相同。一位生物学家拒绝用 AI 生成研究想法，认为保留这项职责应当由个人承担。其他人对 AI 辅助的构思或写作则更为开放。例如，一位人类学家认为，科学论文的某些部分——尤其是对方法和结果的例行描述——程式化程度足够高，可以从自动化中受益。

即便是尝试过用 AI 辅助写作的研究者，有时也会改变主意。一位政治学家谈到，自己曾用 Claude 帮助修改一份稿件，后来决定把整篇论文重写，因为已经分不清哪些属于自己的智力贡献。“我不知道哪部分是 AI，哪部分是我自己，”这位研究者说。

情境同样重要。让 AI 在投稿前批评性地审读一份稿件，得到了一些参与者的认可；但用它去评审另一位研究者尚未发表的工作，则引发了担忧。这一区分不只关乎技术能力；同行评审本身就承载着保密、署名归属以及公正评价他人研究的责任。

这些分歧表明，负责任的自动化无法靠一份“可做与不可做”的通用任务清单来界定。不同科学领域有不同的规范，而个别研究者即便在做类似的工作时，目标也可能不同。

同样的张力也适用于 AI 系统内置的防护措施。一位政治学家谈到，阻止 AI 工具讨论某些话题的内容限制，可能会干扰关于政治暴力或侵犯人权问题的正当研究。与此同时，处理敏感人类受试者数据的参与者，则希望在隐私、访问权限以及信息将被如何使用等方面获得更强的保证。

这两种担忧都成立。缺乏足够防护措施的 agent 可能泄露机密数据或产生有害结果；而受到过宽约束的 agent，则可能让科学家无法开展正当的研究工作。

正因如此，科学社区需要在划定 AI 辅助边界的过程中发挥实质性的作用。开发者需要理解的，不仅是 agent 能做哪些活动，还有研究者希望保留哪些决定权、哪里必须有防护措施——以及这些防护措施在哪些地方可能会妨碍有价值的工作。

## 与科学家一起构建 AI agent

我们的发现指向一种面向科学的 AI 开发路径：从将要使用这项技术的人出发。

研究者应当能够审视 agent 的贡献、决定哪些工作可以交办，并保留发展自身专长的机会。要做到这一点，需要一些技术特性，比如对 agent 行为的透明记录、细粒度的数据控制，以及由不同科学社区的标准与实践所指导的评估。

这还需要持续的合作。我们的研究是探索性的；结论来自对 17 位美国科学家的访谈，既不是对科学界意见的代表性调查，也不是对具体 AI agent 的实证评估。参与者既谈到了他们当下使用的生成式 AI 工具，也谈到了他们对更自主系统的期待。他们的视角指出了重要的关切和设计优先级，而不是就 AI 应如何在科学中使用达成共识。

不过，它们仍提供了一条前进的路径。在 Ai2，我们相信 AI 可以加速科学发现，同时保住让研究可信的开放性、可复现性与独立审视。通过我们在开发和评估科研 agent 方面更广泛的努力，我们希望把这些原则付诸实践。这意味着与科学家合作，找出 agent 有价值的用途，把他们的关切转化为具体的评估，同时也让人们更容易理解这些系统取得了什么成果、又是如何取得的。

科学 AI 的前景，并不只是研究者能交出去更多工作。而是他们能够去追问那些原本可能触及不到的问题，同时保有做出属于自己的发现所需要的知识、判断力和自主性。
