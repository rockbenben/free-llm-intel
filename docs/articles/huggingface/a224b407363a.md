我们很高兴地宣布，Intel Gaudi 硬件支持已原生集成进 Text Generation Inference（TGI）——我们面向大语言模型（LLM）的生产级服务方案。这次集成把 Intel 专用 AI 加速器的算力接入我们的高性能推理技术栈，为开源 AI 社区带来更多部署选择 🎉

## ✨ 有什么新东西？

我们已在 PR [#3091](https://github.com/huggingface/text-generation-inference/pull/3091) 中把 Gaudi 支持完整集成进 TGI 主代码库。此前，我们为 Gaudi 设备单独维护着一个 fork：[tgi-gaudi](https://github.com/huggingface/tgi-gaudi)。这对用户来说很麻烦，也让我们无法在发布当天支持 TGI 的最新特性。现在借助新的 [TGI 多后端架构](https://huggingface.co/blog/tgi-multi-backend)，我们可以直接在 TGI 中支持 Gaudi——再也不用折腾自定义仓库了 🙌

这次集成支持 Intel 的全线 [Gaudi 硬件](https://www.intel.com/content/www/us/en/developer/platform/gaudi/develop/overview.html)：

- Gaudi1 💻：可在 [AWS EC2 DL1 实例](https://aws.amazon.com/ec2/instance-types/dl1/)上使用
- Gaudi2 💻💻：可在 [Intel Tiber AI Cloud](https://ai.cloud.intel.com/) 和 [Denvr Dataworks](https://www.denvrdata.com/guadi2) 上使用
- Gaudi3 💻💻💻：可在 [Intel Tiber AI Cloud](https://ai.cloud.intel.com/)、[IBM Cloud](https://www.ibm.com/cloud) 使用，也可从 [Dell](https://www.dell.com/en-us/lp/intel-gaudi)、[HP](https://www.hpe.com/us/en/compute/proliant-xd680.html)、[Supermicro](https://www.supermicro.com/en/accelerators/intel) 等 OEM 获取

Gaudi 硬件的更多信息也可以在 [Intel 的 Gaudi 产品页](https://www.intel.com/content/www/us/en/developer/platform/gaudi/develop/overview.html) 找到。

## 🌟 为什么这很重要

Gaudi 版的 TGI 后端带来几个关键收益：

- 硬件多样性 🔄：在生产中部署 LLM 时，除了传统 GPU 有了更多选择
- 成本效率 💰：对特定负载，Gaudi 硬件往往有很有吸引力的性价比
- 生产可用 ⚙️：TGI 的全部稳健能力（动态 batching、流式响应等）现在在 Gaudi 上同样可用
- 模型支持 🤖：在 Gaudi 硬件上运行 Llama 3.1、Mixtral、Mistral 等热门模型
- 高级特性 🔥：支持多卡推理（分片）、视觉语言模型和 FP8 精度

## 🚦 在 Gaudi 上开始使用 TGI

在 Gaudi 上运行 TGI 最简单的方式是使用我们的官方 Docker 镜像。你需要在搭载 Gaudi 硬件的机器上运行该镜像。下面是一个上手示例：

```
model=meta-llama/Meta-Llama-3.1-8B-Instruct 
volume=$PWD/data # share a volume with the Docker container to avoid downloading weights every run 
hf_token=YOUR_HF_ACCESS_TOKEN

docker run --runtime=habana --cap-add=sys_nice --ipc=host \
 -p 8080:80 \
 -v $volume:/data \
 -e HF_TOKEN=$hf_token \
 -e HABANA_VISIBLE_DEVICES=all \
 ghcr.io/huggingface/text-generation-inference:3.2.1-gaudi \
 --model-id $model 
```

服务器跑起来后，就可以发送推理请求：

```
curl 127.0.0.1:8080/generate
 -X POST
 -d '{"inputs":"What is Deep Learning?","parameters":{"max_new_tokens":32}}'
 -H 'Content-Type: application/json'
```

关于配合 Gaudi 使用 TGI 的完整文档（包括操作指南和高级配置），请参阅新的 [Gaudi 后端文档](https://huggingface.co/docs/text-generation-inference/backends/gaudi)。

## 🎉 核心特性

我们对以下模型针对单卡和多卡配置都做了优化。这意味着这些模型在 Intel Gaudi 上以最快速度运行。我们专门针对 Intel Gaudi 硬件优化了建模代码，确保提供最佳性能、充分释放 Gaudi 的能力：

- Llama 3.1（8B 和 70B）
- Llama 3.3（70B）
- Llama 3.2 Vision（11B）
- Mistral（7B）
- Mixtral（8x7B）
- CodeLlama（13B）
- Falcon（180B）
- Qwen2（72B）
- Starcoder 和 Starcoder2
- Gemma（7B）
- Llava-v1.6-Mistral-7B
- Phi-2

🏃‍♂️ 我们还在 Gaudi 硬件上提供了许多高级特性，比如借助 [Intel Neural Compressor（INC）](https://docs.habana.ai/en/latest/PyTorch/Inference_on_PyTorch/Quantization/Inference_Using_FP8.html)实现的 FP8 量化，可以带来更进一步的性能优化。

✨ 敬请期待！我们很高兴将扩充模型阵容，加入 DeepSeek-r1/v3、QWen-VL 等前沿模型以及更多强大模型，为你的 AI 应用供能！🚀
