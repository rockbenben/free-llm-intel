# 如何用 NVIDIA Isaac for Healthcare 打造从仿真到部署的医疗机器人

Asawaree（asawareeb，nvidia）

## 一份实操指南：采集数据、训练策略，并在真实硬件上部署自主医疗机器人工作流

在医学影像领域，仿真一直是应对数据缺口的基石。然而在医疗机器人领域，它往往太慢、太孤岛化，或难以转化为真实世界系统。这一点现在正在改变。借助 GPU 加速仿真和数字孪生的新进展，开发者可以完全在虚拟环境里设计、测试和验证机器人工作流——把原型时间从数月缩短到数天，提升模型精度，并在任何设备进入手术室之前实现更安全、更快速的创新。

正因如此，NVIDIA 今年早些时候推出了 Isaac for Healthcare——一个面向 AI 医疗机器人的开发者框架，它通过集成数据采集、训练和评估流水线来帮助开发者解决这些挑战，而这些流水线同时适用于仿真和硬件。具体来说，Isaac for Healthcare v0.4 版本为用户提供了端到端的 [SO-ARM 起步工作流](https://github.com/isaac-for-healthcare/i4h-workflows/blob/main/workflows/so_arm_starter/README.md)和 [自带手术室教程](https://github.com/isaac-for-healthcare/i4h-workflows/blob/main/tutorials/assets/bring_your_own_or/README.md)。SO-ARM 起步工作流降低了 MedTech 开发者的门槛，让他们体验从仿真到训练到部署的完整流程，并立即开始在真实硬件上自主构建和验证。

在本文里，我们会走一遍这个起步工作流及其技术实现细节，帮你在比以往能想象的更短时间里构建一台手术助手机器人。

## SO-ARM 起步工作流：构建一个具身手术助手

SO-ARM 起步工作流引入了一种探索手术辅助任务的新方式，为开发者提供了一条完整的端到端自主手术辅助流水线：

- 用 LeRobot 通过 [SO-ARM](https://huggingface.co/docs/lerobot/en/so101) 采集真实世界和合成数据
- 后训练 GR00T N1.5，在 [Isaac Lab](https://isaac-sim.github.io/IsaacLab/main/index.html) 里评估，然后部署到硬件

这套工作流让开发者拥有一个安全、可重复的环境，在进入手术室之前训练和打磨辅助技能。

### 技术实现

该工作流实现了一条整合仿真与真实硬件的三阶段流水线：

- **数据采集**：用 SO-101 和 LeRobot 做混合的仿真的与真实世界的遥操作演示
- **模型训练**：在合并数据集上、带双相机视觉地对 GR00T N1.5 做后训练
- **策略部署**：在物理硬件上通过 RTI DDS 通信做实时推理

值得注意的是，用于策略训练的数据里有超过 93% 是在仿真中合成生成的，凸显了仿真在弥合机器人数据缺口上的强大能力。

### 仿真到现实的混合训练方法

该工作流把仿真和真实世界数据结合起来，以应对一个根本性挑战：在真实世界训练机器人昂贵且受限，而纯仿真又常常无法捕捉真实世界的复杂性。这一方法用了约 70 个仿真 episode 来覆盖多样场景和环境变化，加上 10-20 个真实世界 episode 来保证真实感和扎根。这种混合训练产生的策略比任何单一领域都能更好地泛化。

### 硬件要求

该工作流需要：

- **GPU**：带 RT Core 的架构（Ampere 或更新），≥30GB 显存用于 GR00T N1.5 推理
- **SO-ARM101 Follower（跟随臂）**：6 自由度精密操作臂，带双相机视觉（腕部和房间）。SO-ARM101 配备 WOWROBO 视觉组件，包括一个腕载相机及 3D 打印适配器。
- **SO-ARM101 Leader（主臂）**：6 自由度遥操作接口，用于采集专家演示

值得注意的是，开发者可以在一台 [DGX Spark](https://www.nvidia.com/en-us/products/workstations/dgx-spark/) 上跑所有的仿真、训练和部署（物理 AI 需要 3 台计算机）。

### 数据采集实现

要用地上的 SO-ARM101 硬件、或 LeRobot 支持的任何其他版本采集真实世界数据：

```
python /path/to/lerobot-record \ 
  --robot.type=so101_follower \ 
  --robot.port=<follower_port_id> \ 
  --robot.cameras="{wrist: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30}, room: {type: opencv, index_or_path: 2, width: 640, height: 480, fps: 30}}" \ 
  --robot.id=so101_follower_arm \ 
  --teleop.type=so101_leader \ 
  --teleop.port=<leader_port_id> \ 
  --teleop.id=so101_leader_arm \ 
  --dataset.repo_id=<user>/surgical_assistance/surgical_assistance \ 
  --dataset.num_episodes=15 \ 
  --dataset.single_task="Prepare and hand surgical instruments to surgeon"
```

基于仿真的数据采集：

```
# With keyboard teleoperation 
python -m simulation.environments.teleoperation_record \ 
  --enable_cameras \ 
  --record \ 
  --dataset_path=/path/to/save/dataset.hdf5 \ 
  --teleop_device=keyboard 

# With SO-ARM101 leader arm 
python -m simulation.environments.teleoperation_record \ 
  --port=<your_leader_arm_port_id> \ 
  --enable_cameras \ 
  --record \ 
  --dataset_path=/path/to/save/dataset.hdf5
```

### 仿真遥操作控制

对于没有物理 SO-ARM101 硬件的用户，该工作流提供基于键盘的遥操作，关节控制如下：

- Joint 1 (shoulder_pan): Q (+) / U (-)
- Joint 2 (shoulder_lift): W (+) / I (-)
- Joint 3 (elbow_flex): E (+) / O (-)
- Joint 4 (wrist_flex): A (+) / J (-)
- Joint 5 (wrist_roll): S (+) / K (-)
- Joint 6 (gripper): D (+) / L (-)
- R 键：重置录制环境
- N 键：把 episode 标记为成功

### 模型训练流水线

采集完仿真和真实世界数据后，转换并合并数据集用于训练：

```
# Convert simulation data to LeRobot format 
python -m training.hdf5_to_lerobot \ 
  --repo_id=surgical_assistance_dataset \ 
  --hdf5_path=/path/to/your/sim_dataset.hdf5 \ 
  --task_description="Autonomous surgical instrument handling and preparation" 


# Post-train GR00T N1.5 on mixed dataset 
python -m training.gr00t_n1_5.train \ 
  --dataset_path /path/to/your/surgical_assistance_dataset \ 
  --output_dir /path/to/surgical_checkpoints \ 
  --data_config so100_dualcam 
```

训练好的模型能处理像 "Prepare the scalpel for the surgeon" 或 "Hand me the forceps" 这样的自然语言指令，并执行相应的机器人动作。借助最新的 LeRobot 版本（v0.4.0），你将能在 LeRobot 中原生地对 GR00T N1.5 做后训练！

## 端到端的"仿真采集-训练-评估"流水线

当仿真处于一个回路之中时最强大：采集数据 → 训练 → 评估 → 部署。Isaac Lab 支持这条完整流水线：

### 在仿真中生成合成数据

- 用键盘或硬件控制器遥操作机器人
- 捕获多相机观测、机器人状态和动作
- 创建带边缘情况的数据集——这些情况在真实环境里无法安全采集

### 训练和评估策略

- 与 Isaac Lab 的 RL 框架深度集成，用于 PPO 训练
- 并行环境（同时跑数千个仿真）
- 内建的轨迹分析和成功指标
- 跨多样场景的统计验证

### 把模型转换为 TensorRT

- 为生产部署做自动优化
- 支持动态形状和多相机推理
- 用于验证实时性能的基准工具

这缩短了从实验到部署的时间，让 sim-to-real 成为日常开发中切实可用的一环。

## 开始上手

Isaac for Healthcare 的 SO-ARM 起步工作流现已可用。要开始：

- **克隆仓库**：`git clone https://github.com/isaac-for-healthcare/i4h-workflows.git`
- **选择一个工作流**：从用于手术辅助的 SO-ARM 起步工作流开始，或探索其他工作流
- **运行设置**：每个工作流都包含一个自动化设置脚本（例如 `tools/env_setup_so_arm_starter.sh`）
