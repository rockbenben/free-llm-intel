# Community Evals：因为我们不再信任黑箱排行榜，而是信任社区

[![banner](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/eval-results-blog/banner.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/eval-results-blog/banner.png)

**TL;DR：** Hugging Face 上的基准数据集现在可以托管排行榜。模型存储自己的评测分数。一切相互链接。社区可以通过 PR 提交结果。认证徽章（Verified badges）证明结果可复现。

## 评测已经坏了

让我们坦诚地看看 2026 年评测（evals）的现状。MMLU 已经在 91% 以上饱和。GSM8K 达到了 94%+。HumanEval 已被攻克。然而，根据使用反馈，一些在基准上拿高分的模型依然无法可靠地浏览网页、编写生产级代码，或在处理多步骤任务时不产生幻觉。基准分数与真实世界表现之间存在明显鸿沟。

此外，已报告的基准分数内部还有*另一重鸿沟*。多个来源报告的结果各不相同。从模型卡（Model Cards）到论文，再到评测平台，报告的分数之间没有一致性。结果就是：社区缺少一个唯一的事实来源（single source of truth）。

## 我们正在交付什么

**去中心化且透明的评测报告。**

我们将让 Hugging Face Hub 上的评测走向一个新方向：把报告去中心化，让整个社区都能公开地为基准报告分数。起初我们会从一份包含 4 个基准的短名单开始，随着时间推移扩展到最相关的那些基准。

**对于基准（Benchmarks）：** 数据集仓库现在可以注册为基准（[MMLU-Pro](https://huggingface.co/datasets/TIGER-Lab/MMLU-Pro)、[GPQA](https://huggingface.co/datasets/Idavidrein/gpqa)、[HLE](https://huggingface.co/datasets/cais/hle) 已经上线）。它们会自动聚合来自整个 Hub 的报告结果，并在数据集卡片中显示排行榜。基准通过 `eval.yaml` 定义评测规范（eval spec），基于 [Inspect AI](https://inspect.aisi.org.uk/) 格式，因此任何人都可以复现它。报告的结果需要与任务定义保持一致。

[![benchmark image](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/eval-results-blog/benchmark.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/eval-results-blog/benchmark.png)

**对于模型（Models）：** 评测分数存放在模型仓库的 `.eval_results/*.yaml` 中。它们会显示在模型卡上，并被输入到基准数据集中。模型作者的结果**以及公开的结果 pull request** 都会被聚合。模型作者将能够关闭分数 PR 并隐藏结果。

**对于社区（Community）：** 任何用户都可以通过 PR 为任何模型提交评测结果。结果会以 "community" 身份显示，无需等待模型作者合并或关闭。社区可以链接到论文、模型卡、第三方评测平台或 `inspect` 评测日志等来源。社区可以像讨论任何 PR 一样讨论分数。由于 Hub 基于 Git，因此有何时添加评测、何时做出修改等历史记录。来源看起来如下面这样。

[![model image](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/eval-results-blog/model.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/eval-results-blog/model.png)

要了解更多关于评测结果的内容，请查看[文档](https://huggingface.co/docs/hub/eval-results)。

## 为什么这很重要

评测的去中心化将把社区中已存在于模型卡、论文等来源里的分数暴露出来。通过暴露这些分数，社区可以在其之上进行聚合、追踪并理解整个领域的分数情况。而且，所有分数都会通过 Hub API 暴露出来，从而可以方便地聚合并构建精选排行榜、看板等。

社区评测并不取代基准，因此排行榜和发布结果的封闭评测仍然至关重要。不过，我们认为基于可复现的评测规范贡献开放评测结果对这一领域很重要。

这不会解决基准饱和问题，也不会弥合基准与现实之间的鸿沟，同样无法阻止在测试集上训练。但它通过暴露"评了什么、怎么评、何时评、由谁评"，让这场博弈变得可见。

最重要的是，我们希望把 Hub 变成一个构建和分享可复现基准的活跃场所，尤其聚焦于那些能对 SOTA 模型提出更大挑战的新任务和新领域。

## **开始使用**

**阅读文档：** 要了解更多关于评测结果的内容，请查看[文档](https://huggingface.co/docs/hub/eval-results)。

**添加评测结果：** 把你所做的评测以 YAML 文件的形式发布到任何模型仓库的 `.eval_results/` 目录。

**查看分数**：见[基准数据集](https://huggingface.co/datasets?benchmark=benchmark:official&sort=trending)。

**注册新基准：** 把 `eval.yaml` 添加到你的数据集仓库，并[联系我们以被纳入短名单](https://huggingface.co/spaces/OpenEvals/README/discussions/2)。

*该功能处于 beta 阶段。我们在公开环境下构建。[欢迎反馈](https://huggingface.co/spaces/OpenEvals/README/discussions/1)。*
