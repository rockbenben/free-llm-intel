# Graphcore 与 Hugging Face 推出全新 IPU 就绪 Transformers 产品线

[Graphcore](https://huggingface.co/hardware/graphcore/) 和 Hugging Face 大幅扩展了 [Hugging Face Optimum](https://github.com/huggingface/optimum)（一个用于 Transformers 性能优化的开源库）所支持的机器学习模态和任务范围。开发者现在可以便捷地使用一系列现成的 Hugging Face Transformer 模型，这些模型均经过优化，可在 Graphcore 的 IPU 上达到最佳性能。

早在 [Optimum Graphcore 发布](https://huggingface.co/blog/graphcore)后不久，[BERT transformer 模型](https://www.graphcore.ai/posts/getting-started-with-hugging-face-transformers-for-ipus-with-optimum)就率先上线；如今开发者可以访问覆盖自然语言处理（NLP）、语音和计算机视觉的 10 款模型，它们附带 IPU 配置文件以及开箱即用的预训练和微调权重。

## 新增 Optimum 模型

### 计算机视觉

[ViT](https://huggingface.co/Graphcore/vit-base-ipu)（Vision Transformer）是图像识别领域的一项突破，以 transformer 机制作为核心组件。图像输入 ViT 时，会被切分成小 patch，类似语言系统中对词的处理方式。每个 patch 由 Transformer 编码（Embedding），随后可被单独处理。

### NLP

[GPT-2](https://huggingface.co/Graphcore/gpt2-medium-wikitext-103)（Generative Pre-trained Transformer 2）是一个文本生成 transformer 模型，以自监督方式在非常大的英文语料上预训练。这意味着它只在原始文本上预训练，没有任何人工标注（这也是它能利用大量公开数据的原因），并通过自动过程从这些文本中生成输入和标签。更确切地说，它被训练为根据 prompt 生成文本，方法是猜测句子中的下一个词。

[RoBERTa](https://huggingface.co/Graphcore/roberta-base-squad2)（Robustly optimized BERT approach）是一个 transformer 模型，与 GPT-2 类似，以自监督方式在大型英文语料上预训练。更确切地说，RoBERTa 使用掩码语言建模（MLM）目标进行预训练。对给定句子，模型随机掩码输入中 15% 的词，然后把整个被掩码的句子送入模型并预测被掩码的词。RoBERTa 可用于掩码语言建模，但主要用于在下游任务上微调。

[DeBERTa](https://huggingface.co/Graphcore/deberta-base-ipu)（Decoding-enhanced BERT with disentangled attention）是用于 NLP 任务的预训练神经语言模型。DeBERTa 在 2018 年的 BERT 和 2019 年的 RoBERTa 基础上，采用两项新技术——解耦注意力机制和增强掩码解码器——显著提升了模型预训练效率和下游任务性能。

[BART](https://huggingface.co/Graphcore/bart-base-ipu) 是一个 transformer encoder-decoder（seq2seq）模型，具有双向（BERT 风格）编码器和自回归（GPT 风格）解码器。BART 的预训练方式为：(1) 用任意噪声函数破坏文本；(2) 学习一个模型来重建原始文本。BART 在面向文本生成（如摘要、翻译）微调时尤其有效，但在理解类任务（如文本分类、问答）上同样表现出色。

[LXMERT](https://huggingface.co/Graphcore/lxmert-gqa-uncased)（Learning Cross-Modality Encoder Representations from Transformers）是一个用于学习视觉与语言表示的多模态 transformer 模型。它有三个编码器：对象关系编码器、语言编码器和跨模态编码器。其预训练结合了掩码语言建模、视觉-语言文本对齐、ROI 特征回归、掩码视觉属性建模、掩码视觉对象建模以及视觉问答等多种目标。它在 VQA 和 GQA 视觉问答数据集上取得了最先进结果。

[T5](https://huggingface.co/Graphcore/t5-small-ipu)（Text-to-Text Transfer Transformer）是一个革命性的新模型，可以把任意文本转换为用于翻译、问答或分类的机器学习格式。它引入了一个统一框架，把所有基于文本的语言问题都转化为 text-to-text 格式以进行迁移学习。由此，它简化了在不同 NLP 任务间复用同一模型、同一目标函数、同一超参数和同一解码流程的方式。

### 语音

[HuBERT](https://huggingface.co/Graphcore/hubert-base-ipu)（Hidden-Unit BERT）是一个在音频上预训练的自监督语音识别模型，在连续输入上学习一个声学与语言联合模型。HuBERT 在 Librispeech（960h）和 Libri-light（60,000h）基准（含 10min、1h、10h、100h、960h 微调子集）上的性能追平或超越了最先进的 wav2vec 2.0。

[Wav2Vec2](https://huggingface.co/Graphcore/wav2vec2-base-ipu) 是一个用于自动语音识别的预训练自监督模型。借助新颖的对比预训练目标，Wav2Vec2 从大量无标注语音数据中学习强大的语音表示，再用少量转录语音数据进行微调，在概念更简单的同时超越了最佳的半监督方法。

## Hugging Face Optimum Graphcore：建立在坚实的合作之上

Graphcore 于 2021 年作为创始成员加入 [Hugging Face 硬件合作伙伴计划](https://huggingface.co/hardware)，两家公司共享一个共同目标：降低创新者驾驭机器智能力量的门槛。

自那以来，Graphcore 与 Hugging Face 密切合作，让在 IPU 上训练 transformer 模型变得快速而简单，首个 Optimum Graphcore 模型（BERT）于去年发布。

事实表明，Transformers 在功能提取、文本生成、情感分析、翻译等众多任务上极为高效。包括 BERT 在内的模型被 Graphcore 客户广泛用于海量应用，包括网络安全、语音通话自动化、药物发现和翻译。

要在真实世界中优化其性能，需要大量时间、精力和技能，而这超出了许多公司和组织的能力范围。Hugging Face 通过提供开源的 transformer 模型库，直接回应了这些问题。将 IPU 与 Hugging Face 集成，还让开发者不仅能利用模型，还能利用 Hugging Face Hub 上的数据集。

开发者现在可以使用 Graphcore 系统训练 10 种不同类型的最先进的 transformer 模型，并以极低的编程复杂度访问数千个数据集。通过这项合作，我们为用户提供了工具与生态，让他们可以轻松下载最先进预训练模型并针对各种领域和下游任务进行微调。

## 带来 Graphcore 最新的硬件与软件

尽管 Hugging Face 不断扩大的用户群早已受益于 IPU 技术的速度、性能以及功耗和成本效率，Graphcore 近期硬件与软件发布的组合将释放更大潜力。

硬件方面，[Bow IPU](https://www.graphcore.ai/bow-processors)——3 月发布、现已向客户发货——是全球首款采用 Wafer-on-Wafer（WoW）3D 堆叠技术的处理器，把 IPU 有口皆碑的优势带到新高度。凭借计算架构与芯片实现、通信和存储方面的突破性进展，每颗 Bow IPU 可提供高达 350 teraFLOPS 的 AI 算力——性能提升 40% 之多——且比上一代 IPU 能效提高最多 16%。重要的是，Hugging Face Optimum 用户可以从上一代 IPU 无缝切换到 Bow 处理器，因为无需任何代码改动。

软件在释放 IPU 能力方面同样至关重要，因此 Optimum 自然与 Graphcore 易用的 Poplar SDK 提供了即插即用的体验——Poplar 本身也迎来了重要的 2.5 更新。Poplar 让在最先进硬件上训练最先进模型变得简单，这得益于它与标准机器学习框架的完整集成（包括 PyTorch、PyTorch Lightning 和 TensorFlow），以及与 Docker 和 Kubernetes 等编排和部署工具的结合。让 Poplar 兼容这些广泛使用的第三方系统，开发者可以轻松地把模型从其他计算平台迁移过来，开始享受 IPU 先进的 AI 能力。
