# LeRobot v0.5.0：每个维度都在扩展

自 v0.4.0 以来合并了 200 多个 PR、新增了 50 多位贡献者，LeRobot v0.5.0 是我们史上最大的一次发布——同时向所有方向扩张。更多机器人（包括首个双足人形）、更多策略（包括自回归 VLA 的回归）、更快的数据集、可直接从 Hub 加载的仿真环境，以及全面现代化的代码库——运行在 Python 3.12 和 Transformers v5 上。无论你在仿真里训练策略还是在真实硬件上部署，v0.5.0 都有你的东西。

## 太长不看

LeRobot v0.5.0 加入完整的 Unitree G1 人形支持（全身控制模型）、新策略——包括 Pi0-FAST 自回归 VLA 和用于响应式推理的 Real-Time Chunking——以及流式视频编码，消除录制 episodes 之间的等待时间。本次发布还引入 EnvHub，可从 Hugging Face Hub 加载仿真环境；集成 NVIDIA IsaacLab-Arena；并完成大规模代码库现代化：Python 3.12+、Transformers v5 和第三方策略插件。

## 硬件：史上最多的机器人

LeRobot v0.5.0 大幅扩充了支持的硬件名单——从机械臂、移动机器人到完整的人形机器人。

### Unitree G1 人形

本次发布最大的硬件新增：**完整的 Unitree G1 人形支持**。这是 LeRobot 第一个人形集成，而且是全面的：

- **移动（Locomotion）**：行走、导航、穿越环境。
- **操作（Manipulation）**：执行灵巧物体操作任务。
- **遥操作（Teleoperation）**：用直观的遥操作界面远程控制 G1。
- **全身控制（WBC）**：同时协调移动与操作，应对复杂的真实世界任务。

G1 集成代表着 LeRobot 迈向通用机器人的一大步——从桌面机械臂扩展到全身具身智能。跟着[文档](https://huggingface.co/docs/lerobot/unitree_g1)自己试试看。

[![unitree-boss](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot-blog/release-v0.5.0/unitree_bosswalk.JPG)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot-blog/release-v0.5.0/unitree_bosswalk.JPG)

### OpenArm 与 OpenArm Mini

我们加入了对 [**OpenArm**](https://openarm.dev) 机器人及其配套**OpenArm Mini** 遥操作器的支持。OpenArm 是一只能与 LeRobot 完整集成的强劲机械臂，Mini 则是它天然的遥操作设备。两者都支持**双臂配置**，让更复杂的操作任务可以双腕齐上。到[文档](https://huggingface.co/docs/lerobot/openarm)了解。

### 更多机器人

硬件生态还在继续增长：

- [**Earth Rover**](https://shop.frodobots.com/products/miniplus)：我们的第一个移动机器人集成，把 LeRobot 带到户外导航和地面机器人场景。
- [**OMX Robot**](https://ai.robotis.com/omx/hardware_omx.html)：新的机械臂，支持可配置夹爪和标定。
- **SO-100/SO-101 整合**：我们把 SO-100 和 SO-101 的实现统一为一套更干净的代码库——包括双臂配置。更少重复代码、更好维护，机器人一样好用。

### CAN 总线电机

新增通过 CAN（Controller Area Network）总线的电机控制器支持，为高性能执行器打开了大门：

- [**RobStride**](https://github.com/RobStride/Product_Information)：面向高扭矩应用的 CAN 电机控制器。
- **Damiao**：另一款 CAN 总线电机控制器，进一步扩大兼容硬件范围。

这些新增意味着 LeRobot 现在可以驱动比现有 Dynamixel 和 Feetech 生态更广的专业级执行器。

## 策略：不断壮大的模型动物园

本次发布为 LeRobot 带来六种新策略与技术，拓展开源机器人学习的边界。

### Pi0-FAST：自回归 VLA

**Pi0-FAST** 把自回归视觉-语言-动作（VLA）模型带入 LeRobot，采用 [FAST（频域动作序列 tokenization）](https://huggingface.co/docs/lerobot/pi0fast)。与 Pi0 的 flow-matching 路线不同，Pi0-FAST 使用一个自回归动作专家（基于 Gemma 300M）生成离散化的动作 token，从而支持：

- **FAST tokenization**：动作被 tokenize 以便自回归解码，配有专门的 [FAST action tokenizer](https://huggingface.co/lerobot/fast-action-tokenizer)。
- **灵活解码**：可配置温度和最大解码步数，在速度与质量之间平衡。
- **兼容 RTC**：与 Real-Time Chunking 配合（见[下一节](https://huggingface.co/blog/lerobot-release-v050#real-time-chunking-rtc)）实现响应式推理。

```
lerobot-train \
  --policy.type=pi0_fast \
  --dataset.repo_id=lerobot/aloha_sim_insertion_human \
  --policy.device=cuda
```

### Real-Time Chunking（RTC）

**Real-Time Chunking** 是来自 [Physical Intelligence](https://www.pi.website) 的推理时技术，能让 flow-matching 策略的响应性大幅跃升。RTC 不再等整个动作 chunk 执行完再重新规划，而是持续把新预测与正在执行的动作融合，产生更平滑、更敏捷的行为。

RTC 不是独立策略——它是可以插入现有 flow-matching 策略（Pi0 家族、SmolVLA 和 Diffusion）的增强。通过 `--policy.rtc_config.enabled=true` 配置。

对延迟敏感的真实部署来说，这是游戏规则的改变者。技术细节读[原论文](https://huggingface.co/papers/2506.07339)，用法看我们的[文档](https://huggingface.co/docs/lerobot/rtc)。

### Wall-X

**Wall-X** 是构建在 [**Qwen2.5-VL**](https://huggingface.co/collections/Qwen/qwen25-vl) 上的新 VLA 策略，用 flow-matching 做动作预测。它把 Qwen2.5-VL 的强视觉-语言理解与 flow-matching 头部结合，实现跨本体（cross-embodiment）机器人控制。

```
pip install lerobot[wall_x]
lerobot-train \
  --policy.type=wall_x \
  --dataset.repo_id=lerobot/aloha_sim_insertion_human
```

### X-VLA

**X-VLA** 把基于 **Florence2** 的 VLA 带进 LeRobot。X-VLA 构建于 Microsoft 的 Florence-2 视觉-语言模型之上，为 VLA 策略提供了另一种骨干，丰富了机器人学习可用的基础模型多样性。查看[训练指南](https://huggingface.co/docs/lerobot/xvla)了解配置步骤，以及[基座模型](https://huggingface.co/lerobot/xvla-base)。

```
pip install lerobot[xvla]
lerobot-train \
  --policy.type=xvla \
  --dataset.repo_id=lerobot/bimanual-so100-handover-cube
```

### SARM

**SARM（Stage-Aware Reward Modeling，阶段感知奖励建模）** 直面机器人学习中最难的问题之一：长程任务。它不再对整个 episode 使用单一的全局线性进度信号，而是以阶段感知的方式建模进度——同时预测任务阶段和该阶段内的进度。这为复杂多步操作任务训练策略降低了难度。按[文档](https://huggingface.co/docs/lerobot/sarm)开始尝试。

[![sarm-community](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot-blog/release-v0.5.0/sarm_community.gif)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot-blog/release-v0.5.0/sarm_community.gif)

### PEFT 支持

现在你可以**用 LoRA**（及其他 PEFT 方法）**微调大型 VLA**，而无需改动核心训练流水线。PEFT 配置在策略层级，让你用一小部分算力就能把庞大的基础模型适配到特定的机器人和任务上。详情读[文档](https://huggingface.co/docs/lerobot/peft_training)。

```
lerobot-train \
  --policy.type=pi0 \
  --policy.peft_config.use_peft=true \
  --dataset.repo_id=lerobot/aloha_sim_insertion_human
```

## 数据集：录制更快，训练更快

本次发布给数据流水线带来了重大性能提升，数据采集和训练都显著加快。

### 流式视频编码

以前录制数据集意味着每个 episode 结束后要等视频编码完成。**现在不了。** 有了流式视频编码，帧在采集的同时就实时编码——**episode 之间零等待**。刚结束一个 episode，马上就能开始下一个。

流式编码还支持**硬件编码器自动检测**：如果你的系统有 GPU 加速的视频编码器，LeRobot 会自动用上：

```
dataset = LeRobotDataset.create(
    repo_id="my/dataset",
    fps=30,
    video_backend="auto",       # Auto-detect best HW encoder
    streaming_encoding=True,    # Encode in real-time
)
```

> 流式编码的性能因硬件和录制配置（摄像头数量、分辨率等）差异很大。启用前务必阅读流式视频编码文档。

### 图像训练快 10 倍、编码快 3 倍

在底层，我们修复了关键的数据访问瓶颈并彻底重做了图像处理：

- **图像训练快 10 倍**：改进图像变换支持，修复一直在悄悄拖慢训练的数据访问瓶颈。
- **编码快 3 倍**：所有平台默认并行编码，不使用流式时还有动态压缩级别，按数据集类型（视频 vs. 图像）自适应。
- **更好的 CPU 利用率**：录制和创建数据集时资源使用更高效。

### 新数据集工具

数据集编辑工具箱持续壮大：

- **子任务支持**：对 episode 内的子任务做标注和查询，用于层级任务学习。
- **图像转视频**：把现有图像数据集转换为视频格式以获得更高存储效率，支持一个视频文件多个 episode。
- **更多编辑操作**：新增用于检查数据集的 `info` 操作、任务修改工具，并修复了现有操作（拆分、合并、特征编辑）的大量问题。
- **暴露更多选项**：可配置视频编解码器、容差设置和 metadata 缓冲区大小，对数据集创建实现精细控制。

## EnvHub：来自 Hub 的环境

**EnvHub** 是 LeRobot 使用仿真环境的新方式：直接从 Hugging Face Hub 加载。不必在本地安装环境包并接线注册，现在只要把 LeRobot 指向一个 Hub 仓库，它就包办一切——下载环境代码、注册到 Gymnasium、供训练和评估使用。

Hub 环境使用 `HubEnvConfig`，它下载并执行远程的 `make_env` 函数：

```
lerobot-train \
  --env.type=hub \
  --env.hub_path="username/my-custom-env" \
  --policy.type=act
```

这降低了向社区分享自定义仿真环境的门槛。把你的环境打包、推到 Hub，任何人都能在上面训练。更多信息看[文档](https://huggingface.co/docs/lerobot/envhub)。这里有个上手示例：[LeIsaac x LeRobot EnvHub 教程](https://huggingface.co/docs/lerobot/envhub_leisaac)。

### NVIDIA IsaacLab-Arena

我们集成了 **NVIDIA IsaacLab-Arena**，把 GPU 加速仿真带入 LeRobot。IsaacLab-Arena 提供一套运行在 NVIDIA Isaac Sim 上的操作任务，给出大规模并行的环境实例，用于快速强化学习。集成包含专门的预处理/后处理步骤，并与 LeRobot 训练流水线完全兼容。查看[文档](https://huggingface.co/docs/lerobot/envhub_isaaclab_arena)。

## 代码库：现代化的地基

本次发布让代码库现代化：

- **Python 3.12+**：LeRobot 现以 Python 3.12 为最低版本，启用现代语法和更好性能。
- **Transformers v5**：我们迁移到 Hugging Face Transformers v5，紧跟最新模型生态。
- **第三方策略插件**：和 v0.4.0 的硬件插件系统一样，你现在可以把自定义策略注册为可安装包——`pip install lerobot_policy_mypolicy`，然后用 `--policy.type=mypolicy`。无需改动核心库。方法见[文档](https://huggingface.co/docs/lerobot/bring_your_own_policies)。
- **远程 Rerun 可视化**：用 Rerun 远程可视化机器人遥测数据，支持压缩图像以节省带宽。
- **安装改进**：新增 `uv` [安装说明](https://huggingface.co/docs/lerobot/installation)、澄清配置步骤、改进依赖管理。顺序安装步骤现在有了清晰的文档。
- **文档版本化**：文档现在带版本，你总能找到与所装发布版匹配的文档。
- **PyTorch 版本上调**：更新 PyTorch 版本范围，支持 NVIDIA Blackwell GPU。
