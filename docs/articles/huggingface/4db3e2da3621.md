以 ChatGPT 为代表的生成式 AI 与 LLM 的兴起，提升了 embedding 模型在各种任务（尤其是检索增强生成，如搜索或与你的数据对话）中的关注度与重要性。Embedding 之所以有用，是因为它把句子、图像、词等表示为数值向量，让我们能映射语义相关的项目、检索有用信息，从而为提示提供相关上下文，改善生成的质量与针对性。

相比 LLM，Embedding 模型体积更小、推理更快。这一点非常重要：在你更换模型或通过微调改进模型后，需要重新生成 embedding。此外，整个检索增强流程要尽可能快，才能提供良好的用户体验。

在这篇博文中，我们将演示如何用 [Text Embedding Inference](https://github.com/huggingface/text-embeddings-inference) 把开源 Embedding 模型部署到 [Hugging Face Inference Endpoints](https://ui.endpoints.huggingface.co/)——我们的托管 SaaS 方案，让模型部署变得简单。另外，我们还会教你如何做大规模批量请求。

开始之前，先温习一下 Inference Endpoints 的知识。

## 1. 什么是 Hugging Face Inference Endpoints？

[Hugging Face Inference Endpoints](https://ui.endpoints.huggingface.co/) 提供了一种简单安全的方式，把机器学习模型部署到生产环境。Inference Endpoints 让开发者与数据科学家无需管理基础设施就能构建生成式 AI 应用：把部署流程简化为几次点击，包括用自动扩缩容应对海量请求、用 scale-to-zero 降低基础设施成本、并提供企业级安全。

以下是最重要的几个特性：

- [简单部署](https://huggingface.co/docs/inference-endpoints/index)：几次点击即可把模型部署为生产就绪的 API，无需操心基础设施或 MLOps。
- [成本效率](https://huggingface.co/docs/inference-endpoints/autoscaling)：享受自动缩容到零的能力，endpoint 闲置时缩掉基础设施以降低成本，同时按 endpoint 在线时长计费，确保经济性。
- [企业安全](https://huggingface.co/docs/inference-endpoints/security)：把模型部署在安全、离线的 endpoint 中，仅可通过 VPC 直连访问，有 SOC2 Type 2 认证背书，并提供 BAA 与 GDPR 数据处理协议，强化数据安全与合规。
- [LLM 优化](https://huggingface.co/text-generation-inference)：为 LLM 优化——借助 Text Generation Inference 的 Paged Attention 实现高吞吐、通过自定义 transformers 代码与 Flash Attention 实现低延迟。
- [任务覆盖全面](https://huggingface.co/docs/inference-endpoints/supported_tasks)：开箱即用地支持 🤗 Transformers、Sentence-Transformers 与 Diffusers 的任务与模型，并可轻松定制以启用说话人分离等高级任务及任意 ML 任务与库。

在 [https://ui.endpoints.huggingface.co/](https://ui.endpoints.huggingface.co/) 开始使用 Inference Endpoints。

## 2. 什么是 Text Embeddings Inference？

[Text Embeddings Inference（TEI）](https://github.com/huggingface/text-embeddings-inference#text-embeddings-inference)是为部署和服务开源文本 embedding 模型量身打造的方案。TEI 面向高性能抽取，支持最流行的模型。TEI 支持 [MTEB（Massive Text Embedding Benchmark）排行榜](https://huggingface.co/spaces/mteb/leaderboard)前 10 的全部模型，包括 FlagEmbedding、Ember、GTE 和 E5。TEI 目前实现了以下性能优化特性：

- 没有模型图编译步骤
- 小巧的 docker 镜像与快速启动。为真正的 serverless 做好准备！
- 基于 token 的动态批处理
- 用 [Flash Attention](https://github.com/HazyResearch/flash-attention)、[Candle](https://github.com/huggingface/candle) 与 [cuBLASLt](https://docs.nvidia.com/cuda/cublas/#using-the-cublaslt-api) 优化的推理 transformers 代码
- [Safetensors](https://github.com/huggingface/safetensors) 权重加载
- 生产就绪（基于 Open Telemetry 的分布式追踪、Prometheus 指标）

这些特性带来了业界领先的吞吐与成本表现。在一项针对 [BAAI/bge-base-en-v1.5](https://huggingface.co/BAAI/bge-base-en-v1.5) 的基准中——Nvidia A10G Inference Endpoint、序列长度 512 token、batch size 32——我们达到了 450+ req/sec 的吞吐，折合成本 $0.00156 / 1M tokens，或 $0.00000156 / 1k tokens。这比 OpenAI Embeddings（$0.0001 / 1K tokens）便宜 64 倍。

[![Performance](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/168_inference_endpoints_embeddings/performance.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/168_inference_endpoints_embeddings/performance.png)

## 3. 把 Embedding 模型部署为 Inference Endpoint

开始之前，你需要用绑定了付款方式的个人或组织账户登录（可[在此](https://huggingface.co/settings/billing)添加），然后访问 Inference Endpoints：[https://ui.endpoints.huggingface.co](https://ui.endpoints.huggingface.co/endpoints)

点击 "New endpoint"。选择仓库、云与区域，调整实例与安全设置并部署——本例是 `BAAI/bge-base-en-v1.5`。

[![create-model](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/168_inference_endpoints_embeddings/create-model.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/168_inference_endpoints_embeddings/create-model.png)

Inference Endpoints 会根据模型大小建议一个实例类型，理论上应足以运行模型。这里是 `Intel Ice Lake 2 vCPU`。要复现我们跑的基准性能，请把实例改为 `1x Nvidia A10G`。

*注意：如果无法选择该实例类型，需要[联系我们](mailto:api-enterprise@huggingface.co?subject=Quota%20increase%20HF%20Endpoints&body=Hello,%0D%0A%0D%0AI%20would%20like%20to%20request%20access/quota%20increase%20for%20%7BINSTANCE%20TYPE%7D%20for%20the%20following%20account%20%7BHF%20ACCOUNT%7D.)申请实例配额。*

[![Select Instance](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/168_inference_endpoints_embeddings/select-instance.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/168_inference_endpoints_embeddings/select-instance.png)

然后点击 "Create Endpoint" 即可部署模型。1-3 分钟后，Endpoint 应已上线并可处理请求。

## 4. 向 endpoint 发送请求创建 embeddings

Endpoint 概览页提供 Inference Widget 入口，可以手动发送请求。这让你能快速用不同输入测试 Endpoint，并可把它分享给团队成员。

[![Test Model](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/168_inference_endpoints_embeddings/test-model.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/168_inference_endpoints_embeddings/test-model.png)

*注意：TEI 目前不会自动截断输入。你可以在请求中设置 `truncate: true` 来启用。*

除 widget 外，概览页还提供 cURL、Python 和 Javascript 代码片段，用于向模型发送请求。代码片段展示的是单次请求，但 TEI 也支持批量请求——同时发送多个文档以提高 endpoint 利用率。下面是开启截断的批量请求示例。

```
import requests

API_URL = "https://l2skjfwp9punv393.us-east-1.aws.endpoints.huggingface.cloud"
headers = {
    "Authorization": "Bearer YOUR TOKEN",
    "Content-Type": "application/json"
}

def query(payload):
    response = requests.post(API_URL, headers=headers, json=payload)
    return response.json()
    
output = query({
"inputs": ["sentence 1", "sentence 2", "sentence 3"],
"truncate": True
})

# output [[0.334, ...], [-0.234, ...]]
```

## 结论

Hugging Face Inference Endpoints 上的 TEI 让最先进 embedding 模型的部署既有闪电速度又极致省钱。业界领先的 450+ req/sec 吞吐和低至 $0.00000156 / 1k tokens 的成本，相比 OpenAI Embeddings 带来 64 倍的节省。

对利用文本 embedding 实现语义搜索、聊天机器人、推荐等的开发者与公司来说，Hugging Face Inference Endpoints 消除了基础设施负担，以最低成本交付高吞吐，让从研究到生产的流程更顺畅。
