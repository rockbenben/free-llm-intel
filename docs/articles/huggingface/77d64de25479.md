# 一键从 Hugging Face 进入 Amazon SageMaker Studio

今天，我们很高兴宣布 [Hugging Face](https://huggingface.co/) 与 [Amazon SageMaker AI](https://aws.amazon.com/sagemaker/ai/studio/) 之间的深链（deep-link）集成。开发者现在只需一次点选，就能从模型发现直接进入 SageMaker Studio 的动手实验环节。无论你是在 [Amazon SageMaker JumpStart](https://aws.amazon.com/sagemaker/ai/jumpstart/) 上微调基础模型（FM），还是将其部署到 [Amazon SageMaker Inference](https://aws.amazon.com/sagemaker/ai/deploy/) 推理端点，现在都可以直接落入相应的 SageMaker Studio 工作流。你选择的模型会被预先加载，环境也已完全配置好、随时可用。

此前，在 Hugging Face 上发现模型后要在 SageMaker Studio 上开始使用，需要在多个步骤之间来回切换：在 AWS Console 中打开 Amazon SageMaker AI、创建域（domain）、配置 IAM 权限，有时还要申请 GPU 配额。对于希望快速迭代的开发者来说，这种摩擦拖慢了从灵感走向实验的路径。这次集成打通了从发现到企业级部署的更直接路径。

> "在 Arcee，我们构建开放模型，让开发者和企业能够真正拥有他们所运行的东西：检查权重、用自己的数据做后训练、按自己的方式部署。这次集成把这一承诺送到了'最后一公里'。从 Hugging Face 上的开放模型一键直达 SageMaker Studio，然后在你自己的 AWS 环境里微调或部署它，无需任何接线配置——这正是开放模型此前缺失的体验。你拥有的开放权重，运行在你控制的云上。这正是我们的客户一直在寻求的组合。"

— Mark McQuade，Arcee AI 创始人兼 CEO

随着一键 Studio 落地体验的推出，在受支持的 Hugging Face 模型页上选择 *Customize on SageMaker AI* 或 *Deploy on SageMaker AI*，会直接把你带到控制台。SageMaker AI 随后会在数秒内自动创建一个预配置好权限的新域，并把模型上下文一路带过来。

## 新特性

本次发布带来三项能力，缩短了从 Hugging Face 模型到可用 SageMaker Studio 工作流的路径。

### 从 Hugging Face 深链进入 SageMaker Studio

当你在 Hugging Face 上浏览模型时，现在会在受支持的模型旁看到直接映射到 SageMaker Studio 工作流的操作按钮：

- **Customize on SageMaker AI** 会在 Studio 中打开模型定制（Model Customization）页面，所选模型已预加载，可随时微调。
- **Deploy on SageMaker AI** 会在 Studio 中打开部署（Deployment）页面，模型已为端点部署预配置好。

每个入口都会保留上下文，意味着进入 Studio 后你无需再次搜索该模型。

### 预配置权限

通过此流程创建的新 Studio 环境已针对 SageMaker AI 的完整能力范围配置好权限，包括模型定制、训练任务、notebook 实验和端点部署。一条新的托管策略 [AmazonSageMakerModelCustomizationCoreAccess](https://aws.amazon.com/about-aws/whats-new/2026/01/quick-setup-model-customization-sagemaker-studio/) 会自动为你创建并附加。它为使用监督微调（SFT）、直接偏好优化（DPO）、带可验证奖励的强化学习（RLVR）以及基于 AI 反馈的强化学习（RLAIF）的无服务器模型定制任务提供权限，并支持部署到 SageMaker AI 或 Amazon Bedrock 端点。这免去了你在开始实验之前手动创建和配置 AWS Identity and Access Management（IAM）角色与策略的需要。对于已有的 Studio 环境，带有文档直链的可操作提示消息会引导你添加这些权限。

### GPU 配额可见性

在为部署或训练选择实例类型时，Studio UI 现在会直接在实例选择列表中显示配额可用性。你可以立即看到在你账号当前限额下哪些 GPU 实例类型（G5、G6）可用，无需再单独前往 Service Quotas。如果仍需申请提升限额，你会被直接重定向到对应实例类型的 Service Quotas 页面。

## 实操演示：从 Hugging Face 深链到 SageMaker Studio

让我们完整走一遍从 Hugging Face 出发定制或部署模型的体验。

### 第 1 步：发现并选择

在 Hugging Face 模型页上，点击 "Deploy" 并选择 "Amazon SageMaker AI"。如果该模型受支持，你会看到两个按钮："Deploy on SageMaker AI" 和 "Customize on SageMaker AI"。接着为一个受支持的模型选择 "Customize on SageMaker AI"。

[![Hugging Face model page showing the Customize on SageMaker AI button for a supported model](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/07/06/ML-21254-1.png)](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/07/06/ML-21254-1.png)

### 第 2 步：登录

系统会提示你使用现有凭证登录 AWS。如果你已有活动的控制台会话，这一步会自动跳过。更多信息参见 [Sign in to the AWS Management Console](https://docs.aws.amazon.com/signin/latest/userguide/how-to-sign-in.html)。

### 第 3 步：进入 Studio

你会直接到达 SageMaker Studio 内的模型定制页面，模型已预先选中。接下来配置你的微调参数，例如训练数据、超参数和实例类型，然后提交定制任务。

[![SageMaker Studio Model Customization page with the selected model pre-loaded and fine-tuning parameters ready to configure](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/07/06/ML-21254-2.png)](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/07/06/ML-21254-2.png)

或者，选择 **Deploy on SageMaker AI** 会在 Studio 中打开端点部署页面，模型已预配置好。选择你的实例类型（含配额可见性），检查设置，然后部署。

[![SageMaker Studio endpoint deployment page with the model pre-configured and instance type selection showing quota visibility](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/07/06/ML-21254-3.png)](https://d2908q01vomqb2.cloudfront.net/f1f836cb4ea6efb2a0b1b99f41ad8b103eff4b59/2026/07/06/ML-21254-3.png)

### 第 4 步：测试你的端点

部署端点之后，可直接通过 Studio 的端点[测试界面](https://docs.aws.amazon.com/sagemaker/latest/dg/manage-endpoints-studio-test.html)测试推理。

## 开始使用

你今天就可以体验这一流程：

- 在 Hugging Face 上浏览模型。
- 在受支持的模型上寻找 **Customize on SageMaker AI** 或 **Deploy on SageMaker AI** 按钮。
- 选择并跟随简化的登录流程。
- 在一个完全配置好的 SageMaker Studio 环境中开始构建。

## 结语

一键 Studio 落地体验的推出，把发现模型与动手实验之间的摩擦降到了最低。通过把 Hugging Face 直接连到 SageMaker Studio 工作流，开发者可以保持心流状态：没有上下文切换，没有手动环境配置，也没有权限排障。

要开始使用，请访问 [Amazon SageMaker Studio](https://aws.amazon.com/sagemaker/ai/studio/) 页面，或在 Hugging Face 上浏览模型并选择 Deploy 或 Customize on SageMaker AI。
