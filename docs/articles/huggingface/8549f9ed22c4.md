# Grabette：一个记录机器人操作数据的开放系统
 *一起来构建共享数据集。*

*用一只手持夹爪，几分钟内记录你自己的操作任务，自动把它们转成机器人可用的数据集，并帮助壮大一个开放、协作的机器人学习数据集。*

## 瓶颈不在模型，在数据

机器人学习有一个供给问题。我们有能打的策略架构（基于 transformer 的 VLA、diffusion 与 flow-matching 策略，甚至有 world model），也有训练它们的 GPU。缺的是大规模、多样化、真实世界的操作数据。

遥操作机器人去采数据既昂贵又费力：首先，*你得先**有一台机器人***。而且取决于遥操作方式，采数据对用户可能很枯燥——一采就是几个小时，还牵扯大量硬件和调度难题。考虑到所需任务和环境的多样性，这很难扩展。

但**采集机器人数据不需要机器人**。只需要一只手、一个夹爪、一个相机，以及一条恢复手部 6-DoF 轨迹的办法。把演示录下来，你就有了机器人能学的数据。

这就是我们今天发布的东西：Grabette，一个开放、低成本的操作性数据记录系统。拿起来，用自己的手录一个任务，交回给你一份干净、机器人可用的数据集。没有机器人，没有实验室，没有遥操作台架。

而更大的目标正在于此：如果录一段演示像拍一段视频一样简单，人人都能参与贡献。我们希望 Grabette 播下一个**大型、开放、协作的操作数据集**——一个任何单一实验室都建不起来的数据集。

## 站在 UMI 的肩膀上

Grabette 直接受斯坦福的 [**Universal Manipulation Interface**（UMI）](https://umi-gripper.github.io/)启发：一只手持夹爪配鱼眼相机，在真实环境中记录演示，用 SLAM 恢复相机轨迹，再从中训练视觉运动策略。

UMI 证明了这套配方行得通。也存在其他（闭源的）设备，比如 Agibot 的 MEgo 夹爪、Genrobot 的 DAS 夹爪、Sunday Robotics 的技能捕捉手套。我们的目标是把它变得毫不费力地使用，把从「我有一个任务」到「我有一个训练好的模型」之间的门槛压到最低。

Grabette 建在现代开源生态之内：数据集用 LeRobot，共享走 Hugging Face Hub，处理流水线**在你的浏览器里**跑——什么都不用装。Grabette 是那种谁都能在工作台上攒一台、到野外去用、并把数据贡献回来的东西。

## 认识 Grabette

我们开发 Grabette 已有数月，觉得它已经足够好用、可以拿出来分享了。现在很高兴介绍给你们！

Grabette 是一只**手持夹爪**，配备了重建一段操作演示所需的一切。

它带**两个相机，各司其职**。把两个角色分开是刻意的：便宜的大广角鱼眼给策略提供它需要的、上下文丰富的腕部相机视角；RGBD 相机则承担稳健 6-DoF 追踪的硬活。

Grabette 在用户执行任务时记录数据，而执行学来的动作则依靠它的机器人对应物。所以，介绍一下 **Gripette**——Grabette 的机器人臂末端执行器孪生兄弟。

这一家族共享同样的硬件基因：

- **Grabette**，手持演示记录设备（相机 + IMU + 夹爪，BOM 成本约 490€）
- **Gripette**，电动夹爪（相机 + 两个舵机，BOM 成本约 120€），在真实或仿真机器人臂上闭合整个回路

*手持记录设备 Grabette（左）与机器人夹爪 Gripette（右）*

## 为人人而建

**一切皆开源**

[去看仓库！](https://github.com/pollen-robotics/grabette)

- **硬件**：Grabette 和 Gripette 的 CAD 与生产文件
- **采集服务**：设备上的 Raspberry Pi 软件
- **处理流水线**：本地跑，或通过我们的 Hugging Face Space 在线跑
- **下游示例栈**：原版 LeRobot 训练 + OpenArm 评估，作为参考

**元器件。** 标准传感器随处可买，没有封闭流水线，没有 fork 绑定。一块 Raspberry Pi、一个标准 Pi 相机、一个现成的 OAK-D 深度相机、磁编码器。全部要点在于：任何人都能从能直接下单的零件攒出一台。

**设计上与机器人无关。** 无论是采集还是数据格式，都不假设特定的机械臂。演示以相机局部坐标的 6-DoF 笛卡尔位姿加夹爪状态存储，输出是 Hugging Face Hub 上的标准 LeRobot 数据集，因此同一份数据可以驱动不同的机器人、不同的学习方法。当然，你的臂上还是需要配一只对应的 Gripette 夹爪。

## 从你的手到数据集，只需两步

这次发布让任何人都能快速、无需既有经验地从「我想演示一个任务」走到「我有训练就绪的数据集」。

### 1. 录制

![web_processing](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/grabette/start_session.gif) ![record_coffee](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/grabette/record_coffee_convert_small.gif)

按下按钮，观测相机、追踪相机（彩色、深度和 IMU）以及夹爪编码器关节值的数据同时开始记录，用单一共享时钟确保同步。再按一次按钮停止本次 episode，数据保存在 Raspberry Pi 本地。

### 2. 直接在浏览器里处理

[![browser-post-process](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/grabette/Browser_postprocess_small2.gif)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/grabette/Browser_postprocess_small2.gif)

在浏览器打开 Grabette 仪表盘。选中要加入数据集的 episodes，一键开始后处理。

- Episodes 上传到 HF Hub
- grabette-slam space 用 RTAB-MAP 库执行 SLAM，并校验轨迹是否正确（无跳变、无跟踪丢失）
- Episodes 转换为 LeRobot 格式
- 一个新数据集上传到你的 space，在那里你可以用 LeRobot 可视化器查看每个 episode 的数据

现在一切就绪，可以开始训练了！

## 现在轮到你了

数据瓶颈不会由一个实验室解决，而是由一个到处记录演示的社区解决。你现在就能帮忙建设这个数据集：造一台 Grabette，录制你感兴趣的任务，把它们分享到 Hub 上。每一条 episode 都让开放数据集更大、更多样；每一位贡献者都让机器人学习少一分被昂贵硬件卡住。
