# Timm ❤️ Transformers：在 transformers 中使用任意 timm 模型

为**任意** `timm` 模型获得极速推理、快速量化、`torch.compile` 加速和轻松微调——全部就在友好的 🤗 `transformers` 生态里。

主角是 [`TimmWrapper`](https://huggingface.co/docs/transformers/main/en/model_doc/timm_wrapper)——一个简单却强大的工具，把这份潜力释放出来。

本文将覆盖：

- timm 集成是怎么工作的、为什么它是游戏规则的改变者。
- 如何把 `timm` 模型接入 🤗 `transformers`。
- 实战示例：pipelines、量化、微调等等。

> 想跟着做，先安装最新版 transformers 和 timm：
> pip install -Uq transformers timm

> 完整代码示例和 notebook 请看仓库：
> 🔗 TimmWrapper Examples

## 什么是 timm？

[PyTorch Image Models（`timm`）库](https://huggingface.co/docs/timm/en/index)提供了丰富的最先进计算机视觉模型集合，外加实用的层、工具、优化器和数据增强。写作时它有超过 32K GitHub star 和超过 20 万次日下载量，是图像分类以及为目标检测、分割、图像搜索等下游任务做特征提取的首选资源。

`timm` 的预训练模型覆盖大量架构，为计算机视觉从业者简化了工作流。

## 为什么用 timm 集成？

尽管 🤗 `transformers` 支持若干视觉模型，`timm` 的收藏还要更广，包括许多 transformers 里没有的、适合移动端和高效的模型。

timm 集成补上了这个缺口，把两边的精华合到一起：

- ✅ **Pipeline API 支持**：把任意 `timm` 模型插到高层 `transformers` pipeline 里，推理一步到位。
- 🧩 **兼容 Auto Classes**：`timm` 模型虽不原生兼容 `transformers`，集成让它们与 `Auto` 类 API 无缝协作。
- ⚡ **快速量化**：约 5 行代码，即可量化**任意** `timm` 模型做高效推理。
- 🎯 **Trainer API 微调**：用 `Trainer` API 微调 `timm` 模型，甚至能接入 LoRA（低秩适配）等适配器。
- 🔁 **往返 timm**：微调后的模型可以拿回 `timm` 继续使用。
- 🚀 **Torch Compile 提速**：用 `torch.compile` 优化推理时间。

## Pipeline API：用 timm 模型做图像分类

timm 集成的亮点之一是能用上 🤗 **`pipeline` API**。`pipeline` API 抽象掉大量复杂性，几行代码就能加载预训练模型、执行推理、查看结果。

看看如何用 transformers pipeline 跑 *MobileNetV4*。这个架构没有原生 `transformers` 实现，但从 `timm` 使用轻而易举：

```
from transformers import pipeline
import requests

# Load the image classification pipeline with a timm model
image_classifier = pipeline(model="timm/mobilenetv4_conv_medium.e500_r256_in1k")

# URL of the image to classify
url = "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/timm/cat.jpg"

# Perform inference
outputs = image_classifier(url)

# Print the results
for output in outputs:
    print(f"Label: {output['label'] :20} Score: {output['score'] :0.2f}")
```

```

Label: tiger cat            Score: 0.21
Label: Egyptian cat         Score: 0.02
Label: bee                  Score: 0.00
Label: marmoset             Score: 0.00
```

## Gradio 集成：做一个食物分类演示 🍣

想快速搭一个图像分类的交互式 Web 应用？**Gradio** 用最少代码就能建出友好的界面。把 **Gradio** 和 `pipeline` API 结合，用一个微调过的 timm ViT 模型对食物图片分类（微调部分后面会讲）。

用 `timm` 模型快速搭 demo：

```
import gradio as gr
from transformers import pipeline

# Load the image classification pipeline using a timm model
pipe = pipeline(
    "image-classification",
    model="ariG23498/vit_base_patch16_224.augreg2_in21k_ft_in1k.ft_food101"
)

def classify(image):
    return pipe(image)[0]["label"]

demo = gr.Interface(
    fn=classify,
    inputs=gr.Image(type="pil"),
    outputs="text",
    examples=[["./sushi.png", "sushi"]]
)

demo.launch()
```

这里有一个托管在 Hugging Face Spaces 的在线示例，可以直接在浏览器里测！

## Auto Classes：简化模型加载

🤗 `transformers` 库用 **Auto Classes** 把加载模型和 processor 的复杂性抽象掉。有了 **`TimmWrapper`**，你可以用 **`AutoModelForImageClassification`** 和 **`AutoImageProcessor`** 轻松加载任意 `timm` 模型。

快速示例：

```
from transformers import (
    AutoModelForImageClassification,
    AutoImageProcessor,
)
from transformers.image_utils import load_image

image_url = "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/timm/cat.jpg"
image = load_image(image_url)

# Use Auto classes to load a timm model
checkpoint = "timm/mobilenetv4_conv_medium.e500_r256_in1k"
image_processor = AutoImageProcessor.from_pretrained(checkpoint)
model = AutoModelForImageClassification.from_pretrained(checkpoint).eval()

# Check the types
print(type(image_processor))  # TimmWrapperImageProcessor
print(type(model))            # TimmWrapperForImageClassification
```

## 运行量化后的 timm 模型

量化是**缩小模型体积、加速推理**的强大技术，对部署到资源受限设备尤其有用。有了 timm 集成，你可以用 [`bitsandbytes`](https://github.com/bitsandbytes-foundation/bitsandbytes) 的 **`BitsAndBytesConfig`**，几行代码就地量化任意 `timm` 模型。

量化有多简单：

```
from transformers import TimmWrapperForImageClassification, BitsAndBytesConfig

quantization_config = BitsAndBytesConfig(load_in_8bit=True)
checkpoint = "timm/vit_base_patch16_224.augreg2_in21k_ft_in1k"

model = TimmWrapperForImageClassification.from_pretrained(checkpoint).to("cuda")
model_8bit = TimmWrapperForImageClassification.from_pretrained(
    checkpoint,
    quantization_config=quantization_config,
    low_cpu_mem_usage=True,
)
```

```
original_footprint = model.get_memory_footprint()
quantized_footprint = model_8bit.get_memory_footprint()

print(f"Original model size: {original_footprint / 1e6:.2f} MB")
print(f"Quantized model size: {quantized_footprint / 1e6:.2f} MB")
print(f"Reduction: {(original_footprint - quantized_footprint) / original_footprint * 100:.2f}%")
```

**输出：**

```
Original model size: 346.27 MB  
Quantized model size: 88.20 MB  
Reduction: 74.53%  
```

量化模型推理时与全精度模型的表现**几乎一模一样**：

| **模型** | **标签** | **置信度** |
| --- | --- | --- |
| 原始模型 | remote control, remote | 0.35% |
| 量化模型 | remote control, remote | 0.33% |

## `timm` 模型的有监督微调

用 🤗 `transformers` 的 **`Trainer` API** 微调 `timm` 模型**既直接又高度灵活**。你可以用 `Trainer` 类在自定义数据集上微调模型，它负责训练循环、日志和评估。此外，你还可以用 **LoRA（Low-Rank Adaptation）**微调，以更少的参数高效训练。

本节对标准微调和 LoRA 微调做个**快速概览**，完整代码见链接。

### 用 `Trainer` API 做标准微调

`Trainer` API 用最少的代码完成训练配置。微调设置大致如下：

```
from transformers import TrainingArguments, Trainer

# Define training arguments
training_args = TrainingArguments(
    output_dir="my_model_output",
    evaluation_strategy="epoch",
    save_strategy="epoch",
    learning_rate=5e-5,
    per_device_train_batch_size=16,
    num_train_epochs=3,
    load_best_model_at_end=True,
    push_to_hub=True,
)

# Initialize the Trainer
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=train_ds,
    eval_dataset=val_ds,
    data_collator=data_collator,
    compute_metrics=compute_metrics,
)

# Start training
trainer.train()
```

这套做法妙在它与原生 `transformers` 模型的工作流完全一致，不同模型类型间保持一致性。

也就是说，你可以用熟悉的 `Trainer` API 微调不只是 Transformers 模型，而是**任意 `timm` 模型**——几乎不用改动就能把 `timm` 库的强力模型带入 Hugging Face 生态。同一套可靠工具与工作流可微调的模型范围因此大大拓宽。

**模型示例：**
在 **Food-101** 上微调的 ViT：[**`vit_base_patch16_224.augreg2_in21k_ft_in1k.ft_food101`**](https://huggingface.co/ariG23498/vit_base_patch16_224.augreg2_in21k_ft_in1k.ft_food101)

## 用 LoRA 高效微调

LoRA（Low-Rank Adaptation）让你**高效微调大模型**：只训练少量附加参数，而不是全部模型权重。这让微调更快，也能用消费级硬件。你可以用 [PEFT 库配合 LoRA](https://huggingface.co/docs/peft/main/en/conceptual_guides/lora) 微调 `timm` 模型。

设置方式：

```
from peft import LoraConfig, get_peft_model

model = AutoModelForImageClassification.from_pretrained(checkpoint, num_labels=num_labels)
lora_config = LoraConfig(
    r=16,
    lora_alpha=16,
    target_modules=["qkv"],
    lora_dropout=0.1,
    bias="none",
    modules_to_save=["head"],
)

# Wrap the model with PEFT
lora_model = get_peft_model(model, lora_config)

lora_model.print_trainable_parameters()
```

**LoRA 的可训练参数：**

```
trainable params: 667,493 || all params: 86,543,818 || trainable%: 0.77%
```

**模型示例：**
在 **Food-101** 上 LoRA 微调的 ViT：[**`vit_base_patch16_224.augreg2_in21k_ft_in1k.lora_ft_food101`**](https://huggingface.co/ariG23498/vit_base_patch16_224.augreg2_in21k_ft_in1k.lora_ft_food101)

LoRA 只是可用于 `timm` 模型的高效适配器微调方法之一。timm 与 🤗 生态的集成打开了多种**参数高效微调（PEFT）**技术的大门，你可以按用例挑最合适的方法。

## 往返集成

Ross（`timm` 的作者）最喜欢的一个特性，是这个集成保持完整的"往返"（round-trip）兼容性。也就是说，用 wrapper 可以在新数据集上以 `transformers` 的 `Trainer` 微调 timm 模型，把结果发布到 Hugging Face hub，然后再用 `timm.create_model('hf-hub:my_org/my_fine_tuned_model', pretrained=True)` 把微调模型加载回 `timm`。

看看如何用 `timm` 加载我们微调的模型 `ariG23498/vit_base_patch16_224.augreg2_in21k_ft_in1k.ft_food101`：

```
checkpoint = "ariG23498/vit_base_patch16_224.augreg2_in21k_ft_in1k.ft_food101"

config = AutoConfig.from_pretrained(checkpoint)

model = timm.create_model(f"hf_hub:{checkpoint}", pretrained=True) # Load the model with timm
model = model.eval()

image = load_image("https://cdn.britannica.com/52/128652-050-14AD19CA/Maki-zushi.jpg")

data_config = timm.data.resolve_model_data_config(model)
transforms = timm.data.create_transform(**data_config, is_training=False)

output = model(transforms(image).unsqueeze(0))

top5_probabilities, top5_class_indices = torch.topk(output.softmax(dim=1) * 100, k=5)

for prob, idx in zip(top5_probabilities[0], top5_class_indices[0]):
    print(f"Label: {config.id2label[idx.item()] :20} Score: {prob/100 :0.2f}%")
```

**输出**

```
Label: spring_rolls         Score: 0.01%
Label: sashimi              Score: 0.00%
Label: club_sandwich        Score: 0.00%
Label: cannoli              Score: 0.00%
```

## Torch Compile：立等可取的速度

有了 PyTorch 2.0 的 **`torch.compile`**，一行代码编译模型就能获得**更快的推理**。timm 集成与 `torch.compile` 完全兼容。下面用 `TimmWrapper` 对有无 `torch.compile` 的推理时间做个快速基准。

```
# Load the model and input
model = TimmWrapperForImageClassification.from_pretrained(checkpoint).to(device)
processed_input = image_processor(image, return_tensors="pt").to(device)

# Benchmark function
def run_benchmark(model, input_data, warmup_runs=5, benchmark_runs=300):
    # Warm-up phase
    model.eval()
    with torch.no_grad():
        for _ in range(warmup_runs):
            _ = model(**input_data)

    # Benchmark phase
    times = []
    with torch.no_grad():
        for _ in range(benchmark_runs):
            start_time = time.perf_counter()
            _ = model(**input_data)
            if device.type == "cuda":
                torch.cuda.synchronize(device=device)  # Ensure synchronization for CUDA
            times.append(time.perf_counter() - start_time)

    avg_time = sum(times) / benchmark_runs
    return avg_time

# Run benchmarks
time_no_compile = run_benchmark(model, processed_input)
compiled_model = torch.compile(model).to(device)
time_compile = run_benchmark(compiled_model, processed_input)

# Results
print(f"Without torch.compile: {time_no_compile:.4f} s")
print(f"With torch.compile: {time_compile:.4f} s")
```
