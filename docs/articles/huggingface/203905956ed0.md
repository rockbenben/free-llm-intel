# 使用 Hugging Face 和 NVIDIA NIM 进行无服务器推理

Philipp Schmid（philschmid）、Jeff Boudier（jeffboudier）

> 更新：该服务已于 2025 年 4 月 10 日弃用，不再可用。若要替代方案，你可以考虑 Inference Providers。

今天，我们激动地宣布上线 **Hugging Face NVIDIA NIM API（serverless）**，这是 Hugging Face Hub 上一项新服务，面向 Enterprise Hub 组织提供。这项新服务让使用开放模型变得简单，借助 [NVIDIA DGX Cloud](https://www.nvidia.com/en-us/data-center/dgx-cloud) 加速计算平台来做推理服务。我们构建这个方案，是为了让 Enterprise Hub 用户能以无服务器（serverless）的方式轻松访问最新的 NVIDIA AI 技术，在包括 Llama 和 Mistral 在内的热门生成式 AI 模型上跑推理——只需在 [Hugging Face Hub](https://huggingface.co/models) 里用标准化 API 和几行代码。

## 由 NVIDIA NIM 驱动的无服务器推理

这一全新体验建立在我们[与 NVIDIA 的合作](https://nvidianews.nvidia.com/news/nvidia-and-hugging-face-to-connect-millions-of-developers-to-generative-ai-supercomputing)之上，旨在简化在 NVIDIA 加速计算上访问和使用开放生成式 AI 模型。开发者和组织面临的主要挑战之一，是基础设施的前期成本，以及为 LLM 优化推理工作负载的复杂性。通过 Hugging Face NVIDIA NIM API（serverless），我们为这些挑战提供了一个简单的方案：即时访问为 NVIDIA 基础设施优化好的最先进开放生成式 AI 模型，并用一个简单的 API 跑推理。按量付费的定价模式确保你只需为你使用的请求时间付费，对各规模的企业都是经济的选择。

NVIDIA NIM API（serverless）与 [Train on DGX Cloud](https://huggingface.co/blog/train-dgx-cloud)（一个已经在 Hugging Face 上提供的 AI 训练服务）相辅相成。

## 它如何工作

用 Hugging Face 模型做无服务器推理从未如此简单。下面是一份手把手的上手指南：

*注意：你需要一个带 [Hugging Face Enterprise Hub](https://huggingface.co/enterprise) 订阅的组织权限才能运行推理。*

开始之前，请确认你满足以下要求：

- 你是某个 Enterprise Hub 组织的成员。
- 你为你的组织创建了一个细粒度 token。按下面的步骤创建你的 token。

### 创建一个细粒度 Token

细粒度 token 允许用户创建带特定权限的 token，从而对资源和命名空间做精确的访问控制。首先，前往 [Hugging Face Access Tokens](https://huggingface.co/settings/tokens)，点击 "Create new Token" 并选择 "fine-grained"。

输入一个 "Token name"，在 "org permissions" 里选择你的 Enterprise 组织作为 scope，然后点击 "Create token"。你不需要选择任何额外的 scope。

现在，务必保存这个 token 值，以便稍后对你的请求做认证。

### **找到你的 NIM**

你可以在受支持的生成式 AI 模型的模型页上找到 "NVIDIA NIM API (serverless)"。你可以在这个 [NVIDIA NIM Collection](https://huggingface.co/collections/nvidia/nim-66a3c6fcdcb5bbc6e975b508) 以及定价一节里找到所有受支持的模型。

我们将使用 `meta-llama/Meta-Llama-3-8B-Instruct`。前往 [meta-llama/Meta-Llama-3-8B-Instruct](https://huggingface.co/meta-llama/Meta-Llama-3-8B-Instruct) 模型卡，打开 "Deploy" 菜单，选择 "NVIDIA NIM API (serverless)"——这会打开一个界面，里面有为 Python、Javascript 或 Curl 预生成的代码片段。

### **发送你的请求**

NVIDIA NIM API（serverless）以 OpenAI API 为标准。这让你可以用 `openai` sdk 做推理。把 `YOUR_FINE_GRAINED_TOKEN_HERE` 替换为你的细粒度 token，就准备好跑推理了。

```
from openai import OpenAI

client = OpenAI(
    base_url="https://huggingface.co/api/integrations/dgx/v1",
    api_key="YOUR_FINE_GRAINED_TOKEN_HERE"
)

chat_completion = client.chat.completions.create(
    model="meta-llama/Meta-Llama-3-8B-Instruct",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Count to 500"}
    ],
    stream=True,
    max_tokens=1024
)

# Iterate and print stream
for message in chat_completion:
    print(message.choices[0].delta.content, end='')
```

恭喜！🎉 你现在可以开始用开放模型构建你的生成式 AI 应用了。🔥

NVIDIA NIM API（serverless）目前只支持 `chat.completions.create` 和 `models.list` API。我们正在扩展它，同时增加更多模型。`models.list` 可用来查看当前哪些模型可用于推理。

```
models = client.models.list()
for m in models.data:
    print(m.id)
```

## 支持的模型与定价

Hugging Face NVIDIA NIM API（serverless）的使用按每个请求花费的算力时间计费。我们 exclusively 使用 NVIDIA H100 Tensor Core GPU，定价为每小时 8.25 美元。为了让它更容易理解成按请求计费，我们可以换算为按秒。

每小时 8.25 美元 = 每秒 0.0023 美元（保留 4 位小数）

一个请求的总成本将取决于模型大小、所需 GPU 数量，以及处理请求所花的时间。下面是我们目前模型供应的明细、它们的 GPU 需求、典型响应时间，以及每个请求的估算成本：

| **Model ID** | **NVIDIA H100 GPU 数量** | **典型响应时间（500 输入 token，100 输出 token）** | **每个请求估算成本** |
| --- | --- | --- | --- |
| meta-llama/Meta-Llama-3-8B-Instruct | 1 | 1 秒 | $0.0023 |
| meta-llama/Meta-Llama-3-70B-Instruct | 4 | 2 秒 | $0.0184 |
| meta-llama/Meta-Llama-3.1-405B-Instruct-FP8 | 8 | 5 秒 | $0.0917 |

使用费用会累加到 Enterprise Hub 组织当前的月度账单周期。你可以在 Enterprise Hub 组织的账单设置中随时查看当前和过往用量。
