作为一名软件工程师兼音乐制作人，我一直在探索技术如何拓展创作表达。这份好奇心最近促使我打造了一款直接在设备端运行的个人声音生成应用——由 Arm 架构 CPU 和开源生成式 AI 模型驱动。它速度快、私密性好，能在几秒钟内从一个简单提示词生成可直接进录音棚的声音。

这个项目把几个领域的精华聚合到了一起：

- 来自 Stability AI 的 **Stable Audio Open** 模型，获取自 Hugging Face
- 由 **PyTorch** 和 **TorchAudio** 驱动的运行时
- 在 **Arm 架构 CPU** 上原生运行的快速、高效流水线
- 与 **Ableton Live** 之间顺畅的创意接力

## 一种新型的创作伙伴

当我沉浸在 Ableton Live 的音乐项目里时，不希望为了翻素材库或浏览 sound pack 而打断自己的工作流。我想要一个能到我所在之处与我会合的工具——就在心流之中。

现在，我只需描述我想象中的声音（「analog bassline」「cinematic riser」「lofi snare」），几秒之内，生成的 `.wav` 文件就会出现在我的 Ableton 浏览器里。接下来，我可以对它做微调、做成 loop，或把它变成一个乐器。

每一个声音都是独一无二的。没有人会生成和我完全一样的东西。这种个人专属感为我的创造力充了电。

## Arm 驱动：设备端、随取随用

这个声音生成器完全在设备端运行，使用 Arm 架构 CPU 技术——没有 GPU、没有云端推理、没有延迟。得益于 Arm 的能效与每瓦性能，即便在多步 diffusion 运行期间，应用依然保持流畅响应。

生成引擎建立在以下基础之上：

- Stability AI 的 [**Stable Audio Open** 模型](https://huggingface.co/stabilityai/stable-audio-open-1.0)，通过 Hugging Face 获取
- 用于模型推理与音频处理的 [**PyTorch**](https://pytorch.org/) 和 [**TorchAudio**](https://pytorch.org/audio/stable/)
- 为流畅 CPU 性能优化的多线程执行

## 示例代码：CPU 生成优化

为了在 Arm CPU 上把性能拉满，我启用了完全线程利用：

```
# Use all available Arm CPU threads
torch.set_num_threads(os.cpu_count())
```

为了在多轮生成之间保持低内存占用：

```
# Clear memory periodically
if gen_count % 3 == 0:
    gc.collect()
    print(f"Memory cleared at generation {gen_count}")
```

核心生成循环，为速度和效率做了调优：

```
output = generate_diffusion_cond(
    model,
    steps=7,                  # Reduced step count for faster inference
    cfg_scale=1,
    conditioning=conditioning,
    sample_size=sample_size,
    sigma_min=0.3,
    sigma_max=500,
    sampler_type="dpmpp-3m-sde",
    device=device
)
```

### 设备灵活性：CPU、Metal、CUDA

虽然针对 CPU 做了优化，程序在需要时也可以在 Metal（Apple Silicon）或 CUDA 上运行：

```
device = "mps"    # Apple Silicon
# device = "cuda" # NVIDIA
# device = "cpu"  # Arm CPU (default)
model = model.to(device).to(torch.float32)
```

## 与 Ableton Live 的无缝工作流

这个工具把 `.wav` 文件直接输出到由 Ableton Live 监控的项目文件夹。下面是一段 CLI 交互示例：

```
Enter a prompt for generating audio:
Ambient texture
Enter a tempo for the audio:
100
Generated audio saved to: Ambient texture.wav
```

我在 Live 的浏览器里立刻就能看到文件出现，随时可以编排、调制和变形。

## 为什么这很重要

这个项目是一个个人原型——但它也是内容创作未来的一个窗口。有了 Arm CPU 上高效的设备端 AI 推理，艺术家和开发者可以：

- 保持创作心流，不必等待云资源
- 确保数据隐私，并完全拥有产出的所有权
- 把 AI 工具延伸到边缘设备、DAW 和全新的创作界面

当开源创新遇上高效算力，就会发生这样的事情：实时生成能力，交到每一位创作者手中。
