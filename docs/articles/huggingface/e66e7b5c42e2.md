# Hugging Face 与 Google 达成开放 AI 合作

[![Hugging Face and Google partner for open AI collaboration](https://huggingface.co/blog/assets/173_gcp-partnership/thumbnail.jpg)](https://huggingface.co/blog/assets/173_gcp-partnership/thumbnail.jpg)

> 2025-11-13 更新：我们宣布了与 Google Cloud 的新的、更深度的合作，帮助企业用开放模型构建自己的 AI！

在 Hugging Face，我们希望让所有公司都能利用开放模型和开源技术构建自己的 AI。我们的目标是打造一个开放平台，让数据科学家、机器学习工程师和开发者轻松获取社区的最新模型，并在自己选择的平台内使用它们。

今天，我们非常兴奋地宣布与 Google Cloud 建立战略合作伙伴关系，共同民主化好的机器学习。我们将在开放科学、开源、云和硬件四个层面与 Google 协作，让企业能够用 Hugging Face 的最新开放模型与 Google Cloud 的最新云和硬件能力构建自己的 AI。

## 面向开放科学的合作

从最初的 Transformer 到 Vision Transformer，Google 发表了开放 AI 研究中一些最重要的贡献，推动 AI 社区一个模型一个模型地改变世界——如今在 Hugging Face 上托管的基于 transformer 的模型、数据集和 AI 应用已超过 100 万个。

我们的战略合作将放大 Google 和 Hugging Face 让最新 AI 研究更易于社区获取的努力。

## 面向开源的合作

从 TensorFlow 到 JAX，Google 贡献了一些最重要的开源工具，让研究者与数据科学家能够构建自己的 AI 模型，通过快速迭代形成模型性能持续改进的良性循环。

我们的战略合作将加速双方的协作，让你无论使用哪个框架，都能通过 Hugging Face 开源库轻松用上最新的 AI 创新。

## 面向 Google Cloud 客户的合作

如今，每月有数十万 Hugging Face 用户在 Google Cloud 上活跃，下载模型以创建生成式 AI 应用。

我们的战略合作将为 Google Cloud 客户带来新体验：在 Google Kubernetes Engine（GKE）和 Vertex AI 中轻松训练和部署 Hugging Face 模型。客户将受益于 Google Cloud 独特的硬件能力，例如 TPU 实例、由 NVIDIA H100 Tensor Core GPU 驱动的 A3 虚拟机，以及由 Intel Sapphire Rapids CPU 驱动的 C3 虚拟机。

## 面向 Hugging Face Hub 用户的合作

数百万研究者、数据科学家、开发者和 AI 爱好者每月依赖 Hugging Face Hub 轻松地创建和体验最新的 AI 模型与应用。

我们与 Google 在开放科学、开源和 Google Cloud 上的合作成果将向 Hugging Face Hub 用户开放，并在 2024 年带来一系列新体验。模型将通过 Inference Endpoints 轻松部署到 Google Cloud 生产环境；AI 构建者将能在 Hugging Face Spaces 上用 TPU 加速其应用；组织将能利用其 Google Cloud 账户轻松管理 Enterprise Hub 订阅的用量与计费。

## 接下来

我们迫不及待要把这些新体验带给大家，请关注本季度开始的系列公告！在此先分享两位 CEO 的话：

*"Google Cloud 和 Hugging Face 共享一个愿景：让生成式 AI 对开发者更易得、更有影响力。这项合作确保 Hugging Face 上的开发者可以访问 Google Cloud 专为 AI 打造的平台 Vertex AI 以及我们安全的基础设施，它们能加速下一代 AI 服务与应用的出现，"* Google Cloud CEO Thomas Kurian 表示。

*"通过这项新合作，我们将让 Hugging Face 用户和 Google Cloud 客户能够轻松地把最新的开放模型与 Google Cloud 业界领先的优化 AI 基础设施和工具（包括 Vertex AI 和 TPU）结合起来，切实提升开发者构建自己 AI 模型的能力，"* Hugging Face CEO Clement Delangue 表示。
