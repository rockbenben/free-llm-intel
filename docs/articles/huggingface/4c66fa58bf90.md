## 什么是情绪分析？

情绪分析用[机器学习](https://en.wikipedia.org/wiki/Machine_learning)自动识别人们在如何谈论某个话题。最常见的用法是检测文本极性，即自动判断一条推文、一条商品评价或一张工单是在正面、负面还是中性地谈论某事。

举些例子，看看提到 [@Salesforce](https://twitter.com/Salesforce) 的推文以及情绪分析模型会怎么打标签：

- *"The more I use @salesforce the more I dislike it. It's slow and full of bugs. There are elements of the UI that look like they haven't been updated since 2006. Current frustration: app exchange pages won't stop refreshing every 10 seconds"* --> 这条推文会被标为 "Negative"（负面）。
- *"That’s what I love about @salesforce. That it’s about relationships and about caring about people and it’s not only about business and money. Thanks for caring about #TrailblazerCommunity"* --> 相反，这条会被归类为 "Positive"（正面）。
- *"Coming Home: #Dreamforce Returns to San Francisco for 20th Anniversary. Learn more: http://bit.ly/3AgwO0H via @Salesforce"* --> 最后这条会被标为 "Neutral"（中性），因为它不含观点或极性。

直到不久前，分析与某品牌、产品或服务相关的推文还是非常手工、费劲、枯燥的过程：需要有人逐条翻找相关推文，阅读并按情绪打标签。可以想象，这不仅无法扩展、昂贵且耗时，还容易出人为错误。

好在 AI 的最新进展让企业可以用与人类相当好的机器学习模型来做推文情绪分析。借助机器学习，企业可以 7x24 实时分析推文，秒级完成数千条推文的规模化分析，更重要的是，在想什么时候要洞察就什么时候拿到洞察。

为什么要对 Twitter 做情绪分析？公司的使用场景很多，但最常见的是两类：分析用户反馈，以及监控提及以尽早发现潜在问题。

**分析 Twitter 上的反馈**

倾听客户是发现"如何改进产品或服务"洞察的关键。虽然反馈来源很多（问卷、公开评价等），但 Twitter 提供的是原始、未经过滤的反馈，直接反映受众对你产品的看法。

通过分析人们在 Twitter 上如何谈论你的品牌，你能了解他们是否喜欢你刚上线的新功能，也能感知你的定价对目标受众是否清晰。你还可以看到产品哪些方面最受喜欢、最受讨厌，用于商业决策（比如客户喜欢界面的简洁，但讨厌客服响应慢）。

**监控 Twitter 提及以检测问题**

Twitter 已成为人们分享糟糕客户体验、吐槽产品或服务故障的首选渠道。所以企业会监控用户在 Twitter 上如何提及自己的品牌，以便尽早发现问题。

通过部署一个实时分析新进提及的情绪分析模型，你可以在负面提及突然飙升时自动收到提醒。很多时候，这是正在发生、需要尽快处理的情况（比如服务器宕机导致应用不可用，或某次极差的客服体验）。

介绍了情绪分析是什么、有什么用之后，让我们撸起袖子真的做一把推文情绪分析！💥

## 如何用代码做 Twitter 情绪分析？

如今，开始 Twitter 情绪分析相当简单直接 🙌

几行代码，就能自动抓取推文、跑情绪分析并可视化结果。所有这些几分钟就能学会！

本节用一个有趣的小项目演示：对提到 [Notion](https://twitter.com/notionhq) 的推文做情绪分析！

首先用 [Tweepy](https://www.tweepy.org/)——一个开源 Python 库——通过 [Twitter API](https://developer.twitter.com/en/docs/twitter-api) 获取提到 @NotionHQ 的推文。然后用 [Inference API](https://huggingface.co/inference-api) 做情绪分析。拿到结果后，再画一些图表来可视化并发现有趣的洞察。

你可以用这个 [Google Colab notebook](https://colab.research.google.com/drive/1R92sbqKMI0QivJhHOp1T03UDaPUhhr6x?usp=sharing) 跟着做。

开始吧！💪

- 安装依赖

第一步，安装所需的依赖。你会用 [Tweepy](https://www.tweepy.org/) 收集推文，[Matplotlib](https://matplotlib.org/) 画图，[WordCloud](https://amueller.github.io/word_cloud/) 可视化高频关键词：


- 设置 Twitter 凭据

然后设置 [Twitter API 凭据](https://developer.twitter.com/en/docs/twitter-api)，用于认证 Twitter 并通过 API 自动抓取推文：

```
import tweepy
 
# Add Twitter API key and secret
consumer_key = "XXXXXX"
consumer_secret = "XXXXXX"
 
# Handling authentication with Twitter
auth = tweepy.AppAuthHandler(consumer_key, consumer_secret)
 
# Create a wrapper for the Twitter API
api = tweepy.API(auth, wait_on_rate_limit=True, wait_on_rate_limit_notify=True)
```

- 用 Tweepy 搜索推文

现在可以开始从 Twitter 收集数据了！🎉 你将用 [Tweepy Cursor](https://docs.tweepy.org/en/v3.5.0/cursor_tutorial.html) 自动收集 1,000 条提到 Notion 的推文：

```
# Helper function for handling pagination in our search and handle rate limits
def limit_handled(cursor):
    while True:
        try:
            yield cursor.next()
        except tweepy.RateLimitError:
            print('Reached rate limite. Sleeping for >15 minutes')
            time.sleep(15 * 61)
        except StopIteration:
            break
 
# Define the term you will be using for searching tweets
query = '@NotionHQ'
query = query + ' -filter:retweets'
 
# Define how many tweets to get from the Twitter API
count = 1000
 
# Search for tweets using Tweepy
search = limit_handled(tweepy.Cursor(api.search,
                       q=query,
                       tweet_mode='extended',
                       lang='en',
                       result_type="recent").items(count))
 
# Process the results from the search using Tweepy
tweets = []
for result in search:
    tweet_content = result.full_text
    tweets.append(tweet_content) # Only saving the tweet content.
```

- 用情绪分析处理推文

数据有了，接下来对推文做情绪分析！💥

你将使用 [Inference API](https://huggingface.co/inference-api)——一个简单易用的机器学习模型调用 API。有了它，你可以直接用 SOTA 模型做情绪分析，无需为机器学习搭基础设施、无需操心模型扩展性。最新（也最棒的！）开源情绪分析模型由它托管，你完全不碰 MLOps。🤩

使用 Inference API，先要定义你的 `model id` 和 `Hugging Face API Token`：

- `model ID` 用于指定用哪个模型做预测。Hugging Face 上有[400 多个多语言情绪分析模型](https://huggingface.co/models?pipeline_tag=text-classification&sort=downloads&search=sentiment)，包括各种专为推文情绪分析微调过的模型。本教程使用 [twitter-roberta-base-sentiment-latest](https://huggingface.co/cardiffnlp/twitter-roberta-base-sentiment-latest)——一个在约 1.24 亿条推文上训练、并为情绪分析微调的模型。
- 你还需要指定 `Hugging Face token`；在[这里](https://huggingface.co/join)免费注册，然后在这个[页面](https://huggingface.co/settings/tokens)复制你的 token。

```
model = "cardiffnlp/twitter-roberta-base-sentiment-latest"
hf_token = "XXXXXX" 
```

接下来，用 `model id` 和 `hf_token` 创建 API 调用：

```
API_URL = "https://api-inference.huggingface.co/models/" + model
headers = {"Authorization": "Bearer %s" % (hf_token)}

def analysis(data):
    payload = dict(inputs=data, options=dict(wait_for_model=True))
    response = requests.post(API_URL, headers=headers, json=payload)
    return response.json()
```

现在可以给每条推文做情绪分析了。🔥🔥🔥

```
tweets_analysis = []
for tweet in tweets:
    try:
        sentiment_result = analysis(tweet)[0]
        top_sentiment = max(sentiment_result, key=lambda x: x['score']) # Get the sentiment with the higher score
        tweets_analysis.append({'tweet': tweet, 'sentiment': top_sentiment['label']})
 
    except Exception as e:
        print(e)
```

## 如何不写代码做 Twitter 情绪分析？

想上手情绪分析，不需要你是开发者，也不需要会写代码。🤯

有一些很棒的无代码方案，让你几分钟内轻松做情绪分析。

本节使用 [Zapier](https://zapier.com/)——一个无代码工具，通过易用的界面连接 5,000 多个应用。你将创建一个 [Zap](https://zapier.com/help/create/basics/create-zaps)：当有人提到 Notion 时触发；Zap 接着用 [Inference API](https://huggingface.co/inference-api) 对推文做情绪分析；最后把结果保存到 Google Sheets：

- 第 1 步（触发器）：获取推文。
- 第 2 步：用情绪分析处理推文。
- 第 3 步：把结果保存到 Google Sheets。

别担心，花不了多少时间：不到 10 分钟，你就能创建并启用这个 zap，看着情绪分析结果不断出现在 Google Sheets 里。

开始！🚀

### 第 1 步：获取推文

先去[创建一个 Zap](https://zapier.com/webintent/create-zap)，配置 Zap 的第一步，也就是 *"Trigger"（触发器）* 步骤。你的场景是：有人在 Twitter 上提到 Notion 时触发。按以下步骤设置：

- 首先选择 "Twitter"，并在 "Choose app & event" 里选择事件 "Search mention"。
- 然后把你的 Twitter 账号连到 Zapier。
- 设置触发器：搜索词填 "NotionHQ"。
- 最后测试触发器，确认它能收集推文并正常运行。

Zap 的第 1 步

### 第 2 步：用情绪分析处理推文

Zap 已经能收集提到 Notion 的推文了，现在加第二步做情绪分析。🤗

你将使用 [Inference API](https://huggingface.co/inference-api)，一个简单易用的机器学习模型调用 API。用它需要定义 "model id" 和 "Hugging Face API Token"：

- `model ID` 告诉 Inference API 用哪个模型预测。本指南使用 [twitter-roberta-base-sentiment-latest](https://huggingface.co/cardiffnlp/twitter-roberta-base-sentiment-latest)——一个在约 1.24 亿条推文上训练、为情绪分析微调的模型。想用别的模型（比如其他语言的情绪分析），可以去翻[Hub 上 400 多个情绪分析模型](https://huggingface.co/models?pipeline_tag=text-classification&sort=downloads&search=sentiment)。
- 你还需要指定 `Hugging Face token`；在[这里](https://huggingface.co/join)免费注册，然后到这个[页面](https://huggingface.co/settings/tokens)复制 token。

拿到 model ID 和 Hugging Face token 后，回到你的 Zap，按以下说明配置第二步：

- 先选择 "Code by Zapier"，事件选 "Run python"（在 "Choose app and event" 里）。
- 在 "Set up action" 中，先把推文的 "full text" 添加为 "input_data"，然后把这 [28 行 Python 代码](https://gist.github.com/feconroses/0e064f463b9a0227ba73195f6376c8ed)贴进 "Code" 区。这段代码让 Zap 能调用 Inference API 并做情绪分析预测。粘贴之前请确认做了以下调整：第 5 行改成你的 Hugging Face token，即把 `hf_token = "ADD_YOUR_HUGGING_FACE_TOKEN_HERE"` 换成类似 `hf_token = "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"`；如果想换别的情绪分析模型，改第 4 行填新模型的 id。例如不用默认模型，可以用[这个模型](https://huggingface.co/finiteautomata/beto-sentiment-analysis?text=Te+quiero.+Te+amo.)做西语推文的情绪分析，把这行 `model = "cardiffnlp/twitter-roberta-base-sentiment-latest"` 改成 `model = "finiteautomata/beto-sentiment-analysis"`。
- 最后测试这一步，确认能正确预测并运行。

Zap 的第 2 步

### 第 3 步：把结果保存到 Google Sheets

Zap 的最后一步，是把情绪分析结果存进 Google Sheets 表格并可视化。📊

先在 [Google Sheets 新建一个电子表格](https://docs.google.com/spreadsheets/u/0/create)，定义以下列：

- **Tweet**：存放推文原文。
- **Sentiment**：存放情绪分析标签（如 positive、negative、neutral）。
- **Score**：存放反映模型预测置信度的数值。
- **Date**：存放推文日期（随后可用于按时间画图表）。

然后按以下说明配置最后一步：

- 在 "Choose app & Event" 中选择 Google Sheets 作为应用，事件选 "Create Spreadsheet Row"。
- 然后把你的 Google Sheets 账号连到 Zapier。
- 接着设置动作：先指定 Google Drive 的值（如 My Drive），再选择电子表格，最后选择 Zapier 要自动写入新行的工作表。之后把表格各列与自动写行时要用的值做映射。如果按我们上面的建议建了列，映射就是这样（列 → 值）：Tweet → Full Text（来自第 1 步的值）；Sentiment → Sentiment Label（来自第 2 步）；Sentiment Score → Sentiment Score（来自第 2 步）；Date → Created At（来自第 1 步）。
- 最后测试这一步，确认能往表格添加新行。确认没问题后，可以把测试行删掉。

Zap 的第 3 步

### 4. 打开你的 Zap

到这里，zap 的所有步骤都完成了！🔥

只差把它打开，让它开始收集推文、做情绪分析、并把结果存进 Google Sheets。⚡️

打开方法：点击屏幕底部的 "Publish" 按钮：

启动 Zap
