> QIMMA 先验证基准，再评测模型，确保上报的分数反映的是 LLM 真实的阿拉伯语语言能力。

🏆 [排行榜](https://huggingface.co/spaces/qimma/leaderboard) · 🔧 [GitHub](https://github.com/tiiuae/QIMMA-leaderboard.git) · 📄 [论文](https://arxiv.org/pdf/2604.03395)

如果你一直关注阿拉伯语 LLM 评测，多半已经注意到一种日益加剧的张力：基准和排行榜数量在飞速膨胀，但**我们真的在测自认为在测的东西吗？**

我们构建 **QIMMA** قمّة（阿拉伯语"顶峰"之意），就是为了系统地回答这个问题。我们没有把现有阿拉伯语基准原样聚合起来跑模型，而是在任何评测发生*之前*先套用了一套严格的质量验证流水线。结果令人清醒：即便那些被广泛使用、口碑良好的阿拉伯语基准，也包含会悄悄污染评测结果的系统性质量问题。

本文将介绍 QIMMA 是什么、怎么建起来的、我们发现了哪些问题，以及清理干净之后模型排名长什么样。

[![image](https://cdn-uploads.huggingface.co/production/uploads/66c8620a79b42e5c941b0265/JFGUze00t2twAEsj6XxCm.png)](https://cdn-uploads.huggingface.co/production/uploads/66c8620a79b42e5c941b0265/JFGUze00t2twAEsj6XxCm.png)

## 🔍 问题：阿拉伯语 NLP 评测既碎片化又未经验证

阿拉伯语的使用者超过 4 亿人，横跨多样的方言与文化语境，但阿拉伯语 NLP 的评测版图仍然十分碎片化。推动这项工作的几个主要痛点：

**翻译问题。** 许多阿拉伯语基准是从英文翻译过来的。这会引入分布偏移：在英语里自然的题目，译成阿拉伯语后变得别扭或文化错位，使基准数据无法代表阿拉伯语的真实使用方式。

**质量验证缺位。** 即便*原生*的阿拉伯语基准，发布时往往也没有经过严格的质量检查。标注不一致、错误的标准答案、编码错误、ground truth 标签中的文化偏差，都已在权威资源中被记录在案。

**可复现性缺口。** 评测脚本和逐样本输出很少公开，导致结果难以审计、也难以在先前工作之上继续建设。

**覆盖碎片化。** 现有排行榜各自覆盖孤立任务和狭窄领域，难以对模型做整体评估。

为了说明 QIMMA 相对现有平台的位置：

| 排行榜 | 开源 | 原生阿拉伯语 | 质量验证 | 编程评测 | 公开输出 |
| --- | --- | --- | --- | --- | --- |
| OALL v1 | ✅ | 混合 | ❌ | ❌ | ✅ |
| OALL v2 | ✅ | 大部分 | ❌ | ❌ | ✅ |
| BALSAM | 部分 | 50% | ❌ | ❌ | ❌ |
| AraGen | ✅ | 100% | ✅ | ❌ | ❌ |
| SILMA ABL | ✅ | 100% | ✅ | ❌ | ✅ |
| ILMAAM | 部分 | 100% | ✅ | ❌ | ❌ |
| HELM Arabic | ✅ | 混合 | ❌ | ❌ | ✅ |
| ⛰ QIMMA | ✅ | 99% | ✅ | ✅ | ✅ |

QIMMA 是唯一同时具备五项特性的平台：开源、内容以原生阿拉伯语为主、系统化质量验证、代码评测，以及公开逐样本推理输出。

## ⛰ QIMMA 里有什么？

QIMMA 把 **14 个源基准**的 **109 个子集**整合为统一评测套件，样本总量超过 **52,000**，覆盖 7 大领域：

| 领域 | 基准 | 任务类型 |
| --- | --- | --- |
| **文化** | AraDiCE-Culture、ArabCulture、PalmX | MCQ |
| **STEM** | ArabicMMLU、GAT、3LM STEM | MCQ |
| **法律** | ArabLegalQA、MizanQA | MCQ、QA |
| **医疗** | MedArabiQ、MedAraBench | MCQ、QA |
| **安全** | AraTrust | MCQ |
| **诗歌与文学** | FannOrFlop | QA |
| **编程** | 3LM HumanEval+、3LM MBPP+ | Code |

这一设计有几个亮点：

- **99% 原生阿拉伯语内容。** 唯一的例外是代码评测——它本质上是语言无关的。
- **首个带代码评测的阿拉伯语排行榜。** QIMMA 集成了 HumanEval+ 和 MBPP+ 的阿拉伯语改编版，让"用阿拉伯语题面考察编程能力"成为可能。
- **领域与任务多样。** QIMMA 评估的是真实世界的能力面：教育、治理、医疗、创作表达和软件开发。

## 🔬 质量验证流水线

这是 QIMMA 方法论的心脏。在运行任何模型之前，我们对每个基准的每个样本都应用了**多阶段验证流水线**。

### 阶段 1：多模型自动评估

每个样本由两个最先进 LLM 独立评估：

- **Qwen3-235B-A22B-Instruct**
- **DeepSeek-V3-671B**

我们特意选了两个阿拉伯语能力强、但训练数据构成不同的模型，让它们*合并*的判断比任何单个模型都更稳健。

每个模型按 **10 项评分细则**给样本打分，每项 0 或 1 分：

任一模型给某样本打出低于 7/10 的分数，该样本即被淘汰。两个模型都判定淘汰的样本直接剔除；只有一个模型标记的样本，进入阶段 2 人工复核。

### 阶段 2：人工标注与复核

被标记的样本交给**以阿拉伯语为母语**、熟悉文化与方言的评审员复核。人工标注员最终裁决：

- 文化语境与地区差异
- 方言细微差别
- 主观解读
- 自动评估可能漏掉的隐蔽质量问题

对于文化敏感内容，会综合考虑多个视角——因为"正确"在不同阿拉伯地区确实可能不同。

## ⚠️ 我们发现：系统性的质量问题

流水线揭示出各基准中反复出现的质量问题——不是孤立错误，而是反映基准原始构建过程缺陷的**系统性模式**。

### 用数字说话

| 基准 | 样本总数 | 弃用数 | 弃用率 |
| --- | --- | --- | --- |
| ArabicMMLU | 14,163 | 436 | 3.1% |
| MizanQA | 1,769 | 41 | 2.3% |
| PalmX | 3,001 | 25 | 0.8% |
| MedAraBench | 4,960 | 33 | 0.7% |
| FannOrFlop | 6,984 | 43 | 0.6% |
| ArabCulture | 3,482 | 7 | 0.2% |
| MedArabiQ | 499 | 1 | 0.2% |
| GAT | 13,986 | 1 | ~0.0% |
| 3LM STEM | 2,609 | 1 | ~0.0% |
| AraDiCE-Culture | 180 | 0 | 0.0% |
| ArabLegalQA | 79 | 0 | 0.0% |
| AraTrust | 522 | 0 | 0.0% |

### 发现的问题分类

⚖️ 答案质量

错误的或错位的 gold 索引、事实性错误答案、缺失的或原始文本形式的答案。

📄 文本与格式质量

乱码或不可辨认的文本、拼写与语法错误、重复样本。

💬 文化敏感性

强化刻板印象、对多元群体的一刀切概括。

🤝 Gold 答案合规性

gold 答案与评测协议不对齐。

## 💻 代码基准：另一种质量工作

代码基准需要的是不同的干预方式。我们没有丢弃样本，而是**精修了阿拉伯语题面**——对 3LM 的 HumanEval+ 与 MBPP+ 阿语改编版，任务标识符、参考解答和测试套件全部保持不变。

修改比例相当惊人：

| 基准 | 题目总数 | 已修改 | 未修改 | 修改率 |
| --- | --- | --- | --- | --- |
| 3LM HumanEval+ | 164 | 145 | 19 | **88%** |
| 3LM MBPP+ | 378 | 308 | 70 | **81%** |

修改分为五类：

- **语言精修**：向自然的现代标准阿拉伯语（MSA）和一致的祈使句式靠拢
- **清晰度改进**：修正含糊的指令和不清楚的约束条件
- **一致性规范化**：统一数学术语、标点和示例格式
- **结构修复**：修补断裂的三引号字符串、缩进错误、乱码片段
- **语义澄清**：明确区间是否含端点等，同时保留任务原意

## ⚙️ 评测设置

### 评测框架

QIMMA 使用 [LightEval](https://github.com/huggingface/lighteval)、[EvalPlus](https://github.com/evalplus/evalplus) 和 [FannOrFlop](https://github.com/mbzuai-oryx/FannOrFlop) 作为评测框架，选择它们是因为一致性好、多语言社区采用广、可复现。

### 按任务类型的指标

| 任务类型 | 指标 | 基准 |
| --- | --- | --- |
| **MCQ** | 归一化对数似然准确率 | AraDiCE-Culture、ArabicMMLU、ArabCulture、PalmX、3LM STEM、MedArabiQ、GAT、MedAraBench、AraTrust |
| **多选 MCQ** | Gold 选项概率质量 | MizanQA |
| **生成式 QA** | F1 BERTScore（AraBERT v02） | MedArabiQ、ArabLegalQA、FannOrFlop |
| **代码** | Pass@1 | 3LM HumanEval+、3LM MBPP+ |

### 提示词模板

QIMMA 按题目格式标准化提示词，共六种模板：

MCQ

：普通选择题 ·

MCQ-C

：带上下文短文的选择题 ·

MCQ-I

：带特定指令的选择题（GAT 类比/补全）·

QA

：普通开放式问答 ·

QA-C

：带上下文的问答 ·

QA-F

：填空题式问答

所有提示词均为阿拉伯语。MizanQA 和 ArabCulture 保留其原论文的基准专属系统提示词。

### 规模与性能的关系

在整个排行榜（46 个模型）上，规模与性能之间存在清晰但不完美的相关性。不过也有一些有意思的例外：

[![c64aafc7-1](https://cdn-uploads.huggingface.co/production/uploads/66c8620a79b42e5c941b0265/KPdYTBwzMvJEyALTYfGji.png)](https://cdn-uploads.huggingface.co/production/uploads/66c8620a79b42e5c941b0265/KPdYTBwzMvJEyALTYfGji.png)

## 🌟 QIMMA 的与众不同

总结 QIMMA 的独特属性：

| 特性 | 说明 |
| --- | --- |
| **质量优先的哲学** | 验证先于评测运行，而不是事后补救 |
| **多模型验证** | 两个训练数据不同的 LLM + 对标记样本的人工复核 |
| **99% 原生阿拉伯语** | 几乎完全避免翻译带来的伪影 |
| **多领域多任务** | 7 大领域、3 种任务类型（MCQ、QA、代码）、109 个子集 |
| **代码评测** | 首个纳入代码生成的阿拉伯语排行榜 |
| **完全透明** | 逐样本推理输出全部公开，而非只有聚合分数 |
| **基于 LightEval** | 统一、可复现的评测代码库 |
| **方言意识** | 提示词与评分细则中显式处理 MSA 与方言差异 |
