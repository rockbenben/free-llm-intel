# 迈向加密的大语言模型：FHE

本文另有[简体中文](https://huggingface.co/blog/zh/encrypted-llm)版本。

大语言模型（LLM）近来已被证明是可靠的工具，能在编程、内容创作、文本分析、网页搜索、远程学习等众多领域提升生产力。

## 大语言模型对用户隐私的影响

尽管 LLM 魅力十足，围绕这些模型处理用户查询的隐私担忧始终存在。一方面，借助 LLM 的强大能力令人向往；另一方面，存在向 LLM 服务商泄露敏感信息的风险。在医疗、金融、法律等领域，这种隐私风险是一票否决的。

对该问题的一种可能解法是本地化部署——由 LLM 所有者把模型部署在客户机器上。然而这并非最优解：构建一个 LLM 可能耗资数百万美元（[GPT3 花了 460 万美元](https://lambdalabs.com/blog/demystifying-gpt-3)），而本地化部署又有模型知识产权（IP）泄露的风险。

Zama 相信你可以鱼与熊掌兼得：我们的抱负是同时保护用户隐私和模型 IP。在这篇博客里，你将看到如何利用 Hugging Face transformers 库，让模型的一部分在加密数据上运行。完整代码见这个[用例示例](https://github.com/zama-ai/concrete-ml/tree/17779ca571d20b001caff5792eb11e76fe2c19ba/use_case_examples/llm)。

## 全同态加密（FHE）能解决 LLM 隐私难题

Zama 应对 LLM 部署挑战的方案是使用全同态加密（FHE）——它能在加密数据上执行函数。既能保护模型所有者的 IP，又能保持用户数据的私密，这个目标是可达到的。这个演示表明，用 FHE 实现的 LLM 模型能保持原始模型的预测质量。为此，需要改造 Hugging Face [transformers 库](https://github.com/huggingface/transformers)中的 [GPT2](https://huggingface.co/gpt2) 实现，用 Concrete-Python 重写推理的若干部分——它能把 Python 函数转换成对应的 FHE 等价形式。

[![Figure 1. GPT2 Architecture. Source: https://en.wikipedia.org/wiki/GPT-2](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/encrypted-llm/gpt2_architecture.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/encrypted-llm/gpt2_architecture.png)

图 1 展示了 GPT2 的架构，其结构是重复的：一系列多头注意力（MHA）层逐级叠加。每个 MHA 层用模型权重投影输入、计算注意力机制、再把注意力输出重投影成一个新张量。

在 [TFHE](https://www.zama.ai/post/tfhe-deep-dive-part-1) 中，模型权重和激活都用整数表示。非线性函数必须用可编程引导（Programmable Bootstrapping，PBS）操作实现。PBS 在加密数据上执行表查找（TLU）操作，同时刷新密文以允许[任意计算](https://whitepaper.zama.ai/)。缺点是 PBS 的计算时间远超线性操作。利用这两类操作，你可以把 LLM 计算的任意部分、乃至全部用 FHE 表达。

## 用 FHE 实现一个 LLM 层

接下来你将看到如何加密多头注意力（MHA）块中的单个注意力头。完整 MHA 块的示例也能在这个[用例示例](https://github.com/zama-ai/concrete-ml/tree/17779ca571d20b001caff5792eb11e76fe2c19ba/use_case_examples/llm)中找到。

[![Figure 2. Running parts of a Large Language Model in FHE.](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/encrypted-llm/hybrid_gpt2_visualisation.svg)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/encrypted-llm/hybrid_gpt2_visualisation.svg)

图 2 是该实现的简化概览。客户端在本地开始推理，直至共享模型中已被移除的第一层。用户把中间运算加密后发送给服务器。服务器执行部分注意力机制并把结果返回，客户端解密后可继续本地推理。

### 量化

首先，要在加密值上执行模型推理，必须把模型的权重和激活量化并转换为整数。理想做法是使用[训练后量化](https://docs.zama.ai/concrete-ml/advanced-topics/quantization)，它不需要重新训练模型。流程是：实现一个 FHE 兼容的注意力机制、使用整数与 PBS，然后考察其对 LLM 精度的影响。

为评估量化的影响，我们运行完整的 GPT2 模型，只让单个 LLM Head 在加密数据上工作。然后改变权重和激活的量化位数，评估得到的精度。

[![Single Quantized Head Attention Average Top-k Accuracy](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/encrypted-llm/qattention_accuracy.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/encrypted-llm/qattention_accuracy.png)

这张图显示 4-bit 量化能保持原始精度的 96%。实验使用约 80 个句子的数据集，指标通过比较原始模型与量化头模型的 logits 预测计算得出。

### 把 FHE 应用到 Hugging Face 的 GPT2 模型

基于 Hugging Face 的 transformers 库，重写你希望加密的模块的 forward 过程，以纳入量化算子。构建 SingleHeadQGPT2Model 实例：先加载一个 [GPT2LMHeadModel](https://huggingface.co/docs/transformers/model_doc/gpt2#transformers.GPT2LMHeadModel)，然后手动按如下方式把第一个多头注意力模块替换为 [QGPT2SingleHeadAttention](https://github.com/zama-ai/concrete-ml-internal/blob/c291399cb1f2a0655c308c14e2180eb2ffda0ab7/use_case_examples/llm/qgpt2_models.py#L191) 模块。完整实现见[这里](https://github.com/zama-ai/concrete-ml-internal/blob/c291399cb1f2a0655c308c14e2180eb2ffda0ab7/use_case_examples/llm/qgpt2_models.py)。

```
self.transformer.h[0].attn = QGPT2SingleHeadAttention(config, n_bits=n_bits)
```

随后覆写 forward，使多头注意力机制的第一个 head——包括为构造 query、key、value 矩阵所做的投影——全部用 FHE 友好的算子完成。下面的 QGPT2 模块见[这里](https://github.com/zama-ai/concrete-ml-internal/blob/c291399cb1f2a0655c308c14e2180eb2ffda0ab7/use_case_examples/llm/qgpt2_class.py#L196)。

```
class SingleHeadAttention(QGPT2):
    """Class representing a single attention head implemented with quantization methods."""


    def run_numpy(self, q_hidden_states: np.ndarray):

        # Convert the input to a DualArray instance
        q_x = DualArray(
            float_array=self.x_calib,
            int_array=q_hidden_states,
            quantizer=self.quantizer
        )

        # Extract the attention base module name
        mha_weights_name = f"transformer.h.{self.layer}.attn."

        # Extract the query, key and value weight and bias values using the proper indices
        head_0_indices = [
            list(range(i * self.n_embd, i * self.n_embd + self.head_dim)) 
            for i in range(3)
        ]
        q_qkv_weights = ...
        q_qkv_bias = ...

        # Apply the first projection in order to extract Q, K and V as a single array
        q_qkv = q_x.linear(
            weight=q_qkv_weights,
            bias=q_qkv_bias,
            key=f"attention_qkv_proj_layer_{self.layer}",
        )

        # Extract the queries, keys and vales
        q_qkv = q_qkv.expand_dims(axis=1, key=f"unsqueeze_{self.layer}")
        q_q, q_k, q_v = q_qkv.enc_split(
            3, 
            axis=-1, 
            key=f"qkv_split_layer_{self.layer}"
        )

        # Compute attention mechanism
        q_y = self.attention(q_q, q_k, q_v)

        return self.finalize(q_y)
```

模型中的其他计算仍保持浮点、非加密状态，预期由客户端在本地执行。

把预训练权重加载进这样修改后的 GPT2 模型，然后即可调用 *generate* 方法：

```
qgpt2_model = SingleHeadQGPT2Model.from_pretrained(
    "gpt2_model", n_bits=4, use_cache=False
)


output_ids = qgpt2_model.generate(input_ids)
```

例如，你可以让量化模型补全句子 "Cryptography is a"。在 FHE 中运行模型且量化精度足够时，生成输出为：

"Cryptography is a very important part of the security of your computer"

而当量化精度太低时，你会得到：

"Cryptography is a great way to learn about the world around you"

### 编译到 FHE

现在你可以用下面的 Concrete-ML 代码编译这个注意力头：

```
circuit_head = qgpt2_model.compile(input_ids)
```

运行时会打印："Circuit compiled with 8 bit-width"。这个与 FHE 兼容的配置显示了在 FHE 中执行运算所需的最大位宽。

### 复杂度

在 transformer 模型中，计算最密集的操作是注意力机制——它把 query、key、value 相乘。在 FHE 中，加密域内乘法的特性使成本进一步放大；而且随着序列长度增加，这些棘手乘法的数量以平方级增长。

对于加密头，长度 6 的序列需要 11,622 次 PBS 操作。这是一次未做性能优化的初步实验。虽然它能在几秒内运行完成，但需要相当多的算力。好在硬件会带来的 1000 倍到 10000 倍的延迟改善，让 CPU 上的几分钟变成 ASIC 上不到 100ms——只需再等几年 ASIC 问世。关于这些预测的更多信息见[这篇博客](https://www.zama.ai/post/chatgpt-privacy-with-homomorphic-encryption)。

## 结语

大语言模型在众多用例中是出色的助手工具，但其实现对用户隐私提出了重大问题。在这篇博客中，你看到了让完整 LLM 在加密数据上工作的第一步：模型可以完全运行在云端，同时用户的隐私得到充分尊重。

这一步包括把 GPT2 这类模型的特定部分转换到 FHE 领域。该实现利用 transformers 库，让你评估模型部分在加密数据上运行时对精度的影响。除了保护用户隐私，这一方法也让模型所有者能将其模型的主要部分保密。完整代码见这个[用例示例](https://github.com/zama-ai/concrete-ml/tree/17779ca571d20b001caff5792eb11e76fe2c19ba/use_case_examples/llm)。
