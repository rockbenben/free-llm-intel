我们无比兴奋地分享 Argilla 加入 Hugging Face 以来最有影响力的功能：你可以不写任何代码准备 AI 数据集，从任意 Hub 数据集起步！使用 Argilla 的 UI，你可以轻松地从 Hugging Face Hub 导入数据集、定义问题，并开始收集人类反馈。

> 还不熟悉 Argilla？Argilla 是一款免费的、开源的数据为中心（data-centric）工具。借助 Argilla，AI 开发者与领域专家可以协作构建高质量数据集。Argilla 是 Hugging Face 家族的一员，与 Hub 完全集成。想了解更多？这里有一篇介绍性博客。

为什么这个新功能对你和社区很重要？

- Hugging Face hub 上有 23 万个数据集，可作为你 AI 项目的基础。
- 它简化了从 Hugging Face 社区或专业团队收集人类反馈的过程。
- 它让数据集创建走向民主化——即使是对某个领域知识渊博但不确定会不会写代码的用户。

## 用例

这个新功能让「在 Hub 上构建高质量数据集」走向民主化：

- 如果你发布了一个开放数据集并希望社区参与贡献，把它导入一个公开的 Argilla Space，并把 URL 分享给全世界！
- 如果你想从零开始标注一个新数据集，把一个 CSV 上传到 Hub，导入你的 Argilla Space，开始打标签！
- 如果你想为微调或评估模型而筛选一个现有 Hub 数据集，把它导入 Argilla Space，开始筛选！
- 如果你想改进一个现有 Hub 数据集以造福社区，把它导入 Argilla Space，开始给反馈！

## 工作原理

首先，你需要部署 Argilla。推荐的方式是按[本指南](https://docs.argilla.io/latest/getting_started/quickstart/)部署到 Spaces。默认部署启用了 Hugging Face OAuth，意味着你的 Space 向任何 Hub 用户开放标注贡献。当你希望社区为你的数据集做贡献时，OAuth 非常合适。如果你想把标注限制在你自己和其他合作者范围内，可以查看[本指南](https://docs.argilla.io/latest/getting_started/how-to-configure-argilla-on-huggingface/)了解其他配置选项。

在 Argilla UI 中从 Hub 导入 HF 数据集

Argilla 运行起来后，登录并点击首页上的「Import dataset from Hugging Face」按钮。你可以从我们的示例数据集之一开始，或输入你想用的数据集的 repo id。

> 在这个初始版本中，Hub 数据集必须是公开的。如果你希望支持私有数据集，我们很乐意在 GitHub 上听听你的想法。

Argilla 会根据数据集的 features 自动建议一个初始配置，所以你不必从零开始，但你可以添加问题或移除不需要的字段。字段应包含你需要反馈的数据，比如文本、对话或图像。问题是你希望收集的反馈，比如标签、评分、排序或文本。所有更改都会实时显示，让你清楚看到自己正在配置的 Argilla 数据集的样子。

对结果满意后，点击「Create dataset」，按你的配置导入数据集。现在可以开始给反馈了！

你可以按照 [quickstart 指南](https://docs.argilla.io/latest/getting_started/quickstart/)亲自体验。只需不到 5 分钟！

这个新工作流简化了从 Hub 导入数据集的过程，但如果需要进一步定制，你仍然可以[用 Argilla 的 Python SDK 导入数据集](https://docs.argilla.io/latest/how_to_guides/dataset/)。
