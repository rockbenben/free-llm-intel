# 如何安装和使用 Hugging Face Unity API

本文另有中文版本 [简体中文](https://huggingface.co/blog/zh/unity-api)。

[Hugging Face Unity API](https://github.com/huggingface/unity-api) 是对 [Hugging Face Inference API](https://huggingface.co/inference-api) 的易用封装，让开发者可以在 Unity 项目中访问和使用 Hugging Face AI 模型。在这篇博客中，我们将逐步讲解安装和使用 Hugging Face Unity API 的方法。

## 安装

- 打开你的 Unity 项目
- 进入 `Window` -> `Package Manager`
- 点击 `+`，选择 `Add Package from git URL`
- 输入 `https://github.com/huggingface/unity-api.git`
- 安装完成后，Unity API 向导应当会自动弹出。如果没有，前往 `Window` -> `Hugging Face API Wizard`

- 输入你的 API key。API key 可以在你的 [Hugging Face 账号设置](https://huggingface.co/settings/tokens)中创建。
- 在 API 向导中点击 `Test API key` 测试你的 API key。
- 可选：修改 model endpoint 来更换所用模型。任何支持 inference API 的模型的 endpoint，都可以在 Hugging Face 官网上找到该模型，点击 `Deploy` -> `Inference API`，复制 `API_URL` 字段中的 url。
- 按需配置高级设置。最新信息请访问项目仓库 `https://github.com/huggingface/unity-api`
- 想查看 API 用法示例，点击 `Install Examples`。之后可以关闭 API 向导。

API 配置完成后，你就可以在脚本中调用 API 了。来看一个执行句子相似度（Sentence Similarity）任务的例子：

```
using HuggingFace.API;

/* other code */

// Make a call to the API
void Query() {
    string inputText = "I'm on my way to the forest.";
    string[] candidates = {
        "The player is going to the city",
        "The player is going to the wilderness",
        "The player is wandering aimlessly"
    };
    HuggingFaceAPI.SentenceSimilarity(inputText, OnSuccess, OnError, candidates);
}

// If successful, handle the result
void OnSuccess(float[] result) {
    foreach(float value in result) {
        Debug.Log(value);
    }
}

// Otherwise, handle the error
void OnError(string error) {
    Debug.LogError(error);
}

/* other code */
```

## 支持的任务与自定义模型

Hugging Face Unity API 目前还支持以下任务：

- [Conversation](https://huggingface.co/tasks/conversational)（对话）
- [Text Generation](https://huggingface.co/tasks/text-generation)（文本生成）
- [Text to Image](https://huggingface.co/tasks/text-to-image)（文本生成图像）
- [Text Classification](https://huggingface.co/tasks/text-classification)（文本分类）
- [Question Answering](https://huggingface.co/tasks/question-answering)（问答）
- [Translation](https://huggingface.co/tasks/translation)（翻译）
- [Summarization](https://huggingface.co/tasks/summarization)（摘要）
- [Speech Recognition](https://huggingface.co/tasks/automatic-speech-recognition)（语音识别）

使用 `HuggingFaceAPI` 类提供的相应方法来执行这些任务。

要使用你自己托管在 Hugging Face 上的自定义模型，请在 API 向导中修改 model endpoint。

## 使用建议

- 注意 API 是异步发起调用的，并通过回调返回响应或错误。
- 如果遇到响应慢或性能问题，可以把 model endpoint 换成资源占用更低的模型。
