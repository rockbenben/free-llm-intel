# 推出 Gradio 全新 Dataframe！

hannah（hmb）

Abubakar Abid（abidlabs）

Gradio 的 `gr.Dataframe` 组件是我们最受欢迎的组件之一，见过它被用在各种很棒的应用里，比如排行榜、仪表盘和交互式可视化。虽然我们已经很久没动过 dataframe 了，但积压的 issue 一直在增长，有些改进是大家期待已久的。

现在——我们特别高兴地发布 Gradio dataframe 组件的一大批更新。过去 6 周里，我们关闭了 70 多个 dataframe 相关的 issue，涵盖 bug、改进和增强。

### **1. 多单元格选择**

可以一次选中多个单元格！在你选中的范围内轻松复制或删除值。

### 2. 行号与**列固定**

用 `pinned_columns` 参数添加行号列、在浏览宽数据集时让关键列始终可见。再也不会看着看着就迷失方向了！

### **3. 复制按钮和全屏按钮**

用新的复制按钮可以把单元格值复制成逗号分隔格式。想要更大的视野？全屏按钮让你在没有干扰的情况下交互，用 `show_full_screen` 参数启用。

### 4. 回到顶部按钮

数据实在太多了！现在可以一键滚回顶部。

### **5. 无障碍升级与样式增强**

改进的键盘导航让 gr.Dataframe 的无障碍性达到新高。你还可以通过专门的 styler 参数掌控 dataframe 的外观，提升应用的用户体验。

### **6. 行选择与列选择**

select 事件中可以拿到整行数据，交互和数据处理更直观。

### 7. 静态列

用 `static_columns` 参数指定不可编辑的列，自定义 dataframe 的交互性。

### **8. 搜索功能**

把 `show_search` 参数设为 `"search"`，用强大的搜索功能快速找到你需要的数据。

### **9. 过滤功能**

把 `show_search` 设为 `"filter"`，用灵活的过滤选项把数据集缩小到你真正关心的部分。

### **10. 更好的单元格选择**

体验更顺滑、更符合直觉的单元格选择行为。

## 接下来做什么？

关闭了 70 多个 issue，我们做了巨大改进，但要做的永远还有更多。往前看，我们还有不少想法要落地，会继续在无障碍性、性能和集成方面打磨。留意 Gradio 的 [X](https://x.com/gradio) 账号，我们会发一些 dataframe 的酷炫 demo。

## 自己试试！

更新后的 dataframe 已随最新 Gradio 版本发布。用 `pip install --upgrade gradio` 升级你的安装。

```
import gradio as gr

df_headers = ["Name", "Population", "Size (min cm)", "Size (max cm)", "Weight (min kg)", "Weight (max kg)", "Lifespan (min years)", "Lifespan (max years)"]
df_data = [
    ["Irish Red Fox", 185000, 48, 92, 4.2, 6.8, 3, 5],
    ["Irish Badger", 95000, 62, 88, 8.5, 13.5, 6, 8],
    ["Irish Otter", 13500, 58, 98, 5.5, 11.5, 9, 13]
]

with gr.Blocks() as demo:
    df = gr.Dataframe(
        label="Irish Wildlife",
        value=df_data,
        headers=df_headers,
        interactive=True,
        show_search="search",
        show_copy_button=True,
        show_fullscreen_button=True,
        show_row_numbers=True,
        pinned_columns=1,
        static_columns=[0],
        column_widths=["300px"]
    )

demo.launch()
```

这些新特性的示例和入门教程请查看 [Gradio 文档](https://www.gradio.app/docs/gradio/dataframe)。我们很想看到你用它们做出什么！有想法或建议？请在我们的 [GitHub](https://github.com/gradio-app/gradio) 仓库提 issue。
