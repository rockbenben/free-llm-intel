# 使用 Optimum 在 IPU 上入门 Hugging Face Transformers

Transformer 模型已被证明在非常广泛的机器学习任务上极为高效，例如自然语言处理、音频处理和计算机视觉。然而，这些大模型的预测速度可能让它们不适合对延迟敏感的用例，如对话应用或搜索。此外，在真实世界中优化它们的性能需要相当多的时间、努力和技能，很多公司和组织难以负担。

幸运的是，Hugging Face 推出了 [Optimum](https://huggingface.co/hardware)——一个开源库，大幅降低了在多种硬件平台上减少 Transformer 模型预测延迟的难度。在这篇博客中，你将学习如何为 Graphcore 的 [Intelligence Processing Unit](https://www.graphcore.ai/products/ipu)（IPU）加速 Transformer 模型。IPU 是一种高度灵活、易于使用的并行处理器，从底层为 AI 工作负载而设计。

### Optimum 邂逅 Graphcore IPU

通过 Graphcore 与 Hugging Face 的这次合作，我们推出首个经过 IPU 优化的模型——BERT。未来几个月我们还将引入更多 IPU 优化模型，覆盖视觉、语音、翻译和文本生成等应用。

Graphcore 工程师已使用 Hugging Face transformers 在我们的 IPU 系统上实现并优化了 BERT，帮助开发者轻松训练、微调并加速其最先进模型。

### IPU 与 Optimum 入门

我们以 BERT 为例，帮助你上手 Optimum 和 IPU。

本指南使用 Graphcloud（Graphcore 的云端机器学习平台）上的 [IPU-POD16](https://www.graphcore.ai/products/mk2/ipu-pod16) 系统，并按照 [Getting Started with Graphcloud](https://docs.graphcore.ai/projects/graphcloud-getting-started/en/latest/index.html) 中的 PyTorch 设置步骤进行。

Graphcore 的 [Poplar SDK](https://www.graphcore.ai/developer) 已预装在 Graphcloud 服务器上。如果你用的是其他设置，可以在 [PyTorch for the IPU: User Guide](https://docs.graphcore.ai/projects/poptorch-user-guide/en/latest/intro.html) 中找到适用于你系统的说明。

#### 设置 Poplar SDK 环境

你需要运行以下命令来设置若干环境变量，以启用 Graphcore 工具和 Poplar 库。在最新系统（Ubuntu 18.04 上运行 Poplar SDK 2.3）上，SDK 位于 `/opt/gc/poplar_sdk-ubuntu_18_04-2.3.0+774-b47c577c2a/` 文件夹。

使用 PyTorch 时，需要同时运行 Poplar 和 PopART（Poplar Advanced Runtime）两个 enable 脚本：

```
$ cd /opt/gc/poplar_sdk-ubuntu_18_04-2.3.0+774-b47c577c2a/
$ source poplar-ubuntu_18_04-2.3.0+774-b47c577c2a/enable.sh
$ source popart-ubuntu_18_04-2.3.0+774-b47c577c2a/enable.sh
```

#### 为 IPU 设置 PopTorch

PopTorch 是 Poplar SDK 的一部分。它提供的函数可以让 PyTorch 模型只需极少代码改动即可运行在 IPU 上。按照 [Setting up PyTorch for the IPU](https://docs.graphcore.ai/projects/graphcloud-pytorch-quick-start/en/latest/pytorch_setup.html) 指南，你可以创建并激活一个 PopTorch 环境：

```
$ virtualenv -p python3 ~/workspace/poptorch_env
$ source ~/workspace/poptorch_env/bin/activate
$ pip3 install -U pip
$ pip3 install /opt/gc/poplar_sdk-ubuntu_18_04-2.3.0+774-b47c577c2a/poptorch-<sdk-version>.whl
```

#### 安装 Optimum Graphcore

现在你的环境已具备全部 Graphcore Poplar 和 PopTorch 库，接下来在该环境中安装最新的 🤗 Optimum Graphcore 包。它将作为 🤗 Transformers 库与 Graphcore IPU 之间的接口。

请确保上一步创建的 PopTorch 虚拟环境处于激活状态。终端应带有类似下方的 poptorch 环境名前缀：

```
(poptorch_env) user@host:~/workspace/poptorch_env$ pip3 install optimum[graphcore] optuna
```

#### 克隆 Optimum Graphcore 仓库

Optimum Graphcore 仓库包含在 IPU 上使用 Optimum 模型的示例代码。你应克隆该仓库并进入 `example/question-answering` 目录，那里有 BERT 的 IPU 实现。

```
$ git clone https://github.com/huggingface/optimum-graphcore.git
$ cd optimum-graphcore/examples/question-answering
```

现在，我们用 `run_qa.py` 在 SQUAD1.1 数据集上微调 [BERT](https://huggingface.co/bert-large-uncased) 的 IPU 实现。

#### 运行示例：在 SQuAD1.1 上微调 BERT

`run_qa.py` 脚本只适用于配备快速 tokenizer（由 🤗 Tokenizers 库支持）的模型，因为它使用了这类 tokenizer 的特殊功能。我们的 [BERT](https://huggingface.co/bert-large-uncased) 模型正是如此，你应把模型名作为 `--model_name_or_path` 的输入参数传入。为了使用 IPU，Optimum 会从 `--ipu_config_name` 参数所给路径中寻找 `ipu_config.json` 文件。

```
$ python3 run_qa.py \
    --ipu_config_name=./ \
    --model_name_or_path bert-base-uncased \
    --dataset_name squad \
    --do_train \
    --do_eval \
    --output_dir output \
    --overwrite_output_dir \
    --per_device_train_batch_size 2 \
    --per_device_eval_batch_size 2 \
--learning_rate 6e-5 \
--num_train_epochs 3 \
--max_seq_length 384 \
--doc_stride 128 \
--seed 1984 \
--lr_scheduler_type linear \
--loss_scaling 64 \
--weight_decay 0.01 \
--warmup_ratio 0.1 \
--output_dir /tmp/debug_squad/
```

### 深入了解 Optimum-Graphcore

#### 获取数据

获取数据集最简单的办法是使用 Hugging Face [Datasets 库](https://github.com/huggingface/datasets)，它让开发者能方便地在 Hugging Face hub 上下载和分享数据集。它还基于 git 和 git-lfs 内建数据版本管理，所以你只需指向同一个仓库，就能迭代数据的新版本。

这里的 Dataset 自带训练和验证文件，以及帮助用户确定模型执行各阶段输入的 dataset configs。参数 `--dataset_name==squad` 指向 Hugging Face Hub 上的 [SQuAD v1.1](https://huggingface.co/datasets/squad)。你也可以提供自己的 CSV/JSON/TXT 训练与评估文件，只要格式与 SQuAD 或 Datasets 库中其他问答数据集一致即可。

#### 加载预训练模型和 tokenizer

这个脚本需要一个快速 tokenizer 来把词转换成 token；如果你没传入，它会报错。供参考的受支持 tokenizer [列表](https://huggingface.co/transformers/index.html#supported-frameworks)在这里。

```
    # Tokenizer check: this script requires a fast tokenizer.
    if not isinstance(tokenizer, PreTrainedTokenizerFast):
        raise ValueError("This example script only works for models that have a fast tokenizer. Checkout the big table of models
            "at https://huggingface.co/transformers/index.html#supported-frameworks to find the model types that meet this "
            "requirement"
                  	)
```

参数 ```--model_name_or_path==bert-base-uncased``` 会加载 Hugging Face Hub 上可用的 [bert-base-uncased](https://huggingface.co/bert-base-uncased) 模型实现。

Hugging Face Hub 描述节选：

"*BERT base model (uncased)：使用掩码语言建模（MLM）目标在英语上训练的预训练模型。它于这篇论文中提出，并首次在该仓库发布。这是一个 uncased 模型：不区分 english 和 English。*"

#### 训练与验证

你现在可以使用 Optimum 中提供的 `IPUTrainer` 类，发挥 Graphcore 软硬件栈的全部能力，在 IPU 上以极少的代码改动训练模型。多亏 Optimum，你可以即插即用地用最先进的硬件训练最先进的模型。

要训练并验证 BERT 模型，把 `--do_train` 和 `--do_eval` 参数传给 `run_qa.py` 脚本。用上面的超参数执行脚本后，你会看到如下训练与验证结果：

```
"epoch": 3.0,
"train_loss": 0.9465060763888888,
"train_runtime": 368.4015,
"train_samples": 88524,
"train_samples_per_second": 720.877,
"train_steps_per_second": 2.809

The validation step yields the following results:
***** eval metrics *****
  epoch            =     3.0
  eval_exact_match = 80.6623
  eval_f1          = 88.2757
  eval_samples     =   10784
```

IPU BERT 实现的其余部分见 [Optimum-Graphcore: SQuAD Examples](https://github.com/huggingface/optimum-graphcore/tree/main/examples/question-answering)。
