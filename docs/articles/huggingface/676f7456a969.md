# 在本地构建 AI，你只需要 Dell Enterprise Hub

本周在 Dell Tech World 上，我们发布了 [Dell Enterprise Hub](https://dell.huggingface.co/) 的新版本，附带一整套模型与应用程序，让你能轻松使用 Dell AI 服务器和 AI PC 在本地构建 AI。

## 随时可用的模型

如果你今天访问 Dell Enterprise Hub，你会发现一些最受欢迎的模型，例如 [Meta Llama 4 Maverick](https://dell.huggingface.co/authenticated/models/meta-llama/Llama-4-Maverick-17B-128E-Instruct)、[DeepSeek R1](https://dell.huggingface.co/authenticated/models/deepseek-ai/deepseek-r1) 或 [Google Gemma 3](https://dell.huggingface.co/authenticated/models/google/gemma-3-27b-it)，只需几次点击即可完成部署和训练。

但你得到的远不止一个模型，而是一个针对特定 Dell AI 服务器平台完全测试并优化过的容器，并附带简单的说明，可用 Docker 和 Kubernetes 在本地部署。

![Meta Llama 4 Maverick available for Dell AI Server platforms](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/dell-ai-applications/dell-blog-1.png)
 *Meta Llama 4 Maverick 可部署在搭载 NVIDIA H200 或 AMD MI300X 的 Dell PowerEdge 服务器上*

我们与 Dell CTIO 及工程团队持续合作，尽可能快地让最新最好的模型在 Dell AI 服务器平台上完成准备、测试与优化——Llama 4 模型在 Meta 公开发布后 1 小时内即已上线 Dell Enterprise Hub！

## 推出 AI 应用程序

Dell Enterprise Hub 现在提供可直接部署的 AI 应用程序！

如果说模型是引擎，那么应用程序就是让它变得有用、能真正带你去远方的汽车。借助新的应用目录（Application Catalog），你可以构建完全在本地运行的强大应用，为员工服务，并使用你的内部数据与服务。

新的 [Application Catalog](https://dell.huggingface.co/authenticated/apps) 让在私有网络内部署领先开源应用变得简单，其中包括 [OpenWebUI](https://github.com/open-webui/open-webui) 和 [AnythingLLM](https://anythingllm.com/)。

[OpenWebUI](https://dell.huggingface.co/authenticated/apps/openwebui) 让你轻松部署本地聊天助手，通过 MCP 连接到你的内部数据与服务，构建能够搜索网络、借助向量数据库和存储检索内部数据的 agentic 体验，以支持 RAG 场景。

[AnythingLLM](https://dell.huggingface.co/authenticated/apps/anythingllm) 让你轻松构建强大的 agentic 助手，可连接多个 MCP 服务器，从而连接你的内部系统甚至外部服务。它包含多项功能：启用多个模型、处理图像与文档，并为你内部的用户设置基于角色的访问控制。

这些应用可使用随附的、可自定义的 helm chart 轻松部署，因此你的 MCP 服务器从一开始就已注册好。

## 由 NVIDIA、AMD 和 Intel 提供支持

Dell Enterprise Hub 是全球唯一一个针对最新 AI 加速器硬件提供即用型模型部署方案的平台：

- 搭载 NVIDIA H100 和 H200 GPU 的 Dell 平台
- 搭载 AMD MI300X 的 Dell 平台
- 搭载 Intel Gaudi 3 的 Dell 平台

我们与 Dell、NVIDIA、AMD 和 Intel 直接合作，因此当你在系统上部署容器时，一切都已配置就绪、经过完整测试和基准评测，能够在你的 Dell AI 服务器平台上开箱即用地以最佳性能运行。

## 面向 Dell AI PC 的端侧模型

新的 Dell Enterprise Hub 除了支持 AI 服务器外，现在还新增了让模型在 Dell AI PC 上端侧运行的支持！

这些模型支持端侧语音转写（OpenAI whisper）、聊天助手（Microsoft Phi 和 Qwen 2.5）、图像超分以及生成 embeddings。

要部署模型，你可以按照针对你所选 Dell AI PC 的具体说明操作——这些 PC 由 Intel 或 Qualcomm NPU 提供支持——并使用新的 [Dell Pro AI Studio](https://www.dell.com/en-us/lp/dell-pro-ai-studio)。再配合 Microsoft Intune 之类的 PC 群组管理系统，对于 IT 组织来说，这是一套为员工赋能力端侧 AI 能力的完整方案。

## 现新增 CLI 与 Python SDK

Dell Enterprise Hub 提供了一个面向 Dell AI 服务器平台和 AI PC 的 AI 能力在线门户。但如果你想直接从你的开发环境开始工作呢？

推出新的 [dell-ai 开源库](https://github.com/huggingface/dell-ai)，内含 Python SDK 与 CLI，因此你可以直接在终端或代码中、在你的环境里使用 Dell Enterprise Hub——只需 `pip install dell-ai`

## 总结

有了模型与应用程序，覆盖了 AI 服务器和 AI PC，并可通过 Docker、Kubernetes 和 Dell Pro AI Studio 轻松安装，Dell Enterprise Hub 是一套在企业中部署 GenAI 应用的完整工具箱，完全安全且全部在本地运行。

作为 Dell 客户，这意味着你可以非常迅速地在 1 小时内（而非数周）完成：

- 在网络内部推出一个由最新开源 LLM 驱动的聊天助手，并使用 MCP 将其连接到你的内部存储系统（例如 Dell PowerScale），整个过程在一个物理隔离（air gapped）的环境中进行
- 提供对复杂 agentic 系统的访问，具备精细化访问控制与 SSO，可处理内部文本、代码、图像、音频和文档，并访问网络以获取最新上下文
- 以完全托管的方式，用一批 Dell AI PC 为员工配备端侧、私有的转写能力
