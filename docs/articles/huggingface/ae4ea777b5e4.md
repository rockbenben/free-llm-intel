# Sentence Transformers 入驻 Hugging Face Hub

过去几周，我们与机器学习生态中的许多开源框架建立了合作。其中让我们格外兴奋的是 Sentence Transformers。

[Sentence Transformers](https://github.com/UKPLab/sentence-transformers) 是一个用于句子、段落和图像嵌入的框架。它可以导出语义上有意义的嵌入（1），对语义搜索、跨语言零样本分类等应用非常有用。作为 Sentence Transformers [v2 发布](https://github.com/UKPLab/sentence-transformers/releases/tag/v2.0.0)的一部分，带来了许多很棒的新特性：

- 轻松在 Hub 上分享你的模型。
- 面向句子嵌入和句子相似度的 Widget 与 Inference API。
- 更好的句子嵌入模型可用（[基准测试](https://www.sbert.net/docs/pretrained_models.html#sentence-embedding-models)，Hub 中的[模型](https://huggingface.co/sentence-transformers)）。

Hub 上已有超过 90 个预训练 Sentence Transformers 模型，覆盖 100 多种语言，人人都能从中受益并轻松使用。预训练模型只需几行代码即可加载使用：

```
from sentence_transformers import SentenceTransformer
sentences = ["Hello World", "Hallo Welt"]

model = SentenceTransformer('sentence-transformers/paraphrase-MiniLM-L6-v2')
embeddings = model.encode(sentences)
print(embeddings)
```

不仅如此。人们可能还想展示自己的模型，或者轻松体验别人的模型，因此我们很高兴地宣布 Hub 上推出两个新 widget！第一个是 `feature-extraction` widget，用于展示句子嵌入。

不过，看一堆数字对你来说可能没什么用（除非你能扫一眼就看懂嵌入向量，那可就太厉害了！）。我们还为 Sentence Transformers 的一个常见用途引入了新 widget：计算句子相似度。

当然，除了 widget 之外，我们的 Inference API 也提供了 API 端点，让你可以通过程序化方式调用你的模型！

```
import json
import requests

API_URL = "https://api-inference.huggingface.co/models/sentence-transformers/paraphrase-MiniLM-L6-v2"
headers = {"Authorization": "Bearer YOUR_TOKEN"}

def query(payload):
    response = requests.post(API_URL, headers=headers, json=payload)
    return response.json()

data = query(
    {
        "inputs": {
            "source_sentence": "That is a happy person",
            "sentences": [
                "That is a happy dog",
                "That is a very happy person",
                "Today is a sunny day"
            ]
        }
    }
)
```

## 释放分享的力量

为什么这很强大？你可以在几分钟之内把训练好的模型分享给整个社区。

```
from sentence_transformers import SentenceTransformer

# Load or train a model

model.save_to_hub("my_new_model")
```

现在你就拥有了一个在 Hub 上托管你模型的[仓库](https://huggingface.co/osanseviero/my_new_model)。系统会自动创建一张 model card：它通过列出各层来描述模型架构，并展示如何用 `Sentence Transformers` 和 `🤗 Transformers` 使用这个模型。你还可以直接试用 widget 并使用 Inference API！

如果这还不够令人兴奋，你的模型还很容易被大家[通过筛选所有](https://huggingface.co/models?filter=sentence-transformers) `Sentence Transformers` 模型找到。

## 接下来？

展望未来，我们希望把这个集成做得更有用。在我们的路线图中，自动创建的 model card 将会包含训练和评估数据，就像 `transformers` 从 `v4.8` 版本开始做的那样。

那么接下来轮到你了？我们非常期待你的贡献！如果你已经在 Hub 上有 `Sentence Transformer` 仓库，现在只需修改 model card 的元数据，就能启用 widget 和 Inference API。

```
---
tags:
  - sentence-transformers
  - sentence-similarity # Or feature-extraction!
---
```

如果你还没有模型在 Hub 上，并且想更多了解 Sentence Transformers，请访问 [www.SBERT.net](https://www.sbert.net)！

## 想把你的库集成到 Hub 吗？

这次集成得益于 [`huggingface_hub`](https://github.com/huggingface/huggingface_hub) 库，它内置了我们所有的 widget 以及所有被支持库的 API。如果你想把自己的库集成到 Hub，我们有为你准备的[指南](https://huggingface.co/docs/hub/models-adding-libraries)！
