# 用 Python 实现 MCP 服务器：基于 Gradio 的 AI 购物助手

Python 开发者们，想给你的 LLM 赋予超能力吗？Gradio 就是最快的方式！借助 Gradio 的 Model Context Protocol（MCP）集成，你的 LLM 可以直接接入托管在 Hugging Face [Hub](https://hf.co) 上的数千个 AI 模型和 Spaces。把 LLM 的通用推理能力与 Hugging Face 上各类模型的专业能力结合起来，你的 LLM 就能超越单纯的文本问答，真正去解决你日常生活中的问题。

对 Python 开发者而言，Gradio 让实现强大的 MCP 服务器变得轻而易举，它提供了如下特性：

- **自动把 Python 函数转换为 LLM 工具：** 你的 Gradio 应用中的每个 API 端点都会被自动转换为一个 MCP 工具，并带有相应的名称、描述和输入 schema。你函数的 docstring 会被用来生成该工具及其参数的描述。
- **实时进度通知：** Gradio 会把进度通知流式传输给你的 MCP 客户端，让你能够实时监控状态，而无需自己实现这一功能。
- **自动文件上传**，包括对公开 URL 的支持以及对各种文件类型的处理。

想象一下：你讨厌购物，因为它太费时间，你也害怕亲自去试穿衣服。如果有个 LLM 能替你搞定这一切呢？在本文中，我们将创建一个由 LLM 驱动的 AI 助手，它能浏览在线服装店、找到特定的衣物，然后使用虚拟试穿模型向你展示这些衣服穿在你身上是什么效果。请看下面的演示：

## 目标：你的私人 AI 造型师

为了让我们的 AI 购物助手落地，我们将组合三个关键组件：

- [IDM-VTON](https://huggingface.co/yisol/IDM-VTON) Diffusion 模型：这个 AI 模型负责虚拟试穿功能。它可以编辑现有照片，让画面中的人看起来像是穿着另一件衣物。我们会使用 IDM-VTON 的 Hugging Face Space，可[在此](https://huggingface.co/spaces/yisol/IDM-VTON)访问。
- Gradio：Gradio 是一个开源 Python 库，可以轻松构建 AI 驱动的 Web 应用，而对我们项目至关重要的是，它还能创建 MCP 服务器。Gradio 将充当桥梁，让我们的 LLM 能够调用 IDM-VTON 模型及其他工具。
- Visual Studio Code 的 AI 聊天功能：我们会使用 VS Code 内置的 AI 聊天，它支持添加任意 MCP 服务器，用来与我们的 AI 购物助手交互。这提供一个友好的界面来下发命令并查看虚拟试穿结果。

## 构建 Gradio MCP 服务器

我们 AI 购物助手的内核就是这个 Gradio MCP 服务器。该服务器将暴露一个主要工具：

- `vton_generation`：这个函数接收一张人模图片和一件衣物图片作为输入，并使用 IDM-VTON 模型生成一张该人穿着这件衣物的新图片。

这是我们 Gradio MCP 服务器的 Python 代码：

```
from gradio_client import Client, handle_file
import gradio as gr
import re


client = Client("freddyaboulton/IDM-VTON",
                hf_token="<Your-token>")


def vton_generation(human_model_img: str, garment: str):
    """Use the IDM-VTON model to generate a new image of a person wearing a garment."""
    """
    Args:
        human_model_img: The human model that is modelling the garment.
        garment: The garment to wear.
    """
    output = client.predict(
        dict={"background": handle_file(human_model_img), "layers":[], "composite":None},
        garm_img=handle_file(garment),
        garment_des="",
        is_checked=True,
        is_checked_crop=False,
        denoise_steps=30,
        seed=42,
        api_name="/tryon"
    )

    return output[0]

vton_mcp = gr.Interface(
    vton_generation,
    inputs=[
        gr.Image(type="filepath", label="Human Model Image URL"),
        gr.Image(type="filepath", label="Garment Image URL or File")
    ],
    outputs=gr.Image(type="filepath", label="Generated Image")
)

if __name__ == "__main__":
    vton_mcp.launch(mcp_server=True)
```

通过在 `launch()` 方法中设置 `mcp_server=True`，Gradio 会自动把我们的 Python 函数转换为 LLM 能够理解并使用的 MCP 工具。我们函数的 docstring 会被用来生成工具及其参数的描述。

> 原始的 IDM-VTON space 是用 Gradio 4.x 实现的，那早于自动 MCP 功能。因此在本演示中，我们会构建一个通过 Gradio API 客户端查询原始空间的 Gradio 界面。

## 配置 VS Code

要把我们的 Gradio MCP 服务器连接到 VS Code 的 AI 聊天，我们需要编辑 `mcp.json` 文件。这个配置告诉 AI 聊天在哪里找到我们的 MCP 服务器以及如何与之交互。

你可以通过在命令面板中输入 `MCP` 并选择 `MCP: Open User Configuration` 来找到这个文件。打开后，请确保存在以下服务器：

```
{
  "servers": {
  "vton": {
    "url": "http://127.0.0.1:7860/gradio_api/mcp/"
  },
  "playwright": {
    "command": "npx",
    "args": [
      "-y",
      "@playwright/mcp@latest"
    ]
   }
  }
}
```

playwright MCP 服务器将让我们的 AI 助手浏览网页。

> 请确保 vton 服务器的 URL 与上一节中控制台打印出的 url 一致。要运行 playwright MCP 服务器，你需要安装 node。
