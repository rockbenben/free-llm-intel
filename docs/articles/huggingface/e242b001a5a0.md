# 用 Gradio 在 Spaces 中展示你的项目

多亏 [Gradio](https://gradio.app/)，演示一个机器学习项目变得极其简单。

在这篇博客中，我们将带你了解：

- 近期推出的 Gradio 集成——借助 [Inference API](https://huggingface.co/inference-api)，只需几行代码就能无缝演示 Hub 上的模型。
- 如何用 Hugging Face Spaces 托管你自己模型的 demo。

## Gradio 中的 Hugging Face Hub 集成

你可以轻松地演示 Hub 上的模型。只需定义 [Interface](https://gradio.app/docs#interface)，包括：

- 你想用于推理的模型的 repository ID
- 一段描述和一个标题
- 引导受众的示例输入

定义好 Interface 后，调用 `.launch()`，你的 demo 就开始运行了。你可以在 Colab 里做这件事，但如果想分享给社区，Spaces 是个很好的选择！

Spaces 是用 Python 托管 ML demo 应用的简单免费方式。要这样做，你可以在 [https://huggingface.co/new-space](https://huggingface.co/new-space) 创建一个仓库并选择 Gradio 作为 SDK。完成后，创建一个名为 `app.py` 的文件，复制下面的代码，你的应用几秒钟就能跑起来！

```
import gradio as gr

description = "Story generation with GPT-2"
title = "Generate your own story"
examples = [["Adventurer is approached by a mysterious stranger in the tavern for a new quest."]]

interface = gr.Interface.load("huggingface/pranavpsv/gpt2-genre-story-generator",
            description=description,
            examples=examples
)

interface.launch()
```

可以在[这里](https://huggingface.co/spaces/merve/GPT-2-story-gen)体验这个故事生成模型。

[![story-gen](https://huggingface.co/blog/assets/28_gradio-spaces/story-gen.png)](https://huggingface.co/blog/assets/28_gradio-spaces/story-gen.png)

在底层，Gradio 调用的是 Inference API——它支持 Transformers，也支持 spaCy、SpeechBrain、Asteroid 等流行 ML 框架。这个集成支持不同类型的模型：`image-to-text`、`speech-to-text`、`text-to-speech` 等等。可以在[这里](https://huggingface.co/spaces/merve/BigGAN-ImageNET)看看这个 BigGAN ImageNet `text-to-image` 模型的例子。具体实现如下。

```
import gradio as gr
description = "BigGAN text-to-image demo."
title = "BigGAN ImageNet"
interface = gr.Interface.load("huggingface/osanseviero/BigGAN-deep-128", 
            description=description,
            title = title,
            examples=[["american robin"]]
)
interface.launch()
```

[![big-gan](https://huggingface.co/blog/assets/28_gradio-spaces/big-gan.png)](https://huggingface.co/blog/assets/28_gradio-spaces/big-gan.png)

## 在 Hugging Face Spaces 中用 Gradio 服务自定义模型 checkpoint

即使 Inference API 不支持你的模型，你也依然可以在 Spaces 中服务它。只需按下面的方式把模型推理包装进一个 Gradio `Interface`，然后放到 Spaces 即可。[![imagenet-demo](https://huggingface.co/blog/assets/28_gradio-spaces/imagenet-demo.gif)](https://huggingface.co/blog/assets/28_gradio-spaces/imagenet-demo.gif)

## 模型混搭！

使用 Gradio Series，你可以把不同的模型混搭！这里，我们在故事生成器前面放一个法译英翻译模型，在后面放一个英译法翻译模型，简单组合出一个法语故事生成器。

```
import gradio as gr
from gradio.mix import Series

description = "Generate your own D&D story!"
title = "French Story Generator using Opus MT and GPT-2"
translator_fr = gr.Interface.load("huggingface/Helsinki-NLP/opus-mt-fr-en")
story_gen = gr.Interface.load("huggingface/pranavpsv/gpt2-genre-story-generator")
translator_en = gr.Interface.load("huggingface/Helsinki-NLP/opus-mt-en-fr")
examples = [["L'aventurier est approché par un mystérieux étranger, pour une nouvelle quête."]]

Series(translator_fr, story_gen, translator_en, description = description,
        title = title,
        examples=examples, inputs = gr.inputs.Textbox(lines = 10)).launch()
```

可以在[这里](https://huggingface.co/spaces/merve/french-story-gen)查看法语故事生成器 [![story-gen-fr](https://huggingface.co/blog/assets/28_gradio-spaces/story-gen-fr.png)](https://huggingface.co/blog/assets/28_gradio-spaces/story-gen-fr.png)
