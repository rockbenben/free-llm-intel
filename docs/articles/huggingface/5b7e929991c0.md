# 公布我们的新社区政策

作为一个致力于推动开放、协作与负责任机器学习的社区驱动平台，我们很高兴为整个社区维护一个包容友善的空间！为支持这一目标，我们更新了[内容政策（Content Policy）](https://huggingface.co/content-guidelines)。

我们鼓励你完整阅读该文件，充分理解其内容。同时，本篇博客旨在提供一个概览、说明背后的理由，并突出驱动本次内容政策更新的价值观。通过浏览这两份材料，你将全面了解我们平台上对内容的期望与目标。

## 审核机器学习内容

审核机器学习产物带来了新的挑战。相较于静态内容，开发和部署人工智能系统和/或模型所伴随的风险，需要更深入的分析、更广的视角来预判可能的危害。正因如此，这份新内容政策的起草工作来自跨职能团队的不同成员与不同专长——而要同时具备全局与细节视野、清楚说明我们如何在平台上支持负责任的开发与部署，这些成员和专长缺一不可。

此外，随着 AI 与机器学习领域的持续扩展，用例和应用的种类也在不断增多。这使我们必须紧跟最新的研究、伦理考量与最佳实践。出于同样的原因，促进用户协作对我们平台的可持续性也至关重要。具体而言，我们通过社区功能（如 Community Tab 社区标签页）鼓励并培养仓库作者、用户、组织与我们团队之间的协作解决方案。

## 把"知情同意"作为核心价值

我们优先尊重人们在机器学习系统开发和使用全过程中的权利，同时以前瞻性的眼光考量技术和法律方面对这些权利的影响。机器学习带来的全新信息处理方式，正在 AI 领域和监管圈子里提出全新的问题——关于人们对自己的作品、形象和隐私的自主权与权利。这些讨论的核心在于：人们的权利应当如何落地——而我们在此提供了一种解决路径。

在这个不断演变的法律格局中，愈发重要的是强调"同意（consent）"这一内在价值，以避免为伤害提供条件。这样做，我们把焦点放在个体的自主性和主观体验上。这种方式不仅支持深谋远虑、对"同意"更具共情的理解，也鼓励主动应对文化与情境因素。具体而言，我们的内容政策旨在就"用户看到什么"以及"人们如何被呈现身份和表达"这两个层面的同意问题作出规范。

人们对平台的同意与体验这一考量，既延伸到社区内容，也延伸到人们在 Hub 上的行为。为维护一个安全、友好的环境，我们不允许针对用户和/或 Hugging Face 员工的攻击性或骚扰性言论。我们专注于促进用户与仓库作者之间潜在冲突的协作解决，只在必要时才介入。为推动透明，我们鼓励在我们的 Community 标签页内进行公开讨论。

我们的做法反映了我们持续适应与进步的不懈努力，而这离不开积极协作并分享反馈的用户们的宝贵输入。我们承诺虚心听取意见，并不断追求卓越。如有任何问题或顾虑，欢迎联系 [feedback@huggingface.co](mailto:feedback@huggingface.co)。

让我们携手共建一个友好、互助的社区，鼓励开放的 AI 与 ML 协作！只要我们齐心协力，就能在营造人人都受欢迎的氛围上迈出更大的步伐。
