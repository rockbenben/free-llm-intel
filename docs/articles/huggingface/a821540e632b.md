# Mask2Former 与 OneFormer：通用的图像分割

本文亦有[简体中文](https://huggingface.co/blog/zh/mask2former)版本。

**本指南介绍 Mask2Former 和 OneFormer——两个用于图像分割的最先进（state-of-the-art）神经网络。这些模型现已收录在 [`🤗 transformers`](https://huggingface.co/transformers) 中，这是一个为前沿模型提供易用实现的开源库。在此过程中，你还会了解到图像分割各种形式之间的区别。**

## 图像分割

图像分割是识别图像中不同"片段"（segment）的任务，比如人或汽车。更技术性的说法是，图像分割是把具有不同语义的像素分组的任务。可参阅 Hugging Face 的[任务页面](https://huggingface.co/tasks/image-segmentation)了解简要介绍。

图像分割大体可分为 3 个子任务——实例分割（instance segmentation）、语义分割（semantic segmentation）和全景分割（panoptic segmentation）——每个子任务都有众多方法和模型架构。

- **实例分割（instance segmentation）**是识别图像中不同"实例"（instance），比如一个个具体的人的任务。实例分割与目标检测非常相似，区别在于我们希望输出一组二值分割掩码（binary segmentation mask）及对应的类别标签，而不是边界框。实例（Instances）也常被称为 "objects" 或 "things"。注意，不同的实例之间可能相互重叠。
- **语义分割（semantic segmentation）**是识别图像中每个像素所属的不同"语义类别"（semantic categories），如 "person" 或 "sky" 的任务。与实例分割相反，语义分割不区分同一语义类别中的不同个体；比如只需要为 "person" 这个类别给出一张掩码，而不必区分每一个人。像 "sky" 或 "grass" 这样没有独立实例的语义类别，通常被称为 "stuff"，以与 "things" 相区分（这名字起得够好的，对吧？）。注意，语义类别之间不可能重叠，因为每个像素只属于一个类别。
- **全景分割（panoptic segmentation）**由 [Kirillov 等人](https://arxiv.org/abs/1801.00868)于 2018 年提出，旨在统一实例分割与语义分割：让模型只需识别出一组"片段"（segments），每个片段带有对应的二值掩码和类别标签。片段既可以是 "things"，也可以是 "stuff"。与实例分割不同，不同片段之间不允许重叠。

下图展示了这 3 个子任务之间的区别（取自[这篇博客](https://www.v7labs.com/blog/panoptic-segmentation-guide)）。

![drawing](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/127_mask2former/semantic_vs_semantic_vs_panoptic.png)

过去几年，研究者提出了若干种架构，通常都是专为实例、语义或全景分割中的某一种而定制的。实例分割和全景分割通常通过输出一组二值掩码加上每个对象实例的对应标签来解决（与目标检测非常相似，只是每个实例输出的是二值掩码而非边界框），这种做法常被称为"二值掩码分类"（binary mask classification）。而语义分割则通常让模型输出一张每个像素对应一个标签的"分割图"（segmentation map）来解决，因此语义分割被视为一个"逐像素分类"（per-pixel classification）问题。采用这一范式的流行语义分割模型包括 [SegFormer](https://huggingface.co/docs/transformers/model_doc/segformer)——我们曾为它写过一篇详细的[博客](https://huggingface.co/blog/fine-tune-segformer)——以及 [UPerNet](https://huggingface.co/docs/transformers/main/en/model_doc/upernet)。

## 通用图像分割

幸运的是，大约从 2020 年开始，人们开始提出能够以统一架构、统一范式同时完成全部 3 项任务（实例、语义和全景分割）的模型。这一趋势始于 [DETR](https://huggingface.co/docs/transformers/model_doc/detr)，它是第一个以"二值掩码分类"范式解决全景分割的模型，将 "things" 和 "stuff" 类别统一处理。其关键创新在于让 Transformer decoder 以并行方式一次性生成一组二值掩码 + 类别。随后 [MaskFormer](https://huggingface.co/docs/transformers/model_doc/maskformer) 论文对此做了改进，证明"二值掩码分类"范式对语义分割同样非常有效。

[Mask2Former](https://huggingface.co/docs/transformers/main/model_doc/mask2former) 通过进一步优化神经网络架构，把这一思路扩展到了实例分割。至此，我们从各自独立的架构演进到了研究者所说的"通用图像分割"（universal image segmentation）架构，能够解决任意图像分割任务。有趣的是，这些通用模型全部采用了"掩码分类"（mask classification）范式，彻底抛弃了"逐像素分类"范式。下图展示了 Mask2Former 的架构（取自[原始论文](https://arxiv.org/abs/2112.01527)）。

![drawing](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/model_doc/mask2former_architecture.jpg)

简而言之：图像首先经过一个骨干网络（backbone，论文中可用 [ResNet](https://huggingface.co/docs/transformers/model_doc/resnet) 或 [Swin Transformer](https://huggingface.co/docs/transformers/model_doc/swin)）得到一组低分辨率特征图；随后，这些特征图经由一个像素解码器（pixel decoder）模块增强，得到高分辨率特征；最后，一个 Transformer decoder 接收一组查询（queries），在像素解码器特征的条件约束下，将它们转换为一组二值掩码和类别预测。

注意，Mask2Former 仍需要针对每个任务分别训练才能取得最先进（state-of-the-art）的结果。[OneFormer](https://arxiv.org/abs/2211.06220) 模型对此做了改进：它通过加入一个文本编码器，让模型可以依据 "instance"、"semantic" 或 "panoptic" 输入进行条件化，从而只需在全景版本的数据集上训练（！），就能在全部 3 项任务上取得最先进性能。该模型如今也已[收录于 🤗 transformers](https://huggingface.co/docs/transformers/main/en/model_doc/oneformer)。它甚至比 Mask2Former 更准确，但额外的文本编码器带来了更高的推理延迟。下图是 OneFormer 概览，它使用 Swin Transformer 或全新的 [DiNAT](https://huggingface.co/docs/transformers/model_doc/dinat) 模型作为骨干网络。

![drawing](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/model_doc/oneformer_architecture.png)

## 在 Transformers 中对 Mask2Former 和 OneFormer 做推理

Mask2Former 和 OneFormer 的用法相当直接，与其前辈 MaskFormer 非常相似。让我们从 hub 上实例化一个在 COCO 全景数据集上训练的 Mask2Former 模型及其处理器（processor）。注意，作者们发布了多达 [30 个](https://huggingface.co/models?other=mask2former)在各种数据集上训练的 checkpoint。

```
from transformers import AutoImageProcessor, Mask2FormerForUniversalSegmentation

processor = AutoImageProcessor.from_pretrained("facebook/mask2former-swin-base-coco-panoptic")
model = Mask2FormerForUniversalSegmentation.from_pretrained("facebook/mask2former-swin-base-coco-panoptic")
```

接下来，加载 COCO 数据集中我们熟悉的那张猫的图片，在它上面进行推理。

```
from PIL import Image

url = "http://images.cocodataset.org/val2017/000000039769.jpg"
image = Image.open(requests.get(url, stream=True).raw)
image
```

我们用图像处理器为模型准备图像，并将其送入模型前向传播。

```
inputs = processor(image, return_tensors="pt")

with torch.no_grad():
    outputs = model(**inputs)
```

模型输出一组二值掩码及对应的类别 logits。Mask2Former 的原始输出可以直接用图像处理器做后处理，得到最终的实例、语义或全景分割预测：

```
prediction = processor.post_process_panoptic_segmentation(outputs, target_sizes=[image.size[::-1]])[0]
print(prediction.keys())
```

```
Output:
----------------------------------------------------------------------------------------------------
dict_keys(['segmentation', 'segments_info'])
```

在全景分割中，最终的 `prediction` 包含两样东西：一个形状为 (height, width) 的 `segmentation` 图，其中每个值编码了对应像素的实例 ID；以及相应的 `segments_info`，其中包含这张图中各个片段的更多信息（例如其类别 / 类目 ID）。注意，出于效率考虑，Mask2Former 输出的二值掩码候选形状为 (96, 96)，而 `target_sizes` 参数用于将最终掩码调整回原始图像尺寸。

让我们可视化一下结果：

```
from collections import defaultdict
import matplotlib.pyplot as plt
import matplotlib.patches as mpatches
from matplotlib import cm

def draw_panoptic_segmentation(segmentation, segments_info):
    # get the used color map
    viridis = cm.get_cmap('viridis', torch.max(segmentation))
    fig, ax = plt.subplots()
    ax.imshow(segmentation)
    instances_counter = defaultdict(int)
    handles = []
    # for each segment, draw its legend
    for segment in segments_info:
        segment_id = segment['id']
        segment_label_id = segment['label_id']
        segment_label = model.config.id2label[segment_label_id]
        label = f"{segment_label}-{instances_counter[segment_label_id]}"
        instances_counter[segment_label_id] += 1
        color = viridis(segment_id)
        handles.append(mpatches.Patch(color=color, label=label))
        
    ax.legend(handles=handles)

draw_panoptic_segmentation(**panoptic_segmentation)
```

在这里可以看到，模型能够检测出图像中每一只猫和每一个遥控器。而语义分割则只会为 "cat" 类别生成单独一张掩码。

至于 OneFormer 的推理——它的 API 完全相同，只是额外还需要接收一个文本提示（text prompt）作为输入——请参阅我们的[演示 notebook](https://github.com/NielsRogge/Transformers-Tutorials/tree/master/OneFormer)。

## 在 Transformers 中微调 Mask2Former 和 OneFormer

若要针对实例、语义或全景分割在自定义数据集上微调 Mask2Former/OneFormer，请查看我们的[演示 notebooks](https://github.com/NielsRogge/Transformers-Tutorials/tree/master/MaskFormer/Fine-tuning)。MaskFormer、Mask2Former 和 OneFormer 共享相似的 API，因此从 MaskFormer 升级很容易，所需改动极少。

演示 notebooks 中使用 `MaskFormerForInstanceSegmentation` 加载模型，你需要改为使用 `Mask2FormerForUniversalSegmentation` 或 `OneFormerForUniversalSegmentation`。对于 Mask2Former 的图像处理，你还需要改用 `Mask2FormerImageProcessor`；也可以用 `AutoImageProcessor` 类来加载图像处理器，它会自动为你的模型选择正确的处理器。而 OneFormer 则需要一个 `OneFormerProcessor`，它负责将图像连同文本输入一起处理后送入模型。
