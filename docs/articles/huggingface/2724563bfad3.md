# 欢迎 PaliGemma 2 – Google 的新视觉语言模型

merve（merve）、Andreas P. Steiner（andsteing，google）、Pedro Cuenca（pcuenq）、Aritra Roy Gosthipaty（ariG23498）

本文另有中文版本 [简体中文](https://huggingface.co/blog/zh/paligemma2)。

我们很高兴迎接 Google 全新的视觉语言模型 PaliGemma 2——PaliGemma 的一次新迭代。和它的前作一样，PaliGemma 2 在视觉端沿用了同样强大的 [SigLIP](https://huggingface.co/collections/google/siglip-659d5e62f0ae1a57ae0e83ba)，但在文本解码器部分升级到了最新的 Gemma 2。

PaliGemma 2 带来全新的预训练（pt）模型，规模为 `3B`、`10B` 和 `28B` 参数。它们都支持多种输入分辨率：`224x224`、`448x448` 和 `896x896`。这些组合为不同用例提供了极大的灵活性，从业者可以在质量/效率之间选择所需的平衡。相比之下，上一代 PaliGemma 只有 3B 变体。

预训练模型被设计成便于微调迁移到下游任务。初代 PaliGemma 被社区广泛采用于多种用途。凭借额外变体带来的更大灵活性，加上更好的预训练质量，我们迫不及待想看社区这次能做出什么。

作为一个示例，Google 还发布了在 [DOCCI](https://huggingface.co/datasets/google/docci) 数据集上的一些微调变体，展示了长、细腻、详尽且稳健的描述能力。微调后的 DOCCI 模型有 3B 和 10B 变体，支持 448x448 输入分辨率。

本次发布包含所有开放的模型仓库、transformers 集成、微调脚本，以及一个由我们自己针对 [VQAv2 数据集](https://huggingface.co/datasets/HuggingFaceM4/VQAv2) 做视觉问答微调的模型 demo。

## 介绍 PaliGemma 2

PaliGemma 2 是 Google 五月发布的 [PaliGemma 视觉语言模型](https://huggingface.co/blog/paligemma)的一次新迭代。PaliGemma 2 把强大的 SigLIP 图像编码器与 [Gemma 2](https://huggingface.co/blog/gemma2) 语言模型连接起来。

[![PaliGemma2 Architecture](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/paligemma/paligemma2_arch.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/paligemma/paligemma2_arch.png)

这些新模型基于 Gemma 2 的 2B、9B 和 27B 语言模型，得出对应的 3B、10B 和 28B PaliGemma 2 变体——命名时计入了（紧凑的）图像编码器的额外参数。如前所述，它们支持三种不同分辨率，为下游任务微调提供了极大灵活性。

PaliGemma 2 以 Gemma 许可证分发，允许再分发、商用、微调和创建模型衍生作品。

本次发布带有以下 `bfloat16` 精度的 checkpoint：

- 9 个预训练模型：3B、10B 和 28B，分辨率为 `224x224`、`448x448` 和 `896x896`。
- 2 个在 DOCCI 上微调的模型：两个在 [DOCCI](https://huggingface.co/datasets/google/docci) 数据集（图文描述对）上微调的模型，支持 3B 和 10B PaliGemma 2 变体，输入分辨率 `448x448`。

## 模型能力

如上一代 PaliGemma 发布所示，预训练（pt）模型在下游任务上进一步微调表现很好。

pt 模型在以下数据混合上预训练。预训练数据集的多样性，使得在与之相似的领域上微调下游任务时可以用相对更少的样本进行。

- **WebLI**：一个从公开网络构建的、web 规模的多语言图文数据集。使用广泛范围的 WebLI 分片来获取多样的模型能力，如视觉语义理解、目标定位、视觉情境文本理解和多语言能力。
- **CC3M-35L:** 来自网页的、经清洗的英文图像-alt_text 对（[Sharma et al., 2018](https://aclanthology.org/P18-1238/)）。为给这个数据集打标签，作者用 [Google Cloud Translation API](https://cloud.google.com/translate) 翻译成额外的 34 种语言。
- **Visual Question Generation with Question Answering Validation (VQ2A)：** 一个用于问答的改进数据集。该数据集用 Google Cloud Translation API 翻译成同样额外的 34 种语言。
- **OpenImages：** 检测与目标感知的问答（Piergiovanni et al. 2022），由在 [OpenImages dataset](https://storage.googleapis.com/openimages/web/factsfigures_v7.html) 上的手工规则生成。
- **WIT**：从维基百科收集的图像和文本（Srinivasan et al., 2021）。

PaliGemma 2 团队在内部对 PT 模型在多种视觉-语言理解任务上做了微调，并在[模型卡](https://huggingface.co/google/paligemma2-28b-pt-896#paligemma-2-results-by-model-resolution-and-size)和[技术报告](https://huggingface.co/papers/2412.03555)中提供了这些微调模型的基准。

在 DOCCI 数据集上微调的 PaliGemma 2，能完成大量描述任务，包括文本渲染、捕捉空间关系、以及在描述中包含世界知识。

## 如何用 Transformers 使用

你可以用 🤗 transformers 在 PaliGemma 2 模型上跑推理，使用 PaliGemmaForConditionalGeneration 和 AutoProcessor API。请确保安装 transformers 4.47 或更高版本：

```
pip install --upgrade transformers
```

之后你可以这样跑推理。照例，请确保遵循该任务在训练模型时所用的提示词格式：

```
from transformers import AutoProcessor, PaliGemmaForConditionalGeneration
from PIL import Image
import requests

model_id = "google/paligemma2-10b-ft-docci-448"
model = PaliGemmaForConditionalGeneration.from_pretrained(model_id)
model = model.to("cuda")
processor = AutoProcessor.from_pretrained(model_id)

prompt = "<image>caption en"
image_file = "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/cats.png"
raw_image = Image.open(requests.get(image_file, stream=True).raw).convert("RGB")

inputs = processor(prompt, raw_image, return_tensors="pt").to("cuda")
output = model.generate(**inputs, max_new_tokens=200)

input_len = inputs["input_ids"].shape[-1]
print(processor.decode(output[0][input_len:], skip_special_tokens=True))
# A medium shot of two cats laying on a pile of brown fishing nets. The cat in the foreground is a gray tabby cat with white on its chest and paws. The cat is laying on its side with its head facing the bottom right corner of the image. The cat in the background is laying on its side with its head facing the top left corner of the image. The cat's body is curled up, its head is slightly turned to the right, and its front paws are tucked underneath its body. There is a teal rope hanging from the fishing net in the top right corner of the image.
```

你也可以用 transformers 的 `bitsandbytes` 集成以量化加载模型。下面示例用 4-bit `nf4`：

```
from transformers import BitsAndBytesConfig

bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_quant_type="nf4",
    bnb_4bit_compute_dtype=torch.bfloat16
)
model = PaligemmaForConditionalGeneration.from_pretrained(
    model_id,
    quantization_config=bnb_config,
    device_map={"":0}
)
```

我们通过在 [textvqa](https://huggingface.co/datasets/lmms-lab/textvqa) 数据集、用 224x224 输入图像评估一个 3B 微调 checkpoint，快速测试了量化存在时的性能退化。这是在 5000 条验证集上得到的结果：

- `bfloat16`，不量化：60.04% 准确率。
- `8-bit`：59.78%。
- `4-bit`，用上面片段的配置：58.72%。

这些数字非常令人鼓舞！当然，量化对更大的 checkpoint 最有意义，我们建议你在将要使用的领域和任务上始终测量结果。

## 微调

如果你之前微调过 PaliGemma，微调 PaliGemma 2 的 API 是一样的，你可以开箱使用你的代码。我们提供了一份[微调脚本](https://github.com/merveenoyan/smol-vision/blob/main/paligemma.py)和一个 [notebook](https://github.com/merveenoyan/smol-vision/blob/main/Fine_tune_PaliGemma.ipynb) 供你微调模型、冻结模型的部分，或应用像 LoRA 或 QLoRA 这样的省内存微调技术。

出于演示目的，我们在一半的 VQAv2 验证集上做了 LoRA 微调一个 PaliGemma 2 模型。这在 3 张 80GB VRAM 的 A100 上花了半小时。模型在[这里](https://huggingface.co/merve/paligemma2-3b-vqav2)，[这是一个展示它的 Gradio demo](https://huggingface.co/spaces/merve/paligemma2-vqav2)。
