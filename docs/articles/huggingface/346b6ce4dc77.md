# BERTopic 与 Hugging Face Hub 集成

[![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/#fileId=https://huggingface.co/spaces/davanstrien/blog_notebooks/blob/main/BERTopic_hub_starter.ipynb)

我们很高兴宣布 [BERTopic](https://maartengr.github.io/BERTopic) Python library的一次重要更新：扩展其能力，并进一步为主题建模的爱好者与从业者理顺工作流。BERTopic 现在支持将训练好的主题模型直接推送到 Hugging Face Hub、或从 Hub 拉取。这一新集成让在生产用例中轻松运用 BERTopic 的强大能力成为可能。

## 什么是主题建模？

主题建模是一种帮助揭示文档集合中隐藏主题（"topics"）的方法。通过分析文档中的词语，我们能找到揭示这些底层主题的 patterns 与关联。例如，一篇关于机器学习的文档比一篇关于烤面包的文档更可能使用 "gradient"、"embedding" 这样的词。

每篇文档通常按不同比例涉及多个主题。通过检查词语统计信息，我们可以识别出代表这些主题的相关词簇。这让我们能够分析一组文档、确定它们讨论的主题，以及每篇文档内部主题的配比。近期，主题建模的新方法已超越单纯使用词语，转向更丰富的表示，例如 Transformer 模型所提供的表示。

## 什么是 BERTopic？

BERTopic 是一款最先进的 Python 库，通过多种 embedding 技术与 [c-TF-IDF](https://maartengr.github.io/BERTopic/api/ctfidf.html) 简化主题建模流程：它创建稠密的簇，既生成易于解释的主题，又在主题描述中保留重要的词。

*BERTopic 库概览*

BERTopic 虽然上手容易，同时支持一系列高级主题建模方法，包括 [guided](https://maartengr.github.io/BERTopic/getting_started/guided/guided.html)、[supervised](https://maartengr.github.io/BERTopic/getting_started/supervised/supervised.html)、[semi-supervised](https://maartengr.github.io/BERTopic/getting_started/semisupervised/semisupervised.html) 和 [manual](https://maartengr.github.io/BERTopic/getting_started/manual/manual.html) 主题建模。最近 BERTopic 还增加了多模态主题模型的支持，并配有一整套丰富的可视化工具。

BERTopic 为用户提供了强有力的工具来揭示文本集合中的重要主题，从而获得有价值的洞见。用 BERTopic，用户可以轻松分析客户评论、探索研究论文或给新闻文章归类，是每个想从文本数据中抽取有意义信息的人的必备工具。

## 用 Hugging Face Hub 管理 BERTopic 模型

借助最新集成，BERTopic 用户可以无缝地把训练好的主题模型推送到 Hugging Face Hub 或从 Hub 拉取。这一集成是简化 BERTopic 模型跨环境部署与管理的里程碑。

训练 BERTopic 模型并推送到 Hub，只需几行：

```
from bertopic import BERTopic

topic_model = BERTopic("english")
topics, probs = topic_model.fit_transform(docs)
topic_model.push_to_hf_hub('davanstrien/transformers_issues_topics')
```

随后两行即可加载这个模型，并用于对新数据做预测。

```
from bertopic import BERTopic
topic_model = BERTopic.load("davanstrien/transformers_issues_topics")
```

借力 Hugging Face Hub，BERTopic 用户可以毫不费力地共享、版本管理和协作开发主题模型。Hub 充当中央仓库，让用户存储和整理模型，从而更容易把模型部署到生产环境、与同事共享，甚至向更广泛的 NLP 社区展示。

你可以在 Hub 上使用 `libraries` 过滤器寻找 BERTopic 模型。

[![BERTopic hub filter](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/BERTopic/bertopic-lib-filter.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/BERTopic/bertopic-lib-filter.png)

找到感兴趣的 BERTopic 模型后，你可以使用 Hub 的推理 widget 试用模型，看看它是否适合你的用例。

一旦有了训练好的主题模型，一行即可推送到 Hugging Face Hub。推送模型到 Hub 会自动为你的模型创建一张初始模型卡，包含所创建主题的概览。下面你可以看到一个[在 ArXiv 数据上训练的模型](https://huggingface.co/MaartenGr/BERTopic_ArXiv)得到的主题示例。

### safetensors：确保安全的模型管理

除 Hugging Face Hub 集成外，BERTopic 现在还支持用 [safetensors 库](https://huggingface.co/docs/safetensors/)做序列化。Safetensors 是一种存放张量的新简洁格式，安全（取代 pickle）且依然快速（零拷贝）。我们看到越来越多库采用 safetensors 实现安全序列化，非常振奋。关于该库近期安全审计的更多内容，可以阅读这篇[博客](https://huggingface.co/blog/safetensors-security-audit)。

### 用 BERTopic 探索 RLHF 数据集的示例

为了展示 BERTopic 的部分能力，我们看一个用它监测聊天模型训练数据集主题变化的例子。

过去一年发布了多个用于人类反馈强化学习（RLHF）的数据集，[OpenAssistant Conversations 数据集](https://huggingface.co/datasets/OpenAssistant/oasst1)就是其中之一。该数据集通过一场覆盖全球、超过 13,500 名志愿者参与的众包活动产出。虽然数据集已带有毒性、质量、幽默等评分，我们可能还想更好地理解其中收录了哪些类型的对话。

BERTopic 提供了理解该数据集主题的一种方式。这里我们在数据集的英文 assistant 回复部分上训练模型，得到一个含 75 个主题的[主题模型](https://huggingface.co/davanstrien/chat_topics)。

BERTopic 提供多种数据集可视化方式。下面是前 8 个主题及其关联词。可以看到，第二高频的主题主要由"回复套话"构成——这正是聊天模型常见的、追求"礼貌"和"有帮助"的回复用语。我们还能看到大量与编程/计算相关的主题，以及物理、食谱和宠物等主题。

[![Words associated with top 8 topics](https://huggingface.co/datasets/huggingface/documentation-images/resolve/2d1113254a370972470d42e122df150f3551cc07/blog/BERTopic/topic_word_scores.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/2d1113254a370972470d42e122df150f3551cc07/blog/BERTopic/topic_word_scores.png)

[databricks/databricks-dolly-15k](https://huggingface.co/datasets/databricks/databricks-dolly-15k) 是另一个可用于训练 RLHF 模型的数据集。它的创建方式与 OpenAssistant Conversations 数据集很不同：它由 Databricks 员工制作，而非志愿者众包。我们能否用训练好的 BERTopic 模型来对比这两个数据集的主题？

新的 BERTopic Hub 集成意味着我们可以加载这个训练好的模型并应用于新样本。

```
topic_model = BERTopic.load("davanstrien/chat_topics")
```

可以对单条示例文本做预测：

```
example = "Stalemate is a drawn position. It doesn't matter who has captured more pieces or is in a winning position"
topic, prob = topic_model.transform(example)
```

我们可以获取更多关于预测主题的信息

```
topic_model.get_topic_info(topic)
```

|  | Count | Name | Representation |
| --- | --- | --- | --- |
| 0 | 240 | 22_chess_chessboard_practice_strategy | ['chess', 'chessboard', 'practice', 'strategy', 'learn', 'pawn', 'board', 'pawns', 'play', 'decks'] |

可以看到这里的主题预测相当合理。我们还可以把它扩展为对整份数据集的预测主题做对比。

```
from datasets import load_dataset

dataset = load_dataset("databricks/databricks-dolly-15k")
dolly_docs = dataset['train']['response']
dolly_topics, dolly_probs = topic_model.transform(dolly_docs)
```

然后就可以对比两个数据集的主题分布。根据我们的 BERTopic 模型，dolly 数据集的主题分布似乎更宽。这可能是两个数据集创建方式不同的结果（为确认这一点、确保没有遗漏主题，我们可能需要在两个数据集合并上重新训练一个 BERTopic）。

[![Topic distribution comparison](https://huggingface.co/datasets/huggingface/documentation-images/resolve/2d1113254a370972470d42e122df150f3551cc07/blog/BERTopic/distribution.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/2d1113254a370972470d42e122df150f3551cc07/blog/BERTopic/distribution.png)

*两个数据集主题分布的对比*

主题模型还可以用于生产环境，监测主题是否偏离预期分布过远。这可以作为一个信号，表明原始训练数据与你在生产中见到的对话类型之间出现了漂移。你也可以在采集训练数据时同步做主题建模，确保为你特别关心的主题收集到了足够样本。
