# 推出 Snowball Fight ☃️——我们的第一个 ML-Agents 环境

我们很高兴分享我们的**第一个自定义深度强化学习环境**：Snowball Fight 1vs1（打雪仗 1 对 1）🎉。[![gif](https://huggingface.co/blog/assets/39_introducing_snowball_fight/snowballfight.gif)](https://huggingface.co/blog/assets/39_introducing_snowball_fight/snowballfight.gif)

Snowball Fight 是一款用 Unity ML-Agents 制作的游戏，你将在游戏中向一个深度强化学习 agent 扔雪球。该游戏[**托管在 Hugging Face Spaces 上**](https://hf.co/spaces/launch)。

👉 [你可以在这里在线游玩](https://huggingface.co/spaces/ThomasSimonini/SnowballFight)

在本文中，我们将介绍**我们为使用 Unity ML-Agents 的深度强化学习研究者和爱好者打造的生态**。

## Hugging Face 的 Unity ML-Agents

[Unity Machine Learning Agents Toolkit](https://github.com/Unity-Technologies/ml-agents) 是一个开源库，让你用 Unity 游戏引擎构建游戏和仿真，**作为训练智能 agent 的环境**。

作为第一步，我们的目标是在 Hugging Face 上为使用 ML-Agents 的深度强化学习研究者和爱好者建立一个生态，包含三个特性。

- **构建并分享自定义环境。** 我们正在开发并分享一些令人兴奋的环境用于试验新问题：打雪仗、竞速、解谜……它们都将开源并托管在 Hugging Face Hub 上。
- **让你轻松托管自己的环境、保存模型并分享**到 Hugging Face Hub。我们已经[在这里](https://huggingface.co/ThomasSimonini/ML-Agents-SnowballFight-1vs1)发布了 Snowball Fight 训练环境，以后还会有更多！
- **你现在可以轻松地把 demo 托管到 Spaces**，快速向整个生态展示你的成果。

## 接下来有什么？

在未来几周和几个月里，我们将通过以下方式扩展这个生态：

- 撰写一些 **关于 ML-Agents 的技术教程**。
- 开发 **Snowball Fight 2vs2 版本**，其中 agent 将以团队形式协作，使用 [MA-POCA——一种训练团队协作行为的深度强化学习新算法](https://blog.unity.com/technology/ml-agents-plays-dodgeball)。
