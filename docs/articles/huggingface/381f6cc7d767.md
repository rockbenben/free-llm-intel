# 通过 Hugging Face 在 AWS Inferentia2 上部署模型

Jeff Boudier (jeffboudier)

Philipp Schmid (philschmid)

[![thumbnail](https://huggingface.co/blog/assets/inferentia-inference-endpoints/thumbnail.jpg)](https://huggingface.co/blog/assets/inferentia-inference-endpoints/thumbnail.jpg)

[AWS Inferentia2](https://aws.amazon.com/machine-learning/inferentia/) 是 AWS 最新的机器学习芯片，通过 Amazon Web Services 上的 [Amazon EC2 Inf2 实例](https://aws.amazon.com/ec2/instance-types/inf2/)提供。Inf2 实例专为 AI 工作负载从零设计，为生产负载提供出色的性能和性价比。

一年多以来，我们与 AWS 的产品和工程团队一起，把 AWS Trainium 和 Inferentia 芯片的高性能与低成本带给 Hugging Face 用户。我们的开源库 `[optimum-neuron](https://huggingface.co/docs/optimum-neuron/index)` 让在这些加速器上训练和部署 Hugging Face 模型变得简单。关于我们在[加速 transformers](https://huggingface.co/blog/accelerate-transformers-with-inferentia2)、[大语言模型](https://huggingface.co/blog/inferentia-llama2) 和 [text-generation-inference](https://huggingface.co/blog/text-generation-inference-on-inferentia2)（TGI）方面的工作，可以阅读相关文章。

今天，我们要把 Inferentia2 的能力直接、广泛地开放给 Hugging Face Hub 用户。

## 借助 Amazon SageMaker 让 10 万多个模型跑在 AWS Inferentia2 上

几个月前，我们推出了一种在 SageMaker 上部署大语言模型（LLM）的新方式，为受支持的模型（比如 Meta [Llama 3](https://huggingface.co/meta-llama/Meta-Llama-3-8B?sagemaker_deploy=true)）新增了 Inferentia/Trainium 选项。你可以把 Llama3 模型部署到 SageMaker 的 Inferentia2 实例上进行规模化推理，并享用 SageMaker 一整套全托管的模型构建与微调、MLOps 和治理能力。

[![catalog](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/inferentia-inference-endpoints/sagemaker.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/inferentia-inference-endpoints/sagemaker.png)

今天，我们把这种部署体验的支持范围扩大到 Hugging Face 上的 10 万多个公开模型，新增 14 种模型架构（`albert`、`bert`、`camembert`、`convbert`、`deberta`、`deberta-v2`、`distilbert`、`electra`、`roberta`、`mobilebert`、`mpnet`、`vit`、`xlm`、`xlm-roberta`）和 6 种机器学习任务（`text-classification`、`text-generation`、`token-classification`、`fill-mask`、`question-answering`、`feature-extraction`）。

按照下面简单的代码片段，AWS 客户就能轻松把模型部署到 Amazon SageMaker 的 Inferentia2 实例上。

## Hugging Face Inference Endpoints 新增对 AWS Inferentia2 的支持

从 Hub 部署模型最简单的方式是 [Hugging Face Inference Endpoints](https://huggingface.co/inference-endpoints/dedicated)。今天我们很高兴地推出 Hugging Face Inference Endpoints 的 Inferentia 2 新实例。现在，在 Hugging Face 上看到心仪的模型后，只需几次点击就能把它部署到 Inferentia2 上。要做的只是选好要部署的模型，在 Amazon Web Services 实例配置下选择新的 Inf2 实例选项，然后就完成了。

对于 Llama 3 这类受支持的模型，可以选两种配置：

- Inf2-small：2 核、32 GB 内存（$0.75/小时），非常适合 Llama 3 8B
- Inf2-xlarge：24 核、384 GB 内存（$12/小时），非常适合 Llama 3 70B

Hugging Face Inference Endpoints 按秒计费所用容量，配合副本自动扩缩（replica autoscaling）成本随负载上升，也支持 scale to zero 自动缩到零——两者都自动化、开箱即用。

[![catalog](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/inferentia-inference-endpoints/create-endpoint.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/inferentia-inference-endpoints/create-endpoint.png)

Inference Endpoints 使用 [Text Generation Inference for Neuron](https://huggingface.co/blog/text-generation-inference-on-inferentia2)（TGI）在 AWS Inferentia 上运行 Llama 3。TGI 是为规模化生产负载部署和服务 LLM 的专用方案，支持连续批处理（continuous batching）、流式输出等诸多特性。此外，用 Text Generation Inference 部署的 LLM 兼容 OpenAI SDK Messages API，如果你的 Gen AI 应用已经集成了 LLM，不用改应用代码，只需指向用 Hugging Face Inference Endpoints 部署的新 endpoint 即可。

把 endpoint 部署到 Inferentia2 之后，你可以用 UI 里提供的 Widget 或 OpenAI SDK 发送请求。

## 下一步

我们正在努力扩大 Hugging Face Inference Endpoints 在 AWS Inferentia2 上支持部署的模型范围。接下来计划加入对 Diffusion 和 Embedding 模型的支持，让你能借助 AWS Inferentia2 的加速和 Hugging Face Inference Endpoints 的易用性来生成图像、构建语义搜索和推荐系统。

同时，我们持续优化 Neuronx 上 Text Generation Inference（TGI）的性能，在开源库里让 AWS Inferentia 2 上的 LLM 部署更快、更高效。敬请期待这些更新，我们会继续增强能力、优化你的部署体验！
