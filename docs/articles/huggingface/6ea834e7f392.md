# Nyströmformer：用 Nyström 方法以线性时间与内存近似自注意力

本文由 Antoine SIMOULIN（asi，客座作者）撰写。

## 引言

Transformer 在各种自然语言处理和计算机视觉任务上展现了卓越的性能。它的成功可归功于自注意力机制——该机制捕捉输入中所有 token 之间的成对交互。然而，标准自注意力机制的时间和内存复杂度为 O(n2)O(n^2)O(n2)（其中 nnn 为输入序列长度），这使得在长输入序列上训练代价高昂。

[Nyströmformer](https://arxiv.org/abs/2102.03902) 是用 O(n)O(n)O(n) 复杂度近似标准自注意力的众多高效 Transformer 模型之一。Nyströmformer 在各类下游 NLP 与 CV 任务上表现出有竞争力的性能，同时改进了标准自注意力的效率。本博客的目的是向读者概述 Nyström 方法，以及如何将它改造用于近似自注意力。

## 用于矩阵近似的 Nyström 方法

Nyströmformer 的核心是用于矩阵近似的 Nyström 方法。它允许我们通过采样矩阵的部分行和列来近似该矩阵。考虑一个矩阵 Pn×nP^{n \times n}Pn×n，完整计算它代价很高。因此我们用 Nyström 方法近似它。我们首先从 PPP 中采样 mmm 行和 mmm 列。然后可以将采样到的行列排列如下：

将 P 表示为分块矩阵

于是我们得到四个子矩阵：AP,BP,FP,A_P, B_P, F_P,AP​,BP​,FP​ 以及 CPC_PCP​，其大小分别为 m×m,m×(n−m),(n−m)×mm \times m, m \times (n - m), (n - m) \times mm×m,m×(n−m),(n−m)×m 以及 (n−m)×(n−m)(n - m) \times (n - m)(n−m)×(n−m)。采样到的 mmm 列包含在 APA_PAP​ 和 FPF_PFP​ 中，而采样到的 mmm 行包含在 APA_PAP​ 和 BPB_PBP​ 中。因此 AP,BP,A_P, B_P,AP​,BP​ 和 FPF_PFP​ 的元素对我们是已知的，而我们要估计 CPC_PCP​。根据 Nyström 方法，CPC_PCP​ 由下式给出：

CPC_P = F_P A_P^+ B_PCP​=FP​AP+​BP​

这里 +++ 表示 Moore-Penrose 逆（或伪逆）。于是 PPP 的 Nyström 近似 P^\hat{P}P^ 可写为：

如第二行所示，P^\hat{P}P^ 可以表示为三个矩阵的乘积。这样做的理由稍后会明朗。

## 我们能用 Nyström 方法近似自注意力吗？

我们的最终目标是近似标准自注意力中的 softmax 矩阵：S = softmax QKTd \frac{QK^T}{\sqrt{d}} d​QKT​

这里 QQQ 和 KKK 分别表示查询（queries）和键（keys）。按照上述流程，我们会从 SSS 中采样 mmm 行和列、构成四个子矩阵，并得到 S^\hat{S}S^：

S 的 Nyström 近似

但是，从 SSS 中采样一列意味着什么？意味着我们从每一行中选取一个元素。回想 SSS 是如何计算的：最后一步运算是逐行的 softmax。要得到某一行中的一个元素，我们必须访问该行的所有其他元素（用于 softmax 的分母）。因此，采样一列需要我们知道矩阵中所有其他列。所以我们不能直接把 Nyström 方法用于近似 softmax 矩阵。

## 我们如何改造 Nyström 方法来近似自注意力？

作者提议不是从 SSS 采样，而是从查询和键中采样地标点（landmarks，即 Nyström 点）。我们把查询地标和键地标分别记作 Q~\tilde{Q}Q~​ 和 K~\tilde{K}K~​。Q~\tilde{Q}Q~​ 和 K~\tilde{K}K~​ 可用来构造与 SSS 的 Nyström 近似中相对应的三个矩阵。我们定义如下矩阵：

F~=softmax(QK~Td)A~=softmax(Q~K~Td)+B~=softmax(Q~KTd)\tilde{F} = softmax(\frac{Q\tilde{K}^T}{\sqrt{d}}) \hspace{40pt} \tilde{A} = softmax(\frac{\tilde{Q}\tilde{K}^T}{\sqrt{d}})^+ \hspace{40pt} \tilde{B} = softmax(\frac{\tilde{Q}K^T}{\sqrt{d}})F~=softmax(d​QK~T​)A~=softmax(d​Q~​K~T​)+B~=softmax(d​Q~​KT​)

F~\tilde{F}F~​、A~\tilde{A}A~​ 和 B~\tilde{B}B~​ 的大小分别为 (n×m,m×m,(n \times m, m \times m,(n×m,m×m, 和 m×nm \times nm×n。我们把 SSS 的 Nyström 近似中的三个矩阵替换为我们新定义的矩阵，从而得到另一种 Nyström 近似：

S^=F~A~B~=softmax(QK~Td)softmax(Q~K~Td)+softmax(Q~KTd)\begin{aligned}\hat{S} &= \tilde{F} \tilde{A} \tilde{B} \\ &= softmax(\frac{Q\tilde{K}^T}{\sqrt{d}}) softmax(\frac{\tilde{Q}\tilde{K}^T}{\sqrt{d}})^+ softmax(\frac{\tilde{Q}K^T}{\sqrt{d}}) \end{aligned}S^​=F~A~B~=softmax(d​QK~T​)softmax(d​Q~​K~T​)+softmax(d​Q~​KT​)​

这就是自注意力机制中 softmax 矩阵的 Nyström 近似。我们把该矩阵与值（VVV）相乘，从而得到自注意力的线性近似。注意，我们从未计算 QKTQK^TQKT 的乘积，因此避免了 O(n2)O(n^2)O(n2) 的复杂度。

## 我们如何选择地标点？

作者提议不是从 QQQ 和 KKK 采样 mmm 行，而是用段均值（segment means）来构造 Q~\tilde{Q}Q~​ 和 K~\tilde{K}K~​。在这一流程中，nnn 个 token 被分成 mmm 个段，并计算每个段的均值。理想情况下 mmm 远小于 nnn。根据论文中的实验，仅选择 323232 或 646464 个地标就能取得与标准自注意力及其他高效注意力机制相比有竞争力的性能，即便对于长序列长度（n=4096n=4096n=4096 或 819281928192）也是如此。

## Nyströmformer 如何实现？

Nyströmformer 的原始实现见[这里](https://github.com/mlpen/Nystromformer)，HuggingFace 实现见[这里](https://github.com/huggingface/transformers/blob/main/src/transformers/models/nystromformer/modeling_nystromformer.py)。我们来看 HuggingFace 实现中的几行代码（附加了一些注释）。注意，为简洁起见，省略了归一化、注意力掩码和深度卷积等细节。

```
key_layer = self.transpose_for_scores(self.key(hidden_states)) # K
value_layer = self.transpose_for_scores(self.value(hidden_states)) # V
query_layer = self.transpose_for_scores(mixed_query_layer) # Q

q_landmarks = query_layer.reshape(
    -1,
    self.num_attention_heads,
    self.num_landmarks,
    self.seq_len // self.num_landmarks,
    self.attention_head_size,
).mean(dim=-2) # \tilde{Q}

k_landmarks = key_layer.reshape(
    -1,
    self.num_attention_heads,
    self.num_landmarks,
    self.seq_len // self.num_landmarks,
    self.attention_head_size,
).mean(dim=-2) # \tilde{K}

kernel_1 = torch.nn.functional.softmax(torch.matmul(query_layer, k_landmarks.transpose(-1, -2)), dim=-1) # \tilde{F}
kernel_2 = torch.nn.functional.softmax(torch.matmul(q_landmarks, k_landmarks.transpose(-1, -2)), dim=-1) # \tilde{A} before pseudo-inverse

attention_scores = torch.matmul(q_landmarks, key_layer.transpose(-1, -2)) # \tilde{B} before softmax

kernel_3 = nn.functional.softmax(attention_scores, dim=-1) # \tilde{B}
attention_probs = torch.matmul(kernel_1, self.iterative_inv(kernel_2)) # \tilde{F} * \tilde{A}
new_value_layer = torch.matmul(kernel_3, value_layer) # \tilde{B} * V
context_layer = torch.matmul(attention_probs, new_value_layer) # \tilde{F} * \tilde{A} * \tilde{B} * V
```

## 在 HuggingFace 上使用 Nyströmformer

用于掩码语言建模（MLM）的 Nyströmformer 已在 HuggingFace 上提供。目前有 4 个检查点，对应不同的序列长度：[`nystromformer-512`](https://huggingface.co/uw-madison/nystromformer-512)、[`nystromformer-1024`](https://huggingface.co/uw-madison/nystromformer-1024)、[`nystromformer-2048`](https://huggingface.co/uw-madison/nystromformer-2048) 和 [`nystromformer-4096`](https://huggingface.co/uw-madison/nystromformer-4096)。地标数量 mmm 可通过 [`NystromformerConfig`](https://huggingface.co/docs/transformers/v4.18.0/en/model_doc/nystromformer#transformers.NystromformerConfig) 中的 `num_landmarks` 参数控制。我们来看一个用于 MLM 的 Nyströmformer 最小示例：

```
from transformers import AutoTokenizer, NystromformerForMaskedLM
import torch

tokenizer = AutoTokenizer.from_pretrained("uw-madison/nystromformer-512")
model = NystromformerForMaskedLM.from_pretrained("uw-madison/nystromformer-512")

inputs = tokenizer("Paris is the [MASK] of France.", return_tensors="pt")

with torch.no_grad():
    logits = model(**inputs).logits

# retrieve index of [MASK]
mask_token_index = (inputs.input_ids == tokenizer.mask_token_id)[0].nonzero(as_tuple=True)[0]

predicted_token_id = logits[0, mask_token_index].argmax(axis=-1)
tokenizer.decode(predicted_token_id)
```

```
from transformers import pipeline

unmasker("Paris is the [MASK] of France.")
```

## 结论

Nyströmformer 提供了一种对标准自注意力机制的高效近似，同时优于其他线性自注意力方案。在本博客中，我们概述了 Nyström 方法以及如何将其用于自注意力。有兴趣在下游任务上部署或微调 Nyströmformer 的读者可以在[这里](https://huggingface.co/docs/transformers/model_doc/nystromformer)找到 HuggingFace 文档。
