# Ryght 借助 Hugging Face 专家支持赋能医疗保健与生命科学

Andrew Reed（andrewrreed）、Johnny Crupi（johnnybio，RyghtAI）

本文另有中文版本 [简体中文](https://huggingface.co/blog/zh/ryght-case-study)。

> 本文由 Ryght 团队投稿。

## Ryght 是谁？

Ryght 正在构建一个面向医疗保健和生命科学领域定制的企业级生成式 AI 平台。今天是他们 [Ryght Preview](https://www.ryght.ai/signup?utm_campaign=Preview%20Launch%20April%2016%2C%2024&utm_source=Huggging%20Face%20Blog%20-%20Preview%20Launch%20Sign%20Up) 的正式发布，现已面向所有人开放。

生命科学公司正从各种来源（实验室数据、EMR、基因组学、理赔、药房、临床等）积累海量数据，但对这些数据的分析还很落后，从简单查询到开发有用的 ML 模型都需要大团队。业界对能驱动药物研发、临床试验和商业活动的可操作知识需求巨大，而精准医疗的兴起还在加速这一需求。

![Ryght Laptop](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/ryght-case-study/click-through.gif)

[Ryght 的](https://hubs.li/Q02sLGKL0)目标是赋能生命科学从业者，让他们快速、安全地获得所需洞察。为此，他们正在构建一个 SaaS 平台，提供行业专属的 AI 副手（copilot）和定制解决方案，帮助从业者和组织在各类复杂数据源上加速研究、分析和文档撰写。

认识到 AI 格局变化之快，Ryght 在旅程早期就通过 [Expert Support Program](https://huggingface.co/support) 寻求 Hugging Face 作为技术咨询伙伴。

## 一起克服挑战

> 我们与 Hugging Face 专家支持的合作，在加速我们生成式 AI 平台的开发上发挥了关键作用。AI 的快速演进格局有变革我们行业的潜力，而 Hugging Face 高性能、可投入企业生产的 Text Generation Inference (TGI) 和 Text Embeddings Inference (TEI) 服务本身就具有颠覆性。——Ryght CTO Johnny Crupi

Ryght 在着手构建其生成式 AI 平台时面临若干挑战。

### 1. 需要快速提升团队技能，在高动态环境中保持信息灵通

随着 AI 和 ML 技术推进如此迅速，确保团队跟得上最新技术、工具和最佳实践至关重要。这条持续学习的曲线很陡，需要齐心努力才能保持信息灵通。

能接触到在 AI 生态核心运作的 Hugging Face 专家团队，帮助 Ryght 跟上与其领域相关的最新进展和模型。这通过开放的、异步的沟通渠道、定期咨询会议和专门的技术工作坊来实现。

### 2. 在喧嚣的众多选项中识别最具[成本]效益的 ML 方法

AI 领域创新繁忙，工具、库、模型和方法论琳琅满目。对 Ryght 这样的初创公司来说，穿透这些噪音、识别哪些 ML 策略最适用于其在生命科学领域的独特用例，是当务之急。这不仅关乎理解当前最先进水平，还要前瞻哪些技术在未来仍相关、可扩展。

Hugging Face 作为 Ryght 技术团队的伙伴——协助方案设计、概念验证开发和生产工作负载优化。这包括为 Ryght 的具体需求量身定制的库、框架和模型推荐，以及如何使用它们的可视化示例。这份指引最终简化了决策流程、缩短了开发时间。

### 3. 需要开发强调安全、隐私与灵活性的高性能解决方案

鉴于对企业级解决方案的侧重，Ryght 把安全、隐私和治理放在首位。这要求一种灵活的架构，能实时对接各种大语言模型（LLM），这对他们生命科学专属内容的生成与查询处理是关键能力。

理解开源社区内的快速创新——尤其关于医疗 LLM——他们采用了一种支持"可插拔"LLM 的架构方式。这一设计选择让他们能在新的或专门的医疗 LLM 涌现时无缝评估并集成。

在 Ryght 的平台上，每个 LLM 都被注册并关联到一个或多个客户专属的推理端点。这一设置不仅保障了连接安全，还提供了在不同 LLM 之间切换的能力，带来无与伦比的灵活性——这一设计选择得益于采用 Hugging Face 的 [Text Generation Inference (TGI)](https://huggingface.co/docs/text-generation-inference/index) 和 [Inference Endpoints](https://huggingface.co/inference-endpoints/dedicated)。

除 TGI 外，Ryght 还把 [Text Embeddings Inference (TEI)](https://huggingface.co/docs/text-embeddings-inference/en/index) 集成进其 ML 平台。用 TEI 服务开源嵌入模型，相比只依赖专有嵌入是一次重大提升——让 Ryght 受益于更快的推理速度、免去速率限制的顾虑，以及服务自己微调模型的灵活性，以契合生命科学领域的独特需求。

为同时服务多个客户，他们的系统被设计成在保持低延迟的同时处理高并发的请求。他们的嵌入和推理服务超越简单的模型调用，涵盖一整套擅长批处理、排队和在 GPU 间分发模型处理的服务。这套基础设施对规避性能瓶颈、确保用户不经历延迟、从而维持最优系统响应时间至关重要。

## 结论
