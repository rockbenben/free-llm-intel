# 在 Intel® Gaudi® 2 AI 加速器上运行文本生成 Pipeline

本文由 Siddhant Jagtap（siddjags，客座作者）撰写。

随着生成式 AI（GenAI）革命方兴未艾，使用 Llama 2 这类开源 transformer 模型进行文本生成已成为风口浪尖的热点。无论是 AI 爱好者还是开发者，都希望借助这类模型的生成能力来服务自己的用例与应用。本文展示了如何使用 Optimum Habana 和一个自定义 pipeline 类，以 Llama 2 系列模型（7b、13b 和 70b）生成文本有多么简单——只需几行代码就能跑起模型！

这个自定义 pipeline 类的设计兼顾了出色的灵活性与易用性。此外，它提供了高层次的抽象，并能执行端到端的文本生成，包括预处理与后处理。使用该 pipeline 有多种方式：你可以在 Optimum Habana 仓库中运行 `run_pipeline.py` 脚本，可以把 pipeline 类加入你自己的 python 脚本，也可以用它初始化 LangChain 类。

## 前置条件

由于 Llama 2 模型属于受限（gated）仓库，如果你还没有申请访问权限，就需要先申请。首先，你需要访问 [Meta 官网](https://ai.meta.com/resources/models-and-libraries/llama-downloads)并接受条款。在 Meta 授予你访问权限后（可能需要一到两天），你还需要使用在 Meta 表单中填写的同一邮箱地址，[在 Hugging Face 上](https://huggingface.co/meta-llama/Llama-2-7b-hf)申请访问权限。

获得访问权限后，请运行以下命令登录你的 Hugging Face 账号（你需要一个 access token，可在[你的用户资料页](https://huggingface.co/settings/tokens)获取）：

```
huggingface-cli login
```

你还需要安装最新版本的 Optimum Habana 并克隆仓库以获取 pipeline 脚本。命令如下：

```
pip install optimum-habana==1.10.4
git clone -b v1.10-release https://github.com/huggingface/optimum-habana.git
```

如果你打算运行分布式推理，请根据你的 SynapseAI 版本安装对应的 DeepSpeed。此处我使用的是 SynapseAI 1.14.0。

```
pip install git+https://github.com/HabanaAI/DeepSpeed.git@1.14.0
```

现在，你就做好了用 pipeline 进行文本生成的一切准备！

## 使用 Pipeline

首先，进入你的 `optimum-habana` 检出目录中包含 pipeline 脚本的以下目录，并按照 `README` 中的说明更新你的 `PYTHONPATH`。

```
cd optimum-habana/examples/text-generation
pip install -r requirements.txt
cd text-generation-pipeline
```

如果你想根据自己选择的提示词生成一段文本，这里有一条示例命令。

```
python run_pipeline.py  --model_name_or_path meta-llama/Llama-2-7b-hf --use_hpu_graphs --use_kv_cache --max_new_tokens 100 --do_sample --prompt "Here is my prompt"
```

你也可以把多条提示词作为输入，并按如下方式更改生成时的 temperature 和 top_p 值。

```
python run_pipeline.py --model_name_or_path meta-llama/Llama-2-13b-hf --use_hpu_graphs --use_kv_cache --max_new_tokens 100 --do_sample --temperature 0.5 --top_p 0.95 --prompt "Hello world" "How are you?"
```

对于在 Llama-2-70b 这样的大模型上生成文本，这里给出一条使用 DeepSpeed 启动 pipeline 的示例命令。

```
python ../../gaudi_spawn.py --use_deepspeed --world_size 8 run_pipeline.py --model_name_or_path meta-llama/Llama-2-70b-hf --max_new_tokens 100 --bf16 --use_hpu_graphs --use_kv_cache --do_sample --temperature 0.5 --top_p 0.95 --prompt "Hello world" "How are you?" "Here is my prompt" "Once upon a time"
```

## 在 Python 脚本中使用

你可以按下面示例那样在自己的脚本中使用该 pipeline 类。请在 `optimum-habana/examples/text-generation/text-generation-pipeline` 目录下运行以下示例脚本。

```
import argparse
import logging

from pipeline import GaudiTextGenerationPipeline
from run_generation import setup_parser

# Define a logger
logging.basicConfig(
    format="%(asctime)s - %(levelname)s - %(name)s - %(message)s",
    datefmt="%m/%d/%Y %H:%M:%S",
    level=logging.INFO,
)
logger = logging.getLogger(__name__)

# Set up an argument parser
parser = argparse.ArgumentParser()
args = setup_parser(parser)

# Define some pipeline arguments. Note that --model_name_or_path is a required argument for this script
args.num_return_sequences = 1
args.model_name_or_path = "meta-llama/Llama-2-7b-hf"
args.max_new_tokens = 100
args.use_hpu_graphs = True
args.use_kv_cache = True
args.do_sample = True

# Initialize the pipeline
pipe = GaudiTextGenerationPipeline(args, logger)

# You can provide input prompts as strings
prompts = ["He is working on", "Once upon a time", "Far far away"]

# Generate text with pipeline
for prompt in prompts:
    print(f"Prompt: {prompt}")
    output = pipe(prompt)
    print(f"Generated Text: {repr(output)}")
```

> 你必须以 python <name_of_script>.py --model_name_or_path a_model_name 的形式运行上述脚本，因为 --model_name_or_path 是必填参数。不过，如代码片段所示，模型名称可以在程序中动态修改。

这表明 pipeline 类可以作用于字符串输入，并为我们完成数据预处理和后处理。

## 兼容 LangChain

通过 `use_with_langchain` 构造参数，可以把文本生成 pipeline 作为输入喂给 LangChain 类。你可以按如下方式安装 LangChain。

```
pip install langchain==0.0.191
```

下面是一个示例脚本，展示了 pipeline 类如何与 LangChain 配合使用。

```
import argparse
import logging

from langchain.llms import HuggingFacePipeline
from langchain.prompts import PromptTemplate
from langchain.chains import LLMChain

from pipeline import GaudiTextGenerationPipeline
from run_generation import setup_parser

# Define a logger
logging.basicConfig(
    format="%(asctime)s - %(levelname)s - %(name)s - %(message)s",
    datefmt="%m/%d/%Y %H:%M:%S",
    level=logging.INFO,
)
logger = logging.getLogger(__name__)

# Set up an argument parser
parser = argparse.ArgumentParser()
args = setup_parser(parser)

# Define some pipeline arguments. Note that --model_name_or_path is a required argument for this script
args.num_return_sequences = 1
args.model_name_or_path = "meta-llama/Llama-2-13b-chat-hf"
args.max_input_tokens = 2048
args.max_new_tokens = 1000
args.use_hpu_graphs = True
args.use_kv_cache = True
args.do_sample = True
args.temperature = 0.2
args.top_p = 0.95

# Initialize the pipeline
pipe = GaudiTextGenerationPipeline(args, logger, use_with_langchain=True)

# Create LangChain object
llm = HuggingFacePipeline(pipeline=pipe)

template = """Use the following pieces of context to answer the question at the end. If you don't know the answer,\
just say that you don't know, don't try to make up an answer.

Context: Large Language Models (LLMs) are the latest models used in NLP.
Their superior performance over smaller models has made them incredibly
useful for developers building NLP enabled applications. These models
can be accessed via Hugging Face's `transformers` library, via OpenAI
using the `openai` library, and via Cohere using the `cohere` library.

Question: {question}
Answer: """

prompt = PromptTemplate(input_variables=["question"], template=template)
llm_chain = LLMChain(prompt=prompt, llm=llm)

# Use LangChain object
question = "Which libraries and model providers offer LLMs?"
response = llm_chain(prompt.format(question=question))
print(f"Question 1: {question}")
print(f"Response 1: {response['text']}")

question = "What is the provided context about?"
response = llm_chain(prompt.format(question=question))
print(f"\nQuestion 2: {question}")
print(f"Response 2: {response['text']}")
```

> 该 pipeline 类已针对 LangChain 0.0.191 版本完成验证，可能无法与其他版本的该包配合工作。
