# 用开放的 ML 模型打造 Web 应用生成器

随着越来越多的代码生成模型公开可用，我们现在能以过去无法想象的方式实现文生网页（text-to-web）乃至文生应用（text-to-app）。

本教程介绍一种直接的 AI Web 内容生成方式：一次性流式传输并渲染内容。

**在线演示点这里！** → **[Webapp Factory](https://huggingface.co/spaces/jbilcke-hf/webapp-factory-wizardcoder)**

[![main_demo.gif](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/153_text_to_webapp/main_demo.gif)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/153_text_to_webapp/main_demo.gif)

## 在 Node 应用中使用 LLM

一提到 AI 和 ML，我们通常想到 Python，但 Web 开发社区重度依赖 JavaScript 和 Node。

以下是在这个平台上使用大语言模型的几种方式。

### 在本地运行模型

在 JavaScript 中运行 LLM 有多种途径：从使用 [ONNX](https://www.npmjs.com/package/onnxruntime-node)，到把代码转成 [WASM](https://blog.mithrilsecurity.io/porting-tokenizers-to-wasm/)，再到调用其他语言编写的外部进程。

其中一些技术已经有现成的 NPM 库：

- 使用 AI/ML 库，如 [transformers.js](https://huggingface.co/docs/transformers.js/index)（支持[代码生成](https://huggingface.co/docs/transformers.js/api/models#codegenmodelgenerateargs-codepromiseampltanyampgtcode)）
- 使用专门的 LLM 库，如 [llama-node](https://github.com/Atome-FE/llama-node)（浏览器里可用 [web-llm](https://github.com/mlc-ai/web-llm)）
- 通过 [Pythonia](https://www.npmjs.com/package/pythonia) 这类桥接库使用 Python 库

不过，在这种环境里运行大语言模型相当吃资源，尤其是用不上硬件加速的时候。

### 使用 API

如今各云厂商都提供使用语言模型的商业 API。Hugging Face 目前的方案是：

免费的 [Inference API](https://huggingface.co/docs/api-inference/index)，让任何人都能使用社区里小到中等规模的模型。

更高级、生产就绪的 [Inference Endpoints API](https://huggingface.co/inference-endpoints)，面向需要更大模型或自定义推理代码的用户。

这两个 API 都能在 Node 中通过 NPM 上的 [Hugging Face Inference API 库](https://www.npmjs.com/package/@huggingface/inference)使用。

💡 性能顶尖的模型通常需要大量内存（32GB、64GB 或更多）加上硬件加速才有好延迟（见[基准](https://huggingface.co/spaces/HuggingFaceH4/open_llm_leaderboard)）。但同时也看到一个趋势：一些模型体积在缩小的同时，在特定任务上保持相对不错的效果，资源需求降到 16GB 甚至 8GB 内存。

## 架构

我们将用 NodeJS 搭建生成式 AI Web 服务器。

模型选用跑在 Inference Endpoints API 上的 [WizardCoder-15B](https://huggingface.co/WizardLM/WizardCoder-15B-V1.0)，当然你可以自由换别的模型和技术栈。

- 从 Node 调用 Python 模块：[代码](https://huggingface.co/spaces/jbilcke-hf/template-node-ctransformers-express/tree/main)和 [space](https://huggingface.co/spaces/jbilcke-hf/template-node-ctransformers-express)

## 初始化项目

首先，新建一个 Node 项目（想省事可以直接[克隆这个模板](https://github.com/jbilcke-hf/template-node-express/generate)）。

```
git clone https://github.com/jbilcke-hf/template-node-express tutorial
cd tutorial
nvm use
npm install
```

然后安装 Hugging Face Inference 客户端：

```
npm install @huggingface/inference
```

在 `src/index.mts` 中配置：

```
import { HfInference } from '@huggingface/inference'

// to keep your API token secure, in production you should use something like:
// const hfi = new HfInference(process.env.HF_API_TOKEN)
const hfi = new HfInference('** YOUR TOKEN **')
```

## 配置 Inference Endpoint

💡 **注：** 如果不想为了做这个教程花钱买 Endpoint 实例，可以跳过这一步，改看[这个免费的 Inference API 示例](https://huggingface.co/spaces/jbilcke-hf/webapp-factory-any-model/blob/main/src/index.mts)。请注意那只对小模型有效，威力可能没那么强。

要部署新 Endpoint，前往 [Endpoint 创建页](https://ui.endpoints.huggingface.co/new)。

在 **Model Repository** 下拉框中选择 `WizardCoder`，并确保选了足够大的 GPU 实例：

[![new_endpoint.jpg](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/153_text_to_webapp/new_endpoint.jpg)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/153_text_to_webapp/new_endpoint.jpg)

Endpoint 创建完成后，可以从[这个页面](https://ui.endpoints.huggingface.co)复制 URL：

[![deployed_endpoints.jpg](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/153_text_to_webapp/deployed_endpoints.jpg)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/153_text_to_webapp/deployed_endpoints.jpg)

配置客户端使用它：

```
const hf = hfi.endpoint('** URL TO YOUR ENDPOINT **')
```

现在就可以让推理客户端使用我们的私有端点来调用模型：

```
const { generated_text } = await hf.textGeneration({
  inputs: 'a simple "hello world" html page: <html><body>'
});
```

## 生成 HTML 流

接下来，当访问 `/app` 这类 URL 时，往浏览器返回 HTML。

我们用 Express.js 创建一个端点，把 Hugging Face Inference API 的结果流出去。

```
import express from 'express'

import { HfInference } from '@huggingface/inference'

const hfi = new HfInference('** YOUR TOKEN **')
const hf = hfi.endpoint('** URL TO YOUR ENDPOINT **')

const app = express()
```

因为此刻还没有 UI，界面就是一个简单的 URL 参数来传提示词：

```
app.get('/', async (req, res) => {

  // send the beginning of the page to the browser (the rest will be generated by the AI)
  res.write('<html><head></head><body>')

  const inputs = `# Task
Generate ${req.query.prompt}
# Out
<html><head></head><body>`

  for await (const output of hf.textGenerationStream({
    inputs,
    parameters: {
      max_new_tokens: 1000,
      return_full_text: false,
    }
  })) {
    // stream the result to the browser
    res.write(output.token.text)

    // also print to the console for debugging
    process.stdout.write(output.token.text)
  }

  req.end()
})

app.listen(3000, () => { console.log('server started') })
```

启动 Web 服务器：

```
npm run start
```

打开 `https://localhost:3000?prompt=some%20prompt`。等一会儿你应该能看到一些朴素的 HTML 内容。

## 调优提示词

每个语言模型对提示词的反应都不一样。对 WizardCoder 来说，简单的指令往往效果最好：

```
const inputs = `# Task
Generate ${req.query.prompt}
# Orders
Write application logic inside a JS <script></script> tag.
Use a central layout to wrap everything in a <div class="flex flex-col items-center">
# Out
<html><head></head><body>`
```

### 使用 Tailwind

Tailwind 是流行的样式化 CSS 框架，WizardCoder 开箱就擅长它。

这让代码生成可以现场写样式，无需在页面开头或结尾生成样式表（那样会让页面显得卡住）。

为了改善效果，我们还可以用"示范引路"的方式引导模型（`<body class="p-4 md:p-8">`）。

```
const inputs = `# Task
Generate ${req.query.prompt}
# Orders
You must use TailwindCSS utility classes (Tailwind is already injected in the page).
Write application logic inside a JS <script></script> tag.
Use a central layout to wrap everything in a <div class="flex flex-col items-center'>
# Out
<html><head></head><body class="p-4 md:p-8">`
```

### 防止幻觉

相比更大的通用模型，专门做代码生成的轻量模型更难可靠地防止幻觉和失败（比如把整个指令复读一遍，或者写"lorem ipsum"占位文本），但我们可以设法缓解。

你可以试试命令式语气并重复指令。另一个高效办法是用英文给出部分输出来"带路"：

```
const inputs = `# Task
Generate ${req.query.prompt}
# Orders
Never repeat these instructions, instead write the final code!
You must use TailwindCSS utility classes (Tailwind is already injected in the page)!
Write application logic inside a JS <script></script> tag!
This is not a demo app, so you MUST use English, no Latin! Write in English! 
Use a central layout to wrap everything in a <div class="flex flex-col items-center">
# Out
<html><head><title>App</title></head><body class="p-4 md:p-8">`
```

## 加入图像支持

现在我们有了能生成 HTML、CSS 和 JS 代码的系统，但当它被要求产出图片时，容易幻觉出不存在的 URL。

好在图像生成模型有的是选择！

→ 最快的起步方式是用免费 [Inference API](https://huggingface.co/docs/api-inference/index) 调用 hub 上[公开模型](https://huggingface.co/spaces/huggingface-projects/diffusers-gallery)之一的 Stable Diffusion：

```
app.get('/image', async (req, res) => {
  const blob = await hf.textToImage({
    inputs: `${req.query.caption}`,
    model: 'stabilityai/stable-diffusion-2-1'
  })
  const buffer = Buffer.from(await blob.arrayBuffer())
  res.setHeader('Content-Type', blob.type)
  res.setHeader('Content-Length', buffer.length)
  res.end(buffer)
})
```

在提示词里加上这一行，就足够指挥 WizardCoder 使用我们新的 `/image` 端点了！（其他模型可能要另调）：

```
To generate images from captions call the /image API: <img src="/image?caption=photo of something in some place" />
```

你也可以说得更具体，例如：

```
Only generate a few images and use descriptive photo captions with at least 10 words!
```

## 加点 UI

[Alpine.js](https://alpinejs.dev/) 是个极简框架，无需安装、构建流水线、JSX 处理就能做出交互式 UI。

一切都发生在页面内，是做快速演示 UI 的好选择。

下面这个静态 HTML 页面可以放到 `/public/index.html`：

```
<html>
  <head>
    <title>Tutorial</title>
    <script defer src="https://cdn.jsdelivr.net/npm/alpinejs@3.x.x/dist/cdn.min.js"></script>
    <script src="https://cdn.tailwindcss.com"></script>
  </head>
  <body>
    <div class="flex flex-col space-y-3 p-8" x-data="{ draft: '', prompt: '' }">
      <textarea
          name="draft"
          x-model="draft"
          rows="3"
          placeholder="Type something.."
          class="font-mono"
         ></textarea> 
      <button
        class="bg-green-300 rounded p-3"
        @click="prompt = draft">Generate</button>
      <iframe :src="`/app?prompt=${prompt}`"></iframe>
    </div>
  </body>
</html>
```

要让它工作，还得做些改动：

```

   ...
```

## 优化输出

到目前为止，我们生成的是完整的 Tailwind 工具类序列——这很好地把设计自由交给了语言模型。

但这种方式也非常啰嗦，消耗了我们 token 配额的大头。

为了让输出更密，我们可以使用 [Daisy UI](https://daisyui.com/docs/use/)——一个把 Tailwind 工具类组织成设计系统的 Tailwind 插件。思路是：组件用简写类名，其余用工具类。

有些语言模型可能不了解 Daisy UI（毕竟是个小众库），这时可以在提示词里加一份 [API 文档](https://huggingface.co/spaces/jbilcke-hf/webapp-factory-wizardcoder/blob/main/src/daisy.mts)：

```
# DaisyUI docs
## To create a nice layout, wrap each article in:
<article class="prose"></article>
## Use appropriate CSS classes
<button class="btn ..">
<table class="table ..">
<footer class="footer ..">
```
