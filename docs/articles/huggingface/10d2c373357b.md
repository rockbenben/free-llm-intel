# 介绍 Trackio：Hugging Face 出品的轻量级实验跟踪库

太长不看版：[Trackio](https://github.com/gradio-app/trackio) 是一个全新的开源免费实验跟踪 Python 库，提供本地仪表盘，并与 Hugging Face Spaces 无缝集成，方便共享与协作。由于 `trackio` 可以直接替换 `wandb`，用你熟悉的语法就能上手！

## 背景

如果你训练过自己的机器学习模型，就知道在训练过程中跟踪指标、参数和超参数，事后再可视化它们以更好理解这次训练，有多重要。

大多数机器学习研究者会用专门的实验跟踪库来做这件事。但这些库要么收费、要么配置复杂，要么缺乏快速实验和分享所需的灵活性。

## 我们为什么转向 Trackio

在 Hugging Face，我们的科学团队已开始用 [Trackio](https://github.com/gradio-app/trackio) 做研究项目。与其他跟踪方案相比，我们发现了几大关键优势：

**易分享、易嵌入**：Trackio 让分享训练进展给同事、或用 iframe 把图表直接嵌进博客和文档变得异常简单。当你想展示某条训练曲线或某个指标、又不想让别人注册账号、研究复杂仪表盘时，这特别有价值。

**标准化与透明**：GPU 能耗这类指标值得跟踪并分享给社区，让大家对模型训练的能源需求与环境影响有更清楚的认识。Trackio 直接从 `nvidia-smi` 命令取信息，量化和比较能耗很容易，也方便加进[模型卡](https://huggingface.co/docs/hub/model-cards)。

**数据可及性**：一些跟踪工具把你的数据锁在专有 API 后面，Trackio 则让提取和分析所记录的数据非常直接。这对需要做自定义分析、或把训练指标整合进研究工作流的研究者至关重要。

**实验的灵活性**：Trackio 的轻量设计让我们能在训练过程中轻松试验新的跟踪功能。例如，记录张量时可以自行决定何时把张量从 GPU 搬到 CPU——当你要跟踪模型/中间状态又不想牺牲性能时，这能显著提升训练吞吐。

## 使用 Trackio

那么 Trackio 到底是什么、怎么用？Trackio 是一个[开源 Python 库](https://github.com/gradio-app/trackio)，让你跟踪任意指标，并用本地 [Gradio](https://gradio.dev/) 仪表盘可视化。你还可以把仪表盘同步到 Hugging Face Spaces——这意味着只要分享一个 URL 就能把仪表盘给别人看。由于 Spaces 可私有可公开，你可以选择对全网公开仪表盘，或只在你的 Hugging Face 组织成员之间分享。

## 安装

用 pip 安装 `trackio`：

```
pip install trackio
```

或者偏好 `uv` 的话：

```
uv pip install trackio
```

## 用法

`trackio` 的设计目标就是直接替换 `wandb` 这类实验跟踪库。API 兼容 `wandb.init`、`wandb.log` 和 `wandb.finish`，你只需在代码里把 `trackio` 当作 `wandb` 导入：

```
- import wandb
+ import trackio as wandb
```

示例：

```
import trackio
import random
import time

runs = 3
epochs = 8

def simulate_multiple_runs():
    for run in range(runs):
        trackio.init(project="fake-training", config={
            "epochs": epochs,
            "learning_rate": 0.001,
            "batch_size": 64
        })
        for epoch in range(epochs):
            train_loss = random.uniform(0.2, 1.0)
            train_acc = random.uniform(0.6, 0.95)
            val_loss = train_loss - random.uniform(0.01, 0.1)
            val_acc = train_acc + random.uniform(0.01, 0.05)
            trackio.log({
                "epoch": epoch,
                "train_loss": train_loss,
                "train_accuracy": train_acc,
                "val_loss": val_loss,
                "val_accuracy": val_acc
            })
            time.sleep(0.2)
        trackio.finish()

simulate_multiple_runs()
```

### 可视化结果

记录完实验后，启动仪表盘来可视化结果。在终端运行：

```
trackio show
```

或从 Python 启动：

```
import trackio
trackio.show()
```

也可以指定项目名：

```
trackio show --project "my project"
```

Python 中：

```
trackio.show(project="my project")
```

### 与 🤗 Spaces 共享

要把本地仪表盘同步到 Hugging Face Spaces，只需给 `init` 传一个 `space_id`：

```
trackio.init(project="fake-training", space_id="org_name/space_name")
```

如果仪表盘托管在 Spaces 上，直接把 URL 分享出去，或用 iframe 嵌入任何地方：

```
<iframe src="https://org_name-space_name.hf.space/?project=fake-training&metrics=train_loss,train_accuracy&sidebar=hidden" width=600 height=600 frameBorder="0"></iframe>
```

由于 Spaces 可私可公，你可以公开分享仪表盘，或只在你的 Hugging Face 组织成员间分享——全部免费！

把 Trackio 仪表盘同步到 Hugging Face Spaces 后，数据会写入 Spaces 上的临时 Sqlite 数据库。由于 Space 重启会重置这个数据库，Trackio 还会每 5 分钟把 Sqlite 数据库转成 Parquet 数据集，备份到一个 Hugging Face Dataset。这意味着你随时可以在 Hugging Face 数据集里查看记录的指标：

提示：给 `trackio.init()` 传入 `dataset_id` 可以指定这个数据集的名字。

### 与 🤗 Transformers 和 🤗 Accelerate 集成

Trackio 与 `transformers`、`accelerate` 等 Hugging Face 库原生集成，极少配置即可记录指标。

**配合 `transformers.Trainer`：**

```
import numpy as np
from datasets import Dataset
from transformers import Trainer, AutoModelForCausalLM, TrainingArguments

# Create a fake dataset
data = np.random.randint(0, 1000, (8192, 64)).tolist()
dataset = Dataset.from_dict({"input_ids": data, "labels": data})

# Train a model using the Trainer API
trainer = Trainer(
    model=AutoModelForCausalLM.from_pretrained("Qwen/Qwen3-0.6B"),
    args=TrainingArguments(run_name="fake-training", report_to="trackio"),
    train_dataset=dataset,
)
trainer.train()
```

**配合 `accelerate`：**

```
from accelerate import Accelerator

accelerator = Accelerator(log_with="trackio")
accelerator.init_trackers("fake-training")

...  # Prepare the model, dataloader, etc.

for step, batch in enumerate(dataloader):
    ...  # Your training logic here
    accelerator.log({"training_loss": loss}, step=step)

accelerator.end_training()
```

不需要额外配置——接上就开跟踪。

## 设计原则

- API 兼容主流实验跟踪库，迁出迁入都顺滑。
- 本地优先：日志与仪表盘默认在本地运行、本地持久化，可以选择托管到 Hugging Face Spaces。
- 轻量可扩展：核心代码库不到 1000 行 Python，易于理解和修改。
- 免费开源：包括托管在 Hugging Face 在内的所有功能都免费。
- 构建在 🤗 Datasets 和 Spaces 之上，数据处理与可视化更可靠。

## 下一步

Trackio 有意保持轻量，目前还在 beta。其他跟踪工具里的某些功能——比如 artifact 管理、复杂可视化——尚未提供。如果你需要这些功能，请到[这里](https://github.com/gradio-app/trackio/issues)提 issue。

鉴于 Trackio 的轻量与开源，我们非常乐意与机器学习社区一起，设计一个适用于我们所有人的实验跟踪产品！
