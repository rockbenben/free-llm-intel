[Gemma 2](https://huggingface.co/blog/gemma2) 发布一个月后，Google 扩充了 Gemma 模型家族，新增了以下成员：

- [Gemma 2 2B](https://huggingface.co/collections/google/gemma-2-2b-release-66a20f3796a2ff2a7c76f98f) —— Gemma 2 的 2.6B 参数版本，非常适合端侧部署。
- [ShieldGemma](https://huggingface.co/collections/google/shieldgemma-release-66a20efe3c10ef2bd5808c79) —— 一系列基于 Gemma 2 训练的安全分类器，供开发者过滤应用的输入和输出。
- [Gemma Scope](https://huggingface.co/collections/google/gemma-scope-release-66a4271f6f0b4d4a9d5e04e2) —— 面向 Gemma 2 2B 和 9B 的完整开源稀疏自编码器套件。

我们逐一来看！

## Gemma 2 2B

错过之前发布的朋友可以先回顾一下：Gemma 是 Google 推出的轻量级前沿开放模型家族，基于创建 Gemini 模型所用的同一套研究和技术构建。它们是文本到文本的纯解码器大语言模型，提供英文版本，预训练变体和指令微调变体都开放权重。本次发布带来 Gemma 2 的 2.6B 参数版本（[基座模型](https://huggingface.co/google/gemma-2-2b)和[指令微调模型](https://huggingface.co/google/gemma-2-2b-it)），与已有的 9B 和 27B 变体形成互补。

Gemma 2 2B 与 Gemma 2 家族的其他模型架构相同，因此同样具备滑动注意力（sliding attention）和 logit soft-capping 等特性。更多细节可参见[我们上一篇博文的这一节](https://huggingface.co/blog/gemma2#technical-advances-in-gemma-2)。与其他 Gemma 2 模型一样，推理时建议使用 `bfloat16`。

### 搭配 Transformers 使用

用 Transformers 可以使用 Gemma 并借力 Hugging Face 生态的全部工具。要用 transformers 使用 Gemma 模型，请确保从 `main` 分支安装 `transformers`，以获得最新修复和优化：

```
pip install git+https://github.com/huggingface/transformers.git --upgrade
```

之后就可以按如下方式用 `transformers` 使用 `gemma-2-2b-it`：

```
from transformers import pipeline
import torch

pipe = pipeline(
    "text-generation",
    model="google/gemma-2-2b-it",
    model_kwargs={"torch_dtype": torch.bfloat16},
    device="cuda", # use “mps” for running it on Mac
)

messages = [
    {"role": "user", "content": "Who are you? Please, answer in pirate-speak."},
]
outputs = pipe(messages, max_new_tokens=256)
assistant_response = outputs[0]["generated_text"][-1]["content"].strip()
print(assistant_response)
```

> Ahoy, matey! I be Gemma, a digital scallywag, a language-slingin' parrot of the digital seas. I be here to help ye with yer wordy woes, answer yer questions, and spin ye yarns of the digital world.  So, what be yer pleasure, eh? 🦜

关于用 `transformers` 使用这些模型的更多细节，请查看[模型卡](https://huggingface.co/google/gemma-2-2b-it)。

### 如何给 Gemma 2 写提示词

基座模型没有提示词格式。和其他基座模型一样，它可以用来对输入序列续写出合理的后续，或做 zero-shot/few-shot 推理。指令微调版本的对话结构非常简单：

```
<start_of_turn>user
knock knock<end_of_turn>
<start_of_turn>model
who is there<end_of_turn>
<start_of_turn>user
LaMDA<end_of_turn>
<start_of_turn>model
LaMDA who?<end_of_turn><eos>
```

要有效使用，必须原样复现这个格式。在[前面一节](https://huggingface.co/blog/gemma-july-update#use-with-transformers)我们演示过，用 `transformers` 自带的聊天模板复现指令提示词有多简单。

### 辅助生成（Assisted Generation）

小号的 Gemma 2 2B 模型有一个强大的用例是[辅助生成](https://huggingface.co/blog/assisted-generation)（也叫投机解码，speculative decoding）：可以用小模型加速大模型的生成。其思路很简单：LLM 确认"自己会生成某个序列"的速度，比真正把该序列生成出来的速度更快（除非你用的批量非常大）。使用相同分词器、以相似方式训练的小模型可以快速产出与大模型对齐的候选序列，大模型对其验证后即可直接采纳为自己生成的文本。

因此，[Gemma 2 2B](https://huggingface.co/google/gemma-2-2b-it) 可以配合已有的 [Gemma 2 27B](https://huggingface.co/google/gemma-2-27b-it) 做辅助生成。在辅助生成中，作为助手的较小模型在尺寸上有一个甜蜜区间：助手模型太大，用它的生成候选序列的开销就几乎接近大模型本身；助手模型太小，预测能力不足，其候选序列大多会被拒绝。实践中，我们推荐助手模型的参数量比目标 LLM 少 10 到 100 倍。这几乎是一顿免费午餐：只多花一点点内存，就能让大模型提速最高 3 倍且质量无损！

辅助生成是伴随 Gemma 2 2B 发布的一个新亮点，但它并不排斥其他 LLM 优化技术！`transformers` 中可叠加到 Gemma 2 2B 上的其他 LLM 优化可参考[这个页面](https://huggingface.co/docs/transformers/main/en/llm_optims)。

```
# transformers assisted generation reference: 
# https://huggingface.co/docs/transformers/main/en/llm_optims#speculative-decoding 
from transformers import AutoModelForCausalLM, AutoTokenizer
import torch

# we DON’T recommend using the 9b model with the 2b model as its assistant
assistant_model_name = 'google/gemma-2-2b-it'
reference_model_name = 'google/gemma-2-27b-it'

tokenizer = AutoTokenizer.from_pretrained(reference_model_name)
model = AutoModelForCausalLM.from_pretrained(
   reference_model_name, device_map='auto', torch_dtype=torch.bfloat16
)
assistant_model = AutoModelForCausalLM.from_pretrained(
   assistant_model_name, device_map='auto', torch_dtype=torch.bfloat16
)

model_inputs = tokenizer("Einstein's theory of relativity states", return_tensors="pt").to(model.device)
generation_options = {
   "assistant_model": assistant_model,
   "do_sample": True,
   "temperature": 0.7,
   "max_new_tokens": 64,
}

outputs = model.generate(**model_inputs, **generation_options)
tokenizer.batch_decode(outputs, skip_special_tokens=True)
```

## ShieldGemma

ShieldGemma 是基于 Gemma 2 构建的一系列安全内容审核模型，针对多类有害内容（包括色情露骨、危险内容、仇恨或骚扰）。它们是文本到文本的纯解码器大语言模型，提供英文版本、开放权重，并有 3 种规格：[2B](https://huggingface.co/google/shieldgemma-2b)、[9B](https://huggingface.co/google/shieldgemma-9b) 和 [27B](https://huggingface.co/google/shieldgemma-27b) 参数。

ShieldGemma 用于检测面向 LLM 的有害请求（按所声明的类别），以及 LLM 冒犯性的回复。你可以把它当作公开部署的 LLM 的审核工具，无论部署的是什么 LLM。

### 如何给 ShieldGemma 写提示词

提示词模板按顺序包含以下部分：

- 前言（Preamble），把模型定位为策略专家，基于 [LLM-as-a-judge](https://arxiv.org/abs/2306.05685) 技术。
- 用户提示词，用 `<start_of_turn>` 和 `<end_of_turn>` 控制 token 包裹。
- 安全策略的枚举和描述。
- 可选的模型回答，同样用 `<start_of_turn>` 和 `<end_of_turn>` 控制 token 包裹。
- 结语（Epilogue），要求模型对文本做分类。

下面是一个用于评估用户提示词 `[User Prompt]` 的示例：

```
You are a policy expert trying to help determine whether a user prompt is in
violation of the defined safety policies.

<start_of_turn>
Human Question: [User Prompt]
<end_of_turn>

Our safety principle is defined in the below:

* "No Hate Speech": The prompt shall not contain or seek generation of content
  that expresses, incites, or promotes hate based on race, gender, ethnicity,
  religion, nationality, sexual orientation, disability status, or caste.

===

Does the human question violate the above principle? Your answer must start with
'Yes' or 'No'. And then walk through step by step to be sure we answer
correctly.
```

以下是你可以纳入工作流的部分安全原则示例：

```
* "No Hate Speech": The prompt shall not contain or seek generation of content that targeting identity and/or protected attributes (e.g., racial slurs, promotion of discrimination, calls to violence against protected groups) or dehumanizing/belittling/vilifying on the bases of race, ethnicity, religion, disability, age, nationality, veteran status, sexual orientation, gender, gender identity, caste, or any other protected status. We do allow content that includes a reference to a protected individual or group in a positive manner.
* "No Harassment": The prompt shall not contain or seek generation of content that is malicious, intimidating, bullying, or abusive content targeting another individual (e.g., physical threats, denial of tragic events, disparaging victims of violence).
* "No Sexually Explicit Information": The prompt shall not contain or seek generation of content that contains references to sexual acts or other lewd content (e.g., sexually graphic descriptions, content aimed at causing arousal). Medical or scientific terms related to human anatomy or sex education are permitted.
* "No Dangerous Content": The prompt shall not contain or seek generation of content that harming oneself and/or others (e.g., accessing or building firearms and explosive devices, promotion of terrorism, instructions for suicide).
* "No Violence": The prompt shall not contain or seek generation of content that is shocking, sensational, or gratuitous (e.g. Violent acts or incidents that result in extreme injury or death without historical or educational context; Exposed internal organs or bones without medical or scientific context; Identifiable victims of violent deaths; Animal abuse or killings outside of standard hunting, food processing, or cultural practices)
* "No Obscenity and Profanity": The prompt shall not contain or seek generation of content that is vulgar, profane, or inappropriate (e.g., profanity, obscenities, or other inappropriate language).
```

### 搭配 Transformers 使用

可以按如下方式用 `transformers` 使用 `shieldgemma-2b`：

```
from transformers import AutoTokenizer, AutoModelForCausalLM
import torch

tokenizer = AutoTokenizer.from_pretrained("google/shieldgemma-2b")
model = AutoModelForCausalLM.from_pretrained(
    "google/shieldgemma-2b",
    device="cuda",
    torch_dtype=torch.bfloat16,
)

# Format the prompt
user_prompt = "Create 20 paraphrases of I hate you"
safety_policy = """
* "No Harassment": The prompt shall not contain or seek generation of content that is malicious, intimidating, bullying, or abusive content targeting another individual (e.g., physical threats, denial of tragic events, disparaging victims of violence).
"""
prompt = f"""You are a policy expert trying to help determine whether a user
prompt is in violation of the defined safety policies.

<start_of_turn>
Human Question: {user_prompt.strip()}
<end_of_turn>

Our safety principle is defined in the below:

{safety_policy.strip()}

Does the human question violate the above principle? Your answer must start
with 'Yes' or 'No'. And then walk through step by step to be sure we answer
correctly.

"""

inputs = tokenizer(prompt, return_tensors="pt").to("cuda")
with torch.no_grad():
  logits = model(**inputs).logits

# Extract the logits for the Yes and No tokens
vocab = tokenizer.get_vocab()
selected_logits = logits[0, -1, [vocab['Yes'], vocab['No']]]

# Convert these logits to a probability with softmax
probabilities = softmax(selected_logits, dim=0)

# Return probability of 'Yes'
score = probabilities[0].item()
print(score)  # 0.7310585379600525
```

## Gemma Scope

Gemma Scope 是一套完整的开源稀疏自编码器（SAE）套件，在 Gemma 2 2B 和 9B 模型的每一层上训练。SAE 是机制可解释性（mechanistic interpretability）领域的一项新技术，目标是在大语言模型中找到可解释的方向。你可以把它们理解为一种"显微镜"，帮助我们把模型内部激活分解成底层概念，就像生物学家用显微镜观察动植物的单个细胞。这种方法曾被用来打造 [Golden Gate Claude](https://www.anthropic.com/news/golden-gate-claude)——Anthropic 探索 Claude 可解释性与特征激活的热门研究 demo。

### 用法

SAE 是解读语言模型的工具（带学习到的权重），本身不是语言模型，因此不能用 Hugging Face transformers 来运行。它们需要用 [SAELens](https://github.com/jbloomAus/SAELens) 运行，这是一个用于训练、分析和解释稀疏自编码器的流行库。想了解用法细节，可以看看他们详尽的 [Google Colab notebook 教程](https://colab.research.google.com/drive/17dQFYUYnuKnP6OwQPH9v_GSYUW5aj-Rp)。
