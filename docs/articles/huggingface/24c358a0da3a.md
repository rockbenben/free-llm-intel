# XLSCOUT 推出 ParaEmbed 2.0：在 Hugging Face 专家支持下为专利与 IP 量身打造的嵌入模型

Andrew Reed

andrewrreed

Khushwant Rai

Khushwant78

xlscout-ai

> 本文由 XLSCOUT 团队投稿。

[XLSCOUT](https://xlscout.ai/) 是总部位于多伦多的知识产权（IP）AI 领军企业。通过与 Hugging Face 专家支持计划（Expert Support Program）的一次雄心勃勃的合作，他们开发了强大的专有嵌入模型 **ParaEmbed 2.0**。这次合作聚焦于把最先进（state-of-the-art）的 AI 技术与开源模型应用于更深层地理解和分析复杂的专利文档——包括专利领域的专门术语、上下文和关系。这让 XLSCOUT 的产品能在撰写专利申请、专利无效检索，以及确认想法相对既有专利与文献的新颖性方面提供最佳表现。

通过在专利专家精挑细选的高质量、多领域专利数据上微调，ParaEmbed 2.0 相比其 2023 年 10 月发布的前代 [ParaEmbed 1.0](https://xlscout.ai/pressrelease/xlscout-paraembed-an-embedding-model-fine-tuned-on-patent-and-technology-data-is-now-opensource-and-available-on-hugging-face)，**准确率提升了惊人的 23%**。凭借这一进步，ParaEmbed 2.0 如今能以更高的精度捕捉上下文，并把专利与现有技术（prior art）、想法、产品或标准进行映射。

## 迈向更强专利分析的旅程

起初，XLSCOUT 尝试用专有 AI 模型做专利分析，但发现 GPT-4、text-embedding-ada-002 这类闭源模型难以捕捉技术与专业化专利权利要求所需的细腻上下文。

在 Hugging Face 的指导下，XLSCOUT 集成了 BGE-base-v1.5、Llama 2 70B、Falcon 40B、Mixtral 8x7B 等开源模型，并在专有专利数据上做微调，得到了更贴合、性能更强的解决方案。这一转变带来了对复杂技术概念与术语更准确的理解，彻底革新了技术文档与专利的分析方式。

## 通过专家支持计划与 Hugging Face 协作

与 Hugging Face 的合作对提升 XLSCOUT 解决方案的质量和性能起到了关键作用。以下是这段伙伴关系如何演进及其影响的详细概览：

- **初始开发与测试：** XLSCOUT 最初在 Google Cloud Platform（GCP）上自建并测试了一个定制 TorchServe 推理服务器，用分布式数据并行（DDP）服务多个副本。集成 ONNX 优化后，达到约每秒 300 条嵌入的性能。
- **通过微调增强模型性能：** 嵌入模型的微调使用了专利专家整理的数据。这一工作流不仅产出更精确、上下文更贴切的嵌入，还显著改善了性能指标，确保检出相关现有技术的能力更准。
- **高吞吐服务：** 借助 Hugging Face 的 [Inference Endpoints](https://huggingface.co/inference-endpoints/dedicated)（内置负载均衡），XLSCOUT 现在用 [Text Embedding Inference (TEI)](https://huggingface.co/docs/text-embeddings-inference/en/index) 服务嵌入模型，这一高吞吐用例已在生产环境成功运行。新方案性能出色，**每秒可交付约 2700 条嵌入！**
- **LLM 提示与推理：** 合作内容包括 LLM 提示工程与推理方面的尝试，提升了模型生成准确、贴合上下文的专利草案的能力。在专利撰写用例上应用提示工程，确保提示词产出连贯、完整且法律上严谨的专利文档。
- **用指令数据微调 LLM：** 指令数据的格式化与微调基于 Meta 和 Mistral 的模型实现。这轮微调让专利撰写流程中某些环节的生成更精确、更细致，进一步改善了输出质量。

与 Hugging Face 的伙伴关系对 XLSCOUT 来说是颠覆性的：处理速度、准确率和 LLM 驱动方案的整体质量都显著提升。这次协作确保高校、律所和其他客户都能受益于最前沿的 AI 技术，为专利领域注入效率与创新。

## XLSCOUT 基于 AI 的 IP 解决方案

XLSCOUT 提供尖端的 AI 驱动解决方案，大幅提升专利相关流程的效率与准确度。企业、高校和律所广泛采用这些方案来简化 IP 工作流的各个环节——从新颖性检索、无效分析到专利撰写。

![XLSCOUT Solutions](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/xlscout-solutions.png)

- **[Novelty Checker LLM](https://xlscout.ai/novelty-checker-llm)：** 借助前沿 LLM 与生成式 AI，快速浏览专利与非专利文献来验证你的想法。它输出按相关性排序的现有技术文献完整清单，并附关键特征分析报告。该工具让发明人、研究者和专利从业者能够把自己的发明与浩如烟海的现有文献及专利对比，确认其新颖性。
- **[Invalidator LLM](https://xlscout.ai/invalidator-llm)：** 使用先进的 LLM 与生成式 AI，以极快的速度和准确度执行专利无效检索。它提供详细的排序现有技术文献清单和关键特征分析报告。对律所和企业而言，这是高效挑战并评估专利有效性的重要工具。
- **[Drafting LLM](https://xlscout.ai/drafting-llm)：** 一个自动化的专利申请撰写平台，发挥 LLM 与生成式 AI 的能力。它能在几分钟内生成精确、高质量的专利初稿，涵盖完整的权利要求、摘要、附图、背景技术与说明书。这帮助专利从业者在制作详尽精确的专利申请时大幅节省时间精力。

企业高校因此能够确保新颖的研究成果得到恰当保护、激励创新、提交高质量的专利。律所则利用 XLSCOUT 的解决方案为客户提供更优质的服务，提升专利代理和诉讼工作的质量。
