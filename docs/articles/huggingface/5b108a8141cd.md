我们近期宣布，Google DeepMind 的开放权重语言模型 [Gemma](https://huggingface.co/blog/gemma) 已通过 Hugging Face 向更广泛的开源社区开放。它提供 20 亿和 70 亿参数两种规模，各有预训练与指令微调两个版本。它在 Hugging Face 上可用、在 TGI 中得到支持，并可在 Vertex Model Garden 与 Google Kubernetes Engine 上便捷地部署和微调。

Gemma 模型家族也很适合利用 Colab 提供的免费 GPU 资源做原型与实验。在本文中，我们将简要回顾如何对 Gemma 模型做[参数高效微调（PEFT）](https://huggingface.co/blog/peft)——使用 Hugging Face Transformers 与 PEFT 库，在 GPU 和 Cloud TPU 上进行，面向任何想在自己数据集上微调 Gemma 模型的人。

## 为什么用 PEFT？

语言模型的默认（全权重）训练，即便规模不大，也往往对内存和算力开销很大。一方面，对依赖 Colab 或 Kaggle 这类公开可用计算平台学习和实验的用户，它可能高不可攀。另一方面，即使对企业用户，把这些模型适配到不同领域的成本也是必须优化的重要指标。PEFT（参数高效微调）正是以低成本达成这一目标的流行技术。

## PyTorch 之于 GPU 与 TPU

Hugging Face `transformers` 中的 Gemma 模型针对 PyTorch 和 PyTorch/XLA 都做了优化，让 TPU 与 GPU 用户都能按需访问和实验 Gemma 模型。伴随 Gemma 发布，我们还改进了 Hugging Face 中 PyTorch/XLA 的 [FSDP](https://engineering.fb.com/2021-07-15/open-source/fsdp/) 体验。这个 [FSDP via SPMD](https://github.com/pytorch/xla/issues/6379) 集成也让其他 Hugging Face 模型能通过 PyTorch/XLA 受益于 TPU 加速。本文聚焦 Gemma 模型的 PEFT，更具体地说是低秩适配（LoRA）。想了解更多 LoRA 技术，推荐读者阅读 [Lialin et al. 的 Scaling Down to Scale Up](https://arxiv.org/pdf/2303.15647.pdf) 以及 [Belkada et al. 的这篇优秀文章](https://pytorch.org/blog/finetune-llms/)。

## 大语言模型的低秩适配

低秩适配（LoRA）是大语言模型（LLM）的参数高效微调技术之一。它只让一小部分模型参数参与微调：冻结原模型，仅训练被分解为低秩矩阵的适配器层。[PEFT 库](https://github.com/huggingface/peft)提供了简单的抽象，让用户可以选择应用适配器权重的模型层。

```
from peft import LoraConfig

lora_config = LoraConfig(
    r=8,
    target_modules=["q_proj", "o_proj", "k_proj", "v_proj", "gate_proj", "up_proj", "down_proj"],
    task_type="CAUSAL_LM",
)
```

在这段代码里，我们把所有 `nn.Linear` 层都选为待适配的目标层。

在下面的示例中，我们将采用来自 [Dettmers et al.](https://arxiv.org/abs/2305.14314) 的 [QLoRA](https://huggingface.co/blog/4bit-transformers-bitsandbytes)，把基座模型量化为 4-bit 精度，得到更省内存的微调协议。用 QLoRA 加载模型，先在你的环境中安装 `bitsandbytes` 库，然后在加载模型时向 `from_pretrained` 传入一个 `BitsAndBytesConfig` 对象。

## 开始之前

要获取 Gemma 模型文件，用户需要先签署[同意书](https://huggingface.co/google/gemma-7b-it)。现在我们开始实现。

## 学会引用

假设你已提交同意书，就可以从 [Hugging Face Hub](https://huggingface.co/collections/google/gemma-release-65d5efbccdbb8c4202ec078b) 获取模型文件。

我们先下载模型和分词器，同时加入一个用于仅权重量化的 `BitsAndBytesConfig`。

```
import torch
import os
from transformers import AutoTokenizer, AutoModelForCausalLM, BitsAndBytesConfig

model_id = "google/gemma-2b"
bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_quant_type="nf4",
    bnb_4bit_compute_dtype=torch.bfloat16
)

tokenizer = AutoTokenizer.from_pretrained(model_id, token=os.environ['HF_TOKEN'])
model = AutoModelForCausalLM.from_pretrained(model_id, quantization_config=bnb_config, device_map={"":0}, token=os.environ['HF_TOKEN'])
```

在微调开始前，我们用一句名言测试模型：

```
text = "Quote: Imagination is more"
device = "cuda:0"
inputs = tokenizer(text, return_tensors="pt").to(device)

outputs = model.generate(**inputs, max_new_tokens=20)
print(tokenizer.decode(outputs[0], skip_special_tokens=True))
```

模型给出了合理补全，只是多了一些多余的 token：

```
Quote: Imagination is more important than knowledge. Knowledge is limited. Imagination encircles the world.

-Albert Einstein

I
```

但这并不是我们希望的格式。看看我们能否用微调教会模型按以下格式生成回答：

```
Quote: Imagination is more important than knowledge. Knowledge is limited. Imagination encircles the world.

Author: Albert Einstein
```

首先，选一个英语名言数据集 [Abirate/english_quotes](https://huggingface.co/datasets/Abirate/english_quotes)。

```
from datasets import load_dataset

data = load_dataset("Abirate/english_quotes")
data = data.map(lambda samples: tokenizer(samples["quote"]), batched=True)
```

现在我们用上面的 LoRA 配置微调模型：

```
import transformers
from trl import SFTTrainer

def formatting_func(example):
    text = f"Quote: {example['quote'][0]}\nAuthor: {example['author'][0]}<eos>"
    return [text]

trainer = SFTTrainer(
    model=model,
    train_dataset=data["train"],
    args=transformers.TrainingArguments(
        per_device_train_batch_size=1,
        gradient_accumulation_steps=4,
        warmup_steps=2,
        max_steps=10,
        learning_rate=2e-4,
        fp16=True,
        logging_steps=1,
        output_dir="outputs",
        optim="paged_adamw_8bit"
    ),
    peft_config=lora_config,
    formatting_func=formatting_func,
)
trainer.train()
```

最后，我们再用之前的同一个提示词测试模型：

```
text = "Quote: Imagination is"
device = "cuda:0"
inputs = tokenizer(text, return_tensors="pt").to(device)

outputs = model.generate(**inputs, max_new_tokens=20)
print(tokenizer.decode(outputs[0], skip_special_tokens=True))
```

这次我们得到了想要的格式：

```
Quote: Imagination is more important than knowledge. Knowledge is limited. Imagination encircles the world.
Author: Albert Einstein
```

## 用 TPU 上的 FSDP via SPMD 加速

如前所述，Hugging Face `transformers` 现已支持 PyTorch/XLA 的最新 FSDP 实现，这能大幅提升微调速度。要启用它，只需给 `transformers.Trainer` 添加一个 FSDP 配置：

```
from transformers import DataCollatorForLanguageModeling, Trainer, TrainingArguments

# Set up the FSDP config. To enable FSDP via SPMD, set xla_fsdp_v2 to True.
fsdp_config = {
    "fsdp_transformer_layer_cls_to_wrap": ["GemmaDecoderLayer"],
    "xla": True,
    "xla_fsdp_v2": True,
    "xla_fsdp_grad_ckpt": True
}

# Finally, set up the trainer and train the model.
trainer = Trainer(
    model=model,
    train_dataset=data,
    args=TrainingArguments(
        per_device_train_batch_size=64,  # This is actually the global batch size for SPMD.
        num_train_epochs=100,
        max_steps=-1,
        output_dir="./output",
        optim="adafactor",
        logging_steps=1,
        dataloader_drop_last = True,  # Required for SPMD.
        fsdp="full_shard",
        fsdp_config=fsdp_config,
    ),
    data_collator=DataCollatorForLanguageModeling(tokenizer, mlm=False),
)
trainer.train()
```
