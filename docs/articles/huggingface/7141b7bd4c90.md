# 共建开放 Agent 生态：介绍 OpenEnv

借助 [TRL](https://github.com/huggingface/trl)、[TorchForge](https://github.com/meta-pytorch/torchforge) 和 [verl](https://github.com/volcengine/verl) 这样的工具，开源社区已经展示了如何在复杂算力基础设施上扩展 AI。但算力只是硬币的一面，另一面是开发者社区——让 agentic 系统成为可能的人与工具。正因如此，Meta 与 Hugging Face 携手推出 [OpenEnv Hub](https://huggingface.co/openenv)：一个面向 agentic 环境（智能体环境）的共享开放社区枢纽。

Agentic 环境定义了 agent 完成任务所需的一切：工具、API、凭证、执行上下文，仅此而已。它们为 agent 行为带来清晰性、安全性与沙箱化控制。

这些环境既可用于训练，也可用于部署，并作为可扩展 agentic 开发的基础。

## 问题

现代 AI agent 能够在成千上万种任务上自主行动。然而，仅有一个大语言模型并不能让这些任务真正跑起来——它还需要访问正确的工具。把数百万个工具直接暴露给模型既不现实（也不安全）。我们需要的是 **agentic 环境**：安全、语义清晰的沙箱，恰好定义一个任务所需的全部内容，不多也不少。这些环境负责处理以下关键细节：

- 关于任务需要什么的高度清晰的语义
- 沙箱化执行与安全性保证
- 对已完成认证的工具和 API 的无缝访问

## 解决方案

为了给下一波 agentic 开发注入强劲动力，Meta-PyTorch 与 Hugging Face 正合作推出一个[环境 Hub](https://huggingface.co/openenv)：一个共享空间，开发者可以在其中构建、分享和探索兼容 OpenEnv、用于训练与部署的环境。下图展示了 **OpenEnv** 如何融入 **Meta** 正在开发的新一代后训练（post-training）栈，并且 **TRL**、**SkyRL**、**Unsloth** 等其他库的集成也在推进中：

![rl_stack](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/openenv/rl-stack.png)

从下周开始，开发者可以：

- 访问 Hugging Face 上全新的 [Environment Hub](https://huggingface.co/openenv)，我们会在那里放入首批一些环境
- 以人类 Agent（Human Agent）的身份直接与环境交互
- 调用一个模型在环境内解决任务
- 检查环境暴露了哪些工具、如何定义其观测（observations）
- 每个上传到 Hub 且符合 OpenEnv 规范的环境都会自动获得这些功能——让在跑完整 RL 训练之前的验证与迭代变得又快又简单。

与此同时，我们发布了 [OpenEnv 0.1 Spec (RFC)](https://github.com/meta-pytorch/OpenEnv/blob/main/rfcs/002-env-spec.md)，以收集社区反馈、共同塑造这一标准。

## RFC

在当前仓库状态下，环境创建者可以使用 `step()`、`reset()`、`close()` API（属于下述 RFC）来创建环境。关于如何创建这类环境的一些示例见[这里](https://github.com/meta-pytorch/OpenEnv/tree/main/src/envs)。环境用户可以对仓库中已有的所有环境试玩本地 Docker 环境。以下 RFC 正在评审中：

- [RFC 001:](https://github.com/meta-pytorch/OpenEnv/blob/main/rfcs/001-abstractions.md) 确立 Environment、Agent、Task 等核心组件之间关系架构
- [RFC 002:](https://github.com/meta-pytorch/OpenEnv/blob/main/rfcs/002-env-spec.md) 提出基础环境接口、打包、隔离以及与环境的通信方式。
- [RFC 003:](https://github.com/meta-pytorch/OpenEnv/blob/main/rfcs/003-mcp-support.md) 提出通过环境抽象与隔离边界封装 MCP 工具

## 用例

- RL 后训练：跨集合拉取环境，并用 TRL、TorchForge+Monarch、VeRL 等训练 RL agent。
- 环境创建：构建一个环境，确保它能与生态中流行的 RL 工具互操作，并与协作者分享等。
- 复现 SOTA 方法：通过集成用于 agentic 编码与软件工程的各类环境，轻松复刻诸如 FAIR 的 [Code World Model](https://huggingface.co/papers/2510.02387) 之类的方法。
- 部署：用户可以创建一个环境、在同一环境上训练，然后将同一环境用于推理（完整流水线）。
