## 第 4 天：2D 资产

在本系列教程的[第 3 部分](https://huggingface.co/blog/ml-for-games-3)中，我们讨论了为什么 **text-to-3D（文本生成 3D）** 还不够成熟。但在 2D 领域，情况截然不同。

在这一部分，我们来聊聊如何用 AI 生成 2D 资产。

### 前言

本教程描述了一种生成 2D 资产的协作流程，其中 Stable Diffusion 作为一件工具融入传统的 2D 工作流。它面向对图像编辑和 2D 资产制作有一定了解的读者，但对新手和资深从业者同样有所帮助。

所需条件：

- 你顺手的图像编辑软件，例如 [Photoshop](https://www.adobe.com/products/photoshop.html) 或 [GIMP](https://www.gimp.org/)（免费）。
- Stable Diffusion。关于 Stable Diffusion 的安装配置，请参考[第 1 部分](https://huggingface.co/blog/ml-for-games-1#setting-up-stable-diffusion)。

### Image2Image

像 Stable Diffusion 这样的[扩散模型](https://en.wikipedia.org/wiki/Diffusion_model)的工作方式是由文本引导、从噪声中重建图像。Image2Image 使用同样的过程，只是输入不再是噪声，而是真实图像。这意味着输出结果会在一定程度上与输入图像相似。

Image2Image 中有一个重要参数：**denoising strength（去噪强度）**。它控制模型对输入的改动幅度。去噪强度为 0 时会原样复现输入图像，而为 1 时则会生成截然不同的图像。理解去噪强度的另一种方式是把它看作**创造力**。下图演示了以一张圆形的图像为输入、提示词为 "moon"，在不同去噪强度下的 image-to-image 效果。

Image2Image 让 Stable Diffusion 可以作为一件工具来用，而不是替代传统的艺术创作工作流。也就是说，你可以把自己的手工资产传给 Image2Image，再手工对结果进行迭代，如此往复。下面以这款农场游戏为例。

### 示例：玉米

本节我将演示如何为这款农场游戏生成一个玉米图标。作为起点，我先画了一个非常粗略的玉米草图，用来确定画面的构图。

接下来，我用 Image2Image 和以下提示词生成了一些图标：

> corn, james gilleard, atey ghailan, pixar concept artists, stardew valley, animal crossing

我使用了 0.8 的去噪强度，以鼓励模型更有创造力。经过多次生成后，我找到了一个满意的结果。

图像不需要完美，只要方向对了就行，因为我们会持续迭代。就我而言，我喜欢生成出来的风格，但觉得茎秆有点过于繁复。于是我在 Photoshop 里做了一些修改。

注意我只是大致涂盖住了想要改动的部分，让 Stable Diffusion 去补全细节。我把修改后的图像再放回 Image2Image，这次用了更低的去噪强度 0.6，因为我不想偏离输入太远。这一次的结果让我*几乎*满意了。

玉米茎秆的底部对我来说还是太有笔触感，而且顶部冒出了一根嫩芽。于是我在 Photoshop 里把这两处涂改掉，又在 Stable Diffusion 里过了一遍，最后去掉了背景。

Voilà，不到 10 分钟就得到一个可以直接用于游戏的玉米图标。当然，你也可以花更多时间获得更好的效果。更精细资产的制作，我推荐[这个视频](https://youtu.be/blXnuyVgA_Y)的详细演示。

### 示例：镰刀

很多时候，你得和 Stable Diffusion 一番较量才能得到你想要的结果。对我来说，镰刀图标绝对是这样——为了把它推向我要的方向，迭代了很多轮。

问题很可能在于：网上关于镰刀的图片大多是作为*武器*而非*农具*的。一个应对办法是提示词工程（prompt engineering），也就是调整提示词把它推向正确的方向，例如在提示词里写 **scythe, scythe tool**，或在负向提示词（negative prompt）里写 **weapon**。但这不是唯一的解法。

[Dreambooth](https://dreambooth.github.io/)、[textual inversion](https://textual-inversion.github.io/) 和 [LoRA](https://huggingface.co/blog/lora) 是定制扩散模型的技术，能让模型产出远比你预期的更具体的结果。这些超出了本教程的范围，但值得一提，因为它们在 2D 资产生成领域正变得越来越重要。

像 [layer.ai](https://layer.ai/) 和 [scenario.gg](https://www.scenario.gg/) 这样的生成服务专门面向游戏资产生成，很可能使用了 dreambooth、textual inversion 之类的技术，让游戏开发者能够生成风格一致的资产。不过，在这个新兴的生成式游戏开发工具箱中，哪些方案会脱颖而出，仍有待观察。

如果你想更深入地探索这些高级工作流，可以看看这篇关于 Dreambooth 训练的[博客文章](https://huggingface.co/blog/dreambooth)和 [space](https://huggingface.co/spaces/multimodalart/dreambooth-training)。
