# 基于 Sentence Transformers 的多模态 Embedding 与 Reranker 模型

作者：Tom Aarsen（tomaarsen）

[Sentence Transformers](https://sbert.net/) 是一个用于使用和训练 embedding 与 reranker 模型的 Python 库，服务于检索增强生成、语义搜索等应用。随着 v5.4 更新，你现在可以用同一套熟悉的 API **对文本、图像、音频和视频进行编码与比较**。在这篇博客里，我会展示如何用这些新的多模态能力做 embedding 和 reranking。

多模态 embedding 模型把不同模态的输入映射到共享的嵌入空间；多模态 reranker 模型则对跨模态的输入对打相关性分。这打开了视觉文档检索、跨模态搜索和多模态 RAG 流水线等用例。

> 想训练自己的多模态模型，请看配套博客：Training and Finetuning Multimodal Embedding & Reranker Models with Sentence Transformers。

## 什么是多模态模型？

传统 embedding 模型把文本转换成[固定长度的向量](https://huggingface.co/blog/matryoshka#understanding-embeddings)。多模态 embedding 模型把这一点做了扩展：将不同模态（文本、图像、音频或视频）的输入映射进同一个嵌入空间。这意味着你可以用已经熟悉的相似度函数，拿一个文本查询去和图像文档比较（或反过来）。

类似地，传统 reranker（Cross Encoder）模型计算文本对之间的相关性分。多模态 reranker 可以给一方或双方是图像、图文组合文档或其他模态的输入对打分。

例如：你可以拿文本查询对比图像文档、找出与描述匹配的视频片段，或构建跨模态的 RAG 流水线。

## 安装

多模态模型需要一些额外依赖。按需安装对应模态的 extras（详见[安装文档](https://sbert.net/docs/installation.html)）：

```
# For image support
pip install -U "sentence-transformers[image]"

# For audio support
pip install -U "sentence-transformers[audio]"

# For video support
pip install -U "sentence-transformers[video]"

# Mix and match as needed
pip install -U "sentence-transformers[image,video,train]"
```

> 基于 VLM 的模型（如 Qwen3-VL-2B）需要至少约 8 GB 显存的 GPU；8B 版本大约需要 20 GB。没有本地 GPU 的话，可以考虑云 GPU 服务或 Google Colab。在 CPU 上这些模型会极慢；纯文本模型或 CLIP 模型更适合 CPU 推理。

## 多模态 Embedding 模型

### 加载模型

加载多模态 embedding 模型与加载纯文本模型完全一样：

```
from sentence_transformers import SentenceTransformer

model = SentenceTransformer("Qwen/Qwen3-VL-Embedding-2B")
```

> 如果某个模型的集成 PR 还在等待合并，目前可能需要传 revision 参数。合并之后，就能像上面这样不指定 revision 直接加载。

模型会自动检测它支持哪些模态，不需要额外配置。想控制图像分辨率、模型精度等，请看 [Processor 与 Model kwargs](https://huggingface.co/blog/multimodal-sentence-transformers#processor-and-model-kwargs)。

### 编码图像

模型加载后，[`model.encode()`](https://sbert.net/docs/package_reference/sentence_transformer/SentenceTransformer.html#sentence_transformers.SentenceTransformer.encode) 除了文本还接受图像。图像可以是 URL、本地文件路径或 PIL Image 对象（全部支持的格式见[支持的输入类型](https://huggingface.co/blog/multimodal-sentence-transformers#supported-input-types)）：

```
from sentence_transformers import SentenceTransformer

model = SentenceTransformer("Qwen/Qwen3-VL-Embedding-2B")

# Encode images from URLs
img_embeddings = model.encode([
    "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/tasks/car.jpg",
    "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/bee.jpg",
])
print(img_embeddings.shape)
# (2, 2048)
```

### 跨模态相似度

由于模型把两类输入映射到同一空间，你可以直接计算文本嵌入与图像嵌入之间的相似度：

```
from sentence_transformers import SentenceTransformer

model = SentenceTransformer("Qwen/Qwen3-VL-Embedding-2B")

# Encode images
img_embeddings = model.encode([
    "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/tasks/car.jpg",
    "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/bee.jpg",
])

# Encode text queries (one matching + one hard negative per image)
text_embeddings = model.encode([
    "A green car parked in front of a yellow building",
    "A red car driving on a highway",
    "A bee on a pink flower",
    "A wasp on a wooden table",
])

# Compute cross-modal similarities
similarities = model.similarity(text_embeddings, img_embeddings)
print(similarities)
# tensor([[0.5115, 0.1078],
#         [0.1999, 0.1108],
#         [0.1255, 0.6749],
#         [0.1283, 0.2704]])
```

不出所料，"A green car parked in front of a yellow building" 与汽车图像最相似（0.51），"A bee on a pink flower" 与蜜蜂图像最相似（0.67）。困难负例（"A red car driving on a highway"、"A wasp on a wooden table"）如预期拿到了更低的分数。

你可能注意到，即使最佳匹配分（0.51、0.67）也离 1.0 很远。这是[模态鸿沟（modality gap）](https://arxiv.org/abs/2203.02053)导致的：不同模态的嵌入倾向于聚在空间中不同的区域。跨模态相似度通常低于同模态（如文本对文本），但相对排序仍然成立，检索照样好用。

### 编码查询与文档

检索任务推荐使用 [`encode_query()`](https://sbert.net/docs/package_reference/sentence_transformer/SentenceTransformer.html#sentence_transformers.SentenceTransformer.encode_query) 和 [`encode_document()`](https://sbert.net/docs/package_reference/sentence_transformer/SentenceTransformer.html#sentence_transformers.SentenceTransformer.encode_document)。许多检索模型会根据输入是查询还是文档，分别前置不同的指令提示词——类似 chat 模型按目标应用不同的 system prompt。模型作者可以在模型配置里指定这些 prompt，`encode_query()` / `encode_document()` 会自动加载并应用正确的一个：

- `encode_query()` 使用模型的 `"query"` prompt（如果有），并设置 `task="query"`。
- `encode_document()` 按 `"document"`、`"passage"`、`"corpus"` 顺序取第一个可用的 prompt，并设置 `task="document"`。

底层上，二者都只是 `encode()` 的薄封装，帮你处理了 prompt 选择。跨模态检索长这样：

```
from sentence_transformers import SentenceTransformer

model = SentenceTransformer("Qwen/Qwen3-VL-Embedding-2B")

# Encode text queries with the query prompt
query_embeddings = model.encode_query([
    "Find me a photo of a vehicle parked near a building",
    "Show me an image of a pollinating insect",
])

# Encode document screenshots with the document prompt
doc_embeddings = model.encode_document([
    "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/tasks/car.jpg",
    "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/bee.jpg",
])

# Compute similarities
similarities = model.similarity(query_embeddings, doc_embeddings)
print(similarities)
# tensor([[0.3907, 0.1490],
#         [0.1235, 0.4872]])
```

这些方法接受的输入类型与 `encode()` 相同（图像、URL、多模态 dict 等），透传的参数也相同。对没有专门 query/document prompt 的模型，它们与 `encode()` 行为完全一致。

## 多模态 Reranker 模型

多模态 reranker（CrossEncoder）模型给输入对打相关性分，每一方都可以是文本、图像、音频、视频或组合。它们的精度通常优于 embedding 模型，但更慢，因为要对每个对单独处理。目前可用的预训练多模态 reranker 聚焦文本和图像输入，但架构支持底层模型能处理的任意模态。

### 对混合模态文档排序

[`rank()`](https://sbert.net/docs/package_reference/cross_encoder/cross_encoder.html#sentence_transformers.cross_encoder.CrossEncoder.rank) 方法给一个查询与一组文档打分并排序，支持混合模态：

```
from sentence_transformers import CrossEncoder

model = CrossEncoder("Qwen/Qwen3-VL-Reranker-2B")

query = "A green car parked in front of a yellow building"
documents = [
    # Image documents (URL or local file path)
    "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/tasks/car.jpg",
    "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/bee.jpg",
    # Text document
    "A vintage Volkswagen Beetle painted in bright green sits in a driveway.",
    # Combined text + image document
    {
        "text": "A car in a European city",
        "image": "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/tasks/car.jpg",
    },
]

rankings = model.rank(query, documents)
for rank in rankings:
    print(f"{rank['score']:.4f}\t(document {rank['corpus_id']})")
"""
0.9375  (document 0)
0.5000  (document 3)
-1.2500 (document 2)
-2.4375 (document 1)
"""
```

reranker 正确地把汽车图像（document 0）识别为最相关结果，其次是关于欧洲城市汽车的图文组合文档（document 3）。蜜蜂图像（document 1）得分最低。要注意[模态鸿沟（modality gap）](https://arxiv.org/abs/2203.02053)会影响绝对分数：图文对的分数区间可能与文文对或图图对不同。

和 embedding 模型一样，你也可以用 [`modalities`](https://sbert.net/docs/package_reference/cross_encoder/cross_encoder.html#sentence_transformers.cross_encoder.CrossEncoder.modalities) 和 [`supports()`](https://sbert.net/docs/package_reference/cross_encoder/cross_encoder.html#sentence_transformers.cross_encoder.CrossEncoder.supports) 查看 reranker 支持哪些模态：

```
print(model.modalities)
# ['text', 'image', 'video', 'message']

print(model.supports("image"))
# True

# Check if the model supports a specific pair of modalities
print(model.supports(("image", "text")))
# True
```

### 预测成对分数

也可以用 [`predict()`](https://sbert.net/docs/package_reference/cross_encoder/cross_encoder.html#sentence_transformers.cross_encoder.CrossEncoder.predict) 获取特定输入对的原始相关性分：

```
from sentence_transformers import CrossEncoder

model = CrossEncoder("jinaai/jina-reranker-m0", trust_remote_code=True)

scores = model.predict([
    ("A green car", "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/tasks/car.jpg"),
    ("A bee on a flower", "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/bee.jpg"),
    ("A green car", "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/bee.jpg"),
])
print(scores)
# [0.9389156  0.96922314 0.46063158]
```

## 检索再重排

一个常见模式是：先用 embedding 模型做快速初检，再用 reranker 精排 top 结果：

```
from sentence_transformers import SentenceTransformer, CrossEncoder

# Step 1: Retrieve with an embedding model
embedder = SentenceTransformer("Qwen/Qwen3-VL-Embedding-2B")

query = "revenue growth chart"
query_embedding = embedder.encode_query(query)

# Pre-compute corpus embeddings (do this once, then store them)
document_screenshots = [
    "path/to/doc1.png",
    "path/to/doc2.png",
    # ... potentially millions of document screenshots
]
corpus_embeddings = embedder.encode_document(document_screenshots, show_progress_bar=True)

# Simple cosine similarity retrieval, viable as long as embeddings fit in memory
similarities = embedder.similarity(query_embedding, corpus_embeddings)
top_k_indices = similarities.argsort(descending=True)[0][:10]

# Step 2: Rerank the top-k results with a reranker model
reranker = CrossEncoder("nvidia/llama-nemotron-rerank-vl-1b-v2", trust_remote_code=True)

top_k_documents = [document_screenshots[i] for i in top_k_indices]
rankings = reranker.rank(query, top_k_documents)
for rank in rankings:
    print(f"{rank['score']:.4f}\t{top_k_documents[rank['corpus_id']]}")
```

由于语料嵌入是预先算好的，即使面对数百万文档，初检也很快。随后 reranker 在较小的候选集上提供更精准的打分。

## 输入格式与配置

### 支持的输入类型

多模态模型接受多种输入格式。以下是可传给 [`model.encode()`](https://sbert.net/docs/package_reference/sentence_transformer/SentenceTransformer.html#sentence_transformers.SentenceTransformer.encode) 的内容汇总：

| 模态 | 接受的格式 |
| --- | --- |
| **文本** | - 字符串 |
| **图像** | - `PIL.Image.Image` 对象 - 文件路径（如 `"./photo.jpg"`） - URL（如 `"https://.../image.jpg"`） - Numpy 数组、torch 张量 |
| **音频** | - 文件路径（如 `"./audio.wav"`） - URL（如 `"https://.../audio.wav"`） - Numpy/torch 数组 - 含 `"array"` 和 `"sampling_rate"` 键的 dict - `torchcodec.AudioDecoder` 实例 |
| **视频** | - 文件路径（如 `"./video.mp4"`） - URL（如 `"https://.../video.mp4"`） - Numpy/torch 数组 - 含 `"array"` 和 `"video_metadata"` 键的 dict - `torchcodec.VideoDecoder` 实例 |
| **多模态** | - 把模态名映射到值的 dict，如 `{"text": "a caption", "image": "https://.../image.jpg"}`。有效键：`"text"`、`"image"`、`"audio"`、`"video"` |
| **消息** | - 含 `"role"` 和 `"content"` 键的消息 dict 列表，如 `[{"role": "user", "content": [...]}]` |

### 检查模态支持

用 [`modalities`](https://sbert.net/docs/package_reference/sentence_transformer/SentenceTransformer.html#sentence_transformers.SentenceTransformer.modalities) 属性和 [`supports()`](https://sbert.net/docs/package_reference/sentence_transformer/SentenceTransformer.html#sentence_transformers.SentenceTransformer.supports) 方法检查模型支持的模态：

```
from sentence_transformers import SentenceTransformer

model = SentenceTransformer("Qwen/Qwen3-VL-Embedding-2B")

# List all supported modalities
print(model.modalities)
# ['text', 'image', 'video', 'message']

# Check for a specific modality
print(model.supports("image"))
# True
print(model.supports("audio"))
# False
```

`"message"` 模态表示模型接受交错内容的 chat 风格消息输入。实践中你很少需要直接使用它：当你传入字符串、URL 或多模态 dict 时，模型会在内部把它们转换成合适的消息格式。Sentence Transformers 支持两种消息格式：

- **结构化**（多数 VLM，如 Qwen3-VL）：content 是带类型的 dict 列表，如 `[{"type": "text", "text": "..."}, {"type": "image", "image": ...}]`
- **扁平**（如 Deepseek-V3）：content 是直接的值，如 `"some text"`

格式会根据模型的 chat template 自动检测。

由于所有输入在内部都会转成同一种消息格式，你可以在同一次 [`encode()`](https://sbert.net/docs/package_reference/sentence_transformer/SentenceTransformer.html#sentence_transformers.SentenceTransformer.encode) 调用中混合输入类型：

```
embeddings = model.encode([
    # A text input
    "A green car parked in front of a yellow building",
    # An image input (URL)
    "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/tasks/car.jpg",
    # A combined text + image input
    {
        "text": "A car in a European city",
        "image": "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/tasks/car.jpg",
    },
])
```

**如果需要直接传原始消息输入，请点这里**

如果模型两种格式都不遵循、你需要完全控制，可以直接传含 `role` 和 `content` 键的原始消息 dict：

```
embeddings = model.encode([
    [
        {
            "role": "user",
            "content": [
                {"type": "image", "image": "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/tasks/car.jpg"},
                {"type": "text", "text": "Describe this vehicle."},
            ],
        }
    ],
])
```

这会绕过自动格式转换，把消息直接传给 processor 的 `apply_chat_template()`。

### Processor 与 Model kwargs

你可能想控制图像分辨率上下限或模型精度。加载模型时使用 `processor_kwargs` 和 `model_kwargs`：

```
model = SentenceTransformer(
    "Qwen/Qwen3-VL-Embedding-2B",
    model_kwargs={"attn_implementation": "flash_attention_2", "torch_dtype": "bfloat16"},
    processor_kwargs={"min_pixels": 28 * 28, "max_pixels": 600 * 600},
)
```

- `processor_kwargs` 控制输入的预处理方式（如图像分辨率上下限）。`max_pixels` 越大质量越高，但显存和计算也越多。这些参数直接传给 `AutoProcessor.from_pretrained(...)`。
- `model_kwargs` 控制底层模型的加载方式（如精度、注意力实现）。这些参数直接传给相应的 `AutoModel.from_pretrained(...)` 调用（依模型模块的配置，可能是 `AutoModel`、`AutoModelForCausalLM`、`AutoModelForSequenceClassification` 等）。

更多细节见 [SentenceTransformer](https://sbert.net/docs/package_reference/sentence_transformer/SentenceTransformer.html#sentence_transformers.SentenceTransformer) API 参考文档。

> 在 Sentence Transformers v5.4 中，`tokenizer_kwargs` 已改名为 `processor_kwargs`，以反映多模态模型使用 processor 而非仅 tokenizer。旧名称仍可用，但已弃用。

**纯文本 reranker 使用示例，请点这里**

```
from sentence_transformers import CrossEncoder

model = CrossEncoder("mixedbread-ai/mxbai-rerank-base-v2")

query = "How do I bake sourdough bread?"
documents = [
    "Sourdough bread requires a starter made from flour and water, fermented over several days.",
    "The history of bread dates back to ancient Egypt around 8000 BCE.",
    "To bake sourdough, mix your starter with flour, water, and salt, then let it rise overnight.",
    "Rye bread is a popular alternative to wheat-based breads in Northern Europe.",
]

pairs = [(query, doc) for doc in documents]
scores = model.predict(pairs)
print(scores)
# [ 7.3077507 -2.6217823  8.724761  -2.2488995]

rankings = model.rank(query, documents)
for rank in rankings:
    print(f"{rank['score']:.4f}\t{documents[rank['corpus_id']]}")
# 8.7248  To bake sourdough, mix your starter with flour, water, and salt, then let it rise overnight.
# 7.3078  Sourdough bread requires a starter made from flour and water, fermented over several days.
# -2.2489 Rye bread is a popular alternative to wheat-based breads in Northern Europe.
# -2.6218 The history of bread dates back to ancient Egypt around 8000 BCE.
```

**CLIP 使用示例，请点这里**

```
from sentence_transformers import SentenceTransformer

model = SentenceTransformer("sentence-transformers/clip-ViT-L-14")

images = [
    "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/tasks/car.jpg",
    "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/bee.jpg",
    "https://huggingface.co/datasets/huggingface/cats-image/resolve/main/cats_image.jpeg"
]
texts = ["A green car", "A bee on a flower", "Some cats on a couch", "One cat sitting in the window"]

image_embeddings = model.encode(images)
text_embeddings = model.encode(texts)
print(image_embeddings.shape, text_embeddings.shape)
# (3, 768) (4, 768)

similarities = model.similarity(image_embeddings, text_embeddings)
print(similarities)
# tensor([[0.2208, 0.1042, 0.0617, 0.0907],  First image (car) is most similar to "A green car"
#         [0.1205, 0.2303, 0.0632, 0.0917],  Second image (bee) is most similar to "A bee on a flower"
#         [0.1107, 0.0196, 0.2425, 0.1162]]) Third image (multiple cats) is most similar to "Some cats on a couch"
```
