# 数据在一起更美好：回顾与展望

过去几个月，我们一直在推进 [Data Is Better Together（数据在一起更美好）](https://github.com/huggingface/data-is-better-together)倡议。在 Hugging Face 与 Argilla 的这次协作中，并得到开源 ML 社区的支持，我们的目标一直是赋能开源社区，让大家共同创建有影响力的数据集。

现在，我们决定朝着同一目标继续前进。为了概述我们已取得的成绩，以及每个人都能参与的任务，我们把它分为两个部分：社区成果（community efforts）与食谱（cookbook）成果。

## 社区成果

我们在这项倡议中的第一步聚焦于 **prompt ranking（提示排序）** 项目。目标是创建一个由 1 万个提示组成的数据集，包含合成的和人类生成的，并按质量排序。社区的响应立竿见影！

- 几天之内，就有超过 385 人加入。
- 我们发布了 [DIBT/10k_prompts_ranked](https://huggingface.co/datasets/DIBT/10k_prompts_ranked) 数据集，用于提示排序任务或合成数据生成。
- 该数据集被用于构建新的[模型](https://huggingface.co/models?dataset=dataset:DIBT/10k_prompts_ranked)，例如 SPIN。

看到全球社区的支持，我们意识到仅有英语为中心的数据是不够的，开放 LLM 也缺乏足够的特定语言基准。于是我们创建了 **多语言提示评测项目（Multilingual Prompt Evaluation Project, MPEP）**，目标是打造一个覆盖多种语言的排行榜。为此，我们从 [DIBT/10k_prompts_ranked](https://huggingface.co/datasets/DIBT/10k_prompts_ranked) 中选取了 500 个高质量提示的子集，用于翻译成不同语言。

- 超过 18 位语言负责人创建了用于翻译的 spaces。
- 完成了 [荷兰语](https://huggingface.co/datasets/DIBT/MPEP_DUTCH)、[俄语](https://huggingface.co/datasets/DIBT/MPEP_RUSSIAN)或[西班牙语](https://huggingface.co/datasets/DIBT/MPEP_SPANISH)的翻译，还有许多工作正朝着提示的完整翻译推进。
- 在 Discord 上建立了一个数据集构建者社区。

展望未来，我们将继续通过工具与文档，支持聚焦于构建数据集的社区成果。

## 食谱成果

作为 [DIBT](https://github.com/huggingface/data-is-better-together) 的一部分，我们还创建了指南和工具，帮助社区自行构建有价值的数据集。

- **领域特定数据集**：为更多面向模型训练的领域特定数据集的创建注入动力，把工程师与领域专家聚集在一起。
- **DPO/ORPO 数据集**：帮助培养一个社区，为不同语言、领域和任务构建更多 DPO 风格的数据集。
- **KTO 数据集**：帮助社区创建自己的 KTO 数据集。

## 我们学到了什么？

- 社区热衷于参与这些工作，并对集体协作构建数据集充满热情。
- 要确保全面且包容的基准，就必须克服现存的种种不平等。某些语言、领域和任务的数据集在开源社区中目前仍代表性不足。
- 社区有效协作以构建有价值数据集所需的工具，我们已具备其中大部分。
