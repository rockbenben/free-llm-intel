## ControlNet：TL;DR

ControlNet 出自 Lvmin Zhang 和 Maneesh Agrawala 的论文 [Adding Conditional Control to Text-to-Image Diffusion Models](https://arxiv.org/abs/2302.05543)。它提出了一种框架，支持多种空间上下文作为 Stable Diffusion 等扩散模型的额外条件。Diffusers 的实现改编自原始[源代码](https://github.com/lllyasviel/ControlNet/)。

训练 ControlNet 包含以下步骤：

- 把扩散模型（如 Stable Diffusion 的 latent UNet）的预训练参数克隆一份（"可训练副本"），同时单独保留一份预训练参数（"锁定副本"）。这样做是为了让锁定的副本保持在大数据集上学到的海量知识，而可训练副本负责学习任务相关的部分。
- 参数的可训练副本与锁定副本之间通过"零卷积（zero convolution）"层连接（详见[这里](https://github.com/lllyasviel/ControlNet#controlnet)），这些层作为 ControlNet 框架的一部分参与优化。这是一种训练技巧，用来在训练新条件时保留冻结模型已有的语义。

每一种新的条件都需要训练一份新的 ControlNet 权重。论文提出了 8 种条件模型，全部[支持](https://huggingface.co/lllyasviel?search=controlnet)于 Diffusers！

推理时，预训练扩散模型权重和训练好的 ControlNet 权重都必需。例如，把 [Stable Diffusion v1-5](https://huggingface.co/runwayml/stable-diffusion-v1-5) 与某个 ControlNet checkpoint 一起使用，比只用原版 Stable Diffusion 多约 7 亿参数，这让 ControlNet 的推理更吃内存。

由于预训练扩散模型在训练期间是锁定的，更换条件时只需切换 ControlNet 参数。这让在同一个应用里部署多份 ControlNet 权重变得相当简单，下文就会看到。

## `StableDiffusionControlNetPipeline`

开始前，我们要向社区贡献者 [Takuma Mori](https://github.com/takuma104) 致以热烈感谢，正是他主导了 ControlNet 进入 Diffusers 的集成 ❤️。

要试验 ControlNet，Diffusers 提供了 [`StableDiffusionControlNetPipeline`](https://huggingface.co/docs/diffusers/main/en/api/pipelines/stable_diffusion/controlnet)，与[其他 Diffusers 流水线](https://huggingface.co/docs/diffusers/api/pipelines/overview)类似。`StableDiffusionControlNetPipeline` 的核心是 `controlnet` 参数：它允许我们在保持预训练扩散模型权重不变的同时，提供某个训练好的 [`ControlNetModel`](https://huggingface.co/docs/diffusers/main/en/api/models#diffusers.ControlNetModel) 实例。

本文会用 `StableDiffusionControlNetPipeline` 探索不同用例。第一个要演示的 ControlNet 模型是 [Canny 模型](https://huggingface.co/runwayml/stable-diffusion-v1-5)——这是最受欢迎的模型之一，你在网上看到的那些惊艳图片很多出自它。

下文各节的代码片段，欢迎用[这个 Colab Notebook](https://colab.research.google.com/github/huggingface/notebooks/blob/main/diffusers/controlnet.ipynb) 直接运行。

现在加载 [runwaylml/stable-diffusion-v1-5](https://huggingface.co/runwayml/stable-diffusion-v1-5) 和 [canny 边缘的 ControlNet 模型](https://huggingface.co/lllyasviel/sd-controlnet-canny)。模型以半精度（`torch.dtype`）加载，以获得快速且省内存的推理。

```
from diffusers import StableDiffusionControlNetPipeline, ControlNetModel
import torch

controlnet = ControlNetModel.from_pretrained("lllyasviel/sd-controlnet-canny", torch_dtype=torch.float16)
pipe = StableDiffusionControlNetPipeline.from_pretrained(
    "runwayml/stable-diffusion-v1-5", controlnet=controlnet, torch_dtype=torch.float16
)
```

我们不使用 Stable Diffusion 默认的 [PNDMScheduler](https://huggingface.co/docs/diffusers/main/en/api/schedulers/pndm)，而是当前最快的扩散调度器之一 [UniPCMultistepScheduler](https://huggingface.co/docs/diffusers/main/en/api/schedulers/unipc)。选对调度器能大幅缩短推理时间——这里我们把推理步数从 50 降到 20，生成质量基本保持不变。关于调度器的更多信息见[这里](https://huggingface.co/docs/diffusers/main/en/using-diffusers/schedulers)。

```
from diffusers import UniPCMultistepScheduler

pipe.scheduler = UniPCMultistepScheduler.from_config(pipe.scheduler.config)
```

我们不直接把流水线载入 GPU，而是启用智能 CPU 卸载，即 [`enable_model_cpu_offload` 函数](https://huggingface.co/docs/diffusers/main/en/api/pipelines/stable_diffusion/controlnet#diffusers.StableDiffusionControlNetPipeline.enable_model_cpu_offload)。

记住：推理时，Stable Diffusion 这类扩散模型需要按顺序运行多个组件而非单个。对带 ControlNet 的 Stable Diffusion，先运行 CLIP 文本编码器，然后依次是扩散模型 unet 和 control net、VAE 解码器，最后是安全检查器。大部分组件在扩散过程中只运行一次，没必要一直占用 GPU 内存。启用智能模型卸载后，每个组件只在需要时才载入 GPU，从而显著降低内存占用而几乎不拖慢推理。

**注意**：运行 `enable_model_cpu_offload` 时，不要再手动 `.to("cuda")` 把流水线搬到 GPU——一旦启用 CPU 卸载，流水线会自动管理 GPU 内存。

```
pipe.enable_model_cpu_offload()
```

最后，我们要充分利用了不起的 [FlashAttention/xformers](https://github.com/facebookresearch/xformers) 注意力层加速，把它也打开！如果这条命令不生效，可能是 `xformers` 没装好，那跳过下面这行即可。

```
pipe.enable_xformers_memory_efficient_attention()
```

现在可以跑 ControlNet 流水线了！

我们仍像普通 Stable Diffusion 图生图那样提供提示词引导生成。但由于刚生成的 canny 边缘图控制了生成图像的确切构图，ControlNet 提供了多得多的控制力。

看看当代名人身穿 17 世纪这幅名画的同款造型会很有趣。而用 ControlNet 做到这点太简单了——只要把这些名人的名字写进提示词！

先写一个把图片显示成网格的小助手函数。

```
def image_grid(imgs, rows, cols):
    assert len(imgs) == rows * cols

    w, h = imgs[0].size
    grid = Image.new("RGB", size=(cols * w, rows * h))
    grid_w, grid_h = grid.size

    for i, img in enumerate(imgs):
        grid.paste(img, box=(i % cols * w, i // cols * h))
    return grid
```

接着定义输入提示词并设置可复现的种子。

```
prompt = ", best quality, extremely detailed"
prompt = [t + prompt for t in ["Sandra Oh", "Kim Kardashian", "rihanna", "taylor swift"]]
generator = [torch.Generator(device="cpu").manual_seed(2) for i in range(len(prompt))]
```

最后运行流水线并展示图片！

```
output = pipe(
    prompt,
    canny_image,
    negative_prompt=["monochrome, lowres, bad anatomy, worst quality, low quality"] * 4,
    num_inference_steps=20,
    generator=generator,
)

image_grid(output.images, 2, 2)
```

### 组合多种条件

单次图像生成可以组合多个 ControlNet 条件：向流水线构造函数传入 ControlNet 列表，并向 `__call__` 传入对应的条件列表。

组合条件时，最好对条件做掩码防止重叠。在下面的例子里，我们把 canny 图中姿势条件所在的中间区域抹掉。

调整各条件的 `controlnet_conditioning_scale` 以强调某一条件，也很有用。

#### Canny 条件

原图

![](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/diffusers/landscape.png)

准备条件

```
from diffusers.utils import load_image
from PIL import Image
import cv2
import numpy as np
from diffusers.utils import load_image

canny_image = load_image(
    "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/diffusers/landscape.png"
)
canny_image = np.array(canny_image)

low_threshold = 100
high_threshold = 200

canny_image = cv2.Canny(canny_image, low_threshold, high_threshold)

# zero out middle columns of image where pose will be overlayed
zero_start = canny_image.shape[1] // 4
zero_end = zero_start + canny_image.shape[1] // 2
canny_image[:, zero_start:zero_end] = 0

canny_image = canny_image[:, :, None]
canny_image = np.concatenate([canny_image, canny_image, canny_image], axis=2)
canny_image = Image.fromarray(canny_image)
```

#### 用多条件运行 ControlNet

```
from diffusers import StableDiffusionControlNetPipeline, ControlNetModel, UniPCMultistepScheduler
import torch

controlnet = [
    ControlNetModel.from_pretrained("lllyasviel/sd-controlnet-openpose", torch_dtype=torch.float16),
    ControlNetModel.from_pretrained("lllyasviel/sd-controlnet-canny", torch_dtype=torch.float16),
]

pipe = StableDiffusionControlNetPipeline.from_pretrained(
    "runwayml/stable-diffusion-v1-5", controlnet=controlnet, torch_dtype=torch.float16
)
pipe.scheduler = UniPCMultistepScheduler.from_config(pipe.scheduler.config)

pipe.enable_xformers_memory_efficient_attention()
pipe.enable_model_cpu_offload()

prompt = "a giant standing in a fantasy landscape, best quality"
negative_prompt = "monochrome, lowres, bad anatomy, worst quality, low quality"

generator = torch.Generator(device="cpu").manual_seed(1)

images = [openpose_image, canny_image]

image = pipe(
    prompt,
    images,
    num_inference_steps=20,
    generator=generator,
    negative_prompt=negative_prompt,
    controlnet_conditioning_scale=[1.0, 0.8],
).images[0]

image.save("./multi_controlnet_output.png")
```
