# 共建开放未来：我们与 Google Cloud 的新合作伙伴关系

今天，我们很高兴宣布与 Google Cloud 建立一项新的、更深入的合作关系，帮助企业用开放模型构建自己的 AI。

*"Google 对开放 AI 做出过一些最有影响力的贡献，从最初的 Transformer 到 Gemma 系列模型。我相信未来所有公司都会构建并定制自己的 AI。通过这项新的战略合作，我们要让这件事在 Google Cloud 上变得简单。"Hugging Face 的 Jeff Boudier 表示。*

*"Hugging Face 一直是推动全球大小企业访问、使用并定制开放模型的力量——现在这些模型已超过 200 万个，我们也自豪地为社区贡献了超过 1000 个模型，"Google Cloud 产品管理高级总监 Ryan J. Salva 说，"我们将携手把 Google Cloud 打造为用开放模型构建的最佳之地。"*

## 面向 Google Cloud 客户的合作

Google Cloud 客户已在其众多领先 AI 服务中使用来自 Hugging Face 的开放模型。在 Vertex AI 里，最受欢迎的开放模型在 Model Garden 中点几下鼠标即可部署。希望对 AI 基础设施有更强掌控力的客户，可以在 GKE AI/ML 中找到同样的模型库，或使用由 Hugging Face 维护的预配置环境。客户还可以在 Cloud Run GPU 上运行 AI 推理负载，实现无服务器（serverless）的开放模型部署。

贯穿其中的主线是：我们与 Google Cloud 合作，充分运用每项服务的独特能力打造无缝体验，把选择权交给客户。

## 开放模型之门——Google Cloud 客户的快速通道

过去 3 年，Google Cloud 客户对 Hugging Face 的使用量增长了 10 倍，如今这意味着每月数十 PB 的模型下载量、数十亿次请求。

为确保 Google Cloud 客户在使用 Hugging Face 的模型和数据集时获得最佳体验，我们正在共同打造一个面向 Hugging Face 仓库的 CDN 网关（CDN Gateway），它构建在 Hugging Face Xet 优化存储与数据传输技术，以及 Google Cloud 先进的存储与网络能力之上。

这个 CDN 网关会把 Hugging Face 的模型和数据集直接缓存在 Google Cloud 上，显著缩短下载时间，并为 Google Cloud 客户增强模型供应链的稳健性。无论你用的是 Vertex、GKE、Cloud Run，还是仅在 Compute Engine 的 VM 上自建技术栈，都能受益于更快的首 token 时间（time-to-first-token）和更简化的模型治理。

## 面向 Hugging Face 客户的合作

Hugging Face [Inference Endpoints](https://endpoints.huggingface.co/) 是从模型到部署最省事的方式，点几下鼠标即可完成。通过深化合作，我们将把 Google Cloud 的独特能力与性价比带给 Hugging Face 客户，首先从 Inference Endpoints 开始。可以期待更多、更新的实例以及降价！

我们要确保产品与工程协作的所有成果，能轻松触达 Hugging Face 上的 1000 万 AI 构建者。从模型页面到部署在 Vertex Model Garden 或 GKE 上，应该只需几个步骤。把私有模型安全托管在 Hugging Face 的 Enterprise 组织里，应该和用公开模型一样简单。

TPU——Google 自研 AI 加速芯片，如今已发展到第七代——在性能和软件栈成熟度上持续进步。我们要确保 Hugging Face 用户在使用开放模型构建 AI 时，能充分利用当前和下一代 TPU。得益于我们在库中的原生支持，我们很高兴能让 Hugging Face 模型用 TPU 像用 GPU 一样简单。

此外，这项新合作还将让 Hugging Face 借助 Google 业界领先的安全技术，使 Hub 上的数百万开放模型更加安全。这一联合项目由 [VirusTotal](https://www.virustotal.com/gui/home/upload)、[Google Threat Intelligence](https://cloud.google.com/security/products/threat-intelligence) 和 [Mandiant](https://www.mandiant.com/) 提供支持，目标是在你日常使用 Hugging Face Hub 的过程中保护模型、数据集和 Spaces 的安全。

## 共同建设 AI 的开放未来

我们期望看到这样的未来：每家公司都能用开放模型构建自己的 AI，托管在自己的安全基础设施内，并拥有完全的控制权。我们很兴奋能与 Google Cloud 一起让这一未来成真。无论你在用 Vertex AI Model Garden、Google Kubernetes Engine、Cloud Run 还是 Hugging Face Inference Endpoints，我们的深度协作都会加速这一愿景。
