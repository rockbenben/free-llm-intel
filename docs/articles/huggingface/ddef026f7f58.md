在机器学习的语境中，主动学习（Active learning）是一个反复迭代的过程：不断加入标注数据、重新训练模型，并把它交付给最终用户。这是一个永无止境的过程，需要人工参与来标注/创造数据。本文将讨论如何用 [AutoNLP](https://huggingface.co/autonlp) 和 [Prodigy](https://prodi.gy/) 搭建一条主动学习流水线。

## AutoNLP

[AutoNLP](https://huggingface.co/autonlp) 是 Hugging Face 创建的框架，几乎不用写代码，就能帮你在自己的数据集上构建最先进的深度学习模型。AutoNLP 建立在 Hugging Face 的 [transformers](https://github.com/huggingface/transformers)、[datasets](https://github.com/huggingface/datasets)、[inference-api](https://huggingface.co/inference-api) 及许多其他工具的巨人肩膀上。

用 AutoNLP，你可以在自己的自定义数据集上训练 SOTA transformer 模型、（自动）微调它们，并交付给最终用户。AutoNLP 训练出的所有模型都是最先进、可用于生产的。

撰写本文时，AutoNLP 支持二分类、回归、多分类、token 分类（如命名实体识别或词性标注）、问答、摘要等任务。所有支持任务的列表见[这里](https://huggingface.co/autonlp/)。AutoNLP 支持英语、法语、德语、西班牙语、印地语、荷兰语、瑞典语等许多语言。也支持带自定义 tokenizer 的自定义模型（如果你的语言不被 AutoNLP 支持）。

## Prodigy

[Prodigy](https://prodi.gy/) 是 Explosion（[spaCy](https://spacy.io/) 的开发者）开发的标注工具。它是一个基于 Web 的工具，让你实时标注数据。Prodigy 支持命名实体识别（NER）和文本分类等 NLP 任务，但绝不局限于 NLP！它还支持计算机视觉任务，甚至可以创建你自己的任务。你可以[在这里](https://prodi.gy/demo)体验 Prodigy demo。

注意 Prodigy 是一款商业工具。更多信息见[这里](https://prodi.gy/buy)。

我们选择 Prodigy，因为它是流行的数据标注工具之一，且可无限定制，同时安装和使用都非常简单。

## 数据集

现在进入本文最有意思的部分。看过大量数据集和各种类型的问题之后，我们在 Kaggle 上偶然发现了 BBC News Classification 数据集。这个数据集曾用于一场课程内比赛，访问入口[在这里](https://www.kaggle.com/c/learn-ai-bbc)。

来看看这个数据集：

如我们所见，这是一个分类数据集。有一个 `Text` 列，是新闻文章正文；还有一个 `Category` 列，是文章的类别。总共有 5 个类别：`business`、`entertainment`、`politics`、`sport` 和 `tech`。

用 AutoNLP 在这个数据集上训练多分类模型简直易如反掌。

第 1 步：下载数据集。

第 2 步：打开 [AutoNLP](https://ui.autonlp.huggingface.co/)，创建新项目。

第 3 步：上传训练数据集，选择自动切分。

第 4 步：接受定价并训练模型。

请注意，上面的例子中我们训练了 15 个不同的多分类模型。AutoNLP 的价格低到每个模型 10 美元。AutoNLP 会自动为你挑选最佳模型并做超参数调优。所以现在，我们要做的只有坐下来、放松，等待结果。

大约 15 分钟后，全部模型训练完毕，结果就绪。看起来最佳模型取得了 98.67% 的准确率！

所以现在我们把数据集中的文章分类到 98.67% 的准确率！但是等等，我们前面说的主动学习和 Prodigy 呢？🤔 我们确实用了 Prodigy，马上会看到。我们用它为命名实体识别任务标注了这个数据集。在开始标注之前，我们觉得做一个既能检测新闻文章中的实体、又能为文章分类的项目会很不错。这就是我们先在已有标签上训练这个分类模型的原因。

## 主动学习

我们用的数据集虽然有类别，但没有实体识别的标签。于是我们决定用 Prodigy 为另一个任务——命名实体识别——标注数据集。

Prodigy 装好后，只需运行：

```
$ prodigy ner.manual bbc blank:en BBC_News_Train.csv --label PERSON,ORG,PRODUCT,LOCATION
```

来看各个取值的含义：

- `bbc` 是 Prodigy 将创建的数据集。
- `blank:en` 是所使用的 `spaCy` tokenizer。
- `BBC_News_Train.csv` 是将用于标注的数据集。
- `PERSON,ORG,PRODUCT,LOCATION` 是标注时将使用的标签列表。

运行上面的命令后，你可以进入 Prodigy 的 Web 界面（通常在 localhost:8080）开始标注数据集。Prodigy 界面非常简单、直观、易用。界面长这样：

你要做的只是选择要标注哪类实体（PERSON、ORG、PRODUCT、LOCATION），然后选中属于该实体的文本。标完一篇文档，点击绿色按钮，Prodigy 会自动给出下一篇未标注的文档。

[![prodigy_ner_demo](https://huggingface.co/blog/assets/43_autonlp_prodigy/prodigy.gif)](https://huggingface.co/blog/assets/43_autonlp_prodigy/prodigy.gif)

我们用 Prodigy 开始标注数据集。攒到大约 20 个样本时，我们用 AutoNLP 训练了一个模型。Prodigy 不会按 AutoNLP 格式导出数据，所以我们写了个简单粗暴的脚本来转换数据格式：

```
import json
import spacy

from prodigy.components.db import connect

db = connect()
prodigy_annotations = db.get_dataset("bbc")
examples = ((eg["text"], eg) for eg in prodigy_annotations)
nlp = spacy.blank("en")

dataset = []

for doc, eg in nlp.pipe(examples, as_tuples=True):
    try:
        doc.ents = [doc.char_span(s["start"], s["end"], s["label"]) for s in eg["spans"]]
        iob_tags = [f"{t.ent_iob_}-{t.ent_type_}" if t.ent_iob_ else "O" for t in doc]
        iob_tags = [t.strip("-") for t in iob_tags]
        tokens = [str(t) for t in doc]
        temp_data = {
            "tokens": tokens,
            "tags": iob_tags
        }
        dataset.append(temp_data)
    except:
        pass

with open('data.jsonl', 'w') as outfile:
    for entry in dataset:
        json.dump(entry, outfile)
        outfile.write('\n')
```

这会给我们一个 `JSONL` 文件，可用于通过 AutoNLP 训练模型。步骤和之前一样，只是创建 AutoNLP 项目时选择 `Token Classification` 任务。用我们最初的数据，我们用 AutoNLP 训练了一个模型。最佳模型准确率约 86%，但精确率和召回率为 0。我们知道模型什么也没学到。这很明显——我们只有大约 20 个样本。

标注了约 70 个样本后，我们开始得到一些结果。准确率升到 92%，精确率 0.52，召回率约 0.42。有了一些效果，但仍不令人满意。在下图中，可以看到这个模型在一个未见样本上的表现。

可以看到，模型还很吃力。但已经比之前好多了！此前模型对同样的文本甚至什么都预测不出来。至少现在，它能识别出 `Bruce` 和 `David` 是人名。

于是我们继续，又标注了一些样本。

请注意，每轮迭代我们的数据集都在变大。我们所做的只是把新数据集上传到 AutoNLP，剩下的交给它。

标注约 150 个样本后，我们开始得到不错的结果。准确率升到 95.7%，精确率 0.64，召回率约 0.76。

来看看这个模型在同一个未见样本上的表现。

哇！太棒了！如你所见，模型现在表现出色！它能在同一段文本中检测到许多实体。精确率和召回率仍偏低，于是我们继续标注更多数据。标注约 250 个样本后，我们得到了精确率和召回率的最佳结果：准确率升到约 95.9%，精确率与召回率分别为 0.73 和 0.79。此时我们决定停止标注，结束实验。下面的曲线展示了随着样本增多，最佳模型准确率如何提升：

众所周知，更多相关数据会带来更好的模型、更好的结果。通过这次实验，我们成功做出了一个不仅能对新闻文章中的实体分类、还能对文章本身归类的模型。借助 Prodigy 和 AutoNLP 这样的工具，我们投入的时间和精力只花在标注数据上（而且 Prodigy 提供的界面连这件事都变得更轻松）。AutoNLP 帮我们要省了大量时间和精力：我们不用去琢磨该用什么模型、怎么训练、怎么评估、怎么调参、用什么优化器和学习率调度器、怎么预处理和后处理等等。我们只需要标注数据集，把其余一切交给 AutoNLP。

我们相信，有了 AutoNLP 和 Prodigy 这样的工具，创造数据和最先进模型都变得非常简单。而且由于整个过程几乎不需要写代码，即使没有编程背景的人也能创建通常对公众不可得的数据集、用 AutoNLP 训练自己的模型，并分享给社区里的所有人（或只用在自己的研究/生意中）。

模型之所以是最先进的，全靠它所训练的数据。
