## 图生图 pipeline

被请求最多的功能之一就是图生图。这个 pipeline 允许你输入一张图和一个提示词，基于它们生成一张新图！

来看基于官方 Colab [notebook](https://colab.research.google.com/github/huggingface/notebooks/blob/main/diffusers/image_2_image_using_diffusers.ipynb) 的一些代码。

```
from diffusers import StableDiffusionImg2ImgPipeline

pipe = StableDiffusionImg2ImgPipeline.from_pretrained(
    "CompVis/stable-diffusion-v1-4",
    revision="fp16", 
    torch_dtype=torch.float16,
    use_auth_token=True
)

# Download an initial image
# ...

init_image = preprocess(init_img)

prompt = "A fantasy landscape, trending on artstation"
images = pipe(prompt=prompt, init_image=init_image, strength=0.75, guidance_scale=7.5, generator=generator)["sample"]
```

Textual Inversion 让你只需 3-5 个样本，就能用你自己的图片个性化定制 Stable Diffusion 模型。借助这个工具，你可以在某个概念上训练模型，然后把该概念分享给社区其他成员！

## 实验性 inpainting pipeline

Inpainting 允许你提供一张图，然后圈选图中区域（或提供掩码），再用 Stable Diffusion 替换掩码区域。效果示例如下：

你可以试试精简版 Colab [notebook](https://colab.research.google.com/github/huggingface/notebooks/blob/main/diffusers/in_painting_with_stable_diffusion_using_diffusers.ipynb)，或者查看下面的代码。demo 马上就来！

```
from diffusers import StableDiffusionInpaintPipeline

pipe = StableDiffusionInpaintPipeline.from_pretrained(
    "CompVis/stable-diffusion-v1-4",
    revision="fp16", 
    torch_dtype=torch.float16,
    use_auth_token=True
).to(device)

images = pipe(
    prompt=["a cat sitting on a bench"] * 3,
    init_image=init_image,
    mask_image=mask_image,
    strength=0.75,
    guidance_scale=7.5,
    generator=None
).images
```

请注意这是实验性的，所以仍有改进空间。

## 面向小显存 GPU 的优化

经过一些改进，扩散模型现在可以大幅降低显存占用。🔥 例如，Stable Diffusion 只需要 3.2GB！代价是速度下降约 10%，但结果完全一致。使用方法如下：

```
from diffusers import StableDiffusionPipeline

pipe = StableDiffusionPipeline.from_pretrained(
    "CompVis/stable-diffusion-v1-4", 
    revision="fp16", 
    torch_dtype=torch.float16,
    use_auth_token=True
)
pipe = pipe.to("cuda")
pipe.enable_attention_slicing()
```

这非常令人兴奋，因为它将进一步降低使用这些模型的门槛！

## 在 Mac OS 上使用 Diffusers

🍎 没错！另一个被广泛请求的功能发布了！完整说明请阅读[官方文档](https://huggingface.co/docs/diffusers/optimization/mps)（包括性能对比、规格说明等）。

借助 PyTorch 的 mps 设备，持有 M1/M2 硬件的用户即可用 Stable Diffusion 做推理。🤯 用户几乎不需要什么配置，快来试试！

```
from diffusers import StableDiffusionPipeline

pipe = StableDiffusionPipeline.from_pretrained("CompVis/stable-diffusion-v1-4", use_auth_token=True)
pipe = pipe.to("mps")

prompt = "a photo of an astronaut riding a horse on mars"
image = pipe(prompt).images[0]
```

## 实验性 ONNX 导出器与 pipeline

新的实验性 pipeline 允许用户在任何支持 ONNX 的硬件上运行 Stable Diffusion。使用示例如下（注意使用了 `onnx` revision）：

```
from diffusers import StableDiffusionOnnxPipeline

pipe = StableDiffusionOnnxPipeline.from_pretrained(
    "CompVis/stable-diffusion-v1-4",
    revision="onnx",
    provider="CPUExecutionProvider",
    use_auth_token=True,
)

prompt = "a photo of an astronaut riding a horse on mars"
image = pipe(prompt).images[0]
```

另外，你也可以直接用导出脚本把你的 SD checkpoint 转成 ONNX。

```
python scripts/convert_stable_diffusion_checkpoint_to_onnx.py --model_path="CompVis/stable-diffusion-v1-4" --output_path="./stable_diffusion_onnx"
```

## 社区

而在我们做上面这些工作的同时，社区也没闲着！以下是社区成果的一些亮点（并不穷尽）

### Stable Diffusion Videos

探索 latent space、在不同文本提示词之间变形，用 Stable Diffusion 创造🔥视频。你可以：

- 为同一个提示词生成不同版本的想象
- 在不同提示词之间做变形过渡

[Stable Diffusion Videos](https://github.com/nateraw/stable-diffusion-videos) 工具可用 pip 安装，附带 Colab notebook 和 Gradio notebook，用起来超级简单！

示例如下：

```
from stable_diffusion_videos import walk

video_path = walk(['a cat', 'a dog'], [42, 1337], num_steps=3, make_video=True)
```

### Diffusers Interpret

[Diffusers interpret](https://github.com/JoaoLages/diffusers-interpret) 是构建在 `diffusers` 之上的可解释性工具，有一些很酷的功能，例如：

- 查看扩散过程中的所有图像
- 分析提示词中每个 token 对生成的影响
- 在指定的边界框内分析，以理解图像的某一部分

[![image info](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/diffusers-2nd-month/interpret.gif)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/diffusers-2nd-month/interpret.gif) (Image from the tool repository)

```
# pass pipeline to the explainer class
explainer = StableDiffusionPipelineExplainer(pipe)

# generate an image with `explainer`
prompt = "Corgi with the Eiffel Tower"
output = explainer(
    prompt, 
    num_inference_steps=15
)

output.normalized_token_attributions # (token, attribution_percentage)
#[('corgi', 40),
# ('with', 5),
# ('the', 5),
# ('eiffel', 25),
# ('tower', 25)]
```

### Japanese Stable Diffusion

顾名思义！JSD 的目标是训练一个同样能捕捉文化、身份与独特表达信息的模型。它用带日语标注的 1 亿张图像训练。模型如何训练，可阅读[模型卡](https://huggingface.co/rinna/japanese-stable-diffusion)。

### Waifu Diffusion

[Waifu Diffusion](https://huggingface.co/hakurei/waifu-diffusion) 是一个为高质量动漫图像生成而微调的 SD 模型。

(Image from the tool repository)

### Cross Attention Control

[Cross Attention Control](https://github.com/bloc97/CrossAttentionControl) 通过修改扩散模型的注意力图实现对提示词的精细控制。你能做的酷事包括：

- 替换提示词中的目标（例如把 cat 换成 dog）
- 降低或提高提示词中某些词的重要性（例如你希望减少对 "rocks" 的关注）
- 轻松注入风格

还有更多！去看看这个仓库。

### 可复用的种子

Stable Diffusion 早期最令人印象深刻的 demo 之一，就是复用种子来微调图像。思路是用某张感兴趣图像的 seed，配不同提示词生成新图像，效果非常棒！详见 [Colab](https://colab.research.google.com/github/pcuenca/diffusers-examples/blob/main/notebooks/stable-diffusion-seeds.ipynb)
