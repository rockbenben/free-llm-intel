# Panel 入驻 Hugging Face

我们非常高兴地宣布 Panel 与 Hugging Face 达成合作！🎉 我们已在 Hugging Face Spaces 中集成了 Panel 模板，帮助你快速上手构建 Panel 应用，并轻松将其部署到 Hugging Face。

## Panel 能提供什么？

[Panel](https://panel.holoviz.org/) 是一个开源 Python 库，让你完全用 Python 就能轻松构建强大的工具、仪表盘和复杂应用。它秉承"电池全含"（batteries-included）的理念，将 PyData 生态、强大的数据表格等尽数送到你手中。高层响应式 API 与底层基于回调的 API，确保你既能快速搭建探索性应用，也能在构建复杂的多页、强交互应用时不受限制。Panel 是 [HoloViz](https://holoviz.org/) 生态的成员，是你进入互联互通的数据探索工具生态的入口。Panel 与其他 HoloViz 工具一样，是 NumFocus 赞助的项目，并得到 Anaconda 和 Blackstone 的支持。

以下是我们的用户认为最有价值的 Panel 特性。

- Panel 对多种绘图库提供广泛支持，如 Matplotlib、Seaborn、Altair、Plotly、Bokeh、PyDeck、Vizzu 等。
- 所有交互功能在 Jupyter 中与独立部署中表现一致。Panel 允许将 Jupyter notebook 中的组件无缝集成到仪表盘中，在数据探索与成果分享之间平滑切换。
- Panel 赋能用户构建复杂的多页应用和高级交互功能，可视化大数据集，并流式传输实时数据。
- 与 Pyodide 和 WebAssembly 的集成，使 Panel 应用可以在浏览器中无缝运行。
