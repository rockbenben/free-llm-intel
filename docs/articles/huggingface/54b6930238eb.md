# 从 GPT2 到 Stable Diffusion：Hugging Face 来到 Elixir 社区

[Elixir](https://elixir-lang.org/) 社区很高兴地宣布，多款神经网络模型——从 GPT2 到 Stable Diffusion——已登陆 Elixir。这要归功于[刚刚发布的 Bumblebee 库](https://news.livebook.dev/announcing-bumblebee-gpt2-stable-diffusion-and-more-in-elixir-3Op73O)，它是 Hugging Face Transformers 的纯 Elixir 实现。

为了帮助大家上手这些模型，[Livebook](https://livebook.dev/)（一个面向 Elixir 的计算 notebook 平台）背后的团队创建了一系列"Smart cells"（智能单元格），让开发者只需 3 次点击即可搭建不同的神经网络任务。你可以观看我的视频发布公告以了解更多：

得益于 Erlang 虚拟机（Elixir 的运行底座）的并发与分布式支持，开发者可以将这些模型嵌入并作为现有 [Phoenix Web 应用](https://phoenixframework.org/)的一部分提供服务，通过 [Broadway 集成到数据处理流水线](https://elixir-broadway.org)，或与 [Nerves 嵌入式系统](https://www.nerves-project.org/) 一起部署——全部无需第三方依赖。在以上所有场景中，Bumblebee 模型都可编译到 CPU 和 GPU。

## 背景

将机器学习带入 Elixir 的努力始于约两年前，从 [Numerical Elixir（Nx）项目](https://github.com/elixir-nx/nx/tree/main/nx)起步。Nx 项目实现了多维张量以及"numerical definitions"（数值定义）——Elixir 的一个子集，可编译到 CPU/GPU。Nx 没有重复造轮子，而是通过 Google XLA 的绑定（[EXLA](https://github.com/elixir-nx/nx/tree/main/exla)）和 Libtorch 的绑定（[Torchx](https://github.com/elixir-nx/nx/tree/main/torchx)）实现 CPU/GPU 编译。

Nx 倡议还催生了多个其他项目。[Axon](https://github.com/elixir-nx/axon) 将函数式、可组合的神经网络带入 Elixir，其灵感来自 [Flax](https://github.com/google/flax) 和 [PyTorch Ignite](https://pytorch.org/ignite/index.html) 等项目。[Explorer](https://github.com/elixir-nx/explorer) 项目借鉴了 [dplyr](https://dplyr.tidyverse.org/) 和 [Rust 的 Polars](https://www.pola.rs/)，为 Elixir 社区提供了表达力强且性能出色的 dataframe。

[Bumblebee](https://github.com/elixir-nx/bumblebee) 和 [Tokenizers](https://github.com/elixir-nx/tokenizers) 是我们最近的发布。感谢 Hugging Face 促成了跨社区、跨工具的协作式机器学习，这在让 Elixir 生态快速跟上步伐方面起到了至关重要的作用。

接下来，我们计划专注于 Elixir 中的神经网络训练与迁移学习，让开发者能够根据业务和应用的需求对预训练模型进行增强和专门化。我们也希望更多地公开我们在传统机器学习算法方面的开发进展。

## 轮到你了

如果你想尝试 Bumblebee，可以：

- 下载 [Livebook v0.8](https://livebook.dev/)，在 notebook 中通过 "+ Smart" 单元格菜单自动生成"神经网络任务"。我们目前正在让 Livebook 支持更多平台以及 *Spaces*（敬请期待！😉）。
- 我们还编写了[单文件 Phoenix 应用](https://github.com/elixir-nx/bumblebee/tree/main/examples/phoenix)，示例展示在你的 Phoenix（+ LiveView）应用中使用 Bumblebee 模型。这些示例应当提供了把它们集成进生产应用所需的构件。
- 想更动手实操，可以阅读我们的一些 [notebook](https://github.com/elixir-nx/bumblebee/tree/main/notebooks)。

如果你想帮助我们共同构建 Elixir 的机器学习生态，请查看上述项目并试用。这里有大量有趣的领域，从编译器开发到模型构建。例如，把更多模型和架构带入 Bumblebee 的 pull request 当然热烈欢迎。未来是并发的、分布式的，也是有趣的！
