# AI Sheets 发布：用开放 AI 模型处理数据集的工具

**🧭 TL;DR**

Hugging Face AI Sheets 是一款全新的**开源工具，无需写代码就能用 AI 模型构建、增强和转换数据集**。该工具可以部署在本地，也可以部署在 Hub 上。你可以通过 Inference Providers 使用 Hub 上的数千个开放模型，也可以使用本地模型，包括 OpenAI 的 `gpt-oss`！

## 常用链接

免费在线试用（无需安装）：[https://huggingface.co/spaces/aisheets/sheets](https://huggingface.co/spaces/aisheets/sheets)
本地安装运行：[https://github.com/huggingface/sheets](https://github.com/huggingface/sheets)

## AI Sheets 是什么

***AI Sheets*** 是一款无代码工具，用于借助（开放）AI 模型构建、转换和增强数据集。它与 Hub 以及开源 AI 生态深度集成。

AI Sheets 采用易学易用的界面，与电子表格类似。这个工具围绕快速实验构建：先在小数据集上试跑，再去运行漫长/昂贵的数据生成流水线。

在 AI Sheets 中，新列是通过写 prompt 创建的，你可以按需反复迭代，并编辑单元格/校验单元格，把模型"教"成你想要的样子。细节后面展开！

## 我能用它做什么

你可以用 AI Sheets：

**对比与"凭感觉"测试模型。** 假设你想在自家数据上测试最新模型。你可以导入一个带 prompt/问题的数据集，然后为每个模型建一列，prompt 类似：`Answer the following: {{prompt}}`，其中 `prompt` 是你数据集里的一列。你可以手动校验结果，也可以新建一列，用 LLM as a judge 的 prompt，例如：`Evaluate the responses to the following question: {{prompt}}. Response 1: {{model1}}. Response 2: {{model2}}`，其中 `model1` 和 `model2` 是数据集中装不同模型回答的两列。

**为你的数据和特定模型改进 prompt。** 假设你想构建一个处理客户请求并自动答复的应用。你可以加载一个含客户请求的样本数据集，开始用不同 prompt 和模型生成回答进行试验和迭代。AI Sheets 的一个很棒的功能是：你可以通过编辑或校验单元格来提供反馈，这些示例单元格会被自动加入你的 prompt。可以把它当作一个高效打磨 prompt、为 prompt 添加 few-shot 示例的工具——实时看着你的数据来调！

**转换数据集。** 假设你想清理数据集里的某一列。你可以新建一列，prompt 类似 `Remove extra punctuation marks from the following text: {{text}}`，其中 `text` 是数据集中存放待清理文本的列。

**给数据集分类。** 假设你想对数据集中的某些内容做分类。你可以新建一列，prompt 类似 `Categorize the following text: {{text}}`，其中 `text` 是数据集中存放待分类文本的列。

**分析数据集。** 假设你想抽取数据集中的主要观点。你可以新建一列，prompt 类似 `Extract the most important ideas from the following: {{text}}`，其中 `text` 是数据集中存放待分析文本的列。

**增强数据集。** 假设你有一个地址数据集但缺少邮政编码。你可以新建一列，prompt 类似 `Find the zip code of the following address: {{address}}`（本例中必须启用 "Search the web" 选项以确保结果准确）。

**生成合成数据集。** 假设你需要一份含逼真邮件的数据集，但出于数据隐私原因无法使用真实数据。你可以先用 prompt 建一列，如 `Write a short description of a professional in the field of pharma companies`，命名为 `person_bio`。然后新建另一列，prompt 如 `Write a realistic professional email as it was written by the following person: {{person_bio}}`。

下面深入了解怎么用它！

## 如何使用

AI Sheets 提供两种起步方式：导入已有数据，或从零生成数据集。数据加载后，你可以通过添加列、编辑单元格和重新生成内容来精修它。

[![image/png](https://cdn-uploads.huggingface.co/production/uploads/60420dccc15e823a685f2b03/jLZPLa0x2EC9Xw4r3PXa6.png)](https://cdn-uploads.huggingface.co/production/uploads/60420dccc15e823a685f2b03/jLZPLa0x2EC9Xw4r3PXa6.png)

### 开始使用

起步时，你可以用自然语言描述并从头创建一个数据集，或导入一个已有数据集。

#### 从零生成数据集

**适合：** 熟悉 AI Sheets、头脑风暴、快速实验和创建测试数据集。

可以把它理解为 auto-dataset 或 prompt-to-dataset 功能——你描述想要什么，AI Sheets 就为你创建整个数据集的结构和内容。

**什么时候用：**

- 第一次探索 AI Sheets
- 需要用于测试或原型的合成数据
- 数据准确性和多样性无关紧要（如头脑风暴用例、快速调研、生成测试数据集）
- 想快速试验想法

**工作方式：**

- 在 prompt 区域描述你想要的数据集，例如："A list of fictional startups with name, industry, and slogan"
- AI Sheets 生成 schema 并创建 5 行样例
- 可扩展到最多 1,000 行，或修改 prompt 改变结构

**示例**

如果你输入这个 prompt：`cities of the world, alongside countries they belong to and a landmark image for each, generated in Ghibli style`：

[![image/png](https://cdn-uploads.huggingface.co/production/uploads/60420dccc15e823a685f2b03/A8n7AE9DnhaVvaQubxYat.png)](https://cdn-uploads.huggingface.co/production/uploads/60420dccc15e823a685f2b03/A8n7AE9DnhaVvaQubxYat.png)

#### 导入你的数据集（推荐）

***适合：** 想要转换、分类、增强和分析真实世界数据的大多数用例。*

*这是大多数用例的推荐方式，因为导入真实数据比从零开始能带来更好的控制力和灵活性。*

***什么时候用：***

- *你有现成数据，想用 AI 模型转换或增强*
- *你想生成合成数据，且准确性和多样性很重要*

***工作方式：***

- *以 XLS、TSV、CSV 或 Parquet 格式上传数据*
- *确保文件至少包含一列列名和一行数据*
- *最多上传 1,000 行（列数不限）*
- *你的数据会以熟悉的电子表格形式呈现*

***小技巧：** 如果文件内容很少，你可以直接在电子表格里打字手动补充条目。*

### 处理你的数据集

无论以哪种方式起步，数据加载后都会出现在可编辑的电子表格界面中。以下是你需要知道的：

**理解 AI Sheets**

- **导入的单元格：** 可以手动编辑，但不能被 AI prompt 修改
- **AI 生成的单元格：** 可以用 prompt 和你的反馈（编辑 + 点赞）重新生成和精修
- **新列：** 始终由 AI 驱动，完全可定制

**开始使用 AI 列**

- 点击 "+" 按钮添加新列
- 从推荐操作中选择：提取特定信息、总结长文本、翻译内容，或用 "Do something with {{column}}" 写自定义 prompt

### 精修与扩展数据集

有了 AI 列之后，你可以改进它们的结果并扩展数据。你可以通过手动编辑和点赞来提供反馈，或调整列配置来改进结果。两种方式都需要重新生成才会生效。

[![image/png](https://cdn-uploads.huggingface.co/production/uploads/60420dccc15e823a685f2b03/nlVWiRnUKCi308kZ-Fxv0.png)](https://cdn-uploads.huggingface.co/production/uploads/60420dccc15e823a685f2b03/nlVWiRnUKCi308kZ-Fxv0.png)

**1. 如何添加更多单元格**

- **向下拖动：** 从某列最后一个单元格下拉，立即生成额外的行
- 无需重新生成——新单元格即时创建
- 也可以用这个方式重新生成出错的单元格

**2. 手动编辑与反馈**

- **编辑单元格：** 点击任意单元格直接编辑内容——这等于给模型提供了你偏好的输出示例
- **点赞结果：** 用竖起大拇指标记优质输出示例
- 重新生成，把反馈应用到该列的其他单元格。

在底层，这些被手动编辑和点赞过的单元格，会在你重新生成或在该列添加更多单元格时被用作 few-shot 示例！

**3. 调整列配置** 修改 prompt、切换模型或 provider、调整设置，然后重新生成以获得更好的结果。

**重写 prompt**

- 每列都有自己的生成 prompt
- 随时编辑以改变或改进输出
- 该列会用新 prompt 重新生成结果

**切换模型/provider**

- 尝试不同模型以获得不同表现，或进行对比。
- 对特定任务，有的模型更准确、更有创造力或更结构化。
- 有的 provider 推理更快、上下文长度也不同；对选定模型多试几个 provider。

**开关搜索**

- 开启：模型从网上拉取最新信息
- 关闭：纯离线、仅靠模型生成

### 把最终数据集导出到 Hub

对新数据集满意后，把它导出到 Hub！额外的好处是会生成一个可复用的配置文件，你可以用它（1）通过 HF jobs [用这个脚本](https://huggingface.co/datasets/aisheets/uv-scripts/blob/main/extend_dataset/script.py)生成更多数据，（2）把 prompt 复用到下游应用中，包括你编辑和点赞过的单元格里的 few-shot。

[![image/png](https://cdn-uploads.huggingface.co/production/uploads/60420dccc15e823a685f2b03/9To_YsUYVyJSqfL0SAJDW.png)](https://cdn-uploads.huggingface.co/production/uploads/60420dccc15e823a685f2b03/9To_YsUYVyJSqfL0SAJDW.png)

这是一个用 AI Sheets 创建的[示例](https://huggingface.co/datasets/dvilasuero/nemotron-personas-kimi-questions)数据集，它[产出的配置](https://huggingface.co/datasets/dvilasuero/nemotron-personas-kimi-questions/raw/main/config.yml)长这样。

### 用 HF Jobs 运行数据生成脚本

如果想生成更大的数据集，可以用上面提到的配置和脚本，像这样：

```
hf jobs uv run \
-s HF_TOKEN=$HF_TOKEN \
https://huggingface.co/datasets/aisheets/uv-scripts/raw/main/extend_dataset/script.py \ # script for running the pipeline
--config https://huggingface.co/datasets/dvilasuero/nemotron-personas-kimi-questions/raw/main/config.yml \ # config with prompts
--num-rows 100 \ # limit to 100 rows, leave empty for the full dataset
nvidia/Nemotron-Personas dvilasuero/nemotron-kimi-qa-distilled 
```

## 示例

本节提供一些可以用 AI Sheets 构建的数据集示例，为你的下一个项目提供灵感。

### 凭感觉测试与对比模型

如果你想在不同 prompt 和你关心的数据上测试最新模型，AI Sheets 是你的完美搭档。

只需导入一个数据集（或从零创建一个），然后用想测试的模型添加不同的列。

之后你可以手动检查结果，也可以添加一列，用 LLM 评判每个模型的质量。

下面是一个例子：为迷你 web 应用对比开放的前沿模型。AI Sheets 让你能直接查看交互式结果并试玩每个应用。此外，数据集还包含若干用 LLM 评判和比较应用质量的列。

[![image/png](https://cdn-uploads.huggingface.co/production/uploads/60420dccc15e823a685f2b03/ArLkbk5trsp1CzehDw45N.png)](https://cdn-uploads.huggingface.co/production/uploads/60420dccc15e823a685f2b03/ArLkbk5trsp1CzehDw45N.png)

从刚才描述的这类会话导出的示例数据集：[https://huggingface.co/datasets/dvilasuero/jsvibes-qwen-gpt-oss-judged](https://huggingface.co/datasets/dvilasuero/jsvibes-qwen-gpt-oss-judged)

配置：

```
columns:
  gpt-oss:
    modelName: openai/gpt-oss-120b
    modelProvider: groq
    userPrompt: Create a complete, runnable HTML+JS file implementing {{description}}
    searchEnabled: false
    columnsReferences:
      - description
  eval-qwen-coder:
    modelName: Qwen/Qwen3-Coder-480B-A35B-Instruct
    modelProvider: cerebras
    userPrompt: "Please compare the two apps and tell me which one is better and why:\n\nApp description:\n\n{{description}}\n\nmodel 1:\n\n{{qwen3-coder}}\n\nmodel 2:\n\n{{gpt-oss}}\n\nKeep it very short and focus on whether they work well for the purpose, make sure they work and are not incomplete, and the code quality, not on visual appeal and unrequested features. Assume the models might provide non working solutions, so be careful to assess that\n\nRespond with:\n\nchosen: {model 1, model 2}\n\nreason: ..."
    searchEnabled: false
    columnsReferences:
      - gpt-oss
      - description
      - qwen3-coder
  eval-gpt-oss:
    modelName: openai/gpt-oss-120b
    modelProvider: groq
    userPrompt: "Please compare the two apps and tell me which one is better and why:\n\nApp description:\n\n{{description}}\n\nmodel 1:\n\n{{qwen3-coder}}\n\nmodel 2:\n\n{{gpt-oss}}\n\nKeep it very short and focus on whether they work well for the purpose, make sure they work and are not incomplete, and the code quality, not on visual appeal and unrequested features. Assume the models might provide non working solutions, so be careful to assess that\n\nRespond with:\n\nchosen: {model 1, model 2}\n\nreason: ..."
    searchEnabled: false
    columnsReferences:
      - gpt-oss
      - description
      - qwen3-coder
  eval-kimi:
    modelName: moonshotai/Kimi-K2-Instruct
    modelProvider: groq
    userPrompt: "Please compare the two apps and tell me which one is better and why:\n\nApp description:\n\n{{description}}\n\nmodel 1:\n\n{{qwen3-coder}}\n\nmodel 2:\n\n{{gpt-oss}}\n\nKeep it very short and focus on whether they work well for the purpose, make sure they work and are not incomplete, and the code quality, not on visual appeal and unrequested features. Assume the models might provide non working solutions, so be careful to assess that\n\nRespond with:\n\nchosen: {model 1, model 2}\n\nreason: ..."
```

### 给 Hub 数据集添加类别

AI Sheets 还可以增广现有数据集，帮你完成涉及文本数据集分析的快速数据分析和数据科学项目。

下面是一个为现有 Hub 数据集添加类别的例子。

[![image/png](https://cdn-uploads.huggingface.co/production/uploads/60420dccc15e823a685f2b03/K3QMIBf0fSeJFUEA3oI5H.png)](https://cdn-uploads.huggingface.co/production/uploads/60420dccc15e823a685f2b03/K3QMIBf0fSeJFUEA3oI5H.png)

一个很酷的功能是：你可以校验或手动修改初始分类输出，然后整列重新生成以改进结果，如下所示：

[![image/png](https://cdn-uploads.huggingface.co/production/uploads/60420dccc15e823a685f2b03/fp7FE4wpCPP9zU48Cyd6S.png)](https://cdn-uploads.huggingface.co/production/uploads/60420dccc15e823a685f2b03/fp7FE4wpCPP9zU48Cyd6S.png)

配置：

```
columns:
  category:
    modelName: moonshotai/Kimi-K2-Instruct
    modelProvider: groq
    userPrompt: |-
      Categorize the main topics of the following question:

      {{question}}
    prompt: "

      You are a rigorous, intelligent data-processing engine. Generate only the
      requested response format, with no explanations following the user
      instruction. You might be provided with positive, accurate examples of how
      the user instruction must be completed.

      # Examples

      The following are correct, accurate example outputs with respect to the
      user instruction:

      ## Example

      ### Input

      question: Given the area of a parallelogram is 420 square centimeters and
      its height is 35 cm, find the corresponding base. Show all work and label
      your answer.

      ### Output

      Mathematics – Geometry

      ## Example

      ### Input

      question: What is the minimum number of red squares required to ensure
      that each of $n$ green axis-parallel squares intersects 4 red squares,
      assuming the green squares can be scaled and translated arbitrarily
      without intersecting each other?

      ### Output

      Geometry, Combinatorics
      # User instruction

      Categorize the main topics of the following question:

      {{question}}

      # Your response
      "
    searchEnabled: false
    columnsReferences:
      - question
```

### 用 LLMs-as-Judge 评估模型

另一个用例是用 LLM as a judge 的方式评估模型输出。这在对比模型或评估现有数据集质量时很有用，例如在 Hugging Face Hub 的现有数据集上微调模型之前。

在第一个例子中，我们把凭感觉测试与一列 judge LLM 结合在一起。下面是 judge prompt：

[![image/png](https://cdn-uploads.huggingface.co/production/uploads/60420dccc15e823a685f2b03/uiP176LVIcfSKHC-RUH6r.png)](https://cdn-uploads.huggingface.co/production/uploads/60420dccc15e823a685f2b03/uiP176LVIcfSKHC-RUH6r.png)

示例数据集：[https://huggingface.co/datasets/dvilasuero/jsvibes-qwen-gpt-oss-judged](https://huggingface.co/datasets/dvilasuero/jsvibes-qwen-gpt-oss-judged)

配置：

```
columns:
  object_name:
    modelName: meta-llama/Llama-3.3-70B-Instruct
    modelProvider: groq
    userPrompt: Generate the name of a common day to day object
    searchEnabled: false
    columnsReferences: []
  object_description:
    modelName: meta-llama/Llama-3.3-70B-Instruct
    modelProvider: groq
    userPrompt: Describe a {{object_name}} with adjectives and short word groups separated by commas. No more than 10 words
    searchEnabled: false
    columnsReferences:
      - object_name
  object_image_with_desc:
    modelName: multimodalart/isometric-skeumorphic-3d-bnb
    modelProvider: fal-ai
    userPrompt: RBNBICN, icon, white background, isometric perspective, {{object_name}} , {{object_description}}
    searchEnabled: false
    columnsReferences:
      - object_description
      - object_name
  object_image_without_desc:
    modelName: multimodalart/isometric-skeumorphic-3d-bnb
    modelProvider: fal-ai
    userPrompt: "RBNBICN, icon, white background, isometric perspective, {{object_name}} "
    searchEnabled: false
    columnsReferences:
      - object_name
  glowing_colors:
    modelName: multimodalart/isometric-skeumorphic-3d-bnb
    modelProvider: fal-ai
    userPrompt: "RBNBICN, icon, white background, isometric perspective, {{object_name}}, glowing colors "
    searchEnabled: false
    columnsReferences:
      - object_name
  flux:
    modelName: black-forest-labs/FLUX.1-dev
    modelProvider: fal-ai
    userPrompt: Create an isometric icon for the object {{object_name}} based on {{object_description}}
    searchEnabled: false
    columnsReferences:
      - object_description
      - object_name
```
