# Hugging Face 的公共政策

Irene Solaiman (irenesolaiman)

Yacine Jernite (yjernite)

Avijit Ghosh (evijit)

Lucie-Aimée Kaffee (frimelle)

Hugging Face 的 AI 政策（AI Policy）是一条跨学科、跨组织的工作线。我们的政策工作不隶属于对外的传播或全球事务部门，而是扎根于众多研究员和开发者的专业能力之中——从[《伦理与社会》专栏](https://huggingface.co/blog/ethics-soc-1)、法务团队，到从事医疗、艺术和评测工作的机器学习工程师。

我们的工作内容来自 Hugging Face 社区在 Hub 上的需求和体验。我们倡导[负责任的开放](https://huggingface.co/blog/ethics-soc-3)，大力投入[以伦理为先的研究](https://huggingface.co/spaces/society-ethics/about)、[透明度机制](https://huggingface.co/blog/model-cards)、[平台安全措施](https://huggingface.co/content-guidelines)，并把获得的经验转化为政策建议。

那么，我们都和政策制定者分享过什么？
