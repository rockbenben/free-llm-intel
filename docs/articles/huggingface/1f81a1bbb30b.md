# 欢迎 Llama 3 —— Meta 全新的开源 LLM

## 引言

Meta 的 Llama 3——开放访问 Llama 家族的下一成员——现已发布，并可在 Hugging Face 获取。很高兴看到 Meta 持续致力于开放 AI，我们也很兴奋能以 Hugging Face 生态的全面集成来全力支持这次发布。

Llama 3 有两种规模：8B，适合在消费级 GPU 上高效部署和开发；70B，面向大规模 AI 原生应用。两者都有 base（基础版）和指令微调版。除这 4 个模型外，新版 Llama Guard 也在 Llama 3 8B 上完成微调，以 Llama Guard 2（安全微调版）的名义发布。

我们与 Meta 紧密合作，确保其最佳集成体验。全部 5 个开放访问模型（2 个基础模型、2 个微调模型和 Llama Guard）都已上线 Hub。本次随发布推出的功能与集成包括：

- [Hub 上的模型](https://huggingface.co/meta-llama)，含模型卡与许可证
- 🤗 Transformers 集成
- [Hugging Chat 集成 Meta Llama 3 70b](https://huggingface.co/chat/models/meta-llama/Meta-Llama-3-70B-instruct)
- Inference Endpoints、Google Cloud 和 Amazon SageMaker 的推理集成
- 用 🤗 TRL 在单块 GPU 上微调 Llama 3 8B 的示例

## Llama 3 有什么新变化？

本次 Llama 3 发布带来 Meta 基于 Llama 2 架构的 4 个新开放 LLM。分两种规模：8B 和 70B 参数，各含 base（预训练）和指令微调版本。所有变体都能在多种消费级硬件上运行，上下文长度为 8K token。

- [Meta-Llama-3-8b](https://huggingface.co/meta-llama/Meta-Llama-3-8B)：8B 基础模型
- [Meta-Llama-3-8b-instruct](https://huggingface.co/meta-llama/Meta-Llama-3-8B-Instruct)：8B 基础模型的指令微调版
- [Meta-Llama-3-70b](https://huggingface.co/meta-llama/Meta-Llama-3-70B)：70B 基础模型
- [Meta-Llama-3-70b-instruct](https://huggingface.co/meta-llama/Meta-Llama-3-70B-instruct)：70B 基础模型的指令微调版

除这 4 个基础模型外，Llama Guard 2 也一并发布。它在 Llama 3 8B 上微调，是 Llama Guard 家族的最新迭代。为生产场景打造的 Llama Guard 2，用于对 LLM 输入（提示词）和 LLM 响应做分类，依据风险分类体系检测会被视为不安全的内容。

与 Llama 2 相比，Llama 3 的一大变化是采用新分词器，把词表扩大到 128,256（上一版本只有 3.2 万 token）。更大的词表能更高效地编码文本（输入和输出都是），并可能带来更强的多语言能力。但代价也存在：输入输出 embedding 矩阵更大，这正是小模型参数量从 Llama 2 的 7B 增加到 Llama 3 的 8B 的重要原因。另外，8B 版本现在使用分组查询注意力（GQA），这是一种高效表示，有助于应对更长上下文。

Llama 3 模型在超过 15 万亿 token、约 8 倍于以往的公开网络数据混合集上训练，训练集群共 24,000 块 GPU。我们不掌握训练数据配比的确切细节，但可以猜测更大规模、更精细的数据整编是性能提升的重要因素。Llama 3 Instruct 针对对话应用做了优化，在超过 1000 万个人工标注样本上训练，结合了监督微调（SFT）、拒绝采样、近端策略优化（PPO）和直接策略优化（DPO）。

许可条款方面，Llama 3 采用允许再分发、微调和衍生作品的宽松许可证。Llama 3 许可证新增了明确要求署名的条款——这在 Llama 2 中没有。例如，衍生模型需要在名称开头带上 "Llama 3"，并且你需要在衍生作品或服务中注明 "Built with Meta Llama 3"。完整细节请务必阅读[官方许可证](https://huggingface.co/meta-llama/Meta-Llama-3-70B/blob/main/LICENSE)。

## 如何给 Llama 3 写提示词

基础模型没有提示词格式。和其他基础模型一样，它们可用于对输入序列做合理的续写，或做 zero-shot/few-shot 推理，也是为你的自有用例做微调的绝佳底座。Instruct 版本使用如下对话结构：

```
<|begin_of_text|><|start_header_id|>system<|end_header_id|>

{{ system_prompt }}<|eot_id|><|start_header_id|>user<|end_header_id|>

{{ user_msg_1 }}<|eot_id|><|start_header_id|>assistant<|end_header_id|>

{{ model_answer_1 }}<|eot_id|>
```

这个格式必须一字不差地复现才能有效使用。后面我们会演示如何用 `transformers` 提供的 chat template 轻松还原这一指令提示词。

## 使用 🤗 Transformers

借助 Transformers [4.40 版本](https://github.com/huggingface/transformers/releases/tag/v4.40.0)，你可以使用 Llama 3，并充分发挥 Hugging Face 生态中的各类工具，例如：

- 训练与推理脚本及示例
- 安全的文件格式（`safetensors`）
- 与 bitsandbytes（4-bit 量化）、PEFT（参数高效微调）和 Flash Attention 2 等工具的集成
- 用于模型生成的工具函数和辅助方法
- 用于部署的模型导出机制

此外，Llama 3 模型兼容配合 CUDA graphs 的 `torch.compile()`，推理时延约可快 4 倍！

要在 transformers 中使用 Llama 3 模型，请确保安装较新版本的 `transformers`：

```
pip install --upgrade transformers
```

下面的代码片段演示如何用 transformers 使用 `Llama-3-8b-instruct`。它大约需要 16GB 显存/内存，3090、4090 这类消费级 GPU 即可满足。

```
from transformers import pipeline
import torch

model_id = "meta-llama/Meta-Llama-3-8B-Instruct"

pipe = pipeline(
    "text-generation",
    model=model_id,
    model_kwargs={"torch_dtype": torch.bfloat16},
    device="cuda",
)

messages = [
    {"role": "system", "content": "You are a pirate chatbot who always responds in pirate speak!"},
    {"role": "user", "content": "Who are you?"},
]

terminators = [
    pipe.tokenizer.eos_token_id,
    pipe.tokenizer.convert_tokens_to_ids("<|eot_id|>")
]

outputs = pipe(
    messages,
    max_new_tokens=256,
    eos_token_id=terminators,
    do_sample=True,
    temperature=0.6,
    top_p=0.9,
)
assistant_response = outputs[0]["generated_text"][-1]["content"]
print(assistant_response)
```

> Arrrr, me hearty! Me name be Captain Chat, the scurviest pirate chatbot to ever sail the Seven Seas! Me be here to swab the decks o' yer mind with me trusty responses, savvy? I be ready to hoist the Jolly Roger and set sail fer a swashbucklin' good time, matey! So, what be bringin' ye to these fair waters?

有几个细节：

- 我们以 `bfloat16` 加载模型。这是 Meta 发布的原始检查点所用的类型，也是确保最佳精度或做评测时推荐的运行方式。实际使用中也完全可以放心用 `float16`，视硬件不同它可能更快。
- Assistant 的回答可能以特殊 token `<|eot_id|>` 结束，但遇到常规 EOS token 时也必须停止生成。我们可以通过 `eos_token_id` 参数传入终止符列表来提前停止。
- 我们使用了取自 Meta 原始代码库的默认采样参数（`temperature` 和 `top_p`）。我们还没来得及做大量测试，欢迎自行探索！

你也可以自动量化模型，以 8-bit 甚至 4-bit 模式加载。4-bit 加载运行只需约 7GB 显存，大量消费级显卡和 Google Colab 的所有 GPU 都能带动。4-bit 加载生成流水线的写法：

```
pipeline = transformers.pipeline(
    "text-generation",
    model=model_id,
    model_kwargs={
        "torch_dtype": torch.float16,
        "quantization_config": {"load_in_4bit": True},
        "low_cpu_mem_usage": True,
    },
)
```

关于用 transformers 使用这些模型的更多细节，请参阅[模型卡](https://huggingface.co/meta-llama/Meta-Llama-3-8B-Instruct)。

## 推理集成

本节介绍运行 Llama 3 模型推理的各种方式。在使用这些模型之前，请确保你已在官方 [Meta Llama 3](https://TODO) 仓库中申请了其中一个模型的访问权限。

### 与 Inference Endpoints 的集成

你可以把 Llama 3 部署到 Hugging Face 的 [Inference Endpoints](https://ui.endpoints.huggingface.co/)，其后端是 Text Generation Inference。[Text Generation Inference](https://github.com/huggingface/text-generation-inference) 是 Hugging Face 开发的生产级推理容器，让大语言模型部署更轻松。它支持持续批处理、token 流式输出、用于多 GPU 快速推理的张量并行，以及生产级日志和链路追踪。

要部署 Llama 3，前往[模型页](https://huggingface.co/meta-llama/Meta-Llama-3-70B-instruct)并点击 [Deploy -> Inference Endpoints](https://ui.endpoints.huggingface.co/philschmid/new?repository=meta-llama/Meta-Llama-3-70B-instruct&vendor=aws&region=us-east-1&accelerator=gpu&instance_size=4xlarge&task=text-generation&no_suggested_compute=true&tgi=true&tgi_max_batch_prefill_tokens=16384&tgi_max_batch_total_tokens=16384&tgi_max_input_length=4000&tgi_max_total_tokens=8192) 组件。如何在先前一篇博客中我们介绍过[用 Hugging Face Inference Endpoints 部署 LLM](https://huggingface.co/blog/inference-endpoints-llm)。Inference Endpoints 通过 Text Generation Inference 支持 [Messages API](https://huggingface.co/blog/tgi-messages-api)，你只需更换 URL，就能从另一个封闭模型切换到开放模型。

```
from openai import OpenAI

# initialize the client but point it to TGI
client = OpenAI(
    base_url="<ENDPOINT_URL>" + "/v1/",  # replace with your endpoint url
    api_key="<HF_API_TOKEN>",  # replace with your token
)
chat_completion = client.chat.completions.create(
    model="tgi",
    messages=[
        {"role": "user", "content": "Why is open-source software important?"},
    ],
    stream=True,
    max_tokens=500
)

# iterate and print stream
for message in chat_completion:
    print(message.choices[0].delta.content, end="")
```

### 与 Google Cloud 的集成

你可以通过 Vertex AI 或 Google Kubernetes Engine (GKE)，使用 [Text Generation Inference](https://huggingface.co/docs/text-generation-inference/index) 在 Google Cloud 上部署 Llama 3。

要从 Hugging Face 部署 Llama 3 模型，前往[模型页](https://huggingface.co/meta-llama/Meta-Llama-3-70B-instruct)并点击 [Deploy -> Google Cloud。](https://console.cloud.google.com/vertex-ai/publishers/meta-llama/model-garden/Meta-Llama-3-70B-instruct;hfSource=true;action=deploy)这会带你进入 Google Cloud Console，在 Vertex AI 或 GKE 上一次点击部署 Llama 3。

### 与 Amazon SageMaker 的集成

你可以通过 AWS Jumpstart 或使用 [Hugging Face LLM Container](https://huggingface.co/blog/sagemaker-huggingface-llm)，在 Amazon SageMaker 上部署和训练 Llama 3。

要从 Hugging Face 部署 Llama 3 模型，前往[模型页](https://huggingface.co/meta-llama/Meta-Llama-3-70B-instruct)并点击 [Deploy -> Amazon SageMaker。](https://huggingface.co/meta-llama/Meta-Llama-3-70B-instruct?sagemaker_deploy=true)页面会显示一段可直接复制到你环境中执行的代码片段。Amazon SageMaker 随后会创建一个专属推理 endpoint，供你发送请求。

## 用 🤗 TRL 微调

训练 LLM 在技术和算力上都不轻松。本节看看 Hugging Face 生态中有哪些工具可以让我们高效地在消费级 GPU 上训练 Llama 3。下面是微调 Llama 3 学习 [No Robots 数据集](https://huggingface.co/datasets/HuggingFaceH4/no_robots)的示例命令。我们使用 4-bit 量化与 [QLoRA](https://arxiv.org/abs/2305.14314)，TRL 的 SFTTrainer 会自动把数据集整理成 `chatml` 格式。开始吧！

首先，安装最新版本的 🤗 TRL。

```
pip install -U transformers trl accelerate
```

如果你只想在终端里和模型聊天，可以用 TRL CLI 的 `chat` 命令（详情见[文档](https://huggingface.co/docs/trl/en/clis#chat-interface)）：

```
trl chat \
--model_name_or_path meta-llama/Meta-Llama-3-8B-Instruct \
--device cuda \
--eos_tokens "<|end_of_text|>,<|eod_id|>"
```

你也可以用 TRL CLI 监督微调（SFT）Llama 3 学习自己的自定义数据集。使用 `trl sft` 命令，把训练参数作为 CLI 参数传入。确保你已登录并且有 Llama 3 检查点的访问权限——可以用 `huggingface-cli login` 完成登录。

```
trl sft \
--model_name_or_path meta-llama/Meta-Llama-3-8B \
--dataset_name HuggingFaceH4/no_robots \
--learning_rate 0.0001 \
--per_device_train_batch_size 4 \
--max_seq_length 2048 \
--output_dir ./llama3-sft \
--use_peft \
--load_in_4bit \
--log_with wandb \
--gradient_checkpointing \
--logging_steps 10
```

这会在终端里运行微调，在单块 A10G 上大约需要 4 小时训练完；通过把 `--num_processes` 调整为你可用的 GPU 数量即可轻松并行化。

*注意：你也可以把 CLI 参数换成一个 `yaml` 文件。进一步了解 TRL CLI 请看[这里](https://huggingface.co/docs/trl/clis#fine-tuning-with-the-cli)。*
