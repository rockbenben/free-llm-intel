介绍 [Synthetic Data Generator（合成数据生成器）](https://huggingface.co/spaces/argilla/synthetic-data-generator)——一个易用的应用，以无代码（no-code）方式借助大语言模型（LLM）创建自定义数据集。最棒的是：一个简单的分步流程，让数据集创建变得毫无技术门槛，任何人都能在几分钟内、不写一行代码地创建数据集和模型。

什么是合成数据，它为什么有用？

合成数据是模拟真实世界数据的人工生成信息。它让我们能够突破数据的限制，扩充或增强数据集。

## 从提示到数据集再到模型

合成数据生成器接收你对想要数据的描述（你的自定义 prompt），通过一条合成数据流水线返回适合你用例的数据集。背后由 [distilabel](https://distilabel.argilla.io/latest/) 和[免费的 Hugging Face text-generation API](https://huggingface.co/docs/api-inference/en/index)驱动，但你无需操心这些复杂性，专注于使用 UI 即可。

### 支持的任务

该工具目前支持文本分类与 chat 数据集。这些任务决定你将生成的数据集类型：分类需要类别，chat 数据需要对话。根据需求，我们会陆续加入评估与 RAG 等任务。

#### 文本分类

文本分类常用于给文本归类，例如客户评论、社交媒体帖子或新闻文章。生成分类型数据集依赖两个不同的步骤，我们都用 LLM 来完成：先多样化的生成文本，再为其添加标签。一个优秀的合成分类型数据集例子是 [argilla/synthetic-text-classification-news](https://huggingface.co/datasets/argilla/synthetic-text-classification-news)，它把合成新闻文章分成 8 个类别。

#### Chat 数据集

这类数据集可用于监督微调（SFT）——让 LLM 能够处理对话数据、通过聊天界面与用户交互的技术。一个合成 chat 数据集的例子是 [argilla/synthetic-sft-customer-support-single-turn](https://huggingface.co/datasets/argilla/synthetic-sft-customer-support-single-turn)，它展示了一个面向客服场景设计的 LLM。在这个例子中，客服的主题正是合成数据生成器本身。

一般来说，文本分类与 chat 每分钟可分别生成 50 和 20 个样本。这些都由免费的 Hugging Face API 驱动，但你可以通过使用自己的账户、选择自定义模型、API 提供商或生成配置来扩展规模。这些我们稍后再谈，先来看基础流程。

### 生成我们的第一个数据集

我们来创建一个基础的 chat 数据集。[访问生成器](https://huggingface.co/spaces/argilla/synthetic-data-generator)时，你需要登录，授权工具访问你想为其生成数据集的组织。这样工具才能上传生成的数据集。如果认证失败，你随时可以[重置连接](https://huggingface.co/settings/connected-applications)。

登录后，UI 会引导你走完简单的三步流程：

#### 1. 描述你的数据集

先提供你想创建的数据集的描述，包含示例用例，帮助生成器理解你的需求。尽可能详细地描述助手的目标与类型。点击 "Create" 按钮后，会生成一个样本数据集，你可以进入第 2 步。

#### 2. 配置与打磨

通过调整根据你的描述生成的 `system prompt` 以及任务相关的设置，来打磨生成的样本数据集。这会帮你得到你想要的特定结果。你可以不断调整这些配置，点 "Save" 并重新生成样本数据集。对配置满意后，进入第 3 步。

#### 3. 生成并推送

填写数据集名称与组织等常规信息。你还可以定义要生成的样本数量与生成使用的 temperature。这个 temperature 代表生成的创造性。点击 "Generate" 开始完整生成。输出会直接保存到 Argilla 和 Hugging Face Hub。

现在可以点击 "Open in Argilla" 按钮，直接进入我们生成的数据集。

### 检查数据集

即便处理的是合成数据，理解并查看你的数据也很重要，这就是我们创建与 [Argilla](https://argilla.io/) 直接集成的原因——Argilla 是 AI 工程师与领域专家协作构建高质量数据集的工具。它让你通过语义搜索、可组合过滤器等强大功能高效探索与评估合成数据集。你可以在[这份指南](https://docs.argilla.io/latest/how_to_guides/annotate/)里了解更多。之后，我们可以把整备好的数据集导出到 Hugging Face Hub，并用它继续微调模型。

### 训练模型

别担心，如今即便构建强大的 AI 模型也可以不写代码——用 [AutoTrain](https://huggingface.co/autotrain)。想了解 AutoTrain 可以看它的[文档](https://huggingface.co/docs/autotrain/en/index)。这里我们[创建自己的 AutoTrain 部署](https://huggingface.co/spaces/autotrain-projects/autotrain-advanced?duplicate=true)，像之前给合成数据生成器那样登录即可。

还记得开头提到的 [argilla/synthetic-text-classification-news 数据集](https://huggingface.co/datasets/argilla/synthetic-text-classification-news)吗？我们来训练一个能正确分类这些样本的模型。需要选择任务 "Text Classification" 并提供正确的 "Dataset source"。然后起一个好听的项目名，按下 play！那个警告成本的弹窗可以忽略，因为我们仍在免费的 Hugging Face CPU 硬件上工作——对这个文本分类例子绰绰有余。

Et voilà，几分钟后，我们就有了[自己的模型](https://huggingface.co/argilla/synthetic-text-classification-news-autotrain-model)！剩下的只是把它[部署为在线服务](https://www.youtube.com/watch?v=J15u1Y2b4sw)，或用少量 Python 代码把它当作 [text-classification pipeline](https://huggingface.co/docs/transformers/main_classes/pipelines#transformers.TextClassificationPipeline) 使用。

## 高级特性

虽然你可以从 prompt 直达专用模型、完全不懂编程，但有些人可能喜欢用更高级的技术特性来定制和扩展部署。

### 提升速度与准确率

你可以创建该工具的自有部署，通过配置不同参数或模型来提升速度与准确率。首先必须[复制（duplicate）合成数据生成器](https://huggingface.co/spaces/argilla/synthetic-data-generator?duplicate=true)，确保创建为私有 Space，以免他人访问。接着你可以[修改某些环境变量的默认值](https://github.com/argilla-io/synthetic-data-generator?tab=readme-ov-file#environment-variables)。过几个场景：

- 使用不同的免费 Hugging Face 模型。把 `MODEL` 从默认值 `meta-llama/Llama-3.1-8B-Instruct` 换成别的模型，例如 `meta-llama/Llama-3.1-70B-Instruct`。
- 使用 OpenAI 模型。把 `BASE_URL` 设为 `https://api.openai.com/v1/`，`MODEL` 设为 `gpt-4o`。
- 增大批次大小，每分钟生成更多样本。把 `BATCH_SIZE` 从默认的 `5` 改成更大的值，如 `10`。注意你的 API 提供商可能有每分钟请求数限制。
- 私有 Argilla 实例。把 `ARGILLA_URL` 与 `ARGILLA_API_KEY` 设为[你的免费 Argilla 实例](https://docs.argilla.io/dev/getting_started/quickstart/)的 URL 与 API key。

### 本地部署

除了托管在 Hugging Face Spaces，我们还以 Apache 2 许可证把它作为开源工具提供，这意味着你可以[前往 GitHub](https://github.com/argilla-io/synthetic-data-generator)，按需使用、修改和适配它。你可以通过一行 `pip install synthetic-dataset-generator` [把它安装为 Python 包](https://github.com/argilla-io/synthetic-data-generator?tab=readme-ov-file#installation)。创建时务必配置正确的环境变量。（原文此处截断）

### 定制流水线

每条合成数据流水线都基于 [distilabel](https://distilabel.argilla.io/latest/)——那个面向合成数据与 AI 反馈的框架。distilabel 是开源的；流水线代码的妙处在于可共享、可复现。例如，你可以在 Hub 的仓库里[找到 argilla/synthetic-text-classification-news 数据集的流水线](https://huggingface.co/datasets/argilla/synthetic-text-classification-news/blob/main/pipeline.py)。此外，你还可以找到[许多其他 distilabel 数据集及其流水线](https://huggingface.co/datasets?other=distilabel)。
