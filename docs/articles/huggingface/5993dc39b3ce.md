# 用 Gradio 做可见水印

[![image/webp](https://cdn-uploads.huggingface.co/production/uploads/60c757ea5f9a76ab3f844f12/DM6_nlPtgsfRytok2F1Ib.webp)](https://cdn-uploads.huggingface.co/production/uploads/60c757ea5f9a76ab3f844f12/DM6_nlPtgsfRytok2F1Ib.webp)

去年，我们分享过一篇[关于水印的博客](https://huggingface.co/blog/watermarking)，解释了给生成式 AI 内容加水印意味着什么、为何重要。随着全世界人们开始生成并分享 AI 生成的图像、视频、音频和文本，对水印的需求变得愈发关键。图像和视频已逼真到几乎无法与真实相机拍摄的内容区分开来。解决这一问题涉及多个层面，但有一个清晰、唾手可得的低垂果实 🍇：

> 要让人们知道什么是真实的、什么是合成的，请使用可见水印。

为助大家一臂之力，我们 Hugging Face 已让可见水印变得极其简单：每当你[创建一个应用或演示形式的 Space](https://huggingface.co/new-space)，都可以使用我们的自研应用构建库 Gradio，只需一条命令即可显示水印。

对于图像和视频，只需添加 `watermark` 参数，像这样：

```
gr.Image(my_generated_image, watermark=my_watermark_image)
```

```
gr.Video(my_generated_video, watermark=my_watermark_image)
```

> 想看实际效果：来查看我们的图像与视频水印示例 Space。

水印可以用文件名指定；对于图像，我们额外还支持直接传入已打开的图像，甚至 numpy 数组，以最好地契合你搭建接口的方式。我特别喜欢的一个选项是 QR 二维码水印，它可以承载关于内容的更多信息，[甚至能与你的图像或视频风格相匹配](https://huggingface.co/spaces/huggingface-projects/QR-code-AI-art-generator)。

你也可以为 AI 生成的文本添加自定义可见水印，使每当它被复制时都会显示水印。像这样：

```
gr.Chatbot(label=my_model_name, watermark=my_watermark_text, type="messages", show_copy_button=True, show_copy_all_button=True)
```

> 想看实际效果：来查看我们的聊天机器人水印示例 Space。

这会自动在用户从 AI 回复中复制文本时加上署名，进一步推动文本生成的 AI 透明度与披露。

今天就来试试这一切，打造你自己的水印，玩得开心！
