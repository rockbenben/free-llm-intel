语言技术实验室（The Language Technologies Lab）在多模态人工智能上迈出了重要一步，发布了 **Visual Salamandra**，把 Salamandra 大语言模型（LLM）的能力扩展到图像和视频。Visual Salamandra 基于这个 **70 亿参数**的基础模型，在保持其紧凑与高效的同时，将其延伸到多模态任务。

Visual Salamandra 以视觉-语言对齐为核心设计，在 Salamandra Instructed 7B 模型之上，集成 Google 的 SigLIP 编码器（SigLIP-So400m）、一个 2 层 MLP projector，以及先进的 late-fusion 技术，以弥合视觉与文本模态之间的鸿沟。

由此得到的架构使 Visual Salamandra 能够从多样输入中理解并生成上下文准确的回答——输入可以是单张或多张图像、视频，也可以是纯文本指令。这一进展体现了实验室更广泛的承诺：支持稳健、多语言、多模态的 AI 系统——尤其是那些重视欧洲语言多样性的系统。

## 训练 Visual Salamandra：视觉实验详解

为了让 Salamandra 适配视觉输入，实验室实施了以 late-fusion 架构为核心的四阶段训练流程。在这一设置下，预训练的图像编码器（SigLIP，14 个 patch，384x384 分辨率）生成图像嵌入，随后通过对齐训练的自定义多层感知机（MLP）projector 与 LLM 对齐。

四个训练阶段包括：

• **阶段 1：Projector 预训练** – 只训练 projector，把图像特征映射进 LLM 的潜空间。

• **阶段 2：高质量视觉预训练** – 使用精修后的数据集（如 OCR 和重新生成描述（re-captioned）的图像），对整个架构（编码器、projector 和 LLM）进行联合训练。

• **阶段 3：指令微调（Instruction Tuning）** – 模型通过视觉问答（VQA）、OCR 及其他有依据（grounded）的视觉任务学会遵循用户指令。

• **阶段 4：完整多模态微调** – 引入单图/多图与视频数据，以及纯文本样本，以优化模型对真实世界多输入场景的泛化能力。

数据多样性在整个训练中扮演了关键角色。指令微调共使用了 610 万条实例，其中包括 84.2 万条纯文本样本。训练语料取材于 AI2D、Cambrian、LLaVA Next 等来源，选择它们是为了增强视觉定位（visual grounding）、文档理解、数学推理和 OCR 能力。

## 多语言数据与欧洲语言的呈现

与语言技术实验室此前的模型一样，Visual Salamandra 延续了对**多语言包容性**的承诺，重点覆盖欧洲语言。

这种做法保证了代表性不足的语言也能受益于指令微调和视觉任务对齐，有助于缩小多模态 AI 研究中的资源差距。Visual Salamandra 是最早把 such 语言多样性融入 **多模态指令微调框架**的模型之一。

## 应用与未来方向

Visual Salamandra 在语言与视觉的交叉领域解锁了大量应用，例如：

• 视觉问答（VQA）：就图像或视频提问，获得符合上下文的准确回答。

• 光学字符识别（OCR）：从文档、实景和图表中准确读取并转录文本。

• 文档与图表理解：分析内嵌文本的复杂视觉文档或图形内容。

• 数学推理：通过多模态推理解决有视觉依据的数学问题。

• 基于指令的图像交互：在视觉场景中遵循详细指令，包括图像描述（captioning）和定位任务。

视频能力的加入也为视频摘要、事件检测和多模态叙事等进一步发展打开了大门……

通过 Visual Salamandra，语言技术实验室展示了其在打造包容、高性能基础模型方面的持续领导力。通过将最先进的视觉编码器与强大的多语言 LLM 相融合，团队正在为能够观看、理解并交流的下一代 AI 系统铺路——跨越模态，跨越语言。

## 伦理关切与局限

虽然 Visual Salamandra 展现出很强的多模态能力，但也需要注意它的局限：

• 它可能产生看似合理但实际错误的「幻觉」回答，尤其是在视觉输入含糊不清时。

• 复杂 OCR 和密集文档排版的处理仍然具有挑战性。

• 模型使用经过过滤且获得许可的数据集训练，但用户仍应对潜在的偏见或不准确保持警惕，特别是在部署到敏感应用场景时。

我们建议在可以有人工监督的场景下使用 Visual Salamandra，并在未经充分评估的情况下避免将其用于高风险应用。
