# 使用 Streamlit 在 Hugging Face Spaces 上托管你的模型与数据集

## 使用 Streamlit 在 Hugging Face Spaces 上展示你的数据集与模型

[Streamlit](https://streamlit.io/) 让你能够以一种简洁的方式可视化数据集并构建机器学习模型的演示。在这篇博客中，我们将带你了解如何在 Hugging Face Spaces 上托管模型与数据集，并运行你的 Streamlit 应用。

## 为你的模型构建演示

你可以加载任意 Hugging Face 模型，并用 Streamlit 构建漂亮的界面。在这个具体示例中，我们将一起重现 ["Write with Transformer"](https://transformer.huggingface.co/doc/gpt2-large)。这是一个让你使用 GPT-2 和 XLNet 等 transformer 进行书写的应用。

[![write-with-transformers](https://huggingface.co/blog/assets/29_streamlit-spaces/write-tr.png)](https://huggingface.co/blog/assets/29_streamlit-spaces/write-tr.png)

我们不会深入探讨推理的具体原理。你只需要知道，这个应用需要指定一些超参数值。Streamlit 提供了许多[组件](https://docs.streamlit.io/en/stable/api.html)，让你轻松实现自定义应用。我们会用其中一些组件在推理代码中接收必要的超参数。

- `.text_area` 组件创建一块用于输入待补全句子的文本区域。
- Streamlit 的 `.sidebar` 方法让你在侧边栏中接收变量。
- `slider` 用于获取连续值。别忘了给 `slider` 设置步长（step），否则它会把值当作整数处理。
- 你可以用 `number_input` 让最终用户输入整数值。

```
import streamlit as st

# adding the text that will show in the text box as default
default_value = "See how a modern neural network auto-completes your text 🤗 This site, built by the    Hugging Face team, lets you write a whole document directly from your browser, and you can trigger the Transformer anywhere using the Tab key. Its like having a smart machine that completes your thoughts 😀 Get started by typing a custom snippet, check out the repository, or try one of the examples. Have fun!"

sent = st.text_area("Text", default_value, height = 275)
max_length = st.sidebar.slider("Max Length", min_value = 10, max_value=30)
temperature = st.sidebar.slider("Temperature", value = 1.0, min_value = 0.0, max_value=1.0, step=0.05)
top_k = st.sidebar.slider("Top-k", min_value = 0, max_value=5, value = 0)
top_p = st.sidebar.slider("Top-p", min_value = 0.0, max_value=1.0, step = 0.05, value = 0.9)
num_return_sequences = st.sidebar.number_input('Number of Return Sequences', min_value=1, max_value=5, value=1, step=1)
```

推理代码会返回生成的输出，你可以用简单的 `st.write` 打印输出。`st.write(generated_sequences[-1])`

这是我们重现版本的样貌。[![streamlit-rep](https://huggingface.co/blog/assets/29_streamlit-spaces/streamlit-rep.png)](https://huggingface.co/blog/assets/29_streamlit-spaces/streamlit-rep.png)

你可以[在这里](https://huggingface.co/spaces/merve/write-with-transformer)查看完整代码。

## 展示你的数据集与数据可视化

Streamlit 提供了许多组件帮助你可视化数据集。它与 🤗 [Datasets](https://huggingface.co/docs/datasets/)、[pandas](https://pandas.pydata.org/docs/index.html)，以及 [matplotlib](https://matplotlib.org/stable/index.html)、[seaborn](https://seaborn.pydata.org/)、[bokeh](https://bokeh.org/) 等可视化库无缝配合。

我们先从加载一个数据集开始。`Datasets` 中一个名为[流式加载（streaming）](https://huggingface.co/docs/datasets/dataset_streaming.html)的新特性让你能够立即处理非常大的数据集，无需下载所有样本并将它们加载到内存中。

```
from datasets import load_dataset
import streamlit as st

dataset = load_dataset("merve/poetry", streaming=True)
df = pd.DataFrame.from_dict(dataset["train"])
```

如果你像我的一样有结构化数据，可以直接用 `st.dataframe(df)` 来展示你的数据集。有很多 Streamlit 组件可以交互式地绘制数据。其中之一是 `st.barchart()`，我用它来可视化诗歌内容中出现频率最高的词。

```
st.write("Most appearing words including stopwords")
st.bar_chart(words[0:50])
```

如果你想使用 matplotlib、seaborn 或 bokeh 这类库，只需在绘图脚本末尾加上 `st.pyplot()`。

```
st.write("Number of poems for each author")
sns.catplot(x="author", data=df, kind="count", aspect = 4)
plt.xticks(rotation=90)
st.pyplot()
```

你可以在下方看到交互式柱状图、dataframe 组件，以及托管的 matplotlib 和 seaborn 可视化。你可以[在这里](https://huggingface.co/spaces/merve/streamlit-dataset-demo)查看代码。

[![spaces-streamlit-dataset-demo](https://huggingface.co/blog/assets/29_streamlit-spaces/streamlit-dataset-vid.gif)](https://huggingface.co/blog/assets/29_streamlit-spaces/streamlit-dataset-vid.gif)

## 在 Hugging Face Spaces 上托管你的项目

你可以像下面展示的那样直接拖放文件。请注意，你需要把额外的依赖项写入 requirements.txt。同时请注意，确保你本地的 Streamlit 版本与托管时的一致。要实现无缝使用，请参考 [Spaces 配置参考](https://huggingface.co/docs/hub/spaces-config-reference)。

[![spaces-streamlit](https://huggingface.co/blog/assets/29_streamlit-spaces/streamlit.gif)](https://huggingface.co/blog/assets/29_streamlit-spaces/streamlit.gif)

有非常多的组件和[包](https://streamlit.io/components)可以用来展示你的模型、数据集和可视化。你可以[从这里](https://huggingface.co/spaces)开始上手。
