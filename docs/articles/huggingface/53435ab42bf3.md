*AI 驱动的 NPC*（非玩家角色）是 LLM 用于游戏带来的**最重要的突破之一**。

LLM（大语言模型）让设计「智能」游戏角色成为可能：它们**能与玩家进行逼真的对话、执行复杂动作并听从指令，显著提升玩家体验**。AI 驱动的 NPC 相对基于规则和启发式的系统是一次巨大进步。

今天，我们很高兴推出 **NPC-Playground**——一个由 [Cubzh](https://github.com/cubzh/cubzh) 与 [Gigax](https://github.com/GigaxGames/gigax) 联合制作的 demo，你可以在其中**与 LLM 驱动的 NPC 互动**，亲眼看看未来的模样！

你可以直接在浏览器里玩这个 demo 👉 [这里](https://huggingface.co/spaces/cubzh/ai-npcs)

在这个 3D demo 中，你可以**与 NPC 互动，只用几行 Lua 脚本就能教会它们新技能！**

## 技术栈

为此，两个团队使用了三个主要工具：

- [Cubzh](https://github.com/cubzh/cubzh)：跨平台 UGC（用户生成内容）游戏引擎。
- [Gigax](https://github.com/GigaxGames/gigax)：智能 NPC 引擎。
- [Hugging Face Spaces](https://huggingface.co/spaces)：托管并迭代游戏概念的最方便的在线开源环境。

## Cubzh 是什么？

[Cubzh](https://github.com/cubzh/cubzh) 是一个跨平台 UGC 游戏引擎，目标是提供 Roblox 的开源替代品。

它提供**丰富的游戏环境，用户可以创建自己的游戏体验并与朋友一起玩**。

在 Cubzh 里，你可以：

- **创建自己的世界物品和角色形象**。
- 借助**社区制作的体素物品**（库中已有 2.5 万+）和**开源 Lua 模块**快速构建。
- **用简单而强大的 Lua 脚本 API 编写游戏**。

Cubzh 处于公开 Alpha 阶段。你可以通过 [Steam](https://store.steampowered.com/app/1386770/Cubzh_Open_Alpha/)、[Epic Game Store](https://store.epicgames.com/en-US/p/cubzh-3cc767) 在桌面端免费下载并游玩，或通过 [Apple App Store](https://apps.apple.com/th/app/cubzh/id1478257849)、[Google Play Store](https://play.google.com/store/apps/details?id=com.voxowl.pcubes.android&hl=en&gl=US&pli=1) 在移动端游玩，甚至直接在[浏览器](https://app.cu.bzh/)里玩。

在这个 demo 中，Cubzh 作为**游戏引擎**直接运行在 Hugging Face Space 内。你可以轻松克隆它，实验自定义脚本与 NPC 人设！

## Gigax 是什么？

[Gigax](https://github.com/GigaxGames/gigax) 是游戏开发者用来**规模化运行 LLM 驱动 NPC** 的平台。

Gigax 为 NPC 交互微调（训练）了大语言模型，**采用「function calling（函数调用）」原则**。

从输入/输出流的角度理解更容易：

- 在**输入**侧，模型读取一段 3D 场景的[文本描述（prompt）](https://github.com/GigaxGames/gigax/blob/main/gigax/prompt.py)，外加近期事件的描述以及 NPC 可用动作的列表（例如 `<say>`、`<jump>`、`<attack>` 等）。
- 模型随后**输出**这些动作之一，使用引用场景中 3D 实体的参数，例如 `say NPC1 "Hello, Captain!"`。

Gigax 已经**开源了他们的技术栈！** 你可以在 GitHub 上克隆他们的[推理栈](https://github.com/GigaxGames/gigax)。

本 demo 中，他们的模型托管在云端，但你也可以[自己在 🤗 Hub 上下载](https://huggingface.co/Gigax)：

- [Phi-3 微调模型](https://huggingface.co/Gigax/NPC-LLM-3_8B)
- [Mistral-7B 微调模型](https://huggingface.co/Gigax/NPC-LLM-7B)
