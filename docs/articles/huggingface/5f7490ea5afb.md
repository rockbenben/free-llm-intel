去年 7 月，我们[宣布](https://huggingface.co/blog/intel) Intel 与 Hugging Face 将合作构建既先进又好用的 Transformer 模型硬件加速工具。今天，我们很高兴地宣布在 [Optimum Intel](https://github.com/huggingface/optimum-intel) 中加入了 Intel [OpenVINO](https://docs.openvino.ai/latest/index.html)。现在你可以用 OpenVINO Runtime 在各种 Intel 处理器上轻松推理（[完整支持设备列表见这里](https://docs.openvino.ai/latest/openvino_docs_OV_UG_supported_plugins_Supported_Devices.html)），模型既可以托管在 Hugging Face hub 上，也可以在本地。你还可以用 OpenVINO 神经网络压缩框架（[NNCF](https://github.com/openvinotoolkit/nncf)）量化模型，在几分钟内近乎无损地缩小模型体积、降低预测延迟。

首个发布版基于 OpenVINO 2022.2，通过我们的 [`OVModels`](https://huggingface.co/docs/optimum/intel/inference) 为大量 PyTorch 模型提供推理能力。训练后静态量化与量化感知训练可用于许多编码器模型（BERT、DistilBERT 等），即将发布的 OpenVINO 版本会支持更多编码器模型。目前 Encoder-Decoder 模型的量化尚未启用，但随下一个 OpenVINO 版本的集成，这一限制应该会解除。

让我们演示如何几分钟内上手！

## 用 Optimum Intel 与 OpenVINO 量化视觉 Transformer

在这个例子中，我们对一个在 [food101](https://huggingface.co/datasets/food101) 数据集上为图像分类微调过的 Vision Transformer（ViT）[模型](https://huggingface.co/juliensimon/autotrain-food101-1471154050)执行训练后静态量化。

量化是一种通过降低模型参数位宽来减少内存与计算需求的过程。减少位数意味着所得模型在推理时占用更少内存，而且得益于整数运算，矩阵乘法等操作也能更快。

首先，创建一个虚拟环境并安装所有依赖。

```
virtualenv openvino
source openvino/bin/activate
pip install pip --upgrade
pip install optimum[openvino,nncf] torchvision evaluate
```

接着，进入 Python 环境，导入相应模块，下载原始模型及其 processor。

```
from transformers import AutoImageProcessor, AutoModelForImageClassification

model_id = "juliensimon/autotrain-food101-1471154050"
model = AutoModelForImageClassification.from_pretrained(model_id)
processor = AutoImageProcessor.from_pretrained(model_id)
```

训练后静态量化需要一个校准（calibration）步骤：把数据喂进网络以计算量化后的激活参数。这里我们从原始数据集取 300 个样本构建校准数据集。

```
from optimum.intel.openvino import OVQuantizer

quantizer = OVQuantizer.from_pretrained(model)
calibration_dataset = quantizer.get_calibration_dataset(
    "food101",
    num_samples=300,
    dataset_split="train",
)
```

和图像数据集的惯例一样，我们需要应用与训练时相同的图像变换。这里使用 processor 中定义的预处理。我们还定义一个数据整理（collate）函数，向模型喂入格式正确的张量 batch。

```
import torch
from torchvision.transforms import (
    CenterCrop,
    Compose,
    Normalize,
    Resize,
    ToTensor,
)

normalize = Normalize(mean=processor.image_mean, std=processor.image_std)
size = processor.size["height"]
_val_transforms = Compose(
    [
        Resize(size),
        CenterCrop(size),
        ToTensor(),
        normalize,
    ]
)
def val_transforms(example_batch):
    example_batch["pixel_values"] = [_val_transforms(pil_img.convert("RGB")) for pil_img in example_batch["image"]]
    return example_batch

calibration_dataset.set_transform(val_transforms)

def collate_fn(examples):
    pixel_values = torch.stack([example["pixel_values"] for example in examples])
    labels = torch.tensor([example["label"] for example in examples])
    return {"pixel_values": pixel_values, "labels": labels}
```

第一次尝试我们使用量化的默认配置。你也可以指定校准步骤使用的样本数，默认是 300。

```
from optimum.intel.openvino import OVConfig

quantization_config = OVConfig()
quantization_config.compression["initializer"]["range"]["num_init_samples"] = 300
```

现在可以量化模型了。`OVQuantizer.quantize()` 方法会量化模型并导出为 OpenVINO 格式。所得图（graph）用两个文件表示：一个描述网络拓扑的 XML 文件和一个描述权重的二进制文件。所得模型可以在任何目标 Intel® 设备上运行。

```
save_dir = "quantized_model"

# Apply static quantization and export the resulting quantized model to OpenVINO IR format
quantizer.quantize(
    quantization_config=quantization_config,
    calibration_dataset=calibration_dataset,
    data_collator=collate_fn,
    remove_unused_columns=False,
    save_directory=save_dir,
)
processor.save_pretrained(save_dir)
```

一两分钟后，模型量化完成。随后我们可以用 [`OVModelForXxx`](https://huggingface.co/docs/optimum/intel/inference) 系列类轻松加载它——它们是 `transformers` 库中 [`AutoModelForXxx`](https://huggingface.co/docs/transformers/main/en/autoclass_tutorial#automodel) 类的对应版本。同理，我们可以创建 [pipelines](https://huggingface.co/docs/transformers/main/en/main_classes/pipelines)，用 [OpenVINO Runtime](https://docs.openvino.ai/latest/openvino_docs_OV_UG_OV_Runtime_User_Guide.html) 运行推理。

```
from transformers import pipeline
from optimum.intel.openvino import OVModelForImageClassification

ov_model = OVModelForImageClassification.from_pretrained(save_dir)
ov_pipe = pipeline("image-classification", model=ov_model, image_processor=processor)
outputs = ov_pipe("http://farm2.staticflickr.com/1375/1394861946_171ea43524_z.jpg")
print(outputs)
```

为验证量化没有损害准确率，我们执行评估步骤，比较原始模型与量化版本的准确率。两个模型都在数据集子集上评估（只取评估集的 20%）。我们观察到几乎没有精度损失，两个模型的准确率均为 **87.6**。

```
from datasets import load_dataset
from evaluate import evaluator

# We run the evaluation step on 20% of the evaluation dataset
eval_dataset = load_dataset("food101", split="validation").select(range(5050))
task_evaluator = evaluator("image-classification")

ov_eval_results = task_evaluator.compute(
    model_or_pipeline=ov_pipe,
    data=eval_dataset,
    metric="accuracy",
    label_mapping=ov_pipe.model.config.label2id,
)

trfs_pipe = pipeline("image-classification", model=model, image_processor=processor)
trfs_eval_results = task_evaluator.compute(
    model_or_pipeline=trfs_pipe,
    data=eval_dataset,
    metric="accuracy",
    label_mapping=trfs_pipe.model.config.label2id,
)
print(trfs_eval_results, ov_eval_results)
```

看看量化后的模型：内存体积从 344MB 降到 90MB，缩小 **3.8 倍**。对 5050 张图像预测做一个快速基准，我们还注意到延迟加速 **2.4 倍**——每个样本从 98ms 降到 41ms。就几行代码，相当不错！

⚠️ 需要特别提醒：模型在第一次推理前才编译，这会抬高首推延迟。所以在你自己做基准之前，务必先至少做一次预测预热模型。

所得[模型](https://huggingface.co/echarlaix/vit-food101-int8)已托管在 Hugging Face hub 上。加载它只需：

```
from optimum.intel.openvino import OVModelForImageClassification

ov_model = OVModelForImageClassification.from_pretrained("echarlaix/vit-food101-int8")
```
