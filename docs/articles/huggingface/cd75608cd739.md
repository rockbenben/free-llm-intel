# 将顶点着色网格转换为纹理网格

作者：Dylan Ebert（dylanebert）

把顶点着色的网格转换为带 UV 展开、带纹理的网格。

## 引言

顶点颜色是一种直接把颜色信息加到网格顶点上的简单方式。[InstantMesh](https://huggingface.co/spaces/TencentARC/InstantMesh) 这类生成式 3D 模型产出网格时常常就是这样。但多数应用更想要的是带 UV 展开、带纹理的网格。

本教程演示一个快速方案：把顶点着色网格转换成 UV 展开的纹理网格。想快速出结果，看[简版](https://huggingface.co/blog/vertex-colored-to-textured-mesh#the-short-version)；想深入理解，看[详版](https://huggingface.co/blog/vertex-colored-to-textured-mesh#the-long-version)。

## 简版

安装 [InstantTexture](https://github.com/dylanebert/InstantTexture) 库，转换就很轻松。这是我们写的一个小库，实现了下面[详版](https://huggingface.co/blog/vertex-colored-to-textured-mesh#the-long-version)描述的步骤。

```
pip install git+https://github.com/dylanebert/InstantTexture
```

### 用法

下面的代码把一个顶点着色的 `.obj` 网格转换为 UV 展开、带纹理的 `.glb` 网格，并保存为 `output.glb`。

```
from instant_texture import Converter

input_mesh_path = "https://raw.githubusercontent.com/dylanebert/InstantTexture/refs/heads/main/examples/chair.obj"

converter = Converter()
converter.convert(input_mesh_path)
```

来看看输出的网格。

```
import trimesh

mesh = trimesh.load("output.glb")
mesh.show()
```

就这么简单！

想看详细演练，请继续往下读。

## 详版

安装以下依赖：

- **trimesh**：加载与保存网格数据
- **xatlas**：生成 UV 图
- **Pillow**：图像处理
- **opencv-python**：图像处理
- **httpx**：下载输入网格

```
pip install numpy trimesh xatlas opencv-python pillow httpx
```

导入依赖。

```
import cv2
import numpy as np
import trimesh
import xatlas
from PIL import Image, ImageFilter
```

加载顶点着色的输入网格。它应是位于 `input_mesh_path` 的 `.obj` 文件。

如果是本地文件，用 `trimesh.load()` 而不是 `trimesh.load_remote()`。

```
mesh = trimesh.load_remote(input_mesh_path)
mesh.show()
```

访问网格的顶点颜色。

如果这一步失败，请确认网格是带顶点颜色的合法 `.obj` 文件。

```
vertex_colors = mesh.visual.vertex_colors
```

用 xatlas 生成 UV 图。

这是整个流程中最耗时的部分。

```
vmapping, indices, uvs = xatlas.parametrize(mesh.vertices, mesh.faces)
```

把顶点和顶点颜色重映射到 UV 图上。

```
vertices = mesh.vertices[vmapping]
vertex_colors = vertex_colors[vmapping]

mesh.vertices = vertices
mesh.faces = indices
```

定义想要的纹理尺寸。

构造一个纹理缓冲区，按 `upscale_factor` 放大，以得到更高质量的纹理。

```
texture_size = 1024

upscale_factor = 2
buffer_size = texture_size * upscale_factor

texture_buffer = np.zeros((buffer_size, buffer_size, 4), dtype=np.uint8)
```

用重心插值填充 UV 展开网格的纹理。

- **重心插值（Barycentric interpolation）**：计算三角形内点 `p` 的插值颜色——三角形由顶点 `v0`、`v1`、`v2` 定义，对应颜色为 `c0`、`c1`、`c2`。
- **点在三角形内判定（Point-in-Triangle test）**：判断点 `p` 是否落在由顶点 `v0`、`v1`、`v2` 定义的三角形内。
- **纹理填充循环**：遍历网格每个面。取出当前面的 UV 坐标（`uv0`、`uv1`、`uv2`）和颜色（`c0`、`c1`、`c2`）。把 UV 坐标转换为缓冲区坐标。确定三角形在纹理缓冲区上的包围盒。对包围盒内每个像素，用点在三角形内判定检查它是否在三角形内。若在，用重心插值算出颜色，并把颜色赋给纹理缓冲区对应的像素。

```
# Barycentric interpolation
def barycentric_interpolate(v0, v1, v2, c0, c1, c2, p):
    v0v1 = v1 - v0
    v0v2 = v2 - v0
    v0p = p - v0
    d00 = np.dot(v0v1, v0v1)
    d01 = np.dot(v0v1, v0v2)
    d11 = np.dot(v0v2, v0v2)
    d20 = np.dot(v0p, v0v1)
    d21 = np.dot(v0p, v0v2)
    denom = d00 * d11 - d01 * d01
    if abs(denom) < 1e-8:
        return (c0 + c1 + c2) / 3
    v = (d11 * d20 - d01 * d21) / denom
    w = (d00 * d21 - d01 * d20) / denom
    u = 1.0 - v - w
    u = np.clip(u, 0, 1)
    v = np.clip(v, 0, 1)
    w = np.clip(w, 0, 1)
    interpolate_color = u * c0 + v * c1 + w * c2
    return np.clip(interpolate_color, 0, 255)


# Point-in-Triangle test
def is_point_in_triangle(p, v0, v1, v2):
    def sign(p1, p2, p3):
        return (p1[0] - p3[0]) * (p2[1] - p3[1]) - (p2[0] - p3[0]) * (p1[1] - p3[1])

    d1 = sign(p, v0, v1)
    d2 = sign(p, v1, v2)
    d3 = sign(p, v2, v0)

    has_neg = (d1 < 0) or (d2 < 0) or (d3 < 0)
    has_pos = (d1 > 0) or (d2 > 0) or (d3 > 0)

    return not (has_neg and has_pos)

# Texture-filling loop
for face in mesh.faces:
    uv0, uv1, uv2 = uvs[face]
    c0, c1, c2 = vertex_colors[face]

    uv0 = (uv0 * (buffer_size - 1)).astype(int)
    uv1 = (uv1 * (buffer_size - 1)).astype(int)
    uv2 = (uv2 * (buffer_size - 1)).astype(int)

    min_x = max(int(np.floor(min(uv0[0], uv1[0], uv2[0]))), 0)
    max_x = min(int(np.ceil(max(uv0[0], uv1[0], uv2[0]))), buffer_size - 1)
    min_y = max(int(np.floor(min(uv0[1], uv1[1], uv2[1]))), 0)
    max_y = min(int(np.ceil(max(uv0[1], uv1[1], uv2[1]))), buffer_size - 1)

    for y in range(min_y, max_y + 1):
        for x in range(min_x, max_x + 1):
            p = np.array([x + 0.5, y + 0.5])
            if is_point_in_triangle(p, uv0, uv1, uv2):
                color = barycentric_interpolate(uv0, uv1, uv2, c0, c1, c2, p)
                texture_buffer[y, x] = np.clip(color, 0, 255).astype(
                    np.uint8
                )
```

先看看目前纹理的样子。

```
from IPython.display import display

image_texture = Image.fromarray(texture_buffer)
display(image_texture)
```

[![Texture with holes](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/vertex-colored-to-textured-mesh/tex_output_1.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/vertex-colored-to-textured-mesh/tex_output_1.png)

可以看到，纹理有很多空洞。

为了解决这个问题，我们组合 4 种技术：

- **修补（Inpainting）**：用周围像素的平均颜色填充空洞。
- **中值滤波（Median filter）**：用每个像素周围像素的中值颜色替换该像素，去除噪声。
- **高斯模糊（Gaussian blur）**：平滑纹理，消除残留噪声。
- **降采样（Downsample）**：用 LANCZOS 重采样缩小到 `texture_size`。

```
# Inpainting
image_bgra = texture_buffer.copy()
mask = (image_bgra[:, :, 3] == 0).astype(np.uint8) * 255
image_bgr = cv2.cvtColor(image_bgra, cv2.COLOR_BGRA2BGR)
inpainted_bgr = cv2.inpaint(
    image_bgr, mask, inpaintRadius=3, flags=cv2.INPAINT_TELEA
)
inpainted_bgra = cv2.cvtColor(inpainted_bgr, cv2.COLOR_BGR2BGRA)
texture_buffer = inpainted_bgra[::-1]
image_texture = Image.fromarray(texture_buffer)

# Median filter
image_texture = image_texture.filter(ImageFilter.MedianFilter(size=3))

# Gaussian blur
image_texture = image_texture.filter(ImageFilter.GaussianBlur(radius=1))

# Downsample
image_texture = image_texture.resize((texture_size, texture_size), Image.LANCZOS)

# Display the final texture
display(image_texture)
```

[![Texture without holes](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/vertex-colored-to-textured-mesh/tex_output_2.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/vertex-colored-to-textured-mesh/tex_output_2.png)

可以看到，纹理现在平滑多了，也没有空洞了。

用更高级的技术或手工纹理编辑还能做得更好。

最后，用生成的 UV 坐标和纹理构建一个新网格。

```
material = trimesh.visual.material.PBRMaterial(
    baseColorFactor=[1.0, 1.0, 1.0, 1.0],
    baseColorTexture=image_texture,
    metallicFactor=0.0,
    roughnessFactor=1.0,
)

visuals = trimesh.visual.TextureVisuals(uv=uvs, material=material)
mesh.visual = visuals
mesh.show()
```

[![Final mesh](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/vertex-colored-to-textured-mesh/mesh_output.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/vertex-colored-to-textured-mesh/mesh_output.png)

完成！网格已经 UV 展开并贴上纹理了。

本地运行时想导出，调用 `mesh.export("output.glb")` 即可。

## 局限

可以看到，网格仍有很多小瑕疵。

UV 图和纹理的质量也远达不到生产级网格的标准。

不过，如果你只是想要一个从顶点着色网格快速映射到 UV 展开网格的方案，这个方法可能对你有用。
