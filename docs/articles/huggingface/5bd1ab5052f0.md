学术研究中频繁涉及**研究发现（research discovery）**：寻找论文、代码、相关模型与数据集。这通常意味着在 [arXiv](https://arxiv.org/)、[GitHub](https://github.com/)、[Hugging Face](https://huggingface.co/) 等平台之间来回切换，手工拼接线索。

[Model Context Protocol（MCP）](https://huggingface.co/learn/mcp-course/unit0/introduction)是一个让 agentic 模型与外部工具和数据源通信的标准。对研究发现而言，这意味着 AI 可以通过自然语言请求使用研究工具，自动化平台切换与交叉引用。

[![Research Tracker MCP in action](https://huggingface.co/blog/assets/mcp-for-research/demo.gif)](https://huggingface.co/blog/assets/mcp-for-research/demo.gif)

## 研究发现：三层抽象

与软件开发类似，研究发现可以按照抽象层次来划分。

### 1. 手工研究

在抽象层级的最底层，研究者手动搜索、手工交叉引用。

```
# Typical workflow:
1. Find paper on arXiv
2. Search GitHub for implementations
3. Check Hugging Face for models/datasets
4. Cross-reference authors and citations
5. Organize findings manually
```

当需要追踪多条研究线索或做系统性文献综述时，这种手工方式会变得低效。跨平台搜索、提取元数据、交叉引用信息的重复性质，天然地导向通过脚本实现自动化。

### 2. 脚本工具

Python 脚本通过处理网络请求、解析响应、整理结果，自动化研究发现。

```
# research_tracker.py
def gather_research_info(paper_url):
    paper_data = scrape_arxiv(paper_url)
    github_repos = search_github(paper_data['title'])
    hf_models = search_huggingface(paper_data['authors'])
    return consolidate_results(paper_data, github_repos, hf_models)

# Run for each paper you want to investigate
results = gather_research_info("https://arxiv.org/abs/2103.00020")
```

[research tracker](https://huggingface.co/spaces/dylanebert/research-tracker) 就是用这类脚本搭建起来的系统化研究发现示例。

脚本比手工研究更快，但常因 API 变动、速率限制或解析错误而无法自动收集数据。没有人工监督，脚本可能漏掉相关结果或返回不完整的信息。

### 3. MCP 集成

MCP 让这些同样的 Python 工具通过自然语言对 AI 系统开放。

```
# Example research directive
Find recent transformer architecture papers published in the last 6 months:
- Must have available implementation code
- Focus on papers with pretrained models
- Include performance benchmarks when available
```

AI 会编排多个工具、补全信息缺口、并对结果进行推理：

```
# AI workflow:
# 1. Use research tracker tools
# 2. Search for missing information
# 3. Cross-reference with other MCP servers
# 4. Evaluate relevance to research goals

user: "Find all relevant information (code, models, etc.) on this paper: https://huggingface.co/papers/2010.11929"
ai: # Combines multiple tools to gather complete information
```

可以把它看作脚本之上的又一层抽象，其中「编程语言」就是自然语言。这遵循 [Software 3.0 类比](https://youtu.be/LCEmiRjPEtQ?si=J7elM86eW9XCkMFj)：自然语言的研究指令就是软件实现本身。

它带有与脚本相同的注意事项：

- 比手工研究快，但没有人类引导时容易出错
- 质量取决于实现
- 理解更底层（手工与脚本层）会带来更好的实现

## 安装与使用

### 快速安装

添加 Research Tracker MCP 最简单的方式是通过 [Hugging Face MCP 设置](https://huggingface.co/settings/mcp)：

- 访问 [huggingface.co/settings/mcp](https://huggingface.co/settings/mcp)
- 在可用工具中搜索 "research-tracker-mcp"
- 点击把它加入你的工具
- 按照为你的具体客户端（Claude Desktop、Cursor、Claude Code、VS Code 等）提供的设置说明操作

这套工作流利用 Hugging Face MCP server——把 Hugging Face Space 用作 MCP 工具的标准方式。设置页提供的客户端专属配置是自动生成的，且永远是最新的。
