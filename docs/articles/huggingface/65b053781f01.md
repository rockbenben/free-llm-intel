# Arc 虚拟细胞挑战赛：入门指南

[Arc Institute](https://arcinstitute.org/) 最近公布了 [Virtual Cell Challenge](https://virtualcellchallenge.org/)（虚拟细胞挑战赛）。参赛者需要训练一个模型，能够预测在（部分）未见过的细胞类型中沉默某个基因的效果——他们称之为*上下文泛化（context generalization）*任务。对于生物学背景很少甚至没有的 ML 工程师来说，那些术语和必备的背景知识可能相当吓人。为了鼓励大家参与，我们把挑战赛用更适合其他领域工程师的形式重新梳理一遍。

> 目标：训练一个模型，预测用 CRISPR 沉默某个基因对细胞的影响。

在原子世界里做实验是昂贵、费力且容易出错的。如果我们能不用碰一个培养皿就测试上千种候选药物呢？这就是虚拟细胞挑战的目标——做一个模型（很可能是神经网络），准确模拟当我们改变某个参数时细胞会发生什么。既然加快反馈循环往往是推进的最佳方式，能精确做到这一点的模型会有重大意义。

要训练这个神经网络，我们需要数据。为这次挑战赛，Arc 精心整理了一个约 30 万条单细胞 RNA 测序（single-cell RNA sequencing） profiles 的数据集。在继续之前，值得先回顾一下[中心法则（Central Dogma）](https://www.khanacademy.org/science/biology/gene-expression-central-dogma/central-dogma-transcription/v/rna-transcription-and-translation)。本文建立在此基础上，提供你参加挑战赛所需的最小生物学知识。

## 训练数据

训练集由一个稀疏矩阵和一些相关元数据组成。更具体地说，我们有 22 万个细胞，每个细胞对应一个[转录组（transcriptome）](https://en.wikipedia.org/wiki/Transcriptome)。这个转录组是一个稀疏行向量，每个元素是**RNA 分子（转录本）的原始计数**，对应列所代表的基因。22 万个细胞中约 3.8 万个是*未扰动的（unperturbed）*，即没有用 CRISPR 沉默任何基因。这些对照细胞非常关键，我们马上就会看到。

要更具体地理解数据集，我们选一个基因 TMSB4X（数据集中被沉默最频繁的基因），比较一个对照细胞和一个扰动细胞检测到的 RNA 分子数。

![](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/virtual-cell-challenge/TMSB4X.png)

可以看到，被沉默了 TMSB4X 的细胞，其转录本数量相比对照细胞大幅减少。

### 对挑战的建模

敏锐的同学可能会问：为什么不直接在沉默基因前后测量 RNA 分子计数——我们到底为什么需要对照细胞？不幸的是，**读取转录组会杀死细胞**，这是个类似[观测者效应](https://en.wikipedia.org/wiki/Observer_effect_(physics))的问题。

无法在扰动前后测量同一个细胞的状态，带来了很多麻烦：我们被迫使用一群**基线（basal）**（即对照、未扰动）细胞作为参照点。对照细胞和扰动细胞即便在扰动之前也并非完全同质。这意味着我们必须把真正的信号——扰动——从异质性带来的噪声中分离出来。

更形式化地，我们可以把扰动细胞的观测基因表达建模为：

$\hat{X}_p \sim \hat{T}_p(\mathcal{D}_{\text{basal}}) + H(\mathcal{D}_{\text{basal}}) + \varepsilon, \quad \varepsilon \sim P_\varepsilon$

其中：

- $\hat{X}_p$：在扰动 p 下测得的基因表达观测量
- $\mathcal{D}_{\text{basal}}$：未扰动的基线细胞群体的分布。
- $\hat{T}_p(\mathcal{D}_{\text{basal}})$：扰动 p 对群体造成的真实效应。
- $H(\mathcal{D}_{\text{basal}})$：基线群体的生物异质性。
- $\varepsilon$：实验特有的技术噪声，假设与未扰动细胞状态和 $\mathcal{D}_{\text{basal}}$ 独立。

# STATE：Arc 给出的基线

在虚拟细胞挑战赛之前，Arc 发布了 [STATE](https://arcinstitute.org/manuscripts/State)——他们自己用一对基于 transformer 的模型解决该挑战的尝试。这为参赛者提供了一个强基线起点，我们详细拆解一下。

STATE 由两个模型组成：**状态转移模型（State Transition Model，ST）**和**状态嵌入模型（State Embedding Model，SE）**。SE 旨在生成细胞的丰富语义嵌入，以提升跨细胞类型的泛化。ST 则是"细胞模拟器"：输入对照细胞的转录组（或 SE 产生的细胞嵌入），加上一个表示目标基因扰动的一热编码向量，输出扰动后的转录组。

## 状态转移模型（ST）

![](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/virtual-cell-challenge/ST.png)

状态转移模型是一个相对简单的 transformer，采用 Llama 主干，处理以下输入：

- 一组协变量匹配的基线细胞转录组（或 SE 嵌入）。
- 一组一热向量，表示每个细胞对应的基因扰动。

使用协变量匹配的对照细胞与配对的目标细胞，应能帮助模型辨别我们目标扰动的真实效应。对照集张量和扰动张量分别经过独立的编码器——其实就是带 GELU 激活的 4 层 MLP。如果直接在基因表达空间工作（即生成完整转录组），它们再把输出经过一个学习到的解码器。

ST 用[最大均值差异（Maximum Mean Discrepancy）](https://en.wikipedia.org/wiki/Kernel_embedding_of_distributions)训练。简单说，模型学习最小化两个概率分布之间的差异。

## 状态嵌入模型（SE）

![](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/virtual-cell-challenge/SE.png)

状态嵌入模型是一个 BERT 风格的自编码器。要更深入理解它，先绕一点路，补一些生物学背景。

### 生物学小插曲

![](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/virtual-cell-challenge/alt_splicing.gif)

基因由*外显子（exons，编码蛋白的部分）*和*内含子（introns，不编码蛋白的部分）*组成。DNA 首先被*转录*成 pre-mRNA，如上图所示。然后细胞执行[可变剪接（Alternative Splicing）](https://en.wikipedia.org/wiki/Alternative_splicing)。基本就是"挑挑拣拣外显子，切掉所有内含子"。你可以把基因想象成一张做桌子的宜家说明书：如果少装一些零件，还能做出三条腿的桌子，甚至费点劲做成一个古怪的书架。这些不同的成品对应**蛋白亚型（protein isoforms）**——由同一个基因编码的不同蛋白。

### 回到模型

有了这个基础理解，我们就可以看 SE 模型怎么工作。记住，SE 的核心目标是创建**有意义的细胞嵌入**。为此，我们得先创建有意义的基因嵌入。

要生成单个基因嵌入，我们首先获取该基因编码的所有不同蛋白亚型的氨基酸序列（例如 TMSB4X 是 `SDKPDMAEI...`）。然后把这些序列输入 [ESM2](https://huggingface.co/facebook/esm2_t48_15B_UR50D)——FAIR 出品的 15B 参数蛋白语言模型。ESM 会为*每个氨基酸*产生一个嵌入，我们对它们做平均池化，得到一个"转录本"（即蛋白亚型）嵌入。

拿到所有蛋白亚型嵌入后，再对它们做平均池化就得到基因嵌入。然后，我们用一个学习到的编码器把基因嵌入投影到模型的维度：

$\tilde{g}_j = \text{SiLU}(\text{LayerNorm}(g_j \mathbf{W}_g + \mathbf{b}_g))$

现在我们得到了基因嵌入，但真正想要的是*细胞嵌入*。为此，Arc 把每个细胞表示为按 [log fold 表达水平](https://en.wikipedia.org/wiki/Fold_change#Fold_changes_in_genomics_and_bioinformatics)排名的前 2048 个基因。

然后我们用这 2048 个基因嵌入构造一个"细胞句子"：

$\tilde{\mathbf{c}}^{(i)} = \left[\mathbf{z}_{\text{cls}}, \tilde{\mathbf{g}}_1^{(i)}, \tilde{\mathbf{g}}_2^{(i)}, \ldots, \tilde{\mathbf{g}}_L^{(i)}, \mathbf{z}_{\text{ds}}\right] \in \mathbb{R}^{(L+2) \times h}$

我们在句子里加了一个 `[CLS]` token 和一个 `[DS]` token。`[CLS]` token 最终充当我们的"细胞嵌入"（非常 BERT 的做法），`[DS]` token 用于"解耦数据集特有效应"。虽然基因按 log fold 表达水平排序，Arc 还以类似于位置嵌入的方式把转录组纳入，进一步强调每个基因表达的量级。通过一个奇特的["软分箱"算法](https://github.com/ArcInstitute/state/blob/main/src/state/emb/nn/model.py#L374)和 2 个 MLP，他们构造出"表达编码"，再逐一加到每个基因嵌入上。这应当会根据基因在转录组中的表达强度，调节每个基因嵌入的量级。

训练时，他们为每个细胞掩码 1280 个基因，让模型预测它们。这 1280 个基因的选择使其表达强度范围尽量宽。对偏好图形的同学，下图演示了细胞句子的构造。

# 评估

理解你的提交将如何被评估，是成功的关键。Arc 选的 3 个评估指标是**扰动判别（Perturbation Discrimination）**、**差异表达（Differential Expression）**和**平均绝对误差（Mean Average Error）**。平均绝对误差简单直白、顾名思义，我们的分析中就略过它了。

## 扰动判别

![](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/virtual-cell-challenge/pert_disc.png)

扰动判别旨在评估你的模型能在多大程度上揭示扰动之间的*相对差异*。做法是：对测试集中所有实测的扰动转录组（我们要预测的真实值 $y_t$，以及所有其他扰动转录组 $y_p$），计算它们与我们的预测转录组 $\hat{y}_t$ 之间的曼哈顿距离。然后把真实值在所有转录组中的位次归一化：

$r_t = \sum_{p \neq t} \mathbf{1}\{d(\hat{y}_t, y_p) < d(\hat{y}_t, y_t)\}$

之后除以转录组总数做归一化：

$\text{PDisc}_t = \frac{r_t}{T}$

0 表示完美命中。你的预测的总分是所有 $\text{PDisc}_t$ 取均值。再归一化为：

$\text{PDiscNorm} = 1 - 2\text{PDisc}$

乘 2 是因为随机预测的话，大约一半结果会更近、一半会更远。

## 差异表达

差异表达旨在评估：真正受影响的基因中，你正确识别出多少比例被显著影响。首先，对每个基因用[带并列值修正的 Wilcoxon 秩和检验](https://en.wikipedia.org/wiki/Mann%E2%80%93Whitney_U_test)计算 p 值。对预测的扰动分布和真实扰动分布都这么做。

然后应用 [Benjamini-Hochberg 程序](https://en.wikipedia.org/wiki/False_discovery_rate#Benjamini%E2%80%93Hochberg_procedure)——基本上是些统计学手段来调整 p 值，因为面对 20,000 个基因、0.05 的 p 值阈值，你会预期 1,000 个假阳性。我们记预测的差异表达基因集为 $G_{p,pred}$，真实的差异表达基因集为 $G_{p,true}$。

如果我们的集合大小小于真实集合大小，就取两个集合的交集，除以真实的差异表达基因数：

$DE_p = \frac{G_{p,pred} \cap G_{p,true}}{n_{p,true}}$

如果我们的集合大小大于真实集合大小，就挑选我们预测差异表达最显著的那个子集（即"最有信心"的预测，记作 $\tilde{G}_{p,pred}$），取它与真实集合的交集，再除以真实数量。

$DE_p = \frac{\tilde{G}_{p,pred} \cap G_{p,true}}{n_{p,true}}$

对所有预测的扰动做这个计算并取均值，得到最终分数。

## 结语

如果这次挑战赛勾起了你的兴趣，该如何开始？幸运的是，Arc 提供了一个 [Colab notebook](https://colab.research.google.com/drive/1QKOtYP7bMpdgDJEipDxaJqOchv7oQ-_l?usp=sharing)，完整讲解训练他们的 STATE 模型的全过程。此外，STATE 很快就会进入 `transformers`，届时使用他们的预训练模型将简单到只需：

```
import torch
from transformers import StateEmbeddingModel

model_name = "arcinstitute/SE-600M"
model = StateEmbeddingModel.from_pretrained(model_name)

input_ids = torch.randn((1, 1, 5120), dtype=torch.float32)
mask = torch.ones((1, 1, 5120), dtype=torch.bool)
mask[:, :, 2560:] = False 
outputs = model(input_ids, mask)
```
