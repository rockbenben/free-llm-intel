## 引言

生成式 AI 已成为游戏开发美术工作流中不可或缺的一部分。但正如我在[ earlier post（早前文章）](https://huggingface.co/blog/ml-for-games-3)中所详述的，text-to-3D（文本生成 3D）在实用性上仍落后于 2D。这一局面正在改变。今天，我们将重新审视 3D 资产生成的实用工作流，并一步步地看在 PS1 风格的 3D 工作流中整合生成式 AI。

为什么选 PS1 风格？因为它对当前 text-to-3D 模型的低保真度宽容得多，能让我们以尽可能少的精力从文本得到可用的 3D 资产。

### 前置要求

本教程假设你具备 Blender 的基础知识，以及材质、UV 映射等 3D 概念。

## 第 1 步：生成一个 3D 模型

首先访问 Shap-E Hugging Face Space（[这里](https://huggingface.co/spaces/hysts/Shap-E)），或在页面下方查看。该 Space 使用开源的 [Shap-E 模型](https://github.com/openai/shap-e)——OpenAI 最新的用文本生成 3D 模型的扩散模型。

输入提示词「Dilapidated Shack」（破败的小屋），点击「Generate」。对生成的模型满意后，下载它用于下一步。

## 第 2 步：导入模型并减面（Decimate）

接下来，打开 [Blender](https://www.blender.org/download/)（3.1 或更高版本），依次进入 File -> Import -> GLTF 2.0，导入你下载的文件。你可能会注意到这个模型的多边形数量远超许多实际应用（比如游戏）的推荐值。

要降低多边形数量，选中模型，进入 Modifiers，选择「Decimate」修改器，把 ratio 调到一个较小的数值（比如 0.02）。这大概*不会*好看。不过在本教程中，我们就是要拥抱这种低保真。

## 第 3 步：安装 Dream Textures

要为模型添加贴图，我们使用 [Dream Textures](https://github.com/carson-katri/dream-textures)——一个 Blender 的 stable diffusion 贴图生成器。按照[官方仓库](https://github.com/carson-katri/dream-textures)的说明下载并安装该插件。

安装并启用后，打开插件首选项，搜索并下载 [texture-diffusion](https://huggingface.co/dream-textures/texture-diffusion) 模型。

## 第 4 步：生成一张贴图

我们来生成一张自定义贴图。在 Blender 中打开 UV Editor，按「N」打开属性菜单，点击「Dream」标签页并选择 texture-diffusion 模型。把 prompt 设为「texture」，seamless 设为「both」（两者），确保生成的图像是无接缝贴图。

在「subject」下输入你想要的贴图内容，比如「Wood Wall」（木墙），然后点击「Generate」。对结果满意后，命名并保存。

要应用贴图，选中模型并进入「Material」，添加一个新材质，在「base color」处点击圆点并选择「Image Texture」，最后选中你刚生成的贴贴图。

## 第 5 步：UV 映射

到了 UV 映射环节，它会把我们的 2D 贴图包裹到 3D 模型上。选中模型并按「Tab」进入 Edit Mode，然后按「U」展开模型并选择「Smart UV Project」。

要预览带贴图的模型，切换到渲染视图（按住「Z」并选择「Rendered」）。你可以放大 UV 图，让它在模型上无缝平铺。记住，我们追求的是复古 PS1 风格，所以别做得太精细。

## 第 6 步：导出模型

对模型满意后，就该导出了。依次进入 File -> Export -> FBX，大功告成！你得到了一个可用的 3D 资产。

## 第 7 步：导入 Unity

最后，来看看我们的模型实际运行的效果。把它导入 [Unity](https://unity.com/download) 或你选择的游戏引擎。为还原怀旧的 PS1 美感，我做了自定义的顶点光照着色（vertex-lit shading）、关闭阴影、加大量雾效，以及带故障感的后期处理。关于复刻 PS1 美学的更多内容可以阅读[这里](https://www.david-colson.com/2021/11/30/ps1-style-renderer.html)。

就这样——我们低保真、带贴图的 3D 模型出现在虚拟环境里了！

## 结论

以上就是用生成式 AI 工作流创建实用 3D 资产的完整流程。虽然结果是低保真的，但潜力巨大：只要投入足够精力，这个方法可以用来生成一个低保真风格的无限世界。而随着这些模型的进步，把这些技术迁移到高保真或写实风格也许会成为可能。
