[Sentence Transformers](https://sbert.net/) 是一个用于使用和训练嵌入模型的 Python 库，面向检索增强生成、语义搜索、语义文本相似度、改写挖掘等广泛应用。在这篇博客里，我会展示如何用它微调 Sentence Transformer 模型，以提升它们在特定任务上的表现。你也可以用这个方法从零训练新的 Sentence Transformer 模型。

微调 Sentence Transformers 涉及若干组件，包括数据集、损失函数、训练参数、评估器以及 Trainer 本身。我会逐一详细讲解这些组件，并给出用它们训练高效模型的示例。

## 为什么要微调？

微调 Sentence Transformer 模型能显著提升它们在特定任务上的表现。这是因为每个任务都需要一种独特的相似度概念。以两条新闻标题为例：

- "Apple launches the new iPad"
- "NVIDIA is gearing up for the next GPU generation"

根据用例，我们可能希望给这些文本相似或不同的嵌入。例如，一个新闻分类模型可能把这两个文本视为相似，因为它们同属科技类别。而另一方面，一个语义文本相似度或检索模型则应把它们视为不同，因为它们含义各异。

## 训练组件

训练 Sentence Transformer 模型涉及以下组件：

- [**数据集**](https://huggingface.co/blog/train-sentence-transformers#dataset)：用于训练和评估的数据。
- [**损失函数**](https://huggingface.co/blog/train-sentence-transformers#loss-function)：一个量化模型表现并引导优化过程的函数。
- [**训练参数**](https://huggingface.co/blog/train-sentence-transformers#training-arguments)（可选）：影响训练表现以及追踪/调试的参数。
- [**评估器**](https://huggingface.co/blog/train-sentence-transformers#evaluator)（可选）：在训练前、中、后评估模型的工具。
- [**Trainer**](https://huggingface.co/blog/train-sentence-transformers#trainer)：把模型、数据集、损失函数及其他组件汇集到一起用于训练。

现在让我们逐个组件更深入地看。

## 数据集

[`SentenceTransformerTrainer`](https://sbert.net/docs/package_reference/sentence_transformer/SentenceTransformer.html#sentence_transformers.SentenceTransformer) 在训练和评估时使用 [`datasets.Dataset`](https://huggingface.co/docs/datasets/main/en/package_reference/main_classes#datasets.Dataset) 或 [`datasets.DatasetDict`](https://huggingface.co/docs/datasets/main/en/package_reference/main_classes#datasets.DatasetDict) 实例。你可以从 Hugging Face Datasets Hub 加载数据，或以 CSV、JSON、Parquet、Arrow 或 SQL 等各种格式使用本地数据。

注意：许多开箱即可配合 Sentence Transformers 使用的 Hugging Face 数据集被打上了 `sentence-transformers` 标签，便于你通过访问 [https://huggingface.co/datasets?other=sentence-transformers](https://huggingface.co/datasets?other=sentence-transformers) 轻松找到它们。我们强烈建议你浏览这些数据集，寻找可能对你任务有用的训练数据集。

要从 Hugging Face Hub 上的数据集加载数据，使用 [`load_dataset`](https://huggingface.co/docs/datasets/main/en/package_reference/loading_methods#datasets.load_dataset) 函数：

```
from datasets import load_dataset

train_dataset = load_dataset("sentence-transformers/all-nli", "pair-class", split="train")
eval_dataset = load_dataset("sentence-transformers/all-nli", "pair-class", split="dev")

print(train_dataset)
"""

    num_rows: 942069
})
"""
```

一些数据集，比如 [`sentence-transformers/all-nli`](https://huggingface.co/datasets/sentence-transformers/all-nli)，有多个格式不同的子集。你需要在指定数据集名时一并指定子集名。

### 本地数据（CSV、JSON、Parquet、Arrow、SQL）

如果你有常见文件格式的本地数据，也可以轻松用 [`load_dataset`](https://huggingface.co/docs/datasets/main/en/package_reference/loading_methods#datasets.load_dataset) 加载：

```
from datasets import load_dataset

dataset = load_dataset("csv", data_files="my_file.csv")
# or
dataset = load_dataset("json", data_files="my_file.json")
```

### 需要预处理的本地数据

如果你的本地数据需要预处理，你可以用 [`datasets.Dataset.from_dict`](https://huggingface.co/docs/datasets/main/en/package_reference/main_classes#datasets.Dataset.from_dict) 用一个列表字典来初始化数据集：

```
from datasets import Dataset

anchors = []
positives = []
# Open a file, perform preprocessing, filtering, cleaning, etc.
# and append to the lists

dataset = Dataset.from_dict({
    "anchor": anchors,
    "positive": positives,
})
```

字典里的每个键都成为结果数据集的一列。

### 数据集格式

确保你的数据集格式匹配你所选的 [损失函数](https://huggingface.co/blog/train-sentence-transformers#loss-function) 至关重要。这涉及检查两件事：

- 如果你的损失函数需要一个 *标签（Label）*（如 [损失概览](https://sbert.net/docs/sentence_transformer/loss_overview.html) 表中所示），你的数据集必须有一个名为 **"label"** 或 **"score"** 的列。
- 除 **"label"** 或 **"score"** 以外的所有列都被视为 *输入（Inputs）*（如 [损失概览](https://sbert.net/docs/sentence_transformer/loss_overview.html) 表中所示）。这些列的数量必须与你所选损失函数的有效输入数匹配。列名并不重要，**只有顺序重要**。

例如，如果你的损失函数接受 `(anchor, positive, negative)` 三元组，那么你的第一、第二、第三数据集列分别对应 `anchor`、`positive` 和 `negative`。这意味着你的第一列和第二列必须包含应嵌入得接近的文本，而你的第一列和第三列必须包含应嵌入得远离彼此的文本。这就是为什么数据集列顺序取决于你的损失函数。

考虑一个列为 `["text1", "text2", "label"]` 的数据集，其中 `"label"` 列包含浮点相似度分数。这个数据集可以用于 `CoSENTLoss`、`AnglELoss` 和 `CosineSimilarityLoss`，因为：

- 数据集有一个 "label" 列，这是这些损失函数所要求的。
- 数据集有 2 个非标签列，匹配这些损失函数所需的输入数。

如果你的数据集列顺序不对，用 [`Dataset.select_columns`](https://huggingface.co/docs/datasets/main/en/package_reference/main_classes#datasets.Dataset.select_columns) 重排。另外，用 [`Dataset.remove_columns`](https://huggingface.co/docs/datasets/main/en/package_reference/main_classes#datasets.Dataset.remove_columns) 移除任何多余列（例如 `sample_id`、`metadata`、`source`、`type`），否则它们会被当作输入。

## 损失函数

损失函数衡量模型在给定一批数据上的表现如何，并引导优化过程。损失函数的选择取决于你可用的数据和目标任务。完整选项列表见 [损失概览](https://sbert.net/docs/sentence_transformer/loss_overview.html)。

多数损失函数只需用你正在训练的 `SentenceTransformer` `model` 初始化：

```
from datasets import load_dataset
from sentence_transformers import SentenceTransformer
from sentence_transformers.losses import CoSENTLoss

# Load a model to train/finetune
model = SentenceTransformer("FacebookAI/xlm-roberta-base")

# Initialize the CoSENTLoss
# This loss requires pairs of text and a floating point similarity score as a label
loss = CoSENTLoss(model)

# Load an example training dataset that works with our loss function:
train_dataset = load_dataset("sentence-transformers/all-nli", "pair-score", split="train")
"""
Dataset({
    features: ['sentence1', 'sentence2', 'label'],
    num_rows: 942069
})
"""
```

## 训练参数

[`SentenceTransformersTrainingArguments`](https://sbert.net/docs/package_reference/sentence_transformer/training_args.html#sentencetransformertrainingarguments) 类允许你指定影响训练表现以及追踪/调试的参数。虽然是可选的，试验这些参数有助于提升训练效率、并对训练过程提供洞见。

在 Sentence Transformers 文档里，我列出了若干最有用的训练参数，我建议阅读 [训练概览 > 训练参数](https://sbert.net/docs/sentence_transformer/training_overview.html#training-arguments)。

以下是初始化 [`SentenceTransformersTrainingArguments`](https://sbert.net/docs/package_reference/sentence_transformer/training_args.html#sentencetransformertrainingarguments) 的示例：

```
from sentence_transformers.training_args import SentenceTransformerTrainingArguments

args = SentenceTransformerTrainingArguments(
    # Required parameter:
    output_dir="models/mpnet-base-all-nli-triplet",
    # Optional training parameters:
    num_train_epochs=1,
    per_device_train_batch_size=16,
    per_device_eval_batch_size=16,
    warmup_ratio=0.1,
    fp16=True,  # Set to False if your GPU can't handle FP16
    bf16=False,  # Set to True if your GPU supports BF16
    batch_sampler=BatchSamplers.NO_DUPLICATES,  # Losses using "in-batch negatives" benefit from no duplicates
    # Optional tracking/debugging parameters:
    eval_strategy="steps",
    eval_steps=100,
    save_strategy="steps",
    save_steps=100,
    save_total_limit=2,
    logging_steps=100,
    run_name="mpnet-base-all-nli-triplet",  # Used in W&B if `wandb` is installed
)
```

注意 `eval_strategy` 是在 `transformers` 的 `4.41.0` 版引入的，之前版本应改用 `evaluation_strategy`。

## 评估器

你可以给 [`SentenceTransformerTrainer`](https://sbert.net/docs/package_reference/sentence_transformer/SentenceTransformer.html#sentence_transformers.SentenceTransformer) 提供一个 `eval_dataset` 以在训练期间拿到评估损失，但在训练期间获取更具体的指标也许更有用。为此你可以用评估器在训练前、中、后用有用的指标评估模型表现。你可以同时用 `eval_dataset` 和一个评估器、只用其一、或都不使用。它们基于 `eval_strategy` 和 `eval_steps` [训练参数](https://huggingface.co/blog/train-sentence-transformers#training-arguments) 进行评估。

以下是 Sentence Transformers 自带的已实现评估器：

| 评估器 | 所需数据 |
| --- | --- |
| [`BinaryClassificationEvaluator`](https://sbert.net/docs/package_reference/sentence_transformer/evaluation.html#binaryclassificationevaluator) | 带类别标签的成对文本 |
| [`EmbeddingSimilarityEvaluator`](https://sbert.net/docs/package_reference/sentence_transformer/evaluation.html#embeddingsimilarityevaluator) | 带相似度分数的成对文本 |
| [`InformationRetrievalEvaluator`](https://sbert.net/docs/package_reference/sentence_transformer/evaluation.html#informationretrievalevaluator) | 查询（qid => 问题）、语料（cid => 文档）以及相关文档（qid => set[cid]） |
| [`MSEEvaluator`](https://sbert.net/docs/package_reference/sentence_transformer/evaluation.html#mseevaluator) | 用教师模型嵌入的源句子和用学生模型嵌入的目标句子。可以是相同文本。 |
| [`ParaphraseMiningEvaluator`](https://sbert.net/docs/package_reference/sentence_transformer/evaluation.html#paraphraseminingevaluator) | ID 到句子的映射，以及带重复句子 ID 的成对文本。 |
| [`RerankingEvaluator`](https://sbert.net/docs/package_reference/sentence_transformer/evaluation.html#rerankingevaluator) | 形如 {'query': '..', 'positive': [...], 'negative': [...]} 的字典列表。 |
| [`TranslationEvaluator`](https://sbert.net/docs/package_reference/sentence_transformer/evaluation.html#translationevaluator) | 两种不同语言间的成对句子。 |
| [`TripletEvaluator`](https://sbert.net/docs/package_reference/sentence_transformer/evaluation.html#tripletevaluator) | (anchor, positive, negative) 三元对。 |

此外，你可以用 [`SequentialEvaluator`](https://sbert.net/docs/package_reference/sentence_transformer/evaluation.html#sequentialevaluator) 把多个评估器组合成一个，然后传给 [`SentenceTransformerTrainer`](https://huggingface.co/blog/train-sentence-transformers#trainer)。

如果你没有必要的评估数据、但仍想跟踪模型在常见基准上的表现，你可以把这些评估器配合来自 Hugging Face 的数据使用：

### 用 STSb 的 EmbeddingSimilarityEvaluator

STS Benchmark（即 STSb）是一个常用基准数据集，用来衡量模型对像"一个男人正在喂一只老鼠给蛇。"这样短文本的语义文本相似度理解。

欢迎在 Hugging Face 上浏览 [sentence-transformers/stsb](https://huggingface.co/datasets/sentence-transformers/stsb) 数据集。

```
from datasets import load_dataset
from sentence_transformers.evaluation import EmbeddingSimilarityEvaluator, SimilarityFunction

# Load the STSB dataset
eval_dataset = load_dataset("sentence-transformers/stsb", split="validation")

# Initialize the evaluator
dev_evaluator = EmbeddingSimilarityEvaluator(
    sentences1=eval_dataset["sentence1"],
    sentences2=eval_dataset["sentence2"],
    scores=eval_dataset["score"],
    main_similarity=SimilarityFunction.COSINE,
    name="sts-dev",
)
# Run evaluation manually:
# print(dev_evaluator(model))

# Later, you can provide this evaluator to the trainer to get results during training
```

### 用 AllNLI 的 TripletEvaluator

AllNLI 是 [SNLI](https://huggingface.co/datasets/stanfordnlp/snli) 和 [MultiNLI](https://huggingface.co/datasets/nyu-mll/multi_nli) 两个自然语言推理数据集的拼接。这个任务传统上用于判断两个文本是蕴含、矛盾还是两者皆非。它后来被采纳用于训练嵌入模型，因为蕴含句和矛盾句能组成有用的 `(anchor, positive, negative)` 三元组——这是训练嵌入模型的常见格式。

在下面这段代码里，它被用来评估模型多大程度上认为锚文本与蕴含文本比锚文本与矛盾文本更相似。一个示例文本是"一位年长的男人在餐厅喝橙汁。"

欢迎在 Hugging Face 上浏览 [sentence-transformers/all-nli](https://huggingface.co/datasets/sentence-transformers/all-nli) 数据集。

```
from datasets import load_dataset
from sentence_transformers.evaluation import TripletEvaluator, SimilarityFunction

# Load triplets from the AllNLI dataset
max_samples = 1000
eval_dataset = load_dataset("sentence-transformers/all-nli", "triplet", split=f"dev[:{max_samples}]")

# Initialize the evaluator
dev_evaluator = TripletEvaluator(
    anchors=eval_dataset["anchor"],
    positives=eval_dataset["positive"],
    negatives=eval_dataset["negative"],
    main_distance_function=SimilarityFunction.COSINE,
    name=f"all-nli-{max_samples}-dev",
)
# Run evaluation manually:
# print(dev_evaluator(model))

# Later, you can provide this evaluator to the trainer to get results during training
```

## Trainer

[`SentenceTransformerTrainer`](https://sbert.net/docs/package_reference/sentence_transformer/SentenceTransformer.html#sentence_transformers.SentenceTransformer) 把模型、数据集、损失函数及其他组件汇集用于训练：

```
from datasets import load_dataset
from sentence_transformers import (
    SentenceTransformer,
    SentenceTransformerTrainer,
    SentenceTransformerTrainingArguments,
    SentenceTransformerModelCardData,
)
from sentence_transformers.losses import MultipleNegativesRankingLoss
from sentence_transformers.training_args import BatchSamplers
from sentence_transformers.evaluation import TripletEvaluator

# 1. Load a model to finetune with 2. (Optional) model card data
model = SentenceTransformer(
    "microsoft/mpnet-base",
    model_card_data=SentenceTransformerModelCardData(
        language="en",
        license="apache-2.0",
        model_name="MPNet base trained on AllNLI triplets",
    )
)

# 3. Load a dataset to finetune on
dataset = load_dataset("sentence-transformers/all-nli", "triplet")
train_dataset = dataset["train"].select(range(100_000))
eval_dataset = dataset["dev"]
test_dataset = dataset["test"]

# 4. Define a loss function
loss = MultipleNegativesRankingLoss(model)

# 5. (Optional) Specify training arguments
args = SentenceTransformerTrainingArguments(
    # Required parameter:
    output_dir="models/mpnet-base-all-nli-triplet",
    # Optional training parameters:
    num_train_epochs=1,
    per_device_train_batch_size=16,
    per_device_eval_batch_size=16,
    warmup_ratio=0.1,
    fp16=True,  # Set to False if GPU can't handle FP16
    bf16=False,  # Set to True if GPU supports BF16
    batch_sampler=BatchSamplers.NO_DUPLICATES,  # MultipleNegativesRankingLoss benefits from no duplicates
    # Optional tracking/debugging parameters:
    eval_strategy="steps",
    eval_steps=100,
    save_strategy="steps",
    save_steps=100,
    save_total_limit=2,
    logging_steps=100,
    run_name="mpnet-base-all-nli-triplet",  # Used in W&B if `wandb` is installed
)

# 6. (Optional) Create an evaluator & evaluate the base model
dev_evaluator = TripletEvaluator(
    anchors=eval_dataset["anchor"],
    positives=eval_dataset["positive"],
    negatives=eval_dataset["negative"],
    name="all-nli-dev",
)
dev_evaluator(model)

# 7. Create a trainer & train
trainer = SentenceTransformerTrainer(
    model=model,
    args=args,
    train_dataset=train_dataset,
    eval_dataset=eval_dataset,
    loss=loss,
    evaluator=dev_evaluator,
)
trainer.train()

# (Optional) Evaluate the trained model on the test set, after training completes
test_evaluator = TripletEvaluator(
    anchors=test_dataset["anchor"],
    positives=test_dataset["positive"],
    negatives=test_dataset["negative"],
    name="all-nli-test",
)
test_evaluator(model)

# 8. Save the trained model
model.save_pretrained("models/mpnet-base-all-nli-triplet/final")

# 9. (Optional) Push it to the Hugging Face Hub
model.push_to_hub("mpnet-base-all-nli-triplet")
```

在这个示例里我从 [`microsoft/mpnet-base`](https://huggingface.co/microsoft/mpnet-base) 微调，那是一个还不是 Sentence Transformer 模型的基座模型。这比微调一个已有的 Sentence Transformer 模型（如 [`all-mpnet-base-v2`](https://huggingface.co/sentence-transformers/all-mpnet-base-v2)）需要更多训练数据。

运行这个脚本后，为我上传了 [tomaarsen/mpnet-base-all-nli-triplet](https://huggingface.co/tomaarsen/mpnet-base-all-nli-triplet) 模型。使用余弦相似度的三元组准确率，即 `cosine_similarity(anchor, positive) > cosine_similarity(anchor, negative)` 所占的比例，开发集为 90.04%，测试集为 91.5%！作为参照，[`microsoft/mpnet-base`](https://huggingface.co/microsoft/mpnet-base) 模型在训练前于开发集上只得 68.32%。

所有这些信息都被存进自动生成的模型卡里，包括基座模型、语言、许可证、评估结果、训练与评估数据集信息、超参数、训练日志以及更多。无需任何额外努力，你上传的模型就会包含潜在用户判断模型是否适合他们所需的全部信息。

### 回调

Sentence Transformers 的 trainer 支持多种 [`transformers.TrainerCallback`](https://huggingface.co/docs/transformers/main_classes/callback#transformers.TrainerCallback) 子类，包括：

- [`WandbCallback`](https://huggingface.co/docs/transformers/en/main_classes/callback#transformers.integrations.WandbCallback)，若安装了 `wandb` 则把训练指标记到 W&B
- [`TensorBoardCallback`](https://huggingface.co/docs/transformers/en/main_classes/callback#transformers.integrations.TensorBoardCallback)，若 `tensorboard` 可访问则把训练指标记到 TensorBoard
- [`CodeCarbonCallback`](https://huggingface.co/docs/transformers/en/main_classes/callback#transformers.integrations.CodeCarbonCallback)，若安装了 `codecarbon` 则跟踪训练期间的碳排放

只要所需依赖被安装，这些就会在你不指定任何东西的情况下自动启用。

关于这些回调以及如何创建你自己的回调，更多信息见 [Transformers 回调文档](https://huggingface.co/docs/transformers/en/main_classes/callback)。

## 多数据集训练

表现最好的模型常常同时在多个数据集上训练。[`SentenceTransformerTrainer`](https://sbert.net/docs/package_reference/sentence_transformer/SentenceTransformer.html#sentence_transformers.SentenceTransformer) 通过允许你用多个数据集训练、而不必把它们转成同一格式来简化这一过程。你甚至可以为每个数据集施加不同的损失函数。多数据集训练的步骤是：

- 用一组 [`datasets.Dataset`](https://huggingface.co/docs/datasets/main/en/package_reference/main_classes#datasets.Dataset) 实例的字典（或一个 [`datasets.DatasetDict`](https://huggingface.co/docs/datasets/main/en/package_reference/main_classes#datasets.DatasetDict)）作为 `train_dataset` 和 `eval_dataset`。
- （可选）如果你想为不同数据集用不同损失，使用把数据集名映射到损失的字典。

每个训练/评估批次只会包含来自其中一个数据集的样本。从多个数据集采样批次的顺序由 [`MultiDatasetBatchSamplers`](https://sbert.net/docs/package_reference/sentence_transformer/training_args.html#sentence_transformers.training_args.MultiDatasetBatchSamplers) 枚举决定，可通过 `multi_dataset_batch_sampler` 传给 [`SentenceTransformersTrainingArguments`](https://sbert.net/docs/package_reference/sentence_transformer/training_args.html#sentencetransformertrainingarguments)。有效选项是：

- `MultiDatasetBatchSamplers.ROUND_ROBIN`：以轮询方式从每个数据集采样，直到某个耗尽。这个策略可能不会用到每个数据集的所有样本，但它确保对每个数据集等量采样。
- `MultiDatasetBatchSamplers.PROPORTIONAL`（默认）：按各数据集大小成比例地从每个数据集采样。这个策略确保每个数据集的所有样本都被使用，且较大的数据集被更频繁地采样。

多任务训练已被证明非常有效。例如，[Huang et al. 2024](https://arxiv.org/pdf/2405.06932) 用了 [`MultipleNegativesRankingLoss`](https://sbert.net/docs/package_reference/sentence_transformer/losses.html#multiplenegativesrankingloss)、[`CoSENTLoss`](https://sbert.net/docs/package_reference/sentence_transformer/losses.html#cosentloss)，以及一个去掉批内负例、只用困难负例的 [`MultipleNegativesRankingLoss`](https://sbert.net/docs/package_reference/sentence_transformer/losses.html#multiplenegativesrankingloss) 变体，在中文上取得了最先进的表现。他们还应用了 [`MatryoshkaLoss`](https://sbert.net/docs/package_reference/sentence_transformer/losses.html#matryoshkaloss) 让模型能够产出 [套娃嵌入](https://huggingface.co/blog/matryoshka)。

以下是多数据集训练的示例：

```
from datasets import load_dataset
from sentence_transformers import SentenceTransformer, SentenceTransformerTrainer
from sentence_transformers.losses import CoSENTLoss, MultipleNegativesRankingLoss, SoftmaxLoss

# 1. Load a model to finetune
model = SentenceTransformer("bert-base-uncased")

# 2. Loadseveral Datasets to train with
# (anchor, positive)
all_nli_pair_train = load_dataset("sentence-transformers/all-nli", "pair", split="train[:10000]")
# (premise, hypothesis) + label
all_nli_pair_class_train = load_dataset("sentence-transformers/all-nli", "pair-class", split="train[:10000]")
# (sentence1, sentence2) + score
all_nli_pair_score_train = load_dataset("sentence-transformers/all-nli", "pair-score", split="train[:10000]")
# (anchor, positive, negative)
all_nli_triplet_train = load_dataset("sentence-transformers/all-nli", "triplet", split="train[:10000]")
# (sentence1, sentence2) + score
stsb_pair_score_train = load_dataset("sentence-transformers/stsb", split="train[:10000]")
# (anchor, positive)
quora_pair_train = load_dataset("sentence-transformers/quora-duplicates", "pair", split="train[:10000]")
# (query, answer)
natural_questions_train = load_dataset("sentence-transformers/natural-questions", split="train[:10000]")

# Combine all datasets into a dictionary with dataset names to datasets
train_dataset = {
    "all-nli-pair": all_nli_pair_train,
    "all-nli-pair-class": all_nli_pair_class_train,
    "all-nli-pair-score": all_nli_pair_score_train,
    "all-nli-triplet": all_nli_triplet_train,
    "stsb": stsb_pair_score_train,
    "quora": quora_pair_train,
    "natural-questions": natural_questions_train,
}

# 3. Load several Datasets to evaluate with
# (anchor, positive, negative)
all_nli_triplet_dev = load_dataset("sentence-transformers/all-nli", "triplet", split="dev")
# (sentence1, sentence2, score)
stsb_pair_score_dev = load_dataset("sentence-transformers/stsb", split="validation")
# (anchor, positive)
quora_pair_dev = load_dataset("sentence-transformers/quora-duplicates", "pair", split="train[10000:11000]")
# (query, answer)
natural_questions_dev = load_dataset("sentence-transformers/natural-questions", split="train[10000:11000]")

# Use a dictionary for the evaluation dataset too, or just use one dataset or none at all
eval_dataset = {
    "all-nli-triplet": all_nli_triplet_dev,
    "stsb": stsb_pair_score_dev,
    "quora": quora_pair_dev,
    "natural-questions": natural_questions_dev,
}

# 4. Load several loss functions to train with
# (anchor, positive), (anchor, positive, negative)
mnrl_loss = MultipleNegativesRankingLoss(model)
# (sentence_A, sentence_B) + class
softmax_loss = SoftmaxLoss(model)
# (sentence_A, sentence_B) + score
cosent_loss = CoSENTLoss(model)

# Create a mapping with dataset names to loss functions, so the trainer knows which loss to apply where
# Note: You can also just use one loss if all your training/evaluation datasets use the same loss
losses = {
    "all-nli-pair": mnrl_loss,
    "all-nli-pair-class": softmax_loss,
    "all-nli-pair-score": cosent_loss,
    "all-nli-triplet": mnrl_loss,
    "stsb": cosent_loss,
    "quora": mnrl_loss,
    "natural-questions": mnrl_loss,
}

# 5. Define a simple trainer, although it's recommended to use one with args & evaluators
trainer = SentenceTransformerTrainer(
    model=model,
    train_dataset=train_dataset,
    eval_dataset=eval_dataset,
    loss=losses,
)
trainer.train()

# 6. Save the trained model and optionally push it to the Hugging Face Hub
model.save_pretrained("bert-base-all-nli-stsb-quora-nq")
model.push_to_hub("bert-base-all-nli-stsb-quora-nq")
```

## 废弃

在 Sentence Transformer v3 发布之前，所有模型都用 [`SentenceTransformer.fit`](https://sbert.net/docs/package_reference/sentence_transformer/SentenceTransformer.html#sentence_transformers.SentenceTransformer.fit) 方法来训练。从 v3.0 开始，我们没有弃用这个方法，而是让它背后改用 [`SentenceTransformerTrainer`](https://sbert.net/docs/package_reference/sentence_transformer/trainer.html#sentence_transformers.trainer.SentenceTransformerTrainer)。这意味着你旧的训练代码应当仍可用，并会被自动升级到多 GPU 训练、损失记录等新特性。话虽如此，新的训练方法要强大得多，所以**建议**用新方法编写新的训练脚本。
