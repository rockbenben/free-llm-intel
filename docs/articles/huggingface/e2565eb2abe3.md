## Qwen3

Qwen3-8B 属于最新一代 Qwen 家族，训练时显式加入了智能体行为。它支持工具调用、多步推理和长上下文处理，非常适合复杂的智能体工作流。与 Hugging Face 🤗smolagents、QwenAgent 或 AutoGen 这类框架集成后，可以构建大量围绕工具使用与推理的智能体应用。与单轮聊天机器人不同，智能体应用依赖会"出声思考"（thinking aloud）的推理模型——中间步骤会放大 token 用量，因此推理速度直接决定响应体验。优化过的推理加上内置的智能体能力，使 Qwen3-8B 成为下一代 AI 智能体的有力底座。

## 用投机解码在 Intel® Core™ Ultra 上加速 Qwen3-8B

我们先用 Intel Lunar Lake 核显对 4-bit 优化的 OpenVINO 版 Qwen3-8B 做了基准测试，把结果作为后续加速的基线。

[投机解码（Speculative decoding）](https://arxiv.org/abs/2211.17192)是一种加速自回归生成的方法：用一个更小更快的模型作为草稿，单次前向传播提出多个 token，再由更大的目标模型一次前向验证。在我们的配置中，[Qwen3-8B](https://huggingface.co/OpenVINO/Qwen3-8B-int4-ov) 作为目标模型，[Qwen3-0.6B](https://huggingface.co/OpenVINO/Qwen3-0.6B-int8-ov) 作为草稿模型。相比基线，平均提速 1.3×。

```
from openvino_genai import LLMPipeline, draft_model

target_path = "/path/to/target/Qwen3-8B-int4-ov"
draft_path = "/path/to/draft/Qwen3-0.6B-int8-ov"
device = "GPU"

model = LLMPipeline(target_path, device, draft_model=draft_model(draft_path, device))

streamer = lambda x: print(x, end="", flush=True)
model.generate("What is speculative decoding and how does it improve inference speed?", max_new_tokens=100, streamer=streamer)
```

> 在初始化 LLMPipeline 之前，请确保目标模型和草稿模型都已转换为 OpenVINO 格式。可以直接下载提供的链接中的转换成品，也可以按说明自行转换。

## 继续压榨性能

投机解码的加速比取决于三个量：目标模型每步前向平均生成的 token 数 γ \gamma γ、推测窗口大小，以及目标模型与草稿模型的延迟比 c c c。更小、更快（虽然不太准）的草稿模型往往能带来更大加速。这启发我们在保住质量的前提下把草稿模型做小，即保住 E(#generated_tokens) E(\# generated\_tokens) E(#generated_tokens)。

Speedup=E(#generated_tokens)γc+1 Speedup = \frac{E(\# generated\_tokens)}{\gamma c + 1} Speedup=γc+1E(#generated_tokens)​

我们[近期的工作](https://huggingface.co/papers/2411.11055)表明，模型深度（层数）是推理延迟的主要来源。我们借鉴了逐层压缩方向的最新进展[1]：用角度距离度量出贡献很小的层块并把它们删掉，剪枝后再微调恢复精度。用这个方法，我们从 Qwen3-0.6B 草稿模型的 28 层中剪掉了 6 层，并用 Qwen3-8B 生成的合成数据对其微调以恢复质量。数据来自对 [BAAI/Infinity-Instruct 数据集](https://huggingface.co/datasets/BAAI/Infinity-Instruct)的 50 万条提示词生成回答。

剪枝后的草稿模型相比基线带来约 1.4× 提速，优于原始草稿模型约 1.3× 的增益。这与理论预期一致——降低草稿延迟就能提高整体加速比，从而带来更快、更高效的推理。

这展示了"剪枝 + 投机解码"如何解锁更快更高效的推理，让本地 AI 智能体更加实用。

想看逐步复现我们的结果，请参考这份 [notebook](https://github.com/openvinotoolkit/openvino_notebooks/blob/latest/supplementary_materials/notebooks/qwen-3/qwen3.ipynb) 和 Qwen3-0.6B 深度剪枝[草稿模型](https://huggingface.co/OpenVINO/Qwen3-pruned-6L-from-0.6B-int8-ov)。

## 与 🤗smolagents 集成

为了展示真实场景的潜力，我们把优化后的配置部署到 🤗smolagents 库上。有了这个集成，开发者可以接入 Qwen3-8B（配上我们的剪枝草稿），构建能调用 API 与外部工具、编写并执行代码、处理长上下文推理的智能体，并高效运行在 Intel® Core™ Ultra 上。受益的不只是 Hugging Face 生态——这对模型组合同样能无缝用于 AutoGen、QwenAgent 等框架，进一步壮大智能体生态。

在我们的演示中，给这个加速后的 Qwen3 智能体派了一个任务：👉 总结 Qwen3 模型系列的关键特性，并做成幻灯片。

它是这样完成的：1. 智能体先用网页搜索工具收集最新信息；2. 然后切换到 Python 解释器，用 `python-pptx` 库生成幻灯片。这个简单的工作流只是"加速版 Qwen3 × 🤗smolagents"所打开的可能性的一小部分——让实用的、高效的 AI 智能体真正落地在 AI PC 上。来[这里](https://github.com/openvinotoolkit/openvino_notebooks/blob/latest/supplementary_materials/notebooks/qwen-3/smolagents/qwen3_agent.ipynb)试试 🚀
