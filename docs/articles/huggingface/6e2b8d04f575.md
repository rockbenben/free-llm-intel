# Hugging Face 机器学习演示登陆 arXiv

我们非常兴奋地宣布：Hugging Face 已与 arXiv 达成合作，让论文更易访问、更易被发现、也更有趣！从今天起，[Hugging Face Spaces](https://huggingface.co/spaces) 已通过一个 Demo 标签页与 arXivLabs 集成，其中收录由社区或论文作者本人创建的演示链接。进入你心仪论文的 Demos 标签页，就能找到开源演示的链接并立即试用 🔥

[![你现在可以在 ArXiv 论文下找到交互式演示](https://huggingface.co/blog/assets/arxiv/recording.gif)](https://huggingface.co/blog/assets/arxiv/recording.gif)

自 2021 年 10 月上线以来，Hugging Face Spaces 已被用于构建和分享超过 12,000 个由社区打造的开源机器学习演示。借助 Spaces，Hugging Face 用户可以分享、探索、讨论模型，并构建交互式应用，让任何拥有浏览器的人无需运行任何代码就能直接试用。这些演示基于开源工具构建，如 Gradio 和 Streamlit Python 库，并利用了 Hugging Face Hub 上可用的模型和数据集。

得益于最新的 arXiv 集成，用户现在可以在论文的 arXiv 摘要页面上找到该论文最受欢迎的演示。例如，如果你想试用 BERT 语言模型的演示，可以前往 BERT 论文的 [arXiv 页面](https://arxiv.org/abs/1810.04805)并进入 demo 标签页。你会看到由开源社区构建的 200 多个演示——有些只是单纯展示 BERT 模型，另一些则展示相关应用，比如对 BERT 加以改造，或在更大的流水线中使用 BERT，上文所示的演示就属于后者。

[![一个可在 Hugging Face Spaces 上使用的蛋白质结构模型交互式演示](https://huggingface.co/blog/assets/arxiv/protein.png)](https://huggingface.co/blog/assets/arxiv/protein.png)

演示让更广泛的受众能够探索机器学习，以及构建计算模型的其他领域，如生物、化学、天文和经济。它们有助于提升人们对模型工作原理的认识与理解，放大研究者工作的可见度，并让更多元的人群发现并调试偏见及其他问题。演示还提升了研究的可复现性——他人无需编写一行代码就能复现论文的结果！我们对这次与 arXiv 的集成感到无比兴奋，并期待看到研究社区如何利用它来改进交流、传播与可解释性。
