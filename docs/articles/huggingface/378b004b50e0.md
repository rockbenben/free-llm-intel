ChatGPT 和各类聊天机器人应用一直是自然语言处理（NLP）领域的焦点。社区始终在寻找强大、可靠的开源模型来支撑自己的应用和用例。这些强力模型的崛起，得益于基于 transformer 的模型的普及和广泛采用——transformer 最早由 Vaswani et al. 在 2017 年提出。这类模型大幅超越了此前基于循环神经网络（RNN）的 SoTA NLP 模型，后者在那篇论文之后几乎被判了死刑。在这篇博客里，我们将介绍一种新架构 RWKV 的落地：它兼具 RNN 和 transformer 两者的优势，并且最近已集成进 Hugging Face 的 [transformers](https://github.com/huggingface/transformers) 库。

### RWKV 项目概览

RWKV 项目由 [Bo Peng](https://github.com/BlinkDL) 发起并持续领导，他也在积极贡献和维护这个项目。社区聚集在官方 Discord 频道，围绕性能（RWKV.cpp、量化等）、规模（数据集处理与抓取）和研究（对话微调、多模态微调等）各类主题不断完善项目的产出。训练 RWKV 模型所用的 GPU 由 Stability AI 捐赠。

欢迎加入[官方 Discord 频道](https://discord.gg/qt9egFA7ve)参与进来；关于 RWKV 背后总体思路的介绍见这两篇博客：[https://johanwind.github.io/2023/03/23/rwkv_overview.html](https://johanwind.github.io/2023/03/23/rwkv_overview.html) / [https://johanwind.github.io/2023/03/23/rwkv_details.html](https://johanwind.github.io/2023/03/23/rwkv_details.html)

### Transformer 架构 vs RNN

RNN 架构是最早被广泛使用的神经网络架构之一，用于处理数据序列——区别于接收固定大小输入的经典架构。它的输入是当前"token"（即数据流中的当前数据点）和上一个"状态"，输出预测的下一个 token 和预测的下一个状态。新状态再用来计算下一个 token 的预测，如此循环。RNN 还可以用于不同的"模式"，因此可以在多种场景下应用，正如 [Andrej Karpathy 的博客](https://karpathy.github.io/2015/05/21/rnn-effectiveness/)所述：一对一（图像分类）、一对多（图像描述）、多对一（序列分类）、多对多（序列生成）等。

| [![rnn_diagram](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/142_rwkv/RNN-scheme.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/142_rwkv/RNN-scheme.png) |
| --- |
| **RNN 各种使用配置总览。来源：[Andrej Karpathy 的博客](https://karpathy.github.io/2015/05/21/rnn-effectiveness/)** |

由于 RNN 在每个时间步都用相同的权重计算预测，它们因梯度消失问题而难以记忆长序列的信息。人们为此做了不少努力，引入了 LSTM、GRU 等新架构。但事实证明，transformer 架构才是迄今解决这个问题最有效的方案。

在 transformer 架构中，输入 token 被同时送进自注意力模块处理。token 先通过 query、key、value 权重被线性投影到不同空间。所得矩阵直接用于计算注意力分数（通过 softmax，如下图），再乘以 value 的隐藏状态得到最终隐藏状态。这一设计让 transformer 能有效缓解长序列问题，推理和训练也比 RNN 模型更快。

| [![transformer_diagram](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/142_rwkv/transformer-scheme.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/142_rwkv/transformer-scheme.png) |
| --- |
| **transformer 模型中注意力分数的公式。来源：[Jay Alammar 的博客](https://jalammar.github.io/illustrated-transformer/)** |

| [![rwkv_attention_formula](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/142_rwkv/RWKV-formula.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/142_rwkv/RWKV-formula.png) |
| --- |
| **RWKV 模型中注意力分数的公式。来源：[RWKV 博客](https://raw.githubusercontent.com/BlinkDL/RWKV-LM/main/RWKV-formula.png)** |

在训练方面，transformer 架构相比传统 RNN 和 CNN 有多项优势。其中最重要的一项是它学习上下文表示的能力。RNN 和 CNN 逐个词地处理输入序列，而 transformer 架构把整个输入序列作为一个整体处理。这让它能捕捉序列中长距离的词间依赖，对机器翻译、问答这类任务尤其有用。

在推理方面，RNN 在速度和内存效率上有优势：一是简单，只需要矩阵-向量运算；二是内存高效，内存需求不会随推理增长。而且由于计算只作用于当前 token 和状态，计算速度不随上下文窗口长度变化。

## RWKV 架构

RWKV 的灵感来自 [Apple 的 Attention Free Transformer](https://machinelearning.apple.com/research/attention-free-transformer)。架构经过精心简化和优化，可以被改造成一个 RNN。此外还加入了一系列技巧，如 `TokenShift` 和 `SmallInitEmb`（技巧清单见[官方 GitHub 仓库的 README](https://github.com/BlinkDL/RWKV-LM/blob/main/README.md#how-it-works)），使其性能足以比肩 GPT。没有这些技巧，模型就不会这么强。在训练方面，目前已具备把训练规模提升到 14B 参数的基础设施，RWKV-4（当前最新版本）中的一些问题也已逐步修复，例如数值不稳定。

### RWKV：RNN 与 transformer 的结合

如何把 transformer 和 RNN 的各自优势合二为一？基于 transformer 的模型最大的短板是：当上下文窗口超过某个值后，模型会变得很难跑——因为注意力分数要同时对整个序列计算。

RNN 天然支持非常长的上下文——上限只受训练时见过的上下文长度限制，而且通过精心编码可以扩展到数百万 token。目前已有在 8192 上下文长度（`ctx8192`）上训练的 RWKV 模型，它们和 `ctx1024` 模型一样快，RAM 占用也相同。

传统 RNN 模型的主要缺陷，以及 RWKV 的不同之处：

- 传统 RNN 模型无法利用超长上下文（LSTM 作为语言模型时也只能处理约 100 个 token）。而 RWKV 可以利用数千 token 乃至更长的上下文，如下图所示：

| [![rwkv_loss](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/142_rwkv/RWKV-loss.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/142_rwkv/RWKV-loss.png) |
| --- |
| **不同上下文长度和模型规模下的语言模型损失。来源：[RWKV 原始仓库](https://raw.githubusercontent.com/BlinkDL/RWKV-LM/main/RWKV-ctxlen.png)** |

- 传统 RNN 模型在训练时无法并行化。RWKV 类似一个"线性化的 GPT"，而且训练比 GPT 更快。

把两种优势合入同一个架构，我们的期望是：RWKV 能成长为一个大于部分之和的整体。

### RWKV 的注意力形式化

模型架构与经典 transformer 非常相似（一个 embedding 层、多个相同的层、layer normalization，以及用因果语言建模头预测下一个 token）。唯一的区别在注意力层——它与传统 transformer 模型完全不同。

想更全面地理解注意力层，推荐阅读 [Johan Sokrates Wind 的详细解释](https://johanwind.github.io/2023/03/23/rwkv_details.html)。

### 现有 checkpoint

#### 纯语言模型：RWKV-4 模型

被广泛采用的 RWKV 模型参数规模从约 170M 到 14B 不等。根据 RWKV 概览[博客](https://johanwind.github.io/2023/03/23/rwkv_overview.html)，这些模型在 Pile 数据集上训练，并在多个基准上与其他 SoTA 模型对比评测，表现相当不错，结果与其他模型非常接近。

| --- |
| **RWKV-4 与其他常见架构的对比。来源：[Johan Wind 的博客](https://johanwind.github.io/2023/03/23/rwkv_overview.html)** |

#### 指令微调/对话版本：RWKV-4 Raven

Bo 还训练了 RWKV 架构的"对话"版本——RWKV-4 Raven 模型。它是在 RWKV-4 pile（在 The Pile 数据集上预训练的 RWKV 模型）基础上，用 ALPACA、CodeAlpaca、Guanaco、GPT4All、ShareGPT 等数据微调而来。该模型有多个版本，覆盖不同语言组合（仅英文、英文+中文+日文、英文+日文等）和不同规模（1.5B、7B、14B 参数）。

所有转换后的 HF 模型都已发布在 Hugging Face Hub 的 [`RWKV` 组织](https://huggingface.co/RWKV)下。

## 🤗 Transformers 集成

该架构已通过[这个 Pull Request](https://github.com/huggingface/transformers/pull/22797)加入 `transformers` 库。就撰写本文之时，你可以通过从源码安装 `transformers` 或使用库的 `main` 分支来使用它。架构与库深度集成，用起来和任何其他架构一样。

下面走几个例子。

### 文本生成示例

要根据输入提示词生成文本，可以用 `pipeline`：

```
from transformers import pipeline

model_id = "RWKV/rwkv-4-169m-pile"

prompt = "\nIn a shocking finding, scientist discovered a herd of dragons living in a remote, previously unexplored valley, in Tibet. Even more surprising to the researchers was the fact that the dragons spoke perfect Chinese."

pipe = pipeline("text-generation", model=model_id)
print(pipe(prompt, max_new_tokens=20))
>>> [{'generated_text': '\nIn a shocking finding, scientist discovered a herd of dragons living in a remote, previously unexplored valley, in Tibet. Even more surprising to the researchers was the fact that the dragons spoke perfect Chinese.\n\nThe researchers found that the dragons were able to communicate with each other, and that they were'}]
```

或者从下面这段代码开始：

```
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer

model = AutoModelForCausalLM.from_pretrained("RWKV/rwkv-4-169m-pile")
tokenizer = AutoTokenizer.from_pretrained("RWKV/rwkv-4-169m-pile")

prompt = "\nIn a shocking finding, scientist discovered a herd of dragons living in a remote, previously unexplored valley, in Tibet. Even more surprising to the researchers was the fact that the dragons spoke perfect Chinese."

inputs = tokenizer(prompt, return_tensors="pt")
output = model.generate(inputs["input_ids"], max_new_tokens=20)
print(tokenizer.decode(output[0].tolist()))
>>> In a shocking finding, scientist discovered a herd of dragons living in a remote, previously unexplored valley, in Tibet. Even more surprising to the researchers was the fact that the dragons spoke perfect Chinese.\n\nThe researchers found that the dragons were able to communicate with each other, and that they were
```

### 使用 Raven 模型（对话模型）

你可以用 alpaca 风格提示对话模型，示例如下：

```
from transformers import AutoTokenizer, AutoModelForCausalLM

model_id = "RWKV/rwkv-raven-1b5"

model = AutoModelForCausalLM.from_pretrained(model_id).to(0)
tokenizer = AutoTokenizer.from_pretrained(model_id)

question = "Tell me about ravens"
prompt = f"### Instruction: {question}\n### Response:"

inputs = tokenizer(prompt, return_tensors="pt").to(0)
output = model.generate(inputs["input_ids"], max_new_tokens=100)

print(tokenizer.decode(output[0].tolist(), skip_special_tokens=True))
>>> ### Instruction: Tell me about ravens
### Response: RAVENS are a type of bird that is native to the Middle East and North Africa. They are known for their intelligence, adaptability, and their ability to live in a variety of environments. RAVENS are known for their intelligence, adaptability, and their ability to live in a variety of environments. They are known for their intelligence, adaptability, and their ability to live in a variety of environments.
```

### 权重转换

任何用户都可以轻松把原始 RWKV 权重转换成 HF 格式，只需运行 `transformers` 库提供的转换脚本。先把"原始"权重推到 Hugging Face Hub（记作 `RAW_HUB_REPO`，原始文件记作 `RAW_FILE`），然后运行转换脚本：

```
python convert_rwkv_checkpoint_to_hf.py --repo_id RAW_HUB_REPO --checkpoint_file RAW_FILE --output_dir OUTPUT_DIR
```

如果你想把转换后的模型推到 Hub（比如推到 `dummy_user/converted-rwkv`），记得先用 `huggingface-cli login` 登录再推送，然后运行：

```
python convert_rwkv_checkpoint_to_hf.py --repo_id RAW_HUB_REPO --checkpoint_file RAW_FILE --output_dir OUTPUT_DIR --push_to_hub --model_name dummy_user/converted-rwkv
```

### 模型压缩与加速

由于只需要矩阵-向量运算，RWKV 是非标准、实验性计算硬件（如光子处理器/加速器）的理想候选。

因此，这一架构也能自然而然地受益于经典的加速与压缩技术（如 [ONNX](https://github.com/harrisonvanderbyl/rwkv-onnx)、4-bit/8-bit 量化等），我们期待随着该架构与 transformers 的集成，这些能力也能普惠给开发者和实践者。

[`optimum`](https://github.com/huggingface/optimum) 库提出的加速技术在不远的将来也能让 RWKV 受益。其中一些技术已在 [`rwkv.cpp` 仓库](https://github.com/saharNooby/rwkv.cpp)或 [`rwkv-cpp-cuda` 仓库](https://github.com/harrisonvanderbyl/rwkv-cpp-cuda)中落地。
