## **介绍 Q-Learning**

### **什么是 Q-Learning？**

Q-Learning 是一种**使用 TD 方法来训练动作价值函数的 off-policy 基于价值方法**：

- *Off-policy*：本章结尾会讲。
- *基于价值的方法*：不直接找最优策略，而是间接地——训练一个价值函数或动作价值函数，它会告诉我们**每个状态或每个状态-动作对的价值**。
- *使用 TD 方法*：**每一步都更新动作价值函数，而不是等到 episode 结束。**

**Q-Learning 是我们用来训练 Q-Function 的算法**。Q-Function 是一个**动作价值函数**，用来确定"处于某个状态并采取某个动作"有多好。

给定状态和动作，我们的 Q Function 输出一个 state-action value（状态-动作值，也叫 Q-value）。

这个 **Q 来自该状态下这个动作的"Quality"（质量）**。

Q-function 内部有一张 **Q-table（Q 表）**，表中每个格子对应一个状态-动作对的价值。可以把 Q-table 看作 Q-function 的**记忆或小抄**。

Q-Table 是初始化的，所以所有值都 = 0。这张表**对每个状态包含四个状态-动作值**。

这里可以看到**初始状态"向上走"的状态-动作值是 0：**

所以，Q-function 含有一张记录每个状态-动作对价值的 Q-table。给定状态和动作，**我们的 Q-Function 就去 Q-table 里查值输出**。

给定一个状态-动作对，Q-function 在其 Q 表中检索出这个状态-动作对的值（Q 值）。

回顾一下，*Q-Learning* **是这样一种 RL 算法**：

- 它训练 *Q-Function*（一个**动作价值函数**），其内部是一张 *Q-table*，**存有所有状态-动作对的value。**
- 给定状态和动作，Q-Function **在其 Q 表中检索对应值。**
- 训练完成后，**我们就有了最优 Q-function，也就有一张最优 Q-Table。**
- 而有了**最优 Q-function**，我们就**有了最优策略**——因为我们**知道每个状态下最好的动作是什么。**

但一开始，**我们的 Q-Table 毫无用处**，因为每个状态-动作对的值都是任意的（通常把 Q-Table 初始化为 0）。不过随着我们**探索环境并更新 Q-Table，它会给出越来越好的近似。**

这里可以看到，经过训练我们的 Q-Table 变好了：借助它，我们能知道每个状态-动作对的价值。

理解了 Q-Learning、Q-Function、Q-Table 是什么之后，**我们再深入 Q-Learning 算法**。

### **Q-Learning 算法**

这是 Q-Learning 的伪代码。我们逐段研究，并用简单例子看看它如何运作，然后再实现。别被它吓到，它比看起来简单！我们一步步过。

**第 1 步：初始化 Q-Table**

需要为每个状态-动作对初始化 Q-Table。**通常全部初始化为 0。**

**第 2 步：用 Epsilon Greedy 策略选动作**

Epsilon Greedy（ε-贪心）策略是一个处理探索/利用权衡的策略。

思路是定义 epsilon ɛ = 1.0：

- *以概率 1 — ɛ*：做**利用 exploitation**（即智能体选择状态-动作值最大的动作）。
- 以概率 ɛ：**做探索 exploration**（随机尝试动作）。

训练开始时，ɛ 很大，**探索的概率极高**，所以大部分时间都在探索。随着训练推进、**Q-Table 的估计越来越好**，我们逐步调小 epsilon——因为需要的探索越来越少，利用越来越多。

**第 4 步：更新 Q(St, At)**

记住，在 TD Learning 中，我们在**一步交互之后**就更新策略或价值函数（取决于所选的 RL 方法）。

构造 TD target 时，我们用的是**即时奖励 Rt+1R_{t+1}Rt+1​ 加上下一状态最优状态-动作对的折扣值**（这叫 bootstrap）。

也就是说，要更新 Q(St,At)Q(S_t, A_t)Q(St​,At​)：

- 需要 St,At,Rt+1,St+1S_t, A_t, R_{t+1}, S_{t+1}St​,At​,Rt+1​,St+1​。
- 我们用 TD target 来更新给定状态-动作对的 Q 值。

TD target 怎么构成？

- 执行动作后得到奖励 Rt+1R_{t+1}Rt+1​。
- 为了拿到**下一状态最优状态-动作对的value**，我们用贪心策略选择下一个最佳动作。注意这不是 ε-贪心，而是永远取状态-动作值最大的动作。

这一个 Q 值更新完之后，我们处在新状态，**再次用 ε-贪心策略**选择动作。

**所以我们说这是 off-policy 算法。**

### **Off-policy vs On-policy**

区别很微妙：

- *Off-policy*：**行动用的策略和更新用的策略不同。**

比如 Q-Learning 中，ε-贪心策略（行为策略 acting policy）不同于**用来挑选"下一状态最佳动作值"以更新 Q 值的贪心策略（更新策略 updating policy）**。

行为策略

与训练阶段用的策略不同：

更新策略

- *On-policy*：**行动和更新用同一个策略。**

比如 Sarsa——另一种基于价值的算法——**由 ε-贪心策略选择下一状态-动作对，而不是贪心策略**。

## **一个 Q-Learning 示例**

为了更好地理解 Q-Learning，看一个简单例子：

- 你是这个小迷宫里的一只老鼠。每次都**从同一个起点出发**。
- 目标是**吃掉右下角那大堆奶酪**，并避开毒药。毕竟，谁不喜欢奶酪呢？
- episode 在以下情况结束：吃到毒药、**吃到大堆奶酪，或者走了超过五步。**
- 学习率为 0.1
- gamma（折扣率）为 0.99

奖励函数如下：

- **+0：** 走到没有奶酪的状态。
- **+1：** 走到有小奶酪的状态。
- **+10：** 走到大堆奶酪的状态。
- **-10：** 走到毒药状态，然后死掉。
- **+0** 如果走了超过五步。

为了让智能体训练出最优策略（即一路向右、再向下的策略），**我们将使用 Q-Learning 算法**。

**第 1 步：初始化 Q-Table**

所以现在**我们的 Q-Table 是没用的**；需要用 Q-Learning 算法**训练 Q-function**。

我们做 2 个训练时间步：

训练时间步 1：

**第 2 步：用 ε-贪心策略选动作**

因为 epsilon 很大 = 1.0，我随机取一个动作，这里选择向右。

**第 3 步：执行动作 At，得到 Rt+1 和 St+1**

向右走，得到一块小奶酪，所以 Rt+1=1R_{t+1} = 1Rt+1​=1，进入新状态。

**第 4 步：更新 Q(St,At)Q(S_t, A_t)Q(St​,At​)**

现在可以用公式更新 Q(St,At)Q(S_t, A_t)Q(St​,At​) 了。

训练时间步 2：

**第 2 步：用 ε-贪心策略选动作**

**再次随机取动作，因为 epsilon 还很大（0.99**——训练推进后我们逐步衰减它，因为需要的探索越来越少）。

我选择向下。**这不是好动作——它通向毒药。**

**第 3 步：执行动作 At，得到 Rt+1R_{t+1}Rt+1​ 和 St+1**

走到了毒药状态，**得到 Rt+1=−10R_{t+1} = -10Rt+1​=−10，然后我死了。**

**第 4 步：更新 Q(St,At)Q(S_t, A_t)Q(St​,At​)**

因为死了，我们开始新 episode。但可以看到，**只经过两步探索，我的智能体就变聪明了。**

随着我们持续探索、利用环境，并用 TD target 更新 Q 值，**Q-Table 会给出越来越好的近似。于是训练结束时，我们就得到最优 Q-Function 的估计。**
