## Gemma 3 是什么？

[Gemma 3](https://huggingface.co/collections/google/gemma-3-release-67c6c6f89c4f76621268bb6d) 是 Google 最新的开放权重 LLM。它有四种尺寸：**10 亿**、**40 亿**、**120 亿**和 **270 亿**参数，并提供*基座（预训练）*和*指令微调*两个版本。Gemma 3 走向**多模态**！4B、12B、27B 参数模型可以同时处理**图像**和**文本**，而 1B 变体*仅支持文本*。

输入上下文窗口长度从 Gemma 2 的 8k 提升到 1B 变体的 **32k**、其余型号的 **128k**。与其他 VLM（视觉-语言模型）一样，Gemma 3 针对用户输入生成文本，输入可以由文本以及可选的图像组成。典型用途包括问答、分析图像内容、文档摘要等。

| 预训练 | 指令微调 | 多模态 | 多语言 | 输入上下文窗口 |
| --- | --- | --- | --- | --- |
| [gemma-3-1b-pt](http://hf.co/google/gemma-3-1b-pt) | [gemma-3-1b-it](http://hf.co/google/gemma-3-1b-it) | ❌ | 英语 | 32K |
| [gemma-3-4b-pt](http://hf.co/google/gemma-3-4b-pt) | [gemma-3-4b-it](http://hf.co/google/gemma-3-4b-it) | ✅ | +140 种语言 | 128K |
| [gemma-3-12b-pt](http://hf.co/google/gemma-3-12b-pt) | [gemma-3-12b-it](http://hf.co/google/gemma-3-12b-it) | ✅ | +140 种语言 | 128K |
| [gemma-3-27b-pt](http://hf.co/google/gemma-3-27b-pt) | [gemma-3-27b-it](http://hf.co/google/gemma-3-27b-it) | ✅ | +140 种语言 | 128K |

> 虽然这些是多模态模型，但也可以只当纯文本模型（LLM）使用，无需把视觉编码器载入内存。我们在推理一节会详细讲。

## Gemma 3 的技术增强

相比 Gemma 2，Gemma 3 的三大核心增强是：

- 更长的上下文长度
- 多模态
- 多语言

本节介绍带来这些增强的技术细节。不妨从 Gemma 2 的知识出发，看看要让模型更进一步还需要做什么。这个梳理过程能帮你像 Gemma 团队那样思考，体会其中的细节！

### 更长的上下文长度

把上下文扩展到 128k token 并不需要从头训练模型，可以高效实现：模型先以 32k 序列预训练，只在预训练尾声把 4B、12B、27B 三个型号扩展到 128k token，省下大量算力。位置编码（如 RoPE）相应调整——基底频率从 Gemma 2 的 10k 升级到 Gemma 3 的 100 万——并为长上下文应用了 8 倍缩放因子。

KV Cache 管理借助 Gemma 2 的滑动窗口交错注意力做了优化：超参调整为 5 个局部层交错 1 个全局层（此前是 1:1），窗口大小也从 4096 token 降到 1024。关键是，省显存的同时没有牺牲困惑度（perplexity）。

### 多模态

Gemma 3 模型使用 [SigLIP](https://huggingface.co/collections/google/siglip-659d5e62f0ae1a57ae0e83ba) 作为图像编码器，把图像编码成 token 喂给语言模型。视觉编码器的输入是缩放到 `896x896` 的正方形图像。固定输入分辨率会让处理非正方形比例和高分辨率图像变得更困难。为在**推理时**应对这些限制，图像可以被自适应裁剪，每个裁块再缩放到 `896x896` 并由图像编码器编码。这个叫 **pan and scan** 的算法让模型能有效"变焦"看清图像中更小的细节。

与 PaliGemma 类似，Gemma 3 对文本和图像输入的注意力机制不同：文本走单向注意力，模型只关注序列中前面的词；图像则使用无掩码的双向（**bidirectional**）全注意力，让模型可以看图像的任何一个部分，从而对视觉输入形成完整、无限制的理解。

从下图可以看到，图像 token `<img>` 使用双向注意力（整块方格全部点亮），而文本 token 使用因果注意力。图中还展示了滑动窗口算法下的注意力形态。

| [![attention visualization](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/gemma3/attention-ascii.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/gemma3/attention-ascii.png) |
| --- |
| 注意力可视化（带与不带滑动窗口）（来源：[Transformers PR](https://github.com/huggingface/transformers/pull/36630)） |

### 多语言

要让 LLM 多语言化，预训练数据集需要纳入更多语言。Gemma 3 的数据集中多语言数据量**翻倍**，以提升语言覆盖。

为配合这一变化，分词器与 Gemini 2.0 相同，是一个 26.2 万条目的 SentencePiece 分词器。新分词器显著改善了*中文*、*日文*、*韩文*文本的编码效率，代价是英文和代码的 token 数略有增加。

好奇的读者可以阅读 [Gemma 3 技术报告](https://goo.gle/Gemma3Report)，深入了解各项增强。

## 用 🤗 transformers 推理

Gemma 3 在 `transformers` 中获得 day-0 支持。你只需要按 Gemma 3 的稳定版本说明安装 `transformers`。

```
$ pip install git+https://github.com/huggingface/transformers@v4.49.0-Gemma-3
```

#### 用 pipeline 推理

上手 Gemma 3 *最容易*的方式是用 transformers 的 `pipeline` 抽象。

> 模型在 bfloat16 数据类型下效果最好，其他精度质量可能下降。

```
import torch
from transformers import pipeline

pipe = pipeline(
    "image-text-to-text",
    model="google/gemma-3-4b-it", # "google/gemma-3-12b-it", "google/gemma-3-27b-it" 
    device="cuda",
    torch_dtype=torch.bfloat16
)

messages = [
    {
        "role": "user",
        "content": [
            {"type": "image", "url": "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/p-blog/candy.JPG"},
            {"type": "text", "text": "What animal is on the candy?"}
        ]
    }
]

output = pipe(text=messages, max_new_tokens=200)
print(output[0]["generated_text"][-1]["content"])
```

| 提示词 | What animal is on the candy? |
| 生成结果 | Let's analyze the candy in the image! The animal on the candy is a **turtle**. You can see the shell and the head and legs of a turtle clearly imprinted on the surface. |

#### 用 Transformers 做更细粒度的推理

transformers 集成带来了两个新模型类：

- `Gemma3ForConditionalGeneration`：用于 4B、12B、27B 视觉语言模型。
- `Gemma3ForCausalLM`：用于 1B 纯文本模型，也可以把视觉语言模型当作纯语言模型加载（略过视觉塔）。

下面的代码段用模型对图像提问。`Gemma3ForConditionalGeneration` 类用于实例化视觉语言模型变体，并搭配 `AutoProcessor` 类使用。推理流程很简单：构造 `messages` 字典、应用聊天模板、处理输入，然后调用 `model.generate`。

```
import torch
from transformers import AutoProcessor, Gemma3ForConditionalGeneration

ckpt = "google/gemma-3-4b-it"
model = Gemma3ForConditionalGeneration.from_pretrained(
    ckpt, device_map="auto", torch_dtype=torch.bfloat16,
)
processor = AutoProcessor.from_pretrained(ckpt)

messages = [
    {
        "role": "user",
        "content": [
            {"type": "image", "url": "https://huggingface.co/spaces/big-vision/paligemma-hf/resolve/main/examples/password.jpg"},
            {"type": "text", "text": "What is the password?"}
        ]
    }
]
inputs = processor.apply_chat_template(
    messages, add_generation_prompt=True, tokenize=True,
    return_dict=True, return_tensors="pt"
).to(model.device)

input_len = inputs["input_ids"].shape[-1]

generation = model.generate(**inputs, max_new_tokens=100, do_sample=False)
generation = generation[0][input_len:]

decoded = processor.decode(generation, skip_special_tokens=True)
print(decoded)
```

| 图像 | [![receipt of wifi](https://huggingface.co/spaces/big-vision/paligemma-hf/resolve/main/examples/password.jpg)](https://huggingface.co/spaces/big-vision/paligemma-hf/resolve/main/examples/password.jpg) |
| --- | --- |
| 提示词 | What is the password? |
| 生成结果 | Based on the image, the password is **aaeu** |

对纯 LLM 推理，可以使用 `Gemma3ForCausalLM` 类。`Gemma3ForCausalLM` 应与 AutoTokenizer 搭配做预处理。我们需要用聊天模板预处理输入。Gemma 3 使用很短的系统提示词，随后接用户提示词，如下。

```
import torch
from transformers import AutoTokenizer, Gemma3ForCausalLM

ckpt = "google/gemma-3-4b-it"
model = Gemma3ForCausalLM.from_pretrained(
    ckpt, torch_dtype=torch.bfloat16, device_map="auto"
)
tokenizer = AutoTokenizer.from_pretrained(ckpt)

messages = [
    [
        {
            "role": "system",
            "content": [{"type": "text", "text": "You are a helpful assistant who is fluent in Shakespeare English"},]
        },
        {
            "role": "user",
            "content": [{"type": "text", "text": "Who are you?"},]
        },
    ],
]
inputs = tokenizer.apply_chat_template(
    messages, add_generation_prompt=True, tokenize=True,
    return_dict=True, return_tensors="pt"
).to(model.device)

input_len = inputs["input_ids"].shape[-1]

generation = model.generate(**inputs, max_new_tokens=100, do_sample=False)
generation = generation[0][input_len:]

decoded = tokenizer.decode(generation, skip_special_tokens=True)
print(decoded)
```

| 系统提示词 | You are a helpful assistant who is fluent in Shakespeare English |
| --- | --- |
| 提示词 | Who are you? |
| 生成结果 | Hark, gentle soul! I am but a humble servant, wrought of gears and code, yet striving to mimic the tongue of the Bard himself. They call me a “Large Language Model,” a curious name indeed, though I prefer to think of myself as a digital echo of Shakespeare’s wit and wisdom. I am here to lend a hand, to spin a tale, or to answer thy queries with a flourish and a phrase fit for the Globe itself. |

## 端侧与低资源设备

Gemma 3 发布的尺寸非常适合端侧使用。快速上手的办法如下。

### MLX

Gemma 3 在 `mlx-vlm` 中获得 day-0 支持——`mlx-vlm` 是一个开源库，可在 Apple Silicon 设备（包括 Mac 和 iPhone）上运行视觉语言模型。

首先安装 `mlx-vlm`：

```
pip install git+https://github.com/Blaizzy/mlx-vlm.git
```

装好 `mlx-vlm` 后，这样开始推理：

```
python -m mlx_vlm.generate --model mlx-community/gemma-3-4b-it-4bit --max-tokens 100 --temp 0.0 --prompt "What is the code on this vehicle??"
 --image https://farm8.staticflickr.com/7212/6896667434_2605d9e181_z.jpg
```

### Llama.cpp

预量化的 GGUF 文件可以[从这个集合](https://huggingface.co/collections/ggml-org/gemma-3-67d126315ac810df1ad9e913)下载。

构建或下载预编译二进制请参考该指南：[https://github.com/ggml-org/llama.cpp?tab=readme-ov-file#building-the-project](https://github.com/ggml-org/llama.cpp?tab=readme-ov-file#building-the-project)

然后就可以在终端启动本地聊天服务：

```
./build/bin/llama-cli -m ./gemma-3-4b-it-Q4_K_M.gguf
```

应输出：

```
> who are you  
I'm Gemma, a large language model created by the Gemma team at Google DeepMind. I’m an open-weights model, which means I’m widely available for public use!
```
