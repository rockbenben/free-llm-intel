## 发布 ScreenSuite——最全面的 GUI 智能体评估套件！

**太长不看**

过去几周，我们马不停蹄地让 GUI 智能体更加开放、更易触达、更容易集成。在这个过程中，我们打造了最大的 GUI 智能体性能基准套件 👉 向你介绍 [ScreenSuite](https://github.com/huggingface/screensuite)。

我们非常兴奋今天能把它分享给你：[ScreenSuite](https://github.com/huggingface/screensuite) 是最全面、最便捷的方式，用来在诸多智能体能力维度上评估[视觉语言模型](https://huggingface.co/blog/vlms)（VLM）！

### GUI 智能体到底是什么？

*GUI 智能体实操演示 - 感谢 [OSWorld](https://os-world.github.io/)*

简单说，AI 智能体就是在虚拟世界中行动的机器人。[更严谨的定义在这里](https://huggingface.co/docs/smolagents/conceptual_guides/intro_agents)

具体而言，"GUI 智能体"是生活在图形用户界面（GUI）里的智能体。想象一下"一个能在我的桌面或手机上点击、导航的智能体"，类似 Claude Computer Use。

这意味着，驱动智能体的 AI 模型会接到类似"把这个 Excel 列填完"的任务，并附带 GUI 的屏幕截图。利用这些信息，它会决定对系统采取行动：`click(x=130, y=540)` 打开浏览器、`type(”Value for XYZ in 2025")`、`scroll(down=2)` 继续往下读……想看 GUI 智能体实操，可以试试我们的 [Open Computer Agent](https://huggingface.co/spaces/smolagents/computer-agent)，由 [Qwen2.5-VL-72B](https://huggingface.co/Qwen/Qwen2.5-VL-72B-Instruct) 驱动。

一个好的 GUI 智能体能像我们一样操作电脑，从而解锁所有电脑任务：在 Google 地图上滚动、编辑文件、网购下单。这涉及各种难以评估的能力。

### 介绍 ScreenSuite 🥳

文献中，例如 [Xu et al. (2025)](https://arxiv.org/abs/2412.04454) 或 [Qin et al. (2025)](https://arxiv.org/abs/2501.12326)，通常把 GUI 智能体的能力划分为几个类别：

- 感知（Perception）：正确感知屏幕上展示的信息
- 定位（Grounding）：理解元素的位置——这对准点击正确位置至关重要
- 单步动作（Single step actions）：在单个动作内正确完成指令
- 多步智能体（Multi-step agents）：在 GUI 环境中通过多个动作完成更高层目标。

所以我们的第一贡献是**收集并统一了一整套覆盖上述全部 GUI 智能体能力的 13 个基准。**

看看上面最后一类：评估多步智能体能力尤其困难，因为它需要虚拟机来运行智能体环境——无论 Windows、Android 还是 Ubuntu……。为此，我们既支持 [E2B desktop](https://github.com/e2b-dev/desktop) 远程沙箱，又从零打造了一个新选项，让你在 Docker 里轻松启动 Ubuntu 或 Android 虚拟机！

**实现细节**

我们精心设计这套基准，兼顾模块化与一致性，确保跨任务、跨环境的强对齐。在需要时——尤其是线上基准——我们以 [smolagents](https://github.com/serain/smolagents) 作为框架层，让智能体的执行与编排更顺畅。

为支持可复现性和易用性，我们构建了自定义 Docker 容器，可在本地部署完整的 **Ubuntu Desktop** 或 **Android** 环境。

与许多依赖无障碍树或其他元数据辅助视觉输入的现有 GUI 基准不同，我们的技术栈有意做到**纯视觉**。这可能导致某些老牌排行榜上的分数有所不同，但我们认为这创造了更真实、更有挑战性的设置，更好地区映人类感知和交互图形界面的方式。

– 所有智能体框架（Android World、OSWorld、GAIAWeb、Mind2Web）都使用 [smolagents](https://github.com/huggingface/smolagents)，并且只依赖**视觉**，不附加任何无障碍树或 DOM（与其他来源报告的评估设置不同）。 – **Mind2Web (Multimodal)** 原本基于无障碍树和截图使用**按元素名称的多选一**，后来被改造为**纯视觉的边界框内点击精度**，任务难度显著提升。

### 在 ScreenSuite 上给主流 VLM 排名 📊

我们在基准上评估了主流 VLM：

- [Qwen-2.5-VL 系列模型](https://huggingface.co/collections/Qwen/qwen25-vl-6795ffac22b334a837c0f9a5)，从 3B 到 72B。这些模型以惊人的定位能力著称，换句话说，它们知道图像中任何元素的坐标，非常适合需要精确点击的 GUI 智能体。
- [UI-Tars-1.5-7B](https://huggingface.co/ByteDance-Seed/UI-TARS-1.5-7B)，字节跳动的全能选手。
- [Holo1-7B](https://huggingface.co/Hcompany/Holo1-7B)，H Company 的最新模型，在其体量下展示了极强的定位性能。
- [GPT-4o](https://arxiv.org/abs/2410.21276)

我们的分数与各方来源报告的分数大体一致！*唯一需要注意的是我们只在纯视觉条件下评估，这会造成一些差异，见上文实现细节。*

> 💡 注意，ScreenSuite 无意完全复现业界发布的基准：我们是基于视觉评估模型的 GUI 智能体能力。因此在像 Mind2Web 这样的基准上——其他评估会给智能体提供 DOM 或无障碍树这类信息丰富的上下文——我们的评估设置要困难得多，所以 ScreenSuite 与其他来源对不上。

### 30 秒开始你的自定义评估 ⚡️

前往[代码仓库](https://github.com/huggingface/screensuite)。

- 连同子模块一起克隆仓库：`git clone --recurse-submodules git@github.com:huggingface/screensuite.git`
- 安装该包：`uv sync --extra submodules --python 3.11`
- 运行 `python run.py`。或者运行 `python examples/run_benchmarks.py` 做更精细的控制，比如并行跑多个模型的评估。

> 多步基准需要一台裸机来运行和部署桌面/移动*环境*模拟器（见 README.md）
