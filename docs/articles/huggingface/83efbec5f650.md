# Quanto：Optimum 的 PyTorch 量化后端

量化是一种降低深度学习模型计算和内存开销的技术，做法是用 8 位整数（int8）这类低精度数据类型来表示权重和激活值，而不是常规的 32 位浮点数（float32）。

减少位数意味着模型所需的存储空间更小——这对在消费级设备上部署大语言模型至关重要。低位宽数据类型还能启用一些专门的优化，比如在 CUDA 设备上做 `int8` 或 `float8` 矩阵乘法。

市面上有很多开源库可以对 PyTorch 深度学习模型做量化，各自都提供了非常强大的功能，但往往受限于特定的模型配置和设备。

而且，尽管它们基于相同的设计原则，彼此之间却常常不兼容。

今天，我们很高兴推出 [quanto](https://github.com/huggingface/optimum-quanto)——一个为 [Optimum](https://huggingface.co/docs/optimum/index) 打造的 PyTorch 量化后端。

它在设计之初就把通用性和简单性放在第一位：

- 所有功能均可在 eager 模式下使用（兼容无法 trace 的模型），
- 量化后的模型可以放到任何设备上（包括 CUDA 和 MPS），
- 自动插入量化与反量化桩（stubs），
- 自动插入量化后的函数式算子，
- 自动插入量化后的模块（支持的模块列表见下文），
- 提供从 float 模型到动态量化再到静态量化模型的无缝工作流，
- 序列化兼容 PyTorch `weight_only` 和 🤗 [Safetensors](https://huggingface.co/docs/safetensors/index)，
- 在 CUDA 设备上加速矩阵乘法（int8-int8、fp16-int4、bf16-int8、bf16-int4），
- 支持 int2、int4、int8 和 float8 权重，
- 支持 int8 和 float8 激活值。

近期的量化方法似乎都聚焦于量化大语言模型（LLM），而 [quanto](https://github.com/huggingface/optimum-quanto) 的目标是为简单的量化方案（线性量化、分组量化）提供极其简单的量化原语，并适配任意模态。

## 量化工作流

Quanto 以 pip 包的形式提供。

```
pip install optimum-quanto
```

典型的量化工作流包含以下步骤：

**1. 量化（Quantize）**

第一步把标准 float 模型转换成动态量化模型。

```
from optimum.quanto import quantize, qint8

quantize(model, weights=qint8, activations=qint8)
```

在这一步，模型的推理过程被修改为动态量化权重。

**2. 校准（Calibrate，若不量化激活值则可省略）**

Quanto 支持校准模式：让代表性样本流过量化模型，同时记录激活值的范围。

```
from optimum.quanto import Calibration

with Calibration(momentum=0.9):
    model(samples)
```

这会自动启用量化模块中激活值的量化。

**3. 微调，即量化感知训练（Quantization-Aware-Training，可选）**

如果模型性能下滑太多，可以微调几个 epoch，把 float 模型的性能找回来。

```
import torch

model.train()
for batch_idx, (data, target) in enumerate(train_loader):
    data, target = data.to(device), target.to(device)
    optimizer.zero_grad()
    output = model(data).dequantize()
    loss = torch.nn.functional.nll_loss(output, target)
    loss.backward()
    optimizer.step()
```

**4. 冻结整数权重**

冻结模型时，其 float 权重会被量化权重替换。

```
from optimum.quanto import freeze

freeze(model)
```

**5. 序列化量化模型**

量化模型的权重可以序列化到 `state_dict` 并保存为文件。支持 `pickle` 和 `safetensors`（推荐后者）。

```
from safetensors.torch import save_file

save_file(model.state_dict(), 'model.safetensors')
```

要重新加载这些权重，还需要保存量化模型的量化映射（quantization map）。

```
import json

from optimum.quanto import quantization_map

with open('quantization_map.json', w) as f:
  json.dump(quantization_map(model))
```

**5. 重新加载量化模型**

借助 `requantize` 辅助函数，可以从 `state_dict` 和 `quantization_map` 重新加载序列化的量化模型。注意，你需要先实例化一个空模型。

```
import json

from safetensors.torch import load_file

state_dict = load_file('model.safetensors')
with open('quantization_map.json', r) as f:
  quantization_map = json.load(f)

# Create an empty model from your modeling code and requantize it
with torch.device('meta'):
  new_model = ...
requantize(new_model, state_dict, quantization_map, device=torch.device('cuda'))
```

关于量化工作流的具体实例，请参考 [examples](https://github.com/huggingface/optimum-quanto/tree/main/examples)。也可以看看这份 [notebook](https://colab.research.google.com/drive/1qB6yXt650WXBWqroyQIegB-yrWKkiwhl?usp=sharing)，我们演示了如何用 quanto 量化 BLOOM 模型！

## 与 transformers 的集成

Quanto 与 Hugging Face [transformers](https://github.com/huggingface/transformers) 库无缝集成。给 `from_pretrained` 传一个 `QuantoConfig` 就能量化任意模型！

目前需要使用最新版 [accelerate](https://github.com/huggingface/accelerate) 以确保集成完全兼容。

```
from transformers import AutoModelForCausalLM, AutoTokenizer, QuantoConfig

model_id = "facebook/opt-125m"
tokenizer = AutoTokenizer.from_pretrained(model_id)

quantization_config = QuantoConfig(weights="int8")

quantized_model = AutoModelForCausalLM.from_pretrained(
    model_id,
    quantization_config= quantization_config
)
```

只需在 `QuantoConfig` 中传入正确的参数，就可以把权重和/或激活值量化为 int8、float8、int4 或 int2。激活值支持 int8 或 float8。使用 float8 需要硬件支持 float8 精度，否则在做矩阵乘法时（仅在权重量化的情况下）quanto 会把权重和激活值静默升精度到 torch.float32 或 torch.float16（取决于模型原始数据类型）。如果在 MPS 设备上使用 `float8`，`torch` 目前会抛出错误。

Quanto 是设备无关的——无论你在 CPU、GPU 还是 MPS（Apple Silicon）上，都可以量化并运行模型。

Quanto 对 torch.compile 也很友好。你可以用 quanto 量化模型，再对模型调用 `torch.compile` 来编译加速生成。如果涉及动态量化（即量化感知训练或启用了量化激活值），这个功能可能无法开箱即用。若通过 transformers 集成使用，创建 `QuantoConfig` 时请保持 `activations=None`。

任何模型、任意模态都可以用 quanto 量化。下面演示用 quanto 以 int8 量化 `openai/whisper-large-v3` 模型。

```
from transformers import AutoModelForSpeechSeq2Seq

model_id = "openai/whisper-large-v3"
quanto_config = QuantoConfig(weights="int8")

model = AutoModelForSpeechSeq2Seq.from_pretrained(
   model_id,
   torch_dtype=torch.float16,
   device_map="cuda",
   quantization_config=quanto_config
)
```

## 参与 quanto 贡献

我们非常欢迎对 [quanto](https://github.com/huggingface/optimum-quanto) 的贡献，尤其是以下方向：

- 面向特定设备的 [quanto](https://github.com/huggingface/optimum-quanto) 算子优化 kernel，
- 用于挽回量化精度损失的训练后量化（Post-Training-Quantization）优化器，
- `transformers` 或 `diffusers` 模型的辅助类。
