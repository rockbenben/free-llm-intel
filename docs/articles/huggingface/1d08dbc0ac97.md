# Gradio 3.0 发布！

### 机器学习演示

机器学习演示正日益成为模型发布的重要一环。演示让任何人——不只是 ML 工程师——都能在浏览器中试用模型、对预测给出反馈，并在模型表现良好时建立对模型的信任。

自 2019 年第一版发布以来，已有超过 60 万个 ML 演示用 Gradio 库构建。今天，我们激动地宣布 **Gradio 3.0**：对 Gradio 库的彻底重构 🥳

### Gradio 3.0 有哪些新内容？

🔥 前端全面重构，源自我们听到的 Gradio 用户反馈：

- 我们改用现代技术（如 [Svelte](https://svelte.dev/)）来构建 Gradio 前端。由此带来的结果是更小的加载体积和更快的页面加载！
- 我们采用的设计也更为简洁，使 Gradio 演示能在更多场景中视觉上融为一体（例如[嵌入](https://discuss.huggingface.co/t/gradio-iframe-embedding/13021/9?u=abidlabs)到博客文章中）。

- 我们改进了现有组件，让 `Dataframe` 等更加用户友好（试试把 CSV 文件拖放到 Dataframe 中），同时新增了如 `Gallery` 这样的组件，让你能为自己的模型搭建合适的 UI。

- 我们新增了 `TabbedInterface` 类，让你可以把相关演示组合成一个 Web 应用中的多个标签页。

来看看你可以使用的所有组件，尽在[我们（重新设计的）文档](http://www.gradio.app/docs) 🤗！

🔥 我们创造了一门全新的低层语言，叫做 **Gradio Blocks**，让你直接用 Python 构建复杂的自定义 Web 应用：

我们为什么要创建 Blocks？Gradio 演示构建起来非常容易，但如果你想更多地控制演示的布局，或对数据流动有更灵活的诉求呢？例如，你可能想要：

- 自定义演示的布局，而不只是把所有输入放左边、输出放右边
- 拥有多步界面，其中一个模型的输出成为下一个模型的输入，或者拥有更通用的灵活数据流
- 根据用户输入改变某个组件的属性（例如下拉框中的选项）或其可见性

底层的 Blocks API 让你可以直接在 Python 中完成以上一切。

这是一个 Blocks 演示的例子，它创建了两个简单的演示，并用 tab 将它们组合在一起：

```
import numpy as np
import gradio as gr

def flip_text(x):
    return x[::-1]

def flip_image(x):
    return np.fliplr(x)

with gr.Blocks() as demo:
    gr.Markdown("Flip text or image files using this demo.")
    with gr.Tabs():
        with gr.TabItem("Flip Text"):
            text_input = gr.Textbox()
            text_output = gr.Textbox()
            # this demo runs whenever the input textbox changes
            text_input.change(flip_text, inputs=text_input, outputs=text_output)
        
        with gr.TabItem("Flip Image"):
            with gr.Row():
                image_input = gr.Image()
                image_output = gr.Image()
            button = gr.Button("Flip")
            # this demo runs whenever the button is clicked
            button.click(flip_image, inputs=image_input, outputs=image_output)
    
demo.launch()
```
