# Keras 中的 Llama 3.2

这将是史上最短的博客。

> 问：Llama 3.2 两周前登陆了 Hugging Face / Transformers。Keras 里什么时候能用？

> 答：从第一天起就能用了 😀。不用等。

是的，Keras 的 Llama3 可以从任何标准（即 safetensors）Hugging Face checkpoint 加载，包括 3.2 的 checkpoint。需要转换时会即时完成。试试这个：

```

```

## Keras 是多后端的

Keras 是久经考验的建模库，服务 JAX、PyTorch 和 TensorFlow。你可能注意到 [demo Colab](https://colab.research.google.com/drive/1cnAUQbDfM8lErQ8MD2x9Mo5sfKIqIxEh) 里这一行：

```
import os
os.environ["KERAS_BACKEND"] = "jax" # or "torch", or "tensorflow"
```

它必须出现在 `import keras` 之前，决定模型跑在 JAX、PyTorch 还是 TensorFlow 上。想在你喜欢的模型上试试带 XLA 编译的 JAX，非常顺手 🚀。

## keras-hub 是什么？

Keras 是建模库，[keras-hub](https://keras.io/keras_hub/) 是它的预训练模型合集。它以前叫 [KerasNLP](https://keras.io/keras_nlp/) 和 [KerasCV](https://keras.io/keras_cv/)，[更名](https://github.com/keras-team/keras-hub/issues/1831)进行中。它收录了所有热门预训练模型（Llama3、Gemma、StableDiffusion、Segment Anything……）在 Keras 中的正统实现。

## Keras 的 LLM "自带电池"

我的意思是"自带 tokenizer"。`model.generate()` 直接对字符串就能用：

```
model.generate("Hi there!")
> "Hi there! I'm looking for information on how to ...
```

训练也一样。你可以直接对一组字符串做训练：

```
model.fit(strings) # list or dataset of input strings
```

## 与 LLM 聊天

热门 LLM 的指令微调版本可以一轮一轮地对话。这里 Llama-3.2-1B-Instruct 能听懂下面这种对话标记（见 [meta 文档](https://www.llama.com/docs/model-cards-and-prompt-formats/llama3_1/#-instruct-model-prompt-)）。

```
<|start_header_id|>system<|end_header_id|>You  are a helpful assistant<|eot_id|>\n
\n
<|start_header_id|>user<|end_header_id|>Hello_<|eot_id|>\n
\n
<|start_header_id|>assistant<|end_header_id|>\n
\n
```

对话按这个格式组织后，可以直接喂给 `model.generate()`。

为了方便，[demo Colab](https://colab.research.google.com/drive/1cnAUQbDfM8lErQ8MD2x9Mo5sfKIqIxEh) 实现了一个叫 `ChatState` 的辅助类，自动完成必要的字符串拼接。

## 更底层访问：Tokenizer、Backbone

如果你不喜欢"自带电池"，想直接用底层的 tokenizer 和模型，它们也很容易拿到：

```
# tokenizer
model.preprocessor.tokenizer

# the model itself
model.backbone

# You can even load them separately from the same preset
backbone = keras_hub.models.Llama3CausalLM.from_preset("hf://meta-llama/Llama-3.2-1B-Instruct", dtype="float16")
tokenizer = keras_hub.models.Llama3Tokenizer.from_preset("hf://meta-llama/Llama-3.2-1B-Instruct")
```

## 等等，Tokenizer、Preprocessor？我糊涂了

Tokenizer 只把文本变成整数向量。这里 "Hello" 翻译成一个 token：

```
tokenizer("Hello")
> Array([9906], dtype=int32)
```

Preprocessor 是个万能概念，负责模型需要的一切数据变换。例如图像任务里的图像缩放或增强，或者这里文本模型的文本分词。对 CausalLM 任务，preprocessor 还额外处理三个细节：

- 加上模型期望的文本起始和结束 token
- 给 token 序列做 padding 并生成 mask
- 为训练和微调生成"期望输出"。对 CausalLM 任务，这就是输入序列右移一位。

```
tokens = model.preprocessor("Hello")

tokens[0] # 128000 and 128009 are the start and end text tokens
> {'token_ids': Array([128000,   9906, 128009, 0, 0, 0], dtype=int32), 'padding_mask': Array([True, True, True, False, False, False], dtype=bool)}

tokens[1] # input sequence shifted by one
> [9906, 128009, 0, 0, 0, 0]

# feeding the model manually
model.backbone(model.preprocessor(["Hello", "Hi!"])[0]) # raw logits as output
> [[[ 0.9805   0.1664   0.625   ... -0.834   -0.264    0.05203]
  ...]]

# More typically you would use Keras built-in functions model.generate, model.fit, model.predict, model.evaluate
```

## Keras 内置训练器

对训练数据集直接调 `model.fit(ds)` 就行。这个训练器兼容 Keras 提供的各种[分布式训练](https://keras.io/guides/distribution/)、[混合精度](https://keras.io/api/mixed_precision/)、[量化](https://keras.io/examples/keras_recipes/float8_training_and_inference_with_transformer/)以及 [LoRA/QLoRA](https://keras.io/examples/keras_recipes/parameter_efficient_finetuning_of_gemma_with_lora_and_qlora/) 选项。它也完全是可选的——想写自定义训练循环也可以。

完整示例见 [demo Colab](https://colab.research.google.com/drive/1cnAUQbDfM8lErQ8MD2x9Mo5sfKIqIxEh)，我们把 Llama 3.2 微调成海盗腔：

对微调结果满意后，直接从 Keras 上传：

```
    preset = "./pirate-llama")
```

## 推理或训练的分布式模型并行

#### 本节 demo Colab：[Llama 3.1 Keras model parallel](https://colab.research.google.com/drive/1WzErEM04rieeCMY6s_wGyTjWcuhAF-3D)

有人纳闷：既然在 Hugging Face 上用 Transformers 就能玩 LLM，为什么还要 Keras？答案是：就算你不在意 Keras 作为建模框架的灵活与好用（你应该在意！），Keras 也是通往高级模型并行的最快捷径——靠的是 [JAX](https://github.com/jax-ml/jax) 和它强大的 [XLA](https://github.com/openxla/xla) 编译器。

拿一个 8B 参数模型来演示：meta-llama/Llama-3.1-8B-Instruct（[demo Colab 在这](https://colab.research.google.com/drive/1WzErEM04rieeCMY6s_wGyTjWcuhAF-3D)）。不做量化的话，这个模型大到任何单块加速卡都装不下。用 Keras，你可以把它分片加载到多块 GPU 或 TPU 上。如果你不确定"正确的"权重切分方式，多数模型都给了合理的默认值——这里调 `keras_hub.models.Llama3Backbone.get_layout_map(device_mesh)`：

```
devices = keras.distribution.list_devices() # 8 TPU cores: let's do a 2x4 mesh
device_mesh = keras.distribution.DeviceMesh((2, 4), ["batch", "model"], devices)
layout_map = keras_hub.models.Llama3Backbone.get_layout_map(device_mesh) # defaults
distrib = keras.distribution.ModelParallel(layout_map=layout_map, batch_dim_name="batch")
keras.distribution.set_distribution(distrib)

# Now load the model, distributed across the accelerators
model = keras_hub.models.Llama3CausalLM.from_preset("hf://meta-llama/Llama-3.1-8B-Instruct")
```

如果不信任模型给的默认 layout map，也可以自己定义。在这个只有 8 核的"小" TPU 配置上，下面这个 layout map 比默认略快（每 epoch 54 秒，而非 62 秒）：

```
layout_map = keras.distribution.LayoutMap(device_mesh)

layout_map["token_embedding/embeddings"] = ("model", None)
layout_map["token_embedding/reverse_embeddings"] = ("model", None)
layout_map["self_attention.*(query|key|value).kernel"] = ("model", None, None)
layout_map["self_attention.*attention_output.kernel"] = ("model", None, None)
layout_map["feedforward_intermediate_dense.kernel"] = (None, "model")
layout_map["feedforward_gate_dense.kernel"] = (None, "model")
layout_map["feedforward_output_dense.kernel"] = ("model", None)
```

看[这里的 demo Colab](https://colab.research.google.com/drive/1WzErEM04rieeCMY6s_wGyTjWcuhAF-3D)——它在 Google TPU v5e 上花了不到 8 分钟，把更大的 8B Llama 微调成海盗腔（可在 [Hugging Face Spaces 的 JupyterLab](https://huggingface.co/docs/hub/main/en/spaces-sdks-docker-jupyter) 上跑）。微调后的模型在[这里](https://huggingface.co/martin-gorner/llama-3.1-8B-pirate-instruct)。如果你还需要一份关于模型并行与 Keras 的简明解释，[这篇覆盖了](https://developers.googleblog.com/en/fine-tuning-gemma-2-with-keras-hugging-face-update/)。
