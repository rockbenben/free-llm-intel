# 新增三个 Serverless 推理提供方：Hyperbolic、Nebius AI Studio 与 Novita 🔥

我们很高兴宣布 Hugging Face Hub 又新增三家杰出的 serverless 推理提供方（Inference Providers）：[Hyperbolic](https://hyperbolic.xyz/)、[Nebius AI Studio](https://studio.nebius.com/) 和 [Novita](https://novita.ai/)。他们加入我们不断成长的生态，直接扩展了 Hub 模型页面上 serverless 推理的广度与能力。他们同样与我们的客户端 SDK（JS 和 Python）无缝集成，让你能极其方便地用首选提供方调用各种模型。

这些伙伴与我们既有的提供方——Together AI、Sambanova、Replicate、fal 和 Fireworks.ai——并肩。

新伙伴带来一大批新模型：DeepSeek-R1、Flux.1 等等。他们支持的全部模型见下方：

- [Nebius AI Studio](https://huggingface.co/models?inference_provider=nebius&sort=trending)
- [Novita](https://huggingface.co/models?inference_provider=novita&sort=trending)
- [Hyperbolic](https://huggingface.co/models?inference_provider=hyperbolic&sort=trending)

我们非常期待看到你用这些新提供方构建什么！

## 工作原理

### 在网站上

- 在你的用户账号设置中，你可以：

- 为你已注册的提供方设置自己的 API key。若不设置自定义 key，你的请求将通过 HF 路由。
- 按偏好给提供方排序。这会影响模型页面上的 widget 和代码片段。

- 如前所述，调用 Inference API 有两种模式：

- 自定义 key（请求直接用你对应推理提供方自己的 API key 发往该推理提供方）
- 由 HF 路由（这种情况下你不需要提供方的 token，费用直接计入你的 HF 账号而非提供方账号）

- 模型页面会展示第三方推理提供方（与当前模型兼容的提供方，按用户偏好排序）

### 从客户端 SDK

#### Python：使用 huggingface_hub

下面的例子展示如何用 Hyperbolic 作为推理提供方使用 DeepSeek-R1。你可以用 [Hugging Face token](https://huggingface.co/settings/tokens)自动经由 Hugging Face 路由，或者如果你有 Hyperbolic API key 也可以直接使用。

从源码安装 `huggingface_hub`（见[说明](https://huggingface.co/docs/huggingface_hub/installation#install-from-source)）。官方支持将很快随 v0.29.0 版本发布。

```
from huggingface_hub import InferenceClient

client = InferenceClient(
    provider="hyperbolic",
    api_key="xxxxxxxxxxxxxxxxxxxxxxxx"
)

messages = [
    {
        "role": "user",
        "content": "What is the capital of France?"
    }
]

completion = client.chat.completions.create(
    model="deepseek-ai/DeepSeek-R1", 
    messages=messages, 
    max_tokens=500
)

print(completion.choices[0].message)
```

以下是用运行在 [Nebius AI Studio](https://studio.nebius.com) 上的 [FLUX.1-dev](https://huggingface.co/black-forest-labs/FLUX.1-dev) 从文本 prompt 生成图像的方法：

```
from huggingface_hub import InferenceClient

client = InferenceClient(
    provider="nebius",
    api_key="xxxxxxxxxxxxxxxxxxxxxxxx"
)

# output is a PIL.Image object
image = client.text_to_image(
    "Bob Marley in the style of a painting by Johannes Vermeer",
    model="black-forest-labs/FLUX.1-schnell"
)
```

想换一个提供方，只需修改 provider 名称，其他都不变：

```
from huggingface_hub import InferenceClient

client = InferenceClient(
-	provider="nebius",
+   provider="hyperbolic",
    api_key="xxxxxxxxxxxxxxxxxxxxxxxx"
)
```

#### JS：使用 @huggingface/inference

```
import { HfInference } from "@huggingface/inference";

const client = new HfInference("xxxxxxxxxxxxxxxxxxxxxxxx");

const chatCompletion = await client.chatCompletion({
    model: "deepseek-ai/DeepSeek-R1",
    messages: [
        {
            role: "user",
            content: "What is the capital of France?"
        }
    ],
    provider: "novita",
    max_tokens: 500
});

console.log(chatCompletion.choices[0].message);
```

## 计费

对于直接请求——即使用推理提供方自己的 key 时——由对应提供方向你计费。例如，如果你使用 Nebius AI Studio 的 key，费用记在你的 Nebius AI Studio 账号上。

对于路由请求——即通过 hub 认证时——你只需支付标准的提供方 API 费率。我们不加任何溢价，只是把提供方成本原样传递。（未来，我们可能会与提供方伙伴达成收入分成协议。）
