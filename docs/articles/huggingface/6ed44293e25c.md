# Optimum + ONNX Runtime：让你的 Hugging Face 模型训练更简单、更快

## 引言

语言、视觉和语音领域中基于 Transformer 的模型正变得越来越大，以支撑面向终端用户的复杂多模态用例。模型规模的增大直接影响训练这些模型、并随规模增长而扩展它们所需的资源。Hugging Face 与微软的 ONNX Runtime 团队正在合作推进大语言模型、语音模型和视觉模型微调方面的技术进展。Hugging Face 的 [Optimum 库](https://huggingface.co/docs/optimum/index) 通过与用于训练的 ONNX Runtime 集成，提供了一个开源方案，**能让许多流行的 Hugging Face 模型训练时间缩短 35% 以上**。本文同时介绍 Hugging Face Optimum 和 ONNX Runtime 训练生态的细节，并用性能数据说明使用 Optimum 库的收益。

## 性能结果

下面这张图表显示，Hugging Face 模型配合 Optimum、并在训练时**使用 ONNX Runtime 加 DeepSpeed ZeRO Stage 1**，加速幅度达到**从 39% 到 130%**，十分可观。性能测量在选定的 Hugging Face 模型上进行：以 PyTorch 作为基线跑第一遍，仅用 ONNX Runtime 训练跑第二遍，再用 ONNX Runtime + DeepSpeed ZeRO Stage 1 跑最后一遍，以展示最大收益。基线 PyTorch 运行使用的优化器是 AdamW，ORT Training 的运行使用 Fused Adam Optimizer。这些实验在单个配备 8 块 GPU 的 Nvidia A100 节点上完成。

关于为训练加速而开启 Optimum 的更多配置细节，可以在[这里](https://huggingface.co/docs/optimum/onnxruntime/usage_guides/trainer)找到。这些运行所使用的版本信息如下：

```
PyTorch: 1.14.0.dev20221103+cu116; ORT: 1.14.0.dev20221103001+cu116; DeepSpeed: 0.6.6; HuggingFace: 4.24.0.dev0; Optimum: 1.4.1.dev0; Cuda: 11.6.2
```

## Optimum 库

Hugging Face 是一个快速增长的开放社区与平台，目标是让好的机器学习走向普惠。继 [Transformers 库](https://huggingface.co/docs/transformers/index) 取得成功之后，我们把模态从 NLP 扩展到音频和视觉，如今覆盖机器学习的各类用例，以满足社区的需求。现在，在 [Hugging Face Hub](https://huggingface.co/models) 上，有超过 120K 个免费、可访问的模型 checkpoint，覆盖各种机器学习任务，还有 18K 个数据集和 20K 个 ML demo 应用。然而，把 transformer 模型扩展到生产环境对业界来说仍然是个挑战。尽管准确率高，基于 transformer 的模型的训练和推理依然耗时且昂贵。

为了应对这些需求，Hugging Face 建立了两个开源库：**Accelerate** 和 **Optimum**。[🤗 Accelerate](https://huggingface.co/docs/accelerate/index) 专注于开箱即用的分布式训练；[🤗 Optimum](https://huggingface.co/docs/optimum/index) 作为 transformers 的扩展，通过发挥用户目标硬件的最大效率来加速模型的训练与推理。Optimum 集成了 ONNX Runtime 这样的机器学习加速器，以及 [Intel 的 Habana Gaudi](https://huggingface.co/blog/habana-gaudi-2-benchmark) 这样的专用硬件，让用户在训练和推理两方面都能获得显著加速。此外，Optimum 无缝集成 Hugging Face 的其他工具，并继承了与 Transformers 相同的易用性。开发者可以轻松地调整自己的工作，用更少的算力实现更低的延迟。

## ONNX Runtime Training

[ONNX Runtime](https://onnxruntime.ai/) 加速[大模型训练](https://onnxruntime.ai/docs/get-started/training-pytorch.html)，单独使用时吞吐最高可提升 40%；与 [DeepSpeed](https://www.deepspeed.ai/tutorials/zero/) 组合使用时，在流行的 HuggingFace transformer 模型上可提升 130%。ONNX Runtime 已经作为 Optimum 的一部分被集成，通过 Hugging Face 的 Optimum 训练框架实现更快的训练。

ONNX Runtime Training 之所以能取得这样的吞吐提升，得益于若干内存与计算优化。内存优化让 ONNX Runtime 能够最大化 batch size、高效利用可用内存；计算优化则缩短训练时间。这些优化包括（但不限于）高效的内存规划、kernel 优化、Adam 优化器的 multi tensor apply（把施加到模型所有参数上的逐元素更新批处理成一次或少数几次 kernel 启动）、FP16 优化器（消除大量设备到主机的内存拷贝）、混合精度训练，以及节点融合与节点消除等图优化。ONNX Runtime Training 同时支持 [NVIDIA](https://techcommunity.microsoft.com/t5/ai-machine-learning-blog/accelerate-pytorch-transformer-model-training-with-onnx-runtime/ba-p/2540471) 和 [AMD GPU](https://cloudblogs.microsoft.com/opensource/2021/07/13/onnx-runtime-release-1-8-1-previews-support-for-accelerated-training-on-amd-gpus-with-the-amd-rocm-open-software-platform/)，并通过自定义算子提供可扩展性。

简而言之，它让 AI 开发者能够充分利用自己熟悉的生态（比如 PyTorch 和 Hugging Face），并在自己选择的目标设备上使用 ONNX Runtime 的加速，从而同时节省时间和资源。

## Optimum 中的 ONNX Runtime Training

Optimum 提供了 `ORTTrainer` API，它扩展了 Transformers 中的 `Trainer`，以 ONNX Runtime 作为后端来实现加速。`ORTTrainer` 是一个易用的 API，包含功能完整的训练循环和评估循环。它支持超参数搜索、混合精度训练以及多 GPU 分布式训练等特性。`ORTTrainer` 让 AI 开发者在训练 Transformers 模型时可以把 ONNX Runtime 与其他第三方加速技术组合起来，从而进一步加速训练，把硬件的潜力用到极致。例如，开发者可以把 ONNX Runtime Training 与 Transformers 的 Trainer 中集成的分布式数据并行和混合精度训练结合使用。此外，`ORTTrainer` 让把 ONNX Runtime Training 与 DeepSpeed ZeRO-1 组合起来变得很简单，后者通过切分优化器状态来节省内存。预训练或微调完成后，开发者既可以保存训练好的 PyTorch 模型，也可以用 Optimum 为 ONNX Runtime 实现的 API 把它转换成 ONNX 格式，从而简化面向推理的部署。并且和 `Trainer` 一样，`ORTTrainer` 与 Hugging Face Hub 完全打通：训练结束后，用户可以把模型 checkpoint 上传到自己的 Hugging Face Hub 账户。

那么具体而言，用户要在 Optimum 中做些什么，才能享受到 ONNX Runtime 带来的训练加速？如果你已经在使用 `Trainer`，只需要改动几行代码，就能获得上面提到的全部改进。主要是两处替换。首先把 `Trainer` 换成 `ORTTrainer`，然后把 `TrainingArguments` 换成 `ORTTrainingArguments`，后者包含训练器在训练和评估中所使用的全部超参数。`ORTTrainingArguments` 扩展了 `TrainingArguments`，增加了若干由 ONNX Runtime 支撑的额外参数。例如，用户可以使用 Fused Adam Optimizer 以获得额外的性能提升。下面是一个例子：

```
-from transformers import Trainer, TrainingArguments
+from optimum.onnxruntime import ORTTrainer, ORTTrainingArguments

# Step 1: Define training arguments
-training_args = TrainingArguments(
+training_args = ORTTrainingArguments(
    output_dir="path/to/save/folder/",
-   optim = "adamw_hf",
+   optim = "adamw_ort_fused",
    ...
)

# Step 2: Create your ONNX Runtime Trainer
-trainer = Trainer(
+trainer = ORTTrainer(
    model=model,
    args=training_args,
    train_dataset=train_dataset,
+   feature="sequence-classification",
    ...
)

# Step 3: Use ONNX Runtime for training!🤗
trainer.train()
```

## 展望

Hugging Face 团队正在致力于开源更多大规模模型，并降低用户从这些模型中获益的门槛，让用户在训练和推理两方面都能用上加速工具。我们正在与 ONNX Runtime 训练团队合作，把更多训练优化带到更新的、更大规模的模型架构上，包括 Whisper 和 Stable Diffusion。微软也把它最先进的训练加速技术打包进了 [Azure Container for PyTorch](https://techcommunity.microsoft.com/t5/ai-machine-learning-blog/enabling-deep-learning-with-azure-container-for-pytorch-in-azure/ba-p/3650489)。这是一个轻量级、经过精心整理的环境，内含 DeepSpeed 和 ONNX Runtime，帮助使用 PyTorch 训练的 AI 开发者提升生产力。除了大模型训练，ONNX Runtime 训练团队还在为边缘侧的学习构建新的方案——在内存和功耗都受限的设备上进行训练。
