今天，我们在 Apache 2.0 许可证下开源 [Rumble-2-Flash](https://huggingface.co/Reson8/Rumble-2-Flash)。它是一个 0.5B 参数的语音识别模型，支持 40 多种语言，可与 3-60 倍大小的模型竞争。

- **在任何地方运行**：🤗 Transformers 和 vLLM 中的本机支持，无需自定义代码
- **40 多种语言**：自动语言检测
- **输出控制**：数字或单词、填充符、逐字重复、强制语言
- **极快**：大约半秒即可播放一小时的音频，全批次有超过 7,000 个 RTFx
- **支持真实通话**：在 302 小时呼叫中心基准测试中与 NVIDIA 的 Nemotron 3.5 Transcribe (30B) 相当

## 快速入门

使用 🤗 Transformers 进行转录
```
uv pip install torch transformers accelerate
```

```
from transformers import AutoProcessor, AutoModelForMultimodalLM

model_id = "Reson8/Rumble-2-Flash"
processor = AutoProcessor.from_pretrained(model_id)
model = AutoModelForMultimodalLM.from_pretrained(model_id, device_map="auto")

inputs = processor.apply_transcription_request(
    audio="https://hf.co/datasets/hf-internal-testing/dummy-audio-samples/resolve/main/bcn_weather.mp3",
    language="English",  # omit to detect automatically
).to(model.device, dtype=model.dtype)

output = model.generate(**inputs, max_new_tokens=512)
generated = output[:, inputs["input_ids"].shape[-1]:]
print(processor.decode(generated, return_format="transcription_only")[0])  # return_format="parsed" if detecting language
```
`audio` 接受本地路径、URL、NumPy 数组或这些的列表。

## 它是如何构建的

Rumble-2-Flash 使用 Qwen3-ASR 架构来支持 day-0。如果您的堆栈运行 Transformers 或 vLLM，它将运行 Rumble-2-Flash，没有分叉运行时或 `trust_remote_code`。

为了找出模型在精度下降之前可以达到多小，我们通过策略蒸馏将较大的生产模型 Rumble-2 提炼到其中。学生不根据老师写的成绩单进行训练。它会转录音频本身，老师会逐个标记地对转录内容进行评分：在每个位置，它都会给出接下来发生的情况的概率，而学生则学会匹配它。因为学生从自己的输出中学习，所以它会准确地纠正自己所犯的错误，并针对每个标记提供反馈，而不是每个剪辑一个分数。

在政策蒸馏通常要求教师和学生共享标记器，而我们的不需要：选择 Qwen3-ASR 也意味着采用它的词汇表。 [GOLD](https://huggingface.co/spaces/HuggingFaceH4/on-policy-distillation) 消除了该限制。它合并两个标记器以不同方式分割文本的标记，因此两个模型都在相同的文本上进行比较。直接比较两个词汇表中存在的标记，其余标记按其排序概率进行比较。

使用 GOLD 进行策略蒸馏

## 结果

### 尺寸精度

在开放 ASR 排行榜 [多语言](https://huggingface.co/spaces/hf-audio/open_asr_leaderboard?languages=Reson8%2FRumble-2-Flash&proprietary=false) 赛道上，Rumble-2-Flash 在中文、德语、法语、意大利语、西班牙语、葡萄牙语、印地语、荷兰语和英语方面的平均错误率为 **6.96%**。这比 Meta 的omniASR-LLM 7B 更好，模型大 15 倍，并且领先于 Whisper large-v3。在 [English](https://huggingface.co/spaces/hf-audio/open_asr_leaderboard) 赛道上，平均成绩为 **6.6% WER**。

其尺寸的最佳得分

### 速度

Rumble-2-Flash 也很快。其吞吐量取决于批次的满度：在 HF 开放 ASR 排行榜中的较大数据集上，批次保持满状态，它达到 **超过 7,000 RTFx**。大约半秒就可以播放一个小时的音频。

### 真实的电话

干净的音频很容易。电话通话压缩且嘈杂，并且说话者的口音通常截然不同。在 [AppTek 的呼叫中心基准测试](https://huggingface.co/datasets/apptek-com/apptek_callcenter_dialogues) 上（302 小时的帮助热线电话，14 种英语口音，用 AppTek 自己的脚本评分），Rumble-2-Flash 达到 **7.86% WER**，与 NVIDIA 的 Nemotron 3.5 Transcribe (30B) 的 7.78% 相当。这远远领先于同一型号系列的 Qwen3-ASR 0.6B (8.7%)，并且接近 Qwen3-ASR 1.7B (7.4%)，这是比较中唯一表现更好的型号。

真实通话，14种英语口音
