# 全新数据集搜索功能发布

AI 与 ML 社区已经在 [Hugging Face Dataset Hub](https://huggingface.co/datasets) 上分享了超过 18 万个公开数据集。研究者和工程师们把这些数据用于各种任务——从训练与用户对话的 LLM，到评估自动语音识别或计算机视觉系统。数据集的可发现性与可视化，是让 AI 构建者能够找到、探索并把数据改造成适合自己用例的关键挑战。

在 Hugging Face，我们把 Dataset Hub 建设成社区协作开放数据的地方，因此构建了 Dataset Search、Dataset Viewer 等工具，以及丰富的开源工具生态。今天我们要宣布四项新功能，把 Hub 上的 Dataset Search 带到新的水平。

## 按模态搜索

数据集的模态（modality）对应数据集中的数据类型。例如，Hugging Face 上最常见的数据类型是文本、图像、音频和表格数据。

我们发布了一组过滤器，让你可以从下列列表中筛选含有一种或多种模态的数据集：

- Text（文本）
- Image（图像）
- Audio（音频）
- Tabular（表格）
- Time-Series（时间序列）
- 3D
- Video（视频）
- Geospatial（地理空间）

例如，可以查找[同时包含文本和图像数据的数据集](https://huggingface.co/datasets?modality=modality:3d&sort=trending)：

[![search by modality example](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/datasets-filters/image_and_text.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/datasets-filters/image_and_text.png)

每个数据集的模态会基于文件内容和扩展名自动检测。

## 按规模搜索

我们最近在界面上发布了新功能，展示每个数据集的行数：

[![number of rows of each dataset](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/datasets-filters/datasets_sizes_in_overview.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/datasets-filters/datasets_sizes_in_overview.png)

在此基础上，现在可以按行数搜索数据集：指定行数的最小值和最大值。这将让你从小型数据集一直找到现存最大的数据集（例如用于预训练 LLM 的那些）。

[受支持格式](https://huggingface.co/docs/hub/datasets-adding#file-formats)的所有数据集都提供行数信息。即使是对元数据中不含行数的最大规模数据集，总行数也会基于前 5GB 内容精确估计。

例如，如果你想看 Hugging Face 上行数最多的数据集，可以查找[行数超过 10B（10¹⁰）的数据集](https://huggingface.co/datasets?size_categories=or:%28size_categories:10B%3Cn%3C100B,size_categories:100B%3Cn%3C1T,size_categories:n%3E1T%29&sort=trending)：

[![biggest datasets](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/datasets-filters/biggest_datasets.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/datasets-filters/biggest_datasets.png)

## 按格式搜索

同一个数据集可以以许多不同格式存储。例如，文本数据集常是 Parquet 或 JSON Lines，但也可能是纯文本文件；图像数据集常常是单个图像目录，但也可能是 [WebDataset 格式](https://huggingface.co/docs/hub/datasets-webdataset)（一种基于 TAR 归档的格式）。

每种格式各有优缺点。例如，与 CSV 不同，Parquet 支持嵌套数据、具备高效过滤/分析能力和良好的压缩率，但访问特定一行需要解码整个 row group。又如 WebDataset 拥有最快的数据流式读取速度，但缺少一些元数据（例如每个文件的行数），而这些元数据在多节点训练环境中高效分发数据时往往是必需的。

因此，数据集格式表明了它偏向哪些用例，以及你是否需要重新格式化数据以满足需求。

这里可以看到 [WebDataset 格式的数据集](https://huggingface.co/datasets?format=format:webdataset&sort=trending)：

[![webdatasets](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/datasets-filters/webdatasets.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/datasets-filters/webdatasets.png)

## 按库搜索

加载数据集并做训练准备的优秀库和工具有很多，如 Pandas、Dask 或 🤗 Datasets 库。Hub 允许你使用自己喜爱的工具，并筛选与任意库兼容的数据集。例如，你可以查找[与 Pandas 兼容的数据集](https://huggingface.co/datasets?library=library:pandas&sort=trending)：

[![pandas compatible datasets](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/datasets-filters/pandas_datasets.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/datasets-filters/pandas_datasets.png)

数据集兼容性基于数据集的格式和规模（例如 Dask 可以加载大型 JSON Lines 数据集，而 Pandas 需要把整个数据集载入内存）。除此之外，我们还提供了用你最喜爱的工具加载任何数据集的代码片段：

[![load fineweb-edu in dask](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/datasets-filters/dask_fineweb_edu.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/datasets-filters/dask_fineweb_edu.png)

如果你希望自己的库出现在受支持库的列表中，欢迎在 [huggingface.js](https://github.com/huggingface/huggingface.js/issues) 上开启讨论！

## 组合过滤器

这四种新的 Dataset Search 工具可以一起使用，也可以与语言、任务、许可证等既有过滤器组合。把这些过滤器和文本搜索栏结合，你就能找到自己正在寻找的特定数据集：

[![search for a webdataset of images of pdf](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/datasets-filters/dataset_cars.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/datasets-filters/dataset_cars.png)
