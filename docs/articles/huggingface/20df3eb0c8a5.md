# Hugging Face 上的推理方案概览

每天都有开发者和组织采用托管在 [Hugging Face](https://huggingface.co/models) 上的模型，把想法变成概念验证演示，再把演示变成生产级应用。例如，Transformer 模型已成为众多机器学习（ML）应用的流行架构，涵盖自然语言处理、计算机视觉、语音等。最近，diffusers（扩散模型）又成为文本生成图像、图像生成图像任务的流行架构。还有其他架构在各自任务上很受欢迎，而我们在 HF Hub 上全都托管！

在 Hugging Face，我们痴迷于在不牺牲最先进质量的前提下简化 ML 开发与运维。就此而言，能够以最小的阻力测试和部署最新模型，贯穿一个 ML 项目的整个生命周期，至关重要。优化性价比同样重要，我们要感谢 [Intel](https://huggingface.co/intel) 的朋友们赞助我们免费的基于 CPU 的推理方案。这是我们[合作伙伴关系](https://huggingface.co/blog/intel)中又一个重要里程碑。这对我们的用户社区也是好消息——他们现在可以零成本享受 [Intel Xeon Ice Lake](https://www.intel.com/content/www/us/en/products/docs/processors/xeon/3rd-gen-xeon-scalable-processors-brief.html) 架构带来的加速。

现在，让我们来梳理一下你在 Hugging Face 上的推理选项。

## 免费推理小组件（Inference Widget）

我在 Hugging Face hub 上最喜欢的功能之一，就是模型页面上的推理 [Widget](https://huggingface.co/docs/hub/models-widgets)。Inference Widget 让你上传示例数据并一键完成预测。

这是用 `sentence-transformers/all-MiniLM-L6-v2` [模型](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2)做的一个句子相似度示例：

它是快速了解一个模型做什么、输出长什么样、以及在你数据的几个样本上表现如何的最佳方式。模型按需加载到我们的服务器上，不再需要时便卸载。你无需编写任何代码，而且该功能免费。有什么理由不爱呢？

## 免费推理 API

[Inference API](https://huggingface.co/docs/api-inference/) 正是在底层驱动推理 Widget 的服务。只需一个简单的 HTTP 请求，你就能加载任意 hub 上的模型，并在几秒内用它预测你的数据。模型 URL 和一个有效的 hub token 就是全部所需。

下面是我用一行命令加载并用 `xlm-roberta-base` [模型](https://huggingface.co/xlm-roberta-base)做预测的方式：

```
curl https://api-inference.huggingface.co/models/xlm-roberta-base \
    -X POST \
    -d '{"inputs": "The answer to the universe is <mask>."}' \
    -H "Authorization: Bearer HF_TOKEN"
```

Inference API 是构建预测服务的最简方式，你在开发和测试期间可以立即从应用中调用它。不需要定制 API，也不需要模型服务器。此外，你可以随时从一个模型切换到下一个，比较它们在你应用中的表现。而且你猜怎么着？Inference API 免费使用。

由于会实施速率限制，我们不推荐把 Inference API 用于生产。相反，你应该考虑 Inference Endpoints。

## 用 Inference Endpoints 做生产

一旦你对 ML 模型的性能满意，就该把它部署到生产环境了。不幸的是，一旦离开沙箱，一切问题都随之而来：安全、扩展、监控等等。这正是许多 ML 项目磕绊甚至翻车的地方。我们打造 [Inference Endpoints](https://huggingface.co/inference-endpoints) 就是为了解决这个问题。

只需几次点击，Inference Endpoints 就能让你在安全、可弹性扩展的基础设施上部署任意 hub 模型，托管在你选择的 AWS 或 Azure 区域。其他配置项还包括 CPU 与 GPU 托管、内建自动扩缩容等。这使得找到合适的性价比变得简单，[定价](https://huggingface.co/pricing#endpoints)低至每小时 $0.06 起。

Inference Endpoints 支持三种安全级别：

- Public（公开）：端点运行在公开的 Hugging Face 子网中，互联网上的任何人都可以在无需认证的情况下访问。
- Protected（受保护）：端点运行在公开的 Hugging Face 子网中，互联网上任何持有恰当 Hugging Face token 的人都可以访问。
- Private（私有）：端点运行在私有的 Hugging Face 子网中，在互联网上不可访问，只能通过你 AWS 或 Azure 账户中的私有连接访问。这能满足最严格的合规要求。

要了解 Inference Endpoints 的更多信息，请阅读这篇[教程](https://huggingface.co/blog/inference-endpoints)和[文档](https://huggingface.co/docs/inference-endpoints/)。

## Spaces

最后，Spaces 是另一个可用于生产的方式，让你在简单的 UI 框架（例如 Gradio）之上部署模型做推理；我们也支持[硬件升级](https://huggingface.co/docs/hub/spaces-gpus)，如高级 Intel CPU 和 NVIDIA GPU。没有比这更好的模型演示方式了！

要了解 Spaces 的更多信息，请查看[文档](https://huggingface.co/docs/hub/spaces)，也欢迎在我们的[论坛](https://discuss.huggingface.co/c/spaces/24)浏览帖子或提问。

## 开始使用

再简单不过了。只需登录 Hugging Face [hub](https://huggingface.co/)，浏览我们的[模型](https://huggingface.co/models)。找到你喜欢的一个后，就可以直接在页面上试用 Inference Widget。点击 "Deploy" 按钮，你会得到自动生成的代码，把模型部署到免费的 Inference API 上做评估，同时还有直接用 Inference Endpoints 或 Spaces 把它部署到生产的链接。

欢迎试一试，并告诉我们你的看法。我们很乐意在 Hugging Face [论坛](https://discuss.huggingface.co/)上读到你的反馈。
