# 欢迎 Fireworks.ai 加入 Hub 🎆

继我们近期宣布 [Hub 上的 Inference Providers](https://huggingface.co/blog/inference-providers)之后，我们很高兴分享：**Fireworks.ai** 现已成为 HF Hub 支持的 Inference Provider！

[Fireworks.ai](https://fireworks.ai) 在模型页面直接提供极速的 serverless 推理，并贯穿整个 HF 库与工具生态，让在你喜欢的模型上跑推理前所未有地简单。

从现在开始，你可以通过 Fireworks.ai 对以下模型运行 serverless 推理（除其他之外）：

- [deepseek-ai/DeepSeek-R1](https://huggingface.co/deepseek-ai/DeepSeek-R1)
- [deepseek-ai/DeepSeek-V3](https://huggingface.co/deepseek-ai/DeepSeek-V3)
- [mistralai/Mistral-Small-24B-Instruct-2501](https://huggingface.co/mistralai/Mistral-Small-24B-Instruct-2501)
- [Qwen/Qwen2.5-Coder-32B-Instruct](https://huggingface.co/Qwen/Qwen2.5-Coder-32B-Instruct)
- [meta-llama/Llama-3.2-90B-Vision-Instruct](https://huggingface.co/meta-llama/Llama-3.2-90B-Vision-Instruct)

还有更多，完整列表见[这里](https://huggingface.co/models?inference_provider=fireworks-ai)。

今天就用 Fireworks.ai 点亮你的项目吧！

## 工作原理

### 在网站 UI 中

[![Fireworks.ai inference provider UI](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/inference-providers/fireworks.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/inference-providers/fireworks.png)

在 HF 上搜索 Fireworks 支持的全部模型请见[这里](https://huggingface.co/models?inference_provider=fireworks-ai)。

### 从客户端 SDK

#### 用 Python 与 huggingface_hub

下面示例展示如何用 Fireworks.ai 作为推理提供方使用 DeepSeek-R1。你可以用 [Hugging Face token](https://huggingface.co/settings/tokens)经由 Hugging Face 自动路由，或使用你自己的 Fireworks.ai API key（如果你有）。

从源码安装 `huggingface_hub`：

```
pip install git+https://github.com/huggingface/huggingface_hub
```

使用 `huggingface_hub` Python 库调用 Fireworks.ai 端点，只需定义 `provider` 参数。

```
from huggingface_hub import InferenceClient

client = InferenceClient(
    provider="fireworks-ai",
    api_key="xxxxxxxxxxxxxxxxxxxxxxxx"
)

messages = [
    {
        "role": "user",
        "content": "What is the capital of France?"
    }
]

completion = client.chat.completions.create(
    model="deepseek-ai/DeepSeek-R1", 
    messages=messages, 
    max_tokens=500
)

print(completion.choices[0].message)
```

#### 用 JS 与 @huggingface/inference

```
import { HfInference } from "@huggingface/inference";

const client = new HfInference("xxxxxxxxxxxxxxxxxxxxxxxx");

const chatCompletion = await client.chatCompletion({
    model: "deepseek-ai/DeepSeek-R1",
    messages: [
        {
            role: "user",
            content: "How to make extremely spicy Mayonnaise?"
        }
    ],
    provider: "fireworks-ai",
    max_tokens: 500
});

console.log(chatCompletion.choices[0].message);
```

### 通过 HTTP 调用

下面是以 Fireworks.ai 作为推理提供方，用 cURL 调用 Llama-3.3-70B-Instruct 的方式。

```
curl 'https://router.huggingface.co/fireworks-ai/v1/chat/completions' \
-H 'Authorization: Bearer xxxxxxxxxxxxxxxxxxxxxxxx' \
-H 'Content-Type: application/json' \
--data '{
    "model": "accounts/fireworks/models/llama-v3p3-70b-instruct",
    "messages": [
        {
            "role": "user",
            "content": "What is the meaning of life if you were a dog?"
        }
    ],
    "max_tokens": 500,
    "stream": false
}'
```
