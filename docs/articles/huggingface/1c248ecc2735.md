# 展翅高飞：Falcon 180B 来了

## 引言

**今天，我们非常高兴地欢迎 [TII](https://falconllm.tii.ae/) 的 Falcon 180B 加入 Hugging Face！** Falcon 180B 为开放模型树立了新的最先进水平。它是目前最大的开放可用语言模型，拥有 1800 亿参数，使用 TII 的 [RefinedWeb](https://huggingface.co/datasets/tiiuae/falcon-refinedweb) 数据集在庞大的 3.5 万亿 token 上完成训练。这是开放模型最长的单轮（single-epoch）预训练。

你可以在 Hugging Face Hub 上找到模型（[基座模型](https://huggingface.co/tiiuae/falcon-180B)和 [chat 模型](https://huggingface.co/tiiuae/falcon-180B-chat)），并在 [Falcon Chat Demo Space](https://huggingface.co/spaces/tiiuae/falcon-180b-chat) 中与模型互动。

在能力方面，Falcon 180B 在各类自然语言任务上取得了最先进水平的成绩。它在（预训练）开放访问模型排行榜上登顶（发布于其发布之时），可与 PaLM-2 等专有模型一较高下。虽然现在还难以给出定论式的排名，但普遍认为它与 PaLM-2 Large 处于同一水平，这使 Falcon 180B 成为公开已知的最强 LLM 之一。

在这篇博客中，我们将通过一些评测结果探讨 Falcon 180B 为什么这么强，并演示如何使用这个模型。

## Falcon-180B 是什么？

Falcon 180B 是 [TII](https://falconllm.tii.ae/) 发布的模型，延续了 Falcon 家族此前的几个版本。

从架构上看，Falcon 180B 是 [Falcon 40B](https://huggingface.co/tiiuae/falcon-40b) 的放大版，并沿用了它的创新设计，比如用于提升可扩展性的 multiquery 注意力。建议先阅读介绍 Falcon 的[首篇博客](https://huggingface.co/blog/falcon)以深入了解架构。Falcon 180B 在最多 4096 块 GPU 上并行训练了 3.5 万亿 token，使用 Amazon SageMaker，总计约 7,000,000 GPU 小时。也就是说，Falcon 180B 比 Llama 2 大 2.5 倍，训练算力是它的 4 倍。

Falcon 180B 的数据集以来自 [RefinedWeb](https://arxiv.org/abs/2306.01116) 的网络数据为主（约 85%）。此外，它还在一个精选数据混合集上训练，包括对话、技术论文以及少量代码（约 3%）。这份预训练数据集体量足够大，即便 3.5 万亿 token 也还不到一个 epoch。

发布的 [chat 模型](https://huggingface.co/tiiuae/falcon-180B-chat)在聊天与指令数据集上进行了微调，其数据是多个大规模对话数据集的混合。

‼️ 商业使用：Falcon 180B 可以商用，但条件非常严格，排除了任何"托管用途"。如果你有意将其用于商业目的，建议查看[许可证](https://huggingface.co/spaces/tiiuae/falcon-180b-license/blob/main/LICENSE.txt)并咨询你的法务团队。

## Falcon 180B 有多强？

Falcon 180B 在其发布时是公开发布的最佳 LLM，在 MMLU 上超过 Llama 2 70B 和 OpenAI 的 GPT-3.5；在 HellaSwag、LAMBADA、WebQuestions、Winogrande、PIQA、ARC、BoolQ、CB、COPA、RTE、WiC、WSC、ReCoRD 上与 Google 的 PaLM 2-Large 打成平手。根据具体评测基准，Falcon 180B 大致落在 GPT 3.5 与 GPT4 之间。既然它已经开放发布，接下来社区的微调非常值得期待。

[![Palm 2 对比](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/162_falcon_180b/palm2_480.jpg)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/162_falcon_180b/palm2_480.jpg)

在发布时，Falcon 180B 以 68.74 分位居 Hugging Face 排行榜首位，是得分最高的开放发布预训练 LLM，超过了 Meta 的 Llama 2。*

## 如何使用 Falcon 180B？

Falcon 180B 已进入 Hugging Face 生态，从 Transformers 4.33 版本起支持。

### 演示

你可以轻松在 [这个 Space](https://huggingface.co/spaces/tiiuae/falcon-180b-demo) 中试用这只巨大的 Falcon 模型（1800 亿参数！），也可以直接用下方嵌入的 playground。

### 硬件要求

我们针对不同的使用场景，测试了运行模型所需的硬件。这些不是绝对的最小值，而是我们所能获取的配置里的最小值。

### 提示词格式

基座模型没有提示词格式。请记住，它不是对话模型，也没有用指令训练，所以不要指望它能生成对话式回复——预训练模型是进一步微调的绝佳平台，但你不应该直接开箱使用它。Chat 模型则有一个非常简单的对话结构。

```
System: Add an optional system prompt here
User: This is the user input
Falcon: This is what the model generates
User: This might be a second turn input
Falcon: and so on
```

### Transformers

随着 Transformers 4.33 的发布，你可以使用 Falcon 180B 并借助 HF 生态中的所有工具，例如：

- 训练与推理脚本及示例
- 安全的文件格式（safetensors）
- 与 bitsandbytes（4-bit 量化）、PEFT（参数高效微调）和 GPTQ 等工具的集成
- 辅助生成（也称"投机解码"）
- 支持更大上下文长度的 RoPE 缩放
- 丰富而强大的生成参数

使用该模型需要你接受其许可证与使用条款。请确保你已登录 Hugging Face 账户，并安装最新版本的 `transformers`：

```
pip install --upgrade transformers
huggingface-cli login
```

#### bfloat16

下面是在 `bfloat16` 下使用基座模型的方式。Falcon 180B 是个大模型，请以上表的硬件要求为准。

```
from transformers import AutoTokenizer, AutoModelForCausalLM
import transformers
import torch

model_id = "tiiuae/falcon-180B"

tokenizer = AutoTokenizer.from_pretrained(model_id)
model = AutoModelForCausalLM.from_pretrained(
    model_id,
    torch_dtype=torch.bfloat16,
    device_map="auto",
)

prompt = "My name is Pedro, I live in"
inputs = tokenizer(prompt, return_tensors="pt").to("cuda")

output = model.generate(
    input_ids=inputs["input_ids"],
    attention_mask=inputs["attention_mask"],
    do_sample=True,
    temperature=0.6,
    top_p=0.9,
    max_new_tokens=50,
)
output = output[0].to("cpu")
print(tokenizer.decode(output))
```

输出可能类似：

```
My name is Pedro, I live in Portugal and I am 25 years old. I am a graphic designer, but I am also passionate about photography and video.
I love to travel and I am always looking for new adventures. I love to meet new people and explore new places.
```

#### 用 `bitsandbytes` 做 8-bit 与 4-bit

Falcon 180B 的 8-bit 和 4-bit 量化版本在评测上与 `bfloat16` 基准几乎看不出差别！这对推理是很好的消息，你可以放心使用量化版本来降低硬件要求。不过要记住，8-bit 推理比 `4-bit` 运行要*快得多*。

要使用量化，你需要安装 `bitsandbytes` 库，并在加载模型时简单地开启对应的开关：

```
model = AutoModelForCausalLM.from_pretrained(
    model_id,
    torch_dtype=torch.bfloat16,
    load_in_8bit=True,
    device_map="auto",
)
```

#### Chat 模型

如上所述，经过对话微调的模型版本使用了一个非常直接的训练模板。要进行 chat 风格的推理，我们必须遵循同样的模式。作为参考，可以查看 Chat 演示中的 [format_prompt](https://huggingface.co/spaces/tiiuae/falcon-180b-demo/blob/main/app.py#L28) 函数，它长这样：

```
def format_prompt(message, history, system_prompt):
    prompt = ""
    if system_prompt:
        prompt += f"System: {system_prompt}\n"
    for user_prompt, bot_response in history:
        prompt += f"User: {user_prompt}\n"
        prompt += f"Falcon: {bot_response}\n"
        prompt += f"User: {message}\nFalcon:"
    return prompt
```

可以看到，用户的输入和模型的回答分别以 `User: ` 和 `Falcon: ` 作为前缀分隔。我们把它们拼接起来，形成包含整段对话历史的提示词。我们还可以提供系统提示词来调整生成风格。
