# 为数据集和模型推出 DOI：数字对象唯一标识符

我们在 Hugging Face 的使命是让优质机器学习走向民主化。这其中包括让 ML 模型和数据集更易复现、文档更完善、更易于使用和共享的最佳实践。

为了应对这一挑战，**我们高兴地宣布，你现在可以直接从 Hub 为你的模型或数据集生成 DOI**！

[![](https://huggingface.co/blog/assets/107_launching_doi/repo-settings.png)](https://huggingface.co/blog/assets/107_launching_doi/repo-settings.png)

DOI 可以直接在你的仓库设置中生成，此后任何人都可以在你的模型或数据集页面上点击"Cite this model/dataset"（引用此模型/数据集）来引用你的工作 🔥。

## 简说 DOI，以及它为何重要？

DOI（Digital Object Identifier，数字对象唯一标识符）是唯一标识某个数字对象的一串字符，对象可以是文章、图表，也包括数据集和模型。DOI 与对象的元数据绑定，包括对象的 URL、版本、创建日期、描述等。它是研究与学术社区普遍认可的数字资源引用方式，作用类似书籍的 ISBN。

DOI 让查找某个模型或数据集的信息更容易，也让它们通过一个永不失效、永不变化的永久链接与世界共享。因此，拥有 DOI 的数据集/模型被设计为永久留存，只有在向我们的支持团队提交删除申请后才可能被删除。

## Hugging Face 如何分配 DOI？

我们与 [DataCite](https://datacite.org) 建立合作，允许已注册的 Hub 用户为其模型或数据集申请 DOI。填好必要的元数据后，你就能获得一个崭新的 DOI 🌟！

如果模型或数据集发布了新版本，DOI 可以轻松更新，旧版本的 DOI 会相应失效。这使得引用某个对象的特定版本变得简单，即使该对象已经发生变化。
