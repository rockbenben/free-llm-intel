# 🇵🇭 FilBench——LLM 能理解和生成菲律宾语吗？

本文由 Lj V. Miranda、Elyanah Aco、Conner Manuel、Jan Christian Blaise Cruz、Joseph Imperial（客座作者与 SEACrowd 成员）等共同撰写。

随着大语言模型（LLM）日益融入我们的生活，评估它们能否反映特定语言社区的细微差别与能力变得至关重要。例如，菲律宾人是全球最活跃的 ChatGPT 用户群体之一，ChatGPT 流量排名世界第四（仅次于美国、印度和巴西[[1](https://blogs.worldbank.org/en/digital-development/who-on-earth-is-using-generative-ai-)] [[2](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=4715603)]），但尽管使用量这么大，我们对 LLM 在其语言（如 Tagalog 和 Cebuano）上的表现仍缺乏清晰的认识。现有证据大多只是轶事式的，比如用 ChatGPT 以菲律宾语作答的截图来证明它足够流利。我们真正需要的，是对 LLM 在菲律宾语言上能力的系统性评估。

正因如此，我们开发了 FilBench：一套全面的评估套件，用于评估 LLM 在 Tagalog、Filipino（Tagalog 的标准化形式）和 Cebuano 上的能力，覆盖语言流利度、语言学与翻译能力，以及特定的文化知识。

我们用 FilBench 评估了 20 多个最先进的 LLM，对其在菲律宾语言上的表现做了全面测评：

- 📄 论文：[https://arxiv.org/abs/2508.03523](https://arxiv.org/abs/2508.03523)
- 🖥️ GitHub：[https://github.com/filbench/filbench-eval](https://github.com/filbench/filbench-eval)

## FilBench

FilBench 评估套件包含四大类别——文化知识（Cultural Knowledge）、经典 NLP（Classical NLP）、阅读理解（Reading Comprehension）与生成（Generation）——细分为 12 个任务。例如，经典 NLP 类别包含情感分析等任务，而生成任务则涵盖翻译的不同侧面。为确保这些类别能反映 NLP 研究与使用中的优先方向和趋势，我们基于对 2006 年至 2024 年初菲律宾语言 NLP 研究的历史综述来整理这些类别。（这些类别中大多数内容仅包含非翻译材料，以忠于菲律宾语言的自然使用。）

- **文化知识**：该类别测试语言模型回忆事实性和特定文化知识的能力。在文化知识方面，我们整理了多种示例，测试 LLM 的地区与事实知识（Global-MMLU）、以菲律宾为中心的价值观念（KALAHI），以及词义消歧能力（StingrayBench）。
- **经典 NLP**：该类别涵盖各种信息抽取与语言任务，例如命名实体识别、情感分析和文本分类——这些过去通常由专门训练的模型完成。该类别包含用于命名实体识别的 CebuaNER、TLUnified-NER 和 Universal NER 的实例，以及用于文本分类与情感分析的 SIB-200 和 BalitaNLP 子集。
- **阅读理解**：该类别评估语言模型理解与解读菲律宾语文本的能力，聚焦于可读性、理解与自然语言推理等任务。该类别包含 Cebuano Readability Corpus、Belebele 和 NewsPH NLI 的实例。
- **生成**：我们把 FilBench 的很大一部分用于测试 LLM 忠实翻译文本的能力，既包括英译菲，也包括 Cebuano 译英。我们纳入了多样化的测试样本，从文档（NTREX-128）、志愿者提供的真实文本（Tatoeba）到领域特定文本（TICO-19）。

每个类别都提供一个聚合指标。为得到一个有代表性的单一分数，我们按各类别样本数量计算加权平均，称之为 FilBench Score。

为了简化使用和环境搭建，我们基于 [Lighteval](https://github.com/huggingface/lighteval) 构建了 FilBench——这是一个一体化的 LLM 评估框架。针对特定语言的评估，我们首先为评估中常用的术语定义了英语到 Tagalog（或 Cebuano）的翻译对，例如 "yes"（*oo*）、"no"（*hindi*）、"true"（*totoo*）等。然后，我们使用提供的模板为我们关心的能力实现自定义任务。

FilBench 现在已作为一组社区任务提供，已进入官方 Lighteval 仓库！

## 我们从 FilBench 学到了什么？

通过在 FilBench 上评估多个 LLM，我们揭示了它们在菲律宾语上的若干表现洞察。

### 发现 #1：尽管特定地区 LLM 仍落后于 GPT-4，但为这些模型收集数据仍是很有前景的方向

过去几年，我们看到面向东南亚语言（SEA-specific）的特定地区 LLM 不断增多，例如 SEA-LION 和 SeaLLM。这些是可以从 HuggingFace 自由下载的开放权重 LLM。我们发现，SEA 特定 LLM 在我们的语言上往往是参数效率最高的，在同等规模模型中取得最高的 FilBench 分数。不过，最好的 SEA 特定模型仍然不敌 GPT-4o 这类闭源 LLM。

构建特定地区 LLM 依然有意义，因为我们观察到：用 SEA 特定的指令微调数据对 base LLM 做持续微调，可以带来 2–3% 的性能提升。这表明**持续整理菲律宾/SEA 特定微调训练数据的努力仍然有价值**，因为它们能带来更好的 FilBench 表现。

### 发现 #2：菲律宾语翻译对 LLM 来说仍然是难题

我们还观察到，在 FilBench 的四个类别中，大多数模型在生成能力上表现挣扎。检查生成的失败模式后，我们发现这些情况包括：模型未能遵循翻译指令、生成过于啰嗦的文本，或者产生幻觉而输出了 Tagalog 或 Cebuano 之外的另一种语言。

### 发现 #3：开放 LLM 仍是菲律宾语言任务的高性价比选择

菲律宾的互联网基础设施往往较为有限、平均收入较低[[3](https://unesdoc.unesco.org/ark:/48223/pf0000393860?posInSet=1&queryId=cb72b22d-9dd3-44cd-9090-c4c89328a09c)]，这要求 LLM 具备可及性且在成本和算力上都高效。通过 FilBench，我们能够识别出处于效率帕累托前沿的 LLM。

总体而言，我们发现开放权重 LLM（即可以从 HuggingFace 自由下载的模型）比商用模型便宜得多，同时不牺牲性能。如果你想为菲律宾语言任务找一个 GPT-4o 的替代方案，那就试试 Llama 4 Maverick！

我们也在 FilBench 排行榜的 HuggingFace space 中公开了这些信息。

## 你的 LLM 支持菲律宾语言吗？来 FilBench 上试试！

我们希望 FilBench 能为 LLM 在菲律宾语言上的能力提供更深入的洞察，并成为推动菲律宾 NLP 研究与开发的催化剂。FilBench 评估套件构建在 Hugging Face 的 lighteval 之上，让 LLM 开发者可以轻松在我们的基准上评估自己的模型。更多信息请访问以下链接：
