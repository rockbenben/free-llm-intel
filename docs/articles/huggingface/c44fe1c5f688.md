LLM-as-a-Judge 已成为给 LLM 应用的自然语言输出打分的流行方式，**但我们怎么知道哪些模型是最好的评审**？

我们很高兴推出 [Judge Arena](https://huggingface.co/spaces/AtlaAI/judge-arena)——一个让任何人轻松并排比较「模型当评审」的平台。只要让评审们跑一个测试样本，投票你最认同哪一位评审。结果会被汇总成一个展示最佳评审的排行榜。

## Judge Arena

众包、随机的对战已被证明是基准测试 LLM 的有效方式。LMSys 的 Chatbot Arena 已收集超过 200 万张选票，并作为识别最强语言模型的实地检验而[备受赞誉](https://x.com/karpathy/status/1737544497016578453)。既然 LLM 评估的目的在于捕捉人类偏好，那么直接的人类反馈同样是判断哪些 AI 评审最有用的关键。

### 工作原理

- 选择你要评估的样本：

- 让系统随机生成一对 👩 用户输入 / 🤖 AI 回答
- 或者输入你自己的自定义样本

- 两位 LLM 评审会：

- 给回答打分
- 给出打分的理由

- 查看两位评审的评估，投票给最符合你判断的那位 *（我们建议先比对分数，再比较评语）*

每次投票后，你可以：

- **重新生成评审：** 对同一样本获得新的评估
- 开始一轮 **🎲 新局：** 随机生成一个新的待评估样本
- 或者输入一个新的自定义样本待评估

为了避免偏见和潜在的操纵，模型名称只在投票提交之后才揭晓。

## 入选模型

Judge Arena 聚焦 LLM-as-a-Judge 方法，因此只收录生成式模型（不包含只输出分数的分类器模型）。我们把 AI 评审的入选标准形式化为：

- **模型应能同时有效地对其他模型的输出打分和点评。**
- **模型应能通过 prompt 按不同评分格式、针对不同标准进行评估。**

我们为排行榜挑选了 18 个最先进的 LLM。其中许多是公开权重的开源模型，我们也加入了专有 API 模型，以便直接比较开放与封闭两种路线。

- **OpenAI**（GPT-4o、GPT-4 Turbo、GPT-3.5 Turbo）
- **Anthropic**（Claude 3.5 Sonnet / Haiku、Claude 3 Opus / Sonnet / Haiku）
- **Meta**（Llama 3.1 Instruct Turbo 405B / 70B / 8B）
- **阿里巴巴**（Qwen 2.5 Instruct Turbo 7B / 72B、Qwen 2 Instruct 72B）
- **Google**（Gemma 2 9B / 27B）
- **Mistral**（Instruct v0.3 7B、Instruct v0.1 7B）

当前这份列表代表 AI 评估流水线中最常用的模型。如果我们的排行榜被证明有用，我们期待加入更多模型。

## 排行榜

Judge Arena 收集的选票将被汇总并展示在一个专门的公开排行榜上。我们为每个模型计算 [Elo 分数](https://en.wikipedia.org/wiki/Elo_rating_system)，并每小时更新排行榜。

## 早期洞见

这些结果还非常初步，但以下是我们迄今的观察：

- **专有与开源头部混战**：GPT-4 Turbo 以微弱领先，但 Llama 和 Qwen 模型极具竞争力，超越了大多数专有模型
- **小模型表现亮眼：** Qwen 2.5 7B 和 Llama 3.1 8B 表现出色，足以与大得多的模型竞争。随着数据增多，我们希望能更好地理解模型规模与评审能力之间的关系
- **对新兴研究的初步实证支持**：LLM-as-a-Judge 文献表明 Llama 模型适合作为基座模型，在评估基准上展现出很强的开箱即用性能。包括 [Lynx](https://arxiv.org/pdf/2407.08488)、[Auto-J](https://arxiv.org/pdf/2310.05470) 和 [SFR-LLaMA-3.1-Judge](https://arxiv.org/pdf/2409.14664) 在内的多种方法，都选择从 Llama 模型出发再做面向评估能力的后训练。我们的初步结果与这一趋势一致：Llama 3.1 70B 和 405B 分别位列第二、第三

随着排行榜在未来几周逐渐成形，我们期待在我们的[博客](https://www.atla-ai.com/blog)上分享更多结果分析。
