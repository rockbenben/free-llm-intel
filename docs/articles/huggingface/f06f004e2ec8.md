# 百艺皆通、数艺精通的多用途 Transformer Agent

本文另有[简体中文](https://huggingface.co/blog/zh/jat)版本。

## 引言

我们很高兴分享 Jack of All Trades（JAT）项目——一个朝通用 agent 方向迈进的项目。项目始于对 [Gato](https://huggingface.co/papers/2205.06175)（Reed 等，2022）工作的开放复现，Gato 提出训练一个既能完成视觉-语言任务又能做决策任务的 Transformer。因此我们先构建了 Gato 数据集的开放版本，然后在其上训练多模态 Transformer 模型，并在处理序列数据与连续值方面对 Gato 做了多项改进。

整体而言，项目成果有：

- 发布大量**专家 RL agent**，覆盖各种各样的任务。
- 发布 **JAT 数据集**——首个用于通用 agent 训练的数据集，包含用专家 agent 收集的数十万条专家轨迹。
- 发布 **JAT 模型**——一个基于 transformer 的 agent，能玩电子游戏、控制机器人完成各种任务、理解并在简单导航环境中执行指令，还有更多！

## 数据集与专家策略

### 专家策略

强化学习（RL）传统上是在单个环境中训练策略。利用这些专家策略是构建多面手 agent 的可行路径。我们选取了范围广泛、性质与难度各异的环境，包括 Atari、BabyAI、Meta-World 和 MuJoCo。对每个环境，我们都训练 agent 直到达到最先进表现（BabyAI 则直接使用 [BabyAI bot](https://github.com/mila-iqia/babyai)）。训出的 agent 称为专家 agent，已发布在 🤗 Hub 上。全部 agent 列表见 [JAT dataset card](https://huggingface.co/datasets/jat-project/jat-dataset)。

### JAT 数据集

我们发布 [JAT 数据集](https://huggingface.co/datasets/jat-project/jat-dataset)——首个通用 agent 训练数据集。它包含用上述专家 agent 收集的数十万条专家轨迹。使用这个数据集，像加载 🤗 Hub 上的其他数据集一样即可：

除了 RL 数据，我们还纳入文本数据集，以提供统一的用户接口。因此你还会找到 [Wikipedia](https://huggingface.co/datasets/wikipedia)、[Oscar](https://huggingface.co/datasets/oscar)、[OK-VQA](https://okvqa.allenai.org) 和 [Conceptual-Captions](https://huggingface.co/datasets/conceptual_captions) 的子集。

## JAT agent 架构

JAT 的架构基于 Transformer，使用 [EleutherAI 的 GPT-Neo 实现](https://huggingface.co/docs/transformers/model_doc/gpt_neo)。JAT 的独特之处在于其嵌入机制——专为内在地处理序列决策任务而构建。我们把观察嵌入与动作嵌入及相应奖励交错排列。

Architecture of the JAT network. For sequential decision-making tasks, observations and rewards on the one hand, and actions on the other, are encoded and interleaved. The model generates the next embedding autoregressively with a causal mask, and decodes according to expected modality.

因此，每个嵌入要么对应一个观察（连同奖励），要么对应一个动作。但 JAT 如何编码这些信息？取决于数据类型。如果数据（观察或动作）是图像（如 Atari 的情况），JAT 使用 CNN；如果是连续向量，JAT 使用线性层；如果是离散值，JAT 使用线性投影层。模型输出也按待预测数据类型采用同样原则。预测是因果的，把观察平移 1 个时间步。这样，agent 必须根据此前全部观察和动作预测下一个动作。

此外，我们觉得训练 agent 顺便做 NLP 和 CV 任务会很有趣。为此我们也让编码器可选择接收文本和图像输入。对文本数据，我们用 GPT-2 的 tokenization 策略；对图像，我们用 [ViT](https://huggingface.co/docs/transformers/model_doc/vit) 型编码器。

既然不同环境的数据模态可能不同，JAT 如何计算损失？它按每种模态分别计算：对图像和连续值用 MSE 损失，对离散值用交叉熵损失。最终损失是序列中各元素损失的均值。等等，这是否意味着预测动作和预测观察被赋予同等权重？其实不是，不过我们[下面](https://huggingface.co/blog/jat#the-surprising-benefits-of-predicting-observations)再谈。

## 实验与结果

我们在全部 157 个训练任务上评估 JAT，每个任务收集 10 个 episode 并记录总奖励。为便于阅读，我们按领域聚合结果。

Aggregated expert normalized scores with 95% Confidence Intervals (CIs) for each RL domain as a function of learning step.

如果用一个数字概括这些结果，那就是 65.8%——四个领域相对 JAT 专家的平均表现。这表明 JAT 能在非常广泛的任务上模仿专家表现。再细看：

- Atari 57 上，agent 达到专家分数的 14.1%，相当于人类表现的 37.6%；它在 21 个游戏上超过人类表现。
- BabyAI 上，agent 达到专家分数的 99.0%，只有 1 个任务未能超过专家的 50%。
- Meta-World 上，agent 达到专家的 65.5%。
- MuJoCo 上，agent 达到专家的 84.8%。

Human normalized scores for the JAT agent on the Atari 57 benchmark.

### 预测观察的意外收益

训练 RL agent 时，首要目标是最大化未来奖励。但如果我们还要求 agent 预测它未来会观察到什么，这一额外任务会帮助还是阻碍学习过程？

对这个问题有两种对立观点。一方面，学会预测观察可以加深对环境的理解，带来更好更快的学习；另一方面，它可能让 agent 分心、偏离主要目标，导致观察预测和动作预测都很平庸。

为了定论，我们做了一个实验：用组合观察损失和动作损失的损失函数，并用权重参数 κ 平衡两个目标。

结果很值得注意。当 κ 太高（0.5）时，预测观察这一额外目标似乎阻碍了学习。但当 κ 较低时，对学习的影响可以忽略，agent 表现与目标中不含观察预测时相当。

不过，我们发现 κ≈0.005 左右存在一个甜蜜点，此时学习预测观察实际上提升了 agent 的学习效率。我们的研究表明，只要平衡得当，在学习过程中加入观察预测可以是有益的。这一发现对此类 agent 的设计有重要启示，凸显了辅助目标在提升学习效率上的潜在价值。

所以，下次你训练 RL agent 时，不妨要求它预测未来的观察——也许会带来更好的表现和更快的学习！

## 结论

在这项工作中，我们推出了 JAT——一个多用途 transformer agent，能掌握各种各样的序列决策任务，并在 NLP 和 CV 任务上表现出初步能力。对所有这些任务，JAT 使用单一网络。我们的贡献包括发布专家 RL agent、JAT 数据集和 JAT 模型。希望这项工作能启发通用 agent 领域的未来研究，并助力构建更具多面性和能力的 AI 系统。

## 下一步：一项研究邀约

我们认为 JAT 项目为通用 agent 研究开辟了新方向，而我们才刚刚触及表面。以下是一些未来工作的想法：

- **改进数据**：JAT 数据集虽然具有开创性，但仍处早期。专家轨迹每个环境只来自一个专家 agent，可能造成某些偏差。尽管我们尽力逼近最先进表现，一些环境仍然很有挑战。我们相信收集更多数据、训练更多专家 agent 会有**很大**帮助。
- **使用离线 RL**：JAT agent 用基础的行为克隆训练。这意味着两点：(1) 无法利用次优轨迹；(2) JAT agent 无法超越专家。我们为了简单选择了这一方法，但相信使用离线 RL 能**真正帮助**提升 agent 表现，而且实现并不复杂。
- **释放更聪明的多任务采样的全部潜力**：目前 JAT agent 对所有任务均匀采样数据，这可能拖了后腿。通过动态调整采样率、聚焦最难的任务，我们可以为 agent 的学习过程增压，释放**显著的性能增益**。
