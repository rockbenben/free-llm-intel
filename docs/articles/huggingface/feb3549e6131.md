# 视觉语言模型详解

merve（[merve](https://huggingface.co/merve)）、Edward Beeching（[edbeeching](https://huggingface.co/edbeeching)）

本文另有官方中文版本：[简体中文](https://huggingface.co/blog/zh/vlms)。

> 这篇博客写于 2024 年 4 月，介绍了视觉语言模型的内部机制、现有视觉语言模型概览以及微调方法。我们已在 2025 年 4 月发布了更新版，涵盖更多能力和更多模型。读完这篇别忘了去看新版！

视觉语言模型（Vision Language Model，VLM）是一类能同时从图像和文本中学习的模型，可以应对视觉问答、图像描述等众多任务。本文将过一遍视觉语言模型的主要组成部分：先有一个整体认识，理解它们如何工作，学会如何找到合适的模型、如何做推理，以及如何用今天发布的最新版 [trl](https://github.com/huggingface/trl) 轻松微调。

## 什么是视觉语言模型？

视觉语言模型的宽泛定义是能够从图像和文本中学习的多模态模型。它们属于生成式模型，接受图像和文本输入，生成文本输出。大型视觉语言模型具备不错的 zero-shot 能力，泛化性好，能处理多种类型的图像，包括文档、网页等等。用例包括围绕图像聊天、基于指令的图像识别、视觉问答、文档理解、图像描述等。一些视觉语言模型还能捕捉图像中的空间属性：在提示下，它们可以输出边界框或分割掩码来检测或分割特定目标，也可以定位不同实体、或回答关于它们相对/绝对位置的问题。现有的大型视觉语言模型在训练数据、图像编码方式乃至能力上都呈现出极大的多样性。

## 找到合适的视觉语言模型

为用例挑选最合适的模型有很多种办法。

[Vision Arena](https://huggingface.co/spaces/WildVision/vision-arena) 是一个完全基于模型输出匿名投票的排行榜，持续更新。在这个竞技场里，用户输入一张图和一个提示词，系统匿名抽样两个不同模型的输出，然后用户选择更喜欢的输出。这样，排行榜就完全由人类偏好构建。

![Vision Arena](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/vlm/arena.png) *Vision Arena*

[Open VLM Leaderboard](https://huggingface.co/spaces/opencompass/open_vlm_leaderboard) 是另一个排行榜，各类视觉语言模型按这些指标及平均分排名。你还可以按模型规模、专有或开源许可证、不同指标上的名次来筛选。

![VLM Capabilities](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/vlm/leaderboard.png) *Open VLM Leaderboard*

[VLMEvalKit](https://github.com/open-compass/VLMEvalKit) 是一个能在视觉语言模型上跑基准的工具包，Open VLM Leaderboard 就是由它驱动的。另一个评测套件是 [LMMS-Eval](https://github.com/EvolvingLMMs-Lab/lmms-eval)，它提供标准的命令行接口，用托管在 Hugging Face Hub 上的数据集评估你选定的 Hugging Face 模型，例如：

```
accelerate launch --num_processes=8 -m lmms_eval --model llava --model_args pretrained="liuhaotian/llava-v1.5-7b" --tasks mme,mmbench_en --batch_size 1 --log_samples --log_samples_suffix llava_v1.5_mme_mmbenchen --output_path ./logs/ 
```

Vision Arena 和 Open VLM Leaderboard 都只覆盖提交给它们的模型，新增模型需要更新榜单。如果想找更多模型，可以在 Hub 上按任务 `image-text-to-text` 浏览 [模型](https://huggingface.co/models?pipeline_tag=image-text-to-text&sort=trending)。

排行榜上你会遇到多种视觉语言模型基准，这里过几个。

### MMMU

[A Massive Multi-discipline Multimodal Understanding and Reasoning Benchmark for Expert AGI (MMMU)](https://huggingface.co/datasets/MMMU/MMMU) 是评估视觉语言模型最全面的基准。它包含 1.15 万个多模态挑战题，要求具备大学水平的学科知识和跨不同学科（如艺术、工程）的推理能力。

### MMBench

[MMBench](https://huggingface.co/datasets/lmms-lab/MMBench) 是一个评测基准，由覆盖 OCR、目标定位等 20 种技能的 3000 道单选题构成。论文还提出了一种叫 CircularEval 的评估策略：把题目的选项做不同组合的打乱，要求模型每一轮都答对。此外还有更聚焦特定领域的基准，包括 MathVista（视觉数学推理）、AI2D（图示理解）、ScienceQA（科学问答）和 OCRBench（文档理解）。

## 技术细节

预训练视觉语言模型的方式有很多种。核心技巧是统一图像和文本的表示，然后喂给文本解码器来生成。最常见、最著名的模型通常由图像编码器、对齐图像与文本表示的嵌入投影器（往往是一个密集神经网络）以及文本解码器按此顺序堆叠而成。在训练环节，不同模型采用的路线并不一样。

例如，LLaVA 由一个 CLIP 图像编码器、一个多模态投影器和一个 Vicuna 文本解码器组成。作者把图像-标题数据集喂给 GPT-4，生成与标题和图像相关的问题。作者冻结图像编码器和文本解码器，只训练多模态投影器：向模型输入图像和生成的问题，把模型输出与真实标题比较，从而对齐图像和文本特征。投影器预训练之后，保持图像编码器冻结、解冻文本解码器，让投影器和解码器一起训练。这种"预训练 + 微调"的方式是训练视觉语言模型最常见的做法。

![VLM Structure](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/vlm/vlm-structure.png)
 *典型视觉语言模型的结构*

![VLM Structure](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/vlm/proj.jpg)
 *投影向量与文本嵌入拼接*

另一个例子是 KOSMOS-2，作者选择端到端完全训练整个模型，相比 LLaVA 式的预训练，计算代价高得多，作者之后做了仅语言侧的指令微调来对齐模型。再比如 Fuyu-8B，它甚至没有图像编码器：图像块直接送入投影层，然后整个序列通过一个自回归解码器。大多数时候你不需要从头预训练一个视觉语言模型——既可以直接用现成的，也可以针对自己的用例微调。下面看如何用 transformers 使用这些模型，以及怎么用 `SFTTrainer` 微调。

## 用 transformers 使用视觉语言模型

你可以按下面的方式用 `LlavaNext` 模型做推理。

先初始化模型和处理器。

```
from transformers import LlavaNextProcessor, LlavaNextForConditionalGeneration
import torch

device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
processor = LlavaNextProcessor.from_pretrained("llava-hf/llava-v1.6-mistral-7b-hf")
model = LlavaNextForConditionalGeneration.from_pretrained(
    "llava-hf/llava-v1.6-mistral-7b-hf",
    torch_dtype=torch.float16,
    low_cpu_mem_usage=True
)
model.to(device)
```

然后把图像和文本提示词传给处理器，再把处理好的输入传给 `generate`。注意每个模型都有自己的提示词模板，务必用对模板，以免性能下降。

```
from PIL import Image
import requests

url = "https://github.com/haotian-liu/LLaVA/blob/1a91fc274d7c35a9b50b3cb29c4247ae5837ce39/images/llava_v1_5_radar.jpg?raw=true"
image = Image.open(requests.get(url, stream=True).raw)
prompt = "[INST] <image>\nWhat is shown in this image? [/INST]"

inputs = processor(prompt, image, return_tensors="pt").to(device)
output = model.generate(**inputs, max_new_tokens=100)
```

调用 decode 来解码输出的 token。

```
print(processor.decode(output[0], skip_special_tokens=True))
```

## 用 TRL 微调视觉语言模型

我们很高兴地宣布，[TRL](https://github.com/huggingface/trl) 的 `SFTTrainer` 现在实验性地支持视觉语言模型！这里给一个示例：如何用 [llava-instruct](https://huggingface.co/datasets/HuggingFaceH4/llava-instruct-mix-vsft) 数据集在 [Llava 1.5 VLM](https://huggingface.co/llava-hf/llava-1.5-7b-hf) 上做 SFT——该数据集包含 26 万个"图像-对话"对，是用户与助手的交互，以消息序列的形式组织。例如，每段对话都配有一张供用户提问的图像。

要使用实验性的 VLM 训练支持，需要安装最新版 TRL：`pip install -U trl`。完整示例脚本在[这里](https://github.com/huggingface/trl/blob/main/examples/sft_visual_chat/sft_visual_chat.py)。

```
from trl.commands.cli_utils import SftScriptArguments, TrlParser

parser = TrlParser((SftScriptArguments, TrainingArguments))
args, training_args = parser.parse_args_and_config()
```

为指令微调初始化聊天模板。

```
LLAVA_CHAT_TEMPLATE = """A chat between a curious user and an artificial intelligence assistant. The assistant gives helpful, detailed, and polite answers to the user's questions. {% for message in messages %}{% if message['role'] == 'user' %}USER: {% else %}ASSISTANT: {% endif %}{% for item in message['content'] %}{% if item['type'] == 'text' %}{{ item['text'] }}{% elif item['type'] == 'image' %}<image>{% endif %}{% endfor %}{% if message['role'] == 'user' %} {% else %}{{eos_token}}{% endif %}{% endfor %}"""
```

接下来初始化模型和分词器。

```
from transformers import AutoTokenizer, AutoProcessor, TrainingArguments, LlavaForConditionalGeneration
import torch

model_id = "llava-hf/llava-1.5-7b-hf"
tokenizer = AutoTokenizer.from_pretrained(model_id)
tokenizer.chat_template = LLAVA_CHAT_TEMPLATE
processor = AutoProcessor.from_pretrained(model_id)
processor.tokenizer = tokenizer

model = LlavaForConditionalGeneration.from_pretrained(model_id, torch_dtype=torch.float16)
```

创建一个数据整理器（data collator），把文本和图像配对组合起来。

```
class LLavaDataCollator:
    def __init__(self, processor):
        self.processor = processor

    def __call__(self, examples):
        texts = []
        images = []
        for example in examples:
            messages = example["messages"]
            text = self.processor.tokenizer.apply_chat_template(
                messages, tokenize=False, add_generation_prompt=False
            )
            texts.append(text)
            images.append(example["images"][0])

        batch = self.processor(texts, images, return_tensors="pt", padding=True)

        labels = batch["input_ids"].clone()
        if self.processor.tokenizer.pad_token_id is not None:
            labels[labels == self.processor.tokenizer.pad_token_id] = -100
        batch["labels"] = labels

        return batch

data_collator = LLavaDataCollator(processor)
```

加载数据集。

```
from datasets import load_dataset

raw_datasets = load_dataset("HuggingFaceH4/llava-instruct-mix-vsft")
train_dataset = raw_datasets["train"]
eval_dataset = raw_datasets["test"]
```

初始化 SFTTrainer，传入模型、数据集划分、PEFT 配置和数据整理器，然后调用 `train()`。最后调用 `push_to_hub()` 把训练好的检查点推到 Hub。

```
from trl import SFTTrainer

trainer = SFTTrainer(
    model=model,
    args=training_args,
    train_dataset=train_dataset,
    eval_dataset=eval_dataset,
    dataset_text_field="text",  # need a dummy field
    tokenizer=tokenizer,
    data_collator=data_collator,
    dataset_kwargs={"skip_prepare_dataset": True},
)

trainer.train()
```

保存模型并推送到 Hugging Face Hub。

```
trainer.save_model(training_args.output_dir)
trainer.push_to_hub()
```
