# SGLang 集成 Transformers 后端

Hugging Face transformers 库是与最先进模型打交道的标准——从尝试前沿研究到在自定义数据上微调。它的简洁、灵活和庞大的模型动物园（model zoo）使它成为快速开发的有力工具。

但一旦你准备从 notebook 实验走向生产，推理性能就变成了关键所在。这时 SGLang 派上用场了。

SGLang 为高吞吐、低延迟推理而设计，现在提供了与 transformers 的无缝后端集成。这意味着你可以把 transformers 的灵活性配上 SGLang 的强悍性能。

让我们深入了解这次集成带来了什么、如何使用。

# TL;DR

SGLang 现已支持 Hugging Face transformers 作为后端，让你开箱即用高性能推理运行任何 transformers 兼容的模型。

```
import sglang as sgl

llm = sgl.Engine("meta-llama/Llama-3.2-1B-Instruct", impl="transformers")
print(llm.generate(["The capital of France is"], {"max_new_tokens": 20})[0])
```

无需原生支持——需要时 SGLang 会自动回退（fallback）到 Transformers，或者你也可以显式设置 `impl="transformers"`。

# Transformers 与 SGLang

我们用 `meta-llama/Llama-3.2-1B-Instruct` 走一遍简单的文本生成示例，对比两种做法。

## Transformers

transformers 库非常适合实验、小规模任务和训练，但它并未针对高吞吐或低延迟场景优化。

```
from transformers import pipeline

pipe = pipeline("text-generation", model="meta-llama/Llama-3.2-1B-Instruct")
generate_kwargs = {
    "top_p": 0.95,
    "top_k": 20,
    "temperature": 0.8,
    "max_new_tokens": 256
}
result = pipe("The future of AI is", **generate_kwargs)
print(result[0]["generated_text"])
```

## SGLang

SGLang 走的是另一条路线，通过 RadixAttention（一种内存高效的注意力机制）等特性优先保证效率。SGLang 的推理明显更快、更省资源，在负载下尤其如此。以下是用 SGLang 离线引擎完成同样任务：

```
import sglang as sgl

if __name__ == '__main__':
    llm = sgl.Engine(model_path="meta-llama/Llama-3.2-1B-Instruct")
    prompts = ["The future of AI is"]
    sampling_params =  {
        "top_p": 0.95,
        "top_k": 20,
        "temperature": 0.8,
        "max_new_tokens": 256
    }
    outputs = llm.generate(prompts, sampling_params)
    print(outputs[0])
```

或者启动一个服务器并发请求：

```
python3 -m sglang.launch_server \
  --model-path meta-llama/Llama-3.2-1B-Instruct \
  --host 0.0.0.0 \
  --port 30000
```

```
response = requests.post(
    "http://localhost:30000/generate",
    json={
        "text": "The future of AI is",
        "sampling_params": {
            "top_p": 0.95,
            "top_k": 20,
            "temperature": 0.8,
            "max_new_tokens": 256
        },
    },
)
print(response.json())
```

注意，SGLang 还提供 OpenAI 兼容 API，可以直接替换外部服务。

# SGLang 中的 Transformers 后端

借助新的 transformers 后端集成，SGLang 现在可以自动回退，用 transformers 运行它不原生支持的模型。在实践中这意味着：

- 即时使用 transformers 新增的任何模型
- 支持来自 Hugging Face Hub 的自定义模型
- 更少的工程开销

这在不牺牲 transformers 生态简洁性与多样性的前提下，解锁了更快的推理和优化的部署（例如启用 RadixAttention）。

## 用法

```
llm = sgl.Engine(model_path="meta-llama/Llama-3.2-1B-Instruct", impl="transformers")
```

注意，指定 impl 参数是可选的。如果 SGLang 不原生支持该模型，它会自动切换到 transformers 实现。

Hugging Face Hub 上任何能用 `transformers` 配合 `trust_remote_code=True` 运行、并正确实现了 attention 的模型都兼容 SGLang。确切要求见官方[文档](https://docs.sglang.ai/supported_models/transformers_fallback.html#remote-code)。如果你的自定义模型满足这些条件，加载时只需设置 trust_remote_code=True。

```
llm = sgl.Engine(model_path="new-custom-transformers-model", impl="transformers", trust_remote_code=True)
```

## 示例

Kyutai 团队的 Helium 尚未被 SGLang 原生支持。这正是 transformers 后端大放异彩之处：无需等待原生支持，就能实现优化推理。

```
python3 -m sglang.launch_server \
  --model-path kyutai/helium-1-preview-2b \
  --impl transformers \
  --host 0.0.0.0 \
  --port 30000
```

```
response = requests.post(
    "http://localhost:30000/generate",
    json={
        "text": "The capital of France is",
        "sampling_params": {
            "top_p": 0.95,
            "top_k": 20,
            "temperature": 0.8,
            "max_new_tokens": 256
        },
    },
)
print(response.json())
```

# 后续计划

我们正在积极加强这次集成的几个关键方向：

- 性能优化：transformer 模型目前的性能仍落后于原生实现。我们的首要目标就是优化并缩小这一差距。
- LoRA 支持
- VLM 集成：我们也在努力加入对视觉语言模型（VLM）的支持，以扩展能力范围和用例。
