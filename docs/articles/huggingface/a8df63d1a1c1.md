## 引言

在本教程中，我们将展示任何人都如何不写一行代码，构建自己的开源 ChatGPT！我们使用 LLaMA 2 基座模型，配合开源指令数据集为聊天做微调，然后把模型部署成一个可以分享给朋友的聊天应用。全程只需点击鼠标，直达伟大。😀

为什么这很重要？机器学习，尤其是 LLM（大语言模型），经历了前所未有的流行，成为我们个人与商业生活中的关键工具。然而，对于 ML 工程这个专门小众圈子之外的大多数人，训练和部署这些模型的复杂细节似乎高不可攀。如果机器学习的预期未来是一个充满无处不在的个性化模型的未来，那么一个挑战正在逼近：如何让非技术背景的人也能独立驾驭这项技术？

在 Hugging Face，我们一直在默默地为这个包容的未来铺路。包括 Spaces、AutoTrain、Inference Endpoints 在内的一整套工具，就是为让全世界的人都能进入机器学习而设计的。

为了展示这个「民主化的未来」究竟有多易及，本教程将演示如何用 [Spaces](https://huggingface.co/Spaces)、[AutoTrain](https://huggingface.co/autotrain) 和 [ChatUI](https://huggingface.co/inference-endpoints) 构建聊天应用。全部三步，一行代码都不用。顺便说，我也不是 ML 工程师，而是 Hugging Face GTM 团队的成员。如果我能做到，你就能做到！开始吧！

## Spaces 简介

Hugging Face 的 Spaces 是一项服务，为构建和部署 Web 托管的 ML demo 与应用提供易用的 GUI。这项服务可以用 Gradio 或 Streamlit 前端快速搭建 ML demo，用 docker 容器上传你自己的应用，甚至可以直接选择若干预配置的 ML 应用立即部署。

我们将部署 Spaces 的两个预配置 docker 应用模板：AutoTrain 和 ChatUI。

关于 Spaces 的更多阅读见[这里](https://huggingface.co/docs/hub/spaces)。

## AutoTrain 简介

AutoTrain 是一个 no-code 工具，让非 ML 工程师（甚至非开发者 😮）无需写代码就能训练最先进的 ML 模型。它可以用于 NLP、计算机视觉、语音、表格数据，甚至现在能为 LLM 做微调——正如我们今天要做的。

关于 AutoTrain 的更多阅读见[这里](https://huggingface.co/docs/autotrain/index)。

## ChatUI 简介

ChatUI 人如其名，它是 Hugging Face 构建的开源 UI，为与开源 LLM 交互提供界面。值得注意的是，它正是 HuggingChat 背后同款 UI——我们是 100% 开源的 ChatGPT 替代品。

关于 ChatUI 的更多阅读见[这里](https://github.com/huggingface/chat-ui)。

### 第 1 步：创建一个新的 AutoTrain Space

1.1 前往 [huggingface.co/spaces](https://huggingface.co/spaces)，选择「Create new Space」。

![](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/llama2-non-engineers/tuto1.png)

1.2 给你的 Space 起个名字；如果你打算把模型或 Space 公开，请选择合适的使用许可证。

1.3 为了在你部署的 Space 中从 Docker 模板启动 AutoTrain 应用，选择 Docker > AutoTrain。

![](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/llama2-non-engineers/tuto2.png)

1.4 选择运行应用的「Space hardware」。（注意：对 AutoTrain 应用而言，免费的 CPU basic 选项就够了；后续模型训练将使用单独的算力，稍后可以选择。）

1.5 在「Space secrets」下添加你的「HF_TOKEN」，让这个 Space 有权访问你的 Hub 账号。没有它，Space 将无法训练模型，也无法把新模型保存到你的账号。（注意：HF_TOKEN 可以在你的 Hugging Face 个人资料的 Settings > Access Tokens 中找到，确保该 token 的权限选了「Write」。）

1.6 选择把 Space 设为「Private」还是「Public」。对 AutoTrain Space 本身，建议保持 Private；但你的模型或 Chat 应用随时可以公开分享。

1.7 点击「Create Space」，大功告成！新 Space 需要几分钟构建，之后就可以打开并开始使用 AutoTrain 了。

![](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/llama2-non-engineers/tuto3.png)

### 第 2 步：在 AutoTrain 中启动一次模型训练

2.1 你的 AutoTrain Space 启动后，会看到下面的 GUI。AutoTrain 支持多种不同类型的训练，包括 LLM 微调、文本分类、表格数据和扩散模型。今天我们聚焦 LLM 训练，所以选择「LLM」标签页。

2.2 在「Model Choice」字段中选择你要训练的 LLM：可以从列表中选一个模型，或按 Hugging Face 模型卡上的名字输入。本例我们使用了 Meta 的 Llama 2 7b 基础模型，模型卡详见[这里](https://huggingface.co/meta-llama/Llama-2-7b-hf)。（注意：LLaMA 2 是 gated 模型，使用前需要向 Meta 申请访问权限；你也可以选择很多非 gated 的模型，比如 Falcon。）

2.3 在「Backend」中选择训练要用的 CPU 或 GPU。对 7b 模型，「A10G Large」就足够了。如果你要训练更大的模型，务必确保模型能完全装进所选 GPU 的显存。（注意：如果你想训练更大的模型并需要 A100 GPU 的访问，请发邮件到 [api-enterprise@huggingface.co](mailto:api-enterprise@huggingface.co)。）

2.4 当然，微调需要上传「Training Data」。上传时请确保数据集格式正确且为 CSV 文件格式。所需格式的示例见[这里](https://huggingface.co/docs/autotrain/main/en/llm_finetuning)。如果你的数据集包含多列，请从文件中标记出装有训练数据的那一列「Text Column」。本例我们使用 Alpaca 指令微调数据集，更多信息见[这里](https://huggingface.co/datasets/tatsu-lab/alpaca)。也可以直接从[这里](https://huggingface.co/datasets/tofighi/LLM/resolve/main/alpaca.csv)下载 CSV 版本。

![](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/llama2-non-engineers/tuto4.png)

2.5 可选：你可以上传「Validation Data」用来测试新训练的模型，但这不是必需的。

2.6 AutoTrain 中可配置许多高级设置来降低模型的内存占用，比如更改精度（「FP16」）、量化（「Int4/8」），或是否采用 PEFT（Parameter Efficient Fine Tuning，参数高效微调）。建议沿用默认设置——这会减少训练模型的时间和成本，而对模型性能只有很小的影响。

2.7 同样，你可以在「Parameter Choice」中配置训练参数，但现在让我们先用默认设置。

![](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/llama2-non-engineers/tuto5.png)

2.8 现在一切就绪，选择「Add Job」把模型加入训练队列，然后选择「Start Training」。（注意：如果你想用不同的超参数训练多个模型版本，可以添加多个任务同时运行。）

2.9 训练开始后，你会看到你的 Hub 账号里新建了一个「Space」。这个 Space 正在运行模型训练；完成后，新模型也会出现在你 Hub 账号的「Models」下。（注意：要查看训练进度，可以在该 Space 里查看实时日志。）

2.10 去泡杯咖啡吧。取决于模型大小和训练数据量，这可能耗时几小时甚至几天。完成后，一个新模型会出现在你的 Hugging Face Hub 账号的「Models」下。

![](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/llama2-non-engineers/tuto6.png)

### 第 3 步：用你的模型创建一个新的 ChatUI Space

3.1 按第 1.1 到 1.3 步相同的方式创建新 Space，但选择 ChatUI docker 模板而不是 AutoTrain。

3.2 选择「Space Hardware」。对我们的 7b 模型，A10G Small 就足以运行，具体视你的模型大小而定。

![](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/llama2-non-engineers/tuto7.png)

3.3 如果你有自家的 Mongo DB，可以在「MONGODB_URL」中提供相关细节来存储聊天记录。否则留空即可，系统会自动创建一个本地 DB。

3.4 要让你训练出的模型驱动聊天应用，需要在「Space variables」部分提供「MODEL_NAME」。你可以在 Hugging Face 个人资料的「Models」部分找到模型名——它就是你在 AutoTrain 中使用的项目名。我们的例子中是「2legit2overfit/wrdt-pco6-31a7-0」。

3.4 在「Space variables」中，你还可以更改模型推理参数，包括 temperature、top-p、最大生成 token 数等，以改变生成风格。现在先用默认设置。

![](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/llama2-non-engineers/tuto8.png)

3.5 现在，你可以按下「Create」，启动属于你自己的开源 ChatGPT 了。恭喜！如果你做对了，它应该长这样。

![](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/llama2-non-engineers/tuto9.png)
