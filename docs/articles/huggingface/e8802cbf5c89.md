# 解放你的 OpenClaw 🦀

Anthropic 正在限制 Pro/Max 订阅者在开放 agent 平台上访问 Claude 模型。不过别担心，Hugging Face 上有很多优秀的开放模型，能让你的 agent 继续跑下去！而且多数时候，成本只要几分之一。

如果你已被切断访问，你的 OpenClaw、Pi 或 Open Code agent 需要"抢救"，可以通过两种方式把它们迁移到开放模型：

- 使用通过 Hugging Face Inference Providers 服务的开放模型。
- 在你自己的硬件上运行一个完全本地的开放模型。

托管路线是最快恢复一个能干活的 agent 的方式；如果你想要隐私、零 API 成本和完全控制，本地路线才是对的选择。

具体做法，只需告诉你的 claude code、你的 Cursor 或你偏爱的 agent：*帮我把 OpenClaw agent 迁移到 Hugging Face 模型*，并附上本页链接。

## Hugging Face Inference Providers

Hugging Face Inference Providers 是一个路由到开源模型供应商的开放平台。如果你想要最好的模型，或者没有必需的硬件，它是正确的选择。

首先，你需要在[这里](https://huggingface.co/settings/tokens)创建一个 token。然后按如下方式把该 token 加入 `openclaw`：

```
openclaw onboard --auth-choice huggingface-api-key
```

按提示粘贴你的 Hugging Face token，随后会被要求选择模型。

我们推荐 [GLM-5](https://huggingface.co/zai-org/GLM-5)，因为它在 [Terminal Bench](https://huggingface.co/datasets/harborframework/terminal-bench-2.0) 上的出色成绩；当然在[这里](https://huggingface.co/inference/models)还有数千个模型可选。

你随时可以在 OpenClaw 配置中填入模型的 `repo_id` 来更新你使用的 Hugging Face 模型：

```
{
  agents: {
    defaults: {
      model: {
        primary: "huggingface/zai-org/GLM-5:fastest"
      }
    }
  }
}
```

注意：HF PRO 订阅者每月获得 $2 免费额度，可用于 Inference Providers，了解更多见[这里](https://huggingface.co/pro)。

## 本地部署

本地运行模型给你完全的隐私、零 API 成本，以及在没有限流的情况下自由实验的能力。

安装 Llama.cpp——一个面向低资源推理的完全开源库。

```
# on mac or linux
brew install llama.cpp

# on windows
winget install llama.cpp
```

启动一个内置 Web UI 的本地服务器：

```
llama-server -hf unsloth/Qwen3.5-35B-A3B-GGUF:UD-Q4_K_XL
```

这里我们用的是 Qwen3.5-35B-A3B，它在 32GB 内存上运行良好。如果你有不同需求，请查看[你感兴趣的模型](https://huggingface.co/unsloth/Qwen3.5-35B-A3B-GGUF)的硬件兼容性。[可选择的模型有成千上万个](https://huggingface.co/models?pipeline_tag=text-generation&library=gguf&sort=trending)。

如果你在 llama.cpp 中加载了 GGUF，请使用类似这样的 OpenClaw 配置：

```
openclaw onboard --non-interactive \                                                                                   
   --auth-choice custom-api-key \                                                                                         
   --custom-base-url "http://127.0.0.1:8080/v1" \                                                                         
   --custom-model-id "unsloth-qwen3.5-35b-a3b-gguf" \                                                                     
   --custom-api-key "llama.cpp" \                                                                                         
   --secret-input-mode plaintext \                                                                                        
   --custom-compatibility openai
```

验证服务器已运行且模型已加载：

```
curl http://127.0.0.1:8080/v1/models
```

## 该选哪条路？

想要最快恢复一个能干活的 OpenClaw agent，就用 Hugging Face Inference Providers；想要隐私、完全的本地控制和没有 API 账单，就用 `llama.cpp`。

无论哪条路，你都不需要一个闭源托管模型就能让 OpenClaw 重新站起来！
