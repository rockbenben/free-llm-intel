# 使用 🤗 Transformers 微调 ViT 做图像分类

正如基于 transformers 的模型彻底改变了 NLP，我们现在也看到大量论文把它们应用到各种其他领域。其中最具革命性的之一是视觉 Transformer（Vision Transformer，ViT），由 Google Brain 的一个研究团队于 [2021 年 6 月](https://arxiv.org/abs/2010.11929)提出。

这篇论文探索了如何对图像做 token 化——就像你对句子做 token 化一样——使图像可以传入 Transformer 模型进行训练。这个概念其实相当简单……

- 把图像切分成一个子图像 patch 组成的网格
- 用线性投影对每个 patch 做嵌入
- 每个嵌入后的 patch 就是一个 token，嵌入 patch 序列就是要传给模型的序列

结果表明，完成上述步骤之后，你就可以像做 NLP 任务时习惯的那样，对 Transformer 进行预训练和微调。相当美妙 😎。

在这篇博客中，我们将演示如何利用 🤗 `datasets` 下载并处理图像分类数据集，然后用它对预训练 ViT 进行 🤗 `transformers` 微调。

开始之前，先安装这两个包。

```
pip install datasets transformers
```

我们写一个函数，展示每个类别若干样本组成的网格，以便更直观地了解手头的数据。

```
import random
from PIL import ImageDraw, ImageFont, Image

def show_examples(ds, seed: int = 1234, examples_per_class: int = 3, size=(350, 350)):

    w, h = size
    labels = ds['train'].features['labels'].names
    grid = Image.new('RGB', size=(examples_per_class * w, len(labels) * h))
    draw = ImageDraw.Draw(grid)
    font = ImageFont.truetype("/usr/share/fonts/truetype/liberation/LiberationMono-Bold.ttf", 24)

    for label_id, label in enumerate(labels):

        # Filter the dataset by a single label, shuffle it, and grab a few samples
        ds_slice = ds['train'].filter(lambda ex: ex['labels'] == label_id).shuffle(seed).select(range(examples_per_class))

        # Plot this label's examples along a row
        for i, example in enumerate(ds_slice):
            image = example['image']
            idx = examples_per_class * label_id + i
            box = (idx % examples_per_class * w, idx // examples_per_class * h)
            grid.paste(image.resize(size), box=box)
            draw.text(box, label, (255, 255, 255), font=font)

    return grid

show_examples(ds, seed=random.randint(0, 1337), examples_per_class=3)
```

## 加载 ViT 图像处理器

现在我们知道了图像长什么样，也对要解决的问题有了更清楚的认识。接下来看看如何为模型准备这些图像！

ViT 模型在训练时对输入图像应用了特定的变换。如果你对自己的图像用错了变换，模型就看不懂它「看到」的东西！🖼 ➡️ 🔢

为确保应用正确的变换，我们使用一个 [`ViTImageProcessor`](https://huggingface.co/docs/transformers/model_doc/vit#transformers.ViTImageProcessor)，并用我们打算使用的预训练模型随附保存的配置来初始化它。本例中我们使用 [google/vit-base-patch16-224-in21k](https://huggingface.co/google/vit-base-patch16-224-in21k) 模型，因此从 Hugging Face Hub 加载它的图像处理器。

```
from transformers import ViTImageProcessor

model_name_or_path = 'google/vit-base-patch16-224-in21k'
processor = ViTImageProcessor.from_pretrained(model_name_or_path)
```

把图像处理器配置打印出来即可查看。

```
ViTImageProcessor {
  "do_normalize": true,
  "do_resize": true,
  "image_mean": [
    0.5,
    0.5,
    0.5
  ],
  "image_std": [
    0.5,
    0.5,
    0.5
  ],
  "resample": 2,
  "size": 224
}
```

要处理一张图像，直接把它传给图像处理器的调用函数即可。这会返回一个包含 `pixel values` 的 dict，即要传给模型的数值表示。

默认返回 NumPy 数组；如果加上 `return_tensors='pt'` 参数，就会得到 `torch` 张量。

```
processor(image, return_tensors='pt')
```

结果大致如下……

```
{
  'pixel_values': tensor([[[[ 0.2706,  0.3255,  0.3804,  ...]]]])
}
```

……其中张量的形状是 `(1, 3, 224, 224)`。

## 处理数据集

现在你知道如何读取图像并把它变换成模型输入了。我们写一个函数，把这两件事合在一起，处理数据集中的单个样本。

```
def process_example(example):
    inputs = processor(example['image'], return_tensors='pt')
    inputs['labels'] = example['labels']
    return inputs
```

```
process_example(ds['train'][0])
```

```
{
  'pixel_values': tensor([[[[-0.6157, -0.6000, -0.6078,  ..., ]]]]),
  'labels': 0
}
```

虽然你可以调用 `ds.map` 把这个函数一次性应用到所有样本上，但这可能非常慢，尤其在使用较大数据集时。替代方案是对数据集应用一个***变换（transform）***。变换只在你索引样本时才对样本生效。

不过首先要更新刚才的函数，让它接受一批数据——这正是 `ds.with_transform` 所期望的。

```
ds = load_dataset('beans')

def transform(example_batch):
    # Take a list of PIL images and turn them to pixel values
    inputs = processor([x for x in example_batch['image']], return_tensors='pt')

    # Don't forget to include the labels!
    inputs['labels'] = example_batch['labels']
    return inputs
```

你可以直接用 `ds.with_transform(transform)` 把它应用到数据集上。

```
prepared_ds = ds.with_transform(transform)
```

从此，每当你从数据集取一个样本，变换都会实时应用（对单个样本和切片都生效，如下所示）

```
prepared_ds['train'][0:2]
```

这次得到的 `pixel_values` 张量形状为 `(2, 3, 224, 224)`。

```
{
  'pixel_values': tensor([[[[-0.6157, -0.6000, -0.6078,  ..., ]]]]),
  'labels': [0, 0]
}
```

## 训练与评估

数据处理好了，可以开始搭建训练流程了。本篇博客使用 🤗 的 Trainer，但在那之前我们需要先做几件事：

- 定义一个 collate 函数。
- 定义一个评估指标。训练过程中要评估模型的预测准确率，因此需要相应地定义一个 `compute_metrics` 函数。
- 加载预训练检查点。需要加载一个预训练检查点，并为训练做好正确配置。
- 定义训练配置。

微调完模型后，我们会在评估数据上正确评估它，验证它确实学会了正确分类图像。

### 定义数据整理器（data collator）

批次进来时是 dict 的列表，所以直接解包再堆叠成批次张量即可。

由于 `collate_fn` 返回一个批次 dict，之后可以用 `**` 解包作为模型的输入。✨

```
import torch

def collate_fn(batch):
    return {
        'pixel_values': torch.stack([x['pixel_values'] for x in batch]),
        'labels': torch.tensor([x['labels'] for x in batch])
    }
```

### 定义评估指标

`evaluate` 里的 [accuracy](https://huggingface.co/metrics/accuracy) 指标可以很方便地比较预测与标签。下面演示如何在 `Trainer` 使用的 `compute_metrics` 函数中调用它。

```
import numpy as np
from evaluate import load

metric = load("accuracy")
def compute_metrics(p):
    return metric.compute(predictions=np.argmax(p.predictions, axis=1), references=p.label_ids)
```

来加载预训练模型。我们在初始化时传入 `num_labels`，让模型创建具有正确输出单元数的分类头。我们还会带上 `id2label` 和 `label2id` 映射，以便在 Hub 的 widget 中显示人类可读的标签（如果你选择 `push_to_hub` 的话）。

```
from transformers import ViTForImageClassification

labels = ds['train'].features['labels'].names

model = ViTForImageClassification.from_pretrained(
    model_name_or_path,
    num_labels=len(labels),
    id2label={str(i): c for i, c in enumerate(labels)},
    label2id={c: str(i) for i, c in enumerate(labels)}
)
```

马上就能训练了！训练前最后一件事是通过定义 [`TrainingArguments`](https://huggingface.co/docs/transformers/v4.16.2/en/main_classes/trainer#transformers.TrainingArguments) 来设置训练配置。

其中大多数参数都不言自明，但这里有一个相当重要的参数是 `remove_unused_columns=False`。它会丢弃模型调用函数未使用的所有特征。该参数默认是 `True`，因为通常丢弃未使用的特征列更省事，便于把输入解包传给模型的调用函数。但在我们的场景里，恰恰需要这些「未使用」的特征（尤其是 'image'），用来生成 'pixel_values'。

我想说的就是：如果忘了设置 `remove_unused_columns=False`，你会吃尽苦头。

```
from transformers import TrainingArguments

training_args = TrainingArguments(
  output_dir="./vit-base-beans",
  per_device_train_batch_size=16,
  evaluation_strategy="steps",
  num_train_epochs=4,
  fp16=True,
  save_steps=100,
  eval_steps=100,
  logging_steps=10,
  learning_rate=2e-4,
  save_total_limit=2,
  remove_unused_columns=False,
  push_to_hub=False,
  report_to='tensorboard',
  load_best_model_at_end=True,
)
```

现在所有实例都可以传给 Trainer，可以开始训练了！

```
from transformers import Trainer

trainer = Trainer(
    model=model,
    args=training_args,
    data_collator=collate_fn,
    compute_metrics=compute_metrics,
    train_dataset=prepared_ds["train"],
    eval_dataset=prepared_ds["validation"],
    tokenizer=processor,
)
```

### 训练 🚀

```
train_results = trainer.train()
trainer.save_model()
trainer.log_metrics("train", train_results.metrics)
trainer.save_metrics("train", train_results.metrics)
trainer.save_state()
```

### 评估 📊

```
metrics = trainer.evaluate(prepared_ds['validation'])
trainer.log_metrics("eval", metrics)
trainer.save_metrics("eval", metrics)
```
