# 📚 3LM：面向阿拉伯语 LLM 的 STEM 与代码基准

📄 [arXiv 论文](https://arxiv.org/abs/2507.15850) | 📦 [HuggingFace 上的数据集](https://huggingface.co/collections/tiiuae/3lm-arabic-benchmark-687de9629072871e702d35e1) | 🔧 [GitHub 代码](https://github.com/tiiuae/3LM-benchmark)

[![image/png](https://cdn-uploads.huggingface.co/production/uploads/659bc8a7b0f43ed69f0b2300/yMGXxcRew14olxaMxgjA_.png)](https://cdn-uploads.huggingface.co/production/uploads/659bc8a7b0f43ed69f0b2300/yMGXxcRew14olxaMxgjA_.png)

## 为什么是 3LM？

近年来，阿拉伯语大语言模型（LLM）取得了显著进展，但在评估高价值技术领域的表现方面，现有基准仍力不从心。迄今为止的大多数评估都聚焦于摘要、情感分析或通用问答等通用任务。然而，科学推理和编程对从教育到技术问题求解的广泛现实应用都至关重要。

为填补这一空白，我们推出 **3LM（علم）**——一个专为评估阿拉伯语 LLM 在 STEM（科学、技术、工程和数学）学科及代码生成上的表现而定制的多组件基准。3LM 是同类基准中的首个，专门设计用于测试阿拉伯语模型在结构化推理与形式逻辑上的能力——这些领域在阿拉伯语 NLP 中长期缺乏代表性。

## 基准里有什么？

3LM 由三个数据集组成，分别针对一个特定的评估维度：真实世界的 STEM 多项选择题（MCQ）、合成的STEM难题，以及翻译后的代码生成任务。

### 1. Native STEM（原生 STEM）

Native STEM 基准由 865 道 MCQ 组成，题目取自真实的阿拉伯语教育内容，包括 8 至 12 年级的教科书、练习册和题库。题目覆盖五个核心学科：物理、化学、生物、数学和地理。

每道题都带有域（domain）和难度（1–10 分制）等元数据标注。数据通过一条流水线获取，该流水线结合了 OCR（包括通过 Pix2Tex 进行 LaTeX 数学公式解析）、LLM 辅助的问答抽取以及人工审核。该数据集使用真实教育材料，为评估阿拉伯语模型的事实性与概念性理解提供了一个现实的测试平台。

### 2. Synthetic STEM（合成 STEM）

为了引入更大的挑战性和多样性，我们使用 [YourBench](https://huggingface.co/spaces/HuggingFaceH4/YourBench) 流水线创建了由 1,744 道 MCQ 组成的合成子集。该组件取材于阿拉伯语教科书文本：先将文本切块、摘要，再输入由 LLM 驱动的提问生成系统。最终得到一个聚焦中等偏难推理的题目集合，涵盖概念性、分析性和应用性问题。

Synthetic STEM 通过探究更深层的推理能力并最小化答案偏好，为原生 MCQ 提供了重要的平衡。所有生成的问题都经过基于清晰度、结构和内容有效性的过滤，随后通过人工审核进行质量保证。

### 3. 阿拉伯语代码基准

3LM 的第三个组件针对代码生成——这是 LLM 评估中一个不断增长的领域。我们将广泛使用的 HumanEval+ 和 MBPP+ 基准翻译并改编为阿拉伯语，创建了首个用自然语言编程提示来测试阿拉伯语 LLM 的代码数据集。

我们使用 GPT-4o 进行提示翻译，并通过回译（backtranslation）流水线验证结果，基于 ROUGE-L F1 阈值（< 0.8）剔除低质量样本。额外的人工过滤确保了提示的清晰与正确。代码和测试套件保持原样不变，以保持评分的一致性。评估使用 EvalPlus 框架计算 pass@1 和 pass@1+ 指标。

## 构建基准的过程

3LM 中的每个数据集都经过多阶段开发流程，以确保数据质量、公平性与代表性。

[![image/png](https://cdn-uploads.huggingface.co/production/uploads/659bc8a7b0f43ed69f0b2300/rnaoRgqUCumXhdEuTvKe2.png)](https://cdn-uploads.huggingface.co/production/uploads/659bc8a7b0f43ed69f0b2300/rnaoRgqUCumXhdEuTvKe2.png) 对于 **Native STEM**，我们收集阿拉伯语 PDF 源文件，并采用双重 OCR 方法同时恢复纯文本和数学公式。题目通过基于 LLM 的分块与模式识别提取，随后按 MCQ 格式分类并随机化选项顺序。最终样本由具备 STEM 专业背景的阿拉伯语母语者审核，以确认答案的有效性与可读性。

对于 **Synthetic STEM**，我们将 YourBench 流水线改编以支持阿拉伯语输入。源文档在导入后先被摘要、切块，然后送入一个受代码控制的 MCQ 生成器。我们过滤掉依赖图像或含糊不清的内容，只保留目标难度范围内的题目。最终得到一套干净、高质量的阿拉伯语 STEM 合成 MCQ。

对于 **代码基准**，我们的目标是在保留代码逻辑的同时单独考察语言理解能力。提示翻译由 GPT-4o 完成，并通过逆向翻译进行验证。代码和测试保持原样，以便与英文版达到对等的评估。成果是一个可以直接用 EvalPlus 工具链评估阿拉伯语提示的基准。

## 关键结果

我们评估了 40 多个 LLM，包括阿拉伯语优先模型、多语言模型，以及通用领域的 base 模型和指令微调模型。评估同时使用多项选择题准确率和生成式补全指标。

[![image/png](https://cdn-uploads.huggingface.co/production/uploads/659bc8a7b0f43ed69f0b2300/AySci4l0C_0QpA7WTmlSw.png)](https://cdn-uploads.huggingface.co/production/uploads/659bc8a7b0f43ed69f0b2300/AySci4l0C_0QpA7WTmlSw.png)

在 **MCQ 设定**下，Qwen2.5-72B-Instruct 在原生（71.8%）和合成（67.0%）STEM 子集上均取得最佳成绩。在**补全任务**中，Gemma-3-27B 表现最强，STEM 答案准确率达到 43.2%。

在**代码生成**方面，GPT-4o 在 HumanEval-ar（pass@1+ 83.5%）和 MBPP-ar（pass@1+ 63.6%）上都展示了同类最佳的表现。这些结果凸显出阿拉伯语与英语 pass@1 分数之间的高度相关（约 0.97），表明语言相关的提示质量对模型结果有重大影响。

[![image/png](https://cdn-uploads.huggingface.co/production/uploads/659bc8a7b0f43ed69f0b2300/ic30v3kwgb8WcxyPut_Yy.png)](https://cdn-uploads.huggingface.co/production/uploads/659bc8a7b0f43ed69f0b2300/ic30v3kwgb8WcxyPut_Yy.png)

我们还考察了**干扰项扰动下的鲁棒性**，结果显示指令微调模型明显比其 base 对应模型更稳定。提示工程和 zero-shot 设计也被证明会显著影响阿拉伯语 STEM 的表现。

## 评估工具

我们把基准构建为可以用标准工具轻松复现：

- [`lighteval`](https://github.com/huggingface/lighteval) 负责 STEM 数据集的多项选择题与开放题评估。
- [`evalplus`](https://github.com/openai/evalplus) 基于函数级测试提供稳健的 pass@1 与 pass@1+ 代码评分。

所有脚本、配置和评估流水线都在我们的 [GitHub 仓库](https://github.com/tiiuae/3LM-benchmark)中公开，可适配评估任何兼容 HuggingFace Transformers 或 OpenAI API 的模型。

## 获取数据集

三个数据集全部开源，托管在 HuggingFace Datasets 上：

- [`3LM-native-stem`](https://huggingface.co/datasets/tiiuae/NativeQA)
