# 向 `hf` 问好：更快、更友好的 Hugging Face CLI ✨

Lucain Pouget（Wauplin）、Célina Hanouti（celinah）、Julien Chaumond（julien-c）

我们很高兴宣布一项期待已久的体验改进：Hugging Face CLI 正式从 `huggingface-cli` 更名为 `hf`！

那么……为什么这么改？

不停地敲 `huggingface-cli` 很快会让人厌烦。更重要的是，随着时间推移加入新功能（上传、下载、缓存管理、仓库管理等），CLI 的命令结构变得混乱。给 CLI 更名，是一次把命令重新整理成更清晰、更一致格式的机会。

我们决定不重新造轮子，而是遵循一个众所周知的 CLI 模式：**`hf <resource> <action>`**。这种可预测的语法让 Hugging Face CLI 更顺手、更容易被发现，同时也为即将到来的功能铺路。

## 开始上手

要开始玩新 CLI，你需要安装最新的 `huggingface_hub` 版本：

```
pip install -U huggingface_hub
```

并重载你的终端会话。要测试安装是否成功，运行 `hf version`：

```
➜ hf version
huggingface_hub version: 0.34.0
```

接下来，用 `hf --help` 探索新语法：

```
➜ hf --help
usage: hf <command> [<args>]

positional arguments:
  {auth,cache,download,jobs,repo,repo-files,upload,upload-large-folder,env,version,lfs-enable-largefiles,lfs-multipart-upload}
                        hf command helpers
    auth                Manage authentication (login, logout, etc.).
    cache               Manage local cache directory.
    download            Download files from the Hub
    jobs                Run and manage Jobs on the Hub.
    repo                Manage repos on the Hub.
    repo-files          Manage files in a repo on the Hub.
    upload              Upload a file or a folder to the Hub. Recommended for single-commit uploads.
    upload-large-folder
                        Upload a large folder to the Hub. Recommended for resumable uploads.
    env                 Print information about the environment.
    version             Print information about the hf version.

options:
  -h, --help            show this help message and exit
```

可以看到，命令按"资源"分组（`hf auth`、`hf cache`、`hf repo` 等）。我们也把 `hf upload` 和 `hf download` 放到根层级，因为它们预期是最高频使用的命令。

要深入了解任何命令组，只需在后面加上 `--help`：

```
➜ hf auth --help
usage: hf <command> [<args>] auth [-h] {login,logout,whoami,switch,list} ...

positional arguments:
  {login,logout,whoami,switch,list}
                        Authentication subcommands
    login               Log in using a token from huggingface.co/settings/tokens
    logout              Log out
    whoami              Find out which huggingface.co account you are logged in as.
    switch              Switch between access tokens
    list                List all stored access tokens

options:
  -h, --help            show this help message and exit
```

## 🔀 迁移

如果你习惯了 `huggingface-cli`，大多数命令都会看着很眼熟。最大的变化在认证：

```
huggingface-cli login
# became
hf auth login
```

```
huggingface-cli whoami
# became
hf auth whoami
```

```
huggingface-cli logout
# became
hf auth logout
```

所有 `auth` 命令都被归到一起，加上现有的 `hf auth switch`（在不同本地配置之间切换）和 `hf auth list`（列出本地配置）。

旧的 `huggingface-cli` 仍然可用且功能完整。我们保留它是为了平滑过渡。如果你使用旧 CLI 的任何命令，会看到一个警告，指向新 CLI 的对应命令：

```
➜ huggingface-cli whoami
⚠️  Warning: 'huggingface-cli whoami' is deprecated. Use 'hf auth whoami' instead.
Wauplin
orgs:  huggingface,competitions,hf-internal-testing,templates,HF-test-lab,Gradio-Themes,autoevaluate,HuggingFaceM4,HuggingFaceH4,open-source-metrics,sd-concepts-library,hf-doc-build,hf-accelerate,HFSmolCluster,open-llm-leaderboard,pbdeeplinks,discord-community,llhf,sllhf,mt-metrics,DDUF,hf-inference,changelog,tiny-agents
```

## 还有一件事…… 💥 `hf jobs`

我们忍不住发布了第一个专属命令：**hf jobs**。

Hugging Face Jobs 是一项新服务，让你用你心仪的硬件规格在 Hugging Face 基础设施上运行任何脚本或 Docker 镜像。计费方式是"按量付费"，意味着你只为使用的秒数付费。下面是启动你第一个命令的方式：

```
# Run "nvidia-smi" on an A10G GPU
hf jobs run --flavor=a10g-small ubuntu nvidia-smi
```

这个 CLI 很大程度上借鉴了大家熟悉的 Docker 命令：

```
➜ hf jobs --help
usage: hf <command> [<args>] jobs [-h] {inspect,logs,ps,run,cancel,uv} ...

positional arguments:
  {inspect,logs,ps,run,cancel,uv}
                        huggingface.co jobs related commands
    inspect             Display detailed information on one or more Jobs
    logs                Fetch the logs of a Job
    ps                  List Jobs
    run                 Run a Job
    cancel              Cancel a Job
    uv                  Run UV scripts (Python with inline dependencies) on HF infrastructure

options:
  -h, --help            show this help message and exit
```

通过[阅读指南](https://huggingface.co/docs/huggingface_hub/main/en/guides/jobs)了解更多关于 Jobs 的信息。

> Hugging Face Jobs 仅对 Pro 用户以及 Team 或 Enterprise 组织开放。升级你的套餐开始使用！
