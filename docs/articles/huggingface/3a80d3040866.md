# 使用 PEFT 进行参数高效微调

Sourab Mangrulkar (smangrul)

Sayak Paul (sayakpaul)

## 动机

基于 transformer 架构的大语言模型（LLM），如 GPT、T5、BERT，已在各类自然语言处理（NLP）任务上取得 SOTA 结果。它们也开始进军其他领域，如计算机视觉（CV）（VIT、Stable Diffusion、LayoutLM）和音频（Whisper、XLS-R）。传统范式是：先在通用网络级数据上大规模预训练，再微调到下游任务。相比开箱即用预训练 LLM（例如零样本推理），在下游数据集上微调这些预训练 LLM 能带来巨大的性能提升。

然而，模型越做越大，全量微调在消费级硬件上已经训不起了。而且，为每个下游任务独立存储和部署微调模型也非常昂贵——微调后的模型和原预训练模型一样大。参数高效微调（PEFT）方法正是要同时解决这两个问题！

PEFT 方法只微调少量（附加的）模型参数，同时冻结预训练 LLM 的大部分参数，从而大幅降低计算和存储成本。它还克服了"[灾难性遗忘](https://arxiv.org/abs/1312.6211)"的问题——这是 LLM 全量微调时观察到的现象。PEFT 方法还被证明在低数据量场景下优于全量微调，并且对域外（out-of-domain）场景泛化更好。它可以应用于各种模态，例如[图像分类](https://github.com/huggingface/peft/tree/main/examples/image_classification)和 [stable diffusion dreambooth](https://github.com/huggingface/peft/tree/main/examples/lora_dreambooth)。

它还有利于可移植性：用户用 PEFT 方法调优模型，得到的检查点只有几 MB，而全量微调的检查点则非常庞大。例如 `bigscience/mt0-xxl` 占用 40GB 存储，全量微调意味着每个下游数据集都要存 40GB 的检查点；而用 PEFT 方法，每个下游数据集只需几 MB，性能却能与全量微调媲美。PEFT 训练出的小权重是叠加在预训练 LLM 之上的，所以同一个 LLM 加上不同的小权重就能服务多个任务，无需整体替换模型。

**简言之，PEFT 方法让你只用少量可训练参数，就能获得与全量微调相当的性能。**

今天，我们很高兴推出 [🤗 PEFT](https://github.com/huggingface/peft) 库，它提供最新的参数高效微调技术，并与 🤗 Transformers 和 🤗 Accelerate 无缝集成。这样既能用上 Transformers 中最流行、性能最好的模型，又能享受 Accelerate 的简洁与可扩展性。目前支持的 PEFT 方法如下，更多方法即将加入：

- LoRA: [LORA: LOW-RANK ADAPTATION OF LARGE LANGUAGE MODELS](https://arxiv.org/pdf/2106.09685.pdf)
- Prefix Tuning: [P-Tuning v2: Prompt Tuning Can Be Comparable to Fine-tuning Universally Across Scales and Tasks](https://arxiv.org/pdf/2110.07602.pdf)
- Prompt Tuning: [The Power of Scale for Parameter-Efficient Prompt Tuning](https://arxiv.org/pdf/2104.08691.pdf)
- P-Tuning: [GPT Understands, Too](https://arxiv.org/pdf/2103.10385.pdf)

## 用 🤗 PEFT 训练你的模型

以 LoRA 微调 [`bigscience/mt0-large`](https://huggingface.co/bigscience/mt0-large) 为例。

- 先备好需要的 import

```
  from transformers import AutoModelForSeq2SeqLM
+ from peft import get_peft_model, LoraConfig, TaskType
  model_name_or_path = "bigscience/mt0-large"
  tokenizer_name_or_path = "bigscience/mt0-large"
```

- 创建对应 PEFT 方法的 config

```
peft_config = LoraConfig(
    task_type=TaskType.SEQ_2_SEQ_LM, inference_mode=False, r=8, lora_alpha=32, lora_dropout=0.1
)
```

- 调用 `get_peft_model` 包装基座 🤗 Transformers 模型

```
  model = AutoModelForSeq2SeqLM.from_pretrained(model_name_or_path)
+ model = get_peft_model(model, peft_config)
+ model.print_trainable_parameters()
# output: trainable params: 2359296 || all params: 1231940608 || trainable%: 0.19151053100118282
```

就这么简单！训练循环的其余部分完全不变。端到端示例参见 [peft_lora_seq2seq.ipynb](https://github.com/huggingface/peft/blob/main/examples/conditional_generation/peft_lora_seq2seq.ipynb)。

- 准备保存模型做推理时，只需：

```
model.save_pretrained("output_dir") 
# model.push_to_hub("my_awesome_peft_model") also works
```

这只保存训练出来的增量 PEFT 权重。例如，用 LoRA 在 `twitter_complaints` raft 数据集上调优的 `bigscience/T0_3B` 在这里：[smangrul/twitter_complaints_bigscience_T0_3B_LORA_SEQ_2_SEQ_LM](https://huggingface.co/smangrul/twitter_complaints_bigscience_T0_3B_LORA_SEQ_2_SEQ_LM)。注意它只包含 2 个文件：adapter_config.json 和 adapter_model.bin，后者仅 19MB。

- 加载模型做推理，参考下面的片段：

```
  from transformers import AutoModelForSeq2SeqLM
+ from peft import PeftModel, PeftConfig

  peft_model_id = "smangrul/twitter_complaints_bigscience_T0_3B_LORA_SEQ_2_SEQ_LM"
  config = PeftConfig.from_pretrained(peft_model_id)
  model = AutoModelForSeq2SeqLM.from_pretrained(config.base_model_name_or_path)
+ model = PeftModel.from_pretrained(model, peft_model_id)
  tokenizer = AutoTokenizer.from_pretrained(config.base_model_name_or_path)

  model = model.to(device)
  model.eval()
  inputs = tokenizer("Tweet text : @HondaCustSvc Your customer service has been horrible during the recall process. I will never purchase a Honda again. Label :", return_tensors="pt")

  with torch.no_grad():
      outputs = model.generate(input_ids=inputs["input_ids"].to("cuda"), max_new_tokens=10)
      print(tokenizer.batch_decode(outputs.detach().cpu().numpy(), skip_special_tokens=True)[0])
# 'complaint'
```

## 下一步

我们把 PEFT 发布出来，作为调优大型 LLM 下游任务和领域的高效方式，在获得与全量微调相当性能的同时，省下大量算力和存储。未来几个月，我们会探索更多 PEFT 方法，如 (IA)3 和 bottleneck adapters。我们还将关注新的用例，例如在 Google Colab 对 [`whisper-large`](https://huggingface.co/openai/whisper-large) 模型进行 INT8 训练，以及用 PEFT 方法调优 RLHF 组件（如策略模型和排序器）。

在此期间，我们很期待看到业界从业者如何把 PEFT 应用到自己的场景中——有任何问题或反馈，请到我们的 [GitHub 仓库](https://github.com/huggingface/peft)提 issue 🤗。
