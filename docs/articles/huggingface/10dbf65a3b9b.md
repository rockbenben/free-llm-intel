# Fetch 借助 Amazon SageMaker 与 Hugging Face 将 ML 处理延迟降低 50%

*本文转发自 2023 年 9 月最初发表于 [AWS 网站](https://aws.amazon.com/fr/solutions/case-studies/fetch-case-study/)的一篇博文。*

## 概览

消费者互动与奖励公司 [Fetch](https://fetch.com/) 提供一款应用，让用户扫描收据即可在消费中获得奖励。该公司还会解析这些收据，生成消费者行为洞察，并把这些洞察提供给品牌合作方。随着每周扫描量快速增长，Fetch 需要提升自己的速度与精度。

在 Amazon Web Services（AWS）上，Fetch 借助 Hugging Face 和 [Amazon SageMaker](https://aws.amazon.com/sagemaker/)（一个用于构建、训练和部署 ML 模型的全托管基础设施、工具与工作流服务）优化了自己的机器学习（ML）流水线。如今，Fetch 应用处理扫描的速度更快，准确率也显著更高。

## 机遇 | 用 Amazon SageMaker 在 12 个月内加速 Fetch 的 ML 流水线

使用 Fetch 应用，顾客可以扫描收据、获得积分，并把积分兑换成礼品卡。为了在用户扫描收据的瞬间给予奖励，Fetch 需要能够从收据中捕获文本、提取相关数据，并将其结构化，好让系统的其余部分进行处理和分析。每周要处理超过 8,000 万张收据——高峰流量下每秒数百张——它必须快速、准确、规模化地完成这一流程。

2021 年，Fetch 着手优化其应用的扫描功能。Fetch 是一家 AWS 原生公司，其 ML 运维团队早已在许多模型上使用 Amazon SageMaker。因此，把模型迁移到 Amazon SageMaker 以增强 ML 流水线的决定顺理成章。

整个项目期间，Fetch 与 AWS 团队每周例会，并得到 AWS 为 Fetch 配备的领域专家的支持。公司在 12 个月内使用 Amazon SageMaker 构建、训练并部署了五个以上的 ML 模型。2022 年底，Fetch 推出了更新后的移动应用和新 ML 流水线。

#### "Amazon SageMaker 对 Fetch 来说是颠覆性的。我们几乎深入使用了它的每一项功能。新功能一推出，立刻就能体现价值。很难想象没有 Amazon SageMaker 的这些功能，这个项目会怎么做成。"

Sam Corzine，Fetch 机器学习工程师

## 方案 | 在 Amazon SageMaker GPU 实例上用 ML 与 Hugging Face 把延迟降低 50%

#### "利用 Hugging Face AWS Deep Learning Container 的灵活性，我们提升了模型质量；而 Hugging Face 与 AWS 的伙伴关系让这些模型的部署变得很简单。"

Sam Corzine，Fetch 机器学习工程师

Fetch 的 ML 流水线由多项 Amazon SageMaker 功能支撑，尤其是 [Amazon SageMaker Model Training](https://aws.amazon.com/sagemaker/train/)（在规模化训练和调优 ML 模型时降低时间与成本）和 [Amazon SageMaker Processing](https://docs.aws.amazon.com/sagemaker/latest/dg/processing-job.html)（以简化、托管的方式运行数据处理工作负载）。公司使用多 GPU 实例运行自定义 ML 模型以获得快速性能。"Amazon SageMaker 上的 GPU 实例非常好用，"Fetch 后端工程师 Ellen Light 说。Fetch 训练这些模型来识别并提取收据上的关键信息，用于生成有价值的洞察并奖励用户。而在 Amazon SageMaker 上，Fetch 的定制 ML 系统可以无缝扩展。"借助 Amazon SageMaker，我们有了扩展系统的简单途径，尤其是在推理和运行时长方面，"Fetch 的 ML 工程师 Sam Corzine 说。同时，标准化的模型部署意味着更少的人工操作。

在打磨和迭代模型的过程中，Fetch 大量依赖 Amazon SageMaker 的 ML 训练功能，特别是其[训练任务（training jobs）](https://docs.aws.amazon.com/sagemaker/latest/APIReference/API_CreateTrainingJob.html)。Fetch 还能并行训练 ML 模型，从而加速开发和部署。"我们部署模型几乎没有阻力，"Fetch 的应用科学家 Alec Stashevsky 说，"基本上不用为此操心。"这提升了整个公司的信心与生产力。一个例子是：一位新实习生在入职第三天就独立部署了一个模型。

自采用 Amazon SageMaker 进行 ML 调优、训练和重训练以来，Fetch 将其文档理解模型的准确率提升了 200%，并持续微调模型以求进一步改进。"Amazon SageMaker 是构建这些卓越模型的关键工具，"Fetch 的 ML 工程师 Quency Yu 说。为优化调优过程，Fetch 依赖 [Amazon SageMaker Inference Recommender](https://docs.aws.amazon.com/sagemaker/latest/dg/inference-recommender.html)——一项通过自动化负载测试和模型调优来缩短 ML 模型上线时间的 Amazon SageMaker 能力。

除了自定义 ML 模型，Fetch 还使用 [AWS Deep Learning Containers](https://aws.amazon.com/machine-learning/containers/)（AWS DL Containers）。企业可以用它通过优化的预打包容器镜像快速部署深度学习环境。这让使用 AI 技术公司、[AWS Partner](https://partners.amazonaws.com/partners/0010h00001jBrjVAAS/Hugging%20Face%20Inc.) 成员 [Hugging Face Inc.](https://huggingface.co/)（Hugging Face）的库的过程变得简单。具体来说，Fetch 使用 Amazon SageMaker Hugging Face Inference Toolkit（一个用于服务 transformers 模型的开源库），以及用于训练和推理的 Hugging Face AWS Deep Learning Container。"利用 Hugging Face AWS Deep Learning Container 的灵活性，我们提升了模型质量，"Corzine 说，"而 Hugging Face 与 AWS 的伙伴关系让这些模型的部署变得很简单。"

在 Fetch 衡量的每一项指标上，采用 Amazon SageMaker 之后性能都有改善。公司把最慢扫描的延迟降低了 50%。"准确率的提升也让合作方对我们的数据更有信心，"Corzine 说。信心增强后，合作方会更多地使用 Fetch 的方案。"能够用 Amazon SageMaker 对字面意义上的每一个数据点显著提升准确率，是巨大的收益，并惠及我们整个业务，"Corzine 说。

现在 Fetch 能从收据中提取更多类型的数据，并能按照品牌合作方的具体需求灵活组织所产生的洞察。"深入投入 ML，让我们能够从收据中精确提取合作方想要的东西，"Corzine 说，"合作方能够推出新型优惠，正得益于我们在 ML 上的投入，这对他们是额外的巨大收益。"

用户也很喜欢这些更新：自新版本发布以来，Fetch 的月活跃用户从 1,000 万增长到 1,800 万。"Amazon SageMaker 对 Fetch 来说是颠覆性的，"Corzine 说，"我们几乎深入使用了它的每一项功能。新功能一推出，立刻就能体现价值。很难想象没有 Amazon SageMaker 的这些功能，这个项目会怎么做成。"例如，Fetch 从自建的影子测试流水线迁移到了 [Amazon SageMaker shadow testing](https://aws.amazon.com/sagemaker/shadow-testing/)——用新 ML 模型与生产模型对拍验证性能，防止事故。如今影子测试更加直接，因为 Fetch 可以直接用生产流量对比性能。

## 成果 | 把 ML 扩展到新的用例

Fetch 的 ML 团队持续开发新模型，并迭代现有模型以调优出更好的性能。"另一点我们很喜欢的是能让技术栈随 Amazon SageMaker 的新功能保持更新，"Fetch 的 ML 开发者 Chris Lee 说。公司将继续在多个团队中把 AWS 的用法扩展到不同的 ML 用例，例如欺诈防范。

作为最大的消费者互动软件公司之一，Fetch 的目标是持续增长。"AWS 是我们扩展规划的关键部分，我们会继续借助 Amazon SageMaker 的功能不断提升准确率，"Corzine 说。
