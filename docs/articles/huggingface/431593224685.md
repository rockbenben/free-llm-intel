![Idefics-Obelics logo](https://huggingface.co/HuggingFaceM4/idefics-80b/resolve/main/assets/IDEFICS.png)

我们兴奋地发布 [Idefics2](https://huggingface.co/HuggingFaceM4/idefics2-8b)——一个通用多模态模型，输入任意交替的文本与图像序列，生成文本响应。它能回答关于图像的问题、描述视觉内容、基于多张图像创作故事、从文档中提取信息，还能做基础算术运算。
Idefics2 在 [Idefics1](https://huggingface.co/blog/idefics) 的基础上全面升级：8B 参数、开放许可证（Apache 2.0）、增强的 OCR（光学字符识别）能力，让 Idefics2 成为多模态社区工作的坚实底座。它在视觉问答基准上的表现是同规模级别中的顶尖，可与 [LLava-Next-34B](https://huggingface.co/liuhaotian/llava-v1.6-34b)、[MM1-30B-chat](https://huggingface.co/papers/2403.09611) 这样大得多的模型掰手腕。
Idefics2 从第一天起就集成进 🤗 Transformers，因此可以为众多多模态应用直接微调。现在就可在 Hub 上试用[模型](https://huggingface.co/HuggingFaceM4/idefics2-8b)！

## 训练数据

Idefics2 在多个开放数据集的混合上预训练：交错网页文档（Wikipedia、[OBELICS](https://huggingface.co/datasets/HuggingFaceM4/OBELICS)）、图文对（Public Multimodal Dataset、LAION-COCO）、OCR 数据（[PDFA (en)](https://huggingface.co/datasets/pixparse/pdfa-eng-wds)、[IDL](https://huggingface.co/datasets/pixparse/idl-wds) 和 [Rendered-text](https://huggingface.co/datasets/wendlerc/RenderedText)），以及图像转代码数据（[WebSight](https://huggingface.co/datasets/HuggingFaceM4/WebSight)）。
这个[交互式可视化](https://atlas.nomic.ai/map/f2fba2aa-3647-4f49-a0f3-9347daeee499/ee4a84bd-f125-4bcc-a683-1b4e231cb10f)可以探索 OBELICS 数据集。
遵循基础模型社区的常见做法，我们在任务导向数据上进一步训练基座模型。但这些数据往往格式各异、散落各处，把它们收拢起来是社区的一道门槛。为解决这一问题，我们发布我们精心烹制的多模态指令微调数据集：*[The Cauldron](https://huggingface.co/datasets/HuggingFaceM4/the_cauldron)*——**50** 个手工整理数据集的开放合集，已格式化为多轮对话。我们在 The Cauldron 与各类纯文本指令微调数据集的拼接上对 Idefics2 做了指令微调。

![The Cauldron](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/idefics2/The_Cauldron.png?download=true)

## 相对 Idefics1 的改进

- 我们按原生分辨率（最高 980 x 980）与原生宽高比处理图像——沿用 NaViT 策略，绕开了计算机视觉社区历史上把图像缩放到固定正方形的需要。此外，我们采用 SPHINX 的策略，（可选地）允许子图切分以及传入超高分辨率图像。
- 我们通过纳入要求模型转录图像或文档中文字的数据，大幅增强了 OCR 能力；并通过恰当的训练数据，提升了在图表、图形与文档上问答的能力。
- 我们放弃了 Idefics1 的架构（门控交叉注意力），简化了视觉特征融入语言主干的方式。图像先送入视觉编码器，经过一个可学习的 Perceiver 池化与 MLP 模态投影，再把池化后的序列与文本嵌入拼接，得到图像与文本的（交错）序列。

这些改进加上更好的预训练主干，让一个体积小 10 倍的模型在性能上相对 Idefics1 实现显著飞跃。

## Idefics2 快速上手

Idefics2 已在 Hugging Face Hub 上发布，并被最新版 `transformers` 支持。示例代码如下：

```
import requests
import torch
from PIL import Image

from transformers import AutoProcessor, AutoModelForVision2Seq
from transformers.image_utils import load_image

DEVICE = "cuda:0"

# Note that passing the image urls (instead of the actual pil images) to the processor is also possible
image1 = load_image("https://cdn.britannica.com/61/93061-050-99147DCE/Statue-of-Liberty-Island-New-York-Bay.jpg")
image2 = load_image("https://cdn.britannica.com/59/94459-050-DBA42467/Skyline-Chicago.jpg")
image3 = load_image("https://cdn.britannica.com/68/170868-050-8DDE8263/Golden-Gate-Bridge-San-Francisco.jpg")


processor = AutoProcessor.from_pretrained("HuggingFaceM4/idefics2-8b")
model = AutoModelForVision2Seq.from_pretrained(
    "HuggingFaceM4/idefics2-8b",
).to(DEVICE)


# Create inputs
messages = [
    {
        "role": "user",
        "content": [
            {"type": "image"},
            {"type": "text", "text": "What do we see in this image?"},
        ]
    },
    {
        "role": "assistant",
        "content": [
            {"type": "text", "text": "In this image, we can see the city of New York, and more specifically the Statue of Liberty."},
        ]
    },
    {
        "role": "user",
        "content": [
            {"type": "image"},
            {"type": "text", "text": "And how about this image?"},
        ]
    },
]
prompt = processor.apply_chat_template(messages, add_generation_prompt=True)
inputs = processor(text=prompt, images=[image1, image2], return_tensors="pt")
inputs = {k: v.to(DEVICE) for k, v in inputs.items()}


# Generate
generated_ids = model.generate(**inputs, max_new_tokens=500)
generated_texts = processor.batch_decode(generated_ids, skip_special_tokens=True)

print(generated_texts)
```
