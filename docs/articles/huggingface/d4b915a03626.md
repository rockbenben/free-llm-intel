# Unity 中的 AI 语音识别

Dylan Ebert（dylanebert）

本文亦有[简体中文](https://huggingface.co/blog/zh/unity-asr)版本。

[![Open Source AI Game Jam](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/124_ml-for-games/gamejambanner.png)](https://itch.io/jam/open-source-ai-game-jam)

## 引言

本教程带你一步步用 Hugging Face Unity API 在自己的 Unity 游戏里实现最先进的语音识别。这个能力可以用来下指令、和 NPC 对话、提升无障碍体验，或任何"把说出的话变成文字"有用的场景。

想亲自试试 Unity 里的语音识别，可以看 [itch.io 上的在线演示](https://individualkex.itch.io/speech-recognition-demo)。

### 前置条件

本教程假设你具备 Unity 基础知识，并要求已安装 [Hugging Face Unity API](https://github.com/huggingface/unity-api)。API 的配置方法见我们[之前的博客](https://huggingface.co/blog/unity-api)。

## 步骤

### 1. 搭建场景

本教程要搭一个非常简单的场景：玩家可以开始和停止录音，录音结果会被转成文字。

先创建一个 Unity 项目，然后建一个 Canvas，包含以下 UI 元素：

- **Start 按钮**：开始录音。
- **Stop 按钮**：停止录音。
- **Text（TextMeshPro）**：显示语音识别的结果。

### 2. 搭脚本

创建一个叫 `SpeechRecognitionTest` 的脚本，挂到一个空的 GameObject 上。

在脚本里定义 UI 组件的引用：

```
[SerializeField] private Button startButton;
[SerializeField] private Button stopButton;
[SerializeField] private TextMeshProUGUI text;
```

在 Inspector 里赋值。

然后用 `Start()` 方法给开始/停止按钮挂监听：

```
private void Start() {
    startButton.onClick.AddListener(StartRecording);
    stopButton.onClick.AddListener(StopRecording);
}
```

到这里，你的脚本应该长这样：

```
using TMPro;
using UnityEngine;
using UnityEngine.UI;

public class SpeechRecognitionTest : MonoBehaviour {
    [SerializeField] private Button startButton;
    [SerializeField] private Button stopButton;
    [SerializeField] private TextMeshProUGUI text;

    private void Start() {
        startButton.onClick.AddListener(StartRecording);
        stopButton.onClick.AddListener(StopRecording);
    }

    private void StartRecording() {

    }

    private void StopRecording() {

    }
}
```

### 3. 录制麦克风输入

现在来录制麦克风输入并编码成 WAV 格式。先定义成员变量：

```
private AudioClip clip;
private byte[] bytes;
private bool recording;
```

然后在 `StartRecording()` 里用 `Microphone.Start()` 开始录音：

```
private void StartRecording() {
    clip = Microphone.Start(null, false, 10, 44100);
    recording = true;
}
```

这会以 44100 Hz 采样率录制最多 10 秒音频。

如果录满最长 10 秒，我们希望自动停止录音。在 `Update()` 方法里写：

```
private void Update() {
    if (recording && Microphone.GetPosition(null) >= clip.samples) {
        StopRecording();
    }
}
```

然后在 `StopRecording()` 里截断录音并编码成 WAV 格式：

```
private void StopRecording() {
    var position = Microphone.GetPosition(null);
    Microphone.End(null);
    var samples = new float[position * clip.channels];
    clip.GetData(samples, 0);
    bytes = EncodeAsWAV(samples, clip.frequency, clip.channels);
    recording = false;
}
```

最后还要实现 `EncodeAsWAV()` 方法，把音频数据处理成 Hugging Face API 需要的格式：

```
private byte[] EncodeAsWAV(float[] samples, int frequency, int channels) {
    using (var memoryStream = new MemoryStream(44 + samples.Length * 2)) {
        using (var writer = new BinaryWriter(memoryStream)) {
            writer.Write("RIFF".ToCharArray());
            writer.Write(36 + samples.Length * 2);
            writer.Write("WAVE".ToCharArray());
            writer.Write("fmt ".ToCharArray());
            writer.Write(16);
            writer.Write((ushort)1);
            writer.Write((ushort)channels);
            writer.Write(frequency);
            writer.Write(frequency * channels * 2);
            writer.Write((ushort)(channels * 2));
            writer.Write((ushort)16);
            writer.Write("data".ToCharArray());
            writer.Write(samples.Length * 2);

            foreach (var sample in samples) {
                writer.Write((short)(sample * short.MaxValue));
            }
        }
        return memoryStream.ToArray();
    }
}
```

要验证这段代码是否正常工作，可以在 `StopRecording()` 方法末尾加上这一行：

```
File.WriteAllBytes(Application.dataPath + "/test.wav", bytes);
```

现在，点击 `Start` 按钮、对着麦克风说几句话、再点 `Stop`，你的 Unity Assets 文件夹里就应该保存了一个包含录音内容的 `test.wav` 文件。

### 4. 语音识别

接下来，我们要用 Hugging Face Unity API 对编码后的音频执行语音识别。创建一个 `SendRecording()` 方法：

```
using HuggingFace.API;

private void SendRecording() {
    HuggingFaceAPI.AutomaticSpeechRecognition(bytes, response => {
        text.color = Color.white;
        text.text = response;
    }, error => {
        text.color = Color.red;
        text.text = error;
    });
}
```

它会把编码后的音频发给 API：成功就白色显示识别结果，失败就红色显示错误信息。

别忘了在 `StopRecording()` 末尾调用 `SendRecording()`：

```
private void StopRecording() {
    /* other code */
    SendRecording();
}
```

### 5. 最后的打磨

最后，用按钮可交互状态和提示文字把 demo 的体验提升一下。

Start 和 Stop 按钮只应在合适的时机可点击——也就是录音可以开始/停止的时候。

然后，在录音中或等待 API 返回时，把响应文字设为简单的状态提示。

最终脚本应该长这样：

```
using System.IO;
using HuggingFace.API;
using TMPro;
using UnityEngine;
using UnityEngine.UI;

public class SpeechRecognitionTest : MonoBehaviour {
    [SerializeField] private Button startButton;
    [SerializeField] private Button stopButton;
    [SerializeField] private TextMeshProUGUI text;

    private AudioClip clip;
    private byte[] bytes;
    private bool recording;

    private void Start() {
        startButton.onClick.AddListener(StartRecording);
        stopButton.onClick.AddListener(StopRecording);
        stopButton.interactable = false;
    }

    private void Update() {
        if (recording && Microphone.GetPosition(null) >= clip.samples) {
            StopRecording();
        }
    }

    private void StartRecording() {
        text.color = Color.white;
        text.text = "Recording...";
        startButton.interactable = false;
        stopButton.interactable = true;
        clip = Microphone.Start(null, false, 10, 44100);
        recording = true;
    }

    private void StopRecording() {
        var position = Microphone.GetPosition(null);
        Microphone.End(null);
        var samples = new float[position * clip.channels];
        clip.GetData(samples, 0);
        bytes = EncodeAsWAV(samples, clip.frequency, clip.channels);
        recording = false;
        SendRecording();
    }

    private void SendRecording() {
        text.color = Color.yellow;
        text.text = "Sending...";
        stopButton.interactable = false;
        HuggingFaceAPI.AutomaticSpeechRecognition(bytes, response => {
            text.color = Color.white;
            text.text = response;
            startButton.interactable = true;
        }, error => {
            text.color = Color.red;
            text.text = error;
            startButton.interactable = true;
        });
    }

    private byte[] EncodeAsWAV(float[] samples, int frequency, int channels) {
        using (var memoryStream = new MemoryStream(44 + samples.Length * 2)) {
            using (var writer = new BinaryWriter(memoryStream)) {
                writer.Write("RIFF".ToCharArray());
                writer.Write(36 + samples.Length * 2);
                writer.Write("WAVE".ToCharArray());
                writer.Write("fmt ".ToCharArray());
                writer.Write(16);
                writer.Write((ushort)1);
                writer.Write((ushort)channels);
                writer.Write(frequency);
                writer.Write(frequency * channels * 2);
                writer.Write((ushort)(channels * 2));
                writer.Write((ushort)16);
                writer.Write("data".ToCharArray());
                writer.Write(samples.Length * 2);

                foreach (var sample in samples) {
                    writer.Write((short)(sample * short.MaxValue));
                }
            }
            return memoryStream.ToArray();
        }
    }
}
```
