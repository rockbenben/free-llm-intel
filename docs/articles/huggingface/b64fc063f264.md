# Hugging Face for Education 来了 🤗

鉴于机器学习将占据软件开发的绝大部分，而非技术人群也将越来越多地接触 AI 系统，AI 的主要挑战之一就是适应并提升员工技能。同时，支持教育工作者主动把 AI 的伦理与批判性议题纳入教学，也正变得不可或缺。

作为一家推动机器学习民主化的开源公司，[Hugging Face](https://huggingface.co/) 认为对不同背景、全世界的人们开展教育至关重要。

我们于 2022 年 3 月启动了 [ML demo.cratization 巡讲](https://www.notion.so/ML-Demo-cratization-tour-with-66847a294abd4e9785e85663f5239652)，Hugging Face 的专家们为来自 16 个国家的 1000 多名学生讲授了「协作构建机器学习」的实践课程。我们的新目标是：**到 2023 年底教会 500 万人机器学习**。

*这篇博客概述我们如何实现教育方面的目标。*

## 🤗 **面向所有人的教育**

🗣️ 我们的目标是让每个人都能理解机器学习的潜力与局限。我们相信这将推动该领域朝着「技术应用为整个社会带来净收益」的方向演进。

我们现有工作的一些例子：

- 我们以非常通俗易懂的方式描述了 [ML 模型的不同用途](https://huggingface.co/tasks)（摘要、文本生成、物体检测……）
- 我们通过模型页面上的 widget 让所有人直接在浏览器里试用模型，从而降低了对技术技能的要求（[示例](https://huggingface.co/cmarkea/distilcamembert-base-sentiment)）
- 我们记录并警示系统中发现的可疑偏见（例如 [GPT-2](https://huggingface.co/gpt2#limitations-and-bias)）
- 我们提供工具来创建开源 [ML 应用](https://huggingface.co/spaces)，让任何人一键就能理解 ML 的潜力。

## 🤗 **面向初学者的教育**

🗣️ 我们希望借助在线课程、实践工作坊和其他创新手段，降低成为机器学习工程师的门槛。

- 我们提供关于自然语言处理（NLP）以及更多领域（即将推出）的免费[课程](https://huggingface.co/course/chapter1/1)，使用 Hugging Face 生态的免费工具和库。课程完全免费、无广告。终极目标是学会把 Transformers 应用到（几乎）任何机器学习问题上！
- 我们提供关于深度强化学习的免费[课程](https://github.com/huggingface/deep-rl-class)。在这门课程中，你可以从理论与实践两个角度学习深度强化学习、使用知名 Deep RL 库、在独特环境中训练 agent、用一行代码把你训练好的 agent 发布到 Hugging Face Hub 等等！
- 我们提供关于如何为你的机器学习模型构建交互式 demo 的免费[课程](https://huggingface.co/course/chapter9/1)。这门课的终极目标是：让 ML 开发者能轻松向包括非技术团队或客户在内的广泛受众展示工作，让研究者更容易复现机器学习模型与行为，让最终用户更容易识别和调试模型的失败点，等等！
- Hugging Face 的专家们撰写了一本关于 Transformers 及其在众多 NLP 任务中应用的[书](https://transformersbook.com/)。

除这些努力外，许多团队成员还参与了其他教育工作，例如：

- 参加 meetup、会议与工作坊。
- 制作播客、YouTube 视频和博客文章。
- [组织活动](https://github.com/huggingface/community-events/tree/main/huggan)，为任何人免费提供 GPU，让大家能够训练和分享模型、并为其创建 demo。

## 🤗 **面向教育者的教育**

🗣️ 我们希望用工具赋能教育者，并提供协作空间，让学生能够使用开源技术和最先进机器学习模型来构建机器学习。

- 我们为教育者提供免费的基础设施与资源，快速向学生介绍 ML 的真实世界应用，让学习更有趣、更吸引人。教师可以在 hub 上免费创建一个[班级（classroom）](https://huggingface.co/classrooms)，把课堂变成协作环境，让学生用免费开源技术和最先进模型来学习并构建 ML 驱动的应用。
- 我们整理了被翻译成 8 种语言的免费[教育工具包](https://github.com/huggingface/education-toolkit)，机器学习或数据科学的教育者可以用它轻松准备实验、作业或课程。内容自成一体系，可以方便地并入现有课程。这些内容免费，并使用知名的开源技术（🤗 transformers、gradio 等）。随便挑一个教程去教吧！1️⃣ [Hugging Face Hub 巡礼](https://github.com/huggingface/education-toolkit/blob/main/01_huggingface-hub-tour.md) 2️⃣ [用 Gradio 和 Hugging Face 构建并托管机器学习 demo](https://colab.research.google.com/github/huggingface/education-toolkit/blob/main/02_ml-demos-with-gradio.ipynb) 3️⃣ [Transformers 入门](https://colab.research.google.com/github/huggingface/education-toolkit/blob/main/03_getting-started-with-transformers.ipynb)
- 我们正在组织一场专门的免费工作坊（6 月 6 日），主题是如何在你的机器学习与数据科学课程中教授我们的教育资源。欢迎[报名](https://www.eventbrite.com/e/how-to-teach-open-source-machine-learning-tools-tickets-310980931337)。
- 我们目前正在与大学教师合作进行全球巡讲，为超过 10000 名学生讲授我们的核心课题之一：如何协作构建机器学习？你可以通过 [ML demo.cratization 巡讲计划](https://www.notion.so/ML-Demo-cratization-tour-with-66847a294abd4e9785e85663f5239652)**。** 申请 Hugging Face 团队成员为你的班级开一场。
