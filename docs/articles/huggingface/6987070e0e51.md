# 从 PyTorch DDP 到 Accelerate 再到 Trainer，轻松掌握分布式训练

## 总体概览

本教程假设你已具备 PyTorch 基础，会训练一个简单的模型。我们将通过三个抽象层级递进的方式，展示如何通过"分布式数据并行（DDP）"在多个 GPU 上训练：

- 通过 `pytorch.distributed` 模块使用 PyTorch 原生 DDP
- 使用 🤗 Accelerate——它在 `pytorch.distributed` 之上做了一层轻量包装，还能保证代码不改一行就能跑在单 GPU 和 TPU 上，相对原始代码只需极小改动
- 使用 🤗 Transformers 的高层 Trainer API，它把所有样板代码抽象掉，并支持各种设备和分布式场景

## 什么是"分布式"训练，为什么它重要？

看下面这段非常基础的 PyTorch 训练代码。它基于 [官方 MNIST 示例](https://github.com/pytorch/examples/blob/main/mnist/main.py)在 MNIST 上搭建并训练模型。

```
import torch
import torch.nn as nn
import torch.nn.functional as F
import torch.optim as optim
from torchvision import datasets, transforms

class BasicNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(1, 32, 3, 1)
        self.conv2 = nn.Conv2d(32, 64, 3, 1)
        self.dropout1 = nn.Dropout(0.25)
        self.dropout2 = nn.Dropout(0.5)
        self.fc1 = nn.Linear(9216, 128)
        self.fc2 = nn.Linear(128, 10)
        self.act = F.relu

    def forward(self, x):
        x = self.act(self.conv1(x))
        x = self.act(self.conv2(x))
        x = F.max_pool2d(x, 2)
        x = self.dropout1(x)
        x = torch.flatten(x, 1)
        x = self.act(self.fc1(x))
        x = self.dropout2(x)
        x = self.fc2(x)
        output = F.log_softmax(x, dim=1)
        return output
```

定义训练设备（`cuda`）：

```
device = "cuda"
```

构建几个 PyTorch DataLoader：

```
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.1307), (0.3081))
])

train_dset = datasets.MNIST('data', train=True, download=True, transform=transform)
test_dset = datasets.MNIST('data', train=False, transform=transform)

train_loader = torch.utils.data.DataLoader(train_dset, shuffle=True, batch_size=64)
test_loader = torch.utils.data.DataLoader(test_dset, shuffle=False, batch_size=64)
```

把模型移到 CUDA 设备上：

```
model = BasicNet().to(device)
```

构建一个 PyTorch 优化器：

```
optimizer = optim.AdamW(model.parameters(), lr=1e-3)
```

最后创建一套极简的训练和评估循环：对整个数据集迭代一轮并计算测试准确率：

```
model.train()
for batch_idx, (data, target) in enumerate(train_loader):
    data, target = data.to(device), target.to(device)
    output = model(data)
    loss = F.nll_loss(output, target)
    loss.backward()
    optimizer.step()
    optimizer.zero_grad()

model.eval()
correct = 0
with torch.no_grad():
    for data, target in test_loader:
        data, target = data.to(device), target.to(device)
        output = model(data)
        pred = output.argmax(dim=1, keepdim=True)
        correct += pred.eq(target.view_as(pred)).sum().item()
print(f'Accuracy: {100. * correct / len(test_loader.dataset)}')
```

通常到这里，你可以把这些全塞进一个 Python 脚本，或者在 Jupyter Notebook 里跑。

但如果你有 2 块 GPU 甚至多台机器这样的资源，想让脚本利用起来通过*分布式*训练加速，该怎么办？光用 `python myscript.py` 永远只会用一块 GPU 跑。这正是 `torch.distributed` 大显身手的地方。

## PyTorch 分布式数据并行

顾名思义，`torch.distributed` 是为*分布式*环境准备的。这可以包括多机（multi-node）——若干台机器各带一块 GPU；或多卡（multi-gpu）——单机上有多块 GPU；或两者兼有。

要把上面的代码改成分布式版本，得先定义几个配置项，详见 [Getting Started with DDP Tutorial](https://pytorch.org/tutorials/intermediate/ddp_tutorial.html)。

首先要声明一个 `setup` 函数和一个 `cleanup` 函数。这会打开一个进程组，让所有计算进程在其中通信。

> 注意：本节教程假设这些代码写在 Python 脚本文件里。后面会讲到用 Accelerate 作为启动器，就不必这么做了。

```
import os
import torch.distributed as dist

def setup(rank, world_size):
    "Sets up the process group and configuration for PyTorch Distributed Data Parallelism"
    os.environ["MASTER_ADDR"] = 'localhost'
    os.environ["MASTER_PORT"] = "12355"

    # Initialize the process group
    dist.init_process_group("gloo", rank=rank, world_size=world_size)

def cleanup():
    "Cleans up the distributed environment"
    dist.destroy_process_group()
```

最后一块拼图是：*我怎么把数据和模型送到另一块 GPU 上？*

这就是 `DistributedDataParallel` 模块的用武之地。它会把模型复制到每块 GPU 上；当调用 `loss.backward()` 时执行反向传播，所有模型副本上的梯度会被平均/归约（reduce）。这样优化器一步之后各设备的权重保持一致。

下面是我们的训练配置——重构成函数后——具备这个能力：

> 注意：这里的 rank 是当前 GPU 相对所有其它 GPU 的总体序号，也就是各卡 rank 为 0 到 n-1。

```
from torch.nn.parallel import DistributedDataParallel as DDP

def train(model, rank, world_size):
    setup(rank, world_size)
    model = model.to(rank)
    ddp_model = DDP(model, device_ids=[rank])
    optimizer = optim.AdamW(ddp_model.parameters(), lr=1e-3)
    # Train for one epoch
    ddp_model.train()
    for batch_idx, (data, target) in enumerate(train_loader):
        data, target = data.to(rank), target.to(rank)
        output = model(data)
        loss = F.nll_loss(output, target)
        loss.backward()
        optimizer.step()
        optimizer.zero_grad()
    cleanup()
```

优化器必须基于*特定设备上的那个模型*来声明（所以用 `ddp_model` 而不是 `model`），梯度才能正确计算。

最后，运行脚本可以用 PyTorch 自带的便捷命令行模块 `torchrun`。只要传入应使用的进程数和要运行的脚本即可：

```
torchrun --nproc_per_node=2 --nnodes=1 example_script.py
```

上面的命令会在单台机器的两块 GPU 上运行训练脚本。这就是用 PyTorch 做分布式训练的全部底层要素。

接下来聊聊 Accelerate——一个旨在让这个过程更顺滑、还帮忙落实一些最佳实践的库。

## 🤗 Accelerate

[Accelerate](https://huggingface.co/docs/accelerate) 就是为让你做上面那些事而几乎不用大改代码而设计的库。除此之外，Accelerate 内置的数据管线还能提升你代码的性能。

首先，把上面所有代码打包进一个函数，方便直观对比差异：

```
def train_ddp(rank, world_size):
    setup(rank, world_size)
    # Build DataLoaders
    transform = transforms.Compose([
        transforms.ToTensor(),
        transforms.Normalize((0.1307), (0.3081))
    ])

    train_dset = datasets.MNIST('data', train=True, download=True, transform=transform)
    test_dset = datasets.MNIST('data', train=False, transform=transform)

    train_loader = torch.utils.data.DataLoader(train_dset, shuffle=True, batch_size=64)
    test_loader = torch.utils.data.DataLoader(test_dset, shuffle=False, batch_size=64)

    # Build model
    model = model.to(rank)
    ddp_model = DDP(model, device_ids=[rank])

    # Build optimizer
    optimizer = optim.AdamW(ddp_model.parameters(), lr=1e-3)

    # Train for a single epoch
    ddp_model.train()
    for batch_idx, (data, target) in enumerate(train_loader):
        data, target = data.to(rank), target.to(rank)
        output = ddp_model(data)
        loss = F.nll_loss(output, target)
        loss.backward()
        optimizer.step()
        optimizer.zero_grad()
    
    # Evaluate
    model.eval()
    correct = 0
    with torch.no_grad():
        for data, target in test_loader:
            data, target = data.to(rank), target.to(rank)
            output = ddp_model(data)
            pred = output.argmax(dim=1, keepdim=True)
            correct += pred.eq(target.view_as(pred)).sum().item()
    print(f'Accuracy: {100. * correct / len(test_loader.dataset)}')
```

再来看 Accelerate 怎么帮忙。上面的代码有几个问题：

- 稍微低效：每个设备都要构建 `n` 份 dataloader 并推送过去。
- 这段代码**只能**跑多 GPU，若想再跑回单机或 TPU，得做特殊处理。

Accelerate 通过 [`Accelerator`](https://huggingface.co/docs/accelerate/v0.12.0/en/package_reference/accelerator#accelerator) 类来解决。有了它，代码与原来几乎一样，单机和多机相比只多三行：

```
def train_ddp_accelerate():
    accelerator = Accelerator()
    # Build DataLoaders
    transform = transforms.Compose([
        transforms.ToTensor(),
        transforms.Normalize((0.1307), (0.3081))
    ])

    train_dset = datasets.MNIST('data', train=True, download=True, transform=transform)
    test_dset = datasets.MNIST('data', train=False, transform=transform)

    train_loader = torch.utils.data.DataLoader(train_dset, shuffle=True, batch_size=64)
    test_loader = torch.utils.data.DataLoader(test_dset, shuffle=False, batch_size=64)

    # Build model
    model = BasicNet()

    # Build optimizer
    optimizer = optim.AdamW(model.parameters(), lr=1e-3)

    # Send everything through `accelerator.prepare`
    train_loader, test_loader, model, optimizer = accelerator.prepare(
        train_loader, test_loader, model, optimizer
    )

    # Train for a single epoch
    model.train()
    for batch_idx, (data, target) in enumerate(train_loader):
        output = model(data)
        loss = F.nll_loss(output, target)
        accelerator.backward(loss)
        optimizer.step()
        optimizer.zero_grad()
    
    # Evaluate
    model.eval()
    correct = 0
    with torch.no_grad():
        for data, target in test_loader:
            data, target = data.to(device), target.to(device)
            output = model(data)
            pred = output.argmax(dim=1, keepdim=True)
            correct += pred.eq(target.view_as(pred)).sum().item()
    print(f'Accuracy: {100. * correct / len(test_loader.dataset)}')
```

有了这些，你的 PyTorch 训练循环就准备好在任何分布式设置上运行了——全靠 `Accelerator` 对象。这段代码既可以通过 `torchrun` CLI 启动，也可以通过 Accelerate 自己的 CLI 接口 [`accelerate launch`](https://huggingface.co/docs/accelerate/v0.12.0/en/basic_tutorials/launch) 启动。

这样一来，用 Accelerate 做分布式训练已是小菜一碟，同时裸写 PyTorch 的代码风格能尽量保持不变。

前文提到 Accelerate 还会让 DataLoader 更高效。这得益于它的自定义 Sampler：训练时可以自动把批次的一部分分发到不同设备上，让同一份数据在内存中只存在一份，而不是视配置同时存在四份。此外，内存中原始数据集总共只保留一份完整拷贝。数据集的子集被切分给所有参与训练的节点，因此更大的数据集也能在单实例上训练而不会内存爆炸。

### 使用 `notebook_launcher`

前面说过，可以直接在 Jupyter Notebook 里启动分布式代码。这来自 Accelerate 的 [`notebook_launcher`](https://huggingface.co/docs/accelerate/v0.12.0/en/basic_tutorials/notebook) 工具，它允许基于 Jupyter Notebook 里的代码启动多 GPU 训练。

用法简单到只需导入 launcher：

```
from accelerate import notebook_launcher
```

然后传入前面声明的训练函数、要传递的任意参数，以及使用的进程数（TPU 上是 8，两块 GPU 就是 2）。上面两个训练函数都可以跑，但注意一次 launch 启动后，必须重启实例才能再次启动。

```
notebook_launcher(train_ddp, args=(), num_processes=2)
```

或：

```
notebook_launcher(train_ddp_accelerate, args=(), num_processes=2)
```

## 使用 🤗 Trainer

最后，我们来到最高的抽象层——Hugging Face [Trainer](https://huggingface.co/docs/transformers/main_classes/trainer)。

它把训练中能封装的都封装了，同时仍然能在分布式系统上训练，用户什么都不用做。

首先导入 Trainer：

```
from transformers import Trainer
```

然后定义一些 `TrainingArguments` 来控制所有常用超参。Trainer 通过字典工作，所以需要做一个自定义 collate 函数。

最后，子类化 Trainer，写上自己的 `compute_loss`。

之后，这段代码同样可以跑在分布式环境上，完全不需要自己写任何训练代码！

```
from transformers import Trainer, TrainingArguments

model = BasicNet()

training_args = TrainingArguments(
    "basic-trainer",
    per_device_train_batch_size=64,
    per_device_eval_batch_size=64,
    num_train_epochs=1,
    evaluation_strategy="epoch",
    remove_unused_columns=False
)

def collate_fn(examples):
    pixel_values = torch.stack([example[0] for example in examples])
    labels = torch.tensor([example[1] for example in examples])
    return {"x":pixel_values, "labels":labels}

class MyTrainer(Trainer):
    def compute_loss(self, model, inputs, return_outputs=False):
        outputs = model(inputs["x"])
        target = inputs["labels"]
        loss = F.nll_loss(outputs, target)
        return (loss, outputs) if return_outputs else loss

trainer = MyTrainer(
    model,
    training_args,
    train_dataset=train_dset,
    eval_dataset=test_dset,
    data_collator=collate_fn,
)
```

```
trainer.train()
```

和上面 `notebook_launcher` 的例子一样，这里也可以把全部代码塞进一个训练函数来跑：

```
def train_trainer_ddp():
    model = BasicNet()

    training_args = TrainingArguments(
        "basic-trainer",
        per_device_train_batch_size=64,
        per_device_eval_batch_size=64,
        num_train_epochs=1,
        evaluation_strategy="epoch",
        remove_unused_columns=False
    )

    def collate_fn(examples):
        pixel_values = torch.stack([example[0] for example in examples])
        labels = torch.tensor([example[1] for example in examples])
        return {"x":pixel_values, "labels":labels}

    class MyTrainer(Trainer):
        def compute_loss(self, model, inputs, return_outputs=False):
            outputs = model(inputs["x"])
            target = inputs["labels"]
            loss = F.nll_loss(outputs, target)
            return (loss, outputs) if return_outputs else loss

    trainer = MyTrainer(
        model,
        training_args,
        train_dataset=train_dset,
        eval_dataset=test_dset,
        data_collator=collate_fn,
    )

    trainer.train()

notebook_launcher(train_trainer_ddp, args=(), num_processes=2)
```
