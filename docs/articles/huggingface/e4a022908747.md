# Hugging Face 与 Cerebras 把 Gemma 4 带入实时语音 AI

对语音 AI 而言，延迟是关键参数。开发者在模型质量上已取得巨大进步，但用户体验仍常常受响应时间拖累。Hugging Face 和 Cerebras 正在改变这种体验。今天，我们演示当开放的、模块化的语音 AI 架构遇上业界领先的推理速度时，会成为什么样子。

结果是一种自然得多的 speech-to-speech 体验。对话不再是等待 AI 回应，而是像用户对人际交流的期待那样流畅地推进。

## 架构：开放的级联式 Speech-to-Speech 技术栈

该 demo 构建为一条实时 speech-to-speech 管道。系统的每个部分都是模块化、开放、可替换的，便于开发者为不同的助手、机器人、产品或研究项目调整整个技术栈。

这形成一个完全开放的语音到语音循环：

```
Speech input
  -> speech recognition with Nvidia's Parakeet
  -> Gemma 4 VLM inference on Cerebras
  -> text-to-speech with Alibaba's Qwen3TTS
  -> spoken response
```

这个架构汇聚了开源 AI 生态的优势：Cerebras 提供快速推理，Google DeepMind 的 Gemma 4 31B 担当语言模型，Qwen 负责文本转语音。每一层都可以被开发者检查、修改和扩展。

## Cerebras 与 Hugging Face 的合作

今天，一些生产系统的中位延迟看起来不错，但在 P95 上仍会出现令人沮丧的数秒级延迟。当工具调用或多模态步骤需要多轮往返时，这些延迟更加明显。

Cerebras 帮助解决该技术栈中最关键的瓶颈之一：语言模型的响应时间。通过让推理显著更快、更稳定，Cerebras 让 Hugging Face 管道的其余部分得以充分发光。

这种稳定性在长尾上尤其重要。许多系统能达到可接受的中位响应时间，但偶发的慢响应仍会让对话显得不可靠。

## 为真实交互而生

同一条 Hugging Face speech-to-speech 管道已经驱动着 Reachy Mini 机器人，而全球在用的 Reachy Mini 已超过 9000 台。对机器人、语音助手和具身 AI 来说，响应速度不是表面修饰，而是让交互"活起来"的关键。

因此，选择 Cerebras 的动机不只是降低成本，而是低延迟、可预测的性能，以及在规模化下创造自然而然的实时体验的能力。

这次合作反映了一个共同信念：AI 的未来既开放又高性能。开源模型、开放基础设施与突破性推理速度结合，为下一代对话 AI 打下基础。

我们邀请开发者体验这个 demo、试验代码，一起塑造实时语音 AI 的未来。
