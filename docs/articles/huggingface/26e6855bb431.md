# Hugging Face Hub：重要的 Git 身份验证变更

Sylvestre Bcht（Sylvestre）、Pierric Cistac（pierric）、Simon Brandeis（sbrandeis）

本文另有中文版本 [简体中文](https://huggingface.co/blog/zh/password-git-deprecation)。

由于我们致力于提升服务的安全性，我们要改变你通过 Git 与 Hugging Face Hub 交互时的身份验证方式。从 **2023 年 10 月 1 日**起，我们不再接受用密码来认证你的命令行 Git 操作。取而代之，我们建议使用更安全的身份验证方式，比如把密码换成个人访问令牌（personal access token）或使用 SSH 密钥。

## 背景

近几个月，我们实现了多项安全增强，包括登录提醒和在 Git 中支持 SSH 密钥。但用户仍能用用户名和密码来认证 Git 操作。为进一步改善安全性，我们现在过渡到基于令牌或 SSH 密钥的身份验证。基于令牌和 SSH 密钥的身份验证相比传统密码认证有诸多优势，包括独有、可撤销、随机等特性，能提升安全性与掌控力。

## 需要立即行动

如果你目前用 HF 账号密码来认证 Git，请在 **2023 年 10 月 1 日**前改用个人访问令牌或 SSH 密钥。

### 切换到个人访问令牌

你需要为账号生成一个访问令牌，可按 [https://huggingface.co/docs/hub/security-tokens#user-access-tokens](https://huggingface.co/docs/hub/security-tokens#user-access-tokens) 生成一个。

生成访问令牌后，你可以用以下命令更新你的 Git 仓库：

```
$: git remote set-url origin https://<user_name>:<token>@huggingface.co/<repo_path>
$: git pull origin
```

其中 `<repo_path>` 形式为：

- 模型用 `<user_name>/<repo_name>`
- 数据集用 `datasets/<user_name>/<repo_name>`
- Spaces 用 `spaces/<user_name>/<repo_name>`

如果你克隆一个新仓库，当你的 Git 凭据管理器索要身份验证凭据时，直接在密码位置填入令牌即可。

### 切换到 SSH 密钥

按照我们的指南生成 SSH 密钥并加到你的账号：[https://huggingface.co/docs/hub/security-git-ssh](https://huggingface.co/docs/hub/security-git-ssh)

之后你就能用以下命令更新 Git 仓库：

```
$: git remote set-url origin git@hf.co:<repo_path> # see above for the format of the repo path
```

## 时间线

接下来几周你会看到：

- 今天：依赖密码做 Git 认证的用户可能会收到邮件，敦促他们更新认证方式。
- 10 月 1 日：所有 Git 操作将强制使用个人访问令牌或 SSH 密钥。
