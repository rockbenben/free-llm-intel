## Falcon 2 模型

[TII](https://huggingface.co/blog/www.tii.ae) 推出新一代模型 [Falcon 2](https://falconllm.tii.ae/)，目标是为开源社区提供一系列性能更强、支持多模态的更小模型。我们的目标是降低推理成本，并推动更多易用性更好的下游应用发展。

第一代 Falcon 模型——[Falcon-40B](https://huggingface.co/tiiuae/falcon-40b) 和 [Falcon-180B](https://huggingface.co/tiiuae/falcon-180B)——为开源社区作出了重要贡献，带动了宽松许可先进 LLM 的发布。上一代 Falcon 模型的详细信息见 [RefinedWeb, Penedo et al., 2023](https://proceedings.neurips.cc/paper_files/paper/2023/hash/fa3ed726cc5073b9c31e3e49a807789c-Abstract-Datasets_and_Benchmarks.html) 和 [The Falcon Series of Open Language Models, Almazrouei et al., 2023](https://arxiv.org/abs/2311.16867) 论文，以及 [Falcon](https://huggingface.co/blog/falcon) 和 [Falcon-180B](https://huggingface.co/blog/falcon-180b) 博客。

第二代模型聚焦更高的易用性与可集成性，构建多模态生态。我们迈出这一步：不仅发布基座 [11B LLM](https://huggingface.co/tiiuae/falcon-11B)，还发布加入图像理解能力的 [11B VLM 模型](https://huggingface.co/tiiuae/Falcon-11B-vlm)。视觉-语言模型（VLM）让用户可以用文字就视觉内容展开对话。

与我们之前的工作一样，模型主要支持英语，但在其他十种语言上也有不错能力，包括西班牙语、法语和德语。

## Falcon2-11B LLM

### 训练数据

Falcon2-11B 在超过 5000 GT（十亿 token）的 RefinedWeb 上训练——这是经过高质量过滤去重的网页数据集，并叠加了精心整理的语料。训练采用四阶段策略：前三个阶段逐步扩展上下文长度，从 2048 到 4096 再到 8192 token；最后一个阶段只用高质量数据进一步提升性能。

总体上数据来源包括 RefinedWeb-English、RefinedWeb-Europe（*cs*、*de*、*es*、*fr*、*it*、*nl*、*pl*、*pt*、*ro*、*sv*）、高质量技术数据、代码数据，以及从公开来源提取的对话数据。

各训练阶段如下：

| 阶段 | 上下文长度 | GT |
| --- | --- | --- |
| Stage 1 | 2048 | 4500 |
| Stage 2 | 4096 | 250 |
| Stage 3 | 8192 | 250 |
| Stage 4 | 8192 | 500 |

数据用 [Falcon2-11B 分词器](https://huggingface.co/tiiuae/falcon-11B/blob/main/tokenizer.json) 分词，与之前的 Falcon 模型相同。

### 模型架构

下表汇总模型架构的一些关键细节：

| 设计选择 | 取值 |
| --- | --- |
| Transformer Block 数 | 60 |
| Query Head 数 | 32 |
| Key/Value Head 数 | 8 |
| Head 维度 | 128 |
| 并行注意力 | 是 |
| MLP 扩展倍数 | 4 |

### 训练过程

Falcon2-11B 大部分训练在 1024 张 A100 40GB 上进行，采用 3D 并行策略（TP=8、PP=1、DP=128），并配合 ZeRO 与 Flash-Attention 2。

### 训练超参数

| 超参数 | 取值 |
| --- | --- |
| 精度 | bfloat16 |
| 优化器 | AdamW |
| 最大 LR | 3.7e-4 |
| 最小 LR | 1.89e-5 |
| LR 调度 | Cos decay（stage 1） |
| 上下文长度 | 8192（stage 3、4） |
| 权重衰减 | 1e-1 |
| Z-loss | 1e-4 |
| Batch size | 可变 |

## 使用 Falcon2-11B

```
from transformers import AutoTokenizer
import transformers
import torch

model = "tiiuae/falcon-11B"

tokenizer = AutoTokenizer.from_pretrained(model)
pipeline = transformers.pipeline(
    "text-generation",
    model=model,
    torch_dtype=torch.bfloat16,
    device_map="auto",
)
```

然后用类似下面的代码做文本生成：

```
sequences = pipeline(
   "Can you explain the concept of Quantum Computing?",
    max_length=200,
    do_sample=True,
    top_k=10,
    num_return_sequences=1,
    eos_token_id=tokenizer.eos_token_id,
)
for seq in sequences:
    print(f"Result: {seq['generated_text']}")
```

## Falcon2-11B VLM

[Falcon2-11B VLM](https://huggingface.co/tiiuae/Falcon-11B-vlm) 是构建在该 LLM 之上的视觉-语言模型（VLM），额外支持图像输入并能回答与图像相关的问题。为此，我们把预训练的 CLIP ViT-L/14 视觉编码器接入基于对话微调的 Falcon2-11B，并用图文数据训练。

为了增强 VLM 对图像中小物体等细节的感知，我们对图像输入采用高分辨率下的动态编码机制，思路类似 [LLaVA-Next](https://llava-vl.github.io/blog/2024-01-30-llava-next/)。

### 训练

训练分两个阶段：预训练和微调。两个阶段中视觉编码器权重都保持冻结。预训练阶段 LLM 也冻结，只训练多模态投影器（projector），使用 55.8 万对图像-说明文本。这让投影器学会从视觉空间到文本嵌入空间的映射。微调阶段则同时训练投影器和 LLM，语料为 120 万条来自公开数据集的图文指令数据，其中也包含多轮对话。

## 使用 Falcon2-11B-FalconVLM

```
from transformers import LlavaNextForConditionalGeneration, LlavaNextProcessor
from PIL import Image
import requests
import torch

processor = LlavaNextProcessor.from_pretrained("tiiuae/falcon-11B-vlm")
model = LlavaNextForConditionalGeneration.from_pretrained("tiiuae/falcon-11B-vlm", torch_dtype=torch.bfloat16)

url = "https://merzougabirding.com/wp-content/uploads/2023/09/falcon-size.jpg"
falcon_image = Image.open(requests.get(url, stream=True).raw)
prompt = "User: <image>\nWhat's special about this bird's vision?"

inputs = processor(prompt, images=falcon_image, return_tensors="pt", padding=True).to('cuda:0')

model.to('cuda:0')
output = model.generate(**inputs, max_new_tokens=256)


prompt_length = inputs['input_ids'].shape[1]
generated_captions = processor.decode(output[0], skip_special_tokens=True).strip()

print(generated_captions)
```
