# 搭建你自己的 Hugging Face 榜单指南：以 Vectara 幻觉榜单为例的端到端实践

Hugging Face 的 [Open LLM Leaderboard](https://huggingface.co/spaces/HuggingFaceH4/open_llm_leaderboard)（最初由 Ed Beeching 和 Lewis Tunstall 创建，现由 Nathan Habib 和 Clémentine Fourrier 维护）以追踪开源 LLM 性能而闻名，在 [TruthfulQA](https://github.com/sylinrl/TruthfulQA)、[HellaSwag](https://rowanzellers.com/hellaswag/) 等多种任务上对比模型表现。

这对开源社区极具价值，为实践者提供了一条追踪最佳开源模型的途径。

2023 年末，我们在 Vectara 推出了 [Hughes 幻觉评估模型](https://huggingface.co/vectara/hallucination_evaluation_model)（HHEM），一个用于衡量 LLM [幻觉](https://vectara.com/glossary-of-llm-terms/#h-hallucinations-aka-llm-hallucinations)程度（生成无意义或偏离所提供源内容的文本）的开源模型。它覆盖 Llama 2、Mistral 7B 等开源模型，也覆盖 OpenAI 的 GPT-4、Anthropic Claude、Google Gemini 等商业模型，凸显了当前不同模型在幻觉倾向上的巨大差异。

随着我们不断向 HHEM 添加新模型，我们在寻找一个开源方案来管理和更新 HHEM 榜单。

最近，Hugging Face 榜单团队发布了榜单模板（[这里](https://huggingface.co/demo-leaderboard)和[这里](https://huggingface.co/demo-leaderboard-backend)）。它们是 Open LLM Leaderboard 本身的轻量版本，既开源又比原始代码更简单易用。

今天我们很高兴宣布[新 HHEM 榜单](https://huggingface.co/spaces/vectara/leaderboard)上线，由 [HF 榜单模板](https://huggingface.co/demo-leaderboard-backend)驱动。

## Vectara 的 Hughes 幻觉评估模型（HHEM）

Hughes 幻觉评估模型（HHEM）榜单专注于评估 GPT-4、Google Gemini、Meta Llama 2 等大语言模型生成文档摘要时幻觉出现的频率。使用方法请遵循[这里](https://huggingface.co/vectara/hallucination_evaluation_model)的说明。

在 [Vectara](https://vectara.com)，我们通过开源发布这个模型，旨在让 LLM 幻觉评估民主化，唤起人们对 LLM 在幻觉倾向性能差异上的关注。

HHEM 的首个版本是一个 [Huggingface 模型](https://huggingface.co/vectara/hallucination_evaluation_model)外加一个 [Github 仓库](https://github.com/vectara/hallucination-leaderboard)，但我们很快意识到需要一种机制来评估新类型的模型。借助 HF 榜单代码模板，我们快速搭建了一个支持动态更新的新榜单，并鼓励 LLM 社区提交新的相关模型进行 HHEM 评估。

对我们 Vectara 人有特别意义的是，HHEM 以我们的伙伴 Simon Hughes 命名。他于 2023 年 11 月因非自然原因骤然离世；我们决定以他之名命名，以纪念他在这个领域留下的持久遗产。

## 用 LLM 榜单模板搭建 HHEM

搭建 Vectara HHEM 榜单时，我们按 HF 榜单模板代码适配自身需求，走了几步：

- 把 space 仓库克隆到我们自己的组织后，创建了两个配套数据集："requests" 和 "results"；这两个数据集分别保存用户提交的新 LLM 评估请求，以及评估结果。
- 我们用首次发布时的既有结果填充了 results 数据集，并更新了 "About" 和 "Citations" 部分。

对于由你的后端把评估结果推送到 results 数据集的简单榜单，这就是全部所需！

由于我们的评估更复杂，我们又为 HHEM 榜单的需求定制了源码——细节如下：

- `leaderboard/src/backend/model_operations.py`：该文件包含两个主要类——`SummaryGenerator` 和 `EvaluationModel`。a. `SummaryGenerator` 基于 HHEM 私有评估数据集生成摘要，并计算 Answer Rate、Average Summary Length 等指标。b. `EvaluationModel` 加载我们自研的 Hughes 幻觉评估模型（HHEM）来评估这些摘要，得出 Factual Consistency Rate、Hallucination Rate 等指标。
- `leaderboard/src/backend/evaluate_model.py`：定义 `Evaluator` 类，同时使用 `SummaryGenerator` 和 `EvaluationModel` 计算并以 JSON 格式返回结果。
- `leaderboard/src/backend/run_eval_suite.py`：包含函数 `run_evaluation`，借助 `Evaluator` 获取评估结果并上传到上述 `results` 数据集，使其出现在榜单上。
- `leaderboard/main_backend.py`：管理待处理评估请求并调用上述类和函数执行自动评估，还提供让用户复现我们评估结果的选项。

最终源码在我们 [HHEM 榜单仓库](https://huggingface.co/spaces/vectara/leaderboard)的 [Files 标签页](https://huggingface.co/spaces/vectara/leaderboard/tree/main)。完成这些改动后，我们的评估管道已经就绪，并且可以轻松部署为 Huggingface Space。

## 总结

[HHEM](https://huggingface.co/vectara/hallucination_evaluation_model)是一种新型分类模型，可用于评估 LLM 幻觉的程度。我们对 Hugging Face 榜单模板的使用，为任何榜单都会遇到的普遍需求提供了急需的支持：管理新模型评估请求的提交，以及随新结果出现更新榜单。

大力感谢 Hugging Face 团队把这个宝贵框架开源，并在实现过程中支持 Vectara 团队。我们期待其他想发布不同类型 LLM 榜单的社区成员复用这份代码。

如果你想用新模型为 HHEM 做贡献，请在榜单上提交——我们非常欢迎任何待评估新模型的建议。

如有关于 Hugging Face LLM 前端或 Vectara 的问题，欢迎在 [Vectara](https://discuss.vectara.com/) 或 [Huggingface](https://discuss.huggingface.co/) 论坛中联系。
