# 从截图到 HTML 代码：介绍 WebSight 数据集

在 Web 开发领域，把设计稿变成可用的网站通常离不开大量编码和反复测试。如果我们能简化这个过程，让 Web 设计更容易、更快地变成能运行的网站会怎样？WebSight 是一个新数据集，旨在构建能够把截图转换成 HTML 代码的 AI 系统。

## 挑战

把网站设计稿或截图转成 HTML 代码通常需要一位经验丰富的开发者。但如果这事能更高效呢？带着这个问题，我们研究了如何将视觉-语言模型（VLM）用于 Web 开发，以打造提升效率的低代码解决方案。

如今，迈向这一目标的主要挑战在于缺乏为该任务定制的高质量数据集。WebSight 正是要填补这一空白。

## WebSight：一个由截图/HTML 代码对组成的大规模合成数据集

2024 年 1 月，我们推出了 [WebSight-v0.1](https://huggingface.co/datasets/HuggingFaceM4/WebSight)，一个由 823,000 组 HTML 代码及其对应截图构成的合成数据集。该数据集旨在训练 AI 模型处理和把视觉化的 Web 设计翻译成可用的 HTML 代码。通过聚焦合成数据，我们绕开了真实世界 HTML 中常见的噪声和复杂性，让 AI 模型能高效学习。

在首次发布之后，基于社区的反馈，我们将数据集更新到 WebSight-v0.2，带来了显著改进。这些改进包括：在截图里使用真实图像，以及改用 Tailwind CSS（而非传统 CSS）。我们还把数据集扩展到 200 万个样本。

WebSight 中包含的网页示例。

## Sightseer：一个在 WebSight 上微调的模型

借助 WebSight 数据集，我们对我们即将推出的基础视觉-语言模型进行了微调，得到 Sightseer——一个能够把网页截图转换成可用 HTML 代码的模型。Sightseer 还展现出将图像嵌入生成 HTML 的能力，使生成的图像与原始截图中高度相似。

左侧为原始网页（输入），右侧为我们模型 Sightseer（输出）生成的代码渲染结果对比。

## 迈向视觉语言模型解锁的更强力工具

通过在 WebSight 上不断迭代，我们的目标是构建更强的 AI 系统，简化把 UI 设计变成可用代码的过程。这可以通过把纸面上的 UI 草图快速转化为可用代码来缩短开发者的迭代时间，同时让非开发者也能更轻松地使用这一流程。这只是视觉语言模型众多实际应用之一。通过开源 WebSight，我们鼓励社区与我们一起，为 UI 开发构建更强力的工具。
