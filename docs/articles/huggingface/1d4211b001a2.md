# 用你的 AWS 账户订阅 Enterprise Hub

现在你可以用 AWS 账户把 Hugging Face 组织升级到 Enterprise——请到 [AWS Marketplace](https://aws.amazon.com/marketplace/pp/prodview-n6vsyhdjkfng2) 开始。

## 什么是 Enterprise Hub？

[Enterprise Hub](https://huggingface.co/enterprise) 是一款高级订阅，可把免费的 Hugging Face 组织升级为具备高级安全功能、访问控制、协作工具与算力选项的版本。借助 Enterprise Hub，企业可以在我们符合 GDPR 且通过 SOC2 Type 2 认证的平台内，私密、安全地构建 AI。专属功能包括：

- 单点登录（SSO）：确保组织的所有成员都是你公司的员工。
- 资源组（Resource Groups）：以细粒度的仓库访问控制管理团队与项目。
- 存储区域（Storage Regions）：把公司仓库存放在欧洲以满足 GDPR 合规。
- 审计日志（Audit Logs）：访问关于组织与仓库变更的详细日志。
- 高级算力选项：给团队更高配额和更强的 GPU。
- 私有数据集查看器：为你的私有数据集启用 Dataset Viewer，让协作更轻松。
- 在 DGX Cloud 上训练：在 NVIDIA DGX Cloud 管理的 NVIDIA H100 GPU 上无需代码训练 LLM。
- 高级支持：通过专属支持充分利用 Enterprise Hub 并控制成本。

如果你是组织的管理员，可以直接用信用卡轻松升级。但如何用 AWS 账户把组织升级到 Enterprise Hub？下面逐步带你完成。

### 1. 开始之前

在把 AWS 账户与 Hugging Face 账户关联之前，你需要满足以下前提条件：

- 拥有一个可用的、且具备 AWS Marketplace 订阅产品权限的 AWS 账户。
- 创建一个 [Hugging Face 组织账户](https://huggingface.co/organizations/new)，并完成邮箱注册与确认（无法关联个人账户）。
- 成为你要连接的 Hugging Face 组织的成员，并持有 ["admin" 角色](https://huggingface.co/docs/hub/organizations-security)。
- 已登录 Hugging Face 平台。

满足这些要求后，就可以开始关联你的 AWS 和 Hugging Face 账户。

### 2. 把 Hugging Face 账户与 AWS 账户关联

第一步，前往 [AWS Marketplace 商品页](https://aws.amazon.com/marketplace/pp/prodview-n6vsyhdjkfng2)订阅 Hugging Face 平台。打开[该 offer](https://aws.amazon.com/marketplace/pp/prodview-n6vsyhdjkfng2)，点击右上角的 "View purchase options"。

[![Marketplace Offer](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/01_bis_offering.jpg)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/01_bis_offering.jpg)

你现在位于 "subscribe" 页面，这里可以看到定价摘要并进行订阅。点击 "Subscribe" 订阅该 offer。

[![Marketplace Subscribe](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/02_bis_subscribe.jpg)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/02_bis_subscribe.jpg)

成功订阅后，顶部会出现一条绿色横幅和 "Set up your account" 按钮。点击 "Set up your account"，将你的 Hugging Face 账户与 AWS 账户关联。

[![Marketplace Redirect](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/03_bis_redirect.jpg)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/03_bis_redirect.jpg)

点击后你会被重定向到 Hugging Face 平台，在这里选择要与 AWS 账户绑定的 Hugging Face 组织账户。选好后点击 "Submit"。

[![Connect Account](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/04_connect.jpg)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/04_connect.jpg)

点击 "Submit" 后，你会被重定向到该 Hugging Face 组织的 Billings 设置页，可以看到当前订阅状态，应为 `subscribe-pending`。

[![Subscription Pending](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/05_pending.jpg)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/05_pending.jpg)

几分钟后，你应该会收到两封邮件：一封来自 AWS 确认你的订阅，一封来自 Hugging Face，样子应如下图所示：

[![Email confirmation](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/07_email.jpg)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/07_email.jpg)

如果你收到了这封邮件，你的 AWS 账户与 Hugging Face 组织账户就已成功关联！可在[组织账户](https://huggingface.co/settings/organizations)的 Billing 设置中确认，此时应显示 `subscribe-success` 状态。

[![Subscription Confirmed](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/06_success.jpg)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/06_success.jpg)

### 3. 为你的团队激活 Enterprise Hub 并解锁新功能

如果你想启用 Enterprise Hub，把组织作为私密、安全的协作平台，让团队用开源构建 AI，请按以下步骤操作。

打开组织的 Billing 设置，点击 "Enterprise Hub" 标签页，然后点击 "Subscribe Now"。

[![Subscribe Now](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/08_subscribe.jpg)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/08_subscribe.jpg)

接着选择你愿意为组织购买的 Enterprise Hub 席位数量、计费周期，然后点击 Checkout。

[![Select Seats](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/09_select.jpg)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/09_select.jpg)

### 恭喜！🥳

你的组织现在已升级为 Enterprise Hub，账单直接由 AWS 账户管理。组织的所有成员现在都能享受 Enterprise Hub 的高级功能，私密而安全地构建 AI。

通过 AWS Marketplace offer 使用 Hugging Face Hub 的定价与 [Hugging Face 公开定价](https://huggingface.co/pricing)完全一致，只是改由你的 AWS 账户出账。你可以随时在[组织设置](https://huggingface.co/settings/organizations)的 Billing 部分查看组织的用量和账单。
