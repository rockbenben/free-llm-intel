# 欢迎 fastText 加入 Hugging Face Hub

[fastText](https://fasttext.cc/) 是一个高效学习文本表示与分类的库。Meta AI 于 2016 年将其[开源](https://fasttext.cc/blog/2016-08-18/blog-post.html)，fastText 融合了过去几十年里在自然语言处理和机器学习中产生关键影响的思想：用词袋（bag of words）和 n-gram 袋表示句子、使用子词信息，以及利用隐变量表示在不同类别间共享信息。

为加速计算，fastText 使用层级 softmax（hierarchical softmax），充分利用了类别分布的不均衡性。这些技术共同为用户提供了可扩展的文本表示与分类方案。

Hugging Face 现在托管了全部 157 种语言词向量（word vectors）以及最新语言识别模型的官方镜像。这意味着借助 Hugging Face，你只需几条命令就能轻松下载和使用这些模型。

### 查找模型

157 种语言的词向量和语言识别模型可以在 [Meta AI](https://huggingface.co/facebook) 组织下找到。例如，英语词向量的模型页面在[这里](https://huggingface.co/facebook/fasttext-en-vectors)，语言识别模型在[这里](https://huggingface.co/facebook/fasttext-language-identification)。

### Widgets

这次集成支持文本分类和特征提取 widget。可以在[这里](https://huggingface.co/facebook/fasttext-language-identification)试用语言识别 widget，在[这里](https://huggingface.co/facebook/fasttext-en-vectors)试用特征提取 widget！

### 如何使用

以下是加载并使用预训练词向量的方法：

```
>>> import fasttext
>>> from huggingface_hub import hf_hub_download

>>> model_path = hf_hub_download(repo_id="facebook/fasttext-en-vectors", filename="model.bin")
>>> model = fasttext.load_model(model_path)
>>> model.words

['the', 'of', 'and', 'to', 'in', 'a', 'that', 'is', ...]

>>> len(model.words)

145940

>>> model['bread']

array([ 4.89417791e-01,  1.60882145e-01, -2.25947708e-01, -2.94273376e-01,
       -1.04577184e-01,  1.17962055e-01,  1.34821936e-01, -2.41778508e-01, ...])
```

以下是用该模型查询英语词向量最近邻的方法：

```
>>> import fasttext
>>> from huggingface_hub import hf_hub_download

>>> model_path = hf_hub_download(repo_id="facebook/fasttext-en-nearest-neighbors", filename="model.bin")
>>> model = fasttext.load_model(model_path)
>>> model.get_nearest_neighbors("bread", k=5)

[(0.5641006231307983, 'butter'), 
 (0.48875734210014343, 'loaf'), 
 (0.4491206705570221, 'eat'), 
 (0.42444291710853577, 'food'), 
 (0.4229326844215393, 'cheese')]
```

以下是用该模型检测给定文本语言的方法：

```
>>> import fasttext
>>> from huggingface_hub import hf_hub_download

>>> model_path = hf_hub_download(repo_id="facebook/fasttext-language-identification", filename="model.bin")
>>> model = fasttext.load_model(model_path)
>>> model.predict("Hello, world!")

(('__label__eng_Latn',), array([0.81148803]))

>>> model.predict("Hello, world!", k=5)

(('__label__eng_Latn', '__label__vie_Latn', '__label__nld_Latn', '__label__pol_Latn', '__label__deu_Latn'), 
 array([0.61224753, 0.21323682, 0.09696738, 0.01359863, 0.01319415]))
```
