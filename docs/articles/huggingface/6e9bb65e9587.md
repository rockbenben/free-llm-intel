# 欢迎 fastai 加入 Hugging Face Hub

本文由 Omar Espejel（espejelomar）撰写。

## 让神经网络再次"不酷"……并把它们分享出来

在让深度学习变得普及方面，很少有人能像 [fast.ai](https://www.fast.ai/) 生态那样贡献良多。我们在 Hugging Face 的使命是让优质的机器学习走向大众化。让我们把包括[预训练模型](https://huggingface.co/models)在内的机器学习资源排他性变成历史，一起推动这个精彩领域更进一步。

fastai 是一个[开源深度学习库](https://github.com/fastai/fastai)，基于 PyTorch 和 Python 提供高层组件，可以快速训练出精度领先的高性能神经网络，覆盖文本、视觉与表格数据。不过，fast.ai 这家公司远不止一个库：它已成长为一个由开源贡献者和神经网络学习者组成的繁荣生态。举几个例子，可以看看他们的[书](https://github.com/fastai/fastbook)和[课程](https://course.fast.ai/)。加入 fast.ai 的 [Discord](https://discord.com/invite/YKrxeNn) 和[论坛](https://forums.fast.ai/)。成为他们社区的一员，你保证能学到东西！

正因为这一切（以及更多——本文作者正是因 fast.ai 课程踏上了这段旅程），我们自豪地宣布：fastai 用户现在可以用一行 Python 把模型分享并上传到 Hugging Face Hub。

👉 在这篇文章中，我们将介绍 fastai 与 Hub 的集成。你也可以把这个教程作为 [Colab notebook](https://colab.research.google.com/github/huggingface/blog/blob/main/notebooks/64_fastai_hub.ipynb) 打开。

我们要感谢 fast.ai 社区，特别是 [Jeremy Howard](https://twitter.com/jeremyphoward)、[Wayde Gilliam](https://twitter.com/waydegilliam) 和 [Zach Mueller](https://twitter.com/TheZachMueller) 提供的反馈 🤗。本博客大量参考了 fastai 文档中的 [Hugging Face Hub 章节](https://docs.fast.ai/huggingface.html)。

## 为什么要分享到 Hub？

Hub 是一个中心化的平台，任何人都可以在这里分享和探索模型、数据集与 ML 演示。它拥有规模最大的开源模型、数据集和演示合集。

在 Hub 上分享会放大你 fastai 模型的影响，让他人可以下载和探索。你也可以对 fastai 模型使用迁移学习；把他人的模型作为你任务的基础。

任何人都可以通过在 [hf.co/models](https://huggingface.co/models?library=fastai&sort=downloads) 页面按 fastai 库过滤来访问 Hub 上所有的 fastai 模型，如下图。

[![Fastai Models in the Hub](https://huggingface.co/blog/assets/64_fastai/hf_hub_fastai.png)](https://huggingface.co/blog/assets/64_fastai/hf_hub_fastai.png)

除了免费的模型托管和面向更广泛社区的曝光，Hub 还内置[基于 git 的版本控制](https://huggingface.co/docs/transformers/model_sharing#repository-features)（大文件用 git-lfs）以及用于提升可发现性与可复现性的[模型卡](https://huggingface.co/docs/hub/models-cards)。关于在 Hub 中导航的更多信息，参见[这份介绍](https://github.com/huggingface/education-toolkit/blob/main/01_huggingface-hub-tour.md)。

## 加入 Hugging Face 与安装

要在 Hub 上分享模型，你需要一个用户账号。请在 [Hugging Face 网站](https://huggingface.co/join)创建。

`huggingface_hub` 库是一个轻量级 Python 客户端，提供与 Hugging Face Hub 交互的工具函数。要把 fastai 模型推送到 Hub，你需要预装一些库（fastai>=2.4、fastcore>=1.3.27 和 toml）。你可以在安装 `huggingface_hub` 时通过指定 ["fastai"] 自动安装它们，环境就准备好了：

```
pip install huggingface_hub["fastai"]
```

## 创建一个 fastai `Learner`

这里我们训练 [fastbook 中的第一个模型](https://github.com/fastai/fastbook/blob/master/01_intro.ipynb)来识别猫 🐱。我们强烈建议通读整本 fastbook。

```
# Training of 6 lines in chapter 1 of the fastbook.
from fastai.vision.all import *
path = untar_data(URLs.PETS)/'images'

def is_cat(x): return x[0].isupper()
dls = ImageDataLoaders.from_name_func(
    path, get_image_files(path), valid_pct=0.2, seed=42,
    label_func=is_cat, item_tfms=Resize(224))

learn = vision_learner(dls, resnet34, metrics=error_rate)
learn.fine_tune(1)
```

## 分享 `Learner` 到 Hub

[`Learner` 是一个 fastai 对象](https://docs.fast.ai/learner.html#Learner)，它把模型、数据加载器和损失函数打包在一起。在本文中，`Learner` 和"模型"这两个词可以互换使用。

首先，登录 Hugging Face Hub。你需要在[账号设置](http://hf.co/settings/tokens)中创建一个 `write` token。然后有三种登录方式：

- 在终端输入 `huggingface-cli login` 并输入你的 token。
- 如果在 python notebook 中，可以使用 `notebook_login`。

```
from huggingface_hub import notebook_login

notebook_login()
```

- 使用 `push_to_hub_fastai` 函数的 `token` 参数。

你可以把要上传的 `Learner` 和 Hub 上格式为 "namespace/repo_name" 的仓库 id 传给 `push_to_hub_fastai`。namespace 可以是个人账号，也可以是你拥有写权限的组织（例如 'fastai/stanza-de'）。更多细节请参考 [Hub Client 文档](https://huggingface.co/docs/huggingface_hub/main/en/package_reference/mixins#huggingface_hub.push_to_hub_fastai)。

```
from huggingface_hub import push_to_hub_fastai

# repo_id = "YOUR_USERNAME/YOUR_LEARNER_NAME"
repo_id = "espejelomar/identify-my-cat"

push_to_hub_fastai(learner=learn, repo_id=repo_id)
```

`Learner` 现在已经在 Hub 上名为 [`espejelomar/identify-my-cat`](https://huggingface.co/espejelomar/identify-my-cat) 的仓库中了。系统会自动创建一个模型卡，包含一些链接和后续步骤。把 fastai `Learner`（或任何模型）上传到 Hub 时，编辑它的模型卡（见下图）会帮助别人更好地理解你的工作（参考 [Hugging Face 文档](https://huggingface.co/docs/hub/models-cards)）。

[![Fastai Model Card](https://huggingface.co/blog/assets/64_fastai/hf_model_card.png)](https://huggingface.co/blog/assets/64_fastai/hf_model_card.png)

想更多了解 `push_to_hub_fastai`，请访问 [Hub Client 文档](https://huggingface.co/docs/huggingface_hub/main/en/package_reference/mixins#huggingface_hub.from_pretrained_fastai)。里面有一些你可能感兴趣酷炫参数 👀。记住，你的模型是一个 [Git 仓库](https://huggingface.co/docs/transformers/model_sharing#repository-features)，拥有它带来的一切优势：版本控制、提交、分支……

## 从 Hugging Face Hub 加载 `Learner`

从 Hub 加载模型更简单。我们将加载我们的 `Learner` "espejelomar/identify-my-cat"，并用一张猫的图片来测试它（🦮？）。这段代码改编自 [fastbook 第一章](https://github.com/fastai/fastbook/blob/master/01_intro.ipynb)。

首先，上传一张猫（或者可能是狗？）的图片。本教程的 [Colab notebook](https://colab.research.google.com/github/huggingface/blog/blob/main/notebooks/64_fastai_hub.ipynb) 使用 `ipywidgets` 交互式上传一张猫（或不是猫？）的图片。这里我们用这只可爱的猫 🐅：

[![Fastai Model Card](https://huggingface.co/blog/assets/64_fastai/cat.jpeg)](https://huggingface.co/blog/assets/64_fastai/cat.jpeg)

现在让我们加载刚分享到 Hub 的 `Learner` 并测试一下。

```
from huggingface_hub import from_pretrained_fastai

# repo_id = "YOUR_USERNAME/YOUR_LEARNER_NAME"
repo_id = "espejelomar/identify-my-cat"

learner = from_pretrained_fastai(repo_id)
```

它工作了 👇！

```
_,_,probs = learner.predict(img)
print(f"Probability it's a cat: {100*probs[1].item():.2f}%")

Probability it's a cat: 100.00%
```

[Hub Client 文档](https://huggingface.co/docs/huggingface_hub/main/en/package_reference/mixins#huggingface_hub.from_pretrained_fastai)包含 `from_pretrained_fastai` 的更多细节。

## 用 `Blurr` 混合 fastai 与 Hugging Face Transformers（并分享它们）！

> [Blurr 是]一个为想要训练和部署 Hugging Face transformers 的 fastai 开发者设计的库 —— Blurr 文档。

我们将：

- 用 [高层 Blurr API](https://github.com/ohmeow/blurr#using-the-high-level-blurr-api) 训练一个 `blurr` Learner。它会从 Hugging Face Hub 加载 `distilbert-base-uncased` 模型并准备一个序列分类模型。
- 用 `push_to_hub_fastai` 以 namespace `fastai/blurr_IMDB_distilbert_classification` 分享到 Hub。
- 用 `from_pretrained_fastai` 加载，并用 `learner_blurr.predict()` 试用。

协作与开源就是如此美好！

首先，安装 `blurr` 并训练 Learner。

```
git clone https://github.com/ohmeow/blurr.git
cd blurr
pip install -e ".[dev]"
```

```
import torch
import transformers
from fastai.text.all import *

from blurr.text.data.all import *
from blurr.text.modeling.all import *

path = untar_data(URLs.IMDB_SAMPLE)
model_path = Path("models")
imdb_df = pd.read_csv(path / "texts.csv")

learn_blurr = BlearnerForSequenceClassification.from_data(imdb_df, "distilbert-base-uncased", dl_kwargs={"bs": 4})
learn_blurr.fit_one_cycle(1, lr_max=1e-3)
```

使用 `push_to_hub_fastai` 分享到 Hub。

```
from huggingface_hub import push_to_hub_fastai

# repo_id = "YOUR_USERNAME/YOUR_LEARNER_NAME"
repo_id = "fastai/blurr_IMDB_distilbert_classification"

push_to_hub_fastai(learn_blurr, repo_id)
```

使用 `from_pretrained_fastai` 从 Hub 加载一个 `blurr` 模型。

```
from huggingface_hub import from_pretrained_fastai

# repo_id = "YOUR_USERNAME/YOUR_LEARNER_NAME"
repo_id = "fastai/blurr_IMDB_distilbert_classification"

learner_blurr = from_pretrained_fastai(repo_id)
```

用几个句子试一试，并用 `learner_blurr.predict()` 查看它们的情感（负面还是正面）。

```
sentences = ["This integration is amazing!",
             "I hate this was not available before."]

probs = learner_blurr.predict(sentences)

print(f"Probability that sentence '{sentences[0]}' is negative is: {100*probs[0]['probs'][0]:.2f}%")
print(f"Probability that sentence '{sentences[1]}' is negative is: {100*probs[1]['probs'][0]:.2f}%")
```

又一次成功了！

```
Probability that sentence 'This integration is amazing!' is negative is: 29.46%
Probability that sentence 'I hate this was not available before.' is negative is: 70.04%
```
