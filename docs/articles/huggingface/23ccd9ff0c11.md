# Baseten 加入 Hugging Face Inference Providers 🔥

[![banner image](https://huggingface.co/blog/assets/inference-providers/welcome-baseten.png)](https://huggingface.co/blog/assets/inference-providers/welcome-baseten.png)

我们很高兴地宣布，**Baseten** 现已成为 Hugging Face Hub 上受支持的 Inference Provider！

Baseten 加入了我们不断壮大的生态，直接在 Hub 的模型页面上扩展了 serverless 推理的广度和能力。Inference Providers 还无缝集成进我们的客户端 SDK（JS 和 Python 双版本），让你能用心仪的 provider 轻松调用各种模型。

[Baseten](https://baseten.com) 是一个覆盖 serverless AI、训练等的 AI 基础设施平台。凭借丰富的前沿模型目录，Baseten 让开发者只需极少配置就能把广泛的 AI 能力集成进自己的应用。

Baseten 支持多种类型的模型——从 LLM 到语音合成（text-to-speech）等等。作为本次集成的一部分，Baseten 在 Hugging Face 上率先开放**对话与文本生成任务**，可以访问诸如 [Kimi K3](https://huggingface.co/moonshotai/Kimi-K3?inference_provider=baseten)、最新的 [DeepSeek V4 Flash](https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash-0731?inference_provider=baseten)、[GLM-5.2](https://huggingface.co/zai-org/GLM-5.2?inference_provider=baseten) 等人气开放权重 LLM。**更多任务的支持**即将推出！

Baseten 支持的完整模型列表见[这里](https://huggingface.co/models?inference_provider=baseten&sort=trending)。

在 Hugging Face 上关注 Baseten：[https://huggingface.co/baseten](https://huggingface.co/baseten)。

## 工作原理

### 在网页 UI 中

- 在你的用户账户设置中，你可以：

- 为你已注册的 provider 设置自己的 API key。若不设置自定义 key，你的请求将经由 HF 路由。
- 按偏好对 provider 排序。这会影响模型页面上的 widget 和代码片段。

- 如前所述，调用 Inference Providers 有两种模式：

- 自定义 key（请求直接发往推理 provider，使用该 provider 你自己的 API key）
- 由 HF 路由（这种方式无需 provider 的 token，费用直接记在你的 HF 账户上，而非 provider 账户）

- 模型页面会展示第三方推理 provider（与当前模型兼容的那些，按用户偏好排序）

### 通过客户端 SDK

Baseten 可以通过 Hugging Face SDK 使用——Python 的 `huggingface_hub`（>= 1.26.1）和 JavaScript 的 `@huggingface/inference`。

以下示例展示如何通过 Baseten 使用最新的 [DeepSeek V4 Flash](https://huggingface.co/blog/deepseek-ai/DeepSeek-V4-Flash-0731)。使用 [Hugging Face token](https://huggingface.co/settings/tokens)认证即可——请求会自动路由到 Baseten。

#### 在你常用的 Agent Harness 中

Hugging Face Inference Providers 已集成进大多数 Agent Harness——包括 Pi、OpenCode、Hermes Agents、OpenClaw 等。这意味着你可以把 baseten 托管的模型直接接入你常用的工具，无需任何额外的胶水代码。完整集成列表见[这里](https://huggingface.co/docs/inference-providers/en/integrations/index)。

#### Python 端

```
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://router.huggingface.co/v1",
    api_key=os.environ["HF_TOKEN"],
)

completion = client.chat.completions.create(
    model="deepseek-ai/DeepSeek-V4-Flash-0731:baseten",
    messages=[
        {
            "role": "user",
            "content": "Write a Python function that returns the nth Fibonacci number using memoization."
        }
    ],
)

print(completion.choices[0].message)
```

#### JS 端

```
import { OpenAI } from "openai";

const client = new OpenAI({
    baseURL: "https://router.huggingface.co/v1",
    apiKey: process.env.HF_TOKEN,
});

const chatCompletion = await client.chat.completions.create({
    model: "deepseek-ai/DeepSeek-V4-Flash-0731:baseten",
    messages: [
        {
            role: "user",
            content: "Write a Python function that returns the nth Fibonacci number using memoization.",
        },
    ],
});

console.log(chatCompletion.choices[0].message);
```

## 计费

直接请求（即使用某个推理 provider 的 key）由对应 provider 计费。例如，使用 baseten 的 API key 就记在您的 baseten 账户上。

路由请求（即通过 Hugging Face Hub 认证）只需支付标准 provider API 费率。我们不加任何差价，provider 成本原样透传。（未来我们可能与 provider 伙伴建立收入分成协议。）
