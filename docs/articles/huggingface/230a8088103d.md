# 视觉文档检索走向多语言

Marco Cimolai（marco，llamaindex）

Logan Markewich（cheesyFishes，llamaindex）

> TL;DR：我们发布 vdr-2b-multi-v1——最强的多语言视觉文档检索嵌入模型。同时发布其纯英文孪生模型 vdr-2b-v1，并开源新的 vdr-multilingual-train 数据集。它有 50 万高质量样本，是最大的开源多语言视觉文档检索合成数据集。

[![image/png](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/vdr-2b-multilingual/cover.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/vdr-2b-multilingual/cover.png)

介绍 [`vdr-2b-multi-v1` (🤗)](https://huggingface.co/llamaindex/vdr-2b-multi-v1)：一个跨多种语言和领域、面向视觉文档检索的多语言嵌入模型。它把文档页面截图编码成稠密的单向量表示，从而无需 OCR、数据抽取管线、切块（chunking），就能直接搜索和查询视觉丰富的多语言文档。

`vdr-2b-multi-v1` 基于 [`MrLight/dse-qwen2-2b-mrl-v1`](https://huggingface.co/MrLight/dse-qwen2-2b-mrl-v1)，在一个自行构建的多语言图文查询对大数据集上训练。该模型与 LlamaIndex 协作打造，是 [`mcdse-2b-v1`](https://huggingface.co/marco/mcdse-2b-v1) 的下一代版本。我们的 `vdr-2b-multi-v1` 扩展并改进了其学习方法和训练手段，得到更强更好的模型。

- **训练覆盖 🇮🇹 意大利语、🇪🇸 西班牙语、🇬🇧 英语、🇫🇷 法语和 🇩🇪 德语：** 五种语言共同构成全新的多语言大型开源训练数据集，含 50 万高质量样本。
- **低显存、更快推理：** 在合成视觉文档检索（ViDoRe）基准上，我们的纯英文模型用 768 个图像 patch 就超过了基座模型用 2560 个 patch 的表现。相当于推理快 3 倍、显存占用大幅降低。
- **跨语言检索：** 在真实场景下明显更强。例如可以用意大利语查询去搜德语文档。
- **套娃表示学习（Matryoshka Representation Learning, MRL）：** 可以把向量缩小 3 倍仍保留 98% 的嵌入质量——检索显著更快，存储成本更低。

## 用法

> 🎲 现在就试试 vdr-2b-multi-v1，可在这个 Hugging Face Space 上体验！

有了 SentenceTransformers 和 LlamaIndex 的直接集成，用 `vdr-2b-multi-v1` 生成嵌入前所未有地简单，几行代码即可上手：

通过 LlamaIndex

```
pip install -U llama-index-embeddings-huggingface
```

```
from llama_index.embeddings.huggingface import HuggingFaceEmbedding

model = HuggingFaceEmbedding(
    model_name="llamaindex/vdr-2b-multi-v1",
    device="cpu",  # "mps" for mac, "cuda" for nvidia GPUs
    trust_remote_code=True,
)

image_embedding = model.get_image_embedding("image.png")
query_embedding = model.get_query_embedding("Chi ha inventato Bitcoin?")
```

通过 SentenceTransformers

```
from sentence_transformers import SentenceTransformer

model = SentenceTransformer(
    model_name_or_path="llamaindex/vdr-2b-multi-v1",
    device="cuda",
    trust_remote_code=True,
    # These are the recommended kwargs for the model, but change them as needed if you don't have CUDA
    model_kwargs={
        "torch_dtype": torch.bfloat16, 
        "device_map": "cuda:0", 
        "attn_implementation": "flash_attention_2"
    },
)

embeddings = model.encode("image.png")
```

## 训练数据集

为视觉文档检索训练好的单向量模型需要高质量数据，但现成的多模态数据集非常稀缺，也不覆盖多语言。

所以我们花了大量时间从零构建。原始数据集由 50 万多语言查询-图像样本组成，完全基于公开互联网 PDF 采集和生成。每张图像对应的查询是合成的，用 VLM 生成。作为对比，我们的数据集样本量是此前最大的多模态视觉文档检索开源合成数据集——[ColPali 训练数据集](https://huggingface.co/datasets/vidore/colpali_train_set)所抓取的文档集——的 10 倍。

[![image/png](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/vdr-2b-multilingual/datapipeline.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/vdr-2b-multilingual/datapipeline.png)

### 数据采集

对每种语言，我们生成一大串覆盖众多主题的搜索查询，再用这些查询去搜 PDF。我们利用搜索引擎的语言过滤能力，只抓取指定语言的文档。这种"按主题搜索"的技术确保模型见过足够多样的主题和领域，在真实场景中表现良好。

抓取过程共产出约 5 万份多语言文档。与之前的 [`mcdse-2b-v1`](https://huggingface.co/marco/mcdse-2b-v1) 模型方法不同，页面不是随机抽取的。我们把每份 PDF 的每一页都跑一遍文档版面分析模型，判断该页偏文本元素还是偏视觉元素，输出一个把页面归类为纯文本/纯视觉/混合的数字。再按该标签在每种页面类型上均匀采样约 10 万页。

### 合成生成

查询用 gemini-1.5-pro 和 Qwen2-VL-72B 生成。我们要求模型各产出一个具体问题和一个宽泛问题。训练只使用具体问题，但强制 LLM 区分两者往往能让具体问题更适合信息检索训练。

生成后还有进一步的清洗步骤确保问题质量足以训练，包括：

- 确保语言正确
- 修正格式问题
- 去掉 markdown
- 确保只提出一个问题
- 删除指涉性短语（如 "according to Figure 1"、"this document"……）

### 过滤与困难负例挖掘

清洗只保证查询语法正确、符合严格规范，但仍不能保证它们适合信息检索。

为了过滤劣质问题，我们用 voyage-3 嵌入模型把所有宽泛查询嵌入并建索引。对每个具体问题去索引里检索：若其配对的宽泛问题出现在 top 100 结果中，该查询标记为"好"。这个方法能剔除低熵、重复或过于相似的问题。平均而言，每种语言数据集有 40% 的查询被移除。

困难负例随后仅用 voyage-3 在具体问题上挖掘，固定阈值 0.75。我们也按 [nvidia/NV-Retriever-v1](https://huggingface.co/nvidia/NV-Retriever-v1) 描述的正例感知负例挖掘做了实验，但在这份数据集上它产出的负例似乎太简单/距离太远。

## 评估

[![image/png](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/vdr-2b-multilingual/ndcgtop.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/vdr-2b-multilingual/ndcgtop.png)

模型在 ViDoRe 基准以及自建评估集上做了评测。自建评估集可在纯文本、纯视觉、混合页面截图上测试其多语言能力。评估数据集也在 Hugging Face 公开（[vdr-multilingual-test 🤗](https://huggingface.co/datasets/llamaindex/vdr-multilingual-test)）。

我们确保这些数据集中没有任何页面出现在训练集中，以免评估污染。评估数据集用与训练数据集相同的方法采集和生成，只是样本量更小。过滤这一步全部手工完成：每条查询都经过评估、筛选，必要时改进，确保数据质量高。

所有评估都用 **1536 维**向量计算 **NDCG@5**，图像分辨率以最多可用 **768 token** 表示。

### 更快推理

[![image/png](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/vdr-2b-multilingual/efficiency.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/vdr-2b-multilingual/efficiency.png)

纯英文的 `vdr-2b-v1` 在 ViDoRe 基准合成数据集上也追平了基座模型表现，而只用了 30% 的图像 token（768 对 2560）。相当于推理快 3 倍、显存占用大幅降低。

| vdr-2b-v1（768 图像 token） | **93.4** | **83.4** | **96.9** | **97.2** | 92.6 | 96.8 |

### MRL 与二值嵌入

该模型使用套娃表示学习（MRL）训练。训练所用的损失函数在多个维度上被校准以跟踪表现，促使模型把最重要的身份信息前置。因此你可以按自己的规模和预算缩减嵌入维度。想深入了解 MRL，Hugging Face 的[这篇博客](https://huggingface.co/blog/matryoshka)讲得很好。

## 结论与下一步

我们相信 [`vdr-2b-multi-v1`](https://huggingface.co/llamaindex/vdr-2b-multi-v1) 和 [`vdr-2b-v1`](https://huggingface.co/llamaindex/vdr-2b-v1) 会对很多用户有用。

我们的多语言模型属同类首创，在多语言和跨语言场景下大幅提升表现；得益于 MRL 和二值量化，检索比以往更高效更快。我们相信这会打开新的用例和机会，尤其在欧洲这样语言碎片化的大陆。

它的纯英文孪生版本相对基座模型也是可观的进步：现在嵌入文档快 3 倍、显存需求低得多，检索质量持平（或更好）。

这一切都得益于全新的 [`vdr-multilingual-train`](https://huggingface.co/datasets/llamaindex/vdr-multilingual-train) 数据集。50 万高质量样本，使其成为视觉文档检索领域最大的多语言开源合成数据集。

未来的工作将探索我们的模型适配新的特定领域时的表现。这还处于开发早期，公布结果前还有很多工作要做，但早期测试已经表明：只需要**极**少的数据和计算资源，就能带来可观的检索提升。

敬请期待后续更新！
