# Google Cloud TPU 向 Hugging Face 用户开放

[![Google Cloud TPUs made available to Hugging Face users](https://huggingface.co/blog/assets/tpu-inference-endpoints-spaces/thumbnail.png)](https://huggingface.co/blog/assets/tpu-inference-endpoints-spaces/thumbnail.png)

我们很高兴分享一个好消息！AI 构建者现在可以在 Hugging Face [Inference Endpoints](https://ui.endpoints.huggingface.co/) 和 [Spaces](https://huggingface.co/spaces) 上用 [Google Cloud TPUs](https://cloud.google.com/tpu?hl=en) 加速他们的应用！

对于还不熟悉的读者，TPU 是 Google 设计的 AI 定制硬件，以高性价比扩展和在各类 AI 工作负载上出色性能著称。在一些 Google 最新创新中，包括 Gemma 2 开放模型的开发，TPU 都发挥了关键作用。我们宣布 TPU 现在可在 Inference Endpoints 和 Spaces 中使用。

这是我们持续[合作](https://huggingface.co/blog/gcp-partnership)为你的 AI 项目提供最佳工具与资源的重要一步。我们非常期待看到你用这一新能力创造出精彩的东西！

## Hugging Face Inference Endpoints 对 TPU 的支持

Hugging Face Inference Endpoints 提供了一种无缝方式，用你选择的云服务商的专用托管基础设施，点几下鼠标就能部署生成式 AI 模型。从今天起，Google [TPU v5e](https://cloud.google.com/tpu/docs/v5e-inference) 已在 Inference Endpoints 上线。选择你要部署的模型，选择 Google Cloud Platform，选择 us-west1，就可以挑选 TPU 配置了：

我们提供 3 种实例配置，未来还会更多：

- v5litepod-1 TPU v5e，1 核、16 GB 内存（$1.375/小时）
- v5litepod-4 TPU v5e，4 核、64 GB 内存（$5.50/小时）
- v5litepod-8 TPU v5e，8 核、128 GB 内存（$11.00/小时）

[![ie-tpu](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/tpu-inference-endpoints-spaces/ie-tpu.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/tpu-inference-endpoints-spaces/ie-tpu.png)

对于最多 20 亿参数的模型，用 v5litepod-1 就能轻松运行；对更大的模型，我们建议使用 v5litepod-4，以避免内存预算问题。配置越大，延迟越低。

我们与 Google 的产品和工程团队一起，很高兴把 TPU 的性能与成本效率带给 Hugging Face 社区。这次合作结出了几项硕果：

- 我们创建了开源库 [Optimum TPU](https://github.com/huggingface/optimum-tpu)，让你在 Google TPU 上训练和部署 Hugging Face 模型变得格外简单。
- Inference Endpoints 使用 Optimum TPU 配合 Text Generation Inference（TGI），在 TPU 上服务大语言模型（LLM）。
- 我们一直在努力支持更多模型架构。从今天起，你可以点击几下就部署 [Gemma](https://huggingface.co/google/gemma-7b-it)、[Llama](https://huggingface.co/meta-llama/Meta-Llama-3-8B-Instruct) 和 [Mistral](https://huggingface.co/mistralai/Mistral-7B-Instruct-v0.3)（Optimum TPU 支持的模型）。

## Hugging Face Spaces 对 TPU 的支持

Hugging Face Spaces 为开发者提供一个平台，快速创建、部署和分享 AI 驱动的演示与应用。我们很高兴为 Hugging Face Spaces 引入新的 TPU v5e 实例支持。要把你的 Space 升级到 TPU 上运行，进入 Space 的 Settings 按钮并选择想要的配置：

- v5litepod-1 TPU v5e，1 核、16 GB 内存（$1.375/小时）
- v5litepod-4 TPU v5e，4 核、64 GB 内存（$5.50/小时）
- v5litepod-8 TPU v5e，8 核、128 GB 内存（$11.00/小时）

[![spaces-tpu](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/tpu-inference-endpoints-spaces/spaces-tpu.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/tpu-inference-endpoints-spaces/spaces-tpu.png)

去 [Hugging Face Spaces](https://huggingface.co/spaces) 上构建并在 TPU 上运行出色的 ML 演示，与社区分享吧！

我们为我们与 Google 共同取得的成果感到自豪，迫不及待想看到你在项目中如何使用 TPU。
