## 引言

SpeechT5 不是一个、也不是两个，而是把三种语音模型装进了同一个架构。

它能做：

- **语音转文本**：用于自动语音识别或说话人识别；
- **文本转语音**：合成音频；
- **语音转语音**：在不同声音之间转换，或做语音增强。

SpeechT5 背后的核心思想是：在文本转语音、语音转文本、文本转文本、语音转语音的混合数据上预训练单个模型。这样，模型同时从文本和语音中学习。这种预训练方式的成果，是一个拥有文本与语音共享的隐藏表示**统一空间**的模型。

SpeechT5 的内核是常规的 **Transformer 编码器-解码器**模型。和所有 Transformer 一样，这个编码器-解码器网络用隐藏表示来建模序列到序列的变换。所有 SpeechT5 任务都共用同一个 Transformer 主干。

为了让同一个 Transformer 能同时处理文本和语音数据，模型加上了所谓的**预网（pre-net）**和**后网（post-net）**。预网的工作是把输入的文本或语音转换成 Transformer 使用的隐藏表示；后网则把 Transformer 的输出重新变回文本或语音。

下图展示了 SpeechT5 的架构（取自[原论文](https://arxiv.org/abs/2110.07205)）。

预训练阶段会同时使用所有预网和后网。预训练之后，整个编码器-解码器主干会在单一任务上微调。微调后的模型只使用与该任务对应的预网和后网。例如，要把 SpeechT5 用于文本转语音，就把文本输入换成文本编码器预网、语音输出换成语音解码器的预网和后网。

注意：尽管各微调模型都从同一个共享预训练权重出发，最终版本彼此差别很大。你不能拿一个微调好的 ASR 模型、替换预网后网就得到一个能用的 TTS 模型。SpeechT5 很灵活，但没*那么*灵活。

## 文本转语音

SpeechT5 是我们加入 🤗 Transformers 的**第一个文本转语音模型**，不久的将来还会加入更多 TTS 模型。

在 TTS 任务上，模型使用以下预网和后网：

- **文本编码器预网。** 一个文本嵌入层，把文本 token 映射为编码器期望的隐藏表示，与 BERT 这类 NLP 模型中的做法类似。
- **语音解码器预网。** 输入是 log mel 频谱图，用一串线性层把它压缩成隐藏表示。这个设计取自 Tacotron 2 TTS 模型。
- **语音解码器后网。** 预测一个加到输出频谱上的残差，用于精修结果，同样来自 Tacotron 2。

微调后模型的架构如下。

下面是使用 SpeechT5 文本转语音模型合成语音的完整示例。也可以跟着[这个交互式 Colab notebook](https://colab.research.google.com/drive/1XnOnCsmEmA3lHmzlNRNxRMcu80YZQzYf?usp=sharing)操作。

SpeechT5 尚未进入 Transformers 的最新正式版本，需要从 GitHub 安装。另外还要安装额外依赖 sentencepiece，然后重启运行时。

```
pip install git+https://github.com/huggingface/transformers.git
pip install sentencepiece
```

首先从 Hub 加载[微调模型](https://huggingface.co/microsoft/speecht5_tts)，以及用于分词和特征提取的 processor 对象。我们使用的类是 `SpeechT5ForTextToSpeech`。

```
from transformers import SpeechT5Processor, SpeechT5ForTextToSpeech

processor = SpeechT5Processor.from_pretrained("microsoft/speecht5_tts")
model = SpeechT5ForTextToSpeech.from_pretrained("microsoft/speecht5_tts")
```

接下来对输入文本分词。

```
inputs = processor(text="Don't count the days, make the days count.", return_tensors="pt")
```

SpeechT5 TTS 模型并不局限于为单一说话人合成语音，它使用所谓的**说话人嵌入（speaker embeddings）**来刻画某个特定说话人的声音特征。我们从 Hub 上的一个数据集加载这样一个说话人嵌入。

```
from datasets import load_dataset
embeddings_dataset = load_dataset("Matthijs/cmu-arctic-xvectors", split="validation")

import torch
speaker_embeddings = torch.tensor(embeddings_dataset[7306]["xvector"]).unsqueeze(0)
```

说话人嵌入是一个形状为 (1, 512) 的张量。这里这个嵌入描述的是一种女声。这些嵌入是用[这个脚本](https://huggingface.co/mechanicalsea/speecht5-vc/blob/main/manifest/utils/prep_cmu_arctic_spkemb.py)从 [CMU ARCTIC](http://www.festvox.org/cmu_arctic/) 数据集得到的，但任何 X-Vector 嵌入都行。

现在可以把输入 token 和说话人嵌入交给模型，让它生成语音。

```
spectrogram = model.generate_speech(inputs["input_ids"], speaker_embeddings)
```

输出一个形状为 (140, 80) 的张量，内容是 log mel 频谱图。第一维是序列长度，每次运行可能不同，因为语音解码器预网总是对输入序列施加 dropout——这让生成的语音带一点随机变化。

要把预测出的 log mel 频谱图转成真正的语音波形，需要一个 **vocoder（声码器）**。理论上任何能处理 80 维 mel 频谱的 vocoder 都可以，但为了方便，我们在 Transformers 里内置了一个基于 HiFi-GAN 的版本。这个 [vocoder 的权重](https://huggingface.co/mechanicalsea/speecht5-tts)以及微调后 TTS 模型的权重，都由 SpeechT5 的原作者们慷慨提供。

加载 vocoder 和加载其他 🤗 Transformers 模型一样简单。

```
from transformers import SpeechT5HifiGan
vocoder = SpeechT5HifiGan.from_pretrained("microsoft/speecht5_hifigan")
```

从频谱图生成音频：

```
with torch.no_grad():
    speech = vocoder(spectrogram)
```

我们还提供了快捷方式，跳过先生成频谱图的中间步骤。把 vocoder 对象传给 `generate_speech`，它就直接输出语音波形。

```
speech = model.generate_speech(inputs["input_ids"], speaker_embeddings, vocoder=vocoder)
```

最后，把语音波形存成文件。SpeechT5 使用的采样率始终是 16 kHz。

```
import soundfile as sf
sf.write("tts_example.wav", speech.numpy(), samplerate=16000)
```

输出效果如下（[下载音频](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/speecht5/tts_example.wav)）：

TTS 模型就是这样！要让声音好听，关键在于用对说话人嵌入。

可以在 Spaces 上体验[交互式 demo](https://huggingface.co/spaces/Matthijs/speecht5-tts-demo)。

## 语音转语音实现声音转换

从概念上讲，用 SpeechT5 做语音到语音和做文本到语音是一样的：只需把文本编码器预网换成语音编码器预网，其余部分保持不变。

**语音编码器预网**与 [wav2vec 2.0](https://huggingface.co/docs/transformers/model_doc/wav2vec2) 的特征编码模块相同：用一系列卷积层把输入波形下采样为音频帧表示序列。

作为语音转语音任务的示例，SpeechT5 的作者提供了用于声音转换的[微调 checkpoint](https://huggingface.co/microsoft/speecht5_vc)。使用时先从 Hub 加载模型，注意此时的模型类是 `SpeechT5ForSpeechToSpeech`。

```
from transformers import SpeechT5Processor, SpeechT5ForSpeechToSpeech

processor = SpeechT5Processor.from_pretrained("microsoft/speecht5_vc")
model = SpeechT5ForSpeechToSpeech.from_pretrained("microsoft/speecht5_vc")
```

我们需要一些语音音频作为输入。在这个示例里，我们从 Hub 上的一个小型语音数据集加载音频。也可以加载自己的语音波形，只要是 16 kHz 采样的单声道即可。本例所用的数据集样本已经是这个格式。

```
from datasets import load_dataset
dataset = load_dataset("hf-internal-testing/librispeech_asr_demo", "clean", split="validation")
dataset = dataset.sort("id")
example = dataset[40]
```

接下来做预处理，把音频转成模型期望的格式。

```
sampling_rate = dataset.features["audio"].sampling_rate
inputs = processor(audio=example["audio"]["array"], sampling_rate=sampling_rate, return_tensors="pt")
```

和 TTS 模型一样，我们需要说话人嵌入——它描述目标声音的样子。

```
import torch
embeddings_dataset = load_dataset("Matthijs/cmu-arctic-xvectors", split="validation")
speaker_embeddings = torch.tensor(embeddings_dataset[7306]["xvector"]).unsqueeze(0)
```

还需要加载 vocoder，把生成的频谱图转成音频波形。就用与 TTS 相同的 vocoder。

```
from transformers import SpeechT5HifiGan
vocoder = SpeechT5HifiGan.from_pretrained("microsoft/speecht5_hifigan")
```

现在调用模型的 `generate_speech` 方法即可完成语音转换。

```
speech = model.generate_speech(inputs["input_values"], speaker_embeddings, vocoder=vocoder)

import soundfile as sf
sf.write("speech_converted.wav", speech.numpy(), samplerate=16000)
```

想换一个声音，只要加载一个新的说话人嵌入即可。你甚至可以用自己的声音做一个嵌入！

原始输入（[下载](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/speecht5/speech_original.wav)）：

## 语音转文本实现自动语音识别

ASR 模型使用以下预网和后网：

- **语音编码器预网。** 与语音转语音模型使用的是同一个预网，即 wav2vec 2.0 的 CNN 特征编码层。
- **文本解码器预网。** 与 TTS 模型的编码器预网类似，用嵌入层把文本 token 映射为隐藏表示。（预训练阶段，文本编码器和解码器预网的这些嵌入是共享的。）
- **文本解码器后网。** 这是最简单的一个：单个线性层，把隐藏表示投影到词表概率上。

微调后模型的架构如下。

如果你用过其他 🤗 Transformers 语音识别模型，会发现 SpeechT5 同样好用。最快的上手方式是使用 pipeline。

```
from transformers import pipeline
generator = pipeline(task="automatic-speech-recognition", model="microsoft/speecht5_asr")
```

语音音频就用上一节同样的输入，不过任何音频文件都可以——pipeline 会自动把音频转换为正确格式。

```
from datasets import load_dataset
dataset = load_dataset("hf-internal-testing/librispeech_asr_demo", "clean", split="validation")
dataset = dataset.sort("id")
example = dataset[40]
```

现在让 pipeline 处理语音并生成文本转写。

```
transcription = generator(example["audio"]["array"])
```

打印转写结果：

```
a man said to the universe sir i exist
```

完全正确！SpeechT5 使用的分词器很简单，是在字符级别工作的，所以 ASR 模型不会输出任何标点或大写。

当然也可以直接使用模型类。先加载[微调模型](https://huggingface.co/microsoft/speecht5_asr)和 processor 对象，此时的类是 `SpeechT5ForSpeechToText`。

```
from transformers import SpeechT5Processor, SpeechT5ForSpeechToText

processor = SpeechT5Processor.from_pretrained("microsoft/speecht5_asr")
model = SpeechT5ForSpeechToText.from_pretrained("microsoft/speecht5_asr")
```

预处理语音输入：

```
sampling_rate = dataset.features["audio"].sampling_rate
inputs = processor(audio=example["audio"]["array"], sampling_rate=sampling_rate, return_tensors="pt")
```

最后，让模型根据语音输入生成文本 token，再用 processor 的解码函数把这些 token 转成真正的文本。

```
predicted_ids = model.generate(**inputs, max_length=100)
transcription = processor.batch_decode(predicted_ids, skip_special_tokens=True)
```

来体验[语音转文本任务](https://huggingface.co/spaces/Matthijs/speecht5-asr-demo)的交互式 demo 吧。

## 结论

SpeechT5 是个很有意思的模型，因为——与大多数模型不同——它可以在同一架构上完成多种任务，变的只是预网和后网。通过在合并任务上预训练，模型在微调后做每项单独任务时都更强。

我们目前只收录了语音识别（ASR）、语音合成（TTS）和声音转换三类任务的 checkpoint，但论文还提到模型被成功用于语音翻译、语音增强和说话人识别。它非常多才多艺！
