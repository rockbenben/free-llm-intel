我们很高兴发布 IDEFICS（**I**mage-aware **D**ecoder **E**nhanced à la **F**lamingo with **I**nterleaved **C**ross-attention**S**，仿 Flamingo 的图像感知解码器，带交错交叉注意力），一个开放访问的视觉语言模型。IDEFICS 基于 [Flamingo](https://huggingface.co/papers/2204.14198)——最初由 DeepMind 开发的最先进视觉语言模型，但从未公开发布。与 GPT-4 类似，IDEFICS 接受任意的图像与文本输入序列并生成文本输出。IDEFICS 完全基于公开可用的数据和模型（LLaMA v1 与 OpenCLIP）构建，提供两个变体——基础版和指令版。每个变体都有 90 亿和 800 亿参数两种尺寸。

最先进 AI 模型的开发过程应该更透明。我们做 IDEFICS 的目标是复现一套能与 Flamingo 这类大型专有模型能力相当的系统，并交给 AI 社区。为此我们采取了若干推动透明度的重要步骤：只使用公开可得的数据；提供可用于探索训练数据集的工具；分享了构建这类系统的[技术经验与踩坑记录](https://github.com/huggingface/m4-logs/blob/master/memos/README.md)；并在发布前通过对抗性提示评估了模型的危害性。我们希望 IDEFICS 能与 [OpenFlamingo](https://huggingface.co/openflamingo)（另一个 90 亿参数规模的 Flamingo 开放复现）等模型一起，成为多模态 AI 开放研究的坚实基础。

来试试 [demo](https://huggingface.co/spaces/HuggingFaceM4/idefics_playground) 和 Hub 上的[模型](https://huggingface.co/HuggingFaceM4/idefics-80b-instruct)吧！

![Screenshot of IDEFICS generation for HF Woodstock of AI](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/idefics/woodstock_ai.png)

## IDEFICS 是什么？

IDEFICS 是一个 800 亿参数的多模态模型，输入图像与文本的序列，输出连贯的文本。它能回答关于图像的问题、描述视觉内容、基于多张图像编故事等等。

IDEFICS 是 Flamingo 的开放访问复现，在多种图文理解基准上与原版闭源模型性能相当。它有两个变体——800 亿参数和 90 亿参数。

![Plot comparing the performance of Flamingo, OpenFlamingo and IDEFICS](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/idefics/Figure_Evals_IDEFICS.png)

我们还提供了适配对话场景的微调版本 [idefics-80B-instruct](https://huggingface.co/HuggingFaceM4/idefics-80b-instruct) 和 [idefics-9B-instruct](https://huggingface.co/HuggingFaceM4/idefics-9b-instruct)。

## 训练数据

IDEFICS 在多个公开数据集的混合数据上训练：Wikipedia、Public Multimodal Dataset、LAION，以及我们新建的 1150 亿 token 数据集 [OBELICS](https://huggingface.co/datasets/HuggingFaceM4/OBELICS)。OBELICS 包含 1.41 亿份从网络抓取的图文交错文档，共含 3.53 亿张图像。

我们提供了一个 OBELICS 的[交互式可视化](https://atlas.nomic.ai/map/f2fba2aa-3647-4f49-a0f3-9347daeee499/ee4a84bd-f125-4bcc-a683-1b4e231cb10f)，可以借助 [Nomic AI](https://home.nomic.ai/) 探索数据集内容。

[ ![Interactive visualization of OBELICS](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/idefics/obelics_nomic_map.png) ](https://atlas.nomic.ai/map/f2fba2aa-3647-4f49-a0f3-9347daeee499/ee4a84bd-f125-4bcc-a683-1b4e231cb10f)

IDEFICS 的架构、训练方法与评测细节，以及数据集相关信息，见[模型卡片](https://huggingface.co/HuggingFaceM4/idefics-80b-instruct)和我们的[研究论文](https://huggingface.co/papers/2306.16527)。另外，我们整理了模型训练过程中的[技术洞见与经验](https://github.com/huggingface/m4-logs/blob/master/memos/README.md)，为理解 IDEFICS 的开发提供有价值的视角。

## 伦理评估

在项目启动之初，经过一系列讨论，我们制定了一份[伦理章程](https://huggingface.co/blog/ethical-charter-multimodal)来指导项目中的决策。章程确立了自我批判、透明、公平等价值观，我们在项目推进和模型发布过程中始终努力践行。

作为发布流程的一部分，我们对模型做了内部的潜在偏见评估：用可能诱导出不期望回答的图像与文本对模型进行对抗性提示（这一过程称为红队测试，red teaming）。

欢迎通过 [demo](https://huggingface.co/spaces/HuggingFaceM4/idefics_playground) 试用 IDEFICS，查看相应的[模型卡片](https://huggingface.co/HuggingFaceM4/idefics-80b)和[数据集卡片](https://huggingface.co/datasets/HuggingFaceM4/OBELICS)，并在 community 标签页反馈你的意见！我们致力于持续改进这些模型，让大型多模态 AI 模型为机器学习社区所共享。

## 许可证

该模型构建在两个预训练模型之上：[laion/CLIP-ViT-H-14-laion2B-s32B-b79K](https://huggingface.co/laion/CLIP-ViT-H-14-laion2B-s32B-b79K) 和 [huggyllama/llama-65b](https://huggingface.co/huggyllama/llama-65b)。前者以 MIT 许可证发布，后者则以面向科研用途的特定非商业许可证发布。因此，用户需要遵循该许可证，直接通过 [Meta 的申请表](https://docs.google.com/forms/d/e/1FAIpQLSfqNECQnMkycAp2jP4Z9TFX0cGR4uf7b_fBxjY_OjhJILlKGA/viewform)申请授权。

这两个预训练模型之间由我们新初始化并训练的参数连接。这些参数不基于构成复合模型的任何一方冻结的基座模型。我们训练的附加权重以 MIT 许可证发布。

## IDEFICS 快速上手

IDEFICS 模型已上架 Hugging Face Hub，并在最新版 `transformers` 中受支持。下面是试用代码：

```
import torch
from transformers import IdeficsForVisionText2Text, AutoProcessor

device = "cuda" if torch.cuda.is_available() else "cpu"

checkpoint = "HuggingFaceM4/idefics-9b-instruct"
model = IdeficsForVisionText2Text.from_pretrained(checkpoint, torch_dtype=torch.bfloat16).to(device)
processor = AutoProcessor.from_pretrained(checkpoint)

# We feed to the model an arbitrary sequence of text strings and images. Images can be either URLs or PIL Images.
prompts = [
    [
        "User: What is in this image?",
        "https://upload.wikimedia.org/wikipedia/commons/8/86/Id%C3%A9fix.JPG",
        "<end_of_utterance>",

        "\nAssistant: This picture depicts Idefix, the dog of Obelix in Asterix and Obelix. Idefix is running on the ground.<end_of_utterance>",

        "\nUser:",
        "https://static.wikia.nocookie.net/asterix/images/2/25/R22b.gif/revision/latest?cb=20110815073052",
        "And who is that?<end_of_utterance>",

        "\nAssistant:",
    ],
]

# --batched mode
inputs = processor(prompts, add_end_of_utterance_token=False, return_tensors="pt").to(device)
# --single sample mode
# inputs = processor(prompts[0], return_tensors="pt").to(device)

# Generation args
exit_condition = processor.tokenizer("<end_of_utterance>", add_special_tokens=False).input_ids
bad_words_ids = processor.tokenizer(["<image>", "<fake_token_around_image>"], add_special_tokens=False).input_ids

generated_ids = model.generate(**inputs, eos_token_id=exit_condition, bad_words_ids=bad_words_ids, max_length=100)
generated_text = processor.batch_decode(generated_ids, skip_special_tokens=True)
for i, t in enumerate(generated_text):
    print(f"{i}:\n{t}\n")
```
