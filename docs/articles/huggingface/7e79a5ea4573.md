# 数据因协作而更好：让社区借助 Argilla 与 Hugging Face Spaces 共同构建更优质的数据集

本文由 Daniel van Strien（davanstrien）与 Daniel Vila（dvilasuero，客座作者）撰写。

最近，Argilla 和 Hugging Face [发起](https://huggingface.co/posts/dvilasuero/680660181190026)了 `Data is Better Together`，这是一次由大家共同构建"提示词排名偏好数据集"的实验。在几天之内，我们就实现了：

- 350 名社区贡献者参与数据标注
- 超过 11,000 条提示词评分

最新统计请查看[进度看板](https://huggingface.co/spaces/DIBT/prompt-collective-dashboard)！

由此产出了 [`10k_prompts_ranked`](https://huggingface.co/datasets/DIBT/10k_prompts_ranked) 数据集的发布——它包含 10,000 条提示词，并附有用户对提示词质量的评分。我们希望能让更多这样的项目落地！

在这篇文章中，我们将讨论为什么我们认为社区协作构建数据集至关重要，并发出邀请：加入 Argilla 与 Hugging Face 首批支持计划中的社区队列，一起开发更优质的数据集！

## 数据对于更好的模型依然不可或缺

数据对于构建更好的模型持续至关重要：从[已发表的研究](https://huggingface.co/papers/2402.05123)、开源[实验](https://argilla.io/blog/notus7b/)以及开源社区中，我们不断看到证据表明——更好的数据能带来更好的模型。

## 为什么要集体构建数据集？

数据对机器学习至关重要，但许多语言、领域和任务仍然缺乏用于训练、评估和基准测试的高质量数据集——而社区每天已经在 Hugging Face Hub 上分享数千个模型、数据集和演示。正是得益于协作，开放获取的 AI 社区创造了了不起的成果。让社区能够集体构建数据集，将为构建下一代数据集、进而构建下一代模型打开独特的机会。

赋能社区集体构建和改进数据集，将使人们能够：

- 无需任何 ML 或编程技能即可为开源 ML 的发展贡献力量。
- 为某一特定语言创建对话（chat）数据集。
- 为某一特定领域开发基准数据集。
- 从多元化的参与者群体中创建偏好数据集。
- 为某一特定任务构建数据集。
- 作为社区共同构建全新类型的数据集。

重要的是，我们相信集体构建数据集能让社区造出更好的数据集，并让不懂编程的人也能为 AI 的发展贡献力量。

### 让人们易于参与

过往许多集体构建 AI 数据集的努力，一大挑战在于如何搭建高效的标注任务。Argilla 是一款开源工具，可以帮助你为 LLM 以及更小的专用任务模型创建数据集。Hugging Face Spaces 是一个用于构建和托管机器学习演示与应用的平台。最近，Argilla 增加了通过 Hugging Face 账号进行认证的支持，适用于托管在 Spaces 上的 Argilla 实例。这意味着用户现在只需几秒就能开始参与标注任务。

在创建 [`10k_prompts_ranked`](https://huggingface.co/datasets/DIBT/10k_prompts_ranked) 数据集的过程中，我们已经对这一新工作流完成了压力测试，现在我们希望支持社区发起更多新的集体数据集行动。

## 加入我们要一起构建更优数据集的首批社区队列！

我们对这一简化的标注任务托管流程所带来的可能性感到非常兴奋。为支持社区构建更优数据集，Hugging Face 和 Argilla 邀请感兴趣的个人与社区加入我们的首批社区数据构建者队列。

加入该队列的人将获得：

- 在创建带 Hugging Face 认证的 Argilla Space 时获得支持。Hugging Face 将为参与者提供免费持久化存储和增强 CPU 的 Space。
- 用于宣传和推广该倡议的消息与传播将由 Argilla 和 Hugging Face 协助放大。
- 受邀加入该队列的社区频道。

我们的目标是支持社区共同构建更优数据集。我们对各种想法都持开放态度，并希望尽可能支持社区一起打造更好的数据集。

## 我们在寻找什么类型的项目？

我们乐于支持许多类型的项目，尤其是现有开源社区的项目。我们特别关注那些为目前在开源社区中代表性不足的语言、领域和任务构建数据集的项目。我们当前唯一的限制是主要聚焦于文本类数据集。如果你有非常酷的多模态数据集想法，我们很乐意倾听，但在首批队列中我们可能无法提供支持。

任务可以完全开放，也可以只对特定 Hugging Face Hub 组织的成员开放。

如果你想成为首批队列的一员，请加入 [Hugging Face Discord](http://hf.co/join/discord) 中的 `#data-is-better-together` 频道，告诉我们你想一起构建什么！

我们期待与你一起构建更优质的数据集！
