我们非常高兴地宣布，**Public AI** 现已成为 Hugging Face Hub 上受支持的 Inference Provider（推理提供商）！Public AI 加入我们不断壮大的生态系统，增强了在 Hub 模型页面上直接提供的 serverless 推理的广度与能力。Inference Providers 还与我们的客户端 SDK（同时支持 JS 和 Python）无缝集成，让你用最喜好的提供商调用各种模型变得超级简单。

此次上线让从 Hugging Face 直接访问来自瑞士 AI 计划（Swiss AI Initiative）和 AI Singapore 等机构的公共与主权模型变得空前便捷。你可以在 Hub 上浏览 Public AI 的组织主页 [https://huggingface.co/publicai](https://huggingface.co/publicai)，并在 [https://huggingface.co/models?inference_provider=publicai&sort=trending](https://huggingface.co/models?inference_provider=publicai&sort=trending) 试用受支持的热门模型。

Public AI Inference Utility 是一个非营利、开源项目。该团队构建产品并开展倡导活动，以支持像瑞士 AI 计划和 AI Singapore 这样的公共 AI 模型构建者的工作。

Public AI Inference Utility 运行在一套分布式基础设施之上，它将 vLLM 驱动的后端与一个为跨多个合作伙伴的高韧性而设计的部署层相结合。在幕后，推理由在 vLLM 上暴露 OpenAI 兼容 API 的服务器处理，这些服务器部署在由国家和行业合作伙伴捐赠的集群上。一个全局负载均衡层确保请求被高效、透明地路由，无论查询由哪个国家的算力来服务。

免费的公共访问由捐赠的 GPU 时间和广告补贴支撑，而长期稳定性则计划通过国家和机构贡献来加以锚定。你可以在 [https://platform.publicai.co/](https://platform.publicai.co/) 了解更多关于 Public AI 的平台和基础设施的信息。

你现在就可以将 Public AI Inference Utility 作为 Hugging Face 上的一个 Inference Provider 来使用。我们很期待看到你用这个新提供商构建出什么。

关于如何将 Public AI 用作 Inference Provider，请阅读其专属的[文档页面](https://huggingface.co/docs/inference-providers/providers/publicai)。

在[此处](https://huggingface.co/models?inference_provider=publicai&sort=trending)查看受支持的模型列表。

## 工作原理

### 在网站 UI 中

- 在你的用户账号设置中，你可以：

- 为你已注册的提供商设置自己的 API key。如果未设置自定义 key，你的请求将通过 HF 路由。
- 按偏好对提供商排序。这会影响模型页面上的 widget 和代码片段。

- 如前所述，调用 Inference Providers 时有两种模式：

- 自定义 key（调用直接发到推理提供商，使用你对应推理提供商自己的 API key）
- 由 HF 路由（这种情况下，你不需要提供商的 token，费用直接记在你的 HF 账号上，而非提供商的账号上）

- 模型页面会展示第三方推理提供商（与当前模型兼容的那些，按用户偏好排序）

### 从客户端 SDK

#### 用 Python，通过 huggingface_hub

下面的示例展示了如何使用 Public AI 作为推理提供商来调用瑞士 AI 的 Apertus-70B。你可以使用 [Hugging Face token](https://huggingface.co/settings/tokens) 通过 Hugging Face 自动路由，或使用你自己的 Public AI API key（如果你有的话）。

注意：这需要使用较新版本的 `huggingface_hub`（>= 0.34.6）。

```
import os
from huggingface_hub import InferenceClient

client = InferenceClient(
    provider="publicai",
    api_key=os.environ["HF_TOKEN"],
)

messages = [
    {
        "role": "user",
        "content": "What is the capital of France?"
    }
]

completion = client.chat.completions.create(
    model="swiss-ai/Apertus-70B-Instruct-2509",
    messages=messages,
)

print(completion.choices[0].message)
```

#### 用 JS，通过 @huggingface/inference

```
import { InferenceClient } from "@huggingface/inference";

const client = new InferenceClient(process.env.HF_TOKEN);

const chatCompletion = await client.chatCompletion({
  model: "swiss-ai/Apertus-70B-Instruct-2509",
  messages: [
    {
      role: "user",
      content: "What is the capital of France?",
    },
  ],
  provider: "publicai",
});

console.log(chatCompletion.choices[0].message);
```

## 计费

在本文撰写时，通过 Hugging Face Inference Providers 使用 Public AI Inference Utility 是免费的。定价和可用性可能变化。

以下是平台上其他提供商的计费方式：

对于直接请求，也就是当你使用某个推理提供商的 key 时，由对应提供商向你计费。例如，如果你使用 Public AI 的 API key，则在你的 Public AI 账号上计费。

对于路由请求，也就是当你通过 Hugging Face Hub 认证时，你只需支付标准的提供商 API 费率。我们不加任何加价；我们只是原样转嫁提供商的成本。（未来，我们可能与提供商合作伙伴建立收益分成协议。）
