是时候让 AI 开放、人人可用了。这正是 Hugging Face 与 Amazon Web Services（AWS）之间这份扩大的长期战略合作伙伴关系的目标。两家行业领导者携手，旨在通过让下一代机器学习模型对机器学习社区更易获取、帮助开发者以最低成本达到最高性能，来加速它们的普及。

## 新一代开放、易及的 AI

机器学习正迅速嵌入所有应用。当它对经济体各个部门的影响日益清晰，确保每位开发者都能获取并评估最新模型就比以往任何时候都重要。与 AWS 的合作为这一未来铺路：借助专用工具，在云上构建、训练和部署最新机器学习模型将更快、更容易。

在处理与生成文本、音频、图像的 Transformer 与 Diffuser 模型上已有重大进展。然而，大多数流行的生成式 AI 模型并不公开可用，拉大了最大科技公司与其他所有人之间机器学习能力的鸿沟。为了对冲这一趋势，AWS 与 Hugging Face 联手，向全球 AI 社区贡献下一代模型，让机器学习走向民主化。通过这一战略合作，Hugging Face 将把 AWS 作为首选云服务商，让 Hugging Face 社区的开发者能够使用 AWS 的最先进工具（如 [Amazon SageMaker](https://aws.amazon.com/sagemaker)、[AWS Trainium](https://aws.amazon.com/machine-learning/trainium/)、[AWS Inferentia](https://aws.amazon.com/machine-learning/inferentia/)）在 AWS 上训练、微调和部署模型。这让开发者可以针对自己的具体用例进一步优化模型性能，同时降低成本。Hugging Face 还将运用 Amazon SageMaker 上的最新创新研究成果，构建下一代 AI 模型。Hugging Face 与 AWS 正在弥合鸿沟，让全球 AI 社区从机器学习的最新进展中受益，加速生成式 AI 应用的创造。

「AI 的未来已来，但它分布得并不均匀，」Hugging Face CEO Clément Delangue 表示。「可及性与透明性是共享进步的关键，也是明智、负责任地使用这些新能力来创造工具的关键。Amazon SageMaker 和 AWS 自研芯片将帮助我们的团队和更广泛的机器学习社区把最新研究转化为任何人都能在其上构建、可公开复现的模型。」

## 携手把云上 AI 推向规模化

这份扩大的战略合作让 Hugging Face 与 AWS 能够以 Amazon SageMaker 的业界领先能力，配合托管在 Hugging Face 上的最新模型，加速机器学习的采用。客户现在只需在 Amazon SageMaker 和 Amazon Elastic Computing Cloud（EC2）上点击几下，即可轻松微调和部署最先进的 Hugging Face 模型，并用上包括 AWS Trainium 和 AWS Inferentia 在内的专用机器学习加速器。

「生成式 AI 有潜力变革整个行业，但它的成本和所需专业知识让除少数公司之外的大多数企业高攀不起，」AWS CEO Adam Selipsky 表示。「Hugging Face 和 AWS 正在让客户更容易访问热门机器学习模型，以最高性能、最低成本创建自己的生成式 AI 应用。这一合作证明了生成式 AI 公司与 AWS 如何协同，把这种创新技术交到更多客户手中。」

Hugging Face 已成为机器学习的中心枢纽，拥有超过 [10 万个免费、可访问的机器学习模型](https://huggingface.co/models)，研究者、数据科学家和机器学习工程师每天下载超过 100 万次。AWS 至今是从 Hugging Face Hub 运行模型最流行的地方。自从我们[开始合作](https://huggingface.co/blog/the-partnership-amazon-sagemaker-and-hugging-face)以来，[Hugging Face on Amazon SageMaker](https://aws.amazon.com/machine-learning/hugging-face/) 呈指数级增长。我们正经历生成式 AI 令人振奋的复兴，而这只是开始。我们期待 Hugging Face、AWS 和 AI 社区的未来。
