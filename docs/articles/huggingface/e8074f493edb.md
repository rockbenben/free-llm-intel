[Gradio](https://github.com/gradio-app/gradio) 是一个 Python 库，每月有超过 100 万开发者用它给机器学习模型做界面。除了创建 UI，Gradio 还暴露 API 能力——而且现在！——Gradio 应用可以直接作为 Model Context Protocol（MCP，模型上下文协议）服务器启动供 LLM 使用。这意味着你的 Gradio 应用，不管是图像生成器、计算器还是别的什么，都能被 LLM 当作工具调用。

本指南教你如何用 Gradio 仅凭几行 Python 构建一个 MCP 服务器。

### 前置条件

如果尚未安装，请带 MCP 扩展安装 Gradio：

```
pip install "gradio[mcp]"
```

这会装上必需的依赖，包括 `mcp` 包。你还需要一个支持通过 MCP 协议进行工具调用的 LLM 应用，比如 Claude Desktop、Cursor 或 Cline（这些被称为 "MCP Clients"，MCP 客户端）。

## 为什么要构建 MCP 服务器？

MCP 服务器是一种标准化方式，把工具暴露给 LLM 使用。MCP 服务器能为 LLM 提供各种扩展能力，比如生成或编辑图像、合成音频，或执行特定计算（例如质因数分解）。

Gradio 让构建这些 MCP 服务器变得简单，把任意 Python 函数变成 LLM 可用的工具。

## 示例：数单词里的字母

LLM 出了名不擅长数一个单词里有几个字母（比如 "strawberry" 里有几个 "r"）。但如果给它配一个工具帮忙呢？我们先写一个简单的 Gradio 应用，统计一个词或短语中某个字母出现的次数：

```
import gradio as gr

def letter_counter(word, letter):
    """Count the occurrences of a specific letter in a word.
    
    Args:
        word: The word or phrase to analyze
        letter: The letter to count occurrences of
        
    Returns:
        The number of times the letter appears in the word
    """
    return word.lower().count(letter.lower())

demo = gr.Interface(
    fn=letter_counter,
    inputs=["text", "text"],
    outputs="number",
    title="Letter Counter",
    description="Count how many times a letter appears in a word"
)

demo.launch(mcp_server=True)
```

注意我们在 `.launch()` 里设置了 `mcp_server=True`。就这一步，Gradio 应用就能作为 MCP 服务器提供服务！运行这个应用后，它会：

- 启动常规的 Gradio Web 界面
- 启动 MCP 服务器
- 在控制台打印 MCP 服务器 URL

MCP 服务器可通过这里访问：

```
http://your-server:port/gradio_api/mcp/sse
```

Gradio 会自动把 `letter_counter` 函数转换成一个可被 LLM 使用的 MCP 工具。**函数的 docstring 会被用来生成工具及其参数的描述。**

你要做的只是把这个 URL 端点加到 MCP 客户端（比如 Cursor、Cline 或 [Tiny Agents](https://huggingface.co/blog/tiny-agents)）里——通常就是把下面这段配置贴进设置：

```
{
  "mcpServers": {
    "gradio": {
      "url": "http://your-server:port/gradio_api/mcp/sse"
    }
  }
}
```

一些 MCP 客户端——尤其是 Claude Desktop——尚不支持基于 SSE 的 MCP 服务器。这时可以用 [mcp-remote](https://github.com/geelen/mcp-remote) 这类工具：先安装 Node.js，然后在你的 MCP 客户端配置里加上：

```
{
  "mcpServers": {
    "gradio": {
      "command": "npx",
      "args": [
        "mcp-remote",
        "http://your-server:port/gradio_api/mcp/sse"
      ]
    }
  }
}
```

（顺带一提，进入 Gradio 应用页脚的 "View API" 链接、再点 "MCP"，就能拿到可以直接复制粘贴的准确配置。）

## 进阶 MCP 功能

### MCP Resources 与 Prompts

除了 tools，MCP 还支持 resources（用于暴露数据）和 prompts（用于定义可复用模板）。Gradio 提供了装饰器，可以轻松地让 MCP 服务器同时具备这三类能力。更多内容见我们的专属指南，[这里](https://www.gradio.app/guides/building-mcp-server-with-gradio#creating-mcp-resources)：

```
import gradio as gr

@gr.mcp.tool()  # Not needed as functions are registered as tools by default
def add(a: int, b: int) -> int:
    """Add two numbers"""
    return a + b

@gr.mcp.resource("greeting://{name}")
def get_greeting(name: str) -> str:
    """Get a personalized greeting"""
    return f"Hello, {name}!"

@gr.mcp.prompt()
def greet_user(name: str, style: str = "friendly") -> str:
    """Generate a greeting prompt"""
    styles = {
        "friendly": "Please write a warm, friendly greeting",
        "formal": "Please write a formal, professional greeting", 
        "casual": "Please write a casual, relaxed greeting",
    }
    return f"{styles.get(style, styles['friendly'])} for someone named {name}."

demo = gr.TabbedInterface(
    [
        gr.Interface(add, [gr.Number(value=1), gr.Number(value=2)], gr.Number()),
        gr.Interface(get_greeting, gr.Textbox("Abubakar"), gr.Textbox()),
        gr.Interface(greet_user, [gr.Textbox("Abubakar"), gr.Dropdown(choices=["friendly", "formal", "casual"])], gr.Textbox()),
    ],
    ["Add", "Get Greeting", "Greet User"]
)

demo.launch(mcp_server=True)
```

### 仅 MCP 可见的函数

Gradio 还允许你创建只出现在 MCP 服务器里（不在 UI 中显示）的函数，用 `gr.api()` 即可：

```
import gradio as gr

def slice_list(lst: list, start: int, end: int) -> list:
    """
    A tool that slices a list given a start and end index.
    Args:
        lst: The list to slice.
        start: The start index.
        end: The end index.
    Returns:
        The sliced list.
    """
    return lst[start:end]

with gr.Blocks() as demo:
    gr.Markdown("This app includes MCP-only tools not visible in the UI.")
    gr.api(slice_list)

demo.launch(mcp_server=True)
```

## Gradio <> MCP 集成的关键特性

- **工具转换**：Gradio 应用里的每个 API 端点都会自动转换成一个 MCP 工具，带有对应的名称、描述和输入 schema。要查看工具和 schema，访问 `http://your-server:port/gradio_api/mcp/schema`，或进入 Gradio 应用页脚的 "View API" 链接并点击 "MCP"。开发者可以用简单 Python 代码构建复杂的交互界面，并获得动态 UI 操作与即时视觉反馈。
- **环境变量支持**。启用 MCP 服务器功能有两种方式：使用上文展示的 `mcp_server` 参数：`demo.launch(mcp_server=True) `；或使用环境变量：`export GRADIO_MCP_SERVER=True `
- **文件处理**：服务器自动处理文件数据转换，包括：把 base64 编码字符串转成文件数据；处理图像文件并以正确格式返回；管理临时文件存储；为无缝本地文件支持而自动上传文件到 MCP 服务器。  近期的 Gradio 更新改进了图像处理能力，新增 Photoshop 风格的缩放平移、完全透明通道控制等特性。
- **性能分析**：Gradio 会自动追踪并展示所有 MCP 工具和 API 端点的性能指标。直接在 "View API" 页面查看成功率、延迟分位数和请求计数，帮助你及你的用户选择最可靠、最快的工具。指标有颜色区分：绿色代表 100% 成功，红色代表 0%，橙色介于两者之间。
- **托管在 🤗 Spaces 上的 MCP 服务器**：你可以把 Gradio 应用免费发布到 Hugging Face Spaces，从而获得一个免费托管的 MCP 服务器。Gradio 属于一个更大的生态，包含用于以编程方式构建或查询机器学习应用的 Python 和 JavaScript 库。

这是一个这样的 Space 示例：[https://huggingface.co/spaces/abidlabs/mcp-tools](https://huggingface.co/spaces/abidlabs/mcp-tools)。注意，把这段配置加入 MCP 客户端，就能立刻使用这个 Space 提供的工具：

```

```
