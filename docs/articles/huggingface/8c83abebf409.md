# StarCoder2 与 The Stack v2

本文另有中文版本 [简体中文](https://huggingface.co/blog/zh/starcoder2)。

BigCode 发布 StarCoder2——新一代训练过程公开透明的开源代码 LLM。所有 StarCoder2 变体都在 [The Stack v2](https://huggingface.co/datasets/bigcode/the-stack-v2/) 上训练，这是一个全新的大规模高质量代码数据集。我们发布了全部模型、数据集、数据处理以及训练代码。详情请阅读[论文](https://drive.google.com/file/d/17iGn3c-sYNiLyRSY-A85QOzgzGnGiVI3/view?usp=sharing)。

## StarCoder2 是什么？

StarCoder2 是一个面向代码的开源 LLM 家族，有 3B、7B 和 15B 三种参数规模。旗舰模型 StarCoder2-15B 使用来自 The Stack v2 的 600 多种编程语言、超过 4 万亿 token 训练。所有模型都使用分组查询注意力（Grouped Query Attention）、16,384 token 的上下文窗口和 4,096 token 的滑动窗口注意力，并采用 Fill-in-the-Middle 目标训练。

StarCoder2 提供三种模型规模：由 ServiceNow 训练的 30 亿参数模型、由 Hugging Face 训练的 70 亿参数模型，以及由 NVIDIA 使用 NVIDIA NeMo 在 NVIDIA 加速基础设施上训练的 150 亿参数模型：

- [StarCoder2-3B](https://huggingface.co/bigcode/starcoder2-3b) 使用来自 The Stack v2 的 17 种编程语言、3+ 万亿 token 训练。
- [StarCoder2-7B](https://huggingface.co/bigcode/starcoder2-7b) 使用来自 The Stack v2 的 17 种编程语言、3.5+ 万亿 token 训练。
- [StarCoder2-15B](https://huggingface.co/bigcode/starcoder2-15b) 使用来自 The Stack v2 的 600+ 种编程语言、4+ 万亿 token 训练。

StarCoder2-15B 在同尺寸模型中表现最佳，并在多项评估中媲美 33B+ 模型。StarCoder2-3B 则达到 StarCoder1-15B 的性能：

## The Stack v2 是什么？

The Stack v2 是可用于 LLM 预训练的最大开源代码数据集。The Stack v2 比 The Stack v1 更大，采用改进的语言与许可证检测流程以及更好的过滤启发式规则。此外，训练数据集按仓库（repository）分组，使模型可以利用仓库上下文进行训练。

|  | [The Stack v1](https://huggingface.co/datasets/bigcode/the-stack/) | [The Stack v2](https://huggingface.co/datasets/bigcode/the-stack-v2/) |
| --- | --- | --- |
| full | 6.4TB | 67.5TB |
| deduplicated | 2.9TB | 32.1TB |
| training dataset | ~200B tokens | ~900B tokens |

该数据集源自 Software Heritage 存档——最大的公开软件源代码及其开发历史存档。Software Heritage 由 Inria 与 UNESCO 合作发起，是一个收集、保存并共享所有公开软件源代码的开放非营利项目。我们感谢 Software Heritage 提供这一宝贵资源的访问。更多详情请访问 [Software Heritage 官网](https://www.softwareheritage.org)。

The Stack v2 可以通过 [Hugging Face Hub](https://huggingface.co/datasets/bigcode/the-stack-v2/) 访问。

## 关于 BigCode

BigCode 是由 Hugging Face 和 ServiceNow 共同领导的开放科研协作项目，致力于负责任地开发面向代码的大语言模型。
