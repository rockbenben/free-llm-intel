# 介绍 HUGS——用开放模型扩展你的 AI

Philipp Schmid（philschmid）、Jeff Boudier（jeffboudier）、Alvaro Bartolome（alvarobartt）、Simon Pagezy（pagezyhf）、Violette（Violette）

> 2025 年 9 月更新：我们不再提供 HUGS 模型部署容器。
> 要在你的基础设施里轻松部署优化过的 Hugging Face 模型，请查看 Dell Enterprise Hub 以及 Azure AI Foundry 里的 Hugging Face Collection。

今天，我们激动地宣布 **Hugging Face Generative AI Services（即 HUGS）** 上线：这是一套优化好的、零配置的推理微服务，旨在简化和加速用开放模型开发 AI 应用。HUGS 构建在开源的 Hugging Face 技术之上，如 Text Generation Inference 和 Transformers，为在你自己的基础设施里高效构建和扩展生成式 AI 应用提供最佳方案。HUGS 针对在各种硬件加速器上运行开放模型做了优化，包括 NVIDIA GPU、AMD GPU，以及即将支持的 AWS Inferentia 和 Google TPU。

[![HUGS Banner](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/hugs/hugs-banner.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/hugs/hugs-banner.png)

## 面向开放模型的零配置优化推理

HUGS 简化了在你自己的基础设施里、在各种硬件上对开放模型的优化部署。开发者和组织面临的一个关键挑战，是为特定 GPU 或 AI 加速器优化 LLM 推理工作负载的工程复杂度。HUGS 为最受欢迎的开放 LLM 提供零配置的最大吞吐量部署。HUGS 提供的每个部署配置都经过充分测试、并保持开箱即用地维护。

HUGS 模型部署提供一个兼容 OpenAI 的 API，可作为基于模型提供商 API 构建的现有生成式 AI 应用的直接替换。只需把你的代码指向 HUGS 部署，就能用托管在你自己基础设施里的开放模型为你的应用提供动力。

## 为什么选 HUGS？

HUGS 提供了一种简单的方式来构建托管在你自己基础设施里的、用开放模型的 AI 应用，优势如下：

- **在你自己的基础设施里**：在你自己的安全环境内部署开放模型。把你的数据和模型留在互联网之外！
- **零配置部署**：HUGS 把部署时间从数周缩短到数分钟，零配置安装，自动为你的 NVIDIA、AMD GPU 或 AI 加速器优化模型和服务配置。
- **硬件优化推理**：构建于 Hugging Face 的 Text Generation Inference（TGI）之上，HUGS 针对不同硬件配置为峰值性能做了优化。
- **硬件灵活性**：HUGS 可在各种加速器上运行，包括 NVIDIA GPU、AMD GPU，对 AWS Inferentia 和 Google TPU 的支持即将推出。
- **模型灵活性**：HUGS 兼容大量开源模型，为你的 AI 应用提供灵活性和选择。
- **行业标准 API**：用 Kubernetes 轻松部署 HUGS，端点兼容 OpenAI API，代码改动最小。
- **企业级分发**：HUGS 是 Hugging Face 开源技术的企业级分发，提供长期支持、严格测试和 SOC2 合规。
- **企业合规**：通过包含必要的许可证和服务条款，最小化合规风险。

**我们向部分 Enterprise Hub 客户提供了 HUGS 的早期访问：**

> HUGS 在本地部署即用、性能良好的模型上是一个巨大的时间节省器——在 HUGS 之前要花我们一周，现在不到 1 小时就能搞定。对于有主权 AI 需求的客户，它是颠覆性的！——Polyconseil CTO Henri Jouhaud

> 我们试过用 HUGS 在 GCP 上、用一块 L4 GPU 部署 Gemma 2——我们不用去折腾库、版本和参数，它就是开箱即用地跑起来了。HUGS 让我们有信心能够扩展内部对开放模型的使用！——Orange 研究员工程师 Ghislain Putois

## 它如何工作

使用 HUGS 很直接。下面是你的上手方式：

*注意：根据你的部署方式，你需要访问相应的订阅或市场服务。*

### 在哪里找到 HUGS

HUGS 通过几个渠道提供：

- **云服务提供商（CSP）市场**：你可以在 [Amazon Web Services (AWS)](https://aws.amazon.com/marketplace/pp/prodview-bqy5zfvz3wox6) 和 [Google Cloud Platform (GCP)](https://console.cloud.google.com/marketplace/product/huggingface-public/hugs) 上找到并部署 HUGS。对 [Microsoft Azure](https://huggingface.co/docs/hugs/how-to/cloud/azure) 的支持即将推出。
- **DigitalOcean**：HUGS 在 [DigitalOcean 中原生可用，作为一个全新的 1-Click Models 服务](http://digitalocean.com/blog/one-click-models-on-do-powered-by-huggingface)，由 Hugging Face HUGS 和 GPU Droplets 驱动。
- **Enterprise Hub**：如果你的组织升级到 Enterprise Hub，[联系我们的销售团队](https://huggingface.co/contact/sales?from=hugs)以获取 HUGS 访问权限。

关于每个平台的具体部署说明，请参考上面链接的相关文档。

### 定价

除 DigitalOcean 上的部署外，HUGS 根据每个容器的运行时间提供按需计费。

- **AWS Marketplace 和 Google Cloud Platform Marketplace**：每个容器每小时 1 美元，无最低费用（算力由 CSP 单独计费）。在 AWS 上你有 5 天免费试用期来免费测试 HUGS。
- **DigitalOcean**：由 Hugging Face HUGS 驱动的 1-Click Models 在 DigitalOcean 上免费可用——照常收取 GPU Droplets 的算力费用。
- **Enterprise Hub**：我们为 Enterprise Hub 组织提供自定义的 HUGS 访问。请[联系](https://huggingface.co/contact/sales?from=hugs)我们的销售团队了解更多。

### 运行推理

HUGS 基于 Text Generation Inference（TGI），提供顺畅的推理体验。详细说明和示例请参考 [Run Inference on HUGS](https://huggingface.co/docs/hugs/guides/inference) 指南。HUGS 利用兼容 OpenAI 的 Messages API，让你能用熟悉的工具和库（如 cURL、`huggingface_hub` SDK 和 `openai` SDK）发送请求。

```
from huggingface_hub import InferenceClient

ENDPOINT_URL="REPLACE" # replace with your deployed url or IP

client = InferenceClient(base_url=ENDPOINT_URL, api_key="-")

chat_completion = client.chat.completions.create(
    messages=[
        {"role":"user","content":"What is Deep Learning?"},
    ],
    temperature=0.7,
    top_p=0.95,
    max_tokens=128,
)
```
