我们很高兴地宣布：**Scaleway** 现已成为 Hugging Face Hub 上受支持的推理提供商（Inference Provider）！Scaleway 加入了不断壮大的生态系统，让 Hub 模型页上的 serverless 推理覆盖面更广、能力更强。Inference Providers 还与我们的客户端 SDK（JS 和 Python 都有）无缝集成，用你偏好的提供商调用各种模型非常轻松。

这次上线让访问 [gpt-oss](https://huggingface.co/openai/gpt-oss-120b?inference_provider=scaleway)、[Qwen3](https://huggingface.co/Qwen/Qwen3-Coder-30B-A3B-Instruct?inference_provider=scaleway)、[DeepSeek R1](https://huggingface.co/deepseek-ai/DeepSeek-R1-Distill-Llama-70B?inference_provider=scaleway) 和 [Gemma 3](https://huggingface.co/google/gemma-3-27b-it?inference_provider=scaleway) 等热门开放权重模型变得前所未有地简单——直接在 Hugging Face 上就能调用。你可以在 Hub 上浏览 Scaleway 的主页 [https://huggingface.co/scaleway](https://huggingface.co/scaleway)，也可以在 [https://huggingface.co/models?inference_provider=scaleway&sort=trending](https://huggingface.co/models?inference_provider=scaleway&sort=trending) 试用受支持的趋势模型。

*Scaleway Generative APIs* 是一个全托管的 serverless 服务，通过简单的 API 调用即可访问来自顶级研究实验室的前沿 AI 模型。服务提供有竞争力的按 token 计费价格，最低每分钟（每百万）token 0.20 欧元起。

服务运行在位于欧洲数据中心（法国巴黎）的安全基础设施上，为欧洲用户保证数据主权和低延迟。平台支持结构化输出（structured outputs）、函数调用（function calling）以及文本和图像的多模态能力等高级特性。

Scaleway 的推理基础设施面向生产环境，首 token 响应时间低于 200ms，非常适合交互式应用和 agentic 工作流。服务同时支持文本生成和嵌入（embedding）模型。了解更多平台与基础设施信息请访问 [https://www.scaleway.com/en/generative-apis/](https://www.scaleway.com/en/generative-apis/)。

关于如何把 Scaleway 用作 Inference Provider，请阅读其专属[文档页](https://huggingface.co/docs/inference-providers/providers/scaleway)。

受支持模型列表见[这里](https://huggingface.co/models?inference_provider=scaleway&sort=trending)。

## 工作原理

### 在网站 UI 中

- 在你的账号设置里，你可以：

- 为你签约的提供商设置自己的 API key。如果不设置自定义 key，你的请求会通过 HF 路由。
- 按偏好给提供商排序。这会影响模型页上的 widget 和代码片段。

- 如前所述，调用 Inference Providers 有两种模式：

- 自定义 key（请求直接发到推理提供商，使用你在对应推理提供商的 API key）
- 由 HF 路由（这种情况下你不需要提供商的 token，费用直接记在你的 HF 账号上，而不是提供商账号上）

- 模型页会展示第三方推理提供商（与当前模型兼容的那些，按用户偏好排序）

### 从客户端 SDK 调用

#### Python，使用 huggingface_hub

下面的示例演示如何用 Scaleway 作为推理提供商调用 OpenAI 的 gpt-oss-120b。你可以用 [Hugging Face token](https://huggingface.co/settings/tokens) 走 Hugging Face 自动路由，也可以用自己的 Scaleway API key。

注意：需要较新版本的 `huggingface_hub`（>= 0.34.6）。

```
import os
from huggingface_hub import InferenceClient

client = InferenceClient(
    provider="scaleway",
    api_key=os.environ["HF_TOKEN"],
)

messages = [
    {
        "role": "user",
        "content": "Write a poem in the style of Shakespeare"
    }
]

completion = client.chat.completions.create(
    model="openai/gpt-oss-120b",
    messages=messages,
)

print(completion.choices[0].message)
```

#### JS，使用 @huggingface/inference

```
import { InferenceClient } from "@huggingface/inference";

const client = new InferenceClient(process.env.HF_TOKEN);

const chatCompletion = await client.chatCompletion({
  model: "openai/gpt-oss-120b",
  messages: [
    {
      role: "user",
      content: "Write a poem in the style of Shakespeare",
    },
  ],
  provider: "scaleway",
});

console.log(chatCompletion.choices[0].message);
```
