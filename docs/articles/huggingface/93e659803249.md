# Hugging Face 计算机视觉的现状 🤗

在 Hugging Face，我们以内置使命感的方式，与社区一起推动人工智能领域的民主化。作为这一使命的一部分，过去一年里我们开始把精力投向计算机视觉。一切始于一个 [在 🤗 Transformers 中加入 Vision Transformers（ViT）的 PR](https://github.com/huggingface/transformers/pull/10950)，如今它已成长为远大于此的东西——Hugging Face Hub 上有 8 个核心视觉任务、3000 多个模型、100 多个数据集。

自 ViT 加入 Hub 以来，发生了许多令人兴奋的事情。在这篇博文中，我们将回顾已经发生的事、以及即将支持的能力，以持续推动 🤗 生态中计算机视觉的进步。

## 赋能社区：一次一个任务 👁

Hugging Face Hub 上托管着超过 100,000 个公开模型，覆盖next-word 预测、掩码填充（mask filling）、token 分类、序列分类等各类任务。截至目前，我们支持 [8 个核心视觉任务](https://huggingface.co/tasks)，并提供了大量模型 checkpoint：

- 图像分类
- 图像分割
- （零样本）目标检测
- 视频分类
- 深度估计
- 图到图合成
- 无条件图像生成
- 零样本图像分类

这些任务中的每一个，Hub 上至少有 10 个模型 checkpoint 供你探索。此外，我们还支持视觉与语言交叉地带的 [任务](https://huggingface.co/tasks)，例如：

- 图像到文本（图像描述、OCR）
- 文本到图像
- 文档问答
- 视觉问答

这些任务不仅涵盖 [ViT](https://huggingface.co/docs/transformers/model_doc/vit)、[Swin](https://huggingface.co/docs/transformers/model_doc/swin)、[DETR](https://huggingface.co/docs/transformers/model_doc/detr) 等最先进（state-of-the-art）的基于 Transformer 的架构，也包括 [ConvNeXt](https://huggingface.co/docs/transformers/model_doc/convnext)、[ResNet](https://huggingface.co/docs/transformers/model_doc/resnet)、[RegNet](https://huggingface.co/docs/transformers/model_doc/regnet) 等*纯卷积*架构！像 ResNet 这样的架构在众多工业场景中依然非常重要，这也是 🤗 Transformers 支持这些非 Transformer 架构的原因。

还需要注意的是，Hub 上的模型并不只来自 Transformers 库，也来自其他第三方库。例如，尽管我们在 Hub 上支持无条件图像生成这样的任务，Transformers 中暂时还没有支持该任务的模型（比如 [这个模型](https://huggingface.co/ceyda/butterfly_cropped_uniq1K_512)）。支持所有机器学习任务——无论它们是用 Transformers 还是第三方库解决——是我们培育协作式开源机器学习生态这一使命的一部分。

## 对 Pipelines 的支持

我们开发 [Pipelines](https://huggingface.co/docs/transformers/main/en/main_classes/pipelines)，是为了给实践者提供随手可用的工具，让机器学习可以轻松进入他们的工具箱。Pipelines 提供了一种简单的方式，针对给定输入、围绕某个任务执行推理。Pipelines 目前覆盖 [七个视觉任务](https://huggingface.co/docs/transformers/main/en/main_classes/pipelines#computer-vision)。下面是一个用 Pipelines 做深度估计的例子：

```
from transformers import pipeline

depth_estimator = pipeline(task="depth-estimation", model="Intel/dpt-large")
output = depth_estimator("http://images.cocodataset.org/val2017/000000039769.jpg")

# This is a tensor with the values being the depth expressed
# in meters for each pixel
output["depth"]
```

即使是视觉问答这样的任务，接口也保持一致：

```
from transformers import pipeline

oracle = pipeline(model="dandelin/vilt-b32-finetuned-vqa")
image_url = "https://huggingface.co/datasets/mishig/sample_images/resolve/main/tiger.jpg"

oracle(question="What's the animal doing?", image=image_url, top_k=1)
# [{'score': 0.778620, 'answer': 'laying down'}]
```

## 训练你自己的模型

能够直接使用现成模型做推理是不错的入门方式，但微调才是社区获益最大的地方。当你的数据集是定制的、预训练模型又给不出理想性能时，尤其如此。

Transformers 为训练相关的一切提供了 [Trainer API](https://huggingface.co/docs/transformers/main_classes/trainer)。目前，`Trainer` 无缝支持以下任务：图像分类、图像分割、视频分类、目标检测、深度估计。其他视觉任务的模型微调同样受到支持，只是不通过 `Trainer`。

只要 Transformers 中的某个模型针对给定任务计算了 loss，它就应当可以用于该任务的微调。如果你发现问题，请在 GitHub 上 [报告](https://github.com/huggingface/transformers/issues)。

**代码在哪里？**

- [模型文档](https://huggingface.co/docs/transformers/index#supported-models)
- [Hugging Face notebooks](https://github.com/huggingface/notebooks)
- [Hugging Face 示例脚本](https://github.com/huggingface/transformers/tree/main/examples)
- [任务页面](https://huggingface.co/tasks)

[Hugging Face 示例脚本](https://github.com/huggingface/transformers/tree/main/examples) 中包含多种[自监督预训练策略](https://github.com/huggingface/transformers/tree/main/examples/pytorch/image-pretraining)，如 [MAE](https://arxiv.org/abs/2111.06377)，以及[对比式图文预训练策略](https://github.com/huggingface/transformers/tree/main/examples/pytorch/contrastive-image-text)，如 [CLIP](https://arxiv.org/abs/2103.00020)。对于研究社区，以及打算在自定义数据语料上从零开始跑预训练的实践者来说，这些脚本都是很有价值的资源。

不过，有些任务本身并不以微调为目的。例子包括零样本图像分类（如 [CLIP](https://huggingface.co/docs/transformers/main/en/model_doc/clip)）、零样本目标检测（如 [OWL-ViT](https://huggingface.co/docs/transformers/main/en/model_doc/owlvit)），以及零样本分割（如 [CLIPSeg](https://huggingface.co/docs/transformers/model_doc/clipseg)）。我们在本文后面还会回到这些模型。

## 与 Datasets 的集成

[Datasets](https://huggingface.co/docs/datasets) 让你轻松访问数千个不同模态的数据集。如前所述，Hub 上有 100 多个计算机视觉数据集。值得一提的几个例子：[ImageNet-1k](https://huggingface.co/datasets/imagenet-1k)、[Scene Parsing](https://huggingface.co/datasets/scene_parse_150)、[NYU Depth V2](https://huggingface.co/datasets/sayakpaul/nyu_depth_v2)、[COYO-700M](https://huggingface.co/datasets/kakaobrain/coyo-700m) 和 [LAION-400M](https://huggingface.co/datasets/laion/laion400m)。既然这些数据集就在 Hub 上，只需两行代码就能轻松加载：

```
from datasets import load_dataset

dataset = load_dataset("scene_parse_150")
```

除了这些数据集，我们还提供与 [albumentations](https://github.com/huggingface/notebooks/blob/main/examples/image_classification_albumentations.ipynb)、[Kornia](https://github.com/huggingface/notebooks/blob/main/examples/image_classification_kornia.ipynb) 等数据增强库的集成支持。社区可以同时受益于 Datasets 的灵活性与性能，以及这些库提供的强大增强变换。除此之外，我们还针对核心视觉任务（图像分类、图像分割、目标检测、深度估计）提供了[专门的数据加载指南](https://huggingface.co/docs/datasets/image_load)。

## 🤗 🤝 timm

`timm`，也叫 [pytorch-image-models](https://github.com/rwightman/pytorch-image-models)，是一个开源的先进（state-of-the-art）PyTorch 图像模型、预训练权重，以及用于训练、推理和验证的工具脚本合集。

Hub 上已有来自 `timm` 的 200 多个模型，而且还会有更多。想了解这一集成的更多细节，请查阅[文档](https://huggingface.co/docs/timm/index)。

## 🧨 Diffusers

[Diffusers](https://huggingface.co/docs/diffusers) 提供预训练的视觉与音频扩散模型，并作为推理与训练的模块化工具箱。借助这个库，你可以在众多创意用例中，从自然语言输入生成逼真的图像。这里有一个例子：

```
from diffusers import DiffusionPipeline

generator = DiffusionPipeline.from_pretrained("CompVis/stable-diffusion-v1-4")
generator.to(“cuda”)

image = generator("An image of a squirrel in Picasso style").images[0]
```

这类技术能够催生新一代创意应用，也能帮助来自不同背景的创作者。想了解更多关于 Diffusers 及其各种用例的内容，请查看[官方文档](https://huggingface.co/docs/diffusers)。

基于扩散（Diffusion）模型的文献正在快速发展，这也是我们与 [Jonathan Whitaker](https://github.com/johnowhitaker) 合作开发相关课程的原因。课程免费，你可以在[这里](https://github.com/huggingface/diffusion-models-class)查看。

## 对第三方库的支持

Hugging Face 生态的核心是 [Hugging Face Hub](https://huggingface.co/docs/hub)，它让人们能够在机器学习上高效协作。如前所述，Hub 上不仅支持 🤗 Transformers 的模型，也支持其他第三方库的模型。为此，我们提供了[一系列工具](https://huggingface.co/docs/hub/models-adding-libraries)，让你可以把自己的库集成到 Hub 上。这样做的主要好处之一是：与社区分享制品（如模型和数据集）变得非常轻松，从而让你的用户更容易试用你的模型。

当你的模型托管在 Hub 上之后，你还可以为它们[添加自定义推理组件（inference widgets）](https://github.com/huggingface/api-inference-community)。推理组件让用户可以快速试用模型，有助于提升用户参与度。

## 用于计算机视觉演示的 Spaces

借助 [Spaces](https://huggingface.co/docs/hub/spaces-overview)，你可以轻松展示自己的机器学习模型。Spaces 直接支持 [Gradio](https://gradio.app/)、[Streamlit](https://streamlit.io/) 和 [Docker](https://www.docker.com/) 集成，让实践者在展示模型时拥有很大的灵活性。你可以带入自己的机器学习框架，用 Spaces 搭建演示应用。

Gradio 库为在 Spaces 上构建计算机视觉应用提供了多种组件，例如 [Video](https://gradio.app/docs/#video)、[Gallery](https://gradio.app/docs/#gallery) 和 [Model3D](https://gradio.app/docs/#model3d)。社区一直在辛勤工作，构建了一些由 Spaces 驱动的出色计算机视觉应用：

- [对 YouTube 视频进行分类](https://huggingface.co/spaces/fcakyon/video-classification)
- [零样本视频分类](https://huggingface.co/spaces/fcakyon/zero-shot-video-classification)
- [视觉问答](https://huggingface.co/spaces/nielsr/vilt-vqa)

## 🤗 AutoTrain

[AutoTrain](https://huggingface.co/autotrain) 提供了一个「无代码」方案，用于训练最先进（state-of-the-art）的机器学习模型，覆盖文本分类、文本摘要、命名实体识别等任务。在计算机视觉方面，我们目前支持[图像分类](https://huggingface.co/blog/autotrain-image-classification)，但预计后续会覆盖更多任务。

AutoTrain 还支持[自动模型评估](https://huggingface.co/spaces/autoevaluate/model-evaluator)。这个应用可以让你在 Hub 上众多[数据集](https://huggingface.co/datasets)上评估各种 🤗 Transformers [模型](https://huggingface.co/models?library=transformers&sort=downloads)。你的评估结果会展示在[公开排行榜](https://huggingface.co/spaces/autoevaluate/leaderboards)上。详情可查看[这篇博客](https://huggingface.co/blog/eval-on-the-hub)。

## 技术理念

在这一节，我们想分享在 🤗 Transformers 中支持计算机视觉背后的理念，让社区了解这一领域特有的设计取舍。

虽然 Transformers 起步于 NLP，但我们今天支持多种模态，例如视觉、音频、视觉-语言、强化学习（Reinforcement Learning）。对所有这些模态，Transformers 中相应的模型都享有以下共同的好处：

- 用 `from_pretrained()` 一行代码即可轻松下载模型
- 用 `push_to_hub()` 轻松上传模型
- 借助高效的 checkpoint 分片（sharding）技术，支持加载超大的 checkpoint
- 优化支持（借助 [Optimum](https://huggingface.co/docs/optimum) 等工具）
- 可以从模型配置进行初始化
- 同时支持 PyTorch 和 TensorFlow（非穷尽）
- 以及更多

与 tokenizer 不同，我们有预处理器（preprocessors）（如[这个](https://huggingface.co/docs/transformers/model_doc/vit#transformers.ViTImageProcessor)）负责为视觉模型准备数据。我们下了很大功夫，确保使用视觉模型的体验依然轻松、并且与文本模型类似：

```
from transformers import ViTImageProcessor, ViTForImageClassification
import torch
from datasets import load_dataset

dataset = load_dataset("huggingface/cats-image")
image = dataset["test"]["image"][0]

image_processor   = ViTImageProcessor.from_pretrained("google/vit-base-patch16-224")
model = ViTForImageClassification.from_pretrained("google/vit-base-patch16-224")
inputs = image_processor(image, return_tensors="pt")

with torch.no_grad():
    logits = model(**inputs).logits

# model predicts one of the 1000 ImageNet classes
predicted_label = logits.argmax(-1).item()
print(model.config.id2label[predicted_label])
# Egyptian cat
```

即使是在目标检测这样复杂的任务上，用户体验也几乎没有变化：

```
from transformers import AutoImageProcessor, AutoModelForObjectDetection
from PIL import Image
import requests

url = "http://images.cocodataset.org/val2017/000000039769.jpg"
image = Image.open(requests.get(url, stream=True).raw)

image_processor = AutoImageProcessor.from_pretrained("microsoft/conditional-detr-resnet-50")
model = AutoModelForObjectDetection.from_pretrained("microsoft/conditional-detr-resnet-50")
inputs = image_processor(images=image, return_tensors="pt")

outputs = model(**inputs)

# convert outputs (bounding boxes and class logits) to COCO API
target_sizes = torch.tensor([image.size[::-1]])
results = image_processor.post_process_object_detection(
    outputs, threshold=0.5, target_sizes=target_sizes
)[0]

for score, label, box in zip(results["scores"], results["labels"], results["boxes"]):
    box = [round(i, 2) for i in box.tolist()]
    print(
        f"Detected {model.config.id2label[label.item()]} with confidence "
        f"{round(score.item(), 3)} at location {box}"
    )
```

输出结果：

```
Detected remote with confidence 0.833 at location [38.31, 72.1, 177.63, 118.45]
Detected cat with confidence 0.831 at location [9.2, 51.38, 321.13, 469.0]
Detected cat with confidence 0.804 at location [340.3, 16.85, 642.93, 370.95]
Detected remote with confidence 0.683 at location [334.48, 73.49, 366.37, 190.01]
Detected couch with confidence 0.535 at location [0.52, 1.19, 640.35, 475.1]
```

## 视觉领域的零样本模型

近来涌现了一大批模型，它们以有趣的方式重构了分割、检测等核心视觉任务，带来了更多灵活性。其中几个来自 Transformers 的模型我们已提供支持：

- [CLIP](https://huggingface.co/docs/transformers/main/en/model_doc/clip)，支持用提示（prompt）做零样本图像分类。给定一张图像，你可以用自然语言向 CLIP 模型提问，比如 "an image of {}"，期望得到的答案就是类别标签。
- [OWL-ViT](https://huggingface.co/docs/transformers/main/en/model_doc/owlvit)，支持以语言为条件的零样本目标检测，以及以图像为条件的单样本（one-shot）目标检测。这意味着即使底层模型在训练时并没有学过检测某些物体，你依然可以在图像中检测它们！更多细节可参考 [这个 notebook](https://github.com/huggingface/notebooks/tree/main/examples#:~:text=zeroshot_object_detection_with_owlvit.ipynb)。
- [CLIPSeg](https://huggingface.co/docs/transformers/model_doc/clipseg)，支持以语言为条件的零样本图像分割，以及以图像为条件的单样本图像分割。这意味着即使底层模型在训练时并没有学过分割某些物体，你依然可以对图像中的物体进行分割！可参考[这篇博客](https://huggingface.co/blog/clipseg-zero-shot)对这个思路的演示。[GroupViT](https://huggingface.co/docs/transformers/model_doc/groupvit) 同样支持零样本分割任务。
- [X-CLIP](https://huggingface.co/docs/transformers/main/en/model_doc/xclip)，展示了向视频方向的零样本泛化能力。准确地说，它支持零样本视频分类。详情可查看 [这个 notebook](https://github.com/NielsRogge/Transformers-Tutorials/blob/master/X-CLIP/Zero_shot_classify_a_YouTube_video_with_X_CLIP.ipynb)。

未来几天，社区可以期待 🤗 Transformers 支持更多面向计算机视觉的零样本模型。

## 部署

- [在 Vertex AI 上部署 🤗 ViT](https://huggingface.co/blog/deploy-vertex-ai)
