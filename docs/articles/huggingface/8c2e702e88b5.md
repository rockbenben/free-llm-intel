# 将 Livebook 笔记本作为应用部署到 Hugging Face Spaces

[Elixir](https://elixir-lang.org/) 社区正在机器学习方向上取得长足进步，而 Hugging Face 在其中发挥着重要的推动作用。为了展示 Elixir 与机器学习今天已经能做到什么，我们使用 [Livebook](https://livebook.dev/) 构建了一个基于 Whisper 的聊天应用，然后将其部署到 Hugging Face Spaces。全程不到 15 分钟，快来看看：

在这个聊天应用中，用户只能通过发送语音消息进行交流，消息随后会由 Whisper 机器学习模型自动转换为文本。

这个应用展示了 Livebook 和 Elixir 机器学习生态系统中几个有趣的功能：

- 与 Hugging Face Models 的集成
- 多人在线（multiplayer）机器学习应用
- 并发的机器学习模型服务（加分项：[你同样可以轻松地把模型服务分布在一个集群上](https://news.livebook.dev/distributed2-machine-learning-notebooks-with-elixir-and-livebook---launch-week-1---day-2-1aIlaw)）

如果你还不了解 Livebook：它是一个用于编写 Elixir 交互式代码笔记本的开源工具，属于 [不断壮大的 Elixir 工具集](https://github.com/elixir-nx)的一部分，覆盖科学计算、数据科学和机器学习。

## Hugging Face 与 Elixir

Elixir 社区在其机器学习版图中广泛借助了 Hugging Face 平台及其开源项目。这里举几个例子。

Hugging Face 带来的第一个积极影响是 [Bumblebee 库](https://github.com/elixir-nx/bumblebee)，它把来自 Hugging Face 的预训练神经网络模型带给了 Elixir 社区，其灵感来自 [Hugging Face Transformers](https://huggingface.co/docs/transformers/index)。除了灵感之外，Bumblebee 还使用 Hugging Face Hub 下载其模型参数。

另一个例子是 [tokenizers 库](https://github.com/elixir-nx/tokenizers)，它是 [Hugging Face Tokenizers](https://github.com/huggingface/tokenizers) 的 Elixir binding。

最后同样重要的是，[Livebook 可以运行在 Hugging Face Spaces 中](https://huggingface.co/docs/hub/spaces-sdks-docker-livebook)，作为其 Space Docker 模板之一，只需几次点击即可。所以，你不仅可以把 Livebook 应用部署到 Hugging Face，还可以免费运行 Livebook 来编写和试验你自己的笔记本。

## 轮到你了

我们希望 Livebook 与 Hugging Face 之间的这一新集成能够赋能更多人使用机器学习，并向世界展示他们的作品。

现在就动手吧：[在 Hugging Face Spaces 上安装 Livebook](https://huggingface.co/docs/hub/spaces-sdks-docker-livebook)，并[跟着我们的视频教程](https://www.youtube.com/watch?v=uyVRPEXOqzw)，构建并把你的第一个 Livebook ML 应用部署到 Hugging Face。
