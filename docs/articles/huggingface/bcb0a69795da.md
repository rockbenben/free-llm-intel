[![logos](https://huggingface.co/blog/assets/bedrock-marketplace/thumbnail.png)](https://huggingface.co/blog/assets/bedrock-marketplace/thumbnail.png)

我们高兴地宣布，Hugging Face 的热门开放模型现已通过全新的 Bedrock Marketplace 登陆 Amazon Bedrock！AWS 客户可以用 Bedrock Marketplace 部署 [83 个开放模型](https://us-east-1.console.aws.amazon.com/bedrock/home?region=us-east-1#/model-catalog)，构建自己的生成式 AI 应用。

在底层，Bedrock Marketplace 的模型端点由 Amazon Sagemaker Jumpstart 管理。有了 Bedrock Marketplace，你可以把 SageMaker JumpStart 的易用性与 Amazon Bedrock 的全托管基础设施结合起来，包括对 Agents、Knowledge Bases、Guardrails 和 Model Evaluations 等高层 API 的兼容。

当你把 Sagemaker Jumpstart 端点注册到 Amazon Bedrock 时，只需支付 Sagemaker 计算资源的费用，Amazon Bedrock 常规 API 价格照常适用。

在本博客中，我们将演示如何部署 [Gemma 2 27B Instruct](https://huggingface.co/google/gemma-2-27b-it) 并用 Amazon Bedrock API 调用模型。你将学到如何：

- 部署 Google Gemma 2 27B Instruct
- 使用 Amazon Bedrock API 发送请求
- 清理资源

## 部署 Google Gemma 2 27B Instruct

把开放模型部署到 Amazon Bedrock 有两条路径：

- 从 Bedrock Model Catalog 直接部署你的开放模型。
- 用 Amazon Jumpstart 部署开放模型，再注册到 Bedrock。

两种方式很相似，这里我们走 Bedrock Model catalog 这条路进行讲解。

开始：在 Amazon Bedrock 控制台，确保你处于 Bedrock Marketplace 可用的 14 个区域之一。然后在导航窗格的「Foundation models」部分选择[「Model catalog」](https://us-east-1.console.aws.amazon.com/bedrock/home?region=us-east-1#/model-catalog)。在这里，你可以同时搜索 serverless 模型和 Amazon Bedrock Marketplace 中的模型。按「Hugging Face」提供方过滤结果，就能浏览 83 个可用的开放模型。

例如，我们搜索并选中 Google Gemma 2 27B Instruct。

[![model-catalog.png](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/bedrock-marketplace/model-catalog.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/bedrock-marketplace/model-catalog.png)

选择模型后会打开模型详情页，你可以看到模型提供方的更多信息，例如模型亮点，以及用法（包括示例 API 调用）。

点击右上角的 Deploy。

[![model-card.png](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/bedrock-marketplace/model-card.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/bedrock-marketplace/model-card.png)

页面会跳转到部署页，你可以在这里选择端点名、实例配置，以及用于在 Sagemaker 执行部署的网络配置和 service role 等高级设置。我们使用默认的高级设置和推荐的实例类型。

你还必须接受模型提供方的最终用户许可协议（EULA）。

在右下角点击 Deploy。

[![model-deploy.png](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/bedrock-marketplace/model-deploy.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/bedrock-marketplace/model-deploy.png)

我们刚刚启动了 Google Gemma 2 27B Instruct 模型在 ml.g5.48xlarge 实例上的部署，它托管在你的 Amazon Sagemaker 租户中，并兼容 Amazon Bedrock API！

端点部署可能需要几分钟。它会出现在「Marketplace deployments」页面，你可以在导航窗格的「Foundation models」部分找到。

## 用 Amazon Bedrock API 调用模型

你可以通过 Playground 的 UI 快速测试模型。但要用任意 Amazon Bedrock API 以编程方式调用已部署的模型，你需要拿到端点的 ARN。

在托管部署列表中，选择你的模型部署，复制它的端点 ARN。

[![model-arn.png](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/bedrock-marketplace/model-arn.png)](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/blog/bedrock-marketplace/model-arn.png)

你可以用自己喜欢的语言的 AWS SDK 或 AWS CLI 查询端点。

下面是一个通过 AWS SDK for Python（boto3）使用 Bedrock Converse API 的例子：

```
import boto3

bedrock_runtime = boto3.client("bedrock-runtime")

# Add your bedrock endpoint arn here.
endpoint_arn = "arn:aws:sagemaker:<AWS::REGION>:<AWS::AccountId>:endpoint/<Endpoint_Name>"

# Base inference parameters to use.
inference_config = {
    "maxTokens": 256,
    "temperature": 0.1,
    "topP": 0.999,
}

# Additional inference parameters to use.
additional_model_fields = {"parameters": {"repetition_penalty": 0.9, "top_k": 250, "do_sample": True}}
response = bedrock_runtime.converse(
    modelId=endpoint_arn,
    messages=[
        {
            "role": "user",
            "content": [
                {
                    "text": "What is Amazon doing in the field of generative AI?",
                },
            ]
        },
        ],
    inferenceConfig=inference_config,
    additionalModelRequestFields=additional_model_fields,
)
print(response["output"]["message"]["content"][0]["text"])
```

```
"Amazon is making significant strides in the field of generative AI, applying it across various products and services. Here's a breakdown of their key initiatives:\n\n**1. Amazon Bedrock:**\n\n* This is their **fully managed service** that allows developers to build and scale generative AI applications using models from Amazon and other leading AI companies. \n* It offers access to foundational models like **Amazon Titan**, a family of large language models (LLMs) for text generation, and models from Cohere"
```

就这么简单！想更进一步，请查看 [Bedrock 文档](https://docs.aws.amazon.com/bedrock/latest/userguide/what-is-bedrock.html)。

## 清理

实验结束后，别忘了删除你的端点，以停止产生费用！在你获取端点 ARN 的页面右上角，点击「Delete」即可删除端点。
