# Hugging Face 与 Cloudflare 合作，用 FastRTC 让实时语音与视频无缝流畅

我们很高兴宣布 Cloudflare 与 Hugging Face 达成新合作：FastRTC 开发者凭一个 Hugging Face token 即可即时获得企业级 WebRTC 基础设施。

想了解用 FastRTC 和 Cloudflare 能构建什么，先看看这个用 Meta 新推出的 Llama 4 模型构建的语音聊天 [app](https://huggingface.co/spaces/fastrtc/talk-to-llama4)！

## 填补 AI 开发者工具箱的空白

随着对话式 AI 成为工具、产品和服务的核心交互界面，实时通信基础设施对于支撑自然的多模态交互越来越不可或缺。Hugging Face 打造 [FastRTC](https://fastrtc.org/)，正是让 AI 开发者用最少的 Python 代码构建低延迟、AI 驱动的音视频流，把 WebRTC——实时通信的金标准技术——的复杂性抽象掉。

WebRTC 应用的部署常常面临挑战，因为它们需要专门的 TURN 服务器在不同网络环境之间建立可靠连接。为解决这一问题，Cloudflare 构建了一张覆盖全球 335 个以上节点的 TURN 服务器网络。

这项合作把 FastRTC 的简单开发方式与 Cloudflare 的全球 TURN 网络结合起来，确保开发者能创建快速、可靠、全球连通 WebRTC 应用。

## 用你的 Hugging Face 账号免费访问

持有有效 Hugging Face Access Token 的 FastRTC 开发者每月可免费传输 10GB 数据，无需绑定信用卡。达到月度限额后，开发者可切换到自己的 Cloudflare 账号获得更高容量（[说明](https://fastrtc.org/deployment/#cloudflare-calls-api)）。

## 这对 AI 开发者为何重要

这项合作对构建以下应用的 AI 开发者尤其有价值：

- 需要可靠、低延迟音频流的语音助手
- 实时处理摄像头画面的视频分析应用
- 融合音频、视频和文本的多模态 AI 应用

借助 FastRTC，这项合作让开发者专注于核心应用逻辑，而无需建设和维护 TURN 基础设施。Cloudflare 的托管服务负责全球扩展性与可靠性，让 AI 开发者在没有基础设施维护负担的情况下交付卓越体验。

## 开始使用

该集成将在 FastRTC `0.0.20` 及以上版本提供。开始步骤：

- 确保你拥有具备读取权限的 Hugging Face token（[这里](https://huggingface.co/settings/tokens)获取）
- 安装或升级 FastRTC：`pip install --upgrade 'fastrtc[vad]'`
- 按下面的方式配置你的 Stream 使用 Cloudflare TURN 网络：

```
from fastrtc import ReplyOnPause, Stream, get_cloudflare_turn_credentials
import os

os.environ["HF_TOKEN"] = "<your-hf-token>"

def echo(audio):
    yield audio

stream = Stream(ReplyOnPause(echo),
                rtc_config=get_cloudflare_turn_credentials)
stream.ui.launch()
```

用 python 启动你的脚本：`python <name of your script>.py`

更多示例请查看 Hugging Face 上的这个 [Collection](https://huggingface.co/collections/fastrtc/cloudflare-partnership-67f437e0dfd19818d62ccb81) 以及 [FastRTC Cookbook](https://fastrtc.org/cookbook/)。
