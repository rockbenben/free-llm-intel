# Falcon-Arabic：阿拉伯语语言模型的突破

[![image/png](https://cdn-uploads.huggingface.co/production/uploads/659bc8a7b0f43ed69f0b2300/O0Y5QAAjDTFiu7WRwcbS1.png)](https://cdn-uploads.huggingface.co/production/uploads/659bc8a7b0f43ed69f0b2300/O0Y5QAAjDTFiu7WRwcbS1.png)

> Check out our official blogpost (EN, AR)

我们兴奋地推出 **Falcon-Arabic**——一个 70 亿参数的语言模型，为阿拉伯语 NLP 树立了新标杆。Falcon-Arabic 基于 Falcon 3 架构构建，是一个支持阿拉伯语、英语及其他多种语言的多语言模型，在通用知识、阿拉伯语语法、数学推理、复杂问题解决和理解丰富多样的阿拉伯方言方面表现出色。Falcon-Arabic 支持 32,000 token 上下文长度，能处理长文档，支撑检索增强生成（RAG）、深度内容创作与知识密集型任务等高级应用。

Falcon-Arabic 重新定义了阿拉伯语语言模型的可能边界。在同等规模档位中，它显著超越其他阿拉伯语 LLM，甚至胜过大其至多四倍的模型——无论阿拉伯语原生模型还是从其他语言适配的模型皆然。这让 Falcon-Arabic 不仅成为性能上的最先进模型，也是处理阿拉伯语的开发者与研究者的独特高效且可及的方案。

## 🚀 Falcon-Arabic 亮相：为阿拉伯语世界推进 LLM

近年来，大语言模型（LLM）彻底改变了人工智能，驱动着翻译、内容创作、虚拟助手等工具。然而这些进展大多聚焦于英语等高资源语言，让阿拉伯语等语言代表性不足。阿拉伯语有其独特挑战：形态丰富、双层语言现象（涵盖现代标准阿拉伯语 MSA 与多样的地区方言），并服务于庞大而文化多元的人群。开发健壮的阿拉伯语 LLM，是确保阿拉伯语社群被完整纳入 AI 革命的必需。

本着这一目标，我们推出 **Falcon-Arabic**——由阿联酋 [**技术创新研究所（TII）**](https://www.tii.ae/) 开发的 [**Falcon 3 模型家族**](https://huggingface.co/collections/tiiuae/falcon3-67605ae03578be86e4e87026)的专门适配版。Falcon 模型以其多语言实力和开源路线赢得全球认可。Falcon-Arabic 建立在这一传承之上，把先进的语言理解与生成带给阿拉伯语。通过让模型同时处理现代标准阿拉伯语与关键方言，Falcon-Arabic 填补了语言技术中的关键空白，在海湾、中东和北非实现更自然、更智能、更包容的阿拉伯语 AI。

## 🦅 Falcon-Arabic 已着陆——训练配方如下 🧪

构建 Falcon-Arabic 始于一个战略决策：与其从零训练模型，我们选择改造一个强多语言底座。在阿拉伯语 LLM 版图中主要有三条路线：从零训练（如 Jais 原生）、适配多语言模型（如 Allam 或 Fanar）、使用原生支持阿拉伯语的多语言模型（如 Qwen 或 LLaMA）。观察 [Open Arabic LLM Leaderboard](https://huggingface.co/spaces/OALL/Open-Arabic-LLM-Leaderboard) 可以发现，适配型与多语言模型在效率与能力上持续领先。为了延续这一势头，我们选择了 **Falcon 3-7B**——由 **技术创新研究所（TII）** 开发的 Falcon 3 家族中，在性能与资源效率之间取得务实平衡的模型。

核心挑战在于改造原本在 tokenizer 和嵌入层面不支持阿拉伯语的 [Falcon 3-7B](https://huggingface.co/tiiuae/Falcon3-7B-Base)。我们的做法是给 tokenizer 词表扩展 **32,000 个阿拉伯语专属 token**，并应用一种基于**文本相似度**的**新颖嵌入初始化策略**。该技术把新的阿拉伯语 token 映射到既有词表中语义相关的嵌入上，让模型继承先验知识、加速学习——尤其在情感、抽象概念和推理模式方面。这让 Falcon-Arabic 在理解与生成高质量阿拉伯语文本上赢在了起跑线。

tokenizer 与嵌入就绪后，我们在高质量、**100% 原生阿拉伯语数据集**上开始**继续预训练**，避免使用机器翻译内容，以尽量减少文化偏置、保持语言纯正。训练遵循**多阶段课程**：早期聚焦**通用知识与方言丰富的阿拉伯语内容**以稳定模型并强化逻辑能力，后期侧重**数学、代码与推理**。最终得到的模型不仅跨方言流利地说阿拉伯语，还保住了 Falcon 的多语言与推理优势——为阿拉伯语优先的 AI 拓展边界。

## 📊 Falcon-Arabic：抬高阿拉伯语 LLM 的门槛

我们在 **[OALL v2](https://huggingface.co/spaces/OALL/Open-Arabic-LLM-Leaderboard)**——阿拉伯语语言模型的领先基准——上评估 Falcon-Arabic。它包含六个多选题任务（如阿拉伯语 MMLU（原生与翻译版）、阿拉伯语考试、Alghafa、MadinahQA、Aratrust）和一个生成式基准 Alrage。**Falcon-Arabic 超越其规模档内所有现存阿拉伯语 LLM，甚至胜过大 4 倍的模型**。它在阿拉伯语 MMLU、Exams、MadinahQA、Aratrust 等关键基准上领先，为阿拉伯语优先的语言模型树立新标准。

## 🗣️ 从预训练到 Instruct：让 Falcon-Arabic 对齐对话

完成 base 模型训练后，我们进行了**后训练对齐**阶段，按人类偏好微调 Falcon-Arabic 的回答。这一阶段以**监督微调（SFT）**开始，使用高质量公开数据集与内部收集的**原生阿拉伯语指令数据**的组合，覆盖多种任务与对话场景。

为进一步强化对齐，我们应用了 **Direct Preference Optimization (DPO)**——一种基于强化学习的方法，让模型偏好人类认为更有用、安全、贴题的输出。这个两步流程保证 Falcon-Arabic Instruct 不仅精通阿拉伯语理解，其回答方式也契合真实用户预期。

## 🔓 释放阿拉伯语 AI 的潜力

Falcon-Arabic 为阿拉伯语语言模型树立了新标杆。仅 70 亿参数，它就交付了最先进性能，在阿拉伯语 MMLU、MadinahQA、Aratrust 等关键基准上超越同等规模甚至大数倍的模型。它兼具现代标准阿拉伯语的流利度、对地区方言的强理解与健壮的推理和多语言能力，适合广泛应用：从阿拉伯语优先的聊天机器人和教育工具，到内容生成、代码辅助与文档理解。

## ⚠️ 局限

与所有大语言模型一样，Falcon-Arabic 也继承了某些常见局限，包括偶发的**幻觉**（产出看似合理但不正确的输出）、**对 prompt 措辞的敏感性**，以及在超长上下文上性能不一。虽然 Falcon-Arabic 尤其针对阿拉伯语任务设计以减少这些问题，用户在解读结果时仍应保持批判性思维，特别是在高风险或事实敏感的用例中。
