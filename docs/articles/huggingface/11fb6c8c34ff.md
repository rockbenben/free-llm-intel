# 机器学习洞察总监（上）

在机器学习的圆桌旁，很少有哪个席位能像机器学习总监那样，同时横跨技术能力、问题解决和商业头脑。

机器学习/数据科学总监常常被要求：设计 ML 系统、精通数学、熟悉 ML 框架、深刻理解数据架构、有把 ML 应用到真实产品的经验、沟通能力强，往往还得紧跟业界动态。这要求可真不低！

[![](https://huggingface.co/blog/assets/61_ml_director_insights/private-model-hub.png)](https://huggingface.co/platform?utm_source=article&utm_medium=blog&utm_campaign=ml_director_insights_1)

正因如此，我们请来这群独特的 ML 总监，推出一个系列文章，听他们聊聊当前的 ML 洞察与行业趋势，涵盖医疗、金融、电商、SaaS、研究、媒体等。比如有位总监提到，用 ML 把卡车空驶（约占行驶时间的 20%）降到 19%，就能减少相当于约 10 万美国人排放的碳。注：这是餐巾纸背面的估算，不过出自一位前火箭科学家之手，我们就信了。

在这第一期里，你将听到：一位用探地雷达探测埋藏地雷的研究者、一位前火箭科学家、一位会说宗卡语的业余游戏玩家（Kuzu = 你好！）、一位曾住面包车的科学家、一位依然亲自上手的高绩效数据科学团队教练、一位重视关系、家庭、狗和披萨的数据从业者。——他们现在都是 ML 总监，拥有丰富的一线洞察。

🚀 来认识几位顶尖的机器学习总监，听听他们怎么看 ML 对各自行业的影响：

### Archi Mitra

**背景：** 让 ML 对商业的承诺回归平衡。人重于流程。战略重于侥幸。AI 伦理重于 AI 利润。布朗大学毕业的纽约人。

**冷知识：** 我会说[宗卡语](https://en.wikipedia.org/wiki/Dzongkha)（自己去搜！），并且是 [Youth for Seva](https://www.youthforseva.org/Donation) 的支持者。

**Buzzfeed：** 一家美国网络媒体、新闻与娱乐公司，专注数字媒体。

#### **1. ML 给媒体行业带来了哪些积极影响？**

*隐私优先的个性化：* 每个用户都是独特的：长期兴趣稳定，短期兴趣随机。他们期望与媒体的关系能体现这一点。硬件加速与深度学习推荐的共同进步，让我们开始能破解这种细微差别，在正确的时机、正确的触点，把正确的内容呈现给用户。

*面向创作者的辅助工具：* 创作者是媒体行业的稀缺资产，用 ML 驱动的人机协同（human-in-the-loop）辅助工具保护他们的创作带宽，效果出奇地好。哪怕只是自动建议与内容匹配的标题、图片、视频和/或商品这样简单的事，也能打开人与机器协作的飞轮。

*更紧凑的测试：* 在资本密集的媒体生意里，需要缩短"收集用户反馈"与"立即行动"之间的时间。借助各种贝叶斯技术和强化学习的进展，我们大幅削减了测试的时间和相关成本。

#### **2. 媒体行业里最大的 ML 挑战是什么？**

*隐私、编辑立场与公平覆盖：* 媒体如今更是民主世界的支柱，ML 必须尊重这一点，在别的领域算不上基本门槛的约束下运作。在编辑精选内容/节目编排与 ML 驱动推荐之间找平衡，始终是挑战。Buzzfeed 还有一个独特挑战：我们相信互联网应该是免费的，这意味着我们不像别人那样跟踪用户。

#### **3. 人们把 ML 整合进媒体时，常见错误是什么？**

忽视媒体的"创作者"：媒体之所以有影响力，是因为它承载着深刻影响人们的声量。编辑、内容创作者、作者与 makers 就是这声音的喉舌，构建能为他们赋能、延伸其影响力、与他们和谐协作的 ML，才是成功的关键配方。

#### **4. 关于 ML 的未来，最让你兴奋的是什么？**

希望是小型数据驱动的通用、多模态、多任务、实时 ML 系统，能在药物发现、高精度手术、气候控制系统和沉浸式元宇宙体验中带来台阶式的改进。现实一点看，是更易用、低投入的元学习技术，用于高精度文本与图像生成。

### Li Tan

**背景：** Li 是 AI/ML 老兵，15 年以上经验，曾在强生、微软、亚马逊等行业巨头领导高规格数据科学团队。

**冷知识：** Li 始终保持好奇、持续学习，并享受亲手编程。

**Johnson & Johnson（强生）：** 跨国企业，生产医疗器械、药品和消费品。

#### **1. ML 给医药行业带来了哪些积极影响？**

过去几年，AI/ML 应用在医药领域爆发，带来许多长期积极影响。医药与医疗健康有大量能利用 AI/ML 的场景。

应用范围从研究、真实世界证据，到智能制造和质量保证。用到的技术也非常广：NLP/NLU、CV、AIIoT、强化学习等，甚至像 AlphaFold 这样的东西。

#### **2. 医药行业里最大的 ML 挑战是什么？**

医药与医疗领域最大的 ML 挑战，是如何确保 AI 应用中的平等与多样性。例如，如何保证训练集对所有族裔都有良好代表性。由于医疗和医药行业的特性，这个问题的影响会比其他一些领域的应用大得多。

#### **3. 人们把 ML 整合进医药时，常见错误是什么？**

算不上错误，但我看到很多人在医疗 AI 应用上偏向两个极端：要么过于保守，要么过于激进。

有些人因监管要求高而抵触。我们的很多 AI 应用必须经过严格的 GxP 验证认定。这可能要做相当多的工作，但我们认为值得。另一个极端，则有人认为 AI/深度学习模型可以在很多应用上胜过人类并完全自主运行。

作为从业者，我们知道目前两种极端都不成立。

ML 模型可以极其有价值，但仍然会犯错。所以我推荐更渐进的方式。关键在于建立一个既能利用 AI 之力、又设有把关机制的框架。[FDA 已采取行动](https://www.fda.gov/medical-devices/software-medical-device-samd/artificial-intelligence-and-machine-learning-software-medical-device)规范 AI/ML 在"软件即医疗器械"中的使用，我认为这是对我们行业前进的积极一步。

#### **4. 关于 ML 的未来，最让你兴奋的是什么？**

AI/ML 与其他硬科学、硬技术的交叉点。我很期待接下来会发生什么。

#### **1. ML 给科学带来了哪些积极影响？**

ML 在很多方面带来了积极影响，从帮助自动化繁琐和/或缓慢的任务，到提供审视各种问题的新视角。我在植物科学 ML 方向的一个例子是：我们开发了用 ML 自动化图像中植物根系分割与特征刻画的方法。这个任务曾是研究根系图像的植物科学家的瓶颈。通过 ML 自动化这一步，我们可以以高得多的吞吐量做这些分析，并开始用这些数据大规模研究植物生物学的科学问题。

#### **2. 科研领域里最大的 ML 挑战是什么？**

挑战很多。举个例子：用 ML 做科学研究时，必须仔细思考数据采集和整编规范。某些情况下，我们用于非 ML 分析的规范并不适用或无效。数据的质量、数据对应用场景的代表性，会极大影响 ML 系统的性能、可靠性与可信度。

#### **3. 人们把 ML 整合进科研时，常见错误是什么？**

和上面那个问题相关，一个常见错误是把结果或性能仅仅归因于 ML 系统本身，而没有同时考虑数据采集、整编、校准和归一化规范。

#### **4. 关于 ML 的未来，最让你兴奋的是什么？**

有很多令人兴奋的方向。我目前的很多研究处在已有大量先验知识和经验推导模型的领域。例如，我正在用 ML 做森林生态学研究。林业界拥有丰富的先验知识，而目前纯数据驱动的 ML 系统并没有利用它们。我认为，把先验知识与 ML 方法无缝融合混合方法，将是一条有趣且令人兴奋的前路。比如理解两个物种在同一区域共现的可能性，或在某些环境条件下可以预期怎样的物种分布。这些与数据驱动方法结合，或许能在变化的条件下做预测。

#### **1. ML 给物流/运输行业带来了哪些积极影响？**

运输行业极度分散。头部玩家的市场份额都不到 1%。因此存在大量可以被数字化解决方案消解的低效。

举个例子，你在路上看到一辆半挂卡车，它现在有 20% 的概率后车厢里空无一物。是的，牵引拖挂车行驶的里程中，20% 来自上一单卸货后到下一单提货之间的空驶。而且很可能，另一辆卡车正朝着相反方向空驶（"deadheading"）。

有了机器学习和优化，空驶比例可以显著下降——仅把 20% 降到 19%，就能减少相当于 10 万美国人的碳排放。

注：这 10 万人的碳排放是我自己餐巾纸背面的计算。

#### **2. 物流行业里最大的 ML 挑战是什么？**

物流的大挑战正来自行业的高度分散：没有共享的数据池能让技术方案"看到"全局。例如，很大比例（也许是大多数）经纪商运单的费用是按单议价的，波动极大。这让定价成为非常难解的问题。如果行业更透明、数据共享更自由，会有太多事情成为可能。

#### **3. 人们把 ML 整合进物流时，常见错误是什么？**

我认为最常见的错误，是关起门来做 ML 和数据科学。

物流里的大多数 ML 应用一旦被使用，就会显著改变问题的动态。因此重要的是与业务一起迭代地开发模型，确保真实表现与训练预期一致。

一个例子是定价：如果你对某条线路报价稍低，价格可能过于有竞争力，导致该线路货量涌入。这反过来会推高成本，因为经纪商难以为这些货找到运力，使问题恶化。

#### **4. 关于 ML 的未来，最让你兴奋的是什么？**

最让我兴奋的，是 ML 有机会让人们工作得更好。

随着 ML 在商业中无处不在，它将帮助加快决策、自动化重复劳动。这会加速创新的步伐，创造巨大的经济价值。我迫不及待想看未来 10 年我们在数据科学与 ML 辅助下解决哪些问题！

#### **1. ML 给营销行业带来了哪些积极影响？**

太多了！它正在彻底改变格局。营销是一个植根于直觉与传统的领域。过去 20 年，营销决策越来越统计化，但很多品牌仍然依赖市场部门的直觉。ML 正在革命这一点。借助分析哪些广告表现好的数据，我们可以对"怎么营销、向谁营销"做出真正有依据的决策。

在 BEN，ML 帮我们省去了网红营销流程中大量的拍脑袋。数据像一束光照穿偏见与主观性的迷雾，让我们能做有依据的决策。

这还只是明面上的好处！ML 还在让品牌的营销决策更安全。例如，向 21 岁以下人群投放酒类广告是违法的。用机器学习，我们可以识别出受众主要为 21 岁以上的网红。这放大了我们服务酒类品牌、以及担心形象与酒关联的品牌的能力。

#### **2. 营销行业里最大的 ML 挑战是什么？**

和机器学习的多数事情一样，问题往往不在模型本身。有了 [Hugging Face](http://huggingface.co)、[torch hub](https://pytorch.org/docs/stable/hub.html) 这类工具，有那么多优秀且灵活的模型可用。

真正的挑战在于收集、清洗和管理数据。如果要谈这份工作中硬核的 ML 部分，有些难度在于：人们看什么、喜欢什么，噪声极大。理解"病毒式传播"之类的东西真的非常非常难。

理解是什么让创作者/网红长期成功也很难。大量奇怪的偏好信息，埋在相当嘈杂、难以获取的数据里。这些问题的解决，最终取决于数据、ML 和业务团队之间真正扎实的沟通，取决于构建与人协作增强、而非完全取代人的模型。

#### **3. 人们把 ML 整合进营销时，常见错误是什么？**

这不只是营销的毛病，但我经常看到一个大问题：重机器学习与数据科学、轻基础设施。组织听说 ML 好、想分一杯羹，于是招了几个数据科学家，随后发现根本没有基础设施来支撑他们时髦的新模型。ML 的大量价值在模型周边的基础设施里——有训练好的模型却没有基础设施，你就完蛋了。

BEN 的一点非常好：我们在数据基础设施上投入很重，先造马再造车。如今数据科学家构建的模型可以快速服务到终端用户，而不用自己折腾流水线的每一步。先投资数据工程，再招一大帮 ML 的人。

#### **4. 关于 ML 的未来，最让你兴奋的是什么？**

令人兴奋的事情太多了。我觉得最让我兴奋的，可能是这个领域的速度与民主化。我记得快 10 年前，我写了第一个用于语言翻译的 seq2seq 模型：几百行代码，训练花了天荒地老，相当艰难。现在基本上用不到 100 行 Python 就能搭出一套任意语言互译的系统。太疯狂了！这个趋势很可能会继续——随着 ML 基础设施越来越好，没有深厚领域功底的普通人也终将越来越容易部署和对外提供模型服务。

就像互联网初期一样：软件开发者凤毛麟角，建个网站需要一支精干的团队。后来有了 Django、Rails 这些，建网站变容易了，但"服务"仍很难。我们如今正处在类似的阶段：建模型容易了，但可靠地提供模型服务、可靠地监控它们，仍然是挑战。我认为未来几年，这里的门槛会大幅降低——基本上任何一个高中生都能把一个深度 transformer 部署到某个云基础设施上，开始给大众提供有用的结果。这真的令人兴奋，因为这意味着我们会看到越来越多看得见摸得着的创新，就像在线服务的爆发一样。太多酷的事情了！

#### **1. ML 给能源/公用事业行业带来了哪些积极影响？**

商业洞察的获得——前提是要有好数据。公用事业公司的数据组合里有很多数据关系：从客户到设备，更具体地说，比如每月账单金额、节能项目的参与情况。这类数据可以存在关系型数据库里；而设备或资产数据——构成电网的那些机器部件——则另当别论。把两类数据桥接起来并不轻松。

此外，第三方数据（空间/GIS 和气象）极其重要。透过机器学习的镜头，我们能够发现并探索那些真正有影响力的特征与结果。

#### **2. 公用事业行业里最大的 ML 挑战是什么？**

行业需要对 ML "祛魅"——机器学习能做什么、哪里需要盯着、哪里可能掉链子。公用事业行业有自己固定的运作方式，ML 会被视为搅局者。因此部门采纳任何新技术或新范式都很慢。不过，如果实践者能证明效果，结果会带来动能和更强的采纳意愿。其他挑战还有本地部署的数据、云与基础设施的访问权限。这是个渐进过程，有学习曲线，需要耐心。

#### **3. 人们把 ML 整合进公用事业时，常见错误是什么？**

不是公用事业独有的：走得太快，忽视数据质量和简单的质量检查。另外，机器学习如今以直接或间接的方式被很多团队使用，一个挑战是让最佳开发实践在各个团队之间拉通。这也意味着模型跟踪、实验留存和持续发现。
