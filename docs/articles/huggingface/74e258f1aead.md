# 在 Intel CPU 上微调 Stable Diffusion 模型

本文由 Julien Simon（juliensimon）撰写。

扩散模型凭借从文本提示生成逼真照片般图像的神奇能力，帮助生成式 AI 走向大众。这些模型如今已进入企业用例，如合成数据生成或内容创作。Hugging Face hub 上有超过 5,000 个预训练的文生图[模型](https://huggingface.co/models?pipeline_tag=text-to-image&sort=trending)。把它们和 [Diffusers 库](https://huggingface.co/docs/diffusers/index)结合起来，开始实验和构建图像生成工作流从未如此简单。

与 Transformer 模型一样，你可以微调扩散模型，让它们生成符合你业务需求的内容。最初，微调只能在 GPU 基础设施上进行，但情况正在改变！几个月前，Intel [发布](https://www.intel.com/content/www/us/en/newsroom/news/4th-gen-xeon-scalable-processors-max-series-cpus-gpus.html#gs.2d6cd7)了第四代 Xeon CPU，代号 Sapphire Rapids。Sapphire Rapids 引入了 Intel Advanced Matrix Extensions（AMX），一种面向深度学习工作负载的全新硬件加速器。我们已在多篇博客中展示了 AMX 的收益：[微调 NLP Transformers](https://huggingface.co/blog/intel-sapphire-rapids)、[NLP Transformers 推理](https://huggingface.co/blog/intel-sapphire-rapids-inference)，以及[Stable Diffusion 模型推理](https://huggingface.co/blog/stable-diffusion-inference-intel)。

本文将演示如何在一个 Intel Sapphire Rapids CPU 集群上微调 Stable Diffusion 模型。我们将使用[文本反演（textual inversion）](https://huggingface.co/docs/diffusers/training/text_inversion)技术，它只需要少量示例图像。我们只用五张！

开始吧。

## 搭建集群

我们的朋友 [Intel](https://huggingface.co/intel) 提供了四台托管在 [Intel Developer Cloud](https://www.intel.com/content/www/us/en/developer/tools/devcloud/services.html)（IDC）上的服务器。IDC 是一个服务平台，用于在 Intel® 优化的部署环境中开发和运行工作负载，配备最新 Intel 处理器和[性能优化的软件栈](https://www.intel.com/content/www/us/en/developer/topic-technology/artificial-intelligence/overview.html)。

```
cat << EOF > nodefile
```

分布式训练要求主节点与其他节点之间可以免密 `ssh`。如果你不熟悉这个过程，这里有一篇不错的[文章](https://www.redhat.com/sysadmin/passwordless-ssh)讲解如何操作。

接下来，我们在每个节点上创建新环境并安装软件依赖。我们特别安装两个 Intel 库：[oneCCL](https://github.com/oneapi-src/oneCCL) 用于管理分布式通信，以及 [Intel Extension for PyTorch](https://github.com/intel/intel-extension-for-pytorch)（IPEX）用于利用 Sapphire Rapids 的硬件加速特性。我们还添加 `gperftools` 以安装 `libtcmalloc`——一个高性能内存分配库。

```
conda create -n diffuser python==3.9
conda activate diffuser
pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu
pip3 install transformers accelerate==0.19.0
pip3 install oneccl_bind_pt -f https://developer.intel.com/ipex-whl-stable-cpu
pip3 install intel_extension_for_pytorch
conda install gperftools -c conda-forge -y
```

然后，我们在每个节点克隆 [diffusers](https://github.com/huggingface/diffusers/) 仓库并从源码安装。

```
git clone https://github.com/huggingface/diffusers.git
cd diffusers
pip install .
```

## 配置微调任务

[Accelerate](https://huggingface.co/docs/accelerate/index) 库让运行分布式训练变得非常容易。我们只需在每个节点上运行它并回答几个简单问题。

这是主节点上的截图。在其他节点上，你需要把 rank 设为 1、2 和 3。其他答案完全相同。

最后，我们需要在主节点上设置环境变量。微调任务启动时，它们会被传播到其他节点。第一行设置连接到所有节点所在本地网络的网络接口名称。你可能需要用 `ifconfig` 查到正确的信息并做调整。

```
export I_MPI_HYDRA_IFACE=ens786f1
oneccl_bindings_for_pytorch_path=$(python -c "from oneccl_bindings_for_pytorch import cwd; print(cwd)")
source $oneccl_bindings_for_pytorch_path/env/setvars.sh
export LD_PRELOAD=${LD_PRELOAD}:${CONDA_PREFIX}/lib/libiomp5.so
export LD_PRELOAD=${LD_PRELOAD}:${CONDA_PREFIX}/lib/libtcmalloc.so
export CCL_ATL_TRANSPORT=ofi
export CCL_WORKER_COUNT=1

export MODEL_NAME="runwayml/stable-diffusion-v1-5"
export DATA_DIR="/home/devcloud/dicoo"
```

现在可以启动微调任务了。

## 微调模型

我们用 `mpirun` 启动微调任务，它在 `nodefile` 列出的节点之间建立分布式通信。我们运行 16 个任务（`-n`），每个节点 4 个任务（`-ppn`）。`Accelerate` 会自动在所有任务间设置分布式训练。

这里我们训练 200 步，大约需要 5 分钟。

```
mpirun -f nodefile -n 16 -ppn 4                                                         \
accelerate launch diffusers/examples/textual_inversion/textual_inversion.py             \
--pretrained_model_name_or_path=$MODEL_NAME --train_data_dir=$DATA_DIR                  \
--learnable_property="object"   --placeholder_token="<dicoo>" --initializer_token="toy" \
--resolution=512  --train_batch_size=1  --seed=7  --gradient_accumulation_steps=1       \
--max_train_steps=200 --learning_rate=2.0e-03 --scale_lr --lr_scheduler="constant"     \
--lr_warmup_steps=0 --output_dir=./textual_inversion_output --mixed_precision bf16      \
--save_as_full_pipeline
```

## 排障

分布式训练可能很棘手，尤其当你刚接触这一领域时。最可能出现的问题是某个节点上的小配置错误：缺少依赖、图片存放在不同位置，等等。

你可以通过登录每个节点并本地训练快速定位问题节点。先设置与主节点相同的环境，然后运行：

```
python diffusers/examples/textual_inversion/textual_inversion.py                        \
--pretrained_model_name_or_path=$MODEL_NAME --train_data_dir=$DATA_DIR                  \
--learnable_property="object"   --placeholder_token="<dicoo>" --initializer_token="toy" \
--resolution=512  --train_batch_size=1  --seed=7  --gradient_accumulation_steps=1       \
--max_train_steps=200 --learning_rate=2.0e-03 --scale_lr --lr_scheduler="constant"     \
--lr_warmup_steps=0 --output_dir=./textual_inversion_output --mixed_precision bf16      \
--save_as_full_pipeline
```

如果训练成功启动，停止它并前往下一个节点。如果所有节点上训练都能成功启动，回到主节点，再次检查节点文件、环境和 `mpirun` 命令。别担心，你会找到问题的 :)

## 用微调后的模型生成图像

训练 5 分钟后，模型已保存在本地。我们可以用普通的 `diffusers` pipeline 加载并预测。这里我们改用 [Optimum Intel 与 OpenVINO](https://huggingface.co/docs/optimum/intel/inference) 对模型做优化。正如[上一篇博文](https://huggingface.co/blog/intel-sapphire-rapids-inference)所讨论的，这能让你在单个 CPU 上不到 5 秒就生成一张图像！

```
pip install optimum[openvino]
```

这里我们加载模型、针对静态形状做优化并保存：

```
from optimum.intel.openvino import OVStableDiffusionPipeline

model_id = "./textual_inversion_output"

ov_pipe = OVStableDiffusionPipeline.from_pretrained(model_id, export=True)
ov_pipe.reshape(batch_size=5, height=512, width=512, num_images_per_prompt=1)
ov_pipe.save_pretrained("./textual_inversion_output_ov")
```

然后加载优化后的模型，生成五张不同的图像并保存：

```
from optimum.intel.openvino import OVStableDiffusionPipeline

model_id = "./textual_inversion_output_ov"

ov_pipe = OVStableDiffusionPipeline.from_pretrained(model_id, num_inference_steps=20)
prompt = ["a yellow <dicoo> robot at the beach, high quality"]*5
images = ov_pipe(prompt).images
print(images)
for idx,img in enumerate(images):
    img.save(f"image{idx}.png")
```

这是一张生成的图像。模型只用了五张图就学会了 dicoo 戴眼镜，令人印象深刻！

如果你愿意，可以再对模型多做些微调。这是一个 3,000 步模型（约一小时训练）生成的漂亮示例。
