## 用模型自身的失败样本构造拒绝对（Rejection Pairs）

今年 4 月，我们发布了 DharmaOCR——我们的专用结构化 OCR 模型（[可在 Hugging Face 获取](https://huggingface.co/Dharma-AI/Dharma-OCR-LITE)），并附上详述其方法论的[论文](https://arxiv.org/abs/2604.14314)，以及一个证明其卓越质量与成本效率的基准。该论文在结构化文档提取任务——巴西葡萄牙语文本 OCR——上对领先的视觉-语言模型家族（开源与商业皆有）进行了基准评测。报告的指标中包括文本退化率（text degeneration rate）：模型产生重复循环而非转写结果的频率。

在被测试的各开源家族中，原始（vanilla）退化率从低于 1% 到高于 33% 不等。监督微调（SFT）降低了多数模型的退化率——但很少降到生产可接受的水平。这一模式指向一个结构性局限：SFT 为正确输出做优化，却不会明确惩罚退化。仅靠面向任务的微调，对这种失败模式的压制似乎存在天花板（[Text Degeneration Article](https://huggingface.co/blog/Dharma-AI/text-degeneration-a-production-failure-mode)）。

第二个训练阶段——在 SFT 之后、对同一批文档、使用同一个模型施加——在每一个被测试的模型家族中都降低了文本退化。无一例外。平均降幅：59.4%。最好情形：87.6%。

[![image](https://cdn-uploads.huggingface.co/production/uploads/69d815b52c6db28cfdfdd422/o-TBg6d-3_PbbSouY5tGM.png)](https://cdn-uploads.huggingface.co/production/uploads/69d815b52c6db28cfdfdd422/o-TBg6d-3_PbbSouY5tGM.png) `图 1：相对 SFT，DPO 在每个被测试的家族中都降低了退化——平均降幅 59.4%，峰值 87.6%（Nanonets-OCR2–3B：1.61% 降至 0.20%）。方向是不变的；变化的只有幅度。`

这第二个阶段就是直接偏好优化（Direct Preference Optimization，DPO）。几乎所有已发表的 DPO 应用都瞄准聊天对齐——即基于人类对有用性或无害性的判断来训练的模型（例如：Rafailov et al., 2023）。OCR 不带有那种主观性：任务是客观的，也没有对话上下文。不过，那里有一个清晰的偏好信号。正确的转写被选中；退化的循环被拒绝。DharmaOCR 利用这个二元性构造了一个 DPO 训练集，检验这一技术不是用于对齐，而是作为针对某一特定失败模式的直接缓解工具。

训练信号来自模型本身——确切说来自它失败时产生的输出。一个失败模式如何变成训练信号，是关于失败本身的结构问题，而不是关于模型的问题。

### 循环在微调后依然存在

为什么 SFT 对退化存在天花板仍是开放问题——但主流的猜想指向损失粒度。SFT 逐 token 训练：每个预测都被孤立地评估，重复循环从来不会被作为「完整输出层面」的失败来惩罚。DPO 反转了这一逻辑。训练信号是完整的输出——选中的或被拒绝的——这意味着一个退化的补全可以被明确标记为错误结果，而不只是一串局部概率上说得通的 token。

当训练目标最大化已有序列的似然时，它会把概率质量集中到这些序列所占据的分布空间的区域。一个在推理时进入某个高概率「吸引子」区域的模型，会给下一步的同一个 token 赋予更高的概率——而这又进一步提高该概率，使循环一直持续到序列触到最大 token 上限。文本退化就是这种几何结构的产物：一个自增强的重复循环，自回归模型若无外部干预便走不出来（Holtzman et al., 2020）。它纯粹不是一个解码产物。这个吸引子牵涉训练目标、学到的分布，以及推理期间概率质量如何集中——是系统层面的失败，而非局限在某个单一组件上的失败。

这种失败的几何在 token 层面清晰可见。

[![image](https://cdn-uploads.huggingface.co/production/uploads/69d815b52c6db28cfdfdd422/kJIgJGSsa8HJqLNkm4Ho8.png)](https://cdn-uploads.huggingface.co/production/uploads/69d815b52c6db28cfdfdd422/kJIgJGSsa8HJqLNkm4Ho8.png) `图 2：当一个 token 主导了自己的条件分布，每一步采样都会加深这个吸引子。解码器是从这种几何中采样；但它并不决定这种几何。`

推理层的干预——repetition penalty、温度调整、提前中止逻辑——作用于采样这一步。它们只是围住症状，却不触碰产生症状的分布。吸引子依然存在。

监督微调把分布推向任务领域。对结构化生成流水线来说，这意味着在领域文档、目标语言、所需输出格式上训练。模型获得了对更长序列、受约束语法、领域词汇的流畅把握。SFT 不做的事，是直接攻击退化。它的目标——最大化已有序列的似然——没有任何一项会惩罚重复循环。这个失败模式根本不在训练信号所优化的范围之内。

DharmaOCR 基准中有一个模型家族呈现了意外的模式：原始退化率为 0.60%，SFT 后升至 3.23%，随后 DPO 阶段又把它带回 1.41%。这只是一个数据点——是例外，不是规律——把它当作机制的证明是过度解读证据。它确实说明的一点是：SFT 并不能可靠地降低退化。任务能力与抗退化性可以各自独立地变化。

这种区分在结构上很重要。SFT 和 DPO 不是同一操作在不同强度下的可互换训练阶段。SFT 缩小的是模型先验分布与任务领域之间的距离。它不做的事，是把退化作为优化目标——它对失败模式的影响是附带的，而基准结果显示这种影响并不稳定。产生退化的那个吸引子，不是模型离任务远近的问题——而是模型现在所处的分布空间的形状问题。

要处理这种几何，需要一个专门构造来把模型引离其自身失败模式的训练信号。对一个没有人工偏好标注、没有传统「有用对有害」之分的结构化非对话任务来说，构造这样的信号是一个设计决策。

### 设计决策：把退化输出用作拒绝对

DharmaOCR 流水线对 DPO 方法论的贡献是具体的：它把 SFT 模型自身的退化输出用作被拒绝的样本——不是当作要清除的噪声，而是当作优化所需要的负训练信号。

DPO 需要偏好对：同一输入下的一个选中输出和一个拒绝输出，且二者质量差异要大到足以让优化从中学习。在聊天对齐中，这些判断由人类标注者产生——给回复在有用、准确或安全程度上打分。结构化生成任务没有对等的标注来源。OCR 流水线要么产出正确的转写，要么不产出。质量差异是存在的，但它们不是由人类偏好排序产生的——它们由任务自身的正确性标准产生。

DharmaOCR 流水线识别出结构化生成任务本来就在产生的偏好信号：即 SFT 模型在推理中生成的输出范围。一个有能力执行结构化任务的模型，同样有能力以特征性的方式失败。那些失败——进入退化吸引子的输出——不是要过滤掉的噪声，而是可获得的信息量最大的负信号。

论文在 23,726 份训练文档上实现了这一点：用 SFT 模型为每份文档生成多个候选回复，并用一个自动化的 LLM 评审为每个回复打分。流水线如下图所示。

[![image](https://cdn-uploads.huggingface.co/production/uploads/69d815b52c6db28cfdfdd422/o6z7skgMtLq22aFGkeYvw.png)](https://cdn-uploads.huggingface.co/production/uploads/69d815b52c6db28cfdfdd422/o6z7skgMtLq22aFGkeYvw.png) `图 3：关键的设计决策不在流水线的结构——而在流水线保留了什么：出现文本退化的输出被刻意标记为拒绝样本，而不是作为低质量噪声被过滤掉。`

当训练数据中出现退化输出时，惯常的处理是删除它们。它们是低质量信号；过滤得到更干净的数据集。DharmaOCR 的做法反转了这一逻辑。退化输出被刻意保留为每个 (chosen, rejected) 对里的拒绝样本，因为它们正是 DPO 阶段设计要压制的那个失败模式。删掉它们等于扔掉最清晰可用的靶子。

论文把这种做法描述为「偏好引导的隐式反似然（preference-guided implicit unlikelihood）」——模型不仅被训练向更好的输出，还被训练远离一类特定的失败。SFT 最大化高质量输出的似然，而 DPO 阶段同时对展示退化吸引子几何的输出施加惩罚。优化的方向是显式的，这是单独的 SFT 做不到的。

退化输出作为拒绝样本特别合适，因为它们代表的是一致性的失败模式，而不是各种各样的低质量输出。漏词的转写是低质量的，但其失败是逐例各异的。相比之下，重复循环即使在 SFT 之后仍然持续出现在不同文档和不同模型家族中——这种模式与「基于似然的优化无法可靠纠正的失败模式」相一致。DPO 施加损失的方式不同：在补全层面，带着显式的拒绝信号。事后分析无法确立因果关系，但证据表明：SFT 目标留下的未解问题，DPO 的目标或许能够解决。

这种方法不需要专门的标注基础设施——只需要一个既能产出可接受输出、又能产出可识别失败输出的模型，以及一个为偏好对打标签的打分模型。基于规则的机制可以在机械层面检测重复循环——但它无法判断哪些输出是值得保留为选中样本的高质量转写。

打分模型两件事都做：它把退化标记为拒绝输出，把干净的提取验证为选中输出；在 DPO 信号惩罚失败模式的同时，保持模型的提取能力完好。由此得到的训练信号能否成功地把分布推向预期方向——以及它是否能在各架构之间保持一致——这是证据层面的问题。

### 五个模型家族上的一致结果

DPO 阶段在每一个被测试的模型家族中都降低了文本退化——相对仅 SFT，降幅从 37% 到 88% 不等，平均 59.4%。这一结果跨越了架构、参数规模，以及相差超过一个数量级的起始退化画像。数据集中有一个案例在 SFT 阶段后退化率上升，随后被 DPO 修正。这个案例并不破坏一致性。它比其他任何案例都更直接地证实了机制。

图 1 展示了五个被测试模型家族各自的三阶段退化率：Vanilla、SFT、SFT+DPO。五个家族中有四个在每一阶段退化都在下降。第五个家族的柱状图走势不同——而这个差异正是整个研究中分析上最重要的数据点。

Qwen2.5-VL-3B 的结果，仔细读来，不是麻烦而是确认。该模型的原始退化率是 0.60%——不是因为它稳定，而是因为它太泛化，根本无法生成长结构化输出。它之所以没有进入退化吸引子，是因为它尝试任务的认真程度还不足以「找到」吸引子。

SFT 改变了这一点。经过领域适配后，Qwen2.5-VL-3B 变得有能力完成该任务——能按流水线要求产出更长、更结构化的输出，带领域词汇和格式。这种能力使它第一次接近了退化吸引子。它的退化率升至 3.23%。

这就是机制被实证地看见了：SFT 同时把模型推向任务和任务的失败几何。这两者未必是同一件事。一个提升任务能力的训练阶段，可能作为副作用增加暴露于失败模式的机会——尤其当失败模式就坐在能力前沿的边缘时。如果把两者当成同一件事，Qwen2.5-VL-3B 的结果看起来像错误；把它们当作不同的操作——这正是 SFT + DPO 流水线在形式上所做的——结果与「SFT 和 DPO 处理不同失败维度」的假设一致。

随后 DPO 阶段把退化率带到 1.41%。它没有把退化恢复到原始基线，因为它本来就不是为此设计的：经过 SFT 的模型比原来更能干了，要回到 0.60% 就得撤销那种能力。DPO 阶段做的事，是处理 SFT 阶段引入的失败几何。

其余四个模型家族为同一结论增添了定量分量。图 1 展示了全部五个家族的 SFT 与 SFT+DPO 对比。

[![image](https://cdn-uploads.huggingface.co/production/uploads/69d815b52c6db28cfdfdd422/zhNY8YL4WieHlJ1JV0Rd-.png)](https://cdn-uploads.huggingface.co/production/uploads/69d815b52c6db28cfdfdd422/zhNY8YL4WieHlJ1JV0Rd-.png) `图 1：相对 SFT，DPO 在每个被测试的家族中都降低了退化——平均降幅 59.4%，峰值 87.6%（Nanonets-OCR2–3B：1.61% 降至 0.20%）。方向是不变的；变化的只有幅度。`

没有任何模型家族在 DPO 后出现退化上升，也没有任何家族对其效果免疫。这种一致性甚至延伸到 gemma-3–4b-it：它以高出其他家族一个数量级的 33.96% 原始退化率进入基准（次高者为 2.62%），在 DPO 阶段后仍实现了 75% 的降幅。37.3% 到 87.6% 的降幅区间反映的是起始配置与架构的差异，而非干预方向上的不一致。

这不是普适适用性的证明。DPO 未必能迁移到每个领域、每种失败模式、每个模型家族。DharmaOCR 基准提供的是跨五种 OCR 架构的证据，证明核心假设成立：在完整偏好对上做优化——而非最大化 token 级似然——处理的是 SFT 在结构上无法瞄准的失败模式。结果在每一个被测试的模型家族上方向一致。在这一基准的范围之内，这种一致性正是证据所支持的内容。

### OCR 之外的模式

DharmaOCR 的做法之所以可行，是因为这条流水线满足了一组结构性条件，使得 DPO 训练阶段能按设计发挥作用——这些条件是否存在，决定了同一方法论是否适用于其他场景（[Dharma OCR 论文（arXiv）](https://arxiv.org/abs/2604.14314)）。而不是因为 OCR 是什么独特的领域。

第一个条件是：失败模式必须可被识别为一类独立的输出，而不只是质量连续谱上的一个点。文本退化符合这一条件，因为重复循环与「漏词或读错字符的转写」在类别上截然不同。输出不只是次优——它以特定的、行为上可识别的方式坏掉了。正是这种类别上的可区分性，让流水线得以构造出「拒绝样本代表连贯失败几何而非噪声」的偏好对。一个失败模式与其可接受变化范围混在一起的任务，不具备这一性质。

第二个条件是：存在某种打分机制，能在不依赖人工标注的前提下可靠地区分可接受输出与失败模式输出。在 DharmaOCR 流水线中，一个自动化 LLM 评审按四项任务特定标准为候选回复打分。打分不需要完美——只需要足够一致，使产出的偏好对在选中与拒绝之间有有意义的质量差距。质量差异含糊的对，给 DPO 训练贡献的是噪声而不是信号。评审的一致性是一项设计要求，不是附带特性。

第三个条件是足够的量——有足够的推理输出，能生成在质量上有有意义方差的偏好数据集。按微调标准这算不上苛刻的要求，但它确实存在。

当这三个条件同时具备，这种方法论操作在结构上就可用。DharmaOCR 流水线的核心设计决策——把模型自身的失败输出当作拒绝样本而不是过滤掉——适用于一切「模型失败在类别上可识别、可打分且数量足够」的场合。

对构建结构化生成流水线的 ML 工程师来说，实践含义是直接的。SFT 是必要的——它拉近了通才模型与任务可用模型的距离。但对结构化输出的可靠性而言它并不充分，因为任务能力和抗退化性是分属分布的不同属性。SFT 之后加一个 DPO 阶段是一次性的训练投入。在 DharmaOCR 的结果中，退化降低并未以提取质量为代价——论文的基准结果显示二者同步向好（[Specialization Beats Scale 文章](https://huggingface.co/blog/Dharma-AI/specialization-beats-scale)）。

让一种失败模式堪用为训练信号的，不是领域——而是失败是否足够一致、足够可识别、数量足够多，从而构成清晰的信号。在 DharmaOCR 流水线中它们做到了。同样的性质在其他场景是否成立，是一个关于任务失败模式的结构问题，而不是关于模型家族或领域的问题。

DharmaOCR 的结果不依赖领域的特殊性，而依赖失败是否有用。

文本退化之所以「有用」，是因为它在类别上与可接受输出截然不同、在多次推理中持续产生、并且无需人工标注即可可靠打分。是这三个属性——不是 OCR 背景、不是模型家族、不是语言——决定了偏好数据集是否可构建。一个满足这三条的失败模式不是要清除的噪声。它是关于「分布不应走向哪里」的最直接的可用证据。

DPO 阶段利用了这一证据。在每一个被测试的模型家族中退化都下降了——包括以低于 1% 原始退化率进入基准的模型，也包括以高于 33% 退化率进入的模型。方向保持了。这条流水线没有丢弃自己的失败。它用失败来训练。
