## Cohere 模型

Cohere 和 Cohere Labs 把一批在特定业务应用上表现出色的模型带进了 Inference Providers。我们详细看看其中几个。

### CohereLabs/c4ai-command-a-03-2025 [🔗](https://huggingface.co/CohereLabs/c4ai-command-a-03-2025)

为要求快速、安全、高质量 AI 的高要求企业优化。256k 上下文长度（多数前沿模型的 2 倍）能处理长得多的企业文档。其他关键特性包括 Cohere 先进的、带可验证引用的检索增强生成（RAG）、智能体工具调用、企业级安全，以及强劲的多语言表现（支持 23 种语言）。

### CohereLabs/aya-expanse-32b [🔗](https://huggingface.co/CohereLabs/aya-expanse-32b)

专注于最先进的多语言支持，应用了多语言预训练的最新研究。支持阿拉伯语、中文（简体与繁体）、捷克语、荷兰语、英语、法语、德语、希腊语、希伯来语、印地语、印尼语、意大利语、日语、韩语、波斯语、波兰语、葡萄牙语、罗马尼亚语、俄语、西班牙语、土耳其语、乌克兰语和越南语，上下文长度 128K。

### CohereLabs/c4ai-command-r7b-12-2024 [🔗](https://huggingface.co/CohereLabs/c4ai-command-r7b-12-2024)

适合低成本或低延迟场景，在其所在的开放权重模型级别中为真实任务带来一流性能。该模型提供 128k 上下文长度，将多语言支持、带引用核验的检索增强生成（RAG）、推理、工具调用与智能体行为强力组合在一起。同样支持 23 种语言。

### CohereLabs/aya-vision-32b [🔗](https://huggingface.co/CohereLabs/aya-vision-32b)

拥有先进能力的 320 亿参数模型，面向多种视觉-语言用例优化，包括 OCR、图像描述、视觉推理、摘要、问答、代码等。它把多模态能力扩展到 23 种语言——覆盖全球一半以上人口使用的语言。

### 通过客户端 SDK

我们走一遍用客户端 SDK 调用 Cohere 模型。我们还准备了一个包含这些片段的 [colab notebook](https://colab.research.google.com/drive/1xxpiB9on_DhZdCpro-f3T07Pd-BfIssz?usp=sharing)，想马上试用可以直接打开。

#### 用 Python 和 huggingface_hub

下面的示例展示如何使用 Cohere 作为推理提供商调用 Command A。你可以用 [Hugging Face token](https://huggingface.co/settings/tokens)经由 Hugging Face 自动路由，也可以直接使用你自己的 cohere API key（如果你有）。

安装 `huggingface_hub` v0.30.0 或更新版本：

```
pip install -U "huggingface_hub>=0.30.0"
```

通过设置 `provider` 参数，用 `huggingface_hub` Python 库调用 Cohere 端点。

```
from huggingface_hub import InferenceClient

client = InferenceClient(
    provider="cohere",
    api_key="xxxxxxxxxxxxxxxxxxxxxxxx",
)

messages = [
        {
            "role": "user",
            "content": "How to make extremely spicy Mayonnaise?"
        }
]

completion = client.chat.completions.create(
    model="CohereLabs/c4ai-command-r7b-12-2024",
    messages=messages,
    temperature=0.7,
    max_tokens=512,
)

print(completion.choices[0].message)
```

Cohere Labs 的多语言多模态模型 Aya Vision 也受支持。可以按下面的方式携带 base64 编码的图像：

```
image_path = "img.jpg"
with open(image_path, "rb") as f:
    base64_image = base64.b64encode(f.read()).decode("utf-8")
image_url = f"data:image/jpeg;base64,{base64_image}"

from huggingface_hub import InferenceClient

client = InferenceClient(
    provider="cohere",
    api_key="xxxxxxxxxxxxxxxxxxxxxxxx",
)

messages = [
        {
            "role": "user",
            "content": [
                {
                    "type": "text",
                    "text": "What's in this image?"
                },
                {
                    "type": "image_url",
                    "image_url": {"url": image_url},
                },
            ]
        }
]

completion = client.chat.completions.create(
    model="CohereLabs/aya-vision-32b",
    messages=messages,
    temperature=0.7,
    max_tokens=512,
)

print(completion.choices[0].message)
```

#### 用 JS 和 @huggingface/inference

const client = new HfInference("xxxxxxxxxxxxxxxxxxxxxxxx");

const chatCompletion = await client.chatCompletion({

## Cohere 模型的工具调用

Cohere 的模型把最先进的智能体工具调用带进了 Inference Providers，我们详细看看。Hugging Face Hub 客户端和 OpenAI 客户端都能经由推理提供商使用工具，所以上面的示例可以继续扩展。

首先，我们要为模型定义可用的工具。下面定义了 `get_flight_info`——用两个地点调用查询最新航班信息的 API。这个工具定义会经由模型的聊天模板来呈现。模板也可以在 [model card](https://huggingface.co/CohereLabs/c4ai-command-a-03-2025?chat_template=default) 中查看（🎉 开源）。

```
tools = [
    {
        "type": "function",
        "function": {
            "name": "get_flight_info",
            "description": "Get flight information between two cities or airports",
            "parameters": {
                "type": "object",
                "properties": {
                    "loc_origin": {
                        "type": "string",
                        "description": "The departure airport, e.g. MIA",
                    },
                    "loc_destination": {
                        "type": "string",
                        "description": "The destination airport, e.g. NYC",
                    },
                },
                "required": ["loc_origin", "loc_destination"],
            },
        },
    }
]
```

接下来，我们需要把消息传给推理客户端，让模型在相关时使用工具。下面的例子里，为清楚起见，我们把助手的工具调用直接写进 `tool_calls`。

```
messages = [
    {"role": "developer", "content": "Today is April 30th"},
    {
        "role": "user",
        "content": "When is the next flight from Miami to Seattle?",
    },
    {
        "role": "assistant",
        "tool_calls": [
            {
                "function": {
                    "arguments": '{ "loc_destination": "Seattle", "loc_origin": "Miami" }',
                    "name": "get_flight_info",
                },
                "id": "get_flight_info0",
                "type": "function",
            }
        ],
    },
    {
        "role": "tool",
        "name": "get_flight_info",
        "tool_call_id": "get_flight_info0",
        "content": "Miami to Seattle, May 1st, 10 AM.",
    },
]
```

最后，把 tools 和 messages 一起传给 create 方法。

```
from huggingface_hub import InferenceClient

client = InferenceClient(
    provider="cohere",
    api_key="xxxxxxxxxxxxxxxxxxxxxxxx",
)

completion = client.chat.completions.create(
    model="CohereLabs/c4ai-command-r7b-12-2024",
    messages=messages,
    tools=tools,
    temperature=0.7,
    max_tokens=512,
)

print(completion.choices[0].message)
```
