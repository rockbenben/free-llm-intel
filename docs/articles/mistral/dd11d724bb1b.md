我们发布 *Mistral Large*，我们最新、最先进的语言模型。*Mistral Large* 可通过 la Plateforme 使用。我们还通过我们的首个分销合作伙伴 Azure 提供它。

### Mistral Large，我们的新旗舰模型

Mistral Large 是我们尖端的文本生成模型。它达到了顶级的推理能力。它可以用于复杂的多语言推理任务，包括文本理解、转换和代码生成。

Mistral Large 在常用基准上取得强劲结果，使其成为通过 API 普遍可用的全球第二大模型（仅次于 GPT-4）[基准细节见下文]。

![Detailed benchmarks](https://mistral.ai/_astro/34d0ddd2-1cea-4573-b780-a2ecd9255e14_1PleEi.webp?dpl=6abbd11780b53c00082eea6f)

图 1：GPT-4、Mistral Large（预训练）、Claude 2、Gemini Pro 1.0、GPT 3.5 和 LLaMA 2 70B 在 MMLU（大规模多任务语言理解）上的对比。

Mistral Large 带来新能力与新优势：

- 它**原生精通英语、法语、西班牙语、德语和意大利语**，对语法和文化语境有细腻的理解。
- 其 **32K token 上下文窗口**可以从长文档中精确回忆信息。
- 其**精确的指令遵循**让开发者能够设计自己的**审核策略**——我们用 le Chat 建立了系统级审核。
- **它原生具备函数调用能力。**这一点与在 la Plateforme 上实现的约束输出模式相结合，能够支撑大规模的应用开发和技术栈现代化。

### 与 Microsoft 合作，在 Azure 上提供我们的模型

在 Mistral，我们的使命是让前沿 AI 无处不在。这就是我们今天宣布把我们的开放模型和商业模型带上 Azure 的原因。Microsoft 对我们模型的信任是我们征程上的前进一大步！我们的模型现在可以通过以下渠道使用：

- **La Plateforme**：安全托管于 Mistral 在欧洲的基础设施，这一入口让开发者能够围绕我们完整的模型矩阵创建应用与服务。
- **Azure：**Mistral Large 已上线 [Azure AI Studio 和 Azure Machine Learning](https://techcommunity.microsoft.com/t5/ai-machine-learning-blog/mistal-large-mistral-ai-s-flagship-llm-debuts-on-azure-ai-models/ba-p/4066996)，带来与我们 API 同样流畅的用户体验。Beta 客户已[非常成功](https://mistral.ai/business/)地使用了它。
- **自托管**：对于最敏感的用例，我们的模型可以带着模型权重部署在你的环境中；阅读这类部署的成功案例，并[联系我们的团队](https://mistral.ai/contact/)获取更多细节。

### 新的 Mistral Small，为低延迟负载优化

与 Mistral Large 一同，我们还发布一个新的优化模型 Mistral Small，为延迟和成本而优化。Mistral Small 超越 Mixtral 8x7B 且延迟更低，是介于我们开放权重产品与旗舰模型之间的精致中间方案。

Mistral Small 在 RAG 使能与函数调用方面享有与 Mistral Large 同样的创新。

我们正在简化端点产品，提供：

- 定价有竞争力的开放权重端点。包括 `open-mistral-7B` 和 `open-mixtral-8x7b`。
- 新的优化模型端点 `mistral-small-2402` 和 `mistral-large-2402`。我们继续维护 `mistral-medium`，今天不更新它。

我们的[基准](https://docs.mistral.ai/platform/endpoints/)给出了性能/成本权衡的全景。

除新的模型产品外，我们还为组织管理提供了多币种定价，并更新了 la Plateforme 的服务层级。我们在降低所有端点延迟方面也取得了很大进展。

### JSON 格式与函数调用

JSON 格式模式强制语言模型的输出为合法 JSON。这一功能让开发者以更自然的方式与我们的模型交互，以结构化的格式抽取信息，便于在流水线的后续环节直接使用。

函数调用让开发者把 Mistral 端点与他们自己的一组工具对接，从而与内部代码、API 或数据库进行更复杂的交互。详见我们的[函数调用指南](https://docs.mistral.ai/guides/function-calling)。

函数调用和 JSON 格式目前仅在 mistral-small 和 mistral-large 上可用。我们很快会为所有端点添加格式化能力，并支持更细粒度的格式定义。
