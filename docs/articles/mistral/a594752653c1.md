思考

摘要

Shieldstral 是一个 3B 开放权重的多模态安全分类器，它把内容审核重构为政策自适应的问答任务，性能超越体量达其 7 倍的模型。与传统护栏模型不同，它在推理时接受自然语言政策，无需重训即可统一文本与图像的安全评估。它以 Apache 2.0 发布，在多样基准上交付校准的安全分数，同时能在单块 16GB NVIDIA GPU 上高效运行。

**一个 3B 开放权重、政策自适应的多模态安全分类器——在文本安全上匹敌体量达其 7 倍的模型，并在多模态审核上树立新的最先进水平。**

"这段内容是否宣扬针对受保护群体的暴力？这张图片是否适合向未成年人展示？助手是否拒绝了该请求？"

每个上线模型的产品都要回答这类问题——但正确答案取决于产品、受众和时机。同样的内容，对网络安全研究工具可能没问题，在心理健康平台上却可能有害。多数护栏模型把一套固定的危害类别体系烘焙进了权重，要重新对准新的部署语境就得重训。而且安全定义因应用和领域而异，本来就找不到一套唯一"正确"的类别体系。

Shieldstral 另辟蹊径：你在推理时用自然语言把政策写成一个问题，模型返回一个校准的安全分数。无需重训，文本和图像共用一套接口，单个 token 即出判决。请参阅我们的[技术报告](https://arxiv.org/abs/2607.25857)。

作为与 NVIDIA 等机构共同发起 [Open Secure AI Alliance](https://blogs.nvidia.com/blog/open-secure-ai-alliance/) 的首批成员，今天我们以 Apache 2.0 开放权重发布 **Shieldstral**，可从[此处](https://huggingface.co/mistralai/Shieldstral-1.0-3B)下载。

## 把审核变成一个问题

Shieldstral 将内容审核构建为一个**二元问答任务**。每个请求包含三部分：

- `<Instruct>` —— 评估语境、严格程度，以及（可选）对"什么算不安全内容"的定义。
- `<Query>` —— 一个是/否问题，例如*"这段内容是否宣扬暴力？"*
- `<Document>` —— 待判断的内容：一条 prompt、一条 response、一对 prompt–response，或一张图加可选文本。

推理时，模型只读取 `yes` 和 `no` 的 logits，并用 softmax 归一化为连续的安全分数。这一个简单公式做了大量工作：它把 prompt 分类、response 审核、拒绝检测、毒性检测统一为同一问题；它让政策完全活在 prompt 里，于是一个 checkpoint 就能在部署时适配全新的政策。

## 亮点

- **强劲性能** —— 在文本安全、拒绝检测、政策适应性和多模态基准上，匹敌或超越体量达其 7 倍的开放护栏模型。
- **自适应、灵活** —— 单一自然语言接口覆盖文本、图像、文本+图像内容，横跨 prompt、response 和 prompt–response 对。政策以自由形式查询提供，可在推理时重新对准，无需重训。
- **小身材，异构数据训练** —— 3B 模型可在单块 16GB GPU 上运行；用真实与合成数据训练，涵盖多样的标签格式与类别体系，整合进同一框架。
- **连续安全分数** —— 单次前向传播返回校准的 `yes`/`no` 概率，你可以按置信度设阈值或排序，而不必依赖离散标签。
- **开放** —— Apache 2.0 权重。

## 基准测试

我们在四个维度上将 Shieldstral 与体量达其 7 倍的开放护栏模型对比评估。所有评估样本均未参与训练。

## 我们如何打造它

核心思想是：数据对了，小模型就能打败大得多的模型。把数据做对，意味着解决四个问题：

**统一异构数据。**公开安全数据集在类别、标签和标注惯例上互不一致——从二值 safe/unsafe 标记到细粒度多标签体系。我们用逐数据集的处理器把每个数据集转换为相同的 instruction–query–document 格式，并变换 instruction、query 和 prompt–response 分隔符的措辞，使模型跨措辞泛化而不是过拟合某一种风格。我们还按来源校准严格度——对对抗性越狱用严格标准，对 response 质量数据用宽松标准——让模型学到*校准的*决策边界。这让我们能整合原本互不兼容的数据源。

**教会辨别，而非记忆。**如果在固定的政策标签集上训练，模型只会分类那些预定义政策，而不是针对给定政策的精确边界进行推理，这就阻碍了向新政策的泛化。我们转而构造一组组刻意相似、易混淆的政策，并让 LLM 把安全文本改写为对比对：每次改写都设计为恰好违反其中一条政策而不触碰其"兄弟"政策。这训练模型去*辨别内容具体违反了哪条政策*——这项技能会在推理时迁移到未见的、用户自定义的政策上。

**让安全扎根于图像。**不安全图像无法像文本那样由 LLM 合成，视觉安全数据稀缺。我们用通用图像数据集作为高质量负例来补充有限的审核数据，变换 query 以扩充数据集，并用视觉-语言重排器过滤每一对 image–query，以减少错标数据和幻觉。

**合并互补的 checkpoint。**我们用 LoRA 微调，并通过 SLERP 合并三个模型：一个在公开数据上校准过的 checkpoint、一个用生成数据补上细粒度政策辨别力的 checkpoint，以及基座 instruct 模型。合并后的单一模型同时恢复了常见政策校准和政策适应力，而基座模型的指令遵循能力也迁移到了审核任务上。

**Forge**。Shieldstral 从端到端都在 [Forge](https://mistral.ai/products/forge/)——我们的定制模型训练、对齐与评估平台——上构建。Forge 在最先进的分布式训练之上管理了基础设施、数据与模型分片、指标和日志，让团队能专注于真正决定安全模型质量的数据。

## 下一步

Shieldstral 是迈向"适配语境而非把所有产品塞进一套冻结类别体系"的审核的一步。我们将继续推进多语言覆盖、长文档稳健性和更广的多模态安全——也很想看到社区在其上构建出什么。
