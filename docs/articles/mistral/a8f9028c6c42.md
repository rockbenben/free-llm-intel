这条消息本来可以只发一条推文，但……在过去几周里，AI 开发者社区接连面对若干次 API 涨价，而我们一直在努力确保继续以可负担的价格把前沿 AI 带给大家。为此，我们推出 batch API，即日起在 [La Plateforme](https://console.mistral.ai/) 上可用。

batch API 提供了一种更高效的方式来批量处理发往 Mistral 模型的高流量请求，成本比同步 API 调用低 50%。如果你构建的 AI 应用更看重数据吞吐量而非同步响应，batch API 会是理想的解决方案。你只需上传批处理文件，待请求处理完成后下载并使用输出文件。详细说明请查阅我们的 [batch API 文档](https://docs.mistral.ai/capabilities/batch/)。

batch API 的常见应用场景包括客户反馈与情感分析、批量文档摘要与翻译、为构建搜索索引准备向量嵌入，以及数据标注。

batch API 对 la Plateforme 上托管的所有模型均可用，并将在近期登陆我们的云服务商合作伙伴。使用速率限制为每个工作区 100 万个进行中请求。
