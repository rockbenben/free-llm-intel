今天，我们推出 Devstral Medium，并对 Devstral Small 进行升级。这些模型由 Mistral AI 与 [All Hands AI](https://www.all-hands.dev/) 合作发布 🙌，特别强调对不同提示词和 agentic 脚手架（scaffold）的泛化能力。

全新的 Devstral Small 1.1 以 Apache 2.0 许可证发布，在面向代码 agent 的开放模型中处于最先进水平。Devstral Medium 通过我们的 API 提供，在成本/性能的帕累托前沿上确立了新的坐标，以四分之一的价格超越 Gemini 2.5 Pro 和 GPT 4.1。

## Devstral Small 1.1

与上一版 Devstral Small 一样，我们把 Devstral Small 1.1 以 Apache 2.0 许可证发布。架构保持不变，仅有 24B 参数，但 Devstral Small 1.1 相对前代有显著提升：

### 性能增强

Devstral Small 1.1 在 SWE-Bench Verified 上取得 53.6% 的分数，在不使用测试时扩展（test-time scaling）的开放模型中创下新纪录。

### 通用性与泛化

Devstral Small 1.1 与 OpenHands 配合使用时表现出色，并在不同提示词和编码环境中展现出更好的泛化能力。它同时支持 Mistral 函数调用格式和 XML 格式，通用性进一步增强，可适配广泛的应用和 agentic 脚手架。

![Devstral Oss.001 (1)](https://mistral.ai/_astro/a8227ebf-fba7-4ad7-9d6b-83ce5da42a3e_Z1yAyas.webp?dpl=6abbd11780b53c00082eea6f)

## Devstral Medium

Devstral Medium 继承了 Devstral Small 的优势，将性能提升到新高度，在 SWE-Bench Verified 上取得 61.6% 的分数。Devstral Medium 通过我们的公开 API 提供，以有竞争力的价格点带来卓越性能，是寻求高质量、高性价比模型的企业和开发者的理想选择。

对于偏好本地部署的用户，Devstral Medium 可以直接部署在私有基础设施上，提供更强的数据隐私与控制。我们还支持对 Devstral Medium 的定制微调，让企业针对特定用例定制模型，达成贴合自身需求的最优性能。

![Devstral Main Graph](https://mistral.ai/_astro/ae27ff96-c7b6-4a6b-a3a1-0e02e156198a_iY90N.webp?dpl=6abbd11780b53c00082eea6f)

## 可用性

两个模型均可通过我们的 API 使用，名称如下：

- devstral-small-2507，价格与 Mistral Small 3.1 相同：每百万输入 token $0.1，每百万输出 token $0.3。
- devstral-medium-2507，价格与 Mistral Medium 3 相同：每百万输入 token $0.4，每百万输出 token $2。

我们把 Devstral Small 1.1 以 Apache 2.0 许可证发布，供社区在其上构建、定制并加速自主软件开发。想亲自试用，请前往我们的[模型卡](https://huggingface.co/mistralai/Devstral-Small-2507)。

Devstral Medium 还将上线面向企业客户的 [Mistral Code](https://mistral.ai/news/mistral-code)，并支持我们的[微调 API](https://docs.mistral.ai/guides/finetuning/)。如要在你的环境中部署和定制该模型，请[联系我们](https://mistral.ai/contact)。

我们致力于将最具可及性、影响最大的模型开源，确保开源社区能轻松使用并从我们的先进技术中受益。Devstral Small 易于本地部署，并以 Apache 2.0 许可证供所有人使用和在其上构建；Devstral Medium 则通过我们的 API 为开发者和企业提供高性能。
