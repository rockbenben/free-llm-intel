今天，我们骄傲地推出 [Le Chat Enterprise](https://mistral.ai/products/le-chat)——一款功能丰富的 AI 助手，由我们全新的 [Mistral Medium 3 模型](https://mistral.ai/news/mistral-medium-3)驱动。它直面企业 AI 的挑战——工具碎片化、知识集成不安全、模型僵化、ROI 缓慢——为组织全部工作提供一个统一的 AI 平台。

在 Le Chat 已有生产力工具的基础上，新套餐包含：

- 企业搜索
- Agent 构建器
- 自定义数据与工具连接器
- 文档库
- 定制模型
- 混合部署

[全部功能将在未来两周内陆续上线。]

我们同时还宣布对 Le Chat Pro 和 Team——面向个人和成长中团队的套餐——的多项重大改进。

Le Chat Enterprise 志在一站式提供你团队所需的 AI 生产力：完全私密、深度可定制。此外，我们的世界级 AI 工程团队全程提供支持直至价值交付。

赋能你的团队，让他们更高效、更具竞争力、更加无所不能。

## 面向组织全部工作的统一 AI。

用通晓各种专业语言的 AI，把复杂任务变成可实现的成果。

无论你的团队是在分析数据、编写代码还是创作内容，都可以通过为技术和非技术用户同时设计的直觉界面获得跨领域的专业能力。

### 带安全数据、工具连接与资料库的企业搜索。

从你的企业数据中释放智能，首批支持 Google Drive、Sharepoint、OneDrive、Google Calendar 和 Gmail。更多连接器即将上线，还包括供你自己搭建的模板。

- 把 Le Chat 连接到你的知识，获得更懂你、更个性化的回答。
- 将外部数据源、文档和网页内容组织成完整知识库，得到最相关的回答。
- 用自动摘要（Auto Summary）快速预览文件，加快阅读消化。

Le Chat 让你的团队可以在上传文件以及 Drive / Sharepoint 之上维护一个顺手的高频文档个人库。引用、提取并分析关键信息。

我们很快还将加入 MCP 支持，让你的组织能更轻松地把 Le Chat 连接到更多企业系统。

### 构建并部署自定义 AI agent，精准自动地处理任务。

用 AI agent 自动化日常任务，连接你的应用和资料库，实现跨工具的上下文理解。Le Chat 将让团队轻松构建符合自身要求的定制助手——无需写代码。

## 隐私优先。

在任何地方部署 Le Chat：自托管、你的公有云或私有云，或 Mistral 云托管的服务。对企业工具的隐私优先数据连接——严格遵循 ACL——确保完整的数据保护与安全。

以真正的灵活性构建你的 AI 战略——Mistral AI 让你有独立选择理想基础设施的自由，没有锁定。

我们提供深度可定制性和贯穿全栈的完全控制，从模型、平台一直到界面。

你可以通过与企业数据的定制集成、自定义平台与模型能力来个性化你的 AI 体验，例如用存储的记忆定制你的助手。更进一步，你还可以启用用户反馈回路，让模型持续自我改进。

你将在自己的安全域内对实施保持完全控制，同时让员工用上 SOTA 智能。

此外，我们提供全面的审计日志与存储。
