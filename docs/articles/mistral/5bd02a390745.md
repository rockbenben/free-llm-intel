## **适用于您的业务流程的代理、工作流程和应用程序**

代理、工作流和应用程序服务于业务流程的不同部分。代理进行调查并采取行动，工作流程协调执行和批准，应用程序为员工提供使用这些系统的方法。

Studio 将这三者整合到共享基础架构上。您可以从 Le Chonk 这样的模型开始，并通过连接器和 MCP 服务器将其连接到您的企业数据和系统。该基础使您可以轻松构建代理、工作流程和应用程序，并可以访问它们所需的上下文。 Studio 管理他们的运行方式并让团队检查发生的情况。

通过新的 Mistral MCP 服务器，开发人员可以使用 Mistral Vibe 或他们已经使用的编码代理进行构建、本地测试并通过一个命令部署到他们的 Studio 环境。 Studio 负责托管和执行，因此团队可以在此基础上进行构建，以更快地将每个新用例投入生产。

### **构建调查和行动的托管代理**

在 Studio 中，开发人员现在可以构建执行复杂的多步骤任务的代理。开发人员可以为他们配备捕获团队程序的技能、可以运行代码的沙箱以及用于委派部分任务的子代理。 Hooks 允许开发人员在执行的关键点添加自定义逻辑，从而确定代理的工作方式以及与现有系统的集成方式。

Studio 使用每周支持数百万次 Mistral Vibe 会话的成熟基础架构来管理所有工作背后的运行时。开发人员可以专注于代理的功能和行为，同时为其可以访问的工具、数据和操作设置边界。这意味着让有能力的代理更快地投入生产，需要构建的基础设施更少，并且可以更好地控制代理的运作方式。

我们的工程团队在 Studio 中建立了一个代理来调查生产事件。当警报发生时，工程师需要弄清楚发生了什么，通常面临着解决问题的压力。代理开始调查：它遵循团队的操作手册，在采取敏感行动之前请求批准，并将调查结果发布在 Slack 中。工程师利用已收集的有用背景信息进行调查，每月为团队节省数百个小时。

### **通过工作流程实现流程自动化**

工作流定义流程如何运行：哪些步骤遵循固定规则、代理在何处推理以及人员何时做出决定。中断的运行可以从中断处恢复。团队可以在 Mistral Vibe 中描述流程，并使用它来生成、测试和部署工作流程，并使用他们可以检查和编辑的代码。今天的版本还添加了来自企业系统的事件触发器和可视化图表，使每个工作流程的逻辑更易于检查。

我们的产品运营团队在 Studio 中构建了一个工作流程，用于对内部团队的想法和客户的反馈进行排序。将每份提交内容发送给合适的人是团队的日常任务之一，但需要时间。模型识别错误和功能请求，然后路由规则将它们发送给适当的团队。这为产品运营团队每周节省了约 35 个小时。

### **构建可供企业使用的应用程序**

编码代理可以轻松构建应用程序，但将其在整个企业中运行意味着满足安全性、访问性和可靠性的要求。 Studio 提供托管、身份验证和访问控制，帮助开发人员更快地准备好应用程序以供企业使用。团队可以使用预先批准的可重用组件进行构建，从而减少需要安全审查的新代码量。

这些应用程序可以使用代理和工作流程，通过搜索索引检索企业文档并访问 Studio 中的共享上下文。开发人员可以在本地进行测试，然后使用一个命令进行部署，使应用程序可以在其自己的链接或 Mistral Vibe 内使用。

我们的应用人工智能团队帮助客户构建人工智能解决方案，在 Studio 中构建了一个人员配置应用程序。以前，为项目配备人员意味着手动将团队资料和过去的经验与分布在文档和工具中的需求进行匹配。

该应用程序使用代理来推荐人员并解释他们的经验如何适合该项目。人员配备主管会获得一份候选名单，其中包含可供审查的支持证据，帮助 Mistral 更快地组建团队，并发现在为复杂的客户 AI 项目配备人员时可能被忽视的专业知识。

每个用例都可以让企业更好地准备构建下一个用例。更多的工程工作投入到改善运营上，而花费更少的时间重建周围的基础设施。

## **保持你的人工智能主权**

Studio 可让您控制 AI 的运行位置、运行方式以及您构建的智能。在您自己的云、VPC 或本地环境中部署模型和平台。您还可以使用 Mistral 托管的部署或组合环境来满足您的要求。敏感数据和围绕它构建的流程可以留在您的范围内。

您选择模型，管理对数据和工具的访问，并决定哪些操作需要人工批准。 OpenTelemetry 跟踪显示运行的每个步骤，包括模型调用、工具使用和批准，因此您的团队可以看到流程在哪里变慢或失败。评估让他们可以在发布之前根据您自己的数据集测试对提示、模型或工具的更改。这些痕迹和评估仍然属于他们，保留了他们通过使用建立的操作知识。

客户已经通过与我们的解决方案团队一起构建的系统将这一点付诸实践。从渗透测试到 KYC 入门，他们将 [AI 引入关键操作](https://www.youtube.com/watch?v=6_eHHtB7Q2I)，同时将敏感数据和专业知识置于自己的控制之下。
