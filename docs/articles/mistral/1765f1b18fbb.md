Mistral AI 团队骄傲地发布 Mistral 7B——迄今为止同尺寸下最强大的语言模型。

## Mistral 7B 速览

Mistral 7B 是一个 7.3B 参数的模型：

- 在所有基准上超越 Llama 2 13B
- 在许多基准上超越 Llama 1 34B
- 在代码上逼近 CodeLlama 7B 的表现，同时保持出色的英语任务能力
- 使用分组查询注意力（GQA）实现更快推理
- 使用滑动窗口注意力（SWA）以更低成本处理更长序列

我们以 Apache 2.0 许可证发布 Mistral 7B，可无限制使用。

- [下载它](https://models.mistralcdn.com/mistral-7b-v0-1/mistral-7B-v0.1.tar)，在任何地方（包括本地）配合[我们的参考实现](https://github.com/mistralai/mistral-src)使用，
- 在任意云（AWS/GCP/Azure）上部署，使用 vLLM [推理服务器和 skypilot](https://docs.mistral.ai/self-deployment/skypilot)，
- 在 [HuggingFace](https://huggingface.co/mistralai) 上使用。

Mistral 7B 在任意任务上都易于微调。作为演示，我们提供一个为聊天微调的模型，其表现超越 Llama 2 13B chat。

## 性能详解

我们将 Mistral 7B 与 Llama 2 家族比较，并自行重新运行所有模型评估以公平对比。

![histograms](https://mistral.ai/_astro/01c5ceab-a881-4b56-af40-82f0197bece3_Z1d8yoO.webp?dpl=6abbd11780b53c00082eea6f)*Mistral 7B 与各 Llama 模型在广泛基准上的表现。为准确比较，所有指标、所有模型都用我们的评估流水线重新评估。Mistral 7B 在所有指标上显著超越 Llama 2 13B，并与 Llama 34B 持平（由于 Llama 2 34B 未发布，我们报告的是 Llama 34B 的结果）。它在代码与推理基准上的优势更为巨大。*

基准按主题分类：

- 常识推理：Hellaswag、Winogrande、PIQA、SIQA、OpenbookQA、ARC-Easy、ARC-Challenge 和 CommonsenseQA 的 0-shot 平均。
- 世界知识：NaturalQuestions 和 TriviaQA 的 5-shot 平均。
- 阅读理解：BoolQ 和 QuAC 的 0-shot 平均。
- 数学：8-shot GSM8K（maj@8）与 4-shot MATH（maj@4）的平均
- 代码：0-shot Humaneval 与 3-shot MBPP 的平均
- 流行的聚合结果：5-shot MMLU、3-shot BBH，以及 3-5-shot AGI Eval（仅英语选择题）

![table](https://mistral.ai/_astro/9b643682-b0af-44a2-a690-13c225681c68_Z1aeDY8.webp?dpl=6abbd11780b53c00082eea6f)

比较模型在成本/性能平面上的表现，一个有趣的指标是计算"等效模型尺寸"。在推理、阅读理解和 STEM 推理（MMLU）上，Mistral 7B 的表现相当于一个尺寸超过其 3 倍的 Llama 2。这既意味着内存的节省，也意味着吞吐的提升。![effective_sizes](https://mistral.ai/_astro/42b76b3a-e891-461b-b5fd-ed68d7f9dfa6_n9jxO.webp?dpl=6abbd11780b53c00082eea6f)*Mistral 7B 与 Llama 2（7B/13B/70B）在 MMLU、常识推理、世界知识和阅读理解上的结果。Mistral 7B 在所有评估上都大幅超越 Llama 2 13B，唯有知识基准持平（这很可能由于其参数数量限制了可压缩的知识量）。*

**注**：我们的评估与 LLaMA2 论文的重要差异：

- 对 MBPP，我们使用人工核验的子集
- 对 TriviaQA，我们不提供维基百科上下文

## 疾速与激情：注意力漂移

Mistral 7B 使用滑动窗口注意力（SWA）机制（[Child et al.](https://arxiv.org/pdf/1904.10509.pdf)、[Beltagy et al.](https://arxiv.org/pdf/2004.05150v2.pdf)），每一层关注之前的 `4,096` 个隐藏状态。其主要改进、也是当初研究它的动因，是 O(sliding_window.seq_len) 的线性计算成本。实践中，对 [FlashAttention](https://github.com/Dao-AILab/flash-attention) 和 [xFormers](https://facebookresearch.github.io/xformers) 的改动带来了 16k 序列长度、4k 窗口下 2 倍的加速。特别感谢 Tri Dao 和 Daniel Haziza 在极紧的时间表内帮助纳入这些改动。

滑动窗口注意力利用 Transformer 的堆叠层来实现超出窗口大小之外的历史关注：第 `k` 层的 token `i` 关注第 `k-1` 层的 token `[i-sliding_window, i]`。而这些 token 又关注了 `[i-2*sliding_window, i]`。更高层能获取的历史信息比注意力模式表面所示的更远。

![Local attention](https://mistral.ai/_astro/b1082a4d-5474-4370-bd53-5a0ef4f2909b_Z1ybpgk.webp?dpl=6abbd11780b53c00082eea6f)

最后，固定的注意力跨度意味着我们可以把缓存限制为 `sliding_window` 个 token 的大小，使用滚动缓冲区（详见我们的[参考实现仓库](https://github.com/mistralai/mistral-src)）。这在 `8192` 序列长度的推理上节省一半缓存内存，而不影响模型质量。

## 微调 Mistral 7B 做聊天

为展示 Mistral 7B 的泛化能力，我们在 HuggingFace 公开可用的指令数据集上对其微调。没有花招，没有专有数据。得到的模型 [Mistral 7B Instruct](https://huggingface.co/mistralai/Mistral-7B-Instruct-v0.1) 在 [MT-Bench](https://arxiv.org/abs/2306.05685) 上超越所有 7B 模型，可与 13B 聊天模型相提并论。

![MT-Bench](https://mistral.ai/_astro/5eaa8fac-3fa7-4728-b64f-1fa92b955df2_Zpv4Bt.webp?dpl=6abbd11780b53c00082eea6f)

Mistral 7B Instruct 模型是一个快速演示，表明基座模型可以轻松微调到令人信服的性能。它不带任何审核机制。我们期待与社区探讨如何让模型精细地遵守护栏，以便部署在需要输出审核的环境。
