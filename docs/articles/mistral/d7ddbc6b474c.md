**注意：Le Chat 现已升级为 Vibe**

Le Chat 现已成为 Vibe——一个 agent、一份授权，贯通工作与代码，所有对话、设置和订阅计划全部无缝迁移。

[了解详情](https://mistral.ai/news/vibe-agent/)

今天，我们发布了全新的对话助手 le Chat Mistral，它首次展示了你能用 Mistral 模型构建什么，以及你能在自己的企业环境中部署什么。

## 基于 Mistral 模型的多语言对话助手

Le Chat 是与 Mistral AI 各类模型交互的对话入口。它提供了一种富有教学性又有趣的方式来探索 Mistral AI 的技术。

Le Chat 底层可以使用 Mistral Large 或 Mistral Small，也可以使用一个名为 Mistral Next 的原型模型，它专为简短精炼的回答而设计。我们正在努力让我们的模型尽可能有用、尽可能少带立场，当然仍有很大的改进空间！得益于可调的系统级内容审核机制，当你把对话引向助手可能产出敏感或争议内容的方向时，le Chat 会以不打扰的方式提醒你（关于我们对内容审核的做法，请参阅我们的[服务条款](https://mistral.ai/terms/#terms-of-use)）。

面向企业，我们推出 le Chat Enterprise，通过自托管部署能力和精细化的审核机制来提升团队生产力。如有兴趣，请联系我们的团队。

## 成为早期用户

我们非常期待你的反馈！[立即注册成为 le Chat 的 beta 用户](https://chat.mistral.ai/)。告诉我们你发现的小毛病、le Chat 何时本可以推理得更好、或何时它不够有帮助或不够中立，我们会持续改进。

请注意，le Chat 目前无法访问互联网来检索讨论内容，因此它可能给出不准确或过时的信息。
