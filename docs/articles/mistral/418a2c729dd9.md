语言模型正在改变我们构建软件的方式，充当知识源与用户界面之间灵活的编排者。构建这类软件也带来了新的挑战：提升质量、降低延迟、快速做原型。今天，我们宣布在这一方向上的多项进展。

### 更简单、更高效的模型定制

由于大语言模型正快速找到越来越多、越来越专门的用例，开发者必须能够快速、高效地把前沿模型裁剪到他们的具体应用上，这一点至关重要。为此，我们宣布可以在 La Plateforme 上定制我们的任何旗舰模型和专家模型，包括 Mistral Large 2 和 Codestral。

模型可以通过基础提示词（base prompt）、少样本提示（few-shot prompting）或微调来定制，并且你可以自带数据集。关键在于，模型定制沿用了 Mistral AI 科学团队为打造强基准模型所研发的技术，因此你可以期待微调后的模型达到相近的性能。开发者可以用模型定制把生成式 AI 能力与特定领域知识、上下文或语气融合进自己的应用。

我们期待在高能力模型上进行微调能解锁大量开创性应用，也很想看看大家会构建出什么。请查阅我们的[微调文档](https://docs.mistral.ai/capabilities/finetuning/)，并在 [La Plateforme](https://console.mistral.ai/) 上试用模型定制。

#### Agents 的 Alpha 版本

我们还推出 Agents 的早期版本，它为模型包裹额外的上下文和指令，可通过 Le Chat 或 API 使用。Agents 帮助你用一组简单的指令和示例创建自定义行为与工作流。借助 Mistral Large 2 的高级推理能力，你可以叠加日益复杂的多 agent 工作流，并在组织内轻松共享。我们正在把 Agents 连接到工具和数据源，期待你的反馈。

[了解 Agents 更多信息](https://docs.mistral.ai/capabilities/agents/)。

### 客户端 SDK 稳定版

我们对 `mistralai` 库做了大量更新以提升可用性和一致性，今天发布 mistralai 1.0，同时支持 [Python](https://github.com/mistralai/client-python) 和 [Typescript](https://github.com/mistralai/client-ts)。了解更多新 SDK 信息并查看[迁移指南](https://github.com/mistralai/client-python/blob/main/MIGRATION.md)。
