今天，我们发布 Devstral 2——我们的下一代编码模型家族，提供两种尺寸：Devstral 2（123B）和 Devstral Small 2（24B）。Devstral 2 采用修改版 MIT 许可证，Devstral Small 2 采用 Apache 2.0。两者都是开源、宽松许可，以加速分布式智能。

Devstral 2 目前可通过[我们的 API](https://console.mistral.ai/) 免费使用。

我们还推出 Mistral Vibe，一个为 Devstral 打造的原生 CLI，实现端到端的代码自动化。

## 亮点

- Devstral 2：面向代码 agent 的 SOTA 开放模型，参数量仅为竞争对手的一小部分，在 SWE-bench Verified 上达到 72.2%。
- 在真实任务上比 Claude Sonnet 最高省钱 7 倍。
- Mistral Vibe CLI：原生、开源的终端 agent，自主解决软件工程任务。
- Devstral Small 2：24B 参数模型，可通过 API 使用，也可在消费级硬件上本地部署。
- 兼容本地部署与定制微调。

## Devstral：下一代 SOTA 编码。

Devstral 2 是一个 123B 参数的稠密 Transformer，支持 256K 上下文窗口。它在 SWE-bench Verified 上达到 72.2%——使其跻身最佳开放权重模型之列，同时保持极高的成本效率。以修改版 MIT 许可证发布，Devstral 确立了代码 agent 的开放最先进水平。

Devstral Small 2 在 SWE-bench Verified 上得分 68.0%，稳稳位列体量最多达其五倍的模型之间，同时能在消费级硬件上本地运行。

Devstral 2（123B）和 Devstral Small 2（24B）分别比 DeepSeek V3.2 小 5 倍和 28 倍，比 Kimi K2 小 8 倍和 41 倍——证明紧凑模型可以匹敌甚至超越大得多的对手。更小的体积让受限硬件上的部署变得可行，降低了开发者、小微企业和爱好者的硬件门槛。

### 为生产级工作流而生。

Devstral 2 支持探索代码库、跨多个文件编排变更，同时保持架构级上下文。它会跟踪框架依赖、检测失败并带修正重试——解决修复 bug、现代化遗留系统这类挑战。

该模型可被微调以优先支持特定语言，或针对大型企业代码库优化。

我们用独立标注服务商执行的人类评估，把 Devstral 2 与 DeepSeek V3.2 和 Claude Sonnet 4.5 做了对比，任务通过 Cline 脚手架运行。Devstral 2 相对 DeepSeek V3.2 优势明显：胜率 42.8%、败率 28.6%。不过 Claude Sonnet 4.5 仍显著更受青睐，说明与闭源模型的差距依然存在。

Devstral Small 2 是 24B 参数模型，同样支持 256K 上下文窗口、以 Apache 2.0 发布，把这些能力装进紧凑、可本地部署的形态。它的尺寸带来快速推理、紧凑的反馈回路和轻松的定制——完全私密的端侧运行时。它还支持图像输入，可以驱动多模态 agents。

## Mistral Vibe CLI。

Mistral Vibe CLI 是由 Devstral 驱动的开源命令行编码助手。它用自然语言在你的代码库中探索、修改并执行变更——可以在终端里，也可以通过 Agent Communication Protocol 集成进你偏好的 IDE。以 Apache 2.0 许可证发布。

Vibe CLI 提供交互式聊天界面，带有文件操作、代码搜索、版本控制和命令执行工具。关键特性：

- 项目感知上下文：自动扫描你的文件结构和 Git 状态，提供相关上下文
- 智能引用：用 @ 自动补全引用文件，用 ! 执行 shell 命令，用斜杠命令改配置
- 多文件编排：理解你的整个代码库——不只是正在编辑的文件——实现架构级推理，可让你的 PR 周期缩短一半
- 持久历史、自动补全和可定制主题。

你可以以编程方式运行 Vibe CLI 做脚本，为工具执行开启自动批准，通过简单的 config.toml 配置本地模型与提供商，并按你的工作流控制工具权限。

## 开始使用。

Devstral 2 目前通过[我们的 API](http://console.mistral.ai) 免费提供。免费期结束后，API 定价为 Devstral 2 每百万 token 输入 $0.40/输出 $2.00，Devstral Small 2 为 $0.10/$0.30。

我们已与领先的开放 agent 工具 [Kilo Code](https://kilo.ai/) 和 [Cline](https://cline.bot/) 合作，把 Devstral 2 带到你已在构建的地方。

Mistral Vibe CLI 已作为扩展上架 [Zed](https://zed.dev/extensions)，你可以直接在 IDE 内使用。

### Devstral 的推荐部署。

Devstral 2 为数据中心 GPU 优化，部署最少需要 4 块 H100 级 GPU。今天就可以在 [build.nvidia.com](http://build.nvidia.com) 试用。Devstral Small 2 为单 GPU 运行打造，可在广泛的 NVIDIA 系统上运行，包括 DGX Spark 和 GeForce RTX。NVIDIA NIM 支持即将提供。

Devstral Small 可在消费级 GPU 上运行，无需独立 GPU 的纯 CPU 配置也能跑。

为获得最佳性能，我们建议使用 0.2 的温度，并遵循 [Mistral Vibe CLI](https://github.com/mistralai/mistral-vibe/blob/main/README.md) 定义的最佳实践。
