摘要

Voxtral 3 推出了一套前沿的语音 agent SDK，以及为 50+ 种语言的实时、多步对话设计的最先进语音模型。它把准确的转写、带情绪适应力的自然语音合成，还有为实现无缝工作流自动化而做的深度工具集成结合在了一起。通过 Mistral 的欧盟托管 API 或者自行部署都能用上，它在保证数据主权的同时，为联络中心、虚拟助手和免提 copilot 带来低延迟、像人一样的交互。

语音转写和语音生成已经进步了很多，但要做能听、能想、能互动、还能处理复杂工作流的端到端语音 agent，仍然很难。

一个靠谱的语音 agent 需要把四件事都做得很好（而且是同时做好）：

- **听得准 **跨语言、跨口音、跨说话人，还要扛得住插话，
- **推理** **深入 **用户在具体语境里真正说的是什么，
- **说得自然 **带情绪、带抑扬，还有
- **动得起手 **在多个相互连接的系统上走完整整几步。

要让这四样在实时里可靠地协同起来，仍然是个难题。

为了解决这一点，我们推出 Voxtral 3：一整套最先进的[语音转文本](https://docs.mistral.ai/studio/audio/speech-to-text/overview)与[文本转语音](https://docs.mistral.ai/studio/audio/text-to-speech/overview)模型家族，外加一个把聆听、思考、工具调用和说话收进同一条实时流式管道的语音 agent SDK。

Voxtral 3 是为做出自然的对话体验而造的，从联络中心 agent、服务台，到虚拟助手和免提 copilot 都能做。凭着对几十种语言、有表现力的语音、复杂推理的支持，以及与你自己的工具和数据深度打通，用 Voxtral 搭出来的 agent 能读懂细微的意图，能把复杂的请求想明白，还能在相互连接的系统上执行多步操作。

和 Mistral 的其他模型一样，Voxtral 3 家族是为主权部署设计的。今天起，通过 Mistral 的欧盟托管 API，或者在你自己的基础设施上自行部署，都能用上它：它让组织自己说了算——音频在哪里处理、数据怎么处理、对话要不要留存。

## 亮点

- **50+ 种语言的准确转写**。语音转文本模型 *Voxtral Small Transcribe 3* 在多语言转写上是业界最先进水平，能认出谁说了什么（diarization），会拿关键短语来把自己的准确度往上抬（context-biasing）。它还能察觉一个人什么时候说完了，好让 agent 不用等就能接话（end-of-turn detection）。
- **随对话而变的自然语音**。文本转语音模型 *Voxtral Mini TTS 3* 带来一批新的声音，它们会根据对话上下文调整自己的情绪、语速和重音，支持 35+ 种语言和 50+ 种方言。
- **听得你吩咐（用嘴说也行）的类人智能**。全新的语音 agent SDK 把聆听、推理、工具调用和说话揉成一个实时体验。Agent 可以检索信息、跟业务系统打交道，并在电话或网页上的实时对话里把活儿干完。
- **Pro Voice，做出真正精准的语音适配**。在基础的声音克隆不够用的专业场景里，Voxtral 的 *Pro Voice* 适配只用 30 分钟音频，就能还原一个说话人独有的音色气质、情绪跨度和说话风格，而且跨语言都行。
- **你的语音 AI，跑在你的基础设施上**。用 Mistral 的欧盟托管 API，或者把 Voxtral 3 部署在你自己的基础设施上。让敏感对话留在你的环境里，并且由你控制任何音频是否留存。

## 它听得到 50+ 种语言，准确度是业界最先进水平。

[Voxtral Transcribe 3](http://docs.mistral.ai/models/voxtral-small-transcribe-3-0) 在转写、diarization（谁在什么时候说话）和 context biasing 这几项能力上都是一个重要的里程碑。支持的语种扩展到 50 种，其中包括 24 种欧盟官方语言，以及许多低资源的亚洲语言和印度系语言。

Small 版本在 diarization 和多语言转写上都拿到了业界最先进的成绩，其中包含英语、法语和西班牙语。它的表现超过 Whisper、Scribe v2 和 Gemini 3.5 Transcribe。[Mini 变体](https://docs.mistral.ai/models/voxtral-mini-transcribe-3-0) 是 4B 参数，能以 $0.0035/min 的价格做出又快又准的转写。

两个模型都支持 context biasing：可以把关键术语和自由形式的文本喂给它，让转写往这些词上偏，从而提高技术术语的召回。这就让它们能用在带专业词汇的生产环境里，而不需要 fine-tuning。

## 语音 agent 掌控着整场对话。

Voxtral 3 推出了一个基于 LiveKit 的语音 agent SDK，把语音进、推理、语音出跑成同一条流式管道。Voxtral Mini Transcribe Realtime 3 负责听，并察觉来电人什么时候说完；一个通用模型——比如 [Mistral Small](https://docs.mistral.ai/models/mistral-small-4-0-26-03)——负责推理和调用工具；Voxtral Speech 3 则顺着到目前为止这段对话的语气来回应。没有任何一个阶段要等它前面那个阶段，所以每一轮都在一秒以内完成，而来电人一插话，agent 就停下不说了。

在通话过程中，agent 可以核实来电人身份、查账单，或者预约挂号，靠的是 function calling、网络搜索，以及在你自己系统上的检索。它通过 SIP 接打电话，在浏览器和 App 里通过 WebRTC 运行，并接上你已经在用的电话、IVR 和联络中心软件。
