总结

Voxtral 3 引入了尖端的语音代理 SDK 和最先进的语音模型，专为跨 50 多种语言的实时、多步骤对话而设计。它结合了准确的转录、具有情感适应性的自然语音合成以及用于无缝工作流程自动化的深度工具集成。它可通过 Mistral 的欧盟托管 API 或自行部署使用，确保数据主权，同时为联络中心、虚拟助理和免提副驾驶提供低延迟、类人交互。

语音转录和语音生成已经取得了长足的进步，但构建可以监听、推理、交互和处理复杂工作流程的端到端语音代理仍然很困难。

一个可靠的语音代理需要很好地（同时）做好四件事：

- **准确地听**各种语言、口音、说话者和干扰，
- **原因** **深入**了解用户在特定上下文中的含义，
- **自然地说话**带有情感和表情，并且
- **通过互联系统分多个步骤采取行动**。

让这四者实时可靠地协同工作仍然是一个挑战。

为了解决这个问题，我们推出了 Voxtral 3：一系列最先进的[语音转文本](https://docs.mistral.ai/studio/audio/speech-to-text/overview) 和[文本转语音](https://docs.mistral.ai/studio/audio/text-to-speech/overview) 模型，以及一个语音代理 SDK，可实现聆听、思考、工具调用、并对单个实时流管道进行对话。

Voxtral 3 旨在创造自然的对话体验，从联络中心代理和服务台到虚拟助理和免提副驾驶。通过支持数十种语言、富有表现力的语音、复杂的推理以及与您自己的工具和数据的深度集成，使用 Voxtral 构建的代理可以解释微妙的意图，通过复杂的请求进行推理，并跨连接的系统执行多步骤操作。

与其他 Mistral 型号一样，Voxtral 3 系列专为主权部署而设计。现在可以通过 Mistral 的欧盟托管 API 或在您自己的基础设施上自行部署来使用，它使组织可以控制音频的处理位置、数据的处理方式以及是否保留对话。

## 它可以听到 50 多种语言，具有最先进的准确性。

[Voxtral Transcribe 3](http://docs.mistral.ai/models/voxtral-small-transcribe-3-0) 代表了转录、二值化（谁在何时发言）和上下文偏置功能方面的一个重要里程碑。支持的语言列表已扩展到 50 种，其中包括 24 种欧盟官方语言以及许多资源匮乏的亚洲和印度语言。

小版本在日记化和多语言转录（包括英语、法语和西班牙语）方面实现了最先进的结果。它的性能优于 Whisper、Scribe v2 和 Gemini 3.5 Transcribe。 [Mini 变体](https://docs.mistral.ai/models/voxtral-mini-transcribe-3-0) 是 4B 参数，能够以 0.0035 美元/分钟的价格实现快速、准确的转录。

两种模型都支持上下文偏差，可以提供关键术语和自由格式文本来偏差转录并提高对技术术语的回忆。这使得它们能够在具有特定领域词汇的生产环境中使用，而无需进行微调。

## 语音代理控制整个对话。

Voxtral 3 引入了一款基于 LiveKit 构建的语音代理 SDK，它将语音输入、推理和语音输出作为一个流管道运行。 Voxtral Mini Transcribe Realtime 3 会监听并检测呼叫者何时结束讲话，一般模型（如 [Mistral Small](https://docs.mistral.ai/models/mistral-small-4-0-26-03)）-原因和呼叫工具，Voxtral Speech 3 以目前对话的语气进行回复。没有任何阶段会等待前面的阶段，因此每个回合都会在一秒钟内完成，并且当呼叫者插话时，座席会停止讲话。

在通话期间，座席可以通过您自己的系统使用函数调用、Web 搜索和检索来验证呼叫者的身份、检查账单或预约。它通过 SIP 接听和拨打电话，通过 WebRTC 在浏览器和应用程序中运行，并连接到您已使用的电话、IVR 和联络中心软件。
