发布 Magistral——Mistral AI 的首个推理模型——专精于领域定制、透明、多语言的推理。

人类最好的思考不是线性的——它在逻辑、洞察、不确定性和发现之间穿梭交织。推理语言模型让我们能够把复杂思考与深度理解增强并委托给 AI，提升我们处理需要精确、逐步斟酌与分析的问题的能力。

但这个领域仍处于早期。缺乏领域问题所需的专业深度、透明度有限、在目标语言中推理不稳定——这些只是早期思考模型已知局限的一部分。

今天，我们很高兴宣布对 AI 研究的最新贡献 Magistral——我们的首个推理模型。Magistral 以开放版和企业版双重发布，被设计为以我们熟悉的方式把问题想透，同时带来跨专业领域的专长、可供你跟随验证的透明推理，以及深入的多语言灵活性。

一段用 Preview 中的 Magistral Medium 一次性生成的物理仿真，展示重力、摩擦与碰撞。

## 亮点

![Plot Magistral](https://mistral.ai/_astro/d73ee721-ea92-46f5-af77-79674fdb4163_1gJcoR.webp?dpl=6abbd11780b53c00082eea6f)

Magistral 是一个双重发布的模型，聚焦真实世界推理与反馈驱动的改进。

- 我们以两种变体发布该模型：Magistral Small——24B 参数的开源版本，以及 Magistral Medium——更强的企业版本。
- Magistral Medium 在 AIME2024 上得分 73.6%，配合 majority voting @64 达到 90%。Magistral Small 分别为 70.7% 和 83.3%。
- 原生推理——Magistral 的思维链适用于全球语言和文字体系。
- 适合广泛的企业用例——从结构化计算和程序化逻辑，到决策树与基于规则的系统。
- 借助 Le Chat 中全新的 Think 模式和 Flash Answers，你可以获得比多数竞品快 10 倍的响应。
- 本次发布有我们的[最新论文](https://arxiv.org/pdf/2506.10910)支撑，涵盖对 Magistral 的全面评估、我们的训练基础设施、强化学习算法，以及训练推理模型的新颖观察。

由于我们把 Magistral Small 开源，我们欢迎社区审视、修改并在其架构和推理过程之上构建，进一步加速思考型语言模型的涌现。我们早期的开放模型已被社区用于激动人心的项目，如 [ether0](https://www.futurehouse.org/research-announcements/ether0-a-scientific-reasoning-model-for-chemistry) 和 [DeepHermes 3](https://huggingface.co/NousResearch/DeepHermes-3-Mistral-24B-Preview)。

### 为透明推理而生。

Magistral 针对多步逻辑进行了微调，提升可解释性，并提供以用户语言呈现的可追溯思考过程——这与通用模型不同。

我们的目标是从这一版本开始快速迭代模型。可以预期模型会持续进步。

### 多语言的游刃有余。

该模型擅长在众多语言中保持高保真推理。Magistral 尤其适合用英语、法语、西班牙语、德语、意大利语、阿拉伯语、俄语和简体中文进行推理。

在 Preview 中的 Le Chat 里用 Magistral Medium 以阿拉伯语进行提示和回答。

### 在 Le Chat 上推理快 10 倍。

借助 Le Chat 的 Flash Answers，Magistral Medium 的 token 吞吐比多数竞品快至多 10 倍。这使得大规模、实时的推理与用户反馈成为可能。

Preview 中 Le Chat 里的 Magistral Medium 与 ChatGPT 的速度对比。

## 应用的多面性。

Magistral 适合需要更长思考过程和更高准确率的通用场景——比非推理 LLM 更能胜任。从法律研究和财务预测，到软件开发与创意叙事——该模型能解决透明度和精确性至关重要的多步挑战。

### 业务战略与运营。

在我们旗舰[模型](https://mistral.ai/models)的基础上，Magistral 为研究、战略规划、运营优化和数据驱动决策而设计——无论是执行多因素风险评估与建模，还是在约束下计算最优交付窗口。

### 受监管行业与部门。

法律、金融、医疗和政府部门的专业人士获得满足合规要求的可追溯推理。每一个结论都可以沿其逻辑步骤回溯，为高风险环境提供可审计性，并辅以领域定制 AI。

### 系统、软件与数据工程。

Magistral 增强了编码与开发用例：与非推理模型相比，它通过涉及外部工具或 API 的有序多步动作，显著提升项目规划、后端架构、前端设计和数据工程。

### 内容与传播。

我们的早期测试表明 Magistral 是一位出色的创作伙伴。我们强烈推荐它用于创意写作和叙事，模型既能产出连贯流畅的文案，必要时也能产出妙趣横生的跳脱之作。
