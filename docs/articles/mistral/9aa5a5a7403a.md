我们很高兴发布 Codestral Embed——我们首个专为代码优化的嵌入模型。它在真实代码数据的检索用例上表现尤其出色。

Codestral Embed 大幅超越当前市场上的领先代码嵌入器：Voyage Code 3、Cohere Embed v4.0 和 OpenAI 的大嵌入模型。

Codestral Embed 可以输出不同维度和精度的嵌入，下图展示了检索质量与存储成本之间的权衡。维度 256、int8 精度的 Codestral Embed 仍然优于我们竞争对手的任何模型。我们嵌入的维度按相关性排序。对任意目标维度 n，你可以只保留前 n 维，在质量与成本之间平滑取舍。

## 应用场景

Codestral Embed 为高性能代码检索和语义理解而优化。它支撑开发工作流中的一系列实用应用，尤其是在处理大规模代码语料时。

### 1. 检索增强生成

Codestral Embed 为代码补全、编辑或解释任务提供快速高效的上下文检索。它是副驾或编码 agent 框架中 AI 驱动软件工程的理想选择。

### 2. 语义代码搜索

Embed 支持从自然语言或代码查询精准检索相关代码片段。适合用在开发者工具、文档系统和副驾中。

### 3. 相似性搜索与重复检测

该模型的嵌入可用于识别近似重复或功能相似的代码段，即使词面差异很大。这支持诸如识别可复用代码以避免重复，或检测复制粘贴复用以执行许可证政策等用例。

### 4. 语义聚类与代码分析

Codestral Embed 支持按功能或结构对代码进行无监督分组。这对分析仓库构成、识别浮现的架构模式，或喂给自动化文档与分类系统都很有用。

### 分块参数

对检索用例，虽然你可以使用 8192 token 的完整上下文长度，但把数据分块通常更高效。我们建议以 3,000 字符为一块、重叠 1,000 字符。更大的块往往会对检索系统性能产生不利影响。关于分块的更多信息请参考[我们的](https://docs.mistral.ai/guides/rag/#split-document-into-chunks)[cookbook](https://colab.research.google.com/github/mistralai/cookbook/blob/main/mistral/embeddings/code_embedding.ipynb)。
