在 Mistral AI，我们持续推动开放模型（[Mistral Small](https://mistral.ai/news/mistral-small-3-1)、Mistral Large、Pixtral 等等）和企业模型（[Mistral OCR](https://mistral.ai/news/mistral-ocr)、Mistral Saba、Ministral 3B / 8B 等）的前沿。从 [Mistral 7B](https://mistral.ai/news/announcing-mistral-7b) 开始，我们的模型一贯展现出远超更高权重、更昂贵模型的性能。今天，我们很高兴宣布 **Mistral Medium 3**，把语言模型的效率与可用性再推一个新高度。

## 亮点

- Mistral Medium 3 开创了一个新的模型层级，平衡了：
- 最先进性能、成本降低 8 倍、更简单的可部署性，以加速企业使用
- 该模型在编码、多模态理解等专业用例中领先
- 该模型提供一系列企业级能力，包括：
- 混合或本地 / VPC 内部署、定制后训练、融入企业工具与系统

## 完美的平衡。

Mistral Medium 3 交付前沿性能，而价格便宜一个数量级。例如，在各基准测试中，该模型达到或超过 Claude Sonnet 3.7 90% 的表现，而成本显著更低（每百万 token 输入 $0.4 / 输出 $2）。

在性能上，Mistral Medium 3 也超越了 Llama 4 Maverick 等领先开放模型和 Cohere Command A 等企业模型。在定价上，无论 API 还是自托管系统，该模型都击败了 DeepSeek v3 这样的成本标杆。

此外，Mistral Medium 3 可部署在任何云上，包括四卡及以上的自托管环境。

Mistral Medium 3 在适应企业环境的能力上从其他 SOTA 模型中脱颖而出。在一个许多组织被迫在"微调、API 或自托管之间二选一"、从零开始定制模型行为的世界里，Mistral Medium 3 提供了一条把智能全面融入企业系统的路径。借助 Mistral 的[应用 AI 解决方案](https://mistral.ai/services)，该模型可以被持续预训练、全量微调，并与企业知识库融合，成为面向领域定制训练、持续学习和自适应工作流的高保真解决方案。来自金融服务、能源和医疗行业的 beta 客户正在用该模型以深度上下文增强客户服务、个性化业务流程并分析复杂数据集。
