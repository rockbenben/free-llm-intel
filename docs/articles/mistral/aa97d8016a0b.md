企业的软件工程团队终于能够以安全、合规的方式把前沿级 AI 编码带入自己的工作流。Mistral Code 是一款 AI 编码助手，把强大的模型、IDE 内助手、本地部署选项和企业工具打包成一个全支持的整体，让开发者在 IT 与安全团队的全力背书下实现 10 倍生产力。

Mistral Code 建立在久经验证的开源项目 [Continue](https://github.com/continuedev/continue) 之上，并补强大型企业所需的管控与可观测性。面向 [JetBrains IDE](https://plugins.jetbrains.com/plugin/27493-mistral-code-enterprise) 和 [VSCode](https://marketplace.visualstudio.com/items?itemName=mistralai.mistral-code) 的私有 beta 今日开放，正式发布（GA）计划在不久后。Mistral Code 是我们"让开发者因 AI 而成功"努力的延续，此前一个月我们刚发布了 [Devstral](https://mistral.ai/news/devstral) 和 [Codestral Embed](https://mistral.ai/news/codestral-embed)。

## 我们为什么打造 Mistral Code

我们对 Mistral Code 的目标很简单：把同类最佳的编码模型交付给企业开发者，支撑从即时补全到多步重构的一切——并通过一个集成平台部署，可上云、可用预留容量、也可在物理隔离的本地 GPU 上。

与典型的 SaaS 副驾不同，技术栈的所有部分——从模型到代码——由单一提供商按同一组 SLA 交付，且每一行代码都留在客户的企业边界之内。

当我们与工程副总裁、平台负责人和 CISO 交流时，他们提出了四个反复出现、令主流副驾止步于概念验证阶段的障碍：

- 与专有仓库和内部服务的连接受限。
- 对底层模型或提示词几乎无法定制。
- 任务覆盖浅，止步于"自动补全"，无法完成多步工作。
- SLA 碎片化：插件一家厂商、模型另一家、基础设施第三家。

Mistral Code 以单一垂直集成的产品解决这些痛点：模型、插件、管理控制和 7x24 支持——让平台团队保有可见性，并能把 AI 赋能的生产力与 ROI 挂钩。

## 智慧编码，自信掌控

在核心层面，Mistral Code 由四个在编码上最先进的模型驱动：

- [Codestral](https://mistral.ai/news/codestral) 用于 fill-in-the-middle / 代码自动补全
- [Codestral Embed](https://mistral.ai/news/codestral-embed) 用于代码搜索与检索
- [Devstral](https://mistral.ai/news/devstral) 用于 agentic 编码
- 以及 [Mistral Medium](https://mistral.ai/news/mistral-medium-3) 用于聊天辅助

关键在于，客户可以在私有仓库上微调或后训练底层模型，或蒸馏轻量变体——这些能力在绑定专有 API 的闭源副驾里根本不存在。

Mistral Code 精通 80 多种编程语言，并能对文件、Git diff、终端输出和 issue 进行推理。我们目前正在测试该产品帮助工程师超越编码辅助和建议，去完整交付界定好的工单：打开文件、编写新模块、更新测试，甚至执行 shell 命令——全部处于可配置的审批工作流之下，让资深工程师保持控制。

对 IT 管理者，功能丰富的管理控制台提供细粒度的平台控制、深度可观测性、席位管理和用量分析。

## 全球企业的选择

客户验证了这一路线：[Abanca](https://www.abanca.com/es/)——西班牙和葡萄牙的领先银行——已为开发团队大规模部署 Mistral Code，采用混合配置，可在云端做原型验证，而核心银行代码留在本地。[SNCF](https://www.groupe-sncf.com/en)——法国国家铁路公司——正通过 Mistral Code Serverless 为其 4,000 名开发者赋予 AI 能力；而[凯捷（Capgemini）](https://www.capgemini.com/news/press-releases/capgemini-partners-with-mistral-ai-to-spearhead-the-adoption-of-new-frontier-generative-ai-models/)——我们的首家全球系统集成商合作伙伴——将为 1,500 多名开发者本地部署 Mistral Code，服务于受监管行业的客户项目。
