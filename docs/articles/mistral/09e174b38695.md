### la Plateforme 免费套餐

[La Plateforme](https://console.mistral.ai/)——以 API 端点形式用 Mistral 模型调优和构建的无服务器平台——现已提供免费套餐，开发者可以零成本开始实验、评估和原型验证。用户可以无缝把端点升级到商用套餐，享有完整的数据隔离（含免费的零保留选项）和更高的速率限制。用户也可以选择把我们的模型部署到不同基础设施：既可以使用我们的云合作伙伴（Azure / AWS / GCP），也可以选择把我们的方案部署在自己的[租户](https://mistral.ai/contact/)中。

### Small 迎来大更新

我们骄傲地揭晓 Mistral Small v24.09——我们最新的、企业级的小模型，Mistral Small v24.02 的升级版。该模型以 Mistral Research License 提供，让客户能够灵活选择一个成本效益高、速度快且可靠的选项，用于翻译、摘要、情感分析等不需要重型通用模型的任务。

Mistral Small v24.09 拥有 220 亿参数，在 Mistral NeMo 12B 和 Mistral Large 2 之间提供了一个理想的中间点，是可部署在各种平台和环境的划算方案。如下图所示，新的小模型相对前代在人类对齐、推理能力和代码方面都有显著提升。

### 虎目生辉——Pixtral 登陆 le Chat

继我们最新的 Apache 模型发布之后，[Pixtral 12B](https://mistral.ai/news/pixtral-12b/)——一个具备图像理解能力的视觉模型——现在已在 [le Chat](https://chat.mistral.ai/) 上免费可用。Pixtral 12B 是第一个支持任意尺寸图像且不损失文本性能开源模型，你现在可以在 le Chat 上用它来扫描、分析、检索、为图片生成描述，并更好地理解你的个人或企业知识文件。

重要的是，该模型以 Apache 2.0 许可证发布，所以你可以把视觉理解能力带进自己的环境，而不必将文件上传给第三方服务商。这对处理敏感或专有信息的客户至关重要。
