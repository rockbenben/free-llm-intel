## 今天，我们给你更多转用 Le Chat 的理由。

- **面向企业、可自定义扩展的最广连接器目录（beta）**，轻松把工作流带入你的 AI 助手。
- 20 多个安全连接器目录——横跨数据、生产力、开发、自动化、商务与自定义集成。在 Databricks、Snowflake、GitHub、Atlassian、Asana、Outlook、Box、Stripe、Zapier 等工具中搜索、摘要和行动。自定义扩展：添加你自己的 MCP 连接器以扩大覆盖，驱动更精准的行动与洞察。灵活部署：移动端、浏览器，或本地/你的云上部署。
- **上下文随身带：引入 Memories（记忆，beta）。**
- 基于你的偏好与事实的高度个性化回答。审慎可靠的记忆管理：保存要紧的，滑走敏感或转瞬即逝的信息。对存什么、改什么、删什么拥有完全控制。还有……从 ChatGPT 快速导入你的记忆。
- **以上全部在 Free 套餐即可使用。**

## 即插即用。

今天，我们在 Le Chat 中发布 20 多个安全的、基于 MCP 的连接器，让你能搜索、摘要并对业务关键工具采取行动。Le Chat 的连接器目录覆盖核心类别，简化你在工作流与聊天之间的集成方式。

![Logo Cloud 1 1](https://mistral.ai/_astro/92e9c189-28ba-4d83-b8c9-058850e1ad30_Z1WvyYy.webp?dpl=6abbd11780b53c00082eea6f)

全新面貌的[连接器目录](https://chat.mistral.ai/connections)打开了通往企业工具的直达管道，把 Le Chat 变成数据、文档与行动的统一界面。

- **数据**：在 Databricks（即将上线）、Snowflake（即将上线）、Pinecone、Prisma Postgres 和 DeepWiki 中搜索并分析数据集。
- **生产力**：在 Box 和 Notion 中协作团队文档，在 Asana 或 Monday.com 上开项目看板，并跨 Jira、Confluence 等 Atlassian 工具分诊。
- **开发**：在 GitHub 管理 issue、pull request、仓库与代码分析；在 Linear 创建任务、在 Sentry 监控错误、并与 Cloudflare Development Platform 集成。
- **自动化**：通过 Zapier 扩展工作流、在 Brevo 中运营营销活动。
- **商务**：访问并对 PayPal、Plaid、Square 和 Stripe 的商户与支付数据采取行动。
- **自定义**：添加你自己的 MCP 连接器以扩展覆盖，查询、获取摘要并对你业务独有的系统与工作流采取行动。
- **部署**：本地、你的云或 Mistral Cloud 上运行，完全掌控你的数据与工作流所在。

### 连接任意 MCP server。

对于其他一切，你现在可以[连接任何你选择的远程 MCP server](https://help.mistral.ai/en/articles/393572-configuring-a-custom-connector)——即使它没有列在[连接器目录](https://chat.mistral.ai/connections)里——来查询、交叉参照并对技术栈中的任意工具执行操作。

### 你的规则。你的控制。

管理员用户可以放心控制组织内哪些人对哪些连接器可用，配合代表式认证（on-behalf authentication），确保用户只能访问其被授权的数据。

按你的方式部署 Le Chat——自托管、你的私有云或公有云，或作为 Mistral Cloud 上的全托管服务。企业部署请[与我们团队聊聊](https://mistral.ai/contact)。

## 记住那份思考。

Le Chat 中的 Memories 让你的上下文跨对话延续，在需要时检索过去的洞见、决策与引用。它们驱动更相关的回答、为你定制的自适应建议、以及注入你工作细节的更丰富答案——带来更快、更相关、完全个性化的体验。

Memories 在我们关于准确性与可靠性的评估中得分很高：保存要紧内容、避免禁区或敏感推断、忽略短暂内容、无幻觉地取回正确信息。

![Grid Lechat](https://mistral.ai/_astro/a0e581b9-125b-4ec7-b03a-9fea8eacbd63_1DXF0r.webp?dpl=6abbd11780b53c00082eea6f)

最重要的是，你始终拥有完全控制——随时添加、编辑、更新或删除任何条目，配以[清晰的隐私设置](https://help.mistral.ai/en/articles/396497-how-do-you-handle-my-data-when-using-the-memories-feature)和值得信赖的选择性记忆处理。
