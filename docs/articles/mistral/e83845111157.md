# 发布 Forge

今天，我们推出 **Forge**——一个让企业**基于自有专有知识构建前沿级 AI 模型**的系统。

当今大多数 AI 模型主要在公开可得的数据上训练，被设计为在众多任务上都有良好表现。但企业的运转依赖内部知识：工程标准、合规政策、代码库、运营流程，以及多年积累的机构决策。

Forge 弥合了通用 AI 与企业特定需求之间的鸿沟。组织不必依赖宽泛的公开数据，而是可以训练理解其内部上下文（那些嵌入在系统、工作流与政策中的知识）的模型，让 AI 与自身独特的运营对齐。

Mistral AI 已经与全球领先机构合作，例如 **ASML**、**新加坡 DSO 国家实验室**、**爱立信（Ericsson）**、**欧洲航天局**、**新加坡内政团队科技局（HTX）** 和 **Reply**，在为它们最复杂系统和定义未来之技术提供动力的专有数据上训练模型。

![Forge Users](https://mistral.ai/_astro/7641c304-ef39-4982-a4fc-62e3e307bd9d_2abPYu.webp?dpl=6abbd11780b53c00082eea6f)

## 在机构知识上训练模型。

Forge 让企业能够构建内化其领域知识的模型。组织可以在海量内部文档、代码库、结构化数据与运营记录上训练模型。训练期间，模型学习定义该环境的词汇、推理模式与约束。

这让团队能够开发使用内部术语进行推理、理解企业工作流的模型和 Agent。Forge 支持覆盖模型生命周期多个阶段的现代训练方法：

- 预训练让组织能够从大型内部数据集中学习，构建具备领域意识的模型。
- post-training 方法让团队针对特定任务与环境打磨模型行为。
- 强化学习帮助组织将模型与 Agent 对齐到内部政策、评估标准和运营目标，同时在真实环境中提升 Agent 表现，如复杂编排、工具使用与决策。

这些能力共同让企业超越通用 AI 行为，打造出体现机构智能的模型。

## 控制权与战略自主。

对许多组织来说，采用 AI 会引发关于模型、数据和长期知识产权控制权的问题。Forge 让企业构建始终处于自身控制之下的模型。模型可以用专有数据集训练，并按内部政策、评估标准与运营要求进行治理。

这让组织能够保留对其知识如何被 AI 系统编码和使用的控制权。在受监管环境中，这种程度的控制至关重要。企业必须确保模型反映合规要求、运营约束和内部治理框架。

通过让组织构建扎根于自身知识、运行在自身基础设施环境中的模型，随着 AI 成为企业核心系统的一部分，Forge 实现了更高程度的战略自主。

## 定制模型让企业 Agent 更可靠。

企业 Agent 必须做的远不止生成答案。它们需要穿行于内部系统、正确使用工具，并在组织约束内做出决策。

定制模型让这一点成为可能：它们为 Agent 提供对所处环境的更深入理解。由领域训练模型驱动的 Agent 不再依赖通用推理，而是能解读内部术语、遵循操作流程，并理解不同系统与数据源之间的关联。

这改变了 Agent 的实际行为。工具选择更精准。多步工作流更可靠。决策可以反映内部政策与业务逻辑，而不是通用假设。

结果是：Agent 超越简单辅助，开始作为企业系统中的运营组件运作——执行任务、跨工具协调，并以更高的精度和速度支撑复杂流程。

## 支持多种模型架构。

Forge 提供灵活性与对 dense 及 mixture-of-experts（MoE）两种架构的支持。这让组织可以在性能、成本与运营约束之间优化。Dense 模型在众多企业任务上提供强大的通用能力；MoE 则让超大模型运行更高效——以低于同等规模 dense 模型的延迟与算力成本交付相当的能力。Forge 还在需要时支持多模态输入，让模型可以从文本、图像及其他数据格式中学习。

## 天生 Agent 优先

代码 Agent 正在成为开发者工具的主要使用者，因此我们首先就为它们构建了 Forge，而不是事后补上。像 Mistral Vibe 这样的自主 Agent 可以用它来微调模型、寻找最优超参数、调度作业、生成合成数据，从而在评测上不断爬坡攀升。整个过程里，Forge 会监控指标，确保模型在你关心的基准上没有退化。由于 Forge 负责基础设施，并内置久经考验的数据管线配方与 Mistral AI 自家的训练方法，任何人——包括 Agent——只需用普通英语描述即可定制一个模型。

## 通过强化学习与评估实现持续改进。

企业环境在不断演化。法规会变化。系统会更新。新数据会出现。Forge 为持续适应而非一次性训练而设计。组织可以使用强化学习管线，利用源自内部评估和运营工作流的反馈来打磨模型行为。

这让团队能够随时间改进模型，并使输出与组织目标对齐。评估框架让企业可以在部署到生产环境之前，用内部基准、合规规则和领域特定任务测试模型。

结果是支持持续改进而非静态部署的模型生命周期。

## 企业应用示例。

组织可以把 Forge 应用于多种企业工作流。

**政府机构**可以构建针对不同语言和方言、政策框架、法规文本与行政流程训练的模型。这让 AI Agent 在处理政策分析、公共服务交付与运营规划时更可靠，同时体现机构职责与治理要求。

**金融机构**可以在合规框架、风险流程与监管文档上训练模型。这让 AI 系统能够产出与内部治理政策一致的输出。

**软件团队**可以在专有代码库和开发标准上训练模型。真正的价值来自让模型在驱动公司内部生产力与质量的特定工程任务上表现出色。在专有仓库和开发标准上训练的模型，能更好地理解内部抽象、模式与架构选择。针对实现、调试、迁移、评审或系统设计支持等优先工作流进行 post-training 后，它能提供更懂上下文、更符合内部实践、在整个软件开发生命周期中都更有用的输出。

**制造商**可以在工程规格、运营数据和维护记录上训练模型。这些模型可以支持故障诊断、设计分析与运营决策。

**大型集团企业**可以部署基于内部知识系统训练模型构建的 Agent。这些 Agent 可以利用公司文档、运营记录和历史决策，在复杂工作流中协助员工。由于底层定制模型理解组织的术语和知识结构，Agent 能以更高的精度和速度检索信息并执行任务。

在每一种场景中，目标都是相同的：让模型以及在其之上构建的 Agent 能够在组织的领域上下文中运作。

## 用 Forge 构建你自己的前沿模型。

AI 模型正在成为企业基础设施的基础层。随着组织把 AI Agent 集成进核心运营，把机构知识编码进模型行为的能力将愈发重要。

Forge 让企业能够构建并持续改进在自身数据上训练、与其运营上下文对齐的模型。这些模型可以驱动使用组织术语、流程和约束运作的 AI 系统与 Agent。久而久之，这种方式让组织可以把 AI 模型不仅仅视为外部工具，而是与自身知识、流程与专长共同演化的战略资产。
