随着对话式 AI 越来越能干，我们的期待也与日俱增。我们不只想要更快的回答，我们想要能记忆、能适应、契合我们工作方式的工具。这正是 [Memories（记忆，beta）](https://chat.mistral.ai/memories)的用武之地。随之而来的是新问题：AI 应该记住什么？它应该如何回忆？你需要什么才会信任它？

## 用户告诉我们的。

当我们与个人和职业场景的用户交流时，三个一致的需求浮出水面：透明、控制和专注。人们想要能问出"你知道我哪些信息？"并得到清晰回答的能力。他们也希望记忆保持就事论事。正如一位 Le Chat 用户所说："我需要一把锤子，不是一个朋友。"

对一些人来说，这意味着引用出处：明确告诉我回答取哪段对话或哪个文件。对另一些人，这意味着限定范围的回忆——项目专属的细节，而不是几个月前的随口闲谈。无论偏好如何，有一点很明确：记忆应当始终可见、可编辑、由你掌控。

## 为用户而建的记忆系统。

如今许多 AI 工具会自动存储信息。有的会毫无预警地把旧信息翻出来；有的只有在你明确要求时才回忆。

Le Chat 采取混合方式。它会自动保存有用的信息，就像你聊天时顺手记笔记。但回忆的设计是智能、及时且可见的。你总会看到正在起作用的是哪条记忆，并附有来源链接。

这一设计源于一个简单的理念：AI 助手应该帮你思考得更好，而不是让你猜它在做什么。以下是我们的实践方式。

## Le Chat 记忆背后的三条原则。

### 透明。

记忆被使用时你总会知道。Le Chat 会清楚展示它何时在回忆、回忆的内容来自哪里、为何相关。可以把它想象成可点击的消费凭证。

### 自主权。

记忆由你管理——而不是它管理你。
你可以：

- 随时关闭 Memories
- 开启不使用记忆无痕聊天
- 从日志中编辑或删除单条记忆

### 主权。

你拥有你的记忆。可以导出，也可以从别处导入。Le Chat 中的记忆在设计上就是可移植、可互通的，因为控制权不应止步于界面。

## 它能帮你做什么。

记忆让你的助手随着时间推移更有用，而又不碍事。它可以表现为：

- 回忆你上一季度如何解决过类似问题
- 翻出你遗忘的一条过往洞见
- 把你当前的问题与你在另一个会话里说过的内容关联起来

一位用户在上传 PDF 几周后就某法律政策提出后续问题，Le Chat 立刻在文档中定位到正确的章节，无需重新上传或重新解释。这种关联式回忆节省时间、让人进入心流。无需重新训练。无需推倒重来。

## 立即体验：Memory Insights。
我们推出了 [Memory Insights](https://chat.mistral.ai/memories)，一组轻量提示，帮你探索 Le Chat 记住了什么、它能怎么帮你。它们会呈现趋势、建议摘要、指出值得重温的时刻——全部基于你自己的数据，且全部可编辑。这是把记忆从被动存储变成主动信号的一种简单方式。从 [App Store](https://apps.apple.com/fr/app/le-chat-by-mistral-ai/id6740410176) 或 [Google Play](https://play.google.com/store/apps/details?id=ai.mistral.chat&hl=fr) 下载 Le Chat，在移动端体验记忆功能。

## 下一步是什么？

我们持续改进记忆的工作方式：削减噪声、加快回忆、让长期组织更容易。你很快会看到更新：把记忆归类、瞬间遗忘某个内容，以及更清楚地看到用了哪条记忆、何时使用。

在底层，我们构建了基于图（graph-based）的架构，在性能与上下文感知之间取得平衡，让记忆不只是变长，而是变聪明。AI 仍处于早期。模型会变，而且变化飞快。记忆是让你的助手锚定在你的上下文中的东西，任凭其他一切如何变迁。它不是一个功能。不是一个朋友。它是一个你可以信任、并随你成长的系统。
