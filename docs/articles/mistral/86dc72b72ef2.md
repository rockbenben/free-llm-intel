# 通过微调释放视觉语言模型在卫星影像上的潜力

微调基础模型正在改变我们把 AI 应用于现实问题的方式。把预训练模型适配到特定领域，我们能在专门任务上解锁显著更好的性能。今天，我们很高兴分享如何通过对卫星影像微调 Pixtral-12B，相对基座模型取得大幅提升，展示领域专用适配的威力。

## LoRA 微调能高效地把模型权重适配到特定任务

微调大语言模型可能很消耗资源，但 Low-Rank Adaptation（LoRA）这类技术让它高效得多。LoRA 的做法是向模型权重中注入小型、可训练的秩分解矩阵，在不修改完整模型的前提下实现定向适配。它让开发者能够把模型适配到特定任务——无论是学习领域词汇、采用特定语气，还是植入专门知识——而无须重新训练整个模型。

当 prompt 工程或少样本示例力有不逮时，这个方法尤其出彩。复杂的 prompt 会变得盘根错节、难以维护，产出不一致的结果。而基于 LoRA 的微调，用少量精心挑选的样本就能更可靠地引导模型，以更少的开销取得更好的性能。

## 卫星影像为何需要专门模型

卫星影像是一个高度专门的视觉领域，在全球经济中有关键应用。从追踪森林砍伐、监测环境变化，到发现新兴威胁，这些图像支撑着政府、农业、国防与气候科学中的高风险决策。要提取可靠的洞见，模型必须针对卫星数据独特的模式与语义精细专门化。这正是微调 Pixtral-12B 的价值——弥合通用视觉模型与领域专业知识之间的鸿沟。

## 案例研究：用 Aerial Image Dataset 对卫星图像分类

为了展示微调的影响，我们使用了 Xia 等人提出的、采用公有领域许可的 Aerial Image Dataset（AID）。这个基准要求把卫星图像分类到细致的场景类别。其中许多类别（如密集住宅区 vs 中等密度住宅区；或"center"这类含糊的词）在没有领域上下文时对通用视觉语言模型很难处理。微调为模型提供了这一上下文，从而实现更准确、更细腻的分类。

*注意：更小的专用视觉模型可能也能达到相近的性能水平。本文旨在带你走完一个用简单示例有效微调 Mistral 视觉语言模型（VLM）的流程，并展示其对基本分类指标的影响。微调更高级的应用可以包括"与图像对话"或生成图像描述等交互。*

### 未微调的 Pixtral-12B 结果尚可，但在模糊类别上力不从心

我们从传统分类设置开始：把数据集切成 8,000 个训练样本和 2,000 个测试样本。使用一个列出所有目标类别并强制结构化输出格式的 system prompt，我们得到了合理的基线结果。然而各类别之间性能差异显著，尤其那些视觉差异细微的类别。此外，由于语言模型没有被显式约束在标签集内，它偶尔会幻觉出不存在或无效的类别名，凸显了纯 prompt 方法的局限。

### 用我们的 API 与 LaPlateforme UI 微调 Mistral 模型易如反掌

为了改善这些结果，我们使用 Mistral 的[微调 API](https://docs.mistral.ai/capabilities/finetuning/text_vision_finetuning/)对 Pixtral-12B 进行微调。微调策略是：给定 system prompt 和输入图像，在 "assistant response" 中提供正确标签。这里不需要大量超参数调优，流程高效且具成本效益。

另一个选项是通过 [LaPlateforme UI](https://console.mistral.ai/build/finetuned-models) 启动微调任务。

![3](https://mistral.ai/_astro/295623e0-3b22-455d-8708-2d1bc35138ac_Z1aiYva.webp?dpl=6abbd11780b53c00082eea6f)

选择超参数

选对超参数对微调成功至关重要。一些提示：

- 学习率：从小学习率开始，避免越过最优权重。
- 批大小（batch size）：选择既能装进你的算力资源、又能提供稳定梯度的 batch size。
- Epoch：先跑一个 epoch 并监控性能。必要时可增加，但我们建议紧盯过拟合风险。

注：直接使用 Mistral 微调 API 调用能让你对超参数有更多控制。在 LaPlateforme 上你只需提供期望的学习率和 epoch 数，微调引擎会根据你的数据集大小及其内部"每批最优 token 数"基准，计算出最优 batch size。

### 微调让模型性能提升 1.6 倍

![4](https://mistral.ai/_astro/fc28729a-e565-425c-b36c-b5bb3b744be7_1hFNeM.webp?dpl=6abbd11780b53c00082eea6f)

微调后，我们观察到所有类别的分类指标发生量级跃升（如总体准确率从 0.56 提升到 0.91）。模型在不同类别间的表现更一致，幻觉显著减少（从 5% 降到 0.1%）。虽然结果不是 100% 完美，但提升是实质性的——考虑到有限的预算（≤$10）和相对少的样本量（分布在 30 个类别上的 8,000 个样本）。

## 结论

在卫星影像上微调 Pixtral-12B，证明了 LoRA 这类技术能在模型性能上取得卓越提升。这种方式不仅具成本效益、可规模化，还适合广泛的应用场景。典型例子是高度专门化、常常是专有、且在传统 VLM 训练集中欠代表的数据，例如：医学影像描述、监控图像的详尽报告、古籍抄本转写等。
