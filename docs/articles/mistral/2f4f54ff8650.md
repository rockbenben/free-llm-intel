### 亮点

- 突破性性能：在表单、扫描文档、复杂表格和手写内容上，相对 Mistral OCR 2 的总体胜率达到 74%。
- 最先进的准确率，同时超越企业文档处理方案与 AI 原生 OCR 方案
- 现在驱动 [Mistral AI Studio](https://console.mistral.ai/build/document-ai/ocr-playground) 中的 Document AI Playground——一个把 PDF/图片解析为干净文本或结构化 JSON 的简单拖放界面
- 在表单、手写内容、低质量扫描件和表格上较 Mistral OCR 2 大幅升级

### 概览

Mistral OCR 3 旨在以极高保真度从各类文档中提取文本和内嵌图像。它支持富化的 markdown 输出，可基于 HTML 重建表格，让下游系统不仅理解文档内容，还理解其结构。相比多数竞品方案，它只是一个小得多的模型，并以行业领先的价格提供：每 1,000 页 $2，配合 Batch API 的 50% 折扣可降至每 1,000 页 $1。

开发者可以通过 API 集成该模型（mistral-ocr-2512），用户也可以使用 Document AI——一个即时把文档解析为文本或结构化 JSON 的界面。

### 相对前几代 OCR 模型的升级

当今多数 OCR 方案只专精特定文档类型，而 Mistral  OCR 3 被设计为在处理组织和日常场景中的绝大多数文档类型上表现出色。

- 手写：Mistral OCR 能准确解读草书、混合内容批注，以及叠加在印刷表单上的手写文字。
- 表单：改进了对框、标签、手写填写项和密集布局的检测。在发票、收据、合规表格、政府文件等场景上表现良好。
- 扫描件与复杂文档：对压缩伪影、倾斜、畸变、低 DPI 和背景噪声显著更稳健。
- 复杂表格：重建带有表头、合并单元格、多行块和列层级结构的表格。输出带 colspan/rowspan 的 HTML 表格标签，完整保留布局。

相比 Mistral OCR 2，Mistral OCR 3 在所有语言和文档形态上都是一次显著升级。

### 推荐用例与应用

Mistral OCR 3 既适合高吞吐的企业流水线，也适合交互式文档工作流。开发者可以用它来：

- 把文本和图像提取为 markdown，供下游 agent 和知识系统使用
- 自动解析表单、发票和运营文档
- 端到端文档理解流水线
- 手写或历史文献的数字化
- 任何其他"文档 → 知识"转化的应用。

我们的早期客户正在用 Mistral OCR 3 把发票处理为结构化字段、给公司档案做数字化、从技术和科学报告中提取干净文本，以及改进企业搜索。

"OCR 仍然是使能生成式 AI 与 agentic AI 的基础设施，"IDC  AI 与自动化研究总监 Tim Law 表示。"那些能够高效、经济、高保真地提取文本和内嵌图像的组织，将通过提供更丰富的上下文来释放价值、从数据中获得竞争优势。"
