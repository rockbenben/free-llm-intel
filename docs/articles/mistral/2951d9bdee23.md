# 发布 Pixtral 12B

**注意：此模型已弃用**

Pixtral 12B 已不再维护，已被我们最新、更强大的视觉与多模态模型取代。

[了解我们当前的视觉能力](https://docs.mistral.ai/capabilities/vision)

### Pixtral 12B 速览：

- 原生多模态，以图文交错数据训练
- 多模态任务表现强劲，尤其擅长指令遵循
- 在纯文本基准上保持最先进水平
- 架构：
- 从零开始训练的全新 400M 参数视觉编码器基于 Mistral Nemo 的 12B 参数多模态解码器支持可变图像尺寸与宽高比在 128k token 的长上下文窗口中支持多张图片
- 使用：
- 许可证：Apache 2.0在 [La Plateforme](https://console.mistral.ai/) 或 [Le Chat](https://chat.mistral.ai/chat) 上试用

Pixtral 的训练目标是同时理解自然图像与文档，在 MMMU 推理基准上取得 52.5%，超越若干更大的模型。该模型在图表与插图理解、文档问答、多模态推理和指令遵循等任务上展现出色能力。Pixtral 能以图像的原始分辨率和宽高比摄入图像，让用户在处理一张图像所用 token 数上有灵活选择。Pixtral 还能在 128K token 的长上下文窗口中处理任意数量的图像。与此前的开源模型不同，Pixtral 不必为多模态任务的出色表现而牺牲文本基准性能。

![Pixtral Benchmarks](https://mistral.ai/_astro/5c571e09-ffe4-47fe-a276-c1bddcab1225_qJwPF.webp?dpl=6abbd11780b53c00082eea6f)

### 性能

Pixtral 的训练目标是成为 **Mistral Nemo 12B 的即插即用替代品**。它与现有开源模型的关键区别在于：**在不牺牲指令遵循、编码和数学等核心文本能力的前提下**，交付**同类最佳的多模态推理**。

#### 评测协议

我们使用*同一个评测 harness* 重新评测了一批开源与闭源模型。对每个数据集，我们挑选 prompt 的标准是能复现领先多模态模型（GPT-4o 和 Claude-3.5-Sonnet）的已报告结果。然后所有模型都用这同一 prompt 评测。总体而言，Pixtral 在其体量级别大幅超越所有开源模型，并在许多场景下超过 Claude 3 Haiku 这类闭源模型。在多模态基准上，Pixtral 甚至超越或持平 LLaVa OneVision 72B 这样远大于它的模型。所有 prompt 都将开源。

![Pixtral Comparison](https://mistral.ai/_astro/9bf72e1d-928e-4fa7-a331-5391ebb508d1_Zmdn4B.webp?dpl=6abbd11780b53c00082eea6f)

*Pixtral 与闭源及更大规模多模态模型的性能对比。所有模型都通过同一个评测 harness、使用同一 prompt 进行基准测试。我们验证了这些 prompt 能复现 GPT-4o 与 Claude 3.5 Sonnet 报告的性能（prompt 将随技术报告提供）。*

#### 指令遵循

与其他开源多模态模型相比，Pixtral 尤其擅长多模态与纯文本两种指令遵循。在指令遵循上它大幅超越 Qwen2-VL 7B、LLaVa-OneVision 7B 和 Phi-3.5 Vision——在文本 *IF-Eval* 与 *MT-Bench* 上比最近的开源模型相对高出 20%。为了进一步评估这一能力在多模态场景的表现，我们创建了这些基准的多模态版本：*MM-IF-Eval* 与 *MM-MT-Bench*。在多模态指令遵循基准上，Pixtral 同样超越开源替代方案。我们将把 *MM-MT-Bench* 开源给社区。

*Pixtral 与开源多模态模型的性能对比。所有模型都通过同一个评测 harness、使用同一 prompt 进行基准测试。*

### 架构

**可变图像尺寸：**Pixtral 的设计同时优化速度与性能。我们训练了一个原生支持可变图像尺寸的新视觉编码器：

- 我们只需按原始分辨率与宽高比把图像送入视觉编码器，把图像中每 16x16 patch 转换成一个 image token
- 这些 token 随后被展平成序列，行间与图像末尾分别加入 `[IMG BREAK]` 和 `[IMG END]` token。
- `[IMG BREAK]` token 让模型能区分 token 数量相同但宽高比不同的图像。

通过这种方式，Pixtral 既能高分辨率地精确理解复杂图表、图形和文档，又能在图标、剪贴画、公式等小图像上提供快速推理。

![Pixtral Architecture](https://mistral.ai/_astro/14c41c1b-f155-4d35-8427-759a6ca5692c_Z1yOwVe.webp?dpl=6abbd11780b53c00082eea6f)

*Pixtral 使用一个从零开始训练的新视觉编码器，原生支持可变图像尺寸。*

**最终架构：**Pixtral 由两个组件构成：对图像做 token 化的视觉编码器（Vision Encoder），以及在给定图文序列时预测下一个文本 token 的多模态 Transformer 解码器（Multimodal Transformer Decoder）。模型在图文交错数据上训练以预测下一个文本 token。该架构让 Pixtral 能在 128K token 的大上下文窗口中处理任意数量、任意尺寸的图像。

![Pixtral Model Architecture](https://mistral.ai/_astro/8ae163bf-f96b-4ed8-b8de-06a82d95f54b_ZE0EzY.webp?dpl=6abbd11780b53c00082eea6f)

### 图表理解与分析

![Loss Curve](https://mistral.ai/_astro/c01d3c14-2857-4d73-8d49-b8adca72d26a_XOBRH.webp?dpl=6abbd11780b53c00082eea6f)

**Prompt：**

dark dragon 从什么时候开始出问题？

**Response：**

这张图是标题为 'train/loss' 的折线图，展示了四个不同模型（dark-dragon-50、dainty-sunset-49、different-haze-34、morning-field-33）训练损失随步数的变化。x 轴表示步数，范围从 0 到 60k；y 轴以对数刻度表示 loss，范围从 1e-5 到 1e+5。

要判断 dark-dragon-50 模型从何时开始出问题，需要看代表该模型的红线。损失起初下降，表明模型在有效学习。然而大约在 10k 步附近，损失开始剧烈飙升。这一飙升说明模型性能正在恶化。损失持续飙升波动、达到非常高的数值，表明模型已不再有效学习，很可能过拟合或遇到了其他问题。

因此，dark-dragon-50 模型开始出问题的临界点大约在 10k 步附近。

### 如何运行 Pixtral？

#### Le Chat

你可以通过 [Le Chat](https://chat.mistral.ai)——我们友好的对话式聊天界面——轻松免费地试用 Pixtral。在模型列表中选择 Pixtral，上传一张图像，然后就可以开始针对图像提问。

#### La Plateforme

Pixtral 也在 La Plateforme 上提供。你可以通过 API 调用发挥 Pixtral 的能力，与各种应用和工作流无缝集成。下面是一个简单示例。更多细节见我们的[文档](https://docs.mistral.ai/capabilities/vision/)。

```
curl https://api.mistral.ai/v1/chat/completions \  -H "Content-Type: application/json" \  -H "Authorization: Bearer $MISTRAL_API_KEY" \  -d '{    "model": "pixtral-12b-2409",    "messages": [      {        "role": "user",        "content": [          {            "type": "text",            "text": "What’s in this image?"          },          {            "type": "image_url",            "image_url": "https://tripfixers.com/wp-content/uploads/2019/11/eiffel-tower-with-snow.jpeg"          }        ]      }    ],    "max_tokens": 300  }'
```

#### vLLM

如果你选择在本地服务 Pixtral，我们也推荐把 Pixtral 与 [vLLM 库](https://github.com/vllm-project/vllm)搭配使用，这是达到更高服务吞吐的极佳选择。感谢 vLLM 团队支持了 Pixtral 的快速集成。下面是一个简单的使用示例。更多信息见[这里](https://huggingface.co/mistralai/Pixtral-12B-2409)。

```
from vllm import LLMfrom vllm.sampling_params import SamplingParams
model_name = "mistralai/Pixtral-12B-2409"
sampling_params = SamplingParams(max_tokens=8192)
llm = LLM(model=model_name, tokenizer_mode="mistral")
prompt = "Describe this image in one sentence."image_url = "https://picsum.photos/id/237/200/300"
messages = [    {        "role": "user",        "content": [{"type": "text", "text": prompt}, {"type": "image_url", "image_url": {"url": image_url}}]    },]
outputs = vllm_model.model.chat(messages, sampling_params=sampling_params)
print(outputs[0].outputs[0].text)
```
