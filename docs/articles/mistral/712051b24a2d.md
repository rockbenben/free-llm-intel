Mistral AI 持续践行其使命：把最佳开放模型交付给开发者社区。AI 要向前，就必须在复用知名架构和训练范式之外走出新的技术转向。更重要的是，它需要让社区从原创模型中受益，以孕育新的发明和新的用法。

今天，团队骄傲地发布 Mixtral 8x7B，一个高质量的开放权重稀疏专家混合模型（SMoE）。以 Apache 2.0 许可。Mixtral 在多数基准上超越 Llama 2 70B，而推理快 6 倍。它是采用宽松许可证的开放权重模型中最强者，也是成本/性能权衡意义上的整体最佳模型。特别地，在多数标准基准上它与 GPT3.5 持平甚至更优。

Mixtral 具备以下能力。

- 它能从容处理 32k token 的上下文。
- 它支持英语、法语、意大利语、德语和西班牙语。
- 它在代码生成上表现强劲。
- 它可以被微调成在 MT-Bench 上得分 8.3 的指令遵循模型。

#### 用稀疏架构推进开放模型的前沿

Mixtral 是一个稀疏专家混合网络。它是一个仅解码器（decoder-only）模型，其中前馈层从 8 组不同的参数集合中选取。在每一层，对每个 token，一个路由网络选择其中两组（即"专家"）来处理该 token，并将它们的输出相加合并。

这项技术由于每个 token 只使用全部参数集中的一小部分，因此在控制成本和延迟的同时增加了模型的参数量。具体来说，Mixtral 总参数 46.7B，但每个 token 仅使用 12.9B 参数。因此，它处理输入和生成输出与一个 12.9B 模型速度相同、成本相同。

Mixtral 在从开放网络提取的数据上预训练——我们同时训练专家和路由器。

#### 指令模型

我们在发布 Mixtral 8x7B 的同时发布 Mixtral 8x7B Instruct。该模型通过监督微调和直接偏好优化（DPO）进行了精心指令遵循的优化。在 MT-Bench 上达到 8.30 分，使其成为最佳开源模型，性能与 GPT3.5 相当。

注：可以通过巧妙提示 Mixtral，禁止某些输出，用于对审核强度有要求的应用构建，示例见[此处](https://docs.mistral.ai/platform/guardrailing)。合适的偏好调优也能达到这一目的。请牢记，若没有此类提示，模型只会照所给的指令执行。

#### 用开源部署栈部署 Mixtral

为了让社区能用完全开源的技术栈运行 Mixtral，我们已向 vLLM 项目提交了更改，其集成了用于高效推理的 Megablocks CUDA kernels。

Skypilot 允许在云上任意实例上部署 vLLM 端点。
