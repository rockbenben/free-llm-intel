### 消除人工撰写 PRD 与工程任务的瓶颈

从最初的产品讨论到实际开发，通常要经过多个人工步骤：

- 转录会议。
- 起草产品需求文档（PRD）
- 创建一条条工程工单

产品经理常常要花数小时把原始会议笔记整理成结构化文档，工程师则浪费宝贵时间解读需求、把它拆解成可执行的任务。随着组织规模扩大、产品项目数量增长，这一流程会形成瓶颈。

但如果我们能自动化整个工作流呢？如果我们能拿一份会议转录，自动生成一份完整的 PRD 和一组可执行的开发工单？这不仅节省时间，还能确保文档一致、团队之间对齐更好。

### 用 AI agent 自动化 PRD 与工程工单生成

设想典型的产品规划周期。利益相关方开会讨论新功能，但后续的文档撰写和任务创建消耗了大量本可用于实际开发的宝贵时间。通过实施自动化的 agentic 工作流，团队可以大幅削减这一开销。

使用我们由 Mistral AI LLM 驱动的 TranscriptToPRDTicket agentic 工作流，我们构建了一套系统。该系统自动处理会议转录、生成详细的产品需求文档（PRD），并创建可执行的开发工单。这套端到端的自动化确保团队能以最少的人工介入从讨论直达开发。

### 用 Mistral AI 构建高效的 agentic 工作流

![Diagram PRD Pipeline](https://mistral.ai/_astro/e46ccb7f-6602-4d31-9391-048eb35ef529_1quvHf.webp?dpl=6abbd11780b53c00082eea6f)

图 2：TranscriptToPRDTicket agentic 工作流

我们的 agentic 方案核心由两个关键组件构成：PRDAgent 和 TicketCreationAgent，均由最先进的大模型 Mistral Large 2 驱动。工作流遵循清晰的推进路径：

- [会议转录](https://github.com/mistralai/cookbook/blob/main/mistral/agents/transcript_linearticket_agent/lechat_product_call_trascript.pdf)作为输入，记录利益相关方的原始讨论。
- PRDAgent 处理这些转录，生成完整的 PRD。
- TicketCreationAgent 把 PRD 内容转换为结构化的开发工单。
- 系统自动在 Linear / Jira 等项目管理工具中创建工单。

这条自动化流水线确保一致性与可追溯性，同时大幅减少人工投入。整个过程由 Mistral AI 先进 LLM 的理解能力与结构化输出机制编排。工作流末端，它会在 Linear 等项目管理工具中自动生成结构化工单，如下图所示。

### 为什么选 Mistral AI？

Mistral AI 的 LLM 凭借强大的自然语言理解与结构化输出能力，为这一 agentic 工作流提供了理想底座。我们的工作流利用 Mistral Large 2 来：

- 以高级自然语言处理精准解读会议转录。
- 智能生成 PRD，内置反馈机制以持续打磨。
- 结构化输出格式，确保任务创建可靠。
