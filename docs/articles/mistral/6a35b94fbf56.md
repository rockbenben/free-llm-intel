# 说到 Voxtral

今天我们发布 Voxtral TTS，我们的首个文本转语音模型，在多语言语音生成上达到最先进表现。模型仅 4B 参数、轻盈小巧，让 Voxtral 驱动的 Agent 自然、可靠，并在规模上经济可负担。

## 亮点。

- 在 9 种常用语言中生成真实、富有情感表达力的语音，支持多样方言。
- 首音频生成时间（time-to-first-audio）延迟极低。
- 轻松适配新声音。
- 可在 [Mistral Studio](https://console.mistral.ai/build/audio/text-to-speech) 中测试。
- 企业级文本转语音，为关键语音 Agent 工作流提供动力。

自然的语音生成取决于模型不仅要"念出"文本，还要准确"解读"文本的能力。上下文理解——中性、开心、讽刺等——决定听者认为生成结果是准确还是机械。我们的模型在上下文理解与说话人建模两方面都表现出色：捕捉特定的人自然的说话方式。我们的声音适配超越传统的朗读式语音，能捕捉说话人的个性，包括其自然停顿、节奏、语调和情感拿捏。凭借紧凑的体积、低成本、低延迟与易适配性，Voxtral TTS 为希望掌控自有语音 AI 技术栈的企业提供完全的控制与定制。

音频就是新的 UX。创造只有在语音中才存在的协作与理解的新交互。现在就在 AI Studio 中用我们的 Mistral Voices 开始——含美式、英式和法式方言。

## 最先进的性能。

词错误率、音频质量分等自动化指标，无法衡量多语言文本转语音系统的"自然度"。语音之所以自然，靠的是极其细腻的把握，需要对文化差异和典型说话模式的深入理解。因此，由母语者完成的对比性人类评估至关重要。

对语音 Agent 而言，延迟与质量始终相互拉扯。人类评估显示，Voxtral TTS 相比 ElevenLabs Flash v2.5 达到更高的自然度，同时保持相近的首音频时间（TTFA）。Voxtral 的声音质量也与 ElevenLabs v3 并驾齐驱，并成功支持情绪引导（emotion-steering），让交互更栩栩如生。

![Voxtral TTS Winrate (1)](https://mistral.ai/_astro/16f25438-cacc-4786-8de7-7852ad0929d4_Mtc6m.webp?dpl=6abbd11780b53c00082eea6f)

我们在零样本定制声音场景下对 Voxtral TTS 与 ElevenLabs v2.5 Flash 进行了对比性人类评估。在 9 种支持语言中，每种语言使用其原生方言的两个可辨识声音，由 3 名标注员对每一对样本就自然度、口音还原和与原始参考的声音相似度做同场偏好测试。在这种零样本多语言定制声音设置下，Voxtral TTS 拉大了对 v2.5 Flash 的质量差距，凸显了 Voxtral TTS 对任意声音的即刻可定制性。

## 母语级发音。

Voxtral TTS 在大规模语音数据集上训练，为全球应用而生。它在 9 种语言上支持最先进性能：英语、法语、德语、西班牙语、荷兰语、葡萄牙语、意大利语、印地语和阿拉伯语。

模型被训练为用短至 3 秒的参考即可适配定制声音，捕捉的不只是音色，还有微妙口音、屈折、语调，甚至与参考中相似的口误停顿。我们在 API 中提供一些预设声音选项，同时也可以轻松扩展到你自有的声音库：按用例定制、按语言与口音本地化、保持中性或更富情感、随意或正式、更自然对话感或更机械。

模型还展示了零样本跨语言声音适配能力——尽管并未为此显式训练。例如，模型可以用电声音生成带法语口音的语音：提供法语的声音 prompt 和英语文本。生成的语音听起来自然，同时带上所提供声音 prompt 的口音（在本例中，生成的是带自然法国口音的英语）。这使该模型适合构建级联的语音到语音翻译系统。

## 为低延迟流式而生。

延迟对语音 Agent 应用至关重要。对典型的 10 秒、500 字符输入声音样本，Voxtral TTS 的模型延迟为 70ms，实时率（RTF）约 9.7x。模型原生可生成长达两分钟的音频，我们的 API 通过智能交错处理支持任意长度的生成。

## Voxtral TTS 架构。

该模型是一个基于 transformer 的自回归 flow-matching 模型，构建于 [Ministral 3B](https://docs.mistral.ai/models/ministral-3-3b-25-12) 之上。它由以下组件构成：

- 3.4B 参数的 transformer 解码器主干
- 390M 参数的 flow-matching 声学 transformer
- 300M 参数的神经音频 codec（对称编码-解码）

模型接收声音 prompt（5 到 25 秒）与 9 种支持语言之一的文本 prompt。对每个音频帧，transformer 主干预测一个语义 token，随后 flow-matching transformer 运行 16 次函数评估（NFE）生成声学隐变量。

我们自研了 codec：使用语义 VQ（词表 8192）与声学 FSQ（36 维、21 层）隐变量，以因果方式处理音频，并以 12.5Hz 帧率产出。

## 驱动企业语音工作流。

Voxtral TTS 闭合了音频智能的回路，为企业语音管线提供一层能通过"人类检验"的输出。它与 [Voxtral Transcribe](https://mistral.ai/news/voxtral-transcribe-2) 协同实现完整的语音到语音，也可集成进任何现有的语音转文本与 LLM 技术栈，并带跨语言支持。

### 客户支持

语音 Agent 以自然、契合品牌的语音跨渠道路由并解决咨询。把 Voxtral TTS 放入现有客服呼叫系统实现自动语音应答，输出可接入现有工作流。

示例（Jane）："感谢联系技术支持。我看到您对 3 月 22 日那笔意外扣款的疑问。我来调出您的账户详情。啊，找到了。这似乎是您申请订阅升级时产生的临时冻结。您希望我取消冻结，还是调整您的套餐？您的来电对我们很重要，在问题解决之前我会一直在线。"

### 金融服务

语音驱动的账户更新、交易确认、欺诈警报与贷款状态通知。把例行咨询自动化以减轻人工客服负担，同时保持自然、与信任场景相称的语气。

示例（Tom）："您的账户已成功更新。转到您储蓄账户的那笔 150 美元交易已处理完毕。出于安全考虑，我们已向您的注册设备发送了确认码。如果这不是您本人的操作，请立即联系我们。"

### 制造与工业运营

向离不开工位的操作工免提播报作业指导书、检验提示与机器状态警报。语音更新可集成进现有 MES 与车间系统，保障生产持续运转。

示例（John）："注意！4B 号机器需要维护。请检查液压系统并立即上报任何泄漏。当前节拍时间延迟 12 分钟。重新启动前等待您的确认，John。"

### 公共服务与政府

面向市民的语音交互：预约排期、许可状态、福利咨询与紧急通知，以多语言服务多元人群。

示例（Jane）："这里是市政府自动服务。您的许可申请 2024-789 已获批准。您可以在上午 9 点至下午 5 点间到办公室领取文件。紧急情况请拨打 911。"

### 合规与风控

实时通话监控、KYC/AML 自动化、带说话人归属的审计追踪。自动播报必需的披露与监管话术，确保跨行业一致、逐字合规。

示例（Peter）："为符合监管要求，我们需要核实您的身份。请说出您的全名、出生日期，以及社会安全号码的最后四位。本次通话正在录音，用于质量保证。"

### 供应链与物流

自动化语音更新：库存管理、货运跟踪与交付通知。为员工与司机提供实时信息。

示例（Jake）："注意，你的下一个取货点在 3 号码头。该批货包含 20 托盘电子产品，预估重量 1200 公斤，预计 2 小时后到达目的地。请确认签收。"

### 汽车与车载系统

为导航、安全警报与免提通信提供自然的语音引导。清晰适配驾驶场景——那些不便看屏的时刻——的语音输出。

示例（Paula）："警告。检测到车辆处于您的盲区。车道偏离警报。请修正方向。当前限速为每小时 65 英里。"

### 销售与市场

为个性化信息提供一致的品牌声音，跨语言复刻让同一声音走遍多个市场。适用于配音、旁白、译制内容、播客，以及内部和对客户的资讯内容。

示例（Oliver）："体验下一代可靠性能，功能设计超越您的期待。经久耐用、能耗更低，为您交付可依赖的稳定结果。现以特别尝鲜价发售，不要错过提升日常运营的机会。"

### 实时翻译

跨 9 种语言的语音到语音翻译，服务跨境运营、活动与内部内容，在目标语言中保留说话人的口音与身份。

示例（Marie，英语）："In English, this definitely won't work. I need a refund for sure."

（法语）："En français, ça ne marchera définitivement pas. Je suis sûre d'avoir droit à un remboursement."

（意大利语）："In italiano, questo non funzionerà di sicuro, ho proprio bisogno di un rimborso."
