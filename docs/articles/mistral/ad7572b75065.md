Mistral AI 把最强的开放生成模型交到开发者手中，并提供高效的部署与定制方式，用于生产环境。

今天我们开放[首批平台服务](https://console.mistral.ai)的 beta 访问。我们从简做起：la plateforme 提供三个聊天端点，用于按照文本指令生成文本，另有一个嵌入（embedding）端点。每个端点都有不同的性能/价格权衡。

#### 生成端点

前两个端点 mistral-tiny 和 mistral-small 目前使用我们已发布的两个开放模型；第三个 mistral-medium 使用一个性能更高的原型模型，我们正在部署环境中对其进行测试。

我们提供模型的指令版（instructed versions）。我们致力于整合最有效的对齐技术（高效微调、直接偏好优化），打造易于控制、使用愉悦的模型。我们在从开放网络提取的数据上预训练模型，并基于人工标注进行指令微调。

**Mistral-tiny**。我们性价比最高的端点目前提供 Mistral 7B Instruct v0.2，这是 Mistral 7B Instruct 的一个新的次要版本。Mistral-tiny 仅支持英语。它在 MT-Bench 上获得 7.6 分。指令模型可在[此处](https://huggingface.co/mistralai/Mistral-7B-Instruct-v0.2)下载。

**Mistral-small**。该端点目前提供我们最新的模型 Mixtral 8x7B，更多细节见我们的[博客文章](https://mistral.ai/news/mixtral-of-experts/)。它精通英语/法语/意大利语/德语/西班牙语和代码，在 MT-Bench 上获得 8.3 分。

**Mistral-medium**。我们质量最高的端点目前提供一个原型模型，按标准基准衡量，它当前位居已提供服务的模型前列。它精通英语/法语/意大利语/德语/西班牙语和代码，在 MT-Bench 上获得 8.6 分。下表对比了 Mistral-medium、Mistral-small 的基础模型与某竞争对手端点的性能。

#### 嵌入端点

Mistral-embed，我们的嵌入端点，提供一个 1024 维的嵌入模型。我们的嵌入模型是围绕检索能力设计的。它在 MTEB 上取得 **55.26** 的检索得分。

#### API 规格

我们的 API 遵循由我们"最亲爱的"竞争对手最初提出的流行聊天界面规范。我们提供 Python 和 Javascript 客户端库来调用端点。我们的端点允许用户提供系统提示词，为模型输出设置更高强度的审核，满足有此重要要求的应用场景。

#### 从 beta 访问逐步走向全面可用

从今天起，任何人都可以[注册](https://console.mistral.ai)使用我们的 API，因为我们在逐步提升容量。我们的商务团队可以帮助你梳理需求并加速开通。在平台朝着完全自助式可用稳步成熟的过程中，请预期会有一些粗糙之处。
