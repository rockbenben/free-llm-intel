## 市面上已有其他 AI 助手，为什么选 le Chat？

### 快如 Flash

le Chat 由性能最强、延迟最低的 Mistral 模型，以及地球上最快的推理引擎驱动。它的推理、思考与响应速度超过任何其他聊天助手，最高可达约 1000 词/秒。我们把这一功能称为 [*Flash Answers*](https://help.mistral.ai/en/articles/268659-flash-answers)，目前面向所有用户开放预览。

### 扎根于多样信息

Le Chat 将 Mistral 模型高质量的预训练知识，与在 [网页搜索](https://help.mistral.ai/en/articles/267605-web-search)、可靠的[新闻业](https://mistral.ai/news/mistral-afp/)、社交媒体及多个其他来源之间均衡取样的最新信息相结合，给出细致且有证据支撑的回答。

### 全球顶尖的上传处理能力

Le Chat 的[图像](https://help.mistral.ai/en/articles/268648-image-understanding)与[文档](https://help.mistral.ai/en/articles/268650-document-understanding)理解能力，由业内最佳的视觉与光学字符识别（OCR）模型驱动，确保在处理 PDF、电子表格、日志文件以及复杂——有时甚至难以辨认的图像等各类任意格式文件时保持高精度。

### 就地代码执行与分析

我们还为 Le Chat 引入 [*Code interpreter*](https://help.mistral.ai/en/articles/268657-code-interpreter)，用户可以执行沙箱代码、进行科学分析、创建可视化并运行模拟。这一功能使 le Chat 成为验证算法和探索数据洞见的实用工具。

### 最先进的图像生成

Le Chat 的[图像生成](https://help.mistral.ai/en/articles/268651-image-generation)由 Black Forest Labs Flux Ultra 驱动，它是当前领先的图像生成模型。用 Le Chat 生成你能想象的一切：从写实照片级图像，到可分享的内容和企业创意物料。
