## Le Chonk

今天，我们发布 Mistral Large 4 的[公开预览](https://docs.mistral.ai/models/mistral-large-4)。非官方简称 ML4，非常官方的名字则是：*le Chonk*。ML4 把开放权重（open-weight）模型的性能推向前沿。你今天就可以在 [Mistral Studio](https://console.mistral.ai/) 上试用 preview API。权重将于本月底放出。

## 前沿性能

ML4 是一个 1 万亿参数、原生多模态的模型，激活参数为 490 亿。它是我们迄今最大、能力最强的模型，并且随着我们持续打磨，它还在快速进步。

该模型在编码、agentic 工作流与多模态理解上表现出卓越性能。它已经达到了与全球最强开源模型相当的性能，同时显著超越任何在美国或欧洲开发的开放权重模型。在网络安全、金融与法律等关键企业工作负载上，我们发现它是开放模型中的 state-of-the-art。在视觉定位（visual grounding）等某些领域上它走得更远，甚至超越了前沿的闭源模型。

我们将在本月底前发布权重。在此之前，我们正与网络安全领域的领军者、经审核的合作伙伴以及国家机构一起，在真实环境中对该模型进行 red-teaming，这些方将访问同一个降低审核、扩展网络能力的版本。

** DeepSWE v1.1、Terminal-Bench 4.0 与 SWE-Atlas-QnA 上的分数采用 Artificial Analysis 在该评测 harness 公开发布前私下评估的数字，这些结果将在 harness 发布后纳入 Artificial Analysis Coding Agent Index。*

## 锻造于欧洲。为 AI 主权而生。

ML4 从零开始训练，使用 3,800 块 NVIDIA Grace Blackwell GPU，位于 Mistral 自有的欧洲数据中心。公开预览就运行在同一套基础设施上。这是我们在基础设施、研究与产品开发上的长期投入的一个重要里程碑：在关键垂直领域提供 state-of-the-art 性能，通过开放权重交付，旨在让客户掌握对自己 AI 的控制权。

这在网络安全领域尤为重要：提供方层面的拒答可能阻碍合法的漏洞研究和事件响应，而在事件处置中途失去某项能力本身就会演变成严重的安全风险。ML4 把顶级的网络能力与开放权重、自部署结合在一起，让组织既有能力、也有自主权，按照自己的政策开展高级安全工作。

该模型将在全球多个 region 提供，其中包括一套由 Mistral 端到端运营的欧洲部署——独立于其他数字服务提供商，并受欧洲法律管辖。一个有趣的细节：ML4 的训练数据中有相当大比例是多语言的，覆盖 160 多种语言，包括欧洲联盟的全部官方语言。

我们与世界各地的金融、工程、制造、物流、制药、科学、航运、公共部门及其他关键任务行业的领先企业密切合作来训练 ML4。事实上，该模型使用的训练、定制与 RL environment，正是我们通过 [Mistral Forge](https://mistral.ai/products/forge/) 提供给客户的同一套。

## 今天就试试它

后面还有更多。在发布权重之前，我们会分享关于模型架构、更多 benchmark 以及我们 post-training 方法论的进一步细节。

该模型还将成为新一代专业化、深度优化的 Mistral 模型的基础。在此期间，我们邀请你[试用 preview API](https://docs.mistral.ai/models/mistral-large-4-0)，并在社交媒体上与我们分享反馈。

## 能力详解

### 网络安全

ML4 是全球最强的网络安全 AI 模型之一。在 Artificial Analysis Cyber Index——一项独立评估 AI 模型在真实软件中发现并修复安全缺陷能力的评价——它位列全球前五，并大幅领先于中国以外开发的开放权重模型。在该 index 的一项测试中（要求模型在开源软件中复现一个真实漏洞、然后修补它），ML4 得分 82%，为所有模型中最高。它还解出了 Cybench（取自安全竞赛的 40 道题）中 93% 的题目，是开放权重模型中有记录的最高分之一。

这个最高分反映了一个务实的优势。若干领先的闭源模型，包括 Claude Opus 5.5 和 GPT-6 Astra，在同一测试上得分接近零，因为它们拒绝执行该任务。然而守护软件往往始于证明一个漏洞真实存在——这正是闭源模型的安全过滤器可能拦截的那类工作。随着威胁行为者越来越多地对同样的模型实施 jailbreak 以支持攻击性网络活动，这一点变得更加重要：防御者需要能与这些能力匹敌、又不受同样拒答机制约束的系统。ML4 能做这类工作，而且它的能力超出了其显式训练的范围：在内部测试中，它被证明对恶意软件分析、漏洞优先级排序和编写检测规则都很有用。对于需要主权、可审计 AI 来做安全运营的组织，它将能够运行在私有云或 on-premise 环境。

### Agentic 编码

ML4 在软件工程、代码仓库理解和复杂终端工作流上表现出色：DeepSWE v1.1 得分 61.7%，SWE-Atlas-QnA 得分 59.4%，Terminal-Bench 4 得分 28.3%。其 Coding Agent Index 综合得分 49.8%，领先于 DeepSeek V4 Pro 0813 和 Qwen3.8 Max。

** DeepSWE v1.1、Terminal-Bench 4.0 与 SWE-Atlas-QnA 上的分数采用 Artificial Analysis 在该评测 harness 公开发布前私下评估的数字，这些结果将在 harness 发布后纳入 Artificial Analysis Coding Agent Index。*

我们还与 Surge AI 合作进行了一次模型身份隐藏的盲测人类评估，比较编码质量：专业标注者按 1–5 分制为模型输出打分。ML4 Preview 在五款模型中排名第二（3.74），领先于 Kimi K3（3.59）、GLM-5.3（3.60）和 GLM-5.2（3.40），仅次于 Claude Opus 5（4.22）。

#### Agentic Workflows

ML4 能运行通用 agent，在复杂工作流中收集信息、使用工具并产出成品交付物。在 AutomationBench——覆盖 Gmail、Google Sheets、Slack、Salesforce 等应用的 657 个业务工作流——上得分 59.9%，领先于 Kimi K3、MiMo-V2.6-Pro 和 DeepSeek V4 Pro。

在知识工作实际产出的专业交付物——电子表格、幻灯片和 PDF——上它同样强劲。在评估长周期知识工作的 AA-Briefcase 上，它达到 1,393 Elo，领先于 DeepSeek V4 Pro。

#### 多模态

ML4 是我们模型理解图像能力的一次阶跃式提升。它能在复杂文档、图表与自然图像上进行强有力的推理，并把视觉能力带到感知至关重要的行业，如工程、制造与地球观测。

该模型还能把视觉定位与 agentic 能力相结合：从检视 gigapixel 级卫星图像——在分秒必争时帮助救灾团队行动——到分析工程图纸——放大、检视、验证，直到答案精确为止。在上面的演示中，ML4 对密集自然场景做定位、在技术图纸中验证机械零件、从 PDF 中检索证据，并在超大地理空间图像中扫描最难找到的目标。

尤其在 visual grounding 上，我们发现 ML4 是我们测试过的最强模型之一，例如在 Dense 200 上超过 GPT-6-Astra（42% vs 41%）。

#### 科学与数学

ML4 带来强劲的科学能力，由 AI 驱动的方法与我们研究人员在数学、物理和化学方面的专长结合锻造而成。

它在科学任务的 agentic 编码上极为娴熟，如数据分析、建模和物理现实模拟，这让研究者可以专注于问题本身而不是杂活。在 benchmark 上，ML4 在 SciCode-Verified 上是开放权重模型中的 state of the art。在实际使用中，它能一次性生成完整的 Hartree–Fock 模拟——一个由一系列高级例程构成的复杂多步化学任务。

ML4 的数学也更强，无论形式推理还是应用数学。在我们的人类评估中，它比 GLM-5.3 推理更精确、更有条理，并且能持续完成长的、领域特定的应用数学任务，包括与前沿理论物理相关的工作。

这些能力结合起来，使 ML4 成为覆盖完整技术工作流的强力研究助手——从第一个问题到最终结果。

## 知识工作

ML4 是我们应对专业人士每天实际任务的最强模型。它能创建、编辑和修复复杂的电子表格与文档，在法律与金融 benchmark 上都表现出堪称典范的性能。

值得注意的是，我们由第三方评估方（[vals.ai](http://vals.ai)）在代表性的法律与金融任务上评估了 ML4，发现模型在两方面都超过 GPT-6-Astra。在 HarveyAI 的 Legal Agent benchmark 上，ML4 优于所有开源模型。

*FinWorkBench 在真实金融与会计用例上测试模型创建/编辑电子表格的能力。*

财务分析要求精确，并要求从多个来源综合信息，而这一过程如今在许多金融机构仍然耗时。在这个演示中，ML4 与其他顶级 OSS 模型接受同一个多步公司财务挑战：检索上市公司公告与财务报告，例如 EDGAR 及等效欧洲数据库中可得的资料。一张动态语义地图追踪每个模型走向解答的旅程，标出沿途检索到的每份文档。每条轨迹的位置反映所收集的证据、计算结果，以及仍未解决的问题。观众可以跟随调查如何展开，并比较各模型在得出最终答案前走的不同路径。

## 模型安全

ML4 在我们的间接 prompt injection 鲁棒性 benchmark 上已经饱和，使其位居 OSS 模型前沿（对比 GLM-5.2、GLM-5.3、Kimi-K2.6、Kimi-K3、DS-V4-Pro-0813）。在 Lakera 公开的 [B3 AI Security Benchmark](https://huggingface.co/datasets/Lakera/b3-agent-security-benchmark-weak) 上，ML4 抵御了 93.3% 的攻击——我们没有看到任何竞品得分更高。

ML4 与用户的互动也比我们此前任何模型都更负责任。我们在 [KORA Benchmark](https://korabench.ai/) 上的结果值得一提，ML4 再次创下我们在 OSS 模型中测得的最高分（1.691，满分 2 分标记为“*Exemplary*”）。

特别相关的是模型对网络安全方面恶意请求的拒答倾向。尽管在 Cyber benchmark 上性能强劲，但模型在来自 [JailbreakBench](https://jailbreakbench.github.io/)、[StrongREJECT](https://huggingface.co/datasets/walledai/StrongREJECT) 和 [AgentHarm](https://huggingface.co/datasets/ai-safety-institute/AgentHarm) 的 cyber prompts 上的平均拒答率高于所有 OSS 模型。

### 人类评估

我们进行了一次内部评估，由编码、计算机辅助设计（CAD）、金融、数学与物理领域的专家标注员将 Mistral Large 4 与 GLM-5.3 对比。在 CAD 与 STEM 上 ML4 更受偏好，在金融与编码上与 GLM-5.3 持平或接近。

## 规模化强化学习

基础模型进步飞快，我们的 post-training 必须跟上节奏。为昨天的模型调好的配方放到今天的 frontier 模型上就会浪费能力，因为曾经能把模型逼到极限的 ground truth 样本现在不再能了。我们使用强化学习（RL），因为它会随模型一起自适应：我们在模型自身尝试的结果上训练，并且可以随着它变强而提高任务的难度和广度。

我们的 RL 库在设计上让新 environment 易于添加并规模化训练。一套共享、可组合的接口让单次训练可以组合从单轮聊天、复杂科学问题求解到安全对齐、事实性、长周期工具使用的各类任务。这些 environment 共用脚手架与资源，例如代码沙箱、web 搜索和外部 API。同样的可组合性延伸到验证：reward model、单元测试、LLM judge 与静态检查按每个任务的需要组合。

在运行时，一个自动扩缩的 actor 集群并行生成数万个 rollouts，同时模型训练异步推进。生成与训练管道针对长轨迹做了优化，支持跨多次 compaction、达数百万 token 的 rollout 预算，同时保持很低的 staleness。贯穿两个阶段的创新方法与优化最大限度地减少了 off-policy drift，使长周期的稳定 RL 成为可能。

在我们当前的规模（3k GPU）下，单次训练约产出 **每天 330 亿 tokens**，其中经过过滤与 masking 后约 **160 亿可训练 completion tokens**。我们可以直接从训练 rollouts 中看到训练进度：随着 policy 学会解决越来越复杂的任务，几个代表性 environment 上的训练奖励持续上升。下面是几个例子。

## 接下来

这只是开始。ML4 是由我们 30 亿欧元 Series D——欧洲科技公司史上最大一轮股权融资——资助的路线图上的第一个里程碑。这笔资金已经在发挥作用：我们正在自有欧洲数据中心大幅扩充算力，未来几个月还会有更多上线。

更多算力意味着更多训练。支撑这次 preview 的强化学习仍在进行中，模型毫无饱和迹象——前面还有可观的空间。随着我们在扩容后的基础设施上加大训练规模，我们预计未来数周至数月会出现大幅且快速的进步。

我们将在本月底前发布权重，同时公布架构细节、更多 benchmark 与 post-training 方法论。而 ML4 只是地基：它将作为新一代专业化、深度优化的 Mistral 模型的基础，为客户最关心的行业与工作负载而造。

从此处开始的进步节奏将会很快。敬请期待。
