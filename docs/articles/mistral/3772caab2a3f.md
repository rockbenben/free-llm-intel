# 发布 Mistral 3

今天我们发布 Mistral 3，Mistral 模型的下一代。Mistral 3 包括三个最先进的小型 dense 模型（14B、8B 和 3B），以及 Mistral Large 3——我们有史以来最强的模型——一个以 41B 激活、675B 总参数训练的稀疏 mixture-of-experts 模型。所有模型均以 Apache 2.0 许可证发布。以多种压缩格式开源我们的模型，赋能开发者社区，并通过分布式智能把 AI 交到人们手中。

Ministral 模型代表了其类别中最佳的性价比。同时，Mistral Large 3 跻身前沿指令微调开源模型之列。

## Mistral Large 3：最先进的开源模型

![Chart Base Models (1)](https://mistral.ai/_astro/98aeee04-e1c3-43b7-b90e-c51da84d5e56_ZdKC34.webp?dpl=6abbd11780b53c00082eea6f)

![3 Model Performance Comparison (instruct)](https://mistral.ai/_astro/bdf27a12-76fd-4e62-be9b-938f14288a9a_ZqfLXe.webp?dpl=6abbd11780b53c00082eea6f)

Mistral Large 3 是全球最好的宽松许可开放权重模型之一，在 3000 块 NVIDIA H200 GPU 上从零开始训练。Mistral Large 3 是自开创性的 Mixtral 系列以来 Mistral 的首个 mixture-of-experts 模型，代表着 Mistral 预训练的实质性跃升。post-training 之后，该模型在通用提示上与市场上最佳的指令微调开放权重模型并驾齐驱，同时展示了图像理解能力，并在多语言对话（即非英/中文）上取得同类最佳表现。

Mistral Large 3 在 [LMArena 排行榜](https://lmarena.ai/leaderboard/text)的开源非推理模型类别中位列第 2（在全部开源模型中排名第 6）。

![Lm Arena Chart Ml3](https://mistral.ai/_astro/4626af3d-7554-4d50-9c0e-041fe7111ece_Z1qTh5k.webp?dpl=6abbd11780b53c00082eea6f)

我们以 Apache 2.0 许可证发布 Mistral Large 3 的 base 版本和指令微调版本，为企业与开发者社区的进一步定制提供坚实底座。推理（reasoning）版本即将推出！

### Mistral、NVIDIA、vLLM 与 Red Hat 联手，让 Mistral 3 更快、更易得

通过与 vLLM 和 Red Hat 协作，Mistral Large 3 对开源社区非常友好。我们发布了一个用 [llm-compressor](https://github.com/vllm-project/llm-compressor) 构建的 NVFP4 格式 checkpoint。这个优化过的 checkpoint 让你可以借助 [vLLM](https://github.com/vllm-project/vllm) 在 Blackwell NVL72 系统上、或在单个 8×A100 / 8×H100 节点上高效运行 Mistral Large 3。

交付先进的开源 AI 模型需要广泛的优化，这通过与 [NVIDIA 的合作](https://blogs.nvidia.com/blog/mistral-frontier-open-models/)实现。我们全部新的 Mistral 3 模型，从 Large 3 到 Ministral 3，都在 NVIDIA Hopper GPU 上训练，以利用高带宽 HBM3e 内存支撑前沿规模的工作负载。NVIDIA 的极致协同设计（extreme co-design）方法把硬件、软件与模型聚合在一起。NVIDIA 工程师为整个 Mistral 3 家族实现了对 [TensorRT-LLM](https://github.com/NVIDIA/TensorRT-LLM) 和 [SGLang](https://github.com/sgl-project/sglang) 的高效推理支持，以实现高效的低精度执行。

针对 Large 3 的稀疏 MoE 架构，NVIDIA 集成了最先进的 Blackwell attention 与 MoE kernel，新增了对 prefill/decode 分离式服务的支持，并与 Mistral 协作研发投机解码（speculative decoding），让开发者能够在 GB200 NVL72 及更高平台上高效服务长上下文、高吞吐的工作负载。在边缘侧，则在 [DGX Spark](http://nvidia.com/en-us/products/workstations/dgx-spark/)、[RTX PC 与笔记本](https://www.nvidia.com/en-us/ai-on-rtx/)以及 [Jetson 设备](https://www.nvidia.com/en-us/autonomous-machines/embedded-systems/jetson-orin/)上交付 Ministral 模型的优化部署，为开发者提供从数据中心到机器人的一致性、高性能开放模型运行路径。

我们非常感谢这次协作，要特别感谢 vLLM、Red Hat 和 NVIDIA。

## Ministral 3：边缘侧的最先进智能

![4 Gpqa Diamond Accuracy](https://mistral.ai/_astro/ea1fcc83-5bad-400e-b63a-35c8a8c0bf9c_ZEaRWe.webp?dpl=6abbd11780b53c00082eea6f)

面向边缘和本地用例，我们发布 Ministral 3 系列，提供三种模型规模：3B、8B 和 14B 参数。此外，每个规模都向社区发布 base、instruct 和 reasoning 三个变体，均具备图像理解能力，全部采用 Apache 2.0 许可证。结合模型原生的多模态与多语言能力，Ministral 3 家族为所有企业或开发者需求都备有一款合适的模型。

而且，Ministral 3 达成了所有开源模型中最佳的性价比。在真实用例中，生成的 token 数量与模型规模同等重要。Ministral instruct 模型匹敌或超越可比模型的表现，同时产出的 token 往往少一个数量级。

在对精度有唯一要求的场景，Ministral reasoning 变体可以思考更久，在同重量级中达到最先进精度——例如 14B 变体在 AIME '25 上取得 85%。

Mistral 3 今天已在 [Mistral AI Studio](https://console.mistral.ai/home)、[Amazon Bedrock](https://aws.amazon.com/about-aws/whats-new/2025/12/mistral-large-3-ministral-3-family-available-amazon-bedrock/)、Azure Foundry、Hugging Face（[Large 3](https://huggingface.co/collections/mistralai/mistral-large-3) 与 [Ministral](https://huggingface.co/collections/mistralai/ministral-3)）、[Modal](https://modal.com/docs/examples/ministral3_inference)、IBM WatsonX、OpenRouter、Fireworks、Unsloth AI 和 Together AI 上可用。此外，即将登陆 NVIDIA NIM 和 AWS SageMaker。

AI 的未来是开放的。Mistral 3 用一个为前沿智能、多模态灵活性与无可比拟的定制能力而打造的模型家族，重新定义了可能性。无论你是在用 Ministral 3 部署边缘优化方案，还是用 Mistral Large 3 探索推理边界，这次发布都把最先进的 AI 直接交到你手上。

### 为什么选 Mistral 3？

- 前沿性能，开放获取：以开源模型的透明与可控，取得闭源级别的结果。
- 多模态与多语言：构建能跨 40+ 种原生语言理解文本、图像与复杂逻辑的应用。
- 可伸缩的效率：从 3B 到 675B 参数，选择契合你需求的模型——从边缘设备到企业工作流。
- Agent 化与强适配：精准部署于编码、创意协作、文档分析或工具使用工作流。
