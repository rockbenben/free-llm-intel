今天，我们发布 Voxtral Transcribe 2——两款下一代语音转文本模型，具备最先进的转写质量、说话人分离与超低延迟。家族成员包括用于批量转写的 Voxtral Mini Transcribe V2 和面向实时应用的 Voxtral Realtime。Voxtral Realtime 以 Apache 2.0 许可证开放权重。

我们同时上线 [Mistral Studio 音频游乐场](https://console.mistral.ai/build/audio/speech-to-text)，由 Voxtral Transcribe 2 驱动，可即时测试带说话人分离和时间戳的转写。

## 亮点

- Voxtral Mini Transcribe V2：最先进的转写，支持 13 种语言中的说话人分离、上下文偏置和词级时间戳。
- Voxtral Realtime：为实时转写专门打造，延迟可配置低至 200ms 以下，赋能语音 agent 与实时应用。
- 同类最佳的效率：以一小部分成本达到行业领先的准确率——Voxtral Mini Transcribe V2 以最低价格拿下最低词错误率。
- 开放权重：Voxtral Realtime 以 Apache 2.0 发布，可部署在边缘，满足隐私优先应用。

## Voxtral Realtime

Voxtral Realtime 为延迟至关重要的应用而生。不同于把离线模型分块处理音频来适配的做法，Realtime 采用一种新颖的流式架构，音频一到即转写。模型交付的转写延迟可配置低至 200ms 以下，打开一整类语音优先应用的可能。

在 2.4 秒延迟（最适合字幕）时，Realtime 与我们最新的批量模型 Voxtral Mini Transcribe V2 打平；在 480ms 延迟时，词错误率差距保持在 1-2% 以内，让语音 agent 获得接近离线的准确率。

该模型原生多语言，在 13 种语言上取得强劲转写表现，包括英语、中文、印地语、西班牙语、阿拉伯语、法语、葡萄牙语、俄语、德语、日语、韩语、意大利语和荷兰语。4B 参数的体量使其能在边缘设备高效运行，为敏感部署保障隐私与安全。

我们在 [Hugging Face Hub](https://huggingface.co/mistralai/Voxtral-Mini-4B-Realtime-2602) 以 Apache 2.0 发布模型权重。

### 模型特性

Voxtral Mini Transcribe 2 引入多项关键能力。

#### 说话人分离

生成带说话人标签和精确起止时间的转写。非常适合会议转写、访谈分析和多方通话处理。注意：遇到重叠语音时，模型通常转写其中一位说话人。

#### 上下文偏置

提供最多 100 个词或短语，引导模型正确拼写姓名、技术术语或领域专属词汇。对专有名词和行业术语——标准模型常常出错的地方——尤其有用。上下文偏置针对英语优化；其他语言的支持处于实验阶段。

#### 词级时间戳

为每个词生成精确的起止时间戳，支撑字幕生成、音频搜索、内容对齐等应用。

#### 扩展的语言支持

与 Realtime 一样，该模型现已支持 13 种语言：英语、中文、印地语、西班牙语、阿拉伯语、法语、葡萄牙语、俄语、德语、日语、韩语、意大利语和荷兰语。非英语表现大幅领先竞品。

#### 抗噪稳健

在声学环境恶劣的场景（如工厂车间、繁忙呼叫中心、外场录音）中保持转写准确率。

#### 更长音频支持

单次请求即可处理最长 3 小时的录音。

## 变革语音应用

Voxtral 为多样的应用和行业驱动语音工作流。

- 会议智能。用清晰的说话人分离转写多语录音，准确归属谁在何时说了什么。以 Voxtral 的价格，按行业最优的成本效率为海量会议内容做标注。
- 语音 agent 与虚拟助手。以低于 200ms 的转写延迟构建对话式 AI。把 Voxtral Realtime 接入你的 LLM 和 TTS 管线，得到自然、响应迅速的语音界面。
- 呼叫中心自动化。实时转写通话，让 AI 系统在对话进行中的同时分析情感、建议应答、填写 CRM 字段。说话人分离确保坐席与客户归属清晰。
- 媒体与广播。以极低延迟生成实时多语字幕。上下文偏置能处理难倒通用转写服务的专有名词和技术术语。
- 合规与存证。为监管合规监控并转写交互，说话人分离提供清晰的发言人归属，时间戳支撑精确的审计轨迹。

两款模型都可通过安全的本地或私有云部署满足 GDPR 和 HIPAA 合规要求。
