思考

摘要

Vibe 是 Mistral 面向工作与编码的统一 AI agent，既能处理收件箱管理、研究、文档起草等长时任务，也能覆盖从功能开发到 pull request 的编码工作流。它提供 Work Mode——跨企业工具的多步任务，以及 Code Mode——远程编码会话，并通过 VS Code 和 CLI 等集成实现无缝协作。Vibe 有免费、Pro、Team 和企业套餐，用可见的推理、可复用的 skills 以及安全可扩展的部署简化工作流。

Vibe 现在是一个面向长时运行、多步骤工作的统一 agent。它能跟进你的收件箱和日历，执行深度研究，起草交付物，并编排贯穿你日常的例行流程。

它还能把编码工作从需求做到合并的变更，贯通网页应用、你的编辑器和终端。这个 agent 能构建功能、修复 bug、重构代码，并交付可评审的 pull request。

Vibe 运行在针对推理、agentic 任务、工具调用和编码优化的 Mistral 旗舰模型之上。

## 亮点

- Le Chat 现在就是 Vibe——一个 agent、一份授权，贯通工作与代码，所有对话、设置和订阅计划全部迁移过来。
- Work Mode 在网页和移动端可用，是一个面向长程任务的强大 agent，会挑选合适的工具、流式展示进度、把复杂工作做到完成。
- Code Mode 从专属网页界面启动远程编码 agent。
- 全新的 Mistral Vibe VS Code 扩展——在你 IDE 里跨整个项目工作的编码 agent。

## 面向工作的 Vibe。

在 Work Mode 中，Vibe 是你处理复杂多阶段任务的 AI agent，熟悉你的知识、应用和工具。它会先制定计划并征得你的认可再动手，然后跨你的各个连接器把任务执行到底。

对个人而言，这能把一上午的杂务变成一条 prompt——补上你错过的信息、拉出数字、起草进展汇报，并整理成随时可发送的状态。而对组织而言，同一个 agent 运行着让企业转起来的那些流程，立足你团队已在使用的文档、邮箱和系统，并受你在管理员层级设置的权限治理。

### Vibe 的 Work Mode 今天能做的事。

- 企业知识搜索：Vibe 把工作深度扎根于你的上下文，贯通 Google Workspace、Outlook、SharePoint、Slack、GitHub 以及任何自定义连接器或资料库。
- 结构化数据分析：连接数据库或上传电子表格，Vibe 会呈现你要找的规律、异常和信号，并在对话内渲染图表和仪表盘。
- 文档与报告综合：Vibe 用 Canvas 工具起草交付物，从一页简报，到报告、RFP 应答或董事会演示稿，供你编辑并推送到 Notion、SharePoint 或你的邮箱。
- 多步任务调度：设置一条 prompt 单次运行或按日/周/月节奏运行，一次运行结束后会有通知送达。
- 可复用 skills：通过开放标准以预设或自定义 skills 扩展 Vibe，以一致性和按序精确性自动化你的可重复工作流。

每一步都在发生时可见，每个工具调用和推理链都可展开查看其输入与输出。

## 面向代码的 Vibe。

Code Mode 是 Vibe 网页应用中的全新编码界面，你可以连接 GitHub、管理项目、开启会话并把它们推进到 pull request。会话中，agent 在隔离的沙箱里运行，你管理敏感操作并在它写代码时检查 diff。

会话可以并行运行，可以在你计算机关机时继续存续，可以由第三方应用（如 Slack，六月推出）触发——除了你的代码编辑器或 Vibe CLI 之外。

### 全新的 Mistral Vibe VS Code 扩展。

我们还发布一个新插件，把 Vibe 编码 agent 带进 VS Code。Vibe 在侧边面板中跨整个项目工作，在你的文件旁读取、编辑并执行命令。打开的文件会自动附加，选区可精确到行，@ 提及可以从其他目录或文件拉入更多上下文。

该扩展与 CLI 运行在同一 harness 上，功能在两个界面保持一致：

- 编写匹配你现有模式的单元测试和集成测试，并为交付写文档，从 README 到行内注释；
- 重构与翻译，把某个模块迁移到新模式，或把遗留文件转成更现代的语言，同时保持行为不变、测试完备；
- 连接你的整个技术栈，从 GitHub、GitLab、Jira 或 Linear 拉取上下文，让每次变更自带它所解决的 issue 和你团队的规范。

## Vibe CLI 的更新。

Vibe CLI 迎来多项重要更新，包括更多会话控制。

- Skills 把可重复的工作流变成 / 命令。
- 自定义模式和子 agent 在会话内路由专业化工作。
- agent 的计划可在运行前编辑，运行中还能提出多选择题。
- 权限按会话作用域设置（总是、从不或询问），包括对文件、命令和目录的覆盖。
- `/teleport` 把实时会话在终端与云之间迁移，保留历史和审批。

## 开始使用 Vibe。

Vibe 已在 [chat.mistral.ai](http://chat.mistral.ai) 上线。从 [App Store](https://apps.apple.com/app/id6740410176) 和 [Google Play](https://play.google.com/store/apps/details?id=ai.mistral.chat) 下载移动应用。如果你之前是 Le Chat 用户，你的套餐、历史与设置已经都在 Chat 模式中。*

- 免费：快速回答和简单的日常任务。
- Pro，$14.99/月：复杂任务、更深推理和全天候编码。
- Team，$24.99/人/月：带管理控制和更多存储的共享工作区。
- Enterprise：定制部署、模型训练和专属方案设计。

参阅 [Vibe 的套餐](https://mistral.ai/pricing)了解更多。

编码方面，Vibe 在网页 [chat.mistral.ai/code](https://chat.mistral.ai/code) 上可用，在 VS Code 中通过[新扩展](https://marketplace.visualstudio.com/items?itemName=mistralai.mistral-vibe-code)可用，在终端中通过 CLI 可用：

```
curl -LsSf https://mistral.ai/vibe/install.sh | bash
```

```
uv tool install mistral-vibe
```

你也可以通过 [Mistral Studio](https://console.mistral.ai/codestral/cli) 的 API 构建，配合免费的 Experiment 套餐做测试和原型验证。

** Chat 模式即将退役；请放心，你的所有 Le Chat 历史都将继续保留在 Work Mode 中。*
