今天，我们给 le Chat 赋予新的能力（beta）。快速摘要如下：

- 带引用来源的网页搜索

##### **网页搜索**

le Chat 的使用中有相当大比例来自用它学习、研究和工作的学生与职场人士。为了更好地服务这些用例，我们用互联网搜索扩充了 le Chat 的训练知识。

这是我们一位市场团队的同事用它评估医疗 AI 市场的例子。

拥有能获取最新知识和动态的最先进语言模型，你就拥有了一个让工作上台阶的强大工具。

##### **Canvas**

Canvas 是一个新界面，当你需要超越对话、进入构思阶段时，它会在你的 le Chat 窗口中弹出。它让你能与 Mistral LLM 围绕共享产出协作，实现知识工作的 0-1 创造与构思。

不再局限于双向对话，Canvas 让你直接修改、编辑或转化内容，并由 LLM 强大的推理能力辅助。

这是一段我们产品团队录制的应用 Canvas 的演示：用 react 做一个产品指标看板的原型。

你可以用 Canvas 创建文档、演示文稿、代码、原型……不胜枚举。如你所见，你可以就地修改内容而无需重新生成回答、为草稿保留版本、预览你的设计。

Canvas 为任何团队提供无限的创意构思空间。

##### **快速准确的文档理解**

Le Chat 现在能够处理大型复杂 PDF 文档和图像，用于分析和摘要。只需把文档附到聊天框，就能洞察一切——图表、表格、示意图、文本、公式、方程……基本上是整份文档。

这些高级能力由全新的 Pixtral Large 实现——一个最先进的多模态模型，远比我们此前的视觉模型 [Pixtral 12B](https://mistral.ai/news/pixtral-12b/) 强大——并结合了一个实验性模型（几周后详解）。

##### **图片生成**

我们与好友 [Black Forest Labs](https://blackforestlabs.ai/) 合作，把他们领先的图片生成模型带入 le Chat。你现在就可以直接在 le Chat 内为你的工作生成高质量图片。

##### **Le Chat Agents 自动化重复工作流**

如果你发现自己在重复使用某些提示词，或识别出某些希望自动化的创作模式，你可以把这些工作流固化为 agents。常见用例包括扫描收据做费用报销、给长会议纪要生成 TL;DR、发票处理。

Agents 可以发布并与你的团队成员共享。你可以递归式地构思，构建越来越强力的 agents，帮你更快完成工作。关于 agents 的更多内容，请看[这篇博客](https://mistral.ai/news/build-tweak-repeat/)或我们的[文档](https://docs.mistral.ai/capabilities/agents/)。
