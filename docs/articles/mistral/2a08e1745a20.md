我们推出 Codestral，我们的首个代码模型。Codestral 是一个开放权重的生成式 AI 模型，专为代码生成任务而设计。它通过共享的指令与补全 API endpoint，帮助开发者编写和交互代码。由于它精通代码和英语，可以被用来为软件开发者设计先进的 AI 应用。

## 精通 80+ 种编程语言的模型

Codestral 在涵盖 80 多种编程语言的多样化数据集上训练，包括 Python、Java、C、C++、JavaScript 和 Bash 等最流行的语言，同时在 Swift、Fortran 等更小众的语言上也有良好表现。这种广泛的语言基础确保 Codestral 能在各种编码环境和项目中协助开发者。

Codestral 为开发者节省时间与精力：它能补全代码函数、编写测试，并通过 fill-in-the-middle 机制补全任意部分代码。与 Codestral 交互将帮助开发者提升编码水平，降低出错和引入 bug 的风险。

## 为代码生成性能树立新标杆

**性能。**作为一个 22B 模型，Codestral 在代码生成的性能/延迟区间上树立了相比以往编码模型的新标准。

我们将 Codestral 与硬件需求更高的现有代码专用模型进行比较。

**Python。**我们使用四项基准：以 HumanEval pass@1、MBPP sanitised pass@1 评估 Codestral 的 Python 代码生成能力，用 CruxEval 评估 Python 输出预测，用 RepoBench EM 评估 Codestral 的长距离仓库级代码补全。

**SQL。**为评估 Codestral 在 SQL 上的表现，我们使用了 Spider 基准。

**其他语言。**此外，我们还在 Python 之外评估了 Codestral 在六种不同语言的多个 HumanEval pass@1 上的表现：C++、bash、Java、PHP、Typescript 和 C#，并计算了这些评测的平均值。

## Codestral 上手

### 下载并测试 Codestral。

Codestral 是一个 22B 开放权重模型，采用全新的 [*Mistral AI Non-Production License*](https://mistral.ai/news/mistral-ai-non-production-license-mnpl/) 授权，意味着你可以将其用于研究与测试目的。Codestral 可在 [HuggingFace](https://huggingface.co/mistralai/Codestral-22B-v0.1) 下载。

如果你想在商业活动中使用该模型，也可通过[联系团队](https://mistral.ai/contact/)按需获取商业授权。

### 通过专用 endpoint 使用 Codestral

随本次发布一同新增了一个 endpoint：`codestral.mistral.ai`。在 IDE 中使用我们的 Instruct 或 Fill-In-the-Middle 路线的用户应优先使用该 endpoint。此 endpoint 的 API Key 在个人账户层级管理，不受常规组织速率限制约束。在为期 8 周的 beta 期间我们允许免费使用该 endpoint，并通过[排队名单](https://console.mistral.ai/codestral)进行准入控制，以确保服务质量。实现 IDE 插件或应用、且预期客户自带 API key 的开发者应优先使用该 endpoint。

### 在 la Plateforme 上用 Codestral 构建

Codestral 也立即可在常规 API endpoint 上使用：`api.mistral.ai`，该处请求按 token 计费。这个 endpoint 及其集成更适合研究、批量查询，或那些直接面向用户展示结果、无需用户自带 API key 的第三方应用开发。

你可以在 [la Plateforme](https://console.mistral.ai) 创建账户，并按照[本指南](https://docs.mistral.ai/capabilities/code_generation/)开始用 Codestral 构建应用。与我们其他所有模型一样，Codestral 从今天起也提供自托管部署方案：[联系销售](https://mistral.ai/contact/)。

### 在你最喜爱的编码与构建环境中使用 Codestral。

我们与社区伙伴合作，把 Codestral 接入开发者生产力和 AI 应用构建的流行工具。

**应用框架。**Codestral 从今天起已集成进 LlamaIndex 和 LangChain，让用户可以轻松用 Codestral 构建 Agent 应用。

**VSCode/JetBrains 集成。**[Continue.dev](https://docs.mistral.ai/capabilities/code_generation/#integration-with-continuedev) 和 [Tabnine](https://docs.mistral.ai/capabilities/code_generation/#integration-with-tabnine) 赋能开发者在 VSCode 和 JetBrains 环境中使用 Codestral，现在他们可以用 Codestral 生成代码并与代码对话。

[这里](https://www.youtube.com/watch?v=mjltGOJMJZA)演示了如何用 Continue.dev 的 VSCode 插件配合 Codestral 进行代码生成、交互式对话与行内编辑；[这里](https://www.youtube.com/watch?v=pFa4NLK9Lbw)演示了用户如何用 Tabnine 的 VSCode 插件与 Codestral 对话。

有关各种集成如何与 Codestral 协作的详细信息，请查阅[我们的文档](https://docs.mistral.ai/capabilities/code_generation/)中的设置说明与示例。
