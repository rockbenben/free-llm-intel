继 Mixtral 系列之后，Codestral Mamba 是我们研究与提供新架构努力的又一步。它可以免费使用、修改和分发，我们希望它为架构研究打开新的视野。Codestral Mamba 的设计得到了 Albert Gu 和 Tri Dao 的帮助。

与 Transformer 模型不同，[Mamba 模型](https://arxiv.org/abs/2312.00752)具有线性时间推理的优势，以及建模无限长序列的理论能力。它让用户可以与模型进行超长交互并获得快速响应，而不受输入长度影响。这种效率对代码生产力场景尤为关键——这就是我们训练此模型时赋予它高级代码与推理能力的原因，使其表现足以与 SOTA 的 Transformer 模型匹敌。

![Codestral Mamba 详细基准测试](https://mistral.ai/_astro/fdd5d6fa-0e15-47b6-a40e-fb81a9f65514_Z29C9mO.webp?dpl=6abbd11780b53c00082eea6f)

我们已在高达 256k token 的上下文内检索能力上测试了 Codestral Mamba。我们期待它成为一款出色的本地代码助手！

你可以使用 [mistral-inference](https://github.com/mistralai/mistral-inference/releases/tag/v1.2.0) SDK 部署 Codestral Mamba，它依赖 Mamba GitHub 仓库的参考实现。该模型也可通过 [TensorRT-LLM](https://github.com/NVIDIA/TensorRT-LLM/tree/main/examples/mamba) 部署。本地推理方面，请留意 llama.cpp 中的支持。你可以从 [HuggingFace](https://huggingface.co/mistralai/mamba-codestral-7B-v0.1) 下载原始权重。这是一个指令模型，拥有 7,285,403,648 个参数。

为了方便试用，我们已把 Codestral Mamba 上架 [la Plateforme](https://console.mistral.ai/)（模型名 `codestral-mamba-2407`），与它的"姐姐"Codestral 22B 并列。Codestral Mamba 以 Apache 2.0 许可证提供，而 Codestral 22B 则以自部署的[商业许可证](https://mistral.ai/contact/)或供测试之用的社区许可证提供。
