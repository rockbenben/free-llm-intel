AI 助手最出色的时刻，是它能让你思考得更深、让对话保持流畅、并维持上下文的连贯。今天，我们让 Le Chat 更强大、更直觉——也更有趣——推出一系列强大新功能，帮助你做研究更透彻、表达更自然，并把你的一切交互——文字、语音和图像——有序地组织在上下文中。

## Le Chat 的新功能

- Deep Research（深度研究，预览版）模式：哪怕最复杂的主题，也能极速生成结构化研究报告。
- 语音模式：用我们的新模型 Voxtral 与 Le Chat 对话，而不必打字。
- 原生多语言推理：调用由我们的[推理模型](https://mistral.ai/news/magistral) Magistral 驱动的深思熟虑的回答。
- Projects（项目）：把你的对话组织成上下文丰富的文件夹。
- 与 Black Forest Labs 合作，在 Le Chat 中直接进行高级图像编辑。

### 用 Deep Research 挖得更深。

研究模式把 Le Chat 变成一位协同的研究助理，能够规划、澄清你的需求、检索并综合。问一个有分量的问题，它会拆解问题、汇集可靠来源，生成易读、有引用支撑的结构化报告。

它由我们工具增强的 Deep Research agent（预览中）驱动，但设计目标是简单、透明、真正有用，让你感觉像在跟一位训练有素的研究伙伴协作。

### Le Chat 洗耳恭听。

语音模式让你像与人交谈一样和 Le Chat 对话——无需打字。你可以散步时头脑风暴、跑腿途中快速获取答案，或转录一场会议。它由我们的新语音输入模型 Voxtral 驱动，为自然、低延迟的语音识别而生，始终跟上你的节奏。

### 用你的语言深入思考。

Think 模式由我们的推理模型 Magistral 驱动，用清晰、深思熟虑的回答帮你推理复杂问题。非常适合用西班牙语起草一份提案、用日语澄清一个法律概念，或仅仅用你最熟悉的语言把事情想透。Le Chat 还能在句子中间进行语码切换。

### Projects 成形之地。

Projects 把相关对话归组到聚焦、上下文丰富的空间中，帮你保持条理。每个项目都有自己的默认资料库（Library），并记得你启用过哪些工具和设置，一切保持你离开时的样子。你可以直接把文件上传到项目里、从你的资料库引入内容，把一切——对话、文档和想法——放在一处。无论是规划搬家、设计新的产品功能，还是让长期工作流保持正轨，都非常合适。

### 先描绘它——再编辑它。

与典型的文生图工具不同，你可以先用简单提示词创建图像，再进行编辑，比如"移除这个物体"或"把我放到另一座城市"，模型会在保留人物与细节的同时转换场景。它特别适合在一系列图片中做风格一致的编辑，让角色、物体和设计元素张张可认、前后呼应。
