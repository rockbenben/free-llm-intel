## 概述

**SenseNova-U1.5-8B-MoT** 是我们最新的原生统一多模式检查点，可实现更准确、一致、可靠且美观的视觉创作。它基于 [NEO-unify](https://huggingface.co/blog/sensenova/neo-unify) 构建，增强了补丁层、数据质量和分布、任务制定、提示增强和训练后管道。

正式版本重点关注六项用户可见的改进：

- **更高质量的图像生成：**改进了构图和色彩和谐，具有更真实的材质渲染、自然光照、更强的视觉保真度和更精细的局部细节。
- **更好的文本渲染和信息图表生成：**更清晰的中英文文本，海报、信息图表、品牌资产和其他文本密集设计中的信息层次结构更清晰。
- **更高效的原生 4K 生成：** 更连贯的全局结构、色彩和谐和稳定的高分辨率输出，并提高了生成效率。
- **更可靠的本机图像编辑：** 在本地、文本、多引用、插入和替换编辑中更好地保​​留主题身份和未编辑的内容。
- **更强的复杂指令如下：**在单个请求中更一致地执行对象计数、空间关系、布局、样式和多个约束。
- **更精确的视觉控制：**通过边界框、视觉标记以及单图像或多图像引用进行更精确的区域和对象级控制。

## 快速入门

参考推理实现可在 [SenseNova-U1 GitHub 存储库](https://github.com/OpenSenseNova/SenseNova-U1/tree/refs/heads/feat/u1.5) 中找到。

＃＃＃ 安装

```
git clone https://github.com/OpenSenseNova/SenseNova-U1.git
cd SenseNova-U1
uv sync
source .venv/bin/activate
```

上游环境使用Python 3.11、PyTorch 2.8和CUDA 12.8。对于其他 CUDA 版本和可选的 FlashAttention 配置，请参阅[安装指南](https://github.com/OpenSenseNova/SenseNova-U1/blob/refs/heads/feat/u1.5/docs/installation.md)。

### 文本转图像

```
python examples/t2i/inference.py \
  --model_path sensenova/SenseNova-U1.5-8B-MoT \
  --prompt "A cinematic mountain lake at sunrise, realistic photography." \
  --width 2048 --height 2048 \
  --device_map auto \
  --output output.png
```

### 图像编辑

```
python examples/editing/inference.py \
  --model_path sensenova/SenseNova-U1.5-8B-MoT \
  --image input.png \
  --prompt "Change the jacket to cobalt blue. Preserve the face, pose, background, lighting, and framing." \
  --output edited.png
```

有关更多选项、支持的分辨率和批处理，请参阅[推理示例](https://github.com/OpenSenseNova/SenseNova-U1/blob/refs/heads/feat/u1.5/examples/README.md)。

## 持续改进

官方版本在预览版的基础上进行了改进，但仍然存在以下挑战：

- **过度强调细节或颜色：** 某些提示可能会产生过多的高频细节或过饱和的颜色，通常可以通过降低 `cfg_scale` 来缓解。
- **密集文本错误：**密集、冗长、小或中英文混合的文本可能包含错误。
- **受限布局：** 在高度受限的布局中，精确的计数、对齐或层次结构可能不完美。
- **不稳定的人体细节：** 小脸、手、四肢和细粒度的物体结构可能仍然不稳定。
- **复杂的编辑漂移：** 广泛、多轮或多参考编辑可能会漂移，特别是当必须同时保留许多区域时。
