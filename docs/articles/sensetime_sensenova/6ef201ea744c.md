# 循环-DiT B/32

Looped-DiT 是一种文本到图像的扩散转换器，它在每个去噪步骤中多次运行一组共享的转换器块，因此模型会变得更深而不变得更大。 **深度监督**在每个循环后训练预测，而**独占自注意力**（XSA）调节循环内的注意力更新。主干是 [MiniT2I](https://github.com/PeppaKing8/minit2i-jax) 的像素空间 MMDiT，以冻结的 [FLAN-T5-Large](https://huggingface.co/google/flan-t5-large) 为条件。

该存储库保存 Looped-DiT B/32 在步骤 290k 处的 EMA 权重：

- 补丁大小 32、512 x 512 图像
- [6,5,6] 块（循环前、循环、循环后），其中 5 个循环块运行 4 次
- 在深度监督下进行训练，在循环块中使用 XSA

## 结果

100 欧拉步，无分类器引导 6.0，循环深度 4。TIIF-Short 是 TIIF-Bench 在其简短提示上的评分。

## 用法

下载检查点，然后使用 Looped-DiT 代码进行采样（链接即将推出）：

```
hf download sensenova/Looped-DiT-B32 looped-dit-b32.pt --local-dir checkpoints
python -m looped_dit.sample --checkpoint checkpoints/looped-dit-b32.pt \
    --prompt "a red cube on top of a blue sphere" --out sample.png
```

添加 `--loops 1 2 3 4` 以在多个循环深度呈现提示。其他深度无需重新训练即可工作。
