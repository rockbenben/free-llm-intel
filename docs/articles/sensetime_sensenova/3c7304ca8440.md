## 使用现有的管道

**相同的架构。相同的官方模型布局。相同的加载 API。** 这些是完整的模型权重：将原始模型 ID 或本地路径替换为 `sensenova/SenseNova-U1.5-8B-MoT-TailSteer`。不需要适配器、合并、额外的推理模块或 TailSteer 特定的运行时。

使用与基础模型相同的官方环境。仅模型 ID 发生变化。

使用【SenseNova官方推理包】(https://github.com/OpenSenseNova/SenseNova-U1)：

```
python examples/editing/inference.py \
  --model_path sensenova/SenseNova-U1.5-8B-MoT-TailSteer \
  --image input.png --prompt "Change the jacket to blue." --output output.png
```

对于下一次编辑，将编辑后的图像传递回同一管道。在整个原始去噪轨迹中使用TailSteer；推理时不需要模型切换或保存掩码。

## 衡量什么保持不变

[**添加和保留**](https://huggingface.co/datasets/Lyricccco/Add-and-Preserve) 使漂移可见：每次在红框内添加一个小物体，保留以前的物体，并保留外面的所有东西。它测试了 100 张图像和 10 个回合的对象完成度和背景保留。

[![对所有 100 张基准图像进行十次以上的保存](https://huggingface.co/sensenova/SenseNova-U1.5-8B-MoT-TailSteer/resolve/main/media/preservation-curves.png)](https://huggingface.co/sensenova/SenseNova-U1.5-8B-MoT-TailSteer/blob/main/media/preservation-curves.png)

|尾舵之后 | 94.78 | 18.22 | 18.22 0.489 | 0.489 0.417 | 0.417

COA（累积对象准确度）平均十回合内请求对象的存在情况。 PSNR、SSIM 和 LPIPS 测量不变区域。这些是标准图像反馈结果；曲线使用全部 100 张图像。 [公制数据](https://huggingface.co/sensenova/SenseNova-U1.5-8B-MoT-TailSteer/blob/main/media/results.json)。

## 运行演示和基准测试

在官方主干环境中安装 TailSteer 代码库后：

```
tailsteer infer --backbone sensenova-u1.5-8b-mot \
  --checkpoint sensenova/SenseNova-U1.5-8B-MoT-TailSteer \
  --policies tailsteer --inference-suite cafe-20turn --gpus 1
```

准备原始基本权重并省略 `--policies tailsteer` 以进行并排比较。配置数据集和判断后，同一套件界面可以运行文本到图像、单轮编辑、多轮编辑以及添加和保留基准测试。

## → [探索并了解 TailSteer 为何有效](https://lyricccco.github.io/tailsteer/)

**保留早期动态；引导轨迹尾部。** TailSteer 从编辑器自己的去噪卷展中学习，使用未更改的源内容作为保存参考。它使用单编辑轨迹提高了长视野稳定性，而不需要策划的地面实况编辑对或多轮编辑链上的训练。

这是本文的 **2,000 更新检查点**，训练转向开始 **42 / 50**。发作控制训练监督；推理在每一步都使用经过训练的模型。打包模型[根据原始推理导出进行验证](https://huggingface.co/sensenova/SenseNova-U1.5-8B-MoT-TailSteer/blob/main/validation/parity.json)。
