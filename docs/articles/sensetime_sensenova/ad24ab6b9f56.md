## 🌟 概述

![SenseNova-U1.5技术进步概述（预览版）](https://raw.githubusercontent.com/OpenSenseNova/SenseNova-U1/main/docs/assets/u1.5_teaser.png)

**SenseNova-U1.5（预览版）**是基于 [NEO-unify](https://huggingface.co/blog/sensenova/neo-unify) 构建的原生统一多模态模型，具有新的补丁编码和解码层。我们进一步扩展和细化文本到图像的训练语料库，同时广泛过滤和合成单图像和多图像参考设置的编辑数据。因此，它显示了本机图像生成和编辑方面的显着飞跃：

- **原生 4K 生成具有卓越的效率**，在高分辨率下保留全局一致性和细粒度细节。
- **纹理、材质、灯光和真实感方面的显着改进**，产生更丰富、更具视觉说服力的图像。
- **明显更强的中英文文本渲染**，以及更可靠的密集和复杂布局的组成。
- **图像编辑方面的重大进步**，具有更强的指令遵循性、主体身份保留和结构一致性。
- **通过蒙版、边界框和视觉标记进行细粒度、区域可控的编辑**。

## 🔬 U1.5 改进了什么

#### 从补丁预测到补丁联合重建

SenseNova-U1 的原始 MLP 头独立重建每个 RGB 补丁。在高分辨率下，这可能会将标记边界暴露为网格图案、接缝或纹理不连续性。 SenseNova-U1.5 相反，通过 [ConvDecoder](https://github.com/OpenSenseNova/SenseNova-U1/blob/main/src/sensenova_u1/models/neo_unify/modeling_fm_modules.py) 采用渐进式空间重建：视觉标记被重塑为二维特征网格，并通过多个 Pixel Shuffle 阶段进行上采样，中间 `3×3` 卷积使相邻补丁能够交互并合并成更连续的图像。

*定性结果表明，这种设计在整个预训练过程中显着抑制了网格状伪影。它还提高了下游适应过程中的鲁棒性，降低了在新域上进行微调时类似工件重新出现的可能性。*

#### 从遵循指令到视觉保护

SenseNova-U1 主要依赖于公开的图像编辑数据集，其中许多数据集包含嘈杂的监督、低质量的样本以及可见的合成或修饰伪影。对于SenseNova-U1.5，我们对编辑语料库进行了广泛的清理、过滤和合成，同时改善了中英平衡并扩大了单图像和多图像参考设置的覆盖范围。

*定量结果表明，无编码器的 NEO-unify 架构仅使用单个参考图像标记序列即可实现强大的指令遵循以及主体身份和结构保留。这带来了更强的编辑性能和更高的推理效率，进一步验证了原生统一多模态建模的有效性。*

#### 从格式暴露到跨任务泛化

用于训练SenseNova-U1.5的生成和编辑语料库仅包含少量简单的JSON格式的提示，而不是长的、分层的或高度结构化的指令。此外，更复杂的类似 JSON 的格式仅出现在理解训练数据语料库中，其内容、结构和任务目标有很大不同。

*尽管存在这样的差距，它还是可以很好地推广到图像生成和编辑中的长而结构化的指令。这表明原生统一多模态建模可以将从理解和生成中学到的功能结合到统一模型中，从而使结构化理解和视觉规划能够跨任务转移，而无需对固定提示模板进行专门培训。*

## ⚠️ 已知限制

我们的目标是带着明确的期望来展示 SenseNova-U1.5（预览版）。其当前的局限性包括：

- **由于简短或未指定的提示而意外生成文本**。
- **密集或冗长文本中的错误**，特别是小字符和中英文混合内容。
- **不完全遵守复杂的布局**，包括精确计数、对齐和层次结构。
- **小脸、手、四肢和细粒度物体细节的不稳定。**
- **复杂编辑中的漂移**，特别是在广泛的、多轮或多参考指令中。

为了帮助用户更好地达到模型当前的能力上限，我们提供了两种可选的开源实践。

## 🧰 最佳实践【强烈推荐】

对于主题明确且限制较少的任务，直接的自然语言提示就足够了。下面的两条路径主要适用于设计信息不完整或用户希望根据参考重新创建成熟的视觉解决方案的任务。它们是模型外部的可选工作流程，不应与原始模型的功能混为一谈。

### 路径A：SenseNova Image PE技能

当输入只是简短的创意简介时，请使用此路径。该技能将摘要转换为紧凑的渲染 JSON 提示，同时保留所需的主题、可见副本、计数、布局约束和排除。

####安装

从存储库根目录中，将技能复制到代理技能目录：

```
SKILL_DIR="$HOME/.agents/skills/sensenova-u1-5-prompt-enhancement"
mkdir -p "$SKILL_DIR"
cp src/sensenova_u1.5/prompt-enhancement-skill/SKILL.md "$SKILL_DIR/"
cp -R src/sensenova_u1.5/prompt-enhancement-skill/agents \
  src/sensenova_u1.5/prompt-enhancement-skill/references \
  "$SKILL_DIR/"
```

#### 使用示例

技能是代理的一组任务指令和参考，而不是独立的程序。安装后，使用您的代理技能机制调用 `sensenova-u1-5-prompt-enhancement` 并提交以下请求。代理遵循 `SKILL.md` 和 `references/` 中的材料将摘要转换为渲染 JSON。调用语法因代理而异。 `$SKILL_DIR` 只是目标目录的安装命令使用的 shell 变量。

```
Convert the brief below into one compact Render JSON object. Save only the JSON
object, without Markdown fences, to enhanced_prompt.json.

Brief:
Design a 3:4 portrait autumn lakeside wedding invitation with embossed paper
and delicate botanical linework. Use only this copy: "OUR DAY / AUTUMN WEDDING
/ 10.18 / LAKESIDE GARDEN".
```

使用签入的渲染 JSON 通过 SenseNova-U1.5 生成图像：

```
MODEL_PATH="sensenova/SenseNova-U1.5-8B-MoT-Preview"

python examples/t2i/inference.py \
  --model_path "$MODEL_PATH" \
  --prompt "$(cat src/sensenova_u1_5/prompt-enhancement-skill/examples/u1_5_pe_skill_wedding_prompt.json)" \
  --width 1760 \
  --height 2368 \
  --cfg_scale 4.0 \
  --cfg_norm global \
  --timestep_shift 3.0 \
  --num_steps 50 \
  --seed 1730675618 \
  --device_map auto \
  --output output.png
```

### 路径 B：参考图像检索 + 标题提示

当抽象风格术语不足以准确描述设计目标时，更直接的方法是首先检索设计完整性较高的参考图像，然后使用我们的 Caption 脚本将该参考中的视觉决策转换为可编辑的提示：

```
Creative objective
  └─► Retrieve and select a reference image
      └─► SenseNova Caption Script
          └─► Composition / hierarchy / palette / typography / materials / lighting / constraints
              └─► Replace the theme, content, copy, subject, or local structure
                  └─► Re-create or reinterpret with SenseNova-U1.5 
```

这条路径的关键不是简单地复制参考图像，而是将“设计为何有效”分解为模型的可执行描述。标题脚本尝试提取布局网格、视觉焦点、排版层次结构、调色板、材料、相机、照明和负面约束。然后，用户可以保留设计语言，同时替换主题、副本、主题或本地结构。使用外部参考图像时，请确保其来源、授权和使用符合适用的许可。

字幕脚本：[src/sensenova_u1_5/caption/caption.py](https://github.com/OpenSenseNova/SenseNova-U1/blob/main/src/sensenova_u1_5/caption/caption.py)

```
pip install openai pillow
export OPENAI_API_KEY="your-api-key"

# Output a structured JSON prompt and a natural-language prompt
python src/sensenova_u1_5/caption/caption.py path/to/reference.jpg

# Save the result for subsequent changes to the theme, copy, subject, or local structure
python src/sensenova_u1_5/caption/caption.py path/to/reference.jpg > result.json
```

### 如何选择

|场景 |推荐方法 |
| --- | --- |
|主题清晰，限制较少 |使用直接的自然语言提示 |
|只有简短的创意简介，但应该自动填写完整的设计方案 | SenseNova 图像 PE 技能 |
|理想的构图或视觉语言已经被发现，应该重新创建、重新主题或修改 |参考图像检索+提示标题|

### 编辑PE

编辑 PE 是图像编辑和参考引导生成的提示预处理步骤。它将有序输入图像与原始指令一起发送到多模式提示重写器，该重写器保留用户的语言和核心意图，同时使图像模型的请求更加明确。根据任务的不同，它可以明确编辑目标和位置，为多个参考图像分配角色，提取参考的视觉语言，指定确切的文本和布局，并说明哪些主题或区域必须保持不变。然后将重写后的提示传给SenseNova-U1.5进行图像生成；编辑 PE 不会修改像素本身。

独立实现可在 [`src/sensenova_u1_5/edit/edit_pe.py`](https://github.com/OpenSenseNova/SenseNova-U1/blob/main/src/sensenova_u1_5/edit/edit_pe.py) 处获得。要在不启动图像生成的情况下检查重写的提示：

```
export OPENAI_API_KEY="your-api-key"
# Optional:
# export OPENAI_MODEL="gpt-5.5"
# export OPENAI_BASE_URL="https://your-openai-compatible-endpoint/v1"

python src/sensenova_u1_5/edit/edit_pe.py \
  path/to/input.png \
  "把天空改成晚霞"
```

该命令将重写的提示打印到标准输出。可以在原始提示之前按顺序列出多个输入图像。

在[`examples/editing/inference.py`](https://github.com/OpenSenseNova/SenseNova-U1/blob/main/examples/editing/inference.py)中，默认情况下禁用编辑PE。使用 `--use-edit-pe` 启用它并设置 `OPENAI_API_KEY`。使用`--print-edit-pe`检查原始和重写的提示，或使用`--edit-pe-model`选择重写器型号。对于多图像任务，请按预期顺序提供图像，并描述每个图像在原始指令中的作用。

## 🚀 快速入门

参考推理实现可在 [SenseNova-U1 GitHub 存储库](https://github.com/OpenSenseNova/SenseNova-U1) 中找到。

＃＃＃ 安装

```
git clone https://github.com/OpenSenseNova/SenseNova-U1.git
cd SenseNova-U1
uv sync
source .venv/bin/activate
```

上游环境当前使用Python 3.11、PyTorch 2.8和CUDA 12.8。对于其他 CUDA 版本和可选的 FlashAttention 配置，请参阅[安装指南](https://github.com/OpenSenseNova/SenseNova-U1/blob/main/docs/installation.md)。

### 🖼️ 文本转图像

```
python examples/t2i/inference.py \
  --model_path sensenova/SenseNova-U1.5-8B-MoT-Preview \
  --prompt "A cinematic mountain lake at sunrise, realistic photography." \
  --width 2048 --height 2048 \
  --device_map auto \
  --output output.png
```

### ✏️ 图像编辑

```
python examples/editing/inference.py \
  --model_path sensenova/SenseNova-U1.5-8B-MoT-Preview \
  --image input.png \
  --prompt "Change the jacket to cobalt blue. Preserve the face, pose, background, lighting, and framing." \
  --output edited.png
```

要使用 Image PE 生成更详细的面向模型的编辑提示：

```
python examples/editing/inference.py \
  --model_path sensenova/SenseNova-U1.5-8B-MoT-Preview \
  --prompt "参考这张图的青花水墨视觉语言，生成一张中国古建筑屋顶形制图鉴。" \
  --image docs/assets/showcases/editing_gallery/case1_ancient_roof_infographic.webp \
  --output edited_with_pe.png \
  --use-edit-pe
```

SenseNova-U1.5 的参考配置为 `cfg_scale=4.0`、`timestep_shift=3.0` 和 `num_steps=50`。

### 训练

SenseNova-U1.5生成预训练代码可在【训练目录】(https://github.com/OpenSenseNova/SenseNova-U1/blob/main/training/README.md)中获取。配置模型、分词器和数据路径后，使用以下命令启动提供的像素头 PT 配方：

```
cd training
bash shell/train_u1/U1.5_8B.sh
```

环境驱动的 PT 配置为 [`sensenovau1_5_8b_mot_pt.py`](https://github.com/OpenSenseNova/SenseNova-U1/blob/main/training/configs/sensenovavl_qwen3_gen/sensenovau1_5_8b_mot_pt.py)。
