## 概述

尽管取得了显著进展，多模态基础模型在空间智能方面仍表现出令人意外的不足。在本工作中，我们探索通过扩展多模态基础模型，在 **SenseNova-SI 系列** 中培养空间智能；该系列构建于成熟的多模态基础之上，包括视觉理解模型（即 Qwen3-VL 和 InternVL3）以及统一理解与生成模型（即 Bagel）。我们采用系统化方法构建高性能且稳健的空间智能：在严格的空间能力分类体系下，系统整理出 SenseNova-SI-8M——800 万条多样化数据样本。SenseNova-SI 在广泛的空间智能基准上展现出前所未有的性能：VSI-Bench 上 68.7%，MMSI 上 43.3%，MindCube 上 85.6%，ViewSpatial 上 54.6%，SITE 上 50.1%，同时保持强大的通用多模态理解能力（例如 MMBench-En 上 84.9%）。更重要的是，我们分析了数据扩展的影响，讨论了多样化数据训练所带来的涌现泛化能力的早期迹象，分析了过拟合与语言捷径的风险，呈现了关于空间思维链推理的初步研究，并验证了潜在的下游应用。SenseNova-SI 是一个持续进行的项目，本报告将持续更新。所有新训练的多模态基础模型均已公开发布，以促进该方向的进一步研究。*未来，SenseNova-SI 将与更大规模的内部模型集成。*

## 发布信息

## 🛠️ 快速开始

### 安装

我们推荐使用 [uv](https://docs.astral.sh/uv/) 管理环境。

> uv 安装指南：https://docs.astral.sh/uv/getting-started/installation/#installing-uv

```
git clone git@github.com:OpenSenseNova/SenseNova-SI.git
cd SenseNova-SI/
uv sync --extra cu124 # or one of [cu118|cu121|cu124|cu126|cu128|cu129], depending on your CUDA version
uv sync
source .venv/bin/activate
```

#### Hello World

一个简单的无图像测试，用于验证环境设置并下载模型。

```
python example.py \
  --question "Hello" \
  --model_path sensenova/SenseNova-SI-1.1-InternVL3-8B
```

### 示例

#### 示例 1

本示例来自 [MMSI-Bench](https://github.com/InternRobotics/MMSI-Bench) 的 `Pos-Obj-Obj` 子集：

```
python example.py \
  --image_paths examples/Q1_1.png examples/Q1_2.png \
  --question "<image><image>
You are standing in front of the dice pattern and observing it. Where is the desk lamp approximately located relative to you?
Options: A: 90 degrees counterclockwise, B: 90 degrees clockwise, C: 135 degrees counterclockwise, D: 135 degrees clockwise" \
  --model_path sensenova/SenseNova-SI-1.1-InternVL3-8B 
# --model_path OpenGVLab/InternVL3-8B 
```

**示例 1 详情**

**Q：**你正站在骰子图案前观察它。台灯相对于你大致位于哪个方向？选项：A：逆时针 90 度，B：顺时针 90 度，C：逆时针 135 度，D：顺时针 135 度

#### 单次运行中测试多个问题

准备一个类似 [examples/examples.jsonl](https://huggingface.co/sensenova/SenseNova-SI-1.1-InternVL3-2B/blob/main/examples/examples.jsonl) 的文件，其中每行表示一个问题。

模型仅加载一次，并按顺序处理问题。各问题彼此保持独立。

> 有关 jsonl 格式的更多细节，请参阅单图像数据和多图像数据的文档。

```
python example.py \
  --jsonl_path examples/examples.jsonl \
  --model_path sensenova/SenseNova-SI-1.1-InternVL3-8B 
# --model_path OpenGVLab/InternVL3-8B 
```
