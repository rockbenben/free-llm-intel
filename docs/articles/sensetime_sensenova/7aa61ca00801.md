# ConsistCompose：面向图像合成的统一多模态布局控制

[![GitHub Stars](https://img.shields.io/github/stars/OpenSenseNova/ConsistCompose?style=social)](https://github.com/OpenSenseNova/ConsistCompose) [![Project Page](https://img.shields.io/badge/Project%20Page-ConsistCompose-blue)](https://OpenSenseNova.github.io/ConsistCompose/) [![arXiv](https://img.shields.io/badge/arXiv-2511.18333-b31b1b.svg)](https://arxiv.org/abs/2511.18333) [![](https://img.shields.io/static/v1?label=%F0%9F%A4%97%20Hugging%20Face&message=Model&color=green)](https://huggingface.co/sensenova/ConsistCompose) [![](https://img.shields.io/static/v1?label=%F0%9F%A4%97%20Hugging%20Face&message=Dataset&color=yellow)](https://huggingface.co/datasets/sensenova/ConsistCompose3M)

## 概述

尽管在整合视觉理解与图像生成的统一多模态模型方面已取得显著进展，但面向多实例图像合成的精确布局控制仍是一个尚未被充分探索的挑战。现有方法通常依赖任务特定模块或结构化空间编码器，这限制了它们与视觉推理、身份保持等更广泛多模态能力的兼容性。

在本工作中，我们提出 **ConsistCompose**，这是一个统一多模态框架，旨在通过语言驱动的范式实现布局可控的多实例生成。ConsistCompose 构建于 Bagel 的 MoT 架构之上，引入语言嵌入式布局接地的生成（Linguistic-Embedded Layout-Grounded Generation，LELG），将布局坐标作为文本 token 直接嵌入语言提示中——从而无需专门的空间编码器或几何分支。为支持大规模训练，我们构建了 **ConsistCompose3M**，这是一个包含 3.4M 样本、带有布局与身份标注的数据集，其中包括 2.6M 文本引导对和 0.8M 图像引导对，提供结构化的空间与语义监督。

ConsistCompose 在布局控制生成基准上取得最先进性能：在 COCO-Position 上带来 7.2% 的布局 IoU 提升和 13.7% 的 AP 改进（实例成功率为 92.6%，图像成功率为 76.1%），同时在 MS-Bench 和 MS-Bench-Random 的核心指标（DINO、mIoU、AP）上领先。值得注意的是，该框架保持了强大的通用多模态能力——在 MMBench、MMMU 和 GenEval 上的性能与其 Bagel 骨干相当——同时增强了多参考生成中的身份保持。一个关键组件 Coordinate-CFG 通过分层无分类器引导进一步增强空间保真度，在严格遵循布局与视觉真实感之间取得平衡。

更重要的是，ConsistCompose 建立了一个统一范式，将布局接地的文本到图像合成、多参考身份保持组合以及通用多模态理解整合到单一生成接口中。我们分析了坐标引导缩放的影响，验证了 LELG 范式的灵活性，并展示了其在不牺牲语义连贯性的情况下处理复杂、杂乱布局的能力。ConsistCompose 为布局可控的多模态生成提供了有原则的解决方案，指向更细粒度空间推理与交互式场景合成的未来方向。

所有技术细节、训练配方和补充结果均已公开，以促进统一布局感知多模态系统的进一步研究。

## 发布信息

我们推出 [**ConsistCompose-BAGEL-7B-MoT**](https://huggingface.co/sensenova/ConsistCompose-BAGEL-7B-MoT)，其构建于一个统一理解与生成基础模型之上。

具体细节见 [**ConsistCompose 技术报告**](https://arxiv.org/abs/2511.18333)。我们的 **ConsistCompose-BAGEL-7B-MoT** 保留了原始 BAGEL 完整的图像通用生成与理解能力，同时引入增强的布局控制，以实现精确的多实例组合。
