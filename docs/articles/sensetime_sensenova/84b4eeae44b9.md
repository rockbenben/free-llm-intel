近期，商汤小浣熊在 C 端和 B 端同时取得进展。

C 端方面，在「AI新榜-AI产品榜」周榜中的排名大幅上升，飙升33名，实现全球涨幅第一，其中周访问量进入国内前三；

B 端方面，收获沙利文两份报告的认可——**一份确认其在企业级桌面智能体市场TOP3位置，一份确认其在企业级数据分析智能体赛道的领先地位**：

🚀「AI新榜-AI产品榜」第104期周榜（10月26日—11月1日）显示，商汤小浣熊单周排名上升33名，位列总榜全球第16、国内榜第8，是本期全榜涨幅最大的产品。

周访问量超过2045万，在国内产品中排名第三，流量势能强劲。榜单覆盖包括ChatGPT、Gemini等全球上千家AI产品，评价维度包括访问量、下载量、提及量和声量值等多个维度，其中商汤小浣熊本次排名上升主要由访问量大幅增长带动，即实际使用规模。

💻 沙利文《2026年全球桌面智能体市场研究报告》发布的中国企业级桌面智能体榜单中，商汤小浣熊排名第三，与WorkBuddy、千问办公同列前三位。

该榜单的综合评分由"产品技术领先"和"用户落地实效"两个维度构成，即技术能力与实际使用效果的综合结果。

🥇沙利文《2026年中国企业级数据分析智能体市场研究》中，商汤小浣熊是"独立应用型数据分析Agent"赛道唯一入选Leaders梯队的产品，排名第一，其余厂商分列挑战者与追随者梯队。

报告从六个维度评估能力，商汤小浣熊在数据接入与语义治理、分析深度与任务自主性、可信度与质量控制、交互体验与业务可用、企业级工程化与部署、生态嵌入与闭环六个维度均处领先，其中三个维度优势突出。

**“通用与专业，商汤小浣熊都有。”**

未来，依托**商汤日日新SenseNova大模型**强大的底层技术与生态闭环能力，商汤小浣熊将继续深耕企业级数据分析与通用桌面办公场景，为更多业务用户打造“能搞定工作的AI助手”，持续领跑企业级AI智能体赛道。
