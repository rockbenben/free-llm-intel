十几年前的论文为何还能接连获奖？因为经过了时间的检验。

计算机图形学顶级会议SIGGRARH ASIA 2024正式落幕，前沿学术成果与交流十分亮眼，本次会议正式颁发的奖项中：

商汤科技董事长兼首席执行官徐立于2012年作为第一作者发表的论文“Structure extraction from texture via relative total variation”获得本届会议的时间检验奖(Test-of-Time Award)。

![1.jpg](https://oss.sensetime.com/58296789573ee55418bb315c93027aaf/1.jpg)

图说：SIGGRAPH ASIA 2024颁奖现场。该论文于2012年发表在国际一流期刊ACM Transactions on Graphics（TOG, 《ACM图形学学报》）上，论文提出了一种基于总变差形式新模型，可以有效分解图像中的结构信息和纹理，并且无需特别指定纹理是否规则或对称。论文地址：[https://dl.acm.org/doi/10.1145/2366145.2366158](https://dl.acm.org/doi/10.1145/2366145.2366158)

由国际计算机学会(ACM, Association for Computing Machinery)举办的SIGGRAPH ASIA是世界上影响最广、规模最大，同时也是最权威的计算机图形和交互技术展览及会议之一，为亚洲相关技术通往世界搭建了“高速公路”，被称为图形图像研究领域的“奥斯卡”。

SIGGRAPH ASIA在去年首次设立“时间检验奖”，旨在表彰发表时间距今10年以上、且对计算机图形学和交互式技术持续产生重大影响、引领相关行业发展的论文。

徐立已连续两年获得这一殊荣，其于2011年作为第一作者发表的论文“Image Smoothing via

![2.jpg](https://oss.sensetime.com/7b0408a901117a3787ee428b2f9cb942/2.jpg)

图说：SIGGRAPH ASIA 2023颁奖现场。该论文于2011年发表在ACM Transactions on Graphics（TOG, 《ACM图形学学报》）上，同年被SIGGRAPH Asia 2011 收录，是该届大会引用最高的论文，并连续五年（2011-2015年)成为TOG论文引用之首。相比以往一般的图像平滑方法，该论文的创新方法在保留较大梯度（图像边缘）的同时去除较小梯度，并用极简单的代码实现。

论文地址：[https://dl.acm.org/doi/10.1145/2070781.2024208](https://dl.acm.org/doi/10.1145/2070781.2024208)

获得时间检验奖的论文在技术创新和实践应用方面具有显著成就——它们不仅在理论上有所建树，而且在实际应用中也展现出了强大的生命力。对于连续两度获奖这个好消息，徐立表示：“我也是刷朋友圈刷到（这个消息）的。”

时间是最好的试金石，商汤科技坚持长期主义，在引领全球的人工智能技术研究方面持续投入，未来将继续发挥在计算机视觉与深度学习领域的优势，打造通用视觉模型深耕各个应用场景。
