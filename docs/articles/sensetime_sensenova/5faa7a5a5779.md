# SenseNova 6.8 Code2Video

一个由代码驱动的视频创作模型，基于 Qwen3.8-27B 微调

[![GitHub](https://img.shields.io/badge/GitHub-skill_%C2%B7_prompts-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/OpenSenseNova/SenseNova-6.8-Code2Video) ![License: Apache 2.0](https://img.shields.io/badge/License-Apache_2.0-2563eb?style=flat-square) ![Params: 27B](https://img.shields.io/badge/Params-27B-db2777?style=flat-square) ![Context: 512K](https://img.shields.io/badge/Context-512K-0891b2?style=flat-square) [![Discord: OpenSenseNova](https://img.shields.io/badge/Discord-OpenSenseNova-5865F2?style=flat-square&logo=discord&logoColor=white)](https://discord.com/invite/BuTXPHmQub)

[发布短片（90 秒，带声音）](https://huggingface.co/sensenova/SenseNova-6.8-Code2Video/resolve/main/media/launch/sensenova_codevideo_launch_film.mp4)，由 SenseNova 6.8 Code2Video 制作

我们提出 SenseNova 6.8 Code2Video，一个面向代码驱动视频创作的轻量级开放模型。该模型通过生成可执行代码来构建并渲染视频，目前主要聚焦于完全用代码实现的短视频。初步结果显示，它在动态设计中具备良好的视觉构图与运动编排能力，表明轻量级模型在程序化视频创作方面具有潜力。

我们选择以代码作为视频创作的切入点，部分原因在于它能够连接不同的模型与创作工具。除了直接构建并渲染视觉内容之外，代码还可以调用图像生成、视频生成、3D 建模和视频编辑的模型与工具，将生成、编辑与合成串联成完整创作工作流。

我们相信，代码可以成为想法与成品之间的共同语言。我们的长期目标是构建一个通过代码协调不同生成模型与创作工具、跨媒介创作数字内容的模型。SenseNova 6.8 Code2Video 是朝向这一方向的第一步。接下来，我们将进一步扩大模型规模，并将这些能力扩展到编辑、合成、动画和 3D 内容创作。

## 部署

### LightLLM

```
docker run --rm --gpus all --ipc=host -p 8000:8000 \
  -v /path/to/SenseNova-6.8-Code2Video:/model \
  ghcr.io/modeltc/lightllm:main \
  python -m lightllm.server.api_server \
    --model_dir /model \
    --tp 4 \
    --max_req_total_len 524288 \
    --host 0.0.0.0 --port 8000
```

### vLLM

```
docker run --rm --gpus all --ipc=host -p 8000:8000 \
  -e VLLM_ALLOW_LONG_MAX_MODEL_LEN=1 \
  -v /path/to/SenseNova-6.8-Code2Video:/model \
  vllm/vllm-openai:latest \
    --model /model \
    --tensor-parallel-size 4 \
    --max-model-len 524288 \
    --reasoning-parser qwen3 \
    --enable-auto-tool-choice \
    --tool-call-parser qwen3_coder \
    --host 0.0.0.0 --port 8000
```

### SGLang

```
docker run --rm --gpus all --ipc=host -p 8000:8000 \
  -e SGLANG_ALLOW_OVERWRITE_LONGER_CONTEXT_LEN=1 \
  -v /path/to/SenseNova-6.8-Code2Video:/model \
  lmsysorg/sglang:latest \
  python -m sglang.launch_server \
    --model-path /model \
    --tp-size 4 \
    --context-length 524288 \
    --reasoning-parser qwen3 \
    --tool-call-parser qwen3_coder \
    --host 0.0.0.0 --port 8000
```

## 推荐运行框架：Claude Code

一部完整的影片是一项长周期任务：模型编写并渲染代码、审看画面并修改，如此一轮接一轮。SenseNova 6.8 Code2Video 可持续运行 **超过 10 小时、超过 2,000 轮**。请为这种长度的运行配置 Claude Code：

| 设置 | 取值 | 配置方式 |
| --- | --- | --- |
| 上下文窗口 | 512K | `CLAUDE_CODE_MAX_CONTEXT_TOKENS=524288` |
| 自动压缩 | 0.8 | `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE=80` |
| 最大输出 | 64K | `CLAUDE_CODE_MAX_OUTPUT_TOKENS=64000` |
| 每次运行的轮数 | 2,000+ | `--max-turns 2000` 或更多 |
| 每次运行的时长 | 10 h+ | `timeout 10h` 或更长 |

请显式设置上下文窗口，否则 Claude Code 会把未知模型当作 200K 模型处理。将压缩阈值设为 0.8、输出上限设为 64K 后，每个请求都保持在服务端 512K 的限制之内。

将 endpoint 和这些变量放入一个私密设置文件，并通过 `ANTHROPIC_AUTH_TOKEN` 或 `ANTHROPIC_API_KEY` 提供凭据：

```
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://your-endpoint.example.com",
    "ANTHROPIC_MODEL": "your-deployed-model-name",
    "CLAUDE_CODE_MAX_CONTEXT_TOKENS": "524288",
    "CLAUDE_AUTOCOMPACT_PCT_OVERRIDE": "80",
    "CLAUDE_CODE_MAX_OUTPUT_TOKENS": "64000"
  },
  "model": "your-deployed-model-name"
}
```

避免缓慢的 shell 初始化：每次 Bash 调用都会启动一个新的 shell。

## 使用方法

制作一部影片分为三个阶段：

| 阶段 | 执行方 | 输出 |
| --- | --- | --- |
| 1. 提示词增强 | 能力较强的通用模型（我们使用 Claude Opus 5.5）配合[提示词增强模板](https://github.com/OpenSenseNova/SenseNova-6.8-Code2Video/blob/main/prompts/enhance_prompt.md) | `dense_prompt.md` |
| 2. 制作 | 在 Claude Code 中使用 `code-video` skill 的 SenseNova 6.8 Code2Video | `out/final.mp4`、`SPEC.md`、`VERIFY.md` |
| 3. 修订（可选） | 创作者写下修改意见；SenseNova 6.8 Code2Video 在同一项目中落实这些意见 | 影片的新版本 |

使用上述设置执行阶段 2：

```
cd /path/to/task   # contains dense_prompt.md, assets/ and .claude/skills/code-video
claude -p --settings /path/to/private-settings.json --model your-deployed-model-name \
  --max-turns 2000 --permission-mode acceptEdits --allowedTools "Bash,Read,Write,Edit,Glob,Grep,Skill" \
  'Use the project code-video skill. Read .claude/skills/code-video/SKILL.md and dense_prompt.md, then the relevant craft guides. Produce the complete video and deliver out/final.mp4, SPEC.md and VERIFY.md.'
```

该运行会在不询问的情况下执行 shell 命令，因此请将其放在隔离的工作环境中启动。若需修订，在同一文件夹中运行 `claude -p --continue`，并以创作者的修改意见作为提示词。

将 skill 原样复制到 `.claude/skills/code-video`，并把具体任务要求写入提示词。环境搭建步骤与依赖见 [GitHub 仓库](https://github.com/OpenSenseNova/SenseNova-6.8-Code2Video)。

## 制作轨迹

[`trajectories/all.openai.jsonl`](https://huggingface.co/sensenova/SenseNova-6.8-Code2Video/blob/main/trajectories/all.openai.jsonl) 每行对应一部影片，采用 OpenAI messages 格式。

每行包含 `messages`、`tools`、`images`、`enable_thinking` 和 `metadata`。messages 中包含推理过程、工具调用与结果、重试记录以及压缩摘要。图片以 `<image>` 占位符出现；有序的 `images` 数组给出它们相对于 `trajectories/` 的路径，全部 357 张图位于 [`trajectories/figures/`](https://huggingface.co/sensenova/SenseNova-6.8-Code2Video/tree/main/trajectories/figures)。私有路径与主机已做匿名化处理，因此记录中的命令无法直接复现运行。
