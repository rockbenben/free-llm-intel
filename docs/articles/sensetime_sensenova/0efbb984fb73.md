今天，我们正式发布并开源 **SenseNova U1.6**。

一张海报已经好看到想发出去了。放大一看，里面却有个错字。画出这张图的 AI，能自己发现并改掉它吗？

SenseNova U1.6 延续了 U 系列的理解与生成统一范式，首次为该系列的 8B 开源模型带来原生图像自修正。 开启自修正后，同一个模型可以先生成首稿，再对照原始提示检查画面，并根据发现的文字问题生成修正版。

字要写得准，画面也要经得起细看。 人像的光影、插画的笔触、海报里字体与版式的配合，也是 U1.6 这次打磨的细节。

在内部用户评测中，U1.6 Lite 的美学得分比 U1.5 Lite 高约10%。在 UltraTextBench 密集信息图测试中，U1.6 Lite 的得分从单次生成的 86.04 升至开启自修正后的 92.28，相对提升 约 7%。

![](https://oss.sensetime.com/strapi/uploads/external_3a900a57d7b43124553d8f31_002_word_image_2_4b291028ff.jpeg)

我们已正式开源 SenseNova U1.6 模型权重。用户还可在 **商汤小浣熊、Seko、Kapi相机、SenseNova Token Plan、SenseNova Studio **等产品或平台上体验。

模型已上线** ComfyUI，**创作者可在熟悉的工作流中调用它的图像生成与自修正能力。

![](https://oss.sensetime.com/strapi/uploads/external_3a900a57d7b43124553d8f31_003_word_image_3_516ab0a4ee.jpeg)

当“画得出来”不再是难题，“画得恰到好处”才是真正的分水岭。同一句提示词，有人想要照片般的真实，有人期待风格化的表达——“美”从来没有统一答案。SenseNova U1.6 的选择，是把美学反馈做得更细，让输出更贴合不同题材的审美期待。人像与写实看重真实感、质感与光影，艺术创作强调创意与风格，信息图则需兼顾文字、布局与整体设计。针对不同题材各有侧重的审美逻辑，SenseNova U1.6 训练面向不同内容的美学模型，把审美要求转化为有针对性的训练反馈，细致改善影响最终观感的每一处细节。针对文字生成，我们加强了透视文字、艺术字等复杂表达，引入了面向文字与布局的信息图美学模型，在提升文字准确性的同时，保留字体表现力、空间透视与版面美感——让“写对”与“好看”不再互相牺牲。

**「 人像 ：把氛围感"拍"进一张图 」**

人像创作的核心是真实感、质感与光影。SenseNova U1.6 对“相机语言”的理解更进一步：动态模糊的速度感、胶片颗粒与复古色调、不同相机的镜头质感，都能通过一句提示词直接调用。**从复古胶片到经典相机风格，数十种胶片质感随心选择**——无论是“大片感”还是“随手一拍的真实”，都由你决定。*（以下图片皆能点开查看到大图）*

**「 插画：笔触即风格 」**

插画的生命力在于创意与风格。SenseNova U1.6 在笔触层面的进步尤为明显：灵感类、抽象类插画画风更灵动，毛毡风等材质感风格质感细腻，画面分割与构图也更大胆多样。同一主题换一种画风描述，便能得到截然不同的视觉语言。

SenseNova U1 Pro 已经展现出 Agentic Generation Loop 的潜力，SenseNova U1.6 则在信息图生成中更进一步，尝试将这一闭环内化为模型自身的能力。

生成首张信息图后，模型会对照用户意图检查画面，针对局部或大面积文字模糊、错字乱码、英文拼写错误、编号错乱等问题提出具体修改意见，再结合原始提示与已有画面完成修正。“生成—检查—修改”在同一次生成中无缝衔接，把原本需要用户复查、反馈、再编辑的工作，交给模型自己完成。我们同时观察到，尽管自修正训练仅针对信息图，这一能力在部分非信息图场景中同样展现出泛化效果。

- 自主检查：对照用户意图审视已生成画面
- 精准定位：文字模糊、错字乱码、英文拼写错误、编号错乱
- 闭环修正：结合原始提示与已有画面完成迭代
- 能力泛化：自修正从信息图延伸至部分非信息图场景

**「实测表现：字更准，返工更少」**

高密度信息图最怕的不是画面不好看，而是“字错了”。一处错字、一个乱码，就可能让整张图失去专业感。SenseNova U1.6 把校对的活儿接了过来：出图后主动对照意图自查，发现问题即行修正，交付到用户手里的，是可以直接使用的成稿。在 UltraTextBench 密集信息图测试中，自修正带来的提升稳定覆盖多类高难度任务，验证了这条“自我改进”路径的有效性。模型不仅能“画得好”，还能在复杂信息图上“写得准”。

在后训练阶段，SenseNova U1.6 沿用 SenseNova U1.5 的多专家、多奖励强化学习范式，结合美学奖励模型与图文交错自修正能力，引入更多面向不同内容与能力方向的专家，并为每位专家配置多种奖励，让训练兼顾各类图像内容的质量要求。
