# SenseNova-RoboRSI-27B-Preview

[简体中文](https://huggingface.co/sensenova/sensenova-roborsi-27b-preview/blob/main/README_zh.md) · [GitHub](https://github.com/OpenSenseNova/SenseNova-RoboRSI) · [演示](https://huggingface.co/sensenova/SenseNova-RoboRSI-27B-Preview#demonstrations) · [快速开始](https://huggingface.co/sensenova/SenseNova-RoboRSI-27B-Preview#quickstart)

**SenseNova-RoboRSI-27B-Preview** 是一个面向具身智能体的开放权重 **27B 视觉语言模型**。通过模型与 Harness 联合 RSI，它从经过验证的交互经验中学习，发展出在仿真环境和真实机器人上进行规划、动作决策以及基于反馈的纠正能力。

本指南介绍如何使用 **RoboRSI Harness** 在 **LIBERO-Pro 和 RoboCasa365** 上部署模型并复现基准测试。RoboDojo 复现说明将随 RoboRSI 即将推出的 RoboDojo 支持一同发布。详细技术报告即将发布。

[![SenseNova-RoboRSI-27B-Preview 在 RoboDojo、LIBERO-Pro 和 RoboCasa365 上的结果](https://huggingface.co/sensenova/SenseNova-RoboRSI-27B-Preview/resolve/main/assets/roborsi-27b-preview-benchmarks.webp)](https://huggingface.co/sensenova/SenseNova-RoboRSI-27B-Preview/blob/main/assets/roborsi-27b-preview-benchmarks.webp)

- **RoboDojo：** 在 VLA 辅助执行下，实现 **平均得分 26.13** 和 **任务成功率 20.83%**。在 RoboDojo 团队的评估中，其平均得分仅比 GPT-6 Astra 低 **2.84 分**。在复杂操作任务中，该模型会主动检查视觉细节、推理空间关系，并根据执行反馈纠正动作。
- **LIBERO-Pro：** 在 VLA 辅助执行（System 2 + System 1）下达到 **92.5% 成功率**，在直接 VLM 控制（System 2）下达到 **95.0%**，在两种设置下均在参与比较的模型中排名第二，仅次于 GPT-6 Astra。这些结果展示了其在不同执行架构下的具身规划与决策能力。
- **RoboCasa365：** 相较 Qwen3.8-27B 基座模型，RSI 训练将成功率从 **26.0% 提升至 46.5%**，同时将平均输出 token 数从 **59.5K 降至 15.9K**，降幅达 **73.3%**。从交互经验中学习可同时提升任务表现和推理效率。

## 快速开始

### 1. 部署模型

#### 安装 vLLM

在你的推理环境中，安装与兼容 NVIDIA 驱动配套的 CUDA 12.9 构建版本：

```
pip install "vllm==0.21.0" huggingface_hub \
  --extra-index-url https://download.pytorch.org/whl/cu129
```

其他 CUDA 构建版本请参阅 [vLLM 安装指南](https://docs.vllm.ai/en/v0.21.0/getting_started/installation/gpu/)。

#### 下载模型

下载完整检查点，包括 tokenizer、processor、生成配置和聊天模板：

```
export MODEL_DIR="$PWD/models/sensenova-roborsi-27b-preview"
hf download sensenova/sensenova-roborsi-27b-preview \
  --local-dir "$MODEL_DIR"
```

对于已有的本地检查点，将 `MODEL_DIR` 设置为其绝对路径。

#### 启动服务

```
export CUDA_VISIBLE_DEVICES=0,1,2,3

vllm serve "$MODEL_DIR" \
  --served-model-name sensenova-roborsi-27b-preview \
  --host 0.0.0.0 \
  --port 8000 \
  --dtype bfloat16 \
  --tensor-parallel-size 4 \
  --max-model-len 262144 \
  --generation-config auto \
  --chat-template "$MODEL_DIR/chat_template.jinja" \
  --reasoning-parser qwen3 \
  --enable-auto-tool-choice \
  --tool-call-parser qwen3_coder \
  --structured-outputs-config '{"backend":"xgrammar","disable_any_whitespace":true}' \
  --enable-prefix-caching \
  --mamba-cache-mode align
```

对于此预览版，我们建议使用 **`medium` 推理强度**。在 vLLM Chat Completions 请求中显式设置 `chat_template_kwargs.reasoning_effort`，如下所示。若省略此设置，随附的聊天模板默认使用 `xhigh`。

#### 检查 endpoint

在同一台机器的另一个终端中，检查服务健康状况并发送一个简短的机器人规划请求：

```
curl --fail http://127.0.0.1:8000/health
curl --fail http://127.0.0.1:8000/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sensenova-roborsi-27b-preview",
    "messages": [{
      "role": "user",
      "content": "A robot needs to place a mug on a coaster. Give a short plan and explain how to verify that the mug is stable before releasing it."
    }],
    "max_tokens": 8192,
    "chat_template_kwargs": {"reasoning_effort": "medium"},
    "stream": false
  }'
```

### 2. 连接 RoboRSI Harness 并运行评估

按照[模型评估指南](https://github.com/OpenSenseNova/SenseNova-RoboRSI/blob/main/docs/model-evaluation.md)安装 RoboRSI Harness 和评估环境，然后使用以下命令：

```
export OPENAI_BASE_URL='http://127.0.0.1:8000/v1'
export OPENAI_API_KEY='EMPTY'
export MODEL_NAME='sensenova-roborsi-27b-preview'

# LIBERO-Pro: VLM + VLA (System 2 + System 1)
# Set up the tool environment, download weights, and deploy VLA/SAM3 in the background; no automatic evaluation
python scripts/deploy/libero_tools.py serve \
  --model-config configs/models/roborsi_27b.yaml \
  --work-dir work/model_eval/libero_tools &

# Wait for Services ready before running the evaluation command below (default URLs shown)
ROBORSI_VLA_URL=http://host.docker.internal:24001 \
ROBORSI_SAM3_URL=http://host.docker.internal:24002 \
python scripts/evaluation/evaluate_model.py --benchmark libero_pro \
  --benchmark-config configs/benchmarks/libero_pro_80.yaml \
  --model-config configs/models/roborsi_27b.yaml \
  --agent-config configs/agents/libero/sensenova_roborsi_27b_vla_sam3.yaml

# LIBERO-Pro: Direct VLM control (System 2); skip the VLA/SAM3 deployment command above
python scripts/evaluation/evaluate_model.py --benchmark libero_pro \
  --benchmark-config configs/benchmarks/libero_pro_80.yaml \
  --model-config configs/models/roborsi_27b.yaml \
  --agent-config configs/agents/libero/sensenova_roborsi_27b_no_tools.yaml

# RoboCasa365
python scripts/evaluation/evaluate_model.py --benchmark robocasa365

# RoboDojo: Evaluation support will be available in a future RoboRSI Harness update
```

## 基于 RoboRSI Harness 构建

SenseNova-RoboRSI-27B-Preview 运行于 **RoboRSI Harness** 之中，该 Harness 是任务执行、评估和迭代改进的共同基础。它将模型学到的能力与机器人动作连接起来，并将新的交互转化为下一轮 RSI 的证据。

[![RoboRSI Harness 架构：智能体接口、执行循环、原生基准集成和评估驱动的改进](https://huggingface.co/sensenova/SenseNova-RoboRSI-27B-Preview/resolve/main/assets/sensenova-roborsi-overview-en.webp)](https://huggingface.co/sensenova/SenseNova-RoboRSI-27B-Preview/blob/main/assets/sensenova-roborsi-overview-en.webp)

- **可组合执行。** 连接模型、提示词、技能和工具/MCP；通过统一的智能体循环协调 VLA 技能、脚本化动作或末端执行器控制。
- **可复现评估。** 基准适配器保留原生执行与评分，同时可配置的上下文、缓存和批量执行支持跨环境的可重复实验。
- **用于持续学习的经验。** 完整轨迹和导出的训练回合将执行与模型训练连接起来；版本化重测可识别哪些 Harness 变更值得延续。

我们开发并维护 [GitHub 上的 SenseNova-RoboRSI](https://github.com/OpenSenseNova/SenseNova-RoboRSI)，作为社区部署、复现和持续训练的共同基础。请关注该仓库以获取 Harness、评估数据、中间结果和发布更新。
