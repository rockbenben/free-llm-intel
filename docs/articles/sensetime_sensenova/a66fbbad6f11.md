## 🌟 概述

SenseNova-Vision 是计算机视觉的统一多模态模型。它将异构视觉感知任务重新表述为**文本生成**、**图像生成**或**混合文本图像生成**，而不是依赖于每个单独任务的特定于任务的头、解码器或损失函数。该模型支持共享指令跟踪界面内的结构化视觉理解、密集几何预测、分割和多视图视觉几何。

## 🚀 型号说明

SenseNova-Vision 将计算机视觉重新思考为**统一的多模态生成**。传统的计算机视觉系统通常附加特定于任务的预测头，用于检测、分割、深度、表面法线或 3D 几何。相反，SenseNova-Vision 通过统一多模态模型的本机输入输出空间来表达这些异构任务。

自然语言指令和可选的视觉提示指定目标任务、区域、视图、输出模式和解码约定。然后，模型根据任务生成不同的目标格式：

|目标类型|代表任务|输出形式|
| --- | --- | --- |
|结构化文本|检测、参考定位、OCR、GUI 基础、关键点、相机参数 |具有标准化坐标或结构化字段的文本记录 |
|密集图像|深度、表面法线、点图、二值蒙版、颜色编码蒙版 |类似图像的目标图 |
|混合文本图像 |多实例分割、扎根对话分割、构图感知 |文本标签加上生成的蒙版或视觉图 |

该公式允许单个模型涵盖结构化视觉理解、密集几何预测、分割和多视图视觉几何，同时保持输出可针对标准基准进行解码。

## 🌐 主要特点

- **统一的视觉任务制定：** 异构计算机视觉任务被投射到统一多模态模型的本机文本、图像和混合生成空间中。
- **没有特定于任务的头：** 该模型不依赖于单独的检测、分割、深度、法线或几何头。
- **可解码输出：** 生成的文本和图像可以转换回基准兼容的框、点、OCR 字符串、蒙版、深度图、法线图、点图和摄像机记录。
- **广泛的任务覆盖范围：** 同一模型处理结构化视觉理解、分割、密集几何和多视图视觉几何。
- **指令定义的任务变体：** 自然语言指令可实现超出固定基准模式的灵活任务定义。

## 🛠️ 如何使用

请使用SenseNova-Vision GitHub存储库中的官方推理代码：

```
git clone https://github.com/OpenSenseNova/SenseNova-Vision.git
cd SenseNova-Vision
```

### 环境设置

从存储库根目录创建环境：

```
bash setup.sh sensenova-vision
conda activate sensenova-vision
```

### 下载模型

您可以使用 `huggingface_hub` 从 Hugging Face 下载模型权重：

```
from huggingface_hub import snapshot_download

model_path = snapshot_download("sensenova/SenseNova-Vision-7B-MoT")
print(model_path)
```

打印出来的`model_path`指向本地检查点目录，可以作为模型路径进行推理。

### 运行策划的示例

我们提供了一个精选示例来快速验证环境和模型设置：

```
bash scripts/run_sensenova_vision.sh example
```

## 📚 训练数据

SenseNova-Vision 在 **SenseNova-Vision-Corpus-50M** 上进行训练，这是一个大型计算机视觉指令响应语料库。该语料库将异构注释转换为具有视觉输入、自然语言指令和表示为文本、图像或混合文本图像响应的可解码目标的共享模式。

该语料库涵盖四个任务系列：

|任务族|代表任务|目标表示 |
| --- | --- | --- |
|结构化视觉理解|检测、参考定位、指向、关键点、OCR、布局、GUI 基础 |具有标准化坐标和轻量级结构标记的文本记录 |
|密集几何预测|单目深度估计和表面法线预测|确定性编码的图像目标 |
|细分|指称、推理、互动、通用和扎根对话分段 |二进制掩码、颜色编码掩码或混合文本图像响应 |
|多视角视觉几何|点图重建和相机位姿估计|类似图像的点图和结构化摄像机记录|

## ⚠️ 限制

- **并非适用于每项任务的专业模型：** 尽管 SenseNova-Vision 涵盖了许多任务，但特定于任务的模型在某些专门基准上仍可能优于它。
- **输出解析与任务相关：**文本输出需要特定于任务的解析器，图像输出需要与训练协议一致的解码规则。
- **不保证度量精度：** 在下游使用之前，应仔细验证密集深度、法线、点图和相机位姿预测。
- **提示灵敏度：** 作为指令遵循模型，性能可能会因提示措辞、输出模式和视觉提示样式而异。
- **数据集和基准偏差：**模型行为反映了训练语料库的分布和注释约定。

## 🛡️ 道德考虑

SenseNova-Vision 可能会生成不正确的定位、分割、深度、法线或相机预测。用户应避免在未经独立验证的情况下在安全关键设置中部署模型。当用于涉及人物、面部、文档、医疗场景、监控图像或私人环境的数据集时，用户有责任遵守适用的隐私、同意和数据治理要求。
