不经过真实机器人数据训练或微调，仅凭在仿真环境中学到的经验，一台机械臂能否在真实世界中完成抓取、放置和积木堆叠？

商汤科技最新发布的具身大脑** SenseNova-RoboRSI-27B** 正式版给出了新的探索成果。使用同一份仿真训练权重，模型在 Piper X 机械臂上完成积木堆叠，10 次实验成功 9 次；在 Piper 机械臂上完成多类型物体抓取与放置，10 次实验成功 6 次。

这一表现背后，是模型自主决策与执行能力的进一步升级。相较于 Preview 版本主要依赖视觉语言动作模型（VLA）执行任务，正式版能够自主判断何时调用 VLA、何时通过代码直接控制机械臂，并根据实际执行反馈调整动作策略。**在知名的机器人仿真榜单 RoboDojo 最新版评测中，模型取得 34.7 分的平均成绩**，较 Preview 版本的 10.0 分提升至原来的 3.47 倍，以 27B 的模型体量超越 RoboDojo 官方团队测试的 GPT-6-Astra 的成绩。

SenseNova-RoboRSI-27B 通过 Code as Policy 协调双臂，观察二阶魔方的六个面后将其还原

**多轮 RSI 迭代优化**
**让模型逐轮学会新的执行方式**

此前的 SenseNova-RoboRSI Preview 版本主要依赖预设的 VLA 技能完成机器人操作，而正式版进一步拓展了模型的自主决策与执行能力。面对不同任务，模型能够使用统一的工具体系，自主判断何时调用 VLA 生成动作轨迹，何时通过代码计算目标位置并直接控制机械臂，还能根据实际执行反馈审查、调整动作方案。

这一能力建立在 VLA 与 Code as Policy 两种技术路径的协同之上。VLA 能够根据视觉观测生成动作轨迹，适合动态接近、连续倾倒等复杂操作；Code as Policy 则通过程序进行空间计算和目标位置规划，适合积木堆叠、精准放置、数字按键等具有明确空间约束的任务。

![](https://oss.sensetime.com/strapi/uploads/external_9f91ef477d2f14c620dc1f37_002_external_image_2_be6f40d717.png)

*SenseNova-RoboRSI-27B 通过多轮 RSI 学习调用 VLA 技能和编写控制代码，并将仿真中学到的操作迁移到两款真实机械臂上。*

在实际操作中，模型可以根据任务需求灵活切换两种执行方式。例如，在叠碗任务中，模型先调用 VLA 完成抓取，再根据碗与目标位置的相对关系，通过代码调整夹爪位置，最终完成精准放置。正式版中，VLA 和 Code as Policy 的环境步执行比例分别为 41.9% 和 58.1%，体现了模型对不同执行策略的自主组织能力。

叠碗过程中，Agent 根据执行反馈在 VLA 与 Code as Policy 之间切换，调整抓取和放置动作。

除了叠碗任务，模型还能够通过 Code as Policy 控制机械臂完成多种具有空间约束的操作，包括根据物体朝向调整抓取方式、侧推 T 形块、双臂对齐衣摆两角，以及对准孔位后分步下探等。

![](https://oss.sensetime.com/strapi/uploads/external_9f91ef477d2f14c620dc1f37_004_external_image_4_1d66d6e1f3.png)

*模型通过 Code as Policy 控制局部动作，包括按物体朝向抓取、侧推 T 形块、双臂对准衣摆两角，以及对准孔位后分步下探。*

**多轮 RSI 迭代训练**
**持续提升模型决策与执行能力**

为了让模型逐步掌握新的执行方式，SenseNova-RoboRSI-27B 正式版采用多轮 RSI（Recursive Self-Improvement）迭代优化机制。

这一机制的核心，是让模型与执行框架 Harness 协同迭代：教师模型负责探索和发现问题，Harness 持续拓展模型可调用的工具与执行能力，27B 模型则通过训练逐步掌握新的工具和执行方式。

具体而言，每轮迭代首先由教师模型 GPT-6 Astra 使用当前工具体系执行任务，根据任务结果和执行反馈发现问题、改进 Harness（工具与执行框架）；随后，通过拒绝采样筛选高质量交互轨迹，并对 27B 模型进行监督微调，使其掌握更新后的工具和执行方式。经过多轮迭代，模型逐步学会 VLA 轨迹审查、Code as Policy 控制以及空间工具调用等能力。

*多轮 RSI 的训练流程：通过任务交互、反馈分析、Harness 改进和模型训练，持续优化模型的执行能力。*

实验显示，相较于仅更新 Harness 或仅更新模型的方式，模型与 Harness 协同迭代的效果更好。经过三轮协同迭代，RoboDojo 平均得分从 10.0 分提升至 34.7 分。

![](https://oss.sensetime.com/strapi/uploads/external_9f91ef477d2f14c620dc1f37_006_external_image_6_3c377cb60f.png)

*左图比较不同模型的 RoboDojo 得分。右图对比三种迭代方式，其中模型与 Harness 协同迭代三轮后，得分从 10.0 升至 34.7。*

除了提升模型的任务决策能力，团队还针对 27B 模型在精细空间定位方面的不足，引入了从现有开源 VLA 训练数据中构造的单轮动作监督，与长程 Agent 轨迹联合训练。该方法在复用已有机器人操作数据的同时，显著降低了数据构造成本。

实验中，模型末端位置预测误差在 5mm 以内的比例从 4.3% 提升至 15.5%，位置误差中位数从 119.7mm 降至 51.6mm，进一步提升了模型的空间控制精度。

![](https://oss.sensetime.com/strapi/uploads/external_9f91ef477d2f14c620dc1f37_007_external_image_7_b7ba779669.png)

*加入 VLA2Agent 数据后，末端位置预测误差在 5 mm 以内的比例从 4.3% 升至 15.5%，位置误差中位数从 119.7 mm 降至 51.6 mm。*

加入 VLA2Agent 数据（左）与未加入该数据（右）的模型，分别执行积木放置、试管插入和手表抓取。

**同一份模型权重**
**从仿真走向真实机械臂**

从仿真环境走向真实世界，是检验具身智能模型泛化能力的重要环节。SenseNova-RoboRSI-27B 正式版将仿真评测中使用的同一份模型权重部署到 Piper X 和 Piper 两款真实机械臂上，仅对观测、状态和控制接口进行适配，未使用真实机器人数据进行训练或微调。

在实测任务中，Piper X 结合 VLA 与 Code as Policy 完成积木堆叠，10 次实验成功 9 次，成功率达到 90%；Piper 则通过 Code as Policy 完成多类型物体的抓取与放置，10 次实验成功 6 次，成功率达到 60%。相比之下，SenseNova-RoboRSI-27B Preview 版本在两项任务中分别成功 3 次和 2 次，未经机器人操作训练的对照模型则均未能完成任务。

同一份模型权重用于两款真机。Piper X 结合 VLA 与 Code as Policy 叠放积木，Piper仅用 Code as Policy 将玩具放入盘。

更值得关注的是，在真实机械臂操作过程中，模型依然能够主动调用空间定位工具，通过多视角观测获取目标位置，并根据任务状态在不同执行策略之间切换。当 VLA 提出的动作轨迹与空间定位结果不一致时，模型还能够主动拒绝不合适的动作方案，重新生成或修正轨迹后再执行。这表明，模型在仿真中学习到的自主定位、策略选择和执行纠偏能力，能够迁移至真实机器人操作场景。

![](https://oss.sensetime.com/strapi/uploads/external_9f91ef477d2f14c620dc1f37_010_external_image_10_e6e85b3512.png)

*模型通过多视角观测获取目标位置，并在执行过程中根据反馈重新定位、调整动作，实现自主纠错。*

从依赖预设技能到自主组合执行策略，再到将仿真中学习的能力迁移至真实机械臂，SenseNova-RoboRSI-27B 正式版进一步探索了通用机器人 Agent 的实现路径。

未来，我们将继续探索强化学习与更高效的具身RSI架构，推动 RoboRSI 在三个方向上走得更远。

**1. 让机器人更独立地完成复杂任务。** 从执行单个动作，到围绕一个目标连续完成多个步骤，机器人还需要学会判断事情做到了哪一步，遇到偏差时调整做法，减少对人工接手的依赖。

**2. 让学到的能力适用于更多真实场景。 **我们将把 RoboRSI 带到更多类型的机器人和开放环境中，检验当设备、物体或环境布局发生变化时，机器人能否运用已有经验，依然可靠地完成任务。

**3. 让机器人以更低成本完成任务。 **我们将继续探索更轻量的开源模型，在保留操作能力的同时，降低每次任务的推理成本、缩短响应时间，让机器人能够在真实场景中更经济地长期运行。

我们期待与开源社区一起，让越来越多需要人全程照看的工作，逐步交给机器人独立、可靠地完成。
