## 🌟 概述

🚀 **SenseNova U1** 是一系列新的原生多模态模型，它将多模态理解、推理和生成统一在一个整体架构中。它标志着多模态人工智能的根本范式转变：**从模态集成到真正的统一**。 SenseNova U1 不依赖适配器在模态之间进行转换，而是对跨语言和视觉的思考和行动进行原生建模。

在从像素到文字的端到端架构中统一视觉理解和生成，开启了巨大的可能性，以原生多模态方式实现高效且强大的理解、生成和交错推理。

### ⚡ 使用 LightLLM + LightX2V 运行（推荐）

对于生产服务，我们在 **[LightLLM](https://github.com/ModelTC/lightllm)**（理解）和 **[LightX2V](https://github.com/ModelTC/lightx2v)**（生成）之上共同设计了专用推理堆栈。这两个引擎被分解，以便每条路径都可以使用自己的并行性和资源预算，并且中间有一个低开销的传输通道。

在具有 `TP2 + CFG2` 的单个节点上，该堆栈为 H100 / H200 上的 **2048×2048** 图像提供大约 **~0.15 s/step** 和 **~9 s 端到端**，并通过我们基于 FA3 的混合掩模注意力在 Triton 基线上实现 ~**2.4–3.2×** 预填充加速。 [`docs/inference_infra.md`](https://github.com/OpenSenseNova/SenseNova-U1/blob/main/docs/inference_infra.md) 中报告了完整的每 GPU 性能。

官方提供了一个 docker 镜像，用于单命令部署：

```
docker pull lightx2v/lightllm_lightx2v:20260407
```

> ⚙️ 部署指南（Docker、启动标志、模式、量化、API 测试）：请参阅 docs/deployment.md。
> 📖 完整的设计和性能分析：请参阅 docs/inference_infra.md。
