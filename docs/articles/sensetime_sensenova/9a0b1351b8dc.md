## 概述

尽管取得了显着的进步，多模态基础模型在空间智能方面仍然表现出令人惊讶的缺陷。在这项工作中，我们探索扩大多模态基础模型的规模，以培养 **SenseNova-SI 系列**中的空间智能，该模型建立在已建立的多模态基础上，包括视觉理解模型（即 Qwen3-VL 和 InternVL3）以及统一理解和生成模型（即 Bagel）。我们采用原则性方法，通过系统地管理 SenseNova-SI-8M 来构建高性能和强大的空间智能：在严格的空间功能分类下的 800 万个不同的数据样本。 SenseNova-SI 在广泛的空间智能基准测试中展示了前所未有的性能，同时保持了强大的通用多模式理解。更重要的是，我们分析了数据扩展的影响，讨论了多样化数据训练所带来的新兴泛化能力的早期迹象，分析了过度拟合和语言捷径的风险，提出了空间思维链推理的初步研究，并验证了潜在的下游应用。 SenseNova-SI是一个正在进行的项目，本报告将不断更新。所有新训练的多模式基础模型都会公开发布，以促进该方向的进一步研究。 *未来，SenseNova-SI将与更大规模的内部模型集成。*

## 发布信息

目前，我们在流行的开源基础模型上构建 SenseNova-SI，以最大限度地提高与现有研究流程的兼容性。在此版本中，我们推出了 [**SenseNova-SI-1.2-InternVL3-8B**](https://huggingface.co/sensenova/SenseNova-SI-1.2-InternVL3-8B)、[**SenseNova-SI-1.1-Qwen2.5-VL-3B**](https://huggingface.co/sensenova/SenseNova-SI-1.1-Qwen2.5-VL-3B)、[**SenseNova-SI-1.1-Qwen2.5-VL-7B**](https://huggingface.co/sensenova/SenseNova-SI-1.1-Qwen2.5-VL-7B) 和[**SenseNova-SI-1.1-Qwen3-VL-8B**](https://huggingface.co/sensenova/SenseNova-SI-1.1-Qwen3-VL-8B)，其中 **SenseNova-SI-1.2-InternVL3-8B** 在最近八个空间智能基准中的同等大小的开源模型中实现了最先进的性能：**VSI**、**MMSI**、**MindCube**、**ViewSpatial**、**SITE**、**BLINK**、**3DSRBench**、 **EmbSpatial 长凳**。

## 🛠️ 快速入门

### 安装

我们建议使用 [uv](https://docs.astral.sh/uv/) 来管理环境。

> uv安装指南：https://docs.astral.sh/uv/getting-started/installation/#installing-uv

```
git clone git@github.com:OpenSenseNova/SenseNova-SI.git
cd SenseNova-SI/
uv sync --extra cu124 # or one of [cu118|cu121|cu124|cu126|cu128|cu129], depending on your CUDA version
uv sync
source .venv/bin/activate
```

#### 世界你好

一个简单的无图像测试，用于验证环境设置并下载模型。

```
python example.py \
  --question "Hello" \
  --model_path sensenova/SenseNova-SI-1.2-InternVL3-8B
```

#### 示例 1

此示例来自 [MMSI-Bench](https://github.com/InternRobotics/MMSI-Bench) 的 `Pos-Obj-Obj` 子集：

python example.py \
  --image_paths examples/Q1_1.png examples/Q1_2.png \
  --question "<image><image>
You are standing in front of the dice pattern and observing it. Where is the desk lamp approximately located relative to you?
Options: A: 90 degrees counterclockwise, B: 90 degrees clockwise, C: 135 degrees counterclockwise, D: 135 degrees clockwise" \

#### 在一次运行中测试多个问题

准备一个类似于 [examples/examples.jsonl](https://huggingface.co/sensenova/SenseNova-SI-1.2-InternVL3-8B/blob/main/examples/examples.jsonl) 的文件，其中每一行代表一个问题。

该模型加载一次并按顺序处理问题。这些问题保持相互独立。

> 有关 jsonl 格式的更多详细信息，请参阅单图数据和多图数据的文档。

```
python example.py \
  --jsonl_path examples/examples.jsonl \
  --model_path sensenova/SenseNova-SI-1.2-InternVL3-8B 
# --model_path OpenGVLab/InternVL3-8B 
```
