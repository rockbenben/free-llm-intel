**大模型和 Agent 技术加速演进，但对政企场景而言，技术能否真正落地、融入业务并持续释放价值，依然是关注的重点。**

基于十余年在政企场景的持续积累，商汤推出面向城市治理与产业数智化转型的全栈式AI智能体应用平台——**商汤小浣熊·政数版**。

「商汤小浣熊 Raccoon Work」 是商汤科技打造的能搞定工作的 AI 助手，面向个人、团队、企业提供「文理兼备」的智能办公解决方案，支持移动端、桌面端及私有化部署等产品服务形态；其中，作为垂直行业版本，**“商汤小浣熊·政数版”**聚焦城市治理、政务服务与产业运营等政企核心场景，结合商汤方舟长期沉淀的视觉AI能力，为政企客户提供可落地、可私有化部署的多智能体协同应用。

![](https://oss.sensetime.com/strapi/uploads/external_30b55e1ea0e77a000ec8e58b_001_external_image_1_a771af143c.png)

**从“有数据”到“能理解、会应用”**

城市治理和产业运营等场景产生并积累了大量视频感知数据、空间数据、业务系统数据和运营管理数据。但面对具体业务问题，如何从海量数据中找到有价值的信息，并进一步形成判断和决策，仍需专业人员投入大量时间和精力。

例如：

一周内，哪些区域的热线投诉增长最快？

重点区域的交通运行是否出现异常？

一个商圈客流变化的背后，可能意味着什么？

这些问题表面上是数据查询，背后却涉及对业务场景、数据关系和治理逻辑的综合理解。

这也是通用大模型进入政企场景时需要进一步解决的问题。模型可以处理文本，却不会天然理解某个城市的治理规则；可以分析数据，却不一定知道哪些变化具有业务意义；可以生成报告，却未必能够判断报告服务于哪项业务决策。

商汤小浣熊·政数版正是由此需求出发，将SenseNova大模型与商汤方舟长期积累的视觉AI、空间数据治理和业务场景经验融合，让模型能够结合具体场景理解数据、关联信息，辅助业务人员形成判断。

**一句话激活视图数据应用价值**

对于业务人员而言，AI最直接的价值不是增加一个新的工具，而是让原本需要专项技能、经过多个步骤才能完成的工作变得更简单。

商汤小浣熊·政数版以“一句话激活视图数据应用价值”为核心理念，让业务人员能够更便捷地从数据中获得业务洞察。

![](https://oss.sensetime.com/strapi/uploads/external_30b55e1ea0e77a000ec8e58b_002_external_image_2_6a180e2a0c.gif)

业务人员无需掌握复杂的数据处理工具，只需输入一句自然语言，系统即可围绕具体需求，完成数据关联、语义解析、趋势研判、可视化分析和报表生成。

这不仅是简化操作，更重要的是，AI参与了从问题理解、数据分析到结果生成的更多环节，让数据应用能力以更低门槛进入日常业务。

**构建“感知-理解-规划-执行”的完整业务闭环**

传统视觉平台更多聚焦于“识别已经发生的事件”。而从“看见发生了什么”，走向“理解为什么发生、判断接下来怎么做”，是政企AI从单点感知迈向业务深度应用的重要一步。

商汤小浣熊·政数版进一步打通“感知 → 理解 → 规划 → 执行”的完整业务闭环，推动AI从事件识别延伸至态势分析、方案规划和辅助决策。

在国内某重点地市的防汛防台实战中，该市部署了5万+视频监测点位，并积累了历年总结形成的80余个易积水风险点位。过去，气象、视频、热线工单等数据分散在不同系统中，汛期管理面临风险发现、预案调整和跨部门协同等多重挑战。

依托商汤小浣熊·政数版，该市实现气象预报、全域视频、市民热线工单等多维数据的融合分析。系统通过多智能体协同能力，动态追踪台风路径与雨情态势，关联预警信息、民生诉求和监测数据，并结合实际情况调整AI监测预案，向指挥端输出分级决策建议。由此，防汛防台模式逐步从传统的“事后被动处置”，转向“事前主动预判、事中动态调优”。

商汤小浣熊·政数版的价值不仅在于完成单次分析，也在于将一次次业务分析和事件处置沉淀为可复用的知识资产。随着经验不断积累，AI将逐步从“回答问题”走向理解业务、辅助判断和支持协同。

商汤方舟持续深耕政企场景，沉淀视觉AI能力，积累对真实业务中数据组织、问题判断和流程协同的长期理解。商汤小浣熊·政数版在此基础上融合大模型与智能体能力，并延续私有化部署、全链路数据治理、国产化适配、高安全合规架构等底层能力，为政企客户提供更贴近实际业务的AI应用。

未来，商汤将持续推动AI能力融入城市治理与产业运营，让更多业务从“数字化可见”走向“智能化可用”，持续创造新的业务价值。
