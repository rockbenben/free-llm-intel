## 概览

**SenseNova-Loop-9B-Preview** 是一个为长上下文与智能体工作流开发的多模态语言模型。它接受文本与图像输入，并生成文本，适用于将文档理解、编码以及与外接工具交互结合起来的应用场景。

该模型将**循环式解码器与双流流形约束超连接（manifold-constrained hyper-connections，mHC）**相结合。一段连续的解码器层以共享权重被执行两次，同时由学习得到的映射管理循环部分中两条残差流之间的信息流动。这些组件共同提供了一条更深的执行路径，而不必复制重复块中的参数。

文档中记录的训练方案结合了长序列、多模态输入与监督式任务轨迹，最大训练序列长度为 262,144 个 token。为获得最佳模型性能，我们建议使用我们文档中给出的部署环境与配置参数。

### 模型亮点

- **共享循环块：** 24 个解码器层按顺序应用两次，由 32 个不同的层产生 56 次解码器层执行。
- **双流 mHC：** 学习得到的映射在循环部分的两条残差流之间路由并组合信息。
- **混合注意力：** 解码器以四层一组的重复模式交替使用线性注意力与全注意力。
- **长上下文多模态训练：** 文档中记录的训练方案包含文本、图像、代码与工具轨迹，序列长度最高可达 256K 个 token。

## 模型架构

SenseNova-Loop-9B-Preview 基于一个 32 层的多模态解码器，结合了共享权重循环计算、混合注意力以及双流流形约束超连接（mHC）。以下小节说明这些组件如何扩展计算路径，并管理模型中的信息流动。

### 循环式解码器

解码器首先通过第 0–3 层处理输入。随后，同一组第 4–27 层按顺序被应用两次，之后由第 28–31 层与输出头产生模型输出。若用 *B* 表示重复的块、*h* 表示其输入，则循环计算可写作 **B(B(h))**。

在推理过程中，**模型每次前向传播执行 56 次解码器层计算，而仅存储 32 套解码器层权重**。循环块在两次传递中复用同一套权重，第二次传递以第一次传递的输出作为输入。

### 混合注意力

解码器交替使用线性注意力层与全注意力层。每个四层组包含三个线性注意力层，随后是一个全注意力层。循环边界与完整的四层组对齐，因此注意力模式在两次传递中保持一致。

### 双流 mHC

在循环部分内部，mHC 在解码器层计算周围承载两条残差流。学习得到的映射决定某一层如何从这些流中读取、如何混合流信息，以及如何将该层输出并入残差状态。Sinkhorn 归一化对流的混合映射施加约束；文档中记录的配置使用 20 次迭代。

循环范围、循环次数与 mHC 路由参数属于检查点执行配置的一部分。兼容的推理实现必须加载这些参数，并复现相同的执行顺序。

| 配置 | 值 |
| --- | --- |
| 不同解码器层数 / 执行次数 | 32 / 56 |
| 重复块 / 循环次数 | [4, 28) / 2 |
| 隐藏维度 | 4,096 |
| 前馈维度 | 12,288 |
| 词表大小 | 248,320 |
| 全注意力头数 / KV 头数 | 16 / 4 |
| mHC 流数 / Sinkhorn 迭代次数 | 2 / 20 |

## 快速开始

使用 Transformers 从 Hugging Face 仓库或本地模型目录加载该模型及其自定义实现。下例在单张 GPU 上运行文本生成。

### 环境要求

经检验的推理环境使用 **Transformers 5.18.0** 与 **PyTorch 2.11.0 搭配 CUDA 13.0**。模型目录必须包含配置、分词器、聊天模板、模型代码以及可访问的权重分片。

首先安装与你的 CUDA 环境兼容的 [PyTorch 版本](https://pytorch.org/get-started/locally/)，然后安装其余依赖：

```
python -m pip install "transformers==5.18.0" accelerate safetensors
```

### 使用 Transformers 进行文本生成

将 `model_id` 设为 Hugging Face 仓库 ID 或本地模型目录，然后运行：

```
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer

model_id = "sensenova/SenseNova-Loop-9B-Preview"
device = "cuda:0"

tokenizer = AutoTokenizer.from_pretrained(model_id, trust_remote_code=True)
model = AutoModelForCausalLM.from_pretrained(
    model_id,
    trust_remote_code=True,
    dtype=torch.bfloat16,
    device_map={"": device},
).eval()

messages = [{"role": "user", "content": "What is 13 times 7? Reply with the number only."}]
prompt = tokenizer.apply_chat_template(
    messages,
    tokenize=False,
    add_generation_prompt=True,
    enable_thinking=False,
)
inputs = tokenizer(prompt, return_tensors="pt").to(device)

with torch.inference_mode():
    outputs = model.generate(
        **inputs,
        max_new_tokens=256,
        do_sample=False,
        use_cache=True,
    )

response = tokenizer.decode(
    outputs[0, inputs.input_ids.shape[1]:],
    skip_special_tokens=True,
)
print(response)
```

该示例使用贪心解码，最多生成 256 个新 token。设置 `enable_thinking=True` 可启用思考模式，或更改 `device` 以选择另一张 GPU。

`trust_remote_code=True` 会加载自定义的 SenseNova Loop 模型实现。

## 训练

### 模型训练

要在配备 8 张 GPU 的单节点上使用 mHC 微调 **SenseNova-Loop-9B-Preview**，请在你已配置好的训练环境中运行以下命令：

```
git clone https://github.com/OpenSenseNova/torchtitan.git
cd torchtitan
MODEL_PATH=/path/to/SenseNova-Loop-9B-Preview DATASET=/path/to/train.jsonl \
  bash examples/train/SenseNova-Loop-9B-Preview/mhc2_loop2_titan.sh
```

将 `/path/to/train.jsonl` 替换为你的 SFT 数据集。有关配置选项、DPO 与 MTP 训练的信息，请参阅[训练指南](https://github.com/OpenSenseNova/torchtitan/tree/main/examples/train/SenseNova-Loop-9B-Preview)。

### 投机解码训练

要在配备 8 张 GPU 的单节点上为 **SenseNova-Loop-9B-Preview** 训练 DSpark 或 DFlash2 草稿模型，请使用 [SenseSpec 仓库](https://github.com/OpenSenseNova/SenseSpec)中提供的训练脚本。

首先克隆仓库并进入项目目录：

```
git clone https://github.com/OpenSenseNova/SenseSpec.git
cd SenseSpec
```

#### DSpark 训练

运行以下命令训练 DSpark 草稿模型：

```
bash examples/SenseNova-Loop-9B-Preview-dspark/run.sh
```

#### DFlash2 训练

运行以下命令训练 DFlash2 草稿模型：

```
bash examples/SenseNova-Loop-9B-Preview-dflash2/run.sh
```

## 部署

### LightLLM

四 GPU 示例；请替换本地模型路径：

```
docker pull ghcr.io/modeltc/lightllm:main

docker run --rm --gpus all --ipc=host -p 8000:8000 \
  -v /path/to/SenseNova-Loop-9B-Preview:/model \
  -e LOADWORKER=4 -e LIGHTLLM_TRITON_AUTOTUNE_LEVEL=1 \
  ghcr.io/modeltc/lightllm:main \
  python -m lightllm.server.api_server \
    --model_dir /model --model_name SenseNova-Loop-9B-Preview \
    --tp 4 --host 0.0.0.0 --port 8000
```

示例请求：

```
curl http://localhost:8000/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{"model": "SenseNova-Loop-9B-Preview", "messages": [{"role": "user", "content": "Hello!"}], "max_tokens": 128}'
```

使用 [SGLang PR #47281](https://github.com/sgl-project/sglang/pull/47281) 中的版本（其中包含 SenseNova Loop 实现），并将下方的模型路径替换为你的本地检查点目录：

