# SenseNova-SI：以多模态基础模型扩展空间智能

![Code](https://img.shields.io/badge/SenseNova_SI-Code-100000?style=flat-square&logo=github&logoColor=white)

🔥欢迎查看我们新发布的 [**SenseNova-SI-1.2-InternVL3-8B**](https://huggingface.co/sensenova/SenseNova-SI-1.2-InternVL3-8B)，它在八个近期空间智能基准（VSI、MMSI、MindCube、ViewSpatial、SITE、BLINK、3DSRBench、EmbSpatial-Bench）上，于同等规模的开源模型中取得了 state-of-the-art 的表现。

## 概述

尽管已取得显著进展，多模态基础模型在空间智能方面仍表现出令人意外的不足。在本工作中，我们探索通过扩展多模态基础模型来培养空间智能，构建了 **SenseNova-SI 系列**，其建立在已有的多模态基础之上，包括视觉理解模型（即 Qwen3-VL 和 InternVL3）以及统一理解与生成模型（即 Bagel）。我们采取系统化的方法构建高性能且鲁棒的空间智能：在严格的空间能力分类体系下，系统化地整理出 SenseNova-SI-8M——八百万条多样化数据样本。SenseNova-SI 在广泛的空间智能基准上展现出前所未有的性能：VSI-Bench 上 68.7%，MMSI 上 43.3%，MindCube 上 85.6%，ViewSpatial 上 54.6%，SITE 上 50.1%，同时保持较强的通用多模态理解能力（例如 MMBench-En 上 84.9%）。更重要的是，我们分析了数据规模扩展的影响，讨论了多样化数据训练所带来的涌现泛化能力的早期迹象，分析了过拟合与语言捷径的风险，呈现了关于空间思维链推理的初步研究，并验证了潜在的下游应用。SenseNova-SI 是一个持续进行的项目，本报告将持续更新。所有新训练的多模态基础模型均已公开发布，以促进该方向的进一步研究。*未来，SenseNova-SI 将与更大规模的内部模型集成。*

## 发布信息

为促进该领域的研究，作为第一步，我们发布了一个高效的子集 [**SenseNova-SI-800K**](https://huggingface.co/datasets/sensenova/SenseNova-SI-800K)。该子集涵盖了完整 SenseNova-SI 数据集所带来性能提升的相当一部分，同时提供了便于实验的可控数据规模。

在此基础上，我们现在发布 [**SenseNova-SI-1.1-InternVL3-8B-800K**](https://huggingface.co/sensenova/SenseNova-SI-1.1-InternVL3-8B-800K)，这是一个仅使用 **SenseNova-SI-800K** 子集训练的模型。该模型作为参考提供给使用 800K 规模数据集的研究者，以便开展实验并验证在 SenseNova-SI 中观察到的扩展行为。

在该子集上训练的模型相比基座模型展现出显著提升，并对强劲的空间智能基线取得有竞争力的性能。然而，我们强调 **SenseNova-SI-1.1-InternVL3-8B (800K)** 的发布**仅用于研究与扩展律分析目的。**它**并非 SenseNova-SI 系列首要推荐的模型**，也不代表使用完整数据集所能达到的完整性能。

## 🛠️ 快速开始

### 安装

我们推荐使用 [uv](https://docs.astral.sh/uv/) 管理环境。

> uv 安装指南：https://docs.astral.sh/uv/getting-started/installation/#installing-uv

```
git clone git@github.com:OpenSenseNova/SenseNova-SI.git
cd SenseNova-SI/
uv sync --extra cu124 # or one of [cu118|cu121|cu124|cu126|cu128|cu129], depending on your CUDA version
uv sync
source .venv/bin/activate
```

#### Hello World

一个简单的无图像测试，用于验证环境配置并下载模型。

```
python example.py \
  --question "Hello" \
  --model_path sensenova/SenseNova-SI-1.1-InternVL3-8B
```
