连接异构本体、零售大脑、真实场景数据与门店运营，打通具身智能商业化的最后一公里——

2026世界人工智能大会（WAIC）期间，在商汤集团“模力共进 向新同行”的整体主题下，商汤善惠集中展示 SenseMart OS 零售物理操作系统。

它连接异构本体、零售大脑、真实场景数据与门店运营，让模型与机器人能力进入真实零售空间。商汤善惠由此明确自身角色：位于上游本体能力与下游零售经营之间，基于不同本体已有的机械结构、运动控制与末端执行能力，叠加零售智能、任务协同、交易履约和运营体系，为运营商、加盟商、品牌商、场地方及零售设施升级企业提供可部署、可经营、可复制的具身零售解决方案。

**一套 OS，接管机器人开店所需的零售能力**

机器人在实验室完成抓取，只解决了零售任务中的一个动作。进入门店后，它还要认商品、懂顾客、查库存、做推荐、调设备、接支付、完成履约，并应对缺货、客诉和设备异常。SenseMart OS 把这些零售能力接入同一套系统，成为机器人在门店工作的业务底座。本体公司可以继续发挥机械结构、运动控制与末端执行等优势；善惠则在本体能力之上，叠加零售场景感知、多模态交互、任务规划、异构协同、交易履约、经营分析与数据闭环学习，把单点动作能力组织为可以持续履约、经营和进化的系统能力。

作为 SenseMart OS 的重要组成部分，“零售大脑”由四类能力协同工作：感知负责看见商品、环境与顾客需求；执行负责抓取、制作、递送和补货；交互负责多语种沟通、推荐与服务；分析负责选品、库存、异常和经营策略。四类能力围绕同一笔订单运行，现场动作与后台经营由此连成一条链。SenseMart OS 也因此获得清晰的品类占位——它是一套连接零售物理世界的操作系统。

**异构本体协同，让不同机器人共享一套零售任务系统**

不同机器人擅长的动作并不相同。SenseMart OS 通过标准化本体接入和统一任务调度，把轮式机械臂、夹爪、灵巧手、人形机器人等异构设备纳入同一条订单链。顾客下单后，系统依据设备能力拆分取货、制作、递送和交付任务，多台机器人可以共同完成一笔订单。WAIC现场的“小麦”和“大麦”协同工作，呈现的正是这套系统能力。目前，善惠已与大晓机器人、零次方等本体公司签约合作，相关合作已推进至本体接入、场景适配与零售场景落地阶段，进一步验证了 SenseMart OS 对不同本体能力的承接与商业化转化能力。

对于运营商、加盟商、智能柜转型企业、品牌商和场地方，进入机器人零售无需从头搭建设备组合、商品库、门店流程、支付接口、消费者交互和现场运维。SenseMart OS 基于不同本体的能力特点进行适配与组合，并提供可复用的零售任务模板、标准接口、远程接管与运营工具。下游客户获得的不是单一机器人设备，而是一套从部署、接单到持续经营的完整方案；上游本体能力也由此能够在真实订单中被验证和迭代。

**快交付、好体验，把技术优势落到每一笔订单**

系统能力最终要由交付结果检验。SenseMart OS 当前最快可在15秒内完成一笔订单；多模态大模型支持中英文无缝切换，并可扩展多语种服务。顾客可以自然询问、获得推荐并完成购买，机器人互动由吸引注意进一步进入交易转化。对于门店，稳定履约、远程运维和异常处理共同降低现场人力压力。

善惠已经把方案部署到几十家门店，覆盖不同城市、点位和经营时段。标准化的软硬件接口、任务模板与运营工具，让新店可以沿用已经验证的系统能力。门店越多，商品识别、交互、执行与经营策略积累得越快；新点位的部署效率和运营稳定性也随之提升。

**为什么是善惠：数据闭环与经营账本同时成立**

善惠的差异来自技术和运营在同一套系统中长期运行。系统已经沉淀30万种商品的2D与3D建模资产，持续积累人手与商品的HOI交互数据；商品识别业务每日处理150万至200万笔订单。门店中的环境、顾客交互、机器人动作、交易履约、失败任务和远程接管记录都会回流，其中也包括发生互动但未形成交易的数据。这些全链路真实场景数据持续进入模型与经营策略，形成“开店—运行—数据回流—能力提升—复制新店”的闭环学习。

门店经营也已经进入可算账阶段。善惠通过硬件规模采购、少人化运营、远程运维和系统化选品补货控制成本，单店盈利模型已获得经营验证，并形成约12个月回本路径。几十家门店的落地，让快速复制从规划变成正在发生的业务过程。技术过硬、顾客愿意互动、订单能够交付、门店账本成立，这四项结果共同构成善惠定义零售物理 OS 的底气。

**从 WAIC 出发，让更多机器人进入零售**

WAIC汇聚模型、本体与产业伙伴，善惠提供的是连接上游本体能力与下游零售需求的平台型基础设施。SenseMart OS 向上承接不同本体，完成场景适配与统一任务调度；向下连接运营商、加盟商、智能柜转型企业、品牌商和场地方，输出可以部署、经营和复制的机器人门店方案。方案价值最终由部署周期、订单交付、顾客互动、单店成本与回本周期等经营结果检验。

当感知、执行、交互、分析在真实门店持续协同，机器人便获得面向零售经营的完整能力。在这一链路中，SenseMart OS 作为零售物理操作系统，向上承接异构本体，补齐零售场景所需的技术与经营能力；向下输出可以部署、经营和复制的智能化方案。随着门店持续运行，每一家新店也能够沿用此前积累的真实场景数据与经营经验。

**关于上海商汤善惠信息科技有限公司**

商汤善惠是商汤科技旗下专注智慧零售赛道的生态企业，核心产品为 SenseMart OS 零售物理操作系统。SenseMart OS 向上接入异构本体并叠加零售智能，向下为运营商、加盟商、品牌商和场地方提供可部署、可经营、可复制的具身零售解决方案。依托商汤原创 AI 多模态大模型，善惠已积累30万+ SKU 商品视觉资产；旗下 SenseMart Go 烧卖购机器人小店已在上海多地落地运营，是国内首个跑通单店盈利模型的具身零售品牌。
