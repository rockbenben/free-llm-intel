## 预训练

Qwen4-Max 采用 **Qwen4 系列的全新架构**，拥有 **2.4T 主干参数，每个 token 激活 71B 参数，另有 328B N-gram Embedding 参数**。该架构围绕 **Attention、Residual 和 Embedding** 三个方面对稀疏 MoE 模型进行系统升级，优化计算效率、模型容量和训练稳定性：

- **GDN + Qwen Sparse Attention（QSA）：** 每四层中，三层 Gated DeltaNet 将历史信息压缩为固定大小的状态，另一层 QSA 通过轻量级 Indexer，以 block 为粒度选择相关上下文，降低长序列的 Attention 计算与索引开销。
- **Gated Residual（GR）：** 将 Residual Stream 扩展为四条并行分支，通过动态读写门控增强跨层信息传递，提升训练稳定性。
- **N-gram Embedding：** 根据局部上下文查表，在第二层提供局部 token 模式的表示，以较低的额外计算开销扩展模型容量。

我们同步开源 [Qwen-Live-Delivery-Plugin](https://github.com/QwenLM/Qwen-Live-Delivery-Plugin)，安装插件即可体验持续交付能力。

### 云资源调度：提升模型自身应用、推理与训练的资源效率

Qwen4-Max 具备围绕复杂目标与约束进行运筹建模、求解与验证的能力，从而交付高质量的优化决策方案。该能力在阿里云真实业务场景中落地，实现了模型自主迭代并优化自身所需调度方案的闭环，涵盖数据标注中的多模型调用调度、云计算 GPU 资源的在线分配调度，以及云计算 CPU 资源的离线重调度。

在这一过程中，模型根据任务设定自主生成候选算法，协同阿里自研求解器 MindOpt 对可行性、目标值与耗时进行评估并获得反馈，进而通过修改代码、交叉验证来迭代更优策略。从上层模型调用到底层云资源调度，Qwen4-Max 依托可量化的反馈持续进化，直接优化了支撑其自身应用、推理与训练的运行系统，而由此带来的成本降低与资源效率提升，又将为下一轮模型迭代提供更坚实的算力支撑。在相应场景中，数据标注场景模型调用调度费用对应参考基线平均降低 10.42%，GPU 在线分配相对基线的整机空闲容量时长提升 4.62%，CPU 离线重调度场景中达到最优目标的求解速度提升超 14.61 倍。

### 干湿实验闭环：Qwen4 自主设计与合成新型冷却液材料

面向下一代高功率芯片给数据中心带来的散热挑战，Qwen4 依托深度原理 Mira 提供的一体化干湿实验环境，自主完成了一种新型冷却液分子的设计、实物合成与测试验证，**最终获得真实材料样品**。

在连续 **48 小时的自主 Agent 运行**中，Qwen4 全自动完成路线调研，构建包含 270 万个分子的候选空间，并依次开展结构筛选、MPA 性质预测、第一性原理计算、逆合成设计与实验规划。Qwen4 进一步调度自动化湿实验室完成真实物料的配制、合成、分离纯化与测试，将屏幕上的分子结构转化为实验室中的实体样品。经过 **4 轮“分子设计-合成测试-主动学习”的闭环迭代**，Qwen4 最终获得经过实验验证的新型冷却液分子。

从用 AI 探索材料，到用材料支撑 AI 基础设施建设，本次任务为破解数据中心散热难题探索了新的材料路径，展现了 Qwen4 跨越数字世界与物理世界的长程科学发现能力。

### 药物发现：以自主科研探寻延缓认知衰退的新路径

阿尔茨海默病逐步损害患者的记忆与认知能力，也给家庭和社会带来长期照护负担。神经炎症是其重要病理环节，参与这一过程的 NLRP3 炎症小体，为探索新的干预策略提供了重要研究方向。围绕这一靶点，Qwen4-Max 在深势科技 PharmMaster 平台上，展示了贯穿靶点研究、分子优化设计与计算评估的全链路能力。它不只是生成分子结构，更将文献与专利理解、专业工具调用和计算反馈融入持续迭代的科研流程。

在这一过程中，Qwen4-Max 自主检索文献与专利证据，选择参考分子并建立评估基线，随后通过多轮结构设计、性质预测与分子对接，根据评估反馈调整优化方向，最终结合跨轮指标比较与相对结合自由能（RBFE）评估完成候选优选。整个流程累计调用工具 454 次，完成 3,239 项计算指标评估，设计优化 24 个候选分子，将证据检索、设计生成、工具执行与反馈验证串成一条完整链路。

相比专利起点，最终优选分子在多项核心计算指标上实现全面改善；RBFE 计算估计显示，其与目标靶点的名义结合亲和力达到起点的约 3.6 倍。深势科技的专家认为，该分子具有较高的研究价值，值得进一步开展湿实验验证。从疾病相关靶点到高潜力候选分子，Qwen4-Max 将证据驱动的设计、专业工具执行与计算反馈相结合，展示了自主推进长程科研任务、持续优化分子并形成有价值研究成果的能力。

在阿里巴巴，我们以六大人工智能发展原则为指导，即：以人为本、包容诚信、隐私保护、安全可靠、可信可控以及开放共治，将模型治理贯穿于整个模型生命周期——从最初的设计与研究，到开发、训练、部署以及实际应用——确保负责任的人工智能是原生内嵌于设计之中，而非事后补充。 在软件工程训练任务中，我们在功能性检查的基础上新增了代码安全检测，以增强模型的内生安全编码能力。在 Last Secure Code Bench 的“无安全提示代码重建”及“功能与漏洞双重检验”中，Qwen4-Max 的函数级功能与安全双通过率从前代（Qwen3.8-Max）的 22.0% 提升至 31.8%；在函数，文件，仓库三个粒度上的同时生成安全代码比例从 8% 提升至 14.7%，接近翻倍。模型在规避注入、内存安全和越权访问等核心风险上表现尤为突出，能显著减少默认生成的代码漏洞，协助开发者从源头压缩系统受攻击面。 在网络安全方面，我们按任务的具体用途筛选，保留用于漏洞验证、检测和修复等防御任务的数据，剔除用于提升攻击能力等进攻任务的数据。经过内部安全专家对长程任务运行轨迹（包含完整 CoT）审查发现，Qwen4-Max 的网络安全防御能力大幅提升，针对攻击性用途的防护能力也显著增强。尚未发现模型产生大规模网络安全风险的能力。 在 CBRN 方面，我们设计了安全数据并在安全后训练阶段提升了 Qwen4-Max 的内生安全。在内部评测中，Qwen4-Max 在未产生过度拒答的同时，识别出更多含有潜在风险的请求并给出安全回答。经过内部专家对模型作答（包含完整 CoT）审查发现，模型提出的方案不具备真正的创新性，也无法端到端的完成任务。尚未发现模型能够将相关知识转化为显著提升使用者能力的风险。
