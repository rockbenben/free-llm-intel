今天，我们很高兴地宣布 [Mercury 已在 Azure AI Foundry 上线](https://ai.azure.com/explore/models/Mercury/version/1/registry/azureml-inceptionlabs)，把第一个商业规模的 diffusion 大语言模型（dLLM）带给企业开发者。此次发布将 Inception 突破性的 diffusion 架构与 Azure 的企业级就绪基础设施结合，让开发者能够获得一个兼具卓越速度与质量的模型。

Mercury 由 Flash Attention、Direct Preference Optimization 以及最早的图像 diffusion 模型等基础 AI 技术背后的团队打造，代表着语言模型生成文本方式的根本转变。Azure AI Foundry 上的开发者现在拥有的模型，重新定义了实时 AI 应用的可能性。

## 面向语言生成的新架构

传统语言模型一次一个 token 地串行生成文本。这造成了一个内在瓶颈：每个 token 都必须等前面所有 token 生成完。Mercury 使用基于 diffusion 的架构并行生成多个 token，从而实现大幅更快的推理。结果：Mercury 的运行速度比同档自回归模型快至多 10 倍。

## 性能：速度与质量

Mercury 以前沿质量提供无与伦比的速度。在知识、编程、指令遵循和数学基准上，Mercury 的表现与 Gemini 2.5 Flash、Claude 4.5 Haiku 这类模型相当，而速度快至多 10 倍。

## 企业级就绪的 Azure 环境

Azure AI Foundry 上的 Mercury 开箱即用、可投入生产。它拥有 128K token 上下文窗口，可处理大型文档、维持长对话；支持原生工具调用与使用 JSON schema 的结构化输出，用于构建 agentic 工作流。API 兼容 OpenAI，与现有代码库的集成无缝。

Azure AI Foundry 提供企业级基础设施，包括网络隔离、确保数据留在你自己的 Azure 环境中且绝不用于训练的数据隐私保障、SOC2 与 HIPAA 等 Azure 合规标准，以及通过 Azure Monitor 和 Application Insights 实现的全面可观测性。

**真实世界用例**

Mercury 的速度-质量组合让应用更快、响应更及时：

- **编程助手：**响应敏捷的自动补全、智能 Tab 建议、快速的聊天回复，帮开发者保持心流。
- **实时语音 agent：**在客服、翻译等场景中与 AI 自然交流。
- **无缝的企业工作流：**用极速响应的 AI 自动化复杂的路由、分析和决策流程。
- **快速企业搜索：**从整个组织的知识库中即刻找到所需数据。

## 在 Azure AI Foundry 上部署

Mercury 已通过 Azure AI Foundry 在美国和加拿大区域提供。部署很直接——在 Azure AI Foundry 的统一目录中开通你的模型端点并配置基础设施。Mercury 的软件许可价格为 $0.78/小时，算力费用根据你开通的资源通过你的 Azure 账户单独计费。

**Azure AI Foundry 集成：**

Mercury 与更广泛的 Azure 生态无缝集成。使用 Azure AI Foundry 的模型目录部署，用 Azure AI Content Safety 做内容过滤，实时监控性能与成本，用 Azure RBAC 和托管身份管理访问，并用 Azure 的 agent 框架构建多模型应用。

三步开始使用

- 进入 Azure AI Foundry 的 [Model Catalog](https://ai.azure.com/explore/models)，搜索 **Mercury**，点击模型卡片。也可以直接访问我们[这里的模型卡片](https://ai.azure.com/explore/models/Mercury/version/1/registry/azureml-inceptionlabs)
- 点击 **Use this model**，选择一个项目，按 UI 提示开通你需要的容量。
- 默认配置适用于大多数开发者，但我们推荐选择 **ND-H100-v5** 实例以获得最佳速度。部署会在几分钟内完成。

就是这样！你现在应该可以基于刚开通的 API 端点开始构建了：

```
curl --location 'https://mercury-endpoint-ftecx.eastus.inference.ml.azure.com/v1/chat/completions' \\
--header 'azureml-model-deployment: mercury-1' \\
--header 'Content-Type: application/json' \\
--header 'Authorization: Bearer <your-api-key>' \\
--data '{
  "model": "mercury",
  "messages":  [
    { "role": "user", "content": "Hello!" }
  ],
  "stream": true,
  "temperature": 0.0,
  "max_tokens": 512
}'
```

Python 版：

```
import requests
import json

url = "https://mercury-endpoint-ftecx.eastus.inference.ml.azure.com/v1/chat/completions"

payload = json.dumps({
  "model": "mercury",
  "messages": [
    {
      "role": "user",
      "content": "Hello!"
    }
  ],
  "stream": False,
  "temperature": 0,
  "max_tokens": 512
})
headers = {
  'azureml-model-deployment': 'mercury-1',
  'Content-Type': 'application/json',
  'Authorization': 'Bearer <your-api-key>'
}

response = requests.request("POST", url, headers=headers, data=payload)

print(json.loads(response.text))
```
