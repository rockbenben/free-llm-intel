AI 系统的未来不是一个包办一切的单一 agent，而是多个 agent 协同工作。

这在编程领域已经发生。从外观看是一个编程 agent，实际是由专门组件构成的系统。一部分负责规划，一部分探索代码库，一部分编写实现，还有一部分压缩上下文，让会话能继续下去。

这不只是实现细节，它正在成为 agentic 系统的核心架构。据 Baseten 等推理平台统计，客户在生产环境中为定向任务运行 7-10 个模型，各自负责流水线中的不同环节。

## **多 Agent 系统为什么赢**

对 LLM 而言，速度、质量、成本之间存在结构性、无法回避的权衡。

你为最难的推理步骤想要的那个模型，往往不是你为所有辅助操作想要的模型。如果哪里都用最贵的模型，延迟和成本就会成为问题；如果哪里都用最便宜的模型，质量会在关键时刻崩塌。

最优的系统是给每个问题选对工具。

这正是多 agent 系统强大的原因。它们让开发者能根据每一步的实际需要，把不同任务路由到不同模型。深度推理可以交给某个模型，高频的辅助任务可以交给另一个。结果是一个整体更好的系统。

## **压缩（Compaction）是最清晰的证明点**

在长的编程会话中，上下文会被塞满很多次。Agent 已经探索了文件、做了决策、调试了问题，积累了大量状态。到某个点，上下文大到无法继续携带。系统有三个选择：失败、盲目截断，或智能压缩。

Compaction 就是第三个选择。一个 subagent 阅读冗长的交互历史，把它转化为紧凑的结构化摘要，保留决策、相关文件、未解决的问题和下一步。这份摘要成为主 agent 新的工作状态。这件事比听起来难。压缩同时需要长上下文理解、忠实度和结构化输出生成，还需要低延迟。

为评估不同模型的上下文压缩质量，我们遵循[这里](https://factory.ai/news/evaluating-compression)提出的方法学。我们从 [SWE-chat](https://huggingface.co/datasets/SALT-NLP/SWE-chat) 和 [SWE-smith](https://huggingface.co/datasets/SWE-bench/SWE-smith) 各随机抽样 250 条多轮 agentic 轨迹，用一个 LLM 针对这些轨迹生成 4 个探测问题，覆盖具体事实回忆、已做的决策、产物文件追踪和逻辑上的续写，并附上对应的 ground truth 答案。然后让候选压缩模型总结这些轨迹，并在提示中明确要求保留上述要素。再让一个 LLM 根据摘要回答这 4 个探测问题，对照 ground truth 以 0–5 分评分。

我们在多个模型上运行这套评测，并把压缩延迟测量为每请求的平均端到端延迟。Mercury 2 是唯一落在「Fast & Good」象限的模型——速度大约比 Sonnet 4.6 快 5 倍，质量与它持平。在*速度-质量-成本的权衡*上，Mercury 2 不做妥协。

以下是 Augment Code 在生产中使用 Mercury 2 的方式：

- **上下文压缩：** Mercury 2 以惊人的效率驱动 Augment 的上下文压缩。与之前的模型（如 Opus 4.7）相比，切换到 Mercury 2 带来 **82% 的延迟下降**和 **90% 的成本削减**，同时压缩质量完全一致。

- **迅捷的工具搜索：** Augment 用 Mercury 2 为 Model Context Protocol（MCP）服务器的工具生成摘要。它是「find-tool」背后的引擎，即时把正确的工具匹配到当前任务。Mercury 2 在**一秒之内**返回这些摘要——这种速度对于保持无缝的用户体验、同时避免把所有工具都留在活动上下文窗口里造成臃肿，极其关键。

## **超越编程：Agentic 系统的去向**

同样的模式远远超出编程。客服系统会在分诊、检索、解决、升级和质量控制等专门 agent 之间路由。工作流自动化系统会用不同的 agent 分别负责接收、路由、执行、异常处理与可审计性。

在所有这些场景中，系统里最重要的许多调用并不要求最高水平的智能。它们要求的是别的东西：足够强的质量、极高的速度、规模化的低成本。这正是 subagent 这一层。它们是维持整个系统运转的那些重复性辅助调用：总结状态、路由任务、检索上下文、准备交接、检查输出、为下一步整理信息。

这正是 Mercury 2 的价值所在。Mercury 2 是基于 diffusion 的 LLM，把速度、质量、成本的 Pareto 前沿向外推。这意味着开发者不必为了压低延迟和成本而牺牲质量，也不必为了可靠性而忍受又慢又贵的辅助调用。对于不要求顶级智能的 subagent，Mercury 2 是最好的解法，因为它把那条前沿向外推移。
