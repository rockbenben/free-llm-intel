今天，我们很高兴地宣布 [Mercury 2 已在 Azure AI Foundry 上线](https://ai.azure.com/explore/models/Mercury-2/version/1/registry/azureml-inceptionlabs)——这款全球最快的推理语言模型，旨在让生产环境中的 AI 响应快到近乎即时。此次发布将 Inception 突破性的 diffusion 架构与 Azure 的企业级就绪基础设施结合起来，让开发者能够使用一个兼具卓越速度与质量的模型。

Mercury 由 Flash Attention、Direct Preference Optimization 以及最早面向图像的 diffusion 模型等基础 AI 技术背后的团队打造，代表着语言模型生成文本方式的一次根本转变。Azure AI Foundry 上的开发者现在可以获得一个在延迟敏感应用中表现出色的模型——在这些应用里，用户体验不容妥协。

## 新的基础：面向实时推理的 Diffusion

Mercury 2 不进行串行解码。它通过并行精化生成响应，同时产出多个 token，并在少量步骤内收敛。不像打字机逐字输出，更像编辑一次性修改整篇草稿。结果是：生成速度快 5 倍以上，并带来一条根本不同的速度曲线。

速度优势也改变了推理的权衡。如今，更高的智能意味着更多的测试时计算——更长的思维链、更多采样、更多重试——直接以延迟和成本为代价。基于 diffusion 的推理让你在实时延迟预算内获得推理级的质量。

## 性能：速度与质量

Mercury 2 为生产部署改变了质量-速度曲线：

- **速度**：在 NVIDIA Blackwell GPU 上达到 1,009 tokens/秒
- **价格**：输入 $0.25/1M tokens · 输出 $0.75/1M tokens
- **质量**：与领先的 speed-optimized 模型不相上下
- **特性**：可调推理强度 · 128K 上下文 · 原生工具调用 · 符合 schema 的 JSON 输出

我们优化的速度是用户真正感受到的速度：用户所经历时刻的响应性——高并发下的 p95 延迟、轮次间的一致表现，以及系统繁忙时稳定的吞吐量。

## 企业级就绪的 Azure 环境

Azure AI Foundry 上的 Mercury 2 开箱即用、可直接投入生产。它拥有 128K token 上下文窗口，可处理大型文档、维持长对话；支持原生工具调用与使用 JSON schema 的结构化输出，用于构建 agentic 工作流。API 兼容 OpenAI，与现有代码库的集成无缝。

Azure AI Foundry 提供企业级基础设施，包括网络隔离、确保数据留在你自己的 Azure 环境中且绝不用于训练的数据隐私保障、SOC2 与 HIPAA 等 Azure 合规标准，以及通过 Azure Monitor 和 Application Insights 实现的全面可观测性。

## 真实世界用例

Mercury 2 在延迟敏感、用户体验不容妥协的应用中表现出色：

- **编程与编辑**：自动补全、下一个编辑建议、重构、交互式代码 agents——开发者在环中、任何停顿都会打断心流的场景。
- **Agent 循环**：agentic 工作流每个任务串联数十次推理调用。降低单次调用延迟不只是省时间，它改变了你能负担的步数，以及最终输出能有多好。
- **实时语音与交互**：语音接口拥有 AI 中最严苛的延迟预算。Mercury 2 让推理级质量在自然语音节奏内成为可能。
- **搜索与 RAG 流水线**：多跳检索、重排与摘要的延迟叠加很快。Mercury 2 让你把推理加入搜索循环而不突破延迟预算。

### 在 Azure AI Foundry 上部署

Mercury 2 已通过 Azure AI Foundry 在美国和加拿大区域提供。部署很直接——在 Azure AI Foundry 的统一目录中开通你的模型端点并配置基础设施。Mercury 2 的软件许可按固定小时费率计费，算力费用根据你开通的资源通过你的 Azure 账户单独结算。

### Azure AI Foundry 集成

Mercury 2 与更广泛的 Azure 生态无缝集成。使用 Azure AI Foundry 的模型目录部署，用 Azure AI Content Safety 做内容过滤，实时监控性能与成本，用 Azure RBAC 和托管身份管理访问，以及使用 Azure 的 agent 框架构建多模型应用。

## 三步开始使用

- 进入 Azure AI Foundry 的 [Model Catalog](https://ai.azure.com/explore/models)，搜索 **Mercury 2**，点击模型卡片。也可以直接访问我们[这里的模型卡片](https://ai.azure.com/explore/models/Mercury-2/version/1/registry/azureml-inceptionlabs)
- 点击 **Use this model**，选择一个项目，按 UI 提示开通你需要的容量。
- 默认配置适用于大多数开发者，但我们推荐选择 **ND-H100-v5** 实例以获得最佳速度。部署会在几分钟内完成。

就是这样！你现在应该可以基于刚开通的 API 端点开始构建了：

```
curl --location 'https://mercury-5892-edfar.eastus.inference.ml.azure.com/v1/chat/completions' \
--header 'azureml-model-deployment: mercury-2' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer &lt;your-api-key&gt;' \
--data '{
  "model": "mercury-2",
  "messages": [
    { "role": "user", "content": "Hello!" }
  ],
  "stream": true,
  "temperature": 0.0,
  "max_tokens": 512
}'
```

### Python 版

```
import requests
import json

url = "https://mercury-5892-edfar.eastus.inference.ml.azure.com/v1/chat/completions"

payload = json.dumps({
  "model": "mercury-2",
  "messages": [
    {
      "role": "user",
      "content": "Hello!"
    }
  ],
  "stream": False,
  "temperature": 0,
  "max_tokens": 512
})

headers = {
  'azureml-model-deployment': 'mercury-2',
  'Content-Type': 'application/json',
  'Authorization': 'Bearer &lt;your-api-key&gt;'
}

response = requests.request("POST", url, headers=headers, data=payload)

print(json.loads(response.text))
```
