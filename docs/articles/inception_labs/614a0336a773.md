# 规模化扩散：Mercury 3 发布

今天我们发布 Mercury 3，这是迄今推出的能力最强的 diffusion-based LLM。在一系列 benchmark 上，Mercury 3 的表现都超过 GPT-6 Luna 和 Claude Haiku 5.5，同时快 4–8 倍，达到每秒 1,000+ tokens。

Mercury 3 证明了文本 diffusion 是可规模化的。它比 Mercury 1 大 40 倍以上，智能程度高出很多，但同样快。

早期接入的合作伙伴已经在把 Mercury 3 用于语音与在线客服、实时辅导、数据工程和网页浏览：

## Mercury 3 一览

- **质量：**与 GPT-6 Luna、Claude Haiku 5.5 这类速度优化的前沿模型相当或更好。
- **速度：**在 NVIDIA GPU 上每秒 1,068 tokens。
- **上下文：**1M tokens，高于 Mercury 2.5 的 260K
- **价格：**每百万输入 tokens $0.20，每百万输出 tokens $0.70。发布之际 Mercury 3 半价，为每 1M 输入 $0.10、每 1M 输出 $0.35。缓存 token 在输入价基础上优惠 90%。

## 规模化扩散

我们发布 Mercury 1 时，它是 diffusion LLM 可以面向商业应用构建的第一个实证。当时 AI 社区悬而未决的问题是：diffusion LLM 能否规模化，在复杂用例上与自回归模型竞争。

Mercury 3 回答了这个问题：能。我们把 Mercury 的总参数量放大了 40 倍以上，一系列标准 benchmark 上的智能水平从 Mercury 1 (mini) 到 Mercury 3 提升了 3 倍。推动自回归模型进步的那些 scaling laws，对 diffusion 同样成立。

## Mercury 3 的生产落地

早期接入的合作伙伴已经在运行 Mercury 3，为浏览器操作 agent、交互式教育、实时搜索 agent 和客服这类对延迟敏感的应用提供支撑。

### 浏览器操作 agent

agent 在每一步都要等模型，所以微小的延迟会迅速累积。Mercury 让每一轮都保持很快，无论 agent 是在网站之间浏览、跨来源做调研，还是在分析日志、追踪事故。agent 能更早完成任务，也有时间在给出答案之前尝试更多方案。

我们在自研的生产级 web-agent harness 里，把 Mercury 3 与前沿模型在 50 个真实 Mind2Web 导航任务上做了对比。Mercury 3 完成了其中 50%，明显高于 GPT-6.1-Sol。而它用的 token 量与 agent 步数和一个前沿模型相同，每 token 成本却只有对方的一小部分。

Shuhao Zhang，TinyFish AI 联合创始人

### 交互式教育

学习依赖快速的反馈 loop，任何延迟都会把学生从内容里拽出来。Mercury 会对每个请求完成推理并近乎实时地回应，无论那是一段撑起对话的语音家教、一个批改作业的助手，还是一个根据学生刚刚答错的内容来调整下一道题的应用。

Mercury 3 让我们能给每个学生即时反馈，同时不牺牲推理。提示、批阅结果和名词解释现在大约一秒就能返回，质量与我们此前运行的模型相当甚至更好。学生卡在某道题上时，这个速度让他们继续做题而不是干等，而且它对我们现有的技术栈是可以直接替换的。

Michael Tong，General Learning（即 RevisionDojo）联合创始人 / CTO

### 实时搜索 agent

搜索应用只要延迟几秒，就会让人觉得没有响应。Mercury 3 运行得足够快，能处理几十份文档，并且仍然在用户还专注等待时给出回答。

在智能眼镜上，一个要五秒才出现的答案会让人觉得系统坏了。在我们的 Sense API 测试中，Octen 的搜索耗时约 80ms，模型生成才是瓶颈。在我们测过的那些快模型里，Mercury 3 在速度与质量之间取得了最好的平衡：生成时间中位数 0.9 秒，端到端响应时间中位数 2.2 秒。

Kuan Zou，Octen AI 创始人 & CEO

### 客户服务

客服 agent 必须答得很快，而且服务的常常是受监管的企业，一次答错的代价很高。Mercury 让回复保持对话感，同时不牺牲准确性。

在 Lorikeet，我们帮助复杂且受监管的企业为客户构建一个跨语音、在线聊天和邮件工作的“管家”。在聊天和语音中，客户需要快速的回应，但我们在准确性、在把事情做对上不做妥协。早期测试中，Mercury 3 在延迟上胜过其他模型，同时在 eval 和生产环境里的表现也更高。

Michael Gribben，Lorikeet 技术团队成员

## 一套实时的产品组合

Mercury 3 是不断扩充的实时 AI 产品组合中的旗舰模型。

- **Mercury Voice:** Mercury Voice 为语音应用极端的低延迟要求做了定制，目标是最小化首个回答 token 的时间（TTFAT），而不只是端到端延迟。它已经在为 Audivi AI、Altur 和 OpenCall 的 agent 提供支撑。

- **Mercury Decide:** Mercury Decide 是一个为大规模分类构建的决策模型。它在包括 JevBench 和 LegalBench 在内的 benchmark 上胜过 Jev。
