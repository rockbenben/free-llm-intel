# Grok Build 中的 Agent Dashboard

同时管理多个编码会话。查看每个会话在做什么，回复需要你介入的会话，并派发新的任务。

Agent Dashboard 把所有 Grok Build 会话集中在一屏。你可以看到每个会话在做什么、让它们并行运行，只在需要输入时才介入。

在 shell 中运行 `grok dashboard`，或在任意会话内运行 `/dashboard`（`Ctrl+\`）。

## [一屏总览所有会话](https://x.ai/news/agent-dashboard#see-every-session-at-a-glance)

Dashboard 按状态对会话排序，把一切等待输入的条目拉到最顶部，让你先处理阻塞项，其余的继续运行。快速扫一眼就能看到每个会话在做什么、已经运行多久，无需打开任何会话就能掌握全局。

会话分散在多个仓库？用 `Ctrl+S` 按工作目录分组。子代理（subagent）会归拢在启动它的会话之下，因此列表展示的是你派发的工作，而不是其下的展开层级。

## [Peek 与回复](https://x.ai/news/agent-dashboard#peek-and-reply)

选中某一行，即可在不离开 dashboard 的情况下查看它的最新输出，并直接在那里回复。空闲会话会立即发送消息；活跃会话则把你的消息排队，等当前回合结束后处理。

当会话请求批准或提出问题时，它的选项会内联显示。用方向键或数字键作答即可继续。多段式问题会逐条送达。

## [派发新会话](https://x.ai/news/agent-dashboard#dispatch-new-sessions)

底部的输入框用于启动新会话。按 `Enter` 派发后仍留在 dashboard；按 `Shift+Enter` 则派发并立即打开。发送前可以设置模型、以 plan mode 启动，或让会话自行批准它的编辑。

## [接管任意会话](https://x.ai/news/agent-dashboard#take-over-any-session)

打开任意会话即可接管它的完整对话。无需返回列表就能切换到下一个或上一个会话，结束后再回到 dashboard。关闭 dashboard 时所有会话都仍在运行，重新打开时它们全都在那里。

## [开始使用](https://x.ai/news/agent-dashboard#get-started)

Agent Dashboard 随 Grok Build 一同发布。用一条命令安装，然后运行 `grok dashboard`，或在已打开的任意会话中运行 `/dashboard`。
