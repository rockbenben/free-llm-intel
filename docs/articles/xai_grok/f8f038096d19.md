## [补上进度、清空积压](https://x.ai/news/introducing-outlook-addin#catch-up-on-threads-and-clear-the-backlog)

打开一条聊了一整周的邮件串，问问发生了什么。Grok 会带着决策、负责人，以及还在等你处理的事项回来。当积压越堆越高，它可以一次性扫描最近的邮件——归档已结束的对话、清掉噪音、并点出需要回复的消息。加载项还能读附件、搜索网页和 X，让你不离开 Outlook 就能查东西。

### [像你一样说话的回复](https://x.ai/news/introducing-outlook-addin#replies-that-sound-like-you)

几个粗糙的词就够了。Grok 把它们变成符合你书写风格的回复，或从零写一封新邮件。然后你可以要求微调：更紧凑的标题、换收件人、更热情的语气。在你按下发送之前，什么都不会发出。

## [开始使用](https://x.ai/news/introducing-outlook-addin#get-started)

Grok for Outlook 是 Microsoft 365 加载项，今日面向所有付费 X 与 SuperGrok 用户开放。[从 Microsoft Marketplace 添加](https://marketplace.microsoft.com/en-us/product/office/WA200011330?tab=Overview)，即可在邮箱里直接与 Grok 协作。[Word](https://x.ai/grok/word)、[Excel](https://x.ai/grok/excel) 和 [PowerPoint](https://x.ai/grok/powerpoint) 版本同样提供。
