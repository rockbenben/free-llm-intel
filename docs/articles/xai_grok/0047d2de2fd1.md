# 在 Kilo Code 中使用 Grok

在你的 SuperGrok 或 X Premium+ 订阅基础上，使用开源智能体编码平台 Kilo Code。

从今天起，你可以直接在 [Kilo Code](https://kilo.ai/) 内使用你的 Grok 订阅。

Kilo Code 是面向 VS Code、JetBrains IDE 和终端的开源智能体工程平台。它为规划、编码、调试和编排提供专门模式，并具备强大的工具使用、浏览器自动化、MCP 扩展能力和 500+ 模型支持。Kilo 为真实软件工程工作流与智能体用例而设计。

用你的 X Premium+ 或 SuperGrok 订阅，连接 Grok 账户即可在 Kilo Code 内使用最新的 Grok 模型——包括用于智能体编码的 Grok Build——无需单独的 API key。

## [设置](https://x.ai/news/grok-kilocode#setup)

Kilo Code 提供 IDE 扩展、CLI 和网页端。要连接你的 xAI 账户，请按以下说明操作：

**VS Code：**

- 从 VS Code Marketplace 安装 [Kilo Code](https://marketplace.visualstudio.com/items?itemName=kilocode.Kilo-Code)。
- 打开 **Settings**（齿轮图标），进入 **Providers** 标签页。
- 点击 **Show more providers**，然后搜索或选择 **xAI**。
- 选择 **xAI Grok OAuth (SuperGrok Subscription)** 登录项，在浏览器中完成 OAuth 流程。

在无头或远程环境（VPS、SSH、Docker、WSL）中，请改选 **xAI Grok OAuth (Headless / Remote / VPS)**。

**CLI：**

```
npm install -g @kilocode/cli
```

bash

在你的项目目录运行 `kilo`，用 `/connect` 命令添加 xAI。

更多细节见 [Kilo Code xAI provider 文档](https://kilo.ai/docs/ai-providers/xai)。

更多开源智能体与集成即将到来。
