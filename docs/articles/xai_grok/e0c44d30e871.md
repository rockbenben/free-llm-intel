# 把 Grok 带给每一个人

Grok 现在更快、更敏锐，多语言支持也得到提升。它已向 𝕏 平台上的所有用户开放。

自 8 月发布 Grok-2 以来，我们一直在努力改进 𝕏 上的 Grok，加入了网页搜索、引用来源，以及我们近期的图像生成器 Aurora 等新功能。

过去几周，我们一直在悄然测试一个新版本的 Grok-2 模型：速度快 3 倍，并在准确性、指令跟随和多语言能力上有所提升。

今天我们兴奋地宣布，开始把这一新版 Grok-2 向 𝕏 上的所有用户免费推送。一如既往，Premium 和 Premium+ 用户享有更高的使用限额，并将率先体验未来的任何新功能。

## [搜索结果与引用来源](https://x.ai/news/grok-1212#search-results-and-citations)

Grok 借助 𝕏 平台实时理解世界上正在发生什么。我们近期上线了两项额外功能，让这一体验更进一步：网页搜索与引用来源。现在 Grok 会同时援引 𝕏 上的帖子和更广泛互联网上的网页，为你的提问提供及时准确的回答。我们还加入了引用来源，方便你轻松深入某个原始出处，进一步了解或验证 Grok 提供的信息。

## [Grok，画一个！](https://x.ai/news/grok-1212#grok-draw-me)

Grok 擅长创作富有创意的照片和逗趣的表情图（meme）。现在有了 Aurora——我们尖端的自回归图像生成模型——它更进一步。Aurora 为你的 Grok 图像生成带来了新水平的照片真实感（photorealism），我们非常乐见大家分享的各种图像和 meme。

作为与 X 平台集成的一部分，我们近期还发布了 "draw me" 功能，用户可以使用自己 𝕏 主页资料中的信息，生成重新想象的自己。如果你在 𝕏 上看到其他用户的 "draw me" 帖子并想亲自试试，只需点击 "Create your version with Grok" 按钮！

## [API 访问](https://x.ai/news/grok-1212#api-access)

一个月前，我们发布了企业 API 的公测版，附带预览模型 `grok-beta` 和 `grok-vision-beta`。今天我们要为 API 新增两个模型：`grok-2-1212` 和 `grok-2-vision-1212`。这些模型在准确性、指令跟随和多语言能力上都有提升，为寻找高可控、智能模型的开发者提供了一个极佳选择。

由于效率方面的改进，我们同时下调这些模型的价格：每 100 万输入 tokens $2，每 100 万输出 tokens $10。
