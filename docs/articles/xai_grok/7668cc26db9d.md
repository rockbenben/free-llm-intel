# Grok Imagine 1.5 预览版

`grok-imagine-video-1.5-preview`——我们最新的图生视频模型——现已通过 xAI API 以预览形式提供。

Create API key

我们最新的图生视频模型 `grok-imagine-video-1.5-preview` 现已通过 xAI API 以预览形式提供。

`grok-imagine-video-1.5-preview` 把一张静态图像变成流畅、有电影感的视频。给它一个起始画面和一段描述运动的提示词，它就会让场景动起来——包括镜头运动、氛围和物理效果——同时忠实于你的源图像。你最高可以生成 720p 的片段。

Your browser does not support the video tag.

用自然语言提示词指导镜头。描述镜头运动、节奏和声音设计，然后设定分辨率与片段时长。模型会保持输入画面的细节与光照，因此成品是原图的延续，而非重新诠释。

该模型同样擅长连续镜头。逐帧设计、逐帧动画化，再把一个个镜头串成更长的场景，让整个项目保持一致的视觉风格。

Your browser does not support the video tag.

几行代码即可让图像动起来。

```
import os
import xai_sdk

client = xai_sdk.Client(api_key=os.getenv("XAI_API_KEY"))

response = client.video.generate(
    prompt="Slow cinematic push-in as embers drift across the battlefield and the helmet's crest stirs in the wind",
    model="grok-imagine-video-1.5-preview",
    image_url="https://your-host.com/helmet.jpg",
    duration=10,
    resolution="720p",
)

print(response.url)
```
