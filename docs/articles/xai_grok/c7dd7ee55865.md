# Grok on Databricks

Grok 模型现已在 Databricks Agent Bricks 上可用。

我们很高兴分享：Grok 模型现已原生支持 Databricks Agent Bricks——Databricks 的开发者智能体平台。

作为 Databricks 2026 Data + AI Summit 的一部分，Databricks 正与 SpaceXAI 合作，让 Grok 与其他前沿及开源模型一起，在一个统一、可治理的平台上可用。

Agent Bricks 把源自 Lakehouse 数据的上下文（context）与控制和选择连接起来，让工程团队能够高效构建在海量数据上运行的 AI 智能体。

与 [Grok on Amazon Bedrock](https://x.ai/news/grok-amazon-bedrock) 一起，企业有了更多方式在数据所在之地运行 SpaceXAI 模型。

有关 Agent Bricks 的更多信息，参见 [Databricks 公告](https://www.databricks.com/blog/agent-bricks-dais-2026)。
