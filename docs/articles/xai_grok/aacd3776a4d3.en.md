# Grok 4.6 on Amazon Bedrock

Grok 4.6 is now available via Amazon Bedrock.

Today, we’re excited to announce that Grok 4.6 is now generally available on Amazon Bedrock.

Grok 4.6 is our latest flagship model, built for long-running agents and ambitious interactive and visual work. It offers 500k context window and configurable reasoning efforts (low, medium, high, xhigh). Now, Amazon Bedrock users can leverage the model through Amazon Bedrock.

## [Capabilities & Pricing](https://x.ai/news/grok-4-6-amazon-bedrock#capabilities--pricing)

Grok 4.6 is available for:

- **Input**: $2 per 1 million tokens
- **Cached input**: $0.50 per 1 million tokens
- **Output**: $6 per 1 million tokens

For more on the model, read the [Grok 4.6 announcement](https://x.ai/news/grok-4-6).

## [Build with Grok 4.6 on Amazon Bedrock](https://x.ai/news/grok-4-6-amazon-bedrock#build-with-grok-46-on-amazon-bedrock)

Grok 4.6 is now available to all developers in supported AWS Regions. Please visit AWS documentation to get started - we're excited to see what you build!
