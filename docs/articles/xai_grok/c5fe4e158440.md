## [训练 Grok 4.5](https://x.ai/news/grok-4-5#training-grok-45)

Grok 4.5 在数万块 NVIDIA GB300 GPU 上训练，并采用了为大规模运行设计的训练与稳定性技术。除了原始 token 数量，我们在数据过滤与策展上投入巨大：去重、质量打分、面向领域的精选，让数据配比始终保持高覆盖、高信噪比。

我们扩展了强化学习，并高度聚焦"每 token 智能"（per-token intelligence）。RL 训练覆盖数十万个任务，以多步软件工程和其他技术工作为核心，配合自动化与基于模型的评分。我们的技术栈为高度异步训练而生，因此智能体 rollout 可以运行数小时，而学习在数万块 GPU 上持续进行。带来的结果是在真实工程与智能体任务上更智能、更高效的推理。

## [定价](https://x.ai/news/grok-4-5#pricing)

与其他领先模型相比，Grok 4.5 的成本极具竞争力。Grok 4.5 定价为每百万输入 tokens $2、每百万输出 tokens $6。该模型还实现了约为同类领先模型 2 倍的 token 效率，用不到一半的步骤完成任务。总体而言，Grok 4.5 在单位时间与单位成本上交付最高的智能。
