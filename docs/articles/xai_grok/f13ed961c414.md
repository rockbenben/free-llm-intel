# Microsoft Foundry 上的 Grok 4.6

Grok 4.6 现已通过 Microsoft Foundry 提供。

今天，我们兴奋地宣布 Grok 4.6 现已在 Microsoft Foundry 上线。

Grok 4.6 是我们最新的旗舰模型，为长时间运行的智能体以及更具雄心的交互式与视觉化工作而生。它提供 500k 上下文窗口和可配置的推理强度（low、medium、high、xhigh）。

有关模型的更多信息，请阅读 [Grok 4.6 发布公告](https://x.ai/news/grok-4-6)。

## [在 Microsoft Foundry 上用 Grok 4.6 构建](https://x.ai/news/grok-4-6-microsoft-foundry#build-with-grok-46-on-microsoft-foundry)

Foundry 为组织提供了一个统一的场所：把 Grok 4.6 与其他前沿模型对比评估、运行业务场景专用测试、部署托管端点（managed endpoints），并在企业级安全与治理管控下运行。

如果你正在构建编码智能体、工程副驾（engineering copilot）、研究助手或企业自动化，可以从 [Foundry 模型目录](https://ai.azure.com/catalog/models)开始。部署细节参见微软的公告 [Grok 4.6 comes to Microsoft Foundry Models](https://techcommunity.microsoft.com/blog/azure-ai-foundry-blog/grok-4-6-comes-to-microsoft-foundry-models-built-for-long-horizon-reasoning-and-/4547578)，以及我们的 [Microsoft Foundry 集成指南](https://docs.x.ai/developers/community/microsoft-foundry)。
