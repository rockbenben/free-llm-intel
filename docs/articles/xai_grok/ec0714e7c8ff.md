# 推出 The X Subscription

Grok、Grok Bot、Cursor 和 X Premium，一个套餐全部包含。

[对比套餐](https://x.ai/pricing)

今天我们推出 The X Subscription，把 Grok、Grok Bot、Cursor 和 X Premium 收进同一个套餐。接下来几天内，全球所有用户都能用上它。

这是第一次，一份 AI 订阅能覆盖从思考、创作到构建、分享的完整链路。

- **Grok** 支持对话、语音，以及图片和视频生成。
- **Grok Bot** 提供能把活干完的 AI 队友。
- **Cursor** 提供业界领先的本地与云端编程智能体。
- **X** 则加上认证蓝标、创作者工具和更少的广告，更高档位会把信息流里的广告彻底移除。

The X Subscription 的付费套餐包含一份充裕的 Grok 模型用量池，由 Grok 和 Cursor 共享。**每一档对标的新套餐，每一美元换来的用量都多于它所取代的套餐。**

这份共享用量池覆盖所有 Grok 模型，无论你是在 Grok 应用里、X 上的 Grok 标签页里，还是在 Cursor 里使用它们。每一档 X Subscription 套餐用我们的模型编程的用量，至少是对应 Cursor 套餐的两倍。在新套餐下，Premium 及以上档位仍然可以在 Cursor 里使用第三方模型，这部分用量按 API 牌价单独计费，通过加购额度来用。

The X Subscription 从今天起面向新客户开放。

我们也在逐步向现有的 SuperGrok、Cursor 和 X Premium 订阅用户开放转换选项。当你的账号可以用时，会在账号的账单设置里看到它。你可以保留当前套餐，也可以转换，并就此前的套餐拿到未使用时长折算的退款。

## [一份订阅，覆盖团队与企业](https://x.ai/news/x-subscription#one-subscription-for-teams-and-enterprises)

团队用户在 The X Subscription 上可以使用 Premium、Super 和 Ultra，每个席位的价格与个人套餐相同。这比旧的 Cursor Teams 每席位更便宜，编程用量却多出 3 倍，另外还包含 SSO、管理员控制、统一账单、用量分析和 SOC 2 合规。

企业客户可以在一个控制台上管理 Grok 和 Cursor，两个产品共用同一份用量池。我们的销售团队随时可以帮助你[开始使用](https://x.ai/contact-sales)。

## [保留现有套餐，或转到 The X Subscription](https://x.ai/news/x-subscription#keep-your-current-plans-or-move-to-the-x-subscription)

现有的 SuperGrok、Cursor 或 X Premium 订阅用户不会有任何变化。你可以保留当前的套餐、价格和功能，也可以转到 The X Subscription。
