# 介绍 X 订阅

Grok、Grok Bot、Cursor 和 X Premium，全部包含在一个计划中。

[比较计划](https://x.ai/pricing)

今天，我们推出 X 订阅，它将 Grok、Grok Bot、Cursor 和 X Premium 整合在一个计划中。在接下来的几天里，我们将向全球所有人提供它。

一次人工智能订阅首次支持从思考、创造到构建和共享的完整路径。

- **Grok** 支持聊天、语音、图像和视频生成。
- **Grok Bot** 为您提供完成工作的人工智能队友。
- **Cursor** 提供领先的本地和云编码代理。
- **X** 添加了复选标记、创作者工具和更少的广告，更高的级别会完全从时间轴中删除广告。

X 订阅的付费计划包括在 Grok 和 Cursor 之间共享的大量 Grok 模型使用池。 **每个类似的新套餐比它所取代的计划提供更多的每美元使用量。**

无论您是在 Grok 应用程序、X 上的 Grok 选项卡还是 Cursor 中使用它们，您的共享池都会涵盖 Grok 模型。每个 X 订阅计划在我们的模型中包含的编码使用量至少是同类 Cursor 计划的两倍。在新计划中，第三方模型仍然可以在 Cursor on Premium 及更高版本中使用。使用量通过充值按 API 标价单独计费。

从今天开始，新客户可以使用 X 订阅。

我们还推出了针对现有 SuperGrok、Cursor 和 X Premium 订阅者的切换选项。当它可用时，您将在帐户结算设置中看到它。您可以保留当前的计划，也可以切换旧计划并获得按比例退款。
