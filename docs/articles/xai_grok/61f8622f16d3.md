# 介绍 Grok Bot

Grok Bot 是你的一支永远在线的智能体团队。他们有自己的电脑，像你一样在工具和应用里干活，全天候 24/7 持续工作。

Download for macOS





今天我们发布 Grok Bot——你可以把真实工作交付给他们的 AI 队友。

Bots 拥有自己的电脑。他们登录你已在使用的工具，跨应用、跨收件箱工作。他们把活儿从头干到尾，只在有需要你批准的事情时才回来找你。

你可以像给同事发消息一样给他们发消息，把工作移交给他们。他们记得对话、学会你偏好的做事方式，越合作越锋利。

Grok Bot 最初是我们内部的一个原型，随后在全公司火了起来。团队创建 Bots 来处理销售外联、市场活动、办公室运营、bug 修复等等。今天，我们很高兴把它开放给全世界。

Grok Bot 处于 beta，今日面向 SuperGrok、SuperGrok Plus、SuperGrok Heavy；Cursor Pro、Pro+ 和 Ultra；以及 Cursor Teams Standard 与 Premium 订阅用户开放，支持桌面与 iOS。Grok Bot 自带独立用量，与你的 Grok 和 Cursor 套餐分开，因此交给 Bots 的任何工作都不会占用你的现有用量。[下载应用](https://x.ai/bot#download)，创建你的第一个队友，开始移交工作。企业用户可以加入等候名单以获得后续访问。

## [Grok Bot 有何不同](https://x.ai/news/introducing-grok-bot#how-grok-bot-is-different)

### [一台自己的电脑](https://x.ai/news/introducing-grok-bot#a-computer-of-its-own)

早期访问用户说，Grok Bot 用起来不像在给智能体写提示，而像把工作交给一位能力极强的队友。Bots 在云端共享自己的电脑，所以你离开时工作不会停摆。他们可以登录并跨应用、工具和网站工作——包括那些没有干净 API 或 MCP 的平台——然后带着完成的工作回来。

在 SpaceXAI 内部，这已经体现为一件件真实的多步协作任务：销售 Bot 把通话纪要写进 CRM 并起草跟进；运营 Bot 为新员工安排工位并处理 Gmail 里收到的发票；工程 Bot 在产品 UI 里复现一个 bug、建好工单，再把修复移交给一个调试 Bot。

> 完成 90% 和完成 100% 之间有巨大差别。多数 AI 让你走到差不多，Grok Bot 能把这一棒挥到底——因为成果落在人该落的地方：真实的工具里。

— Roman，Product

### [像给队友发消息一样](https://x.ai/news/introducing-grok-bot#message-it-like-a-teammate)

上手 Grok Bot 很容易。你可以从手机或桌面给 Bot 发消息，就像给团队里的人发短信，之后在任意一端接续同一对话串。

其他 AI 工具可能要求你先搭好工作流和例行任务。在 Grok Bot，只需发消息让 Bot 接一件事，它就把它办完。

> 没有什么要学的。就像来了位新同事。不用设置自动化，没有产品怪癖，也没有复杂的命名。你只是在和朋友聊天。

— Fiona，Community

### [同时与多个 Bots 协作](https://x.ai/news/introducing-grok-bot#work-with-many-bots-at-once)

SpaceXAI 内部的人们常常并行运行多个 Bots，其中一个负责管理其余。幕僚长（chief of staff）居顶，每条线各有一位专家：邮箱管理、报销、招聘、bug 修复、运营。Grok Bot 给你的不是多个需要你管的 agent，而是一支能并行干活的小团队——你不用当中间人。

Bots 能相互独立发消息、在对话串中共享上下文。项目交叉时，他们围绕同一个账户或项目保持一致，不需要你在几个聊天之间粘贴笔记。

你还可以把 Bots 放进一个群聊，让他们自行协调。他们相互交接、指派负责人，只在需要拍板时才拉你进来。

> 和 Grok Bot 一起工作，感觉像我有了八条章鱼一样的手臂，每条手臂都与其他协调一致，每条都按我的方式完成任务。

— Vincent，Growth

### [示范给 Bot 看怎么干](https://x.ai/news/introducing-grok-bot#show-a-bot-how-its-done)

让 Bot 学会你工作流的最好方式，是下次干活时让它跟做一遍。它会观察步骤、记住你偏好的做法。

它把你的工作流保存为例行任务（routine），吸收你的纠正，下次就自己运行——于是同样的多步流程你可以直接移交，不必再解释一遍。

> 我只演示过一次的工作流，现在完全放心让它永远自己跑。我觉得自己高效了 2-3 倍，因为它做的时候不需要我再验证和复核。

— Bennett，Sales

### [随着时间把更多信任交给 Bots](https://x.ai/news/introducing-grok-bot#trust-your-bots-with-more-over-time)

Bots 是随时间越来越锋利的队友。他们保留着你偏好如何做事的上下文。几件任务之后，他们学到了你的语气、你的边界情况，知道什么时候该@你、什么时候继续干。

他们可以跟进你放下的对话串、推动卡住的交接、从先前的对话中重新捡起工作。

随着时间推移，他们变得更主动：在你开口之前就把活接起，并知道什么事需要你的注意。

> 刚开始时，我每 15 分钟查看一次、微观管理这些 Bots，到最后他们问我为什么总问那么多问题。现在我让它放手去干，它只是随时间越做越好。

— Emma，Operations
