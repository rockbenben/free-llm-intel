# Grok Build 插件市场

推出 Grok Build 内建插件市场。

今天我们推出 [Grok Build Plugin Marketplace](https://github.com/xai-org/plugin-marketplace)——一套为 [Grok Build](https://x.ai/build) 内建的插件。

一个插件把 [skills](https://x.ai/news/grok-skills)、斜杠命令、agent、hooks、MCP 服务器和 LSP 打包成一个可安装的套件。市场内建于 Grok Build，你可以不离开终端就浏览、安装和更新插件。

## [上线即可用](https://x.ai/news/grok-plugin-marketplace#available-at-launch)

市场首发汇聚了全栈各层的伙伴插件：

- **[MongoDB](https://www.mongodb.com/docs/mcp-server/overview/)** — 探索数据、管理集合、优化查询。
- **[Vercel](https://github.com/vercel/vercel-plugin)** — 管理部署、查看构建状态、配置域名。
- **[Sentry](https://github.com/getsentry/sentry-for-ai)** — 分析堆栈跟踪、调试生产环境错误。
- **[Chrome DevTools](https://github.com/ChromeDevTools/chrome-devtools-mcp)** — 控制实时浏览器、录制性能轨迹、检查网络请求。
- **[Cloudflare](https://github.com/cloudflare/skills)** — 面向 Workers、Durable Objects 等的 Skills。
- **[Superpowers](https://github.com/obra/superpowers)** — 流行的智能体驱动工作流。

## [秒装](https://x.ai/news/grok-plugin-marketplace#install-in-seconds)

在 Grok Build 内输入 `/marketplace` 浏览目录，按 `i` 安装插件。或者从终端：

```
grok plugin marketplace list
grok plugin install <name> --trust
```

bash

目录中的每个远程插件都钉在特定的 commit SHA 上，Grok Build 会在安装时校验该钉。

## [发布你自己的插件](https://x.ai/news/grok-plugin-marketplace#publish-your-own)

市场是开放的目录。如果你做了一个想分享的插件，向 [xai-org/plugin-marketplace](https://github.com/xai-org/plugin-marketplace) 提交 pull request 即可。

初用 Grok Build？访问 [x.ai/build](https://x.ai/build) 开始。
