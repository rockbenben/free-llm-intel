# Gemini Enterprise Agent Platform 上的 Grok 4.6

Grok 4.6 现已通过 Gemini Enterprise Agent Platform 提供。

今天，我们兴奋地宣布 Grok 4.6 现已在 Gemini Enterprise Agent Platform 上线。

Grok 4.6 是我们最新的旗舰模型，为长时间运行的智能体以及更具雄心的交互式与视觉化工作而生。它提供 500k 上下文窗口和可配置的推理强度（low、medium、high、xhigh）。现在，Gemini Enterprise Agent Platform 用户可以通过 [Model Garden](https://console.cloud.google.com/agent-platform/publishers/xai/model-garden/grok-4.6) 使用该模型。

## [能力与定价](https://x.ai/news/grok-4-6-vertex-ai#capabilities--pricing)

Grok 4.6 的价格：

- **输入**：每 100 万 tokens $2
- **缓存输入**：每 100 万 tokens $0.50
- **输出**：每 100 万 tokens $6

有关模型的更多信息，请阅读 [Grok 4.6 发布公告](https://x.ai/news/grok-4-6)。

## [在 Gemini Enterprise Agent Platform 上用 Grok 4.6 构建](https://x.ai/news/grok-4-6-vertex-ai#build-with-grok-46-on-gemini-enterprise-agent-platform)

Grok 4.6 现已在 Model Garden 中向开发者开放。要开始使用，请访问 [Grok 4.6 模型卡](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/partner-models/grok/grok-4-6)。我们期待看到你的作品！
