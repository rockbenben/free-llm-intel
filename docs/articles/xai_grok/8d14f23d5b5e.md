# 宣布 PromptIDE

面向提示工程与可解释性研究的集成开发环境。

**xAI PromptIDE 是一个面向提示工程（prompt engineering）与可解释性研究的集成开发环境。它通过一个可实现复杂提示技巧的 SDK、以及可视化网络输出的丰富分析能力，加速提示工程。在我们对 [Grok™](https://x.ai/news/grok) 的持续开发中大量使用了它。**

我们开发 PromptIDE，是为了让社区里的工程师和研究人员透明地访问 Grok-1——为 [Grok™](https://x.ai/news/grok) 提供动力的模型。这个 IDE 旨在赋能用户，帮助他们快速探索我们大语言模型（LLM）的能力。IDE 的核心是一个 Python 代码编辑器——配合全新的 [SDK](https://developers.x.ai/python-sdk/)，可实现复杂的提示技巧。在 IDE 中执行提示时，用户能看到有用的分析：精确的 tokenization、采样概率、候选 token，以及聚合的注意力掩码。

IDE 还提供多项提升体验的功能。它自动保存所有提示并内置版本管理。运行提示产生的分析可永久保存，让用户比较不同提示技巧的输出。最后，用户可以上传 CSV 之类的小文件，并用 SDK 的一个 Python 函数读取。结合 SDK 的并发能力，即使是中等规模的文件也能快速处理。

我们还希望围绕 PromptIDE 建立社区。任何提示都可以一键公开分享。用户可以决定只分享提示的单个版本，还是分享整棵版本树。分享提示时还可以带上任何已保存的分析数据。

PromptIDE 面向我们早期访问计划的成员开放。下面是这个 IDE 主要功能的导览。

## [代码编辑器与 SDK](https://x.ai/news/prompt-ide#code-editor--sdk)

PromptIDE 的核心是一个代码编辑器和一个 [Python SDK](https://developers.x.ai/python-sdk/)。SDK 提供了一种新的编程范式，可以优雅地实现复杂提示技巧。所有 Python 函数都在一个隐式上下文（一段 token 序列）中执行。你可以用 `prompt()` 函数手动向上下文添加 token，也可以用我们的模型基于上下文通过 `sample()` 函数生成 token。

代码在本地执行，使用运行在独立 web worker 中的浏览器内 Python 解释器。多个 web worker 可以同时运行，意味着你可以并行执行大量提示。

复杂提示技巧可以在同一程序中使用多个上下文实现。若函数带有 `@prompt_fn` 装饰器，它会在自己全新的上下文中执行。该函数可以独立于父上下文做某些操作，并通过 `return` 语句把结果传回调用方。这种编程范式支持带任意嵌套子上下文的递归与迭代提示。

## [并发](https://x.ai/news/prompt-ide#concurrency)

SDK 使用 Python 协程，可并发处理多个带 `@prompt_fn` 注解的 Python 函数。这能显著缩短完成时间——尤其在处理 CSV 文件时。

## [用户输入](https://x.ai/news/prompt-ide#user-inputs)

通过 `user_input()` 函数可以让提示具有交互性：它会阻塞执行，直到用户在 UI 文本框中输入字符串。`user_input()` 返回用户输入的字符串，随例可以借此通过 `prompt()` 函数加入上下文。用这些 API，四行代码就能实现一个聊天机器人：

```
await prompt(PREAMBLE)
while text := await user_input("Write a message"):
    await prompt(f"<|separator|>\n\nHuman: {text}<|separator|>\n\nAssistant:")
    await sample(max_len=1024, stop_tokens=["<|separator|>"], return_attention=True)
```

## [文件](https://x.ai/news/prompt-ide#files)

开发者可以向 PromptIDE 上传小文件（每个最多 5 MiB，总量最多 50 MiB），并在提示中使用这些上传的文件。`read_file()` 函数把任何上传文件以字节数组返回。结合上文提到的并发能力，可以实现批量处理提示，在多种问题上评估一种提示技巧。下面的截图展示了一个计算 MMLU 评估分数的提示。

## [分析](https://x.ai/news/prompt-ide#analytics)

执行提示期间，用户能看到逐 token 的详细分析，帮助他们更好地理解模型输出。补全窗口显示上下文的精确 tokenization 及每个 token 的数字标识。点击某个 token，用户还能看到应用 top-P 阈值后的 top-K token，以及该 token 处的聚合注意力掩码。
