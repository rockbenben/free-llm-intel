# 把 Grok 4.5 带到 iOS、Android、网页和 X

Grok 4.5——我们迄今最智能的模型——现已登陆 grok.com、X、iOS 和 Android。

Open Grok.com

**Grok 4.5 现在在你使用 Grok 的任何地方为其提供动力**，今日已在 [grok.com](https://grok.com/?referrer=website)、X 以及 iOS 和 Android 版 Grok 应用上线。

## [对任何问题更聪明的回答](https://x.ai/news/grok-4-5-everywhere#smarter-answers-to-any-question)

Grok 4.5 是我们能力最强的模型。在日常使用中，它能领会你真正的问题、跟住更长的对话，并给出更清晰可靠的回答。让它解释一个陌生概念、帮你权衡一笔大额消费、规划一次旅行，或深入钻研你好奇的话题。而在更难的问题上，它的推理更高效，答案来得更快。

## [覆盖你的全部知识工作](https://x.ai/news/grok-4-5-everywhere#for-all-your-knowledge-work)

Grok 4.5 还能从头到尾独立完成一项任务：搭建可用的电子表格、把提纲变成干净利落的幻灯片和图示、撰写清晰的文字，或从一份长 PDF 中提取要点——无论你在办公桌前还是在手机上。

通过我们的 Microsoft 365 加载项，Grok 还能直接在 [Word](https://x.ai/grok/word)、[Excel](https://x.ai/grok/excel)、[PowerPoint](https://x.ai/grok/powerpoint) 和 [Outlook](https://x.ai/grok/outlook) 内工作。有关模型本身的更多细节，请阅读 [Grok 4.5 发布公告](https://x.ai/news/grok-4-5)。
