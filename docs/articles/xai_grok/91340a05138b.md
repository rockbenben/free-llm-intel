# Grok on Amazon Bedrock

Grok 模型现已通过 Amazon Bedrock 提供。

今天，我们兴奋地宣布 Grok 4.3 在 Amazon Bedrock 上正式全面可用（generally available）。

Grok 4.3 实现了前沿模型中最低的幻觉率，提供 100 万 tokens 上下文窗口，并支持可配置的推理强度（none、low、medium、high）。现在，Amazon Bedrock 用户可以通过 Bedrock 安全可靠的推理引擎使用这一模型。

## [企业场景的领先性能](https://x.ai/news/grok-amazon-bedrock#leading-performance-in-enterprise)

Grok 4.3 是当前构建企业级 AI 智能体最强的模型之一：

- 在 Artificial Analysis Omniscience 基准*上排名第一*，在前沿模型中实现最低幻觉率。
- 在 Artificial Analysis Tau2 Telecom 基准*上排名第一*，该基准评估客户支持智能体场景中的真实工具调用性能。
- 在 Vals AI Case Law 与 Corporate Finance 基准上排名第一，这些基准衡量 Grok 在复杂文档理解任务上的能力。

\* 与主要前沿实验室比较

## [能力与定价](https://x.ai/news/grok-amazon-bedrock#capabilities--pricing)

Grok 4.3 位于"智能 vs 成本"的帕累托前沿，每一美元带来的智能是其他前沿模型的 2-10 倍。

- **输入**：每 100 万 tokens $1.25
- **输出**：每 100 万 tokens $2.50

它拥有 100 万 tokens 上下文窗口，可以轻松处理超长文档和代码库。开发者还可以配置推理：简单请求用 `none` 追求最高速度，或用 `low` / `medium` / `high` 让推理强度随问题难度伸缩。

## [在 Amazon Bedrock 上用 Grok 4.3 构建](https://x.ai/news/grok-amazon-bedrock#build-with-grok-43-on-amazon-bedrock)

Grok 4.3 现已向[受支持 AWS 区域](https://docs.aws.amazon.com/bedrock/latest/userguide/model-card-xai-grok-4-3.html#model-card-xai-grok-4-3-programmatic-access)的所有开发者开放。

```
curl https://bedrock-mantle.us-west-2.api.aws/openai/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $BEDROCK_API_KEY" \
  -d '{
    "model": "grok-4.3",
    "input": "What is the meaning of life?",
    "reasoning": {
        "effort": "low"
    },
    "include": ["reasoning.encrypted_content"]
  }'
```
