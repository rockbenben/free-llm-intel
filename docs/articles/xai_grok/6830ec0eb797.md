# 介绍 /goal

在 Grok Build 中用 /goal 进行长时间运行的自主任务执行。

今天我们在 Grok Build 中引入 `/goal`。这一新模式带来长时、自主的执行，帮你把更大的实现任务移交给智能体。

现已在 Grok Build 中提供。用一条命令安装并登录你的账户：

### 安装 Grok Build

Upgrade

Introducing /goal

多数编码会话需要来回的执行与验证。有了 `/goal`，智能体会持续推进直到任务完成并通过验证——无论那意味着审阅代码、检查网页还是执行脚本。

## [一行设定目标](https://x.ai/news/introducing-goal#set-a-goal-in-one-line)

给 `/goal` 一个目标，剩下的交给 Grok Build：

```
/goal Migrate the auth module to the new API
```

bash

它会规划方案、把工作拆成进度清单，然后开始执行。工作期间你可以继续给智能体补充指令。

新模式还提供用于监控和引导长时任务的额外命令：

```
/goal status     # see the live progress panel
/goal pause      # stop work, keep the goal
/goal resume     # pick back up
/goal clear      # drop the goal entirely
```

bash

目标完成时，面板翻转为 **Complete**，清单上的每一项都已打勾。

## [开始使用](https://x.ai/news/introducing-goal#getting-started)

用上面的命令安装 Grok Build，然后调用 `/goal`，移交你的第一个长时任务。
