# Grok Collections API

直接内建于我们 API 的 state-of-the-art RAG 系统。

今天，我们兴奋地宣布 Collections API。有了 Collections，你可以上传并检索整个数据集。从 PDF、Excel 表格到整个代码库，你都可以把文件上传到一个支持精准快速搜索的知识库。这让开发者能够构建 RAG 应用，而不必头疼于管理索引与检索基础设施。

为帮助你上手，第一周文件索引与存储免费*，检索按每 1,000 次搜索 $2.50 的固定价格计费。

## [索引](https://x.ai/news/grok-collections-api#indexing)

- **强大的文档理解**：我们使用 OCR 与版式感知解析来提取文本，同时保留结构——如 PDF 的版面、Excel 表格的层级、代码的语法。
- **智能文件管理**：轻松上传、更新和下载文件。当文件变化时，我们的系统会高效地重新索引，确保你的 collection 永不陈旧。
- **广泛格式支持**：Collections 支持大量文件类型。[(查看完整列表)](https://docs.x.ai/developers/files/collections#supported-mime-types)

## [检索](https://x.ai/news/grok-collections-api#retrieval)

选择最适合你用例的检索方式：

- **语义搜索**：按查询的含义与意图进行搜索。
- **关键词搜索**：精确词条匹配。
- **混合搜索**：结合关键词与语义搜索，获得最高准确率。我们同时支持专用 reranker 模型和 reciprocal rank fusion。

### [创建与搜索 Collections](https://x.ai/news/grok-collections-api#creating-and-searching-collections)

```
from xai_sdk import Client

client = Client()
collection = client.collections.create(
    name="Research Papers",
    model_name="grok-embedding-small"
)

document = client.collections.upload_document(
    collection.collection_id,
    name="ml-fundamentals.txt",
    data=b"...",
)

results = client.collections.search(
    query="What is machine learning?",
    collection_ids=[collection.collection_id],
    retrieval_mode="hybrid",
)
```

### [在聊天中使用 Collections](https://x.ai/news/grok-collections-api#using-collections-in-chat)

```
from xai_sdk import Client
from xai_sdk.chat import user, system
from xai_sdk.tools import collections_search

client = Client()
chat = client.chat.create(
    model="grok-4-1-fast",
    messages=[
        system("You are a personal tutor teaching the Fundamentals of AI and ML, check our notes."),
        user("Explain to me the core concepts."),
    ],
    tools=[
        collections_search(
            collection_ids=["collection_27ce08b9-87fd-4d1a-a9e7-8a199107e54f"],
            retrieval_mode="hybrid",
        ),
    ],
)
```

        "source": {

                "collection_27ce08b9-87fd-4d1a-a9e7-8a199107e54f"
            ]
        },
        "retrieval_mode": { "type": "hybrid" }
    }'
