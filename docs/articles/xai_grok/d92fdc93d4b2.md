# Grok 图像生成发布

我们用一款全新的自回归图像生成模型（代号 Aurora）升级 Grok 的能力，现已在 𝕏 平台提供。

A newer model is available

### Grok Imagine API is here

Our most powerful generative model yet — state-of-the-art video generation, video editing, and image creation, all in one API.

See what's new

我们用代号 Aurora 的新模型增强了 Grok 的图像生成能力。Aurora 是一个自回归专家混合（mixture-of-experts）网络，通过在文本与图像交错的语料上预测下一个 token 训练而成。我们在来自互联网的数十亿样本上训练了这个模型，赋予它对世界的深刻理解。因此，它在照片级真实渲染和精确遵循文本指令方面表现出色。除文本外，该模型还原生支持多模态输入，可以从用户提供的图像中汲取灵感，或直接编辑这些图像。

Grok 的新能力现已在 𝕏 平台的部分国家可用，并将在一周内向所有用户推送。
