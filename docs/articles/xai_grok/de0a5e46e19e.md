# 使用 Grok Bot 为每个团队配备一名数据科学家

作者：莎莉·徐

Data Bot 是数据科学团队教授的 Grok Bot 中的团队机器人，因此每个团队都可以像数据科学家那样查询仓库、运行分析并获得答案。

在 SpaceXSI，我们的数据科学团队在整个公司范围内工作，帮助团队回答难题并寻找将数据整合到我们产品中的新方法。随着时间的推移，我们对数据形成了一种直觉，包括如何解释它以及它的局限性。

但我们的小团队无法回答快速发展的公司中出现的所有问题。人们全天都向我们提出问题，这些问题可能很简单，但仍然需要我们的专业知识才能准确回答。这很容易使我们成为瓶颈。

几个月前，我们开始探索人工智能代理如何改变这种关系。我们希望为每个人提供一名全天候的数据科学家，他可以利用我们的集体知识，同时将我们自己的更多工作转移到构建和改进人工智能队友上。

我们在 Grok Bot 中构建了 Data Bot，这是一个团队机器人，我们已经教授了我们的数据科学团队如何工作。它可以查询我们的仓库，进行分析，并以每个人喜欢的形式返回结果。与个人机器人不同，个人机器人依赖于主人所知道的知识来教它们，数据机器人利用了我们的数据团队为每个人维护和改进的一组共享技能。

团队还可以将数据机器人添加到他们的 Slack 渠道中，它可以回答问题并主动为正在进行的工作做出贡献。随着我们提高技能，每个人都会从不断增长的专业知识中受益。

## [教授数据机器人数据团队如何工作](https://x.ai/news/data-bot#teaching-data-bot-how-the-data-team-works)

数据机器人需要足够的上下文才能像我们团队那样处理问题。我们通过技能为其提供背景信息，涵盖以下主要领域：

- **指标和分析。** 我们定义整个业务的核心指标，例如活跃用户和收入，并确定其背后的源表和查询逻辑。这些技能还指导数据机器人调查这些指标的变化，从按段或区域分解峰值或下降，到检查假期或记录变化，然后再将其归因于产品变化。
- **实验。** 这些内容涵盖了我们如何设置 A/B 测试、运行功效分析、检查曝光平衡和样本偏差、计划推出、深入研究不直观的结果以及在实验达到功效后写入读数。
- **图表和仪表板。** 我们为 Data Bot 配备了数据可视化最佳实践，例如使用折线图显示一段时间内的趋势，使用水平条来比较类别，以及我们团队的图表主题和风格指南。其他技能指导 Data Bot 创建仪表板，因此它可以将聊天中的图表转换为整个团队都可以使用的 Databricks 或 Hex 仪表板。
- **数据工程。** 这些涵盖了我们编写和审查 dbt 模型的最佳实践、我们的自动化管道警报约定，以及如何添加分析事件日志记录，以便我们可以衡量人们从新功能发布那一刻起如何使用它们。

## [数据机器人从经验中学习](https://x.ai/news/data-bot#data-bot-learns-from-experience)

我们还为数据机器人提供共享内存，以便它可以保留日常使用中产生的知识。例如，它可能会了解到哪个队友拥有特定的管道，或者之前某个重要指标的下降结果是地区性假期。下次调查类似的更改时，它可以借鉴该经验并检查假期日历，然后将下降归因于产品更改。

作为团队机器人的管理者，我们可以在数据机器人与每个使用它的人共享这些知识之前审查这些建议添加到其内存中的内容并批准或拒绝它们。

## [帮助产品经理更好地了解他们的产品](https://x.ai/news/data-bot#helping-pms-better-understand-their-products)

产品经理不断地询问人们如何使用他们的产品，其中许多问题超出了他们现有的仪表板所能告诉他们的范围。传统上，回答这些问题意味着自己深入研究数据或向数据团队中的人员寻求帮助。

数据机器人为产品经理提供了一种在出现问题时探索这些问题的方法。

SpaceXSI 的产品经理 Kevin Niparko 可以像对待队友一样在 Grok Bot 中发送消息，在几分钟内得到答案，并进行跟进，而无需开始新的分析。他将这种经历描述为口袋里有一位数据科学家。

![Kevin Niparko 询问 Grok Bot 中的数据机器人人们如何使用产品，答案显示为标题和图表](https://media.x.ai/cdn-cgi/image/fit=scale-down,onerror=redirect,f=auto/v1/website/message-1_v4-2757a6b6.png)

询问的便捷性意味着产品经理可以全天调查更多问题。以前，即使打开仪表板或在 Cursor 中开始分析也会产生足够的摩擦来阻止某些问题。现在，凯文可以探索他原本可能放弃的事物，而无需向数据科学家寻求帮助。

数据机器人还适应人们喜欢消费信息的方式。 Kevin 喜欢简洁的标题和图表，因此 Data Bot 以这种格式呈现其发现，让他快速从问题转向他可以使用的答案。

## [帮助营销人员了解他们的营销活动取得的成果](https://x.ai/news/data-bot#helping-marketers-understand-what-their-campaigns-accomplish)

营销团队需要了解客户在收到营销活动后会做什么。电子邮件平台会跟踪打开次数和点击次数，但这些指标并不总是显示活动是否实现了目标。

Jon Brenner 在 SpaceXSI 从事生命周期营销工作，他使用 Data Bot 作为值班分析师。他可以给它一个 Braze 活动 ID，并询问接收者随后做了什么。数据机器人会查询仓库，看看点击的人是否继续使用该功能。

![Jon Brenner 询问 Slack 中的数据机器人 Braze 活动的接收者点击后做了什么](https://media.x.ai/cdn-cgi/image/fit=scale-down,onerror=redirect,f=auto/v1/website/slack-2_v3-26d03ac8.png)

对于我们最近发布的 X 订阅，Jon 想知道有多少电子邮件收件人实际上改变了计划。 Braze 的内置转换指标无法回答这个问题，因此 Data Bot 查询仓库以跟踪有多少收件人收到了电子邮件以及有多少收件人继续转换计划。

我们的收入增长总监 Katy Abbaszadeh 使用 Data Bot 来衡量事件对销售的影响。她跟踪事件如何促进管道生成并帮助加速现有交易。她还使用数据机器人来监控每周的目标进度，调查可能减缓进度的因素，并将结果转化为图表进行演示。

借助 Data Bot，我们的营销团队现在可以回答更多自己的问题，而无需等待数据团队，同时仍然可以利用团队的专业知识。

![Katy Abbaszadeh 使用 Slack 中的数据机器人来衡量事件如何影响管道并绘制每周进度图表](https://media.x.ai/cdn-cgi/image/fit=scale-down,onerror=redirect,f=auto/v1/website/slack-1_v3-0e82404f.png)

## [让数据机器人处理整个分析工作流程](https://x.ai/news/data-bot#letting-data-bot-handle-entire-analytics-workflows)

数据机器人可以承担的工作远远超出了回答个人问题的范围。数据团队为其提供了进行更实质性分析的工具，包括通常需要与数据科学家进行多轮合作的项目。

例如，调查产品采用变化的产品经理可以要求数据机器人弄清楚发生了什么。数据机器人可以规划分析、查询仓库并探索可能的解释。然后，它可以生成带有图表的书面报告或以十六进制构建一个可供团队继续使用的仪表板。

![数据机器人在 Grok Bot 中进行产品采用分析，并返回带有图表的书面报告](https://media.x.ai/cdn-cgi/image/fit=scale-down,onerror=redirect,f=auto/v1/website/message-2_v5-0f61ccb4.png)

## [数据机器人加入团队频道并主动贡献](https://x.ai/news/data-bot#data-bot-joins-team-channels-and-contributes-proactively)

团队可以将数据机器人添加到他们的 Slack 渠道中，并赋予其持续报告的责任。例如，团队可以要求它跟踪重要指标并每周发布更新，遵循我们的数据科学团队建立的报告惯例。

数据机器人可以按计划运行该工作流程，并直接向群组对话提供更新。然后，同事可以提出后续问题或让它调查意外的变化，就像他们与其他队友一样。

## [面向所有人的数据科学专业知识](https://x.ai/news/data-bot#data-science-expertise-for-all)

SpaceXSI 内部数据机器人的采用正在迅速增长。仅上周，我们估计它就处理了大约 70 个小时的工作，否则这些工作将由数据科学团队承担。

我们仍然处理需要更多判断的复杂分析，并且我们正在了解数据机器人在哪里需要额外的指导。我们的目标是为全公司的同事提供一位人工智能队友，他们可以在需要时利用我们的专业知识，同时让数据科学团队有更多时间专注于需要我们直接关注的问题。
