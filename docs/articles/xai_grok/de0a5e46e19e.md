# 用 Grok Bot 给每个团队配一位数据科学家

作者：Sally Xu

Data Bot 是 Grok Bot 里的一个 Team Bot，由数据科学团队亲自调教，好让每个团队都能像数据科学家那样查询数据仓库、跑分析并拿到答案。

在 SpaceXSI，我们的数据科学团队服务于全公司，帮助各个团队回答难题，也在寻找把数据融入我们产品的新方式。日积月累，我们对自家的数据形成了一种直觉，知道该怎么解读它、它的局限又落在哪里。

但我们这支小团队不可能回答一家快速成长的公司里冒出的每一个问题。一整天都有人来问问题，这些问题听上去也许并不复杂，可要答准仍然需要我们的专业能力。这很容易就让我们变成瓶颈。

几个月前，我们开始探索 AI agent 能怎样改变这种关系。我们想给每个人配一位全天候可用的数据科学家，它能调用我们共同积累的知识；与此同时，让我们自己更多的工作转向打造和改进这位 AI 队友。

我们做出了 Data Bot——Grok Bot 里的一个 Team Bot，我们教会了它数据科学团队的工作方式。它能查询我们的数据仓库、开展分析，并以每个人偏好的形式返回结果。personal bot 只能靠它主人知道的东西来教，Data Bot 不一样，它依靠的是一整套共享的 skills，由我们的数据团队为所有人共同维护和打磨。

团队还可以把 Data Bot 加进自己的 Slack 频道，它在那里回答问题，也主动参与正在进行的工作。我们每改进它的一分 skills，所有人就都能从同一份不断增长的专门知识里受益。

## [教会 Data Bot 数据团队的工作方式](https://x.ai/news/data-bot#teaching-data-bot-how-the-data-team-works)

Data Bot 需要足够的上下文，才能像我们团队那样去处理一个问题。我们通过 skills 把这些上下文给它，覆盖以下几个主要方面：

- **指标与分析。** 我们定义了业务各处使用的核心指标，例如活跃用户和营收，并找出它们背后的源表和查询逻辑。这些 skills 还会指导 Data Bot 去调查这些指标的变动：既可以把一次尖峰或下跌按用户分群或地区拆开来看，也可以在把它归结为某次产品改动之前，先检查节假日或埋点日志的变化。
- **实验。** 这部分覆盖我们如何搭建 A/B test、做功效分析、检查曝光均衡与样本偏差、规划放量、深挖那些不符合直觉的结果，以及在实验达到所需功效之后撰写结论报告。
- **图表与仪表盘。** 我们给 Data Bot 配上数据可视化的最佳实践，比如用折线图看随时间变化的趋势、用横向条形图比较类别，还有我们团队的图表主题和风格指南。另有 skills 指导 Data Bot 创建仪表盘，让它能把聊天里的一张图表变成人人可用的 Databricks 或 Hex 仪表盘。
- **数据工程。** 这部分覆盖我们编写和评审 dbt model 的最佳实践、我们对自动化 pipeline 告警的约定，以及如何添加分析事件埋点，好在新功能上线的那一刻起就能衡量人们怎么使用它。

## [Data Bot 从经验中学习](https://x.ai/news/data-bot#data-bot-learns-from-experience)

我们还给 Data Bot 配了共享 memory，让它把日常使用中沉淀出来的知识留住。举例来说，它可能记住了某位同事负责哪一条 pipeline，或者上一次某个重要指标下跌其实只是一个地区的节假日。下次再调查类似的变动时，它就能用上这段经验，在把下跌归结为产品改动之前先去查一查节假日日历。

作为这个 Team Bot 的管理者，我们可以审阅这些它提议写入 memory 的新增内容，在 Data Bot 把这份知识分享给所有使用它的人之前，决定批准还是驳回。

## [帮助 PM 更好地理解自己的产品](https://x.ai/news/data-bot#helping-pms-better-understand-their-products)

产品经理会源源不断地冒出关于「人们到底怎么用我的产品」的问题，其中很多超出了他们现有仪表盘能够告诉他们的范围。过去要回答这些问题，只能自己扎进数据里刨，或者请数据团队的同事帮忙。

Data Bot 让 PM 能在这些问题出现的那一刻就去探索它们。

Kevin Niparko 是 SpaceXSI 的一位 PM，他在 Grok Bot 里给 Data Bot 发消息，就像给一位同事发消息那样，几分钟内拿到答案，还能接着追问，而不必重开一次分析。他把这种体验形容为口袋里装了一位数据科学家。

![Kevin Niparko 在 Grok Bot 里问 Data Bot 人们如何使用某个产品，答案以一句结论配一张图表的形式呈现](https://media.x.ai/cdn-cgi/image/fit=scale-down,onerror=redirect,f=auto/v1/website/message-1_v4-2757a6b6.png)

问起来如此轻松，意味着 PM 一天里可以去调查的问题多了很多。以前光是打开一个仪表盘、或者在 Cursor 里起一次分析，那点摩擦就足以让一些疑问被放弃。现在 Kevin 可以去探索那些他本来会放下的事情，不必再向数据科学家求助。

Data Bot 还会适应人们偏好的信息消费方式。Kevin 喜欢一句简洁的结论配上一张图表，Data Bot 就按那种格式呈现它的发现，让他能快速地从一个问题走到一个可以直接用的答案。

## [帮助市场团队看清自己的活动做成了什么](https://x.ai/news/data-bot#helping-marketers-understand-what-their-campaigns-accomplish)

市场团队需要了解客户在收到一次营销活动之后做了什么。邮件平台会统计打开和点击，但这些指标并不总能说明活动是否达成了它的目标。

Jon Brenner 在 SpaceXSI 做生命周期营销，他把 Data Bot 当成一位随叫随到的分析师。他可以直接给它一个 Braze 活动 ID，问收件人后来做了什么。Data Bot 会查询数据仓库，看那些点击了的人是否接着用起了相应的功能。

![Jon Brenner 在 Slack 里问 Data Bot：一个 Braze 活动的收件人在点击之后做了什么](https://media.x.ai/cdn-cgi/image/fit=scale-down,onerror=redirect,f=auto/v1/website/slack-2_v3-26d03ac8.png)

在我们最近[发布 The X Subscription](https://x.ai/news/x-subscription)时，Jon 想知道究竟有多少邮件收件人真的转换了套餐。Braze 内置的转化指标答不了这个问题，于是 Data Bot 去查询数据仓库，追踪有多少收件人收到了这封邮件、又有多少人随后转换了套餐。

Katy Abbaszadeh 是我们的营收增长总监，她用 Data Bot 衡量各类活动对销售的影响。她会跟踪活动贡献了多少 pipeline 生成、有没有帮助加速已有的交易。她还用 Data Bot 监控每周相对目标的进度、调查可能拖慢进度的原因，并把结果做成汇报用的图表。

有了 Data Bot，我们的市场团队现在能自己回答更多的问题，不必等数据团队，同时依旧用得上这个团队的专业能力。

![Katy Abbaszadeh 在 Slack 里用 Data Bot 衡量一场活动对 pipeline 的影响，并把每周进度画成图表](https://media.x.ai/cdn-cgi/image/fit=scale-down,onerror=redirect,f=auto/v1/website/slack-1_v3-0e82404f.png)

## [让 Data Bot 接手整条分析工作流](https://x.ai/news/data-bot#letting-data-bot-handle-entire-analytics-workflows)

Data Bot 能接下的工作远不止回答一个个问题。数据团队给了它做更扎实分析的工具，包括那些通常要和数据科学家来回协作好几轮才能完成的项目。

举例来说，一位正在调查产品采用度变化的 PM，可以让 Data Bot 去弄明白发生了什么。Data Bot 能规划这次分析、查询数据仓库、探索各种可能的解释，然后产出一份带图表的成文报告，或者在 Hex 里搭一个团队可以持续使用的仪表盘。

![Data Bot 在 Grok Bot 里逐步完成一份产品采用度分析，并返回一份带图表的成文报告](https://media.x.ai/cdn-cgi/image/fit=scale-down,onerror=redirect,f=auto/v1/website/message-2_v5-0f61ccb4.png)

## [Data Bot 加入团队频道并主动贡献](https://x.ai/news/data-bot#data-bot-joins-team-channels-and-contributes-proactively)

团队可以把 Data Bot 加进自己的 Slack 频道，把持续汇报这件事交给它负责。比如，团队可以让它跟踪一个关键指标并按周发布更新，遵循我们数据科学团队定下的汇报规范。

Data Bot 能按计划定时跑完这条工作流，把更新直接发到群组的讨论里。同事们随后可以在下面追问，也可以让它去调查一个出乎意料的变动，就像对待另一位队友那样。

Data Bot 在 SpaceXSI 内部的采用增长得很快。仅上周，我们估计它接下了大约 70 小时原本会落到数据科学团队头上的工作。

我们仍然在处理那些需要更多判断的复杂分析，也还在学习 Data Bot 在哪些地方需要额外的指引。我们的目标是给全公司的同事一位 AI 队友，让他们随时都能调用我们的专业能力，同时给数据科学团队留出更多时间，专注在那些需要我们亲自过问的问题上。
