# 发布 Grok-1.5

Grok-1.5 带来更强的推理能力，上下文长度为 128,000 tokens。即将登陆 𝕏。

**介绍 Grok-1.5——我们最新的模型，具备长上下文理解与高级推理能力。未来几天内，𝕏 平台上的早期测试者和现有 Grok 用户即可使用 Grok-1.5。**

两周前，我们发布了 Grok-1 的模型权重与网络架构，让大家一窥 xAI 截至去年 11 月所取得的进展。此后，我们在最新模型 Grok-1.5 中进一步提升了推理与问题求解能力。

## [能力与推理](https://x.ai/news/grok-1.5#capabilities-and-reasoning)

Grok-1.5 最显著的改进之一，是其在编码和数学相关任务上的表现。在我们的测试中，Grok-1.5 在 MATH 基准上取得 50.6%，在 GSM8K 基准上取得 90%——这两个数学基准覆盖了从小学到高竞赛难度的广泛题目。此外，它在评估代码生成与问题求解能力的 HumanEval 基准上取得 74.1%。

## [长上下文理解](https://x.ai/news/grok-1.5#long-context-understanding)

Grok-1.5 的新特性是能够在上下文窗口内处理长达 128K tokens 的长上下文。这让 Grok 的记忆容量提升至此前上下文长度的最多 16 倍，使其能够利用显著更长的文档中的信息。

此外，模型能够处理更长、更复杂的提示，同时在上下文窗口扩展时依然保持指令跟随能力。在 Needle In A Haystack（NIAH）评估中，Grok-1.5 展示了在最长 128K tokens 上下文中检索嵌入文本的强大能力，取得了满分的检索结果。

## [Grok-1.5 的基础设施](https://x.ai/news/grok-1.5#grok-15-infra)

在大规模 GPU 集群上运行的前沿大语言模型（LLM）研究，需要强健而灵活的基础设施。Grok-1.5 构建于基于 JAX、Rust 和 Kubernetes 的定制分布式训练框架之上。这套训练栈让团队能以最少的心力验证想法并大规模训练新架构。在大型算力集群上训练 LLM 的一大挑战，是最大化训练任务的可靠性与在线率。我们的定制训练调度器确保问题节点被自动检测并从训练任务中剔除。我们还优化了 checkpoint、数据加载和训练任务重启，以在故障发生时把停机时间降到最低。如果你对参与我们的训练栈感兴趣，请[申请加入团队](https://x.ai/careers)。

## [展望未来](https://x.ai/news/grok-1.5#looking-ahead)

Grok-1.5 很快将开放给早期测试者，我们期待收到你的反馈以帮助改进 Grok。随着我们逐步把 Grok-1.5 推广到更广泛的用户，我们还会在未来几天内推出若干新功能。

*注意：GPT-4 的分数取自 2023 年 3 月发布的版本。MATH 与 GSM8K 给出的是 maj@1 结果；HumanEval 报告的是 pass@1 基准分数。*
