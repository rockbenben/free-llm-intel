# 网页、iOS 与 Android 上的 Connectors

深度集成，把你每天使用的应用直接带进 Grok。

Try Connectors

**今天，我们兴奋地推出 Connectors（连接器）**——把你的日常应用直接接入 Grok 的深度集成。Connectors 让 Grok 与你的工具端到端协作，把碎片化的工作流变成无缝的体验。阅读并总结邮件、更新幻灯片、整理日历、编辑电子表格，以及更多——全程不必反复复制粘贴。

## [在 Grok 网页、iOS 和 Android 上可用](https://x.ai/news/grok-connectors#available-on-grok-web-ios-and-android)

Connectors 现已在 **Grok 网页、iOS 和 Android** 上线。

- **网页**：登录，点击 **+** 按钮，选择 **Connectors**，点击 **+ Add connector** 开始。[立即体验](https://grok.com/connectors)。
- **iOS 和 Android**：进入 **设置 → Connectors**，连接你想与 Grok 一起使用的服务。

Your browser does not support the video tag.

## [以下 Connectors 现已可用](https://x.ai/news/grok-connectors#the-following-connectors-are-now-available)

- **SharePoint**：Grok 可以搜索、阅读并综合你组织内最新的文件、列表和页面。开启写权限后，Grok 还能创建、编辑和更新文档、列表与页面。高级文档编辑能力由 Grok 4.3 提供。
- **Outlook**：带着完整上下文搜索你的收件箱、日历和会议。Grok 可以起草并发送邮件、创建日历邀请，或帮你分拣和排定收件箱优先级。
- **OneDrive**：即时访问你的所有个人与共享文件。让 Grok 分析电子表格、演示文稿、报告等——无需离开对话。
- **Google Workspace**：一次集成即可连接 Gmail、Drive、Docs、Sheets 和 Calendar。Grok 可以读写邮件、文档、电子表格和日程事件。
- **Notion**：直接在你的 Notion 工作区里工作。搜索或编辑页面、数据库和 wiki——覆盖你与团队的全部文档。
- **GitHub**：连接你的仓库、issue 和 pull request。Grok 可以搜索代码、总结 PR、审阅改动，帮你掌控开发工作流。
- **Linear**：连接你的 Linear 工作区，把任务、issue、路线图和项目直接带进 Grok。Grok 可以搜索你的 backlog、总结 sprint 进展、起草更新、创建新 issue。

除以上全部连接器外，我们还推出 **自带 MCP（Bring Your Own MCP）**：把任何自定义 Model Context Protocol 服务器接入 Grok。无论你的团队用什么——自研知识库、专有 API，还是内部 MCP 网关——Grok 都能直接插入你自己的工具与工作流。

有关 Connectors 的文档请访问 [https://docs.x.ai/grok/connectors](https://docs.x.ai/grok/connectors)
