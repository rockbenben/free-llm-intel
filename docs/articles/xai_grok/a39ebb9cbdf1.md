# Grok Bot 现已打通 X

Grok Bot 与 X 的集成现在更加紧密了。

Download for macOS


在 Grok Bot 中连接你的 X 账户；如果你还没有开发者账户，我们会为你创建一个。付费 Grok Bot 用户可免费获得起始的 X API 额度。

开始使用：打开 Grok Bot，用 X 连接器登录。

然后让某个 Bot 搜索帖子、阅读你的时间线、查看 mentions（提及），或汇总 X 上正在发生的事。这是该集成的第一个版本，我们很期待继续让 Grok Bot 更容易在 X 上做真正的工作。

这里还有一个 [X 插件](https://x.ai/bot/plugin/49086599)，可搜索帖子、读取时间线、获取趋势并管理书签。
