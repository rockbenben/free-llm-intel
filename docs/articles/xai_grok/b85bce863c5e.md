# Grok Voice Agent API

把 Grok Voice 的力量带给所有开发者。

今天，我们很高兴推出 Grok Voice Agent API，让开发者能够构建能说数十种语言、调用工具、检索实时数据的语音智能体。

Grok Voice Agent API 构建在为数百万用户提供手机应用中 Grok Voice 与 Tesla 车辆动力的同一套技术栈上，我们非常高兴通过 xAI API 把这项久经考验的技术向所有人开放。

## [聪明而快速](https://x.ai/news/grok-voice-agent-api#smart-and-fast)

Grok Voice Agents 是市场上最快、最智能的语音智能体。

我们自研了整条语音技术栈，从零训练了自己的语音活动检测（VAD）、tokenizer 和音频模型。对栈中每个组件的精细掌控，让我们能快速迭代，持续提升 Grok 的智能与速度。

Grok Voice Agent API 在 [Big Bench Audio](https://artificialanalysis.ai/models/speech-to-speech) 上排名第一——这是衡量语音智能体解决复杂问题能力的领先音频推理基准。平均首个音频输出时间不到 1 秒，Grok 比最接近的竞争者快近 5 倍。

## [多语言流利度](https://x.ai/news/grok-voice-agent-api#multilingual-fluency)

Grok Voice Agents 能以母语级水平说数十种语言，准确捕捉方言与发音的细微之处。Grok Voice Agents 经过训练，会自动用用户所说的语言回应，并能在对话中无缝切换语言。开发者也可以通过系统提示词要求 Grok 始终以特定语言回答。

在与 OpenAI Realtime API 的盲测一对一人工评估中，Grok 在发音、口音、韵律等维度上持续被评为更受偏好的模型。

## [Tesla 中的 Grok Voice](https://x.ai/news/grok-voice-agent-api#grok-voice-in-tesla)

Tesla 是 Grok Voice Agent API 的关键设计伙伴，该 API 如今为数百万辆车中的 Grok 提供动力。

Grok 感觉就像你 Tesla 的自然延伸——专门的工具让它能访问车辆状态、查询路线、控制导航。Grok 会组合使用这些工具，提供无缝的路线规划体验。例如，让 Grok 规划一次公路旅行，它会搜索 X 上的推荐、计算最优路线、添加途经点，几秒钟生成完整行程。




Grok Voice Agents 能实时执行任务、查询信息。借助我们的 API，开发者可以轻松集成自己的自定义工具，或接入 xAI 强大的跨 X 与互联网的实时搜索能力。
