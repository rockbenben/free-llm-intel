# Grok Bot 现已纳入更多套餐

Grok Bot 现已面向 SuperGrok、Cursor Pro 以及所有 Cursor Teams 套餐提供。

Download for macOS


我们于 8 月 11 日以 beta 形式发布了 [Grok Bot](https://x.ai/news/introducing-grok-bot)，目标是给人们提供能力极强、能干真实工作、并且极易协作的 AI 队友。

此后，试用过 Grok Bot 的人惊讶于上手的容易程度，也惊讶于 Bots 比其他 AI 工具更"聪明"——不用你一步步牵着走，就能把活儿推进得更远。

今天，我们扩大 Grok Bot 的开放范围。Grok Bot 现已包含在所有 SuperGrok、Cursor Pro 和 Cursor Teams 套餐中。

随着这次扩展，Grok Bot 现已包含在：

- SuperGrok
- SuperGrok Plus
- SuperGrok Heavy
- Cursor Pro
- Cursor Pro+
- Cursor Ultra
- Cursor Teams 套餐（Standard 与 Premium）

Grok Bot 自带独立用量，与你的 Grok 和 Cursor 套餐分开，因此交给 Bots 的任何工作都不会占用你现有的用量。

## [把真实工作交给 Bots](https://x.ai/news/grok-bot-more-plans#give-bots-real-work)

Grok Bot 为那些希望智能体从单个项目一直管到整个职能部门的人而设计。他们是你可以发消息、并行运行、并放心托付的数字化队友——在你已有的工具里完成工作。Bots 跨应用、跨收件箱工作，你离开时他们继续干，只在需要拍板时才把你拉进来。

通过 Grok Bot，你可以获得：

- **文本对话式体验。** 像给团队同事发消息一样给 Bot 发消息，手机或桌面皆可，同一对话串两端随时接续——无需任何预先设置。
- **同时运行多个 Bots。** 立一个研究员、一个写手、一个幕僚长。把他们拉进群聊，让他们相互交接，你不用当中间人。
- **一位能力极强的数字同事。** 他们在云端有自己的电脑，永远在线，带浏览器和终端访问。他们登录你的应用，工作发生在真实工具里，而不是聊天草稿里。
- **轻松设置的例行任务。** 请 Bot 下次你跟做一遍，此后它就能独立运行。

## [Bots 今天就在做的工作](https://x.ai/news/grok-bot-more-plans#jobs-bots-are-doing-today)

- **销售拓客。** 调研并补全客户信息，撰写个性化外联草稿。每次发送都留在你的收件箱或 navigator 里等你批准。
- **建站。** 建网站、购买域名、部署最终版本。帮忙配置插件、交付可访问的线上 URL、添加重定向规则。
- **数字断舍离。** 全天候审计邮件、Drive 和付费订阅。只有你说可以，才丢弃或退订。
- **客户支持。** 阅读支持邮件并接入你的支付服务商。在你的政策范围内处理所有常规退款。
- **游戏美术。** 走进美术管线，按你的创意方向制作定制资产。带着游戏需要的东西回来。
- **运营管家。** 受理工单、规划产能，并在 Gmail、Slack、ServiceTitan、Quo 和客户门户之间排期派单。替你完成这些门户里的浏览器操作，让店主不必活在六个工具里。
- **邮箱管理员。** 逐封处理收件箱，清掉成堆邮件。只留下真正需要人处理的消息。
- **会议替身。** 你没空时替你进会、让会议室知道你到了。做详细笔记并发摘要，让你保持知情。
- **退款追讨员。** 找到理赔项、提交、跟进到底。带着追回来的退款或折扣回来。

下载 Grok Bot，创建你的第一个队友，把一件你自己在做的活儿交给它。当工作以"已完成"的形态回来时，你会看到有用的 AI 长什么样。
