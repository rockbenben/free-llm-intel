## 世界级的视频生成模型。突破性的视频编辑模型。

我们兴奋地揭晓 [Grok Imagine API](https://x.ai/api/imagine)——一整套为端到端创作流程设计的强力 API 组合。Grok Imagine 是我们迄今最强大的音视频生成模型。让一张图像活起来，从一条简单的文本提示出发，甚至精修一段复杂的电影级序列。

## [性能与基准](https://x.ai/news/grok-imagine-api#performance-and-benchmarks)

我们工程化这些模型的目标，是交付与当今顶级供应商比肩的高质量原生音视频生成，同时优化延迟、并发与成本——并经多轮密切伙伴反馈打磨。有一条信息始终如一：如果延迟和成本让迭代痛不欲生，光有质量是不够的。通过提升速度与经济性，我们让开发者、创作团队和企业工作流能够并行探索多个方向——以快速、高性价比的实验更快收敛。
