# 推出 Grok Voice 3.0

世界上最智能的语音模型。

[免费试用](https://console.x.ai/team/default/voice/agents?campaign=voice-3-blog&utm_source=website&utm_medium=referral&utm_campaign=voice-3-blog)[查看文档](https://docs.x.ai/developers/model-capabilities/audio/voice?campaign=voice-3-blog)

今天我们宣布 Grok Voice 3.0，世界上最智能的 speech-to-speech 模型。它在客服通话的问题解决上创下新纪录，延迟低于一秒、同类领先，并且比其他前沿模型更便宜。Grok Voice 每天在 Tesla 和 SpaceX 支撑数百万次对话，现已在 API 上可用，价格与前一代相同。

## [最准确的语音模型](https://x.ai/news/grok-voice-3#the-most-accurate-voice-model)

在 Artificial Analysis 的独立测试中，Grok Voice 3.0 在 Speech-to-Speech Index 上排名第一，得分 86.9。该 Index 综合了语音推理、τ-Voice，以及来自盲测一对一通话的偏好与任务成功率。Grok Voice 3.0 在 Full Duplex Bench 上同样拿到 97%，这项指标衡量它处理停顿、轮流发言和打断时有多自然。

τ-Voice 衡量 agent 在面对各种口音、背景噪声和打断时，处理客服通话的水平有多好。Grok Voice 3.0 得分 71.6%，与 GPT-Live-1 (Astra) 相当，但延迟低 40%，在 agent 智能与响应速度之间立起了新的前沿。

在 [EVA-Bench](https://servicenow.github.io/eva)——ServiceNow 面向企业语音 agent 的基准——上，Grok Voice 3.0 取得了最高的准确率得分 74%，并且在准确率与客户体验联合评分时是表现最好的模型。

> “Grok Voice 3.0 在 EVA-Bench 上立起了新的 Pareto 前沿。EVA-Bench 是 ServiceNow 的开源基准，在 200 多个真实企业场景上为语音 agent 的准确率与体验打分。它把顶尖准确率与一段自然、有回应感的对话结合在一起，为「企业在客户服务第一线可以从 AI 期待什么」设立了新标准。”

Nitin Aggarwal，Senior Director of Product Management, Agentic Evals and RAI，ServiceNow

## [被 Tesla 与 SpaceX 的数百万客户使用](https://x.ai/news/grok-voice-3#used-by-millions-of-customers-at-tesla--spacex)

Grok Voice 3.0 每天在 Tesla 的车里处理数百万次对话。司机可以用 Connectors 处理简单的请求，比如查看日历或回复一封邮件，用 Grok Bot 处理更大的任务，比如点一杯咖啡或预订晚餐——全程完全免手操作（[在 X 上看演示](https://x.com/Tesla/status/2102430656349544590)）。Grok Voice 3.0 同时也为 Grok Bot 的语音模式提供动力。

Starlink 的客服中心用 Grok Voice 以多种语言每天接听 20,000 个客户电话。大约 70% 无需人工介入即可解决，四分之一个销售电话在来电者挂断之前就以成交告终。一个基于 Grok Voice 3.0 构建的 agent 就能完成客户身份核验、硬件故障排查、发放额度以及寄出替换设备。

## [定价与可用性](https://x.ai/news/grok-voice-3#pricing-and-availability)

Grok Voice 3.0 今天在 Voice Agent API 上可用，价格为 [$0.08 / 分钟（$4.80 / 小时）](https://docs.x.ai/developers/pricing?campaign=voice-3-blog#voice-api-pricing)，与 Grok Voice 2.0 同价。使用 `grok-voice-latest` 的 agent 已经自动切换过来，无需任何改动。
