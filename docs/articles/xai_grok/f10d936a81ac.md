# 把 Grok 接入 Hermes Agent

在你的 Grok 账户和订阅基础上，使用 Nous Research 开源、自我改进的 Hermes 智能体。

从今天起，你可以直接在 Hermes Agent 内使用你的 Grok 订阅。

Hermes Agent 是 Nous Research 的开源自改进智能体。它可以在任何电脑、沙箱或 VPS 上持续运行，跨会话建立长期记忆，随用随学。与其他开源个人智能体一样，Hermes 可以连接 WhatsApp、Discord、Telegram、Signal 或其他消息服务提供商。

在 Hermes 中使用你的 Grok 订阅，你可以用上：

- Grok 4.3：文本对话与高级推理
- Grok Text-to-Speech：语音回答
- Grok Imagine：让你的智能体创作图像与视频

把 Grok 连接到你的 Hermes 智能体在所有档位均可用。

## [设置](https://x.ai/news/grok-hermes#setup)

安装 Hermes Agent：

```
# Linux / macOS / WSL2 / Android (Termux)
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
```

bash

选择 Grok provider：

```
hermes model
```

bash

选择 **xAI Grok OAuth (SuperGrok Subscription)**，通过浏览器登录，然后开始聊天：

```
hermes --tui
```

bash

更多信息见 [Hermes Agent xAI Grok OAuth 文档](https://hermes-agent.nousresearch.com/docs/guides/xai-grok-oauth)。

更多开源智能体与集成即将到来。
