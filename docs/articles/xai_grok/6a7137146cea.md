# Grok for PowerPoint

Grok 现在可以在 Microsoft PowerPoint 内部工作——把提纲变成幻灯片、扩充演示文稿、打磨叙事——全程不离开应用。

Add to PowerPoint

Try Grok

**今天，我们把 Grok 带进 Microsoft PowerPoint。** 在 deck 旁边使用这个加载项，让 Grok 帮你调研、写作、打磨幻灯片。

Introducing Grok for PowerPoint

## [从提示词到 PPT](https://x.ai/news/introducing-powerpoint-addin#go-from-prompts-to-powerpoints)

把提纲分享给 Grok，生成完整的幻灯片——附带来自网页或 X 搜索的调研、图示，甚至有图片。或者与 Grok 协作添加单页幻灯片、应用样式与主题，或用一条指令重组章节。Grok 会回来向你提出澄清问题。

### [调研、写作与样式](https://x.ai/news/introducing-powerpoint-addin#research-writing-and-styling)

Grok 能帮你改进样式、收紧幻灯片叙事，甚至从网上搜索最新信息。加载项还能利用你的 [Grok 连接器](https://grok.com/connectors)——让它根据最近的邮件，或你 SharePoint、Google Drive 里的文件来写幻灯片。

## [开始使用](https://x.ai/news/introducing-powerpoint-addin#get-started)

Grok for PowerPoint 是免费的 Microsoft 365 加载项。[从 Microsoft Marketplace 添加](https://marketplace.microsoft.com/en-us/product/office/WA200011057?tab=Overview)，即可在你的演示文稿里直接与 Grok 协作。[Word](https://x.ai/grok/word) 和 [Excel](https://x.ai/grok/excel) 版本同样提供。
