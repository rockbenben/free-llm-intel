# Grok-2 Beta 发布

宣布我们的新模型 Grok-2 与 Grok-2 mini。

**我们很高兴发布 Grok-2 的早期预览版——相比上一代模型 Grok-1.5 的重大进步，在聊天、编码和推理方面具备前沿能力。同时，我们推出 Grok-2 mini，一个体量小而能力不俗的 Grok-2 兄弟模型。Grok-2 的早期版本曾以 "sus-column-r" 之名在 LMSYS 排行榜上接受测试。截至本篇博文发布时，它的表现已同时超过 Claude 3.5 Sonnet 与 GPT-4-Turbo。**

Grok-2 与 Grok-2 mini 目前正在 𝕏 上进行 beta 测试，我们也会在本月晚些时候通过企业 API 提供这两个模型。

## [Grok-2 语言模型与聊天能力](https://x.ai/news/grok-2#grok-2-language-model-and-chat-capabilities)

我们以 "sus-column-r" 之名将 Grok-2 的早期版本引入 [LMArena.ai](https://lmarena.ai) 的 Chatbot Arena——一个热门的竞争性语言模型基准。在 LMSYS 排行榜上，它的综合 Elo 分数超过 Claude 与 GPT-4。

在内部，我们采用类似的流程来评估模型。我们的 AI Tutors（人工智能导师）在反映真实世界 Grok 交互的各类任务中与模型互动。每次交互中，AI Tutors 会看到由 Grok 生成的两个回答，并按照我们指南中列出的标准选择更优的回答。我们聚焦于评估模型在两个关键领域的表现：遵循指令，以及提供准确、符合事实的信息。Grok-2 在结合检索内容进行推理以及工具使用能力方面表现出显著进步，例如正确识别缺失信息、对事件序列进行推理、剔除无关帖子。

## [基准测试](https://x.ai/news/grok-2#benchmarks)

## [在 𝕏 上用实时信息体验 Grok](https://x.ai/news/grok-2#experience-grok-with-real-time-information-on-𝕏)

过去几个月，我们一直在持续改进 𝕏 平台上的 Grok。今天，我们推出 Grok 体验的下一次进化，包括全新设计的界面和新功能。

𝕏 Premium 和 Premium+ 用户将可使用两个新模型：Grok-2 与 Grok-2 mini。Grok-2 是我们尖端的 AI 助手，在文本和视觉理解方面都有高级能力，集成来自 𝕏 平台的实时信息，可通过 𝕏 应用中的 Grok 标签访问。Grok-2 mini 是我们小而能干的模型，在速度与回答质量之间取得平衡。与前代相比，Grok-2 在寻找答案、协作写作或解决编码问题等各类任务中都更直观、更可控、更多才多艺。我们正在与 [Black Forest Labs](https://blackforestlabs.ai/) 合作，试验其 [FLUX.1](https://blackforestlabs.ai/#get-flux) 模型，以扩展 Grok 在 𝕏 上的能力。如果你是 Premium 或 Premium+ 订阅者，请确保更新到最新版 𝕏 应用，以便参与 Grok-2 的 beta 测试。

### [用企业 API 基于 Grok 构建](https://x.ai/news/grok-2#build-with-grok-using-the-enterprise-api)

我们还将在本月晚些时候通过全新的企业 API 平台向开发者发布 Grok-2 与 Grok-2 mini。我们的 API 建立在全新的定制技术栈之上，支持多区域推理部署，以实现全球范围的低延迟访问。我们提供更强的安全特性，如强制多因素认证（例如使用 Yubikey、Apple TouchID 或 TOTP）、丰富的流量统计，以及高级账单分析（含详细数据导出）。我们还提供管理 API，让你把团队、用户和账单管理集成到现有内部工具与服务中。[订阅我们的新闻通讯](https://x.ai/api)，在本月晚些时候上线时获取通知。
