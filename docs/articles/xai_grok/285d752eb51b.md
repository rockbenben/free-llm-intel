# 在 Warp 中使用 Grok

在你的 Grok 和 X Premium 订阅基础上使用 Warp。

你现在可以在 [Warp](https://www.warp.dev/) 内使用你的 Grok 或 X Premium 订阅——这是一个构建于终端之上的智能体开发环境，被近一百万开发者使用。

你现有的订阅即可访问 Grok 模型，包括为 [Grok Build](https://x.ai/build) 提供动力的 `grok-build-0.1`。

## [设置](https://x.ai/news/grok-warp#setup)

- 从 [warp.dev/download](https://www.warp.dev/download) 下载 Warp 并打开。
- 进入 "Agent > Warp Agent" 设置页，点击 "Connect SuperGrok subscription"
- 切换到 `grok-build-0.1` 模型，开始提问。

就这么简单！更多智能体与集成将很快面向 SuperGrok 和 X Premium 订阅用户到来。订阅请访问[定价页](https://x.ai/pricing)。
