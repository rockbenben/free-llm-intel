只需几行代码，开发者就能让 Grok 浏览网页、搜索 X 帖子、执行代码、检索已上传文档等等。

```
import os
from xai_sdk import Client
from xai_sdk.tools import code_execution, web_search, x_search, collections_search, mcp

client = Client(api_key=os.getenv("XAI_API_KEY"))
chat = client.chat.create(
    model="grok-4-1-fast-reasoning",
    tools=[
        web_search(),
        x_search(),
        code_execution(),
        collections_search(collection_ids=["..."]),
        mcp(server_url="..."),
    ],
)
```

这些工具完全运行在 xAI 的基础设施上，开发者不再需要管理 API key、速率限制、沙箱或检索管线。Grok 自行决定何时、如何使用它们，常常在多轮中并行调用多个工具，直到集齐给出最终答案所需的一切。

## [功能完备的工具集](https://x.ai/news/grok-4-1-fast#a-full-featured-toolset)

Agent Tools API 是一套多用途工具集，可以大幅扩展我们基础 Grok 模型的能力。核心特性包括：

### Search Tools

利用实时的 X 与互联网搜索，对当前事件与趋势快速形成全面洞察。

### Files Search

从你上传的文件中智能搜索并检索相关文档，附带引用来源。

### Code Execution

在安全沙箱中执行 Python 代码，分析数据、运行仿真。

### MCP Tools

与外部 MCP 服务器无缝连接，接入强大的自定义第三方工具。
