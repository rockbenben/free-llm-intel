# Grok 语音转文字与文字转语音 API

快速而准确。自然、富有表现力的声音。简单的定价。多语言支持。

Get Started

Try Playground

今天，我们宣布两个强大的独立音频 API：**Grok Speech to Text (STT)** 和 **Grok Text to Speech (TTS)**。它们构建在为 Grok Voice、Tesla 车辆和 Starlink 客户支持提供动力的同一套技术栈上。

这些独立端点让开发者可以轻松地把高质量语音能力集成进任何应用——无论你是在做语音智能体、实时转录工具、无障碍方案、播客还是交互式音频体验。

## [语音转文字](https://x.ai/news/grok-stt-and-tts-apis#speech-to-text)

高准确率，低延迟。

- 通过我们的 [REST API](https://docs.x.ai/developers/rest-api-reference/inference/voice#speech-to-text---rest) 在毫秒级从大型音频文件生成转录文本
- 用我们最低延迟的 [WebSocket API](https://docs.x.ai/developers/rest-api-reference/inference/voice#speech-to-text---streaming) 实时转录语音

我们加入了强大功能：词级时间戳、说话人分离（diarization）和多声道支持。还包括智能逆向文本规范化（Inverse Text Normalization），能正确处理数字、日期、货币等。

## [文字转语音](https://x.ai/news/grok-stt-and-tts-apis#text-to-speech)

快速、自然、富有表现力的声音，带 Speech Tags。

- 用我们的 [REST API](https://docs.x.ai/developers/model-capabilities/audio/text-to-speech#quick-start) 把长文本转成语音
- 用我们的 [WebSocket API](https://docs.x.ai/developers/model-capabilities/audio/text-to-speech#streaming-tts-websocket) 实时生成语音

### [精细化控制](https://x.ai/news/grok-stt-and-tts-apis#fine-grained-control)

用简单的内联与包裹式 speech tags 添加自然的韵律与情感：`[laugh]`、`[sigh]`、`[whisper]`、`<emphasis>`、`<slow>`、`<pause>`，以及更多。这些控制让你无需复杂标记，就能做出引人入胜、栩栩如生的演绎。
