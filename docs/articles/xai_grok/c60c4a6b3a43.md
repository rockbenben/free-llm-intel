# Grok Build 0.1 上线 API

Grok Build 0.1——我们最快的编码模型——现已通过 xAI API 公开测试。

Try it now

Create API key

我们的最新编码模型 `grok-build-0.1` 现已通过 xAI API 公开测试。

`grok-build-0.1` 是专为智能体编码任务训练的编码模型，包括 Web 开发、调试和 MCP 支持。它就是为 [Grok Build](https://docs.x.ai/build/overview#getting-started) 提供动力的同一个模型。

该模型以极速的 100+ tokens/秒提供服务，定价为每百万输入 tokens $1、每百万输出 tokens $2。在编码之外，它也是通用智能体与工具调用用例下一个快速、经济的选择。

```
curl https://api.x.ai/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $XAI_API_KEY" \
  -d '{
    "model": "grok-build-0.1",
    "input": [
        {
            "role": "user",
            "content": "Generate a clean, tasteful, and minimalist personal website design with elegant typography"
        }
    ]
}'
```

`grok-build-0.1` 在智能体 harness 中表现最佳，例如 [Grok Build](https://docs.x.ai/build/overview)、Cursor、[Hermes Agent](https://x.ai/news/grok-hermes)、[OpenClaw](https://x.ai/news/grok-openclaw)、[Kilo Code](https://x.ai/news/grok-kilocode) 或 [OpenCode](https://x.ai/news/grok-opencode)。它也可通过 [OpenRouter](https://openrouter.ai/x-ai/grok-build-0.1) 和 [Vercel AI Gateway](https://vercel.com/changelog/grok-build-0-1-now-available-on-vercel-ai-gateway) 使用。
