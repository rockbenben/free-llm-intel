# Amazon Bedrock 上的 Grok 4.6

Grok 4.6 现已通过 Amazon Bedrock 提供。

今天，我们兴奋地宣布 Grok 4.6 在 Amazon Bedrock 上正式全面可用（generally available）。

Grok 4.6 是我们最新的旗舰模型，为长时间运行的智能体以及更具雄心的交互式与视觉化工作而生。它提供 500k 上下文窗口和可配置的推理强度（low、medium、high、xhigh）。现在，Amazon Bedrock 用户可以通过 Amazon Bedrock 使用这一模型。

## [能力与定价](https://x.ai/news/grok-4-6-amazon-bedrock#capabilities--pricing)

Grok 4.6 的价格：

- **输入**：每 100 万 tokens $2
- **缓存输入**：每 100 万 tokens $0.50
- **输出**：每 100 万 tokens $6

有关模型的更多信息，请阅读 [Grok 4.6 发布公告](https://x.ai/news/grok-4-6)。
