# API 公开测试版

从今天起，开发者可以通过我们新发布的 API 基于 Grok 基础模型进行构建。我们将运行公测项目直到 2024 年底，期间每个人每月可获得 $25 的免费 API 额度。

我们很高兴地宣布 API 即刻可用，它为开发者提供了对我们 Grok 系列基础模型的编程访问。要开始使用，请前往 [console.x.ai](https://console.x.ai?utm_source=website&utm_medium=referral&utm_campaign=api-blog) 注册创建账户。我们非常期待看到开发者用 Grok 构建出什么。

## [模型](https://x.ai/news/api#models)

我们的公测以一款正处于开发最后阶段的 Grok 新模型的预览版开启。该模型以暂定名 grok-beta 发布，上下文长度为 128,000 tokens，并支持函数调用（function calling）和系统提示词（system prompts）。我们将很快发布关于该模型的更多信息。

除了纯文本版本的 grok-beta 模型外，我们还将发布一个能够摄取图像的多模态版本。视觉模型将于下周上线。

## [免费额度](https://x.ai/news/api#free-credits)

我们将在年底前整个时段运行公测项目。每个人每月可获得 $25 的免费 API 额度，用于测试 API 并开始使用 Grok。

此前购买过预充值额度的用户，到年底前的每个月都可获得等额的全新免费月度额度。例如，如果你已经购买了 $50 的预充值额度，那么你在 11 月和 12 月将拥有 $25 + $50 的额外免费额度。

## [API](https://x.ai/news/api#api)

要了解更多关于 API 的信息，请查阅我们在 [docs.x.ai](https://docs.x.ai) 的文档。我们的 REST API 与 OpenAI 和 Anthropic 提供的 API 完全兼容，这简化了迁移。例如，如果你当前使用 OpenAI Python SDK，只需将 `base_url` 改为 `https://api.x.ai/v1`，并使用你在 [console.x.ai](https://console.x.ai?utm_source=website&utm_medium=referral&utm_campaign=api-blog) 上创建的 xAI API key，就可以开始使用 Grok。
