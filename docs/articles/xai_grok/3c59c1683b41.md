# 带参考的 Imagine Video 1.5

我们最好的视频模型，现在支持文本、图像与语音参考——最高生成 1080p。

Open Grok.com

上个月我们发布 [Imagine Video 1.5](https://x.ai/news/grok-imagine-video-1-5) 时，它就是我们迄今最好的视频模型——更好的运动、更好的物理、更好的音频。今天它走得更远：图像与语音参考、仅凭提示词生成视频，以及原生 1080p 生成。

图像与语音参考今日在美国面向 [grok.com/imagine](https://grok.com/imagine?referrer=website&campaign=imagine-video-1-5-references-blog) 和 [iOS](https://apps.apple.com/app/grok-ai-chat-video/id6670324846) 上的 SuperGrok Heavy 与 SuperGrok Plus 开放，未来几天推广到所有档位。

## [文生视频与原生 1080p](https://x.ai/news/grok-imagine-video-1-5-references#text-to-video-and-native-1080p)

描述镜头即可——不需要起始图像。文生视频把我们的图像生成与图生视频衔接起来。文生视频与图生视频现在都支持原生 1080p。文生视频与原生 1080p 已在 grok.com/imagine、iOS 和 [Android](https://play.google.com/store/apps/details?id=ai.x.grok) 正式全面可用。

## [语音一致性](https://x.ai/news/grok-imagine-video-1-5-references#voice-consistency)

传入一张角色图像和一段语音参考，两者都会保持稳定——每个场景都是同一张脸、同一个声音。

## [API 中可用](https://x.ai/news/grok-imagine-video-1-5-references#in-the-api)

图像参考、文生视频与原生 1080p 已随我们最好的视频模型 `grok-imagine-video-1.5` 在 [xAI API](https://docs.x.ai/developers/model-capabilities/video/generation) 上线。语音参考支持可[按需申请](https://x.ai/contact-sales?interest=imagine)。

```
import os
import xai_sdk

client = xai_sdk.Client(api_key=os.getenv("XAI_API_KEY"))

response = client.video.generate(
    prompt="Slow cinematic push-in as embers drift across the battlefield and the helmet's crest stirs in the wind",
    model="grok-imagine-video-1.5",
    reference_image_urls=["https://example.com/helmet.jpg"],
    duration=6,
    aspect_ratio="16:9",
    resolution="720p",
)

print(response.url)
```
