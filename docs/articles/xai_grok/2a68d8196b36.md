Grok 4.6 现已在 GitHub Copilot 上线，服务每天在 VS Code 和 GitHub 各处工作的数百万开发者。

## [开始使用](https://x.ai/news/grok-4-6-github-copilot#getting-started)

GitHub Copilot 覆盖多款产品，包括云端智能体（cloud agents）、Copilot CLI 和 VS Code IDE。打开模型选择器，选择 "Grok 4.6"，即可开始使用我们最新的编码模型。部分商业与企业客户需要先在 Copilot 设置中启用该模型。

Grok 4.6 也可通过 [SpaceXAI console](https://console.x.ai/?campaign=grok-4-6-github-copilot-blog&utm_source=website&utm_medium=referral&utm_campaign=grok-4-6-github-copilot-blog) 使用，价格为每百万输入 tokens $2、每百万输出 tokens $6。有关模型的更多信息（包括编码性能），请阅读 [Grok 4.6 发布公告](https://x.ai/news/grok-4-6)。
