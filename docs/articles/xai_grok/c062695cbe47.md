# 在 OpenCode 中使用 Grok

在你的 SuperGrok 或 X Premium 订阅基础上，使用 OpenCode。

连接你的 Grok 账户后，即可用 Grok Build 开始编码——正是为 xAI [终端编码智能体](https://x.ai/build) 提供动力的同一个模型。

## [设置](https://x.ai/news/grok-opencode#setup)

安装 OpenCode：

```
curl -fsSL https://opencode.ai/install | bash
```

bash

启动 OpenCode：

```
opencode
```

bash

在 OpenCode 内运行 `/connect`，选择 **xAI**：

```
/connect
```

txt

选择适合你环境的登录方式——两者都使用你的 Grok 订阅：

- **xAI Grok OAuth (SuperGrok Subscription)** — 打开浏览器登录。
- **xAI Grok OAuth (Headless / Remote / VPS)** — 为 SSH 或远程主机打印一个码和 URL。

更多开源智能体与集成即将到来。
