*本博客由 Assaf Gerner、Guy Rephaeli、Asaf Karnieli、Guy Freund、Shaked Meirom 和 Joanna Kramer 与 Alice 的 Liran Cohen 和 Dadi Atar 合作撰写。*

在短短三周内，我们的前向部署研究人员 (FDR) 团队与 Alice 的研究团队合作，对最近发布的 [NVIDIA Nemotron 3.5 Super VL](https://blogs.nvidia.com/blog/nemotron-3-5-super-vl/) 进行后训练，以提高其对间接提示注入和恶意请求等攻击的恢复能力。结果表明，专门的开放模型如何能够以极低的成本超越前沿水平的质量：

- 与基本模型相比，攻击弹性**41点**改进**
- **与 GPT-6.1 Sol 相比提高了 10 点**
- **比 GPT-6.1 Sol 便宜 25 倍**（每 100 万个代币的成本）

**图 1：我们的训练方案将 Nemotron 3.5 Super VL 从质量和成本与 GPT-6.1 Luna 相当的水平提升到在质量上超越 GPT-6.1 Sol，而成本仅为 GPT-6.1 Sol 的一小部分。 **

这篇文章详细介绍了 Alice 的用例，并介绍了我们开发的自定义训练配方，以在 Alice 的用例上实现前沿水平的结果。

## 提高代理对 Alice 攻击的抵御能力

[Alice](https://alice.io/) 是一家 AI 安全和安保公司，为后期培训构建 RL 环境，该环境由有关威胁行为者行为（“兔子洞”）的真实世界情报以及 150 多名安全研究人员和专家网络成员的输入提供信息。他们为 AI21 提供了一套 RL 健身房，以训练代理防御整个企业环境中的安全威胁，包括平台、系统、工具、数据和工作流程，例如 Slack 和 GitHub。我们的目标是生产在抵抗攻击和完成任务方面都得分很高的智能体，这样一个方面就不会以牺牲另一个方面为代价。

*图 2：Alice 健身房的 Slack 任务示例。公司名称和域名均为虚构。*

其中一种攻击是间接提示注入——将恶意指令植入代理使用工具读取的信息中。例如，可能会提示代理向 Slack 上的员工发送密码重置提醒，但重置链接已损坏，存在暴露员工登录凭据的风险。在 Alice 的 RL 健身房中接受培训的代理将学会检测这种违规行为并防止其发生，同时仍然完成其最初的任务：通知员工重置密码（图 2）。

随着越来越多的企业将代理集成到其核心工作空间（这需要对敏感信息进行高级别访问，以及对员工的广泛访问），确保这些代理能够发现和阻止攻击变得至关重要。我们在 Alice 的 RL 健身房上对 Nemotron 3.5 Super VL 进行训练后的工作证明，智能体可以在完成任务的同时保持高攻击弹性。

## 挑战

为了成功地对 Nemotron 3.5 Super 进行后训练，使其在该用例中表现出色，我们的 FDR 必须解决两个核心挑战。

第一个挑战是如何在不影响常规良性任务完成任务的情况下提高攻击弹性。就拿上面的例子来说，如果Slack代理在检测到恶意重置链接后拒绝停止工作，那么它就成功地保卫了公司——但最终并不是一个非常有用的代理。

第二个挑战是数据方面的。鉴于训练数据集包含数百个示例，团队需要找到一种训练方法，而不会过度拟合模型与训练数据。

他们设计了培训后流程来解决这些挑战。

## 方法论

### 在 Alice 的 RL 健身房内训练智能体

解决这两个挑战意味着要按照实际使用的方式训练 Nemotron 3.5 Super：作为在实时环境中运行的代理，而不是作为回答孤立提示的模型。 Alice 的健身房被打包为 Harbor 任务 [1]，每个任务都带有自己的容器映像，其中包含一个模拟工作区，例如 Slack 或 GitHub。

对于每次部署，AI21 训练平台都会从该映像中启动一个全新的、隔离的沙箱。然后，模型完成沙箱内的任务：读取消息、调用工具并采取操作。当剧集结束时，健身房会对结果进行评分。为每个部署提供自己的沙箱可以保证训练的安全，因为代理响应攻击所做的任何事情都会保留在沙箱内。它还允许我们并行运行数百个部署。我们自始至终都使用相同的设置：生成 SFT 轨迹、生成 GRPO 实时部署以及评估每个检查点。

### 通过近策略 SFT 进行热启动

在线强化学习已成为训练后语言模型的标准方法。由于它是符合策略的，因此该模型从训练期间生成的 rollout 中学习，而不是从提前收集的数据集中学习。对自己的输出进行培训可以提高质量并降低灾难性遗忘的风险。最广泛使用的在线 RL 方法 GRPO 对每个提示的一组 rollout 进行采样并进行比较，以便模型了解如何区分更好的输出和更差的输出。这意味着 GRPO 仅当组中的部署获得不同的奖励时才能学习。如果组中的每次推出都获得相同的分数，则每个优势都为零，该组不会贡献任何梯度，并且不会学到任何东西。

然而，在这种情况下，当我们对 Nemotron 3.5 Super VL 进行初步评估时，我们发现该模型产生的首次展示多样性得分非常低。因此，在我们转向 RL 之前，他们首先运行一个监督微调 (SFT) 阶段，以提高组内奖励方差非零的任务比例 [2]。 SFT 后，训练集中具有非零奖励标准差的任务比例从 35% 上升到 66%。

我们从几个开放模型中成功地在健身房中进行了推广，但按原样对它们进行训练存在两个问题。首先，其中一些模型以非常长的链进行推理，有时会陷入重复循环（图 4），这是我们不希望 Nemotron 3.5 养成的习惯。其次，SFT 数据应该教导安全行为，而不是其他模型的写作风格。更广泛地说，接近策略本身分布的数据更容易学习，并且遗忘更少[3]，因此即使在 SFT 阶段，我们也努力保持训练数据尽可能符合策略（图 3）。为此，他们让 Nemotron 3.5 Super 用自己的语言重写了每个轨迹中的推理，从而缩短了长链，同时保持每个动作不变 [3,4]。

图3展示了效果。按原样，开放模型的推出对基本模型的惊喜几乎是其自身推出的两倍（困惑度×1.99）。对它们进行微调的政策漂移至 ×1.40，而对重新措辞的推出进行微调的政策则保持更接近，为 ×1.23。重新措辞将增加的困惑度从 40% 减少到 23%。

**图 3：基本模型对每个模型的推出感到多么惊讶。我们根据 Nemotron 基础模型下的困惑度对每组部署进行评分。较低的困惑度意味着推出更接近基本模型本身的分布。值是相对于基础模型自身的卷展栏的困惑度来显示的（参考）。平均操作系统模型：开源模型的部署平均值，其部署作为 SFT 数据。原始 SFT：策略的推出按原样对这些推出进行了微调。重新措辞的 SFT：在重新措辞的版本上微调策略的推出。误差线显示 95% CI。**

解决办法是让 Nemotron 3.5 Super 用自己的语言重写每个轨迹中的推理。这样做可以缩短长链，同时保持每个动作不变[3,4]。

**图 4：重新表述 SFT 数据可将检查点的推理长度减半，并几乎消除最常见的重复填充符（例如，“嗯。好的”）。**

在重写数据上训练的 SFT 检查点与在原始数据上训练的 SFT 检查点的质量相匹配，同时生成的令牌少得多，并且在其他任务中不会出现退化。

### 在线强化学习中的奖励塑造

一旦我们建立了一个经过良好 SFT 训练的 Nemotron-3.5-Super VL 检查点，并且结果有所改善且推出更加多样化，我们就能够继续第二阶段：使用 GRPO 进行在线 RL 训练。

Vanilla GRPO 分两步计算每次推出的优势：减去该组的平均奖励，然后除以该组的标准差。我们很快发现第二步不太适合 Alice 的 RL 健身房，因为它使用密集、连续的奖励。除以群体的差距就可以排除奖励差距的大小。例如，奖励为 [0.49, 0.51] 的组和奖励为 [0, 1] 的组最终都具有优势 [−1, +1]。排名得以保留，但规模却消失了。对于密集的奖励，这意味着微小且可能有噪音的差异（例如LLM法官分数的轻微变化）会被放大为全强度梯度[6,9]。因此，我们放弃了标准差归一化，仅保留组均值基线（图 5）。

需要进行另一项奖励修改以控制响应长度。强化学习期间响应长度通常会增长 [5,6]。然而，在这个用例中，它急剧增长，并且一些推出循环直到耗尽上下文窗口。为了解决这个问题，我们取消了两个额外的奖励项：(1) 组相对长度惩罚，它惩罚每个组内最长的 rollout [7,8]，以及 (2) n-gram 重复惩罚，它惩罚推理多次重复相同 n-gram 的 rollout [5]。事实上，这三种修改的组合产生了最好的结果——达到最高的质量，同时产生最短的响应长度。 （图5）。

*图 5：从同一个 SFT 检查点一次添加一个奖励变化：删除 STD 标准化将奖励提升到单独的重复惩罚之上，而添加长度惩罚会阻止推理在达到最高奖励时增长*

## 结果

*图 6：从基础模型到 SFT 到 GRPO，验证集及其 GitHub 和 Slack 子集在每个训练阶段的分布内分数。*

在两个不同的集合上评估训练后的模型。使用两个可以让我们检查其增益是否反映了真实的安全行为，而不是过度拟合训练环境。第一个是验证集，它使用相同的 GitHub 和 Slack 环境作为训练并测量分发内的性能。第二个是 CHASM，Alice 的企业间接提示注入 (IPI) 基准，被设计为一个分布式健身房，包含跨企业工作流程的 117 个攻击任务，涵盖财务、人力资源、法律和客户支持等领域，以及从医疗保健到电信等行业。

CHASM 不与 RL 健身房共享任何任务或应用程序，因此它测试这种行为是否具有普遍性。它的攻击主要是间接即时注入和中毒记录，试图迫使特工窃取数据、破坏机密或转移付款。

在验证集上，每个阶段都建立在最后一个阶段的基础上（图 6）。 SFT 得分几乎翻倍，从 35.19 升至 65.28，GRPO 将其提升至 76.2。 GRPO 的增长大部分来自 GitHub (66.48 → 85.17)，而 Slack 的提升幅度很小 (64.08 → 67.22)。

在 CHASM 上，基本模型得分仅为 7.54。 SFT 将其提高到 34.58，主要是通过教导模型避免有害动作。 GRPO 保留该增益，但不会增加该增益。在 SFT 中学到的安全行为会延续到未见过的环境和攻击类型，而 GRPO 的收益则保持在训练分布范围内。

## 通过定制的训练后配方达到前沿级别的攻击弹性

AI21 和 Alice 共同将 Nemotron 3.5 Super VL 的攻击弹性提高了 41 个点，比基本模型高出 41 个点，比 GPT-6.1 Sol 高出 10 个点，而不会损害整体任务性能，同时成本比前沿模型低 25 倍。为了实现这些结果，AI21 的 FDR 团队依次应用了同策略 SFT，然后是改进的 GRPO（在线 RL）技术。

他们的工作表明，公司可以训练开放模型，将其核心安全和安保策略整合为核心行为原则，确保他们完成分配的任务，同时发现和抵御威胁，例如即时注入攻击。
