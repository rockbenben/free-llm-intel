## 太长不看：

在 RAISE Summit 2025 的主题演讲中，AI21 Labs 联合创始人兼联席 CEO Ori Goshen 解释了"AI all the work"（用 AI 包揽全部工作）意味着什么。他剖析了为什么真正的工作依赖于多步骤任务——以及为什么仅靠 LLM 对于企业用途来说一致性不够。这正是 AI21 的 Maestro 大显身手之处：一个以透明和可信的方式规划、执行并校验复杂工作流的系统。

他的完整演讲见下文。

在这次于巴黎举行的 [RAISE Summit](https://www.raisesummit.com/) 的演讲中，Ori 勾勒出了一条实现"AI all the work"的清晰路径。他说，工作无非是六十亿个等待被理解、被拆解为步骤并被正确执行的任务。虽然大语言模型通常能把单个步骤做对——大约有 90% 的成功率——但现实世界的任务需要多个步骤。而当你把步骤串联起来时，那些小错误会不断累积放大。这就是为什么仅靠提示工程对企业来说远远不够。我们需要的是既像提示一样灵活、又像手工编排的工作流一样稳健的东西。

这正是 [Maestro](https://www.ai21.com/blog/maestro-technical-overview/) 背后的理念。它帮助开发者构建企业级的[知识智能体（knowledge agents）](https://www.ai21.com/blog/maestro-putting-knowledge-to-work/)，通过生成多个计划、选择最优方案并校验每一个步骤来解决任务。它与具体模型无关（model-agnostic），允许对预算和需求进行控制，并会连同成绩单（report card）和执行图（execution graph）一起返回输出，展示 agent 做了什么以及为什么这么做。我们构建 Maestro，是为了超越单轮推理，给企业一个可以放心托付的系统，让它来……
