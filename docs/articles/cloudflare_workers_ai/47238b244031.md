# Workers AI - GLM-5.2 现已登陆 Workers AI

GLM-5.2 现已登陆 Workers AI

- [`@cf/zai-org/glm-5.2`](https://developers.cloudflare.com/workers-ai/models/glm-5.2/) 现已在 Workers AI 上可用。这是 Z.ai 的旗舰 agentic 编码模型，拥有 262,144 token 上下文窗口，支持 function calling 与 reasoning。阅读[更新日志](https://developers.cloudflare.com/changelog/2026-06-16-glm-5.2-workers-ai/)开始使用。
