# Workers AI - 新增 GLM-4.7-Flash、@cloudflare/tanstack-ai 与 workers-ai-provider v3.1.1

GLM-4.7-Flash、@cloudflare/tanstack-ai 与 workers-ai-provider v3.1.1

- [`@cf/zai-org/glm-4.7-flash`](https://developers.cloudflare.com/workers-ai/models/glm-4.7-flash/) 现已在 Workers AI 上可用！这是一个快速、高效的多语言文本生成模型，为 100 多种语言下的多轮 tool calling 做了优化。阅读[更新日志](https://developers.cloudflare.com/changelog/2026-02-13-glm-4.7-flash-workers-ai/)开始使用。
- 全新的 [`@cloudflare/tanstack-ai`](https://www.npmjs.com/package/@cloudflare/tanstack-ai) 包，用于在 TanStack AI 中配合使用 Workers AI 与 AI Gateway。
- [`workers-ai-provider v3.1.1`](https://www.npmjs.com/package/workers-ai-provider) 新增了转写（transcription）、text-to-speech 与 reranking 能力。
