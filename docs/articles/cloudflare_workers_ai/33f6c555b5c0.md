# Workers AI - Workers AI 缺陷修复

Workers AI 缺陷修复

- 我们修复了一个 `max_tokens` 默认值未被正确遵守的 bug —— `max_tokens` 现在如模型页面所显示的那样，正确默认为 `256`。依赖此前行为的用户可能把它看作一次破坏性变更。如果你想生成更多 token，请把 `max_tokens` 参数设置为你的需要值。
- 我们更新了模型页面以展示上下文窗口（context window）—— 其定义为 prompt 中使用的 token + 响应中使用的 token。如果你的 prompt + 响应 token 超出上下文窗口，请求将会报错。请根据你的 prompt 长度和上下文窗口长度相应地设置 `max_tokens`，以确保能成功拿到响应。
