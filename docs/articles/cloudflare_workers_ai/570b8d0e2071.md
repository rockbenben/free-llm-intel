# Workers AI - 介绍来自 Google 的 EmbeddingGemma

介绍来自 Google 的 EmbeddingGemma

- 我们很高兴与 Google 一起作为发布合作伙伴，把他们最新的 embedding 模型带上 Workers AI。我们很高兴引入 EmbeddingGemma，它在同尺寸模型中带来一流的性能，可支撑 RAG 与语义搜索用例。更多细节请查看 [`@cf/google/embeddinggemma-300m`](https://developers.cloudflare.com/workers-ai/models/embeddinggemma-300m)。现在也可用于 AI Search 中的 embedding。
