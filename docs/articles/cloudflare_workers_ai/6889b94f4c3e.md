# Workers AI - 新增语音与 LLM 模型

Workers AI 上线全新语音与 LLM 模型

- Deepgram Aura 2 为 Workers AI 带来全新的 text-to-speech 能力。查看 [`@cf/deepgram/aura-2-en`](https://developers.cloudflare.com/workers-ai/models/aura-2-en/) 和 [`@cf/deepgram/aura-2-es`](https://developers.cloudflare.com/workers-ai/models/aura-2-es/)，了解如何使用这些新模型。
- IBM Granite 模型也上线了！这个新的 LLM 模型虽小但强悍，更多内容请看文档 [`@cf/ibm-granite/granite-4.0-h-micro`](https://developers.cloudflare.com/workers-ai/models/granite-4.0-h-micro/)
