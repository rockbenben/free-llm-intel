# Workers AI - Deepgram Flux 现已登陆 Workers AI

Deepgram Flux 现已登陆 Workers AI

- 我们很高兴成为 Deepgram 的发布合作伙伴，并提供他们专为构建 voice agents 而打造的新款 Speech Recognition 模型。关于本次发布的更多细节，请查看 [Deepgram 的博客](https://deepgram.com/flux)。
- 通过 [`@cf/deepgram/flux`](https://developers.cloudflare.com/workers-ai/models/flux/) 访问该模型，并查看[更新日志](https://developers.cloudflare.com/changelog/2025-10-02-deepgram-flux/)获取深入的示例。
