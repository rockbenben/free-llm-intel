## 2026 年 9 月 17 日

*     **Antigravity Agent 09-2026**：发布了 `antigravity-preview-09-2026`，它取代并弃用了 `antigravity-preview-05-2026`。

  如果你在远程 sandbox 上运行（`environment: "remote"`），并且只读取 `output_text` 或 `model_output` 步骤，只需更新 agent 字符串，其余均无需改动。

  如果你在本地运行工具（`local_environment`）或解析 `function_call` 步骤，内置工具已发生变化。参数改用 PascalCase 而非 snake_case，文件编辑也改为按行范围替换，而非整体重写。

  | 能力 | 05-2026 | 09-2026 |
  | :--- | :--- | :--- |
  | 文件创建 | `write_file(path, content)` | `write_to_file(TargetFile, CodeContent, Overwrite, Description)` |
  | 文件编辑 | `write_file(path, content)`，整体重写 | `replace_file_content(TargetFile, StartLine, EndLine, TargetContent, ReplacementContent)` |
  | 文件读取 | `read_file(path, offset, limit)`，字节偏移 | `view_file(AbsolutePath, StartLine, EndLine, ContentOffset)` |
  | 目录列举 | `list_files(path)` | `list_dir(DirectoryPath)` |
  | 文件与代码搜索 | 无，agent 使用 shell 命令 | `find_by_name(SearchDirectory, Pattern, MaxDepth)` 和 `grep_search(SearchPath, Query, IsRegex)` |
  | Shell 执行 | `code_execution(command, timeout_seconds)` | 不变 |
  | 网页搜索 | `google_search(queries)` | 不变 |

  请参阅 [Antigravity Agent](/docs/antigravity-agent) 指南。
  `antigravity-preview-05-2026` 将于 2026 年 10 月 5 日关停，相关进展记录在 [deprecations](/docs/deprecations#managed-agents) 页面。
