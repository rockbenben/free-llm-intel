## 2026 年 10 月 27 日

- **Gemini API CLI (`gemini-api`) Beta 版**：发布了 [Gemini API CLI](https://ai.google.dev/gemini-api/docs/cli?hl=zh-cn) (`gemini-api`)，这是一款无状态、零依赖的命令行客户端，适用于 AI 编码代理、脚本和 CI 流水线。在 [Interactions API](https://ai.google.dev/gemini-api/docs/interactions?hl=zh-cn) 上使用 `gemini-api`，以生成文本和媒体、分析文件以及运行 [Gemini 托管式智能体](https://ai.google.dev/gemini-api/docs/agents?hl=zh-cn)。如需开始使用，请参阅 [Gemini API CLI 指南](https://ai.google.dev/gemini-api/docs/cli?hl=zh-cn)。
