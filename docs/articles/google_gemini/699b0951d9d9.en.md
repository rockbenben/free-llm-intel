## March 18, 2026  

*     Released the new [Built-in Tools and Function Calling
  Combination](/docs/tool-combination) feature, making it possible to use
  Gemini's built-in tools alongside custom function calling tools in a single
  API call.

*     [Grounding with Google Maps](/docs/maps-grounding#supported-models) is now
  supported for Gemini 3 models going forward.
