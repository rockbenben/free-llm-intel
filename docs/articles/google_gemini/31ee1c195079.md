## 2026 年 10 月 26 日

- **Generate Content API 存储功能默认开启**：使用 Generate Content API（`generateContent`、`streamGenerateContent` 和 `batchGenerateContent`）的新项目现在默认存储请求 (`store=true`)，与 Interactions API 保持一致。现有项目会保留其当前设置。如需停用，请在各个请求中设置 `store=false`，或在[日志和数据集](https://aistudio.google.com/logs?hl=zh-cn)信息中心的**设置**面板中关闭 Generate Content API 日志记录。如需了解详情，请参阅[日志和数据集](https://ai.google.dev/gemini-api/docs/logs-datasets?hl=zh-cn#configure-logging)。
