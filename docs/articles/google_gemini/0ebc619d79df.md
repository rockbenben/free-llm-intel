## 2026 年 1 月 8 日  

*   推出了对 Cloud Storage 存储桶以及任意公开和私有 DB pre-signed URL 作为 Gemini API 数据输入源的支持。文件大小上限也从 20MB 提高到 100MB。有关详情，请参阅 [File input methods guide](/docs/file-input-methods)。
