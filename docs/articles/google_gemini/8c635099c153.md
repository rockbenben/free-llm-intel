## 2026 年 10 月 27 日  

*   **Gemini API CLI (`gemini-api`) beta**：发布了 [Gemini API CLI](/docs/cli)（`gemini-api`），这是一个用于 AI 编码 agents、脚本和 CI 管道的无状态、零依赖命令行客户端。在 [Interactions API](/docs/interactions-overview) 上使用 `gemini-api` 来生成文本和媒体、分析文件，以及运行 [Gemini managed agents](/docs/agents)。要开始使用，请参阅 [Gemini API CLI 指南](/docs/cli)。
