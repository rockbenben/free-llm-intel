**Gemini 3.5 Transcribe Live** (`gemini-3.5-transcribe-live`)：通过 WebSocket 使用 Live API 进行低延迟双向流式语音转文字，支持临时和最终转写事件、智能转写模式以及多种语音活动检测 (VAD) 策略。
