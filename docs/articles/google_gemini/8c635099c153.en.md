## October 27, 2026  

*   **Gemini API CLI (`gemini-api`) beta**: Released the [Gemini API
  CLI](/docs/cli) (`gemini-api`), a stateless, zero-dependency command-line
  client for AI coding agents, scripts, and CI pipelines. Use `gemini-api` on
  the [Interactions API](/docs/interactions-overview) to generate text and
  media, analyze files, and run [Gemini managed agents](/docs/agents). See the
  [Gemini API CLI guide](/docs/cli) to get started.
