## September 15, 2026  

*     **Gemini 3.8 Live and Gemini 3.8 Live Extended Thinking generally available
  (GA)**: Released our next-generation Live API models for real-time
  multimodal dialogue and agentic tool use:

  *   **[Gemini 3.8 Live](/docs/models/gemini-3.8-live) (`gemini-3.8-live`)**:
    Engineered for sub-second conversational latency with native audio
    understanding, affective dialogue, proactive audio, and
    synchronous/asynchronous function calling.
  *   **[Gemini 3.8 Live Extended Thinking](/docs/models/gemini-3.8-live-extended-thinking)
    (`gemini-3.8-live-extended-thinking`)**: Specialized for complex
    reasoning, multi-step planning, and long-horizon state tracking with
    configurable thinking levels (`MINIMAL`, `LOW`, `MEDIUM`, `HIGH`) and
    asynchronous function calling.

  To get started, see the
  [Thinking in the Live API guide](/docs/live-api/thinking) and the
  [Live API overview](/docs/live-api).
