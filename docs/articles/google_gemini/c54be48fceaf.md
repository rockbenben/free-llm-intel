## 2026 年 9 月 15 日

*     **Gemini 3.8 Live 和 Gemini 3.8 Live Extended Thinking 全面上市
  (GA)**：发布了我们的下一代 Live API 模型，用于实时
  多模态对话和代理工具使用：

  *   **[Gemini 3.8 Live](/docs/models/gemini-3.8-live) (`gemini-3.8-live`)**：
    专为亚秒级对话延迟而设计，具备原生音频
    理解、情感化对话、主动音频，以及
    同步/异步 function calling。
  *   **[Gemini 3.8 Live Extended Thinking](/docs/models/gemini-3.8-live-extended-thinking)
    (`gemini-3.8-live-extended-thinking`)**：专用于复杂
    推理、多步规划和长程状态跟踪，具备
    可配置的思考级别 (`MINIMAL`、`LOW`、`MEDIUM`、`HIGH`) 和
    异步 function calling。

  如需开始使用，请参阅
  [Live API 中的思考指南](/docs/live-api/thinking) 和
  [Live API 概览](/docs/live-api)。
