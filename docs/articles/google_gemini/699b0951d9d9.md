## 2026 年 3 月 18 日

*     发布了全新的 [Built-in Tools and Function Calling Combination](/docs/tool-combination) 功能，使得可以在单个 API 调用中同时使用 Gemini 的内置工具与自定义函数调用工具。

*     即日起，Gemini 3 模型已支持 [Grounding with Google Maps](/docs/maps-grounding#supported-models)。
