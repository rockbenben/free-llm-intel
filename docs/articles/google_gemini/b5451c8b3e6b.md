## 2026 年 10 月 26 日  

*   **Generate Content API 存储默认开启**：在付费层上使用 Generate Content API（`generateContent`、`streamGenerateContent` 和 `batchGenerateContent`）的新项目现在默认存储请求（`store=true`），与 Interactions API 保持一致。现有项目保留其当前设置。要选择退出，请在单个请求上设置 `store=false`，或在 [Logs and Datasets](/logs) 仪表板的 **Settings** 面板中关闭 Generate Content API 日志记录。详情请参阅 [日志和数据集](/docs/logs-datasets#configure-logging)。
