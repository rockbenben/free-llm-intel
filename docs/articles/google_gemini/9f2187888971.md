## 2026 年 9 月 15 日

- **Gemini 3.8 Live 和 Gemini 3.8 Live 扩展思考正式版 (GA)**：发布了两款新的音频转音频模型，用于使用 Live API 的实时语音应用：  **Gemini 3.8 Live** ([`gemini-3.8-live`](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-live?hl=zh-cn))：大多数低延迟语音代理体验和实时对话的默认选项，不会出现推理延迟。具有交错推理、默认异步函数调用和完整会话客户端内容更新功能。 **Gemini 3.8 Live 扩展思考**（[`gemini-3.8-live-extended-thinking`](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-live-extended-thinking?hl=zh-cn)）：高推理音频转音频模型，支持在实时音频互动期间进行后台推理，建议在需要更高后台推理能力时使用。  如需开始使用，请参阅 [Live API 指南](https://ai.google.dev/gemini-api/docs/live-api?hl=zh-cn)、[功能指南](https://ai.google.dev/gemini-api/docs/live-api/capabilities?hl=zh-cn)和[思维指南](https://ai.google.dev/gemini-api/docs/live-api/thinking?hl=zh-cn)。
