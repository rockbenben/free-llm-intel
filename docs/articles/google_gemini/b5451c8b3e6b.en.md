## October 26, 2026  

*   **Generate Content API storage on by default**: New projects using the
  Generate Content API (`generateContent`, `streamGenerateContent`, and
  `batchGenerateContent`) on the paid tier now store requests by default
  (`store=true`), matching the Interactions API. Existing projects
  keep their current setting. To opt out, set `store=false` on individual
  requests or turn off Generate Content API logging in the **Settings** panel
  of the [Logs and Datasets](/logs) dashboard. See
  [Logs and datasets](/docs/logs-datasets#configure-logging) for details.
