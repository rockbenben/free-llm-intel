## 2026 年 11 月 19 日  

* **精灵 4 (`models/genie-4`) 全面上市 (GA)**：已发布
    [精灵 4](/docs/models/genie-4) (`models/genie-4`) 上
    [交互API](/docs/genie) (`v1beta`) 用于实时交互世界
    生成，流式传输可操纵的 `24 fps` `16:9` 视频，并同步
    通过 WebRTC 和 WebSockets 的 `48 kHz` 立体声音频。来自文本的种子世界，
    `16:9` 参考图像或两者，并使用 `WASD`/箭头键和
    会话中文本事件。可在付费等级上使用
    [定价](/docs/pricing#genie-4) 每 1M 输入代币 `$1.50`，`$9.00`
    每 1M 文本输出令牌，每 1M 视频输出令牌 `$17.50`
    （`~$0.10/sec`，包括立体声音频）；看到
    【精灵4互动世界生成】(/docs/genie)，
    [精灵4提示和控制指南](/docs/genie-prompting)，以及
    [速率限制](/docs/rate-limits#genie-4)。

* **工具检索（预览版）**：Interactions API 现在可以搜索您的工具
    按需库和加载函数模式，因此不再需要大型工具集
    每个请求都必须完整发送。用“defer_loading”标记工具：
    true` and add a `{"type": "tool_search"}` 让 Gemini 检索的工具
    为您提供架构，或设置 `execution: "client"` 来运行您自己的检索
    逻辑。远程 MCP 服务器也支持 `defer_loading`。

工具检索适用于 Gemini 3.6 及更高版本，包括所有 Gemini
    交互 API 中的 4 个模型。请参阅
    [工具检索](/docs/tool-retrieval)指南。
