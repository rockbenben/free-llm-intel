## 2026 年 11 月 19 日  

*   **Genie 4（`models/genie-4`）正式开放（GA）**：在
    [Interactions API](/docs/genie)（`v1beta`）上发布
    [Genie 4](/docs/models/genie-4)（`models/genie-4`），用于实时交互式世界生成，
    可在 WebRTC 与 WebSockets 上流式输出可操控的 `24 fps` `16:9` 视频，
    并带有同步的 `48 kHz` 立体声。世界种子可来自文本、一张
    `16:9` 参考图，或两者兼用；还可用 `WASD` / 方向键以及会话中的文本事件实时操控。
    已在付费层级开放，价格见
    [定价页](/docs/pricing#genie-4)：每 100 万输入 token `$1.50`、每 100 万
    文本输出 token `$9.00`、每 100 万视频输出 token `$17.50`
    （约 `$0.10/sec`，含立体声）；另见
    [用 Genie 4 生成交互式世界](/docs/genie)、
    [Genie 4 提示词与操控指南](/docs/genie-prompting)，以及
    [速率限制](/docs/rate-limits#genie-4)。

*   **工具检索（预览）**：Interactions API 现在可以检索你的工具库并按需加载函数 schema，
    大规模工具集因此不必在每次请求时全量发送。给工具标注
    `defer_loading: true`，并添加一个 `{"type": "tool_search"}` 工具，就能让 Gemini 代为检索
    schema；也可以设置 `execution: "client"` 来运行自己的检索逻辑。
    远程 MCP 服务器同样支持 `defer_loading`。

    工具检索可用于 Gemini 3.6 及之后的模型（含全部 Gemini 4 模型），
    且需在 Interactions API 中使用。参见
    [工具检索](/docs/tool-retrieval)指南。
