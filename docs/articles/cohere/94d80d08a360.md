# 推出 Command A+：让主权的 agentic 能力惠及所有人

我们迄今最快、最强的语言模型。Command A+ 是一款开源的企业级主力模型，为复杂推理、多模态与多语言的 agentic 任务而生——而它最低只需两块 H100 GPU 即可运行。

今天，我们开源发布 Command A+。Command A+ 是一个 mixture-of-experts（MoE）模型，高效、多面、可私有化部署，为高性能 agentic 任务打造，计算开销极低。

它脱胎于过去一年与客户共同部署 [North](https://cohere.com/north) 的经验，超越 [Command](https://docs.cohere.com/docs/command-a) 系列的每一代前作，并将它们的能力统一进一个可扩展的模型。

Command A+ 现以 [Apache 2.0 许可证](https://www.apache.org/licenses/LICENSE-2.0)自由开放，推进着 Cohere 让主权 AI 成为技术现实的使命——让开发者在实验、部署和生产工作流中直接获得企业级的 agentic 能力。

前往 [Hugging Face](https://huggingface.co/CohereLabs/command-a-plus-05-2026-w4a4) 下载权重（提供多种近乎无损的量化版本）并阅读我们的实施指南。如需专用的托管推理环境，今天就可以在 [Model Vault](https://dashboard.cohere.com/welcome/login) 部署 Command A+。

Command A+ 在 North 应用中表现强劲，印证了其最初的设计目标。相比 Command A Reasoning，Agentic Question Answering 准确率和电子表格分析质量分别提升 20% 和 32%。Memory 性能——测试 North 跨对话与存储数据推理的能力——Command A+ 得分为 54%，而 Command A Reasoning 为 39%。

在多模态理解与推理方面，Command A+ 在 MMMU Pro 上达到 63%，在 MMMU 上达到 75.1%（后者对比 Command A Vision 的 65.3%）。MathVista 得分从 73.5% 提升到 80.6%，CharXiv 推理从 46.9% 提升到 52.7%，反映出文档理解任务的全面增益。

图 5：Command A+ 与 Command A Vision 的多模态性能对比。Command A+ 是 Cohere 首个多模态推理模型，在 CharXiv 推理等相关任务集上相较 Command A Vision 带来显著提升。各基准均遵循标准评测方法。

Command A+ 大幅扩展了多语言能力，语言覆盖从 23 种拓宽到 48 种，并在机器翻译和多语言推理上录得增益。

图 6：Command A+ 与 Command A Reasoning 的多语言性能对比。MT-AIME 2025 是对 AIME-2025（一个英文数学基准）的内部翻译版本，评测语种为阿拉伯语、日语和韩语。WMT24++ 是广泛使用的公开基准，此处评测 xCOMETxl。2

Command A+ 在 [Artificial Analysis Intelligence Index 上获得 37 分](https://artificialanalysis.ai/evaluations/artificial-analysis-intelligence-index)，超过其他领先的开放模型，体现了它作为企业 agentic 工作流通用模型的实力 [3]。

## 规模化的效率

效率是企业 AI 部署的核心约束。它决定一个语言模型能否实际大规模部署——因为它塑造了可靠、经济地服务该模型所需的计算、内存、延迟、功耗和基础设施。

我们把 Command A+ 工程化为极其硬件高效的模型。该模型今天在 Hugging Face 上提供 [16-bit](https://huggingface.co/CohereLabs/command-a-plus-05-2026-bf16)（BF16）、[8-bit](https://huggingface.co/CohereLabs/command-a-plus-05-2026-fp8)（FP8）和 [4-bit](https://huggingface.co/CohereLabs/command-a-plus-05-2026-w4a4)（W4A4）量化版本，质量差异几不可察。实践中，这意味着 Command A+ 最低在两块 NVIDIA H100 或一块 NVIDIA Blackwell GPU 上即可运行，且几乎没有质量损失。

Command A+ 也是我们迄今最快的模型：总参数 218B、激活参数 25B，对比 Command A Reasoning 的 111B 稠密架构。在相同量化和并发级别下，它提供最高 63% 更高的 Output Tokens per Second（TOPS），并将 Time To First Token（TTFT）最多降低 17%。W4A4 量化再额外带来 47% 的速度提升和 13% 的延迟下降。

图 7：Command A+ 与 Command A Reasoning 在不同并发和量化下的速度与延迟。TOPS = 模型生成 token 期间每秒收到的 token 数（即收到 API 第一个 chunk 之后）；TTFT = 发出 API 请求后收到第一个 token 的时间（秒）。4

我们还使用 speculative decoding 在不影响输出质量的前提下加速文本生成。我们针对该模型的 MoE 架构专门优化了这一方法，为文本和多模态输入额外带来 1.5-1.6 倍的推理加速。关于这项工作可阅读[这里](https://cohere.com/blog/mixture-of-experts-models-get-more-from-speculative-decoding)。

Command A+ 是首个使用我们最新 tokenizer 的模型，相较上一代带来显著的压缩改进。生成同样的回答所需 token 更少，从而降低了推理成本的一个主要驱动因素。值得注意的是，这些增益延伸到主要非欧洲语言——它们在 tokenizer 训练中常常代表性不足。阿拉伯语的 tokenization 效率提升 20%，韩语提升 16%，日语提升 18%。

图 8：Command A+、Command A Reasoning 与 gpt-oss 在不同语言上产生的 token 数对比（以 Command A+ tokenizer 产生量为其倍数表示）。

## 下一步是什么？

如今主权 AI 的进展取决于同时推进三条战线：性能、安全和成本。在 Cohere，我们在三条线上同时投入——既投入模型本身，也投入支撑 North 的领域专有能力。

这意味着持续改进推理、多模态理解和编程表现，同时确保模型完全适合在客户环境中运行。目标不只是更强的基准分数，而是能在真实运营约束下支撑全企业转型的系统。

我们已经把这一方法应用到其他模型家族——包括 [Embed](https://cohere.com/embed)、[Rerank](https://cohere.com/rerank) 和 [Transcribe](https://cohere.com/transcribe)——在它们身上我们同样实现了先进性能与高效、成本可控推理的兼顾。
