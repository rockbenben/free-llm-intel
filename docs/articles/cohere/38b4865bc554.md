# AI 的总拥有成本

对各行各业的许多企业来说，人工智能的使用已从好奇心的实验变成必要开支，其数字化转型战略随 AI 创新一同成长。然而许多公司仍然没有完全理解购买 AI 技术时到底买的是什么单元经济学——当 AI 工作流的野心不断扩张、成为做生意的永久组成部分时，这可能演变为一项财务风险。

## AI 成本如何计算

AI 的可见价格通常以 token 报价。Token 是模型读取和生成的文本碎片。每一次 prompt、每一次回复、每份被检索的文档、agent 的每一步、每次工具调用、每个循环、每次重试都会产生 token。但 token 定价只是成本的一部分——尽管鉴于 AI 在企业中被有效实施后使用量的扩张方式，它是最显眼也最难预测的那部分。

更大的问题并不是厂商每百万 token 收多少钱，而是当 AI 成为生意运转不可分割的一环后，**拥有、运营、保护和扩展它的成本**是多少。这正是 AI 所有权向组织提出的核心挑战。

## AI TCO 随使用量一起上升

今天，随着企业 AI 成为一大业务开支，总拥有成本正在上升。[Gartner 预测 2026 年全球 AI 支出将达到 2.52 万亿美元](https://www.gartner.com/en/newsroom/press-releases/2026-05-05-gartner-says-autonomous-business-and-artificial-intelligence-layoffs-may-create-budget-room-but-do-not-deliver-returns)，年增 44%，主要由基础设施驱动。AI 采用越多，这个问题越重要，因为 [AI 成熟度](https://cohere.com/blog/enterprise-ai-maturity-model)和用量意味着更多推理、更长的上下文窗口、更多的 agentic 步骤、更多的检索，以及对速度的需求。

屏幕上的一个答案，可能代表一串模型调用、文档搜索、工具调用和验证步骤——而这些步骤并不藏在基础设施或模型的账单里。

## AI 所有权的层次：租用与拥有基础设施

当 AI 成为标准业务成本，企业必须理解自己买的是什么：token、延迟、吞吐、利用率、数据控制权，以及预测费用的能力。企业——尤其是财务领导者和贴近 AI 转型项目的人——必须聚焦哪些变量驱动成本、哪些变量保障控制。

能够盈利地规模化 AI 的公司不会是花钱最多的，而是想清楚哪些 AI 能力该拥有、哪些该租用——并建立起区分两者的纪律的那些。把一切都租来的公司最终也会得出同样的结论，只不过是在成本高到不可持续、或者控制权悄悄溜走之后。

## AI 的隐性成本

Token 经济学是明显的起点，因为它解释了 AI 支出为什么与传统软件行为不同。在传统云计算中，成本对应熟悉的单位：服务器、存储、带宽、时间。AI 引入了一个波动性更强的记账单位。

一个 token 很小，但构建在 token 之上的系统不小。一次用户请求可以触发一段长 prompt、一个大的上下文窗口、多个推理步骤、若干工具调用，以及一个精心打磨的最终答案。用户体验的是一次交互；公司支付的是整条链。

这就是为什么 AI 成本可以在产品毫无可见变化的情况下飙升。团队可能为了更好的答案扩大上下文窗口，为了减少幻觉加入检索，为复杂任务引入 agent 循环，或把请求路由到更大的模型——每一个都是合理的决定，叠加起来却极大改变成本结构。

## 从整个 AI 系统来看

常见的错误是把 token 价格当作单元经济学。它不是。**总拥有成本是那个产出 token 的系统。**相关的问题更宽：

- 一个任务消耗多少 token？
- 一个用户动作背后有多少次模型调用？
- 每个步骤由哪个模型处理、如何路由？
- 传递了多少上下文？
- 系统多久重试一次？
- 业务要求什么延迟？
- 花钱买的基础设施真的在被利用吗？

其中很大一部分由基础设施驱动，但同样由公司必须站在数字创新前沿以保持竞争力的迫切性驱动。因此，公司倾向于消费处于商业创新最前沿的最大模型。例如，[Uber 的一通财报电话会](https://fortune.com/2026-05-26/uber-coo-ai-spending-tokens-claude-code/)上表示"公司承诺维护代码的 10% 由自主 agent 构建"，而这家公司只在四个月里就花光了一年的 AI 预算。

新闻标题铺天盖地，但问题依旧：AI 造就了更高产的组织，可对关心收入预测的领导者而言，创新不能以预测失准为代价。

## 意外已在市场上随处可见

近期研究凸显了意外 [AI 基础设施](https://cohere.com/blog/ai-infrastructure)成本的规模。根据 DataRobot 委托的 [2025 年 12 月](https://www.datarobot.com/newsroom/press/the-hidden-ai-tax-idc-research-reveals-nearly-all-organizations-lose-cost-control-when-deploying-genai-and-agentic-workflows-at-scale/) IDC InfoBrief，96% 部署生成式 AI 的组织和 92% 使用 agentic AI 的组织面临高于预期的成本。如此普遍的超支表明，当前的规划模型与实际工作负载并不匹配。Gartner 预计 AI 将进入幻灭低谷期（trough of disillusionment），届时规模化的主要障碍是回报的不确定，而非雄心不足。

麦肯锡 [2025 年 11 月覆盖 105 个国家近 2,000 家组织的调查](https://www.mckinsey.com/capabilities/quantumblack/our-insights/the-state-of-ai)发现：AI 采用虽然普遍，只有约三分之一在全企业范围扩展它，仅 5-6% 报告了显著的财务影响。教训很清楚：支出不确定而价值不清晰，会让糟糕的成本管理付出代价。

预测和治理仍然困难。[Mavvrik 与 Benchmarkit 的 2025 年调查](https://www.mavvrik.ai/state-of-ai-cost-governance-report/)发现，80% 的公司 AI 基础设施预测偏差超过 25%，近 25% 偏差超过 50%；只有 15% 与实际支出相差在 10% 以内。此外，84% 的公司报告因 AI 基础设施导致毛利率侵蚀 6% 以上。对软件公司来说，这些是经常性成本，不是可自由裁量的创新开支。关键的启示是：有限的可见性使 AI 成本难以管理——尤其因为只有约三分之一的公司报告本地（on-premises）AI 支出。

## 与成本相关的更多考量

成本不是唯一的顾虑。随着各国政府强化 AI 治理与标准，依赖外部拥有的模型会引入访问、条款和可用性方面的风险。实际问题在于：一个不受公司控制的模型，本质上就是租来的能力。

当前，AI 成本比传统技术费用上涨得更快、往往更晚才显现、且不遵循可预测的模式。对 agent 编排或 prompt 的小改动就可能显著增加 token 消耗。无法归因、无法管理的成本，就无法被完全控制。

## AI 的资本性支出与运营性支出

投资 AI 系统需要考虑两类不同的成本：资本性（capital）与运营性（operational）。资本性支出覆盖公司拥有的资产，如芯片、服务器、存储和网络设备。这些投资通常是实体的，前期成本高、随时间折旧。运营性支出包括租用的或计量的资源，如云实例、token、电力、冷却和场地。运营费用起步容易，但在规模上会变得巨大。

横跨两类的关键成本驱动因素是：吞吐（每秒 token 数）、单价（每百万 token 的成本）、响应速度（首 token 时间），以及最重要的利用率。利用率是判断拥有还是租用更划算的首要因素。

## 通过高效部署降低 AI 成本

硬件决定最大容量，而模型效率决定实际性能，因此它是预测成本的关键变量。Cohere 的模型在参数量和量化上各有跨度，但让 token 只流经模型参数一部分（mixture-of-experts 即 MoE 方法）之类的做法，能在不明显损失能力的前提下压低生成成本。此外，低位重量化的模型可以提高吞吐、降低延迟，最大化硬件产出。

正因如此，模型路由——或者说为特定任务选择合适尺寸的模型——对降低模型推理成本很重要。这些技术是在自有硬件上取得高性价比性能的关键。

这也是为什么只看硬件原始价格同样不能很好指导成本。芯片承担了大量世界推理算力的 [NVIDIA](https://blogs.nvidia.com/blog/lowest-token-cost-ai-factories/)认为，重要的指标不是计算成本或每美元理论运算次数（衡量你付出什么），而是每 token 成本（衡量你实际产出什么）。按其自述，一块更便宜但每秒产出更少 token 的 GPU，最终每 token 成本反而更高而非更低。代际收益巨大：NVIDIA 报告其 Blackwell 级系统每兆瓦产出的 token 约为上一代 Hopper 的 50 倍，每 token 成本削减约 35 倍。

要把权衡讲具体，想象一个全天候运行的客服助手：比如每天五十万个请求、每个几千 token（算上每个答案背后的检索和重试）。通过前沿 API 租用，用量和成本永不停歇。把同样的负载跑在自有硬件上，成本结构就反转了：硬件成为固定的、折旧中的费用，在此之后的每个额外请求几乎免费。低于某个量级，API 占优，因为闲置硬件是纯粹浪费；高于它，所有权开始领先，且差距随每个 token 扩大。

在数据中心规模，这一差距以硬数字呈现。[2026 年 Lenovo 的一项分析](https://lenovopress.lenovo.com/lp2368-on-premise-vs-cloud-generative-ai-total-cost-of-ownership-2026-edition)用其自有 8-GPU 服务器服务 70B 至 405B 参数模型得出（比上例更大的一档）。其摊薄后的每百万 token 生成成本，在自有 H100 硬件上约 $0.11，对应云实例约 $0.89，可比前沿 API 约 $2.00。

以两种不同方法估算，自有推理都落在 $0.11–0.12 USD 附近（Lenovo 的 5 年所有权 TCO；NVIDIA/SemiAnalysis 在更新的 GB300 芯片上的 InferenceX 基准，两者并不严格可比）。租用数字来自 Lenovo。自有数字假设持续的高利用率。

这相当于相对租用云基础设施 8 倍的优势，相对按 API 购买 token 至多 18 倍的优势；在持续使用下，五年节省以每台服务器数百万美元计。同一分析显示，一台 8-GPU 服务器不到四个月即可回本——但这一结论只针对按需云价格，即最贵的一种租法。

两项独立估计、经由不同方法，把自有推理落在同一区间。Lenovo 的约 $0.11 来自 H100 五年所有权模型；[NVIDIA 报告](https://developer.nvidia.com/deep-learning-performance-training-inference/ai-inference)在其旗舰 GB300 平台上每百万 token $0.123，由第三方 SemiAnalysis InferenceX 基准测量。数字并不严格可比——一个是会计摊销，一个是新芯片上的推理基准——但两个来源在自托管产出上都落在 $0.11–0.12 附近，而云实例约 $0.89、前沿 API 约 $2.00，这比任何单一数字都更站得住。

有两点会给这些数字降温。它们是厂商成本、基于该厂商硬件计算，且云端一侧刻意省略了存储、出口流量和支持费用，所以可以想象真实差距比标题数字更窄。同样的谨慎也适用于"每 token 成本"这一表述本身：它是 NVIDIA 的说法，恰好展示 NVIDIA 自己的芯片；分析师指出，该指标对高度优化、同构的环境的粉饰程度高于对混乱的真实环境。

而且每个数字都假设持续的、高的利用率。同一分析显示，一台 8-GPU 机器每天只用约四小时的话，自有反而比租用更贵。诚实的论点不是"所有权总是赢"，而是它对全天候负载有决定性优势。

## AI 所有权实践

实践中，所有权意味着拥有或对 AI 系统所依赖的组件价值链——数据中心、芯片和模型层——持有有意义的控制，而不是通过 API 向另一家公司付费换取访问。

一家公司可以拥有模型但租用硬件，可以在托管（colocation）设施里跑开放权重，也可以把三者作为一个整体计量服务购买。在依赖光谱的另一端，一家企业如今最依赖的战略能力可能既不属于它、也不由它治理：别人的模型，跑在别人的芯片上，在别人的数据中心里，按 token 计费。

随着各国政府收紧 AI 规则和出口管制，这种依赖不仅是财务上的，也是战略上的敞口。一项能被另一家公司——或另一个国家——重新定价、限流、弃用或限制的能力，无论你在它身上花了多少钱，都是租来的。

所有权提供对模型部署的控制，保护数据、prompt 和微调权重，并实现可预测的、摊薄后的成本，而非随用量波动的开支。围绕自有基础设施、高效模型和诚实的成本归因构建起来之后，AI 战略就变成董事会可以据以规划、可以辩护的东西，而不是一季度一度要硬着头皮面对的开支。云仍然赢在它被创造出来的用途上：训练突发、实验和不可预测的需求。但驱动长期成本的那台"主力推理机"，正越来越应该离家更近。
