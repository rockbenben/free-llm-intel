# 全球领先的开放模型，完全由你掌控

为每个任务配上合适的模型，一切都在你的管辖之下。

![一张抽象意象图，上面叠印着文字「世界领先的开放模型，由你掌控。已在 Model Vault 上线」](https://cdn.sanity.io/images/rjtqmwfu/web3-prod/94683ad16fe28268fa577a6c84a3556bb7fc1a43-3840x2160.png?auto=format&fit=max&q=80&w=1130)

核心要点

- **开放模型现已登陆 Model Vault**：企业可以在一个完全托管、加密的推理平台上，同时运行 Cohere 的模型与领先的开放模型（例如 DeepSeek V4.1 Flash、Gemma 4、GPT-OSS 和 Phi）。
- **默认零数据保留： **Model Vault 既不保留 prompts，也不保留输出，由此提供一条坚实的安全基线。
- **主权推理： **你保留对四个关键要素的控制权：你的数据存放在哪里（数据驻留与监管合规）、谁能访问它（在 Encrypted 中是享有完全隐私的隔离租户）、你能使用哪些模型（为每个任务挑合适的模型，而不是只有一家供应商的产品可选），以及你的 AI 如何运行（不由供应商说了算）。
- **区域可用性：** Model Vault 已在美国、欧盟和加拿大上线；Model Vault Encrypted 已在美国上线，欧盟和加拿大的支持即将推出。

AI 上的主权，意味着客户能够选择、审查并部署最贴合自身需求的模型，而不必把控制权交给某一家供应商；但这份自由绝不该以牺牲安全或隐私为代价。把 Cohere 以及来自全球其他供应商的领先开放模型加进 Model Vault，让我们的客户拿到了按需选用合适工具的灵活性，同时不必牺牲那些约束其业务的标准。

每个组织都想为手头的任务用上能拿到的最好 AI 模型，但许多组织做不到。对一家银行、一所医院或一个政府部门而言，把敏感数据发往共享 API 往往根本不用谈。与此同时，受能力或容量所限，自行管理开放模型或 on-premise 模型的推理也可能行不通。于是团队最终要在自己想要的模型、自己需要的控制力，以及自己用来管理它们的容量三者之间做取舍。

他们本不该被逼到这一步。今天我们宣布第三方模型在 Model Vault 与 Model Vault Encrypted 内上线，让企业能够在一个完全托管且加密的推理平台上，同时运行 Cohere 的模型和领先的开放模型。对 prompts 与输出的零数据保留，在 Model Vault 中是默认实现的。

### **两档防护**

Model Vault 提供完整的推理技术栈，经由一个只专属于你所在组织的隔离实例来托管。Model Vault Encrypted 走得更远：即使模型正在处理你的数据，数据也始终保持加密。

**Model Vault：** 你的模型与工作负载运行在单租户基础设施上。区域由你来选，你的 prompts 和输出就留在该区域。基础设施由 Cohere 管理，因此你不必搭建和运维自己的集群，也能获得生产级的服务。

**Model Vault Encrypted：** 面向你最敏感的工作，Model Vault Encrypted 保护的是使用中的数据，而不仅仅是静态数据与传输中的数据。prompts 与输出在隔离环境内部处理，并借助机密计算全程保持加密。连 Cohere 也无法看到你发给模型的内容或模型返回的内容。任何云服务商同样不能。

### **主权推理意味着什么**

主权推理意味着由你决定你的 AI 如何运行，而不是由你的供应商决定。它落在四件事上：

- **你的数据存放在哪里。** 在你偏好的受支持区域内运行推理工作负载，帮助你满足所在组织的数据驻留与监管要求。
- **谁能访问它。** Model Vault 把你的工作负载放在一个独立、隔离的租户中。而用 Model Vault Encrypted，除了你没有人能看到你的 prompts 或输出，Cohere 也不行。
- **你能使用哪些模型。** 用最适合这个任务的那个模型，而不是只挑某一家供应商恰好提供的那一个。

### **给每个任务都配上合适的模型**

没有任何一个模型样样皆优。Model Vault 让你为每个任务挑出合适的那一个，并让它们在完全相同的保护下运行。

**Cohere 的模型。** Command 用于生成式与 agentic 工作，Embed 和 Rerank 用于搜索与检索，Parse 用于文档，Transcribe 用于语音，Translate 用于多语言工作流。

**高性能的开放模型。** 除了我们自己的模型，Model Vault 还运行着使用量最大的那些开放模型，包括 DeepSeek V4.1 Flash（OpenRouter 上使用量最大的开放模型）、GLM 5.3 Flash、MiMo V2.6 Pro、Gemma 4 和 NVIDIA Nemotron。GPT-OSS 与 Phi 系列模型也同样可用。

有了 Model Vault，你可以为每个任务挑选最好的模型，并在一个统一的、生产级的推理栈内运行它们。

### **常见问题**

**哪个选项适合我？** Model Vault 适合大多数受监管的工作负载——它们需要一个隔离租户、区域内的处理，以及覆盖面广的模型目录。数据敏感的工作负载请选择 Model Vault Encrypted：此时组织之外的任何人都不能看到你的数据，Cohere 也不例外。

**我能在 Model Vault Encrypted 里运行开放模型吗？** 能。Gemma、GPT-OSS 和 Phi 这类模型如今就运行在 Model Vault Encrypted 中，Cohere 的 Embed、Rerank、Transcribe 和 Translate 也是如此。完整清单见上文表格。

**Model Vault 如何定价？** 定价按 GPU 类型计。请访问 [cohere.com/pricing](http://cohere.com/pricing) 了解详情，其中包括按需（按小时）计费与促销活动。需要预留容量请联系销售；月度与年度承诺用量的价格同样提供。
