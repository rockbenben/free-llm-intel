# 全球领先的开放模式，完全由你掌控

正确的模型适合正确的工作，一切都在您的管辖范围内。

！[抽象图像，上面覆盖着文字“世界领先的开放模型，在您的控制之下。可在模型中找到”保险库”](https://cdn.sanity.io/images/rjtqmwfu/web3-prod/94683ad16fe28268fa577a6c84a3556bb7fc1a43-3840x2160.png?auto=format&fit=max&q=80&w=1130)

要点

- **开放模型现已在 Model Vault 上可用**：企业可以在完全托管的加密推理平台上运行 Cohere 模型和领先的开放模型（例如 DeepSeek V4.1 Flash、Gemma 4、GPT-OSS 和 Phi）。
- **默认情况下零数据保留：**提示和输出都不会保留在 Model Vault 中，从而提供强大的安全基线。
- **主权推论：**您保留对四个关键要素的控制：数据所在的位置（数据驻留和监管合规性）、谁可以访问它（加密中具有完全隐私的隔离租户）、您可以使用哪些模型（每项任务的正确模型而不仅仅是一个提供商的产品）以及您的 AI 运行方式（不是由提供商决定）。
- **区域可用性：** Model Vault 在美国、欧盟和加拿大上线； Model Vault Encrypted 在美国上线，欧盟和加拿大的支持即将推出。

人工智能的主权意味着客户可以选择、检查和部署最能满足其需求的模型，而无需将控制权交给单个供应商，但这种自由决不应该以牺牲安全或隐私为代价。在 Model Vault 中添加来自 Cohere 和全球其他提供商的领先开放模型，为我们的客户提供了所需的灵活性，让他们可以使用正确的工具来完成工作，而无需牺牲管理其业务的标准。

每个组织都希望使用最好的人工智能模型来完成手头的任务，但许多组织却做不到。对于银行、医院或政府部门来说，将敏感数据发送到共享 API 通常是不可能的。同时，由于能力或容量的限制，管理开放或本地模型的推理也可能无法实现。团队最终需要在他们想要的模型、他们需要的控制以及他们必须管理的能力之间进行选择。

他们不应该这样做。今天，我们在 Model Vault 和 Model Vault Encrypted 中推出第三方模型，允许企业在完全托管和加密的推理平台上运行 Cohere 模型和领先的开放模型。默认情况下，Model Vault 中会实现提示和输出的零数据保留。

### **两级保护**

Model Vault 提供了通过专用于您的组织的隔离实例进行管理的完整推理堆栈。 Model Vault Encrypted 更进一步，即使在模型处理数据时也能保持数据加密。

**模型库：** 您的模型和工作负载在单租户基础架构上运行。您选择区域，您的提示和输出就会保留在那里。 Cohere 管理基础设施，因此您无需构建和运行自己的集群即可获得生产级服务。

**Model Vault Encrypted：** 对于您最敏感的工作，Model Vault Encrypted 可以保护正在使用的数据，而不仅仅是静态和传输中的数据。提示和输出在隔离环境中进行处理，并在整个过程中使用机密计算保持加密状态。即使 Cohere 也无法看到您发送给模型的内容或模型发回的内容。任何云提供商也不能。

### **主权推论意味着什么**

主权推理意味着您决定人工智能的运行方式，而不是您的提供商。归结为四件事：

- **您的数据所在的位置。** 在您首选的支持区域运行推理工作负载，以帮助满足您组织的数据驻留和监管要求。
- **谁可以访问它。** Model Vault 将您的工作负载保存在单独、隔离的租户中。通过 Model Vault Encrypted，除了您之外，没有人可以看到您的提示或输出，包括 Cohere。
- **您可以使用哪些模型。** 最适合任务的模型，而不仅仅是碰巧通过单个提供商提供的模型。

### **适合每项工作的正确模型**

没有一个模型在所有方面都是最好的。 Model Vault 可让您为每项任务选择正确的任务，并使用相同的保护来运行每一项任务。

**Cohere 的模型。** 用于生成和代理工作的命令、用于搜索和检索的嵌入和重新排序、用于文档的解析、用于语音的转录和用于多语言工作流程的翻译。

**高性能开放模型。** 除了我们自己的模型之外，Model Vault 还运行最常用的开放模型，包括 DeepSeek V4.1 Flash（OpenRouter 上最常用的开放模型）、GLM 5.3 Flash、MiMo V2.6 Pro、Gemma 4 和 NVIDIA Nemotron。 GPT-OSS 和 Phi 模型也可用。

使用 Model Vault，您可以为每个任务选择最佳模型，并在统一的生产推理堆栈中运行它。

### **常见问题解答**

**哪个选项适合我？** Model Vault 适合大多数受监管的工作负载，这些工作负载需要隔离租户和具有广泛模型目录的区域内处理。当组织外部的任何人（包括 Cohere）都无法看到您的数据时，请为数据敏感工作负载选择 Model Vault Encrypted。

**我可以在加密的 Model Vault 中运行开放模型吗？** 可以。如今，Gemma、GPT-OSS 和 Phi 模型等模型以及 Cohere 的嵌入、重新排序、转录和翻译都在 Model Vault Encrypted 中运行。完整列表请参见上表。

**Model Vault 如何定价？** 定价按 GPU 类型计算。请访问 [cohere.com/pricing](http://cohere.com/pricing) 了解包括按需（每小时）定价和促销活动在内的详细信息。联系销售人员以获取预留容量；提供每月和每年的承诺定价。
