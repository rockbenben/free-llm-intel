# 介绍 Cohere Model Vault 上的机密计算

现已在 Microsoft Azure 上使用 NVIDIA GPU 进行 NVIDIA 机密计算的公开测试版，为敏感的企业 AI 带来硬件支持的保护和可验证的安全性。

![](https://cdn.sanity.io/images/rjtqmwfu/web3-prod/b2a2c86e80e6776dd67b69232fef3daa01301682-2260x1130.png?auto=format&fit=max&q=80&w=1130)

要点

- **保护使用中的数据：** Model Vault 将保护范围从静态和传输中的数据扩展到推理运行时的提示、文档、响应和模型执行。
- **端到端加密敏感请求内容：**应用程序有效负载通过中间基础设施保持加密状态，并且只能在经过验证的机密环境内解密。
- **信任前验证：** 客户可以在敏感数据离开其基础设施之前以加密方式验证硬件和软件环境。
- **使用机密 AI 作为托管服务：** Cohere 在具有 NVIDIA H100 GPU 机密计算功能的 Microsoft Azure 基础设施上运营服务平台。
- **今天开始公开测试版：** 客户今天就可以开始部署加密的 Model Vault 工作负载。

今天，我们宣布推出 **Cohere Model Vault 上的机密计算** 的公开测试版，为托管企业 AI 带来硬件支持的保护和独立可验证的安全性。

Model Vault 为企业提供专用、完全托管的模型推理。通过机密计算，我们将这种体验扩展到组织的一些最敏感的工作负载和数据，包括财务信息、临床记录、特权文档、专有源代码和知识产权。

目标很简单：企业应该能够使用托管人工智能的功能和操作简单性，而无需让运行它的基础设施访问其敏感的明文数据。

### **保护使用中的数据**

传统上，加密在两个地方保护数据：存储时和通过网络传输时。

Model Vault 上的机密计算旨在保护第三种状态：**使用中的数据**。

推理在跨 CPU 和 GPU 的硬件支持的机密环境中运行。硬件强制隔离可保护工作负载内存免受机密边界之外的一切影响，包括特权基础设施软件和操作员。借助 NVIDIA 机密计算，GPU 内存会受到保护，并且在模型执行推理时 CPU 和 GPU 之间的流量会被加密。

这使得企业能够将更敏感的工作负载引入人工智能，同时减少需要信任其数据的各方和系统的数量。

### **信任之前先验证
**

仅靠保护是不够的。企业还需要一种方法来了解这些保护措施是否确实到位。

这就是为什么远程证明是 Model Vault 机密计算的核心部分。

在发送敏感数据之前，客户端软件会验证有关处理该数据的环境的加密签名证据，包括其硬件、固件和软件配置。该证据将根据已批准的安全策略进行检查。

如果环境不满足策略，则客户端拒绝发送请求。

这将信任模型从**“信任我们”更改为“自己验证”。**

> “企业不必在托管 AI 的简单性和对最敏感信息的控制之间做出选择。通过 Model Vault 和机密计算，客户可以在发送数据之前验证将处理其数据的环境。通过硬件证明，客户不仅可以获得工作负载在安全、机密计算环境中运行的加密证明，还可以验证其数据是否受到未经授权的访问（甚至来自 Cohere 的访问）。”- Cohere 首席技术官 Phil Blunsom

### **敏感请求内容的端到端保护**

机密计算保护计算环境内发生的事情。 Model Vault 还可以保护敏感的请求内容。

Model Vault 不只依赖连接级加密，而是对经过验证的机密环境的应用程序负载进行端到端加密。加密的请求可以通过中间基础设施而不会暴露其内容，并且只有机密环境才能对其进行解密。返回路径上的响应也受到保护。

这保留了托管人工智能平台的运营优势，而无需将客户请求的明文内容暴露给中介基础设施。

客户继续使用 Model Vault API 和熟悉的请求格式。额外的保护内置于客户端和基础设施层中，而不需要应用程序重新设计其有效负载。

### **使用 Microsoft Azure 和 NVIDIA 构建**

公开测试版由 **Microsoft Azure 上的 NVIDIA H100 GPU** 提供支持。

Microsoft Azure 提供底层机密计算基础设施。NVIDIA 机密计算将这些功能扩展到 NVIDIA H100 GPU。 Cohere 通过 Model Vault 的托管模型服务、加密请求路径、远程证明和客户端验证将这些技术整合在一起。

其结果是一个托管人工智能平台，它将云人工智能的操作简单性与推理过程中敏感数据访问的更强大的技术控制结合起来。

> “企业需要相信，他们最敏感的 AI 工作负载受到的保护不仅仅是合同承诺。我们与 Cohere 在 Model Vault 上的合作展示了机密计算如何将托管 AI 的简单性与可独立验证的技术控制相结合。”- Microsoft Azure 机密计算产品主管 Vikas Bhatia

> “机密计算为需要在高度敏感数据上运行 AI 的企业带来了新的可能性。NVIDIA GPU 上的 NVIDIA 机密计算提供了硬件支持的保护，可帮助 Cohere Model Vault 等平台为企业工作负载带来机密的 AI 推理。”- NVIDIA 企业软件副总裁 John Fanelli

### **为敏感企业工作负载解锁人工智能**

对于许多组织来说，问题不再是人工智能是否可以执行任务。问题是该任务所需的数据是否可以安全地与人工智能一起使用。

Model Vault 上的机密计算旨在保护安全、合同或监管要求可能将有价值的数据保留在托管 AI 平台之外的工作负载，包括：

- 金融服务欺诈调查
- 法律服务中的特权文件检索和尽职调查
- 敏感的公共部门信息
- 专利和研究材料
- 专有工程设计文件（EDD）、界面设计文件（IDD）和架构材料
- 跨专有源代码搜索和分析

在这些工作负载中，减少特权基础设施访问并为客户提供独立可验证的证据可以使之前受限的人工智能用例变得实用。

机密计算并不能消除所有风险，也不能取代应用程序安全性、合规性、合同控制或数据驻留要求。它在推理发生时围绕数据和计算提供硬件强制且可验证的保护边界。

### **现已推出公开测试版**

**Cohere Model Vault 上的机密计算现已推出公开测试版，由 Microsoft Azure 上的 NVIDIA H100 GPU 提供支持。**

客户可以通过 Model Vault 创建和管理加密的保管库，并使用相同的 Cohere API 进行集成，并通过客户端验证和端到端加密在敏感请求内容离开客户环境之前对其进行保护。
