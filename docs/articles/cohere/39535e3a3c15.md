# 介绍 Cohere Model Vault 上的机密计算

现已在 Microsoft Azure 上以 NVIDIA GPU 运行 NVIDIA Confidential Computing 的公开测试阶段，为敏感的企业 AI 带来硬件支持的保护和可验证的安全性。

![](https://cdn.sanity.io/images/rjtqmwfu/web3-prod/b2a2c86e80e6776dd67b69232fef3daa01301682-2260x1130.png?auto=format&fit=max&q=80&w=1130)

要点

- **保护使用中的数据：** Model Vault 把保护范围从静态数据和传输中的数据，扩展到推理运行期间的 prompts、文档、响应和模型执行。
- **端到端加密敏感请求内容：** 应用程序负载在穿过中间基础设施时始终保持加密，只有在经过证明的机密环境内部才能解密。
- **信任之前先验证：** 客户可以在敏感数据离开自己的基础设施之前，以密码学方式验证硬件与软件环境。
- **把机密 AI 当作托管服务使用：** Cohere 在具备 NVIDIA H100 GPU 机密计算能力的 Microsoft Azure 基础设施上运营服务平台。
- **今天就在公开测试阶段开始：** 客户今天就可以开始部署加密的 Model Vault 工作负载。

今天，我们宣布 **Cohere Model Vault 上的机密计算**进入公开测试阶段，为托管的企业 AI 带来硬件支持的保护和可独立验证的安全性。

Model Vault 为企业提供专用、完全托管的模型推理。有了机密计算，我们把这种体验扩展到组织中最敏感的部分工作负载和数据，包括财务信息、临床记录、特权文档、专有源代码和知识产权。

目标很简单：企业应该既能享用托管 AI 的能力与运维简便，又不必让运营它的基础设施接触其敏感的明文数据。

### **保护使用中的数据**

传统上，加密在两个地方保护数据：存储时，以及在网络上传输时。

Cohere Model Vault 上的机密计算正是为保护第三种状态而设计的：**使用中的数据**。

推理运行在横跨 CPU 与 GPU 的硬件支持机密环境中。硬件强制的隔离让工作负载内存不受机密边界之外的一切影响，包括特权基础设施软件和运维人员。借助 NVIDIA Confidential Computing，GPU 内存得到保护，模型执行推理时 CPU 与 GPU 之间的流量也被加密。

这让企业可以把更敏感的工作负载带到 AI 上，同时减少需要对其数据托付信任的各方与系统。

### **信任之前先验证
**

仅有保护还不够。企业还需要一种办法，确认这些保护确实已经就位。

这正是远程证明成为 Cohere Model Vault 机密计算核心部分的原因。

在发送敏感数据之前，客户侧软件会验证关于「将要处理这份数据的环境」的密码学签名证据，其中包括它的硬件、固件和软件配置。这段证据会对照一份已批准的安全策略进行核验。

如果该环境不满足策略要求，客户端就会拒绝发送请求。

这把信任模型从**「相信我们」变成「自己动手验证」**。

> 「企业不该在托管 AI 的简便与对最敏感信息的掌控之间做二选一。有了 Model Vault 和机密计算，客户可以在发送数据之前先验证将要处理它的环境。借助硬件证明，客户不仅拥有工作负载运行在安全机密计算环境中的密码学证据，还能验证自己的数据免于被未授权访问——哪怕访问方是 Cohere。」- Phil Blunsom，Cohere 首席技术官

### **敏感请求内容的端到端保护**

机密计算保护计算环境内部发生的一切。Model Vault 还保护敏感请求内容在前往该环境的路上。

Model Vault 不只依赖连接级加密，而是把应用程序负载端到端加密到经过证明的机密环境。加密后的请求可以穿过中间基础设施而不暴露内容，并且只有机密环境能解密它。响应在回程路径上同样受到保护。

这样既保留了托管 AI 平台的运维优势，又不会把客户请求的明文内容暴露给中间基础设施。

客户继续使用 Model Vault API 和熟悉的请求格式。这层额外保护内置在客户端与基础设施层，不需要应用重新设计自己的负载。

### **基于 Microsoft Azure 与 NVIDIA 构建**

公开测试由 **Microsoft Azure 上的 NVIDIA H100 GPU** 提供支持。

Microsoft Azure 提供底层的机密计算基础设施，NVIDIA Confidential Computing 则把这些能力扩展到 NVIDIA H100 GPU 上。Cohere 通过 Model Vault 的托管模型服务、加密请求路径、远程证明和客户侧验证，把这些技术整合到一起。

最终得到的是一个托管 AI 平台：既有云端 AI 的运维简便，又能在推理期间对敏感数据的访问实施更强的技术管控。

> 「企业需要有把握：他们最敏感的 AI 工作负载所受的保护，不只是合同承诺。我们与 Cohere 在 Model Vault 上的合作表明，机密计算如何把托管 AI 的简便与可独立验证的技术控制结合起来。」- Vikas Bhatia，Microsoft Azure 机密计算产品负责人

> 「机密计算为那些需要在高敏感数据上运行 AI 的企业打开了新的可能。NVIDIA GPU 上的 NVIDIA Confidential Computing 提供硬件支持的保护，帮助 Cohere Model Vault 这样的平台把机密 AI 推理带进企业工作负载。」- John Fanelli，NVIDIA 企业软件副总裁

### **为敏感的企业工作负载解锁 AI**

对许多组织来说，问题已经不再是 AI 能不能完成某项任务，而是这项任务所需的数据究竟能不能安全地与 AI 一起使用。

Cohere Model Vault 上的机密计算正是为保护这类工作负载而设计的——出于安全、合同或监管要求，有价值的数据此前可能一直被挡在托管 AI 平台之外，包括：

- 金融服务中的欺诈调查
- 法律服务中的特权文件检索与尽职调查
- 敏感的公共部门信息
- 专利与研究材料
- 专有工程设计文档（EDD）、接口设计文档（IDD）和架构材料
- 跨专有源代码的搜索与分析

正是这类工作负载：减少特权基础设施访问、并给客户可独立验证的证据，能让此前受限的 AI 用例变得切实可行。

机密计算并不能消除全部风险，也不能取代应用安全、合规、合同控制或数据驻留要求。它提供的是一道由硬件强制、可验证的保护边界，在推理进行期间把数据和计算圈在其中。

### **现已开放公开测试**

**Cohere Model Vault 上的机密计算现已开放公开测试，由 Microsoft Azure 上的 NVIDIA H100 GPU 提供支持。**

客户可以通过 Model Vault 创建并管理加密的保管库，并用同一套 Cohere API 完成集成；客户侧验证与端到端加密会在敏感请求内容离开客户环境之前为其提供保护。
