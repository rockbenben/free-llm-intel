# 推出 North Automations：智能工作流编排

我们很高兴宣布 [North Automations](https://cohere.com/north/automations) 上线。这是 Cohere 帮助企业轻松弥合 AI ROI 缺口的最新一步——从底层内建控制与治理。

AI agent 在企业中的快速扩散带来了一整套新挑战，正在拉大 agentic AI 潜力与实际落地之间的差距。这些挑战包括：

- **狭窄的工作流：**一次性的 agent 只解决狭窄任务，而不是模拟员工跨系统、跨团队实际工作方式 end-to-end 的工作流。
- **缺乏治理：**agent 在业务中碎片化的落地，使大规模治理使用成为不可能。
- **成本：**在流程所有步骤上沿用同一个模型导致预算虚高；为流程的每一步路由合适的模型正变成刚需。

这些市场挑战导致 ROI 十分有限。

*"当前的 AI agent 落地大多由单个、任务专用的 agent 构成，只能带来渐进式收益，却为企业级 AI 采用留下了价值缺口，"* Gartner 研究分析师 Anushree Verma 和 Alastair Woolcock 在《Agentic AI Hype Cycle 2026》报告中指出。这种碎片化限制了 AI agent 的变革潜力，并造成失控的安全与风险问题。

Agent 编排代表企业 AI 的下一个进化阶段和关键缺失环节：从孤立的任务自动化走向协同的、结果驱动的工作流。这个 [**5500 亿美元的市场机会**](https://www.gartner.com/document-reader/document/code/841867?ref=authbody&refval=7671861)直击企业今天面临的核心 ROI 挑战——提供一个集中层，协调企业内多样化的 agent，同时在规模上交付企业级的治理与安全。

## North Automations 的关键特性

Automations 的设计目标就是弥合 AI ROI 缺口，从底层内建简洁、控制与治理。它由 Cohere 安全的 agentic 平台 **[North](https://cohere.com/north)** 驱动，让不同技术能力的员工都能：

**1. 把复杂工作流变成简单产出**

- 用平实语言描述目标，连接你的技术栈。
- 通过定时运行设定频率。
- 用循环与分支创建清晰、可审计的执行路径。

**2. 每一步都保持掌控**

- 在流程的每一步选择合适的模型，在成本与性能之间平衡。
- 用 Plan mode 在构建前审阅并修改你的方案。
- 用版本管理跟踪随时间推移的每次修改。
- 发布到生产前先测试和迭代。

**3. 安全地规模化治理 AI**

- 识别需要拉同事审批的关键节点。
- 分析 automations 的长期使用并识别最活跃的用户。
- 监控输入和输出 token 消耗以管理成本。

Automations 内嵌于 Cohere 的全栈 agentic 平台 North 之中，North 使企业能够：

- 在任何本地或云环境安全部署。
- 在你的技术栈内互操作：使用我们的第一方集成、为任何自定义工具接入 MCP，或用我们的 SDK 驱动定制的 agentic 平台。
- 灵活选择 Cohere 高效的企业专用生成或搜索模型，或任意外部 LLM。
- 借助护栏、分析、细粒度的角色与权限，保持完全的可见性与控制。

## North Automations 的用例

在 Cohere，我们已在多个业务部门使用 Automations 简化工作方式。一些例子：

我们的**营销运营团队**创建了一个 automation，简化获取营销活动表现洞察的流程。

> "我们通过 BigQuery 连接到我们的数据语义层。North 把平实语言的问题翻译成 SQL、运行分析并立即返回答案，消除了分析瓶颈、加速获得洞察，把分析师解放出来投身更具战略性的工作。"– Martin Guzman，Cohere 高级营销分析与数据运营经理

我们的**客户成功领导团队**搭建了一个每日客户互动跟踪 automation，随时掌握客户健康度与沟通情况。

> "我们的 automation 从 HR 系统拉取当前团队成员，与该名单对比每日日程，匹配 1:1 会议对象，然后针对匹配到的 CSM 在 Slack、Salesforce 和其他来源搜索活动摘要与待办事项。接着它把这些摘要整理成一条晨间 Slack 消息发给我们审阅，帮助经理与 CSM 进行聚焦而有成效的 1:1 会议。没有 North Automations 就做不到这种细节程度。"– Derek McNeil，Cohere 客户成功高级经理

我们的**销售团队**搭建了一个 automation，更高效地准备潜在客户通话。

> "通过汇总 Salesforce 商机、Slack 对话和 Gmail 会话、Notion 里的个人笔记以及外部市场研究的洞察，并整合成一份演示材料，我们把准备与探需流程提升到了新层次，专注于深入理解客户并与客户建立牢固关系。"– Shaun Paga，Cohere GTM
