# North 2：不妥协的企业级 AI

North 2 是 Cohere 迄今为止最大的一次升级——把企业级安全、智能、成本治理和全栈控制统一到单一 agentic AI 平台，运行在你的数据所在的任何地方。

关键要点

- **全新的 agent harness: **North 2 拥有重新设计的编排系统，能在整个企业范围内支撑更复杂、更可靠、多步骤的自动化与 agent。
- **更强的智能：**用 memory、libraries、skills、artifact 与应用创建能力，构建更聪明的工作流程和更丰富的 agent 对话体验。
- **Model agnostic（模型无关）：**无论你用的是 Cohere 的模型——还是自带模型——都可以用支撑团队最佳产出的那些模型。
- **AI 主权：**你将完全掌控 AI 在哪里、如何运行，支持灵活的云端、本地（on-premises）和 air-gapped（物理隔离）部署。
- **企业级治理：**North admin 新增细粒度成本控制、速率限制、用户配额和全组织上限，让 AI 运行可预测、受治理。

过去几年，企业一直在竞相部署 agentic AI，并为此付出了复杂性、成本和妥协的代价。每个选项都要求某种牺牲：安全够强的平台不够聪明；聪明的又不够可控；能治理的，规模化运行又太贵。

[North 2](https://cohere.com/north) 是这种权衡终结的地方。

过去一年，Cohere 已把 North 推广到金融、医疗、电信、制造、能源和公共部门等高风险行业，并大规模投入生产级部署。这些积累把 North 2 打磨成一个全栈 agentic 平台，为那些在安全、智能、成本或控制上输不起的组织而建。企业选择 North，是为了让通往 AI ROI 的旅程更可预测、更透明，并完全由企业自己掌控。

下面看看实际是什么样子。

## 与你的企业一起扩展的智能

North 本就基于你的知识工作，而现在你可以教给它更多关于「成功」在你组织内意味着什么。

用户现在可以创建可复用的 agent 和自动化，并在整个组织内共享，不必一再重建相似的工作流。直接在对话里做文档或应用的原型，或把 North 连接到你常用的既有工具。

North 2 的核心是一个先进的 agent 编排系统，可独立管理复杂的多步骤流程。用简单 prompt 构建 agent 和自动化，把最繁琐的工作流自动化——在真正要紧的地方把 human-in-the-loop 保留给人。

### North 2 包含的核心能力

- **Skills**：agent 可随时调用的可复用能力，让任何员工都不必浪费时间重建同一套逻辑。
- **Libraries**：整个组织都可取用的共享知识与资产。
- **Memory**：跨会话保持上下文的 agent，而不是每次都从零开始。
- **Applications**：用自然语言从原型到交付 deck、dashboard、文档和轻量应用。
- **Automations**：面向常见流程的预置模板、拖拽式可视化工作流构建器、实时性能监控，以及与你已在使用的工具的集成。
- **Connectors**：把 North 连接到你的数据，新增的 connectors 包括通往 Slack、SharePoint、OneDrive、Microsoft Outlook、Microsoft Exchange、Jira、Linear、Notion 和 GitHub 的企业连接器，以及计划中的金融数据提供方 PitchBook、Crunchbase、Daloopa、FiscalAI、S&P Global、FactSet 等。

LG CNS 借助 North，把 AI 规模化地带给韩国各地的客户，释放真实的业务价值。

> “North 为企业提供了一个安全、务实的基础，把 agentic AI 转化为真正的业务价值。我们在 LG CNS 内部使用 North、并把它带给韩国各地客户的经验，强化了我们的信心：它能够在整个企业范围内扩展智能自动化。”— Yohan Jin，LG CNS AI Center 负责人

## 企业优先的安全

Agentic AI 改变了每个企业安全团队的风险算式。当 agent 触及内部工具、当模型面临 prompt injection 暴露风险，保护数据从未如此重要。

North 正是为这种现实而生。它可以私有部署——on-prem、云端或完全 air-gapped——而 North Admin 让团队在单个 agent 层面执行护栏，因此把 agentic AI 推向全体员工，不等于把风险一起推了出去。你的知识图谱会越来越聪明，而你的知识始终保持安全，从不冒离开本地的风险。

### North 2 包含的核心能力

- **部署灵活性：**选择最符合你安全需求的部署环境（self-hosted、VPC、混合或 on-premises）。
- **超越全球安全标准: **持有 SOC 2 Type 2、ISO 27001 和 ISO 42001 认证。
- **Guardrails: **获得用于过滤内容、提升安全性、校验模型响应的护栏。
- **自主性策略: **构建只执行其被授权操作的 agent，并在关键决策或行动上寻求人工监督。
- **严格的安全：**通过持续安全测试（包括红队演练和第三方漏洞扫描）主动识别并缓解潜在威胁。
- **系统可观测性: **用易用的工具监控服务性能、获取所有变更的详细日志，洞察 North 的运行状况。

再举一个例子，Bell Cyber 正与 North 合作，把政府级安全带入 agentic AI。

> 在 Bell Cyber，我们每天都能看到威胁格局演化得多快，也深知安全与数据主权对我们保护的组织有多重要。North 让我们能够把 agentic AI 引入安全运营，而客户所要求的控制、隐私与主权从一开始就内建其中。这一点不仅对我们加强 Bell 和客户的防护很重要，对帮助加拿大企业和政府安心、有信心地采用 agentic AI 也很重要。— Jawed Ahmad，Bell Cyber 首席技术与 AI 官

## 细粒度控制，更好的 token 经济性

North Admin 提供企业级控制。管理员设置角色与权限，控制哪些模型在哪里、被谁使用。此外，管理员可以通过详细分析实时监控和管理活动，获得 AI 投资用量的细粒度明细或系统级总览，包括 token 支出与限额。

在设定限额之前，可先通过告警阈值提示团队风险。无论你的组织衡量的是采用度还是模型消耗，Cohere 都提供度量 AI ROI 的工具。

### North 2 包含的核心能力

- **North Admin: **把可见性配置到你想要的层级，细到用户和 agent 级别，让企业确切知道 AI 正如何被使用，并据此设置护栏。
- **细粒度访问控制与权限: **与你现有的身份与访问管理系统集成，获得更强的认证和细粒度的管理控制。
- **Flow control: **通过按请求数和 token 速率为用户与组定义消费层级，监控并控制 token 支出与限额。
- **高效的 token 消耗: **在 NVIDIA 硬件上运行 Cohere 模型时，获得更高的每节点 tokens per second，有效降低成本。
- **自带你组织的现有模型: **North 是 model agnostic 的，既可以用我们的生成式模型产品，也可以带上你偏爱的模型。

此外，我们与 [NVIDIA](https://www.nvidia.com/en-us/data-center/technologies/blackwell-architecture/) 的协作发现：在 [NVIDIA Blackwell](https://www.nvidia.com/en-us/data-center/technologies/blackwell-architecture/) 和 Hopper 上训练并部署的 Cohere 模型，让 North 用更少的 token 产出更多洞察。这意味着更少的 token 支出，同时不牺牲模型智能。关于我们模型的更多信息见[这里](https://docs.cohere.com/docs/models)。

> “组织需要掌控他们的 AI 在哪里运行、数据如何受到保护，”NVIDIA 研究生成式 AI 的副总裁 Kari Briski 表示。“NVIDIA Blackwell 和 Hopper 加速了 Cohere 模型的推理，帮助 North 2.0 用更少的钱产出更多 token。”

对那些要求在 AI 投资上看到严谨性的组织，North 2 带来的是生产就绪的全栈 AI 解决方案。借助 North，你得到端到端、可定制、有能力且安全的工具，它们与现有系统集成并帮助保护敏感数据——把团队引向真正赋能人的 AI 之路。

North 生来就是可以被拥有的，而且它越来越能被专业化。有了 North，即使监管最严的行业也能安心采用 agentic AI，因为他们的部署与其运营、合规和治理需求保持一致。
