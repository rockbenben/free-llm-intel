# 推出 North Mini Code：Cohere 首个面向开发者的模型

小巧、高效、开源——我们的首个 agentic 编程模型，为主权开发者生态而生。

今天，我们开源发布 North Mini Code。North Mini Code 是一个 mixture-of-experts（MoE）模型，是 Cohere 的首个 agentic 编程模型，也是我们下一代强大模型的开篇成员。

总参数 30B、激活参数仅 3B，North Mini Code 在不需要对等庞大硬件的情况下交付强劲的软件开发表现。它以效率为设计初衷，为在你需要的地方运行而生。

North Mini Code 以 [Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0?_gl=1*gri8sk*_gcl_au*MjU0OTU5MzQwLjE3Nzk4MDczMTc.) 许可证自由开放，推进 Cohere 让主权 AI 成为现实可行之物的使命，赋予开发者对 agentic 编程能力的直接访问权。我们公开构建，因为 AI 的未来应由运行它、测试它、改进它的人来塑造。

在 [Hugging Face](https://huggingface.co/CohereLabs/North-Mini-Code-1.0) 下载权重（[bf16](https://huggingface.co/CohereLabs/North-Mini-Code-1.0)、[fp8](https://huggingface.co/CohereLabs/North-Mini-Code-1.0-fp8)、[w4a16](https://huggingface.co/CohereLabs/North-Mini-Code-1.0-w4a16)），或在 [Model Vault](https://dashboard.cohere.com/welcome/login) 上部署到专属托管推理环境。也可以在你选用的 harness 中试用：[OpenCode](https://opencode.ai/)、[OpenRouter](https://openrouter.ai/cohere/north-mini-code:free)，或配合一个 [Cohere API key](https://dashboard.cohere.com/)。分享你的构建成果并在 [X](https://x.com/cohere) 或 [Discord](https://discord.com/invite/co-mmunity) 上 @Cohere，或在 [Reddit](https://www.reddit.com/r/LocalLLaMA/comments/1tylzy2/coheres_unreleased_coding_model_early_access_for/) 上与我们交流。

## Agentic 编程能力

North Mini Code 在与同尺寸级别模型的基准对比中取得有竞争力的分数，展示了在真实世界软件工程任务上的强劲表现。

图 1：North Mini Code 在 agentic 软件工程、终端任务以及复杂代码生成基准上，与同级别领先开源模型的对比。¹ ²

North Mini Code 的基准分数[折算为 Artificial Analysis Coding Index 的 33.4](https://artificialanalysis.ai/models/north-mini-code)，在同等尺寸模型中位居有竞争力的位置。

## 开发者任务的速度优势

North Mini Code 为速度与效率而设计，并高度聚焦于在持续打磨和扩展模型的过程中最小化总拥有成本。

在我们的测试中，North Mini Code 在相同并发和硬件配置下，输出吞吐最高达到 Devstral Small 2 的 2.8 倍。换算到实际使用，接近三倍的干活速度，让迭代更快、计算开销更低。

North Mini Code 还在 token 间延迟（inter-token latency）上展现了 30% 的优势——该指标反映 token 生成的连贯性与节奏。两者的首 token 时间（TTFT）表现较为接近，在测试条件下 Devstral Small 2 略有领先。

图 2：在高并发与低并发下，North Mini Code 与 Devstral Small 2 的输出速度与延迟对比（内部测试，使用编程类 prompt）。

## 面向开发者的主权开放模型

North Mini Code 是我们首个面向开发者的开源模型。当 coding agent 正在改变软件工程时，开发者需要对自己的 agentic 编程基础设施拥有控制和灵活性。

North Mini Code 代表了小型 agentic 编程模型向前迈出的一步——它们能完成对开发者真正重要的任务。具体地说，它为 agentic 工作流而生，包括理解和编排 sub-agent、梳理系统架构、执行代码评审。按你自己的条件在本地或 on-prem 部署。

社区反馈将直接塑造我们的路线图，随着我们把生态扩展向更多开放、主权的开发者模型。当你需要摆脱厂商约束时，试试 North Mini Code，并帮我们一起构建下一步。

## 下一步是什么？

North Mini Code 作为 Cohere 新一代强大模型中的第一个发布——但显然不会是最后一个。这一代模型为更主权、更开源的生态而生。

我们致力于不断提升能力，并以社区输入决定接下来的方向。
