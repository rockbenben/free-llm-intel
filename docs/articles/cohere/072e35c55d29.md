# 文化漏斗：不在数据里的东西，就无法对齐

Cohere Labs 分析了现代 LLM 训练管线的数据，发现文化多样性经常在 post-training 数据配比中流失。

核心要点

- 构建全球包容的 AI 需要超越多语言。一个模型可能精通数十种语言，却依然错过塑造人们交流方式的文化规范、价值观与社会语境。从多语言走向多文化 AI，是构建更好服务世界各地人群系统的下一步。
- 当前让 LLM 对齐不同文化视角的做法聚焦于推理时干预，其假设是模型已经包含足够的文化知识，只需在用户 prompt 需要时将其引出。然而，我们对训练管线各阶段流行数据集的分析结果挑战了这一假设。
- 我们发现 **现代 LLM 管线深受"文化数据漏斗"之苦：**post-training 数据丢失了大量文化多样性，且领域选择进一步塑造了留存下来的文化内容。
- 我们的发现提示 AI 开发者必须更仔细地审视文化在训练数据本身中如何表达。仅扩展 LLM 的多语言能力并不保证文化上丰富的代表性。它需要包含更广地区覆盖的数据，以及对文化代表性内容的刻意策划。在训练数据内部让文化更显性，在帮助 LLM 更好保留多元、代表性不足的文化维度上显示出可观的前景。

随着 AI 系统日益全球化，只关注多语言覆盖不足以构建服务全世界人群的系统。模型可能以数十种语言流利作答，却依然错过人们交流背后的语境——本土规范、价值观、假设、社会期望，或文化如何塑造日常互动。[文化觉察正变得与语言覆盖同样重要](https://cohere.com/blog/why-cultural-awareness-is-essential-for-global-ai)。但为什么文化差距持续存在？

研究这个问题的一个核心挑战是：文化本身天然难以量化——它以隐性的方式渗透在几乎所有用户交互中，受语境塑造，无法仅靠语言或地理完整呈现。一个常见假设是文化知识已经存在于训练好的语言模型里，只需通过 prompting、对齐或更好的推理把它引出。但如果限制更早就开始呢？在这项工作中，我们向上游看——看数据本身。

为了更好地理解文化差距可能源自训练数据的哪里，我们最近的预印本 [The Culture Funnel: You Can't Align What isn't in the Data](https://arxiv.org/pdf/2606.13808) 提出了一个框架，用于在训练数据中大规模浮现并检视文化信号。用这副透镜，我们追踪文化代表性在 LLM 训练管线不同阶段如何变化，并探讨这些模式对构建更好容纳多元文化语境 AI 系统的启示。

在分析了语言模型训练管线各阶段超过 560 万个[训练数据样本](https://huggingface.co/datasets/CohereLabs/CultureMarkers)后，我们发现一个一致的模式：文化多样性随着数据从 pretraining 流向 post-training 而收窄。我们把这一现象称为*文化漏斗（the culture funnel）*。我们的分析考察了与这一模式相关的若干因素，包括 post-training 数据集的构成、文化内容的长尾效应，以及数据策划实践。

通过我们的分析，我们延伸了 [2025 年一支研究团队提出的原则](https://arxiv.org/pdf/2509.01301)："每一次评估和每一次数据选择都应从文化情境化的考量来审视"——由此确立文化作为数据文档、处理和评估中的首要因素之一。

## 沿训练管线寻找文化

为了理解文化信息如何在模型开发全程出现，我们选取了 LLM 训练各阶段——pretraining、SFT、对齐、推理——常用的数据集，并为每个来源的抽样 prompt 打上文化信号标签。我们使用 Cohere 的 Command A 模型按照我们给出的指令自动标注 prompt，并通过人工复核六种语言的部分 prompt 来验证生成标签的质量。重要的是，我们不把语言或地理当作文化的替身。我们标注的文化信号反映文化的多个维度：领域、任务意图、语言、地理位置和文化特征。文化特征的定义基于 [AlKhamissi et al. (2026)](https://arxiv.org/pdf/2510.05931) 开发的一套分类法，它对常用评估基准进行分类（示例见下）。这让我们得以考察随着模型穿过训练流程，文化代表性如何演化。

## 发现 1：文化信号在 post-training 数据中流失

**文化信号的占比沿训练管线递减：pretraining 数据中占比较高，到 post-training 数据集则所剩无几甚至完全没有。**

我们的第一个观察是我们命名为*文化漏斗*的现象：pretraining 数据的文化根基（被打上文化标记的数据占比）远高于任何 post-training 数据集。为什么会这样？旨在提升 LLM 推理或对齐能力的 posttraining 数据集，往往把重心大幅放在技术任务上：做数学计算或写代码。考虑到 LLM 在这些任务上的表现已取得巨大提升，这也许不意外，但这意味着含有更高文化标记占比的数据集变得不再显眼。其结果是，LLM 学习和反映多元文化知识的机会可能减少了。

我们还发现，留下来的文化内容大多落入*文化知识*或*一般文化*两类（即含食物、节日、命名实体、翻译语境等文化实体的数据）。这种失衡有助于解释为什么模型在事实型或 trivia 型文化基准上表现尚可，却在需要对[隐性文化偏好、规范或社会动态](https://arxiv.org/html/2504.01127v1)进行推理的任务上更加吃力。如果文化在整个训练过程中消失，模型可能只更擅长解决抽象问题，却失去支撑其众多多元用户语境所需的文化理解。

## 发现 2：更多语言意味着更多地理多样性，但不意味着更多文化……

多语言 AI 中最常见的假设之一，是加入更多语言自然会带来足够的文化覆盖。我们的结果表明这种关系更复杂。

**随着更多语言加入，地理多样性持续上升，而文化内容的整体占比趋于平缓。**

当我们逐步累加数据集中各语言集的数据时发现：扩大多语言覆盖，对提升 pretraining 和 SFT 数据集中文化根基数据的整体占比存在边际递减（上图中浅蓝色线）。文化内容的占比更多由数据策划策略决定：例如 [Aya 数据集](https://arxiv.org/pdf/2402.06619)的文化内容占比高得多，因为它刻意从国际贡献者社区策划了文化根基的 prompt 与回复。

不过，加入语言会使各数据集中出现的唯一地理位置数量增加。因此，扩展多语言并不提升数据中文化主题内容的整体占比，但确实提升其地理多样性。这意味着：越是多语言，模型就可能习得关于世界更多地区的知识。

## 发现 3：文化数据中的地理代表性严重偏斜

**pretraining 数据中文化内容的前 50 个地理位置分布严重偏斜。**

检查地理位置标签时，我们看到某些地区的代表性远高于其他地区。这一模式我们从[以往研究](https://aclanthology.org/2022.aacl-main.62.pdf)对大数据中语言分布的观察中早已熟知：它们遵循长尾分布，少数语言主导多数 NLP 资源。我们发现文化代表性的表现类似。在我们的分析中，被标记为文化的子集内，印度是最常被代表的地理位置，伴随的是亚洲和欧洲国家的集中。以上文图示的 Cultura X 为例，前 50 个地理位置中只出现一个南美国家、一个非洲国家和一个北美国家。

除印度外，中国和美国也是主导位置，在其他数据集里同样排名前十之内。后果是，在这份数据上训练的模型会在整个训练管线中被偏袒。而与之相比，与代表性不足地区相关的文化知识对模型会特别难学——即便当地语言有充分代表。

## 文化到底在哪里重要？

**标准训练数据集与 ShareLM 中各任务的文化占比，与调研回答的对比。**

Post-training 的知识以任务为中心：先围绕用户任务策划数据，再进行多任务微调。上图突出各任务间文化内容的分布。我们发现翻译、本地信息请求和消息撰写含有最强的文化信号。更技术化的类别（如编程或医学问题）含较少显性文化标记。当我们把这些模式与我们的[用户调研](https://cohere.com/blog/why-cultural-awareness-is-essential-for-global-ai)对比时，一幅更有意思的图景浮现：用户报告最需要更好文化觉察的场景是创意写作、翻译和邮件/消息撰写——恰与我们分析中训练数据承载文化最多的任务一致。此外，文化觉察的相关任务范围比当前训练分布所反映的更广，例如也出现在医疗和商业语境中。

## 我们能找回文化知识吗？

对训练数据集中文化标记的分析使一件事很清楚：文化内容在现代 AI 系统底层数据中稀疏分布。改善整条数据管线中的文化代表性，需要的努力远超单纯扩展数据规模——它同样要求刻意的策划以纳入多元文化覆盖。理想情况下，我们会用社区来源的数据从头解决这一问题，让数据更好反映多元全球视角。但实践中，跨所有可能的领域、任务意图和地理位置大规模做到这一点既昂贵又难策划，稀疏性仍将不可避免。因此，除了收集更多数据之外的干预措施仍然必要。

[我们早期的研究](https://arxiv.org/pdf/2506.14702v1)表明，在微调数据中加入显式标记能帮助模型更好学习长尾分布。受此启发，我们在微调 [TinyAya](https://arxiv.org/abs/2603.11510) 基础模型时添加文化标记——不改变数据分布，而是为每个训练样本增加元信息。也就是说，我们不是把数据做得"更文化"，而是让文化内容更显性，给模型一个即便文化表征稀疏也能学到文化属性的机会。我们观察到下游文化基准的表现在不牺牲通用多语言能力的前提下有所提升：NormAd +8%，BBQ +6%，GMMLU +2.3%。

更常见的替代方案——不加任何标记、直接用"更文化"的数据训练——在文化基准上的提升更小，还伴随通用能力的退化。

## 建议

在整条训练管线中，我们观察到文化多样性从 pretraining 到 post-training 数据的一致收窄。我们的发现指向驱动这一文化漏斗的三个关键因素。

- 领域构成强烈决定文化信息出现在哪里，而 post-training 数据集越来越优先数学和代码这类显性文化信号较少的领域。
- 仅扩展多语言并不保证文化上的多元代表性：地理位置覆盖仍高度不均，少数地区被不成比例地代表，更广的语言覆盖不一定转化为更广的文化覆盖。
- 需要文化觉察的任务范围，远比当前训练数据分布所反映的宽。

我们的发现突出现代 AI 数据中文化代表性天然的长尾属性。更重要的是，我们发现数据管线本身就是对齐机制——它塑造了哪类文化知识对模型仍然可学。作为最佳实践，这意味着超越单纯的多语言规模，转而在语言、地理位置、领域和任务意图之间刻意平衡代表性。我们还发现，在训练中显式标记文化维度，可以帮助模型更好保留并学习长尾的文化属性。

归根结底，LLM 的文化能力不会从单纯扩大数据自动涌现，而来自刻意设计让文化的诸多维度可见、有代表、可学习的数据管线。
