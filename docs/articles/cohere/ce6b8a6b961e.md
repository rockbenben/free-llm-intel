# 推出 North Small Translate：领先的开放权重主权机器翻译模型

性能超预期，规模恰到好处——为速度和成本效率而生的翻译。

今天，我们发布 North Small Translate，一个 mixture-of-experts 机器翻译模型，在 50+ 种语言上表现强劲。在 WMT26 基准上，¹ North Small Translate 全部语言得分 83.6，超过 DeepL 和 Google Translate 等专有模型，以及 Gemma 4 31B (off)、GLM 5.2、Mistral Large 3 等开放权重替代品。

North Small Translate 是一个重要里程碑——它是 North 模型家族中的首个翻译模型。它建立在我们的多语言与翻译血脉之上——从 [Tiny Aya 模型家族](https://cohere.com/blog/cohere-labs-tiny-aya)到 [Command A Translate](https://docs.cohere.com/docs/command-a-translate)——标志着 Cohere 在一切需要之处提供高质量机器翻译承诺的清晰下一步。

North Small Translate 现以 [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/deed.en) 许可证开放用于研究和非商业用途，推进 Cohere 让主权 AI 成为技术现实的使命。

前往 [Hugging Face](https://huggingface.co/CohereLabs/North-Small-Translate-1.0) 下载权重（提供多种近乎无损的量化版本），在 [HuggingFace space](https://huggingface.co/spaces/CohereLabs/North-Small-Translate-1.0) 体验模型演示，并阅读我们的[实施指南](https://docs.cohere.com/docs/north-small-translate-1.0)。

### 开放生态中的领先翻译质量

North Small Translate 在机器翻译的多个维度上，平均表现优于 1T 参数以下的同量级开放权重模型以及基于 API 的翻译模型。在 WMT 模型评测中，North Small Translate 以 WMT26 All Languages 基准 83.60 的得分领先——对比 Qwen 3.5 397B A17B 的 81.56、GLM 5.2 FP8 的 76.50、DeepL NextGen 的 81.37、Gemma 4 31B (on) 的 79.46、Google Translate 的 68.20。North Small Translate（Agentic）——能够发现并修正翻译中的错误——得分更高，达到 84.36。²

图 1：以 GPT-5.6-Sol 为评审、按 WMT 2026 评测的主要模型在所有语言上的 WMT26 总分。

North Small Translate 在 32 种高资源语言和另外 18 种语言上均表现强劲。在所有地区跨度中，它是稳定性最好的模型，没有同尺寸其他模型那种剧烈的地区性下滑。在所有语言的平均值上，它是本次评测中表现最好的专用机器翻译模型——无论开放还是闭源。

图 2：以 GPT-5.6-Sol 为评审，DeepL、Google Translate、Gemma 31B (on) 与 North Small Translate 按地区平均的 WMT 总分。

在地区层面，North Small Translate 表现出超越自身体量的实力：在欧洲直接击败 Gemma 4 31B (on)（82.2 对 73.9），在南亚则基本与之持平（86.2 对 86.7）。

在地区层面，North Small Translate 及其 Agentic 版本在欧洲全面直接击败 Gemma 4 31B (on)——欧盟语言（Agentic 82.74 / 标准版 82.17，对比 72.73）和非欧盟欧洲语言（81.52 / 81.24，对比 75.90）——而在南亚基本与其持平（87.13 / 86.16，对比 88.04）。

两个版本还在我方测试的所有非欧洲地区——MENA、南亚、东南亚和东亚——胜过 DeepL NextGen：南亚和 MENA 优势最大（约领先 DeepL 8–10 分），东南亚为中等优势（约 4–5 分），东亚优势最小（约 1-3 分，标准版正在逼近 DeepL 的 85.41 分）。

### 更高吞吐，更快工作流

North Small Translate 为高吞吐生成而生，即使并发扩张也优先保证原始输出速度。

在我们的测试中，在相同并发与硬件配置下，North Small Translate 的输出吞吐最高达到 Gemma 4 31B TP1（1 x GPU）的 1.4 倍——低并发下 112 对 81 Output Tokens per Second（TOPS），高并发下 39 对 30 TOPS。换算到实际使用，即每秒多生成 30-38% 的 token，长输出的完成时间显著缩短。

图 3：在相同硬件的内部测试中，高并发与低并发下 North Small Translate 与 Gemma 4 31B (off) 的输出速度对比。

长文档是许多翻译模型崩溃的地方，North Small Translate 不在此列。它在我们的长上下文评测中得到 48.9 分，是 Google Translate（21.3）和 Gemma 4 31B（19.4）的两倍多，并领先我们测试的所有通用 LLM。³

加上吞吐优势，这意味着长文本上快速而可靠的翻译，没有多数非专用替代品那种质量崩塌。

### 规模化翻译的高效成本

效率是企业翻译部署的核心约束，我们把 North Small Translate 设计得极其成本高效，且不牺牲性能。

图 4：各机器翻译模型的整体 WMT 得分与单任务成本拆解，成本按模型提供商网站上的每 token 或每字符定价计算。

对正在评估 North Small Translate 商业许可的企业来说，它可以仅以每任务 $0.000676 的成本、平均只用 661 个 token，交付强劲的 80.1 分。对比 Gemini 3.1 Pro Preview (high)——每任务成本 $0.038928（比 North Small Translate 贵 5,762%）。

Qwen 3.5 397B A17B 和 Cohere 自家的 Command A+ 等同量级模型也有不错的表现，每任务成本分别为 $0.004525 和 $0.005158。

### 携手 RWS，翻译称雄

North Small Translate 与 [RWS](https://cohere.com/blog/rws-and-cohere-build-ai-language-intelligence) 合作开发——这是一家在语言技术与服务领域处于先锋地位、并因此成为顶尖 AI 语言技术合作伙伴的公司。与 RWS 的紧密协作——尤其是 Language Weaver 的研究与科学团队及其语言专家——在整个开发过程中塑造了模型的真实世界翻译表现。RWS 与全球百强品牌中的 80% 以上合作，帮助世界上最有雄心的品牌跨越国界与文化无缝沟通。

对于不满足于开放权重研究访问、还需要安全、可扩展以及专属翻译与本地化平台的企业，North Small Translate 可通过 RWS 的 [Language Weaver](https://www.rws.com/language-weaver/pro/) 产品获得。

### 脚注

¹ [WMT 基准](https://www2.statmt.org/wmt26/translation-task.html)侧重评估机器翻译（MT）系统的综合能力，首要目标是跨广泛的语言、领域、文体和模态测试性能。

² 关于 WMT 基准分数的解读，评分方法将性能区间定义为：0-20（不可接受）、20-40（临界）、40-60（可接受）、60-80（良好但有重大错误）、80-100（完美或仅有轻微错误）。

³ 长上下文评测衡量模型在单次调用中翻译一本书两个章节的能力。质量以 xComet-XL 指标逐段落独立测量。
