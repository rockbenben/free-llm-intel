# 推出 Cohere Transcribe：开源语音识别的新的先进水平

无与伦比的转写准确率——我们在 North 中赋能企业语音智能的第一步。

Cohere 宣布推出 Transcribe，一个先进的自动语音识别（ASR）模型，开源并即日起可[下载](https://huggingface.co/CohereLabs/cohere-transcribe-03-2026)。

语音正迅速成为 AI 工作负载与自动化的核心模态——从会议转写、语音分析到实时客服 agent。

我们的目标很直接：在现实条件下推进专用 ASR 模型准确率的边界。该模型从零开始训练，刻意聚焦于最小化词错误率（WER），同时始终把生产可用性放在头等位置。换句话说，它不是一件研究展品，而是一个为日常使用设计的系统。

Cohere Transcribe 体现了这份意图。它以开源方式提供、可完全掌控基础设施；保持适合实际 GPU 和本地使用的可控推理占用；提供同类最优的服务效率；也可通过 [Model Vault](https://cohere.com/solutions/model-vault)——Cohere 安全的全托管模型推理平台——获取。

Cohere Transcribe 目前在 HuggingFace 的 [Open ASR Leaderboard](https://huggingface.co/spaces/hf-audio/open_asr_leaderboard) 上准确率排名第一，为真实世界转写性能确立了新标杆。

这是我们从零到一，把高性能语音识别带进企业 AI 工作流的标志。继续阅读了解更多。

## 模型概览

| 名称 | **cohere-transcribe-03-2026** |
| --- | --- |
| 架构 | 基于 conformer 的 encoder-decoder |
| 输入 | 音频波形 → log-Mel 频谱图 |
| 输出 | 转写文本 |
| 模型规模 | 2B |
| 模型 | 大型 Conformer encoder 提取声学表示，随后由轻量 Transformer decoder 生成 token |
| 训练目标 | 对输出 token 的标准监督交叉熵；从零训练 |
| 语言 | 在 14 种语言上训练：**欧洲：**英语、法语、德语、意大利语、西班牙语、葡萄牙语、希腊语、荷兰语、波兰语 **亚太：**中文（普通话）、日语、韩语、越南语 **中东和北非：**阿拉伯语 |
| 许可证 | Apache 2.0 |

图 1：Cohere Transcribe 是一个开放权重的 Conformer ASR 模型，将语音音频转换为 14 种支持语言的文字。

## 模型性能

**准确率**

Cohere Transcribe 是英语语音识别准确率的新标准。它以仅 5.42% 的平均词错误率领跑 HuggingFace Open ASR Leaderboard，超越所有开源与闭源的专用 ASR 替代品，包括 Whisper Large v3、ElevenLabs Scribe v2 和 Qwen3-ASR-1.7B。这体现了模型在真实语音任务上的多面能力，例如对多人环境的鲁棒性、会议室式声学条件（如 AMI 数据集）和多样口音（如 Voxpopuli 数据集）。

**吞吐**

在生产环境中，ASR 系统必须在严格的延迟与吞吐约束下运行；即便准确，缓慢或资源消耗的转写也会直接影响用户体验、运营效率和成本。

Transcribe 扩展了帕累托前沿：在 1B+ 参数级模型阵营中，它既交付先进水平的准确率（低 WER），又保持同类最优的吞吐（高 RTFx）。

图 5：规模大于 1B 的领先模型的吞吐（RTFx）与准确率（WER）关系图。RTFx（real-time factor multiple）衡量音频模型相对实时处理输入的速度。
