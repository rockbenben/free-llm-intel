# 塑造 ML 研究的前沿

Cohere Labs 的 Scholars Program 为新兴研究者提供资源，去推进 AI 的边界。

状态：

已关闭

下一个截止时间：

我们正在演进 Research Scholars 项目，申请预计于 Fall 2026 开放

资格条件：

- 可全职投入
- 展现出对 AI/ML 的好奇心

收益：

- 来自 ML 专家的定制化 mentorship
- 可使用大规模实验环境来开展研究
- 有竞争力的薪酬

### 关于这个项目

Scholars Program 是一个 remote-first 的全职带薪岗位，按研究领域把新兴研究者与导师配对。Scholars 是 Cohere Labs 团队的重要贡献者。

Mentorship

从世界上最好的 ML 研究与工程专家那里获得定制化的 mentorship。

工具

使用我们的大规模实验环境，开展探索复杂 ML 问题的研究。

主导权

负责一个与你匹配的项目，发挥你的长处去探索高影响力的研究问题。
