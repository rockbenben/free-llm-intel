今天，我们正式更新 **MiniMax M3.1 Flash**。

此前以匿名身份处理了超过 200T Token 的 Space Bunny 🐰，正是 MiniMax M3.1 Flash 的早期版本。

**作为新一代 Flash 模型，M3.1 Flash 在 Agentic 任务、编程、Computer Use 及网络安全能力等方面实现了代际的提升，同时线上推理速度提升了近 3 倍，使用成本降低了 70%。**

### **模型能力全面提升**

M3.1 Flash 在多项基准测试中取得了全面进步，在复杂 Agent 任务（Cowork）、Computer Use、软件开发（Coding）及网络安全方面，达到了领先模型水平。

![](https://filecdn.minimax.chat/public/m31-flash-zh-2-1792403273121-webp)

**复杂任务与自动化能力：**

- 在 AutomationBench-AA 中位居最前列。在跨 SaaS 系统的真实企业业务工作流中，能完整解决销售、营销、运营、客服、财务、HR 的真实问题。
- 在 BankerToolBench 中 76.2 分，擅长多步骤规划、跨文档 / 跨文件一致性、金融业务合规、工具链式调用等真实复杂问题。

**编程与软件工程能力：**

- 在 DeepSWE v1.1 评测中取得 73.7% 的成绩，达到顶尖模型水平。DeepSWE 聚焦复杂软件任务，要求模型独立完成代码理解、功能开发、问题修复与测试验证。M3.1 Flash 展现出出色的长链路任务执行能力，能够以更低的成本支持复杂的软件开发工作流。

**Computer Use 能力：**

- 在衡量 AI 电脑操作与跨应用任务执行能力的 OSWorld V2 中取得 61.7 分，在衡量真实并有经济价值场景下电脑操作能力的 Agents' Last Exam（ALE）中取得 29.6 分，两项得分均位列国产模型第一。
- M3.1 Flash 展现出出色的真实环境交互、工具使用与长链路任务执行能力，能够从理解任务进一步走向实际操作与交付。

**网络安全能力：**

- 在 CyberGym 基准测试中取得 82% 的高分，展现出领先的漏洞发现与验证能力。
- 经内部安全专家深度评测，模型在代码审计、漏洞修补、渗透测试、恶意代码分析与逆向工程等场景下均表现出色，能够以低成本、高效率支持复杂的安全体系建设。

我们进一步优化了 M3.1 Flash 的推理效率，使用了更激进的稀疏注意力架构，日常使用场景下的输出速度可达 200+ TPS（Tokens per Second），中位数（P50）稳定达到 170+ TPS。

### **模型价格**

在 Agentic 类任务中，模型的综合使用成本较前代模型降低了 70%。输入价格为每百万 Token 1 元，输出价格为每百万 Token 4 元，缓存读取价格为每百万 Token 0.1 元。

![](https://filecdn.minimax.chat/public/m31-flash-pricing-cn-1792408628164.png)

### **重新定义 Agent 任务的能力和成本**

在衡量复杂 Agent 任务执行能力的 Automation-Bench、衡量真实编程能力的 DeepSWE，以及衡量真实并有经济价值场景下电脑操作能力的 Agents' Last Exam（ALE）三项基准测试中，M3.1 Flash 以极低的任务成本实现了顶尖模型级别的性能表现，在性能与成本之间建立了极具竞争力的新标杆。
