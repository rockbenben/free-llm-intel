## 要点

- Meta 推出了 Muse Wonder 和 Muse Wonder Full，这是我们迄今为止最强大的模型，旨在为个人和专业代理任务提供最先进的性能 - 从处理保险索赔到理解租赁，再到构建工作应用程序。
- Muse Wonder 现已通过元模型 API 和 Muse Code 向开发人员和构建者开放，而 Muse Wonder Full 现已向 Muse Code 订阅者开放。
- Muse Wonder 很快将增强 [Muse](http://muse.ai) 的体验，并将首先向订阅者推出。

十四个月前，我们开始对人工智能工作进行彻底改革，在那段时间里，我们从重建基础转向推动前沿。今天，Meta 推出了 [Muse Wonder](http://research.meta.ai/blog/muse-wonder) 系列，包括 Muse Wonder 和 Muse Wonder Full，这是我们迄今为止最强大的模型，建立在我们与 [Muse Spark](https://about.fb.com/news/2026/09/introducing-muse-personal-ai-agent/) 奠定的基础上。这些模型在个人和专业代理任务上提供了最先进的性能。

## 专为现实世界的需求而打造

无论工作是处理保险索赔、了解租赁还是了解某人的财务状况，模型都必须解释面前的信息并解决问题。 Muse Wonder 和 Muse Wonder Full 将该功能引入法律、金融和健康等专家领域，并为人们构建从游戏到新业务应用程序等各种内容的人员提供前沿编码性能。

真正的工作也会随着时间的推移而展开。这就是为什么我们构建了具有主动记忆功能的新模型，能够在对话中携带对您重要的内容，并带回与手头任务相关的细节。他们还具备主动专注能力，能够在任务变得困难时继续朝着目标努力，尝试其他方法，从错误中恢复，并坚持到底，在需要时要求澄清，并在完成任何重要事情之前进行检查。

## 我们如何构建安全

个人代理可以为您承担实际任务，这通常意味着处理您的消息、日历和文档。这就是为什么我们训练 Muse Wonder 家族避免在未经许可的情况下分享私人信息；拒绝协助实施实际有害行为的请求；并努力提高安全性并加强对网络攻击的防御。开发人员和安全团队可以使用 Muse Wonder 等模型来查找自己代码中的缺陷并增强其系统，因此我们确保这些模型仍然可以完成这项工作。我们根据[元超级智能扩展框架](https://research.meta.ai/blog/developing-capable-models-responsible)中规定的标准来训练、评估和发布我们最有能力的人工智能模型。包含额外安全评估的完整报告即将发布。

Muse Wonder 现已通过 Meta Model API 和 Muse Code 提供。它将很快为 [Muse](https://muse.ai/) 提供更多支持，并首先向订阅者推出。对于每个人来说，这都是迈向个人超级智能的重要一步，未来还会有更多的进步。

要详细了解这些模型的构建方式、测试方式以及它们的功能，请访问[我们的研究博客](http://research.meta.ai/blog/muse-wonder)。
