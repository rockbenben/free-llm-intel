## 要点

- Meta 推出 Muse Wonder 与 Muse Wonder Full，这是我们迄今能力最强的模型，目标是把个人和专业场景下的智能体任务做到业界领先水平——从走通一笔保险理赔、看懂一份租约，到搭出一个能用的 app。
- Muse Wonder 今天起通过 Meta Model API 和 Muse Code 向开发者和构建者开放，Muse Wonder Full 则今天起向 Muse Code 订阅用户开放。
- Muse Wonder 很快将为 [Muse](http://muse.ai) 里的体验提供支撑，并首先向订阅用户推出。

十四个月前，我们着手对整个 AI 工作做一次彻底改造；这段时间里，我们从重建底座一路走到推进前沿。今天，Meta 推出 [Muse Wonder](http://research.meta.ai/blog/muse-wonder) 系列，包含 Muse Wonder 与 Muse Wonder Full——这是我们迄今能力最强的模型，建立在我们在 [Muse Spark](https://about.fb.com/news/2026/09/introducing-muse-personal-ai-agent/) 上打下的地基之上。两款模型在个人与专业场景的智能体任务上都达到了业界领先水平。

## 为真实世界的需求而打造

不管是要走通一笔保险理赔、看懂一份租约，还是把一个人的财务状况理清楚，模型都得先读懂摆在它面前的信息，再把问题一步步解出来。Muse Wonder 与 Muse Wonder Full 把这种能力带进了法律、金融、健康等专业领域，同时提供前沿级的编程表现，服务于那些从做一款游戏到为一个新生意搭 app 的人。

真正的工作还会随时间铺开。所以我们让新模型具备 Active Memory——跨对话记住对你重要的东西，并在处理眼前的任务时把相关的细节重新取回来。它们同样配备了 Active Focus——任务变难时仍能朝着你的目标继续推进，换个思路再试、从错误里恢复、把事情做完，需要时主动询问澄清，而在任何重要的事情落地之前先跟你确认。

## 我们如何保障安全

个人智能体能替你接手真实的工作，而这通常意味着要在你的消息、日历和文档之间来回取用信息。正因如此，我们训练 Muse Wonder 系列时，让它不在未经许可的情况下分享隐私信息；拒绝那些要求协助造成真实伤害的请求；并致力于提升安全、加固针对网络攻击的防线。开发者和安全团队会用 Muse Wonder 这样的模型来发现自己代码里的缺陷、把系统做得更牢固，所以我们确保模型仍然能做这类工作。我们能力最强的 AI 模型，其训练、评测与发布都遵循 [Meta Superintelligence Scaling Framework](https://research.meta.ai/blog/developing-capable-models-responsibly) 设定的标准。包含更多安全评估的完整报告很快会发布。

Muse Wonder 今天起通过 Meta Model API 和 Muse Code 开放。它很快会支撑起 [Muse](https://muse.ai/) 更多的部分，并首先向订阅用户推出。这是迈向人人可用的个人超级智能的重要一步，后面还有更多内容。

想更仔细地了解这些模型是怎么构建的、怎么测试的、能做些什么，请到[我们的研究博客](http://research.meta.ai/blog/muse-wonder)。
