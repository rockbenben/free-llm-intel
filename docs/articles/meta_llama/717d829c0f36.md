## 要点

- Muse 是一个个人 AI agent。它不只是回答问题，而是真正替你干活：帮你把事情保持在掌控之中，接手你的任务与项目，把长期目标变成行动计划。
- Meta 从零开始构建 Muse，目标是让它成为一个安全、可靠、私密且人人可用的个人 AI agent。
- Muse 运行在 Muse Secure VM 上——一台拥有独立浏览器的专用安全计算机——并能跨用户日常使用的应用代为办事，从对话中学习、思考什么对你重要、并在这个过程中越来越敏锐。
- 每个人始终掌控自己的 Muse，由本人决定授予它多少访问权限。
- 想深入了解 Muse 的设计理念以及安全、防护与隐私如何内建于其中，请阅读 [How We Built Safety Into Muse](http://security.muse.ai) 和 [How We Designed Muse](http://introducing.muse.ai)。

今天，Meta 推出 Muse——一个安全、私密、能主动帮助用户达成目标并提出点子的个人 AI agent。由于个人 agent 需要一种全新的安全计算机，[Muse 运行在 Muse Secure VM](http://security.muse.ai) 上——一个专门托管该 agent 及用户数据的虚拟机（VM）。Muse 围绕人们已有的沟通方式设计，因此与它对话就像给另一个人发消息一样自然——可以在 Muse 应用里，也可以直接在 WhatsApp 中。

它上手极简。人们只要告诉 Muse 需要完成什么，它就会采取行动——由 [Muse Spark](https://research.meta.ai/blog/introducing-muse-spark-1-3) 提供动力。这是 Meta 迄今最强的模型，专为这类真实世界的 agentic 工作而打造。

## 运作方式

与其他 agent 不同，[Muse 为服务全球数十亿人而建](http://introducing.muse.ai)，因此没有学习曲线。任何人开箱即用，无需任何技术经验。它能处理发送电子邮件、预订行程这类任务，也能承接宏大的长期目标。一旦人们向 Muse 分享一个目标，它就会帮你制定个性化计划、统筹你的时间和资源，然后自行推进工作。它可以打开浏览器、填写表单，并代表你进行谈判。

对于耗时较长的任务，Muse 在你关闭应用后仍会继续工作，并在情况有变或需要批准时回来找你——比如发邮件或完成购买前都会先请示。它用更少的付出带来更好的结果：把车卖出更高的价、把账单降下来、随着生活节奏变化调整训练计划。

到了付款环节，Muse 可以使用 Stripe 打造的 Link 完成结账，它也是首个享有 [Link 购物保障](https://support.link.com/questions/what-s-covered-with-protections)覆盖的 AI agent：损坏或丢失商品的免费保障、降价保护、免手续费退货，以及合格购买的退货保证。Link 面向 agent 的钱包会生成一次性使用的虚拟卡，让你真实的卡片信息保持隐匿，从而在整个互联网上安全购物。Shop Pay 作为另一种支付方式即将上线，1Password 支持也将加入，让 Muse 可以使用你已有的登录凭证。

Muse 还会记住对你重要的事，因此能主动提出建议，并基于你只提过一次细节采取行动。它可以把你存在 Instagram 上的一道菜谱 Reels 转成购物清单，为你的晚宴建议菜单，并在发出邀请前记得朋友们的饮食禁忌。

## 为私密、安全、可靠而生

个人 agent 需要一种全新的安全计算机，所以 Meta 为所有人造了一台。Muse Secure VM 内建了前所未有的隐私、安全与防护机制，这是其他 agent 所不具备的：

- Muse 运行在云端属于它自己的专用计算机上，隔离严密，其他人的 agent 无法触及。Muse 就居住在那里，人们连接的任何服务的数据与凭证也都安全存储在那里。
- 一个独立的 Sentinel agent 运行在同一台机器上，在系统层面与 Muse 隔离。除非 Sentinel 批准，Muse 的任何操作都不会触达互联网；需要时它会向本人请求许可。
- Muse 无法看到人们的密码或支付方式。人们分享给 Muse 的任何凭证都会进入安全存储，Muse 可以使用它们但看不到它们。Muse 也无法看到人们在浏览器中亲自输入的密码。
- 在发送邮件、完成购买等敏感操作前，Muse 会先与本人确认。Muse 会向用户展示它已完成和计划执行的一切的完整审计轨迹。
- 由人们选择 Muse 连接哪些应用、精确授予多少访问权限。对于邮箱这类应用，人们可以选择 Muse 能做什么——是只读邮件，还是也可以代发。
- 人们可以随时更改权限或断开某个服务。人们也可以选择退出，不让自己的交互数据用于训练 Meta 的 AI 模型。
- Muse 不会把人们的对话或其 VM 中的数据提供给 Meta 的广告系统。
- Muse 会记住对你重要的事，而你随时可以让它"忘记"它学到的特定内容。

## 展望未来

Meta 认为，个人超级智能（personal superintelligence）将成为一代人中最具变革性的技术之一。Muse 是第一步：一个承担更多工作、让人们专注于真正重要之事的 agent。

Muse 正在美国市场推出，支持 iOS、Android 和 [muse.ai](http://muse.ai)，并将很快登陆 AI 眼镜。人们日常所需的大部分功能免费，并为想要更多能力的用户准备了订阅套餐。
