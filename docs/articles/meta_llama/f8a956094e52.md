今天，我们很高兴推出 Muse Spark 1.1——Meta Superintelligence Labs 的最新模型，也是 Muse Spark 的一次重要升级。Muse Spark 1.1 是一个面向 agentic 任务构建的多模态推理模型，在工具与计算机使用、编程和多模态理解上均有大幅提升。

凭借这些改进，Muse Spark 1.1 推进了性能-效率前沿。与本周发布的 [Muse Image](https://ai.meta.com/blog/introducing-muse-image-muse-video-msl/) 一起，这次发布让我们更接近个人超级智能（personal superintelligence）的愿景：帮助你追求目标、创作你想象中的东西、深化你的人际关系，并在你最珍视的事情上采取行动。

伴随本次发布，我们同步上线了全新 [Meta Model API](https://developer.meta.com/ai/resources/blog/build-with-muse-spark) 的公开预览，开发者可通过它访问 Muse Spark 1.1。该模型现已在 Meta AI 应用和 [meta.ai](https://meta.ai/) 上以"Thinking"（思考）模式提供。

## 评测

关于评测的更多细节，[请见我们的报告](https://ai.meta.com/static-resource/muse-spark-1-1-evaluation-report)[。](https://ai.meta.com/static-resource/muse-spark-1-1-eval-methodology)

## Agent

Muse Spark 1.1 在个人 agentic 任务上表现出色——这类任务需要在多种外部应用与服务之间进行规划和调度。它能零样本泛化到新的原生工具、MCP 服务器和自定义技能。

它处理复杂项目的速度显著快于 Muse Spark，因为训练目标就是编排多 agent 系统以优化端到端延迟。作为主 agent，它可以收集上下文、制定计划，并把执行分派给并行的子 agent。作为子 agent，它恪守职责、理解可用工具，并知道何时向主 agent 升级汇报。

Muse Spark 1.1 能主动管理其 100 万 token 的上下文窗口。它记得已执行的动作，能检索很久之前工作中的信息，并以保留后续工作关键步骤的方式进行上下文压缩。

## 计算机使用

Muse Spark 1.1 擅长横跨多个应用、信息实时变化的 computer-use 工作流。它能在长时间会话中保持上下文、适应不断变化的需求，并以最少的人工干预导航陌生的界面。

Muse Spark 1.1 不再逐次点击地推理每一个桌面步骤，而是理解何时该自动化、何时该直接操作界面。我们训练模型在自动化更快时编写脚本、在直接交互更简单时点击、并在每一步生成成批的动作。

Agentic 晚宴筹备：在真实应用中，会出现改变任务的新上下文。Muse Spark 1.1 在下晚餐订单时察觉到这些变化，无需用户介入即做出必要更新。

## 编程

Muse Spark 1.1 在涉及大型复杂代码库的真实任务上，编程性能大幅提升。它能诊断并修复复杂 bug、在企业级系统中实现新功能、执行大规模代码迁移。在创建 Web 应用、端到端问答等用例中，Muse Spark 1.1 相比我们的首个模型显示出巨大进步。

我们训练模型顺畅适配多样化的 harness，并可靠处理复杂的多轮动态。Muse Spark 1.1 在主流 agentic 编程环境中表现良好，支持规划模式、目标条件化、子 agent 委派、上下文压缩等常用功能。

OpenCode 中的调试演示：Muse Spark 1.1 构建一个聊天 Web 应用，自动截图识别用户可见的故障，把问题追溯到相关代码并实施修复，然后验证变更。模型无缝结合了编程、多模态理解与工具调用。

在 Meta 内部，开发者和研究员每天都在用 Muse Spark 1.1 更快地构建、更聪明地工作。在我们的主要内部编程评测 Meta Internal Coding Bench 上，Muse Spark 1.1 相比 Muse Spark 显著进步，可与领先的同类产品竞争。

研究员们现在也在其工作流中借助 Muse Spark 1.1 来自动化模型开发与评测任务。

OpenCode 中的 DeepSWE 评测：Muse Spark 1.1 在不同推理强度下对 DeepSWE 任务子集进行自评，并基于结果生成分析仪表盘。

## 多模态

除编程与 agentic 能力外，Muse Spark 1.1 在感知、多模态推理和工具使用方面同样出色。它能与现实环境交互并产出有依据的输出，强项包括视觉到代码（visual-to-code）的成果生成、超详尽的图像与视频描述，以及面向多模态用例的 agentic 工作流执行。

当感知与行动需要同步发生时，Muse Spark 1.1 的多模态能力尤为宝贵。模型能检视视觉与音频信息、在长工作流中保留细节，并在代表用户操作计算机时运用这些细节。

Facebook Marketplace agent：利用智能手机拍摄的视频，Muse Spark 1.1 提取有用的照片并对产品进行推理，操作用户的浏览器，代用户在 Facebook Marketplace 上发布商品列表。

## 安全

在部署之前，我们依照[高级 AI 扩展框架（Advanced AI Scaling Framework）](https://ai.meta.com/static-resource/Meta_Advanced-AI-Scaling-Framework-v2)进行了全面的安全评估。该框架为我们最先进的模型定义了评估、威胁模型与部署门槛。

在所有前沿风险类别——化学与生物、网络安全、失控（Loss of Control）——中，我们的评估显示 Muse Spark 1.1 均在安全裕度内运行。Muse Spark 1.1 对直接越狱攻击以及来自不可信数据、提示注入、开发者提示攻击的间接攻击表现出强抵抗力。因此，它展现出更好的对抗鲁棒性、更低的幻觉率和更少的谄媚（sycophancy）倾向。

关于 1.1 的完整安全态势记录在我们的 [Muse Spark 1.1 评测报告](https://ai.meta.com/static-resource/muse-spark-1-1-evaluation-report)中。
