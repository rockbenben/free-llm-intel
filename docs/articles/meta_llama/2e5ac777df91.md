今天，我们正式推出 Muse Spark。这是 Meta Superintelligence Labs 开发的 Muse 系列模型中的第一款。Muse Spark 是一个原生多模态推理模型，支持工具调用、视觉思维链和多 agent 编排。

Muse Spark 是我们扩展阶梯上的第一级，也是我们全面重构 AI 工作之后交出的第一个成果。为了支撑进一步的扩展，我们正在整个技术栈上做战略性投入——从研究与模型训练，一直到基础设施，其中包括 Hyperion 数据中心。

本文先介绍 Muse Spark 的新能力与实际应用。看完这些结果之后，我们再揭开帷幕，看看推动我们走向个人超级智能的各项扩展轴。

Muse Spark 从今天起可在 [meta.ai](https://applink.meta.ai/?utm_source=ai_meta&amp;utm_medium=web&amp;utm_content=Blog-Intro-Muse-Spark_Avail-Today_Meta-AI&amp;utm_campaign=04082026) 以及 Meta AI 应用中使用。我们同时向部分用户开放了私有 API 预览。

面向个人超级智能的能力

Muse Spark 在多模态感知、推理、健康以及 agentic 任务上都表现出有竞争力的性能。对于目前仍存在能力差距的领域，例如长程 agentic 系统和编码工作流，我们会继续投入。

随着规模更大的模型进入开发阶段，这些结果表明我们的技术栈正在有效地扩展。

应用

Muse Spark 是迈向个人超级智能的第一步，这种超级智能理解你所处的世界。从分析你所处的环境，到支持你的健康管理，Muse Spark 先进的推理能力支撑起了强大且高度个性化的用例。

**多模态。** Muse Spark 从底层设计上就把视觉信息整合到各个领域和工具之中。它在视觉 STEM 问题、实体识别和定位上表现强劲。这些能力汇聚在一起，支撑起诸如制作有趣的小游戏，或者借助动态标注排查家中电器故障这类交互体验。

**健康。** 个人超级智能的一大应用，是帮助人们了解自身健康并加以改善。为了提升 Muse Spark 的健康推理能力，我们与 1,000 多名医生合作筛选训练数据，让回答更符合事实、也更全面。Muse Spark 能够生成交互式界面，把各类健康信息拆解开来并加以解释，例如不同食物的营养成分，或者运动过程中被激活的肌肉。

### 扩展轴

要构建个人超级智能，模型能力必须能够可预测、高效率地扩展。下面我们介绍自己如何沿着三条轴研究和追踪 Muse Spark 的扩展特性：预训练、强化学习和测试时推理。

**预训练。** 预训练阶段是 Muse Spark 获得核心多模态理解、推理和编码能力的环节——这是强化学习和测试时算力所依托的基础。

过去九个月里，我们重建了预训练技术栈，在模型架构、优化和数据整理上都做了改进。这些进步叠加起来，提升了我们能从每一单位算力中获取的能力。为了严格评测这套新配方，我们对一系列小模型拟合扩展定律，比较达到某一特定性能水平所需的训练 FLOPs。结果很清楚：与上一代模型 Llama 4 Maverick 相比，我们能用低一个数量级以上的算力达到同等能力。这一改进也让 Muse Spark 显著比可用于对比的领先基础模型更高效。

![](https://scontent-itm1-1.xx.fbcdn.net/v/t39.2365-6/667580961_1557898095990047_8798526624523628592_n.png?_nc_cat=108&_nc_map=urlgen_bucketless&ccb=1-7&_nc_sid=e280be&_nc_ohc=OfMHKCSG4agQ7kNvwFSp4AN&_nc_oc=AdoWXySTH9SRKxwGtnaerfk35_6VYpnUkGnauyjPfXX5r8DE-P2vLfaUOzILaKux1lc&_nc_zt=14&_nc_ht=scontent-itm1-1.xx&_nc_gid=OyW7qOdstTS5Mwkm4T1cfg&_nc_ss=7f20f&oh=00_AQSJ_EnWVSONM_qVRScSCC6EN2MYX3pLqzxo6kzmHCdUIQ&oe=6B1BB363)

**强化学习。** 预训练之后，强化学习（RL）利用算力以可扩展的方式放大模型能力。大规模 RL 素来以容易失稳著称，而我们的新技术栈仍能带来平滑、可预测的提升。

下图展示了为 Muse Spark 扩展 RL 算力（以步数计量）所带来的收益。左图显示，在训练数据上，pass@1 与 pass@16（16 次尝试中至少成功一次）呈对数线性增长。这说明 RL 在提升模型可靠性的同时，没有牺牲推理的多样性。右图显示，留出评测集上的准确率增长证明 RL 的收益可以可预测地泛化：Muse Spark 在训练中未曾见过的任务上也能平滑地提升。

**测试时推理。** RL 会训练模型在作答之前先"思考"——这一过程称为测试时推理。要把这项能力服务给数十亿用户，就必须高效地使用推理 token。为此，我们依靠两个关键杠杆：用思考时间惩罚来优化 token 使用，以及用多 agent 编排在不拖慢响应时间的前提下提升表现。

为了在每个 token 上交付最多的智能，我们的 RL 训练在对思考时间的惩罚约束下最大化正确率。在诸如 AIME 等一部分评测上，这会引发一次相变。起初，模型通过思考更久而得到提升；随后，长度惩罚带来了*思维压缩 *——Muse Spark 压缩自己的推理过程，用显著更少的 token 解决问题。压缩之后，模型又会重新展开它的解法，取得更强的表现。

要在不显著增加延迟的情况下投入更多测试时推理，我们可以扩展协作解决难题的并行 agent 数量。下图展示了这种做法的收益。标准的测试时扩展让单个 agent 思考更久，而用多 agent 思维来扩展 Muse Spark，则能在相当的延迟下取得更优的表现。

安全

Muse Spark 在两用科学领域具备广泛的推理能力，因此我们在部署之前做了大量安全评测。我们的流程遵循更新后的 [Advanced AI Scaling Framework](https://ai.meta.com/static-resource/Meta_Advanced-AI-Scaling-Framework-v2)，该框架为我们最先进的模型定义了威胁模型、评测协议和部署门槛。我们在应用安全缓解措施之前和之后，分别从前沿风险类别、行为对齐和对抗鲁棒性三个方面对 Muse Spark 做了评测。

我们发现，得益于预训练数据过滤、以安全为重点的后训练以及系统级护栏，Muse Spark 在生物与化学武器等高风险领域表现出很强的拒答行为。在网络安全和失控这两个领域，Muse Spark 并未表现出实现威胁情景所需的自主能力或危险倾向。评测显示，考虑到其部署语境，Muse Spark 在我们测过的所有前沿风险类别中都处于安全边际之内。完整结果见我们的 [Safety & Preparedness Report](https://ai.meta.com/static-resource/muse-spark-safety-and-preparedness-report/)。

在对接近发布版本的 checkpoint 所做的第三方评测中，Apollo Research 发现，Muse Spark 的评测意识出现率是他们观察过的模型中最高的一档。该模型经常把场景识别为"对齐陷阱"，并推理自己应当诚实作答，因为它正在被评测。这一点之所以重要，是因为能够识别评测语境的模型，在测试时的行为可能与部署时不同。不过，这些结果并不能确认这种意识会直接改变行为；我们自己的后续调查也发现了初步证据，表明评测意识可能在一小部分对齐评测上影响模型行为，而这些评测都与影响模型发布决策的危险能力或倾向无关。我们判定这不构成发布上的阻塞性顾虑，但仍值得进一步研究。更多内容见我们的 [Safety & Preparedness Report](https://ai.meta.com/static-resource/muse-spark-safety-and-preparedness-report/)。

结论

借助 Muse Spark，我们走上了一条可预测且高效率的扩展轨迹。我们期待不久后在通往个人超级智能的道路上，分享能力越来越强的模型。
