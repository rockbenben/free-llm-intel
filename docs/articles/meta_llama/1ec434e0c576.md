## 要点

- 我们推出 Facebook Verified——一枚免费徽章，通过简单的自拍验证流程，确认个人资料背后是真实的人。
- 这枚徽章会出现在 Facebook 上最关键的场景，且没有任何订阅费用。

每天有数十亿人在 Facebook 上实现真实人与人之间的真诚连接——在 Facebook Marketplace 上买卖、在 Facebook Dating 上结识对象、或在 Groups 小组里参与讨论。随着 AI 让生成内容、资料和消息变得越来越容易，我们希望提供一种方式，让你知道个人资料的另一端是一个真实的人。这就是我们推出 Facebook Verified 的原因——一枚面向 Facebook 用户的免费徽章。

[![Facebook 认证界面](https://about.fb.com/wp-content/uploads/2026/07/01_Introducing-Facebook-Verified.jpg?resize=960%2C836)](https://about.fb.com/wp-content/uploads/2026/07/01_Introducing-Facebook-Verified.jpg)

## 运作方式

Facebook Verified 采用简单的自拍流程。你录制一段简短的自拍视频，我们会将其与你现有的头像照片进行比对，确认为同一人。该流程免费，通常只需几分钟。账号必须符合我们的信任与安全标准才能获得认证资格。

https://about.fb.com/wp-content/uploads/2026/07/02_Verification_Flow.mp4

Facebook Verified 面向符合条件的 Facebook 用户开放：年满 18 岁、良好遵守我们的[社区准则](https://transparency.meta.com/policies/community-standards/fraud-and-scams/)（特别是禁止欺诈、诈骗和欺骗性行为的条款），且没有[虚假行为](https://transparency.meta.com/policies/community-standards/inauthentic-behavior/)迹象的用户。主页（Pages）和 ProMode 账号不适用。

我们将分阶段推出 Facebook Verified，首先在部分市场上线，并计划逐步扩展至全球。

## 你会在哪里看到它

认证成功后，你的徽章将出现在 Facebook 上最关键的场景：首先是 Marketplace、Dating、Groups 和个人资料页。未来我们还会逐步在信息流（Feed）帖子中添加徽章。没有订阅费用——认证一次，徽章就伴随你在 Facebook 全平台通行。

当你浏览 Marketplace 的商品列表、查看交友资料，或在 Groups 里了解某人时，你会在完成认证流程的账号上看到 Verified 徽章。

https://about.fb.com/wp-content/uploads/2026/07/03_Profile_Checkmark.mp4

## 徽章意味着什么——以及不意味着什么

Facebook Verified 徽章意味着该个人资料属于一个真实的人——一个完成了自拍验证并符合我们信任与安全标准的人。在你回应一条商品列表、接受一次约会邀请或参与一场对话之前，它是一个快速、醒目的信号：另一端是一个真实的人。

Facebook Verified 徽章并不意味着 Facebook 对该用户表示背书，也不保证其绝对可信。所有用户仍然受 Meta 各项政策的约束，例如[社区准则](https://l.facebook.com/l.php?u=https%3A%2F%2Ftransparency.meta.com%2Fpolicies%2Fcommunity-standards%2F%3Fsource%3Dhttps%253A%252F%252Fwww.facebook.com%252Fcommunitystandards%252F&h=AUDBpa-riGhEl4Z8SFVoHo-Dv2vFfeFLVXSBRyKPzKO_9dIihBj1hotYpgVsEQWF08DtH4I17Kt-2HimPTvOy5TsqDIF3pguSYWO8LCHXuYUZfbC9lJzAuqS7smbIeMt3X7HBv1iTGSB_w)和[商务政策](https://l.facebook.com/l.php?u=https%3A%2F%2Fwww.facebook.com%2Fpolicies_center%2Fcommerce%2F&h=AUAp1UoEFFPeoXIJkL9VLuMciH-vFU-HoyiNguaQGIa1u_keVqLwDHo1BmZNKddiMVmj9hkaM_QKG-CHRvC8NIvMVGZeq1edHriPsmlgiVrsLmvGQPFrHkbclSaXjXjp6GyQS4zY4ZsWLw)。

随着 AI 让人们在 Facebook 上能做的事情越来越多，一个能够区分真实用户的清晰信号变得至关重要。这正是 Facebook Verified 的意义所在：让 Facebook 上那些重要的时刻扎根于真实的人。
