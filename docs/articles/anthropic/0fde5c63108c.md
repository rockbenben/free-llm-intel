# Claude 的记忆处处通用，而由你决定其中存了什么

- 类别：[产品公告](https://claude.com/blog/category/announcements)
- 产品：[Claude Cowork](https://claude.com/product/cowork)
- 日期：2026 年 8 月 25 日
- 阅读时长：5 分钟
- 分享：[复制链接](https://claude.com/blog/claudes-memory-works-everywhere-and-you-decide-whats-in-it#)https://claude.com/blog/claudes-memory-works-everywhere-and-you-decide-whats-in-it

从今天起，你在 chat 里使用的记忆，与在 Claude Cowork 里的是同一份。如今，无论你在哪里与 Claude 协作，它都从它已知关于你的事情起步。你能看到 Claude 记住的一切，按主题逐条查看，并编辑或删除其中任何内容。Claude 默认不会把那些被认为敏感的主题（如健康或信仰）存入记忆，但如果这些正是你厌倦了反复解释的话题，你可以在记忆设置里把它们开启。

## **一份记忆，贯穿 Claude Cowork 与 chat**

Cowork 如今有了记忆，而且就是你在 chat 里使用的同一份，从而少些反复解释、多些从上次停下的地方接续。当 Cowork 在云端运行一个任务时，Claude 从你聊天中记住的东西就在那里，反之亦然。你跨数月对话积累起来的上下文——例如你的 Q3 优先级、以及你各个项目的状态——在你把任务交给 Cowork 的那一刻就在场，而 Cowork 里出现的内容也会带回到 chat。

请 Cowork 为你的经理起草一份更新，它已经知道那是谁、以及她喜欢怎样的更新写法。在你组织的一场大会的 chat 里头脑风暴议程；当 Cowork 构建预算和后勤文档时，它知道人数、城市和演讲嘉宾。在 chat 里解释一次你的团队如何定义指标，此后 Cowork 构建的每份季度业务评审幻灯片都会采用它们，无需重新交代。

## **记忆随你聊天而更新**

Claude 如今是在你聊天时就把主题加入记忆，而不是在对话结束后再总结。提到你的项目截止日期移到了九月，你的下一次对话就已经知道了，无需你说「记住这个」。你可以随时暂停记忆或重置它。

## **查看并编辑你保存的记忆**

Claude 记住的一切，都在记忆设置的「主题（Topics）」下、以一份文件列表呈现，你可以在其中阅读、编辑或删除每一条。这些文件很短，而一处修正处处受益：在一个文件里改正你公司的旧名称，此后每一场对话都会写对。

## **决定你是否想让 Claude 记住敏感主题**

默认情况下，Claude 不会存储与个人或敏感题材相关的主题，例如你的健康、种族、族裔、宗教信仰、政治、性别认同及其他类似领域。

但一些人视为敏感的，另一些人可能觉得让 Claude 记住很有用。如果你选择开启「在记忆中包含敏感主题」，Claude 会在为你推荐每周备餐食谱时记住诸如你的麸质过敏这样的事情。

设置开启后，每当 Claude 在这些主题之一上保存某样东西到记忆，你都会看到一条提示。Claude 从今往后保存敏感主题。任何在你开启之前的内容都不会被追溯保存。你可以随时关掉这个设置。

为保护你的安全和隐私，有些主题即使你在记忆中开启了敏感主题，Claude 也不会存储。这包括敏感的身份号码（SSN、政府身份证号码等）、犯罪记录、移民身份，或任何违反我们可接受使用政策（AUP）的内容。当 Claude 无法把这些信息更新进记忆时，它会告知你。访问[帮助中心](https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context#h_6fe1d0e66f)了解更多。

## **如何开始**

在 Free、Pro 和 Max 套餐上，记忆在网页、桌面和移动端默认开启。请注意，在记忆中保存敏感主题默认关闭。在 iOS 和 Android 上，更新到最新版的移动应用以获得最近的更新。对于 Team 和 Enterprise，管理员控制其组织的可用性，而在个别用户开启之前，对他们默认关闭。

访问[设置 > 记忆](https://claude.ai/new#settings/customize-memory)来开启记忆并控制 Claude 记住什么。
