今天我们推出 Claude Platform 上的关联计费（linked billing）测试版。第三方平台（例如编码 agent 和工作流自动化工具）可以让其最终客户为 Claude API 用量付费，而无需共享 API key。最终客户保留其现有的 Anthropic 计费关系并自行设置支出上限，平台则获得一种更简单、更安全的方式来提供 Claude。

## 比共享 API key 更安全的替代方案

在第三方平台上为 Claude API 用量付费，通常意味着共享 API key，而 API key 的作用如同密码：任何持有该 key 的人都可以发起计入客户账下的请求，因此平台必须妥善保管它。

通过关联计费，客户改为关联其 Claude Platform 组织，用量直接计入该组织。无需交接任何 API key，因此平台没有客户 key 需要存储、加密或轮换，客户的 API key 也永远不会离开其组织。

平台可以查看每个已关联客户的用量。客户批准每个关联的平台、设置支出上限，并可随时取消关联。

Claude Platform 上的关联计费

## 平台无需自建计费即可向客户提供 Claude

关联计费为平台提供了向其客户提供 Claude 的新方式。平台发送请求，Anthropic 直接向最终客户计费。通过关联计费，平台可以：

- **更快上线。** Anthropic 托管审批流程和计费，因此无需构建计量或开票系统。
- **按客户了解用量。** 在 Console 中，或通过 [Usage and Cost Analytics API](https://platform.claude.com/docs/en/manage-claude/usage-cost-analytics-api)（测试版）以编程方式，获取每个已关联客户的请求数、token 用量和所用模型。
- **选择由谁付费。** 针对每个请求决定由平台还是最终客户付费，因此平台可以将 Claude API 成本转嫁给客户，或按产品或实例自行承担部分功能的费用。

## 客户获得更多可见性和控制权

客户可以使用 Anthropic 托管的流程轻松关联平台。随后他们可以从现有的 Anthropic 承诺用量中抵扣，或按用量付费。通过关联计费，客户还可以：

- **一次关联，覆盖整个组织。** 拥有 Owner、Admin 或 Billing 角色的 Console 用户批准关联，因此无论对个人开发者还是大型团队，运作方式都相同。
- **为每个平台设置限额。** 客户可以为每个平台设置每月支出上限，或设置适用于每个平台的默认值。
- **查看 API 支出流向。** Console 显示每个已关联平台的支出。
- **随时取消关联。** 客户可以直接在 Console 中取消关联。

请求在平台的组织中运行，因此客户组织中的设置（例如 IP 允许列表、加密密钥和数据保留策略）不适用。

目前支持关联计费的平台包括 Asana、ClickHouse、Factory、Gumloop、Harness、Higgsfield AI、Kilo Code、Linear、Major、Mintlify、Omni、OpenArt、Niteshift、Railway、Ramp、Runlayer、Tessera、Tines 和 Warp。

## 开始使用

关联计费现已在 Claude Platform 上以测试版提供。第三方平台可以在 [Console](https://platform.claude.com/settings/oauth-apps) 中创建应用，并按照[文档](https://platform.claude.com/docs/en/manage-claude/oauth-apps/organization-billing-connections)中的步骤添加支持。Claude Platform 客户可以从任何支持的平台关联其组织，并在 [Claude Marketplace](https://claude.com/marketplace/agents-products?howYouPay=linkedBilling) 上查找提供关联计费的平台。
