今天我们推出 Claude Platform 上的关联计费（linked billing）测试版。编码 agent、工作流自动化工具这类第三方平台，现在可以让自己的最终客户为 Claude API 用量付费，而无需共享 API key。最终客户继续沿用现有的 Anthropic 计费关系，并自行设定支出上限；平台则获得一种更简单、更安全的方式来提供 Claude。

## 比共享 API key 更安全的替代方案

在第三方平台上为 Claude API 用量付费，通常意味着要共享 API key。API key 的作用等同于密码：谁拿到它，谁就能发起计入该客户账下的请求，所以平台必须把它妥善保管。

改用关联计费后，客户关联的是自己的 Claude Platform 组织，用量直接计入该组织。整个过程中没有任何 API key 易手，平台因此没有客户 key 需要存储、加密或轮换，客户的 API key 也始终不离开自己的组织。

平台可以查看每个已关联客户的用量。客户逐个批准要关联的平台、设定支出上限，并可以随时取消关联。

## 平台无需自建计费即可向客户提供 Claude

关联计费为平台提供了向客户提供 Claude 的新途径：请求由平台发出，账单由 Anthropic 直接开给最终客户。借助关联计费，平台可以：

- **更快上线。** 审批流程和计费都由 Anthropic 托管，平台不必自建计量或开票系统。
- **按客户掌握用量。** 在 Console 中，或通过 [Usage and Cost Analytics API](https://platform.claude.com/docs/en/manage-claude/usage-cost-analytics-api)（测试版）以编程方式，获取每个已关联客户的请求数、token 用量和所用模型。
- **决定由谁付费。** 逐请求决定费用由平台还是最终客户承担，平台因此可以把 Claude API 成本转嫁给客户，也可以按产品或实例自行承担部分功能的费用。

## 客户获得更多可见性与控制力

客户可以通过 Anthropic 托管的流程轻松关联平台，之后从既有的 Anthropic 承诺用量中抵扣，或按用量付费。借助关联计费，客户还可以：

- **一次关联，覆盖整个组织。** 由拥有 Owner、Admin 或 Billing 角色的 Console 用户批准关联，因此无论个人开发者还是大型团队，体验都一致。
- **为每个平台设置限额。** 客户可以为每个平台单独设置每月支出上限，也可以设置一个适用于所有平台的默认值。
- **看清 API 支出流向。** Console 会显示每个已关联平台的支出。
- **随时取消关联。** 客户可以直接在 Console 中操作。

请求在平台的组织中运行，因此客户组织里的设置（例如 IP 允许列表、加密密钥和数据保留策略）不适用。

目前支持关联计费的平台包括 Asana、ClickHouse、Factory、Gumloop、Harness、Higgsfield AI、Kilo Code、Linear、Major、Mintlify、Omni、OpenArt、Niteshift、Railway、Ramp、Runlayer、Tessera、Tines 和 Warp。

## 开始使用

关联计费现已在 Claude Platform 上以测试版形式提供。第三方平台可以在 [Console](https://platform.claude.com/settings/oauth-apps) 中创建应用，并按[文档](https://platform.claude.com/docs/en/manage-claude/oauth-apps/organization-billing-connections)中的步骤添加支持。Claude Platform 客户可以从任意受支持的平台发起组织关联，也可以在 [Claude Marketplace](https://claude.com/marketplace/agents-products?howYouPay=linkedBilling) 上查找提供关联计费的平台。
