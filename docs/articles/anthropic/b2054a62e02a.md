# 面向财务顾问的 Claude

财务顾问现在可以把 Claude 连接到他们所依赖的托管机构、组合平台、CRM 和规划工具，还有为财务顾问日常工作量身打造的全新技能。

今天我们发布 Claude for Financial Advisors——一套连接器和工作流技能，旨在帮助处理占据顾问时间、使其无法投入面向客户工作的研究、准备和文档任务。

对财务顾问而言，时间极为稀缺。根据 [Kitces 的研究](https://www.kitces.com/kitces-report-how-financial-planners-actually-do-financial-planning/)，一个典型的顾问业务只把六分之一的时间花在客户会议上。其余都花在了围绕这些会议的工作上——跨系统拼凑信息来做准备、规划、记录所讨论的内容。与此同时，据 [EBRI 的 2026 退休信心调查](https://www.ebri.org/docs/default-source/rcs/2026-rcs/rcs_26-fs-3_prep.pdf)，超过四成美国上班族说他们不知道该找谁获取好的财务或退休规划建议。顾问在准备和文书上省下的时间，就可以用在现有客户、或他们尚有余力服务的新家庭上。

Claude for Financial Advisors 包括：

- **连接器，** 让 Claude 能访问顾问最依赖的托管机构、资产管理人和财富技术提供商，使顾问能在一处处理客户的信息。
- **技能，** 用这些信息协助完成特定任务，如会议准备、组合分析和合规检查——始终服务于顾问自身的判断和风格。

## **连接顾问已在使用的工具**

新连接器带来顾问所依赖的 CRM、托管机构、组合报告、财务规划软件、遗产工具和会议记录。

- **Addepar** 把投资情报带入 Claude，给顾问对公开和私募市场组合数据、分析和流程的有治理访问。
- **BlackRock** 通过 Advisor Center 把它的组合构建专长、模型组合和机构级分析带入 Claude，使顾问能在公开和私募市场提供整体性建议。
- **Charles Schwab** 把 Claude 连到 Schwab Advisor Services 的托管数据，包括余额、持仓、交易、成本基础、告警和资金划转状态，使顾问能审阅客户信息、看出哪些客户需要关注、并为审阅做准备。
- **Envestnet** 让顾问用自然语言总结 Tamarac 的账户和家庭，并附一份来自 MoneyGuide 的财务规划快照。
- **iCapital** 把客户的另类投资持仓带入 Claude，使顾问能查看净值（NAV）、承诺、未到位资本、近期资本活动和业绩，并更容易把这些洞察连到客户更广泛的组合。
- **Orion** 把组合报告和 Redtail CRM 洞察带入 Claude，用于家庭审阅、机会分析、会议准备和跟进。
- **SS&C Black Diamond** 把组合、业绩、持仓和再平衡数据带入 Claude，使顾问能审阅他们的业务簿、发现超出容忍度的客户、浮现税务亏损收割机会，并在其批准下生成客户报告、任务和再平衡会话。
- **Wealthbox** 把 Claude 连到客户记录和会议历史，以驱动入职、会议准备和跟进。
- **Wealth.com** 给 Claude 一份对每个客户遗产与税务图景的结构化视图，包括信托和遗嘱摘要、报税洞察和完整资产负债表，使顾问能用一份有条理的可用信息摘要开始规划，而不是散落在多个系统里的文档。
- **Vanguard** 把它模型组合和顾问投资解决方案的信息带入 Claude，使顾问在为客户做决策时能借助 Vanguard 可信的研究、组合构建和资产配置专长。
- **Zocks**——这款面向财务顾问的 AI 会议助手——把 Claude 所需的客户情报从它捕获的每场对话中带入，包括画像、目标、人生事件和承诺。

这些新连接器加入了 Claude 中已有的其他[连接器](https://claude.com/connectors)，包括 Microsoft 365、Salesforce、DocuSign、Box、FactSet、S&P Global、Morningstar 等。

Claude for Financial Advisors 插件——把顾问技能和连接器打包成一次安装——可与 BlackRock、Charles Schwab、Addepar、Envestnet、iCapital、Orion、Wealthbox、Wealth.com 和 Zocks 一起工作，顾问在引导式设置中选择连接其中哪些。某些伙伴也提供他们自己的插件：BlackRock 正为 Advisor Center 推出一个，加入 S&P Global 和 LSEG 已有的插件。

## **围绕顾问一天构建的技能**

Claude for Financial Advisors 插件里的每个技能，都支持顾问一天中的某个特定时刻——从为客户会议做准备，到解释一个漂移的组合——并路由到公司已在用来经营业务的工具。公司可以从我们的面向财务顾问的 Claude [技能仓库](https://github.com/anthropics/claude-for-financial-advisors)原样采用这些技能，或把它们改造到自己的工作流、服务模式和本行风格。

- **顾问入职** 连接一个公司的工具，并自动运行第一次会议准备，帮助一位新顾问在第一天而不是第三周就能上手。
- **另类投资简报** 把一个家庭的另类投资从 iCapital 或 Addepar 拉进一份可用于会议的摘要，连同组合的其余部分一起呈现，而不是让顾问手动核对一份份独立对账单。
- **合规与 AI 政策** 基于用户配置的标准，突出可能值得额外合规审阅的内容，协助公司记录审阅流程，并支持 AI 治理文档流程。
- **遗产与税务简报** 对照实际账户所有权和受益人核查客户的遗产规划，回顾上一年的税务，并能创建 CRM 跟进任务，让不匹配之处浮现出来供顾问审阅。
- **组合再平衡审阅** 对照客户的目标配置标记漂移和集中持仓，并创建一份顾问本要从头撰写的初步解释草稿。
- **会后笔记与跟进** 在一次处理中把一份文字记录转成客户摘要、一封回顾邮件和 CRM 任务，而不是让顾问在通话后逐个手动完成。
- **会前准备** 把来自已连接系统的信息（包括客户的持仓、近期账户活动和以往会议的未决事项）整合成一份供顾问审阅的简报，使他们能为该客户的具体情境做好准备、胸有成竹地走进对话，而不是从三个系统重建上下文。
- **潜在客户录入** 把一位潜客分享的内容整理成一份摘要、一份分析师交接和一份「预期」备忘录，让第一次会议在基本信息已就位的情况下开始。

合在一起，这些技能在顾问的一天里收集信息、总结并起草客户沟通。投资建议、客户沟通、合规判定及其他受监管的活动，仍须经人类审阅和批准。

## **为受监管的专业人士而建**

Claude for Financial Advisors 的设计让顾问保持掌控，关键任务需经批准。Claude 为顾问审阅准备简报、摘要并起草分析，并把诸如 CRM 更新或客户沟通草稿这类行政操作暂存，供顾问审阅和批准。合规技能会对照 SEC 营销规则（Marketing Rule）筛查面向客户的措辞、标记潜在问题，帮助公司在其现有治理和留痕流程内记录审阅活动，并包含一套自助式 AI 政策工作流，帮助公司在 SEC 规则下记录其对 AI 的使用。工作流活动可被记录，以协助公司维持恰当的留痕和监督流程。

## **服务更多家庭、服务得更好**

当 Claude 处理会议准备、跟进草稿和管道审阅这类行政任务时，顾问可以把更多时间用于服务客户。公司能扩大其客户基础，并提供更多客户所需的服务，如税务、遗产、保险和退休规划。
