今天，[Claude for Government](https://claude.com/solutions/government) 已面向联邦及州级机构正式可用（generally available）。该平台通过 FedRAMP High 授权环境提供 Claude 的编码与 agentic 工作能力，自[7 月起一直处于公开测试](https://claude.com/resources/articles/bringing-claude-code-and-claude-cowork-to-government)阶段。

机构可获得与 Anthropic 商业客户相当的能力，同时不牺牲合规要求。新能力通常按商业版本的发布节奏上线。

[Claude](https://claude.com/product/overview) 可直接处理桌面上的文件，使机构工作人员能够使用 [skills](https://claude.com/resources/articles/skills-explained)、插件和 projects 来完成备忘录撰写、RFP 评审、案件处理及其他任务。借助 [Claude Code](https://claude.com/product/claude-code)，公共部门团队可以[构建并现代化改造](https://claude.com/resources/webinars/claude-code-and-public-service-modernizing-how-state-and-local-governments-build-software)支撑公共服务的软件系统。

Claude for Government 的治理控制专为公共部门机构打造。管理员可设置配置默认值，并跨部门分配和控制支出。安全团队和授权官员可获得审计日志与文档，以支持机构的 ATO 流程。采购人员可直接与 Anthropic 签约，并按正式可用条款授予合同。

Claude Code 命令行界面和 [Claude for Microsoft 365](https://claude.com/claude-for-microsoft-365) 也正在同一环境中以早期访问形式推出，并采用相同的管理控制。

## 计费、管理与监督

**不收取席位费。** 机构按固定增量支付使用费，并设有硬性不可超支上限，因此支出不会超过机构已承诺的金额。管理员可定义各用户层级的支出与模型限制，按用户和模型跟踪使用情况，并在余额不足前收到消耗预警。

管理控制台中的支出分析视图

**与部门组织结构相匹配的管理方式。** 部门级管理员可将预付使用额度分配给下属机构，同时各机构管理自己的用户。机构可接入自己的身份提供商实现单点登录，并在管理门户中自助配置。SCIM 组映射可为每个席位层级设置速率限制、金额上限和允许使用的模型。分层配置可为下属机构设置默认值，包括 Claude 可连接的对象以及可用的功能。

**将监督融入设计。** 管理操作会记录在审计日志中，组织管理员可进行审查。Anthropic 一侧的敏感操作需要双人审批。使用量导出仅为计量数据，因此机构无需移动敏感材料即可回应 ATO 和 IG 的请求。对话历史保留在机构管理的设备本地。

## 开始使用

Claude for Government 今日起面向联邦及州级机构正式可用。机构无需另行建立云服务商关系即可开始使用。现有客户可迁移至桌面应用，并通过应用内导入功能一并带走对话历史。

我们的 [FedRAMP 安全配置指南](https://trust.anthropic.com/resources#6ab2b125752bf0e0e8025505)可通过 Anthropic 的[信任中心](https://trust.anthropic.com/)获取。该应用通过机构标准的 MDM 平台部署。

新机构可在 [claude.com/solutions/government](http://claude.com/solutions/government) 申请访问权限。如需加入 Claude Code CLI 或 Claude for Microsoft 365 的早期访问，请联系我们的公共部门团队。也可通过 [Claude for Government 文档](https://claude.com/docs/government/overview)了解更多。
