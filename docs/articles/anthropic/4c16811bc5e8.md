今天，[Claude for Government](https://claude.com/solutions/government) 面向联邦与州级机构正式可用（generally available）。该平台通过 FedRAMP High 授权环境提供 Claude 的编码与 agentic 工作能力，自 7 月起一直处于[公开测试](https://claude.com/resources/articles/bringing-claude-code-and-claude-cowork-to-government)阶段。

各机构可以使用与 Anthropic 商业客户相当的能力，同时不牺牲合规要求。新能力通常按商业版本的发布节奏上线。

[Claude](https://claude.com/product/overview) 可直接操作桌面上的文件，让机构员工使用 [skills](https://claude.com/resources/articles/skills-explained)、plugins 和 projects 完成备忘录撰写、RFP 审阅、案件处理以及其他任务。借助 [Claude Code](https://claude.com/product/claude-code)，公共部门团队可以[构建并现代化支撑公共服务的软件系统](https://claude.com/resources/webinars/claude-code-and-public-service-modernizing-how-state-and-local-governments-build-software)。

Claude for Government 的治理控制专为公共部门机构打造。管理员可以设置配置默认值，并在各部门之间分配和控制支出。安全团队与授权官员可获得审计日志和文档，用于支持机构的 ATO 流程。采购官员可以直接与 Anthropic 签约，并按正式可用条款授予合同。

Claude Code 命令行界面和 [Claude for Microsoft 365](https://claude.com/claude-for-microsoft-365) 也将在同一环境中、沿用同一套管理控制，以 early access 形式逐步推出。

## 计费、管理与监督

**无席位费。** 机构按固定增量购买用量，并设有硬性不可超支上限，因此支出不会超过机构已承诺的额度。管理员可按用户组定义带有支出与模型限制的用户层级，按用户和模型追踪用量，并在余额偏低之前收到消耗预警。

管理控制台中的支出分析视图

**与部门组织方式相匹配的管理。** 部门级管理员可把预付费用量分配给下级机构，而各下级机构自行管理自己的用户。机构可接入自己的身份提供商实现单点登录，并在管理门户中自助完成配置。SCIM 组映射可为每个席位层级设置速率限制、金额上限和允许使用的模型。分层配置可为下级机构设定默认值，包括 Claude 可以连接哪些服务、哪些功能可用。

**设计即监督。** 管理操作会记录在审计日志中，机构管理员可以查看。Anthropic 一侧的敏感操作需要双人审批。用量导出仅为计量数据，因此机构可以回应 ATO 与 IG 的请求，而无需转移敏感材料。对话历史保留在机构管理的设备本地。

## 开始使用

Claude for Government 今天起面向联邦与州级机构正式可用。机构无需另行建立云服务商关系即可开始使用。现有客户可以迁移到桌面应用，并通过应用内导入把对话历史一并带走。

我们的 [FedRAMP 安全配置指南](https://trust.anthropic.com/resources#6ab2b125752bf0e0e8025505)可通过 Anthropic 的 [信任中心](https://trust.anthropic.com/)获取。该应用通过机构标准的 MDM 平台部署。

新机构可在 [claude.com/solutions/government](http://claude.com/solutions/government) 申请访问权限。如需加入 Claude Code CLI 或 Claude for Microsoft 365 的 early access，请联系我们的公共部门团队。也可通过 [Claude for Government 文档](https://claude.com/docs/government/overview)了解更多。
