# Claude Cowork 与 chat 现已合二为一

你不必再为任务该去哪而做选择。Claude 承担更多工作。

- 类别：[产品公告](https://claude.com/blog/category/announcements)
- 产品：Claude 应用、[Claude Cowork](https://claude.com/product/cowork)
- 日期：2026 年 9 月 16 日
- 阅读时长：5 分钟
- 分享：[复制链接](https://claude.com/blog/cowork-is-now-claude#)https://claude.com/blog/cowork-is-now-claude

从今天起，Claude Cowork 与 chat 正合并为一个 Claude。带一个简短的问题，或者交给它一份中午要交的报告，Claude 就接手处理——哪怕你已经合上笔记本电脑之后依然如此。它将在未来几周内于 Pro 和 Max 套餐上推出，更多套餐随后跟进。

Claude 产出的东西也不必自有其归属之地。Claude Docs 和 Claude Slides 今日全新上线，而 [Claude Design](https://claude.com/product/design) 如今也能在你的对话内部工作。要一份文档，你和 Claude 便一起撰写。要一份演示，Claude 就起草幻灯片。你可以直接编辑、直接从 Claude 演示，或下载为 PowerPoint 或 PDF。三者都在付费套餐上以 beta 形式提供，企业管理员决定何时开启。如果你单独使用 Claude Design，它会像以往一样继续工作。

我们把 Cowork 建成为一个独立空间，用于更大的工作；把 Design 用于视觉工作。人们两者都用，并告诉我们令人沮丧的地方在于决定一项任务归属何处。他们在一个里开始的，也无法延续到另一个里。于是我们不再让你做选择。Claude 现在能判断任务需要什么，因此 Cowork 和 Design 能做的，都可从任何一次对话中获取，并带着你已有的上下文、技能和连接器。

> “我可以让 Claude 调取 [我的法律研究数据库]，它会拉出所有判例、阅读它们、判断我可能还需要哪些其他判例、下载它们，并存进一个文件夹供我本人审阅。”——Andrew Keller，资深经济学家

## 它是什么样子

一份周报中午要交。在你出门前，你问 Claude 上周管道里有什么进展，然后补上：「照我们一贯的写法写出来，标出任何落后的地方，并把要点做成五页幻灯片供领导会议用。」如果有不清楚之处，Claude 会问。你在赶往办公室的路上就能用手机查看进度。等你坐到桌前，报告已作为一份带着同事批注的文档等在那里，幻灯片也已准备好可供打开、调整并下载为 PowerPoint。两者都出自同一次对话，所以幻灯片与报告本就一致。你自己改一句话，在某页幻灯片上给 Claude 留一条评论，然后分享出去。把它排定为每周一，Claude 便会在无人要求时开始撰写报告。

你用 Claude Design、Slides 或 Docs 做的任何东西，都存在于一个可分享的链接里，你可以在手机上打开。你可以选中某个元素并移动它，或者告诉 Claude 你想改什么。

你可以选择 Claude 如何向你确认。默认情况下，Claude 在采取行动前会先询问。如果你宁愿让它继续工作、只在某事需要细看时才来确认，也可以开启这种模式。最终决定权在你手里。

## 如何开始

如果你主要用 chat，你无需做任何不同的事。当你想交出更大的工作时，试着交给你下一份报告或演示——那些你原本自己动手做的。如果你一直在 Cowork 里工作，一切都在你离开时所在的位置：你的对话、项目、产物、连接器和技能。打开应用，就能从上次停下的地方接续。

它首先向 Pro 和 Max 套餐推出，在未来几周内，在网页、桌面和移动端的 Claude 应用中面向这些套餐的现有及新用户。没有需要开启的东西。Team 和 Free 套餐随后很快跟进，而企业管理员会在其组织的任何变动前至少 30 天收到我们的通知。

完整的功能列表见 [帮助中心](https://support.claude.com/en/articles/16761823)。如果你一直攒着一个庞大杂乱的项目，现在就是时候了。
