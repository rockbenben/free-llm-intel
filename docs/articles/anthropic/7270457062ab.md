智能报告（smart reports）呈现工作内容及其发生的位置，应用内问卷收集他们对 Claude 如何助力开展新工作的反馈，团队池化预算则让管理员为每个团队设置一份共享预算。这三项功能现已面向 Claude Enterprise 正式可用。

## 智能报告呈现你的团队如何使用 Claude，以及如何推广有效的做法

[智能报告](https://support.claude.com/en/articles/16893491-get-started-with-smart-reports)呈现一个团队用 Claude 完成了什么，以及这些工作花掉了多少成本。报告会展示你的团队用 Claude 做出的高价值工作，以及 Claude 如何让这些工作成为可能，并进一步说明如何把这些工作沉淀为可复用的 workflow，让组织里的其他人也能照做。

选定一个团队、一段日期范围以及要纳入统计的产品。Claude 会分析该团队对话记录的一个样本，把工作归入若干 workstream。你可以看到每条 workstream 的花费、产出的交付物，以及最常见的卡点，比如缺少连接器或工具调用失败。

每份报告都有一份汇总的建议清单，其中包括适合沉淀为 skills 的重复性 workflow，以及适合加入代码仓库的规则。你可以以 artifact 的形式把任意一条发现分享给能够据此行动的人。报告还能回答你自定义的模型使用与成本问题，管理员可以把自己这些问题和自定义洞察保存为模板，在未来的报告里复用。如果某人的花费上限拖住了手脚，拥有账单权限的管理员可以直接在报告里调高它。

负责人可以授权非管理员的团队负责人为自己的小组运行报告，让最贴近这项工作的人去落实发现。智能报告帮助管理员了解使用情况、为投入规划提供依据，但它不用于评估个人绩效，也不用于做雇佣决定。

## 应用内问卷收集反馈

![应用内问卷编辑器，含一道文本题和一道关于节省时间的多选题](https://assets.claude.com/1ed37b4afed48de6da20d4be0d99e76a98be3c9d.png)

[应用内问卷](https://support.claude.com/en/articles/16764057-create-surveys-for-your-organization)补上了团队自己对这项工作的看法。默认问题聚焦在价值上：最近用 Claude 做的最有价值的一件事是什么，Claude 改变了这项工作花费的时间，同事该效仿哪一种 Claude 用法，以及如果团队明天就失去访问权限，最先会瘫痪或变慢的是什么。管理员可以自定义或删除问题，并选择谁收到问卷、何时发放、在哪里呈现。成员会在自己正在使用的工具里、收到回复之后看到一张简短的问卷卡片。

问卷回复会陆续出现在问卷页面上，管理员可以导出为电子表格。现在，使用客户自管加密密钥的组织也可以启用应用内问卷；而对所有数据设置了统一保留期限的组织，问卷及其回复会按该周期删除。

应用内问卷被视为你的数据，因此 Anthropic 只在运营服务所必需的范围内访问它们。

## 团队池化预算让花费落在真正发生工作的地方

[团队池化预算](https://support.claude.com/en/articles/17005973-manage-pooled-group-budgets-on-enterprise-plans)让一个小组共享一份月度预算，这样重度使用 Claude 的人就不容易在月初就撞上个人上限，而其他人也不会把预算白白闲置。成员上限仍然作为一道 guardrail，用于防范异常高的个人用量。每次请求都会同时计入两者，成员在先耗尽的那一个上停下。当有人触到上限时，可以在 Claude 里申请追加，申请会交由管理员审核。设置时会根据该小组近期的用量给出建议额度，拥有账单权限的管理员会在预算用到 50%、75%、95% 和 100% 时收到邮件提醒。

## 快速上手

智能报告、应用内问卷和团队池化预算现已面向 Claude Enterprise 正式可用。是否可用取决于具体配置，包括配置了 HIPAA 或使用客户自管加密密钥的组织。请前往[帮助中心](https://support.claude.com/en/)查看适用条件与详细设置步骤。
