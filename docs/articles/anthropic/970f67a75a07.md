9 月，Chat 与 Cowork 首次为 Pro 和 Max 套餐[融为一体](https://claude.com/resources/articles/cowork-is-now-claude)。如今，同样的统一 Claude 体验已面向 Claude Enterprise 套餐全面可用。

Chat 与 Cowork 现在在网页端、桌面端和移动端是同一个 Claude，你的团队可以在同一段对话里问一个快问题，也可以交出一整个项目。智能体工作运行在由 Anthropic 管理的云环境中，Claude Enterprise 管理员可按角色控制访问，并通过新的 Efficient 模式管理用量。

## 一个 Claude 应对所有任务

团队成员在开始用 Claude 工作前，不必再在 chat 和 Cowork 之间做选择。对话从聊天开始，一个简单的问题依然能很快得到回答。当任务需要运行代码或处理文件时，Claude 会在云端继续，并交回完成的文档、分析或演示文稿。由于工作在云端运行，即便有人合上笔记本电脑，它也会继续推进，而他们可以在网页端、桌面端或移动端接着做。聊天、项目、连接器、技能与插件都会延续到新的统一体验中。

## 维护安全

如果你的组织已经批准使用 Claude chat，那么这一体验建立在你已经在用的企业级控制之上，包括单点登录（SSO）与 Compliance API。Anthropic 仍然对传输中和静态的数据进行加密，并且默认不会将其用于模型训练。

Claude 在云会话中执行智能体工作，每个会话都运行在自己的隔离虚拟机里；对 Claude Enterprise 而言，网络出口默认关闭，连接器凭据则保存在沙箱之外。由于这些工作运行在由 Anthropic 管理的同一个环境中，你的安全团队可以对它获得集中的可见性与控制。Anthropic Trust Center 上的[安全最佳实践指南](https://trust.anthropic.com/resources?s=3puokpm2aa1nn24nbcp0l&name=unified-claude-security-best-practices)涵盖了完整架构。

## 管理成本

Claude Enterprise 的定价仍按用量计费。最新的 Claude 模型比前代更高效：按用量计费，在典型工作负载上 Claude Opus 5.5 的运行成本比 Claude Opus 5 低 40%，而对大多数工作而言，Claude Sonnet 5.5 的成本比 Claude Sonnet 5 低至多 30%。

视任务而定，智能体工作可能比一次快速聊天消耗更多 token。Claude Enterprise 管理员有四类控制手段来管理这部分用量。Efficient 模式是一项新设置，它让统一的 Claude 体验保持在 Sonnet 与 Haiku 模型上。模型权益决定每个角色可以使用哪些模型。支出上限可在组织、群组和成员层级应用，而群组预算池让一个群组拥有一笔共享的月度额度可供支取。

## 开始使用

统一的 Claude 体验今天已面向 Claude Enterprise 套餐全面可用。管理员可以在组织设置中管理推广。对 Claude Code 使用零数据留存、采用 HIPAA-ready 配置或使用客户管理加密密钥的组织，将保持其当前配置。

详情见[管理员设置指南](https://support.claude.com/en/articles/17444462)。如果你是现有 Claude Enterprise 客户，你会收到一封关于你所在组织推广安排的邮件。
