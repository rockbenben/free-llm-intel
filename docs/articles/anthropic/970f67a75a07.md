Chat 和 Cowork 首先在 9 月份针对 Pro 和 Max 计划[结合在一起](https://claude.com/resources/articles/cowork-is-now-claude)。现在，Claude Enterprise 计划普遍提供相同的统一 Claude 体验。

Chat 和 Cowork 现在在网络、桌面和移动设备上合二为一，因此您的团队可以在同一对话中提出快速问题或移交完整的项目。代理工作在 Anthropic 管理的云环境中运行，Claude Enterprise 管理员按角色控制访问并通过新的高效模式管理使用情况。

## 每项任务一个Claude

团队成员在开始与 Claude 一起工作之前不再在聊天和 Cowork 之间进行选择。对话以聊天开始，一个简单的问题仍然可以得到快速解答。当任务需要运行代码或处理文件时，Claude会在云中继续并返回完成的文档、分析或幻灯片。由于工作在云端运行，因此在某人关闭笔记本电脑后，工作仍会继续进行，并且他们可以在网络、桌面或移动设备上继续工作。聊天、项目、连接器、技能和插件延续到新的统一体验中。

## 维护安全

如果您的组织已批准 Claude 聊天，则这将建立在您已使用的企业控制之上，包括单点登录 (SSO) 和合规性 API。 Anthropic 仍然对传输中和静态的数据进行加密，并且默认情况下不将其用于模型训练。

Claude 在云会话中执行代理工作，每个会话都在自己的隔离虚拟机中运行，默认情况下 Claude Enterprise 的网络出口处于关闭状态，并且连接器凭据保留在沙箱之外。由于该工作在 Anthropic 管理的一个环境中运行，因此您的安全团队可以对其进行集中监控和控制。 Anthropic Trust Center 上的[安全最佳实践指南](https://trust.anthropic.com/resources?s=3puokpm2aa1nn24nbcp0l&name=unified-claude-security-best-practices) 涵盖了完整的架构。

## 管理成本

Claude Enterprise 定价仍然基于使用情况。最新的 Claude 模型比前代模型更加高效：按使用量计费，在典型工作负载上，Claude Opus 5.5 的运行成本比 Claude Opus 5 低 40%，而对于大多数工作，Claude Sonnet 5.5 的运行成本比 Claude Sonnet 5 低 30%。

根据任务的不同，代理工作可以比快速聊天使用更多的令牌。 Claude Enterprise 管理员有四个控件来管理此使用情况。高效模式是一种新设置，可在 Sonnet 和 Haiku 模型上保持统一的 Claude 体验。模型权利设置每个角色可以使用哪些模型。支出限额适用于组织、团体和成员级别，并且团体预算为团体提供每月共享的金额可供提取。

## 开始使用

统一的 Claude 体验现已普遍适用于 Claude Enterprise 计划。管理员可以在组织设置中管理部署。对 Claude Code 使用零数据保留、HIPAA 就绪配置或客户管理的加密密钥的组织将保留其当前配置。

有关详细信息，请参阅[管理设置指南](https://support.claude.com/en/articles/17444462)。如果您是现有的 Claude Enterprise 客户，您将收到一封有关为您的组织推出的电子邮件。
