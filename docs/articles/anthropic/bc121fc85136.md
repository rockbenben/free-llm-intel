今天，我们推出 [Claude for Manufacturing](http://claude.com/solutions/manufacturing)，这款插件自带的 skills 覆盖从为新订单报价到诊断停机机器的各项工作。估算员现在可以让 Claude 读取客户请求、比照类似订单的成本，并起草报价。该插件通过 connectors 接入 Autodesk Fusion、Infor、Microsoft 365 和 Oracle NetSuite，基于制造商自有的记录工作。Claude for Manufacturing 的设计让负责人在成果送达客户或供应商之前，能够先审阅并批准。

制造团队一天里往往要花大量时间收集信息。在 2025 年 Manufacturing Leadership Council 的一项调查中，79% 的制造商表示自己[手动录入数据](https://manufacturingleadershipcouncil.com/survey-october/)。有了 Claude 把每个流程推进到待审阅这一步，估算员可以专注定价，质量工程师专注修复，技术人员专注先检查哪里。

## **为制造商打造的 skills**

这款插件的 17 个 skills 覆盖销售、质量、运营、供应链、设计和设置。有的只处理单一任务，有的按顺序连跑多个任务，让 Claude 能把一项工作推进若干步骤，直到需要人工审阅为止。这些 skills 可运行的流程包括：

- **为新订单报价**：估算员可以让 Claude 读取客户请求、列出缺失信息、比照类似订单的成本，并起草可供发布的报价。
- **排查检验不合格**：质量工程师可以让 Claude 记录不合格情况、翻查过往报告里是否有同类问题、给可能原因排序，并起草纠正措施报告。
- **诊断设备故障**：技术人员可以让 Claude 读取传感器导出数据、维修记录、照片和手册，再把可能原因排序，供技术人员逐项排查并决定下一步。
- **改向其他供应商采购**：采购员可以让 Claude 拟好询价单，再比较回收的报价。
- **用 Autodesk Fusion 比选设计方案**：工程师可以让 Claude 基于现有模型生成多个变体，按工程师设定的目标打分，并起草决策备忘录。
- **生成生产报表**：工厂经理可以让 Claude 把生产数据汇总成一份报告，列出实际产量与目标的差距、设备停机时间，以及停机和欠产造成的损失。

这些 skills 只是起点。企业可以在此基础上按自身运营情况改制，我们也会逐步增加新的制造类 skills。

## **对接制造系统的 connectors**

Claude for Manufacturing 与制造运营核心软件协同工作，而这些软件仍是团队经营业务的中枢：

- **Autodesk Fusion**：工程师能在定案前比选更多设计方案，因为 Claude 会基于他们现有的模型生成变体。
- **Infor**：采购员和计划员可以在行动前核对采购订单与库存，因为 Claude 会在 Infor 里查出来。
- **Microsoft 365**：质量工程师可以把操作规程、供应商邮件和导出的报告汇进同一项工作，因为 Claude 能在共享文件夹和收件箱里找到它们。
- **Oracle NetSuite**：估算员可以对照真实订单、库存、生产工序和订单成本为新工作定价，因为 Claude 起草报价时会调取这些记录。

对于没有 connectors 的系统，制造商同样可以使用这款插件。他们把那些系统定期导出的文件存到 Microsoft 365，Claude 便据这些文件起草报价或汇总生产报表。

## **用 Claude 在 Infor 里改动数据**

为制造商提供核心软件的 Infor 也在[推出自己的插件](https://claude.ai/directory/infor)。借助 Claude for Manufacturing 里的 Infor connector，团队可以查询记录；借助 Infor 的插件，他们还能在 Claude 里直接改动 Infor 中的数据。

举例来说，如果一批钢材延迟两周到货，采购员可以问 Claude 哪些客户订单受影响、其他厂区还有多少钢材。采购员一经批准，Claude 就能向另一家供应商下达采购订单，并在 Infor 里重排受影响的生产计划。Claude 的访问权限遵循该采购员在 Infor 中的权限。

## **制造团队始终掌握主动**

skills 都以用户审阅收尾：估算员核对并发布报价，质量工程师确认纠正措施报告里的修复方案。为便于审阅，Claude 能把数字和论断回溯到对应的原始数据与文档。

Claude for Manufacturing 不操作设备。为此，Anthropic 正在开发 [Model Hardware Standard](https://www.anthropic.com/news/model-hardware-standard-research-preview)，这是一项研究预览，为可编程设备提供一套标准方式来描述自身的测量值、设置和安全限值。

## **如何开始使用**

在 Team 或 Enterprise 计划下，[安装插件](https://claude.ai/customize/plugins/id/45112ff2-6233-4954-b8ec-c448ef2d1e59%40anthropic-plugin-directory)，然后对 Claude 说"帮我们配置好"。Claude 会询问团队使用哪些系统、测试 connectors，并报告哪些 skills 暂时还无法完整运行。

想看插件实际运行，可[报名参加我们的技术网络研讨会](https://claude.com/resources/webinars/claude-for-manufacturing-put-your-plants-know-how-to-work)，时间为美国东部时间 11 月 17 日上午 11:00。想结合贵公司的制造系统详谈，请[联系我们的销售团队](https://claude.com/contact-sales)。
