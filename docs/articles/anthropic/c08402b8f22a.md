英国全能银行巴克莱银行 (Barclays) 正在扩大与 Anthropic 的战略合作，以在其全球运营中集成安全的企业级人工智能系统。

巴克莱正在将 Claude 扩展到整个银行，以加速软件开发、实现遗留系统的现代化并提高运营效率。作为此次部署的一部分，巴克莱预计到 2026 年底，Claude Code 的采用率将达到其开发人员总数的 50%，到 2027 年将上升到大多数软件工程师。

### 巴克莱银行与 Claude 合作，更好地服务客户

将人工智能集成到大型、复杂且高度监管的组织中需要强大的技术和严格的治理。扩大与 Anthropic 的合作反映了双方的共同承诺，即以负责任、可靠的方式部署人工智能，并以交付实际成果的方式，例如为客户提供更快的支持。

巴克莱银行集团联席首席运营官 Anne Marie Darling 表示：“衡量任何技术的真正标准是它对客户、客户和同事的影响及其带来的成果。” “在巴克莱银行扩大 Claude 的使用不仅仅是采用人工智能。它还涉及到改变工作的完成方式：重新构想流程，增强客户和客户体验，并在安全和治理良好的环境中建立更简单、更高效的组织。通过减少日常活动所花费的时间和简化决策，我们可以让同事将他们的专业知识集中在最重要的地方，解决更复杂的问题，加速创新，并为我们的客户、客户和业务提供更好的成果。”

巴克莱集团联席首席运营官 Craig Bright 表示：“软件工程和网络安全都在被日益强大的人工智能系统重塑。” “我们正在将人工智能作为一种日益代理的能力，嵌入到我们构建、测试、保护和操作技术的方式中。在巴克莱，我们利用 Claude 来帮助实现遗留平台的现代化，提高软件质量，并让我们的技术专家专注于最复杂的挑战。熟练的工程师、网络专家和值得信赖的人工智能能力的结合有可能从根本上改善大型企业的技术开发和管理方式。”

### Claude 提供知识协助以加快客户服务速度

巴克莱银行的同事知识助手就是已经开始实施的合作伙伴关系的一个例子，它可以帮助巴克莱英国员工在为超过 2000 万英国零售客户提供支持时更快地找到信息和答案。

该功能自 2025 年起就已上线，由 Claude 通过检索增强生成架构提供支持。超过 16,000 名同事已经使用了这款助手，并且它已经处理了超过 100 万次搜索。

其结果是更快地获取信息并更快地为客户提供支持。

### 提高巴克莱全球市场业务的运营效率

在巴克莱的全球市场业务中，克劳德模型正在帮助简化客户查询的处理和管理方式。

团队使用 Claude 模型对传入电子邮件进行分类、丰富和确定最佳处理路线，帮助确定优先级并确保请求包含运营同事采取行动所需的信息。该平台每天处理约 120,000 封电子邮件，减少了人工处理活动，同时帮助同事更有效地识别相关信息并采取行动。

### 负责任地扩展人工智能

随着巴克莱银行继续扩大人工智能的使用，负责任的部署仍然是合作伙伴关系的核心。该银行对人工智能用例应用强大的治理、安全控制和人工监督，确保技术在整个组织中安全有效地部署。

Anthropic 首席商务官 Paul Smith 表示：“我们与巴克莱银行的合作对于我们在英国来说是一个重要的里程碑。巴克莱银行为全球数百万客户和客户提供服务，因此他们对人工智能的标准很高。这就是巴克莱银行为 Claude 提供强大安全和监督的原因。” “Claude 现在帮助 16,000 名巴克莱同事为客户找到答案，每天分类 120,000 封电子邮件，到 2027 年将由大多数巴克莱工程师负责。很少有机构能将人工智能达到如此高的标准。”

### 展望未来

扩大的合作伙伴关系反映了巴克莱银行对利用人工智能提高生产力、增强弹性以及改善客户和客户成果的长期承诺。通过将 Anthropic 的前沿人工智能能力与巴克莱银行对负责任创新的关注相结合，两家公司正在共同努力，在全球最大的金融机构之一中扩展实际的人工智能应用。
