摩根大通正在全公司范围内向工程师以外的更多员工推广Claude。在商业和投资银行，工作更快地投入生产，并且公司根据其业务优先事项重新部署能力。

团队正在对其他遗留系统进行现代化改造，工程师正在构建自己的代理，包括拉取请求审查和自我修复代理，并分享有效的方法。

基础设施和运营团队使用 [Claude Code（在新选项卡中打开）](https://claude.com/product/claude-code) 进行监控、警报和根本原因分析。该公司的安全团队使用我们的前沿模型来更快地查找和修复漏洞，我们首先在 [Project Glasswing（在新选项卡中打开）](https://www.anthropic.com/glasswing) 中描述了这项工作。

## **联系产品团队和顾问**

与业务关系最密切的人也在与Claude一起建设。产品团队将需求直接转化为工程积压工作，其他团队使用Claude Code进行风险和控制评估以及项目规划。

知识工作已经在进行中。产品开发生命周期的大部分发生在代码之外：研究、需求、设计和规划。

在资产和财富管理业务中，摩根大通将具有最深刻的业务洞察力和最大胆的想法的人员与技术和产品专家一起组成了小型、授权的团队。这有助于他们更轻松地大规模构建和提供定制的客户投资解决方案。 Claude Code 现在已成为他们工程工作流程的一部分，团队的行动速度更快，同时在每项更改到达客户之前都经过更严格的测试。

上个月，摩根大通资产管理公司宣布推出一款连接器，将 55ip 的 ActiveTax Technology® 引入 [Claude for Financial Advisors（在新选项卡中打开）](https://claude.com/resources/articles/claude-for-financial-advisors)，将税务意识投资组合过渡分析纳入顾问的日常工作中。

## **专为受监管的公司打造**

Claude Code 在受控环境中运行，包括在其自己的基础设施上的公司容器化开发平台 Devspace。目的是防止代理直接访问员工凭据或内部系统。访问范围分阶段扩大，新的Claude模型要经过公司自己的批准流程，然后任何人都可以使用它们。

代码遵循相同的规则。数千个自动化测试和批准门会检查每一个更改，并且自动门会返回管道强制执行的硬通过或停止，因此 Claude 无法批准自己的工作。人们对每一次生产变更负责。

在过去的一年里，摩根大通对Claude的使用已经从软件工程扩展到网络防御，再到财务顾问的工具，摩根大通对我们的要求是塑造我们为其他受监管机构构建的产品。Claude在世界上最大的金融机构之一的控制下工作是我们的目标。
