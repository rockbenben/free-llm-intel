9 月 28 日，NVIDIA 宣布推出 [Open Agent Safety Platform](https://nvidianews.nvidia.com/news/open-agent-safety-platform)，这是一个用于加强 AI 安全的开源软件平台和参考系统设计。Anthropic 与 NVIDIA 合作，为 agent 技术栈增添了更多安全与控制层。

用 Managed Agents 构建的 agent 本来就在安全沙箱中工作，而 NVIDIA OpenShell 在该执行环境内部提供额外保护，控制 agent 能访问什么、能做什么。

## 安全 agent：架构与沙箱

### 把「大脑」和「双手」分开

agent 的风险之一是，不可信内容可能随 agent 一起进入沙箱。agent 会克隆仓库、读取网站、解析工具输出，甚至安装软件包，这些内容里都可能包含模型会当作指令执行的文本（prompt injection），或者会被运行的代码。业界大体上正在收敛到的一个架构解法是[把「大脑」和「双手」分开](https://www.anthropic.com/engineering/managed-agents)。

这意味着 harness、会话状态和凭据都位于沙箱之外的持久基础设施上，沙箱只成为 agent 用于执行的一个工具。对任何要构建安全 agent 的人来说，这个架构选择是容易迈出的第一步。Claude Managed Agents 遵循这些原则，其核心能力就是为安全 agent 开发而构建，自托管沙箱则让你能在自己掌控的基础设施上运行执行过程。

### Claude Managed Agents 的自托管沙箱

Managed Agents 就是为企业环境而构建的，支持自托管沙箱。使用自托管沙箱时，负责编排、上下文管理和错误恢复的 agent loop 留在 Anthropic 的基础设施上，而每个会话的工具调用则在由你掌控的环境中运行——可以是你自己的基础设施，也可以是托管沙箱提供商。代码执行、敏感文件、软件包、服务与数据都留在企业边界之内，受你自己的安全和运行时控制。

图 1：Claude Managed Agents 自托管沙箱

### NVIDIA OpenShell 规定 agent 能触及什么

NVIDIA 的 [OpenShell](https://www.nvidia.com/en-us/ai/openshell/) 是 NVIDIA 开源软件，可以作为该沙箱的运行时。它治理并监控所有 AI agent 的行为，并对每个操作执行策略。OpenShell 默认拦截一切，除非有规则允许。它会检查 agent 尝试使用的每个工具，并针对 agent 访问的文件、网络连接和数据应用规则。规则在 agent 之外强制执行，OpenShell 会记录它允许或拦截的每一个决定。

团队可以从较窄的权限起步，查看日志，再用 Claude 收紧规则，逼近任务所需的最小权限。随后 OpenShell 的策略证明器会用数学证明确认：在团队写下的规则下，agent 能触及什么。

图 2：Claude Managed Agents + NVIDIA OpenShell

### 团队正在构建什么

一些公司已经在用 Managed Agents 搭配自托管沙箱来增强 agent 安全。[Clay](https://claude.com/blog/claude-managed-agents-updates) 在沙箱中运行其 GTM 工程 agent Sculptor，该沙箱允许它挂载外部文件存储并随时安装软件包。[Rogo](https://claude.com/blog/claude-managed-agents-updates) 服务的是受高度监管行业的客户，因此它把 agent 的代码放在隔离的 microVM 中运行，让代码和数据都留在自己的边界内。

**可用性**

Claude Managed Agents 现已进入公开测试。NVIDIA OpenShell 以 Apache 2.0 许可开源，可在 [GitHub](https://github.com/NVIDIA/OpenShell) 和 NVIDIA 的[开发者资源页面](https://docs.nvidia.com/openshell/latest/about/overview)获取。

查阅我们的[文档](https://platform.claude.com/docs/en/managed-agents/self-hosted-sandboxes)了解更多，并按 [cookbooks](https://github.com/anthropics/claude-quickstarts/tree/main/managed-agents/self-hosted-sandboxes/openshell) 配置你的沙箱提供商。
