9 月 28 日，NVIDIA 宣布推出[开放代理安全平台（在新选项卡中打开）](https://nvidianews.nvidia.com/news/open-agent-safety-platform)，这是一个用于加强 AI 安全的开放软件平台和参考系统设计。 Anthropic 和 NVIDIA 合作，为代理堆栈带来额外的安全和控制层。

使用托管代理构建的代理已经在安全沙箱中完成工作，并且 NVIDIA OpenShell 在该执行环境中添加了额外的保护，控制代理可以访问和执行的操作。

## 安全代理：架构和沙箱

### 将大脑与双手分开

代理的一个风险是，不受信任的内容最终可能会与代理一起进入沙箱。代理克隆存储库、读取网站、解析工具输出，甚至安装软件包，其中任何一个都可以包含模型可能遵循的文本作为指令（提示注入）或运行的代码。业界普遍采用的架构修复方法是[将“大脑”与“双手”分开（在新选项卡中打开）](https://www.anthropic.com/engineering/management-agents)。

这意味着工具、会话状态和凭证位于沙箱外部的持久基础设施上，而沙箱只是代理用于执行的工具。对于任何构建安全代理的人来说，这种架构选择是简单的第一步。 Claude Managed Agents 遵循这些原则，具有专为安全代理开发而构建的核心功能，而自托管沙箱可让您在您控制的基础设施上运行该执行。

### 使用 Claude Managed Agents 的自托管沙箱

托管代理专为在企业环境中运行而构建，具有自托管沙箱。使用自托管沙箱，处理编排、上下文管理和错误恢复的代理循环保留在 Anthropic 的基础设施上，而每个会话的工具调用都在您控制的环境中运行，无论是在您自己的基础设施上还是通过托管沙箱提供商。代码执行、敏感文件、包、服务和数据保留在您的企业范围内，受您自己的安全和运行时控制。

图 1：Claude Managed Agents 自托管沙箱

### NVIDIA OpenShell 设置代理可以达到的范围

NVIDIA [OpenShell（在新选项卡中打开）](https://www.nvidia.com/en-us/ai/openshell/) 是 NVIDIA 的开源软件，可以充当该沙箱的运行时。它管理和监控所有人工智能代理的行为，并为每项操作执行策略。 OpenShell 会阻止一切，除非规则允许。它检查代理尝试使用的每个工具，并将规则应用于代理访问的文件、网络连接和数据。这些规则在代理外部强制执行，OpenShell 会记录它允许或阻止的每个决定。

团队可以从狭窄的权限开始，查看日志，并使用 Claude 来收紧规则，以实现任务所需的最少访问权限。然后，OpenShell 的策略证明器使用数学证明来确认代理在团队编写的规则下可以达到的目标。

图 2：Claude 托管代理 + NVIDIA OpenShell

### 正在建设哪些团队

公司已经在使用带有自托管沙箱的托管代理来增强代理安全性。 [Clay（在新选项卡中打开）](https://claude.com/blog/claude-management-agents-updates) 在沙箱中运行其 GTM 工程代理 Sculptor，使其可以挂载外部文件存储并动态安装软件包。 [Rogo（在新选项卡中打开）](https://claude.com/blog/claude-management-agents-updates) 为高度监管行业的客户提供服务，因此它在隔离的 microVM 中运行其代理的代码，并将代码和数据保留在自己的边界内。
