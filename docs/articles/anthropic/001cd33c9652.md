今天，我们推出 Claude Whiteboards 和 Claude Sheets 的 beta 版，[Claude Dashboards](https://claude.com/resources/articles/dashboards-and-motion) 则以 Claude Data 之名正式可用。Whiteboards 是一块共享画板，团队可以在上面与 Claude 一起头脑风暴；Sheets 是 Claude 与你共同构建、编辑的电子表格；Claude Data 则加入了数据故事、认证查询和实时共享。这些功能面向所有付费计划开放。

过去，用 Claude 做一个项目，往往要把它产出的内容搬到另一个工具或程序里，而 Claude 在那里无法实时跟进进度和改动。现在，你的文档、看板、表格和仪表板都能留在 Claude 里，团队成员可以一起继续编辑。准备好之后，你可以把这些成果直接带到我们合作伙伴的工具中，接着在那里推进。

## Claude Whiteboards

很多人把 Claude 当作一起想问题的搭档，但和它头脑风暴，通常意味着把结果复制粘贴到别处，才能开始与同事一起讨论、协作。现在，你可以把一团乱麻的计划说出来，和 Claude 边聊边理，Claude 会把它整理成一块带时间线的看板，标好负责人和日期，你和团队就能实时协作。比如在复盘会上，每个人都能添上自己的笔记，Claude 可以按主题归类，并为每个人起草待办事项。你只要在画板上拖一个框圈住某块区域，就能针对它向 Claude 提问。头脑风暴结束后，Claude 可以把画板变成文档或演示文稿，也可以导入 Lucid、Miro 或 Zoho 的 Vani 之类的工具，让你和团队继续在上面加工。

## Claude Sheets

Claude 现在能生成带标签页、公式、格式和下拉菜单的电子表格，往往只要一句 prompt 就够，比如要一个营销活动跟踪表或招聘预算表。它可以直接在单元格里编辑，并把每一处新改动标注出来，方便你追踪变更。你可以把表格分享给团队，和 Claude 一起在上面协作。

目前，表格只具备基础的电子表格功能，我们还在继续加。需要 Excel 的完整功能时，你可以把文件导出为 .xlsx 或 CSV，也可以改用 [Claude for Excel](https://claude.com/claude-for-microsoft-365)。你还能在 Airtable、Asana、monday.com 和 Smartsheet 等合作伙伴工具里接着做。

## Claude Data

[Claude Dashboards](https://claude.com/resources/articles/dashboards-and-motion) 于 10 月推出 beta 版，让团队可以对存放在 Amazon Redshift、BigQuery、ClickHouse 等工具里的公司数据快速发问。从今天起，它以 Claude Data 之名正式可用。改名是因为企业使用数据的方式早已不止于仪表板，产品如今覆盖的工作范围也更广。认证查询和实时共享仍处于 beta 阶段。团队可以这样用 Claude Data：

- **创建经过认证的指标定义。 **你的数据团队可以认证所有人都该用的查询，这样就不会出现基于相互矛盾的数据去搭建或使用仪表板的情况。基于这些指标生成的图表会带上 "certified" 徽章，表明它们已通过认证。
- **撰写故事** **从数据出发。** 你可以在 Claude Data 中与 Claude 一起，根据指标起草数据故事或带旁白的视频，供你在分享前审阅。
- **把最新数字分享给** **所有人。** 借助实时共享，同事打开共享仪表板就能看到最新数字，哪怕他们没有权限访问那些让数据保持更新的 connectors。查看者只能看到你已批准的查询结果，无法借你的权限运行别的查询。
- **贴合你的视觉风格。 **Claude Data 现已支持设计系统。
- **用缓存加快加载。 **过去，每个仪表板每次打开都要重新加载。现在，仪表板支持缓存，还可以按单个仪表板分别设置刷新节奏。
- **追踪随时间的变化。 **Claude Data 现在会记录改动，你能看到谁改过，需要时还能回滚到某个具体版本。

Claude Data 的合作伙伴包括 Amplitude、Mixpanel、Omni、PostHog 和 Sigma。

## 也能在其他工具里继续工作

从今天起，[交互式 connectors](https://claude.com/resources/articles/interactive-connectors-full-tool) 可以完整应用的形式在对话旁打开，或全屏展开。你既可以自己在 Adobe、Atlassian、Box、Notion 等工具里操作，也可以让 Claude 和你一起改动。

## 开始使用

Claude Whiteboards、Sheets 和 Data 在网页、桌面和移动端都能用。Claude Data 需要数据 connector，比如数据仓库或 CRM。

**面向管理员：** 在 Team 计划中，三者默认全部开启。在 Enterprise 计划中，Claude Whiteboards 和 Sheets 默认关闭，Claude Data 则于 2026 年 11 月 19 日默认开启。你可以随时在组织设置 > Artifacts 里调整。
