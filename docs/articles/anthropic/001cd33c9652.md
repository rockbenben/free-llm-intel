今天，我们推出测试版 Claude Whiteboards 和 Claude Sheets，并且 [Claude Dashboards（在新选项卡中打开）](https://claude.com/resources/articles/dashboards-and-motion) 以 Claude Data 的形式普遍提供。 Whiteboards 是一个共享板，您的团队可以在其中与 Claude 进行头脑风暴；Sheets 是 Claude 与您一起构建和编辑的电子表格；Claude Data 添加数据故事、经过认证的查询和实时共享。所有付费计划均提供这些服务。

与 Claude 一起完成一个项目通常意味着将输出转移到另一个工具或程序，而 Claude 无法实时跟踪进度和更改。现在，您的文档、看板、工作表和仪表板可以保留在 Claude 中，您的团队可以继续一起编辑。准备好后，您可以将输出直接导入我们合作伙伴的工具中并继续在那里工作。

## Claude白板

许多人使用Claude作为思想伙伴，但用它进行头脑风暴通常意味着将结果复制粘贴到其他地方，这样你就可以开始头脑风暴或与同事合作。现在，您可以与 Claude 大声讨论杂乱的计划，Claude 可以将其变成带有所有者和日期的时间表的板，以便您和您的团队可以实时协作。例如，在复古会议中，每个人都可以添加自己的笔记，Claude可以按主题对它们进行分组，并为每个人起草行动项目。您可以通过在其周围拖动一个框并询问 Claude 问题来关注面板的任何部分。当您完成头脑风暴后，Claude 可以将板子变成文档或套牌，或者将其放入 Lucid、Miro 或 Zoho 的 Vani 等工具中，您可以在其中继续与团队一起工作。

## Claude表

Claude现在可以生成带有选项卡、公式、格式和下拉菜单的电子表格，通常只需询问活动跟踪器或招聘预算等提示即可。它可以在单元格中进行编辑，概述每个新的编辑，以便您可以跟踪更改。您可以与您的团队共享工作表，以便您和 Claude 可以一起处理它们。

目前，工作表具有简单的电子表格功能，但我们正在努力添加更多功能。当您需要 Excel 的完整功能时，可以将文件导出为 .xlsx 或 CSV，或使用 [Claude for Excel（在新选项卡中打开）](https://claude.com/claude-for-microsoft-365)。您还可以继续使用合作伙伴工具，包括 Airtable、Asana、monday.com 和 Smartsheet。

## Claude·数据

[Claude Dashboards（在新选项卡中打开）](https://claude.com/resources/articles/dashboards-and-motion) 于 10 月份推出测试版，使团队能够在 Amazon Redshift、BigQuery 和 ClickHouse 等工具中快速询问公司的数据问题。从今天开始，它通常以 Claude Data 的形式提供。我们更改了名称，因为公司使用数据的方式比仪表板更广泛，并且该产品现在涵盖了更广泛的工作方式。认证查询和实时共享处于测试阶段。以下是团队使用 Claude Data 的一些方法：

- **创建经过认证的指标定义。 **您的数据团队可以验证每个人都应该使用的查询，因此您最终不会构建或处理具有冲突数据的仪表板。基于这些指标构建的图表带有“认证”徽章，表明它们已经过认证。
- **根据数据制作故事**。** 您可以在 Claude Data 中与 Claude 合作，根据您的指标起草数据故事或解说视频，以便您在共享之前查看。
- **与** **所有人共享当前数字。** 通过实时共享，您的同事可以在打开共享仪表板时看到最新的数字，即使他们无权访问保持该数据最新的连接器。查看者可以看到您已批准的查询的结果，并且无法使用您的访问权限运行其他查询。
- **符合您的外观和感觉。 **Claude Data 现在支持设计系统。
- **通过缓存获得更快的加载速度。 **以前，每个仪表板都会在每次加载时重新加载。现在，仪表板支持缓存，并且可以基于每个仪表板设置刷新节奏。
- **跟踪随时间的变化。 **Claude Data 现在已跟踪更改，因此您可以查看谁进行了编辑，并在需要时回滚到特定版本。

我们的 Claude Data 合作伙伴包括 Amplitude、Mixpanel、Omni、PostHog 和 Sigma。

## 也可以使用其他工具

从今天开始，[交互式连接器（在新选项卡中打开）](https://claude.com/resources/articles/interactive-connectors-full-tool) 可以作为完整应用程序在对话旁边或全屏打开，这样您就可以自己使用 Adob​​e、Atlassian、Box 和 Notion 等工具，或者要求 Claude 与您一起进行更改。

## 开始使用

Claude 白板、表格和数据适用于 Web、桌面和移动设备。 Claude Data 需要数据连接器，例如仓库或 CRM。

**对于管理员：** 在团队计划中，默认情况下所有三个都处于启用状态。在企业版计划中，Claude Whiteboards 和 Sheets 默认关闭，而 Claude Data 在 2026 年 11 月 19 日默认打开。您可以随时在组织设置 > 工件中更改这些设置。
