今天我们扩展了 Claude Startups——我们面向在 Claude 上构建公司的创始人的计划。成员权益包括一年的 Claude Team 套餐、API credits、有助于运营一家 AI 原生公司的工具的特别优惠、与 Anthropic 的 Applied AI 团队的 office hours，以及更多。

## **我们为什么扩展这个计划**

把一个想法变成产品，从未像今天这样可行。一个小团队可以以创纪录的速度搭出原型，没有编程背景的人也能交付可用的软件。但想法只是第一步。当任何人都能快速构建时，就越难知道是什么让你的产品与众不同，尤其是在它底下的模型还在持续变强的情况下。创始人还得承担起步的成本，而合适的工具既难找、又难快速配好。这正是紧密的伙伴关系能帮上忙的地方：与构建模型的人共处的那段时间，能让你在了解模型将往何处去、决定在哪里做差异化，以及尽早化解这些挑战上有所作为。

这就是我们创建 Claude Startups 的原因。自今年早些时候启动该计划以来，成员们获得了 Claude credits 和工具、连接到一个构建者社群，以及获取生态新闻和产品功能的通道。许多高速增长的 AI 原生公司已加入该计划，而在下一阶段我们要向更多公司开放。

## **今天就开始构建**

我们希望在 Claude 上构建的创始人能够成功，而早期我们能做的最有用的事，就是从一开始把我们的模型和产品交到你手上。Claude 每隔几个月就会实实在在地变强一层，而一家为未来而建的公司，可以在我们模型发布当天就把它们用起来。

Claude Startups 成员最多可获得价值 $7,000 的 Claude 产品与 credits 用于构建*：

- **免费的 Claude Team 一年：** 为此前没用过 Team 的公司提供最多五个 Premium seat。
- **一笔 $1,000 的一次性 API credit 用来起步：** 一旦你通过审核即可使用，所以你能马上开始——把 API 接通、试几个想法、跑早期的 eval。

## **运营一家 AI 原生公司所需的工具**

全新的 Claude Startup Stack 是一组面向 startup 日常所用工具的权益，从销售到设计再到数据工程。成员可以从与 Claude 共建的公司那里拿到总价值最高 $45,000 的折扣与 credits**。

### **额外权益**

成员还会得到一套支持业务成长的后盾，从触达新客户，到和我们的团队一起解决技术问题，再到与其他创始人一同学习。

- **与 Anthropic 保持贴近：** 成员可以预约与 Anthropic Applied AI 团队的线上 office hours。
- **触达 Claude 用户：** Claude Marketplace 是使用 Claude 的人寻找 connector 和 plugin 的地方，因此一个通过审核的 listing 会让你的产品出现在他们使用 Claude 各应用的路径上。成员会获得手把手的帮助来构建自己的产品并提交审核。
- **接入社群：** 获得 Founder House、hackathon、meetup 等活动的参与资格（名额有限），以及我们的 Startup Newsletter，里面有产品与生态新闻，还有被报道的机会。

**立即申请**

成立五年以内、或近两年获得融资的 startup 有资格申请。我们创建这个计划，是因为我们相信 AI 的好处会主要通过那些在模型之上构建的公司传递给大多数人，而不是只通过模型本身。这让与创始人和开发者的紧密协作成为我们使命的核心。AI 会让他们有能力为社会带来更快的科学发现、全新的产品品类，以及能力更强的公司。Claude Startups 就是我们帮助更多这样的公司起步、并在它们成长过程中提供支持的方式。

访问 [Claude Startups 页面](https://claude.com/programs/startups)了解更多并申请。
