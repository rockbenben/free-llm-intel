自从 [Claude Security](https://claude.com/product/claude-security) 四月份进入公开测试版以来，数千个组织已使用它发现了超过一百万个漏洞。

现在，Claude Security 不再需要等待某人开始扫描，而是可以在代码更改时跟踪您的存储库，跟踪哪些结果已得到修复，并使用您的团队告知的有关您的环境的信息来决定什么是重要的。 Claude Security 由我们全系列的模型（包括 Claude Mythos）提供支持，无需访问网络验证程序。

最新版本的 Claude Security 现已面向 Claude Enterprise 客户推出公开测试版。组织每月可获得 25,000 美元的免费使用积分，为期两个月。该优惠适用于 2026 年 12 月 31 日之前的使用。您可以在[帮助中心](https://support.claude.com/en/articles/14661296-use-claude-security)查看完整条款。

## **持续监控与您的代码保持同步**

扫描捕捉一瞬间，代码每天都在变化。团队告诉我们，他们希望报道能够保持最新状态，而无需任何人安排。

创建一个项目，通过 Claude GitHub 应用程序（包括 GitHub Enterprise Server）或使用来自 GitLab 和其他 Git 提供商的访问令牌连接您的存储库，然后为每个存储库选择分支和范围。 Claude 运行深度基线扫描，然后根据风险和复杂性定期扫描更改，以便您的发现列表保持接近代码的当前状态。

一个项目可以拥有多个存储库，因此 Claude 可以捕获服务之间存在的问题，例如信任客户端应该验证的输入的后端。

![克劳德安全用户界面](https://assets.claude.com/fe39204ec42e8d48c853bf16bb08bdb19bf99a22.png)

## **当修复发布时，调查结果被标记为已修复**

大多数修复都是在发现问题的工具之外进行的。 Claude Security 会根据已更改的代码检查未解决的问题，并在修复完成后将其标记为已修复，无论您的团队是在 Claude 代码中还是在单独的流程中修复了该问题。如果 Claude Security 稍后再次发现该问题，则会自动重新打开该发现。

![克劳德安全用户界面](https://assets.claude.com/579a7fb43c95d281cf38ba2dafca75eea40a7058.png)

## **您团队的知识塑造扫描**

每个环境都有扫描器无法仅从代码中看到的控件。团队想要一种方法来告诉 Claude Security 有关这些控制的信息，并查看相互依赖的服务。现在，每个项目都有一个知识库，您可以在其中描述如何部署代码、应用哪些安全策略以及团队中的新安全工程师需要了解的任何内容。

![克劳德安全用户界面](https://assets.claude.com/440f4c1037a629695ec66eb0a17c218782b51d35.png)

Claude Security 还会根据您的代码生成威胁模型，您的团队可以审查和编辑。后续扫描使用这些威胁模型来决定哪些内容值得标记。添加的上下文还可以帮助 Claude Security 跳过您的环境已处理的风险。

## **每个发现的严重性和利用路径**

每个发现都带有严重性评级，根据项目的威胁模型进行判断，并解释攻击者如何访问易受攻击的代码，以便团队可以首先修复实际可访问的内容。调查结果可以包括攻击路径图。

![克劳德安全用户界面](https://assets.claude.com/58c85ec0105dd3b16b367ae71e70c14db55e6d4f.png)

## **调查结果到达您的工具，并控制更大规模的部署**

新的 API 允许您将 Claude Security 集成到现有的工作流程中。您可以列出和阅读项目和发现、解决或重新打开发现以及创建和管理项目及其存储库。用户可以在 Claude Security 设置中创建个人访问令牌，它只能查看和更改用户可以查看和更改的内容。当有新发现时，Webhook 还可以通知您的系统。

Claude Security 还可作为 [Claude.ai](http://claude.ai) 和 Claude Code 中的 MCP 连接器使用。工程师可以调出一个发现，向克劳德询问，开始修复，并在同一会话中将其标记为已解决。

新的基于角色的访问控制让管理员可以决定谁可以查看项目、对结果进行分类以及创建项目。组织可以向更多拥有代码的团队开放 Claude Security，而无需授予每个人创建项目的权限。
