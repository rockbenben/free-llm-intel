在线购物通常是一件一件地挑：顾客看中一件毛衣，还得再去找搭配的裤子和鞋。为了改变这一点，J.Crew 今天在 [JCrew.com](https://www.jcrew.com/) 上线了 Style Advisor——一位 AI 造型师，帮顾客按整套穿搭来选购。J.Crew 团队用 [Claude Code](https://claude.com/product/claude-code) 搭建它，调用了多个 Claude 模型，从 Fable 到 Haiku，每个都对应自己最擅长的活儿。目前美国地区的女装和男装款式已可使用。

四十多年来，J.Crew 自己的造型师靠平衡比例、色彩和层次，再用出人意料的方式搭配单品，搭出完整造型。Style Advisor 把这份专长搬到了线上。顾客说出需求，比如海滩婚礼或初次工作面试要穿什么，它就从 J.Crew 自家拍摄的大片里给出整套造型。顾客可以接着不断调整，购物于是变成一场看得见的对话。

## **它是怎么搭起来的**

J.Crew 的产品团队先用 [Claude Fable](https://www.anthropic.com/claude/fable) 5.1——Anthropic 面向复杂、开放式工作的模型——规划 Style Advisor 该如何像造型师一样思考，再在 Claude Code 里用 [Claude Opus](https://www.anthropic.com/claude/opus) 5.5 做出可运行的原型。J.Crew 的工程师把这个原型推上了生产环境。每次对话里，[Claude Sonnet](https://www.anthropic.com/claude/sonnet) 5.5 充当造型师，决定回复的每一步；[Claude Haiku](https://www.anthropic.com/claude/haiku) 5.5 则处理快速、聚焦的小任务，让 Style Advisor 答得快。由于每套造型都出自 J.Crew 造型师之手，推荐始终与 J.Crew 的造型主张保持一致。

### **顾客怎么用 Style Advisor**

- **按整套穿搭选购。** 每条推荐都源于 J.Crew 造型师为品牌目录拍摄打造的造型，Style Advisor 用照片呈现，顾客一眼能看到整套效果。
- **从一件单品搭起。** 顾客可以从某一件开始，得到能补全整套造型的其他单品建议。
- **按场合搭配。 **顾客说出要去哪里，无论是度假、节日聚会还是婚礼，就能拿到相应推荐。
- **感受 J.Crew 的风格主张。 **Style Advisor 用的，和 J.Crew 造型师在门店里用的是同一套造型原则。

## **接下来**

上线之初，Style Advisor 帮顾客找到新的穿搭灵感，买得更有底气。往后，J.Crew 计划按每位顾客的偏好和过往购买记录调整建议，让它更贴合个人，并推广到更多市场和产品线。

"随着消费者期待不断变化、AI 为零售打开新的可能，J.Crew 正在挑战传统的在线购物模式，从一件件单品搜索，走向更连贯、由灵感带动的体验，"J.Crew Group 首席执行官 Libby Wadle 说，"很久以来，我们一直在想顾客将来会怎么购物，以及我们如何引领这场变化，而不是被动应对。我们看到一个从根本上重新思考购物体验的机会。通过与 Anthropic 的合作，我们把 J.Crew 数十年在造型、商品企划和创意上的积累汇聚起来，一起塑造顾客行为的下一步。"

"J.Crew 有着时尚界辨识度最高的风格主张之一，它的团队用 Claude 把这份专长以全新的方式带到了顾客面前，"Anthropic 首席商务官 Paul Smith 说，"他们用前沿模型搭起这套体验，再用更快、更高效的模型来跑，于是顾客能很快得到答案，又不失品牌一贯的造型调性。"

***今天就动手，用 [Claude Code](https://claude.com/product/claude-code) 构建吧。***
