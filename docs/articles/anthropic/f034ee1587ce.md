# 把 Claude Mythos 5 的网络安全能力带给更多防守方

- 类别：[产品公告](https://claude.com/blog/category/announcements)
- 产品：未发现相关条目
- 日期：2026 年 8 月 21 日
- 阅读时长：5 分钟

*我们分享一份关于我们帮助更多团队用前沿能力做网络防御这一努力的更新。*[*Claude Mythos 5*](https://www.anthropic.com/news/claude-fable-5-mythos-5)* 现已在 *[Claude Security](https://claude.com/product/claude-security)* 中可用，并即将进入合作伙伴的网络防御工具。我们还启动了一项 3,500 万美元的基金来帮助保护开源软件，并分享扩展我们*[Cyber Verification Program](https://support.claude.com/en/articles/14604842-real-time-cyber-safeguards-on-claude-opus-and-sonnet)* 的计划。*

四月，我们启动了 [Project Glasswing](https://www.anthropic.com/glasswing)，把我们能力最强的前沿模型 Claude Mythos Preview（及其继任者 Claude Mythos 5）交到一小批保护全球最关键软件的机构手中。这让防守方赢得了一段窗口时间，在具备类似能力的模型普遍可用或落入恶意行为者之手之前，先找到并修复漏洞。

我们的目标一直是把 Mythos 级的防御扩展到我们在安全前提下能覆盖的尽可能多的防守方。为此，我们一直在开发[安全分类器](https://www.anthropic.com/research/next-generation-constitutional-classifiers)和防护，让我们能扩大对 Mythos 级模型的访问、又不把它们的攻击性网络能力交到错误的人手里。[Claude Fable 5](https://www.anthropic.com/news/claude-fable-5-mythos-5) 是第一步：它让模型广泛可用，同时屏蔽军民两用的网络工作。

今天，我们迈出下一步。风险最高的行为发生在用户能直接访问模型时——那时恶意行为者能试图把它引向有害用途。但如果用户只能收到特定的输出，比如一个漏洞补丁或一条安全告警，那种风险就低得多。我们宣布的这些变化让用户更大程度地获得防御性成果，同时围绕对模型的直接访问维持恰当的护栏：

- **把 Claude Mythos 5 集成进防守方所依赖的工具。** 我们正与我们的网络安全技术和服务伙伴合作，把 Claude Mythos 5 集成进防守方已在用于保护其软件的产品和服务中。
- **Claude Security 扫描现在可在 Claude Mythos 5 上运行。** Claude Enterprise 套餐的客户现在可以在 Claude Security 里运行我们能力最强的模型，用它扫描他们的代码库、寻找安全漏洞并建议补丁。
- **为开源安全提供 3,500 万美元额度。** 我们新的 Defender Advantage Fund（0xDAF）将向那些致力于修补开源项目漏洞、把扫描和修补开源软件的流程部分自动化、并尝试新安全方法的组织提供 3,500 万美元额度。
- **扩展我们的 Cyber Verification Program。** 该计划已经在 Opus 和 Sonnet 模型上为经过审查的防守方放宽防护。未来几周，我们会把该计划扩展到在 Opus 和 Sonnet 上覆盖更广的军民两用能力，Mythos 级的访问随后跟进。

我们的目标始终是，帮助各机构适应网络安全随着 AI 模型日益强大而带来的节奏和要求。我们会继续开发防护、访问计划和社区支持，把我们能力最强的模型安全地提供给广泛的人群和机构。

## 把 Mythos 集成进现有的网络防御工具

保护医院、公用事业、金融系统和软件供应链的团队，已经依赖一整套产品和服务来做安全运营、事故响应、威胁情报和检测工程。让前沿能力触达这些防守方最快的方式，就是把 Mythos 级模型集成进他们已在运行的工具。

我们许多伙伴已经[在 Claude Opus 上构建了网络产品](https://claude.com/blog/how-our-partners-are-putting-opus-to-work-for-cybersecurity)，帮助安全团队更快地分类告警、识别威胁和修复漏洞。我们现在正与这些伙伴及更多伙伴合作，把 Claude Mythos 5 构建进他们的产品和服务，从而他们能把 Mythos 级的防御成果交付给他们的客户。

当终端用户使用这些产品之一时，他们并非在与 Mythos 直接互动。相反，他们通过一个专门打造的界面工作，该界面在后台为一个定义好的任务运行 Mythos，用户只收到该产品本意要提供的那份特定成果物。例如，一个修复漏洞的工具，其输出可能是一份建议补丁的列表。这份输出由 Mythos 生成，但用户没有办法去 prompt 模型，比如说去开发一个漏洞利用代码。我们和我们的伙伴也部署了防滥用措施，以验证模型保持在它预期的范围内。

我们在这项工作上还处于早期，并预期它会随时间扩展。如果你构建安全产品或服务、想把 Claude Mythos 5 带给你的客户，你可以[在此登记你的意向](https://claude.com/form/mythos-cyber-partner)。

## 让企业客户在 Claude Mythos 5 上使用 Claude Security

从今天起，[Claude Security](https://claude.com/product/claude-security) 扫描可在 Claude Mythos 5 上运行。Claude Security 扫描代码库寻找漏洞，并建议补丁交人类审阅；它目前对 Claude Enterprise 客户处于公开 beta，用 Mythos 5 做的扫描按标准 token 用量计入你现有套餐计费，无需单独的附加项。

企业管理员可在[管理控制台](http://claude.ai/admin-settings/claude-code)启用 Claude Security。从 [claude.ai/security](http://claude.ai/security)，用户可以选择一个仓库，用 Claude Mythos 5 来扫描。随后 Claude 扫描代码库寻找漏洞，并返回每一条发现，附一个 [CWE](https://cwe.mitre.org/)（通用缺陷枚举）类别、置信度和严重性评级，以及一个建议的修复。

用户随后可以打开网页版 Claude Code 来实施修复。交互式修补使用你组织在 Claude Code 里能访问的模型。Mythos 扫描本身并不把 Mythos 访问扩展到别的界面。每一个补丁都必须经人类审阅并批准后，才能被实施。

Claude Security 用 Mythos 5 扫描你拥有的代码，返回详细的发现而非原始输出，且不暴露模型本身。这意味着防守方可以访问 Claude Mythos 5 的能力，而模型不会变得对那些可能滥用它的人可及。

关于 Claude Security 的更多内容，见我们的[上手指南](https://claude.com/resources/tutorials/getting-started-with-claude-security)。

## 启动 Defender Advantage Fund 以保护开源软件

世界上一些使用最广泛的程序运行在开源软件上。然而这些项目往往由志愿者或非营利基金会维护，他们可能缺乏资源或人力去全面保护自己的项目免受攻击。通过 Project Glasswing，我们向开源安全组织直接捐赠了 400 万美元，为计划中的开源安全基金会提供额度，帮助扫描和修补广泛使用的项目，并支持像 [Akrites](https://akrites.org/) 和 [Gold Eagle](https://www.whitehouse.gov/releases/2026/07/white-house-launches-gold-eagle-initiative-for-unprecedented-cybersecurity-vulnerability-coordination/) 这样的协调式漏洞修复努力。

我们新的 Defender Advantage Fund（0xDAF）在这一工作之上，用 3,500 万美元的 Claude 额度资助那些帮助开源维护者保护其软件的组织。资助将聚焦三个领域：修补广泛使用项目中的现行漏洞、以其他项目可复制的方式把扫描和修补自动化，以及帮助项目追求更雄心勃勃、使其能抵御整类攻击的安全方法。

我们从少量更大的试点资助起步，以学习什么有效、什么最能扩展。我们会在接下来几周分享首批受助者的细节。

## 扩展我们的 Cyber Verification Program

迄今为止，我们的 Cyber Verification Program 已在组织使用 Claude Opus 和 Sonnet 模型时提供对军民两用能力的访问。计划中的组织会体验到放宽的防护，让那些在他们有权保护的系统上开展正当网络安全工作的、获认可的团队所受到的打断最小化。

未来几周，我们正在演进该计划，以扩大对 Claude Mythos 受防护的访问。作为其中一部分，诸如漏洞分类和验证这类防御能力的访问，将扩展到 Mythos 级模型，而网络防守方在 Claude Opus 和 Sonnet 级模型上会看到更少的拦截。此外，我们正通过 Project Glasswing、与美国政府伙伴协作，继续扩大对 Claude Mythos 的访问，聚焦于那些符合严格安全控制要求、保护至关重要基础设施的守护者。

我们会在接下来几周分享关于 Cyber Verification Program 扩展的更多细节。在此期间，我们鼓励所有开展正当网络安全工作的安全团队申请该计划，以在 Claude Opus 和 Sonnet 模型上获得放宽的防护。如果你已经注册并被接受，无需采取任何行动；我们会带着更新联系你。
