- Some customers might encounter [429 (`rate_limit_error`) errors](https://platform.claude.com/docs/en/api/errors) following a sharp increase in API usage because of acceleration limits on the API. Previously, 529 (`overloaded_error`) errors would occur in similar scenarios.
