# Claude 在 Cowork 中拥有了自己的浏览器

Claude 会打开自己的浏览器，在桌面应用内浏览网站、阅读页面、填写表单。

Claude 如今在桌面端的 Claude Cowork 里内置了一个浏览器。当某项任务需要使用网站时，侧边栏会打开一个浏览器，Claude 在其中导航网页、阅读、点击和输入。你现在可以把任务里与网络有关的部分交给它，而自己留在原地：Claude 能填表单、从仪表盘拉取数字，或操作一个没有连接器的门户。无需扩展、无需设置，除非你主动选择，你自己的浏览器中不会有任何内容被共享。

在此之前，要在 Cowork 里让 Claude 具备使用网络的能力，就得通过 [Claude in Chrome](http://claude.com/claude-in-chrome) 扩展把你对自己浏览器的访问权限交给它。当工作就在你已打开的页面上时，那仍是正确的选择。但很多网络任务并不需要你 *自己的* 浏览器，只需要 *一个* 浏览器——而现在 Claude 有了一个。

它本周将在 Claude 桌面应用中向 Pro、Max 和 Team 套餐推出。企业管理员从今天起就可以为其组织开启。

## 用哪个浏览器、何时用

那是 Claude 的浏览器，不是你的。内置浏览器与你自己的是分开的。Claude 永远看不到你的标签页、书签或密码。为了保持你在自己网站上的登录状态，你可以逐个站点把你的登录信息带过来，来源可以是 macOS 上的 Chrome、Edge 或 Firefox，以及 Windows 和 Linux 上的 Firefox。除非你主动选择纳入，银行、邮件和单点登录站点会被排除在外。

这也是 Claude 使用网络的两种方式之间的区别。内置浏览器用于在你继续工作的同时把网络任务交给 Claude：为一份报告收集研究资料，或从供应商门户里收齐本月的发票。Claude in Chrome 则用于你已经打开的那个页面、你已经登录的那些账户，例如更新你的 CRM、处理你的收件箱，或编辑你眼前的那份文档。

如果你已经在用 Claude in Chrome，它会继续工作并保持为你的默认；否则 Claude 使用内置浏览器。随时可在「设置 → Cowork → 首选浏览器」中切换。

## 保持掌控

内置浏览器与任何在浏览器中行动的 AI agent 一样，存在 [提示注入](https://www.anthropic.com/research/prompt-injection-defenses) 风险——页面中隐藏的指令会试图转移 Claude 的目标。它运行与 Claude in Chrome 相同的防护，包括那些把你要求的与 Claude 采取的行动进行比对的检查。我们在 [Claude in Chrome 博客文章](http://claude.com/blog/%20claude-in-chrome-generally-available) 中描述了它们。这些措施能显著降低风险但无法消除，因此我们建议从你信任的站点开始使用。更多内容请阅读我们的[安全指南](https://support.claude.com/en/articles/12902428-use-claude-in-chrome-safely)。

## 如何开始

内置浏览器将在接下来的一周内，向 macOS、Windows 和 Linux（测试版）上的 Claude 桌面应用中的 Pro、Max 和 Team 套餐推出。一旦推送给你，它默认开启：交给 Claude 一个涉及网站的任务，浏览器就会自行打开。在企业套餐上，它现已可用，管理员可在「组织设置 → Cowork → 内置浏览器」中管理。

内置浏览器栖身于桌面应用。从网页或手机上，只要你的桌面应用处于打开且在线状态，Claude 仍能操控它。在没有桌面应用的网页环境下，Claude in Chrome 仍是给 Claude 配备浏览器的途径。
