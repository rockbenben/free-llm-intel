今年早些时候，我们推出了[交互式 connectors](https://claude.com/resources/articles/interactive-tools-in-claude)，把工具的小型实时视图带进 Claude。从今天起，只要 connector 支持，你就能在对话旁打开某个工具，或把它展开到全屏，让 Claude 陪你一起操作，直接做出改动。

这项能力正在网页版和各计划下的 Claude 桌面应用中陆续推出，属于把聊天和 Cowork 合到一起的[全新 Claude 体验](https://claude.com/resources/articles/cowork-is-now-claude)的一部分。等你的账户升级到新版 Claude，或组织为你开启后，就能看到这些功能。

新增内容：

- **Claude 能在你打开的工具里干活。** 你可以让 Claude 改动当前打开的页面、某一行或某个文件，并像批准 connector 操作那样逐项确认它的动作。改动会随做随现在工具里，你可以始终和它并肩推进。
- **整个工具** **在对话旁打开。** 你可以在工具里操作，需要空间时把聊天收起或切到全屏。对 Confluence、Notion 这类工具来说，这意味着你拿到的是登录自己账号的完整编辑器，而不是受限的预览。
- **直接打开已连接的工具，不必先写一段 Claude prompt。 **需要 Claude 帮忙时，在同一块屏幕上开口就行。
- **把最常用的工具固定住。** 你可以把它们排在 artifacts 旁边，在侧边栏和 + 菜单里一键打开。

## 在你常用的工具里与 Claude 协作

我们先从目录中一小批工具开始，包括 Asana、Canva、Carta、Dropbox、monday.com、Smartsheet、Vercel 和 Webflow。

下面是 Claude 里现有的一部分工具能做的事：

- **Adobe.** 让 Claude 修图、编辑照片、添加效果；也能对 PDF 做高亮、编辑和涂黑处理。
- **Atlassian.** 在聊天旁打开 Confluence 页面，让 Claude 撰写和编辑，并在页面上实时查看改动。
- **Box.** 在聊天旁打开 Box 文件，让 Claude 修订，保留改动前先并排比对两个版本。
- **HubSpot. **给销售管线里的任务和后续跟进排优先级，然后直接在 Claude 里处理。
- **Notion.** 让 Claude 创建 Notion 文档或数据库。边聊边搭，或者自己动手改，都不用离开 Claude。

![Claude 中支持交互式 connectors 的 13 个工具的徽标](https://assets.claude.com/98d2cbf9c0392a81da0d53ea7666bf08528db80e.png)

Figma、Harvey 和 Shopify 也在开发集成，我们鼓励其他开发者跟进。

## 面向开发者：构建在 MCP Apps 之上

交互式 connectors 运行在 MCP Apps 之上，这是 [Model Context Protocol](https://modelcontextprotocol.io/docs/getting-started/intro) 的开放扩展，让 MCP server 可以把自己的界面带进 AI 应用。你做的 MCP App 并不局限在 Claude，任何支持该[扩展](https://modelcontextprotocol.io/extensions/apps/overview)的 AI 应用都能运行它。

此前，Claude 里的 MCP Apps 主要以对话中的交互视图出现。现在 Claude 支持该扩展的更多能力，比如 app tools 和嵌入式站点，因此开发者可以把完整应用跑在 Claude 内部。

这些能力对开发者处于公开预览阶段，今天就可以动手构建。阅读我们的[文档](https://claude.com/docs/connectors/building/mcp-apps/getting-started)即可开始。

## 开始使用

你可以从[目录](https://claude.ai/directory/featured/interactive-connectors)里连接上面提到的工具，然后在聊天中打开任意一个，或把它固定到侧边栏。

**面向管理员：** 如果组织已经放行某个 connector 的全部工具，它的新功能会随上线自动出现。管理员仍可像现在这样限制 connector 的工具。
