今年早些时候，我们推出了[交互式连接器（在新选项卡中打开）](https://claude.com/resources/articles/interactive-tools-in-claude)，将工具的小型实时视图引入 Claude。从今天开始，在连接器支持的情况下，您可以在对话旁边打开一个工具或将其扩展到全屏，并要求 Claude 与您一起工作并直接进行更改。

这是在所有计划的网络和 Claude 桌面应用程序中推出的，作为将聊天和 Cowork 结合在一起的 [新 Claude 体验（在新选项卡中打开）](https://claude.com/resources/articles/cowork-is-now-claude) 的一部分。一旦您的帐户更新为新的Claude或您的组织将其启用，您就会看到这些功能。

什么是新的：

- **Claude 可以在您打开的工具中工作。** 您可以要求 Claude 对您已打开的页面、行或文件进行更改，并以与批准连接器操作相同的方式批准其操作。 Claude 所做的更改会显示在工具中，因此您可以继续与它一起工作。
- **整个工具** **在您的对话旁边打开。** 您可以在该工具中工作并隐藏聊天或在需要空间时全屏显示。对于像 Confluence 或 Notion 这样的工具，这意味着您可以获得完整的编辑器，登录到您自己的帐户，而不是有限的预览。
- **直接打开连接的工具，无需编写Claude提示符。 **当您需要Claude的帮助时，您可以在同一屏幕上询问。
- **固定您最常使用的工具。** 您可以将它们排列在您的工件旁边，并通过侧边栏和 + 菜单中的一键访问它们。

## 与 Claude 一起使用您使用的工具

我们从目录中的一小部分工具开始，包括 Asana、Canva、Carta、Dropbox、monday.com、Smartsheet、Vercel 和 Webflow。

以下是您现在可以使用 Claude 中提供的一些工具执行的操作：

- **Adobe.** 要求 Claude 修饰、编辑照片并添加效果；突出显示、编辑和编辑 PDF。
- **Atlassian。** 在聊天旁边打开 Confluence 页面，要求 Claude 编写和编辑，并在页面上实时查看其更改。
- **Box.** 在聊天旁边打开一个 Box 文件，请 Claude 修改它，并在保留更改之前并排比较版本。
- **HubSpot。 **确定管道任务和后续任务的优先级，然后在 Claude 中对其采取行动。
- **Notion.** 要求 Claude 创建一个 Notion 文档或数据库。边聊天边构建，或者自己编辑，无需离开 Claude。

![Claude 中支持交互式连接器的 13 个工具的徽标](https://assets.claude.com/98d2cbf9c0392a81da0d53ea7666bf08528db80e.png)

Figma、Harvey 和 Shopify 也在构建集成，我们鼓励其他开发人员也这样做。

## 对于开发人员：基于 MCP 应用程序构建

交互式连接器在 MCP 应用程序上运行，这是 [模型上下文协议（在新选项卡中打开）](https://modelcontextprotocol.io/docs/getting-started/intro) 的开放扩展，允许 MCP 服务器将自己的接口引入 AI 应用程序。您构建的 MCP 应用程序不仅限于 Claude，还可以在支持[扩展（在新选项卡中打开）](https://modelcontextprotocol.io/extensions/apps/overview) 的任何 AI 应用程序中运行。

到目前为止，Claude 中的 MCP Apps 主要以交互视图的形式出现在对话中。 Claude 现在支持更多扩展，例如应用程序工具以及嵌入式站点，因此开发人员的完整应用程序可以在 Claude 内部运行。

对这些功能的支持已向开发人员公开预览。开发人员今天就可以开始使用它们进行构建。阅读我们的[文档（在新选项卡中打开）](https://claude.com/docs/connectors/building/mcp-apps/getting-started) 开始构建。

## 开始使用

您可以从[目录（在新选项卡中打开）](https://claude.ai/directory/featured/interactive-connectors) 连接我们上面提到的工具，然后从聊天中打开任何工具或将其固定到侧边栏。

**对于管理员：** 如果您的组织已允许使用连接器的所有工具，则其新功能会在推出时出现。管理员可以像现在一样限制连接器的工具。
