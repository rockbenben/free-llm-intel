使用 Claude 构建的公司还依赖其他软件来完成工作，例如用于存储和分析数据的 Snowflake 或用于运行应用程序的 Vercel。 Claude Marketplace 允许具有人性化承诺的公司将部分资金用于其团队已经依赖的工具，因此一项投资涵盖了其团队日常使用的更多内容，而无需提出新的预算请求。

以下是 CodeRabbit、Power Digital 和 ThoughtSpot 如何利用 Claude Marketplace 来扩展他们与 Vercel 和 Snowflake 的合作。

## **Power Digital 在 Snowflake 上运行客户数据**

[Power Digital](https://powerdigitalmarketing.com/) 是一家营销机构，为其团队和客户构建 Nova 平台。客户通过 Nova 连接他们的数据，Nova 在 Snowflake 上运行并支持报告、内部工具和模型，从而提高营销绩效。 Snowflake 让 Power Digital 能够快速为每个客户建立安全的数据环境，并且借助 Snowflake Cortex AI，它可以直接在现有治理框架内的数据上运行 Claude 等模型。

Claude 现在负责 Power Digital，从客户交付成果和财务运营到内置于自己产品中的模型。使用人数已从 1 月份的约 12 名工程师增加到如今的 800 多人。
Power Digital 已是 Snowflake 的五年客户，今年通过 Claude Marketplace 扩大了其对 Snowflake 的承诺。由于支出来自已批准的预算，因此其团队可以快速扩展 Snowflake 的使用量。

> ““我们在 Claude 上集中了很多运行方式，并且管理整个公司的数百个工具。 Claude Marketplace 让我们将保存客户数据的 Snowflake 纳入同样的 Anthropic 承诺中。当我们询问时，合同已经起草完毕，”Power Digital 创新高级副总裁 John Saunders 说道。

## **ThoughtSpot 在 Snowflake 上构建人工智能分析**

[ThoughtSpot 的代理分析平台](https://www.thoughtspot.com/) 为业务用户提供决策就绪的见解，基于其公司的语义和上下文层，通过确定性和可验证的查询提供可信的答案。

为了支持其 AI 功能，ThoughtSpot 使用 Snowflake 的推理 API 直接针对 Snowflake 内的客户数据运行 Claude 等模型，将数据、业务上下文、访问控制和 AI 保留在一个生态系统内。 ThoughtSpot 将其对 Snowflake 推理 API 的购买应用于其现有的 Anthropic 承诺，因此其产品团队可以在已经预留的预算内开始使用该 API 进行构建。

> “我们的 Agentic Analytics 平台在 Claude 上运行，因此通过 Claude Marketplace 购买 Snowflake 的推理 API 是自然的途径。我们履行了已经做出的承诺，因此这次购买超出了我们已经批准的预算。”ThoughtSpot 产品管理高级副总裁 Francois Lopitaux 说道。

ThoughtSpot 也与 Claude 一起成长。其 AI 分析师 [Spotter](https://claude.com/connectors/thoughtspot-spotter) 可作为 Claude 的连接器，因此用户可以分析数据、构建和探索仪表板，并在不离开 Claude 的情况下采取行动。

> ““我们的人工智能分析师 Spotter 已经在 Claude 的连接器目录中，我们希望自己通过市场销售我们的代理产品，这样我们的客户就可以完全按照我们刚才所做的操作，”Lopitaux 补充道。”

## **CodeRabbit 在 Vercel 上运行其编码代理**

[CodeRabbit](https://claude.com/platform/marketplace/coderabbit) 基于 Claude 构建，以[验证 AI 生成的代码](https://claude.com/resources/articles/how-coderabbit-used-claude-to-build-an-agent-orchestration-system)，以便工程团队可以控制发货内容。它的代理编写和测试代码，因此他们需要一个安全的地方来运行代码。 [Vercel Sandbox](https://vercel.com/sandbox) 在具有自己的文件系统和网络的隔离 Linux microVM 中运行每个代理的代码，远离其他作业和 CodeRabbit 自己的系统。[Vercel Workflows](https://vercel.com/workflows) 协调工作，因此长时间运行的作业可以暂停、恢复和完成，而不会达到时间限制。

当 CodeRabbit 的工程和产品负责人希望从即用即付的 Vercel 计划转变为承诺计划时，该公司通过其最近扩大的 Anthropic 承诺为升级提供了资金。由于预算已经获得批准，交易在一周内完成。

> “‍“对我们来说，价值在于灵活性：用我们已经批准的预算来支持我们的工程师信任的工具。事实上，我们可以直接在 Claude Marketplace 上为客户提供同样的价值，这是最终的双赢。”CodeRabbit 全球合作伙伴关系主管 Blair Pierson 说道。

## **Snowflake 和 Vercel 在 Claude 的基础上与客户共同成长**

对于像 [Snowflake](https://claude.com/platform/marketplace/snowflake) 和 [Vercel](https://claude.com/platform/marketplace/vercel) 这样的卖家来说，Claude Marketplace 是一种接触已经在 Claude 上构建的客户的方式，并为那些有 Anthropic 承诺的人提供更快的购买方式。

> ““当人工智能以数据和背景为基础时，它就会受到信任。 Claude 直接在 Snowflake 中运行，因此我们客户的治理、上下文和权限已经就位，作为第一天获得可信见解的基础。 Claude Marketplace 可以轻松扩展这种关系，让客户将其 Anthropic 承诺的一部分直接转移到 Snowflake 来处理 AI 工作负载。 Snowflake 企业技术合作总监 Omar Bed-Mohamed 表示：“我们正在与 Anthropic 一起在我们的共享账户中推动这一动议。”

> ““Claude Marketplace 使 CodeRabbit 等客户能够快速采购 Vercel 的代理基础设施并扩展其平台。我们期待帮助每家以 Claude 为基础的公司运营代理。”Vercel 产品合作伙伴主管 Zack Ciesinski 说道。

## **通过Claude市场购买**

与 Claude 一起构建通常意味着引入您的团队已经依赖的数据平台和基础设施。 [Claude Marketplace](https://claude.com/marketplace) 让客户将其 Anthropic 承诺的一部分投向 Vercel、Snowflake 等合作伙伴，这样团队就可以减少采购时间，将更多时间花在构建内容上。

以这种方式使用你的Anthropic承诺的预览是有限的。如果您有，请与您的客户团队联系或[提交请求](https://claude.com/marketplace-contact-sales)，看看您是否符合资格。 [了解有关Claude市场的更多信息](https://claude.com/resources/articles/claude-marketplace)。
