用 Claude 构建的公司也会依赖其他软件来完成工作，比如用 Snowflake 存储和分析数据，或用 Vercel 运行应用。Claude Marketplace 让持有 Anthropic 承诺额度的公司可以把其中一部分用于团队已经在用的工具，这样一笔投入就能覆盖团队日常使用的更多东西，无需再单独申请新预算。

以下是 CodeRabbit、Power Digital 和 ThoughtSpot 如何借助 Claude Marketplace 扩大与 Vercel 和 Snowflake 的合作。

## **Power Digital 在 Snowflake 上运行客户的数据**

[Power Digital](https://powerdigitalmarketing.com/) 是一家营销机构，它为内部团队和客户打造了平台 Nova。客户通过 Nova 接入自己的数据，Nova 运行在 Snowflake 上，支撑报表、内部工具，以及用于提升营销表现的模型。Snowflake 让 Power Digital 能够快速为每个客户搭建安全的数据环境；借助 Snowflake Cortex AI，它可以在客户现有的治理框架内，直接对这些数据运行 Claude 等模型。

如今，Claude 在 Power Digital 各处都有使用，从客户交付物、财务运营，到内建在其自有产品中的模型。使用规模从 1 月的约 12 名工程师，增长到今天的 800 多人。
Power Digital 成为 Snowflake 客户已有五年，今年它通过 Claude Marketplace 扩大了在 Snowflake 上的承诺额度。由于这笔支出来自已经获批的预算，它的团队可以迅速扩大 Snowflake 的使用规模。

> ““我们已经在 Claude 上集中了太多的运行方式，而且在整个公司管理着数百个工具。Claude Marketplace 让我们把保存客户数据的 Snowflake 纳入同一份 Anthropic 承诺额度。等我们开口询问时，合同已经在起草了，”Power Digital 创新业务高级副总裁 John Saunders 说道。”

## **ThoughtSpot 在 Snowflake 上构建 AI 分析**

[ThoughtSpot 的 agentic 分析平台](https://www.thoughtspot.com/) 为业务用户提供可直接用于决策的洞察，它以企业的语义层和上下文层为基础，通过确定性、可验证的查询给出可信的答案。

为了支撑自己的 AI 功能，ThoughtSpot 使用 Snowflake 的 inference API，直接在 Snowflake 内针对客户数据运行 Claude 等模型，让数据、业务上下文、访问控制和 AI 都留在同一个生态里。ThoughtSpot 把购买 Snowflake inference API 的支出计入其现有的 Anthropic 承诺额度，因此产品团队可以在已经预留的预算上直接开始用该 API 构建。

> ““我们的 Agentic Analytics 平台运行在 Claude 上，所以通过 Claude Marketplace 购买 Snowflake 的 inference API 是顺理成章的选择。我们把已有的承诺额度用在这里，所以这笔采购走的是已经获批的预算，”ThoughtSpot 产品管理高级副总裁 Francois Lopitaux 说道。”

ThoughtSpot 也在与 Claude 一同成长。它的 AI 分析师 [Spotter](https://claude.com/connectors/thoughtspot-spotter) 已经作为 Claude 的 connector 提供，用户无需离开 Claude 就能分析数据、构建和探索仪表板并采取行动。

> ““我们的 AI 分析师 Spotter 已经进入 Claude 的 connectors directory，我们也希望自己通过这个市场销售我们的 agentic 产品，让客户能够做到我们刚刚做过的事情，”Lopitaux 补充道。”

## **CodeRabbit 在 Vercel 上运行自己的编程 agents**

[CodeRabbit](https://claude.com/platform/marketplace/coderabbit) 基于 Claude 来[验证 AI 生成的代码](https://claude.com/resources/articles/how-coderabbit-used-claude-to-build-an-agent-orchestration-system)，让工程团队能掌控上线的内容。它的 agents 会编写和测试代码，因此需要一个安全的地方来运行这些代码。[Vercel Sandbox](https://vercel.com/sandbox) 让每个 agent 的代码运行在隔离的 Linux microVM 中，拥有独立的文件系统和网络，与其他任务以及 CodeRabbit 自身系统隔开。[ Vercel Workflows](https://vercel.com/workflows) 负责协调这些工作，让长时间运行的任务可以暂停、恢复并完成，不会撞上时间上限。

当 CodeRabbit 的工程和产品负责人希望把 Vercel 套餐从按量付费转为承诺用量套餐时，公司用最近扩大的 Anthropic 承诺额度为这次升级出资。由于预算已经获批，这笔交易在一周内就完成了。

> ““对我们来说，价值在于灵活性：用已经获批的预算支持工程师们信任的工具。而且我们能在 Claude Marketplace 上把同样的价值直接带给客户，这是最终的双赢，”CodeRabbit 全球合作伙伴关系负责人 Blair Pierson 说道。”

## **Snowflake 与 Vercel 与基于 Claude 构建的客户共同成长**

对 [Snowflake](https://claude.com/platform/marketplace/snowflake) 和 [Vercel](https://claude.com/platform/marketplace/vercel) 这样的卖家来说，Claude Marketplace 是一种触达已经在基于 Claude 构建的客户的方式，也为持有 Anthropic 承诺额度的客户提供了更快的购买途径。

> ““只有当 AI 扎根于数据和上下文时，它才值得信任。Claude 直接运行在 Snowflake 中，因此我们客户的治理、上下文和权限已经到位，从第一天起就能作为可信洞察的基础。Claude Marketplace 让这种关系易于扩展，客户可以把其 Anthropic 承诺额度的一部分直接用于 Snowflake 上的 AI 工作负载。这是我们与 Anthropic 在共同客户中一起推进的举措，”Snowflake 企业技术合作伙伴关系总监 Omar Bed-Mohamed 说道。”

> ““Claude Marketplace 让 CodeRabbit 这样的客户能够快速采购 Vercel 的 Agentic Infrastructure 并扩展其平台。我们期待帮助每一家基于 Claude 构建的公司运行 agents，”Vercel 产品合作伙伴关系负责人 Zack Ciesinski 说道。”

## **通过 Claude Marketplace 采购**

用 Claude 构建，往往意味着要引入团队已经依赖的数据平台和基础设施。[Claude Marketplace](https://claude.com/marketplace) 让客户把其 Anthropic 承诺额度的一部分用于 Vercel、Snowflake 等合作伙伴，从而让团队少花时间在采购上，多花时间在自己构建的东西上。

以这种方式使用你的 Anthropic 承诺额度目前处于有限预览阶段。如果你持有承诺额度，请联系你的客户团队，或[提交申请](https://claude.com/marketplace-contact-sales)确认自己是否符合条件。[进一步了解 Claude Marketplace](https://claude.com/resources/articles/claude-marketplace)。
