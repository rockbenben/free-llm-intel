Claude Opus 5.5 现在是 Claude Pro、Max、Ultra 和 Team 计划中的默认型号。我们建议您将其作为知识工作的日常驱动力，这意味着您在与 Claude 一起研究、分析以及撰写或制作备忘录、报告、电子表格和幻灯片时选择的模型。

如果您或您的团队一直使用 Sonnet 进行日常工作，并保存 Opus 进行繁重的分析或复杂的项目，那么值得重新考虑，因为功能更强大的模型可以通过更少的工作来完成任务，这[可以抵消每个代币较高的价格](https://platform.claude.com/docs/en/about-claude/models/optimizing-for-cost-and-intelligence)。

[**Haiku 5.5**](https://www.anthropic.com/claude-haiku-5-5) 是我们最快且最便宜的模型，专为快速查找和大批量工作（例如编写摘要和排序数据）而构建。这是我们的第一个具有力度控制的Haiku模型，因此您可以在切换到更大的模型之前要求更仔细的传递。它最适合短期、范围狭窄的任务。如需更长时间的分析，请切换到 Opus 5.5。

[**Sonnet 5.5**](https://www.anthropic.com/claude-sonnet-5-5) 比 Opus 5.5 更快、更便宜，适用于具有明确概要的范围广泛的任务。这可能是要求Claude将完成的笔记变成精美的文档，或者使用幻灯片模板构建一个幻灯片。然而，在较高工作量设置下，Sonnet 5.5 的每项任务成本接近 Opus 5.5，因此，如果您发现自己将 Sonnet 推至超高或最大工作量，请考虑切换到 Opus 5.5。

**[Opus 5.5](https://www.anthropic.com/claude-opus-5-5) **专为需要仔细判断的复杂工作而构建，例如研究、财务分析以及生成成品文档、幻灯片和电子表格。稍后我们会详细分享为什么推荐 Opus 5.5 进行日常知识工作。

[**寓言 5.2**](https://www.anthropic.com/claude-fable-and-mythos-5-2) 最适合您最苛刻的推理和长期运行的工作，例如深入的多步骤研究或编码，您可以将其交给运行数小时的大型子代理团队。对于大多数知识工作，从 Opus 5.5 开始，并在项目范围和复杂性需要时转向 Fable 5.2。 《神鬼寓言 5.2》适用于所有付费计划，但[它如何利用您的使用情况](https://support.claude.com/en/articles/15424964-claude-fable-models-on-your-plan)取决于您的计划。

无论您选择哪种模式，如果Claude没有达到您的预期，请在升级之前先尝试更高的努力。如果它有上下文，明确尝试过，但仍然出错，则升级模型。

## **Opus 5.5 在文档、研究、财务和图表方面表现出色**

Opus 5.5 精确遵循说明并保持在范围内，因此它生成的电子表格、幻灯片和文档通常几乎不需要编辑。它对数据和来源也很谨慎。在一项内部研究测试中，Opus 5.5 仅使用保存的网络快照编写了公司的季度业绩报告，而在该快照中很难找到该公司的收益发布。自动评分员根据该快照中的页面检查每个数字和引言，条件是即使发明了一个数字或引言，报告也会失败。在各项工作设置中，18 份报告中有 16 份通过了。

它的文字也比早期型号更清晰。 Opus 5.5 将最重要的信息放在第一位，使用较少的术语，并遵循您给出的写作规则，对于较长的任务，它会清楚地说明它做了什么、发现了什么以及需要您提供什么。这也使得它的工作更容易检查，我们认为这是一种安全效益和实用效益。

Ramp 的一名软件工程师 John Ruelas 表示：“它的写作方式就像一位好同事，并且遵循我们的写作规则。只需极少的编辑即可使用设计规范，当它重写我们的一个提示时，我更喜欢它的版本而不是我自己的版本。”

财务分析是另一个优势。 Opus 5.5 准确读取密集的文件、财务模型和图表，并跟踪整个项目或交易的背景。在另一项内部测试中，它分析了两家虚构的人力资源软件公司之间的拟议合并，在 Excel 中构建了财务模型，然后将其转化为高管演示文稿，说明该交易以其价格是否合理。它只用了 63 分钟就完成了，而 Opus 5 完成相同任务的时间为 93 分钟，成本只有一半，模型更全面，演示文稿也更容易阅读。

投资公司 Walleye Capital 中央股票量化研究工程负责人 Frank Corrao 表示，在较高的工作量设置下，Opus 5.5“检测到我们自己的指令中的分钟索引偏离了一位，并进行了修正，并指出这会导致评分者得分。这是正确的，我们之前测试过的模型都没有捕捉到这一点并采取行动。”

Opus 5.5 是我们最佳的视觉 Opus 型号。它可以准确读取密集的文档、图表、屏幕截图和图表，这使得从文档中提取数据变得可靠。即使在最低工作量设置下，它从密集图表中读取的值也比 Opus 5 在最高设置下更准确。

## **充分利用 Opus 5.5**

每一个新模型都是一个重新测试你交给Claude的东西的理由，并放弃为旧模型建立的提示习惯。

### **首先尝试这些任务**

- **索取完成的文件。** 如果您想要电子表格或文档，请索取电子表格或文档，而不是构建的大纲。通常，Opus 5.5 可以一次性从您的请求生成最终文件。
- **让它检查长文档。**给它一份长计划、报告或甲板，并要求它发现错误和不一致之处。 Opus 5.5 捕捉长文档中容易遗漏的细节，例如套牌中与其源数据不匹配的图表。
- **交给它一个研究问题。**提出一个没有固定答案的问题，让它收集资源，浏览长文档，并将发现的内容写成备忘录、报告或甲板。
- **尝试视觉工作。**它的愿景可以延续到设计中，所以尝试用它来制作界面原型、构建网站或说明概念。

![claude opus 5.5 任务说明](https://assets.claude.com/43af7ca2d9f20a0722825b0c207cd80af4d3fdab.png)

### **改变这些提示习惯**

- **将 Claude 连接到您的工作文件和系统。** 这是获取适合您工作的输出的最有用的步骤之一，因为当 Claude 可以通过连接器访问您的文件和系统时，它可以获取任务所需的内容，而不是仅根据您粘贴的内容进行工作。在团队和企业计划中，所有者必须先打开连接器，然后成员才能使用它。
- **在你的第一条消息中说明完成的内容。** 不要每次向 Claude 提示一个指令，而是描述你的目标、完成的输出以及你希望它何时停止并询问。 Opus 5.5 比 Opus 5 更好地完成了漫长的、多部分的工作。
- **删除“努力思考”和“仔细思考”。** Opus 5.5 的思考始终处于开启状态，它根据您的要求和努力程度来决定思考的程度。在我们的测试中，删除这些行可以更快地开始回复，并且质量没有明显下降。
- **从中等努力开始。** 中等是 Opus 5.5 的默认设置，在我们的编码和知识工作评估中，中等程度的 Opus 5.5 与高程度的 Opus 5 相匹配或击败。较高的设置思考时间更长，成本更高，但并不总能产生更好的工作，因此当“中”停顿时，请升至“高”。要更改设置，请单击发送按钮旁边的型号名称，然后选择“Effort”。
- **附加图表而不是重新输入。** 共享图表、屏幕截图或图表本身，而不是将其数字复制到提示中。可能不再需要为早期模型构建的解决方法，例如转录图表的值。
- **说出您不想要的样式。** 对于设计工作，诸如“避免通用外观”之类的一般说明往往会将一种默认样式替换为另一种默认样式。命名要避免的特定图案，例如奶油色背景或药丸形按钮，效果会更好。
- **赋予它您的风格。** 将您的品牌或写作指南粘贴到请求中，或将 Claude 指向您最好的现有套牌，例如它可以通过连接器到达的 Google Drive 文件夹中，并要求它匹配它们。预计要经过几轮才能完全正确。

![claude opus 5.5提示习惯图解](https://assets.claude.com/d61fa79e1e1a38bd6ad4547ddb66c993ef569705.png)

这一努力结果也适用于早期测试人员。工厂技术人员 Zimu Li 表示，(https://www.anthropic.com/claude-opus-5-5)，“Claude Opus 5.5 是我们默认的第一个中等工作量的模型。在我们的测试中，它与高工作量的 Opus 5 相匹配，同时使用的输出令牌少了 20% 到 25%。”

## **在演示项目上测试 Opus 5.5**

这是我们在演示中完成的一个项目中的所有内容。在一家假设的零售公司，收入增长在过去一年中放缓，领导层有四种关于原因的理论，分析师有一个材料文件夹：各商店的销售电子表格、最新领导层场外的 PDF 以及其他文件。在中等程度的 Opus 5.5 中，提示大致如下：

“今年增长放缓很多。领导层有几种关于原因的理论：它们在[我的经理]的笔记中。我拥有的所有内容都在上传的文件夹中。请根据数据测试这四种理论，并告诉我哪些理论成立。

提示并没有告诉Claude认真思考，也没有说明要检查哪个文件以查找哪个理论。它说明了目标和最终输出，并将方法留给 Claude。

Claude发现数据并不支持这四种理论中的任何一种，尽管不能完全排除其中一种理论。然后，它提出了一个没有人提出的解释：新店开得离现有店太近，从而吸引了现有店的销售。对于按城市列出的商店，这种模式有点不清楚，但一旦按照与新商店的邻近程度进行过滤，这种模式就很清楚了。Claude通过销售影响与该距离的回归来支持这一发现。

接下来，Claude将分析结果转化为一份文档，其中包含图表和交互式元素以及文本，其中包括一个滑块，显示销售额如何随着新商店和现有商店之间的距离而变化。一位队友同时审阅了该文档。

然后，经理要求Claude将文档转换成董事会幻灯片，以答案开头。对于不使用 Claude 的队友，文档可以导出为 Word、PDF 或 Google 文档，而幻灯片可以导出为 PowerPoint、PDF 或 Google 幻灯片。

要查看整个项目，包括问答，请[点播观看 Opus 5.5 for Work 会议](https://claude.com/resources/webinars/opus-5-5-for-work)。

## **在您自己的作品中尝试 Opus 5.5**

选择通常会分为多个请求的内容，例如研究备忘录、方差分析或根据现有文档构建的演示文稿。在一条消息中向 Opus 5.5 提供文件和最终结果的描述，将其保留为中等工作量，然后将结果与您习惯从其他模型获得的结果进行比较。
