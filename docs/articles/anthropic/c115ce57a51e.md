Claude for Google Workspace™ 现已在所有付费 Claude 套餐上进入 public beta。它把 Claude 加进 Google Docs、Sheets 和 Slides，让你可以直接在打开的文件里和 Claude 一起工作。此外，我们还发布了新的 Google Docs、Sheets 和 Slides connector（beta），Claude 用它们从 Claude 内部直接创建和编辑 Google 文件。

## Claude 在你工作的地方工作

装上这个 add-on 后，Claude 会在你文件旁边侧栏打开，因此你工作时不必在应用或浏览器标签之间来回切换。Claude 能读你打开的 doc、sheet 或 deck，看到你选中的文本、单元格或幻灯片，并直接在文件里做修改。

**在 Docs 里**，例如，Claude 可以在原位修好一句话或给一个标题重新设样式，而不动周围的格式。对于更大的改写，它可以把编辑建议作为侧栏里的 suggestion card 提出来。每张卡片都会高亮它要改动的那段文字，你可以采纳或忽略。你可以让 Claude 精简一份产品需求文档的高管摘要，并把下一步行动变成一张表格，Claude 会直接在文档里把两件事都做掉。

**在 Sheets 里**，Claude 可以写公式、构建数据透视表和 Sheets 原生图表，并新增标签页。对于 join 或数据清洗，它可以把一个区域拉进 Python，再把结果写回表格。你可以从一张空 sheet 开始，附上你的源文件，要一份 Q3 预算与实际对比报告，每个团队一个标签页并配一张汇总图表，Claude 还能标出所有超出预算的项。

**在 Slides 里**，Claude 可以用你 deck 的 layout 和 theme 来新建幻灯片，让它们与 deck 的其余部分保持一致。然后它会检查自己的成果，标出相互重叠或超出幻灯片边界的元素，或难以阅读的文本。

Claude 自主做到什么程度由你决定。在默认的「Ask before edits」模式下，每一处改动都以一张带摘要的 approval card 呈现，Claude 会等你的批准才做编辑。在「Accept all edits」模式下，Claude 一路把任务做完，应用改动而不逐次停下。

## 你的 connector、skill 和企业管控一路随行

当你用自己的 Claude 账号登录时，侧栏里有你在 Claude 中使用的同一套模型、[connector](https://claude.com/marketplace/connectors-plugins)和 [skill](https://claude.com/skills)。例如，如果你要为客户做一份季度业务回顾（QBR）的 deck，Claude 可以从 Salesforce 拉取账户历史，并通过你的 Google Drive connector 拿到最近的通话记录。如果你把这套 QBR 格式存成一个 skill，你的团队就能按同样的格式和步骤做出下一份 deck。

在 Enterprise 套餐上，Compliance API、客户自管加密密钥（CMEK）和 OpenTelemetry 审计导出等管控同样适用于这个 add-on。

## 从 Claude 里编辑 Google 文件

借助同样处于 beta 的 [Google Docs、Sheets 和 Slides connector](https://support.claude.com/en/articles/10166901-use-google-workspace-connectors)，你可以从 Claude 起步，由它在对话中创建并编辑你的 Google 文件。粘贴一个 Google 文件链接，或者要一份 Google 的 doc、sheet 或 deck，在支持的配置下，它会在你对话旁的一个窗格里打开。从 Claude 起步最合适的场景是你需要一个新文件，或者你的工作横跨多个文件。Claude 的访问权限与你已有的 Google 共享权限一致。

## 开始使用

[Claude for Google Workspace](https://claude.com/claude-for-google-workspace)已在所有付费套餐上进入 beta。

从 [Google Workspace Marketplace](https://workspace.google.com/marketplace/app/claude/12459801340)安装它，然后打开一个文件，前往 Extensions > Claude > Open Claude。管理员可以从 Google Admin console 把它部署到他们的域或指定的用户组。[Help Center 指南涵盖配置步骤](https://support.claude.com/en/articles/16951679-use-claude-in-google-docs-sheets-and-slides)。

若要在 Claude 里编辑 Google 文件，请开启 [Google Docs、Sheets 和 Slides connector](https://support.claude.com/en/articles/10166901-use-google-workspace-connectors)。在 Team 和 Enterprise 套餐上，需要 owner 或 primary owner 先启用这些 connector。
