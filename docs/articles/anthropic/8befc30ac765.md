# MCP 服务器现在能交付技能、运行任务，还能与 Claude 做更多事

Skills over MCP 现已在 Claude 中进入公开 beta，因此 MCP 服务器可以在提供工具的同时交付技能。我们也在为服务器提供处理更长、更具交互性的工作的方法：Tasks 与 Elicitation 现已正式可用，File Uploads 也即将推出。

两年前，Anthropic [推出 Model Context Protocol（MCP）](https://www.anthropic.com/news/model-context-protocol)，作为把 AI agent 连接到数据所在系统的新标准。该规范一直在演进，以满足生产环境中 agent 的连接需求，并正成为 agentic 消息传递与编排的基础。

有了今天的这些更新，Claude 与服务器协作的方式更接近它与另一个 agent 协作：向它学习、把工作委派给它，并在过程中交换输入与文件。

## 用 Skills over MCP 在交付工具的同时交付专业能力

工具名称与描述告诉 Claude 一个服务器能做什么，但并未涵盖如何处理具体用例。借助 [Skills over MCP](https://modelcontextprotocol.io/extensions/skills/overview)，服务器可以在发布工具的同时发布技能，帮助 Claude 承接更长的多步工作。Claude 只在需要时加载技能，从而把上下文占用保持在低位。技能随服务器一起更新，因此开发者可以把工具与使用指引一同交付，用户无需另外安装任何东西。

技能可以涵盖最佳实践、分步工作流，甚至是为某个用户账户或组织量身定制的操作手册。使用 Skills over MCP 的包括：

- [Shopify](https://claude.com/marketplace/connectors/shopify) 帮助 Claude 端到端地设计和更新商家的在线商店。
- [HubSpot](https://claude.com/marketplace/connectors/hubspot) 为客户完成入驻，并让他们在 Claude 中完成配置。
- [Atlassian](https://claude.com/marketplace/connectors/atlassian) 帮助 Claude 借助深厚的组织上下文来获得洞察、分析工作。
- [Carta](https://claude.com/marketplace/connectors/carta) 将帮助 Claude 从上传的文档起草并发放股权（即将推出）。

Skills over MCP 在 Claude 与 Claude Code 中处于公开 beta，对 Pro、Max 和 Ultra 套餐默认开启，Team 套餐需管理员启用后可用。即将支持 Enterprise。

## MCP 服务器现在可以承接长时间运行、需要交互的工作

生产环境中的 agent 正在承接更长、影响更重大的任务。服务器现在可以支持这类工作：在后台运行它、与用户确认进展，并接收来自 Claude 的文件。

**把长时间运行的工作交办给** **[Tasks](https://modelcontextprotocol.io/extensions/tasks/overview)。** 过去，工具调用必须先结束，Claude 才能继续往下走。有了 Tasks，服务器可以运行耗时的操作，甚至完整的 agent 循环，而 Claude 继续工作，并在结果就绪时取回它。借助 Tasks，[ZoomInfo](https://claude.com/marketplace/connectors/zoominfo) 得以执行更深入的客户与联系人调研，而这在过去需要好几轮 prompt。

![Tasks：Claude 把一项长时间运行的任务交给 MCP 服务器，自己继续工作，并在结果就绪时取回。](https://assets.claude.com/e53adba43ded0a4377bdd900155891633b3edbc7.png)

**在调用中途用** **[Elicitation](https://modelcontextprotocol.io/specification/2026-07-28/client/elicitation) 请求输入。** 有些操作需要用户签字同意，比如花钱或删除数据。借助 Elicitation，服务器可以暂停，通过表单或链接请用户提供输入，然后从停下的地方继续。使用 Elicitation 的包括：

- [Supabase](https://claude.com/marketplace/connectors/supabase) 在创建付费项目之前、以及运行破坏性 SQL 之前确认费用。
- [Railway](https://claude.com/marketplace/connectors/railway) 在做出可能有破坏性的更改前先行询问，比如移除某个服务。
- [GitHub](https://claude.com/marketplace/plugins/github) 会在 agent 删除某个仓库之前，让用户输入该仓库的名称。

Tasks 与 Elicitation 现已在 Claude 和 Claude Code 中对 Pro、Max 和 Ultra 套餐正式可用，并正在向 Team 与 Enterprise 组织逐步推出。

**用** **[File Uploads](https://github.com/modelcontextprotocol/experimental-ext-file-uploads) 收发文件。** Claude 将能够把文件传给 MCP 服务器，而不只是文本。File Uploads 扩展可以把 PDF、电子表格和图片发送到服务器，而无需让它们经由上下文窗口。

File Uploads 即将在 Claude 与 Claude Code 中向 Pro、Max、Ultra 以及符合条件的 Team 和 Enterprise 套餐推出。

## 现在就让你的插件支持这些功能

这些功能属于开放的 MCP 规范及其扩展，因此支持它们的服务器在任何兼容客户端中都能工作，而不只是在 Claude 中。要添加支持，请参阅 [Skills over MCP](https://code.claude.com/docs/en/mcp#use-skills-from-mcp-servers)、[Tasks](https://code.claude.com/docs/en/mcp#mcp-tasks-for-server-authors)、[Elicitation](https://code.claude.com/docs/en/mcp#respond-to-mcp-elicitation-requests) 和 [File Uploads](https://claude.com/docs/connectors/building/files?open_in_browser=1) 的文档。

## 建立在更坚实的基础之上：连接生产环境中的 agent

得益于 AI 生态各方的贡献，MCP 现在的 SDK 月下载量超过 7 亿次，面向 Claude 的 MCP connector 超过 10,000 个。我们与 MCP 社区合作，改进了 MCP 在 Claude 中的工作方式。过去一年里，它变得：

- **更省 token：** [Tool search](https://platform.claude.com/docs/en/agents-and-tools/tool-use/tool-search-tool) 只在需要时加载工具定义，在多服务器配置下可以把它们占用的上下文削减 85% 以上。
- **更易扩展：** [最新的 MCP 规范](https://claude.com/resources/articles/bringing-mcp-2026-07-28-to-claude) 是无状态的，并在各 Claude 产品中得到支持，让服务器更易构建，也更容易在规模增长时维持其可靠性。
- **授权更简单：** [Enterprise Managed Auth](https://claude.com/docs/connectors/building/enterprise-managed-auth) 扩展让管理员只需对受支持的服务器授权一次，用户即可自动连接。
- **更具交互性：** [MCP Apps](https://claude.com/docs/connectors/building/mcp-apps/quickstart) 扩展把完整界面引入 Claude，可显示在对话旁边或全屏。

这些改进加在一起，让 MCP 更易于在其上构建、也更易于采用，并为这一标准打下坚实基础，使其能继续演进，以满足生产环境中 agent 的需求。

## 感谢 MCP 社区

MCP 是一项开放标准，由 [Agentic AI Foundation](https://aaif.io/) 托管，由在其之上构建的人们共同塑造。[两年的进展](https://blog.modelcontextprotocol.io/posts/mcp-turns-two) 来自那些撰写规范、构建 SDK、发布服务器并添加客户端支持的 maintainer、贡献者和开发者。感谢你们造就了今天的 MCP。
