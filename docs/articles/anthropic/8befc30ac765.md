Skills over MCP 现已在 Claude 中进入公开测试阶段，因此 MCP 服务器可以在提供工具的同时一并发布 skills。我们还为服务器提供了与 Claude 协作处理更长、更具交互性工作的方式：Tasks 和 Elicitation 现已正式可用，File Uploads 也即将推出。

两年前，Anthropic [推出了 Model Context Protocol（MCP）](https://www.anthropic.com/news/model-context-protocol)，作为连接 AI agent 与其数据所在系统的新标准。该规范持续演进，以满足生产环境中 agent 的连接需求，并正成为 agent 消息传递与编排的基础。

借助今天的更新，Claude 与服务器协作的方式更接近于它与另一个 agent 协作：向它学习、向它委派任务，并在过程中交换输入与文件。

## 用 Skills over MCP 在工具之外一并交付专业知识

工具名称和描述告诉 Claude 一个服务器能做什么，但并未涵盖如何处理具体用例。借助 [Skills over MCP](https://modelcontextprotocol.io/extensions/skills/overview)，服务器可以在发布工具的同时发布 skills，帮助 Claude 承担更长的多步骤工作。Claude 仅在需要时加载 skill，从而保持较低的上下文占用。Skills 随服务器一同更新，因此开发者可以把工具与指导一并交付，用户无需单独安装任何东西。

Skills 可以涵盖最佳实践、分步工作流，甚至是为某个用户的账户或组织量身定制的 playbook。使用 Skills over MCP 的案例：

- [Shopify](https://claude.com/marketplace/connectors/shopify) 帮助 Claude 端到端地设计和更新商家的在线商店。
- [HubSpot](https://claude.com/marketplace/connectors/hubspot) 负责客户入驻，并让他们在 Claude 中完成设置。
- [Atlassian](https://claude.com/marketplace/connectors/atlassian) 帮助 Claude 调用深层的组织上下文，用于洞察与工作分析。
- [Carta](https://claude.com/marketplace/connectors/carta) 将帮助 Claude 根据上传的文档起草并发行股权（即将推出）。

Skills over MCP 在 Claude 和 Claude Code 中处于公开测试阶段，在 Pro、Max 和 Ultra 套餐中默认开启，Team 套餐在管理员启用后即可使用。即将登陆 Enterprise。

## MCP 服务器现在可以与 Claude 一起承担长时间运行、交互式的工作

生产环境中的 agent 正在承担更长时间、更重要的任务。服务器现在可以通过在后台运行这些工作、与用户确认进度，以及接收来自 Claude 的文件来支持这类任务。

**把长时间运行的工作交给** **[Tasks](https://modelcontextprotocol.io/extensions/tasks/overview)。** 过去，工具调用必须完成后 Claude 才能继续。借助 Tasks，服务器可以运行耗时的操作，甚至完整的 agent 循环，而 Claude 可以继续工作，并在结果就绪时取回。使用 Tasks，[ZoomInfo](https://claude.com/marketplace/connectors/zoominfo) 可以执行更深入的账户与联系人研究，这在以前需要多次 prompt。

![Tasks：Claude 将一项长时间运行的任务交给 MCP 服务器，继续自己的工作，并在结果就绪时取回。](https://assets.claude.com/e53adba43ded0a4377bdd900155891633b3edbc7.png)

**在调用中途请求输入，使用** **[Elicitation](https://modelcontextprotocol.io/specification/2026-07-28/client/elicitation)。** 有些操作需要用户批准，比如花钱或删除数据。借助 Elicitation，服务器可以暂停，通过表单或链接向用户请求输入，然后从暂停处继续。使用 Elicitation：

- [Supabase](https://claude.com/marketplace/connectors/supabase) 在创建付费项目前、以及执行破坏性 SQL 前确认费用。
- [Railway](https://claude.com/marketplace/connectors/railway) 在做出可能具有破坏性的更改（如移除某个服务）前先询问。
- [GitHub](https://claude.com/marketplace/plugins/github) 在 agent 删除仓库前，让用户输入仓库名称。

Tasks 和 Elicitation 现已在 Claude 和 Claude Code 中正式可用，适用于 Pro、Max 和 Ultra 套餐，并正在向 Team 和 Enterprise 组织推出。

**收发文件，使用** **[File Uploads](https://github.com/modelcontextprotocol/experimental-ext-file-uploads)。** Claude 将能够把文件传给 MCP 服务器，而不只是文本。File Uploads 扩展可以把 PDF、电子表格和图片发送到服务器，而无需经过上下文窗口。

File Uploads 即将在 Claude 和 Claude Code 中向 Pro、Max、Ultra 以及符合条件的 Team 和 Enterprise 套餐推出。

## 立即为你的插件添加支持

这些功能属于开放的 MCP 规范及其扩展，因此支持它们的服务器可在任何兼容客户端中工作，而不仅限于 Claude。要添加支持，请参阅 [Skills over MCP](https://code.claude.com/docs/en/mcp#use-skills-from-mcp-servers)、[Tasks](https://code.claude.com/docs/en/mcp#mcp-tasks-for-server-authors)、[Elicitation](https://code.claude.com/docs/en/mcp#respond-to-mcp-elicitation-requests) 和 [File Uploads](https://claude.com/docs/connectors/building/files?open_in_browser=1) 的文档。

## 建立在更坚实的基础之上，连接生产环境中的 agent

得益于整个 AI 生态的贡献，MCP 目前的 SDK 月下载量已超过 7 亿次，面向 Claude 的 MCP 连接器超过 10,000 个。我们与 MCP 社区合作，改进了 MCP 在 Claude 中的工作方式。在过去一年里，它变得：

- **更省 token：** [Tool search](https://platform.claude.com/docs/en/agents-and-tools/tool-use/tool-search-tool) 仅在需要时加载工具定义，在多服务器配置下可将它们占用的上下文减少 85% 以上。
- **更易扩展：** [最新的 MCP 规范](https://claude.com/resources/articles/bringing-mcp-2026-07-28-to-claude) 是无状态的，并在 Claude 各产品中得到支持，使服务器更易构建，并在规模增长时更易保持可靠性。
- **授权更简单：** [Enterprise Managed Auth](https://claude.com/docs/connectors/building/enterprise-managed-auth) 扩展让管理员只需授权一次受支持的服务器，用户即可自动连接。
- **更具交互性：** [MCP Apps](https://claude.com/docs/connectors/building/mcp-apps/quickstart) 扩展将完整界面引入 Claude，可显示在对话旁边或以全屏方式呈现。

这些改进共同让 MCP 更易于构建和采用，也为该标准奠定了坚实基础，使其能够持续演进，以满足生产环境中 agent 的需求。

## 感谢 MCP 社区

MCP 是一项开放标准，由 [Agentic AI Foundation](https://aaif.io/) 托管，并由在其之上构建的人们共同塑造。[两年的进展](https://blog.modelcontextprotocol.io/posts/mcp-turns-two)来自那些编写规范、构建 SDK、发布服务器并添加客户端支持的维护者、贡献者和开发者。感谢你们让 MCP 成为今天的样子。
