我们在 [Claude Marketplace](https://claude.com/marketplace) 中添加了新的代理和产品，团队可以在这里找到合作伙伴工具和服务，以帮助他们从 Claude 那里获得更多收益。新增内容涵盖安全性、开发人员基础设施、创意和生产力。

符合条件的企业客户可以将其承诺的 Anthropic 支出的一部分用于这些解决方案。这让他们可以在 Claude 和合作伙伴的产品中使用一项承诺，无论他们是购买新产品还是利用他们已经使用的平台进行扩展。

目前市场上有超过 25 个合作代理商和产品。以下是最新添加的内容以及团队可以使用它们做什么。

## **用于保护代码和系统的产品和代理**

**[Chainguard](https://claude.com/marketplace/agents-products/chainguard)：** Chainguard Harness 在隔离的 microVM 中从源代码构建应用程序，并探测实时应用程序是否存在可利用的漏洞。它可以帮助团队修复 Claude 发现的问题，并针对可重现的漏洞提供自定义修复建议。

**[Checkmarx](https://claude.com/marketplace/agents-products/checkmarx)：** Checkmarx One 将基于规则的分析与人工智能推理相结合，以查找代码中的漏洞。它可以帮助团队对发现的问题进行优先排序并在代码发布之前修复它们。

**[Cyera](https://claude.com/marketplace/agents-products/cyera)：** Cyera Agent Guardian 清点 Claude 部署，在 Claude 运行之前管理权限，并对提示、文件和工具调用强制执行策略。它可以帮助团队通过红队测试这些控制。

**[Rubrik](https://claude.com/marketplace/agents-products/rubrik)：** Rubrik Code Guardian 使用 Anthropic 的前沿 AI 模型来审查 GitHub 或 Azure DevOps 存储库的安全副本以了解多步攻击路径。它可以帮助安全和工程团队按严重程度对问题进行排名，并将已确认的关键问题转化为可跟踪的票证。

**[Tanium](https://claude.com/marketplace/agents-products/tanium)：** Tanium Cloud 为团队提供跨端点的实时可见性和控制。它可以帮助 IT 和安全团队查找并修复漏洞、错误配置和缺失的补丁。

## **工程团队的开发基础设施**

**[Datadog](https://claude.com/marketplace/agents-products/datadog-agent-observability)：** Datadog Agent Observability 通过工具和服务跟踪代理执行情况。它通过展示生产模式和建议修复建议来帮助团队提高代理质量、性能和成本效率。

**[Netlify](https://claude.com/marketplace/agents-products/netlify)：** Netlify Enterprise 将应用程序、站点和代理部署到全球边缘网络，并在每次更改时提供预览 URL。它可以帮助团队将与 Claude 一起构建的内容从原型到生产，无需配置基础设施，并且包括 SSO、基于角色的访问和审核日志。

## **营销和创意工作工具**

**[AirOps](https://claude.com/marketplace/agents-products/airops)：** AirOps 为 AI 搜索策略、内容和多渠道执行提供代理平台。它帮助营销团队分析人工智能搜索中的品牌表现，并将结果与​​渠道和收入联系起来。

**[Runway](https://claude.com/marketplace/agents-products/runway)：** Runway 生成和编辑视频、图像和音频。它可以帮助创意和营销团队将简报转化为成品资产并使用自然语言编辑素材。

**[Webflow](https://claude.com/marketplace/agents-products/webflow)：** Webflow 提供内置工具来构建、管理和优化网站。它通过内置的控制和治理帮助营销人员、设计师、开发人员和代理商做出改变。

## **适合每个团队的生产力应用程序**

[**Asana**](https://claude.com/marketplace/agents-products/asana)：Asana AI Teammates 是使用 Asana 工作图上下文的预构建代理，每个代理都有自己的身份、范围权限和审计跟踪。他们帮助团队处理多步骤工作，将需要判断的决策传递给所有者。

**[Glean](https://claude.com/marketplace/agents-products/glean)：** Glean 将公司知识和跨系统的工作流程连接起来。它可以帮助员工跨连接的应用程序找到答案并完成多步骤任务。

**[星期一](https://claude.com/marketplace/agents-products/monday)：** 星期一代理在项目、董事会、文档和会议中工作，使用其所有者和截止日期作为背景。它们帮助 PMO、IT、营销、财务和运营团队控制 AI 可以访问、批准和支出的内容。

[**Zoom:**](https://claude.com/marketplace/agents-products/zoom) Zoom Agentic Search 使用最新的会议摘要、工作对话、文档和连接的第三方来源回答 Claude 内部的问题。团队无需分析原始记录或将工具链接在一起即可获得许可感知的结果。
