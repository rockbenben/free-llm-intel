# Claude Marketplace 上新增的安全、生产力与创意类 agent 和产品

我们在 [Claude Marketplace](https://claude.com/marketplace) 上新增了一批 agent 和产品——团队在这里找到合作伙伴的工具与服务，帮他们从 Claude 获得更多。此次新增覆盖安全、开发者基础设施、创意与生产力。

符合条件的企业客户可以将其承诺 Anthropic 消费额的一部分用于这些解决方案。这让企业能用同一份承诺同时覆盖 Claude 与合作伙伴产品，无论是要新买点什么，还是在已使用的平台上扩展。

Marketplace 上现在的合作伙伴 agent 和产品已超过 25 个。以下是最新新增的成员，以及团队能用它们做什么。

## **用于保护代码与系统的产品和 agent**

**[Chainguard](https://claude.com/marketplace/agents-products/chainguard)：** Chainguard Harness 在隔离的 microVM 中从源码构建应用，并对运行中的应用探查可被利用的漏洞。它帮助团队修复 Claude 发现的问题，并为可复现的漏洞提供定制修复建议。

**[Checkmarx](https://claude.com/marketplace/agents-products/checkmarx)：** Checkmarx One 将基于规则的分析与 AI 推理相结合，在代码中查找漏洞。它帮助团队对发现的问题排定优先级，并在代码上线之前完成修复。

**[Cyera](https://claude.com/marketplace/agents-products/cyera)：** Cyera Agent Guardian 盘点 Claude 部署情况，在 Claude 运行之前管控权限，并对 prompt、文件和工具调用执行策略。它帮助团队通过红队测试检验这些控制。

**[Rubrik](https://claude.com/marketplace/agents-products/rubrik)：** Rubrik Code Guardian 使用 Anthropic 的前沿 AI 模型，审查 GitHub 或 Azure DevOps 仓库的安全副本，寻找多步攻击路径。它帮助安全与工程团队按严重程度为问题排序，并把确认的关键问题变成可跟踪的工单。

**[Tanium](https://claude.com/marketplace/agents-products/tanium)：** Tanium Cloud 为团队提供跨端点的实时可见性与控制。它帮助 IT 与安全团队找到并修复漏洞、错误配置和缺失的补丁。

## **为工程团队提供的开发基础设施**

**[Datadog](https://claude.com/marketplace/agents-products/datadog-agent-observability)：** Datadog Agent Observability 追踪 agent 穿过工具与服务的执行过程。它通过呈现生产环境模式并推荐修复方案，帮助团队提升 agent 质量、性能与成本效率。

**[Netlify](https://claude.com/marketplace/agents-products/netlify)：** Netlify Enterprise 将应用、站点和 agent 部署到全球边缘网络，每次变更都有预览 URL。它帮助团队把用 Claude 构建的东西从原型推进到生产，无需配置任何基础设施，并包含 SSO、基于角色的访问控制与审计日志。

## **营销与创意工作的工具**

**[AirOps](https://claude.com/marketplace/agents-products/airops)：** AirOps 提供一个面向 AI 搜索策略、内容与多渠道执行的 agentic 平台。它帮助营销团队分析品牌在 AI 搜索中的表现，并把结果与 pipeline 和收入挂钩。

**[Runway](https://claude.com/marketplace/agents-products/runway)：** Runway 生成并编辑视频、图像与音频。它帮助创意与营销团队把一份 brief 变成成品素材，并用自然语言剪辑素材。

**[Webflow](https://claude.com/marketplace/agents-products/webflow)：** Webflow 提供内置工具来构建、管理和优化网站。它帮助营销人员、设计师、开发者和 agent 进行改动，控制与治理内建其中。

## **面向每个团队的生产力应用**

[**Asana**](https://claude.com/marketplace/agents-products/asana)： Asana AI Teammates 是预构建的 agent，使用来自 Asana Work Graph 的上下文，各自拥有独立身份、限定范围的权限和审计轨迹。它们帮助团队处理多步骤工作，把需要判断的决策路由给负责人。

**[Glean](https://claude.com/marketplace/agents-products/glean)：** Glean 连接跨系统的公司知识与工作流。它帮助员工找到答案，并在已连接的应用中完成多步骤任务。

**[monday](https://claude.com/marketplace/agents-products/monday)：** monday agent 在项目、看板、文档和会议中工作，以其所有者和截止日期作为上下文。它们帮助 PMO、IT、营销、财务和运营团队控制 AI 能访问什么、批准什么、花费什么。

[**Zoom：**](https://claude.com/marketplace/agents-products/zoom) Zoom Agentic Search 在 Claude 内部使用最新的会议摘要、工作对话、文档和已连接的第三方来源回答问题。团队获得权限感知的结果，无需分析原始转录文本，也无需把工具串联起来。
