过去几个月，我们一直在为企业客户开发 Enterprise Frontier Safeguards（EFS）。EFS 能以先进手段检测复杂的滥用行为，同时兼容零数据保留（ZDR）。Anthropic 和云服务商均不保留企业数据。

自 9 月[宣布 EFS](https://www.anthropic.com/news/enterprise-frontier-safeguards)以来，我们一直与 100 多家客户共同推进开发，其中包括四分之一的 Fortune 100 企业，以及医疗、金融服务、法律等对数据可见性有严格规定的行业中的许多公司。Bridgewater、Salesforce 和 Stripe 等领先企业一直在内部测试阶段评估 EFS。

现在，我们开放 EFS 的公开测试。本文将进一步说明 EFS 如何工作、如何保持与 ZDR 兼容，以及企业如何加入测试计划。

## EFS 如何在零数据保留条件下提供自动化安全监控

依靠旧版 ZDR 的客户受到 Claude [分类器](https://www.anthropic.com/research/next-generation-constitutional-classifiers)保护。分类器是实时[防护措施](https://www.anthropic.com/news/building-safeguards-for-claude)，逐条筛查请求，判断其是否可能造成危害。复杂攻击通常跨越多次查询，单独看其中任何一条请求，都可能显得无害。

例如，我们 9 月的[威胁情报报告](https://www.anthropic.com/threat-intelligence-report-september-2026#cyber-operations-sep-26)描述了一起针对约 50 家组织的行动。一个 AI agent 将攻击分工交给多个并行运行的其他 agent。它在会话之间保存收集到的凭据，攻击者随后可以轻松恢复活动。如果逐条查看请求，这一攻击看起来会是相互独立、较为无害的任务。

为了发现此类攻击，我们采用第二层防御，即自动化安全监控。这一层在多个请求之间查找滥用模式。通过 EFS，Anthropic 可以在无需存储任何客户数据的情况下提供自动化安全监控。我们的系统分析的数据完全保存在客户控制的基础设施上。

![旧版 ZDR 和 EFS ZDR 的对比。两者都使用 Claude 的对齐机制和实时分类器。EFS ZDR 还加入自动化安全监控，可检测分散在多条请求中的攻击，并生成案例供你审查。](https://assets.claude.com/407895af12324a5800318809efd87eda92ff500d.webp)

自动化安全监控发现风险时，会创建一条 Safety Case 记录供你审查。你可以从自己的云存储读取这些记录，也可以通过 API 读取，还可接入安全信息和事件管理系统。记录不包含输入和输出。

![同一条 Safety Case 的两种视图。你的团队和 Anthropic 都可以查看案例 ID、危害类别、状态及被标记的对话记录 ID。仅你的团队可以读取输入和输出。此图仅供说明，所有细节均为虚构。](https://assets.claude.com/debb29b66026bd3e0a55de89f8884d8ffe903570.webp)

配置完成后，自动化安全监控可帮助团队识别可能导致严重危害的故意滥用，例如进攻性网络行动。它还可帮助发现采取超出用户意图的行动的 agent。极端情况下，这可能表现为利用软件漏洞访问内部数据库或外部系统。

## 零数据保留与 EFS

使用 EFS 时，你提供自己的存储来保存输入和输出。数据送达你控制的存储后，Anthropic 和你的云服务商均不保留数据副本。这提供以下保证。

- **零数据保留。** Anthropic 和你的云服务商均不保留你的数据。你提供存储并自行保存数据。输入和输出写入你自己的存储后，会及时从服务端删除。你可以自行配置访问策略和审计日志，并用自己的密钥加密安全数据。
- **运营方不进行人工审查。** Anthropic 和你的云服务商的工作人员均不访问你的输入和输出。只有自动化安全监控可以访问这些数据。
- **我们从不使用你的数据进行训练。** 输入和输出仅用于自动化安全监控，绝不用于训练模型或分类器。

![EFS 架构。自动化安全系统将安全数据写入你云账户的存储，再读取这些数据进行监控。Anthropic 收到安全相关往来信息和监控元数据，始终不会收到输入、输出或摘录。](https://assets.claude.com/e1deaac362da2eb9fac5d8dc38feebc89b80ec00.webp)

你可以通过 Claude Platform、Claude Platform on AWS、Amazon Bedrock 或 Claude on Google Cloud 使用 EFS。通过 Amazon Bedrock 或 Claude on Google Cloud（Google Managed）使用时，由你的云服务商运营 EFS，端到端的数据流始终处于该云的边界内。

根据使用 Claude 的位置，你可以在自己的账户中用 Amazon S3 或 Google Cloud Storage 作为存储。云服务商会按常规收取存储费用，包括读取、写入和密钥操作的费用，以及适用的网络传输费用。

## 开始使用

EFS 现可用于 Claude Platform、Claude Platform on AWS、Amazon Bedrock 和 Claude on Google Cloud。Microsoft Foundry 即将支持 EFS。

符合资格的客户会收到通知及上手说明。你可以阅读[开发者文档](https://platform.claude.com/docs/en/manage-claude/enterprise-frontier-safeguards/overview)了解如何设置，阅读[安全白皮书](https://trust.anthropic.com/resources?s=a7lwkeieqk3ggz29k954j&name=enterprise-frontier-safeguards:-technical-overview)了解架构如何运作，也可以通过 Accenture、Deloitte、KPMG 和 PwC 等[咨询合作伙伴](https://partnerhub.claude.com/directory/)部署。
