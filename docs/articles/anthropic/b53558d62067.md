过去几个月，我们一直在为商业客户开发 Enterprise Frontier Safeguards（EFS）。EFS 能够以最先进的技术检测复杂的高级滥用行为，同时保持与零数据保留（ZDR）兼容：Anthropic 与任何云服务提供商都不会保留企业的数据。

自我们[在 9 月发布 EFS](https://www.anthropic.com/news/enterprise-frontier-safeguards) 以来，我们与 100 多家客户共同对其进行了进一步开发——其中包括四分之一的《财富》100 强企业，以及医疗健康、金融服务和法律等对数据可见性有严格规定的行业中的许多公司。Bridgewater、Salesforce 和 Stripe 等领先企业一直在通过非公开测试评估 EFS。

现在，我们正式开放 EFS 公开测试。在本文中，我们将更详细地解释 EFS 的工作原理、它如何保持与 ZDR 兼容，以及企业如何加入测试计划。

## EFS 如何在 ZDR 下提供自动化安全监控

依赖传统 ZDR 的客户受到 Claude [分类器](https://www.anthropic.com/research/next-generation-constitutional-classifiers)的保护：这些实时[安全保障机制](https://www.anthropic.com/news/building-safeguards-for-claude)会筛查单个请求，评估其是否可能造成危害。但复杂的攻击通常跨越多个查询——而任何单个请求孤立来看都可能显得无害。

例如，我们 9 月的[威胁情报报告](https://www.anthropic.com/threat-intelligence-report-september-2026#cyber-operations-sep-26)描述了针对约五十个组织的一次行动，其中一个 AI agent 将攻击工作分配给许多并行运行的其他 agent。它在会话之间保存了收集到的凭据，使攻击者能够轻松恢复其行动。如果一次只看一个请求，这次攻击会表现为彼此独立、更为无害的任务。

为了捕获此类攻击，我们使用了第二层防御，即自动化安全监控。这一层会跨多个请求寻找滥用模式。通过 EFS，Anthropic 可以在不存储任何客户数据的情况下提供自动化安全监控。相反，我们的自动化安全监控系统分析的数据完全存储在我们客户控制的基础设施上。

![传统 ZDR 与 EFS ZDR 的对比。两者都使用 Claude 对齐和实时分类器；只有 EFS ZDR 增加了自动化安全监控，它可以检测跨请求拆分的攻击，并创建一个案例供你审查。](https://assets.claude.com/407895af12324a5800318809efd87eda92ff500d.webp)

当自动化安全监控发现风险时，它会创建一个 Safety Case 供你审查。这些案例可以从你的云存储中读取，也可以通过 API 读取，并且可以与安全信息和事件管理系统集成。它们不包含输入和输出。

![Safety Case 示例的两个视图。你的团队和 Anthropic 都能看到案例 ID、危害类别、状态和标记的转录 ID；只有你的团队可以读取输入和输出。仅为示意示例；所有细节均为虚构。](https://assets.claude.com/debb29b66026bd3e0a55de89f8884d8ffe903570.webp)

设置完成后，自动化安全监控可以帮助你的团队检测可能导致严重危害的故意滥用（例如进攻性网络行动）。它还可以帮助检测执行超出用户意图的操作的 agent，例如——在极端情况下——利用软件漏洞访问内部数据库或外部系统。

## 零数据保留与 EFS

使用 EFS 时，你自带存储来存储输入和输出。一旦数据交付到你控制的存储中，Anthropic 和你的云服务提供商都不会保留你的数据副本。这为你提供以下保证：

- **零数据保留**。Anthropic 和你的云服务提供商都不会保留你的数据。你自带存储并存储自己的数据。输入和输出在写入你自己的存储后会立即被删除。你可以配置自己的访问策略和审计日志记录，并使用自己的密钥加密安全数据。
- **无运营人员人工审查。** Anthropic 和你的云服务提供商的人员均不会访问你的输入和输出。只有自动化安全监控可以访问这些数据。
- **我们绝不会使用你的数据训练。** 输入和输出仅用于自动化安全监控，绝不用于模型或分类器训练。

![EFS 架构。自动化安全系统将安全数据写入你云账户中的存储，并读取这些数据进行监控。Anthropic 接收安全通信和监控元数据，绝不接收输入、输出或摘录。](https://assets.claude.com/e1deaac362da2eb9fac5d8dc38feebc89b80ec00.webp)

你可以通过 Claude Platform、Claude Platform on AWS、Amazon Bedrock 或 Claude on Google Cloud 使用 EFS。当你通过 Amazon Bedrock 或 Claude on Google Cloud（Google Managed）使用 EFS 时，它由你的云服务提供商运营，端到端数据流保持在该云环境的边界内。

根据你使用 Claude 的位置，你可以使用自己账户中的 Amazon S3 或 Google Cloud Storage 作为存储。你的云服务提供商会照常就该存储向你收费，包括读取、写入和密钥操作（以及任何适用的网络传输费用）。

## 开始使用

EFS 已在 Claude Platform、Claude Platform on AWS、Amazon Bedrock 和 Claude on Google Cloud 上可用。Microsoft Foundry 对 EFS 的支持即将推出。

符合条件的客户将收到通知，其中包含如何开始使用的说明。请阅读我们的[开发者文档](https://platform.claude.com/docs/en/manage-claude/enterprise-frontier-safeguards/overview)了解如何设置，以及我们的[安全白皮书](https://trust.anthropic.com/resources?s=a7lwkeieqk3ggz29k954j&name=enterprise-frontier-safeguards:-technical-overview)了解该架构如何运作，或通过 Accenture、Deloitte、KPMG 和 PwC 等[咨询合作伙伴](https://partnerhub.claude.com/directory/)进行部署。
