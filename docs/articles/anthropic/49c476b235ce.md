# Claude Marketplace：在一处发现来自我们合作伙伴的插件、agent 与服务

找到那些工具和服务来用 Claude 做更多，或者上架你已构建的东西，与 Claude 客户一同成长。

- 类别：[产品公告](https://claude.com/blog/category/announcements)
- 产品：[Claude Platform](https://claude.com/platform/api)
- 日期：2026 年 9 月 23 日
- 阅读时长：5 分钟
- 分享：[复制链接](https://claude.com/blog/claude-marketplace#)https://claude.com/blog/claude-marketplace

从今天起，[Claude Marketplace](https://claude.com/marketplace) 把插件和连接器、agent 和产品，以及服务伙伴汇聚到一处。对客户，它提供了一个单一的去处来找到合适的工具和服务。对建设者和伙伴，它提供了一条更简便的路径来触达正在使用 Claude 的团队。

## **对客户：发现工具和服务，帮你用 Claude 做更多**

Claude Marketplace 是团队找到所需、以拓展其 Claude 用法的地方。你可以：

- **添加连接器和插件。** 从如今可用的 2,000 多个中挑选，包括 Atlassian、Google、Microsoft、Notion、Salesforce 等。
- **购买 agent 和产品。** 用你已承诺的 Anthropic 支出的一部分，来购买来自 CrowdStrike、Cursor、Harvey、Legora、Lovable、Snowflake 等公司的 Claude 驱动软件。
- **与服务伙伴一起扩展。** 从 [Claude Partner Network](https://partnerhub.claude.com/directory/) 里对接一家咨询伙伴或系统集成商，如埃森哲、波士顿咨询集团或德勤，来构建你的 AI 战略、并把 Claude 推广到整个组织。

## **对建设者和伙伴：让使用 Claude 的团队发现你**

为 Claude 客户构建工具、产品或服务的公司，可以在 Claude Marketplace 上架。选择契合你所供产品的那条路径：

- **为使用 Claude 的团队构建？** 使用由 Anthropic 率先开创的开放标准——Model Context Protocol（MCP）和 Agent Skills——创建一个[连接器](https://claude.com/docs/connectors/building/submission)或[插件](https://claude.com/docs/plugins/submit)。
- **在销售一个 Claude 驱动的 agent 或产品？** [申请](https://claude.com/marketplace-partners)在 marketplace 上架。团队随后可以用其已承诺 Anthropic 支出的一部分来购买它。
- **提供咨询或系统集成？** 加入 [Claude Partner Network](https://claude.com/form/cpn-partner-application) 以出现在 marketplace 上，让 Claude 客户能找到并对接你。
