每天都有数百万用户将 Claude 接入他们的应用、工作工具和数据。今天，我们让开发者更容易触达这些用户。

Plugin 可以打包 MCP 连接器、Agent Skills，或两者兼有，是为 Claude 构建第三方扩展的主要方式。构建一个 plugin，通过新的目录提交门户提交，审核通过后，它就会出现在 [Claude 目录](https://claude.ai/directory)中。

## **在目录提交门户中提交和跟踪插件**

[目录提交门户](https://claude.ai/directory/manage/new)面向付费 Claude 套餐的开发者开放。有两种方式可以提交插件并将其发布到 Claude 目录：

- **单一 MCP 连接器：** 指向你的远程 MCP 服务器。
- **Plugin 包：** 将 MCP 服务器与 skills 组合起来，托管在 GitHub 上，然后提交该仓库。在 Claude Code 中，plugin 还可以包含 LSP、命令、hooks 和 agents。

无论选择哪种方式，门户都会引导你从提交走到发布。你可以：

- **自动校验你的 plugin。** 每次提交后都会立即进行检查和安全扫描，让你尽早发现问题。
- **查看状态和反馈。** 了解你的 plugin 处于审核流程的哪个阶段、安全扫描的结果以及建议的修改。
- **准备好后再发布。** 审核通过后，由你决定何时在 Claude 中发布你的 plugin。

## **plugin 发布后对其进行监控和改进**

plugin 上线后，使用分析会显示按产品入口和版本划分的安装量，让你能够优先为用户安排修复和新功能。在发现方面，你可以看到列表的浏览次数，以及哪些搜索带来了这些访问，从而优化列表以触达新用户。

## **借助 MCP 2.0 及其扩展为用户带来丰富体验**

Claude 支持最新的 MCP 规范，通常被称为 [MCP 2.0](https://modelcontextprotocol.io/specification/2026-07-28)，其中包含无状态核心。你可以通过两个 [MCP 扩展](https://modelcontextprotocol.io/extensions/overview)改善 plugin 的使用体验：[MCP Apps](https://claude.com/docs/connectors/building/mcp-apps/getting-started)，用于在聊天中提供交互式 UI；以及 [Enterprise Managed Auth](https://claude.com/docs/connectors/building/enterprise-managed-auth)，为企业用户提供零接触 OAuth。对更多 MCP 功能和扩展的支持即将推出。

## **开始为 Claude 构建 plugin**

plugin 是第三方开发者为 Claude 创建扩展的主要方式。在未来几周内，统一的发现体验将在 Claude 和 Claude Code 中逐步上线。

Skills 和 MCP 连接器仍作为构建模块保留，Claude 目录也会继续列出它们。未来，开发者将能够把自己的连接器列表转变为 plugin。如果你在 Claude 目录中已有 skill、连接器或 plugin，则无需做任何更改。

要开始构建 plugin，请阅读我们的文档了解[如何构建 plugin](https://claude.com/docs/build/overview)，并[在此处](https://claude.ai/directory/manage/new)提交你的 plugin。
