每天，数以百万计的人将 Claude 接入自己的应用、工作工具和数据。今天，我们让开发者更容易触达这些用户。

Plugin 可以打包 MCP connector、Agent Skills，或两者兼有，是为 Claude 构建第三方扩展的主要方式。构建一个 plugin，通过新的目录提交门户提交，一经批准，它就会被列入 [Claude 目录](https://claude.ai/directory)。

## 在目录提交门户中提交并跟踪 plugin

[目录提交门户](https://claude.ai/directory/manage/new)面向使用付费 Claude 套餐的开发者开放。要提交 plugin 并把它发布到 Claude 目录，有两种方式：

- **单一 MCP connector：** 指向你的远程 MCP server。
- **Plugin 包：** 把 MCP server 与 skills 组合在一起，托管到 GitHub 上，然后提交该仓库。在 Claude Code 中，plugin 还可以包含 LSP、命令、hooks 和 agents。

无论选择哪条路径，门户都会引导你从提交走到发布。你可以：

- **自动校验 plugin。** 每次提交都会在提交后立即接受检查和安全扫描，让你尽早发现问题。
- **查看状态和反馈。** 看到你的 plugin 处于审核流程的哪个阶段、安全扫描的结果，以及建议的修改。
- **准备好后再发布。** 审核通过后，由你决定何时在 Claude 中发布 plugin。

## plugin 发布后进行监控和改进

plugin 上线后，使用分析会按产品入口和版本显示安装量，让你能够优先为用户安排修复和新功能。在发现方面，你能看到列表被浏览了多少次，以及哪些搜索把人们带到这里，从而优化列表，触达新用户。

## 借助 MCP 2.0 及其扩展为用户带来丰富体验

Claude 支持最新的 MCP 规范，通常被称为 [MCP 2.0](https://modelcontextprotocol.io/specification/2026-07-28)，其中包含无状态核心。你可以用两个 [MCP 扩展](https://modelcontextprotocol.io/extensions/overview)改善 plugin 的使用体验：[MCP Apps](https://claude.com/docs/connectors/building/mcp-apps/getting-started)，在聊天中提供交互式 UI；以及 [Enterprise Managed Auth](https://claude.com/docs/connectors/building/enterprise-managed-auth)，为企业用户提供零接触 OAuth。对更多 MCP 功能和扩展的支持即将推出。

## 开始为 Claude 构建 plugin

plugin 是第三方开发者为 Claude 创建扩展的主要方式。未来几周，一套统一的发现体验将在 Claude 和 Claude Code 中逐步上线。

Skills 和 MCP connector 仍作为构建模块保留，Claude 目录也会继续列出它们。未来，开发者将能够把自己的 connector 列表转变为 plugin。如果你在 Claude 目录中已有 skill、connector 或 plugin，则无需做任何改动。

要开始构建 plugin，请阅读我们的文档，了解[如何构建 plugin](https://claude.com/docs/build/overview)，并[在此处](https://claude.ai/directory/manage/new)提交你的 plugin。
