# 把 artifacts 变成 Mac 和 Windows 应用

从今天起，你可以用 Claude artifacts 来创建、运行和分享桌面应用。“Install as app”功能正在 Claude for Mac 和 Claude for Windows 上以 beta 形式逐步推出。

当一个 artifact 被安装为 Mac 或 Windows 应用后，它会拥有自己的图标，并在自己的窗口中打开，而不是在 Claude 内部。你可以把它分享给其他人，而它在能够与你的计算机交互之前需要你的许可。允许多少，由你决定。

每个应用都可以使用 Claude 和你的 connector，并且当底层的 artifact 被编辑时，它会自动更新。这为知识工作者和开发者都简化了构建和维护应用的流程。应用向 Claude 发起的请求会计入你所在套餐的用量限制。

artifacts 最初只是你会分享出去的一项工作产出，比如一张图表或一个网页。如今人们把它们当作日常工作的工具，比如一个会定期从日历和邮件中取数的会议准备页面，或者一个追踪当天需要发货的订单的工具。

如果你依赖某个工具来工作，它就应该像你的其他应用一样打开，并在有事情需要你关注时提醒你。

## 已安装的应用能做什么

已安装的应用可以发送通知，或向你的菜单栏或系统托盘添加项目。你为每个应用选择权限，Team 和 Enterprise 的管理员可以为他们的组织开启或关闭应用权限和完全访问。

Anthropic 的员工用这些功能做出过：

- [Linnet](https://claude.ai/artifact/HPtmhTpoSdHmRKNCJEUsoS)，一个完整的分层图像编辑器
- [Phosphor](https://claude.ai/artifact/UtJhPrH24ejRTTWRtohwbx)，一个看起来像是为电影片场打造的文件管理器
- [Sift](https://claude.ai/artifact/BDCr8b2L6rbJQXhsztAL2x)，可以设置文件夹规则，并用 Claude 帮你把东西整理得井井有条
- [Tern](https://claude.ai/artifact/7QjDeZEKPQUsDUCmFEjvyy)，一个终端，Claude 就在你身边提供帮助和讲解
- [Vitals](https://claude.ai/artifact/NSkw2jaPZdkdqkrVfswSGc)，一个菜单栏和托盘应用，用来瞄一眼你电脑的性能

你可以在[这里](https://claude.ai/artifact/9j53nCVcrSdZyCHtxUZkWJ)看到更多由我们的一位工程师制作的演示应用。

## 权限

共有三个权限层级：

- **默认：** 已安装的应用只能做它们在浏览器里能做的事。
- **应用权限：** 应用可以请求使用 Claude 能够严密控制的常用功能，比如创建始终置顶的窗口、监听全局快捷键或发送通知。
- **完全访问计算机：** 应用可以请求运行程序，以及读取、修改或删除你的文件，而不必每次都询问。

你的授权只覆盖应用的当前版本，因此每次更新后 Claude 都会再次询问，即便更新来自你自己的编辑。如果应用的某一部分来自另一个网站，那么这一部分可以在 Claude 不再询问你的情况下发生变化。

你只能为你自己制作的应用授予完全访问权限；在 Team 和 Enterprise 上，也可以为组织内成员制作的应用授予完全访问权限。Anthropic 不会在你安装应用之前对其进行审查，所以只把完全访问权限授予你信任的应用。

## 开始使用

向 Claude 描述你的应用，先把它当作 artifact 试用，然后点击“Install as app”。你不需要打包或签名，它使用的是你的 Claude 账号，因此无需 API key，也无需单独登录。

Install as app 正在以 beta 形式向所有套餐推出。符合 HIPAA 要求的组织和混合部署无法使用。在 Team 上，它默认开启，完全访问默认关闭。在 Enterprise 上，它默认为关闭，直到所有者开启。你需要在线并已登录 Claude 才能打开应用。有些 artifacts 无法安装，包括 Claude Docs、Slides 和 Sheets。

更新 Claude for Mac 或 Claude for Windows，打开一个你每天都会用到的 artifact，然后从 Share 菜单中选择“Install as app”。
