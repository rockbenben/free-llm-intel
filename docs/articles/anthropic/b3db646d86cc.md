从今天开始，你可以使用 Claude artifacts 创建、运行和共享桌面应用。“Install as app”功能正在 Claude for Mac 和 Windows 中以 beta 版形式逐步推出。

当某个 artifact 被安装为 Mac 或 Windows 应用后，它会拥有自己的图标，并在自己的窗口中打开，而不是在 Claude 内部打开。你可以与他人共享它，并且它需要获得你的许可才能与你的电脑交互。你可以选择允许多少权限。

每个应用都可以使用 Claude 和你的 connectors，并且当底层 artifact 被编辑时，它会自动更新。这为知识工作者和开发者简化了构建和维护应用的流程。应用向 Claude 发出的请求会计入你套餐的使用限制。

Artifacts 最初是一种你会分享的工作成果，比如图表或网页。现在，人们把它们当作日常工作的工具，比如定期从日历和电子邮件中拉取内容的会议准备页面，或者用于跟踪当天需要发货订单的追踪器。

如果你在工作中依赖某个工具，它应该像你其他应用一样打开，并在有事情需要你关注时提醒你。

## 已安装应用能做什么

已安装的应用可以发送通知，或将项目添加到你的菜单栏或系统托盘。你可以为每个应用选择权限，Team 和 Enterprise 管理员可以为其组织开启或关闭应用权限和完全访问权限。

Anthropic 的员工曾用这些功能制作：

- [Linnet](https://claude.ai/artifact/HPtmhTpoSdHmRKNCJEUsoS)，一个完整的分层图像编辑器
- [Phosphor](https://claude.ai/artifact/UtJhPrH24ejRTTWRtohwbx)，一个看起来像是为电影片场打造的文件管理器
- [Sift](https://claude.ai/artifact/BDCr8b2L6rbJQXhsztAL2x)，它会设置文件夹规则，并使用 Claude 帮你保持内容井然有序
- [Tern](https://claude.ai/artifact/7QjDeZEKPQUsDUCmFEjvyy)，一个在你身边由 Claude 提供帮助和解释的终端
- [Vitals](https://claude.ai/artifact/NSkw2jaPZdkdqkrVfswSGc)，一个用于查看电脑性能的菜单栏和托盘应用

你可以在[这里](https://claude.ai/artifact/9j53nCVcrSdZyCHtxUZkWJ)看到更多由我们的一位工程师制作的演示应用。

## 权限

权限有三个级别：

- **默认：** 已安装的应用只能执行它们在浏览器中能够执行的操作。
- **应用权限：** 应用可以请求使用 Claude 能够严格控制的常见功能，例如创建始终置顶的窗口、监听全局快捷键或发送通知。
- **完全访问计算机：** 应用可以请求运行程序，以及读取、更改或删除你的文件，而无需每次都询问。

你的许可仅覆盖应用的当前版本，因此每次更新后 Claude 都会再次询问，即使是你自己所做的编辑也是如此。如果应用的某一部分来自其他网站，那么该部分可能会在未经 Claude 再次询问你的情况下发生变化。

你只能向你制作的应用授予完全访问权限；在 Team 和 Enterprise 中，只能向组织内人员制作的应用授予完全访问权限。Anthropic 不会在你安装应用前审核它们，因此请只向你信任的应用授予完全访问权限。

## 开始使用

向 Claude 描述你的应用，将它作为 artifact 试用，然后点击“Install as app”。你无需打包或签名，它会使用你的 Claude 账户，因此不需要 API key 或单独登录。

Install as app 正在所有套餐中以 beta 版形式逐步推出。HIPAA-ready 组织和混合部署无法使用它。它在 Team 中默认开启，完全访问权限关闭。在 Enterprise 中，它默认关闭，直到所有者将其开启。你需要联网并登录 Claude 才能打开应用。某些 artifacts 无法安装，包括 Claude Docs、Slides 和 Sheets。

更新 Claude for Mac 或 Windows，打开你每天使用的 artifact，然后从 Share 菜单中选择“Install as app”。
