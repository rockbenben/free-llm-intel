我们已经看到 Claude Code 改变了开发者的工作方式：工程师从一行行手写代码，变成描述想法、再审阅 Claude 搭出来的东西，重新找回了动手创造的乐趣。我们的目标是把这种魔力带给每个团队，而今天我们正在拓宽 Claude 能做到的事。我们借 **Claude Sheets,** **Claude Whiteboards** 和 **Claude Data** 引入新的 artifact 类型，还升级了 **交互式 connectors**，让你在最常用的应用里工作更顺手。**Claude Meetings** 也即将推出。

## 你所有的 connectors 和上下文

在 Claude Code 里，Claude 需要的上下文本来就在代码库中。对其他团队来说，上下文散落在邮件、应用和网盘里。Claude 通过构建在 [Model Context Protocol](https://www.anthropic.com/news/model-context-protocol) (MCP) 之上的 connectors 触达这些内容——MCP 是我们提出的开放标准，用来把 AI 接到你日常使用的工具上。Claude Marketplace 收录了 9,000 多个 connectors 和插件，其中也有社区贡献的。

[**交互式 connectors**](https://claude.com/resources/articles/interactive-connectors-full-tool) 把这件事又往前推了一步。从今天起，合作伙伴可以把应用直接嵌进 Claude，你无须切换标签页就能在 Adobe、Atlassian 等工具里工作。来自 Salesforce (beta)、NetSuite 和 Workday (beta) 的插件自带 skills，销售可以为通话做准备，会计可以分析财务数据，HR 团队可以处理休假和报销。

## 一起更快地把想法变成现实

从今天起，Claude 可以和你的团队一起搭建电子表格、白板和仪表板。这些能力与它原有的[文档、幻灯片和设计](https://www.youtube.com/watch?v=To5nrYqvR44)生成能力，以及 [Claude Motion](https://support.claude.com/en/articles/17454997-get-started-with-claude-motion) (beta)（帮你把内容变成短动画）配合使用。在每一种里，Claude 都能很快领会你要什么，于是工作节奏由你的思路来定：

- [**新的 artifact 类型**](https://claude.com/resources/articles/sheets-whiteboards-data)：在 Claude Sheets 中，团队和 Claude 一起搭建电子表格、协作整理数据、创建和编辑公式，并跨多个标签页工作。Claude Whiteboards 是一块数字白板，团队可以在会议里一起铺开、梳理想法，再让 Claude 总结结论。Claude Data（原 Dashboards）连接 Snowflake、Salesforce 等工具，还能用数据团队认证过的定义 (beta) 生成仪表板、可视化数据故事或带旁白的短视频。

你还可以让 Claude 按团队的工作方式定制 artifact，比如客户跟踪表、每日简报、项目状态板或合同审查表。由于 Claude 在每一步都带着同一份上下文，一个想法可以从白板流到电子表格、再到仪表板，不必反复重述细节。

即将推出的 **Claude Meetings** 可以让你把 Claude 加进通话，由它记笔记，并在对话过程中更新团队正在处理的文档。

## 已经这样工作的团队

在 Anthropic 内部，非技术团队从 Claude 身上获得的帮助，正开始不输给工程师。法务团队和 Claude 一起搭了一个基于 Slack 的法律审查工具，能自动依据团队自己的规范手册标出修订意见。这把营销材料审核从三天压到 24 小时，简单的修改在律师看草稿之前就已处理妥当。财务团队则把一份给高管看的长篇业务更新文档变成了交互式页面，现在全组和 Claude 一起更新它。

这两个团队都不写代码，却都是各自领域的行家。他们用 Claude 把这些经验变成省时的工具，还能给其他人复用。我们的客户也在这样工作：

## 为企业打造，也与企业共建

随着 Claude 接入的工具越来越多，企业需要更好的办法来监督它的访问权限和动作。我们在产品里内置了安全与合规控制，帮助企业满足自身要求；我们自己最敏感的工作，用的也是同一个 Claude。在 Enterprise 计划中，管理员决定谁能用哪些产品和 connectors，并为组织设置细粒度的支出上限。

这套控制同样适用于 Claude 接入的工具。借助 [**Claude auto-connect**](https://support.claude.com/en/articles/15537633-auto-connect-your-organization-s-apps-to-claude)（目前对符合条件的 Team 和 Enterprise 计划开放 beta），连接 Notion、Atlassian、Dropbox 这类应用只需一次性配置。之后员工第一次在 Claude 里用到该工具时就会自动连上，不必逐个手动连接。

无论工具以哪种方式接入，Claude 都只在你现有的权限范围内工作。管理员还能限制每个 connector 能做什么，比如让 Claude 可以读 Slack，却不能替你发消息。

保护敏感业务数据是我们做产品的根本，随着 Claude 承担起更长、更复杂的任务，我们也在持续加固这些防护：

- [来自 Enterprise 组织的数据](https://claude.com/resources/articles/unified-claude-enterprise) 在传输和静态存储时都经过加密。
- 在 Enterprise 计划中，安全团队[可以查看 Claude 的使用情况](https://support.claude.com/en/articles/15167101-get-started-with-claude-compliance-api-integrations)，途径是审计日志和一个 Compliance API，后者能对接 100 多种安全与合规工具，包括 Splunk 和 CrowdStrike。
- 在 Enterprise 的全新 Claude 体验中，每个云会话都跑在自己的[隔离虚拟机](https://claude.com/resources/articles/unified-claude-enterprise)里，connector 凭据保存在虚拟机之外。

## 跟得上你思路的工作

现代工作是围绕软件组织起来的，而 Claude 围绕你来运转。它通过你接入的工具了解团队的工作，帮你把想法变成所需格式，并且只在管理员设定的控制范围内运行。这样你就有更多时间专注于大目标，稳步推进。
