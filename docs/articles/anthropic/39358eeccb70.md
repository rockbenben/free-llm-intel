我们已经看到 Claude Code 改变了开发人员的工作方式。工程师从逐行手动编码，到描述想法并审查 Claude 构建的内容。它让他们重新感受到了建造的乐趣。我们的目标是将这种魔力带给每个团队，今天我们正在扩展Claude所实现的功能。我们通过 **Claude Sheets、** **Claude Whiteboards** 和 **Claude Data** 引入新的工件类型。我们还通过升级到**交互式连接器**，让您更轻松地在最常用的应用程序中工作。 **Claude会议**即将推出。

## 所有连接器和上下文

在 Claude Code 中，Claude 需要的上下文已经在代码库中。对于其他团队来说，上下文遍布电子邮件、应用程序和驱动器。 Claude 通过基于模型上下文协议（在新选项卡中打开）](https://www.anthropic.com/news/model-context-protocol) (MCP) 构建的连接器来实​​现这一目标，MCP 是我们引入的开放标准，用于将 AI 连接到您使用的工具。 Claude Marketplace 列出了 9,000 多个连接器和插件，其中包括社区构建的连接器和插件。

[**交互式连接器**（在新选项卡中打开）](https://claude.com/resources/articles/interactive-connectors-full-tool) 更进一步。从今天开始，合作伙伴可以将他们的应用程序直接嵌入到 Claude 中，这样您就可以在 Adob​​e、Atlassian 等中工作，而无需切换选项卡。 Salesforce（测试版）、NetSuite 和 Workday（测试版）的插件具有内置技能，因此销售人员可以准备通话，会计师可以分析财务数据，人力资源团队可以处理休假和费用。

## 一起更快地将想法变为现实

从今天开始，Claude 可以与您的团队一起构建电子表格、白板和仪表板。这些工具可利用其现有功能来创建[文档、幻灯片和设计（在新选项卡中打开）](https://www.youtube.com/watch?v=To5nrYqvR44)，并与[Claude Motion（在新选项卡中打开）](https://support.claude.com/en/articles/17454997-get-started-with-claude-motion) (测试版) 配合使用，帮助您将内容转换为短动画。在每一项中，Claude都能快速找到您需要的内容，因此您的想法决定了工作节奏：

- [**新工件类型**（在新选项卡中打开）](https://claude.com/resources/articles/sheets-whiteboards-data)：在 Claude Sheets 中，您的团队和 Claude 一起构建电子表格、协作组织数据、创建和编辑公式以及跨多个选项卡工作。Claude Whiteboards 是一个数字白板，您的团队可以使用它在会议中一起布置和组织想法，然后要求 Claude 总结结果。Claude 数据（以前称为 Dashboards）连接到 Snowflake 和 Salesforce 等工具，并且可以使用数据团队认证（测试版）的定义来创建仪表板、可视化数据故事或解说短视频。

您还可以要求 Claude 为您的团队工作方式构建自定义工件，例如帐户跟踪器、每日简报、项目状态板或合同审查表。由于Claude在每个步骤中都携带相同的上下文，因此一个想法可以从白板到电子表格再到仪表板，而无需重申细节。

即将推出的 **Claude Meetings** 将允许您将 Claude 添加到通话中，以记笔记并更新您的团队在对话期间正在处理的文档。

## 团队已经以这种方式工作

在 Anthropic 内部，非技术团队开始像我们的工程师一样从 Claude 身上得到同样多的帮助。我们的法律团队与 Claude 合作构建了一个基于 Slack 的法律审查工具，可以自动从团队自己的剧本中划出红线。这使得营销审核时间从三天缩短到了 24 小时，并且在律师审核草稿之前就可以轻松修复。我们的财务团队将一份供高管使用的冗长的业务更新文档变成了交互式页面，现在整个团队与 Claude 一起更新它。

这些团队都不编写代码，但他们都是各自领域的专家。他们利用Claude将这些知识转化为工具，节省了他们的时间，并可供其他人使用。我们的客户也采用这种方式工作：

## 为企业打造并与企业合作

随着Claude开始连接更多工具，企业需要更好的方法来监督其访问和操作。我们建立安全和合规控制来帮助企业满足他们自己的要求，并且我们使用同样的Claude来完成我们自己最敏感的工作。在企业计划中，管理员决定谁可以使用哪些产品和连接器，并为组织设置精细的支出限制。

该控制适用于 Claude 连接的工具。使用 [**Claude 自动连接**（在新选项卡中打开）](https://support.claude.com/en/articles/15537633-auto-connect-your-organization-s-apps-to-claude)（目前在符合条件的团队和企业计划中处于测试阶段），连接 Notion、Atlassian 或 Dropbox 等应用程序是一次性设置。然后，员工在 Claude 第一次使用该工具时就会连接到该工具，而不是单独连接每个工具。

无论工具以哪种方式连接，Claude 都会在您现有的权限范围内工作。管理员还可以限制每个连接器的功能，这意味着 Claude 可能能够读取 Slack，但不能代表您发送消息。

保护敏感业务数据是我们构建方式的核心，随着 Claude 承担更长、更复杂的工作，我们将继续加强这些保护：

- [来自企业组织的数据（在新选项卡中打开）](https://claude.com/resources/articles/unified-claude-enterprise) 在传输和静态时均进行加密。
- 在企业计划中，安全团队[可以通过审核日志和可与 100 多种安全和合规工具（包括 Splunk 和 CrowdStrike）配合使用的合规性 API 查看 Claude 的使用方式（在新选项卡中打开）](https://support.claude.com/en/articles/15167101-get-started-with-claude-compliance-api-integrations)。
- 在 Enterprise 上的新 Claude 体验中，每个云会话都在自己的[隔离虚拟机（在新选项卡中打开）](https://claude.com/resources/articles/unified-claude-enterprise) 中运行，连接器凭据保留在其外部。

## 与您的想法保持同步的工作

现代工作是围绕软件进行的，但Claude是围绕你工作的。它通过您连接的工具了解您团队的工作，帮助您以所需的格式将想法变为现实，并在管理员设置的控制范围内运行。这让你有更多的时间专注于大目标并取得进展。
