从今天起，[Claude Marketplace](https://claude.com/platform/marketplace) 把 plugins 与 connectors、agents 与产品，以及服务合作伙伴汇聚到一处。对客户来说，它是一个集中寻找合适工具与服务的目的地。对开发者和合作伙伴来说，它提供了一条更轻松的路径，触达正在使用 Claude 的团队。

## **面向客户：发现各类工具与服务，用 Claude 做得更多**

Claude Marketplace 是团队寻找所需内容、扩展 Claude 用法的地方。你可以：

- **添加 connectors 与 plugins。** 目前已有 2,000 多个可供选择，包括 Atlassian、Google、Microsoft、Notion、Salesforce 等。
- **购买 agents 与产品。** 将已承诺的 Anthropic 支出中的一部分，用于购买 CrowdStrike、Cursor、Harvey、Legora、Lovable、Snowflake 等公司提供的 Claude 驱动软件。
- **借助服务合作伙伴扩展规模。** 与 [Claude Partner Network](https://partnerhub.claude.com/directory/) 中的咨询合作伙伴或系统集成商联系，例如 Accenture、Boston Consulting Group 或 Deloitte，共同制定 AI 战略，并在整个组织中推广 Claude。

![](https://assets.claude.com/6af000f4ed9f59ecaf6a104191c1d2af6f2559aa.png)

## **面向开发者与合作伙伴：让使用 Claude 的团队发现你**

为 Claude 客户开发工具、产品或服务的公司，都可以入驻 Claude Marketplace。选择与你所提供内容相符的路径：

- **为使用 Claude 的团队开发？ **使用 Anthropic 开创的开放标准 Model Context Protocol (MCP) 与 Agent Skills，创建一个 [connector](https://claude.com/docs/connectors/building/submission) 或 [plugin](https://claude.com/docs/plugins/submit)。
- **在销售由 Claude 驱动的 agent 或产品？** [申请](https://claude.com/marketplace-partners)将其上架到 marketplace。随后团队可以使用其已承诺 Anthropic 支出中的一部分来购买。
- **提供咨询或系统集成服务？** 加入 [Claude Partner Network](https://claude.com/form/cpn-partner-application) 以出现在 marketplace 中，Claude 客户可以在那里找到你并与你建立联系。

## **客户聚焦**
