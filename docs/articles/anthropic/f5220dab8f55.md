# Claude Duet 正式发布

今天，我们开放了 Claude Duet 的研究预览，这是一款让 Claude 作为主动型 agent 工作的新应用。它会主动来找你，告诉你哪些事需要关注，完成你交给它的任务，即使你走开也继续工作，并在代替你行动之前先向你确认。我们打造 Claude Duet，是给那些手头事务多到来不及一一盯住的专业人士和小企业主的。

它以独立应用的形式提供，支持 iOS 和 Android，也可以在 claude.ai 上使用。在本次研究预览期间，Claude Duet 已包含在 Pro 和 Max 套餐中，并与其他 Claude 产品使用同一套用量额度。想要获得访问权限，请[加入候补名单（在新选项卡中打开）](https://claude.com/product/claude-duet)。

## 把注意力放在最重要的地方

我们把 Claude Duet 设计成一个你可以信赖的伙伴。各行各业的专业人士每天都要在许多决定之间周旋，我们认为他们会觉得 Claude Duet 最有用。它帮你看清该把时间和精力花在哪里，也为那些过去觉得不可能或令人却步的宏大项目留出空间。

Claude Duet 之所以这么好用，关键在于它的判断力。我们围绕 [Claude Opus 5.5（在新选项卡中打开）](https://www.anthropic.com/claude-opus-5-5) 来设计它，把它做得善于想办法，能判断哪些事需要你、哪些事可以等、什么时候该先来跟你确认。

每天早上，它会把你所有已连接应用中最重要的事项汇总成一份简短简报发给你。一整天里，它持续留意这些应用，只在有需要你关注的事情时才给你发消息。你也可以把各种各样的任务交给它——从安排会议这类简单的行政事务，到更复杂的任务，例如用几十种工具搭建 dashboard、做财务或销售预测、做原型，以及构建 web 应用。

## 安全与审慎是内置的

Claude Duet 借鉴了我们多年来在 agent 的安全、可靠性与隐私方面的工作积累，既包括我们自己的成果，也包括企业用来运行其 agent 的那套基础设施：

- Claude Duet 沿用我们[值得信赖的 agent 框架（在新选项卡中打开）](https://www.anthropic.com/research/trustworthy-agents)，同样的框架也指导着 Claude Code、Claude in Chrome 这类 agent。
- Claude Duet 对凭证的处理遵循我们在 [Claude Managed Agents（在新选项卡中打开）](https://www.anthropic.com/engineering/managed-agents) 中使用的设计，因此它绝不会直接看到你的密码或登录 token。
- 动作要经由我们的 [auto mode 分类器（在新选项卡中打开）](https://www.anthropic.com/engineering/claude-code-auto-mode) 批准，这正是保护 Claude 和 Claude Code 不踏出你没要求的那一步的同一项保障措施。
- Claude Duet 对隐藏指令与 prompt injection 的防护来自我们的[浏览器使用研究（在新选项卡中打开）](https://www.anthropic.com/research/prompt-injection-defenses)，我们的模型与保障措施也在更广的范围内覆盖这一点。
- 我们针对 Claude Duet 的安全基础设施开展对抗性测试。红队和一家外部公司对 Claude Duet 做了渗透测试，它也纳入我们公开的[漏洞赏金计划（在新选项卡中打开）](https://hackerone.com/anthropic)。

**Duet 如何处理敏感信息。**我们发布 Claude Duet 时还带来了一个全新的专用分类器和 safety system prompt，它们逐条检查消息、防止敏感信息泄露。一个替你读邮件、发消息的 agent，无时无刻不在判断信息该往哪里去。这套新的分类器和 prompt 的设计目标是拒绝共享最高级别敏感信息的请求，包括信用卡号和政府签发的身份证件。其他敏感信息，例如健康状况或个人财务，只有在你明确指示 Claude Duet 发送时才会放行。

我们会继续开发并加强这些保护，并在接下来几天分享更多细节，说明 Claude Duet 在安全方面是如何设计的。

## Claude Duet 如何工作

**你在 Claude 里已有的上下文就是基础。** Claude Duet 会把你 Claude 账号中的 memory、skills 和已连接应用一并继承过来，所以配置它几乎不需要做什么。改变的是你们的协作方式：Claude Duet 会先来找你，你可以在一个持续进行的会话线程里用打字或语音给它发消息，因此一句快速回复和一个为期一周的项目都从同一个地方开始。

**你走开之后工作继续。** Claude Duet 有一台自带浏览器的虚拟机，所以不需要你的笔记本电脑或手机保持开机。用一条简短消息描述任务，它就会在后台自己算清楚该用哪些应用、该走哪些步骤。任务完成或需要你审核时，你会收到通知。

**有事需要你时给你发消息。** Claude Duet 每隔几小时检查一次你已连接的账号，因为不间断地检查会快得多地耗尽你套餐的额度。我们会继续检验它关于何时该给你发消息的判断，并根据测试者告诉我们的情况持续调校。你也可以告诉它你想听到哪些事、以及多久一次。

**重要决定仍然留在你手里。** Claude Duet 会自己阅读、起草和准备工作。但在它发送消息、支付款项、签署文件或删除任何东西之前，它会准确地展示自己即将做什么，并等待你的批准。有少数事情即使你批准也不允许，比如交易证券或在账户之间转移资金。你也能断开 Claude Duet 有权访问的任何应用。

**接入你业务赖以运转的工具。** Claude Duet 可以使用 [Claude Marketplace（在新选项卡中打开）](https://claude.com/marketplace/connectors-plugins) 中超过 6,000 个连接器和插件来：

- 找出你错过的 Gmail 和 Slack 消息，并帮你回复。
- 到 Intuit QuickBooks 或 Stripe 里查看未付款的发票，并起草提醒。
- 在 Gusto 里准备并发放工资，工时、奖金和报销都已填好。
- 起草一份招聘启事，等你修改并批准后发布到 LinkedIn。
- 帮忙准备协议，并通过 Docusign 发送出去供审阅和签署。
- 用 HubSpot 里的联系人和交易记录起草跟进邮件。
- 在 Canva 里把你的产品发布做成一场社交推广活动。
- 搭建、设计并管理你的 Shopify 店铺。即将推出的、功能更丰富的可视化编辑器会让你设计店铺页面，并在任何内容上线前先预览。

你也可以用 Claude Duet 通过 Link（Stripe 的数字钱包）为你的业务采购东西。Claude Duet 会和你确认要买的商品，Link 则请你批准这笔支出，随后用虚拟卡付款，因此你真实的卡号不会被共享。它还能用 Shopify 的 Shop Pay 在网上商店结账。即将上线的是：经你允许后，它可以用你保存在 1Password 里的登录信息登录网站。

## 加入研究预览

这是 Claude Duet 的早期版本，它仍可能误读一个会话线程，或判断错什么才算紧急。它的核心能力是围绕工作构建的，所以订票这类个人事务表现得没那么强，它也还不能把自己正在使用的浏览器展示给你看。目前 Claude Duet 待在自己独立的应用里，与主 Claude 应用是分开的。我们从早期用户那里学到的东西，会塑造这两者今后如何协作。

在研究预览期间，Claude Duet 与 Claude 的其他部分共用你套餐的用量额度，而且它的消耗方式和普通对话不同。它的后台检查会计入这些额度，而更大的任务，比如搭建财务模型或做一份 deck，需要更多轮模型调用和后台工作。

我们今天先从美国的 Pro 和 Max 用户开始。加入[候补名单（在新选项卡中打开）](https://claude.com/product/claude-duet)，Claude Duet 一旦准备好面向你开放，我们就给你发邮件。
