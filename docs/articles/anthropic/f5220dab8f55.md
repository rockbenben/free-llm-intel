今天，我们将开放 Claude Duet 的研究预览版，这是一款新应用程序，Claude 在其中充当主动代理。它会向您提供需要您关注的内容，完成您要求它完成的任务，即使您离开后仍会继续工作，并在代表您采取行动之前与您核实。我们为专业人士和小企业主打造了 Claude Duet，他们的工作量超出了他们的能力范围。

它可以在 iOS 和 Android 以及 claude.ai 上作为独立应用程序使用。对于本研究预览，Claude Duet 包含在 Pro 和 Max 计划中，并使用与 Claude 的其他部分相同的使用限制。要获得访问权限，请[加入候补名单（在新选项卡中打开）](https://claude.com/product/claude-duet)。

## 将注意力放在最重要的地方

我们将 Claude Duet 设计为您可以信赖的合作伙伴。各类专业人士每天都必须做出许多决定，我们认为他们会发现 Claude Duet 最有用。它可以帮助您优先考虑将时间和精力花在哪里，并为以前感觉不可能或令人畏惧的雄心勃勃的项目留出空间。

Claude Duet 之所以如此有帮助，是因为它的判断力。我们围绕 [Claude Opus 5.5（在新选项卡中打开）](https://www.anthropic.com/claude-opus-5-5) 进行设计，并将其构建为足智多谋，并决定什么需要您、什么可以等待以及何时首先与您联系。

每天早上，它都会向您发送有关所连接应用程序中最重要项目的简短摘要。一整天，它都会密切关注这些应用程序，并仅在有事情需要您注意时才向您发送消息。您还可以将各种类型的任务交给它，从安排会议的简单管理任务到更复杂的任务，例如使用数十种工具构建仪表板、创建财务或销售预测、原型设计和构建 Web 应用程序。

## 安全性和谨慎性是内置的

Claude Duet 借鉴了我们多年来对代理的安全、保障和隐私工作的经验，包括我们自己的代理和用于运行其代理的基础设施企业：

- Claude Duet 利用了我们的[值得信赖的代理框架（在新选项卡中打开）](https://www.anthropic.com/research/trustworthy-agents)，该框架还为 Chrome 中的 Claude Code 和 Claude 等代理提供了指导。
- Claude Duet 对凭据的处理遵循我们用于 [Claude Managed Agents（在新选项卡中打开）](https://www.anthropic.com/engineering/managed-agents) 的设计，因此它永远不会直接看到您的密码或登录令牌。
- 操作由我们的[自动模式分类器（在新选项卡中打开）](https://www.anthropic.com/engineering/claude-code-auto-mode) 批准，同样的保护措施可以保护 Claude 和 Claude Code 不采取您不要求的步骤。
- Claude Duet 对隐藏指令和提示注入的防御来自我们的[浏览器使用研究（在新选项卡中打开）](https://www.anthropic.com/research/prompt-injection-defenses)，我们的模型和防护措施也更广泛地涵盖了这一点。
- 我们对 Claude Duet 的安全基础设施进行对抗性测试。红队和外部公司渗透测试了 Claude Duet，它由我们的公共 [bug 赏金计划（在新选项卡中打开）](https://hackerone.com/anthropic) 涵盖。

**Duet 如何处理敏感信息。** 我们还发布了 Claude Duet，其中包含新的专用分类器和安全系统提示，可检查每条消息并防止敏感信息泄露。为您读取电子邮件和发送消息的代理不断地决定信息的去向。这种新的分类器和提示旨在拒绝共享最严格信息层的请求，包括信用卡号码和政府身份证明。其他敏感信息（例如健康或个人财务）仅在您明确指示 Claude Duet 发送时才会发送。

我们将继续开发和加强这些保护措施，并将在未来几天分享有关 Claude Duet 的安全设计的更多详细信息。

## 克劳德二重唱如何运作

**Claude 的背景是基础。** Claude Duet 会继承您的 Claude 帐户中的记忆、技能和连接的应用程序，因此设置它只需很少的工作。改变的是你们的合作方式：Claude Duet 首先来找您，您可以在一个正在进行的线程中通过打字或语音向其发送消息，因此快速回复和为期一周的项目都在同一个地方开始。

**当您离开时，工作仍在继续。** Claude Duet 有一个带有自己的浏览器的虚拟机，因此不需要您的笔记本电脑或手机处于打开状态。在短信中描述一项任务，它会计算出要使用哪些应用程序以及在后台执行哪些步骤。当任务完成或需要您审核时，您会收到通知。

**当有需要时收到消息。** Claude Duet 每隔几个小时检查一次您连接的帐户，因为不间断检查会更快地用完您的计划的限额。我们正在继续测试它对何时向您发送消息的判断，并且我们将根据测试人员告诉我们的内容不断调整它。您还可以告诉它您想听什么以及多久听一次。

**重要决定由您决定。** Claude Duet 自行阅读、起草和准备工作。但在它发送消息、付款、签署文档或删除任何内容之前，它会准确地向您显示它将要执行的操作并等待您的批准。即使经过您的批准，有些事情也是禁止的，例如交易证券或在账户之间转移资金。您还可以断开 Claude Duet 有权访问的任何应用程序。

**与您的业务运行所用的工具连接。** Claude Duet 可以使用 [Claude Marketplace（在新选项卡中打开）](https://claude.com/marketplace/connectors-plugins) 中的 6,000 多个连接器和插件来：

- 查找您错过的 Gmail 和 Slack 消息并帮助您回复。
- 检查 Intuit QuickBooks 或 Stripe 是否有未付发票和草稿提醒。
- 在 Gusto 中准备和运行工资单，填写工时、奖金和报销。
- 起草职位发布，编辑并批准后将其发布到 LinkedIn。
- 帮助准备协议并通过 Docusign 发送以供审核和签名。
- 使用 HubSpot 中的联系和交易历史记录起草后续电子邮件。
- 在 Canva 中将您的产品发布变成一场社交活动。
- 设置、设计和管理您的 Shopify 商店。即将推出的更丰富的可视化编辑器将允许您设计店面并在任何内容上线之前预览它。

您还可以使用 Claude Duet 通过 Stripe 的数字钱包 Link 为您的企业购买物品。 Claude Duet 与您确认该项目，Link 要求您批准支出。然后它会使用虚拟卡进行支付，因此您的真实卡号不会被共享。它还可以使用 Shopify 的 Shop Pay 在在线商店结账。很快，在您的许可下，它将能够使用您在 1Password 中保存的登录信息登录网站。

## 加入研究预览

这是 Claude Duet 的早期版本，它仍然可能会误读线程或错误校准紧急事项。我们围绕工作构建了它的核心功能，因此个人事务（例如订票）不太强大，而且它还无法向您显示其浏览器。目前，Claude Duet 运行在自己的应用程序中，与主 Claude 应用程序分开。我们从早期用户那里学到的东西将决定两者如何协同工作。

在研究预览期间，Claude Duet 与 Claude 的其他人分享您的计划的使用限制，并且它使用这些限制的方式与典型对话的方式不同。它的背景调查会计入这些限制，而更大的任务，比如构建财务模型或套牌，需要更多的模型转变和后台工作。

我们从今天开始面向美国的 Pro 和 Max 用户。加入[候补名单（在新选项卡中打开）](https://claude.com/product/claude-duet)，一旦 Claude Duet 准备好，我们就会向您发送电子邮件。
