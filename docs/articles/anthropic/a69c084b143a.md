# 站在前沿工作：Balyasny 资产管理如何评估与治理 Claude Fable 5

Balyasny 资产管理（BAM）首席 AI 官 Charlie Flanagan 谈该公司为何使用 Claude Fable 5，以及防护在跨组织安全、可靠地部署前沿智能中所扮演的角色。

Balyasny 资产管理（BAM）是一家全球性、多策略投资公司，管理约 380 亿美元资产，支撑着一支约 2,000 名投资专业人士和员工的团队。首席 AI 官 Charlie Flanagan 与 Anthropic 谈了该公司如何在数千个真实金融任务上评估新模型、为何构建了自己的运行 agent 的平台，以及 Claude Fable 5 的发布带来了什么变化。

## 前沿 AI 在 2026 年为 BAM 带来了怎样的变化？

2026 年是我们从做搜索的 AI 系统，转向做工作的 AI 系统的一年。

关键的变化不只是模型，而是围绕它们的那些 harness，比如 Claude Code。它们让我们构建的 AI 方案能承担远更复杂、运行更长的任务。能给一个 AI 一个成果、而非一个 prompt，并让它一直工作到完成——这种能力是颠覆性的。

一个实际的例子是并购套利分析。当一桩交易被宣布时，agent 现在会构建初步的交易分析包。它们估计交易成交的可能性有多大、要花多久，提取关键的经济和法律条款，识别条件和里程碑，并标记出需要投资人判断的领域。

一年前，那些步骤还零散分布在人工研究和各个独立工具之间；我们没有能可靠地把完整多步骤工作流坚持到一个可用结论的 agent。那项工作过去要三到五天。现在不到一天。agent 运行大约 30 分钟，在任何被依赖的重要输出之前都有人类审阅。

我们使用 Anthropic 的前沿模型，但大部分基础设施是在 BAM 内部构建的，包括执行 harness、数据访问和审阅控制。

## 在开启 Claude Fable 5 之前，你们是如何评估它的？

我们多年前做的一件、一直极其受用的事，是投资于稳健的评测系统。我们用结果可验证的数千个真实金融任务——横跨股票、宏观和大宗商品——来测试新模型，而非依赖通用基准或孤立的演示。它让我们能就模型选择和路由做出数据驱动的决策，我认为所有企业都应当在这上面投入。

我们既测模型本身，也测它在我们 agentic 环境内的表现——用我们用户所用的相同工具、文件和需求。它能否规划工作、选择并使用正确的工具、查找并分析证据、从错误中恢复、检查其中间结果，并产出一份有据可依的交付物？我们也寻找特定的失败模式，如数值错误、覆盖不全、无依据的结论和检索问题。

在相关子集上，Fable 在数千个任务上达到 89.4%，而此前的生产模型为 86.1%。它最出彩的地方是复杂规划、分析和 agentic 执行。

令人惊讶的结果是一组经济学问题——我们测过却从未有任何模型成功完成——直到 Fable。起初我们把这个结果当作一个潜在的评测问题，因为它相对我们测过的每一个模型都代表着一次重大的阶跃变化。我们重跑了评测、独立核查了任务和打分逻辑，并与 Anthropic 一起审阅了结果，最终断定这一改进是真实的。那是一个惊艳的时刻。

如今，我们的投资团队把 Fable 用作其系统化和编码工作的首选前沿模型。我们基于效率和成本，就何时用 Fable、何时用其他模型给他们指导。

## 你们如何看待当今前沿模型的安全性？

我们把安全当作一个产品和运营模式的问题来对待，而不是一次性的模型选择练习。相关的问题不只是模型能做什么，而是它能访问什么数据、能用什么工具、能采取什么动作、什么必须保持人类批准，以及当某件事出错时我们如何得知。

这意味着在模型周围布置控制，而非假设模型本身就是控制。我们使用获批准的数据边界、最小权限访问、工具级权限、日志与可追溯性、对重要输出的人类审阅，以及为边缘情形设置的清晰升级路径。我们在扩大访问之前，也会测试对抗和失败场景。

这些控制是第一天的优先事项，而安全并没有随 Fable 发生根本变化。一个更有能力的模型不会仅因为它能更有效地推理或规划，就获得更广泛的授权。模型只能使用为该用户和该任务批准的工具和数据源，且它们不能给自己授予更多访问权。投资判断和问责仍留在人手中。

## BAMAgent 在何处发挥作用？

展望未来，行进的方向是朝着更有能力的、能承担更长运行、多步骤动作的 agent。这让治理更重要，而非更不重要。对我们而言，那意味着构建 BAMAgent——我们内部用于把 agent 安全部署进获批准企业工作流的平台。它给 agent 所需的工具与系统，但只是那些工具与系统。我们已经构建了六个月，它支撑着数千个自主 agent 全天候 24/7 工作。

BAMAgent 是我们聊天平台之后的下一步。聊天帮助人们接收并综合信息。BAMAgent 则来做工作：能运行数小时或数天的多步骤研究和分析，agent 并行工作，最后以一个人可审阅的东西收尾。它能构建并维护一份公司研究包、为一次财报或宏观事件做准备，或把新证据变成金融情景。agent 规划工作、使用获批准的内部系统、运行分析、检查其中间输出，并返回一份研究产物、模型或决策支持包。

Fable 是我们在规划和分析阶段的首选模型。那里的一个错误会流过随后的每一份交付物，因此我们希望可用的最强模型来决定如何拆解一个问题、哪些证据重要、如何调和相互冲突的信号。这正是让 agent 像一个有能力的同事那样工作的原因。

每家企业都应当制定战略，迈向一种托管 agent 的模型，它允许企业管理和执法，同时为用户把 agent 的效用最大化。

## Claude Fable 5 为 BAM 带来了什么可能？

反响极其正面。归根结底，人们关心的是这项技术能在他们的日常工作中解锁什么。

在一个例子中，一个 BAMAgent 运行了一次税务亏损收割分析。它探查了 90,000 张数据库表，找到了相关的共同基金持仓数据，并构建了自己的加权系统。经我们团队审阅后，其结果比传统方法所能产生的更全面。

另外，我们的首席经济学家配置了一套 agent 工作流，把一项周期性的央行分析从约两天缩减到大约 30 分钟，而经济学家保留了审阅和判断。

Fable 贡献推理、综合和多步骤问题求解。BAM 的 harness 提供工作流设计、获批准的数据和工具访问、检索上下文、权限、监控和人工审阅控制。两者都是产出生产级质量结果所必需的。

## 随着模型日益强大，你们 AI 路线图的下一步是什么？

这是从「人们拥有工具」走向「人们拥有队友」的一年。就像一名队友那样，随着你与 agent 共事、完成更复杂的任务、并开始让它们主动来帮忙，它们会随时间变得更有用。

我们已经有一些团队在运行 300 多个 agent，不断对新数据和新信息做分析。它帮助团队既更快地获得洞察、又不遗漏任何东西。

它也改变了我们提的问题。我们过去构建专家系统、并教人们去自动化他们已经拥有的流程。现在我们问的是：有没有一条通往成果的更好办法。

真正的限制不过是我们自己的想象力。工具、数据和模型如今已到了一个能实实在在工作好几个小时的地步；轮到我们继续重新想象什么是可能的。接下来的 12 个月将会激动人心。
