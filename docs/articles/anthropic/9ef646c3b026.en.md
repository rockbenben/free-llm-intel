- You can now manage the people in your **Claude Enterprise** (claude.ai) organization with the Admin API (see the [Admin API reference](https://platform.claude.com/docs/en/api/beta/organization)), in beta for all Claude Enterprise organizations: list members and look them up by email address, change a member’s role, remove members, send and withdraw invites, manage groups and their membership, and read custom roles. Group and custom-role requests require the `anthropic-beta: ce-user-management-2026-07-13` beta header; member and invite requests take no beta header. An Admin API key with the `read:org_audit` scope can also call every user-management `GET` endpoint. See [User management](https://platform.claude.com/docs/en/manage-claude/user-management).
