# HCLTech 以 Global Premier Partner 身份加入 Claude 合作伙伴网络

Anthropic 正在与 [HCLTech](https://www.hcltech.com/)展开合作，这是一家在全球 60 个国家拥有超过 23 万名员工的科技公司。HCLTech 将通过一个专属的 Anthropic 业务单元和卓越中心，为其客户在 Claude 之上构建 agentic 解决方案；把 Claude 嵌入 HCLSoftware 的产品；并把 Claude 与 Claude Code 集成进 AI Force——它是 HCLTech 用来为客户运营 IT 服务的平台。HCLTech 成为 Claude Partner Network 中的 [Global Premier Partner](https://claude.com/partners)。

HCLTech 为金融服务、制造、生命科学与医疗、科技、半导体、电信与媒体、零售与 CPG、出行与公共服务提供解决方案。在这些环境里，一次失误的代价都很高，每一项变更都需要被审查、记录和批准。这项合作的设计目的，就是把 Claude 放进这类工作中，并配上有针对这些环境设计的控制措施。

## **HCLTech 如何把 Claude 投入使用**

HCLTech 正在三个场景把 Claude 引入自身业务，并且每一个场景都设计了护栏与人工审查。

- **一个专属的 Anthropic 业务单元和卓越中心。** HCLTech 的前沿部署工程师将搭建安全的沙箱环境，让客户在部署之前就能拿自己的系统和数据来测试 Claude。该中心将培训客户的员工队伍，帮助工程团队采用 AI 原生的实践，并建立安全地大规模运行 agents 所需的组织控制。
- **Claude 进入 HCLSoftware 产品。** HCLSoftware 成为 Anthropic 的独立软件供应商（ISV）合作伙伴，并将把 Claude 嵌入网络安全、自动化、业务流程应用和应用开发等领域的部分产品。首批产品是用于端点管理的 HCL BigFix、用于应用安全测试的 HCL AppScan，以及用于数据与分析的 Actian AI analyst。
- **Claude 与 Claude Code 进入 AI Force。** AI Force 是 HCLTech 为其服务的企业交付 IT 支持、代码修复和数字员工服务的方式。Claude 与 Claude Code 进入那个平台时带有策略护栏、异常处理，以及对高影响变更的人工监督。agents 处理常规工作，任何触及客户生产系统的内容都由 HCLTech 的工程师审查并批准。

「很少有科技公司能同时具备全球系统集成商的规模和 ISV 的产品深度，」HCLTech 首席执行官兼董事总经理 C Vijayakumar 说。「这让我们拥有一种难得的优势，能够安全地工程设计并大规模部署 Agentic AI，交付对我们客户最重要的业务成果。我们与 Anthropic 的合作进一步强化了我们达成这一目标的能力。」

「AI 只有值得信赖才有用处，而我们构建 Claude，是为了让企业有信心把它带入自己最敏感、最有价值的工作，」Anthropic 联合创始人兼总裁 Daniela Amodei 说。「HCLTech 为银行、医院、电信公司和制造商管理这类系统，我们很高兴与他们合作，支持他们集成 Claude 和 Claude Code。这项合作——以及我们更广泛的、同步推进能力与安全的承诺——正是 AI 让整个行业的运转方式变得更好的途径。」

要了解关于与 Anthropic 合作伙伴合作的更多信息，请访问 [Claude Partner Network](https://claude.com/partners)。
