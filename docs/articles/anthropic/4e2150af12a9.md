Anthropic 正在与 [HCLTech（在新选项卡中打开）](https://www.hcltech.com/) 合作，这是一家在 60 个国家/地区拥有超过 230,000 名员工的全球科技公司。 HCLTech 将通过专门的人类业务部门和卓越中心为客户构建 Claude 代理解决方案，将 Claude 嵌入 HCLSoftware 产品中，并将 Claude 和 Claude Code 集成到 AI Force（该平台用于为客户运行 IT 服务）中。 HCLTech 成为 Claude 合作伙伴网络中的[全球首要合作伙伴（在新选项卡中打开）](https://claude.com/partners)。

HCLTech 为金融服务、制造、生命科学和医疗保健、技术、半导体、电信和媒体、零售和消费品、以及移动和公共服务提供解决方案。在这些环境中，错误的代价是昂贵的，并且每项更改都需要经过审查、记录和批准。此次合作的目的是让 Claude 参与针对这些环境设计的控件的工作。

## **HCLTech 如何让 Claude 投入工作**

HCLTech 正在将 Claude 引入其在三个地方的业务，并在每个地方设计护栏和人工审核。

- **专门的人类业务部门和卓越中心。** HCLTech 的前沿部署工程师将建立安全的沙箱环境，客户可以在部署之前针对自己的系统和数据测试 Claude。该中心将培训客户员工，帮助工程团队采用人工智能原生实践，并建立组织控制以大规模安全运行代理。
- **Claude 在 HCLSoftware 产品中。** HCLSoftware 成为 Anthropic 独立软件供应商 (ISV) 合作伙伴，并将把 Claude 嵌入网络安全、自动化、业务流程应用程序和应用程序开发的精选产品中。第一个是用于端点管理的 HCL BigFix、用于应用程序安全测试的 HCL AppScan 以及用于数据和分析的 Actian AI 分析师。
- **AI Force 中的 Claude 和 Claude Code。** AI Force 是 HCLTech 为其服务的企业提供 IT 支持、代码修复和数字员工服务的方式。 Claude 和 Claude Code 进入该平台，提供政策护栏、异常处理和对高影响力变更的人工监督。代理负责处理日常工作，HCLTech 工程师负责审查和批准任何涉及客户生产系统的事情。

“很少有科技公司能够将全球系统集成商的规模与 ISV 的产品深度结合起来，”HCLTech 首席执行官兼董事总经理 C Vijayakumar 说道。 “这为我们提供了难得的优势，可以安全地大规模设计和部署 Agentic AI，并交付对我们的客户最重要的业务成果。我们与 Anthropic 的合作进一步增强了我们实现这一目标的能力。”

Anthropic 联合创始人兼总裁 Daniela Amodei 表示：“人工智能只有值得信赖才能发挥作用，我们打造 Claude 是为了让公司有信心将其运用到最敏感和最有价值的工作中。” “HCLTech 为银行、医院、电信公司和制造商管理此类系统，我们很高兴与他们合作，帮助他们集成 Claude 和 Claude Code。这种合作伙伴关系以及我们对共同提高能力和安全性的更广泛承诺，是人工智能将如何改变整个行业的运行方式，使其变得更好。”

要了解有关与 Anthropic 合作伙伴合作的更多信息，请访问 [Claude 合作伙伴网络（在新选项卡中打开）](https://claude.com/partners)。
