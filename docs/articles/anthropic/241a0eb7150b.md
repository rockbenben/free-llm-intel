今天，我们正在新加坡开设新办事处（我们在该地区的第五个办事处），并与新加坡数字发展和信息部签署谅解备忘录 (MOU)，从而扩大我们在亚太地区的业务。新加坡是我们在世界上最活跃的市场之一，Claude 已经为数百万人每天使用的新加坡商业和政府服务提供支持，例如 GovTech Singapore、Grab 和 DBS。我们不断壮大的本地团队将确保这些组织和更多组织始终走在安全、强大的人工智能前沿。

Anthropic 东盟总经理 Dale Finlay 表示：“我们长期致力于新加坡。” “我们的客户对人工智能有着极高的标准，特别是在可靠性和安全性方面。拥有一支实地团队意味着我们可以更接近让 Claude 解决最棘手问题的组织。”

### 支持新加坡负责任的人工智能

数字发展和信息部常务秘书 Kai Fong Chng 与 Anthropic 联合创始人 Ben Mann 在新加坡国际网络周期间签署了谅解备忘录。数字发展和信息部长 Josephine Teo 和亚太政策人类学主管 Michael Sellitto 见证了签字仪式。确定了人工智能安全、安保和模型评估方面的合作领域；研究人工智能的采用及其影响；以及公共和私营部门负责任的采用。

曼恩表示：“新加坡一直是负责任的人工智能领域的领导者，在模型测试和评估方面拥有长期的投资记录。” “我们创立 Anthropic 的信念是，能力和安全必须齐头并进。通过这份谅解备忘录，我们将与新加坡合作，帮助确保这里、整个亚太地区和世界各地顺利向强大的人工智能过渡。”

Chng 表示：“新加坡的人工智能方针始终是在推动创新的同时应对不断变化的风险。信任对于企业、工人和公众充满信心地使用人工智能至关重要。” “与 Anthropic 的合作反映了政府致力于扩大人工智能的负责任应用、深化我们公司和政府机构的能力以及为新加坡带来影响。”

我们与新加坡的合作可以追溯到 2023 年，当时我们加入了由 Infocomm 媒体发展局和 AI 验证基金会运营的[生成式 AI 评估沙盒](https://www.imda.gov.sg/resources/press-releases-factsheets-and-speeches/press-releases/2023/generative-ai-evaluation-sandbox)。后来我们与他们合作开展了英语、普通话、马来语和泰米尔语的[红队项目](https://www.anthropic.com/news/challenges-in-red-teaming-ai-systems)。

根据谅解备忘录，我们计划与新加坡人工智能安全保障机构就模型评估、测试标准和事件响应等方面进行技术交流。我们与世界各地的安全机构开展类似的工作，共享技术信息可以让政府更清晰地了解前沿人工智能的能力和风险，同时帮助开发人员构建更安全的模型。

我们还将寻找加强新加坡人工智能技能的方法，帮助中小企业负责任地采用人工智能，并支持政府在公职人员中建立人工智能能力的目标。我们计划与政府分享研究和数据，包括来自[人类经济指数](https://www.anthropic.com/economic-index#global-usage)的研究和数据，并在新加坡制定人工智能规则时提供技术和政策专业知识。

### 新加坡如何与克劳德合作

在我们最新的[经济指数](https://www.anthropic.com/economic-index#country-usage)中，新加坡的 Claude.ai 使用率（相对于其人口）在 121 个国家中排名第二，几乎是其规模预测的六倍。

在公共部门，新加坡政府科技局 (GovTech Singapore) 的 1,500 多名工程师和技术人员采用了 Claude Code 来实现政府系统现代化并加快软件交付速度。这帮助新加坡政府科技团队在全国范围内更有效地构建、维护和增强数字服务。新加坡网络安全局正在探索克劳德如何帮助加强该国的网络防御。

在金融服务领域，东南亚最大的银行星展银行与克劳德在其新加坡业务的一系列用例中进行合作，包括软件开发和日常生产力，作为其更广泛的人工智能创新努力的一部分。这些应用程序在银行严格的安全和治理框架内运行。新加坡主权财富基金 GIC 正在其投资和企业服务团队中引入 Claude。金融服务等受监管行业的组织现在可以在 Amazon Bedrock 上使用区域内推理运行 Claude，帮助他们满足严格的数据处理要求。

新加坡最大的科技公司和初创公司也与克劳德一起建设。 Grab 与 Claude 一起为其销售助理 BriX 提供支持。该助理每个季度为 Grab 的销售团队节省了大约 40,000 个小时的时间，并带来了新的销售机会。 Sea（Shopee、Garena 和 Monee 背后的公司）与 Claude 合作，帮助 Shopee 的客户服务聊天机器人更快、更准确地做出响应，数千名员工与 Claude 一起编写和调试代码。 Supabase——扎根于新加坡的开发者平台——正在使用 Claude Code 进行构建。

### 与开发者社区一起构建

本周，Anthropic 的高级领导将在新加坡开设办事处，并与客户、开发商和政策制定者会面。

今天，我们在新加坡举办了 Builder Summit，汇聚了 300 多名开发人员以及 Anthropic 的工程和产品领导者。本周早些时候，新加坡 Claude 社区大使为 700 多名当地建筑商举办了一次聚会。

我们的新加坡办事处现已开放并正在招聘。要了解有关加入团队的更多信息，请访问我们的[职业页面](https://www.anthropic.com/careers/jobs?office=4063231008)。
