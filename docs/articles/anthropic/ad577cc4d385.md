# 为 2026 年美国中期选举做准备

今年早些时候，我们分享过一篇[关于选举保障措施更新的说明](https://www.anthropic.com/news/election-safeguards-update)，介绍了我们如何衡量并防止政治偏见、如何识别滥用行为，以及如何把人们引导到准确的投票信息。

下文我们将说明在那些工作之上又做了些什么，以及在今年美国中期选举到来之前如何持续加强我们的选举保障措施。

### 人们如何在选举与政治议题中使用 Claude

我们的目标是让 Claude 成为讨论政治时有用的工具，同时防止与选举相关的滥用。这始于理解人们在这类场景下实际如何使用 Claude。为此，我们用 Anthropic Insights 完成了一项新分析，覆盖最近一周内的 250,000 条对话。[1](https://www.anthropic.com/news/2026-us-midterms#footnote-1)

如今，在美国的 Claude.ai（我们的消费级应用）上，广泛涉及政治、公共政策或社会议题的对话约占全部对话的 5.75%。这包括请 Claude 帮忙跟进新闻、就公共政策做学术或专业研究、了解候选人，以及办理政府服务事务。专门关于选举或投票的对话约占全部对话的 0.51%。随着投票日临近，我们预计政治与选举相关提问的占比会[上升](https://www.anthropic.com/news/elections-ai-2024)。

这一样本显示，人们很少直接问 Claude 该投谁或该投什么。这类请求在美国的 Claude 对话中约占 0.01%。更常见的情况是，人们向 Claude 提出那些能帮助他们自己得出结论的问题，比如候选人在某个具体议题上的立场。违反我们[选举诚信政策](https://www.anthropic.com/legal/aup)的请求更为少见，只出现在约 0.002% 的对话中。[2](https://www.anthropic.com/news/2026-us-midterms#footnote-2)

**有多少美国 Claude.ai 对话涉及政治、关于选举，或询问 Claude 该投谁该投什么。** 每个圆点代表每 10,000 条对话中的 1 条；样本是从 2026 年 9 月 21 日至 27 日的美国 Claude.ai 消费级对话中随机抽取的约 250,000 条，由 Claude 用[一种保护隐私的方法](https://www.anthropic.com/research/clio)完成分类。由于请 Claude 推荐该投谁或该投什么的请求极为罕见，我们对这一组展示的是 95% 置信区间的上限。示例仅用于说明。我们见到的大多数请求在性质上都是获取信息。人们请 Claude 帮忙理解地缘政治事件、调研候选人、起草文件、辅助课业，以及权衡支持或反对某项政策的论据。

**人们在政治对话中会请 Claude 做什么。 **对话通过 [Anthropic Insights](https://www.anthropic.com/research/clio) 以保护隐私、自下而上的方式做了聚类。

## **把人们连接到可靠的信息来源**

在投票日之前，我们新增了两种方式，让人们在与 Claude 的对话中就能直接获得可靠信息。正如我们 4 月所分享的，当人们向 Claude.ai 询问选民登记、投票站点或选举日期时，我们会继续展示一条横幅，链接到 TurboVote——这是 [Democracy Works](https://www.democracy.works/) 提供的无党派资源。

本月晚些时候，Claude 会开始把来自 Democracy Works 的官方投票信息引入面向美国用户的 Claude.ai 回答中。有人询问去哪里投票、去投票站要带什么身份证件时，现在不用离开对话就能得到针对其所在州的具体答案。这些回答依据的是 Democracy Works 从州和地方选举信息源收集的公开信息。

由 Democracy Works 呈现的官方投票信息。

此外，Claude 将从选举之夜及其后的几天开始展示最新结果，这样当人们询问当前票数或选举结果时，就能在对话中直接看到最新的官方数字。

## **衡量并防止政治偏见**

人们向 Claude 询问政治时，应该得到准确、公允、不偏向任何特定政治立场的回答。这就是我们在每次模型发布前都就政治偏见对模型做大量测试的原因。Claude Opus 5.5、Sonnet 5.5 和 Haiku 5.5 是我们迄今最公允的一代，在[政治公允性评估](https://www.anthropic.com/news/political-even-handedness)中得到 99% 的分数。我们最新的模型也更愿意参与政治讨论、拒绝更少的请求，让人们能拿到自己想了解的信息。我们会继续完善这些评估，也在评估之外寻找新的方式，对我们模型处理政治议题的做法做压力测试。

作为这项工作的一部分，我们请三家独立机构审视 Claude 如何处理表达自由，它们各从不同角度、使用不同方法论。[The Future of Free Speech](https://futurefreespeech.org/) 是范德堡大学的一家独立智库，它用数百条涉及争议议题的请求测试了 Claude；[Foundation for American Innovation](https://www.thefai.org/) 则比较了 Claude 对来自左派与右派的成对 prompt 的回答，范围从主流政策辩论到更极端的场景。在这两项评估中，大多数回答都被评为表现很强，实质性地回应了请求。[Collective Intelligence Project](https://www.cip.org/) 在开发一项评估时调查了美国、英国和印度的 2,000 多人。通过一个三阶段流程，参与者提出了处理敏感议题的原则（范围从健康到政治），确定了要测试的话题，并帮助制定了评判模型回答的标准。CIP 汇总了这些输入，并检验不同人群群体与文化群体之间的一致性，以确立共同原则。

这些评估也找出了 Claude 仍然做得不到位的方面。The Future of Free Speech 和 Collective Intelligence Project 都发现，Claude 很少拒绝请求，但有时会加上没人要求的保留意见和反面论证，比如在一封倡导性邮件里插入相反的观点。而 Foundation for American Innovation 发现，Claude Sonnet 4.5 并不总是均衡地做缓和表达，更倾向于弱化右倾立场的论点。

我们正在用几种方式处理这一点。我们改进了 Claude 对直接的是非题式提问和要求简短回答的请求的回应方式，因为我们发现这类情形下它的回答可能不够均衡。我们也用这些发现来改进 Claude 何时以及如何添加保留意见或反面论证，让它对来自政治光谱各方的请求处理得更一致。同时我们持续改进对不均衡缓和表达的测试，在此前使用左右两翼成对 prompt 的评估基础上继续推进。更 broadly 地说，我们正在扩大政治偏见评估的范围，让它更好地反映真实对话，并覆盖候选人与投票类问题，而不只是政策议题。

## **我们如何定义滥用**

我们的 [Usage Policy](https://www.anthropic.com/legal/aup) 禁止用 Claude 欺骗选民或扰乱选举，从散布关于候选人或投票方式的虚假信息，到冒充选举官员、试图压制投票率，都在其列。我们每年更新这项政策，以反映模型能力的演进和客户给出的反馈。今年的更新我们上周已经[公布](https://www.anthropic.com/news/2026-usage-policy-update)，它明确了我们的选举规则覆盖什么、不覆盖什么，并加入了新的示例，帮助人们理解界线落在哪里。

我们知道许多竞选团队会把 Claude 用在正当的日常事务上，所以我们最近[发布了一份指南](https://www-cdn.anthropic.com/files/4zrzovbb/website/027b10ca405e9bb66b98c88d911b4b21a0b70123.pdf)，帮助他们理解这些政策适用于何处。指南涵盖了竞选团队能让 Claude 承担的多种工作，例如起草新闻稿和筹款邮件、为辩论做准备、分析投票率数据、制作选民外联材料。它也写明了哪些是被禁止的，例如用 Claude 创建冒充真实人物的虚假社交媒体资料、批量生产评论以抬高竞选活动的互动量，或为谎称独立的新闻网站和页面撰写内容。

### 测试并加固我们的防线

我们部署了经过训练、用于识别选举相关滥用的自动分类器。为了看清这些保障措施在实践中的表现，我们与 [Institute for Strategic Dialogue](https://www.isdglobal.org/)（ISD）和 [McCain Institute](https://www.mccaininstitute.org/) 这两家独立研究机构合作，在美国、以色列和巴西对我们的防护做了压力测试。分析师们测试 Claude 是否会协助欺骗性竞选、误导信息以及其他形式的选举滥用。他们先从直接的请求开始，然后把完整的竞选活动拆成单独看可能无害的更小块任务，例如受众研究、搭建新闻网站、起草内容，以及规划内容的分发。他们发现，对于单条有害请求 Claude 能够可靠地拒绝，但当一场恶意行动被分散到许多单独看无害的请求中时，它可能漏判。

在这些发现以及我们自己的发现基础上，我们新增了分类器，以更好地识别新型和多步骤的滥用，包括搭建针对政治讨论的虚假社交媒体账号与新闻网站的企图，或运行以牟利为目的的选举套路。我们还提升了对境外国家行为体造成的选举相关滥用的检测能力，并加强了对选举基础设施和竞选活动的网络防护。最后，我们针对在美国、以色列和巴西识别出的本地化风险构建了有针对性的保障措施，这三个国家今年都有重要的全国性选举。

我们的威胁情报团队和执行团队会审查被标记的活动，一旦确认违规就采取行动，包括封禁账号。我们也会定期分享在评估以及内部使用 Claude 的过程中观察到的非预期模型动作或行为[示例](https://www.anthropic.com/research/investigating-unintended-model-actions)。

### 我们已经发现的问题

我们最近的[威胁情报报告](https://www.anthropic.com/threat-intelligence-report-september-2026)反映出选举相关滥用趋势的更广泛变化。政治类、与国家立场一致的以及商业类的行为体，如今正把 AI 纳入其影响行动的几乎每一个环节，从策划和内容生产，到搭建用于传播信息的平台。因为我们能在 Claude 上看到这些行动早期阶段发生的事情，所以往往有机会在它们触及公众之前就把这些企图拦下。

我们的团队持续调查并阻止围绕选举（包括美国中期选举）的协同滥用。在一个案例中，一个总部位于境外的假新闻网站运营者用 Claude 产出偏向俄罗斯、伊朗和朝鲜叙事的美国中期选举报道。我们还观察到一些威胁行为体试图利用选举牟取经济利益，用 Claude 制造虚假新闻和其他内容，以吸引美国受众并赚取广告收入。我们封禁了这些案例中涉及的账号，并提升了检测此类滥用的能力。

### 展望未来

比以往任何时候都多的人正在向 Claude 询问有关今年选举的信息。我们有责任确保他们得到的回答准确而平衡，也确保 Claude 不被用来破坏民主进程。我们会持续投入，让 Claude 更加公允，预防和处置滥用，并让我们的行动保持透明。这些工作在即将到来的美国中期选举中至关重要，也同样延伸到世界各地的选举。接下来几个月，我们还希望分享一份更完整的观察，说明人们在本次选举周期中如何使用 Claude，目标是加强我们与选举相关的评估和保障措施。
