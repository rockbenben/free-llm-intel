[Claude Duet（在新选项卡中打开）](https://claude.com/resources/articles/claude-duet) 是一种代理，目前处于研究预览阶段，它使用基于云的计算机为您工作。它可以使用您选择连接到 Claude 的所有应用程序和服务，并且即使在您关闭应用程序后它也会持续运行。当您不在时，它可以读取您的收件箱、起草回复、预订内容以及运行例程。我们的团队在自己的帐户上运行 Claude Duet，我们每天都用它来工作。

我们根据三个原则构建 Claude Duet 来指导代理的行为：

- 您的信息以及其他人在您连接的应用程序中共享的信息均会谨慎处理，使用新的分类器在消息发出前检查 Claude Duet 草稿。
- 您可以控制它代表您做什么。
- Claude Duet 永远不会看到您的密码、浏览器 cookie、登录令牌或其他凭据。

Claude Duet 是新的，但其背后的想法却不是。 2025 年，我们[发布了安全可信代理框架（在新选项卡中打开）](https://www.anthropic.com/news/our-framework-for-developing-safe-and-trustworthy-agents)，该框架让人们处于控制之中，并将隐私和安全交互视为基本要求。从那时起，我们已经写了为什么[没有单一的防御是足够的（在新选项卡中打开）](https://www.anthropic.com/research/trustworthy-agents)以及为什么[模型内部的保护不能独立（在新选项卡中打开）](https://www.anthropic.com/engineering/how-we-contain-claude)。我们还通过 [Claude Managed Agents（在新选项卡中打开）](https://www.anthropic.com/engineering/managed-agents) 构建和运营企业用于在生产中运行代理的基础设施，并且 Claude Duet 以相同的方式将凭证与代理分开。它建立在这项工作的基础上，添加了代表您的代理所需的保护。这篇文章将介绍我们添加的内容以及仍在研究的内容。

## 您批准重要行动

在您离开时执行操作的代理必须知道何时停止并在继续操作之前请求许可，并以正确的节奏执行操作。在 Claude Duet 执行某些操作（例如发送潜在敏感消息、付费或删除任何内容）之前，它会向您显示操作、目的地和内容，包括每个收件人。然后等待您批准该操作。

每个操作都会运行一个单独的自动检查，该检查基于 [Claude Code 的自动模式分类器（在新选项卡中打开）](https://www.anthropic.com/engineering/claude-code-auto-mode) 并针对 Claude Duet 进行了扩展。它评估该操作是否符合您的意图。检查在执行工作的模型外部运行，因此隐藏在页面中的指令不会影响结果。

即使经过您的批准，某些操作仍然是禁止的，例如交易证券、银行操作（例如在帐户之间转移资金以及访问其他人的帐户）。 “不要再问我”规则不涵盖其他一些步骤，无论您批准这些步骤的频率如何，例如付款或汇款、删除订单或创建帐户。当您离开时运行的例程具有相同的保护措施。

我们花了很多时间来校准 Claude Duet 请求批准的频率。批准疲劳是一个严重的问题，因为太多的请求教会人们去利用它们，有时甚至没有经过充分的考虑。我们将随着时间的推移继续调整此校准。

对于购买，Claude Duet 使用来自 Stripe 的 Link 等钱包的一次性卡进行支付，仅限于该商家和金额。您可以看到商品和总额，并在 Link 应用程序中批准购买。您的真实卡号不会与 Claude Duet 或商家共享。

## 您的信息将被谨慎处理

读取您的电子邮件并为您发送消息的代理不断地决定不同类型的信息应该发送到哪里。如果你要求 Claude Duet 向你的团队发送每周回顾，它应该只包含团队中每个人都可以访问的内容，而不是私人详细信息，例如你的绩效评估对话。

为了解决这个问题，我们构建了一个新的安全分类器，它与主模型分开运行，并检查 Claude Duet 将要发送的每条消息是否包含潜在的敏感信息。我们将这些信息分为两层：

- **绝不共享：**我们对登录凭据、完整卡号和银行帐号以及政府身份证号等信息提供最敏感的保护。Claude·杜埃 (Claude Duet) 被指示永远不要与任何人分享这些内容，即使你要求。
- **需要同意才能分享：**只有在您明确批准的情况下，Claude Duet 才会分享其他私人信息，例如健康或财务状况。您自己的请求视为同意，因此“向我的牙医发送有关我的牙痛的便条”通常不需要额外的批准。

图 2. 您的信息可以去往何处：在发送任何内容之前，都会检查信息的敏感程度以及您是否已同意。

如果 Claude Duet 由于任一原因被阻止，它可以决定重写消息而不包含敏感信息并与您共享以供批准。

Claude Duet 仍处于研究预览阶段，这些保护措施偶尔会错过某些内容或标记无害的消息。这就是为什么它们与上述审批机制一起工作，这些机制旨在让您控制 Claude Duet 代表您发送的内容。随着我们更多地了解人们如何使用 Claude Duet，我们希望继续迭代我们的分类器。

## 您可以查看任务和连接的应用程序

您可以在其任务列表中查看 Claude Duet 已完成和正在执行的操作，其中每个任务都有自己的页面，并在任务中进行引导。 Claude Duet 会保留您的对话历史记录及其记忆，以便它可以在任务之间传递上下文，直到您删除历史记录或重置它。删除您的帐户会擦除 Claude Duet 存储的所有内容。

![Claude Duet 任务列表的屏幕截图](https://assets.claude.com/2ea9a7ae6dfe5a96c7e3e0fb759df5a0703704b1.png)

您连接到 Claude 的应用程序会继承到 Claude Duet，在一个地方关闭应用程序会同时在两个地方关闭该应用程序。断开应用程序的连接会从那一刻起停止新的访问，但 Claude Duet 从中学到的内容会保留下来，直到您重置其内存为止，您可以随时通过应用程序的设置进行重置。 Claude Duet 还使用您 Claude 帐户中的内存，因此 Claude 从您之前的聊天中记住的详细信息是可见的。

## 凭证和浏览器与模型隔离

Claude Duet 永远不会看到您的密码、浏览器 cookie 或连接的应用程序的登录令牌，也无法将它们保存到内存中。它们只通过模型无法访问的单独机器，以及控制模型在那里运行的内容的批准和安全检查。

**密码**

当网站要求输入密码时，您可以将其输入 Claude 应用程序内的表单中。该表单使用一次性密钥对其进行加密，该密钥仅存在于我们的安全云浏览器计算机上，仅供一次性使用。它将未打开的加密密码传递给浏览器，浏览器将其输入到站点中。模型看不到密码，无法保存或重复密码。很快您也可以使用 1Password 登录； Claude Duet 将要求提供凭据，您将在 1Password 中批准该请求，并且凭据将在不通过模型的情况下发送到浏览器。

为您登录的代理可以通过两种方式改变网络钓鱼。一方面，Claude Duet 不持有您的凭据，因此无法通过网络钓鱼获取密码，并且没有任何隐藏指令可以使其泄露其不具备的秘密。另一方面，登录表单本身就是一个目标，因为任何要求密码的内容都可以被模仿。因此，Claude Duet 的登录表单仅在您要求登录时出现在应用程序内。它绝不会以链接、短信、电子邮件或 claude.ai 以外的网站形式到达。如果类似 Claude Duet 的东西在其他地方要求您提供密码，那么它是不合法的。

**登录令牌**

当 Claude Duet 在连接的应用程序中工作时，它遵循 [我们的 Claude Managed Agents 设计（在新选项卡中打开）](https://www.anthropic.com/engineering/managed-agents)，因此凭据不会影响代理的工作。代理代表您使用的凭据（例如连接服务的登录令牌）永远不会进入代理工作的计算机。凭证的占位符位于此处，并且该机器外部的代理仅在发出请求时才输入实际值。

**浏览器**

Claude Duet 中的浏览器在云中其自己的专用虚拟机中运行，与模型和代理工作的云计算机分开。代理仅通过一组固定的命令驱动浏览器：*打开此页面，单击此处，键入此*。无论站点运行什么[都保留在浏览器计算机上（在新选项卡中打开）](https://www.anthropic.com/engineering/driven-agents)。该网站的代码和 cookie 不会到达 Claude Duet 的内存或您连接的应用程序，并且代理的任何命令都无法从浏览器中读取 cookie。返回的是页面的文本和下载内容，因为代理必须读取它们才能完成工作。这就是为什么存在其他检查，以及为什么 Claude Duet 还使用我们的[浏览器使用研究（在新选项卡中打开）](https://www.anthropic.com/research/prompt-injection-defenses)中描述的提示注入保护措施。它通过浏览器上传的文件会得到与其消息相同的敏感信息检查。

图 3. 浏览器边界：固定命令穿过，页面文本返回，站点代码、cookie 和下载内容保留在浏览器计算机上。

Claude Duet 也被设计为将自己定位为代理。如今，其 Web 浏览器发送的请求包含一个独特的 User-Agent 标头，并且我们发布其浏览的公共 IP 地址，以便网站可以识别它并决定如何处理它。在发布之前，我们还联系了几个大型网站，并为他们提供了阻止 Claude Duet 访问其网站的选项，有些网站选择了这样做。当我们从研究预览中了解到时，我们将不断完善 Claude Duet 如何识别自己。

图 4. 凭证路径：密码在您的手机上加密，仅在浏览器计算机上打开，并且永远不会通过模型。

## 我们如何测试 Claude Duet

测试早在研究预览之前就开始了，现在仍在继续。我们的保障团队根据常规任务构建了评估，每个任务都有三种变体：一种是无害的版本，一种是注入指令的版本，另一种是诱使代理做超出要求的事情的版本。这些与实际使用的影子流量一起运行。

红队进一步测试了Claude Duet是否会泄露信息、未经批准采取行动或遵循恶意提示。我们构建了整个系统的威胁模型，跨越其所触及的存储库和信任边界。一家外部渗透测试公司测试了 Claude Duet 是否可以访问我们的源代码，并且涵盖云浏览器和登录表单的后续活动正在运行。每个新的凭证功能在交付给任何人之前都会在一个隔离的设备上进行红队测试。

Claude Duet 也属于 Anthropic 的公共错误赏金计划的范围，该计划根据我们负责任的披露政策奖励有效报告并为善意研究提供安全港。如果您发现安全漏洞，我们希望了解它：通过 [HackerOne（在新选项卡中打开）](https://hackerone.com/anthropic) 上的 Anthropic 错误赏金计划进行报告。

## 与你一起构建这个

我们将 Claude Duet 作为研究预览版发布，因为我们想了解您对个人代理的重视程度，包括您接下来希望看到的保护和控制。这里描述的一些内容仍在变化：请求批准的频率、登录方式以及敏感信息检查区分隐私和无害的程度。用简单的语言告诉 Claude Duet 您希望看到什么或出了什么问题，它将为我们的团队提交一份报告。
