# 介绍 Anthropic Cyber Mission

今天我们启动 Anthropic Cyber Mission，这是一项长期承诺，致力于保护所有人都依赖的系统。Cyber Mission 是一项全新行动，用工具、研究与资源支持防御者，帮助他们保障自己的软件与系统安全。我们从两个领域起步：

- **关键基础设施：**从保障电网、水务系统与交通网络背后的运营技术起步，并保护政府系统。今天我们推出 Critical Infrastructure Defense Program（CIDP），把前沿模型、驻场工程师与威胁研究带给守护运营技术的防御者。
- **开源软件：**在大多数软件都依赖的那些免费、共享的代码中寻找漏洞并给出补丁建议，加固底层代码。今天我们上线 [OSS Scanner](http://anthropic.com/research/launching-opt-in-vuln-finding-service-for-open-source)，用我们最强的模型为开源项目提供免费定期安全扫描。

前沿模型可能被滥用于利用漏洞、实施网络行动。尽管各方尽最大努力，技术领域的许多环节仍处于危险的暴露状态。国家支持的对手多年来已在众多行业的这些系统中建立立足点，以便随时打断它们。关键基础设施的防御者与 OSS 社区拥有几十年的安全经验，却长期面临严重的资源短缺，而当下这一时点更让短缺雪上加霜。我们承认他们在这些领域的专业能力，并提供我们的支持。我们还会扩展 Cyber Mission，在新领域释出工具、研究与资源，帮助让世界更安全。

作为 [Project Glasswing](https://www.anthropic.com/glasswing) 的一部分，合作方发现了许多漏洞，但我们还没有把网络风险降到足够低的程度。发现漏洞比以往任何时候都容易，但核实、排定优先级并修复这些发现仍然充满挑战。基于 Project Glasswing 的经验，我们启动这些新行动来支持防御者。本周早些时候，我们把 Project Glasswing 并入已经扩容的 [Cyber Verification Program](https://www.anthropic.com/news/cyber-verification-program)，让更多防御者能用上我们最强的模型。而通过 Anthropic Cyber Mission，我们将投入 Anthropic 的工程人才，并为守护关键基础设施与开源软件的人提供工具和资金。

## 守护关键基础设施

电网、水务、工厂与交通网络都运行在控制器、控制软件和工业网络之上，而这些东西的设计寿命长达几十年。这类系统被称为「运营技术」（operational technology），它们通常无法停机打补丁，因此已知漏洞可能多年悬而未决。保障它们的安全是高度专门化的工作：设备是专有的，改动有风险，一个失误就可能让一座工厂停摆。各种规模的运营商都依赖少数几家可信赖的供应商来支撑这项工作，由它们告知哪些东西暴露在外、在不停机的运行系统上该做哪些修复。

今天我们推出 **Critical Infrastructure Defense Program**，把前沿的 Claude 模型、驻场工程师和我们的威胁研究带到这些可信赖的供应商面前。其创始合作方为 Accenture、Booz Allen、CrowdStrike、Deloitte、Dragos、Hitachi、Insane Cyber、Nozomi Networks、Palo Alto Networks、PwC 与 Rockwell Automation。

这些机构正是运营商为守护这些系统所依赖的供应商群体：开展安全项目的咨询与先进科技公司，守卫业务网络与工业网络的安全公司，以及制造设备并为设备打补丁的制造商。

这项工作已经在进行。多家合作方目前正借助 Claude 修复漏洞，并帮助客户做同样的事。关键基础设施难以防守的地方有很多是 AI 修不好的，但我们相信前沿模型能够赶在弱点被用来切断电力或让水变得不安全之前，先把它们找出来并修好。我们的第一步是与一小批供应商合作，弄清哪些策略最有效、也最可行。

今年 6 月，我们面向州、地方、部落及属地政府[启动了一项网络防御计划](https://statescoop.com/anthropic-launches-15m-cyber-defense-program-for-state-local-tribal-and-territorial-governments/)。此后，我们已经为超过半数的美国州以及国内一些最大的公共关键基础设施运营商提供了前沿 Claude 模型与技术支持，加快了代码扫描与打补丁、事件响应、红队演练以及其他安全工作流。

我们在倾听并向最了解这一领域的人学习。我们的做法是与那些熟悉这一领域、且被运营商信任的公司、联盟、政府和非营利组织合作，把支持给到最需要的地方。

## 保障开源软件安全

几乎所有软件都依赖开源代码，其中大量代码由少数志愿者组成的小团队维护。在 Project Glasswing 之下，我们扫描了数百个被广泛使用的开源项目，由人工对发现的许多潜在漏洞做分诊与复核，并通过我们的[ 协调式漏洞披露流程](https://red.anthropic.com/2026/cvd/)把发现的问题私下报告给它们的维护者。

一些具备大规模分诊能力的维护者向我们要取了我们的模型在他们项目中发现的全部内容，无论是否经过复核。作为回应，我们上线 [OSS Scanner](https://red.anthropic.com/oss-scanner)，一项受 [Google's OSS-Fuzz](https://github.com/google/oss-fuzz) 启发、需选择加入的服务。加入的项目会定期由我们最强的模型进行扫描，完全免费。每份报告都包含这个 bug 可如何被利用的概念验证、一段解释，以及在有方案时的修复建议。报告由模型生成、不经人工复核就直接发出。这意味着维护者能更快收到它们，但同时也意味着其中一些会有不准确之处，比如错误的严重程度评级。我们预计真阳性率高于 90%，并会随时间不断努力提高真阳性率与修复质量。[该团队的帖子](http://anthropic.com/research/launching-opt-in-vuln-finding-service-for-open-source)说明了它如何运作、如何加入。

这项服务面向有能力跟进浮现出来的这些发现的项目。对其余项目，我们会继续按我们的 CVD 政策分享经人工核实的披露。

OSS Scanner 只是第一步。从这里出发，我们的开源工作有以下目标：

- **更快地把发现送到维护者手上。**把 OSS Scanner 推向更多项目，同时为需要的项目保留经人工核实的披露。
- **加快修复。**为愿意尝试的项目把分诊和打补丁自动化——这两项目前仍主要靠人工。
- **探索新的安全架构与编码实践。**与那些不满足于只打补丁的项目一起研究并分享加固或重写代码的方法。

我们会依据开源维护者与基金会的指引来做这些事，并分享行之有效的做法，让其他项目能够复制。我们为广泛使用的开源代码背后的机构提供了资金，包括 Python Software Foundation、通过 Linux Foundation 的 Alpha-Omega 与 OpenSSF，以及 Apache Software Foundation；同时也支持 Akrites 和 Gold Eagle——它们汇集并协调来自多个来源的漏洞报告，以免维护者被淹没。我们在 8 月[推出的 Defender Advantage Fund（0xDAF）](https://claude.com/resources/articles/bringing-claude-mythos-5-to-more-defenders)为这些领域的试点计划提供支持，并让 OSS Scanner 保持免费。

维护者还可以向 [Claude for Open Source](https://claude.com/contact-sales/claude-for-oss) 申请免费的 Claude Max 订阅，以及向 [Cyber Verification Program](https://portal.anthropic.com/login) 申请，为防御性工作获取更大范围使用 Claude 网络能力的权限。

## 我们为什么做这件事

网络能力很强的 AI 模型如今已被攻击者广泛可得。但防御工具——包括我们自己的——还没有送达足够多需要它们的防御者手中。[OSS Scanner](https://red.anthropic.com/oss-scanner)、我们的 [Cyber Verification Program](https://portal.anthropic.com/login)、合作方在我们平台上构建的防御产品，以及 [Claude Security](https://claude.com/product/claude-security) 是我们在这方面的一部分努力，我们会尽快加上其他手段。

我们的预测是，两年之后 AI 会有利于防御：在 bug 交付之前就把它们抓住、从零写出从根本上安全的软件、用模型主动防守系统，都会变得更容易。但短期内未必如此。[利用漏洞的成本已经下降](https://www.anthropic.com/news/expanding-project-glasswing)，而核实、披露和修复漏洞却很慢，仍然依赖人。在 Glasswing 中，我们常常看到从发现一个漏洞到把它修复过去了几个月。至于运营技术，一次修复可能要等到能够安全地施加到运行中的机器上——某些罕见情况下，这会需要几十年。

成功的含义是：面对有能力对手的进攻，水务、电力、交通、通信这些关键基础设施仍在运转，可被利用的入口更少，而一旦有东西穿透进来也能更快恢复。这件事要很多年，我们预计 Anthropic Cyber Mission 会随着我们与公共和私营部门一同弄清什么有效而不断变化。

## 前路

未来几个月，我们会把 Critical Infrastructure Defense Program 带给更多合作方、更多行业，也会分享途中所学，包括那些不奏效的部分。我们也预期其他 AI 开发者、安全公司和政府会开展自己的行动，凡是能帮助防御者的地方，我们都愿意与他们协作。

我们还会扩展工作范围以帮助保障开源以及更广的供应链。这包括研究编写软件的新方式与防守系统的新方式。我们打算分享前沿研究、工具与资源，帮助别人保障自己的软件与供应链。

如果你愿意与我们合作：

- 为关键基础设施构建安全产品或服务的公司，包括安全厂商、系统集成商和设备制造商，可以在我们扩展 [Critical Infrastructure Defense Program](http://claude.com/form/critical-infrastructure-defense-program-interest) 的过程中登记意向。
- 关键开源项目的核心维护者可以[加入 OSS Scanner](https://red.anthropic.com/oss-scanner)。
- 各种规模的安全团队，包括关键基础设施运营商和开源维护者，都可以[申请加入我们已扩容的 Cyber Verification Program](https://portal.anthropic.com/login)以使用我们的模型。
