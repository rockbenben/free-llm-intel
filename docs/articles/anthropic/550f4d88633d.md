# 扩大我们与 GSA 的合作伙伴关系，将 Claude 带到各级政府

我们正在扩大与美国总务管理局（GSA）的合作伙伴关系，通过一项新协议为政府合作伙伴提供 Claude Enterprise、Claude for Government 和 Claude API 的 40% 折扣。这是该折扣首次覆盖所有产品形态，既包括各机构目前直接从我们这里购买的情形，也包括未来几个月通过云提供商购买的情形。折扣还扩展至州、地方、部落和领地政府。

我们还在启动一项专门计划，帮助各机构落地并充分利用 Claude。这类计划通常被我们的私营部门客户所采用，我们期待在未来几周把这些最佳实践带给公共部门合作伙伴。

目前约有 500 个美国联邦、州和地方政府机构在使用 Claude。自 2 月以来，Claude for Government 的周活跃用户增长约 8 倍，联邦文职机构的使用量在一年内增长约 20 倍。这些机构运行着国内一些最重要的系统，通常预算紧张、采购周期漫长。这项协议正是为支持这类工作而设计，让它们无需大额前期承诺即可把 Claude 用于难题。

通过该协议提供的折扣，预计将为政府节省 10 亿美元。各机构不受最低消费承诺的约束，可以按实际用量付费。

### Claude 如何帮助公务人员完成更多工作

政府机构正使用 Claude 解决一些最重要的挑战，例如管理积压、记录和表单，以及让旧代码现代化。机构使用 Claude 的一些方式包括：

- 犹他州将 Claude Code 提供给 10 个州机构的 34 名开发者。80% 的人在 30 分钟内就拥有了可用的环境，71% 的人在为期四周的试点结束时表示节省了 20 小时以上。
- 美国某州的 CIO 证实，得益于 Claude，其团队能在 8 分钟内响应一次勒索软件攻击，而通常需要 2-3 天。
- 美国一个联邦安全团队使用 Claude Mythos 检测并修补了一个本可导致关键生产系统被接管的漏洞，用时约两天。而一个月前进行的人工渗透测试漏掉了它。
- 某大型机构的一位网络安全专业人员发现并修补了关键金融系统中的漏洞。
- 美国某州的 IT 开发者用两天将近 900 个 API 方法迁移到新框架。该项目原本预估需要一个月。
- 美国某州的 IT 主管用 Claude Code 为 12 个遗留代码仓库编写文档，梳理了 467 张数据库表，并沿途标记出 27 处风险。
- 美国超过半数的州、一些最大的地方辖区，以及该国一些最大的关键基础设施运营商[参与](https://www.anthropic.com/news/anthropic-cyber-mission)了我们的 SLTT 网络防御计划。

### 满足政府安全要求

各机构可以将 Claude 用于最敏感的未分类工作。Claude for Government 提供 Claude 的编码与 agent 工作能力，并在 FedRAMP High 授权级别上提供与商业产品近乎同等的功能，已于 9 月 30 日[正式可用](https://claude.com/resources/articles/claude-for-government-is-now-generally-available)。

自建工具的机构可以通过 Amazon Bedrock 或 Google Cloud 的 Vertex AI 使用 Claude。在 Bedrock 上，Claude 已获 FedRAMP High 授权，部分模型获准用于 AWS GovCloud 中的 DoD IL4 和 IL5 工作负载。在 Vertex AI 上，Claude 已获 FedRAMP High 授权。

Claude Enterprise 正在通过 FedRAMP 20x 计划进行 FedRAMP Moderate 授权流程，这标志着我们如何把商业上可用的同样创新技术带给政府的下一步演进。

### 开始使用

政府机构今天即可通过 GSA 的 Multiple Award Schedule 以 OneGov 折扣购买 Claude。无论你的部门或机构已经在使用 Claude，还是有兴趣使用，我们的公共部门团队都会协助讨论你的选择。

如需了解更多信息，请[在此](https://claude.com/solutions/government)联系我们。
