Code Review 已走出 research preview，向 Claude Team 和 Enterprise 组织开放。

> 符合条件的 Claude Enterprise 组织可在 2027 年 1 月 15 日前领取至少 $10,000 的 Code Review 额度。额度在你领取后 30 天过期。适用相关条款。

### Code Review 的新变化

Coding agent 在不断加快团队写代码的节奏，而评审这个瓶颈并没有缓解。在正式可用版本里，我们让 Code Review 更快、更擅长找出那些真正要紧的 bug，也更容易针对你的每一个仓库做调优。

自从我们发布 [research preview](https://claude.com/resources/articles/code-review) 以来，Code Review 变得更犀利，能抓到更多原本会一路进到生产环境的 bug。我们也在 Anthropic 内部的 pull request 上跑 Code Review，这让我们看到评审在哪些地方拖慢了自己工程师的节奏。在 preview 期间使用 Code Review 的团队把其余的问题告诉了我们：它确实能在人工评审者看 PR 之前就抓到真实问题，但他们希望评审更安静、规模与每次改动相称、并且更快。以下是我们交付的内容：

- **速度：** 相比 preview 期间，现在大多数评审的完成速度大约快 3 倍（从约 20 分钟降到 6-10 分钟）。
- **质量：** 找出更多真正要紧的 bug，并给出清晰、简洁的结论，用几句话说明问题是什么、什么触发了它，以及怎么修。
- **灵活性：** 管理员为每个仓库选择 Quick、Standard 或 Deep，因此常规代码库走一遍快速评审，最关键的代码库得到一次深入评审。每一档都提供高质量评审。

### 开始使用

Code Review 现已在 Team 和 Enterprise 套餐正式可用。

- **给管理员**：在你的[ Claude Code 设置](http://claude.ai/admin-settings/claude-code)中启用 Code Review，安装 GitHub App，并选择你希望运行评审的仓库。
- **给开发者**：一旦启用，评审会在新建的 PR 上自动运行。无需任何配置。

更多信息请[查看文档](http://code.claude.com/docs/en/code-review)。
