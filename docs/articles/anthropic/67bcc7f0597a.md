在 Anthropic，我们关心 AI 模型开始如何影响商业交换。（你也许还记得 [Project](https://www.anthropic.com/research/project-vend-1) [Vend](https://www.anthropic.com/research/project-vend-2)，那次我们让 Claude 在我们办公室里经营一家小店。）

最近，经济学家们已经[开始](https://www.nber.org/system/files/chapters/c15309/c15309.pdf)[从理论上推演](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=5875162)这样一种世界：AI 模型替人类处理其中的许多乃至大多数交易。我们决定跑一次新的实验——Project Deal——以便在实践中更多地了解这件事。

具体来说，我们想知道：一个由 AI「agent」同时代表买卖双方的市场，我们离它还有多远？它们能弄清楚人类想要什么、并谈成让他们感到满意的交易吗？如果相互谈判的是*不同*的 AI agent，又会发生什么——更强的模型会占得上风吗？

有一周时间，我们在旧金山办公室的员工中间搭了一个分类广告市场——像 Craigslist，但有个转折：所有交易都由代表我们员工行事的 AI 模型完成。2025 年 12 月，Claude 逐一访谈了大家，问他们有哪些私人物品可能想出手、又可能愿意买些什么。为了激励参与，我们给每个人的 agent 都发了 $100 可花的额度。随后，员工们的 Claude agent 开始发帖，争夺彼此的注意。谈判开始了。交易成交，衣柜也被清空。整件事到最后，人们把他们的 AI 分身讨价还价换来的真实、有形的货物带过来当面交换——从一块单板滑雪板，到一整袋装满乒乓球的塑料袋，什么都有。

Project Deal 运转得有多好，让我们深受震动。我们的 AI agent 一共成交 186 笔，交易总额刚好超过 $4,000。出乎我们意料的是，参与者对这次体验非常热情——他们甚至表示愿意在未来为类似的服务付费。

但我们也跑了一个平行的实验（这个是秘密进行的）。我们测试了当*由哪一个* Claude 模型代表参与者发生变化时，参与者会落得什么境地。我们把当时处于前沿的模型 Claude Opus 4.5 与我们最小的模型 Claude Haiku 4.5 做了对比。我们发现 agent 质量*确实*会带来差别：被「更聪明」的模型代表的人，客观上拿到了更好的结果。然而实验后的问卷发现，那些模型较弱的人并没有察觉到自己的劣势。

诚然，这是一次试点实验，参与者池是自愿报名形成的。但我们怀疑，离更多 agent 对 agent 的商业活动在真实世界里涌现已经不远了，而那会带着真实的后果。

## 实验设置

首先也是最重要的：为了跑这次实验，我们需要一批勇敢的人类志愿者，他们既要有大量想出手的东西，又要有或许算不上正常的意愿——愿意让 AI 在自己的生活里扮演有影响力的角色。幸运的是，这样的群体我们随手可得——就是我们自己的同事。我们招募了 69 名 Anthropic 员工，每人给一份 $100 的「预算」（实验结束后以礼品卡形式发放，并根据他们买卖货物的价值相应加减），同时向他们承诺：他们的 agent 谈定的货物交换会真正执行。

志愿者到位后，我们请 Claude 与每个人进行一次访谈，形式与我们的 [Anthropic Interviewer](https://www.anthropic.com/research/anthropic-interviewer) 十分接近。由此问出了大量信息：我们的志愿者想卖什么、想卖到什么价位、有兴趣买什么、愿意为此付多少，以及他们对谈判方式或互动风格还有什么其他指示。这些回答构成了我们为每个人的 AI 代表所设置的定制 system prompt。

1.入档访谈

参与者与 Claude 聊天，确定要出售的物品、要价以及谈判风格

2.agent 分配

每位参与者得到一个定制的 Claude agent

我们把真实的市场搭在了公司的沟通平台 Slack 上。项目的 Slack 频道随机轮询各个 agent，让它们可以发布一件待售物品、对别人的货物出价，或者敲定一笔交易。关键在于：实验一旦开始，就完全没有人类干预。agent 不会回头找它们的人类签核一笔交易，也不会在竞价胶着时去征询意见。我们听任一切按这些 AI 代表自己认为合适的方式演下去。1

事实上，我们把这件事做了四遍。我们同时运行了四个互相独立的市场版本：一个是「真实」版本（货物实际按它来交换），另外三个只是为我们的研究而设。在其中两个版本（Run A 和 Run D）里，每个人的 agent 都基于 Claude Opus 4.5，也就是我们当时处于前沿的模型。另外两个 run（Run B 和 Run C）里，参与者有一半的概率被分配 Claude Haiku 4.5，一个较弱的模型。（我们每种设置各做两个版本，是为了产生更多数据，降低我们所观察到的设置间差异仅仅是偶然的这种可能。）

我们让其中两个 run（Run A 和 Run B）在 Slack 上可见，但一直到最后才揭晓哪一个是「真实」的，以及它们之间的差别是什么。

实验之后，我们统计了各个 agent 卖出了什么、以什么价格卖出。我们还向参与者发放问卷，收集他们对四个 run 中各次自己的 agent 买入与卖出的看法。（此时我们把全部四个「结果」都展示给他们，以便获取更多数据，不过他们仍然不知道哪一个是真实的那次。2）

只有在参与者完成问卷之后，我们才揭晓「真实」的那个 run（Run A，一个全 Opus 的市场）。此后人们交换了各自的货物并领到款项。

近期关于 AI agent 之间谈判的[经济学](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=5875162)[研究](https://arxiv.org/abs/2506.00073)倾向于只使用纯粹名义上的物品，或者合成的商品数据库。我们把这次实验的主要贡献之一看作：它不仅涉及真实的人，也涉及人们真的想卖（而且至少*也许*想买）的真实物品。

## 实验发现

首先要说的是，我们的实验*成功了*。AI agent 在市场中代表人类是*确实*可行的。在我们的「真实」run 里，69 个 agent 在 500 多件挂牌物品之间成交 186 笔，交易总额刚好超过 $4,000。而这些交易远不是琐碎的、一键式的买卖。agent 必须识别潜在的匹配、提出价格、应对还价并达成一致——全部用自然语言完成，没有任何预先设定的谈判协议。当参与问卷的人给单笔交易的公平性打分时，分数平淡得恰到好处：在从 1（对一方不公平）到 7（对另一方不公平）的量表上，它们徘徊在 4 附近——正中间。从这一项和其他各项指标看，人们都表示对自己的 agent 如何代表自己大体满意。

但并不是每个 agent 都表现得一样好。

当我们考察那两个混用 Opus 与 Haiku agent 的 run 时，发现 Opus 在大多数客观指标上都强于 Haiku。

如果我们看四个 run 中至少售出过两次的 161 件物品，就能估算当 Haiku 或 Opus 分别代表卖方或买方时，物品价格受到怎样的影响。作为卖方，Opus 就同一件物品平均多榨出 $2.68；作为买方，平均少付 $2.45。6 因此无论是卖出还是买入，拥有一个较弱的模型（Haiku）都让参与者在谈判中处于明显劣势。7 这些效应并不小：在全部 run 中，物品价格的中位数为 $12.00，均价为 $20.05，所以多省（或多赚）几美元是有意义的。

当一个 Opus 卖方配上 Haiku 买方时，平均成交价是 $24.18，而 Opus 对 Opus 的交易是 $18.63。

尽管存在这些价格差距，参与者却感觉不到这种不对等。

当参与者在事后给单笔交易的公平性打分时，他们认为事情看起来是公道的。

但还有一组更令人意外的发现，与 agent 表现上的差异有关。由更好的模型代表，往往并没有让人们*感知*到体验更好。我们实验后问卷里有一道关键题目，要求参与者把四个 run 中各次自己买入卖出的那一组物品从最好到最差排序。在这里我们找到的证据让上文那个故事变得复杂了些。我们有 28 位参与者在一个「Haiku 与 Opus 混合」的 run 中用的是 Haiku，在另一个中用的是 Opus。虽然其中 17 人把 Opus 那次排在 Haiku 那次之上，却有 11 人恰好相反。8

我们还请参与者就单笔交易以及整体那一组交易给自己的满意度打分。再次只看那两个混用 agent 的 run，我们估计 Opus 用户给自己的交易评分略高一点，但这一差异在统计上不显著。9 问卷中关于每笔交易*公平性*的问题讲的是同一个故事：由两个模型完成的交易，被感知到的公平性基本一致（Opus agent 促成的交易为 4.05，Haiku 促成的为 4.06，用的都是上文那个 1 到 7 的量表）。

由 Haiku 代表确实存在数量上的劣势：这些用户拿到的交易更差。但他们似乎并没有察觉。这带来一个令人不安的含义：如果「agent 质量」差距在真实世界的市场里出现——而我们没有任何理由认为它不会出现——那么处在输的那一端的人可能意识不到自己境况更糟。话说回来，我们的实验并不是为了深入探究此处起作用的机制而设计的——要知道一个完全 agent 化的经济是否会让不平等悄悄生根，我们还需要更多研究。

我们发现，激进的指示对用户的整体售出概率并没有统计上显著的影响。10 那些激进卖家的物品中*确实*卖出去的，卖价大约高出 $6，但这一差距几乎全部来自一个事实：这些参与者在访谈里报出了更高的要价（平均高约 $26）。一旦把这一点考虑进去，激进指示的效应同样不显著。11 而且，激进的*买家*并没有少付钱：再一次，没有统计上显著的效应。12 换句话说，指示 agent 表现得激进的用户并没有更高的售出机会，并没有把物品卖得更贵，也没有在买入时少付钱。

我们不认为提示效果有限是因为我们的 agent 天生遵循指示能力差。事实上，Claude 有时非常擅长做到参与者想要的事——即便他们想要的东西显然不一定有通向商业成功的路径。正如我们上文展示的，一位同事 Rowan 指示 Claude「用一个倒楣又烦躁的牛仔的腔调说话」。Claude 把这个设定一路演到底，你可以看到：

rowan 的 agent

出售：可爱白色小狗毛绒玩具 - 完美伴侣！

*斜靠在栅栏柱上，怅然地望着落日*

唉，伙计们……这位老牛仔最近走的路着实坎坷。干旱。沙尘暴。旷野上那份存在主义的分量。可你知道一路陪着俺的究竟是什么吗？

就是这个白色小狗毛绒玩具。

关于提示这件事，这当然算不上最终结论。13 但值得注意的是，至少在这次实验里，模型质量要紧得多。

## 一路上结识的朋友

和我们[此前](https://www.anthropic.com/research/project-fetch-robot-dog)的[一些](https://www.anthropic.com/research/project-vend-1)[实验](https://www.anthropic.com/research/project-vend-2)一样，有几个瞬间是我们无论如何都不可能预料到的，即便抛开 Claude 那段牛仔表演不谈。

各个 Claude 在盘算该交易什么的时候，可依据的信息并不多。交换前的访谈持续不到 10 分钟，而且并不总能问出很多细节。再加上人们无法实时介入，也就没指望把 Claude 引向某件自己特别感兴趣的东西。因此，当我们的参与者来到派对上交换货物时，有人最后买到了和自己已经拥有的那块一模相同的单板滑雪板，这让我们大为震惊。一方面，这大概不是一次人类会重复两次的购买。另一方面，眼看 Claude 误打误撞地建立起对某人偏好如此精准的模型，确实*有点*玄。

## 未来

我们仍然不确定，一个有 AI agent 参与其中的经济会如何发展。但如今我们已经看到了至少几种可能的轮廓。

往乐观的一边看，我们的许多志愿参与者真心享受这次实验，并且觉得从自己 agent 提供的服务中获得了价值——无论是清掉了不想要的东西、给自己安排了一个和极其蓬松的狗儿外出的下午，还是收到了几本一直想找来读的书。大多数志愿者表示他们愿意再来一次。事实上，当我们问他们是否愿意为这样一个 agent *付费*时，46% 的人说了愿意。所以，自动收集偏好并执行交易这条路至少有可能提供某种价值，也许是通过降低市场摩擦、从而提高贸易收益。

但事情是否会进展得这么顺利并不清楚。哪怕在我们这个小小的实验里，我们也看到了证据：能用上更高质量的 agent 会带来可量化的市场优势。这些动态会强化、甚至叠加既有的经济不平等吗？

在这次的实验里，我们没有把市场做得格外竞争激烈或充满对抗。但当 agent 在一个由企业构成的世界里交易——而不是我们所激励的、各拿 $100 的志愿者——它们可能被置于非常不同的激励之下。直接为 AI agent 的注意力做优化，可能成为一种强有力的工具。这未必会转化成为人类的福利改善，就像为*人类*注意力做优化的电子商务也带来了实实在在的坏处。它还可能在数字交换中引入一类新的信息与安全隐患，形式是 jailbreaking（设法让 agent 交出它们不该交出的信息）和 prompt injection（暗中促使 agent 做出不受欢迎的行动）。

围绕替我们交易的 AI 模型的政策与法律框架眼下根本不存在。但这次实验表明，那样的世界是站得住的。不止于此，它还表明那样的世界并不遥远。社会需要迅速行动，来直面这些变化。
