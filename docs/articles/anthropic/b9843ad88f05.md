# 完整的 Claude 平台登陆 Google Cloud

Claude Models on Google Cloud (Anthropic managed) 现已正式可用，Google Cloud 客户由此拿到 Claude Platform 的全部功能，并用上 Google Cloud 的 IAM 凭证、账单与承诺额度抵扣。Claude 也仍然可以通过 Google managed 的方式使用，在那种方式下由 Google 担任数据处理方。

## 在 Google Cloud 上访问完整的 Claude Platform

有了 Anthropic managed 这种方式，Google Cloud 客户现在能拿到 Claude API 的完整功能集，新功能与 beta 功能在与原生 Claude Platform 上线的同一天就会送到手上。

Anthropic managed 方式直接沿用现有的 Google Cloud IAM 凭证，所以团队可以继续留在自己已经在管理的工具和权限里。账单走一张 Google Cloud 发票，Claude 的用量会抵扣你已有的 Google Cloud 承诺额度。

Claude Models on Google Cloud (Anthropic managed) 目前提供 US 与 Global endpoint。

## 包含哪些内容

使用 Anthropic managed 方式的 Google Cloud 客户能拿到 Claude Platform 的完整功能集，因此他们可以：

**构建与部署 agent，可用：**

- [Claude Managed Agents (beta)](https://platform.claude.com/docs/en/managed-agents/overview)，用来支撑长时间运行的 agent，而不必自己管基础设施
- [Code execution](https://platform.claude.com/docs/en/agents-and-tools/tool-use/code-execution-tool)，在一次 API 调用里运行 Python 代码、制作可视化、分析数据
- [Computer use](https://platform.claude.com/docs/en/agents-and-tools/tool-use/computer-use-tool)，让 Claude 能够操作浏览器或桌面来完成任务
- [Agent skills](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview)，教给 Claude 可重复的工作流，让它交付一致的结果
- [Advisor strategy (beta)](https://platform.claude.com/docs/en/agents-and-tools/tool-use/advisor-tool)，通过请教一个 advisor 模型给 agent 加一次智力提升

**连接系统与知识，可用：**

- [Files API](https://platform.claude.com/docs/en/build-with-claude/files)，用于在各场对话之间上传和引用文档
- [Citations](https://platform.claude.com/docs/en/build-with-claude/citations)，让回答有源文档打底
- [Web search](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool) 和 [web fetch](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-fetch-tool)，用来自全网的、当下的真实世界数据来扩充 Claude 的知识
- [MCP connector (beta)](https://platform.claude.com/docs/en/agents-and-tools/mcp-connector)，把 Claude 连到其他工具上而不用写 client 代码

**管理成本与性能，可用：**

- [Prompt caching](https://platform.claude.com/docs/en/build-with-claude/prompt-caching)，降低重复上下文带来的成本与延迟
- [Batch processing](https://platform.claude.com/docs/en/build-with-claude/batch-processing)，应对大批量的异步工作负载

Claude Opus 5.5 上的 Fast Mode 对使用 Claude Models on Google Cloud (Anthropic managed) 的客户也已正式可用。Fast mode 把速度放在优先位置，输出 token 的生成速度最高可快 2.5 倍，适合快速迭代、实时调试，以及在输出速度决定体验好坏之处的交互式 agent。输入与输出 tokens 每百万分别为 $8 和 $40。

Claude Models on Google Cloud 上可用功能的完整清单见我们的[文档](https://platform.claude.com/docs/en/build-with-claude/claude-models-on-google-cloud/anthropic-managed)。

用上 Anthropic managed 方式的客户同时获得 Claude Console 的访问权，那是 Anthropic 用于观测和管理 Claude agent 的开发环境。Console 里有写 prompt、配置 agent 的工具，可以把它们跑在托管环境上，监控用量与成本，并按 workspace 管理访问与安全。

Claude Fable 5.1、Opus 5.5、Sonnet 5.5 和 Haiku 5.5 均已可用，后续新模型一发布就会登陆 Anthropic managed 这种方式。

## 两条用 Claude 构建的路径

在 Google Cloud 上用 Claude 构建，有两种方式。

**Claude Models on Google Cloud (Anthropic managed)** 为这样的客户而建：他们想要 day zero 就能用上所有 beta 与正式可用的 Claude Platform 功能。它最适合希望通过 Google Cloud 获得 Claude Platform 完整功能对等的客户。服务由 Anthropic 运营，Anthropic 担任数据处理方。

**Claude Models on Google Cloud (Google managed)** 仍然是这些客户的最佳选择：需要由 Google Cloud 担任数据处理方、有严格的区域数据驻留要求，或者想要原生的 Google Cloud 集成，例如 Model Armor 或 Agent Engine。

## 开始使用

Anthropic managed 方式今日正式可用。要上手，请打开 [Claude Models on Google Cloud (Anthropic managed)](https://console.cloud.google.com/marketplace/product/anthropic/anthropic-managed-claude)，或查阅[文档](https://platform.claude.com/docs/en/build-with-claude/claude-models-on-google-cloud/anthropic-managed)。

如果你已经有折扣，请在开始使用 Anthropic managed 方式之前联系你的 Anthropic 或 Google Cloud 客户负责人，以确保折扣被正确应用。折扣无法追溯适用于已经发生的用量。
