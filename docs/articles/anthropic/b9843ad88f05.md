Google Cloud 上的 Claude Models（Anthropic 托管）现已全面推出，为 Google Cloud 客户提供全套 Claude Platform 功能，包括 Google Cloud IAM 凭证、计费和承诺停用。克劳德仍然可以通过 Google 托管产品进行访问，其中 Google 是数据处理者。

## 访问 Google Cloud 上完整的 Claude 平台

借助 Anthropic 托管产品，Google Cloud 客户现在可以获得全套 Claude API 功能，新功能和测试版会在原生 Claude 平台上线的同一天发布。

Anthropic 托管产品可与现有的 Google Cloud IAM 凭证配合使用，因此团队可以保留他们已管理的工具和权限。通过一张 Google Cloud 发票进行计费，Claude 的使用会减少您现有的 Google Cloud 承诺。

Google Cloud 上的 Claude Models（Anthropic 托管）目前可在美国和全球端点上使用。

## 包含什么

使用 Anthropic 托管产品的 Google Cloud 客户可以获得全套 Claude Platform 功能，因此他们可以：

**使用以下方式构建和部署代理：**

- [Claude Managed Agents（测试版）（在新选项卡中打开）](https://platform.claude.com/docs/en/managed-agents/overview) 为长期运行的代理提供支持，无需管理基础设施
- [代码执行（在新选项卡中打开）](https://platform.claude.com/docs/en/agents-and-tools/tool-use/code-execution-tool) 在 API 调用中运行 Python 代码、创建可视化并分析数据
- [计算机使用（在新选项卡中打开）](https://platform.claude.com/docs/en/agents-and-tools/tool-use/computer-use-tool)允许Claude操作浏览器或桌面来完成任务
- [代理技能（在新选项卡中打开）](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview) 教授 Claude 可重复的工作流程，以便提供一致的结果
- [顾问策略（测试版）（在新选项卡中打开）](https://platform.claude.com/docs/en/agents-and-tools/tool-use/advisor-tool) 通过咨询顾问模型为代理提供情报提升

**通过以下方式连接到系统和知识：**

- [文件 API（在新选项卡中打开）](https://platform.claude.com/docs/en/build-with-claude/files)，用于在对话中上传和引用文档
- [引文（在新选项卡中打开）](https://platform.claude.com/docs/en/build-with-claude/itations) 用于在源文档中提供基础响应
- [网络搜索（在新选项卡中打开）](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool) 和 [网络获取（在新选项卡中打开）](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-fetch-tool) 通过网络上当前的真实数据来增强 Claude 的知识
- [MCP 连接器（测试版）（在新选项卡中打开）](https://platform.claude.com/docs/en/agents-and-tools/mcp-connector) 将 Claude 连接到其他工具，而无需编写客户端代码

**通过以下方式管理成本和性能：**

- [提示缓存（在新选项卡中打开）](https://platform.claude.com/docs/en/build-with-claude/prompt-caching) 用于降低重复上下文的成本和延迟
- [批处理（在新选项卡中打开）](https://platform.claude.com/docs/en/build-with-claude/batch-processing) 适用于大容量、异步工作负载

Claude Opus 5.5 上的快速模式也适用于在 Google Cloud（人工管理）上使用 Claude Models 的客户。快速模式优先考虑速度，提供高达 2.5 倍的输出令牌生成速度，用于快速迭代、实时调试和交互式代理，其中输出速度可带来更好的用户体验。输入和输出代币分别为每百万 8 美元和 40 美元。

请参阅我们的[文档（在新选项卡中打开）](https://platform.claude.com/docs/en/build-with-claude/claude-models-on-google-cloud/anthropic-management)，了解 Google Cloud 上 Claude Models 可用功能的完整列表。

使用 Anthropic 托管产品的客户还可以访问 Claude Console，这是 Anthropic 的开发环境，用于使用 Claude 观察和管理代理。该控制台包括用于编写提示和配置代理、在托管环境中运行它们、监控使用情况和成本以及管理每个工作区的访问和安全性的工具。

Claude Fable 5.1、Opus 5.5、Sonnet 5.5 和 Haiku 5.5 现已推出，新型号在推出时将通过 Anthropic 托管产品发货。

## 与 Claude 一起构建的两条路径

在 Google Cloud 上使用 Claude 进行构建的方法有两种。

**Google Cloud 上的 Claude Models（Anthropic 托管）** 专为希望零日访问所有测试版和普遍可用的 Claude 平台功能的客户而构建。对于想要通过 Google Cloud 访问的完整 Claude Platform 功能对等的客户来说，这是最好的选择。 Anthropic 运营该服务并充当数据处理器。

**Google Cloud 上的 Claude Models（Google 托管）** 对于需要 Google Cloud 作为数据处理器、有严格的区域数据驻留要求或想要原生 Google Cloud 集成（如 Model Armor 或 Agent Engine）的客户来说，仍然是最佳选择。

## 开始吧

Anthropic 托管产品现已全面上市。要开始使用，请打开 [Google Cloud 上的 Claude Models（Anthropic 托管）（在新选项卡中打开）](https://console.cloud.google.com/marketplace/product/anthropic/anthropic-management-claude) 或浏览[文档（在新选项卡中打开）](https://platform.claude.com/docs/en/build-with-claude/claude-models-on-google-cloud/anthropic-driven)。

如果您已有折扣，请在开始使用 Anthropic 托管产品之前联系您的 Anthropic 或 Google Cloud 客户主管，以确保正确应用您的折扣。折扣不能追溯至使用情况。
