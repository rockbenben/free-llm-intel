# 在 Claude 中推出个人理财

要搞明白自己的钱都去了哪儿，不再意味着打开每一个银行应用、自己一笔笔算账。借助 Claude 中的「个人理财」（Personal Finance），你可以安全地连接自己的银行和银行卡账户，用自己的话提问。访问是只读的，「个人理财」无法动用、管理或投资你的资金。

![](https://assets.claude.com/b87507b2ca680b626804a95946d15f34391e07f7.png)

Claude 用日常语言，根据你各账户的余额和交易记录给出解答，并解释任何对你来说陌生的术语。和 [Claude 的其他部分](https://www.anthropic.com/news/claude-is-a-space-to-think)一样，「个人理财」没有广告，也没有赞助推荐，并且它自己不发行信用卡、贷款或储蓄账户，所以你关于钱的问题能得到一个直截了当的答案。

「个人理财」本周开始在 beta 阶段陆续推出，面向美国地区的 Pro、Max 和 Ultra 套餐。

## **「它是什么样」**

假设已到月底，而发薪日还有 10 天。当你问 Claude「我这个月的钱都花哪儿了？」时，它会把你连接的所有账户上的支出加总，并按类别归类。在这个例子里，总额是 $4,309.37，其中一半以上花在房租和水电上，另有 $1,024.51 花在餐饮上。

![](https://assets.claude.com/bc5343b7f36d1704f728e53c69f672ae05c576e1.png)

接下来，你可以进一步追问：「这比平时多吗？」「还有什么是我漏掉的？」「那么发薪日之前我还剩多少？」Claude 会查看过去几个月的情况，并指出一笔会员续费。然后它会告诉你发薪日之前将有哪些笔付款从你的活期账户里划走，以及你还剩下多少：$1,393.22。

![](https://assets.claude.com/734b3f5688057d9a672bf9f32aa4c450c8732e8d.png)

如果你问有没有什么不对劲的地方，Claude 会通读你连接的每一个账户，指出那些容易错过的情况，比如被扣了两次的款项、意外的费用，或是一年来悄悄上涨的一笔账单。你也可以问更大的问题，比如「我花的比挣的多吗？」或「什么是 APR，它今年花掉了我多少钱？」Claude 会先解释这个术语，再把你被收取的利息加总起来。

要一张每周支出图表、一份到期事项的日历，或一块展示你自己选定数字的仪表盘，开口向 Claude 要一个就行，它会为你搭建一个你可以不断调整的成品。

## **「安全与隐私」**

Claude 的访问是只读的。「个人理财」帮助你理解自己的财务状况，它并非为提供投资建议而设计。Claude 的回答可能会出错，所以要问清某个数字背后对应的是哪些交易，并向你的银行核实重要数字。

只有当你自己通过 [Plaid](https://plaid.com/)（一项把应用与银行连接起来的服务）登录你的银行之后，你的账户才会被连接。你正是在那里同意它的条款、并批准 Claude 的只读访问，因此 Claude 不会索取或看到你的银行密码。

对于你选择连接的账户（也只有这些账户），Claude 会看到银行的名称、每个账户的名称、类型和后四位数字、余额和信用额度，以及最多两年的交易记录。当你在「个人理财」专区里与 Claude 聊天时，这些对话不会被用来训练我们的模型。对于你在该专区之外分享给 Claude 的任何内容，你的[隐私设置](https://claude.ai/settings/privacy)依然适用。你可以随时断开某个账户的连接，此后 Claude 就再也看不到它的数据。更多细节见我们的 [Privacy Center](https://privacy.claude.com/en/collections/10663362-consumers)。

## **「如何开始」**

当你在 Claude 的侧边栏里看到「个人理财」时，打开它，连接一个账户，问一个问题，比如「这个春天我出得起一次旅行吗？」或「我每个月能省下多少钱？」你会在[帮助中心](https://support.claude.com/en/articles/18185620-use-personal-finance-with-claude)找到设置步骤，以及你的数据如何被使用和保管。

## **「下一步」**

「个人理财」只是第一步。面对人生里更大的财务决策，我们相信最能服务人们的，是让 Claude 与他们信赖的持牌专业人士和受监管机构并肩协作。我们正在探索如何在 Claude 中做到这一点，也希望听到有意帮忙塑造它的银行、财富管理机构和金融服务公司的声音。
