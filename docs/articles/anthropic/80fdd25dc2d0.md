# Claude Tag 现已在频道中支持个人连接器

Claude Tag 现在可以为你在频道中提出的请求使用你自己的连接器。其他人都无法使用它们，而由你来掌控如何呈现输出。

- 类别：[产品公告](https://claude.com/blog/category/announcements)、[企业 AI](https://claude.com/blog/category/enterprise-ai)
- 产品：[Claude Tag](https://claude.com/product/tag)
- 日期：2026 年 9 月 24 日
- 阅读时长：5 分钟

[Claude Tag（beta）](https://claude.com/product/tag)让你可以把 Claude 加入一个 Slack 频道，在其中与你的团队并肩工作。此前，Claude 只能使用 [管理员挂到频道上的](https://claude.com/blog/agent-identity-access-model)连接器，而大多数组织有意让那份清单保持简短：他们希望访问权限跟随人，而非跟随频道。

如今，Claude 可以使用你自己的 [连接器](https://claude.com/docs/claude-tag/concepts/settings-map) 来处理你在频道中提出的请求。例如，你的日历、你的云盘、你在 CRM 中被分配的客户，或你的预发布部署。只要你 [把它连接到了你的 Claude 账户](http://claude.ai/customize)，你就能在频道里访问它。

从你请求 Claude 访问你的连接器那一刻起，由你决定信息如何呈现。你可以在每条回复发布前先审阅它。或者，你可以使用自动模式，除非 Claude 判定有需要你审阅的敏感内容，否则自动发布。在企业套餐上，管理员将能对所有人强制要求审阅。

个人连接器为管理员提供了更多治理选项。他们可以在一个 agent 身份下提供对一整套共享工具的访问、让频道成员仅使用个人连接器以依赖现有的基于角色的访问，或逐工具地做决定。

Claude Tag 中的个人连接器现正于 Team 套餐推出，Enterprise 随后跟进。

## **使用个人连接器**

人们在频道里所需的很多东西，都藏在你自己的登录之后：你的日历上合适的时间、你未成交的单子、一份只有你能打开的计划。如今你在频道里也能索取这些了。

例如，这里是 Priya 在 #checkout-migration 频道中，该频道连接了 GitHub。她问道：「@Claude 对照我们已经上线的内容，检查我的 Google 文档『Checkout migration, Q3』。还有什么没完成？」

Priya 在 #checkout-migration 里请 Claude 对照已上线内容检查她的计划。该频道可访问 GitHub。这份文档只有 Priya 能打开。

Claude 通过频道的 GitHub 连接器读取已合并的 pull request。这份文档只有 Priya 能打开。以前，Claude 到这里就会停下。

现在，Claude 通过 Priya 的 Google Drive 连接器读取文档，与频道自身的工作分开进行，并发布出已上线的和尚遗留的内容。Priya 的计划并不敏感，所以她用自动模式，Claude 会在发布前筛查这份比对结果。对于一份她宁愿先检查的文档，她可以切换到审阅模式，在频道看到回复之前自己先看到。

同一个讨论串。Claude 带着比对结果的回复，以及在发布前展示将要发布内容的审阅提示。

Claude 通过你的连接器所做的一切，都会出现在该工具自己位于你账户下的日志中，就像你私信中的工作今天所做的那样。频道自身的工作则留在它的服务账户下——即你的安全团队已经在跟进的那个。

由你决定 Claude 能触达什么、频道能看到什么，与你直接在私信里使用连接器时一样，而且你可以随时断开某个连接器。

## **频道自身连接器仍然重要的地方**

个人连接器不会无人值守地运行。排定的例程，以及 Claude 自行启动的任何动作，使用的都是管理员挂到频道上的连接器。无人值守动作所需的、或整个频道都依赖的工具，应当使用共享连接器。

例如，你可能想把 Claude 加进你的 [#on-call 频道以协助 CI 分类和响应](https://claude.com/blog/ai-ci-cd-on-call)。如果你为 Claude 设置了指向你的 runbook、监控工具和部署历史的共享连接器，Claude 就能在下班时间之后也识别并协助修复问题。

一个完全依赖个人连接器的频道适合被密切监督的工作。例如，协作起草一份 RFP 响应，可能需要从定价或其他未向整个频道开放配置的敏感来源拉取数据。Claude 发布的一切都对该频道里的每个人可见。

## **接下来**

无需安装任何东西。当你的一次请求需要你的某个连接器时，Claude 会第一次问你，然后在讨论串里使用它。

在频道里 @Claude 索取只有你能触达的内容。了解更多关于 [Claude Tag](https://claude.com/product/tag) 的信息。
