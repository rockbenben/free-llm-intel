T. Rowe Price 的投资组合经理和分析师正借助 Claude 和 Claude Cowork 开展基本面研究，其开发人员则用 Claude Code 构建投资工具。

全球投资管理公司 T. Rowe Price 与 Anthropic 今日 [宣布扩大](https://www.prnewswire.com/news-releases/t-rowe-price-works-with-anthropic-to-bring-claude-to-more-of-its-investment-process-302875582.html) Claude 在该投资公司业务中的应用范围。这家全球投资管理公司的投资组合经理和分析师正借助 Claude 和 Claude Cowork 开展研究工作，其开发人员则用 Claude Code 构建投资工具。

T. Rowe Price 是一家主动管理机构，因此其投资决策建立在自身基本面研究之上。分析师和投资组合经理阅读并评估大量信息，然后运用判断形成观点。该公司使用 Claude 的目标，是为这类工作腾出更多余力。

## T. Rowe Price 如何使用 Claude

该公司把 Claude 用于投资流程的三个环节：

- **研究。** 投资专业人士请 Cowork 综合复杂信息，从而腾出更多时间用于分析和讨论。
- **多步骤流程。** 团队与 Cowork 协作处理知识密集型任务，在这些任务中一致性与监督尤为重要。
- **工具构建。** 开发人员与 Claude Code 协作，构建并改进支持投资与运营团队的工具。

这一切都在 T. Rowe Price 于八月宣布的 AI 领导模式下运行：该模式把 AI 负责人嵌入投资部和全球分销部，并要求公司的企业级 AI 与数据创新中心 T. Rowe Price Labs 负责评估并在整个公司推广 AI。每个应用由业务部门自主拥有，遵循公司负责任使用的标准治理，其构建方式确保人类判断和问责始终处于客户成果的核心。

Anthropic 资产与财富管理负责人 Peter Nolan 表示：「大多数企业 AI 部署都从后台起步。而 T. Rowe Price 是从挑选证券的人开始的。」

T. Rowe Price 总裁、全球投资联席负责人兼首席投资官 Eric Veiel 把 Claude 形容为一套研究流程的延伸——这套流程已服务该公司客户近 90 年。「Claude 让我们的投资专业人士能覆盖更广、在真正重要的问题上走得更深。」他说。

## **下一步**

这项工作契合 T. Rowe Price 更广泛的 AI 努力，包括培训、人才培养和负责任使用指南，以帮助员工在使用 AI 时建立信心，同时把人类判断和客户关注置于核心位置。该公司公开表达的雄心，是在 AI 如何应用于投资、如何运营公司、如何服务客户方面引领投资管理行业。
