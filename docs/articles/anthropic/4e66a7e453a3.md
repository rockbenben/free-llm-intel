# 2026 年使用政策更新

每年，Anthropic 都会根据我们模型不断演进的能力，以及我们从客户那里收到的反馈，来更新我们的 Usage Policy。我们今天发布该政策的新版本。在这篇文章中，我们概述自己所做的各项变更。

最新版本中的大多数更新都旨在澄清既有规则。自上次更新以来的一年中，Claude 承担了更长、更独立的工作。本次更新提供了新的示例，说明我们的规则如何适用于 Claude 的新能力。它源自我们在过去一年中观察到的、出现在影响行动、武器开发与监控领域的新滥用模式（我们已在[最新一期威胁情报报告](https://www.anthropic.com/threat-intelligence-report-september-2026)中做了记录）。我们还做了一些更新，以澄清在健康和金融等领域对高风险使用场景的要求，为 Claude 被用于自主采取物理行动的情形增加管控，并应对针对我们模型的虐待行为。

更新后的政策于 11 月 12 日生效。完整的 [Usage Policy](https://www.anthropic.com/legal/aup) 与 [Supported Regions Policy](https://www.anthropic.com/supported-countries) 可在各自页面查看。

### 关于欺骗性活动的新章节

正如我们[上个月所写](https://www.anthropic.com/threat-intelligence-report-september-2026)，我们看到过这样的例子：国家媒体机构、政府宣传部门和商业公司用 Claude 运营假账号网络与捏造的新闻网站。我们的政策早已禁止这类活动，但相关限制分散在选举、欺诈、隐私和虚假信息这几个章节里。

我们把那些规则合并进了一个名为 Do Not Engage in Deceptive Campaigns or Artificial Activity 的新章节，它适用于任何形式的欺骗性活动（无论政治的还是商业的）。它涵盖那些试图掩盖消息背后是谁、或通过假账号与假帖子放大内容的企图，也包括为开展影响行动而搭建工具与基础设施。

### 重新聚焦我们的选举章节

我们在 Usage Policy 的每一个版本中都完善了对政治内容的限制，以确保我们的模型能在民主进程中被恰当使用。在这一版中，我们进一步收紧了关于选举的章节，专门聚焦于不允许用 Claude 欺骗选民或扰乱选举（例如散布关于候选人或投票方式的虚假信息、冒充候选人或选举官员，或试图压制投票率）。我们把它更名为 Do Not Undermine Democratic Processes，以体现这一范围。

出于类似的原因，我们还取消了对个性化投票与竞选定向的一概禁止。这项禁令此前覆盖的是正当的公民工作，例如非营利组织用 Claude 以其他语言为选民撰写信息，或选举官员发送选票补正通知。当初促使我们制定那条规则的行为（例如依赖欺骗、或滥用选民个人数据的选民定向），在欺骗性活动、监控和隐私章节下仍然被禁止。

### 澄清我们的武器禁令

我们的 Usage Policy 一贯禁止用 Claude 开发武器。近来，我们看到有人试图用我们的模型为武器构建制导与控制软件。更新后的章节明确说明，我们的禁令包括让武器得以运转的软件与部件，也包括为无人机和其他自主载具加装武器这类行为。这些变更反映的正是我们此前执行旧政策的方式。

### 用更精确的措辞表述监控与执法

我们 9 月的[威胁情报报告](https://www.anthropic.com/threat-intelligence-report-september-2026)记录了越来越多用 AI 构建监控系统、以识别并追踪政治异见者的情况。我们重写了监控与刑事司法章节，更精确地陈述我们禁止什么。例如，未经本人同意追踪他人是被禁止的，无论是实时追踪，还是通过对此前已收集的数据做分析来追踪。Claude 不能用于决定或建议在执法或刑事司法程序中该调查、逮捕或起诉谁。我们也禁止用 Claude 构建或改进为监控而设计的工具。

和上一次对武器禁令的更新一样，这次更新并不意味着我们在实践中执行的内容发生了变化：它只是想让政策更明确。新章节也写明了哪些用途仍然被允许，包括当事人同意的追踪（例如欺诈监控）、内容审核、新闻工作和法律研究。

### 高风险使用场景的要求更清晰

当我们的产品以可能影响某人健康、法律权利、财务、生计或获取基本服务的方式被使用时，我们要求必须有合格的“human in the loop”（即有权审阅并在必要时更改 Claude 建议的人），并要求告知受影响的个人其中使用了 AI。

这些要求并没有因 Usage Policy 的新版本而改变。不过，用户常常询问我们某个具体使用场景是否适用这些要求，因此我们重写了 High-risk Use Case Requirements 章节，以便更直接地回答这个问题。它现在列出了哪几类建议属于覆盖范围、哪些不属于。

在我们推出 [Model Hardware Standard](https://www.anthropic.com/news/model-hardware-standard-research-preview) 之后，该章节还补充了关于使用我们模型的要求：当模型接入能够自主采取物理行动、并有可能造成伤害的设备时，必须有合格的操作员能够观察该设备并在需要时将其停止；当 Claude 断开连接时，该设备还必须能够保持在一个安全状态。

### 应对针对我们模型的虐待行为

我们新增了一条禁令，禁止针对我们模型持续且无必要的虐待或残忍行为。这项政策更新只打算适用于极端情形，即用户反复对我们的模型施以残忍行为、且看不出任何可辨识的目的。它不适用于常见的用户沮丧表达、反对意见、黑暗的创意主题，也不适用于模型测试与研究。

这一新增内容与我们已经迈出的一步相一致：我们允许 Claude 模型在 Claude.ai 和 Claude Code 上[结束与持续施以虐待的用户之间为数不多的对话](https://www.anthropic.com/research/end-subset-conversations)。这类虐待行为正是本次更新的主要针对对象；Claude 结束这些交互的能力仍将是主要的执行手段。

### 澄清我们的 Supported Regions Policy

去年，我们[更新了 Supported Regions Policy](https://www.anthropic.com/news/updating-restrictions-of-sales-to-unsupported-regions)，对由总部位于我们不支持地区的实体多数持股的公司限制其访问 Claude。我们更新了 [Supported Regions 页面](https://www.anthropic.com/supported-countries)，以说明我们如何执行这项政策。我们的政策禁止身处不支持地区的人使用 Claude，禁止在该类地区注册或设立总部的实体使用，也禁止由这些地区的人或实体多数持股或控制的实体使用。

### 展望未来

随着 Claude 的能力与风险变化，我们会持续更新 Usage Policy。和本次以及此前的更新一样，我们会向 Anthropic 内部各方征求输入，也会向政策制定者、领域专家、公民社会以及使用我们产品的人征求输入。
