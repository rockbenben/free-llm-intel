Anthropic 正在加深对美国科学研究的支持，承诺在三年内向 [Genesis Mission](https://www.energy.gov/undersecretaryforscience/genesis-mission/genesis-mission) 提供 1.5 亿美元，这是一项通过人工智能加速科学和技术发现的联邦倡议。这笔资金将用于让参与该任务的超过 15 个机构能够使用 Claude，其中包括 NASA、美国国立卫生研究院和国家科学基金会。

我们首先宣布与美国能源部 (DOE) 和 Genesis Mission 建立合作伙伴关系 [去年 12 月](https://www.anthropic.com/news/genesis-mission-partnership)。从那时起，我们与美国能源部合作，将克劳德带到国家实验室的科学家们面前。今天，我们在华盛顿特区白宫科学技术政策办公室主办的科学：新黄金时代峰会上宣布了这一新承诺。

### 支持美国科学家

我们赞同政府在《科学：新黄金时代》(https://www.whitehouse.gov/science/) 中阐述的观点，即人工智能可以对科学发现产生深远而积极的影响，我们很高兴支持其支持美国科学家的努力。

联邦机构和国家实验室的研究人员致力于解决世界上一些最困难的科学问题。通过我们的承诺，我们的目标是帮助他们利用 Claude 来有意义地推进他们的工作。未来三年，我们将：

- 为数百个 Genesis Mission 研究项目提供 Claude、Claude Code 和 API 学分；
- 与机构和国家实验室在政府的首要科学优先事项上密切合作，包括聚变能源和量子计算；和
- 为创世纪任务项目的科学家提供培训、入职和技术支持，并帮助新加入创世纪任务的机构启动其第一个项目。

### 加速科学研究

这一承诺是我们支持科学研究的更广泛努力的一部分。今年早些时候，我们推出了 [Claude Science](https://claude.com/product/claude-science)，这是一个人工智能工作台，集成了研究人员最常用的工具和软件包，并为学术科学家[开放了 10,000 个免费和打折的 Claude 席位](https://www.anthropic.com/news/expanding-support-for-scientists)。我们还扩展了 [AI for Science](https://www.anthropic.com/news/ai-for-science-program) 计划，该计划为高影响力项目的研究人员提供学分，并启动了 [模型硬件标准](https://www.anthropic.com/news/model-hardware-standard-research-preview) 的研究预览，这是一个 AI 代理安全操作实验室仪器的共享规范。我们对创世任务的承诺是我们帮助世界各地研究人员的下一步。
