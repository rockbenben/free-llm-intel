# 从搜索结果到证据：DeepInfra 上的 NVIDIA Nemotron 3.5 Embed 与 Rerank

发布于 2026.10.21，作者 Aray Sultanbekova

![从搜索结果到证据：DeepInfra 上的 NVIDIA Nemotron 3.5 Embed 与 Rerank](https://deepinfra.com/blog/nvidia-nemotron-3.5-embed-rerank-release.png)

[NVIDIA Nemotron 3.5 Embed 与 Rerank](https://huggingface.co/blog/nvidia/nemotron-retriever-world-class-agentic-retrieval) 属于 [NVIDIA Nemotron Retriever](https://huggingface.co/collections/nvidia/nemotron-retriever) 系列，从第 0 天起就可在 DeepInfra 上使用。从今天开始，你可以通过 DeepInfra API 访问 [Embed 1B](https://deepinfra.com/nvidia/Nemotron-3.5-Embed-1B-BF16)、[Embed 8B](https://deepinfra.com/nvidia/Nemotron-3.5-Embed-8B-BF16) 和 [Rerank 8B](https://deepinfra.com/nvidia/Nemotron-3.5-Rerank-8B-BF16)，无需任何部署配置，按 token 计费。

企业级 agent 的上限，取决于它能检索到什么信息。一个客服 agent 需要政策 PDF 里的那一条具体条款。一个财务 agent 需要图表里包含的那个数字，而不是图表周围的文字。

传统的纯文本检索会漏掉嵌在表格、图表和复杂文档版式里的关键信息。Nemotron 3.5 Embed 帮助在文本与视觉内容中检索信息，而 Rerank 则为下游推理优先排出最相关的结果。

两者配合，可以帮助开发者构建检索管线，让 agent 拿到更有力的证据，同时更高效地使用它们的上下文与推理预算。

## Nemotron 3.5 Embed 与 Rerank 有哪些新东西？

Embed 和 Rerank 属于 NVIDIA Nemotron Retriever——一套开放的、在排行榜上名列前茅的模型集合，用于为 agent 构建检索系统；同系列还有 Nemotron 3.5 Parse，用于把复杂文档转成结构化的、可直接交给 agent 的内容。

**多模态 embeddings。** Nemotron 3.5 Embed 在文本、表格、图表、图像、示意图和文档页面之间创建统一的表示，因此即使答案是靠视觉方式表达的，agent 也能检索到信息。它有两种规模：1B 面向大规模下的效率，8B 面向以质量为重的检索，尤其是在 agentic 工作流中。

**为 agent 打造的 reranking。** Nemotron 3.5 Rerank 8B 依据 agent 的问题对检索到的段落打分，然后为推理模型优先排出最相关的证据。它支持会迭代检索、跨多个来源比较证据的 agent。

**更好的检索质量，更高效的 agent 工作流。** NVIDIA Nemotron 3.5 Embed 8B 在 dense retrieval 模型中领跑 [ViDoRe v3.1](https://mteb-leaderboard.hf.space/benchmark/ViDoRe%28v3.1%29) 排行榜；在 NVIDIA 的评估中，加上 Nemotron 3.5 Rerank 可使 agent 的推理成本最多降低 14%。

**开放且可定制。** 权重是开放的，NVIDIA 发布了 NeMo 后训练配方，用于把检索适配到你自己的术语、数据和相关性标准。

## 你可以构建什么

- **面向企业文档的 agentic RAG：** 从 PDF、演示文稿、扫描页、表格、图表和示意图中检索相关信息——而不只是抽取出来的文本。
- **多步研究 agent：** 支持查询改写、迭代检索，以及跨多个资源的证据比较。
- **agent 记忆与代码检索：** 从已存储的交互、技术文档和代码仓库中检索相关上下文，以支撑长时运行的工作流和编码 agent。

## 在 DeepInfra 上入门

从 [DeepInfra 控制台](https://deepinfra.com/dash/api_keys) 获取 API key，并将其设置为 DEEPINFRA_TOKEN。下面的示例用 Embed 1B 嵌入一个客服问题和四段段落，保留最接近的三段，再用 Rerank 8B 对它们重排。问题请把 input_type 设为 "query"，你要检索的内容则设为 "passage"。

```
import os

import numpy as np
import requests
from openai import OpenAI

TOKEN = os.environ["DEEPINFRA_TOKEN"]
EMBED = "nvidia/Nemotron-3.5-Embed-1B-BF16"
RERANK = "nvidia/Nemotron-3.5-Rerank-8B-BF16"

client = OpenAI(
    api_key=TOKEN,
    base_url="https://api.deepinfra.com/v1/openai",
)

query = "What is the refund window for annual plans?"
docs = [
    "Monthly plans can be cancelled at any time from the billing page.",
    "Annual plans can be refunded in full within 30 days of purchase.",
    "Enterprise contracts follow the terms in the signed order form.",
    "Invoices are emailed on the first business day of each month.",
]

# 1. Retrieve: embed the query and documents, keep the closest matches
q = client.embeddings.create(
    model=EMBED, input=[query], extra_body={"input_type": "query"}
)
d = client.embeddings.create(
    model=EMBED, input=docs, extra_body={"input_type": "passage"}
)
q_vec = np.array(q.data[0].embedding)
d_vecs = np.array([e.embedding for e in d.data])
similarity = d_vecs @ q_vec  # vectors are L2-normalized
candidates = [docs[i] for i in np.argsort(-similarity)[:3]]

# 2. Rerank: score each candidate against the query
resp = requests.post(
    f"https://api.deepinfra.com/v1/inference/{RERANK}",
    headers={"Authorization": f"Bearer {TOKEN}"},
    json={"queries": [query] * len(candidates), "documents": candidates},
)
for score, doc in sorted(zip(resp.json()["scores"], candidates), reverse=True):
    print(f"{score:.3f}  {doc}")
copy
```

**输出：**

```
-1.112  Annual plans can be refunded in full within 30 days of purchase.
-2.912  Monthly plans can be cancelled at any time from the billing page.
-3.290  Invoices are emailed on the first business day of each month.
copy
```

回答问题的那个段落排在第一位。Rerank 返回的是原始相关性分数，因此出现负值是正常的。

**提示：页面截图也能搜。** Embed 同样接受图像，所以用一句大白话就能检索到政策表格的截图：

![带有退款条款表格的政策页面](https://deepinfra.com/blog/nvidia-nemotron-3.5-embed-rerank-release-refund-policy.png)

```
import base64

with open("refund_policy_page.png", "rb") as f:
    page_b64 = base64.b64encode(f.read()).decode()

page = client.embeddings.create(
    model=EMBED,
    input=[[
        {"type": "image_url", "image_url": {"url": f"data:image/png;base64,{page_b64}"}},
    ]],
    extra_body={"input_type": "passage"},
)
page_vec = np.array(page.data[0].embedding)
print(f"{page_vec @ q_vec:.3f}")
copy
```

**输出：** 0.576（对比"如何重置密码？"的 0.110）
