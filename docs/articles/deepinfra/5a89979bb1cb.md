# 从搜索结果到证据：NVIDIA Nemotron 3.5 在 DeepInfra 上的嵌入和重新排名

发布于 2026.10.21 作者：Aray Sultanbekova

![从搜索结果到证据：NVIDIA Nemotron 3.5 在 DeepInfra 上的嵌入和重新排名](https://deepinfra.com/blog/nvidia-nemotron-3.5-embed-rerank-release.png)

[NVIDIA Nemotron 3.5 嵌入和重新排序](https://huggingface.co/blog/nvidia/nemotron-retriever-world-class-agentic-retrieval) 是 [NVIDIA Nemotron Retriever](https://huggingface.co/collections/nvidia/nemotron-retriever) 系列的一部分，从第 0 天开始在 DeepInfra 上提供。从今天开始，您可以访问 [Embed 1B](https://deepinfra.com/nvidia/Nemotron-3.5-Embed-1B-BF16)、[Embed 8B](https://deepinfra.com/nvidia/Nemotron-3.5-Embed-8B-BF16) 和 [Rerank 8B](https://deepinfra.com/nvidia/Nemotron-3.5-Rerank-8B-BF16) 通过DeepInfra API 无需部署设置和按代币付费定价。

企业代理的好坏取决于他们能够检索到的信息。支持代理需要政策 PDF 中的特定条款。财务代理需要图表中包含的数字，而不是周围的文本。

传统的纯文本检索可能会错过表格、图表和复杂文档布局中嵌入的关键信息。 Nemotron 3.5 Embed 可帮助检索文本和视觉内容中的信息，而 Rerank 会优先考虑最相关的结果以进行下游推理。

它们共同帮助开发人员构建检索管道，为代理提供更有力的证据，同时更有效地使用他们的上下文和推理预算。

## Nemotron 3.5 嵌入和重新排序中有哪些新功能？

Embed 和 Rerank 是 NVIDIA Nemotron Retriever 的一部分，NVIDIA Nemotron Retriever 是一系列开放的、荣获排行榜冠军的模型，用于为代理构建检索系统，而 Nemotron 3.5 Parse 则用于将复杂文档转换为结构化的、代理就绪的内容。

**多模态嵌入。** Nemotron 3.5 Embed 在文本、表格、图表、图像、图表和文档页面上创建统一的表示，因此即使答案以视觉方式表达，代理也可以检索信息。它有两种大小：1B 用于大规模效率，8B 用于注重质量的检索，特别是在代理工作流程中。

**为代理构建的重新排名。** Nemotron 3.5 Rerank 8B 根据代理的问题对检索到的段落进行评分，然后优先考虑与推理模型最相关的证据。它支持迭代检索并比较多个来源的证据的代理。

**更好的检索质量、更高效的代理工作流程。** NVIDIA Nemotron 3.5 Embed 8B 在密集检索模型中的 [ViDoRe v3.1](https://mteb-leaderboard.hf.space/benchmark/ViDoRe%28v3.1%29) 排行榜上处于领先地位，同时添加 Nemotron 3.5 Rerank 在 NVIDIA 评估中可将代理推理成本降低高达 14%。

**开放且可定制。** 权重是开放的，NVIDIA 发布了 NeMo 训练后配方，用于根据您自己的术语、数据和相关性标准调整检索。

## 你可以构建什么

- **对企业文档进行代理 RAG：** 从 PDF、演示文稿、扫描页面、表格、图表和图表中检索相关信息，而不仅仅是提取的文本。
- **多步骤研究代理：** 支持跨多个资源的查询重写、迭代检索和证据比较。
- **代理内存和代码检索：** 从存储的交互、技术文档和代码存储库中检索相关上下文，以支持长期运行的工作流程和编码代理。

## DeepInfra 入门

从 [DeepInfra 仪表板](https://deepinfra.com/dash/api_keys) 获取 API 密钥并将其设置为 DEEPINFRA_TOKEN。下面的示例使用 Embed 1B 嵌入一个支持问题和四个段落，保留三个最接近的，并使用 Rerank 8B 对它们重新排名。对于问题，将 input_type 设置为“query”；对于搜索内容，将 input_type 设置为“passage”。
```
import os

import numpy as np
import requests
from openai import OpenAI

TOKEN = os.environ["DEEPINFRA_TOKEN"]
EMBED = "nvidia/Nemotron-3.5-Embed-1B-BF16"
RERANK = "nvidia/Nemotron-3.5-Rerank-8B-BF16"

client = OpenAI(
    api_key=TOKEN,
    base_url="https://api.deepinfra.com/v1/openai",
)

query = "What is the refund window for annual plans?"
docs = [
    "Monthly plans can be cancelled at any time from the billing page.",
    "Annual plans can be refunded in full within 30 days of purchase.",
    "Enterprise contracts follow the terms in the signed order form.",
    "Invoices are emailed on the first business day of each month.",
]

# 1. Retrieve: embed the query and documents, keep the closest matches
q = client.embeddings.create(
    model=EMBED, input=[query], extra_body={"input_type": "query"}
)
d = client.embeddings.create(
    model=EMBED, input=docs, extra_body={"input_type": "passage"}
)
q_vec = np.array(q.data[0].embedding)
d_vecs = np.array([e.embedding for e in d.data])
similarity = d_vecs @ q_vec  # vectors are L2-normalized
candidates = [docs[i] for i in np.argsort(-similarity)[:3]]

# 2. Rerank: score each candidate against the query
resp = requests.post(
    f"https://api.deepinfra.com/v1/inference/{RERANK}",
    headers={"Authorization": f"Bearer {TOKEN}"},
    json={"queries": [query] * len(candidates), "documents": candidates},
)
for score, doc in sorted(zip(resp.json()["scores"], candidates), reverse=True):
    print(f"{score:.3f}  {doc}")
copy
```
**输出：**
```
-1.112  Annual plans can be refunded in full within 30 days of purchase.
-2.912  Monthly plans can be cancelled at any time from the billing page.
-3.290  Invoices are emailed on the first business day of each month.
copy
```
回答问题的段落出现在最上面。重新排名会返回原始相关性分数，因此预计会出现负值。

**提示：也搜索页面图像。** Embed 还接受图像，因此可以通过简单语言问题检索策略表的屏幕截图：

![表格中包含退款条款的政策页面](https://deepinfra.com/blog/nvidia-nemotron-3.5-embed-rerank-release-refund-policy.png)
```
import base64

with open("refund_policy_page.png", "rb") as f:
    page_b64 = base64.b64encode(f.read()).decode()

page = client.embeddings.create(
    model=EMBED,
    input=[[
        {"type": "image_url", "image_url": {"url": f"data:image/png;base64,{page_b64}"}},
    ]],
    extra_body={"input_type": "passage"},
)
page_vec = np.array(page.data[0].embedding)
print(f"{page_vec @ q_vec:.3f}")
copy
```
**输出：** 0.576（对比“如何重置密码？”的 0.110）
