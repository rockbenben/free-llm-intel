# Gemini 3.7 Flash：新增功能、基准测试和 API 指南

发布于 2026.11.17，作者 DeepInfra

![Gemini 3.7 Flash：新增功能、基准测试和 API 指南](https://deepinfrabldev.wpenginepowered.com/wp-content/uploads/2026/11/gemini-3-7-flash-model-overview-integration-guide-header.png)

[Gemini 3.7 Flash](https://deepinfra.com/google/gemini-3.7-flash) 是 Google 的 Flash 档推理模型。它以文本、图像、视频、音频和 PDF 文件为输入，输出文本，在 DeepInfra 上拥有 1,000,000 token 的上下文窗口。Google DeepMind 于 [2026 年 8 月 13 日](https://artificialanalysis.ai/articles/gemini-3-7-time-frontier)发布该模型，距 Gemini 3.6 Flash 约三周，并将其定位为面向编码和 agent 场景的主力模型。

这是一个闭源模型。DeepInfra 作为合作伙伴模型，通过 Google 的 API 提供服务，因此你可以用已经在用的同一个 OpenAI 兼容 endpoint、API key 和账单来调用它——就像调用 [DeepSeek-V4.1-Flash](https://deepinfra.com/deepseek-ai/DeepSeek-V4.1-Flash)、[GLM-5.3](https://deepinfra.com/zai-org/GLM-5.3) 和 [MiMo-V2.6-Flash](https://deepinfra.com/XiaomiMiMo/MiMo-V2.6-Flash) 等开放模型一样。DeepInfra 收费为每 100 万输入 token 0.75 美元、每 100 万输出 token 3.75 美元，与 Google 当前折扣后的标准价格相同。

此后 Google 又发布了更新的 Flash 版本。[Artificial Analysis](https://artificialanalysis.ai/models/gemini-3-7-flash) 现已将 Gemini 3.7 Flash 标记为 deprecated，并建议改用 Gemini 3.8 Flash。如果你已经在运行 3.7 Flash，或者想让它与开放模型同处一个 API 之下，本指南介绍它有哪些变化、基准表现如何、价格多少，以及如何调用。

模型字符串：**`google/gemini-3.7-flash`**

## 与 Gemini 3.6 Flash 相比有哪些变化

Gemini 3.7 Flash 沿用了 3.6 Flash 的 1M token 上下文和输入类型。变化在于 agentic 工作、每任务速度和价格。

**Agentic 编码（Google 报告数据）。** Google 的发布数据（经 [MindStudio 汇总](https://www.mindstudio.ai/blog/gemini-3-7-flash-benchmarks/)）显示，最大的提升出现在长程软件工程：DeepSWE 从 49% 升至 65.3%，FrontierCode 从 34.4% 升至 43.6%。Web Dev Arena 从约 1538 Elo 升至约 1588 Elo。

**Agent 与知识工作（独立评测）。** [Artificial Analysis](https://artificialanalysis.ai/articles/gemini-3-7-time-frontier) 把大部分提升归因于 agentic 评测：Terminal-Bench v2.1 提升 8 分，Tau3 Banking 提升 3 分，GDPval-AA v2 提升 103 Elo 至 1525，其 AA-Briefcase 知识工作评测提升 169 Elo 至 1132。

**每任务速度。** Artificial Analysis 在发布时测得约 340 输出 token/秒，在高推理强度下每个 Intelligence Index 任务平均耗时 1.7 分钟。这让 3.7 Flash 落在其「智能 vs. 每任务耗时」的帕累托前沿上。

**每任务成本。** 按 Google 的折扣价，Artificial Analysis 测得 Gemini 3.7 Flash（high）每个 Intelligence Index 任务 0.40 美元，比 Gemini 3.6 Flash 低 30%。在 medium 推理强度下，该数字降至 0.26 美元。

**推理强度档位。** Google 提供三档推理强度（high、medium、low），Artificial Analysis 对三档都做了基准测试。DeepInfra 对应的参数见 [Parameters](https://deepinfra.com/blog/gemini-3-7-flash-model-overview-integration-guide#parameters) 一节。

## 基准测试

### Google 报告数据：Gemini 3.7 Flash 对比 3.6 Flash

这些是 Google 发布时由厂商报告的数据，经由 [MindStudio 的文章](https://www.mindstudio.ai/blog/gemini-3-7-flash-benchmarks/)转引。

| 基准测试 | Gemini 3.6 Flash | Gemini 3.7 Flash |
| --- | --- | --- |
| DeepSWE（长程软件工程） | 49% | **65.3%** |
| FrontierCode | 34.4% | **43.6%** |
| Web Dev Arena（Elo） | ~1538 | **~1588** |
| AutomationBench | ~17% | **~30%** |

AutomationBench 的相对跃升最大，不过该模型在 Google 版本的这项测试中仍未能完成大多数任务。DeepSWE 则是最强的绝对成绩。

### Artificial Analysis 发布时数据（2026 年 8 月 13 日）

[Artificial Analysis](https://artificialanalysis.ai/articles/gemini-3-7-time-frontier) 在该模型发布前做了基准测试。这些分数来自 2026 年 8 月使用的 Intelligence Index 版本，与当前 index（v5.0.1）上的分数不可比——在后者上 Artificial Analysis 已不再报告该模型的分数。

| 指标（AA，2026 年 8 月） | Gemini 3.7 Flash |
| --- | --- |
| Intelligence Index，高推理强度 | 56（较 3.6 Flash +4） |
| Intelligence Index，medium / low 推理强度 | 53 / 51 |
| 输出速度 | ~340 tokens/s |
| 每个 Index 任务平均耗时（high） | 1.7 分钟 |
| 每个 Index 任务成本（high / medium，折扣价） | $0.40 / $0.26 |
| AutomationBench-AA | 62.7%（发布时最高） |
| AA-AnalystAgent，pass^5 | 60%（发布时最高） |
| AA-Briefcase | 1132 Elo |
| GDPval-AA v2 | 1525 Elo |

**领先之处与不足之处。** 发布时，Gemini 3.7 Flash 在 AA 的 AutomationBench-AA 上领先，超过 Kimi K3（53%）和 GPT-5.6 Sol（51.2%）；在 AA-AnalystAgent 上也领先，超过 Claude Opus 5（54%）和 Fable 5（49%）。在总体 Index 上，它略落后于 GPT-5.6 Terra 和 Muse Spark 1.2（均为 57）。在 GDPval-AA v2 上，其 1525 分与 GLM-5.2（1506）持平，低于 DeepSeek V4 Flash 0731（1558）。

AutomationBench-AA（62.7%）是 Artificial Analysis 自己版本的基准测试，因此与上文 Google 的 AutomationBench 数值并不对应。

### 如今的位置

Artificial Analysis 现在把 Gemini 3.7 Flash 列为 deprecated：它仍在对该模型做基准测试，但频率从每 6 小时改为每 18 小时，并指向 [Gemini 3.8 Flash](https://artificialanalysis.ai/models/gemini-3-8-flash)。其当前排行榜由 Claude Fable 5.2、Gemini 4 Carbon 和 Claude Opus 5.5 等闭源前沿模型领跑。Gemini 3.7 Flash 的强项是在 agentic 和文档类工作上的吞吐量与每任务价格，而不是那张表的顶端。

## 模态与上下文

| 规格 | DeepInfra 上的 Gemini 3.7 Flash |
| --- | --- |
| 输入 | 文本、图像、视频、音频、PDF |
| 输出 | 文本 |
| 上下文窗口 | 1,000,000 tokens |
| 推理 | 是（推理模型） |
| 特性 | OpenAI 兼容 API、JSON 模式、结构化输出、函数调用、OCR |
| 权重 | 专有（不提供 open-weight） |

PDF 和 OCR 支持使它成为文档密集型 agent 步骤的实用选择：读取合同、发票或幻灯片并返回结构化 JSON。这也与它在 AA-AnalystAgent 上的领先相吻合，该评测考查的是针对电子表格和文档的问答。

## 定价

定价截至 2026-11-17。[模型页面](https://deepinfra.com/google/gemini-3.7-flash)始终显示当前费率。

| 档位 | 输入 / 1M | 输出 / 1M | 缓存输入 / 1M |
| --- | --- | --- | --- |
| Standard | $0.75 | $3.75 | 未列出 |

- **与 Google 折扣价同价。** DeepInfra 的 $0.75 / $3.75 与 Google 在其自家 API 上提供的折扣标准价相同。Google 未折扣的标准价为 $1.50 / $7.50（[Artificial Analysis](https://artificialanalysis.ai/articles/gemini-3-7-time-frontier)）。
- **档位少于 Google 的 API。** Google 还提供缓存输入 90% 的折扣，以及半价的 Flex 和 Batch 档位，而 DeepInfra 对该模型一项都没列出。对于 prompt 高度重复的高吞吐批处理任务，Google 自家 API 更便宜。
- **DeepInfra 上没有 Flex 或 Priority。** DeepInfra 的 Flex（0.8×）和 Priority（1.5×）档位只适用于带这些标签的模型，而该模型不带。

DeepInfra 为该模型提供的是整合，而不是更低的价格。一个 API key、一张账单、一个 OpenAI 兼容客户端，既能用于 Gemini 也能用于开放模型。你不需要 Google Cloud 项目、第二个 SDK 或第二套账单关系。

### 一次 agent 步骤的成本

一个发送 20,000 输入 token、返回 2,000 输出 token 的文档抽取步骤，成本为：

- 输入：20,000 × $0.75 / 1M = $0.015
- 输出：2,000 × $3.75 / 1M = $0.0075
- **合计：每次调用 $0.0225**，或每 1,000 次调用 $22.50

推理 token 按输出计费，因此推理强度越高，算式里输出那一侧就越大。

## 快速上手

Gemini 3.7 Flash 使用 DeepInfra 的 [OpenAI 兼容 API](https://deepinfra.com/docs/openai_api)：

- **Base URL：** `https://api.deepinfra.com/v1/openai`
- **Endpoint：** `POST /chat/completions`
- **认证头：** `Authorization: Bearer $DEEPINFRA_API_KEY`（在[控制台](https://deepinfra.com/dash/api_keys)中创建 key）

该模型需要一个已登录账户和 API key；不提供匿名免费调用。

### 参数

完整 schema 见该模型的 [API 页面](https://deepinfra.com/google/gemini-3.7-flash/api)。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `model` | string | — | `google/gemini-3.7-flash` |
| `messages` | array | — | 聊天历史；支持多模态内容 |
| `reasoning_effort` | string | — | DeepInfra 接受 `none`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max`。取值越低，推理 token 和延迟越少 |
| `max_tokens` | integer | — | DeepInfra 未公布该模型的最大输出，因此长输出时请显式设置 |
| `temperature` | float | 0.7 | 采样温度 |
| `top_p` | float | 0.9 | 核采样 |
| `stream` | boolean | false | Server-sent events |
| `stop` | array | — | 最多 16 个停止字符串 |
| `n` | integer | 1 | 最多 4 个补全 |
| `presence_penalty` / `frequency_penalty` | float | 0 | −2 到 2 |
| `response_format` | object | `{"type": "text"}` | 结构化输出用 `json_object` 或 `json_schema` |
| `tools` / `tool_choice` | array / string | — | 函数调用：`none`、`auto` 或 `required` |
| `seed` | integer | random | 不保证确定性 |

`reasoning_effort` 属于 OpenAI SDK 的标准参数，因此可以直接传。在生产中选定某一档之前，先在自己的 prompt 上测试各档位，比较质量、延迟和输出 token 数。

### Python

```
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["DEEPINFRA_API_KEY"],
    base_url="https://api.deepinfra.com/v1/openai",
)

response = client.chat.completions.create(
    model="google/gemini-3.7-flash",
    messages=[
        {"role": "system", "content": "Extract fields as JSON."},
        {
            "role": "user",
            "content": "Invoice 4417 from Acme GmbH, dated 2026-10-02, total EUR 1,240.00. "
                       "Return invoice_number, vendor, date and total.",
        },
    ],
    reasoning_effort="low",
    response_format={"type": "json_object"},
    max_tokens=2048,
)

print(response.choices[0].message.content)
print(response.usage)copy
```

在 Gemini 3.7 Flash 与开放模型之间切换，只需改动 `model` 一行。这对成本和质量的 A/B 测试很有用，也适合[两层 agent](https://deepinfra.com/blog/two-tier-agent-two-models)：把机械性步骤交给更便宜的模型，把更难的步骤留给更强的模型。

### 输出限制

模型页面把最大上下文设为 1,000,000 tokens，输入和输出合并计算。DeepInfra 未说明该模型单独的最大输出，因此在预期长回答时请传 `max_tokens`，并检查 `finish_reason` 是否为 `"length"`，以捕捉被截断的响应。

## 结语

Gemini 3.7 Flash 相比 3.6 Flash，在 agentic 编码和文档工作上带来了实实在在的提升，发布时每任务速度也很快。Artificial Analysis 现在把用户引向更新的 Gemini 版本，因此它主要适合两种情况：你已经验证过它，或者需要它的 PDF、音频和视频输入与开放模型同处一个 API 之下。

在 DeepInfra 上，它的每 token 价格与 Google 的折扣价相同，并与你技术栈的其余部分共享一个 key、一张账单和一个客户端。如果缓存输入折扣或批处理定价对你的账单影响很大，请在决定前比较一下 Google 自家的 API。

**下一步**

- **为模型退役做规划。** 把模型 ID 放在配置里，并搭建一个评测来比较替代模型；参见[如何构建能在模型退役后存活的 LLM 应用](https://deepinfra.com/blog/model-deprecation-llm-apps)。
- **与开放模型搭配使用。** 把批量 agent 步骤路由到开放模型，把 Gemini 留给多模态或文档类步骤。我们的[最佳开源编码模型指南](https://deepinfra.com/blog/best-open-source-models-for-coding)比较了候选者。
- **试一试。** 打开 [Gemini 3.7 Flash 模型页面](https://deepinfra.com/google/gemini-3.7-flash)，创建 API key，运行上面的示例。
