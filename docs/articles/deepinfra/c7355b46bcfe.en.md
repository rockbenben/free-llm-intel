# Kimi K3.1 Pro: Model Overview, Benchmarks & API Guide

Published on 2026.11.17 by DeepInfra

![Kimi K3.1 Pro: Model Overview, Benchmarks & API Guide](https://deepinfrabldev.wpenginepowered.com/wp-content/uploads/2026/11/kimi-k3-1-pro-model-overview-header.png)

[Kimi K3.1 Pro](https://deepinfra.com/moonshotai/Kimi-K3.1-Pro) is Moonshot AI’s flagship open-weight model, [released on October 23, 2026](https://artificialanalysis.ai/models/kimi-k3-1-pro) and built for long-horizon agent work: coding, 3D creation, financial research and document-heavy tasks. It is a 2.8-trillion-parameter Mixture-of-Experts model with 104B parameters active per token, takes text and images as input, returns text, and has a [1,048,576-token context window](https://huggingface.co/moonshotai/Kimi-K3.1-Pro).

K3.1 Pro is not a new pre-training run. Moonshot [post-trained it from Kimi K3](https://www.kimi.ai/blog/kimi-k3-1-pro) “with substantially larger post-training compute” and large-scale reinforcement learning across hundreds of domains, and swapped K3’s full-attention layers for sparse attention to make long contexts cheaper to serve. It is the first model in the K3.1 series.

On DeepInfra the model runs behind an OpenAI-compatible API with zero data retention, JSON and structured output, function calling and image input. If you need a cheaper model for simpler agent steps, [DeepSeek V4.1 Flash-1017](https://deepinfra.com/deepseek-ai/DeepSeek-V4.1-Flash-1017) is on the same API. The model string is:

**`moonshotai/Kimi-K3.1-Pro`**

## What changed from Kimi K3

Moonshot’s claims below are vendor-reported unless marked otherwise.

### Post-training and coding

- **Long-horizon coding:** on Kimi Code Bench 3.0 Long-horizon, an internal Moonshot benchmark, K3.1 Pro scores 61.2 against K3’s 55.95 ([release post](https://www.kimi.ai/blog/kimi-k3-1-pro)).
- **Independent check:** on [LiveBench 2.0](https://livebench.ai/) (November 6, 2026 table), coding rises from 53.1 for Kimi K3 to 67.8, and long-horizon agentic work from 36.0 to 38.7. That is a real coding gain, though K3.1 Pro still sits mid-pack among open-weight models on LiveBench coding.

### Factual accuracy

- On Moonshot’s internal Kimi Hallu Bench Hard, the claim-level hallucination rate falls from 23.4% for K3 to 8.3%. Moonshot calls the benchmark a deliberate stress test, so the rate does not describe everyday error rates.

### Finance and business work

- Moonshot’s internal finance benchmarks improve by 7.2 points (financial modeling) and 11.6 points (financial research), and its Business Operation simulation scores about 4.2 times K3’s result. On the public OfficeQA Pro v2, K3.1 Pro scores 64.4, the top score in Moonshot’s table.

### Attention and long context

- K3.1 Pro replaces K3’s full-attention Gated MLA layers with **Gated DeepSeek Sparse Attention (Gated DSA)**: 24 of its 93 layers now use sparse attention with a top-k of 2,048 indexed tokens, and the other 69 use KDA linear attention. The point is cheaper long-context modeling at the full 1M window.

### Cyber capability, deliberately capped

- For the open-weight release, Moonshot removed cyber-related data from mid-training and RL. On its internal xdev-bench-hard, the unfiltered checkpoint solves 90.5% of tasks at pass@3; the released model solves 81.0%. Moonshot says K3.1 Pro’s offensive cyber capability remains behind frontier proprietary models.

### Price on DeepInfra

- [Kimi K3](https://deepinfra.com/moonshotai/Kimi-K3) is still listed at $2.85 input and $14.25 output per 1M tokens. K3.1 Pro’s promotional rate of $1.90 / $9.50 is a third lower on both, and K3.1 Pro adds a Flex tier.

| Flex (0.8×) | $1.52 | $7.60 | $0.152 |
| Priority (1.5×) | $2.85 | $14.25 | $0.285 |

**How the discounts stack.** The 5% promotion comes off list, and Flex takes a further 20% off the promotional rate: $1.90 × 0.8 = $1.52 input, $9.50 × 0.8 = $7.60 output. Priority applies 1.5× to the promotional rate. Cached input is 10% of the input rate in every tier. No end date has been published for the promotion.

**Against other providers.** On [Artificial Analysis’s provider benchmarks](https://artificialanalysis.ai/models/kimi-k3-1-pro/providers), DeepInfra’s $1.90 / $9.50 is the second-lowest input, output and blended price of the providers it measures, and the lowest of those that returned no errors: DeepInfra’s measured error rate is 0.0%, while the one cheaper endpoint (PrimaLabs, $1.80 / $9.00) failed 15.4% of requests. Most providers charge Moonshot’s own $2.00 / $10.00, and high-speed tiers run $4.00–$6.00 input and $20–$30 output. If response speed is your product, test DigitalOcean or Baseten, which measure around 200 and 183 tokens per second at the standard $2.00 / $10.00 rate against DeepInfra’s 47; for batch, agents and cost-sensitive work, the per-token gap compounds over long outputs.

**Flex** is the cheapest way to run the model if your work can wait. Send `"service_tier": "flex"`: when capacity is short, the request waits up to 10 minutes and then returns HTTP 429, and a rejected Flex request is not charged. Overnight evaluations, batch extraction and background agents are a good fit. The [Flex service tier announcement](https://deepinfra.com/blog/flex-service-tier) covers the details.

**Priority** (`"service_tier": "priority"`) is for traffic that should not queue. At $2.85 / $14.25 it costs more than Moonshot’s list price, so use it only where queueing costs you more than the premium.

**Caching** matters with a verbose model and long agent sessions: cached input costs $0.19 against $1.90 for fresh input. Use `prompt_cache_key` to route repeated prefixes to the same cache, and `prompt_cache_options` to keep it warm for longer (see [prompt cache retention](https://deepinfra.com/blog/prompt-cache-retention)).

For worked monthly cost scenarios, see the [Kimi K3.1 Pro pricing guide](https://deepinfra.com/blog/kimi-k3-1-pro-pricing-guide). Startups can apply for free credits through [DeepStart](https://deepinfra.com/deepstart).

## Getting started

The API is OpenAI-compatible:

- **Base URL:** `https://api.deepinfra.com/v1/openai`
- **Endpoint:** `POST /chat/completions`
- **Auth header:** `Authorization: Bearer $DEEPINFRA_API_KEY`

The full request schema is on the model’s [API page](https://deepinfra.com/moonshotai/Kimi-K3.1-Pro/api).

### Parameters

Model-specific parameters first. Send non-standard fields through `extra_body` in the OpenAI Python SDK.

| Parameter | Default | Notes |
| --- | --- | --- |
| `reasoning_effort` | model default | `none`, `minimal`, `low`, `medium`, `high`, `xhigh`, `max`. `"none"` turns thinking off. Moonshot’s benchmarks use `max`. Reasoning tokens bill as output |
| `reasoning` | — | Object form: `{"effort": "...", "enabled": true/false}` |
| `temperature` | 1 | Moonshot’s evaluations use 1.0 |
| `top_p` | 1 | Moonshot’s evaluations use 0.95 |
| `service_tier` | standard | `flex` (0.8×, may queue up to 10 min, then 429) or `priority` (1.5×) |
| `fail_fast` | false | Return 429 immediately instead of queueing |
| `models` | — | Up to 4 fallback models, tried in order if this one has no capacity |
| `prompt_cache_key`, `prompt_cache_options` | — | Share a prompt cache across requests; e.g. `{"ttl": "1h"}` |
| `model` | (required) | `moonshotai/Kimi-K3.1-Pro` |
| `messages` | (required) | Chat messages; user content can include images |
| `max_tokens` | min(context − input, 65,536) | Up to 943,718 |
| `stream` | false | Server-sent events |
| `stop` | — | Up to 16 sequences |
| `n` | 1 | Up to 4 |
| `top_k`, `min_p` | 0 | Optional sampling controls |
| `presence_penalty`, `frequency_penalty` | 0 | −2 to 2 |
| `response_format` | text | `json_object`, `json_schema` or `regex` |
| `tools`, `tool_choice` | — | OpenAI-style function calling |

### Python

```
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["DEEPINFRA_API_KEY"],
    base_url="https://api.deepinfra.com/v1/openai",
)

response = client.chat.completions.create(
    model="moonshotai/Kimi-K3.1-Pro",
    messages=[
        {"role": "system", "content": "You are a senior equity research analyst."},
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "Summarize the revenue trend in this chart and list three risks."},
                {"type": "image_url", "image_url": {"url": "https://example.com/revenue-chart.png"}},
            ],
        },
    ],
    temperature=1.0,
    top_p=0.95,
    max_tokens=32768,
    extra_body={
        "reasoning_effort": "high",  # none | minimal | low | medium | high | xhigh | max
        "service_tier": "flex",      # remove this line for the standard tier
    },
)

print(response.choices[0].message.content)
print(response.usage)copy
```

For short, well-defined steps such as classification, extraction or routing, start with `"reasoning_effort": "low"` or `"none"`. K3.1 Pro is verbose at high effort, and reasoning tokens are billed as output at $9.50 per 1M on the standard tier.

### Output limits

There is no 16,384-token output cap on this model. You can request up to **943,718 output tokens**. If you leave `max_tokens` unset, DeepInfra uses the smaller of 65,536 tokens and whatever remains of the 1,048,576-token window after your input. Input and output together must fit in that window.

Moonshot’s published results use `max` effort, and long agent runs at that setting can spend tens of thousands of tokens reasoning before the final answer starts. To get closer to Moonshot’s setup, set `max_tokens` explicitly above the 65,536 default, use `max` effort, and stream the response so long generations don’t hit client timeouts. Exact reproduction isn’t guaranteed, because Moonshot ran most benchmarks inside its own harnesses.

## Conclusion

Kimi K3.1 Pro has the highest Artificial Analysis Intelligence Index score among the 29 open-weight models of its size, and Moonshot’s own table puts it at or near the top on agentic, tool-using and document work. Its weak spots are clear too: closed models still lead on knowledge without tools, ProgramBench and cyber tasks, and it is verbose, so output tokens drive most of the bill.

That makes price per output token the number to watch. On DeepInfra, K3.1 Pro costs $9.50 per 1M output tokens at the current promotion, or $7.60 on Flex. That is below Moonshot’s list price and below the model it replaces, with a measured 0% error rate.
