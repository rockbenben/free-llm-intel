**Quick reference by priority**

- Lowest price per token among the providers in this guide: DeepInfra ($1.90 input / $9.50 output / $0.19 cached per 1M tokens; Flex $1.52 / $7.60)
- Fastest answers at list price: DigitalOcean or Baseten
- Fastest in this guide: Amazon Bedrock’s Highspeed variant, at twice the list price
- First-party features and apps: Moonshot AI
- One key with failover: OpenRouter

Kimi K3.1 Pro is Moonshot AI’s open-weight agentic model, [released October 23, 2026](https://www.kimi.ai/blog/kimi-k3-1-pro), with weights published on [Hugging Face](https://huggingface.co/moonshotai/Kimi-K3.1-Pro) in early November. It is a mixture-of-experts model with 2.8T total and 104B active parameters, natively multimodal (text and image in, text out) and a 1M-token context window. It was post-trained from Kimi K3 with much larger reinforcement-learning compute, and it replaces K3’s full-attention layers with Gated DeepSeek Sparse Attention for cheaper long-context serving. On Artificial Analysis’s Intelligence Index it scores 46, the highest of the 29 open-weight models of its size. It is also verbose and reasons for a long time before answering, so where you run it shapes both the bill and the wait.

This guide compares the ways to run Kimi K3.1 Pro on what decides the choice: price and pricing tiers, features, deployment model, and who each option suits. Each entry gets one line on measured speed. The full speed and latency comparison is in the [Kimi K3.1 Pro API benchmarks](https://deepinfra.com/blog/kimi-k3-1-pro-api-benchmarks), including time to first token versus time to first answer token, which for this reasoning model ranges from about 25 seconds to over two minutes. Speed, blended price and error rates come from [Artificial Analysis](https://artificialanalysis.ai/models/kimi-k3-1-pro/providers) (reasoning effort max, pulled 2026-11-17), which benchmarks 16 endpoints from 14 providers for this model. Rates and features come from each provider’s own pages. Pricing as of 2026-11-17.

## Hosted API Providers

### 1. DeepInfra

DeepInfra is the best pick when cost per token decides the choice and you want production reliability, service tiers and a path to dedicated capacity.

- **Current rates:** [$1.90 input / $9.50 output / $0.19 cached input](https://deepinfra.com/moonshotai/Kimi-K3.1-Pro) per 1M tokens, a 5% promotional discount on the $2.00 / $10.00 / $0.20 list price
- **Flex tier:** $1.52 / $7.60 / $0.152. Opt in with `"service_tier": "flex"`. A request waits up to 10 minutes for capacity, then returns HTTP 429, and a rejected Flex request is not charged ([how Flex works](https://deepinfra.com/blog/flex-service-tier))
- **Priority tier:** $2.85 / $14.25 / $0.285 with `"service_tier": "priority"`, for requests that can’t queue
- **Blended price (Artificial Analysis, 7:2:1):** $1.46, below every standard-price endpoint at $1.54 and every fast tier ($2.31 to $4.62). With the same weighting, Flex works out to about $1.17
- **Reliability:** 0.0% error rate in Artificial Analysis’s runs. DeepInfra is the cheapest endpoint Artificial Analysis measures with a 0% error rate
- **Context and output:** 1,048,576-token context; up to 943,718 output tokens per request. If `max_tokens` is unset, the default is the lesser of the remaining context and 65,536
- **Features:** OpenAI-compatible API, image input, tool calling, JSON mode and structured outputs (JSON schema and regex), `reasoning_effort` from `none` (thinking off) to `max`, prompt caching with `prompt_cache_key` and a configurable TTL, up to 4 fallback models per request
- **Deployment:** serverless per-token API, or a private endpoint on dedicated GPUs; zero data retention
- **Speed:** 46.9 tokens/s output on Artificial Analysis. If response speed is your product, test DigitalOcean or Baseten; for batch, agents and cost-sensitive work, the per-token gap compounds.

Kimi K3.1 Pro is verbose: Artificial Analysis counted 113M output tokens to run its Intelligence Index, against a class median of 104M. Output tokens, including reasoning tokens, therefore drive most of the bill, and DeepInfra’s $9.50 output rate ($7.60 on Flex) is where the saving shows. It suits background agents, document and finance pipelines, evaluation runs and any workload that can absorb a longer wait for a lower price. One thing to measure on your own traffic: DeepInfra’s cache hit rate on Artificial Analysis’s agentic workload was 92.6%, below the 98–100% several hosts reached. Cache-heavy agent loops should set `prompt_cache_key` and check the hit rate before projecting costs.

A first call with the OpenAI SDK:

```
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["DEEPINFRA_API_KEY"],
    base_url="https://api.deepinfra.com/v1/openai",
)

response = client.chat.completions.create(
    model="moonshotai/Kimi-K3.1-Pro",
    messages=[{"role": "user", "content": "Reconcile these two revenue tables and explain each difference."}],
    temperature=1.0,
    top_p=0.95,
    extra_body={"reasoning_effort": "high", "service_tier": "flex"},
)
print(response.choices[0].message.content)copy
```

The endpoint is `/chat/completions` and the auth header is `Authorization: Bearer $DEEPINFRA_API_KEY`. Full parameters are on the [Kimi K3.1 Pro API page](https://deepinfra.com/moonshotai/Kimi-K3.1-Pro/api).

### 2. Moonshot AI (Kimi API)

Moonshot’s own [Kimi API](https://platform.kimi.ai/) is the best pick when you want first-party access, the Highspeed variant, or the model inside Moonshot’s products.

- **Model names:** `kimi-k3.1-pro` and `kimi-k3.1-pro-highspeed` ([Moonshot release post](https://www.kimi.ai/blog/kimi-k3-1-pro))
- **Rates (Artificial Analysis):** $2.00 / $10.00 / $0.20 cached; Highspeed $4.00 / $20.00 / $0.20
- **Highspeed:** Moonshot says it delivers 2-3× the speed of K3.1 Pro
- **Products:** also available in Kimi.ai, Kimi Work and Kimi Code; zero data retention is available for API customers
- **Speed:** 31.0 tokens/s on Artificial Analysis for the standard endpoint (Highspeed: 69.4 tokens/s)

The first-party API gets new Moonshot features first, and the Highspeed variant is the simplest way to cut response time without leaving Moonshot. It costs more than DeepInfra on every token category, and Artificial Analysis measured an 8.0% error rate on the standard endpoint in its runs, so build in retries.

### 3. DigitalOcean

[DigitalOcean Serverless Inference](https://docs.digitalocean.com/products/inference/details/pricing/) is the best pick when users wait on every answer and you want to stay at Moonshot’s list price.

- **Rates:** $2.00 input / $10.00 output / $0.20 cache read per 1M tokens
- **Billing:** prepaid serverless credits; dedicated GPU inference billed per GPU-hour
- **Platform:** model catalog, Inference Router and agent tooling in one console
- **Speed:** 200.8 tokens/s and the lowest time to first answer token among standard-price endpoints on Artificial Analysis

DigitalOcean is the provider to test for chat UIs and interactive coding agents. It costs about 5% more per token than DeepInfra’s standard rate, and its pricing page lists only a Standard tier for this model.

### 4. Baseten

[Baseten’s Model API](https://www.baseten.co/library/kimi-k31-pro/) is the best pick when you want a fast per-token API now and dedicated deployments when volume grows.

- **Model:** Kimi K3.1 Pro, 1M context, text and image input
- **Rates (Artificial Analysis):** $2.00 / $10.00 / $0.20 cached
- **Deployment:** per-token Model API, plus dedicated deployments and engineering support for custom setups
- **Speed:** 183.0 tokens/s on Artificial Analysis, among the fastest at list price

Baseten suits product teams that expect to move from shared to dedicated capacity. Its per-token rates match Moonshot’s list price, so it costs more than DeepInfra per token.

### 5. Modal

[Modal’s Model APIs](https://modal.com/library/moonshot/kimi-k3-1-pro) are the best pick when you run K3.1 Pro inside coding agents and want low cost per finished task.

- **Rates:** $2.00 input / $0.20 cached input / $10.00 output per 1M tokens
- **API:** OpenAI-compatible, with native integrations for Claude Code, Codex, OpenCode and Hermes Agent
- **Inputs:** text and images, 1,048,576-token context
- **Cost per task:** $3.19 per Artificial Analysis Intelligence Index task, among the lowest measured, helped by a 100% cache hit rate
- **Speed:** 118.0 tokens/s on Artificial Analysis

Modal’s high cache hit rate means agent loops that resend long prefixes pay less per task than the list price suggests. Per token it charges Moonshot’s list rate, about 5% above DeepInfra’s.

### 6. Amazon Bedrock

[Amazon Bedrock](https://docs.aws.amazon.com/bedrock/latest/userguide/model-card-moonshot-ai-kimi-k3-1-highspeed.html) is the best pick when your workloads already run in AWS and you want the Highspeed variant under AWS governance.

- **Model:** Kimi K3.1 Pro Highspeed (`global.moonshotai.kimi-k3.1`), 1M context
- **Rates (Standard tier):** $4.00 input / $20.00 output / $0.20 cache read on the global profile; $4.40 / $22.00 / $0.22 on the US and India profiles; cache writes $5.00 per 1M tokens
- **Service tiers:** Flex at 0.5× and Priority at 1.75× the Standard rate
- **APIs:** OpenAI-compatible Chat Completions and Responses, plus Converse and Invoke; reasoning effort `none` to `max` (default `max`)
- **Speed:** 218.2 tokens/s on Artificial Analysis, among the fastest measured

Bedrock keeps data inside the AWS boundary, with regional profiles for US and India data residency. The standard rate is twice Moonshot’s list price for the Highspeed variant. Bedrock’s Flex tier brings it back to $2.00 / $10.00 for workloads that can wait, which is still above DeepInfra’s standard rate.

### 7. OpenRouter

[OpenRouter](https://openrouter.ai/moonshotai/kimi-k3.1-pro) is the best pick when you want one API key and automatic failover across the hosts that serve K3.1 Pro.

- **Model slug:** `moonshotai/kimi-k3.1-pro`
- **Hosts routed:** over 20 endpoints, DeepInfra among them, each at the host’s own price
- **Routing:** balanced, fastest or cheapest modes; you can pin a single host
- **Speed:** whatever the selected host delivers; OpenRouter adds a network hop but no compute of its own

OpenRouter lists some smaller hosts with lower prices than DeepInfra, served at a range of precisions. Pin a host if output consistency matters. Teams that settle on one host usually go direct for its full feature set, service tiers and support.

### 8. Featherless AI

[Featherless AI](https://featherless.ai/blog/kimi-k3-1-pro-is-live-on-featherless) is the best pick when you already use its OpenAI-compatible API for many open models and want K3.1 Pro on the same key.

- **Rates (Developer plan):** $2.00 input / $0.20 cached / $10.00 output per 1M tokens
- **Context:** 256K on the Developer plan; the full 1M window on a dedicated instance
- **Data:** no logging of prompts or completions
- **Deployment:** serverless API, or dedicated GPU clusters
- **Speed:** not tracked by Artificial Analysis for this model

The 256K window is a quarter of the model’s native context, which matters for whole-repository and long-document work. It fits teams consolidating many open models under one provider.

## About the License

Kimi K3.1 Pro ships under the [Kimi K3.1-Pro License](https://huggingface.co/moonshotai/Kimi-K3.1-Pro), a custom license that allows commercial use with conditions. Model-as-a-service operators with group revenue above $20 million over any 12 months need a separate agreement with Moonshot, and products with over 100 million monthly active users or over $20 million monthly revenue must display “Kimi K3.1-Pro” in their interface. The license names exemptions for internal use and for some access routes. Read the full text, or ask your provider, if either threshold could apply to you.

## Final Thoughts

- **Lowest price per token in this guide:** DeepInfra, at $1.90 / $9.50 / $0.19, $1.46 blended on Artificial Analysis, and Flex at $1.52 / $7.60 for async work
- **Lowest price with a 0% measured error rate:** DeepInfra
- **Fastest answers at list price:** DigitalOcean or Baseten
- **Fastest in this guide:** Amazon Bedrock’s Highspeed variant, at $4.00 / $20.00
- **Low cost per agentic task:** Modal, helped by a 100% cache hit rate
- **First-party features and apps:** Moonshot AI
- **One key, automatic failover:** OpenRouter
- **One key across a large open-model catalog:** Featherless AI

### The Best Overall Solution

For most teams running Kimi K3.1 Pro as an API, [DeepInfra](https://deepinfra.com/moonshotai/Kimi-K3.1-Pro) is the default choice. It has the lowest price of the providers in this guide at $1.90 input and $9.50 output, and a Flex tier at $7.60 output for anything that can wait. It is the cheapest endpoint Artificial Analysis measures with a 0% error rate, it serves the full 1M context with up to 943K output tokens, and it offers zero data retention and private endpoints, all on an OpenAI-compatible API you can switch to by changing a base URL.
