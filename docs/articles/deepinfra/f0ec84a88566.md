# Wan 3.0 定价指南：阿里巴巴 vs OpenRouter vs DeepInfra

DeepInfra 发布于 2026.10.20

![Wan 3.0 定价指南：阿里巴巴 vs OpenRouter vs DeepInfra](https://deepinfrabldev.wpenginepowered.com/wp-content/uploads/2026/10/wan-pricing-guide.png)

[Wan3.0](https://deepinfra.com/Wan-AI/Wan3.0-Video) 的价格随你在哪里购买而差异巨大。作为模型创造者的阿里云，在新加坡以外地区的标价为每秒 $0.041256 起。OpenRouter 在 480p 下的标价为每秒 $0.0425 起。DeepInfra 将 Wan3.0-Video 标为每秒 $0.20，并接受参考图像、视频、音频、文件和网页。

阿里巴巴和 OpenRouter 是更便宜的入口。而对多模态、文档密集的工作流来说，DeepInfra 更宽的请求 schema 更容易被证明划算。

## **Wan3.0 执行摘要**

阿里云按区域为 Wan3.0 定价。其新加坡标价在 480p、720p 和 1080p 下分别为每秒 $0.05、$0.10 和 $0.20。其美国、德国、日本和中国区域统一标价为 $0.041256、$0.082513 和 $0.165025。OpenRouter 将 Wan 3.0 在 480p 下标为每秒 $0.0425 起，这意味着在同样的 15% 折扣下，720p 约为 $0.085、1080p 约为 $0.17。DeepInfra 则不论档位，统一标价每秒 $0.20。

在正式投入之前，比较不同代际同样重要。OpenRouter 将 Wan 2.6 text-to-video 标为每秒 $0.04 起，而 DeepInfra 的 Wan2.6 text-to-video 模型为每秒 $0.10。

| **最适合** | **提供商** | **原因** |
| --- | --- | --- |
| 新加坡以外的最低标价 | Alibaba Cloud, wan3.0-video | 美国、德国、日本和中国区域标价为每秒 $0.041256 至 $0.165025 |
| 文档密集或输入复杂度高的工作流 | DeepInfra, Wan-AI/Wan3.0-Video | 通过一个 media 数组接受参考图像、视频、音频、文件和网页 |
| 可见的延迟与可用性数据 | OpenRouter, alibaba/wan-3.0 | 为其单一路由提供商公布延迟和可用性 |
| 具备生产管控的托管接入 | DeepInfra, Wan-AI/Wan3.0-Video | 上架一个公开的 Partner 模型，带分辨率、时长、水印、prompt 扩展和 seed 控制 |

## **Wan3.0 如何计费**

视频模型并不遵循语言模型所用的 [token 定价](https://deepinfra.com/blog/pricing-101-token-math-cost-per-completion)。你购买的是生成视频的秒数，而价格会随提供商的打包方式和分辨率而变化。

### **什么在推高账单**

- 你生成的秒数
- 你选择的分辨率档位，多数提供商对不同档位分别定价
- 你使用的提供商和区域
- 当片段未达目标时，你需要的重新生成次数

| **计费因素** | **它是什么** | **为什么重要** |
| --- | --- | --- |
| 输出视频秒数 | 生成片段的时长 | 这是三家提供商共同的主要成本驱动因素 |
| 分辨率档位 | 480p、720p 或 1080p 输出 | 阿里巴巴和 OpenRouter 的费率随分辨率变化，所以 480p 的草稿只占最终渲染成本的一小部分 |
| 区域 | 由哪个阿里云区域处理请求 | 新加坡价格比其他五个已列出区域高出约 20% |
| prompt 与媒体输入 | 文本、图像、参考视频、参考音频、文件和链接 | 三份标价都没有对输入单独收取 token 费用 |
| 重新生成 | prompt 未命中或出现质量问题后的额外付费生成 | 如果片段需要频繁重跑，更低费率也可能花更多钱 |

## **按提供商的实用成本建议**

### **阿里云适合追求最低标价**

在新加坡以外，阿里巴巴自己的费率在每个分辨率档位上都低于 OpenRouter 和 DeepInfra。能把请求路由到美国、德国、日本或中国区域的团队，可以拿到最便宜的标价，而且没有中间商。

### **OpenRouter 适合最便宜的路由秒**

在网关选项中，OpenRouter 在 480p 下拥有最低标价，并且公布延迟和可用性数据，这对成本受控的 prompt 迭代有帮助。

### **DeepInfra 适合流水线繁重的工作负载**

如果一个 endpoint 就能接参考图像、参考音频、文件或网页，你需要的外围服务就更少。每秒费率更高，但整个工作流的总成本仍可能更低。

### **分辨率纪律很重要**

在 1080p 下测试 prompt，会把小实验变成预算项目。更稳妥的做法大致如下：

- 尽可能在 480p 下打草稿。
- 验证运动与内容。
- 只对入选片段以更高分辨率重跑。

节省幅度取决于提供商。阿里巴巴和 OpenRouter 的费率随分辨率下降，而 DeepInfra 是单一费率，所以在 DeepInfra 上用 480p 打草稿省的是时间，不是钱。

### **重新生成是隐性成本**

OpenRouter 公布的延迟和可用性，有助于你估算不稳定运行的成本。每次未命中都消耗生成时间，每个重新提交的任务都会拖慢流水线。

### **输入复杂度会改变成本账**

传文档、URL、音频参考和混合媒体的团队，能从 DeepInfra 更宽的请求 schema 中获益，它可以省掉胶水代码。只发送 prompt 和偶尔一张首帧图像的团队，则更容易为阿里巴巴或 OpenRouter 的更低价率辩护。

### **把 token 成本当作渲染成本**

对语言模型来说，成本跟随 prompt 和 completion 的长度。对 Wan3.0 来说，更贴切的心智模型是渲染。每个额外的秒、每个更高的分辨率、每次不必要的重跑，都会加到账单上。

## **用 DeepInfra 跑 Wan3.0**

DeepInfra 将 Wan-AI/Wan3.0-Video 定价为每生成秒 $0.20。它把这个模型定位为高端且灵活的视频 endpoint，而不是大宗渲染 API。

该平台运行在美国数据中心的裸金属基础设施上，并拥有 SOC 2 和 ISO 27001 认证。零保留政策覆盖输入和输出。

DeepInfra 也托管价格更低的视频模型以应对较轻的任务，包括每秒 $0.10 的 [Wan2.6 text-to-video](https://deepinfra.com/Wan-AI/Wan2.6-T2V) 和每秒 $0.15 的 [Google Veo 3.1 Fast](https://deepinfra.com/google/veo-3.1-fast)。针对某个语言模型的 [DeepInfra 与阿里巴巴定价对比](https://deepinfra.com/blog/qwen3-8-27b-pricing-deepinfra-vs-alibaba) 展示了两个平台在同一模型上的差异。

## **面向开发者的真实成本场景**

每个场景都使用 DeepInfra 的每秒 $0.20 费率。OpenRouter 的数字使用其每秒 $0.17（1080p）和 $0.0425（480p）费率。阿里云的数字使用其新加坡以外的 1080p 费率，即每秒 $0.165025。

### **场景 1：URL 到视频的讲解流水线**

一个内部工具把产品页、文档和发布 URL 变成简短的讲解片段。DeepInfra 上的 Wan3.0 可以直接解析网页、文件和复杂图像，因此许多请求能跳过单独的抽取层。

- 量级：每月 200 个视频，每个 10 秒，即 2,000 输出秒
- DeepInfra：2,000 秒 × 每秒 $0.20 = $400
- OpenRouter：1080p 下 $340，480p 下 $85
- 阿里云：新加坡以外 1080p 下 $330.05，新加坡则为 $400

这个场景适合那些接收用户提供的原始链接、上传简报或混合参考素材的应用。

### **场景 2：角色一致的营销视频**

一个团队需要跨活动复用的短片，要求角色、风格和声音提示保持一致。DeepInfra 通过一个 endpoint 支持参考图像、参考视频、参考音频和编辑工作流。

- 量级：每月 120 个视频，每个 15 秒，即 1,800 输出秒
- DeepInfra：1,800 秒 × 每秒 $0.20 = $360
- OpenRouter：1080p 下 $306，480p 下 $76.50
- 阿里云：新加坡以外 1080p 下 $297.05，新加坡则为 $360

当一致性比最便宜的草稿更重要时，DeepInfra 更高的费率就值回来了。

### **场景 3：可复现输出的创意工具**

面向开发者的视频 API 或创意 copilot 需要可控的重跑。DeepInfra 暴露 seed、时长、分辨率、水印和 prompt 扩展控制，以实现可重复的重新生成。

- 量级：每月 500 个视频，每个 5 秒，即 2,500 输出秒
- DeepInfra：2,500 秒 × 每秒 $0.20 = $500
- OpenRouter：1080p 下 $425，480p 下 $106.25
- 阿里云：新加坡以外 1080p 下 $412.56，新加坡则为 $500

这个场景适合开发者希望有标准化生成设置的 SaaS 产品。

### **场景 4：媒体密集型素材转换服务**

一个服务接收客户媒体包，其中包含作为文件的简报、参考片段、声音提示和一组图像。DeepInfra 在一个模型接口中处理 reference_audio、reference_video、reference_image、file 和 link 输入。

- 量级：每月 80 个视频，每个 20 秒，即 1,600 输出秒
- DeepInfra：1,600 秒 × 每秒 $0.20 = $320
- OpenRouter：1080p 下 $272，480p 下 $68
- 阿里云：新加坡以外 1080p 下 $264.04，新加坡则为 $320

在这里，DeepInfra 更高的费率最容易辩护，因为它替代了预处理步骤和服务之间的格式交接。

### **场景 5：带音频的生产级批量生成**

每月稳定的短片批量任务带生成音频，需要一个 endpoint 既能跑今天只有 prompt 的任务，又能跑之后媒体引导更丰富的任务。DeepInfra 的默认音频和宽泛输入设计简化了这种迁移。

- 量级：每月 300 个视频，每个 8 秒，即 2,400 输出秒
- DeepInfra：2,400 秒 × 每秒 $0.20 = $480
- OpenRouter：1080p 下 $408，480p 下 $102
- 阿里云：新加坡以外 1080p 下 $396.06，新加坡则为 $480

这个场景适合预期从基于 prompt 的生成转向参考素材繁多的生成的团队。

### **这些场景说明了什么**

在每个场景的 1080p 下，阿里云的非新加坡区域都给出最低成本，因为没有中间商加价。DeepInfra 在 Wan3.0 上的强项是输入范围和生产管控，而不是最低的每秒价格。

只需要纯 text-to-video 或简单 image-to-video 的应用，仅凭渲染成本就能为阿里巴巴或 OpenRouter 的费率辩护。需要参考音频、参考视频、文件解析、网页摄取、编辑、复刻或驱动的应用，往往发现 DeepInfra 尽管费率更高却更实用。

一种拆分式工作流能显示差距。假设做 100 个 10 秒的草稿和 10 个 10 秒的最终稿。全部在 DeepInfra 上跑要用 1,100 秒，花费 $220。在 OpenRouter 上以 480p 打草稿，1,000 秒花 $42.50，再用 DeepInfra 跑 100 个最终秒花 $20，合计 $62.50。

## **结论**

Wan3.0 的核心决策不止取决于每秒价格，还取决于提供商内建的工作流假设。阿里云和 OpenRouter 提供更低的入门费率，而 OpenRouter 公布延迟和可用性数据，这在快速迭代且成本优先时很有帮助。DeepInfra 提供更丰富的输入面和生产管控，当流水线从 prompt 加图像走向参考视频、音频、文件或网页时，这些就变得重要。更大规模的[推理成本](https://deepinfra.com/blog/inference-economics-ai-costs-at-scale)遵循同样的逻辑。

在投入之前权衡四个因素：输入复杂度、预期重新生成率、分辨率纪律，以及直连阿里云是否契合你的区域和速率限制需求。每个草稿都默认 1080p，会在任何提供商上迅速改变成本结构。

如果你的工作流已准备好上生产，并且需要全套参考输入，DeepInfra 的 Wan-AI/Wan3.0-Video 是一个实用的起点。如果你的输入更简单且价格优先，请在投入前把阿里巴巴自己的区域费率与 OpenRouter 做比较。
