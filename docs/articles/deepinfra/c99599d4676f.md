# Qwen3.8-27B 现已上线 DeepInfra

Qwen 团队最新的开放权重发布 Qwen3.8-27B 是一个 270 亿参数的视觉-语言模型。它在大多数模型容易栽跟头的任务上深入发力：多步骤智能体工作流、软件工程，以及跨图像、文档与视频的多模态推理。在 SWE-bench Pro 上，它得到 61.7 分，超过 Opus4.6 Max 的 53.4。在 QwenSWEBench 上，它从上代的 49.3 跳到 79.0——这样的差距很难被解读为渐进式进步。

对生产使用而言，Qwen3.8-27B 特别有意思的地方在于它的混合架构：64 层，将 Gated DeltaNet 线性注意力与标准门控注意力混合。它搭配了 262,144 token 的原生上下文窗口，通过 YaRN RoPE 缩放可扩展至一百万 token。Thinking 模式默认开启，但可按请求完全控制，并通过 reasoning_effort 调节推理深度。你可以在不换模型的情况下，用深度思考换取快速响应。视觉-语言基准也体现了同样的趋势：OSWorld-Verified 达到 84.3，领先于 Qwen3.6-27B 的 63.9 和 Qwen3.7-Plus 的 73.3。

[模型现已在 DeepInfra 上线](https://deepinfra.com/Qwen/Qwen3.8-27B)。

## **这款模型有何不同**

Qwen3.8-27B 是一个 27B 参数的稠密视觉-语言模型，但它的架构不是标准 transformer。它在 64 层中采用线性注意力与全注意力混合的设计：16 个重复块，每块为 3 x（Gated DeltaNet 接 FFN）后跟 1 x（Gated Attention 接 FFN）。四分之三的层使用线性注意力，即 Gated DeltaNet，V 用 48 个头、QK 用 16 个头。四分之一使用标准门控注意力：24 个 Q 头、4 个 KV 头、head dimension 256。这种布局在长上下文效率与全注意力的表达力之间取得平衡，而不是倒向其中一边。原生上下文长度为 262,144 token，通过 YaRN RoPE 缩放可扩展至 1M。

相对 Qwen3.5-27B 和上一代 Qwen3.6-27B，其提升十分显著，尤其在编码与智能体任务上：

| **基准** | **Qwen3.8-27B** | **Qwen3.6-27B** | **变化** |
| --- | --- | --- | --- |
| **SWE-bench Pro** | 61.7 | 53.5 | +8.2 |
| **DeepSWE 1.1** | 42.2 | 13.3 | +28.9 |
| **QwenSWEBench** | 79.0 | 49.3 | +29.7 |
| **LiveCodeBench v6** | 90.3 | 83.9 | +6.4 |
| **OSWorld-Verified** | 84.3 | 63.9 | +20.4 |
| **IFBench** | 79.5 | 69.1 | +10.4 |

DeepSWE 与 QwenSWEBench 的跳升（分别 +28.9 和 +29.7）尤为突出。这些是真实世界的软件工程任务基准，不是合成推理评测。

多模态方面，Qwen3.8-27B 原生处理图像和视频输入，包括 STEM 图表、文档和小时级视频。视觉基准反映了这里真实的能力：OSWorld-Verified 84.3（Opus4.6 Max 为 72.7）、AndroidWorld 81.9，以及不使用代码解释器的 MathVision 90.0。这些分数让它在若干 GUI 与视觉智能体任务上领先于更大的闭源模型。你可以结合 [DeepInfra 上的其他多模态模型](https://deepinfra.com/Qwen/Qwen3-VL-235B-A22B-Instruct)探索其多模态能力。

更实用的特性之一是灵活的 thinking 控制。Thinking 模式默认开启，但可以按请求切换。推理深度可通过 reasoning_effort（xhigh、medium、low）调节，此前轮次的推理上下文可用 preserve_thinking 保留。这让你在推理时对延迟与质量的权衡拥有明确控制，而无需单独的模型 checkpoint。

该模型以 BF16/Safetensors 格式发布，兼容 vLLM、SGLang、TokenSpeed 和 Hugging Face Transformers。Hugging Face 上已有大量且不断增长的社区量化版本，为低显存部署做适配很直接。

## **在 DeepInfra 上开始使用**

[Qwen3.8-27B](https://deepinfra.com/Qwen/Qwen3.8-27B) 已作为公开 API endpoint 在 DeepInfra 上提供。定价按用量计：输入 token 为 $0.15 / 1M token，输出为 $1.875 / 1M token，缓存 token 为 $0.038 / 1M token。平台上还提供 Priority 和 Flex 层级。262,144 token 上下文窗口、function calling、JSON 输出、多模态（图像和视频）输入都开箱即用。如需专用容量，可通过 [DeepInfra dashboard](https://deepinfra.com/dash/deployments?new=custom-llm&base_model=Qwen%2FQwen3.8-27B) 部署私有 endpoint。

DeepInfra 通过 OpenAI 兼容 API 提供 Qwen3.8-27B：无需搭建基础设施，无需管理模型权重，除了拿一个 API key 之外没有任何额外配置。完整的 [API 文档](https://deepinfra.com/Qwen/Qwen3.8-27B/api)覆盖所有可用参数，包括 reasoning_effort 和 preserve_thinking 字段。DeepInfra 实行零数据保留政策，并通过了 SOC 2 和 ISO 27001 认证。

下面是你的第一次调用：

```
from openai import OpenAI

client = OpenAI(
    api_key="$DEEPINFRA_TOKEN",
    base_url="https://api.deepinfra.com/v1/openai",
)

response = client.chat.completions.create(
    model="Qwen/Qwen3.8-27B",
    messages=[{"role": "user", "content": "Explain the difference between linear attention and standard attention."}],
)
print(response.choices[0].message.content)

import OpenAI from "openai";

const openai = new OpenAI({
  apiKey: "$DEEPINFRA_TOKEN",
  baseURL: "https://api.deepinfra.com/v1/openai",
});

const response = await openai.chat.completions.create({
  model: "Qwen/Qwen3.8-27B",
  messages: [{ role: "user", content: "Explain the difference between linear attention and standard attention." }],
});
console.log(response.choices[0].message.content);

curl "https://api.deepinfra.com/v1/openai/chat/completions" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $DEEPINFRA_TOKEN" \
  -d '{
      "model": "Qwen/Qwen3.8-27B",
      "messages": [
        {
          "role": "user",
          "content": "Explain the difference between linear attention and standard attention."
        }
      ]
    }'copy
```

相对任何现有 OpenAI 客户端配置，唯一需要替换的是 base URL (https://api.deepinfra.com/v1/openai)、你的 DeepInfra token 和模型名。其他一切——流式输出、工具调用、结构化输出——用法完全相同。

如果想在接入流水线之前先试试模型，Qwen3.8-27B 模型页上的实时 demo 可以让你直接在浏览器里运行它。想更广泛地了解可用模型，完整的[模型目录](https://deepinfra.com/models?type=text-generation)在评估替代方案或搭建多模型流水线时很有用。如果想和上一代对比，[Qwen3.5-27B API 文档](https://deepinfra.com/Qwen/Qwen3.5-27B)在参数结构和特性支持方面值得一看。

## **结论**

Qwen3.8-27B 代表着开放权重模型在进步通常最慢的领域迈出的实质性一步：真实软件工程任务、长上下文多模态推理，以及要求可靠性与灵活性的智能体工作流。混合注意力架构与可调推理深度意味着你不会被锁死在单一性能形态上。在同一个模型内，既可以为复杂任务追求最高质量，也可以用推理深度换更低延迟。

这让 Qwen3.8-27B 成为自主编码智能体、基于文档的流水线与 GUI 自动化系统的合理起点——这些场景此前需要闭源的更大规模模型。如果这与你在构建的东西契合，Qwen3.8-27B demo 是快速感受这个模型的方式。更广泛的 [Qwen 模型家族](https://deepinfra.com/qwen)值得在生产工作负载中探索。
