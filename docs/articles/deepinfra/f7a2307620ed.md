# DeepInfra 上的 Kimi K3.1 Pro：定价、基准和 API

DeepInfra 发布于 2026.11.17

![DeepInfra 上的 Kimi K3.1 Pro：定价、基准测试和 API](https://deepinfrabldev.wpenginepowered.com/wp-content/uploads/2026/11/kimi-k3-1-pro-deepinfra-header.png)

根据 [Kimi K3.1 Pro 型号卡](https://huggingface.co/moonshotai/Kimi-K3.1-Pro)（供应商报告），Moonshot AI 的 Kimi K3.1 Pro 在 BrowseComp（92.1）和 Humanity's Last Exam with tools（70.0）上的自己的比较表中获得最高分，领先于 Moonshot 测试的封闭边界模型。独立测试支持了标题：[人工分析](https://artificialanalysis.ai/models/kimi-k3-1-pro) 在其智能指数 v5.0.1 中给出了 46 分，是同等规模的 29 个开放权重模型中最高的，而班级中位数为 23。

Moonshot于2026年10月23日发布了K3.1 Pro，并于11月初公布了权重。它是一个 2.8 万亿参数的专家混合模型，具有 104B 个活动参数、1M 代币上下文窗口和本机图像输入。它专为长期代理工作而构建：编码代理、浏览和研究，以及财务、法律和电子表格工作等文档繁重的办公任务。

[Kimi K3.1 Pro 现已在 DeepInfra 上发售](https://deepinfra.com/moonshotai/Kimi-K3.1-Pro)，每 100 万个输入代币 1.90 美元，每 100 万个输出代币 9.50 美元，目前有 5% 的促销。这低于 Moonshot 自己的 API 标价 2.00 美元/10.00 美元，而 Flex 层将产出降至 7.60 美元。 Artificial Analysis 还在 DeepInfra 的端点上记录了 0% 的错误率。

K3.1 Pro 在使用工具的代理任务方面表现最强。它在 BrowseComp、带有工具的 HLE、AutomationBench、长时间运行的软件工作（SWE Marathon）和办公文档 QA 方面名列前茅。在Moonshot自己用工具进行的内部幻觉测试中，其错误率从Kimi K3的23.4%下降到了8.3%。

它并不是在所有地方都获胜。 Claude Opus 5.5 在 Terminal-Bench 4.0（66.4 vs 65.7）和计算机使用（OSWorld V2.1）方面处于领先地位，并且封闭模型在无工具推理（HLE-Full 和 HLE-Diamond）以及网络安全方面遥遥领先，Moonshot 表示它从开放权重版本中删除了网络训练数据。在开放权重模型中，DeepSeek-V4.1-Flash-1017 在 DeepSWE v1.1 上击败了它（77.0 vs 75.5）。 Moonshot 运行了上述所有数字，并且模型卡还包含其他人无法重现的内部基准测试；这些都被排除在此处的表格之外。

## 这个模型有何不同

Kimi K3.1 Pro是K3.1系列的首款机型。 Moonshot 使用跨数百个领域的大规模联合强化学习，通过“大幅增加的训练后计算”对 Kimi K3 进行了后训练。这就是 K3 的大部分收益的来源。

该架构是一个稀疏的专家混合体：2.8T 总参数、104B 活跃、896 个专家（每个代币选择 16 个专家）加上 2 个共享专家，跨 93 层。每个令牌所涉及的权重都低于 4%，因此您可以通过对每个令牌进行小得多的计算来获得非常大的模型的容量。

### 对长上下文的稀疏关注

K3 的架构变化之一是注意力。 K3.1 Pro 用 Gated DeepSeek Sparse Attention (Gated DSA) 取代了 K3 的全注意力 Gated MLA 层。该模型现在混合了 69 个 KDA 层和 24 个门控 DSA 层，这使得长上下文建模更便宜。这在 1M 令牌上下文中很重要，其中长代理跟踪和大型文档集会快速增加。

### 原生视觉

K3.1 Pro 可以拍摄图像和文本。 401M 参数的 MoonViT-V2 视觉编码器直接向语言模型提供数据。当模型还可以运行 Python 时，Moonshot 的图表、文档和多模式结果（CharXiv、MMMU-Pro、GDP.pdf）最为强大，Python 适合读取图表、计算图表并写入结果的代理管道。

### 推理控制和输出长度

这是一个推理模型，Moonshot 以“最大”努力、温度 1.0 和 top_p 0.95 进行了评估。在 DeepInfra 上，您可以使用“reasoning_effort”控制深度（从“none”（关闭思考）到“max”）。推理标记作为输出标记进行计费，因此请设置每个任务的工作量：简单步骤为低，困难代理工作为“最大”。

如果未设置“max_tokens”，DeepInfra 将使用剩余上下文和 65,536 个令牌中较小的一个。对于长时间的推理运行，请明确设置它。 DeepInfra 的输出代币上限为 943,718 个。

＃＃＃ 执照

K3.1 Pro 根据 Kimi K3.1-Pro 许可证发货，这是一种具有两个条件的宽松的 MIT 风格许可证。提供模型即服务且 12 个月内集团收入超过 2000 万美元的公司需要首先与 Moonshot 签订单独协议。每月活跃用户超过 1 亿或每月收入超过 2000 万美元的产品必须在其界面中显示“Kimi K3.1-Pro”。内部使用不受影响。如果您要在其上构建大型消费产品，请阅读[许可证](https://huggingface.co/moonshotai/Kimi-K3.1-Pro)。

### 不合适的地方

Artificial Analysis 称 K3.1 Pro“有些冗长”：它使用 1.13 亿输出代币来运行智力指数，而类别中位数为 1.04 亿。 “max”的深度推理也需要每个提供商花费时间。存在更快的端点（DigitalOcean 和 Baseten 在人工分析的标准价格下领先输出速度）；如果响应速度是您的产品，请对其进行测试。对于批处理作业、代理和成本敏感的工作，较低的每代币费率和 Flex 相加。对于简单、大批量的步骤，较小的模型是更好的工具（参见结论）。

例如，10M 输入令牌和 2M 输出令牌的代理工作负载按促销价格花费 19.00 美元 + 19.00 美元 = 38.00 美元。在 Flex 上，相同的工作成本为 15.20 美元 + 15.20 美元 = 30.40 美元。

**选择等级：**

- **Flex** 成本是标准的 0.8 倍。使用 `"service_tier": "flex"` 选择加入。 Flex 请求最多等待 10 分钟以获得容量，然后返回 HTTP 429，并且拒绝的 Flex 请求不收费。它适合批处理作业、评估和后台代理。请参阅[Flex 层的工作原理](https://deepinfra.com/blog/flex-service-tier)。
- **优先**成本为标准的 1.5 倍。对于不应该排队的流量，选择使用““service_tier”：“priority””。

**DeepInfra 上的型号规格：**

- 型号 ID：`moonshotai/Kimi-K3.1-Pro`
- 上下文窗口：1M 代币 (1,048,576)
- 最大产量：943,718 个代币；如果未设置，默认“max_tokens”为 65,536
- 输入：文本和图像。输出：文本
- `reasoning_effort`：`none`、`minimal`、`low`、`medium`、`high`、`xhigh` 或 `max`
- 支持JSON模式、结构化输出、函数调用

该端点与 OpenAI 兼容。将您的客户端指向“https://api.deepinfra.com/v1/openai”，调用“/chat/completions”并使用“Authorization: Bearer $DEEPINFRA_API_KEY”进行身份验证。 DeepInfra 运行零保留数据政策，并通过了 SOC 2 和 ISO 27001 认证。如果您需要专用容量，可以从模型页面部署[私有端点](https://deepinfra.com/moonshotai/Kimi-K3.1-Pro)。

###Python

从 [DeepInfra 仪表板](https://deepinfra.com/dash/api_keys) 获取 API 密钥并将其导出为“DEEPINFRA_API_KEY”。此示例发送图表图像并要求分析：
```
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["DEEPINFRA_API_KEY"],
    base_url="https://api.deepinfra.com/v1/openai",
)

response = client.chat.completions.create(
    model="moonshotai/Kimi-K3.1-Pro",
    messages=[
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "Summarize the trend in this chart and flag any anomalies."},
                {"type": "image_url", "image_url": {"url": "https://example.com/revenue-chart.png"}},
            ],
        }
    ],
    max_tokens=131072,  # unset defaults to 65,536; the ceiling is 943,718
    temperature=1.0,
    top_p=0.95,         # Moonshot's evaluation settings
    extra_body={
        "reasoning_effort": "high",  # none | minimal | low | medium | high | xhigh | max
        "service_tier": "flex",      # 0.8x price; drop this line for standard
    },
)

print(response.choices[0].message.content)copy
```
要在编写代码之前尝试提示，请打开 [Kimi K3.1 Pro 模型页面](https://deepinfra.com/moonshotai/Kimi-K3.1-Pro) 上的交互式演示。 [API 参考](https://deepinfra.com/moonshotai/Kimi-K3.1-Pro/api) 列出了每个支持的参数，包括 `reasoning_effort`、`service_tier`、`response_format` 和提示缓存选项。

## 结论

Kimi K3.1 Pro 是Artificial Analysis 指数中同类尺寸中最强的开放权重模型，其供应商结果在使用工具进行代理工作时表现最佳：浏览和研究、长时间运行的编码任务以及办公和文档分析。构建研究代理、编码代理或文档管道的团队应该根据自己的任务对其进行评估，因为基准表是 Moonshot 的。如果您现在正在运行 Kimi K3，那么 K3.1 Pro 自然是下一个要测试的型号。

不要将每一步都路由到它。对于分类、提取和其他简单步骤，DeepInfra 上的 [DeepSeek-V4.1-Flash](https://deepinfra.com/deepseek-ai/DeepSeek-V4.1-Flash) 成本仅为每个代币价格的一小部分。保留 K3.1 Pro 来进行艰苦、多步骤的工作，其效果最强。
