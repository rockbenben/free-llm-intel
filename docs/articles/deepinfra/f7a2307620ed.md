# DeepInfra 上的 Kimi K3.1 Pro：定价、基准测试与 API

2026.11.17 由 DeepInfra 发布

![DeepInfra 上的 Kimi K3.1 Pro：定价、基准测试与 API](https://deepinfrabldev.wpenginepowered.com/wp-content/uploads/2026/11/kimi-k3-1-pro-deepinfra-header.png)

据 [Kimi K3.1 Pro model card](https://huggingface.co/moonshotai/Kimi-K3.1-Pro)（厂商自报），Moonshot AI 的 Kimi K3.1 Pro 在自家对比表中于 BrowseComp（92.1）和带工具的 Humanity's Last Exam（70.0）拿下最高分，领先于 Moonshot 所对比的闭源前沿模型。独立测试也印证了这个招牌成绩：[Artificial Analysis](https://artificialanalysis.ai/models/kimi-k3-1-pro) 在 Intelligence Index v5.0.1 上给它 46 分，是同尺寸 29 个 open-weights 模型中的最高分，而该类模型的中位数为 23。

Moonshot 于 2026 年 10 月 23 日发布 K3.1 Pro，并在 11 月初公开权重。这是一个 2.8 万亿参数的 Mixture of Experts 模型，激活参数 1040 亿，上下文窗口 100 万 token，原生支持图像输入。它面向长程 agentic 工作打造：coding agents、浏览与研究，以及金融、法律、表格等文档密集型办公任务。

[Kimi K3.1 Pro 现已在 DeepInfra 上线](https://deepinfra.com/moonshotai/Kimi-K3.1-Pro)，当前 5% 促销价为 $1.90 / 1M input tokens、$9.50 / 1M output tokens。这低于 Moonshot 自家 API 的标价 $2.00 / $10.00，Flex 层还能把输出价格降到 $7.60。Artificial Analysis 还记录到 DeepInfra 的 endpoint 错误率为 0%。

K3.1 Pro 在使用工具的 agentic 任务上最强。它在 BrowseComp、带工具的 HLE、AutomationBench、长时运行的软件工作（SWE Marathon）和办公文档 QA 上领跑该表。在 Moonshot 内部的带工具幻觉测试中，它的错误率从 Kimi K3 的 23.4% 降至 8.3%。

它并非处处领先。Claude Opus 5.5 在 Terminal-Bench 4.0（66.4 对 65.7）和 computer use（OSWorld V2.1）上略胜一筹，而闭源模型在不使用工具的推理（HLE-Full 与 HLE-Diamond）以及网络安全方面明显领先——Moonshot 表示，它在 open-weight 发布版本中移除了网络安全训练数据。在 open-weights 模型中，DeepSeek-V4.1-Flash-1017 在 DeepSWE v1.1 上胜过它（77.0 对 75.5）。上表中的每个数字都由 Moonshot 跑出，model card 还包含外部无法复现的内部 benchmark；这些没有列入本表。

## 这个模型有何不同

Kimi K3.1 Pro 是 K3.1 系列的首个模型。Moonshot 以“大幅提升的后训练算力”从 Kimi K3 后训练得到它，使用了覆盖数百个领域的大规模联合强化学习。它对 K3 的大部分提升正来源于此。

架构是稀疏 Mixture of Experts：总参数 2.8 万亿，激活 1040 亿，896 个专家、每个 token 选择 16 个，再加上 2 个共享专家，共 93 层。每个 token 只触及不到 4% 的权重，因此你用远小于它的模型所需的每 token 计算量，就能获得一个超大模型的容量。

### 面向长上下文的稀疏注意力

相对 K3 的唯一架构改动在注意力。K3.1 Pro 用 Gated DeepSeek Sparse Attention（Gated DSA）替换了 K3 的全注意力 Gated MLA 层。模型现在混合 69 层 KDA 与 24 层 Gated DSA，让长上下文建模更便宜。这在 100 万 token 上下文下很重要——长篇 agent 轨迹和成批文档会迅速累积。

### 原生视觉

K3.1 Pro 除文本外也接受图像。一个 4.01 亿参数的 MoonViT-V2 视觉编码器直接把图像送入语言模型。Moonshot 的图表、文档和多模态结果（CharXiv、MMMU-Pro、GDP.pdf）在模型还能同时运行 Python 时最强——这正好契合“读图、计算、写结论”的 agent 流水线。

### 推理控制与输出长度

它是一个推理模型，Moonshot 以 temperature 1.0、top_p 0.95 和 `max` effort 运行评测。在 DeepInfra 上，你可以用 `reasoning_effort` 控制推理深度（从关闭思考的 `none` 直到 `max`）。推理 token 按 output token 计费，所以请按任务设置 effort：简单步骤用低档，困难的 agentic 工作用 `max`。

如果你不设置 `max_tokens`，DeepInfra 会取剩余上下文与 65,536 tokens 中的较小值。长时间推理请显式设置。DeepInfra 上的上限是 943,718 output tokens。

### 许可证

K3.1 Pro 以 Kimi K3.1-Pro License 发布，这是一份宽松的 MIT 风格许可证，附带两个条件。将模型作为服务提供、且 12 个月内集团收入超过 2000 万美元的公司，需要先与 Moonshot 单独签约。月活用户超过 1 亿、或月收入超过 2000 万美元的产品，必须在界面中显示“Kimi K3.1-Pro”。内部使用不受影响。如果你要基于它构建大型消费级产品，请阅读[许可证](https://huggingface.co/moonshotai/Kimi-K3.1-Pro)。

### 它不适合的场景

Artificial Analysis 称 K3.1 Pro“略显啰嗦”：跑完 Intelligence Index 用了 1.13 亿 output tokens，而同类模型的中位数是 1.04 亿。`max` 档的深度推理在任何 provider 上也都需要时间。存在更快的 endpoint（在 Artificial Analysis 的标价下，DigitalOcean 和 Baseten 的输出速度领先）；如果你的产品核心是响应速度，可以试试它们。对于批处理任务、agents 和成本敏感的工作，更低的每 token 价格加上 Flex 会累积出优势。对于简单、高并发的步骤，更小的模型是更合适的工具（见结论）。

## 在 DeepInfra 上开始使用

Kimi K3.1 Pro 现已在 DeepInfra 的[文本生成目录](https://deepinfra.com/models/text-generation/)中可用。按 token 定价，没有最低消费。

| 层级 | 输入 | 输出 | 缓存输入 |
| --- | --- | --- | --- |
| 标准，促销价（5% 折扣） | $1.90 | $9.50 | $0.19 |
| 标准，标价 | $2.00 | $10.00 | $0.20 |
| Flex（0.8×） | $1.52 | $7.60 | $0.152 |
| Priority（1.5×） | $2.85 | $14.25 | $0.285 |

*每 1M tokens。价格截至 2026-11-17。Flex 与 Priority 适用于促销价。来源：[model page](https://deepinfra.com/moonshotai/Kimi-K3.1-Pro) 与 [pricing page](https://deepinfra.com/pricing)。*

促销没有公布结束日期，所以预算请按 $2.00 / $10.00 的标价来算，把 5% 当作额外收益。缓存输入的价格是输入费率的 10%，这对每轮都要重发同一 system prompt 和工具定义的 agents 很有帮助。

举例来说，一个 1000 万 input tokens、200 万 output tokens 的 agent 工作负载，按促销价花费 $19.00 + $19.00 = $38.00。用 Flex 跑同样的任务花费 $15.20 + $15.20 = $30.40。

**选择层级：**

- **Flex** 是标准价格的 0.8×。通过 `"service_tier": "flex"` 选用。Flex 请求最多等待 10 分钟以获取容量，之后返回 HTTP 429；被拒绝的 Flex 请求不收费。它适合批处理任务、eval 和后台 agents。参见 [Flex 层级如何工作](https://deepinfra.com/blog/flex-service-tier)。
- **Priority** 是标准价格的 1.5×。通过 `"service_tier": "priority"` 选用，适用于不应排队的流量。

**DeepInfra 上的模型规格：**

- 模型 ID：`moonshotai/Kimi-K3.1-Pro`
- 上下文窗口：100 万 tokens（1,048,576）
- 最大输出：943,718 tokens；未设置时 `max_tokens` 默认为 65,536
- 输入：文本与图像。输出：文本
- `reasoning_effort`：`none`、`minimal`、`low`、`medium`、`high`、`xhigh` 或 `max`
- 支持 JSON 模式、结构化输出和 function calling

该 endpoint 兼容 OpenAI。把客户端指向 `https://api.deepinfra.com/v1/openai`，调用 `/chat/completions`，并用 `Authorization: Bearer $DEEPINFRA_API_KEY` 认证。DeepInfra 执行零保留数据政策，并通过 SOC 2 与 ISO 27001 认证。如果需要专属容量，可以在 model page 部署[私有 endpoint](https://deepinfra.com/moonshotai/Kimi-K3.1-Pro)。

### Python

从 [DeepInfra dashboard](https://deepinfra.com/dash/api_keys) 获取 API key，并以 `DEEPINFRA_API_KEY` 导出。下面这个示例发送一张图表图片并请求分析：

```
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["DEEPINFRA_API_KEY"],
    base_url="https://api.deepinfra.com/v1/openai",
)

response = client.chat.completions.create(
    model="moonshotai/Kimi-K3.1-Pro",
    messages=[
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "Summarize the trend in this chart and flag any anomalies."},
                {"type": "image_url", "image_url": {"url": "https://example.com/revenue-chart.png"}},
            ],
        }
    ],
    max_tokens=131072,  # unset defaults to 65,536; the ceiling is 943,718
    temperature=1.0,
    top_p=0.95,         # Moonshot's evaluation settings
    extra_body={
        "reasoning_effort": "high",  # none | minimal | low | medium | high | xhigh | max
        "service_tier": "flex",      # 0.8x price; drop this line for standard
    },
)

print(response.choices[0].message.content)copy
```

想在写代码前试 prompt，可以打开 [Kimi K3.1 Pro model page](https://deepinfra.com/moonshotai/Kimi-K3.1-Pro) 上的交互式 demo。[API reference](https://deepinfra.com/moonshotai/Kimi-K3.1-Pro/api) 列出了所有支持的参数，包括 `reasoning_effort`、`service_tier`、`response_format` 和 prompt-caching 选项。

## 结论

Kimi K3.1 Pro 是 Artificial Analysis 指数上同尺寸档中最强的 open-weights 模型，其厂商结果在带工具的 agentic 工作上最佳：浏览与研究、长时运行的 coding 任务、办公与文档分析。构建研究 agents、coding agents 或文档流水线的团队应该在自己的任务上评估它，因为那张 benchmark 表是 Moonshot 自己的。如果你今天在跑 Kimi K3，K3.1 Pro 是自然要测的下一个模型。

不要把每一步都路由给它。对于分类、抽取和其他简单步骤，DeepInfra 上的 [DeepSeek-V4.1-Flash](https://deepinfra.com/deepseek-ai/DeepSeek-V4.1-Flash) 每 token 价格只是零头。把 K3.1 Pro 留给它表现最强的困难、多步工作。
