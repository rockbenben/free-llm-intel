# Wan 3.0：模型文档和集成指南

DeepInfra 发布于 2026.10.22

![Wan 3.0：模型文档和集成指南](https://deepinfrabldev.wpenginepowered.com/wp-content/uploads/2026/10/model.png)

[Wan3.0](https://deepinfra.com/Wan-AI/Wan3.0-Video) 是 Wan-AI 的一款一体化视频生成模型，托管在 DeepInfra 上。它涵盖了基于参考的生成、编辑、复制和单一模型中的驱动，并且接受图像、视频剪辑、音频、文档和 Web 链接作为输入。

使用它来讲述电影故事、社交媒体内容和视频编辑。默认情况下，每一代都包含同步音频，并且该模型使角色在剪辑中保持稳定和可识别。

## **关键功能**

- **全模式参考：** 解析文档、网页和复杂图像以驱动视频生成。
- **带音频的长剪辑：** 默认情况下生成长达 30 秒的带有同步音轨的视频。
- **角色一致性：** 在整个视频持续时间内保持主体稳定且可识别。
- **编辑和扩展：** 处理风格转换，例如粘土艺术转换，并向前或向后扩展现有视频。

## **技术规格和基准**

### **标准规格**

| **公制** | **规格** | **注释** |
| --- | --- | --- |
|最大分辨率| 1080P | 480P、720P 和 1080P 等级 |
|帧率| 30 帧/秒 |输出是 MP4 视频 |
|持续时间 | 2 至 30 秒 |设置-1让模型选择|
|音频|默认生成 |将音频设置为 false 以实现静音输出 |
|参考输入|图片、视频、音频、文件、链接 |每个请求最多 20 个参考资产 |

### **质量基准**

人工分析通过其视频竞技场中的盲用户投票来衡量视频质量。 Wan3.0 在两个文本转视频排行榜上均排名第一。

| **排行榜** | **埃洛** | **排名** |
| --- | --- | --- |
|文本到视频与音频 | 1,173（95% 区间 1,157 至 1,189）| 1 |
|无音频文本转视频 | 1,134 | 1,134 1 |

在带音频的排行榜上，Wan3.0 以 1,166 分领先于 Utopai X，以 1,159 分领先于 Dreamina Seedance 2.5。排名区间从第一到第三，因此顶级模特坐在一起。

### **与Wan2.7比较**

| **功能** | **万2.7** | **万3.0** |
| --- | --- | --- |
|输入类型 |图片或参考视频，具体取决于型号 |文本、图像、视频、音频、文件和网络链接 |
|最长持续时间| 15 秒 | 30 秒 |
| DeepInfra 上的模型 |独立的图像到视频和参考到视频模型 |每个工作流程都有一个模型 |
| DeepInfra 价格 |每秒 0.10 美元 |每秒 0.20 美元 |

两种 Wan2.7 型号仍然可用，包括 [Wan2.7 图像转视频](https://deepinfra.com/Wan-AI/Wan2.7-I2V)。阿里巴巴在Wan2.7中引入了视频编辑功能，Wan3.0将其进一步发扬光大。

## **入门**

要使用[Wan3.0-Video](https://deepinfra.com/Wan-AI/Wan3.0-Video)，您需要一个DeepInfra帐户和一个API密钥。 DeepInfra 对输入和输出应用[零保留策略](https://deepinfra.com/blog/data-sovereignty-ai-open-weight-adoption)。

### **身份验证**

在 [DeepInfra 仪表板](https://deepinfra.com/dash/api_keys) 中创建一个密钥并将其传递到每个请求的 Authorization 标头中：

授权：持有者<DEEPINFRA_API_KEY>

### **API端点基础知识**

- 基本 URL：https://api.deepinfra.com/v1/inference
- 模型路径：/Wan-AI/Wan3.0-Video
- HTTP 方法：POST
- 内容类型：应用程序/json

### **进行您的第一个 API 调用**

下面的示例使用 Python 生成一个短视频。
```
import os
import requests
 
url = "https://api.deepinfra.com/v1/inference/Wan-AI/Wan3.0-Video"
headers = {
    "Authorization": f"Bearer {os.environ['DEEPINFRA_API_KEY']}",
    "Content-Type": "application/json",
}
 
payload = {
    "prompt": "A cinematic drone shot flying over a misty pine forest at sunrise",
    "duration": 5,
    "resolution": "720P",
    "audio": True,
    "prompt_extend": True,
}
 
response = requests.post(url, headers=headers, json=payload)
print(response.json()["video_url"])copy
```
要使用参考媒体引导一代，请添加媒体阵列。将提示中的每个资源称为“图像 1”、“视频 1”等，并按照资源在数组中出现的顺序进行编号。
```
payload = {
    "prompt": "Image 1 walks through a rainy neon street at night",
    "media": [
        {"type": "reference_image", "url": "https://example.com/character.png"}
    ],
    "duration": 8,
}copy
```
## **配置和参数**

每个请求都需要提示或媒体。

### **常用参数**

| **参数** | **类型** | **默认** | **描述** |
| --- | --- | --- | --- |
|提示|字符串|空 |视频的文字描述。使用图像 n 或视频 n 引用媒体数组中的资源。 |
|媒体|数组|空 |输入媒体对象，每个媒体对象都有一个类型和一个 url。 |
|持续时间|整数 | 5 |视频长度从 2 到 30 秒。将 -1 设置为模型选择的持续时间。 |
|分辨率 |字符串| 1080P |输出层：480P、720P 或 1080P。 |
|比率|字符串|自适应 |宽高比例如 16:9 或 9:16。自适应从输入媒体中得出比率。 |
|音频|布尔 |真实|生成同步音轨。 |
|提示扩展 |布尔 |真实|重写提示以提高输出质量。 |
|水印|布尔 |假 |添加人工智能生成的水印。 |
|种子 |整数 |无 |可重复输出的值范围为 0 到 2147483647。 |

媒体条目使用以下类型之一：first_frame、last_frame、reference_image、reference_video、reference_audio、file 或 link。参考类型不能与first_frame 或last_frame 组合。当请求包含参考视频时，输入和输出持续时间合计必须保持在 30 秒以内。

### **输入限制**

| **输入类型** | **限制** | **格式和注释** |
| --- | --- | --- |
|文字提示| 20,000 个字符 |描述场景、动作和音频 |
|参考图片| 10 张图片 | JPEG、PNG、BMP 和 WEBP，每个最大 20 MB |
|参考视频| 5 个剪辑，共 15 秒 | MP4 和 MOV，每个最大 100 MB |
|参考音频| 5 个剪辑，共 15 秒 | WAV 和 MP3，每个最大 15 MB |
|文件 | 1 个文件，最多 50 页 | PDF、DOCX、PPTX 和 Markdown，最大 100 MB |
|网页链接 | 1 链接 |无需登录的公共 URL |

## **响应格式**

API 返回一个 JSON 负载，其中包含指向生成视频的链接。 inference_status 对象报告请求的状态、运行时间和成本。
```
{
  "video_url": "https://example.com/video.mp4",
  "request_id": null,
  "inference_status": {
    "status": "succeeded",
    "runtime_ms": 0,
    "cost": 0.0
  }
}copy
```
## **定价**

Wan3.0-Video 按生成视频每秒 0.20 美元计费。 10 秒的剪辑售价为 2.00 美元，30 秒的剪辑售价为 6.00 美元。 DeepInfra 列出了每秒生成输出的速率。

## **结论**

Wan3.0-Video将全模态输入与音频和视频输出结合在一种模型中。创作者可以将文本、图像和文档转换为成品视频，而无需组装多模型管道。

- **范围：** 生成长达 30 秒的视频，其中包含集成音频和多模式参考。
- **控制：** 提供提示扩展、自适应宽高比、种子和可选水印。
- **简单计费：** 对生成的视频按每秒单一费率收费。

DeepInfra 还托管其他接受参考输入的视频模型，例如 [ByteDance Seedance 2.0](https://deepinfra.com/ByteDance/Seedance-2.0)，因此您可以通过相同的 API 比较输出。
