# Wan 3.0：模型文档与集成指南

发布于 2026.10.22，作者 DeepInfra

![Wan 3.0：模型文档与集成指南](https://deepinfrabldev.wpenginepowered.com/wp-content/uploads/2026/10/model.png)

[Wan3.0](https://deepinfra.com/Wan-AI/Wan3.0-Video) 是 Wan-AI 推出的全功能视频生成模型，托管在 DeepInfra 上。它把基于参考的生成、编辑、复刻与驱动整合在同一个模型里，并接受图像、视频片段、音频、文档和网页链接作为输入。

可用于电影化叙事、社交媒体内容和视频剪辑。每次生成默认都包含同步音频，并且模型能让角色在整段视频中保持稳定、可辨识。

## **核心能力**

- **全模态参考：** 解析文档、网页和复杂图像来驱动视频生成。
- **带音频的长片段：** 默认生成最长 30 秒的视频，并附带同步音轨。
- **角色一致性：** 在视频全程保持主体稳定、可辨识。
- **编辑与延展：** 处理黏土动画转换之类的风格迁移，并可向前或向后延展现有视频。

## **技术规格与基准**

### **标准规格**

| **指标** | **规格** | **说明** |
| --- | --- | --- |
| 最高分辨率 | 1080P | 480P、720P 和 1080P 三档 |
| 帧率 | 30 fps | 输出为 MP4 视频 |
| 时长 | 2 至 30 秒 | 设为 -1 由模型自行选择 |
| 音频 | 默认生成 | 将 audio 设为 false 可输出静音 |
| 参考输入 | 图像、视频、音频、文件、链接 | 每个请求最多 20 个参考素材 |

### **质量基准**

Artificial Analysis 通过其 Video Arena 中的盲测用户投票来衡量视频质量。Wan3.0 在其两个文生视频排行榜上均排名第一。

| **排行榜** | **Elo** | **排名** |
| --- | --- | --- |
| 带音频的文生视频 | 1,173（95% 区间 1,157 至 1,189） | 1 |
| 不带音频的文生视频 | 1,134 | 1 |

在带音频榜单上，Wan3.0 以 1,166 领先 Utopai X，以 1,159 领先 Dreamina Seedance 2.5。排名区间覆盖第一到第三，说明头部模型彼此咬得很紧。

### **与 Wan2.7 对比**

| **特性** | **Wan2.7** | **Wan3.0** |
| --- | --- | --- |
| 输入类型 | 图像或参考视频，取决于具体模型 | 文本、图像、视频、音频、文件和网页链接 |
| 最长时长 | 15 秒 | 30 秒 |
| DeepInfra 上的模型 | 图生视频与参考生视频是两个独立模型 | 一个模型覆盖所有工作流 |
| DeepInfra 价格 | 每秒 0.10 美元 | 每秒 0.20 美元 |

两个 Wan2.7 模型仍然可用，包括 [Wan2.7 图生视频](https://deepinfra.com/Wan-AI/Wan2.7-I2V)。阿里巴巴在 Wan2.7 中引入了视频编辑，Wan3.0 将其延续下来。

## **快速上手**

要使用 [Wan3.0-Video](https://deepinfra.com/Wan-AI/Wan3.0-Video)，你需要一个 DeepInfra 账号和 API key。DeepInfra 对输入和输出采取[零保留策略](https://deepinfra.com/blog/data-sovereignty-ai-open-weight-adoption)。

### **身份验证**

在 [DeepInfra 控制台](https://deepinfra.com/dash/api_keys)创建 key，并在每个请求的 Authorization 请求头中传入：

Authorization: Bearer <DEEPINFRA_API_KEY>

### **API 端点基础**

- Base URL：https://api.deepinfra.com/v1/inference
- 模型路径：/Wan-AI/Wan3.0-Video
- HTTP 方法：POST
- 内容类型：application/json

### **发起第一次 API 调用**

下面的示例用 Python 生成一段短视频。

```
import os
import requests
 
url = "https://api.deepinfra.com/v1/inference/Wan-AI/Wan3.0-Video"
headers = {
    "Authorization": f"Bearer {os.environ['DEEPINFRA_API_KEY']}",
    "Content-Type": "application/json",
}
 
payload = {
    "prompt": "A cinematic drone shot flying over a misty pine forest at sunrise",
    "duration": 5,
    "resolution": "720P",
    "audio": True,
    "prompt_extend": True,
}
 
response = requests.post(url, headers=headers, json=payload)
print(response.json()["video_url"])copy
```

要用参考媒体引导生成，添加一个 media 数组。在提示词中按素材在数组里的出现顺序，依次称它们为 Image 1、Video 1，以此类推。

```
payload = {
    "prompt": "Image 1 walks through a rainy neon street at night",
    "media": [
        {"type": "reference_image", "url": "https://example.com/character.png"}
    ],
    "duration": 8,
}copy
```

## **配置与参数**

每个请求需要 prompt 或 media 之一。

### **常用参数**

| **参数** | **类型** | **默认值** | **说明** |
| --- | --- | --- | --- |
| prompt | string | 空 | 视频的文本描述。使用 Image n 或 Video n 引用 media 数组中的素材。 |
| media | array | 空 | 输入媒体对象，每个都带 type 和 url。 |
| duration | integer | 5 | 视频长度 2 至 30 秒。设为 -1 表示由模型选择时长。 |
| resolution | string | 1080P | 输出档位：480P、720P 或 1080P。 |
| ratio | string | adaptive | 宽高比，例如 16:9 或 9:16。adaptive 会从输入媒体推导比例。 |
| audio | boolean | true | 生成同步音轨。 |
| prompt_extend | boolean | true | 重写提示词以提升输出质量。 |
| watermark | boolean | false | 添加 AI 生成水印。 |
| seed | integer | None | 0 到 2147483647 之间的值，用于可复现的输出。 |

媒体条目使用以下类型之一：first_frame、last_frame、reference_image、reference_video、reference_audio、file 或 link。参考类型不能与 first_frame 或 last_frame 组合使用。当请求包含 reference_video 时，输入与输出的时长之和必须控制在 30 秒以内。

### **输入限制**

| **输入类型** | **限制** | **格式与说明** |
| --- | --- | --- |
| 文本提示词 | 20,000 字符 | 描述场景、运动与音频 |
| 参考图像 | 10 张图像 | JPEG、PNG、BMP 和 WEBP，每张最大 20 MB |
| 参考视频 | 5 段，合计 15 秒 | MP4 和 MOV，每个最大 100 MB |
| 参考音频 | 5 段，合计 15 秒 | WAV 和 MP3，每个最大 15 MB |
| 文档 | 1 个文件，最多 50 页 | PDF、DOCX、PPTX 和 Markdown，最大 100 MB |
| 网页链接 | 1 个链接 | 无需登录的公开 URL |

## **响应格式**

API 返回一个 JSON 载荷，其中包含指向生成视频的链接。inference_status 对象报告请求的状态、运行时长和成本。

```
{
  "video_url": "https://example.com/video.mp4",
  "request_id": null,
  "inference_status": {
    "status": "succeeded",
    "runtime_ms": 0,
    "cost": 0.0
  }
}copy
```

## **定价**

Wan3.0-Video 按生成视频每秒 0.20 美元计费。10 秒的片段花费 2.00 美元，30 秒的片段花费 6.00 美元。DeepInfra 列出的是每生成一秒输出的费率。

## **结论**

Wan3.0-Video 把全模态输入与音频、视频输出整合在一个模型里。创作者可以把文本、图像和文档变成成品视频，无需拼装多模型流水线。

- **范围：** 可生成最长 30 秒的视频，内置音频并支持多模态参考。
- **控制：** 提供 prompt_extend、自适应宽高比、seed 和可选水印。
- **简单计费：** 对生成的视频按单一每秒费率收费。

DeepInfra 还托管其他接受参考输入的视频模型，例如 [ByteDance Seedance 2.0](https://deepinfra.com/ByteDance/Seedance-2.0)，因此你可以通过同一个 API 对比输出。
