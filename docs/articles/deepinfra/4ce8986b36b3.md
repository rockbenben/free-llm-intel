大多数网站项目都卡在同一步：空白画布。你能一句话描述想要的感觉——"干净、现代、一个大气的 hero、一个明确的行动号召"——但要把这句话变成一屏可供别人评判的首屏，仍然意味着打开设计工具、摆一个小时的矩块。*知道方向*与*有东西可看*之间的这道缝，正是项目动能消亡的地方。

图像模型本该填上这道缝，但多数时候它们做不到。让通用文生图模型"做一个网站"，你会得到一张桌上笔记本电脑的照片，或一幅按钮位置挤满乱码的漂亮图片。Ming-Image 不同，因为它就是为这件事训练的。给它一份真正的简报，它还你一张真正的 mockup——导航栏、hero、能用的字体排印、看起来像按钮的按钮。

## 认识 Ming-Image

**Ming-Image-0.1-Design** 是 inclusionAI 的开放权重模型，专门针对 UI 与界面设计做了调优。撰稿时，它位居 Artificial Analysis UI/UX Design 排行榜榜首，并能在 DeepInfra 的推理 API 上几秒内渲染出完整的高清 mockup——最高 2560×1440——调用方式与你调用任何其他模型相同。

不过最关键的一点是：一张随手生成的图片和一张你真的会拿去开工的 mockup 之间的差别，几乎完全在提示词里。本文讲的就是怎么把这条提示词写好。下面每张图都只用了 Ming-Image，别无其他。

## 含糊的提示词只能换来含糊的网站

先看失败案例。这是 Ming-Image 对 `a website` 这条提示词的输出：

![A generic stock-photo render of a monitor on a desk with scrambled text](https://deepinfra.com/blog/ming-image-vague.webp)

技术上算个网站。作为 mockup 毫无用处。再看同一个模型拿到一份真正的简报时：

![A clean landing page for a product called Flow, with nav, a bold hero headline, a purple CTA button, and three feature cards](https://deepinfra.com/blog/ming-image-flow-landing.webp)

一条详细的提示词换来一张真正的落地页——wordmark、导航、hero、CTA、功能卡片行。同一个模型，前后不过三十秒。唯一变化的变量，是提示词告诉了模型多少。这就是全部的游戏规则。

## 像写设计简报一样写提示词

第二张图背后的提示词，读起来就像你会交给一位初级设计师的东西：

```
Landing page for a productivity app called Flow. Clean minimal design,
white background, generous whitespace. Top nav with the wordmark 'Flow'
on the left and links Product, Pricing, Docs on the right. Centered hero
with a bold headline 'Focus without the noise' and a subtle gray
subheading. A single purple call-to-action button labeled 'Start free'.
Below the hero, three feature cards with small icons, soft rounded
corners and soft shadows. Modern sans-serif typography.
```

三个习惯让这条提示词生效，它们能撑起你大部分的效果：

- **点名页面类型和产品。** "Landing page for a productivity app called Flow" 锚定了整个布局。模型是*带着目的*在设计，而不是对它见过的所有网站做平均。
- **自上而下描述布局。** 先是导航，然后 hero，然后 CTA，然后功能行。Ming-Image 尊重空间顺序，所以在提示词里沿页面从上往下走，是控制构图最可靠的方式。
- **点名组件。** "Three feature cards with small icons, soft shadows" 就会产出带小图标和柔和阴影的三张功能卡片。含糊是敌人，具体是免费的。

## 明确点出美学风格

布局告诉模型*什么放哪里*，风格关键词告诉它*这东西应该是什么感觉*——而少数几个选得好的词，正是在这里最有力地撬动结果。同样一句"做一个落地页"的指令，会因为点名的美学不同而产出完全不同、却同样自洽的设计：

![A dark glassmorphism SaaS landing page for a product called Signal with frosted cards and a floating dashboard preview](https://deepinfra.com/blog/ming-image-glass-signal.webp)

*关键词："dark glassmorphism, deep navy, purple-to-blue gradient glow, frosted translucent cards."*

![A warm editorial photographer portfolio with a cream background, serif display headline, and a three-photo grid](https://deepinfra.com/blog/ming-image-editorial-portfolio.webp)

*关键词："warm editorial, cream background, large serif display headline, muted terracotta accent."*

要用模型真的画得出来的、具体可视的形容词——`glassmorphism`、`frosted`、`gradient glow`、`serif display`、`editorial`、`brutalist`、`muted terracotta`。"premium""clean" 这类笼统的氛围词有一点帮助；点名一种真实的视觉风格帮助极大。

## 把真实的文案放进提示词

通用图像模型会把文字糊成一团乱码。Ming-Image 能渲染文字——所以把你真正想出现在页面上的文案给它，别交给运气。指定具体的标签和数字，它们就能出现在图上：

![A revenue analytics dashboard with a sidebar, three KPI cards showing exact numbers, and two charts](https://deepinfra.com/blog/ming-image-dashboard.webp)

提示词要求 KPI 卡片显示 "MRR $48.2k"、"Active users 12,904" 和 "Churn 1.8%"——渲染出来的就是这些。

有一个值得知道的限制：**短字符串**的文字保真度极佳——标题、导航链接、按钮标签、数字、KPI 卡片——但在长正文段落上仍会退化，仔细看小字会看到形似而实非的假字形。所以把你真正的标题、真正的 CTA、真正的数据放进提示词，长正文之后再拿回设计工具里替换。

## 锁住 seed，然后一次只改一处

上面的每张 hero 图都用了固定的 `seed`。seed 是模型的初始随机性——保持它固定，构图在各次运行之间保持稳定；改变它，你就对同一份简报得到一个新的演绎。

这给了你一个干净的迭代循环。当一个设计已经九成到位、你只想要绿色而不是紫色的 CTA 时，别盲目重掷。保留 seed，只改那一个子句（`a purple call-to-action button` → `an emerald call-to-action button`），重新生成。你得到的是同一页面上只有那一处变化，而不是从头再来。只有当你想要几个真正不同的方向可供挑选时，才变化 seed。

## 选好宽高比

1:1 只是选项之一——Ming-Image 能以多种宽高比渲染，你可以让画布匹配你正在设计的屏幕。设置 `aspect_ratio` 字段：

| `aspect_ratio` | 分辨率 | 适合 |
| --- | --- | --- |
| `16:9` | 2560×1440 | 桌面端与落地页 hero |
| `4:3` | 2432×1824 | dashboard、幻灯片 |
| `1:1` | 2048×2048 | 社交图块、头像 |
| `2:3` | 1664×2496 | 移动屏、海报 |

选择与布局匹配的宽高比，而不是设计一个正方形再去裁切——移动屏要用 `2:3`，桌面 hero 要用 `16:9`。提示词里其他一切保持不变。

## 一份可以直接抄的提示词模板

填空即可，你就完成了一大半：

```
[Page type] for a [product type] called [name].
[Aesthetic keywords], [background], [spacing].
Top nav with [logo/wordmark] and links [A, B, C].
Hero with the headline '[exact headline]' and [subheading].
A [color] call-to-action button labeled '[exact label]'.
Below the hero, [components: N cards / a chart / a photo grid].
[Typography]. [Accent color].
```

## 试一试

调用 Ming-Image 只需一个请求——和你用于任何模型的 `POST /v1/inference/<model>` 一样，把你的简报放进 `prompt` 字段：

```
curl -X POST https://api.deepinfra.com/v1/inference/inclusionAI/Ming-Image-0.1-Design \
  -H "Authorization: Bearer $DEEPINFRA_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Landing page for a productivity app called Flow...", "aspect_ratio": "16:9"}'
```

用 AI 设计网站，从来不是敲一句"给我做个网站"然后祈祷，而是写出一份精确到模型只能画出一件东西的简报——那件你心里早就有的东西。把提示词写对，空白画布就不再是项目卡住的地方，而成了它们开始的地方。
