# Kimi K3.1 Pro：模型概述、基准测试和 API 指南

DeepInfra 发布于 2026.11.17

![Kimi K3.1 Pro：模型概述、基准测试和 API 指南](https://deepinfrabldev.wpenginepowered.com/wp-content/uploads/2026/11/kimi-k3-1-pro-model-overview-header.png)

[Kimi K3.1 Pro](https://deepinfra.com/moonshotai/Kimi-K3.1-Pro) 是 Moonshot AI 的旗舰开放权重模型，[于 2026 年 10 月 23 日发布](https://artificialanalysis.ai/models/kimi-k3-1-pro)，专为长期代理工作而构建：编码、3D 创建、金融研究和文档繁重的任务。它是一个 2.8 万亿参数的 Mixture-of-Experts 模型，每个 token 有 104B 个活跃参数，将文本和图像作为输入，返回文本，并具有 [1,048,576-token 上下文窗口](https://huggingface.co/moonshotai/Kimi-K3.1-Pro)。

K3.1 Pro 并不是新的预训练运行。 Moonshot [从 Kimi K3 进行后训练](https://www.kimi.ai/blog/kimi-k3-1-pro)“具有更大的训练后计算量”和跨数百个领域的大规模强化学习，并将 K3 的全注意力层替换为稀疏注意力层，以使长上下文的服务成本更低。它是K3.1系列的第一款型号。

在 DeepInfra 上，该模型在兼容 OpenAI 的 API 后面运行，具有零数据保留、JSON 和结构化输出、函数调用和图像输入。如果您需要更便宜的模型来实现更简单的代理步骤，[DeepSeek V4.1 Flash-1017](https://deepinfra.com/deepseek-ai/DeepSeek-V4.1-Flash-1017) 使用相同的 API。模型字符串是：

**`moonshotai/Kimi-K3.1-Pro`**

## Kimi K3 有何变化

除非另有标记，Moonshot 的以下声明均由供应商报告。

### 训练后和编码

- **Long-horizon 编码：** 在 Kimi Code Bench 3.0 Long-horizon（一项内部 Moonshot 基准）上，K3.1 Pro 得分为 61.2，而 K3 为 55.95（[发布帖子](https://www.kimi.ai/blog/kimi-k3-1-pro)）。
- **独立检查：**在[LiveBench 2.0](https://livebench.ai/)上（2026年11月6日表），Kimi K3的编码从53.1上升到67.8，长期代理工作从36.0上升到38.7。这是一个真正的编码增益，尽管 K3.1 Pro 在 LiveBench 编码上的开放重量模型中仍然处于中游。

### 事实准确性

- 在 Moonshot 的内部 Kimi Hallu Bench Hard 上，声称级别的幻觉率从 K3 的 23.4% 降至 8.3%。 Moonshot 将基准测试称为有意的压力测试，因此该比率并不描述日常错误率。

### 财务和业务工作

- Moonshot的内部财务基准提高了7.2分（财务建模）和11.6分（财务研究），其业务运营模拟得分约为K3结果的4.2倍。在公开的 OfficeQA Pro v2 上，K3.1 Pro 得分为 64.4，在 Moonshot 的排行榜中名列前茅。

### 注意力和长上下文

- K3.1 Pro 将 K3 的全注意力门控 MLA 层替换为**门控 DeepSeek 稀疏注意力（门控 DSA）**：其 93 层中的 24 层现在使用稀疏注意力，top-k 为 2,048 个索引标记，其他 69 层使用 KDA 线性注意力。重点是在完整的 1M 窗口中进行更便宜的长上下文建模。

### 网络能力，故意限制

- 对于开放重量版本，Moonshot 从训练中期和强化学习中删除了与网络相关的数据。在其内部 xdev-bench-hard 上，未经过滤的检查点在 pass@3 处解决了 90.5% 的任务；发布的模型解决了81.0%。 Moonshot 表示 K3.1 Pro 的攻击性网络能力仍然落后于前沿专有模型。

### DeepInfra 价格

- [Kimi K3](https://deepinfra.com/moonshotai/Kimi-K3) 仍以每 100 万代币 2.85 美元的输入和 14.25 美元的输出列出。 K3.1 Pro 的促销价格为 1.90 美元/9.50 美元，比两者低三分之一，而且 K3.1 Pro 增加了 Flex 层。

如果您的工作可以等待，**Flex** 是运行模型最便宜的方式。发送`"service_tier": "flex"`：当容量不足时，请求最多等待10分钟，然后返回HTTP 429，被拒绝的Flex请求不收费。隔夜评估、批量提取和背景剂是一个不错的选择。 [Flex 服务层级公告](https://deepinfra.com/blog/flex-service-tier) 涵盖了详细信息。

**优先级** (`"service_tier": "priority"`) 用于不应排队的流量。它的价格为 2.85 美元/14.25 美元，比 Moonshot 的标价更高，因此仅在排队成本高于保费的情况下使用它。

**缓存**对于冗长的模型和长时间的代理会话很重要：缓存输入的成本为 0.19 美元，而新输入的成本为 1.90 美元。使用“prompt_cache_key”将重复的前缀路由到同一缓存，并使用“prompt_cache_options”使其保持更长时间（请参阅[提示缓存保留](https://deepinfra.com/blog/prompt-cache-retention)）。

对于每月的成本方案，请参阅 [Kimi K3.1 Pro 定价指南](https://deepinfra.com/blog/kimi-k3-1-pro-pricing-guide)。初创公司可以通过[DeepStart](https://deepinfra.com/deepstart)申请免费积分。

## 开始使用

该 API 与 OpenAI 兼容：

- **基本 URL：** `https://api.deepinfra.com/v1/openai`
- **端点：** `POST /聊天/完成`
- **身份验证标头：** `授权：承载 $DEEPINFRA_API_KEY`

完整的请求架构位于模型的 [API 页面](https://deepinfra.com/moonshotai/Kimi-K3.1-Pro/api)。

＃＃＃ 参数

首先是模型特定的参数。通过 OpenAI Python SDK 中的“extra_body”发送非标准字段。

＃＃＃ Python
```
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["DEEPINFRA_API_KEY"],
    base_url="https://api.deepinfra.com/v1/openai",
)

response = client.chat.completions.create(
    model="moonshotai/Kimi-K3.1-Pro",
    messages=[
        {"role": "system", "content": "You are a senior equity research analyst."},
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "Summarize the revenue trend in this chart and list three risks."},
                {"type": "image_url", "image_url": {"url": "https://example.com/revenue-chart.png"}},
            ],
        },
    ],
    temperature=1.0,
    top_p=0.95,
    max_tokens=32768,
    extra_body={
        "reasoning_effort": "high",  # none | minimal | low | medium | high | xhigh | max
        "service_tier": "flex",      # remove this line for the standard tier
    },
)

print(response.choices[0].message.content)
print(response.usage)copy
```
对于简短、定义明确的步骤，例如分类、提取或路由，请从“reasoning_effort”：“low”或“none”开始。 K3.1 Pro 在高强度工作时比较冗长，并且推理代币在标准层上按每 100 万美元 9.50 美元的输出计费。

### 输出限制

该模型没有 16,384 个代币的输出上限。您最多可以请求 **943,718 个输出令牌**。如果您未设置“max_tokens”，DeepInfra 将使用 65,536 个令牌中较小的一个以及输入后 1,048,576 个令牌窗口中剩余的内容。输入和输出一起必须适合该窗口。

Moonshot 发布的结果使用“最大”努力，在该设置下长时间运行代理可能会在最终答案开始之前花费数万个令牌进行推理。为了更接近 Moonshot 的设置，请将“max_tokens”显式设置为高于默认值 65,536，使用“max”工作量，并流式传输响应，以便长代不会遇到客户端超时。无法保证精确再现，因为 Moonshot 在自己的工具中运行了大多数基准测试。

## 结论

Kimi K3.1 Pro 在同尺寸的 29 款开放式重量模型中拥有最高的人工智能分析智能指数得分，而 Moonshot 自己的表格在代理、工具使用和文档工作方面使其处于或接近顶部。它的弱点也很明显：封闭模型仍然领先于没有工具、ProgramBench 和网络任务的知识，而且它很冗长，因此输出代币推动了大部分账单。

这使得每个输出代币的价格成为值得关注的数字。在 DeepInfra 上，K3.1 Pro 在当前促销活动中每 100 万个输出代币的售价为 9.50 美元，在 Flex 上售价为 7.60 美元。这低于 Moonshot 的标价，也低于它所取代的型号，测量错误率为 0%。
