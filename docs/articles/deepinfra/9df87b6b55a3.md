# DeepInfra 推出 Wan 3.0

DeepInfra 发布于 2026.10.19

![DeepInfra 推出 Wan 3.0](https://deepinfrabldev.wpenginepowered.com/wp-content/uploads/2026/10/wan-3.0.png)

[Wan3.0](https://deepinfra.com/Wan-AI/Wan3.0-Video) 是阿里巴巴 Wan 团队推出的视频生成模型，它把文生视频、图生视频、基于参考的生成、视频编辑和视频延长融合在同一个模型里。你在请求中发送的媒体类型会决定走哪条工作流，因此一个模型就能处理所有输入类型。

一个请求可以把文本提示词与最多 20 个参考素材组合起来，包括图像、视频片段和音频。它还可以包含一份文档或一个公共网页。Wan3.0 会把这样的输入变成最长 30 秒、带同步音频的 1080P 视频。

Artificial Analysis 在其带音频的文生视频排行榜上把 Wan3.0 排在第一位，Elo 为 1,173。Wan3.0 已在 DeepInfra 上线，定价为每生成一秒视频 0.20 美元。

## **这个模型的不同之处**

Wan3.0 最具特色的设计决策是它的统一模型。更早的版本把这些任务拆分到不同的模型上，例如 Wan2.7 的参考生视频模型和 Wan2.6 的文生视频模型。Wan3.0 把所有任务都放在同一个模型标识符后面处理，因此当你的用例发生变化时，你管理的始终只是一个端点。

Wan3.0 还把最长片段时长翻了一倍。阿里巴巴列出 Wan2.7 每次生成 2 到 15 秒，而 Wan3.0 一次就能达到 30 秒。前两代模型在 DeepInfra 上仍然可用，包括 [Wan2.7 参考生视频](https://deepinfra.com/Wan-AI/Wan2.7-R2V) 和 [Wan2.6 文生视频](https://deepinfra.com/Wan-AI/Wan2.6-T2V)，两者均为每秒 0.10 美元。

支持的任务类型有：

| **任务** | **输入** | **说明** |
| --- | --- | --- |
| 文生视频 | 仅提示词 | 时长 2 到 30 秒 |
| 图生视频 | 首帧，或首帧加尾帧 | 让提供的图像动起来 |
| 参考生视频 | 图像、视频片段、音频、一个文件或一个链接 | 每个请求最多 20 个参考素材 |
| 视频编辑 | 参考视频加一条自然语言指令 | 修改画面、情节或对白，无需重新生成整段视频 |
| 视频延长 | 已有视频加提示词 | 输入与输出的时长合计不超过 30 秒 |

参考系统在一个请求中最多接受 10 张参考图像、5 个视频片段和 5 段音频。一个请求还可以包含一份文档（例如 PDF、DOCX、PPTX 或 Markdown 文件），或一个公共网页。模型会解析它并把它变成视频。

你可以直接在提示词里用位置名称引用素材，例如 Image 1 或 Video 2。编号遵循媒体数组的顺序，图像与视频分别计数。

音频默认开启。模型会在生成视频的同时生成对白、背景音乐和音效。如果你单独处理声音，请把 audio 设为 false。

输出最高为 1080P、30 fps，同时提供 480P 和 720P 档位。时长可设为 2 到 30 秒，或设为 -1，让模型根据提示词和媒体自行选择长度。

prompt_extend 参数默认为 true，会在生成之前重写你的提示词。提示词越是简略，收益越大，所以除非你需要精确控制措辞，否则就让它保持开启。

## **在 DeepInfra 上开始使用**

[Wan3.0-Video](https://deepinfra.com/Wan-AI/Wan3.0-Video) 已在 DeepInfra 上线，模型标识符为 Wan-AI/Wan3.0-Video。定价为每生成一秒视频 0.20 美元，因此一段 10 秒的视频花费 2.00 美元，完整的 30 秒生成则花费 6.00 美元。

计费按用量进行，通过一个能接上现有工具链的 REST API 完成。DeepInfra 对输入、输出和用户数据执行[零保留政策](https://deepinfra.com/blog/data-sovereignty-ai-open-weight-adoption)，该平台也通过了 SOC 2 和 ISO 27001 认证。

### **快速开始**

在 [DeepInfra 控制台](https://deepinfra.com/dash/api_keys)中创建一个密钥，然后提交一个文生视频请求。响应里会包含一个 video_url，指向生成好的 MP4。

```
curl -X POST "https://api.deepinfra.com/v1/inference/Wan-AI/Wan3.0-Video" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $DEEPINFRA_TOKEN" \
  -d '{
    "prompt": "A red fox running through a snowy pine forest at dusk, cinematic lighting",
    "resolution": "1080P",
    "ratio": "16:9",
    "duration": 5,
    "audio": true,
    "prompt_extend": true
  }'copy
```

```
import os
import requests
 
response = requests.post(
    "https://api.deepinfra.com/v1/inference/Wan-AI/Wan3.0-Video",
    headers={
        "Authorization": f"Bearer {os.environ['DEEPINFRA_TOKEN']}",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "A red fox running through a snowy pine forest at dusk, cinematic lighting",
        "resolution": "1080P",
        "ratio": "16:9",
        "duration": 5,
        "audio": True,
        "prompt_extend": True,
    },
)
 
print(response.json()["video_url"])copy
```

**关键参数**

- duration 接受 2 到 30 的整数，或 -1，让模型根据你的提示词和媒体挑选长度。
- ratio 默认为 adaptive，会从你的输入媒体推导宽高比。这在图生视频工作流里最有用。
- audio 默认为 true。传 false 得到静音输出。
- prompt_extend 默认为 true，会重写提示词以提升输出质量。
- watermark 默认为 false。设为 true 可加上 AI 生成水印。
- seed 接受 0 到 2,147,483,647 的整数，用于可复现的输出。
- 参考媒体类型不能与 first_frame 或 last_frame 出现在同一个请求里。

模型页面还让你能在浏览器里跑一次生成，并查看完整的参数参考。

## **结论**

Wan3.0 省去了为每种视频任务拼装不同模型的麻烦。一个端点即可接受文本、图像、视频片段、音频、文档和网页，并在同一次生成中产出同步音频。

这样的覆盖面适合以往难以自动化的工作流。例子包括用 URL 生成产品演示视频、用 PDF 剧本生成故事化片段，以及保持角色一致性的短视频内容。

先用一小段 480P 或 720P 视频检查运动与构图，然后用 1080P 渲染最终版本。
