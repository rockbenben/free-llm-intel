# 在 DeepInfra 上推出 Wan 3.0

DeepInfra 发布于 2026.10.19

![在 DeepInfra 上推出 Wan 3.0](https://deepinfrabldev.wpenginepowered.com/wp-content/uploads/2026/10/wan-3.0.png)

[Wan3.0](https://deepinfra.com/Wan-AI/Wan3.0-Video)是阿里巴巴Wan团队的视频生成模型，它将文本到视频、图像到视频、基于参考的生成、视频编辑和视频扩展结合在一个模型中。您通过请求发送的媒体会选择工作流程，因此一个模型可以处理每种输入类型。

请求可以将文本提示与最多 20 个参考资源结合起来，包括图像、视频剪辑和音频。它还可以包括文档或公共网页。 Wan3.0 将输入转换为长达 30 秒的带有同步音频的 1080P 视频。

Artificial Analysis 将 Wan3.0 在其音频文本到视频排行榜上排名第一，Elo 为 1,173。 Wan3.0 在 DeepInfra 上可用，生成视频每秒 0.20 美元。

## **这个模型有何不同**

Wan3.0最有特色的设计决策是其统一的模型。早期版本将这些任务划分为不同的模型，例如 Wan2.7 参考视频模型和 Wan2.6 文本到视频模型。 Wan3.0 在一个模型标识符后面处理所有这些，因此您可以在用例发生变化时管理单个端点。

Wan3.0还将最大剪辑长度加倍。阿里巴巴列出Wan2.7每代2到15秒，而Wan3.0则达到30秒一代。前几代仍然可以在 DeepInfra 上使用，包括 [Wan2.7 视频参考](https://deepinfra.com/Wan-AI/Wan2.7-R2V) 和 [Wan2.6 文本到视频](https://deepinfra.com/Wan-AI/Wan2.6-T2V)，每个价格为每秒 0.10 美元。

支持的任务类型有：

| **任务** | **输入** | **注释** |
| --- | --- | --- |
|文字转视频|仅提示 |持续时间 2 至 30 秒 |
|图像到视频 |第一帧，或第一帧和最后一帧 |对提供的一个或多个图像进行动画处理 |
|参考视频 |图片、视频剪辑、音频、一个文件或一个链接 |每个请求最多 20 个参考资产 |
|视频编辑|参考视频和自然语言教学 |更改视觉效果、情节或对话，无需重新生成完整剪辑 |
|视频延伸|现有视频和提示|输入和输出持续时间合计保持在 30 秒以内 |

参考系统在一次请求中最多接受 10 个参考图像、5 个视频剪辑和 5 个音频剪辑。请求还可以包括一份文档，例如 PDF、DOCX、PPTX 或 Markdown 文件，或一个公共网页。该模型对其进行解析并将其转换为视频。

您可以直接在提示中使用位置名称（例如图像 1 或视频 2）引用资源。数字遵循媒体数组的顺序，并且图像和视频单独计数。

音频默认打开。该模型会在视频旁边生成对话、背景音乐和声音效果。如果单独处理声音，请将音频设置为 false。

输出最高可达 1080P 和 30 fps，并提供 480P 和 720P 等级。持续时间可以设置为 2 到 30 秒，或者设置为 -1 让模型从提示和媒体中选择长度。

Prompt_extend 参数默认为 true 并在生成之前重写提示。稀疏提示受益最多，因此除非您需要精确控制措辞，否则请将其保留。

## **DeepInfra 入门**

[Wan3.0-Video](https://deepinfra.com/Wan-AI/Wan3.0-Video) 在 DeepInfra 上可用，型号标识符为 Wan-AI/Wan3.0-Video。生成视频的定价为每秒 0.20 美元，因此 10 秒的剪辑成本为 2.00 美元，完整的 30 秒生成成本为 6.00 美元。

通过适合现有工具的 REST API 根据使用情况进行计费。 DeepInfra 对输入、输出和用户数据运行[零保留政策](https://deepinfra.com/blog/data-sovereignty-ai-open-weight-adoption)，并且该平台经过 SOC 2 和 ISO 27001 认证。

### **快速入门**

在 [DeepInfra 仪表板](https://deepinfra.com/dash/api_keys) 中创建密钥，然后提交文本转视频请求。响应包括指向完成的 MP4 的 video_url。
```
curl -X POST "https://api.deepinfra.com/v1/inference/Wan-AI/Wan3.0-Video" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $DEEPINFRA_TOKEN" \
  -d '{
    "prompt": "A red fox running through a snowy pine forest at dusk, cinematic lighting",
    "resolution": "1080P",
    "ratio": "16:9",
    "duration": 5,
    "audio": true,
    "prompt_extend": true
  }'copy
```

```
import os
import requests
 
response = requests.post(
    "https://api.deepinfra.com/v1/inference/Wan-AI/Wan3.0-Video",
    headers={
        "Authorization": f"Bearer {os.environ['DEEPINFRA_TOKEN']}",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "A red fox running through a snowy pine forest at dusk, cinematic lighting",
        "resolution": "1080P",
        "ratio": "16:9",
        "duration": 5,
        "audio": True,
        "prompt_extend": True,
    },
)
 
print(response.json()["video_url"])copy
```
**关键参数**

- 持续时间接受 2 到 30 之间的整数，或 -1 让模型从提示和媒体中选择长度。
- 比例默认为自适应，它从输入媒体中获取宽高比。这对于图像到视频的工作流程很有帮助。
- 音频默认为 true。传递 false 以获得静默输出。
-prompt_extend 默认为 true 并重写提示以提高输出质量。
- 水印默认为 false。将其设置为 true 以添加 AI 生成的水印。
- 种子接受 0 到 2,147,483,647 之间的整数以获得可重现的输出。
- 参考媒体类型不能与同一请求中的first_frame 或last_frame 组合。

模型页面还允许您在浏览器中运行第一代并检查完整的参数引用。

## **结论**

Wan3.0 不再需要为每个视频任务拼接单独的模型。一个端点接受文本、图像、视频剪辑、音频、文档和网页，并在同一通道中生成同步音频。

该范围适合以前难以自动化的工作流程。示例包括从 URL 构建的产品演示视频、从 PDF 脚本构建的故事驱动剪辑以及具有一致字符的简短内容。

从一个简短的 480P 或 720P 剪辑开始，检查动作和构图，然后以 1080P 渲染最终版本。
