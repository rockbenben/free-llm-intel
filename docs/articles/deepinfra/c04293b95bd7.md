[MiMo-V2.6-Pro](https://deepinfra.com/XiaomiMiMo/MiMo-V2.6-Pro) 是 Xiaomi 在大语言模型市场上的旗舰之作，也是 Artificial Analysis 目前追踪的开放权重模型中实力靠前的一个。这款稀疏 Mixture-of-Experts（MoE）模型发布于 2026 年 9 月，总参数 1.02 万亿，而推理时只激活 420 亿——这样一个设计在原始能力与实际部署成本之间求得平衡。

按 Artificial Analysis 当前的 Intelligence Index 评测方法（v5.0），MiMo-V2.6-Pro 得 30 分，在「Large」（超过 1,500 亿参数）尺寸级别的 21 个模型中排第 3，而该级别的中位得分是 23——稳稳高于级别中位数，但并不是该级别里得分最高的那一个。该模型原生支持多模态输入（文本、图像、视频和音频），上下文窗口 100 万 token，全部以允许商用的 MIT 许可证发布。

*注：Artificial Analysis 会随着新增或替换评测项，周期性地重新标度 Intelligence Index（当前版本 v5.0 依据九项评测，包括 AA-Briefcase v1.1、Terminal-Bench 4.0 和 HLE-Diamond）。不同 index 版本之间的分数不可直接比较，所以本指南里任何跨模型对比都对应同一套、也就是当前的方法。*

本指南按生产部署真正在意的几个维度来评估 MiMo-V2.6-Pro：智能基准、定价经济性、速度与延迟、提供商选项，以及实际用例。

## 模型能力与提供商对比

### MiMo-V2.6-Pro 与竞品的对比

MiMo-V2.6-Pro 在 agentic 与工具调用任务上表现很强，而成本只是专有模型的一小部分，这正是它对大批量 agentic 和编码工作负载有吸引力的原因。下面的 benchmark 数字是 Xiaomi 自己发布的对比，而不是 Artificial Analysis 被独立复现的结果，应当按厂商自报的口径来读。

| **Benchmark** | **MiMo-V2.6-Pro** | **Claude Opus 5** | **GPT-5.6 Sol** | **GPT-6 Astra** |
| --- | --- | --- | --- | --- |
| DeepSWE v1.1 | 71.9 | 74.0 | 73.0 | 74.0 |
| AutomationBench v1.0.6 | 53.1 | 50.3 | 45.8 | 52.0 |
| Terminal Bench 2.1 | 89.9 | 89.1 | 88.8 | 89.9 |
| Terminal Bench 4.0 | 34.9 | 49.0 | 39.9 | 59.6 |
| Toolathlon-Verified | 76.9 | 80.6 | 74.9 | — |
| ExploitBench | 47.9 | 70.0 | 78.5 | — |
| CyberGym | 94.0 | — | — | — |
| JobBench | 62.0 | 65.7 | 45.4 | — |

### 关键要点

- 优势：MiMo-V2.6-Pro 在通用 agentic 任务、工具调用和自动化 benchmark 上表现不错——按 Xiaomi 的数字，在其中几项上它追平甚至超过了 Claude Opus 5 和 GPT-5.6 Sol。
- 劣势：在最苛刻的长时程编码 benchmark（Terminal Bench 4.0）和安全漏洞利用（ExploitBench）上它落后。
- 价值主张：它以明显更低的成本跑出接近若干前沿模型的成绩，是 Artificial Analysis 当前 Intelligence Index 上得分较硬的开放权重选项之一，但并不是排名第一的那一个。

按 Xiaomi 自己的数字，从 V2.5 到 V2.6 的跃升相当大：DeepSWE v1.1 从 19.0 提升到 71.9，Terminal Bench 4.0 从 1.5 升到 34.9。

## 模型架构、权重与开放程度

### 模型规模：总参数与激活参数

MiMo-V2.6-Pro 采用稀疏 Mixture-of-Experts 架构：

| **规格** | **值** |
| --- | --- |

| Hidden Size | 6,144 |

| 音频编码器 | 308M 参数 |

### 开放权重对比专有

MiMo-V2.6-Pro 是完全开放权重的，checkpoint 以 XiaomiMiMo/MiMo-V2.6-Pro-RL 的名字在 Hugging Face 上提供。

| **模型** | **权重** | **许可证** | **商用** |

### 许可证与模型权重

- 许可证：MIT（商用与研究使用都完全宽松）
- 权重位置：Hugging Face（XiaomiMiMo/MiMo-V2.6-Pro-RL）
- 下载体积：约 573 GB（8-bit 打包容器，其中部分张量使用 FP8/BF16）
- 自托管要求：一个 Q4 级别的构建大约需要 612 GB VRAM——超出任何消费级机器的能力，现实上要么多 GPU 服务器，要么走 API 访问。

### 开放度画像

- 权重公开可得
- MIT 许可证允许商用
- 提供 model card 与技术文档
- 可通过多家第三方 API 提供商访问
- 已发布 checkpoint 所用的确切量化方案未完全披露

## 上下文窗口与 token 使用

| **模型** | **上下文窗口** | **等效** |
| --- | --- | --- |
| MiMo-V2.6-Pro | 1,048,576 tokens（约 1M） | 约 1,500 页 A4 |
| MiMo-V2.6-Flash | 1,048,576 tokens（约 1M） | 约 1,500 页 A4 |
| 最大输出 | 131,072 tokens（约 128K） | — |

1M token 的上下文窗口让单次调用就能完成整个代码库分析、长视频转写与多轮 agent trace，以及更长的文档处理或 RAG 工作流。

MiMo-V2.6-Pro 使用针对多语文本优化的自定义 tokenizer（中英文支持强），覆盖多种编程语言代码以及多模态内容编码。Artificial Analysis 给它的输出详尽度评级是 4 分制里的 3 分——在 Intelligence Index 的评测集上比同级模型略啰嗦，这一点在给推理密集型工作负载估算成本时值得计入。

## 常见问题

### 哪家提供商的智能与成本比最好？

在 DeepInfra 追踪的提供商里，每个 Intelligence Index 任务的成本是最干净的同类对比口径：MiMo-V2.6-Pro 目前约 $0.26 每任务，与若干专有前沿模型相比有竞争力，同时在 Artificial Analysis 当前的 Intelligence Index 上得 30 分——>150B 参数级别的第 3 名。

### 总参数和激活参数有什么区别？

MiMo-V2.6-Pro 共有 1.02 万亿参数，但每次前向传播只激活 420 亿。这种 Mixture-of-Experts 设计让模型有很大的知识存储容量，同时把推理成本控制在可承受范围——你不是每个 token 都要为整万亿参数付运行成本。

### prompt 缓存如何影响 LLM API 定价？

MiMo-V2.6-Pro 提供 99% 的缓存折扣，把缓存输入的成本从 $0.435/M 降到 $0.0036/M token。DeepInfra 的 [prompt 缓存文档](https://docs.deepinfra.com/chat/prompt-caching) 说明了缓存命中如何被检测与计费。对于上下文重复的应用——RAG 系统、多轮对话、批处理——这能大幅削减成本。

### 我能在本地跑 MiMo-V2.6-Pro 吗？

权重是公开的，但在 1.02T 总参数（激活 42B）的规模下，一个 Q4 级别的构建大约需要 612 GB VRAM——超出任何消费级机器。在更小的官方构建发布之前，API 访问或多 GPU 服务器才是现实路径。

### MiMo-V2.6-Pro 与其他开放权重模型相比如何？

MiMo-V2.6-Pro 是 Artificial Analysis 当前追踪的开放权重模型里得分较高的那一批之一，但并不是排名第一的那个——它在 >150B 参数级别的 21 个模型里排第 3。与其他开放模型的具体正面对比（例如对 Kimi K3）在本指南中没有独立复核，所以我们把这些略去，而不是复述一个未经验证的数字。

### MiMo-V2.6-Pro 支持哪些模态？

MiMo-V2.6-Pro 是「原生全模态」的，接受文本、图像、视频和音频作为输入，输出文本。这是通过专用的视觉（681M 参数）和音频（308M 参数）编码器直接建在架构里的。

### MiMo-V2.6-Pro 的推荐配置是什么？

Xiaomi 推荐 temperature=1.0 和 top_p=0.95 以获得最佳效果。

## 结论

MiMo-V2.6-Pro 是开放权重 LLM 版图中一个可信的入场者：Intelligence Index 得分强但不登顶、定价激进、权重完整 MIT 许可。

### 关键要点

- 强，但不是第一：在当前 Artificial Analysis Intelligence Index 上得 30 分——>150B 参数级别 21 个模型中的第 3，明显高于该级别中位数 23。
- 成本效率高：大约每个 Intelligence Index 任务 $0.26，按单任务成本计价，明显低于若干专有前沿模型。
- 完全开放：MIT 许可证加上 Hugging Face 上的权重，带来商用、fine-tuning 与自托管（硬件要足够）的可能。
- 原生多模态：处理文本、图像、视频和音频输入，配 1M token 的上下文窗口。
- 取舍：比该级别中位数更慢（53.4 对 73.9 tokens/sec），延迟更高（3.16s 对 1.67s TTFT）。

### 谁应该用 MiMo-V2.6-Pro

- 跑大批量 agentic 与编码工作负载、在意成本的团队
- 因合规、定制或自托管选项而需要开放权重的大型组织
- 构建有长上下文需求的多模态应用的开发者
- 想要强劲又经济的表现、却不想付前沿模型定价的任何使用者

对于生产部署，DeepInfra 这类提供商提供的托管访问，在开放权重的灵活性与托管基础设施的省心之间取得了平衡。从 [quickstart 指南](https://docs.deepinfra.com/quickstart) 开始把第一次调用跑通，并为需求演变保留一条可行的自托管路径。

开放模型与专有模型之间的差距仍在收窄，MiMo-V2.6-Pro 是这个方向上一个清楚的证据点——一个强劲且成本效率高的开放权重模型，即便它不是当前 Intelligence Index 上得分最高的那一个。想看它与另一个近期 agentic 发布相比如何，可参考我们的 [Kimi K3 vs. Claude Opus 4.8 vs. GPT-5.6 Sol 实用模型对比](https://deepinfra.com/blog/kimi-k3-vs-claude-opus-4-8-vs-gpt-5-6-sol)。
