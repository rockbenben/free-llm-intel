# GLM-5.3-Flash API 现已登陆 DeepInfra

Z.ai 的 [GLM-5.3-Flash](https://deepinfra.com/zai-org/GLM-5.3-Flash) 推理时在其 3,200 亿参数中只激活 180 亿，而按 Z.ai 报告的成绩，它在高难度软件工程基准 DeepSWE v1.1 上超过了 Claude Opus 4.8（63.4 对 58.0）。它是 GLM-5 系列第一个原生多模态模型，把文本、图像和视频输入与一百万 token 的上下文窗口结合在一起，价格约为 [GLM-5.2](https://deepinfra.com/zai-org/GLM-5.2) 的十分之一。

这种效率来自专门设计的混合架构——稀疏 attention 与线性 attention 配对——相比完整版 [GLM-5.3](https://deepinfra.com/zai-org/GLM-5.3)，attention 计算量降低 3 倍、KV cache 缩小 4.4 倍，在大规模服务长上下文时这是实打实的差别。

正式发布之前，Z.ai 曾以 "ox-alpha" 之名在 OpenCode 和 OpenRouter 上匿名测试该模型，据 Z.ai 称，它成了当周最受欢迎的模型。它用 30 万亿 token 的多模态语料训练。GLM-5.3-Flash 现已进入 [DeepInfra 模型目录](https://deepinfra.com/models)。

## **这个模型有何不同**

GLM-5.3-Flash 是 GLM-5 系列首个原生多模态模型，它从一个全新训练的基座模型出发，而不是对早期 checkpoint 的更新。架构引入了两个值得注意的机制：Manifold-Constrained Hyper-Connections（mHC），提升扩展效率；以及 IndexPool，通过加权池化把四个 indexer key 向量压缩成一个，削减长上下文下的延迟与内存开销。最大的变化是转向稀疏与线性混合的 attention 设计——GLM 系列头一回——它让百万 token 级上下文从"技术上可行"变成"运维上可落地"。

这种混合 attention 在规模下的收益是可测量的。与完整版 GLM-5.3 相比，GLM-5.3-Flash 少用 3.0 倍 attention 算力、KV cache 小 4.4 倍。与 GLM-4.5 相比，激活参数（18B 对 32B）和层数（45 对 92）几乎都减半，而总参数量相当（320B 对 355B）。成果是一个每次前向传播只跑 18B 参数的 320B Mixture-of-Experts 模型。

在 Z.ai 报告的基准上，相对 GLM-5.2 的提升全面且显著：

| **基准** | **GLM-5.3-Flash** | **GLM-5.2** | **Claude Opus 4.8** |
| --- | --- | --- | --- |
| DeepSWE v1.1 | 63.4 | 46.2 | 58.0 |
| AutomationBench v1.0.6 | 48.8 | 26.2 | 41.0 |
| Toolathlon Verified | 78.4 | 59.9 | 76.2 |
| NL2Repo | 56.3 | 48.9 | 69.7 |
| GDPval-AA v2 | 1773 | 1504 | 1582 |

在 Z.ai 内部 Code Bench v1.0 的 max 档位上，它得 29.0 分，Claude Opus 4.8 为 29.5。所有数字均为 Z.ai 自报，且各基准的测试 harness 并不相同，跨行比较前请先看[模型卡](https://huggingface.co/zai-org/GLM-5.3-Flash)上的脚注。

原生视觉能力是 GLM 系列的新领地。GLM-5.3-Flash 开箱接受图像与视频输入，Z.ai 报告 MMVU 80.5、CharXiv Reasoning（带工具）89.4、Chartography（带工具）78.0、MVBench 77.8、OfficeQA Pro 62.4。这让它成为文档与图表分析、GUI 智能体、computer-use 工作流的合理候选，而不只是文本进文本出的任务。你可以在 [DeepInfra 上浏览多模态模型](https://deepinfra.com/models/multimodal)，看看它与同类模型相比如何。

## **在 DeepInfra 上开始使用**

GLM-5.3-Flash 的模型标识为 zai-org/GLM-5.3-Flash。标准定价为每 1M 输入 token $0.15、每 1M 输出 token $0.50，缓存 token 每 1M $0.03。当前有 50% 折扣，三项分别降到 $0.075、$0.25 和 $0.015；[定价页](https://deepinfra.com/pricing)始终展示最新费率。支持完整的 1,048,576 token 上下文窗口，以及 JSON mode、function calling 与多模态输入。需要独享容量，可以[部署私有端点](https://deepinfra.com/dash/deployments?new=custom-llm&base_model=zai-org%2FGLM-5.3-Flash)。

DeepInfra 通过 OpenAI 兼容 API 暴露该模型：无需采购基础设施、无需管理模型权重，从第一个 token 起就按用量计费。如果你已经在用 OpenAI SDK，要改的只有 base URL 和模型名。该模型的 [API 页面](https://deepinfra.com/zai-org/GLM-5.3-Flash/api)列出了可用参数，包括用于在延迟与准确率之间权衡的 reasoning_effort 字段（low、high 或 max），API 其余部分见 [DeepInfra 文档](https://docs.deepinfra.com)。

DeepInfra 对推理数据执行[零保留政策](https://trust.deepinfra.com)，并持有 SOC 2 与 ISO 27001 认证。

下面是完成第一个调用所需的全部内容。

cURL:

```
curl "https://api.deepinfra.com/v1/openai/chat/completions" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $DEEPINFRA_TOKEN" \
  -d '{
    "model": "zai-org/GLM-5.3-Flash",
    "messages": [
      {
        "role": "user",
        "content": "Explain the tradeoffs between sparse and linear attention in one paragraph."
      }
    ]
  }'
Python:
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["DEEPINFRA_TOKEN"],
    base_url="https://api.deepinfra.com/v1/openai",
)

response = client.chat.completions.create(
    model="zai-org/GLM-5.3-Flash",
    messages=[
        {
            "role": "user",
            "content": "Explain the tradeoffs between sparse and linear attention in one paragraph.",
        }
    ],
)

print(response.choices[0].message.content)
JavaScript:
import OpenAI from "openai";

const openai = new OpenAI({
  apiKey: process.env.DEEPINFRA_TOKEN,
  baseURL: "https://api.deepinfra.com/v1/openai",
});

const response = await openai.chat.completions.create({
  model: "zai-org/GLM-5.3-Flash",
  messages: [
    {
      role: "user",
      content:
        "Explain the tradeoffs between sparse and linear attention in one paragraph.",
    },
  ],
});

console.log(response.choices[0].message.content);
```

从 [DeepInfra dashboard](https://deepinfra.com/dash/api_keys)取好 API key，然后到[模型 demo 页](https://deepinfra.com/zai-org/GLM-5.3-Flash)快速试一下，或在集成前查阅完整规格。

## **总结**

GLM-5.3-Flash 是一个技术上很有意思的成果：一个每次前向传播只跑 18B 参数的 320B MoE 模型，原生处理视觉，并且按 Z.ai 报告的数据，以一小部分成本在软件工程基准上与前沿模型平分秋色。这里的架构选择不是表面文章——混合 attention 设计与 IndexPool 压缩，正是让百万 token 多模态推理可以被实际服务起来的原因。

这个组合打开了一整类智能体的空间（带完整仓库上下文的代码助手、GUI 自动化流水线、文档密集的工作流），它们在过去常常贵到无法可靠地构建。如果你想在投入之前看看它如何处理你的工作负载，[在线 demo](https://deepinfra.com/zai-org/GLM-5.3-Flash)是合理的起点；需要保证容量的团队可以搭建[私有端点](https://deepinfra.com/dash/deployments?new=custom-llm&base_model=zai-org%2FGLM-5.3-Flash)。为智能体工作负载做预算时，可以读读我们关于[为什么单任务成本比单 token 成本更重要](https://deepinfra.com/blog/token-verbosity)的观点，以及[双层智能体如何把前沿模型与更便宜的模型配对](https://deepinfra.com/blog/two-tier-agent-two-models)。也欢迎浏览我们的其余[文本生成模型](https://deepinfra.com/models/text-generation)。
