Kimi K3.1 Pro 是 Moonshot AI 的 open-weight agentic 模型，[于 2026 年 10 月 23 日发布](https://www.kimi.ai/blog/kimi-k3-1-pro)，权重在 11 月初发布到 [Hugging Face](https://huggingface.co/moonshotai/Kimi-K3.1-Pro)。它是 mixture-of-experts 模型，总参数 2.8T、激活参数 104B，原生多模态（输入文本和图像，输出文本），上下文窗口 1M token。它由 Kimi K3 后训练而来，强化学习算力大得多，并用 Gated DeepSeek Sparse Attention 替换了 K3 的 full-attention 层，以降低长上下文服务的成本。在 Artificial Analysis 的 Intelligence Index 上它得分 46，是同规模 29 个 open-weight 模型中最高的。它还很啰嗦，回答前会推理很久，所以在哪里运行它，会同时决定账单和等待时间。

本指南按决定选择的关键维度，比较运行 Kimi K3.1 Pro 的几种方式：价格与定价档位、功能、部署模式，以及每种选项适合谁。每个条目都附一行实测速度。完整的测速与延迟对比见 [Kimi K3.1 Pro API benchmark](https://deepinfra.com/blog/kimi-k3-1-pro-api-benchmarks)，其中包括首 token 时间与首个答案 token 时间的对比——对这个推理模型来说，后者从约 25 秒到两分多钟不等。速度、混合价格和错误率来自 [Artificial Analysis](https://artificialanalysis.ai/models/kimi-k3-1-pro/providers)（reasoning effort 为 max，数据抓取于 2026-11-17），它对 14 家提供商的 16 个 endpoint 就这个模型做了 benchmark。价格与功能来自各提供商自己的页面。价格截至 2026-11-17。

## 托管 API 提供商

### 1. DeepInfra

当你按每 token 成本做决定，同时又想要生产级可靠性、服务档位和通往专用容量的路径时，DeepInfra 是最佳选择。

- **当前价格：** 每 1M token [输入 $1.90 / 输出 $9.50 / 缓存输入 $0.19](https://deepinfra.com/moonshotai/Kimi-K3.1-Pro)，较 $2.00 / $10.00 / $0.20 的标价有 5% 促销折扣
- **Flex 档：** $1.52 / $7.60 / $0.152。通过 `"service_tier": "flex"` 启用。请求最多等待 10 分钟以获取容量，之后返回 HTTP 429，被拒绝的 Flex 请求不收费（[Flex 如何工作](https://deepinfra.com/blog/flex-service-tier)）
- **Priority 档：** 使用 `"service_tier": "priority"` 时为 $2.85 / $14.25 / $0.285，适用于无法排队的请求
- **混合价格（Artificial Analysis，7:2:1）：** $1.46，低于所有标准价 endpoint 的 $1.54，也低于所有快速档（$2.31 到 $4.62）。按相同权重，Flex 约为 $1.17
- **可靠性：** 在 Artificial Analysis 的测试中错误率 0.0%。DeepInfra 是 Artificial Analysis 测到的、错误率为 0% 的最便宜 endpoint
- **上下文与输出：** 1,048,576 token 上下文；每个请求最多 943,718 个输出 token。若未设置 `max_tokens`，默认取剩余上下文与 65,536 中的较小值
- **功能：** OpenAI 兼容 API、图像输入、工具调用、JSON 模式与结构化输出（JSON schema 与正则）、`reasoning_effort` 从 `none`（关闭 thinking）到 `max`、使用 `prompt_cache_key` 与可配置 TTL 的 prompt caching、每个请求最多 4 个 fallback 模型
- **部署：** serverless 按 token 计费的 API，或在专用 GPU 上的 private endpoint；零数据保留
- **速度：** 在 Artificial Analysis 上输出 46.9 tokens/s。如果响应速度就是你的产品，请测试 DigitalOcean 或 Baseten；对于批处理、agent 和对成本敏感的工作，每 token 的差距会不断累积。

Kimi K3.1 Pro 很能输出：Artificial Analysis 跑完它的 Intelligence Index 共统计到 1.13 亿个输出 token，而同类中位数是 1.04 亿个。因此，包括推理 token 在内的输出 token 占了账单的大头，而 DeepInfra 的 $9.50 输出价格（Flex 上 $7.60）正是省钱的地方。它适合后台 agent、文档与金融流水线、评测批跑，以及任何能接受为更低价格多等一会的负载。有一件事要在你自己的流量上实测：DeepInfra 在 Artificial Analysis 的 agentic 负载上的缓存命中率是 92.6%，低于若干主机达到的 98–100%。缓存密集的 agent 循环应设置 `prompt_cache_key`，并在预估成本前先检查命中率。

用 OpenAI SDK 完成第一次调用：

```
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["DEEPINFRA_API_KEY"],
    base_url="https://api.deepinfra.com/v1/openai",
)

response = client.chat.completions.create(
    model="moonshotai/Kimi-K3.1-Pro",
    messages=[{"role": "user", "content": "Reconcile these two revenue tables and explain each difference."}],
    temperature=1.0,
    top_p=0.95,
    extra_body={"reasoning_effort": "high", "service_tier": "flex"},
)
print(response.choices[0].message.content)copy
```

endpoint 是 `/chat/completions`，认证头是 `Authorization: Bearer $DEEPINFRA_API_KEY`。完整参数见 [Kimi K3.1 Pro API 页面](https://deepinfra.com/moonshotai/Kimi-K3.1-Pro/api)。

### 2. Moonshot AI（Kimi API）

当你想要第一方访问、Highspeed 变体，或想在 Moonshot 自家产品里使用这个模型时，Moonshot 自己的 [Kimi API](https://platform.kimi.ai/) 是最佳选择。

- **模型名称：** `kimi-k3.1-pro` 与 `kimi-k3.1-pro-highspeed`（[Moonshot 发布博文](https://www.kimi.ai/blog/kimi-k3-1-pro)）
- **价格（Artificial Analysis）：** $2.00 / $10.00 / $0.20 缓存；Highspeed $4.00 / $20.00 / $0.20
- **Highspeed：** Moonshot 称其速度是 K3.1 Pro 的 2–3 倍
- **产品：** 在 Kimi.ai、Kimi Work 和 Kimi Code 中也可用；API 客户可选择零数据保留
- **速度：** 标准 endpoint 在 Artificial Analysis 上为 31.0 tokens/s（Highspeed：69.4 tokens/s）

第一方 API 会最先获得 Moonshot 的新功能，而 Highspeed 变体是不离开 Moonshot 就能缩短响应时间的最简单方式。它在每一类 token 上都比 DeepInfra 贵，而且 Artificial Analysis 在测试中对标准 endpoint 测到 8.0% 的错误率，所以要把重试考虑进去。

### 3. DigitalOcean

当用户会等待每一个答案，而你又想留在 Moonshot 的标价水平时，[DigitalOcean Serverless Inference](https://docs.digitalocean.com/products/inference/details/pricing/) 是最佳选择。

- **价格：** 每 1M token 输入 $2.00 / 输出 $10.00 / 缓存读取 $0.20
- **计费：** 预付费 serverless credits；专用 GPU 推理按 GPU 小时计费
- **平台：** 一个控制台内提供模型目录、Inference Router 和 agent 工具
- **速度：** 200.8 tokens/s，并且是 Artificial Analysis 上标准价 endpoint 中首个答案 token 时间最低的

对于聊天界面和交互式 coding agent，DigitalOcean 值得一试。它每 token 比 DeepInfra 的标准价贵约 5%，而且它的定价页对这个模型只列出 Standard 一个档位。

### 4. Baseten

当你现在想要一个按 token 计费的快速 API、并在用量增长时切换到专用部署时，[Baseten 的 Model API](https://www.baseten.co/library/kimi-k31-pro/) 是最佳选择。

- **模型：** Kimi K3.1 Pro，1M 上下文，文本与图像输入
- **价格（Artificial Analysis）：** $2.00 / $10.00 / $0.20 缓存
- **部署：** 按 token 计费的 Model API，另有专用部署和针对自定义配置的工程支持
- **速度：** Artificial Analysis 上 183.0 tokens/s，是标价档中最快的之一

Baseten 适合预期会从共享容量迁移到专用容量的产品团队。它的每 token 价格与 Moonshot 的标价一致，因此每 token 比 DeepInfra 贵。

### 5. Modal

当你在 coding agent 里运行 K3.1 Pro，并希望每个完成任务的成本很低时，[Modal 的 Model APIs](https://modal.com/library/moonshot/kimi-k3-1-pro) 是最佳选择。

- **价格：** 每 1M token 输入 $2.00 / 缓存输入 $0.20 / 输出 $10.00
- **API：** OpenAI 兼容，并为 Claude Code、Codex、OpenCode 和 Hermes Agent 提供原生集成
- **输入：** 文本与图像，1,048,576 token 上下文
- **每个任务的成本：** Artificial Analysis 的每个 Intelligence Index 任务 $3.19，是测到的低值之一，这得益于 100% 的缓存命中率
- **速度：** Artificial Analysis 上 118.0 tokens/s

Modal 的高缓存命中率意味着，对反复重发长前缀的 agent 循环来说，每个任务的实际花费低于标价给人的印象。按 token 计它收的是 Moonshot 的标价，比 DeepInfra 高约 5%。

### 6. Amazon Bedrock

当你的工作负载已经在 AWS 上运行，并希望在 AWS 治理下使用 Highspeed 变体时，[Amazon Bedrock](https://docs.aws.amazon.com/bedrock/latest/userguide/model-card-moonshot-ai-kimi-k3-1-highspeed.html) 是最佳选择。

- **模型：** Kimi K3.1 Pro Highspeed（`global.moonshotai.kimi-k3.1`），1M 上下文
- **价格（Standard 档）：** 在 global profile 上为输入 $4.00 / 输出 $20.00 / 缓存读取 $0.20；在 US 和 India profile 上为 $4.40 / $22.00 / $0.22；缓存写入每 1M token $5.00
- **服务档位：** Flex 为标准价的 0.5 倍，Priority 为 1.75 倍
- **API：** OpenAI 兼容的 Chat Completions 与 Responses，外加 Converse 和 Invoke；reasoning effort 从 `none` 到 `max`（默认 `max`）
- **速度：** Artificial Analysis 上 218.2 tokens/s，是测到的最快之一

Bedrock 让数据保持在 AWS 边界内，并为美国和印度的数据驻留提供区域 profile。标准价是 Moonshot 对 Highspeed 变体标价的两倍。Bedrock 的 Flex 档能把可等待的工作负载拉回 $2.00 / $10.00，但这仍高于 DeepInfra 的标准价。

### 7. OpenRouter

当你想要一个 API key，并在提供 K3.1 Pro 的各主机之间自动 failover 时，[OpenRouter](https://openrouter.ai/moonshotai/kimi-k3.1-pro) 是最佳选择。

- **模型 slug：** `moonshotai/kimi-k3.1-pro`
- **路由的主机：** 20 多个 endpoint，其中包括 DeepInfra，各自按主机自己的价格
- **路由：** 均衡、最快或最便宜模式；也可以固定到单个主机
- **速度：** 取决于所选主机；OpenRouter 增加一跳网络，但自身不提供算力

OpenRouter 上有些小主机价格比 DeepInfra 更低，提供的精度也各不相同。如果在意输出一致性，就固定到一个主机。最终选定某个主机的团队，通常会直接对接该主机，以获得完整的功能集、服务档位和支持。

### 8. Featherless AI

当你已经在用它 OpenAI 兼容的 API 跑许多 open 模型，并希望 K3.1 Pro 也用同一个 key 时，[Featherless AI](https://featherless.ai/blog/kimi-k3-1-pro-is-live-on-featherless) 是最佳选择。

- **价格（Developer 档）：** 每 1M token 输入 $2.00 / 缓存 $0.20 / 输出 $10.00
- **上下文：** Developer 档为 256K；专用实例上是完整的 1M 窗口
- **数据：** 不记录 prompt 或补全内容
- **部署：** serverless API，或专用 GPU 集群
- **速度：** Artificial Analysis 未跟踪这个模型的该项数据

256K 窗口只有该模型原生上下文的四分之一，这对整仓库和长文档类工作有影响。它适合把许多 open 模型收拢到一家提供商旗下的团队。

## 关于许可证

Kimi K3.1 Pro 以 [Kimi K3.1-Pro License](https://huggingface.co/moonshotai/Kimi-K3.1-Pro) 发布，这是一份允许商用但附带条件的自定义许可证。任意 12 个月内集团营收超过 2000 万美元的 model-as-a-service 运营方，需要与 Moonshot 另行签约；月活跃用户超过 1 亿或月营收超过 2000 万美元的产品，必须在其界面中展示“Kimi K3.1-Pro”。许可证为内部使用和某些访问途径列明了豁免。如果上述任一门槛可能适用于你，请阅读完整文本，或询问你的提供商。

## 结语

- **本指南中每 token 价格最低：** DeepInfra，$1.90 / $9.50 / $0.19，在 Artificial Analysis 上的混合价为 $1.46，异步工作用 Flex 为 $1.52 / $7.60
- **实测错误率为 0% 的最低价：** DeepInfra
- **标价下答案最快：** DigitalOcean 或 Baseten
- **本指南中最快：** Amazon Bedrock 的 Highspeed 变体，价格 $4.00 / $20.00
- **每个 agentic 任务成本低：** Modal，得益于 100% 的缓存命中率
- **第一方功能与应用：** Moonshot AI
- **一个 key、自动 failover：** OpenRouter
- **一个 key 覆盖大型 open 模型目录：** Featherless AI

各主机不断调整 serving stack，所以这个模型的速度和延迟每周都会变化，相关讨论见[为什么 open 模型上线后会变快](https://deepinfra.com/blog/why-open-models-get-faster)。在做出承诺前，先查看 [benchmark 指南](https://deepinfra.com/blog/kimi-k3-1-pro-api-benchmarks) 中的最新数字。

### 最佳整体方案

对大多数把 Kimi K3.1 Pro 作为 API 来运行的团队，[DeepInfra](https://deepinfra.com/moonshotai/Kimi-K3.1-Pro) 是默认选择。在本指南的提供商中它的价格最低，输入 $1.90、输出 $9.50，而对任何能等待的工作负载，Flex 档输出价为 $7.60。它是 Artificial Analysis 测到的、错误率为 0% 的最便宜 endpoint；它提供完整的 1M 上下文，输出 token 最多可达 943K；它还提供零数据保留和 private endpoint——这一切都在一个 OpenAI 兼容 API 上，改一下 base URL 就能切换过来。对于 agent 流水线里较轻的步骤，[DeepSeek V4.1 Flash](https://deepinfra.com/deepseek-ai/DeepSeek-V4.1-Flash-1017) 可以在同一个 API 上以很小的成本运行。
