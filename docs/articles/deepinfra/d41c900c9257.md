Kimi K3.1 Pro 是 Moonshot AI 的开放权重代理模型，[2026 年 10 月 23 日发布](https://www.kimi.ai/blog/kimi-k3-1-pro)，权重于 11 月初发布在 [Hugging Face](https://huggingface.co/moonshotai/Kimi-K3.1-Pro) 上。它是一个专家混合模型，总参数为 2.8T，活动参数为 104B，原生多模态（文本和图像输入，文本输出）和 1M 令牌上下文窗口。它是从 Kimi K3 进行后训练的，具有更大的强化学习计算，并且用 Gated DeepSeek Sparse Attention 取代了 K3 的全注意力层，以实现更便宜的长上下文服务。在人工智能分析的智能指数上，它得分为 46，是同尺寸的 29 个开放权重模型中最高的。它也很冗长，并且在回答之前要解释很长时间，所以你在哪里运行它会影响账单和等待。

本指南比较了运行 Kimi K3.1 Pro 的方法，以确定选择的因素：价格和定价层、功能、部署模型以及每个选项的适合对象。每个条目都有一行关于测量的速度。完整的速度和延迟比较位于 [Kimi K3.1 Pro API 基准测试](https://deepinfra.com/blog/kimi-k3-1-pro-api-benchmarks)，包括第一个令牌的时间与第一个答案令牌的时间，对于此推理模型，时间范围从大约 25 秒到超过两分钟。速度、混合价格和错误率来自[人工分析](https://artificialanalysis.ai/models/kimi-k3-1-pro/providers)（最大推理工作量，2026 年 11 月 17 日拉动），该分析针对该模型对来自 14 个提供商的 16 个端点进行了基准测试。费率和功能来自每个提供商自己的页面。定价截至 2026 年 11 月 17 日。

## 托管 API 提供商

### 1. 深基础设施

当每个代币的成本决定选择并且您想要生产可靠性、服务级别和专用容量的路径时，DeepInfra 是最佳选择。

- **当前费率：** [$1.90 输入 / $9.50 输出 / $0.19 缓存输入](https://deepinfra.com/moonshotai/Kimi-K3.1-Pro) 每 1M 代币，在 $2.00 / $10.00 / $0.20 标价的基础上享受 5% 促销折扣
- **弹性层：** $1.52 / $7.60 / $0.152。使用 `"service_tier": "flex"` 选择加入。请求最多等待 10 分钟以获得容量，然后返回 HTTP 429，并且被拒绝的 Flex 请求不收费（[Flex 的工作原理](https://deepinfra.com/blog/flex-service-tier)）
- **优先级：** $2.85 / $14.25 / $0.285，带有 `"service_tier": "priority"`，适用于无法排队的请求
- **混合价格（人工分析，7:2:1）：** 1.46 美元，低于每个标准价格端点 1.54 美元和每个快速层（2.31 美元至 4.62 美元）。在相同的权重下，Flex 的价格约为 1.17 美元
- **可靠性：** 人工分析运行中的错误率为 0.0%。 DeepInfra 是最便宜的端点人工分析措施，错误率为 0%
- **上下文和输出：** 1,048,576 个令牌上下文；每个请求最多 943,718 个输出令牌。如果未设置“max_tokens”，则默认值是剩余上下文和 65,536 中的较小者
- **功能：** OpenAI 兼容 API、图像输入、工具调用、JSON 模式和结构化输出（JSON 模式和正则表达式）、“reasoning_effort”从“none”（思考）到“max”、使用“prompt_cache_key”和可配置 TTL 进行提示缓存、每个请求最多 4 个后备模型
- **部署：**无服务器每代币 API，或专用 GPU 上的专用端点；零数据保留
- **速度：** 人工分析时输出为 46.9 个令牌/秒。如果您注重响应速度，请测试 DigitalOcean 或 Baseten；对于批量、代理和成本敏感的工作，每个令牌的差距会复合。

Kimi K3.1 Pro 很冗长：人工分析计算出 1.13 亿输出代币来运行其智能指数，而类别中位数为 1.04 亿。因此，输出代币（包括推理代币）占据了大部分账单，而 DeepInfra 的 9.50 美元输出率（Flex 上为 7.60 美元）就是节省的体现。它适合后台代理、文档和财务管道、评估运行以及任何可以吸收较长等待时间以获取较低价格的工作负载。根据您自己的流量衡量的一件事是：DeepInfra 对人工分析代理工作负载的缓存命中率为 92.6%，低于几台主机达到的 98-100%。缓存密集型代理循环应设置“prompt_cache_key”并在预测成本之前检查命中率。

使用 OpenAI SDK 的第一次调用：
```
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["DEEPINFRA_API_KEY"],
    base_url="https://api.deepinfra.com/v1/openai",
)

response = client.chat.completions.create(
    model="moonshotai/Kimi-K3.1-Pro",
    messages=[{"role": "user", "content": "Reconcile these two revenue tables and explain each difference."}],
    temperature=1.0,
    top_p=0.95,
    extra_body={"reasoning_effort": "high", "service_tier": "flex"},
)
print(response.choices[0].message.content)copy
```
端点是“/chat/completions”，auth 标头是“Authorization: Bearer $DEEPINFRA_API_KEY”。完整参数位于[Kimi K3.1 Pro API页面](https://deepinfra.com/moonshotai/Kimi-K3.1-Pro/api)。

### 2.Moonshot AI（Kimi API）

当您需要第一方访问、Highspeed 变体或 Moonshot 产品内的模型时，Moonshot 自己的 [Kimi API](https://platform.kimi.ai/) 是最佳选择。

- **型号名称：** `kimi-k3.1-pro` 和 `kimi-k3.1-pro-highspeed` （[Moonshot 发布帖子](https://www.kimi.ai/blog/kimi-k3-1-pro)）
- **费率（人工分析）：** $2.00 / $10.00 / $0.20 缓存；高速 $4.00 / $20.00 / $0.20
- **高速：** Moonshot 表示其速度是 K3.1 Pro 的 2-3 倍
- **产品：** 也可在 Kimi.ai、Kimi Work 和 Kimi Code 中使用； API 客户可以使用零数据保留
- **速度：** 标准端点的人工分析为 31.0 个令牌/秒（高速：69.4 个令牌/秒）

第一方 API 首先获得新的 Moonshot 功能，而 Highspeed 变体是在不离开 Moonshot 的情况下缩短响应时间的最简单方法。它在每个代币类别上的成本都高于 DeepInfra，人工分析在其运行中的标准端点上测量到 8.0% 的错误率，因此需要进行重试。

### 3.数字海洋

当用户等待每个答案并且您希望保持 Moonshot 的标价时，[DigitalOcean Serverless Inference](https://docs.digitalocean.com/products/inference/details/pricing/) 是最佳选择。

- **费率：** 每 1M 代币 2.00 美元输入 / 10.00 美元输出 / 0.20 美元缓存读取
- **计费：** 预付费无服务器积分；专用 GPU 推理按 GPU 小时计费
- **平台：** 模型目录、推理路由器和代理工具位于一个控制台中
- **速度：** 200.8 个代币/秒，在人工分析的标准价格端点中首次应答代币的最短时间

DigitalOcean 是测试聊天 UI 和交互式编码代理的提供商。每个代币的成本比 DeepInfra 的标准费率高出约 5%，并且其定价页面仅列出了该模型的标准层。

### 4.巴斯坦

当您现在想要快速的每个代币 API 并在数量增长时进行专用部署时，[Baseten 的模型 API](https://www.baseten.co/library/kimi-k31-pro/) 是最佳选择。

- **型号：** Kimi K3.1 Pro，1M上下文、文本和图像输入
- **费率（人工分析）：** $2.00 / $10.00 / $0.20 缓存
- **部署：** 每个代币模型 API，以及针对自定义设置的专用部署和工程支持
- **速度：** 人工分析为 183.0 代币/秒，是标价中最快的

Baseten 适合希望从共享容量转向专用容量的产品团队。它的每个代币费率与 Moonshot 的标价一致，因此它的每个代币成本高于 DeepInfra。

### 5. 模态

当您在编码代理内运行 K3.1 Pro 并希望每完成任务的成本较低时，[Modal 的模型 API](https://modal.com/library/moonshot/kimi-k3-1-pro) 是最佳选择。

- **费率：** 每 1M 代币 2.00 美元输入 / 0.20 美元缓存输入 / 10.00 美元输出
- **API：** OpenAI 兼容，具有 Claude Code、Codex、OpenCode 和 Hermes Agent 的本机集成
- **输入：** 文本和图像，1,048,576 个令牌上下文
- **每个任务的成本：** 每个人工分析智能指数任务的成本为 3.19 美元，是衡量的最低成本之一，这得益于 100% 的缓存命中率
- **速度：** 人工分析为 118.0 代币/秒

Modal 的高缓存命中率意味着重新发送长前缀的代理循环为每个任务支付的费用低于标价所示。每个代币按 Moonshot 的列表费率收费，比 DeepInfra 的费率高出约 5%。

### 6. Amazon Bedrock

当您的工作负载已在 AWS 中运行并且您希望 Highspeed 变体受 AWS 监管时，[Amazon Bedrock](https://docs.aws.amazon.com/bedrock/latest/userguide/model-card-moonshot-ai-kimi-k3-1-highspeed.html) 是最佳选择。

- **型号：** Kimi K3.1 Pro Highspeed (`global.moonshotai.kimi-k3.1`)，1M 上下文
- **费率（标准层）：** $4.00 输入 / $20.00 输出 / $0.20 全局配置文件上的缓存读取；美国和印度配置文件为 4.40 美元/22.00 美元/0.22 美元；缓存每 100 万个代币写入 5.00 美元
- **服务等级：** Flex 为标准费率的 0.5 倍，优先级为标准费率的 1.75 倍
- **API：** OpenAI 兼容的聊天完成和响应，以及 Converse 和 Invoke；推理工作“none”到“max”（默认“max”）
- **速度：** 人工分析为 218.2 代币/秒，是测得最快的之一

Bedrock 将数据保留在 AWS 边界内，并提供美国和印度数据驻留的区域配置文件。标准价格是 Moonshot 高速型号标价的两倍。对于可以等待的工作负载，Bedrock 的 Flex 层将其价格恢复到 2.00 美元/10.00 美元，这仍然高于 DeepInfra 的标准费率。

### 7. 开放路由器

当您需要一个 API 密钥并在服务 K3.1 Pro 的主机之间进行自动故障转移时，[OpenRouter](https://openrouter.ai/moonshotai/kimi-k3.1-pro) 是最佳选择。

- **模型块：** `moonshotai/kimi-k3.1-pro`
- **路由的主机：** 超过 20 个端点，其中包括 DeepInfra，每个端点均按主机自己的价格
- **路由：**平衡、最快或最便宜的模式；您可以固定单个主机
- **速度：** 无论所选主机提供什么； OpenRouter 添加了一个网络跃点，但没有自己的计算

OpenRouter 列出了一些价格低于 DeepInfra 的小型主机，并以一系列精度提供服务。如果输出一致性很重要，请固定主机。选择一台主机的团队通常会直接获取其完整的功能集、服务级别和支持。

### 8. 无羽人工智能

当您已经在许多开放模型中使用其与 OpenAI 兼容的 API 并且希望 K3.1 Pro 使用同一密钥时，[Featherless AI](https://featherless.ai/blog/kimi-k3-1-pro-is-live-on-featherless) 是最佳选择。

- **费率（开发者计划）：** 每 100 万代币输入 2.00 美元/缓存 0.20 美元/输出 10.00 美元
- **上下文：** 开发者计划 256K；专用实例上的完整 1M 窗口
- **数据：** 不记录提示或完成情况
- **部署：**无服务器 API，或专用 GPU 集群
- **速度：** 人工分析未跟踪此模型

256K 窗口是模型本机上下文的四分之一，这对于整个存储库和长文档工作很重要。它适合将许多开放模型整合到一个提供商下的团队。

## 关于许可证

Kimi K3.1 Pro 根据 [Kimi K3.1-Pro 许可证](https://huggingface.co/moonshotai/Kimi-K3.1-Pro) 发货，这是一个允许有条件商业使用的自定义许可证。任何 12 个月内集团收入超过 2000 万美元的模型即服务运营商需要与 Moonshot 签订单独协议，每月活跃用户超过 1 亿或月收入超过 2000 万美元的产品必须在其界面中显示“Kimi K3.1-Pro”。该许可证指定了内部使用和某些访问路线的豁免。阅读全文，或询问您的提供商，了解任一阈值是否适用于您。
