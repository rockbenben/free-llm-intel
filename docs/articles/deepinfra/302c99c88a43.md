# Qwen3.8-27B：前沿级视觉语言AI

DeepInfra 发布于 2026.10.09

![Qwen3.8-27B：前沿级视觉语言AI](https://deepinfrabldev.wpenginepowered.com/wp-content/uploads/2026/10/qwen3.8-27b-vision-language.png)

Qwen3.8-27B 是一个拥有 270 亿个参数的密集视觉语言模型，旨在缩小紧凑部署和前沿性能之间的差距。它专为复杂的多步骤任务而设计，包括编码、专业研究和长期代理工作流程。

该模型将原生视觉编码器与 262,144 个令牌上下文窗口配对，可扩展至 1,000,000 个令牌。它可以读取文本和视觉数据，从 STEM 图表到小时尺度的视频。它适合构建自主代理或文档智能工具的团队，这些工具可以在同一请求中对图像和长文档进行推理。

## **最新进展和架构**

Qwen3.8-27B 建立在 [Qwen3.5 系列](https://deepinfra.com/qwen) 的架构基础上，并对其前身 Qwen3.6-27B 进行了一些更改。

在底层，它是一个带有视觉编码器的 64 层因果语言模型，隐藏维度为 5,120。该布局将线性注意力（Gated DeltaNet）块与全注意力（Gated Attention）块混合在一起，并训练多令牌预测以加快生成速度。

### **灵活的思维控制**

Qwen3.8 最重要的新增功能之一是灵活的思维控制，它使开发人员能够对模型的推理过程进行精细控制。思考模式默认处于开启状态，可以根据请求禁用，或者进行调整而不是完全关闭：

- **推理深度：**使用reasoning_effort参数使计算资源与任务复杂性保持一致。
- **思考持久性：**preserve_thinking 参数保留早期消息的推理上下文，从而提高长期运行的代理工作流程的连续性。

### **原生多模式智能**

Qwen3.8-27B 不依赖外部视觉插件，而是对图像和视频理解提供原生支持。它在其 262,144 个令牌的本机上下文窗口中处理复杂的文档和视觉数据。

## **性能基准和比较分析**

Qwen3.8-27B 在大多数文本和多模式评估中优于 Qwen3.6-27B 和 Muse Glimmer-30B，并在多个代理和编码基准测试中击败了更大的 Opus4.6 Max。

### **主要亮点**

- **代理执行：**该模型在 UI 导航方面领先 OSWorld 验证，得分为 84.3。它还在多模式工具使用方面取得了最强的结果，ClawEval-MM 上的 Pass@3 为 57.4。
- **软件工程：**内部 QwenSWEBench 的得分为 79.0，是其比较集中最好的，远远领先于 Qwen3.6-27B 的 49.3 分和 Opus4.6 Max 的 63.8 分。它标志着处理复杂的多文件代码库的巨大飞跃。
- **效率：**多令牌预测被训练到架构中，通常通过每次前向传递生成多个令牌来提高推理速度。

## **API 入门**

[DeepInfra](https://deepinfra.com/models?type=text- Generation) 提供了兼容 OpenAI 的 API，可将 Qwen3.8-27B 集成到您的应用程序中。

### **身份验证**

要与 API 交互，请在 HTTP 标头中使用您的 DeepInfra API 密钥：
```
Authorization: Bearer <YOUR_DEEPINFRA_API_KEY>
Content-Type: application/jsoncopy
```
### **API端点基础知识**

- **端点：**https://api.deepinfra.com/v1/openai/chat/completions
- **型号标识符：**Qwen/Qwen3.8-27B

完整的参数参考（包括流式传输）位于 [Qwen3.8-27B API 页面](https://deepinfra.com/Qwen/Qwen3.8-27B/api)。

### **使用 cURL**
```
curl https://api.deepinfra.com/v1/openai/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $DEEPINFRA_API_KEY" \
  -d '{
    "model": "Qwen/Qwen3.8-27B",
    "messages": [
      {
        "role": "user",
        "content": "Write a Python function to check if a number is prime."
      }
    ]
  }'copy
```
**使用Python**
```
import requests
import os

API_KEY = os.getenv("DEEPINFRA_API_KEY")
url = "https://api.deepinfra.com/v1/openai/chat/completions"

headers = {
    "Authorization": f"Bearer {API_KEY}",
    "Content-Type": "application/json"
}

payload = {
    "model": "Qwen/Qwen3.8-27B",
    "messages": [{"role": "user", "content": "Explain the benefits of the Qwen3.8 architecture."}]
}

response = requests.post(url, headers=headers, json=payload)
print(response.json())copy
```
## **高级配置参数**

使用 JSON 负载中的以下参数自定义模型的行为：

| **参数** | **类型** | **描述** |
| ---| ---| ---|
| **型号** |字符串|必需的。设置为 Qwen/Qwen3.8-27B。 |
| **消息** |数组|必需的。支持文本、图像和视频输入。 |
| **推理_努力** |字符串/浮点数 |当思维模式处于活动状态时调整推理深度。 |
| **保留思维** |布尔 |保留多轮对话中的推理上下文。 |
| **响应格式** |对象|使用 {“type”: “json_object”} 进行结构化 JSON 输出。 |
| **流** |布尔 |设置为 true 以接收令牌流形式的响应。 |

## **结论**

Qwen3.8-27B 在 27B 密集模型中结合了 1M 令牌可扩展上下文窗口、灵活的思维控制和强大的多模态推理。对于要求较高的代理和文档繁重的工作负载来说，它是一个强大的选择。需要更多空间的团队还可以考虑更大的 [Qwen3.8-2.4T-A95B](https://deepinfra.com/Qwen/Qwen3.8-2.4T-A95B)，这是 Qwen3.8-Max 的稀疏专家混合变体。
