# Qwen3.8-27B：前沿水平的视觉语言 AI

发布于 2026.10.09，作者 DeepInfra

![Qwen3.8-27B：前沿水平的视觉语言 AI](https://deepinfrabldev.wpenginepowered.com/wp-content/uploads/2026/10/qwen3.8-27b-vision-language.png)

Qwen3.8-27B 是一个 270 亿参数的稠密视觉语言模型，构建目标是弥合紧凑部署与前沿性能之间的距离。它为复杂的多步骤任务而设计，包括编码、专业研究，以及长周期的智能体工作流。

这款模型把原生视觉编码器与 262,144 token 的上下文窗口结合在一起，可扩展到 1,000,000 token。它同时读取文本和视觉数据，从 STEM 图表到小时级的视频都能处理。它适合这样的团队：要构建自主智能体，或要在同一个请求里对图片和长文档做推理的文档智能工具。

## **最新进展与架构**

Qwen3.8-27B 构建在 [Qwen3.5 系列](https://deepinfra.com/qwen)的架构基础之上，相比前代 Qwen3.6-27B 引入了若干变化。

内部结构上，它是一个 64 层的因果语言模型，附带一个视觉编码器，隐藏维度为 5,120。层的布局把线性注意力（Gated DeltaNet）块与全注意力（Gated Attention）块混合在一起，并把 multi-token prediction 一并训练进模型，用来加快生成。

### **灵活的思考控制**

Qwen3.8 最重要的新增项之一是灵活的思考控制，它让开发者可以对模型的推理过程做细粒度掌控。思考模式默认开启，可以按请求关闭，也可以只是调节强度而不是整个关掉：

- **推理深度： **用 reasoning_effort 参数把算力资源与任务复杂度对齐。
- **思考延续： **preserve_thinking 参数会保留此前消息里的推理上下文，改善长时间运行的智能体工作流中的连续性。

### **原生多模态智能**

Qwen3.8-27B 不依赖外部视觉插件，而是原生支持图像和视频理解。它在自身 262,144 token 的原生上下文窗口内处理复杂文档和视觉数据。

## **性能基准与对比分析**

在大多数文本与多模态评测中，Qwen3.8-27B 的表现都优于 Qwen3.6-27B 和 Muse Glimmer-30B，并在若干智能体与编码基准上胜过了参数更大的 Opus4.6 Max。

### **文本与推理性能**

| **基准** | **Qwen3.8-27B** | **Qwen3.6-27B** | **Muse Glimmer-30B** | **Opus4.6 Max** |
| --- | --- | --- | --- | --- |
| **GPQA Diamond（科学推理）** | 89.2 | 87.8 | 83.5 | 91.3 |
| **SWE-bench Pro（智能体编码）** | 61.7 | 53.5 | 51.2 | 53.4 |
| **LiveCodeBench v6（竞赛级编程）** | 90.3 | 83.9 | N/A | 88.8 |
| **IFBench（指令遵循）** | 79.5 | 69.1 | 77.0 | 62.5 |
| **CoWorkBench（长周期办公任务）** | 70.7 | 61.0 | N/A | 68.2 |

### **视觉语言性能**

| **基准** | **Qwen3.8-27B** | **Qwen3.6-27B** | **Muse Glimmer-30B** | **Opus4.6 Max** |
| --- | --- | --- | --- | --- |
| **OSWorld-Verified（计算机操作）** | 84.3 | 63.9 | 65.9 | 72.7 |
| **MathVision，带推理（视觉数学）** | 94.6 | 85.1 | N/A | 65.5 |
| **OmniDocBench 1.5（文档智能）** | 91.1 | 89.4 | N/A | 86.6 |
| **RealWorldQA（感知）** | 85.9 | 84.1 | N/A | 73.9 |

### **关键亮点**

- **智能体执行： **模型在考察 UI 导航的 OSWorld-Verified 上以 84.3 领先。它在多模态工具使用上也追平了最强结果，在 ClawEval-MM 上的 Pass@3 为 57.4。
- **软件工程： **在内部的 QwenSWEBench 上拿到 79.0，是对比集合中的最好成绩，明显领先于 Qwen3.6-27B 的 49.3 和 Opus4.6 Max 的 63.8。这意味着它在处理复杂的多文件代码库时有了一次大幅跃升。
- **效率： **multi-token prediction 直接训练进了架构，它每次前向传播生成不止一个 token，通常能提升推理速度。

## **API 上手**

[DeepInfra](https://deepinfra.com/models?type=text-generation) 提供兼容 OpenAI 的 API，方便你把 Qwen3.8-27B 接入自己的应用。

### **身份验证**

要与 API 交互，请在 HTTP 头部带上你的 DeepInfra API key：

```
Authorization: Bearer <YOUR_DEEPINFRA_API_KEY>
Content-Type: application/jsoncopy
```

### **API 端点基础**

- **端点： **https://api.deepinfra.com/v1/openai/chat/completions
- **模型标识： **Qwen/Qwen3.8-27B

完整的参数参考（包括流式输出）在 [Qwen3.8-27B API 页面](https://deepinfra.com/Qwen/Qwen3.8-27B/api)上。

### **使用 cURL**

```
curl https://api.deepinfra.com/v1/openai/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $DEEPINFRA_API_KEY" \
  -d '{
    "model": "Qwen/Qwen3.8-27B",
    "messages": [
      {
        "role": "user",
        "content": "Write a Python function to check if a number is prime."
      }
    ]
  }'copy
```

**使用 Python**

```
import requests
import os

API_KEY = os.getenv("DEEPINFRA_API_KEY")
url = "https://api.deepinfra.com/v1/openai/chat/completions"

headers = {
    "Authorization": f"Bearer {API_KEY}",
    "Content-Type": "application/json"
}

payload = {
    "model": "Qwen/Qwen3.8-27B",
    "messages": [{"role": "user", "content": "Explain the benefits of the Qwen3.8 architecture."}]
}

response = requests.post(url, headers=headers, json=payload)
print(response.json())copy
```

## **进阶配置参数**

用 JSON 负载中的以下参数来自定义模型行为：

| **参数** | **类型** | **说明** |
| --- | --- | --- |
| **model** | string | 必填。设为 Qwen/Qwen3.8-27B。 |
| **messages** | array | 必填。支持文本、图像和视频输入。 |
| **reasoning_effort** | string / float | 思考模式处于开启状态时，调节推理深度。 |
| **preserve_thinking** | boolean | 在多轮对话之间保留推理上下文。 |
| **response_format** | object | 需要结构化的 JSON 输出时，使用 {“type”: “json_object”}。 |
| **stream** | boolean | 设为 true，以 token 流的形式接收响应。 |

## **结论**

Qwen3.8-27B 在一个 27B 的稠密模型里，把可扩展到 1M token 的上下文窗口、灵活的思考控制和强劲的多模态推理结合到了一起。对于要求高的智能体负载和文档密集的负载，它是一个称职的选择。需要更大余量的团队也可以看看参数更大的 [Qwen3.8-2.4T-A95B](https://deepinfra.com/Qwen/Qwen3.8-2.4T-A95B)，那是 Qwen3.8-Max 的稀疏 Mixture-of-Experts 变体。
