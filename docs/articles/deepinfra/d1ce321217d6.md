# 西方开放权重模型：Beam 与 Le Chonk

发布于 2026.10.14，作者 Stefan Fidanov

![西方开放权重模型：Beam 与 Le Chonk](https://deepinfrabldev.wpenginepowered.com/wp-content/uploads/2026/10/Western-Open-Weight-Models_-The-Deployability-Case.png)

Reflection AI 和 Mistral 在 10 月的第一周、相隔一天各自发布了开放权重的旗舰模型，两家都声称自己能与中国拿得出手的最好模型相提并论。

[Reflection 的 Beam](https://reflection.ai/blog/introducing-beam) 是一个 501B 参数的干活主力，声称在只花一小部分推理算力的前提下达到 [GLM-5.2](https://deepinfra.com/zai-org/GLM-5.2) 水平的推理能力——而这条标准线 Z.ai 已经用 [GLM-5.3](https://deepinfra.com/blog/glm-5-3-deepinfra) 往上抬过一次。[Mistral 的 Large 4](https://mistral.ai/news/mistral-large-4/) 被该公司昵称为 “le Chonk”，是一个 1 万亿参数的旗舰，在欧洲构建、在欧洲训练、也在欧洲提供服务。

中国实验室依然是单位能力价格这条线的制定者，这两次发布都没有把它挪动。在 Artificial Analysis 的开放权重指数上，Le Chonk 得分 38，MiMo-V2.6-Pro 是 46，GLM-5.3 是 45。

于是西方的这套说辞落在另外四个问题上：模型在哪里运行、由谁运维、适用哪份许可证，以及每个答案各自要花多少钱。下面我们把这件事拆细一点看。

| --- | --- | --- | --- | --- | --- |

| Mistral Large 4 (le Chonk) | 法国 | 1.05T / 49B | 尚未公布 | 10 月底 | [Mistral Studio preview](https://docs.mistral.ai/models/mistral-large-4-0)，每 1M token $1.36 / $4.18 |
| [GLM-5.3](https://deepinfra.com/zai-org/GLM-5.3) | 中国 | 753B / ~40B | 自定义 GLM-5.3 License | 公开 | DeepInfra，每 1M token $0.90 / $4.00 |

## 中国实验室定下的单位能力价格这条线

过去一年半，开放权重的最前沿一直属于中国。Nathan Lambert 的 [Interconnects](https://interconnects.ai/p/the-current-balance-of-power-in-open) 把中国的明显领先定在 2025 年 4 月前后，而 Hugging Face 的 [2026 年夏季开放模型现状](https://huggingface.co/blog/state-of-open-models-summer-2026) 发现，今年发布的超过 100B 参数的模型，要么构建在中国模型之上，要么用到了中国实验室的产物。

中国实验室还把强模型和激进定价配在一起。在 Artificial Analysis 的 [开放权重排行榜](https://artificialanalysis.ai/models/open-source)（Intelligence Index v4.3.2）上，[MiMo-V2.6-Pro](https://deepinfra.com/XiaomiMiMo/MiMo-V2.6-Pro) 得分 **46**，GLM-5.3 得分 **45**，Kimi K3 得分 **44**，[GLM-5.3-Flash](https://deepinfra.com/zai-org/GLM-5.3-Flash) 得分 **42**。该榜上最好的美国条目是 Inkling 的 **25** 和 Nemotron 3 Ultra 的 **23**。Le Chonk 在 [它自己的 Artificial Analysis 页面](https://artificialanalysis.ai/models/mistral-large-4) 上落到 **38** 分，AA 的发布分析称它是“美国和中国之外最智能的模型”。

把它们和输出价格放在一起看。

左上角属于中国。GLM-5.3-Flash 在 DeepInfra 上按每百万输出 token $0.50 拿到 42 分，而西方模型价格更高、分数反而更低。Beam 缺席，因为它在两个轴上都还没有数据。Artificial Analysis 没给它打分，Reflection 也没公布定价。只看每一美元换来的跑分，就很容易明白这两家实验室为什么选择去论证别的东西。（更宽泛的 [开放对闭源这一版权衡](https://deepinfra.com/blog/open-vs-closed-source-ai-models)我们单独写过。）

## Beam：一个靠每答案算力来卖的干活主力

Reflection 的[发布文章](https://reflection.ai/blog/introducing-beam)承认 Kimi K3 在原始能力上仍然领先，于是它改从效率角度卖 Beam。按它的说法，Beam “取得了与 GLM-5.2 相当的分数，却少用 3–4× 的推理算力”。Beam 是一个纯文本的 mixture-of-experts (MoE) 模型，总参数 501B、每个 token 激活 23B，在 6,144 块 NVIDIA GB300 GPU 上用 23.8T token 完成预训练。

在引用那个数字之前先读脚注。Reflection 把生成算力定义为大约 2 × 激活参数 × 每次作答平均生成的 token 数，计算推理部分加上最终答案。这使它成为一个估算值，而它的第一个因子很容易画出来：

Beam 的 23B 激活参数（高亮部分）对比 GLM-5.2 的[大约 40B](https://techcrunch.com/2026/10/05/reflection-debuts-beam-a-open-weight-ai-model-to-rival-chinese-models-at-lower-compute-cost/)，带来每 token 大约 1.7x 的优势。DeepSeek V4.1 Flash 和 GLM-5.3-Flash 还要更精简。要达到 3-4x，剩下的部分必须来自 Beam 每次答案生成更少的 token。拿到了早期访问权限的 Artificial Analysis [说](https://x.com/artificialanlys/status/2107219177132155233)，Beam 看起来是“我们在其智能水平上所见过的最省 token 的开放模型之一”。算术如下：

```
def decode_flops(active_params_b: float, generated_tokens: int) -> float:
    """Reflection's proxy: 2 x active params x generated tokens (decode only)."""
    return 2 * active_params_b * 1e9 * generated_tokens

# Active parameters, in billions
BEAM, GLM_5_2 = 23, 40

param_ratio = GLM_5_2 / BEAM
print(f"Per-token advantage from active params: {param_ratio:.2f}x")

# What token ratio would close the gap to Reflection's 3-4x claim?
for claimed in (3.0, 4.0):
    implied = claimed / param_ratio
    print(f"{claimed:.0f}x total implies GLM-5.2 writes {implied:.2f}x more tokens per answer")

# Sanity check with a hypothetical 6,000-token reasoning trace
print(f"Beam, 6k tokens: {decode_flops(BEAM, 6_000) / 1e12:.0f} TFLOPs")copy
```

那么同样的结果，GLM-5.2 就得写出多大约 1.7x 到 2.3x 的输出 token。Beam 真的推理得这么短吗？在权重发布、独立评测方测量它的输出长度之前，这一点无从验证。等它能被调用之后，用你自己的 prompt 去验一验这个说法。这个公式还把智能体负载里占大头的成本漏掉了。

prefill 就是大头。一个每次工具调用都要重读 100K token 上下文的智能体循环，大部分算力花在“读”上，而 3-4x 这个数字对那个阶段只字未提。此外，尽管每个 token 只激活 23B，全部 501B 参数还是都得待在 GPU 显存里。正如我们在[小型开放权重模型隐藏的成本优势](https://deepinfra.com/blog/small-open-weight-models-cost)里论证的：每个完成任务的成本更多跟轮次和 token 数挂钩，而不是每 token 单价。

## Le Chonk：一个靠“在哪儿运行”来卖的旗舰

Mistral 走了另一条路。[Mistral Large 4](https://mistral.ai/news/mistral-large-4/) 是一个 1.05T 参数的 MoE，每个 token 激活 49B（按它 [Hugging Face 模型卡](https://huggingface.co/mistralai/Mistral-Large-4.0-1T05-A52B) 的说法，算上 embedding 和输出层是 52B）。它接受文本和图像输入，覆盖 160 多种语言，Mistral 称它显著超过“任何在美国或欧洲开发的开放权重模型”。至于规格，请按实际交付的能力来规划，而不是按纸面印出来的：Mistral 的文档列出 1M token 上下文窗口，但 Artificial Analysis 对它测过的 preview API 列的是大约 512K；而 Beam 的 beta API 把请求上限设为 256K，尽管宣称是 1M。

最醒目的是司法辖区。Mistral 说 Large 4 是在它自有的欧洲数据中心里、用 3,800 块 NVIDIA Grace Blackwell GPU 从零训练出来的，preview 也跑在同样的硬件上。它将运行在“一个由 Mistral 端到端运维、独立于其他数字服务提供商、并受欧洲法律约束的欧洲部署”里，而涉及安全的工作负载可以跑在私有云或本地机房。Guillaume Lample 对 [WIRED](https://www.wired.com/story/mistral-new-model-le-chonk-open-source-china-us-frontier/) 把这层理由说得很直白：“如果你用的是闭源模型，没人能保证它明天还在。”

把它想成一架梯子，每一级都让模型更接近你自己掌控的硬件。

今天 Le Chonk 只站在最下面两级，而上面两级取决于 Mistral 尚未公布的许可证。能力是实打实的，但 。Artificial Analysis [测得](https://artificialanalysis.ai/articles/mistral-large-4-france-ai)按标价每个 Intelligence Index 任务 $1.13，比 GLM-5.3-Flash 这类分数更高的开放模型贵 4 倍以上，部分原因是 Large 4 为了跑完整份指数产出了 200M 输出 token，而中位数只有 82M。[开放权重的数据主权这套说法](https://deepinfra.com/blog/data-sovereignty-ai-open-weight-adoption)只有在你真能往上爬那架梯子时才会兑现。这两次发布同样缺少独立的服务指标。Beam 和 Large 4 都没有在负载下测得的延迟、吞吐或首 token 时间，所以这架梯子评估的是一个模型能在哪儿运行；它服务得好不好，得等权重发布、提供方公布测量数字之后才知道。

Inkling 是你现在就能调用的、最接近“西方版 Beam”的东西。它是一个 Apache 2.0 许可下的 975B MoE，而且接受音频，这是 Beam 和 Le Chonk 都做不到的。Nemotron 3 Ultra 的卖点是超越权重本身的开放度，因为 NVIDIA 在放出 checkpoint 的同时也[发布](https://research.nvidia.com/labs/nemotron/Nemotron-3-Ultra/)了训练数据和训练配方。在便宜那一端，gpt-oss-120b 和 [Nemotron 3 Super](https://deepinfra.com/blog/nvidia-nemotron-3-super-deepinfra) 是干脏活累活的选择。当每百万输出 token 只要 $0.17 和 $0.40 时，分诊和路由这类步骤上前沿能力就不再重要了。

## 许可证才是西方开放权重模型能赢的地方

扫一眼许可证那一列，会发现中国旗舰正朝着自定义条款漂移。GLM-5.2 发布时用的是普通的 MIT，但 GLM-5.3 换成了[自己的许可证](https://huggingface.co/zai-org/GLM-5.3/blob/main/LICENSE)，要求营收超过 $100 亿的公司必须先通过 Z.ai 的安全审查，才能把它作为托管服务提供。[Kimi K3](https://deepinfra.com/moonshotai/Kimi-K3) 和 [Qwen3.8-Max](https://deepinfra.com/Qwen/Qwen3.8-Max) 各自用自己命名的许可证发布，附带商业条件。DeepSeek 是唯一没跟着动的，仍然用 MIT。

西方这一侧在朝相反方向移动，至少 Reflection 如此。Beam 的权重承诺以 Apache 2.0 发布，与 Inkling、gpt-oss-120b 和 Gemma 4 一致。这正是法务团队不用开会就会批的那份许可证。Mistral 是个未决问题。它上一代旗舰 [Mistral Large 3](https://huggingface.co/mistralai/Mistral-Large-3-675B-Instruct-2512) 是 Apache 2.0，但它最近的中型发布 [Medium 3.5](https://huggingface.co/mistralai/Mistral-Medium-3.5-128B/blob/main/LICENSE) 用的是一份改过的 MIT 许可证，把月营收超过 $2000 万的公司排除在外。Large 4 的 Hugging Face 页面干脆没有许可证这一栏。

Axios 也[指出](https://axios.com/2026/10/06/reflection-mistral-open-weight-ai-models-china)，FY2026 NDAA 指示国防部把 DeepSeek 从政府及其承包商系统中移除，而西方的这些发布让企业有了替代品，可以取代它们出于安全考虑可能一直回避的中国选项。Reflection 的 CEO Misha Laskin 对 Axios 说：“当你在智能上花到那个量级的钱，你就会想从租用转向自己拥有。”

“产地”这个词里藏着三种不同的风险。

- **服务地点**说的是谁的机房在处理你的 prompt：今天你在 DeepInfra 上能调用的每一个模型，不管是不是中国出身，都跑在美国数据中心、零留存，这就覆盖了绝大多数数据处理方面的顾虑。
- **权重出身**指的是谁构建了这个模型、它的许可证允许什么，这决定法律风险敞口以及你能改动什么。
- **法定采购**是最窄的一种情形，也是唯一一个出身本身就足以一票否决的情形：如果 NDAA 或客户合同排除中国出身的权重，那么在美国提供服务怎么变都没用，而你的选项就是 Beam、Le Chonk、Inkling、Nemotron 和 gpt-oss。

如果法定采购不是你的处境，那中国旗舰凭单位能力价格挣得了它们的位置。同一个区分也回答了关于 Le Chonk 的那个明显问题：如果你明确需要它在欧洲法律之下运行，那条路只能走 Mistral 自有的 EU 部署，或者等权重发布后自托管；美国的推理提供方给不了欧洲司法辖区。

## 今天就在 DeepInfra 上运行西方开放权重模型

你不必等这两个发布中的任何一个，就能把管线搭起来。把模型选择变成代码里的一个策略决定，让出身和许可证跟价格待在同一个地方。DeepInfra 通过一个 OpenAI 兼容的 endpoint 提供一大堆模型，所以这份策略不过是一份模型 ID 列表。

```
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["DEEPINFRA_API_TOKEN"],
    base_url="https://api.deepinfra.com/v1/openai",
)

# Candidates per role, tagged with origin and license.
# Add Beam or Mistral Large 4 here once a provider serves their weights.
CATALOG = {
    "agent": [
        ("thinkingmachines/Inkling", "US", "apache-2.0"),
        ("nvidia/NVIDIA-Nemotron-3-Ultra-550B-A55B", "US", "openmdw-1.1"),
        ("zai-org/GLM-5.3", "CN", "glm-5.3"),
    ],
    "triage": [
        ("openai/gpt-oss-120b", "US", "apache-2.0"),
        ("deepseek-ai/DeepSeek-V4.1-Flash", "CN", "mit"),
    ],
}

POLICY = {"origins": {"US", "EU"}, "licenses": {"apache-2.0", "openmdw-1.1", "mit"}}


def allowed(role: str) -> list[str]:
    return [
        model for model, origin, license_id in CATALOG[role]
        if origin in POLICY["origins"] and license_id in POLICY["licenses"]
    ]


def complete(role: str, messages: list[dict]) -> str:
    last_error = None
    for model in allowed(role):  # first allowed model wins, the rest are fallbacks
        try:
            resp = client.chat.completions.create(model=model, messages=messages, timeout=60)
            return resp.choices[0].message.content
        except Exception as err:
            last_error = err
    raise RuntimeError(f"No allowed model succeeded for role {role!r}") from last_error


print(complete("triage", [{"role": "user", "content": "Classify: 'refund not received'"}]))copy
```

把 POLICY 放松一点，GLM-5.3 就会加入智能体池。等 Beam 的权重落地，那只是再多一个 tuple。

接下来做一个 token 效率检查，因为 Beam 的论点建立在每次答案生成的 token 数上。用同一组 prompt 跑一遍候选模型，记录每个模型写了多少：

```
import asyncio
import os
from openai import AsyncOpenAI

client = AsyncOpenAI(
    api_key=os.environ["DEEPINFRA_API_TOKEN"],
    base_url="https://api.deepinfra.com/v1/openai",
)

# (model id, active params in billions, $ per 1M input, $ per 1M output)
CANDIDATES = [
    ("thinkingmachines/Inkling", 41, 0.95, 4.05),
    ("nvidia/NVIDIA-Nemotron-3-Ultra-550B-A55B", 55, 0.50, 2.20),
    ("zai-org/GLM-5.3", 40, 0.90, 4.00),
]

PROMPT = [{"role": "user", "content": "Find the bug: def avg(xs): return sum(xs) / len(xs) - 1"}]


async def measure(model: str, active_b: float, price_in: float, price_out: float) -> dict:
    resp = await client.chat.completions.create(model=model, messages=PROMPT)
    u = resp.usage
    return {
        "model": model.split("/")[-1],
        "out_tokens": u.completion_tokens,
        "decode_tflops": 2 * active_b * 1e9 * u.completion_tokens / 1e12,
        "cost_usd": (u.prompt_tokens * price_in + u.completion_tokens * price_out) / 1e6,
    }


async def main():
    rows = await asyncio.gather(*(measure(*c) for c in CANDIDATES))
    for r in sorted(rows, key=lambda r: r["cost_usd"]):
        print(f"{r['model']:<40} {r['out_tokens']:>6} tok  {r['decode_tflops']:>7.1f} TFLOPs  ${r['cost_usd']:.5f}")


asyncio.run(main())copy
```

拿几百条真实 prompt 跑一遍，你就得到了在你自己负载上测出来的 Reflection 那个代理指标。等 Beam 可以被调用，加一行进去，看看那个 3-4x 能不能扛住你的真实流量。

这里的一切都跑在 DeepInfra 的按量付费定价上、无需签合同，底层是通过 SOC 2 和 ISO 27001 认证、零留存的美国基础设施。

## 结论

Beam 和 Le Chonk 都没有缩小与最好那批中国开放模型之间的差距。Reflection 自己的表格就是这么显示的，Artificial Analysis 也一样。它们改的是比较的条款本身。这道分野整齐得近乎刻意：Beam 靠“每次答案写更少的 token”来卖，讲的是每答案算力和 Apache 2.0 许可证；而 Le Chonk 为了跑完 Artificial Analysis 的指数烧掉了 200M 输出 token，讲的是欧洲运维和本地掌控。Inkling、Nemotron 3 系列和 gpt-oss-120b 已经在宽松许可和价格上竞争了。如果你的采购规则排除中国出身的权重，那么这是头一回出现一份真正可选的菜单，而且随着权重落地，这份菜单还会变长。

## 常见问题

### Reflection Beam 在 DeepInfra 上能用吗？

还不行。截至发布时，Beam 只能通过 Reflection 自己 OpenAI 兼容 API 上的 waitlist beta 使用，它的 Hugging Face 组织下也没有公开模型。Reflection 承诺 10 月晚些时候发布 Apache 2.0 权重，推理提供方要等那些权重发布后才能托管这个模型。在那之前，DeepInfra 上最接近的西方 MoE 是 Inkling。

### Mistral Large 4 的权重什么时候发布，用什么许可证？

Mistral 说是 10 月底，它的 Hugging Face 页面列的 ETA 是 10 月 31 日。Mistral 还没宣布许可证，而它最近的几次发布也没能把这个问题定下来，所以在规划自托管部署之前先去确认 LICENSE 文件。

### Beam 运行起来真的比 GLM-5.2 便宜 3-4x 吗？

不一定体现在美元上。3-4x 这个数字只估算了 decode 算力，而 Reflection 还没公布定价，所以美元成本未知。上面代码那一节里的 token 效率检查会在你自己的流量上把它测出来。
