# 从录音到记录：NVIDIA Nemotron 3.5 在 DeepInfra 上转录

发布于 2026.10.28 作者：Aray Sultanbekova

![从记录到记录：NVIDIA Nemotron 3.5 在 DeepInfra 上转录](https://deepinfra.com/blog/nvidia-nemotron-3-5-transcribe-release.png)

[NVIDIA Nemotron 3.5 Transcribe](https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Transcribe-30B-A4B) 现已在 [DeepInfra](https://deepinfra.com/nvidia/NVIDIA-Nemotron-3.5-Transcribe-30B-A4B) 上发布，从发布的第 0 天开始。它是一种开放权重语音模型，可以在一个模型中处理转录、说话者归因、语音翻译、上下文偏差和音频理解。在 DeepInfra 上，它通过兼容 OpenAI 的语音转文本 API 提供服务，并提供转录、单词和片段时间戳、上下文提示以及英语翻译。 API 中的演讲者归属功能即将推出。

构建呼叫分析、会议工具和媒体产品的团队需要的不仅仅是原始记录。他们需要知道谁说了什么，正确理解领域术语，处理多语言录音，并从音频中提取答案。构建此模型的一种方法是将 ASR 模型、二值化模型、翻译模型和 LLM 链接起来。这是可行的，但它增加了集成工作并使管道更难以评估。

Nemotron 3.5 Transcribe 将这些任务整合到一个模型中，因此单个请求可以返回适合您的应用程序的转录本。

## Nemotron 3.5 Transcribe 有何不同？

**多种语音任务，一种模型。** NVIDIA 在单个检查点报告 11 项语音任务，包括多语言 ASR、语音翻译、语码转换、说话人归因、单词时间戳、带有标点符号和大小写的丰富转录以及音频理解。您可以编排一个模型而不是多个模型。

**上下文感知转录。** 在简短的提示中传递域名术语和产品名称。该模型使用该上下文来帮助识别通用 ASR 经常遗漏的名称，例如药品名称、产品名称或客户名称。

**多语言。** NVIDIA 报告了 40 种语言的转录、英语和 31 种语言之间的语音翻译以及跨 13 种语言的语码转换。在 DeepInfra 上，可以通过 OpenAI 兼容的“/audio/translations”端点进行英语翻译。

**一次请求中的长录音。** 在一次请求中发送最多 60 分钟的音频，无需分块或拼接。

**高效的专家混合 (MoE) 设计。** Nemotron 3.5 Transcribe 是一种语音增强语言模型 (SALM)：语音和说话人编码器为自回归 Nemotron 3.5 Lightning MoE 主干网提供数据。 30B-A4B 设计每个令牌激活大约 4B 个参数。

**专为录制音频而构建。** 它是一种离线（非流式传输）模型，是您处理录制的通话、会议和媒体或对实时通话记录进行第二次传递时的选择。

## 它是如何执行的

NVIDIA 报告称，Nemotron 3.5 Transcribe 的转录准确性可与领先的专有语音 API 相媲美，完整结果请参见其[技术报告](https://research.nvidia.com/labs/nemotron/files/NVIDIA-Nemotron-3.5-Transcribe-Technical-Report.pdf)。

独立研究结果也表明了同样的观点。在 [Cekura](https://www.cekura.ai/) 的语音转文本排行榜上，Nemotron 3.5 Transcribe 在 Cekura 采购的独家私有数据集 Ocular WER** 上排名**#1，单词错误率为 2.48%，领先于板上的所有专有 API。私人设备是您自己录音的最接近的代理，因为没有模型可以在其上进行调整。

!【Cekura Oural WER 排行榜：NVIDIA Nemotron 3.5 Transcribe 以 2.48% WER 排名第一】(https://deepinfra.com/blog/nemotron-3-5-transcribe-cekura- eyes-wer.webp)

在 Cekura 的公共 Pipecat WER 集上，它的得分为 2.32%，与领先者相差半分左右，领先于 Cartesia Ink 2、Speechmatics Linden、Soniox STT-RT v5 和 Deepgram Nova-3。

![Cekura Pipecat WER 排行榜：NVIDIA Nemotron 3.5 转录率为 2.32% WER](https://deepinfra.com/blog/nemotron-3-5-transcribe-cekura-pipecat-wer.webp)

它是这两个排行榜上唯一的开放权重模型，因此这种准确性伴随着您可以检查、微调或自行运行的权重。

## 你可以构建什么

- **联络中心分析：** 将记录的支持呼叫转换为带时间戳的文字记录，以进行质量检查和呼叫后分析，并提供产品名称作为上下文。
- **会议和笔记工具：** 转录长达 60 分钟的会议，为总结和行动项目做好准备。
- **媒体和字幕：** 转录录制的媒体或将其翻译成英语，并为字幕、搜索和导航提供单词时间戳。
- **可搜索的音频档案：** 将成绩单与 DeepInfra 上的 [NVIDIA Nemotron 3.5 Embed](https://deepinfra.com/nvidia/Nemotron-3.5-Embed-8B-BF16) 和 [Nemotron 3.5 Rerank](https://deepinfra.com/nvidia/Nemotron-3.5-Rerank-8B-BF16) 配对，以便从数千个通话中检索正确的时刻。

## 开始使用

Nemotron 3.5 Transcribe 在 DeepInfra 兼容 OpenAI 的语音转文本端点上运行。将 OpenAI SDK 指向 DeepInfra，发送音频文件，并添加一个简短的提示，其中包含与您的域相关的术语。
```
import os

from openai import OpenAI

client = OpenAI(
    api_key=os.environ["DEEPINFRA_API_KEY"],
    base_url="https://api.deepinfra.com/v1/openai",
)

with open("support_call.mp3", "rb") as audio:
    transcript = client.audio.transcriptions.create(
        model="nvidia/NVIDIA-Nemotron-3.5-Transcribe-30B-A4B",
        file=audio,
        prompt="Customer support call about a GPU cloud bill. "
               "Terms: DeepInfra, Nemotron.",
    )

print(transcript.text)
copy
```
对于标题或搜索，请询问单词和片段时间戳：
```
with open("support_call.mp3", "rb") as audio:
    transcript = client.audio.transcriptions.create(
        model="nvidia/NVIDIA-Nemotron-3.5-Transcribe-30B-A4B",
        file=audio,
        response_format="verbose_json",
        timestamp_granularities=["word", "segment"],
    )

for segment in transcript.segments:
    print(f"[{segment.start:.1f}s - {segment.end:.1f}s] {segment.text}")
copy
```
还支持“srt”和“vtt”响应格式。要将语音翻译成英语，请使用相同的模型调用“client.audio.translations.create”。
