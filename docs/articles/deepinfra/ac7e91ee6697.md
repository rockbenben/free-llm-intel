# 从录音到记录：NVIDIA Nemotron 3.5 Transcribe 在 DeepInfra 上线

2026.10.28 发布，作者 Aray Sultanbekova

![从录音到记录：NVIDIA Nemotron 3.5 Transcribe 在 DeepInfra 上线](https://deepinfra.com/blog/nvidia-nemotron-3-5-transcribe-release.png)

[NVIDIA Nemotron 3.5 Transcribe](https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Transcribe-30B-A4B) 现已在 [DeepInfra](https://deepinfra.com/nvidia/NVIDIA-Nemotron-3.5-Transcribe-30B-A4B) 上线，与发布首日同步。它是一个开放权重语音模型，一个模型就能处理转写、说话人归属、语音翻译、上下文偏置和音频理解。在 DeepInfra 上，它通过兼容 OpenAI 的语音转文本 API 提供服务，目前支持转写、词级与片段级时间戳、上下文提示，以及翻译成英语。API 中的说话人归属功能即将推出。

打造通话分析、会议工具和媒体产品的团队，需要的不只是原始转写文本。他们需要知道是谁说了什么、需要把专业术语听准、需要处理多语种录音，并从音频中提取答案。实现这一点的一种方式，是把 ASR 模型、说话人分离（diarization）模型、翻译模型和 LLM 串起来。这条路可行，但会增加集成工作，也让整条流水线更难评估。

Nemotron 3.5 Transcribe 把这些任务收进一个模型，因此单次请求就能返回贴合你应用形态的转写结果。

## Nemotron 3.5 Transcribe 有何不同？

**多种语音任务，一个模型。** NVIDIA 称单个 checkpoint 就覆盖 11 项语音任务，包括多语种 ASR、语音翻译、语种切换、说话人归属、词级时间戳、带标点和大小写的完整转写，以及音频理解。你编排的是一个模型，而不是好几个。

**上下文感知的转写。** 用一段简短的 prompt 传入领域术语和产品名。模型会利用这些上下文，帮助识别通用 ASR 经常漏掉的名称，比如药品名、产品名或客户名。

**多语种。** NVIDIA 称支持 40 种语言的转写、英语与另外 31 种语言之间的语音翻译，以及跨 13 种语言的语种切换。在 DeepInfra 上，翻译成英语可通过兼容 OpenAI 的 `/audio/translations` 端点使用。

**单次请求处理长音频。** 单次请求最多可发送 60 分钟音频，你这边不需要做 chunking 或拼接。

**高效的 Mixture-of-Experts（MoE）设计。** Nemotron 3.5 Transcribe 是一个 Speech-Augmented Language Model（SALM）：语音编码器和说话人编码器为自回归的 Nemotron 3.5 Lightning MoE 主干网络供能。30B-A4B 的设计每个 token 激活约 4B 参数。

**为录制音频而生。** 它是一个离线（非流式）模型，适合处理录制下来的通话、会议和媒体，或对实时通话转写结果跑第二遍。

## 效果表现

NVIDIA 称 Nemotron 3.5 Transcribe 的转写准确率与领先的专有语音 API 相当，完整结果见其[技术报告](https://research.nvidia.com/labs/nemotron/files/NVIDIA-Nemotron-3.5-Transcribe-Technical-Report.pdf)。

独立评测的结果也指向同一结论。在 [Cekura](https://www.cekura.ai/) 的语音转文本排行榜上，Nemotron 3.5 Transcribe 在 Ocular WER 上**排名第一**——这是 Cekura 独家采购的私有数据集——词错误率为 2.48%，领先榜上的每一个专有 API。私有数据集最接近你自己的录音，因为任何模型都不可能针对它做过调优。

![Cekura Ocular WER 排行榜：NVIDIA Nemotron 3.5 Transcribe 以 2.48% WER 位居第一](https://deepinfra.com/blog/nemotron-3-5-transcribe-cekura-ocular-wer.webp)

在 Cekura 公开的 Pipecat WER 数据集上，它的得分为 2.32%，与榜首相差约 0.5 分，并领先 Cartesia Ink 2、Speechmatics Linden、Soniox STT-RT v5 和 Deepgram Nova-3。

![Cekura Pipecat WER 排行榜：NVIDIA Nemotron 3.5 Transcribe 的 WER 为 2.32%](https://deepinfra.com/blog/nemotron-3-5-transcribe-cekura-pipecat-wer.webp)

它是两个排行榜上唯一的开放权重模型，因此这份准确率背后是你可以检视、微调或自己运行的权重。

## 你可以构建什么

- **呼叫中心分析：** 把录下的支持通话转成带时间戳的转写文本，用于质检和通话后分析，同时把产品名作为上下文提供。
- **会议与笔记工具：** 转写长达 60 分钟的会议，直接可用于生成摘要和待办事项。
- **媒体与字幕：** 转写录制的媒体或把它翻译成英语，并提供词级时间戳用于字幕、检索和定位。
- **可检索的音频归档：** 把转写文本与 DeepInfra 上的 [NVIDIA Nemotron 3.5 Embed](https://deepinfra.com/nvidia/Nemotron-3.5-Embed-8B-BF16) 和 [Nemotron 3.5 Rerank](https://deepinfra.com/nvidia/Nemotron-3.5-Rerank-8B-BF16) 搭配使用，从数千通通话中检索出正确的那个片段。

## 快速上手

Nemotron 3.5 Transcribe 运行在 DeepInfra 兼容 OpenAI 的语音转文本端点上。把 OpenAI SDK 指向 DeepInfra，发送一个音频文件，并附上一段简短的 prompt，写上对你的领域重要的术语。

```
import os

from openai import OpenAI

client = OpenAI(
    api_key=os.environ["DEEPINFRA_API_KEY"],
    base_url="https://api.deepinfra.com/v1/openai",
)

with open("support_call.mp3", "rb") as audio:
    transcript = client.audio.transcriptions.create(
        model="nvidia/NVIDIA-Nemotron-3.5-Transcribe-30B-A4B",
        file=audio,
        prompt="Customer support call about a GPU cloud bill. "
               "Terms: DeepInfra, Nemotron.",
    )

print(transcript.text)
copy
```

要生成字幕或做检索，就要求词级和片段级时间戳：

```
with open("support_call.mp3", "rb") as audio:
    transcript = client.audio.transcriptions.create(
        model="nvidia/NVIDIA-Nemotron-3.5-Transcribe-30B-A4B",
        file=audio,
        response_format="verbose_json",
        timestamp_granularities=["word", "segment"],
    )

for segment in transcript.segments:
    print(f"[{segment.start:.1f}s - {segment.end:.1f}s] {segment.text}")
copy
```

同样支持 `srt` 和 `vtt` 响应格式。要把语音翻译成英语，用同一个模型调用 `client.audio.translations.create`。
