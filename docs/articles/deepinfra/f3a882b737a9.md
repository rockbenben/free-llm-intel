## 关于Kimi K3.1 Pro

Kimi K3.1 Pro 是在 Kimi K3 的基础上进行后训练的，具有更大的强化学习计算量。主要的架构变化在于注意力：K3 的全注意力门控 MLA 层与 KDA 层一起被替换为门控 DeepSeek 稀疏注意力，以实现更便宜的长上下文工作。它保留 1M 令牌上下文并通过 401M 参数视觉编码器读取图像。

Moonshot 自己的结果（供应商报告，以最大推理努力运行）使其在代理任务的比较表中名列前茅，例如带有工具的 HLE-Full (70.0)、BrowseComp (92.1) 和 AutomationBench-AA (73.3)。封闭模型在无工具推理方面仍然领先（HLE-Full 51.1 vs Claude Opus 5.5 的 59.8），在 Terminal-Bench 4.0 上领先（65.7 vs 66.4），在网络安全方面也领先。与其前身相比，Moonshot 报告称 Kimi Code Bench 3.0 Long-horizo​​n 为 61.2，而 Kimi K3 为 55.95。我们的[Kimi K3 API 提供程序分析](https://deepinfra.com/blog/kimi-k3-model-analysis-api-provider-comparison)涵盖了之前的模型。

两个服务细节决定了提供商的选择。首先，模型进行详细推理：Artificial Analysis 统计了 1.13 亿个输出代币来完成其索引，推理代币按输出计费，因此输出价格主导成本。其次，每个端点上第一个答案的延迟都很长（17.87 秒到 152.69 秒），因此第一个答案令牌的时间比第一个令牌的时间更重要。

### DeepInfra：整体推荐的提供商

从价格和可靠性来看，DeepInfra 是推荐的 Kimi K3.1 Pro API。每 100 万代币的输入为 1.90 美元，输出为 9.50 美元，比 16 个基准端点中的 9 个收取的 2.00 美元/10.00 美元标价低 5%，其 1.46 美元的混合价格是所有记录了 0% 错误率的端点中最低的。在人工分析基准的提供商中，只有 PrimaLabs 列出了较低的价格。

[Flex 服务层](https://deepinfra.com/blog/flex-service-tier) 的价格较低：输入 1.52 美元，输出 7.60 美元，缓存 0.152 美元。该产出率比列表低 24%。在人工分析使用相同的 7:2:1 加权时，Flex 的混合结果约为 1.17 美元（我们的计算）。发送 `"service_tier": "flex"`; Flex 请求最多等待 10 分钟以获得容量，然后返回 HTTP 429，并且拒绝的请求不收费。优先级还可享受 1.5 倍促销价。

由于产出在该模型的账单中占主导地位，因此每个代币的差距会增加。生成 1 亿个输出令牌的批处理作业在 DeepInfra Standard 上的成本为 950 美元，在 Flex 上的成本为 760 美元，按标价计算为 1,000 美元。

如果您注重响应速度，请按标准标价测试 DigitalOcean 或 Baseten；对于批量、代理和成本敏感的工作，DeepInfra 的每个代币差距会复合。

- **混合价格：** 每 100 万美元 1.46 美元（输入 1.90 美元，输出 9.50 美元，缓存 0.19 美元）；弹性约 1.17 美元
- **输出速度：** 46.9 吨/秒
- **延迟 (TTFT)：** 2.09 秒； 109.82 秒到第一个应答令牌
- **最佳工作负载：** 批量推理、后台代理和评估运行，其中价格和干净的错误率比第一个答案的秒数更重要

## 技术深入探讨：开发人员需要了解什么

### 1. 首次应答时间标记是重要的延迟数

在 16 个端点上，第一个令牌的时间从 0.95 秒到 6.54 秒不等，但第一个应答令牌的时间从 17.87 秒到 152.69 秒不等，因为模型会在应答之前进行推理。对于面向用户的任何内容，比较提供商与首次答复的时间，并考虑交互式调用的较低“reasoning_effort”：DeepInfra 的 API 通过“max”接受“none”，Artificial Analysis 的数据均以“max”测量。

### 2. 产出价格驱动账单

以 1.13 亿个输出代币来运行 Artificial Analysis 的指数（类中位数 1.04 亿），Kimi K3.1 Pro 有点冗长，其输出价格是其输入价格的五倍。对于输出量大的工作，输出率是要比较的数字：DeepInfra 为 9.50 美元，Flex 为 7.60 美元，标价为 10.00 美元，快速层为 20.00-30.00 美元。

### 3. 每个任务的成本取决于您的缓存命中率

Artificial Analysis 的混合价格假设 70% 的令牌是缓存命中，其每个任务的成本反映了每个端点在长时间代理工作负载上测得的缓存命中率。如果您的流量主要是新鲜提示或输出密集型推理，则每个代币的价格比每个任务的数字更好地预测您的账单。在 DeepInfra 上使用“prompt_cache_key”以在代理轮次之间缓存重复的上下文。

### 4. 输出限制和长上下文

DeepInfra 服务于完整的 1,048,576 个令牌上下文，并允许多达 943,718 个输出令牌。如果你不设置 max_tokens ，它默认为剩余上下文和 65,536 中较小的一个。

### 5. API 功能对等

上述所有提供商都通过 OpenAI 兼容的 API 提供相同的开放权重，因此您只需更改基本 URL 和模型名称即可将成本敏感的流量路由到一个端点，将延迟敏感的流量路由到另一个端点。

## 结论

- **最低价格，错误率为 0%：** DeepInfra（1.90 美元/9.50 美元，混合 1.46 美元；Flex 输出 7.60 美元）
- **按标价计算的速度和延迟：** DigitalOcean（200.8 t/s，第一个答案需要 25.35 秒）；巴斯坦紧随其后
- **无论价格如何，最快：** LithosAI ULTRA（258.5 t/s，17.87 s）和 Amazon Bedrock High Speed
- **最低标价：** PrimaLabs，计划错误率为 15.4%
- **基线：** Moonshot 的第一方 Kimi API 价格为 2.00 美元/10.00 美元
