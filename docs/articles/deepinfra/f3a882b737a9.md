## Kimi K3.1 Pro API 评测摘要

- **实验室与发布：** Moonshot AI，2026 年 10 月 23 日发布；open weights 于 11 月初跟进。
- **智能：** [Artificial Analysis Intelligence Index v5.0.1](https://artificialanalysis.ai/models/kimi-k3-1-pro) 得分 46，在同等规模的 open-weights 模型中**排名第 1 / 共 29**（同类中位数 23）。
- **DeepInfra 价格：** 每 1M tokens 输入 $1.90 / 输出 $9.50 / 缓存 $0.19（比标价低 5%）；Flex $1.52 / $7.60 / $0.152。
- **混合价格：** DeepInfra 上每 1M $1.46，是所有录得 0% 错误率的 benchmark endpoint 中最低的。
- **可靠性：** DeepInfra 在 Artificial Analysis 的测量窗口内录得 0.0% 错误率。
- **标价下的速度领先者：** DigitalOcean（200.8 t/s，25.35 秒到首个答案 token）和 Baseten（183.0 t/s，25.53 秒）。
- **话痨程度：** 跑完 Intelligence Index 用了 1.13 亿输出 token，同类中位数为 1.04 亿。
- **上下文与输出：** 1,048,576 token 上下文；在 DeepInfra 上最多输出 943,718 token（若未设置 `max_tokens`，默认 65,536）。
- **模态：** 文本和图像输入，文本输出。
- **规模：** Mixture-of-Experts，总参数 2.8T，激活参数 104B（[Hugging Face](https://huggingface.co/moonshotai/Kimi-K3.1-Pro)）。
- **许可证：** 自定义 Kimi K3.1-Pro License；允许商业使用，但对超大型 model-as-a-service 运营商和超大型消费级产品有额外条款。
- **覆盖的提供商：** 来自 14 家提供商的 16 个 endpoint。

## 关于 Kimi K3.1 Pro

Kimi K3.1 Pro 由 Kimi K3 post-train 而来，使用了多得多的强化学习算力。主要架构变化在 attention：K3 的全注意力 Gated MLA 层被替换为 Gated DeepSeek Sparse Attention，以更低的成本处理长上下文，同时保留其 KDA 层。它保持了 1M token 上下文，并通过一个 401M 参数的 vision encoder 读取图像。

Moonshot 自己的结果（厂商自报，在最高 reasoning effort 下运行）让它在 HLE-Full with tools（70.0）、BrowseComp（92.1）和 AutomationBench-AA（73.3）等 agentic 任务上位居其对比表首位。闭源模型在无工具推理（HLE-Full 51.1 对 Claude Opus 5.5 的 59.8）、Terminal-Bench 4.0（65.7 对 66.4，差距微弱）以及网络安全几行上仍然领先。相比上一代，Moonshot 报告 Kimi Code Bench 3.0 Long-horizon 为 61.2，而 Kimi K3 为 55.95。我们的 [Kimi K3 API 提供商分析](https://deepinfra.com/blog/kimi-k3-model-analysis-api-provider-comparison)覆盖了上一代模型。

有两个服务细节会左右提供商的选择。第一，这个模型推理很长：Artificial Analysis 统计完成其 index 需要 1.13 亿输出 token，而 reasoning token 按输出计费，所以输出价格主导成本。第二，每个 endpoint 到首个答案的延迟都很长（17.87 秒到 152.69 秒），因此首个答案 token 时间远比首个 token 时间重要。

### DeepInfra：总体最推荐提供商

DeepInfra 是在价格和可靠性上最推荐的 Kimi K3.1 Pro API。每 1M tokens 输入 $1.90、输出 $9.50，比 16 个 benchmark endpoint 中有 9 个收取的 $2.00 / $10.00 标价低 5%；其 $1.46 的混合价格是所有录得 0% 错误率的 endpoint 中最低的。在 Artificial Analysis 评测的提供商中，只有 PrimaLabs 的标价更低。

[Flex 服务层级](https://deepinfra.com/blog/flex-service-tier)把价格压得更低：输入 $1.52、输出 $7.60、缓存 $0.152。这个输出价率比标价低 24%。按 Artificial Analysis 使用的同一套 7:2:1 加权，Flex 折算约为 $1.17 混合价（我们的计算）。发送 `"service_tier": "flex"`；Flex 请求最多会等 10 分钟获取容量，之后返回 HTTP 429，被拒绝的请求不计费。此外还有 Priority 层级，价格是促销价的 1.5 倍。

由于输出占这个模型账单的大头，每 token 的差价会累积起来。一个生成 1 亿输出 token 的批处理任务，在 DeepInfra Standard 上花费 $950，在 Flex 上 $760，在标价下 $1,000。

如果响应速度就是你的产品，可以在标准标价下测试 DigitalOcean 或 Baseten；对于批处理、agents 和对成本敏感的工作，DeepInfra 的每 token 差价会继续放大。

- **混合价格：** 每 1M $1.46（输入 $1.90、输出 $9.50、缓存 $0.19）；Flex 约 $1.17
- **输出速度：** 46.9 t/s
- **延迟（TTFT）：** 2.09 s；109.82 秒到首个答案 token
- **最佳工作负载：** 批处理推理、后台 agents 和评测运行，在这些场景里价格和干净的错误率比到首个答案的秒数更重要

[Kimi K3.1 Pro 模型页面](https://deepinfra.com/moonshotai/Kimi-K3.1-Pro)列出了 JSON mode、structured output、tool calling、图像输入、零数据保留和私有 endpoint。API 兼容 OpenAI，地址为 `https://api.deepinfra.com/v1/openai/chat/completions`，使用 `Authorization: Bearer $DEEPINFRA_API_KEY`；参数见 [API 页面](https://deepinfra.com/moonshotai/Kimi-K3.1-Pro/api)。

```
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["DEEPINFRA_API_KEY"],
    base_url="https://api.deepinfra.com/v1/openai",
)

response = client.chat.completions.create(
    model="moonshotai/Kimi-K3.1-Pro",
    messages=[{"role": "user", "content": "Plan the migration steps for this schema change."}],
    temperature=1.0,
    top_p=0.95,
    max_tokens=32768,
    extra_body={
        "reasoning_effort": "high",
        "service_tier": "flex",  # remove for standard tier
    },
)
print(response.choices[0].message.content)copy
```

## 技术深潜：开发者需要知道什么

### 1. 首个答案 token 时间才是真正重要的延迟数字

16 个 endpoint 的首 token 时间在 0.95 到 6.54 秒之间，但首个答案 token 时间在 17.87 到 152.69 秒之间，因为模型会先推理再回答。对于任何面向用户的东西，比较提供商时要看首个答案时间，并考虑对交互式调用降低 `reasoning_effort`：DeepInfra 的 API 接受从 `none` 到 `max` 的取值，而 Artificial Analysis 的数字全部是在 `max` 下测得的。

### 2. 输出价格驱动账单

跑完 Artificial Analysis 的 index 需要 1.13 亿输出 token（同类中位数 1.04 亿），Kimi K3.1 Pro 算是偏话痨的，而它的输出价格是输入价格的五倍。在输出密集的工作上，要比较的数字是输出价率：DeepInfra 上 $9.50、Flex 上 $7.60、标价下 $10.00、快速层级 $20.00–$30.00。

### 3. 每任务成本取决于你的缓存命中率

Artificial Analysis 的混合价格假设 70% 的 token 是缓存命中，其每任务成本反映的是各 endpoint 在长 agentic 工作负载上实测的缓存命中率。如果你的流量主要是全新 prompt 或输出密集的推理，每 token 价格比每任务数字更能预测你的账单。在 DeepInfra 上用 `prompt_cache_key` 让重复上下文在多个 agent 轮次间保持缓存。

### 4. 输出限制与长上下文

DeepInfra 提供完整的 1,048,576 token 上下文，并允许最多 943,718 输出 token。如果你不设置 `max_tokens`，它默认取剩余上下文与 65,536 中的较小者。

### 5. API 功能对齐

上面所有提供商都通过兼容 OpenAI 的 API 提供同样的 open weights，所以你只需更改 base URL 和模型名，就能把对成本敏感的流量路由到一个 endpoint，把对延迟敏感的流量路由到另一个。

## 结论

- **0% 错误率下的最低价格：** DeepInfra（$1.90 / $9.50，混合 $1.46；Flex 输出 $7.60）
- **标价下的速度与延迟：** DigitalOcean（200.8 t/s，25.35 秒到首个答案）；Baseten 紧随其后
- **不计价格的最快：** LithosAI ULTRA（258.5 t/s，17.87 s）和 Amazon Bedrock High Speed
- **标价最低：** PrimaLabs，但要为 15.4% 的错误率做好准备
- **基线：** Moonshot 第一方 Kimi API，$2.00 / $10.00
