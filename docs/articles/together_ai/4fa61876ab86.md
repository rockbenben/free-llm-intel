## 摘要

我们提出 **Parcae**——最早稳定的**循环（looped）语言模型**架构之一，用干净、可预测的训练达到**两倍尺寸** Transformer 的质量。Parcae 创造了一个新的质量扩展介质：增加循环（recurrence）而非单纯堆数据，为内存受限的端侧模型训练开辟了一条高效前沿。

## 把参数的价值榨到极致

传统 scaling law 告诉我们：要取得最佳表现，必须扩展 FLOPs，通常靠更多参数或更多数据。但随着模型走向边缘、推理成本飙升，我们思考的问题是：**能否在不膨胀内存占用的情况下扩展质量？**

为此，我们一直在探索循环架构——通过让激活多次穿过同一批层来增加计算的模型。这些模型有前景，但训练不稳定。我们直接 tackle 这个问题，推出 **Parcae**，一个稳定的循环架构：

- **优于此前的循环模型**：Parcae 比之前的大规模循环配方最多**降低 6.3% 验证 perplexity**。
- **以小博大**：我们的 **770M Parcae 追平 1.3B 参数 Transformer** 在相同数据上训练的质量——用约一半的参数达到同样表现。
- **可预测地扩展**：我们建立了**首个循环的 scaling laws**，发现计算最优训练需要**循环与数据同步增长**。

## 循环模型很棒，但实践中难训练

随着模型走向边缘、推理部署占据计算的比重越来越大，人们越来越想在不动参数的前提下扩展模型质量。一个让我们兴奋的机制是层循环（layer looping），已有初步工作训练出质量匹敌更深的固定深度架构的循环模型。

要把一个普通 Transformer 变成循环模型，我们遵循先前工作，把它的层划分为三个功能块：**prelude（$\mathcal{P}$）**、**recurrent（$\mathcal{R}$）** 和 **coda（$\mathcal{C}$）**。前向传播分三个阶段：

- **嵌入：** prelude 把输入变换为潜在状态 $e$。
- **循环：** recurrent 块对隐藏状态 $h_t$ 迭代更新 $T$ 轮。为保持输入的影响，$e$ 被**注入**每一轮，典型方式是通过加法 <a id="cite-1" href="#ref-1">[1]</a>（$h_{t+1} = \mathcal{R}(h_t + e)$）或拼接后投影 <a id="cite-2" href="#ref-2">[2]</a>（$h_{t+1} = \mathcal{R}(W[h_t; e])$）。
- **输出：** coda 处理最终的 $h_T$ 生成模型输出。

不幸的是，循环模型训练起来很头疼 <a id="cite-2b" href="#ref-2">[2]</a><a id="cite-3" href="#ref-3">[3]</a><a id="cite-4" href="#ref-4">[4]</a>。我们亲自遇到**残差状态爆炸**和**loss 尖峰**。让循环模型更棘手的是，**recurrent 块**由若干普通 Transformer 块组成，很难推断不稳定的来源。

## 理解循环的不稳定性

虽然不稳定是个难以捉摸的对手，我们观察到一套简单的线性框架就能捕捉不稳定的一个重要来源。具体地，我们把循环重述为残差流上的非线性时变动力系统，其更新规则为：

$$h_{t+1} = \overline{A} h_t + \overline{B} e + \overline{\mathcal{R}}(h_t, e)$$

其中 $\overline{A}, \overline{B}$ 执行**注入**，$\overline{\mathcal{R}}$ 是 Transformer 块对残差流的贡献。对于热衷于次二次序列混合的朋友们，注意：若忽略非线性项 $\overline{\mathcal{R}}$，所得系统就是残差状态上沿模型深度的离散线性时不变（LTI）动力系统。

妙处在于：离散 LTI 系统的稳定性与收敛性由 $\overline{A}$ 的特征值决定。具体地，用谱范数 $\rho(\overline{A})$（即 $\overline{A}$ 绝对值最大的特征值）分类稳定性：稳定系统（收敛）满足 $\rho(\overline{A})<1$，不稳定（发散）系统 $\rho(\overline{A}) \geq 1$。

虽然这一分析绕过了循环的非线性（如 Attention 和 MLP 单元），上表与上图确认我们的分析在经验上是重要的：发散的 run 学到谱半径 $\rho(\overline{A}) \geq 1$，收敛的 run 保持 $\rho(\overline{A}) < 1$。当我们用 Parcae 维持 LTI 条件，循环模型对超参数选择变得显著更鲁棒。

## Parcae：稳定、省心的循环模型

那我们是稳定下来的？我们设计了新循环模型 Parcae，通过构造显式维持上节观察到的稳定性条件。具体地，我们用连续形式 $A, B$ 参数化输入注入参数，用 ZOH 和 Euler 方案离散化（即 $\overline{A} = \exp(\Delta A)$、$\overline{B} = \Delta B$），使用可学习的 $\Delta \in \mathbb{R}^{d_h}$。然后我们约束 $A := \texttt{Diag}(-\exp(\texttt{log}_A))$ 为负对角矩阵——对向量取 $\texttt{Diag}(-\exp(\cdot))$ 强制 negativity，$\texttt{log}_A\in \mathbb{R}^{d_h}$ 是我们的可学习向量。这就保证了 $\rho(\overline{A}) < 1$！

那么，我们是否解决了全部问题、让循环模型稳定了？不幸的是，要让 Parcae 干净训练还需要若干其他小技巧。感兴趣者请看我们的[论文](https://arxiv.org/abs/2604.12946)。

## 回到语言建模：扩展 Parcae

Parcae 不仅训练更可靠，还产出比先前 RDM 更高质量的模型。用 RDM <a id="cite-2c" href="#ref-2">[2]</a>（一种先前的循环模型）的完全相同设置，我们在参数和数据对齐的 RDM 上对比，观察到 Parcae 最多把验证 perplexity 降低 6.3%。

| --- | --- |
| **100M 规模** |  |

| └ **Parcae** | **13.59** |
| **350M 规模** |  |

把一个很强的 Transformer 基线改造成 RDM、不做任何超参数调优时，我们发现 Parcae 相对 RDM（直接发散）是鲁棒的。

## 循环还是不循环

但循环真的 FLOP 高效吗？为研究这点，我们探索一个设置：在固定参数数量与 FLOP 预算下，用训练中的平均循环与数据做交换（例如增加平均循环，就减少训练数据以维持固定 FLOP 预算）。

在两个规模上，我们发现：提高训练所用平均循环 $\mu_{\text{rec}}$ 并按比例减少 token，比低循环多数据的训练得到更低的验证 loss。更妙的是，如果用抛物线拟合提取每个 FLOP 档位的最优 $\mu_{\text{rec}}$ 与 token 预算，我们发现二者都遵循指数一致的幂律。
