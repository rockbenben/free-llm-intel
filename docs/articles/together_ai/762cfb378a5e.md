**摘要**

我们把 12 个落地页分别交给 Kimi K2.7 Code 和 Claude Fable 5 生成。Kimi 成本低 94%，几乎每个页面的得分只差几分。开源模型不只是更便宜——它们在质量上真正有竞争力。而且差距闭合得比人们意识到的更快。

我们做了一个实验：让 Kimi K2.7 Code 和 Claude Fable 5 各生成 12 个落地页做并排对比。总体而言，Kimi K2.7 Code 比 Fable 5 便宜约 94%，产出的质量相近——尤其在我们用 design MCP 给 Kimi 提供恰当上下文之后。

我们把发现发布在 [OVSC 网站](https://ovsc.vercel.app/)上，连同 Claude Opus 4.8、Claude Fable 5 和 Kimi K2.7 Code 生成的全部变体。平均下来，Kimi 比 Fable 便宜约 16 倍，比 Opus 便宜约 8 倍。

OVSC 网站让你浏览所有落地页，并附总成本、token 用量和生成时间的分解。

要了解实验怎么跑的：我们先建立基线，看看模型仅凭 prompt 能产出什么。

## 提示词

我们从一小批跨不同类别的落地页 prompt 开始，包括 B2B SaaS、一个屋顶地下酒吧（speakeasy），以及一个把 SQL 查询变成图表的开发者工具。以下是部分 prompt：

- 为一个把 SQL 查询变成图表的开发者工具构建落地页。
- 为一个屋顶 speakeasy 鸡尾酒吧构建落地页——装饰艺术风、金箔与祖母绿、1920 年代的风华。
- 为一家 B2B SaaS 创业公司构建落地页——一个团队项目管理与协作工具（任务、时间线、团队工作流、集成）。

同样的 prompt 分别交给 Kimi K2.7 Code 和 Claude Fable 5。

当被要求*"为一个把 SQL 查询变成图表的开发者工具构建落地页"*时，两个模型做出的页面如下：

Claude Fable 5；Kimi K2.7 Code

遗憾的是，两个模型做出的落地页都带着"一眼 AI 生成"的味道。

尽管如此，这给了我们一个有用的基线：每个模型仅凭简单 prompt 能产出什么。要把设计推向更高，我们需要给模型更强的创意指导，而我们发现最有效的方式是一个自定义 MCP server。

## Design inspiration MCP server

我们搭了一个自定义 MCP server，提供精心设计的落地页截图，以及单独的 UI 元素和其他视觉参考。由于 Kimi K2.7 Code 是多模态的，我们可以把这些图片连同文字直接放进 prompt。

这显著改变了结果。Kimi 不再只从短短一句 prompt 生成布局，而是能从具体示例出发、领会视觉语言、把这些模式应用到新页面。实践中，产出的页面层级更强、排印更好、构图更有意图。

下面是屋顶 Speakeasy 落地页的前后对比：

Kimi K2.7 Code 仅给 prompt；Kimi K2.7 Code 加上 design inspiration MCP server

有了设计灵感，Kimi 做出的页面加载更快、避开了坏图占位符、排印可读性高得多。

设计改进之后，我们接下来想探索的是成本。

## 每个落地页的成本

使用 Kimi K2.7 Code 这类开源模型的一个优势是成本。例如，这个 B2B SaaS 落地页用 Kimi 只花 4 美分。同样的 prompt 用 Claude Fable 要 \$1.09——贵了近 27 倍。

Claude Fable：总成本 $1.09；Kimi K2.7：总成本 4 美分

平均而言，我们用 Kimi K2.7 Code 生成的落地页比用 Claude Fable 5 这样的专有模型生成的便宜约 16 倍。

用生成式编码 agent，你很少只生成一个版本的落地页。更常见的做法是生成许多变体，探索不同的设计方向、文案和页面元素，然后对有希望的版本反复迭代——通过一轮轮实验和调整来编辑打磨。有了这些来回，哪怕只是一个简单的 SaaS 落地页，价差也会迅速累积。

如果你用 Kimi K2.7 Code 生成 100 个页面，相比用 Claude Fable 5 这样的专有模型大约能省 \$94。

更低的成本是明确的优势，但我们还想要一个比较产出质量的方法。

## 最后想法

Kimi K2.7 Code 这样的开源模型已经能够生成有用的落地页，但我们的实验表明，光靠 prompt 只是等式的一部分。没有更好的上下文，Kimi 和 Claude Fable 都倾向于产出精致但千篇一律的结果。

最大的改进来自通过自定义 MCP server 给 Kimi 视觉灵感。一旦它能对着截图和设计参考工作，页面就变得更可读、更有结构、视觉上更有意图。

加上更低的成本，开源模型在这类工作流中就是务实之选。如果你能给模型更强的输入、并以低成本迭代，你能走到出奇地远的地方。
