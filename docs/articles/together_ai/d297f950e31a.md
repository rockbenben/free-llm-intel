一个 [voice](https://www.together.ai/solutions/voice) agent 可以答得都对，用起来却仍然让人觉得坏掉了。客户会用接打电话的标准来评判它：只要它迟疑、一听就是合成音，或者把某个关键词念错，信任在他们还没来得及评估推理能力之前就已经崩了。在生产环境里，这种体验归结为一个实时回路：STT（speech-to-text）模型转写语音，LLM 决定要说什么，TTS（text-to-speech）把回应念出来。上了规模之后，团队要跨多家供应商把这个回路拼起来，于是延迟、可靠性、可观测性，以及最终客户听到的效果，都变得难以端到端管理。

从今天起，在 AI Native Cloud——Together AI 上，我们把 Rime 的 [Arcana v2](https://www.together.ai/models/arcana-v2) 和 [Mist v2](https://www.together.ai/models/mist-v2) 加入 Together Model Library，把专有 TTS 模型接进你为 LLM 与语音负载已经在用的同一套 API、鉴权与可观测界面。Arcana v2 提供富有表现力、口语化的音色，用真实客服交互训练，覆盖多种语言与地区方言的 40+ 音色适合对质量敏感的场景。Mist v2 为大批量生产环境带来确定性发音控制，在 Together AI 的 dedicated endpoint 上 time-to-first-audio 约 225ms——你通过 API 为一个词定义一次怎么念，之后它在所有音色、流程和渠道中都保持一致。两者都以 dedicated endpoint 的形式跑在同一朵云上，与你的 LLM 和 STT 负载放在一起，于是你的端到端语音技术栈在一个生产平台上运转，而不是被拆到多家供应商那里。

## **Arcana v2：面向企业对话的表现力**

Arcana v2 如今已被从高增长初创公司到财富 500 强的企业部署在自己的生产基础设施里。在这些环境中，客户报告了可量化的收益，包括一家全国性连锁餐饮的销售提升 15%、一家电信运营商的通话放弃率下降 75%，以及呼叫成功率提升 10%。

### **基于规模最大的专有全双工对话语音数据集训练**

Arcana v2 是用与普通人之间的真实对话训练的——不是有声书、播客，也不是配音播音员。模型从生产对话里学到自然的呼吸、填充词、backchannel cues 和对话节奏。来电者会认出这些模式，在自动流程里停留得更久，从而提升完成率和 containment rate。

### **40 多种音色与地区方言**

Arcana v2 自带 40 多种覆盖英语、西班牙语、法语和德语的音色。英语一侧有 18 种音色，涵盖英式、澳洲和美式南方口音。西班牙语包含四种主要音色和三种双语音色。日常词汇会自动匹配当地用法。例如 "schedule" 在英式英语里读作 "SHED-ule"，在美式英语里读作 "SKED-ule"。

## **Mist v2：生产规模下的确定性发音**

Mist v2 为大批量生产环境而设计，这类环境必须在上百万通电话里保证发音准确度。它已经在客服与 IVR 系统中每月支撑数千万通生产电话，而这些场景里停机或质量回退会直接影响营收与合规。

### **确定性发音控制**

多数 TTS 模型每次生成都在猜发音。Mist v2 是确定性的。你通过 API 为一个词定义一次该怎么念，这个发音就会在 40 多种音色、流程和渠道中保持成立。不需要重新训练，也不需要各供应商自己的土办法。当你的 agent 把一个产品名、药物或缩写念错时，你纠正一次，修正就全域生效。Mist v2 的确定性发音配置现已通过我们的 Sales 团队面向生产部署开放；要在你的环境中启用，请[联系 Sales](https://www.together.ai/contact-sales)。

### **英语与西班牙语，配进阶发音控制**

Mist v2 支持英语和西班牙语，并提供确定性发音控制。你通过 API 指定品牌名、药品名或技术术语该怎么念，Mist 就会在对话级延迟下把它们一致地渲染出来。如果你需要在 Mist v2 里实现规模化的确定性发音，请联系 Sales 为你的环境启用。

### **经过规模验证**

Mist v2 每月在生产级客服与 IVR 环境中服务数千万通电话。这些是全量部署——停机或质量回退会直接影响营收和合规，而不是有限范围的试点。

### **面向对话式 agent 的生产级延迟**

Mist v2 在 Together AI 的 dedicated endpoint 上达到约 225ms 的 p50 time-to-first-audio。语音 agent 需要端到端总延迟低于 700ms 才有对话感，这意味着 TTS 必须足够快，为 STT 和 LLM 的处理留出余量。当你把 Mist v2 与 LLM、STT 一起 colocate 在 Together AI 上时，从语音识别到推理再到合成的整条 pipeline 都能待在这个预算之内，从而直接改善完成率与用户满意度。

### **对话真实感**

和 Arcana v2 一样，Mist v2 也是用真实客服电话训练的。它在保持生产级吞吐的同时，留住自然的填充词、backchanneling、呼吸模式和节奏。这让它适合同时要求真实感与响应速度的大批量场景。

## **使用场景**

### **全球呼叫中心**

全球团队可以在同一套环境里混用 Arcana v2 和 Mist v2。Arcana v2 处理销售、复杂支持这类对质量敏感的交互；Mist v2 承接基础咨询与 IVR routing 这类大批量流程。改一下配置就能切换模型，而配置与可观测性通过 Together AI 保持统一。

### **实时客服**

大批量支持流程需要 TTS 延迟低于 250ms 才有对话感，同时整条端到端 pipeline（STT → LLM → TTS）低于 700ms。当 Mist v2 与 LLM、STT 一起 colocate 在 Together AI 上时，两个阈值同时满足，既去掉了跨供应商的网络开销，也把 pipeline 留在同一个环境里。

### **医疗语音 agent**

像 "lisinopril"、"atorvastatin"、"metformin" 这样的药品名必须每一次都念对。Mist v2 用的是确定性发音，所以这些术语只需定义一次，就能在 40+ 种音色里都正确渲染。跑在 Together AI 符合 HIPAA 的基础设施上，意味着一次合规评审就能覆盖整条语音技术栈。

### **语音银行**

账号、路由号和产品名需要在上百万通电话中被清晰、一致地念出来。Rime 的模型是用客服对话训练的，就是为这类高精度场景打造的。在 Together AI 上，银行和金融机构可以把 Rime 的 TTS 模型部署在满足其监管要求的 SOC 2 Type II、PCI 合规基础设施上。
