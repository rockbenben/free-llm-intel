## **Arcana v2：企业对话的表达力**

如今，从高增长的初创公司到财富 500 强企业，都部署了 Arcana v2，作为其生产基础设施的一部分。在这些环境中，客户报告了可衡量的收益，包括全国连锁餐厅的销售额提高了 15%，电信提供商的呼叫放弃率减少了 75%，呼叫成功率提高了 10%。

### **在最大的全双工会话语音数据专有数据集上进行训练**

Arcana v2 是根据与日常生活中的人的真实对话进行训练的，而不是有声读物、播客或配音播音员。该模型从生产对话中学习自然呼吸、填充语、后台线索和对话节奏。呼叫者认识到这些模式并在自动化流程中停留更长时间，从而提高完成率和遏制率。

### **40 多种声音和地方方言**

Arcana v2 附带 40 多种语音，涵盖英语、西班牙语、法语和德语。英语包括 18 种声音，涵盖英国、澳大利亚和美国南部口音。西班牙语包括四种主要声音和三种双语声音。日常用语会自动匹配当地用法。例如，“schedule”在英国英语中发音为“SHED-ule”，在美国英语中发音为“SKED-ule”。

## **Mist v2：生产规模的确定性发音**

Mist v2 专为大批量生产环境而设计，必须在数百万次通话中保证发音准确性。它每月已经为客户服务和 IVR 系统提供数千万次生产呼叫，其中停机或质量下降会直接影响收入和合规性。

### **确定性发音控制**

大多数 TTS 模型都会猜测每一代的发音。 Mist v2 是确定性的。您可以通过 API 定义一个单词的发音，并且该发音适用于 40 多种语音、流程和渠道。无需再培训，也无需针对每个供应商进行黑客攻击。当您的代理人念错产品名称、药物或缩写词时，您只需纠正一次，该修正就适用于所有地方。今天，我们的销售团队可以为生产部署提供 Mist v2 的确定性发音配置； [联系销售人员](https://www.together.ai/contact-sales) 以便为您的环境启用它。

### **英语和西班牙语，具有高级发音控制**

Mist v2 支持英语和西班牙语，并具有确定性发音控制。您可以通过 API 指定品牌名称、药物名称或技术术语的发音，Mist 在对话延迟时一致地呈现它们。如果您需要在 Mist v2 中大规模确定发音，请联系销售人员为您的环境启用它。

### **经过大规模验证**

Mist v2 在生产客户服务和 IVR 环境中每月处理数千万个呼叫。这些是全面部署，其中停机或质量下降会直接影响收入和合规性，而不仅限于试点。

### **对话代理的生产级延迟**

Mist v2 在 Together AI 专用端点上达到约 225 毫秒 p50 首个音频时间。语音代理需要低于 700 毫秒的总端到端延迟才能感觉到对话，这意味着 TTS 必须足够快，以便为 STT 和 LLM 处理留出空间。当您将 Mist v2 与 LLM 和 STT 共同部署在 Together AI 上时，从语音识别到推理再到合成的整个流程都保持在预算范围内，从而直接提高了完成率和用户满意度。

### **对话现实主义**

与 Arcana v2 一样，Mist v2 也是根据真实的客户服务电话进行训练的。它保留自然填充词、反向通道、呼吸模式和节奏，同时保持生产级吞吐量。这使得它适合需要真实性和响应能力的大容量场景

## **用例**

### **全球联络中心**

全球团队可以在同一环境中混合使用 Arcana v2 和 Mist v2。 Arcana v2 处理质量关键的交互，例如销售和复杂的支持。 Mist v2 可处理大量流量，包括基本查询和 IVR 路由。您可以通过配置更改来交换模型，并通过 Together AI 保持配置和可观察性的统一。

### **实时客户服务**

大容量支持流程需要 TTS 延迟低于 250 毫秒才能感受到对话性，总端到端管道（STT → LLM → TTS）低于 700 毫秒。当 Mist v2 与 Together AI 上的 LLM 和 STT 共置时，满足这两个阈值，消除了多供应商网络开销并将管道保持在单一环境内。

### **医疗保健语音代理**

“赖诺普利”、“阿托伐他汀”和“二甲双胍”等药物名称每次都必须正确发音。 Mist v2 使用确定性发音，因此您只需定义一次这些术语，它们就能在 40 多种语音中正确呈现。在符合 HIPAA 标准的 Together AI 基础设施上运行意味着一次合规性审查即可覆盖整个语音堆栈。

### **语音银行**

帐号、路由号码和产品名称需要在数百万次通话中清晰一致地读取。 Rime 的模型经过客户服务对话训练，专为这些高精度用例而构建。在Together AI上，银行和金融机构可以在符合其监管要求的SOC 2 Type II和PCI兼容基础设施上部署Rime的TTS模型。
