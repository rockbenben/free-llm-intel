## 摘要

我们提出一致性扩散语言模型（consistency diffusion language models，CDLM），它把基于一致性（consistency）的多 token 定稿与分块（block-wise）KV 缓存结合起来，加速扩散语言模型的推理，在数学和编程任务上取得最高 14.5 倍的延迟提速。

扩散语言模型（DLM）正在成为自回归（AR）语言模型一个很有前景的替代。DLM 不再一次生成一个 token，而是在多个采样步上迭代精化一个部分掩码的序列，把一个全掩码序列逐步变成干净文本。这个精化过程创造了一个诱人的机会：它支持并行生成，模型每次迭代可以定稿多个 token，可能比 AR 解码取得更高吞吐；同时它能利用双向上下文，解锁文本填充（infilling）、文本修订等新能力。

CDLM、朴素 DLM 与自回归（AR）模型推理过程的可视化。

然而实践中，标准 DLM 受制于两大低效。[1]

- **全双向注意力下 KV 缓存不兼容。**
标准 DLM 通常使用双向（非因果）注意力，每个去噪步都要在整个上下文上重算注意力，推理代价高昂，且无法使用标准 KV 缓存。
- **为保质量需要大量精化步。**
高质量生成通常需要很多去噪/精化步，往往与生成长度相当。天真地减少步数会导致质量急剧下降。

CDLM 通过一套训练后配方同时针对这两个瓶颈：让更少步数的推理变得可靠，同时启用精确的分块 KV 缓存。

## **预备知识：扩散语言模型的推理**

DLM 生成是在 N 个离散采样步上的迭代精化，把 t=1 时的全掩码序列变换为 t=0 时的干净序列。每一步，模型在当前含噪序列 xt 和 prompt c 的条件下预测干净序列分布 x0：

$p_{\theta}(\mathbf{X}_0 \mid \mathbf{X}_t, c)$

一种常见的确定性实例化是低置信度重掩码（low-confidence remasking）：模型贪心地解掩 token（通常在块内），定稿置信度最高的掩码位置、其余保持掩码。由此得到解码轨迹：

$\mathcal{T}_{\mathbf{x}} = \left(\mathbf{x}_{t_0}, \mathbf{x}_{t_1}, \ldots, \mathbf{x}_{t_N}\right), \quad t_k = 1 - \frac{k}{N}$

它记录了部分精化序列如何逐步演化。这条轨迹成为 CDLM 训练的核心对象。

## **CDLM 训练**

### **1）轨迹采集**

我们离线运行 DLM 在领域专属 prompt 上的推理来采集轨迹。对每个 prompt x，记录 token 级解码轨迹 T_x、一个紧凑的隐藏状态缓冲 H_x（包含 token 定稿时刻的最后一层隐藏状态），以及真实文本 ŷ。具体地，我们采用分块解码，生成长度 L_g = 256、块大小 B = 32、共 N = L_g 步（即当前块内每步恰好定稿一个 token）。这种保守设置能产出更高质量的蒸馏用轨迹。

左：带全双向注意力的教师 DLM。右：带分块因果掩码的学生 DLM。

### **2）分块因果学生模型与注意力掩码**

轨迹提取时使用全双向注意力掩码；而训练 CDLM 时采用分块因果掩码，注意范围是 prompt、已完成的块和当前解码块。这个设计让模型可以从全双向切换到块扩散模型（block-diffusion model，类似 [2]），从而对已定稿的块启用精确的分块 KV 缓存。

左：教师的分块解码轨迹（步 0 → N；扩散时间 t：1 → 0）。右：学生在中间状态 y 上的三目标损失。

### **3）训练目标**

CDLM 联合最小化三个目标：

**(i) 蒸馏损失（新解掩位置）**

对介于中间状态 y 与其块完成态 y* 之间 newly unmasked 的位置，让学生预测分布在存储的隐藏状态还原出的教师重构分布上对齐。

直觉：这个目标是主锚点，教会学生在分块因果约束下于一个块内定稿多个 token。

**(ii) 一致性损失（仍被掩码的位置）**

对仍被掩码的位置，用 stop-gradient 目标把学生在状态 y 的预测与其在信息更充分的 y* 状态自身的预测对齐，强制块内时间一致性。

直觉：这个目标鼓励沿解码轨迹的稳定多步迁移。

**(iii) 辅助 DLM 掩码去噪损失**

加入施加在随机掩码真实文本上的标准掩码去噪目标。

直觉：这个目标保留模型一般的掩码 token 预测能力，并有助于保推理行为，尤其在数学任务上。

### **4）推理**

推理时，CDLM 以分块自回归方式解码，复用 prompt 和所有已定稿块的 KV 缓存。每个块内应用带置信度阈值的并行定稿。[3] 当当前块中出现 end-of-text token 时提前停止。

我们有意避免引入额外超参数的启发式（例如带任务相关设置跨块并行），专注于一个基于精确 KV 缓存与可靠步数削减的稳健默认解码流水线。

**主要结果：CDLM–Dream**

Dream-7B-Instruct 的评估结果。表头箭头指示越高越好（↑）还是越低越好（↓）。注：Par. = 并行解码；D.C. = 双缓存 KV。

我们看到：

- CDLM–Dream 在各基准上取得最大的步数削减：多数任务上精化步数减少约 4.1–7.7 倍，精度变化很小。
- 步数削减转化为大幅延迟改善：GSM8K-CoT 上最高 11.2 倍，MBPP-Instruct 上最高 14.5 倍。
- CDLM 往往取得最高的 Tokens Per Second 吞吐，但有一个值得注意的细节：由于 CDLM 严格分块因果、可能在保持 pass@1 质量的同时产出更短的输出，不同任务会呈现不同的解码动态。

**有效步数削减：为什么训练很重要**

精化步数消融实验。GSM8K 结果由朴素截断基线 DLM 的步数得到，步数预算与 CDLM–Dream 和 CDLM–LLaDA 使用的对齐。

朴素截断步数会造成显著的精度退化，而 CDLM 在相同步数预算下保持质量（并因缓存获得约一半的延迟）。这凸显核心要点：稳定的多 token 精化不是免费的，它需要强制轨迹一致性的训练。

**系统级分析：为什么分块 DLM 恰在甜点区**

为理解硬件利用率，我们分析随 batch size 增长的算术强度（AI，每字节搬运的 FLOPs），对比：AR 解码、原生（全注意力）DLM、块大小 B∈{4,16,32} 的分块 DLM（CDLM）。

自回归（AR）模型、原生 DLM 与分块 DLM（CDLM）在解码期的算术强度（AI）随 batch size（bs ∈ {1, 2, 4, 8, 16, 32, 128}）的变化。

关键解读：

- AR 解码在小 batch size 下强内存受限（bs=1 时 AI 接近 1），随 batch 增大而改善，因为权重加载被摊薄。
- 原生 DLM 即使 bs=1 也是计算受限，因为全双向注意力每步都要处理整个序列，导致饱和。
- 分块 DLM（CDLM）处于中间区域：因块内并行（在相近内存流量下处理 B 个 token），AI 高于 AR，但低于原生 DLM——常常是小批设置下均衡的工作点。

自回归（AR）模型、原生 DLM 与块大小 B ∈ {4, 16, 32} 的分块 DLM 在 batch size bs ∈ {1, 2, 4, 8, 16, 32, 64, 128} 下的解码 roofline 位置。

总体上，该分析解释了 CDLM 这类分块扩散为何能在小 batch size 下取得强效率：它用并行摊薄内存访问，同时仍处于能从实际扩展中获益的区域。

## **讨论与结论**

### **表达力 vs. 效率**

DLM 的全双向注意力要求每个去噪步重算 O(L^2) 的注意力，推理计算量巨大。CDLM 在保留每个块内双向上下文——保住局部精化能力（如在当前块内填充）——的同时实现精确 KV 缓存。

### **随更强 DLM 主干扩展**

CDLM 是一个可应用于任何块扩散模型的训练后配方，其收益会随更强 DLM 的出现而增长。一个有前景的方向是：从更大更强的 DLM 教师采集轨迹，用 CDLM 训练中等规模的学生。

## **结论**

我们提出 CDLM——一种把一致性建模带入 DLM 的基于训练的加速方案。通过强制块内时间一致性并微调一个分块因果的学生模型，CDLM 削减精化步数并启用精确 KV 缓存。在数学与编程任务上，CDLM 带来更快的推理、更少的步数、更低的延迟和更高的吞吐，同时保持有竞争力的精度。
