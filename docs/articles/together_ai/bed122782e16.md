# Meta Muse Spark Open 已在 Together AI 上线

Muse Spark Open，Meta 面向 agentic coding 的开放权重模型，已在 Together AI 上线，在 serverless 与专属基础设施上提供 1M token 上下文窗口。

Meta 的 Muse Spark Open 今天起可在 Together AI 上使用。我们是这款迄今最强的美国开放权重模型的 Day 0 发布合作伙伴，它为长时间运行的 agentic coding 工作流而构建，能把整个代码库留在上下文里。

Muse Spark Open 在 agentic 软件工程、computer use 与网页自动化，以及把文档、图像、音频和视频放在一起理解这几方面都是一次进步。通过我们的早期访问计划，我们在发布前把它提供给了少数选定客户。他们对它做了评估，准备在 day 0 就把它提供给自己的客户，并与 Meta 分享了真实世界的使用反馈。

[阅读 Meta 的公告](https://research.meta.ai/blog/muse-spark-open)。

### **关于 Muse Spark Open**

Muse Spark Open 是在真实的开发者工作上训练的：跨多文件重构、调试会话以及长时间运行的任务。带来的结果是更高的首次尝试准确率、可靠的 tool calling，以及在开发者真正工作的那些代码仓库上的深入代码库理解。

最突出的地方：

- **1M token 上下文窗口。** 它能装下整个项目，包括复杂的依赖关系、遗留代码和成千上万个文件，而不必把工作拆成碎片。
- **长时程自主性。** 它能在很长的时程上规划、行动、观察并自我纠正，并为可以拆分的工作协调 subagent。
- **Computer use 与浏览。** 它把 computer-use 能力用在桌面、移动端和浏览器上，并用多模态浏览的方式上网。
- **多模态输入。** 它接受文本、图像、音频以及音视频输入。
- **意图说明。** 它在行动前先说明自己在做什么、为什么这么做，这让长时间运行的任务更容易审计。

### **早期访问客户怎么说**

Factory 和 Ollama 是两家获得早期访问的客户。两家都在发布前用过 Muse Spark Open，两家也都从 day 0 起把它提供给自己的用户。

> “企业选择 Factory，是因为他们想让自己的 Droid 跑在该任务最好的模型上。在我们的 agentic 工程工作流里，Muse Spark Open 始终能选对工具、并保持回答简洁，这正是生产环境 agent 需要的果断。通过 Together AI 拿到的早期访问让我们得以在发布前对它做压力测试，所以我们的客户从 day 0 起就能用上它。”Zimu Li，Member of technical staff，Factory

> “全球有数百万开发者依赖 Ollama，把它当作上手开源模型的去处。我们很高兴能与 Together AI 合作提供 Muse Spark Open。这款模型在 tool calling 和长上下文上表现尤其出色，包括多步与并行调用，并给出干净的结构化输出。与 Together AI 的早期访问合作让我们有充分的时间评估并优化这款模型，从而开发者从它发布的那一刻起就体验到一款支持完善、可用于生产的模型。”Dong Chen，Senior AI Engineer，Ollama

### **在 Together AI 上运行它**

**Serverless。** 用 Together API 调用 Muse Spark Open：

```
from together import Together

client = Together()

response = client.chat.completions.create(
    model="meta-models/Muse-Spark-Open-816B-A42B",
    messages=[{"role": "user", "content": "Refactor this module to remove the circular import."}],
)
print(response.choices[0].message.content)
```

定价为每 1M 输入 token $1.25、每 1M 输出 token $4.25、每 1M 缓存输入 token $0.15。你也可以在 playground 里试用。
