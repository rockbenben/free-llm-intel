Together AI 为领先开源模型交付最快推理

Together AI 现在为高要求开源 LLM 提供最高 2 倍更快的 serverless 推理，在输出速度基准中排名第一。这次性能突破来自新一代 GPU 硬件、优化 kernel、近无损量化，以及用定制训练的草稿模型做的生产级推测解码——多环节的协同改进。

关键创新包括架构感知校准、自适应接受策略，以及支持 1T+ 参数模型的可扩展训练流水线——为 GPT-OSS、Qwen3、Kimi-K2、DeepSeek-R1、DeepSeek-V3.1 等模型带来突破性的速度。

过去几个月，我们团队全心锁定一个目标：把我们的推理平台变成运行全球最佳开源模型的最快之地。今天，我们很高兴分享一组不证自明的结果。

在 [Artificial Analysis](https://artificialanalysis.ai/) 的多个独立基准中，对最苛刻的开源模型——包括 GPT-OSS-20B、GPT-OSS-120B、Qwen-3-235B-Instruct、Qwen-3-Coder-480B、Kimi-K2-Instruct、DeepSeek-R1 和 DeepSeek-V3.1——我们的平台在基于 GPU 的提供商中输出速度稳定排名第一。在若干模型上，我们现已交付比竞争提供商最高快 2 倍的输出速度。

GPT-OSS-20B：比次快提供商快近 2 倍

GPT-OSS-120B：比次快提供商快近 10%。

Qwen3-235B-2507：比次快提供商快 2.75 倍以上。

Qwen3-Coder-480B：比次快提供商快 22% 以上。

Kimi-K2-0905：比次快提供商快 65% 以上。

DeepSeek-V3.1：比次快提供商快 10% 以上。

DeepSeek-R1-0528：比次快提供商快 13% 以上。

这种水平的性能不来自单一改动——它是硬件、kernel、运行时引擎调优、推测解码和草稿模型训练流水线协同改进的结果。在这篇文章里，我们分享其背后的故事。

## 1. 新一代 GPU 硬件加引擎优化

我们性能收益的很大一部分，来自一个全面现代化的推理引擎——为利用最新 GPU 硬件、优化 kernel 和 FP4 等新兴低位宽量化格式而构建。我们没有优化孤立层，而是重新架构了整个栈——计算 kernel、内存布局、执行图、调度——让它们作为一个统一的高效率系统协同工作。

### **在最新 GPU 上的硬件感知执行**

我们的引擎专门为 NVIDIA Blackwell 架构调优，包括 NVIDIA GB200 NVL72。这包括低精度计算（FP8、FP4）的优化路径、高带宽数据移动，以及在所有计算层级最大化利用率的近零开销调度。我们不只是"跑在快硬件上"——我们围绕硬件来组织执行，在真实负载中榨取其全部能力。

### **Together Kernels**

我们构建并集成了一代全新的高性能 GPU kernel，为 NVIDIA Blackwell 架构设计，让我们能充分利用巨大带宽。其中包括优化的 FlashAttention-4 kernel、把路由和专家 FFN 融合的 fused MoE kernel 等。这些硬件感知 kernel 共同大幅提升大模型的吞吐，是我们如今在真实工作负载上看到性能跃升的关键驱动力。

## 2. Turbo 优化套件

### 量化

我们速度收益的一个关键部分，是把大模型权重量化到 FP8、FP4（nvfp4 或 mxfp4）和混合精度等低位宽格式、同时实际上保持近乎无损的能力。我们的流水线执行架构感知校准、细粒度的分块缩放、对敏感路径的选择性混合精度，让我们在极限压缩下仍保住目标模型的质量。再配合为低位宽执行而构建的运行时——包括融合的 FP4/FP8 kernel、量化 KV 缓存和 Blackwell 优化的内存布局——我们在不牺牲精度的情况下取得大幅延迟与吞吐改善。这种近无损量化能力，是我们在最大开源模型上交付更快推理速度的基础。

### 推测器算法

让我们近期性能跃升的最大解锁之一，是我们在生产级推测解码算法上的工作。

推测解码不新鲜，但让它跨数据领域保持可靠、并在多租户 serverless 环境中持续更快，极其困难。我们的实现包括：

- 训练高效的算法，让每单位训练 FLOPs 换来更高性能
- 针对每个目标模型专门优化、训练高精度草稿模型
- 自适应接受策略，在保持输出质量的同时最大化速度
- 故障安全回退机制，让负载下的延迟保持可预测

这解锁了可观的收益——尤其对 Kimi、Qwen3 这类模型，我们的 SpecDec 栈提供了近两倍的输出速度。详情见我们的 [ATLAS 博客](https://www.together.ai/blog/adaptive-learning-speculator-system-atlas)和 [Blackwell 全球最快推理](https://www.together.ai/blog/fastest-inference-for-deepseek-r1-0528-with-nvidia-hgx-b200)。

### 大规模推测器训练

为支撑最大的现代 LLM，我们构建了完全可扩展的草稿模型训练流水线。这是 Backbone：让我们能为没有现成推测器的模型部署高质量推测解码器，也能改进已有的推测器。

我们开发了：

- 可扩展训练框架，支持 1T 参数及更大目标模型的高性能推测器算法
- 基于课程学习的训练、后训练配方与数据混合策略，让草稿模型匹配目标模型的风格与结构输出
- 对齐评估框架，围绕目标模型测试并迭代草稿模型质量
- 高性能架构和预训练基础模型，可被改造为许多目标模型的推测器

成果：草稿模型取得高接受率和高速率，带来 NVIDIA Blackwell 架构上全球最快的推理速度。
