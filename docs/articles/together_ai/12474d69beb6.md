Cursor 是一个具备持续后台智能的 AI 编码平台，由一支训练 agentic 编码模型并把它们送上生产的研究团队打造。开发者打字时，Cursor 维护一个代码上下文的实时模型——预测编辑、重构代码、实时管理上下文。

交付这种体验，要求响应落在编辑器的反馈回路之内。这个约束把服务问题从批量式转为实时、低延迟推理。Cursor 与 Together AI——AI Native Cloud——合作为这个回路构建基础设施——使用 [NVIDIA Blackwell](https://www.nvidia.com/en-us/data-center/technologies/blackwell-architecture/) 架构，并对推理栈做调优以满足严格的延迟目标。

## **为什么编辑器内部的延迟不同**

编辑器内的 agent 在开发者积极编辑的同时生成输出，所以时机决定一条建议是否恰好落在模型用来生成它的同一段局部上下文中。一旦开发者移动到代码的另一区域，输出常常已不再与它本要支持的状态对齐。

在 Cursor 里，这些 agent 在开发者继续工作的同时调试问题、生成特性、执行重构。这种负载要求：并发下可预测的最坏情况延迟、重叠请求间一致的上下文处理、以及持续负载下的稳定运行。

## **在 NVIDIA Blackwell 上做工程**

在规模上满足延迟预算，把两个团队引向 NVIDIA Blackwell GB200 NVL72 和 [NVIDIA HGX™ B200](https://www.nvidia.com/en-us/data-center/hgx/)——更高的内存带宽和 tensor 吞吐支撑更快的服务。在产品生命周期早期部署生产负载，意味着贯穿全栈——硬件、固件、主机软件和服务层——驱动可靠性与优化。

- **带 NVIDIA Blackwell 的前沿基础设施：** Together AI 与 Cursor 协作交付并参与 NVIDIA Blackwell 的早期部署。对 Cursor 来说，早期硬件获取是产品优势，Together 工程师做快速升级与替换，交付这一新的前沿基础设施。这些努力为 Cursor 快速可靠地送上了新芯片。
- **ARM 主机上的满吞吐：** GB200 NVL72 把 GPU 与采用 ARM 指令集的 [NVIDIA Grace™ CPU](https://www.nvidia.com/en-us/data-center/grace-cpu-superchip/) 配对。高性能推理生态的多数部分假设 x86 主机。把推理栈移植到 ARM，需要为 GB200 NVL72 做 kernel 和主机级调优。
- **为 Blackwell Tensor Core 写定制 kernel：** Blackwell 引入了为低位宽格式优化的新 Tensor Core 指令。Together AI 为 Blackwell 构建直接瞄准这些指令的 kernel，捕获硬件更多的吞吐。**‍**
- **跨 NVIDIA GB200 NVL72 的高效并行：** GB200 NVL72 以全互连拓扑连接 72 块 NVIDIA Blackwell GPU。在该域内分布模型会增加芯片间的通信与同步开销。Together 为 GB200 NVL72 设计了并行网格，让协调成本保持有界——计算收益得以贯穿到推理。

## **缩短"权重到生产"的周期**

Cursor 的研究团队在内部训练模型——把专有数据与针对编码工作流的定向优化结合——产出新的候选权重。与 Together AI 的合作建立了一条可重复的路径，把这些权重移到接近生产的 endpoint 上立即测试。

这条路径上的关键一步是量化。实时服务运行在紧张的内存与计算预算上，而量化用更少的 bit 表示权重、同时削减两者。在编码场景中，质量下滑会以微妙的逻辑错误或语法错误的形式浮现，所以量化必须在改善延迟与成本的同时保住输出质量。

Together AI 实现了围绕 [NVIDIA TensorRT LLM](https://developer.nvidia.com/tensorrt) 和 Blackwell 上 NVFP4 构建的量化流水线——在激进压缩与 Cursor 编码模型的质量要求之间走钢丝。当 Cursor 产出新候选时，Together 在数天内完成量化、验证并拉起一个测试 endpoint。Cursor 运行内部评估套件，然后在真实流量下分阶段 A/B 测试，之后完成切换。切换由验证和真实流量检查把门。

## **下一步——从延迟到吞吐**

Cursor 的生产部署运行在跨多个数据中心的 NVIDIA Blackwell GPU 上。NVIDIA GB200 NVL72 承担推理，基础设施支撑模型迭代——随着 Cursor 的研究团队交付新权重。

随着这条延迟路径在生产中运行，焦点转向吞吐与利用率。Cursor 和 Together AI 正在 NVIDIA Blackwell 平台构建更高吞吐的 endpoint，随着用量增长改善每 GPU 经济性。
