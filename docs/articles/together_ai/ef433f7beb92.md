视频已成为最流行的信息分享介质之一。然而，互联网上热门视频内容的语言分布，并不反映全球受众的多样性。例如，一项先前研究发现，Top 250 YouTube 频道中 66% 的视频是英语，而第二常见的语言西班牙语只占 15% [1,2]——这让全球大量观众无法接触这些内容。这个缺口凸显了对可扩展视频翻译方案的需求。

**前沿 AI 能否帮助打破语言壁垒，让视频内容更可达于全球观众？**

今天，我们很高兴介绍 **Violin**——一个完全开源的视频翻译工具，由 **Together API** 驱动。Violin 流水线使用最先进的语音识别、大语言模型和语音合成，实现高质量视频翻译。

除标准翻译外，我们还开发了交互式与个性化功能，比如视频内容感知的 chat 助手和自然语言选声器。我们希望 Violin 能让跨语言的用户更容易地获取信息，帮助高质量视频内容在互联网上传播更远。

## **Violin 如何工作**

*Violin 如何工作：* 从输入视频到完全翻译的输出，Violin 编排三个核心阶段：ASR（自动语音识别）、LLM 翻译、TTS（语音合成）声音合成，同时支持视频 chat 助手和声音风格个性化。全部在 Together AI 云上。

Violin 分三个直白的阶段工作：

首先，它提取视频音频并转录为带时间戳的文本。我们使用 Together 的 Whisper V3 large endpoint，以优化的速度提供高质量多语言转录。

然后由大语言模型翻译这段转录。这里我们默认用最新的 DeepSeek V4 Pro 作为翻译器。我们还允许用户输入一份预定义翻译规则列表，以保持忠实与准确。

最后，TTS 模型生成翻译后的语音，用户可以用纯文本指定想要的声音特征。Together 托管的 Cartesia Sonic 3 支持韩语、荷兰语、意大利语、中文等大量母语者声音，让翻译后的视频听起来自然。注意：我们的工具不允许声音克隆，而是使用与原说话人不同的声音，并默认把新声音以低音量叠在原声音之上。

此外，视频 chat 模块让你就视频提问，背后是一个视觉-语言模型——它既懂音频里说了什么、也懂屏幕上显示什么。实现方式是采样近期视频帧和字幕上下文，发送给像 Qwen3.5-397B-A17B 这样的视觉-语言模型做自由形式问答。这样，模型可以基于这些上下文返回恰当的回应。

## **为人人设计：Web 应用、CLI 和 agent skills**

我们构建 Violin 时以可用性为核心。无论你是偏好简洁 web 界面的内容创作者、住在命令行里的开发者，还是把工具集成进自主 agent 的 AI 从业者，Violin 都有对应方案：

- Web App——一个干净极简的前端，用于上传视频、选择翻译选项、预览结果、与视频助手交互。无需代码。
- CLI Tool——直截了当的命令行界面，用于脚本、批处理和接入现有流水线。
- Agent Skills——我们把 Violin 的能力打包成可以丢进常见 agent 框架的 skill。

一切——从 GUI 到后端模型到 agent skills——完全开源。我们在宽松的 MIT 许可下发布代码库，邀请社区改编、扩展和改进。我们相信开放协作是让视频内容真正语言无关的最快路径。
