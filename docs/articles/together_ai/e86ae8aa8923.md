今年，Together AI 很高兴参与 NVIDIA GTC，有多项重大发布和对话正在塑造 AI 生态——从前沿模型发布到新语音 AI 能力，还有与我们研究及工程领导者的技术分会场。

如果你参加 GTC，我们很想认识你。

## **核心发布**

在 GTC 2026，我们参与的若干发布突出一条核心主题：**AI 系统正变得更开放、更 agentic、更接近生产就绪。** Together AI——AI Native Cloud——正是为支撑这一转变而设计，帮助开发者以真实应用所需的性能与成本效率训练、塑形和部署大规模 AI 系统。今天在 GTC 我们有多项发布。

### 在 Together AI 使用 NVIDIA Dynamo 1.0

NVIDIA 发布了 [NVIDIA Dynamo 1.0](https://nvidianews.nvidia.com/news/dynamo-1-0?ncid=partn-859211)——面向规模生成式与 agentic 推理的开源软件。我们很高兴与 NVIDIA 合作 Dynamo 1.0，并早已把 Dynamo 作为推理栈的一部分，在生产用例中交付更优化的性能。Together AI 承诺开放创新，期待探索 Dynamo 1.0 可应用的更多用例。

### 通过 NVIDIA OpenShell 接入 Together 的高性能推理

Together AI 与 NVIDIA 正共同推进 [NVIDIA NemoClaw](https://www.nvidia.com/en-us/ai/nemoclaw/)——一个开源技术栈，用一条命令更安全地简化运行 OpenClaw 常驻助手。作为 NVIDIA Agent Toolkit 的一部分，它安装 NVIDIA OpenShell runtime——一个运行自主 agent 的安全环境和开放源模型（如 NVIDIA Nemotron）。Together 很高兴托管 NVIDIA OpenShell runtime——为希望用高性能模型构建 agent 的客户打造。Together AI 有 150+ 优化模型的库，现在可通过 NemoClaw 轻松访问。搭配 Together 的 dedicated endpoints，开发者在生产规模上获得其推理引擎的速度与成本效率。

### 用 NVIDIA Nemotron 3 Super 支撑多 agent 工作流

[NVIDIA Nemotron 3 Super](https://blogs.nvidia.com/blog/nemotron-3-super-agentic-ai/?ncid=partn-620329) 是一个混合 Mixture-of-Experts 模型，为高性能推理与多 agent 工作流而设计。它结合 Mamba-Transformer 架构与 1M token 上下文窗口，支撑长程推理与复杂 agent 交互。120B 总参数（每 token 激活 12B），模型被优化为高效运行多个协作 agent——甚至单 GPU 即可——非常适合 AI 原生工作流，如软件开发 agent、金融分析和网络安全自动化。Nemotron 3 Super 可通过我们的 [Dedicated Model Inference](https://www.together.ai/dedicated-model-inference) 部署，为开发者提供在生产中运行高级推理模型的简单、可扩展方式。

### 用 NVIDIA Parakeet TDT 0.6B V3 构建语音 agent

作为我们近期[语音方案发布](https://www.together.ai/blog/build-real-time-voice-agents-on-together-ai)的一部分，[NVIDIA Parakeet](https://catalog.ngc.nvidia.com/orgs/nvidia/teams/nim/collections/parakeet-ctc-riva-0-6b) TDT 0.6b V3 自动语音识别（ASR）模型现已进入 [Together AI Model Library](http://www.together.ai/models/parakeet-tdt-0-6b-v3)，让开发者获得为实时语音应用优化的高性能、低延迟转录。把 Parakeet 的 ASR 准确率与 Together 的高性能推理基础设施结合，AI 原生团队可以构建生产就绪的语音 agent，交付快速、可靠、可扩展的转录。
