# Together Link：在你已在用的 harness 中用上前沿品质的开放模型

在你已经在用的编码 agent 里用上前沿开放模型，成本降低 50% 以上。

## 摘要

[Together Link](http://together.ai/link) 把你团队已经在用的 harness（即你日常使用的那套编码 agent 工具）连接到 Together AI 上最优秀的开放模型，并将你的支出降低 50% 以上。同样的 agent、同样的工作流，账单却只有零头。

编码 agent 如今在工程团队中已十分普遍，而你交给它们的每一项任务——从改一行代码到彻底重写——往往都跑在同一款高端模型上。一旦上量，成本就会迅速攀升：工程组织每月在闭源模型上的花费从数万美元到数百万美元不等。

开放模型已经实实在在地缩小了与闭源实验室顶级模型之间的差距。Kimi K3、GLM 5.3 等领先者如今能以远低于对方的每 token 价格，处理许多最难的编码任务；而 GLM 5.3 Flash、DeepSeek V4.1 Flash 这类小巧而强力的模型则能胜任日常编码任务。Together Link 把这些模型带进了你团队已经熟悉的工具里。

## 在你已有的工作场景里就能用

Together Link 支持 Claude Code、Claude Desktop、Codex（在 ChatGPT 应用和 CLI 中）、OpenCode 和 Pi。你的团队照常工作：设置和登录保持原样，没有新东西要学，而想要切回原生的闭源模型只需一条命令。几分钟之内，你就能在开放模型上跑起来。

## 开始使用

```
curl -fsSL https://link.together.ai/install | bash
```

- **运行一条命令即可设置好 Together Link：** 你的 agent 打开方式与以往完全相同，只是现在通过你的 Together AI API key 连接到了 Together AI。前往[创建账号](https://api.together.ai/)获取 API key。
- **用"Auto"借助 Together AI Router 挑选模型：** 它会读取每个会话的首个任务，并把它发给合适的模型：快速修复交给又快又便宜的模型，难题则用上前沿能力。如果你自带 Anthropic key，它会在 Opus 5.5 与 GLM 5.3 之间路由；若没有，则在 GLM 5.3 与 GLM 5.3 Flash 之间路由。路由每个会话只发生一次，因此 prompt caching 依然有效。
- **每个会话结束后查看你省下的钱。** 按会话统计的追踪器会把你实际花的钱，与同样这个会话若跑在 Opus 5.5 上本应花的钱并排展示出来。

计费在你现有的 Together API key 上进行，走 serverless 按量付费或额度包。你不需要单独签合同。

## 构建在开发者早已选定的 serverless 平台之上

Together Link 运行在 Together 的 serverless 推理之上，也就是开发者在 OpenRouter 上为这些模型早已选定的同一套基础设施。Together AI 在 OpenRouter 上承接了最大份额的 token：DeepSeek V4.1 Flash（40.8%）、GLM 5.3 Flash（28.2%）和 Kimi K3（23.1%），速度与定价在各方面都具竞争力。（*截至 9/30/2026 的脚注*）
