# 腾讯 Hy4 上线 Together AI

腾讯的旗舰模型现在可以理解图像和文本，开发人员可以在Together Serverless Inference上运行它。

长话短说

- **Tencent Hy4 on Together AI：** 腾讯的旗舰模型现已在 Together Serverless Inference 上提供，具有 1M 代币上下文窗口。
- **图像输入：** Hy4是Hy家族中第一个接受图像和文本的模型，它支持工具调用和JSON输出。
- **我们测试的内容：** Hy4 从我们的一个图表中读取值，将图表重建为网页，然后根据一个提示编写一个可以运行的浏览器游戏。
- **无服务器定价：** Hy4 每 1M 个输入代币成本为 0.83 美元，每 1M 缓存输入代币为 0.042 美元，每 100 万个输出代币为 2.50 美元。

从今天开始，开发者可以在Together Serverless Inference上运行[Tencent Hy4](https://www.together.ai/models/tencent-hy4)。 Hy4 是腾讯的旗舰机型，也是 Hy 系列中首款支持图像和文本的机型。

我们给它两项小任务，看看它在实践中做了什么：从我们的一个图表中提取数据并用 HTML 重建该图表，然后通过单个提示编写一个浏览器游戏。这是返回的内容，以及您自己发出图表请求的代码。

## 它读取我们的图表，然后重建它

我们从愿景开始，因为这是 Hy4 添加的功能。我们从我们的 [Together Storage Accelerator](https://www.together.ai/blog/introducing-together-storage-accelerator) 帖子中获取了这张图表，给 Hy4 提供了它的屏幕截图，并要求其内容为 JSON。

Hy4 复制了布局、标签、值、颜色、天花板虚线和脚注。我们要求它使用通用字体，因此字体有所不同。

## 它写了一个游戏

对于第二个测试，我们给 Hy4 一个文本提示而不是图像，并要求它在一个 HTML 文件中编写一个浏览器游戏，没有库或外部资源：

> 在单个 HTML 文件中制作小型原创浏览器游戏，无需库和外部资源。键盘控制、分数、失败方式和重新开始。两分钟应该会很有趣。仅使用 HTML 进行回复。

Hy4回归了一款名为Polarity的游戏。我们将响应保存为 HTML 文件并在浏览器中打开它，而无需更改代码。

## 关于腾讯Hy4

Hy4继Hy4 Preview之后，添加了图像输入和计算机使用功能。腾讯表示，它训练了该模型来操作 Blender 和 CAD 工具等专业软件。它还与自己的产品团队合作，对 Hy4 在虚幻引擎、Unity 和 Godot 中进行办公室工作、金融研究和游戏开发进行培训和评估。 【腾讯公告】(https://www.tencent.com/tencent-launches-hy4-joining-the-ranks-of-the-worlds-leading-open-source-ai-models/)有详细内容。

## 在 Together AI 上运行

Hy4 现在可以通过 Together 的聊天完成 API 在模型字符串 `tencent/Hy4` 下使用。下面的示例是本文前面的图表请求。要运行它，请安装Together Python SDK (`pip install together`)，设置`TOGETHER_API_KEY`，并将[我们使用的图表](https://cdn.prod.website-files.com/69654e88dce9154b5f12070c/6afe92cf7001ead389e131e7_tsa-results-chart-brand.png)保存为`chart.png`。
```
import base64

from together import Together

client = Together()

with open("chart.png", "rb") as f:
    image = base64.b64encode(f.read()).decode()

response = client.chat.completions.create(
    model="tencent/Hy4",
    messages=[
        {
            "role": "user",
            "content": [
                {
                    "type": "text",
                    "text": "Read this chart. Return a JSON object with a title "
                    "and a list of bars, each with a label and a value.",
                },
                {
                    "type": "image_url",
                    "image_url": {"url": f"data:image/png;base64,{image}"},
                },
            ],
        }
    ],
    response_format={"type": "json_object"},
)

print(response.choices[0].message.content)
```
如果您想在编写任何代码之前尝试 Hy4，您可以在 [playground](https://api.together.ai/playground/v2/chat/tencent/Hy4) 打开它，[模型页面](https://www.together.ai/models/tencent-hy4) 包含完整的详细信息。

## 常见问题解答

### 腾讯 Hy4 在 Together AI 上的售价是多少？

腾讯 Hy4 在 Together AI 上的成本为每 100 万个输入代币 0.83 美元，每 100 万个输出代币 2.50 美元，每 100 万个缓存输入代币 0.042 美元。

### 腾讯Hy4在Together AI上的上下文窗口是什么？

腾讯 Hy4 在 Together AI 上有一个 1M 代币的上下文窗口，您可以使用模型字符串 `tencent/Hy4` 来调用它。

### 腾讯Hy4接受图片吗？

是的，腾讯Hy4在Together AI上接受文本和图像输入并返回文本，它是腾讯Hy家族中第一款具有视觉功能的模型。您可以将每个图像作为消息内容中的 `image_url` 块发送，如上例所示。

### 腾讯Hy4支持JSON输出和工具调用吗？

是的，腾讯 Hy4 在 Together AI 上都支持两者。您可以通过将 `response_format` 设置为 `{"type": "json_object"}` 来获取 JSON 输出，并通过在标准 `tools` 参数中传递函数来启用工具调用。
