# Tencent Hy4 已在 Together AI 上线

腾讯的旗舰模型现在既能理解文本，也能理解图像，开发者可以直接在 Together Serverless Inference 上运行它。

- 作者：Sonny Khan
- 本文中的链接[在 playground 中试用 Hy4](https://api.together.ai/playground/v2/chat/tencent/Hy4)[Tencent Hy4 模型页](https://www.together.ai/models/tencent-hy4)[腾讯公告](https://www.tencent.com/tencent-launches-hy4-joining-the-ranks-of-the-worlds-leading-open-source-ai-models/)

TL;DR

- **Tencent Hy4 on Together AI：** 腾讯的旗舰模型现已上线 Together Serverless Inference，支持 1M token 的上下文窗口。
- **图像输入：** Hy4 是 Hy 系列中首个同时接受图像与文本的模型，支持 tool calling 和 JSON 输出。
- **我们测了什么：** Hy4 从我们的一张图表里读出数值，把这张图重建为网页，还凭一句 prompt 写出一个能玩的浏览器游戏。
- **Serverless 价格：** Hy4 每 1M 输入 token 收费 \$0.83，每 1M 缓存输入 token 收费 \$0.042，每 1M 输出 token 收费 \$2.50。

从今天起，开发者可以在 Together Serverless Inference 上运行 [Tencent Hy4](https://www.together.ai/models/tencent-hy4)。Hy4 是腾讯的旗舰模型，也是 Hy 系列中首个支持图像与文本输入的模型。

我们给它安排了两个小任务，看它在实际场景里表现如何：先从我们的一张图表中提取数据、再用 HTML 把这张图重建出来，然后凭一句 prompt 写一个浏览器游戏。下面是它返回的结果，以及你自己发起那次图表请求所需的代码。

## 它读懂了我们的图表，还把它重建了出来

我们从视觉能力入手，因为这是 Hy4 新增的部分。我们取来 [Together Storage Accelerator](https://www.together.ai/blog/introducing-together-storage-accelerator) 那篇文章里的一张图表，把截图交给 Hy4，要求它把图表内容以 JSON 返回。

![我们交给 Tencent Hy4 的图表：来自 Together Storage Accelerator 文章的条形图，共三根柱子，分别标注为 TSA 热读取 3.18 GB/s、R2 源站直连 0.16 GB/s、TSA 冷读取 0.14 GB/s。](https://cdn.prod.website-files.com/69654e88dce9154b5f12070c/6aff9343e74092fb5e5a45a0_hy4-chart-original.png)

返回结果里的标题和三个数值，与图表上显示的完全一致：

```
{
  "title": "A warm TSA read is 3.2 GB/s: 20x the R2 origin",
  "bars": [
    {
      "label": "TSA warm read",
      "value": 3.18
    },
    {
      "label": "R2 origin, direct",
      "value": 0.16
    },
    {
      "label": "TSA cold read",
      "value": 0.14
    }
  ]
}
```

接着我们用同一张截图，要求它把图表复现为单个 HTML 文件。这次输出不仅要数字对，还要保住视觉布局。上面是原图，下面是 Hy4 的版本。

![同一条形图的两个版本上下堆叠。上方是 Together Storage Accelerator 文章中的原图，下方是 Tencent Hy4 依据截图重建的版本，布局、标签、数值和配色都相同。](https://cdn.prod.website-files.com/69654e88dce9154b5f12070c/6aff944a13ada1c388c8adc6_hy4-chart-original-vs-rebuilt.png)

Hy4 复现了布局、标签、数值、配色、顶部那条虚线基准线以及脚注。我们要求它使用通用字体，所以字形与原图不同。

## 它写出了一个游戏

第二个测试，我们给 Hy4 的是一段纯文本 prompt 而不是图片，要求它在单个 HTML 文件里写出一个浏览器游戏，不许用库，也不许用外部资源：

> 在单个 HTML 文件里做一个原创的小型浏览器游戏，不用任何库，也不使用外部资源。要有键盘操作、分数、失败机制和重新开始。玩两分钟要觉得有意思。只回复 HTML。

Hy4 返回的游戏叫 Polarity。我们把响应存成 HTML 文件，未改一行代码直接在浏览器里打开。

方块从屏幕顶部落下，你要接住与自身颜色一致的那些，按空格键切换颜色。黄色障碍一旦碰到你就结束本局。Hy4 还自己加了标题界面来解释规则，以及跨局延续的最高分——这两样我们都没要求。

![Tencent Hy4 所写浏览器游戏 Polarity 的三张画面：列出三条规则的标题界面、方块下落中的一局，以及显示新纪录的结束界面。](https://cdn.prod.website-files.com/69654e88dce9154b5f12070c/6aff947ca9cbf529712aa72f_hy4-polarity-game.png)

我们完整玩了一局，走到结束界面，并成功重新开始。

## 关于 Tencent Hy4

Hy4 继 Hy4 Preview 之后加入了图像输入和 computer-use 能力。腾讯称他们训练该模型操作 Blender 和 CAD 工具这类专业软件，还与自家产品团队合作，让 Hy4 在办公工作、金融研究以及基于 Unreal Engine、Unity 和 Godot 的游戏开发场景中接受训练与评估。[腾讯公告](https://www.tencent.com/tencent-launches-hy4-joining-the-ranks-of-the-worlds-leading-open-source-ai-models/) 里有详细说明。

## 在 Together AI 上运行

Hy4 现已可用，模型串为 `tencent/Hy4`，通过 Together 的 chat completions API 调用。下面的示例就是前文的图表请求。要运行它，请安装 Together Python SDK（`pip install together`），设置 `TOGETHER_API_KEY`，并[把这张图表](https://cdn.prod.website-files.com/69654e88dce9154b5f12070c/6afe92cf7001ead389e131e7_tsa-results-chart-brand.png)另存为 `chart.png`。

```
import base64

from together import Together

client = Together()

with open("chart.png", "rb") as f:
    image = base64.b64encode(f.read()).decode()

response = client.chat.completions.create(
    model="tencent/Hy4",
    messages=[
        {
            "role": "user",
            "content": [
                {
                    "type": "text",
                    "text": "Read this chart. Return a JSON object with a title "
                    "and a list of bars, each with a label and a value.",
                },
                {
                    "type": "image_url",
                    "image_url": {"url": f"data:image/png;base64,{image}"},
                },
            ],
        }
    ],
    response_format={"type": "json_object"},
)

print(response.choices[0].message.content)
```

## 常见问题

### Tencent Hy4 在 Together AI 上怎么收费？

Tencent Hy4 在 Together AI 上每 1M 输入 token 收费 \$0.83，每 1M 输出 token 收费 \$2.50，每 1M 缓存输入 token 收费 \$0.042。

### Tencent Hy4 在 Together AI 上的上下文窗口有多大？

Tencent Hy4 在 Together AI 上提供 1M token 的上下文窗口，调用时使用模型串 `tencent/Hy4`。

### Tencent Hy4 接受图像吗？

接受。Tencent Hy4 在 Together AI 上接受文本与图像输入并返回文本，是腾讯 Hy 系列中首个具备视觉能力的模型。每张图都作为 message content 里的一个 `image_url` 块发送，写法见上面的示例。

### Tencent Hy4 支持 JSON 输出和 tool calling 吗？

支持，这两项在 Together AI 上都可用。把 `response_format` 设为 `{"type": "json_object"}` 即可获得 JSON 输出；把函数放进标准的 `tools` 参数即可启用 tool calling。
