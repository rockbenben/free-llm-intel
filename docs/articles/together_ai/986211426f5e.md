# 隆重推出 Together Storage Accelerator：为您的 GPU 集群提供快速、免费的数据缓存

每个 GPU 节点上的分布式缓存：热读取速度提高约 20 倍，每个集群一次原始提取，并且没有应用程序更改。随 Together GPU Clusters 免费提供。

GPU 的速度取决于数据管道的速度。每次以 30 分钟的模型下载开始的训练运行、从全国各地重新提取相同数据集的每个节点，以及每一个导致工作停滞的 Hugging Face 速率限制，都会导致计算资源闲置，等待您的数据，而您却在为它们付费。

今天，我们推出 **Together Storage Accelerator (TSA)**，它是 Together GPU 集群的分布式缓存层，可减少从对象存储和 Hugging Face Hub 重复读取数据的需要，从而显着加速您的 AI 数据管道，同时减少数据传出费用。 TSA 现在**免费**包含在每个 Together GPU 集群中。

## 问题：您的数据距离 GPU 很远

大多数人工智能团队将其事实来源保存在对象存储中（Amazon S3、Cloudflare R2、Together AI 的 T4*）或直接从 Hugging Face Hub 中提取模型。这意味着每次冷启动都要缴纳 WAN 税：跨云或跨区域读取速度慢、成本高（AWS 的出口高达 0.09 美元/GB）且速率有限。当数百个节点拉取相同的检查点时，浪费会增加，并会花费您的时间、金钱，并且当源端限制您时，作业也会失败。

**T4 是 Together AI 的数据中心 S3 兼容对象存储解决方案，目前处于有限预览版。如果您有兴趣尝试，请联系销售人员或您的客户团队。*

## TSA 缓存数据，提高性能、可靠性和成本

TSA 为您提供 GPU 集群的分布式缓存层。它在集群中的每个 GPU 节点上运行，并为您已使用的存储提供直接端点。任何节点第一次读取对象时，TSA 都会将其缓存在集群 NVMe 上。因此，来自任何节点的每个后续读取都将从集群内部以显着更高的本地速度提供服务。

在 Together GPU Cluster H100 节点上测量的结果：

- **比从跨云源拉取的热读取速度快约 20 倍**，每个节点高达 **3.4 GB/s**。从 Cloudflare R2 下载需要 13-15 秒的 2 GiB 对象，可以在 0.6 - 0.7 秒内从缓存中读取
- **冷读无需额外费用**：通过 TSA 的首次读取运行速度约为直接下载的 5%
- **每个集群一次源获取。** 由 200 个节点拉取的 70 GB 检查点从源下载一次，而不是 200 次
- **对中断和速率限制的恢复能力。** 即使上游不提供服务，缓存数据也能继续提供服务。

您可以开始使用 TSA **无需对您的应用程序进行任何更改**。无需新的 SDK，无需重写数据加载器，您只需一个命令即可开始使用。

**入门：**
```
# S3-compatible storage (S3, R2, T4, ...)
export AWS_ENDPOINT_URL=http://tsa.tsa.svc.cluster.local:18080

# Hugging Face Hub
export HF_ENDPOINT=http://tsa.tsa.svc.cluster.local:18080
```
您现有的 boto3 代码、变压器调用和 CLI 工作流程按原样工作。 TSA 使用您配置的凭据处理身份验证。凭证经过加密并安全地存储在机密库中。

## 测量结果

![](https://cdn.prod.website-files.com/69654e88dce9154b5f12070c/6afe92cf7001ead389e131e7_tsa-results-chart-brand.png)

于 2026 年 10 月 28 日从 Together GPU 集群 (us-central) 中的一个 H100 节点上的 Pod 进行测量。除非另有说明，否则均为单流读取；客户端写入 /dev/null 或节点 NVMe。

- **从跨云存储桶 (Cloudflare R2) 读取 2 GiB 对象：** 无 TSA 时为 143–169 MB/s（12.7–15.0 秒），在 TSA 热时为 3.0–3.4 GB/s（0.64–0.72 秒）。 **~20×**
- **从同一存储桶读取小文件（5 KB、2.4 MB）：** 不使用 TSA 时为 320 毫秒和 680 毫秒，使用 TSA 热时为 5 毫秒和 8 毫秒。 **~60–80×** 较低的延迟
- **200 个节点的集群拉取相同的检查点：** 200 个不带 TSA 的源获取，1 个带 TSA。 **减少 200×** 出口

*在 Together GPU 集群预览部署上测量（TSA 图表 0.6.0）；您的结果取决于来源、对象大小和网络路径。起源速度是区域性的：相同的 Hugging Face 下载从美国中部地区运行的速度比从加州西部地区快 5 倍，因此，在起源最慢的地方，TSA 的优势最大。方法：来自 GPU 节点上的 pod 的单流curl 和 aws s3 cp，重复读取同一对象，针对直接下载进行 MD5 验证。*

## 由 ASTRA 提供支持

TSA 利用 [**ASTRA**](https://docs.together.ai/docs/astra)（加速存储传输和检索架构），这是我们为满足世界上一些最大的 GPU 队列（包括我们自己的推理队列）而构建的分布式缓存技术。我们将在即将发布的工程帖子中分享对 ASTRA 的更深入的技术了解。

## 与T4一起使用效果更好

TSA 可与任何 S3 兼容的存储配合使用，并与 Together AI 的托管对象存储解决方案 **T4** 自然配对。立即将 TSA 指向您现有的 S3 或 R2 存储桶，无需迁移数据。当您希望温数据永久驻留在 GPU 旁边时，T4 只需进行一次配置更改即可。 T4 目前处于**有限预览版**：联系销售人员或您的客户团队以获取访问权限。
