[NVIDIA Nemotron™ 3 Nano Omni](https://developer.nvidia.com/blog/nvidia-nemotron-3-nano-omni-powers-multimodal-agent-reasoning-in-a-single-efficient-open-model) 现已[在 Together AI 平台可用](https://blogs.nvidia.com/blog/nemotron-3-nano-omni-multimodal-ai-agents/)。Nemotron 3 Nano Omni 是多模态 AI 的一次实质进步——一个单一的开放模型，跨视频、图像、音频和语言进行推理。对构建 agentic 应用的开发者，Together AI Dedicated Inference 是最快的上手与扩展方式。

## **为什么在 Together AI 上运行它**

Together AI——AI Native Cloud——一直是那些想要快速、实惠、可靠地访问全球最佳开放模型做生产规模推理的开发者的首选平台。

Nemotron 3 Nano Omni 通过执行链式动作把跨模态上下文统一起来——这对需要确定性行为的 agent 常常是关键。这意味着一个 agent 可以同时跨音频输入（如录音或转录）、截图、视频、结构化文档这类视觉输入进行推理——不必把理解碎片化到多次独立推理中。

**1. Together AI 的研究优化释放模型架构的全部潜力**

Nemotron 3 Nano Omni 的混合 Mamba-Transformer Mixture-of-Experts（MoE）架构在 30B 总参数中每 token 仅激活约 3B，并用多 token 预测（MTP）在单次前向传播中同时生成多个未来 token。Together AI 的技术栈由前沿 AI 系统研究驱动，实现高吞吐、具成本效益、生产级、延迟持续稳定的推理。把它与这个全新、高效、高精度的 Nemotron 3 Nano Omni 模型结合，意味着更快的多模态推理、每单位算力更多智能。

**2. 为 agentic、生产规模推理负载打造的托管基础设施**

Agent 应用依赖可预测的性能。Together AI 在流量尖峰下保持可靠性能、高在线率与 token 流式输出，帮助 agent 循环即使在长上下文或持续决策任务中也保持响应。开发者可以快速在 Together AI 上部署 Nemotron 3 Nano Omni、无需管理基础设施，并从原型到生产无缝扩展。这个全托管环境消除运维开销，让团队专注构建，而不是维护 GPU。

**3. 保护你数据的安全、生产就绪平台**

Together AI 提供简单、开发者友好的 API——轻松把 Nemotron 3 Nano Omni 集成进多 agent 框架、规划系统和多模态系统。加上稳定安全的 API，平台给组织一个可信的根基大规模部署 AI——不必用速度换安全。

## **Nemotron 3 Nano Omni 擅长哪里**

今天多数生产 AI 系统通过碎片化流水线处理多模态输入：一个模型管视觉、另一个管音频、再一个管文档——用定制编排逻辑缝起来。这个架构的每一个接缝都是潜在故障点——增加的延迟、错位的上下文、跨模级联的错误。

Nemotron Nano Omni 消除了这些接缝。

基于 Mixture of Experts（MoE）架构与混合 Transformer-Mamba 设计构建，这个 30B A3B 模型支持在单一连贯推理循环内最多 256K token 的共享多模态输入上下文。这允许 agent 理解音频输入（如转录）、截图这类视觉输入和相关文档——而不把理解碎片化到独立推理轮次中。

效率收益很显著：

- 减少对多模型流水线的需求，降低系统复杂度
- 跨视频、音频、文档负载的多模态处理更高效
- 长上下文 agentic 应用的吞吐与可扩展性更好
- 部署灵活，在 [NVIDIA Hopper](https://www.nvidia.com/en-us/data-center/technologies/hopper-architecture/)、[NVIDIA Blackwell](https://www.nvidia.com/en-us/data-center/technologies/blackwell-architecture/) 等硬件上支持 FP8 与 NVFP4

而且它完全开放。开放权重、开放数据、开放训练后配方。开发者可以在任何地方部署——云、本地、气隙环境——拥有完整数据控制权、没有模型锁定。

## **你可以构建什么**

把感知与推理统一进一个模型，打开了此前太复杂或太昂贵而无法投产的用例：

**客服 agent** 可以同时跨通话录音、屏幕录制和政策文档进行推理——既理解用户意图也理解系统上下文。

**金融分析 agent** 跨财报电话会音频、投资人演示视频、扫描的图表图像和 SEC 文件推理——产出有据可依的洞见，而非表面摘要。

**计算机使用 agent** 通过屏幕录制看 UI、解读指令、对照约束文档验证动作——全部在单一推理上下文内。

任何以前需要组装多模型栈的应用，如今都有了一条更干净的投产之路。
