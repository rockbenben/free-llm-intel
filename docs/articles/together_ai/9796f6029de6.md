摘要

- **FLUX.2 登陆 Together AI**：Black Forest Labs 最新的图像模型，用多参考图像输入保证角色/产品一致性，现已面向 100 万以上 Together AI 开发者开放
- **关键规格**：最高 4MP 分辨率、<10s 生成、32K 字符、hex code 颜色匹配，400x400px 的输入即可工作
- **三款模型**：[FLUX.2 [dev]](https://www.together.ai/models/flux-2-dev)、[FLUX.2 [pro]](https://www.together.ai/models/flux-2-pro)、[FLUX.2 [flex]](https://www.together.ai/models/flux-2-flex)
- [‍](https://www.together.ai/models/flux-2-flex)**与 LLM 用同一套 SDK**：与现有 Together AI 代码可直接替换，serverless 或 dedicated 部署皆可

图像生成已经跨过了演示关卡，但生产团队仍然无法端到端地信任它。失误不在审美，而在运营层面：品牌色接近却不够精确，文字退化成噪点，角色或产品在不同镜头之间微妙漂移，破坏一整场 campaign 或整套目录的连续性。结果是一笔隐性税负——手工修补与返工，把承诺过的速度抵消殆尽。即便某个新模型补上了其中一处短板，它通常又是另一个独立服务，自带一套 SDK、鉴权、计费和限额——在本已大规模跑着 LLM 和语音的技术栈里，让碎片化雪上加霜。

今天，AI Native Cloud——Together AI，把 [Black Forest Labs](https://www.together.ai/models-providers/black-forest-labs) 的 FLUX.2 带进了 Together Model Library，让超过 100 万 AI 开发者用得上生产级图像生成。FLUX.2 瞄准的正是真实应用所要求的控制力：多参考图像输入，让角色与产品跨场景保持一致；hex code 颜色匹配，满足严格的品牌规范；文字渲染则扛得住排版、UI 和信息图。FLUX.2 [dev] 是开放权重模型，FLUX.2 [pro] 作为优化过的 API 模型交付，FLUX.2 [flex] 提供可调参数，三者都通过 Together AI 快速可靠的基础设施、以及生成式技术栈其余部分沿用的同一套 API 提供服务

## **代码**

标准的 Together AI Python SDK，与文本生成用的是同一套模式：

```
    
    from together import Together

    client = Together()

    response = client.images.generate(
        model="black-forest-labs/FLUX.2-pro",
        prompt="A mountain landscape at sunset with golden light reflecting on a calm lake",
        width=1024,
        height=768,
    )

    print(response.data[0].url)

    
```

选契合你工作流的模型：Dev 用于实验，Pro 用于生产速度，Flex 用于文字密集的内容。
