总结

- **Together AI 上的 FLUX.2**：Black Forest Labs 的最新图像模型具有多参考输入，可实现字符/产品一致性，现已可供 100 万以上 Together AI 开发人员使用
- **关键规格**：高达 4MP 分辨率，<10 秒生成，32K 字符，十六进制代码颜色匹配，适用于 400x400px 输入
- **三个模型**：[FLUX.2 [dev]](https://www.together.ai/models/flux-2-dev)、[FLUX.2 [pro]](https://www.together.ai/models/flux-2-pro)、[FLUX.2 [flex]](https://www.together.ai/models/flux-2-flex)
- [‍](https://www.together.ai/models/flux-2-flex)**与 LLM 相同的 SDK**：与现有 Together AI 代码、无服务器或专用部署兼容

图像生成已经清除了演示栏，但制作团队仍然不能完全信任它。这些失误不是审美上的，而是操作性的：品牌颜色接近但不准确，文本退化为噪音，人物或产品在镜头之间微妙地变化，破坏了整个活动或目录的连续性。其结果是产生了手动清理和返工的隐性税收，从而抹去了承诺的速度。即使新模型修复了其中一个缺陷，它通常也是作为另一项独立服务提供的，具有自己的 SDK、身份验证、计费和限制——在已经大规模运行 LLM 和语音的堆栈中加剧碎片化。

今天，Together AI（AI 原生云）将 [Black Forest Labs](https://www.together.ai/models-providers/black-forest-labs) 的 FLUX.2 引入 Together 模型库，为超过 100 万 AI 开发人员提供生产级图像生成功能。 FLUX.2 针对实际应用程序所需的控件：跨场景的一致字符和产品的多参考输入、严格品牌合规性的十六进制代码颜色匹配，以及支持排版、UI 和信息图表的文本渲染。 FLUX.2 [dev] 是一个开放权重模型，FLUX.2 [pro] 作为优化的 API 模型提供，FLUX.2 [flex] 提供可调参数，所有这些都通过 Together AI 快速、可靠的基础设施以及在生成堆栈的其余部分使用的相同 API 提供服务

## **代码**

标准Together AI Python SDK，与文本生成相同的模式：
```
    
    from together import Together

    client = Together()

    response = client.images.generate(
        model="black-forest-labs/FLUX.2-pro",
        prompt="A mountain landscape at sunset with golden light reflecting on a calm lake",
        width=1024,
        height=768,
    )

    print(response.data[0].url)

    
```
选择适合您工作流程的模型：Dev 用于实验，Pro 用于生产速度，Flex 用于文本密集型内容。
