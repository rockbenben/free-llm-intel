## 摘要

我们与大语言模型（LLM）的交互被任务或主题特定的提问主导，比如"*解决这个编程问题*"或"*什么是民主？*"。这种框架强烈塑造 LLM 生成响应的方式，约束了可观察到的行为与知识范围。我们用极简、主题中立的 prompt 研究 LLM 的行为。**尽管没有显式的任务或主题指定，LLM 生成的内容依然多样；但每个模型家族表现出截然不同的主题偏好**。GPT-OSS 偏好编程和数学，Llama 偏向文学，DeepSeek 经常产出宗教内容，Qwen 倾向于多选题。我们还观察到生成分裂可能退化为重复或无意义的输出，暴露模型特有的怪癖——比如 Llama 会生成个人社交媒体 URL。

### **我们研究什么？**

多数 LLM 行为分析都是受限的：prompt 严重塑造了模型能说什么 [1,2]。这有用——但也深度局限。

**Prompt 像过滤器。** 数学问题强制数学推理；chat template 把模型塞进助手人设。模型生成空间的大片区域从未被调用。我们观察到的不是模型的自然行为，而是我们的指令诱导的行为。所以我们问一个更基本的问题：

***当你不告诉语言模型该生成什么时，它会生成什么？***

为回答这个问题，我们研究近无约束生成。我们使用主题中立、开放式的种子 prompt，比如 "Actually"、"Let's think step by step"，甚至只是一个标点 "."。我们完全移除 chat template——没有 system prompt、没有角色——使用标准解码。这个设置近似模型心头的第一反应：在对齐和 prompt 接管之前，对其学到的生成先验的一瞥。

### **为什么这很重要**

如果你关心模型审计、行为监控、LLM 指纹识别，或安全与隐私风险，条件化基准还不够。我们需要直视模型的原始生成，看 LLM 在多样输入和 prompt 条件下如何表现。

作为一个少有研究但科学上引人入胜的设置，**近无约束生成让我们能观察模型偏好谈论什么、哪些内容被过度表征，以及当固定的 chat template 和特殊标签被移除时它们如何失败。** 关键在于，这些信号被证明是系统性的，而非轶事。

## **结果：当你不告诉 LLM 该想什么时，它们在想什么？**

### **结果 1：模型家族有不同的知识先验**

图 1。近无约束 LLM 生成的 embedding 可视化。每个点代表一个生成样本；颜色表示事后推断的语义类别；虚线表示高密度区域。即使没有显式主题，模型输出也聚成清晰区域，每个模型家族形成不同的语义偏好。交互图见 https://tinyurl.com/mzr5cckz。

如图 1(a) 所示，*尽管 prompt 中没有显式指令或主题，LLM 生成了广泛的主题范围*。LLM 生成各类内容，包括文科（文学、哲学、教育）、科学与工程（物理、数学、编程），以及法律、金融、音乐、体育、烹饪、农业、考古、军事和时尚等领域。

更令人惊讶的是，如图 1(b) 所示，**不同模型家族即使面对相同的最小 prompt，也倾向语义空间的不同区域。** GPT-OSS 压倒性地默认编程（27.1%）和数学（24.6%）——超过一半的模型家族输出集中在这两个领域！Llama 产出多得多的文学与叙事文本（9.1%），较少侧重技术领域（见图 2）。DeepSeek 生成宗教内容的比率显著高于其他家族。Qwen 频繁输出多选题考题，连答案选项一起。

图 2。近无约束生成下按模型家族的主要语义类别。每个家族呈现稳定、可解释的主题分布。

这里值得注意的是**一致性**。这些分布在不同 prompt、不同 embedding 模型、不同语义标注器下都持续存在。这种行为看起来不像噪声，更像一种群体级指纹。图 3 展示了代表性例子。

图 3。无约束设置下模型输出的例子。更多例子见论文。

### **结果 2：深度也是先验的一部分**

差异不仅在模型谈论什么、多常谈论，也在它们深入的程度。我们在图 4 中评估编程与数学文本的复杂度。

我们发现 **GPT-OSS 频繁产出高级或专家级内容（68.2%）**，如深度优先搜索、广度优先搜索或动态规划（见图 3）。Llama 和 Qwen 更偏向基础或中级材料。即使控制标注模型与评估设置，这些深度差异仍然成立。

图 4。数学与编程文本的难度等级分布。难度标签由 Claude-4.5-Opus 标注。高级与专家级内容在 GPT-OSS 输出中出现得多得多。

### **结果 3：退化文本是信号，不只是噪声**

最后，沿袭先前工作 [3,4]，我们也观察到模型有时会陷入重复或退化模式，尤其在约束被移除时。这种行为通常被当作乱码丢弃。**我们把它当数据。**

通过分析退化从哪里开始、多常发生、长什么样，我们发现了鲜明的模型差异。GPT-OSS 倾向重复短格式伪影，如代码块分隔符（```\n\n```\n\n）。Qwen 产出长对话短语、emoji 和中文文本。Llama 有时会发出指向真实个人 Facebook 和 Instagram 账号的 URL（图 6）。深入分析见论文。

图 5。（上）各模型家族的退化文本行为：退化频率、起始位置和重复长度跨家族差异巨大。（下）退化文本的例子。Llama 的文本我们做了遮蔽，因为这些链接可访问个人账户。

**退化文本原来是对安全与隐私风险最清晰的窗口之一，恰恰因为它反映的是无控制的生成。** 这些行为很少出现在标准基准里，却极具揭示力。

## **为什么这让我们惊讶，以及收获**

鉴于所有被评估的模型在数学、编程和通用任务上大体有竞争力，我们起初预期它们的近无约束生成在各模型家族间会呈现相似的语义分布。结果我们观察到的却是跨越家族的鲜明、系统性偏差。我们没料到 GPT-OSS 超过 50% 生成数学和编程，也没料到 Qwen 生成这么高比例的多选题。

这些行为在各种实验设置下显得相当鲁棒。无论我们怎么改变 prompt、embedding 或标注器，同样的模式反复出现。也许最令人惊讶的是，退化并不是一种随机失败模式。相反，退化生成表现出一致的结构和风格，某些情况下还包含潜在的个人可识别信息。这些输出常常像训练分布的碎片，尽管其涌现背后的机制仍不清楚。

我们研究的近无约束生成不会取代标准基准评估。但它暴露了基准系统性漏掉的东西：当没人告诉 LLM 该说什么时，它们倾向于说什么。如果我们想把 LLM 当作系统来理解、而不只是考生，就需要研究它们的默认——不只是最佳答案或 prompt 诱导的输出。更详细的解释和实验见论文。
