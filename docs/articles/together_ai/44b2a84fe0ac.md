## **面向 agentic 工作流的架构能力**

现代 agentic 系统——分析海量文档库或编排多步规划——需要模型在长上下文中维持状态、又不牺牲生成速度。Nemotron 3 Super 引入了若干架构创新，使它非常适合这些负载：

- **混合 MoE 架构（Transformer + Mamba）：** 把 Mamba 高效的序列处理与 Transformer 注意力结合，模型在保持强推理能力的同时，把激活参数（120B 中仅 12B）控制在可支撑更快推理的规模。其 Latent MoE 设计让模型能以一个专家的推理成本调用四个专家，提升推理密集负载的效率。
- **1M token 上下文窗口：** 一百万 token 的上下文长度让应用能处理整个代码库、在长 agent 轨迹中维持状态，并把大得多的检索载荷直接注入 prompt。
- **多 token 预测：** Nemotron 3 Super 训练为在单次前向传播中同时生成多个 token。对产生大输出的应用——代码生成、结构化响应——这大幅降低生成延迟，token 生成速度比当前领先的开放模型快超过 50%。

为在 AIME 2025、SWE Bench Verified 等基准上取得领先准确率，模型使用多环境强化学习（RL）和 [NVIDIA 生成的高质量合成数据](https://docs.nvidia.com/nemo/microservices/latest/design-synthetic-data-from-scratch-or-seeds/index.html)训练。由于 NVIDIA 提供了开放权重、数据集和开发配方，工程团队保有完全的掌控，可为自己的特定环境定制和微调模型。

## **在 Together AI 上运行 Nemotron 3 Super**

服务一个 120B 参数、1M token 上下文的混合模型，通常需要跨多节点分布式计算。Nemotron 3 Super 通过 Together AI Dedicated Inference 提供——一个为实验和生产规模双重定制的基础设施环境，没有 GPU 自运维的开销：

- **单 GPU 部署：** 模型经过优化，在单 GPU 占用上运行协作 agent，支持部署在单块 NVIDIA H200 或 H100 GPU 上。Together AI 处理底层基础设施编排，让团队无需直接开通或管理 GPU。
- **为研究优化的性能：** 高效运行混合 MoE 架构需要高度调优的服务软件。Together AI 通过 Together Inference Engine 和定制 CUDA kernel 加速模型执行。这套栈帮助团队在实时推理中取得更低延迟和更高吞吐。**‍**
- **生产级隔离：** Dedicated Inference 在预留硬件上隔离工作负载，支撑可预测的吞吐与规模下的一致性能。平台运行在企业就绪的基础设施上，包括 99.9% 在线率 SLA 和 SOC 2 合规。

### **FAQ**

**NVIDIA Nemotron 3 Super 是什么？**

[NVIDIA Nemotron 3 Super](https://www.together.ai/models/nvidia-nemotron-3-super) 是一个混合 Mixture-of-Experts（MoE）推理模型，为复杂 AI 工作流与多步问题求解而设计。它结合 Transformer 与 Mamba 组件，以高效推理交付强推理能力。

**Nemotron 3 Super 使用什么架构？**

Nemotron 3 Super 使用把 Transformer 注意力与 Mamba 序列处理结合的混合 Mixture-of-Experts 架构。这一设计在保持强推理性能的同时提升计算效率。

**Nemotron 3 Super 支持多长的上下文？**

Nemotron 3 Super 支持最高 100 万 token 的上下文窗口，让应用能分析大型文档合集、维持长对话，并把大量检索上下文纳入推理工作流。

**哪些类型的应用可以使用 Nemotron 3 Super？**

Nemotron 3 Super 适合协调多个 agent 或在大型知识源上操作的应用。例子包括分析与重构代码库的开发者助手、处理大型文档合集的企业系统、分诊漏洞或分析系统日志的网络安全工作流，以及按用户意图在专精 agent 间路由任务的编排系统。

**开发者如何在 Together AI 上运行 Nemotron 3 Super？**

Nemotron 3 Super 通过 [Dedicated Model Inference](https://www.together.ai/dedicated-model-inference) 部署在 Together AI。专属部署让团队在为生产负载设计、性能可预测的预留基础设施上运行模型。

**开发者需要自己管理 GPU 吗？**

不需要。Together AI 管理底层基础设施，开发者无需直接开通 GPU 资源即可部署和扩展 AI 工作负载。

**为什么用 Together AI 跑这些负载？**

Together AI 为大规模 AI 系统提供专门设计的基础设施，包括可靠的推理、serverless 扩展，以及面向现代 AI 应用的托管基础设施。
