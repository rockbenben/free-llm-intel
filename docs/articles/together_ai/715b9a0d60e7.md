# 批量推理 API 升级：界面增强、模型支持扩展、速率限制提升 3000 倍

我们对 Batch Inference API 进行了一系列重大改进，让处理海量数据集的团队用起来更简单、更快、更强大。

### 新增内容

**精简的 UI**
在直观的界面中创建和跟踪批处理任务——无需复杂的 API 调用。

**全模型覆盖**
Batch Inference API 现在支持*所有* serverless 模型和私有部署，你可以在Exactly所需的模型上运行批处理工作负载。

**规模巨幅跃升**
速率限制从每模型每用户 **1000 万**入队 token 提升到 **300 亿**，提升 **3000 倍**。还不够？我们会与你合作定制。

**更低成本**
对大多数 serverless 模型，Batch Inference API 的费用是实时 API 的 **50%**，是处理高吞吐工作负载最经济的方式。

### Batch Inference API 实战

> "我们依赖 Batch Inference API 处理非常大量的请求。高额度速率限制——最高 300 亿入队 token——让我们能运行大规模实验而不受瓶颈限制，任务总是稳稳地在 24 小时 SLA 内完成，常常几小时就跑完。它彻底改变了我们测试和迭代的节奏。" —— Volodymyr Kuleshov，Inception Labs 联合创始人

Inception Labs 只是众多借助 Batch Inference API 加速实验与生产工作负载的团队之一。从研究数据集到面向客户的应用，Batch 让此前根本不可行的大规模处理成为可能。

### 理想用例

当你需要高吞吐但不受实时约束时，Batch Inference API 非常合适：

- **大规模文本分析**：情感分析、文档分类、内容打标
- **欺诈检测**：扫描数百万笔交易寻找异常
- **合成数据生成**：创建海量训练数据集
- **Embedding 生成**：把大型语料转成向量表示
- **内容审核**：规模化处理用户生成内容
- **模型评估：**运行大型基准测试套件
- **客服自动化：**高效处理 SLA 较宽的工单
