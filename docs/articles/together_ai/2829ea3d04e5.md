## Nemotron 3 Nano

**混合 Mamba–Transformer + 稀疏 MoE 架构**

[Nemotron 3 Nano](https://www.nvidia.com/en-us/ai-data-science/foundation-models/nemotron/) 采用一种混合架构，在不损失推理效率的同时取得强劲的推理表现：

- Mamba 层帮助高效处理长程依赖与结构化任务
- Transformer 层提供强力的通用推理与指令遵循
- 稀疏 Mixture-of-Experts 每个 token 仅激活 30B 参数中的约 3B，改善速度与成本

这个架构让 Nemotron 3 Nano 足够聪明以胜任复杂推理，又足够快以降低多 agent 系统成本。

凭借 1M token 上下文，Nemotron 3 Nano 能支撑长程规划、重 RAG 的流水线、文档与日志级负载，以及跨会话的持久 agent 记忆。

它包含开放权重、开放训练数据和开放训练配方。这使它适用于研究、企业使用和合规部署。

Nemotron 3 Nano 在编码、数学、科学推理和函数调用上表现强劲。[*阅读 NVIDIA Nemotron 3 Nano 发布公告。*](https://nvidianews.nvidia.com/news/nvidia-debuts-nemotron-3-family-of-open-models)

### Together AI 上的 NVIDIA Nemotron 3 Nano

Together AI 为生产规模的推理与 agentic 工作负载而设计——是部署 Nemotron 3 Nano 的理想平台。聚焦规模、可靠性、成本效率和简单 API，Together AI 让充分释放这个模型的潜力变得轻松。

- **性能：** Together AI 交付生产级推理，持续低延迟、高吞吐，帮助 Nemotron 3 Nano 支撑快速的多步推理循环、没有瓶颈。Together AI 还能跨并行 agentic 负载无缝扩展，服务多 agent 编排与工具使用流水线。
- **可靠性：** Agent 应用依赖可预测的性能。Together AI 在流量尖峰下保持可靠性能、高在线率和 token 流式输出，帮助 agent 循环即使在长上下文或持续决策任务中也保持响应。
- **成本效率：** Nemotron 3 Nano 每 token 仅 3B 激活参数，运行极其高效——而 Together AI 放大这一优势。工程师受益于更低的每 agent 步成本，可以大规模部署 agent、频繁跑推理循环——而没有高不可攀的推理成本。
- **灵活性：** Together AI 提供简单、开发者友好的 API——包括 OpenAI 兼容接口——让团队以极小代码改动采用 Nemotron 3 Nano。平台干净地集成进多 agent 框架、规划系统和工具使用工作流，部署无摩擦。
