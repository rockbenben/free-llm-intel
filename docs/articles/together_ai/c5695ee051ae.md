# 利用 IBM Cloud 和 NVIDIA 扩展我们的企业推理能力

- 作者麦凯
- 目录[40+ 选择用于生产的模型...40+ 选择用于生产的模型...40+ 选择用于生产的模型...](https://www.together.ai/blog/expanding-our-enterprise-inference-capacity-with-ibm-cloud-and-nvidia)

我们很高兴与大家分享，Together AI 正在与 IBM 和 NVIDIA 合作，从由 NVIDIA Spectrum-X 以太网网络支持的 IBM Cloud 上的 NVIDIA B300 GPU 大型集群开始，扩展企业级 AI 推理。它是 IBM Cloud 上同类中第一个专用的大规模推理集群，我们是第一个在其上运行的客户。

## 实际发生了什么

- **基础设施**：专用 NVIDIA B300 GPU 集群，专为推理而构建，在 IBM Cloud 上运行。
- **模型**：我们运营推理层，IBM 提供云，NVIDIA 提供芯片和网络。
- **轨迹**：随着代币需求呈抛物线增长，我们正在规划未来

## 为什么这很重要

我们创办 Together AI 是因为我们相信人工智能的未来不应该由少数封闭实验室拥有。这一赌注的回报速度甚至比我们预期的还要快：每月向超过一百万开发者提供数百万亿的代币，并且需求不断攀升。

企业和人工智能原生公司选择开放模型有两个简单的原因：他们的主权数据仍然属于他们自己，并且他们以封闭模型成本的一小部分获得前沿水平的性能。使用量越大，数学看起来就越好。

通过这次合作：

- NVIDIA 带来了专为高吞吐量推理而设计的芯片 — B300 GPU 和 Spectrum-X 以太网网络。
- IBM 为全球最大的企业带来了数十年运行的关键任务基础架构。
- 人工智能共同带来了推理平台——在生产中运行开放模型的最快、最有效的方式，并通过地球上一些最苛刻的人工智能工作负载进行了强化。

将这些放在一起，结果很简单：大规模的企业级推理——更多的生产级代币，以及企业所期望的可靠性、安全性和防护措施。

开源人工智能必须像任何封闭的人工智能一样，在任何地方、大规模、快速、可靠地运行。在过去的几年里，我们一直在确保它能够实现，而这次合作正是朝着这个目标迈出的一大步。
