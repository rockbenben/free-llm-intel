# AI，你的方式：引入 Poolside 平台

今天我们宣布 [  Poolside 平台](https://poolside.ai/enterprise)：一套生产级的系统，用来在你的安全边界之内运行 AI 智能体，落在你业务需要它运行的任何地方。Poolside 平台的目标是帮企业采用 AI，同时不在安全和治理上做任何妥协。

一个平台，用来管理要求最复杂的 AI。模型由你来选，而无论这个选择最终落在哪里，平台都会在那里接住你。

今天绝大多数 AI 系统都是租来的：基于第三方 API 访问，token 费用你无法控制。而一次 Poolside 部署交给你的是对模型权重的完全掌控，以及一份可预期的订阅方案，并且带有完整的可见性、可审计性和遥测。这是一套企业级方案，为那些运营着全球最重要业务的企业而造。

## 我们为谁打造

Poolside 平台是为某一类特定的团队打造的：这类团队里，批准使用的基础镜像（base image）是一项政策规定；网络架构确保没有任何单个节点同时拥有 GPU 访问权和对外出网能力；过去两年里，他们的 CISO 被迫为某家 AI 厂商放松管控，因为没有真正的替代选项。现在有了 Poolside。

在平台内部，智能体运行在开发者本来就在工作的地方——VS Code、Visual Studio、Zed、IntelliJ 或终端——并通过集中管理的 MCP server 接入团队真正在用的工具，例如 Slack、Jira、GitHub、Workday 和 Salesforce。每个会话都在容器化环境中运行，内置密钥管理和网络策略控制。每一个智能体动作，包括工具调用、文件编辑、推理步骤和决策，都会被记录成可检索的轨迹（trajectory）。凭证在静态存储时加密、在运行时注入，并会自动从输出中被脱敏。管理员集中定义边界，平台负责执行这些边界。

四种部署方式：在你自己的裸金属服务器上；通过 Dell 这类合作伙伴，在交付即用的硬件上以气隙（air-gapped）方式部署；在你已有的 VPC 里，跑在 AWS、Azure 或 Google Cloud 上。

还有真正和你一起把它交付上线的前沿部署研究工程师（Forward Deployed Research Engineers）。我们的 FDRE 与你的团队坐在一起，弄清楚在你具体的工作流中智能体在哪些环节创造的价值最大，在平台上与你一同构建，几周内就把第一个自动化工作流上线，然后继续加固和度量。

可说的远不止这些。请到我们的企业页面了解更多，那里对 Console、沙箱执行、审计留存以及各种部署形态讲得更深入。

让你的组织保持快速推进，同时不牺牲管控——对 AI 做出的每一个决策、每一个动作都拥有完全的可见性。

## 为什么是现在

快速演进的 AI 编程市场主要是靠云端 API 推进的，而这要求企业放松自身的安全保障与管控，或者为了避免落后而容忍危险的操作方式。企业值得更好的对待。AI 厂商不应该要求企业放弃已经确立已久的最佳实践，Poolside 不会这样要求。企业预计 AI 的可审计性与治理会在 2026 年成为主流优先事项 [[]](https://poolside.ai/blog/introducing-the-poolside-platform#83d77dd6884f)，把它们推到这个位置的并不是监管者，而是那些对在生产环境中运行 AI 负责的人。

## 这带来了什么

对于任何数据过于敏感、受监管过于严格、或过于战略而不能送出安全边界之外的团队，Poolside 平台让 AI 变得触手可及。

一家银行一直在为期三个月的安全豁免之下悄悄使用某款 AI 编程工具——有了 Poolside，你不再需要为了团队的效率而在安全上妥协。一家军工承包商的 AI 使用政策早已跑在了可用于执行这些政策的工具前面——这意味着你的管控手段终于能匹配你的要求。

客户已经用这个平台建出的东西让我们很兴奋。Hunted Labs——帮你保护软件供应链安全的公司——已经把 Poolside 纳入自己的全栈方案：

> Poolside 从根本上改变了为安全计算环境编写软件的方式。Poolside 的模型……改变了我们在 Hunted 内部为客户构建安全软件的方式”

这就是我们想更多讲述的故事。不是因为演示会很炫目（尽管其中一些确实会），而是因为在这些环境里运行的工作流，恰恰就是最重要的那一批。
