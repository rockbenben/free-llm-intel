# Laguna XS.2 和 Laguna M.1 简介

## 我们今天发布两个基础模型，并把两款产品投入 preview。

## 重要

2026-05-26

Laguna XS.2 和 Laguna M.1 现在以 256K 的上下文长度提供服务，并且在 SWE-bench Verified、SWE-Bench Pro 和 Terminal-Bench 2.0 上拿到了更高的分数。请阅读这篇[长上下文更新](https://poolside.ai/blog/long-context-update-laguna-xs-2-and-m-1)。

Laguna M.1 的[开放权重](https://huggingface.co/poolside/Laguna-M.1)现已放出。

Laguna XS 2.1 [现已上线](https://poolside.ai/blog/introducing-laguna-xs-2-1)。

今天我们向全世界发布两个基础模型，以及两款专注于 agentic coding 的产品。我们发布 Laguna M.1，一个 225B 的模型（激活 23B），它于去年完成预训练，现在将公开提供。

我们同时把我们的下一代模型 Laguna XS.2 以开放权重形式发布。总参数 33B，激活参数 3B。Apache 2.0。今天在 [  Hugging Face](https://huggingface.co/poolside/Laguna-XS.2) 上即可获取。

两款模型都可以在有限时间内通过 [  我们的 API](https://platform.poolside.ai/) 以及在 [  OpenRouter](https://openrouter.ai/provider/poolside) 免费使用。

为了在使用我们的模型时获得最好的体验，今天有两款产品进入 preview：

- pool，我们的终端 coding agent，以及
- Shimmer，一套云端开发体验，用来和我们的模型一起迭代 web 应用、API 和 CLI。

Laguna XS.2 是在我们的 Model Factory 里从零训练出来的，延续了由 Laguna M.1——我们迄今规模最大的模型——所开辟的工作。XS.2 在 5 周前开始预训练，而今天它已经完成全部后训练并发布。随着我们未来继续迭代 Laguna 家族并把它规模做大，预计我们会持续在开放的道路上拿出进展。

我们的期望，是与来自全世界的反馈和协作紧密合作，加速朝前沿推进。

Laguna M.1 就绝对能力而言仍然远远是我们最强的模型，虽然它比 XS.2 落后一代，我们依然很高兴把它交到开发者手里。

这些模型出自我们 Applied Research 组织里大约 60 个人的工作，覆盖基础设施、架构、数据、预训练和强化学习。我们很高兴与你分享它们。

### 这对我们意味着什么

Poolside 是一家专注于 agentic 模型的基础模型实验室。预训练、后训练、agent RL，全部都在我们的 Model Factory 之内。今天是我们第一次面向公众交付模型。我们期待拿到所有人的反馈，从而持续交付能力越来越强的模型。

### 为什么 XS.2 选择开放权重

我们想看到人们用 Laguna XS.2 造出什么。你拿到的是权重、一份 Apache 2.0 许可证，以及按你自己的方式运行它的自由。

西方的开放权重生态仍处于发展的早期。我们想改变这一点。而让我们的工作进步最快的方式，就是把它交到那些会去推动它的人手里。未来请期待我们在开放生态中带来更多。

## 开始使用

- **安装 [  pool](https://poolside.ai/get-started)，** 我们的终端 coding agent，用它获得与我们的模型搭配的最佳 agent 体验。两款模型都可以从我们自有的推理端点以及 OpenRouter 上使用。Laguna XS.2 可以在本地通过 [  Ollama](https://ollama.com/library/laguna-xs.2) 获取，并原生支持 MLX：运行 `ollama launch pool --model laguna-xs.2`
- **在 [  Shimmer](https://shimmer.run/) 里用两款模型构建**，那是一个即开即用的 Virtual Machine 沙箱，预装了 Poolside Agent。构建 web 应用、API、CLI 等等，来试用 Laguna M.1 和 Laguna XS.2。
- **使用我们的 [  API](https://platform.poolside.ai/) 或 [  OpenRouter](https://openrouter.ai/provider/poolside) 来与 Laguna M.1 & XS.2 交互。** 在 platform.poolside.ai 创建密钥，或者在 OpenRouter 上调用这些模型。限时免费。
- **从 [  Hugging Face](https://huggingface.co/poolside/Laguna-XS.2) 下载 Laguna XS.2 模型权重。** 权重今天已经上线，采用 Apache 2.0。

想要更完整的技术故事——合成数据与 automixing、我们在 Muon 优化器上的工作、异步 on-policy agent RL、我们的 Titan 训练代码库，以及我们在内部使用的 agent harness——请查看我们的技术博客文章 [  A Deeper Dive](https://poolside.ai/blog/laguna-a-deeper-dive)，并关注我们即将发布的技术报告。

如果你是在初创公司、大学或研究机构里用模型构建的小团队，我们乐意提高速率限制，或应你的请求分享 Laguna M.1 的权重。发邮件到 [  models@poolside.ai](mailto:models@poolside.ai)，或者在 [  X](https://x.com/poolsideai) 上给我们发私信。

脚注：Laguna M.1 和 Laguna XS.2 的全部基准测试都是使用 Laude Institute 的 Harbor Framework，配合我们的 [  agent harness](https://github.com/poolsideai/pool) 完成的，最多 500 步，并在 8 GB 内存/2 CPU 的沙箱执行环境中运行（Terminal-Bench 2.0 除外，见下文）。两个模型、以及所有基准测试都使用同一套采样参数：`temperature=0.7` 和 `top_k=20`。

一些基础任务镜像和 verifier 被打过补丁，用以修复任务设置中固有的基础设施可靠性问题，比如 verifier 所用的外部仓库里第三方依赖的限流。关于这些更新以及其他发现的更多细节，将在此后的某篇技术博文中说明。

- SWE-Bench Pro：3 次运行的 pass@1 平均值。
- SWE-bench Verified：4 次运行的 pass@1 平均值。
- SWE-bench Multilingual：7 次运行的 pass@1 平均值。
- Terminal-Bench 2.0：5 次运行的 pass@1 平均值。48GB 内存/32 CPU。

* 对每个基准上的所有对比模型，我们采用的都是公开引用到的最高分。所有情况下这些都是发布博文或同等材料里公布的官方分数，例外有两处：Gemma 4 31B IT 公布的最高分是 [  由 Qwen 团队报告的](https://qwen.ai/blog?id=qwen3.6-35b-a3b)；Claude Haiku 4.5 在 SWE-Bench Pro 和 Terminal-Bench 2.0 上的最高公布（verified）分数，则来自它们各自的官方排行榜。
