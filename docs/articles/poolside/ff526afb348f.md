# Introducing Laguna XS 2.1

今天我们发布 Laguna XS 2.1，它是我们的 Laguna XS.2 模型的升级版。

Laguna XS 2.1 是一个总参数 33B 的 Mixture-of-Experts 模型，每个 token 激活 3B 参数，为本机上的 agentic coding 和长周期工作而设计。它与 XS.2 的架构相同，但在 SWE-bench Multilingual 上有显著提升，并且在终端类任务上表现更强。

## XS 2.1 对比 XS.2

在一系列关键的 agentic coding 基准上，XS 2.1 相对 XS.2 都有改进。最大的提升出现在 SWE-bench Multilingual 上，上涨 5.4 个百分点至 63.1%。

## 更好的本地体验

XS 2.1 已经得到 vLLM、SGLang、NVIDIA TensorRT-LLM、HF transformers 和 Ollama 的支持，llama.cpp 支持也即将推出。我们同时放出三个量化 checkpoint——FP8、INT4 和 NVFP4——让 XS 2.1 可以部署在 VRAM 与算力预算更紧的配置里。我们还打算在不久之后提供量化的 GGUF checkpoint，作为我们原生 llama.cpp 支持的一部分。

我们还为每一个 XS 2.1 checkpoint 开放了 DFlash speculator 模型的权重。我们训练这些 speculator 时在开销与接受率之间做了平衡。在我们的测试中，这些 speculator 模型把实际达到的 tok/s 提升到原来的两倍，让 XS 2.1 的本地推理比以往更快。

我们以 256K 的上下文长度在 [  我们的 API](https://platform.poolside.ai/) 上以及通过 [  OpenRouter](https://openrouter.ai/provider/poolside) 提供服务。

## 一份更开放的许可证

我们采用 OpenMDW-1.1 授权 Laguna XS 2.1。

做出这一改变，是为了支持面向社区的开放模型分发。OpenMDW-1.1 是完全宽松的许可，并且是为模型及相关产物而设计的，它给开发者和组织提供了一个更一致的框架，用来使用、修改和部署开放模型。

我们很高兴支持 [  NVIDIA 和 Linux Foundation 在 OpenMDW 上选择的方向](https://www.linuxfoundation.org/press/linux-foundation-releases-openmdw-1.1-nvidia-adopts-openmdw-for-cosmos-isaac-gr00t-ising-and-nemotron-ai-model-families)，我们认为这是为开放模型发布减少许可摩擦的一个有用步骤。

## 开始使用

- **下载权重**，来自 Hugging Face 上的 [  Laguna XS 2.1 合集](https://huggingface.co/collections/poolside/laguna-xs-21)——BF16、FP8、NVFP4 和 INT4。
- **使用这个模型**，可在 [  OpenRouter](https://openrouter.ai/provider/poolside) 上（poolside/laguna-xs-2.1）或通过 [  我们的 API](https://platform.poolside.ai/)。免费端点和付费端点都可用，付费定价与 XS.2 保持一致，为每 1M 输入 / 输出 / 缓存读取 token 分别 $0.10 / $0.20 / $0.05。
- **在本地运行它**，可用 Ollama、llama.cpp、TRT-LLM、vLLM 或 SGLang，并加上 DFlash draft model 以获得更快的推理。
- **安装 [  pool](https://poolside.ai/get-started)**，我们的终端 coding agent，用它获得与该模型搭配的最佳 agent 体验。

我们想看到人们用 XS 2.1 造出什么，我们也想要你的反馈。把两个模型放在一起对比试用，告诉我们 2.1 哪里更好、哪里还不够好。加入我们的 [  Discord](https://discord.gg/PtTS6EwXG) 分享你的发现并与团队直接交流，或者通过 models@poolside.ai 或在 [  X](https://x.com/poolsideai) 上找到我们。

*Laguna XS.2 将在 1 周之后从我们的 API 上下线。XS.2 仍会作为 [  Baseten 的 Model Library](https://www.baseten.co/library/laguna-xs/) 的一部分保留，用于专属部署。*

**脚注**

Laguna XS 2.1 的全部基准测试都是使用 Laude Institute 的 Harbor Framework，配合我们的 [  agent harness](https://github.com/poolsideai/pool) 完成的，最多 500 步，并在沙箱执行环境中运行。Laguna XS 2.1 的所有基准测试都使用同一套采样参数：temperature=1.0、top_k=20 以及 top_p=1，开启 thinking 模式，上下文长度为 256K token。所有任务都在各自的沙箱里运行，使用 8 GB 内存/2 CPU，Terminal-Bench 2.0 除外，它使用 48 GB 内存/32 CPU。

一些基础任务镜像和 verifier 被打过补丁，用以修复任务设置中固有的基础设施可靠性问题，比如 verifier 所用的外部仓库里第三方依赖的限流。四个 agentic 基准全都用打过补丁的镜像运行。我们还对 Laguna XS 2.1 的评估运行事后跑了一次 reward-hack judge，在 judge 联合评审与人工评审之后没有发现明显的 reward hacking。

- SWE-bench Verified：每个任务 4 次尝试的 pass@1 平均值
- SWE-bench Multilingual：每个任务 4 次尝试的 pass@1 平均值
- SWE-Bench Pro：每个任务 2 次尝试的 pass@1 平均值
- Terminal-Bench 2.0：每个任务 5 次尝试的 pass@1 平均值；48 GB 内存/32 CPU

* 对每个基准上的所有对比模型，我们采用的都是公开引用到的最高分。所有情况下这些都是发布博文或同等材料里公布的官方分数，例外是 gpt-oss-120b 和 Claude Haiku 4.5：它们在 SWE-Bench Pro 和 Terminal-Bench 2.0 上的最高公布（verified）分数来自各自的官方排行榜。
