# 利用 Redpanda 实现代理企业

我们很高兴宣布与 Redpanda 达成战略合作伙伴关系。Redpanda 是面向企业的领先流式数据平台，我们要通过智能体（agent）与多智能体系统，在后果最重大的环境中交付垂直整合的 AI：政府、国防以及 Global 2000 企业。

Poolside 构建基础模型、智能体和编排系统，改变企业中工作完成的方式。我们与 Redpanda 的合作，让 300 多个企业数据源在所有环境中即时、安全地供我们的智能体调用。

我们正在朝向一个未来努力：企业能够真正大规模部署智能体，也就是代理企业（agentic enterprise）的基础设施。在你的防火墙之内，对你数据拥有经授权且可追溯的访问，是硬性要求。Poolside 为你的头等重要的工作而设计——那些既要求信任与可审计、又不能在交付的智能水平上打折扣的工作。

## 为什么说数据访问是缺失的那一块

随着智能体能力越来越强，它们需要安全、一致的数据访问，才能在现代企业高度复杂的环境中解决最难的问题。最聪明的模型—智能体系统，其效果只取决于它能拿到的上下文，其安全程度只取决于底层的那套授权框架。

这次合作把 Poolside 的单智能体与多智能体系统（智能）、我们基于策略的智能体编排（控制），以及 Redpanda 的流式数据网格与分布式日志（上下文）结合在了一起。

得到结果是一支可控、可观测的智能体队伍：智能体运行在由 Poolside 基础模型驱动的推理层里；一个灵活、高性能的查询引擎（而不是固定不变的工具集合）；清晰的行动策略；以及集中式编排——复杂度在数据面（data plane）里被统一管理。

对企业内数据访问的人和智能体实施最小权限控制，同时在性能与安全上不做任何妥协。企业可以放心地把 Poolside 和 Redpanda 带到自己最敏感的数据环境中，因为我们完整支持自带云（BYOC）、本地部署（on-premise）和气隙（air-gapped）环境。

## 我们如何协同工作

我们正在与 Redpanda 一起，在他们的数据平台之上构建对智能体友好的抽象层，并由 Redpanda 收购 Oxla 一事进一步加持。Redpanda Connect 负责从 300 多个来源做数据接入；Oxla 现在是 Redpanda 智能体数据平面（Agentic Data Plane，ADP）的一部分，它把强大的查询引擎直接放到智能体手边，让实时数据更容易被拉取、过滤并整理成上下文。

在我们的联合架构中，企业侧的消费方可以订阅、检视并批准数据访问事件——从而在所有智能体与关键专有数据的交互中，实现人在回路（human-in-the-loop）的控制和扎实的取证能力。

这次合作把我们的触达面扩展到企业中的各类知识工作，因为我们的智能体现几乎可以对任何能想到的数据源采取行动——同时具备完整的可观测性与完整的控制权。
