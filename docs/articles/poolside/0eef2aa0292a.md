# 宣布收购 Fern Labs

Poolside 把企业转变为 AI 原生的、agentic 的组织。我们亲身体验到，在大组织内部构建能驱动价值的 AI，光有一个能力过硬的基础模型是不够的：它需要能够在生产环境中运行的 agent 系统，也需要一种高投入的推进方式，以及那些知道如何在失败会带来真实后果的地方部署它们的团队。

正因如此，我们很高兴宣布 Poolside 收购了 Fern Labs，一家位于伦敦的 forward-deployed 研究工程公司，也是 Bridge 背后的团队——Bridge 是一个为高风险生产环境构建的 multi-agent 编排层。

有了 Fern Labs，Poolside 把自身的前沿模型与 Model Factory 基础设施，同驻场部署 agent 的能力结合了起来，让客户能够完全在自己的安全边界之内设计、验证并规模化真正的 agentic 系统。

## Fern Labs 打造了什么

Fern Labs 由 Ash Edwards、Alex Goddijn 和 Taylor Young 创立，此前他们曾在 Palantir 主导复杂的部署。Fern 的工作重心是长时间运行的 multi-agent 系统：它们能理解企业环境，并且可以被快速地调试、审计和改进。凭借他们 forward-deployed 的研究工程方法，这个团队直接嵌入客户一侧，共同设计工作流，在一个高风险用例上证明价值，再把学到的经验转化为产品。

前沿模型的 agentic 能力在持续快速提升，为企业许多最关键的流程提供了彻底全新的做法。因此，如何把 agents 规模化地跑起来、如何让 multi-agent 系统在真正重要的任务上保持稳定、如何有效地拆解问题——这些既是艺术也是科学。Fern Labs 围绕 forward-deployed 研究工程师建立了一种文化，这些工程师在前线既能做工程，也能做 R&D。

## Poolside 与 Fern Labs 将如何共同加速

Poolside 在企业边界之内以及受监管行业里部署前沿 AI 系统。借助 Fern Labs 的软件与专业能力，我们能够加快 agents 进入私有客户环境的部署，在具体上下文中观察它们遇到的问题，把这些问题转化为可被强化学习塑造的问题，并训练模型在这些特定用例上表现出色——所有这些都使用我们现有的基础设施。

要真正为客户交付价值，你需要三样东西：对客户问题域的清晰理解；对 agents 以及如何搭建 multi-agent 系统结构的深入了解；以及能够快速实验、安全部署的工具。

再加上 Poolside 业界领先的 GTM 团队，这次收购加速了我们在世界上后果最重的那些环境里扩展 agents 的进程。

## 我们的客户将如何受益

把 forward-deployed 研究工程师、Bridge 与我们的模型搭配起来，Poolside 现在可以直接嵌入客户组织，针对他们最有价值的问题构建并部署定制的高性能 agentic 系统。我们的合作模式如下：

- **落地**在一个高风险问题上。通常，这是一个核心运营工作流，例如更快地解决事故、在生产环节更早发现质量问题，或者自动化客户 onboarding。
- **构建**一个 agentic 系统，用 Bridge 搭配 Poolside 模型，可度量地缩短 time-to-resolution、降低成本、提升吞吐量或增加收入。这个系统嵌入组织内部，在关键决策点上保持 humans in the loop。
- **扩展**到相邻的用例；每一次部署都会让下一次更快，因为新的用例建立在此前已经配置好的环境、流程和 agent 构件之上。随着时间推移，你会得到一个可规模化的 agent 劳动力，它创造出复利式的价值。

## 建设面向 agentic 的企业

让 multi-agent 系统在高风险环境中可靠地运行，仍然是一个开放问题。要搞明白的东西很多：agents 之间协作的正确模式是什么？agents 如何处理不确定性，在无人监督地运行时又该如何从失败中恢复？我们如何让 agents 运行几个小时——很快就是几天——同时不牺牲可观测性与健壮性？

这一切都会发生在边缘地带，也就是 agents 撞上真实约束的地方，比如数据安全。破解它需要既能构建 AI 系统又理解该领域的工程师。它需要一款支持快速迭代、又不会破坏已经部署好的东西的产品。它还需要一个能根据这些 agents 学到的东西不断改进的模型。Poolside 现在三样都有了：负责编排的 Bridge，一支已经证明能在安全且高度监管的环境里部署的团队，以及一个随每一次部署都在进步的模型。

走到那一步需要规模化地部署并从这些部署中学习，从而弥合实验室研究与真实企业价值之间的差距。在 Poolside 增长的关键节点上能有 Fern Labs 加入团队，我们无比兴奋。
