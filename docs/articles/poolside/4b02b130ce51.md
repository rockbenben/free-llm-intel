# Poolside 通往 AGI 的旅程

Jason Warner

CEO 兼联合创始人

@ poolside

Eiso Kant

CTO 兼联合创始人

@ poolside

我们相信一个积极的技术未来，一个属于人类的丰裕未来；在那个未来里，AI 的进步会帮助我们推动科学、健康、住房、食物和教育的改善，让它们变得更好、更可负担、更容易获得。

要到那里，我们需要发展出足够先进的人工智能，而今天我们距离它还很远。我们相信，人类所有最伟大的技术突破都可以追溯到持续的迭代——想法彼此叠加、不断复利。我们相信，在有生之年，神经网络将能够学习任何一切东西，并达到人类技能水平乃至超越它。

我们相信通往 AGI 最快的路径，是掌握软件开发——那种长周期的、多步骤的、复杂任务的软件开发。在构建长周期任务的软件系统时，你需要对世界有一种理解和模型，要具备推理与规划的能力，更不用说还要能权衡各种备选方案。在我们看来，软件开发代表了构成人类智能的很多东西。它同时也是一种能力：随着我们持续改进它，它会对我们这个世界的进步产生巨大的、即时的正面影响。掌握软件可以泛化为能够思考、能够推理、能够规划，而这些共同构成了基础智能。所以，尽管我们并不是只做软件，但正是带着这份理解与洞察，才能解锁未来所有的 AI 能力。

我们想朝着这样一个未来努力：人工智能如此地融入我们的生活，以至于大多数具有经济价值的工作都能交由机器完成，从而让人拥有选择如何度过自己时间的自由。

## 为这段旅程排好前进的顺序

通往这个未来的旅程很漫长，而那些推动人类走向更丰裕的雄心目标，只有在 Poolside 能够长期存在的前提下才可能实现。正因如此，我们非常强烈地认为，面向这个未来排好先后顺序至关重要。

- ### 第一步 通过打造面向软件开发的最强 AI，来辅助开发者构建软件
- ### 第二步 让「AI 主导、人类辅助」的交互成为构建软件的下一层抽象，从而让任何人都能构建软件
- ### 第三步 把这些能力从软件泛化到所有其他领域

我们相信，随着时间推移，人与机器的交互会从人类主导、AI 辅助，变成 AI 主导、人类辅助。

我们在第一步里的第一个重大里程碑，是显著超越目前由通用模型保持的 state of the art。为此，我们专注于训练一个完全面向软件开发的大语言模型，并让它通过在数万个真实世界软件项目中完成数百万个任务来获得改进。

我们把这种方法称为 Reinforcement Learning from Code Execution Feedback，之后会分享大量关于它的内容。

我们有几条深信不疑、却并不固执坚持的信念（实证结果会告诉我们答案）：

- 要想突破当前的能力，你需要训练自己的基础模型
- 你没法靠微调走通这条路——主要能力是在训练基础模型时「涌现」出来的，并在微调阶段变得准确而有用的
- 规模很重要，更多的算力和数据能解决很大一类问题
- 并非所有 token 都是等价的——真正对我们的数据质量偏执到底，价值巨大
- 构建我们自己的训练技术栈，让我们能更快地迭代
- 合成数据生成——看起来有违直觉，但它确实有效，而且在代码上尤其有效。随着时间推移，我们猜测模型所训练的全部数据都会变成合成数据
- 是的，更大的模型更有可能展现出最强的能力，但一旦你有了它们，就能把它们蒸馏成在生产中有用小模型
- 要想让 LLM 在软件开发上进步，它们需要一个真实世界的环境，让它们能通过 self-play 来改进
