# 揭晓 Poolside 与 AWS 的第一方合作伙伴关系

今天，我们非常激动地宣布与 Amazon Web Services（AWS）建立一段具有变革意义的合作伙伴关系，Poolside 由此成为 AWS 的第一方产品。这一战略关系意味着 Poolside 的产品与模型现在可以直接向 AWS 签约获取，这是我们发展轨迹上的一个重要里程碑。

一切始于差不多一年前——那时我们正想拿到 1,000 块 GPU，并找到一个能与我们一起扩规模的伙伴。我们的关系从今年早些时候的第一个训练集群，发展到现在这个 10,000 块 GPU 的集群；快进到今天，我们与 AWS 正在共同执行一份独特而有雄心的 go-to-market 计划，它从根本上加速着我们的未来。

对于这一切意味着什么——无论是对我们的客户还是对我们自己——我们再兴奋不过了。我们在 AWS 身上找到了一支和我们一样深切关心客户、并且不懈执行的团队。

## 落到实践中……

第一方的 AWS 体验让企业能够像我们是一个原生 AWS 服务那样获取我们的产品和模型。这让企业无需额外的签约就能开始使用 Poolside：只需接受 AWS 的标准条款与条件，只需消耗他们已有的 AWS 消费承诺，就能获得他们对任何 AWS 服务所期待的同等级别的企业支持、安全与治理。借助 EC2 的可获得性以及无缝的 Amazon Bedrock 集成，企业可以立刻开始部署。

## 顺理成章的下一步

Poolside 从第一天起就是为企业而建的，因为我们能够部署在客户那一侧，也因为我们专注于把治理要求和数据隐私需求放在优先位置。在 Poolside，我们不会用客户数据来训练我们的基础模型——而我们能做到这一点，靠的是我们通过 Reinforcement Learning From Code Execution Feedback（也就是 RLCEF）来改进模型的方法。它让我们得以突破可用代码与推理数据的限制 [[]](https://poolside.ai/blog/unveiling-our-partnership-with-aws#6969f1982507)，大规模生成合成训练数据。这让客户同时得到两边的好处：开发者手中有精密的模型，同时又确信自己最重要的资产——他们的数据——保持私密。

我们与 AWS 的合作伙伴关系以及紧密集成交付的正是这一点——它让客户能够在自己的 AWS Virtual Private Cloud 之内运行 Poolside，并借助 AWS 企业级的安全基础设施，把对自身 IP 的掌控留在手里，把 Poolside 部署在他们数据所在的地方。

正如人们所说，这是一件大事。Poolside 基础模型的设计目标，是用客户的代码库和数据做微调，产出一个专有的、为客户定制的、面向软件工程的模型。把 Poolside 模型部署在数据存储的地方、部署在一家公司的防火墙之内、部署在这个世界上最安全的云上，并且不向我们回传任何数据——这正是我们核心原则的体现。我们相信，企业不应该为了构建自己的智能层而抵押未来，也不应该为此牺牲自己的安全或治理标准。

在我们持续为客户带来更多选择的过程中，我们很高兴能用 AWS Trainium 芯片为我们的 malibu 和 point 基础模型提供推理算力。Trainium 为客户带来最优的价格性能，并提升可用性。从今天起，Poolside 基础模型既可以由 Trainium 驱动，也可以由 NVIDIA 芯片驱动。[[]](https://poolside.ai/blog/unveiling-our-partnership-with-aws#0625bf4e9c1f)

尽管 Poolside on AWS 带来的体验无可比拟，我们依然致力于部署上的灵活性。我们继续支持 air-gapped 环境、on-prem 部署以及其他云环境，以满足企业多样化的需求。

## 加速我们的愿景

Poolside 的存在，是为了给全世界带来[  无处不在的软件智能](https://poolside.ai/blog/announcing-our-500-million-fundraise-to-make-progress-towards-agi)。我们相信每个人都应该有能力构建和创造各种类型的软件，并打算在未来几年里把这件事变成现实：先为全球的开发者和企业提供软件辅助与 fullstack 解决方案。这段合作关系通过让我们在世界领先的云平台上变得可被获取，极大地加速了这个愿景。从我们的基础模型到微调过的企业解决方案，一切现在都可以直接通过 AWS 获得，背后是企业所信赖的基础设施与支持。
