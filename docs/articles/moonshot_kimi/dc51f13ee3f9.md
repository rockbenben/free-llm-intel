## 特工群，高架

**横向扩展，而不仅仅是向上扩展。** Agent Swarm 将任务动态分解为异构子任务，由自创建的域专用代理同时执行。

基于 K2.5 Agent Swarm 研究预览，[Kimi K2.6 Agent Swarm](https://www.kimi.com/en/agent-swarm) 展示了 Agent Swarm 体验的**质的飞跃**。它无缝地协调异构代理以结合互补的技能：广泛的搜索与深入的研究、大规模文档分析与长篇写作相融合，以及并行执行的多格式内容生成。这种组合智能使群体能够在一次自主运行中提供端到端的输出——涵盖文档、网站、幻灯片和电子表格。

该架构可水平扩展至 **300 个子代理同时执行 4,000 个协调步骤**，这是对 K2.5 的 100 个子代理和 1,500 个步骤的大幅扩展。这种大规模并行化从根本上减少了端到端延迟，同时显着提高了输出质量并扩展了代理群的操作边界。

它还可以将 PDF、电子表格、幻灯片和 Word 文档等任何高质量文件转化为**技能**。 Kimi K2.6 捕获并保留文档的结构和风格 DNA，使您能够在未来的任务中重现相同的质量和格式。

## 自带代理

基于 Kimi K2.6 强大的编排功能，Kimi K2.6 将您的主动代理扩展到 **Claw Groups** 作为研究预览 - Agent Swarm 架构的新实例。

Claw Groups 拥抱一个开放的、异构的生态系统：多个代理和人类作为真正的合作者运作。用户可以从任何设备上加入代理，运行任何模型，每个代理都带有自己的专用工具包、技能和持久内存上下文。无论是部署在本地笔记本电脑、移动设备还是云实例上，这些不同的代理都可以无缝集成到共享操作空间中。

在这个群体的中心，Kimi K2.6 充当自适应协调员。它根据座席的特定技能概况和可用工具动态地将任务与座席匹配，从而优化能力契合度。当代理遇到故障或停滞时，协调器会检测到中断，自动重新分配任务或重新生成子任务，并主动管理可交付成果的整个生命周期 - 从启动到验证再到完成。

我们还要感谢 Claw Groups 中由 K2.6 支持的代理——我们一直在通过在实践中改进人工代理工作流程来测试我们自己的代理营销团队。使用 Claw Groups，我们与演示制作者、基准制作者、社交媒体代理和视频制作者等专业代理一起开展端到端内容制作和发布活动。 K2.6 协调流程，使代理能够共享中间结果并将想法转化为一致的、完全打包的可交付成果。

我们正在超越简单地向人工智能提出问题或为人工智能分配任务，并进入人类和人工智能作为真正合作伙伴进行协作的阶段——结合优势共同解决问题。 Claw Groups 标志着我们为实现“我的代理”、“您的代理”和“我们的团队”之间的界限无缝融入协作系统而做出的最新努力。
