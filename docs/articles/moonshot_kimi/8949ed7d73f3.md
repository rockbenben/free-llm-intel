- `kimi-k2.5` 与 `moonshot-v1` 全系列模型（含 `-vision-preview`、`moonshot-v1-auto`）在国内外全平台下线，调用将返回 404 错误，请迁移至 [Kimi K3](https://platform.kimi.com/docs/guide/kimi-k3-quickstart)
- Files API 更新：新生成的文件 ID 统一添加 `file_` 前缀；提升文档解析效果，优化表格、公式等复杂内容的解析；不再对图片进行 OCR 文本提取，图片理解请使用 `purpose=image` 上传图片（详见 [使用视觉模型](https://platform.kimi.com/docs/guide/use-kimi-vision-model)）；上传的文件与已有文件同名时，服务端自动为新文件重命名
