# Kimi K2.5：视觉代理智能

今天，我们推出 Kimi K2.5，迄今为止最强大的开源模型。

Kimi K2.5 以 Kimi K2 为基础，对大约 15T 混合视觉和文本标记进行持续预训练。 K2.5 作为原生多模式模型构建，提供最先进的**编码和视觉**功能以及自我导向的**代理群**范例。

对于复杂的任务，Kimi K2.5 可以自我指导具有多达 100 个子代理的**代理群**，在多达 **1,500** **工具调用**中执行并行工作流程。与单代理设置相比，执行时间最多可减少 **4.5 倍**。代理群由 Kimi K2.5 自动创建和编排，无需任何预定义的子代理或工作流程。

Kimi K2.5 可通过 **[Kimi.com](https://www.kimi.com/en)、Kimi 应用程序、[API](https://platform.kimi.com/) 和 [Kimi 代码](https://www.kimi.com/code/en)** 获取。 Kimi.com 和 Kimi App 现在支持 4 种模式：K2.5 Instant、K2.5 Thinking、K2.5 Agent 和 K2.5 Agent Swarm（Beta）。 Agent Swarm 目前在 Kimi.com 上处于测试阶段，为高级付费用户提供免费积分。

## 2. 特工群

**横向扩展，而不仅仅是向上。**我们发布了 **[K2.5 Agent Swarm](https://www.kimi.com/en/agent-swarm)** 作为研究预览，标志着从单代理扩展到自我引导、协调的集群式执行的转变。

经过并行智能体强化学习 (PARL) 的训练，K2.5 学会自我指导由最多 **100 个子智能体**组成的**智能体群**，跨**多达 1,500 个协调步骤**执行并行工作流程，无需预定义角色或手工制作的工作流程。

PARL 使用***可训练的协调器代理***将任务分解为可并行的子任务，每个子任务由动态实例化的***冻结子代理***执行。与顺序代理执行相比，同时运行这些子任务可显着减少端到端延迟。

由于独立运行的子代理的延迟、稀疏和非平稳反馈，训练可靠的并行协调器具有挑战性。常见的故障模式是**串行崩溃**，其中编排器默认为单代理执行，尽管具有并行能力。为了解决这个问题，PARL 采用“分阶段奖励塑造”，鼓励训练早期的并行性，并逐渐将重点转向任务成功。

我们将奖励定义为

$r_{\mathrm{PARL}}(x, y) = \lambda_1 \cdot \mkern-26mu \underbrace{r_{\text{并行}}}_{\text{实例化奖励}} \mkern-9mu + \mkern18mu\lambda_2 \cdot \mkern-32mu\underbrace{r_{\text{完成}}}_{\text{子代理完成率}} +
\underbrace{r_{\text{perf}}(x, y)}_{\text{任务级结果}}
\, .$

绩效奖励 $r_{\text{perf}}$ 评估给定任务 $x$ 的解决方案 $y$ 的总体成功和质量。两个辅助奖励增强了这一点，每个奖励都解决了学习并行编排方面的独特挑战。引入奖励 $r_{\text{parallel}}$ 是为了减轻*串行崩溃*——协调器默认为单代理执行的局部最优。通过激励子代理实例化，该术语鼓励对并发调度空间的探索。 $r_{\text{finish}}$ 奖励侧重于成功完成分配的子任务。它用于防止“虚假并行性”，这是一种奖励黑客行为，在这种行为中，协调器通过在没有有意义的任务分解的情况下产生许多子代理来显着增加并行指标。通过奖励完成的子任务，$r_{\text{finish}}$ 增强了可行性并指导策略进行有效且有效的分解。超参数 $\lambda_1$ 和 $\lambda_2$ 在训练过程中退火为零。

为了进一步迫使并行策略出现，我们引入了一个计算瓶颈，这使得顺序执行变得不切实际。我们不计算总步数，而是使用 **关键步骤** 来评估性能，这是一种受并行计算中关键路径启发的面向延迟的指标：

$\text{CriticalSteps} = \sum_{t=1}^{T} \left( S_{\text{main}}^{(t)} + \max_{i} S_{\text{sub},i}^{(t)} \right)$

$S_{\text{main}}^{(t)}$捕获编排开销，而$\max_{i} S_{\text{sub},i}^{(t)}$反映每个阶段最慢的子代理。在这个指标下，产生更多的子任务只有在缩短关键路径的情况下才有帮助。

![Kimi K2.5 Agent Swarm 架构图，显示 Orchestrator 动态创建任务并将任务分配给专用子代理以并行执行](https://statics.kimi.ai/blogs/k2-5/orchestrator-1.png)

## 3. 办公效率

Kimi K2.5 将代理智能带入**现实世界的知识工作中。**

**[K2.5 Agent](https://www.kimi.com/en)** 可以**端到端处理高密度、大规模的办公室工作。** 它对大量、高密度的输入进行推理，协调多步骤工具的使用，并直接通过对话提供专家级的输出：文档、电子表格、PDF 和幻灯片。

我们专注于现实世界的专业任务，设计了**两个内部专家生产力基准**。 **AI Office 基准**评估端到端 Office 输出质量，而**常规** **代理基准** 根据人类专家的表现衡量多步骤、生产级工作流程。在这两个基准测试中，**K2.5 显示** **比 K2 Thinking** 提高了 59.3% 和 24.3%，反映了在实际任务中更强的端到端性能。
