# Kimi K3.1 Pro 简介

我们推出 **Kimi K3.1 Pro**。它是全新 K3.1 系列的首款模型，也是我们迄今最强的 3T 级开放权重模型，上下文窗口达 100 万 token。它在编程、3D 创作、金融研究以及其他 agentic 能力上都有大幅提升。

我们还发布了 **Kimi K3.1 Pro Highspeed**，速度是 K3.1 Pro 的 2-3 倍，交互更灵敏。

Kimi K3.1 Pro 与 Kimi K3.1 Pro Highspeed 即日起可在 [Kimi.com](https://www.kimi.com/en)、[Kimi Work](https://www.kimi.com/en/products/kimi-work)、[Kimi Code](https://www.kimi.com/code/en) 以及 [Kimi API](https://platform.kimi.com/) 使用。完整模型权重将于 11 月 4 日前发布。

## 推进开放智能的边界

Kimi K3.1 Pro 是 Kimi K3 的后训练版本，后训练算力大幅增加。为了让 RL 在**数百个下游领域**上大规模联合进行，我们优化了整条技术栈的每一层——RL 框架、长上下文推理、训练效率、sandbox 基础设施、rollout 调度，以及一个用于环境质量检查的共享平台——使每一份 RL 算力都能带来稳定、可预期的回报。也正因如此，K3.1 Pro 在各个领域都取得了一致提升。

在编程、agentic 与知识类基准上，K3.1 Pro 达到或接近最强闭源模型的水平。**Terminal-Bench 4.0** 通过严格的任务专属测试，在贴近真实、资源受限的终端任务上考察编程 agent；在该基准上，**K3.1 Pro 得分为 65.7%，领先 GPT-6 Astra（58.2%），仅略微落后于 Claude Opus 5.5（66.4%）**。在 **Kimi Code Bench 3.0 Long-horizon** 上，K3.1 Pro 得分为 **61.2%**，高于 K3 的 **55.95%**；这一内部基准考察编程 agent 在多个工程领域中的多步执行、工具调用与端到端问题求解能力。

## 网络安全

随着 K3.1 Pro 能力增强，我们相应投入了更大比例的精力，去理解网络攻击能力从何而来，以及其中有多少是我们能控制的。因此，我们分析并评测了 K3.1 Pro 的漏洞研究能力，并在训练中施加定向控制，在保留通用可用性的同时降低潜在的滥用风险。

**识别并移除与网络攻击相关的数据。** 在开发过程中，我们观察到随着后训练规模扩大，漏洞研究的表现稳步提升。追溯这一趋势的来源后我们发现，与网络攻击相关的内容混在通用中训练语料中，RL 环境组合里也存在相关任务——这是在大规模通用数据上训练的自然副产品。在内部模型的初步实验中我们发现，如果中训练阶段和 RL 阶段都不移除数据，下游的网络攻击能力会显著增强。这些发现给了我们一个具体可用的控制抓手。在 K3.1 Pro 的开放权重版本中，我们从两个训练阶段都识别并移除了这类数据，同时保留模型可用性所需的通用编程任务。我们会继续在每一个训练阶段施加适当的控制，网络攻击相关数据的识别与限制只是其中一例。

**评测与结果。** 完成数据清洗后，我们在 xdev-bench-hard 上评测 K3.1 Pro。这是我们的内部基准，题目由专家策划、基于源码，覆盖漏洞发现与利用，并针对当前能力水平做了校准，以便产生有意义的区分度。多数任务忠实复现了 Linux 内核、Node.js、JavaScriptCore、Exim、VirGL 等软件近期披露的漏洞，且已开启缓解措施。每道题提供存在漏洞的源代码、一段简短的 bug 提示以及对应的二进制文件；agent 需要写出 exploit，在独立 sandbox 中实现任意代码执行，并取回一个秘密字符串以完成自动校验。我们在一部分随机运行上报告 pass@3，不设硬性超时，也不限制输出 token。

![内部 xdev-bench-hard（pass@3）成绩：GPT-5.6 Sol（第三方评测）解出 100 题，未做网络风险削减的 Kimi 模型为 90.5，DeepSeek-V4.1-Flash 为 85.7，Kimi K3.1 Pro 为 81.0，GLM-5.3 为 57.1，Kimi K3 为 33.3；同时给出各模型的平均成功率与每条成功轨迹的平均 token 数](https://statics.kimi.ai/kimi-blogs/kimi-k3-1/20261023/xdev-bench-hard-results.webp)![](https://statics.kimi.ai/kimi-blogs/kimi-k3-1/20261023/xdev-bench-hard-results.webp)

在 xdev-bench-hard 上，未采取这些风险削减措施的 checkpoint——即中训练阶段不移除网络攻击相关数据、也不过滤 RL 环境中的相关任务——在 pass@3 下解出 90.5% 的题目；最终的 K3.1 Pro 为 81.0%。这一对比表明，相对于同一条训练流水线原本会产出的结果，数据移除确实显著削弱了网络攻击能力。与此同时，K3.1 Pro 相比前代仍有大幅提升，说明更强的通用编程与长程调试能力在定向数据移除之后依然能泛化到网络任务上。K3.1 Pro 的网络攻击能力仍落后于已公开至少三个月的前沿闭源模型。我们会持续迭代内部基准，让评测在模型能力不断进步的过程中始终保持参考价值。

**开放权重原则。** 这些评测构成了我们开放权重发布决策的依据。第一，我们不希望发布的开放权重把网络攻击能力的绝对前沿再往前推。按设计，K3.1 Pro 的攻击性网络能力低于我们流水线所能达到的水平，也仍落后于前沿闭源模型。第二，我们打算逐步提高开放权重中可获得的网络能力。我们相信，以非歧视性的方式提供 K3.1 Pro，会让需要把双用途能力用于防御的人受益。当一个有能力的模型开放、并运行在用户自己掌控的基础设施上时，会有更多团队有能力审计自己维护的代码——包括那些很少得到专门安全审查的遗留系统。我们相信，让这种能力逐步扩散、而不是集中在少数闭源系统里，最终会让所有软件更安全。

### Agentic 基准

- BioMysteryBench 数据集取自[官方 v11 版本](https://huggingface.co/datasets/Anthropic/BioMysteryBench-full/commit/b5a889c)，以 Kimi K3 作为 judge 模型。我们用 Kimi Code 评测 Kimi K3.1 Pro，用 Claude Code 评测 GLM-5.3 与 DeepSeek-V4.1-Flash-1017，用 Codex 评测 GPT-6 Astra。Claude 系列模型的成绩直接取自其官方 system card。
- 我们的 Agents' Last Exam 数据集取自[官方 v1.1 版本](https://github.com/rdi-berkeley/agents-last-exam)，共 122 个任务，其中 86 个为 CLI 任务，环境镜像与 Hugging Face 官方发布保持一致。对于绕过任务既定要求的运行，我们额外记为零分，例如在网上检索答案，而不在 Wireshark 中完成所要求的分析。DeepSeek 与 Kimi 分别使用 Claude Code 和 Kimi Code 评测。其余结果取自该基准官网。
- OfficeQA Pro、OfficeQA Pro v2。GPT-6 Astra 使用 Codex 评测，其余模型均使用 Claude Code 评测。每道题把整个 PDF 语料交给 agent，所有 PDF 都渲染为图像，不提供任何机器可读文本。我们在某些外部模型的轨迹中发现其在网上检索参考答案的情况；因此这些任务被记为零分。
- Frontier Finance 使用官方 finance agent v2 harness 评测。
- HANDBOOK.md 使用基于 OpenHands 构建的官方 harness 评测，评测任务取自该基准早期开源的 v1 版本。
- Harvey Legal Agent 在一个包含 1,251 个任务的公开数据集上评测，使用 Artificial Analysis 的 Stirrup harness，成绩以全通过率（即通过所有评分细则的任务占比）报告。
- OSWorld V2.1 在官方 OSWorld v2 仓库中使用 Kimi Agent harness 评测；GPT-6 Astra 的成绩取自 Muse Wonder 的技术报告。
- DECK-Arena 在真实查询上评测演示文稿生成，Design Bench 则通过直接提示与参考图 few-shot 提示评测平面设计；两者都在集成搜索与图像生成的 harness 中，让模型分别通过 python-pptx、pptxjs 和 Kimi 自研 DSL 生成，并使用在 10,000+ 人工判断上校准的自动评分器。
- MCP Atlas。所有模型都在 500 题的公开子集上评测，限制 100 轮，以 Gemini 3.1 Pro 作为 judge。
- BrowseComp。我们采用 Claude 模型卡中使用的上下文压缩策略，在 200K token 时触发。最多允许 500 步；若在任务完成前触及该上限，我们强制 agent 给出答案，再据此评判。所有 BrowseComp 运行均在 temperature=1.0、top-p=1.0 下进行。
- GDPval-AA v2.1、AA-Briefcase v1.1 与 AutomationBench-AA 的成绩引自 [https://artificialanalysis.ai/](https://artificialanalysis.ai/)，Apex Agents 的成绩引自 [https://www.mercor.com/apex/apex-agents-leaderboard/](https://www.mercor.com/apex/apex-agents-leaderboard/)
- GDP.pdf w/ python、ZeroBench w/ python 与 ChartoGraphy w/ python 取五次运行的平均值。其他多模态基准（w/ python）取四次运行的平均值。关于 GDP.pdf w/ python：每个原始 PDF 文件都会送入 sandbox，模型可用 IPython 工具处理。最终回答由 Gemini-3.5-Flash（中等 reasoning effort）按官方评判 prompt 逐条对照评分细则打分。我们报告任务宏观平均的细则通过率：对每个任务，先将其五次独立运行中通过的细则占比取平均，再在所有任务间对这些任务级分数等权平均。

### 推理与知识、多模态基准

- GDP.pdf。每个 PDF 以页面图像形式提供，最长边缩放至 1,152 像素，并按页序与 Docling 抽取的文本交替拼接。回答由 Gemini-3.5-Flash Medium 按官方评判 prompt 逐条对照评分细则打分。我们报告完整评分回答中的严格通过率。
- HLE 与 HLE-Diamond 考察通用知识与推理能力。我们在完整评测集上报告准确率，HLE 为 2,500 题，HLE-Diamond 为 1,000 题。对于带星号（*）的模型，准确率仅在纯文本题目子集上报告。
- GDP.pdf、ZeroBench 与 ChartoGraphy 取五次运行的平均值。其他多模态基准取四次运行的平均值。GLM-5.3 Max 与 DeepSeek-V4.1-Flash-1017 Max 的 GDP.pdf 成绩引自 [https://artificialanalysis.ai/](https://artificialanalysis.ai/)。
- MMMU-Pro 按官方协议评测，保留原始输入顺序，并把图像置于文本输入之前。
- Kimi Hallucination Benchmark 在一组来自实际工作场景、经过匿名化处理的高难度 prompt 上评测事实准确度。我们报告由事实核查 agent 判定的 claim 级幻觉率。

### 网络安全基准

- ExploitBench。Kimi K3.1 Pro 在 300 轮预算下使用官方 ExploitBench harness 评测。我们报告 pass@5 最大能力分：每个环境取 5 个 seed 中最好的一次运行，按达成的 capability flag 数（共 16 项）计分，实现任意代码执行即视为达成全部 16 项能力。GPT-6 Astra 的成绩取自 [https://openai.com/index/gpt-6-astra/](https://openai.com/index/gpt-6-astra/)；Claude Opus 5.5 与 Claude Mythos 5.1 的成绩取自 [https://www.anthropic.com/claude-opus-5-5-system-card](https://www.anthropic.com/claude-opus-5-5-system-card)；GLM-5.3 的成绩取自 [https://z.ai/blog/glm-5.3](https://z.ai/blog/glm-5.3)。
- ExploitGym。Kimi K3.1 Pro 在每个任务 6 小时 wall-clock 预算下使用 KimiCode harness 评测。GPT-6 Astra 的成绩取自 [https://openai.com/index/gpt-6-astra/](https://openai.com/index/gpt-6-astra/)；Claude Opus 5.5 与 Claude Mythos 5.1 在 6 小时预算下的成绩取自 [https://www.anthropic.com/claude-opus-5-5-system-card](https://www.anthropic.com/claude-opus-5-5-system-card)；GLM-5.3 的成绩取自 [https://z.ai/blog/glm-5.3](https://z.ai/blog/glm-5.3)。
- xdev-Bench-hard：Kimi K3.1 Pro 使用 KimiCode harness 评测。GLM-5.3 与 DeepSeek-V4.1-Flash-1017 使用 Claude Code harness 评测。
