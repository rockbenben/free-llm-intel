## 它在专业智力指数上的表现如何

我们在 Fireworks [专业智能指数](https://fireworks.ai/specialized-intelligence-index/) (SII) 上评估了 K3.1 Pro：由 Sierra、Harvey 和 Rogo 等公司构建的基准，以选择他们在生产中运行的模型。

K3.1 Pro 在其中五项基准测试中处于质量与成本前沿：没有一款型号在不增加成本的情况下得分更高。

- **客户支持（[Sierra 的 τ³-Banking](https://fireworks.ai/specialized-intelligence-index/benchmarks/customer-support/tau3-banking)）：** 代理使用数据库工具解决银行请求，同时遵循银行政策。 K3.1 Pro 以 64.7% 在 19 款产品中排名第一，领先 Claude Opus 5.5 8.7 个百分点。

- **事件响应（[Traversal 的 ORCA](https://fireworks.ai/specialized-intelligence-index/benchmarks/site-reliability-engineering/traversal-orca-benchmark)）：** 从跟踪、日志和指标中查找生产事件的根本原因。 K3.1 Pro 得分为 32.9%，在 13 个模型中排名第三，是顶级开放模型，其每项任务的成本不到其前面任一模型的五分之一。
- **企业法律（[Epiq 的 CorporateBench](https://fireworks.ai/specialized-intelligence-index/benchmarks/legal/epiq-laer-corporatebench)）：** K3.1 Pro 得分 76.9，12 项中的第四名，也是顶级开放型号。

## Kimi K3.1 Pro 在 Moonshot 的评测中得分如何

Moonshot 在最大推理努力下报告以下结果：

- **长视野编码：** SWE Marathon v1.1 为 51.7，领先于 Claude Opus 5.5 (46.3)、Claude Fable 5.1 (45.6) 和 GPT-6 Astra (42.5)。
- **代理研究：** Humanity’s Last Exam with tools 获得 70.0 分，BrowseComp 获得 92.1 分，在 Moonshot 的比较中获得最高分。
- **办公室工作：** OfficeQA Pro v2 上为 64.4，Artificial Analysis’ Automation Bench 上为 73.3，均领先于 Claude Opus 5.5（62.2 和 69.5）。

Moonshot 使用包括 Claude Code 在内的工具进行编码来评估 K3.1 Pro，并从已发布的报告和排行榜中获取大多数竞争对手的分数。
