Moonshot AI 的 [Kimi K3.1 Pro](https://fireworks.ai/models/fireworks/kimi-k3p1-pro) 在 Fireworks 首发上线。你可以在 serverless 上按 token 计费使用，也可以用专属部署预留容量。

## K3.1 Pro 有哪些新变化

在我们 [Specialized Intelligence Index](https://fireworks.ai/specialized-intelligence-index/) 的评测中，K3.1 Pro 是 Legacy Bench 与 CorporateBench 上速度最快的模型，在 ORCA 上第二快。Moonshot 在 K3 的基础上后训练出 K3.1 Pro，并把 K3 的全注意力层换成稀疏注意力，让长上下文的服务效率更高。主要规格：

## 它在 Specialized Intelligence Index 上的表现

我们在 Fireworks 的 [Specialized Intelligence Index](https://fireworks.ai/specialized-intelligence-index/)（SII）上评测了 K3.1 Pro：这是一组由 Sierra、Harvey、Rogo 等公司构建的基准，用来挑选它们在生产环境中运行的模型。

在其中五项基准上，K3.1 Pro 处在质量-成本前沿：没有哪个模型能在不增加成本的前提下拿到更高分数。

![Kimi K3.1 Pro 在 Sierra 的 τ³-Banking 上的得分与每次试验成本](https://fireworks.ai/_next/image?url=https%3A%2F%2Fcdn.sanity.io%2Fimages%2Fpv37i0yn%2Fhorizon%2F93ec1e20bba65b3443d63b82dde4edbd420b1e08-3600x2325.png%3Fauto%3Dformat&w=3840&q=75)

图 1：Kimi K3.1 Pro 在 Sierra 的 τ³-Banking 上的得分与每次试验成本，来自 Fireworks 的 Specialized Intelligence Index。

- **客户支持（[Sierra 的 τ³-Banking](https://fireworks.ai/specialized-intelligence-index/benchmarks/customer-support/tau3-banking)）：** agent 使用数据库工具处理银行业务请求，同时遵守银行政策。K3.1 Pro 以 64.7% 在 19 个模型中排名第一，领先 Claude Opus 5.5 达 8.7 个百分点。
- **遗留代码（[Factory 的 Legacy Bench](https://fireworks.ai/specialized-intelligence-index/benchmarks/code-generation/legacy-bench)）：** 维护 COBOL、Fortran 与 Java 7 代码库。K3.1 Pro 得分 61.0%，在 14 个模型中排名第三，是得分最高的开放模型。
- **法律（[Harvey 的 LAB](https://fireworks.ai/specialized-intelligence-index/benchmarks/legal/lab)）：** 通常由一年级律师处理的工作。K3.1 Pro 以 15.4% 在 13 个模型中排名第二，落后于 Grok 4.6。
- **金融（[Rogo 的 Big Finance Benchmark](https://fireworks.ai/specialized-intelligence-index/benchmarks/finance/big-finance-benchmark)）：** 928 道取自金融研究工作流的问题。K3.1 Pro 以 48.2% 与 Claude Opus 5.5 打平。
- **事件响应（[Traversal 的 ORCA](https://fireworks.ai/specialized-intelligence-index/benchmarks/site-reliability-engineering/traversal-orca-benchmark)）：** 从 trace、日志与指标中定位生产事故的根因。K3.1 Pro 得分 32.9%，在 13 个模型中排名第三、为最佳开放模型，单任务成本不到排在它前面的两个模型的五分之一。
- **企业法务（[Epiq 的 CorporateBench](https://fireworks.ai/specialized-intelligence-index/benchmarks/legal/epiq-laer-corporatebench)）：** K3.1 Pro 得分 76.9，在 12 个模型中排名第四、为最佳开放模型。

## Kimi K3.1 Pro 在 Moonshot 评测中的成绩

Moonshot 在最大推理强度下报告了以下结果：

- **长周期编码：** SWE Marathon v1.1 上 51.7，领先 Claude Opus 5.5（46.3）、Claude Fable 5.1（45.6）与 GPT-6 Astra（42.5）。
- **Agentic 研究：** 使用工具时在 Humanity’s Last Exam 上 70.0、在 BrowseComp 上 92.1，两项都是 Moonshot 对比中的最高分。
- **办公任务：** OfficeQA Pro v2 上 64.4、Artificial Analysis 的 Automation Bench 上 73.3，两项均领先 Claude Opus 5.5（62.2 与 69.5）。

Moonshot 评测 K3.1 Pro 时使用了包括 Claude Code 在内的编码 harness，竞品分数大多取自公开报告与排行榜。
