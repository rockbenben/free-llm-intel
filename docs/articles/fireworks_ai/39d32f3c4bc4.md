[Hy4 Flash](https://fireworks.ai/models/fireworks/hy4-flash) 是腾讯新推出的开放权重模型，现已在 Fireworks 无服务器平台上提供。它是一个混合专家（MoE）模型，总参数量约 220B，每个 token 激活约 12B，上下文窗口为 1M token（在 Fireworks 上线时为 512K），支持文本和图像输入。腾讯为文档处理、研究、办公工作和 agent 工作流而构建了它。

在我们记录了成本的每一个 [Specialized Intelligence Index](https://fireworks.ai/specialized-intelligence-index/) 基准上，Hy4 Flash 都位于得分-成本帕累托前沿。在这些榜单上，没有模型能以更低的成本获得更高的得分。最明显的例子是 Epiq 的 CorporateBench，它以每任务低 200 倍以上的成本（$0.013 对 $2.80）险胜 Claude Opus 5.5。它还在 Rogo 的 Big Finance Benchmark 上与 Claude Opus 5 持平，在 Sierra 的 τ³-Banking 上与之相当，同样成本低 200 倍以上。

Hy4 Flash 在 Fireworks 无服务器平台上运行，Standard 层级的价格为每百万未缓存输入 token $0.07、每百万缓存输入 token $0.003、每百万输出 token $0.281，另有 Priority 层级可用。它在全球范围内提供服务。

## Hy4 Flash 在专业工作上与 Claude Opus 保持同步

我们在七个 [Specialized Intelligence Index](https://fireworks.ai/specialized-intelligence-index/) 基准上运行了 Hy4 Flash，使用与各榜单上其他所有模型相同的测试框架，并采用高推理强度。成本按 Fireworks 无服务器价格计算所记录的 token 得出。有三项结果尤为突出：

- 在 **Epiq 的 CorporateBench** 上领先于 Claude Opus 5.5。该基准测试在数千封公司内部邮件和会议记录中回答问题。Hy4 Flash 得分 75.9%，在 14 个模型中排名第 6，略高于 Claude Opus 5.5（75.4%）。它的每任务成本为 $0.013，而 Opus 5.5 为 $2.80，低 200 倍以上，并且是榜单上成本最低的模型。
- 在 **Rogo 的 Big Finance Benchmark** 上与 Claude Opus 5 持平。两者均得分 49.2%，但 Hy4 Flash 每任务成本为 $0.0065，Opus 5 为 $1.83，约高 280 倍。Hy4 Flash 也领先于 Claude Opus 5.5 和 Kimi K3.1 Pro（各 48.2%）。榜单上唯一成本更低的模型 GPT-6 Luna 得分为 35.3%。
- 在 **Sierra 的 τ³-Banking** 上与 Claude Opus 5 相当。在这个面向银行任务的 agent 基准上，Hy4 Flash 得分为 49.2%，Opus 5 为 49.1%，每次试验成本为 $0.012 对 $2.59。它是榜单上成本最低的模型，这使其位于该榜单的成本前沿。

在我们记录了成本的每一个榜单上，Hy4 Flash 都是成本最低的模型，Big Finance 除外。它在 HealthBench Professional（18 个中第 16）和 DeepSWE（22 个中第 19）上排名较低；对于长周期软件工程，腾讯推荐更大的 Hy4。

*结果来自 Fireworks 的 [Specialized Intelligence Index](https://fireworks.ai/specialized-intelligence-index/) 在 Hy4 Flash 的 Fireworks 部署上的运行，截至 2026 年 11 月 22 日。*
