## 美国托管、零数据保留，Day-0 即可训练

Kimi K3 今日开放权重，并在 Fireworks 上 Day-0 同时提供推理与训练。它以闭源模型一小部分的成本交付前沿级智能——全球最强开源模型。它是前端代码世界第一，写作能力强，并且能可靠完成其他模型会卡死的长链条多步智能体任务。

Replit 总裁 Michele Catasta 告诉我们：

> “Kimi K3 在 Replit Design 上超出了我们的预期。前所未有的产品设计与 UI 能力，成本只有我们已经习惯的前沿模型的一小部分。”

Cognition 研究高级副总裁 Silas Alberti 强调：

> “我们信任 Fireworks 提供高质量的 Kimi K3 推理，让我们能在 FrontierCode 上顺畅评估该模型。结果清楚地表明，Kimi K3 代表着开源模型的阶跃式变化。”

这是一个转折点。开源模型已经越过那条线：在真实工作上追平闭源前沿质量，而成本远低。这改变了默认选项：大部分任务先从一个像 Kimi K3 的开源模型开始，清楚看到每一分开销，只在任务确实要求的地方路由到专用智能。

有了 Fireworks 上的 Kimi K3，你就握住了自己的路线图。训练一个 3T 级模型可以从你的笔记本电脑开始——不需要搭基础设施，不需要拉起部署，开个会话发 token 就行。而且我们让你的私有数据保持私有。在 Fireworks 上，专用智能变成一条每个循环都在增值的护城河。

这种所有权附带受监管团队需要的保障：美国托管推理与零数据保留，跑在一个不给你的 API 上。

Mercor CEO Brendan Foody 这样说道：

> “用我们的基准评估新模型通常要在性能、成本和规模之间做取舍，但 Fireworks 上的 Kimi K3 全面都交付了。性能是顶级的，serverless 扩缩无缝，零数据保留的承诺让我们对规模化运作充满信心。”

这种所有权改变了经济性。要紧的是你每个完成任务的成本，由模型首次尝试的成功率和所需的步数决定。定制 Kimi K3 能提高成功率、缩短轨迹，于是预算从通用 token 转向让你公司与众不同的差异化上。

## **Kimi K3 可与 Anthropic 和 OpenAI 的顶级模型匹敌**

Kimi K3 是第一个达到 2.8 万亿参数的开源模型，提供可与 Fable 5、Opus 5 和 GPT 5.5 等闭源模型匹敌的前沿级推理。Kimi K3 为最苛刻的用例而设计：软件开发、网络安全、知识工作、多模态与视觉工作。让 K3 可信的是，其突出的结果大多来自独立基准：

- •**前端代码世界第一**：K3 以 1,679 分登顶 Arena 的 [Frontend Code Arena](https://x.com/arena/status/2077824029126504525?s=20)，超过 Fable 5。这使它成为第一个把全部闭源模型甩在身后的开源模型。它还在 [Vercel 自家的 Next.js 评测套件](https://x.com/rauchg/status/2077900518404321759?s=20)上占据头名。
- •**前沿全栈编码：**在 [DeepSWE（Datacurve）](https://x.com/datacurve/status/2078189882707730535?s=20)上排名第 3，仅次于 Fable 5 和 GPT-5.6 Sol。
- •**通用智能最强开源模型：**在 [Artificial Analysis Intelligence Index](https://x.com/ArtificialAnlys/status/2077832874183860404?s=20)上以 57 分排名世界第 3，与 Opus 和 GPT-5.5 级模型相当。
- •**编辑口吻写作第一，[Elo 2840](https://x.com/Whats_AI/status/2077860441380798908)**：超过 Claude Fable 5。相比前代 Kimi K2.6，这是从第 21 名到第 1 名的跃升。
- •**为法律分析树立新标准**：K3 在 [Harvey 的 LAB 法律基准](https://artificialanalysis.ai/evaluations/harvey-lab-aa?eval-score=all-pass-rate)上取得 26.7% 的全通过率，接近 **2 倍**于 Fable 5。
- •**客服表现无出其右：**在 [Sierra 的 Tau3-Banking](https://artificialanalysis.ai/evaluations/tau3-banking) 基准上，K3 得 33.4%，险胜 GPT 5.6 Sol。
- •**多模态智能顶级：**在复杂图表、截图与密集文档分析（[CharXiv 与 Zerobench](https://x.com/Kimi_Moonshot/status/2077830229968683203?s=20)）上位列全球前二。
- •**高端网络安全：**在 [Vercel 的私有网络安全评测](https://x.com/cramforce/status/2078574147333152957?s=20)上与 GPT 5.5 召回率相当，而价格低得多。
- •**自主游戏开发顶级：**开发者社区正在为智能体游戏开发的新前沿热议，从 [Night Rider](https://x.com/HakeemPH41/status/2078219978395054341) 到 [Fluppy Bird](https://x.com/Sonika_KK/status/2078068051614859621)

## **Kimi Delta Attention：为大上下文负载带来更快 token 与更低成本**

对多数工程团队来说，自己托管 K3 并不现实。Moonshot 建议在 64+ 加速超节点（GPU）集群上运行它。这意味着巨大的前期硬件开支，以及在闲置 GPU 上无休止的钱。Fireworks 让你跳过集群的头痛：不必为专用 GPU 预留烧预算，按 token 付费，在你需要的任何地方获得前沿级推理。

K3 不只是更大，它在设计上就更高效。Moonshot 通过改变信息在模型中的流动方式改进了设计。我们在 Fireworks 的团队为 Kimi Delta Attention 手写了自定义 kernel、FP4 MoE kernel，并改造了解码 kernel 以释放 K3 的全部性能。模型架构引入了全新的 Kimi Delta Attention 架构与改进的注意力残差。他们扩展了混合专家（MoE），在 Stable Latent MoE 下从 896 个专家中激活 16 个。相比 Kimi K2，这一方法带来 2.5 倍的扩展效率。结果是一个既能为大型长周期任务提供前沿推理，又对高吞吐生产负载保持成本效益的模型。

## **在 Fireworks 上按你想要的方式运行 Kimi K3**

你可以把 Kimi K3 像大多数 AI 工作负载一样在 Fireworks 上互换使用。我们的 serverless 平台把用模型简化到只需填一个 API key。你不必操心 GPU 管理或 API 兼容性。

Fireworks 把 Serverless 推理的默认速率限制提升了 10 倍以上，推出了更可靠保障的 [Priority Serverless](https://docs.fireworks.ai/serverless/overview)，并为更快的 token 速度优化了 [Fast Serverless](https://docs.fireworks.ai/serverless/overview)。最棒的是这些选项都不需要你租 GPU：像你为 Claude 和 OpenAI 付费那样，只为使用的 token 付费。

> “当我们与其他供应商做 bakeoff 时，Fireworks 胜出只是因为它的稳定可用。我们部署的任何模型，第一次就能跑通。不用调参，不用折腾。我不想陷入三周的开发循环只为让一个模型跑起来。”

> — Travis Rehl，Innovation Solutions CTO

对于可以延后的工作，[**Batch 模式**](https://docs.fireworks.ai/guides/batch-inference)在低峰时段跑任务，价格打五折。这正是各团队用 K3 的视觉推理处理整文件夹图片——打字幕、标注或裁剪——的方式，同样的节省适用于任何可批处理的事，比如跑评估。

## **为受监管行业打造：仅限美国的 Serverless 与零数据保留**

今天，我们还推出了 [**US-only Serverless**](https://docs.fireworks.ai/serverless/us-only-serverless) 端点，从 Kimi K3 开始。未来几天到几周，我们会为 Fireworks 上最受欢迎的其他模型增加更多 US-only 端点。要求美国数据驻留的金融服务、医疗和其他受监管公司，现在就可以注册，连上具备[零数据保留](https://docs.fireworks.ai/guides/security_compliance/data_handling)与美国境内推理的端点。

对于数据隐私不容妥协的安全敏感负载，Fireworks 默认按[零数据保留](https://docs.fireworks.ai/guides/security_compliance/data_handling)运行。未经你明确选择加入，我们从不记录或存储你开源模型的 prompt 或生成数据，给你的团队完整的数据控制权与安心。
