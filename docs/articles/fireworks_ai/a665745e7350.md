# Fireworks 上线 Muse Spark Open：Meta 的开放权重模型，跑在美国 serverless 上

![Terminal-Bench 2.1 上的 Muse Spark Open](https://fireworks.ai/_next/image?url=https%3A%2F%2Fcdn.sanity.io%2Fimages%2Fpv37i0yn%2Fproduction%2Fce7c3fd6fee91f09efac2a6391bff7e59bcb3c58-1920x1080.png%3Fauto%3Dformat&w=3840&q=75)

[Muse Spark Open](https://fireworks.ai/models/fireworks/muse-spark-open) 是 Meta 出品的一个开放权重模型，Day-0 就在 Fireworks 上可用。它是一个 8,160 亿参数的 mixture-of-experts 模型，每个 token 激活 420 亿参数，context window 达 100 万 token，为长周期 coding 和 agent 工作而生，这类活儿要求在超长会话里始终保持连贯。

它是迄今最有实力的美国开放权重模型之一，也是我们在受监管的专业工作里见过的最强开放权重模型。在 Vals AI 为 Harvey 的 Legal Agent Benchmark 设立的排行榜上，它位列第一，通过率接近 Claude Opus 5 的 4 倍。在 Rogo 的 Big Finance Bench 上，它在每一个难度级别都击败了 Claude Opus 5.5，在最难的任务上还略胜 GPT-6 Astra。

Muse Spark Open 在美国完成训练与开发，Fireworks 默认以 Zero Data Retention 的方式运行它。[今天就试试 serverless 版本](https://app.fireworks.ai/models/fireworks/muse-spark-open)，它跑在仅限美国的算力上，且不收美国溢价。之后可切换到 reserved throughput 上生产，并用 serverless LoRA training 对它做精调。

> Muse Spark Open 展现出很强的 agentic 工程能力：它能穿梭于代码仓库、实现不那么简单的改动，并验证复杂的 coding 工作 —— Zimu，Factory 的 Member of Technical Staff

## 在受监管的工作上，Muse Spark Open 压过 Claude Opus

Muse Spark Open 最能发挥的地方是准确性至上的场景，比如法律、金融和临床任务。以下结果来自独立评测方和我们的 Specialized Intelligence Index，其中每个模型都跑在同一套 harness 上：

- •**Harvey 的 egal Agent Benchmark 上排名第一：**在以文件和使用工具完成法律工作的 [Vals AI 排行榜](https://www.vals.ai/benchmarks/hlab)上，Muse Spark Open 在 75 个模型中位列第一，得分 25.4%，接近 Claude Opus 5（6.7%）的 4 倍。
- •**在 Rogo 的 Big Finance Bench 上领先 Claude Opus 5.5：**在 Fireworks 的 [Specialized Intelligence Index](https://fireworks.ai/specialized-intelligence-index/benchmarks/finance/big-finance-benchmark) 运行中，Muse Spark Open 在每个难度级别都击败了 Claude Opus 5.5。在最难的任务上，它以 17.3% 对 16.5% 略胜 GPT-6 Astra，得分是 Opus 5.5（6.6%）的 2.5 倍以上（图 1）。
- •**Finance Agent 上位列前三：**在 [Vals AI 的 Finance Agent v2](https://www.vals.ai/benchmarks/fabv2) 上，它得到 60.6%，与 Gemini 3.8 Flash 相差不到 1 个百分点，而每次测试的成本约低 60%。
- •**临床文档：**它在 [Vals MedScribe](https://www.vals.ai/benchmarks/medscribe) 上得分 90.1%，与 Claude Opus 5（91.0%）相差不到 1 个百分点，token 单价却低 75-83%。

本文中 Vals AI 和 Artificial Analysis 的第三方结果，是在 Meta 面向 API 发布的这个模型版本上测得的。

> 在 Rogo，我们让每一个新模型都过一遍 Big Finance Bench，那是我们收录 928 道真实金融工作流问题的题集。Muse Spark Open 得分 53.3%，是我们榜单上成绩最好的开放权重模型，甚至超过了前沿的 Claude Opus 5（49.2%）。高性能的美国开放权重模型开始涌现，这一点尤其令人振奋。它们为持续实验提供了底座，也让我们能把智能调校到金融工作的特定需求上。我们很期待在推进模型性能边界的同时，为客户释放新的价值与效率。 —— Alex Wang，Rogo 的 Member of Technical Staff

## Muse Spark Open 在标准基准上的表现

在标准的公开基准上，Muse Spark Open 同样站得住脚：

- •幻觉更少：在 [Artificial Analysis 的 AA-Omniscience](https://artificialanalysis.ai/models/muse-spark-1-2?omniscience=omniscience-hallucination-rate) 上，它的幻觉率为 33%，低于 Claude Opus 5.5（59%）和 GPT-6 Astra（51%），因为它在没把握时会拒绝作答而不是硬猜。
- •Agentic coding：在 Meta 的评测中，它在 Terminal-Bench 2.1 上得分 82.9%，领先 GPT-5.6 Terra 和 Grok 4.5（图 2）。

> Muse Spark Open 是西方开源模型的一次阶跃式变化，在我们的早期评测里，它的指令遵循尤其出色。我们很兴奋能在这一基础上，通过 post-training 来强化 Decagon 支撑的那些复杂工作流 —— Decagon Labs
