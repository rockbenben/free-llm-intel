## [#](https://inference.net/blog/minimax-m3-1-flash-day-0/#what-is-minimax-m31-flash)What is MiniMax M3.1 Flash?

MiniMax M3.1 Flash is a native multimodal Mixture-of-Experts model. It has roughly 428B total parameters and activates 23B per token, which keeps latency and cost low while preserving deep reasoning ability.

It builds on MiniMax-M3 with three changes aimed at efficiency:

- **Sparse attention throughout.** MiniMax Sparse Attention now runs in every layer, including the first three layers that used full attention in M3.
- **Quantization-aware training.** The routed experts and attention paths are quantized during training, which reduces the memory footprint and improves serving efficiency.
- **DSpark speculative decoding.** A new draft head replaces the earlier MTP approach to speed up generation.

On Inference, M3.1 Flash supports a 1M-token context window, image input, function calling, structured outputs, and automatic prompt caching. Reasoning effort is selectable per request: `low`, `medium`, `high`, `xhigh`, or `max`.
