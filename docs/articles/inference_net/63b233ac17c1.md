# OSSAS 项目：定制LLM可处理 1 亿篇研究论文

作者：Sam Hogan

## **引言**

今天，我们联合 [LAION](https://laion.ai/) 与 [Wynd Labs](https://www.wyndlabs.ai/) 一起推出 OSSAS 项目。OSSAS 项目是一项大规模的开放科学行动，目标是通过对研究论文做结构化的、由 AI 生成的摘要，让全世界的科学知识变得人人可及。它建立在 [Project Alexandria](https://projects.laion.ai/project-alexandria/) 的基础之上，使用自训的大语言模型（Large Language Models），以及来自全球数万台计算机的闲置算力，把科研论文处理成一种标准化格式。这种机器可读的格式可以被浏览、被检索，并在不同学科之间相互关联。

**贡献者：** [Christoph Schuhmann](https://scholar.google.com/citations?user=EvrlaSAAAAAJ&hl=de)、[Amarjot Singh](https://x.com/AmarSVS)、[Andrii Prolorenzo](https://www.researchgate.net/profile/Andrii-Prolorenzo)、[Andrej Radonjic](https://x.com/0xdrej)、[Sean Smith](https://x.com/bonham_sol)，以及 [Sam Hogan](https://x.com/samhogan)

**模型：** [OSSAS-Qwen3-14B](https://huggingface.co/inference-net/OSSAS-Qwen3-14B)、[OSSAS-Nemotron-12B](https://huggingface.co/inference-net/OSSAS-Nemotron-12B)

**可视化器：** [https://ossas.inference.net](https://laion.inference.net)

**可视化器代码：** [在 GitHub 上查看](https://github.com/context-labs/aella-data-explorer)

**论文：** 即将发布

完成这个项目的工作同样横跨许多学科：定制的模型训练管线、在闲置算力上抓取数据并处理推理的高吞吐分布式系统、确保完整性的密码学协议，等等。这些组成部分是：

**Inference Devnet** [（链接）](https://devnet.inference.net/) —— 面向 LLM 推理负载的银河级分布式网络基础设施。

**OSSAS Models** [（链接）](https://huggingface.co/inference-net/Aella-Nemotron-12B) —— 经过后训练的 Nemotron 与 Qwen 模型，以接近前沿的水准、低成本地处理科学文献。

**Inference Staking** [（链接）](https://github.com/context-labs/inference-staking) —— 基于 Solana 的质押与增发协议，用来协调每日的 USDC 发放（相关说明文章即将发布）

**LOGIC** [（链接）](https://inference.net/blog/logic) —— 基于 LogProb 的推理验证，用来约束网络参与者必须诚实。

在这篇文章里，我们先从整体上了解 OSSAS 项目，再深入我们在训练、评估和部署这些定制语言模型时所走过的完整过程——正是这些模型构成了整个行动的骨架。

## **背景**

获取科学知识的机会不平等，依然是我们这个时代最大的不公之一。付费墙、许可限制和版权约束筑起了一道道阻碍，拖慢研究、限制教育，并把知识集中在那些付得起访问费用的机构里。发展中国家的研究者、独立开展工作的公民科学家、资源匮乏高校的学生，往往拿不到他们所需要的论文。

除此之外，科学文献的绝对体量也让跟上进度几乎不可能。每年有数百万篇论文发表在数千种期刊和预印本服务器上。不同的论文使用不同的格式、结构和写作风格。跨论文比较论断、理解方法学上的差异、或者识别出相互矛盾之处，都需要极其吃力的手工工作。

OSSAS 项目的目标是改变这一局面：创建一套标准化结构，用自训的大语言模型规模化地生成科学论文的摘要。

[Project Alexandra](https://projects.laion.ai/project-alexandria/) 为这项工作奠定了法律与技术基础，它证明我们既能从学术文本中抽取事实性知识，又能通过"Knowledge Units"来尊重版权——那是一种保留科学内容、但不复制受版权保护表达的结构化表示形式。

在这一基础之上，过去四个月我们开发了一整套用于规模化处理科学文献的管线。今天，我们放出第一阶段进展预览，其中包括：

- OSSAS Models：用于结构化摘要的、经过微调的 [Qwen 3 14B](https://huggingface.co/context-labs/Paper-Summarizer-Qwen3-14B) 与 [Nemotron 12B](https://huggingface.co/context-labs/Paper-Summarizer-Nemotron-12B) 模型
- 首批 100,000 篇研究论文摘要，采用标准化 JSON 格式
- 位于 [https://ossas.inference.net](https://laion.inference.net) 的交互式数据集探索
- 完整的评估框架与训练方法

我们的微调模型取得的性能可以与 GPT-5、Claude 4.5 Sonnet 这类领先的闭源模型相媲美，而成本低 98%，同时还提供了开放科学所要求的透明度与可及性。这是我们朝更大目标迈出的第一步：处理并结构化来自 1 亿篇研究论文的知识。

## **从 1 亿篇论文到结构化知识**

我们的主数据集由大约 **1 亿篇研究论文** 构成，通过与 Wynd Labs 的合作、借助 Grass 网络从公开互联网上抓取而来。我们对这个庞大的集合做了去重，并用来自既有权威来源的论文加以补充：

- **bethgelab 的 paper_parsed_jsons 数据集**：高质量的已解析研究论文
- **LAION 的 COREX-18text 数据集**：多样化的科学文本
- **来自 Common Pile 的 PubMed 文章**：生物医学研究文献
- **LAION 的 Pes2oX-fulltext 数据集**：科学论文全文

这是有史以来为知识抽取而组建的最大规模的科学文献集合之一。这样的规模至关重要，它能把学科、方法学和研究年代的覆盖面最大化。

在模型训练上，我们整理出一个精选的 110,000 篇论文子集，采样时仔细保证了来源与科学领域的多样性。这个子集被划分为 100,000 条训练样本和 10,000 条验证样本。这些论文篇幅都不小，平均每篇 81,334 个字符，中位数为 45,025 个字符。

### **设计 Schema**

我们开发了一套完整的 Json schema 来组织科学论文摘要，其灵感来自 Alexandria 项目的 Knowledge Units 概念。该 schema 把文章分为三类：

SCIENTIFIC_TEXT：完整的科学研究论文

PARTIAL_SCIENTIFIC_TEXT：部分的科学内容

NON_SCIENTIFIC_TEXT：非研究内容

对于科学论文类文本，schema 会抽取详细信息，包括标题、作者、发表年份、研究背景、方法、结果、论断以及其他关键要素。完整 schema 附在本文末尾。

这种结构化格式让论文之间可以直接比较，并催生出探索科学文献的全新方式。研究者不必再在非结构化文本里翻找，而是可以查询特定字段，找出所有使用某一特定方法学的论文、跨研究比较结果，或者识别出文献中互相矛盾的论断。

### **模型训练**

为了规模化地生成这些结构化摘要，我们微调了两个开源模型：

**Qwen 3 14B：** 阿里巴巴的稠密 transformer 模型，以推理能力强著称**Nemotron 12B：** NVIDIA 的 Mamba-Transformer 混合架构，提供高吞吐

两个模型都在我们精选的 110,000 篇数据集上做了后训练，训练目标使用的是顶尖闭源模型生成的摘要。这一训练把通用开源模型变成了专门的科学摘要器，让它们理解各个不同领域中研究论文的惯例、结构与细微之处。

## **验证质量**

对一个野心如此之大的项目，评估至关重要。我们不能只是宣称模型好用——必须通过多种互补的方法来加以证明。

### **LLM-as-a-Judge 评估**

我们的主要评估使用一个由三个前沿模型（GPT-5、Gemini 2.5 Pro 和 Claude 4.5 Sonnet）组成的集成，按 1-5 分制为摘要打分。这种多模型集成降低了任何单一评审带来的偏差，并在多个维度上给出稳健的评价：事实准确性、完整性、对结构的遵循程度，以及清晰度。

结果印证了：调优得当的开源模型可以匹敌闭源模型的表现。

图 1：这一组模型的平均 LLM-as-a-Judge 得分。评分量表满分为 5 分，并给出基于 bootstrap 的置信区间。

我们的微调模型得分与 GPT-5 本身相差在 15% 以内——考虑到它们是开源模型、体量更小、运行起来高效得多，这是相当出色的表现。基座模型与微调版本之间显著的差距，说明了面向特定领域的训练对科学摘要的价值。

### **QA 数据集评估：衡量事实效用**

为了验证事实准确性与下游效用，我们设计了一套受 Alexandria 方法启发的补充评估。对一批留出的论文，我们用 GPT-5 为每篇生成 5 道选择题，然后测试模型能否仅凭自己生成的摘要（截断到 10,000 个字符）答对这些题目。

这检验的是一件关键的事：这些摘要是否真的能支撑下游的推理与信息检索？

图 2：各模型的 QA 评估对比。准确率由 1,270 道选择题的作答情况计算得出。

我们的模型追平甚至超过了领先的闭源替代品。Qwen 3 14B 微调模型与 Gemini 2.5 Flash 打平，同为 73.9%，仅略低于 GPT-5 的 74.6%。

这两种评估方法一起提供了有力的验证：LLM-as-a-judge 评估确认我们的摘要质量高、结构良好；QA 数据集则证明它们有事实依据，对下游任务确实有用。

## **经济性与吞吐量**

基准测试上的性能很重要，但实际可部署性同样重要。我们用这些模型真的能处理 1 亿篇论文吗？处理完整个数据集要消耗多少 GPU 小时、花多少钱？

我们在一台 8×H200 节点上使用 vLLM 测量了吞吐量：

在所有指标上——包括每秒请求数、输入 token 处理、输出生成以及单请求解码速度——OSSAS Nemotron 12B 模型的吞吐量都比 OSSAS Qwen 3 14B 高 2.25 倍。对于大规模处理，这一差距直接转化为总算力成本低 2.25 倍。

经济上的对比十分悬殊：

- 用 GPT-5 处理 1 亿篇论文：按当前定价超过 500 万美元
- 用我们的定制模型处理：不到 100,000 美元

这是 50 倍的成本下降，而且质量还保持在可比的水平。若没有如此剧烈的成本下降，我们几乎不可能为本项目的全部工作提供资金。借助定制 LLM，我们让科学知识抽取在一个前所未有的规模上变得可行——在这个规模上，过去除了世界上最富有的机构，谁都承担不起。

## **闲置算力：面向开放科学的基础设施**

即便微调模型的成本已经大幅降低，处理 1 亿篇论文仍然需要庞大的计算资源。传统云计算会让这件事贵到无法承受。我们提供一个替代方案：[Inference Devnet](https://devnet.inference.net)——一个无需许可的去中心化 GPU 网络，可以在全球范围内众包闲置算力资源。你可以把 Inference Devnet 理解为 [SETI@Home](https://en.wikipedia.org/wiki/SETI@home) 的现代版本，专为处理大规模 LLM 负载而打造。Inference Devnet 通过一张分布式 GPU 网络提供海量算力，这些 GPU 运行在贡献者家中的设备和遍布全球的数据中心里。我们相信，闲置算力正是为科学研究进一步扩展计算资源的关键：它让人们能够把自己闲置的资源贡献给那些自己认可的科学行动，同时也让资源不足的研究者获得一条以自己的研究取得实质推进的路径。敬请期待，我们很快会分享更多内容。

## **可视化与发现**

为了展示结构化摘要的实用性，我们用最初生成的 100,000 条摘要搭建了一个[交互式可视化工具](https://aella.inference.net)。

这个可视化器把科学文献做成一个具象化的空间表示：对由摘要生成的 embedding（使用 Qwen 3 Embedding 4B）做 [UMAP](https://github.com/lmcinnes/umap) 聚类。论文按主题、方法学和领域聚成簇，以直观的视觉形式呈现科学知识的全貌。

**核心特性：**

- **空间聚类：** 相关的论文彼此靠近显示
- **相似度检索：** 基于摘要 embedding 的余弦相似度来查找论文
- **交互式探索：** 点击论文即可查看其结构化摘要
- **关联发现：** 识别文献之间的联系与规律

这只是规模化结构化摘要所能打开的可能性中的一个例子。一旦科学知识被整理成标准格式，我们就可以构建用于对比分析、论断核查、矛盾检测、知识图谱构建的工具，以及其他在非结构化文本上根本行不通的应用。

这个可视化表明，结构化摘要并不只是抽象产物；它们让探索和理解科学文献出现了此前根本不可能的新方式。

## **局限性**

**幻觉与事实精确度**

大语言模型，哪怕是前沿模型，都可能生成流畅但存在细微错误的陈述。这种风险在颗粒度很细的科学细节上尤为突出：样本量、效应量、置信区间、精确日期和单位换算。我们的评估框架验证了摘要是有用且形式良好的，但无法对每一条原子论断保证逐行的事实准确。

QA 评估说明摘要能有效支撑下游推理，但这并不能担保每一个数字、每一处引用、每一项领域特定细节都完全精确。

**上下文限制与覆盖度**

当前的上下文长度限制（在我们的配置中是 128,000 token）会迫使模型对超长文档做取舍式阅读，可能漏掉对特定用户或特定任务很重要的细节。尽管论文的平均长度在我们的配置下装得下绰绰有余，但仍存在边缘情况，其中重要信息可能被截断。

**领域异质性**

不同学科的方法学规范差异极大。一篇物理论文、一项临床试验、一项定性社会学研究、一篇计算机科学基准论文，各自需要不同类型的信息抽取。我们统一的 schema 能较好地满足宽泛的需求，但如果没有额外的领域特定后训练，在高度专门化的子领域上召回率可能会有所下降。

**恰当使用**

基于上述考虑，我们强调恰当使用：**我们的摘要是对文献的高质量概览，让文献更易检索、更易比较、更易于探索**。它们是教育与研究辅助工具，用来加速入门定位和文献综述。

对于高风险的科学活动，例如工程实现、临床或政策决策、撰写学术论文或学位论文，用户应当对照原始论文核实具体细节（数字、日期、专业术语）。摘要只是探索的起点；在需要精确的地方，它不能替代对一手文献的细读。

我们公开这些摘要，正是为了让社区能够验证、批评并改进它们。

## **扩展到 1 亿篇论文**

这次发布的 100,000 条摘要是我们的第一个里程碑。接下来是：

**处理全部语料**

我们眼下最优先的事，是用微调后的模型处理完整的约 1 亿篇论文集合。每一篇论文都会得到一份标准化的结构化摘要，从而形成有史以来最全面的科学文献知识抽取成果。

**接入 OpenAlex 元数据**

我们会把每一份摘要与 OpenAlex 元数据关联起来，让用户可以在作者、发表平台、机构、概念、参考文献与引用之间穿行。这会形成一个原生于图结构的探索层，摘要被锚定在文献语境与引用邻域之中。你不仅能浏览论文说了什么，还能看到它们与更广泛研究生态如何相连。

**发布宽松许可的全文**

对于采用宽松许可的论文（来自 PeS2o 和 Common Pile PubMed 的子集），我们会发布与摘要配对的对应全文。这可以支持长上下文训练与基准测试：AI agent 可以从数百万份文档中检索并论证某个论断，把摘要当作查询的脚手架，同时把答案建立在已发布的全文之上。

**转换为 Knowledge Units**

沿着我们的 Alexandria 框架，我们希望逐步把语料转换成结构化、与文风无关的 Knowledge Units，用来捕捉实体、属性与关系，而不复制受版权保护的表达。这将产出一层可共享的事实基底，无论在法律上还是在技术上都适合开放传播和机器使用。

Knowledge Unit 转换比生成摘要计算量大得多，因此我们的分阶段方案先把规模化摘要和元数据关联做掉，再逐步推进 Knowledge Unit 转换。

这些步骤中的每一步都让我们更接近目标：让科学知识在全球规模上真正做到可获取、可比较、可探索。

## **开放模型、开放科学、开放未来**

定制模型完全能够有效、规模化地生成科学论文的高质量结构化摘要。我们的微调模型性能可以与领先的闭源替代品相媲美，同时在经济性、透明度和可及性上更胜一筹。

今天发布的 100,000 条摘要、两个微调模型和一个交互式可视化工具，是朝一个更大愿景迈出的切实进展：处理并结构化来自 1 亿篇研究论文的知识，让任何有好奇心、能上网的人都真正能获取科学知识。这是为开放科学打造开放基础设施的起点。
