## [#](https://inference.net/blog/minimax-m3-1-flash-day-0/#what-is-minimax-m31-flash)什么是 MiniMax M3.1 Flash？

MiniMax M3.1 Flash 是原生多模态 Mixture-of-Experts 模型，总参数约 428B，每个 token 激活 23B，在保持深度推理能力的同时把延迟和成本压得很低。

它在 MiniMax-M3 基础上做了三项面向效率的改动：

- **全程稀疏注意力。** MiniMax Sparse Attention 如今在每一层都运行，包括 M3 中原先使用全注意力的前三层。
- **量化感知训练。** 路由专家和注意力路径在训练过程中被量化，减少了内存占用、提升了服务效率。
- **DSpark 投机解码。** 新的 draft head 取代了早先的 MTP 方案，以加快生成速度。

在 Inference 上，M3.1 Flash 支持 1M-token 上下文窗口、图像输入、function calling、结构化输出和自动 prompt caching。推理强度可按请求选择：`low`、`medium`、`high`、`xhigh` 或 `max`。

```

    base_url="https://api.inference.net/v1",

    model="minimax-m3.1-flash",
    messages=[{"role": "user", "content": "Write a function that merges two sorted lists."}],

```
