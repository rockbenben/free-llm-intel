# Schematron V2：以极低的成本实现前沿级 HTML-to-JSON 提取

A

Amar Singh

## 引言

今天我们发布 Schematron V2，这是我们专门化 HTML-to-JSON 提取模型家族的下一代产品。如果你是第一次接触这里：Schematron 是一族小型的、为目标而生的模型，它们把凌乱的 HTML 变成干净、结构化的 JSON，用大型通用 LLM 一小部分的成本和延迟，交付前沿级别的提取质量。

[Schematron V1](https://inference.net/blog/schematron/) 已经在生产环境中，为那些在 web 规模数据上运营的公司支撑着海量的提取负载；我们很高兴发布把性能推进得更远的新一批变体。

Schematron V2 引入两个新模型：Schematron V2 Small 和 Schematron V2 Turbo。Schematron V2 Small 的质量几乎追平我们第一代的 8B 模型，同时保持着 3B 量级的速度。Schematron V2 Turbo 为最大吞吐而优化，在单张 H100 上处理 4.14 次请求/秒（相比最初的 Schematron 3B 提升 2.5 倍），同时质量仍然超过上一代的 3B 模型。

我们使用 [Inference platform](https://inference.net/blog/introducing-inference-platform/) 训练 Schematron——这是我们专为训练高性能任务型 LLM 而打造的 LLM 精调引擎。两款 Schematron 模型今天都能通过我们在 [Inference.net](http://inference.net) 上的 serverless API 调用。

创建一个[免费账号](https://inference.net/register)，或者查看我们的[文档](https://docs.inference.net/workhorse-models/schematron)即可上手。

## Schematron API

用下面的代码通过 Inference.net 的 serverless API 调用 Schematron V2。请务必设置好你的 `INFERENCE_API_KEY`，并把 `HTML` 变量指向你的 HTML 文档。

```
import os
from pydantic import BaseModel, Field
from openai import OpenAI

class Product(BaseModel):
    name: str
    price: float = Field(
        ..., description=(
            "Primary price of the product."
        )
    )
    specs: dict = Field(
        default_factory=dict,
        description="Specs of the product.",
    )
    tags: list[str] = Field(
        default_factory=list,
        description="Tags assigned of the product.",
    )

HTML = '<YOUR_HTML_DOC>'

client = OpenAI(
    base_url="https://api.inference.net/v1",
    api_key=os.environ.get("INFERENCE_API_KEY"),
)

resp = client.beta.chat.completions.parse(
    model="inference-net/schematron-v2-small",
    messages=[
        {"role": "user", "content": HTML},
    ],
    response_format=Product,
)

print(resp.choices[0].message.parsed.model_dump_json(indent=2))
```

## 为什么这很重要

2025 年 9 月我们推出 Schematron V1 时，我们证明了小型的专门化模型可以在 HTML 提取上追平前沿 LLM，同时便宜 40-80 倍。社区的回应印证了我们早已知道的事：各地的团队都在试图从 web 上规模化地提取结构化数据，而成本一直是瓶颈。

到了 V2，我们把质量与体积之比推进得更远。你可以拿到远更小的模型的速度，同时保持 8B 量级的成本。而如果吞吐是你的首要考虑，Turbo 变体让你处理页面的速度超过以往任何时候。

### 质量：缩小与 8B 的差距

我们使用与最初发布时相同的 LLM-as-a-judge 方法来评估 Schematron V2，由 GPT 5.4 按 1-5 分制为提取结果打分。

LLM-as-a-Judge：各模型平均质量分

Schematron V2 Small 得 4.060 分，让它处在与最初的 Schematron 8B（4.070）一箭之遥的位置，并明显领先于第一代的 Schematron 3B（3.909）。对多数生产负载来说，V2 Small 与 8B 之间的差别可以忽略。

Schematron V2 Turbo 得 4.039 分，相对最初的 3B 仍然是一次显著跃升，而且它是在为速度而非质量做优化的情况下做到这一点的。

为了给出参照：在这项 benchmark 上，两款 V2 模型都超过了 DeepSeek V3.2 和 GPT-5.4 Nano，而这两款都是体量远大于它们的模型。

### 吞吐：比 V1 快 2.5 倍

Schematron V2 Turbo 为高容量负载而生，在那里每一个毫秒、每一美元都算数。

请求吞吐对比

在单张 H100 上、输入 10k token、输出 500 token 的条件下：

**Schematron V2 Small**：2.47 次请求/秒

**Schematron V2 Turbo**：4.14 次请求/秒

**Schematron 8B（V1）**：1.63 次请求/秒

**Schematron 3B（V1）**：2.47 次请求/秒

Turbo 模型达到 4.14 次请求/秒，相比最初的 8B 提升 2.5 倍，相比上一代的 3B 接近 1.7 倍。对于延迟敏感的抓取与爬取管线（想想面向实时交易的金融文档解析，或者实时价格监控），这种速度优势会迅速复利放大。

## 提升 LLM 的事实准确性：SimpleQA 结果

我们还重跑了 SimpleQA benchmark，它衡量的是当 Schematron 被用作 web 搜索增强管线中的提取层时，能在多大程度上提升事实准确性（以 GPT-5 Nano 作为基座模型，配合 Exa 搜索）。

SimpleQA Benchmark 得分

**Schematron V2 Turbo**：79.42

**Schematron V2 Small**：83.10

**Schematron 8B（V1）**：85.58

**Schematron 3B（V1）**：75.47

**GPT-5 Nano（不带搜索）**：8.54

Schematron V2 Small 达到 83.10 分，相比第一代的 3B 是一次 7.6 分的大幅提升，只比 8B 模型落后 2.5 分。即便是 Turbo 变体也拿到 79.42 分，相比最初的 3B 接近 4 分的增益，而处理页面的速度显著更快。

这些结果强化了我们的核心结论：结构化提取从根本上改变了 LLM 使用 web 搜索的经济性。Schematron 不再把整页原始 HTML 塞进一个大模型（每次查询数以万计的 token），而是只提取那些真正重要的结构化数据，让 web 增强的事实准确性在规模化下变得可行。

## 定价

Schematron V2 的定价，是为了让互联网规模的提取人人可及：

**Schematron V2：** 每 100 万输入 token $0.10 – 每 100 万输出 token $0.25

**Schematron V2 Turbo：** 每 100 万输入 token $0.06 – 每 100 万输出 token $0.15

按这些价格，每天处理 100 万个页面（假设每个页面 10k 输入 + 8k 输出 token）用 V2 3B 大约花费 $700/天，用 V2 3B Turbo 大约 $440/天。对于高容量负载，通过 dedicated instances 还可以拿到额外折扣。可以[与我们会面](https://inference.net/meet-with-us/)，了解更多关于 dedicated capacity 的信息。

### 开始使用

两款 V2 模型与最初的 Schematron 家族共享同样的核心能力：128K token 的上下文窗口，以及保证 100% 符合 schema 输出的严格 JSON 模式。用 Pydantic、Zod 或 JSON Schema 定义你的 schema，传入原始 HTML，拿回经过校验的、类型安全的数据。

关于用法更多信息，请参阅我们的[文档](https://docs.inference.net/workhorse-models/schematron)。

Schematron V2 Small 和 V2 Turbo 的模型权重目前将继续闭源，只通过我们的 serverless API 提供。最初开源的 Schematron 3B 和 8B 模型仍然[可在 Hugging Face 上获取。](https://huggingface.co/inference-net/Schematron-8B)
