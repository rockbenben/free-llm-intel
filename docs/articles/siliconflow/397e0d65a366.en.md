### [[Model Service Adjustment] Wan2.2 Series Retirement and MiniMax-H3 Launch](https://docs.siliconflow.cn/docs/release-notes/overview#model-service-adjustment-wan22-series-retirement-and-minimax-h3-launch)

The platform will retire the Wan2.2 series models on **2026-11-10** and launch MiniMax-H3 on the same day:

- Retired models: `Wan-AI/Wan2.2-T2V-A14B` (text-to-video) and `Wan-AI/Wan2.2-I2V-A14B` (image-to-video). From 2026-11-10, these models will no longer accept new requests. There is no transition window, so please migrate before that date.
- New model: `MiniMaxAI/MiniMax-H3`, supporting text-to-video, first-frame-to-video, last-frame-to-video, and first-and-last-frame-to-video.

The video generation API (`/v1/video/submit`) is updated on the same day:

- New parameters: `duration` (in seconds, 5 to 15, default 5), `resolution` (`480p` / `768p`), `ratio` (aspect ratio), and `images` (reference image list, with `role` set to `first_frame` or `last_frame`).
- Videos are billed by the requested `duration`. `negative_prompt` and `image_size` no longer take effect: passing them does not raise an error, but they are ignored.
- See the [video generation API](https://docs.siliconflow.cn/docs/api/video-submit-post) for parameter details and examples.

If you are using the Wan2.2 series, please switch to MiniMax-H3 or another model before 2026-11-10. For the full list of available models, see [Models](https://cloud.siliconflow.cn/models?types=to-video).
