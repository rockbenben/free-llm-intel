### [[Model Service Adjustment] Qwen3-Coder-30B-A3B-Instruct, GLM-4.5V and Other Models to Be Retired](https://docs.siliconflow.cn/docs/release-notes/overview#model-service-adjustment-qwen3-coder-30b-a3b-instruct-glm-45v-and-other-models-to-be-retired)

To further optimize resource allocation and provide more advanced, high-quality technical services, the platform will retire the following models on **2026-11-16**:

- Qwen/Qwen3-Coder-30B-A3B-Instruct
- tencent/Hunyuan-A13B-Instruct
- inclusionAI/Ling-mini-2.0
- Qwen/Qwen3-VL-30B-A3B-Thinking
- stepfun-ai/Step-3.5-Flash
- zai-org/GLM-4.5V
- Qwen/Qwen3.5-122B-A10B

If you are using any of these models, we recommend switching to another model soon to avoid service impact. For the full list of available models, see [Models](https://cloud.siliconflow.cn/models).
