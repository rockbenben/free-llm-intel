### [【接口服务调整】生图 API 下线 batch_size 字段、水印默认添加](https://docs.siliconflow.cn/docs/release-notes/overview#接口服务调整生图-api-下线-batch_size-字段水印默认添加)

为持续优化平台服务，`/v1/images/generations` 生图 API 将于 **2026-09-30** 进行以下调整：

- **`batch_size` 字段下线**：请求正文中不再支持 `batch_size` 字段。若此前依赖该字段在单次请求中生成多张图片，请改为多次调用。
- **图片生成 API 默认添加「AI 生成」显式水印**：本次变更适用于通过 API 执行的图片生成请求。API 生成的图片将默认添加「AI 生成」显式水印，隐式水印固定添加。当且仅当开发者需要对生成图片执行下游的进一步处理时，才应显式传入 `X-Enable-Watermark: 0` 声明不添加显式水印；此时，开发者有法定义务自行对最终输出图片添加相关显式水印。

若您正在使用生图 API，请及时确认上述变更对业务的影响。
