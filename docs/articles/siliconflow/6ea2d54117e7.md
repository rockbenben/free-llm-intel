### [【账户安全】API Key 仅在新建时展示一次，不再回显明文](https://docs.siliconflow.cn/docs/release-notes/overview#账户安全api-key-仅在新建时展示一次不再回显明文)

为提升账户安全，自 **2026-11-28** 起，API Key 的明文仅在新建时展示一次，平台不再以任何形式回显完整 Key。

- **新建 API Key**：创建成功时展示一次完整明文，请立即复制并妥善保管；此后无法再次查看。
- **存量 API Key**：不再支持查看或复制明文；已配置在客户端、环境变量或第三方工具中的 Key，调用不受影响。
- **如何区分不同 Key**：平台会保留每个 Key 的末尾几位，并保存在该 Key 的备注信息中。在 [API 密钥](https://cloud.siliconflow.cn/account/ak) 管理界面与费用明细中，可据此分辨对应的 Key。

如已遗失某个 Key 的明文，请新建一个 API Key 替换旧 Key，确认替换完成后再删除旧 Key。创建方式参见[快速入门](https://docs.siliconflow.cn/docs/userguide/quickstart)。
