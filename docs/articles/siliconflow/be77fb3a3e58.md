### [[服务调整] api.siliconflow.com 端点将被逐步淘汰](https://docs.siliconflow.cn/docs/release-notes/overview#service- adjustment-apisiliconflowcom-endpoint-to-be-phased-out)

为了更好地服务全球开发者用户，SiliconFlow即将推出国际站点并逐步开放多个服务区域。

由于此次调整，现有的 api.siliconflow.com API 端点将在适当的时间逐步淘汰。请尽快切换至api.siliconflow.cn继续使用服务。

我们已经为 .cn 端点配置了全局流量管理器 (GTM)，以提供与当前 .com 端点相同的全局访问体验。您只需将 API 请求的基本 URL 更改为 api.siliconflow.cn。

我们建议您在本月底（3 月 31 日）之前完成迁移。如果您有任何疑问，请随时联系我们。
