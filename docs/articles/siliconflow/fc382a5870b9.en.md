### [[Model Upgrade] DeepSeek-V4.1-Flash Upgraded to DeepSeek-V4.1-Flash-1017](https://docs.siliconflow.cn/docs/release-notes/overview#model-upgrade-deepseek-v41-flash-upgraded-to-deepseek-v41-flash-1017)

To further improve model service quality, the platform upgraded `deepseek-ai/DeepSeek-V4.1-Flash` to version `DeepSeek-V4.1-Flash-1017` on **2026-10-21**.

The model ID remains unchanged — requests to `deepseek-ai/DeepSeek-V4.1-Flash` are now served by the `1017` version, with no need to change the model name or your calling code.
