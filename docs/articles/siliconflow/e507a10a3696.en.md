### [[Model Service Adjustment] diffusiongemma Model in the systemone API to Be Discontinued](https://docs.siliconflow.cn/docs/release-notes/overview#model-service-adjustment-diffusiongemma-model-in-the-systemone-api-to-be-discontinued)

To further optimize resource allocation and provide more advanced and high-quality technical services, the `diffusiongemma` model in the systemone API (`/v1/systemone`) will be discontinued on **2026-10-17**.

From that date, requests specifying `model: diffusiongemma` will no longer be served. Other models of the systemone API (`Kev-4b`, `SemIf`) are not affected. If you are currently using `diffusiongemma`, it is recommended that you switch as soon as possible to avoid service disruptions.
