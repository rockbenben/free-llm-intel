### [【功能更新】推理模型 reasoning_content 字段分离](https://docs.siliconflow.cn/docs/release-notes/overview#功能更新推理模型-reasoning_content-字段分离)

推理模型思维链的展示方式，从之前的 `content` 中的 `<think></think>` 独立成单独的单独的 `reasoning_content` 字段，兼容 `OpenAI` 和 `deepseek` api 规范，便于各个框架和上层应用在进行多轮会话时进行裁剪。使用方式详见[推理模型（DeepSeek-R1）使用](https://docs.siliconflow.cn/docs/userguide/capabilities/reasoning)。
