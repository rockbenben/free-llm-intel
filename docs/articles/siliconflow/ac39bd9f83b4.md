2026.09.09

### [[API 服务调整] 聊天模型将忽略 repetition_penalty 参数](https://docs.siliconflow.cn/docs/release-notes/overview#api-service-adjustment-chat-models-will-ignore-the-repetition_penalty-parameter)

自 **2026-09-15** 起，发往聊天模型（`/v1/chat/completions`、`/v1/messages`）请求中传入的 `repetition_penalty` 参数将被忽略，服务端将按固定值 `1`（即不启用重复惩罚）处理。

此调整不影响其他采样参数（如 `temperature`、`top_p` 和 `top_k`）。如果您的业务此前依赖 `repetition_penalty` 调节生成结果，请提前评估影响。

2026.09.09

### [[API 服务调整] 图像生成 API：移除 batch_size 并默认添加明水印](https://docs.siliconflow.cn/docs/release-notes/overview#api-service-adjustment-image-generation-api-batch_size-removal-and-default-watermark)

为持续优化平台服务，`/v1/images/generations` 图像生成 API 将于 **2026-09-30** 进行以下调整：

- **移除 `batch_size` 字段**：请求体中不再支持 `batch_size` 字段。如果您此前依赖该字段在单次请求中生成多张图片，请改为发起多次请求。
- **图像生成 API 默认开启"AI 生成"明水印**：此变更适用于通过 API 发起的图像生成请求。API 生成的图像默认会添加"AI 生成"明水印，暗水印则始终添加。当且仅当开发者需要对生成图像进行进一步下游处理时，才应显式传入 `X-Enable-Watermark: 0` 以免除明水印；在此情况下，开发者负有法律义务自行在最终输出图像上添加相应的明水印。

如果您正在使用图像生成 API，请评估这些变更可能对业务造成的影响。
