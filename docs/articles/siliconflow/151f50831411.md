### [[API服务调整]图像生成API：batch_size去除和默认水印](https://docs.siliconflow.cn/docs/release-notes/overview#api-service- adjustment-image- Generation-api-batch_size-removal-and-default-watermark)

为持续优化平台服务，“/v1/images/ Generations”镜像生成接口将于**2026-09-30**进行如下调整：

- **`batch_size` 字段删除**：请求正文中将不再支持 `batch_size` 字段。如果您之前依赖此字段在单个请求中生成多个图像，请改为发出多个请求。
- **默认情况下为图像生成 API 启用显式“AI 生成”水印**：此更改适用于通过 API 发出的图像生成请求。默认情况下，显式“AI 生成”水印将添加到 API 生成的图像中，而隐式水印始终会添加。当且仅当开发人员需要对生成的图像执行进一步的下游处理时，他们才应显式传递“X-Enable-Watermark：0”以选择退出显式水印；在这种情况下，开发商有法律义务自行将相关的显式水印添加到其最终输出图像中。

如果您正在使用图像生成 API，请查看这些更改可能如何影响您的业务。
