今天，我们发布 Hy Image3.5 preview。它延续Hy Image3.0系列的设计思路，在文本渲染与布局、真实感与风格表现力、编辑一致性等方面显著提升提升，以极具吸引力的性价比为日常创作和专业视觉生产提供效果卓越的图像生成能力。经过上百名专业设计师GSB盲测对比上一代模型胜率综合提升30%以上。

Hy Image3.5 preview 支持文生图和图生图，单次最多可上传 5 张参考图，可基于历史上下文进行多轮创作和连续编辑，支持多种尺寸比例及最高 2K 分辨率输出。

# 面向专业创作的图像生成能力

从一张知识卡片到一套商业物料，创作对模型提出了更具体的要求：文字要准确，信息要有层次，光影和材质要自然，编辑还需要保持人物、商品与场景的一致性。Hy Image3.5 preview 围绕这些要求，对意图理解、视觉规划和生成过程进行了系统优化。

## 文本渲染与布局

Hy Image3.5 preview 进一步提升中英文文字，尤其是小字号文字的生成质量，并加强长文本、复杂版式和图文混排能力。在海报、知识卡片、信息图和 UI 设计中，模型能够结合内容组织标题、正文、图表和视觉元素，更好地响应字体、字号、字重及间距等排版要求。

**影视与创意生产**。 WorkRally 在漫剧工作室的使用中，重点验证了剧本道具、人物和场景资产的批量生成。团队反馈，模型能够满足较多指令遵循与人物一致性需求，减少反复尝试的成本。Miora 与 WorkBuddy 团队则在影视人物与场景、营销创意、信息图和游戏技能序列帧等任务中，观察到指令遵循、图像编辑与文字生成的提升。

**知识工作与视觉交付**。 ima 围绕配图、海报、信息图和图片编辑，与模型团队共同打磨 Copilot 的图像生成与编辑能力。团队反馈，模型在复杂指令理解、文字渲染、画面质量和美感方面表现更好，能够更稳定地衔接内容创作与视觉产物交付；相关生图功能的调用量已达到上线初期的 3 倍。

# 让专业生成更高效、更易用

专业创作往往需要多次修改和批量生成，成本与效率直接影响模型的实用价值。简化的架构结合高效蒸馏算法和文本与图像分支的解耦部署、注意力算子适配等系统优化，我们进一步提升推理资源利用率，为高性价比的图像生成提供基础。让Hy Image3.5 preview 具备了超高的性价比。
