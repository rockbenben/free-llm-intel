# 免费 LLM API 比较：速率限制、模型和实际成本 (2026)

OpenRouter ·6/15/2026 · 更新于 9/24/2026

你在做一个副业项目或早期应用，暂时不想为 LLM 调用付钱。你搜"free llm api"，然后被几十个自称免费的平台淹没。有些真有货；有些给一点试用水点，一个下午就烧光；还有几家拿你的提示词训练它们的下一代模型，还不明说。

OpenRouter 在 [70 多家 LLM 提供商](https://openrouter.ai/providers)之间路由流量，每月处理 100 万亿 token。因为它挡在这些提供商前面，它路由的就是它们服务的同一批模型——包括最快和上下文最长的那些。在下面做比较时，这一点值得记住。

## 太长不看

- 2026 年有 13 个平台提供可用的免费 LLM API 接入，其中几个是文本推理的永久免费档。限额和代价差别很大。
- [OpenRouter](https://openrouter.ai) 是很好的起点：20 多个免费模型、一个 API key、不要信用卡。
- 论原生速度，[Groq](https://groq.com) 的 LPU 硬件跑 Llama 3.3 70B 约每秒 320 token（[Artificial Analysis](https://artificialanalysis.ai/models/llama-3-3-instruct-70b/providers)）。论长上下文，[Google AI Studio](https://aistudio.google.com) 和若干开源模型可达 1M token。OpenRouter 两边都能路由到——一个 key 拿到，或者直连。
- 每个免费档都有隐性成本：速率限制、数据训练默认、缩水的上下文窗口、质量折损，都是这套游戏规则的一部分。
- 早点测 2 到 3 个选项并做好故障转移。它省下的麻烦比任何单一端点都多。

## 2026 年"免费 LLM API"到底意味着什么

免费 LLM 接入分三类。"免费"这个词被用得很宽松，混淆由此而来。

**永久免费档**：无需信用卡、无过期时间的长期接入，你只需要应付速率限制，别的没有。

**试用额度**：临时的营销赠品（$1 到 $30），几周后过期或要求绑定信用卡。适合一次性测试，不适合持续工作。

**本地推理**：把开放权重模型下载到自己的机器上，用 [Ollama](https://ollama.com) 或 vLLM 这类工具跑。装好之后没有按 token 费用，但硬件、电和维护归你。

从永久免费档（OpenRouter、Google AI Studio、Groq、Mistral、Cerebras）开始。试用额度适合一次性评估。本地推理在硬件到位时适合极限隐私和无限量。

## "免费" LLM API 的隐性成本

免费档不免费，只是成本从你的钱包转移到了隐私、性能或可靠性上。4 个取舍最要紧。

**数据训练默认**是最大的隐私问题。不在 EU/UK/EEA 的话，Google 会拿你的提示词改进模型。Mistral 的 Experiment 档要求同意训练才能拿 1B token/月 的配额。处理专有代码、客户数据或任何机密内容时，这些政策制造出的合规风险，事后整改的代价比今天买个付费档贵。

**缩水的上下文窗口**会让人措手不及。有些提供商在免费端点上给的上下文窗口比同一模型的付费方案小——于是长对话被截断、RAG 系统丢上下文、文档分析做到一半失败。请查你实际使用的那个免费端点的上下文长度，而不是模型的宣传数字。

**更低的量化**更隐蔽。为控成本，一些平台在免费档上服务的是量化权重（比如 8-bit 或 4-bit）而不是全精度版本。精度降低可能在复杂任务上折损输出质量，在意准确性就查量化等级。OpenRouter 在每个端点上列出量化方式。

**没有 SLA** 等于零承诺。免费档可以随时收紧速率限制、在高峰期变慢、完全宕机且无任何补偿。个人项目可接受，任何面向客户的东西都有风险。

IP 封锁和反滥用也常见。很多平台会强硬地封锁 VPN、共享主机 IP 或数据中心网段。在某些环境里开发，你可能在被封锁的状态下直到升级或换服务。

敏感工作的更安心默认：政策明确不训练的服务（OpenRouter、Groq、Cerebras），或者用 Ollama 在本地跑模型。

## 你该用哪个免费 LLM API？

没有普适最佳的免费 LLM API。正确选择取决于你当下的主要约束。

**长文档分析或研究。** Google AI Studio 在 Gemini Flash 上的 1M token 上下文能整本书、大代码库或长 PDF 直接吞，不用激进分块，而且 Gemini 还吃多模态输入（图像、音频）。OpenRouter 上也有免费 1M 上下文模型（例如 Qwen3 Coder），路由即可，不必直接集成 Google。

**速度敏感应用（语音、实时聊天）。** Groq 的专用 LPU 硬件跑 Llama 3.3 70B 约每秒 320 token（[Artificial Analysis](https://artificialanalysis.ai/models/llama-3-3-instruct-70b/providers)）。可以直连 Groq，也可以经 OpenRouter 路由。

**编码助手与开发者工具。** Mistral Codestral 在 Experiment 档上有每月 1B token 的预算，为代码生成和重构优化。想在 agent 里用免费模型，可以通过 OpenRouter[给 OpenClaw 配免费模型](https://openrouter.ai/blog/tutorials/openclaw-openrouter/)或[在 Kilo Code 里跑免费模型](https://openrouter.ai/blog/tutorials/kilo-code-openrouter/)。

**复杂推理任务。** 用 DeepSeek 试用额度跑 DeepSeek R1——它就是为多步推理、数学解题和逻辑推导造的。

**高量批处理。** Cerebras 每天约 1M token，够批量清洗数据、做摘要、跑离线负载——这些活儿在别处会直接撞上速率限制。

**一个 key 要最大模型多样性。** [OpenRouter](https://openrouter.ai) 用一个 OpenAI 兼容端点给你多家提供商的 20 多个免费模型，单个提供商限流时自动故障转移。

**带故障转移的生产级。** OpenRouter 加一笔 [$10 充值](https://openrouter.ai/credits)，免费模型日上限提到 1,000 次请求，任一底层提供商退化时在提供商之间自动转移。

**隐私优先或 EU 合规。** [Scaleway](https://www.scaleway.com) 提供欧洲托管、GDPR 对齐的数据处理。或者用 Ollama 本地跑。

有些坦白值得说。直连提供商给你完整的原生免费额度和提供商特性——比如 Google AI Studio 的基于文件 RAG、Mistral 更大的月度 token 配额。OpenRouter 路由到同样的提供商，速度和上下文对得上，但它自己的免费档有独立请求上限，统一端点也不会暴露每个原生特性。需求窄而明确时，直连意味着更少限制；要多样性、故障转移和一份集成时，路由器赢。

## 快速上手：60 秒发出第一个免费 LLM API 调用

本指南多数服务用 OpenAI 兼容 API，意味着同一份代码换一下 base URL 和 API key 就能通用。以下以 OpenRouter 为主要示例展示这个模式。

用 [OpenRouter SDK](https://openrouter.ai/docs/sdks)（推荐）：

```
from openrouter import OpenRouter

client = OpenRouter()

response = client.chat.send(
    model="meta-llama/llama-3.3-70b-instruct:free",
    messages=[{"role": "user", "content": "Explain rate limiting in one sentence."}],
)

print(response.choices[0].message.content)
```

```
import { OpenRouter } from '@openrouter/sdk';

const openRouter = new OpenRouter();

const response = await openRouter.chat.send({
  model: 'meta-llama/llama-3.3-70b-instruct:free',
  messages: [{ role: 'user', content: 'Explain rate limiting in one sentence.' }],
  stream: false,
});

console.log(response.choices[0].message.content);
```

或者通过 OpenAI SDK 换 base URL（对所有 OpenAI 兼容提供商通用）：

```
curl https://openrouter.ai/api/v1/chat/completions \
  -H "Authorization: Bearer $OPENROUTER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "meta-llama/llama-3.3-70b-instruct:free",
    "messages": [{"role": "user", "content": "Explain rate limiting in one sentence."}]
  }'
```

用 OpenRouter 不需要换 base URL 去够不同的提供商。端点和 API key 不变，改 `model` 字符串就能路由到别处。想让同一个提示词跑在 1M 上下文模型或另一个模型家族上，换 slug 即可：

```
# Llama 3.3 70B
model="meta-llama/llama-3.3-70b-instruct:free"

# Qwen3 Coder, 1M token context
model="qwen/qwen3-coder:free"

# OpenAI gpt-oss 120B
model="openai/gpt-oss-120b:free"
```

有些提供商在你直连时并不完全遵循 OpenAI API schema。例如 Google 的 Gemini 模型给到 1M token 上下文，但直连集成需要 Google 原生 SDK。OpenRouter 把这些差异归一化在那一个端点之后，同一份代码按 slug 就能到达它们。

## 免费额度用完后会发生什么

下午 2 点你撞上每日上限，应用停止响应。过渡路径取决于你从哪里开始。

**OpenRouter。** 充一笔[$10 最低额度](https://openrouter.ai/credits)，免费模型日上限升到 1,000 次。OpenRouter 按提供商每 token 单价加 5.5% 平台费收取，提供商价格无额外加价——付费用量贴近直连价格，同时保住故障转移和单 key 的好处。开始付费后，[如何在 OpenRouter 上获得最低成本 LLM 推理](https://openrouter.ai/blog/tutorials/how-to-get-the-lowest-cost-llm-inference-on-openrouter/)讲那些把账单压低的设置。

**Google AI Studio。** 切到 Gemini 的按量付费；Flash 档不贵，Google 的[定价页](https://ai.google.dev/gemini-api/docs/pricing)列着当前每 token 费率。

**Groq。** 迁到 Groq 的付费按量[定价](https://groq.com/pricing)，同一个 OpenAI 兼容端点上提高速率限制。切换前查当前每 token 费率。

**Mistral。** Experiment 档（免费、同意数据训练）按标准每 token 费率过渡到 Production 档（付费、不训练）。

最有韧性的配置是多种战术的组合，而不是吊死一个端点：

- **标准化并配故障转移。** 在主、备两个 OpenAI 兼容提供商之间用换 base URL 的模式（例如 OpenRouter 主、Groq 备）。核心代码保持干净，撞上速率限制时应用自动换端点。
- **为专项能力走路由。** 任务需要超长上下文窗口时，把那个请求用 Google 原生 SDK 发给 Google AI Studio。拿到 1M token 窗口，又不用让整个技术栈去迁就非标准 schema。
- **为稳定小额投入。** 给 OpenRouter 或类似网关充 $10 额度，高峰期有稳定、不被掐的表现为底线。
- **卸载给本地推理。** 负载成长后，把后台批处理和非实时任务转向用 Ollama 跑的本地模型。

一个实际的故障转移示例：

```
import os
from openai import OpenAI


def call_llm(prompt: str, max_tokens: int = 500):
    providers = [
        {
            "name": "OpenRouter",
            "base_url": "https://openrouter.ai/api/v1",
            "key": os.environ.get("OPENROUTER_API_KEY"),
            "model": "meta-llama/llama-3.3-70b-instruct:free",
        },
        {
            "name": "Groq",
            "base_url": "https://api.groq.com/openai/v1",
            "key": os.environ.get("GROQ_API_KEY"),
            "model": "llama-3.3-70b-versatile",
        },
    ]

    for provider in providers:
        if not provider["key"]:
            continue
        try:
            client = OpenAI(api_key=provider["key"], base_url=provider["base_url"])
            response = client.chat.completions.create(
                model=provider["model"],
                messages=[{"role": "user", "content": prompt}],
                max_tokens=max_tokens,
            )
            print(f"Success via {provider['name']}")
            return response
        except Exception as e:
            print(f"{provider['name']} failed: {e}")
            continue

    raise Exception("All providers failed")
```
