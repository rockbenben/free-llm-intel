多项呼声很高的开发者功能刚刚上线——让 OpenRouter 更顺滑、更聪明、开发更快：

## 🖼️ 跨模型 GIF 支持

现在可以向 OpenAI、Gemini、Anthropic 和 Llama 模型发送 image/gif 提示。
无需预先转换——直接发送你的动图即可。

## 🔍 Omni-Search 支持服务商页面

按下 ⌘/Ctrl + K，输入任意服务商名称，即可直达其页面，查看可用模型、定价和可用性。

## ⚡ Anthropic 工具调用缓存

与 Anthropic 的 tool calls 现在支持缓存——显著降低延迟和 token 用量。

## 🔑 用量中的 `is_byok` 标记

当你在请求中带上 `"usage": { "include": true }` 时，响应现在会包含一个 `is_byok` 标记。
这有助于确认是否使用了 BYOK（自带密钥）配置。
