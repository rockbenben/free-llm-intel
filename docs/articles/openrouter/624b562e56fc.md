我们与 [Stripe Projects](https://projects.dev/) 合作，让你的 coding agent（或你自己）可以从命令行开通 OpenRouter 账户。一条命令即可完成账户创建、API key 生成、通过 Stripe 接好账单，并把凭证写入你的 `.env`。无需打开浏览器，你的应用就能调用 400+ 文本、图像、视频和音频模型。

首先需要[安装 Stripe CLI](https://docs.stripe.com/stripe-cli/install)，然后运行：

```
stripe projects add openrouter/api
```

![Stripe Projects CLI provisioning OpenRouter](https://openrouter.ai/blog/images/stripe-projects-capture.png)

## 账户自动开通，并签发 API key

Stripe Projects 处理完整的开通流程：

- **创建账户。** 新建一个 OpenRouter 账户并与你的 Stripe 身份绑定。如果你已有 OpenRouter 账户，也可以选择连接现有账户。
- **生成 API key。** 生成一把新密钥并存储在你项目的加密保险库（`.projects/vault/vault.json`）中，然后同步到 `.env` 里作为 `OPENROUTER_API_KEY`。
- **配置账单。** 把你的 Stripe 支付方式绑定到 OpenRouter 账户。你可以从免费层开始（无需信用卡），也可以直接进入按 token 计费的 pay-as-you-go 模式，覆盖所有模型。

没有注册表单，没有仪表盘点击，不需要在标签页之间复制密钥。

## 让你的 coding agent 开通账户

如果你在用 coding agent 开发，你的 agent 已经会写代码、装包、配置服务。唯一做不到的，是创建这些服务所需的账户。

凭证被安全存储并以项目为作用域，因此不存在 agent 跨环境泄露密钥的风险。

## 关联已有账户

已经在用 OpenRouter？不必每次都开新账户。运行命令时，你可以选择关联现有的 OpenRouter 账户而不是新建。你当前的 API key 和计费保持原样；CLI 只是把一切接入你的 Stripe Projects 配置，让凭证管理更轻松。

## 一个 CLI 管理你的整个技术栈

OpenRouter 是 Stripe Projects 目前 20+ 服务商之一。你可以用一个工具接好整个应用栈：

```
stripe projects init my-app
stripe projects add clerk/auth
stripe projects add posthog/analytics
stripe projects add openrouter/api
```

所有凭证同步到 `.env`，所有账单走你的 Stripe 账户。而且全部可在命令行完成——不管是你亲手敲命令，还是你的 agent 在敲。

在 [projects.dev/providers](https://projects.dev/providers/) 浏览完整服务商目录。

每个 project 都是一份轻量清单，记录你的应用所需的服务、服务商账户和凭证，全部由 Stripe 支撑。这套配置在多台机器和多个成员之间可重复：新人入职或换笔记本，只需 `stripe projects env --pull`，不用再翻 Slack 消息和旧 `.env` 文件寻宝。凭证始终可审计、作用域清晰，agent 和人都基于同一个事实来源工作。

## 开始上手

- 安装 [Stripe CLI](https://docs.stripe.com/stripe-cli) 和 Projects 插件：`stripe plugin install projects`
- 运行 `stripe projects add openrouter/api`
- 选择一个层级（免费或按量付费），开始调用模型
