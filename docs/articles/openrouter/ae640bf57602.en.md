# Can Claude Generate Images? Yes, with a Connector

OpenRouter ·11/23/2026

![Can Claude Generate Images? Yes, with a Connector](https://openrouter.ai/blog/images/can-claude-generate-images.png)![Can Claude Generate Images? Yes, with a Connector](https://openrouter.ai/blog/images/can-claude-generate-images-dark.png)

Claude cannot generate images on its own, because it has no image model. With a connector, it can call an image model and hand you the finished picture.

You give a short request, and Claude writes the detailed prompt and shows it to you before anything is billed. When the picture comes back, Claude can look at the result and check it against what you asked for. This post uses the OpenRouter MCP server as the connector, which reaches 74 image models from different labs as of November 19, 2026.

If you only want the setup, skip to [How to make images in Claude with a connector](https://openrouter.ai/blog/tutorials/can-claude-generate-images/#how-to-make-images-in-claude-with-a-connector).

## Tl;dr

- Claude has no image model of its own. A connector lets it call one and return a real picture.
- Add `https://mcp.openrouter.ai/mcp` as a connector in the Claude app or Claude Code. Nothing is installed on your computer.
- Name the model you want in your request, or ask Claude to compare models for your job first, which is not billed.
- Our test images cost between $0.035 and $0.10 each on November 19, 2026, and you approve each one before it is charged.
- The picture arrives either in the chat or as a link that works for 24 hours.

## Can Claude generate images?

Claude cannot generate photos or illustrations on its own. Anthropic’s March 16, 2026 [Help Center article](https://support.claude.com/en/articles/9002504-can-claude-produce-images) says “Claude doesn’t generate photos or illustrations the way image-generation tools do” and notes that it builds diagrams and charts with HTML and SVG. Its [vision documentation](https://platform.claude.com/docs/en/build-with-claude/vision) adds: “Claude is an image understanding model only. It can interpret and analyze images, but it cannot generate, produce, edit, manipulate, or create images.”

A connector is Claude’s word for an MCP server added to the app. The [OpenRouter MCP server](https://openrouter.ai/docs/guides/overview/mcp-server) is one connector, and it reaches every model in the [OpenRouter image catalog](https://openrouter.ai/models?output_modalities=image).

## What does Claude do with an image model?

The image model draws, and Claude does the work around the drawing. With an image tool on its own, that surrounding work is the hard part: you write the detailed prompt yourself, and once the picture arrives you check it against your request and carry the file to where it belongs.

In Claude, a short request is enough, because Claude writes the detailed prompt. Name the model you want, for example: “Can you generate an image of a red fox reading a paperback under a streetlamp on a snowy night, in soft watercolor? Use Seedream 5.5.” In our run, Claude expanded that line into a longer prompt. Claude asks for approval before each image, and that approval shows the model and the prompt it wrote, so you can read it before anything is billed.

![Claude Desktop approval card reading "Claude wants to use Generate an image from OpenRouter", showing the model, the prompt and the Deny, Allow for this task and Allow once buttons.](https://openrouter.ai/blog/images/can-claude-generate-images-approval.jpg)

Claude can also look at the result. When the image came back in our Claude app run, Claude had seen the picture and described it.

![Claude Desktop showing a generated watercolor of a red fox reading under a streetlamp in the snow, opened full size inside the app.](https://openrouter.ai/blog/images/can-claude-generate-images-claude-app.jpg)

In our Claude Code run, Claude opened the saved file and reported that the book was a green hardback where we had asked for a paperback. When that happens, a mismatch gets caught without you comparing the picture to your request yourself. When you ask for a change, Claude can pass the first image back to the model as a reference, and in our run the rest of the scene stayed the same. See [Can Claude edit an image it generated?](https://openrouter.ai/blog/tutorials/can-claude-generate-images/#can-claude-edit-an-image-it-generated) for details.

## How to make images in Claude with a connector

Add the OpenRouter MCP server as a custom connector. It is a remote server, so nothing is installed on your computer. You need an OpenRouter account with credits.

In the Claude app:

- Open Settings > Connectors and add a custom connector.
- Name it `OpenRouter MCP` and set the remote MCP server URL to `https://mcp.openrouter.ai/mcp`. Leave the OAuth fields blank.
- Add the connector, then connect it. An OpenRouter consent page opens in your browser.
- Approve the dedicated key for this connection. It expires within 7 days, and you can disconnect at any time.

Some organizations do not allow custom connectors, so this option may be missing on a work account.

In Claude Code, run:

```
claude mcp add --transport http openrouter https://mcp.openrouter.ai/mcp
claude mcp login openrouter
```

The [OpenRouter MCP server guide](https://openrouter.ai/docs/guides/overview/mcp-server) has the click-by-click steps for each client.

## What does it cost?

Each image costs the price of the model that makes it, which was $0.035 to $0.10 in our runs on November 19, 2026. Claude’s own usage is separate.

Aspect ratio and resolution change the price. GPT Image 2.6 Flare cost $0.058 at 16:9 against $0.094 at 1:1, and FLUX 3 Image cost $0.10 at 16:9 and 2K resolution (2736×1536).

The connector’s key starts with a $10 spend cap that you can edit on the consent screen. In our runs Claude also repeated each image’s cost in its reply.

## Why does the image sometimes come back as a link?

The `generate-image` tool returns a link when one can be issued, and the image itself otherwise. A link opens in any browser, without signing in, for 24 hours.

In the Claude app, an image shows in the chat and Claude can see it. A link opens in your browser, and in our run Claude had not seen that picture and could not show it in the chat. In Claude Code, a link is the easier case, because the image downloads straight into your project. An image that comes back directly stays in Claude Code’s own folder until you approve copying it.

Which one you get varied between requests, even for the same model. In our small set of runs on November 19, 2026, Seedream 5.5 returned the image itself 4 of 4 times, GPT Image 2.6 Flare returned a link 3 of 4 times, FLUX 3 Image returned a link 2 of 2 times, and Nano Banana 2.1 returned each once. If you want the picture inside the Claude app, Seedream 5.5 did that every time for us. If you get a link, open it.

## Can Claude Code generate images?

Yes. Claude Code generates images with the same connector and puts them straight into your project. Say where to save the file and which page uses it, for example: “This landing page needs a hero illustration. Use OpenRouter to generate one: a red fox reading a paperback under a streetlamp on a snowy night, soft watercolor style. Save it to assets/hero.png and add it to index.html.”

In our run, Claude Code saved a 2736×1536 illustration from FLUX 3 Image at that path and added it to the page. For the full recipe, follow the cookbook [Generate and Edit Images from Claude Code](https://openrouter.ai/docs/cookbook/coding-agents/generate-images-in-claude-code).

## Can Claude edit an image it generated?

Yes, when the first result came back as a link and the model accepts image input. Claude passes that link back to the model as a reference, along with the changes you asked for.

In our Claude Code session, we asked for a red scarf on the fox and a paperback with a plain red cover, saved over the same file. Claude sent the first image back to FLUX 3 Image, and both changes appeared while the rest of the scene stayed the same.

![Two versions of a watercolor fox illustration side by side: the first request, and the same scene after a follow-up request added a red scarf and a red book.](https://openrouter.ai/blog/images/can-claude-generate-images-claude-code-edit.jpg)

Without a link, Claude cannot reuse the picture. In the Claude app, after a result that came back as the image itself, asking for a red scarf produced a new picture from a description. The scene changed, and Claude said so.

## Frequently asked questions

### Can Claude create real images?

Not on its own. Without a connector, Claude builds diagrams and charts in HTML and SVG. With a connector such as the OpenRouter MCP server, it calls an image model and returns a real picture.

### Why can’t Claude generate images?

Claude has no image generation model. Anthropic’s documentation describes it as “an image understanding model only”, so it can read the pictures you give it, and drawing one takes a separate image model, which a connector provides.

### Does Claude generate images like an image generator does?

No. The image model draws, and Claude writes the prompt from your request and can check the result.

### Can Claude generate videos?

We did not test video for this post. The OpenRouter MCP connector also has `generate-video`, `generate-speech` and `transcribe-audio` tools, and they come with the same setup.
