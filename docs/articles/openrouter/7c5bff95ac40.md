我们经常看到大家为了在自己喜欢的 harness 里用上 OpenRouter，不得不写[临时脚本](https://x.com/xlr8harder/status/2081834210445152438)或复杂配置才能调到刚刚好。有些 harness 只需极少的配置，也许就一个环境变量；但像 Claude Code 这样的则需要设置得多得多。

现在你可以安装 [ori CLI](https://openrouter.ai/ori/harness)，用 OpenRouter 登录，开箱即得一份针对所有你喜欢的 harness 优化好的配置：

```
# Install ori cli
curl -fsSL https://openrouter.ai/labs/ori/install.sh | bash

ori login # Log in to OpenRouter

# Set up and optimized for OpenRouter
ori claude
ori codex
ori opencode
ori hermes
# ... more to come
```

## 我自己改几个设置不就行了，为什么还需要这个？

使用 OpenRouter 这类网关时，要想在 Claude Code 里获得与 Anthropic 第一方 harness 相同的开箱体验，需要设置*大量*环境变量……

```
ANTHROPIC_BASE_URL=https://openrouter.ai/api
ANTHROPIC_AUTH_TOKEN=<openrouter-api-key>
ANTHROPIC_API_KEY=
OPENROUTER_API_KEY=<openrouter-api-key>
CLAUDE_CODE_SKIP_FAST_MODE_ORG_CHECK=1
CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1
ENABLE_TOOL_SEARCH=true
CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=1
ANTHROPIC_DEFAULT_HAIKU_MODEL=~anthropic/claude-haiku-latest
ANTHROPIC_DEFAULT_SONNET_MODEL=~anthropic/claude-sonnet-latest
ANTHROPIC_DEFAULT_OPUS_MODEL=~anthropic/claude-opus-latest
ANTHROPIC_DEFAULT_FABLE_MODEL=~anthropic/claude-fable-latest[1m]
ANTHROPIC_DEFAULT_FABLE_MODEL_NAME=Fable
```

对 Anthropic 模型，开启 `ENABLE_TOOL_SEARCH` 能为你省下近一半 system prompt 的 token，这也是现代 Claude 模型的默认设置……*前提是 Claude Code 识别出第一方 harness*。

Tool search 还会实质性地改变 agent 的行为：禁用 tool search 时，Claude 会用更多 token、更多轮次来完成同一任务，而且更多地使用 Todo 工具！

但如今大多数开放模型根本不支持 tool search。在 `ori claude` 中，我们会检测你的 `--model` 参数，并把设置切换为你所用模型的最优组合。未来我们计划更进一步，根据模型优化工具设置、system prompt 冗长度等更多方面。

Claude Code 是一个特别棘手的例子，但我们会为许多 harness 优化 ori harness。目前支持：

- Claude Code
- Codex
- OpenCode
- Hermes
