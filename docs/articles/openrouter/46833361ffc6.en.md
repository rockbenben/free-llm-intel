# The First-Ever Image Model Is Up on OpenRouter

OpenRouter ·8/26/2025 · Updated 6/24/2026

## 🍌 Gemini 2.5 Image Preview is Live

We’ve just launched the **first-ever image model** on OpenRouter: Gemini 2.5 Flash Image Preview.
 This model combines the intelligence of LLMs with the visual quality of diffusion models — unlocking workflows like:

- Generating pages of a website
- Making comic panels with consistent characters
- Creating logo iterations in bulk

![Preview Sample](https://openrouter.ai/cdn-cgi/imagedelivery/Xq3eUzdKO2-MoBklzEEuMQ/63129492-1473-432c-5bc6-2a67423e3200/public)

### Features

- State-of-the-art image generation and editing
- Incredible character consistency across scenes
- Can generate multiple images in a single call
- 32k context length

![Multiple Images](https://openrouter.ai/cdn-cgi/imagedelivery/Xq3eUzdKO2-MoBklzEEuMQ/d34a2d00-da22-43de-e84f-17331cf28600/public)

Use it for just **$0.30 per million input tokens** → [Try it here](https://openrouter.ai/google/gemini-2.5-flash-image-preview)

We’re proud to be a launch partner with Google DeepMind. Learn more in the [Gemini 2.5 Flash Image blog post](https://developers.googleblog.com/en/introducing-gemini-2-5-flash-image/) from Google DeepMind.
