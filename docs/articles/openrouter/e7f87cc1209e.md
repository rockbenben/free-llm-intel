## 可用性（Uptime）追踪 API

现在可以通过新的 OpenRouter API 端点以编程方式追踪模型可用性。详情：[https://x.com/OpenRouterAI/status/1937869909448441980](https://x.com/OpenRouterAI/status/1937869909448441980)

## BYOK 改进

为 Bring Your Own Key 用户带来多项体验升级：

- 保存密钥前可以先测试
- 按密钥限制上游用量
- 在 API 响应中通过 `"is_byok": true` 追踪用量

更多细节：[https://x.com/OpenRouterAI/status/1937872903988535400](https://x.com/OpenRouterAI/status/1937872903988535400)
