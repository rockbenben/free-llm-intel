# OpenRouter 现在支持Hugging Face推理

萨莎·布卢门菲尔德·11/16/2026

![OpenRouter 现在支持Hugging Face部推理](https://openrouter.ai/blog/images/hugging-face-inference-providers.jpg)![OpenRouter 现在支持Hugging Face部推理](https://openrouter.ai/blog/images/hugging-face-inference-providers-dark.jpg)

我们构建了 OpenRouter，以便开发人员可以通过一个 API 访问许多模型和提供者，为每项任务使用最佳模型，并依靠它来响应。从今天开始，这将延伸到所有使用 Hugging Face 进行开发的人。 Hugging Face Inference Providers 上的聊天模型现在通过 OpenRouter 运行，跨提供商的路由与 OpenRouter 客户已经依赖的相同。

集成也以另一种方式运行。 OpenRouter 现在可以将每个请求的跟踪发送到您拥有的 Hugging Face 存储桶，因此来自真实流量的提示和响应位于您用来评估或微调的模型和数据集旁边。 [设置指南](https://openrouter.ai/docs/guides/features/broadcast/hugging-face) 有步骤。

![Hugging Face 模型页面上的推理提供程序小部件回答聊天消息，带有“由 OpenRouter 提供支持”标签](https://openrouter.ai/blog/images/hugging-face-inference-providers/inference-widget.gif)

## 你在 Hugging Face 上能得到什么

Hugging Face 上的许多聊天模型由多个提供商提供服务。 OpenRouter 的提供商路由现在支持 Hugging Face Inference Provider 上的路由，并根据实时价格、速度和可靠性为每个请求选择提供商。您无需进行任何设置，现有的 Hugging Face 令牌和代码就可以继续工作。

您还可以获得自动故障转移。如果某个提供程序速度变慢或开始出现故障，请求将发送至其他提供程序，直到其恢复。如果提供程序返回错误，则会在同一调用中的下一个请求中重试该请求。

当我们 [10 月份重建此路由](https://openrouter.ai/blog/how-we-rebuilt-provider-routing) 时，现场实验测量到，遇到容量错误的请求减少了 46%，获得第一个令牌的时间缩短了 16.9%，吞吐量提高了 16.3%，每个请求的成本提高了 6.0%。现在，每个在 Hugging Face 上构建的人都会获得相同的路由。

您可以掌控权衡。向模型 ID 添加后缀，例如“:fastest”、“:cheapest”或提供程序名称，告诉 OpenRouter 优先考虑什么，并通过 OpenAI 的聊天完成和响应 API 或 Anthropic 的消息 API 请求工作。对话也会保留在保存其提示缓存的提供者上。

每个模型页面都有一个新的“提供商”选项卡，其中包含每个提供商的实时价格、速度和正常运行时间。您可以按提供商查看您的支出，并关闭任何您不想使用的提供商。

## 您的痕迹可以存在于 Hub 上

添加 Hugging Face Storage Buckets 作为广播目标（处于测试阶段），OpenRouter 将每个请求作为 JSON 文件发送到您拥有的存储桶。每个文件都保存输入消息、模型的输出、令牌计数和成本。图像和其他媒体被排除在外。

这是评估集或开放权重模型微调运行的原材料。您可以按日期或 API 密钥组织文件。

![OpenRouter 可观测性设置中的新 Hugging Face Storage Buckets 目标表单，其中包含命名空间、存储桶名称、访问密钥 ID 和秘密访问密钥字段。](https://openrouter.ai/blog/images/hugging-face-inference-providers/storage-buckets-destination.png)

## 开始吧

Hugging Face上：

- 使用“调用推理提供商”权限在 [hf.co/settings/tokens](https://hf.co/settings/tokens) 创建令牌。
- 在 Hub 上打开任何支持型号的页面。在那里与它聊天，或者单击“查看代码”以了解您的代码或编码代理的设置步骤，包括 Claude Code、Codex、OpenCode、Pi 和 Hermes Agent。
- 要选择哪些提供商可以满足您的请求，请转到 Hugging Face 设置中的 [推理提供商](https://huggingface.co/settings/inference-providers)。

要将跟踪发送到存储桶：

- 在Hugging Face上创建一个存储桶。
- 创建具有写入权限的访问令牌并从中生成 S3 凭证。
- 在 OpenRouter 中，进入【设置 > 可观察性】(https://openrouter.ai/settings/observability)，打开广播，然后打开Hugging Face存储桶。
- 输入您的命名空间、存储桶名称、访问密钥 ID 和秘密访问密钥。诸如“{apiKeyName}/{date}”之类的路径模板是可选的。
- 单击“测试连接”，然后保存。

[完整设置指南](https://openrouter.ai/docs/guides/features/broadcast/hugging-face)涵盖了路径模板和跟踪文件格式。

[在 Hugging Face Playground 中尝试模型](https://huggingface.co/playground)，或[将痕迹发送到存储桶](https://openrouter.ai/docs/guides/features/broadcast/hugging-face)。
