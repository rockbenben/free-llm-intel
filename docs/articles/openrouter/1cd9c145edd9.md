# DeepSeek V4 有视觉能力吗？

DeepSeek V4 不是一个模型。在我们的目录里它是一个家族，包括 V4.1 Flash、V4 Pro 0813、V4 Flash 0731、V4 Flash Vision Exp、两个较早的 0423 检查点，以及一个 Flash「latest」别名。名字告诉你的档位和发布版本，但不告诉你能不能喂图像。

本指南逐个过一遍家族成员，使用我们目录中的确切 slug，并展示两种在图像上用 V4 的方式。第一种把图像发给会读图的 V4 模型；第二种在纯文本 V4 模型前面跑一个独立的视觉模型。

## 按模型给出的简短答案

两个 V4 模型接受图像。[DeepSeek V4.1 Flash](https://openrouter.ai/deepseek/deepseek-v4.1-flash) 原生读图，是新的图像任务应选用的模型。[DeepSeek V4 Flash Vision Exp](https://openrouter.ai/deepseek/deepseek-v4-flash-vision-exp) 也读图，DeepSeek 将其标注为实验性。

我们目录上其余所有 V4 slug 都是文本进、文本出。包括 [V4 Pro 0813](https://openrouter.ai/deepseek/deepseek-v4-pro-0813)、[V4 Flash 0731](https://openrouter.ai/deepseek/deepseek-v4-flash-0731)、两个 0423 检查点，以及 [`~deepseek/deepseek-v4-flash-latest`](https://openrouter.ai/~deepseek/deepseek-v4-flash-latest) 别名。向这些模型发送带 `image_url` part 的请求会失败，因为它们的输入模态列表里没有 `image`。

## 有哪些 V4 模型、分别接受什么

下表列出我们目录中每个 V4 模型，模态一列直接回答问题。价格为 2026 年 9 月 29 日目录标价的每百万 token 费率，小数位多于三位的四舍五入到三位。

| 模型 | Slug | 输入 | 价格 输入/输出 | 上下文 | 图像输入 |
| --- | --- | --- | --- | --- | --- |
| V4.1 Flash | `deepseek/deepseek-v4.1-flash` | 文本、图像 | $0.30 / $1.20 | 1,048,576 | 是 |
| V4 Flash Vision Exp | `deepseek/deepseek-v4-flash-vision-exp` | 文本、图像 | $0.216 / $0.647 | 1,048,576 | 是，实验性 |
| V4 Pro 0813 | `deepseek/deepseek-v4-pro-0813` | 文本 | $0.395 / $3.490 | 1,048,576 | 否 |
| V4 Flash 0731 | `deepseek/deepseek-v4-flash-0731` | 文本 | $0.018 / $0.320 | 1,310,720 | 否 |
| V4 Pro 0423 | `deepseek/deepseek-v4-pro` | 文本 | $0.928 / $1.856 | 1,048,576 | 否 |
| V4 Flash 0423 | `deepseek/deepseek-v4-flash` | 文本 | $0.076 / $0.153 | 1,048,576 | 否 |

两个 0423 slug 没有日期后缀。`deepseek/deepseek-v4-pro` 和 `deepseek/deepseek-v4-flash` 是 2026 年 4 月的 V4 首发版本，只有后来的检查点才在 slug 中带日期。

六款模型都只返回文本。每个模型页面列出当前的价格、上下文长度和输入模态，这些值会随 provider 和检查点变化。把 slug 定进生产之前先读页面。

`~deepseek/deepseek-v4-flash-latest` 别名会重定向到 V4 Flash 家族中最新的模型。写作时它解析到 Flash 0731，且输入模态只列文本。不要用该别名发图像请求。请直接固定 `deepseek/deepseek-v4.1-flash` 或 `deepseek/deepseek-v4-flash-vision-exp`。

## V4.1 Flash 原生读图

[DeepSeek V4.1 Flash](https://openrouter.ai/deepseek/deepseek-v4.1-flash) 是首个基于 DeepSeek Causal Encoder-Decoder 架构构建的模型。它在 552B 参数骨干上，输入侧激活 8B 参数、输出侧激活 16B。图像理解是架构的一部分，视觉与文本 embedding 从预训练一开始就联合训练。它有 1,048,576-token 上下文窗口，DeepSeek 端点上最大输出 384,000 tokens，并支持 tool calling、`response_format` 和结构化输出。

带图像调用它的请求，就是你平时发的 chat 请求，只需在消息 content 里加一个 image part。TypeScript SDK 把请求体嵌在 `chatRequest` 下并使用 camelCase 字段名，因此图像 part 在 SDK 里是 `imageUrl`，在线上是 `image_url`。

```
import { OpenRouter } from "@openrouter/sdk";

const openRouter = new OpenRouter({
  apiKey: process.env.OPENROUTER_API_KEY,
});

const result = await openRouter.chat.send({
  chatRequest: {
    model: "deepseek/deepseek-v4.1-flash",
    messages: [
      {
        role: "user",
        content: [
          { type: "text", text: "What error state is this screenshot showing?" },
          { type: "image_url", imageUrl: { url: "https://example.com/screenshot.png" } },
        ],
      },
    ],
    stream: false,
  },
});

if (!("choices" in result)) {
  throw new Error("Expected a non-streaming response");
}

console.log(result.choices[0]?.message.content);
```

`url` 字段接受公开图像 URL 或 base64 data URL。先发文本 part 再发图像 part。base64 形式、支持的图像类型、以及一次请求发多张图，见 [图像输入指南](https://openrouter.ai/docs/guides/overview/multimodal/image-understanding)。

## V4 Flash Vision Exp 是实验性选项

[DeepSeek V4 Flash Vision Exp](https://openrouter.ai/deepseek/deepseek-v4-flash-vision-exp) 是 V4 Flash 0731 的实验性视觉版本。它增加了图像理解，同时在文本任务上与基础模型保持一致。它于 2026 年 8 月 21 日发布，在 2026 年 9 月 10 日 V4.1 Flash 上线之前，它是唯一接受图像的 V4 模型。

它与上面示例接受完全相同的请求，只需把 `model` 字段改为 `deepseek/deepseek-v4-flash-vision-exp`。它有 1,048,576-token 上下文窗口，支持 tool calling、`response_format` 和结构化输出。

DeepSeek 把这个模型标注为实验性。除非你有特定原因要测试实验模型，否则新的图像任务用 V4.1 Flash；真要测就固定确切的 slug。

## 在纯文本 V4 模型前面放一个视觉模型

V4 Pro 0813、V4 Flash 0731 和 0423 检查点不接受图像。如果你想让其中之一对图像做推理，先跑一个视觉模型，把它的文本输出传给 V4 模型。V4 模型永远看不到像素，它读的是描述。

接受图像和视频输入的两个模型是 [Qwen3.8 27B](https://openrouter.ai/qwen/qwen3.8-27b)（`qwen/qwen3.8-27b`）和 [Kimi K3](https://openrouter.ai/moonshotai/kimi-k3)（`moonshotai/kimi-k3`）。我们的 [视觉模型合集](https://openrouter.ai/collections/vision-models)列出了目录中所有接受图像输入的模型。

```
import { OpenRouter } from "@openrouter/sdk";

const openRouter = new OpenRouter({
  apiKey: process.env.OPENROUTER_API_KEY,
});

const imageUrl = "https://example.com/screenshot.png";
const userTask = "Explain the error and propose a fix.";

// Step 1: a vision model reads the image and returns a text description.
const seen = await openRouter.chat.send({
  chatRequest: {
    model: "qwen/qwen3.8-27b",
    messages: [
      {
        role: "user",
        content: [
          {
            type: "text",
            text: "Describe this screenshot for a reasoning model. Report only what is visible.",
          },
          { type: "image_url", imageUrl: { url: imageUrl } },
        ],
      },
    ],
    stream: false,
  },
});

if (!("choices" in seen)) {
  throw new Error("Expected a non-streaming response");
}

const description = seen.choices[0]?.message.content;

if (typeof description !== "string") {
  throw new Error("Expected a text description from the vision model");
}

// Step 2: a text-only V4 model reasons over the description.
const reasoned = await openRouter.chat.send({
  chatRequest: {
    model: "deepseek/deepseek-v4-pro-0813",
    messages: [
      {
        role: "user",
        content: `Image notes:\n${description}\n\nTask: ${userTask}`,
      },
    ],
    stream: false,
  },
});

if (!("choices" in reasoned)) {
  throw new Error("Expected a non-streaming response");
}

console.log(reasoned.choices[0]?.message.content);
```

把 `qwen/qwen3.8-27b` 换成 `moonshotai/kimi-k3` 就能让 Kimi K3 看图；把 `deepseek/deepseek-v4-pro-0813` 换成 `deepseek/deepseek-v4-flash-0731` 就换了文本推理那一轮。

两次调用比一次贵。2026 年 9 月 29 日，Qwen3.8 27B 标价为每百万输入 token $0.025、每百万输出 $4.40，Kimi K3 为 $3.00 和 $15.00。V4 模型的费用还要另加。当你确实需要一个纯文本 V4 模型或视频输入时才用这个模式，而不是把它当作 V4 读图的默认方式。

## 该走哪条路线

按你需要的模型和手头的输入匹配路线。

- **静态图像或文档，Flash 档质量够用。**一次调用发给 `deepseek/deepseek-v4.1-flash`。
- **静态图像，且你想测试实验模型。**一次调用发给 `deepseek/deepseek-v4-flash-vision-exp`，并固定 slug。
- **对图像做 Pro 档推理。**没有任何 V4 Pro 模型接受图像。先跑视觉模型，把其文本传给 `deepseek/deepseek-v4-pro-0813`。
- **视频输入。**没有任何 V4 模型接受视频。用支持的模型（如 Qwen3.8 27B 或 Kimi K3），再把其文本传给 V4 模型。请求结构见[视频输入指南](https://openrouter.ai/docs/guides/overview/multimodal/videos)。
- **文本与图像混合流量。**纯文本请求继续走你已在用的文本模型，图像请求发给 V4.1 Flash。

如果图像会毫无预警地出现，请在你自己的代码里检查消息 content，发送请求前先选定模型。[Provider 路由](https://openrouter.ai/docs/guides/routing/provider-selection)在你指定模型的各 provider 之间做选择，它不会切换到另一个模型，所以无法把发给纯文本模型的图像请求变成发给视觉模型的请求。

## 如何自己核对模型的模态

模型页面和 models API 是某个 slug 接受什么的权威来源。每个模型页面列出其输入和输出模态。models API 在 `architecture.input_modalities` 中返回同样的数据。

```
curl -s https://openrouter.ai/api/v1/models \
  | jq -r '.data[] | select(.id | startswith("deepseek/deepseek-v4")) | "\(.id)\t\(.architecture.input_modalities | join(","))"'
```

[模型页面](https://openrouter.ai/models?input_modalities=image)按图像输入过滤后，会显示我们目录上所有接受图像的模型。如果未来的 V4 检查点增加了图像输入，其模型页面和 API 响应会体现，我们也会更新本页。

## 常见问题

### DeepSeek V4 Flash 有视觉能力吗？

看具体检查点。`deepseek/deepseek-v4.1-flash` 和 `deepseek/deepseek-v4-flash-vision-exp` 接受文本和图像。`deepseek/deepseek-v4-flash-0731` 和 `deepseek/deepseek-v4-flash` 是纯文本，`~deepseek/deepseek-v4-flash-latest` 别名在写作时解析到 Flash 0731。

### DeepSeek V4 Pro 有视觉能力吗？

没有。`deepseek/deepseek-v4-pro-0813` 和更早的 `deepseek/deepseek-v4-pro` 只把文本列为输入模态。要在图像上用 Pro，先跑视觉模型，把其文本描述传给 Pro。

### 图像该用哪个 DeepSeek V4 模型？

用 `deepseek/deepseek-v4.1-flash`。它原生读图，没有标注实验性，且 2026 年 9 月 29 日标价为每百万输入 token $0.30、每百万输出 $1.20。实验性替代是 `deepseek/deepseek-v4-flash-vision-exp`。

### DeepSeek V4 的图像输入要花多少钱？

图像输入按模型的 token 价格计费。2026 年 9 月 29 日，V4.1 Flash 标价为每百万 token 输入 $0.30、输出 $1.20，V4 Flash Vision Exp 为输入 $0.216、输出 $0.647。定预算前先查模型页面，标价会变。

### DeepSeek V4 能处理视频吗？

我们目录中没有 V4 模型把视频列为输入模态。对视频，用支持的模型，如 `qwen/qwen3.8-27b` 或 `moonshotai/kimi-k3`，再把其文本输出传给 V4 模型。
