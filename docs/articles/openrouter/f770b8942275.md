# OpenAI GPT-4.1 ⭐️

**GPT-4.1** 现已正式发布，具备 1M token 上下文。
还有 Mini 和 Nano 版本，但 Quasar 和 Optimus 测试的是完整版（4.1）。

## 💰 定价

**GPT-4.1**

- 输入 $2.00
- 缓存输入 $0.50
- 输出 $8.00（每 1M tokens）

**GPT-4.1 Mini**

- 输入 $0.40
- 缓存输入 $0.10
- 输出 $1.60（每 1M tokens）

**GPT-4.1 Nano**

- 输入 $0.10
- 缓存输入 $0.025
- 输出 $0.40（每 1M tokens）

## 📢 详情

- X 上的公告：[OpenRouter X Announcement](https://x.com/OpenRouterAI/status/1911833662464864452)
- **Alpha 立即下线**：Optimus 和 Quasar 的免费 alpha 端点现已下线。API 请求将返回 404，且不做自动重定向，以避免产生意外费用。
