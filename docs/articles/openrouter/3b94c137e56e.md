# OpenRouter MCP Server

你的编码 agent 写代码非常出色。

但谈到为该选哪个模型犯难——比如写代码又不想一天烧光月度预算，或设计落地页用哪个模型最好——它就真的不行了。

你的 agent 只能大致猜一个「最佳」模型，但它靠的是早已过时数月的训练数据在猜：不知道价格、不知道在某任务上表现如何、不知道该固定到哪个 provider，等等。

这种日子结束了。

今天，我们非常高调地宣布 OpenRouter MCP 发布。

OpenRouter MCP server 把实时的模型数据、基准排名、价格、文档和测试推理直接交给你和你的 agent，帮你选出最合适的模型。一条命令安装，你最爱的 agent 就能用来自 Artificial Analysis、Design Arena 以及 OpenRouter 自家模型排名的最新数据，回答「哪个模型写代码最强又不会让我破产」。剧透：是 GLM-5.2。

[立即连接](https://openrouter.ai/docs/guides/overview/mcp-server) | [文档](https://openrouter.ai/docs/guides/overview/mcp-server)

## 一条命令安装

**Claude Code：**

```
claude mcp add --transport http openrouter https://mcp.openrouter.ai/mcp
claude mcp login openrouter
```

**Codex CLI：**

```
codex mcp add openrouter --url https://mcp.openrouter.ai/mcp
codex mcp login openrouter
```

**Cursor：** 添加到 `~/.cursor/mcp.json`：

```
{
  "mcpServers": {
    "openrouter": { "url": "https://mcp.openrouter.ai/mcp" }
  }
}
```

**Claude Desktop / Web：** OpenRouter 不在 Claude 的连接器目录里，需要自己添加：**Settings > Connectors > Customize > Connectors**，点击 **+** > **Add custom connector**，填入名称 `OpenRouter MCP` 和 Remote MCP server URL `https://mcp.openrouter.ai/mcp`，点击 **Add**，然后打开该连接器并点击 **Connect** 走 OAuth 流程。

部分组织不允许添加自定义连接器，这个选项可能不是所有人都能看到。若是如此，请联系你的管理员。

OAuth 登录及所有支持的客户端见[连接指南](https://openrouter.ai/docs/guides/overview/mcp-server)。

## 不用切标签页就能选对模型

你在做一个需要结构化 JSON 输出的功能，想要一个又快又便宜、而且真擅长的模型。平时你得打开 OpenRouter 网站、浏览模型列表、比较基准、查价格，也许还在 playground 跑几条测试 prompt。写第一行集成代码之前，就为了这个切换了 15 分钟的上下文。

接上 MCP server 后，这一切都能在编码 agent 里完成：

```
You: "I need a model for structured JSON extraction from legal documents.
     Fast, under $1/M input tokens, good at following schemas."

Agent: [calls list-models with filters] → [calls list-benchmarks] → [calls list-model-endpoints]

Agent: "google/gemini-3-flash-preview fits well: $0.10/M input,
       138k context, strong structured output support. Here's the
       endpoint with the lowest latency..."
```

agent 从实时模型目录取数，交叉引用 Artificial Analysis 的智能分与 Design Arena 的 ELO 排名，并核对各 provider 的价格和延迟。推荐完全基于当下数据，而不是模型半年前训练时的那些旧信息。

## 先测试，再投入

`send-message` 让你的 agent 向任意模型发一条测试 prompt，看到响应、成本以及是哪个 provider 服务的。你的 agent 可以把多个模型的答案并排比较：

```
You: "Compare how Claude Opus 4.8, GPT-5.5, and DeepSeek V4 Pro
     handle this structured extraction prompt."

Agent: [sends the same prompt to all three via send-message]
       [calls get-generation for each to get cost breakdowns]

Agent: "All three produced valid JSON. Opus 4.8 nailed the edge
       case in row 12. GPT-5.5 was 40% cheaper. DeepSeek V4 Pro
       was fastest at 180ms TTFB."
```

模型 slug 支持后缀：`:online` 开 web 搜索、`:nitro` 排速度、`:floor` 取最低价、`:free` 用免费端点。你的 agent 可以跨 variant 测试，你不用记这些语法。

## 不出编辑器就能搜文档

你的 agent 有 `search-docs`，它对 OpenRouter 文档做全文搜索。「怎么把模型固定到指定 provider？」「tool calling 的格式是什么？」「prompt 缓存怎么工作？」agent 找到答案并直接应用，全在一个流程里。

这正是 MCP server 作为开发助手最有价值的地方。你的 agent 能查到你需要的确切 API 参数、正确的请求格式，并接进你的代码，而你不用自己去找到并读完那一页文档。

## 专用、封顶的 key

服务器是远程的（本地什么都不装），首次登录会走 OAuth 流程，铸造一个专用 API key：7 天过期、$10 消费上限（在授权页面可编辑）。它与你的其他 key 相互独立，会出现在你的 [keys 仪表盘](https://openrouter.ai/settings/keys)上。你可以随时吊销。

OpenCode、Claude Desktop 及其他所有支持客户端的配置见[连接指南](https://openrouter.ai/docs/guides/overview/mcp-server)。

## 工具箱里有什么

| 工具 | 作用 |
| --- | --- |
| `list-models` | 带过滤条件搜索实时模型目录：价格区间、上下文长度、模态、provider、模型家族等 |
| `get-model` | 单个模型的完整详情：能力、价格、上下文窗口、支持的参数 |
| `list-model-endpoints` | 按 provider 拆分：价格、延迟、吞吐、数据政策 |
| `list-benchmarks` | 来自 Artificial Analysis 和 Design Arena 的第三方质量分 |
| `list-daily-model-rankings` | 按 token 量统计的最热门与上升中模型 |
| `send-message` | 向任意模型发送测试 prompt，获得响应与成本 |
| `get-generation` | 指定 generation 的成本、token 计数和服务 provider |
| `search-docs` | 全文搜索 OpenRouter 文档 |
| `get-credits` | 你的账户剩余额度 |
| `list-providers` | 可用于路由偏好的 provider |
| `list-app-rankings` | 按类别统计哪些应用为 OpenRouter 带来最多流量 |

除 `send-message` 外所有工具都是只读查询。`send-message` 会发起一次计费推理调用，消耗你的 MCP key 余额。

## FAQ

### 这会取代 OpenRouter API 吗？

不会。MCP server 是给编码 agent 用的开发助手。它拉取实时 OpenRouter 数据、可发送测试消息，让你构建应用时 agent 能做有依据的决策。你的应用仍应直接调用 OpenRouter API。

### 认证如何工作？

由你的 MCP 客户端触发 OAuth 流程，浏览器打开 OpenRouter 授权页。你批准一个 7 天过期、$10 消费上限的专用 API key。该 key 与其他 key 相互独立，可随时从你的[仪表盘](https://openrouter.ai/settings/keys)断开。

### 我的源代码会被发送到别处吗？

不会。这些工具是对 OpenRouter API 的只读查询。唯一的例外是 `send-message`，它会把你显式传入的消息发给模型。除非你把代码放进 `send-message` 调用里，否则没有任何源代码离开你的机器。

现在就试：[连接你的 agent](https://openrouter.ai/docs/guides/overview/mcp-server)，问一句「我的用例最适合哪个模型？」
