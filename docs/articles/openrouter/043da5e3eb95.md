## 音频支持

让用户可以用 wav 或 mp3 输入与你的 app 对话。

- 查看[支持音频输入的模型](https://openrouter.ai/models?fmt=cards&input_modalities=audio)
- 阅读[音频输入指南](https://openrouter.ai/docs/features/multimodal/audio)

![Audio Input Preview](https://openrouter.ai/cdn-cgi/imagedelivery/Xq3eUzdKO2-MoBklzEEuMQ/baa34a95-589f-462e-6ca8-5afd78ddb900/public)

## PDF 链接

现在可以直接把 PDF 链接发给 OpenRouter——无需 base64 编码。

- 适用于 OpenRouter 上的任意 LLM
- 使用方法见 [PDF URL 文档](https://openrouter.ai/docs/features/multimodal/pdfs#using-pdf-urls) ![PDF Input Preview](https://openrouter.ai/cdn-cgi/imagedelivery/Xq3eUzdKO2-MoBklzEEuMQ/0f006f6e-2203-43fb-46a6-dd66a2775600/public) 这让在你的 app 中集成文档工作流比以往任何时候都更简单，免去手动编码的麻烦。
