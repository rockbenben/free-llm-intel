构建一个 agent 需要超出 chat completion 的一层层行为：调用模型、检查输出里的工具请求、执行这些工具、把结果喂回去，如此循环直到任务完成。而要把这个循环做得健壮，就意味着要处理输入校验、流式输出、成本追踪，以及知道何时停止。

[`@openrouter/agent`](https://openrouter.ai/sdk) 是一个与模型无关的 TypeScript SDK，把所有这些打包成一个函数，可以在 OpenRouter 的 400+ 任意模型上执行这个 agentic 循环。为了展示这个 agentic 循环有多强大，我们发布了一篇教程，讲解 Agent SDK 之上的一个 skill 如何让你[构建自己的个人 agent harness](https://openrouter.ai/announcements/create-agent-harness-with-agent-sdk)。

## 从 chat completion 到 agentic 行为

标准的 chat completion 是无状态的：你发送消息，得到响应。要把它变成 agent，需要外挂若干行为：

**工具执行。** 模型产生一个结构化的 tool call，你的代码必须解析它、校验参数、运行函数，并把结果格式化为下一次请求。用 `callModel` 时，你用 `tool()` 和 Zod schema 定义工具。工具运行独立于模型调用，边界清晰、逻辑不纠缠。SDK 会在运行时校验来自模型的输入和你函数的输出。如果模型发来坏参数，你会得到清晰的错误，而不是下游的静默失败。

**多轮循环。** Agent 很少一步就完成。它可能先搜索、读结果、再搜索，然后写摘要。这意味着循环：调用模型、执行工具、再调用模型、重复。`callModel` 在内部处理这个循环，你通过停止条件控制它：停止条件是可以拿到完整步骤历史、并决定是否继续的自定义函数。

**停止条件。** 没有护栏，agent 循环可以永远跑下去（至少跑到账单让你不舒服）。`callModel` 接受可组合的停止条件：`stepCountIs(10)` 把循环限制在 10 轮，`maxCost(1.00)` 设定美元上限，`hasToolCall('done')` 在某个特定工具被调用时停止。可以组合使用，也可以写自定义函数。

```
import { stepCountIs, maxCost, hasToolCall } from '@openrouter/agent/stop-conditions';

const result = client.callModel({
  model: 'openai/gpt-5',
  input: 'Research this topic and compile a report',
  tools: [searchTool, writeTool, doneTool],
  stopWhen: [
    stepCountIs(15),
    maxCost(2.00),
    hasToolCall('done'),
  ],
});
```

**流式输出。** 需要多步的 agent 得展示进度。`callModel` 提供 `getTextStream()`、`getToolCallsStream()` 和 `getReasoningStream()`。可以同时对同一响应进行流式输出、提取和处理，无需提前二选一。

**成本追踪。** 每个响应都通过 `result.getResponse()` 包含 token 数和成本数据，让你精确知道每次 agent 运行花了多少钱。

**工具审批。** 对于会执行现实世界动作的 agent，你可以把工具标记为需要审批。当模型调用它时，SDK 会暂停执行、把控制权交还你的代码，等你收集到决定后再继续。

`callModel` 把这一切都处理好了，你可以专注于应用特有的工具和逻辑。而且由于 SDK 与模型无关，你在 OpenRouter 上切换任何模型都不用改 agent 代码。

## 开始使用

```
npm install @openrouter/agent
```

```
import { OpenRouter } from '@openrouter/agent';
import { tool } from '@openrouter/agent/tool';
import { stepCountIs } from '@openrouter/agent/stop-conditions';
import { z } from 'zod';

const client = new OpenRouter({ apiKey: process.env.OPENROUTER_API_KEY });

const result = client.callModel({
  model: 'anthropic/claude-sonnet-4',
  input: 'What time is it in Tokyo?',
  tools: [
    tool({
      name: 'get_time',
      description: 'Get current time in a timezone',
      inputSchema: z.object({ timezone: z.string() }),
      execute: async ({ timezone }) => {
        try {
          return { time: new Date().toLocaleString('en-US', { timeZone: timezone }) };
        } catch {
          return { error: `Invalid timezone: ${timezone}. Use IANA format like 'Asia/Tokyo'.` };
        }
      },
    }),
  ],
  stopWhen: [stepCountIs(5)],
});

const text = await result.getText();
```

SDK 调用模型、看到它想使用 `get_time`、按你的 Zod schema 校验输入、执行函数、把结果喂回去，并返回最终文本。你没有写一行循环逻辑。

[获取你的 API key](https://openrouter.ai/settings/keys)，然后把你的 agent 指向 [callModel 文档](https://openrouter.ai/docs/sdks/typescript/call-model/overview)。
