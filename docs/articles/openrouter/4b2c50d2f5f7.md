现在你可以自动为 OpenRouter 的生成结果附加结构化元数据分类，用于 AI 使用报告。

每个请求都携带着信息：工作类型、复杂度级别、来自哪个部门、是否包含不该有的内部数据。现已开放 beta 的 Classifiers 给你这种可见性。定义你的标准（任务类型、agent 复杂度、合规类别、成本中心），由你选择的模型按你的分类体系为每次生成——或采样的子集——打标签，并把结果写入你的日志。你就能持续看到你的 agent 和用户在做什么、不同任务用了哪些模型、成本流向了哪里。

在工作区设置中[创建 classifier](https://openrouter.ai/workspaces/default/classifiers)，或先阅读[文档](https://openrouter.ai/docs/guides/features/classifiers)。

## 选一个模板或定义你自己的分类体系

一个 classifier 是一份包含四部分的小配置：**分类体系（taxonomy）**（最多八个维度，每个维度含你选择的取值）、**分类 prompt**（作为 system message 发给分类模型的指令）、一个用于阅读每条 prompt 并执行分类的**模型**，以及一个**采样率**。分类在每次请求完成后异步运行，绝不会给推理路径增加延迟。

从六个预设模板中选择、定制一个模板，或从零构建你自己的。

| Template | What it tags |
| --- | --- |
| **Department** | 请求源自哪个业务职能：工程、销售、市场、法务等。适合查看组织的哪些部分在驱动推理成本 |
| **Audience** | 输出面向谁：内部使用、客户可见、监管方或公众。服务于依赖“谁会读模型输出”的合规工作流 |
| **Task type** | 模型在做什么：编码、agent 工作流、数据处理、内容写作。适合检查每类任务是否用了正确档位的模型 |
| **Engineering work** | 功能开发、bug 修复、文档、重构、代码评审。适合追踪 AI 在帮什么忙、每类工作用了哪些模型 |
| **Agent complexity** | 难度层级（从琐碎的工具调用到前沿专家级工作）加任务族。对运行 agent 的团队，关键问题是“哪个模型把难题处理得好” |
| **Capitalizable software expense** | AI 辅助的工程工作是否可能属于可资本化的开发，相对于维护、运维或支持 |

选择你的分类模型。我们推荐 [Gemini 3.5 Flash Lite](https://openrouter.ai/google/gemini-3.5-flash-lite) 以获得最佳性价比：便宜、结构化输出准确率高，对大多数分类体系都够用。你可以随时更换模型。

在高吞吐下，对每个请求分类的成本会累积。用采样率来控制成本。让高保真的合规 classifier 以 100% 运行，同时让更宽泛的成本归因 classifier 对同一流量的 10% 采样——让成本与你需要的监督程度成比例。

## 日志中的结构化标签

Classifier 的输出会被强制转换为结构化格式，约束在你定义的维度和取值内。每条被分类的生成都会在你的[日志](https://openrouter.ai/logs)中打标签，你可以按分类筛选请求。例如，你可以拉出所有标记为 `department: legal` 或 `agent_complexity_difficulty_tier: complex_multistep` 的请求。每条带标签生成的详情面板会分解展示其分类维度与取值。

你也可以对任意历史生成按需运行一次 classifier，以校验新分类体系是否合理。在日志中打开它、选一个 classifier，看看它会被打上什么标签。

## 在 Activity 中汇总

生成上的单个标签回答“这个请求是什么”。[Activity Explorer](https://openrouter.ai/activity/explore) 回答的是聚合问题：按任意 classifier 维度对流量分组，查看每种任务类型或 agent 复杂度层级在用哪些模型，哪些部门或任务驱动了最多支出。

结果随时间聚合；观察你的数据中模式的迁移，向干系人展示你的 AI 使用是如何被治理的。Classifier 筛选在各 Activity 标签页间保持生效，让你能按任意 classifier 取值查看[趋势](https://openrouter.ai/activity/trends)和 [guardrail](https://openrouter.ai/activity/guardrails) 执行情况。

![Activity Explore grouping total usage by the agent complexity classifier's difficulty tier, showing spend per tier from complex_multistep to frontier_expert](https://openrouter.ai/blog/images/classifiers-activity.png)

## 开始使用

Classifiers 现已开放 beta。在你的工作区[创建 classifier](https://openrouter.ai/workspaces/default/classifiers)，或阅读[文档](https://openrouter.ai/docs/guides/features/classifiers)深入了解分类体系设计、计费，以及分类在底层如何运作。即使关闭输入与输出日志，Classifiers 也能工作。
