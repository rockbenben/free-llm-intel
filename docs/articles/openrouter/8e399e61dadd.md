今天，我们兴奋地宣布将与 [Stripe](https://stripe.com/) 联手，为全球下一波 GDP 增长提供动力。

OpenRouter 是第一家、也是最大的模型市场与网关。我们是发现和使用任意 AI 模型的最佳方式：一个接口、广泛的服务商选择、与模型无关的可观测性、成本管理，以及能改善价格、性能与可用性的路由。我们现在每天处理来自 400+ AI 模型的 10 万亿+ token，服务超过 1000 万开发者与公司组成的社区。自创立以来，我们的推理量每年都至少增长 10 倍。

我们想解释为什么做出加入 Stripe 的决定，以及这对数百万在我们之上构建的开发者和公司意味着什么。

## 这对我们的用户意味着什么

OpenRouter 将继续照现状运营：同样的使命、同样的名字、同样的产品、同样的路线图。如果你今天在 OpenRouter 上构建，你的集成什么都不会变。

OpenRouter 的存在，是为了让用户平等地获得每一个模型、提供关于模型在市场中使用方式的开放信号、帮助开发者把它们编排在一起、并在规模化下让它们可观测、可管理。这一承诺是我们运营方式的核心，不会向任何模型、任何服务商、任何母公司弯曲。它也延伸到一个不断成长的推理周边服务生态，包括 AI 原生 web 搜索、上下文管理，以及更多在路上。

路由决策将只由一件事驱动：什么对你——用户——最好。

## 我们的使命

2023 年初我们创立 OpenRouter，基于一个简单的信念：智能将是多模型的。没有任何单一模型能赢得所有任务，而前沿会快速移动。这种自由是这个行业至关重要的基础设施。AI 太重要了，它的未来不能由最先被嵌入的那个单一模型来决定。AI 已成为美国经济增长的最大单一驱动力，而推理正迅速成为每家公司最大的开支项之一。

我们展望一个健康的 AI 生态：众多模型繁荣共生，AI 的“神经多样性”成为一种优势，任何有突破的实验室或推理服务商都能触达数百万开发者，没有任何单一模型会因惯性成为默认。

我们的使命就是实现这个未来，它比其他任何事都重要。与 Stripe 的机遇让我们能一起加速它。

## 为什么是 Stripe？

这世上没几家公司我们会考虑卖身给它；我们的使命、我们的中立性和市场领先地位，让“独立”的故事很有说服力。我们只会加入一家我们认为能一起做得更多、更快、且不牺牲任何这些的东西的公司。

Stripe 就是那家公司。他们是世界上最好的金融基础设施平台。他们的 API 定下了此后所有开发者产品（包括我们的）被衡量所参照的标准。这是两个由开发者凭实力选择平台的结合，两种聚焦质量、规模与对构建者承诺的文化相遇——而在后 AGI 经济中，两者都将不可或缺。

多年来，OpenRouter 一直被称为“LLM 界的 Stripe”。两家公司共享相似的 DNA：我们把复杂的基础设施和市场动态抽象成令人愉悦的 API，并痴迷于 API 另一端的开发者和用户。企业信任 Stripe 优化他们收入技术栈的每个部分——支付方式、授权、反欺诈等。构建者、客户、模型实验室和服务商信任 OpenRouter 在一个快速变化的生态上运营一个中立、可靠的一层。

Stripe 带来庞大的客户网络、关于互联网企业如何成长的数据，以及多年运营可信全球基础设施的经验。在管理欺诈与滥用方面也没人比他们更擅长——而我们认为 AI 公司应对这个问题只会越来越难。现在我们能以一个独自无法企及的速度服务开发者。
