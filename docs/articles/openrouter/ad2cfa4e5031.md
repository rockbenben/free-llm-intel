### 概览

GPT-5 是 OpenAI 迄今最智能的模型，在推理、可靠性和专项用例上都有大幅提升。

- 动态推理（“think hard about this”）让复杂任务上达到专家级的回答
- 复杂前端生成能力显著增强
- 健康类问题的最佳模型
- 幻觉大幅减少（思考模式下相比 o3 减少约 80%）

支持 **400,000 token 上下文窗口**，输出最多 **128,000 tokens**。

该模型的早期迭代曾以 Horizon Alpha 和 Horizon Beta 的名义提供。

### SWE-Bench Verified（500 轮）

| Model | Accuracy |
| --- | --- |
| **Open AI GPT-5** | **74.9%** |
| Claude Sonnet-4 | 70.4% |
| Qwen3-Coder | 69.6% |
| OpenAI o3 | 69.1% |

### 模型变体

| Model | Best for |
| --- | --- |
| **GPT-5** | 复杂推理、广博的世界知识和重度代码任务 |
| **GPT-5-mini** | 均衡表现：成本优化的对话、尚可的推理、速度快 |
| **GPT-5-nano** | 高吞吐用例，如分类或简单问答 |
