# Audio Inputs and PDF URLs for Apps

OpenRouter ·8/4/2025 · Updated 6/24/2026

## Audio Support

Let users talk to your app using wav or mp3 inputs.

- View [Models that support audio input](https://openrouter.ai/models?fmt=cards&input_modalities=audio)
- Read the [Audio Input Guide](https://openrouter.ai/docs/features/multimodal/audio)

![Audio Input Preview](https://openrouter.ai/cdn-cgi/imagedelivery/Xq3eUzdKO2-MoBklzEEuMQ/baa34a95-589f-462e-6ca8-5afd78ddb900/public)

## PDF URLs

Now you can send PDF links directly to OpenRouter—no base64 encoding needed.

- Works with any LLM on OpenRouter
- Learn how in the [PDF URL Docs](https://openrouter.ai/docs/features/multimodal/pdfs#using-pdf-urls) ![PDF Input Preview](https://openrouter.ai/cdn-cgi/imagedelivery/Xq3eUzdKO2-MoBklzEEuMQ/0f006f6e-2203-43fb-46a6-dd66a2775600/public) This makes it easier than ever to integrate document workflows into your apps without the hassle of manual encoding.
