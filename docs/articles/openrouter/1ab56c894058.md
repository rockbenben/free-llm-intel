四月最重要的发布：视频生成、面向多项目隔离的 Workspaces，以及能把任意模型变成 agent 的 TypeScript SDK。以下是本月交付的内容。

## 视频生成

通过一个统一 API 从文本或图像生成视频。首日即支持 Seedance 2.0、Veo 3.1、Wan 2.7、Sora 2 Pro 等，内置归一化参数、异步作业跟踪和能力发现。视频与文本、图像、音频、embedding 和 reranker 共享同一套路由与计费层。

[浏览视频模型](https://openrouter.ai/models?fmt=cards&output_modalities=video) · [API 文档](https://openrouter.ai/docs/api/api-reference/videos) · [公告](https://openrouter.ai/announcements/video-generation)

## Workspaces

把你的 OpenRouter 项目组织成独立环境，每个环境有自己的 API key、路由默认值、guardrails 和可观测性。为多项目开发者、企业团队，以及需要 staging 与 production 隔离的 agent 而生。

你现有的配置位于 Default workspace 中。如果你不需要多环境，一切不变。

[创建 workspace](https://openrouter.ai/workspaces/new) · [文档](https://openrouter.ai/docs/guides/features/workspaces) · [公告](https://openrouter.ai/announcements/introducing-workspaces)

## 带 `callModel` 的 Agent SDK

[`@openrouter/agent`](https://openrouter.ai/sdk) 提供了 `callModel`：一个函数搞定 400+ 模型上的多轮 tool calling、流式输出、停止条件和成本追踪。用 Zod schema 定义工具，设置 `stepCountIs(10)` 或 `maxCost(1.00)` 这样的停止条件，让 SDK 跑完整个 agentic 循环。

在其之上还交付了两个 skills：`create-agent-tui` 用于快速搭建带终端 UI 的 coding agent，`create-headless-agent` 用于配合任意 coding agent 构建多模型 CLI 工具。

[SDK 文档](https://openrouter.ai/sdk) · [公告](https://openrouter.ai/announcements/agent-sdk-with-callmodel) · [Agent harness 教程](https://openrouter.ai/announcements/create-agent-harness-with-agent-sdk)

## 本月其他交付

**Reranker 模型。** 一个新模态，用于按相关性重排搜索结果和文档片段。Cohere Rerank 和 Fireworks rerankers 已上线，配新的 `/rerank` 端点。[API 文档](https://openrouter.ai/docs/api/api-reference/rerank/create-rerank) · [模型](https://openrouter.ai/models?fmt=cards&output_modalities=rerank)

**Model Fusion。** 把多个模型的结果融合为一条响应。[试用](https://openrouter.ai/fusion)

**Prompt 历史。** 查看、重放和重新混合来自 OpenRouter 的过往 prompt。审计输出质量、迭代 prompt，并把同一输入重放到不同模型上做对比。

**模型对比页上的基准测试。** 模型对比页现在展示 Design Arena ELO 排名，并带有 3D、网站构建、SVG 等可视化。点击任意模型页面顶部的“Compare”。[对比模型](https://openrouter.ai/compare)

**知识截止日期。** LLM 训练截止日期现已可在 `/models` API 中获取，方便你以编程方式检查模型知识的新鲜度。

**Stripe Projects。** 运行 `stripe projects add openrouter/api`，从命令行即可获得 OpenRouter 账户、API key 和 Stripe 计费。你的 agent 也能做到。[公告](https://openrouter.ai/announcements/openrouter-on-stripe-projects)

**TypeScript SDK 中的类型化工具上下文。** 在工具上定义 `contextSchema`，从 `callModel` 传入上下文，用 `setContext()` 修改，变更跨轮次持久保存，全程由 Zod 校验。

## 前沿模型发布

本月有大量模型发布：

- **GPT-5.5 & GPT-5.5 Pro**：OpenAI 最新的前沿模型，在跨代码、数据、工具的长时间任务上处于顶尖水平
- **DeepSeek V4 Pro & V4 Flash**：相比 V3.2 巨大跃升，在各项基准上达到或超过当前顶尖水平
- **Claude Opus 4.7**：Anthropic 最强的 Opus，为长时间异步 agent 打造
- **GPT-5.4 Image 2**：带顶尖图像生成能力的 GPT-5.4
- **Kimi K2.6**：Moonshot AI 面向长周期 agentic 工作的编码模型
