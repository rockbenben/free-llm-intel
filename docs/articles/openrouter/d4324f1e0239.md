# 体验优化更新

我们在全面提升透明度和易用性方面推出了三项体验优化更新。

## 🔹 Activity 图表筛选

现在只要对表格应用筛选，就能同步筛选 Activity 页面上的图表。
 无论你是按模型、API key 还是服务商筛选，图表都会随之更新——让趋势和尖峰更容易分析。
 见这里：[https://openrouter.ai/activity](https://openrouter.ai/activity)

## 🖼️ Chatroom SVG 预览

SVG 文件现在可以在聊天室内联预览，无需下载即可即时查看图示、图标和矢量设计。
 ![Chatroom SVG Previews](https://openrouter.ai/cdn-cgi/imagedelivery/Xq3eUzdKO2-MoBklzEEuMQ/e5dc1b47-3455-423c-eb31-5bd5cab47d00/public)

## 📊 流内用量统计

开发者现在可以直接在每轮流式响应中收到实时的 token 和费用数据。
 只需在请求中设置 `"usage": { "include": true }`，即可获得如下详情：

```
"usage": {
  "completion_tokens": 2000,
  "completion_tokens_details": { "reasoning_tokens": 100 },
  "cost": 0.2,
  "prompt_tokens": 194,
  "prompt_tokens_details": { "cached_tokens": 20 },
  "total_tokens": 2194
}
```

无需额外的 API 调用。
