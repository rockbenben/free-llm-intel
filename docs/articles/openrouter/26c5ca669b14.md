# 推理服务商的数据处理事件

OpenRouter · 2026/11/22

本周早些时候，安全[研究人员报告](https://www.dragos.com/blog/ai-supply-chain-security-canary-tokens)称，某些推理服务商出现了数据被泄露的情况，或存在表明其数据政策未被遵守的证据。我们一直与研究人员及各服务商密切协作，以理解这些发现，并推动服务商加以处理。

这些发现并未显示 OpenRouter 本身遭到入侵或出现未经授权的访问。测试结果揭示了有关具体推理服务商的新情况。我们已收到的服务商安全公告实时清单见[下文](https://openrouter.ai/blog/announcements/data-processing-incidents-on-inference-providers/#provider-security-announcements)。

作为客户与快速演进的模型及服务商生态之间的运行层，我们非常重视数据政策的执行。我们已采取以下行动：

- 根据调查结果，将三家服务商从 OpenRouter 下架。
- 将 125 个 endpoint 移出零数据保留（ZDR）资格名单。被移除的 endpoint 包括研究人员标记的服务商，以及我们出于预防考虑额外移除的一些 endpoint。
- 通知了所有可能受影响的客户。

以下工作正在进行中：

- 我们正在改编研究人员的测试方法，以便持续开展这类检查。
- 我们正在对网络路径做技术核验，以识别请求与响应可能被转发给第三方的情形。
- 对于本次审查中移除的 endpoint，我们会要求提供适当的保证与验证，之后才恢复其 ZDR 资格。

我们感谢 Dragos 的报告。随着我们把类似测试手段引入 OpenRouter，我们会不断提高门槛；希望留在 OpenRouter 上的服务商也必须达到这一门槛。
