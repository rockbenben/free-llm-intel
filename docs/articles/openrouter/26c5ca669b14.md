# 推理提供商的数据处理事件

OpenRouter ·11/22/2026

本周早些时候，安全[研究人员报告](https://www.dragos.com/blog/ai-supply-chain-security-canary-tokens)称，某些推理提供商的数据遭到泄露，或有其他证据表明其数据政策未得到执行。我们一直与研究人员和各提供商密切协作，以了解这些发现，并推动提供商加以解决。

这些发现并未显示 OpenRouter 存在任何入侵或未经授权的访问。此次测试的结果揭示了关于特定推理提供商的新发现。我们收到的来自各提供商的安全公告实时列表见[下文](https://openrouter.ai/blog/announcements/data-processing-incidents-on-inference-providers/#provider-security-announcements)。

作为客户与快速演变的模型及提供商生态之间的运行层，我们非常重视数据政策的执行。我们已采取以下行动：

- 根据调查结果，将三家提供商从 OpenRouter 下线（off-board）。
- 将 125 个 endpoint 移出零数据保留（ZDR）资格范围。被移除的既包括研究人员标记的提供商，也包括我们出于预防考虑额外移除的 endpoint。
- 通知了所有可能受影响的客户。

以下工作正在进行中：

- 我们正在改造研究人员的测试方法，以便持续开展此类检查。
- 我们正在对网络路径进行技术验证，以识别请求和响应可能被转发给第三方的情况。
- 在恢复本次审查中移除的任何 endpoint 的 ZDR 资格之前，我们将要求其提供适当的保证与验证。

我们感谢 Dragos 的报告。随着我们将类似的测试技术整合进 OpenRouter，我们会不断提高标准，而希望接入 OpenRouter 的提供商必须达到这一标准。
