## 🚨 - OpenRouter 上的作者页面

我们刚上线了一种探索模型的全新酷炫方式。访问 `openrouter.ai/<author>`，深入浏览某位创作者的每一款模型。

### ⚡️ 新特性

```
•    Check out detailed stats for each author’s collection
•    See all models by an author at a glance
•    Discover related models with our new carousel feature on the model page
```

点击查看：[https://openrouter.ai/anthropic](https://openrouter.ai/anthropic)
