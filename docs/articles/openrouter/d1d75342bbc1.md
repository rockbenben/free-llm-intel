DeepSeek——在很多人心目中仍是开源 LLM 代名词的公司——于 4 月 24 日发布了新的旗舰 V4 模型。

V4 重写了轨迹。六个月里，DeepSeek 在 OpenRouter 上的 token 份额大约翻倍，而 agentic 负载贡献了其中大部分增长。

## 当下驱动 token 用量的模型作者们

![Model authors driving token usage](https://openrouter.ai/blog/images/deepseek-v4-animated.gif)

年初时，DeepSeek 在 OpenRouter 的周 token 流量占比还不到 10%。2 月到 3 月 agentic 工作开始起势、以前所未有的速度推高 token 用量时，DeepSeek 反而跌到了总量的 5%。它被上下夹击：上面是专有模型，下面是一波其他开源 LLM。

V4 模型家族的发布立竿见影地带来了正向影响。到 6 月初，DeepSeek 已赢得近 20% 的 token 份额，并且自 5 月中旬起一直是 OpenRouter 上的头号模型。

![Token share comparison between January and June 2026](https://openrouter.ai/blog/images/deepseek-v4-token-share-comparison.png)

2026 年 1 月与 6 月的直接对比，显示出偏好模型作者的转变有多快。期间 DeepSeek 的 token 份额实际上翻了一倍（从 9% 到 18%），而许多其他模型服务商的境遇也大幅起落。

包括小米、Minimax、腾讯在内的一批中国开源模型，过去 6 个月的 token 份额都在上升。这似乎是以两家头部美国模型公司为代价的——具体说是 Google 和 OpenAI。

![DeepSeek token usage by user type](https://openrouter.ai/blog/images/deepseek-v4-user-types.png)

DeepSeek 的翻倍并不局限于单一用户类型。到 6 月初，各类公司和个人都在使用越来越多的 DeepSeek token。爱好者用户（他们通常通过角色扮演、通用聊天、个人 agent 等面向消费的应用类别产生大量用量）现在将近三分之一的 token 路由给 DeepSeek 模型。

即使在 AI 原生公司或大型组织的用户中——按预期这两类可能更偏爱前沿闭源模型——6 月初发往 DeepSeek 的 token 流量也远多于年初。

![DeepSeek V4 pricing comparison](https://openrouter.ai/blog/images/deepseek-v4-pricing.png)

DeepSeek V4 Flash 在最便宜的端点上，输入 $0.09 / 输出 $0.18（每百万 token）。作为对比，GPT-5.5 目前定价为输入 $5 / 输出 $30（每百万 token）。

所以 V4 的 token 量突然暴涨，并没有让支出份额出现同样幅度的飙升——这并不令人意外。V4 的性价比到输出质量比是同类最佳——事实上足够好，以致各种规模的组织都开始把真正的 agentic 工作交给 DeepSeek。

## V4 是第一个足以胜任 agentic 负载的 DeepSeek 模型

![Agentic workloads token breakdown](https://openrouter.ai/blog/images/deepseek-v4-agentic-workloads.png)

我们在 API key 层面把 token 流量分为三大类（Agentic、Mixed、Human）。分类依据是一个 7 信号加权综合分数，输入包括 tool call 率、轮次数、间隔时间等。

谁都知道 agentic 工作比正常人类 AI 使用烧更多 token（按 OpenRouter 数据约为每请求 15 倍）。但值得记住的是，这场 agentic token 爆炸是 2026 年的现象，真正开始发力是今年 2 月初。

不过对某些模型作者来说，连这句话都说重了。

![Agentic vs human token usage over time](https://openrouter.ai/blog/images/deepseek-v4-agentic-vs-human.png)

Agentic 负载消耗的 token 大约就在 2 月 1 日前后超过了人类使用的 token。起初 agentic 工作只集中在少数几家模型作者那里，而那批作者并不包括 DeepSeek。

V4 的发布标志着 DeepSeek 正式入场 agentic 工作流竞赛。

![V4 Flash agentic token flow](https://openrouter.ai/blog/images/deepseek-v4-flash-agentic.png)

并非所有负载都会同时切换到最新模型。上面的图显示：今年前 5 个月里，DeepSeek token 用量中的人类活动始终绑定在 DeepSeek V3.2 上。

而 agentic 负载则把 V4 选为了首选模型。到 5 月底——发布仅一个月——V4-Flash 已占 DeepSeek agentic token 流量的 70%。

## DeepSeek 与中国模型的崛起

![US vs China token volume](https://openrouter.ai/blog/images/deepseek-v4-us-vs-china.png)

Token 流向两个国家创造的 LLM：美国和中国（其他国家的少量代表在图中那块小小的米色切片里）。2026 年 token 量爆炸式增长，但这份增长并未惠及其他国家的大模型。

![China token share in 2025 vs 2026](https://openrouter.ai/blog/images/deepseek-v4-china-share.png)

2025 年属于美国的 token——来自美国的模型约占所用 token 的四分之三。2026 年的竞争激烈得多：截至 6 月初，中国模型在 token 份额上实际已反超美国模型。

![Chinese models token surge](https://openrouter.ai/blog/images/deepseek-v4-chinese-models.png)

不出所料，自 4 月底 V4 发布以来，在中国模型中领衔冲锋的正是 DeepSeek。过去 6 周，几家美国头部玩家的 token 用量陷入平台期，而多个中国竞争者的 token 在 6 月开局时一路飙升。

当高性价比的 token 用量统治了夏天的头条，我们有理由预期这些更便宜但仍强大的开源模型会随时间吸引更多 token。正如《华尔街日报》在[这篇近期报道](https://www.wsj.com/tech/ai/the-ai-price-war-is-here-piling-pressure-on-openai-and-anthropic-86e1d21b?st=Jm3E6f&reflink=article_copyURL_share)（引用了 OpenRouter 数据）中所说：“初创公司和技术巨头都在混用搭配 AI 模型，以避开高溢价。”

DeepSeek V4 必将是这个组合中的一员。

## 方法说明

关于这些数字如何统计的几点说明：

- **来源**：OpenRouter 的请求日志。
- **样本量**：2026 年 1 月 1 日至 6 月 14 日，超过 450 万亿 token。
- **份额指标**：所有“份额”数字指 token 量份额（输入与输出合计），不是支出份额。如定价部分所述，对 V4 这样的低成本模型，两者可能差异巨大。
- **活动类型**：我们在 API key 层面把 token 流量分为三大类（Agentic、Mixed、Human），依据是包含 tool call 率、轮次数、间隔时间等输入的 7 信号加权综合分数。由于划分发生在 key 层面，做混合工作的单个 key 按其主导模式分类，而非按请求分类。
