# ElevenLabs 现已在 OpenRouter 上

萨莎·布卢门菲尔德·10/7/2026

ElevenLabs 现已在 OpenRouter 上提供九个文本到语音模型和两个语音到文本模型。

如果您的应用程序已经通过 OpenRouter 与语言模型对话，那么它现在也可以说和听。使用 Eleven v4 通过音调方向和传递来叙述长格式内容，使用 v4 Turbo 为您的客服人员提供更快的语音回复，或者使用 Scribe v2 转录带有说话者标签的对话。您不需要单独的 ElevenLabs 计划。只需使用您的 OpenRouter API 密钥调用“POST /api/v1/audio/speech”和“POST /api/v1/audio/transcriptions”即可。

*截至 10 月 19 日上午 8 点（太平洋时间），所有 OpenRouter 客户的所有 ElevenLabs 型号均可享受 OpenRouter 标价 50% 的折扣*

## Which model to use

从三个模型开始，然后在工作需要时使用其余模型：

- **旁白、角色、产品视频：** 11 v4。音频标签让脚本承载表演。
- **语音代理和实时回复：** 11 v4 Turbo，ElevenLabs 构建它用于实时使用，速率是 v4 的一半。
- **文字记录、会议记录、说明文字：** Scribe v2，带有演讲者标签和单词时间戳。

当长格式音频需要速度控制时，请使用 Multilingual v2；对于每个请求最多 40,000 个字符的大容量语音，请使用 Flash v2.5。 Scribe v2 Medical 针对医学术语进行了微调。

| ---| ---| ---|

## 演练：从第一个 MP3 到语音代理

我们将分三步构建一个小型产品之旅。 《前十一》v4 对此进行了叙述。然后语音代理回答相关问题，最后 Scribe v2 将团队的审核会议转化为笔记，显示谁说了什么。如果请求的行为不符合您的预期，请查看最后的提示。

设置一次密钥：
```
export OPENROUTER_API_KEY="your-api-key"
```
### 第 1 步：用 Eleven v4 讲述产品之旅

从一行叙述开始：
```
curl https://openrouter.ai/api/v1/audio/speech \
  --fail-with-body \
  -H "Authorization: Bearer $OPENROUTER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "elevenlabs/eleven-v4",
    "input": "[cheerfully] Welcome to the tour. [whispering] Let me show you the shortcut first.",
    "voice": "george",
    "response_format": "mp3"
  }' \
  --output intro.mp3
```
`voice` 采用 ElevenLabs 21 个预制声音中的任何一个的名称（此处为 `george`）；名称不区分大小写。请注意显式的“response_format”——请参阅两者的**首次请求提示**。

括号内的单词是音频标签。 11 个 v4 和 v3 读取“[耳语]”、“[笑]”、“[叹息]”和“[好奇]”等标签作为传递方向，而不是说出它们。标签计入您的计费字符数。

完整的导览脚本比一个请求允许的长度要长（v4 上为 10,000 个字符，v3 上为 5,000 个字符），因此请按段落边界将其拆分。仅 ElevenLabs 设置位于“provider.options.elevenlabs”下。将相邻文本作为“previous_text”和“next_text”传递，以便语调在连接之间保持一致，并修复“seed”，以便重新运行更具可重复性：
```
import os

import requests

API = "https://openrouter.ai/api/v1"
HEADERS = {"Authorization": f"Bearer {os.environ['OPENROUTER_API_KEY']}"}
NARRATOR = "george"


def split_paragraphs(text: str, limit: int = 9000) -> list[str]:
    chunks, current = [], ""
    for para in text.split("\n\n"):
        if current and len(current) + len(para) + 2 > limit:
            chunks.append(current)
            current = para
        else:
            current = f"{current}\n\n{para}" if current else para
    return chunks + [current] if current else chunks


chunks = split_paragraphs(open("tour-script.txt").read())

with open("tour.mp3", "wb") as out:
    for i, chunk in enumerate(chunks):
        options = {"seed": 7}
        if i > 0:
            options["previous_text"] = chunks[i - 1][-500:]
        if i + 1 < len(chunks):
            options["next_text"] = chunks[i + 1][:500]
        r = requests.post(
            f"{API}/audio/speech",
            headers=HEADERS,
            json={
                "model": "elevenlabs/eleven-v4",
                "input": chunk,
                "voice": NARRATOR,
                "response_format": "mp3",
                "provider": {"options": {"elevenlabs": options}},
            },
        )
        r.raise_for_status()
        out.write(r.content)
```
### 第 2 步：通过语音代理回答问题

现在让用户大声提出游览问题。语音代理链接三个模型：用于问题的 Scribe v2、用于答案的聊天模型以及用于回复的 Eleven v4 Turbo。 ElevenLabs 构建了 v4 Turbo 供实时使用，其计费费率是 v4 的一半。
```
import base64


def transcribe(path: str) -> str:
    with open(path, "rb") as f:
        audio_b64 = base64.b64encode(f.read()).decode()
    r = requests.post(
        f"{API}/audio/transcriptions",
        headers=HEADERS,
        json={
            "model": "elevenlabs/scribe-v2",
            "input_audio": {"data": audio_b64, "format": "wav"},
        },
    )
    r.raise_for_status()
    return r.json()["text"]


def answer(question: str) -> str:
    r = requests.post(
        f"{API}/chat/completions",
        headers=HEADERS,
        json={
            "model": "openai/gpt-5-mini",
            "messages": [
                {"role": "system", "content": "You are the product tour guide. Answer in one or two sentences."},
                {"role": "user", "content": question},
            ],
        },
    )
    r.raise_for_status()
    return r.json()["choices"][0]["message"]["content"]


def speak(text: str, out_path: str) -> None:
    r = requests.post(
        f"{API}/audio/speech",
        headers=HEADERS,
        json={
            "model": "elevenlabs/eleven-v4-turbo",
            "input": text,
            "voice": NARRATOR,
            "response_format": "mp3",
        },
    )
    r.raise_for_status()
    with open(out_path, "wb") as f:
        f.write(r.content)


speak(answer(transcribe("question.wav")), "reply.mp3")
```
转录响应是 JSON，其中包含“text”中的转录内容和一个报告音频秒数和请求的美元“成本”的“usage”对象。将“openai/gpt-5-mini”替换为[目录](https://openrouter.ai/models)中的任何聊天模型，而不接触音频通话，并保持相同的“声音”，以便代理听起来像步骤 1 中的旁白者。

### 步骤 3：将评审会议变成带有演讲者标签的笔记

当您的团队开会回顾游览时，Scribe v2 可以告诉您谁说了什么。以多部分形式上传录音，请求带有单词时间戳的“verbose_json”，并在“provider.options.elevenlabs”下设置“diarize”。响应中的每个词都会有一个说话者。如果您知道会议中有多少人，请传递“num_speakers”以改善分配。
```
curl https://openrouter.ai/api/v1/audio/transcriptions \
  --fail-with-body \
  -H "Authorization: Bearer $OPENROUTER_API_KEY" \
  -F file="@tour-review.mp3" \
  -F model="elevenlabs/scribe-v2" \
  -F response_format="verbose_json" \
  -F "timestamp_granularities[]=word" \
  -F provider='{"options": {"elevenlabs": {"diarize": true, "num_speakers": 3, "tag_audio_events": true}}}'
```
“words”中的每个条目都有“word”、“start”、“end”、“confidence”、“speaker”（整数）和“speaker_label”（“speaker_0”、“speaker_1”等）。 “tag_audio_events”在单词旁边添加了诸如“（笑声）”之类的条目。按“speaker”对连续单词进行分组以获得轮次，然后将轮次发送到聊天模型以获取摘要和操作项：
```
def to_turns(words: list[dict]) -> list[str]:
    turns: list[tuple[int, list[str]]] = []
    for w in words:
        if turns and turns[-1][0] == w.get("speaker"):
            turns[-1][1].append(w["word"])
        else:
            turns.append((w.get("speaker"), [w["word"]]))
    return [f"Speaker {s}: {' '.join(ws)}" for s, ws in turns]
```
上传上限为 25 MB，涵盖约 27 分钟的 128 kbps MP3。

对于较长的录音，请传递公共 URL，ElevenLabs 会直接下载文件，因此 25 MB 上限不适用：
```
"input_audio":{ "url": "https://example.com/tour-review.mp3" }
```
非常长的文件仍然可能会遇到 180 秒的上游请求超时，因此请分割运行时间较长的记录。

## 针对您的首次请求的提示

- **按名称或 ID 选择声音。** 对于“voice”，请按名称传递 ElevenLabs 21 个预制声音中的任何一个：“george”、“sarah”、“adam”、“alice”、“bella”、“brian”、“charlie”、“daniel”、“jessica”、“roger”、“will”等（每个模型页面上的完整列表）。名称不区分大小写。要使用任何其他语音，请将其 ElevenLabs 语音 ID 作为“voice”传递 - 从 [ElevenLabs 语音库](https://elevenlabs.io/app/voice-library) 复制它。您在自己的 ElevenLabs 帐户中实时克隆或设计的声音，因此请使用带有 [BYOK](https://openrouter.ai/docs/guides/overview/auth/byok) 的声音。
- **当您想要一个可以播放的文件时，询问“mp3”** 如果您省略“response_format”，我们的语音端点将返回原始 PCM（24 kHz 的 16 位小端单声道）。这适合音频管道，但大多数玩家无法打开它。设置 `"response_format": "mp3"` 以获得可播放的 44.1 kHz、128 kbps 文件。
- **使用多语言 v2 或 Flash 进行速度控制** 多语言 v2 和 Flash 将“速度”从 0.7 调整到 1.2。 11 v4 和 v4 Turbo 没有速度控制并拒绝非默认“速度”，因此将其保留在这些模型上并使用音频标签更改节奏。
- **分割长脚本** 每个模型都有每个请求的字符限制（请参阅模型表）。音频标签会计入限制和计费字符数。如步骤 1 中那样在段落边界上进行拆分，并传递“previous_text”和“next_text”，以便连接听起来很自然。
- **ElevenLabs 特定设置位于`provider.options.elevenlabs`下**文本转语音接受`seed`、`previous_text`、`next_text`、`language_code`、`apply_text_normalization`、`apply_language_text_normalization`、`pronunciation_dictionary_locators`、`voice_settings`（`stability`、`similarity_boost`、 `style`、`use_speaker_boost`、`speed`）和 `output_format`（ElevenLabs 格式名称，例如 `mp3_22050_32` 或 `pcm_16000`；它必须与您的 `response_format` 编解码器匹配）。语音转文本接受“diarize”、“num_speakers”、“diarization_threshold”、“tag_audio_events”、“no_verbatim”和“seed”。 `num_speakers` 和 `diarization_threshold` 需要 `diarize: true`，并且您可以设置其中之一，而不是同时设置两者。完全按照列出的方式使用字段名称。不在这些列表中的键将被忽略；列出的键值错误会返回 400。
- **Scribe 返回三个字母的语言代码** 您可以发送两个字母的“语言”提示 (`en`)。检测到的语言以 ISO 639-3 代码 (`eng`) 的形式返回。

## 开始使用

- 创建一个 [OpenRouter API 密钥](https://openrouter.ai/settings/keys)。
- 使用上面步骤 1 中的curl 示例提出您的第一个请求。
- 对于每个参数，请参阅[文本转语音](https://openrouter.ai/docs/guides/overview/multimodal/tts)和[语音转文本](https://openrouter.ai/docs/guides/overview/multimodal/stt)指南。

文本转语音按输入字符计费，计为 Unicode 代码点，因此表情符号或 CJK 字符计一次。音频标签算作字符。 Scribe 按每秒音频计费，每个转录响应上的 use.cost 字段会告诉您该请求的成本。我们通过ElevenLabs定价，不加价；请参阅每个型号页面了解当前费率。

*已经有 ElevenLabs 帐户？*

使用 [BYOK](https://openrouter.ai/docs/guides/overview/auth/byok) 添加密钥，以使用您自己的克隆语音、发音词典和更高质量的格式，例如 mp3_44100_192。

创建 [OpenRouter API 密钥](https://openrouter.ai/settings/keys)，或先在 [Playground](https://openrouter.ai/playground) 中尝试模型。 [文本转语音](https://openrouter.ai/docs/guides/overview/multimodal/tts) 和 [语音转文本](https://openrouter.ai/docs/guides/overview/multimodal/stt) 指南具有完整的请求参考。
