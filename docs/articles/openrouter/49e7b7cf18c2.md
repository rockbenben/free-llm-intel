## Nitro 变体：速度优先 ⚡

`:nitro` 后缀现在在所有模型上通用可用！`:nitro` 不再是单独的端点，而是一个按**吞吐量**（tokens per second）对服务商排序的快捷方式，让你在所选模型上始终拿到可用的最快服务商。

### 使用 Nitro 快捷方式的示例：

```
{
  "model": "meta-llama/llama-3.1-70b-instruct:nitro",
  "messages": [{ "role": "user", "content": "Hello" }]
}
```

等价于在 API 中把 `provider.sort` 设为 `"throughput"`。

## Floor Price：成本优先 💰

想把成本降到最低？`:floor` 快捷方式确保 OpenRouter 始终为你的模型选择价格最低的服务商。

### 使用 Floor 快捷方式的示例：

```
{
  "model": "meta-llama/llama-3.1-70b-instruct:floor",
  "messages": [{ "role": "user", "content": "Hello" }]
}
```

等价于在 API 中把 `provider.sort` 设为 `"price"`。

## 高级服务商排序

如果你想对服务商选择有更明确的控制，可以在 `provider` 偏好中设置 `sort` 字段。这会关闭 OpenRouter 默认的负载均衡，并按你选择的属性对服务商排序：

- **`"price"`**：优先成本最低的服务商
- **`"throughput"`**：优先最快的服务商（tokens/sec 最高）
- **`"latency"`**：优先延迟最低的服务商

### 显式排序的示例：

```
{
  "model": "meta-llama/llama-3.1-70b-instruct",
  "messages": [{ "role": "user", "content": "Hello" }],
  "provider": {
    "sort": "throughput"
  }
}
```
