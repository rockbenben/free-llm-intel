我们的每月 Product Spotlight 会精选过去一个月里最重要的几项发布。

## OpenRouter 上的 Claude Code

现在可以在 Claude Code 中使用 OpenRouter，从而追踪团队用量并控制成本。

[试用](https://openrouter.ai/docs/guides/guides/claude-code-integration) | [公告](https://x.com/OpenRouterAI/status/2002067582569066979)

## Response Healing：自动 JSON 修复

LLM 破坏 JSON 的频率远比你想的高。OpenRouter 现在会在畸形响应（尾逗号、未转义字符、缺失括号）到达你的应用之前自动修复它们。在 Gemini 2.0 Flash 上缺陷减少 80%，在 Qwen3 235B 上减少 99.8%。免费，仅限非流式，开销小于 1ms。在 Settings > Plugins 下启用。

[公告](https://openrouter.ai/announcements/response-healing-reduce-json-defects-by-80percent)

## Chatroom 通知

Chatroom 现在会在长响应完成时发送浏览器通知，不用再盯着标签页等了。

[公告](https://x.com/OpenRouterAI/status/2000980715501138180)
