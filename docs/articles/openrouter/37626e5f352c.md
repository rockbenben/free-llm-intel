# 达到您的Claude Code使用限制吗？如何继续编码

开放路由器 ·10/28/2026

![达到您的Claude Code使用限制？如何保持编码](https://openrouter.ai/blog/images/claude-code-usage-limit.png)！[达到您的 Claude 代码使用限制？如何保持编码](https://openrouter.ai/blog/images/claude-code-usage-limit-dark.png)

当您达到 Claude Code 使用限制时，您可以通过在 OpenRouter API 密钥上运行 Claude Code 来继续编码。通过 OpenRouter，Claude Code 在按令牌付费的 API 密钥上运行，具有相同的 Claude 模型，并且没有 5 小时窗口。您设置了三个环境变量，并在重置时切换回您的计划。

我们使用 Claude Code 测试了此设置。下面的产出和成本来自这些运​​行。

## Tl;博士

- 您的Claude计划有五个小时的限制和每周的限制。 OpenRouter API 密钥两者都没有。您需要为您使用的代币付费。
- 最快的设置是 Ori Harness：`ori claude` 在该会话的 OpenRouter 上启动 Claude Code，通过浏览器登录，无需粘贴密钥。
- 要手动执行此操作，三个环境变量将 Claude Code 指向 OpenRouter。我们将它们放入名为“claude-or”的 shell 函数中，因此“claude”仍然使用您的计划。
- 从Claude Sonnet 5.5 开始。典型的短 Claude Code 会话在 Sonnet 5.5 上花费 0.16 美元，在 Opus 5.5 上花费 0.31 美元，在 Haiku 5.5 上花费不到 1 美分。
- 不要相信 Claude Code 打印的成本。在我们的测试中，它显示每次运行费用为 0.375 美元，而我们的费用为 0.008 美元。请检查您的密钥或“活动”页面。
- 当您的计划重置时，再次输入“claude”。没有什么可以撤销的。

## 为什么 Claude Code 达到了使用限制？

Claude计划有两个同时运行的限制。第一个在第一次提示后五个小时重置。第二个每 7 天重置一次。 Anthropic 没有公布其中任何一个提示的确切数量。 Claude Code 使用的令牌比普通聊天多得多，因此您可能会在任务中用完。当这种情况发生时，Claude·科德会停下来并告诉您限制何时重置。 [Anthropic 关于使用限制的帮助文章](https://support.claude.com/en/articles/11647753-how-do-usage-and-length-limits-work) 解释了这两个限制。

OpenRouter API 密钥不能以这种方式工作。您为使用的每个代币付费，只要有信用就可以继续使用。

## 最快的方法：通过 Ori Harness 运行 Claude Code

[Ori Harness](https://openrouter.ai/docs/guides/ori/harness) 在 OpenRouter 设置到位的情况下启动计算机上已有的 Claude 代码。安装它并通过它启动 Claude Code：
```
curl -fsSL https://openrouter.ai/labs/ori/install.sh | bash
ori claude --model anthropic/claude-sonnet-5.5
```
Ori 打开浏览器，以便您可以使用 OpenRouter 帐户登录。它使用 OAuth，因此无需创建或粘贴密钥。只有以 `ori claude` 启动的会话才会在 OpenRouter 上运行，因此普通的 `claude` 会继续使用您的计划，并且当您的计划重置时，您可以通过输入 `claude` 切换回来。使用量记入您的 OpenRouter 账单。如果您在组织中，则帐户预算限制的 [guardrail](https://openrouter.ai/docs/guides/features/guardrails) 会限制其可以支出的金额，并且 OpenRouter 也将其应用于 Ori 会话。

以下步骤使用 API 密钥和 shell 函数手动执行相同的操作。如果您想要一个具有自己的信用额度且适用于任何帐户的密钥，请使用它们。步骤 4 中的成本建议适用于任何一种情况。

## 步骤 1：获取 OpenRouter API 密钥并设置限制

在[API密钥页面](https://openrouter.ai/settings/keys)上创建一个密钥并为其设置信用额度。我们将其设置为 4 美元。这样，即使是长时间的会话花费也不会超过 4 美元。信用限额是控制 OpenRouter 支出的几种方法之一。 [我们的团队 AI 支出管理指南](https://openrouter.ai/blog/insights/governing-team-ai-spend/) 涵盖了其他内容。

要检查限制，请向我们的 API 询问您的密钥：
```
curl https://openrouter.ai/api/v1/key \
  -H "Authorization: Bearer $OPENROUTER_API_KEY"
```
这是响应中重要的部分：
```
{
  "data": {
    "limit": 4,
    "limit_remaining": 4,
    "usage": 0
  }
}
```
“limit_remaining”数字告诉您钥匙上还剩下多少钱。您可以随时运行此检查。发出请求后，可能需要几秒钟才能显示新的总数。

## 步骤 2：添加切换到您的密钥的命令

您可以将变量添加到您的 shell 配置文件中，但是每个 Claude Code 会话都会对您的密钥进行收费。我们希望正常的“claude”命令继续使用您的计划，因此我们将变量放在一个小 shell 函数中。将其添加到“~/.zshrc”或“~/.bashrc”：
```
claude-or() {
  ANTHROPIC_BASE_URL="https://openrouter.ai/api" \
  ANTHROPIC_AUTH_TOKEN="$OPENROUTER_API_KEY" \
  ANTHROPIC_API_KEY="" \
  ANTHROPIC_DEFAULT_SONNET_MODEL="anthropic/claude-sonnet-5.5" \
  ANTHROPIC_DEFAULT_OPUS_MODEL="anthropic/claude-opus-5.5" \
  ANTHROPIC_DEFAULT_HAIKU_MODEL="anthropic/claude-haiku-5.5" \
  CLAUDE_CODE_SUBAGENT_MODEL="anthropic/claude-haiku-5.5" \
  claude "$@"
}
```
前三行是重要的：

- `ANTHROPIC_BASE_URL` 告诉 Claude Code 将其请求发送给我们。
- `ANTHROPIC_AUTH_TOKEN` 保存您的 OpenRouter 密钥。
- `ANTHROPIC_API_KEY` 必须为空。如果不是，Claude Code 可能会尝试登录 Anthropic。

其他四行是可选的。他们告诉 Claude Code 在十四行诗、作品和俳句中使用哪种Claude模型。他们还向 Haiku 5.5 发送子代理（Claude Code 自行启动的较小辅助任务）。

这些变量仅在您输入“claude-or”时适用。保存文件并打开一个新终端，以便该功能准备就绪。

![图表：在终端中输入 claude 使用您的 Claude 计划，其限制为五小时和每周。输入 claude-or 在您的 API 密钥上将相同的会话发送到 OpenRouter，按令牌付费，没有使用窗口，并且 OpenRouter 提供来自 Anthropic、Amazon Bedrock 和 Google Vertex 的相同 Claude 模型。](https://openrouter.ai/blog/images/claude-code-usage-limit-claude-or.png)

## 步骤 3：检查 Claude Code 是否正在使用您的密钥

在开始实际工作之前，请检查 Claude Code 是否将其请求发送到 OpenRouter 而不是您的计划。最快的方法是发送一个简短的提示，然后查看哪个型号做出了回答。在你的终端中运行：
```
claude-or --model sonnet -p "Reply with exactly: ok" --output-format json
```
这是我们回应中最重要的部分：
```
{
  "is_error": false,
  "result": "ok"
}
```
回复没有错误。完整输出中的“modelUsage”字段命名了回答的模型，在我们的运行中它是“anthropic/claude-sonnet-5.5”。我们使用“--model haiku”和名为“anthropic/claude-haiku-5.5”的“modelUsage”运行相同的提示。

然后再次运行步骤 1 中的密钥检查。如果“使用量”增加，则请求将按您的密钥计费，而不是按计划计费。如果没有，Claude·科德就不会获取这些变量。打开一个新终端并重试。

## 步骤 4：降低成本

在密钥上，您为每条消息付费。下表显示了三款 Claude 5.5 型号的价格。它还显示了 OpenRouter 上 2 到 9 条消息的真实 Claude Code 会话的中值成本。

|型号|每 100 万个输入代币的价格 |每 100 万个输出代币的价格 |会话成本中值（2 到 9 条消息）|
| --- | --- | --- | --- |
|Claude Opus 5.5 | 4.00 美元 | 20.00 美元 | 0.305 美元 |
|Claude Sonnet 5.5 | 2.00 美元 | 10.00 美元 | 0.155 美元 |
|Claude Haiku 5.5 | 0.10 美元 | 0.50 美元 | 0.007 美元 |

*截至 2026 年 10 月 21 日的价格。会话成本来自我们的[session-cost 数据集](https://openrouter.ai/docs/api/api-reference/datasets/cost-per-session-by-harness-and-model)，涵盖截至 2026 年 10 月 18 日的 30 天。*

从十四行诗 5.5 开始。它每次会话的成本约为 Opus 5.5 的一半，可以处理大多数日常编码。当问题很难时，输入“/model opus”进行切换，完成后再切换回来。如果您在我们的 API 上构建自己的应用程序，当更便宜的模型对其答案没有信心时，您还可以[自动将请求移至更强大的模型](https://openrouter.ai/blog/insights/confidence-thresholds-for-model-escalation-routing/)。

每个新会话都以 Claude Code 自己的指令和工具列表的约 28,000 个令牌开始（我们在 Claude Code 2.1.307 上运行时为 28,156 个，版本之间的数量会发生变化）。它们在第一个请求时写入提示缓存，因此第 3 步中的单字提示在 Sonnet 5.5 上花费约 0.07 美元，在 Haiku 5.5 上花费不到半美分。

俳句的次级代理很便宜。当我们要求 Sonnet 5.5 启动子代理时，主代理在 Sonnet 5.5 上运行，子代理在 Haiku 5.5 上运行，正如函数设置的那样。

Haiku 还可以自行处理一些小问题。我们为 Haiku 5.5 提供了一个购物车文件，其中包含两个错误和三个失败的测试。它修复了这两个错误，所有三个测试都通过了，我们为这次运行支付了 0.008 美元的费用。

不要依赖 Claude Code 打印的成本。对于俳句运行，Claude Code 报告为 0.375 美元，但我们的费用为 0.008 美元。 Claude Code 使用 Anthropic 自己的价格表对会话进行定价，并在无法识别 OpenRouter 模型名称时进行猜测。要查看您的实际支出，请使用步骤 1 命令检查“limit_remaining”，或打开您的[活动页面](https://openrouter.ai/activity)。

## 步骤 5：当您的计划重置时切换回来

当您的计划的限制重置时，请输入“claude”而不是“claude-or”。您不需要更改任何内容，因为 OpenRouter 设置仅存在于函数内部。在我们的测试中，简单的“claude”回答了计划的模型，并且 OpenRouter 密钥的用法没有改变。

## 如果 API 密钥用完会发生什么？

当您的密钥达到其信用额度或您的帐户信用额度用完时，我们会在请求到达模型之前停止请求并返回错误。该错误包含一个“limit_source”字段，告诉您原因：

- `openrouter_key_limit` 表示密钥已用完其限制。
- `openrouter_credits` 表示您的帐户信用不足。

要继续操作，请在 API 密钥页面上提高密钥限制或为您的帐户添加积分。我们的[限制页面](https://openrouter.ai/docs/api_reference/limits)解释了各种限制，包括团队管理员可以设置的限制。

## 常见问题

### OpenRouter 对 Claude Code 有使用限制吗？

没有五小时或每周的限制。唯一的限制是支出：您拥有多少信用额度、您为密钥设置的限制以及您的团队管理员设置的任何预算。

### 模型与我的Claude计划中的模型相同吗？

是的。他们是 Anthropic 的Claude模型。我们从 Anthropic 以及 Amazon Bedrock 和 Google Vertex 等云提供商处获取它们，如果其中一个提供商出现问题，[我们会将您的请求发送给另一提供商](https://openrouter.ai/docs/guides/routing/provider-selection)。对于 Claude Code，我们建议[将 Anthropic 设置为您的首选提供商](https://openrouter.ai/docs/guides/routing/provider-selection)，因为 Claude Code 只能保证与 Anthropic 配合使用。

### 当我达到限额时，我可以使用更便宜的型号吗？

是的。 Sonnet 5.5 每次会话的费用约为 Opus 5.5 的一半，而 Haiku 5.5 每次会话的费用不到 1 美分。您还可以将不同的模型放入函数的变量之一中。很多人通过 OpenRouter 使用 Claude Code 中的其他模型。本月，GLM 5.3 Flash 是[我们应用程序页面上的 Claude Code](https://openrouter.ai/apps/claude-code) 中第二常用的模型，仅次于 Claude Opus 5.5。不过，Claude Code 是为 Claude 模型构建的，因此请先在小任务上尝试任何其他模型。如果您从自己的代码调用我们的 API，您还可以[列出后备模型](https://openrouter.ai/docs/guides/routing/model-fallbacks)，以便在第一个模型失败时请求转移到第二个模型。有关降低每次请求费用的更多方法，请参阅[我们的 OpenRouter 上成本最低的 LLM 推理指南](https://openrouter.ai/blog/tutorials/how-to-get-the-lowest-cost-llm-inference-on-openrouter/)。

### Claude Code使用限制何时重置？

五小时限制会在该窗口中出现第一个提示后五小时重置。每周限制在开始 7 天后重置。 Claude Code 在停止时显示重置时间，因此您知道何时再次输入“claude”。

### 如何查看我还剩多少使用量？

在您的Claude计划中，Claude Code会告诉您限制何时会在您停止时重置。在 OpenRouter 上，使用“GET /api/v1/key”检查“limit_remaining”，或打开您的“活动”页面。
