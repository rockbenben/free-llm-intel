## 🚀 核心特性

- 适用于 OpenRouter 上可用的任意 LLM。
- 能处理所有类型的 PDF，包括纯图像的扫描件。
- 对 Gemini、Anthropic、OpenAI 等提供商会自动使用其原生 PDF 支持。
- 可将 PDF 中嵌入的图像直接发送给多模态模型。
- 可与 web search 或 Auto Router 组合使用，获得更强的功能。
- 可通过 API 或直接在 OpenRouter Chatroom 使用，单个请求支持多个 PDF 和多个模型。

## ⚙️ 定价

可选两种 PDF 处理引擎：

- `mistral-ocr`（默认）：支持 OCR，可提取文本和嵌入图像——每 1000 页 $2。
- `pdf-text`：仅提取文本，无 OCR、无图像支持——免费。
