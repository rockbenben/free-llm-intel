## 🔄 变化内容

我们将取消固定的 $0.35 Stripe 手续费

对大多数充值而言，总费用将会更低

更容易计算——不用再反推公式了

## 💵 新费用结构

非加密货币支付：订单金额的 5.5%，最低手续费 $0.80

加密货币支付：固定 5.0%，无最低手续费

BYOK 费用：当前按用量 5% 的费用未来将取消，改为固定月度订阅（定价待定——欢迎提建议！）

## 📉 实际影响

| Order Size | Old Fee | New Fee |
| --- | --- | --- |
| $5 | $0.61 | $0.80 |
| $10 | $0.88 | $0.80 |
| $25 | $1.67 | $1.38 |
| $100 | $5.61 | $5.50 |
| $1,000 | $52.98 | $55.00 |

在新的费用结构下，大多数用户的总成本都会下降。

## 🧾 无需任何操作

计费将自动更新——你不需要改任何东西。
