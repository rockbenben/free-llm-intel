# Happy New Year! Introducing a new Auto Router

OpenRouter ·1/1/2025 · Updated 6/11/2026

Happy new year! To start off 2025, we have an upgrade to the [Auto Router](https://openrouter.ai/openrouter/auto):

- 🧠 Lots more models: it now routes to 19 different models, optimizing for quality.
- 🗨️ Chatroom UI: the chatroom now more clearly shows which model was used. It’s available via API as well!
- Meta Model: we’re testing out routing powered by Not Diamond’s meta model.

The API is currently free, but may change in the future, along with more customizability.

Learn more [here](https://openrouter.ai/openrouter/auto)
