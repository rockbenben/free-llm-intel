# Claude Code要多少钱？按模型划分的实际会话成本

开放路由器·10/30/2026

![Claude Code要多少钱？按模型划分的实际会话成本](https://openrouter.ai/blog/images/claude-code-cost.png)！[Claude Code 的成本是多少？按模型划分的实际会话成本](https://openrouter.ai/blog/images/claude-code-cost-dark.png)

Claude Code可以免费安装。你所支付的费用就是它所调用的模型。如果您在 API 密钥上运行 Claude Code，则使用 Claude Opus 5.5 进行 2 到 9 轮的短会话的费用中值为 0.31 美元，而 10 到 49 轮的长会话的费用为 1.39 美元。 Claude Sonnet 5.5 的相同课程费用为 0.16 美元和 0.60 美元。

这些中位数来自截至 2026 年 10 月 18 日的 30 天内 OpenRouter 上的真实 Claude Code 会话。[Claude Code](https://openrouter.ai/apps/claude-code) 是我们 10 月 21 日每日应用排名中的顶级应用，因此它们背后有很多使用情况。下面，我们使用该数据来显示每个模型上的会话成本，然后如何在 OpenRouter 上运行 Claude Code，以便您可以为每个会话选择模型，查看其成本并限制支出。

## Tl;博士

- Claude Code是免费的。您可以通过 Claude 订阅或 API 密钥上的每个令牌为其调用的模型付费。
- 在 API 密钥上，Opus 5.5 上 2 到 9 回合的费用中位数为 0.31 美元，Sonnet 5.5 上 0.16 美元，Haiku 5.5 上不到 1 美分。
- 大部分成本是 Claude Code 自己的上下文，在第一个请求时写入提示缓存，并在之后的每个回合中读回。
- 将 Sonnet 设为默认值，将后台作业和子代理发送到 Haiku，保持会话简短，并设置密钥的信用限额。
- 使用 `ori claude --model <model>` 在 OpenRouter 上运行 Claude Code，为每个会话选择模型。您的“活动”页面显示每个会话的实际费用。

## Claude Code要花钱吗？

CLI 无需任何费用。它发出的每个请求都会发送到一个模型，您可以通过两种方式之一为这些请求付费。 Claude 订阅涵盖了它们的使用限制，并且 API 密钥按令牌收费。这篇文章介绍了 API 密钥途径，因为您可以在其中查看和控制每个会话的成本。通过 OpenRouter，相同的密钥适用于 Claude 模型以及 Claude Code 可以调用的其他模型。

在 OpenRouter 上运行 Claude Code 的最快方法是 [Ori Harness](https://openrouter.ai/docs/guides/ori/harness)。它会启动您计算机上已有的 Claude 代码并设置 OpenRouter 设置，并通过浏览器登录您，因此无需粘贴密钥：
```
curl -fsSL https://openrouter.ai/labs/ori/install.sh | bash
ori claude --model anthropic/claude-sonnet-5.5
```
只有以“ori claude”启动的会话才会在 OpenRouter 上运行。普通的“claude”继续使用您的订阅。

|型号| 1 回合 | 2-9 圈 | 10–49 圈 |
| ---| ---| ---| ---|
|Claude寓言5.1 | 0.342 美元 | 1.049 美元 | $3.734 | $3.734
|Claude Opus 5.5 | 0.136 美元 | 0.305 美元 | 1.390 美元 |
|Claude Sonnet 5.5 | 0.071 美元 | 0.155 美元 | 0.596 美元 |
|Claude Haiku 5.5 | 0.002 美元 | 0.007 美元 | 0.053 美元 |
|基米K3 | 0.040 美元 | 0.117 美元 | 0.825 美元 |
| GLM-5.3 | 0.010 美元 | 0.044 美元 | 0.363 美元 |
| [DeepSeek V4.1 Flash](https://openrouter.ai/deepseek/deepseek-v4.1-flash) | 0.003 美元 | 0.009 美元 | 0.047 美元 |
| GPT-6 露娜 | 0.002 美元 | 0.005 美元 | 0.024 美元 |

*截至 2026 年 10 月 18 日的 30 天内，每次 Claude Code 课程的中位成本（按型号和圈数）。*

您选择的型号对成本影响最大。一回合《神鬼寓言 5.1》的费用比一长段俳句 5.5 的费用要高。一旦您选择了模型，会话时长就最为重要。 10 到 49 回合的 Opus 片段的成本约为一回合片段的十倍，而 Sonnet 5.5 的每个长度的成本约为 Opus 5.5 的一半或更少。

## 为什么一回合的费用为 14 美分？

大部分成本是 Claude Code 自己的上下文，而不是您的提示。我们通过 OpenRouter 在 Claude Code 2.1.307 上的空文件夹中针对 Opus 5.5 运行了“claude -p "Reply with strict: ok"”。回复是 4 个令牌，但会话将 17,047 个令牌写入提示缓存。这些标记是 Claude Code 的系统提示符和工具定义。按照 Opus 5.5 的缓存写入价格为每百万代币 5 美元，它们的成本为 0.085 美元。真实的项目会添加自己的指令和 Claude Code 读取的文件，这就是为什么数据集的一圈中位数更高，为 0.136 美元。启动令牌的数量也会因 Claude Code 版本和设置而异。

一旦该上下文进入缓存，后续请求就会以每百万代币 0.20 美元的价格将其读回，这比写入它便宜 25 倍。这就是为什么第一轮之后的每一轮增加的量都比第一轮少。随着上下文的增长，成本再次攀升，因为 Claude Code 会将其读取的每个新文件写入缓存一次，然后在之后的每个回合中将其读回。我们的[提示缓存指南](https://openrouter.ai/docs/guides/best-practices/prompt-caching)介绍了写入和读取的计费方式。

## 我们自己的课程花费了多少？

该数据集显示了其他人的会话费用。为了比较我们控制的任务的模型，我们给了 Claude Code 一个小型发票库，其中包含三个错误和五个失败的测试。我们通过 OpenRouter 在每个模型上运行了三次，每次运行都修复了所有三个错误。

|型号|每次会话费用中位数 |转 |从缓存中读取令牌 |写入缓存的令牌 |
| ---| ---| ---| ---| ---|
|作品 5.5 | 0.098 美元 | 5 | 111,000 | 9,800–10,300 |
|十四行诗 5.5 | 0.062 美元 | 5 | 125,000–154,000 | 15,000–43,500 |
|俳句 5.5 | 0.0052 美元 | 6–8 | 126,000–199,000 | 16,400–45,800 |

这些成本低于数据集 2 到 9 回合的中位数，原因有两个。我们的任务很小，我们连续运行每个模型的三个会话，因此它们共享一个热缓存。这也是为什么 Opus 运行向缓存写入的令牌比我们的一轮测试少的原因。对于真实项目的新会话，上面的数据集中位数是更好的指南。模型仍然以相同的顺序着陆。十四行诗的成本约为作品的三分之二，俳句的成本约为十四行诗的十二分之一。

如果您自己检查这些数字，请不要依赖 Claude Code 自己的“total_cost_usd”。它使用 Anthropic 的内置价格表，当它无法识别 OpenRouter 型号名称时，它会进行猜测。在我们的运行中，它报告了花费约半美分的 Haiku 课程 0.16 至 0.31 美元，并且它夸大了 Opus 课程约 50%。您的[活动页面](https://openrouter.ai/activity)显示您实际支付的金额。对于 Claude Code 内的运行总计，您可以添加我们的[成本跟踪状态行](https://openrouter.ai/docs/cookbook/coding-agents/claude-code-integration#cost-tracking-statusline)，该状态行从 OpenRouter 读取每个会话的支出。

将您运行的训练次数乘以典型训练长度的中位数。以下是使用数据集中位数和每月 22 个工作日的三个示例：

|用途 |作品 5.5 |十四行诗 5.5 |
| ---| ---| ---|
|轻量级：每个工作日 5 次短期训练（2-9 回合）| 34 美元 | 17 美元 |

这些是估计值。您自己的会话的费用或多或少取决于您的代码库的大小以及 Claude Code 的读取量。

## 如何降低 Claude Code 的成本？

您可以控制驱动账单的两件事：每个会话运行的模型以及会话持续的时间。

### 将十四行诗设为默认

如果您使用 Opus 做所有事情，那么将默认值切换为 Sonnet 大约可以节省一半的费用。在我们的测试中，Sonnet 修复了相同的错误。保留 Opus 以供需要的会议使用。

### 将后台工作和子代理发送到 Haiku

Claude Code 对小型后台作业使用快速模型，它可以将部分任务交给子代理。 Haiku 5.5 通过了我们的错误修复测试，成本仅为 Sonnet 的一小部分，因此它非常适合两者。这些设置使 Sonnet 5.5 成为您的默认设置，并将后台作业和子代理路由到 Haiku 5.5：
```
export ANTHROPIC_BASE_URL="https://openrouter.ai/api"
export ANTHROPIC_AUTH_TOKEN="$OPENROUTER_API_KEY"
export ANTHROPIC_API_KEY=""
export ANTHROPIC_MODEL="anthropic/claude-sonnet-5.5"
export ANTHROPIC_DEFAULT_HAIKU_MODEL="anthropic/claude-haiku-5.5"
export CLAUDE_CODE_SUBAGENT_MODEL="anthropic/claude-haiku-5.5"
```
前三行将 Claude Code 连接到 OpenRouter；最后三个设定了模型。我们的[Claude Code集成指南](https://openrouter.ai/docs/cookbook/coding-agents/claude-code-integration)和[设置教程](https://openrouter.ai/blog/tutorials/claude-code-openrouter/)涵盖了其余的设置。

### 保持会话简短

10 到 49 回合的费用大约是 2 到 9 回合的费用的四到五倍。当您继续执行不相关的任务时，启动一个新的会话或运行“/compact”，而不是随身携带旧的上下文。

### 尝试使用更便宜的型号进行日常工作

通过 OpenRouter，Claude Code 可以调用其他实验室的模型，数据集显示人们正在这样做。 GLM-5.3 和 Kimi K3 会话在每个长度上的成本都低于 Opus 会话，我们的 [OpenRouter 上成本最低的 LLM 推理](https://openrouter.ai/blog/tutorials/how-to-get-the-lowest-cost-llm-inference-on-openrouter/) 指南介绍了如何找到更便宜的选项。要尝试一个，请将其传递给 Ori Harness：
```
ori claude --model z-ai/glm-5.3
```
不过，Claude Code 是为Anthropic模型构建的，因此在切换之前，请在您自己的任务中测试任何其他模型。 [Ori Eval](https://openrouter.ai/docs/guides/ori/eval) 会为您执行此操作：您的编码代理在您的项目中查找测试材料，运行您想要对其进行比较的模型，并推荐一个包含其背后的分数和成本的模型。

### 设置支出上限

您可以对 API 密钥设置信用限额，以便失控会话停止在您选择的数字处。在组织中，具有预算限制的 [guardrail](https://openrouter.ai/docs/guides/features/guardrails) 会限制每个成员或密钥每天、每周或每月的上限，并且 OpenRouter 也将其应用于使用 Ori Harness 启动的会话。在企业计划中，[工作空间预算](https://openrouter.ai/docs/guides/features/workspaces/workspace-budgets)限制[整个团队的支出](https://openrouter.ai/blog/insights/governing-team-ai-spend/)每天、每周、每月或一生。

## 常见问题

### Claude Code 每个代币的价格是多少？

Claude Code的成本与它所谓的每个代币收费的模型无关。 Claude Opus 5.5 每百万输入令牌的成本为 4 美元，每百万输出令牌的成本为 20 美元，写入提示缓存的每百万令牌的成本为 5 美元，从提示缓存中读取的每百万令牌的成本为 0.20 美元。Claude Sonnet 5.5 的价格是这些价格的一半。 Claude Haiku 5.5 的成本为每百万个输入令牌 0.10 美元，每百万个输出令牌 0.50 美元，缓存读取成本为每百万个 0.01 美元。大多数 Claude Code 会话的令牌都是缓存读取。

### Claude Code使用 Sonnet 还是 Opus 更便宜？

十四行诗更便宜。在我们的会话成本数据中，在每个会话长度上，Claude Sonnet 5.5 上的 Claude Code 会话成本约为 Claude Opus 5.5 上会话的一半。在我们自己的错误修复测试中，Sonnet 修复了与 Opus 相同的错误。

### 我可以将 Claude Code 与其他模型一起使用吗？

是的。当你将 Claude Code 指向 OpenRouter 时，它可以调用其他实验室的模型。我们的会话成本数据包括 GLM、Kimi、DeepSeek、Qwen 和 GPT 模型上的 Claude Code 会话。 Claude Code 是为Anthropic模型构建的，因此在切换到另一个模型之前，请在您自己的任务中测试另一个模型。

### 为什么我的第一个Claude Code请求如此昂贵？

第一个请求将 Claude Code 的系统提示符、工具定义和项目上下文写入提示符缓存。在我们在空文件夹中使用 Claude Opus 5.5 进行的测试中，大约有 17,000 个代币，成本约为 0.085 美元，而真正的项目会增加更多。后来的请求以低得多的价格从缓存中读取相同的上下文，在 Opus 5.5 上低了 25 倍。
