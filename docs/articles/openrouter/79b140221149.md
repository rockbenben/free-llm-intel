我们的每月 Product Spotlight 会精选过去一个月里最重要的几项发布。

## Partition Sorting：优先快的服务商

设置最低吞吐量或最高延迟阈值，OpenRouter 就会降低不达标服务商的优先级，且不会给你的请求增加延迟。跨 fallback 模型配合 `partition: "none"` 使用，可以找到仍满足你性能下限的最便宜方案。

[试用](https://openrouter.ai/docs/guides/routing/provider-selection#advanced-sorting-with-partition) | [公告](https://x.com/OpenRouterAI/status/2009323851864526856)

## Provider Explorer

在一处浏览 OpenRouter 上的所有服务商。DeepInfra 拥有的模型最多，而 OpenAI 拥有的专有模型最多。

[试用](https://openrouter.ai/providers) | [公告](https://x.com/OpenRouterAI/status/2008946242982907959)

## Bug 与反馈上报

现在可以从 Chatroom、你的 [Activity 页面](https://openrouter.ai/activity)或通过 API 对任意一次生成上报 bug 或反馈。我们会用它来帮助量化服务商的性能劣化，更多功能在路上。

[试用](https://openrouter.ai/docs/guides/overview/report-feedback) | [公告](https://x.com/OpenRouterAI/status/2008963322327216205)

## Auto Router 定制

Auto Router 现在支持 58 个模型（包括 Opus 4.5），兼容 tool calling，并可用通配符语法（如 `anthropic/*`）自定义允许的模型。不在被路由模型的市场价之上加价。包含按请求的 API 支持。

[试用](https://openrouter.ai/docs/guides/routing/routers/auto-router#configuring-allowed-models) | [公告](https://x.com/OpenRouterAI/status/2008219757905121495)

## SDK Skills Loader

通过 OpenRouter SDK 把封装好、可组合的 skills 加载进任意模型的上下文。Skills 会自动注入领域特定指令，内置幂等性保证同一个 skill 不会被加载两次。

[试用](https://openrouter.ai/docs/agent-sdk/call-model/examples/skills-loader) | [公告](https://x.com/OpenRouterAI/status/2009687407067836900)

## LLM Leaderboard 提速超 50%

LLM Leaderboard 现在快了 50% 以上——基于 intersection observer 的懒加载结合代码分割，把总阻塞时间砍半。

![Page Speed Capture](https://imagedelivery.net/Xq3eUzdKO2-MoBklzEEuMQ/809720ad-e042-49b4-1ab9-0b7ff6cf6800/public)

[公告](https://x.com/OpenRouterAI/status/2008578452753207437)

整个网关的 p99 延迟大幅改善。我们基准测试中最快的网关。
