新年快乐！为开启 2025，我们对 [Auto Router](https://openrouter.ai/openrouter/auto) 做了一次升级：

- 🧠 更多模型：现在会路由到 19 个不同的模型，以质量为导向进行优化。
- 🗨️ Chatroom UI：聊天室现在更清晰地展示实际使用了哪个模型，同样可通过 API 使用！
- Meta Model：我们正在测试由 Not Diamond 的 meta model 驱动的路由。

该 API 目前免费，未来可能会调整，并会提供更多可定制选项。

了解更多请见[这里](https://openrouter.ai/openrouter/auto)。
