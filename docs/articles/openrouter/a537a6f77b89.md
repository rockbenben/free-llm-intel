随着 AI 系统走向定制化，新的挑战浮现：如何高效创建贴合你所在领域的专用模型，同时保持对许可和数据使用约束的合规？

今天，我们介绍两块拼图，它们正好结合起来解决这个问题：

- [OpenRouter 上的可蒸馏模型（Distillable Models）](https://openrouter.ai/models?distillable=true)
- 基于 NVIDIA [NeMo Data Designer](https://github.com/NVIDIA-NeMo/DataDesigner) 构建的参考[合成数据工作流](https://github.com/NVIDIA/GenerativeAIExamples/blob/main/nemo/NeMo-Data-Designer/self-hosted-tutorials/community-contributions/qa-generation/product-question-answer-generator_OR_v3.ipynb)

## OpenRouter 上的可蒸馏模型

我们现在会显式标记 OpenRouter 上可用的 Distillable Models。这些模型的许可证允许生成合成训练数据。

许可元数据直接采集自模型实验室和服务商，开发者无需自己解读条款。

现在你可以：

- 在 Models 页面筛选[可蒸馏模型](https://openrouter.ai/models?distillable=true)
- 使用 [enforce_distillable_text](https://openrouter.ai/docs/guides/routing/provider-selection#distillable-text-enforcement) 请求参数在运行时强制合规。启用后，OpenRouter 保证所有输出都来自许可证允许将输出用于训练和蒸馏的模型。

## NVIDIA NeMo Data Designer

NVIDIA 最近发布了 NeMo Data Designer，一个[开源](https://github.com/NVIDIA-NeMo/DataDesigner)框架，用于以编程方式生成面向特定领域的大规模高质量数据集。它让你把数据生成器定义为代码，而不是一次性的 prompt 脚本。

它支持：

- 指令与任务导向数据集
- 问答对
- 结构化推理轨迹
- 多步 agentic 工作流
- 领域特定的 schema 与约束

## OpenRouter 与 NeMo Data Designer

把 OpenRouter 和 NeMo Data Designer 结合使用，团队可以在清晰、可执行的许可保证下生成大量合成数据，把大型推理模型蒸馏为更小的任务优化变体，并在不牺牲准确度的情况下大幅降低推理成本。这种方式支持完全建立在开放工具之上、可重复的、生产就绪的专用化工作流。

NVIDIA 还在 [Nemotron](https://openrouter.ai/nvidia) 系列下发布了几款基础模型，包括 [Nemotron 3 Nano](https://openrouter.ai/nvidia/nemotron-3-nano-30b-a3b:free)，非常适合生成合成数据。
