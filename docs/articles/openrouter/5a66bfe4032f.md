如果你把 [Cursor](https://cursor.com) 作为 AI 编码助手，现在可以把它连到 OpenRouter，访问诸如 Moonshot AI 的 Kimi K2 等模型——该模型已在平台上上线。

Kimi K2 拥有 **1 万亿参数**、**65.8% 的 SWE-Bench Verified 得分**，在代码生成和工具使用的开源榜单上领先。只需几个配置步骤，就能在 Cursor 中完整使用它。

## ⚙️ 如何在 Cursor 中使用 OpenRouter

- 打开 Cursor，进入：
 `Settings → Cursor Settings → Models`

![Preview 1](https://openrouter.ai/cdn-cgi/imagedelivery/Xq3eUzdKO2-MoBklzEEuMQ/677c220c-da7a-4b83-04f6-4f4ef9c4e000/public)

- 滚动到 **API Keys**，执行以下操作： 打开 **OpenAI API Key** 粘贴你的 **OpenRouter API key** 启用 **Override OpenAI Base URL** 设置为：`https://openrouter.ai/api/v1/cursor`
- 向上滚动到 **“Add or search model”**，输入： **moonshotai/kimi-k2** 添加并开启开关，即可使用。

![Preview 2](https://openrouter.ai/cdn-cgi/imagedelivery/Xq3eUzdKO2-MoBklzEEuMQ/b1de0e29-a755-47dd-d52a-f5667c931900/public)

- 现在进入 Cursor 的聊天面板，在模型下拉菜单中选择 **Kimi K2**。

![Preview 4](https://openrouter.ai/cdn-cgi/imagedelivery/Xq3eUzdKO2-MoBklzEEuMQ/e524a81c-3345-4ff7-a0b1-e221d0a24200/public)

> ⚠️ 提醒：Cursor 可能会警告该模型的 agentic 支持有限。这个可以放心忽略——Kimi K2 在助手式工作流中完全够用。

## 🔗 开始使用

- 注册并在 [OpenRouter](https://openrouter.ai) 获取你的 API key
- 浏览可用模型：[openrouter.ai/models](https://openrouter.ai/models)
- 加入我们的开发者社区：[openrouter.ai/discord](https://openrouter.ai/discord)
