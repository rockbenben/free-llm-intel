# Claude 能生成图片吗？可以，用连接器就行

OpenRouter ·2026/11/23

![Claude 能生成图片吗？可以，用连接器就行](https://openrouter.ai/blog/images/can-claude-generate-images.png)![Claude 能生成图片吗？可以，用连接器就行](https://openrouter.ai/blog/images/can-claude-generate-images-dark.png)

Claude 自身无法生成图片，因为它没有图像模型。借助连接器，它可以调用图像模型，并把成品图片交给你。

你给出一句简短请求，Claude 会写出详细提示词，并在产生任何费用前展示给你看。图片返回后，Claude 能查看结果，并核对是否符合你的要求。本文以 OpenRouter MCP server 作为连接器，截至 2026 年 11 月 19 日，它可访问来自不同实验室的 74 个图像模型。

如果你只想看设置步骤，请跳到[如何在 Claude 中用连接器生成图片](https://openrouter.ai/blog/tutorials/can-claude-generate-images/#how-to-make-images-in-claude-with-a-connector)。

## Tl;dr

- Claude 没有自己的图像模型。连接器让它调用一个模型并返回真实图片。
- 在 Claude 应用或 Claude Code 中添加 `https://mcp.openrouter.ai/mcp` 作为连接器。你的电脑上无需安装任何东西。
- 在请求中指定你要的模型，或先让 Claude 为你的任务比较模型，后者不收费。
- 我们 2026 年 11 月 19 日的测试图片每张成本在 $0.035 到 $0.10 之间，每张在收费前都会由你批准。
- 图片要么出现在聊天中，要么以链接形式提供，链接有效期为 24 小时。

## Claude 能生成图片吗？

Claude 无法自行生成照片或插画。Anthropic 2026 年 3 月 16 日的[帮助中心文章](https://support.claude.com/en/articles/9002504-can-claude-produce-images)称“Claude 不会像图像生成工具那样生成照片或插画”，并指出它用 HTML 和 SVG 构建图表。其[视觉文档](https://platform.claude.com/docs/en/build-with-claude/vision)补充道：“Claude 仅是图像理解模型。它可以解读和分析图像，但不能生成、产出、编辑、操作或创建图像。”

连接器是 Claude 对添加到应用中的 MCP server 的叫法。[OpenRouter MCP server](https://openrouter.ai/docs/guides/overview/mcp-server) 就是其中一个连接器，它可访问 [OpenRouter 图像目录](https://openrouter.ai/models?output_modalities=image)中的每一个模型。

## Claude 用图像模型做什么？

图像模型负责绘制，Claude 负责绘制之外的工作。仅有一个图像工具时，周边工作才是难点：你自己写详细提示词，图片到达后你还要对照请求检查，并把文件搬到该去的地方。

在 Claude 中，一句简短请求就够了，因为详细提示词由 Claude 来写。指定你要的模型，例如：“你能生成一张图片吗？一只红狐在雪夜的街灯下读平装书，柔和的水彩风格。使用 Seedream 5.5。”在我们的运行中，Claude 把这句话扩展成了更长的提示词。Claude 在每张图片前请求批准，批准界面会显示它写好的模型和提示词，让你在产生任何费用前阅读。

![Claude Desktop 的批准卡片，写着“Claude 想要使用 Generate an image from OpenRouter”，显示模型、提示词以及 Deny、Allow for this task 和 Allow once 按钮。](https://openrouter.ai/blog/images/can-claude-generate-images-approval.jpg)

Claude 也能查看结果。在我们的 Claude 应用运行中，图片返回后，Claude 已经看到了图片并对其进行了描述。

![Claude Desktop 显示一张生成的水彩画：雪中街灯下阅读的红狐，在应用内以完整尺寸打开。](https://openrouter.ai/blog/images/can-claude-generate-images-claude-app.jpg)

在我们的 Claude Code 运行中，Claude 打开了保存的文件，并报告说书是绿色精装，而我们要求的是平装。发生这种情况时，无需你亲自对照请求检查图片，不一致就会被发现。当你要求修改时，Claude 可以把第一张图作为参考传回模型，在我们的运行中，场景的其余部分保持不变。详见[Claude 能编辑它生成的图片吗？](https://openrouter.ai/blog/tutorials/can-claude-generate-images/#can-claude-edit-an-image-it-generated)。

## 如何在 Claude 中用连接器生成图片

将 OpenRouter MCP server 添加为自定义连接器。它是远程服务器，因此你的电脑上无需安装任何东西。你需要一个带有额度的 OpenRouter 账户。

在 Claude 应用中：

- 打开 Settings > Connectors，添加自定义连接器。
- 将其命名为 `OpenRouter MCP`，并将远程 MCP server URL 设置为 `https://mcp.openrouter.ai/mcp`。OAuth 字段留空。
- 添加连接器，然后连接它。浏览器中会打开 OpenRouter 的同意页面。
- 批准此连接专用的密钥。它在 7 天内过期，你可以随时断开连接。

有些组织不允许自定义连接器，因此工作账户上可能没有此选项。

在 Claude Code 中，运行：

```
claude mcp add --transport http openrouter https://mcp.openrouter.ai/mcp
claude mcp login openrouter
```

[OpenRouter MCP server 指南](https://openrouter.ai/docs/guides/overview/mcp-server)中有每个客户端的逐点击步骤。

## Claude 应该使用哪个图像模型？

指定你要的模型，因为没有单一模型适合所有任务。我们将相同的狐狸提示词发给四个模型，采用 1:1 宽高比和默认分辨率，以比较外观和价格。

![相同的狐狸提示词在四个图像模型上的效果，呈 2×2 网格：GPT Image 2.6 Flare、Seedream 5.5、MAI-Image-2.7 和 Nano Banana 2.1。](https://openrouter.ai/blog/images/can-claude-generate-images-four-models.jpg)

每一行是一次单独测量，按 2026 年 11 月 19 日的计费。每个模型页面有其当前价格。

| 模型 | Slug | 时间 | 每张成本 | 尺寸 |
| --- | --- | --- | --- | --- |
| [GPT Image 2.6 Flare](https://openrouter.ai/openai/gpt-image-2.6-flare) | `openai/gpt-image-2.6-flare` | 26.4 s | $0.094 | 1024×1024 |
| [Seedream 5.5](https://openrouter.ai/bytedance-seed/seedream-5-5) | `bytedance-seed/seedream-5-5` | 20.9 s | $0.035 | 2048×2048 |
| [MAI-Image-2.7](https://openrouter.ai/microsoft/mai-image-2.7) | `microsoft/mai-image-2.7` | 34.0 s | $0.035 | 1024×1024 |
| [Nano Banana 2.1](https://openrouter.ai/google/gemini-nano-banana-2.1) | `google/gemini-nano-banana-2.1` | 13.2 s | $0.040 | 1024×1024 |

最贵的图片成本超过最便宜的两倍（$0.094 对 $0.035），而 Seedream 5.5 并列最低价，返回的图片却最大。四个模型中有三个添加了我们未要求的文字，比如书名或悬挂招牌，因此请在请求中加入“无文字”。如需更广泛的比较，请阅读[图像生成模型比较](https://openrouter.ai/blog/insights/image-generation-models-compared/)。

你可以让 Claude 在花费任何费用前为你的任务比较模型，因为查询模型不收费。当我们询问纯白背景的产品照片该用哪个模型时，Claude 从五个选项中推荐了 Nano Banana 2.1，为每个选项给出了理由和注意事项，并说明候选名单来自目录数据而非测试图片。它提出在我们同意后对前三名进行付费测试。

如果你不指定模型，Claude 会自行选择。在我们的 Claude Code 运行中，它选择了 [FLUX 3 Image](https://openrouter.ai/black-forest-labs/flux-3-image)，而在一次 Claude 应用运行中，它选择了一个较旧的模型。

## 费用是多少？

每张图片的成本就是生成它的模型的价格，在 2026 年 11 月 19 日的运行中为 $0.035 到 $0.10。Claude 自身的使用量单独计算。

宽高比和分辨率会改变价格。GPT Image 2.6 Flare 在 16:9 下成本为 $0.058，而 1:1 下为 $0.094；FLUX 3 Image 在 16:9 和 2K 分辨率（2736×1536）下成本为 $0.10。

连接器的密钥初始设有 $10 的支出上限，你可以在同意页面编辑。在我们的运行中，Claude 还在回复中重复了每张图片的成本。

## 为什么图片有时以链接形式返回？

`generate-image` 工具在可以签发链接时返回链接，否则返回图片本身。链接可在任何浏览器中打开，无需登录，有效期为 24 小时。

在 Claude 应用中，图片显示在聊天中，Claude 也能看到它。链接会在你的浏览器中打开，在我们的运行中，Claude 没有看到那张图片，也无法在聊天中展示它。在 Claude Code 中，链接是更简单的情况，因为图片会直接下载到你的项目中。直接返回的图片会留在 Claude Code 自己的文件夹中，直到你批准复制它。

你得到哪一种在请求之间会变化，即使对同一个模型也是如此。在 2026 年 11 月 19 日我们的小规模运行中，Seedream 5.5 在 4 次中 4 次返回图片本身，GPT Image 2.6 Flare 在 4 次中 3 次返回链接，FLUX 3 Image 在 2 次中 2 次返回链接，Nano Banana 2.1 各返回一次。如果你想要图片出现在 Claude 应用内，Seedream 5.5 对我们每次都做到了。如果你得到的是链接，打开它即可。

## Claude Code 能生成图片吗？

可以。Claude Code 用同一个连接器生成图片，并直接放入你的项目。说明文件保存到哪里以及哪个页面使用它，例如：“这个落地页需要一张主视觉插图。使用 OpenRouter 生成一张：一只红狐在雪夜的街灯下读平装书，柔和的水彩风格。保存到 assets/hero.png 并添加到 index.html。”

在我们的运行中，Claude Code 将 FLUX 3 Image 生成的 2736×1536 插图保存到该路径，并添加到了页面。完整配方请参阅 cookbook [从 Claude Code 生成和编辑图片](https://openrouter.ai/docs/cookbook/coding-agents/generate-images-in-claude-code)。

## Claude 能编辑它生成的图片吗？

可以，前提是第一张结果以链接形式返回，且模型接受图像输入。Claude 将该链接作为参考传回模型，并附上你要求的修改。

在我们的 Claude Code 会话中，我们要求给狐狸加上红围巾，并让平装书有纯红色封面，保存覆盖同一文件。Claude 将第一张图传回 FLUX 3 Image，两项修改都出现了，而场景的其余部分保持不变。

![两版水彩狐狸插图并排：第一次请求，以及后续请求添加红围巾和红书后的同一场景。](https://openrouter.ai/blog/images/can-claude-generate-images-claude-code-edit.jpg)

没有链接，Claude 就无法复用该图片。在 Claude 应用中，当结果以图片本身形式返回后，要求加红围巾会根据描述生成一张新图片。场景变了，Claude 也说明了这一点。

## 常见问题

### Claude 能创建真实图片吗？

不能自行创建。没有连接器时，Claude 用 HTML 和 SVG 构建图表。借助 OpenRouter MCP server 这样的连接器，它调用图像模型并返回真实图片。

### 为什么 Claude 不能生成图片？

Claude 没有图像生成模型。Anthropic 的文档将其描述为“仅是图像理解模型”，因此它可以读取你给它的图片，而绘制图片需要单独的图像模型，这由连接器提供。

### Claude 生成图片的方式和图像生成器一样吗？

不一样。图像模型负责绘制，Claude 根据你的请求写提示词，并能检查结果。

### Claude 能生成视频吗？

本文未测试视频。OpenRouter MCP 连接器还有 `generate-video`、`generate-speech` 和 `transcribe-audio` 工具，它们随相同的设置一起提供。
