# Claude 能生成图像吗？可以，借助连接器

![Claude 能生成图像吗？可以，借助 connector](https://openrouter.ai/blog/images/can-claude-generate-images.png)![Claude 能生成图像吗？可以，借助 connector](https://openrouter.ai/blog/images/can-claude-generate-images-dark.png)

Claude 本身无法生成图像，因为它没有图像模型。借助 connector，它可以调用一个图像模型，把画好的图交到你手上。

你给出一句简短的请求，Claude 写出详细的 prompt，并在任何计费发生之前拿给你看。图片返回后，Claude 可以查看结果，并对照你的要求做检查。本文把 OpenRouter MCP server 用作 connector，截至 2026 年 11 月 19 日，它可触达来自不同实验室的 74 个图像模型。

如果你只想要配置步骤，可以跳到[如何借助 connector 在 Claude 中生成图像](https://openrouter.ai/blog/tutorials/can-claude-generate-images/#how-to-make-images-in-claude-with-a-connector)。

## 太长不看（Tl;dr）

- Claude 没有自己的图像模型。connector 让它能调用一个模型，并返回一张真实的图片。
- 在 Claude app 或 Claude Code 中把 `https://mcp.openrouter.ai/mcp` 添加为 connector。你的电脑上不会安装任何东西。
- 在请求里指明你要的模型，或者先让 Claude 为你的任务比较各模型——这一步不计费。
- 2026 年 11 月 19 日，我们测试的图片每张花费在 $0.035 到 $0.10 之间，而且每一张都在你批准之后才被收费。
- 图片会出现在对话里，或以免登录、24 小时内有效的链接形式送达。

## Claude 能生成图像吗？

Claude 本身无法生成照片或插图。Anthropic 于 2026 年 3 月 16 日发布的[帮助中心文章](https://support.claude.com/en/articles/9002504-can-claude-produce-images)称，“Claude 不像图像生成工具那样生成照片或插图”，并指出它会用 HTML 和 SVG 构建示意图与图表。其[视觉文档](https://platform.claude.com/docs/en/build-with-claude/vision)补充说：“Claude 只是一个图像理解模型。它可以解读和分析图像，但不能生成、产出、编辑、操纵或创造图像。”

connector 是 Claude 对“添加到应用中的 MCP 服务器”的叫法。[OpenRouter MCP server](https://openrouter.ai/docs/guides/overview/mcp-server) 就是其中一个 connector，它可触达 [OpenRouter 图像模型目录](https://openrouter.ai/models?output_modalities=image) 中的每一个模型。

## Claude 用图像模型做什么？

图像模型负责画，Claude 负责画之外的工作。只用一个图像工具时，这些周边工作恰恰是难的部分：你得自己写详细的 prompt，图片到了之后还得对照请求检查一遍，再把文件搬到它该去的地方。

在 Claude 里，一句简短的请求就够了，因为详细的 prompt 由 Claude 来写。指明你要用的模型，例如：“你能生成一张图吗？雪夜里，一只红狐在路灯下读一本平装书，柔和的水彩风格。用 Seedream 5.5。”在我们的运行中，Claude 把这一行扩写成了更长的 prompt。每张图之前 Claude 都会请求批准，而那张批准卡片会显示模型和它写好的 prompt，因此你可以在任何计费发生之前先读一遍。

![Claude Desktop 的批准卡片，标题为 “Claude wants to use Generate an image from OpenRouter”，显示模型、prompt，以及 Deny、Allow for this task 和 Allow once 三个按钮。](https://openrouter.ai/blog/images/can-claude-generate-images-approval.jpg)

Claude 还能查看结果。在我们的 Claude app 运行中，图片返回之后，Claude 看过这张图并把它描述了出来。

![Claude Desktop 中展示的一张生成好的水彩图：雪地里，一只红狐在路灯下读书，图片在应用内以全尺寸打开。](https://openrouter.ai/blog/images/can-claude-generate-images-claude-app.jpg)

在我们的 Claude Code 运行中，Claude 打开了保存好的文件，并报告说我们要的是平装书，而图上是一本绿色精装书。碰上这种情况，不用你自己拿图和请求逐项比对，不匹配就会被抓出来。当你要求做改动时，Claude 可以把第一张图作为参考传回给模型；在我们的运行中，场景的其余部分保持不变。详情见[Claude 能编辑它生成的图像吗？](https://openrouter.ai/blog/tutorials/can-claude-generate-images/#can-claude-edit-an-image-it-generated)。

## 如何借助 connector 在 Claude 中生成图像

把 OpenRouter MCP server 添加为自定义 connector。它是远程服务器，因此你的电脑上不会安装任何东西。你需要一个带有余额的 OpenRouter 账户。

在 Claude app 中：

- 打开 Settings > Connectors，添加一个自定义 connector。
- 把它命名为 `OpenRouter MCP`，并把远程 MCP 服务器的 URL 设为 `https://mcp.openrouter.ai/mcp`。OAuth 字段留空。
- 添加这个 connector，然后连接它。浏览器中会打开 OpenRouter 的授权同意页。
- 批准专用于这条连接的 key。它在 7 天内过期，你随时可以断开连接。

有些组织不允许使用自定义 connector，所以在工作账户上这个选项可能不存在。

在 Claude Code 中运行：

```
claude mcp add --transport http openrouter https://mcp.openrouter.ai/mcp
claude mcp login openrouter
```

[OpenRouter MCP server 指南](https://openrouter.ai/docs/guides/overview/mcp-server)给出了每个客户端逐步点击的操作步骤。

## Claude 该用哪个图像模型？

指明你要的模型，因为没有哪个模型适合所有任务。我们把同一个狐狸 prompt 发给了四个模型，采用 1:1 宽高比和默认分辨率，以比较观感与价格。

![同一个狐狸 prompt 在四个图像模型上的效果，呈两行两列的网格：GPT Image 2.6 Flare、Seedream 5.5、MAI-Image-2.7 和 Nano Banana 2.1。](https://openrouter.ai/blog/images/can-claude-generate-images-four-models.jpg)

每一行是一次单独的测量，按 2026 年 11 月 19 日的计费口径。每个模型的页面上都有它的当前价格。

| 模型 | Slug | 耗时 | 每张图成本 | 尺寸 |
| --- | --- | --- | --- | --- |
| [GPT Image 2.6 Flare](https://openrouter.ai/openai/gpt-image-2.6-flare) | `openai/gpt-image-2.6-flare` | 26.4 s | $0.094 | 1024×1024 |
| [Seedream 5.5](https://openrouter.ai/bytedance-seed/seedream-5-5) | `bytedance-seed/seedream-5-5` | 20.9 s | $0.035 | 2048×2048 |
| [MAI-Image-2.7](https://openrouter.ai/microsoft/mai-image-2.7) | `microsoft/mai-image-2.7` | 34.0 s | $0.035 | 1024×1024 |
| [Nano Banana 2.1](https://openrouter.ai/google/gemini-nano-banana-2.1) | `google/gemini-nano-banana-2.1` | 13.2 s | $0.040 | 1024×1024 |

最贵的一张图比最便宜的贵了一倍多（$0.094 对 $0.035），而 Seedream 5.5 在并列最低价的同时给出了最大的图。四个模型里有三个加上了我们没要求的文字，比如书名或悬挂的招牌，所以在请求里加上 “no text”。想看更全面的比较，请读[图像生成模型对比](https://openrouter.ai/blog/insights/image-generation-models-compared/)。

你可以先让 Claude 为你的任务比较各模型，再花任何钱，因为查询模型不计费。当我们问纯白背景的产品图该用哪个模型时，Claude 从五个选项里推荐了 Nano Banana 2.1，为每个选项都给出理由和一条注意事项，并说明这份候选清单来自目录数据，而非测试图片。它提出，在我们同意之后可以对前三名跑付费测试。

如果你不指明模型，Claude 会自己选一个。在我们的 Claude Code 运行中，它选了 [FLUX 3 Image](https://openrouter.ai/black-forest-labs/flux-3-image)；有一次 Claude app 运行中，它选了一个更旧的模型。

## 费用是多少？

每张图的花费就是生成它的那个模型的价格，在我们 2026 年 11 月 19 日的运行中是 $0.035 到 $0.10。Claude 自身的用量另计。

宽高比和分辨率会改变价格。GPT Image 2.6 Flare 在 16:9 下花费 $0.058，在 1:1 下为 $0.094；FLUX 3 Image 在 16:9、2K 分辨率（2736×1536）下花费 $0.10。

connector 的 key 初始带有 $10 的消费上限，你可以在授权同意页上修改它。在我们的运行中，Claude 还会在回复里复述每张图的成本。

## 为什么图片有时以链接形式返回？

`generate-image` 工具在能签发链接时返回链接，否则返回图片本身。链接可以在任意浏览器中打开，无需登录，24 小时内有效。

在 Claude app 中，图片会显示在对话里，Claude 也能看到它。链接则会在你的浏览器中打开；在我们的运行中，Claude 并没有看到那张图，也无法在对话里显示它。在 Claude Code 中，链接反而是更省事的情况，因为图片会直接下载到你的项目里。直接返回的图片则留在 Claude Code 自己的文件夹中，直到你批准复制它。

即使是同一个模型，返回哪种形式也会随请求而变化。在我们 2026 年 11 月 19 日的那一小批运行中，Seedream 5.5 四次全部返回图片本身，GPT Image 2.6 Flare 四次里有三次返回链接，FLUX 3 Image 两次全部返回链接，Nano Banana 2.1 则各返回一次。如果你希望图片就在 Claude app 里，Seedream 5.5 对我们每次都做到了。如果你拿到的是链接，打开它。

## Claude Code 能生成图像吗？

可以。Claude Code 用同一个 connector 生成图像，并把它们直接放进你的项目。说清文件存到哪里、哪个页面会用到它，例如：“这个落地页需要一张 hero 插图。用 OpenRouter 生成一张：雪夜里，一只红狐在路灯下读一本平装书，柔和的水彩风格。保存到 assets/hero.png，并加进 index.html。”

在我们的运行中，Claude Code 把 FLUX 3 Image 生成的一张 2736×1536 插图保存到了那个路径，并把它加进了页面。完整做法见 cookbook [从 Claude Code 生成和编辑图像](https://openrouter.ai/docs/cookbook/coding-agents/generate-images-in-claude-code)。

## Claude 能编辑它生成的图像吗？

能，前提是第一次结果以链接形式返回，且该模型接受图像输入。Claude 会把那个链接连同你要求的改动一起作为参考传回给模型。

在我们的 Claude Code 会话中，我们要求给狐狸加一条红围巾，并把平装书换成素红封面，覆盖保存到同一个文件。Claude 把第一张图传回给 FLUX 3 Image，两处改动都出现了，而场景的其余部分保持不变。

![两版水彩狐狸插图并排对比：第一版是原始请求，第二版是追加请求加上红围巾与红书之后的同一场景。](https://openrouter.ai/blog/images/can-claude-generate-images-claude-code-edit.jpg)

没有链接时，Claude 无法复用那张图。在 Claude app 中，如果返回的是图片本身，之后要求一条红围巾，得到的会是一张按描述重新生成的新图。场景变了，Claude 也说明了这一点。

## 常见问题

### Claude 能创建真实的图像吗？

单靠自己不行。没有 connector 时，Claude 用 HTML 和 SVG 构建示意图与图表。有了 OpenRouter MCP server 这类 connector，它会调用图像模型，返回一张真实的图片。

### 为什么 Claude 不能生成图像？

Claude 没有图像生成模型。Anthropic 的文档把它描述为“只是一个图像理解模型”，因此它能读懂你给它的图片；而要画出一张图，需要另一个图像模型，由 connector 提供。

### Claude 生成图像的方式和图像生成器一样吗？

不一样。图像模型负责画，Claude 根据你的请求写出 prompt，并能检查结果。

### Claude 能生成视频吗？

本文没有测试视频。OpenRouter MCP connector 还有 `generate-video`、`generate-speech` 和 `transcribe-audio` 工具，配置方式相同。
