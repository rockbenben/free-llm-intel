# 什么是 Qwen 3.8

OpenRouter ·9/28/2026

Qwen 3.8 是 Alibaba（阿里巴巴）2026 年 8 月发布的一代模型。四个模型共用这个名字，而它们在选型的关口上彼此不同。你可以在 Hugging Face 上以 Apache 2.0 下载 [Qwen3.8 27B](https://huggingface.co/Qwen/Qwen3.8-27B)，以 Qwen3.8-Max License 下载 [Qwen3.8 2.4T A95B](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B)。Qwen3.8 Flash 没有自己的仓库，但它所基于的 [Qwen3.8-Flash-Next](https://huggingface.co/Qwen/Qwen3.8-Flash-Next) 可以按 Qwen Community License 1.0 下载。Qwen3.8 Max 没有公开权重。

Alibaba [宣布 Qwen3.8-Max](https://qwen.ai/blog?id=qwen3.8) 为这一代中的托管模型。[QwenLM/Qwen3.8 发布记录](https://github.com/QwenLM/Qwen3.8)记载 Qwen3.8-2.4T-A95B 权重于 2026 年 8 月 12 日上线 Hugging Face，27B 权重于 8 月 14 日上线。2.4T 的[模型卡](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B)称这是 Qwen-Max 级模型的首次开放发布。

能下载的模型和能调用的模型不是同一个。Alibaba 的模型卡把 Qwen3.8-Max 描述为 Qwen3.8-2.4T-A95B 的托管版本，外加一些特性：视觉输入、非思考模式、默认 1,000,000 token 上下文和内置工具。Flash 也是这层关系：Alibaba 把 Qwen3.8-Flash 描述为 Qwen3.8-Flash-Next 的托管版本，默认 1,000,000 token 上下文、带内置工具。

四个模型我们都在路由。本文讲清楚每个模型是什么、哪些能下载、许可证有什么要求、跑起来各要多少钱。

## Qwen 3.8 的四个模型

价格单位为美元/百万 token，先提示词后补全，取自我们 2026 年 9 月 11 日的模型目录。27B 的价格是个区间，因为有 14 家提供商按不同费率服务它。2.4T 的七家提供商里六家收 $2 / $6，Venice 收 $2.50 / $7.50。

| 模型 | 权重 | 许可证 | 输入 | 上下文，原生 / 最大托管 | 价格 |
| --- | --- | --- | --- | --- | --- |
| [qwen/qwen3.8-max-0902](https://openrouter.ai/qwen/qwen3.8-max-0902) | 仅 API | 专有 | 文本、图像、视频 | 未公布 / 1,000,000 | $2 / $6 |
| [qwen/qwen3.8-2.4t-a95b](https://openrouter.ai/qwen/qwen3.8-2.4t-a95b) | [Hugging Face](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B) | Qwen3.8-Max License | 文本 | 262,144 / 1,048,576 | $2 / $6 |
| [qwen/qwen3.8-27b](https://openrouter.ai/qwen/qwen3.8-27b) | [Hugging Face](https://huggingface.co/Qwen/Qwen3.8-27B) | Apache 2.0 | 文本、图像、视频 | 262,144 / 1,000,000 | $0.15 到 $0.45 / $2.00 到 $3.20 |
| [qwen/qwen3.8-flash](https://openrouter.ai/qwen/qwen3.8-flash) | [Hugging Face](https://huggingface.co/Qwen/Qwen3.8-Flash-Next)，以 Qwen3.8-Flash-Next 之名 | Qwen Community License 1.0（针对 Qwen3.8-Flash-Next） | 文本、图像、视频 | Qwen3.8-Flash-Next 为 262,144 / 1,000,000 | $0.15 / $0.47 |

模型 ID `qwen/qwen3.8-max` 是一个别名，当前解析到 `qwen/qwen3.8-max-0902`，即 2026 年 9 月 2 日的快照。如果你想在 Alibaba 发布新快照之后仍锁定同一个快照，请使用带日期的 ID。

上下文列写了两个数字，因为它们衡量的东西不同。第一个是模型训练时使用的窗口长度——Alibaba 为开放权重模型公布这个数字，但没有为 Max 公布。第二个是我们目录里任何提供商提供的最大窗口，它更大是因为窗口可以被扩展到训练长度以上。[Qwen3.8-27B 模型卡](https://huggingface.co/Qwen/Qwen3.8-27B)描述用 YaRN（一种 RoPE 缩放技术）把 27B 扩展到 1,000,000 token，并提示静态 YaRN 可能降低短输入的表現。提供商是否扩展窗口、怎么扩展，是提供商自己的决定，所以你拿到的上限取决于我们把你的请求路由到哪里。

如果你用[提示词缓存](https://openrouter.ai/docs/guides/best-practices/prompt-caching)，缓存费率因模型和提供商而异。Max 读缓存 $0.25/百万 token，写缓存 $2.50。Flash 读 $0.016，在 Alibaba 上写 $0.20。2.4T 在多数提供商读价 $0.25，只有 Alibaba 列了写价 $2.50。27B 的读缓存价在提供缓存的提供商之间从 $0.032 到 $0.18 不等，只有 Alibaba 列了写价 $0.53。

## Qwen 3.8 是开源的吗？

部分是，答案取决于你指哪个模型。

**Max 下载不了。** 它没有 Hugging Face 仓库。Max 跑在 Alibaba 的服务器上，只能通过 API 访问。

**2.4T 可以下载，但它的许可证在规模上附加了条件。** [Qwen/Qwen3.8-2.4T-A95B](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B) 是指令微调模型，总参数 2.4 万亿、每 token 激活 950 亿。它不使用 Apache 2.0，Qwen 为它专门写了 [Qwen3.8-Max License](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B/blob/main/LICENSE)。Hugging Face 的元数据把许可证记为 `other`，名称 `qwen3.8-max`。

许可证授予使用、复制、修改、分发、再许可、出售、部署、托管、微调和创作衍生作品的权利，但附带两个条件。

- 署名。如果基于该模型构建的商业产品或服务月活跃用户超过 100,000,000，或月收入超过 2,000 万美元，必须在其用户界面中显著展示模型名称。
- 大型"模型即服务"业务需单独授权。如果你或你的关联公司运营 Model as a Service（模型即服务）或 AI Work Assistant（AI 工作助手）业务，且任意连续十二个月总收入超过 5,000 万美元，商业使用前需要从 Qwen 获得单独许可。不向第三方开放模型、其输出或其能力的内部使用不受此条约束。

许可证把 Model as a Service 定义为：以让第三方能控制输入、参数或训练数据的方式向其提供模型推理或微调。它不包括把请求转发给他人托管的模型的情形。AI Work Assistant 定义为以 AI 辅助编码或办公生产力为主要用途的独立产品。

**27B 可以按 Apache 2.0 下载。** [Qwen/Qwen3.8-27B](https://huggingface.co/Qwen/Qwen3.8-27B) 的 Hugging Face 元数据记录为 `apache-2.0`。Apache 2.0 在开源促进会（OSI）的批准列表上，不带任何收入或用户数条件。

**Flash 有开放权重，但名字不同、又是第三种许可证。** 没有 Qwen3.8 Flash 的仓库。有 [Qwen3.8-Flash-Next](https://huggingface.co/Qwen/Qwen3.8-Flash-Next) 的仓库，Alibaba 称它是未来支撑 Qwen4 的架构的实验性预览。它的[许可证](https://huggingface.co/Qwen/Qwen3.8-Flash-Next/blob/main/LICENSE)是 Qwen Community License 1.0：署名条件与 Qwen3.8-Max License 相同，并且要求任何 Model as a Service 或 AI Work Assistant 业务在商用前取得 Qwen 的单独许可——没有收入门槛。

所以三个开放权重模型里，有两个的许可证是 Qwen 自己写的、未经 OSI 批准。开放权重意味着你可以下载并检查检查点，不代表许可证是开源的。

### Qwen 3 是更早的一代

Qwen 3 不是 Qwen 3.8 的前一版。Qwen 3 发布于 2025 年 4 月，[Qwen 3.5、Qwen 3.6 和 Qwen 3.7](https://openrouter.ai/qwen) 发布在两者之间。Qwen 3.8 紧跟在 Qwen 3.7 之后。适用于某个 Qwen 3 模型的许可条款，说明不了本文这四个模型的任何事情。

## 你能在本地跑 Qwen 3.8 吗？

27B 可以在你自己的硬件上跑；2.4T 需要多卡基础设施。

![按"权重能否下载"与"输入模态"划分 Qwen 3.8 模型的四象限图。Qwen3.8 2.4T A95B 可下载、仅文本。Qwen3.8 27B 和 Qwen3.8-Flash-Next 可下载、接受文本图像视频。Qwen3.8 Max 和 Qwen3.8 Flash 仅 API、接受文本图像视频。](https://openrouter.ai/blog/images/qwen-3-8-downloadable-vs-modality.png)

*图 1. 可下载权重 vs 输入模态。2.4T 是这个家族里唯一只读文本的模型。没有任何一个 Qwen 3.8 模型是"仅 API 且仅文本"的。*

2.4T 是混合专家模型。任何一个 token 只激活 950 亿参数，但 2.4 万亿参数必须全部载入——因为模型为每个 token 选一组不同的专家。你的硬件要装下的数字是 2.4 万亿。[QwenLM/Qwen3.8 仓库](https://github.com/QwenLM/Qwen3.8)的 README 只给了 27B 的服务命令。

27B 是 270 亿参数的稠密模型。bf16 下每参数两字节，权重约占 54 GB，fp8 大约减半。Alibaba 的服务示例用 SGLang、vLLM 或 TokenSpeed 在四张 GPU 上跑满 262,144 token 原生窗口。

```
vllm serve Qwen/Qwen3.8-27B --port 8000 --tensor-parallel-size 4 --max-model-len 262144 --reasoning-parser qwen3 --enable-auto-tool-choice --tool-call-parser qwen3_coder
```

以 1,000,000 token 服务需要模型卡里描述的 YaRN 覆盖参数；模型卡建议只在确实需要更长上下文时才改动 RoPE 参数。

**大模型的开放权重只读文本。** 托管的 Max 接受图像和视频，开放权重的 27B 也接受；开放权重的 2.4T 不接受。2026 年 9 月 11 日我们向 `qwen/qwen3.8-2.4t-a95b` 发送图片时，请求以 HTTP 404 失败，报错 `No endpoints found that support image input`。同样的请求发给 `qwen/qwen3.8-27b` 和 `qwen/qwen3.8-flash` 都成功了。

在文本上，开放权重的得分和 Max 很接近。

| 模型 | 智能指数 | 编码指数 | Agent 指数 |
| --- | --- | --- | --- |
| Qwen3.8 Max (0902) | 40.3 | 71.8 | 49.6 |
| Qwen3.8 2.4T A95B | 40.0 | 71.9 | 50.4 |
| Qwen3.8 27B (xhigh) | 33.9 | 68.1 | 46.5 |

这些分数来自独立基准测试机构 [Artificial Analysis](https://artificialanalysis.ai)，我们发布在每个模型页面上，2026 年 9 月 11 日取数。Artificial Analysis 测的是每个模型带日期的快照，所以 Max 一行是 2026 年 9 月 2 日快照，27B 一行是在 `xhigh` 推理强度下测的。如果 Artificial Analysis 重测某模型，或你用不同的推理设置运行模型，分数会移动。

2.4T 在智能指数上落后 Max 0.3 分，编码指数领先 0.1 分，Agent 指数领先 0.8 分。27B 分别落后 Max 6.4、3.7 和 3.1 分。

如果你想拿 Max 级的权重自托管一个要读截图的工作负载，能读图的模型是 27B。

## 怎么选模型

用这些事实缩小选择。

- 需要图像或视频输入、又想持有权重：27B 是我们目录里唯一接受这两者的 Qwen 3.8 开放权重模型，而且是 Apache 2.0。
- 需要图像或视频输入、又想拿家族里最高的 Artificial Analysis 分数：Max 在智能指数上最高。
- 要最低的每 token 价格：Flash 提示词 $0.15/百万、补全 $0.47/百万，且接受图像和视频。但 Qwen3.8 Flash 本身不能下载，只能下载 Qwen3.8-Flash-Next。
- 做文本工作、又想持有权重：2.4T 就是 Max 的开放权重变体。拿上面的许可证门槛对照你自己的数字。
- 做文本工作、又不想托管任何东西：Max 和 2.4T 通过我们调用的价格在 2.4T 的七家提供商里有六家相同，所以区别只在于你是否需要图像输入。

### 如何调用 Qwen 3.8 模型

改模型 ID，请求其他部分不动。示例用 [TypeScript SDK](https://openrouter.ai/docs/client-sdks/typescript/overview)。

```
import { OpenRouter } from '@openrouter/sdk';

const openRouter = new OpenRouter({
  apiKey: process.env.OPENROUTER_API_KEY ?? '',
});

const result = await openRouter.chat.send({
  chatRequest: {
    model: 'qwen/qwen3.8-27b',
    messages: [
      {
        role: 'user',
        content: 'Summarize the trade-offs between fp8 and bf16 inference in two sentences.',
      },
    ],
    stream: false,
  },
});

if (result instanceof ReadableStream) {
  throw new Error('Expected a non-streaming response');
}

console.log(result.choices[0].message.content);
```

要发图片，把 content 换成内容部件数组而不是字符串。请求形态见[图像输入](https://openrouter.ai/docs/guides/overview/multimodal/image-understanding)。

```
const result = await openRouter.chat.send({
  chatRequest: {
    model: 'qwen/qwen3.8-27b',
    messages: [
      {
        role: 'user',
        content: [
          { type: 'text', text: 'What changed in this screenshot?' },
          { type: 'image_url', imageUrl: { url: screenshotUrl } },
        ],
      },
    ],
    stream: false,
  },
});

if (result instanceof ReadableStream) {
  throw new Error('Expected a non-streaming response');
}

console.log(result.choices[0].message.content);
```

同样的请求发给 `qwen/qwen3.8-2.4t-a95b` 会失败，因为它的任何提供商都不接受图像输入。

## 什么在影响成本

标价之外有两件事会改变账单。模型会先推理再作答，而推理 token 是要付钱的；我们把你路由到哪家的提供商也决定价格。

### 推理默认开启

四个模型默认都会在回答前推理。推理 token 按补全费率计费，即两个费率中较高的那个。`reasoning` 参数怎么用，见[推理 token](https://openrouter.ai/docs/guides/best-practices/reasoning-tokens)。

推理可能占你输出的很大份额。我们三次通过 Alibaba 让 27B 用两句话解释为什么 fp8 量化会改变模型输出，每次推理 token 都占补全 token 的 74%：128/174、171/231、181/243。对同一模型的图像描述请求，121 个补全 token 里有 87 个是推理。

能不能关掉推理，取决于模型和端点。2026 年 9 月 11 日我们对每个模型发送了 `reasoning: { effort: 'none' }`。

| 模型 | `effort: 'none'` 的结果 |
| --- | --- |
| qwen/qwen3.8-max-0902 | HTTP 400，`Reasoning is mandatory for this endpoint and cannot be disabled.` |
| qwen/qwen3.8-2.4t-a95b | HTTP 400，同样的报错 |
| qwen/qwen3.8-27b | HTTP 200，零推理 token |
| qwen/qwen3.8-flash | HTTP 200，零推理 token |

Alibaba 的模型卡把非思考模式列为托管 Max 的特性，但我们路由到的 Alibaba 端点拒绝这个请求。27B 的结果覆盖我们测的路由（Alibaba 和 Chutes），Flash 的结果覆盖 Makora。其他提供商行为可能不同，依赖"推理已关闭"时请检查响应的 `usage` 字段。

要在 27B 上关闭推理，只需加一个字段。

```
const result = await openRouter.chat.send({
  chatRequest: {
    model: 'qwen/qwen3.8-27b',
    messages: [{ role: 'user', content: 'Reply with the single word OK.' }],
    reasoning: { effort: 'none' },
    stream: false,
  },
});
```

我们把那个 fp8 问题带着推理跑了三次、关掉推理又跑了三次，都走 Alibaba。开推理时平均每次 216 个补全 token、$0.00058；关推理时平均 61 个补全 token、$0.00017。无论按 token 还是按美元算，大约省 70%。

Max 和 2.4T 仍然接受其他 effort 值。同一轮测试里，`effort` 设为 `max`、`high`、`minimal` 的请求在四个模型上都返回 HTTP 200，所以你能控制它们推理多少，只是在当前端点上没法让它们不推理。

### 提供商定价与上下文限制

Max 在我们目录里只有一家提供商：Alibaba。Flash 有两家：Alibaba 和 Makora。2.4T 有七家。27B 有十四家，而且收费不一样。2026 年 9 月 11 日，27B 的提示词价格在 $0.15 到 $0.45/百万 token 之间，补全在 $2.00 到 $3.20 之间。[当前列表](https://openrouter.ai/qwen/qwen3.8-27b/providers)在模型页上，而且会变，本文的数字请当作快照。

27B 的各提供商上下文也不一致：十四家里两家提供 1,000,000 token 窗口，一家止步 65,536，其余止步 262,144。携带 400,000 token 输入的请求必须路由到接受它的提供商。各家量化方式也不同：十四家大多列 fp8，一家列 fp4，还有几家的量化标注为未知。同一个模型 ID 背后的权重在各提供商之间并不相同，上面的 Artificial Analysis 分数描述的是该机构测的这个模型，不是任何一家的副本。

没有单一数字能说明 27B 的成本。数字对你要紧时，请锁定提供商。你可以用 `order` 字段指定提供商并关掉回退，完整控制项见[提供商路由](https://openrouter.ai/docs/guides/routing/provider-selection)。

**推理 token 并不是到处都单独列示。** 2026 年 9 月 11 日的测试中，Chutes 返回了模型的推理文本，但三次里有三次在 `usage` 里报告零推理 token。Alibaba、CoreWeave 和 Novita 每次都报告非零的推理 token 数。无论如何这些 token 你都在付钱，所以一个跨提供商把 `reasoning_tokens` 加总的仪表盘会少算。

直接对接 27B 的各提供商意味着 14 个账户、14 份集成。通过我们，请求里只是一个模型 ID；某家提供商变慢或报错时，我们把请求转到另一家。

## 常见问题

### Qwen 3.8 是开源的吗？

部分是。Qwen3.8 27B 以 Apache 2.0 发布。Qwen3.8 2.4T A95B 以 Qwen3.8-Max License 发布——那是 Qwen 自己写的、在规模上附加条件的许可证。Qwen3.8 Flash 没有自己的仓库，但它所基于的 Qwen3.8-Flash-Next 以 Qwen Community License 1.0 发布。Alibaba 称 -Next 模型是 Qwen4 计划架构的实验预览，而 Qwen3.8 Flash 是它的托管版本，所以这个后缀标记的是预览版本，不是第二款 Flash 模型。Qwen3.8 Max 没有公开权重。

### Qwen 3.8 免费吗？

你可以从 Hugging Face 下载 Qwen3.8 27B、Qwen3.8 2.4T A95B 和 Qwen3.8-Flash-Next，在自己的硬件上跑，没有按 token 的费用。Qwen3.8 Max 只能通过 API 使用。四个模型任何一个通过 OpenRouter 调用都按 token 计费。

### Qwen 3.8 能商用吗？

Qwen3.8 27B 是 Apache 2.0。Qwen3.8 2.4T A95B 允许商用，附两个条件：产品月活跃用户超过 100,000,000 或月收入超过 2,000 万美元时，必须在界面中展示模型名称；你或关联公司运营 Model as a Service 或 AI Work Assistant 业务且任意连续十二个月总收入超过 5,000 万美元时，商用前需从 Qwen 取得单独许可。Qwen3.8-Flash-Next 的 Qwen Community License 1.0 有同样的署名条件，并要求任何 Model as a Service 或 AI Work Assistant 业务单独取得许可、无收入门槛。条款详见 [Qwen3.8-Max License](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B/blob/main/LICENSE) 和 [Qwen Community License 1.0](https://huggingface.co/Qwen/Qwen3.8-Flash-Next/blob/main/LICENSE) 文件。

### 开放的 Qwen 3.8 权重能接受图像吗？

Qwen3.8 27B 接受文本、图像和视频。Qwen3.8-Flash-Next 是带视觉编码器的因果语言模型。Qwen3.8 2.4T A95B 仅文本。在 OpenRouter 上，向 `qwen/qwen3.8-2.4t-a95b` 发图像请求会返回 404，报错 `No endpoints found that support image input`。

### Qwen 3 是 Qwen 3.8 的前一作吗？

不是。Qwen 3 发布于 2025 年 4 月；Qwen 3.5、Qwen 3.6 和 Qwen 3.7 发布在 Qwen 3 和 Qwen 3.8 之间。Qwen 3.8 紧跟 Qwen 3.7。

### 我能关闭 Qwen 3.8 的推理吗？

取决于模型和端点。在 OpenRouter 上，`qwen/qwen3.8-max-0902` 和 `qwen/qwen3.8-2.4t-a95b` 以 400 拒绝 `reasoning: { effort: 'none' }`，报错称该端点的推理是强制的。`qwen/qwen3.8-27b` 和 `qwen/qwen3.8-flash` 在我们测的路由上接受并返回零推理 token。在我们的测试里，27B 关掉推理让同一提示词的成本降了约 70%。
