今天我们很高兴宣布，把 Zero Completion Token Insurance（零补全 token 保险）的保障范围扩展到 OpenRouter 上**每一个**可用模型！即日起，如果你收到的响应没有任何输出 token——因空响应或错误 finish reason 导致——你将不会被收费，即使底层模型服务商向我们收取了 prompt 处理费用。

按当前的用量规模，这项举措预计将在数百个模型上每周为用户节省**超过 $18,000**，彰显我们对公平与可靠的承诺。

### 工作原理

在以下情况下，Zero Completion Insurance 会自动保护你的账户：

- 响应的补全 token 为零，且 finish reason 为空白或 null。
- 响应的 finish reason 为错误。

无论哪种情形，**都不会从你的账户扣除任何额度**，与服务商向 OpenRouter 收取的费用无关。

### 自动生效、无感体验

Zero Completion Insurance 对每位 OpenRouter 用户自动启用，你无需任何额外配置或操作。

### 查看受保护的请求

在 Activity 页面上很容易识别受保护的请求——任何输出 token 为 0 的请求，其费用也会显示为 0。

### 我们的承诺

作为第一家、也是最大的 LLM 路由器，我们几乎遇到过模型服务商可能出现的所有质量问题。我们致力于在全行业提升质量标准，并会主动在所有服务商背后开展协作。我们的目标是打造一个可持续、对用户友好的生态。
