# 值得关注的开放权重模型：2026 年 6 月

Chris Clark ·6/27/2026 · 更新于 6/29/2026

过去几个月发布了一大批有竞争力的开放权重模型，中国和美国的玩家都有新面孔。同时，随着成本成为 AI 规模化使用的组织们的核心关注点，开放权重模型也正迎来属于自己的高光时刻。与许多人的预期相反，开放权重模型的智能和能力正跟得上美国前沿实验室，并且 18 个多月来始终稳定在 3–6 个月的差距内。前沿实验室目前（至少现在）并没有把开放权重实验室甩开的迹象。

把工作负载从前沿模型迁到开放权重，有巨大的降本空间。前沿当然会继续前进，但对任何一个固定的智能水位，成本都会持续下降。

发布节奏快、能力边界参差不齐、新玩家不断进场——想搞清楚哪些模型值得看、为什么值得看，非常难。站在 2026 年 6 月，我们认为最重要的开放权重模型是下面四个。

## 1. [DeepSeek V4 Flash](https://openrouter.ai/deepseek/deepseek-v4-flash) — 第一个跨过 agent 之河的模型

DeepSeek V4 Flash 是第一个被团队直接扔进真实 agent 流水线、当作 Anthropic 或 OpenAI 级前沿模型可信替代品的开放权重模型。更大的 V4 Pro 变体以 SWE-bench Verified 80.6% 定住了天花板——开放权重的最高分，对得上 GPT-5.5 级的 agent 表现。但真正破圈的是 Flash，因为它以性能和成本的帕累托前沿上的价格，拿到了那份能力的大头。

数字支撑着这种迁移行为。Flash 是 MIT 许可证，约 284B 参数 / 约 13B 激活的 MoE，1M token 上下文，SWE-bench Verified 拿到 79.0%——距 Pro 的 80.6% 以及那个约 1.6T / 49B 的同门师兄只有约 1.6 分。模型发布于 2026 年 4 月。

采用也在很大程度上是被价格推动的：DeepSeek 自家 API 给 Flash 标价 $0.14 / $0.28 每百万 token（输入/输出），但**会**为训练目的保留数据。配合缓存，实际价格更低（输入 $0.029/M）。DeepSeek 发布模型时就是按这个价格，把它宣传成 75% 的"折扣"，并从 5 月起变成永久价。这大致比 GPT-5.5 的输出成本低 150 倍。不过，DeepSeek 会保留并用你的数据训练。

不拿数据训练的西方托管方（如 Fireworks、Together、DeepInfra）报价约为第一方价格的两倍。以这个智能水平来说仍是极好的性价比。我们不清楚训练数据的价值在多大程度上支撑了 DeepSeek 的低价，还是算力补贴等等——但肯定的是，第一方的低价给所有提供商制造了竞争格局，把这一档智能水平的价格压到了异常之低。

OpenRouter 在模型页面的 [providers 标签](https://openrouter.ai/deepseek/deepseek-v4-flash#providers)详情栏里公开每家提供商的所属国家，并允许你精细控制你和组织能接受哪些数据政策。

**注意点：**纯文本，无图像或视频输入。第一方 API 的数据经由中国路由，ToS 允许拿你的数据训练——如前所述，价格相当的 no-train 西方托管方是可用的。 使用体验层面，这个模型更偏技术工作，写作与语气上的满意度较低。我们也见到反馈说提示词写法需要相对 Anthropic 模型调整——Flash 在非常具体的指令下表现更好，靠它自己发挥判断则差一些。

**什么时候选它：**想要前沿级的 agentic/编码模型但只花一小部分钱。从 Flash 开始，只有当边际质量值那个溢价时再上 Pro。

## 2. [GLM 5.2](https://openrouter.ai/z-ai/glm-5.2) — 让 Opus 式 agentic 编码变得可移植的开放模型

GLM 5.2 六月中旬发布，但早期口碑非常强。DeepSeek 是在价格上破圈，GLM 5.2 看起来是在规划质量和长程编码上破圈。

[Artificial Analysis](https://artificialanalysis.ai/evaluations/artificial-analysis-intelligence-index) 把 GLM 5.2 列为其智能指数（v4.1）开放权重第一：51 分，领先 Nemotron 3 Ultra（48）、MiniMax M3（44）、DeepSeek V4 Pro（44）和 Kimi K2.6（43），只比 Claude Fable 5 低约 5 分。它在 Artificial Analysis 的真实世界 agentic 基准（GDPval-AA v2）上领跑开放权重，与 GPT-5.5 xhigh 基本打平。

采用还处于早期，但模型已经在一批有意义的第三方托管方可用。价格谈不上 DeepSeek 式便宜，但仍显著低于闭源前沿编码模型。实际价格是 OpenRouter 加权平均 **$0.447 / $3.31 每百万 token（输入/输出）**。按 token 单价它比 GPT-5.5 / Opus 级模型便宜，但这个模型很爱思考，输出 token 可以很快烧钱。

还有一股地缘政治顺风。GLM 5.2 落地仅几天前，美国的出口管制指令迫使 Anthropic 大范围关停 Fable 5 和 Mythos 5，以防止外国国民访问。一个 MIT 权重、编码表现接近前沿的模型，对要求业务连续性的组织突然更有吸引力了。

**注意点：**纯文本，无图像或视频输入。它很吃 token，在高思考模型上会烧钱。它还很新，提供商质量会参差。各家提供商的吞吐上限约 78 tok/s（DeepSeek V4-Flash 约 84 tok/s）。

**什么时候选它：**agentic 规划和编码最接近的直接替代品。擅长架构规划、仓库规模重构和长时间运行的 agent 任务。当质量和规划比极限低价更重要时，选它而不是 DeepSeek。

## 3. [MiniMax M3](https://openrouter.ai/minimax/minimax-m3) — 多模态长上下文模型

MiniMax M3 是这一组里唯一原生理解文本之外还能理解图像和视频的模型。如果你的 agent 需要读截图、检查 UI 状态、解析图表或对视频推理，M3 是开放权重赛道上第一个该测的。

Artificial Analysis 给 M3 的智能指数（v4.1）是 44 分——与 DeepSeek V4 Pro 并列，落后 GLM 5.2 和 Nemotron 3 Ultra，但它的差异化在模态，不在指数排名。更能说明问题的是，它在 GDPval-AA（Artificial Analysis 的真实世界 agentic 基准）上大致与 Claude Sonnet 4.6 打平。它也是真正的长上下文模型：约 428B 参数 / 约 23B 激活的 MoE，1M token 上下文，加上 MiniMax Sparse Attention 让百万 token 推理不再是天方夜谭。

实际价格很有吸引力，OpenRouter 加权平均 **$0.098 / $1.21 每百万 token（输入/输出）**（上下文超过 512k token 时价格上涨）。但和 GLM 一样，便宜的 token 不等于便宜的运行。M3 可以很啰嗦、很吃推理。

架构同样有创新：MSA 在真实 K/V 块上做块级稀疏注意力，而不是另搭一套检索或压缩系统。论文报告注意力计算量大幅下降而质量几乎无损。落到实际，这就是 M3 能以合理成本支撑整仓库、长文档、截图密集或视频接地 agent 的原因。

**注意点：**不是 MIT 许可证。权重放出来了，但挂在 MiniMax Community License 下：商用需要署名/声明，大型商业产品还需要事先书面许可。提供商质量和完整上下文支持会参差。它也不是这组里最强的纯编码模型；纯文本 agentic 编码，GLM 5.2 大概率是更好的默认。

**什么时候选它：**你需要带原生图像或视频输入的长上下文 agent。最合适的场景是 UI 自动化、screenshot-to-code、图表/文档理解、视频接地的工作流，或混合模态的仓库/文档 agent。它会是对同样擅长多模态理解的 Gemini Flash 系列的有力竞争者。

## 4. [NVIDIA Nemotron 3 Ultra](https://openrouter.ai/nvidia/nemotron-3-ultra-550b-a55b) — 美国的开放权重加速器

NVIDIA 的 Nemotron 3 Ultra 是最清楚的信号：强力的开放权重模型不只来自中国实验室。它不是全开放模型里的头名，但它是美国最强的开放权重入场者：一个认真的推理模型，为企业部署而建，背后站着 NVIDIA 的硬件和软件栈。

基准面读数扎实。Artificial Analysis 给 Nemotron 3 Ultra 的智能指数（v4.1）48 分——开放权重第二，仅次于 GLM 5.2（51），领先 MiniMax M3、DeepSeek V4 Pro 和 Kimi K2.6，也是当之无愧的美国最强开放权重入场者。它的差异化在部署效率。OpenRouter 加权平均价 **$0.423 / $2.61 每百万 token（输入/输出）**，另有一条**`:free`** 路线人气极高、正在拉动采用。

模型本体是 550B / 55B 激活的 Mamba-2 + Transformer MoE 混合架构，用 NVFP4 训练，1M 上下文，Multi-Token Prediction，许可证是 OpenMDW。NVIDIA 放出来的也不只是权重：还有数据、配方、评测工具和 RL 基础设施。NVIDIA 的动机很直白：开放模型用得越多（且有更多有意义的模型），对 Blackwell/Hopper 推理、NIM 微服务、CUDA、AI Enterprise 和主权 AI 部署的需求就越大。Nemotron 是一个模型，也是被设计来推高整个开放生态——从而推高 NVIDIA AI 栈的。

盯着 NVIDIA 在这里的动作：它有持续向全球生态扩散模型的动力，也有足够的钱，供得起和地球上任何实验室并跑的研究和训练。

**注意点：**纯文本，无图像或视频输入。原始智能落后 GLM 5.2，更广泛的中国开放前沿在峰值编码分数上领先。免费路线适合测试和拉新，不适合围绕它签严肃的生产 SLA。

**什么时候选它：**你想要一个美国制造的开放权重模型，用于长时运行的 agent、RAG、编排、编码辅助，或速度、可部署性、数据掌控和供应商安心感比绝对排名更重要的企业工作流。要开放编码的峰值质量，选 GLM 或 DeepSeek；要看重整个技术栈，选 Nemotron。
