## ⚡ 推理模型性能指标改进

- 延迟现在以到第一个推理 token 的时间来衡量。
- 吞吐量同时计入推理 token 和输出 token。

## 🛠️ 面向开发者

- 全新 Request Builder：轻松生成请求体 JSON，更好地理解请求。
 在这里试用：[https://openrouter.ai/request-builder](https://openrouter.ai/request-builder)
- Prompt Category API：直接请求针对特定 prompt 类别优化的模型。
 编程类模型示例：[https://openrouter.ai/api/v1/models?category=programming](https://openrouter.ai/api/v1/models?category=programming)
- 通过侧边栏浏览所有可用类别：[https://openrouter.ai/models](https://openrouter.ai/models)
