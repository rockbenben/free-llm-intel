# Jevons 悖论还成立吗？

在 AI 热潮至今的进程中，Jevons 悖论一直是推理领域的决定性法则：随着 token 价格下降，使用量会膨胀到足以把总支出推高的程度。近几个月来，这一动态有所减弱。token 消耗毫无放缓的迹象，但支出增长已急剧放慢。

## 目前的情况

![折线图：2026 年 OpenRouter 上每周付费 token、支出与每 token 价格，以 1 月 5 日当周为基期、采用对数尺度。token 增至 44 倍，支出增至 7.6 倍，每 token 平均价格下降 83%。自 10 月初以来支出大致持平。](https://openrouter.ai/blog/images/is-jevons-paradox-holding-1.png)

2026 年迄今为止，token 总量增长了 **44 倍**，而总支出增长了 **7.6 倍**。这种分化在今年秋天变得更加清晰：使用量持续攀升，而支出自 10 月初以来只是微幅上浮。对 token 的胃口显然依旧旺盛，只是买家在不增加预算的情况下得到了多得多的产出。

## 各季度弹性

![柱状图：2026 年各季度的 token 弹性——第一季度 5.4，第二季度 5.5，第三季度 1.6，第四季度截至 11 月 16 日为 1.2。1 处的虚线标出盈亏平衡点，即价格下降时支出保持不变。](https://openrouter.ai/blog/images/is-jevons-paradox-holding-2.png)

弹性衡量的是使用量对价格的反应强度，更准确的说法是：每 token 价格每下降 1%，token 量上升的百分比。弹性大于 1 时，总支出随价格下降而上升，这就是 Jevons 悖论。等于 1 时，支出保持不变：买家把省下的钱换成了更多 token。季度弹性（把每个季度开始前的四周与结束前的四周相比，取 token 的对数变化与每 token 价格的对数变化之比）清晰地展示了这一转变。第一季度弹性为 **5.4**，第二季度为 **5.5**，属于典型的 Jevons 区间——更便宜的 token 推动了大量新增支出。第三季度降至 **1.6**，第四季度截至目前为 **1.2**。

这不是第一次回落。2024 年 12 月和 2025 年 11 月，弹性也曾降到 1 附近，而两次都随着下一波模型发布而回升。当前的放缓可能只是两波之间的间歇，而不是一次持久的断裂。

## 月度环比增长：token 与支出

![折线图：2026 年每周付费 token 与支出的月度环比增长，并标出重要模型发布：Claude 4.6、DeepSeek V4、Kimi K3 与 GPT-5.6、DeepSeek V4.1 Flash、Claude Opus 5.5。今年上半年两条线同步移动。自 7 月起，token 保持每月约 40% 的增长，而支出增长降至 0%。](https://openrouter.ai/blog/images/is-jevons-paradox-holding-3.png)

把月度环比增长与重要模型发布并列来看，就能看到两者在哪里分道扬镳。2026 年上半年，支出的增速几乎与 token 相当。自 7 月起，两者就此分开：token 仍以每月约 **39%** 的速度增长，而支出增长已跟不上。重要的是，每 token 成本（尤其是在 Claude 或 GPT 这类闭源模型家族内部）在同一时期仍持续大幅下降。

## 这意味着什么

更便宜的推理仍在推动大规模采用，**44 倍**的 token 增长就是证明，但近几个月它并未带来与之相称的支出增长。这一模式也因客户类型而异：企业看起来比 AI 原生的快速成长型公司更在意成本，更多地把降价当作节省，而不是新增支出。

值得注意的是，2026 年初真正意义上的 agentic coding 出现，很可能帮助 Jevons 悖论维持了如此强的势头。这就引出一个问题：如果支出增长回到此前的速度，下一次跃迁会是什么？

随着下一批模型发布落地，我们会持续跟踪这一点。
