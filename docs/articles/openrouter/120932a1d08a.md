# Jevons Paradox 还成立吗？

OpenRouter ·11/26/2026

在 AI 热潮迄今为止的发展中，Jevons paradox（杰文斯悖论）一直是推理领域的决定性法则：随着 token 价格下降，使用量爆炸式增长，足以推高总支出。近几个月来，这一动态有所减弱。token 消耗没有放缓的迹象，但支出增长已急剧放缓。

## 目前的情况

![2026 年 OpenRouter 上每周付费 token、支出和每 token 价格的折线图，以 1 月 5 日当周为基准、采用对数尺度。Token 增至 44 倍，支出增至 7.6 倍，每 token 平均价格下降 83%。自 10 月初以来，支出大致持平。](https://openrouter.ai/blog/images/is-jevons-paradox-holding-1.png)

2026 年迄今为止，token 总量增至 **44 倍**，而总支出增至 **7.6 倍**。今年秋天，这种分化变得更加明显：使用量持续攀升，而自 10 月初以来支出仅小幅上升。对 token 的需求显然仍然强劲，但买家只是在不增加预算的情况下获得了多得多的产出。

## 各季度弹性

![2026 年各季度 token 弹性柱状图：第一季度为 5.4，第二季度为 5.5，第三季度为 1.6，第四季度截至 11 月 16 日为 1.2。1 处的虚线标示临界点，即价格下降时支出保持持平。](https://openrouter.ai/blog/images/is-jevons-paradox-holding-2.png)

弹性衡量使用量对价格的反应强度，更准确地说，是每 token 价格每下降 1% 时，token 数量增加的百分比。高于 1 时，价格下降而总支出上升，这就是 Jevons paradox。等于 1 时，支出持平：买家把节省下来的钱转化为更多 token。季度弹性将各季度开始前四周与结束前四周进行比较（以 token 数量与每 token 价格的对数变化之比计算），清晰显示了这一转变。第一季度弹性保持在 **5.4**，第二季度为 **5.5**，处于典型的 Jevons 区间，更便宜的 token 推动了大量净新增支出。第三季度降至 **1.6**，第四季度迄今为 **1.2**。

这不是第一次下滑。2024 年 12 月和 2025 年 11 月，弹性也曾降至约 1，而两次都随着下一波模型发布而回升。当前的放缓可能只是两波之间的间歇，而非持久的断裂。

## 环比增长：token 与支出

![2026 年每周付费 token 与支出的环比增长折线图，并标注了重大模型发布：Claude 4.6、DeepSeek V4、Kimi K3 和 GPT-5.6、DeepSeek V4.1 Flash，以及 Claude Opus 5.5。今年上半年，两条线同步变动。自 7 月以来，token 每月持续增长约 40%，而支出增长降至 0%。](https://openrouter.ai/blog/images/is-jevons-paradox-holding-3.png)

将环比增长与重大模型发布放在一起绘制，可以看出两者在何处分化。2026 年上半年，支出的增长几乎与 token 一样快。自 7 月以来，两者出现分化：token 仍以每月约 **39%** 的速度增长，而支出增长未能跟上。重要的是，同期每 token 成本（尤其是在 Claude 或 GPT 等闭源模型系列中）仍在持续大幅下降。

## 这意味着什么

更便宜的推理仍在推动大规模采用，**44 倍**的 token 增长证明了这一点，但近几个月来，它并未带来与之匹配的支出增长。这一模式也因客户而异：与 AI 原生高增长企业相比，企业看起来更注重成本，更多地将价格下降转化为节省，而非新增支出。

值得注意的是，2026 年初真正意义上的 agentic coding 的出现，很可能帮助 Jevons 悖论维持了如此强劲的成立态势，这引出了一个问题：如果支出增长恢复到此前的速度，下一次飞跃会是什么？

随着下一批产品发布落地，我们将持续跟踪。
