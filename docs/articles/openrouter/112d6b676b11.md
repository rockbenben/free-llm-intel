我们很高兴终于宣布 BYOK 面向所有人开放。这是一种使用 OpenRouter 的强大新方式，可以继续利用你在主流服务商处已有的 API 密钥和额度。

## 🚀 核心优势

- 更高限速：把你的服务商限额与 OpenRouter 的合并，获得更高吞吐量。现在对免费模型同样有效！
- 使用第三方额度：充分利用你在 OpenAI、Google Cloud、AWS 及其他数十个平台上已有的额度
- 统一分析：通过 Activity 仪表盘在一个地方追踪你所有的 LLM 用量

BYOK 收取上游服务商成本 5% 的费用，同时让你享有 OpenRouter 的全部其他优势。

准备好开始了吗？前往 [Settings](https://openrouter.ai/settings/integrations) 添加你的密钥。
