# Dev & BYOK Updates: Uptime API + Smarter Key Management

OpenRouter ·6/25/2025 · Updated 6/11/2026

## Uptime Tracking API

You can now programmatically track model uptime using the new OpenRouter API endpoint. Details: [https://x.com/OpenRouterAI/status/1937869909448441980](https://x.com/OpenRouterAI/status/1937869909448441980)

## BYOK Improvements

Several quality-of-life upgrades for Bring Your Own Key users:

- Test keys before saving them
- Limit upstream usage per key
- Track usage with `"is_byok": true` in your API responses

More details: [https://x.com/OpenRouterAI/status/1937872903988535400](https://x.com/OpenRouterAI/status/1937872903988535400)
