# 🔐 Passkeys 正式上线

你现在可以用 passkeys 保护账户——这是我们强烈推荐的一种更安全、免密码的登录方式。
 👉 立即设置：[https://openrouter.ai/settings/preferences](https://openrouter.ai/settings/preferences)

## 🛠️ 开发者体验提升

- 服务商和量化版本现在都有了 slug，方便通过 API 精确定位。
 → 点击任意模型旁的“Copy”按钮，即可获得带 slug 信息的精确 API 调用示例。
 实际效果见：[https://x.com/OpenRouterAI/status/1924868065910518226](https://x.com/OpenRouterAI/status/1924868065910518226)
- 文档页面新增了 Copy Page 下拉菜单，导航和复用更快。

## 📚 文档上新：TypeScript Agent 指南

来自 Mastra 的 TypeScript agent 编写新指南现已上线我们的文档！
 阅读地址：[https://openrouter.ai/docs](https://openrouter.ai/docs)
