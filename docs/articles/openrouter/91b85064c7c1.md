# 如何将 Claude Code 与 OpenRouter 结合使用

OpenRouter ·6/16/2026 · 更新于 9/24/2026

你正深入一次重构。Claude Code 已经跨十几个文件拉好了上下文、规划了 diff、开始执行。然后会话在70%进度处被一条速率限制掐断。

把 Claude Code 经 OpenRouter 路由，就是让这场会话活下来的办法。OpenRouter 挡在 Claude Code 和 Anthropic API 之间，充当可靠性和管理层：提供商故障转移、预算控制和用量可视性——而且不需要你在本地跑任何代理。配置就三个环境变量。本文讲这套配置、模型路由、Fast Mode 和成本账。如果你和 Claude Code 一起还跑别的工具，同一个 key 全都通用，见[如何把 OpenRouter 接入任意编码 agent](https://openrouter.ai/blog/tutorials/any-coding-agent/)。

团队场景同样实际。多名开发者同时跑 Claude Code，就意味着多个 Anthropic 账户、没有共享支出视图、在账单落地之前没有按开发者的上限。一个 OpenRouter key 挡在所有这些前面：共享计费、按 key 限额，和一个能显示每次会话成本的 [Activity 面板](https://openrouter.ai/activity)。

## 三步接上 Claude Code

整个配置就是三个环境变量，记录在 [Claude Code 集成指南](https://openrouter.ai/docs/cookbook/coding-agents/claude-code-integration)里。没有代理、没有 Docker、没有本地端口要跑。

```
# Add to ~/.zshrc or ~/.bashrc
export OPENROUTER_API_KEY="<your-openrouter-api-key>"
export ANTHROPIC_BASE_URL="https://openrouter.ai/api"
export ANTHROPIC_AUTH_TOKEN="$OPENROUTER_API_KEY"
export ANTHROPIC_API_KEY=""   # must be explicitly empty
```

三件事必须对。base URL 是 `https://openrouter.ai/api`；auth token 是你的 [OpenRouter key](https://openrouter.ai/settings/keys)，以 `sk-or-` 开头；`ANTHROPIC_API_KEY` 必须是空字符串而不是未设置，否则 Claude Code 可能回退到直接向 Anthropic 认证。

想只作用于单个项目？把同样三个值放进项目根 `.claude/settings.local.json` 的 `env` 块里。别用裸 `.env` 文件——原生安装器不读它。

如果你之前用 Anthropic 账户登录过 Claude Code，先运行一次 `/logout` 再重启，否则缓存的登录会盖掉你的变量，报一些莫名其妙的 model-not-found 错误。用 `/status` 确认切换成功：

```
> /status
Auth token: ANTHROPIC_AUTH_TOKEN
Anthropic base URL: https://openrouter.ai/api
```

你的请求也应该在几秒内出现在 [Activity 面板](https://openrouter.ai/activity)上。

## 没有代理，Anthropic Skin 是怎么工作的

OpenRouter 暴露了一个兼容 Anthropic Messages API 的端点，他们称之为 Anthropic Skin。Claude Code 用自己的原生协议直连 OpenRouter，Skin 负责模型映射，高级特性原样透传。

也就是说 Thinking 块、原生工具使用、流式和多轮上下文都和直连 Anthropic 时一样工作。旧方案依赖 claude-code-router 这类本地代理翻译请求，意味着一个 Node.js 运行时、一个本地端口、一层还得有人盯着健康的翻译层。原生路由把 Anthropic 工作流里的这一整层去掉了。

底层，OpenRouter 在服务某模型的各 Anthropic 提供商之间做负载均衡。先试的那家对你限流时，它把同一个模型路由给另一家服务的提供商，你只为落地的调用付钱。对一个在多次调用之间持有状态的多步 agentic 任务，故障转移发生在 Claude Code 之下，就是"任务完成"和"改了一半"之间的区别。

## 把每类任务路由到合适的模型

Claude Code 把工作分到多个模型槽位。逐个覆盖它们，指向 OpenRouter 上的具体模型。`~author/model-latest` 别名永远解析到该家族最新版本，不会过时：

```
export ANTHROPIC_DEFAULT_OPUS_MODEL="~anthropic/claude-opus-latest"
export ANTHROPIC_DEFAULT_SONNET_MODEL="~anthropic/claude-sonnet-latest"
export ANTHROPIC_DEFAULT_HAIKU_MODEL="~anthropic/claude-haiku-latest"
export CLAUDE_CODE_SUBAGENT_MODEL="~anthropic/claude-opus-latest"
```

一个合理的分工：Opus 管架构和深度推理，Sonnet 管日常编码，Haiku 管快速转换和分类。把这些放到与 base URL、token 同一个 shell profile 或项目设置文件里。

但模型请保持 Anthropic。Claude Code 围绕 Anthropic 的请求语义构建，这个集成只保证在 Anthropic 第一方提供商上工作。要最大兼容性，请把 [Anthropic 1P 设为你的最高优先级提供商](https://openrouter.ai/docs/guides/routing/provider-selection)。

## Opus 会话的 Fast Mode

Anthropic 的 Fast Mode 以更高单价换取最高 2.5 倍的输出速度，只由 Anthropic 第一方提供商服务。它适用于 [Claude Opus 4.6](https://openrouter.ai/anthropic/claude-opus-4.6)、4.7 和 4.8，其他模型没有。

Claude Code 内置 `/fast` 开关。开启时，Claude Code 会随所配置的 Opus 模型发送 `speed: "fast"`，OpenRouter 重路由到对应的 `-fast` 变体。要用它，只需设一个变量：

```
export CLAUDE_CODE_SKIP_FAST_MODE_ORG_CHECK=1
```

需要 Claude Code v2.1.96 或更新。向不支持它的模型发 `speed: "fast"`，OpenRouter 会直接丢弃这个参数，请求按标准速度和价格运行。在延迟是你直接体感的交互式会话和现场调试里用它。给生产开启前，先到[定价页](https://openrouter.ai/pricing)核实现行 Opus 费率。

## 多少钱，以及免费档

OpenRouter 不加价 token 定价。你付的就是提供商的每 token 单价——[模型目录](https://openrouter.ai/models)上显示的价格——额度购买收 5.5% 手续费，最低 $0.80。

相对真实用量，这笔手续费很小。取每月 10M token 跑 Claude Sonnet 4.5、按 80/20 的输入输出占比：$3/百万输入、$15/百万输出，直接 token 成本约 $54，5.5% 的额度手续费再加约 $3。换来的是故障转移、按 key 预算封顶，和全团队一个计费视图。

试用还有免费档。[免费模型](https://openrouter.ai/models?max_price=0)每天最多 50 次请求，充值 $10 额度后升到每天 1,000 次。它们的上下文窗口比付费 Anthropic 模型小，适合学习 Claude Code 的工作流，不适合生产会话。支出在 [Activity 面板](https://openrouter.ai/activity)实时可见——发现某次会话被路由到比任务所需更重的模型，这是最快的办法。

## 接入 CI 和你的终端

同一套路由不止在你本地 shell 里生效。

CI 方面，官方 [Claude Code GitHub Action](https://github.com/anthropics/claude-code-action) 只需要两处改动：把 OpenRouter key 通过 `anthropic_api_key` 传入，并在 step 的 env 里设 base URL。

```
- name: Run Claude Code
  uses: anthropics/claude-code-action@v1
  with:
    anthropic_api_key: ${{ secrets.OPENROUTER_API_KEY }}
  env:
    ANTHROPIC_BASE_URL: https://openrouter.ai/api
```

想在终端里实时看到成本：[openrouter-examples 仓库](https://github.com/OpenRouterTeam/openrouter-examples/tree/main/claude-code)提供一个 statusline 脚本，显示提供商、模型、累计成本和缓存折扣。把 `~/.claude/settings.json` 指向它：

```
{
  "statusLine": {
    "type": "command",
    "command": "/path/to/statusline.sh"
  }
}
```

在 Claude Code 之上构建 agent？[Anthropic Agent SDK](https://openrouter.ai/docs/guides/community/anthropic-agent-sdk) 使用 Claude Code 运行时，同样这三个环境变量就能把它的请求路由经 OpenRouter，无需额外配置。

## 常见问题

### 用 OpenRouter 跑 Claude Code 需要 Anthropic 订阅吗？

不需要。请求走你的 OpenRouter 额度，你只需要一个 OpenRouter 账户和 API key，不需要 Anthropic 套餐。之前若用 Anthropic 账户登录过 Claude Code，切换前先运行一次 `/logout` 清掉缓存会话。

### 能通过 OpenRouter 让 Claude Code 用非 Anthropic 模型吗？

原生集成为 Anthropic 模型构建，且只保证在 Anthropic 第一方提供商上工作。Claude Code 期望的是 Anthropic 请求语义，非 Anthropic 模型不能通过原生端点支持。

### 经 OpenRouter 用 Claude Code 要花多少钱？

提供商的每 token 单价，加额度购买上 5.5% 手续费（最低 $0.80）。推理本身维持提供商价格。[Activity 面板](https://openrouter.ai/activity)实时显示每次会话的精确成本。

### OpenRouter 会记录我的源码吗？

不会。默认 OpenRouter 只保留 token 数这类元数据，不保留你的提示词或补全。记录你自己的输入输出是可选项；另有一个独立的 opt-in：让 OpenRouter 用你的数据改进产品，换 1% 用量折扣。条款见[隐私政策](https://openrouter.ai/privacy)。

### 什么是 Fast Mode，哪些模型支持？

Fast Mode 由 Anthropic 第一方提供商服务，以更高单价换取最高 2.5 倍的输出速度。仅 Claude Opus 4.6、4.7 和 4.8 可用。在 Claude Code 里用 `/fast` 切换。

### Anthropic API 对我限流了怎么办？

OpenRouter 故障转移到服务同一模型的另一家 Anthropic 提供商，会话无需重连继续运行。按实际服务该请求的提供商费率计费。
