我们完成了 [1.13 亿美元的 B 轮融资](https://openrouter.ai/announcements/series-b)，现在每月路由 100 万亿 token。以下是五月交付的其他所有内容。

## Workspace Guardrails

为经由你的 workspace 路由的每个请求提供集中式安全与治理。设置按成员、按密钥的支出上限，把流量锁定在模型与服务商白名单内，强制零数据保留，针对 30+ 个源自 OWASP 的模式拦截 prompt 注入，并在 PII 到达服务商之前将其脱敏。可以把规则叠进一个 guardrail，也可以限定到特定的 API key 和成员——无需改代码。

[文档](https://openrouter.ai/docs/guides/features/guardrails) · [公告](https://openrouter.ai/announcements/guardrails)

## Speech 与 Transcription API

用你已有的同一枚 API key 为任意应用加上语音。语音转文本已上线 Whisper、GPT-4o Mini Transcribe 和 Voxtral；文本转语音在 models API 中暴露 `supported_voices`。两者都内置服务商故障转移和上游错误透传。

[浏览音频模型](https://openrouter.ai/models?fmt=cards&output_modalities=audio) · [公告](https://openrouter.ai/announcements/announcing-audio-apis)

## Model Fusion

把 prompt 并行路由给多个模型，并将它们的响应综合为一条更高质量的回答。Model Fusion 现已有 API 插件、服务端工具和 chatroom 输入框三种形态。一次调用得到一个专家集合，而不是依赖单一模型。

[试用 Model Fusion](https://openrouter.ai/fusion) · [文档](https://openrouter.ai/docs/guides/features/server-tools/fusion)

## 模型对比

最多五个模型并排比较价格、上下文长度和基准分数。重造的对比页包含“Highlight best”开关、按服务商编码的 Intelligence/Coding/Agentic 指标基准图，以及可快速添加模型的交互式插槽卡片。

[对比模型](https://openrouter.ai/compare)

## 私有模型（Enterprise）

通过标准的 completions 和 responses API 路由到你自己的定制、微调或专属模型端点。私有模型享受与平台上任何公开模型同等的 guardrails、可观测性和计费。仅 Enterprise 套餐可用。

[文档](https://openrouter.ai/docs/guides/routing/private-models)

## Pareto Code Router

设置 `min_coding_score`，路由到能通过你质量门槛的最便宜的编码模型。你的 coding agent 不再为“够用的代码”过度付费。插件设置中可按 workspace 配置默认值。

[试用](https://openrouter.ai/openrouter/pareto-code)

## 企业与 Workspace 管控

一系列为大规模运行 OpenRouter 的团队准备的发布：

- **IP allowlist 强制执行。** 带 IP 白名单的 API key 现在会以 `403` 主动拦截未授权 IP 的请求，从仅观察模式升级而来。[文档](https://openrouter.ai/docs/guides/features/workspaces)
- **BYOK 管理 API。** 以编程方式跨 workspace 列出、创建、更新和删除自带密钥凭证。密钥现按优先级分组，支持拖拽排序，失败请求可一键“Test Key”。[API 文档](https://openrouter.ai/docs/api/api-reference/byok/create-byok-key)
- **Observability 目的地 API。** 通过 management key 管理 Datadog、Langfuse、LangSmith 等可观测性集成的 CRUD 端点。[API 文档](https://openrouter.ai/docs/api/api-reference/observability/create-observability-destination)
- **按服务商的 ZDR 控制。** 为非前沿模型、Anthropic、OpenAI 和 Google 服务商提供独立的 Zero Data Retention 开关，在不限缩整个模型目录的情况下按服务商满足合规要求。
- **跨 workspace 复制 guardrails。** 通过“Copy to…”菜单，几次点击即可在所有 workspace 间统一安全政策。

## 本月其他交付

**Presets API。** 直接从推理请求体创建或版本化一个 preset，新增 Anthropic Messages 和 Responses skins，并支持 TypeScript 和 Python SDK。[文档](https://openrouter.ai/docs/guides/features/presets)

**Human-in-the-loop 工具。** 一种新的 SDK 工具类型，会暂停执行等待人工输入再返回结果，为任务中需要人类判断的 agent 准备。[博客文章](https://openrouter.ai/announcements/human-in-the-loop-tools)

**Session-id 服务商粘性。** 共享 `session_id` 的请求现在会路由到同一服务商、跨轮次钉住同一具体模型，提升多轮 agentic 工作流的缓存命中率。[文档](https://openrouter.ai/docs/guides/routing/provider-selection)

**Auto router 的 `cost_quality_tradeoff`。** 一个 0 到 10 的整数，取代旧的二元开关，在使用 auto router 时对成本与质量做更细的权衡。[文档](https://openrouter.ai/docs/guides/routing/routers/auto-router)

**重造的模型页面。** 新的模型页头部、带 `/responses` 和 `/messages` 端点的分步 API 标签页、全屏模型选择器，以及可即时测试的 playground 侧边面板。

**日志中的 Requests 标签页。** 与生成日志并列的完整请求级下钻，支持请求 ID 过滤和时间选择器的简写（`15min`、`1h`、`3d`）。[Logs](https://openrouter.ai/logs)

**改进的 coding agent 归因。** Cursor、GitHub Copilot、Cline、RooCode、Kilo Code、Zed 和 OpenCode 现在会在活动日志中被正确识别，你可以看到哪些工具在驱动用量。

**API key 上的用量与预算。** 按 guardrail 层级展示的支出图表和预算进度，直接显示在每个 API key 上。

**Rankings 每日数据集。** `GET /api/v1/datasets/rankings-daily` 返回按每日 token 量排名前 50 的模型，供编程分析。

## 新模型

五月发布了 20 个模型，横跨文本、语音、图像、视频和编码：

- **Anthropic Claude Opus 4.8**：Anthropic 最新的 Opus，带会话中期 system 支持，另有快速变体
- **Google Gemini 3.5 Flash**：Google 最新的 Flash 模型
- **xAI Grok 4.3**：xAI 最新的前沿模型
- **xAI Grok Imagine Video**：xAI 的视频生成
- **xAI Grok Build 0.1**：xAI 的代码生成模型
- **Qwen Qwen3.7 Max**：Qwen 最新的 max 档模型
- **Recraft V3、V4、V4 Pro**：三款新的图像生成模型
- **Mistral Voxtral Mini Transcribe**：Mistral 的语音转文本模型

此外还有：Gemini 3.1 Flash Lite、GPT Chat Latest、CoBuddy（免费）、Ring-2.6-1T（免费）、Perceptron Mk1 等。
