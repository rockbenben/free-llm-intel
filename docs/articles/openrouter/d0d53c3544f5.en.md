# Better Insights, Faster Metrics, and New Developer Power Tools

OpenRouter ·5/6/2025 · Updated 6/11/2026

## 📊 Enhanced Activity Page

- Dive deeper into model usage with multiple new charts.
- Check your personalized model rankings by clicking on one.
 Screencast: [https://x.com/OpenRouterAI/status/1920141911928488305](https://x.com/OpenRouterAI/status/1920141911928488305)

## ⚡ Improved Reasoning Model Performance Metrics

- Latency now measures time until the first reasoning token.
- Throughput includes both reasoning and output tokens.

## 🛠️ For Developers

- New Request Builder: Easily generate request body JSON and understand requests better.
 Try it here: [https://openrouter.ai/request-builder](https://openrouter.ai/request-builder)
- Prompt Category API: Request models optimized for specific prompt categories directly.
 Example for programming models: [https://openrouter.ai/api/v1/models?category=programming](https://openrouter.ai/api/v1/models?category=programming)
- Explore all available categories via the sidebar: [https://openrouter.ai/models](https://openrouter.ai/models)
