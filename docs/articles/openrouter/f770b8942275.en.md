# Quasar Alpha and Optimus Alpha Reveal

OpenRouter ·4/14/2025 · Updated 6/11/2026

# OpenAI GPT-4.1 ⭐️

**GPT-4.1** is now generally available with a 1M token context.
 There’s a Mini and a Nano version as well, but Quasar and Optimus were tests of the large one (4.1).

## 💰 Pricing

**GPT-4.1**

- $2.00 input
- $0.50 cached input
- $8.00 output per 1M tokens

**GPT-4.1 Mini**

- $0.40 input
- $0.10 cached input
- $1.60 output per 1M tokens

**GPT-4.1 Nano**

- $0.10 input
- $0.025 cached input
- $0.40 output per 1M tokens

## 📢 Details

- Announcement on X: [OpenRouter X Announcement](https://x.com/OpenRouterAI/status/1911833662464864452)
- **Immediate Alpha Retirement**: The free alpha endpoints for Optimus and Quasar are now retired. API requests will return a 404 and no automatic redirects to prevent unexpected costs.
