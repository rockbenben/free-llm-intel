GLM-TTS-Clone 音色克隆模型上线

🎵

GLM-TTS-Clone

- 只需录制约 3 秒清晰语音，即可生成专属音色
- 支持普通话及轻口音，更好复刻节奏、停顿、语气词等个性化表达
- 无论旁白、客服、剧情配音、教育讲解，均可保持音色统一与情感一致性
- 可与 GLM-TTS 联动，通过音色 ID 进行批量生产
