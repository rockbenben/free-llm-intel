jina-reranker-v3：用于文档重排的 last but not late 交互

jina-reranker-v3 是一个 0.6B 参数的多语言文档重排器，引入了新颖的 last but not late 交互。与 ColBERT 等先单独编码再进行多向量匹配的 late interaction 模型不同，我们的方法在同一上下文窗口内对查询和文档进行因果自注意力，从而在从每个文档的最后一个 token 提取上下文 embedding 之前，实现丰富的跨文档交互。这一紧凑架构以 61.94 nDCG@10 达到最先进的 BEIR 性能，同时体积比生成式 listwise 重排器小十倍。

## [*tag*](https://jina.ai/news/jina-reranker-v3-0-6b-listwise-reranker-for-sota-multilingual-retrieval/#model-architecture)模型架构

[jina-reranker-v3](https://jina.ai/?sui&model=jina-reranker-v3) 基于 [Qwen3-0.6B](https://huggingface.co/Qwen/Qwen3-0.6B) 基座构建，这是一个采用因果自注意力的 decoder-only transformer 模型。该模型同时处理多个文档和查询，在指定的 token 位置提取上下文 embedding，以进行高效的相似度计算。

[jina-reranker-v3](https://jina.ai/?sui&model=jina-reranker-v3) 的架构，展示了带有用于 embedding 提取的特殊 token 位置的 transformer 基座。该模型在一个上下文窗口中处理多个文档和查询，在指定 token 位置提取上下文 embedding 以进行相似度计算。

| 参数 | 值 |
| --- | --- |
| 总参数 | 0.6B |
| 非 embedding 参数 | 0.44B |
| 隐藏层大小 | 1,024 |
| 层数 | 28 |
| 注意力头（Q/KV） | 16/8（GQA） |
| 上下文长度 | 131,072 |
| MLP 投影器 | 1024→512→256 |
| 最终 embedding 大小 | 256 |

给定一个查询和一组候选文档，[jina-reranker-v3](https://jina.ai/?sui&model=jina-reranker-v3) 用一个专门的 prompt 模板处理重排任务，使其能在单次前向传播中实现跨文档交互。输入构造遵循特定格式：

```
<|im_start|>system
You are a search relevance expert who can determine
a ranking of passages based on their relevance to the query.
<|im_end|>

<|im_start|>user
I will provide you with k passages, each indicated by a numerical identifier.
Rank the passages based on their relevance to query: [QUERY]

<passage id="1">
[DOCUMENT_1]<|doc_emb|>
</passage>
<passage id="2">
[DOCUMENT_2]<|doc_emb|>
</passage>
...
<passage id="k">
[DOCUMENT_k]<|doc_emb|>
</passage>

<query>
[QUERY]<|query_emb|>
</query>
<|im_end|>

<|im_start|>assistant
<think></think>
```

每个文档都被包裹在带顺序 ID 的 passage 标签中，从而在共享上下文窗口内形成清晰的文档边界。该模型在其 131K token 的上下文容量内最多同时处理 64 个文档。对于更大的文档集合，则分批处理，同时在各批之间保持查询一致。

查询在输入结构中出现**两次**——一次在开头用于任务指令，一次在结尾用于最终的注意力处理。这种双重放置使最终的查询位置能通过因果注意力关注所有前面的文档。两个关键的特殊 token 标记 embedding 提取位置：`<|doc_emb|>` token 放在每个文档之后，标记文档 embedding 提取点；而 `<|query_emb|>` token 放在最终查询之后，标记查询 embedding 提取点。这些 embedding 通过共享的因果自注意力机制，同时捕获局部文档语义和全局跨文档上下文。

**我们把这种查询-文档交互称为 "last but not late"。** 它是 "last"，因为 `<|doc_emb|>` 被放在每个文档的最后一个 token。它是 "not late"，因为与 [ColBERT 等 late interaction 模型](https://jina.ai/news/what-is-colbert-and-late-interaction-and-why-they-matter-in-search/) 先单独编码文档再进行多向量匹配不同，我们在前向传播期间于同一上下文窗口内实现查询-文档和文档-文档交互。

最后，一个带 ReLU 激活的两层 MLP 投影器把 1024 维隐藏状态映射到 256 维的排序空间。相关性打分通过投影后的查询 embedding 与每个投影后的文档 embedding 之间的余弦相似度计算。这为输入集中的每个文档产出一个相关性分数。

### [*tag*](https://jina.ai/news/jina-reranker-v3-0-6b-listwise-reranker-for-sota-multilingual-retrieval/#via-transformers)通过 `transformers`

```
from transformers import AutoModel

model = AutoModel.from_pretrained(
    'jinaai/jina-reranker-v3',
    dtype="auto",
    trust_remote_code=True,
)
model.eval()
```

现在你可以用模型的 `rerank` 函数为一个查询和一组文档计算相关性分数：

```
query = "What are the health benefits of green tea?"
documents = [
    "Green tea contains antioxidants called catechins that may help reduce inflammation and protect cells from damage.",
    "El precio del café ha aumentado un 20% este año debido a problemas en la cadena de suministro.",
    "Studies show that drinking green tea regularly can improve brain function and boost metabolism.",
    "Basketball is one of the most popular sports in the United States.",
    "绿茶富含儿茶素等抗氧化剂，可以降低心脏病风险，还有助于控制体重。",
    "Le thé vert est riche en antioxydants et peut améliorer la fonction cérébrale.",
]

# Rerank documents
results = model.rerank(query, documents)

# Results are sorted by relevance score (highest first)
for result in results:
    print(f"Score: {result['relevance_score']:.4f}")
    print(f"Document: {result['document'][:100]}...")
    print()
```

## [*tag*](https://jina.ai/news/jina-reranker-v3-0-6b-listwise-reranker-for-sota-multilingual-retrieval/#conclusion)结论

[jina-reranker-v3](https://jina.ai/?sui&model=jina-reranker-v3) 是一个新的 0.6B 参数多语言 listwise 重排器，引入 *last but not late* 交互以实现高效的文档重排。文档在编码期间可以相互关注，建立起为最终排序提供信息的交互。

主要顾虑之一是这种交互对输入排列是否具有鲁棒性——也就是说，如果我们打乱输入顺序，排名是否会保持不变？我们用一个查询对 110 个候选文档进行随机排列来测试这一点，并在下图中绘制了每个排名位置的方差。

排名稳定性图可视化了文档在 1,000 次随机输入排列中出现在特定排名位置的一致性。y 轴以百分比表示稳定性方差，其中 0% 表示完全稳定（同一文档总是出现在该排名），100% 表示最大方差（几乎所有文档都在各次排列中出现过该排名）。x 轴显示从 1 到 110 的排名位置。

关键发现是排名靠前的位置表现出极好的稳定性。第 1-10 名方差极小，最相关的文档无论输入顺序如何都持续排在顶部。这对 nDCG@10 及类似的 top-k 指标至关重要。不相关的文档持续留在底部，在相关与不相关内容之间形成清晰的分隔。

中间部分表现出明显的位置互换，这是意料之中且可接受的。该模型使用因果自注意力，并根据序列中出现在文档之前的内容编码不同的上下文信息。

在实践中，当我们只关心最靠前的结果时，这种行为是完全可以接受的。我们的评测表明 [jina-reranker-v3](https://jina.ai/?sui&model=jina-reranker-v3) 超越了我们更早的几代，包括 [jina-reranker-v2-base-multilingual](https://jina.ai/?sui&model=jina-reranker-v2-base-multilingual) 和 [jina-colbert-v2](https://jina.ai/?sui&model=jina-colbert-v2)，以及大得多的替代模型如 `Qwen3-Reranker-4B` 和 [jina-reranker-m0](https://jina.ai/?sui&model=jina-reranker-m0)，进一步印证了这一点。
