# AI 竞赛为什么转向速度

James Wang

2025 年的大部分时间，AI 竞赛比的是模型智能。过去三个月，赛道变了。模型智能依然关键，但在每一家主要前沿实验室，推理速度已成为新的、迫在眉睫的焦点：

- **Google** 发布 Gemini 3 Flash。为 agentic 编码而生，比 Gemini 3 Pro 快 3 倍。
- **Anthropic** 推出了快 2.5 倍版本的 Claude Opus 4.6，面向对速度要求苛刻的编码用例。
- **OpenAI** 宣布与 Cerebras 合作发布 GPT-5.3-Codex-Spark，运行速度超过 1,200 tokens/秒，成为 OpenAI 迄今最快的编码模型。

推理速度为什么突然变得如此重要？因为模型生成 token 的速率，如今直接影响各大实验室迭代模型的速率，也影响整个经济体构建软件的速率。

2 月，OpenAI 和 Anthropic 都披露：它们正在用自己的编码模型来打造自己 AI 模型的下一个版本。这是一次不同寻常的披露。在 OpenAI 的博客《[Harness Engineering](https://openai.com/index/harness-engineering/)》中，他们写道：

GPT-5.3-Codex 是我们第一个在"创造自己"过程中起到关键作用的模型。Codex 团队用它的早期版本调试它自己的训练、管理它自己的部署、诊断测试结果与评估——Codex 能在多大程度上加速自己的开发，让我们团队震撼。

文章描述了一个三人工程师团队用 Codex 在五个月内产出百万行生产代码——用大约手工十分之一的时间造出产品。人类没有手写过一行代码。他们给 agent 下 prompt、审查它的 pull request、清除障碍。用 OpenAI 的话说："人类掌舵，agent 执行。"

Anthropic 的故事类似。在发布快 2.5 倍版本的 Claude Opus 4.6 时，他们承认这正是他们内部早已在使用的速度。Anthropic 的 Claude Code 负责人 Boris Cherny 公开表示，他的代码已 100% 由 AI 编写两个多月，Claude Code 自身代码库约 90% 由 Claude Code 自己完成。简言之，Anthropic 一直在用自家编码工具打造下一代产品——而在不久前，他们把最快的模型版本留给了自己。

其影响既深远又清晰——软件开发的那个"递归时刻"已经到来；而在推理上，你的 token 输出越快，就能越快交付下一个产品。每家实验室都在竞相构建更强的模型。过去，谁拥有最大的训练集群谁先到终点。如今，其他条件相同，谁在模型开发中使用最快的推理谁先冲线。推理速度已经位于通往下一个前沿模型——进而通往 AGI——的关键路径上。

如果快速推理真的如此重要，它就应该非常值钱。验证方法之一，是看 Anthropic 如何按智能与速度为其模型定价。

**Claude API Token 定价**

Anthropic 的旗舰模型 Opus 4.6 相对其中档模型 Sonnet 4.6 有 66% 的溢价。而运行快 2.5 倍的 Opus 4.6 Fast，定价是基础模型的 6 倍。Anthropic 的定价印证了这个判断：速度如今重要到值得自成一个价格品类；就价值而言，它甚至可能比"模型智能升一档"更值钱。

### **快速推理加速"到达收入的时间"**

推理速度不只是对 OpenAI 和 Anthropic 具有战略意义，它对任何构建并交付软件产品的公司都是战略性的。

设想两家公司——A 公司与 B 公司——都在构建一款新的 AI 驱动 CRM。A 公司使用一款领先的前沿模型，六周完成开发。

B 公司有同样的点子、同等的人才和资金。但它用的是跑快速推理的前沿模型，仅 3 周就交付了第一版。随后的几周里，B 公司基于用户反馈快速迭代。产品的第 3 版走红，到第 8 周 ARR 达到 1000 万美元。而此时 A 公司还在从第一次发布中学习。在这个例子里，快速推理直接加速了产品迭代和收入到账。

上面的例子听上去或许有点奇幻，但它已经在真实经济体中发生。Stripe 2025 年[年度信函](https://stripe.com/annual-updates/2025)披露：上线 3 个月内就达到 1,000 万美元 ARR 的公司数量相比 2024 年翻了一倍。这几乎可以肯定是由 agentic coding 日益普及驱动的。我们预计 2026 年会出现更剧烈的加速——开发者将用上比 2025 年快一个数量级的更强编码 agent。

上述模式不仅适用于初创公司，也适用于大企业。2026 年 1 月是各阶段、各规模 SaaS 公司的一次[清算](https://www.reuters.com/business/us-software-stocks-stabilize-after-bruising-selloff-ai-disruption-fears-2026-02-05/)。团队都在争先重构自己的产品栈与营收模式。拥有最快、最强编码 agent 的公司，更可能在后 agent 经济中站稳脚跟。

速度一直是数字经济的驱动力。1990 年代，公司买下所能负担的最快计算机；2000 年代，竞相抢占最快的互联网连接。在 AI 时代，高速推理就是关键基础设施。Cerebras 从第一天起就专注于速度。看看这个行业的轨迹——模型构建模型、编码 agent 取代手工开发、进入市场的速度成为 token 吞吐量的函数——很明确：速度只会愈发重要。
