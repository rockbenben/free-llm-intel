# 合作伙伴聚焦：Armis + Cerebras 让团队更快构建并保护软件

Eric Gardner

在 Cerebras，我们始终相信速度改变可能性。在软件开发中，这不只意味着更快的生成或更快的推理，而是更快的迭代、更快的验证和更快的行动。这正是我们乐于聚焦 Armis 的原因——其 Armis Centrix™ for Application Security 在整个软件生命周期内统一应用安全。有了 Armis 和 Cerebras，团队可以更快地识别并修复漏洞，同时减少噪声、聚焦于最重要的风险。

时机很关键。Armis 于 2026 年 2 月 10 日发布了 Armis Centrix™ for Application Security，将其定位为覆盖软件开发全生命周期的 AI 驱动检测、语境化与修复平台。在发布材料中，Armis 指出：AI 辅助编码与持续开发流水线正在暴露碎片化 AppSec 单点工具的极限——噪声太多、语境太少、安全与开发之间摩擦太大。

这个问题只会越来越大。Armis 表示，AI 生成的代码正在提升漏洞被引入的速度和规模，而传统工具往往难以捕捉新奇变种，也难以把发现与生产环境中真正可被利用的东西联系起来。Armis Centrix™ 的设计是对代码、依赖、容器镜像和配置文件进行全面扫描，同时理解更宏观的 CI/CD 流水线与生产侧管控。目标不只是发现更多问题，而是更早浮出*对的*问题，并让它们更容易被修复。

这正是 Cerebras 天然契合之处。Cerebras 为生而超快的 AI 与即时的开发者工作流而建。在我们的平台上，我们谈即时答案、"思维速度的代码"、帮助团队保持心流的低延迟 AI 体验。当 AI 能近乎实时地响应，价值就不仅是开发者生产力，而是缩短"检测—理解—修复"整个循环的能力。让这段 Armis 合作如此动人的，正是同一条原则。

这在实践中解锁了什么？

- **保护现代代码。**团队可以在风险变成生产暴露之前，跨代码、依赖和容器抓住它。
- **更快的修复。**发现可以被路由给对的开发者，附上更清晰的指引，帮助团队更早从检测走向行动。
- **更少噪声。**Armis 称其平台可将误报减少最高 70%，让"真正可达且重要的东西"更容易排序。
- **以开发速度运转的安全。**通过集成进 Git 和 CI/CD 工作流，安全发生在软件被构建的近旁，而不是事后。

我们同样欣赏 Armis 带来了可度量的验证。公司表示，Armis Centrix™ for Application Security 在 Public CASTLE Benchmark C@250——一项检测并在部署前拦截代码问题的第三方基准——中取得了最佳性能。在一个充斥着静态、碎片化工具的品类里，这样的信号意义重大。

更广义地看，这次合作反映了我们在整个行业观察到的转变：AI 辅助开发正在压缩"从想法到部署"的时间，所以安全必须以同样的紧迫感运转。光有更快的模型不够。团队需要的是语境的、自动化的、嵌入开发工作流的应用安全。Armis 正在构建这个安全层。Cerebras 天生支撑现代 AI 工作流所要求的速度。两者在一起，对想快速构建而不失控风险的团队，是一个强大的组合。

软件的未来不只是更快的代码生成，而是更快、更安全的迭代。我们乐于聚焦 Armis，因为这正是让 AI 原生开发对企业更切实的那类合作：更少等待、更少噪声、更快修复，从 commit 到生产的更多信心。更快地构建并保护软件——Armis + Cerebras。
