# 高级代码，晶圆级性能

[Michael James](https://www.cerebras.ai/author/michael-james)

## 推出 Tungsten 与 Aviary

*Michael James，Cerebras Systems 联合创始人兼先进技术首席架构师*

上个月，我们的一位研究员在一片 Cerebras 晶圆 98% 的范围上跑了一场等离子体物理模拟。它的每一行代码都是一个 coding agent 写的。

今天我们发布让这一切成为可能的工具。Tungsten 是一门语言兼编译器，让你在高层次上为 Cerebras Wafer-Scale Engine 编程，同时不牺牲性能。Aviary 则是用它编写的一套高性能应用和教程作品集。

现代科学很大一部分建立在模拟之上：金属在反应堆内如何老化、海啸如何横越海洋、等离子体如何在电场中运动。这些模拟以微小的时间步向前推进，而往超级计算机里加更多芯片并不会让这些步子变快。晶圆可以。在某些问题上，它比最大的超级计算机快数百倍，把一年的计算量压缩成两三天。

这种速度改变了 AI 在科学中能做的事。快到足以与 AI 模型肩并肩运行的模拟会成为它的世界模型，于是 AI 可以对照真实物理检验成千上万种设计。而 AI agent 现在可以自己写这些模拟。Tungsten 把这一切交到并非硬件专家的科学家手中。

### 硬件能给你什么

Wafer-Scale Engine 是一台拥有 90 万个核心的数据流机器，核心多到它们可以像一个连续体那样工作：计算铺在本地内存之上，由晶圆上的 fabric 相连。数据到达某个核心，就会触发消费它的工作。访问模式寄存器负责遍历多维数组和 fabric 流，因此地址运算不消耗指令。

一条指令可以把整个循环当作它的操作数。核心之间通过在 fabric 上互发消息来互相调用函数，基于事件的控制流取代了轮询和分支。

硬件承担了循环和控制开销，因此即便内层循环很短，核心也能接近峰值运行。把一个问题稀薄地摊到整片晶圆上，它会持续变快，越过其他机器停滞或变慢的那个点。然而传统编译器无法对这些机制进行推理。为它编程一直是困难的那部分。

### 抽象鸿沟

先前的编译器把这些特性暴露为 intrinsic。标量代码没问题。任何触及向量、流或事件硬件的代码都必须显式调用它们。实践中，每个非标量程序都写得接近汇编。

你手工配置 descriptor，手工把任务接上事件，手工为 fabric 布线。我们自己就这样写过很多代码。它很快，但也需要深厚的专业知识，而且结果难以阅读、修改或复用。

### 一台为机器建模的编译器

Tungsten 弥合了这道鸿沟。它的记法在数学上自然，并且贴合这台机器的特性，因此代码读起来接近算法的教科书形式。编译器携带完整的架构模型，把代码映射到访问模式寄存器、事件驱动任务、fabric 调用和承载循环的指令上。

每一行都是对整个 block 的循环，而且每一行都编译成一条向量指令。`<+-` 会像 `+=` 一样向目标累加。没有 descriptor 设置，也没有任务接线，只有 stencil 本身。

几十年前，编译器就不再要求程序员分配 CPU 寄存器了。由编译器决定什么东西驻留在寄存器里，寄存器用尽时就溢出到内存。Tungsten 对晶圆上更复杂的资源做同样的事：访问模式、循环定义、fabric socket 和微线程。成本模型和优化 pass 在通观整个程序的情况下分配它们，并在程序运行时换入换出。因为这些决定由编译器掌管，事后重构代码只是一次编辑，而不是重写。

### Aviary

Aviary 的项目被画成由钨丝构成的鸟，聚集在铜晶圆的裸片网格上。

![](https://cdn.sanity.io/images/e4qjo92p/production/44929d40ab24d7b79c88e2c04efc305fdb18f932-1254x1254.png)

![](https://cdn.sanity.io/images/e4qjo92p/production/46fa841520f2e020e15cd030ede05c4d8b3b919f-1275x1233.png)

Aviary 收录了若干在所计算内容上属于世界最快的代码：

- SNAP 是核辐射输运代码的标准代理程序，在单台 CS-4 上跑到 1.6 PFLOP/s，超过了 El Capitan 超级计算机上的 10,800 块 GPU。
- HPCG 是用于给超级计算机排名的基准测试，考察真实世界的稀疏工作负载，在单套系统上达到 1.04 PFLOP/s。
- 我们的晶圆级分子动力学比 Frontier 快 748 倍，Frontier 是世界上最大的超级计算机之一 [3]。

一款设计优化器即将加入 Aviary。它把 AI 模型与充当其世界模型的物理模拟耦合起来，两者都运行在晶圆上。如果你在 SC26 现场，欢迎到我们的展台看看。

这些应用从紧凑的 stencil 代码一直到完整的科学应用。更小的教程示例会一步步教你这门语言。

来自 Aviary 教程代码的 Gray-Scott 反应-扩散图案，约 50 行 Tungsten。

这些应用中有许多源自我们与 Sandia、Lawrence Livermore 和 Los Alamos 国家实验室在 NNSA 先进内存技术计划下的合作 [5, 6]。分子动力学应用建立在那次合作中我们 2024 年 Gordon Bell Prize 入围工作的基础之上。它们不是同一份代码，但那个成果已经使用了一版早期的 Tungsten [2]。

Gresho 涡旋——高阶流体动力学的经典测试——在随材料一起移动的网格上。

### 为 agentic coding 而构建

particle-in-cell 代码展示了在 Tungsten 上进行 agentic coding 是什么样子。粒子在场的作用下运动，并从核心迁移到核心。一个隐式求解器根据粒子的位置和速度，在分解后的网格上计算场。

一位研究员。一个 coding agent。大约两周的聊天窗口时间。agent 依据已发表的算法构建了代码，将它的参考实现与开源代码 XOOPIC 做了验证，并运行了一个参照 EMPIRE 等离子体代码建模的问题。在这个过程中，它写下了测试、图表和文档，还找出并修掉了自己的 bug。完整运行以每秒 7,200 个时间步推进了 6,000 万个粒子，在单套系统上达到每秒 4,300 亿次粒子更新。（对不是等离子体物理学家的人来说，这非常快。）

Tungsten 的参考实现已经完整到足以支撑这种工作方式，所以你几乎不用任何启动成本就能试用 Tungsten。不过也请自己学一学。总得有人把 agent 们留在正轨上。

### 扩展触达范围

我们的使命是扩展 AI 与科学的触达范围。当一份高性能代码不再需要专家来编写，就有更多问题值得尝试。

同一份 Tungsten 代码可以运行在一片晶圆上，也可以跨越一个集群运行。我们的全球海啸模拟运行在一套 AI 部署的 64 片晶圆上 [1]，而那些部署可扩展到 2,048 套系统 [4]。

我们很自豪地发布 Tungsten 和 Aviary，希望它们对你和我们一样有用。一切都在 [labs.cerebras.ai](https://labs.cerebras.ai/) 上线。
