# 全球最快的 GLM-4.6——现已登陆 Cerebras

James Wang

今天，Cerebras 上线 GLM-4.6——我们在 Cerebras Inference API 上迄今最强的模型。GLM-4.6 在推理、工具使用和编码方面全面升级，把卓越的智能与 Cerebras 上无人能敌的 1,000 tokens/秒 速度结合在一起。对许多任务，GLM-4.6 的输出可与 Sonnet 4.5 媲美，而在 Cerebras 上快 17 倍、便宜 25%。GLM-4.6 今天即可用：按量付费的开发者档位起步价 $10，或 Cerebras Code 套餐起步价每月 $50。

### GLM-4.6

GLM-4.6 被广泛认为是全球顶尖的开放编码模型之一。GLM-4.5 是 [Berkeley Function Calling Leaderboard](https://gorilla.cs.berkeley.edu/leaderboard.html)（BFCL）上工具调用排名第一的模型，领先于 Opus 4.1。基于数千张用户投票，GLM-4.6 在 LM Arena 的网页开发[排行榜](https://lmarena.ai/leaderboard)上与 Sonnet 4.5 表现相当。

在真实使用中，开发者总结出四大核心优势：

- 工具调用的可靠性——精准执行多步工具链，干净地传递结构化参数，跨调用维持状态，避免早期开放模型常见的循环或 JSON 格式错误。
- 网页开发的流畅度——生成全栈、可直接运行的应用——从 React + Tailwind 前端到 Node 和 Flask 后端——文件结构整洁、几乎不需要语法修补，跨文件的上下文连贯性强。
- Token 效率——在 zAI 的 CC-Bench 套件中，GLM-4.6 比 Kimi K2-0905 少用 26% 的 token，比 DeepSeek V3.1 Terminus 少用 31%，是效率最高的开放模型之一。
- 代码编辑准确率——根据头部 agentic IDE Cline 的实时遥测数据，GLM-4.6 在编辑既有代码上达到 94.5% 准确率——逼近 Sonnet 4.5 的 96.2%。

简而言之，GLM-4.6 是一次里程碑式的开放权重发布，收窄了领先开放与闭源编码模型在推理、工具使用和编码上的差距。
