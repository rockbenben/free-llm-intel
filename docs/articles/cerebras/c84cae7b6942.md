# Cerebras 携 Kimi K2.6 将万亿参数推理带入企业

James Wang

Cerebras 现已在企业客户试点中运行 Kimi K2.6——这款领先的万亿参数开放权重模型。作为公认的快速推理领导者，Cerebras 已在 GLM-4.7、GPT-OSS-120B、Qwen 3 等众多开放权重模型上树立基准，并为 OpenAI、Cognition 等客户的 agentic 编码模型带来显著提速。K2.6 是客户请求最多的模型之一，我们很高兴把它带给客户。这是我们服务的首个一万亿参数开放权重模型，按 Artificial Analysis 的测量，性能逼近 1,000 tokens/秒。结果是：agentic 编码从"等待-审查"循环转变为实时开发，大幅提升开发者生产力。

### **最快的 1 万亿参数开放模型**

Artificial Analysis 测得 Cerebras 运行 K2.6 的输出速度为 981 tokens/秒——比第二快的 GPU 云快 6.7 倍，比推理服务商的中位水平快 23 倍。

快速推理显著加快端到端响应时间，让 agentic 编码接近即时。对于一个 10,000 token 输入的请求——包含 prompt 处理、推理和生成 500 个输出 token——Cerebras 在 5.6 秒内交付了完整响应，而官方 Kimi 端点需要 163.7 秒。最终答案的获取时间提升了 29 倍。

> "Cerebras 在 Kimi K2.6 上达到了 981 tokens/秒——这是我们在万亿参数模型上测过的最快表现。这一结果与 Cerebras 在其硬件所服务的所有模型上保持领先输出速度的记录一脉相承。"Artificial Analysis 联合创始人 George Cameron 表示。

### **Kimi K2.6——前沿智能，开放权重**

K2.6 被广泛认为是编码与 agentic 工作领域最强的开放权重模型。它以 58.6 分领跑 SWE-Bench Pro，超过 Claude Opus 4.6、追平 GPT-5.4，同时在 Humanity's Last Exam 和 DeepSearchQA 等 agentic 基准上领先全场。开发者已把它作为闭源前沿模型的开放替代——尤其在编码领域，它对简洁前端设计的品味使其成为全栈应用生成的心头好。2.6 版本把这种能力从前端延伸到全栈工作流，涵盖认证、数据库操作和长程 agent 执行。

### **在 Cerebras 上服务万亿参数模型**

Cerebras Wafer-Scale Engine 生来就是为了规模。一组 CS-3 系统可以配置为支持数万亿参数模型的训练与推理，我们投入了大量工程精力优化整个技术栈，以高效服务大模型。

Cerebras 以模型原始的 4-bit 权重存储 Kimi K2.6，同时以 16-bit 浮点精度进行计算，以获得最佳准确率。权重分布在多片晶圆上，激活值在其间流动。层与层之间的 all-to-all 通信完全使用片上网络结构（network fabric）运行，其带宽超过 NVL72 上 NVLink 的 200 倍以上。结合我们的定制 kernel 和投机解码，我们能让万亿参数 MoE 模型以接近 1,000 tokens/秒 的速度对外服务，创下一项世界纪录。

### **这解锁了什么：高速 Agentic 编码**

Agentic 编码已成为大语言模型价值最高的用例，也是对推理速度最敏感的工作负载。在接近一千 tokens/秒 的速度下，Kimi 生成代码比 Claude Opus 等流行模型快一个数量级。开发者能够快速迭代、更快抵达最终方案，并把注意力集中在单一任务上，而不是启动多个 agent 在它们之间来回切换。前端迭代几乎感受不到延迟，而代码重构和高难度 bug 修复所花的时间只是过去的一小部分。
