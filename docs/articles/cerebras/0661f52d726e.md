# Cerebras 如何以最高 750 tokens/秒 服务 GPT-5.6 Sol

Sarah Chieng

Halley Chang

过去两年，AI 模型的能力大幅跃升。它们能进行更长时间的推理、写出可上生产的代码、操作计算机、使用浏览器，并在科学、金融、数学、物理和工程领域产出专业级成果。

但体验中有一样东西始终没变：等待。

OpenAI 正在预览 GPT-5.6 Sol 的全新 Ultrafast 模式，运行在 Cerebras 上，输出速度最高 750 tokens/秒。这个速度改变了我们使用 AI 的方式：我们现在可以保持心流，与 agent 实时协作。

最重要的细节，恰恰是我们没有改变的东西。

Cerebras 上的 GPT-5.6 Sol 不是被蒸馏过、也不是被量化到低精度的小模型。它使用与标准 OpenAI 端点上的 GPT-5.6 Sol 完全相同的模型架构、权重、精度、上下文配置和推理设置。人们喜爱 GPT-5.6-Sol 的 browser-use、computer-use 和编码能力全部保留。

唯一的差别是模型跑在什么硬件上：我们不用 GPU，而是在 Cerebras WSE-3 上服务 Sol-Ultrafast——这颗全球最大的 AI 芯片，也是最快 AI 产品的引擎（[产品页 - Chip-Cerebras](https://www.cerebras.ai/chip)）。

有了 Cerebras，GPT-5.6-Sol 重新定义了速度与智能的帕累托前沿。

### 为什么前沿模型的推理通常很慢

在传统 GPU 上，计算核心与存放模型权重的高带宽内记分处不同的芯片。推理中的每一次计算，权重都必须一次又一次跨过这道边界抵达计算单元。随着模型变大，制约推理的越来越不是算术，而是系统搬运这些权重的速度。

这就是 GPU 的内存墙。

增加 GPU 可以提升吞吐量，但不会自动让单次响应更快。把模型切分到多块芯片上，意味着每一层都以一个同步步骤收尾；你每加一块芯片，这个同步就更贵，而它本要加速的计算反而被摊薄。存在一个交叉点——互联开销开始占上风，更多硬件反而让模型更慢。简单说：计算机把太多时间花在搬数据上。

Cerebras 的生来使命就是解决这个内存搬运瓶颈：造一颗足够大的处理器，把模型的活跃权重直接放在使用它们的计算单元旁边。

### Cerebras 如何加速模型——从一整片硅晶圆说起

传统芯片是从硅晶圆上切割下来的。Cerebras 直接把晶圆本身用作芯片。

在传统 GPU 上，模型权重住在片外 HBM 里，每个 token 都要跨过边界进入计算单元。WSE-3 则把 44 GB SRAM 分布到整片晶圆上，紧挨着它的 900,000 个核心。这些内存合计提供 21 PB/s 的聚合带宽，让每个核心都能快速取到自己需要的权重。

GPT-5.6 Sol 对单台加速器来说太大了，所以 Cerebras 按层边界把它切分到多台 CS-3 系统上。每片晶圆把分配给自己的层保存在本地 SRAM 中。对每个 token，激活值从一片晶圆流向下一片，直到最后一级输出结果。

这取代了传统 GPU 集群所需的大量细粒度分片与同步，换成一条更简单的路径：权重守在计算旁，只有激活值在各级之间移动。然后流水线重复这个过程——每秒最多 750 次。

### 最高 750 tokens/秒 对你意味着什么

多数人把工作流想象成输入一些东西、得到一些输出。

但底层其实不然：agent 会走很多步。它读取任务、对结果推理、写一些代码、测试自己的工作、决定下一步，循环往复直到可以交还控制权。

一个复杂任务可能涉及多次模型请求和工具调用，延迟会在整个工作流中累积。

这意味着单 token 延迟不是只付一次的开销，而是每一步都在付的成本，再乘以完成任务所需的步数——步数累积得非常快。

这个乘数是可测量的，而且比你想的大。在质量对齐的 GDP-Val 任务样本上（包括法律、金融和工程交付物），GPT-5.6 Sol Ultrafast 完成同样任务比标准端点上的同一模型快 5.6 倍。

在推理主导工作流的 Humanity's Last Exam 同题对比中，Sol Ultrafast 成功完成工作的速度快 [6.9 倍](https://www.cerebras.ai/blog/accelerating-gpt-5-6-sol-ultrafast-with-openai)。有了这种速度，一小时的任务不到九分钟就能完成。

### 给开发者

没有哪里比编码更能体现 Cerebras 的速度。开发者把 agent 支出去工作几小时甚至几天司空见惯。无论你跑循环还是长时 agent，Cerebras 上的 Sol 都是无双的体验。前沿级智能以最炽烈的速度交付，让你构建、测试、迭代想法的速度前所未有。

### 给知识工作者

知识工作有更多人在环。但它仍是环。工作流里有相当一部分是阅读与决策、评估输出、制作交付物——全程都有一个人在干等。最高 750 tokens/秒 带来显著更快的迭代，让你在更少的时间里完成更多工作，无论是起草邮件、处理报税，还是剪辑视频。

### Computer Use 与自动化

agent 最受欢迎的新用例之一，是让模型在你许可的前提下、在你工作时于后台使用你的机器或浏览器。这让你能构建强大的自动化——把你描述得清的任务直接委派给 agent，而不占用你正专注于更重要事务的机器。

更快的推理通过缩短"观察界面—决定做什么—执行下一步"之间的延迟，惠及 computer-use 工作负载。
