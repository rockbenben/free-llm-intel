# Cerebras 推出分离式推理

[Atharva Talpade](https://www.cerebras.ai/author/atharva-talpade)

*我们将 Cerebras 晶圆级引擎与 GPU 配合部署，以规模化提供闪电般快速的 token*

世界渴望超快 token。2026 年，Cerebras 在我们的推理云以及合作伙伴渠道上都看到了对快速推理的旺盛需求。为满足需求，我们开始开发分离式推理：由 GPU 处理提示处理（prefill），由 Cerebras 系统处理输出生成（decode）。

该方案现已投入生产，在保持 Cerebras 同等超快速度的同时，每兆瓦可多交付五倍的 token。

我们现在可以通过 Cerebras Inference Cloud 提供更多超快 token，以满足市场需求。基础设施合作伙伴也可以利用 Cerebras 分离式方案，在自己的数据中心内获得更多超快 token。

连同我们近期发布的 CS-4、大幅扩张的制造能力，以及计划中的 700MW 数据中心容量，分离式推理将助力 Cerebras 及合作伙伴在 2027 年及以后提供更多超快 token。

### 对更多快速推理容量的需求

Muse、Copilot 和 Codex 等智能体应用正快速扩张，需要高度交互式的推理来维持用户参与度。为在电力受限的环境中满足这些应用日益增长的需求，我们的行业必须以让这些应用真正有用的响应速度，提供显著更高的每兆瓦推理容量。

来源：Goldman Sachs Research，“AI Agents Forecast to Boost Tech Cash Flow as Usage Soars”，2026 年 5 月 20 日；Goldman Sachs 数据中心容量估算，据 Investing.com 2026 年 11 月 6 日报道。

正因如此，Cerebras 投资于[分离式架构](https://www.cerebras.ai/blog/disaggregated-inference-from-the-ground-up)。将用于提示处理的 prefill 加速器与用于响应生成的 Cerebras 系统配对，可在保持 Cerebras 超快生成速度的同时，提高每兆瓦的 token 吞吐量。对推理服务提供商而言，这意味着在相同电力预算下拥有更多服务客户的容量和更大的收入潜力。

### 为什么 Cerebras 在 decode 上具有优势

一次推理请求包含两个主要阶段。提示处理（称为 prefill）处理输入并生成中间模型状态。响应生成（称为 decode）利用该状态生成输出 token。拆分推理负载的方式有很多，包括 draft–target、attention–FFN 等，但当目标是高度交互式推理时，将 prefill 与 decode 分离具有独特的优势。

Decode 是自回归的。这意味着模型一次生成一个 token，并将每个已生成的 token 作为输入来生成下一个。每一步都意味着再次从内存读取模型数据，因此内存带宽至关重要。在超快推理领域，以 SRAM 为中心的芯片具有优势，因为它们可以将数据保留在片上并更快地读取。Cerebras 将这一优势扩展到晶圆级，在单颗芯片上拥有数十 GB 的 SRAM 和每秒数十 PB 的内存带宽——是典型 GB300 GPU 的 350 倍 SRAM 容量和 5,400 倍内存带宽。这使 Cerebras 系统能够在芯片上直接容纳更多并发请求和模型层，使 CS-3、CS-4 和 CS-5 以极具吸引力的吞吐量实现超快速度。

### Cerebras 分离式推理的生产结果

将为超快 decode 优化的 Cerebras 系统与非常适合 prefill 计算需求的加速器（如 AMD Instinct GPU）配对，可以大规模交付大量超快推理。在 Cerebras Inference Cloud 的生产部署中，AMD Instinct GPU 处理提示，Cerebras CS-3 系统生成响应。将提示处理转移到 GPU 使 Cerebras 系统能够将服务容量专用于响应生成。在我们实测的生产部署中，这一组合实现了仅使用 CS-3 配置的 5 倍每兆瓦吞吐量，且 token 生成速度没有任何损失。

来源：2026 年 11 月 14 日通过 Cerebras Inference Cloud 共享的 GPT-OSS-120B endpoint，启用分离式推理前后的每兆瓦吞吐量，按聚合推理基线（1×）归一化。

我们计划到 2027 年底，在 Cerebras Inference Cloud 及合作伙伴部署中，将分离式推理广泛部署到数百兆瓦的规模。我们的目标是增加可供客户使用的超快推理容量。

### 面向基础设施合作伙伴的 Cerebras 分离式推理

Cerebras 分离式推理方案也为合作伙伴采用而构建。基础设施合作伙伴可以基于 Cerebras 提供的参考架构部署分离式推理集群，在统一网络中将所选 prefill 加速器与 Cerebras 系统同址部署。在软件集成方面，合作伙伴既可以集成 Cerebras 端到端分离式软件栈，也可以集成仅 decode 的 SDK。

端到端分离式软件栈最适合优先优化上市时间的合作伙伴。它包括：

- 一个分离式推理框架，用于在 prefill 池和 decode 池之间路由请求，并管理副本容量和健康状态。
- 一个 prefill 引擎，使用 vLLM 或 SGLang 等开源推理引擎处理提示。
- 一个 Cerebras decode 引擎，用于在 Cerebras 系统上生成响应。
- KV Portal 软件，一个通过 RDMA 在 prefill 和 decode 引擎之间传输中间模型状态（包括键值缓存）的接口。

仅 decode 的 SDK 最适合优先优化控制力的合作伙伴。使用仅 decode 的 SDK，合作伙伴可以将自己的推理框架和 prefill 引擎接入 Cerebras decode 引擎和 KV Portal 软件。此外，仅 decode 的 SDK 还提供开发辅助工具，例如模拟 Cerebras decode 副本，以及与开源分离式推理框架和 prefill 引擎的参考集成。

包括 Amazon Web Services、Fireworks AI、Gimlet Labs 和 General Compute 在内的早期访问合作伙伴，已可在其部署中使用 Cerebras 分离式推理方案。我们现在正将访问权限扩展至更多希望为其客户大规模提供超快推理的合作伙伴。
