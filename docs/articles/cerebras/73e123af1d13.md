# Cerebras 亮相 NeurIPS 2025：从预训练到推理的九篇论文

Cerebras 很高兴参加 NeurIPS 2025——而这是非凡的一年。我们去年 8 月发布了推理 API，在俄克拉荷马城启用了新数据中心，并见证了最新先进开放权重模型带来的 Cerebras Inference 需求爆发。

我们的研究团队也一直埋头苦干，今年他们将发表九篇论文，追问现代 AI 实践的基础性问题：训练过程中算力浪费在哪里？推理时推理型模型应如何分配 token？小模型何时能战胜大模型？这些工作横跨预训练到推理——在扩展定律、训练效率，以及测试时算力（test-time compute）的更智能调度方面都有新发现。

下面是每篇论文的概览、我们的发现，以及它们各自适合谁阅读。文中附有完整 arXiv 论文的链接。如果你也在现场，欢迎来我们的展位打卡，和晶圆拍张自拍；如果不在，我们也很乐意通过 X 或邮件听取你的想法。

### **The Conductor and the Engine: A Path Towards Co-Designed Reasoning**

CODA（Conductor-Driven Architecture）根据问题难度优化规划、执行、自我精炼和验证环节的测试时算力——在我们的基准测试中，它帮助 32B 模型击败了 235B+ 的竞争对手。其洞见在于：大多数测试时算力都被浪费了——外部编排和模型内部推理都在试图处理高层思考，重复劳动、疯狂烧 token。CODA 把角色干净地分离开来——Conductor 负责规划、反思和验证，Engine 负责执行——在不使用前沿规模模型的前提下解锁前沿级性能。

**关键发现**

- 32B 模型击败 235B+ 对手。搭载 CODA 的 Qwen3 32B 在 AIME 和 LiveCodeBench 上超过 Qwen3 235B、DeepSeek R1 和 OpenAI o3-mini。120B 的 GPT-OSS 模型在 LiveCodeBench 上达到 87.5%，力压 Grok4。
- 自适应路径选择很重要。有些数学题用直接推理解决得更好，有些则需要代码生成。CODA 为每道题动态选择正确的方法——在 15 道高难度 Numina Math 题目上，单一路径都到不了 100%，而自适应选择做到了。
- 验证是瓶颈。CODA 的最终准确率与理论上的 best-of-N 上限之间存在稳定差距，说明更好的验证器（或可经由 RL 训练得到）能释放大量额外收益。

**适合谁**

在内存受限硬件上部署推理系统的团队。研究测试时算力扩展的研究者。任何想要前沿级性能却不必用前沿级模型规模的人。

📄 [[论文链接](https://arxiv.org/abs/2509.19762)]

### Calibrated Reasoning: An Explanatory Verifier for Dynamic and Efficient Problem-Solving

在测试时扩展推理模型时，实践者会遇到一个令人沮丧的瓶颈：这些模型非常不擅长评估自己的解答。best-of-n 采样这类多路径探索策略依赖模型知道自己何时对、何时错，但当前的推理模型严重倾向于给所有答案打高分，不管对错。本文提出了一个通过强化学习（GRPO）训练的 Explanatory Verifier（解释型验证器），它不仅输出校准后的置信度分数，还附带自然语言说明解答为何正确或错误。核心洞见是比较成对的候选解答，而不是孤立地评估单个解答，这帮助验证器捕捉细微错误。

**关键发现**

- best-of-n 中节省 1-3 倍 token。在低 k 值时，验证器比 self-consistency 准确率更高；在高 k 值时以显著更少的 token 达到相同准确率——因为它只在当前两个选项都看起来错误时才生成额外候选。
- 能抓住投票法抓不到的失败模式。当两个候选解答以完全相同的方式出错时（这在难题上是常见失败模式——模型坍缩到狭窄、有偏的答案），多数投票会彻底失效，而验证器能可靠地检测出这些情况。
- 跨模型规模迁移。虽然只在 Qwen3-8B 的输出上训练，这个 8B 验证器却能有效评估更大的 Qwen3-32B 的生成结果，在 AIME 2025 上达到 0.77 的准确率，token 用量仅为 self-consistency 的 75%。

**适合谁**

大规模运行 best-of-n 或多数投票、在冗余生成上烧 token 的团队。研究推理奖励模型与验证器的研究者。任何注意到自家推理模型"自信地答错"并想要更好的过滤器的开发者。

📄 [[论文链接](https://arxiv.org/abs/2509.19681)]

### DREAM: Drafting with Refined Target Features and Entropy-Adaptive Cross-Attention Fusion for Multimodal Speculative Decoding

投机解码（speculative decoding）已成为加速纯文本 LLM 的常用技术，但把它应用到视觉-语言模型上更难——视觉和文本信息需要在整个生成过程中保持紧密融合。DREAM 是专为 VLM 构建的投机解码框架，结合了三方面创新：把目标模型中间特征注入草稿模型的交叉注意力机制、引导草稿训练的熵自适应特征选择，以及在不失关键信息的前提下降低延迟的视觉 token 压缩。

**关键发现**

- 相比标准解码最高提速 3.6 倍。在 LLaVA、Pixtral、SmolVLM 和 Gemma3 上，DREAM 在吞吐量和接受长度上都稳定超越此前的投机解码基线。
- 交叉注意力是关键架构选择。与拼接特征的纯文本方法不同，DREAM 的交叉注意力保留了结构化的视觉表征——消融实验中去掉它造成的性能下降最大。
- 视觉 token 可以大胆压缩。基于注意力重要性分数只保留 75% 的视觉 token，即可带来 7% 的提速，而准确率损失极小。

**适合谁**

在延迟敏感应用中部署视觉-语言模型的团队。研究高效多模态推理的研究者。任何大规模运行 VLM、希望削减解码时间又不牺牲输出质量的人。

📄 [[论文链接](https://arxiv.org/abs/2505.19201)]

### Don't be lazy: CompleteP enables compute-efficient deep transformers

在扩展 transformer 模型时，学习率等在较小模型上表现良好的超参数，随着深度增加往往需要昂贵的重新调参。本文研究了参数化方案（parameterizations）——即模型架构变化时如何调整超参数的规则——并识别出一种名为 CompleteP 的方案，它使超参数能在宽度和深度两个维度上可靠迁移。核心改动是把每个残差块的输出在加入残差流之前除以 1/L，从而在保持稳定的同时确保每一层都充分榨取其非线性容量。

**关键发现**

- 跨深度超参数迁移可行。在 2 层模型上调好的超参数可以直接迁移到 128 层模型而无须重新调参——但只有配合 CompleteP 才行。
- 相比 µP 节省 12-34% 计算。模型越深收益越大，此前不占优的"窄而深"架构变得可行。
- 理论解释了原因。先前的参数化会导致层随深度增加而事实上线性化（"懒惰学习"），浪费了深度带来的表征能力。CompleteP 是确保完整特征学习的唯一参数化。

**适合谁**

训练大型 transformer 的 ML 工程师。研究神经扩展定律的研究者。硬件条件偏好窄深架构的团队。

📄 [[论文链接](https://arxiv.org/abs/2505.01618)]

### Power Lines: Scaling Laws for Weight Decay and Batch Size in LLM Pre-training

weight decay 和 batch size 等超参数在小规模下有效，但随着模型规模、数据集规模和批大小变化需要昂贵的重新调参。本文研究了这些超参数的扩展定律，识别出精确的幂律关系，使得在大规模训练开始前就能准确预测最优设置。

核心洞见是用作者所说的"AdamW 时间尺度"（AdamW timescale）来建模训练——一个捕捉权重更新如何在训练过程中被积分的比值，把批大小、学习率、weight decay 和数据集规模合并为单一量。与其在批大小变化时调整学习率（会撞上稳定性极限），不如调节 weight decay，从而在更宽的范围内维持最优时间尺度。

**关键发现**

- 最优时间尺度遵循关于"每参数 token 数"的幂律。当相对模型规模训练更多数据时，最优时间尺度可预测地下降。这使你能针对模型规模、数据集规模和批大小的任意组合，准确预测最优 weight decay。
- 最优批大小和临界批大小随数据而非算力扩展。使损失最小的批大小和临界批大小（超过后收益急剧递减）都遵循关于数据集规模的幂律，这与先前工作"它们随 FLOPs 或损失扩展"的结论相矛盾。这意味着过训练（overtrained）模型可以高效地使用大得多的批大小。
- 在时间受限的训练中，过训练模型是帕累托最优的。当在训练时间与算力成本之间权衡时，"小模型+更多数据"占优——它们同时受益于更高的临界批大小和更大的数据并行度。

**适合谁**

为大规模预训练设置超参数的 ML 工程师。在模型训练中做算力/时间权衡的团队。研究神经扩展定律与最优训练配置的研究者。

📄 [[论文链接](https://arxiv.org/abs/2505.13738)]

### PTPP-Aware Adaptation Scaling Laws predict domain-adaptation performance at unseen pre-training budgets

把预训练语言模型迁移到新领域（例如给英语/阿拉伯语模型加上法语）时，你需要在学习新领域与遗忘旧领域之间取得平衡。现有的相关扩展定律假设预训练预算固定，但实践中你往往要面对训练程度各不相同的模型。本文提出了显式纳入预训练预算（以每参数 token 数即 PTPP 度量）的扩展定律，能够对你实际上还没训练过的模型预测其适应表现。

**关键发现**

- 早期拟合可预测后期表现。仅在 PTPP=15 和 31 的模型上训练的定律，能准确预测 PTPP=279 时的法语验证损失——近 10 倍外推——优于完全忽略 PTPP 的基线。
- 预训练预算以两种方式影响适应。它既移动损失下限（训练更充分的模型起点更低），也改变学习曲线的形状（模型使用适应数据的效率）。用"gated+floor"公式同时捕捉这两种效应可得到最佳预测。
- 支持解析式优化回放比例。无须昂贵的网格搜索，拟合出的定律可以直接解出满足遗忘与目标性能双重约束的最优适应参数（每参数 8.9 token，34% 回放）。

**适合谁**

把基础模型迁移到新语言或新领域的团队。研究持续预训练动态的研究者。任何想在不做穷举实验的情况下规划适应算力预算的人。

📄 [[论文链接](https://arxiv.org/abs/2510.23198)]

### 与 Inception Institute of Artificial Intelligence 的生命科学合作

Cerebras 与 Inception 人工智能研究所在生命科学基础模型上有深度合作。我们共同发表了三篇论文，介绍 Omics42 平台：Prot42 是一族蛋白质语言模型，仅凭序列即可生成高亲和力蛋白结合物，其结合强度可与 Google 的 AlphaProteo 相媲美，并支持最长 8,192 个氨基酸的序列；Chem42 是一族面向类药分子生成的化学语言模型，在标准基准上以少 6 倍的参数量超越更大的模型，并能为特定蛋白靶点定制配体；Gene42 是基因组基础模型，以单核苷酸分辨率处理最长 192,000 个 DNA 碱基对——首个达到该规模的 dense-attention 模型——在物种分类和疾病变异预测任务上创下 SOTA。
