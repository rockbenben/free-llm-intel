# 谁更快：Cerebras 上的 Kimi K2.6 还是 Gemini Flash？

James Wang

在 Google I/O 2026 上，Google 做了件不按常理出牌的事：没有发布以智能为核心的新旗舰，而是发布了 Gemini 3.5 Flash——一个把速度摆在第一优先级的模型。

随着模型能承担更复杂的编码任务，完成一条 prompt 的时间从秒涨到了分钟，有时甚至拖长到数小时。于是开发者在寻找更快的[推理](https://www.cerebras.ai/inference)选项。今年早些时候，OpenAI 和 Anthropic 都为其主力模型推出了高速变体，定价比基础模型高 3 倍。Google 如今加入战场，把速度从附注提成了头条。

Cerebras 是公认的快速推理领导者，在 OpenAI、Kimi、GLM、Qwen 等模型家族上屡创速度纪录。今天，我们把 Google 最快的模型与运行在 Cerebras 上的 Kimi K2.6 正面对决，看哪家推理服务商能最快完成任务。

### **智能**

Kimi K2.6 是 Moonshot AI 的一万亿参数 Mixture-of-Experts 模型，每个 token 激活 320 亿参数。它在 MiMo V2.5、DeepSeek V4、GLM-5.1 等一众高能同伴中是最强的开放权重模型，尤其受编码场景欢迎，值得注意的是，它还是 Cursor 的 Composer 2.5 的基座模型。相比之下，Gemini 3.5 Flash 是一个闭源、规模未披露的模型，设计为跑在 Google 的 TPU 上。它比 Gemini 3.1 Pro 略欠智能，但把速度放在第一位。

Gemini 3.5 Flash 与 Kimi K2.6 是一对理想的比较对象，因为两者同属近前沿级别。在 Artificial Analysis Intelligence Index——十项基准的综合——上，两个模型不分伯仲，分别得 53.9（Kimi K2.6）和 55.3（Gemini 3.5 Flash）。聚焦编码，Kimi K2.6 更突出：它以 58.6% 领跑 SWE-Bench Pro，超过 Gemini 3.5 Flash 的 55.1%。

推理速度的主指标是输出 tokens/秒。输出越快，模型完成编码任务越快。Artificial Analysis 用标准的 10,000 token 输入测试，测量输出 token 返回的速率。

Gemini 3.5 Flash 在该基准上达到 181 tokens/秒，显著快于处于 60 tokens/秒 区间的 Claude Opus 4.8 和 GPT-5.5。但 Cerebras 上的 Kimi K2.6 属于另一个量级。Cerebras 的表针停在 981 输出 tokens/秒——比 Gemini 3.5 Flash 快 5.4 倍。即便是对照 Google 自家的现场演示——显示 Gemini 3.5 Flash 在疑似下一代 TPU 上约 280 tokens/秒——Cerebras 依然快三倍以上。这靠的是把模型跑在 [Cerebras Wafer](https://www.cerebras.ai/chip) Scale Engines 上：整个模型存于片上，免去了从外部内存加载。

### **端到端响应**

更全面的速度指标是端到端响应，包含输入处理、思考/推理时间和输出生成。在 Artificial Analysis 的测量中（10,000 输入 token、500 输出 token），Gemini 3.5 Flash 用了 17.5 秒完成任务；Cerebras 上的 Kimi K2.6 用了 5.6 秒。这说明即使计入输入处理——它在多轮编码任务中往往增长——Cerebras 上的 Kimi K2.6 仍能以 3.5 Flash 一小部分的时间完成任务。

### **延迟**

语音 agent 正越来越多地用于客服、教育和车内助手。延迟是这里最重要的指标，没有之一：延迟越高，用户流失越直接。首 token 时间到 500ms 以上，对话就开始像对讲机。最聪明的模型可能需要好几秒才回应，导致开发者在语音应用里改用更不智能的模型。

这种取舍已不再必要。在最新的"多轮语音 agent"基准（Kwindla 的 aiewf-eval）上，Cerebras 上的 Kimi K2.6 以 452ms 首 token 时间拿下全场最低延迟——成为第一个快到足以实时语音的前沿级模型。这是真正的"首次"：一个万亿参数模型在开启 chain-of-thought 推理的情况下跨过 500ms 门槛。对照之下，Google 全新主打速度的 Gemini 3.5 Flash 是 960ms，Claude Sonnet 4.6 是 850ms。

### **开放与闭源**

还有一个维度不会出现在跑分图上。Kimi K2.6 是开放的。权重以 Modified MIT 许可证发布，你可以微调、检视，并在你选择的任何基础设施上运行它，包括 Cerebras。Gemini 3.5 Flash 是闭源的，只能通过 Google 获取。即便模型开箱即用完全令人满意，也没有第二家供应商兜底，只能受制于单一服务商的定价、弃用时间表和在线率。

### **结论**

每一家基础模型构建者如今都提供高速推理 API 端点。按 Artificial Analysis 的测量，Gemini 3.5 Flash 是这批里最快的，181 tokens/秒。Cerebras 上的 Kimi K2.6 智能与其相当，输出快 5 倍以上，端到端时间只用了它的三分之一。而且，它是第一个快到能撑实时语音的前沿模型。得益于开放权重，你可以按需微调和部署它。速度与智能——现在在 Cerebras 上两者兼得。
