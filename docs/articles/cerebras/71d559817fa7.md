# Cerebras 即将登陆 AWS

James Wang

全球最快的推理即将进入全球领先的云。今天我们宣布：Amazon Web Services 正在其数据中心部署 Cerebras CS-3 系统。该新服务将通过 AWS Bedrock 提供，以最领先开源 LLM 和 Amazon 的 Nova 模型运行业界最高的推理速度。此外，AWS 与 Cerebras 正在协作打造一种全新的解耦架构，把 AWS Trainium 与 Cerebras WSE 配对，在相同的硬件占地面积内提供 5 倍的高速 token 容量。

**对快速推理的需求**

AI 正在重塑软件开发。代码正越来越多地由 AI agent 而非人类开发者编写。与对话式聊天不同，agentic 编码每次查询生成的 token 约为 15 倍，并要求高速的 token 输出来保持开发者的生产力。其结果是整个行业对更多快速推理的需求既迫切又在增长。

Cerebras 是高速 AI 推理市场的领导者，为 OpenAI、Cognition 和 Meta 的模型提供动力，速度最高达 3,000 tokens/秒。今天的公告把这种速度带到 AWS 的全球客户群。而通过我们在解耦推理上的独特合作，我们将能提供 5 倍的高速推理容量。

### **解耦推理（Disaggregated Inference）**

每当你向 AI 提一个问题，都会发生两种截然不同的计算：prefill（预填充）和 decode（解码）。Prefill 处理问题，decode 生成答案。Prefill 是算力受限（compute-bound）的操作，对内存带宽要求不高。Decode 则需要为生成的每个 token 从内存中读取整个模型，因而极度消耗带宽。如今，AI 加速器在同一块芯片上运行这两个阶段。虽然这简单而灵活，但也意味着可以通过为每个阶段使用专用硬件来提升性能。

Trainium 是 Amazon 专为 AI 打造的芯片，为广泛的生成式 AI 工作负载提供可扩展的性能与成本效率。其稠密计算核心尤其适合 prefill 阶段。Cerebras CS-3 是全球最快的 AI 推理系统，把所有模型权重以 SRAM 形式存储在片上，其内存带宽比最快的 GPU 高数千倍，是 decode 最快的处理器。

通过本次合作，我们正在构建一个解耦配置，兼取两家公司之长。在解耦模式下，Trainium 专门处理 prefill 工作：计算 KV cache 并通过 Amazon 高速 EFA 互联发送给 WSE。Cerebras WSE 接收结果并专门执行 decode，以每秒数千个输出 token 的速度生成内容，而 GPU 只有每秒数百个。这种架构充分利用了每种处理器的长处，让 AWS 客户的高速 token 处理量提升 5 倍。

> "推理是 AI 为客户交付真实价值的地方，但对于实时编码助手和交互式应用这类高要求负载，速度仍然是关键瓶颈。我们与 Cerebras 正在构建的方案解决的正是这个问题：把推理负载拆分到 Trainium 和 CS-3 上，用 Amazon 的 Elastic Fabric Adapter 将两者相连，让每个系统做自己最擅长的事。其结果将是比当前可用方案快一个数量级、性能更高的推理。"AWS 计算与机器学习服务副总裁 David Brown 表示。

AWS 与 Cerebras 将同时支持聚合式与解耦式配置。当你拥有大规模、稳定的工作负载时，解耦式是理想选择。大多数客户运行的是混合负载，prefill/decode 比例各不相同，此时传统的聚合方式仍是最佳。我们预期大多数客户会希望两者兼得，并能把工作负载路由到对其最优的配置上。

我们非常兴奋能与 AWS 团队合作这项独特的协作。解耦推理是一项横跨 AI 硬件、模型与基础设施的深度技术工程。AWS 带来在定制芯片、网络与分布式计算方面的世界级专长；[Cerebras](https://www.cerebras.ai/chip) 带来在晶圆级系统架构、模型专长和推理服务方面十年的创新。我们携手把两支卓越且互补的工程团队合而为一，在[第一云平台](https://aws.amazon.com/?)上以前所未有的规模打造全球最快的 AI 推理。我们期待在未来几个月内将这一切交付给客户。
