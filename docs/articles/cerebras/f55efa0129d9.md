# StackAI × Cerebras：为企业 AI Agent 启用最快推理

StackAI 是一个低代码企业平台，用于在受监管行业构建和部署 AI agent，支撑合规审查、核保、理赔自动化等工作流。当客户从简单的 copilot 转向复杂的多步 agentic 工作流，StackAI 需要一个能在多样化模型尺寸与用例中交付亚秒级延迟的推理层。通过集成 Cerebras，StackAI 为企业提供了快速、灵活、生产级的推理——让理赔分诊、合规检查、信贷决策这些高风险工作流拥有即时般的体验。StackAI 与 Cerebras 联手，让实时、可规模化的 agentic 自动化在金融、医疗和公共部门落地。

> "Cerebras 给了我们的 agent 一个 GPU 根本够不着的性能挡位。我们在复杂多步工作流上拿到亚秒级延迟，而不牺牲质量或灵活性。"

Bernard Aceituno

Co-Founder & President @ StackAI

## **挑战**

StackAI 支持数百种用例，从文档密集的流程到实时运营决策，全部在一个安全平台上，且每一种都建立在结构化检索、多步推理和跨几十个企业系统的集成之上。随着需求增长、客户从简单助手转向全自动工作流，速度与响应性成了产品采用的关键。

企业 agent 的行为更像分布式系统，而不是聊天机器人。单条工作流可能包含多轮 RAG、工具使用、规划、验证和摘要。有些负载需要在超长文档上做深入的多跳推理；另一些——一线客服 chatbot、看板驱动的洞察——需要近乎即时的响应。

随着 StackAI 扩展到更多受监管行业，两项要求凸显出来：

- **响应敏捷**
如果 agent 被嵌入理赔系统、合规看板或核保工具，哪怕很小的延迟也会打断心流、侵蚀信任。
- **灵活性**
不同工作流需要不同的模型家族：路由与分类用小模型，日常运营用中型模型，高难度推理任务用大模型。

为支撑这些负载的广度，StackAI 需要一个快速、灵活且可扩展的推理地基——而不强迫团队管理 GPU 集群，或在延迟与模型选择上妥协。

### **方案：关键处快，其余地方灵活**

StackAI 围绕"企业自主选择"设计。平台不强制单一推理服务商、也不藏一个黑盒路由层，而是让企业对 agent 工作流每一步用哪个模型、哪家服务商拥有完全控制权。客户可在宽泛的开源模型中挑选（路由或分类用小模型，运营任务用中型模型，复杂推理用大模型），取决于其成本、性能与治理要求。

Cerebras 成为速度挑战的清晰答案。在 StackAI 灵活的"自带模型"框架里，只要有人在环等待，Cerebras 就是默认选择——理赔分诊、合规检查、信贷决策、异常处理、质量核验，以及其他延迟敏感步骤。它的超低延迟推理（比 GPU 最快快 15 倍）让多步、重度 RAG 的 agent 链保持"即时"手感，甚至让对长文档的深度推理也落地成一次普通 UI 交互，而不是一场漫长作业。

通过在最创造用户价值之处点亮 Cerebras，StackAI 帮企业在速度、成本效率与推理深度之间取得平衡，而不把他们锁进单一推理战略。StackAI 用户在以下场景尤其受益于 Cerebras：

- **文档密集的推理循环**——亚秒级响应在多轮之间复利累积
- **阻塞后续动作的规划与编排步骤**
- **质量检查、快速分类、验证与路由决策**
- **嵌入看板、表单和运营工具的实时 agent 界面**

对于"响应性决定采用度"的工作流，Cerebras 确保 StackAI 的 agent 表现得像高速运营系统，而不是慢吞吞的顺序脚本。
