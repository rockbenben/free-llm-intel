# 发布由 Cerebras 驱动的 OpenAI GPT-5.3-Codex-Spark

James Wang

今天，我们宣布 OpenAI 全新的 GPT-5.3-Codex-Spark 模型以研究预览形式上线，由 Cerebras 提供算力。这是我们 [Cerebras 与 OpenAI 合作](https://www.cerebras.ai/blog/openai-partners-with-cerebras-to-bring-high-speed-inference-to-the-mainstream)以来的首个发布。Codex-Spark 为响应速度与智能同等重要的实时软件开发而生。在 Cerebras Wafer-Scale Engine 的驱动下，它以超过 1,000 tokens/秒 运行，让实时代码环境中的反馈近乎即时。

Agentic 编码从根本上改变了软件开发。机器第一次可以在无人监督的情况下自主工作数小时甚至数天。但这种交互模式也让开发者在漫长的等待中被晾在环外，少了指挥工作的机会。既然软件开发是迭代性的，开发者需要在过程中持续注入品味、方向与判断。Codex-Spark 正是为这种实时的、迭代式的工作而设计。它快、有响应、可操纵，把开发者重新放回驾驶座。

Codex-Spark 是 Codex 的精简版本，为快速推理而优化。在 SWE-Bench Pro、Terminal-Bench 2.0 等 agentic 软件工程基准上，它的回答比 GPT-5.1-Codex-mini 更有能力，完成时间却只是后者的一小部分。

Codex-Spark 擅长做精确编辑、修订计划，以及回答关于你代码库的上下文问题。它是快速可视化新布局、打磨样式、测试新界面改动的捷径。

"Cerebras 是一位出色的工程伙伴，我们很高兴把快速推理新增为一项平台能力。把晶圆级计算带入生产，给了我们一种让 Codex 在延迟敏感工作中保持敏捷的新方式。我们期待从开发者反馈中学习，把我们的算力能力组合成一条顺滑的工作流。"OpenAI 工业算力负责人 Sachin Katti 表示。

Codex-Spark 只是 Cerebras 硬件可能性的一角。我们更大的目标是加速从实时到异步各类广泛场景的 AI 工作负载。我们专为 AI 打造的 Wafer-Scale Engine 拥有任何 AI 处理器中最大的片上内存，实现每位用户数千 tokens/秒的高速推理。该架构可横向扩展到数千台系统，把快速内存容量延伸到数十 TB 域，为训练与推理同时支撑万亿参数模型。我们预计在 2026 年将这种超快推理能力带给最大的前沿模型。

[Codex-Spark](https://openai.com/index/introducing-gpt-5-3-codex-spark/) 正以研究预览形式面向 ChatGPT Pro 用户推出，覆盖 Codex 应用、CLI 和 VS Code 扩展，API 访问则向部分设计伙伴开放。今天就试试 [Codex-Spark](https://openai.com/codex/)。
