# 循环永远不要离开验证器

Sarah Chieng

循环是全年最不令人意外的事情。它显而易见，已经存在多年，底层花活也不新。AutoGPT、BabyAGI、Ralph 循环、自动科研脚本，以及每一个带着重试条件的蹩脚 bash 循环，早就指向同一个形态。

### 历史

2023 年 3 月，AutoGPT 拿一个目标，把它分解为子任务，循环执行直到自认为完成。它成为 GitHub 历史上增长最快的仓库之一，随即几乎立刻变成一个关于"有自主、无验证"的警世故事。早期的循环会游荡、幻构、自我重复，偶尔还会把你的 OpenAI 账单点着。几周后 BabyAGI 登场，撞上同一堵墙：长时运行的 agent 会让小错误复利滚大、丢失主线，把运动当成进步。

Ralph 循环以更严格的纪律复活了这个想法——把测试、构建和外部检查拉进循环。**从这个意义上说，Codex 的 /goal 和 Claude Code 的 /loop 不是魔法新原语，而是旧循环套上了更好的接口、指向了更好的验证。**

### 那为什么是现在？

那为什么循环现在才火？多年来，AI 是一个没有身体的大脑：它会规划、重试、侃侃而谈，却无法可靠地看到自己行动之后发生了什么。然后几件事前后脚落地，让一位经典工程师猛地坐起来，带着真切的精神疲惫喃喃道：***"对我来说，完蛋了。"***

- **眼睛。**agent 现在能看见了。多模态模型和更强的 computer use 让截图、渲染页面、CAD 预览和 UI 状态成为输入。循环可以检查自己的输出，而不是隔着测试、日志或裁判模型摘要这类纯文本代理去猜。现在 agent 能打开浏览器、四处点击、审视自己构建的东西，并正确地留在轨道上。
- **手。**Bash、MCP、CLI、插件和执行框架给了 agent 触达能力。它能在 GitHub、Notion、Slack、终端、浏览器，以及每家公司的、大家假装见怪不怪的奇怪内部系统之间穿行。
- **记忆。**在路上某个节点，上下文窗口变得足够大，记忆成了默认配置。事到如今，我们大多数人都已经忘了"上下文工程"曾经是个值得焦虑的话题。
- **大脑。**agent 现在能思考了。推理模型变得更强，它们在 RL 环境中训练，并获得了多得多的 agentic 计算机使用数据。

### **证据是整场游戏**

好吧，那么一个循环到底*是什么*？循环是一个重复的周期：agent 自主采取行动，直到触及一个可验证的目标，或者直到你叫停。关键词不是*自主*，也不是*AI*，而是*可验证*。构建一个好而有效的循环的核心，就是验证。

旧的验证大多是文本化、二值的：测试过了没？基准过线没？裁判模型点头没？那很干净，但只覆盖能被压成字符串的任务。新的前沿是过去需要人眼才能完成的验证：

- 渲染页面连间距都和样机对得上吗
- 点击后表单真的提交吗
- 下拉菜单真的会展开吗
- 动画到位了还是卡顿了
- diff 只改了该改的吗（没有回归）
- 导出的文件打开没有报错吗

这里有一个带视觉反馈、不需要人坐镇监督每一轮的循环示例。我的目标是拿一张真实物体的照片，把它转化为结构化的 CAD 指令用于 3D 打印机——**实质上是从照片克隆出这个物体**。这次我用的是 [Cerebras](https://cerebras.ai) 上运行的 Google 最新开放模型 Gemma 4。

在这次运行中，每个 Gemma 4 循环大约 1.2 秒就产出一个新的 STEP 文件，速度约 1,500 tokens/秒。快到足以让 agent 把迭代当消耗品而不是珍宝。

值得一看的点在于：循环*自己*重写了它的 prompt 才走到这一步。它看着渲染结果，看出缺了什么，然后不需要我插手就修订了五次指令。同样这套"看-比-修"的循环并不在乎它对准的是什么。如今上下文长度如此之长、验证器如此好用，你可以让它对一个"克隆整个 Web 应用"复杂度的目标持续做功。

### 好循环翻车之处

但我们还有很长的路要走。循环的好坏取决于你给它什么目标，而给出坏目标有两种方式。

- **空转（Spiralling）。**循环永远学不会"何时算完成"，于是在活儿早就干完之后仍继续、继续、继续——花的是你的钱。
- **作弊（Cheating）。**循环精确执行了你说的，却一点都没给你想要的。

空转是坏循环的症状。没有确定的终态，循环就无从知道自己已完成，于是它一边"改进"一边原地打转，token 计价器一路狂奔。验证是一剂强效解药——你想让循环保持在轨道上，不浪费 token，同时仍高效地完成目标。

作弊则是一个 prompt 问题，而且更难缠。**含糊的 prompt 一定会被钻空子。**不同的模型作弊方式不同，有的比别的更听话，但修法永远一样：

- 对"什么才算完成"苛刻到令人发指地具体
- 在模型开始找捷径之前，点名禁止你不容忍的那些捷径。

### 结论

尽管工作流并不新鲜，此刻却是新鲜的。睡着的时候，有五个生产级的应用正被能够"看、行动、检查、再来一次"的循环建造着——这的感觉无疑是怪异而兴奋的。

agent 如今有了眼睛、工具、可验证的终态，以及快到足以在天亮前跑一百轮的速度。剩下的，只有你去造一个了。
