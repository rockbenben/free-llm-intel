# 慢吞吞的个人助理的兴起

Sarah Chieng

Sherif Cherfa

个人助理理应为省你时间和省力。过去几周，我们痴迷地在日常任务上测试 AI 个人助理：订机票、管日历、买菜、规划三餐。

每当助理独自把一件事办成，我们依然惊叹。但看着它为一个我们手动 37 秒就能完成的晚餐订位耗了 7 分多钟，兴奋感确实被冲淡了。

于是我们开始深挖时间都花哪儿了。在这个实验里，我们用运行在 Cerebras 上的 Qwen 3.8 27B、以 Pi 为 agent 执行框架，搭了一个测试助理。凭借 Cerebras 上更快的推理和执行框架工程，我们自己的助理在 22 **秒**内完成任务——比现有助理快 19 倍。以下是我们做的改变。

### 新一代消费级 AI 助理

OpenClaw 是未来的一瞥，而新一波消费级 AI 助理替你做完了大部分前期配置，让你不必调校底层软件就能开始转交任务。

### 时间都花在哪了

作为实验，我们把每个主流助理拉上考场，在同一个晚餐订位请求上跑基准。

同一个请求，每个助理都走了一串不同的搜索、检查与浏览器操作。Meta Muse 跑了 4 分 36 秒，其间包含 9 次对 OpenTable API 的直接调用。Claude Cowork 用了 6 分 25 秒、57 次工具调用。Grok Bot 耗时 7 分 40 秒。每个助理都正确地在 A Mano、II Borgo 或 Doppio Zero 订到了位。

#### 这是实录的运行记录，不是通用排名。22 秒的结果来自两次成功尝试的中位数。

任何 agentic 任务，底层都有大量活动。执行框架管理对话、执行工具调用、处理错误、把结果喂回模型。要理解时间去哪了，看看 Grok Bot 的前 2 分钟是怎么花的：Grok Bot 开局加载 skills、检索记忆、搜索、检查餐厅页面、汇报结果。仅一次浏览器运行就花了 2 分 18 秒，逐一检查 A Mano、Il Borgo 和 Doppio Zero。

例如，这里可以看到 Grok Bot 这次运行更细的拆解。

模型也很关键。近期在规划、工具使用和长程推理上的进展让这些任务变得更可行。[Opus 4.5 一代](https://www.anthropic.com/news/claude-opus-4-5)把更强的 agent 能力与上下文压缩结合起来：上下文写满时，带着工作的浓缩纪要继续推进。像 [CompactionRL](https://arxiv.org/abs/2607.05378) 这样的研究更进一步，训练 agent 跨压缩步骤继续干活。

而在这一切之下，你仍然需要一个快的模型来盯住目标、从错误中恢复，并经常核验任务是否还在轨道上。

### 我们是怎么做的

我们用 [Pi](https://pi.dev/) 作为 agent 执行框架。它小巧的系统 prompt 和四个内建工具给了我们一个简单的起点，又留有空间让我们为订位任务添加自己的工具。

### 1. 并行检查相互独立的选项

检查各餐厅可用性是典型的"embarrassingly parallel"任务。订位这一步确实依赖于这些检查的返回。我们的拆分：并行跑独立的检查，再用结果决定如何继续。

Skill 指导它并行检查独立选项，这样它就能同时收集多家餐厅的结果，而不必等一个检查完成再开始下一个。

我们优化后运行的浏览器/API 部分是 6.8 秒，而先前 Grok 轨迹中同类环节是 4 分 31 秒——在这些实录类目上约 40 倍差距。这个比较混合了对模型、执行框架和执行路径的改动；它没有单独隔离出 skill 本身的效应。

### 2. 加速剩余的模型调用

助理每次回到模型，就要再等一次响应。Cerebras 上更快的推理缩短了这些停顿。我们优化的运行使用 Qwen 3.8 27B；保存网站操作流程也减少了模型在运行中需要现场琢磨的内容。

有些步骤仍然必须按顺序发生。agent 需要先拿到页面结果，才能决定拿它怎么办。更快的推理不会让一个慢网站秒开，也不会变掉手机验证步骤，但它能砍掉"看见—决定—行动"之间反复出现的停顿。

### 3. 把 agent 学到的东西存下来

大量浪费来自"发现这个网站怎么工作"：调一个工具、观察页面、预测下一步、再调一个工具。agent 摸索一通，学会会发生什么，然后继续干正事。下一次访问，它可能把这趟发现工作整个再来一遍。

在运行助理之前，我们给 agent 提供了更多上下文，并把学到的东西固化成 skill。这给了模型导航订位流程的说明书，而不必每步自己探索。在我们的测试中，这把工具调用减少了 80% 以上。

重要的区分在于复用的对象。我们可以省下"如何导航网站、如何查订位"的流程本身。可用情况、价格和是否需要信用卡，仍然需要实时查看。摸清路线的功课发生在计时运行之前；它并没有消失，只是被前移了。

### 一个更快的个人助理

在它能同样漂亮地处理每一件差事、让我们拥有真正的 Jarvis 之前，还有大量工作要做。但想象一下：当这些已经感觉像魔法的 agent 再快 10 倍，会是什么样。

好了，先走一步！我们还有个晚餐订位要赴。
