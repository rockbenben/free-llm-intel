# OpenAI GPT-OSS 120B 基准测评——NVIDIA Blackwell 对阵 Cerebras

James Wang

一年前，Cerebras 发布了推理 API——为 AI 性能立下新标杆。当基于 GPU 的服务商还在输出 50 到 100 tokens/秒时，Cerebras 已在 Llama、Qwen、GPT-OSS 等一系列开放权重模型上交付 1,000 到 3,000 tokens/秒。彼时，一些质疑者认为，击败 NVIDIA 的 Hopper 代 GPU 只是一回事，真正的考验要等它的下一代 Blackwell GPU。如今来到 2025 年末，云服务商终于开始上线 GB200 Blackwell 系统，是时候重新审视这个问题了：AI 推理谁更快——NVIDIA 还是 Cerebras？

### 开放权重的对决：GPT-OSS 120B

OpenAI 的 GPT-OSS-120B 是当今由美国公司开发的最强开放权重模型，凭借出色的推理和编码能力被广泛使用。根据 Artificial Analysis 的基准测试，目前多数厂商的 GPT-OSS-120B 跑在 100 到 300 tokens/秒 的区间，这正是广泛部署的 NVIDIA H100 GPU 的典型水平。性能：Cerebras 占优。

上个月，Baseten 发布了 GPT-OSS-120B 运行在 Nvidia 最新 Blackwell GPU 上的首份[结果](https://www.baseten.co/blog/how-we-made-the-fastest-gpt-oss-on-nvidia-gpus-60-percent-faster/#baseline-performance-engineering)，达到 650 tokens/秒——当时 GPU 上取得的最快纪录。为了达成这一里程碑，Baseten 在八块通过 NVLink 互联的 GB200 GPU 上运行该模型，使用 Tensor Parallel 8（TP8）进行模型分布，采用 TensorRT-LLM 和 NVIDIA Dynamo 做动态图优化，并用 EAGLE-3 投机解码加速 token 生成。这是一份亮眼的成绩，展示了 Blackwell 在生产级推理云上的巅峰性能。

凭借这个结果，Baseten 不仅超越了市场上所有其他 GPU 厂商，还超过了 Groq 这类以速度为核心差异化的公司。Blackwell 也证明了一点：当 Nvidia 每年更新硬件时，对 GPU 厂商的 2-3 倍速度优势会迅速化为乌有。

值得称赞的是，Baseten 在结果中纳入了 Cerebras，显示我们的硬件运行 GPT-OSS-120B 模型超过 3,000 tokens/秒。这得益于我们的晶圆级架构——把整个模型存放在片上存储器中，消除了 GPU 的带宽制约。值得注意的是，2024 年发布的 Cerebras Wafer Scale Engine 3 至今仍比 NVIDIA 最新的 Blackwell 代快近 5 倍——这凸显了为大规模 AI 推理量体裁衣的计算架构所具有的持久优势。

### **不只快，性价比同样出色**

Cerebras 一直以原始速度著称——但我们常被问到：这钱花得值吗？在大多数高性能产品里，速度遵循收益递减定律。Ferrari 的价格是 Camry 的 10 倍，但速度只快不了 3 倍。那么 Cerebras 处在这条曲线的什么位置？

Cerebras 以每百万 token 0.75 美元的价格交付 3,000 tokens/秒，而 Baseten 以每百万 token 0.50 美元交付 650 tokens/秒——性能价格比是 4,000 对 1,300。换句话说，Cerebras 只是略贵，却快出数倍——与 Ferrari-Camry 的例子恰好相反。你不是为边际提升付 10 倍价钱，而是为巨大的性能飞跃只多付一点点。

### **Cerebras——2025 年仍然最快的推理**

Nvidia Blackwell 相对 Hopper 是一次实质性升级，把 GPU 推理的顶速提升了 2-3 倍，并反超了 Groq 这类小芯片 AI 竞争者。Cerebras 是唯一超越 Nvidia 的架构，在 OpenAI 旗舰开放权重 AI 模型上保持着 5 倍的压倒性领先。我们期待在 2026 年再次重排这份榜单。
