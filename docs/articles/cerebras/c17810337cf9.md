# 延迟负债之年（以及科技巨头们如何偿还它）

Sarah Chieng

Sarah Su

我往世界上语言模型中最先进的一位里敲入一句话："写一个函数，从 markdown 代码块里解析 JSON。"然后我开始等。光标一闪一闪。我在椅子上挪了挪身子。"Thinking……"我去刷了眼 Instagram 快拍。等模型写完，我已经被拉进了一场会议。

回答很漂亮。**体验却远谈不上理想。**如果你一直在用前沿 AI 模型构建产品，你多半也有同感。这是人类造过的最好的技术，用起来却常常像看油漆变干。

### 什么是"延迟负债"？

在软件工程中，"技术债"指那些今天能跑、明天生事的捷径与垃圾代码累积下来的成本。工程师们追求快，自动接受 AI 建议，把清理往后拖。

延迟负债的机理相同。过去几年，我们投入了海量资源让 AI 模型更能干、更大、更聪明、更懂语境。我们没做的，是更新硬件去支撑这新一代软件。

**延迟负债**是我们在"模型优化快于基础设施"的过程中攒下的隐性成本。我们为智能做优化，但每一次进步——更多的模型参数、新的推理模型——都意味着每次响应要消耗更多算力。

账单的到期形式是：迟钝的用户体验、名为实时却并不实时的应用，以及理论上无所不能、实际上慢得没法用的 AI agent。

### 延迟负债的配方

要理解我们怎么走到这一步，看看过去几年 AI 的几大进展。每个趋势都代表 AI 的进步，但**每一个也都在给我们的延迟负债添砖加瓦。**

**模型越来越大。**

2018 年，BERT-Large 有 3.4 亿参数。今天，Kimi-k2 这样的前沿模型超过 1 万亿参数，增长了 3,000 倍。更大的模型更能干，但它们每生成一个 token 也需要更多计算。

**推理 token 已经反客为主。**

如今，现代 AI 模型不只是生成回答，它们先*思考*。

这些中间的"reasoning tokens"是模型在给出最终答案前一步步解题的过程。一年前，reasoning tokens 占总生成量不到 10%。今天，[它们已超过 50%。](https://openrouter.ai/state-of-ai?utm_source=chatgpt.com)

**上下文窗口越来越长。**

2019 年的 GPT-2 大约能处理 1,000 个 token 的上下文。今天的模型能处理 1,000 万 token，大致相当于[三十本 500 页的书。](https://news.ycombinator.com/item?id=39384145)这对需要在大型文档或整个代码库上推理的应用是变革性的。

它同时也意味着，模型在回答之前要处理的信息急剧增多。

**开发者确实在用这些上下文。**

仅过去一年，[平均输入 token 长度翻了四倍。](https://openrouter.ai/state-of-ai?utm_source=chatgpt.com)用户把整个仓库、完整文档集和全部对话历史喂给模型。

**输出长度也在爆炸。**

另一边，平均[输出 token 数过去一年也涨了 3 倍。](https://openrouter.ai/state-of-ai?utm_source=chatgpt.com)这要"归功"于 test-time compute。

### 延迟负债是什么感觉

延迟负债是你的编码 copilot 为了一行建议让你等五分钟，从而打断你的心流。是你的 AI agent 理论上能订机票、查日程、起草邮件，但每一步慢到你还不如自己来。

**人类对延迟从来都极度敏感。**IBM 1968 年的一项[用户体验研究](https://arxiv.org/html/2507.22352v1)发现，计算机响应延迟超过 2 秒就会导致参与度显著下滑，超过 4 秒的延迟"令人尴尬，因为它意味着沟通的线头被打断"。超过 15 秒，对话式交互便不复可能，用户在心理上已经离场。

最近，2025 年[中佛罗里达大学的一项研究](https://arxiv.org/html/2507.22352v1#bib.bib71)针对 LLM 驱动的 agent 发现了同样的阈值。**超过四秒的延迟会让用户体验的每一个被测量维度都变差，74% 的用户表示他们根本不会使用一个慢的系统。**

### 一个不断重演的模式

这个模式以前就发生过。在计算领域，工作负载定义硬件。***每一次工作负载改变，服务旧负载的硬件就会变成新负载的瓶颈。***

**
1985（定制硬件 → CPU）：**计算从专用科学模拟转向需要可编程的通用软件。

**
2003（CPU → GPU）：**机器学习和图形渲染等新负载要求大规模并行。于是 CPU 成了瓶颈，GPU 是答案。

**
2026（GPU → Cerebras WSE）：**今天，随着我们构建多 agent 系统、编码助手、语音接口和 human-in-the-loop 工作流，工作负载又一次在变。这些负载是顺序的、内存受限的、对延迟极其苛刻的。GPU 不是为此设计的。

幸运的是，硬件迁移已经启动。Cerebras 的 Wafer-Scale Engine（WSE）——一块餐盘大小的单芯片——是为需要低延迟的 AI 负载优化的新一代架构。**与在芯片和内存之间来回搬运数据的 GPU 不同，WSE 把一切留在片上，消除了卡住 GPU 推理的内存带宽制约。**

### 聪明钱已经在动

想知道延迟负债是不是真的，跟着钱走就行。

过去六个月，AI 领域最重要的四家公司都对更快的推理下注了数十亿美元，而这些下注没有一笔押在如今已经主导 AI 的 NVIDIA 硬件上。

**Google**——尽管是 NVIDIA 最大的客户之一——自研了 Ironwood TPU，[推理负载上比 NVIDIA 的 GPU 快 4 倍](https://www.techbuzz.ai/articles/google-unleashes-ironwood-tpu-4x-faster-ai-chip-challenges-nvidia)。

**Anthropic** 向 Google 的 TPU 基础设施[投入了数百亿美元](https://www.cnbc.com/2025-10-23/anthropic-google-cloud-deal-tpu.html)，而不是扩充其 NVIDIA 容量。

**NVIDIA** 自己则[支付 200 亿美元吞并了 Groq](https://www.cnbc.com/2025-12-24/nvidia-buying-ai-chip-startup-groq-for-about-20-billion-biggest-deal.html)，买的是它的 IP 和顶尖人才——一家价值主张完全是推理速度的公司。这是 NVIDIA 迄今最大的一笔收购。

而 **OpenAI** 刚刚[从 Cerebras 购买了 750 MW 的算力](https://openai.com/index/cerebras-partnership/)。Cerebras 制造的晶圆级芯片，正是专为 AI 推理所需的顺序型、内存受限负载而设计的。

**
四家在一切事情上竞争的公司，做了同一个赌注。*这不是巧合。***

### 偿还负债

延迟负债不是绝症。上述收购与投资，是向更新、SOTA 的 AI 优化硬件设计迁移的开端。

更好的是，回报立竿见影。当你在为推理设计的硬件上运行前沿模型，体验是切肤的：那个让你等三十秒的模型，现在两秒内作答。**AI 从瓶颈变成了协作者。**

我们在"教会机器思考"上取得了可度量的进步。但要真正把它们融入我们的工作流和生活，我们需要为"思维速度级交互"而设计的硬件。**这就是我们偿还延迟负债的方式。**
