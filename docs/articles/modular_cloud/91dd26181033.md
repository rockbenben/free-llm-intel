# Modular Hack Weekend 回顾：优胜项目与社区亮点

上周末，来自 AI 与系统编程社区各地的开发者齐聚一堂，参加 **Modular Hack Weekend**：一场聚焦用 Mojo 和 MAX 进行 GPU 编程和模型实现、面向全球的线上黑客松。活动主要通过我们的 Discord 服务器和论坛在线举行，带来了全新的能量、大胆的想法，以及一个有力的提醒——这个社区在短短 48 小时内就能构建出什么。

黑客松于周五晚以一场混合式 GPU 编程工作坊开幕，观众通过直播来自世界各地，许多人则亲临我们加州 Los Altos 的办公室。工作坊安排了以下嘉宾的闪电演讲：

- [Chris Lattner，Modular CEO 兼联合创始人](https://www.youtube.com/watch?v=DqTBvi0DKgg)
- [Chuan Li，Lambda 创始成员兼首席科学家](https://www.youtube.com/watch?v=F7jGCKHl7Wg)
- [Bin Bao，Meta 软件工程师、torch.compile 技术负责人](https://www.youtube.com/watch?v=BBhZ9Ltpmdw)
- [Jared Roesch，NVIDIA 杰出工程师、OctoAI 联合创始人](https://www.youtube.com/watch?v=BBhZ9Ltpmdw)

我们的工作坊还探讨了用 Mojo 编写高性能 kernel 的基础，以及 MAX 如何能构建跨异构硬件运行的模型图，最后留出了大量自由交流时间。随后， hacking 正式开始——参赛者既有在工作坊现场组队，也有通过 [Discord 服务器](https://discord.gg/modular)和[论坛](https://forum.modular.com/)在线集结队友。

# Modular Hack Weekend 合作伙伴

没有以下伙伴的支持，活动不可能顺利举行：

- ‍[**NVIDIA**](https://www.nvidia.com/en-us/) 赞助了比赛的 GPU 奖池，为前三名优胜者颁发 RTX 5090、5080 和 5070 GPU。**‍**
- [**Lambda**](https://lambda.ai/) 为每位参赛者提供 400 美元的云算力积分，让建设者整个周末都能用上强大的 NVIDIA 硬件。**‍**
- [**GPU MODE**](https://www.youtube.com/watch?v=yOMflrCRya0)——互联网上最大的 GPU 编程社区，为活动注入了能量与专业。

我们无比感谢这三家伙伴对这次黑客松成功的支持。

# 优胜项目

### 🏆 **第一名：Martin Vuyk 的快速傅里叶变换**

[*GitHub 仓库*](https://github.com/martinvuyk/hackathon-fft)* 和 *[*论坛帖子*](https://forum.modular.com/t/hackathon-2025-06-fast-fourier-transform/1843)‍

Martin 是一名机电一体化工程师，转型进入软件开发。他工作中使用 Python 和 SQL，业余时间则是 Mojo 标准库的主力贡献者。这次 Hack Weekend，他选择用 Mojo 在 GPU 上实现快速傅里叶变换。这个项目建立在他大学期间的信号处理功底之上，也让他得以探索并行计算。

> "这是我第一次真正给 GPU 编程，之前只是用用 TensorFlow。正如很多人说的，它出奇地简单。我还特意选了个我熟悉、且只在一维上求解的题目，以避开多维张量带来的种种头疼问题。如果这么多人能在一个周末就上手 GPU 编程，恰恰说明 Modular 正在打造的这套工具多么出色！"

Martin 捧走第一名和一块 RTX 5090。

### 🥈 **第二名：Seth Stadick 的 Mojo-Lapper**

[*GitHub 仓库*](https://github.com/sstadick/mojo-lapper)* 和 *[*论坛帖子*](https://forum.modular.com/t/hackathon-mojo-lapper-gpu-accelerated-interval-overlap-detection/1812)

[*‍*](https://forum.modular.com/t/hackathon-mojo-lapper-gpu-accelerated-interval-overlap-detection/1812)Seth 是 Bio-Rad Laboratories 的生物信息软件工程师，对开发者工具和高性能计算有浓厚兴趣。他的项目是 Mojo-Lapper——一个 GPU 加速的区间重叠检测库。kernel 采用 BITS 算法，相比 CPU 版本取得 60 到 140 倍加速，在基因组学、数据库和时间序列分析中有实际应用价值。

> "Mojo-Lapper 是一个做区间集合运算的库，为 CPU 和 GPU 提供统一 API。作为其中一部分，我把用于统计区间交集的 BITS 算法移植为 Mojo kernel，相比单线程 CPU 版本加速 140 倍。这里还有很多性能可以挖掘，但再一次，为 CPU 写的代码几乎可以直接丢给一个 GPU 线程就取得巨大收益，这一点令人印象深刻。"

Seth 获得第二名和一块 RTX 5080。

### 🥉 **第三名：Thomas Trenty 的 QLabs：量子电路模拟器**

[*GitHub 仓库*](https://github.com/ttrenty/QLabs)* 和 *[*论坛帖子*](https://forum.modular.com/t/qlabs-quantum-circuit-simulator-with-gpu-acceleration/1815)‍

Thomas 是一名主攻 AI 与量子计算的计算机硕士研究生。他此前构建过底层系统，例如一个 C 语言线程库和基于 WebAssembly 的可视化工具。这次黑客松，他创建了 QLabs——一个完全用 Mojo 写成、GPU 加速的量子电路模拟器。这也是他第一次做任何形式的 GPU 编程。

> "在做的过程中学习，收获非凡。Mojo 文档和 GPU 编程谜题给了我扎实的基础，帮我强势起步。而更重要的是，能与 Modular 内外这些充满热情、聪明又才华横溢的人交流，让这段经历真正难忘。"

Thomas 拿下第三名，赢得一块 RTX 5070。

## **Quinn Avila 的 Boids 模拟**

[*GitHub 仓库*](https://github.com/quinnavila/mojo_swarm)* 和 *[*论坛帖子*](https://forum.modular.com/t/hackathon-june-hack-project-boids-simulation-in-mojo-gpu-naive-to-optimized/1803)

这个项目用 Mojo 的 GPU 编程重新实现了 [Boids 模拟](https://en.wikipedia.org/wiki/Boids)。通过把暴力 kernel 替换为空间感知的流水线，Quinn 取得了 14.5 倍加速。优化版把复杂度从 O(N²) 降到 O(N)，实现 10 万只 boid 的实时模拟。

### **Viraj 的 Whisper‑Mel‑Mojo**

[*GitHub 仓库*](https://github.com/vrtnis/whisper-mel-mojo)* 和 *[*论坛帖子*](https://forum.modular.com/t/mel-spectrogram-mojo-front-end-for-whisper/1805/2)

Whisper‑Mel‑Mojo 是一个可移植的 Mojo kernel，把 log-Mel 频谱提取与 3×3 平均卷积融合在一起，复现 Whisper 的前端。它完全在设备端运行、零 host 到 device 传输，音频驻留在 GPU 内存中，降低了开销。
