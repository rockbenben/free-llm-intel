# Mojo🔥 现已开源！

我们高兴地宣布，Mojo🔥 语言现已在 [Apache 2.0 许可证（含 LLVM 例外条款）](https://github.com/modular/modular/blob/main/LICENSE)下完全开源！Mojo 编译器的源码、工具链以及构建该语言所需的一切，现已开放在 [我们的](https://github.com/modular/modular)[`modular`](https://github.com/modular/modular)[ GitHub 仓库](https://github.com/modular/modular)中。

Mojo 语言是一次大胆的押注：一门超越前辈的、新颖的通用编程语言。Mojo 融合了编译器与编程语言研究的最新成果，释放 GPU、AI 加速器及其他先进算力的潜能。过去四年，Mojo 的开发面向开放社区，但编译器始终闭源。上周 [Mojo 发布了 1.0](https://www.modular.com/blog/modular-26-5-mojo-1-0-is-here)（源码稳定性得到保证），今天我们很兴奋地把整个编译器和工具链开源。

### Apache 2：宽松的许可证

Apache 2.0 许可证是编程语言与编译器领域的金标准，因为它为各类应用提供了极大的使用灵活性。许可证中的 LLVM 例外条款进一步扩展了构建和分发 Mojo 编译产物的自由度。我们希望你能在能想到的尽可能多的应用中采用和使用 Mojo。

我们的开源路线是深思熟虑的：我们发现小而紧密的设计团队（而非委员会）最适合寻找一门语言的"灵魂"，而更广泛社区的反馈对于跳出信息茧房至关重要。因此，我们先开源了 [Mojo 标准库](https://www.modular.com/blog/the-next-big-step-in-mojo-open-source)，随后发布了[数十万行用 Mojo 编写的 kernel 代码](https://www.modular.com/blog/modular-platform-25-3-450k-lines-of-open-source-code-and-pip-install-modular)、工具和支持。我们结合社区反馈与公开设计提案一起构建，如今开源编译器。随着 Mojo 不断成熟，我们会持续开放我们的流程。

### 如何获取并构建编译器

Mojo 语言的全部代码现已开放在主 [`modular`](https://github.com/modular/modular)[ GitHub 仓库](https://github.com/modular/modular)。首先把仓库克隆到本地：

bash

```
git clone https://github.com/modular/modular.git

cd modular
```

然后，要从源码构建 Mojo 编译器并对某个 Mojo 文件运行它，只需一条构建命令：

bash

```
./bazelw run --config=build-mojo KGEN:mojo -- run hello.mojo
```

在 Modular，我们使用 [Bazel](https://bazel.build/) 管理 Mojo 和 MAX 复杂的构建流程与缓存。这一条命令会下载或构建构建 Mojo 编译器和 Mojo 标准库所需的一切。`--config=build-mojo` 标志告诉构建系统使用你本地系统上的源码，从零开始编译所有内容。

这也适用于 Mojo 标准库的开发：你可以修改编译器或库代码，并通过以下命令运行完整测试套件：

bash

```
./bazelw test --config=build-mojo mojo/stdlib/test/...
```

如果你不是在做编译器本身的开发，可以使用 `--config=prebuilt-mojo` 标志，构建系统会下载最新的 nightly 二进制编译器发行版，为你节省一些编译时间。注意，如果你要定制 MAX kernel 或模型，目前仍然需要预构建的 Mojo 编译器。

### 贡献

Mojo 标准库自 2024 年起就接受贡献，我们感谢每一位帮助推进这门语言的人。一个教训（尤其是在当下的 AI 编码时代）是：我们必须审慎地处理贡献。因此，我们目前还未准备好接受针对编译器和工具链的贡献。我们目标是今年年底前开始接受编译器与工具链的贡献，届时会分享更多细节。

在阅读 Mojo 编译器源码的过程中有任何问题，或想分享你正在做的项目，欢迎加入[我们的论坛](https://forum.modular.com/)。克隆源码，告诉我们你用 Mojo 语言构建了什么。我们很兴奋把 Mojo 向世界敞开，期待它成长！
