# Modular 2025 年度回顾

2025 年临近尾声，我们想回顾一下 Modular 这一年经历的非凡历程。这一年，我们把全部心力投入一个使命：[**构建面向未来的 AI 基础设施**](https://www.modular.com/democratizing-ai-compute)——一个统一的计算层，让开发者和企业能在任意规模、任意硬件上不打折扣地部署 AI。以下是年度"十大"亮点。感谢你参与其中。

### 2025 年十大亮点

**1. 发布 AMD 支持，并在 AMD MI355X 上达成 SOTA**

AMD 发布 MI355 时，我们仅用两周就达到最先进性能。而此时距我们首次支持 AMD GPU 只有三个月。这一速度的背后，是 MAX 的统一抽象层让你能在新硬件上部署优化模型，无需重写代码，也不必等上几个月去等厂商专用实现。

→ [阅读故事](https://www.modular.com/blog/achieving-state-of-the-art-performance-on-amd-mi355----in-just-14-days)

**2. 在 NVIDIA Blackwell 上刷新性能纪录**

我们记录破纪录矩阵乘法性能之路的四部曲系列，成为所有认真做 LLM 优化的人的必读材料。系列 walkthrough 了每一个优化步骤——从基线实现到 warp 特化、异步拷贝等高级技术——手把手教你从最前沿的硬件中榨取最大性能。

→ [从第一篇开始](https://www.modular.com/blog/matrix-multiplication-on-nvidias-blackwell-part-1-introduction)

**3. 为排名第一的语音模型供能**

运行在 Modular Platform 上的 Inworld TTS 1 Max 登顶 Artificial Analysis 语音排行榜——延迟快 70%，成本低 60%。这意味着生产可用的文本转语音，音质更高、成本更低，证明性能与成本效率不必互相牺牲。

→ [看看我们怎么做到的](https://www.modular.com/blog/tts-1-max-ranked-1-speech-model-on-artificial-analysis)

**4. MAX AI 内核与 Mojo 标准库开源**

整个 2025 年，Modular 开源了 Mojo 与 MAX 代码库的大部分内容。我们完成了 Mojo 标准库的开放（2024 年启动），公开了底层 GPU 交互细节。随后发布了超过 45 万行 Mojo 代码的 MAX 内核——全球最大的 Mojo 代码仓库。这为开发者编写兼具内存安全保证与最优硬件利用所需底层控制的高性能 GPU 内核，提供了一份全面的参考。

→ [查看 25.3 更新日志](https://docs.modular.com/max/changelog/#v253-2025-05-06)

**5. MAX Python API 全面开源**

MAX Python API 现已在 [GitHub 上完全开源](https://github.com/modular/modular)——开发者可以完整看到 MAX 模型如何在各硬件上构建、执行与服务。现在你可以检视、修改并贡献整个模型执行栈，从高层 Python API 一直到硬件特定优化。

→ [查看 25.7 更新日志](https://docs.modular.com/max/changelog/#v257-2025-11-20)

**6. Mammoth 发布：最大规模 AI 工作负载的无限扩展，轻松拿捏**

这是我们面向企业级 GenAI 部署的 Kubernetes 原生控制平面。分离式推理（disaggregated inference）、智能路由、多模型编排——2026 年将以托管端点的形式来到你身边。Mammoth 负责处理在分布式基础设施上运行多模型的复杂性，自动扩缩资源、路由请求，同时优化性能与成本。

→ [观看技术分享](https://youtu.be/jatv_K0D1fo?si=I_SJa67Cq_1W2hhB)

**7. 学习 GPU 编程的新途径**

我们上线了动手学习的 [Mojo GPU Puzzles](https://puzzles.modular.com/)，以及面向 GPU 概念新手的 [YouTube 教程系列](https://youtu.be/-VsP4kT6DjA?si=J8XHSl_oGiSeHvPb)。无论你是学 GPU 基础还是磨高级优化技能，这些资源都能让你通过交互式题目和清晰讲解建立直觉。

→ [亲自试试谜题](https://github.com/modular/mojo-gpu-puzzles)

**8. 全新 MAX API**

我们发布了[在 MAX 中构建自定义模型的新 API](https://docs.modular.com/max/api/python/experimental/)，并配套做了一个实战教程。从零构建一个 transformer：embedding、注意力机制、前馈层，直到一个能运行的语言模型。教程演示了如何从第一性原理构建生产质量的模型，为你实现贴合特定用例的新架构打下基础。

→ [在 MAX 中从零构建 LLM](https://llm.modular.com/)

**9. 两场黑客松，一个了不起的社区**

从 AGI House 的 [GPU Kernel Hackathon](https://app.agihouse.org/events/modular-hackathon-20250510)，到我们 Palo Alto 办公室的 [Hack Weekend](https://www.modular.com/blog/modular-hack-weekend)——你们来了，造出了令人惊叹的东西，让 2025 年难以忘怀。多个黑客松项目直接贡献给了 Mojo 生态。我们全年还举办了多场社区聚会，包括 12 月 11 日带你走进 MAX Framework 内部的 Modular Meetup。在下面这场直播中，看 Chris Lattner 阐述他的愿景：让 MAX 成为最好、最开放的生成式 AI 框架。

→ [观看直播](https://www.youtube.com/watch?v=WK5dVQ8vhbU)

**10. 融资 2.5 亿美元，扩建 AI 统一计算层**

我们募集了 2.5 亿美元来加速使命——构建让 AI 可移植、高性能、随处可得的基础设施层。这笔资金将帮助我们扩展硬件支持、壮大工程团队、交付企业级特性，让 AI 工作负载在任何基础设施上的部署都更简单、更可靠。

→ [阅读公告](https://www.modular.com/blog/modular-raises-250m-to-scale-ais-unified-compute-layer)
