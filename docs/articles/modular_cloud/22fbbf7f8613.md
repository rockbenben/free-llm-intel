# Modverse #52：共同推进人工智能——社区项目和平台里程碑

Modular 宇宙一片热闹！从硬核的社区项目，到 AI 与开发者圈子里的认可，以下是来自我们不断成长的生态系统的最新动态。

## 社区创新

Modular 社区的创造力和创新力从不让我们失望。来自世界各地的开发者分享着他们拓展 MAX 与 Mojo 边界的项目——从让 AI 开发更省事的工具，到探索性能新前沿的实验。来看看社区都在造什么：

- 在最近的社区会议上，Martin Vuyk 分享了他在 Mojo 中的通用 FFT 实现——在他的基准测试中比 cuFFT 快至多 18 倍；Gabriel de Marmiesse 分享了他为 PyTorch 打造的 MAX 后端。完整内容请看 [10 月社区会议](https://www.youtube.com/watch?v=6OHgKUL65yU)录像。
- mewmix 的项目是 [Keccak-256 的纯 Mojo 实现](https://forum.modular.com/t/keccak-256-in-mojo/2419)，自带独立测试脚手架和可复现的测试向量。
- Photon 创建了 [SciJo](https://forum.modular.com/t/scijo-scientific-computing-library-for-mojo/2386?utm_source=chatgpt.com)，一个面向 Mojo 的高性能科学计算库，以原生 Mojo 代码的速度与效率提供类 SciPy 的功能。
- Laranzu 用 Mojo 创建了[一个 Julia 分形图像生成器](https://forum.modular.com/t/example-fractal-julia-set-in-mojo-and-mojo-gpu/2374)，CPU 和 GPU 都能跑，既给 Python 程序员提供了一个上手示例，也展示了 Mojo 相对 C++ 和 Python 的出色性能。
- Sören 开发了 [duckdb.mojo](https://forum.modular.com/t/duckdb-mojo-mojo-bindings-for-duckdb/2314)，提供 Mojo 绑定，让开发者能接入 DuckDB 的高性能分析数据库。
- Constantin G 创建了 [Butterfly](https://www.linkedin.com/posts/logicalguess_mojo-quantumcomputing-quantumsimulator-activity-7390921824420888576-juTr/?utm_source=share&utm_medium=member_desktop&rcm=ACoAAADYG-sBeXCycWTGv55OvhuNplb0W7AgorY)，一个基于 Mojo 的新型量子比特模拟器，性能已比 Qiskit 快 10–15 倍，同时展示了 Mojo 处理核心量子运算的优雅程度。
- Ash Vardanian 的 [Scaling Elections](https://ashvardanian.com/posts/scaling-elections/) 探索了如何用 GPU 和 Mojo 大幅加速计算昂贵的 Schulze 投票法——让更公平的排序选择投票能够高效扩展。
- spluta 创建了 [MMMAudio](https://forum.modular.com/t/mmmaudio-creative-coding-audio-environment/2359)，一个创意编程音频环境：用 Python 做控制、Mojo 做音频，在一个统一工作流里兼顾高层乐器搭建与底层 DSP。

💡 我们爱看你们的创作！把 MAX 或 Mojo 项目发到[论坛的 Community Showcase 分类](https://forum.modular.com/c/community-showcase/8)，方便我们在下一期中展示它们。

## Modular 声浪持续

Modular 持续在 AI 与高性能计算领域掀起声浪——从管理层露面，到展示 MAX 与 Mojo 能力的基准测试。

- Meta AI 最近在 Triton Conf 上展示的独立基准测试显示，Mojo 持平或超过 CUDA，并大幅领先 Triton 和 TileLang 等 DSL，凸显了 Modular 的高性能实力。

- 由 Modular Platform 驱动的 Inworld TTS 1 MAX 在 [Artificial Analysis 语音竞技场排行榜](https://artificialanalysis.ai/text-to-speech/leaderboard)上位居顶级表现，超越了 MiniMax Speech-02 系列和 OpenAI TTS-1 系列创下的基准。Modular 很自豪能为这一成就提供基础设施。

- Modular 联合创始人兼 CEO Chris Lattner 分享了他的 Swift 到 Mojo 之旅 🔥、让 AI 计算跨越 CPU 与 GPU 的愿景，以及 AI 如何提升而非取代软件工艺。相关内容见于 [The Pragmatic Engineer](https://newsletter.pragmaticengineer.com/p/from-swift-to-mojo-and-high-performance) 的访谈，以及与 [fast.ai 联合创始人 Jeremy Howard 的对谈](https://lnkd.in/dQSuYkd4)
- Modular 总裁兼联合创始人 Tim Davis 在一场关于构建可扩展 AI 系统的网络研讨会上做了分享，介绍 Modular、AMD、Supermicro 和 TensorWave 如何加速 AMD Instinct MI350 GPU 液冷系统上的 AI 工作负载。[观看回放](https://www.brighttalk.com/webcast/17278/655223)
- Modular 高级总监 Abdul Dakkak 在一场关于 NVIDIA 与 AMD GPU 光速推理（Speed of Light Inference）的演讲中展示了 Modular Cloud、MAX 和 Mojo，演示 Modular 如何高效扩展 AI 工作负载并降低 TCO。[观看视频](https://www.youtube.com/watch?v=2EWDG_Dxjs8)
