# Modular Platform 25.3：45 万+ 行开源代码与 pip 打包

今天我们很高兴宣布 Modular Platform 25.3——MAX 与 Mojo 作为一体化 AI 库与工具套件（旨在统一 AI 部署工作流）的重大进展。随着我们的**开源库**大规模扩展和全新的**统一 pip 包**，Modular Platform 25.3 让高性能 AI 更易得、更具社区驱动力。

## **🔓 开源 kernel、Mojo 标准库与服务 API**

Modular 25.3 中最引人注目的是，我们在 [Apache 2.0 许可证（含 LLVM 例外条款）](https://github.com/modular/modular/blob/main/LICENSE)下发布 [MAX AI kernels](https://github.com/modular/modular/tree/main/max/kernels)和完整的 [Mojo 标准库](https://github.com/modular/modular/tree/main/mojo/stdlib)。这些库包含数千行高性能、硬件优化的 Mojo 代码，包括面向各种 CPU 和 GPU 的生产级 kernel 实现——涵盖 NVIDIA 的 T4、A10G、L40、RTX 40 系列、Jetson Orin Nano、A100、H100 等。我们的量化方案包括 `Q4_K`、`Q4_0`、`Q6_K`、`GPTQ` 和 `FP8`，为高要求的工作负载提供高性价比的性能。

此外，我们还开源了 [MAX 服务库](https://github.com/modular/modular/tree/main/max/serve)——我们的推理服务器，支持 OpenAI 兼容 endpoint，实现大规模的高效 LLM 服务。这些发布共同构成一个开放、可扩展的 AI 推理栈，不受专有 GPU 依赖束缚。

通过公开这些新代码，**我们累计已开源超过 45 万行代码、来自近 6500 次贡献**，为开发者提供生产级的参考实现，以及用新算法、新操作和新硬件目标扩展 Modular Platform 的工具。有了这么多全新的高性能代码，你可以微调你的 LLM 来用 Mojo "vibe code"，释放现代 AI 硬件的全部威力。我们发现，把这些上下文全部提供给 [Claude Code](https://docs.anthropic.com/en/docs/claude-code/overview) 后，它写 Mojo 尤其强大！

**我们相信这是史上规模最大的 CPU 与 GPU kernel 开源！**为庆祝这次发布，Modular 正与 [AGI House](https://agihouse.ai) 和 [Crusoe GPU Cloud](https://crusoe.ai/) 合作，于 5 月 10 日在 Hillsborough 的 AGI House 举办一场[社区黑客松](https://app.agihouse.org/events/modular-hackathon-20250510)，聚焦用 Mojo 编写下一代 GPU kernel。

## **🐍 用 pip 简化安装并支持 Colab**

我们还发布了对 Modular Platform 的一项重大改进：基于 pip 的打包。只需简单的 `pip install modular`**，**你就能立即获得 Mojo——我们的高性能 CPU 与 GPU 编程语言，以及 MAX——我们的快速 AI 服务框架。这个 pip 包深化了我们与 Python 生态的集成，让你更容易开始用 Mojo 和 MAX 承载关键 AI 工作负载。

把 Modular 放上 PyPI 绝非易事，今天我们无比兴奋终于原生支持 pip。作为仅有的 100 家拥有 Enterprise PyPI 账户的公司之一，我们以直接的财务贡献支持着 Python 开发者生态，并承诺维持包质量、安全与文档的最高标准。

`pip install modular` 的发布还解锁了一个激动人心的新能力：在 [Google Colab](https://colab.research.google.com/) 中运行 MAX 模型和图。`modular` 稳定包支持在 Google Colab Pro 上使用 A100 或 L4 GPU 实例运行完整 LLM。我们最新的 nightly 构建还初步支持在 Colab 免费层的 T4 GPU 上用 MAX 图进行 GPU 编程。[在 Modular 论坛了解更多 Colab 支持信息](https://forum.modular.com/t/max-can-now-be-used-in-google-colab/1383)。

[Modular 的 pip 包今天即可获取](https://pypi.org/project/modular/)！现在就下载，并务必在 [Modular 社区论坛](https://forum.modular.com/)分享你开发出的精彩代码。

## **📓 面向新时代的更新版使用许可证**

为了让我们的技术更易得，我们[基于用户反馈](https://www.modular.com/blog/a-new-simpler-license-for-max-and-mojo)简化了 Mojo 与 MAX 的社区许可证。我们直白的分层结构让每个人都能在极少限制下自由使用 Mojo 和 MAX。[在此观看我们关于许可证更新的社区活动。](https://youtu.be/lJkHv0juxUE?feature=shared&t=460)

对于非生产-商用用途，一切免费。在任何设备上使用 Mojo 和 MAX 进行任何研究、爱好或学习项目。对于生产和商用，Mojo 与 MAX 在 CPU 和 NVIDIA GPU 上依旧免费——我们只请你分享你的成功故事。对于在非 NVIDIA 加速器上的商用部署，我们提供最多 8 台设备的免费使用权，超出该阈值有企业级选项。在其他平台上的扩展用例需要与平台厂商就最佳 MAX 分发方式达成协议。

这一更新体现了我们的承诺：开放构建、降低入门门槛、把社区放在首位——随着我们进入"Build with Modular"的新时代。简化许可证的完整细节见 [modular.com/pricing](https://www.modular.com/pricing) 和 [modular.com/legal/community](https://www.modular.com/legal/community)。
