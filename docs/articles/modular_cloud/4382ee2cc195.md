# Modular GPU Kernel 黑客松精彩回顾：创新、社区与 Mojo🔥

5 月 10 日，来自 AI 生态各环节的 100 多位工程师和研究人员齐聚加州希尔斯伯勒的 AGI House，参加我们的首届黑客松：一个节奏飞快、充满极客、学习与 Mojo 构建的日子。Modular GPU Kernel 黑客松把各种经验水平的开发者聚在一起，在现代 GPU 硬件上试验 Mojo、面对面协作，加速高性能 AI 基础设施的未来。

参与者解决了一系列问题，从底层 kernel 实现到完整的模型训练框架。很多参与者此前完全没有 Mojo 或 GPU 编程经验。到当天结束时，数十支队伍拿出了可运行的原型，并对 Mojo 的能力有了新的认识。

我们对这个社区在短短一天内完成的一切感到无比振奋！

# 获奖项目

## 第一名：Monolithic Sup

**团队**：Marcel Roed（斯坦福大学博士生）、Herman Brunborg（斯坦福大学博士生）与 Rajat Vadiraj Dwaraknath（斯坦福大学博士生）

Marcel 和团队挑战了本次黑客松最宏伟的课题之一。他们用 Mojo/MAX 搭建了一个训练框架，实现了从零训练一个 Transformer 模型所需的 kernel 和反向传播。这需要在 MAX 中实现反向传播，以及 AdamW 之类的梯度下降算法，还要弄清如何在 MAX kernel 库中使用 FlashAttention，并实现其导数以进行梯度训练。虽然他们在黑客松期间没来得及完整实现 FlashAttention、改用了标准缩放点积注意力，但他们仍在持续推进该项目，并计划很快完成实现。

> "先做出能用的东西，往往比一上来就追求速度更合理……能实时调试、和 Modular 员工一起讨论错误和解法太有趣了，因为我们在用 Modular 团队此前未曾探索过的方式使用 Mojo。" —— Herman

> "让 kernel 正确很难，弄清如何使用 FlashAttention 实现也相当有挑战。但我们证明了：用 Mojo 在短时间内从骨架起步，也能构建出有用的 SoTA 级工具。" —— Marcel

## 第二名：基于解耦回看（Decoupled Lookback）在 AMD MI300X 上快速实现前缀扫描算法

**团队**：Kirill Bobyrev（Waymo 软件工程师）

Kirill 的目标是为高性能 GPU 实现最优的并行前缀扫描算法——在这个过程中，他还帮助改进了 Mojo 的标准库。他的贡献包括 warp 级和 block 级扫描的全新正确实现，以及一个高效、可调的全设备扫描。这些更新现已纳入 Mojo 的开源仓库。

> "GPU 编程出了名的难，但 Mojo 让它出奇地愉悦。语言感觉很现代，它的模板和元编程特性支持快速实验，代码可读性极高——类似于 Rust 的标准库，与常常笨重的 C++ 标准库形成鲜明对比。" —— Kirill

更令人印象深刻的是，Kirill 在黑客松那一周之前从未写过一行 CUDA 或 Mojo。

### 第三名：用 Mojo 实现高斯泼溅（Gaussian Splatting）

**团队**：Sandeep Menon（Kodiak 深度学习软件工程师）与 Owen Leather（Kodiak 感知软件工程师）

高斯泼溅是一种渲染技术，此前只在 CUDA 上实现过。Sandeep 的团队旨在开拓新天地，把这个 kernel 移植到 Mojo，让它能运行在 AMD MI300X 等 GPU 上。虽然他们没能在活动结束时完全实现，但取得了长足进展，并在此基础上继续构建。

> "学习 Mojo、结识出色的 Modular 团队是一大亮点。在 AI 编程的时代写代码令人既敬畏又谦卑。我希望未来能受邀参加活动，多参加黑客松，作为开启新领域学习的方式。" —— Sandeep

# 更多黑客松项目

留到深夜展示作品的敬业黑客队伍 💪

除了获奖者，各队伍还用 Mojo 深入了一连串挑战：

- 基于有限差分模板（stencil）方法的热扩散 kernel
- GPU 加速的 BM25 排序算法
- 针对 YOLO 风格模型的优化非极大值抑制（NMS）实现
- 一项基准研究：不使用 barrier 或 synchronize 调用运行 Mojo kernel
- 用 Mojo 实现快速傅里叶变换（FFT）
- 针对小矩阵的求逆与 LU 分解 kernel
- 一个点积原语及相关的线性代数构件

许多参与者第一次编写 Mojo 或 GPU 代码，并热切地想在接下来的几周继续打磨他们的作品。我们为每一位参与黑客松的人感到无比骄傲。无论你是构建编译器、训练框架还是从零开始的 GPU kernel，你们的努力正是这个社区如此令人兴奋的原因！
