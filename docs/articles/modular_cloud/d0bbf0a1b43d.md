# Modular 开设爱丁堡与旧金山办公室

Modular 正在成长！我们在两座城市开设了办公室，它们与我们所做的事业有着深厚的渊源。

## 爱丁堡：坐落于 Bayes Centre 的家

我们的爱丁堡新办公室位于 [Bayes Centre](https://bayes-centre.ed.ac.uk/)——爱丁堡大学的数据科学与 AI 中心。研究人员、学生和企业在同一栋楼里共享空间，致力于把 AI 和数据科学转化为服务行业与社会的实用方案。

爱丁堡是 Modular 的天然归属。这座城市在计算机科学、编译器和编程语言研究方面根基深厚，而这些学科正是我们所做之物的定义。爱丁堡大学信息学院是欧洲规模最大、最受尊敬的计算机系之一，更广泛的苏格兰 AI 社区在机器学习、自然语言处理和系统工程领域产出了奠基性的工作。

Bayes Centre 让我们置身于这个社区的中心。这里既入驻了一批 AI 公司，也聚集了研究人员和 AI Accelerator、Venture Builder Incubator 等项目，全部在同一栋楼里。之所以选择这里，正是因为它紧邻活跃的研究与新兴人才。

我们的爱丁堡团队已经在扩张。入驻 Bayes Centre 的第一周，我们就在线下办理新员工入职、举行跨团队工作营。我们期待成为 Bayes Centre 社区的一部分：活动、协作，以及那种当你与解决相邻难题的人共享一栋楼时自然会发生的对话。

## 旧金山：Jackson Square

我们还在旧金山的 Jackson Square 社区开设了新办公室，作为继 Los Altos 总部之后的第二个湾区据点。旧金山让我们更接近 AI 人才、前沿模型提供商，以及正在打造下一代技术的基础设施公司。这个空间包含用于活动和客户会议的场地。很快你会看到我们在城里举办更多活动。

## Modular 做什么

每个 AI 团队都会撞上同一堵墙。你用 Python 做原型，因为它写得快；然后花上几个月用 C++ 和 CUDA 重写，以获得生产所需性能。你被锁死在一家硬件供应商上。扩展意味着买更多 GPU，而不是把手里的 GPU 用得更高效。

Modular 由 [Chris Lattner](https://nondot.org/sabre/)（LLVM、Clang、Swift 和 MLIR 背后的工程师）与 [Tim Davis](https://www.timdavis.com/)（曾在 Google Brain 领导 AI 基础设施，构建过 TensorFlow 及其背后的编译器和运行时栈）共同创立，为的是在基础设施层解决这个问题。

[**Mojo**](https://www.modular.com/mojo) 是我们的编程语言：Python 的可读性，加上编译级的裸机性能。会写 Python 就会写 Mojo，而你的代码运行速度快几个数量级。Mojo 免费使用，拥有数十万行开源代码和超过 5 万名开发者的社区。

[**MAX**](https://www.modular.com/max) 是我们的 AI 推理平台。它开箱支持数百种模型（Llama、DeepSeek、Mistral、用于图像生成的 FLUX），并提供 OpenAI 兼容的 API。由于 MAX 采用编译优先的方式而非手工调优的 kernel，同一份代码无需修改即可运行在 NVIDIA、AMD 和 CPU 硬件上。各团队如今正用 MAX 在生产环境中服务数十亿 token。

## 为什么这很重要

硬件正在快速多元化。新 GPU 架构、定制加速器、边缘设备层出不穷。而多数 AI 框架仍然假设你在跑 NVIDIA GPU + CUDA，移植到其他硬件需要数月的工程投入。

Modular 的编译器基础设施替你完成移植。新硬件到来时，技术栈随之适配。开发者专注于自己的模型和应用，而不是底层硬件管道。这是一个处在编译器、系统工程与 AI 交叉点上的问题——而爱丁堡恰恰一直在为这类工作培养顶尖人才。
