# 在 Mojo🔥 中调试

开发者工具是 Mojo 和 MAX 的重大优先事项，我们希望相比传统的 Python、C++ 和 CUDA 栈大幅改善调试体验。机器学习常常需要在长时间运行的过程之后检查程序状态，这需要的控制力远超 "print 调试" 所能给的。随着时间推移，这套工具将扩展到 GPU，让你能以同样顺畅的开发体验从 CPU 代码单步进入 GPU 调用。

本教程以 VS Code 为例，但可借助 [LLDB-DAP](https://lldb.llvm.org/resources/lldbdap.html) 适配到其他编辑器。它面向没有调试经验的人讲解通用调试，同时也会过一遍当前已实现的所有 Mojo 调试特性。目标是向你展示 Mojo 的调试多么简单而强大，让你摆脱"写 print、删 print"的循环，更快定位逻辑错误。

### 调试当前文件

首先确保你已安装 [Mojo 扩展](https://marketplace.visualstudio.com/items?itemName=modular-mojotools.vscode-mojo)；如果你装的是 nightly 编译器，则安装 [Mojo Nightly](https://marketplace.visualstudio.com/items?itemName=modular-mojotools.vscode-mojo-nightly)。

从在 VS Code 中启动调试器的最简单方式开始：点击某行左侧设置一个 *🔴 断点*，然后按右上角 *▶️ 运行* 按钮旁的 *⌄*，选择 *Debug Mojo File*：

注意：点击任何 GIF 可以放大，点击任意处或按任意键可最小化。

按 *|▶ Continue* 按钮会前进到下一个断点；如果循环中不断命中同一行代码，它会前进到循环的下一次迭代。

默认快捷键：

- *F5*：启动调试器（用此方式启动时，首次运行请选择 *Mojo*）
- *F5*：调试器已启动时，继续到下一个断点
- *Shift+F5*：停止调试会话
- *`Control+Shift+P`*（macOS 上为 *`Command+Shift+P`*）：重启调试会话
- ‍*F9*：切换当前行的断点

你也可以在终端中启动调试器：

Bash

mojo debug --rpc main.mojo

输入 *mojo debug --help* 获取更多选项。

### 单步进入、跳出与跳过

一个强大的特性是单步进入函数、跳出函数、以及跳过你设置的任何断点：

第一个动作是 *Step Into* 进入 *List.append* 方法，接着两次 *Step Over* 在后续表达式处断下，最后 *Step Out* 返回到原来的 *List.append* 断点。

默认快捷键：

- *F10*：Step Over（跳过）。
- *F11*：Step Into（进入）。
- *Shift+F11*：Step Out（跳出）。

### 监视（Watches）

有时你关心的局部变量不在 *Locals* 区域里，或者那里变量太多、你想把特定变量固定在列表顶部，又或者你想用一个表达式（例如对 list 做索引）。为此你可以按 *WATCH* 旁的 ✚ 按钮：

### 日志断点（Logpoints）

与其在程序里写 *print* 语句、还可能把它们提交进你的 PR，你可以使用日志断点表达式——它同样能通过 Mojo LSP 获得代码补全。在你通常设断点的位置简单右键，选择 *Add Logpoint*：

### 命中次数（Hit Count）

如果你想等 *x* 次迭代后断点才触发，可以使用 *Hit Count*。右键断点位置，选择 *Conditional Breakpoint*，然后把类型改为 *Hit Count*——示例中我选择第三次迭代。断点在当前行表达式执行之前触发，本例中即在第三个元素被加入 *List* 之前：

### 等待断点

如果你想跳过某个断点、直到另一个断点被触发后才生效，可以用这个功能。右键断点位置，选择 *Triggered Breakpoint*，然后选择你要等待的另一个断点：

### 自定义启动配置

如果你的程序较大、需要对调试启动配置有更多控制，或者你运行的是服务端+客户端、需要附加到某个进程，你可以创建一个 *launch.json* 文件。你也可以把它提交到仓库，方便其他人轻松启动调试会话。先按侧边栏的 Debug 图标，然后点击 *create a launch.json file* 并选择 Mojo，在 *.vscode/launch.json* 创建文件：

json

{
    "version": "0.2.0",
    "configurations": [
        {
            "type": "mojo-lldb",
            "request": "launch",
            "name": "Mojo: Debug current Mojo file",
            "description": "Launch and debug the Mojo file that is active on the editor when the debug session starts.",
            "mojoFile": "${file}",
            "args": [ ],
            "env": [ ],
            "cwd": "${workspaceFolder}",
            "runInTerminal": false
        },
        {
            "type": "mojo-lldb",
            "request": "launch",
            "name": "Mojo: Debug Mojo file",
            "description": "Launch and debug a Mojo file given its path.",
            "mojoFile": "${workspaceFolder}/[your-program.mojo]",
            "args": [ ],
            "env": [ ],
            "cwd": "${workspaceFolder}",
            "runInTerminal": false
        },
        {
            "type": "mojo-lldb",
            "request": "launch",
            "name": "Mojo: Debug binary",
            "description": "Launch and debug a precompiled binary given its path.",
            "program": "${workspaceFolder}/[your-binary]",
            "args": [ ],
            "env": [ ],
            "cwd": "${workspaceFolder}",
            "runInTerminal": false
        },
        {
            "type": "mojo-lldb",
            "request": "attach",
            "name": "Mojo: Attach to process",
            "description": "Search for a process to attach the debugger to.",
            "pid": "${command:pickProcessToAttach}"
        }
    ]
}

按 *Control + Space* 可以发现所有配置选项。记得把 *[your-program.mojo]* 和 *[your-binary]* 改成你的目标，并删掉你不需要的配置。

现在，在调试面板右上方选择一个启动配置，按 *F5* 即会运行它：
