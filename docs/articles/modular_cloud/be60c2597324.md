# Modular 正在如何民主化 AI 算力？（AI 算力民主化，第 11 篇）

在拥有时间、预算，以及一支[曾经构建过这个栈的](https://www.modular.com/blog/modulars-bet-to-break-out-of-the-matrix-democratizing-ai-compute-part-10)老兵团队的前提下，Modular 着手解决我们这个时代的定义性挑战之一：**如何让 AI 算力民主化**。但这*究竟*意味着什么——这一切如何拼成整体？

本文就是你的端到端导览。我们将走查技术、架构和底层哲学——之后的文章再逐层深入。

核心是一个单一理念：要让 AI 算力民主化，**我们需要统一 AI 世界四散的星辰**：

- 统一开发者——跨越背景与技能水平。
- 统一底层软件——跨越框架与运行时。
- 统一硬件厂商——跨越供应商、设备与用例。
- 统一一个利益相互竞争的行业——它长出了一个向单一主导厂商收敛的混乱软件栈。

长久以来，AI 软件版图是一片彼此失联的星空——点点创新的星光，但难以导航、更难连接，而且每年都在彼此远去。Modular 正在构建**把这片星空变成星座的基础设施**：一个连贯的系统，帮助开发者标定航路、把群星连成一体，释放 AI 的全部潜能。

AI 的成功不仅关乎你的硬件多强，还关乎有多少人能*用上*它。这意味着降低门槛、开放访问，并**构建人们乐意使用的软件工具**——而不只是跑 benchmark 的工具。

# 🌌 全球首座统一的 AI 星座

民主化 AI 算力，就是移除分裂版图的隐形[暗物质](https://en.wikipedia.org/wiki/Dark_matter)。今天，AI 的群星散落在厂商边界、孤岛式软件栈和过时抽象之中。我们都想要更高吞吐、更低延迟和 TCO，但 AI 开发者与部署者被迫二选一：“今天的安全押注”，还是用可移植性与通用性把命运握在自己手里。

在 Modular，我们相信存在更好的路——一条不需要开发者妥协的路：**我们正在奔向一个统一的星座。**

我们的目标是释放现代硬件的*全部能量*——NVIDIA 的 Tensor Cores、AMD 的矩阵单元、Apple 的先进统一内存架构——不是靠掩盖它们的复杂性，而是靠构建一个*理解*这种复杂性的系统。一个让开发者在客户端、数据中心和边缘设备之间从容扩展，而不至于迷失在不兼容编译器和碎片化运行时迷宫里的系统。

是时候超越 OpenCL 和 CUDA 这些诞生于 GenAI 前时代的遗留架构了。CUDA 开启了 AI 革命，[行业欠它很多](https://www.modular.com/blog/democratizing-ai-compute-part-3-how-did-cuda-succeed)。但未来需要更多：**一个从底层就为 GenAI 而生的软件栈**，为今天的工作负载、今天的开发者、今天的硬件与规模而设计。

这个星座[不可能由任何单一硬件厂商来统一](https://www.modular.com/blog/democratizing-ai-compute-part-9-why-do-hw-companies-struggle-to-build-ai-software)：厂商会为*自家*芯片做很好的软件——但星空远比这辽阔。它横跨 NVIDIA、AMD、Intel、Apple、Qualcomm 等，包括[硬件帆船赛 ⛵](https://www.modular.com/blog/democratizing-ai-compute-part-9-why-do-hw-companies-struggle-to-build-ai-software)诸强，以及 AI 硬件边疆上[一](https://www.cerebras.net/)[批](https://www.etched.com/)[正](https://groq.com/)[在](https://www.sifive.com/)[升起](https://tenstorrent.com/)[的](https://www.graphcore.ai/)[新](https://mythic.ai/)星。我们认为行业必须挽起手臂共建，而不是把星系撕得更碎。

在 Modular，我们用一条简单而宏大的目标来衡量成功：

> 我们想要一个统一、可编程的系统（一个小小的二进制！），能跨多家厂商的架构扩展——同时在最广泛使用的 GPU（和 CPU）上提供业界领先的性能。

这就是统一星座的含义：不是千篇一律——而是连贯、协作、集体的动能。一个礼赞硬件多样性、同时交给开发者一张共同海图的系统——凭这张海图，他们能构建、能探索、能抵达比以往更远的地方。

## Mojo🔥：面向异构 GenAI 计算的编程语言

[**Mojo**](https://www.modular.com/mojo) 是为 GenAI 时代而生的新语言，旨在解决 AI 的语言碎片化问题。开发者喜爱 Mojo，因为它提供 C++、Rust 和 CUDA 的速度与能力，却带着 AI 开发者熟悉的、易学的 Python 语法。

Mojo 无缝融入现有工作流——Mojo 文件与 Python 模块并肩共存，无需绑定层或额外构建工具——同时解锁现代硬件：CPU、GPU 和定制加速器。无论你是打造 FlashAttention 这样的高级 GPU kernel、利用 Tensor Cores 与 TMA，还是以底层控制实现 AI 专属优化，它都给开发者极大的灵活与易用。

> Mojo 就像太阳系的内行星——贴近炽热，贴近金属。性能住在这里，FLOPS 在这里轰鸣。

虽然 Modular 聚焦 AI，但我们相信 Mojo 加速*既有* Python 代码的能力，会把高性能 GPU 编程向**多出数百万的开发者**开放，跨越各个领域。我们期望 Mojo 成为所有领域开发者“扩展 Python 代码的最佳方式”。

## MAX 👩‍🚀：建模与服务层

环绕 Mojo 运行的是 [**MAX**](https://www.modular.com/max)——统一的、生产级的 GenAI 服务框架，回应了 Mojo 可移植性引出的那个自然追问：“为什么不直接用 PyTorch？”MAX 去 PyTorch 到不了的地方，把最先进推理打包进一个约 1 GB、冷启动极快的精简容器。

GenAI 远不止一次前向传播。现代管线要平衡 KV-cache 生命周期、分页注意力、投机解码和硬件感知调度。MAX 把所有这些复杂性收进一个熟悉的、类 PyTorch 的 Python API——你写动态图，它交付可预测的机群级性能。

> 把 MAX 想象成你 GenAI 太阳系里的巨行星。计算是中央恒星，MAX 那关于 KV-cache 处理、分页注意力和投机解码的深厚“大气层”，提供了引力质量，让一个个 AI 应用保持在有序轨道上，也让新模型或新硬件能无扰动地漂移进来。

为异构集群而生的单个 MAX 二进制，能从今天的 H200、B200 和 MI325 中榨取峰值吞吐，并延伸到明天的 MI355 和 B300，甚至 CPU/GPU 混布。激进的批处理与内存优化带来最高的每美元 token 数；消除意外的重编译与 kernel 切换，让延迟在尖峰负载下依然平稳——把研究 notebook 变成生产就绪的 GenAI 服务，不牺牲速度、灵活性或硬件选择。

## Mammoth 🦣：GenAI 时代的 GPU 集群管理

[**Mammoth**](https://www.modular.com/mammoth) 是一个 **Kubernetes 原生**平台，把固定的 GPU 资源——无论本地还是云端——变成弹性的高性能推理织物。

GenAI 把优化压力推向了栈的更上层：现代 transformer 模型把 pre-fill 与 decode 阶段拆分到*许多*GPU 上，击碎了两条旧的云假设。其一，负载不再无状态——聊天机器人和智能体需要保留对话上下文。其二，GPU 不能随需拉起；它们是绑定多年承诺的容量受限资产，每一 TFLOP 都必须用在刀刃上。

因为 **Kubernetes 已经是企业信赖的控制面**，Mammoth 直接落入现有集群，叠加团队缺失的能力：

- **MAX 感知的编排**：Mammoth 与 MAX 协同实现即时弹性扩缩、pre-fill 与 decode 节点的智能放置，以及快速 checkpoint 流式传输。
- **动态多硬件调度**：把多厂商的加速器集群当作单一资源池，实时把负载装箱到最合适的芯片上。
- **统一的声明式运维模型**：为本地与云端集群暴露一个 API，让平台团队扔掉定制调度器和手搓脚本。

结果是一个**简单、可扩展的编排层**，让 CIO 们无需厂商锁定即可拥抱异构硬件——而开发者全程留在他们已经熟悉的 Kubernetes 工作流里。

> Mammoth 就像星系的螺旋臂——一个统摄多个太阳系的引力框架。Mammoth 的调度引力让每个太阳系平滑、可预期地自转，为新“恒星”或“行星”（硬件与负载）腾出位置，而从不撼动整个星系的稳定。

Mojo、MAX、Mammoth 每一层都能独立成立，合在一起则构成 GenAI 计算的一张**连贯银河地图**：跨硬件、跨时间地可扩展、可靠、可移植。

## 💠 高性能模型与 Kernels

Modular 平台不止是 CUDA 替代品——它是一个发射台，在两类截然不同的人群工作的地方迎接他们：

- **AI 工程师与 MLOps 团队要生产就绪的资产。** 我们交付完整、开源、预先调速的模型管线，打包进约 1 GB 容器，在 CPU 与 NVIDIA 或 AMD GPU 上不做修改即可运行。
- **AI 研究者与 kernel 黑客渴望底层控制。** 我们的 GitHub 仓库 `modular/modular` 开放手工优化的 GPU kernels——FlashAttention、分页注意力、KV-cache 编排、投机解码——全部用 Mojo 编写，你可以调内部细节，也可以发明全新算子而不必重写整个栈。

因为每个模型和 kernel 都坐在同一个运行时上，你可以从成熟的构件快速起步，只在需要时才潜到底层。结果是当今规模最大、连贯一致的可移植开源 AI 组件库——对只想交付的企业团队足够强大，对推动前沿的研究者足够模块化。

> 把这些模型管线想象成绕太阳系飞驰的彗星——是让基础设施有意义的内容本身。

开源仍是 AI 进步的基石；统一的生态确保你能从一个强大的起点出发，走得更远——无论是周一上线一个功能，还是周五发表一篇论文。
