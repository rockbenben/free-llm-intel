# Modular 26.5：Mojo 1.0 来了！

今天，Mojo 语言正式抵达 1.0：这是自 2023 年首次发布以来，这门语言一路构建、逐步抵达的里程碑。Mojo 已成长为一门通用语言，拥有充满活力的开发者社区，在其之上编写自己的库、工具和应用。随着 Mojo 1.0，开发者现在可以在稳定、生产就绪的语言底座之上开展长期开发。

## Mojo 1.0：生态增长的稳定基石

Modular 通过广泛的内部使用快速演进了 Mojo 语言。但这种推进速度也带来了一个权衡：频繁变更让社区难以维护长期项目。

正如我们[首次宣布 Mojo 1.0 路线图](https://www.modular.com/blog/the-path-to-mojo-1-0)时所述，它的首要目标是提供一个开发者可以依托的稳定基础。我们今天兑现这一承诺，因为 Mojo 已经就绪：它不再只是我们正在开发的一门语言，而是我们每天在生产环境中依赖、作为我们商业基础设施 MAX 和 Modular Cloud 基石的一门语言。

重要的是，Mojo 1.0 并不标志着语言演进的终结，而是更漫长旅程上的一个重要里程碑。在 1.x 周期内，变更应当主要是新增性的，让开发者确信语言不会在他们脚下持续变动。破坏性变更仍可能发生，但会被审慎管理，遵循成熟语言（如 C++）随时间演进的标准。

然而，这个里程碑同样属于我们了不起的社区，而不只是我们。自我们开源标准库以来，近 200 位贡献者合入了 1,100 多个 pull request，改动了超过 20 万行代码，还有上千人提交了影响语言走向的 issue。向每一位提交 issue、开 pull request、撰写语言提案或构建包的开发者说声：谢谢你，与我们一同担任这门语言的设计师。

## 26.5 中的 Mojo 改进

本版本的很大一部分工作专注于完成 Mojo 1.0 所需的收尾——这是我们过去几个版本一贯的主线：让语言更一致、更可预测、更平易近人。

凡是 Mojo 提供多种表达同一想法方式的地方，我们都收敛为一种。变量现在统一用 var 声明，闭包被统一，只有一个 Pointer 类型，并且一系列重命名让 Mojo 的词汇更精确、更一致。

本版本完成了这最后一轮语言简化与清理，赋予 Mojo 1.0 我们希望开发者能在未来数年持续构建的稳定、连贯基础。

除这些基础工作之外，Mojo 1.0 还包含自上一个 beta 版本以来的若干新功能与改进：

- Mojo 现在支持 Python 风格的 "lambda" 语法来写内联闭包。
- Mojo LSP 服务器更加稳定可靠，极大改善了你在 VS Code 及其他编辑器中的日常体验。
- [Mojo AI Skills](https://github.com/modular/skills) 现已"1.0 ready"，覆盖新项目创建、GPU 编程、从其他语言移植等。
- Mojo 现在能诊断涉及引用失效的内存安全问题，例如注意到 List.append 使一个指向 list 内部的引用失效。
- "where" 子句在标准库中运用得更一致，并允许携带描述性消息，使失败更可行动。

这些只是几处亮点。完整变更列表见 [mojolang.org](http://mojolang.org/) 上的 [Mojo changelog](https://mojolang.org/releases/v1.0.0/)。

## Mojo 接下来走向何方

Mojo 1.0 是一个重大里程碑，但我们对这门语言的规划远不止于此。Mojo 已经确立了自己作为编写跨现代 CPU、GPU 和加速器的高性能代码的强大语言的地位。其演进的下一阶段是拓宽这一基础，把 Mojo 打造成一门真正出色的通用系统编程语言。

这意味着持续投资核心语言与开发者体验，未来的重要能力包括健壮的异步编程模型、模式匹配与联合类型等等。你可以在 [Mojo 路线图](https://mojolang.org/docs/roadmap/)中看到我们努力的方向。

最后，我们将持续逐步开源更多 Mojo 语言本身，以及我们用 MAX 构建的相关组件。我们的承诺不变——我们将在 2026 年开源 Mojo 编译器和工具链。

## 26.5 中的 MAX 增强

虽然 Mojo 1.0 是本版本的亮点，26.5 也为 MAX 带来了改进。

MAX 的安装现在更容易：用 `max["serve"]` 和 `max["benchmark"]`（在 conda 下为 `max-serve` 和 `max-benchmark`）只安装你需要的依赖，或用 `max["all"]` 安装全部内容。`modular` 包将在 26.6 中退役。

MAX 还新增支持两个模型家族：GLM-5.2 和 Nemotron-H，二者都是混合 Mamba-2 模型。Kimi 2.5 现在也能配合 Module V3 使用——这是我们简化的模型编写路径。

最后，[我们的开源 agent skills 合集](https://github.com/modular/skills)是上手本版本的好方式。我们在内部已用这些 skills 加速完整模型生命周期的 bring-up，它们通过 skills.sh 已获得 7.2K+ 下载。

完整更新列表见 [MAX changelog](https://docs.modular.com/releases/v26.5/)。

## 开始使用 26.5 与 Mojo 1.0

安装或升级，几分钟内上手：

bash

```
uv pip install --upgrade mojo

uv pip install max[all]
```
