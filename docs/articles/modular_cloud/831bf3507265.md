# 培育 Modular 生态：Modular 社区资助计划

Alister Burt

社区

今年早些时候，我们发布了[社区项目提案征集](https://forum.modular.com/t/introducing-the-modular-community-grant-program/2941)，用小额资助支持那些正在构成生态基础的 Mojo 和 MAX 库。我们收到了大量各类贡献者的来信，拿到的优质提案数量远超我们所能支持的范围。

以下是我们当前正在支持的项目：

## [noeira](https://github.com/denislabs/mojo-rl)

**Denis Laboureyras (**[@denislabs](https://github.com/denislabs)**)**

*noeira* 创建于 2026 年初，是一个完全用 Mojo 编写的开源强化学习（RL）框架。该项目目前支持 40+ 种 RL 算法、GPU 加速的深度 RL、自定义 2D/3D 物理引擎、原生街机游戏引擎以及 SDL3 渲染。

它的诞生源于对 Python 强化学习技术栈中性能断崖的不满。这个项目的长期目标，是提供一个完全端到端的 RL 框架，让环境、智能体和训练全部以纯 Mojo 运行在 GPU 上。

近期，该项目计划发布与成熟 RL 技术栈（*Gymnasium*、*Stable Baselines3*、*PyTorch*）对标的严格基准测试，以此量化采用纯 Mojo 路线所获得的性能收益。

[在此观看 Denis 的社区例会分享。](https://www.youtube.com/watch?v=gvDEC5_iEb4&list=PLh0S94-sJw_6UcaIMgpESb5KSVRsuuhnX&index=1)

## [**bajo**](https://github.com/jgsimard/bajo)

**Jean-Gabriel Simard (**[**@jgsimard**](https://github.com/jgsimard)**)**

*bajo* 是一个并行物理仿真器，其设计目标是让数千个 RL/机器人训练环境在单张 GPU 上同时运行。该项目已经交付了一套业界领先的 GPU 排序实现（Morton 编码 + BVH 构建），作为其计算底座。

未来六个月的计划是把那个排序层打包成型，实现高性能的并行碰撞检测与刚体动力学。随后将其扩展为一个可运行的数千环境原型，并与 NVIDIA 的 *Warp* 和 *Madrona* 进行基准对比。

[在此观看 Jean-Gabriel 的社区例会分享。](https://www.youtube.com/watch?v=Fps_baqJg8E&list=PLh0S94-sJw_6UcaIMgpESb5KSVRsuuhnX&index=2)

## [**Fast Fourier Transform**](https://github.com/martinvuyk/hackathon-fft)

**Martin Vuyk Loperena (**[**@martinvuyk**](https://github.com/martinvuyk)**)**

这是一套快速傅里叶变换（FFT）实现，在 CPU 和 GPU 上都已接近业界领先性能，可分别与 *FFTW* 和 *cuFFT* 竞争。项目始于 2025 年中期的一场黑客松，此后一直在持续演进。

近期目标包括加入半尺寸变换支持（hC2R、R2hC），并在已经支持的 R2R、C2R 和 R2C 变换上争取彻底的性能胜出。如果剩余的差距能够被抹平，MAX 对 *cuFFT* 的依赖就有望被完全移除。

[来 11 月的社区例会观看 Martin 关于他的 FFT 实现的分享。](https://luma.com/nov-modular)

## [**EmberJson**](https://github.com/bgreni/EmberJson)

**Brian Grenier (**[**@bgreni**](https://github.com/bgreni)**)**

*EmberJson* 是当今 Mojo 生态中使用最广泛的 JSON 解析库。这个包大量依赖 Mojo 的反射能力，同时支持结构化和非结构化解析。

其路线图指向一个秉承 Rust 的 *Serde* 思路的通用序列化框架，同时持续推进 Python 互操作。尽管存在互操作开销，早期基准测试已经显示它的速度快于 Python 内置的 JSON 处理。

[参加我们 10 月的社区例会，听 Brian 更多讲讲他在该项目上取得的进展。](https://luma.com/oct-modular)

## [**floki**](https://github.com/thatstoasty/floki)

**Mikhail Tavarez (**[**@thatstoasty**](https://github.com/thatstoasty)**)**

*floki* 是一个易于使用的 Mojo HTTP 客户端，构建在 *libcurl* 绑定之上。该项目已经支持 Python 的 *requests* 模块用户熟悉并喜爱的许多特性。当前的开发重点是：以更顺手的方式访问高级 *libcurl* 配置，并简化底层绑定的实现。

[在此观看 Mikhail 的社区例会分享。](https://www.youtube.com/watch?v=gvDEC5_iEb4)

## [**momanim**](https://github.com/josiahls/momanim)

**Josiah Laivin (**[**@josiahls**](https://github.com/josiahls)**)**

*momanim* 是受 [*Manim*](https://github.com/3b1b/manim) 启发、为 Mojo 打造的 2D 动画框架。该项目旨在利用 CPU 和 GPU 加速大幅缩短渲染时间，并追求与 Manim 的 API 足够接近，使得由 LLM 辅助的 Python 到 Mojo 转换切实可行。项目还处于起步阶段：基础的图像/视频 API 和形状渲染已经就位，3D 渲染 API 是路线图上的下一步。

[锁定 10 月的社区例会，听 Josiah 谈谈 momanim。](https://luma.com/oct-modular)

## 未来的轮廓

把这些项目放在一起看，正是 Modular 社区在 Mojo 与 MAX 持续发展中所走向之处的一个切片：底层基础设施，以及令人兴奋的应用。我们感谢社区里的每一个人推动着平台向前，也迫不及待想看到你们接下来会做出什么。
