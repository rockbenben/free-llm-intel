# AI Agents for AWS Marketplace

Modular Team

Product

***Modular Inc.**** announces the availability of two Modular Platform applications in the new AWS Marketplace AI Agents and Tools category: ****MAX High-Performance GenAI Serving ****and**** MAX Code Repo Agent****.*

**San Francisco, CA** -- **July 16, 2025** -- Modular Inc., a leading provider of AI infrastructure and high-performance compute solutions, today announced the availability of two Modular Platform applications,** MAX High-Performance GenAI Serving Platform** and the **MAX Code Repo Agent**, in the [new AI Agents and Tools category of AWS Marketplace](https://aws.amazon.com/marketplace/solutions/ai-agents-and-tools/). Customers can now use AWS Marketplace to easily discover, purchase, and deploy AI agent solutions, including Modular's AI inference and development productivity solutions, all using their AWS accounts, thereby accelerating agent and agentic workflow development.

Modular Platform helps organizations accelerate AI inference deployment with 10x performance improvements, optimize GPU utilization across NVIDIA and AMD hardware, and streamline development workflows with intelligent code assistance. This enables customers to deploy production-ready AI applications with industry-leading speed and efficiency while maintaining complete control over their AI infrastructure.

*"By offering MAX and Code Repo Agent in AWS Marketplace, we're providing customers with a streamlined way to access our high-performance AI infrastructure solutions, helping them deploy and scale agentic solutions faster and more efficiently,"* said Tim Davis, President at Modular. *"Our customers in financial services, healthcare, and enterprise software development are already using these capabilities to achieve 10x faster inference speeds, reduce operational costs by up to 40%, and accelerate development cycles, demonstrating the real-world value of unified AI infrastructure platforms."*

[**MAX High-Performance GenAI Serving**](https://aws.amazon.com/marketplace/pp/prodview-t6oswipky4fhs) delivers essential capabilities, including over 500 pre-optimized models, OpenAI-compatible API integration, and cross-platform GPU acceleration. These features enable customers to deploy production-grade AI applications with minimal code changes while achieving industry-leading performance across NVIDIA and AMD hardware.

[**MAX Code Repo Agent**](https://aws.amazon.com/marketplace/pp/prodview-y6sus6r2riy6e) provides repository-aware Q&A capabilities, automatic documentation generation, and intelligent code assistance. This enables customers to accelerate development cycles and improve code quality through AI-powered developer productivity tools.

Key technical differentiators include:

- **GPU-native inference engine** built with innovative Mojo kernels, eliminating CUDA dependencies.
- **Cross-platform compatibility** across NVIDIA A100, H100, H200, L40, L4, A10, and AMD MI300X accelerators.
- **OpenAI-compatible REST API** for seamless integration with existing applications.

With the availability of AI Agents and Tools in AWS Marketplace, customers can significantly accelerate their procurement process to drive AI innovation, reducing the time needed for vendor evaluations and complex negotiations. With centralized purchasing using AWS accounts, customers maintain visibility and control over licensing, payments, and access through AWS.

To learn more about **Modular Platform** in AWS Marketplace, visit [**AWS Marketplace Modular listings**](https://aws.amazon.com/marketplace/seller-profile?id=seller-hcgoj6obnqlhs)** - **[**MAX Container**](https://aws.amazon.com/marketplace/pp/prodview-t6oswipky4fhs) and [**Code Repo Agent**](https://aws.amazon.com/marketplace/pp/prodview-y6sus6r2riy6e).

*About ****Modular Inc.*** ***Modular is building the world's best AI infrastructure company, founded by a team with decades of experience from leading engineers who have built AI infrastructure across the stack at major technology companies. The company's mission is to reimagine AI infrastructure through the MAX platform and Mojo programming language, enabling organizations to build, deploy, and scale AI applications with unprecedented performance and simplicity.***
