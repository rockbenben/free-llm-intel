# MAX 25.2：释放你 H200 的全部算力——不需要 CUDA！

我们很高兴宣布 **MAX 25.2**——一次重大更新，为最大的语言模型解锁业界领先性能——*完全从零构建、不使用 CUDA*。

本次发布延续了仅一个月前 [MAX 25.1](https://www.modular.com/blog/max-25-1-introducing-max-builds) 的势头，交付了支撑更快、更敏捷、更可定制的规模化 GenAI 部署的关键特性：

- **H100 与 H200 上的业界领先性能**：支持[超过 500 个 GenAI 模型](https://builds.modular.com/)。
- **多 GPU 支持**：[无缝运行](https://builds.modular.com/models/Llama-3.3-Instruct/70B)超出单卡显存的大型 LLM。
- **增强的 LLM 服务**：改进的调度、批处理与缓存进一步优化了 TCO 与性能——在数值完全一致的情况下，MAX 在 Sonnet 基准上已比 vLLM 0.8 快 12%。
- **用于快速部署的超精简容器（"without CUDA"）**：[比 NVIDIA 容器小 80%](https://docs.modular.com/max/container#base-container)——是部署到生产环境的理想选择。
- **用 Mojo 🔥 解锁 GPU 编程**：MAX 允许你用 Mojo 编写自定义的[高性能 GPU 代码](https://docs.modular.com/mojo/manual/gpu/basics)，直接访问 NVIDIA GPU。
- **高级特性**：包括 GPTQ 量化，高效运行最大的模型。

MAX 25.2 是我们使命中的一座里程碑：构建一个**无 CUDA 的 GenAI 模型推理平台**，让单一异构技术栈给你不打折扣的性能与掌控力。

## **多 GPU + H100/H200 支持：以业界领先性能运行超大 LLM**

本次发布的头条特性是在 NVIDIA H100 和 H200 上的完整多 GPU 支持，让你能以惊人性能运行更大的语言模型。你现在就可以直接从 MAX Builds 把 Llama-3.3-70B-Instruct 部署到多块 GPU 上。

安装 [`max-pipelines`](https://docs.modular.com/stable/max/max-pipelines/) 后，用一条简单命令在 4 块 GPU 上以 `bfloat16` 运行一个 700 亿参数的模型：

Bash

max-pipelines generate \
  --model-path=meta-llama/Llama-3.3-70B-Instruct \	
  --quantization-encoding bfloat16 \
  --devices gpu:0,1,2,3 \
  --prompt="Design a self-sustaining colony on Neptune's moon Triton..."

`‍`为了给 AI 带来"即插即用"的简单体验、同时不剥夺你对 AI 的掌控力，我们从底层重建了整个 AI 技术栈——包括所有在 GPU 上运行的软件。为此，我们面向复杂的 H100/H200 架构实现了所有 GenAI GPU 算法，性能追平并超越 NVIDIA 库。你无需操心这些，但这意味着你可以忘掉 CUDA 的版本错配和它的历史包袱！

Bash

max-pipelines generate \
  --model-path hugging-quants/Meta-Llama-3.1-70B-Instruct-GPTQ-INT4 \
  --prompt "Why is the sky blue?" \
  --max-batch-size 1 --max-length 10000

## **LLM 服务改进**

本次发布在我们的 LLM 服务能力之上进一步新增：

- **前缀缓存感知的批调度**：调度器可以在大量 prompt token 已缓存时创建更大的批次，某些基准中吞吐量提升最高 10%。
- **飞行中批处理（in-flight batching）**：允许把 token 生成请求与上下文编码一起调度，降低 token 间延迟。
- **写时复制 KV block**：集成进带 Prefix Caching 的 Paged Attention，通过优化缓存命中提升性能。

这些改进给你带来更好的性能与能力，而且继续"即插即用"。

## **精简 Docker 容器：部署快前所未有**

速度不仅体现在推理，也体现在部署。由于 MAX 模型不使用 CUDA 构建，我们不必背着它的重量。[我们新的精简 Docker 容器](https://docs.modular.com/max/container/#base-container)把服务容器的体积压缩到仅 1.3 GB（压缩后），即使是最大的模型也能闪电般部署。让你的 AI 应用以创纪录的速度跑起来，且不牺牲性能。
