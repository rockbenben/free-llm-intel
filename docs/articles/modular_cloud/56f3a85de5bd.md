# Modverse #51：Modular x Inworld x Oracle、Modular 聚会回顾与社区项目

这个月 Modular 社区热闹非凡：从我们 Los Altos 聚会的演讲、全新公开的工程文档，到与 Inworld 和 Oracle 的重大进展。在本期 *Modverse* 中了解亮点、新教程和开源贡献。

# **博客、教程与视频**

- 错过了 Modular 聚会？在线观看演讲！我们的 Los Altos Modular 聚会把 AI 专家和建设者聚在一起，度过了一个充满前沿工程洞见的夜晚。从 AI 算力普惠化、生产就绪的语音 AI，到矩阵乘法优化，演讲现已向所有人开放观看。演讲包括：
[Chris Lattner，Modular](https://www.youtube.com/watch?v=I0_XvXXlG5w)——AI 算力普惠化的未来，以及开放协作在加速进步中的角色。​[Feifan Fan，Inworld AI](https://www.youtube.com/watch?v=PCKXHijq99c)——如何把最先进的语音 AI 集成进消费级应用并做到生产就绪，包含 Inworld 与 Modular 合作的洞察。​[Chris Hoge，Modular](https://www.youtube.com/watch?v=crOKTQ7_4Zs)——为什么矩阵乘法仍是计算机科学中最具挑战的问题之一，以及 Modular 技术栈如何帮助开发者优化它。

- 在我们的 [9 月社区会议](https://www.youtube.com/watch?v=TmHM7Gtjjk0&t=38s)上，我们邀请了 Mojo 团队进行问答，讨论最近发布的 Mojo 愿景与路线图文档。我们还聆听了 Bernardo Taveira 的 "Porting GSplat Kernels to Mojo" 和 Seif Lotfy 的 "Datastructures for DB Development"。

‍

- ‍[Modular x Inworld x Oracle。](https://www.youtube.com/watch?v=OiSMQUOXaH4)看我们如何通过与 Inworld 和 Oracle Cloud 的合作，帮 Inworld 把 TTS 成本削减 70%、性能提升 4 倍——首次同时解锁 NVIDIA 和 AMD GPU。

- 查看更多现已公开的内部工程文档：
[WGMMA Programming](https://modular.github.io/modular/wgmma-programming/)[Elementwise Operations on GPUs](https://modular.github.io/modular/elementwise-ops/)

- 探索我们关于 NVIDIA Blackwell 上矩阵乘法（matmul）kernel 的四部曲系列：带你用 Mojo 编写高性能 GPU kernel，揭示先进优化技术，并提供最大化 NVIDIA Blackwell GPU 性能的分步蓝图。
[Part 1: Introduction](https://www.modular.com/blog/matrix-multiplication-on-nvidias-blackwell-part-1-introduction)[Part 2: Using Hardware Features to Optimize Matmul](https://www.modular.com/blog/matrix-multiplication-on-nvidias-blackwell-part-2-using-hardware-features-to-optimize-matmul)[Part 3: The Optimizations Behind 85% of SOTA Performance](https://www.modular.com/blog/matrix-multiplication-on-nvidias-blackwell-part-3-the-optimizations-behind-85-of-sota-performance)[Part 4: Breaking SOTA](https://www.modular.com/blog/matrix-multiplication-on-blackwell-part-4---breaking-sota)
