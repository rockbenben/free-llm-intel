# 介绍 MAX 24.6：一个 GPU 原生的生成式 AI 平台

[三年前](https://www.modular.com/blog/the-future-of-ai-depends-on-modularity)，我们着手重新定义 AI 的开发与部署方式。我们的目标不只是改进现有系统，而是[从零重建 AI 基础设施](https://www.modular.com/blog/the-future-of-ai-depends-on-modularity)，交付一个性能更强、可编程、可移植的基础设施平台。我们认识到，要应对当下的挑战并跑赢快速的技术演进，就必须从第一性原理彻底重构 AI 技术栈。

大规模生成式 AI 的到来，改变了 AI 基础设施的本质。为满足其飞速增长的资源需求，GenAI 需要从上到下整个层级的创新——从 GPU 编程的最底层一直到服务层——而这只有 Modular 有定位去做。

今天，我们宣布这段旅程的第一步来应对这些挑战：**MAX 24.6**，带来 **MAX GPU** 的预览。这次 GPU 发布展示了 MAX 平台的力量，只是我们在迈向 2025 年为 AI 基础设施带来诸多进展的开端。我们希望你与我们同行，在未来几个月我们继续为世界推进 AI 基础设施时，和我们一起开发。

## 介绍 MAX GPU：新的 GenAI 原生服务栈

[MAX 24.6 发布](https://docs.modular.com/max/changelog)的核心是 MAX GPU——首个垂直整合的生成式 AI 服务栈，消除了对 NVIDIA CUDA 这类厂商专用计算库的依赖。

MAX GPU 建立在两项突破性技术之上。第一项是 MAX Engine——一个高性能 AI 模型编译器与运行时，为 NVIDIA GPU 用创新的 Mojo GPU kernel 构建——不受 CUDA kernel 依赖束缚。第二项是 MAX Serve——一个专为 LLM 应用打造的、精密的 Python 原生服务层。MAX Serve 精巧地处理复杂的请求批处理与调度，即便在高负载下也能交付一致可靠的性能。

不同于只解决 AI 工作流某个特定环节的工具，MAX 旨在支持完整的开发体验——从最初的实验，经过部署，一直到生产。MAX 提供一个统一平台，用于探索新模型、测试与优化，并[交付此前只能靠拼凑旧技术才能获得的高性能推理能力](https://www.modular.com/blog/max-gpu-state-of-the-art-throughput-on-a-new-genai-platform)。

### 企业级、从开发到部署的灵活性

MAX Engine 支持跨多种硬件平台的灵活推理部署，让开发者先在笔记本上本地实验，再无缝扩展到生产云环境。结合 MAX Serve 原生的 Hugging Face 模型支持，团队可以快速开发、测试并部署任意 PyTorch LLM。自定义权重支持（含 Llama Guard 集成）进一步让开发者为特定任务定制模型。

当把模型投入生产时，MAX Serve 提供一个 OpenAI 兼容的客户端 API，装进可在 NVIDIA 平台上运行的紧凑 Docker 容器。随后团队可以把模型部署到 AWS、GCP、Azure 等所有主流云，方式既有 [直接 VM 部署](https://docs.modular.com/max/tutorials/max-serve-local-to-cloud/)，也有 [企业级 Kubernetes 编排](https://docs.modular.com/max/tutorials/deploy-max-serve-on-kubernetes/)。这种灵活性确保你能安全地托管自己的模型，把 GenAI 基础设施完全掌控在自己手里。

这套工作流的核心是 [Magic](https://docs.modular.com/magic/)——Modular 的命令行工具，简化整个 MAX 生命周期。Magic 处理从安装、环境管理，到开发与部署的一切——让管理 AI 基础设施更容易。[在此阅读更多关于 Magic 的信息](https://docs.modular.com/magic/)。

### 高性能 GenAI 模型与硬件可移植性

我们还用新的高性能模型扩展 MAX 的能力。这些模型对 Llama、Mistral 等许多流行 LLM 提供了优化实现。[在 NVIDIA GPU 上开箱运行时，MAX 在标准吞吐量基准上追平了成熟 AI 服务框架 vLLM 的性能。](https://www.modular.com/blog/max-gpu-state-of-the-art-throughput-on-a-new-genai-platform)这些模型还支持一系列量化方案，我们正为此原生 MAX 模型合集在未来几周和几个月内定义 SOTA 性能而加倍努力。

行业标准的 [ShareGPTv3](https://blog.vllm.ai/2024/09/05/perf-update.html) 基准展示了 MAX GPU 搭配 Llama 3.1 的性能能力，仅用 MAX 创新的 NVIDIA kernel，在 [**NVIDIA A100 GPU 上达到 3860 输出 token 每秒**](https://www.modular.com/blog/max-gpu-state-of-the-art-throughput-on-a-new-genai-platform)——**GPU 利用率超过 95%**。目前我们尚未使用 PagedAttention 这类优化就已达到这一水平——它将于明年年初落地。这一切都在说明我们才刚刚起步，我们的数字只会持续改进，而且[我们自己来跑这些基准也很容易](https://docs.modular.com/max/tutorials/benchmark-max-serve/)。

MAX GPU 首发支持 NVIDIA A100、L40、L4 和 A10 加速器——它们是 LLM 推理的行业标准、市场上优化最充分的 GPU——H100、H200 和 AMD 支持将于明年年初到来。

### 为硬件可移植性而生

下一步是带来 AMD MI300X GPU 的支持，我们正在打磨，预计很快交付。MAX 的 NVIDIA 与 AMD kernel 建立在同一种底层技术之上，使我们能快速支持新的硬件平台。关于我们 AMD 适配的激动人心的细节即将分享，并将在 2025 年初持续扩展我们的 AMD 支持。
