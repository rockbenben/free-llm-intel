在处理 PyTorch 模型时，你可能会在特定操作遇到性能瓶颈，它们能从自定义优化中获益。你也可能想试验新的 GPU 算法，或实现标准框架尚未提供的前沿研究想法。与其重写整个模型或更换框架，你可以用 Mojo 编写高性能 kernel，并把它们集成进现有的 PyTorch 工作流，在熟悉的开发环境中同时实现优化与实验。

本教程演示如何通过用 Mojo 实现一个自定义灰度图像转换操作来增强 PyTorch 模型。你会发现：既能保留熟悉的 PyTorch 开发体验，又能为计算密集型操作解锁 Mojo 带来的性能收益。

在本教程中，你将学习如何通过集成一个 Mojo 自定义 op 并在 PyTorch 中运行，把 RGB 图像转换为灰度图像。

## 搭建环境[​](https://max.modular.com/develop/custom-kernels-pytorch/#set-up)

首先创建一个 Python 项目并安装所需工具。

- pixi / uv

- 如果尚未安装，请安装 [`uv`](https://docs.astral.sh/uv/)：`curl -LsSf https://astral.sh/uv/install.sh | sh`，然后重启终端使 `uv` 可用。创建项目：`uv init pytorch_custom_ops && cd pytorch_custom_ops`。创建并启动虚拟环境：`uv venv && source .venv/bin/activate`。安装带全部依赖的 `max`（nightly；要获取稳定版请在网站页头切换版本）及其他所需包：`uv add "max[all]" torch pillow numpy \ --index https://whl.modular.com/nightly/simple/ \ --prerelease allow`

这会安装 `max` 包，以及 PyTorch（`torch`）、用于图像处理的 PIL（`pillow`）和用于数组操作的 NumPy。安装 `max` 包后，你就能访问 MAX Python API 和 Mojo 编译器——构建高性能自定义操作所需的一切。

## 构建 PyTorch 接口[​](https://max.modular.com/develop/custom-kernels-pytorch/#build-the-pytorch-interface)

先创建我们集成方案的 PyTorch 一侧。我们会构建一个使用自定义操作的简单函数，但需要先建立接口。

新建一个名为 `grayscale.py` 的文件，加入以下代码：

🐍 grayscale.py

```
from pathlib import Path
import torch

@torch.compile
def grayscale(pic: torch.Tensor):
    output = pic.new_empty(pic.shape[:-1])  # Remove color channel dimension
    # We'll call our custom operation here
    return output
```

`grayscale` 函数把彩色图像（含红、绿、蓝通道）转换为单通道灰度图像。虽然 PyTorch 内置了相应操作，但把它实现为 Mojo 自定义 op 能展示可套用于任何性能关键计算的集成模式。接下来需要桥接到我们的 Mojo 实现。

## 集成自定义操作[​](https://max.modular.com/develop/custom-kernels-pytorch/#integrate-the-custom-operation)

[`max.experimental.torch`](https://max.modular.com/api/python/experimental.torch/) 模块提供了 [`CustomOpLibrary`](https://max.modular.com/api/python/generated/max.experimental.torch.CustomOpLibrary/)，让你能在 PyTorch 中直接加载并使用编译好的 Mojo 操作。

更新 `grayscale.py`，加入以下代码：

🐍 grayscale.py

```
from pathlib import Path
import torch
from max.experimental.torch import CustomOpLibrary

# Load the compiled Mojo package containing our custom operations
mojo_kernels = Path(__file__).parent / "operations"
ops = CustomOpLibrary(mojo_kernels)

@torch.compile
def grayscale(pic: torch.Tensor):
    output = pic.new_empty(pic.shape[:-1])  # Remove color channel dimension
    ops.grayscale(output, pic)  # Call our Mojo custom op
    return output
```

`CustomOpLibrary` 从预编译的 Mojo 包文件（`.mojoc`）加载操作。加载后，你可以像调用其他 PyTorch 函数一样调用这些操作。这些操作会自动处理 PyTorch 与 MAX 之间的数据搬运，并在需要时与 PyTorch 集成。

你的 Mojo 代码编译为 `.mojoc` 文件的过程在你运行 Python 脚本时自动完成，无需手动调用 Mojo 编译器或管理构建步骤。

## 实现 Mojo kernel[​](https://max.modular.com/develop/custom-kernels-pytorch/#implement-the-mojo-kernel)

接下来是核心实现——我们的高性能 Mojo kernel。我们创建一个定义灰度转换操作的 Mojo 包。

首先，在 `operations` 文件夹里创建一个空的 `__init__.mojo` 文件。这个文件把该文件夹标记为一个 Mojo 包，这是 `CustomOpLibrary` 的要求：

```
touch operations/__init__.mojo
```

然后在 `operations` 文件夹中创建 `grayscale.mojo` 文件，加入以下代码：

🔥 grayscale.mojo

```
import extensibility

from max.gpu.host import DeviceContext
from extensibility import InputTensor, OutputTensor, foreach

from std.utils.coord import Coord, coord_to_index_list
from std.utils.index import IndexList


@extensibility.register("grayscale")
struct Grayscale:
    """Convert RGB image tensor to grayscale using weighted formula."""

    @staticmethod
    def execute[
        target: StaticString,  # "cpu" or "gpu"
    ](
        img_out: OutputTensor[dtype=.uint8, rank=2, ...],
        img_in: InputTensor[dtype=.uint8, rank=3, ...],
        ctx: DeviceContext,
    ) raises:
        """Execute grayscale conversion on the input image tensor.

        Args:
            img_out: Output tensor for grayscale image (height x width).
            img_in: Input tensor for RGB image (height x width x channels).
            ctx: Device context for execution.
        """

        @__parameter
        @inline(.always)
        def color_to_grayscale[
            simd_width: Int
        ](idx: Coord) -> SIMD[.uint8, simd_width]:
            """Convert RGB pixel to grayscale using perceptual weighting.

            Args:
                idx: Index into the output tensor (row, col).

            Returns:
                Grayscale value as SIMD vector.
            """

            @__parameter
            def load(
                idx: IndexList[img_in.rank],
            ) -> SIMD[.float32, simd_width]:
                return img_in.load[simd_width](idx).cast[.float32]()

            var idx_l = coord_to_index_list(idx)
            var row = idx_l[0]
            var col = idx_l[1]

            # Load RGB values from input tensor
            var r = load(IndexList[3](row, col, 0))
            var g = load(IndexList[3](row, col, 1))
            var b = load(IndexList[3](row, col, 2))

            # Apply standard grayscale conversion formula
            # These weights are based on human visual perception
            var gray = 0.21 * r + 0.71 * g + 0.07 * b

            # Clamp to valid uint8 range and convert back
            return min(gray, 255).cast[.uint8]()

        # Execute the conversion using parallel foreach
        foreach[color_to_grayscale, target=target, simd_width=1](img_out, ctx)
```

首先，`@extensibility.register("grayscale")` 装饰器让这个操作以 `grayscale` 的名字对 PyTorch 可用。它就是 PyTorch 模型里调用的 `ops.grayscale(output, pic)` 函数。

`color_to_grayscale` 函数接收一个输出张量坐标，返回灰度值的 SIMD 向量。[`foreach`](https://max.modular.com/api/mojo/extensibility/managed_tensor_slice/foreach/) 原语会自动把操作并行化到可用的计算单元上。

最后，`target` 参数让同一份代码可以同时运行在 CPU 和 GPU 上。

这种方式让 Mojo 负责底层优化细节——内存布局、向量化和并行化——而你专注于算法本身。

## 运行示例[​](https://max.modular.com/develop/custom-kernels-pytorch/#run-the-example)

现在我们有了 PyTorch 模型和 Mojo kernel，可以用真实图像测试了。

在项目根目录创建 `main.py`，加入以下代码：

🐍 main.py

```
import io
import numpy as np
from PIL import Image
import torch
from grayscale import grayscale

# Specify a test image
image = Image.open("test_image.jpg")
# Convert to PyTorch tensor and move to GPU for processing
image_tensor = torch.from_dlpack(np.array(image)).cuda()

# Apply our custom grayscale operation
gray_image = grayscale(image_tensor)

# Convert back to PIL Image for display or further processing
result = Image.fromarray(gray_image.cpu().numpy())
```

你可以用以下命令运行示例：

```
python main.py
```

下图展示了灰度操作的结果。

这个示例演示了完整流水线：加载图像、转换为 PyTorch 张量、用我们的 Mojo 自定义 op 处理、再转回标准 Python 图像格式。该操作会在可用时自动利用 GPU 加速，相比纯 CPU 实现带来显著的性能提升。
