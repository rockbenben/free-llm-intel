# Modverse #55：Mojo 1.0 Beta、社区 Mojo 库，以及由 MAX 驱动的实时患者对话

上个月的 26.3 版本让 Mojo 1.0 Beta 转正、为 MAX 添加了 Wan 2.2 视频生成，并把 [mojolang.org](http://mojolang.org/) 作为 Mojo 文档新家上线。社区也紧跟步伐：Decimo v0.10.0、Mojo 科学计算库 MSL、Thistle 和 mojo-kafka 都进入了 [modular-community 频道](https://github.com/modular/modular-community)，[Hippocratic AI 正用 MAX 推理运行实时患者对话](https://www.modular.com/blog/hippocratic-ai-partners-with-modular-to-power-flexible-high-quality-inference-for-real-time-patient-conversations)，[AI agent 构建了后端零 Python 的可用 Mojo 应用](https://www.modular.com/blog/how-i-built-a-pure-mojo-app-and-10-libraries-with-ai-agents)。以下是本月汇总。

## 社区创新

上个月社区用 MAX 和 Mojo 构建的东西：

- [**Decimo v0.10.0**](https://forum.modular.com/t/decimo-just-hit-v0-10-0-mojo-v1-0-0b1/3085)**：** Yuhao Zhu 把他的任意精度小数库更新到 Mojo v1.0.0b1，带来该项目迄今最大的发布。v0.10.0 新增：CLI 计算器的 REPL 模式（可通过 Homebrew 安装）、优化后的 `Decimal128`（语义与 Python `decimal.Decimal` 兼容）、基于 MPFR 的任意精度浮点类型 `BigFloat`，以及新的 `Rational` 类型。发布中的基准显示 `Decimal128` 性能与 Rust 的 `rust_decimal` 相当、在 ULP 精度上更优。用 `pixi add decimo` 安装，或在 [GitHub](https://github.com/forfudan/decimo) 上找到代码。

Decimo v0.10.0：用 Mojo 构建的交互式任意精度 REPL 计算器

- [**Mojo Scientific Library (MSL) v0.1.0**](https://forum.modular.com/t/mojo-scientific-library-msl-v0-1-0-release/3087)**：** MSL 的首个稳定版发布——这是 GNU Scientific Library 的 Mojo 移植，覆盖数值积分、微分、插值和统计例程。现已在 modular-community conda 频道提供。代码在 [GitHub](https://github.com/mojomath/MSL)。
- [**Thistle：Mojo 原生加密库**](https://forum.modular.com/t/thistle-native-crypto-library-written-in-mojo/3082)**：** Thistle 是一个纯 Mojo 加密库，支持 ED25519 和 X25519。现已上架 modular-community 频道。仓库在[这里](https://github.com/libalpm64/Thistle)。
- [**mojo-kafka：Mojo 的 Apache Kafka 客户端**](https://forum.modular.com/t/mojo-kafka-apache-kafka-client-for-mojo-over-librdkafka/3067)**：** dvirarad 基于 librdkafka 为 Mojo 构建了一个 Kafka 客户端，配有 Pythonic 的生产者与消费者 API。让 Mojo 工作负载连接 Kafka，无需 Python 中间层。项目在 [GitHub](https://github.com/dvirarad/mojo-kafka)。
- [**Light of Baldr**](https://forum.modular.com/t/light-of-baldr-a-full-pure-mojo-web-stack-a-gpu-multi-pattern-matching-kernel-11-repos-on-mojo-1-0/3101)**：** Adam Kruger 发布了一批 Mojo 1.0 仓库，涵盖一个 web 技术栈、一个 GPU Aho-Corasick 多模式匹配 kernel，以及安全工具。见 [github.com/lightofbaldr](http://github.com/lightofbaldr)。

💡 在用 MAX 或 Mojo 构建什么？分享到 [Community Showcase](https://forum.modular.com/c/community-showcase/8)，我们可能会在这里刊登。

## Modular 的动态

- [**Modular 26.3：Mojo 1.0 Beta、视频生成与文档新家。**](https://www.modular.com/blog/modular-26-3-mojo-1-0-beta-max-video-gen-and-more) 5 月 7 日的 26.3 发布带来了首个官方 Mojo 1.0 beta（v1.0.0b1），还为 MAX 添加 Wan 2.2 视频生成、推出 LayoutTensor 的继任者 TileTensor 用于 GPU kernel 开发、上线 [mojolang.org](http://mojolang.org/) 作为 Mojo 专属文档站点，并引入了分布式张量与安全闭包。
- [**Hippocratic AI 与 Modular 合作。**](https://www.modular.com/blog/hippocratic-ai-partners-with-modular-to-power-flexible-high-quality-inference-for-real-time-patient-conversations) Hippocratic AI 现已在 MAX 推理上运行实时患者对话。迁移到 MAX 让 NVIDIA B300 硬件上的平均端到端延迟快了 22%。![](https://cdn.prod.website-files.com/68c9c3107effc2ea46e1a81f/6a29a3949618434859f16d2a_Hippocratic.png)
- [**Inkwell：为什么推理基础设施与模型同等重要。**](https://www.modular.com/blog/inkwell-why-your-inference-platform-matters-as-much-as-your-model) Modular 发布了一份案例研究，用其实时 AI 故事书应用 Inkwell 展示底层推理平台能带来什么。论点很务实：模型质量与推理质量都是约束，而且它们并不独立。来 [inkwell.modular.com](http://inkwell.modular.com/) 体验应用。
- [**用 AI agent 把代码翻译成 Mojo。**](https://www.modular.com/blog/translating-to-mojo-via-ai-agents) 一篇新博客完整走了一遍借助 AI agent 把 Python 和 C++ 代码迁移到 Mojo 的过程，包括工作流在哪里可靠、哪里仍需人工审查。
- [**AI agent 如何构建纯 Mojo 应用和 10 个库。**](https://www.modular.com/blog/how-i-built-a-pure-mojo-app-and-10-libraries-with-ai-agents) 一篇后续文章讲了 mobin——一个用 Mojo 构建、后端零 Python 的 pastebin 服务，通过与 AI agent 协作写成。文章还包含用同样方式构建的 10 个支撑库，以及从 AI 辅助视角看 Mojo 1.0 Beta 开发是什么样子。

## Modular 新闻与活动：保持连接

- **Mojo 标准库的新贡献流程。**从 26.3 开始，非平凡的 stdlib PR 需要先开 issue。先开 issue，等待 `accepted` 标签，然后再写代码。此举是为了防止贡献者把真功夫花在停滞或无法合入的变更上，团队承诺在 48-72 个工作小时内响应 issue。拼写修正、文档修复和小型 bug 修复仍可直接提 PR。如果你在找朝 Mojo 1.0 贡献的方向，该帖子列出三个优先领域：在 stdlib 全面应用稳定性标记、审计方法上的 custom-Self 类型、改进 Python-Mojo 互操作。完整细节见[论坛公告](https://forum.modular.com/t/updating-our-contribution-process-for-the-mojo-stdlib/3060)。
- **Mojo 1.0 Beta 追踪。**Mojo 1.0.0b1 已发布。随着稳定版临近，请关注[nightly 发布帖](https://forum.modular.com/c/nightly)和 [Mojo 路线图](https://docs.modular.com/mojo/roadmap/)保持同步。
- **月度社区会议。**社区会议每月举行，线上且公开。在 [Luma](https://lu.ma/modular-ai) 报名，想展示的话把自己加进[议程](https://docs.google.com/document/d/1Hdy52tJXbUR2jZSYt-IFdaEJRRBHvHCQkODAZnuXsNc/edit?tab=t.0#heading=h.hthojob043vc)。
