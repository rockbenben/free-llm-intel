# Modverse #48：Modular 平台 25.3、MAX AI Kernels 与 Modular GPU Kernel 黑客松

五月是一阵狂风骤雨：重大开源发布、满满的线下活动、硬核技术内容！

我们从 5 月 6 日发布的 **Modular 平台 25.3** 开启这个月——开源 AI 的一个重大里程碑。这次发布包含超过 45 万行 Mojo 与 MAX 代码，涵盖完整的 Mojo 标准库、MAX AI Kernels 和 MAX 服务库。全部开源，用 `pip install modular` 几秒即可完成安装，无论你是本地工作还是在 Colab 上用 A100 或 L4 GPU。

这份势能延续到了现实世界：我们在 Los Altos 的 Modular 总部举办了首场社区 Meetup，并在 AGI House 举办了首届 GPU Kernel Hackathon——100 多位工程师与研究者聚在一共建、共学，挑战 Mojo 与 MAX 的极限。

继续往下读，查看这个满满当当的月份的全部亮点：演讲、教程、技术深潜、开源项目等。

# 博客、教程与视频

- 本月早些时候，来自 AI 生态各处的 100 多位工程师与研究者齐聚加州 Hillsborough 的 AGI House，参加 Modular GPU Kernel Hackathon！黑客开始前，我们有幸聆听了全明星讲者阵容。查看全部演讲录像：[Democratizing AI compute together: Chris Lattner, CEO of Modular](https://www.youtube.com/watch?v=-zpsg72FcCc)[Open GenAI on AMD: Ramine Roane, CVP of AI at AMD](https://www.youtube.com/watch?v=bq4i_D2xjK8)[A Hundred PyTorch Backends: Mark Saroufim, cofounder of GPU MODE & software engineer at Meta](https://www.youtube.com/watch?v=OJG2k0vVjP4)[triton_lite, a Triton clone in Mojo: Jeff Niu, member of technical staff at OpenAI](https://www.youtube.com/watch?v=zUwyO2PZisw)[Claude on Three Accelerators: Simon Boehm and Sasha Krassovsky, members of technical staff at Anthropic](https://www.youtube.com/watch?v=-k6yikkxQqI)来看[黑客松精彩集锦](https://www.youtube.com/watch?v=FSBnDzMwOKs)和[完整回顾博文](https://www.modular.com/blog/modular-gpu-kernel-hackathon?utm_source=x&utm_campaign=community)，其中列出了获奖项目。
- 没能亲临我们在 Los Altos Modular 总部的 meetup？通过 [Chris Lattner 与 Jack Clayton 演讲录像](https://www.youtube.com/watch?v=uul6hZ5NXC8)看看现场发生了什么。
- Chris Lattner 与 Abdul Dakkak 在最近一期 GPU MODE 直播中对 Mojo 做了马拉松式（2 小时以上！）深潜。别错过[这场干货满满的录像](https://www.youtube.com/watch?v=yOMflrCRya0)——关于 Mojo 的能力与我们对高性能 GPU 编程的愿景，满是 🤯 时刻。
- 想旁听我们的内部技术分享吗？机会来了！[Modular Tech Talks](https://www.youtube.com/watch?v=MEoGt_cxNSs&list=PLh0S94-sJw_6ygGMynvQkt32IwBJM4DBW) 是一个独家系列，收录工程团队的内部演讲，讲解我们技术栈的内在工作机制。[Kernel Programming and Mojo🔥](https://www.youtube.com/watch?v=Invd_dxC2RU) 探索 Mojo 编译器的独特架构，分享我们团队如何应对现代 GPU 开发的挑战。[MAX Graph Compilation to Execution](https://www.youtube.com/watch?v=MEoGt_cxNSs) 展示 MAX 图编译器如何利用 Mojo 优雅平衡性能、控制与易用性，带来开发动态模型的新路径。
- 现在你可以从最新 nightly 版本直接在 Python 中调用 Mojo 代码！无需重写既有 Python 项目即可享用 Mojo 的性能红利。[更新后的 Mojo 手册](https://docs.modular.com/mojo/manual/python/mojo-from-python/) 讲解其底层原理，[GitHub 仓库中的示例](https://github.com/modular/modular/tree/main/examples/python_mojo_interop) 让你上手实操——甚至包含从 Python 调用运行在 GPU 上的 Mojo 代码的示例。
- Mojo 现已支持 [LeetGPU](https://x.com/LeetGPU/status/1925076979428057380) 和 [Tensara](https://x.com/tensarahq/status/1924876628737589396) 的 GPU 挑战！是时候用 Mojo 技能登顶排行榜了。
- 通过解 GPU 谜题学习 Mojo GPU 编程：从[这里](https://builds.modular.com/puzzles/introduction.html)开始，[完成谜题可赢贴纸](https://forum.modular.com/t/releasing-mojo-gpu-puzzles/1373)。解锁我们刚上线的章节[理解 GPU 性能：Roofline 模型](https://builds.modular.com/puzzles/puzzle_14/roofline.html)，探索用于理解 GPU 优化的可视化性能模型。第三部分通过 MAX Graph 自定义算子与 Python 交互，[从 1D 卷积算子开始](https://builds.modular.com/puzzles/puzzle_15/puzzle_15.html)。
- 在[社区会议 #16](https://www.youtube.com/watch?v=-MNPowZ7xYE)中，团队分享了 Modular 平台 25.3 的重要更新、重大开源消息以及更新后的 Mojo 路线图。
- Chris Lattner 受邀参加 Kevin Ball 的 [Software Engineering Daily 播客](https://softwareengineeringdaily.com/2025-05-22/mojo-and-building-a-cuda-replacement-with-chris-lattner/)，谈他的工程历程与当下在 AI 基础设施及 Modular 方方面面的工作。
- 我们的仓库[本月在 GitHub 上 trending](https://github.com/trending/?since=monthly)！
- Mojo 的参数系统帮你编写灵活、类型安全的代码且不增加运行时开销。[Brian Grenier 近期的客座博客](https://www.modular.com/blog/metaprogramming?utm_campaign=community&utm_source=modverse)深入其工作原理，附真实示例与 Mojo 编译器输出的 LLVM IR。
- 在[GPU 编程入门视频系列第 3 集](https://www.youtube.com/watch?v=694uegmao1o)中，你将学习 Mandelbrot 集合如何定义、如何用 Mojo 实现计算并在 GPU 上运行。
- 补更“AI 算力民主化”系列的最新篇：[第 9 篇](https://www.modular.com/blog/democratizing-ai-compute-part-9-why-do-hw-companies-struggle-to-build-ai-software)剖析阻碍硬件公司构建有竞争力 AI 软件的因素。[第 10 篇](https://www.modular.com/blog/modulars-bet-to-break-out-of-the-matrix-democratizing-ai-compute-part-10)回顾 Modular 三年埋头研发，我们如何把栈重新设计为“AI 开发者优先”，以及应对这一巨大挑战所用的策略。
- Electronic Engineering Times 近期[报道了我们如何让 GPU 兼具性能与可移植性、把 AI 还给开发者](https://www.eetimes.com/after-three-years-modulars-cuda-alternative-is-ready/)。
