# Modverse #47：MAX 25.2 与 Modular 总部的 GPU 编程之夜

MAX 25.2 正在引来众人侧目——且事出有因。这次强力更新为 NVIDIA GPU 上的大语言模型带来业界领先的性能，全程无需 CUDA。MAX 25.2 延续了 25.1 的势能，引入多项大升级，助你构建更快、更精简、更易扩展的 GenAI 系统。亮点包括：

- H100 与 H200 GPU 上的最先进性能
- 多 GPU 支持
- 增强的 LLM 服务
- 用于快速部署的超精简容器
- Mojo 驱动的 GPU 编程
- GPTQ 量化等高级特性

想亲眼看看？4 月 **24** 日来 **Modular 总部**参加一个专为 Mojo 与 MAX GPU 编程打造的夜晚：[**Next-Gen GPU Programming: Hands-On with Mojo & MAX**](https://lu.ma/modular-meetup?utm_source=modverse)。听 Chris Lattner 与 Jack Clayton 分享，结识同行开发者，探索这些工具如何重塑 AI 的可能性。

如果还没看过，别忘了[最新一期社区会议录像](https://www.youtube.com/watch?v=lJkHv0juxUE)——内容包括 MAX 与 Mojo 许可证的重要更新、Kelvin（Mojo 的类型安全量纲分析库）现场演示，以及团队 Q&A。

# 博客、教程与视频

- MAX 25.2 在 NVIDIA GPU 上交付业界领先性能，从底层构建、不使用 CUDA，驱动更快、更灵敏、更可定制的规模化 GenAI 部署。详见[**发布博客**](https://www.modular.com/blog/max-25-2-unleash-the-power-of-your-h200s-without-cuda?utm_source=modverse)。
- 补更 Chris Lattner 的“AI 算力民主化”系列：第 5 篇 [**CUDA C++ 替代方案（如 OpenCL）怎么样？**](https://www.modular.com/blog/democratizing-ai-compute-part-5-what-about-cuda-c-alternatives?utm_source=modverse)探讨 CUDA 的 C++ 替代方案为何未能在 AI 中立足、面临的挑战以及对 GPU 编程未来的关键教训。第 6 篇 [**AI 编译器（TVM 与 XLA）怎么样？**](https://www.modular.com/blog/democratizing-ai-compute-part-6-what-about-ai-compilers?utm_source=modverse)拆解 kernel 融合如何提升性能、AI 编译器为何在 GenAI 负载上吃力，以及是什么阻碍了 TVM 和 XLA 完全释放 GPU 性能或民主化 AI 算力。第 7 篇 [**Triton 与 Python eDSL 怎么样？**](https://www.modular.com/blog/democratizing-ai-compute-part-7-what-about-triton-and-python-edsls?utm_source=modverse)审视 Python eDSL 并深入 Triton——该领域最受欢迎的方法之一——以及其他几个项目。第 8 篇 [**MLIR 编译器基础设施怎么样？**](https://www.modular.com/blog/democratizing-ai-compute-part-8-what-about-the-mlir-compiler-infrastructure?utm_source=modverse)中，Chris Lattner 讲述 MLIR 编译器框架的创始故事：如何起步、改变了什么、以及一路上的权力博弈。
- 准备好用 Mojo 让你的 GPU 轰鸣了吗？Mojo 手册刚刚升级——新增[**GPU 编程深度讲解**](https://docs.modular.com/mojo/manual/gpu/basics/?utm_source=modverse)，面向从资深 GPU 开发者到完全新手的所有人。
- 看看我们的新 recipes——用 MAX 部署 GenAI 的分步指南：[GPU Functions in Mojo](https://builds.modular.com/recipes/gpu-functions-mojo?utm_source=modverse)[Custom Operations: An Introduction](https://builds.modular.com/recipes/custom-ops-introduction?utm_source=modverse)[Custom Operations: Optimizing Matrix Multiplication](https://builds.modular.com/recipes/custom-ops-matrix-multiplication?utm_source=modverse)[Custom Operations: Applications In AI Models](https://builds.modular.com/recipes/custom-ops-ai-applications?utm_source=modverse)[Code Executor Agent With E2B Sandbox](https://builds.modular.com/recipes/code-execution-sandbox-agent-with-e2b?utm_source=modverse)[Auto Documentation Agent For GitHub Repository](https://builds.modular.com/recipes/autodoc-repo-chat-agent?utm_source=modverse)[AI Agent with DeepSeek-R1, AutoGen And MAX Serve](https://builds.modular.com/recipes/deepseek-qwen-autogen-agent?utm_source=modverse)[Use AnythingLLM and Llama3.1 With MAX Serve](https://builds.modular.com/recipes/max-serve-anythingllm?utm_source=modverse)
- [**MAX 25.2 直播**](https://www.youtube.com/watch?v=dG0L1GalIHU)应有尽有：Connor 的 Mojo 魔法、Brad 的 MAX 洞见、Tim 的创始人愿景、Modular 亮相 NVIDIA GTC 回顾，以及与团队的现场 Q&A。
- 错过 Chris Lattner 在 Modular NVIDIA GTC 展台的闪电演讲？[**录像**](https://www.youtube.com/watch?v=d89mHSeN_QE)已上线 YouTube。几分钟内，Chris 剖析了 GPU 编程被什么拖住——以及 MAX 与 Mojo 如何让它重新变得快速、可扩展、对开发者友好。
- [**社区会议 #14**](https://www.youtube.com/watch?v=KphrTiT-vPo)包括 Chris Lattner 就其“AI 算力民主化”系列的 Q&A、Brian 演示他的 Conway's Game of Life MAX 自定义算子，以及 Hammad 关于 CombustUI（一个 Mojo GUI 库）的分享。
- [**社区会议 #15**](https://www.youtube.com/watch?v=lJkHv0juxUE)上，我们宣布了 MAX 与 Mojo 许可证的关键更新，并欣赏了新 Mojo 类型安全量纲分析库 Kelvin 的现场演示。
