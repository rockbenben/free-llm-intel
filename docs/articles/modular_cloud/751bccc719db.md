# Modular 26.6：开放编译器贡献、音频生成与扩展模型支持

Modular 26.6 是我们在 ModCon 开源 Mojo 编译器之后的首个版本。随着 Mojo 1.1，我们在这条路上迈出下一步：向外部贡献开放编译器，并把更多开发工作迁移到 GitHub 仓库中。

MAX 26.6 扩展了对音频生成的支持，加入新的前沿模型，并在 NVIDIA 和 AMD GPU 上带来显著性能提升。我们也在积极推进生态联盟计划，并计划在 2026 年底启动（联系 [alliance@modular.com](mailto:alliance@modular.com) 了解更多信息）。

# **Mojo 1.1：编译器现已接受贡献**

在 8 月的 ModCon 上，我们宣布了 [Mojo 编译器在 Apache 2.0 许可证下开源](https://www.modular.com/blog/mojo-open-source)。开放源码是第一步，今天我们很高兴宣布 [Mojo 编译器开始接受贡献](https://github.com/modular/modular/blob/main/Mojo/docs/contributing/contribution-areas.md)！

这是我们在 Mojo 编译器开源后收到的呼声最高的请求之一，感谢你在我们搭建好相应基础设施期间的耐心等待。为了让你更容易跟进进行中的工作并与 Modular 团队直接协作，我们把内部 issue 迁移到了[公开的 GitHub issues](https://github.com/modular/modular/issues)。

Mojo 1.1 在 Mojo 1.0 的基础上，带来了大量编译器、语言和开发者体验方面的改进：

- **编译时间加速**：隐式转换的编译以及 t-string 字面量的使用有所改进。
- **LSP 改进**：编译器会对常见的差一（off-by-one）拼写错误给出建议。

- **上下文类型推断**：当类型可以推断时，允许把 `DType.float32` 这样的声明简写为 `.float32`。
- **OSS 目录组织：**统一的[顶层 Mojo 目录](https://github.com/modular/modular/tree/main/Mojo)，包含编译器和标准库，并附上一份[开源 Mojo 协作新指南](https://mojolang.org/community/contributing/)。

完整语言和工具链改进列表见 [Mojo 1.1 changelog](https://mojolang.org/releases/v1.1.0/)。

# MAX 26.6：新模态与新模型，性能更快

MAX 的开发在快速推进，我们致力于让 MAX 源码可用。在 26.6 中，我们扩展了 MAX 以支持音频输出模态，新增了若干前沿模型，并在 NVIDIA 和 AMD GPU 上带来显著性能改进。

**音频模型生成支持：**MAX 现在支持音频生成，扩展到文本、视觉和图像生成之外。`audio_generation` 流水线首发支持 MiniMax-Music3 (`MiniMaxAI/MiniMax-Music3`)，这是一个文本转音乐模型，从风格提示和歌词生成 44.1 kHz 立体声音频。音频生成可通过 `/v1/audio/speech` 和 `/v1/responses` API endpoint 访问，并支持控制时长、去噪步数、引导比例（guidance scale）和输出格式。

**模型架构支持：**MAX 26.6 增加了对新前沿模型架构的支持，同时扩展了现有模型系列的能力。包括支持 Thinking Machines 的 Inkling (`InklingForConditionalGeneration`) 架构，以及对 Kimi、Qwen、Gemma 和 GLM 模型系列的改进。投机解码技术（如 DFlash 和 DSpark）现已在 MAX 内支持，同时改进了工具调用和数据类型支持。

**性能改进：**MAX 在各类硬件和工作负载上提升性能，在众多代表性基准上取得广泛收益。在 NVIDIA B200 上，这些优化带来 Gemma 4 decode attention 最高快 4.8×、MoE 路由最高快 7.9×、低批次 NVFP4 量化最高快 16×。在 AMD MI355 上，decode attention 投影最高快 6.6×，而 MXFP8 QKV 投影相比上一版最高快 4.8×。

完整更新列表（包括额外模型支持、服务改进和投机解码控制）见 [MAX 26.6 changelog](https://max.modular.com/releases/v26.6/)。

# **开始使用 26.6 与 Mojo 1.1**

安装或升级，几分钟内上手：

bash

```
uv pip install --upgrade mojo

uv pip install max[all]
```

如 26.5 中所宣布的，`modular` 包在本版本中退役。请改为安装 `max["all"]` 获取全部内容；如果你只需要一个 endpoint，安装 `max["serve"]`；如果你只需要对 endpoint 做基准测试，安装 `max["benchmark"]`（在 conda 下使用 `max-serve` 或 `max-benchmark`）。
