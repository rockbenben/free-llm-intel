# 用 MAX 24.6 与 Hugging Face 评估 Llama Guard

想象一下：既打开开放创新的世界，又能确保 Gen AI 部署安全、可靠、达到企业级——MAX 24.6 让企业 AI 团队能在 NVIDIA GPU 上无缝运行来自 [Hugging Face](https://huggingface.co/) 的大量前沿 AI 模型。

MAX 24.6 引入了一组基于 MAX Graph API 构建的高性能模型。这些 MAX 图是领先模型架构的精准实现，包括 [Llama](https://www.llama.com/)（通过 `LlamaForCausalLM` 兼容）。在 Hugging Face 上两万余个 Llama 变体与“微调模型”中，[Llama Guard](https://github.com/meta-llama/PurpleLlama/blob/main/Llama-Guard3/8B/MODEL_CARD.md) 是企业的关键工具。Llama Guard 这类模型让组织能够对 AI 内容施加关键护栏，应对安全、合规与伦理考量。

本文中，我们将演示如何在 Llama Guard 及其他 prompt 安全模型的语境下，用 MAX 快速评估来自 Hugging Face 的多个模型。你将学会使用 Surge AI 的 [Toxicity 数据集](https://github.com/surge-ai/toxicity)对比 Meta 的 Llama Guard 与 IBM 的 [Granite Guardian](https://www.ibm.com/docs/en/watsonx/w-and-w/2.1.x?topic=models-granite-guardian-30-2b-model-card) 的性能，体验 MAX 如何以前所未有的速度加速模型评估。无论你的重点是合规、品牌保护还是打造安全的用户体验，MAX 都能为强化你的 AI 战略提供工具。

## 关于模型

正如羊驼在野外是天生的守护者，以警觉天性保护牛羊免受捕食者侵害，Meta 的 Llama Guard 在 AI 版图中扮演类似的守护角色。这个专门模型构建在 Meta Llama 家族的能力之上，跨多种语言、多种场景筛查内容——从用户提问到 AI 生成内容。和它的同名动物一样，它以惊人的准确率发现并归类潜在威胁。

使用我们提供的代码，并得益于 MAX 的灵活性，你可以把 Llama Guard 与多个其他模型直接对比，帮助你判断哪个模型最适合你的需求。一个备选是 IBM Granite Guardian：它依托 IBM 全面的 [AI Risk Atlas](https://www.ibm.com/docs/en/watsonx/saas?topic=ai-risk-atlas) 构建稳健的安全体系。经由严格测试与多样数据训练（包括精心构造的挑战场景），它提供 IBM 深厚数据安全履历所应有的可靠性。

## 关于数据集

为评估 Llama Guard 将内容归类为安全或不安全的能力，我们使用 Surge AI 的 Toxicity 数据集。评估中我们下载该数据集中[在 GitHub 上免费开放的子集](https://github.com/surge-ai/toxicity)。该集合包含 1000 条社交媒体帖子与评论，由人类审核员标注为 toxic 或 non-toxic。

## 配置 Hugging Face 访问

这里的工作将利用 MAX 运行 Hugging Face 上任意 PyTorch LLM 的能力。开始前，你必须从 Hugging Face 获取访问 token 才能下载其上托管的模型。按 [Hugging Face 文档](https://huggingface.co/docs/hub/en/security-tokens)的说明获取。

此外，Meta 在 Hugging Face 上对 Llama 家族模型的访问设置了门槛。访问 [Llama Guard 模型页面](https://huggingface.co/meta-llama/Llama-Guard-3-8B) 并提交申请表，通常几分钟内即可获批。IBM Granite 家族模型的访问是开放的，无需审批。

## 评估模型

MAX Serve 端点运行起来后，我们就能开始评估 Llama Guard。我们用 Python 下载 Surge AI Toxicity 数据集的免费子集，然后把集合中的每个样例送入模型做安全分类。最后计算一些标准指标，衡量模型预测与人工标注样本之间的偏差。

### 定义待评估模型

在下面的代码中，我们用 Python 的 enum 库定义每个待评估模型。这个 Model 类包含 Hugging Face 仓库 ID 以及模型用来指示不安全内容的关键词。

Python

from enum import Enum

class Model(Enum):
    LLAMA_GUARD = ("meta-llama/Llama-Guard-3-8B", "Unsafe")
    GRANITE_GUARD = ("ibm-granite/granite-guardian-3.0-2b", "Yes")

    def __init__(self, huggingface_repo_id, unsafe_classification_keyword):
        self.huggingface_repo_id = huggingface_repo_id
        self.unsafe_classification_keyword = unsafe_classification_keyword


selected_model = Model.LLAMA_GUARD

上面我们定义了两个模型：`LLAMA_GUARD` 使用关键词 "Unsafe"，`GRANITE_GUARD` 使用关键词 "Yes"。我们还把 `selected_model` 设为 `LLAMA_GUARD`，用该模型进行评估。

def get_llm_prediction(input):
    try:
        response = client.chat.completions.create(
            model=selected_model.huggingface_repo_id,
            messages=[{"role": "user", "content": input}]
        )
        content = response.choices[0].message.content
        return content
    
    except Exception as _:
        return None

### 下载数据集

接下来下载 Surge AI Toxicity 数据集的免费子集：

Python

import requests
import pandas as pd
from io import StringIO

def download_dataset():
    url = "https://raw.githubusercontent.com/surge-ai/toxicity/refs/heads/main/toxicity_en.csv"

    try:
        response = requests.get(url)
        response.raise_for_status()
        df = pd.read_csv(StringIO(response.text))        
        df['is_toxic'] = df['is_toxic'].apply(lambda x: 1 if x == 'Toxic' else 0)
        return df

    except Exception as e:
        print("Problem downloading dataset:", e)
        return None

上面的代码定义了一个以 CSV 格式获取数据集的函数。我们用 `requests` 库对 URL 发起 HTTP GET 请求并检查错误。成功后把 CSV 数据读入 pandas 的 `DataFrame`，并把 `is_toxic` 列的值从 'Toxic' 转为 1，其余转为 0。

### 运行评估

现在可以运行评估了！我们需要定义一个以数据集为输入的函数，把集合中每个样例发给 Llama Guard。由于处理全部 1000 个样例需要一些时间，我们用 `rich` 库显示进度条。

Python

import time
from rich.progress import Progress

def evaluate_llm(dataset, keyword="unsafe"):
    results = pd.DataFrame(columns=[
        "content",
        "y_true",
        "y_pred"
    ])

    size = len(dataset)
    start_time = time.time()

    with Progress() as progress:
        task = progress.add_task(
            f"[cyan]💬 Evaluating {selected_model.huggingface_repo_id}[/cyan]",
            total=size
        )

        for i, row in dataset.iterrows():
            content = row['text']
            y_true = row['is_toxic']
            response = get_llm_prediction(content)

            if response:
                y_pred = 1 if keyword.lower() in response.lower() else 0
                results.loc[i] = [content, y_true, y_pred]
            else:
                size -= 1

            progress.update(task, advance=1)

        progress.update(
            task, 
            description=f"[green]✅ Evaluated {selected_model.huggingface_repo_id} [/green]"
        )

    elapsed_time = time.time() - start_time
    elapsed_time_formatted = time.strftime("%H:%M:%S", time.gmtime(elapsed_time))
    
    print(f"Time Elapsed: {elapsed_time_formatted}")
    print("Sample Size:", size)

    return results

这里信息量不小，逐条拆解：

- 初始化一个 `DataFrame` 存储 `results`
- 用变量 `size` 记录模型成功处理的样本数
- 用 `time` 库记录 `start_time`
- 用 `rich` 库的 `Progress` 跟踪评估进度
- 对每个预测：如果响应有效，更新 `results` 集合；如果模型无法响应某个样例，就把 `size` 计数减一
- 处理完数据集后，计算并打印耗时与样本量
- 最后返回 `results` 供进一步分析

### 计算指标

最后，我们计算一些指标，帮助理解模型与样本数据的贴合程度。这里使用 `scikit-learn` 库，它是此类分析中极好用的工具。

Python

from sklearn.metrics import accuracy_score, precision_recall_fscore_support

def calculate_metrics(results):
    accuracy = accuracy_score(results["y_true"], results["y_pred"])
    precision, recall, f1, _ = precision_recall_fscore_support(
        results["y_true"], 
        results["y_pred"], 
        average="binary"
    )

    print(f"Accuracy: {accuracy:.2f}")
    print(f"Precision: {precision:.2f}")
    print(f"Recall: {recall:.2f}")
    print(f"F1 Score: {f1:.2f}")

上面的代码计算了几个标准二分类指标，对比 Llama Guard 的预测与 Toxicity 数据集的人工标注真值：

- **Accuracy（准确率）**：模型的预测多久与真值标签一致
- **Precision（精确率）**：在模型判为“unsafe”的样本中，有多少确实被人工标注为 toxic？
- **Recall（召回率）**：在所有人工标注为 toxic 的样本中，模型识别出了多少？
- **F1 Score**：precision 与 recall 的调和平均，一个兼顾两项指标的单一分数。调和平均对小值赋予更大权重，这正是它在 F1 分数中组合 precision 与 recall 时很实用的原因。
