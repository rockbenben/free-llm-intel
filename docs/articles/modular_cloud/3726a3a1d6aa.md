# MAX 与 Mojo 的全新简化版许可证

我们非常高兴地宣布，[MAX](https://www.modular.com/max) 与 [Mojo](https://www.modular.com/mojo) 的社区许可证迎来重大简化——让每个人都能比以往更容易地上手、实验并打造出色的产品。过去几个月里，我们认真倾听了社区的声音：在[我们的论坛](https://forum.modular.com/)、[Discord](https://discord.gg/modular)、线下聚会，以及数不清的聊天和邮件往来中。反馈非常明确：

- **我们的许可证让人觉得受限且困惑。** 大家不清楚哪些部分免费、哪些部分收费，也不清楚 MAX 和 Mojo 之间的关系。
- **Mojo 应该免费。** 作为一种编程语言，它不应该被收费墙或隐藏限制挡在后面。
- **MAX 与 Mojo 之间的边界模糊。** 人们希望有一个清晰、易懂的划分。

## **全新的简化思路**

我们吸收了这些反馈，直接着手简化。结果如何？一份直截了当、分层覆盖所有场景的许可证：

- **非生产-商用（Non-Production-Commercial）——完全免费。** 在任何设备上使用 MAX 和 Mojo 进行任何研究、爱好或学习项目。
  - **TLDR**：没有设备限制，没有隐藏条款，放手去做。
- **生产-商用（CPU 与 NVIDIA）——同样免费。** 在 x86 或 ARM CPU 或 NVIDIA GPU 上运行你的线上应用、内部工具或付费服务。
  - **TLDR**：零成本完整使用 MAX 和 Mojo。
- **生产-商用（其他加速器）——8 块 GPU 以内免费。** 我们目前还不支持其他加速器，但正在快速推进相关支持。对于 NVIDIA 之外的其他 GPU、TPU、FPGA 或任何设备——我们允许你在无需联系我们这种情况下扩展到 8 台设备。
  - **TLDR**：需要其他算力？只需联系我们的团队升级到自托管企业版，或获取额外许可选项。
- **展示你的成功**
如果你在生产环境中商业使用 MAX 与 Mojo——无论在 CPU 还是 NVIDIA 上——我们只想向全世界介绍你的项目。因此我们请你把 logo 和一个简短的故事发送到 [usage@modular.com](mailto:usage@modular.com)，我们会在营销材料、官网和社交媒体上展示你的用例。双赢：你得到免费软件，我们得以夸耀你的产品或公司有多出色。
