# Modverse #53：社区建设、研究里程碑和不断发展的生态系统

这一期收录了 Modular 生态系统的方方面面——从开发者用 MAX 和 Mojo🔥 搞的建设，到 Modular 在 AI 基础设施领域更广泛的影响力。一起来看看近来的动态。

## 社区创新

Modular 社区持续令人惊艳。从实用工具到在意外领域落地的 GPU 实验，以下是开发者们用 MAX 和 Mojo 创造的东西：

- [**ArgMojo**](https://github.com/forfudan/argmojo)**：** Yuhao Zhu 为 Mojo 打造了一个功能完备的 CLI 参数解析器，灵感来自 Python 的 argparse、Rust 的 clap 和 Go 的 cobra。支持长/短选项、flag 合并、可取反的 flag、互斥分组，以及自动生成的 `-help`/`-version`。用 `pixi add argmojo` 安装。
- [**EmberJSON：任意结构体的惰性解析**](https://forum.modular.com/t/lazy-parsing-arbitrary-structs-in-emberjson/2766)**：** Brian Grenier 借助 Mojo 新的类型反射工具，把 EmberJSON 又往前推了一步，加入了结构化序列化/反序列化和惰性解析。用户现在可以把个别字段（或整个结构体）的解析推迟到真正用到值的时候。
- [**Mojo GPU 内核用于数码照片编辑**](https://forum.modular.com/t/from-opencl-towards-mojo-gpu-kernels-in-digital-photo-editing-first-look/2764)**：** Max Chistokletov 尝试用 Mojo GPU 内核替换 Darktable 的 OpenCL 图像处理内核。在计算量更大的逐通道 sigmoid 色调映射操作上，他的 Mojo 实现在 Radeon RX 9070（RDNA4）上比 OpenCL 快 2.2 倍，直观展示了 Mojo 在 AI 推理之外的发光发热之地。

- [**MojoR：R 语言的"Numba"**](https://forum.modular.com/t/mojor-a-numba-for-r/2718)**：** 统计学博士 Seyoon Ko 正在构建一个 JIT 编译器，把标准 R 代码转译为 Mojo 内核，在 CPU/GPU 上执行，全程无需离开 R 会话。在二元 Gibbs 采样器上的早期基准显示，相比 GNU R 加速约 117 倍（0.16 秒对 19.28 秒）。
- [**Mist：ANSI 友好的终端工具箱**](https://forum.modular.com/t/mist-ansi-friendly-terminal-toolkit/2709)**：** Mikhail Tavarez 把 `mist` 重构成了一个功能全面的 Mojo 终端操作库，覆盖文本样式、ANSI 感知变换、终端控制（备用屏幕缓冲区、鼠标捕获、光标操作）和事件解析。配套 `banjo` 仓库里提供了包括贪吃蛇在内的新 TUI 示例。
- [**Floki：Requests 风格的 HTTP 客户端**](https://forum.modular.com/t/floki-requests-like-http-client-powered-by-libcurl/2739)**：** 同样出自 Mikhail Tavarez，Floki 是一个 Mojo 的 HTTP 客户端，API 仿照 Python 的 `requests` 包，底层由 libcurl 驱动。
- [**Decimo v0.8.0**](https://forum.modular.com/t/decimo-v0-8-0-is-out-on-pixi-a-big-milestone/2772)（原名 DeciMojo）：Yuhao Zhu 发布了以性能为重心的重要里程碑版本。亮点包括全新的 2^32 进制 `BigInt` 类型（带 Karatsuba 乘法和 Burnikel-Ziegler 除法）、`BigUInt` 的 Toom-Cook 三向乘法，以及大幅改进的 `BigDecimal` `sqrt`、`ln`、`exp` 实现。用 `pixi add decimo` 安装。
- [**NuMojo v0.8.0**](https://forum.modular.com/t/numojo-v0-8-0-update-is-here/2579)**：** Photon 的类 NumPy Mojo 库迎来大更新：Python 风格的复数字面量（`1j`）、初步的矩阵视图、与 Mojo 所有权模型对齐的显式拷贝语义、支持完整负索引的 NumPy 兼容切片，以及基于 Pixi 的构建后端。向 v1.0 迈出一大步。
- [**Mojo-GTK：自动生成的 GTK 绑定**](https://forum.modular.com/t/mojo-gtk-autogenerated-gtk-bindings-for-mojo/2581)**：** Hammad Ali 写了 Python 脚本为 Mojo 自动生成 GTK 绑定，覆盖 GTK 大部分控件与功能。已在 macOS 和 Ubuntu 上测试，并附带一个 OpenGL 演示。
- [**粉末模拟**](https://forum.modular.com/t/powder-simulation/2611)**：** 为了检验这些 GTK 绑定，Hammad 还用 Mojo + cairo + GTK 做了一个"落沙"风格的粉末模拟，包含沙、水、火、石头和木头。这是 Mojo GUI 开发可能性的一次趣味展示。

- [**mojo-marimo：在 Marimo 笔记本里跑 Mojo**](https://forum.modular.com/t/announcing-mojo-marimo-run-mojo-in-marimo-notebooks/2615)**：** Michael Booth 发布了一个库，提供三种在 marimo 交互式 Python 笔记本中运行 Mojo 的模式：基于装饰器的 API、动态字符串执行器，以及调用开销近乎为零的编译 `.so` 扩展模块。现已以 `py-run-mojo` 之名上架 PyPI。

💡 我们爱看你们的创作！把 MAX 或 Mojo 项目发到[论坛的 Community Showcase 分类](https://forum.modular.com/c/community-showcase/8)，方便我们在下一期中展示它们。

## Modular 声浪持续

Modular 持续在 AI 与开发者领域产生影响。近期动态一览：

- 橡树岭国家实验室（ORNL）与田纳西大学诺克斯维尔分校的研究人员在 SC '25 上发表了同行评审论文，评估 Mojo 在 GPU 上用于性能可移植科学计算的表现。结果显示，在访存受限的科学内核上，Mojo 在 NVIDIA H100 和 AMD MI300A 上与 CUDA 和 HIP 不相上下；该论文还获得了 WACCPD 2025 研讨会的最佳论文奖。[阅读论文](https://arxiv.org/abs/2509.21039)。她在最近的社区会议上也做了报告，解读这些结果对 Mojo 的意义。[观看录像](https://www.youtube.com/watch?v=IKA9fb5Zs7k)。

- 社区贡献者 Maxim Zaks 写了一篇精彩的文章 [当"魔法"变得显式](https://mzaks.medium.com/when-magic-becomes-explicit-mojos-take-on-metaprogramming-61bcfafc5145)，探讨 Mojo 的编译期反射与 trait 默认方法实现如何让任何库作者都能做出 Swift 一直锁在编译器魔法背后的那种自动 conformance 合成。他还在 CODAI 2026 上做了演讲，提出 Mojo 是多平台 AI 计算问题的答案，演示了编译期泛型、跨 GPU 派发以及 MAX 的定位。[观看演讲](https://www.youtube.com/watch?v=Wi6xnD-8Hp0&t=21398s)。
- QWERKY AI 发布了一篇详细的[技术深潜](https://qwerky.ai/blog/bringing-blazing-fast-state-space-models-to-the-modular-max-framework)，讲述他们的团队如何在两周内把状态空间模型（SSM/Mamba）作为一等公民支持做进 MAX 框架——其中包括可能是史上第一个纯 CPU 的 Selective Scan 和因果 conv1d 内核，以及新的 SSM 缓存层。想了解给 MAX 扩展一个根本不同的模型架构是什么体验，这篇很值得一读。
- Mojo 进 Jupyter 成了现实。fast.ai 联合创始人 Jeremy Howard 发布了 [mojokernel](https://github.com/AnswerDotAI/mojokernel)，一个 Jupyter 内核，让你在笔记本里直接运行 Mojo，变量在 cell 之间完全保持。支持 macOS 和较新的 Linux 版本，用 pip 或 uv 即可安装。来试试！
- TensorWave 发布了[一篇博客](https://tensorwave.com/blog/real-ai-workloads-on-amd-gpus-inference-training-and-scaling)，讲如何在 AMD GPU 上跑真实 AI 工作负载（推理、训练与扩展），其栈中包含了 Modular 平台。
- Business Insider 报道了 Modular 如何让 AI 无需重写代码就能在任何芯片上运行，以及这对 AI 基础设施未来意味着什么。戳[这里](https://www.businessinsider.com/nvidia-ai-chip-gpu-grip-modular-chris-lattner-google-2025-12)阅读。
- Chris Lattner 做客 Scott Hanselman 的 [Hanselminutes 播客](https://www.youtube.com/watch?v=pTM2bnFxyf8)，聊 Mojo，以及为什么今天的 AI 基础设施需要新的抽象。两人走完了从 LLVM、Swift 到 Mojo 的全程，深谈异构计算、内存所有权，以及"让开发者精确控制 AI 工作负载如何落到硅片上"意味着什么。
