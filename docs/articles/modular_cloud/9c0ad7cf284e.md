# Modverse #54：AMD AI DevDay、新的 Modular 办公室和持续交付的社区

四月值得庆祝的事很多：社区交付了 GPU 渲染器、FFmpeg 绑定、raylib 封装、BLAS 例程和一个 2D 图形 API——仅举这几样。团队在 AMD AI DevDay 以及我们与 AMD 的联合聚会上结识了大量开发者，Modular 在两大洲各开了一间新办公室，Gemma 4 发布当天即在 NVIDIA 和 AMD 上获得支持。以下是四月盘点。

## 社区创新

从 GPU 渲染到生物信息学工具再到游戏开发绑定，看看开发者这个月用 MAX 和 Mojo 造了什么：

- [**从 OpenCL 到 Mojo，第 2 篇：集成进现有项目**](https://forum.modular.com/t/from-opencl-to-mojo-part-2-integrating-into-an-existing-project/2974)**：** Max Chistokletov 带着他三月系列的续作回归——那个把 Darktable 的 OpenCL 图像处理内核换成 Mojo GPU 内核的项目。第 2 篇讲把这些内核接进生产代码库所需的集成工作——事实证明这比写内核本身还难。
- [**Mojo 进军机器人：移植 GPU 导航内核**](https://forum.modular.com/t/mojo-for-robotics-porting-gpu-navigation-kernels-jetson-strix-halo/2952)**：** 一个探索把 Mojo GPU 导航内核移植到 Jetson 和 AMD Strix Halo 需要付出什么代价的项目——两个硬件目标特性差异巨大。讨论涉及跨平台权衡与可移植性的成本。脚手架仓库在 [GitHub](https://github.com/aleph-ra/kompass-mojo)。
- [**MAV：Mojo 的 FFmpeg 绑定**](https://forum.modular.com/t/mav-ffmpeg-bindings-for-mojo/2955)**：** MAV（Mojo Audio Video）把 FFmpeg 绑定带进 Mojo，为这门语言打开视频与音频处理工作流。该项目在 4 月社区会议上做了展示。绑定入门见 [GitHub](https://forum.modular.com/t/mav-ffmpeg-bindings-for-mojo/2955)。
- [**Wgpu-mojo：wgpu-native 绑定**](https://forum.modular.com/t/wgpu-mojo-wgpu-native-bindings/2957)**：** Hundo1018 编写的绑定让 Mojo 程序能直接调用 wgpu-native 做 GPU 渲染。初始演示只画了一个三角形，但通往 Mojo 原生图形工具的道路已经打开。项目在 [GitHub](https://github.com/Hundo1018/wgpu-mojo)。

wgpu-mojo：通过 Mojo GPU 管线渲染的 RGB 渐变三角形

- [**MojoFlow：AI 原生的全栈框架**](https://forum.modular.com/t/introducing-mojoflow-ai-native-full-stack-framework-for-mojo/2956)**：** 一个面向生产的开源 Mojo 框架，覆盖服务端、客户端和 AI 管线组件。代码见 [GitHub](https://github.com/Lyvena/Mojoflow)。
- [**Cairo-mojo：Mojo 的 2D 渲染 API**](https://forum.modular.com/t/cairo-mojo-cairo-bindings-high-level-2d-rendering-api-for-mojo/2990)**：** Cairo-mojo 用高层 Mojo API 封装了 Cairo 图形库。不离开 Mojo 就能做实用的 2D 渲染。项目在 [GitHub](https://github.com/MoSafi2/cairo-mojo)。

cairo-mojo：由纯 Mojo 渲染的矢量图形输出

- [**mojoBLAS v0.1.0：纯 Mojo 的 BLAS 实现**](https://forum.modular.com/t/mojoblas-v0-1-0-a-pure-mojo-implementation-of-blas-routines/2992)**：** shivasankarka 发布了 mojoBLAS v0.1.0——BLAS 例程的纯 Mojo 实现，也就是几乎所有数值计算底层的线性代数原语。代码见 [GitHub](https://github.com/shivasankarka/mojoBLAS)。
- [**HDF5 绑定 v0.2.0**](https://forum.modular.com/t/hdf5-bindings-v0-2-0-is-out-mojo-v26-2/2993)**：** shivasankarka 还把 Mojo 的 HDF5 绑定更新到兼容 Mojo 26.2。HDF5 是科学计算和大型 ML 数据集的标准数据格式。代码见 [GitHub](https://github.com/shivasankarka/hdf5-mojo)。
- [**Mojo-bindgen：自动 C 绑定生成**](https://forum.modular.com/t/mojo-bindgen-automatic-c-binding-generation-for-mojo/2998)**：** MoSafi2 做了一个用 libclang 从 C 头文件生成 Mojo 绑定的工具，类似 rust-bindgen 但面向 Mojo。这套工具让你无需手工封装就能接入 C 生态。代码见 [GitHub](https://github.com/MoSafi2/mojo_bindgen)。
- [**Mojo-raylib：完整的 raylib v6 绑定**](https://forum.modular.com/t/mojo-raylib-complete-raylib-v6-bindings-for-mojo/3003)**：** 受 Mr. Azozin 近期视频启发，[kivicode](https://forum.modular.com/u/kivicode) 发布了 raylib v6 在 Mojo 下的完整代码生成绑定，覆盖这个流行 2D/3D 游戏开发库的全部 API。项目在 [GitHub](https://github.com/kivicode/mojo-raylib)。
- [**《Mojo By Example》一书更新到 v0.26.3**](https://forum.modular.com/t/book-mojo-by-example-is-now-updated-with-changes-corresponding-to-mojo-0-26-3/2982)**：** "Mojo By Example" 已更新以跟进最新稳定版，对正在入门这门语言的开发者重新变得有用。

💡 在用 MAX 或 Mojo 造东西？发到 [Community Showcase](https://forum.modular.com/c/community-showcase/8)，我们就可能在这里展示它。

## Modular 声浪持续

- **Gemma 4 在 Modular Cloud 零日上线。** Google DeepMind 发布 Gemma 4 时，Modular 已准备就绪。由 MAX 驱动的全部 Gemma 4 变体端点（包括 31B 稠密模型和 26B A4B MoE）当天上线，在 NVIDIA B200 上吞吐量比 vLLM 高 15%，且没有任何精度损失。完整故事见 [Modular 博客](https://www.modular.com/blog/day-zero-launch-fastest-performance-for-gemma-4-on-nvidia-and-amd)。
- **新博客系列：GPU 内核的软件流水线。** 第 1 篇讲核心挑战：如何让内存传输与计算重叠，让 GPU 硬件保持繁忙。如果你一直在追"结构化 Mojo 内核"系列，这是很好的下一篇。从 [第 1 篇](https://www.modular.com/blog/software-pipelining-for-gpu-kernels-part-1-the-pipeline-problem)读起。
- **结构化 Mojo 内核，第 4 篇：可移植性与未来之路。** 系列终篇讲述 Modular 的内核抽象如何处理跨硬件可移植性——同一份内核代码面向 NVIDIA 和 AMD GPU，无需重写。[第 4 篇在这里](https://www.modular.com/blog/structured-mojo-kernels-part-4-portability-and-the-road-ahead)。
- **TileTensor，第 1 篇：更安全、更高效的 GPU 内核。** 新系列介绍 TileTensor——Modular 用于在 GPU 内核开发中组织张量数据的抽象。第一篇讲核心设计，以及它为什么能让内核既更安全又更好写。从 [第 1 篇](https://www.modular.com/blog/tiletensor-part-1-safer-more-efficient-gpu-kernels)开始。
- **前沿编码智能体如何在 MAX 上构建视频扩散管线。** Claude、Cursor 和 Codex 借助 Mojo AI 编码技能在 MAX 上构建出可用的视频扩散管线，全程没有一行 GPU 内核代码由人类直接手写。这是了解当下 AI 辅助 GPU 开发面貌的极佳案例。全文见 [Modular 博客](https://www.modular.com/blog/how-frontier-coding-agents-built-a-video-diffusion-pipeline-on-max)。
- **MAX Serve 内部：从提示词到响应。** 新视频 walkthrough MAX Serve 如何处理一次推理请求的完整生命周期——从 token 到达，到调度、批处理，再到 GPU 执行。在 [YouTube](https://www.youtube.com/watch?v=hewZwTwDBcM) 观看。
- **爱丁堡和旧金山办公室开业。** Modular 新落成的爱丁堡办公室位于 Bayes Centre 内，AI 研究与产业团队比邻而作。团队同时也在旧金山 Jackson Square 打开了新办公室的大门。阅读[办公室公告](https://www.modular.com/blog/modular-opens-edinburgh-san-francisco-offices)。
