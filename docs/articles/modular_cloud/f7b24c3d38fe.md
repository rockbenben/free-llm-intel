# AI Agents 上架 AWS Marketplace

***Modular Inc.**** 宣布两款 Modular Platform 应用上架 AWS Marketplace 全新的 AI Agents and Tools 类别：****MAX High-Performance GenAI Serving**** 和 ****MAX Code Repo Agent****。*

**加州旧金山** -- **2025 年 7 月 16 日** -- AI 基础设施与高性能计算解决方案的领先提供商 Modular Inc. 今日宣布，其两款 Modular Platform 应用——**MAX High-Performance GenAI Serving Platform** 和 **MAX Code Repo Agent**——已上架 [AWS Marketplace 全新的 AI Agents and Tools 类别](https://aws.amazon.com/marketplace/solutions/ai-agents-and-tools/)。客户现在可以通过 AWS Marketplace 轻松发现、购买并部署 AI agent 解决方案，包括 Modular 的 AI 推理与开发效率解决方案，全程使用其 AWS 账户，从而加速 agent 与智能体工作流的开发。

Modular Platform 帮助企业加速 AI 推理部署，性能提升可达 10 倍，跨 NVIDIA 与 AMD 硬件优化 GPU 利用率，并借助智能代码辅助简化开发工作流。这让客户能够以业界领先的速度和效率部署生产就绪的 AI 应用，同时对 AI 基础设施保持完全的控制。

"把 MAX 和 Code Repo Agent 上架 AWS Marketplace，为客户提供了更便捷的途径来获取我们的高性能 AI 基础设施解决方案，帮助他们更快、更高效地部署和扩展智能体方案，"Modular 总裁 Tim Davis 表示，"我们在金融服务、医疗和企业软件开发行业的客户，已经在用这些能力实现 10 倍更快的推理速度、将运营成本最多降低 40%、加速开发周期，证明了统一 AI 基础设施平台的真实价值。"

[**MAX High-Performance GenAI Serving**](https://aws.amazon.com/marketplace/pp/prodview-t6oswipky4fhs) 提供一系列关键能力，包括 500 多个预优化模型、OpenAI 兼容的 API 集成以及跨平台 GPU 加速。这些特性让客户只需极少的代码改动即可部署生产级 AI 应用，并在 NVIDIA 与 AMD 硬件上取得业界领先的性能。

[**MAX Code Repo Agent**](https://aws.amazon.com/marketplace/pp/prodview-y6sus6r2riy6e) 提供仓库感知的问答能力、自动文档生成和智能代码辅助，帮助客户借助 AI 驱动的开发效率工具加速开发周期、提升代码质量。

关键技术差异化包括：

- 基于创新 Mojo kernel 构建的 **GPU 原生推理引擎**，消除对 CUDA 的依赖。
- 跨平台兼容性：支持 NVIDIA A100、H100、H200、L40、L4、A10 以及 AMD MI300X 加速器。
- **OpenAI 兼容的 REST API**，与现有应用无缝集成。

随着 AI Agents and Tools 类目在 AWS Marketplace 上线，客户可以显著加速采购流程、推动 AI 创新，减少供应商评估和复杂谈判所需的时间。通过 AWS 账户集中采购，客户可以在 AWS 内保持对许可、支付和访问的可见性与控制。

要了解 AWS Marketplace 上的 **Modular Platform** 更多信息，请访问 [**AWS Marketplace Modular 店铺**](https://aws.amazon.com/marketplace/seller-profile?id=seller-hcgoj6obnqlhs)**——**[**MAX Container**](https://aws.amazon.com/marketplace/pp/prodview-t6oswipky4fhs) 和 [**Code Repo Agent**](https://aws.amazon.com/marketplace/pp/prodview-y6sus6r2riy6e)。

*关于 ****Modular Inc.*** ***Modular 正在打造全球最佳的 AI 基础设施公司，创始团队来自主流科技公司中曾跨全栈构建 AI 基础设施、拥有数十年经验的顶尖工程师。公司使命是通过 MAX 平台和 Mojo 编程语言重新构想 AI 基础设施，让组织以前所未有的性能和简洁性构建、部署和扩展 AI 应用。***
