# 介绍 Mammoth：让企业级 GenAI 部署变得简单

今天，我们很高兴宣布 [**Mammoth**](https://www.modular.com/mammoth) 的公开预览——Modular 面向可扩展、高性能 GenAI 服务的 Kubernetes 原生平台。Mammoth 标志着我们普惠化 AI 基础设施使命的一大步。

## **Mammoth 是什么？**

Mammoth 是一款为企业级部署而设计的分布式 AI 服务工具。它弥合了模型与生产级推理基础设施之间的鸿沟，让你能在多样硬件上高效地服务多个模型——同时优化性能、控制成本、降低运维复杂度。

现有的服务方案迫使你在简单与规模之间二选一，而 Mammoth 通过智能自动化以及与 MAX 平台的垂直整合，把两者同时给到你。

## **我们为什么要构建 Mammoth**

构建 Mammoth 的旅程始于倾听我们的企业客户。一次又一次，我们听到同样的困扰：

> "我们能把一个模型跑好，但在整个基础设施上管理几十个模型简直是一场噩梦。"

> "我们的 GPU 利用率糟糕透顶，因为无法在不同的 AI 工作负载之间高效共享资源。"

> "竞争对手每月都在交付新的 AI 功能，而我们却被困在长达数月的部署周期里，只为把最新模型推上生产。"

随着组织从原型走向生产级 AI 服务、从小模型走向大模型，这些挑战会愈发尖锐。在受控演示里可行的东西，在数百万用户的规模下会失灵。

这些问题不只是技术上的不便——它们是 AI 规模化采用的根本障碍。公司花于管理基础设施的时间超过了创新。他们眼看昂贵的 GPU 资源闲置，同时又苦苦挣扎于满足性能需求。

业界需要一个既能抽象掉分布式 AI 服务的复杂性、又保留性能与硬件灵活性的平台。Mammoth 正是为此而生——建立在 MAX 无可匹敌的速度与可移植性之上。

## **智能编排的力量**

Mammoth 的智能控制面是它脱颖而出的地方——它充当你的 AI 基础设施的大脑，基于性能需求、集群状态和硬件能力自动优化模型放置。

想象你是一家媒体公司，在一个混合 GPU 集群上运行多个 AI 应用。你的内容审核系统在高峰期依赖 Llama 模型做快速文本分析，而你的视频平台用 Gemma 模型做实时分析和超低延迟聊天审核。同时，你的标签系统用 embedding 模型给海量内容分类，追求吞吐量而非速度。

为了支持这些用例，你的基础设施横跨混合 GPU——新的 NVIDIA B200 和 H100、早期部署留下的旧 A100，以及为降本和避免厂商锁定而近期加入的 AMD MI300x 和 MI325x。

> "传统做法迫使你对特定硬件手动配置每个模型，导致部署流程复杂、性能欠佳、资源利用率低下。"

Mammoth 的智能编排彻底改变了这一局面，重塑工作负载在你整个 GPU 集群上的运行方式。它在高峰期把实时内容分析优先放到最快的 GPU 上，在 A100 上高效运行审核模型，并把标签任务转移到性价比更高的 AMD 硬件上。当需求变化——比如标签任务在夜间激增——Mammoth 会自动重新分配资源以维持性能、最大化效率。

结果：每个模型都在恰当的时间运行在恰当的硬件上，把你多样的基础设施变成统一的、自适应的系统，为性价比和你不断变化的业务需求而优化。

## **生产中真正重要的特性**

**多模型、多硬件的高效：**在不同硬件类型上同时部署并服务多个模型，无需复杂配置。Mammoth 无缝地处理编排。

**带智能的自动扩缩：**Mammoth 的自动扩缩不只是拉起更多实例——它理解你的应用的性能需求，并以既维持这些保证又优化成本的方式进行扩缩。

**先进的资源优化：**Mammoth 实现解耦式推理架构，自动把工作负载拆分为专用于提示处理的 prefill 节点和专用于 token 生成的 decode 节点。这种智能拆分把每个推理阶段匹配到最优硬件，同时自动处理复杂的分布式优化，让你的团队专注于模型质量而非基础设施调优。

**企业级可靠性：**Mammoth 构建在 Kubernetes 之上，采用企业级可靠性模式，提供生产 AI 应用所需的容错与可观测性。

## **惊人的性能收益**

Mammoth 不是又一个 Kubernetes operator 或服务框架。Mammoth 提供的不是编排一堆定制组件，而是一个垂直整合的技术栈——从 MAX 到 Mojo 编程语言，每一层协同运作，把性能、效率和可移植性放大到传统框架无法企及的高度。

通过 Mammoth 部署意味着 MAX 的编译器、调度和批处理优化会自动针对你的硬件和流量调优，而 Mammoth 既理解模型特性又理解集群状态，并在各推理阶段之间无缝协调。结果：呈乘法效应的性能提升。

在把 Mammoth 的智能路由与传统服务框架所用的标准负载均衡进行对比的基准测试中，我们展示了**在多轮对话场景下超过 2 倍的吞吐量提升**。

最重要的是，Mammoth 随我们整个系统一起演进。当我们推进服务优化、硬件支持和模型架构时，你的部署会自动获益——无需重写，无需手动集成。技术栈无缝升级，让你的 AI 基础设施保持前沿，而不是沦为技术债。
