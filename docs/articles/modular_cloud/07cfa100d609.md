# Modular 25.6：统一 NVIDIA、AMD 与 Apple 的最新 GPU

## 介绍 25.6

我们很高兴宣布 Modular Platform 25.6——我们"构建 AI 统一计算层"使命中的一座重要里程碑。25.6 交付了迄今为止对我们使命最清晰的证明：**一个从笔记本一直延伸到全球最强大数据中心 GPU 的统一计算层**。该平台现在交付：

- **NVIDIA Blackwell (B200) GPU 上的峰值性能**：MAX 取得业界领先的吞吐与延迟收益，用我们公开的基准脚本完全可复现。
- **AMD MI355X GPU 上的峰值性能**：Modular 的性能提升在 AMD 最新的 MI355X GPU 上更为显著——早期基准显示 MI355X 上的 MAX 甚至能超过 Blackwell 上的 vLLM——而且我们还没到头！
- **面向 Apple、AMD 和 NVIDIA 消费级 GPU 的开发者支持**：开发者现在可以用 Mojo 为 AMD、NVIDIA 以及——呼声极高的——Apple Silicon GPU 等众多消费级 GPU 编程。Mojo 统一的编程模型，让广大学习 GPU 编程的开发者都能受益，而不只是拥有数据中心级加速器的企业。

除了新硬件，本次发布还构建在仅仅 7 周前 25.5 版之后的无数改进之上：开发者将享有全新的 `pip install mojo` 支持、增强的 VS Code 支持、Mojo 与 MAX API 的大量改进、更多模型支持，以及 changelog（[MAX](https://docs.modular.com/max/changelog/)🧑‍🚀、[Mojo](https://docs.modular.com/mojo/changelog/)🔥）里涵盖的许多其他特性。

## **为什么要统一计算？为什么是现在？**

**AI 极度渴望更多算力**！模型更大、prompt 更长、推理更复杂、推理需求爆炸。数据中心建设激增，新的"neo-cloud"不断涌现，各国政府竞相建设主权算力。NVIDIA、AMD 等 GPU 厂商加快产品周期——每年升级更多内存、带宽和新数据类型（FP4、FP6 及更远）。硬件初创公司募集数十亿美元试图切入，而超大规模云商则在自研硅片以保障供应、降低对第三方 GPU 厂商的依赖。

**但仅有硬件并不够。没有合适的软件，即便最强大的硬件也无法兑现其承诺。**开发者一直被困在碎片化、低效的技术栈里，让可移植性与峰值性能难以企及。Anthropic [最近揭开了这种痛苦的真相](https://www.anthropic.com/engineering/a-postmortem-of-three-recent-issues)——周旋于 NVIDIA GPU、Google TPU 和 AWS Trainium 之间：**瓶颈不是 FLOPs，而是缺乏能提供抽象、可移植性和端到端性能的全栈软件**。这是一场部署与运维的噩梦！

**业界长期寻求一个简单、可扩展的 AI 根基：**一个能在最先进硬件上交付业界最优性能与可移植性的统一计算层。随着 Modular 25.6 的发布，那个愿景如今已成现实——**一个统一 NVIDIA、AMD 和 Apple 最新 GPU 的统一软件层**。

#### **AMD MI355X：与 Blackwell 正面交锋**

AMD 发布 MI355X 正是为了与 NVIDIA Blackwell 正面竞争——而且它已被全球主要云服务商部署，包括我们的[合作伙伴 TensorWave](https://tensorwave.com/blog/save-up-to-70-with-max-the-fastest-inference-engine-on-amd-compute)。多亏 TensorWave，我们在 9 月 5 日——才两周半前——首次拿到 MI355X 硬件，我们很高兴分享：已经看到了强劲的成果。

## **Mojo🔥 支持 Apple Silicon GPU**

Modular 的使命是[普惠化 AI 算力](https://www.modular.com/democratizing-ai-compute)，我们深知数据中心加速器并非许多开发者触手可及。25.6 中，我们开始打破这层壁垒——启用对 **Apple Silicon GPU 的初步支持**，以及众多 NVIDIA 和 AMD 消费级 GPU。

Mac 用户第一次可以**用 Mojo 直接调用笔记本或桌面 GPU**，并尝试[前七个 Mojo GPU puzzles](https://puzzles.modular.com/introduction.html)。这一步让这些 GPU 算法无需修改即可运行在 Apple Silicon GPU、NVIDIA Blackwell、AMD MI325X、AMD MI355X 上，更不用说 Modular **已经支持**的 Hopper、Ampere、MI300 及其他 GPU。*一次编写，随处运行。*

Modular 对 Apple Silicon GPU 的支持正在快速演进：我们鼓励开发者使用我们的 [nightly 发布](https://docs.modular.com/mojo/manual/install)，它很快会启用端到端的 GenAI 模型执行。

## **pip install mojo 与全新的 Mojo LSP**

Mojo 开发现在只需一条命令：`pip install mojo`。

Mojo 的 PyPI 包第一次把**编译器、语言服务器协议（LSP）服务器和调试器打包在一起**。这意味着用 pip 或 uv 的开发者开箱即得*完整*的 Mojo 体验——甚至能发布直接依赖 Mojo 的自己的 PyPI 包。

我们还在推出一个**大幅改进的 Mojo VS Code 扩展**。它从零重建，同时支持 nightly 与 stable 项目，交付更流畅的体验——更快、更灵活，而且[完全开源](https://github.com/modular/mojo-vscode)！随着时间推移，它会变得更可定制，改善 Mojo 开发者的生活，无论你用 VS Code、Cursor 还是其他 IDE 编码。

Mojo 作为一门语言也获得了一些**令人兴奋的新能力**，例如崩溃时的调用栈、trait 的默认方法、对标准库的重大扩展，以及[远不止这些](https://docs.modular.com/mojo/changelog/)。
