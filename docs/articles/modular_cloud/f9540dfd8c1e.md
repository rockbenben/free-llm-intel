# Modverse #50：Modular 平台 25.5、社区聚会与 Mojo 首登 Stack Overflow 开发者调查

过去一个月，Modular 生态涌来一波社区项目与里程碑！

[Modular 平台 25.5 落地](https://www.modular.com/blog/modular-platform-25-5)，带来大规模批量推理（Large Scale Batch Inference）、更精简的包，以及让 AI 扩展前所未有的轻松的新集成。它已经在支撑生产部署——例如 SF Compute 的大规模推理批量 API——成本最多节省 80%，同时支持 15 个以上头部模型。

世界各地，Modular 社区忙得热火朝天：实验 Gaussian splatting、用 Mojo 构建概率数据结构、钻研 GPU 谜题、组织线下聚会。Mojo 还首次进入 [2025 Stack Overflow 开发者调查](https://survey.stackoverflow.co/2025/technology#admired-and-desired)——发布仅两年，又是其被快速采用的一座里程碑。

来看看 Modular 宇宙创造的一切。

# **博客、教程与视频**

- 在[七月社区会议](https://www.youtube.com/watch?v=VHhX3CkbtjQ)上，Maxim 展示了他刚合并的基于 Hasher 的哈希工作；三位 Modular Hack Weekend 获奖者也依次登场：用 Mojo 实现快速傅里叶变换的 Martin Vuyk、构建 GPU 加速区间重叠检测库 Mojo-Lapper 的 Seth Stadick，以及创建 GPU 驱动量子电路模拟器 QLabs 的 Thomas Trenty。

- Mojo 团队在论坛分享了 [Q2 回顾与 Q3 路线图更新](https://forum.modular.com/t/mojo-q3-roadmap-update/1957)。
- 两个 Modular 平台应用现已在 AWS Marketplace 新的 AI Agents and Tools 分类上线：[MAX 高性能 GenAI 服务平台](https://x.com/Modular/status/1945547983661240569)，含 500 多个预优化模型、OpenAI 兼容 API 与跨平台 GPU 加速。[MAX Code Repo Agent](https://aws.amazon.com/marketplace/pp/prodview-y6sus6r2riy6e)，提供仓库感知问答、自动化文档与智能代码辅助。
- 在 AI Performance Engineering Meetup 上，[Ehsan M. Kermani 演示了如何用 MAX 与 Mojo 替换 PyTorch 模型的任何部分](https://www.youtube.com/watch?v=jaiMotxv8ck)，让自定义算子轻松许多。
- Shubham Gupta 发布了 GPU Puzzles 系列的两篇深潜文章：[第 1 部分](https://shubhamg.in/posts/2025-07-06-gpu-puzzles-p1.html)讲解谜题 1-8，[第 2 部分](https://shubhamg.in/posts/2025-07-20-gpu-puzzles-p2.html)讲解谜题 9-14。全部解完后[告诉我们](https://docs.google.com/forms/d/e/1FAIpQLSeN1mwmLhF0fhtA6UBJnxhxmwgEVgrX4rV7Og2DrQVFmCt1JA/viewform)，我们会给你寄贴纸。
- GPU 开发者迎来了新挑战：
‍[GPU Puzzle 25](https://puzzles.modular.com/puzzle_25/puzzle_25.html)：用异步内存操作克服 GPU 内存瓶颈，优化一个内存受限的一维卷积。GPU Puzzles 第二部分：[谜题 9](https://puzzles.modular.com/puzzle_09/puzzle_09.html)介绍调试工作流与常见 GPU 问题；[谜题 10](https://puzzles.modular.com/puzzle_10/puzzle_10.html)教你用 NVIDIA 的 [`compute-sanitizer`](https://lnkd.in/gNZUg5yk) 发现并修复竞态条件。
- [Chris Lattner 做客 Richard Feldman 的](https://www.youtube.com/watch?v=ah9Tfebk7JA) Software Unscripted 播客。
- [新 Modular Tech Talk](https://www.youtube.com/watch?v=jatv_K0D1fo)：Deep Dhillon 探讨高性能 LLM 服务的挑战，以及我们的 Kubernetes 原生分布式服务工具 Mammoth 如何跨架构交付可扩展性能。

- Mojo 在发布仅两年后[首次进入](https://survey.stackoverflow.co/2025/technology#admired-and-desired) 2025 Stack Overflow 开发者调查。
- 我们与 SF Compute 合作推出大规模推理批量 API，提供最多 80% 的成本节省、15 个以上头部模型支持和实时 GPU 现货定价。观看[发布视频](https://www.youtube.com/watch?v=PZIqVuvaJgE&feature=youtu.be)，阅读[博客](https://www.modular.com/blog/sf-compute?utm_source=x&utm_campaign=sfcompute)，想试用请[联系我们](https://www.modular.com/company/talk-to-us)。

- [Modular 平台 25.5 已至](https://www.modular.com/blog/modular-platform-25-5)，为需要规模的开发者而生。亮点包括：大规模批量推理——由 Mammoth 驱动的高吞吐 OpenAI 兼容 API，已在 SF Compute 生产上线。独立 Mojo Conda 包、更精简（<700 MB）的 MAX Serving 包、完全开源的 MAX Graph API，以及无缝的 MAX ↔ PyTorch 集成。完整细节：[MAX changelog](https://docs.modular.com/max/changelog/#v255-2025-08-05) | [Mojo changelog](https://docs.modular.com/mojo/changelog/#v255-2025-08-05)。
- [八月社区会议](https://www.youtube.com/watch?v=t2hAfgDYHoc)包括 Manuel 的 mojo-regex 优化、Amir 的 Apple GPU 更新，以及与团队的现场 Q&A。

- 错过我们的 [Modular 平台 25.5 直播](https://www.youtube.com/watch?v=CUzBMz-61GE)？内容覆盖大规模批量推理、Mojo、MAX、PyTorch 自定义算子，并回答了海量社区问题。

- 8 月 28 日将在我们 Los Altos 总部搞大事：与 Modular 和 Inworld AI 的演讲与社交！[Chris Lattner](https://www.linkedin.com/in/chris-lattner-5664498a/) 谈算力的开放未来与 Mojo，[Feifan Fan](https://www.linkedin.com/in/fanff/) 谈生产环境中的语音 AI，[Chris Hoge](https://www.linkedin.com/in/hogepodge/) 谈 matmul 优化。[来占个座](https://lu.ma/modular-aug-meetup)。

- Ferdinand Schenck 撰文讲述[把 scikit-learn 的 Cython 翻译成 Mojo](https://fnands.com/blog/2025/sklearn-mojo-dbscan-inner/)。
- Ekemini Samuel 在非洲发起了[聚焦 Mojo 的社区](https://x.com/mojoafricahq)，并在 Uyo 举办了[首场聚会](https://app.getriver.io/beta/events/mojo-africa-premiere-2025-1h7)。

# **Awesome MAX + Mojo**

- Bernardo 分享了[把 CUDA C++ 写的 Gaussian splatting kernels 移植到 Mojo](https://forum.modular.com/t/my-first-rasterized-image-from-3d-gaussians-in-mojo-called-as-pytorch-customop/1971)的工作。

- seiflotfy 构建了 [mojo-hyperloglog](https://forum.modular.com/t/hyperloglog-in-mojo/2032)——HyperLogLog 的 Mojo 实现。HyperLogLog 是一种用极小内存统计唯一元素数量的概率数据结构。
- rd4com 创建了 [live-stats-for-linux-based-operating-systems-in-mojo](https://forum.modular.com/t/live-stats-for-linux-based-operating-systems-in-mojo/1948)——一个提供 CPU 与 GPU 状态实时系统总览的应用。

- TilliFe 发布了 [Nabla Python API 的 GPU 支持](https://forum.modular.com/t/releasing-the-nabla-python-api/1646/6?u=caroline)。
- HammadHAB 为其 Mojo GUI 库 CombustUI 发布了[完整 API 参考、安装文档与示例](https://forum.modular.com/t/combustui-gui-bindings-for-mojo/573)。
