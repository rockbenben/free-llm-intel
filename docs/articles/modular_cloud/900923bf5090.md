# Modverse #46：MAX 25.1、MAX Builds 与 AI 算力普惠化

我们不久前发布了 MAX 25.1，这是 AI 开发的一次重大飞跃。该版本增强了 agentic 与 LLM 工作流，推出 MAX Builds 作为 GenAI 模型与应用配方的中心枢纽，并首发了全新 GPU 编程接口。开发者现在可以用上 GPU 加速的 embeddings、OpenAI 兼容的 function calling、结构化输出生成，以及 paged attention 和 prefix caching 这类高性能 LLM 优化以提升效率。

MAX 25.1 也标志着转向 nightly 发布模式，让开发者提前获得新功能、实时社区驱动的改进和持续创新。配合离线批量推理、通过 MAX Graphs 用 Mojo 做 GPU 编程、以及从本地到云的简化部署，MAX 25.1 带来了更强的性能与灵活性。今天就上手：探索 [MAX Builds](https://builds.modular.com/?category=featured&utm_campaign=community&utm_source=modverse)、深入[文档](https://docs.modular.com/max/?utm_campaign=community&utm_source=modverse)，并加入[社区论坛](https://forum.modular.com/)！
