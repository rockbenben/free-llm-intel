# Modverse #54：从 GTC 到爱丁堡，社区势能持续累积

这一期覆盖的是 Modular 近来最忙的时段之一：GTC 上的四天、另一大洲的新办公室、新鲜出炉的社区作品，还有一个拓展 MAX 与 Mojo🔥 能力边界的版本。以下是整个生态的近况。

## 社区创新

本月聚焦：

- [**mojo-js：一个 Mojo 转 JavaScript 的转译器实验**](https://forum.modular.com/t/mojo-js-a-mojo-to-javascript-transpiler-experiment/2819)：Jeroen van Bemmel（jbemmel）做了一个概念验证转译器，把 Mojo 风格的源码映射成可执行的 JavaScript，自带词法分析器、AST 解析器和约 50 个 CI 测试用例。目标是概念性的：探索 Mojo 作为浏览器运行时的编写语言。[演示](https://exergy-connect.github.io/mojo-js/web/) · [GitHub](https://github.com/exergy-connect/mojo-js)
- [**实用 Mojo 示例集**](https://forum.modular.com/t/tested-mojo-0-26-1-examples-in-github/2826)：ahmetax 一直在 GitHub 上构建并分享一个不断增长的集合——50 多个经过测试的 Mojo 0.26.1 脚本，是学习这门语言的开发者的实用上手参考。[GitHub](https://github.com/ahmetax/Practical-Mojo-Examples)
- [**ui-terminal-mojo 更新到 26.2.0**](https://forum.modular.com/t/ui-terminal-mojo-upgraded-to-26-2-0-nightly/2829)：rd4com 把他们的纯 Mojo TUI 框架更新到 26.2.0 nightly，现已确认在 macOS M4 和 Linux 上可用，内存占用约 6MB、CPU 占用 0.3。框架用即时模式循环取代回调，支持自动缩放的动态布局和可切换的标签菜单。没有额外依赖，只用 `external_call`。[GitHub](https://github.com/rd4com/ui-terminal-mojo)
- [**Marrow：Mojo 实现的 Apache Arrow**](https://forum.modular.com/t/marrow-apache-arrow-in-mojo/2840)：kszucs 正在用 Mojo 构建原生 Apache Arrow 实现，已经引人侧目。核心抽象就位：数组、builder、计算内核、Python 绑定，以及经由 C Data Interface 与 PyArrow 的零拷贝互操作。早期基准显示，在数值、字符串和嵌套列表类型转换上 Marrow 比 PyArrow 快 1.3-3.9 倍，并通过 Mojo 的 `DeviceContext` 提供实验性 GPU 支持。Arrow 驱动着 Pandas 2.0、Polars、Spark 和几乎所有现代数据工具。Mojo 现在有了一条进入该生态的路。[GitHub](https://github.com/kszucs/marrow)

- [**Decimo v0.9.0：CLI 计算器与 Python 绑定**](https://forum.modular.com/t/decimo-v0-9-0-now-with-a-cli-calculator-and-python-bindings/2899)：Yuhao Zhu 发布了 Decimo v0.9.0（兼容 Mojo 26.2），这个版本很好玩。Decimo 现在也是一个基于 ArgMojo 的命令行任意精度计算器——词法分析、调度场算法解析器、RPN 求值器，全部编译成一个零运行时依赖的单一原生二进制。该版本还通过 `PythonModuleBuilder` 添加了 Python 绑定，把 `BigDecimal` 作为原生 CPython 扩展暴露出来，已上架 PyPI。`pixi add decimo` [GitHub](https://github.com/forfudan/decimo)
- [**Mojo 与异构计算中缺失的那一层**](https://forum.modular.com/t/mojo-and-the-missing-layer-in-heterogeneous-compute/2905)：Jeroen van Bemmel 在 mojo-js 之后跟进了一场讨论——可编程的异构计算与*经济上可触及的*异构计算之间的鸿沟——并把项目扩展到从浏览器把 Mojo 源计算任务发往 Distributive Compute Platform（DCP）。关于 Mojo 运行时与分布式计算市场之间的协调层可能长什么样，这篇很能引发思考。[原型](https://exergy-connect.github.io/mojo-js/web/dcp.html)
- **BlazeSeq**——Mohamed Mabrouk 面向生物信息学管线的高吞吐 FASTQ 解析器，在我们 3 月的社区会议上做了展示。BlazeSeq 单线程零拷贝解析达到 5+ GB/s，附带 GPU 友好的 Structure-of-Arrays 批量 API 可直接做主机到设备的传输，并通过 `rapidgzip` 集成并行 gzip 解压，相比标准工具端到端提速最高 5 倍。Python 绑定可用 `pip install blazeseq` 安装。[论坛帖](https://forum.modular.com/t/blazeseq-zero-copy-gpu-friendly-fastq-parsing/2795)

💡 我们爱看你们的创作！把 MAX 或 Mojo 项目发到[论坛的 Community Showcase 分类](https://forum.modular.com/c/community-showcase/8)，方便我们在下一期中展示。

## Modular 新闻与活动：保持联络

- **Modular 26.2 发布。** 最新版本把 Modular Platform 扩展到了图像生成与编辑工作流，支持 FLUX.2 模型变体，相对最先进方案加速超过 4 倍。Mojo 方面，26.2 带来了新语言特性和专为 GPU 内核开发打造的 AI 编码技能。Claude、Cursor、Codex 这样的智能体现在可以跨硬件目标编写、移植和优化内核——上下文是 Mojo 的类 Python 语法和 75 万多行开源内核代码。[阅读发布博客](https://www.modular.com/blog/modular-26-2-state-of-the-art-image-generation-and-upgraded-ai-coding-with-mojo)。
- **错过了我们 3 月的社区会议？** Mohamed Mabrouk 展示了 BlazeSeq，Modular 的 Lukas 深度讲解了 Mojo 中的可变参数元编程（Variadic Metaprogramming），我们还串讲了 26.2 的发布亮点。[点击观看](https://www.modular.com/blog/modular-26-2-state-of-the-art-image-generation-and-upgraded-ai-coding-with-mojo)。
- **结构化 Mojo 内核系列。** 如果你一直没追这个系列，现在是补上的好时机。已出三篇，团队 walkthrough 了 Modular 最高性能内核背后的架构——从设计理念到 TileIO、TilePipeline、TileOp，再到 conv2d 和 block-scaled matmul 如何构建在同一套地基上。[阅读第 1 篇](https://www.modular.com/blog/structured-mojo-kernels-part-1-peak-performance-half-the-code)。
- **《Programming Massively Parallel Processors》** 是 GPU 编程教材的金标准，第 5 版刚刚发布。每道习题都有 Mojo 解答。[来看看仓库，感受 GPU 编程在 Mojo 里长什么样](https://github.com/modular/modular/tree/main/max/kernels/examples/pmpp)。
