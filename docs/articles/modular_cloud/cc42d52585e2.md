# 本地开发，全球部署

近来 AI 应用开发的激增可归因于几个因素：(1) 机器学习算法的进步解锁了以往难以处理的应用场景，(2) 算力的指数级增长让训练越来越复杂的模型成为可能，(3) 支撑这些算法的海量数据集无处不在。然而，随着 AI 项目日益普及，**传统软件开发中常见的那些高效开发范式仍然难以企及。**

具体而言，构建打通本地开发与云端部署的精简、可扩展开发工作流几乎仍不可能。这些工作流之所以复杂，是因为 AI 工具链高度碎片化，每个工具都有各自的取舍与局限。

今天的 AI 开发者不得不在端到端 AI 工作流中使用大量不同的工具。有些工具适用于云端加速器，但本地只能跑 CPU；另一些擅长本地 CPU 开发，却无法上云。跨这些工具协作需要令人头疼的抽象层和翻译层来统一根本互不兼容的技术，甚至要求重写模型或应用代码才能让它们协同工作。

有时候，**要拼出正确的工具与硬件组合，以支持完整的开发生命周期、并为任意给定模型提供最佳的性价比权衡，似乎是不可能的。**

## MAX 如何提供帮助

MAX 通过提供统一的推理 API 来解决这些问题，其背后是业界领先的编译器和推理运行时，可跨本地笔记本和常见云实例支持多种模型与硬件类型。MAX 不要求你把整条 AI 流水线和服务基础设施迁移到新东西上——它在你的现状处接住你，让你渐进式升级。

MAX 让你的流水线可在广泛的 CPU 架构（Intel、AMD 和 ARM）与 GPU 之间移植，打开更大的可移植性与性能空间。MAX 让你能以最优价格利用不同云实例的广度与深度，确保始终获得最佳的推理性价比。

### MAX 解锁从本地到云

有了 MAX，你可以在本地开发 AI 应用，然后轻松打包部署到任何云环境。这个统一工作流带来几个关键优势：

- **速度与灵活性**：下载 MAX 即可本地开发，快速迭代和测试。重要的是，MAX 不只是能跑在本地，在许多场景下还比 llama.cpp 这类业界标准本地 LLM 框架更快，让开发更快。你可以迅速修改代码、跑实验、调试问题，无需远程服务器的搭建和延迟。
- **资源可得性**：在本地机器上，你可以免费直接使用 CPU、GPU 等本地硬件资源。无需开启并付费云实例，也不受供应瓶颈限制。
- **控制与定制**：本地环境可以按具体项目需求定制，开发者可不受限制地安装自定义库、框架和工具。重要的是，对于延迟敏感的应用，完全受控的本地开发机器比共享云实例噪音更小。
- **一致性**：在本地用 MAX 开发，并把我们的基础设施打包进 Docker 等 OCI 兼容容器，意味着你可以确保本地构建的东西在生产环境无缝运行。
- **全球规模**：最后，MAX 针对 AWS、Azure、GCP 等主流数据中心云供应商的 AI 硬件（包括 CPU 和 GPU *(即将推出！)*）做了高度优化。用户无需修改代码即可全球扩展其 AI 应用，并获得业界领先性能。

## MAX 的工作原理

业界缺乏统一的 AI 基础设施平台，充斥的只是只对特定模型、硬件和操作系统有效的"点状方案"。当我们着手统一全球 AI 基础设施时，意识到技术栈的碎片化源于缺乏面向 AI 硬件的统一编程模型。这就是[我们创造 Mojo 的原因](https://docs.modular.com/mojo/why-mojo)——一门面向 AI 硬件的崭新统一编程语言，兼具 Python 的表达力与 C 的性能。

Mojo 是核心技术，为 MAX 平台的其余部分提供根基。MAX Engine——我们的下一代图编译器与运行时系统——用 Mojo 实现其底层数学操作，如 MatMul。这带来了无可比拟的可移植性与性能，让本地到云的工作流成为可能。你可以把任意模型加载进 MAX Engine，在广泛的硬件上实现低延迟推理。

话虽如此，**使用 MAX 并不需要你会 Mojo**。你可以用我们的 Python 和 C API 库把现有模型带入框架并在 MAX Engine 上执行。不过，Mojo 配合 MAX 会给你超能力：Mojo 允许你为模型[编写自定义 ops](https://docs.modular.com/nightly/max/tutorials/build-custom-ops)，或在 MAX Engine 中[编写完整推理图](https://docs.modular.com/max/graph/)以获得最佳性能。

最后，把 MAX 集成进你的 AI 开发工作流，让你能轻松使用具备健壮扩缩、监控和部署模板的可信工具，把本地开发的模型部署到生产。

借助 MAX，你可以用业界兼容的工具（包括 NVIDIA 的 Triton Server）来服务你的模型。由于我们已经与你现用的工具互操作，把 MAX 放进需要模型版本管理、多模型部署和多样部署环境的既有工作流非常容易，使它成为 AI 推理部署的多面手。[现在就读读这件事有多简单！](https://docs.modular.com/nightly/max/get-started)
